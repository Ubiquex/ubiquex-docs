`ubx` is currently in **private preview**. The repository is private and
external contributions are not yet open.

## Reporting issues

If you have access to the private repository, file issues directly at
[github.com/Ubiquex/ubiquex-cli](https://github.com/Ubiquex/ubiquex-cli).

## Requesting access

Access to the private preview is granted individually. If you operate
Terraform, GCP, or Kubernetes infrastructure in production and want to
try ubx against a real account, reach out — early users get direct
support and their feedback shapes the roadmap.

## When this changes

This page will be replaced with full contribution guidelines
(development setup, conformance testing conventions, and the
documentation verification workflow) when the repository opens.

`datadog_due_date_rule_response` is a real rule that automatically assigns a due date to a Datadog Case Management case or Security Inbox finding based on its own severity or type -- the mechanism behind Datadog's real SLA tracking for security and operational work.

## Properties

<ResponseField name="data" type="object" required>
  The data object for a due date rule create or update request. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for creating or updating a due date rule. Required.
      <Expandable title="properties">
        <ResponseField name="action" type="object" required>
          The action to take when the due date rule matches a finding. Required.
          <Expandable title="properties">
            <ResponseField name="due_days_per_severity" type="list(object)" required>
              A list of severity-to-due-date mappings. Each severity may appear at most once. Required.
              <Expandable title="properties">
                <ResponseField name="due_in_days" type="number">
                  Optional; if omitted, computed by Datadog.
                </ResponseField>
                <ResponseField name="severity" type="string">
                  Optional; if omitted, computed by Datadog.
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="due_from" type="string" required>
              The reference point from which the due date is calculated. When `fix_available` is selected but not applicable to the finding type, `first_seen` is used instead. Required.
            </ResponseField>
            <ResponseField name="reason_description" type="string">
              An optional description providing more context for the due date assignment. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="enabled" type="bool">
          Whether the due date rule is enabled. Optional.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of the due date rule. Required.
        </ResponseField>
        <ResponseField name="rule" type="object" required>
          Defines the scope of findings to which the automation rule applies. Required.
          <Expandable title="properties">
            <ResponseField name="finding_types" type="list(string)" required>
              The list of security finding types that the automation rule applies to. Required.
            </ResponseField>
            <ResponseField name="query" type="string">
              A search query to further filter the findings matched by this rule. The `@workflow.*` namespace and `@status` fields are not permitted. For a reference of available fields, see the [Security Findings schema documentation](https://docs.datadoghq.com/security/guide/findings-schema/). Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The JSON:API type for due date rules. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

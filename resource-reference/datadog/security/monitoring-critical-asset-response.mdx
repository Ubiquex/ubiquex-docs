`datadog_security_monitoring_critical_asset_response` is a real asset an organization has flagged as business-critical inside Datadog Cloud SIEM -- security findings touching a critical asset are weighted/prioritized differently than the same finding on a non-critical one.

## Properties

<ResponseField name="critical_asset_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="data" type="object" required>
  Object for a single critical asset. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Object containing the attributes of the critical asset to be created. Required.
      <Expandable title="properties">
        <ResponseField name="description" type="string">
          A description of the critical asset. Optional.
        </ResponseField>
        <ResponseField name="enabled" type="bool">
          Whether the critical asset is enabled. Defaults to `true` if not specified. Optional.
        </ResponseField>
        <ResponseField name="query" type="string" required>
          The query for the critical asset. It uses the same syntax as the queries to search signals in the Signals Explorer. Required.
        </ResponseField>
        <ResponseField name="rule_query" type="string" required>
          The rule query of the critical asset, with the same syntax as the search bar for detection rules. This determines which rules this critical asset will apply to. Required.
        </ResponseField>
        <ResponseField name="severity" type="string" required>
          Severity associated with this critical asset. Either an explicit severity can be set, or the severity can be increased or decreased, or the severity can be left unchanged (no-op). Required.
        </ResponseField>
        <ResponseField name="tags" type="list(string)">
          List of tags associated with the critical asset. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. The value should always be `critical_assets`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

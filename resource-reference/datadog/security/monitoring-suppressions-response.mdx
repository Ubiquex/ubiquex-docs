`datadog_security_monitoring_suppressions_response` is the real, listable collection view over an organization's configured `datadog_security_monitoring_suppression_response` entries.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own monitoring suppressions response"})

    		ubx.Resource(security.MonitoringSuppressionsResponse, "example", security.MonitoringSuppressionsResponseConfig{
    			RuleId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

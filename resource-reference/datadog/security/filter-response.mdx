`datadog_security_filter_response` is a real filter controlling which logs are actually evaluated by Datadog Cloud SIEM's security-monitoring detection rules -- scoping detection to relevant log traffic and excluding known-noisy or irrelevant sources.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})

## Input properties

<ResponseField name="data" type="object" required>
  Object for a single security filter. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Object containing the attributes of the security filter to be created. Required.
      <Expandable title="properties">
        <ResponseField name="exclusion_filters" type="list(object)" required>
          Exclusion filters to exclude some logs from the security filter. Required.
          <Expandable title="properties">
            <ResponseField name="name" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="query" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="filtered_data_type" type="string" required>
          The filtered data type. Required.
        </ResponseField>
        <ResponseField name="is_enabled" type="bool" required>
          Whether the security filter is enabled. Required.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of the security filter. Required.
        </ResponseField>
        <ResponseField name="query" type="string" required>
          The query of the security filter. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. The value should always be `security_filters`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="security_filter_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`datadog_security_monitoring_dataset_response` is a real, defined dataset scoped specifically for Cloud SIEM security-monitoring rules to run against -- the security-specific counterpart to the general `datadog_dataset_response_single`.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own monitoring dataset response"})

    		ubx.Resource(security.MonitoringDatasetResponse, "example", security.MonitoringDatasetResponseConfig{

    		})
    	}))
    }

`datadog_cloud_workload_security_agent_policy_response` is a real policy controlling what Datadog Cloud Workload Security (CWS) monitors and enforces on a protected host or container -- which detection rules are active and in what mode (detect-only vs. block).

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workload security agent policy response"})

    			Data:     map[string]any{"attributes": map[string]any{"name": "example-name"}},

    		})
    	}))
    }

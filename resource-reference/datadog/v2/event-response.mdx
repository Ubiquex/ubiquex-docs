`datadog_v2_event_response` is v2's own richer representation of a Datadog Event -- a real, timestamped occurrence (a deploy, an alert, a comment) posted to the Event stream, distinct from this same resource's plain `datadog_event_response` (v1) by carrying a real, structured `attributes` payload instead of v1's flatter shape.

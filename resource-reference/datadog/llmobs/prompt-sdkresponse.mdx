`datadog_llmobs_prompt_sdkresponse` is a real, versioned prompt managed through Datadog LLM Observability's Prompt Hub -- letting a team track and iterate on the actual prompt text used in a production LLM application as a first-class, versioned object.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	llmobs "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/llmobs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own prompt sdkresponse"})

    		ubx.Resource(llmobs.PromptSdkresponse, "example", llmobs.PromptSdkresponseConfig{
    			Data:     map[string]any{"attributes": map[string]any{"prompt_id": "example"}},
    			PromptId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="data" type="object" required>
  Data object for creating an Agent Observability prompt. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for creating an Agent Observability prompt and its first version. `prompt_id` and `template` are required; all other attributes are optional. Required.
      <Expandable title="properties">
        <ResponseField name="description" type="string">
          Optional description of the prompt. Optional.
        </ResponseField>
        <ResponseField name="env_ids" type="list(string)">
          Optional feature-flag environment UUIDs the service attempts to enable and configure to use the first version as their default after creation. Optional.
        </ResponseField>
        <ResponseField name="labels" type="list(string)">
          Optional labels to attach to the first version. Do not use this attribute for new integrations. Optional.
        </ResponseField>
        <ResponseField name="prompt_id" type="string" required>
          Customer-provided identifier for the new prompt. Required.
        </ResponseField>
        <ResponseField name="template" type="any" required>
          A text template or a list of chat messages. Required.
        </ResponseField>
        <ResponseField name="title" type="string">
          Optional title of the prompt. Optional.
        </ResponseField>
        <ResponseField name="user_version" type="string">
          Optional user-supplied version identifier for the first version. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Resource type of an Agent Observability prompt. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

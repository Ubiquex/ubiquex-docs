`datadog_dashboard` is a real-time visualization built from Datadog's own metrics, traces, and logs, used to track KPIs, spot anomalies, and troubleshoot problems as they happen. Dashboards come in a few real layout styles -- grid-based, timeboard, and free-form screenboard -- suited to different jobs, from an always-on status view to ad hoc data exploration.

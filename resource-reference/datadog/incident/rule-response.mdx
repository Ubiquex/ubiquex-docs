`datadog_incident_rule_response` is a real rule that automatically classifies or acts on an incoming Datadog incident based on its own attributes -- for example, auto-assigning a severity or a responder team based on which service is affected.

## Example

    ```go
    package main

    import (
    	incident "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/incident"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own rule response"})

    		ubx.Resource(incident.RuleResponse, "example", incident.RuleResponseConfig{
    			Data:   map[string]any{"attributes": map[string]any{"condition": map[string]any{"normalized_query": "example"}}},
    			RuleId: "example",
    		})
    	}))
    }
    ```

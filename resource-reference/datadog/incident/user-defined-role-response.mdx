`datadog_incident_user_defined_role_response` is a real, custom responder role an organization defines for incidents beyond Datadog's built-in roles -- for example, "Communications Lead" or "Customer Liaison", used the same way `datadog_incident_responder_response` assigns built-in roles.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	incident "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/incident"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user defined role response"})

    		ubx.Resource(incident.UserDefinedRoleResponse, "example", incident.UserDefinedRoleResponseConfig{
    			Data:   map[string]any{"attributes": map[string]any{"name": "example-name"}},
    			RoleId: "example",
    		})
    	}))
    }
    ```
  </Tab>

    import { intent, resource, stack } from "@ubx/sdk";

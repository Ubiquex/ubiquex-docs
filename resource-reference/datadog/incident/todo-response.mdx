`datadog_incident_todo_response` is a real, tracked action item on a Datadog incident -- a concrete follow-up task (write the postmortem, patch the root cause) with its own assignee and completion state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	incident "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/incident"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own todo response"})

    		ubx.Resource(incident.TodoResponse, "example", incident.TodoResponseConfig{
    			Data:       map[string]any{"attributes": map[string]any{"assignees": []string{"example"}}},
    			IncidentId: "example",
    			TodoId:     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="data" type="object" required>
  Incident todo data for a create request. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Incident todo's attributes. Required.
      <Expandable title="properties">
        <ResponseField name="assignees" type="list(any)" required>
          Array of todo assignees. Required.
        </ResponseField>
        <ResponseField name="completed" type="string">
          Timestamp when the todo was completed. Optional.
        </ResponseField>
        <ResponseField name="content" type="string" required>
          The follow-up task's content. Required.
        </ResponseField>
        <ResponseField name="created" type="string">
          Timestamp when the incident todo was created. Computed by Datadog after `ship`.
        </ResponseField>
        <ResponseField name="due_date" type="string">
          Timestamp when the todo should be completed by. Optional.
        </ResponseField>
        <ResponseField name="incident_id" type="string">
          UUID of the incident this todo is connected to. Optional.
        </ResponseField>
        <ResponseField name="modified" type="string">
          Timestamp when the incident todo was last modified. Computed by Datadog after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Todo resource type. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="incident_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="todo_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

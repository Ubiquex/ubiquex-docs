`datadog_incident_integration_metadata_response` is the real, linked metadata connecting a Datadog incident to an external system's own record of it -- for example, the Jira ticket or Slack channel Datadog created and is keeping in sync for that incident.

    	ubx.Main(ubx.Stack("example", func() {

    	}))

## Input properties

<ResponseField name="data" type="object" required>
  On-call page data in a link request. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object">
      Attributes for linking a page to an incident. Optional.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key of the on-call page. Optional.
        </ResponseField>
        <ResponseField name="page_target" type="object">
          The target of an on-call page. Optional.
          <Expandable title="properties">
            <ResponseField name="identifier" type="string" required>
              The identifier of the page target. Required.
            </ResponseField>
            <ResponseField name="type" type="string" required>
              The type of the page target. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="team_id" type="string">
          The team ID associated with the page (deprecated, use page_target instead). Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The ID of the on-call page to link. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      On-call page resource type. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

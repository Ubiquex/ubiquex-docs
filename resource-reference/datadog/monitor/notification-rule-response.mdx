`datadog_monitor_notification_rule_response` is a real, centrally-managed rule controlling which real notification targets a monitor alert reaches, based on the monitor's own tags -- lets a platform team manage monitor routing centrally instead of every monitor author hand-writing its own notify list.

        </ResponseField>

          The name of the monitor notification rule. Required.
        </ResponseField>

          A list of recipients to notify. Uses the same format as the monitor `message` field. Must not start with an '@'. Cannot be used with `conditional_recipients`. Optional.

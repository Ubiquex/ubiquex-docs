`datadog_notebook_response` is a collaborative document that embeds live Datadog graphs directly alongside written text, letting multiple people build an investigation, a postmortem, or a runbook together with real, current monitoring data attached to the narrative rather than screenshots that go stale.

## Example

    ```go
    package main

    import (
    	notebook "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/notebook"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own response"})

    		ubx.Resource(notebook.Response, "example", notebook.ResponseConfig{
    			Data:       map[string]any{"attributes": map[string]any{"name": "example-name"}},
    			NotebookId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="data" type="object" required>
  The data for a notebook create request. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The data attributes of a notebook. Required.
      <Expandable title="properties">
        <ResponseField name="cells" type="list(object)" required>
          List of cells to display in the notebook. Required.
          <Expandable title="properties">
            <ResponseField name="attributes" type="object">
              Optional; if omitted, computed by Datadog.
              <Expandable title="properties">
                <ResponseField name="definition" type="object">
                  An object that contains the content and configuration for the notebook cell. Its structure depends on the cell type (e.g., markdown, timeseries). Optional; if omitted, computed by Datadog. **(AI-inferred)**
                  <Expandable title="properties">
                    <ResponseField name="text" type="string">
                      The Markdown text displayed in the notebook cell. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                    <ResponseField name="type" type="string">
                      The type of notebook cell this definition represents, determining how the cell content is interpreted and rendered. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                  </Expandable>
                </ResponseField>
                <ResponseField name="graph_size" type="string">
                  The size of the graph in the notebook cell, controlling its display dimensions. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="split_by" type="object">
                  Configuration for splitting the widget's data by one or more tag keys, including a limit on the number of groups. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                  <Expandable title="properties">
                    <ResponseField name="keys" type="list(string)">
                      The list of tag keys used to split the graph into multiple series. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                    <ResponseField name="tags" type="list(string)">
                      The list of tags used to split the data in this notebook cell. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                  </Expandable>
                </ResponseField>
                <ResponseField name="time" type="object">
                  The time range for the notebook cell, specifying the period over which data is displayed. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                  <Expandable title="properties">
                    <ResponseField name="end" type="string">
                      The end of the time range for the notebook cell, in ISO 8601 format (e.g., '2023-01-01T00:00:00Z'). Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                    <ResponseField name="live" type="bool">
                      Boolean flag indicating whether the time range is live (auto-refreshing) as opposed to a fixed time range. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                    <ResponseField name="live_span" type="string">
                      The live time span for the notebook cell's time range, such as '5m', '1h', or '1d'. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                    <ResponseField name="start" type="string">
                      The start timestamp of the time range for the notebook cell, represented as a string (e.g., ISO 8601 format). Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                  </Expandable>
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="type" type="string">
              The type of notebook cell. The only allowed value is "notebook_cells". Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="metadata" type="object">
          Metadata associated with the notebook. Optional.

              Whether or not the notebook is a template. Optional.

            <ResponseField name="take_snapshots" type="bool">

              Metadata type of the notebook. Optional.

        <ResponseField name="template_variables" type="list(object)">
          List of template variables for this notebook. Optional.
          <Expandable title="properties">
            <ResponseField name="available_values" type="list(string)">
              The list of possible values that can be assigned to the template variable in a Datadog notebook. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="available_values_query" type="object">
              An object that configures a query to determine the list of available values for this template variable. Optional; if omitted, computed by Datadog. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="data_source" type="string">
                  Specifies the data source (such as metrics or logs) from which the available values for the template variable are retrieved. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="group_by" type="list(object)">
                  Groups the metric query results by one or more tags or attributes, using the distinct values of those groupings to populate the template variable's available values. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                  <Expandable title="properties">
                    <ResponseField name="facet" type="string">
                      The name of the facet (attribute) used to group the results in the available values query for template variables. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                  </Expandable>
                </ResponseField>
                <ResponseField name="query" type="string">
                  The query string that defines the set of available values for the template variable. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="search" type="object">
                  Optional; if omitted, computed by Datadog.
                  <Expandable title="properties">
                    <ResponseField name="query" type="string">
                      The search query string used to retrieve the available values for the template variable. Optional; if omitted, computed by Datadog. **(AI-inferred)**
                    </ResponseField>
                  </Expandable>
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="data_source_mappings" type="map(string)">
              A map from data source types (e.g., 'metrics', 'logs') to template variable values, allowing the variable to resolve to different values depending on the data source used by a panel. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="default" type="string">
              The default value for the template variable, used when no other value is selected. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="defaults" type="list(string)">
              List of default values for the template variable. These are used when the notebook is loaded and no other value is specified. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="name" type="string">
              The name of the template variable, used to reference it in notebook queries. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="placement" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="prefix" type="string">
              The text prefix that is prepended to the template variable's value when used in notebook queries. For example, a prefix of 'env:' with a selected value of 'prod' would produce 'env:prod'. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="type" type="string">
              The type of the template variable, either 'tag' for tag keys or 'host' for host names. Optional; if omitted, computed by Datadog. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="time" type="object" required>

              Optional; if omitted, computed by Datadog.

            </ResponseField>

`datadog_tenancy_config` is real, org-level configuration controlling Datadog's own multi-tenancy behavior for an organization -- part of the underlying structure that `datadog_org_group_response` and related multi-org features are built on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	tenancy "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/tenancy"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own config"})

    		ubx.Resource(tenancy.Config, "example", tenancy.ConfigConfig{
    			Data:        map[string]any{"id": "example"},
    			TenancyOcid: "example",
    		})
    	}))
    }
    ```

              The fingerprint of the OCI API signing key used for authentication. Optional.
            </ResponseField>
            <ResponseField name="private_key" type="string" required>
              The PEM-encoded private key corresponding to the OCI API signing key fingerprint. Required.

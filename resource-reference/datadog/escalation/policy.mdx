`datadog_escalation_policy` is a real Datadog On-Call escalation policy -- the ordered chain of who gets notified, and after how long the alert escalates to the next person or team, if a page for an active incident goes unacknowledged.

    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="data" type="object" required>
  Represents the data for creating an escalation policy, including its attributes, relationships, and resource type. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Defines the attributes for creating an escalation policy, including its description, name, resolution behavior, retries, and steps. Required.
      <Expandable title="properties">
        <ResponseField name="name" type="string" required>
          Specifies the name for the new escalation policy. Required.
        </ResponseField>
        <ResponseField name="resolve_page_on_policy_end" type="bool">
          Indicates whether the page is automatically resolved when the policy ends. Optional.
        </ResponseField>
        <ResponseField name="retries" type="number">
          Specifies how many times the escalation sequence is retried if there is no response. Optional.
        </ResponseField>
        <ResponseField name="steps" type="list(object)" required>
          A list of escalation steps, each defining assignment, escalation timeout, and targets for the new policy. Required.
          <Expandable title="properties">
            <ResponseField name="assignment" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="escalate_after_seconds" type="number">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="targets" type="list(object)">
              Optional; if omitted, computed by Datadog.
              <Expandable title="properties">

                  <Expandable title="properties">

                      Optional; if omitted, computed by Datadog.
                      <Expandable title="properties">

                        </ResponseField>
                      </Expandable>
                    </ResponseField>
                  </Expandable>
                </ResponseField>
                <ResponseField name="id" type="string">

                </ResponseField>
                <ResponseField name="type" type="string">

              </Expandable>

        </ResponseField>
      </Expandable>
    </ResponseField>

      Represents relationships in an escalation policy creation request, including references to teams. Optional.

          <Expandable title="properties">

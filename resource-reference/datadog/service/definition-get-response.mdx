`datadog_service_definition_get_response` is a real Datadog Software Catalog service definition -- the real, structured metadata (owning team, repository, on-call, documentation links) describing one service, the object Software Catalog is built on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own definition get response"})

    		ubx.Resource(service.DefinitionGetResponse, "example", service.DefinitionGetResponseConfig{
    			ServiceName: "example-service-name",
    		})
    	}))
    }
    ```

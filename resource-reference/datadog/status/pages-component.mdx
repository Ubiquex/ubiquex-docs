`datadog_status_pages_component` is a real, individual component (a listed service or subsystem) shown on a `datadog_status_page`, each with its own real, independently reported status.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	status "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/status"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own pages component"})

    		ubx.Resource(status.PagesComponent, "example", status.PagesComponentConfig{
    			ComponentId: "example",
    			PageId:      "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

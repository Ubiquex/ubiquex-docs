`datadog_tag_policy_response` is a real, org-wide policy enforcing tag governance -- for example, requiring a specific tag key to be present, or restricting a tag's allowed values, applied consistently across the resources it's scoped to.

## Input properties

<ResponseField name="data" type="object" required>
  Data object for creating a tag policy. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes that can be supplied when creating a tag policy. Required.
      <Expandable title="properties">
        <ResponseField name="enabled" type="bool">
          Whether the policy is currently enforced. Defaults to `true` for newly created policies. Optional.
        </ResponseField>
        <ResponseField name="negated" type="bool">
          When `true`, the policy matches tag values that do NOT match any of the supplied patterns. Defaults to `false`. Optional.
        </ResponseField>
        <ResponseField name="policy_name" type="string" required>
          Human-readable name for the tag policy. Required.
        </ResponseField>
        <ResponseField name="policy_type" type="string" required>
          The policy type allowed when creating a tag policy. Only `surfacing` is accepted at creation time. Required.
        </ResponseField>
        <ResponseField name="required" type="bool">
          When `true`, telemetry without this tag is treated as a violation. Defaults to `false`. Optional.
        </ResponseField>
        <ResponseField name="scope" type="string" required>
          The scope the policy applies within. Typically an environment, team, or organization-level identifier used to limit where the policy is enforced. Required.
        </ResponseField>
        <ResponseField name="source" type="string" required>
          The telemetry source that a tag policy applies to. Required.
        </ResponseField>
        <ResponseField name="tag_key" type="string" required>
          The tag key that the policy governs (for example, `service`). Required.
        </ResponseField>
        <ResponseField name="tag_value_patterns" type="list(string)" required>
          One or more patterns that valid values for the tag key must match. At least one pattern is required. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      JSON:API resource type for a tag policy. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="policy_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Input properties

<ResponseField name="data" type="object" required>
  Data object for creating a tag rule. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes that can be supplied when creating a tag rule. Required.
      <Expandable title="properties">
        <ResponseField name="enabled" type="bool">
          Whether the rule is currently enforced. Defaults to `true` for newly created rules. Optional.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          Human-readable name for the tag rule. Required.
        </ResponseField>
        <ResponseField name="negated" type="bool">
          When `true`, the rule matches tag values that do NOT match any of the supplied patterns. Defaults to `false`. Optional.
        </ResponseField>
        <ResponseField name="required" type="bool">
          When `true`, telemetry without this tag is treated as a violation. Defaults to `false`. Optional.
        </ResponseField>
        <ResponseField name="rule_type" type="string" required>
          The rule type allowed when creating a tag rule. Only `surfacing` is accepted at creation time. Required.
        </ResponseField>
        <ResponseField name="scope" type="string" required>
          The scope the rule applies within. Typically an environment, team, or organization-level identifier used to limit where the rule is enforced. Required.
        </ResponseField>
        <ResponseField name="source" type="string" required>
          The telemetry source that a tag rule applies to. Required.
        </ResponseField>
        <ResponseField name="tag_key" type="string" required>
          The tag key that the rule governs (for example, `service`). Required.
        </ResponseField>
        <ResponseField name="tag_value_patterns" type="list(string)" required>
          One or more patterns that valid values for the tag key must match. At least one pattern is required. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      JSON:API resource type for a tag rule. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rule_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`datadog_tag_indexing_rule_response` is a real rule controlling which tag keys Datadog actually indexes for fast filtering/faceting -- since indexing every possible tag isn't free at scale, this rule is how an organization controls which tags stay queryable.

The metric must be submitted for at least as long as the selected window. 2. A tag key must have been submitted for at least 15 days. Any metric or tag key that does not meet these conditions are excluded from this indexing rule. The `exclude_not_*` fields require `exclude_tags_mode` to be set to `true`. Optional.

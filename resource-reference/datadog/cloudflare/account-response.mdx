`datadog_cloudflare_account_response` is a real Cloudflare account connected to Datadog's own Cloudflare integration -- the credentials and account identifier Datadog uses to pull Cloudflare's own metrics and logs (CDN, WAF, DNS) into Datadog.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudflare "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/cloudflare"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own account response"})

    		ubx.Resource(cloudflare.AccountResponse, "example", cloudflare.AccountResponseConfig{
    			AccountId: "example",
    			Data:      map[string]any{"attributes": map[string]any{"name": "example-name"}},
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="account_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="data" type="object" required>
  Data object for creating a Cloudflare account. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes object for creating a Cloudflare account. Required.
      <Expandable title="properties">
        <ResponseField name="api_key" type="string" required>
          The API key (or token) for the Cloudflare account. Required.
        </ResponseField>
        <ResponseField name="email" type="string">
          The email associated with the Cloudflare account. If an API key is provided (and not a token), this field is also required. Optional.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of the Cloudflare account. Required.
        </ResponseField>
        <ResponseField name="resources" type="list(string)">
          An allowlist of resources to restrict pulling metrics for including `'web', 'dns', 'lb' (load balancer), 'worker'`. Optional.
        </ResponseField>
        <ResponseField name="zones" type="list(string)">
          An allowlist of zones to restrict pulling metrics for. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The JSON:API type for this API. Should always be `cloudflare-accounts`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

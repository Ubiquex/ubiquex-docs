`datadog_dataset_response_single` is one real, defined dataset within Datadog's data platform -- a named, scoped view over log or event data (by index, query, or source) that other Datadog features (like security monitoring rules) can be scoped to run against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dataset "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/dataset"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own response single"})

    		ubx.Resource(dataset.ResponseSingle, "example", dataset.ResponseSingleConfig{
    			Data:      map[string]any{"attributes": map[string]any{"name": "example-name"}},
    			DatasetId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="data" type="object" required>
  **Datasets Object Constraints** - **Tag limit per dataset**: - Each restricted dataset supports a maximum of 10 key:value pairs per product. - **Tag key rules per telemetry type**: - Only one tag key or attribute may be used to define access within a single telemetry type. - The same or different tag key may be used across different telemetry types. - **Tag value uniqueness**: - Tag values must be unique within a single dataset. - A tag value used in one dataset cannot be reused in another dataset of the same telemetry type. Required.

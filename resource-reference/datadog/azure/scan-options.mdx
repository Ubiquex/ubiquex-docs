`datadog_azure_scan_options` is the Azure counterpart to `datadog_aws_scan_options_response` -- the real, configured scope and cadence Datadog Cloud Security Management uses when scanning a connected Azure subscription for posture and vulnerability findings.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	azure "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/azure"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own scan options"})

    		ubx.Resource(azure.ScanOptions, "example", azure.ScanOptionsConfig{
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="data" type="object">
  Single Azure scan options entry. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object">
      Attributes for Azure scan options configuration. Optional.
      <Expandable title="properties">
        <ResponseField name="compliance_host" type="bool">
          Indicates whether host compliance scanning is enabled. Optional.
        </ResponseField>
        <ResponseField name="function" type="bool">
          Indicates if scanning of Azure Functions is enabled. Optional.
        </ResponseField>
        <ResponseField name="vuln_containers_os" type="bool">
          Indicates if scanning for vulnerabilities in containers is enabled. Optional.
        </ResponseField>
        <ResponseField name="vuln_host_os" type="bool">
          Indicates if scanning for vulnerabilities in hosts is enabled. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The Azure subscription ID. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. The value should always be `azure_scan_options`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`datadog_google_chat_organization_handle_response` is a real, configured Google Chat destination Datadog notifications can be routed to at the organization level -- the connection Datadog monitors and workflows use to post into a Google Chat space.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

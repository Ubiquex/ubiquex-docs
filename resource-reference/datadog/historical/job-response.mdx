`datadog_historical_job_response` is a real, completed background job that computed historical data for a Datadog feature (for example, backfilling `datadog_historical_metrics_configuration_response` data) -- its own real status and time range.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	historical "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/historical"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own job response"})

    		ubx.Resource(historical.JobResponse, "example", historical.JobResponseConfig{
    			JobId: "example",
    		})
    	}))
    }
    ```

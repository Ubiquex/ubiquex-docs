`datadog_custom_ruleset_response` is a named collection of `datadog_custom_rule_response` rules applied together, the general-purpose counterpart to the more specific `datadog_ai_custom_ruleset_response` and `datadog_sast_ruleset_response`.

## Example

<Tabs>

    ```go
    package main

    import (
    	custom "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/custom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ruleset response"})

    		ubx.Resource(custom.RulesetResponse, "example", custom.RulesetResponseConfig{
    			RulesetName: "example-ruleset-name",
    		})
    	}))
    }
    ```

`datadog_org_group_policy_response` is a real policy applied across Datadog org groups (Datadog's multi-org/child-org structure for large enterprises) -- a governance rule enforced consistently across every child org unless a `datadog_org_group_policy_override_response` says otherwise.

## Properties

<ResponseField name="data" type="object" required>
  Data for creating an org group policy. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for creating an org group policy. If `policy_type` or `enforcement_tier` are not provided, they default to `org_config` and `DEFAULT` respectively. Required.
      <Expandable title="properties">
        <ResponseField name="content" type="map(any)" required>
          The policy content as key-value pairs. Required.
        </ResponseField>
        <ResponseField name="enforcement_tier" type="string">
          The enforcement tier of the policy. `OVERRIDE_ALLOWED` means the policy is set but member orgs may mutate it. `GROUP_MANAGED` means the policy is strictly controlled and mutations are blocked for affected orgs. `DELEGATE` means each member org controls its own value. Optional.
        </ResponseField>
        <ResponseField name="policy_name" type="string" required>
          The name of the policy. Required.
        </ResponseField>
        <ResponseField name="policy_type" type="string">
          The type of the policy. Only `org_config` is supported, indicating a policy backed by an organization configuration setting. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="relationships" type="object" required>

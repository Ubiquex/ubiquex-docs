`datadog_synthetics_apitest` sends real requests against a system's own network layers -- HTTP, SSL, DNS, WebSocket, TCP, UDP, ICMP, or gRPC -- from managed or private locations, to catch degraded performance or an unexpected response before a real user does. A failing test can alert a team, block a CI pipeline, or trigger a rollback directly.

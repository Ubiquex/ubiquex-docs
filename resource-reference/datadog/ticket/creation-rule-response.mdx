`datadog_ticket_creation_rule_response` is a real rule that automatically creates an external ticket (Jira, ServiceNow) when a real condition is met -- for example, automatically opening a Jira ticket the moment a Datadog incident is declared, using the linked `datadog_jira_issue_template_response`.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

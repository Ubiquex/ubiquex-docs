`datadog_awscloud_auth_persona_mapping_response` is a real mapping between an AWS IAM identity and a Datadog Cloud Security persona/role -- part of Datadog's cloud-native, keyless AWS authentication model, associating cloud-side identities with the access level Datadog grants them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	awscloud "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/awscloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own auth persona mapping response"})

    		ubx.Resource(awscloud.AuthPersonaMappingResponse, "example", awscloud.AuthPersonaMappingResponseConfig{
    			Data:             map[string]any{"attributes": map[string]any{"account_identifier": "example"}},
    			PersonaMappingId: "example",
    		})
    	}))
    }
    ```

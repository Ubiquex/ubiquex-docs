`datadog_spans_metric_response` is a real, custom metric generated by aggregating APM span data -- the tracing counterpart to `datadog_logs_metric_response`/`datadog_rum_metric_response`, turning high-cardinality span data into a cheap, long-retention metric.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	spans "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/spans"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own metric response"})

    		ubx.Resource(spans.MetricResponse, "example", spans.MetricResponseConfig{
    			Data:     map[string]any{"attributes": map[string]any{"compute": map[string]any{"aggregation_type": "example"}}},
    			MetricId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="data" type="object" required>
  The new span-based metric properties. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The object describing the Datadog span-based metric to create. Required.
      <Expandable title="properties">
        <ResponseField name="compute" type="object" required>
          The compute rule to compute the span-based metric. Required.
          <Expandable title="properties">
            <ResponseField name="aggregation_type" type="string" required>
              The type of aggregation to use. Required.
            </ResponseField>
            <ResponseField name="include_percentiles" type="bool">
              Toggle to include or exclude percentile aggregations for distribution metrics. Only present when the `aggregation_type` is `distribution`. Optional.
            </ResponseField>
            <ResponseField name="path" type="string">
              The path to the value the span-based metric will aggregate on (only used if the aggregation type is a "distribution"). Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="filter" type="object">
          The span-based metric filter. Spans matching this filter will be aggregated in this metric. Optional.
          <Expandable title="properties">
            <ResponseField name="query" type="string">
              The search query - following the span search syntax. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="group_by" type="list(object)">
          The rules for the group by. Optional.
          <Expandable title="properties">
            <ResponseField name="path" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="tag_name" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The name of the span-based metric. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of resource. The value should always be spans_metrics. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metric_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`datadog_datastore` is a real, structured key-value data store inside Datadog Workflow Automation and App Builder -- a place workflows and custom apps read and write real, persistent data (a lookup table, a small state store) without needing an external database.

## Example

    ```go
    package main

    import (
    	datastore "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/datastore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own datastore"})

    		ubx.Resource(datastore.Datastore, "example", datastore.DatastoreConfig{
    			DatastoreId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="data" type="object">
  Data wrapper containing the configuration needed to create a new datastore. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object">
      Configuration and metadata to create a new datastore. Optional.
      <Expandable title="properties">
        <ResponseField name="description" type="string">
          A human-readable description about the datastore. Optional.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The display name for the new datastore. Required.
        </ResponseField>
        <ResponseField name="org_access" type="string">
          The organization access level for the datastore. For example, 'contributor'. Optional.
        </ResponseField>
        <ResponseField name="primary_column_name" type="string" required>
          The name of the primary key column for this datastore. Primary column names: - Must abide by both [PostgreSQL naming conventions](https://www.postgresql.org/docs/7.0/syntax525.htm) - Cannot exceed 63 characters Required.
        </ResponseField>
        <ResponseField name="primary_key_generation_strategy" type="string">
          Can be set to `uuid` to automatically generate primary keys when new items are added. Default value is `none`, which requires you to supply a primary key for each new item. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">
      Optional ID for the new datastore. If not provided, one will be generated automatically. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The resource type for datastores. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="datastore_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

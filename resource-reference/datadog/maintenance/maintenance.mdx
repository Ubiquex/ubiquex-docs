`datadog_maintenance` is a real, scheduled maintenance window inside Datadog's Cloud Security Management -- suppresses posture/vulnerability findings for a defined scope and time range during planned, expected changes, the CSM counterpart to `datadog_downtime_response`.

## Example

  <Tab title="Go">

    ```go
    package main

    import (
    	maintenance "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/maintenance"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own maintenance"})

    		ubx.Resource(maintenance.Maintenance, "example", maintenance.MaintenanceConfig{
    			MaintenanceId: "example",
    			PageId:        "example",
    		})
    	}))
    }
    ```

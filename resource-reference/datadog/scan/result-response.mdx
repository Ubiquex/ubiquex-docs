`datadog_scan_result_response` is a real, individual result produced by one of Datadog's security scans (a code, cloud posture, or vulnerability scan) -- the actual finding, before it's necessarily promoted into a tracked `datadog_case_response` or `datadog_issue_response`.

## Example

    ```go
    package main

    import (
    	scan "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/scan"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own result response"})

    		ubx.Resource(scan.ResultResponse, "example", scan.ResultResponseConfig{
    			Data:  map[string]any{"attributes": map[string]any{"commit_hash": "example"}},
    			JobId: "example",
    		})
    	}))
    }
    ```

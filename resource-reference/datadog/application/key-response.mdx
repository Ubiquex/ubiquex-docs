---
title: "datadog_application_key_response"
description: "`datadog_application_key_response` works alongside an API key to authorize programmatic access to Datadog's own API."
---

Unlike an API key, an application key is tied to the user who created it and carries that user's own permissions -- it's what a script or integration uses to act on Datadog data on that user's behalf, not what an agent uses to submit it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	application "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/application"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key response"})

    		ubx.Resource(application.KeyResponse, "example", application.KeyResponseConfig{
    			Key:  "example",
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="key" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="name" type="string">
  Name of an application key. Optional.
</ResponseField>

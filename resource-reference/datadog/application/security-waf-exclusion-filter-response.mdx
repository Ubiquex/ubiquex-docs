`datadog_application_security_waf_exclusion_filter_response` is a real, scoped exception that tells Datadog ASM's WAF to skip evaluating specific traffic (a known-safe path, a trusted source) that would otherwise trigger a false positive.

        </ResponseField>
        <ResponseField name="enabled" type="bool" required>
          Indicates whether the exclusion filter is enabled. Required.
        </ResponseField>
        <ResponseField name="ip_list" type="list(string)">
          The client IP addresses matched by the exclusion filter (CIDR notation is supported). Optional.
        </ResponseField>
        <ResponseField name="on_match" type="string">
          The action taken when the exclusion filter matches. When set to `monitor`, security traces are emitted but the requests are not blocked. By default, security traces are not emitted and the requests are not blocked. Optional.

        <ResponseField name="parameters" type="list(string)">
          A list of parameters matched by the exclusion filter in the HTTP query string and HTTP request body. Nested parameters can be matched by joining fields with a dot character. Optional.
        </ResponseField>
        <ResponseField name="path_glob" type="string">
          The HTTP path glob expression matched by the exclusion filter. Optional.

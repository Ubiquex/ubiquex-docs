`datadog_aws_on_demand_response` represents a real, on-demand (as opposed to continuously scheduled) scan or check Datadog Cloud Security Management runs against an AWS account -- used to get fresh posture/vulnerability results outside the normal periodic scan cadence.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	aws "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/aws"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own on demand response"})

    		ubx.Resource(aws.OnDemandResponse, "example", aws.OnDemandResponseConfig{
    			Data:   map[string]any{"attributes": map[string]any{"arn": "example"}},
    			TaskId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="data" type="object" required>
  Object for a single AWS on demand task. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for the AWS on demand task. Required.
      <Expandable title="properties">
        <ResponseField name="arn" type="string" required>
          The arn of the resource to scan. Agentless supports the scan of EC2 instances, lambda functions, AMI, ECR, RDS and S3 buckets. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the on demand task. The value should always be `aws_resource`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="task_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

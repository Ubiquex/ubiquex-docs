`datadog_aws_scan_options_response` is the real, configured scan settings Datadog Cloud Security Management uses for a connected AWS account -- what gets scanned (resource types, regions) and how often, controlling the actual scope of AWS posture and vulnerability coverage.

## Example

    ```go
    package main

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own scan options response"})

    		ubx.Resource(aws.ScanOptionsResponse, "example", aws.ScanOptionsResponseConfig{
    			AccountId: "example",
    			Data:      map[string]any{"attributes": map[string]any{"compliance_host": true}},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="account_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="data" type="object" required>
  Object for the scan options of a single AWS account. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for the AWS scan options to create. Required.
      <Expandable title="properties">
        <ResponseField name="compliance_host" type="bool" required>
          Indicates whether host compliance scanning is enabled. Required.
        </ResponseField>
        <ResponseField name="lambda" type="bool" required>
          Indicates if scanning of Lambda functions is enabled. Required.
        </ResponseField>
        <ResponseField name="sensitive_data" type="bool" required>
          Indicates if scanning for sensitive data is enabled. Required.
        </ResponseField>
        <ResponseField name="vuln_containers_os" type="bool" required>
          Indicates if scanning for vulnerabilities in containers is enabled. Required.
        </ResponseField>
        <ResponseField name="vuln_host_os" type="bool" required>
          Indicates if scanning for vulnerabilities in hosts is enabled. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The ID of the AWS account. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. The value should always be `aws_scan_options`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

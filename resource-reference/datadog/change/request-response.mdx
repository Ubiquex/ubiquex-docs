`datadog_change_request_response` is a real, tracked change request under Datadog's change-management surface -- a proposed infrastructure or configuration change with its own approval workflow, letting teams correlate incidents against what actually changed and when.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	change "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/change"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own request response"})

    		ubx.Resource(change.RequestResponse, "example", change.RequestResponseConfig{
    			ChangeRequestId: "example",
    			Data:            map[string]any{"attributes": map[string]any{"title": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="change_request_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="data" type="object" required>
  Data object to create a change request. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for creating a change request. Required.
      <Expandable title="properties">
        <ResponseField name="change_request_linked_incident_uuid" type="string">
          The UUID of an incident to link to the change request. Optional.
        </ResponseField>
        <ResponseField name="change_request_maintenance_window_query" type="string">
          The maintenance window query for the change request. Optional.
        </ResponseField>
        <ResponseField name="change_request_plan" type="string">
          The plan associated with the change request. Optional.
        </ResponseField>
        <ResponseField name="change_request_risk" type="string">
          The risk level of the change request. Optional.
        </ResponseField>
        <ResponseField name="change_request_type" type="string">
          The type of the change request. Optional.
        </ResponseField>
        <ResponseField name="description" type="string">
          The description of the change request. Optional.
        </ResponseField>
        <ResponseField name="end_date" type="string">
          The planned end date of the change request. Optional.
        </ResponseField>
        <ResponseField name="project_id" type="string">
          The project UUID to associate with the change request. Optional.
        </ResponseField>
        <ResponseField name="requested_teams" type="list(string)">
          A list of team handles to request decisions from. Optional.
        </ResponseField>
        <ResponseField name="start_date" type="string">

        </ResponseField>
        <ResponseField name="title" type="string" required>

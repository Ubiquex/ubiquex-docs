`datadog_rum_retention_filter_response` is a real filter controlling which RUM sessions Datadog actually retains in full -- since RUM data volume can be very high, this filter decides which sessions (by real criteria like error presence or a specific user segment) are worth keeping versus sampling out.

    func main() {

    			RfId:  "example",
    		})
    	}))

<ResponseField name="data" type="object" required>
  The new RUM retention filter properties to create. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The object describing attributes of a RUM retention filter to create. Required.
      <Expandable title="properties">

          The configuration for cross-product retention filters. Optional.

            <ResponseField name="trace_enabled" type="bool">
              Whether the cross-product retention filter for APM traces is enabled. Optional.
            </ResponseField>
            <ResponseField name="trace_sample_rate" type="number" required>

            </ResponseField>
          </Expandable>

          Whether the retention filter is enabled. Optional.
        </ResponseField>

        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of a RUM retention filter. Required.

        <ResponseField name="query" type="string">
          The query string for a RUM retention filter. Optional.

        <ResponseField name="sample_rate" type="number" required>
          The sample rate for a RUM retention filter, between 0.1 and 100. Required.
        </ResponseField>

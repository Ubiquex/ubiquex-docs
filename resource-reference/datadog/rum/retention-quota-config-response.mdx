`datadog_rum_retention_quota_config_response` is the real, configured quota (a percentage or a hard cap) for how much RUM session volume a `datadog_rum_retention_filter_response` is allowed to retain -- controls the actual cost impact of a retention filter.

## Properties

<ResponseField name="data" type="object" required>
  The RUM retention quota configuration to create or update. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The RUM retention quota configuration properties to create or update. Required.
      <Expandable title="properties">
        <ResponseField name="adaptive" type="object">
          The configuration used when `mode` is `adaptive`. Optional.
          <Expandable title="properties">
            <ResponseField name="max_retention_rate" type="number" required>
              The maximum fraction of sessions to retain, in the range `(0, 1]`. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="custom" type="object">
          The configuration used when `mode` is `custom`. Optional.
          <Expandable title="properties">
            <ResponseField name="daily_reset_time" type="string" required>
              The time of day when the daily quota resets, in `HH:MM` 24-hour format. Required.
            </ResponseField>
            <ResponseField name="daily_reset_timezone" type="string" required>
              The timezone offset used for the daily reset time, in `±HH:MM` format. Required.
            </ResponseField>
            <ResponseField name="quota_reached_action" type="string" required>
              The action to take when the session quota is reached. Required.
            </ResponseField>
            <ResponseField name="session_limit" type="number" required>
              The maximum number of sessions allowed within the window. Must be at least `1000`. Required.
            </ResponseField>
            <ResponseField name="window_type" type="string" required>
              The window type over which the session limit is enforced. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="mode" type="string" required>
          The retention quota mode. `custom` enforces a fixed session limit, while `adaptive` dynamically adjusts retention. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The identifier of the scope the retention quota configuration applies to. Must match `scope_id` in the path. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource, always `rum_quota_config`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scope_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

  path parameter, not part of the API's own resource representation Required.

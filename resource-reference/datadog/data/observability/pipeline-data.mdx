`datadog_observability_pipeline_data` looks up a real Observability Pipeline -- a configured route processing telemetry before it reaches Datadog or another destination.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	observability "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/observability"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_observability_pipeline_data"})

    		ubx.Data(observability.PipelineData, "example", observability.PipelineDataConfig{})
    	}))
    }
    ```

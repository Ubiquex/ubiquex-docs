`datadog_page_annotations_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Result properties

<ResponseField name="data" type="object">
  Annotations grouped by widget for a single page. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of the annotations on a page. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="annotations" type="map(object)" required>
          Map of annotation UUID to annotation object, keyed by annotation ID. Required lookup argument.
        </ResponseField>
        <ResponseField name="global_annotations" type="list(string)" required>
          List of annotation IDs that apply to the entire page rather than a specific widget. Required lookup argument.
        </ResponseField>
        <ResponseField name="widget_mapping" type="map(list(string))" required>
          Map from widget ID to the list of annotation IDs displayed on that widget. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      ID of the page, prefixed with the page type and joined by a colon (for example, `dashboard:abc-def-xyz` or `notebook:1234567890`). Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Page annotations resource type. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

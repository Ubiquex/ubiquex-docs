## Lookup arguments

<ResponseField name="aggregation" type="string" required>
  Dimension to group scores by. Required lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

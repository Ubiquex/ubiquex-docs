## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_service_access_token"})

    		ubx.Data(service.AccessToken, "example", service.AccessTokenConfig{
    			ServiceAccountId: "example",
    			Filter:           "example",
    			Sort:             "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="filter" type="string">
  A real filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="service_account_id" type="string" required>
  The real, unique identifier of this service account. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  Sorting options Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  Array of access tokens. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Additional information related to the access token response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="page" type="object">
      Pagination information. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="total_filtered_count" type="number">
          Total filtered access token count. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

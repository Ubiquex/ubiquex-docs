`datadog_blueprint_metadata_data` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	blueprint "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/blueprint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_blueprint_metadata_data"})

    		ubx.Data(blueprint.MetadataData, "example", blueprint.MetadataDataConfig{
    			Limit: 1,
    			Page:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

  <Tab title="Python">

    from ubx.datadog.data.blueprint import MetadataData, MetadataDataConfig

            page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

`datadog_check_can_delete_monitor_response` checks whether a real monitor is currently safe to delete, without any dependent SLOs or dashboards blocking it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	check "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/check"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_check_can_delete_monitor_response"})

    		ubx.Data(check.CanDeleteMonitorResponse, "example", check.CanDeleteMonitorResponseConfig{
    			MonitorIds: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="monitor_ids" type="list(number)" required>
  The real, unique identifiers of the monitors this request is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Wrapper object with the list of monitor IDs. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="ok" type="list(number)">
      An array of Monitor IDs that can be safely deleted. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="map(list(string))">
  A mapping of Monitor ID to strings denoting where it's used. Returned by the lookup.
</ResponseField>

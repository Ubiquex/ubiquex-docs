`datadog_annotations_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	annotations "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/annotations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_annotations_response"})

    		ubx.Data(annotations.Response, "example", annotations.ResponseConfig{
    			EndTime:   1,
    			PageId:    "example",
    			StartTime: 1,
    			WidgetId:  "example",
    		})
    	}))
    }
    ```
  </Tab>

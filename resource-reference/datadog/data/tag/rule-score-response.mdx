## Lookup arguments

<ResponseField name="rule_id" type="string" required>
  The real, unique identifier of this rule. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ts_end" type="number">
  The real, inclusive end of the time range this request covers, as a Unix timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ts_start" type="number">
  The real, inclusive start of the time range this request covers, as a Unix timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  A compliance score resource for a tag rule. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of a tag rule compliance score. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="score" type="number" required>
          The compliance score for the rule over the requested time window, as a percentage between 0 and 100. `null` indicates that no relevant telemetry was found. Required lookup argument.
        </ResponseField>
        <ResponseField name="ts_end" type="number" required>
          End of the time window the score was computed over, as a Unix timestamp in milliseconds. Required lookup argument.
        </ResponseField>
        <ResponseField name="ts_start" type="number" required>
          Start of the time window the score was computed over, as a Unix timestamp in milliseconds. Required lookup argument.
        </ResponseField>
        <ResponseField name="version" type="number" required>
          The version of the tag rule that the score was computed against. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the compliance score resource. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      JSON:API resource type for a tag rule compliance score. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

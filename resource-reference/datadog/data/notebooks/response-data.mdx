## Lookup arguments

<ResponseField name="author_handle" type="string">
  The real handle of the account that authored this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="count" type="number">
  The total number of matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="exclude_author_handle" type="string">
  Excludes results authored by this real handle. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="include_cells" type="bool">
  Whether the real, underlying cells are included alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="is_template" type="bool">
  Whether this object is a reusable template rather than a concrete instance. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query" type="string">
  The real query string evaluated against the underlying data. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_dir" type="string">
  The sort direction, ascending or descending. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_field" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="start" type="number">
  The real, inclusive start of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string">
  The real, discriminating type of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

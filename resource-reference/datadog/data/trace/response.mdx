`datadog_trace_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	trace "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/trace"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_trace_response"})

    		ubx.Data(trace.Response, "example", trace.ResponseConfig{
    			TraceId:       "example",
    			IncludeFields: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Response } from "@ubx/sdk-datadog/datadog/data/trace/response";

    export default stack("example", () => {
      intent({ summary: "look up datadog_trace_response" });

      data(Response, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.trace import Response, ResponseConfig

    def describe():
        ubx.intent("look up datadog_trace_response")

        ubx.data(Response, "example", ResponseConfig(
            trace_id="example",
            include_fields=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Result properties

<ResponseField name="data" type="object">
  A trace resource document. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The attributes of a trace returned by the Get trace by ID endpoint. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="is_truncated" type="bool" required>
          Indicates whether the trace was truncated because its size exceeded the maximum response payload. Required lookup argument.
        </ResponseField>
        <ResponseField name="spans" type="list(object)" required>
          The list of spans that compose the trace. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The full 128-bit trace ID, encoded as a 32-character hexadecimal string. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the trace resource. The value is always `trace`. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

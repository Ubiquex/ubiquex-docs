## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_security_monitoring_signal_response"})

    		ubx.Data(security.MonitoringSignalResponse, "example", security.MonitoringSignalResponseConfig{
    			SignalId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="signal_id" type="string" required>
  The real, unique identifier of this security signal. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Object description of a security signal. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object">
      The object containing all signal attributes and their associated values. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="custom" type="map(any)">
          A JSON object of attributes in the security signal. Optional lookup argument.
        </ResponseField>
        <ResponseField name="message" type="string">
          The message in the security signal defined by the rule that generated the signal. Optional lookup argument.
        </ResponseField>
        <ResponseField name="tags" type="list(string)">
          An array of tags associated with the security signal. Optional lookup argument.
        </ResponseField>
        <ResponseField name="timestamp" type="string">
          The timestamp of the security signal. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique ID of the security signal. Optional lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of event. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

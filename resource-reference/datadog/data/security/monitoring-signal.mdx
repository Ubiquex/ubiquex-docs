## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_security_monitoring_signal"})

    		ubx.Data(security.MonitoringSignal, "example", security.MonitoringSignalConfig{
    			Sort: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { MonitoringSignal } from "@ubx/sdk-datadog/datadog/data/security/monitoring_signal";

    export default stack("example", () => {
      intent({ summary: "look up datadog_security_monitoring_signal" });

      data(MonitoringSignal, "example", {
        sort: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.security import MonitoringSignal, MonitoringSignalConfig

    def describe():
        ubx.intent("look up datadog_security_monitoring_signal")

        ubx.data(MonitoringSignal, "example", MonitoringSignalConfig(
            sort="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="sort" type="string">
  The sort parameters used for querying security signals. Optional lookup argument.
</ResponseField>

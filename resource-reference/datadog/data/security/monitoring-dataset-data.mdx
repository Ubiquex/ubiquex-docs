`datadog_security_monitoring_dataset_data` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_security_monitoring_dataset_data"})

    		ubx.Data(security.MonitoringDatasetData, "example", security.MonitoringDatasetDataConfig{
    			Sort: "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="disable_corrections" type="bool">
  Whether known SLO corrections are excluded from this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="from_ts" type="number" required>
  The real, inclusive start of the time range this request covers, as a Unix timestamp. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="slo_id" type="string" required>
  The real, unique identifier of this Service Level Objective. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="to_ts" type="number" required>
  The real, inclusive end of the time range this request covers, as a Unix timestamp. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">

            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="sli" type="number" required>
          The current Service Level Indicator (SLI) value as a percentage. Required lookup argument.

        <ResponseField name="span_precision" type="number" required>
          The precision of the time span in seconds. Required lookup argument.
        </ResponseField>
        <ResponseField name="state" type="string" required>

        </ResponseField>

    <ResponseField name="id" type="string" required>
      The ID of the SLO. Required lookup argument.

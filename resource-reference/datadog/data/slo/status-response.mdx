`datadog_slo_status_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	slo "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/slo"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_slo_status_response"})

    		ubx.Data(slo.StatusResponse, "example", slo.StatusResponseConfig{
    			FromTs:             1,
    			SloId:              "example",
    			ToTs:               1,
    			DisableCorrections: true,
    		})
    	}))
    }
    ```

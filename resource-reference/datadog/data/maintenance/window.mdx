`datadog_maintenance_window` looks up a real, scheduled maintenance window inside Cloud Security Management -- suppresses posture/vulnerability findings for a defined scope and time range during planned, expected changes.

## Example

    package main

    	ubx.Main(ubx.Stack("example", func() {

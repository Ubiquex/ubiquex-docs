## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dashboard "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/dashboard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_dashboard_list_item"})

    		ubx.Data(dashboard.ListItem, "example", dashboard.ListItemConfig{
    			DashboardListId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ListItem } from "@ubx/sdk-datadog/datadog/data/dashboard/list_item";

    export default stack("example", () => {
      intent({ summary: "look up datadog_dashboard_list_item" });

      data(ListItem, "example", {
        dashboardListId: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.dashboard import ListItem, ListItemConfig

    def describe():
        ubx.intent("look up datadog_dashboard_list_item")

        ubx.data(ListItem, "example", ListItemConfig(
            dashboard_list_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="dashboard_list_id" type="number" required>
  The real, unique identifier of this dashboard list. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="dashboards" type="list(object)">
  List of dashboards in the dashboard list. Returned by the lookup.
</ResponseField>

<ResponseField name="total" type="number">
  Number of dashboards in the dashboard list. Returned by the lookup.
</ResponseField>

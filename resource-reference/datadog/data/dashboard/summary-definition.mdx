## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dashboard "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/dashboard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_dashboard_summary_definition"})

    		ubx.Data(dashboard.SummaryDefinition, "example", dashboard.SummaryDefinitionConfig{
    			Count: 1,
    			Start: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.dashboard import SummaryDefinition, SummaryDefinitionConfig

    def describe():
        ubx.intent("look up datadog_dashboard_summary_definition")

        ubx.data(SummaryDefinition, "example", SummaryDefinitionConfig(
            count=1,
            start=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="count" type="number">
  The total number of matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="start" type="number">
  The real, inclusive start of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="dashboards" type="list(object)">
  List of dashboard definitions. Returned by the lookup.
</ResponseField>

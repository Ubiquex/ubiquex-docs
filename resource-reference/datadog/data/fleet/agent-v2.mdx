## Lookup arguments

<ResponseField name="filter" type="string">
  A real filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_number" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_attribute" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_descending" type="bool">
  Whether results are sorted in descending order. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tags" type="string">
  The real tags applied to this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  Array of agents matching the query criteria. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Metadata for the v2 list of agents, including pagination information. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="page" type="object">
      Pagination details for the v2 list of agents. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="total_count" type="number">
          Total number of agents in the fleet, regardless of any filter. Optional lookup argument.
        </ResponseField>
        <ResponseField name="total_filtered_count" type="number">
          Total number of agents matching the current filter criteria. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

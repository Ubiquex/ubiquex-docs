## Lookup arguments

<ResponseField name="detection_type" type="string" required>
  The real type of detection this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  An array of governance control detection resources. Returned by the lookup.
</ResponseField>

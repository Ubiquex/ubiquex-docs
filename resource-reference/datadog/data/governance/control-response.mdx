## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	governance "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/governance"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_governance_control_response"})

    		ubx.Data(governance.ControlResponse, "example", governance.ControlResponseConfig{
    			DetectionType: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="detection_type" type="string" required>
  The real type of detection this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  A governance control resource. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The attributes of a governance control. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="active_detections_count" type="number" required>
          The number of active detections for the control. Required lookup argument.
        </ResponseField>
        <ResponseField name="category" type="string" required>
          The value driver the control is grouped under, such as `security` or `cost`. Required lookup argument.
        </ResponseField>
        <ResponseField name="created_at" type="string" required>
          The time the control configuration was created. Required lookup argument.
        </ResponseField>
        <ResponseField name="created_by" type="string" required>
          The UUID of the user who created the control configuration. Required lookup argument.
        </ResponseField>
        <ResponseField name="description" type="string" required>
          A human-readable description of what the control detects. Required lookup argument.
        </ResponseField>
        <ResponseField name="detection_parameters" type="map(any)" required>
          A free-form map of parameter names to their configured values. Required lookup argument.
        </ResponseField>
        <ResponseField name="insights" type="list(string)" required>
          The insight slugs associated with the control. Required lookup argument.
        </ResponseField>
        <ResponseField name="last_detection_at" type="string" required>
          The time of the most recent detection for the control. `null` when there are no detections. Required lookup argument.
        </ResponseField>
        <ResponseField name="mitigated_detections_count" type="number" required>
          The number of mitigated detections for the control. Required lookup argument.
        </ResponseField>
        <ResponseField name="mitigation_parameters" type="map(any)" required>
          A free-form map of parameter names to their configured values. Required lookup argument.
        </ResponseField>
        <ResponseField name="mitigation_type" type="string" required>
          The configured mitigation type for the control. Empty when not configured. Required lookup argument.
        </ResponseField>
        <ResponseField name="mitigations" type="list(object)" required>
          The mitigations available for a control. Required lookup argument.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          Human-readable name of the control. Required lookup argument.
        </ResponseField>
        <ResponseField name="priority" type="string" required>
          The priority of the control, such as `High`. Required lookup argument.
        </ResponseField>
        <ResponseField name="product" type="string" required>
          The product the control belongs to. Required lookup argument.
        </ResponseField>
        <ResponseField name="resource_type" type="string" required>
          The type of resource the control evaluates. Required lookup argument.
        </ResponseField>
        <ResponseField name="resource_type_display_name" type="string" required>
          The human-readable name of the resource type. Required lookup argument.
        </ResponseField>
        <ResponseField name="supported_detection_parameters" type="list(object)" required>
          An array of parameter definitions. Required lookup argument.
        </ResponseField>
        <ResponseField name="type" type="string" required>
          The control type, such as `Proactive` or `Detection`. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The detection type that uniquely identifies the control. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      JSON:API resource type for a governance control. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

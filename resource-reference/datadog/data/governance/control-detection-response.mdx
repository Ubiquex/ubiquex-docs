## Lookup arguments

<ResponseField name="detection_id" type="string" required>
  The real, unique identifier of this detection. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  A governance control detection resource. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The attributes of a governance control detection. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="assigned_team" type="string">
          The identifier of the team the detection is assigned to, if any. Optional lookup argument.
        </ResponseField>
        <ResponseField name="assigned_to" type="string">
          The identifier of the user the detection is assigned to, if any. Optional lookup argument.
        </ResponseField>
        <ResponseField name="assignment_source" type="string" required>
          How the detection's current assignment was determined. Possible values are `auto_resolved`, `manual`, `reassigned`, and `cleared`. Required lookup argument.
        </ResponseField>
        <ResponseField name="control_id" type="string" required>
          DEPRECATED: mirrors `detection_type` for backward compatibility; use `detection_type` instead. Required lookup argument.
        </ResponseField>
        <ResponseField name="created_at" type="string" required>
          The date and time when the detection was created. Required lookup argument.
        </ResponseField>
        <ResponseField name="detection_type" type="string" required>
          The type of detection, which determines what condition was detected. Required lookup argument.
        </ResponseField>
        <ResponseField name="display_name" type="string" required>
          The human-readable name of the detected resource. Required lookup argument.
        </ResponseField>
        <ResponseField name="exception_at" type="string">
          The date and time when the detection was marked as an exception, if applicable. Optional lookup argument.
        </ResponseField>
        <ResponseField name="exception_by" type="string">
          The identifier of the user who marked the detection as an exception, if applicable. Optional lookup argument.
        </ResponseField>
        <ResponseField name="metadata" type="any">
          Free-form metadata associated with the detection. Optional lookup argument.
        </ResponseField>
        <ResponseField name="mitigate_after" type="string">
          The date and time after which the detection is scheduled to be mitigated, if applicable. Optional lookup argument.
        </ResponseField>
        <ResponseField name="mitigated_at" type="string">
          The date and time when the detection was mitigated, if applicable. Optional lookup argument.
        </ResponseField>
        <ResponseField name="priority" type="number" required>
          The priority of the detection, if set. Required lookup argument.
        </ResponseField>
        <ResponseField name="resource_id" type="string" required>
          The identifier of the resource the detection applies to. Required lookup argument.
        </ResponseField>
        <ResponseField name="resource_type" type="string" required>
          The type of resource the detection applies to, for example `api_key` or `dashboard`. Required lookup argument.
        </ResponseField>
        <ResponseField name="state" type="string" required>
          The current state of the detection. Possible values are `active`, `exception`, `mitigated`, `inactive`, `obsolete`, `resolved_externally`, and `mitigation_in_progress`. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the detection. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Governance control detection resource type. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

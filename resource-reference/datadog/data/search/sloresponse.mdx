## Example

    package main

    import (
    	search "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/search"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_search_sloresponse"})

    		ubx.Data(search.Sloresponse, "example", search.SloresponseConfig{
    			IncludeFacets: true,
    			Query:         "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="include_facets" type="bool">
  Whether facet values are included alongside the matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query" type="string">
  The real query string evaluated against the underlying data. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="from_ts" type="number">
  The real, inclusive start of the time range this request covers, as a Unix timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="probe_dc" type="list(string)">
  The real Synthetic testing location (data center) this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="public_id" type="string" required>
  The real, public identifier of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="to_ts" type="number">
  The real, inclusive end of the time range this request covers, as a Unix timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="last_timestamp_fetched" type="number">
  Timestamp of the latest browser test run. Returned by the lookup.
</ResponseField>

<ResponseField name="results" type="list(object)">
  Result of the latest browser test run. Returned by the lookup.
</ResponseField>

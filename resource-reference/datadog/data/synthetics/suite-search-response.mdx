## Lookup arguments

<ResponseField name="count" type="number">
  The total number of matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="facets_only" type="bool">
  Whether the response is restricted to facet values only, without the underlying matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query" type="string">
  The real query string evaluated against the underlying data. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="start" type="number">
  The real, inclusive start of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

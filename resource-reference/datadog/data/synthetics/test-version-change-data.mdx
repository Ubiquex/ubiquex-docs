## Lookup arguments

<ResponseField name="last_version_number" type="number">
  The real, most recent version number of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="public_id" type="string" required>
  The real, public identifier of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  List of version change records. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for a version history response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="next_last_version_number" type="number">
      The version number to use as the `last_version_number` query parameter to fetch the next page. `null` indicates there are no more pages. Optional lookup argument.
    </ResponseField>
    <ResponseField name="retention_period_in_days" type="number">
      The number of days that version history is retained. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

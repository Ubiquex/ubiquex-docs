## Lookup arguments

<ResponseField name="include_change_metadata" type="bool">
  Whether metadata about recent changes is included alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="only_check_existence" type="bool">
  Whether the request only checks for existence, without returning the real, full object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="public_id" type="string" required>
  The real, public identifier of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="version_number" type="number" required>
  The real, numeric version of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

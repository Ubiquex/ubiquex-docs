## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	role "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/role"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_role"})

    		ubx.Data(role.Role, "example", role.RoleConfig{
    			ArchiveId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Role } from "@ubx/sdk-datadog/datadog/data/role/role";

    export default stack("example", () => {
      intent({ summary: "look up datadog_role" });

      data(Role, "example", {
        archiveId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.role import Role, RoleConfig

    def describe():
        ubx.intent("look up datadog_role")

        ubx.data(Role, "example", RoleConfig(
            archive_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="archive_id" type="string" required>

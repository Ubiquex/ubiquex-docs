## Lookup arguments

<ResponseField name="include" type="string">
  Which real, additional related data to include alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="schedule_id" type="string" required>
  The real, unique identifier of this schedule. **(AI-inferred)** Required lookup argument.
</ResponseField>

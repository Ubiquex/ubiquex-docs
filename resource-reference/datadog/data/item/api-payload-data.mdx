## Lookup arguments

<ResponseField name="datastore_id" type="string" required>
  The real, unique identifier of this datastore. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="filter" type="string">
  A real filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="item_key" type="string">
  The real key identifying this item. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  An array of datastore items with their content and metadata. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	awsaccount "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/awsaccount"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_awsaccount"})

    		ubx.Data(awsaccount.Awsaccount, "example", awsaccount.AwsaccountConfig{
    			AccessKeyId: "example",
    			AccountId:   "example",
    			RoleName:    "example-role-name",
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    # ubx sdk gen --only datadog --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/datadog/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.datadog.data.awsaccount import Awsaccount, AwsaccountConfig

    def describe():
        ubx.intent("look up datadog_awsaccount")

        ubx.data(Awsaccount, "example", AwsaccountConfig(
            access_key_id="example",
            account_id="example",
            role_name="example-role-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="access_key_id" type="string">
  The real, unique identifier of this access key. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="account_id" type="string">
  The real, unique identifier of the account this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="role_name" type="string">
  The real name of this role. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="accounts" type="list(object)">
  List of enabled AWS accounts. Returned by the lookup.
</ResponseField>

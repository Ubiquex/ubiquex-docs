## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	custom "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/custom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_custom_rule_revision"})

    		ubx.Data(custom.RuleRevision, "example", custom.RuleRevisionConfig{
    			RuleName:    "example-rule-name",
    			RulesetName: "example-ruleset-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    # ubx sdk gen --only datadog --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/datadog/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.datadog.data.custom import RuleRevision, RuleRevisionConfig

    def describe():
        ubx.intent("look up datadog_custom_rule_revision")

        ubx.data(RuleRevision, "example", RuleRevisionConfig(
            rule_name="example-rule-name",
            ruleset_name="example-ruleset-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="rule_name" type="string" required>
  The real name of this rule. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ruleset_name" type="string" required>
  The real name of this ruleset. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  List of custom rule revisions. Returned by the lookup.
</ResponseField>

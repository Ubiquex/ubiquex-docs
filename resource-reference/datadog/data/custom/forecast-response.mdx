## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	custom "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/custom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_custom_forecast_response"})

    		ubx.Data(custom.ForecastResponse, "example", custom.ForecastResponseConfig{
    			BudgetId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.custom import ForecastResponse, ForecastResponseConfig

    def describe():
        ubx.intent("look up datadog_custom_forecast_response")

        ubx.data(ForecastResponse, "example", ForecastResponseConfig(
            budget_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="budget_id" type="string" required>
  The real, unique identifier of this budget. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Custom forecast resource wrapper in a response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of a custom forecast. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="budget_uid" type="string" required>
          The UUID of the budget that this custom forecast belongs to. Required lookup argument.
        </ResponseField>
        <ResponseField name="created_at" type="number" required>
          Timestamp the custom forecast was created, in Unix milliseconds. Required lookup argument.
        </ResponseField>
        <ResponseField name="created_by" type="string" required>
          The id of the user that created the custom forecast. Required lookup argument.
        </ResponseField>
        <ResponseField name="entries" type="list(object)" required>
          Monthly custom forecast entries. Required lookup argument.
        </ResponseField>
        <ResponseField name="updated_at" type="number" required>
          Timestamp the custom forecast was last updated, in Unix milliseconds. Required lookup argument.
        </ResponseField>
        <ResponseField name="updated_by" type="string" required>
          The id of the user that last updated the custom forecast. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the custom forecast. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the custom forecast resource. Must be `custom_forecast`. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

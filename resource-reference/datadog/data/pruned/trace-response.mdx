## Lookup arguments

<ResponseField name="expand_span_id" type="number">
  Whether the response expands the real span ID into its own full span details. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="force_source" type="string">
  Whether the request is forced to read from the real, underlying source rather than a cache. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="include_path" type="list(string)">
  Whether the real, full path is included alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="only_service_entry_spans" type="bool">
  Whether results are restricted to spans that are the entry point of their own service. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tag_exclude" type="list(string)">
  Tags that, if present, exclude a result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tag_include" type="list(string)">
  Tags that must be present for a result to be included. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="time_hint" type="number">
  A real, approximate timestamp hinting where to look, used to speed up the lookup. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="trace_id" type="string" required>
  The real, unique identifier of this APM trace. **(AI-inferred)** Required lookup argument.
</ResponseField>

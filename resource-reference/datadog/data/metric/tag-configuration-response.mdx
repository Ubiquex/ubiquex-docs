## Lookup arguments

  The real name of the metric this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Object for a single metric tag configuration. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object">
      Object containing the definition of a metric tag configuration attributes. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="aggregations" type="list(object)">
          Deprecated. You no longer need to configure specific time and space aggregations for Metrics Without Limits. Optional lookup argument.
        </ResponseField>
        <ResponseField name="created_at" type="string">
          Timestamp when the tag configuration was created. Optional lookup argument.
        </ResponseField>
        <ResponseField name="exclude_tags_mode" type="bool">
          When set to true, the configuration will exclude the configured tags and include any other submitted tags. When set to false, the configuration will include the configured tags and exclude any other submitted tags. Defaults to false. Requires `tags` property. Optional lookup argument.
        </ResponseField>
        <ResponseField name="include_percentiles" type="bool">
          Toggle to include or exclude percentile aggregations for distribution metrics. Only present when the `metric_type` is `distribution`. Optional lookup argument.
        </ResponseField>
        <ResponseField name="metric_type" type="string">
          The metric's type. Optional lookup argument.
        </ResponseField>
        <ResponseField name="modified_at" type="string">
          Timestamp when the tag configuration was last modified. Optional lookup argument.
        </ResponseField>
        <ResponseField name="tags" type="list(string)">
          List of tag keys on which to group. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">

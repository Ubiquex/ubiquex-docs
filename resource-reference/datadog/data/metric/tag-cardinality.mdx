## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	metric "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/metric"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_metric_tag_cardinality"})

    		ubx.Data(metric.TagCardinality, "example", metric.TagCardinalityConfig{
    			MetricName: "example-metric-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="metric_name" type="string" required>
  The real name of the metric this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  A list of tag cardinalities associated with the given metric. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Response metadata object. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="metric_name" type="string">
      The name of metric for which the tag cardinalities are returned. This matches the metric name provided in the request. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

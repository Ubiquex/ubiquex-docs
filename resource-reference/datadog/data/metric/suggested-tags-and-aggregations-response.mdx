## Lookup arguments

<ResponseField name="metric_name" type="string" required>
  The real name of the metric this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Object for a single metric's actively queried tags and aggregations. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object">
      Object containing the definition of a metric's actively queried tags and aggregations. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="active_aggregations" type="list(object)">
          List of aggregation combinations that have been actively queried. Optional lookup argument.
        </ResponseField>
        <ResponseField name="active_tags" type="list(string)">
          List of tag keys that have been actively queried. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">
      The metric name for this resource. Optional lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string">
      The metric actively queried configuration resource type. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

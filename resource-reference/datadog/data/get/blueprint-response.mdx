`datadog_get_blueprint_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	get "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/get"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_get_blueprint_response"})

    		ubx.Data(get.BlueprintResponse, "example", get.BlueprintResponseConfig{
    			BlueprintId: "example",
    		})
    	}))
    }
    ```

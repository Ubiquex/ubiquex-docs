## Lookup arguments

<ResponseField name="include_triage_history" type="bool">
  Whether the real triage history is included alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="indicator" type="string" required>
  The real indicator (metric or signal) this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ocsf" type="bool">
  Whether results are returned in the Open Cybersecurity Schema Framework (OCSF) format. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="triage_history_limit" type="number">
  The maximum number of real triage history entries to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="triage_history_offset" type="number">
  The number of real triage history entries to skip before returning the rest. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="include" type="string">
  Which real, additional related data to include alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="team_id" type="string" required>
  The real, unique identifier of this team. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Defines the main on-call responder object for a team, including relationships and metadata. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique identifier of the on-call responder configuration. Optional lookup argument.
    </ResponseField>
    <ResponseField name="relationships" type="object">
      Relationship objects linked to a team's on-call responder configuration, including escalations and responders. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="escalations" type="object">
          Defines the escalation policy steps linked to the team's on-call configuration. Optional lookup argument.
          <Expandable title="properties">
            <ResponseField name="data" type="list(object)">
              Array of escalation step references. Optional lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="responders" type="object">
          Defines the list of users assigned as on-call responders for the team. Optional lookup argument.
          <Expandable title="properties">
            <ResponseField name="data" type="list(object)">
              Array of user references associated as responders. Optional lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Represents the resource type for a group of users assigned to handle on-call duties within a team. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="included" type="list(object)">
  The `TeamOnCallResponders` `included`. Returned by the lookup.
</ResponseField>

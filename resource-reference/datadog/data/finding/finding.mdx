## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	finding "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/finding"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_finding"})

    		ubx.Data(finding.Finding, "example", finding.FindingConfig{
    			DetailedFindings:  true,
    			SnapshotTimestamp: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only datadog --lang ts --out ./local-sdk

    export default stack("example", () => {
      intent({ summary: "look up datadog_finding" });

      data(Finding, "example", {
        detailedFindings: true,
        snapshotTimestamp: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only datadog --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/datadog/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.datadog.data.finding import Finding, FindingConfig

    def describe():
        ubx.intent("look up datadog_finding")

        ubx.data(Finding, "example", FindingConfig(
            detailed_findings=True,
            snapshot_timestamp=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="detailed_findings" type="bool">
  The real, detailed findings included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="snapshot_timestamp" type="number">
  The real timestamp this snapshot was captured at. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  Array of findings. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Metadata for pagination. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="page" type="object">
      Pagination and findings count information. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="cursor" type="string">
          The cursor used to paginate requests. Optional lookup argument.
        </ResponseField>
        <ResponseField name="total_filtered_count" type="number">
          The total count of findings after the filter has been applied. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="snapshot_timestamp" type="number">
      The point in time corresponding to the listed findings. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

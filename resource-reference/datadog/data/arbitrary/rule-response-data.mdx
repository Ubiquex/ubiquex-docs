`datadog_arbitrary_rule_response_data` looks up a real, custom detection rule defined with an arbitrary (freeform) query, outside the standard rule templates.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	arbitrary "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/arbitrary"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_arbitrary_rule_response_data"})

    		ubx.Data(arbitrary.RuleResponseData, "example", arbitrary.RuleResponseDataConfig{})
    	}))
    }
    ```
  </Tab>

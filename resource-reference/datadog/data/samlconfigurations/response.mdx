`datadog_samlconfigurations_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Lookup arguments

## Result properties

<ResponseField name="data" type="list(object)">
  Array of SAML configurations. An organization has at most one SAML configuration. Returned by the lookup.
</ResponseField>

<ResponseField name="included" type="list(object)">
  Resources related to the SAML configurations, such as the default roles. Returned by the lookup.

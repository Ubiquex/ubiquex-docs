## Lookup arguments

<ResponseField name="include" type="string">
  Authentication protocol used by the auth method. Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  An array of webhooks auth methods. Returned by the lookup.
</ResponseField>

<ResponseField name="included" type="list(object)">
  Resources related to the auth methods, included when requested via the `include` query parameter. Returned by the lookup.
</ResponseField>

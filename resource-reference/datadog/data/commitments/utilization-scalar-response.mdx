## Lookup arguments

<ResponseField name="commitment_type" type="string">
  Type of commitment. ri for Reserved Instances, sp for Savings Plans. Optional lookup argument.
</ResponseField>

<ResponseField name="end" type="number" required>
  The real, inclusive end of the time range this request covers. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="filter_by" type="string">
  The real field results are filtered by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="product" type="string" required>
  The real Datadog product this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="provider" type="string" required>
  Cloud provider for commitment programs. Required lookup argument.
</ResponseField>

<ResponseField name="start" type="number" required>
  The real, inclusive start of the time range this request covers. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="columns" type="list(object)">
  Array of scalar columns in the response. Returned by the lookup.
</ResponseField>

<ResponseField name="product_breakdown" type="list(object)">
  Array of per-product utilization breakdown entries. Returned by the lookup.
</ResponseField>

`datadog_application_key` looks up a real Datadog application key's own metadata (name, owner, scopes) -- the safe-to-list read, never exposing the real secret value that's only ever shown once at creation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	application "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/application"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_application_key"})

    		ubx.Data(application.Key, "example", application.KeyConfig{})
    	}))
    }
    ```
  </Tab>

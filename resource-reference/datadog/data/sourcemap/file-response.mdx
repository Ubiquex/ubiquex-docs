## Lookup arguments

<ResponseField name="filename" type="string" required>
  The real name of this file. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="service" type="string" required>
  The real service name this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="version" type="string" required>
  The real version identifier for this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  JavaScript source map file data object. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of a JavaScript source map file. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="file" type="string" required>
          The name of the minified JavaScript file. Required lookup argument.
        </ResponseField>
        <ResponseField name="mappings" type="string" required>
          The Base64 VLQ encoded string that maps positions in the minified file to positions in the original source files. Required lookup argument.
        </ResponseField>
        <ResponseField name="minified_line_lengths" type="list(number)" required>
          List of character counts for each line in the minified file. Required lookup argument.
        </ResponseField>
        <ResponseField name="names" type="list(any)" required>
          List of symbol names referenced in the mappings. Required lookup argument.
        </ResponseField>
        <ResponseField name="source_root" type="string" required>
          The root path prepended to source file paths. Required lookup argument.
        </ResponseField>
        <ResponseField name="sources" type="list(string)" required>
          List of original source file paths. Required lookup argument.
        </ResponseField>
        <ResponseField name="sources_content" type="list(string)" required>
          List of original source file contents corresponding to the paths in `sources`. Required lookup argument.
        </ResponseField>
        <ResponseField name="version" type="number" required>
          The version of the source map format (typically 3). Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the source map file, typically the path to the file. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The resource type for source map file objects. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

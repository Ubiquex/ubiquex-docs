title: "datadog_environment"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	environment "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/environment"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_environment"})

    		ubx.Data(environment.Environment, "example", environment.EnvironmentConfig{
    			Name:   "example",
    			DdEnv:  "example",
    			Key:    "example",
    			Limit:  1,
    			Offset: 1,
    		})
    	}))
    }
    ```
  </Tab>

            name="example",

## Lookup arguments

<ResponseField name="dd_env" type="string">
  The real `env` tag value this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="key" type="string">
  The real, unique key identifying this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="name" type="string">
  The real, given name of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="offset" type="number">
  The number of matching results to skip before returning the rest, for offset-based pagination. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">

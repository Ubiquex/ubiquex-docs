`data_datadog_sample_log_generation_subscription_data` is a real, live lookup against Datadog, generated from datadog's own real schema -- read-only, never created or destroyed.

## Example

    ```go
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_sample_log_generation_subscription_data"})

    		ubx.Data(sample.LogGenerationSubscriptionData, "example", sample.LogGenerationSubscriptionDataConfig{
    			EndTimestamp:   "example",
    			StartTimestamp: "example",
    			Status:         "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="end_timestamp" type="string">
  Optional lookup argument.
</ResponseField>

<ResponseField name="start_timestamp" type="string">
  Optional lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  Filter that controls whether to return only active subscriptions or every subscription on record. Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  The list of sample log generation subscriptions. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Metadata returned alongside a list of sample log generation subscriptions. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="total_subscriptions" type="number" required>
      The total number of subscriptions matching the request, irrespective of pagination. Required lookup argument.
    </ResponseField>
  </Expandable>

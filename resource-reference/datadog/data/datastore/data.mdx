`datadog_datastore_data` looks up a real, structured key-value data store inside Datadog Workflow Automation and App Builder -- a place workflows and custom apps read and write real, persistent data without needing an external database.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datastore "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/datastore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_datastore_data"})

    		ubx.Data(datastore.Data, "example", datastore.DataConfig{})
    	}))
    }
    ```

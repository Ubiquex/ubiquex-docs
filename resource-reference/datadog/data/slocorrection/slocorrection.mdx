## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	slocorrection "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/slocorrection"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_slocorrection"})

    		ubx.Data(slocorrection.Slocorrection, "example", slocorrection.SlocorrectionConfig{
    			Limit:  1,
    			Offset: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="offset" type="number">
  The number of matching results to skip before returning the rest, for offset-based pagination. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">

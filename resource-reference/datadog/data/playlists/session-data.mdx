`datadog_playlists_session_data` reads the real, current playback session of a Playlist -- which dashboard is showing now and where the auto-cycle is in its own rotation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	playlists "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/playlists"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_playlists_session_data"})

    		ubx.Data(playlists.SessionData, "example", playlists.SessionDataConfig{
    			PlaylistId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.playlists import SessionData, SessionDataConfig

    def describe():
        ubx.intent("look up datadog_playlists_session_data")

        ubx.data(SessionData, "example", SessionDataConfig(
            playlist_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="playlist_id" type="number" required>

## Lookup arguments

<ResponseField name="include" type="string">
  Which real, additional related data to include alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_id" type="string" required>
  The real, unique identifier of this status page. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  A list of component data objects. Returned by the lookup.
</ResponseField>

<ResponseField name="included" type="list(object)">
  The included related resources of a component. Client must explicitly request these resources by name in the `include` query parameter. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	table "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/table"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_table_result_v2_data"})

    		ubx.Data(table.ResultV2Data, "example", table.ResultV2DataConfig{
    			Sort: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ResultV2Data } from "@ubx/sdk-datadog/datadog/data/table/result_v2_data";

    export default stack("example", () => {
      intent({ summary: "look up datadog_table_result_v2_data" });

      data(ResultV2Data, "example", {
        sort: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.table import ResultV2Data, ResultV2DataConfig

    def describe():
        ubx.intent("look up datadog_table_result_v2_data")

        ubx.data(ResultV2Data, "example", ResultV2DataConfig(
            sort="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="sort" type="string">
  Sort field and direction for reference tables. Use field name for ascending, prefix with "-" for descending. Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  The reference tables. Returned by the lookup.
</ResponseField>

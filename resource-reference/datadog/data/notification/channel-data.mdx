## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	notification "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/notification"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_notification_channel_data"})

    		ubx.Data(notification.ChannelData, "example", notification.ChannelDataConfig{
    			UserId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ChannelData } from "@ubx/sdk-datadog/datadog/data/notification/channel_data";

    export default stack("example", () => {
      intent({ summary: "look up datadog_notification_channel_data" });

      data(ChannelData, "example", {
        userId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.notification import ChannelData, ChannelDataConfig

    def describe():
        ubx.intent("look up datadog_notification_channel_data")

        ubx.data(ChannelData, "example", ChannelDataConfig(
            user_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="user_id" type="string" required>
  The real, unique identifier of this user. **(AI-inferred)** Required lookup argument.

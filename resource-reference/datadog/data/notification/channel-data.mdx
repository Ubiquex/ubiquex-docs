`datadog_notification_channel_data` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	notification "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/notification"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_notification_channel_data"})

    		ubx.Data(notification.ChannelData, "example", notification.ChannelDataConfig{
    			UserId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

  </Tab>

    import ubx_sdk as ubx

    def describe():

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

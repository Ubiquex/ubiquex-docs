## Lookup arguments

<ResponseField name="filter" type="string">
  A real filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of resource being mapped to. Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  Sorting options for AuthN Mappings. Optional lookup argument.
</ResponseField>

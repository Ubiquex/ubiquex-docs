## Lookup arguments

<ResponseField name="group_bys" type="string">
  The real fields results are grouped by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query_filter" type="string">
  A real filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Data object containing the count results, including per-field group breakdowns. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for the count response, including the total count and optional facet breakdowns. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="groups" type="list(object)" required>
          List of facet groups, one per field specified in `group_bys`. Required lookup argument.

    <ResponseField name="id" type="string" required>
      Count response identifier. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Count resource type. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "datadog_case_view"
description: "`datadog_case_view` looks up a real, saved view (a filtered, saved list) of cases in Case Management."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	case_ "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/case_"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_case_view"})

    		ubx.Data(case_.View, "example", case_.ViewConfig{
    			ProjectId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { View } from "@ubx/sdk-datadog/datadog/data/case/view";

    export default stack("example", () => {
      intent({ summary: "look up datadog_case_view" });

      data(View, "example", {
        projectId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.case import View, ViewConfig

    def describe():
        ubx.intent("look up datadog_case_view")

        ubx.data(View, "example", ViewConfig(
            project_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="project_id" type="string" required>
  The real, unique identifier of this project. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  A list of case views. Returned by the lookup.
</ResponseField>

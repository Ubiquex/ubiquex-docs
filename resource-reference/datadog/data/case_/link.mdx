## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	case_ "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/case_"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_case_link"})

    		ubx.Data(case_.Link, "example", case_.LinkConfig{
    			EntityId:     "example",
    			EntityType:   "example",
    			Relationship: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="entity_id" type="string" required>
  The real, unique identifier of this entity. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="entity_type" type="string" required>
  The real type of this entity. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="relationship" type="string">
  The real relationship this result describes between two entities. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  A list of case links. Returned by the lookup.
</ResponseField>

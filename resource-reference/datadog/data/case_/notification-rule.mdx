`datadog_case_notification_rule` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	case_ "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/case_"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_case_notification_rule"})

    		ubx.Data(case_.NotificationRule, "example", case_.NotificationRuleConfig{
    			ProjectId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="filter" type="string">
  A real filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="include_descendant_matches" type="bool">
  Whether matches found in descendant (nested) objects are included in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="include_pinned" type="bool">
  Whether pinned items are included in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="pinned_first" type="bool">
  Whether pinned items are returned ahead of the rest of the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="facet_name" type="string" required>
  The real name of the facet (filterable attribute) this request is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="facet_type" type="string" required>
  The type of facet for filtering Model Lab runs. Required lookup argument.
</ResponseField>

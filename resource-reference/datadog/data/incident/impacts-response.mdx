## Lookup arguments

<ResponseField name="incident_id" type="string" required>
  The real, unique identifier of this incident. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="include" type="list(string)">
  Which real, additional related data to include alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  An array of incident impacts. Returned by the lookup.
</ResponseField>

<ResponseField name="included" type="list(object)">
  Included related resources that the user requested. Returned by the lookup.
</ResponseField>

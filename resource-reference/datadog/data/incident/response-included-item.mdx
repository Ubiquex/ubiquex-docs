## Lookup arguments

<ResponseField name="include" type="string">

</ResponseField>

<ResponseField name="query" type="string" required>
  The real query string evaluated against the underlying data. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The ways searched incidents can be sorted. Optional lookup argument.
</ResponseField>

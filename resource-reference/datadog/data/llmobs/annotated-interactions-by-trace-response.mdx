`datadog_llmobs_annotated_interactions_by_trace_response` reads the real human annotations attached to LLM Observability interactions within one specific trace.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	llmobs "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/llmobs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_llmobs_annotated_interactions_by_trace_response"})

    		ubx.Data(llmobs.AnnotatedInteractionsByTraceResponse, "example", llmobs.AnnotatedInteractionsByTraceResponseConfig{
    			ContentIds: []string{"example"},
    			Limit:      1,
    			Offset:     1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="content_ids" type="list(string)" required>
  The real, unique identifiers of the content items this request is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="offset" type="number">
  The number of matching results to skip before returning the rest, for offset-based pagination. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	llmobs "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/llmobs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_llmobs_custom_eval_config_response"})

    		ubx.Data(llmobs.CustomEvalConfigResponse, "example", llmobs.CustomEvalConfigResponseConfig{
    			EvalName: "example-eval-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { CustomEvalConfigResponse } from "@ubx/sdk-datadog/datadog/data/llmobs/custom_eval_config_response";

    export default stack("example", () => {
      intent({ summary: "look up datadog_llmobs_custom_eval_config_response" });

      });
    ```

  </Tab>
  <Tab title="Python">

    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.llmobs import CustomEvalConfigResponse, CustomEvalConfigResponseConfig
    ```

## Lookup arguments

<ResponseField name="eval_name" type="string" required>
  The real name of this evaluation. **(AI-inferred)** Required lookup argument.
</ResponseField>

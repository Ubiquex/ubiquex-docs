## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_llmobs_dataset_record_data_response"})

    		ubx.Data(llmobs.DatasetRecordDataResponse, "example", llmobs.DatasetRecordDataResponseConfig{
    			DatasetId: "example",
    			ProjectId: "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="dataset_id" type="string" required>
  The real, unique identifier of this dataset. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project_id" type="string" required>
  The real, unique identifier of this project. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">

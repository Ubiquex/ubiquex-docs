## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	llmobs "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/llmobs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_llmobs_dataset_version_data"})

    		ubx.Data(llmobs.DatasetVersionData, "example", llmobs.DatasetVersionDataConfig{
    			DatasetId: "example",
    			ProjectId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

      intent({ summary: "look up datadog_llmobs_dataset_version_data" });

      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.datadog.data.llmobs import DatasetVersionData, DatasetVersionDataConfig

    def describe():
        ubx.intent("look up datadog_llmobs_dataset_version_data")

        ubx.data(DatasetVersionData, "example", DatasetVersionDataConfig(
            dataset_id="example",
            project_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="dataset_id" type="string" required>
  The real, unique identifier of this dataset. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project_id" type="string" required>
  The real, unique identifier of this project. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  List of dataset versions. Returned by the lookup.
</ResponseField>

    	ubx.Main(ubx.Stack("example", func() {

    			Limit:    1,
    		})

## Lookup arguments

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="signal_id" type="string" required>
  The real, unique identifier of this security signal. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Entities related to a security signal. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes containing the entities related to the signal. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="identities" type="list(map(any))" required>
          The identity entities related to the signal. Each item is a free-form object describing an identity (for example, a user or principal). Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The signal ID the entities are associated with. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. The value should always be `entities`. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

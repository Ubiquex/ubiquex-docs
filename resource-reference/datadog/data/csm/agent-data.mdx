## Lookup arguments

<ResponseField name="order_direction" type="string">
  The sort direction for results. Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query" type="string">
  The real query string evaluated against the underlying data. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="size" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

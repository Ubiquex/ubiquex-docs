## Lookup arguments

<ResponseField name="facet" type="string" required>
  The real facet (filterable attribute) this request is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="query" type="string">
  The real query string evaluated against the underlying data. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="search" type="string">
  The real search query string. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  The data wrapper for a facet info response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of a facet info response, containing the value distribution for the requested facet. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="items" type="list(object)" required>
          The list of facet value entries for the current page. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The identifier of the facet. Required lookup argument.
    </ResponseField>
    <ResponseField name="meta" type="object" required>
      Metadata for the facet info response. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="total_count" type="number" required>
          The total number of distinct values for this facet. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The JSON:API type for facet info resources. The value should always be `facet_info`. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

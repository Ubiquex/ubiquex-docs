## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_app_version"})

    		ubx.Data(app.Version, "example", app.VersionConfig{
    			AppId: "example",
    			Limit: 1,
    			Page:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.datadog.data.app import Version, VersionConfig

    def describe():
        ubx.intent("look up datadog_app_version")

        ubx.data(Version, "example", VersionConfig(
            app_id="example",
            limit=1,
            page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The real, unique identifier of the app this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  The list of app versions. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="page" type="object">
      Information on the total number of apps, to be used for pagination. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="total_count" type="number">
          The total number of apps under the Datadog organization, disregarding any filters applied. Optional lookup argument.
        </ResponseField>
        <ResponseField name="total_filtered_count" type="number">
          The total number of apps that match the specified filters. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

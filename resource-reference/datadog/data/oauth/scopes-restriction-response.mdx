## Lookup arguments

<ResponseField name="client_uuid" type="string" required>
  The real, unique identifier of the client making this request. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  Data object of an OAuth2 client scopes restriction response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of an OAuth2 client scopes restriction. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="required_permission_scopes" type="list(string)" required>
          Permission scopes automatically required for this client (for example, mobile-app permission scopes). Returns `null` when no scopes are required. Required lookup argument.
        </ResponseField>
        <ResponseField name="scopes_restriction" type="object" required>
          Allowlist of OIDC and permission scopes enforced for the OAuth2 client. Required lookup argument.
          <Expandable title="properties">
            <ResponseField name="oidc_scopes" type="list(string)" required>
              OIDC scopes the client is restricted to. Required lookup argument.
            </ResponseField>
            <ResponseField name="permission_scopes" type="list(string)" required>
              Datadog permission scopes the client is restricted to. Required lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      UUID of the OAuth2 client this restriction applies to. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      JSON:API resource type for an OAuth2 client scopes restriction. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

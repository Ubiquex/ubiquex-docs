`datadog_rum_permanent_retention_filter_response` looks up a real RUM permanent retention filter -- a rule exempting matching RUM events from standard retention limits.

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The real, unique identifier of the app this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="permanent_rf_id" type="string" required>
  The identifier of a permanent RUM retention filter. Required lookup argument.
</ResponseField>

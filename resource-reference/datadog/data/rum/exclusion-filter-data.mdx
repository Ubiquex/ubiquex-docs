## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rum "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/rum"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_rum_exclusion_filter_data"})

    		ubx.Data(rum.ExclusionFilterData, "example", rum.ExclusionFilterDataConfig{
    			AppId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.datadog.data.rum import ExclusionFilterData, ExclusionFilterDataConfig

        ubx.intent("look up datadog_rum_exclusion_filter_data")

        ubx.data(ExclusionFilterData, "example", ExclusionFilterDataConfig(

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The real, unique identifier of the app this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  A list of exclusion filters. Returned by the lookup.

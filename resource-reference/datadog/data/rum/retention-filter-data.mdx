## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rum "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/rum"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_rum_retention_filter_data"})

    		ubx.Data(rum.RetentionFilterData, "example", rum.RetentionFilterDataConfig{
    			AppId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.datadog.data.rum import RetentionFilterData, RetentionFilterDataConfig

        ubx.intent("look up datadog_rum_retention_filter_data")

    if __name__ == "__main__":

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The real, unique identifier of the app this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  A list of RUM retention filters. Returned by the lookup.
</ResponseField>

## Result properties

<ResponseField name="pipeline_ids" type="list(string)">
  Ordered Array of `&lt;PIPELINE_ID&gt;` strings, the order of pipeline IDs in the array define the overall Pipelines order for Datadog. Returned by the lookup.
</ResponseField>

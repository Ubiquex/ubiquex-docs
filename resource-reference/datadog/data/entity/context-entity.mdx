## Lookup arguments

<ResponseField name="as_of" type="string">
  Restricts the lookup to the real state as it existed at this point in time. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="from" type="string">
  The real, inclusive start of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query" type="string">
  The real query string evaluated against the underlying data. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="to" type="string">
  The real, inclusive end of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  The list of entities matching the query. Returned by the lookup.
</ResponseField>

<ResponseField name="meta" type="object">
  Metadata returned alongside the entity context response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="page" type="object" required>
      Pagination metadata for the entity context response. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="next_token" type="string" required>
          An opaque token to pass as `page_token` in a subsequent request to retrieve the next page of results. Empty when there are no more results. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="total_count" type="number" required>
      The total number of entities matching the query, irrespective of pagination. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

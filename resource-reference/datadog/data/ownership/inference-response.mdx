## Lookup arguments

<ResponseField name="owner_type" type="string" required>
  The owner type for an ownership inference. Required lookup argument.
</ResponseField>

<ResponseField name="resource_id" type="string" required>
  The real, unique identifier of this resource. **(AI-inferred)** Required lookup argument.
</ResponseField>

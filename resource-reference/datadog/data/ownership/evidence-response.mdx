## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner_type" type="string" required>
  The owner type for an ownership inference. Required lookup argument.
</ResponseField>

<ResponseField name="resource_id" type="string" required>
  The real, unique identifier of this resource. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  The data wrapper for an ownership evidence response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The attributes of an ownership evidence response. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="evidence_versions" type="list(map(any))" required>
          The list of evidence versions associated with an inference. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The identifier of the resource the evidence applies to. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the ownership evidence resource. The value should always be `ownership_evidence`. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

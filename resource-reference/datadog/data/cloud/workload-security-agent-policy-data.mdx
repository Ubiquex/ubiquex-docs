`datadog_cloud_workload_security_agent_policy_data` looks up a real Cloud Workload Security Agent policy -- a bundle of runtime detection rules deployed to Agents.

    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_cloud_workload_security_agent_policy_data"})

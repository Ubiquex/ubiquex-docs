`datadog_playlist_data` looks up a real, ordered sequence of Datadog dashboards that auto-cycles on a timer -- commonly used to drive a wall-mounted status display through a rotating set of dashboards.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	playlist "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/data/playlist"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_playlist_data"})

    		ubx.Data(playlist.Data, "example", playlist.DataConfig{})
    	}))
    }
    ```

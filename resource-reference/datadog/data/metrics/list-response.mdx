`datadog_metrics_list_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Datadog's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up datadog_metrics_list_response"})

    		ubx.Data(metrics.ListResponse, "example", metrics.ListResponseConfig{
    			From:      1,
    			Host:      "example",
    			TagFilter: "example",
    		})
    	}))
    }

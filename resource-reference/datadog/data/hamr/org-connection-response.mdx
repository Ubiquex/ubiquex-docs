## Result properties

<ResponseField name="data" type="object">
  Data object for a HAMR organization connection response. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes of a HAMR organization connection response. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="hamr_status" type="number" required>
          Status of the HAMR connection: - 0: UNSPECIFIED - Connection status not specified - 1: ONBOARDING - Initial setup of HAMR connection - 2: PASSIVE - Secondary organization in passive standby mode - 3: FAILOVER - Liminal status between PASSIVE and ACTIVE - 4: ACTIVE - Organization is an active failover - 5: RECOVERY - Recovery operation in progress Required lookup argument.
        </ResponseField>
        <ResponseField name="is_primary" type="bool" required>
          Indicates whether this organization is the primary organization in the HAMR relationship. If true, this is the primary organization. If false, this is the secondary/backup organization. Required lookup argument.
        </ResponseField>
        <ResponseField name="modified_at" type="string" required>
          Timestamp of when this HAMR connection was last modified (RFC3339 format). Required lookup argument.
        </ResponseField>
        <ResponseField name="modified_by" type="string" required>
          Username or identifier of the user who last modified this HAMR connection. Required lookup argument.
        </ResponseField>
        <ResponseField name="target_org_datacenter" type="string" required>
          Datacenter location of the target organization (e.g., us1, eu1, us5). Required lookup argument.
        </ResponseField>
        <ResponseField name="target_org_name" type="string" required>
          Name of the target organization in the HAMR relationship. Required lookup argument.
        </ResponseField>
        <ResponseField name="target_org_uuid" type="string" required>
          UUID of the target organization in the HAMR relationship. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The organization UUID for this HAMR connection. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Type of the HAMR organization connection resource. Required lookup argument.
    </ResponseField>
  </Expandable>

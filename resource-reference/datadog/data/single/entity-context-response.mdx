## Lookup arguments

<ResponseField name="as_of" type="string">
  Restricts the lookup to the real state as it existed at this point in time. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="from" type="string">
  The real, inclusive start of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="id" type="string" required>
  The real, unique identifier for this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="to" type="string">
  The real, inclusive end of the time range this request covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="object">
  A single entity returned by the entity context endpoint. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The attributes of an entity context entry, grouping all the historical revisions of the entity. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="revisions" type="list(object)" required>
          The historical revisions of the entity, ordered chronologically. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the entity. Required lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the entity. Reflects the underlying entity kind from the entity context store (for example, `siem_entity_identity` for identities). Defaults to `entity` when the kind is unknown. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

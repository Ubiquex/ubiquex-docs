`datadog_ai_custom_ruleset_response` is a named collection of `datadog_ai_custom_rule_response` rules grouped together and applied as one unit to LLM Observability traces -- the organizing container a team attaches to an LLM application rather than managing individual rules ad hoc.

## Example

    import (
    	ai "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/ai"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom ruleset response"})

    		ubx.Resource(ai.CustomRulesetResponse, "example", ai.CustomRulesetResponseConfig{
    			RulesetName: "example-ruleset-name",
    		})
    	}))
    }

`datadog_secure_embed_get_response` is a real, secure, shareable embed of a Datadog dashboard or graph -- a signed, access-controlled URL a team can embed in an external page or status site without exposing that dashboard to the public internet unrestricted.

## Properties

<ResponseField name="dashboard_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="data" type="object" required>
  Data object for creating a secure embed. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      Attributes for creating a secure embed shared dashboard. Required.
      <Expandable title="properties">
        <ResponseField name="global_time" type="object" required>
          Default time range configuration for the secure embed. Required.
          <Expandable title="properties">
            <ResponseField name="live_span" type="string">
              Dashboard global time live_span selection. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="global_time_selectable" type="bool" required>
          Whether viewers can change the time range. Required.
        </ResponseField>
        <ResponseField name="selectable_template_vars" type="list(object)" required>
          Template variables viewers can modify. Required.
          <Expandable title="properties">
            <ResponseField name="default_values" type="list(string)">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="name" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="prefix" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="visible_tags" type="list(string)">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="status" type="string" required>
          The status of the secure embed share. Active means the shared dashboard is available. Paused means it is not. Required.
        </ResponseField>
        <ResponseField name="title" type="string" required>
          Display title for the shared dashboard. Required.
        </ResponseField>
        <ResponseField name="viewing_preferences" type="object" required>
          Display settings for the secure embed shared dashboard. Required.
          <Expandable title="properties">
            <ResponseField name="high_density" type="bool">
              Whether widgets are displayed in high density mode. Optional.
            </ResponseField>
            <ResponseField name="theme" type="string">
              The theme of the shared dashboard view. `system` follows the viewer's system default. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Resource type for secure embed create requests. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="token" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

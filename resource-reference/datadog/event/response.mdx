`datadog_event_response` represents one entry in Datadog's own event stream -- generated automatically by monitors, Error Tracking, and over a hundred real integrations (Kubernetes, Jenkins, and similar), or submitted directly. Events get correlated together to cut down alert fatigue and feed the Triage Inbox teams use to investigate and resolve incidents.

## Input properties

<ResponseField name="aggregation_key" type="string">
  An arbitrary string to use for aggregation. Limited to 100 characters. If you specify a key, all events using that key are grouped together in the Event Stream. Optional.
</ResponseField>

<ResponseField name="alert_type" type="string">
  If an alert event is enabled, set its type. For example, `error`, `warning`, `info`, `success`, `user_update`, `recommendation`, and `snapshot`. Optional.
</ResponseField>

<ResponseField name="date_happened" type="number">
  POSIX timestamp of the event. Must be sent as an integer (that is no quotes). Limited to events no older than 18 hours Optional.
</ResponseField>

<ResponseField name="device_name" type="string">
  A device name. Optional.
</ResponseField>

<ResponseField name="event_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="host" type="string">
  Host name to associate with the event. Any tags associated with the host are also applied to this event. Optional.
</ResponseField>

<ResponseField name="priority" type="string">
  The priority of the event. For example, `normal` or `low`. Optional.
</ResponseField>

<ResponseField name="related_event_id" type="number">
  ID of the parent event. Must be sent as an integer (that is no quotes). Optional.
</ResponseField>

<ResponseField name="source_type_name" type="string">
  The type of event being posted. Option examples include nagios, hudson, jenkins, my_apps, chef, puppet, git, bitbucket, etc. A complete list of source attribute values [available here](https://docs.datadoghq.com/integrations/faq/list-of-api-source-attribute-value). Optional.
</ResponseField>

<ResponseField name="tags" type="list(string)">
  A list of tags to apply to the event. Optional.
</ResponseField>

<ResponseField name="text" type="string" required>
  The body of the event. Limited to 4000 characters. The text supports markdown. To use markdown in the event text, start the text block with `%%% \n` and end the text block with `\n %%%`. Use `msg_text` with the Datadog Ruby library. Required.
</ResponseField>

<ResponseField name="title" type="string" required>
  The event title. Required.
</ResponseField>

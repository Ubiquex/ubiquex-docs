---
title: "datadog_shared_dashboard"
description: "`datadog_shared_dashboard` publishes a dashboard to a public link that anyone can view outside Datadog entirely, without a Datadog account or credentials."
---

It's the mechanism for showing metric, trace, and log visualizations to people outside your organization, and every publicly shared dashboard can be tracked and revoked from one place in your account settings.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    			DashboardType: "example",

## Properties

<ResponseField name="author" type="object">
  User who shared the dashboard. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="handle" type="string">
      Identifier of the user who shared the dashboard. Computed by Datadog after `ship`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Name of the user who shared the dashboard. Computed by Datadog after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created" type="string">
  Date the dashboard was shared. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="dashboard_id" type="string" required>
  ID of the dashboard to share. Required.
</ResponseField>

<ResponseField name="dashboard_type" type="string" required>
  The type of the associated private dashboard. Required.
</ResponseField>

<ResponseField name="embeddable_domains" type="list(string)">
  The `SharedDashboard` `embeddable_domains`. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="expiration" type="string">
  The time when an OPEN shared dashboard becomes publicly unavailable. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="global_time" type="object">
  Object containing the live span selection for the dashboard. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="live_span" type="string">
      Dashboard global time live_span selection Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="global_time_selectable_enabled" type="bool">
  Whether to allow viewers to select a different global time setting for the shared dashboard. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="invitees" type="list(object)">
  The `SharedDashboard` `invitees`. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="access_expiration" type="string">
      Optional; if omitted, computed by Datadog.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Optional; if omitted, computed by Datadog.
    </ResponseField>
    <ResponseField name="email" type="string">
      The email address of the invitee granted access to the shared dashboard. Optional; if omitted, computed by Datadog. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="last_accessed" type="string">
  The last time the shared dashboard was accessed. Null if never accessed. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="public_url" type="string">
  URL of the shared dashboard. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="selectable_template_vars" type="list(object)">
  List of objects representing template variables on the shared dashboard which can have selectable values. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="default_value" type="string">
      The default value for the template variable when the dashboard is shared. Viewers can override this value. Optional; if omitted, computed by Datadog. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the template variable that will be selectable by viewers of the shared dashboard. Must correspond to a template variable defined on the dashboard. Optional; if omitted, computed by Datadog. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="prefix" type="string">
      The tag key prefix associated with a selectable template variable in a shared dashboard, used to scope the variable's values (e.g., 'service' for service-specific filtering). Optional; if omitted, computed by Datadog. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Optional; if omitted, computed by Datadog.
    </ResponseField>
    <ResponseField name="visible_tags" type="list(string)">
      List of tag values that are shown as selectable options for this template variable in the shared dashboard. Optional; if omitted, computed by Datadog. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="share_list" type="list(string)">
  List of email addresses that can receive an invitation to access to the shared dashboard. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="share_type" type="string">
  Type of sharing access (either open to anyone who has the public URL or invite-only). Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="status" type="string">
  Active means the dashboard is publicly available. Paused means the dashboard is not publicly available. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="title" type="string">
  Title of the shared dashboard. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="token" type="string">
  A unique token assigned to the shared dashboard. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="viewing_preferences" type="object">
  The viewing preferences for a shared dashboard. Optional; if omitted, computed by Datadog.
  <Expandable title="properties">
    <ResponseField name="high_density" type="bool">
      Whether the widgets on the shared dashboard should be displayed with high density. Optional.
    </ResponseField>
    <ResponseField name="theme" type="string">
      The theme of the shared dashboard view. "system" follows your system's default viewing theme. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

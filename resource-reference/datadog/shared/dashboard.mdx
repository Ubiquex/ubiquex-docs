`datadog_shared_dashboard` publishes a dashboard to a public link that anyone can view outside Datadog entirely, without a Datadog account or credentials. It's the mechanism for showing metric, trace, and log visualizations to people outside your organization, and every publicly shared dashboard can be tracked and revoked from one place in your account settings.

Real, typed bindings generated directly from the real Datadog OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

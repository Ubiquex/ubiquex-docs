`datadog_user_response` represents one person's account inside a Datadog organization, along with the roles and permissions that determine what they can actually do -- managed from the Users tab in Organization Settings, where an admin invites, assigns roles to, and can disable individual accounts.

## Input properties

<ResponseField name="access_role" type="string">
  The access role of the user. Options are **st** (standard user), **adm** (admin user), or **ro** (read-only user). Optional.
</ResponseField>

<ResponseField name="disabled" type="bool">
  The new disabled status of the user. Optional.
</ResponseField>

<ResponseField name="email" type="string">
  The new email of the user. Optional.
</ResponseField>

<ResponseField name="handle" type="string">
  The user handle, must be a valid email. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the user. Optional.
</ResponseField>

<ResponseField name="user_handle" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

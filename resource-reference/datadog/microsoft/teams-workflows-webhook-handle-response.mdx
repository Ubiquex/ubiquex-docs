`datadog_microsoft_teams_workflows_webhook_handle_response` is a real, configured Microsoft Teams destination using a Teams Workflows (Power Automate) webhook URL -- the webhook-based way Datadog notifications post into a Teams channel, Microsoft's current replacement for the deprecated Office 365 Connector webhook.

`datadog_logs_metric_response` is a real, custom metric generated by aggregating log data -- letting a team turn high-volume or expensive-to-retain logs into a cheap, long-retention metric (a count or a measured value) instead of paying to index every underlying log line.

## Properties

<ResponseField name="data" type="object" required>
  The new log-based metric properties. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The object describing the Datadog log-based metric to create. Required.
      <Expandable title="properties">
        <ResponseField name="compute" type="object" required>
          The compute rule to compute the log-based metric. Required.
          <Expandable title="properties">
            <ResponseField name="aggregation_type" type="string" required>
              The type of aggregation to use. Required.
            </ResponseField>
            <ResponseField name="include_percentiles" type="bool">
              Toggle to include or exclude percentile aggregations for distribution metrics. Only present when the `aggregation_type` is `distribution`. Optional.
            </ResponseField>
            <ResponseField name="path" type="string">
              The path to the value the log-based metric will aggregate on (only used if the aggregation type is a "distribution"). Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="filter" type="object">
          The log-based metric filter. Logs matching this filter will be aggregated in this metric. Optional.
          <Expandable title="properties">
            <ResponseField name="query" type="string">
              The search query - following the log search syntax. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="group_by" type="list(object)">
          The rules for the group by. Optional.
          <Expandable title="properties">
            <ResponseField name="path" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
            <ResponseField name="tag_name" type="string">
              Optional; if omitted, computed by Datadog.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The name of the log-based metric. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. The value should always be logs_metrics. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metric_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

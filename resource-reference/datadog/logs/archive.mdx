`datadog_logs_archive` is a real, configured long-term log archive -- where Datadog forwards a copy of ingested logs (to Amazon S3, Azure Blob Storage, or Google Cloud Storage) for cheap, long-term retention and rehydration, outside Datadog's own indexed retention window.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own archive"})

    		ubx.Resource(logs.Archive, "example", logs.ArchiveConfig{
    			ArchiveId: "example",
    		})
    	}))
    }
    ```
  </Tab>

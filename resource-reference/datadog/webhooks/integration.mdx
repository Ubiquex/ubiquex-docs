`datadog_webhooks_integration` sends a real POST request to an external endpoint whenever a monitor alert fires, triggered by adding `@webhook-<name>` to the monitor's own alert text. Built-in variables like `$ALERT_ID` and `$ALERT_STATUS` populate the payload automatically, giving the receiving service real, structured context about exactly what happened.

Real, typed bindings generated directly from the real Datadog OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	webhooks "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/webhooks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own integration"})

    		ubx.Resource(webhooks.Integration, "ci-runner", webhooks.IntegrationConfig{
    			Name:        "ci-runner",
    			Url:         "example",
    			WebhookName: "example-webhook-name",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="custom_headers" type="string">
  If `null`, uses no header. If given a JSON payload, these will be headers attached to your webhook. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="encode_as" type="string">
  Encoding type. Can be given either `json` or `form`. Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the webhook. It corresponds with `&lt;WEBHOOK_NAME&gt;`. Learn more on how to use it in [monitor notifications](https://docs.datadoghq.com/monitors/notify). Required.
</ResponseField>

<ResponseField name="payload" type="string">
  If `null`, uses the default payload. If given a JSON payload, the webhook returns the payload specified by the given payload. [Webhooks variable usage](https://docs.datadoghq.com/integrations/webhooks/#usage). Optional; if omitted, computed by Datadog.
</ResponseField>

<ResponseField name="url" type="string" required>
  URL of the webhook. Required.
</ResponseField>

<ResponseField name="webhook_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`datadog_retention_filter_response` is v2's own general logs retention filter representation -- a real filter query that routes matching logs into a specific `datadog_logs_index` with its own retention period, the general form `datadog_rum_retention_filter_response` specializes for RUM.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only datadog --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (
    	retention "github.com/ubiquex/ubx-sdk-datadog/sdk/go/datadog/retention"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own filter response"})

    		ubx.Resource(retention.FilterResponse, "example", retention.FilterResponseConfig{
    			Data:     map[string]any{"attributes": map[string]any{"name": "example-name"}},
    			FilterId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="data" type="object" required>
  The body of the retention filter to be updated. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="object" required>
      The object describing the configuration of the retention filter to create/update. Required.
      <Expandable title="properties">
        <ResponseField name="enabled" type="bool" required>
          Enable/Disable the retention filter. Required.
        </ResponseField>
        <ResponseField name="filter" type="object" required>
          The spans filter. Spans matching this filter will be indexed and stored. Required.
          <Expandable title="properties">
            <ResponseField name="query" type="string" required>
              The search query - following the [span search syntax](https://docs.datadoghq.com/tracing/trace_explorer/query_syntax/). Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="filter_type" type="string" required>
          The type of retention filter. Required.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of the retention filter. Required.
        </ResponseField>
        <ResponseField name="rate" type="number" required>
          Sample rate to apply to spans going through this retention filter. A value of 1.0 keeps all spans matching the query. Required.
        </ResponseField>
        <ResponseField name="trace_rate" type="number">
          Sample rate to apply to traces containing spans going through this retention filter. A value of 1.0 keeps all traces with spans matching the query. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The ID of the retention filter. Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the resource. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="filter_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

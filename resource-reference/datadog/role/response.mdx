`datadog_role_response` is a real Datadog organization role -- the named permission set (Datadog Admin, Standard, Read Only, or a custom role) assigned to organization members, controlling what each user is allowed to see and do.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-datadog/sdk/go => ./local-sdk/datadog/sdk/go
    package main

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

---
title: "aws_iam_policy"
description: "A reusable IAM policy document."
---

`aws_iam_policy` creates a standalone, reusable IAM policy, a real JSON
document describing what's allowed. It grants nothing on its own,
attach it to a role or user with `aws_iam_role_policy_attachment` to
actually apply it.

Every tab below is a complete, runnable program, not a fragment,
real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	"encoding/json"

    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own policy"})

    		accessPolicy, _ := json.Marshal(map[string]any{
    			"Version": "2012-10-17",
    			"Statement": []map[string]any{{
    				"Effect":   "Allow",
    				"Action":   "*",
    				"Resource": "*",
    			}},
    		})

    		ubx.Resource(iam.Policy, "ci-runner", iam.PolicyConfig{
    			Policy:                       string(accessPolicy),
    			Name:                         "ci-runner",
    			DelayAfterPolicyCreationInMs: 1,
    			Description:                  "Managed by ubx.",
    			Path:                         "/ci/",
    			Tags:                         map[string]string{"managed-by": "ubx"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Policy } from "jsr:@ubx/sdk-aws/aws/iam/policy";

    export default stack("payments", () => {
      intent({ summary: "payments own policy" });

      const accessPolicy = JSON.stringify({
        Version: "2012-10-17",
        Statement: [{
          Effect: "Allow",
          Action: "*",
          Resource: "*",
        }],
      });

      resource(Policy, "ci-runner", {
        policy: accessPolicy,
        name: "ci-runner",
        delayAfterPolicyCreationInMs: 1,
        description: "Managed by ubx.",
        path: "/ci/",
        tags: { "managed-by": "ubx" },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import json
    import ubx_sdk as ubx
    from ubx.aws.iam import Policy, PolicyConfig

    def describe():
        ubx.intent("payments own policy")

        access_policy = json.dumps({
            "Version": "2012-10-17",
            "Statement": [{
                "Effect": "Allow",
                "Action": "*",
                "Resource": "*",
            }],
        })

        ubx.resource(Policy, "ci-runner", PolicyConfig(
            policy=access_policy,
            name="ci-runner",
            delay_after_policy_creation_in_ms=1,
            description="Managed by ubx.",
            path="/ci/",
            tags={"managed-by": "ubx"},
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Input properties

<ResponseField name="name" type="string">
  The policy's own name. Conflicts with `name_prefix`.
</ResponseField>

<ResponseField name="name_prefix" type="string">
  A prefix, with a generated suffix appended. Conflicts with `name`.
</ResponseField>

<ResponseField name="path" type="string" default="/">
  The policy's own path.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the policy.
</ResponseField>

<ResponseField name="policy" type="string (JSON)" required>
  The real policy document itself.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Same value as `arn`.
</ResponseField>

<ResponseField name="arn" type="string">
  The policy's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="policy_id" type="string">
  AWS's own stable unique identifier for the policy.
</ResponseField>

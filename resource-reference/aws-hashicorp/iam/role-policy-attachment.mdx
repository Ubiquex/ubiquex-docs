---
title: "aws_iam_role_policy_attachment"
description: "Attach a managed policy to a role."
---

`aws_iam_role_policy_attachment` is the actual grant, it attaches an
existing, standalone policy to an existing role. Neither the role nor
the policy alone grants anything, this attachment is what connects
them.

Every tab below is a complete, runnable program, not a fragment,
real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own role policy attachment"})

    		ubx.Resource(iam.RolePolicyAttachment, "ci-runner", iam.RolePolicyAttachmentConfig{
    			PolicyArn: "arn:aws:iam::123456789012:policy/ci",
    			Role:      "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { RolePolicyAttachment } from "jsr:@ubx/sdk-aws/aws/iam/role_policy_attachment";

    export default stack("payments", () => {
      intent({ summary: "payments own role policy attachment" });

      resource(RolePolicyAttachment, "ci-runner", {
        policyArn: "arn:aws:iam::123456789012:policy/ci",
        role: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.iam import RolePolicyAttachment, RolePolicyAttachmentConfig

    def describe():
        ubx.intent("payments own role policy attachment")

        ubx.resource(RolePolicyAttachment, "ci-runner", RolePolicyAttachmentConfig(
            policy_arn="arn:aws:iam::123456789012:policy/ci",
            role="example",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```
  </Tab>

## Input properties

<ResponseField name="role" type="string" required>
  The name of the role to attach the policy to.
</ResponseField>

<ResponseField name="policy_arn" type="string" required>
  The ARN of the policy to attach.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  A computed identifier combining the role name and policy ARN.
</ResponseField>

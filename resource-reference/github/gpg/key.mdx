`github_gpg_key` signs commits and tags with real, verifiable cryptographic proof of who actually authored them, and unlike an SSH key used the same way, a GPG key supports real expiration and revocation -- lifecycle management SSH signing has no equivalent for.

Real, typed bindings generated directly from the real GitHub REST API OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

## Example

<Tabs>

    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	gpg "github.com/ubiquex/ubx-sdk-github/sdk/go/github/gpg"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own key"})

    		ubx.Resource(gpg.Key, "ci-runner", gpg.KeyConfig{
    			ArmoredPublicKey: "example",
    			GpgKeyId:         "example",
    			Name:             "ci-runner",
    		})
    	}))
    }
    ```

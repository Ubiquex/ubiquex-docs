`github_copilot_space` organizes real context -- repositories, code, pull requests, issues, free-text notes, images -- that grounds Copilot's own answers in the specific project or task a space was built for. Spaces stay in sync as the underlying GitHub content changes, and can belong to a personal account or an organization, shared with a team or made public.

## Input properties

<ResponseField name="base_role" type="string">
  The base role that determines default permissions for organization members. - `no_access`: No default access (default) - `reader`: Organization members can read the space - `writer`: Organization members can read and edit the space - `admin`: Organization members have full admin access to the space Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="description" type="string">

</ResponseField>

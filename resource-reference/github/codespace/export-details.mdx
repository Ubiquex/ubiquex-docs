`github_codespace_export_details` tracks the real, asynchronous process of pushing a codespace's own uncommitted changes out to a new branch -- the mechanism for recovering real work done in a codespace that's about to be deleted without a normal commit ever having been made.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codespace "github.com/ubiquex/ubx-sdk-github/sdk/go/github/codespace"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own export details"})

    		ubx.Resource(codespace.ExportDetails, "example", codespace.ExportDetailsConfig{
    			CodespaceName: "example-codespace-name",
    			ExportId:      "example",
    		})
    	}))
    }
    ```
  </Tab>

## Output properties

<ResponseField name="branch" type="string">
  Name of the exported branch Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="completed_at" type="string">
  Completion time of the last export operation Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="export_url" type="string">
  Url for fetching export details Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="html_url" type="string">
  Web url for the exported branch Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  Id for the export details Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="sha" type="string">
  Git commit SHA of the exported branch Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  State of the latest export Computed by GitHub after `ship`.
</ResponseField>

`github_codespaces_org_secret` creates or updates an encrypted secret available to Codespaces for repositories within an organization, scoped to a caller-chosen selection of them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	codespaces "github.com/ubiquex/ubx-sdk-github/sdk/go/github/codespaces"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own org secret"})

    		ubx.Resource(codespaces.OrgSecret, "example", codespaces.OrgSecretConfig{
    			Org:                   "example",
    			SecretName:            "example-secret-name",
    			Visibility:            "example",
    			EncryptedValue:        "example",
    			KeyId:                 "example",
    			SelectedRepositoryIds: []any{1},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="encrypted_value" type="string">
  The value for your secret, encrypted with [LibSodium](https://libsodium.gitbook.io/doc/bindings_for_other_languages) using the public key retrieved from the [Get an organization public key](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/organization-secrets#get-an-organization-public-key) endpoint. Optional.
</ResponseField>

<ResponseField name="key_id" type="string">
  The ID of the key you used to encrypt the secret. Optional.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="secret_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="selected_repository_ids" type="list(number)">
  An array of repository IDs that can access the organization secret. You can only provide a list of repository IDs when the `visibility` is set to `selected`. You can manage the list of selected repositories using the [List selected repositories for an organization secret](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/organization-secrets#list-selected-repositories-for-an-organization-secret), [Set selected repositories for an organization secret](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/organization-secrets#set-selected-repositories-for-an-organization-secret), and [Remove selected repository from an organization secret](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/organization-secrets#remove-selected-repository-from-an-organization-secret) endpoints. Optional.
</ResponseField>

<ResponseField name="visibility" type="string" required>
  Which type of organization repositories have access to the organization secret. `selected` means only the repositories specified by `selected_repository_ids` can access the secret. Required.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time at which the secret was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the secret Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The API URL at which the list of repositories this secret is visible to can be retrieved Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time at which the secret was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

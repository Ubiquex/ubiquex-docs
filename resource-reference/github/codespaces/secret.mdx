    			SecretName:            "example-secret-name",
    			EncryptedValue:        "example",
    			SelectedRepositoryIds: []any{"example"},
    		})
    	}))
    }

## Input properties

<ResponseField name="encrypted_value" type="string">
  Value for your secret, encrypted with [LibSodium](https://libsodium.gitbook.io/doc/bindings_for_other_languages) using the public key retrieved from the [Get the public key for the authenticated user](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/secrets#get-public-key-for-the-authenticated-user) endpoint. Optional.
</ResponseField>

<ResponseField name="key_id" type="string" required>
  ID of the key you used to encrypt the secret. Required.
</ResponseField>

<ResponseField name="secret_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="selected_repository_ids" type="list(any)">
  An array of repository ids that can access the user secret. You can manage the list of selected repositories using the [List selected repositories for a user secret](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/secrets#list-selected-repositories-for-a-user-secret), [Set selected repositories for a user secret](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/secrets#set-selected-repositories-for-a-user-secret), and [Remove a selected repository from a user secret](https://docs.github.com/enterprise-cloud@latest/rest/codespaces/secrets#remove-a-selected-repository-from-a-user-secret) endpoints. Optional.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time at which the secret was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the secret Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The API URL at which the list of repositories this secret is visible to can be retrieved Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time at which the secret was last updated, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="visibility" type="string">
  The type of repositories in the organization that the secret is visible to Computed by GitHub after `ship`.
</ResponseField>

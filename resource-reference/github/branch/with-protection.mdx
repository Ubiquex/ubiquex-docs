title: "github_branch_with_protection"
description: "`github_branch_with_protection` enforces real requirements on a specific branch, a name pattern..."
---

`github_branch_with_protection` enforces real requirements on a specific branch, a name pattern, or every branch in a repository -- passing status checks, an approving review, a linear history -- and can block force pushes or deletion outright. It's the mechanism that turns "please don't break main" into something GitHub actually enforces rather than a convention people can ignore.

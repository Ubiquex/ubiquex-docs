`github_commit` is one real, immutable snapshot of a repository at a point in time -- an author, a message, a parent commit (or commits, for a merge), and the tree of file contents that snapshot actually contains.

## Input properties

<ResponseField name="base" type="string" required>
  The name of the base branch that the head will be merged into. Required.
</ResponseField>

<ResponseField name="commit_message" type="string">
  Commit message to use for the merge commit. If omitted, a default message will be used. Optional.
</ResponseField>

<ResponseField name="head" type="string" required>
  The head to merge. This can be a branch name or a commit SHA1. Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="ref" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`github_attestation` is a cryptographically signed record establishing where and how a real software artifact was built -- the real supply-chain-security mechanism for proving a binary or container image's own build provenance, so anyone consuming it can verify it actually came from the build it claims to.

    			SubjectDigest: "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="bundle" type="object" required>
  The attestation's Sigstore Bundle. Refer to the [Sigstore Bundle Specification](https://github.com/sigstore/protobuf-specs/blob/main/protos/sigstore_bundle.proto) for more information. Required.
  <Expandable title="properties">
    <ResponseField name="dsse_envelope" type="any">
      The DSSE envelope containing the signed attestation payload and its signature. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="media_type" type="string">
      The media type (MIME type) of the attestation bundle, indicating the format used to serialize the bundle's content. This helps consumers parse and validate the bundle according to its specified schema. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="verification_material" type="any">
      The verification material associated with the attestation bundle, including certificates and transparency log entries used to verify the attestation's provenance. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="owner" type="string" required>

</ResponseField>

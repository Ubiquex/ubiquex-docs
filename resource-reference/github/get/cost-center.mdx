`github_get_cost_center` is an enterprise's own real billing grouping -- a named bucket (mapped to an Azure subscription, a set of users, or a set of resources) that GitHub's own cost-management reporting attributes spend to, letting a large organization break down its GitHub bill by team or department rather than reading one undifferentiated enterprise total.

## Input properties

<ResponseField name="ai_credit_pool_enabled" type="bool">
  Whether the cost center draws from the AI credit pool. This can only be enabled for cost centers that contain only user or team resources. - `false`  --  no cap; the cost center draws from the shared enterprise pool. - `true`  --  the cost center is capped at an amount derived from its members' license entitlements. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="cost_center_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the cost center (max length 255 characters) Required.
</ResponseField>

## Output properties

<ResponseField name="ai_credit_pool_enabled" type="bool">
  Whether the cost center draws from the AI credit pool. This can only be enabled for cost centers that contain only user or team resources. - `false`  --  no cap; the cost center draws from the shared enterprise pool. - `true`  --  the cost center is capped at an amount derived from its members' license entitlements. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="ai_credit_pool_state" type="object">
  Read-only cap-budget projection for the cost center. Only present when the cost center draws from the AI credit pool. Computed by GitHub after `ship`.
  <Expandable title="properties">
    <ResponseField name="current_amount" type="number">
      The current-month applied amount against the AI credit pool cap, in AI Credits. Null when the cap budget has not been materialized yet. Optional.
    </ResponseField>
    <ResponseField name="target_amount" type="number">
      The AI credit pool cap target amount, in AI Credits. Null when the cap budget has not been materialized yet. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="azure_subscription" type="string">
  Azure subscription ID associated with the cost center. Only present for cost centers linked to Azure subscriptions. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="has_next_page" type="bool">
  Indicates if there are more resources available for pagination. Only present when pagination is used. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  ID of the cost center. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="resources" type="list(object)">
  Computed by GitHub after `ship`.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Optional; if omitted, computed by GitHub.
    </ResponseField>
    <ResponseField name="type" type="string">
      Optional; if omitted, computed by GitHub.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  State of the cost center. Computed by GitHub after `ship`.
</ResponseField>

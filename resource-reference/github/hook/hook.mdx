`github_hook` (a repository webhook) delivers real event data to an external server the moment a subscribed event happens on that repository -- a push, an issue opened, a pull request merged -- the mechanism behind triggering an external CI pipeline, a deployment, or a notification without polling GitHub for changes.

## Example

    package main

    import (
    	hook "github.com/ubiquex/ubx-sdk-github/sdk/go/github/hook"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hook"})

    		ubx.Resource(hook.Hook, "example", hook.HookConfig{
    			HookId: "example",
    			Owner:  "example",
    			Repo:   "example",
    			Name:   "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="active" type="bool">
  Determines if notifications are sent when the webhook is triggered. Set to `true` to send notifications. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="config" type="object">
  Key/value pairs to provide settings for this webhook. Optional; if omitted, computed by GitHub.
  <Expandable title="properties">
    <ResponseField name="content_type" type="string">
      The media type used to serialize the payloads. Supported values include `json` and `form`. The default is `form`. Optional.
    </ResponseField>
    <ResponseField name="insecure_ssl" type="any">
      Controls whether GitHub disables SSL verification when delivering webhook payloads. Accepts '0' or false to enable verification, and '1' or true to allow insecure connections (e.g., self-signed certificates). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="secret" type="string">
      If provided, the `secret` will be used as the `key` to generate the HMAC hex digest value for [delivery signature headers](https://docs.github.com/enterprise-cloud@latest/webhooks/event-payloads/#delivery-headers). Optional.
    </ResponseField>
    <ResponseField name="url" type="string">
      The URL to which the payloads will be delivered. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="events" type="list(string)">
  Determines what [events](https://docs.github.com/enterprise-cloud@latest/webhooks/event-payloads) the hook is triggered for. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="hook_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="name" type="string">
  Use `web` to create a webhook. Default: `web`. This parameter only accepts the value `web`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`github_key` is an SSH public key added to a personal account for authentication -- what actually lets `git push`/`git pull` over SSH identify a specific real user, distinct from a deploy key's own repository-only scope.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    			KeyId: "example",
    		})
    	}))

## Input properties

<ResponseField name="key" type="string" required>
  The public SSH key to add to your GitHub account. Required.
</ResponseField>

<ResponseField name="key_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="title" type="string">
  A descriptive name for the new key. Optional; if omitted, computed by GitHub.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time when the key was created, in ISO 8601 format (e.g., 2023-01-01T12:00:00Z). This timestamp is set by the GitHub API upon key creation. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="number">
  Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="last_used" type="string">
  The date and time when this GitHub key was last used for authentication. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="read_only" type="bool">
  Indicates whether the key is read-only (true) or has read/write access (false). Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="title" type="string">
  A descriptive name for the new key. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="url" type="string">
  The GitHub API URL for this SSH key. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="verified" type="bool">
  Boolean indicating whether the key has been verified by GitHub. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

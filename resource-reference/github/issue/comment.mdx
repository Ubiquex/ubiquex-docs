`github_issue_comment` is one comment in the real, ongoing discussion thread attached to an issue -- the same real commenting mechanism issues share with pull requests and commits, applied to whatever conversation an issue itself is tracking.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	issue "github.com/ubiquex/ubx-sdk-github/sdk/go/github/issue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own comment"})

    		ubx.Resource(issue.Comment, "example", issue.CommentConfig{
    			CommentId: "example",
    			Owner:     "example",
    			Repo:      "example",
    		})
    	}))
    }
    ```
  </Tab>

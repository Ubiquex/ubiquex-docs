`github_usage_report_export` is a requested, generated export of an enterprise's own GitHub Actions/Packages/Copilot usage data over a real date range -- its status, the actor who requested it, and the download URLs for the finished report. Enterprises use these for real cost attribution and usage auditing beyond what the live billing dashboard shows.

## Input properties

<ResponseField name="end_date" type="string">
  The end date for the report in YYYY-MM-DD format. Defaults to today (UTC) if not provided. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="report_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="report_type" type="string" required>
  The type of usage report to generate Required.
</ResponseField>

<ResponseField name="send_email" type="bool">
  Whether to send an email notification to the requester when the report is ready. Defaults to false. Optional.
</ResponseField>

<ResponseField name="start_date" type="string" required>
  The start date for the report in YYYY-MM-DD format Required.
</ResponseField>

## Output properties

<ResponseField name="actor" type="string">
  The login of the user who requested the export Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  When the report export was created Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="download_urls" type="list(string)">
  URLs to download the completed report. Only present when the report status is `completed`. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="end_date" type="string">
  The end date for the report in YYYY-MM-DD format. Defaults to today (UTC) if not provided. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="id" type="string">
  Unique identifier for the usage report export Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the report export Computed by GitHub after `ship`.
</ResponseField>

`github_enterprise_team` is a team defined once at the enterprise level and assignable across up to 15,000 organizations within it, rather than being recreated separately inside every organization -- real, centralized team management at a scale a single organization's own teams were never meant to cover.

## Input properties

<ResponseField name="description" type="string">
  A description of the team. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="group_id" type="string">
  The ID of the IdP group to assign team membership with. You can get this value from the [REST API endpoints for SCIM](https://docs.github.com/rest/scim#list-provisioned-scim-groups-for-an-enterprise). Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the team. Required.
</ResponseField>

<ResponseField name="notification_setting" type="string">
  The notification setting the team is set to. The options are: * `notifications_enabled` - team members receive notifications when the team is @mentioned. * `notifications_disabled` - no one receives notifications. Default: `notifications_enabled` Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="organization_selection_type" type="string">
  Specifies which organizations in the enterprise should have access to this team. Can be one of `disabled`, `selected`, or `all`. `disabled`: The team is not assigned to any organizations. This is the default when you create a new team. `selected`: The team is assigned to specific organizations. You can then use the [add organization assignments API](https://docs.github.com/rest/enterprise-teams/enterprise-team-organizations#add-organization-assignments) endpoint. `all`: The team is assigned to all current and future organizations in the enterprise. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="sync_to_organizations" type="string">
  Retired: this field is no longer supported. Whether the enterprise team should be reflected in each organization. This value cannot be set. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="team_slug" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`github_dependabot_secret` creates or updates an encrypted secret available to Dependabot version updates in a repository, referenced by name from a manifest's own registry configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	dependabot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/dependabot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own secret"})

    		ubx.Resource(dependabot.Secret, "example", dependabot.SecretConfig{
    			Owner:          "example",
    			Repo:           "example",
    			SecretName:     "example-secret-name",
    			EncryptedValue: "example",
    			KeyId:          "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="encrypted_value" type="string">
  Value for your secret, encrypted with [LibSodium](https://libsodium.gitbook.io/doc/bindings_for_other_languages) using the public key retrieved from the [Get a repository public key](https://docs.github.com/enterprise-cloud@latest/rest/dependabot/secrets#get-a-repository-public-key) endpoint. Optional.
</ResponseField>

<ResponseField name="key_id" type="string">
  ID of the key you used to encrypt the secret. Optional.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="secret_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">

</ResponseField>

<ResponseField name="name" type="string">
  The name of the secret. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">

</ResponseField>

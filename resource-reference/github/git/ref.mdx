`github_git_ref` is a named pointer -- a branch head or a tag -- to a specific real commit, the real object that moves forward every time a branch gets a new commit.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	git "github.com/ubiquex/ubx-sdk-github/sdk/go/github/git"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ref"})

    		ubx.Resource(git.Ref, "example", git.RefConfig{
    			Owner: "example",
    			Ref:   "example",
    			Repo:  "example",
    			Sha:   "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="ref" type="string" required>
  The name of the fully qualified reference (ie: `refs/heads/master`). If it doesn't start with 'refs' and have at least two slashes, it will be rejected. Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="sha" type="string" required>
  The SHA1 value for this reference. Required.
</ResponseField>

## Output properties

<ResponseField name="node_id" type="string">
  The GraphQL node ID of the git reference. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="object" type="object">
  Details of the object that this Git ref points to, including its SHA and type (e.g., commit). Computed by GitHub after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="sha" type="string" required>
      SHA for the reference Required.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of Git object that this ref points to. Valid values are commit, tree, blob, and tag. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="url" type="string" required>
      The API URL for the git object associated with the reference. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="url" type="string">
  The API URL of the Git reference, as returned by the GitHub API. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

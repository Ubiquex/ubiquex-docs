`github_organization_custom_property` is a custom metadata field an organization defines for its own repositories -- a name, a value type (string, single-select, multi-select, true/false), and who's allowed to edit it. Organizations use these to tag repositories with facts GitHub doesn't track natively (an internal team owner, a compliance tier, a deployment environment), then filter and govern repositories by that tag at scale.

    ```go
    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom property"})

    		ubx.Resource(organization.CustomProperty, "example", organization.CustomPropertyConfig{
    			CustomPropertyName: "example-custom-property-name",
    			Enterprise:         "example",
    			ValueType:          "example",
    			AllowedValues:      []string{"example"},
    			DefaultValue:       "example",
    			Description:        "Managed by ubx.",
    			Required:           true,
    			ValuesEditableBy:   "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="allowed_values" type="list(string)">

</ResponseField>

`github_organization_simple` is a shared account real teams collaborate through -- a container with its own name and brand for repositories, projects, and members, each granted a real role that controls exactly what they can see and do inside it.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

`github_organization_actions_variable` is the same real Actions configuration-variable mechanism as a repository-level variable, defined once at the organization level so every repository underneath can read it through the `vars` context without redefining it repository by repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organization "github.com/ubiquex/ubx-sdk-github/sdk/go/github/organization"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own actions variable"})

    		ubx.Resource(organization.ActionsVariable, "example", organization.ActionsVariableConfig{
    			Name:                  "example",
    			Org:                   "example",
    			Value:                 "example",
    			Visibility:            "example",
    			SelectedRepositoryIds: []any{1},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The name of the variable. Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="selected_repository_ids" type="list(number)">
  An array of repository ids that can access the organization variable. You can only provide a list of repository ids when the `visibility` is set to `selected`. Optional.
</ResponseField>

<ResponseField name="value" type="string" required>
  The value of the variable. Required.
</ResponseField>

<ResponseField name="visibility" type="string" required>
  The type of repositories in the organization that can access the variable. `selected` means only the repositories specified by `selected_repository_ids` can access the variable. Required.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time at which the variable was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  API URL listing the repositories this organization-level Actions variable is selectively exposed to. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time at which the variable was last updated, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

`github_organization_role` is an organization-level (not repository-level) custom permission role -- what an organization owner can grant someone to manage organization settings, teams, or security configuration without handing over full organization-owner access. Distinct from `github_organization_custom_repository_role`, which scopes to a single repository rather than the whole organization.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(organization.Role, "example", organization.RoleConfig{
    			Name:        "example",
    			Org:         "example",
    			Permissions: []string{"example"},
    			RoleId:      "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="base_role" type="string">
  The system role from which this role can inherit permissions. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="description" type="string">
  A short description about the intended usage of this role or what permissions it grants. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the custom role. Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="permissions" type="list(string)" required>
  A list of additional permissions included in this role. Required.
</ResponseField>

<ResponseField name="role_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`github_gist_comment` is a comment left on a real gist, the same real commenting mechanism GitHub uses on issues and commits, applied to a shared code snippet instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gist "github.com/ubiquex/ubx-sdk-github/sdk/go/github/gist"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own comment"})

    		ubx.Resource(gist.Comment, "example", gist.CommentConfig{
    			Body:      "example",
    			CommentId: "example",
    			GistId:    "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.github.gist.comment import Comment, CommentConfig

    def describe():

            body="example",
            comment_id="example",
            gist_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="body" type="string" required>
  The comment text. Required.
</ResponseField>

<ResponseField name="comment_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="gist_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`github_label` categorizes issues, pull requests, and discussions inside a repository -- a real, lightweight classification tool for organizing and filtering work rather than hunting through everything unsorted.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	label "github.com/ubiquex/ubx-sdk-github/sdk/go/github/label"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own label"})

    		ubx.Resource(label.Label, "example", label.LabelConfig{
    			Name:  "example",
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="color" type="string">
  The [hexadecimal color code](http://www.color-hex.com/) for the label, without the leading `#`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="description" type="string">
  A short description of the label. Must be 100 characters or fewer. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the label. Emoji can be added to label names, using either native emoji or colon-style markup. For example, typing `:strawberry:` will render the emoji ![:strawberry:](https://github.githubassets.com/images/icons/emoji/unicode/1f353.png ":strawberry:"). For a full list of available emoji and codes, see "[Emoji cheat sheet](https://github.com/ikatyang/emoji-cheat-sheet)." Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="color" type="string">
  The [hexadecimal color code](http://www.color-hex.com/) for the label, without the leading `#`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="default" type="bool">
  Whether this label comes by default in a new repository. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="description" type="string">
  A short description of the label. Must be 100 characters or fewer. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="id" type="number">
  Unique identifier for the label. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="node_id" type="string">
  The label's GraphQL node ID. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="url" type="string">
  URL for the label Computed by GitHub after `ship`.
</ResponseField>

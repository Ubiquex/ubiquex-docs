`github_actions_hosted_runner` is a virtual machine GitHub provisions and maintains to run one Actions job -- Ubuntu, Windows, or macOS, with maintenance and OS upgrades handled automatically. Standard GitHub-hosted runners are free and unlimited on public repositories; private repositories consume the account's own included minutes, then bill per minute.

    	}))
    }

## Input properties

<ResponseField name="enable_static_ip" type="bool">
  Whether this runner should be created with a static public IP. Note limit on account. To list limits on account, use `GET actions/hosted-runners/limits` Optional.
</ResponseField>

<ResponseField name="hosted_runner_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="image" type="object" required>
  The image of runner. To list all available images, use `GET /actions/hosted-runners/images/github-owned` or `GET /actions/hosted-runners/images/partner`. Required.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The unique identifier of the runner image. Optional.
    </ResponseField>
    <ResponseField name="source" type="string">
      The source of the runner image. Optional.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of the runner image to deploy. This is relevant only for runners using custom images. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_gen" type="bool">
  Whether this runner should be used to generate custom images. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="maximum_runners" type="number">
  The maximum amount of runners to scale up to. Runners will not auto-scale above this number. Use this setting to limit your cost. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the runner. Must be between 1 and 64 characters and may only contain upper and lowercase letters a-z, numbers 0-9, '.', '-', and '_'. Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="runner_group_id" type="number" required>
  The existing runner group to add this runner to. Required.
</ResponseField>

<ResponseField name="size" type="string" required>
  The machine size of the runner. To list available sizes, use `GET actions/hosted-runners/machine-sizes` Required.
</ResponseField>

</ResponseField>

    </ResponseField>
    <ResponseField name="source" type="string" required>

    </ResponseField>
    <ResponseField name="version" type="string">

    </ResponseField>
  </Expandable>
</ResponseField>

    </ResponseField>
  </Expandable>

<ResponseField name="platform" type="string">
  The operating system of the image. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="public_ip_enabled" type="bool">
  Whether public IP is enabled for the hosted runners. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="public_ips" type="list(object)">
  The public IP ranges when public IP is enabled for the hosted runners. Computed by GitHub after `ship`.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">

    </ResponseField>
    <ResponseField name="length" type="number">
      The network prefix length in bits for the IP range assigned to this hosted runner. For instance, 28 represents a /28 subnet. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="prefix" type="string">
      The IP prefix in CIDR notation (e.g., '192.0.2.0/24') that defines a public IP range associated with the hosted runner. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  The status of the runner. Computed by GitHub after `ship`.
</ResponseField>

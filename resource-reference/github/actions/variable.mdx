`github_actions_variable` stores non-sensitive configuration -- a compiler flag, a hostname, anything safe to appear unmasked in a build log -- reused across workflows via the `vars` context. It's the deliberate counterpart to a secret: secrets are encrypted client-side before reaching GitHub and must be explicitly referenced to be read; variables carry no such protection because they were never meant to hold anything sensitive.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own variable"})

    		ubx.Resource(actions.Variable, "example", actions.VariableConfig{
    			Name:  "example",
    			Owner: "example",
    			Repo:  "example",
    			Value: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    import { Variable } from "@ubx/sdk-github/github/actions/variable";

    export default stack("example", () => {
      intent({ summary: "example own variable" });

      resource(Variable, "example", {
        name: "example",
        owner: "example",
        repo: "example",
        value: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.actions import Variable, VariableConfig

    def describe():
        ubx.intent("example own variable")

        ubx.resource(Variable, "example", VariableConfig(
            name="example",
            owner="example",
            repo="example",
            value="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Input properties

<ResponseField name="name" type="string" required>
  The name of the variable. Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="value" type="string" required>
  The value of the variable. Required.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time at which the variable was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time at which the variable was last updated, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

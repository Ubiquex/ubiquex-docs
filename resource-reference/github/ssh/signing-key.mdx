`github_ssh_signing_key` is an SSH key used to sign commits and tags rather than to authenticate -- functionally the same kind of key as one used for `git push`, and the same key can genuinely serve both roles, added here specifically as a signing key with no real limit on how many an account can have.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssh "github.com/ubiquex/ubx-sdk-github/sdk/go/github/ssh"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own signing key"})

    		ubx.Resource(ssh.SigningKey, "example", ssh.SigningKeyConfig{
    			Key:             "example",
    			SshSigningKeyId: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="key" type="string" required>
  The public SSH key to add to your GitHub account. For more information, see "[Checking for existing SSH keys](https://docs.github.com/enterprise-cloud@latest/authentication/connecting-to-github-with-ssh/checking-for-existing-ssh-keys)." Required.
</ResponseField>

<ResponseField name="ssh_signing_key_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="title" type="string">
  A descriptive name for the new key. Optional; if omitted, computed by GitHub.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">

</ResponseField>

<ResponseField name="id" type="number">
  The SSH signing key's numeric ID. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="title" type="string">
  A descriptive name for the new key. Optional; if omitted, computed by GitHub.
</ResponseField>

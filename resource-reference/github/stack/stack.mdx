`github_stack` records where one pull request sits inside a real stack -- a chain of smaller, dependent pull requests, each showing only its own layer's diff instead of one large change. Stacks merge from the bottom up, and any contiguous run of pull requests starting from the lowest unmerged one can be merged together at once.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	stack "github.com/ubiquex/ubx-sdk-github/sdk/go/github/stack"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stack"})

    		ubx.Resource(stack.Stack, "example", stack.StackConfig{
    			Owner:        "example",
    			PullRequests: []string{"example"},
    			Repo:         "example",
    			StackNumber:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="pull_requests" type="list(number)" required>
  An ordered list of pull request numbers forming the stack from bottom to top. Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="stack_number" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

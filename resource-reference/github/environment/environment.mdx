`github_environment` is a named deployment target -- staging, production -- that a workflow job references, and which can enforce real protection rules (required approvers, wait timers, branch restrictions) before the job is allowed to run or read that environment's own secrets.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	environment "github.com/ubiquex/ubx-sdk-github/sdk/go/github/environment"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment"})

    		ubx.Resource(environment.Environment, "example", environment.EnvironmentConfig{
    			EnvironmentName:   "example-environment-name",
    			Owner:             "example",
    			Repo:              "example",
    			PreventSelfReview: true,
    			Reviewers:         []map[string]any{{"id": 1}},
    			WaitTimer:         1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="deployment_branch_policy" type="object">
  The type of deployment branch policy for this environment. To allow all branches to deploy, set to `null`. Optional; if omitted, computed by GitHub.
  <Expandable title="properties">
    <ResponseField name="custom_branch_policies" type="bool" required>
      Whether only branches that match the specified name patterns can deploy to this environment. If `custom_branch_policies` is `true`, `protected_branches` must be `false`; if `custom_branch_policies` is `false`, `protected_branches` must be `true`. Required.
    </ResponseField>
    <ResponseField name="protected_branches" type="bool" required>
      Whether only branches with branch protection rules can deploy to this environment. If `protected_branches` is `true`, `custom_branch_policies` must be `false`; if `protected_branches` is `false`, `custom_branch_policies` must be `true`. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="environment_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="prevent_self_review" type="bool">
  Whether or not a user who created the job is prevented from approving their own job. Optional.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="reviewers" type="list(object)">
  The people or teams that may review jobs that reference the environment. You can list up to six users or teams as reviewers. The reviewers must have at least read access to the repository. Only one of the required reviewers needs to approve the job for it to proceed. Optional.
  <Expandable title="properties">
    <ResponseField name="id" type="number">
      The unique identifier of an environment reviewer. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of reviewer, either 'User' or 'Team'. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="wait_timer" type="number">
  The amount of time to delay a job after the job is initially triggered. The time (in minutes) must be an integer between 0 and 43,200 (30 days). Optional.
</ResponseField>

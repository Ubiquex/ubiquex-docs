`github_blob` is a raw git object holding one file's own content at a specific point in history, addressed by its own SHA rather than a filename or path -- the lowest-level building block a git tree assembles into a real directory structure.

## Example

    ```go
    package main

    import (
    	blob "github.com/ubiquex/ubx-sdk-github/sdk/go/github/blob"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own blob"})

    		ubx.Resource(blob.Blob, "example", blob.BlobConfig{
    			Content: "example",
    			FileSha: "example",
    			Owner:   "example",
    			Repo:    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="content" type="string" required>
  The new blob's content. Required.
</ResponseField>

<ResponseField name="encoding" type="string">
  The encoding used for `content`. Currently, `"utf-8"` and `"base64"` are supported. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="file_sha" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

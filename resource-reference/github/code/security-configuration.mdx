`github_code_security_configuration` bundles real security features -- Dependabot alerts, CodeQL code scanning, secret protection -- into one named, centrally-managed policy an organization can apply across many repositories at once, instead of enabling each feature repository by repository.

## Input properties

<ResponseField name="advanced_security" type="string">
  The enablement status of GitHub Advanced Security features. `enabled` will enable both Code Security and Secret Protection features. &gt; [!WARNING] &gt; `code_security` and `secret_protection` are deprecated values for this field. Prefer the individual `code_security` and `secret_protection` fields to set the status of these features. Optional; if omitted, computed by GitHub.
</ResponseField>

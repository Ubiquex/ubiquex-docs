`github_runner_groups_org` looks up a real, already-configured collection of self-hosted runners at the organization level, along with which repositories are allowed to use them.

## Example

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="visible_to_repository" type="string">
  Whether this runner group is visible to the whole repository rather than selected workflows only. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="runner_groups" type="list(object)">
  The real Actions runner groups included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

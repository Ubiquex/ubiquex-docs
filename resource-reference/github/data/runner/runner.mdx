title: "github_runner"

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	runner "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/runner"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_runner"})

    		ubx.Data(runner.Runner, "example", runner.RunnerConfig{
    			Enterprise:    "example",
    			RunnerGroupId: 1,
    			Page:          1,
    			PerPage:       1,
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx

    def describe():
        ubx.intent("look up github_runner")

            enterprise="example",

            page=1,
            per_page=1,

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="runner_group_id" type="number" required>
  The real, numeric ID of this Actions runner group. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="runners" type="list(object)">
  The real Actions runners included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

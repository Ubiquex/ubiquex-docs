`github_runner_groups_enterprise` looks up a real, already-configured named collection of self-hosted GitHub Actions runners managed at the enterprise level and shared across member organizations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	runner "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/runner"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_runner_groups_enterprise"})

    		ubx.Data(runner.GroupsEnterprise, "example", runner.GroupsEnterpriseConfig{
    			Enterprise:            "example",
    			Page:                  1,
    			PerPage:               1,
    			VisibleToOrganization: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="visible_to_organization" type="string">
  Whether this runner group is visible to the whole organization rather than selected repositories only. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="runner_groups" type="list(object)">
  The real Actions runner groups included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

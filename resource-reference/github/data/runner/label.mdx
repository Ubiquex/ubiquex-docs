---
title: "github_runner_label"
description: "`github_runner_label` looks up a real, custom label already attached to a self-hosted runner, used to target workflow jobs at it."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	runner "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/runner"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_runner_label"})

    		ubx.Data(runner.Label, "example", runner.LabelConfig{
    			Enterprise: "example",
    			RunnerId:   1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Label } from "@ubx/sdk-github/github/data/runner/label";

    export default stack("example", () => {
      intent({ summary: "look up github_runner_label" });

      data(Label, "example", {
        enterprise: "example",
        runnerId: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.runner import Label, LabelConfig

    def describe():
        ubx.intent("look up github_runner_label")

        ubx.data(Label, "example", LabelConfig(
            enterprise="example",
            runner_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="runner_id" type="number" required>
  The real, numeric ID of this Actions runner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="busy" type="bool">
  Whether this runner is currently executing a job. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="ephemeral" type="bool">
  Whether this runner is torn down automatically after running one job. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  The ID of the runner. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="list(object)">
  The real labels attached to this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the runner. Returned by the lookup.
</ResponseField>

<ResponseField name="os" type="string">
  The Operating System of the runner. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_group_id" type="number">
  The ID of the runner group. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the runner. Returned by the lookup.
</ResponseField>

<ResponseField name="version" type="string">
  The version of the GitHub Actions Runner software. This is only set if the runner has connected to the service at least once. Returned by the lookup.
</ResponseField>

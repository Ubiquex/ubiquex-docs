## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="total_seats_consumed" type="number">
  The real number of Copilot seats currently assigned. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_seats_purchased" type="number">
  The real number of Copilot seats this account has purchased. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="users" type="list(object)">
  The real user accounts included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

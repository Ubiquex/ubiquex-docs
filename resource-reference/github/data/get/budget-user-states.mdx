`github_get_budget_user_states` reads the real, current per-user notification state for an organization's budget alerts -- who's been notified and whose acknowledgment is still pending.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_get_budget_user_states"})

## Lookup arguments

<ResponseField name="budget_id" type="string" required>
  The real, unique identifier of this spending budget. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_order" type="string">
  The direction results are sorted in, ascending or descending. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="threshold_lower_bound" type="number">
  The real, lower spending threshold that triggers a budget alert. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="threshold_upper_bound" type="number">
  The real, upper spending threshold that triggers a budget alert. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="user" type="string">
  The real user account this result refers to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

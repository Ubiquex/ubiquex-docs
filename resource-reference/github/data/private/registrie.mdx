## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	private "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/private"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_private_registrie"})

    		ubx.Data(private.Registrie, "example", private.RegistrieConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only github --lang ts --out ./local-sdk
    import { Registrie } from "./local-sdk/github/sdk/typescript/github/data/private/registrie.ts";

    export default stack("example", () => {
      intent({ summary: "look up github_private_registrie" });

      data(Registrie, "example", {
        org: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.private import Registrie, RegistrieConfig

    def describe():
        ubx.intent("look up github_private_registrie")

        ubx.data(Registrie, "example", RegistrieConfig(
            org="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="key" type="string">
  The Base64 encoded public key. Returned by the lookup.
</ResponseField>

<ResponseField name="key_id" type="string">
  The identifier for the key. Returned by the lookup.
</ResponseField>

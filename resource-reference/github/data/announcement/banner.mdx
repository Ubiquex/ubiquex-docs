`github_announcement_banner` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	announcement "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/announcement"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_announcement_banner"})

    		ubx.Data(announcement.Banner, "example", announcement.BannerConfig{
    			Enterprise: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="announcement" type="string">
  The announcement text in GitHub Flavored Markdown. For more information about GitHub Flavored Markdown, see "[Basic writing and formatting syntax](https://docs.github.com/enterprise-cloud@latest/github/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)." Returned by the lookup.
</ResponseField>

<ResponseField name="expires_at" type="string">
  The time at which the announcement expires. This is a timestamp in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format: `YYYY-MM-DDTHH:MM:SSZ`. To set an announcement that never expires, omit this parameter, set it to `null`, or set it to an empty string. Returned by the lookup.
</ResponseField>

<ResponseField name="user_dismissible" type="bool">
  Whether an announcement can be dismissed by the user. Returned by the lookup.
</ResponseField>

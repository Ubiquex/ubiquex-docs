## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	group "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/group"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_group_mapping"})

    		ubx.Data(group.Mapping, "example", group.MappingConfig{
    			Org:     "example",
    			Page:    "example",
    			PerPage: 1,
    			Q:       "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="string">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="q" type="string">
  The real search query string. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="groups" type="list(object)">
  Array of groups to be mapped to this team Returned by the lookup.
</ResponseField>

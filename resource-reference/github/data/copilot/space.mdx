`github_copilot_space` looks up a real, already-created Copilot Space -- the organized context of repositories, code, pull requests, issues, and notes that grounds Copilot's own answers for a specific project or task.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	copilot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/copilot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_copilot_space"})

    		ubx.Data(copilot.Space, "example", copilot.SpaceConfig{
    			Org:         "example",
    			SpaceNumber: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Space } from "@ubx/sdk-github/github/data/copilot/space";

    export default stack("example", () => {
      intent({ summary: "look up github_copilot_space" });

      data(Space, "example", {
        org: "example",
        spaceNumber: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.copilot import Space, SpaceConfig

    def describe():
        ubx.intent("look up github_copilot_space")

        ubx.data(Space, "example", SpaceConfig(
            org="example",
            space_number=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="space_number" type="number" required>
  Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="collaborators" type="list(any)">
  The list of collaborators for this Copilot Space. Returned by the lookup.
</ResponseField>

`github_copilot_space` looks up a real, already-created Copilot Space -- the organized context of repositories, code, pull requests, issues, and notes that grounds Copilot's own answers for a specific project or task.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	copilot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/copilot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_copilot_space"})

    		ubx.Data(copilot.Space, "example", copilot.SpaceConfig{
    			Org:     "example",
    			After:   "example",
    			Before:  "example",
    			PerPage: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="after" type="string">
  Only return results after this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before" type="string">
  Only return results before this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="spaces" type="list(object)">
  The list of Copilot Spaces on this page of results. Returned by the lookup.
</ResponseField>

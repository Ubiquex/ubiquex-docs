## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	copilot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/copilot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_copilot"})

    		ubx.Data(copilot.Copilot, "example", copilot.CopilotConfig{
    			Enterprise: "example",
    			Page:       1,
    			PerPage:    1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.copilot import Copilot, CopilotConfig

    def describe():
        ubx.intent("look up github_copilot")

        ubx.data(Copilot, "example", CopilotConfig(
            enterprise="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="custom_agents" type="list(object)">
  List of custom agents defined in the repository. Returns `null` if no source repository is configured. Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="cli" type="string">
  The organization policy for allowing or disallowing Copilot CLI. Returned by the lookup.
</ResponseField>

<ResponseField name="ide_chat" type="string">
  The organization policy for allowing or disallowing Copilot Chat in the IDE. Returned by the lookup.
</ResponseField>

<ResponseField name="plan_type" type="string">
  The Copilot plan of the organization, or the parent enterprise, when applicable. Returned by the lookup.
</ResponseField>

<ResponseField name="platform_chat" type="string">
  The organization policy for allowing or disallowing Copilot features on GitHub.com. Returned by the lookup.
</ResponseField>

<ResponseField name="public_code_suggestions" type="string">
  The organization policy for allowing or blocking suggestions matching public code (duplication detection filter). Returned by the lookup.
</ResponseField>

<ResponseField name="seat_breakdown" type="object">
  The breakdown of Copilot Business seats for the organization. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="active_this_cycle" type="number">
      The number of seats that have used Copilot during the current billing cycle. Optional lookup argument.
    </ResponseField>
    <ResponseField name="added_this_cycle" type="number">
      Seats added during the current billing cycle. Optional lookup argument.
    </ResponseField>
    <ResponseField name="inactive_this_cycle" type="number">
      The number of seats that have not used Copilot during the current billing cycle. Optional lookup argument.
    </ResponseField>
    <ResponseField name="pending_cancellation" type="number">
      The number of seats that are pending cancellation at the end of the current billing cycle. Optional lookup argument.
    </ResponseField>
    <ResponseField name="pending_invitation" type="number">
      The number of users who have been invited to receive a Copilot seat through this organization. Optional lookup argument.
    </ResponseField>
    <ResponseField name="total" type="number">
      The total number of seats being billed for the organization as of the current billing cycle. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="seat_management_setting" type="string">
  The mode of assigning new seats. Returned by the lookup.
</ResponseField>

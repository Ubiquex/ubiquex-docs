`github_copilot_space_resource` looks up one real, already-added piece of content -- a repository, a file, a pull request, a note -- inside a Copilot Space.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	copilot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/copilot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_copilot_space_resource"})

    		ubx.Data(copilot.SpaceResource, "example", copilot.SpaceResourceConfig{
    			Org:         "example",
    			SpaceNumber: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SpaceResource } from "@ubx/sdk-github/github/data/copilot/space_resource";

    export default stack("example", () => {
      intent({ summary: "look up github_copilot_space_resource" });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.copilot import SpaceResource, SpaceResourceConfig

    def describe():
        ubx.intent("look up github_copilot_space_resource")

        ubx.data(SpaceResource, "example", SpaceResourceConfig(
            org="example",
            space_number=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="space_number" type="number" required>
  The real, unique number identifying this Copilot Space. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="resources" type="list(object)">
  The list of resources attached to this Copilot Space. Returned by the lookup.
</ResponseField>

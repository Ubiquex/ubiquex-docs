## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="seats" type="list(object)">
  The real, assigned Copilot seats included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_seats" type="number">
  The total number of Copilot seats the enterprise is being billed for. Users with access through multiple organizations or enterprise teams are only counted once. Returned by the lookup.
</ResponseField>

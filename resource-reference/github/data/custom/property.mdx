## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	custom "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/custom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_custom_property"})

    		ubx.Data(custom.Property, "example", custom.PropertyConfig{
    			CustomPropertyName: "example-custom-property-name",
    			Org:                "example",
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx

    def describe():
        ubx.intent("look up github_custom_property")

            custom_property_name="example-custom-property-name",

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="custom_property_name" type="string" required>
  The real name of this custom property definition. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="allowed_values" type="list(string)">
  An ordered list of the allowed values of the property. The property can have up to 200 allowed values. Returned by the lookup.
</ResponseField>

<ResponseField name="default_value" type="any">
  Default value of the property Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Short description of the property Returned by the lookup.
</ResponseField>

<ResponseField name="property_name" type="string">
  The name of the property Returned by the lookup.
</ResponseField>

<ResponseField name="require_explicit_values" type="bool">
  Whether setting properties values is mandatory Returned by the lookup.
</ResponseField>

<ResponseField name="required" type="bool">
  Whether the property is required. Returned by the lookup.
</ResponseField>

<ResponseField name="source_type" type="string">
  The source type of the property Returned by the lookup.
</ResponseField>

<ResponseField name="url" type="string">
  The URL that can be used to fetch, update, or delete info about this property via the API. Returned by the lookup.
</ResponseField>

<ResponseField name="value_type" type="string">
  The type of the value for the property Returned by the lookup.
</ResponseField>

<ResponseField name="values_editable_by" type="string">
  Who can edit the values of the property Returned by the lookup.
</ResponseField>

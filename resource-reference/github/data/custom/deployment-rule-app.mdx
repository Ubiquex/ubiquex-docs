`github_custom_deployment_rule_app` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    import (
    	custom "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/custom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_custom_deployment_rule_app"})

    		ubx.Data(custom.DeploymentRuleApp, "example", custom.DeploymentRuleAppConfig{
    			EnvironmentName: "example-environment-name",
    			Owner:           "example",
    			Repo:            "example",
    			Page:            1,
    			PerPage:         1,
    		})
    	}))
    }
    ```

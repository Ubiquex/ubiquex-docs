`github_codespaces_permissions_check_for_devcontainer` reads whether a user has already granted the extra permissions a repository's own devcontainer configuration requests, before a Codespace using it can be created.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codespaces "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/codespaces"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_codespaces_permissions_check_for_devcontainer"})

    		ubx.Data(codespaces.PermissionsCheckForDevcontainer, "example", codespaces.PermissionsCheckForDevcontainerConfig{
    			DevcontainerPath: "example",
    			Owner:            "example",
    			Ref:              "example",
    			Repo:             "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="devcontainer_path" type="string" required>
  The real path to the devcontainer configuration file this Codespace was created from. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ref" type="string" required>
  The real git reference (a branch or tag name) this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="accepted" type="bool">
  Whether the user has accepted the permissions defined by the devcontainer config Returned by the lookup.
</ResponseField>

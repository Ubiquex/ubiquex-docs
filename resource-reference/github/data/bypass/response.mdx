`github_bypass_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	bypass "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/bypass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_bypass_response"})

    		ubx.Data(bypass.Response, "example", bypass.ResponseConfig{
    			BypassRequestNumber: 1,
    			Owner:               "example",
    			Repo:                "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="created_at" type="string">
  The date and time the bypass request was created. Returned by the lookup.
</ResponseField>

<ResponseField name="data" type="list(object)">
  Data describing the push rules that are being requested to be bypassed. Returned by the lookup.
</ResponseField>

<ResponseField name="expires_at" type="string">
  The date and time the bypass request will expire. Returned by the lookup.
</ResponseField>

<ResponseField name="html_url" type="string">
  The URL to view the bypass request in a browser. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  The unique identifier of the bypass request. Returned by the lookup.
</ResponseField>

<ResponseField name="number" type="number">
  The number uniquely identifying the bypass request within its repository. Returned by the lookup.
</ResponseField>

---
title: "github_restriction"
description: "`github_restriction` reads a protected branch's own current push restrictions -- which users, teams, or apps are allowed to push directly."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	restriction "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/restriction"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_restriction"})

    		ubx.Data(restriction.Restriction, "example", restriction.RestrictionConfig{
    			Branch: "example",
    			Owner:  "example",
    			Repo:   "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.github.data.restriction import Restriction, RestrictionConfig

    def describe():

        ubx.data(Restriction, "example", RestrictionConfig(
            branch="example",

            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="branch" type="string" required>
  The real branch name this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

`github_license_content` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	license "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/license"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_license_content"})

    		ubx.Data(license.Content, "example", license.ContentConfig{
    			Owner: "example",
    			Repo:  "example",
    			Ref:   "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Content } from "@ubx/sdk-github/github/data/license/content";

    export default stack("example", () => {
      intent({ summary: "look up github_license_content" });

      data(Content, "example", {

        ref: "example",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.license import Content, ContentConfig

    def describe():

            owner="example",
            repo="example",
            ref="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

<ResponseField name="ref" type="string">
  The Git reference, formatted as `refs/pull/&lt;number&gt;/merge`, `refs/pull/&lt;number&gt;/head`, `refs/heads/&lt;branch name&gt;` or simply `&lt;branch name&gt;`. Optional lookup argument.

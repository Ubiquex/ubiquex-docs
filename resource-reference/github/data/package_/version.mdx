## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	package_ "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/package_"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_package_version"})

    		ubx.Data(package_.Version, "example", package_.VersionConfig{
    			Org:              "example",
    			PackageName:      "example-package-name",
    			PackageType:      "example",
    			PackageVersionId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.package_ import Version, VersionConfig

    def describe():
        ubx.intent("look up github_package_version")

        ubx.data(Version, "example", VersionConfig(
            org="example",
            package_name="example-package-name",
            package_type="example",
            package_version_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="package_name" type="string" required>
  The real name of the package. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="package_type" type="string" required>
  The real type of package registry this package is published to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="package_version_id" type="number" required>
  The real, numeric ID of this package version. **(AI-inferred)** Required lookup argument.
</ResponseField>

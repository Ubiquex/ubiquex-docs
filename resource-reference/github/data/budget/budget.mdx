## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	budget "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/budget"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_budget"})

    		ubx.Data(budget.Budget, "example", budget.BudgetConfig{
    			Enterprise: "example",
    			Page:       1,
    			PerPage:    1,
    			Scope:      "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="scope" type="string">
  The real scope this setting, permission, or token applies to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="budgets" type="list(object)">
  Array of budget objects for the enterprise Returned by the lookup.
</ResponseField>

<ResponseField name="effective_budget" type="object">
  Effective user-level budget details returned when the response is scoped with the `user` query parameter. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="budget_amount" type="number" required>
      The budget amount for the effective budget. Required lookup argument.
    </ResponseField>
    <ResponseField name="consumed_amount" type="number" required>
      The consumed amount for the specified user within the effective budget. Required lookup argument.
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the effective budget. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="has_next_page" type="bool">
  Indicates if there are more pages of results available (maps to hasNextPage from billing platform) Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  Total number of budgets matching the query Returned by the lookup.
</ResponseField>

<ResponseField name="user" type="string">
  The real user account this result refers to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="include_claim_keys" type="list(string)">
  Array of unique strings. Each claim key can only contain alphanumeric characters and underscores. Returned by the lookup.
</ResponseField>

<ResponseField name="sub_claim_prefix" type="string">
  The current `sub` claim prefix for this repository. Returned by the lookup.
</ResponseField>

<ResponseField name="use_default" type="bool">
  Whether to use the default template or not. If `true`, the `include_claim_keys` field is ignored. Returned by the lookup.
</ResponseField>

<ResponseField name="use_immutable_subject" type="bool">
  Whether the repository has opted in to the immutable OIDC subject claim format. When `true`, OIDC tokens will use a stable, repository-ID-based `sub` claim. If not set at the repository level, falls back to the organization-level setting. Returned by the lookup.
</ResponseField>

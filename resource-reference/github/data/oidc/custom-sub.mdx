    		})

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="include_claim_keys" type="list(string)">
  Array of unique strings. Each claim key can only contain alphanumeric characters and underscores. Returned by the lookup.
</ResponseField>

<ResponseField name="use_immutable_subject" type="bool">
  Whether to opt in to the immutable OIDC subject claim format for the organization. When `true`, new OIDC tokens will use a stable, repository-ID-based `sub` claim instead of the name-based format. Returned by the lookup.
</ResponseField>

`github_oidc_custom_sub` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	oidc "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/oidc"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_oidc_custom_sub"})

    		ubx.Data(oidc.CustomSub, "example", oidc.CustomSubConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>

  Required lookup argument.

## Result properties

<ResponseField name="include_claim_keys" type="list(string)">
  Array of unique strings. Each claim key can only contain alphanumeric characters and underscores. Returned by the lookup.
</ResponseField>

<ResponseField name="use_immutable_subject" type="bool">
  Whether to opt in to the immutable OIDC subject claim format for the organization. When `true`, new OIDC tokens will use a stable, repository-ID-based `sub` claim instead of the name-based format. Returned by the lookup.
</ResponseField>

---
title: "github_codeql"
description: "`github_codeql` looks up a real CodeQL analysis result or configuration for a repository's own code scanning setup."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codeql "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/codeql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_codeql"})

    		ubx.Data(codeql.Codeql, "example", codeql.CodeqlConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Codeql } from "@ubx/sdk-github/github/data/codeql/codeql";

    export default stack("example", () => {
      intent({ summary: "look up github_codeql" });

      data(Codeql, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.codeql import Codeql, CodeqlConfig

    def describe():
        ubx.intent("look up github_codeql")

        ubx.data(Codeql, "example", CodeqlConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

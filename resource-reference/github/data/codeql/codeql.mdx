title: "github_codeql"

---

`github_codeql` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codeql "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/codeql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_codeql"})

    		ubx.Data(codeql.Codeql, "example", codeql.CodeqlConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Codeql } from "@ubx/sdk-github/github/data/codeql/codeql";

    export default stack("example", () => {
      intent({ summary: "look up github_codeql" });

      data(Codeql, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.codeql import Codeql, CodeqlConfig

    def describe():
        ubx.intent("look up github_codeql")

        ubx.data(Codeql, "example", CodeqlConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

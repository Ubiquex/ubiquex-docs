---
title: "github_feed"
description: "`github_feed` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_feed` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	feed "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/feed"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_feed"})

    		ubx.Data(feed.Feed, "example", feed.FeedConfig{})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Feed } from "@ubx/sdk-github/github/data/feed/feed";

    export default stack("example", () => {
      intent({ summary: "look up github_feed" });

      data(Feed, "example", {});
    });
    ```
  </Tab>
  <Tab title="Python">

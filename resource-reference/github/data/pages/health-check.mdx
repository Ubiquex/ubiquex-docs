title: "github_pages_health_check"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pages "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/pages"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_pages_health_check"})

    		ubx.Data(pages.HealthCheck, "example", pages.HealthCheckConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { HealthCheck } from "@ubx/sdk-github/github/data/pages/health_check";

    export default stack("example", () => {
      intent({ summary: "look up github_pages_health_check" });

      data(HealthCheck, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.pages import HealthCheck, HealthCheckConfig

    def describe():
        ubx.intent("look up github_pages_health_check")

        ubx.data(HealthCheck, "example", HealthCheckConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

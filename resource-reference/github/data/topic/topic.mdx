---
title: "github_topic"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	topic "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/topic"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_topic"})

    		ubx.Data(topic.Topic, "example", topic.TopicConfig{
    			Owner:   "example",
    			Repo:    "example",
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

      data(Topic, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.topic import Topic, TopicConfig

    def describe():
        ubx.intent("look up github_topic")

        ubx.data(Topic, "example", TopicConfig(
            owner="example",
            repo="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="names" type="list(string)">
  The real, given names of the objects in this list. **(AI-inferred)** Returned by the lookup.
</ResponseField>

`github_milestone` looks up a real, already-created grouping of issues or pull requests toward one shared target, with its own due date and completion percentage.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	milestone "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/milestone"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_milestone"})

    		ubx.Data(milestone.Milestone, "example", milestone.MilestoneConfig{
    			MilestoneNumber: 1,
    			Owner:           "example",
    			Repo:            "example",
    			Page:            1,
    			PerPage:         1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="milestone_number" type="number" required>
  The real, repository-scoped number identifying this milestone. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

`github_artifact_deployment_record` looks up the real deployment record GitHub Enterprise Importer created while migrating a repository's own release artifacts.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	artifact "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/artifact"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_artifact_deployment_record"})

    		ubx.Data(artifact.DeploymentRecord, "example", artifact.DeploymentRecordConfig{
    			Org:           "example",
    			SubjectDigest: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subject_digest" type="string" required>
  The real cryptographic digest of the artifact this attestation is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="deployment_records" type="list(object)">
  The real deployment records matching this query. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The number of deployment records for this digest and organization Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="client_ip" type="string">
  The real client IP address that requested this GitHub-hosted runner. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="location" type="string">
  The real, physical or logical location associated with this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ref" type="string">
  The real git reference (a branch or tag name) this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="machines" type="list(object)">
  The real hardware machine specs available for this GitHub-hosted runner. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

`github_codespace` looks up a real, already-running or stopped cloud-hosted development environment, running in a Docker container, reachable from a browser, VS Code, or the GitHub CLI.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	codespace "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/codespace"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_codespace"})

    		ubx.Data(codespace.Codespace, "example", codespace.CodespaceConfig{
    			Org:     "example",
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.codespace import Codespace, CodespaceConfig

    def describe():
        ubx.intent("look up github_codespace")

        ubx.data(Codespace, "example", CodespaceConfig(
            org="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="codespaces" type="list(object)">
  Whether the Codespaces service is currently operating normally, from GitHub's own status API, or the real Codespaces included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

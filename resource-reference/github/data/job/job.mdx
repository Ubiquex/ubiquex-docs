`github_job` looks up a real, already-run or in-progress unit of work within an Actions workflow run -- a set of steps executed together on the same runner.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	job "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/job"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_job"})

    		ubx.Data(job.Job, "example", job.JobConfig{
    			JobId: 1,
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk

    import ubx_sdk as ubx
    from ubx.github.data.job import Job, JobConfig

    def describe():
        ubx.intent("look up github_job")

        ubx.data(Job, "example", JobConfig(
            job_id=1,
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="job_id" type="number" required>
  The real, numeric ID of this Actions workflow job. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

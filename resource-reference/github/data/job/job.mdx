`github_job` looks up a real, already-run or in-progress unit of work within an Actions workflow run -- a set of steps executed together on the same runner.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	job "github.com/ubiquex/ubx-sdk-github/sdk/go/github/job"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own job"})

    		ubx.Resource(job.Job, "example", job.JobConfig{
    			Cluster:             "example",
    			Deployments:         []map[string]any{{"name": "example-name"}},
    			LogicalEnvironment:  "example",
    			Org:                 "example",
    			PhysicalEnvironment: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.job import Job, JobConfig
    from ubx.github.job.job import Job_Deployments

    def describe():
        ubx.intent("example own job")

        ubx.resource(Job, "example", JobConfig(
            cluster="example",
            deployments=[Job_Deployments(name="example-name")],
            logical_environment="example",
            org="example",
            physical_environment="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="job_id" type="number" required>
  The real, numeric ID of this Actions workflow job. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

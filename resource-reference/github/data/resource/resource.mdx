title: "github_resource"
description: "`github_resource` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_resource` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resource "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/resource"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_resource"})

    		ubx.Data(resource.Resource, "example", resource.ResourceConfig{
    			Affects:        "example",
    			After:          "example",
    			Before:         "example",
    			CveId:          "example",
    			Cwes:           "example",
    			Direction:      "example",
    			Ecosystem:      "example",
    			EpssPercentage: "example",
    		})
    	}))
    }
    ```

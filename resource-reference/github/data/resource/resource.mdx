## Lookup arguments

<ResponseField name="affects" type="any">
  The real package versions this security advisory affects. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="after" type="string">
  Only return results after this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before" type="string">
  Only return results before this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="cve_id" type="string">
  The real, published CVE identifier for this vulnerability, if one was assigned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="cwes" type="any">
  The real CWE (Common Weakness Enumeration) identifiers classifying this vulnerability. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="direction" type="string">
  The sort direction, asc or desc. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ecosystem" type="string">
  The package's language or package management ecosystem. Optional lookup argument.
</ResponseField>

<ResponseField name="epss_percentage" type="string">
  The real EPSS (Exploit Prediction Scoring System) probability score for this vulnerability. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="epss_percentile" type="string">
  The real EPSS percentile rank for this vulnerability relative to all scored vulnerabilities. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ghsa_id" type="string">
  The real GitHub Security Advisory identifier. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="is_withdrawn" type="bool">
  Whether this security advisory has since been withdrawn. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="modified" type="string">
  The real timestamp this security advisory was last modified. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="published" type="string">
  The real timestamp this object was published. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="severity" type="string">
  The real, assigned severity level of this finding. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string">
  The real, discriminating type of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="updated" type="string">
  The real timestamp this object was last updated. **(AI-inferred)** Optional lookup argument.
</ResponseField>

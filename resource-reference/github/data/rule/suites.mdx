## Lookup arguments

<ResponseField name="actor_name" type="string">
  The real login of the actor evaluated against this ruleset. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="evaluate_status" type="string">
  The real outcome of evaluating this ruleset against the push -- pass, fail, or bypass. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ref" type="string">
  The real git reference (a branch or tag name) this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string">
  The real name of the repository this result belongs to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="rule_suite_result" type="string">
  The real, overall pass/fail result of this ruleset evaluation run. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="time_period" type="string">
  The real time window the returned statistics are aggregated over. **(AI-inferred)** Optional lookup argument.
</ResponseField>

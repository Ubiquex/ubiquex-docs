## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	rule "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/rule"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_rule_suite"})

    		ubx.Data(rule.Suite, "example", rule.SuiteConfig{
    			Org:         "example",
    			RuleSuiteId: 1,
    		})
    	}))
    }
    ```

    ```python
    def describe():
        ubx.intent("look up github_rule_suite")

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="rule_suite_id" type="number" required>
  The real, numeric ID of this ruleset evaluation run. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="actor_id" type="number">
  The number that identifies the user. Returned by the lookup.
</ResponseField>

<ResponseField name="actor_name" type="string">
  The handle for the GitHub user account. Returned by the lookup.
</ResponseField>

<ResponseField name="after_sha" type="string">
  The new commit SHA of the ref. Returned by the lookup.
</ResponseField>

<ResponseField name="before_sha" type="string">
  The previous commit SHA of the ref. Returned by the lookup.
</ResponseField>

<ResponseField name="evaluation_result" type="string">
  The result of the rule evaluations for rules with the `active` and `evaluate` enforcement statuses, demonstrating whether rules would pass or fail if all rules in the rule suite were `active`. Null if no rules with `evaluate` enforcement status were run. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  The unique identifier of the rule insight. Returned by the lookup.
</ResponseField>

<ResponseField name="pushed_at" type="string">
  The real timestamp of the most recent push to this repository. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="ref" type="string">
  The ref name that the evaluation ran on. Returned by the lookup.
</ResponseField>

<ResponseField name="repository_id" type="number">
  The ID of the repository associated with the rule evaluation. Returned by the lookup.
</ResponseField>

<ResponseField name="repository_name" type="string">
  The name of the repository without the `.git` extension. Returned by the lookup.
</ResponseField>

<ResponseField name="result" type="string">
  The result of the rule evaluations for rules with the `active` enforcement status. Returned by the lookup.
</ResponseField>

<ResponseField name="rule_evaluations" type="list(object)">
  Details on the evaluated rules. Returned by the lookup.
</ResponseField>

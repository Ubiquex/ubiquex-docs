`github_scim_user` looks up a real, SCIM-provisioned organization member, synced by the organization's own connected identity provider rather than an enterprise-wide one.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	scim "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/scim"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_scim_user"})

    		ubx.Data(scim.User, "example", scim.UserConfig{
    			Org:    "example",
    			Count:  1,
    			Filter: "example",
    		})
    	}))
    }
    ```

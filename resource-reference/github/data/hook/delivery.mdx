---
title: "github_hook_delivery"
description: "`github_hook_delivery` looks up one real, already-attempted webhook delivery -- its own request and response payloads, and whether it succeeded."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	hook "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/hook"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_hook_delivery"})

    		ubx.Data(hook.Delivery, "example", hook.DeliveryConfig{
    			DeliveryId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Delivery } from "@ubx/sdk-github/github/data/hook/delivery";

    export default stack("example", () => {
      intent({ summary: "look up github_hook_delivery" });

      data(Delivery, "example", {
        deliveryId: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.hook import Delivery, DeliveryConfig

    def describe():
        ubx.intent("look up github_hook_delivery")

        ubx.data(Delivery, "example", DeliveryConfig(
            delivery_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="delivery_id" type="number" required>
  The real, numeric ID of this webhook delivery attempt. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="action" type="string">
  The type of activity for the event that triggered the delivery. Returned by the lookup.
</ResponseField>

<ResponseField name="delivered_at" type="string">
  Time when the delivery was delivered. Returned by the lookup.
</ResponseField>

<ResponseField name="duration" type="number">
  Time spent delivering. Returned by the lookup.
</ResponseField>

<ResponseField name="event" type="string">
  The event that triggered the delivery. Returned by the lookup.
</ResponseField>

<ResponseField name="guid" type="string">
  Unique identifier for the event (shared with all deliveries for all webhooks that subscribe to this event). Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  Unique identifier of the delivery. Returned by the lookup.
</ResponseField>

<ResponseField name="installation_id" type="number">
  The id of the GitHub App installation associated with this event. Returned by the lookup.
</ResponseField>

<ResponseField name="redelivery" type="bool">
  Whether the delivery is a redelivery. Returned by the lookup.
</ResponseField>

<ResponseField name="repository_id" type="number">
  The id of the repository associated with this event. Returned by the lookup.
</ResponseField>

<ResponseField name="request" type="object">
  The real HTTP request payload sent for this webhook delivery. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="headers" type="any" required>
      The request headers sent with the webhook delivery. Required lookup argument.
    </ResponseField>
    <ResponseField name="payload" type="any" required>
      The webhook payload. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="response" type="object">
  The real HTTP response payload received for this webhook delivery. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="headers" type="any" required>
      The response headers received when the delivery was made. Required lookup argument.
    </ResponseField>
    <ResponseField name="payload" type="string" required>
      The response payload received. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  Description of the status of the attempted delivery Returned by the lookup.
</ResponseField>

<ResponseField name="status_code" type="number">
  Status code received when delivery was made. Returned by the lookup.
</ResponseField>

<ResponseField name="throttled_at" type="string">
  Time when the webhook delivery was throttled. Returned by the lookup.
</ResponseField>

<ResponseField name="url" type="string">
  The URL target of the delivery. Returned by the lookup.
</ResponseField>

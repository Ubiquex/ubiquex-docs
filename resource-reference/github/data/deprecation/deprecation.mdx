`github_deprecation` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	deprecation "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/deprecation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_deprecation"})

    		ubx.Data(deprecation.Deprecation, "example", deprecation.DeprecationConfig{
    			Enterprise: "example",
    			Version:    "example",
    		})
    	}))
    }
    ```
  </Tab>

## Result properties

<ResponseField name="registration_deprecates_at" type="string">
  The date after which this runner version can no longer register. Null if no schedule is set. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_version" type="string">
  The runner version string. Returned by the lookup.
</ResponseField>

<ResponseField name="runtime_deprecates_at" type="string">
  The date after which jobs will no longer be dispatched to runners on this version. Returned by the lookup.
</ResponseField>

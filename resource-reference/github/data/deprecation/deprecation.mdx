## Example

    package main

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_deprecation"})

    		ubx.Data(deprecation.Deprecation, "example", deprecation.DeprecationConfig{
    			Enterprise: "example",
    			Version:    "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="version" type="string" required>
  The real version identifier for this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="registration_deprecates_at" type="string">
  The date after which this runner version can no longer register. Null if no schedule is set. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_version" type="string">
  The runner version string. Returned by the lookup.
</ResponseField>

<ResponseField name="runtime_deprecates_at" type="string">
  The date after which jobs will no longer be dispatched to runners on this version. Returned by the lookup.
</ResponseField>

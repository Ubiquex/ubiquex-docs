## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	stargazer "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/stargazer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_stargazer"})

    		ubx.Data(stargazer.Stargazer, "example", stargazer.StargazerConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Stargazer } from "@ubx/sdk-github/github/data/stargazer/stargazer";

    export default stack("example", () => {
      intent({ summary: "look up github_stargazer" });

      data(Stargazer, "example", {
        owner: "example",
        repo: "example",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.stargazer import Stargazer, StargazerConfig

    def describe():
        ubx.intent("look up github_stargazer")

        ubx.data(Stargazer, "example", StargazerConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="count" type="number">
  The total number of matching items. **(AI-inferred)** Returned by the lookup.
</ResponseField>

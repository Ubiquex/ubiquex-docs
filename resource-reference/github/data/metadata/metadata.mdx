---
title: "github_metadata"
description: "`github_metadata` reads real, stored metadata associated with a dependency graph submission, such as build tool provenance."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	metadata "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/metadata"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_metadata"})

    		ubx.Data(metadata.Metadata, "example", metadata.MetadataConfig{
    			Org:           "example",
    			SubjectDigest: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

      data(Metadata, "example", {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.metadata import Metadata, MetadataConfig

    def describe():
        ubx.intent("look up github_metadata")

        ubx.data(Metadata, "example", MetadataConfig(
            org="example",
            subject_digest="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subject_digest" type="string" required>
  The real cryptographic digest of the artifact this attestation is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="deployment_records" type="list(object)">
  Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The number of deployment records for this digest and organization Returned by the lookup.
</ResponseField>

---
title: "github_metadata"
description: "`github_metadata` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_metadata` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	metadata "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/metadata"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_metadata"})

    		ubx.Data(metadata.Metadata, "example", metadata.MetadataConfig{
    			Org:           "example",
    			SubjectDigest: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Metadata } from "@ubx/sdk-github/github/data/metadata/metadata";

    export default stack("example", () => {
      intent({ summary: "look up github_metadata" });

      data(Metadata, "example", {
        org: "example",
        subjectDigest: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.metadata import Metadata, MetadataConfig

    def describe():
        ubx.intent("look up github_metadata")

        ubx.data(Metadata, "example", MetadataConfig(
            org="example",
            subject_digest="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

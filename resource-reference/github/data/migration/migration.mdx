`github_migration` looks up a real, in-progress or completed transfer of repository or organization data into GitHub Enterprise Cloud via GitHub Enterprise Importer.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	migration "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/migration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_migration"})

    		ubx.Data(migration.Migration, "example", migration.MigrationConfig{
    			MigrationId: 1,
    			Org:         "example",
    			Page:        1,
    			PerPage:     1,
    		})
    	}))
    }
    ```

`github_installation` looks up a real, live installation of a GitHub App on a user account, organization, or enterprise -- which repositories it can see and which permissions it was granted.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	installation "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/installation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_installation"})

    		ubx.Data(installation.Installation, "example", installation.InstallationConfig{
    			Enterprise:     "example",
    			InstallationId: 1,
    			Org:            "example",
    			Page:           1,
    			PerPage:        1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="installation_id" type="number" required>
  The real, numeric ID of this GitHub App installation. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

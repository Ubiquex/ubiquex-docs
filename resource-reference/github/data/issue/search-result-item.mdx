    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			AdvancedSearch: "example",
    			Order:          "example",
    			Page:           1,
    			PerPage:        1,
    			Sort:           "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="advanced_search" type="string">
  Whether this search used GitHub's own advanced search syntax. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="order" type="string">
  The sort direction, asc or desc. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="q" type="string" required>
  The real search query string. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="incomplete_results" type="bool">
  Whether the search timed out before scanning every possible match, making the result set incomplete. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="items" type="list(object)">
  The list of results for this page of the response. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="lexical_fallback_reason" type="list(string)">
  When a semantic or hybrid search falls back to lexical search, this field contains the reasons for the fallback. Only present when a fallback occurred. Returned by the lookup.
</ResponseField>

<ResponseField name="search_type" type="string">
  Which real GitHub search this query ran against. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

`github_org_private_registry_configuration` looks up the real, already-stored credentials an organization's own Actions workflows use to pull from a private package registry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	org "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/org"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_org_private_registry_configuration"})

    		ubx.Data(org.PrivateRegistryConfiguration, "example", org.PrivateRegistryConfigurationConfig{
    			Org:     "example",
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```

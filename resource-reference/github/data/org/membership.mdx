---
title: "github_org_membership"
description: "`github_org_membership` looks up one real user's own already-established role inside an organization -- `admin` or `member`."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	org "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/org"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_org_membership"})

    		ubx.Data(org.Membership, "example", org.MembershipConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

      data(Membership, "example", {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.org import Membership, MembershipConfig

    def describe():
        ubx.intent("look up github_org_membership")

        ubx.data(Membership, "example", MembershipConfig(
            org="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="direct_membership" type="bool">
  Whether the user has direct membership in the organization. Returned by the lookup.
</ResponseField>

<ResponseField name="enterprise_teams_providing_indirect_membership" type="list(string)">

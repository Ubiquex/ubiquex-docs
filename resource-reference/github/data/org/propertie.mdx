`github_org_propertie` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    package main

    import (
    	org "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/org"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_org_propertie"})

    		ubx.Data(org.Propertie, "example", org.PropertieConfig{
    			Enterprise: "example",
    		})
    	}))
    }

`github_clone_traffic` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	clone "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/clone"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_clone_traffic"})

    		ubx.Data(clone.Traffic, "example", clone.TrafficConfig{
    			Owner: "example",
    			Repo:  "example",
    			Per:   "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

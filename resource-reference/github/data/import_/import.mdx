---
title: "github_import"
description: "`github_import` looks up a real, in-progress or completed repository import from an external version control system."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	import_ "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/import_"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_import"})

    		ubx.Data(import_.Import, "example", import_.ImportConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only github --lang ts --out ./local-sdk
    import { Import } from "./local-sdk/github/sdk/typescript/github/data/import_/import.ts";

    export default stack("example", () => {
      intent({ summary: "look up github_import" });

      data(Import, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.import_ import Import, ImportConfig

    def describe():
        ubx.intent("look up github_import")

        ubx.data(Import, "example", ImportConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="authors_count" type="number">
  The real number of distinct commit authors found in the source repository being imported. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="authors_url" type="string">
  The real API URL for reviewing and mapping commit authors during a repository import. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="commit_count" type="number">
  The real number of commits found in the source repository being imported. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="error_message" type="string">
  A real, human-readable error message, when the operation this result describes failed. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="failed_step" type="string">
  The real step in the workflow job that failed, if the job failed. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="has_large_files" type="bool">
  Whether the source repository being imported contains files exceeding GitHub's own size limits. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="html_url" type="string">
  The real, browsable web URL for this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="import_percent" type="number">
  The real, current progress of the repository import, as a percentage. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="large_files_count" type="number">
  The real number of oversized files found in the source repository being imported. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="large_files_size" type="number">
  The real total size of oversized files found in the source repository being imported, in bytes. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="message" type="string">
  A real, human-readable status message. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="project_choices" type="list(object)">
  The real candidate project names GitHub detected while importing from Team Foundation Version Control. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="push_percent" type="number">
  The real, current progress of pushing imported commits into the new repository, as a percentage. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="repository_url" type="string">
  The real API URL for the repository this object belongs to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  The real, current status of this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="status_text" type="string">
  A real, human-readable description of the current status. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="svc_root" type="string">
  The real root URL of the Subversion or TFVC server being imported from. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="svn_root" type="string">
  The real root URL of the Subversion repository being imported from. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="tfvc_project" type="string">
  The real Team Foundation Version Control project path being imported. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="url" type="string">
  The real, canonical API URL for this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="use_lfs" type="bool">
  Whether Git LFS is being used for large files during this import. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="vcs" type="string">
  The real, source version control system this migration is importing from. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="vcs_url" type="string">
  The URL of the originating repository. Returned by the lookup.
</ResponseField>

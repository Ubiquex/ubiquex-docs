`github_thread_subscription` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	thread "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/thread"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_thread_subscription"})

    		ubx.Data(thread.Subscription, "example", thread.SubscriptionConfig{
    			ThreadId: 1,
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx

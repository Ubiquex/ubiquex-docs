---
title: "github_language"
description: "`github_language` reads the real breakdown of programming languages used in a repository, by byte count."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	language "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/language"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_language"})

    		ubx.Data(language.Language, "example", language.LanguageConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Language } from "@ubx/sdk-github/github/data/language/language";

    export default stack("example", () => {
      intent({ summary: "look up github_language" });

      data(Language, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.language import Language, LanguageConfig

    def describe():
        ubx.intent("look up github_language")

        ubx.data(Language, "example", LanguageConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

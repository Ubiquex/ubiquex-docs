`github_organization_simple` looks up the real, compact identity record for an organization -- its name and basic profile -- without pulling its entire full account record.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organization "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/organization"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_organization_simple"})

    		ubx.Data(organization.Simple, "example", organization.SimpleConfig{
    			Enterprise: "example",
    			Page:       1,
    			PerPage:    1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.github.data.organization import Simple, SimpleConfig

    def describe():
        ubx.intent("look up github_organization_simple")

        ubx.data(Simple, "example", SimpleConfig(
            enterprise="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>

<ResponseField name="page" type="number">

</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.

## Result properties

<ResponseField name="organizations" type="list(object)">

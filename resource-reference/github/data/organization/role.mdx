## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	organization "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/organization"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_organization_role"})

    		ubx.Data(organization.Role, "example", organization.RoleConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    export default stack("example", () => {
      intent({ summary: "look up github_organization_role" });
    ```

  <Tab title="Python">
    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.organization import Role, RoleConfig

    def describe():
        ubx.intent("look up github_organization_role")

        ubx.data(Role, "example", RoleConfig(
            org="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="roles" type="list(object)">
  The list of organization roles available to the organization. Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of organization roles available to the organization. Returned by the lookup.
</ResponseField>

`github_organization_custom_repository_role` looks up a real, already-defined repository-level permission role an organization created on top of GitHub's own built-in roles.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	organization "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/organization"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_organization_custom_repository_role"})

    		ubx.Data(organization.CustomRepositoryRole, "example", organization.CustomRepositoryRoleConfig{
    			OrganizationId: "example",
    		})
    	}))
    }
    ```

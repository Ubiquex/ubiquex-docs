`github_organization_actions_variable` looks up a real, already-defined Actions configuration variable set at the organization level, readable by every repository underneath through the `vars` context.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	organization "github.com/ubiquex/ubx-sdk-github/sdk/go/github/organization"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own actions variable"})

    		ubx.Resource(organization.ActionsVariable, "example", organization.ActionsVariableConfig{
    			Name:                  "example",
    			Org:                   "example",
    			Value:                 "example",
    			Visibility:            "example",
    			SelectedRepositoryIds: []any{1},
    		})
    	}))
    }
    ```
  </Tab>

    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.organization import ActionsVariable, ActionsVariableConfig

    def describe():
        ubx.intent("example own actions variable")

        ubx.resource(ActionsVariable, "example", ActionsVariableConfig(
            name="example",
            org="example",
            value="example",
            visibility="example",
            selected_repository_ids=[1],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="variables" type="list(object)">
  The real Actions configuration variables included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	review "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/review"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_review"})

    		ubx.Data(review.Review, "example", review.ReviewConfig{
    			Owner:      "example",
    			PullNumber: 1,
    			Repo:       "example",
    			ReviewId:   1,
    			Page:       1,
    			PerPage:    1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="pull_number" type="number" required>
  The real, repository-scoped number identifying this pull request. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="review_id" type="number" required>
  The real, numeric ID of this pull request review. **(AI-inferred)** Required lookup argument.
</ResponseField>

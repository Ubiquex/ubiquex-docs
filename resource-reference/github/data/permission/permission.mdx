---
title: "github_permission"
description: "`github_permission` reads a real user's own current permission level on a specific repository."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	permission "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/permission"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_permission"})

    		ubx.Data(permission.Permission, "example", permission.PermissionConfig{
    			Enterprise: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Permission } from "@ubx/sdk-github/github/data/permission/permission";

    export default stack("example", () => {
      intent({ summary: "look up github_permission" });

      data(Permission, "example", {
        enterprise: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.permission import Permission, PermissionConfig

    def describe():
        ubx.intent("look up github_permission")

        ubx.data(Permission, "example", PermissionConfig(
            enterprise="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="disable_self_hosted_runners_for_all_orgs" type="bool">
  When true, repository-level runners will be disabled across all organizations in the enterprise Returned by the lookup.
</ResponseField>

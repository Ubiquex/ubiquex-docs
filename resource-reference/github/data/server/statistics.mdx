`github_server_statistics` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	server "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/server"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_server_statistics"})

    		ubx.Data(server.Statistics, "example", server.StatisticsConfig{
    			EnterpriseOrOrg: "example",
    			DateEnd:         "example",
    			DateStart:       "example",
    		})
    	}))
    }
    ```

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	participation "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/participation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_participation_stats"})

    		ubx.Data(participation.Stats, "example", participation.StatsConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>

    def describe():
        ubx.intent("look up github_participation_stats")

        ubx.data(Stats, "example", StatsConfig(

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="all" type="list(number)">
  Whether every matching item is included, rather than a filtered subset. **(AI-inferred)** Returned by the lookup.
</ResponseField>

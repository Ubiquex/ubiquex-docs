`github_enterprise_security_analysis_settings` reads the real, enterprise-wide default settings for GitHub Advanced Security features applied to newly created repositories.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	enterprise "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/enterprise"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_enterprise_security_analysis_settings"})

    		ubx.Data(enterprise.SecurityAnalysisSettings, "example", enterprise.SecurityAnalysisSettingsConfig{
    			Enterprise: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="advanced_security_enabled_for_new_repositories" type="bool">
  Whether GitHub advanced security is automatically enabled for new repositories and repositories transferred to this enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="advanced_security_enabled_for_new_user_namespace_repositories" type="bool">
  Whether GitHub Advanced Security is automatically enabled for new user namespace repositories. Returned by the lookup.
</ResponseField>

<ResponseField name="dependabot_alerts_enabled_for_new_repositories" type="bool">
  Whether Dependabot alerts are automatically enabled for new repositories and repositories transferred to this enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="secret_scanning_enabled_for_new_repositories" type="bool">
  Whether secret scanning is automatically enabled for new repositories and repositories transferred to this enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="secret_scanning_non_provider_patterns_enabled_for_new_repositories" type="bool">
  Whether secret scanning of non-provider patterns is enabled for new repositories under this enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="secret_scanning_push_protection_custom_link" type="string">
  An optional URL string to display to contributors who are blocked from pushing a secret. Returned by the lookup.
</ResponseField>

<ResponseField name="secret_scanning_push_protection_enabled_for_new_repositories" type="bool">
  Whether secret scanning push protection is automatically enabled for new repositories and repositories transferred to this enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="secret_scanning_validity_checks_enabled" type="bool">
  Whether secret scanning automatic validity checks on supported partner tokens is enabled for all repositories under this enterprise. Returned by the lookup.
</ResponseField>

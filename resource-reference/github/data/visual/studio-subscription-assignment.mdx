`github_visual_studio_subscription_assignment` reads whether a specific user's own GitHub Enterprise access is currently granted through a Visual Studio subscription benefit.

## Lookup arguments

<ResponseField name="enterprise" type="string" required>

</ResponseField>

<ResponseField name="is_unmatched_only" type="bool">
  Whether results are restricted to pushes that did not match any existing push protection bypass. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

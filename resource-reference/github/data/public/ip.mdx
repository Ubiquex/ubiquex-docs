## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	public "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/public"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_public_ip"})

    		ubx.Data(public.Ip, "example", public.IpConfig{
    			HostedRunnerId: 1,
    			Org:            "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="hosted_runner_id" type="number" required>
  The real, numeric ID of this GitHub-hosted runner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="number">
  The unique identifier of the hosted runner. Returned by the lookup.
</ResponseField>

<ResponseField name="image_details" type="object">
  Provides details of a hosted runner image Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="display_name" type="string" required>
      Display name for this image. Required lookup argument.
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The ID of the image. Use this ID for the `image` parameter when creating a new larger runner. Required lookup argument.
    </ResponseField>
    <ResponseField name="size_gb" type="number" required>
      Image size in GB. Required lookup argument.
    </ResponseField>
    <ResponseField name="source" type="string" required>
      The image provider. Required lookup argument.
    </ResponseField>
    <ResponseField name="version" type="string">
      The image version of the hosted runner pool. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_gen" type="bool">
  Whether custom image generation is enabled for the hosted runners. Returned by the lookup.
</ResponseField>

<ResponseField name="last_active_on" type="string">
  The time at which the runner was last used, in ISO 8601 format. Returned by the lookup.
</ResponseField>

<ResponseField name="machine_size_details" type="object">
  Provides details of a particular machine spec. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="cpu_cores" type="number" required>
      The number of cores. Required lookup argument.
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The ID used for the `size` parameter when creating a new runner. Required lookup argument.
    </ResponseField>
    <ResponseField name="memory_gb" type="number" required>
      The available RAM for the machine spec. Required lookup argument.
    </ResponseField>
    <ResponseField name="storage_gb" type="number" required>
      The available SSD storage for the machine spec. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="maximum_runners" type="number">
  The maximum amount of hosted runners. Runners will not scale automatically above this number. Use this setting to limit your cost. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the hosted runner. Returned by the lookup.
</ResponseField>

<ResponseField name="platform" type="string">
  The operating system of the image. Returned by the lookup.
</ResponseField>

<ResponseField name="public_ip_enabled" type="bool">
  Whether public IP is enabled for the hosted runners. Returned by the lookup.
</ResponseField>

<ResponseField name="public_ips" type="list(object)">
  The public IP ranges when public IP is enabled for the hosted runners. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_group_id" type="number">
  The unique identifier of the group that the hosted runner belongs to. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the runner. Returned by the lookup.
</ResponseField>

`github_label_search_result_item` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	label "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/label"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_label_search_result_item"})

    		ubx.Data(label.SearchResultItem, "example", label.SearchResultItemConfig{
    			Q:            "example",
    			RepositoryId: 1,
    			Order:        "example",
    			Page:         1,
    			PerPage:      1,
    			Sort:         "example",
    		})
    	}))
    }
    ```

`github_api_insights_summary_stats` reads a real, top-level summary of REST API usage across an enterprise -- total requests, rate-limit hits -- from API Insights.

## Lookup arguments

<ResponseField name="max_timestamp" type="string">
  The latest real timestamp to include in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="min_timestamp" type="string" required>
  The earliest real timestamp to include in the results. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="rate_limited_request_count" type="number">
  The total number of requests that were rate limited within the queried time period Returned by the lookup.
</ResponseField>

<ResponseField name="total_request_count" type="number">
  The total number of requests within the queried time period Returned by the lookup.
</ResponseField>

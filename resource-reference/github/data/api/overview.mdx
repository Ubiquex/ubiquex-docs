`github_api_overview` reads GitHub's own real, published API metadata -- the current IP address ranges for GitHub's services (web, API, Actions, Pages, and more), from the `/meta` endpoint.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_api_overview"})

    		ubx.Data(api.Overview, "example", api.OverviewConfig{})
    	}))
    }
    ```
  </Tab>

_This lookup takes no arguments._

## Lookup arguments

<ResponseField name="max_timestamp" type="string">
  The latest real timestamp to include in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="min_timestamp" type="string" required>
  The earliest real timestamp to include in the results. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="timestamp_increment" type="string" required>
  The real granularity (hour, day) results are bucketed into. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "github_dependabot_public_key"
description: "`github_dependabot_public_key` reads the real public key used to encrypt a Dependabot secret's value before it's sent to GitHub."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dependabot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/dependabot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_dependabot_public_key"})

    		ubx.Data(dependabot.PublicKey, "example", dependabot.PublicKeyConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { PublicKey } from "@ubx/sdk-github/github/data/dependabot/public_key";

    export default stack("example", () => {
      intent({ summary: "look up github_dependabot_public_key" });

      data(PublicKey, "example", {
        org: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.dependabot import PublicKey, PublicKeyConfig

    def describe():
        ubx.intent("look up github_dependabot_public_key")

        ubx.data(PublicKey, "example", PublicKeyConfig(
            org="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="key" type="string">
  The Base64 encoded public key. Returned by the lookup.
</ResponseField>

<ResponseField name="key_id" type="string">
  The identifier for the key. Returned by the lookup.
</ResponseField>

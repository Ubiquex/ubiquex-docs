  The real user this item is assigned to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before" type="string">
  Only return results before this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="classification" type="string">
  The real classification GitHub assigned to this finding. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="direction" type="string">
  The sort direction, asc or desc. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ecosystem" type="string">
  The real package ecosystem (npm, pip, and similar) this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="epss_percentage" type="string">

</ResponseField>

<ResponseField name="package" type="string">

<ResponseField name="per_page" type="number">

<ResponseField name="relationship" type="string">

<ResponseField name="scope" type="string">

<ResponseField name="severity" type="string">

</ResponseField>

<ResponseField name="sort" type="string">

---
title: "github_dependabot_secret"
description: "`github_dependabot_secret` looks up the real metadata of a repository-level Dependabot secret -- never its own decrypted value."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dependabot "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/dependabot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_dependabot_secret"})

    		ubx.Data(dependabot.Secret, "example", dependabot.SecretConfig{
    			Owner:   "example",
    			Repo:    "example",
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="secrets" type="list(object)">
  The real Actions or Dependabot secrets included in this result -- names and metadata only, never a decrypted value. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

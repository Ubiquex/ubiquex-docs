`github_minimal_repository` looks up the compact, real shape of a repository's own record -- a lighter view of the same real repository `github_full_repository` represents in full.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	minimal "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/minimal"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_minimal_repository"})

    		ubx.Data(minimal.Repository, "example", minimal.RepositoryConfig{
    			Org:           "example",
    			RunnerGroupId: 1,
    			Page:          1,
    			PerPage:       1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.minimal import Repository, RepositoryConfig

    def describe():
        ubx.intent("look up github_minimal_repository")

        ubx.data(Repository, "example", RepositoryConfig(
            org="example",
            runner_group_id=1,
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="runner_group_id" type="number" required>
  The real, numeric ID of this Actions runner group. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="repositories" type="list(object)">
  The real repositories included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="per" type="string">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="clones" type="list(object)">
  The real number of times this repository was cloned. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="count" type="number">
  The total number of matching items. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="uniques" type="number">
  The real count of unique visitors or cloners, deduplicated. **(AI-inferred)** Returned by the lookup.
</ResponseField>

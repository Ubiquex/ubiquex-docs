---
title: "github_root"
description: "`github_root` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_root` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	root "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/root"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_root"})

    		ubx.Data(root.Root, "example", root.RootConfig{})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Root } from "@ubx/sdk-github/github/data/root/root";

    export default stack("example", () => {
      intent({ summary: "look up github_root" });

      data(Root, "example", {});
    });
    ```
  </Tab>
  <Tab title="Python">

---
title: "github_pull"
description: "`github_pull` looks up a real pull request, the compact shape returned when a pull request is referenced from elsewhere rather than fetched directly."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pull "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/pull"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_pull"})

    		ubx.Data(pull.Pull, "example", pull.PullConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Pull } from "@ubx/sdk-github/github/data/pull/pull";

    export default stack("example", () => {
      intent({ summary: "look up github_pull" });

      data(Pull, "example", {
        org: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.pull import Pull, PullConfig

    def describe():
        ubx.intent("look up github_pull")

        ubx.data(Pull, "example", PullConfig(
            org="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="enabled" type="bool">
  Whether the pull request creation cap is enabled Returned by the lookup.
</ResponseField>

<ResponseField name="max_open_pull_requests" type="number">
  The maximum number of open pull requests a user can have at one time Returned by the lookup.
</ResponseField>

`github_pull_request_review_request` looks up which real reviewers or teams are currently requested on an open pull request, part of the same real pull request `github_pull_request` represents as a whole.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	pull "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/pull"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_pull_request_review_request"})

    		ubx.Data(pull.RequestReviewRequest, "example", pull.RequestReviewRequestConfig{
    			Owner:      "example",
    			PullNumber: 1,
    			Repo:       "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.pull import RequestReviewRequest, RequestReviewRequestConfig

    def describe():
        ubx.intent("look up github_pull_request_review_request")

        ubx.data(RequestReviewRequest, "example", RequestReviewRequestConfig(
            owner="example",
            pull_number=1,
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="pull_number" type="number" required>
  The real, repository-scoped number identifying this pull request. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="teams" type="list(object)">
  The real teams included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="users" type="list(object)">
  The real user accounts included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

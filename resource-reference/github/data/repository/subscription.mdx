## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="created_at" type="string">
  The real timestamp this object was created. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="ignored" type="bool">
  Determines if all notifications should be blocked from this repository. Returned by the lookup.
</ResponseField>

<ResponseField name="reason" type="string">
  The real reason this notification, invitation, or event exists. **(AI-inferred)** Returned by the lookup.

<ResponseField name="repository_url" type="string">

</ResponseField>

<ResponseField name="subscribed" type="bool">
  Determines if notifications should be received from this repository. Returned by the lookup.

<ResponseField name="url" type="string">

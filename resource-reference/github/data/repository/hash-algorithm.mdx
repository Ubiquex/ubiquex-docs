---
title: "github_repository_hash_algorithm"
description: "`github_repository_hash_algorithm` reads which real Git object hash algorithm (SHA-1 or SHA-256) a repository was created with."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	repository "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/repository"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_repository_hash_algorithm"})

    		ubx.Data(repository.HashAlgorithm, "example", repository.HashAlgorithmConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">

    ```python
    import ubx_sdk as ubx
    from ubx.github.data.repository import HashAlgorithm, HashAlgorithmConfig

    def describe():
        ubx.intent("look up github_repository_hash_algorithm")

        ubx.data(HashAlgorithm, "example", HashAlgorithmConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="hash_algorithm" type="string">
  The Git hash algorithm used by this repository. Returned by the lookup.
</ResponseField>

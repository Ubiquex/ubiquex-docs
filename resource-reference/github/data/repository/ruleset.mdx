`github_repository_ruleset` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	repository "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/repository"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_repository_ruleset"})

    		ubx.Data(repository.Ruleset, "example", repository.RulesetConfig{
    			Org:       "example",
    			RulesetId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">

    ```python
    def describe():

            org="example",

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_repository_collaborator_permission"})

    		ubx.Data(repository.CollaboratorPermission, "example", repository.CollaboratorPermissionConfig{

    		})
    	}))
    }

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="username" type="string" required>
  The real account's own username. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="permission" type="string">
  The real permission level (read, triage, write, maintain, admin) granted here. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="role_name" type="string">
  The real name of the permission role granted here. **(AI-inferred)** Returned by the lookup.
</ResponseField>

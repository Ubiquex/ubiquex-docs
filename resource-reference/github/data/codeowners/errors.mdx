## Example

  <Tab title="Go">

    package main

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_codeowners_errors"})

    		ubx.Data(codeowners.Errors, "example", codeowners.ErrorsConfig{
    			Owner: "example",
    			Repo:  "example",
    			Ref:   "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ref" type="string">
  The real git reference (a branch or tag name) this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="errors" type="list(object)">
  The real errors encountered while processing this request. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "github_content"
description: "`github_content` looks up the real contents of a file or directory in a repository at a specific ref."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	content "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/content"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_content"})

    		ubx.Data(content.Content, "example", content.ContentConfig{
    			Owner: "example",
    			Path:  "/example/",
    			Repo:  "example",
    			Ref:   "example",
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.github.data.content import Content, ContentConfig

    def describe():

            owner="example",

    if __name__ == "__main__":

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="path" type="string" required>
  The real file path within the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ref" type="string">
  The real git reference (a branch or tag name) this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

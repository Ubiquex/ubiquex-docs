`github_stat` reads a real, aggregated repository statistic -- one of the real code-frequency, commit-activity, or contributor-count views GitHub computes and caches for a repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	stat "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/stat"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_stat"})

    		ubx.Data(stat.Stat, "example", stat.StatConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only github --lang ts --out ./local-sdk
    import { Stat } from "./local-sdk/github/sdk/typescript/github/data/stat/stat.ts";

    export default stack("example", () => {
      intent({ summary: "look up github_stat" });

      data(Stat, "example", {
        owner: "example",

      });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.stat import Stat, StatConfig

    def describe():
        ubx.intent("look up github_stat")

        ubx.data(Stat, "example", StatConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

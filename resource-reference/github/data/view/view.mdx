## Example

    ```go
    package main

    import (
    	view "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/view"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_view"})

    		ubx.Data(view.View, "example", view.ViewConfig{
    			Org:           "example",
    			ProjectNumber: 1,
    			ViewNumber:    1,
    			After:         "example",
    			Before:        "example",
    			Fields:        "example",
    			PerPage:       1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="after" type="string">
  Only return results after this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before" type="string">
  Only return results before this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="fields" type="any">
  The real, custom fields configured on this Projects (v2) board. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="project_number" type="number" required>
  The real, organization- or user-scoped number identifying this project. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="view_number" type="number" required>
  The real, unique number identifying this Projects (v2) view. **(AI-inferred)** Required lookup argument.
</ResponseField>

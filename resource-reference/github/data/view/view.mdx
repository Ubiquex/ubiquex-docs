title: "github_view"
description: "`github_view` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_view` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	view "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/view"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_view"})

    		ubx.Data(view.View, "example", view.ViewConfig{
    			Org:           "example",
    			ProjectNumber: 1,
    			ViewNumber:    1,
    			After:         "example",
    			Before:        "example",
    			Fields:        "example",
    			PerPage:       1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

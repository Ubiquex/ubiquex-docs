`github_concurrency_group` looks up one real Actions concurrency group currently active for a repository or organization -- the group's own key, and whether a run is queued or in progress under it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	concurrency "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/concurrency"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_concurrency_group"})

    		ubx.Data(concurrency.Group, "example", concurrency.GroupConfig{
    			ConcurrencyGroupName: "example-concurrency-group-name",
    			Owner:                "example",
    			Repo:                 "example",
    			AheadOfJob:           1,
    			AheadOfRun:           1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="ahead_of_job" type="number">
  The real number of jobs still queued ahead of this one within its own concurrency group. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ahead_of_run" type="number">
  The real number of runs still queued ahead of this one within its own concurrency group. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="concurrency_group_name" type="string" required>
  The real, computed key identifying this Actions concurrency group. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="group_members" type="list(object)">
  The real workflow runs currently queued or running under this concurrency group. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="group_name" type="string">
  The name of the concurrency group. Returned by the lookup.
</ResponseField>

<ResponseField name="group_url" type="string">
  API URL for this concurrency group. Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

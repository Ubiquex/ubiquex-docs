`github_concurrency_group_list` lists the real Actions concurrency groups currently active for a repository or organization, each one throttling workflow runs that share its own concurrency key.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_concurrency_group_list"})

    			Owner:   "example",
    			Repo:    "example",
    			After:   "example",
    			PerPage: 1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="after" type="string">
  Only return results after this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="concurrency_groups" type="list(object)">
  The real Actions concurrency groups included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.

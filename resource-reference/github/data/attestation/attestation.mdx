`github_attestation` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	attestation "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/attestation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_attestation"})

    		ubx.Data(attestation.Attestation, "example", attestation.AttestationConfig{
    			Org:           "example",
    			After:         "example",
    			Before:        "example",
    			PerPage:       1,
    			PredicateType: "example",
    		})
    	}))
    }
    ```

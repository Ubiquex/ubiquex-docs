---
title: "github_commit_comparison"
description: "`github_commit_comparison` reads the real difference between two commits or refs -- the commits between them, and the combined file diff."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	commit "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/commit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_commit_comparison"})

    		ubx.Data(commit.Comparison, "example", commit.ComparisonConfig{
    			Basehead: "example",
    			Owner:    "example",
    			Repo:     "example",
    			Page:     1,
    			PerPage:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    export default stack("example", () => {

      data(Comparison, "example", {
        basehead: "example",

        repo: "example",
        page: 1,
        perPage: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.commit import Comparison, ComparisonConfig

    def describe():
        ubx.intent("look up github_commit_comparison")

        ubx.data(Comparison, "example", ComparisonConfig(
            basehead="example",
            owner="example",
            repo="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="basehead" type="string" required>
  The real base and head refs being compared, formatted as base...head. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

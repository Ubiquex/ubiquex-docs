---
title: "github_commit_comparison"
description: "`github_commit_comparison` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_commit_comparison` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	commit "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/commit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_commit_comparison"})

    		ubx.Data(commit.Comparison, "example", commit.ComparisonConfig{
    			Basehead: "example",
    			Owner:    "example",
    			Repo:     "example",
    			Page:     1,
    			PerPage:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Comparison } from "@ubx/sdk-github/github/data/commit/comparison";

    export default stack("example", () => {
      intent({ summary: "look up github_commit_comparison" });

      data(Comparison, "example", {
        basehead: "example",
        owner: "example",
        repo: "example",
        page: 1,
        perPage: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.github.data.commit import Comparison, ComparisonConfig

    def describe():

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

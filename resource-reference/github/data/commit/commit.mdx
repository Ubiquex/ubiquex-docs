`github_commit` looks up one real, immutable snapshot of a repository at a point in time -- its author, message, parent commit, and the tree of file contents it contains.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	commit "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/commit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_commit"})

    		ubx.Data(commit.Commit, "example", commit.CommitConfig{
    			CommitSha: "example",
    			Owner:     "example",
    			Repo:      "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="commit_sha" type="string" required>
  The real, full SHA of the commit this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

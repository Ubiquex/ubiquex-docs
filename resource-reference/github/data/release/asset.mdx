---
title: "github_release_asset"
description: "`github_release_asset` looks up one real file already attached to a release beyond the zip and tarball archives GitHub generates automatically."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	release "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/release"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_release_asset"})

    		ubx.Data(release.Asset, "example", release.AssetConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Asset } from "@ubx/sdk-github/github/data/release/asset";

    export default stack("example", () => {
      intent({ summary: "look up github_release_asset" });

      data(Asset, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.release import Asset, AssetConfig

    def describe():
        ubx.intent("look up github_release_asset")

        ubx.data(Asset, "example", AssetConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

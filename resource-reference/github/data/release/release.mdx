`github_release` looks up one real, already-published point in a repository's history, built on a specific git tag, with its own release notes and binary files.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	release "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/release"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_release"})

    		ubx.Data(release.Release, "example", release.ReleaseConfig{
    			Owner:     "example",
    			ReleaseId: 1,
    			Repo:      "example",
    			Page:      1,
    			PerPage:   1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="release_id" type="number" required>
  The real, numeric ID of this release. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

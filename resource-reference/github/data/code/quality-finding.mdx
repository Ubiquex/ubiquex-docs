## Lookup arguments

<ResponseField name="finding_number" type="number" required>
  The real, repository-scoped number identifying this code quality finding. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="created_at" type="string">
  The time the code quality finding was created. Returned by the lookup.
</ResponseField>

<ResponseField name="location" type="object">
  Code quality file location Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="end_column" type="number">
      The column number where the finding ends. Optional lookup argument.
    </ResponseField>
    <ResponseField name="end_line" type="number">
      The line number where the finding ends. Optional lookup argument.
    </ResponseField>
    <ResponseField name="path" type="string" required>
      The file path where the finding was detected. Required lookup argument.
    </ResponseField>
    <ResponseField name="start_column" type="number">
      The column number where the finding starts. Optional lookup argument.
    </ResponseField>
    <ResponseField name="start_line" type="number">
      The line number where the finding starts. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="message" type="object">
  Code quality finding message Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="markdown" type="string" required>
      The message text of the code quality finding in markdown format. Required lookup argument.
    </ResponseField>
    <ResponseField name="text" type="string" required>
      The message text of the code quality finding. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="number" type="number">
  The finding number. Returned by the lookup.
</ResponseField>

<ResponseField name="rule" type="object">
  Code quality rule Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="category" type="string" required>
      The category of the rule used to detect the finding. Required lookup argument.
    </ResponseField>
    <ResponseField name="description" type="string" required>
      A short description of the rule used to detect the finding. Required lookup argument.
    </ResponseField>
    <ResponseField name="help" type="string">
      A detailed description of the rule used to detect the finding. Optional lookup argument.
    </ResponseField>
    <ResponseField name="id" type="string" required>
      A unique identifier for the rule used to detect the finding. Required lookup argument.
    </ResponseField>
    <ResponseField name="severity" type="string" required>
      The severity of the rule used to detect the finding. Required lookup argument.
    </ResponseField>
    <ResponseField name="title" type="string" required>
      The name of the rule used to detect the finding. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  State of the code quality finding. Returned by the lookup.
</ResponseField>

<ResponseField name="url" type="string">
  The REST API URL of the code quality finding resource. Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="alert_number" type="number">
  The security alert number. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  The description of an autofix. Returned by the lookup.
</ResponseField>

<ResponseField name="started_at" type="string">
  The start time of an autofix in ISO 8601 format: `YYYY-MM-DDTHH:MM:SSZ`. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  The status of an autofix. Returned by the lookup.
</ResponseField>

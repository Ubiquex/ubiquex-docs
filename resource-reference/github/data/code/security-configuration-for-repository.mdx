`github_code_security_configuration_for_repository` looks up which real Code Security configuration a specific repository currently has applied, and its own current attachment status.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_code_security_configuration_for_repository"})

    		ubx.Data(code.SecurityConfigurationForRepository, "example", code.SecurityConfigurationForRepositoryConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SecurityConfigurationForRepository } from "@ubx/sdk-github/github/data/code/security_configuration_for_repository";

    export default stack("example", () => {

        summary: "look up github_code_security_configuration_for_repository",
    ```

  </Tab>
  <Tab title="Python">

    ```python
    import ubx_sdk as ubx

    def describe():
        ubx.intent("look up github_code_security_configuration_for_repository")

        ubx.data(SecurityConfigurationForRepository, "example", SecurityConfigurationForRepositoryConfig(
            owner="example",

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

  </Tab>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="language" type="string" required>
  The real, primary programming language detected for this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="commit_oid" type="string">
  The commit SHA of the repository at the time the CodeQL database was created. Returned by the lookup.
</ResponseField>

<ResponseField name="content_type" type="string">
  The MIME type of the CodeQL database file. Returned by the lookup.
</ResponseField>

<ResponseField name="created_at" type="string">
  The date and time at which the CodeQL database was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  The ID of the CodeQL database. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the CodeQL database. Returned by the lookup.
</ResponseField>

<ResponseField name="size" type="number">
  The size of the CodeQL database file in bytes. Returned by the lookup.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time at which the CodeQL database was last updated, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Returned by the lookup.
</ResponseField>

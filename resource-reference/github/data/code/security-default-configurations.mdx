`github_code_security_default_configurations` reads which Code Security configuration an organization has set as the default, automatically applied to newly created repositories.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_code_security_default_configurations"})

    		ubx.Data(code.SecurityDefaultConfigurations, "example", code.SecurityDefaultConfigurationsConfig{
    			Enterprise: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="ai_findings_option" type="string">
  The AI findings configuration for the repository. Returned by the lookup.
</ResponseField>

<ResponseField name="languages" type="list(string)">
  Languages to be analyzed. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_label" type="string">
  Runner label to be used if the runner type is labeled. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_type" type="string">
  Runner type to be used. Returned by the lookup.
</ResponseField>

<ResponseField name="schedule" type="string">
  The frequency of the periodic analysis. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Code quality setup has been configured or not. Returned by the lookup.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp of latest configuration update. Returned by the lookup.
</ResponseField>

`github_code_scanning_default_setup` reads whether a repository is using code scanning's own default, no-workflow-file setup, and its current configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_code_scanning_default_setup"})

    		ubx.Data(code.ScanningDefaultSetup, "example", code.ScanningDefaultSetupConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="languages" type="list(string)">
  Languages to be analyzed. Returned by the lookup.
</ResponseField>

<ResponseField name="query_suite" type="string">
  CodeQL query suite to be used. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_label" type="string">
  Runner label to be used if the runner type is labeled. Returned by the lookup.
</ResponseField>

<ResponseField name="runner_type" type="string">
  Runner type to be used. Returned by the lookup.
</ResponseField>

<ResponseField name="schedule" type="string">
  The frequency of the periodic analysis. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Code scanning default setup has been configured or not. Returned by the lookup.
</ResponseField>

<ResponseField name="threat_model" type="string">
  Threat model to be used for code scanning analysis. Use `remote` to analyze only network sources and `remote_and_local` to include local sources like filesystem access, command-line arguments, database reads, environment variable and standard input. Returned by the lookup.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp of latest configuration update. Returned by the lookup.
</ResponseField>

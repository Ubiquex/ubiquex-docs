`github_code_scanning_analysis` looks up one real, completed code scanning analysis run for a specific commit -- which tool produced it and how many results it found.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_code_scanning_analysis"})

    		ubx.Data(code.ScanningAnalysis, "example", code.ScanningAnalysisConfig{
    			AnalysisId: 1,
    			Owner:      "example",
    			Repo:       "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    ```

## Lookup arguments

<ResponseField name="analysis_id" type="number" required>
  The real, numeric ID of this code scanning analysis. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="analysis_key" type="string">
  Identifies the configuration under which the analysis was executed. For example, in GitHub Actions this includes the workflow filename and job name. Returned by the lookup.
</ResponseField>

<ResponseField name="category" type="string">
  Identifies the configuration under which the analysis was executed. Used to distinguish between multiple analyses for the same tool and commit, but performed on different languages or different parts of the code. Returned by the lookup.
</ResponseField>

<ResponseField name="commit_sha" type="string">
  The SHA of the commit to which the analysis you are uploading relates. Returned by the lookup.
</ResponseField>

<ResponseField name="created_at" type="string">
  The time that the analysis was created in ISO 8601 format: `YYYY-MM-DDTHH:MM:SSZ`. Returned by the lookup.
</ResponseField>

<ResponseField name="deletable" type="bool">
  Whether this code scanning analysis is currently eligible for deletion. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="environment" type="string">
  Identifies the variable values associated with the environment in which this analysis was performed. Returned by the lookup.
</ResponseField>

<ResponseField name="error" type="string">
  A real, human-readable error message, when the operation this result describes failed. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  Unique identifier for this analysis. Returned by the lookup.
</ResponseField>

<ResponseField name="ref" type="string">
  The Git reference, formatted as `refs/pull/&lt;number&gt;/merge`, `refs/pull/&lt;number&gt;/head`, `refs/heads/&lt;branch name&gt;` or simply `&lt;branch name&gt;`. Returned by the lookup.
</ResponseField>

<ResponseField name="results_count" type="number">
  The total number of results in the analysis. Returned by the lookup.
</ResponseField>

<ResponseField name="rules_count" type="number">
  The total number of rules used in the analysis. Returned by the lookup.
</ResponseField>

<ResponseField name="sarif_id" type="string">
  An identifier for the upload. Returned by the lookup.
</ResponseField>

<ResponseField name="tool" type="object">
  The real analysis tool that produced this result. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="guid" type="string">
      The GUID of the tool used to generate the code scanning analysis, if provided in the uploaded SARIF data. Optional lookup argument.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the tool used to generate the code scanning analysis. Optional lookup argument.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of the tool used to generate the code scanning analysis. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="url" type="string">
  The REST API URL of the analysis resource. Returned by the lookup.
</ResponseField>

<ResponseField name="warning" type="string">
  Warning generated when processing the analysis Returned by the lookup.
</ResponseField>

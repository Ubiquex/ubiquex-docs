## Lookup arguments

<ResponseField name="codeql_variant_analysis_id" type="number" required>
  The real, numeric ID of this Multi-Repository Variant Analysis run. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo_name" type="string" required>
  The real name of the repository this task result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo_owner" type="string" required>
  The real owner of the repository this task result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

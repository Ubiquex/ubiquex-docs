`github_code_scanning` reports whether a real, already-uploaded SARIF results file has finished processing -- the same real confirmation `github_code_scanning_sarifs_status` provides for a specific upload.

    	ubx.Main(ubx.Stack("example", func() {

## Lookup arguments

<ResponseField name="after" type="string">
  Only return results after this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="assignees" type="string">
  The real users this item is assigned to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before" type="string">
  Only return results before this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="direction" type="string">
  The sort direction, asc or desc. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="state" type="string">
  State of a code scanning alert. Optional lookup argument.
</ResponseField>

<ResponseField name="tool_guid" type="string">
  The GUID of the tool used to generate the code scanning analysis, if provided in the uploaded SARIF data. Optional lookup argument.
</ResponseField>

<ResponseField name="tool_name" type="string">
  The name of the tool used to generate the code scanning analysis. Optional lookup argument.
</ResponseField>

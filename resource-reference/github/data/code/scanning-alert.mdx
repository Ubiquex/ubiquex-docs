`github_code_scanning_alert` looks up one real code scanning finding -- its own severity, state, and the specific rule that flagged it, the fuller record `github_alert` represents more narrowly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_code_scanning_alert"})

    		ubx.Data(code.ScanningAlert, "example", code.ScanningAlertConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ScanningAlert } from "@ubx/sdk-github/github/data/code/scanning_alert";

    export default stack("example", () => {
      intent({ summary: "look up github_code_scanning_alert" });

      data(ScanningAlert, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.code import ScanningAlert, ScanningAlertConfig

    def describe():
        ubx.intent("look up github_code_scanning_alert")

        ubx.data(ScanningAlert, "example", ScanningAlertConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

`github_code_security_configuration` looks up a real, already-defined named policy bundling Dependabot alerts, CodeQL code scanning, and secret protection for applying across repositories.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_code_security_configuration"})

    		ubx.Data(code.SecurityConfiguration, "example", code.SecurityConfigurationConfig{
    			ConfigurationId: 1,
    			Org:             "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx

    def describe():

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="configuration_id" type="number" required>
  The real, numeric ID of this configuration. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`github_rate_limit_overview` reads the real, current REST and GraphQL API rate limit status for the authenticated caller -- how many requests remain before the next reset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rate "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/rate"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_rate_limit_overview"})

    		ubx.Data(rate.LimitOverview, "example", rate.LimitOverviewConfig{})
    	}))
    }
    ```

title: "github_team_repository"
description: "`github_team_repository` reads which real permission level a specific team has been granted on a specific repository."

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	team "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/team"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_team_repository"})

    		ubx.Data(team.Repository, "example", team.RepositoryConfig{
    			Org:      "example",
    			Owner:    "example",
    			Repo:     "example",
    			TeamSlug: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="team_slug" type="string" required>
  The real, URL-safe slug identifying the team. **(AI-inferred)** Required lookup argument.
</ResponseField>

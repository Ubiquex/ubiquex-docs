`github_projects_v2_item_with_content` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	projects "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/projects"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_projects_v2_item_with_content"})

    		ubx.Data(projects.V2ItemWithContent, "example", projects.V2ItemWithContentConfig{
    			ItemId:        1,
    			ProjectNumber: 1,
    			Username:      "example",
    		})
    	}))
    }
    ```

title: "github_projects_v2"
description: "`github_projects_v2` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_projects_v2` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	projects "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/projects"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_projects_v2"})

    		ubx.Data(projects.ProjectsV2, "example", projects.ProjectsV2Config{
    			Org:           "example",
    			ProjectNumber: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ProjectsV2 } from "@ubx/sdk-github/github/data/projects/projects_v2";

    export default stack("example", () => {
      intent({ summary: "look up github_projects_v2" });

      data(ProjectsV2, "example", {
        org: "example",
        projectNumber: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.projects import ProjectsV2, ProjectsV2Config

    def describe():
        ubx.intent("look up github_projects_v2")

        ubx.data(ProjectsV2, "example", ProjectsV2Config(
            org="example",
            project_number=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

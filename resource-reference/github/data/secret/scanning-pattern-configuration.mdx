## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="custom_pattern_overrides" type="list(object)">
  Overrides for custom patterns defined by the organization. Returned by the lookup.
</ResponseField>

<ResponseField name="pattern_config_version" type="string">
  The version of the entity. This is used to confirm you're updating the current version of the entity and mitigate unintentionally overriding someone else's update. Returned by the lookup.
</ResponseField>

<ResponseField name="provider_pattern_overrides" type="list(object)">
  Overrides for partner patterns. Returned by the lookup.
</ResponseField>

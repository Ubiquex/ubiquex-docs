## Lookup arguments

<ResponseField name="after" type="string">
  Only return results after this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="assignee" type="string">
  The real user this item is assigned to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before" type="string">
  Only return results before this real cursor or timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="direction" type="string">
  The sort direction, asc or desc. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="exclude_providers" type="string">
  Secret providers to exclude from these results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="exclude_secret_types" type="string">
  Secret types to exclude from these results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="hide_secret" type="bool">
  Whether the detected secret's own value is masked in this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="included_metadata" type="string">
  Which extra metadata fields are included alongside each alert in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="is_bypassed" type="bool">
  Whether push protection was bypassed to allow this secret to be pushed. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="is_multi_repo" type="bool">
  Whether this secret scanning alert spans more than one repository. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="is_publicly_leaked" type="bool">
  Whether this secret has also been found exposed in a public location outside this repository. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner_email_hash" type="string">
  A real, hashed identifier for the repository owner, used for anonymized aggregation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="providers" type="string">
  The real list of secret providers this scan covers. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="resolution" type="string">
  The real resolution recorded for this alert, once it's been closed. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="secret_type" type="string">
  The real type of secret this alert detected, such as an API key or access token. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="state" type="string">
  The real, current state of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="validity" type="string">
  Whether the detected secret was confirmed to still be a real, active credential. **(AI-inferred)** Optional lookup argument.
</ResponseField>

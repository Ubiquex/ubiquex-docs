`github_secret_scanning_alert_with_metadata` looks up one real secret scanning finding -- the detected secret type, its own state, and push-protection bypass details if any.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	secret "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/secret"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_secret_scanning_alert_with_metadata"})

    		ubx.Data(secret.ScanningAlertWithMetadata, "example", secret.ScanningAlertWithMetadataConfig{
    			Owner:      "example",
    			Repo:       "example",
    			HideSecret: true,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ScanningAlertWithMetadata } from "@ubx/sdk-github/github/data/secret/scanning_alert_with_metadata";

    export default stack("example", () => {
      intent({ summary: "look up github_secret_scanning_alert_with_metadata" });

      data(ScanningAlertWithMetadata, "example", {
        owner: "example",
        repo: "example",
        hideSecret: true,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.secret import ScanningAlertWithMetadata, ScanningAlertWithMetadataConfig

    def describe():
        ubx.intent("look up github_secret_scanning_alert_with_metadata")

        ubx.data(ScanningAlertWithMetadata, "example", ScanningAlertWithMetadataConfig(
            owner="example",
            repo="example",
            hide_secret=True,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="hide_secret" type="bool">
  Whether the detected secret's own value is masked in this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

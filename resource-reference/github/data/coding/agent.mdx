## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	coding "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/coding"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_coding_agent"})

    		ubx.Data(coding.Agent, "example", coding.AgentConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    export default stack("example", () => {

      data(Agent, "example", {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.coding import Agent, AgentConfig

    def describe():
        ubx.intent("look up github_coding_agent")

        ubx.data(Agent, "example", AgentConfig(
            org="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="enabled_repositories" type="string">
  The policy for which repositories can use Copilot cloud agent. Can be one of `all`, `selected`, or `none`. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The URL for the selected repositories endpoint. Only present when `enabled_repositories` is `selected`. Returned by the lookup.
</ResponseField>

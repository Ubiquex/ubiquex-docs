`github_status_check_policy` reads a protected branch's own currently required status checks -- which context names must report success before a merge is allowed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	status "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/status"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_status_check_policy"})

    		ubx.Data(status.CheckPolicy, "example", status.CheckPolicyConfig{
    			Branch: "example",
    			Owner:  "example",
    			Repo:   "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="branch" type="string" required>
  The real branch name this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="checks" type="list(object)">
  The real status checks included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="contexts" type="list(string)">
  The real list of status check contexts included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="contexts_url" type="string">
  The real API URL for a branch's own required status check contexts. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="strict" type="bool">
  Whether a branch must be up to date with its base branch before merging is allowed. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="url" type="string">
  The real, canonical API URL for this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

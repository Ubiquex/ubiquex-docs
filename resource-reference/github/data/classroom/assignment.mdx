`github_classroom_assignment` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	classroom "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/classroom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_classroom_assignment"})

    		ubx.Data(classroom.Assignment, "example", classroom.AssignmentConfig{
    			AssignmentId: 1,
    		})
    	}))
    }
    ```

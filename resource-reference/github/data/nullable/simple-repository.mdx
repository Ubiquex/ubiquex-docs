`github_nullable_simple_repository` looks up the compact, real shape of a repository reference that may legitimately be absent -- for example, a fork whose parent was deleted.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	nullable "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/nullable"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_nullable_simple_repository"})

    		ubx.Data(nullable.SimpleRepository, "example", nullable.SimpleRepositoryConfig{
    			Enterprise: "example",
    			Page:       1,
    			PerPage:    1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "github_integration"
description: "`github_integration` looks up a real GitHub App, under the legacy \"integration\" name the API still exposes for it."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	integration "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/integration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_integration"})

    		ubx.Data(integration.Integration, "example", integration.IntegrationConfig{})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Integration } from "@ubx/sdk-github/github/data/integration/integration";

    export default stack("example", () => {
      intent({ summary: "look up github_integration" });

      data(Integration, "example", {});
    });
    ```
  </Tab>
  <Tab title="Python">

## Lookup arguments

_This lookup takes no arguments._

## Result properties

<ResponseField name="client_id" type="string">
  The real OAuth client ID issued to this app. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="created_at" type="string">
  The real timestamp this object was created. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  The real, free-text description set on this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="events" type="list(string)">
  The list of events for the GitHub app. Note that the `installation_target`, `security_advisory`, and `meta` events are not included because they are global events and not specific to an installation. Returned by the lookup.
</ResponseField>

<ResponseField name="external_url" type="string">
  A real, external URL associated with this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="html_url" type="string">
  The real, browsable web URL for this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="number">
  Unique identifier of the GitHub app Returned by the lookup.
</ResponseField>

<ResponseField name="installations_count" type="number">
  The number of installations associated with the GitHub app. Only returned when the integration is requesting details about itself. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">

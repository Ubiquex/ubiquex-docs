`github_deployment_protection_rule` looks up a real, already-configured custom gate a deployment to a protected environment must pass before it's allowed to proceed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	deployment "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/deployment"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_deployment_protection_rule"})

    		ubx.Data(deployment.ProtectionRule, "example", deployment.ProtectionRuleConfig{
    			EnvironmentName: "example-environment-name",
    			Owner:           "example",
    			Repo:            "example",
    			Page:            1,
    			PerPage:         1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="environment_name" type="string" required>
  The real name of the deployment environment. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="available_custom_deployment_protection_rule_integrations" type="list(object)">
  Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of custom deployment protection rule integrations available for this environment. Returned by the lookup.
</ResponseField>

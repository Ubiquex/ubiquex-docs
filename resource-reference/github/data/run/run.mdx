## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	run "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/run"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_run"})

    		ubx.Data(run.Run, "example", run.RunConfig{
    			Owner: "example",
    			Repo:  "example",
    			RunId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only github --lang ts --out ./local-sdk
    import { Run } from "./local-sdk/github/sdk/typescript/github/data/run/run.ts";

    export default stack("example", () => {
      intent({ summary: "look up github_run" });

      data(Run, "example", {
        owner: "example",
        repo: "example",
        runId: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only github --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.run import Run, RunConfig

    def describe():
        ubx.intent("look up github_run")

        ubx.data(Run, "example", RunConfig(
            owner="example",
            repo="example",
            run_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="run_id" type="number" required>
  The real, numeric ID of this Actions workflow run. **(AI-inferred)** Required lookup argument.
</ResponseField>

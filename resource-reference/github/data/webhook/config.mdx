`github_webhook_config` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Lookup arguments

_This lookup takes no arguments._

## Result properties

<ResponseField name="content_type" type="string">
  The media type used to serialize the payloads. Supported values include `json` and `form`. The default is `form`. Returned by the lookup.
</ResponseField>

<ResponseField name="insecure_ssl" type="any">
  Returned by the lookup.
</ResponseField>

<ResponseField name="secret" type="string">
  If provided, the `secret` will be used as the `key` to generate the HMAC hex digest value for [delivery signature headers](https://docs.github.com/enterprise-cloud@latest/webhooks/event-payloads/#delivery-headers). Returned by the lookup.
</ResponseField>

<ResponseField name="url" type="string">
  The URL to which the payloads will be delivered. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	invitation "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/invitation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_invitation"})

    		ubx.Data(invitation.Invitation, "example", invitation.InvitationConfig{
    			InvitationId: 1,
    			Org:          "example",
    			Page:         1,
    			PerPage:      1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.github.data.invitation import Invitation, InvitationConfig

    def describe():
        ubx.intent("look up github_invitation")

        ubx.data(Invitation, "example", InvitationConfig(
            invitation_id=1,
            org="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="invitation_id" type="number" required>
  The real, numeric ID of this invitation. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

title: "github_community_profile"
description: "`github_community_profile` is a real, live lookup against GitHub, generated from github's own real schema -- read-only, never created or destroyed."
---

`github_community_profile` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	community "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/community"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_community_profile"})

    		ubx.Data(community.Profile, "example", community.ProfileConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Profile } from "@ubx/sdk-github/github/data/community/profile";

    export default stack("example", () => {
      intent({ summary: "look up github_community_profile" });

      data(Profile, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.community import Profile, ProfileConfig

    def describe():
        ubx.intent("look up github_community_profile")

        ubx.data(Profile, "example", ProfileConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

`github_community_profile` reads a repository's own real community health checklist -- whether it has a README, license, contributing guide, and code of conduct.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	community "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/community"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_community_profile"})

    		ubx.Data(community.Profile, "example", community.ProfileConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Profile } from "@ubx/sdk-github/github/data/community/profile";

    export default stack("example", () => {
      intent({ summary: "look up github_community_profile" });

      data(Profile, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.community import Profile, ProfileConfig

    def describe():
        ubx.intent("look up github_community_profile")

        ubx.data(Profile, "example", ProfileConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

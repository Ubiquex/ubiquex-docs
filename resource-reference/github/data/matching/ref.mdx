`github_matching_ref` looks up every real git reference -- branch head or tag -- whose name matches a given prefix, built on the same real ref object `github_git_ref` represents individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	matching "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/matching"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_matching_ref"})

    		ubx.Data(matching.Ref, "example", matching.RefConfig{
    			Owner: "example",
    			Ref:   "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="ref" type="string" required>
  The real git reference (a branch or tag name) this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

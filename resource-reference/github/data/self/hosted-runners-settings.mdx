`github_self_hosted_runners_settings` reads an organization or enterprise's own real policy for which repositories are allowed to register self-hosted runners.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	self "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/self"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_self_hosted_runners_settings"})

    		ubx.Data(self.HostedRunnersSettings, "example", self.HostedRunnersSettingsConfig{
    			Org: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="enabled_repositories" type="string">
  The policy that controls whether self-hosted runners can be used by repositories in the organization Returned by the lookup.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The URL to the endpoint for managing selected repositories for self-hosted runners in the organization Returned by the lookup.
</ResponseField>

`github_self_hosted_runners_settings` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="enabled_repositories" type="string">
  The policy that controls whether self-hosted runners can be used by repositories in the organization Returned by the lookup.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The URL to the endpoint for managing selected repositories for self-hosted runners in the organization Returned by the lookup.
</ResponseField>

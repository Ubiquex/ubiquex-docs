## Example

    ```go
    package main

    import (
    	dependency "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/dependency"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_dependency_graph_diff"})

    		ubx.Data(dependency.GraphDiff, "example", dependency.GraphDiffConfig{
    			Basehead: "example",
    			Owner:    "example",
    			Repo:     "example",
    			Name:     "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="basehead" type="string" required>
  The real base and head refs being compared, formatted as base...head. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="name" type="string">
  The real, given name of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

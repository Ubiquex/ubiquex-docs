## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go

    	dependency "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/dependency"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_dependency_graph_spdx_sbom"})

    		ubx.Data(dependency.GraphSpdxSbom, "example", dependency.GraphSpdxSbomConfig{

    			Repo:  "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="sbom" type="object">
  The real Software Bill of Materials generated for this repository. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="comment" type="string">
      An optional comment about the SPDX document. Optional lookup argument.
    </ResponseField>
    <ResponseField name="creation_info" type="object" required>
      Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="created" type="string" required>
          The date and time the SPDX document was created. Required lookup argument.
        </ResponseField>
        <ResponseField name="creators" type="list(string)" required>
          The tools that were used to generate the SPDX document. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="data_license" type="string" required>
      The license under which the SPDX document is licensed. Required lookup argument.
    </ResponseField>
    <ResponseField name="document_namespace" type="string" required>
      The namespace for the SPDX document. Required lookup argument.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      The name of the SPDX document. Required lookup argument.
    </ResponseField>
    <ResponseField name="packages" type="list(object)" required>
      Required lookup argument.
    </ResponseField>
    <ResponseField name="relationships" type="list(object)">
      Optional lookup argument.
    </ResponseField>
    <ResponseField name="spdx_version" type="string" required>
      The version of the SPDX specification that this document conforms to. Required lookup argument.
    </ResponseField>
    <ResponseField name="spdxid" type="string" required>
      The SPDX identifier for the SPDX document. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

`github_dependency_graph_spdx_sbom` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	dependency "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/dependency"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_dependency_graph_spdx_sbom"})

    		ubx.Data(dependency.GraphSpdxSbom, "example", dependency.GraphSpdxSbomConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_network_settings"})

    		ubx.Data(network.Settings, "example", network.SettingsConfig{
    			Enterprise:        "example",
    			NetworkSettingsId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">

    ```python
    import ubx_sdk as ubx
    from ubx.github.data.network import Settings, SettingsConfig

    def describe():
        ubx.intent("look up github_network_settings")

        ubx.data(Settings, "example", SettingsConfig(
            enterprise="example",
            network_settings_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="network_settings_id" type="string" required>
  The real, unique ID of this network settings resource. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="string">
  The unique identifier of the network settings resource. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the network settings resource. Returned by the lookup.
</ResponseField>

<ResponseField name="network_configuration_id" type="string">
  The identifier of the network configuration that is using this settings resource. Returned by the lookup.
</ResponseField>

<ResponseField name="region" type="string">
  The location of the subnet this network settings resource is configured for. Returned by the lookup.
</ResponseField>

<ResponseField name="subnet_id" type="string">
  The subnet this network settings resource is configured for. Returned by the lookup.
</ResponseField>

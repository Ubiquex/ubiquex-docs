## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	hovercard "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/hovercard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_hovercard"})

    		ubx.Data(hovercard.Hovercard, "example", hovercard.HovercardConfig{
    			Username:    "example",
    			SubjectId:   "example",
    			SubjectType: "example",
    		})
    	}))
    }
    ```

    # export PYTHONPATH=./local-sdk/github/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.github.data.hovercard import Hovercard, HovercardConfig

    def describe():
        ubx.intent("look up github_hovercard")

        ubx.data(Hovercard, "example", HovercardConfig(
            username="example",
            subject_id="example",
            subject_type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="subject_id" type="string">
  The real, unique identifier of the subject this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="subject_type" type="string">
  The real type of the subject this result is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="username" type="string" required>
  The real account's own username. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="contexts" type="list(object)">
  The real list of status check contexts included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

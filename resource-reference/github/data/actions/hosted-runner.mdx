`github_actions_hosted_runner` looks up a real, already-provisioned GitHub-hosted runner -- the virtual machine GitHub provisions and maintains to run one Actions job, Ubuntu, Windows, or macOS.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_hosted_runner"})

    		ubx.Data(actions.HostedRunner, "example", actions.HostedRunnerConfig{
    			Enterprise: "example",
    			Page:       1,
    			PerPage:    1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="runners" type="list(object)">
  The real Actions runners included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

`github_actions_get_default_workflow_permissions` reads the default `GITHUB_TOKEN` permission level (read or write) newly created workflows get unless a workflow overrides it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_get_default_workflow_permissions"})

    		ubx.Data(actions.GetDefaultWorkflowPermissions, "example", actions.GetDefaultWorkflowPermissionsConfig{
    			Enterprise: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="can_approve_pull_request_reviews" type="bool">
  Whether GitHub Actions can approve pull requests. Enabling this can be a security risk. Returned by the lookup.
</ResponseField>

<ResponseField name="default_workflow_permissions" type="string">
  The default workflow permissions granted to the GITHUB_TOKEN when running workflows. Returned by the lookup.
</ResponseField>

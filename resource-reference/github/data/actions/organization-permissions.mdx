## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="allowed_actions" type="string">
  The permissions policy that controls the actions and reusable workflows that are allowed to run. Returned by the lookup.
</ResponseField>

<ResponseField name="enabled_repositories" type="string">
  The policy that controls the repositories in the organization that are allowed to run GitHub Actions. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_actions_url" type="string">
  The API URL to use to get or set the actions and reusable workflows that are allowed to run, when `allowed_actions` is set to `selected`. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The API URL to use to get or set the selected repositories that are allowed to run GitHub Actions, when `enabled_repositories` is set to `selected`. Returned by the lookup.
</ResponseField>

<ResponseField name="sha_pinning_required" type="bool">
  Whether actions must be pinned to a full-length commit SHA. Returned by the lookup.
</ResponseField>

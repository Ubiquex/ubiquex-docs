`github_actions_enterprise_permissions` reads the enterprise-wide policy for which organizations and repositories are allowed to run Actions workflows at all.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_enterprise_permissions"})

    		ubx.Data(actions.EnterprisePermissions, "example", actions.EnterprisePermissionsConfig{
    			Enterprise: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="allowed_actions" type="string">
  The permissions policy that controls the actions and reusable workflows that are allowed to run. Returned by the lookup.
</ResponseField>

<ResponseField name="enabled_organizations" type="string">
  The policy that controls the organizations in the enterprise that are allowed to run GitHub Actions. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_actions_url" type="string">
  The API URL to use to get or set the actions and reusable workflows that are allowed to run, when `allowed_actions` is set to `selected`. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_organizations_url" type="string">
  The API URL to use to get or set the selected organizations that are allowed to run GitHub Actions, when `enabled_organizations` is set to `selected`. Returned by the lookup.
</ResponseField>

<ResponseField name="sha_pinning_required" type="bool">
  Whether actions must be pinned to a full-length commit SHA. Returned by the lookup.
</ResponseField>

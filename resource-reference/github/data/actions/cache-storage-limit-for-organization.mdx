## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="max_cache_size_gb" type="number">
  For repositories in the organization, the maximum size limit for the sum of all caches in a repository, in gigabytes. Returned by the lookup.
</ResponseField>

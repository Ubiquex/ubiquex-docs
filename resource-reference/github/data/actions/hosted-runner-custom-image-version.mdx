`github_actions_hosted_runner_custom_image_version` looks up one real, specific version of a custom VM image already uploaded for provisioning GitHub-hosted runners.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_hosted_runner_custom_image_version"})

    		ubx.Data(actions.HostedRunnerCustomImageVersion, "example", actions.HostedRunnerCustomImageVersionConfig{
    			Enterprise:        "example",
    			ImageDefinitionId: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="image_definition_id" type="number" required>
  The real, unique ID of this GitHub-hosted runner image definition. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="image_versions" type="list(object)">

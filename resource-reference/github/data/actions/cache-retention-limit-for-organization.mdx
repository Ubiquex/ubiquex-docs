`github_actions_cache_retention_limit_for_organization` reads the organization-level policy controlling how long an Actions cache entry can sit unused before eviction.

## Result properties

  For repositories in this organization, the maximum duration, in days, for which caches in a repository may be retained. Returned by the lookup.

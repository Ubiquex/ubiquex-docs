`github_actions_workflow_access_to_repository` reads whether workflows in other repositories are permitted to access this repository's own Actions resources.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_workflow_access_to_repository"})

    		ubx.Data(actions.WorkflowAccessToRepository, "example", actions.WorkflowAccessToRepositoryConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="access_level" type="string">
  Defines the level of access that workflows outside of the repository have to actions and reusable workflows within the repository. `none` means the access is only possible from workflows in this repository. `user` level access allows sharing across user owned private repositories only. `organization` level access allows sharing across the organization. `enterprise` level access allows sharing across the enterprise. Returned by the lookup.
</ResponseField>

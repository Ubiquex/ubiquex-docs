`github_actions_fork_pr_workflows_private_repos` reads whether workflows triggered by a fork's own pull request are permitted to run at all on a private repository.

## Result properties

<ResponseField name="require_approval_for_fork_pr_workflows" type="bool">
  Whether workflows triggered by pull requests from forks require approval from a repository administrator to run. Returned by the lookup.
</ResponseField>

<ResponseField name="run_workflows_from_fork_pull_requests" type="bool">
  Whether workflows triggered by pull requests from forks are allowed to run on private repositories. Returned by the lookup.
</ResponseField>

<ResponseField name="send_secrets_and_variables" type="bool">
  Whether to make secrets and variables available to workflows triggered by pull requests from forks. Returned by the lookup.
</ResponseField>

<ResponseField name="send_write_tokens_to_workflows" type="bool">
  Whether GitHub Actions can create pull requests or submit approving pull request reviews from a workflow triggered by a fork pull request. Returned by the lookup.
</ResponseField>

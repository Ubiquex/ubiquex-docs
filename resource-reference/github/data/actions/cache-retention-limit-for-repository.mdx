`github_actions_cache_retention_limit_for_repository` reads the repository-level policy controlling how long an Actions cache entry can sit unused before eviction.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go

    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_cache_retention_limit_for_repository"})

    		ubx.Data(actions.CacheRetentionLimitForRepository, "example", actions.CacheRetentionLimitForRepositoryConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="max_cache_retention_days" type="number">
  The maximum number of days to keep caches in this repository. Returned by the lookup.
</ResponseField>

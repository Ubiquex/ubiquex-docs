`github_actions_public_key` reads the real public key Actions uses to encrypt a secret's value before it's ever sent to GitHub, so a client can encrypt a secret client-side before creating it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_actions_public_key"})

    		ubx.Data(actions.PublicKey, "example", actions.PublicKeyConfig{
    			Org: "example",
    		})
    	}))
    }
    ```
  </Tab>

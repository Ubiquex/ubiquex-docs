## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="allowed_actions" type="string">
  The permissions policy that controls the actions and reusable workflows that are allowed to run. Returned by the lookup.
</ResponseField>

<ResponseField name="enabled" type="bool">
  Whether GitHub Actions is enabled on the repository. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_actions_url" type="string">
  The API URL to use to get or set the actions and reusable workflows that are allowed to run, when `allowed_actions` is set to `selected`. Returned by the lookup.
</ResponseField>

<ResponseField name="sha_pinning_required" type="bool">
  Whether actions must be pinned to a full-length commit SHA. Returned by the lookup.
</ResponseField>

`github_immutable_releases_organization_settings` reads an organization's own real, default policy for whether newly created repositories have immutable releases enabled.

## Lookup arguments

<ResponseField name="org" type="string" required>
  The real organization this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="enforced_repositories" type="string">
  The policy that controls how immutable releases are enforced in the organization. Returned by the lookup.
</ResponseField>

<ResponseField name="selected_repositories_url" type="string">
  The API URL to use to get or set the selected repositories for immutable releases enforcement, when `enforced_repositories` is set to `selected`. Returned by the lookup.
</ResponseField>

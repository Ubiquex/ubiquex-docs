`github_repo` lists the real repositories an organization or user actually owns, with real filters for creation, visibility, and archive status -- the search/listing counterpart to looking up one `github_full_repository` by name.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	repo "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/repo"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_repo"})

    		ubx.Data(repo.Repo, "example", repo.RepoConfig{
    			Owner:      "example",
    			Repo:       "example",
    			CreatorId:  []string{"example"},
    			Direction:  "example",
    			IsArchived: true,
    			Page:       1,
    			PerPage:    1,
    			Since:      "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="creator_id" type="list(number)">
  The real, numeric ID of the user who created this. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="direction" type="string">
  The sort direction, asc or desc. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="is_archived" type="bool">
  Whether the repository is currently archived, read-only. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="since" type="string">
  Only return results updated at or after this real timestamp. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort" type="string">
  The field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="state" type="string">
  The real, current state of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="tasks" type="list(object)">

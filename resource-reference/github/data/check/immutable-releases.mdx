`github_check_immutable_releases` reads whether immutable releases are currently enabled for a repository, preventing a published release's own tag and assets from being altered afterward.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go

    	check "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/check"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_check_immutable_releases"})

    		ubx.Data(check.ImmutableReleases, "example", check.ImmutableReleasesConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="enabled" type="bool">
  Whether immutable releases are enabled for the repository. Returned by the lookup.
</ResponseField>

<ResponseField name="enforced_by_owner" type="bool">
  Whether immutable releases are enforced by the repository owner. Returned by the lookup.
</ResponseField>

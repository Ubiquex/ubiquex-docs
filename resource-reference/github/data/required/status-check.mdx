`github_required_status_check` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against GitHub's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	required "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/required"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_required_status_check"})

    		ubx.Data(required.StatusCheck, "example", required.StatusCheckConfig{
    			Branch: "example",
    			Owner:  "example",
    			Repo:   "example",
    		})
    	}))
    }
    ```

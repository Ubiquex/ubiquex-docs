`github_required_status_check` reads which specific status check contexts a branch's own protection rule currently requires to pass before a merge is allowed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	required "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/required"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_required_status_check"})

    		ubx.Data(required.StatusCheck, "example", required.StatusCheckConfig{
    			Branch: "example",
    			Owner:  "example",
    			Repo:   "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="branch" type="string" required>
  The real branch name this result is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

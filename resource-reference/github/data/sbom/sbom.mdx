`github_sbom` exports a repository's own real, current dependency graph as an SPDX-format software bill of materials, the same real export `github_dependency_graph_spdx_sbom` provides.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sbom "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/sbom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_sbom"})

    		ubx.Data(sbom.Sbom, "example", sbom.SbomConfig{
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Sbom } from "@ubx/sdk-github/github/data/sbom/sbom";

    export default stack("example", () => {
      intent({ summary: "look up github_sbom" });

      data(Sbom, "example", {
        owner: "example",
        repo: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.github.data.sbom import Sbom, SbomConfig

    def describe():
        ubx.intent("look up github_sbom")

        ubx.data(Sbom, "example", SbomConfig(
            owner="example",
            repo="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="sbom_url" type="string">
  URL to poll for the SBOM export result. Returned by the lookup.
</ResponseField>

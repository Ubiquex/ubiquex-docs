## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	comment "github.com/ubiquex/ubx-sdk-github/sdk/go/github/data/comment"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up github_comment"})

    		ubx.Data(comment.Comment, "example", comment.CommentConfig{
    			CommentId: 1,
    			Owner:     "example",
    			Repo:      "example",
    			Content:   "example",
    			Page:      1,
    			PerPage:   1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="comment_id" type="number" required>
  The real, numeric ID of this comment. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="content" type="string">
  The real, base64-encoded content of this file. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The real account (user or organization) that owns the repository. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repo" type="string" required>
  The real repository's own name, without its owner. **(AI-inferred)** Required lookup argument.
</ResponseField>

`github_advanced_security_active_committers_repository` reads the real, per-repository count of unique committers GitHub Advanced Security bills for, the usage metric behind GHAS seat consumption.

## Lookup arguments

<ResponseField name="advanced_security_product" type="string">
  The real GitHub Advanced Security product this committer count is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="enterprise" type="string" required>
  The real enterprise account this result belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number of results to fetch, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="maximum_advanced_security_committers" type="number">
  The total number of GitHub Advanced Security licences required if all repositories were to enable GitHub Advanced Security Returned by the lookup.
</ResponseField>

<ResponseField name="purchased_advanced_security_committers" type="number">
  The total number of GitHub Advanced Security licences purchased Returned by the lookup.
</ResponseField>

<ResponseField name="repositories" type="list(object)">
  The real repositories included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_advanced_security_committers" type="number">
  The real, total count of unique committers billed for GitHub Advanced Security. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="total_count" type="number">
  The total number of results matching the request, across every page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

`github_runner_groups_org` controls real access to a set of self-hosted runners at the organization level -- every organization starts with one default group, and access policies on a custom group decide which repositories are even allowed to use the runners inside it.

## Input properties

<ResponseField name="allows_public_repositories" type="bool">
  Whether the runner group can be used by `public` repositories. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the runner group. Required.
</ResponseField>

<ResponseField name="network_configuration_id" type="string">
  The identifier of a hosted compute network configuration. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="restricted_to_workflows" type="bool">
  If `true`, the runner group will be restricted to running only the workflows specified in the `selected_workflows` array. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="runner_group_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="runners" type="list(number)">
  List of runner IDs to add to the runner group. Optional.
</ResponseField>

<ResponseField name="selected_repository_ids" type="list(number)">
  List of repository IDs that can access the runner group. Optional.
</ResponseField>

<ResponseField name="selected_workflows" type="list(string)">
  List of workflows the runner group should be allowed to run. This setting will be ignored unless `restricted_to_workflows` is set to `true`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="visibility" type="string">
  Visibility of a runner group. You can select all repositories, select individual repositories, or limit access to private repositories. Optional; if omitted, computed by GitHub.
</ResponseField>

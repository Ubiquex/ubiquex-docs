## Input properties

<ResponseField name="artifact_id" type="number">

</ResponseField>

<ResponseField name="artifact_url" type="string">
  The URL of an artifact that contains the .zip or .tar of static assets to deploy. The artifact belongs to the repository. Either `artifact_id` or `artifact_url` are required. Optional.
</ResponseField>

<ResponseField name="environment" type="string">
  The target environment for this GitHub Pages deployment. Optional.
</ResponseField>

</ResponseField>

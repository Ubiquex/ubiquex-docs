`github_pull_request_review` is a real, submitted verdict on a pull request's own changes -- approve, request changes, or comment -- the structured mechanism that turns informal feedback into an actual, trackable review a repository's own rules can require before merging.

## Input properties

<ResponseField name="body" type="string">
  **Required** when using `REQUEST_CHANGES` or `COMMENT` for the `event` parameter. The body text of the pull request review. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="comments" type="list(object)">
  Use the following table to specify the location, destination, and contents of the draft review comment. Optional.
  <Expandable title="properties">
    <ResponseField name="body" type="string">
      The text content of the review comment. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="line" type="number">
      The line number in the pull request diff that the comment applies to, based on the current version of the file. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="path" type="string">
      The path to the file in the repository that the comment is associated with, relative to the repository root. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="position" type="number">
      The line number in the pull request diff where the comment is located. Deprecated in favor of the 'line' field. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="side" type="string">
      The side of the diff to which the comment applies. Valid values are 'LEFT' and 'RIGHT'. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="start_line" type="number">
      For multi-line review comments, the line number in the diff where the comment begins. This is null for single-line comments. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="start_side" type="string">
      Indicates which side of the diff the start of a multi-line comment applies to. Valid values are 'LEFT' or 'RIGHT', with 'RIGHT' as the default. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="commit_id" type="string">
  The SHA of the commit that needs a review. Not using the latest commit SHA may render your review comment outdated if a subsequent commit modifies the line you specify as the `position`. Defaults to the most recent commit in the pull request when you do not specify a value. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="event" type="string">
  The review action you want to perform. The review actions include: `APPROVE`, `REQUEST_CHANGES`, or `COMMENT`. By leaving this blank, you set the review action state to `PENDING`, which means you will need to [submit the pull request review](https://docs.github.com/rest/pulls/reviews#submit-a-review-for-a-pull-request) when you are ready. Optional.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="pull_number" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="review_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

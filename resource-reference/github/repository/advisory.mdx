`github_repository_advisory` is a private, real space for a repository's own maintainers and a vulnerability reporter to discuss, fix, and prepare a security issue before it's ever disclosed publicly -- published only once a real patch is actually ready.

## Example

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    			StartPrivateFork: true,
    		})

## Input properties

<ResponseField name="credits" type="list(object)">
  A list of users receiving credit for their participation in the security advisory. Optional; if omitted, computed by GitHub.
  <Expandable title="properties">
    <ResponseField name="login" type="string">
      The GitHub username of the user receiving credit for the advisory. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      The role or classification of the credited entity in a GitHub repository advisory. Allowed values are analyst, finder, reporter, coordinator, remediation_developer, remediation_reviewer, remediation_verifier, tool, sponsor, and other. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cve_id" type="string">
  The Common Vulnerabilities and Exposures (CVE) ID. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="cvss_vector_string" type="string">
  The CVSS vector that calculates the severity of the advisory. You must choose between setting this field or `severity`. Optional.
</ResponseField>

<ResponseField name="cwe_ids" type="list(string)">
  A list of Common Weakness Enumeration (CWE) IDs. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="description" type="string" required>
  A detailed description of what the advisory impacts. Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="severity" type="string">
  The severity of the advisory. You must choose between setting this field or `cvss_vector_string`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="start_private_fork" type="bool">
  Whether to create a temporary private fork of the repository to collaborate on a fix. Optional.
</ResponseField>

<ResponseField name="summary" type="string" required>
  A short summary of the advisory. Required.
</ResponseField>

<ResponseField name="vulnerabilities" type="list(object)" required>
  A product affected by the vulnerability detailed in a repository security advisory. Required.
  <Expandable title="properties">
    <ResponseField name="package" type="object">
      The package affected by the vulnerability, including details such as its name and ecosystem. Optional; if omitted, computed by GitHub. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="ecosystem" type="string">
          The ecosystem of the affected package, such as rubygems, npm, pip, maven, nuget, composer, go, rust, erlang, actions, pub, swift, or other. This identifies the package manager or language ecosystem to which the package belongs. Optional; if omitted, computed by GitHub. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of the affected package within the specified ecosystem. Optional; if omitted, computed by GitHub. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="patched_versions" type="string">
      The range of versions that are patched by the security advisory for this vulnerability. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vulnerable_functions" type="list(string)">
      A list of names of functions within the affected package that are vulnerable to the advisory. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vulnerable_version_range" type="string">
      The vulnerable version range for the advisory, expressed as a semantic version range (e.g., '&gt;= 1.0.0, &lt; 2.0.0'). Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

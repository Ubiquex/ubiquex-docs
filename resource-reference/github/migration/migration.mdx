`github_migration` is a real, in-progress or completed transfer of repository (or, from GitHub.com, whole-organization) data into GitHub Enterprise Cloud via GitHub Enterprise Importer -- the API-driven path for advanced migrations too customized for the CLI tool most customers use instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only github --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-github/sdk/go => ./local-sdk/github/sdk/go
    package main

    import (
    	migration "github.com/ubiquex/ubx-sdk-github/sdk/go/github/migration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own migration"})

    		ubx.Resource(migration.Migration, "example", migration.MigrationConfig{
    			MigrationId:  "example",
    			Org:          "example",
    			Repositories: []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="exclude" type="list(string)">
  Exclude attributes from the API response to improve performance Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="exclude_attachments" type="bool">
  Do not include attachments in the migration Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="exclude_git_data" type="bool">
  Indicates whether the repository git data should be excluded from the migration. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="exclude_metadata" type="bool">
  Indicates whether metadata should be excluded and only git source should be included for the migration. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="exclude_owner_projects" type="bool">
  Indicates whether projects owned by the organization or users should be excluded. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="exclude_releases" type="bool">
  Do not include releases in the migration Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="lock_repositories" type="bool">
  Lock the repositories being migrated at the start of the migration Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="migration_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="org_metadata_only" type="bool">
  Indicates whether this should only include organization metadata (repositories array should be empty and will ignore other flags). Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="repositories" type="list(string)" required>
  The list of repositories to include in the migration. Each item typically identifies a repository (e.g., in 'owner/name' format) that will be migrated. Required. **(AI-inferred)**
</ResponseField>

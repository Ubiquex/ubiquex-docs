`github_job` is one real unit of work within an Actions workflow run -- a set of steps executed together on the same runner -- the actual thing a runner (hosted or self-hosted) picks up and works through from start to finish.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	job "github.com/ubiquex/ubx-sdk-github/sdk/go/github/job"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own job"})

    		ubx.Resource(job.Job, "example", job.JobConfig{
    			Cluster:             "example",
    			Deployments:         []map[string]any{{"name": "example-name"}},
    			LogicalEnvironment:  "example",
    			Org:                 "example",
    			PhysicalEnvironment: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cluster" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="deployments" type="list(object)" required>
  The list of deployments to record. Required.
  <Expandable title="properties">
    <ResponseField name="deployment_name" type="string">
      A human-readable name for a deployment associated with the job. Must be between 1 and 256 characters in length. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="digest" type="string">
      The SHA256 digest of the container image, formatted as `sha256:` followed by 64 lowercase hexadecimal characters (e.g., `sha256:abcdef...`). This uniquely identifies the image content. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="github_repository" type="string">
      The name of the GitHub repository, up to 100 characters, containing only alphanumeric characters, dots, hyphens, and underscores. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      Optional; if omitted, computed by GitHub.
    </ResponseField>
    <ResponseField name="runtime_risks" type="list(string)">
      Optional; if omitted, computed by GitHub.
    </ResponseField>
    <ResponseField name="status" type="string">
      The status of the deployment, which can be `deployed` or `decommissioned`. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="tags" type="map(string)">
      Optional; if omitted, computed by GitHub.
    </ResponseField>
    <ResponseField name="version" type="string">
      Optional; if omitted, computed by GitHub.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="logical_environment" type="string" required>
  The stage of the deployment. Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="physical_environment" type="string">
  The physical region of the deployment. Optional.
</ResponseField>

## Output properties

<ResponseField name="errors" type="list(any)">
  Processing errors (only present when completed or failed). Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="job_id" type="number">
  The ID of the job. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="started_at" type="string">
  When the job started processing (only present when processing, completed, or failed). Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the job. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="total_count" type="number">
  The number of records successfully mutated (only present when completed). Computed by GitHub after `ship`.
</ResponseField>

`github_network_configuration` is the real, organization- or enterprise-level construct that governs private networking for GitHub-hosted compute -- controlling outbound access, routing runner traffic through a private Azure VNet, and optionally a real failover subnet if the primary one becomes unavailable.

## Input properties

<ResponseField name="compute_service" type="string">
  The hosted compute service to use for the network configuration. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="failover_network_enabled" type="bool">
  Indicates whether the failover network resource is enabled. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="failover_network_settings_ids" type="list(string)">
  A list of identifiers of the failover network settings resources to use for the network configuration. Exactly one resource identifier must be specified in the list. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the network configuration. Must be between 1 and 100 characters and may only contain upper and lowercase letters a-z, numbers 0-9, '.', '-', and '_'. Required.
</ResponseField>

<ResponseField name="network_configuration_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="network_settings_ids" type="list(string)" required>
  A list of identifiers of the network settings resources to use for the network configuration. Exactly one resource identifier must be specified in the list. Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">

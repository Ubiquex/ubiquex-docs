`github_page_build` is one real run of GitHub Pages' own publish pipeline -- taking a repository's HTML, CSS, and JavaScript (optionally through Jekyll or another build tool first) and deploying the resulting static site to the web.

## Example

<Tabs>

    ```go
    package main

    import (
    	page "github.com/ubiquex/ubx-sdk-github/sdk/go/github/page"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own build"})

    		ubx.Resource(page.Build, "example", page.BuildConfig{
    			BuildId: "example",
    			Owner:   "example",
    			Repo:    "example",
    		})
    	}))
    }
    ```

## Output properties

<ResponseField name="commit" type="string">
  The SHA of the commit that this page build was triggered by or built from. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_at" type="string">
  The date and time when the page build was created. This value is set by GitHub and is not editable. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="duration" type="number">
  The duration of the page build, in seconds, as computed by the system after the build completes. Computed by GitHub after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="error" type="object">
  An object containing error details for the GitHub Pages build, if any. This computed field is present only when the build encounters an error. Computed by GitHub after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="message" type="string" required>
      The error message describing why the page build failed. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`github_deployment` is a real request to deploy a specific ref -- a branch, a SHA, a tag -- that GitHub turns into a `deployment` event external services can listen for and act on, the API-level record of a deployment actually having been requested.

## Input properties

<ResponseField name="auto_merge" type="bool">
  Attempts to automatically merge the default branch into the requested ref, if it's behind the default branch. Optional.
</ResponseField>

<ResponseField name="deployment_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="description" type="string">
  Short description of the deployment. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="environment" type="string">
  Name for the target deployment environment (e.g., `production`, `staging`, `qa`). Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="payload" type="any">
  The payload of the deployment, a free-form JSON object passed to the deployment task. Optional; if omitted, computed by GitHub. **(AI-inferred)**
</ResponseField>

<ResponseField name="production_environment" type="bool">
  Specifies if the given environment is one that end-users directly interact with. Default: `true` when `environment` is `production` and `false` otherwise. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="ref" type="string" required>
  The ref to deploy. This can be a branch, tag, or SHA. Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="required_contexts" type="list(string)">
  The [status](https://docs.github.com/rest/commits/statuses) contexts to verify against commit status checks. If you omit this parameter, GitHub verifies all unique contexts before creating a deployment. To bypass checking entirely, pass an empty array. Defaults to all unique contexts. Optional.
</ResponseField>

<ResponseField name="task" type="string">
  Specifies a task to execute (e.g., `deploy` or `deploy:migrations`). Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="transient_environment" type="bool">
  Specifies if the given environment is specific to the deployment and will no longer exist at some point in the future. Default: `false` Optional; if omitted, computed by GitHub.
</ResponseField>

`github_deployment_protection_rule` is a real, custom gate a deployment to a protected environment must pass before it's allowed to proceed -- configured, created, and deleted through the same API, giving an external system its own say in whether a deployment continues.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	deployment "github.com/ubiquex/ubx-sdk-github/sdk/go/github/deployment"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own protection rule"})

    		ubx.Resource(deployment.ProtectionRule, "example", deployment.ProtectionRuleConfig{
    			EnvironmentName:  "example-environment-name",
    			Owner:            "example",
    			ProtectionRuleId: "example",
    			Repo:             "example",
    			IntegrationId:    1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="environment_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="integration_id" type="number">
  The ID of the custom app that will be enabled on the environment. Optional.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="protection_rule_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="app" type="object">
  A GitHub App that is providing a custom deployment protection rule. Computed by GitHub after `ship`.
  <Expandable title="properties">
    <ResponseField name="id" type="number" required>
      The unique identifier of the deployment protection rule integration. Required.
    </ResponseField>
    <ResponseField name="integration_url" type="string" required>
      The URL for the endpoint to get details about the app. Required.
    </ResponseField>
    <ResponseField name="node_id" type="string" required>
      The node ID for the deployment protection rule integration. Required.
    </ResponseField>
    <ResponseField name="slug" type="string" required>
      The slugified name of the deployment protection rule integration. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="enabled" type="bool">
  Whether the deployment protection rule is enabled for the environment. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="id" type="number">
  The unique identifier for the deployment protection rule. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="node_id" type="string">
  The node ID for the deployment protection rule. Computed by GitHub after `ship`.
</ResponseField>

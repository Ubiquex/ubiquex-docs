`github_deploy_key` is an SSH key attached directly to one repository rather than to a personal account -- the public half lives on the repository, the private half stays on the server that needs access, with no expiration date, making it the real fit for automated deployments that shouldn't depend on any one person's own credentials.

## Example

    package main

    import (
    	deploy "github.com/ubiquex/ubx-sdk-github/sdk/go/github/deploy"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key"})

    		ubx.Resource(deploy.Key, "example", deploy.KeyConfig{
    			Key:   "example",
    			KeyId: "example",
    			Owner: "example",
    			Repo:  "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="key" type="string" required>
  The contents of the key. Required.
</ResponseField>

<ResponseField name="key_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="read_only" type="bool">
  If `true`, the key will only be able to read repository contents. Otherwise, the key will be able to read and write. Deploy keys with write access can perform the same actions as an organization member with admin access, or a collaborator on a personal repository. For more information, see "[Repository permission levels for an organization](https://docs.github.com/articles/repository-permission-levels-for-an-organization/)" and "[Permission levels for a user account repository](https://docs.github.com/articles/permission-levels-for-a-user-account-repository/)." Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="repo" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="title" type="string">
  A name for the key. Optional; if omitted, computed by GitHub.
</ResponseField>

`github_deploy_key` is an SSH key attached directly to one repository rather than to a personal account -- the public half lives on the repository, the private half stays on the server that needs access, with no expiration date, making it the real fit for automated deployments that shouldn't depend on any one person's own credentials.

Real, typed bindings generated directly from the real GitHub REST API OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

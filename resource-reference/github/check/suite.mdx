`github_check_suite` is the real collection of every check run one GitHub App created for a single commit, automatically created the moment that commit is pushed -- the grouping check runs belong to, not something created directly on its own.

## Example

    	check "github.com/ubiquex/ubx-sdk-github/sdk/go/github/check"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			HeadSha:      "example",
    			Owner:        "example",
    			Repo:         "example",
    		})
    	}))
    }

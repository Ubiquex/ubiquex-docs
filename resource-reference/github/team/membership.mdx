`github_team_membership` records one real person's own place inside a team -- member or maintainer -- which is what actually determines whether they inherit that team's own repository permissions and get included in its notifications and review requests.

Real, typed bindings generated directly from the real GitHub REST API OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

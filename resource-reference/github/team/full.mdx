`github_team_full` is a real group of organization members reflecting a company's own structure, with access permissions that cascade down through nested teams -- the mechanism for granting repository access to a whole group at once instead of adding people individually.

## Input properties

<ResponseField name="description" type="string">
  The description of the team. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="maintainers" type="list(string)">
  List GitHub usernames for organization members who will become team maintainers. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the team. Required.
</ResponseField>

<ResponseField name="notification_setting" type="string">
  The notification setting the team has chosen. The options are: * `notifications_enabled` - team members receive notifications when the team is @mentioned. * `notifications_disabled` - no one receives notifications. Default: `notifications_enabled` Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="parent_team_id" type="number">
  The ID of a team to set as the parent team. Optional.
</ResponseField>

<ResponseField name="parent_team_slug" type="string">
  The slug of a team to set as the parent team. Ignored when `parent_team_id` is also provided. Optional.
</ResponseField>

<ResponseField name="permission" type="string">
  **Closing down notice**. The permission that new repositories will be added to the team with when none is specified. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="privacy" type="string">
  The level of privacy this team should have. The options are: **For a non-nested team:** * `secret` - only visible to organization owners and members of this team. * `closed` - visible to all members of this organization. Default: `secret` **For a parent or child team:** * `closed` - visible to all members of this organization. Default for child team: `closed` Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="repo_names" type="list(string)">
  The full name (e.g., "organization-name/repository-name") of repositories to add the team to. Optional.
</ResponseField>

<ResponseField name="team_slug" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

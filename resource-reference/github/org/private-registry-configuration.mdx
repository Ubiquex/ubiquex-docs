`github_org_private_registry_configuration` stores the real credentials an organization's own Actions workflows use to pull from a private package registry -- npm, Docker, or another supported registry -- configured once centrally rather than duplicated into every workflow that needs it.

## Input properties

<ResponseField name="account_id" type="string">
  The AWS account ID. Required when `auth_type` is `oidc_aws`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="api_host" type="string">
  The Cloudsmith API host. Optional for `oidc_cloudsmith` auth type. If omitted, `api.cloudsmith.io` is used by default. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="audience" type="string">
  The OIDC audience. Optional for `oidc_aws`, `oidc_jfrog`, and `oidc_gcp`, and required for `oidc_cloudsmith` auth types. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="auth_type" type="string">
  The authentication type for the private registry. Defaults to `token` if not specified. Use `oidc_azure`, `oidc_aws`, `oidc_jfrog`, `oidc_cloudsmith`, or `oidc_gcp` for OIDC authentication. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="aws_region" type="string">
  The AWS region. Required when `auth_type` is `oidc_aws`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="client_id" type="string">
  The client ID of the Azure AD application. Required when `auth_type` is `oidc_azure`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="domain" type="string">
  The CodeArtifact domain. Required when `auth_type` is `oidc_aws`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="domain_owner" type="string">
  The CodeArtifact domain owner (AWS account ID). Required when `auth_type` is `oidc_aws`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="encrypted_value" type="string">
  The value for your secret, encrypted with [LibSodium](https://libsodium.gitbook.io/doc/bindings_for_other_languages) using the public key retrieved from the [Get private registries public key for an organization](https://docs.github.com/rest/private-registries/organization-configurations#get-private-registries-public-key-for-an-organization) endpoint. Required when `auth_type` is `token` or `username_password`. Should be omitted for OIDC auth types. Optional.
</ResponseField>

<ResponseField name="identity_mapping_name" type="string">
  The JFrog identity mapping name. Optional for `oidc_jfrog` auth type. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="jfrog_oidc_provider_name" type="string">
  The JFrog OIDC provider name. Required when `auth_type` is `oidc_jfrog`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="key_id" type="string">
  The ID of the key you used to encrypt the secret. Required when `auth_type` is `token` or `username_password`. Should be omitted for OIDC auth types. Optional.
</ResponseField>

<ResponseField name="namespace" type="string">
  The Cloudsmith organization namespace. Required when `auth_type` is `oidc_cloudsmith`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="registry_type" type="string" required>
  The registry type. Required.
</ResponseField>

<ResponseField name="replaces_base" type="bool">
  Whether this private registry should replace the base registry (e.g., npmjs.org for npm, rubygems.org for rubygems). When set to `true`, Dependabot will only use this registry and will not fall back to the public registry. When set to `false` (default), Dependabot will use this registry for scoped packages but may fall back to the public registry for other packages. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="role_name" type="string">
  The AWS IAM role name. Required when `auth_type` is `oidc_aws`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="secret_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="selected_repository_ids" type="list(number)">
  An array of repository IDs that can access the organization private registry. You can only provide a list of repository IDs when `visibility` is set to `selected`. You can manage the list of selected repositories using the [Update a private registry for an organization](https://docs.github.com/rest/private-registries/organization-configurations#update-a-private-registry-for-an-organization) endpoint. This field should be omitted if `visibility` is set to `all` or `private`. Optional.
</ResponseField>

<ResponseField name="service_account" type="string">
  The GCP service account email to impersonate. Optional for `oidc_gcp` auth type. If omitted, the federated token is used directly (direct WIF). Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="service_slug" type="string">
  The Cloudsmith service account slug. Required when `auth_type` is `oidc_cloudsmith`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="tenant_id" type="string">
  The tenant ID of the Azure AD application. Required when `auth_type` is `oidc_azure`. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="url" type="string" required>
  The URL of the private registry. Required.
</ResponseField>

<ResponseField name="username" type="string">
  The username to use when authenticating with the private registry. This field should be omitted if the private registry does not require a username for authentication. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="visibility" type="string" required>
  Which type of organization repositories have access to the private registry. `selected` means only the repositories specified by `selected_repository_ids` can access the private registry. Required.
</ResponseField>

<ResponseField name="workload_identity_provider" type="string">
  The full resource name of the GCP Workload Identity Provider (e.g. `projects/&lt;NUM&gt;/locations/global/workloadIdentityPools/&lt;POOL&gt;/providers/&lt;PROVIDER&gt;`). Required when `auth_type` is `oidc_gcp`. Optional; if omitted, computed by GitHub.
</ResponseField>

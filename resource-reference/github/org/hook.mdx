`github_org_hook` is a webhook scoped to an entire organization rather than one repository -- the same real event-delivery mechanism, applied once at the org level instead of being configured separately on every repository inside it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	org "github.com/ubiquex/ubx-sdk-github/sdk/go/github/org"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hook"})

    		ubx.Resource(org.Hook, "example", org.HookConfig{
    			Config: map[string]any{"url": "example"},
    			HookId: "example",
    			Name:   "example",
    			Org:    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="active" type="bool">
  Determines if notifications are sent when the webhook is triggered. Set to `true` to send notifications. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="config" type="object" required>
  Key/value pairs to provide settings for this webhook. Required.
  <Expandable title="properties">
    <ResponseField name="content_type" type="string">
      The media type used to serialize the payloads. Supported values include `json` and `form`. The default is `form`. Optional.
    </ResponseField>
    <ResponseField name="insecure_ssl" type="any">
      Controls whether SSL verification is enabled for webhook deliveries. Set to '1' or true to ignore SSL certificate errors, or '0' or false to require valid certificates. Accepts both boolean and string values due to its dynamic type. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="password" type="string">
      Optional.
    </ResponseField>
    <ResponseField name="secret" type="string">
      If provided, the `secret` will be used as the `key` to generate the HMAC hex digest value for [delivery signature headers](https://docs.github.com/webhooks/event-payloads/#delivery-headers). Optional.
    </ResponseField>
    <ResponseField name="url" type="string" required>
      The URL to which the payloads will be delivered. Required.
    </ResponseField>
    <ResponseField name="username" type="string">
      Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="events" type="list(string)">
  Determines what [events](https://docs.github.com/webhooks/event-payloads) the hook is triggered for. Set to `["*"]` to receive all possible events. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="hook_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  Must be passed as "web". Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

`github_org_membership` records one real user's own role inside an organization -- `admin` (owner-level access) or `member` (everything else) -- and only an existing organization owner can create or change it; promoting someone to admin sends them a real notification email, demoting an owner does not.

## Input properties

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="role" type="string">
  The role to give the user in the organization. Can be one of: * `admin` - The user will become an owner of the organization. * `member` - The user will become a non-owner member of the organization. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="username" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

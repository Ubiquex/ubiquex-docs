`github_scim_user` is a SCIM-provisioned organization member -- the org-scoped counterpart to `github_scim_enterprise_user_response`, synced by an organization's own connected identity provider rather than the enterprise-wide one. Represents one real person's provisioned GitHub organization membership and its current active/inactive state.

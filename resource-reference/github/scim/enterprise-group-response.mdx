`github_scim_enterprise_group_response` is a SCIM-provisioned group at the enterprise level -- its display name, external ID from the identity provider, and real member list -- kept in sync by an enterprise's own SSO/identity provider (Okta, Azure AD, and similar) rather than managed by hand inside GitHub. Enterprises with SCIM provisioning enabled use groups like this to drive automatic team membership from their own IdP.

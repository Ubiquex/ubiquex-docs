`github_scim_enterprise_user_response` is a SCIM-provisioned enterprise member -- their real identity attributes (name, emails, roles, active status) as synced from the enterprise's own identity provider, the standard mechanism large organizations use to add, update, and deactivate GitHub access automatically as employees join, move, or leave.

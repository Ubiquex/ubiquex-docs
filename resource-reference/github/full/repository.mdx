`github_full_repository` is the complete, real record of a repository -- code, files, and their revision history -- along with every setting and permission attached to it, the base unit almost every other GitHub resource in this reference is scoped underneath.

## Example

<Tabs>

    ```go
    import (
    	full "github.com/ubiquex/ubx-sdk-github/sdk/go/github/full"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own repository"})

    		ubx.Resource(full.Repository, "example", full.RepositoryConfig{
    			Name:              "example",
    			OwnerPath:         "example",
    			Repo:              "example",
    			AutoInit:          true,
    			GitignoreTemplate: "example",
    			LicenseTemplate:   "example",
    			TeamId:            1,
    		})
    	}))
    }
    ```

<ResponseField name="squash_merge_commit_title" type="string">
  Required when using `squash_merge_commit_message`. The default value for a squash merge commit title: - `PR_TITLE` - default to the pull request's title. - `COMMIT_OR_PR_TITLE` - default to the commit's title (if only one commit) or the pull request's title (when more than one commit). Optional; if omitted, computed by GitHub.

  The id of the team that will be granted access to this repository. This is only valid when creating a repository in an organization. Optional.
</ResponseField>

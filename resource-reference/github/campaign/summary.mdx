`github_campaign_summary` groups a real set of code scanning or secret scanning alerts into one trackable effort, shared with the developers who need to fix them. Code-scanning campaigns automatically trigger Copilot Autofix for every included alert, and a campaign's own tracking view shows real progress toward remediation across however many repositories it spans.

## Input properties

<ResponseField name="campaign_number" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="code_scanning_alerts" type="list(object)">
  The code scanning alerts to include in this campaign Optional.
  <Expandable title="properties">
    <ResponseField name="alert_numbers" type="list(number)">
      The list of alert numbers for the code scanning alerts in this campaign summary. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="repository_id" type="number">
      The numeric identifier of the repository in which the code scanning alert was found. Optional; if omitted, computed by GitHub. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contact_link" type="string">
  The contact link of the campaign. Must be a URI. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="description" type="string" required>
  A description for the campaign Required.
</ResponseField>

<ResponseField name="ends_at" type="string" required>
  The end date and time of the campaign. The date must be in the future. Required.
</ResponseField>

<ResponseField name="generate_issues" type="bool">
  If true, will automatically generate issues for the campaign. The default is false. Optional.
</ResponseField>

<ResponseField name="managers" type="list(string)">
  The logins of the users to set as the campaign managers. At this time, only a single manager can be supplied. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the campaign Required.
</ResponseField>

<ResponseField name="org" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="team_managers" type="list(string)">
  The slugs of the teams to set as the campaign managers. Optional; if omitted, computed by GitHub.
</ResponseField>

## Output properties

<ResponseField name="alert_stats" type="object">
  Computed by GitHub after `ship`.
  <Expandable title="properties">
    <ResponseField name="closed_count" type="number" required>
      The number of closed alerts Required.
    </ResponseField>
    <ResponseField name="in_progress_count" type="number" required>
      The number of in-progress alerts Required.
    </ResponseField>
    <ResponseField name="open_count" type="number" required>
      The number of open alerts Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="closed_at" type="string">
  The date and time the campaign was closed, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Will be null if the campaign is still open. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="contact_link" type="string">
  The contact link of the campaign. Must be a URI. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="created_at" type="string">
  The date and time the campaign was created, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="managers" type="list(string)">
  The logins of the users to set as the campaign managers. At this time, only a single manager can be supplied. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="number" type="number">
  The number of the newly created campaign Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="published_at" type="string">
  The date and time the campaign was published, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  Indicates whether a campaign is open or closed Computed by GitHub after `ship`.
</ResponseField>

<ResponseField name="team_managers" type="list(string)">
  The slugs of the teams to set as the campaign managers. Optional; if omitted, computed by GitHub.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time the campaign was last updated, in ISO 8601 format':' YYYY-MM-DDTHH:MM:SSZ. Computed by GitHub after `ship`.
</ResponseField>

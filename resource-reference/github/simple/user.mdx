`github_simple_user` is the minimal, real identity record behind a GitHub account -- username, ID, avatar, profile URL -- the compact shape GitHub's own API returns whenever a resource needs to reference a user without pulling their entire, full account record.

## Example

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own user"})

    		ubx.Resource(simple.User, "ci-runner", simple.UserConfig{

    			Username:   "example",
    		})
    	}))
    }

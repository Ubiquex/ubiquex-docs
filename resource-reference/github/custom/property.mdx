`github_custom_property` is a structured metadata field an organization defines and attaches to its own repositories -- text, a single or multi-select value, or a boolean -- used to target repositories with rulesets and drive real governance and automation without relying on naming conventions alone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	custom "github.com/ubiquex/ubx-sdk-github/sdk/go/github/custom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own property"})

    		ubx.Resource(custom.Property, "example", custom.PropertyConfig{
    			CustomPropertyName: "example-custom-property-name",
    			Enterprise:         "example",
    			ValueType:          "example",
    		})
    	}))
    }
    ```
  </Tab>

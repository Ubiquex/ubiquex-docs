---

`kubernetes_rbac_cluster_role` defines a real set of permissions that apply cluster-wide, across every namespace, or to cluster-scoped resources that don't belong to any namespace at all -- the RBAC building block for something like `view all pods everywhere`, not one namespace's own scope.

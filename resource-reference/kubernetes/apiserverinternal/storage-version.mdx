`kubernetes_apiserverinternal_storage_version` records which real, actual API version each `kube-apiserver` replica currently uses to persist a given resource to etcd -- the internal bookkeeping that makes it safe to run mixed-version API servers during a rolling upgrade without silently corrupting stored data.

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own storage version"})

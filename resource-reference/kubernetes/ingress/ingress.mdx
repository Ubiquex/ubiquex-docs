`kubernetes_ingress` -- real, typed bindings generated directly from the
`hashicorp/kubernetes` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/ingress"
    )

    cfg := ingress.IngressConfig{
        WaitForLoadBalancer: true,
    }
    ubx.Resource(ingress.Ingress, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Ingress } from
      "jsr:@ubx/sdk-kubernetes/kubernetes/ingress/ingress";

    resource(Ingress, "example", {
      waitForLoadBalancer: true,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.kubernetes.ingress import Ingress, IngressConfig

    cfg = IngressConfig(
        wait_for_load_balancer=True,
    )
    ubx.resource(Ingress, "example", cfg)
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Provision kubernetes_ingress with wait_for_load_balancer.
    ```
  </Tab>
</Tabs>

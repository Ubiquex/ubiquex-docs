title: "kubernetes_networking_ipaddress"
description: "`kubernetes_networking_ipaddress` records one real IP address actually allocated to a Service..."
---

`kubernetes_networking_ipaddress` records one real IP address actually allocated to a Service, tracked as its own object rather than implicitly -- part of the newer allocator that lets a cluster's own set of usable Service IPs grow by adding another ServiceCIDR instead of being fixed at cluster creation.

## Example

    ```go
    package main

    import (

    	networking "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/networking"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own ipaddress"})

    		ubx.Resource(networking.Ipaddress, "ci-runner", networking.IpaddressConfig{
    			Name: "ci-runner",
    			Spec: map[string]any{"parent_ref": map[string]any{"name": "example-name"}},
    		})
    	}))
    }
    ```

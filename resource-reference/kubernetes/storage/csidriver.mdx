`kubernetes_storage_csidriver` registers a real Container Storage Interface driver with the cluster, declaring what it actually supports -- volume attach/detach, expansion, snapshotting -- so Kubernetes knows which real operations it can ask that driver to perform.

Real, typed bindings generated directly from the real Kubernetes OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

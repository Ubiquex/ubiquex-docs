`kubernetes_storage_volume_attachment` is the real, internal record of one volume actually attached to one node -- API-server-managed detail a CSI driver and the attach/detach controller use to coordinate, not something a workload references directly.

## Example

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own volume attachment"})

    		ubx.Resource(storage.VolumeAttachment, "example", storage.VolumeAttachmentConfig{

    			Spec: map[string]any{"attacher": "example"},

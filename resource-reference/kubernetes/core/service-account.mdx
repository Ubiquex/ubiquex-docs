`kubernetes_core_service_account` is a real identity a pod authenticates to the Kubernetes API as -- distinct from a human user account -- and is what RBAC RoleBindings actually grant permissions to when a workload, not a person, needs to call the API.

Real, typed bindings generated directly from the real Kubernetes OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

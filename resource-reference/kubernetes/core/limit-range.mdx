---

`kubernetes_core_limit_range` sets real default and boundary constraints on compute resource requests and limits for every pod or container created in a namespace, so a workload that forgets to specify its own limits doesn't silently consume unbounded resources.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	core "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/core"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own limit range"})

    		ubx.Resource(core.LimitRange, "example", core.LimitRangeConfig{
    			Name:      "example",
    			Namespace: "example",
    		})
    	}))
    }
    ```
  </Tab>

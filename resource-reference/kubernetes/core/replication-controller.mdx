`kubernetes_core_replication_controller` is the original, real mechanism for keeping a stable count of identical pods running -- functionally superseded by ReplicaSet (and, above that, Deployment) for new workloads, but still real, supported API surface.

## Example

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own replication controller"})

    		ubx.Resource(core.ReplicationController, "example", core.ReplicationControllerConfig{

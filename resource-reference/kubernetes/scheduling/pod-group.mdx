`kubernetes_scheduling_pod_group` is the real, runtime instance of a group of pods that must be scheduled together as a single unit -- if the scheduler can't place every pod in the group, none of them get bound, the mechanism behind real gang scheduling for distributed training and similar all-or-nothing workloads. This is the `scheduling.k8s.io/v1beta1` shape, the real, current generation gang-scheduled workloads should target -- the Workload/PodGroup APIs moved from an original `v1alpha2` generation (entirely removed in a later release) to `v1alpha3` (`kubernetes_scheduling_v1alpha3_pod_group`, still served but older) to this v1beta1 generation.

    func main() {

    			Namespace: "example",

    		})
    	}))
    }

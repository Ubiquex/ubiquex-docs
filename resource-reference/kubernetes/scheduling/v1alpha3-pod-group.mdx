The real, older `scheduling.k8s.io/v1alpha3` shape of `kubernetes_scheduling_pod_group`, still served for compatibility but not the current one -- that's the plain, unversioned sibling (`v1beta1`), the generation new gang-scheduled workloads should actually target.

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha3 pod group"})

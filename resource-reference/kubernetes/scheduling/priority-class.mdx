title: "kubernetes_scheduling_priority_class"
description: "`kubernetes_scheduling_priority_class` names a real priority level pods can reference..."
---

`kubernetes_scheduling_priority_class` names a real priority level pods can reference, which the scheduler uses to decide which pending pod gets scheduled first, and which lower-priority pods can be preempted to make room for a higher-priority one under real resource pressure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	scheduling "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/scheduling"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own priority class"})

    		ubx.Resource(scheduling.PriorityClass, "example", scheduling.PriorityClassConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

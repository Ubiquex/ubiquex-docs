---

`kubernetes_apiextensions_custom_resource_definition` defines a real, new resource type -- its own schema, its own API group and version -- that the Kubernetes API server then serves exactly like a built-in type. It's the real foundation every operator and every custom controller pattern in the ecosystem is built on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only kubernetes --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-kubernetes/sdk/go => ./local-sdk/kubernetes/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apiextensions "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/apiextensions"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own custom resource definition"})

    		ubx.Resource(apiextensions.CustomResourceDefinition, "ci-runner", apiextensions.CustomResourceDefinitionConfig{
    			Name: "ci-runner",
    			Spec: map[string]any{"group": "example"},
    		})
    	}))
    }
    ```

`kubernetes_flowcontrol_flow_schema` classifies incoming API server requests into a real priority level based on who's making them -- the mechanism behind API Priority and Fairness, which stops one noisy client from starving every other real client's own requests during a busy period.

Real, typed bindings generated directly from the real Kubernetes OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

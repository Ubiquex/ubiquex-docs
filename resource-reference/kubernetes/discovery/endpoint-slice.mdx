`kubernetes_discovery_endpoint_slice` is the real, scalable replacement for the older Endpoints resource -- splitting a Service's own backing endpoints across multiple, smaller objects so a Service with thousands of real pods doesn't force every watcher to process one enormous, constantly-changing record.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discovery "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/discovery"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint slice"})

    		ubx.Resource(discovery.EndpointSlice, "example", discovery.EndpointSliceConfig{
    			AddressType: "example",
    			Name:        "example",
    			Namespace:   "example",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="address_type" type="string" required>
  addressType specifies the type of address carried by this EndpointSlice. All addresses in this slice must be the same type. This field is immutable after creation. The following address types are currently supported: * IPv4: Represents an IPv4 Address. * IPv6: Represents an IPv6 Address. * FQDN: Represents a Fully Qualified Domain Name. (Deprecated) The EndpointSlice controller only generates, and kube-proxy only processes, slices of addressType "IPv4" and "IPv6". No semantics are defined for the "FQDN" type. Required.
</ResponseField>

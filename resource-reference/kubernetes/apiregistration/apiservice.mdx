---

`kubernetes_apiregistration_apiservice` registers a real, separate API server -- an extension API server, not the main one -- to handle requests for one specific API group and version, letting the main API server transparently proxy those requests to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apiregistration "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/apiregistration"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own apiservice"})

    		ubx.Resource(apiregistration.Apiservice, "example", apiregistration.ApiserviceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

These are sorted first by GA &gt; beta &gt; alpha (where GA is a version with no suffix such as beta or alpha), and then by comparing major version, then minor version.

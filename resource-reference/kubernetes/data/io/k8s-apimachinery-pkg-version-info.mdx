`kubernetes_io_k8s_apimachinery_pkg_version_info` reads the real Kubernetes version the API server is currently running -- major, minor, git version, build date, platform -- the same information `kubectl version` reports, useful for a stack that needs to branch on cluster version rather than assume one.

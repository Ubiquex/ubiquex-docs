`kubernetes_batch_job` looks up a real Job running one or more pods to completion for a one-off or parallelizable task, tracking real success and retrying on failure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	batch "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/data/batch"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up kubernetes_batch_job"})

    		ubx.Data(batch.Job, "example", batch.JobConfig{})
    	}))
    }
    ```
  </Tab>

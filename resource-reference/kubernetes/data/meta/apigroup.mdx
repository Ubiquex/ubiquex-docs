`kubernetes_meta_apigroup` reads one real API group the cluster's API server currently serves -- its name and the API versions available within it -- part of the same discovery mechanism `kubectl api-versions` uses.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	meta "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/data/meta"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up kubernetes_meta_apigroup"})

    		ubx.Data(meta.Apigroup, "example", meta.ApigroupConfig{})
    	}))
    }
    ```

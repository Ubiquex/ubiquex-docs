`kubernetes_config_map` -- real, typed bindings generated directly from the
`hashicorp/kubernetes` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-kubernetes-go/kubernetes/config"
    )

    cfg := config.MapConfig{
        BinaryData: map[string]string{"key": "value"},
        Data: map[string]string{"key": "value"},
    }
    ubx.Resource(config.Map, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Map } from
      "jsr:@ubx/sdk-kubernetes/kubernetes/config/map";

    resource(Map, "example", {
      binaryData: { key: "value" },
      data: { key: "value" },
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.kubernetes.config import Map, MapConfig

    cfg = MapConfig(
        binary_data={"key": "value"},
        data={"key": "value"},
    )
    ubx.resource(Map, "example", cfg)
    ```
  </Tab>
  <Tab title="Markdown">

  </Tab>

`kubernetes_labels` -- real, typed bindings generated directly from the
`hashicorp/kubernetes` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/labels"
    )

    cfg := labels.LabelsConfig{
        ApiVersion: "example",
        Kind: "example",
        Labels: map[string]string{"key": "value"},
        FieldManager: "example",
        Force: true,
    }
    ubx.Resource(labels.Labels, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Labels } from
      "jsr:@ubx/sdk-kubernetes/kubernetes/labels/labels";

    resource(Labels, "example", {
      apiVersion: "example",
      kind: "example",
      labels: { key: "value" },
      fieldManager: "example",
      force: true,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.kubernetes.labels import Labels, LabelsConfig

    cfg = LabelsConfig(
        api_version="example",
        kind="example",
        labels={"key": "value"},
        field_manager="example",
        force=True,
    )
    ubx.resource(Labels, "example", cfg)
    ```

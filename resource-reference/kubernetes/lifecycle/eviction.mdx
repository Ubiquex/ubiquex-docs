`kubernetes_lifecycle_eviction` requests the real, graceful removal of a pod, respecting that pod's own PodDisruptionBudget rather than deleting it outright -- the mechanism `kubectl drain` and the cluster autoscaler both use so a voluntary disruption doesn't take down more of an application than its own budget allows.

Real, typed bindings generated directly from the real Kubernetes OpenAPI specification, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

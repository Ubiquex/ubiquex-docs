`kubernetes_lifecycle_eviction_request` is a newer, coordinated eviction mechanism that lets a workload controller intercept a pending eviction and migrate the real pod gracefully -- checkpointing state, moving a connection -- before falling back to a real, standard eviction if nothing intercepts it in time.

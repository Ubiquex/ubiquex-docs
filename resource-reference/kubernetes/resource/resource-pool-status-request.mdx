`kubernetes_resource_resource_pool_status_request` asks for a real, point-in-time snapshot of device availability -- total, allocated, available, unavailable -- for a specific driver's own resource pool under Dynamic Resource Allocation, the mechanism for actually checking real hardware capacity before assuming a claim will succeed.

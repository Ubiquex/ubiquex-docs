The v1beta1 shape of `kubernetes_resource_device_class` -- Dynamic Resource Allocation's own pre-GA API generation, one step before the resource.k8s.io/v1beta2 shape and two before the now-stable v1 API DRA's core graduated to in Kubernetes 1.34. Kept being served during the deprecation window; new device classes should target the stable `kubernetes_resource_device_class` instead.

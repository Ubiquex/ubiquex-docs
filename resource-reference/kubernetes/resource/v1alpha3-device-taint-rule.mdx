The v1alpha3 shape of `kubernetes_resource_device_taint_rule` -- DeviceTaintRule's original, alpha-numbered API version string (KEP-5055), kept even after the feature itself reached beta-quality stability in Kubernetes 1.36 without a matching version-string rename. Kept being served alongside the resource's own current, stable v1 API this cluster's own pinned schema also carries; new taint rules should target the stable `kubernetes_resource_device_taint_rule` instead.

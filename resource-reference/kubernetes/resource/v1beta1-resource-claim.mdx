The v1beta1 shape of `kubernetes_resource_resource_claim` -- Dynamic Resource Allocation's own pre-GA API generation, one step before the resource.k8s.io/v1beta2 shape and two before the now-stable v1 API DRA's core graduated to in Kubernetes 1.34. Kept being served during the deprecation window; new claims should target the stable `kubernetes_resource_resource_claim` instead.

    import (

    func main() {

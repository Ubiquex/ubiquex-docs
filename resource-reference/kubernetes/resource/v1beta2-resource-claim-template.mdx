The v1beta2 shape of `kubernetes_resource_resource_claim_template` -- Dynamic Resource Allocation's own later pre-GA API generation, one step past v1beta1 and one step before the now-stable v1 API DRA's core graduated to in Kubernetes 1.34. Kept being served during the deprecation window; new templates should target the stable `kubernetes_resource_resource_claim_template` instead.

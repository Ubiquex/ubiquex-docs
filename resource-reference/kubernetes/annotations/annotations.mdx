`kubernetes_annotations` -- real, typed bindings generated directly from the
`hashicorp/kubernetes` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/annotations"
    )

    cfg := annotations.AnnotationsConfig{
        ApiVersion: "example",
        Kind: "example",
        Annotations: map[string]string{"key": "value"},
        FieldManager: "example",
    }
    ubx.Resource(annotations.Annotations, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Annotations } from
      "jsr:@ubx/sdk-kubernetes/kubernetes/annotations/annotations";

    resource(Annotations, "example", {
      apiVersion: "example",
      kind: "example",
      annotations: { key: "value" },
      fieldManager: "example",
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.kubernetes.annotations import (
        Annotations,
        AnnotationsConfig,
    )

    cfg = AnnotationsConfig(
        api_version="example",
        kind="example",
        annotations={"key": "value"},
        field_manager="example",
    )
    ubx.resource(Annotations, "example", cfg)
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Provision kubernetes_annotations with api_version, kind,
annotations, field_manager.
    ```
  </Tab>
</Tabs>

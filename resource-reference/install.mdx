Every SDK language needs exactly two real, published packages: the
shared **runtime** (`stack`/`resource`/`intent`/`secret`, the
serializer that maps your program's config back to a provider's real
wire attribute names) and a provider's own **bindings** (the typed
resource classes themselves, e.g. `sqs.Queue`, generated directly from
a real provider schema). Neither works alone: the runtime has no idea
what `aws_sqs_queue` looks like, and bindings have no `resource()`/
`stack()` to call. Every SDK Reference page's own example imports both,
for exactly this reason.

Versions below are the real, live-published versions as of this page's
own last check, fetched directly from each real registry, not memory.

## Go

**Requirements**: Go 1.26.3 or newer (`ubx-sdk-go`'s and every generated
bindings repo's own real `go.mod` `go` directive).

**Install** (the bindings repo declares the runtime as its own real
dependency, so one `go get` pulls both):

```bash
go mod init payments
go get github.com/ubiquex/ubx-sdk-aws/sdk/go
```

Real, live-confirmed versions this resolves: runtime
`github.com/ubiquex/ubx-sdk-go` v0.1.2, bindings
`github.com/ubiquex/ubx-sdk-aws/sdk/go` v0.3.1 (Go module proxy, checked
directly).

**Hello world**:

```go
package main

import (
	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sqs"
)

func main() {
	ubx.Main(ubx.Stack("payments", func() {
		ubx.Intent(ubx.IntentInfo{Summary: "hello, ubx"})
		ubx.Resource(sqs.Queue, "example", sqs.QueueConfig{
			Name: "example",
		})
	}))
}
```

## TypeScript

**Requirements**: Node.js 22.x or newer (the real, pinned version every
published repo's own CI workflow builds and publishes against).

**Install** (the bindings package declares the runtime as its own real
dependency, so one `npm install` pulls both):

```bash
npm install @ubx/sdk-aws
```

TypeScript now publishes to npm, not JSR -- npm has no protocol
specifier that resolves inline the way `jsr:` does under Deno, so
installing first is required, not optional, before the bare import
below resolves. Check `https://registry.npmjs.org/@ubx%2fsdk-aws`
directly for the current live version rather than trusting this page's
own memory of one.

**Hello world**:

```typescript
import { stack, intent, resource } from "@ubx/sdk";
import { Queue } from "@ubx/sdk-aws/aws/sqs/queue";

export default stack("payments", () => {
  intent({ summary: "hello, ubx" });
  resource(Queue, "example", {
    name: "example",
  });
});
```

## Python

**Requirements**: Python 3.9 or newer (`ubx-sdk`'s own real
`requires_python`, PyPI metadata, checked directly).

**Install** (the bindings package declares the runtime as its own real
dependency, so one `pip install` pulls both):

```bash
pip install ubx-sdk-aws
```

Real, live-confirmed versions this resolves: runtime `ubx-sdk`
(imported as `ubx_sdk`) 0.1.1, bindings `ubx-sdk-aws` 0.3.1 (PyPI,
checked directly).

**Hello world**:

```python
import ubx_sdk as ubx
from ubx.aws.sqs import Queue, QueueConfig

def describe():
    ubx.intent("hello, ubx")
    ubx.resource(Queue, "example", QueueConfig(
        name="example",
    ))

if __name__ == "__main__":
    ubx.run("payments", describe)
```

`azure_appplatform_appplatform_storage_resource` mounts an external storage account (e.g. Azure Files) as a persistent volume accessible to applications running in Azure Spring Apps.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appplatform storage resource"})

    		ubx.Resource(appplatform.StorageResource, "example", appplatform.StorageResourceConfig{})
    	}))
    }
    ```

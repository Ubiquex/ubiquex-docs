`azure_appplatform_appplatform_apm_resource` configures an Application Performance Monitoring integration (e.g. Application Insights, Dynatrace) for services running in an Azure Spring Apps instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_appplatform_appplatform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_appplatform_appplatform/sdk/go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_appplatform_appplatform/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own appplatform apm resource"})

    		ubx.Resource(appplatform.AppplatformApmResource, "ci-runner", appplatform.AppplatformApmResourceConfig{})
    	}))
    }
    ```

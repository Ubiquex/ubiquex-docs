`azure_appplatform_appplatform_apm_resource` configures an Application Performance Monitoring integration (e.g. Application Insights, Dynatrace) for services running in an Azure Spring Apps instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appplatform apm resource"})

    		ubx.Resource(appplatform.ApmResource, "example", appplatform.ApmResourceConfig{})
    	}))
    }
    ```

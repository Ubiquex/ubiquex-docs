`azure_appplatform_build` is a single build execution compiling application source code into a deployable container image within Azure Spring Apps' own build service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_appplatform_appplatform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_appplatform_appplatform/sdk/go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_appplatform_appplatform/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appplatform build"})

    		ubx.Resource(appplatform.AppplatformBuild, "example", appplatform.AppplatformBuildConfig{})
    	}))
    }
    ```
  </Tab>

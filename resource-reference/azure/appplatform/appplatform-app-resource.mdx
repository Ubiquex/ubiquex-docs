`azure_appplatform_app_resource` is a single microservice application deployed within an Azure Spring Apps service instance, that deployment(s) and binding(s) belong to.

## Example

    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_appplatform_appplatform/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

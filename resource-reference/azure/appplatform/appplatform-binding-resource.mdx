`azure_appplatform_appplatform_binding_resource` connects an Azure Spring Apps application to a backing service (a database, a message broker) by injecting its own connection details as environment configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appplatform binding resource"})

    		ubx.Resource(appplatform.BindingResource, "example", appplatform.BindingResourceConfig{})
    	}))
    }
    ```

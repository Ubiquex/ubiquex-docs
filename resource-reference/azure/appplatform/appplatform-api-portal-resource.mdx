`azure_appplatform_appplatform_api_portal_resource` deploys the API portal, a self-service UI aggregating OpenAPI documentation for every service registered in an Azure Spring Apps app.

## Example

    	ubx.Main(ubx.Stack("example", func() {

## Properties

<ResponseField name="properties" type="object">
  API portal properties payload Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="api_try_out_enabled_state" type="string">
      Indicates whether the API try-out feature is enabled or disabled. When enabled, users can try out the API by sending requests and viewing responses in API portal. When disabled, users cannot try out the API. Optional.
    </ResponseField>
    <ResponseField name="gateway_ids" type="list(string)">
      The array of resource Ids of gateway to integrate with API portal. Optional.
    </ResponseField>
    <ResponseField name="https_only" type="bool">
      Indicate if only https is allowed. Optional.
    </ResponseField>
    <ResponseField name="instances" type="list(object)">
      Collection of instances belong to API portal. Computed by Microsoft Azure after `ship`.
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The resource's own name, unique within its parent scope. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="status" type="string">
          The current status of this resource. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      State of the API portal. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="public" type="bool">
      Indicates whether the API portal exposes endpoint. Optional.
    </ResponseField>
    <ResponseField name="resource_requests" type="object">
      Resource requests of the API portal Optional.
      <Expandable title="properties">
        <ResponseField name="cpu" type="string">
          Cpu allocated to each API portal instance Computed by Microsoft Azure after `ship`.
        </ResponseField>
        <ResponseField name="memory" type="string">

        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="source_urls" type="list(string)">
      Collection of OpenAPI source URL locations. Optional.
    </ResponseField>
    <ResponseField name="sso_properties" type="object">
      Single sign-on related configuration Optional.

          The public identifier for the application Optional.

        <ResponseField name="client_secret" type="string">
          The secret known only to the application and the authorization server Optional.
        </ResponseField>
        <ResponseField name="issuer_uri" type="string">
          The URI of Issuer Identifier Optional.
        </ResponseField>
        <ResponseField name="scope" type="list(string)">
          It defines the specific actions applications can be allowed to do on a user's behalf Optional.

      </Expandable>
    </ResponseField>
    <ResponseField name="url" type="string">
      URL of the API portal, exposed when 'public' is true. Computed by Microsoft Azure after `ship`.

`azure_graphservicesprod_graphservicesprod_account_resource` provisions a Microsoft Graph Data Connect account, enabling bulk export of Microsoft 365 data into Azure data stores for analytics.

## Example

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

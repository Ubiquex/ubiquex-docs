`azure_databricks_openapi_virtual_network_peering` peers an Azure Databricks workspace's own managed virtual network with another VNet, extending connectivity between them.

## Properties

<ResponseField name="properties" type="object" required>
  Properties of the virtual network peering. Required.
  <Expandable title="properties">
    <ResponseField name="allow_forwarded_traffic" type="bool">
      Whether the forwarded traffic from the VMs in the local virtual network will be allowed/disallowed in remote virtual network. Optional.
    </ResponseField>
    <ResponseField name="allow_gateway_transit" type="bool">
      If gateway links can be used in remote virtual networking to link to this virtual network. Optional.
    </ResponseField>
    <ResponseField name="allow_virtual_network_access" type="bool">
      Whether the VMs in the local virtual network space would be able to access the VMs in remote virtual network space. Optional.
    </ResponseField>
    <ResponseField name="databricks_address_space" type="object">
      AddressSpace contains an array of IP address ranges that can be used by subnets of the virtual network. Optional.
      <Expandable title="properties">
        <ResponseField name="address_prefixes" type="list(string)">
          A list of address blocks reserved for this virtual network in CIDR notation. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="databricks_virtual_network" type="object">
      The remote virtual network should be in the same region. See here to learn more (https://docs.microsoft.com/en-us/azure/databricks/administration-guide/cloud-configurations/azure/vnet-peering). Optional.
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          The Id of the databricks virtual network. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="peering_state" type="string">
      The status of the virtual network peering. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The current provisioning state. Optional.
    </ResponseField>
    <ResponseField name="remote_address_space" type="object">
      AddressSpace contains an array of IP address ranges that can be used by subnets of the virtual network. Optional.
      <Expandable title="properties">
        <ResponseField name="address_prefixes" type="list(string)">
          A list of address blocks reserved for this virtual network in CIDR notation. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="remote_virtual_network" type="object" required>
      The remote virtual network should be in the same region. See here to learn more (https://docs.microsoft.com/en-us/azure/databricks/administration-guide/cloud-configurations/azure/vnet-peering). Required.
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          The Id of the remote virtual network. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="use_remote_gateways" type="bool">
      If remote gateways can be used on this virtual network. If the flag is set to true, and allowGatewayTransit on remote peering is also true, virtual network will use gateways of remote virtual network for transit. Only one peering can have this flag set to true. This flag cannot be set if virtual network already has a gateway. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

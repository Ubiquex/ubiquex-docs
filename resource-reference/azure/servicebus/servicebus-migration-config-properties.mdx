`azure_servicebus_servicebus_migration_config_properties` migrates a Service Bus Standard namespace to Premium tier in place, preserving the namespace's own connection strings and endpoint.

## Properties

<ResponseField name="location" type="string">
  The geo-location where the resource lives Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties required to the Create Migration Configuration Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="migration_state" type="string">
      State in which Standard to Premium Migration is, possible values : Unknown, Reverting, Completing, Initiating, Syncing, Active Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="pending_replication_operations_count" type="number">
      Number of entities pending to be replicated. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="post_migration_name" type="string" required>
      Name to access Standard Namespace after migration Required.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Provisioning state of Migration ConfigurationProvisioning state of Migration Configuration Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="target_namespace" type="string" required>
      Existing premium Namespace ARM Id name which has no entities, will be used for migration Required.
    </ResponseField>
  </Expandable>
</ResponseField>

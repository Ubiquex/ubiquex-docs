`azure_servicebus_rule` defines a filter and optional action applied to a Service Bus topic subscription, determining which published message(s) that subscription actually receives.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own servicebus rule"})

    		ubx.Resource(servicebus.Rule, "example", servicebus.RuleConfig{})
    	}))
    }
    ```

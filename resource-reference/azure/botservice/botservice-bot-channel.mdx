`azure_botservice_botservice_bot_channel` connects an Azure AI Bot Service bot to a specific messaging channel (Teams, Slack, web chat), making it reachable from that platform.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	botservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/botservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own botservice bot channel"})

    		ubx.Resource(botservice.BotChannel, "example", botservice.BotChannelConfig{})
    	}))
    }
    ```

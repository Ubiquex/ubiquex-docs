`azure_botservice_botservice_bot_channel` connects an Azure AI Bot Service bot to a specific messaging channel (Teams, Slack, web chat), making it reachable from that platform.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_botservice_botservice --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_botservice_botservice/sdk/go
    package main

    import (
    	botservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_botservice_botservice/botservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own botservice bot channel"})

    		ubx.Resource(botservice.BotserviceBotChannel, "ci-runner", botservice.BotserviceBotChannelConfig{})
    	}))
    }
    ```

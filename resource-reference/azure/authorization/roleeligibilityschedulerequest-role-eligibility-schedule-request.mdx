`azure_authorization_roleeligibilityschedulerequest_role_eligibility_schedule_request` requests an eligible Azure RBAC role assignment via Microsoft Entra Privileged Identity Management -- one the assigned principal must actively activate (with MFA, justification, or approval, per policy) before it grants any real access.

`azure_cpim_externalidentities_b2_ctenant_resource` is an Azure AD B2C tenant, a separate Microsoft Entra directory dedicated to customer identity and access management for an organization's own consumer-facing applications. No longer available for new customers since May 2025; existing tenants continue to be supported, with Microsoft steering new deployments toward Microsoft Entra External ID instead.

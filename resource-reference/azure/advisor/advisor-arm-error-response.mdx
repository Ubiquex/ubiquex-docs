`azure_advisor_advisor_arm_error_response` is Azure Advisor's own standard API error envelope, returned when a request to the Advisor management API fails -- not a deployable resource in its own right.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

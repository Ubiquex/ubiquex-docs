`azure_advisor_suppression_contract` suppresses a specific Azure Advisor recommendation for a resource, either permanently or for a defined time window.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	advisor "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/advisor"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own advisor suppression contract"})

    		ubx.Resource(advisor.SuppressionContract, "example", advisor.SuppressionContractConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<ResponseField name="name" type="string" required>

<ResponseField name="properties" type="object">
  The properties of the suppression. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="expiration_time_stamp" type="string">
      Gets or sets the expiration time stamp. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="suppression_id" type="string">
      The GUID of the suppression. Optional.
    </ResponseField>
    <ResponseField name="ttl" type="string">
      The duration for which the suppression is valid. Optional.
    </ResponseField>
  </Expandable>

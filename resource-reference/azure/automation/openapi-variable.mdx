---
title: "azure_automation_openapi_variable"
description: "`azure_automation_openapi_variable` stores a named configuration value (plain or encrypted) within an Azure Automation account, referenced by runbook(s)."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi variable"})

    		ubx.Resource(automation.OpenapiVariable, "example", automation.OpenapiVariableConfig{
    			Name:       "example",
    			Properties: map[string]any{"description": "example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { OpenapiVariable } from "@ubx/sdk-azure/azure/automation/openapi_variable";

    export default stack("example", () => {
      intent({ summary: "example own openapi variable" });

      resource(OpenapiVariable, "example", {
        name: "example",
        properties: { description: "example" },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.automation import OpenapiVariable, OpenapiVariableConfig

    def describe():
        ubx.intent("example own openapi variable")

        ubx.resource(OpenapiVariable, "example", OpenapiVariableConfig(
            name="example",
            properties={"description": "example"},
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Create azure_automation_openapi_variable called "example", with
    properties a set value.
    ```

</Tabs>

</ResponseField>

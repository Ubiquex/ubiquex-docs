`azure_automation_openapi_source_control` links an Azure Automation account to an external Git repository, syncing runbook source code automatically on push.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi source control"})

    		ubx.Resource(automation.OpenapiSourceControl, "example", automation.OpenapiSourceControlConfig{
    			Properties: map[string]any{"auto_sync": true},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.azure.automation import OpenapiSourceControl, OpenapiSourceControlConfig
    from ubx.azure.automation.openapi_source_control import OpenapiSourceControl_Properties

    def describe():
        ubx.intent("example own openapi source control")

            properties=OpenapiSourceControl_Properties(auto_sync=True),
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Properties

<ResponseField name="properties" type="object" required>
  The properties of the create source control operation. Required.
  <Expandable title="properties">
    <ResponseField name="auto_sync" type="bool">
      The auto async of the source control. Default is false. Optional.
    </ResponseField>
    <ResponseField name="branch" type="string">
      The repo branch of the source control. Include branch as empty string for VsoTfvc. Optional.
    </ResponseField>
    <ResponseField name="description" type="string">
      The user description of the source control. Optional.
    </ResponseField>
    <ResponseField name="folder_path" type="string">
      The folder path of the source control. Path must be relative. Optional.
    </ResponseField>
    <ResponseField name="publish_runbook" type="bool">
      The auto publish of the source control. Default is true. Optional.
    </ResponseField>
    <ResponseField name="repo_url" type="string">
      The repo url of the source control. Optional.
    </ResponseField>
    <ResponseField name="security_token" type="object">
      The credential used to authenticate this webhook. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="access_token" type="string">
          The access token. Optional.
        </ResponseField>
        <ResponseField name="refresh_token" type="string">
          The refresh token. Optional.
        </ResponseField>
        <ResponseField name="token_type" type="string">
          The token type. Must be either PersonalAccessToken or Oauth. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="source_type" type="string">
      The source type. Must be one of VsoGit, VsoTfvc, GitHub. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_automation_openapi_source_control_sync_job_by_id` starts a source control sync job, pulling the latest runbook source code from an Azure Automation account's own linked Git repository on demand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi source control sync job by id"})

    		ubx.Resource(automation.OpenapiSourceControlSyncJobById, "example", automation.OpenapiSourceControlSyncJobByIdConfig{
    			Properties: map[string]any{"commit_id": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="properties" type="object" required>
  Definition of create source control sync job properties. Required.
  <Expandable title="properties">
    <ResponseField name="commit_id" type="string" required>
      The commit id of the source control sync job. If not syncing to a commitId, enter an empty string. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The id of the job. Computed by Microsoft Azure after `ship`.
</ResponseField>

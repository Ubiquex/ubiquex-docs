`azure_automation_openapi_runtime_environment` defines a custom language version and package set that PowerShell or Python runbook(s) execute within, beyond Azure Automation's own default runtime.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi runtime environment"})

    		ubx.Resource(automation.OpenapiRuntimeEnvironment, "example", automation.OpenapiRuntimeEnvironmentConfig{})
    	}))
    }
    ```
  </Tab>

`azure_automation_openapi_certificate` stores a certificate securely within an Azure Automation account, referenced by runbook(s) needing it for authentication.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi certificate"})

    		ubx.Resource(automation.OpenapiCertificate, "example", automation.OpenapiCertificateConfig{
    			Name:       "example",
    			Properties: map[string]any{"base64_value": "example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { OpenapiCertificate } from "@ubx/sdk-azure/azure/automation/openapi_certificate";

    export default stack("example", () => {
      intent({ summary: "example own openapi certificate" });

      resource(OpenapiCertificate, "example", {
        name: "example",
        properties: { base64Value: "example" },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.automation import OpenapiCertificate, OpenapiCertificateConfig
    from ubx.azure.automation.openapi_certificate import OpenapiCertificate_Properties

    def describe():
        ubx.intent("example own openapi certificate")

        ubx.resource(OpenapiCertificate, "example", OpenapiCertificateConfig(
            name="example",
            properties=OpenapiCertificate_Properties(base64_value="example"),
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
  <Tab title="Markdown">
    ```

    with properties a set value.
    ```
  </Tab>
</Tabs>

  Gets or sets the name of the certificate. Required.
</ResponseField>

  <Expandable title="properties">

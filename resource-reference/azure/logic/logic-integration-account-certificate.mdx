`azure_logic_integration_account_certificate` stores a certificate within a Logic Apps integration account, used to sign or encrypt B2B message exchanges.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_logic_logic --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_logic_logic/sdk/go
    package main

    import (
    	logic "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_logic_logic/logic"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own logic integration account certificate"})

    		ubx.Resource(logic.LogicIntegrationAccountCertificate, "example", logic.LogicIntegrationAccountCertificateConfig{
    			Properties: map[string]any{"changed_time": "example"},
    		})
    	}))
    }
    ```
  </Tab>

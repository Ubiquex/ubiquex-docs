`azure_logic_batch_configuration` defines batching rule(s) (release criteria based on message count, size, or a schedule) that a Logic Apps workflow uses to accumulate and release messages together.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logic "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/logic"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own logic batch configuration"})

    		ubx.Resource(logic.BatchConfiguration, "example", logic.BatchConfigurationConfig{
    			Properties: map[string]any{"batch_group_name": "example-batch-group-name"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

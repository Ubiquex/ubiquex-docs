`azure_cost_management_openapi_cost_details_operation_results` reports the completion status and download link for an asynchronous detailed cost export request.

## Input properties

<ResponseField name="billing_period" type="string">
  This parameter can be used only by Enterprise Agreement customers. Use the YearMonth(e.g. 202008) format. This parameter cannot be used alongside either the invoiceId or timePeriod parameters. If a timePeriod, invoiceId or billingPeriod parameter is not provided in the request body the API will return the current month's cost. Optional.
</ResponseField>

<ResponseField name="invoice_id" type="string">
  This parameter can only be used by Microsoft Customer Agreement customers. Additionally, it can only be used at the Billing Profile or Customer scope. This parameter cannot be used alongside either the billingPeriod or timePeriod parameters. If a timePeriod, invoiceId or billingPeriod parameter is not provided in the request body the API will return the current month's cost. Optional.
</ResponseField>

<ResponseField name="metric" type="string">
  The type of the detailed report. By default ActualCost is provided Optional.
</ResponseField>

<ResponseField name="scope" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="time_period" type="object">
  The start and end date for pulling data for the cost detailed report. API only allows data to be pulled for 1 month or less and no older than 13 months. Optional.
  <Expandable title="properties">
    <ResponseField name="end" type="string" required>
      The end date to pull data to. example format 2020-03-15 Required.
    </ResponseField>
    <ResponseField name="start" type="string" required>
      The start date to pull data from. example format 2020-03-15 Required.
    </ResponseField>
  </Expandable>
</ResponseField>

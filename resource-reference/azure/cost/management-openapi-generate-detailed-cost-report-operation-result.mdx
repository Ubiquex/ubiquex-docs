## Input properties

<ResponseField name="billing_period" type="string">
  Billing period in YearMonth(e.g. 202008) format. Only for legacy enterprise customers can use this. Can only have one of either timePeriod or invoiceId or billingPeriod parameters. If none provided current month cost is provided. Optional.
</ResponseField>

<ResponseField name="customer_id" type="string">
  Customer ID for Microsoft Customer Agreement scopes (Invoice Id is also required for this). Optional.
</ResponseField>

<ResponseField name="invoice_id" type="string">
  Invoice ID for Pay-as-you-go and Microsoft Customer Agreement scopes. Can only have one of either timePeriod or invoiceId or billingPeriod parameters. If none provided current month cost is provided. Optional.
</ResponseField>

<ResponseField name="metric" type="string">
  The type of the detailed report. By default ActualCost is provided Optional.
</ResponseField>

<ResponseField name="scope" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="time_period" type="object">
  The start and end date for pulling data for the cost detailed report. Optional.
  <Expandable title="properties">
    <ResponseField name="end" type="string" required>
      The end date to pull data to. example format 2020-03-15 Required.
    </ResponseField>
    <ResponseField name="start" type="string" required>
      The start date to pull data from. example format 2020-03-15 Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="properties" type="object">
  The URL to download the generated report. Computed by Microsoft Azure after `ship`.
  <Expandable title="properties">
    <ResponseField name="download_url" type="string">
      The URL to download the generated report. Optional.
    </ResponseField>
    <ResponseField name="expiry_time" type="string">
      The time at which report URL becomes invalid/expires in UTC e.g. 2020-12-08T05:55:59.4394737Z. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="valid_till" type="string">
      The time at which report URL becomes invalid/expires in UTC e.g. 2020-12-08T05:55:59.4394737Z. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

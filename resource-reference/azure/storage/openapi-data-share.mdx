`azure_storage_openapi_data_share` configures Data Share integration for a storage account, enabling secure sharing of its own data with external consumers.

## Example

    import (
    	storage "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_storage_openapi/storage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own openapi data share"})

`azure_storage_openapi_advanced_platform_metrics_rule` enables Advanced Platform Metrics on a storage account, extending Azure Monitor's platform metrics with per-container capacity and object count insights for Blob Storage.

## Properties

<ResponseField name="properties" type="object">
  An object that defines the advanced platform metrics rule. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool" required>
      A boolean flag which enables the advanced platform metrics rule. Required.
    </ResponseField>
    <ResponseField name="last_modified_time" type="string">
      Gets the last modification date and time of the advanced platform metrics rule in UTC. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="metrics_emitted" type="list(string)">
      The metrics emitted by the rule. Metrics are mapped according to the rule type from RuleTypeProperty. Rule type to metrics mapping: ContainerLevelCapacityMetrics =&gt; &#123;ContainerUsedSize, ContainerBlobCount&#125;. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="rule_config" type="object" required>
      Configuration for the advanced platform metrics rule. Required.
      <Expandable title="properties">
        <ResponseField name="filter_type" type="string">
          The type of filter applied to the advanced platform metrics rule. Optional.
        </ResponseField>
        <ResponseField name="filter_values" type="list(string)">
          The values for the filter applied to the rule. If filter type is AllContainersFilter, filter values should be empty. If filter type is ContainerPrefixFilter, filter values should contain a list of container prefixes. If filter type is ContainerListFilter, filter values should contain a list of container names. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="rule_type" type="string">
      The type of the advanced platform metrics rule. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_storage_openapi_encryption_scope` defines a named encryption configuration (a specific customer-managed or Microsoft-managed key) scoped to a subset of blobs within a storage account.

## Properties

<ResponseField name="properties" type="object">
  Properties of the encryption scope. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="creation_time" type="string">
      Gets the creation date and time of the encryption scope in UTC. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="key_vault_properties" type="object">
      The key vault properties for the encryption scope. This is a required field if encryption scope 'source' attribute is set to 'Microsoft.KeyVault'. Optional.
      <Expandable title="properties">
        <ResponseField name="current_versioned_key_identifier" type="string">
          The object identifier of the current versioned Key Vault Key in use. Computed by Microsoft Azure after `ship`.
        </ResponseField>
        <ResponseField name="key_uri" type="string">
          The object identifier for a key vault key object. When applied, the encryption scope will use the key referenced by the identifier to enable customer-managed key support on this encryption scope. Optional.
        </ResponseField>
        <ResponseField name="last_key_rotation_timestamp" type="string">
          Timestamp of last rotation of the Key Vault Key. Computed by Microsoft Azure after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="last_modified_time" type="string">
      Gets the last modification date and time of the encryption scope in UTC. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="require_infrastructure_encryption" type="bool">
      A boolean indicating whether or not the service applies a secondary layer of encryption with platform managed keys for data at rest. Optional.
    </ResponseField>
    <ResponseField name="source" type="string">
      The provider for the encryption scope. Possible values (case-insensitive): Microsoft.Storage, Microsoft.KeyVault. Optional.
    </ResponseField>
    <ResponseField name="state" type="string">
      The state of the encryption scope. Possible values (case-insensitive): Enabled, Disabled. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

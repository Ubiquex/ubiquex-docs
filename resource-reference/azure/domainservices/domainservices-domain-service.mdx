---
title: "azure_domainservices_domain_service"
description: "`azure_domainservices_domainservices_domain_service` provisions Microsoft Entra Domain Services..."
---

`azure_domainservices_domainservices_domain_service` provisions Microsoft Entra Domain Services, a fully managed Active Directory-compatible domain without the caller having to run domain controllers.

## Example

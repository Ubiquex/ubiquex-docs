`hashicorp/azurerm` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-azure-go/azurerm/spring"
    )

    cfg := spring.CloudAppConfig{
        Name: "example-name",
        ResourceGroupName: "example-resource-group-name",
        ServiceName: "example-service-name",
        HttpsOnly: true,
        IsPublic: true,
    }
    ubx.Resource(spring.CloudApp, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { CloudApp } from
      "jsr:@ubx/sdk-azure/azurerm/spring/cloud_app";

    resource(CloudApp, "example", {
      name: "example-name",
      resourceGroupName: "example-resource-group-name",
      serviceName: "example-service-name",
      httpsOnly: true,
      isPublic: true,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.azurerm.spring import CloudApp, CloudAppConfig

    cfg = CloudAppConfig(
        name="example-name",
        resource_group_name="example-resource-group-name",
        service_name="example-service-name",
        https_only=True,
        is_public=True,
    )
    ubx.resource(CloudApp, "example", cfg)
    ```

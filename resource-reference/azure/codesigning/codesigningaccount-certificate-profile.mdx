`azure_codesigning_codesigningaccount_certificate_profile` defines a certificate profile (a specific signing identity and validity policy) within a Trusted Signing account, that signing request(s) are issued against.

<ResponseField name="properties" type="object">
  Properties of the certificate profile. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="certificates" type="list(object)">
      List of renewed certificates. Computed by Microsoft Azure after `ship`.
      <Expandable title="properties">
        <ResponseField name="created_date" type="string">
          When this signing certificate was issued. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="enhanced_key_usage" type="string">
          The X.509 Enhanced Key Usage extension value declaring what this certificate may be used for, e.g. code signing. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="expiry_date" type="string">
          When this signing certificate expires. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="revocation" type="object">
          The revocation request and outcome for this certificate, present only if revocation was ever requested. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="effective_at" type="string">
              The timestamp revocation takes effect from -- signatures made with this certificate after this time are treated as invalid. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="failure_reason" type="string">
              Why the revocation request failed, if `status` is `Failed`. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="reason" type="string">
              The reason given for revoking this certificate. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="remarks" type="string">
              Free-text notes attached to this revocation request. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="requested_at" type="string">
              When revocation of this certificate was requested. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="status" type="string">
              The current status of this revocation request: `InProgress`, `Succeeded`, or `Failed`. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="serial_number" type="string">
          This certificate's own serial number. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="status" type="string">
          This certificate's own current status: `Active`, `Expired`, or `Revoked`. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="subject_name" type="string">
          This certificate's own subject (the signing identity it represents). Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="thumbprint" type="string">
          A SHA-1 hash of this certificate's own raw bytes, used to identify it (e.g. when requesting revocation). Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>

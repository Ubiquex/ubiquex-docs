---
title: "azure_oracle_openapi_autonomous_database_backup"
description: "`data_azure_oracle_openapi_autonomous_database_backup` looks up a real, already-existing `azure_oracle_openapi_autonomous_database_backup`."
---

It is a point-in-time backup of an Oracle Autonomous Database instance provisioned through Oracle Database@Azure.

---
title: "azure_oracle_openapi_autonomous_database"
description: "`data_azure_oracle_openapi_autonomous_database` looks up a real, already-existing `azure_oracle_openapi_autonomous_database`."
---

It provisions a self-managing Oracle Autonomous Database instance through Oracle Database@Azure, running on Oracle Cloud Infrastructure but integrated into an Azure subscription.

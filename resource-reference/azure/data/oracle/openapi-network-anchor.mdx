---
title: "azure_oracle_openapi_network_anchor"
description: "`data_azure_oracle_openapi_network_anchor` looks up a real, already-existing `azure_oracle_openapi_network_anchor`."
---

It provisions the Oracle Cloud Infrastructure-side networking foundation Oracle Database@Azure resources are deployed into, peered with the Azure virtual network they're linked to.

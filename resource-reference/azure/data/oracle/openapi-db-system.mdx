---
title: "azure_oracle_openapi_db_system"
description: "`data_azure_oracle_openapi_db_system` looks up a real, already-existing `azure_oracle_openapi_db_system`."
---

It provisions an Oracle Base Database Service system through Oracle Database@Azure, a lighter-weight (non-Exadata) managed Oracle database deployment.

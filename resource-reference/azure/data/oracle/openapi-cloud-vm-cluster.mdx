---
title: "azure_oracle_openapi_cloud_vm_cluster"
description: "`data_azure_oracle_openapi_cloud_vm_cluster` looks up a real, already-existing `azure_oracle_openapi_cloud_vm_cluster`."
---

It provisions a cluster of VM(s) on Oracle Exadata infrastructure within Oracle Database@Azure, that Oracle database instance(s) run on.

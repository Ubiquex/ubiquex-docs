---
title: "azure_hdinsight_applications_application"
description: "`data_azure_hdinsight_applications_application` looks up a real, already-existing `azure_hdinsight_applications_application`."
---

It installs a custom or marketplace application onto an HDInsight cluster's own edge node.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

</ResponseField>

</ResponseField>

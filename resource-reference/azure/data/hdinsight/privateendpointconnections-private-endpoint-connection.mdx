`data_azure_hdinsight_privateendpointconnections_private_endpoint_connection` looks up a real, already-existing `azure_hdinsight_privateendpointconnections_private_endpoint_connection`. It represents the connection between a Private Endpoint and an HDInsight cluster, tracking its own approval state.

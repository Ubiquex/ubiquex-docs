---
title: "azure_scvmm_cloud"
description: "`data_azure_scvmm_cloud` looks up a real, already-existing `azure_scvmm_cloud`."
---

It represents an SCVMM private cloud resource pool, exposed as an Azure Arc resource that VM(s) can be provisioned onto through Azure tooling.

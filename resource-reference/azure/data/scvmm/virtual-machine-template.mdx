---
title: "azure_scvmm_virtual_machine_template"
description: "`data_azure_scvmm_virtual_machine_template` looks up a real, already-existing `azure_scvmm_virtual_machine_template`."
---

It is an SCVMM VM template, exposed as an Azure Arc resource that new Arc-enabled SCVMM VM(s) can be provisioned from.

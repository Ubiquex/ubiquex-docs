---
title: "azure_scvmm_virtual_network"
description: "`data_azure_scvmm_virtual_network` looks up a real, already-existing `azure_scvmm_virtual_network`."
---

It is an SCVMM logical network, exposed as an Azure Arc resource that Arc-enabled SCVMM VM(s) can be attached to.

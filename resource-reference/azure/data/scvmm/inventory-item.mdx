---
title: "azure_scvmm_inventory_item"
description: "`data_azure_scvmm_inventory_item` looks up a real, already-existing `azure_scvmm_inventory_item`."
---

It is a discovered SCVMM object (a VM, template, or network) surfaced as an Azure Arc resource once its own management server is onboarded.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	scvmm "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/scvmm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_scvmm_inventory_item"})

    		ubx.Data(scvmm.InventoryItem, "example", scvmm.InventoryItemConfig{
    			VmmServerName: "example-vmm-server-name",
    		})
    	}))
    }
    ```

    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.scvmm import InventoryItem, InventoryItemConfig

    def describe():
        ubx.intent("look up azure_scvmm_inventory_item")

        ubx.data(InventoryItem, "example", InventoryItemConfig(
            vmm_server_name="example-vmm-server-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

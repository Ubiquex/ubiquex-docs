---
title: "azure_scvmm_vmm_server"
description: "`data_azure_scvmm_vmm_server` looks up a real, already-existing `azure_scvmm_vmm_server`."
---

It registers an on-premises System Center Virtual Machine Manager management server with Azure Arc, making its own managed VM(s), cloud(s), and template(s) manageable through Azure.

---
title: "azure_scvmm_availability_set"
description: "`data_azure_scvmm_availability_set` looks up a real, already-existing `azure_scvmm_availability_set`."
---

It groups VM(s) together on an Azure Arc-enabled System Center Virtual Machine Manager private cloud so the underlying hypervisor keeps them on separate hosts for fault tolerance.

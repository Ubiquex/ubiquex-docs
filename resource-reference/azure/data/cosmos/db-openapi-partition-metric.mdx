  The real, internal resource identifier (RID) of this collection. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="database_rid" type="string" required>
  The real, internal resource identifier (RID) of this database. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="partition_key_range_id" type="string" required>

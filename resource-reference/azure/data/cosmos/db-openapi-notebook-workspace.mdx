---
title: "azure_cosmos_db_openapi_notebook_workspace"
description: "`data_azure_cosmos_db_openapi_notebook_workspace` looks up a real, already-existing `azure_cosmos_db_openapi_notebook_workspace`."
---

It provisions a hosted Jupyter notebook environment attached to a Cosmos DB account, for interactively exploring and analyzing its own data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cosmos "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cosmos"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cosmos_db_openapi_notebook_workspace"})

    		ubx.Data(cosmos.DbOpenapiNotebookWorkspace, "example", cosmos.DbOpenapiNotebookWorkspaceConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

`data_azure_cosmos_db_openapi_mongo_mirole_definition_resource` looks up a real, already-existing `azure_cosmos_db_openapi_mongo_mirole_definition_resource`. It defines a set of data-plane permissions that can be granted to identities accessing a Cosmos DB for MongoDB (vCore/MI) instance.

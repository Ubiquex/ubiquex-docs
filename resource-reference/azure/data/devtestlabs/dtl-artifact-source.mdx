---
title: "azure_devtestlabs_dtl_artifact_source"
description: "`data_azure_devtestlabs_dtl_artifact_source` looks up a real, already-existing `azure_devtestlabs_dtl_artifact_source`."
---

It is a source repository (e.g. a Git repo) DevTest Labs pulls reusable artifact definitions from, for installation onto lab virtual machines.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_artifact_source"})

    		ubx.Data(devtestlabs.DtlArtifactSource, "example", devtestlabs.DtlArtifactSourceConfig{
    			LabName: "example-lab-name",
    		})
    	}))
    }
    ```

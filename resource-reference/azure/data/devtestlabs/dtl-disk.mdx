---
title: "azure_devtestlabs_dtl_disk"
description: "`data_azure_devtestlabs_dtl_disk` looks up a real, already-existing `azure_devtestlabs_dtl_disk`."
---

It is a data disk attached to a lab virtual machine, managed as its own DevTest Labs resource independent of the VM's own OS disk.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_disk"})

    		ubx.Data(devtestlabs.DtlDisk, "example", devtestlabs.DtlDiskConfig{
    			LabName:  "example-lab-name",
    			UserName: "example-user-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="lab_name" type="string" required>

  The real username this lookup is scoped to. **(AI-inferred)** Required lookup argument.

---
title: "azure_devtestlabs_dtl_formula"
description: "`data_azure_devtestlabs_dtl_formula` looks up a real, already-existing `azure_devtestlabs_dtl_formula`."
---

It is a reusable VM creation template within a lab -- a saved set of VM size, image, and artifact choices lab users can create new virtual machines from without re-specifying every setting.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_formula"})

    		ubx.Data(devtestlabs.DtlFormula, "example", devtestlabs.DtlFormulaConfig{
    			LabName: "example-lab-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.devtestlabs import DtlFormula, DtlFormulaConfig

    def describe():
        ubx.intent("look up azure_devtestlabs_dtl_formula")

        ubx.data(DtlFormula, "example", DtlFormulaConfig(
            lab_name="example-lab-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

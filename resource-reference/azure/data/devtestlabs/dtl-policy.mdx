---
title: "azure_devtestlabs_dtl_policy"
description: "`data_azure_devtestlabs_dtl_policy` looks up a real, already-existing `azure_devtestlabs_dtl_policy`."
---

It is a lab policy -- a constraint like a maximum VM count per user or an allowed VM size list -- enforced against every virtual machine created in the lab.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_policy"})

    		ubx.Data(devtestlabs.DtlPolicy, "example", devtestlabs.DtlPolicyConfig{
    			LabName:       "example-lab-name",
    			PolicySetName: "example-policy-set-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="lab_name" type="string" required>
  The real name of the DevTest Lab this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="policy_set_name" type="string" required>
  The real name of the Azure Policy initiative (policy set) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

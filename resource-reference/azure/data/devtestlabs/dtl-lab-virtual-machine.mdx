---
title: "azure_devtestlabs_dtl_lab_virtual_machine"
description: "`data_azure_devtestlabs_dtl_lab_virtual_machine` looks up a real, already-existing `azure_devtestlabs_dtl_lab_virtual_machine`."
---

It is a virtual machine created within a DevTest Lab, distinct from a plain Azure VM in that it's subject to the lab's own cost, schedule, and access policies.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_lab_virtual_machine"})

    		ubx.Data(devtestlabs.DtlLabVirtualMachine, "example", devtestlabs.DtlLabVirtualMachineConfig{
    			LabName: "example-lab-name",
    		})
    	}))
    }
    ```

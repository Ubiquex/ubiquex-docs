---
title: "azure_devtestlabs_dtl_schedule"
description: "`data_azure_devtestlabs_dtl_schedule` looks up a real, already-existing `azure_devtestlabs_dtl_schedule`."
---

It is an automated schedule within a lab, most commonly an auto-shutdown or auto-start time applied to a lab virtual machine or the whole lab.

## Example

    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dtl schedule"})

    			Name:       "example",
    			Properties: map[string]any{"daily_recurrence": map[string]any{"time": "example"}},
    		})
    	}))
    }

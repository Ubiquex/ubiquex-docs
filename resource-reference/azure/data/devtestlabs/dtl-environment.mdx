title: "azure_devtestlabs_dtl_environment"

It is a DevTest Labs environment, a set of resources deployed together from an Azure Resource Manager template (e.g. a multi-VM topology) and managed as a single unit within a lab.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_environment"})

    		})
    	}))

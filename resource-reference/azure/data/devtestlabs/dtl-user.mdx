---
title: "azure_devtestlabs_dtl_user"
description: "`data_azure_devtestlabs_dtl_user` looks up a real, already-existing `azure_devtestlabs_dtl_user`."
---

It is a lab user profile, tracking one individual's own permissions, secrets, and per-user settings within a DevTest Lab.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_user"})

    		ubx.Data(devtestlabs.DtlUser, "example", devtestlabs.DtlUserConfig{
    			LabName: "example-lab-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.devtestlabs import DtlUser, DtlUserConfig

    def describe():
        ubx.intent("look up azure_devtestlabs_dtl_user")

        ubx.data(DtlUser, "example", DtlUserConfig(
            lab_name="example-lab-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

---
title: "azure_devtestlabs_dtl_secret"
description: "`data_azure_devtestlabs_dtl_secret` looks up a real, already-existing `azure_devtestlabs_dtl_secret`."
---

It is a per-user secret value (e.g. a credential) stored within a lab, scoped to that individual lab user rather than shared across the lab.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_secret"})

    		ubx.Data(devtestlabs.DtlSecret, "example", devtestlabs.DtlSecretConfig{
    			LabName:  "example-lab-name",
    			UserName: "example-user-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.devtestlabs import DtlSecret, DtlSecretConfig

    def describe():
        ubx.intent("look up azure_devtestlabs_dtl_secret")

        ubx.data(DtlSecret, "example", DtlSecretConfig(
            lab_name="example-lab-name",
            user_name="example-user-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="lab_name" type="string" required>
  The real name of the DevTest Lab this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="user_name" type="string" required>
  The real username this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

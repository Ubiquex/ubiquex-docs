---
title: "azure_devtestlabs_dtl_notification_channel"
description: "`data_azure_devtestlabs_dtl_notification_channel` looks up a real, already-existing `azure_devtestlabs_dtl_notification_channel`."
---

It configures where a lab sends event notifications (e.g. an autoshutdown warning), such as a webhook URL or email address.

## Example

    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_notification_channel"})

    		ubx.Data(devtestlabs.DtlNotificationChannel, "example", devtestlabs.DtlNotificationChannelConfig{
    			LabName: "example-lab-name",
    		})
    	}))
    ```

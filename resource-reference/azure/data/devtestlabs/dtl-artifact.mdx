## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	devtestlabs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devtestlabs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devtestlabs_dtl_artifact"})

    		ubx.Data(devtestlabs.DtlArtifact, "example", devtestlabs.DtlArtifactConfig{
    			ArtifactSourceName: "example-artifact-source-name",
    			LabName:            "example-lab-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

      intent({ summary: "look up azure_devtestlabs_dtl_artifact" });

        artifactSourceName: "example-artifact-source-name",
        labName: "example-lab-name",
      });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only azure --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.devtestlabs import DtlArtifact, DtlArtifactConfig

    def describe():
        ubx.intent("look up azure_devtestlabs_dtl_artifact")

        ubx.data(DtlArtifact, "example", DtlArtifactConfig(
            artifact_source_name="example-artifact-source-name",
            lab_name="example-lab-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="artifact_source_name" type="string" required>
  The real name of the DevTest Labs artifact source this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="lab_name" type="string" required>
  The real name of the DevTest Lab this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The Artifact items on this page Returned by the lookup.
</ResponseField>

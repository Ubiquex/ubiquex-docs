---
title: "azure_signalr_private_endpoint_connection"
description: "`data_azure_signalr_private_endpoint_connection` looks up a real, already-existing `azure_signalr_private_endpoint_connection`."
---

It represents the connection between a Private Endpoint and a SignalR Service resource, tracking its own approval state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	signalr "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/signalr"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_signalr_private_endpoint_connection"})

    		ubx.Data(signalr.PrivateEndpointConnection, "example", signalr.PrivateEndpointConnectionConfig{
    			ResourceName: "example-resource-name",
    		})
    	}))
    }
    ```
  </Tab>

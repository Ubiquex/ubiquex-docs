---
title: "azure_signalr_replica"
description: "`data_azure_signalr_replica` looks up a real, already-existing `azure_signalr_replica`."
---

It deploys an additional regional replica of a SignalR Service resource, for lower-latency access and regional resiliency.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	signalr "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/signalr"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_signalr_replica"})

    		ubx.Data(signalr.Replica, "example", signalr.ReplicaConfig{
    			ResourceName: "example-resource-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Replica } from "@ubx/sdk-azure/azure/data/signalr/replica";

    export default stack("example", () => {
      intent({ summary: "look up azure_signalr_replica" });

      data(Replica, "example", {
        resourceName: "example-resource-name",
      });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.signalr import Replica, ReplicaConfig

    def describe():
        ubx.intent("look up azure_signalr_replica")

        ubx.data(Replica, "example", ReplicaConfig(
            resource_name="example-resource-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

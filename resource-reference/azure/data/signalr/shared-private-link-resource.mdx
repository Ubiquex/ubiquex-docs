---
title: "azure_signalr_shared_private_link_resource"
description: "`data_azure_signalr_shared_private_link_resource` looks up a real, already-existing `azure_signalr_shared_private_link_resource`."
---

It creates a Private Endpoint from a SignalR Service resource to another Private Link-enabled Azure service, so outbound calls (e.g. to Event Grid) can stay private.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_signalr_shared_private_link_resource"})

    		ubx.Data(signalr.SharedPrivateLinkResource, "example", signalr.SharedPrivateLinkResourceConfig{
    			ReplicaName:  "example-replica-name",
    			ResourceName: "example-resource-name",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="replica_name" type="string" required>
  The real name of the replica this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  Request URL that can be used to query next page of private endpoint connections. Returned when the total number of requested private endpoint connections exceed maximum page size. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of the shared private link resources Returned by the lookup.
</ResponseField>

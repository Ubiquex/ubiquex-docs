---
title: "azure_capacity_reservation"
description: "`data_azure_capacity_reservation` looks up a real, already-existing `azure_capacity_reservation`."
---

It reserves compute capacity for one specific VM size in one region or zone, for as long as you keep it. Unlike a Reserved Instance, there's no one- or three-year term: you create and delete a reservation whenever you want, and it's billed at the same pay-as-you-go rate as the VM size itself whether a VM is actually using it or not. A VM only consumes the reservation if it explicitly specifies it in its own properties.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_capacity_reservation"})

    		ubx.Data(capacity.Reservation, "example", capacity.ReservationConfig{
    			CapacityReservationGroupName: "example-capacity-reservation-group-name",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="capacity_reservation_group_name" type="string" required>
  The real name of the capacity reservation group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

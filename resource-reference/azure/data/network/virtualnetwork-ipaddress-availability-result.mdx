`azure_network_virtualnetwork_ipaddress_availability_result` reads whether a real, specific IP address is currently available for use within a virtual network subnet.

## Lookup arguments

<ResponseField name="ip_address" type="string" required>
  The real IP address this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="virtual_network_name" type="string" required>
  The real name of the virtual network this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="available" type="bool">
  Private IP address availability. Returned by the lookup.
</ResponseField>

<ResponseField name="available_ipaddresses" type="list(string)">
  Contains other available private IP addresses if the asked for address is taken. Returned by the lookup.
</ResponseField>

<ResponseField name="is_platform_reserved" type="bool">
  Private IP address platform reserved. Returned by the lookup.
</ResponseField>

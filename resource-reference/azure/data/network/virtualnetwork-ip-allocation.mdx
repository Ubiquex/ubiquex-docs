---
title: "azure_network_virtualnetwork_ip_allocation"
description: "`data_azure_network_virtualnetwork_ip_allocation` looks up a real, already-existing `azure_network_virtualnetwork_ip_allocation`."
---

It reserves a specific IP address block for a defined purpose (e.g. an Azure PaaS service delegation) within a virtual network's own address space.

---
title: "azure_network_virtualwan_hub_ip_configuration"
description: "`data_azure_network_virtualwan_hub_ip_configuration` looks up a real, already-existing `azure_network_virtualwan_hub_ip_configuration`."
---

It defines the IP configuration for a Virtual WAN hub's own routing infrastructure, e.g. for Azure Firewall integration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualwan_hub_ip_configuration"})

    		ubx.Data(network.VirtualwanHubIpConfiguration, "example", network.VirtualwanHubIpConfigurationConfig{
    			VirtualHubName: "example-virtual-hub-name",
    		})
    	}))
    }
    ```

`data_azure_network_virtualwan_vpn_server_configuration_policy_group` looks up a real, already-existing `azure_network_virtualwan_vpn_server_configuration_policy_group`. It groups point-to-site VPN client(s) by attribute (e.g. Entra ID group) and applies a distinct address pool or configuration to that group.

`data_azure_network_networkmanager_security_user_configuration` looks up a real, already-existing `azure_network_networkmanager_security_user_configuration`. It defines security user rule(s) Virtual Network Manager applies across the virtual network(s) in a network group, evaluated after local NSG rules.

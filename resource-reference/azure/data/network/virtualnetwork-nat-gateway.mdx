---
title: "azure_network_virtualnetwork_nat_gateway"
description: "`data_azure_network_virtualnetwork_nat_gateway` looks up a real, already-existing `azure_network_virtualnetwork_nat_gateway`."
---

It provides managed, scalable outbound internet connectivity (source NAT) for resources in an attached subnet, without requiring a public IP directly on each resource.

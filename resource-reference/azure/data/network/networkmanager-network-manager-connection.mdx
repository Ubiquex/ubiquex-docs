---
title: "azure_network_networkmanager_network_manager_connection"
description: "`data_azure_network_networkmanager_network_manager_connection` looks up a real, already-existing `azure_network_networkmanager_network_manager_connection`."
---

It delegates management of a subscription or management group's own virtual networks to a Virtual Network Manager instance in a different scope.

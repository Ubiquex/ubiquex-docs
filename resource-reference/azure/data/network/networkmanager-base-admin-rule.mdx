---
title: "azure_network_networkmanager_base_admin_rule"
description: "`data_azure_network_networkmanager_base_admin_rule` looks up a real, already-existing `azure_network_networkmanager_base_admin_rule`."
---

It is the base type for a security admin or default rule enforced centrally across a Virtual Network Manager network group, evaluated before any local NSG rules.

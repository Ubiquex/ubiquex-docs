---
title: "azure_network_expressroute_express_route_port"
description: "`data_azure_network_expressroute_express_route_port` looks up a real, already-existing `azure_network_expressroute_express_route_port`."
---

It provisions a dedicated, physical ExpressRoute Direct port pair at a Microsoft peering location, that circuit(s) can be created directly on top of.

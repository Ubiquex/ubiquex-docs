---
title: "azure_network_networkmanager_admin_rule_collection"
description: "`data_azure_network_networkmanager_admin_rule_collection` looks up a real, already-existing `azure_network_networkmanager_admin_rule_collection`."
---

It groups related security admin rule(s) together within an Azure Virtual Network Manager security admin configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_admin_rule_collection"})

    		ubx.Data(network.NetworkmanagerAdminRuleCollection, "example", network.NetworkmanagerAdminRuleCollectionConfig{
    			ConfigurationName:  "example-configuration-name",
    			NetworkManagerName: "example-network-manager-name",
    		})
    	}))
    }
    ```

`data_azure_network_expressroute_express_route_circuit_peering` looks up a real, already-existing `azure_network_expressroute_express_route_circuit_peering`. It configures a specific peering type (Azure Private or Microsoft) on an ExpressRoute circuit, including its own BGP session details.

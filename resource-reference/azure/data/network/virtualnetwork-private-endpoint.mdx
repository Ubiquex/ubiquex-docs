`azure_network_virtualnetwork_private_endpoint` looks up a real Private Endpoint -- a private, in-VNet IP address connecting to an Azure PaaS service or Private Link service.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualnetwork_private_endpoint"})

    	}))
    }

`data_azure_network_applicationgateway_application_gateway_private_endpoint_connection` looks up a real, already-existing `azure_network_applicationgateway_application_gateway_private_endpoint_connection`. It represents the connection between a Private Endpoint and an Application Gateway's own private frontend, tracking its own approval state.

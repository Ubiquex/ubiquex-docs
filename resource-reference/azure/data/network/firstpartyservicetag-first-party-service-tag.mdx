`data_azure_network_firstpartyservicetag_first_party_service_tag` looks up a real, already-existing `azure_network_firstpartyservicetag_first_party_service_tag`. It reports a Microsoft first-party service's own IP address range grouping, usable in network security rules the same way a regular Azure service tag is.

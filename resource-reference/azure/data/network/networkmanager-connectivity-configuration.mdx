---
title: "azure_network_networkmanager_connectivity_configuration"
description: "`data_azure_network_networkmanager_connectivity_configuration` looks up a real, already-existing `azure_network_networkmanager_connectivity_configuration`."
---

It defines the connectivity topology (hub-and-spoke or mesh) Azure Virtual Network Manager establishes across the virtual network(s) in a network group.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_connectivity_configuration"})

    		ubx.Data(network.NetworkmanagerConnectivityConfiguration, "example", network.NetworkmanagerConnectivityConfigurationConfig{
    			NetworkManagerName: "example-network-manager-name",
    		})
    	}))
    }
    ```
  </Tab>

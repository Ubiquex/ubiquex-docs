---
title: "azure_network_loadbalancer_load_balancer"
description: "`data_azure_network_loadbalancer_load_balancer` looks up a real, already-existing `azure_network_loadbalancer_load_balancer`."
---

It is an Azure Load Balancer, distributing inbound Layer 4 traffic across a pool of backend instance(s) based on load-balancing rule(s).

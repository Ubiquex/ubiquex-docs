`data_azure_network_networkgateway_virtual_network_gateway_nat_rule` looks up a real, already-existing `azure_network_networkgateway_virtual_network_gateway_nat_rule`. It applies NAT translation to traffic passing through a virtual network gateway's own VPN connection, for connecting sites with overlapping address spaces.

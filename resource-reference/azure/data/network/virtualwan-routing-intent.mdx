---
title: "azure_network_virtualwan_routing_intent"
description: "`data_azure_network_virtualwan_routing_intent` looks up a real, already-existing `azure_network_virtualwan_routing_intent`."
---

It configures a Virtual WAN hub to route all internet-bound or private inter-hub traffic through a security appliance (e.g. Azure Firewall) by default, without manual route table configuration.

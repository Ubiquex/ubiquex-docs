---
title: "azure_network_virtualnetwork_static_cidr"
description: "`data_azure_network_virtualnetwork_static_cidr` looks up a real, already-existing `azure_network_virtualnetwork_static_cidr`."
---

It tracks an IP address range already in use outside Azure Virtual Network Manager's own control (e.g. on-premises or manually allocated) within an IPAM pool, preventing it from being allocated again.

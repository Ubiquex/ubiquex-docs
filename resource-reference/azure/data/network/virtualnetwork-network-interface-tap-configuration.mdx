`azure_network_virtualnetwork_network_interface_tap_configuration` reads a real Virtual Network TAP configuration mirroring traffic from a network interface.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualnetwork_network_interface_tap_configuration"})

    		ubx.Data(network.VirtualnetworkNetworkInterfaceTapConfiguration, "example", network.VirtualnetworkNetworkInterfaceTapConfigurationConfig{
    			NetworkInterfaceName: "example-network-interface-name",
    		})
    	}))
    }
    ```

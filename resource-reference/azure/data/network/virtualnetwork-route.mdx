---
title: "azure_network_virtualnetwork_route"
description: "`data_azure_network_virtualnetwork_route` looks up a real, already-existing `azure_network_virtualnetwork_route`."
---

It is a single custom route within a route table, directing traffic matching an address prefix to a specific next hop.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualnetwork_route"})

    		ubx.Data(network.VirtualnetworkRoute, "example", network.VirtualnetworkRouteConfig{
    			RouteTableName: "example-route-table-name",
    		})
    	}))
    }
    ```
  </Tab>

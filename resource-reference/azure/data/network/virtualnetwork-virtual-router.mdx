---
title: "azure_network_virtualnetwork_virtual_router"
description: "`data_azure_network_virtualnetwork_virtual_router` looks up a real, already-existing `azure_network_virtualnetwork_virtual_router`."
---

It provisions Azure Route Server, a managed BGP route reflector that lets network virtual appliances exchange dynamic routes directly with a virtual network without static route table configuration.

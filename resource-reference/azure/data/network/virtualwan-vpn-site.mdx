---
title: "azure_network_virtualwan_vpn_site"
description: "`data_azure_network_virtualwan_vpn_site` looks up a real, already-existing `azure_network_virtualwan_vpn_site`."
---

It represents a remote, on-premises site (its own address space and link details) that connects into a Virtual WAN hub via site-to-site VPN.

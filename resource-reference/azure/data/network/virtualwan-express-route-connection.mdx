---
title: "azure_network_virtualwan_express_route_connection"
description: "`data_azure_network_virtualwan_express_route_connection` looks up a real, already-existing `azure_network_virtualwan_express_route_connection`."
---

It connects an ExpressRoute circuit to a Virtual WAN hub's own ExpressRoute gateway.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualwan_express_route_connection"})

    		ubx.Data(network.VirtualwanExpressRouteConnection, "example", network.VirtualwanExpressRouteConnectionConfig{
    			ExpressRouteGatewayName: "example-express-route-gateway-name",
    		})
    	}))
    }
    ```

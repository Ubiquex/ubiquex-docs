---
title: "azure_network_networkmanager_static_member"
description: "`data_azure_network_networkmanager_static_member` looks up a real, already-existing `azure_network_networkmanager_static_member`."
---

It explicitly adds a specific virtual network to a Virtual Network Manager network group, as an alternative to dynamic, Azure Policy-based group membership.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_static_member"})

    		ubx.Data(network.NetworkmanagerStaticMember, "example", network.NetworkmanagerStaticMemberConfig{
    			NetworkGroupName:   "example-network-group-name",
    			NetworkManagerName: "example-network-manager-name",
    		})
    	}))
    }
    ```

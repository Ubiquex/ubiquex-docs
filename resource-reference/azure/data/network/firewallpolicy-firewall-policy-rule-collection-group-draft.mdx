`azure_network_firewallpolicy_firewall_policy_rule_collection_group_draft` reads the real, unpublished draft state of a rule collection group within an Azure Firewall Policy.

## Lookup arguments

<ResponseField name="firewall_policy_name" type="string" required>
  The real name of the Azure Firewall Policy this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="rule_collection_group_name" type="string" required>
  The real name of the rule collection group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

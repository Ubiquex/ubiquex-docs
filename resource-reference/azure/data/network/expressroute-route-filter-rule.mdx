---
title: "azure_network_expressroute_route_filter_rule"
description: "`data_azure_network_expressroute_route_filter_rule` looks up a real, already-existing `azure_network_expressroute_route_filter_rule`."
---

It is a single BGP community match rule within an ExpressRoute route filter.

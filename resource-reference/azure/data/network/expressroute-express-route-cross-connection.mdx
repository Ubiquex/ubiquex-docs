`data_azure_network_expressroute_express_route_cross_connection` looks up a real, already-existing `azure_network_expressroute_express_route_cross_connection`. It is the connectivity provider-managed representation of a customer's own ExpressRoute circuit, used by providers to configure circuit-level settings on the customer's behalf.

`data_azure_network_networkmanager_network_manager_routing_configuration` looks up a real, already-existing `azure_network_networkmanager_network_manager_routing_configuration`. It defines centralized routing rule(s) Virtual Network Manager applies across the virtual network(s) in a network group.

## Example

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_network_manager_routing_configuration"})

    		ubx.Data(network.NetworkmanagerNetworkManagerRoutingConfiguration, "example", network.NetworkmanagerNetworkManagerRoutingConfigurationConfig{

    		})
    	}))

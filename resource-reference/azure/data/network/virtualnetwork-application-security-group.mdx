---
title: "azure_network_virtualnetwork_application_security_group"
description: "`data_azure_network_virtualnetwork_application_security_group` looks up a real, already-existing `azure_network_virtualnetwork_application_security_group`."
---

It groups network interface(s) together as a named, logical unit, letting network security group rules reference the group instead of raw IP addresses.

---
title: "azure_network_networkmanager_commit"
description: "`data_azure_network_networkmanager_commit` looks up a real, already-existing `azure_network_networkmanager_commit`."
---

It deploys a Virtual Network Manager configuration (connectivity or security) to its own target scope, making it take actual effect.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_commit"})

    		ubx.Data(network.NetworkmanagerCommit, "example", network.NetworkmanagerCommitConfig{
    			NetworkManagerName: "example-network-manager-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { NetworkmanagerCommit } from "@ubx/sdk-azure/azure/data/network/networkmanager_commit";

    export default stack("example", () => {
      intent({ summary: "look up azure_network_networkmanager_commit" });

      data(NetworkmanagerCommit, "example", {
        networkManagerName: "example-network-manager-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.network import NetworkmanagerCommit, NetworkmanagerCommitConfig

    def describe():
        ubx.intent("look up azure_network_networkmanager_commit")

        ubx.data(NetworkmanagerCommit, "example", NetworkmanagerCommitConfig(
            network_manager_name="example-network-manager-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="network_manager_name" type="string" required>
  The real name of the Azure Virtual Network Manager this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

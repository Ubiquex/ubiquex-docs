---
title: "azure_network_virtualwan_bgp_connection"
description: "`data_azure_network_virtualwan_bgp_connection` looks up a real, already-existing `azure_network_virtualwan_bgp_connection`."
---

It establishes a BGP peering session between a Virtual WAN hub and an external router, exchanging dynamic routes without static route configuration.

---
title: "azure_network_virtualwan_route_map"
description: "`data_azure_network_virtualwan_route_map` looks up a real, already-existing `azure_network_virtualwan_route_map`."
---

It transforms route attributes (prefix, community, AS-path) as they're advertised to or received from a Virtual WAN hub connection, for advanced routing policy scenarios.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualwan_route_map"})

    		ubx.Data(network.VirtualwanRouteMap, "example", network.VirtualwanRouteMapConfig{
    			VirtualHubName: "example-virtual-hub-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { VirtualwanRouteMap } from "@ubx/sdk-azure/azure/data/network/virtualwan_route_map";

    export default stack("example", () => {
      intent({ summary: "look up azure_network_virtualwan_route_map" });

      data(VirtualwanRouteMap, "example", {
        virtualHubName: "example-virtual-hub-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.network import VirtualwanRouteMap, VirtualwanRouteMapConfig

    def describe():
        ubx.intent("look up azure_network_virtualwan_route_map")

        ubx.data(VirtualwanRouteMap, "example", VirtualwanRouteMapConfig(
            virtual_hub_name="example-virtual-hub-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="virtual_hub_name" type="string" required>
  The real name of the Virtual WAN hub this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

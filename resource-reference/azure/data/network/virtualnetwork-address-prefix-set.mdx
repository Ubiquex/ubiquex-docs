---
title: "azure_network_virtualnetwork_address_prefix_set"
description: "`data_azure_network_virtualnetwork_address_prefix_set` looks up a real, already-existing `azure_network_virtualnetwork_address_prefix_set`."
---

It defines a named, reusable set of IP address prefixes managed by Azure Virtual Network Manager, referenced by IP address management pools and connectivity/security configurations.

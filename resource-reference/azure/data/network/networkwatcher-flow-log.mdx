---
title: "azure_network_networkwatcher_flow_log"
description: "`data_azure_network_networkwatcher_flow_log` looks up a real, already-existing `azure_network_networkwatcher_flow_log`."
---

It records accepted and denied IP traffic flow information for a Network Security Group, written to a Storage account for traffic analytics and security auditing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkwatcher_flow_log"})

    		ubx.Data(network.NetworkwatcherFlowLog, "example", network.NetworkwatcherFlowLogConfig{
    			NetworkWatcherName: "example-network-watcher-name",
    		})
    	}))
    }
    ```

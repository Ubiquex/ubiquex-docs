---
title: "azure_network_interconnectgroup_interconnect_group"
description: "`data_azure_network_interconnectgroup_interconnect_group` looks up a real, already-existing `azure_network_interconnectgroup_interconnect_group`."
---

It groups ExpressRoute Direct port pair(s) together at the datacenter interconnection level, coordinating link status across the group.

---
title: "azure_network_virtualnetwork_reachability_analysis_run"
description: "`data_azure_network_virtualnetwork_reachability_analysis_run` looks up a real, already-existing `azure_network_virtualnetwork_reachability_analysis_run`."
---

It is a single execution of Azure Virtual Network Manager's own Network Verifier against a reachability analysis intent, statically checking NSGs, routes, peering, and other configuration for whether the defined traffic path would actually succeed.

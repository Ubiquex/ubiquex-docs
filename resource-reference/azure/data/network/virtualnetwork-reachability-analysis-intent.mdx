`data_azure_network_virtualnetwork_reachability_analysis_intent` looks up a real, already-existing `azure_network_virtualnetwork_reachability_analysis_intent`. It defines the source and destination traffic path Azure Virtual Network Manager's own Network Verifier should evaluate for reachability, before any actual analysis run is executed.

## Lookup arguments

<ResponseField name="network_manager_name" type="string" required>
  The real name of the Azure Virtual Network Manager this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="skip" type="number">
  The number of matching results to skip before returning the rest, for pagination. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="skip_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_key" type="string">
  The real field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_value" type="string">
  The real value results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="top" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

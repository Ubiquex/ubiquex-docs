---
title: "azure_network_virtualnetwork_ip_group"
description: "`data_azure_network_virtualnetwork_ip_group` looks up a real, already-existing `azure_network_virtualnetwork_ip_group`."
---

It is a named, reusable collection of IP address(es) or address range(s) that Azure Firewall rules can reference by name instead of enumerating addresses inline.

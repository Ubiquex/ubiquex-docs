## Lookup arguments

<ResponseField name="circuit_name" type="string" required>
  The real name of the ExpressRoute circuit this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="peering_name" type="string" required>
  The real name of the virtual network peering this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

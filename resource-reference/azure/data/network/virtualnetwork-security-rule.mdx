---
title: "azure_network_virtualnetwork_security_rule"
description: "`data_azure_network_virtualnetwork_security_rule` looks up a real, already-existing `azure_network_virtualnetwork_security_rule`."
---

It is a single custom allow/deny rule within a network security group, evaluated in priority order against matching traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_virtualnetwork_security_rule"})

    		ubx.Data(network.VirtualnetworkSecurityRule, "example", network.VirtualnetworkSecurityRuleConfig{
    			NetworkSecurityGroupName: "example-network-security-group-name",
    		})
    	}))
    }
    ```
  </Tab>

---
title: "azure_network_virtualnetwork_custom_ip_prefix"
description: "`data_azure_network_virtualnetwork_custom_ip_prefix` looks up a real, already-existing `azure_network_virtualnetwork_custom_ip_prefix`."
---

It brings a caller-owned public IP address range into Azure for advertisement and use, via Custom IP Prefix (BYOIP).

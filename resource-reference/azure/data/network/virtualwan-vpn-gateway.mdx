---
title: "azure_network_virtualwan_vpn_gateway"
description: "`data_azure_network_virtualwan_vpn_gateway` looks up a real, already-existing `azure_network_virtualwan_vpn_gateway`."
---

It provisions the site-to-site VPN gateway within a Virtual WAN hub, that VPN site connection(s) terminate on.

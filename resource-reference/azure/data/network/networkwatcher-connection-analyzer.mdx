---
title: "azure_network_networkwatcher_connection_analyzer"
description: "`data_azure_network_networkwatcher_connection_analyzer` looks up a real, already-existing `azure_network_networkwatcher_connection_analyzer`."
---

It (Connection Troubleshoot) runs a one-off connectivity check between a source and destination, reporting whether the connection succeeds and the hop(s) it takes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkwatcher_connection_analyzer"})

    		ubx.Data(network.NetworkwatcherConnectionAnalyzer, "example", network.NetworkwatcherConnectionAnalyzerConfig{
    			NetworkWatcherName: "example-network-watcher-name",
    		})
    	}))
    }
    ```
  </Tab>

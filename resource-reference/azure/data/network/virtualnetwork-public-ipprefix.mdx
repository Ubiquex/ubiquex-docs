---
title: "azure_network_virtualnetwork_public_ipprefix"
description: "`data_azure_network_virtualnetwork_public_ipprefix` looks up a real, already-existing `azure_network_virtualnetwork_public_ipprefix`."

It reserves a contiguous, statically allocated range of public IP addresses that individual public IP address resources can be created from.

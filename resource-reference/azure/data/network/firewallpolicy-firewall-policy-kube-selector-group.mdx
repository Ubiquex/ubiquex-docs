`data_azure_network_firewallpolicy_firewall_policy_kube_selector_group` looks up a real, already-existing `azure_network_firewallpolicy_firewall_policy_kube_selector_group`. It defines Kubernetes namespace/pod selector(s) that an Azure Firewall policy rule can match traffic against, for AKS-aware filtering.

`data_azure_network_virtualnetworkappliance_virtual_network_appliance` looks up a real, already-existing `azure_network_virtualnetworkappliance_virtual_network_appliance`. It deploys a third-party network virtual appliance (firewall, router) from the Azure Marketplace directly into a virtual network.

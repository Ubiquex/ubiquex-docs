---
title: "azure_network_expressroute_route_filter"
description: "`data_azure_network_expressroute_route_filter` looks up a real, already-existing `azure_network_expressroute_route_filter`."
---

It restricts which BGP community-tagged route(s) are advertised over an ExpressRoute circuit's own Microsoft Peering, limiting the Microsoft service(s) reachable through it.

---
title: "azure_network_networkwatcher_packet_capture_result"
description: "`data_azure_network_networkwatcher_packet_capture_result` looks up a real, already-existing `azure_network_networkwatcher_packet_capture_result`."
---

It captures raw network traffic to and from a specific VM, triggerable remotely without installing packet-capture software manually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkwatcher_packet_capture_result"})

    		ubx.Data(network.NetworkwatcherPacketCaptureResult, "example", network.NetworkwatcherPacketCaptureResultConfig{
    			NetworkWatcherName: "example-network-watcher-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.network import NetworkwatcherPacketCaptureResult, NetworkwatcherPacketCaptureResultConfig

    def describe():
        ubx.intent("look up azure_network_networkwatcher_packet_capture_result")

        ubx.data(NetworkwatcherPacketCaptureResult, "example", NetworkwatcherPacketCaptureResultConfig(
            network_watcher_name="example-network-watcher-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="network_watcher_name" type="string" required>
  The real name of the Network Watcher this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  URL to get the next set of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Information about packet capture sessions. Returned by the lookup.
</ResponseField>

---
title: "azure_network_virtualnetwork_ddos_custom_policy"
description: "`data_azure_network_virtualnetwork_ddos_custom_policy` looks up a real, already-existing `azure_network_virtualnetwork_ddos_custom_policy`."
---

It overrides Azure DDoS Protection's own default traffic thresholds for a specific public IP address, tuning detection sensitivity for that resource's own traffic pattern.

`data_azure_network_networksecurityperimeter_network_security_perimeter` looks up a real, already-existing `azure_network_networksecurityperimeter_network_security_perimeter`. It is the top-level Network Security Perimeter resource, defining a logical boundary around a group of PaaS resource(s) that access is restricted to and from as a unit, regardless of their own individual network configuration.

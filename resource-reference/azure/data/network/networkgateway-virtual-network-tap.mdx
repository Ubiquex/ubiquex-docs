---
title: "azure_network_networkgateway_virtual_network_tap"
description: "`data_azure_network_networkgateway_virtual_network_tap` looks up a real, already-existing `azure_network_networkgateway_virtual_network_tap`."
---

It mirrors traffic from a network interface's own Virtual Network TAP configuration to a collector destination for out-of-band monitoring.

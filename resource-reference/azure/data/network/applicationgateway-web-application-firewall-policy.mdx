`data_azure_network_applicationgateway_web_application_firewall_policy` looks up a real, already-existing `azure_network_applicationgateway_web_application_firewall_policy`. It defines the Web Application Firewall rule(s) (managed or custom) applied to matching requests reaching an Application Gateway.

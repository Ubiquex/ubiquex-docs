---
title: "azure_network_networkmanager_network_group"
description: "`data_azure_network_networkmanager_network_group` looks up a real, already-existing `azure_network_networkmanager_network_group`."
---

It is a named collection of virtual network(s), defined statically or dynamically via Azure Policy conditions, that Virtual Network Manager configurations are applied to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_network_group"})

    		ubx.Data(network.NetworkmanagerNetworkGroup, "example", network.NetworkmanagerNetworkGroupConfig{
    			NetworkManagerName: "example-network-manager-name",
    		})
    	}))
    }
    ```

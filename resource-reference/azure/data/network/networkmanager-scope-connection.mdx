---
title: "azure_network_networkmanager_scope_connection"
description: "`data_azure_network_networkmanager_scope_connection` looks up a real, already-existing `azure_network_networkmanager_scope_connection`."
---

It extends a Virtual Network Manager instance's own management scope to include another subscription or management group.

## Example

    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networkmanager_scope_connection"})

    		ubx.Data(network.NetworkmanagerScopeConnection, "example", network.NetworkmanagerScopeConnectionConfig{
    			NetworkManagerName: "example-network-manager-name",
    		})
    	}))
    }
    ```

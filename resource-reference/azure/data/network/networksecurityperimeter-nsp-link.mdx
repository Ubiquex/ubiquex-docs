---
title: "azure_network_networksecurityperimeter_nsp_link"
description: "`data_azure_network_networksecurityperimeter_nsp_link` looks up a real, already-existing `azure_network_networksecurityperimeter_nsp_link`."
---

It connects two Network Security Perimeters together, permitting resources in each to communicate as if they were in the same perimeter.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_network_networksecurityperimeter_nsp_link"})

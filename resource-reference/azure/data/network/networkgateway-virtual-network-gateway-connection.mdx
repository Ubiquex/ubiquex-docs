`data_azure_network_networkgateway_virtual_network_gateway_connection` looks up a real, already-existing `azure_network_networkgateway_virtual_network_gateway_connection`. It establishes an IPsec VPN or ExpressRoute connection between a virtual network gateway and a remote endpoint (a local network gateway, another VNet gateway, or an ExpressRoute circuit).

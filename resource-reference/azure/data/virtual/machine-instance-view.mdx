`azure_virtual_machine_instance_view` reads the real, current runtime status of a virtual machine -- its own power state, provisioning state, and installed extensions' own status.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	virtual "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/virtual"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_virtual_machine_instance_view"})

    		ubx.Data(virtual.MachineInstanceView, "example", virtual.MachineInstanceViewConfig{
    			VmName: "example-vm-name",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="vm_name" type="string" required>
  The real name of the virtual machine this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "azure_virtual_machine_scale_set_vm"
description: "`data_azure_virtual_machine_scale_set_vm` looks up a real, already-existing `azure_virtual_machine_scale_set_vm`."
---

It represents one individual VM instance that's part of a scale set, letting that specific instance be read or managed on its own rather than only through the scale set as a whole.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	virtual "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/virtual"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_virtual_machine_scale_set_vm"})

    		ubx.Data(virtual.MachineScaleSetVm, "example", virtual.MachineScaleSetVmConfig{
    			VirtualMachineScaleSetName: "example-virtual-machine-scale-set-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="virtual_machine_scale_set_name" type="string" required>
  The real name of the virtual machine scale set this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

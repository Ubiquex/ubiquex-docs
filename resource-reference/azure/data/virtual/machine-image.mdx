## Lookup arguments

<ResponseField name="edge_zone" type="string" required>
  The real Azure Edge Zone this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="offer" type="string" required>
  The real Marketplace offer this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="publisher_name" type="string" required>
  The real name of the publisher this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="skus" type="string" required>
  The real, available pricing tiers (SKUs) included in this result. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="version" type="string" required>
  The real version identifier for this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="properties" type="object">
  Describes the properties of a Virtual Machine Image. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="architecture" type="string">
      Specifies the Architecture Type Optional lookup argument.
    </ResponseField>
    <ResponseField name="automatic_osupgrade_properties" type="object">
      Describes automatic OS upgrade properties on the image. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="automatic_osupgrade_supported" type="bool" required>
          Specifies whether automatic OS upgrade is supported on the image. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="data_disk_images" type="list(object)">
      The list of data disk images information. Optional lookup argument.
    </ResponseField>
    <ResponseField name="disallowed" type="object">
      Specifies the disallowed configuration for a virtual machine image. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="vm_disk_type" type="string">
          VM disk types which are disallowed. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="features" type="list(object)">
      Optional lookup argument.
    </ResponseField>
    <ResponseField name="hyper_vgeneration" type="string">
      Specifies the HyperVGeneration Type Optional lookup argument.
    </ResponseField>
    <ResponseField name="image_deprecation_status" type="object">
      Describes image deprecation status properties on the image. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="alternative_option" type="object">
          Describes the alternative option specified by the Publisher for this image when this image is deprecated. Optional lookup argument.
          <Expandable title="properties">
            <ResponseField name="type" type="string">
              Describes the type of the alternative option. Optional lookup argument.
            </ResponseField>
            <ResponseField name="value" type="string">
              Indicates the alternative option value specified by the Publisher. This is the Offer name when the type is Offer or the Plan name when the type is Plan. Optional lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="image_state" type="string">
          Describes the state of the image. Optional lookup argument.
        </ResponseField>
        <ResponseField name="scheduled_deprecation_time" type="string">
          The time, in future, at which this image will be marked as deprecated. This scheduled time is chosen by the Publisher. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="os_disk_image" type="object">
      Contains the os disk image information. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="operating_system" type="string" required>
          This property allows you to specify the type of the OS that is included in the disk if creating a VM from user-image or a specialized VHD. Possible values are: **Windows,** **Linux.** Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="plan" type="object">
      Used for establishing the purchase context of any 3rd Party artifact through MarketPlace. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="name" type="string" required>
          The plan ID. Required lookup argument.
        </ResponseField>
        <ResponseField name="product" type="string" required>
          Specifies the product of the image from the marketplace. This is the same value as Offer under the imageReference element. Required lookup argument.
        </ResponseField>
        <ResponseField name="publisher" type="string" required>
          The publisher ID. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

It manages a group of load-balanced VM instances as a single resource, built from one common base image and configuration. The set can automatically grow or shrink in response to real demand or a defined schedule, and spreading instances across fault domains or availability zones protects the application from a single instance's failure -- up to 1,000 instances for gallery or custom images, 600 for a managed image.

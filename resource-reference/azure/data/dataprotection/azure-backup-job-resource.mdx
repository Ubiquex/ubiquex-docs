title: "azure_dataprotection_azure_backup_job_resource"

It is a backup or restore job in Azure Backup's Data Protection service, tracking one asynchronous operation (e.g. a scheduled backup run, or a restore) from start to completion.

## Example

<Tabs>
  <Tab title="Go">
    ```go

    import (
    	dataprotection "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/dataprotection"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_dataprotection_azure_backup_job_resource"})

    		ubx.Data(dataprotection.AzureBackupJobResource, "example", dataprotection.AzureBackupJobResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```

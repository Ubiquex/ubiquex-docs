---
title: "azure_dataprotection_backup_instance_resource"
description: "`data_azure_dataprotection_backup_instance_resource` looks up a real, already-existing `azure_dataprotection_backup_instance_resource`."
---

It represents one datasource (e.g. a disk, a Kubernetes cluster, a database) actually configured for backup within a Backup vault, linking it to a backup policy.

---
title: "azure_dataprotection_resource_guard_proxy_base_resource"
description: "`data_azure_dataprotection_resource_guard_proxy_base_resource` looks up a real, already-existing `azure_dataprotection_resource_guard_proxy_base_resource`."
---

It links a Backup vault to a Resource Guard, enforcing multi-user authorization (MUA) on that vault's own critical operations -- disabling immutability, changing retention, or deleting backups all then require a second approver who doesn't control the vault.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dataprotection "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/dataprotection"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_dataprotection_resource_guard_proxy_base_resource"})

    		ubx.Data(dataprotection.ResourceGuardProxyBaseResource, "example", dataprotection.ResourceGuardProxyBaseResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```

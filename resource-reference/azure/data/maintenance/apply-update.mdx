---
title: "azure_maintenance_apply_update"
description: "`data_azure_maintenance_apply_update` looks up a real, already-existing `azure_maintenance_apply_update`."

It triggers an immediate, on-demand application of pending maintenance update(s) to a resource, outside its own scheduled maintenance window.

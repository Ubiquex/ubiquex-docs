---
title: "azure_cognitiveservices_project"
description: "`data_azure_cognitiveservices_project` looks up a real, already-existing `azure_cognitiveservices_project`."
---

It is a project within an Azure AI Foundry account, scoping model deployment(s), agent(s), and connection(s) to a specific team or workload.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_project"})

    		ubx.Data(cognitiveservices.Project, "example", cognitiveservices.ProjectConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only azure --lang ts --out ./local-sdk
    import { Project } from "./local-sdk/azure/sdk/typescript/azure/data/cognitiveservices/project.ts";

    export default stack("example", () => {
      intent({ summary: "look up azure_cognitiveservices_project" });

      data(Project, "example", {
        accountName: "example-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only azure --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.cognitiveservices import Project, ProjectConfig

    def describe():
        ubx.intent("look up azure_cognitiveservices_project")

        ubx.data(Project, "example", ProjectConfig(
            account_name="example-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of projects. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Gets the list of Cognitive Services projects and their properties. Returned by the lookup.
</ResponseField>

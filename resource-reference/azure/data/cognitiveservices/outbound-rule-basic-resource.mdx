It defines an allowed outbound network destination for an Azure AI Foundry account's own managed virtual network, permitting egress to a specific service.

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="managed_network_name" type="string" required>
  The real name of the managed network this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page constructed using the continuationToken. If null, there are no additional pages. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of cognitive services accounts. Since this list may be incomplete, the nextLink field should be used to request the next list of cognitive services accounts. Returned by the lookup.
</ResponseField>

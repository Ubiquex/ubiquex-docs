`data_azure_cognitiveservices_managed_network_settings_properties_basic_resource` looks up a real, already-existing `azure_cognitiveservices_managed_network_settings_properties_basic_resource`. It configures whether an Azure AI Foundry account's own managed virtual network allows all outbound traffic by default or only explicitly approved outbound rule(s).

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page constructed using the continuationToken. If null, there are no additional pages. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of managed network settings of an account. Since this list may be incomplete, the nextLink field should be used to request the next list of cognitive services accounts. Returned by the lookup.
</ResponseField>

---
title: "azure_cognitiveservices_rai_blocklist"
description: "`data_azure_cognitiveservices_rai_blocklist` looks up a real, already-existing `azure_cognitiveservices_rai_blocklist`."
---

It defines a custom list of blocked term(s) or phrase(s) enforced by a Responsible AI content filter policy on Azure AI services model deployment(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_rai_blocklist"})

    		ubx.Data(cognitiveservices.RaiBlocklist, "example", cognitiveservices.RaiBlocklistConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

---
title: "azure_cognitiveservices_private_endpoint_connection"
description: "`data_azure_cognitiveservices_private_endpoint_connection` looks up a real, already-existing `azure_cognitiveservices_private_endpoint_connection`."
---

It represents the connection between a Private Endpoint and an Azure AI services account, tracking its own approval state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_private_endpoint_connection"})

    		ubx.Data(cognitiveservices.PrivateEndpointConnection, "example", cognitiveservices.PrivateEndpointConnectionConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>

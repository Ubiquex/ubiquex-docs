`data_azure_cognitiveservices_network_security_perimeter_configuration` looks up a real, already-existing `azure_cognitiveservices_network_security_perimeter_configuration`. It associates an Azure AI services account with a network security perimeter, restricting its own network access to the perimeter's own boundary rules.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_network_security_perimeter_configuration"})

    		ubx.Data(cognitiveservices.NetworkSecurityPerimeterConfiguration, "example", cognitiveservices.NetworkSecurityPerimeterConfigurationConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

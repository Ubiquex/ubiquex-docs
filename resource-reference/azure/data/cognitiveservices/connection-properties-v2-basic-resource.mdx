`data_azure_cognitiveservices_connection_properties_v2_basic_resource` looks up a real, already-existing `azure_cognitiveservices_connection_properties_v2_basic_resource`. It defines a connection from an Azure AI Foundry account to an external resource (a data source, an API key-authenticated service).

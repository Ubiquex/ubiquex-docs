---
title: "azure_cognitiveservices_agent_application"
description: "`data_azure_cognitiveservices_agent_application` looks up a real, already-existing `azure_cognitiveservices_agent_application`."
---

It registers an AI agent application built on Azure AI Foundry's own Agent Service, the deployable unit an agent's tools and instructions are packaged into.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_agent_application"})

    		ubx.Data(cognitiveservices.AgentApplication, "example", cognitiveservices.AgentApplicationConfig{
    			AccountName: "example-account-name",
    			ProjectName: "example-project-name",
    			Count:       1,
    			Names:       []string{"example"},
    			OrderBy:     "example",
    			OrderByAsc:  true,
    			SearchText:  "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="count" type="number">
  The total number of matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="names" type="list(string)">
  The real, given names of the objects this request is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="order_by" type="string">
  The real field results are ordered by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="order_by_asc" type="bool">
  Whether results are ordered ascending by the given field. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="project_name" type="string" required>
  The real name of the project this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="search_text" type="string">
  The real search query string. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

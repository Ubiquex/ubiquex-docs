---
title: "azure_cognitiveservices_rai_tool_label"
description: "`data_azure_cognitiveservices_rai_tool_label` looks up a real, already-existing `azure_cognitiveservices_rai_tool_label`."
---

It classifies a specific tool an AI agent can call under a Responsible AI risk category, so Foundry Guardrails can apply appropriate policy when that tool is invoked.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_rai_tool_label"})

    		ubx.Data(cognitiveservices.RaiToolLabel, "example", cognitiveservices.RaiToolLabelConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { RaiToolLabel } from "@ubx/sdk-azure/azure/data/cognitiveservices/rai_tool_label";

    export default stack("example", () => {
      intent({ summary: "look up azure_cognitiveservices_rai_tool_label" });

      });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.cognitiveservices import RaiToolLabel, RaiToolLabelConfig

    def describe():
        ubx.intent("look up azure_cognitiveservices_rai_tool_label")

        ubx.data(RaiToolLabel, "example", RaiToolLabelConfig(
            account_name="example-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of RaiToolLabels. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of RAI Tool Labels. Returned by the lookup.
</ResponseField>

---
title: "azure_cognitiveservices_account"
description: "`data_azure_cognitiveservices_account` looks up a real, already-existing `azure_cognitiveservices_account`."
---

It provisions an Azure AI services (Cognitive Services) account -- or an Azure AI Foundry (Microsoft Foundry) resource -- the top-level container that model deployment(s) and API access are billed and managed under.

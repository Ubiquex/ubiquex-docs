---
title: "azure_cognitiveservices_encryption_scope"
description: "`data_azure_cognitiveservices_encryption_scope` looks up a real, already-existing `azure_cognitiveservices_encryption_scope`."
---

It defines a customer-managed encryption key configuration scoped to a subset of data within an Azure AI services account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_encryption_scope"})

    		ubx.Data(cognitiveservices.EncryptionScope, "example", cognitiveservices.EncryptionScopeConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

    from ubx.azure.data.cognitiveservices import EncryptionScope, EncryptionScopeConfig

    def describe():
        ubx.intent("look up azure_cognitiveservices_encryption_scope")

        ubx.data(EncryptionScope, "example", EncryptionScopeConfig(

        ))

    if __name__ == "__main__":

---
title: "azure_cognitiveservices_deployment"
description: "`data_azure_cognitiveservices_deployment` looks up a real, already-existing `azure_cognitiveservices_deployment`."
---

It is a specific model deployment (e.g. a GPT or embedding model) on an Azure AI services / Azure OpenAI account, servable for inference calls.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_deployment"})

    		ubx.Data(cognitiveservices.Deployment, "example", cognitiveservices.DeploymentConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Deployment } from "@ubx/sdk-azure/azure/data/cognitiveservices/deployment";

    export default stack("example", () => {
      intent({ summary: "look up azure_cognitiveservices_deployment" });

      data(Deployment, "example", {
        accountName: "example-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.cognitiveservices import Deployment, DeploymentConfig

    def describe():
        ubx.intent("look up azure_cognitiveservices_deployment")

        ubx.data(Deployment, "example", DeploymentConfig(
            account_name="example-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of Deployment. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Gets the list of Cognitive Services accounts Deployment and their properties. Returned by the lookup.
</ResponseField>

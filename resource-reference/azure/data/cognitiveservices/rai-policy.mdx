---
title: "azure_cognitiveservices_rai_policy"
description: "`data_azure_cognitiveservices_rai_policy` looks up a real, already-existing `azure_cognitiveservices_rai_policy`."
---

It defines the Responsible AI content filter configuration (categories, severity thresholds) enforced on Azure AI services model deployment(s) it's attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_rai_policy"})

    		ubx.Data(cognitiveservices.RaiPolicy, "example", cognitiveservices.RaiPolicyConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

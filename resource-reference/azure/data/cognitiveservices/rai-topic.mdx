---
title: "azure_cognitiveservices_rai_topic"
description: "`data_azure_cognitiveservices_rai_topic` looks up a real, already-existing `azure_cognitiveservices_rai_topic`."
---

It defines a custom sensitive topic a Responsible AI content filter policy detects and restricts, beyond Microsoft's own built-in harm categories.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_rai_topic"})

    		ubx.Data(cognitiveservices.RaiTopic, "example", cognitiveservices.RaiTopicConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.cognitiveservices import RaiTopic, RaiTopicConfig

        ubx.data(RaiTopic, "example", RaiTopicConfig(
            account_name="example-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of RaiTopics. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of RaiTopic. Returned by the lookup.
</ResponseField>

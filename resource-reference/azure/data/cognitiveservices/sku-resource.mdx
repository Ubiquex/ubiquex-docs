## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="deployment_name" type="string" required>
  The real name of the deployment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of deployment skus. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Gets the list of Cognitive Services accounts deployment skus. Returned by the lookup.
</ResponseField>

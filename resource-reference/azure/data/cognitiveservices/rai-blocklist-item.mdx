## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="rai_blocklist_name" type="string" required>
  The real name of the Responsible AI content-filter blocklist this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

</ResponseField>

`data_azure_cognitiveservices_commitment_plan_account_association` looks up a real, already-existing `azure_cognitiveservices_commitment_plan_account_association`. It attaches an Azure AI services account to a commitment plan, applying the plan's own discounted pricing to that account's usage.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cognitiveservices_commitment_plan_account_association"})

    		ubx.Data(cognitiveservices.CommitmentPlanAccountAssociation, "example", cognitiveservices.CommitmentPlanAccountAssociationConfig{
    			CommitmentPlanName: "example-commitment-plan-name",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="commitment_plan_name" type="string" required>
  The real name of the commitment plan this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of Commitment Plan Account Association. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Gets the list of Cognitive Services Commitment Plan Account Association and their properties. Returned by the lookup.
</ResponseField>

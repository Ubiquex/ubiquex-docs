---
title: "azure_botservice_bot"
description: "`data_azure_botservice_bot` looks up a real, already-existing `azure_botservice_bot`."
---

It registers a conversational bot with Azure AI Bot Service, the resource its own channel(s) and connection(s) are configured under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	botservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/botservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_botservice_bot"})

    		ubx.Data(botservice.Bot, "example", botservice.BotConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    export default stack("example", () => {

      data(Bot, "example", {
        apiVersion: "example",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.botservice import Bot, BotConfig

    def describe():
        ubx.intent("look up azure_botservice_bot")

        ubx.data(Bot, "example", BotConfig(
            api_version="example",
            subscription_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of bot service resources. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Gets the list of bot service results and their properties. Returned by the lookup.
</ResponseField>

---
title: "azure_botservice_bot_channel"
description: "`data_azure_botservice_bot_channel` looks up a real, already-existing `azure_botservice_bot_channel`."
---

It connects an Azure AI Bot Service bot to a specific messaging channel (Teams, Slack, web chat), making it reachable from that platform.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	botservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/botservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_botservice_bot_channel"})

    		ubx.Data(botservice.BotChannel, "example", botservice.BotChannelConfig{
    			ApiVersion:        "example",
    			ResourceGroupName: "example-resource-group-name",
    			ResourceName:      "example-resource-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of bot service channel resources. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  Gets the list of bot service channel results and their properties. Returned by the lookup.
</ResponseField>

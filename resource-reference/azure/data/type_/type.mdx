title: "azure_type"
description: "`azure_type` is a real, live lookup against Microsoft Azure, generated from azure's own real schema -- read-only, never created or destroyed."
---

`azure_type` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	type_ "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/type_"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_type"})

    		ubx.Data(type_.Type, "example", type_.TypeConfig{
    			PublisherName: "example-publisher-name",
    			Type:          "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Type } from "@ubx/sdk-azure/azure/data/type_/type";

    export default stack("example", () => {
      intent({ summary: "look up azure_type" });

      data(Type, "example", {
        publisherName: "example-publisher-name",
        type: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.type_ import Type, TypeConfig

    def describe():
        ubx.intent("look up azure_type")

        ubx.data(Type, "example", TypeConfig(
            publisher_name="example-publisher-name",
            type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

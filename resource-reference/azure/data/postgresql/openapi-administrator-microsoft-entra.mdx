`azure_postgresql_openapi_administrator_microsoft_entra` looks up a real Microsoft Entra ID administrator configured for an Azure Database for PostgreSQL flexible server.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	postgresql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/postgresql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_postgresql_openapi_administrator_microsoft_entra"})

    		ubx.Data(postgresql.OpenapiAdministratorMicrosoftEntra, "example", postgresql.OpenapiAdministratorMicrosoftEntraConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>

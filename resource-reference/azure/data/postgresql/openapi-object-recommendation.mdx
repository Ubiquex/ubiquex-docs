`azure_postgresql_openapi_object_recommendation` reads a real, system-generated performance recommendation for an Azure Database for PostgreSQL flexible server.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	postgresql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/postgresql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_postgresql_openapi_object_recommendation"})

    		ubx.Data(postgresql.OpenapiObjectRecommendation, "example", postgresql.OpenapiObjectRecommendationConfig{
    			ServerName:         "example-server-name",
    			TuningOption:       "example",
    			RecommendationType: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="recommendation_type" type="string">
  The real type of this recommendation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="server_name" type="string" required>
  The real name of the server this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="tuning_option" type="string" required>
  The real, recommended tuning option this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

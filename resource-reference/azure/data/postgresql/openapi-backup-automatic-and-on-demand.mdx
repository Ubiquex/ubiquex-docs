`azure_postgresql_openapi_backup_automatic_and_on_demand` looks up a real automatic or on-demand backup of an Azure Database for PostgreSQL flexible server.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	postgresql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/postgresql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_postgresql_openapi_backup_automatic_and_on_demand"})

    		ubx.Data(postgresql.OpenapiBackupAutomaticAndOnDemand, "example", postgresql.OpenapiBackupAutomaticAndOnDemandConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>

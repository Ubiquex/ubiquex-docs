---
title: "azure_datadog_monitoring_tag_rules"
description: "`data_azure_datadog_monitoring_tag_rules` looks up a real, already-existing `azure_datadog_monitoring_tag_rules`."
---

It configures which resource tags include or exclude resource(s) from monitoring by a Datadog resource on Azure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datadog "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datadog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datadog_monitoring_tag_rules"})

    		ubx.Data(datadog.MonitoringTagRules, "example", datadog.MonitoringTagRulesConfig{
    			MonitorName: "example-monitor-name",
    		})
    	}))
    }
    ```
  </Tab>

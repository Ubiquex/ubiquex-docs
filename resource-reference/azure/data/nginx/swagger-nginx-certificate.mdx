---
title: "azure_nginx_swagger_nginx_certificate"
description: "`data_azure_nginx_swagger_nginx_certificate` looks up a real, already-existing `azure_nginx_swagger_nginx_certificate`."
---

It uploads a TLS certificate (referenced from Key Vault) to an NGINX for Azure deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	nginx "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/nginx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_nginx_swagger_nginx_certificate"})

    		ubx.Data(nginx.SwaggerNginxCertificate, "example", nginx.SwaggerNginxCertificateConfig{
    			DeploymentName: "example-deployment-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SwaggerNginxCertificate } from "@ubx/sdk-azure/azure/data/nginx/swagger_nginx_certificate";

    export default stack("example", () => {
      intent({ summary: "look up azure_nginx_swagger_nginx_certificate" });

      data(SwaggerNginxCertificate, "example", {
        deploymentName: "example-deployment-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.nginx import SwaggerNginxCertificate, SwaggerNginxCertificateConfig

    def describe():
        ubx.intent("look up azure_nginx_swagger_nginx_certificate")

        ubx.data(SwaggerNginxCertificate, "example", SwaggerNginxCertificateConfig(
            deployment_name="example-deployment-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

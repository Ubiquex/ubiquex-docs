---
title: "azure_nginx_swagger_nginx_configuration_response"
description: "`data_azure_nginx_swagger_nginx_configuration_response` looks up a real, already-existing `azure_nginx_swagger_nginx_configuration_response`."
---

It is the current NGINX configuration file set applied to an NGINX for Azure deployment.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	nginx "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/nginx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_nginx_swagger_nginx_configuration_response"})

    		ubx.Data(nginx.SwaggerNginxConfigurationResponse, "example", nginx.SwaggerNginxConfigurationResponseConfig{
    			DeploymentName: "example-deployment-name",
    		})
    	}))
    }
    ```

---
title: "azure_managedservices_registration_definition"
description: "`data_azure_managedservices_registration_definition` looks up a real, already-existing `azure_managedservices_registration_definition`."
---

It defines the role(s) and principal(s) an Azure Lighthouse delegation grants a managing tenant over a delegated customer resource.

<ResponseField name="api_version" type="string" required>

</ResponseField>

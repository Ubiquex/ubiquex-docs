`data_azure_sql_databasesecurityalertpolicies_database_security_alert_policy` looks up a real, already-existing `azure_sql_databasesecurityalertpolicies_database_security_alert_policy`. It enables Microsoft Defender for SQL threat detection alerts on a single Azure SQL Database.

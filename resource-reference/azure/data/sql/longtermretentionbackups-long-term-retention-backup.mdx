`data_azure_sql_longtermretentionbackups_long_term_retention_backup` looks up a real, already-existing `azure_sql_longtermretentionbackups_long_term_retention_backup`. It is a single Azure SQL Database backup retained under a long-term retention policy, beyond standard point-in-time restore retention.

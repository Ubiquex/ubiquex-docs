`data_azure_sql_servertrustcertificates_server_trust_certificate` looks up a real, already-existing `azure_sql_servertrustcertificates_server_trust_certificate`. It establishes trust for a distributed availability group linking an Azure SQL Managed Instance to an external SQL Server instance.

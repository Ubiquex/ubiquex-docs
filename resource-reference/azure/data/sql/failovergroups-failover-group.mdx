---
title: "azure_sql_failovergroups_failover_group"
description: "`data_azure_sql_failovergroups_failover_group` looks up a real, already-existing `azure_sql_failovergroups_failover_group`."
---

It groups Azure SQL Database(s) on a primary server for coordinated automatic or manual failover to a secondary server in another region.

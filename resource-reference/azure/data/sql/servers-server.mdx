---
title: "azure_sql_servers_server"
description: "`data_azure_sql_servers_server` looks up a real, already-existing `azure_sql_servers_server`."
---

It is an Azure SQL logical server, the administrative and connectivity boundary that Azure SQL Database(s) and elastic pool(s) are created under.

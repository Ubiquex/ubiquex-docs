`data_azure_sql_instancefailovergroups_instance_failover_group` looks up a real, already-existing `azure_sql_instancefailovergroups_instance_failover_group`. It groups Azure SQL Managed Instance(s) on a primary instance for coordinated automatic or manual failover to a secondary instance in another region.

`data_azure_sql_serverazureadonlyauthentications_server_azure_adonly_authentication` looks up a real, already-existing `azure_sql_serverazureadonlyauthentications_server_azure_adonly_authentication`. It restricts an Azure SQL logical server to Microsoft Entra ID authentication only, disabling SQL authentication entirely.

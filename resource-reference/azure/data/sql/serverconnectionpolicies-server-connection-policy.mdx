`data_azure_sql_serverconnectionpolicies_server_connection_policy` looks up a real, already-existing `azure_sql_serverconnectionpolicies_server_connection_policy`. It sets whether connections to an Azure SQL logical server use the redirect or proxy connection policy, affecting connection latency and required outbound firewall rules.

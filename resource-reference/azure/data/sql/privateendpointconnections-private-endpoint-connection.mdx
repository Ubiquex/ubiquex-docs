`data_azure_sql_privateendpointconnections_private_endpoint_connection` looks up a real, already-existing `azure_sql_privateendpointconnections_private_endpoint_connection`. It represents the connection between a Private Endpoint and an Azure SQL logical server, tracking its own approval state.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

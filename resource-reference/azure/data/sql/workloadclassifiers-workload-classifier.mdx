---
title: "azure_sql_workloadclassifiers_workload_classifier"
description: "`data_azure_sql_workloadclassifiers_workload_classifier` looks up a real, already-existing `azure_sql_workloadclassifiers_workload_classifier`."
---

It assigns incoming query(ies) matching a defined condition to a specific workload group on an Azure SQL Database, for workload management.

---
title: "azure_sql_syncmembers_sync_member"
description: "`data_azure_sql_syncmembers_sync_member` looks up a real, already-existing `azure_sql_syncmembers_sync_member`."

It is a single database participating in a SQL Data Sync group, either as the hub or a member.

## Lookup arguments

<ResponseField name="database_name" type="string" required>

</ResponseField>

<ResponseField name="sync_group_name" type="string" required>
  The real name of the SQL Data Sync group this lookup is scoped to. **(AI-inferred)** Required lookup argument.

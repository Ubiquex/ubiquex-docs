---
title: "azure_sql_serverkeys_server_key"
description: "`data_azure_sql_serverkeys_server_key` looks up a real, already-existing `azure_sql_serverkeys_server_key`."
---

It registers a Key Vault key with an Azure SQL logical server for use in transparent data encryption.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_serverkeys_server_key"})

    		ubx.Data(sql.ServerkeysServerKey, "example", sql.ServerkeysServerKeyConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>

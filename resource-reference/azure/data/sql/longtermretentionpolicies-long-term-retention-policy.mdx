`data_azure_sql_longtermretentionpolicies_long_term_retention_policy` looks up a real, already-existing `azure_sql_longtermretentionpolicies_long_term_retention_policy`. It defines the weekly/monthly/yearly backup retention schedule applied to an Azure SQL Database beyond its own standard short-term retention.

---
title: "azure_sql_jobsteps_job_step"
description: "`data_azure_sql_jobsteps_job_step` looks up a real, already-existing `azure_sql_jobsteps_job_step`."
---

It is a single T-SQL script step within an Elastic Database Jobs job, run in sequence against the job's own target group.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_jobsteps_job_step"})

    		ubx.Data(sql.JobstepsJobStep, "example", sql.JobstepsJobStepConfig{
    			JobAgentName: "example-job-agent-name",
    			JobName:      "example-job-name",
    			ServerName:   "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.azure.data.sql import JobstepsJobStep, JobstepsJobStepConfig

    def describe():
        ubx.intent("look up azure_sql_jobsteps_job_step")

        ubx.data(JobstepsJobStep, "example", JobstepsJobStepConfig(
            job_agent_name="example-job-agent-name",
            job_name="example-job-name",
            server_name="example-server-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="job_agent_name" type="string" required>
  The real name of the SQL Elastic Job agent this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_name" type="string" required>
  The real name of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="server_name" type="string" required>
  The real name of the server this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The JobStep items on this page Returned by the lookup.
</ResponseField>

---
title: "azure_sql_jobcredentials_job_credential"
description: "`data_azure_sql_jobcredentials_job_credential` looks up a real, already-existing `azure_sql_jobcredentials_job_credential`."
---

It stores a credential an Elastic Database Jobs agent uses to authenticate to target database(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_jobcredentials_job_credential"})

    		ubx.Data(sql.JobcredentialsJobCredential, "example", sql.JobcredentialsJobCredentialConfig{
    			JobAgentName: "example-job-agent-name",
    			ServerName:   "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="job_agent_name" type="string" required>
  The real name of the SQL Elastic Job agent this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="server_name" type="string" required>
  The real name of the server this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

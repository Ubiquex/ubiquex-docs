---
title: "azure_sql_replicationlinks_replication_link"
description: "`data_azure_sql_replicationlinks_replication_link` looks up a real, already-existing `azure_sql_replicationlinks_replication_link`."

It reports an active geo-replication link between an Azure SQL Database and its own secondary replica.

---
title: "azure_sql_restorepoints_restore_point"
description: "`data_azure_sql_restorepoints_restore_point` looks up a real, already-existing `azure_sql_restorepoints_restore_point`."
---

It is a caller-created, named restore point for an Azure SQL Database, letting it be restored to that exact moment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_restorepoints_restore_point"})

    		ubx.Data(sql.RestorepointsRestorePoint, "example", sql.RestorepointsRestorePointConfig{
    			DatabaseName: "example-database-name",
    			ServerName:   "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { RestorepointsRestorePoint } from "@ubx/sdk-azure/azure/data/sql/restorepoints_restore_point";

    export default stack("example", () => {
      intent({ summary: "look up azure_sql_restorepoints_restore_point" });

      data(RestorepointsRestorePoint, "example", {
        databaseName: "example-database-name",
        serverName: "example-server-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.sql import RestorepointsRestorePoint, RestorepointsRestorePointConfig

    def describe():
        ubx.intent("look up azure_sql_restorepoints_restore_point")

        ubx.data(RestorepointsRestorePoint, "example", RestorepointsRestorePointConfig(
            database_name="example-database-name",
            server_name="example-server-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="database_name" type="string" required>
  The real name of the database this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="server_name" type="string" required>
  The real name of the server this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

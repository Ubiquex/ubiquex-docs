`data_azure_sql_managedinstanceadministrators_managed_instance_administrator` looks up a real, already-existing `azure_sql_managedinstanceadministrators_managed_instance_administrator`. It designates a Microsoft Entra ID principal as the administrator for an Azure SQL Managed Instance.

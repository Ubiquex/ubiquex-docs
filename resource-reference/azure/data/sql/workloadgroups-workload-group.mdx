---
title: "azure_sql_workloadgroups_workload_group"
description: "`data_azure_sql_workloadgroups_workload_group` looks up a real, already-existing `azure_sql_workloadgroups_workload_group`."
---

It reserves a share of an Azure SQL Database's own compute resources for a specific class of workload, isolating it from contention with other query traffic.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_workloadgroups_workload_group"})

    		ubx.Data(sql.WorkloadgroupsWorkloadGroup, "example", sql.WorkloadgroupsWorkloadGroupConfig{
    			DatabaseName: "example-database-name",
    			ServerName:   "example-server-name",
    		})
    	}))
    }

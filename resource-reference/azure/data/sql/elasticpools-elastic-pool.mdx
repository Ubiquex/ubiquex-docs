---
title: "azure_sql_elasticpools_elastic_pool"
description: "`data_azure_sql_elasticpools_elastic_pool` looks up a real, already-existing `azure_sql_elasticpools_elastic_pool`."
---

It is a shared pool of compute resources that multiple Azure SQL Databases draw from, letting variable-usage databases share capacity cost-effectively.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_elasticpools_elastic_pool"})

    		ubx.Data(sql.ElasticpoolsElasticPool, "example", sql.ElasticpoolsElasticPoolConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```

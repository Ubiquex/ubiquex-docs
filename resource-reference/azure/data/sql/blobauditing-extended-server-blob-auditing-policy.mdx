`data_azure_sql_blobauditing_extended_server_blob_auditing_policy` looks up a real, already-existing `azure_sql_blobauditing_extended_server_blob_auditing_policy`. It extends an Azure SQL logical server's own audit logging with additional auditing actions and predicates.

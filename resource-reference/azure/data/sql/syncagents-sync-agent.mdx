---
title: "azure_sql_syncagents_sync_agent"
description: "`data_azure_sql_syncagents_sync_agent` looks up a real, already-existing `azure_sql_syncagents_sync_agent`."
---

It is a local agent enabling SQL Data Sync between an on-premises SQL Server database and Azure SQL Database.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_syncagents_sync_agent"})

    		ubx.Data(sql.SyncagentsSyncAgent, "example", sql.SyncagentsSyncAgentConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

    ```python
    if __name__ == "__main__":
    ```

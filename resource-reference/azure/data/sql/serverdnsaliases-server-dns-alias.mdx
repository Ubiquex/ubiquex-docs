---
title: "azure_sql_serverdnsaliases_server_dns_alias"
description: "`data_azure_sql_serverdnsaliases_server_dns_alias` looks up a real, already-existing `azure_sql_serverdnsaliases_server_dns_alias`."
---

It creates an alternate, alias DNS name pointing to an Azure SQL logical server, usable to redirect connections during failover without changing client connection strings.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/sql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_sql_serverdnsaliases_server_dns_alias"})

    		ubx.Data(sql.ServerdnsaliasesServerDnsAlias, "example", sql.ServerdnsaliasesServerDnsAliasConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```

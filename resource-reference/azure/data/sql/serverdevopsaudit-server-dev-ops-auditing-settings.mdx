`data_azure_sql_serverdevopsaudit_server_dev_ops_auditing_settings` looks up a real, already-existing `azure_sql_serverdevopsaudit_server_dev_ops_auditing_settings`. It enables DevOps audit logging (schema and permission changes) for an Azure SQL logical server, exported to Log Analytics or Event Hub.

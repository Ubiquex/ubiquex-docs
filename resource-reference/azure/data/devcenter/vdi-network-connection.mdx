---
title: "azure_devcenter_vdi_network_connection"
description: "`data_azure_devcenter_vdi_network_connection` looks up a real, already-existing `azure_devcenter_vdi_network_connection`."
---

It defines the virtual network a Microsoft Dev Box's own dev box definition is domain-joined and deployed into.

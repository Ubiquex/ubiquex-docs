`azure_devcenter_environment_definition` looks up a real, catalog-sourced environment definition (an IaC template) usable in a Dev Center Deployment Environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devcenter_environment_definition"})

    		ubx.Data(devcenter.EnvironmentDefinition, "example", devcenter.EnvironmentDefinitionConfig{
    			CatalogName:   "example-catalog-name",
    			DevCenterName: "example-dev-center-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="catalog_name" type="string" required>
  The real name of the catalog this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="dev_center_name" type="string" required>
  The real name of the dev center this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

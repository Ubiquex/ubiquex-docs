---
title: "azure_devcenter_project_policy"
description: "`data_azure_devcenter_project_policy` looks up a real, already-existing `azure_devcenter_project_policy`."
---

It restricts which user(s) or group(s) can access resources across multiple Dev Box projects collectively, via a centrally defined policy.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devcenter_project_policy"})

    		ubx.Data(devcenter.ProjectPolicy, "example", devcenter.ProjectPolicyConfig{
    			DevCenterName: "example-dev-center-name",
    		})
    	}))
    }
    ```
  </Tab>

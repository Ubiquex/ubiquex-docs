---
title: "azure_devcenter_vdi_schedule"
description: "`data_azure_devcenter_vdi_schedule` looks up a real, already-existing `azure_devcenter_vdi_schedule`."
---

It configures an automatic shutdown schedule for dev box(es) in a pool, reducing idle compute cost.

---
title: "azure_devcenter_environment_type"
description: "`data_azure_devcenter_environment_type` looks up a real, already-existing `azure_devcenter_environment_type`."
---

It defines a named category of deployment environment (e.g. `Sandbox` or `Production`) at the dev center level, that project(s) can enable for self-service provisioning.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devcenter_environment_type"})

    		ubx.Data(devcenter.EnvironmentType, "example", devcenter.EnvironmentTypeConfig{
    			DevCenterName: "example-dev-center-name",
    		})
    	}))
    }
    ```

    from ubx.azure.data.devcenter import EnvironmentType, EnvironmentTypeConfig

    def describe():
        ubx.intent("look up azure_devcenter_environment_type")

        ubx.data(EnvironmentType, "example", EnvironmentTypeConfig(
            dev_center_name="example-dev-center-name",

    if __name__ == "__main__":

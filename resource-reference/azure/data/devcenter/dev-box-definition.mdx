---
title: "azure_devcenter_dev_box_definition"
description: "`data_azure_devcenter_dev_box_definition` looks up a real, already-existing `azure_devcenter_dev_box_definition`."

It defines the image and compute/storage SKU a Microsoft Dev Box cloud development workstation is created from.

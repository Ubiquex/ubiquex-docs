---
title: "azure_devcenter_attached_network_connection"
description: "`data_azure_devcenter_attached_network_connection` looks up a real, already-existing `azure_devcenter_attached_network_connection`."
---

It attaches a Microsoft Dev Box network connection to a dev center, making it available for dev box definitions across the dev center's own project(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devcenter_attached_network_connection"})

    		ubx.Data(devcenter.AttachedNetworkConnection, "example", devcenter.AttachedNetworkConnectionConfig{
    			DevCenterName: "example-dev-center-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { AttachedNetworkConnection } from "@ubx/sdk-azure/azure/data/devcenter/attached_network_connection";

    export default stack("example", () => {
      intent({ summary: "look up azure_devcenter_attached_network_connection" });

      data(AttachedNetworkConnection, "example", {
        devCenterName: "example-dev-center-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.devcenter import AttachedNetworkConnection, AttachedNetworkConnectionConfig

    def describe():
        ubx.intent("look up azure_devcenter_attached_network_connection")

        ubx.data(AttachedNetworkConnection, "example", AttachedNetworkConnectionConfig(
            dev_center_name="example-dev-center-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

---
title: "azure_devcenter_dev_center"
description: "`data_azure_devcenter_dev_center` looks up a real, already-existing `azure_devcenter_dev_center`."

It is the top-level Microsoft Dev Box / Azure Deployment Environments resource that project(s), catalog(s), and dev box definition(s) are managed centrally under.

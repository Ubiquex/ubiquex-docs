---
title: "azure_devcenter_project"
description: "`data_azure_devcenter_project` looks up a real, already-existing `azure_devcenter_project`."
---

It scopes Microsoft Dev Box and Azure Deployment Environments access to a specific team, granting them self-service provisioning of dev box(es) and environment(s) from dev center-provided resources.

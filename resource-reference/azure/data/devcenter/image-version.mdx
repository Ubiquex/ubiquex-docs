## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_devcenter_image_version"})

    		ubx.Data(devcenter.ImageVersion, "example", devcenter.ImageVersionConfig{
    			DevCenterName: "example-dev-center-name",
    			GalleryName:   "example-gallery-name",
    			ImageName:     "example-image-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="dev_center_name" type="string" required>
  The real name of the dev center this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="gallery_name" type="string" required>
  The real name of the Compute Gallery this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="image_name" type="string" required>
  The real name of the image this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

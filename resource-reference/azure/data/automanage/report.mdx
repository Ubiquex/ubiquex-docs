## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	automanage "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automanage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automanage_report"})

    		ubx.Data(automanage.Report, "example", automanage.ReportConfig{
    			ClusterName:                        "example-cluster-name",
    			ConfigurationProfileAssignmentName: "example-configuration-profile-assignment-name",
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">

    ```python
    # ubx sdk gen --only azure --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.automanage import Report, ReportConfig

    def describe():
        ubx.intent("look up azure_automanage_report")

        ubx.data(Report, "example", ReportConfig(
            cluster_name="example-cluster-name",
            configuration_profile_assignment_name="example-configuration-profile-assignment-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="cluster_name" type="string" required>
  The real name of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="configuration_profile_assignment_name" type="string" required>
  The real name of the configuration profile assignment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="value" type="list(object)">
  Result of the list report operation. Returned by the lookup.
</ResponseField>

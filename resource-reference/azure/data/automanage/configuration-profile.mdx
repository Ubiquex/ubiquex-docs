---
title: "azure_automanage_configuration_profile"
description: "`data_azure_automanage_configuration_profile` looks up a real, already-existing `azure_automanage_configuration_profile`."
---

It defines a reusable Azure Automanage best-practice configuration (backup, security, monitoring settings) that VM(s) can be assigned.

---
title: "azure_automanage_configuration_profile_assignment"
description: "`data_azure_automanage_configuration_profile_assignment` looks up a real, already-existing `azure_automanage_configuration_profile_assignment`."
---

It applies an Azure Automanage configuration profile to a specific VM, keeping it continuously conformant to the profile's own best practices.

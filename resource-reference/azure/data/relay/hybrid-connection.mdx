---
title: "azure_relay_hybrid_connection"
description: "`data_azure_relay_hybrid_connection` looks up a real, already-existing `azure_relay_hybrid_connection`."
---

It establishes outbound-only relayed connectivity from an on-premises or firewalled service to Azure, without opening inbound firewall ports.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	relay "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/relay"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_relay_hybrid_connection"})

    		ubx.Data(relay.HybridConnection, "example", relay.HybridConnectionConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.relay import HybridConnection, HybridConnectionConfig

    def describe():
        ubx.intent("look up azure_relay_hybrid_connection")

        ubx.data(HybridConnection, "example", HybridConnectionConfig(
            namespace_name="example-namespace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

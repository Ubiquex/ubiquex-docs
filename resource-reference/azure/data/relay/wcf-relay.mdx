---
title: "azure_relay_wcf_relay"
description: "`data_azure_relay_wcf_relay` looks up a real, already-existing `azure_relay_wcf_relay`."
---

It relays a WCF (Windows Communication Foundation) service through Azure Relay, exposing an on-premises WCF endpoint to internet callers without inbound firewall changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	relay "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/relay"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_relay_wcf_relay"})

    		ubx.Data(relay.WcfRelay, "example", relay.WcfRelayConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.azure.data.relay import WcfRelay, WcfRelayConfig

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

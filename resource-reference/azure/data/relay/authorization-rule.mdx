---
title: "azure_relay_authorization_rule"
description: "`data_azure_relay_authorization_rule` looks up a real, already-existing `azure_relay_authorization_rule`."
---

It defines a shared access policy (with specific permissions) for connecting to an Azure Relay namespace, hybrid connection, or WCF relay.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	relay "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/relay"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_relay_authorization_rule"})

    		ubx.Data(relay.AuthorizationRule, "example", relay.AuthorizationRuleConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>

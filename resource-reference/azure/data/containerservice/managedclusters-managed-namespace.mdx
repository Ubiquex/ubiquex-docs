`data_azure_containerservice_managedclusters_managed_namespace` looks up a real, already-existing `azure_containerservice_managedclusters_managed_namespace`. It provisions a Kubernetes namespace on an AKS cluster as its own manageable Azure resource, with per-namespace resource quotas, network policy, and labels applied declaratively.

`data_azure_containerservice_managedclusters_trusted_access_role_binding` looks up a real, already-existing `azure_containerservice_managedclusters_trusted_access_role_binding`. It grants another Azure resource's own system-assigned managed identity secure, RBAC-scoped access to an AKS cluster's own API server, without exposing the cluster to public networks.

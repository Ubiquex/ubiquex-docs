---
title: "azure_containerservice_fleets_auto_upgrade_profile"
description: "`data_azure_containerservice_fleets_auto_upgrade_profile` looks up a real, already-existing `azure_containerservice_fleets_auto_upgrade_profile`."
---

It schedules AKS Fleet member cluster(s) to be automatically upgraded to a new Kubernetes or node image version on a defined cadence.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	containerservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/containerservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_containerservice_fleets_auto_upgrade_profile"})

    		ubx.Data(containerservice.FleetsAutoUpgradeProfile, "example", containerservice.FleetsAutoUpgradeProfileConfig{
    			FleetName: "example-fleet-name",
    		})
    	}))
    }
    ```

---
title: "azure_containerservice_fleets_update_run"
description: "`data_azure_containerservice_fleets_update_run` looks up a real, already-existing `azure_containerservice_fleets_update_run`."
---

It is a single execution of rolling a Kubernetes or node image update across an AKS Fleet's own member cluster(s), following a defined update strategy.

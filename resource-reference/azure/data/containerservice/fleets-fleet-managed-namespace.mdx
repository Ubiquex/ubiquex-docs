---
title: "azure_containerservice_fleets_fleet_managed_namespace"
description: "`data_azure_containerservice_fleets_fleet_managed_namespace` looks up a real, already-existing `azure_containerservice_fleets_fleet_managed_namespace`."
---

It provisions the same managed Kubernetes namespace configuration across every member cluster of an AKS Fleet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	containerservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/containerservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_containerservice_fleets_fleet_managed_namespace"})

    		ubx.Data(containerservice.FleetsFleetManagedNamespace, "example", containerservice.FleetsFleetManagedNamespaceConfig{
    			FleetName: "example-fleet-name",
    		})
    	}))
    }
    ```

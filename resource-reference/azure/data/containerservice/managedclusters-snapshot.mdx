---
title: "azure_containerservice_managedclusters_snapshot"
description: "`data_azure_containerservice_managedclusters_snapshot` looks up a real, already-existing `azure_containerservice_managedclusters_snapshot`."
---

It captures a point-in-time configuration snapshot of an AKS cluster or node pool, usable as a template for creating new ones with the same settings.

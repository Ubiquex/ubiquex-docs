`data_azure_containerservice_managedclusters_private_endpoint_connection` looks up a real, already-existing `azure_containerservice_managedclusters_private_endpoint_connection`. It represents the connection between a Private Endpoint and an AKS cluster's own private API server, tracking its own approval state.

## Lookup arguments

<ResponseField name="agent_pool_name" type="string" required>
  The real name of the agent pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="properties" type="object">
  The list of available upgrade versions. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="kubernetes_version" type="string" required>
      The Kubernetes version (major.minor.patch). Required lookup argument.
    </ResponseField>
    <ResponseField name="latest_node_image_version" type="string">
      The latest AKS supported node image version. Optional lookup argument.
    </ResponseField>
    <ResponseField name="os_type" type="string" required>
      The operating system type. The default is Linux. Required lookup argument.
    </ResponseField>
    <ResponseField name="recently_used_versions" type="list(object)">
      List of historical good versions for rollback operations. Returned by the lookup.
    </ResponseField>
    <ResponseField name="upgrades" type="list(object)">
      List of orchestrator types and versions available for upgrade. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

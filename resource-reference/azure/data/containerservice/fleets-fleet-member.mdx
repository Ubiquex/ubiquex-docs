---
title: "azure_containerservice_fleets_fleet_member"
description: "`data_azure_containerservice_fleets_fleet_member` looks up a real, already-existing `azure_containerservice_fleets_fleet_member`."
---

It joins an existing AKS cluster to a Fleet, making it eligible for Fleet-orchestrated update runs and multi-cluster workload placement.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_containerservice_fleets_fleet_member"})

    		ubx.Data(containerservice.FleetsFleetMember, "example", containerservice.FleetsFleetMemberConfig{

    		})
    	}))
    }

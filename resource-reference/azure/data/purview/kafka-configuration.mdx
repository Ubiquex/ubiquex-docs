---
title: "azure_purview_kafka_configuration"
description: "`data_azure_purview_kafka_configuration` looks up a real, already-existing `azure_purview_kafka_configuration`."
---

It configures the Event Hubs-based Kafka-compatible endpoint(s) a Microsoft Purview account uses to publish and consume metadata event(s).

---
title: "azure_healthbot_health_bot"
description: "`data_azure_healthbot_health_bot` looks up a real, already-existing `azure_healthbot_health_bot`."
---

It provisions a Microsoft Healthcare Bot instance, a conversational AI service purpose-built for healthcare organizations to build compliant symptom-checking and triage bots.

## Example

<Tabs>

    ```go
    package main

    import (
    	healthbot "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/healthbot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_healthbot_health_bot"})

    		ubx.Data(healthbot.HealthBot, "example", healthbot.HealthBotConfig{})
    	}))
    }
    ```

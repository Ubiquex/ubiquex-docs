---
title: "azure_dedicated_host_group"
description: "`data_azure_dedicated_host_group` looks up a real, already-existing `azure_dedicated_host_group`."
---

It is the resource that represents a collection of dedicated hosts. It's created in a specific region and, if you want zone-level fault isolation, a specific availability zone -- every host you add to the group inherits that placement. The group also controls whether new VMs get placed onto its hosts automatically or only when you explicitly pick a host.

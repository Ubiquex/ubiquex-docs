## Lookup arguments

<ResponseField name="host_group_name" type="string" required>
  The real name of the Dedicated Host Group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="host_name" type="string" required>
  The real name of the Dedicated Host this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(string)">
  The list of dedicated host sizes. Returned by the lookup.
</ResponseField>

## Example

    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    import (
    	run "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/run"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_run_command_document_base"})

    	}))
    }

## Lookup arguments

_This lookup takes no arguments._

## Result properties

<ResponseField name="next_link" type="string">
  The uri to fetch the next page of run commands. Call ListNext() with this to fetch the next page of run commands. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of virtual machine run commands. Returned by the lookup.
</ResponseField>

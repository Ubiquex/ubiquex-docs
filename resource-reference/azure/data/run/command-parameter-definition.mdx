## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	run "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/run"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_run_command_parameter_definition"})

    		ubx.Data(run.CommandParameterDefinition, "example", run.CommandParameterDefinitionConfig{
    			CommandId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { CommandParameterDefinition } from "@ubx/sdk-azure/azure/data/run/command_parameter_definition";

    export default stack("example", () => {
      intent({ summary: "look up azure_run_command_parameter_definition" });

      data(CommandParameterDefinition, "example", {
        commandId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.run import CommandParameterDefinition, CommandParameterDefinitionConfig

    def describe():
        ubx.intent("look up azure_run_command_parameter_definition")

        ubx.data(CommandParameterDefinition, "example", CommandParameterDefinitionConfig(
            command_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="command_id" type="string" required>
  The real, unique identifier of this command. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="parameters" type="list(object)">
  The parameters used by the script. Returned by the lookup.
</ResponseField>

<ResponseField name="script" type="list(string)">
  The script to be executed. Returned by the lookup.
</ResponseField>

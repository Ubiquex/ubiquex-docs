---
title: "azure_ssh_public_key_resource"
description: "`data_azure_ssh_public_key_resource` looks up a real, already-existing `azure_ssh_public_key_resource`."
---

It stores an SSH public key in Azure as its own standalone resource, independent of any single VM. Once created (generated fresh as RSA or Ed25519, or uploaded from an existing key you already have), the same stored key can be attached to any number of new VM deployments instead of pasting the raw key text in every time.

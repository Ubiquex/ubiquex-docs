`data_azure_applicationinsights_components_application_insights_component` looks up a real, already-existing `azure_applicationinsights_components_application_insights_component`. It is an Application Insights component, the top-level resource that collects and stores an application's own telemetry (requests, dependencies, exceptions, custom events) for monitoring and diagnostics.

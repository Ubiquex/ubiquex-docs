`data_azure_applicationinsights_apikeys_application_insights_component_apikey` looks up a real, already-existing `azure_applicationinsights_apikeys_application_insights_component_apikey`. It is an API key for an Application Insights component, used to authenticate an external tool or the Application Insights REST API against that component's own telemetry.

---
title: "azure_batch_openapi_application"
description: "`data_azure_batch_openapi_application` looks up a real, already-existing `azure_batch_openapi_application`."
---

It registers a versioned application package with an Azure Batch account, deployable to compute node(s) for task execution.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	batch "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/batch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_batch_openapi_application"})

    		ubx.Data(batch.OpenapiApplication, "example", batch.OpenapiApplicationConfig{
    			AccountName: "example-account-name",
    			Maxresults:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx

    if __name__ == "__main__":
    ```

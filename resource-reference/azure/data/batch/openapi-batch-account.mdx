---
title: "azure_batch_openapi_batch_account"
description: "`data_azure_batch_openapi_batch_account` looks up a real, already-existing `azure_batch_openapi_batch_account`."
---

It is the top-level Azure Batch resource that pool(s), job(s), and application(s) are created within, for large-scale parallel and HPC batch job execution.

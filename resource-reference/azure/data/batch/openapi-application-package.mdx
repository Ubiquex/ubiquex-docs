---
title: "azure_batch_openapi_application_package"
description: "`data_azure_batch_openapi_application_package` looks up a real, already-existing `azure_batch_openapi_application_package`."
---

It is a specific uploaded version of an Azure Batch application, containing the actual executable and supporting file(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	batch "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/batch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_batch_openapi_application_package"})

    		ubx.Data(batch.OpenapiApplicationPackage, "example", batch.OpenapiApplicationPackageConfig{
    			AccountName:     "example-account-name",
    			ApplicationName: "example-application-name",
    			Maxresults:      1,
    		})
    	}))
    }
    ```
  </Tab>

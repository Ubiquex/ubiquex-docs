---
title: "azure_batch_openapi_pool"
description: "`data_azure_batch_openapi_pool` looks up a real, already-existing `azure_batch_openapi_pool`."
---

It is a collection of compute node(s) within an Azure Batch account that job(s) and their own task(s) actually run on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	batch "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/batch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_batch_openapi_pool"})

    		ubx.Data(batch.OpenapiPool, "example", batch.OpenapiPoolConfig{
    			AccountName: "example-account-name",
    			Maxresults:  1,
    		})
    	}))
    }
    ```
  </Tab>

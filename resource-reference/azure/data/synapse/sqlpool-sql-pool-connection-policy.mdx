## Lookup arguments

<ResponseField name="connection_policy_name" type="string" required>
  The real name of the connection policy this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sql_pool_name" type="string" required>
  The real name of the Synapse SQL pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

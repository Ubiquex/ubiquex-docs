---
title: "azure_synapse_sqlpool_sensitivity_label"
description: "`data_azure_synapse_sqlpool_sensitivity_label` looks up a real, already-existing `azure_synapse_sqlpool_sensitivity_label`."
---

It classifies a specific column in a Synapse dedicated SQL pool with a data sensitivity label (e.g. `Confidential`), surfaced in vulnerability assessment and compliance reporting.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_sensitivity_label"})

    		ubx.Data(synapse.SqlpoolSensitivityLabel, "example", synapse.SqlpoolSensitivityLabelConfig{
    			SqlPoolName: "example-sql-pool-name",
    		})
    	}))
    }
    ```
  </Tab>

---
title: "azure_synapse_sqlpool_restore_point"
description: "`data_azure_synapse_sqlpool_restore_point` looks up a real, already-existing `azure_synapse_sqlpool_restore_point`."
---

It is a caller-created, named restore point for a Synapse dedicated SQL pool, letting it be restored to that exact moment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_restore_point"})

    		ubx.Data(synapse.SqlpoolRestorePoint, "example", synapse.SqlpoolRestorePointConfig{
    			SqlPoolName: "example-sql-pool-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SqlpoolRestorePoint } from "@ubx/sdk-azure/azure/data/synapse/sqlpool_restore_point";

    export default stack("example", () => {
      intent({ summary: "look up azure_synapse_sqlpool_restore_point" });

      data(SqlpoolRestorePoint, "example", {
        sqlPoolName: "example-sql-pool-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.synapse import SqlpoolRestorePoint, SqlpoolRestorePointConfig

    def describe():
        ubx.intent("look up azure_synapse_sqlpool_restore_point")

        ubx.data(SqlpoolRestorePoint, "example", SqlpoolRestorePointConfig(
            sql_pool_name="example-sql-pool-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

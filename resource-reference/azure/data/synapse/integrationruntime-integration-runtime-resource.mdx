`data_azure_synapse_integrationruntime_integration_runtime_resource` looks up a real, already-existing `azure_synapse_integrationruntime_integration_runtime_resource`. It is the compute infrastructure (Azure-hosted or self-hosted) a Synapse Pipelines activity actually executes on.

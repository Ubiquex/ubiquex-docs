title: "azure_synapse_workspace"
description: "`data_azure_synapse_workspace` looks up a real, already-existing `azure_synapse_workspace`."

It is a Synapse workspace, the unified analytics platform combining SQL pool(s), Spark pool(s), and Pipelines under a single collaborative workspace.

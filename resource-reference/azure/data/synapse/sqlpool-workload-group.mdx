---
title: "azure_synapse_sqlpool_workload_group"
description: "`data_azure_synapse_sqlpool_workload_group` looks up a real, already-existing `azure_synapse_sqlpool_workload_group`."
---

It reserves a share of a Synapse dedicated SQL pool's own compute resources for a specific class of workload, isolating it from contention with other query traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_workload_group"})

    		ubx.Data(synapse.SqlpoolWorkloadGroup, "example", synapse.SqlpoolWorkloadGroupConfig{
    			SqlPoolName: "example-sql-pool-name",
    		})
    	}))
    }
    ```
  </Tab>

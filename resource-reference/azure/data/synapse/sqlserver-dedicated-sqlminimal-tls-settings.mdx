`data_azure_synapse_sqlserver_dedicated_sqlminimal_tls_settings` looks up a real, already-existing `azure_synapse_sqlserver_dedicated_sqlminimal_tls_settings`. It sets the minimum TLS protocol version accepted for connections to a Synapse workspace's own dedicated SQL endpoint.

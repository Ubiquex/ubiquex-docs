---

It enables encryption-at-rest for a Synapse dedicated SQL pool's own data and log files.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_transparent_data_encryption"})

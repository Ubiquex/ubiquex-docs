---
title: "azure_synapse_sqlpool_data_masking_rule"
description: "`data_azure_synapse_sqlpool_data_masking_rule` looks up a real, already-existing `azure_synapse_sqlpool_data_masking_rule`."
---

It defines a single dynamic data masking rule (a column and masking function) applied within a Synapse dedicated SQL pool's own masking policy.

## Example

    ```go
    package main

    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_data_masking_rule"})

    		ubx.Data(synapse.SqlpoolDataMaskingRule, "example", synapse.SqlpoolDataMaskingRuleConfig{
    			DataMaskingPolicyName: "example-data-masking-policy-name",
    			SqlPoolName:           "example-sql-pool-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="data_masking_policy_name" type="string" required>
  The real name of the data masking policy this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sql_pool_name" type="string" required>
  The real name of the Synapse SQL pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="value" type="list(object)">
  The list of Sql pool data masking rules. Returned by the lookup.
</ResponseField>

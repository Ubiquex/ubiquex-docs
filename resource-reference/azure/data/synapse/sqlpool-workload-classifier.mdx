---
title: "azure_synapse_sqlpool_workload_classifier"
description: "`data_azure_synapse_sqlpool_workload_classifier` looks up a real, already-existing `azure_synapse_sqlpool_workload_classifier`."
---

It assigns incoming query(ies) matching a defined condition to a specific workload group on a Synapse dedicated SQL pool, for workload management.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_workload_classifier"})

    		ubx.Data(synapse.SqlpoolWorkloadClassifier, "example", synapse.SqlpoolWorkloadClassifierConfig{
    			SqlPoolName:       "example-sql-pool-name",
    			WorkloadGroupName: "example-workload-group-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="sql_pool_name" type="string" required>
  The real name of the Synapse SQL pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="workload_group_name" type="string" required>
  The real name of the workload group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

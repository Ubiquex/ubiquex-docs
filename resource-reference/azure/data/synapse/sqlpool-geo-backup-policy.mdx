---
title: "azure_synapse_sqlpool_geo_backup_policy"
description: "`data_azure_synapse_sqlpool_geo_backup_policy` looks up a real, already-existing `azure_synapse_sqlpool_geo_backup_policy`."
---

It controls whether a Synapse dedicated SQL pool's own automated backups are geo-replicated to a paired region.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_geo_backup_policy"})

    		ubx.Data(synapse.SqlpoolGeoBackupPolicy, "example", synapse.SqlpoolGeoBackupPolicyConfig{
    			SqlPoolName: "example-sql-pool-name",
    		})
    	}))
    }
    ```

## Lookup arguments

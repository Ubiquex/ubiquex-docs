`data_azure_synapse_sqlpool_extended_sql_pool_blob_auditing_policy` looks up a real, already-existing `azure_synapse_sqlpool_extended_sql_pool_blob_auditing_policy`. It extends a Synapse dedicated SQL pool's own audit logging with additional, database-specific auditing actions and predicates beyond the server-level default.

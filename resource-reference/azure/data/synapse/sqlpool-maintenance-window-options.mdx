## Lookup arguments

<ResponseField name="maintenance_window_options_name" type="string" required>
  The real name of the maintenance window options this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sql_pool_name" type="string" required>
  The real name of the Synapse SQL pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

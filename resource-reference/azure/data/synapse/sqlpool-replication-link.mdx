## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	synapse "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/synapse"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_synapse_sqlpool_replication_link"})

    		ubx.Data(synapse.SqlpoolReplicationLink, "example", synapse.SqlpoolReplicationLinkConfig{
    			SqlPoolName: "example-sql-pool-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SqlpoolReplicationLink } from "@ubx/sdk-azure/azure/data/synapse/sqlpool_replication_link";

    export default stack("example", () => {
      intent({ summary: "look up azure_synapse_sqlpool_replication_link" });

      data(SqlpoolReplicationLink, "example", {
        sqlPoolName: "example-sql-pool-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.synapse import SqlpoolReplicationLink, SqlpoolReplicationLinkConfig

    def describe():
        ubx.intent("look up azure_synapse_sqlpool_replication_link")

        ubx.data(SqlpoolReplicationLink, "example", SqlpoolReplicationLinkConfig(
            sql_pool_name="example-sql-pool-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="sql_pool_name" type="string" required>
  The real name of the Synapse SQL pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  Link to retrieve next page of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of Sql pool replication links housed in the Sql pool. Returned by the lookup.
</ResponseField>

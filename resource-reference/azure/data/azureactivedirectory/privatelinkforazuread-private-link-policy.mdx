`data_azure_azureactivedirectory_privatelinkforazuread_private_link_policy` looks up a real, already-existing `azure_azureactivedirectory_privatelinkforazuread_private_link_policy`. It restricts Microsoft Entra ID sign-in for a tenant to only occur through an approved Private Link connection, blocking access from outside the configured network(s).

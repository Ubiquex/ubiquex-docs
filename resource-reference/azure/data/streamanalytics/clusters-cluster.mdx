---
title: "azure_streamanalytics_clusters_cluster"
description: "`data_azure_streamanalytics_clusters_cluster` looks up a real, already-existing `azure_streamanalytics_clusters_cluster`."

It provisions a dedicated Stream Analytics cluster, single-tenant capacity reserved for large-scale streaming job(s) at predictable, reserved throughput.

---
title: "azure_streamanalytics_inputs_input"
description: "`data_azure_streamanalytics_inputs_input` looks up a real, already-existing `azure_streamanalytics_inputs_input`."

It defines a source (Event Hub, IoT Hub, Blob Storage) a Stream Analytics job reads real-time data from.

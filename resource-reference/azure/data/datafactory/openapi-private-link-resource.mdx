`azure_datafactory_openapi_private_link_resource` reads a real Private Link resource exposed by an Azure Data Factory, that a Private Endpoint can connect to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_private_link_resource"})

    		ubx.Data(datafactory.OpenapiPrivateLinkResource, "example", datafactory.OpenapiPrivateLinkResourceConfig{
    			FactoryName: "example-factory-name",
    		})
    	}))
    }
    ```
  </Tab>

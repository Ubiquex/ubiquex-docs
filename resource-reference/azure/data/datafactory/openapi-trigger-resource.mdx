---
title: "azure_datafactory_openapi_trigger_resource"
description: "`data_azure_datafactory_openapi_trigger_resource` looks up a real, already-existing `azure_datafactory_openapi_trigger_resource`."
---

It defines when a Data Factory pipeline runs automatically -- on a schedule, in response to a storage event, or when a tumbling window elapses.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_trigger_resource"})

    		ubx.Data(datafactory.OpenapiTriggerResource, "example", datafactory.OpenapiTriggerResourceConfig{
    			FactoryName: "example-factory-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.datafactory import OpenapiTriggerResource, OpenapiTriggerResourceConfig

    def describe():
        ubx.intent("look up azure_datafactory_openapi_trigger_resource")

        ubx.data(OpenapiTriggerResource, "example", OpenapiTriggerResourceConfig(
            factory_name="example-factory-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

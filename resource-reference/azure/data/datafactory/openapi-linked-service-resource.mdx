---
title: "azure_datafactory_openapi_linked_service_resource"
description: "`data_azure_datafactory_openapi_linked_service_resource` looks up a real, already-existing `azure_datafactory_openapi_linked_service_resource`."
---

It defines the connection information and credentials a Data Factory uses to connect to an external data store or compute service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_linked_service_resource"})

    		ubx.Data(datafactory.OpenapiLinkedServiceResource, "example", datafactory.OpenapiLinkedServiceResourceConfig{
    			FactoryName: "example-factory-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.azure.data.datafactory import OpenapiLinkedServiceResource, OpenapiLinkedServiceResourceConfig

    def describe():
        ubx.intent("look up azure_datafactory_openapi_linked_service_resource")

        ubx.data(OpenapiLinkedServiceResource, "example", OpenapiLinkedServiceResourceConfig(
            factory_name="example-factory-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

`data_azure_datafactory_openapi_managed_private_endpoint_resource` looks up a real, already-existing `azure_datafactory_openapi_managed_private_endpoint_resource`. It creates a Private Endpoint within a Data Factory's own managed virtual network, letting it privately reach a data source without traversing the public internet.

## Example

<Tabs>

    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_managed_private_endpoint_resource"})

    		ubx.Data(datafactory.OpenapiManagedPrivateEndpointResource, "example", datafactory.OpenapiManagedPrivateEndpointResourceConfig{
    			FactoryName:               "example-factory-name",
    			ManagedVirtualNetworkName: "example-managed-virtual-network-name",
    		})
    	}))
    }
    ```

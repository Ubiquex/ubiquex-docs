---
title: "azure_datafactory_openapi_credential_resource"
description: "`data_azure_datafactory_openapi_credential_resource` looks up a real, already-existing `azure_datafactory_openapi_credential_resource`."
---

It stores a reusable credential (a managed identity or service principal) within a Data Factory, referenced by linked service(s) needing to authenticate.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_credential_resource"})

    		ubx.Data(datafactory.OpenapiCredentialResource, "example", datafactory.OpenapiCredentialResourceConfig{
    			FactoryName: "example-factory-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiCredentialResource } from "@ubx/sdk-azure/azure/data/datafactory/openapi_credential_resource";

    export default stack("example", () => {
      intent({ summary: "look up azure_datafactory_openapi_credential_resource" });

      data(OpenapiCredentialResource, "example", {
        factoryName: "example-factory-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.datafactory import OpenapiCredentialResource, OpenapiCredentialResourceConfig

    def describe():
        ubx.intent("look up azure_datafactory_openapi_credential_resource")

        ubx.data(OpenapiCredentialResource, "example", OpenapiCredentialResourceConfig(
            factory_name="example-factory-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="factory_name" type="string" required>
  The real name of the Azure Data Factory this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The CredentialResource items on this page Returned by the lookup.
</ResponseField>

`azure_datafactory_openapi_integration_runtime_outbound_network_dependencies_category_endpoint` reads a real, required outbound network endpoint for an Azure Data Factory integration runtime.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_integration_runtime_outbound_network_dependencies_category_endpoint"})

    		ubx.Data(datafactory.OpenapiIntegrationRuntimeOutboundNetworkDependenciesCategoryEndpoint, "example", datafactory.OpenapiIntegrationRuntimeOutboundNetworkDependenciesCategoryEndpointConfig{
    			FactoryName:            "example-factory-name",
    			IntegrationRuntimeName: "example-integration-runtime-name",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="factory_name" type="string" required>
  The real name of the Azure Data Factory this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="integration_runtime_name" type="string" required>
  The real name of the Data Factory or Synapse integration runtime this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of outbound network dependency endpoints. Returned by the lookup.

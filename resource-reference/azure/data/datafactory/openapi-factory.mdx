---
title: "azure_datafactory_openapi_factory"
description: "`data_azure_datafactory_openapi_factory` looks up a real, already-existing `azure_datafactory_openapi_factory`."
---

It is the top-level Azure Data Factory resource that pipeline(s), dataset(s), and linked service(s) are created within.

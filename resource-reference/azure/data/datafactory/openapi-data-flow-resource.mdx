---
title: "azure_datafactory_openapi_data_flow_resource"
description: "`data_azure_datafactory_openapi_data_flow_resource` looks up a real, already-existing `azure_datafactory_openapi_data_flow_resource`."
---

It defines a visually designed Mapping Data Flow, a Spark-executed data transformation graph within a Data Factory pipeline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_datafactory_openapi_data_flow_resource"})

    		ubx.Data(datafactory.OpenapiDataFlowResource, "example", datafactory.OpenapiDataFlowResourceConfig{
    			FactoryName: "example-factory-name",
    		})
    	}))
    }
    ```

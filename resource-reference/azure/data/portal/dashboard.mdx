---
title: "azure_portal_dashboard"
description: "`data_azure_portal_dashboard` looks up a real, already-existing `azure_portal_dashboard`."
---

It is a shared Azure portal dashboard, a saved, customizable arrangement of tile(s) visualizing resource status and metrics.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	portal "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/portal"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_portal_dashboard"})

    		ubx.Data(portal.Dashboard, "example", portal.DashboardConfig{})
    	}))
    }
    ```

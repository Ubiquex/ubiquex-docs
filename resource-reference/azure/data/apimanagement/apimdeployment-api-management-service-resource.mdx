`data_azure_apimanagement_apimdeployment_api_management_service_resource` looks up a real, already-existing `azure_apimanagement_apimdeployment_api_management_service_resource`. It is the top-level Azure API Management service instance, the resource that API(s), product(s), and their own policy and gateway configuration are managed under.

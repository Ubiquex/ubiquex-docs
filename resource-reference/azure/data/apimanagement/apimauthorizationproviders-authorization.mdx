`data_azure_apimanagement_apimauthorizationproviders_authorization` looks up a real, already-existing `azure_apimanagement_apimauthorizationproviders_authorization`. It holds an OAuth-authorized credential (obtained via an authorization provider) that Azure API Management policy can use to call a backend on a user's own behalf.

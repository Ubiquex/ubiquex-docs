`data_azure_apimanagement_apimauthorizationproviders_authorization_provider` looks up a real, already-existing `azure_apimanagement_apimauthorizationproviders_authorization_provider`. It registers an OAuth 2.0 identity provider with Azure API Management, letting policies obtain and manage delegated user credentials for calling backend APIs.

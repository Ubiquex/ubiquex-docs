`data_azure_apimanagement_apigateway_api_management_gateway_resource` looks up a real, already-existing `azure_apimanagement_apigateway_api_management_gateway_resource`. It is the self-hosted or cloud gateway data-plane component of Azure API Management that actually processes and routes API traffic.

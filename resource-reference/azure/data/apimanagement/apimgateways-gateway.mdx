---
title: "azure_apimanagement_apimgateways_gateway"
description: "`data_azure_apimanagement_apimgateways_gateway` looks up a real, already-existing `azure_apimanagement_apimgateways_gateway`."
---

It registers a self-hosted or workspace gateway with Azure API Management, that specific API(s) can be deployed to independently of the managed cloud gateway.

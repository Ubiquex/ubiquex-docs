`azure_apimanagement_apimprivatelink_service` reads a real Private Link resource exposed by an API Management instance, that a Private Endpoint can connect to.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_apimanagement_apimprivatelink_service"})

    		ubx.Data(apimanagement.ApimprivatelinkService, "example", apimanagement.ApimprivatelinkServiceConfig{})
    	}))
    }

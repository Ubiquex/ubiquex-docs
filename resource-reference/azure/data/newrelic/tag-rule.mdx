---
title: "azure_newrelic_tag_rule"
description: "`data_azure_newrelic_tag_rule` looks up a real, already-existing `azure_newrelic_tag_rule`."
---

It configures which resource tags include or exclude resource(s) from monitoring by a New Relic resource on Azure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	newrelic "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/newrelic"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_newrelic_tag_rule"})

    		ubx.Data(newrelic.TagRule, "example", newrelic.TagRuleConfig{
    			MonitorName: "example-monitor-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { TagRule } from "@ubx/sdk-azure/azure/data/newrelic/tag_rule";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.newrelic import TagRule, TagRuleConfig

    def describe():

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

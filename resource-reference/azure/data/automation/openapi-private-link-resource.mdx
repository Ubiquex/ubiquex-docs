`azure_automation_openapi_private_link_resource` reads a real Private Link resource exposed by an Azure Automation account, that a Private Endpoint can connect to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_private_link_resource"})

    		ubx.Data(automation.OpenapiPrivateLinkResource, "example", automation.OpenapiPrivateLinkResourceConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="runbook_name" type="string" required>
  The real name of the runbook this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="creation_time" type="string">
  Gets or sets the creation time of the runbook draft. Returned by the lookup.
</ResponseField>

<ResponseField name="draft_content_link" type="object">
  Definition of the content link. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="content_hash" type="object">
      Definition of the runbook property type. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="algorithm" type="string" required>
          Gets or sets the content hash algorithm used to hash the content. Required lookup argument.
        </ResponseField>
        <ResponseField name="value" type="string" required>
          Gets or sets expected hash value of the content. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="uri" type="string">
      Gets or sets the uri of content. Optional lookup argument.
    </ResponseField>
    <ResponseField name="version" type="string">
      Gets or sets the version of the content. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="in_edit" type="bool">
  Gets or sets whether runbook is in edit mode. Returned by the lookup.
</ResponseField>

<ResponseField name="last_modified_time" type="string">
  Gets or sets the last modified time of the runbook draft. Returned by the lookup.
</ResponseField>

<ResponseField name="output_types" type="list(string)">
  Gets or sets the runbook output types. Returned by the lookup.
</ResponseField>

<ResponseField name="parameters" type="map(object)">
  Gets or sets the runbook draft parameters. Returned by the lookup.
</ResponseField>

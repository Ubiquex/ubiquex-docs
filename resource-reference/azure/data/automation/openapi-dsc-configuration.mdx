---
title: "azure_automation_openapi_dsc_configuration"
description: "`data_azure_automation_openapi_dsc_configuration` looks up a real, already-existing `azure_automation_openapi_dsc_configuration`."
---

It defines a PowerShell Desired State Configuration script managed by Azure Automation State Configuration, describing the target state for registered node(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_dsc_configuration"})

    		ubx.Data(automation.OpenapiDscConfiguration, "example", automation.OpenapiDscConfigurationConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiDscConfiguration, OpenapiDscConfigurationConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_dsc_configuration")

        ubx.data(OpenapiDscConfiguration, "example", OpenapiDscConfigurationConfig(
            automation_account_name="example-automation-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

---
title: "azure_automation_openapi_hybrid_runbook_worker_group"
description: "`data_azure_automation_openapi_hybrid_runbook_worker_group` looks up a real, already-existing `azure_automation_openapi_hybrid_runbook_worker_group`."
---

It groups related hybrid runbook worker(s) together, that a runbook job can be targeted to run on any member of.

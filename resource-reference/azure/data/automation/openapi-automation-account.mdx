---
title: "azure_automation_openapi_automation_account"
description: "`data_azure_automation_openapi_automation_account` looks up a real, already-existing `azure_automation_openapi_automation_account`."
---

It is the top-level Azure Automation resource that runbook(s), schedule(s), and other automation asset(s) are organized within.

---
title: "azure_automation_openapi_connection"
description: "`data_azure_automation_openapi_connection` looks up a real, already-existing `azure_automation_openapi_connection`."
---

It stores connection details for an external service (of a specific connection type) that Azure Automation runbook(s) authenticate against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_connection"})

    		ubx.Data(automation.OpenapiConnection, "example", automation.OpenapiConnectionConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiConnection } from "@ubx/sdk-azure/azure/data/automation/openapi_connection";

    export default stack("example", () => {
      intent({ summary: "look up azure_automation_openapi_connection" });

      data(OpenapiConnection, "example", {
        automationAccountName: "example-automation-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiConnection, OpenapiConnectionConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_connection")

        ubx.data(OpenapiConnection, "example", OpenapiConnectionConfig(
            automation_account_name="example-automation-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The Connection items on this page Returned by the lookup.
</ResponseField>

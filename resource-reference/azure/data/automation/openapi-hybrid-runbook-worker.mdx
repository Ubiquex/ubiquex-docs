---
title: "azure_automation_openapi_hybrid_runbook_worker"
description: "`data_azure_automation_openapi_hybrid_runbook_worker` looks up a real, already-existing `azure_automation_openapi_hybrid_runbook_worker`."
---

It registers a machine (on-premises or another cloud) as a hybrid worker, letting Azure Automation runbooks execute directly on it rather than Azure-hosted sandboxes.

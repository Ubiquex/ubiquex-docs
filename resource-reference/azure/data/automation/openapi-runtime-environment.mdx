---
title: "azure_automation_openapi_runtime_environment"
description: "`data_azure_automation_openapi_runtime_environment` looks up a real, already-existing `azure_automation_openapi_runtime_environment`."
---

It defines a custom language version and package set that PowerShell or Python runbook(s) execute within, beyond Azure Automation's own default runtime.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_runtime_environment"})

    		ubx.Data(automation.OpenapiRuntimeEnvironment, "example", automation.OpenapiRuntimeEnvironmentConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiRuntimeEnvironment } from "@ubx/sdk-azure/azure/data/automation/openapi_runtime_environment";

    export default stack("example", () => {
      intent({ summary: "look up azure_automation_openapi_runtime_environment" });

      data(OpenapiRuntimeEnvironment, "example", {
        automationAccountName: "example-automation-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiRuntimeEnvironment, OpenapiRuntimeEnvironmentConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_runtime_environment")

        ubx.data(OpenapiRuntimeEnvironment, "example", OpenapiRuntimeEnvironmentConfig(
            automation_account_name="example-automation-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

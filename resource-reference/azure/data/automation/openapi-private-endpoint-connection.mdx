title: "azure_automation_openapi_private_endpoint_connection"

It represents the connection between a Private Endpoint and an Azure Automation account, tracking its own approval state.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_private_endpoint_connection"})

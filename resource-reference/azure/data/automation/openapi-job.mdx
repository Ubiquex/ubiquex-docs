---
title: "azure_automation_openapi_job"
description: "`data_azure_automation_openapi_job` looks up a real, already-existing `azure_automation_openapi_job`."
---

It is a single execution of an Azure Automation runbook.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_job"})

    		ubx.Data(automation.OpenapiJob, "example", automation.OpenapiJobConfig{
    			AutomationAccountName: "example-automation-account-name",
    			JobName:               "example-job-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiJob } from "@ubx/sdk-azure/azure/data/automation/openapi_job";

    export default stack("example", () => {
      intent({ summary: "look up azure_automation_openapi_job" });

      data(OpenapiJob, "example", {
        automationAccountName: "example-automation-account-name",
        jobName: "example-job-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiJob, OpenapiJobConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_job")

        ubx.data(OpenapiJob, "example", OpenapiJobConfig(
            automation_account_name="example-automation-account-name",
            job_name="example-job-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_name" type="string" required>
  The real name of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

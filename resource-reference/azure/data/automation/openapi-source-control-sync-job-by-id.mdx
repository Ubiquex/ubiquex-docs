## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="source_control_name" type="string" required>
  The real name of the source control connection this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="source_control_sync_job_id" type="string" required>
  The real, unique identifier of the source control sync job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

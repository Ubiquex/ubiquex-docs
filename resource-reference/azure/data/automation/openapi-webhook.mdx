---
title: "azure_automation_openapi_webhook"
description: "`data_azure_automation_openapi_webhook` looks up a real, already-existing `azure_automation_openapi_webhook`."
---

It exposes an HTTP endpoint that, when called, triggers a specific Azure Automation runbook to run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_webhook"})

    		ubx.Data(automation.OpenapiWebhook, "example", automation.OpenapiWebhookConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiWebhook } from "@ubx/sdk-azure/azure/data/automation/openapi_webhook";

    export default stack("example", () => {
      intent({ summary: "look up azure_automation_openapi_webhook" });

      data(OpenapiWebhook, "example", {
        automationAccountName: "example-automation-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiWebhook, OpenapiWebhookConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_webhook")

        ubx.data(OpenapiWebhook, "example", OpenapiWebhookConfig(
            automation_account_name="example-automation-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The Webhook items on this page Returned by the lookup.
</ResponseField>

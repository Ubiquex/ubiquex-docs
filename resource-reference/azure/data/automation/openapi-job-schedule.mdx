---
title: "azure_automation_openapi_job_schedule"
description: "`data_azure_automation_openapi_job_schedule` looks up a real, already-existing `azure_automation_openapi_job_schedule`."
---

It links an Azure Automation runbook to a schedule, triggering it to run automatically at the schedule's own defined times.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_job_schedule"})

    		ubx.Data(automation.OpenapiJobSchedule, "example", automation.OpenapiJobScheduleConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiJobSchedule } from "@ubx/sdk-azure/azure/data/automation/openapi_job_schedule";

    export default stack("example", () => {
      intent({ summary: "look up azure_automation_openapi_job_schedule" });

      data(OpenapiJobSchedule, "example", {

      });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiJobSchedule, OpenapiJobScheduleConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_job_schedule")

        ubx.data(OpenapiJobSchedule, "example", OpenapiJobScheduleConfig(
            automation_account_name="example-automation-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "azure_automation_openapi_certificate"
description: "`data_azure_automation_openapi_certificate` looks up a real, already-existing `azure_automation_openapi_certificate`."
---

It stores a certificate securely within an Azure Automation account, referenced by runbook(s) needing it for authentication.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_certificate"})

    		ubx.Data(automation.OpenapiCertificate, "example", automation.OpenapiCertificateConfig{
    			AutomationAccountName: "example-automation-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiCertificate } from "@ubx/sdk-azure/azure/data/automation/openapi_certificate";

    export default stack("example", () => {
      intent({ summary: "look up azure_automation_openapi_certificate" });

      data(OpenapiCertificate, "example", {
        automationAccountName: "example-automation-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiCertificate, OpenapiCertificateConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_certificate")

        ubx.data(OpenapiCertificate, "example", OpenapiCertificateConfig(
            automation_account_name="example-automation-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "azure_automation_openapi_dsc_node_configuration"
description: "`data_azure_automation_openapi_dsc_node_configuration` looks up a real, already-existing `azure_automation_openapi_dsc_node_configuration`."
---

It is a compiled DSC configuration assigned to specific registered node(s), the actual configuration those nodes are enforced against.

---
title: "azure_automation_openapi_connection_type"
description: "`data_azure_automation_openapi_connection_type` looks up a real, already-existing `azure_automation_openapi_connection_type`."
---

It defines the schema (field names) for a category of Azure Automation connection, e.g. the fields needed to connect to Azure itself.

## Example

    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_connection_type"})

    		})
    	}))
    }
    ```

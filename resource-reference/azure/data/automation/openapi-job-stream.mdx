## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	automation "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/automation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_automation_openapi_job_stream"})

    		ubx.Data(automation.OpenapiJobStream, "example", automation.OpenapiJobStreamConfig{
    			AutomationAccountName: "example-automation-account-name",
    			JobName:               "example-job-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.automation import OpenapiJobStream, OpenapiJobStreamConfig

    def describe():
        ubx.intent("look up azure_automation_openapi_job_stream")

        ubx.data(OpenapiJobStream, "example", OpenapiJobStreamConfig(
            automation_account_name="example-automation-account-name",
            job_name="example-job-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="automation_account_name" type="string" required>
  The real name of the Azure Automation account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_name" type="string" required>
  The real name of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The JobStream items on this page Returned by the lookup.
</ResponseField>

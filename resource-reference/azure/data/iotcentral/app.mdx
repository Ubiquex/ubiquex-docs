---
title: "azure_iotcentral_app"
description: "`data_azure_iotcentral_app` looks up a real, already-existing `azure_iotcentral_app`."
---

It is an IoT Central application, a fully managed SaaS IoT solution builder requiring no separate backend service management.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iotcentral "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/iotcentral"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_iotcentral_app"})

    		ubx.Data(iotcentral.App, "example", iotcentral.AppConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.azure.data.iotcentral import App, AppConfig

    def describe():
        ubx.intent("look up azure_iotcentral_app")

        ubx.data(App, "example", AppConfig(
            api_version="example",
            subscription_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of IoT Central Applications. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A list of IoT Central Applications. Returned by the lookup.
</ResponseField>

---
title: "azure_web_openapi_deployment"
description: "`data_azure_web_openapi_deployment` looks up a real, already-existing `azure_web_openapi_deployment`."
---

It is a single deployment record for an App Service web app, tracking a specific push of code to the app.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_deployment"})

    		ubx.Data(web.OpenapiDeployment, "example", web.OpenapiDeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

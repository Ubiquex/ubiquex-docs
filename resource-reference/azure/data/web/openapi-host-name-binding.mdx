---
title: "azure_web_openapi_host_name_binding"
description: "`data_azure_web_openapi_host_name_binding` looks up a real, already-existing `azure_web_openapi_host_name_binding`."
---

It maps a custom domain hostname to an App Service web app, routing that hostname's own traffic to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_host_name_binding"})

    		ubx.Data(web.OpenapiHostNameBinding, "example", web.OpenapiHostNameBindingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

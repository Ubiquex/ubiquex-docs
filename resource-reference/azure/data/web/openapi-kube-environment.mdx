---
title: "azure_web_openapi_kube_environment"
description: "`data_azure_web_openapi_kube_environment` looks up a real, already-existing `azure_web_openapi_kube_environment`."
---

It is the legacy App Service Kubernetes Environment resource, an earlier Azure Arc-enabled Kubernetes hosting environment for App Service and Functions, since superseded by newer Container Apps-based hosting.

---
title: "azure_web_openapi_hybrid_connection"
description: "`data_azure_web_openapi_hybrid_connection` looks up a real, already-existing `azure_web_openapi_hybrid_connection`."
---

It establishes outbound-only connectivity from an App Service web app to an on-premises or other-network TCP endpoint, without requiring inbound firewall changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_hybrid_connection"})

    		ubx.Data(web.OpenapiHybridConnection, "example", web.OpenapiHybridConnectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

---
title: "azure_web_openapi_identifier"
description: "`data_azure_web_openapi_identifier` looks up a real, already-existing `azure_web_openapi_identifier`."
---

It verifies ownership of a custom domain for use with an App Service web app, via a domain verification identifier record.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_identifier"})

    		ubx.Data(web.OpenapiIdentifier, "example", web.OpenapiIdentifierConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

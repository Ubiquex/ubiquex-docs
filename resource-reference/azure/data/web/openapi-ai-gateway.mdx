title: "azure_web_openapi_ai_gateway"
description: "`data_azure_web_openapi_ai_gateway` looks up a real, already-existing `azure_web_openapi_ai_gateway`."
---

It configures the AI Gateway tier of Azure API Management (public preview, 2026), a dedicated gateway for AI traffic that fronts model and MCP server endpoints behind one governed entry point with policies like semantic caching and token rate limiting.

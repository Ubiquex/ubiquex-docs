---
title: "azure_web_openapi_public_certificate"
description: "`data_azure_web_openapi_public_certificate` looks up a real, already-existing `azure_web_openapi_public_certificate`."
---

It uploads a public certificate (no private key) to an App Service web app, made available to the app's own code for validating outbound connections.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_public_certificate"})

    		ubx.Data(web.OpenapiPublicCertificate, "example", web.OpenapiPublicCertificateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

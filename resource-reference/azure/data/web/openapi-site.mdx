---
title: "azure_web_openapi_site"
description: "`data_azure_web_openapi_site` looks up a real, already-existing `azure_web_openapi_site`."
---

It is an App Service web app (or Function App), the deployable application resource that App Service Plan compute serves.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_site"})

    		ubx.Data(web.OpenapiSite, "example", web.OpenapiSiteConfig{})
    	}))
    }
    ```

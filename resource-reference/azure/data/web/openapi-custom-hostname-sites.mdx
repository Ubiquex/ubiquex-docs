`data_azure_web_openapi_custom_hostname_sites` is a real, live lookup against Microsoft Azure, generated from azure's own real schema -- read-only, never created or destroyed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_custom_hostname_sites"})

    		ubx.Data(web.OpenapiCustomHostnameSites, "example", web.OpenapiCustomHostnameSitesConfig{
    			Hostname: "example",
    		})
    	}))
    }
    ```

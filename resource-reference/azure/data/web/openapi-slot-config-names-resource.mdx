`azure_web_openapi_slot_config_names_resource` reads which real app settings and connection strings are marked slot-specific, so they don't swap between deployment slots.

<ResponseField name="properties" type="object">
  Names for connection strings, application settings, and external Azure storage account configuration identifiers to be marked as sticky to the deployment slot and not moved during a swap operation. This is valid for all deployment slots in an app. Returned by the lookup.

    </ResponseField>
  </Expandable>
</ResponseField>

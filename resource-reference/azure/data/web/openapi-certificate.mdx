---
title: "azure_web_openapi_certificate"
description: "`data_azure_web_openapi_certificate` looks up a real, already-existing `azure_web_openapi_certificate`."
---

It is a TLS certificate uploaded to App Service, bindable to a custom domain on a web app.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_certificate"})

    		ubx.Data(web.OpenapiCertificate, "example", web.OpenapiCertificateConfig{})
    	}))
    }
    ```

---
title: "azure_web_openapi_site_config_resource"
description: "`data_azure_web_openapi_site_config_resource` looks up a real, already-existing `azure_web_openapi_site_config_resource`."
---

It holds the detailed runtime configuration (stack, always-on, app settings behavior) for an App Service web app.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_site_config_resource"})

    		ubx.Data(web.OpenapiSiteConfigResource, "example", web.OpenapiSiteConfigResourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

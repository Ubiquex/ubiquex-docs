`azure_web_openapi_custom_hostname_analysis_result` reads the real result of analyzing whether a custom hostname is correctly configured (DNS records, TXT verification) for adding to an App Service site.

## Example

<Tabs>
  <Tab title="Go">
    ```go

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_custom_hostname_analysis_result"})

    		ubx.Data(web.OpenapiCustomHostnameAnalysisResult, "example", web.OpenapiCustomHostnameAnalysisResultConfig{
    			Name:     "example",
    			HostName: "example-host-name",
    		})
    	}))
    }
    ```

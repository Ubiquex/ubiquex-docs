`azure_web_openapi_route` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_route"})

    		ubx.Data(web.OpenapiRoute, "example", web.OpenapiRouteConfig{
    			Name:      "example",
    			RouteName: "example-route-name",
    			VnetName:  "example-vnet-name",
    		})
    	}))
    }
    ```
  </Tab>

    def describe():

            name="example",

            vnet_name="example-vnet-name",

    if __name__ == "__main__":

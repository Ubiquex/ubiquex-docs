---
title: "azure_web_openapi_backup_item"
description: "`data_azure_web_openapi_backup_item` looks up a real, already-existing `azure_web_openapi_backup_item`."
---

It is a single completed or scheduled backup of an App Service web app's own content and configuration.

## Example

<Tabs>
  <Tab title="Go">

    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_web_openapi_backup_item"})

    		ubx.Data(web.OpenapiBackupItem, "example", web.OpenapiBackupItemConfig{
    			Name: "example",
    		})
    	}))
    }

`data_azure_machinelearningservices_openapi_environment_version` looks up a real, already-existing `azure_machinelearningservices_openapi_environment_version`. It is a specific, immutable version of a training or inference software environment (a container image or Conda spec) registered in an Azure Machine Learning workspace.

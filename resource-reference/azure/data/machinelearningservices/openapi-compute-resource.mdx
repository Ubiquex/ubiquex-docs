---
title: "azure_machinelearningservices_openapi_compute_resource"
description: "`data_azure_machinelearningservices_openapi_compute_resource` looks up a real, already-existing `azure_machinelearningservices_openapi_compute_resource`."
---

It provisions compute (a compute instance, cluster, or attached external compute) within an Azure Machine Learning workspace, that training and inference workload(s) run on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_compute_resource"})

    		ubx.Data(machinelearningservices.OpenapiComputeResource, "example", machinelearningservices.OpenapiComputeResourceConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

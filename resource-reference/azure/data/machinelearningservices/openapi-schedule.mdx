---
title: "azure_machinelearningservices_openapi_schedule"
description: "`data_azure_machinelearningservices_openapi_schedule` looks up a real, already-existing `azure_machinelearningservices_openapi_schedule`."

It triggers an Azure Machine Learning job or pipeline to run automatically on a recurring cron-style schedule.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

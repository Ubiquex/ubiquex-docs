`azure_machinelearningservices_openapi_private_link_resource` reads a real Private Link resource exposed by an Azure Machine Learning workspace, that a Private Endpoint can connect to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_private_link_resource"})

    		ubx.Data(machinelearningservices.OpenapiPrivateLinkResource, "example", machinelearningservices.OpenapiPrivateLinkResourceConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

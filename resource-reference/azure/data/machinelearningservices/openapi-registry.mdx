---
title: "azure_machinelearningservices_openapi_registry"
description: "`data_azure_machinelearningservices_openapi_registry` looks up a real, already-existing `azure_machinelearningservices_openapi_registry`."
---

It is an Azure Machine Learning registry, a shared catalog letting model(s), environment(s), and component(s) be published and consumed across multiple workspaces and regions.

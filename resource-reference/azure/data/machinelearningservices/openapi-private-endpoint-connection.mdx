`data_azure_machinelearningservices_openapi_private_endpoint_connection` looks up a real, already-existing `azure_machinelearningservices_openapi_private_endpoint_connection`. It represents the connection between a Private Endpoint and an Azure Machine Learning workspace, tracking its own approval state.

## Example

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_private_endpoint_connection"})

    		ubx.Data(machinelearningservices.OpenapiPrivateEndpointConnection, "example", machinelearningservices.OpenapiPrivateEndpointConnectionConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }

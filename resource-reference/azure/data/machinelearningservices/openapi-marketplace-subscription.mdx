`data_azure_machinelearningservices_openapi_marketplace_subscription` looks up a real, already-existing `azure_machinelearningservices_openapi_marketplace_subscription`. It subscribes an Azure Machine Learning workspace to a model or offer available through the Azure Marketplace, required before deploying certain third-party Model Catalog models.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_marketplace_subscription"})

    		ubx.Data(machinelearningservices.OpenapiMarketplaceSubscription, "example", machinelearningservices.OpenapiMarketplaceSubscriptionConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```

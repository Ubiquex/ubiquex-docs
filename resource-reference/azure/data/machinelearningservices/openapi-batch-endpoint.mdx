---
title: "azure_machinelearningservices_openapi_batch_endpoint"

It is the stable, addressable endpoint that Azure Machine Learning batch deployment(s) are invoked through for offline, large-scale scoring jobs.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_batch_endpoint"})

    		ubx.Data(machinelearningservices.OpenapiBatchEndpoint, "example", machinelearningservices.OpenapiBatchEndpointConfig{
    			WorkspaceName: "example-workspace-name",
    			Count:         1,
    		})
    	}))
    }
    ```

`data_azure_machinelearningservices_openapi_featureset_container` looks up a real, already-existing `azure_machinelearningservices_openapi_featureset_container`. It is the named container in an Azure Machine Learning workspace that version(s) of a feature set are registered under, part of the Managed Feature Store capability.

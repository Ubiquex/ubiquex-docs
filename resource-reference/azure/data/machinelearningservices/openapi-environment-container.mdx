`data_azure_machinelearningservices_openapi_environment_container` looks up a real, already-existing `azure_machinelearningservices_openapi_environment_container`. It is the named container in an Azure Machine Learning workspace that version(s) of a training/inference environment definition are registered under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_environment_container"})

    		ubx.Data(machinelearningservices.OpenapiEnvironmentContainer, "example", machinelearningservices.OpenapiEnvironmentContainerConfig{
    			RegistryName: "example-registry-name",
    			ListViewType: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="description" type="string">
  The real, free-text description set on this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="feature_name" type="string">
  The real name of the feature this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="featureset_name" type="string" required>
  The real name of the feature set this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="featureset_version" type="string" required>
  The real version of the feature set this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="list_view_type" type="string">
  Which real subset of results to include, such as only enabled entries or all of them. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tags" type="string">
  The real tags applied to this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`azure_machinelearningservices_openapi_virtual_machine_size` reads a real, available VM size an Azure Machine Learning compute instance or cluster can be provisioned with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_virtual_machine_size"})

    		ubx.Data(machinelearningservices.OpenapiVirtualMachineSize, "example", machinelearningservices.OpenapiVirtualMachineSizeConfig{
    			Location: "example",
    		})
    	}))
    }
    ```

---
title: "azure_machinelearningservices_openapi_code_version"
description: "`data_azure_machinelearningservices_openapi_code_version` looks up a real, already-existing `azure_machinelearningservices_openapi_code_version`."
---

It is a specific, immutable version of source code registered in an Azure Machine Learning workspace, referenced by job(s) and component(s) that use it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_machinelearningservices_openapi_code_version"})

    		ubx.Data(machinelearningservices.OpenapiCodeVersion, "example", machinelearningservices.OpenapiCodeVersionConfig{
    			CodeName:     "example-code-name",
    			RegistryName: "example-registry-name",
    		})
    	}))
    }
    ```

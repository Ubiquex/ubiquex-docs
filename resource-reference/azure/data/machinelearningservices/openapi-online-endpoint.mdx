---
title: "azure_machinelearningservices_openapi_online_endpoint"

---

It is the stable, addressable endpoint that Azure Machine Learning online deployment(s) are invoked through for real-time inference, with traffic splitting across them.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

`data_azure_machinelearningservices_openapi_outbound_rule_basic_resource` looks up a real, already-existing `azure_machinelearningservices_openapi_outbound_rule_basic_resource`. It defines an allowed outbound network destination for an Azure Machine Learning workspace's own managed virtual network, permitting egress to a specific service.

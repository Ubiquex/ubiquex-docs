`data_azure_healthcareapis_healthcare_apis_services_description` looks up a real, already-existing `azure_healthcareapis_healthcare_apis_services_description`. It is the legacy, standalone Azure API for FHIR resource, the predecessor to workspace-scoped FHIR services in Azure Health Data Services.

`data_azure_healthcareapis_healthcare_apis_private_endpoint_connection_description` looks up a real, already-existing `azure_healthcareapis_healthcare_apis_private_endpoint_connection_description`. It represents the connection between a Private Endpoint and an Azure Health Data Services workspace or service, tracking its own approval state.

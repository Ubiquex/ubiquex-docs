`data_azure_hybridkubernetes_connectedclusters_connected_cluster` looks up a real, already-existing `azure_hybridkubernetes_connectedclusters_connected_cluster`. It represents a Kubernetes cluster running outside Azure (on-premises or another cloud), connected via Azure Arc for centralized management, GitOps, and policy enforcement.

`azure_consumption_openapi_reservation_transaction` looks up a real reservation transaction (purchase, exchange, refund) on an Enterprise Agreement billing account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	consumption "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/consumption"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_consumption_openapi_reservation_transaction"})

    		ubx.Data(consumption.OpenapiReservationTransaction, "example", consumption.OpenapiReservationTransactionConfig{
    			BillingAccountId:        "example",
    			PreviewMarkupPercentage: 1,
    			UseMarkupIfPartner:      true,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="billing_account_id" type="string" required>
  The real, unique identifier of the billing account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="preview_markup_percentage" type="number">
  The real, previewed markup percentage that would be applied to cost values. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="use_markup_if_partner" type="bool">
  Whether partner markup is applied to the returned cost values. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link (url) to the next page of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of reservation recommendations. Returned by the lookup.

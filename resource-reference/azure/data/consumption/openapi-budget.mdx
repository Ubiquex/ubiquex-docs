---
title: "azure_consumption_openapi_budget"
description: "`data_azure_consumption_openapi_budget` looks up a real, already-existing `azure_consumption_openapi_budget`."
---

It sets a spending threshold on a scope and triggers notification(s) when actual or forecasted spend crosses it, via the Consumption API's own budget resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	consumption "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/consumption"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_consumption_openapi_budget"})

    		ubx.Data(consumption.OpenapiBudget, "example", consumption.OpenapiBudgetConfig{
    			Scope: "example",
    		})
    	}))
    }
    ```
  </Tab>

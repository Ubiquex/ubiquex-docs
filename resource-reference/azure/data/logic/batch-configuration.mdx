---
title: "azure_logic_batch_configuration"
description: "`data_azure_logic_batch_configuration` looks up a real, already-existing `azure_logic_batch_configuration`."
---

It defines batching rule(s) (release criteria based on message count, size, or a schedule) that a Logic Apps workflow uses to accumulate and release messages together.

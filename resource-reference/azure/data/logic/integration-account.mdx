---
title: "azure_logic_integration_account"
description: "`data_azure_logic_integration_account` looks up a real, already-existing `azure_logic_integration_account`."
---

It is the top-level B2B integration resource for Logic Apps, holding the trading partner(s), agreement(s), schema(s), and map(s) EDI/XML workflows reference.

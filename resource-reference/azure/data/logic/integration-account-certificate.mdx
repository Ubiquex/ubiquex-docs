---
title: "azure_logic_integration_account_certificate"
description: "`data_azure_logic_integration_account_certificate` looks up a real, already-existing `azure_logic_integration_account_certificate`."
---

It stores a certificate within a Logic Apps integration account, used to sign or encrypt B2B message exchanges.

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="integration_account_name" type="string" required>
  The real name of the Logic Apps integration account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL to get the next set of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of integration account certificates. Returned by the lookup.
</ResponseField>

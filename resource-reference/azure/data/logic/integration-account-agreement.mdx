title: "azure_logic_integration_account_agreement"
description: "`data_azure_logic_integration_account_agreement` looks up a real, already-existing `azure_logic_integration_account_agreement`."
---

It defines the B2B protocol (AS2, X12, EDIFACT) and validation rule(s) governing message exchange between two trading partners in a Logic Apps integration account.

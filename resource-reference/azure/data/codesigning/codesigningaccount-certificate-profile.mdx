`data_azure_codesigning_codesigningaccount_certificate_profile` looks up a real, already-existing `azure_codesigning_codesigningaccount_certificate_profile`. It defines a certificate profile (a specific signing identity and validity policy) within a Trusted Signing account, that signing request(s) are issued against.

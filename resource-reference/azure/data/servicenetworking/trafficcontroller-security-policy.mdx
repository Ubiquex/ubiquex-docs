`data_azure_servicenetworking_trafficcontroller_security_policy` looks up a real, already-existing `azure_servicenetworking_trafficcontroller_security_policy`. It attaches a Web Application Firewall policy to an Azure Application Load Balancer, applying WAF inspection to matching traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicenetworking "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicenetworking"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicenetworking_trafficcontroller_security_policy"})

    		ubx.Data(servicenetworking.TrafficcontrollerSecurityPolicy, "example", servicenetworking.TrafficcontrollerSecurityPolicyConfig{
    			TrafficControllerName: "example-traffic-controller-name",
    		})
    	}))
    }
    ```
  </Tab>

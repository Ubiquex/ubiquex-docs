---
title: "azure_servicenetworking_trafficcontroller_association"
description: "`data_azure_servicenetworking_trafficcontroller_association` looks up a real, already-existing `azure_servicenetworking_trafficcontroller_association`."
---

It attaches an Azure Application Load Balancer's own Traffic Controller to a subnet, delegating that subnet for the load balancer's own use.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

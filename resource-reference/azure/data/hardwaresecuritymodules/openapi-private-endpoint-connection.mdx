`data_azure_hardwaresecuritymodules_openapi_private_endpoint_connection` looks up a real, already-existing `azure_hardwaresecuritymodules_openapi_private_endpoint_connection`. It represents the connection between a Private Endpoint and an Azure Cloud HSM resource, tracking its own approval state.

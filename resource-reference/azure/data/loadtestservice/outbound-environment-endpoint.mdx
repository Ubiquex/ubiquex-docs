`data_azure_loadtestservice_outbound_environment_endpoint` is a real, live lookup against Microsoft Azure, generated from azure's own real schema -- read-only, never created or destroyed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	loadtestservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/loadtestservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_loadtestservice_outbound_environment_endpoint"})

    		ubx.Data(loadtestservice.OutboundEnvironmentEndpoint, "example", loadtestservice.OutboundEnvironmentEndpointConfig{
    			LoadTestName: "example-load-test-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

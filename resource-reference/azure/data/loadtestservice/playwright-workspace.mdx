---
title: "azure_loadtestservice_playwright_workspace"
description: "`data_azure_loadtestservice_playwright_workspace` looks up a real, already-existing `azure_loadtestservice_playwright_workspace`."
---

It is a Playwright Workspace under Azure App Testing (the GA successor to the now-retired Microsoft Playwright Testing service, retired 2026-03-08), providing managed cloud browsers for running Playwright end-to-end tests at scale.

---
title: "azure_resources_openapi_policy_definition"
description: "`data_azure_resources_openapi_policy_definition` looks up a real, already-existing `azure_resources_openapi_policy_definition`."
---

It defines a single Azure Policy rule -- the condition it evaluates and the effect (deny, audit, append) it takes when a resource matches.

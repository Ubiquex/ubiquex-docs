---
title: "azure_resources_provider"
description: "`azure_resources_provider` looks up a real Azure resource provider (such as `Microsoft.Compute`) and its own registration state on a subscription."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_resources_provider"})

    		ubx.Data(resources.Provider, "example", resources.ProviderConfig{
    			ResourceProviderNamespace: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Provider } from "@ubx/sdk-azure/azure/data/resources/provider";

    export default stack("example", () => {
      intent({ summary: "look up azure_resources_provider" });

      data(Provider, "example", {
        resourceProviderNamespace: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.resources import Provider, ProviderConfig

    def describe():
        ubx.intent("look up azure_resources_provider")

        ubx.data(Provider, "example", ProviderConfig(
            resource_provider_namespace="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="resource_provider_namespace" type="string" required>
  Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="string">
  The provider ID. Returned by the lookup.
</ResponseField>

<ResponseField name="namespace" type="string">
  The namespace of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="provider_authorization_consent_state" type="string">
  The provider authorization consent state. Returned by the lookup.
</ResponseField>

<ResponseField name="registration_policy" type="string">
  The registration policy of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="registration_state" type="string">
  The registration state of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="resource_types" type="list(object)">
  The collection of provider resource types. Returned by the lookup.
</ResponseField>

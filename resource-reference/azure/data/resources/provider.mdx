---
title: "azure_resources_provider"
description: "`azure_resources_provider` looks up a real Azure resource provider (such as `Microsoft.Compute`) and its own registration state on a subscription."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own provider"})

    		ubx.Resource(resources.Provider, "example", resources.ProviderConfig{
    			ThirdPartyProviderConsent: map[string]any{"consent_to_authorization": true},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Provider } from "@ubx/sdk-azure/azure/resources/provider";

    export default stack("example", () => {
      intent({ summary: "example own provider" });

      resource(Provider, "example", {
        thirdPartyProviderConsent: { consentToAuthorization: true },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.resources import Provider, ProviderConfig
    from ubx.azure.resources.provider import Provider_ThirdPartyProviderConsent

    def describe():
        ubx.intent("example own provider")

        ubx.resource(Provider, "example", ProviderConfig(
            third_party_provider_consent=Provider_ThirdPartyProviderConsent(consent_to_authorization=True),
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
  <Tab title="Markdown">
    ```

    consent a set value.
    ```

  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="resource_provider_namespace" type="string" required>
  Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="string">
  The provider ID. Returned by the lookup.
</ResponseField>

<ResponseField name="namespace" type="string">
  The namespace of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="provider_authorization_consent_state" type="string">
  The provider authorization consent state. Returned by the lookup.
</ResponseField>

<ResponseField name="registration_policy" type="string">
  The registration policy of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="registration_state" type="string">
  The registration state of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="resource_types" type="list(object)">
  The collection of provider resource types. Returned by the lookup.
</ResponseField>

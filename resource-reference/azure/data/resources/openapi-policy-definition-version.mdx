---
title: "azure_resources_openapi_policy_definition_version"
description: "`data_azure_resources_openapi_policy_definition_version` looks up a real, already-existing `azure_resources_openapi_policy_definition_version`."
---

It is a specific, versioned revision of an Azure Policy definition, letting assignments pin to a known version even as the definition continues to evolve.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_resources_openapi_policy_definition_version"})

    		ubx.Data(resources.OpenapiPolicyDefinitionVersion, "example", resources.OpenapiPolicyDefinitionVersionConfig{
    			PolicyDefinitionName: "example-policy-definition-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

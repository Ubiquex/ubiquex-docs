`data_azure_resources_privatelinks_resource_management_private_link` looks up a real, already-existing `azure_resources_privatelinks_resource_management_private_link`. It creates a Private Endpoint for Azure Resource Manager itself, letting management-plane API calls stay on a private network path.

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="value" type="list(object)">
  An array of resource management private links. Returned by the lookup.
</ResponseField>

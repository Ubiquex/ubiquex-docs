---
title: "azure_resources_locks_management_lock_object"
description: "`data_azure_resources_locks_management_lock_object` looks up a real, already-existing `azure_resources_locks_management_lock_object`."
---

It prevents a resource, resource group, or subscription from being accidentally deleted or modified, requiring the lock to be explicitly removed first.

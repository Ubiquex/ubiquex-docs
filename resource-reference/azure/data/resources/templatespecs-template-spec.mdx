---
title: "azure_resources_templatespecs_template_spec"
description: "`data_azure_resources_templatespecs_template_spec` looks up a real, already-existing `azure_resources_templatespecs_template_spec`."
---

It publishes a reusable ARM template as a versioned, shareable resource, so teams can deploy from a governed, centrally managed template instead of copying template files around.

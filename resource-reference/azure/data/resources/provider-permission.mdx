`data_azure_resources_provider_permission` is a real, live lookup against Microsoft Azure, generated from azure's own real schema -- read-only, never created or destroyed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_resources_provider_permission"})

    		ubx.Data(resources.ProviderPermission, "example", resources.ProviderPermissionConfig{
    			ResourceProviderNamespace: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

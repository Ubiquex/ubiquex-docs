---
title: "azure_resources_deploymentscripts_deployment_script"
description: "`data_azure_resources_deploymentscripts_deployment_script` looks up a real, already-existing `azure_resources_deploymentscripts_deployment_script`."
---

It runs a PowerShell or Azure CLI script as part of an ARM template deployment, for imperative logic a declarative template alone can't express.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_resources_deploymentscripts_deployment_script"})

    		ubx.Data(resources.DeploymentscriptsDeploymentScript, "example", resources.DeploymentscriptsDeploymentScriptConfig{})
    	}))
    }
    ```
  </Tab>

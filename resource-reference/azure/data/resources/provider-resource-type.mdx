`azure_resources_provider_resource_type` reads a real resource type (such as `virtualMachines`) exposed by an Azure resource provider, and the API versions it supports.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_resources_provider_resource_type"})

    		ubx.Data(resources.ProviderResourceType, "example", resources.ProviderResourceTypeConfig{
    			ResourceProviderNamespace: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="resource_provider_namespace" type="string" required>
  The real Azure resource provider namespace (such as `Microsoft.Compute`) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="string">
  The provider ID. Returned by the lookup.
</ResponseField>

<ResponseField name="namespace" type="string">
  The namespace of the resource provider. Returned by the lookup.
</ResponseField>

<ResponseField name="provider_authorization_consent_state" type="string">

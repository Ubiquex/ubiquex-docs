It is a specific, immutable version of a Template Spec's own template content.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_resources_templatespecs_template_spec_version"})

    		ubx.Data(resources.TemplatespecsTemplateSpecVersion, "example", resources.TemplatespecsTemplateSpecVersionConfig{

    		})
    	}))
    }

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="template_spec_name" type="string" required>
  The real name of the ARM template spec this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL to use for getting the next set of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  An array of Template Spec versions. Returned by the lookup.
</ResponseField>

---
title: "azure_security_datascanners_data_scanner"
description: "`data_azure_security_datascanners_data_scanner` looks up a real, already-existing `azure_security_datascanners_data_scanner`."
---

It configures Microsoft Defender for Cloud's own sensitive data discovery scanner for a data resource, automatically classifying sensitive data at rest.

## Example

    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_security_datascanners_data_scanner"})

    		ubx.Data(security.DatascannersDataScanner, "example", security.DatascannersDataScannerConfig{
    			ScopeId: "example",
    		})
    	}))
    }

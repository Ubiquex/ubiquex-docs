---
title: "azure_kusto_database"
description: "`data_azure_kusto_database` looks up a real, already-existing `azure_kusto_database`."
---

It is a database within an Azure Data Explorer cluster, the container table(s) are created within and queried via KQL.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kusto_database"})

    		ubx.Data(kusto.Database, "example", kusto.DatabaseConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    # ubx sdk gen --only azure --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.kusto import Database, DatabaseConfig

    def describe():
        ubx.intent("look up azure_kusto_database")

        ubx.data(Database, "example", DatabaseConfig(
            cluster_name="example-cluster-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

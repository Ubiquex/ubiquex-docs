---
title: "azure_kusto_attached_database_configuration"
description: "`data_azure_kusto_attached_database_configuration` looks up a real, already-existing `azure_kusto_attached_database_configuration`."
---

It follows database(s) from a leader Azure Data Explorer cluster into a follower cluster in read-only mode, without duplicating the underlying data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kusto_attached_database_configuration"})

    		ubx.Data(kusto.AttachedDatabaseConfiguration, "example", kusto.AttachedDatabaseConfigurationConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { AttachedDatabaseConfiguration } from "@ubx/sdk-azure/azure/data/kusto/attached_database_configuration";

    export default stack("example", () => {
      intent({ summary: "look up azure_kusto_attached_database_configuration" });

      data(AttachedDatabaseConfiguration, "example", {
        clusterName: "example-cluster-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.kusto import AttachedDatabaseConfiguration, AttachedDatabaseConfigurationConfig

    def describe():
        ubx.intent("look up azure_kusto_attached_database_configuration")

        ubx.data(AttachedDatabaseConfiguration, "example", AttachedDatabaseConfigurationConfig(
            cluster_name="example-cluster-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="cluster_name" type="string" required>
  The real name of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  Link to the next page of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of attached database configurations. Returned by the lookup.
</ResponseField>

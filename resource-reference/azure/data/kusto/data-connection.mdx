---
title: "azure_kusto_data_connection"
description: "`data_azure_kusto_data_connection` looks up a real, already-existing `azure_kusto_data_connection`."
---

It continuously ingests data from an external source (Event Hub, IoT Hub, Event Grid) into an Azure Data Explorer database table.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kusto_data_connection"})

    		ubx.Data(kusto.DataConnection, "example", kusto.DataConnectionConfig{
    			ClusterName:  "example-cluster-name",
    			DatabaseName: "example-database-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { DataConnection } from "@ubx/sdk-azure/azure/data/kusto/data_connection";

    export default stack("example", () => {
      intent({ summary: "look up azure_kusto_data_connection" });

      data(DataConnection, "example", {
        clusterName: "example-cluster-name",
        databaseName: "example-database-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.kusto import DataConnection, DataConnectionConfig

    def describe():
        ubx.intent("look up azure_kusto_data_connection")

        ubx.data(DataConnection, "example", DataConnectionConfig(
            cluster_name="example-cluster-name",
            database_name="example-database-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="cluster_name" type="string" required>
  The real name of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="database_name" type="string" required>
  The real name of the database this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  Link to the next page of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of Kusto data connections. Returned by the lookup.
</ResponseField>

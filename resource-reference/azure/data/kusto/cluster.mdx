---
title: "azure_kusto_cluster"
description: "`data_azure_kusto_cluster` looks up a real, already-existing `azure_kusto_cluster`."
---

It is an Azure Data Explorer (Kusto) cluster, the provisioned compute that database(s) are created within for high-performance log and telemetry analytics.

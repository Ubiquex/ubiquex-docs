---
title: "azure_kusto_database_principal_assignment"
description: "`data_azure_kusto_database_principal_assignment` looks up a real, already-existing `azure_kusto_database_principal_assignment`."
---

It grants a principal a role (admin, ingestor, viewer) scoped to a single Azure Data Explorer database.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kusto_database_principal_assignment"})

    		ubx.Data(kusto.DatabasePrincipalAssignment, "example", kusto.DatabasePrincipalAssignmentConfig{
    			ClusterName:  "example-cluster-name",
    			DatabaseName: "example-database-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="cluster_name" type="string" required>
  The real name of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="database_name" type="string" required>
  The real name of the database this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

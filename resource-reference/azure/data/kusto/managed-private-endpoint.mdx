---
title: "azure_kusto_managed_private_endpoint"
description: "`data_azure_kusto_managed_private_endpoint` looks up a real, already-existing `azure_kusto_managed_private_endpoint`."
---

It creates a Private Endpoint from an Azure Data Explorer cluster to an external resource, so outbound data ingestion or external table access can stay private.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kusto_managed_private_endpoint"})

    		ubx.Data(kusto.ManagedPrivateEndpoint, "example", kusto.ManagedPrivateEndpointConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ManagedPrivateEndpoint } from "@ubx/sdk-azure/azure/data/kusto/managed_private_endpoint";

    export default stack("example", () => {
      intent({ summary: "look up azure_kusto_managed_private_endpoint" });

      data(ManagedPrivateEndpoint, "example", {
        clusterName: "example-cluster-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.kusto import ManagedPrivateEndpoint, ManagedPrivateEndpointConfig

    def describe():
        ubx.intent("look up azure_kusto_managed_private_endpoint")

        ubx.data(ManagedPrivateEndpoint, "example", ManagedPrivateEndpointConfig(
            cluster_name="example-cluster-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

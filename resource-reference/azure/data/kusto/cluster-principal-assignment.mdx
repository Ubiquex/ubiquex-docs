---
title: "azure_kusto_cluster_principal_assignment"
description: "`data_azure_kusto_cluster_principal_assignment` looks up a real, already-existing `azure_kusto_cluster_principal_assignment`."
---

It grants a principal a cluster-wide administrative role on an Azure Data Explorer cluster.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kusto_cluster_principal_assignment"})

    		})
    	}))

---
title: "azure_azurestackhci_hci_security_setting"
description: "`data_azure_azurestackhci_hci_security_setting` looks up a real, already-existing `azure_azurestackhci_hci_security_setting`."
---

It reports and configures security posture settings (e.g. WDAC, Secured-core) for an Azure Stack HCI cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	azurestackhci "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/azurestackhci"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_azurestackhci_hci_security_setting"})

    		ubx.Data(azurestackhci.HciSecuritySetting, "example", azurestackhci.HciSecuritySettingConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

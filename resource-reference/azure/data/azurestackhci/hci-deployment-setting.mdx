---
title: "azure_azurestackhci_hci_deployment_setting"
description: "`data_azure_azurestackhci_hci_deployment_setting` looks up a real, already-existing `azure_azurestackhci_hci_deployment_setting`."
---

It defines the full deployment configuration (networking, storage, node topology) an Azure Stack HCI cluster is initially deployed with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	azurestackhci "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/azurestackhci"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_azurestackhci_hci_deployment_setting"})

    		ubx.Data(azurestackhci.HciDeploymentSetting, "example", azurestackhci.HciDeploymentSettingConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

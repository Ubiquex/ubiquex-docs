---
title: "azure_dashboard_grafana_integration_fabric"
description: "`data_azure_dashboard_grafana_integration_fabric` looks up a real, already-existing `azure_dashboard_grafana_integration_fabric`."
---

It connects an Azure Managed Grafana instance to a Microsoft Fabric workspace, letting Grafana dashboards query Fabric data sources.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dashboard "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/dashboard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_dashboard_grafana_integration_fabric"})

    		ubx.Data(dashboard.GrafanaIntegrationFabric, "example", dashboard.GrafanaIntegrationFabricConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { GrafanaIntegrationFabric } from "@ubx/sdk-azure/azure/data/dashboard/grafana_integration_fabric";

    export default stack("example", () => {
      intent({ summary: "look up azure_dashboard_grafana_integration_fabric" });

      data(GrafanaIntegrationFabric, "example", {
        workspaceName: "example-workspace-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.dashboard import GrafanaIntegrationFabric, GrafanaIntegrationFabricConfig

    def describe():
        ubx.intent("look up azure_dashboard_grafana_integration_fabric")

        ubx.data(GrafanaIntegrationFabric, "example", GrafanaIntegrationFabricConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

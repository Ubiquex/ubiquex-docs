---
title: "azure_dashboard_grafana_managed_private_endpoint_model"

---

It creates a Private Endpoint from an Azure Managed Grafana instance to a private data source, so it can query it without traversing the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dashboard "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/dashboard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_dashboard_grafana_managed_private_endpoint_model"})

    		ubx.Data(dashboard.GrafanaManagedPrivateEndpointModel, "example", dashboard.GrafanaManagedPrivateEndpointModelConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    export default stack("example", () => {
      intent({
        summary: "look up azure_dashboard_grafana_managed_private_endpoint_model",
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.dashboard import GrafanaManagedPrivateEndpointModel, GrafanaManagedPrivateEndpointModelConfig

    def describe():
        ubx.intent("look up azure_dashboard_grafana_managed_private_endpoint_model")

        ubx.data(GrafanaManagedPrivateEndpointModel, "example", GrafanaManagedPrivateEndpointModelConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

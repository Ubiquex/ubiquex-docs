## Lookup arguments

<ResponseField name="fluid_relay_server_name" type="string" required>
  The real name of the Fluid Relay server this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

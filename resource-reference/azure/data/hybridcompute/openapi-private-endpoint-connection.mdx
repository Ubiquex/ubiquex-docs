---
title: "azure_hybridcompute_openapi_private_endpoint_connection"
description: "`data_azure_hybridcompute_openapi_private_endpoint_connection` looks up a real, already-existing `azure_hybridcompute_openapi_private_endpoint_connection`."
---

It represents the connection between a Private Endpoint and an Arc-enabled server's own Private Link Scope, tracking its own approval state.

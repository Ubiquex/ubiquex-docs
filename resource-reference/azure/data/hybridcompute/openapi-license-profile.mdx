---
title: "azure_hybridcompute_openapi_license_profile"
description: "`data_azure_hybridcompute_openapi_license_profile` looks up a real, already-existing `azure_hybridcompute_openapi_license_profile`."
---

It is an Arc-enabled server's own current license assignment and Extended Security Update/Software Assurance eligibility state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	hybridcompute "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/hybridcompute"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_hybridcompute_openapi_license_profile"})

    		ubx.Data(hybridcompute.OpenapiLicenseProfile, "example", hybridcompute.OpenapiLicenseProfileConfig{
    			MachineName: "example-machine-name",
    		})
    	}))
    }
    ```
  </Tab>

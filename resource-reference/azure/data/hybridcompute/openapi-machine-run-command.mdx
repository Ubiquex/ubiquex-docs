---
title: "azure_hybridcompute_openapi_machine_run_command"
description: "`data_azure_hybridcompute_openapi_machine_run_command` looks up a real, already-existing `azure_hybridcompute_openapi_machine_run_command`."
---

It runs a one-time script on an Arc-enabled server via the Azure Arc connected machine agent, without needing direct network access or a pre-installed remote-execution tool.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	hybridcompute "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/hybridcompute"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_hybridcompute_openapi_machine_run_command"})

    		ubx.Data(hybridcompute.OpenapiMachineRunCommand, "example", hybridcompute.OpenapiMachineRunCommandConfig{
    			MachineName: "example-machine-name",
    		})
    	}))
    }
    ```
  </Tab>

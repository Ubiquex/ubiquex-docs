`azure_hybridcompute_openapi_private_link_resource` reads a real Private Link resource exposed by Azure Arc-enabled servers, that a Private Endpoint can connect to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	hybridcompute "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/hybridcompute"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_hybridcompute_openapi_private_link_resource"})

    		ubx.Data(hybridcompute.OpenapiPrivateLinkResource, "example", hybridcompute.OpenapiPrivateLinkResourceConfig{
    			ScopeName: "example-scope-name",
    		})
    	}))
    }
    ```
  </Tab>

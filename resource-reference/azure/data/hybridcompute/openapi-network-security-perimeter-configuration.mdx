`azure_hybridcompute_openapi_network_security_perimeter_configuration` reads the real Network Security Perimeter configuration applied to an Azure Arc-enabled server.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	hybridcompute "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/hybridcompute"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_hybridcompute_openapi_network_security_perimeter_configuration"})

    		ubx.Data(hybridcompute.OpenapiNetworkSecurityPerimeterConfiguration, "example", hybridcompute.OpenapiNetworkSecurityPerimeterConfigurationConfig{
    			ScopeName: "example-scope-name",
    		})
    	}))
    }
    ```
  </Tab>

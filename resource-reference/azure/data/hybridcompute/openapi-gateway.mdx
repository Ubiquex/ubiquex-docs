---
title: "azure_hybridcompute_openapi_gateway"
description: "`data_azure_hybridcompute_openapi_gateway` looks up a real, already-existing `azure_hybridcompute_openapi_gateway`."
---

It is an Azure Arc gateway, a regional proxy endpoint Arc-enabled servers can route their own outbound Azure connectivity through, reducing the set of external endpoints each server needs direct network access to.

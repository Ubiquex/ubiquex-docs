## Lookup arguments

<ResponseField name="private_link_scope_id" type="string" required>
  The real, unique identifier of the Azure Monitor Private Link Scope this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="connection_details" type="list(object)">
  List of Private Endpoint Connection details. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  Azure resource Id Returned by the lookup.
</ResponseField>

<ResponseField name="public_network_access" type="string">
  Indicates whether machines associated with the private link scope can also use public Azure Arc service endpoints. Returned by the lookup.
</ResponseField>

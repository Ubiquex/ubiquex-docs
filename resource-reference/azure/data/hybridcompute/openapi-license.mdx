---
title: "azure_hybridcompute_openapi_license"
description: "`data_azure_hybridcompute_openapi_license` looks up a real, already-existing `azure_hybridcompute_openapi_license`."
---

It represents an on-premises Windows Server license (or Software Assurance/subscription benefit) registered with Azure Arc, used to determine an Arc-enabled server's own Extended Security Update and licensing eligibility.

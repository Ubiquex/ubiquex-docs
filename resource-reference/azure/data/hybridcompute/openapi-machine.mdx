---
title: "azure_hybridcompute_openapi_machine"
description: "`data_azure_hybridcompute_openapi_machine` looks up a real, already-existing `azure_hybridcompute_openapi_machine`."
---

It is an Arc-enabled server -- an on-premises or other-cloud physical or virtual machine projected into Azure as a manageable resource, without migrating the machine itself.

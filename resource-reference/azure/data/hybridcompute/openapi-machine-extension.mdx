---
title: "azure_hybridcompute_openapi_machine_extension"
description: "`data_azure_hybridcompute_openapi_machine_extension` looks up a real, already-existing `azure_hybridcompute_openapi_machine_extension`."
---

It is a VM extension installed on an Arc-enabled server, extending it with capabilities like monitoring agents, configuration management, or security tooling -- the same extension model Azure VMs themselves use.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	hybridcompute "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/hybridcompute"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_hybridcompute_openapi_machine_extension"})

    		ubx.Data(hybridcompute.OpenapiMachineExtension, "example", hybridcompute.OpenapiMachineExtensionConfig{
    			MachineName: "example-machine-name",
    		})
    	}))
    }
    ```
  </Tab>

---
title: "azure_operationalinsights_openapi_linked_service"
description: "`data_azure_operationalinsights_openapi_linked_service` looks up a real, already-existing `azure_operationalinsights_openapi_linked_service`."
---

It links a Log Analytics workspace to another Azure resource (e.g. an Automation account) for integrated functionality.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_linked_service"})

    		ubx.Data(operationalinsights.OpenapiLinkedService, "example", operationalinsights.OpenapiLinkedServiceConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

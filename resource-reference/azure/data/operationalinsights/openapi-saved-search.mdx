---
title: "azure_operationalinsights_openapi_saved_search"
description: "`data_azure_operationalinsights_openapi_saved_search` looks up a real, already-existing `azure_operationalinsights_openapi_saved_search`."
---

It is a named, reusable Log Analytics query saved directly to a single workspace.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_saved_search"})

    		ubx.Data(operationalinsights.OpenapiSavedSearch, "example", operationalinsights.OpenapiSavedSearchConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiSavedSearch } from "@ubx/sdk-azure/azure/data/operationalinsights/openapi_saved_search";

    export default stack("example", () => {
      intent({ summary: "look up azure_operationalinsights_openapi_saved_search" });

      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.operationalinsights import OpenapiSavedSearch, OpenapiSavedSearchConfig

    def describe():
        ubx.intent("look up azure_operationalinsights_openapi_saved_search")

        ubx.data(OpenapiSavedSearch, "example", OpenapiSavedSearchConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

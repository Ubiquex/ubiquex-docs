---
title: "azure_operationalinsights_openapi_summary_logs"
description: "`data_azure_operationalinsights_openapi_summary_logs` looks up a real, already-existing `azure_operationalinsights_openapi_summary_logs`."
---

It schedules a Log Analytics query to run periodically and write its own aggregated results into a summary table, reducing the cost and latency of repeatedly re-running an expensive query.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_summary_logs"})

    		ubx.Data(operationalinsights.OpenapiSummaryLogs, "example", operationalinsights.OpenapiSummaryLogsConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiSummaryLogs } from "@ubx/sdk-azure/azure/data/operationalinsights/openapi_summary_logs";

    export default stack("example", () => {
      intent({ summary: "look up azure_operationalinsights_openapi_summary_logs" });

      data(OpenapiSummaryLogs, "example", {
        workspaceName: "example-workspace-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.operationalinsights import OpenapiSummaryLogs, OpenapiSummaryLogsConfig

    def describe():
        ubx.intent("look up azure_operationalinsights_openapi_summary_logs")

        ubx.data(OpenapiSummaryLogs, "example", OpenapiSummaryLogsConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The SummaryLogs items on this page Returned by the lookup.
</ResponseField>

`data_azure_operationalinsights_openapi_linked_storage_accounts_resource` looks up a real, already-existing `azure_operationalinsights_openapi_linked_storage_accounts_resource`. It links a storage account to a Log Analytics workspace, used for custom log ingestion or query result caching.

## Example

    ```go
    package main

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_linked_storage_accounts_resource"})

    		ubx.Data(operationalinsights.OpenapiLinkedStorageAccountsResource, "example", operationalinsights.OpenapiLinkedStorageAccountsResourceConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```

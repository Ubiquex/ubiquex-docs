---
title: "azure_operationalinsights_openapi_data_source"
description: "`data_azure_operationalinsights_openapi_data_source` looks up a real, already-existing `azure_operationalinsights_openapi_data_source`."
---

It configures a legacy Log Analytics data collection source (e.g. Windows event logs) for a connected agent-based machine.

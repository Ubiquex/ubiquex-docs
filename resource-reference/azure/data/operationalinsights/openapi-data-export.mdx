---
title: "azure_operationalinsights_openapi_data_export"
description: "`data_azure_operationalinsights_openapi_data_export` looks up a real, already-existing `azure_operationalinsights_openapi_data_export`."
---

It continuously exports matching Log Analytics workspace data (specific table(s)) to an external destination (a Storage account or Event Hub).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_data_export"})

    		ubx.Data(operationalinsights.OpenapiDataExport, "example", operationalinsights.OpenapiDataExportConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.operationalinsights import OpenapiDataExport, OpenapiDataExportConfig

    def describe():
        ubx.intent("look up azure_operationalinsights_openapi_data_export")

        ubx.data(OpenapiDataExport, "example", OpenapiDataExportConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL to get the next set of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  List of data export instances within a workspace.. Returned by the lookup.
</ResponseField>

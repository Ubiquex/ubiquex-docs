`data_azure_operationalinsights_openapi_log_analytics_query_pack` looks up a real, already-existing `azure_operationalinsights_openapi_log_analytics_query_pack`. It is a shareable collection of saved Log Analytics query/queries, reusable across multiple workspace(s) rather than saved to just one.

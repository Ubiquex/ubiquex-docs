---
title: "azure_operationalinsights_openapi_workspace"
description: "`data_azure_operationalinsights_openapi_workspace` looks up a real, already-existing `azure_operationalinsights_openapi_workspace`."
---

It is a Log Analytics workspace, the top-level container log and telemetry data across Azure Monitor, Microsoft Sentinel, and other services is ingested into and queried from.

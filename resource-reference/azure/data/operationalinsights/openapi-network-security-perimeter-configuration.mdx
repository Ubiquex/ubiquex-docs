## Lookup arguments

<ResponseField name="network_security_perimeter_configuration_name" type="string" required>
  The real name of the Network Security Perimeter configuration this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

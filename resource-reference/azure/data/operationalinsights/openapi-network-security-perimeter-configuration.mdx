`azure_operationalinsights_openapi_network_security_perimeter_configuration` reads the real Network Security Perimeter configuration applied to a Log Analytics workspace.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_network_security_perimeter_configuration"})

    		ubx.Data(operationalinsights.OpenapiNetworkSecurityPerimeterConfiguration, "example", operationalinsights.OpenapiNetworkSecurityPerimeterConfigurationConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

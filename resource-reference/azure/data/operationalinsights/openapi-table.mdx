---
title: "azure_operationalinsights_openapi_table"
description: "`data_azure_operationalinsights_openapi_table` looks up a real, already-existing `azure_operationalinsights_openapi_table`."
---

It is a table within a Log Analytics workspace, holding ingested log data of a specific schema and its own retention/plan configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_operationalinsights_openapi_table"})

    		ubx.Data(operationalinsights.OpenapiTable, "example", operationalinsights.OpenapiTableConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

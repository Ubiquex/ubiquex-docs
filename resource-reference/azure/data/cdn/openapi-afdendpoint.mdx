---
title: "azure_cdn_openapi_afdendpoint"
description: "`data_azure_cdn_openapi_afdendpoint` looks up a real, already-existing `azure_cdn_openapi_afdendpoint`."
---

It is the entry point through which Azure Front Door serves traffic for one or more custom domain(s), routed to origin group(s) via defined route(s).

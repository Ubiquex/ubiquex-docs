---
title: "azure_cdn_openapi_security_policy"
description: "`data_azure_cdn_openapi_security_policy` looks up a real, already-existing `azure_cdn_openapi_security_policy`."
---

It attaches a Web Application Firewall policy to specific domain(s) served by an Azure Front Door profile.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cdn_openapi_security_policy"})

    		ubx.Data(cdn.OpenapiSecurityPolicy, "example", cdn.OpenapiSecurityPolicyConfig{
    			ProfileName: "example-profile-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiSecurityPolicy } from "@ubx/sdk-azure/azure/data/cdn/openapi_security_policy";

    export default stack("example", () => {
      intent({ summary: "look up azure_cdn_openapi_security_policy" });

      data(OpenapiSecurityPolicy, "example", {
        profileName: "example-profile-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.cdn import OpenapiSecurityPolicy, OpenapiSecurityPolicyConfig

    def describe():
        ubx.intent("look up azure_cdn_openapi_security_policy")

        ubx.data(OpenapiSecurityPolicy, "example", OpenapiSecurityPolicyConfig(
            profile_name="example-profile-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

---
title: "azure_cdn_openapi_route"
description: "`data_azure_cdn_openapi_route` looks up a real, already-existing `azure_cdn_openapi_route`."
---

It maps an incoming Azure Front Door request pattern (domain and path) to a specific origin group, with its own caching and protocol behavior.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cdn_openapi_route"})

    		ubx.Data(cdn.OpenapiRoute, "example", cdn.OpenapiRouteConfig{
    			EndpointName: "example-endpoint-name",
    			ProfileName:  "example-profile-name",
    		})
    	}))
    }
    ```

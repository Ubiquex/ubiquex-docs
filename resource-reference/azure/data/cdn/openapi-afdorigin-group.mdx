---
title: "azure_cdn_openapi_afdorigin_group"
description: "`data_azure_cdn_openapi_afdorigin_group` looks up a real, already-existing `azure_cdn_openapi_afdorigin_group`."

It groups related origin(s) together in Azure Front Door, providing health-probe-based load balancing and failover across them.

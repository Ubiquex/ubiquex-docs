---
title: "azure_cdn_openapi_rule"
description: "`data_azure_cdn_openapi_rule` looks up a real, already-existing `azure_cdn_openapi_rule`."
---

It defines a match condition and action(s) (e.g. a redirect or header modification) applied to matching requests within an Azure Front Door or CDN rule set.

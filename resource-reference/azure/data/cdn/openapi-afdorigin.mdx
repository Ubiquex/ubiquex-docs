---
title: "azure_cdn_openapi_afdorigin"
description: "`data_azure_cdn_openapi_afdorigin` looks up a real, already-existing `azure_cdn_openapi_afdorigin`."
---

It defines a single backend server Azure Front Door retrieves content from, within an origin group.

## Example

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cdn"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cdn_openapi_afdorigin"})

    		ubx.Data(cdn.OpenapiAfdorigin, "example", cdn.OpenapiAfdoriginConfig{
    			OriginGroupName: "example-origin-group-name",
    			ProfileName:     "example-profile-name",
    		})
    	}))
    }

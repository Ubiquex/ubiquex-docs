---
title: "azure_cdn_openapi_origin"
description: "`data_azure_cdn_openapi_origin` looks up a real, already-existing `azure_cdn_openapi_origin`."
---

It defines the backend server a classic Azure CDN endpoint retrieves and caches content from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cdn_openapi_origin"})

    		ubx.Data(cdn.OpenapiOrigin, "example", cdn.OpenapiOriginConfig{
    			EndpointName: "example-endpoint-name",
    			ProfileName:  "example-profile-name",
    		})
    	}))
    }
    ```
  </Tab>

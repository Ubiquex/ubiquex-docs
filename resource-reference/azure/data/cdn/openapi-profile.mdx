---
title: "azure_cdn_openapi_profile"
description: "`data_azure_cdn_openapi_profile` looks up a real, already-existing `azure_cdn_openapi_profile`."
---

It is the top-level Azure CDN or Front Door resource that endpoint(s), origin group(s), and their own configuration are created within.

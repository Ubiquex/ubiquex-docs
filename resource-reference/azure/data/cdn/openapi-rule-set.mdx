---
title: "azure_cdn_openapi_rule_set"
description: "`data_azure_cdn_openapi_rule_set` looks up a real, already-existing `azure_cdn_openapi_rule_set`."
---

It groups related rule(s) together, applied to route(s) referencing the rule set within Azure Front Door or CDN.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cdn_openapi_rule_set"})

    		ubx.Data(cdn.OpenapiRuleSet, "example", cdn.OpenapiRuleSetConfig{
    			ProfileName: "example-profile-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiRuleSet } from "@ubx/sdk-azure/azure/data/cdn/openapi_rule_set";

    export default stack("example", () => {
      intent({ summary: "look up azure_cdn_openapi_rule_set" });

      data(OpenapiRuleSet, "example", {
        profileName: "example-profile-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.cdn import OpenapiRuleSet, OpenapiRuleSetConfig

    def describe():
        ubx.intent("look up azure_cdn_openapi_rule_set")

        ubx.data(OpenapiRuleSet, "example", OpenapiRuleSetConfig(
            profile_name="example-profile-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

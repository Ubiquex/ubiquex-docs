`data_azure_kubernetesconfiguration_source_control_configuration` looks up a real, already-existing `azure_kubernetesconfiguration_source_control_configuration`. It is the legacy GitOps configuration resource for Azure Arc-enabled and AKS clusters, superseded by Flux configurations.

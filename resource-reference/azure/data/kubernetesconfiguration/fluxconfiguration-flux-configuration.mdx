`data_azure_kubernetesconfiguration_fluxconfiguration_flux_configuration` looks up a real, already-existing `azure_kubernetesconfiguration_fluxconfiguration_flux_configuration`. It configures GitOps-based continuous deployment for a Kubernetes cluster using Flux, reconciling cluster state against a Git repository.

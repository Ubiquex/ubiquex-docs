---
title: "azure_kubernetesconfiguration_extensions_extension"
description: "`data_azure_kubernetesconfiguration_extensions_extension` looks up a real, already-existing `azure_kubernetesconfiguration_extensions_extension`."
---

It installs a Kubernetes cluster extension (via the Azure Arc/AKS Cluster Extensions framework) onto a connected cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kubernetesconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/kubernetesconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_kubernetesconfiguration_extensions_extension"})

    		ubx.Data(kubernetesconfiguration.ExtensionsExtension, "example", kubernetesconfiguration.ExtensionsExtensionConfig{})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

_This lookup takes no arguments._

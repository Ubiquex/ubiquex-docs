---
title: "azure_mysql_openapi_configuration"
description: "`data_azure_mysql_openapi_configuration` looks up a real, already-existing `azure_mysql_openapi_configuration`."
---

It sets a single MySQL server parameter (e.g. `max_connections`) on an Azure Database for MySQL flexible server.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mysql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/mysql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_mysql_openapi_configuration"})

    		ubx.Data(mysql.OpenapiConfiguration, "example", mysql.OpenapiConfigurationConfig{
    			ServerName: "example-server-name",
    			Keyword:    "example",
    			Page:       1,
    			PageSize:   1,
    			Tags:       "example",
    		})
    	}))
    }
    ```

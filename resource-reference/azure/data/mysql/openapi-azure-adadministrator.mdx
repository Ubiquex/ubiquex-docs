---
title: "azure_mysql_openapi_azure_adadministrator"
description: "`data_azure_mysql_openapi_azure_adadministrator` looks up a real, already-existing `azure_mysql_openapi_azure_adadministrator`."
---

It designates a Microsoft Entra ID principal as the administrator for an Azure Database for MySQL flexible server, enabling Entra ID authentication.

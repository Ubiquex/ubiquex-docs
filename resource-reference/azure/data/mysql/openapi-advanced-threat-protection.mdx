---
title: "azure_mysql_openapi_advanced_threat_protection"
description: "`data_azure_mysql_openapi_advanced_threat_protection` looks up a real, already-existing `azure_mysql_openapi_advanced_threat_protection`."
---

It enables Microsoft Defender for Cloud's own threat detection (anomalous access patterns, SQL injection attempts) on an Azure Database for MySQL flexible server.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mysql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/mysql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_mysql_openapi_advanced_threat_protection"})

    		ubx.Data(mysql.OpenapiAdvancedThreatProtection, "example", mysql.OpenapiAdvancedThreatProtectionConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```

`azure_mysql_openapi_server_backup_v2` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_mysql_openapi_server_backup_v2"})

    		ubx.Data(mysql.OpenapiServerBackupV2, "example", mysql.OpenapiServerBackupV2Config{
    			ServerName: "example-server-name",
    		})
    	}))
    }

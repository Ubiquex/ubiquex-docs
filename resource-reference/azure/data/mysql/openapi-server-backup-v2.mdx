---
title: "azure_mysql_openapi_server_backup_v2"
description: "`data_azure_mysql_openapi_server_backup_v2` looks up a real, already-existing `azure_mysql_openapi_server_backup_v2`."
---

It is the current-generation backup resource for Azure Database for MySQL flexible server, supporting longer retention and on-demand backup triggering.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mysql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/mysql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_mysql_openapi_server_backup_v2"})

    		ubx.Data(mysql.OpenapiServerBackupV2, "example", mysql.OpenapiServerBackupV2Config{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```

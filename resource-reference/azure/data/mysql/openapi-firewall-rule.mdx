---
title: "azure_mysql_openapi_firewall_rule"
description: "`data_azure_mysql_openapi_firewall_rule` looks up a real, already-existing `azure_mysql_openapi_firewall_rule`."
---

It allows a specific IP address range to connect to an Azure Database for MySQL flexible server that hasn't been placed inside a virtual network.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mysql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/mysql"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_mysql_openapi_firewall_rule"})

    		ubx.Data(mysql.OpenapiFirewallRule, "example", mysql.OpenapiFirewallRuleConfig{
    			ServerName: "example-server-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.mysql import OpenapiFirewallRule, OpenapiFirewallRuleConfig

        ubx.data(OpenapiFirewallRule, "example", OpenapiFirewallRuleConfig(
            server_name="example-server-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

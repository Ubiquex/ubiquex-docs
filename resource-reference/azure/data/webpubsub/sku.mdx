## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	webpubsub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/webpubsub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_webpubsub_sku"})

    		ubx.Data(webpubsub.Sku, "example", webpubsub.SkuConfig{
    			ReplicaName:  "example-replica-name",
    			ResourceName: "example-resource-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    });

  </Tab>
  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.azure.data.webpubsub import Sku, SkuConfig

    def describe():
        ubx.intent("look up azure_webpubsub_sku")

        ubx.data(Sku, "example", SkuConfig(
            replica_name="example-replica-name",
            resource_name="example-resource-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="replica_name" type="string" required>
  The real name of the replica this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL the client should use to fetch the next page (per server side paging). It's null for now, added for future use. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of skus available for the resource. Returned by the lookup.
</ResponseField>

---
title: "azure_webpubsub_shared_private_link_resource"
description: "`data_azure_webpubsub_shared_private_link_resource` looks up a real, already-existing `azure_webpubsub_shared_private_link_resource`."
---

It creates a Private Endpoint from a Web PubSub resource to another Private Link-enabled Azure service, so outbound event handler calls can stay private.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	webpubsub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/webpubsub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_webpubsub_shared_private_link_resource"})

    		ubx.Data(webpubsub.SharedPrivateLinkResource, "example", webpubsub.SharedPrivateLinkResourceConfig{
    			ReplicaName:  "example-replica-name",
    			ResourceName: "example-resource-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.webpubsub import SharedPrivateLinkResource, SharedPrivateLinkResourceConfig

    def describe():
        ubx.intent("look up azure_webpubsub_shared_private_link_resource")

        ubx.data(SharedPrivateLinkResource, "example", SharedPrivateLinkResourceConfig(
            replica_name="example-replica-name",
            resource_name="example-resource-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="replica_name" type="string" required>
  The real name of the replica this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  Request URL that can be used to query next page of private endpoint connections. Returned when the total number of requested private endpoint connections exceed maximum page size. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of the shared private link resources Returned by the lookup.
</ResponseField>

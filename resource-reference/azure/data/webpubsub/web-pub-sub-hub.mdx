---
title: "azure_webpubsub_web_pub_sub_hub"
description: "`data_azure_webpubsub_web_pub_sub_hub` looks up a real, already-existing `azure_webpubsub_web_pub_sub_hub`."
---

It is a hub within a Web PubSub resource, defining the event handler(s) and behavior applied to WebSocket connections scoped to that hub.

## Example

    	webpubsub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/webpubsub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_webpubsub_web_pub_sub_hub"})

    		})

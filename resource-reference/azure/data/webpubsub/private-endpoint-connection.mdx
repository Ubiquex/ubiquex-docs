---
title: "azure_webpubsub_private_endpoint_connection"
description: "`data_azure_webpubsub_private_endpoint_connection` looks up a real, already-existing `azure_webpubsub_private_endpoint_connection`."
---

It represents the connection between a Private Endpoint and a Web PubSub resource, tracking its own approval state.

## Example

    	ubx.Main(ubx.Stack("example", func() {

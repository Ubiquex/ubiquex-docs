---
title: "azure_webpubsub_custom_certificate"
description: "`data_azure_webpubsub_custom_certificate` looks up a real, already-existing `azure_webpubsub_custom_certificate`."
---

It uploads a TLS certificate (referenced from Key Vault) to a Web PubSub resource, bindable to a custom domain.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	webpubsub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/webpubsub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_webpubsub_custom_certificate"})

    		ubx.Data(webpubsub.CustomCertificate, "example", webpubsub.CustomCertificateConfig{
    			ResourceName: "example-resource-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { CustomCertificate } from "@ubx/sdk-azure/azure/data/webpubsub/custom_certificate";

    export default stack("example", () => {
      intent({ summary: "look up azure_webpubsub_custom_certificate" });

      data(CustomCertificate, "example", {
        resourceName: "example-resource-name",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.webpubsub import CustomCertificate, CustomCertificateConfig

    def describe():
        ubx.intent("look up azure_webpubsub_custom_certificate")

        ubx.data(CustomCertificate, "example", CustomCertificateConfig(
            resource_name="example-resource-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

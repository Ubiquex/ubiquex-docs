## Lookup arguments

</ResponseField>

<ResponseField name="scope" type="string" required>
  The real Azure Resource Manager scope (subscription, resource group, or resource) this lookup is applied at. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="value" type="list(object)">

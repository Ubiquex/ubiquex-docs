---
title: "azure_cost_management_openapi_setting"
description: "`data_azure_cost_management_openapi_setting` looks up a real, already-existing `azure_cost_management_openapi_setting`."
---

It configures Cost Management-level preferences (e.g. default currency) for a scope.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	cost "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/cost"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_cost_management_openapi_setting"})

    		ubx.Data(cost.ManagementOpenapiSetting, "example", cost.ManagementOpenapiSettingConfig{
    			Scope: "example",
    		})
    	}))
    }
    ```

---
title: "azure_cost_management_openapi_markup_rule"
description: "`data_azure_cost_management_openapi_markup_rule` looks up a real, already-existing `azure_cost_management_openapi_markup_rule`."
---

It applies a percentage markup to cost data shown to a customer, used by partners billing through Azure to add their own margin.

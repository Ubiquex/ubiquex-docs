`data_azure_securityinsights_openapi_data_connector_definition` looks up a real, already-existing `azure_securityinsights_openapi_data_connector_definition`. It defines the connection UI and configuration schema for a Microsoft Sentinel data connector, used when publishing a connector as reusable content.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_data_connector_definition"})

    		ubx.Data(securityinsights.OpenapiDataConnectorDefinition, "example", securityinsights.OpenapiDataConnectorDefinitionConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

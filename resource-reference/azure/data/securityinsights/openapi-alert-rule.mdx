---
title: "azure_securityinsights_openapi_alert_rule"
description: "`data_azure_securityinsights_openapi_alert_rule` looks up a real, already-existing `azure_securityinsights_openapi_alert_rule`."
---

It defines the detection logic (a scheduled query, ML analytics, or fusion rule) Microsoft Sentinel evaluates to generate an alert from matching log or signal data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_alert_rule"})

    		ubx.Data(securityinsights.OpenapiAlertRule, "example", securityinsights.OpenapiAlertRuleConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```

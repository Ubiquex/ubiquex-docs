---
title: "azure_securityinsights_openapi_incident"
description: "`data_azure_securityinsights_openapi_incident` looks up a real, already-existing `azure_securityinsights_openapi_incident`."
---

It is a Microsoft Sentinel security incident, grouping related alert(s) together as the unit an analyst investigates and resolves.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_incident"})

    		ubx.Data(securityinsights.OpenapiIncident, "example", securityinsights.OpenapiIncidentConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.securityinsights import OpenapiIncident, OpenapiIncidentConfig

    def describe():
        ubx.intent("look up azure_securityinsights_openapi_incident")

        ubx.data(OpenapiIncident, "example", OpenapiIncidentConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

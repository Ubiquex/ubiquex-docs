---
title: "azure_securityinsights_openapi_source_control"
description: "`data_azure_securityinsights_openapi_source_control` looks up a real, already-existing `azure_securityinsights_openapi_source_control`."
---

It links a Microsoft Sentinel workspace to an external Git repository, syncing analytics rule and other content definitions from source control.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_source_control"})

    		ubx.Data(securityinsights.OpenapiSourceControl, "example", securityinsights.OpenapiSourceControlConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiSourceControl } from "@ubx/sdk-azure/azure/data/securityinsights/openapi_source_control";

    export default stack("example", () => {
      intent({ summary: "look up azure_securityinsights_openapi_source_control" });

      data(OpenapiSourceControl, "example", {
        workspaceName: "example-workspace-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.securityinsights import OpenapiSourceControl, OpenapiSourceControlConfig

    def describe():
        ubx.intent("look up azure_securityinsights_openapi_source_control")

        ubx.data(OpenapiSourceControl, "example", OpenapiSourceControlConfig(
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

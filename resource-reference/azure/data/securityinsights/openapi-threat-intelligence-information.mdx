`data_azure_securityinsights_openapi_threat_intelligence_information` looks up a real, already-existing `azure_securityinsights_openapi_threat_intelligence_information`. It is a single threat intelligence indicator (an IP, domain, or hash) ingested into Microsoft Sentinel, used to enrich and match against incoming log data.

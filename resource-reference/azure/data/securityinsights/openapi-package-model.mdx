---
title: "azure_securityinsights_openapi_package_model"
description: "`data_azure_securityinsights_openapi_package_model` looks up a real, already-existing `azure_securityinsights_openapi_package_model`."
---

It is an installable bundle of related Microsoft Sentinel content (analytics rules, workbooks, playbooks) for a specific solution, distributed through the content hub.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_package_model"})

    		ubx.Data(securityinsights.OpenapiPackageModel, "example", securityinsights.OpenapiPackageModelConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

`azure_securityinsights_openapi_threat_intelligence_metrics` reads real, aggregated metrics about threat intelligence indicators ingested into Microsoft Sentinel.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_threat_intelligence_metrics"})

    		ubx.Data(securityinsights.OpenapiThreatIntelligenceMetrics, "example", securityinsights.OpenapiThreatIntelligenceMetricsConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

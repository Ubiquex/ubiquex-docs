---
title: "azure_securityinsights_openapi_metadata_model"
description: "`data_azure_securityinsights_openapi_metadata_model` looks up a real, already-existing `azure_securityinsights_openapi_metadata_model`."
---

It describes the source, author, and dependency metadata for a piece of Microsoft Sentinel content (an analytics rule, playbook, or workbook) published to the content hub.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_metadata_model"})

    		ubx.Data(securityinsights.OpenapiMetadataModel, "example", securityinsights.OpenapiMetadataModelConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```

---
title: "azure_securityinsights_openapi_action_response"
description: "`data_azure_securityinsights_openapi_action_response` looks up a real, already-existing `azure_securityinsights_openapi_action_response`."
---

It defines a playbook (Logic App) that an alert rule or automation rule triggers to run automatically in Microsoft Sentinel.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_action_response"})

    		ubx.Data(securityinsights.OpenapiActionResponse, "example", securityinsights.OpenapiActionResponseConfig{
    			RuleId:        "example",
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.securityinsights import OpenapiActionResponse, OpenapiActionResponseConfig

    def describe():
        ubx.intent("look up azure_securityinsights_openapi_action_response")

        ubx.data(OpenapiActionResponse, "example", OpenapiActionResponseConfig(
            rule_id="example",
            workspace_name="example-workspace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="rule_id" type="string" required>
  The real, unique identifier of the rule this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`data_azure_securityinsights_openapi_security_mlanalytics_setting` looks up a real, already-existing `azure_securityinsights_openapi_security_mlanalytics_setting`. It configures a Microsoft Sentinel built-in machine learning analytics detection (e.g. anomalous sign-in detection).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_securityinsights_openapi_security_mlanalytics_setting"})

    		ubx.Data(securityinsights.OpenapiSecurityMlanalyticsSetting, "example", securityinsights.OpenapiSecurityMlanalyticsSettingConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```
  </Tab>

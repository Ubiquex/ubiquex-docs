---
title: "azure_availability_set"
description: "`data_azure_availability_set` looks up a real, already-existing `azure_availability_set`."
---

It groups VMs so a single hardware failure or maintenance event can't take down every instance of an application at once. Azure spreads the VMs across up to 3 fault domains (shared power and network switch) and up to 20 update domains (VMs that restart together during planned maintenance), and neither count can change after the set is created. There's no extra cost for using one, but Microsoft's own current guidance recommends Virtual Machine Scale Sets with flexible orchestration for new deployments needing the widest range of availability features.

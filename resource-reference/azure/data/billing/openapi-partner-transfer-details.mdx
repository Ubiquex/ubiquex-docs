---
title: "azure_billing_openapi_partner_transfer_details"
description: "`data_azure_billing_openapi_partner_transfer_details` looks up a real, already-existing `azure_billing_openapi_partner_transfer_details`."
---

It tracks a CSP partner-initiated request to transfer billing ownership of subscription(s) to a different partner or customer.

## Example

    ```go

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_billing_openapi_partner_transfer_details"})

    		ubx.Data(billing.OpenapiPartnerTransferDetails, "example", billing.OpenapiPartnerTransferDetailsConfig{
    			BillingAccountName: "example-billing-account-name",
    			BillingProfileName: "example-billing-profile-name",
    			CustomerName:       "example-customer-name",
    		})
    	}))
    }
    ```

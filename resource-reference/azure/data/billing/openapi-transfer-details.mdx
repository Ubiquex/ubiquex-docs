---
title: "azure_billing_openapi_transfer_details"
description: "`data_azure_billing_openapi_transfer_details` looks up a real, already-existing `azure_billing_openapi_transfer_details`."
---

It records a request to transfer billing ownership of Azure subscription(s), product(s), or reservation(s) to a different billing account.

## Example

    ```go
    package main

    import (
    	billing "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/billing"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_billing_openapi_transfer_details"})

    		ubx.Data(billing.OpenapiTransferDetails, "example", billing.OpenapiTransferDetailsConfig{
    			BillingAccountName: "example-billing-account-name",
    			BillingProfileName: "example-billing-profile-name",
    			InvoiceSectionName: "example-invoice-section-name",
    		})
    	}))
    }
    ```

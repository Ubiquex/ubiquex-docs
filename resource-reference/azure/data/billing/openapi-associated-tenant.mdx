---
title: "azure_billing_openapi_associated_tenant"
description: "`data_azure_billing_openapi_associated_tenant` looks up a real, already-existing `azure_billing_openapi_associated_tenant`."
---

It links an additional Microsoft Entra ID tenant to a billing account, letting resources in that tenant be billed against the account.

## Lookup arguments

<ResponseField name="billing_account_name" type="string" required>
  The real name of the billing account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="billing_profile_name" type="string" required>
  The real name of the billing profile this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="count" type="bool">
  The total number of matching results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="expand" type="string">
  Which real, additional related data to expand and include in the response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filter" type="string">
  A real OData filter expression restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="order_by" type="string">
  The real field results are ordered by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="search" type="string">
  The real search query string. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="skip" type="number">
  The number of matching results to skip before returning the rest, for pagination. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="top" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

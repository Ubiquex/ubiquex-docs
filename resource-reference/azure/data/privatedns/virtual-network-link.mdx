---
title: "azure_privatedns_virtual_network_link"
description: "`data_azure_privatedns_virtual_network_link` looks up a real, already-existing `azure_privatedns_virtual_network_link`."
---

It links a virtual network to a Private DNS zone, enabling resources in that network to resolve the zone's own record(s) (and optionally register their own via autoregistration).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	privatedns "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/privatedns"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_privatedns_virtual_network_link"})

    		ubx.Data(privatedns.VirtualNetworkLink, "example", privatedns.VirtualNetworkLinkConfig{
    			PrivateZoneName: "example-private-zone-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.privatedns import VirtualNetworkLink, VirtualNetworkLinkConfig

    def describe():
        ubx.intent("look up azure_privatedns_virtual_network_link")

        ubx.data(VirtualNetworkLink, "example", VirtualNetworkLinkConfig(
            private_zone_name="example-private-zone-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

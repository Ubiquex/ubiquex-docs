`azure_privatedns_record_set` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	privatedns "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/privatedns"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_privatedns_record_set"})

    		ubx.Data(privatedns.RecordSet, "example", privatedns.RecordSetConfig{
    			PrivateZoneName: "example-private-zone-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

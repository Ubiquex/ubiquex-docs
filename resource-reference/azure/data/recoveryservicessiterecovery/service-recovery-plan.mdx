`data_azure_recoveryservicessiterecovery_service_recovery_plan` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_recovery_plan`. It orchestrates the ordered failover and startup sequence for a group of related machine(s) in Azure Site Recovery, so multi-tier applications recover in the correct order.

`azure_recoveryservicessiterecovery_service_target_compute_size` reads a real, recommended target Azure VM size for failing over a replicated item via Azure Site Recovery.

## Lookup arguments

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="protection_container_name" type="string" required>
  The real name of the Recovery Services protection container this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="replicated_protected_item_name" type="string" required>
  The real name of the replicated protected item this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

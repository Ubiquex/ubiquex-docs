`data_azure_recoveryservicessiterecovery_service_recovery_services_provider` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_recovery_services_provider`. It registers the on-premises agent (e.g. the Azure Site Recovery Provider on a VMM server) that communicates with a Recovery Services vault.

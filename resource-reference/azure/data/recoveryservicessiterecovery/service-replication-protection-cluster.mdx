`data_azure_recoveryservicessiterecovery_service_replication_protection_cluster` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_replication_protection_cluster`. It protects a Windows Server Failover Cluster (WSFC) running on shared disks as a single Azure Site Recovery unit, rather than protecting each cluster node independently.

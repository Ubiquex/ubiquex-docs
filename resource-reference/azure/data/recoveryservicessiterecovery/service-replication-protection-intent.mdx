`data_azure_recoveryservicessiterecovery_service_replication_protection_intent` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_replication_protection_intent`. It records a caller's own request to enable Azure Site Recovery protection for a machine, before the actual replication protected item has finished being created.

`data_azure_recoveryservicessiterecovery_service_protection_container` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_protection_container`. It is a logical grouping (e.g. a VMware datacenter or Hyper-V host) within a fabric that replication protected item(s) belong to in Azure Site Recovery.

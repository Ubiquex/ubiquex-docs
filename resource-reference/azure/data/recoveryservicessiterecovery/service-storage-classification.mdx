`azure_recoveryservicessiterecovery_service_storage_classification` looks up a real storage classification registered with a Recovery Services vault for Site Recovery storage mapping.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	recoveryservicessiterecovery "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicessiterecovery"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicessiterecovery_service_storage_classification"})

    		ubx.Data(recoveryservicessiterecovery.ServiceStorageClassification, "example", recoveryservicessiterecovery.ServiceStorageClassificationConfig{
    			FabricName:   "example-fabric-name",
    			ResourceName: "example-resource-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

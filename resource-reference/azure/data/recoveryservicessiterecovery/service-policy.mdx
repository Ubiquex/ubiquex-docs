---
title: "azure_recoveryservicessiterecovery_service_policy"

It defines the replication frequency, recovery point retention, and app-consistent snapshot interval Azure Site Recovery applies to protected item(s) using it.

    	ubx.Main(ubx.Stack("example", func() {

`data_azure_recoveryservicessiterecovery_service_migration_item` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_migration_item`. It tracks a single machine undergoing agentless migration (rather than ongoing disaster recovery replication) into Azure through Azure Site Recovery's own migration capability.

## Lookup arguments

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="protection_container_name" type="string" required>
  The real name of the Recovery Services protection container this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="skip_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="take_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

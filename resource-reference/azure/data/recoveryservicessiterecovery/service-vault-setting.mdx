`data_azure_recoveryservicessiterecovery_service_vault_setting` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_vault_setting`. It configures Recovery Services vault-level settings (e.g. migration solution details) used by Azure Site Recovery.

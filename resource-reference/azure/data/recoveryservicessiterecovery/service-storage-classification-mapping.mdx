`data_azure_recoveryservicessiterecovery_service_storage_classification_mapping` looks up a real, already-existing `azure_recoveryservicessiterecovery_service_storage_classification_mapping`. It maps a source storage classification to a target one in Azure Site Recovery, so failed-over VM disks land on the correct target storage tier.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicessiterecovery "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicessiterecovery"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicessiterecovery_service_storage_classification_mapping"})

    		ubx.Data(recoveryservicessiterecovery.ServiceStorageClassificationMapping, "example", recoveryservicessiterecovery.ServiceStorageClassificationMappingConfig{
    			FabricName:                "example-fabric-name",
    			ResourceName:              "example-resource-name",
    			StorageClassificationName: "example-storage-classification-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="storage_classification_name" type="string" required>
  The real name of the storage classification this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`azure_recoveryservicessiterecovery_service_migration_recovery_point` looks up one real, restorable recovery point for an item being migrated via Azure Site Recovery.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicessiterecovery "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicessiterecovery"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicessiterecovery_service_migration_recovery_point"})

    		ubx.Data(recoveryservicessiterecovery.ServiceMigrationRecoveryPoint, "example", recoveryservicessiterecovery.ServiceMigrationRecoveryPointConfig{
    			FabricName:              "example-fabric-name",
    			MigrationItemName:       "example-migration-item-name",
    			ProtectionContainerName: "example-protection-container-name",
    			ResourceName:            "example-resource-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="migration_item_name" type="string" required>
  The real name of the migration item this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="protection_container_name" type="string" required>
  The real name of the Recovery Services protection container this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`azure_recoveryservicessiterecovery_service_cluster_recovery_point` looks up one real, restorable recovery point for a clustered replicated item protected by Azure Site Recovery.

## Example

    ```go

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicessiterecovery_service_cluster_recovery_point"})

    		ubx.Data(recoveryservicessiterecovery.ServiceClusterRecoveryPoint, "example", recoveryservicessiterecovery.ServiceClusterRecoveryPointConfig{
    			FabricName:                       "example-fabric-name",
    			ProtectionContainerName:          "example-protection-container-name",
    			ReplicationProtectionClusterName: "example-replication-protection-cluster-name",
    			ResourceName:                     "example-resource-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="protection_container_name" type="string" required>
  The real name of the Recovery Services protection container this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="replication_protection_cluster_name" type="string" required>
  The real name of the replication protection cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

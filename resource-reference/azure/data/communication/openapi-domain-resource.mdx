---
title: "azure_communication_openapi_domain_resource"
description: "`data_azure_communication_openapi_domain_resource` looks up a real, already-existing `azure_communication_openapi_domain_resource`."
---

It registers a sending domain (Azure-managed or a caller-verified custom domain) for Azure Communication Services Email.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	communication "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/communication"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_communication_openapi_domain_resource"})

    		ubx.Data(communication.OpenapiDomainResource, "example", communication.OpenapiDomainResourceConfig{
    			EmailServiceName: "example-email-service-name",
    		})
    	}))
    }
    ```

    from ubx.azure.data.communication import OpenapiDomainResource, OpenapiDomainResourceConfig

        ubx.intent("look up azure_communication_openapi_domain_resource")

        ))

    if __name__ == "__main__":

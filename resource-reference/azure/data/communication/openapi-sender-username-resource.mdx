---
title: "azure_communication_openapi_sender_username_resource"
description: "`data_azure_communication_openapi_sender_username_resource` looks up a real, already-existing `azure_communication_openapi_sender_username_resource`."

It defines a sender username (the part before `@`) permitted to send email from a verified domain in Azure Communication Services.

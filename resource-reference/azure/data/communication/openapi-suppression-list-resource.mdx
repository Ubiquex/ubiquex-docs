---
title: "azure_communication_openapi_suppression_list_resource"
description: "`data_azure_communication_openapi_suppression_list_resource` looks up a real, already-existing `azure_communication_openapi_suppression_list_resource`."
---

It is a named list of email address(es) Azure Communication Services Email excludes from delivery, e.g. addresses that previously bounced or unsubscribed.

    	ubx.Main(ubx.Stack("example", func() {

---
title: "azure_chaos_openapi_target"
description: "`data_azure_chaos_openapi_target` looks up a real, already-existing `azure_chaos_openapi_target`."
---

It onboards a resource to Azure Chaos Studio, enabling fault-injection capability(ies) to be run against it.

## Example

    // ubx sdk gen --only azure --lang go --out ./local-sdk

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_chaos_openapi_target"})

    			ParentProviderNamespace: "example",
    			ParentResourceName:      "example-parent-resource-name",
    			ParentResourceType:      "example",
    			ContinuationToken:       "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="continuation_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="parent_provider_namespace" type="string" required>
  The real Azure resource provider namespace of the parent resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="parent_resource_name" type="string" required>
  The real name of the parent resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="parent_resource_type" type="string" required>
  The real resource type of the parent resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The Target items on this page Returned by the lookup.
</ResponseField>

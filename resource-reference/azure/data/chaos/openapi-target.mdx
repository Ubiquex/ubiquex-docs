`azure_chaos_openapi_target` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chaos "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/chaos"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_chaos_openapi_target"})

    		ubx.Data(chaos.OpenapiTarget, "example", chaos.OpenapiTargetConfig{
    			ParentProviderNamespace: "example",
    			ParentResourceName:      "example-parent-resource-name",
    			ParentResourceType:      "example",
    			ContinuationToken:       "example",
    		})
    	}))
    }
    ```

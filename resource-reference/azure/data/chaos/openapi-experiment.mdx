---
title: "azure_chaos_openapi_experiment"
description: "`data_azure_chaos_openapi_experiment` looks up a real, already-existing `azure_chaos_openapi_experiment`."
---

It defines an Azure Chaos Studio experiment -- an ordered sequence of fault-injection step(s) run against target resource(s) to test their own resilience.

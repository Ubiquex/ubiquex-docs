---
title: "azure_eventgrid_topic"
description: "`data_azure_eventgrid_topic` looks up a real, already-existing `azure_eventgrid_topic`."
---

It is a custom Event Grid topic, the endpoint a caller-defined application publishes its own event(s) to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	eventgrid "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventgrid"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_topic"})

    		ubx.Data(eventgrid.Topic, "example", eventgrid.TopicConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```

    from ubx.azure.data.eventgrid import Topic, TopicConfig

    def describe():
        ubx.intent("look up azure_eventgrid_topic")

        ubx.data(Topic, "example", TopicConfig(
            api_version="example",

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  A link for the next page of topics Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A collection of Topics Returned by the lookup.
</ResponseField>

---
title: "azure_eventgrid_partner_namespace"
description: "`data_azure_eventgrid_partner_namespace` looks up a real, already-existing `azure_eventgrid_partner_namespace`."
---

It is the resource a registered Event Grid partner publishes third-party SaaS event(s) into, for delivery to subscribed Azure customer(s).

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_partner_namespace"})

    		ubx.Data(eventgrid.PartnerNamespace, "example", eventgrid.PartnerNamespaceConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  A link for the next page of partner namespaces. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A collection of partner namespaces. Returned by the lookup.
</ResponseField>

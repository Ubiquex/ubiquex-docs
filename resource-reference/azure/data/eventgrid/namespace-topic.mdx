---
title: "azure_eventgrid_namespace_topic"
description: "`data_azure_eventgrid_namespace_topic` looks up a real, already-existing `azure_eventgrid_namespace_topic`."
---

It is a topic within an Event Grid namespace, that publisher(s) send CloudEvents-formatted event(s) into and event subscription(s) pull or receive push delivery from.

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="namespace_name" type="string" required>
  The real name of the namespace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "azure_eventgrid_partner_topic"
description: "`data_azure_eventgrid_partner_topic` looks up a real, already-existing `azure_eventgrid_partner_topic`."
---

It is the customer-side topic receiving event(s) published by a registered Event Grid partner's own SaaS platform.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eventgrid "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventgrid"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_partner_topic"})

    		ubx.Data(eventgrid.PartnerTopic, "example", eventgrid.PartnerTopicConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  A link for the next page of partner topics. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A collection of partner topics. Returned by the lookup.
</ResponseField>

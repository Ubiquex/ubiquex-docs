`azure_eventgrid_private_link_resource` reads a real Private Link resource exposed by an Event Grid topic or domain, that a Private Endpoint can connect to.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_private_link_resource"})

    			ApiVersion:        "example",
    			ParentName:        "example-parent-name",

    			SubscriptionId:    "example",
    		})

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="parent_name" type="string" required>
  The real name of the parent resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="parent_type" type="string" required>
  The real type of the parent resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

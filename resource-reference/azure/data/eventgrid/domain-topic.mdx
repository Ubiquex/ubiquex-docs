---
title: "azure_eventgrid_domain_topic"
description: "`data_azure_eventgrid_domain_topic` looks up a real, already-existing `azure_eventgrid_domain_topic`."
---

It is a single logical topic within an Event Grid domain, that event subscription(s) are created against.

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The real domain name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

  A collection of Domain Topics. Returned by the lookup.

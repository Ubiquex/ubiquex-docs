---
title: "azure_eventgrid_channel"
description: "`data_azure_eventgrid_channel` looks up a real, already-existing `azure_eventgrid_channel`."
---

It establishes the event delivery link between an Event Grid partner topic (or partner destination) and the consuming or publishing Azure subscription.

## Example

<Tabs>

    ```go

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_channel"})

    		ubx.Data(eventgrid.Channel, "example", eventgrid.ChannelConfig{
    			ApiVersion:           "example",
    			PartnerNamespaceName: "example-partner-namespace-name",
    			ResourceGroupName:    "example-resource-group-name",
    			SubscriptionId:       "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="partner_namespace_name" type="string" required>
  The real name of the Event Grid partner namespace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  A link for the next page of channels. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A collection of Channels. Returned by the lookup.
</ResponseField>

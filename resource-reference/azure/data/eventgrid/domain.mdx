---
title: "azure_eventgrid_domain"
description: "`data_azure_eventgrid_domain` looks up a real, already-existing `azure_eventgrid_domain`."
---

It is a management tier grouping many related Event Grid topics together under a single endpoint and access control boundary, for large-scale multi-tenant event publishing scenarios.

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

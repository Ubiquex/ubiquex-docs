---
title: "azure_eventgrid_topic_space"
description: "`data_azure_eventgrid_topic_space` looks up a real, already-existing `azure_eventgrid_topic_space`."
---

It is a named group of MQTT topic pattern(s) within an Event Grid namespace, that permission binding(s) grant client access to collectively.

## Example

<Tabs>

    ```go

    import (
    	eventgrid "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventgrid"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_topic_space"})

    		ubx.Data(eventgrid.TopicSpace, "example", eventgrid.TopicSpaceConfig{
    			ApiVersion:        "example",
    			NamespaceName:     "example-namespace-name",
    			ResourceGroupName: "example-resource-group-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="namespace_name" type="string" required>
  The real name of the namespace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  A link for the next page of Topic Space. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A collection of Topic Space. Returned by the lookup.

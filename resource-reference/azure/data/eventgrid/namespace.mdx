---
title: "azure_eventgrid_namespace"
description: "`data_azure_eventgrid_namespace` looks up a real, already-existing `azure_eventgrid_namespace`."
---

It is an Event Grid namespace, the newer resource providing both MQTT broker capability and namespace topics for pull or push event delivery.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eventgrid "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventgrid"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventgrid_namespace"})

    		ubx.Data(eventgrid.Namespace, "example", eventgrid.NamespaceConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  A link for the next page of namespaces. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  A collection of namespaces. Returned by the lookup.
</ResponseField>

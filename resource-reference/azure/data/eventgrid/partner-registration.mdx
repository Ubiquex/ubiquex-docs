---
title: "azure_eventgrid_partner_registration"
description: "`data_azure_eventgrid_partner_registration` looks up a real, already-existing `azure_eventgrid_partner_registration`."
---

It registers a third-party SaaS provider as an Event Grid partner, authorizing it to publish events into customer Azure subscriptions.

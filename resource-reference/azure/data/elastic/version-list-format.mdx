`data_azure_elastic_version_list_format` is a real, live lookup against Microsoft Azure, generated from azure's own real schema -- read-only, never created or destroyed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elastic "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/elastic"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_elastic_version_list_format"})

    		ubx.Data(elastic.VersionListFormat, "example", elastic.VersionListFormatConfig{
    			Region: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

---
title: "azure_elastic_open_aiintegration_rpmodel"
description: "`data_azure_elastic_open_aiintegration_rpmodel` looks up a real, already-existing `azure_elastic_open_aiintegration_rpmodel`."
---

It connects an Elastic resource's own AI Assistant features to an Azure OpenAI deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elastic "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/elastic"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_elastic_open_aiintegration_rpmodel"})

    		ubx.Data(elastic.OpenAiintegrationRpmodel, "example", elastic.OpenAiintegrationRpmodelConfig{
    			MonitorName: "example-monitor-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenAiintegrationRpmodel } from "@ubx/sdk-azure/azure/data/elastic/open_aiintegration_rpmodel";

    export default stack("example", () => {
      intent({ summary: "look up azure_elastic_open_aiintegration_rpmodel" });

      data(OpenAiintegrationRpmodel, "example", {
        monitorName: "example-monitor-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.elastic import OpenAiintegrationRpmodel, OpenAiintegrationRpmodelConfig

    def describe():
        ubx.intent("look up azure_elastic_open_aiintegration_rpmodel")

        ubx.data(OpenAiintegrationRpmodel, "example", OpenAiintegrationRpmodelConfig(
            monitor_name="example-monitor-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="monitor_name" type="string" required>
  The real name of the monitor this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

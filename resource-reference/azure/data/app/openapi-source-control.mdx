---
title: "azure_app_openapi_source_control"
description: "`data_azure_app_openapi_source_control` looks up a real, already-existing `azure_app_openapi_source_control`."
---

It configures continuous deployment for a Container App from a linked source control repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_source_control"})

    		ubx.Data(app.OpenapiSourceControl, "example", app.OpenapiSourceControlConfig{
    			ContainerAppName: "example-container-app-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiSourceControl } from "@ubx/sdk-azure/azure/data/app/openapi_source_control";

    export default stack("example", () => {
      intent({ summary: "look up azure_app_openapi_source_control" });

      data(OpenapiSourceControl, "example", {
        containerAppName: "example-container-app-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import OpenapiSourceControl, OpenapiSourceControlConfig

    def describe():
        ubx.intent("look up azure_app_openapi_source_control")

        ubx.data(OpenapiSourceControl, "example", OpenapiSourceControlConfig(
            container_app_name="example-container-app-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="container_app_name" type="string" required>
  The real name of the Container App this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

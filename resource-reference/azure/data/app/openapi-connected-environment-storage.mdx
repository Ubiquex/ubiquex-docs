---
title: "azure_app_openapi_connected_environment_storage"
description: "`data_azure_app_openapi_connected_environment_storage` looks up a real, already-existing `azure_app_openapi_connected_environment_storage`."
---

It mounts an external storage volume accessible to container app(s) running in a Connected (Arc-enabled) Container Apps environment.

## Example

    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_connected_environment_storage"})

    		ubx.Data(app.OpenapiConnectedEnvironmentStorage, "example", app.OpenapiConnectedEnvironmentStorageConfig{
    			ConnectedEnvironmentName: "example-connected-environment-name",
    		})
    	}))
    }

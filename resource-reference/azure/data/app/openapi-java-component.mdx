---
title: "azure_app_openapi_java_component"
description: "`data_azure_app_openapi_java_component` looks up a real, already-existing `azure_app_openapi_java_component`."
---

It enables a managed Java runtime add-on (e.g. Config Server, Eureka service registry, Admin dashboard) for Java-based container app(s) in a Container Apps environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_java_component"})

    		ubx.Data(app.OpenapiJavaComponent, "example", app.OpenapiJavaComponentConfig{
    			EnvironmentName: "example-environment-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">

    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import OpenapiJavaComponent, OpenapiJavaComponentConfig

    def describe():
        ubx.intent("look up azure_app_openapi_java_component")

        ubx.data(OpenapiJavaComponent, "example", OpenapiJavaComponentConfig(
            environment_name="example-environment-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

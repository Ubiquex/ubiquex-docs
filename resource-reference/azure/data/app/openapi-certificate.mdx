---
title: "azure_app_openapi_certificate"
description: "`data_azure_app_openapi_certificate` looks up a real, already-existing `azure_app_openapi_certificate`."
---

It uploads a TLS certificate to a Container Apps environment, bindable to a custom domain.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_certificate"})

    		ubx.Data(app.OpenapiCertificate, "example", app.OpenapiCertificateConfig{
    			ConnectedEnvironmentName: "example-connected-environment-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiCertificate } from "@ubx/sdk-azure/azure/data/app/openapi_certificate";

    export default stack("example", () => {
      intent({ summary: "look up azure_app_openapi_certificate" });

      data(OpenapiCertificate, "example", {
        connectedEnvironmentName: "example-connected-environment-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import OpenapiCertificate, OpenapiCertificateConfig

    def describe():
        ubx.intent("look up azure_app_openapi_certificate")

        ubx.data(OpenapiCertificate, "example", OpenapiCertificateConfig(
            connected_environment_name="example-connected-environment-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="connected_environment_name" type="string" required>
  The real name of the Container Apps connected environment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "azure_app_sreagent_agent_space_connector"
description: "`data_azure_app_sreagent_agent_space_connector` looks up a real, already-existing `azure_app_sreagent_agent_space_connector`."
---

It connects an external tool or data source at the agent space level, made available to every SRE agent within that space.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_sreagent_agent_space_connector"})

    		ubx.Data(app.SreagentAgentSpaceConnector, "example", app.SreagentAgentSpaceConnectorConfig{
    			AgentSpaceName: "example-agent-space-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

    if __name__ == "__main__":
        ubx.run("example", describe)

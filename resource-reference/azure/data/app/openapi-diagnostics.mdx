## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_diagnostics"})

    		ubx.Data(app.OpenapiDiagnostics, "example", app.OpenapiDiagnosticsConfig{
    			ContainerAppName: "example-container-app-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiDiagnostics } from "@ubx/sdk-azure/azure/data/app/openapi_diagnostics";

    export default stack("example", () => {
      intent({ summary: "look up azure_app_openapi_diagnostics" });

      data(OpenapiDiagnostics, "example", {
        containerAppName: "example-container-app-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import OpenapiDiagnostics, OpenapiDiagnosticsConfig

    def describe():
        ubx.intent("look up azure_app_openapi_diagnostics")

        ubx.data(OpenapiDiagnostics, "example", OpenapiDiagnosticsConfig(
            container_app_name="example-container-app-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="container_app_name" type="string" required>
  The real name of the Container App this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to the next page of items Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The Diagnostics items on this page Returned by the lookup.
</ResponseField>

---
title: "azure_app_openapi_workflow_envelope"
description: "`data_azure_app_openapi_workflow_envelope` looks up a real, already-existing `azure_app_openapi_workflow_envelope`."
---

It describes a single Logic Apps (Standard) workflow hosted within a Container Apps-based Logic App resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_workflow_envelope"})

    		ubx.Data(app.OpenapiWorkflowEnvelope, "example", app.OpenapiWorkflowEnvelopeConfig{
    			ContainerAppName: "example-container-app-name",
    			LogicAppName:     "example-logic-app-name",
    		})
    	}))
    }
    ```

---
title: "azure_app_openapi_dapr_component"
description: "`data_azure_app_openapi_dapr_component` looks up a real, already-existing `azure_app_openapi_dapr_component`."
---

It configures a Dapr building block (state store, pub/sub, secret store) made available to container app(s) in a Container Apps environment via the built-in Dapr sidecar.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_dapr_component"})

    		ubx.Data(app.OpenapiDaprComponent, "example", app.OpenapiDaprComponentConfig{
    			ConnectedEnvironmentName: "example-connected-environment-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiDaprComponent } from "@ubx/sdk-azure/azure/data/app/openapi_dapr_component";

    export default stack("example", () => {
      intent({ summary: "look up azure_app_openapi_dapr_component" });

      data(OpenapiDaprComponent, "example", {
        connectedEnvironmentName: "example-connected-environment-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import OpenapiDaprComponent, OpenapiDaprComponentConfig

    def describe():
        ubx.intent("look up azure_app_openapi_dapr_component")

        ubx.data(OpenapiDaprComponent, "example", OpenapiDaprComponentConfig(
            connected_environment_name="example-connected-environment-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="connected_environment_name" type="string" required>
  The real name of the Container Apps connected environment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

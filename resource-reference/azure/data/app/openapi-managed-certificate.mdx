---
title: "azure_app_openapi_managed_certificate"
description: "`data_azure_app_openapi_managed_certificate` looks up a real, already-existing `azure_app_openapi_managed_certificate`."
---

It is an automatically provisioned and renewed free TLS certificate for a custom domain bound to a Container App.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_managed_certificate"})

    		ubx.Data(app.OpenapiManagedCertificate, "example", app.OpenapiManagedCertificateConfig{
    			EnvironmentName: "example-environment-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import OpenapiManagedCertificate, OpenapiManagedCertificateConfig

    def describe():
        ubx.intent("look up azure_app_openapi_managed_certificate")

        ubx.data(OpenapiManagedCertificate, "example", OpenapiManagedCertificateConfig(
            environment_name="example-environment-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

---
title: "azure_app_openapi_http_route_config"
description: "`data_azure_app_openapi_http_route_config` looks up a real, already-existing `azure_app_openapi_http_route_config`."
---

It defines HTTP routing rule(s) directing matching traffic to a specific revision or target within a Container Apps environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_http_route_config"})

    		ubx.Data(app.OpenapiHttpRouteConfig, "example", app.OpenapiHttpRouteConfigConfig{
    			EnvironmentName: "example-environment-name",
    		})
    	}))
    }
    ```

    from ubx.azure.data.app import OpenapiHttpRouteConfig, OpenapiHttpRouteConfigConfig

        ubx.intent("look up azure_app_openapi_http_route_config")

        ubx.data(OpenapiHttpRouteConfig, "example", OpenapiHttpRouteConfigConfig(

        ))

    if __name__ == "__main__":

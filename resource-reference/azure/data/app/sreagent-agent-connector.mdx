---
title: "azure_app_sreagent_agent_connector"
description: "`data_azure_app_sreagent_agent_connector` looks up a real, already-existing `azure_app_sreagent_agent_connector`."
---

It connects an external tool or data source (e.g. a monitoring or ticketing system) to an Azure SRE Agent, extending what it can observe or act on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_sreagent_agent_connector"})

    		ubx.Data(app.SreagentAgentConnector, "example", app.SreagentAgentConnectorConfig{
    			AgentName: "example-agent-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.app import SreagentAgentConnector, SreagentAgentConnectorConfig

        ubx.data(SreagentAgentConnector, "example", SreagentAgentConnectorConfig(
            agent_name="example-agent-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

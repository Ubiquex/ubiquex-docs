---
title: "azure_app_openapi_job"
description: "`data_azure_app_openapi_job` looks up a real, already-existing `azure_app_openapi_job`."
---

It runs a Container Apps container to completion for a batch, scheduled, or event-driven task, rather than serving ongoing request traffic like a Container App.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_job"})

    		ubx.Data(app.OpenapiJob, "example", app.OpenapiJobConfig{})
    	}))
    }
    ```

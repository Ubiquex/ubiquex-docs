---
title: "azure_app_sreagent_agent"
description: "`data_azure_app_sreagent_agent` looks up a real, already-existing `azure_app_sreagent_agent`."
---

It deploys Azure SRE Agent (preview), an AI agent that monitors application health, investigates incidents, and proposes or takes remediation action within a defined agent space.

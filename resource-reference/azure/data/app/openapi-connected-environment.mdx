---
title: "azure_app_openapi_connected_environment"
description: "`data_azure_app_openapi_connected_environment` looks up a real, already-existing `azure_app_openapi_connected_environment`."
---

It is a Container Apps environment running on Azure Arc-enabled Kubernetes, for deploying container apps outside standard Azure regions.

## Example

    package main

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_connected_environment"})

    	}))
    }

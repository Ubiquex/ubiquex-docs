---
title: "azure_app_openapi_managed_environment"
description: "`data_azure_app_openapi_managed_environment` looks up a real, already-existing `azure_app_openapi_managed_environment`."
---

It is the Container Apps environment -- the secure, isolated boundary sharing a virtual network and Log Analytics workspace -- that container app(s) and job(s) are deployed within.

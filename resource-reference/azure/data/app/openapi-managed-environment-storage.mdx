---
title: "azure_app_openapi_managed_environment_storage"
description: "`data_azure_app_openapi_managed_environment_storage` looks up a real, already-existing `azure_app_openapi_managed_environment_storage`."
---

It mounts an external storage volume (Azure Files) accessible to container app(s) running in a Container Apps environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_app_openapi_managed_environment_storage"})

    		ubx.Data(app.OpenapiManagedEnvironmentStorage, "example", app.OpenapiManagedEnvironmentStorageConfig{
    			EnvironmentName: "example-environment-name",
    		})
    	}))
    }
    ```
  </Tab>

---
title: "azure_vmware_pure_storage_policy"
description: "`data_azure_vmware_pure_storage_policy` looks up a real, already-existing `azure_vmware_pure_storage_policy`."
---

It defines the vVols storage policy applied to VM(s) using Pure Storage Cloud as a datastore within an Azure VMware Solution private cloud.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_pure_storage_policy"})

    		ubx.Data(vmware.PureStoragePolicy, "example", vmware.PureStoragePolicyConfig{
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

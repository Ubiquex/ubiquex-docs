---
title: "azure_vmware_express_route_authorization"
description: "`data_azure_vmware_express_route_authorization` looks up a real, already-existing `azure_vmware_express_route_authorization`."
---

It generates an authorization key letting an external ExpressRoute circuit connect to an Azure VMware Solution private cloud's own ExpressRoute circuit.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_express_route_authorization"})

    		ubx.Data(vmware.ExpressRouteAuthorization, "example", vmware.ExpressRouteAuthorizationConfig{
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ExpressRouteAuthorization } from "@ubx/sdk-azure/azure/data/vmware/express_route_authorization";

    export default stack("example", () => {
      intent({ summary: "look up azure_vmware_express_route_authorization" });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.vmware import ExpressRouteAuthorization, ExpressRouteAuthorizationConfig

    def describe():
        ubx.intent("look up azure_vmware_express_route_authorization")

        ubx.data(ExpressRouteAuthorization, "example", ExpressRouteAuthorizationConfig(
            private_cloud_name="example-private-cloud-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

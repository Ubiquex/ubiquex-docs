---
title: "azure_vmware_global_reach_connection"
description: "`data_azure_vmware_global_reach_connection` looks up a real, already-existing `azure_vmware_global_reach_connection`."
---

It peers an Azure VMware Solution private cloud's own ExpressRoute circuit with another ExpressRoute circuit, extending connectivity to on-premises or another Azure VNet.

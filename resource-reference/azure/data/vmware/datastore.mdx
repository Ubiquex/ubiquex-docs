---
title: "azure_vmware_datastore"
description: "`data_azure_vmware_datastore` looks up a real, already-existing `azure_vmware_datastore`."
---

It attaches external storage (e.g. Azure NetApp Files, Pure Storage Cloud) as a datastore to an Azure VMware Solution cluster, supplementing its own native vSAN capacity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_datastore"})

    		ubx.Data(vmware.Datastore, "example", vmware.DatastoreConfig{
    			ClusterName:      "example-cluster-name",
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="cluster_name" type="string" required>
  The real name of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="private_cloud_name" type="string" required>
  The real name of the Azure VMware Solution private cloud this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

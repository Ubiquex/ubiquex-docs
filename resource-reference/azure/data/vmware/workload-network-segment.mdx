---
title: "azure_vmware_workload_network_segment"
description: "`data_azure_vmware_workload_network_segment` looks up a real, already-existing `azure_vmware_workload_network_segment`."
---

It is a logical Layer 2 network segment within an Azure VMware Solution private cloud's own NSX-T environment, that workload VM(s) are attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_workload_network_segment"})

    		ubx.Data(vmware.WorkloadNetworkSegment, "example", vmware.WorkloadNetworkSegmentConfig{
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

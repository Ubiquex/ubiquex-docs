---
title: "azure_vmware_cluster"
description: "`data_azure_vmware_cluster` looks up a real, already-existing `azure_vmware_cluster`."
---

It is a cluster of node(s) within an Azure VMware Solution private cloud, the unit VMware ESXi/vSAN compute and storage capacity is added in.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_cluster"})

    		ubx.Data(vmware.Cluster, "example", vmware.ClusterConfig{
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Cluster } from "@ubx/sdk-azure/azure/data/vmware/cluster";

    export default stack("example", () => {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.vmware import Cluster, ClusterConfig

    def describe():
        ubx.intent("look up azure_vmware_cluster")

        ubx.data(Cluster, "example", ClusterConfig(
            private_cloud_name="example-private-cloud-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

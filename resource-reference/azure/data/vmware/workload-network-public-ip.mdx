---
title: "azure_vmware_workload_network_public_ip"
description: "`data_azure_vmware_workload_network_public_ip` looks up a real, already-existing `azure_vmware_workload_network_public_ip`."
---

It assigns a public IP address reachable by VM workload(s) within an Azure VMware Solution private cloud's own NSX-T environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_workload_network_public_ip"})

    		ubx.Data(vmware.WorkloadNetworkPublicIp, "example", vmware.WorkloadNetworkPublicIpConfig{
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

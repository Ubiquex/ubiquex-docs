---
title: "azure_vmware_hcx_enterprise_site"
description: "`data_azure_vmware_hcx_enterprise_site` looks up a real, already-existing `azure_vmware_hcx_enterprise_site`."
---

It activates a VMware HCX site connecting an on-premises VMware environment to an Azure VMware Solution private cloud, for live workload migration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_vmware_hcx_enterprise_site"})

    		ubx.Data(vmware.HcxEnterpriseSite, "example", vmware.HcxEnterpriseSiteConfig{
    			PrivateCloudName: "example-private-cloud-name",
    		})
    	}))
    }
    ```
  </Tab>

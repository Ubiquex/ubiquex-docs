---
title: "azure_eventhub_openapi_eventhub"
description: "`data_azure_eventhub_openapi_eventhub` looks up a real, already-existing `azure_eventhub_openapi_eventhub`."
---

It is an event hub, the partitioned append-only log that producer(s) publish event(s) to and consumer group(s) read from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eventhub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventhub_openapi_eventhub"})

    		ubx.Data(eventhub.OpenapiEventhub, "example", eventhub.OpenapiEventhubConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```

---
title: "azure_eventhub_openapi_consumer_group"
description: "`data_azure_eventhub_openapi_consumer_group` looks up a real, already-existing `azure_eventhub_openapi_consumer_group`."
---

It is a named view of an event hub's own event stream, letting multiple independent consumer application(s) read the same stream at their own pace and offset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eventhub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventhub_openapi_consumer_group"})

    		ubx.Data(eventhub.OpenapiConsumerGroup, "example", eventhub.OpenapiConsumerGroupConfig{
    			EventHubName:  "example-event-hub-name",
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>

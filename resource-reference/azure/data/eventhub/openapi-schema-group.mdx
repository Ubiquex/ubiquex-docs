---
title: "azure_eventhub_openapi_schema_group"
description: "`data_azure_eventhub_openapi_schema_group` looks up a real, already-existing `azure_eventhub_openapi_schema_group`."
---

It groups related message schema(s) together within an Event Hubs namespace's own integrated Schema Registry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eventhub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventhub_openapi_schema_group"})

    		ubx.Data(eventhub.OpenapiSchemaGroup, "example", eventhub.OpenapiSchemaGroupConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.eventhub import OpenapiSchemaGroup, OpenapiSchemaGroupConfig

    def describe():
        ubx.intent("look up azure_eventhub_openapi_schema_group")

        ubx.data(OpenapiSchemaGroup, "example", OpenapiSchemaGroupConfig(
            namespace_name="example-namespace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

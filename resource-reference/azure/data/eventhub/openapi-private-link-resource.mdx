`azure_eventhub_openapi_private_link_resource` reads a real Private Link resource exposed by an Event Hubs namespace, that a Private Endpoint can connect to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eventhub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/eventhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_eventhub_openapi_private_link_resource"})

    		ubx.Data(eventhub.OpenapiPrivateLinkResource, "example", eventhub.OpenapiPrivateLinkResourceConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

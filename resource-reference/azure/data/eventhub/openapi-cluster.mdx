title: "azure_eventhub_openapi_cluster"
description: "`data_azure_eventhub_openapi_cluster` looks up a real, already-existing `azure_eventhub_openapi_cluster`."

It provisions a dedicated Event Hubs cluster, single-tenant capacity reserved for one or more namespace(s) at high, predictable throughput.

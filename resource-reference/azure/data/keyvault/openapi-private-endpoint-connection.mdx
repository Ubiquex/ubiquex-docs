---
title: "azure_keyvault_openapi_private_endpoint_connection"

---

It represents the connection between a Private Endpoint and a Key Vault, tracking its own approval state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	keyvault "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/keyvault"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_keyvault_openapi_private_endpoint_connection"})

    		ubx.Data(keyvault.OpenapiPrivateEndpointConnection, "example", keyvault.OpenapiPrivateEndpointConnectionConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```
  </Tab>

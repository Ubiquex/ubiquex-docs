---
title: "azure_keyvault_openapi_key"
description: "`data_azure_keyvault_openapi_key` looks up a real, already-existing `azure_keyvault_openapi_key`."
---

It is a cryptographic key stored in a Key Vault, used for encrypt/decrypt, sign/verify, or wrap/unwrap operations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	keyvault "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/keyvault"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_keyvault_openapi_key"})

    		ubx.Data(keyvault.OpenapiKey, "example", keyvault.OpenapiKeyConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```

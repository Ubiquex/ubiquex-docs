---
title: "azure_keyvault_openapi_vault"
description: "`data_azure_keyvault_openapi_vault` looks up a real, already-existing `azure_keyvault_openapi_vault`."
---

It is an Azure Key Vault, the managed store for key(s), secret(s), and certificate(s) with its own access policy and audit logging.

## Example

<Tabs>

    package main

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_keyvault_openapi_vault"})

    	}))
    }

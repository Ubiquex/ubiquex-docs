`azure_workloads_monitors_sap_landscape_monitor` reads the real SAP landscape (multi-system topology) view configured on an Azure Center for SAP solutions monitor.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	workloads "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/workloads"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_workloads_monitors_sap_landscape_monitor"})

    		ubx.Data(workloads.MonitorsSapLandscapeMonitor, "example", workloads.MonitorsSapLandscapeMonitorConfig{
    			MonitorName: "example-monitor-name",
    		})
    	}))
    }
    ```

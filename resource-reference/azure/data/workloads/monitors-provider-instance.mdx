---
title: "azure_workloads_monitors_provider_instance"
description: "`data_azure_workloads_monitors_provider_instance` looks up a real, already-existing `azure_workloads_monitors_provider_instance`."
---

It registers a specific SAP system component (e.g. the database or a NetWeaver instance) as a data source for Azure Monitor for SAP solutions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	workloads "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/workloads"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_workloads_monitors_provider_instance"})

    		ubx.Data(workloads.MonitorsProviderInstance, "example", workloads.MonitorsProviderInstanceConfig{
    			MonitorName: "example-monitor-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    export default stack("example", () => {
    ```

  <Tab title="Python">
    ```python
    # ubx sdk gen --only azure --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.workloads import MonitorsProviderInstance, MonitorsProviderInstanceConfig

    def describe():
        ubx.intent("look up azure_workloads_monitors_provider_instance")

        ubx.data(MonitorsProviderInstance, "example", MonitorsProviderInstanceConfig(
            monitor_name="example-monitor-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

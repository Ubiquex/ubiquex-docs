---
title: "azure_workloads_monitors_monitor"
description: "`data_azure_workloads_monitors_monitor` looks up a real, already-existing `azure_workloads_monitors_monitor`."
---

It enables Azure Monitor for SAP solutions, collecting telemetry from an SAP landscape's own infrastructure and database components.

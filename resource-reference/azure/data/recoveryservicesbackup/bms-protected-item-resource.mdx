`data_azure_recoveryservicesbackup_bms_protected_item_resource` looks up a real, already-existing `azure_recoveryservicesbackup_bms_protected_item_resource`. It is a single resource (a VM, a database, a file share) currently under active Azure Backup protection.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_protected_item_resource"})

    		ubx.Data(recoveryservicesbackup.BmsProtectedItemResource, "example", recoveryservicesbackup.BmsProtectedItemResourceConfig{
    			ContainerName:     "example-container-name",
    			FabricName:        "example-fabric-name",
    			OperationId:       "example",
    			ProtectedItemName: "example-protected-item-name",
    			VaultName:         "example-vault-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="container_name" type="string" required>
  The real name of the container this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="fabric_name" type="string" required>
  The real name of the Site Recovery fabric (a registered on-premises or Azure site) this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="operation_id" type="string" required>
  The real, unique identifier of this asynchronous operation. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="protected_item_name" type="string" required>
  The real name of the protected item this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="vault_name" type="string" required>
  The real name of the vault this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`azure_recoveryservicesbackup_bms_backup_engine_base_resource` looks up a real backup management server (such as a DPM or MABS server) registered with a Recovery Services vault.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_backup_engine_base_resource"})

    		ubx.Data(recoveryservicesbackup.BmsBackupEngineBaseResource, "example", recoveryservicesbackup.BmsBackupEngineBaseResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

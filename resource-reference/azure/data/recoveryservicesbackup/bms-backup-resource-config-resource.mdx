`azure_recoveryservicesbackup_bms_backup_resource_config_resource` reads the real backup storage configuration (redundancy type) of a Recovery Services vault.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_backup_resource_config_resource"})

    		ubx.Data(recoveryservicesbackup.BmsBackupResourceConfigResource, "example", recoveryservicesbackup.BmsBackupResourceConfigResourceConfig{
    			VaultName: "example-vault-name",
    ```

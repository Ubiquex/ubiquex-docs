`azure_recoveryservicesbackup_bms_workload_protectable_item_resource` looks up a real workload item that's eligible to have backup enabled within a Recovery Services vault.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_workload_protectable_item_resource"})

    		ubx.Data(recoveryservicesbackup.BmsWorkloadProtectableItemResource, "example", recoveryservicesbackup.BmsWorkloadProtectableItemResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```
  </Tab>

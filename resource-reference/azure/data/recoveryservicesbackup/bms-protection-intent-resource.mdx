`data_azure_recoveryservicesbackup_bms_protection_intent_resource` looks up a real, already-existing `azure_recoveryservicesbackup_bms_protection_intent_resource`. It records a caller's own request to enable Azure Backup protection for a resource, before the actual protected item has finished being configured.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_protection_intent_resource"})

    		ubx.Data(recoveryservicesbackup.BmsProtectionIntentResource, "example", recoveryservicesbackup.BmsProtectionIntentResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

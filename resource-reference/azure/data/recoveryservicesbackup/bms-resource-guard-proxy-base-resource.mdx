`data_azure_recoveryservicesbackup_bms_resource_guard_proxy_base_resource` looks up a real, already-existing `azure_recoveryservicesbackup_bms_resource_guard_proxy_base_resource`. It links a Recovery Services vault to a Resource Guard, requiring separately-privileged approval before critical backup operations (like disabling soft delete) can be performed.

`azure_recoveryservicesbackup_bms_backup_resource_vault_config_resource` reads the real vault-level backup configuration (such as soft delete) of a Recovery Services vault.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_backup_resource_vault_config_resource"})

    		ubx.Data(recoveryservicesbackup.BmsBackupResourceVaultConfigResource, "example", recoveryservicesbackup.BmsBackupResourceVaultConfigResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```

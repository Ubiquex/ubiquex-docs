`data_azure_recoveryservicesbackup_bms_protection_policy_resource` looks up a real, already-existing `azure_recoveryservicesbackup_bms_protection_policy_resource`. It defines the backup schedule and retention rule(s) Azure Backup applies to protected item(s) using it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	recoveryservicesbackup "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/recoveryservicesbackup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_recoveryservicesbackup_bms_protection_policy_resource"})

    		ubx.Data(recoveryservicesbackup.BmsProtectionPolicyResource, "example", recoveryservicesbackup.BmsProtectionPolicyResourceConfig{
    			VaultName: "example-vault-name",
    		})
    	}))
    }
    ```
  </Tab>

`data_azure_solutions_managedapplications_jit_request_definition` looks up a real, already-existing `azure_resources_managedapplications_jit_request_definition`. It requests temporary, approval-gated access for a Managed Application's own publisher to troubleshoot a customer's deployed instance, via Just-In-Time access.

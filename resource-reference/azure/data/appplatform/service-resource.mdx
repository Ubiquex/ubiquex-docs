---
title: "azure_appplatform_service_resource"
description: "`data_azure_appplatform_service_resource` looks up a real, already-existing `azure_appplatform_service_resource`."
---

It is the top-level Azure Spring Apps service instance that application(s) and their own shared infrastructure (gateway, config service, registry) are deployed within.

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

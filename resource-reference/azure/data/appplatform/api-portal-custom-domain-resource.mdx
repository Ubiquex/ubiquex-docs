---
title: "azure_appplatform_api_portal_custom_domain_resource"
description: "`data_azure_appplatform_api_portal_custom_domain_resource` looks up a real, already-existing `azure_appplatform_api_portal_custom_domain_resource`."
---

It maps a custom domain to an Azure Spring Apps API portal, the self-service API documentation and testing UI for services in the app.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_appplatform_api_portal_custom_domain_resource"})

    		ubx.Data(appplatform.ApiPortalCustomDomainResource, "example", appplatform.ApiPortalCustomDomainResourceConfig{
    			ApiPortalName:     "example-api-portal-name",
    			ApiVersion:        "example",
    			ResourceGroupName: "example-resource-group-name",
    			ServiceName:       "example-service-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_portal_name" type="string" required>
  The real name of the API portal this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="service_name" type="string" required>
  The real name of the service this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

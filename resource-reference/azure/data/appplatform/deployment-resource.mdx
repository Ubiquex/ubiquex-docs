---
title: "azure_appplatform_deployment_resource"
description: "`data_azure_appplatform_deployment_resource` looks up a real, already-existing `azure_appplatform_deployment_resource`."
---

It is a specific, running deployment of an Azure Spring Apps application's own code, the unit compute resources and instance count are configured on.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_appplatform_deployment_resource"})

---
title: "azure_appplatform_custom_domain_resource"
description: "`data_azure_appplatform_custom_domain_resource` looks up a real, already-existing `azure_appplatform_custom_domain_resource`."
---

It maps a custom domain to a specific application within an Azure Spring Apps instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appplatform "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/appplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_appplatform_custom_domain_resource"})

    		ubx.Data(appplatform.CustomDomainResource, "example", appplatform.CustomDomainResourceConfig{
    			ApiVersion:        "example",
    			AppName:           "example-app-name",
    			ResourceGroupName: "example-resource-group-name",
    			ServiceName:       "example-service-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="app_name" type="string" required>
  The real name of the app this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="resource_group_name" type="string" required>
  The real name of the resource group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="service_name" type="string" required>
  The real name of the service this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link to next page of custom domain list. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The custom domain resources list. Returned by the lookup.
</ResponseField>

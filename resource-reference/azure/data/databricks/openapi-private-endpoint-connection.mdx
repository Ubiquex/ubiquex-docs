---
title: "azure_databricks_openapi_private_endpoint_connection"
description: "`data_azure_databricks_openapi_private_endpoint_connection` looks up a real, already-existing `azure_databricks_openapi_private_endpoint_connection`."
---

It represents the connection between a Private Endpoint and an Azure Databricks workspace, tracking its own approval state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databricks "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/databricks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_databricks_openapi_private_endpoint_connection"})

    		ubx.Data(databricks.OpenapiPrivateEndpointConnection, "example", databricks.OpenapiPrivateEndpointConnectionConfig{
    			WorkspaceName: "example-workspace-name",
    		})
    	}))
    }
    ```

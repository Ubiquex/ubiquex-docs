---
title: "azure_databricks_openapi_access_connector"
description: "`data_azure_databricks_openapi_access_connector` looks up a real, already-existing `azure_databricks_openapi_access_connector`."
---

It is a managed identity resource letting an Azure Databricks workspace securely access other Azure resource(s) (e.g. a storage account) using Azure AD authentication, without embedding credentials.

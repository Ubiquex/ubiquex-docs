---
title: "azure_storage_openapi_blob_inventory_policy"
description: "`data_azure_storage_openapi_blob_inventory_policy` looks up a real, already-existing `azure_storage_openapi_blob_inventory_policy`."
---

It schedules Azure Storage to generate a periodic inventory report listing every blob and its own metadata across a storage account.

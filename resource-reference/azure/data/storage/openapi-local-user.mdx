---
title: "azure_storage_openapi_local_user"
description: "`data_azure_storage_openapi_local_user` looks up a real, already-existing `azure_storage_openapi_local_user`."
---

It defines a local (non-Entra ID) identity for a storage account, authenticated by SSH key or password, used for SFTP or NFS access.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	storage "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/storage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_storage_openapi_local_user"})

    		ubx.Data(storage.OpenapiLocalUser, "example", storage.OpenapiLocalUserConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>

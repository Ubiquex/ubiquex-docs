---
title: "azure_storage_openapi_advanced_platform_metrics_rule"
description: "`data_azure_storage_openapi_advanced_platform_metrics_rule` looks up a real, already-existing `azure_storage_openapi_advanced_platform_metrics_rule`."
---

It enables Advanced Platform Metrics on a storage account, extending Azure Monitor's platform metrics with per-container capacity and object count insights for Blob Storage.

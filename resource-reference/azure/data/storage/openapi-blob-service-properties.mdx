`azure_storage_openapi_blob_service_properties` reads the real, account-wide Blob service properties (such as soft delete and versioning) of a storage account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	storage "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/storage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_storage_openapi_blob_service_properties"})

    		ubx.Data(storage.OpenapiBlobServiceProperties, "example", storage.OpenapiBlobServicePropertiesConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>

---
title: "azure_storage_openapi_connector"
description: "`data_azure_storage_openapi_connector` looks up a real, already-existing `azure_storage_openapi_connector`."
---

It links a storage account to another Azure resource (e.g. a Purview account) for integrated data governance or discovery.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	storage "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/storage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_storage_openapi_connector"})

    		ubx.Data(storage.OpenapiConnector, "example", storage.OpenapiConnectorConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { OpenapiConnector } from "@ubx/sdk-azure/azure/data/storage/openapi_connector";

    export default stack("example", () => {
      intent({ summary: "look up azure_storage_openapi_connector" });

      data(OpenapiConnector, "example", {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.storage import OpenapiConnector, OpenapiConnectorConfig

    def describe():
        ubx.intent("look up azure_storage_openapi_connector")

        ubx.data(OpenapiConnector, "example", OpenapiConnectorConfig(
            account_name="example-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

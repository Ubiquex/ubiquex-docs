## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="migration_name" type="string" required>
  The real name of the migration this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="properties" type="object">
  The properties of a storage account's ongoing or enqueued migration. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="migration_failed_detailed_reason" type="string">
      Reason for migration failure Returned by the lookup.
    </ResponseField>
    <ResponseField name="migration_failed_reason" type="string">
      Error code for migration failure Returned by the lookup.
    </ResponseField>
    <ResponseField name="migration_status" type="string">
      Current status of migration Optional lookup argument.
    </ResponseField>
    <ResponseField name="target_sku_name" type="string" required>
      The SKU name. Required for account creation; optional for update. Note that in older versions, SKU name was called accountType. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

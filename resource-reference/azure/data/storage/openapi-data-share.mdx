---
title: "azure_storage_openapi_data_share"
description: "`data_azure_storage_openapi_data_share` looks up a real, already-existing `azure_storage_openapi_data_share`."
---

It configures Data Share integration for a storage account, enabling secure sharing of its own data with external consumers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	storage "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/storage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_storage_openapi_data_share"})

    		ubx.Data(storage.OpenapiDataShare, "example", storage.OpenapiDataShareConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

    from ubx.azure.data.storage import OpenapiDataShare, OpenapiDataShareConfig

        ubx.intent("look up azure_storage_openapi_data_share")

        ubx.data(OpenapiDataShare, "example", OpenapiDataShareConfig(

        ))

    if __name__ == "__main__":

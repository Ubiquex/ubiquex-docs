---
title: "azure_mongocluster_private_endpoint_connection_resource"

---

It represents the connection between a Private Endpoint and a MongoDB vCore cluster, tracking its own approval state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mongocluster "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/mongocluster"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_mongocluster_private_endpoint_connection_resource"})

    		ubx.Data(mongocluster.PrivateEndpointConnectionResource, "example", mongocluster.PrivateEndpointConnectionResourceConfig{
    			MongoClusterName: "example-mongo-cluster-name",
    		})
    	}))
    }
    ```

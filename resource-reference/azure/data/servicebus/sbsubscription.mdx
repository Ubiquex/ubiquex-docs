---
title: "azure_servicebus_sbsubscription"
description: "`data_azure_servicebus_sbsubscription` looks up a real, already-existing `azure_servicebus_sbsubscription`."
---

It is a named, independent view of a Service Bus topic's own published messages, letting multiple subscription(s) each receive a copy of matching message(s) via the publish/subscribe pattern.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicebus_sbsubscription"})

    		ubx.Data(servicebus.Sbsubscription, "example", servicebus.SbsubscriptionConfig{
    			NamespaceName: "example-namespace-name",
    			TopicName:     "example-topic-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="namespace_name" type="string" required>
  The real name of the namespace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="topic_name" type="string" required>
  The real name of the Event Grid topic this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

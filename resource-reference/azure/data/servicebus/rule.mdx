`azure_servicebus_rule` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicebus_rule"})

    		ubx.Data(servicebus.Rule, "example", servicebus.RuleConfig{
    			NamespaceName:    "example-namespace-name",
    			SubscriptionName: "example-subscription-name",
    			TopicName:        "example-topic-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

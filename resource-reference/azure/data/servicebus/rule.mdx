---
title: "azure_servicebus_rule"
description: "`data_azure_servicebus_rule` looks up a real, already-existing `azure_servicebus_rule`."
---

It defines a filter and optional action applied to a Service Bus topic subscription, determining which published message(s) that subscription actually receives.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicebus_rule"})

    		ubx.Data(servicebus.Rule, "example", servicebus.RuleConfig{
    			NamespaceName:    "example-namespace-name",
    			SubscriptionName: "example-subscription-name",
    			TopicName:        "example-topic-name",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="namespace_name" type="string" required>
  The real name of the namespace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_name" type="string" required>
  The real name of the subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="topic_name" type="string" required>
  The real name of the Event Grid topic this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

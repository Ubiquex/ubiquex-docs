---
title: "azure_servicebus_sbqueue"
description: "`data_azure_servicebus_sbqueue` looks up a real, already-existing `azure_servicebus_sbqueue`."
---

It is a Service Bus queue, providing reliable, ordered, first-in-first-out message delivery to a single consumer per message.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicebus_sbqueue"})

    		ubx.Data(servicebus.Sbqueue, "example", servicebus.SbqueueConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.servicebus import Sbqueue, SbqueueConfig

    def describe():
        ubx.intent("look up azure_servicebus_sbqueue")

        ubx.data(Sbqueue, "example", SbqueueConfig(
            namespace_name="example-namespace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

---
title: "azure_servicebus_sbauthorization_rule"
description: "`data_azure_servicebus_sbauthorization_rule` looks up a real, already-existing `azure_servicebus_sbauthorization_rule`."
---

It defines a shared access policy (with specific permissions) for connecting to a Service Bus namespace, queue, or topic.

## Example

    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicebus_sbauthorization_rule"})

    		ubx.Data(servicebus.SbauthorizationRule, "example", servicebus.SbauthorizationRuleConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }

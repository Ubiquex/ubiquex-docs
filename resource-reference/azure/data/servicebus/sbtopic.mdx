---
title: "azure_servicebus_sbtopic"
description: "`data_azure_servicebus_sbtopic` looks up a real, already-existing `azure_servicebus_sbtopic`."
---

It is a Service Bus topic, publishing message(s) to every subscription attached to it, for one-to-many publish/subscribe messaging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	servicebus "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/servicebus"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_servicebus_sbtopic"})

    		ubx.Data(servicebus.Sbtopic, "example", servicebus.SbtopicConfig{
    			NamespaceName: "example-namespace-name",
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.azure.data.servicebus import Sbtopic, SbtopicConfig

    def describe():
        ubx.intent("look up azure_servicebus_sbtopic")

        ubx.data(Sbtopic, "example", SbtopicConfig(
            namespace_name="example-namespace-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

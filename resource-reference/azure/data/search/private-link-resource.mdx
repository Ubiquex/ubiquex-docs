`azure_search_private_link_resource` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	search "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/search"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_search_private_link_resource"})

    		ubx.Data(search.PrivateLinkResource, "example", search.PrivateLinkResourceConfig{
    			SearchServiceName: "example-search-service-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	search "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/search"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_search_private_link_resource"})

    		ubx.Data(search.PrivateLinkResource, "example", search.PrivateLinkResourceConfig{
    			SearchServiceName: "example-search-service-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only azure --lang ts --out ./local-sdk
    import { PrivateLinkResource } from "./local-sdk/azure/sdk/typescript/azure/data/search/private_link_resource.ts";

    export default stack("example", () => {
      intent({ summary: "look up azure_search_private_link_resource" });

      data(PrivateLinkResource, "example", {
        searchServiceName: "example-search-service-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only azure --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/azure/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.azure.data.search import PrivateLinkResource, PrivateLinkResourceConfig

    def describe():
        ubx.intent("look up azure_search_private_link_resource")

        ubx.data(PrivateLinkResource, "example", PrivateLinkResourceConfig(
            search_service_name="example-search-service-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="search_service_name" type="string" required>
  The real name of the Azure AI Search service this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL to get the next set of private link resources, if there are any. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of supported Private Link Resources. Returned by the lookup.
</ResponseField>

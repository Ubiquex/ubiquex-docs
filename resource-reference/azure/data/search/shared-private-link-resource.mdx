---
title: "azure_search_shared_private_link_resource"
description: "`data_azure_search_shared_private_link_resource` looks up a real, already-existing `azure_search_shared_private_link_resource`."
---

It creates a Private Endpoint from an Azure AI Search service to another Private Link-enabled Azure service, so its own indexer(s) can reach data sources privately.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	search "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/search"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_search_shared_private_link_resource"})

    		ubx.Data(search.SharedPrivateLinkResource, "example", search.SharedPrivateLinkResourceConfig{
    			SearchServiceName: "example-search-service-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SharedPrivateLinkResource } from "@ubx/sdk-azure/azure/data/search/shared_private_link_resource";

    export default stack("example", () => {
      intent({ summary: "look up azure_search_shared_private_link_resource" });

      data(SharedPrivateLinkResource, "example", {
        searchServiceName: "example-search-service-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.search import SharedPrivateLinkResource, SharedPrivateLinkResourceConfig

    def describe():
        ubx.intent("look up azure_search_shared_private_link_resource")

        ubx.data(SharedPrivateLinkResource, "example", SharedPrivateLinkResourceConfig(
            search_service_name="example-search-service-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="search_service_name" type="string" required>
  The real name of the Azure AI Search service this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL to get the next set of shared private link resources, if there are any. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of shared private link resources. Returned by the lookup.
</ResponseField>

---
title: "azure_search_private_endpoint_connection"
description: "`data_azure_search_private_endpoint_connection` looks up a real, already-existing `azure_search_private_endpoint_connection`."
---

It represents the connection between a Private Endpoint and an Azure AI Search service, tracking its own approval state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	search "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/search"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_search_private_endpoint_connection"})

    		ubx.Data(search.PrivateEndpointConnection, "example", search.PrivateEndpointConnectionConfig{
    			SearchServiceName: "example-search-service-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { PrivateEndpointConnection } from "@ubx/sdk-azure/azure/data/search/private_endpoint_connection";

    export default stack("example", () => {
      intent({ summary: "look up azure_search_private_endpoint_connection" });

      data(PrivateEndpointConnection, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.search import PrivateEndpointConnection, PrivateEndpointConnectionConfig

    def describe():
        ubx.intent("look up azure_search_private_endpoint_connection")

        ubx.data(PrivateEndpointConnection, "example", PrivateEndpointConnectionConfig(
            search_service_name="example-search-service-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="search_service_name" type="string" required>
  The real name of the Azure AI Search service this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  Request URL that can be used to query next page of private endpoint connections. Returned when the total number of requested private endpoint connections exceed maximum page size. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of private endpoint connections. Returned by the lookup.
</ResponseField>

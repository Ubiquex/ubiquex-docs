---
title: "azure_management_subscription_under_management_group"
description: "`data_azure_management_subscription_under_management_group` looks up a real, already-existing `azure_management_subscription_under_management_group`."
---

It places a subscription under a specific management group, inheriting its own policy and access control.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	management "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/management"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_management_subscription_under_management_group"})

    		ubx.Data(management.SubscriptionUnderManagementGroup, "example", management.SubscriptionUnderManagementGroupConfig{
    			GroupId: "example",
    		})
    	}))
    }
    ```

`azure_management_hierarchy_settings` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="properties" type="object">
  The generic properties of hierarchy settings. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="default_management_group" type="string">
      Settings that sets the default Management Group under which new subscriptions get added in this tenant. For example, /providers/Microsoft.Management/managementGroups/defaultGroup Optional lookup argument.
    </ResponseField>
    <ResponseField name="require_authorization_for_group_creation" type="bool">
      Indicates whether RBAC access is required upon group creation under the root Management Group. If set to true, user will require Microsoft.Management/managementGroups/write action on the root Management Group scope in order to create new Groups directly under the root. This will prevent new users from creating new Management Groups, unless they are given access. Optional lookup argument.
    </ResponseField>
    <ResponseField name="tenant_id" type="string">
      The AAD Tenant ID associated with the hierarchy settings. For example, 00000000-0000-0000-0000-000000000000 Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

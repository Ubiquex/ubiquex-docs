---
title: "azure_maps_management_creator"
description: "`data_azure_maps_management_creator` looks up a real, already-existing `azure_maps_management_creator`."
---

It provisions Azure Maps Creator, letting custom indoor map data be uploaded and converted into a usable indoor mapping dataset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	maps "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/maps"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_maps_management_creator"})

    		ubx.Data(maps.ManagementCreator, "example", maps.ManagementCreatorConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

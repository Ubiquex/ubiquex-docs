## Lookup arguments

<ResponseField name="bot_right" type="list(number)">
  The real level of bot access rights this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="heat_map_type" type="string" required>
  The real type of geographic heat map (latency or endpoint) to compute for a Traffic Manager profile. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="profile_name" type="string" required>
  The real name of the profile this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="top_left" type="list(number)">
  The real top-left coordinate of the region this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

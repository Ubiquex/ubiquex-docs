---
title: "azure_netapp_backup_vault"
description: "`data_azure_netapp_backup_vault` looks up a real, already-existing `azure_netapp_backup_vault`."
---

It is the storage container Azure NetApp Files backups are written into and organized under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_backup_vault"})

    		ubx.Data(netapp.BackupVault, "example", netapp.BackupVaultConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { BackupVault } from "@ubx/sdk-azure/azure/data/netapp/backup_vault";

    export default stack("example", () => {
      intent({ summary: "look up azure_netapp_backup_vault" });

      data(BackupVault, "example", {
        accountName: "example-account-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.data.netapp import BackupVault, BackupVaultConfig

    def describe():
        ubx.intent("look up azure_netapp_backup_vault")

        ubx.data(BackupVault, "example", BackupVaultConfig(
            account_name="example-account-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

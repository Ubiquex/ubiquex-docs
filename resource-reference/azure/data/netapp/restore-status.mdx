## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_restore_status"})

    		ubx.Data(netapp.RestoreStatus, "example", netapp.RestoreStatusConfig{
    			AccountName: "example-account-name",
    			PoolName:    "example-pool-name",
    			VolumeName:  "example-volume-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="pool_name" type="string" required>
  The real name of the pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="volume_name" type="string" required>
  The real name of the Azure NetApp Files volume this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

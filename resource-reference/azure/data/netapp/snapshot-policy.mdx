---
title: "azure_netapp_snapshot_policy"
description: "`data_azure_netapp_snapshot_policy` looks up a real, already-existing `azure_netapp_snapshot_policy`."
---

It defines the automated snapshot schedule (hourly, daily, weekly, monthly, with its own retention) applied to Azure NetApp Files volume(s) it's attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_snapshot_policy"})

    		ubx.Data(netapp.SnapshotPolicy, "example", netapp.SnapshotPolicyConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>

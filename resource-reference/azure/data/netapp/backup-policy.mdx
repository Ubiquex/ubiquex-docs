---
title: "azure_netapp_backup_policy"
description: "`data_azure_netapp_backup_policy` looks up a real, already-existing `azure_netapp_backup_policy`."
---

It defines the automated backup schedule (frequency, retention) applied to Azure NetApp Files volume(s) it's attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_backup_policy"})

    		ubx.Data(netapp.BackupPolicy, "example", netapp.BackupPolicyConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```

`azure_netapp_backup` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_backup"})

    		ubx.Data(netapp.Backup, "example", netapp.BackupConfig{
    			AccountName:     "example-account-name",
    			BackupVaultName: "example-backup-vault-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    from ubx.azure.data.netapp import Backup, BackupConfig

    def describe():

            account_name="example-account-name",

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

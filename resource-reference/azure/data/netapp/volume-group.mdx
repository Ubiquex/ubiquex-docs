`azure_netapp_volume_group` looks up a real Azure NetApp Files volume group -- a set of volumes provisioned and managed together, most commonly for a SAP HANA deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_volume_group"})

    		ubx.Data(netapp.VolumeGroup, "example", netapp.VolumeGroupConfig{
    			AccountName: "example-account-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx

    def describe():

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

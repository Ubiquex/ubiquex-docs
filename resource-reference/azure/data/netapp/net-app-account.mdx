---
title: "azure_netapp_net_app_account"
description: "`data_azure_netapp_net_app_account` looks up a real, already-existing `azure_netapp_net_app_account`."

It is the top-level Azure NetApp Files resource that capacity pool(s) and their own volume(s) are organized within.

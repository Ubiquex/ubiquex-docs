---
title: "azure_netapp_snapshot"
description: "`data_azure_netapp_snapshot` looks up a real, already-existing `azure_netapp_snapshot`."
---

It is a point-in-time, storage-efficient snapshot of an Azure NetApp Files volume, restorable in place or usable as the source for a new volume clone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_snapshot"})

    		ubx.Data(netapp.Snapshot, "example", netapp.SnapshotConfig{
    			AccountName: "example-account-name",
    			PoolName:    "example-pool-name",
    			VolumeName:  "example-volume-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="account_name" type="string" required>
  The real name of the account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="pool_name" type="string" required>
  The real name of the pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="volume_name" type="string" required>
  The real name of the Azure NetApp Files volume this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "azure_netapp_cache"
description: "`data_azure_netapp_cache` looks up a real, already-existing `azure_netapp_cache`."
---

It accelerates access to a remote data source by caching its own content on Azure NetApp Files storage close to compute.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_netapp_cache"})

    		ubx.Data(netapp.Cache, "example", netapp.CacheConfig{
    			AccountName: "example-account-name",
    			PoolName:    "example-pool-name",
    		})
    	}))
    }
    ```

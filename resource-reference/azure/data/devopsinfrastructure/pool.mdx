---
title: "azure_devopsinfrastructure_pool"
description: "`data_azure_devopsinfrastructure_pool` looks up a real, already-existing `azure_devopsinfrastructure_pool`."
---

It provisions Managed DevOps Pools, ephemeral, autoscaling Azure-hosted compute for Azure DevOps or GitHub Actions pipeline agents.

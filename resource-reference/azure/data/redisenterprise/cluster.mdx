---
title: "azure_redisenterprise_cluster"
description: "`data_azure_redisenterprise_cluster` looks up a real, already-existing `azure_redisenterprise_cluster`."
---

It is an Azure Managed Redis (Enterprise) cluster, a Redis Enterprise deployment offering active-active geo-replication and modules unavailable on standard Memorystore-style tiers.

---
title: "azure_redisenterprise_access_policy_assignment"
description: "`data_azure_redisenterprise_access_policy_assignment` looks up a real, already-existing `azure_redisenterprise_access_policy_assignment`."

It grants a Microsoft Entra ID identity data-plane access to an Azure Managed Redis (Enterprise) database via a named access policy.

---
title: "azure_redisenterprise_database"
description: "`data_azure_redisenterprise_database` looks up a real, already-existing `azure_redisenterprise_database`."
---

It is a database within an Azure Managed Redis (Enterprise) cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redisenterprise "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/redisenterprise"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_redisenterprise_database"})

    		ubx.Data(redisenterprise.Database, "example", redisenterprise.DatabaseConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

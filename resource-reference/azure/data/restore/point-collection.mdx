---
title: "azure_restore_point_collection"
description: "`data_azure_restore_point_collection` looks up a real, already-existing `azure_restore_point_collection`."
---

It is the real Azure Resource Manager resource a VM's own restore points live inside -- scoped to exactly one VM, it's what you create first before any individual restore point can exist.

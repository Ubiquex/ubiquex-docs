---
title: "azure_iothub_certificate_description"
description: "`data_azure_iothub_certificate_description` looks up a real, already-existing `azure_iothub_certificate_description`."
---

It uploads a CA certificate to an IoT Hub, used to establish trust when verifying connecting device certificates.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iothub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/iothub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_iothub_certificate_description"})

    		ubx.Data(iothub.CertificateDescription, "example", iothub.CertificateDescriptionConfig{
    			ApiVersion:        "example",
    			ResourceGroupName: "example-resource-group-name",
    			ResourceName:      "example-resource-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```
  </Tab>

</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

`azure_iothub_job_response` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go

    import (
    	iothub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/iothub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_iothub_job_response"})

    		ubx.Data(iothub.JobResponse, "example", iothub.JobResponseConfig{
    			ApiVersion:        "example",
    			ResourceGroupName: "example-resource-group-name",
    			ResourceName:      "example-resource-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```

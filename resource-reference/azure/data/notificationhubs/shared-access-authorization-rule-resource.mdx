`data_azure_notificationhubs_shared_access_authorization_rule_resource` looks up a real, already-existing `azure_notificationhubs_shared_access_authorization_rule_resource`. It defines a shared access policy (with specific permissions) for connecting to a Notification Hubs namespace or hub.

## Lookup arguments

<ResponseField name="resource_name" type="string" required>
  The real name of the resource this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="upgrade_graph" type="string" required>
  The real, available upgrade path graph for this resource. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="string">
  The appliance resource path Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The release train name. Returned by the lookup.
</ResponseField>

<ResponseField name="properties" type="object">
  The Upgrade Graph Properties for appliance. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="appliance_version" type="string">
      The current appliance version Returned by the lookup.
    </ResponseField>
    <ResponseField name="supported_versions" type="list(object)">
      This contains the current version and supported upgrade versions. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "azure_msi_managedidentity_identity"
description: "`data_azure_msi_managedidentity_identity` looks up a real, already-existing `azure_msi_managedidentity_identity`."
---

It is a user-assigned managed identity, an Azure AD identity that can be assigned to one or more resource(s) for passwordless authentication to other Azure services.

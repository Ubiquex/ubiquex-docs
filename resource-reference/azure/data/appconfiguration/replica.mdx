`azure_appconfiguration_replica` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Microsoft Azure's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go

    import (
    	appconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/appconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_appconfiguration_replica"})

    		ubx.Data(appconfiguration.Replica, "example", appconfiguration.ReplicaConfig{
    			ApiVersion:        "example",
    			ConfigStoreName:   "example-config-store-name",
    			ResourceGroupName: "example-resource-group-name",
    			SubscriptionId:    "example",
    		})
    	}))
    }
    ```

`azure_appconfiguration_deleted_configuration_store` looks up a real, recently deleted App Configuration store that's still within its own soft-delete retention window.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/appconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_appconfiguration_deleted_configuration_store"})

    		ubx.Data(appconfiguration.DeletedConfigurationStore, "example", appconfiguration.DeletedConfigurationStoreConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The URL to get the next set of deleted configuration stores. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of deleted configuration store. Returned by the lookup.
</ResponseField>

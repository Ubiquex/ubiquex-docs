---
title: "azure_domainservices_domain_service"
description: "`data_azure_domainservices_domain_service` looks up a real, already-existing `azure_domainservices_domain_service`."
---

It provisions Microsoft Entra Domain Services, a fully managed Active Directory-compatible domain without the caller having to run domain controllers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	domainservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/domainservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_domainservices_domain_service"})

    		ubx.Data(domainservices.DomainService, "example", domainservices.DomainServiceConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    import ubx_sdk as ubx
    from ubx.azure.data.domainservices import DomainService, DomainServiceConfig

    def describe():
        ubx.intent("look up azure_domainservices_domain_service")

        ubx.data(DomainService, "example", DomainServiceConfig(
            api_version="example",
            subscription_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The continuation token for the next page of results. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  the list of domain services. Returned by the lookup.
</ResponseField>

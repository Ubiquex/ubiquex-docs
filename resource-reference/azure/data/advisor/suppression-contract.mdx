---
title: "azure_advisor_suppression_contract"
description: "`data_azure_advisor_suppression_contract` looks up a real, already-existing `azure_advisor_suppression_contract`."
---

It suppresses a specific Azure Advisor recommendation for a resource, either permanently or for a defined time window.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	advisor "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/data/advisor"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up azure_advisor_suppression_contract"})

    		ubx.Data(advisor.SuppressionContract, "example", advisor.SuppressionContractConfig{
    			ApiVersion:     "example",
    			SubscriptionId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="api_version" type="string" required>
  The real Azure REST API version this request targets. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subscription_id" type="string" required>
  The real, unique identifier of the Azure subscription this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_link" type="string">
  The link used to get the next page of suppressions. Returned by the lookup.
</ResponseField>

<ResponseField name="value" type="list(object)">
  The list of suppressions. Returned by the lookup.
</ResponseField>

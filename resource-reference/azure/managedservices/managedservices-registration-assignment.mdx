`azure_managedservices_registration_assignment` delegates management of a specific resource group or subscription to a managing tenant, per an Azure Lighthouse registration definition.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	managedservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/managedservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own managedservices registration assignment"})

    		ubx.Resource(managedservices.RegistrationAssignment, "example", managedservices.RegistrationAssignmentConfig{
    			Scope: "example",
    			Name:  "example",
    		})
    	}))
    }
    ```
  </Tab>

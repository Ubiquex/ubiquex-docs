`azure_resources_generic_resource` is the generic Azure Resource Manager representation of any resource, used when working across resource types that don't have a more specific typed model.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_resources_resources --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_resources_resources/sdk/go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_resources_resources/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resources generic resource"})

    		ubx.Resource(resources.ResourcesGenericResource, "example", resources.ResourcesGenericResourceConfig{})
    	}))
    }
    ```

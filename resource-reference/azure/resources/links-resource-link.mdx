`azure_resources_links_resource_link` creates an explicit, trackable relationship between two Azure resources that isn't otherwise expressed by a direct reference.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resources "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/resources"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own links resource link"})

    		ubx.Resource(resources.LinksResourceLink, "example", resources.LinksResourceLinkConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="id" type="string">
  The fully qualified ID of the resource link. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the resource link. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  The resource link properties. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="notes" type="string">
      Notes about the resource link. Optional.
    </ResponseField>
    <ResponseField name="source_id" type="string">
      The fully qualified ID of the source resource in the link. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="target_id" type="string" required>
      The fully qualified ID of the target resource in the link. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="any">
  The resource link object. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

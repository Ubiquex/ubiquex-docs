`azure_virtual_machine_extension` installs a small, publisher-provided application onto a running VM after deployment -- monitoring agents, security tooling, and custom scripts are all shipped this way. Extensions are managed entirely through the Azure platform, never by logging into the VM directly, and their own lifecycle (install, upgrade, remove) is tracked outside the guest OS.

`azure_restore_point` is a point-in-time capture of every disk attached to one VM -- the OS disk and each data disk gets its own disk restore point inside it. The first restore point is a full copy; every one after that captures only the changes since the previous one, and individual disks can be excluded to control storage cost. Restoring a VM means restoring each disk from its own disk restore point, then reassembling them.

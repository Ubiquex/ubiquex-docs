`azure_oracle_openapi_autonomous_database_backup` is a point-in-time backup of an Oracle Autonomous Database instance provisioned through Oracle Database@Azure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	oracle "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/oracle"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi autonomous database backup"})

    		ubx.Resource(oracle.OpenapiAutonomousDatabaseBackup, "example", oracle.OpenapiAutonomousDatabaseBackupConfig{
    			Adbbackupid:            "example",
    			Autonomousdatabasename: "example",
    		})
    	}))
    }
    ```
  </Tab>

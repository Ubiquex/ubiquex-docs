`azure_oracle_openapi_autonomous_database` provisions a self-managing Oracle Autonomous Database instance through Oracle Database@Azure, running on Oracle Cloud Infrastructure but integrated into an Azure subscription.

## Example

    	oracle "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_oracle_openapi/oracle"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

`azure_securityinsights_openapi_threat_intelligence_information` is a single threat intelligence indicator (an IP, domain, or hash) ingested into Microsoft Sentinel, used to enrich and match against incoming log data.

## Example

    ```go
    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/securityinsights"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi threat intelligence information"})

    		ubx.Resource(securityinsights.OpenapiThreatIntelligenceInformation, "example", securityinsights.OpenapiThreatIntelligenceInformationConfig{
    			Name:       "example",
    			Properties: map[string]any{"confidence": 1},
    		})
    	}))
    }
    ```

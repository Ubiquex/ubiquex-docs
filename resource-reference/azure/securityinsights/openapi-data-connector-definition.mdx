`azure_securityinsights_openapi_data_connector_definition` defines the connection UI and configuration schema for a Microsoft Sentinel data connector, used when publishing a connector as reusable content.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_securityinsights_openapi --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_securityinsights_openapi/sdk/go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_securityinsights_openapi/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own openapi data connector definition"})

    		ubx.Resource(securityinsights.OpenapiDataConnectorDefinition, "ci-runner", securityinsights.OpenapiDataConnectorDefinitionConfig{
    			Kind: "example",
    		})
    	}))
    }
    ```

`azure_securityinsights_openapi_source_control` links a Microsoft Sentinel workspace to an external Git repository, syncing analytics rule and other content definitions from source control.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/securityinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi source control"})

    		ubx.Resource(securityinsights.OpenapiSourceControl, "example", securityinsights.OpenapiSourceControlConfig{
    			Properties: map[string]any{"content_types": []string{"example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

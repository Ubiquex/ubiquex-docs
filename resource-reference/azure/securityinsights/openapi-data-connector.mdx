`azure_securityinsights_openapi_data_connector` ingests log or event data from a specific source (an Azure service, a third-party product, or a custom feed) into Microsoft Sentinel.

## Example

<Tabs>

    ```go
    package main

    import (
    	securityinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/securityinsights"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi data connector"})

    		ubx.Resource(securityinsights.OpenapiDataConnector, "example", securityinsights.OpenapiDataConnectorConfig{
    			Kind: "example",
    		})
    	}))
    }
    ```

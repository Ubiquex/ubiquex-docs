`azure_datafactory_openapi_data_flow_resource` defines a visually designed Mapping Data Flow, a Spark-executed data transformation graph within a Data Factory pipeline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi data flow resource"})

    		ubx.Resource(datafactory.OpenapiDataFlowResource, "example", datafactory.OpenapiDataFlowResourceConfig{
    			Properties: map[string]any{"type": "example"},
    		})
    	}))
    }
    ```
  </Tab>

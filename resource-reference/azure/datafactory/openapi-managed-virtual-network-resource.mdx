`azure_datafactory_openapi_managed_virtual_network_resource` provisions a Data Factory-managed virtual network, isolating its own managed integration runtime compute for private connectivity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datafactory "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/datafactory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi managed virtual network resource"})

    		ubx.Resource(datafactory.OpenapiManagedVirtualNetworkResource, "example", datafactory.OpenapiManagedVirtualNetworkResourceConfig{
    			Properties: map[string]any{"alias": "example"},
    		})
    	}))
    }
    ```

`azure_redisenterprise_cluster` is an Azure Managed Redis (Enterprise) cluster, a Redis Enterprise deployment offering active-active geo-replication and modules unavailable on standard Memorystore-style tiers.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

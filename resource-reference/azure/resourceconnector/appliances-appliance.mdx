`azure_resourceconnector_appliances_appliance` is an Azure Arc resource bridge, a prepackaged on-premises virtual appliance that projects a private cloud platform's own resources (Azure Local, VMware, or System Center Virtual Machine Manager) into Azure for unified, Arc-based management.

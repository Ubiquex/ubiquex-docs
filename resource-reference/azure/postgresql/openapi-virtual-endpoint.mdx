`azure_postgresql_openapi_virtual_endpoint` is a stable read-write or read-only DNS endpoint pointing at the current primary (or a standby) in an Azure Database for PostgreSQL flexible server's own high-availability pair, surviving a failover without a client reconnect to a new hostname.

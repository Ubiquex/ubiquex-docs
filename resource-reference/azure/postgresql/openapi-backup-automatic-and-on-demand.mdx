`azure_postgresql_openapi_backup_automatic_and_on_demand` triggers an on-demand backup of an Azure Database for PostgreSQL flexible server, alongside the server's own automatic backup schedule.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    	}))

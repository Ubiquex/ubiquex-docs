`azure_devcenter_catalog` links a Git repository of Environment Definitions or image templates to a dev center, making its own reusable infrastructure templates available for self-service provisioning.

## Example

<Tabs>
  <Tab title="Go">
    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_devcenter/sdk/go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_devcenter/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own devcenter catalog"})

    		ubx.Resource(devcenter.DevcenterCatalog, "example", devcenter.DevcenterCatalogConfig{})
    	}))
    }
    ```

    <ResponseField name="last_connection_time" type="string">

    </ResponseField>
    <ResponseField name="last_sync_stats" type="object">
      Stats of the synchronization. Optional.

        </ResponseField>
        <ResponseField name="removed" type="number">
          Count of catalog items removed during synchronization. Computed by Microsoft Azure after `ship`.
        </ResponseField>
        <ResponseField name="synced_catalog_item_types" type="list(string)">

        </ResponseField>

        </ResponseField>
        <ResponseField name="updated" type="number">
          Count of catalog items updated during synchronization. Computed by Microsoft Azure after `ship`.

        <ResponseField name="validation_errors" type="number">
          Count of catalog items that had validation errors during synchronization. Computed by Microsoft Azure after `ship`.

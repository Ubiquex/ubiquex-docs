`azure_devcenter_devcenter_project_policy` restricts which user(s) or group(s) can access resources across multiple Dev Box projects collectively, via a centrally defined policy.

## Example

    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_devcenter_devcenter/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    	}))

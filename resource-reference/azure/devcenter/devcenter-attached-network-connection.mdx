`azure_devcenter_attached_network_connection` attaches a Microsoft Dev Box network connection to a dev center, making it available for dev box definitions across the dev center's own project(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	devcenter "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/devcenter"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own devcenter attached network connection"})

    		ubx.Resource(devcenter.AttachedNetworkConnection, "example", devcenter.AttachedNetworkConnectionConfig{})
    	}))
    }
    ```

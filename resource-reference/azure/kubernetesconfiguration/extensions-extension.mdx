`azure_kubernetesconfiguration_extensions_extension` installs a Kubernetes cluster extension (via the Azure Arc/AKS Cluster Extensions framework) onto a connected cluster.

## Example

<Tabs>
  <Tab title="Go">

    package main

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own extensions extension"})

`azure_eventhub_openapi_arm_disaster_recovery` pairs an Event Hubs namespace with a secondary namespace in another region for geo-disaster recovery, replicating metadata (not event data) between them.

<ResponseField name="alias" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="location" type="string">
  The geo-location where the resource lives Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties required to the Create Or Update Alias(Disaster Recovery configurations) Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="alternate_name" type="string">
      Alternate name specified when alias and namespace names are same. Optional.
    </ResponseField>
    <ResponseField name="partner_namespace" type="string">
      ARM Id of the Primary/Secondary eventhub namespace name, which is part of GEO DR pairing Optional.
    </ResponseField>
    <ResponseField name="pending_replication_operations_count" type="number">
      Number of entities pending to be replicated. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Provisioning state of the Alias(Disaster Recovery configuration) - possible values 'Accepted' or 'Succeeded' or 'Failed' Optional.
    </ResponseField>
    <ResponseField name="role" type="string">
      role of namespace in GEO DR - possible values 'Primary' or 'PrimaryNotReplicating' or 'Secondary' Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

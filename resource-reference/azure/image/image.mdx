`azure_image` defines a reusable, versioned VM image inside an Azure Compute Gallery, built from an existing VM, a VHD, a snapshot, a managed image, or another image version. An image definition describes what the image is (Windows or Linux, generalized or specialized, memory requirements); an image version is the actual buildable artifact you point a new VM at, and you can keep several versions of the same definition side by side, replicated to whichever regions you choose.

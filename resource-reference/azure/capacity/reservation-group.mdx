`azure_capacity_reservation_group` is the parent resource every individual capacity reservation belongs to. It pins the region (and, optionally, which availability zones are eligible) for every reservation created inside it, and it's what a VM's own properties reference to actually consume a reservation -- a group can hold at most one reservation per VM size per zone.

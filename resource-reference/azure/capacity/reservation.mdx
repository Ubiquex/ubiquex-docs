---
title: "azure_capacity_reservation"
description: "`azure_capacity_reservation` reserves compute capacity for one specific VM size in one region or zone, for as long as you keep it."
---

Unlike a Reserved Instance, there's no one- or three-year term: you create and delete a reservation whenever you want, and it's billed at the same pay-as-you-go rate as the VM size itself whether a VM is actually using it or not. A VM only consumes the reservation if it explicitly specifies it in its own properties.

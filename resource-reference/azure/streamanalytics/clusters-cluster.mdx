`azure_streamanalytics_clusters_cluster` provisions a dedicated Stream Analytics cluster, single-tenant capacity reserved for large-scale streaming job(s) at predictable, reserved throughput.

## Properties

<ResponseField name="etag" type="string">
  The current entity tag for the cluster. This is an opaque string. You can use it to detect whether the resource has changed between requests. You can also use it in the If-Match or If-None-Match headers for write operations for optimistic concurrency. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  The properties associated with a Stream Analytics cluster. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="capacity_allocated" type="number">
      Represents the number of streaming units currently being used on the cluster. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="capacity_assigned" type="number">
      Represents the sum of the SUs of all streaming jobs associated with the cluster. If all of the jobs were running, this would be the capacity allocated. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="cluster_id" type="string">
      Unique identifier for the cluster. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="created_date" type="string">
      The date this cluster was created. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The status of the cluster provisioning. The three terminal states are: Succeeded, Failed and Canceled Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sku" type="object">
  The SKU of the cluster. This determines the size/capacity of the cluster. Required on PUT (CreateOrUpdate) requests. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="capacity" type="number">
      Denotes the number of streaming units the cluster can support. Valid values for this property are multiples of 36 with a minimum value of 36 and maximum value of 216. Required on PUT (CreateOrUpdate) requests. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      Specifies the SKU name of the cluster. Required on PUT (CreateOrUpdate) requests. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

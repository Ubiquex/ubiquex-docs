`azure_help_help_diagnostic_resource` runs an Azure Help + Support automated diagnostic check against a resource, surfacing likely causes and remediation steps for a reported issue.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_help_help --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_help_help/sdk/go
    package main

    import (
    	help "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_help_help/help"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own help diagnostic resource"})

    		ubx.Resource(help.HelpDiagnosticResource, "example", help.HelpDiagnosticResourceConfig{
    			Scope: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

`azure_notificationhubs_notificationhubs_namespace_resource` is a Notification Hubs namespace, the management container that notification hub(s) are created within.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	notificationhubs "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/notificationhubs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own notificationhubs namespace resource"})

    		ubx.Resource(notificationhubs.NamespaceResource, "example", notificationhubs.NamespaceResourceConfig{
    			Sku: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```
  </Tab>

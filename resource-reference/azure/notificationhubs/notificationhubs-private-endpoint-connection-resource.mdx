`azure_notificationhubs_private_endpoint_connection_resource` represents the connection between a Private Endpoint and a Notification Hubs namespace, tracking its own approval state.

## Properties

<ResponseField name="properties" type="object">
  Private Endpoint Connection properties. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="group_ids" type="list(string)">
      List of group ids. For Notification Hubs, it always contains a single "namespace" element. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="private_endpoint" type="object">
      Represents a Private Endpoint that is connected to Notification Hubs namespace using Private Endpoint Connection. Optional.
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          ARM resource ID of the Private Endpoint. This may belong to different subscription and resource group than a Notification Hubs namespace. Computed by Microsoft Azure after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="private_link_service_connection_state" type="object">
      State of the Private Link Service connection. Optional.
      <Expandable title="properties">
        <ResponseField name="actions_required" type="string">
          Human-friendly description of required actions. Computed by Microsoft Azure after `ship`.
        </ResponseField>
        <ResponseField name="description" type="string">
          Human-friendly description. Computed by Microsoft Azure after `ship`.
        </ResponseField>
        <ResponseField name="status" type="string">
          State of Private Link Connection. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      State of Private Endpoint Connection. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

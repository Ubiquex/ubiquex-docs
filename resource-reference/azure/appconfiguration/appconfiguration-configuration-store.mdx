`azure_appconfiguration_configuration_store` is an App Configuration store, the managed service for centrally storing application configuration and feature flag(s) separately from application code.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/appconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own configuration store"})

    		ubx.Resource(appconfiguration.ConfigurationStore, "example", appconfiguration.ConfigurationStoreConfig{
    			Sku: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    ```

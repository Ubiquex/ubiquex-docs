`azure_appconfiguration_replica` deploys an additional regional replica of an App Configuration store, for lower-latency access and regional resiliency.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_appconfiguration --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_appconfiguration/sdk/go
    package main

    import (
    	appconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_appconfiguration/appconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appconfiguration replica"})

    		ubx.Resource(appconfiguration.AppconfigurationReplica, "example", appconfiguration.AppconfigurationReplicaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

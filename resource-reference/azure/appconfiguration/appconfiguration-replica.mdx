`azure_appconfiguration_appconfiguration_replica` deploys an additional regional replica of an App Configuration store, for lower-latency access and regional resiliency.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/appconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appconfiguration replica"})

    		ubx.Resource(appconfiguration.Replica, "example", appconfiguration.ReplicaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

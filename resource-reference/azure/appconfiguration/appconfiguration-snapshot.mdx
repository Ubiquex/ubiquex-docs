`azure_appconfiguration_snapshot` captures an immutable, point-in-time set of key/value setting(s) from an App Configuration store, usable to guarantee a consistent configuration read even as the live store keeps changing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appconfiguration "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/appconfiguration"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own appconfiguration snapshot"})

    		ubx.Resource(appconfiguration.Snapshot, "example", appconfiguration.SnapshotConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="id" type="string">
  The resource ID. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the snapshot. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  All snapshot properties. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="composition_type" type="string">
      The composition type describes how the key-values within the snapshot are composed. The 'key' composition type ensures there are no two key-values containing the same key. The 'key_label' composition type ensures there are no two key-values containing the same key and label. Optional.
    </ResponseField>
    <ResponseField name="created" type="string">
      The time that the snapshot was created. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="etag" type="string">
      A value representing the current state of the snapshot. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="expires" type="string">
      The time that the snapshot will expire. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="filters" type="list(object)" required>
      A list of filters used to filter the key-values included in the snapshot. Required.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The configuration key name (or prefix pattern) this snapshot filter matches. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="label" type="string">
          The configuration key label this snapshot filter matches. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="items_count" type="number">
      The amount of key-values in the snapshot. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The provisioning state of the snapshot. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="retention_period" type="number">
      The amount of time, in seconds, that a snapshot will remain in the archived state before expiring. This property is only writable during the creation of a snapshot. If not specified, the default lifetime of key-value revisions will be used. Optional.
    </ResponseField>
    <ResponseField name="size" type="number">
      The size in bytes of the snapshot. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="status" type="string">
      The current status of the snapshot. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="tags" type="map(string)">
      The tags of the snapshot. NOTE: These are data plane tags, not Azure Resource Manager (ARM) tags. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of the resource. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

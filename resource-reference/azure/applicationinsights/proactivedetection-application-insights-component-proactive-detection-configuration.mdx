`azure_applicationinsights_proactivedetection_application_insights_component_proactive_detection_configuration` configures one of Application Insights' own Smart Detection rules, which automatically analyze collected telemetry and alert on anomalies like a sudden rise in failure rate or an unusual load pattern.

`azure_applicationinsights_components_application_insights_component` is an Application Insights component, the top-level resource that collects and stores an application's own telemetry (requests, dependencies, exceptions, custom events) for monitoring and diagnostics.

## Properties

<ResponseField name="kind" type="string" required>
  The kind of application that this component refers to, used to customize UI. This value is a freeform string, values should typically be one of the following: web, ios, other, store, java, phone. Required.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties that define an Application Insights component resource. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="app_id" type="string">
      Application Insights Unique ID for your Application. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="application_id" type="string">
      The unique ID of your application. This field mirrors the 'Name' field and cannot be changed. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="application_type" type="string" required>
      Type of application being monitored. Required.
    </ResponseField>
    <ResponseField name="connection_string" type="string">
      Application Insights component connection string. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="creation_date" type="string">
      Creation Date for the Application Insights component, in ISO 8601 format. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="disable_ip_masking" type="bool">
      Disable IP masking. Optional.
    </ResponseField>
    <ResponseField name="flow_type" type="string">
      Used by the Application Insights system to determine what kind of flow this component was created by. This is to be set to 'Bluefield' when creating/updating a component via the REST API. Optional.
    </ResponseField>
    <ResponseField name="hockey_app_id" type="string">
      The unique application ID created when a new application is added to HockeyApp, used for communications with HockeyApp. Optional.
    </ResponseField>
    <ResponseField name="hockey_app_token" type="string">
      Token used to authenticate communications with between Application Insights and HockeyApp. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="immediate_purge_data_on30_days" type="bool">
      Purge data immediately after 30 days. Optional.
    </ResponseField>
    <ResponseField name="ingestion_mode" type="string">
      Indicates the flow of the ingestion. Optional.
    </ResponseField>
    <ResponseField name="instrumentation_key" type="string">
      Application Insights Instrumentation key. A read-only value that applications can use to identify the destination for all telemetry sent to Azure Application Insights. This value will be supplied upon construction of each new Application Insights component. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="private_link_scoped_resources" type="list(object)">
      List of linked private link scope resources. Computed by Microsoft Azure after `ship`.
      <Expandable title="properties">
        <ResponseField name="resource_id" type="string">
          A reference to the Private Link Scope resource this component is linked to. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="scope_id" type="string">
          The Private Link Scope's own identifier. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Current state of this component: whether or not is has been provisioned within the resource group it is defined. Users cannot change this value but are able to read from it. Values will include Succeeded, Deploying, Canceled, and Failed. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="request_source" type="string">
      Describes what tool created this Application Insights component. Customers using this API should set this to the default 'rest'. Optional.
    </ResponseField>
    <ResponseField name="retention_in_days" type="number">
      Retention period in days. Optional.
    </ResponseField>
    <ResponseField name="sampling_percentage" type="number">
      Percentage of the data produced by the application being monitored that is being sampled for Application Insights telemetry. Optional.
    </ResponseField>
    <ResponseField name="tenant_id" type="string">
      Azure Tenant Id. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

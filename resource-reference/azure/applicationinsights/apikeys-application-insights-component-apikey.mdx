`azure_applicationinsights_apikeys_application_insights_component_apikey` is an API key for an Application Insights component, used to authenticate an external tool or the Application Insights REST API against that component's own telemetry.

## Input properties

<ResponseField name="linked_read_properties" type="list(string)">
  The read access rights of this API Key. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="linked_write_properties" type="list(string)">
  The write access rights of this API Key. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the API Key. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

## Output properties

<ResponseField name="api_key" type="string">
  The API key value. It will be only return once when the API Key was created. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="created_date" type="string">
  The create date of this API key. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="id" type="string">

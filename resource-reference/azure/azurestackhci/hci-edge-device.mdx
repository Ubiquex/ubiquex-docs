`azure_azurestackhci_hci_edge_device` represents a single physical node's own Azure resource within an Azure Stack HCI deployment, prior to or during cluster formation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	azurestackhci "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/azurestackhci"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hci edge device"})

    		ubx.Resource(azurestackhci.HciEdgeDevice, "example", azurestackhci.HciEdgeDeviceConfig{
    			Kind: "example",
    		})
    	}))
    }
    ```

`azure_dataprotection_resource_guard_proxy_base_resource` links a Backup vault to a Resource Guard, enforcing multi-user authorization (MUA) on that vault's own critical operations -- disabling immutability, changing retention, or deleting backups all then require a second approver who doesn't control the vault.

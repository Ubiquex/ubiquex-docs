`azure_healthcareapis_healthcare_apis_iot_fhir_destination` defines the mapping rules an IoT connector uses to transform incoming device data into FHIR resource(s) written to a specific FHIR service.

## Example

    ```go
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own healthcare apis iot fhir destination"})

    		ubx.Resource(healthcareapis.HealthcareApisIotFhirDestination, "example", healthcareapis.HealthcareApisIotFhirDestinationConfig{
    			Properties: map[string]any{"fhir_mapping": map[string]any{"content": "example"}},
    		})
    	}))
    }
    ```

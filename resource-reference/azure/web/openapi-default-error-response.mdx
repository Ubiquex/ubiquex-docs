`azure_web_openapi_default_error_response` is App Service's own standard API error envelope, returned when a request to the App Service management API fails -- not a deployable resource in its own right.

## Example

  <Tab title="Go">
    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_web_openapi/sdk/go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_web_openapi/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi default error response"})

    		ubx.Resource(web.OpenapiDefaultErrorResponse, "example", web.OpenapiDefaultErrorResponseConfig{
    			Location: "example",
    		})
    	}))
    }
    ```

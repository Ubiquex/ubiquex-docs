`azure_web_openapi_app_service_environment_resource` provisions an App Service Environment, a single-tenant, isolated deployment of App Service running inside the caller's own virtual network.

## Example

<Tabs>

    ```go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi app service environment resource"})

    		ubx.Resource(web.OpenapiAppServiceEnvironmentResource, "example", web.OpenapiAppServiceEnvironmentResourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`azure_web_openapi_route` defines a routing rule within an Azure API Management gateway, mapping an incoming request path and method to a backend operation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure/sdk/go
    package main

    import (
    	web "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/web"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi route"})

    		ubx.Resource(web.OpenapiRoute, "example", web.OpenapiRouteConfig{
    			Name:       "example",
    			Kind:       "example",
    			Properties: map[string]any{"end_address": "example"},
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="properties" type="object">
  VnetRoute resource specific properties Optional.
  <Expandable title="properties">
    <ResponseField name="end_address" type="string">
      The ending address for this route. If the start address is specified in CIDR notation, this must be omitted. Optional.
    </ResponseField>
    <ResponseField name="route_type" type="string">
      The type of route this is: DEFAULT - By default, every app has routes to the local address ranges specified by RFC1918 INHERITED - Routes inherited from the real Virtual Network routes STATIC - Static route set on the app only These values will be used for syncing an app's routes with those from a Virtual Network. Optional.
    </ResponseField>
    <ResponseField name="start_address" type="string">
      The starting address for this route. This may also include a CIDR notation, in which case the end address must not be specified. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

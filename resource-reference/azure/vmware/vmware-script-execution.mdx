`azure_vmware_script_execution` runs a predefined PowerShell script package against an Azure VMware Solution private cloud, for administrative operations the vCenter UI doesn't directly expose.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vmware "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/vmware"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vmware script execution"})

    		ubx.Resource(vmware.ScriptExecution, "example", vmware.ScriptExecutionConfig{})
    	}))
    }
    ```

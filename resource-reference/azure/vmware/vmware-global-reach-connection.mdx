`azure_vmware_vmware_global_reach_connection` peers an Azure VMware Solution private cloud's own ExpressRoute circuit with another ExpressRoute circuit, extending connectivity to on-premises or another Azure VNet.

## Properties

<ResponseField name="properties" type="object">
  The properties of a global reach connection Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="address_prefix" type="string">
      The network used for global reach carved out from the original network block provided for the private cloud Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="authorization_key" type="string">
      Authorization key from the peer express route used for the global reach connection Optional.
    </ResponseField>
    <ResponseField name="circuit_connection_status" type="string">
      Global Reach Connection status Optional.
    </ResponseField>
    <ResponseField name="express_route_id" type="string">
      The ID of the Private Cloud's ExpressRoute Circuit that is participating in the global reach connection Optional.
    </ResponseField>
    <ResponseField name="peer_express_route_circuit" type="string">
      Identifier of the ExpressRoute Circuit to peer with in the global reach connection Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Global Reach Connection provisioning state Computed by Microsoft Azure after `ship`.

`azure_vmware_express_route_authorization` generates an authorization key letting an external ExpressRoute circuit connect to an Azure VMware Solution private cloud's own ExpressRoute circuit.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vmware express route authorization"})

    		ubx.Resource(vmware.ExpressRouteAuthorization, "example", vmware.ExpressRouteAuthorizationConfig{})
    	}))
    }
    ```

`azure_hardwaresecuritymodules_openapi_cloud_hsm_cluster` provisions Azure Cloud HSM, a single-tenant FIPS 140-3 Level 3 hardware security module cluster and the GA successor to Azure Dedicated HSM (which stopped accepting new onboarding in August 2025).

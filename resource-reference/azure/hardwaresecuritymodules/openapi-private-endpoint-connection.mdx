`azure_hardwaresecuritymodules_openapi_private_endpoint_connection` represents the connection between a Private Endpoint and an Azure Cloud HSM resource, tracking its own approval state.

## Properties

<ResponseField name="etag" type="string">
  Modified whenever there is a change in the state of private endpoint connection. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties of the private endpoint connection. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="group_ids" type="list(string)">
      The group ids for the private endpoint resource. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="private_endpoint" type="object">
      The private endpoint resource. Optional.
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          The ARM identifier for private endpoint. Computed by Microsoft Azure after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="private_link_service_connection_state" type="object" required>
      A collection of information about the state of the connection between service consumer and provider. Required.
      <Expandable title="properties">
        <ResponseField name="actions_required" type="string">
          A message indicating if changes on the service provider require any updates on the consumer. Optional.
        </ResponseField>
        <ResponseField name="description" type="string">
          The reason for approval/rejection of the connection. Optional.
        </ResponseField>
        <ResponseField name="status" type="string">
          The private endpoint connection status. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The current provisioning state. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_cdn_openapi_secret` stores a TLS certificate or managed identity credential used by Azure Front Door for custom domain HTTPS or origin authentication.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi secret"})

    		ubx.Resource(cdn.OpenapiSecret, "example", cdn.OpenapiSecretConfig{})
    	}))
    }
    ```

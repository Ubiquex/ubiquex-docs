`azure_cdn_openapi_secret` stores a TLS certificate or managed identity credential used by Azure Front Door for custom domain HTTPS or origin authentication.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_cdn_openapi --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_cdn_openapi/sdk/go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_cdn_openapi/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own openapi secret"})

    		ubx.Resource(cdn.OpenapiSecret, "ci-runner", cdn.OpenapiSecretConfig{})
    	}))
    }
    ```

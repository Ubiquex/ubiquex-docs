`azure_cdn_openapi_profile` is the top-level Azure CDN or Front Door resource that endpoint(s), origin group(s), and their own configuration are created within.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cdn "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/cdn"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi profile"})

    		ubx.Resource(cdn.OpenapiProfile, "example", cdn.OpenapiProfileConfig{
    			Sku: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```

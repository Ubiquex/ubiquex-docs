`azure_machinelearningservices_openapi_code_container` is the named container in an Azure Machine Learning workspace that version(s) of a specific piece of source code are registered under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi code container"})

    		ubx.Resource(machinelearningservices.OpenapiCodeContainer, "example", machinelearningservices.OpenapiCodeContainerConfig{
    			Properties: map[string]any{"provisioning_state": "example"},
    		})
    	}))
    }
    ```
  </Tab>

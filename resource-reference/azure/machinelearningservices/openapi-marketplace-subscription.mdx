`azure_machinelearningservices_openapi_marketplace_subscription` subscribes an Azure Machine Learning workspace to a model or offer available through the Azure Marketplace, required before deploying certain third-party Model Catalog models.

## Example

    package main

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    		})
    	}))
    }

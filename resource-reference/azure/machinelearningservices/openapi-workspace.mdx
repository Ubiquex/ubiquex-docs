`azure_machinelearningservices_openapi_workspace` is the top-level Azure Machine Learning (or Azure AI Foundry hub) resource that compute, datastore(s), and every registered asset are organized within.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi workspace"})

    		ubx.Resource(machinelearningservices.OpenapiWorkspace, "example", machinelearningservices.OpenapiWorkspaceConfig{

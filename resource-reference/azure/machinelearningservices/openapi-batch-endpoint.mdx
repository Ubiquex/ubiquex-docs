`azure_machinelearningservices_openapi_batch_endpoint` is the stable, addressable endpoint that Azure Machine Learning batch deployment(s) are invoked through for offline, large-scale scoring jobs.

## Example

<Tabs>

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi batch endpoint"})

    		ubx.Resource(machinelearningservices.OpenapiBatchEndpoint, "example", machinelearningservices.OpenapiBatchEndpointConfig{

    		})
    	}))
    }

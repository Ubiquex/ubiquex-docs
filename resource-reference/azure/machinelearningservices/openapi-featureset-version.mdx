`azure_machinelearningservices_openapi_featureset_version` is a specific, immutable version of a feature set definition in an Azure Machine Learning Managed Feature Store.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi featureset version"})

    		ubx.Resource(machinelearningservices.OpenapiFeaturesetVersion, "example", machinelearningservices.OpenapiFeaturesetVersionConfig{
    			Name:       "example",
    			Properties: map[string]any{"entities": []string{"example"}},
    			Version:    "example",
    		})
    	}))
    }
    ```
  </Tab>

`azure_machinelearningservices_openapi_data_container` is the named container in an Azure Machine Learning workspace that version(s) of a registered dataset are grouped under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	machinelearningservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/machinelearningservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi data container"})

    		ubx.Resource(machinelearningservices.OpenapiDataContainer, "example", machinelearningservices.OpenapiDataContainerConfig{
    			Name:       "example",
    			Properties: map[string]any{"data_type": "example"},
    		})
    	}))
    }
    ```
  </Tab>

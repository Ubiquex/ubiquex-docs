`azure_azure_kusto_kusto_attached_database_configuration` follows database(s) from a leader Azure Data Explorer cluster into a follower cluster in read-only mode, without duplicating the underlying data.

## Properties

<ResponseField name="location" type="string">
  Resource location. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Class representing the an attached database configuration properties of kind specific. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="attached_database_names" type="list(string)">
      The list of databases from the clusterResourceId which are currently attached to the cluster. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="cluster_resource_id" type="string" required>
      The resource id of the cluster where the databases you would like to attach reside. Required.
    </ResponseField>
    <ResponseField name="database_name" type="string" required>
      The name of the database which you would like to attach, use * if you want to follow all current and future databases. Required.
    </ResponseField>
    <ResponseField name="database_name_override" type="string">
      Overrides the original database name. Relevant only when attaching to a specific database. Optional.
    </ResponseField>
    <ResponseField name="database_name_prefix" type="string">
      Adds a prefix to the attached databases name. When following an entire cluster, that prefix would be added to all of the databases original names from leader cluster. Optional.
    </ResponseField>
    <ResponseField name="default_principals_modification_kind" type="string" required>
      The default principals modification kind Required.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The provisioned state of the resource. Optional.
    </ResponseField>
    <ResponseField name="table_level_sharing_properties" type="object">

`azure_servicefabric_application_application_type_resource` registers an application type with a Service Fabric cluster, the versioned template application instance(s) are created from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicefabric "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/servicefabric"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own application type resource"})

    		ubx.Resource(servicefabric.ApplicationTypeResource, "example", servicefabric.ApplicationTypeResourceConfig{})
    	}))
    }
    ```

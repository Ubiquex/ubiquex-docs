`azure_servicefabric_application_service_resource` is a single microservice within a Service Fabric application, running as either a stateless or stateful service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicefabric "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/servicefabric"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own application service resource"})

    		ubx.Resource(servicefabric.ApplicationServiceResource, "example", servicefabric.ApplicationServiceResourceConfig{})
    	}))
    }
    ```

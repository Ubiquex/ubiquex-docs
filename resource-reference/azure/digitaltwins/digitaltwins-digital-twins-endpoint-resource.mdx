`azure_digitaltwins_digitaltwins_digital_twins_endpoint_resource` routes matching Azure Digital Twins event(s) (twin changes, telemetry) to an external destination (Event Hub, Event Grid, or Service Bus).

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {

    	}))

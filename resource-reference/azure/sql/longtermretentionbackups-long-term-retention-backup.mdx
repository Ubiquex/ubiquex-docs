`azure_sql_longtermretentionbackups_long_term_retention_backup` is a single Azure SQL Database backup retained under a long-term retention policy, beyond standard point-in-time restore retention.

    	sql "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_sql_longtermretentionbackups/sql"

    	ubx.Main(ubx.Stack("payments", func() {

## Input properties

<ResponseField name="backup_storage_access_tier" type="string" required>
  The long term retention backup storage access tier Required.
</ResponseField>

<ResponseField name="operation_mode" type="string" required>
  The operation mode when updating ltr backup storage access tier Required.
</ResponseField>

## Output properties

<ResponseField name="properties" type="object">
  Properties of a long term retention backup Computed by Microsoft Azure after `ship`.
  <Expandable title="properties">
    <ResponseField name="backup_expiration_time" type="string">
      The time the long term retention backup will expire. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="backup_storage_access_tier" type="string">
      The BackupStorageAccessTier for the LTR backup Optional.
    </ResponseField>
    <ResponseField name="backup_storage_redundancy" type="string">
      The storage account type used to store backups for this database. Optional.
    </ResponseField>
    <ResponseField name="backup_time" type="string">
      The time the backup was taken Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="database_deletion_time" type="string">
      The delete time of the database Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="database_name" type="string">
      The name of the database the backup belong to Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="is_backup_immutable" type="bool">
      The setting whether the LTR backup is immutable Optional.
    </ResponseField>
    <ResponseField name="legal_hold_immutability" type="string">
      The setting for whether LegalHold is enabled or disabled on the LTR backup. When LegalHold is enabled, the backup cannot be deleted until the LegalHold is removed. Optional.
    </ResponseField>
    <ResponseField name="requested_backup_storage_redundancy" type="string">
      The storage account type used to store backups for this database. Optional.
    </ResponseField>
    <ResponseField name="server_create_time" type="string">
      The create time of the server. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="server_name" type="string">
      The server name that the backup database belong to. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="time_based_immutability" type="string">
      The setting for whether or not time-based immutability is enabled for the LTR backup. When time-based immutability is enabled and locked, the backup cannot be deleted until BackupExpirationTime. Optional.
    </ResponseField>
    <ResponseField name="time_based_immutability_mode" type="string">
      The time-based immutability mode. Only applicable if time-based immutability is enabled. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_sql_instancepools_instance_pool` is a shared pool of compute resources that multiple Azure SQL Managed Instances draw from, for cost-efficient hosting of smaller instances.

## Properties

<ResponseField name="properties" type="object">
  Properties of an instance pool. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="dns_zone" type="string">
      The Dns Zone that the managed instance pool is in. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="license_type" type="string" required>
      The license type. Possible values are 'LicenseIncluded' (price for SQL license is included) and 'BasePrice' (without SQL license price). Required.
    </ResponseField>
    <ResponseField name="maintenance_configuration_id" type="string">
      Specifies maintenance configuration id to apply to this managed instance. Optional.
    </ResponseField>
    <ResponseField name="subnet_id" type="string" required>
      Resource ID of the subnet to place this instance pool in. Required.
    </ResponseField>
    <ResponseField name="v_cores" type="number" required>
      Count of vCores belonging to this instance pool. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

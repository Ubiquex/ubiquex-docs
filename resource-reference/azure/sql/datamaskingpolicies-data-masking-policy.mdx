`azure_sql_datamaskingpolicies_data_masking_policy` enables dynamic data masking on a single Azure SQL Database, limiting sensitive data exposure to non-privileged users without altering stored data.

## Properties

<ResponseField name="kind" type="string">
  The kind of Data Masking Policy. Metadata, used for Azure portal. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="location" type="string">
  The location of the data masking policy. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  The properties of a database data masking policy. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="application_principals" type="string">
      The list of the application principals. This is a legacy parameter and is no longer used. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="data_masking_state" type="string" required>
      The state of the data masking policy. Required.
    </ResponseField>
    <ResponseField name="exempt_principals" type="string">
      The list of the exempt principals. Specifies the semicolon-separated list of database users for which the data masking policy does not apply. The specified users receive data results without masking for all of the database queries. Optional.
    </ResponseField>
    <ResponseField name="masking_level" type="string">
      The masking level. This is a legacy parameter and is no longer used. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

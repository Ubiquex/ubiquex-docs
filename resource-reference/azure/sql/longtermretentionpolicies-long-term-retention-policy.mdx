`azure_sql_longtermretentionpolicies_long_term_retention_policy` defines the weekly/monthly/yearly backup retention schedule applied to an Azure SQL Database beyond its own standard short-term retention.

<ResponseField name="properties" type="object">
  Properties of a long term retention policy Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="monthly_retention" type="string">
      The monthly retention policy for an LTR backup in an ISO 8601 format. Optional.
    </ResponseField>
    <ResponseField name="time_based_immutability" type="string">
      The setting for whether or not time-based immutability is enabled for the LTR backup. When time-based immutability is enabled and locked, the backup cannot be deleted until BackupExpirationTime. Optional.
    </ResponseField>
    <ResponseField name="time_based_immutability_mode" type="string">
      The time-based immutability mode. Only applicable if time-based immutability is enabled. Optional.
    </ResponseField>
    <ResponseField name="week_of_year" type="number">
      The week of year to take the yearly backup in an ISO 8601 format. Optional.
    </ResponseField>
    <ResponseField name="weekly_retention" type="string">
      The weekly retention policy for an LTR backup in an ISO 8601 format. Optional.
    </ResponseField>
    <ResponseField name="yearly_retention" type="string">
      The yearly retention policy for an LTR backup in an ISO 8601 format. Optional.

## Properties

<ResponseField name="kind" type="string">
  Kind of encryption protector. This is metadata used for the Azure portal experience. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="location" type="string">
  Resource location. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties for a server key execution. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="auto_rotation_enabled" type="bool">
      Key auto rotation opt-in flag. Either true or false. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="creation_date" type="string">
      The server key creation date. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="key_version" type="string">
      The version of the server key. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="server_key_type" type="string" required>
      The encryption protector type like 'ServiceManaged', 'AzureKeyVault'. Required.
    </ResponseField>
    <ResponseField name="subregion" type="string">
      Subregion of the server key. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="thumbprint" type="string">
      Thumbprint of the server key. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI of the server key. If the ServerKeyType is AzureKeyVault, then the URI is required. The AKV URI is required to be in this format: 'https://YourVaultName.vault.azure.net/keys/YourKeyName/YourKeyVersion' or can be 'https://YourVaultName.vault.azure.net/keys/YourKeyName' Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

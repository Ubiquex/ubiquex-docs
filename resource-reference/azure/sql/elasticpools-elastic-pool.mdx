`azure_sql_elasticpools_elastic_pool` is a shared pool of compute resources that multiple Azure SQL Databases draw from, letting variable-usage databases share capacity cost-effectively.

      Specifies the availability zone the database is pinned to. Optional.

    </ResponseField>

    <ResponseField name="license_type" type="string">
      The license type to apply for this elastic pool. Optional.

    <ResponseField name="maintenance_configuration_id" type="string">

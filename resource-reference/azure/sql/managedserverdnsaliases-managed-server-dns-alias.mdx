`azure_sql_managedserverdnsaliases_managed_server_dns_alias` creates an alternate, alias DNS name pointing to an Azure SQL Managed Instance, usable to redirect connections during failover without changing client connection strings.

## Input properties

<ResponseField name="create_dns_record" type="bool">
  Whether or not DNS record should be created for this alias. Optional.
</ResponseField>

## Output properties

<ResponseField name="properties" type="object">
  Properties of a managed server DNS alias. Computed by Microsoft Azure after `ship`.

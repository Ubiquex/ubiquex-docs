`azure_sql_instancefailovergroups_instance_failover_group` groups Azure SQL Managed Instance(s) on a primary instance for coordinated automatic or manual failover to a secondary instance in another region.

      List of managed instance pairs in the failover group. Required.

          A reference to the partner managed instance in this failover pairing. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="primary_managed_instance_id" type="string">
          A reference to the primary managed instance in this failover pairing. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="partner_regions" type="list(object)" required>
      Partner region information for the failover group. Required.
      <Expandable title="properties">
        <ResponseField name="location" type="string">
          The Azure region this resource is deployed to, e.g. `eastus`. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="replication_role" type="string">
          Whether this partner region acts as the primary or a secondary in the failover group. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="read_only_endpoint" type="object">
      Read-only endpoint of the failover group instance. Optional.
      <Expandable title="properties">
        <ResponseField name="failover_policy" type="string">
          Failover policy of the read-only endpoint for the failover group. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="read_write_endpoint" type="object" required>
      Read-write endpoint of the failover group instance. Required.
      <Expandable title="properties">
        <ResponseField name="failover_policy" type="string" required>
          Failover policy of the read-write endpoint for the failover group. If failoverPolicy is Automatic then failoverWithDataLossGracePeriodMinutes is required. Required.
        </ResponseField>
        <ResponseField name="failover_with_data_loss_grace_period_minutes" type="number">
          Grace period before failover with data loss is attempted for the read-write endpoint. If failoverPolicy is Automatic then failoverWithDataLossGracePeriodMinutes is required. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="replication_role" type="string">
      Local replication role of the failover group instance. Optional.
    </ResponseField>
    <ResponseField name="replication_state" type="string">
      Replication state of the failover group instance. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="secondary_type" type="string">
      Type of the geo-secondary instance. Set 'Standby' if the instance is used as a DR option only. Optional.
    </ResponseField>

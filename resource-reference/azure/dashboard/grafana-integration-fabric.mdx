`azure_dashboard_grafana_integration_fabric` connects an Azure Managed Grafana instance to a Microsoft Fabric workspace, letting Grafana dashboards query Fabric data sources.

## Example

    package main

    	dashboard "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_dashboard_grafana/dashboard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

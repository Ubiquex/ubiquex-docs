`azure_cognitiveservices_quota_tier` reports the throughput quota tier assigned to a specific model within an Azure AI services account, e.g. tokens-per-minute limits.

## Properties

<ResponseField name="default" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties of Quota Tier resource'. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="assignment_date" type="string">
      The date on which the current tier was assigned to the subscription (UTC). Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="current_tier_name" type="string">
      Name of the current quota tier for the subscription. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="tier_upgrade_eligibility_info" type="object">
      Information about the quota tier upgrade eligibility for the subscription. Optional.
      <Expandable title="properties">
        <ResponseField name="next_tier_name" type="string">
          Name of the next quota tier for the subscription. Optional.
        </ResponseField>
        <ResponseField name="upgrade_applicable_date" type="string">
          The date after which the current tier will be upgraded to the next tier if the TierUpgradePolicy is "OnceUpgradeIsAvailable" (UTC). Optional.
        </ResponseField>
        <ResponseField name="upgrade_availability_status" type="string">
          Specifies whether an upgrade to the next quota tier is available. Optional.
        </ResponseField>
        <ResponseField name="upgrade_unavailability_reason" type="string">
          Reason in case the subscription is not eligible for upgrade to the next tier. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="tier_upgrade_policy" type="string">
      Gets the tier upgrade policy for the subscription. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

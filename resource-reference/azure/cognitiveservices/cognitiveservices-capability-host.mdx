`azure_cognitiveservices_capability_host` provisions the compute and storage backing a specific AI capability (e.g. agent execution) within an Azure AI Foundry account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cognitiveservices "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/cognitiveservices"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own capability host"})

    		ubx.Resource(cognitiveservices.CapabilityHost, "example", cognitiveservices.CapabilityHostConfig{
    			Properties: map[string]any{"ai_services_connections": []string{"example"}},
    		})
    	}))
    }
    ```

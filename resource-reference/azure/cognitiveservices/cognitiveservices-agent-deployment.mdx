`azure_cognitiveservices_cognitiveservices_agent_deployment` is a specific, running deployment of an Azure AI Foundry agent application, servable for real conversation traffic.

## Example

    package main

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cognitiveservices agent deployment"})

    		ubx.Resource(cognitiveservices.AgentDeployment, "example", cognitiveservices.AgentDeploymentConfig{

`azure_signalr_custom_certificate` uploads a TLS certificate (referenced from Key Vault) to a SignalR Service resource, bindable to a custom domain.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	signalr "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/signalr"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom certificate"})

    		ubx.Resource(signalr.CustomCertificate, "example", signalr.CustomCertificateConfig{
    			Properties: map[string]any{"key_vault_base_uri": "example", "key_vault_secret_name": "example-key-vault-secret-name"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { CustomCertificate } from "@ubx/sdk-azure/azure/signalr/custom_certificate";

    export default stack("example", () => {
      intent({ summary: "example own custom certificate" });

      resource(CustomCertificate, "example", {
        properties: {
          keyVaultBaseUri: "example",
          keyVaultSecretName: "example-key-vault-secret-name",
        },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.azure.signalr import CustomCertificate, CustomCertificateConfig
    from ubx.azure.signalr.custom_certificate import CustomCertificate_Properties

    def describe():
        ubx.intent("example own custom certificate")

        ubx.resource(CustomCertificate, "example", CustomCertificateConfig(
            properties=CustomCertificate_Properties(key_vault_base_uri="example", key_vault_secret_name="example-key-vault-secret-name"),
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="properties" type="object" required>
  Custom certificate properties. Required.
  <Expandable title="properties">
    <ResponseField name="key_vault_base_uri" type="string" required>
      Base uri of the KeyVault that stores certificate. Required.
    </ResponseField>
    <ResponseField name="key_vault_secret_name" type="string" required>
      Certificate secret name. Required.
    </ResponseField>
    <ResponseField name="key_vault_secret_version" type="string">
      Certificate secret version. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Provisioning state of the resource. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

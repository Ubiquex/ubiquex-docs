`azure_paloaltonetworks_paloaltonetworks_cloudngfw_prefix_list_resource` is a reusable list of IP address prefix(es) referenced by rule(s) within a Cloud NGFW local rulestack.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

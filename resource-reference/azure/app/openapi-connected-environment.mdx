`azure_app_openapi_connected_environment` is a Container Apps environment running on Azure Arc-enabled Kubernetes, for deploying container apps outside standard Azure regions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_app_openapi --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_app_openapi/sdk/go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_app_openapi/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own openapi connected environment"})

    		ubx.Resource(app.OpenapiConnectedEnvironment, "ci-runner", app.OpenapiConnectedEnvironmentConfig{})
    	}))
    }
    ```
  </Tab>

`azure_kusto_script` runs a batch of KQL control commands against an Azure Data Explorer database as part of resource deployment, e.g. to create tables or ingestion mappings declaratively.

## Properties

<ResponseField name="properties" type="object">
  A class representing database script property. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="continue_on_errors" type="bool">
      Flag that indicates whether to continue if one of the command fails. Optional.
    </ResponseField>
    <ResponseField name="force_update_tag" type="string">
      A unique string. If changed the script will be applied again. Optional.
    </ResponseField>
    <ResponseField name="managed_identity_resource_id" type="string">
      The resource identifier of the managed identity to be used. When provided, the managed identity will be used to read the script content from the scriptUrl. Optional.
    </ResponseField>
    <ResponseField name="principal_permissions_action" type="string">
      Indicates if the permissions for the script caller are kept following completion of the script. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The provisioned state of the resource. Optional.
    </ResponseField>
    <ResponseField name="script_content" type="string">
      The script content. This property should be used when the script is provide inline and not through file in a SA. Must not be used together with scriptUrl and scriptUrlSasToken properties. Optional.
    </ResponseField>
    <ResponseField name="script_level" type="string">
      Differentiates between the type of script commands included - Database or Cluster. The default is Database. Optional.
    </ResponseField>
    <ResponseField name="script_url" type="string">
      The url to the KQL script blob file. Must not be used together with scriptContent property Optional.
    </ResponseField>
    <ResponseField name="script_url_sas_token" type="string">
      The SaS token that provide read access to the file which contain the script. Must be provided when using scriptUrl property. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

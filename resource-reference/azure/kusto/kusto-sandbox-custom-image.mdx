`azure_kusto_sandbox_custom_image` defines a custom Python runtime image (base image, package requirements) available to the `python()` plugin's own isolated sandbox execution in Azure Data Explorer queries.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kusto "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/kusto"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own kusto sandbox custom image"})

    		ubx.Resource(kusto.SandboxCustomImage, "example", kusto.SandboxCustomImageConfig{})
    	}))
    }
    ```

## Properties

<ResponseField name="properties" type="object">
  A class representing the properties of a sandbox custom image object. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="base_image_name" type="string">
      The base image name on which the custom image is built on top of. It can be one of the LanguageExtensionImageName (e.g.: 'Python3_10_8', 'Python3_10_8_DL') or the name of an existing custom image. Either this property or languageVersion should be specified. Optional.
    </ResponseField>
    <ResponseField name="language" type="string" required>
      The language name, for example Python. Required.
    </ResponseField>
    <ResponseField name="language_version" type="string">
      The version of the language. Either this property or baseImageName should be specified. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The provisioned state of the resource. Optional.
    </ResponseField>
    <ResponseField name="requirements_file_content" type="string">
      The requirements file content. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

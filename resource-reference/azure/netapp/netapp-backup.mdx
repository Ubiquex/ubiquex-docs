`azure_netapp_netapp_backup` is a point-in-time backup of an Azure NetApp Files volume, stored independently of the volume's own snapshot history for longer-term retention.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only azure_netapp_netapp --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_netapp_netapp/sdk/go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_netapp_netapp/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own netapp backup"})

    		ubx.Resource(netapp.NetappBackup, "ci-runner", netapp.NetappBackupConfig{
    			Properties: map[string]any{"volume_resource_id": "example"},
    		})
    	}))
    }
    ```
  </Tab>

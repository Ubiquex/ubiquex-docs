`azure_netapp_snapshot` is a point-in-time, storage-efficient snapshot of an Azure NetApp Files volume, restorable in place or usable as the source for a new volume clone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	netapp "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/netapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own netapp snapshot"})

    		ubx.Resource(netapp.Snapshot, "example", netapp.SnapshotConfig{
    			Location: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {
    ```

  <Tab title="Python">

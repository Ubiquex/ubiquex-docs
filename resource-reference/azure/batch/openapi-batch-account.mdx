`azure_batch_openapi_batch_account` is the top-level Azure Batch resource that pool(s), job(s), and application(s) are created within, for large-scale parallel and HPC batch job execution.

## Properties

<ResponseField name="identity" type="object">
  The identity of the Batch account, if configured. This is used when the user specifies 'Microsoft.KeyVault' as their Batch account encryption configuration or when `ManagedIdentity` is selected as the auto-storage authentication mode. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="principal_id" type="string">
      The principal id of the Batch account. This property will only be provided for a system assigned identity. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="tenant_id" type="string">
      The tenant id associated with the Batch account. This property will only be provided for a system assigned identity. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of identity used for the Batch account. Required.
    </ResponseField>
    <ResponseField name="user_assigned_identities" type="map(object)">
      The list of user identities associated with the Batch account. Optional.
      <Expandable title="properties">
        <ResponseField name="client_id" type="string">
          The client (application) ID of the user-assigned managed identity to use. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="principal_id" type="string">
          Output only. The Microsoft Entra ID object ID of this resource's own managed identity or service principal. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location" type="string" required>

</ResponseField>

`azure_security_datascanners_data_scanner` configures Microsoft Defender for Cloud's own sensitive data discovery scanner for a data resource, automatically classifying sensitive data at rest.

## Properties

<ResponseField name="identity" type="object">
  Managed service identity (either system assigned, or none) Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="principal_id" type="string">
      The service principal ID of the system assigned identity. This property will only be provided for a system assigned identity. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="tenant_id" type="string">
      The tenant ID of the system assigned identity. This property will only be provided for a system assigned identity. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Type of managed service identity (either system assigned, or none). Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="properties" type="any">
  Data scanner resource properties. The data scanner is an identity-only resource defined solely by its assigned managed identity. Optional; if omitted, computed by Microsoft Azure.

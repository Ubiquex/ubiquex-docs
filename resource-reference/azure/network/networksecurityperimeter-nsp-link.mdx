`azure_network_networksecurityperimeter_nsp_link` connects two Network Security Perimeters together, permitting resources in each to communicate as if they were in the same perimeter.

## Properties

<ResponseField name="properties" type="object">
  Properties of NSP Link resource. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="auto_approved_remote_perimeter_resource_id" type="string">
      Perimeter ARM Id for the remote NSP with which the link gets created in Auto-approval mode. It should be used when the NSP admin have Microsoft.Network/networkSecurityPerimeters/linkPerimeter/action permission on the remote NSP resource. Optional.
    </ResponseField>
    <ResponseField name="description" type="string">
      A message passed to the owner of the remote NSP link resource with this connection request. In case of Auto-approved flow, it is default to 'Auto Approved'. Restricted to 140 chars. Optional.
    </ResponseField>
    <ResponseField name="local_inbound_profiles" type="list(string)">
      Local Inbound profile names to which Inbound is allowed. Use ['*'] to allow inbound to all profiles. Optional.
    </ResponseField>
    <ResponseField name="local_outbound_profiles" type="list(string)">
      Local Outbound profile names from which Outbound is allowed. In current version, it is readonly property and it's value is set to ['*'] to allow outbound from all profiles. In later version, user will be able to modify it. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The current provisioning state of NSP Link/LinkReference. Optional.
    </ResponseField>
    <ResponseField name="remote_inbound_profiles" type="list(string)">
      Remote Inbound profile names to which Inbound is allowed. Use ['*'] to allow inbound to all profiles. This property can only be updated in auto-approval mode. Optional.
    </ResponseField>
    <ResponseField name="remote_outbound_profiles" type="list(string)">
      Remote Outbound profile names from which Outbound is allowed. In current version, it is readonly property and it's value is set to ['*'] to allow outbound from all profiles. In later version, user will be able to modify it. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="remote_perimeter_guid" type="string">
      Remote NSP Guid with which the link gets created. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="remote_perimeter_location" type="string">
      Remote NSP location with which the link gets created. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="status" type="string">
      The NSP link state. Optional.
    </ResponseField>

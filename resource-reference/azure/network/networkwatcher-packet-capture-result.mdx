`azure_network_networkwatcher_packet_capture_result` captures raw network traffic to and from a specific VM, triggerable remotely without installing packet-capture software manually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	network "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/network"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own networkwatcher packet capture result"})

    		ubx.Resource(network.NetworkwatcherPacketCaptureResult, "example", network.NetworkwatcherPacketCaptureResultConfig{
    			Properties: map[string]any{"storage_location": map[string]any{"file_path": "example"}, "target": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="properties" type="object" required>
  Parameters that define the create packet capture operation. Required.
  <Expandable title="properties">
    <ResponseField name="bytes_to_capture_per_packet" type="number">
      Number of bytes captured per packet, the remaining bytes are truncated. Optional.
    </ResponseField>
    <ResponseField name="capture_settings" type="object">
      The storage location for a packet capture session. Optional.
      <Expandable title="properties">
        <ResponseField name="file_count" type="number">
          Number of file count. Default value of count is 10 and maximum number is 10000. Optional.
        </ResponseField>
        <ResponseField name="file_size_in_bytes" type="number">
          Number of bytes captured per packet. Default value in bytes 104857600 (100MB) and maximum in bytes 4294967295 (4GB). Optional.
        </ResponseField>
        <ResponseField name="session_time_limit_in_seconds" type="number">
          Maximum duration of the capture session in seconds is 604800s (7 days) for a file. Default value in second 86400s (1 day). Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="continuous_capture" type="bool">
      This continuous capture is a nullable boolean, which can hold 'null', 'true' or 'false' value. If we do not pass this parameter, it would be consider as 'null', default value is 'null'. Optional.
    </ResponseField>
    <ResponseField name="filters" type="list(object)">
      A list of packet capture filters. Optional.
      <Expandable title="properties">
        <ResponseField name="local_ipaddress" type="string">
          The source IP address this test originates from. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="local_port" type="string">
          The source port this test originates from. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="protocol" type="string">
          The network protocol this rule or listener applies to, e.g. `Tcp`, `Udp`, or `*` for any. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="remote_ipaddress" type="string">
          The destination IP address this test targets. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="remote_port" type="string">
          The destination port this test targets. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="scope" type="object">
      A list of AzureVMSS instances which can be included or excluded to run packet capture. If both included and excluded are empty, then the packet capture will run on all instances of AzureVMSS. Optional.
      <Expandable title="properties">
        <ResponseField name="exclude" type="list(string)">
          List of AzureVMSS instances which has to be excluded from the AzureVMSS from running packet capture. Optional.
        </ResponseField>
        <ResponseField name="include" type="list(string)">
          List of AzureVMSS instances to run packet capture on. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="storage_location" type="object" required>
      The storage location for a packet capture session. Required.
      <Expandable title="properties">
        <ResponseField name="file_path" type="string">
          This path is invalid if 'Continuous Capture' is provided with 'true' or 'false'. A valid local path on the targeting VM. Must include the name of the capture file (*.cap). For linux virtual machine it must start with /var/captures. Required if no storage ID is provided, otherwise optional. Optional.
        </ResponseField>
        <ResponseField name="local_path" type="string">
          This path is valid if 'Continuous Capture' is provided with 'true' or 'false' and required if no storage ID is provided, otherwise optional. Must include the name of the capture file (*.cap). For linux virtual machine it must start with /var/captures. Optional.
        </ResponseField>
        <ResponseField name="storage_id" type="string">
          The ID of the storage account to save the packet capture session. Required if no localPath or filePath is provided. Optional.
        </ResponseField>
        <ResponseField name="storage_path" type="string">
          The URI of the storage path to save the packet capture. Must be a well-formed URI describing the location to save the packet capture. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="target" type="string" required>
      The ID of the targeted resource, only AzureVM and AzureVMSS as target type are currently supported. Required.
    </ResponseField>
    <ResponseField name="target_type" type="string">
      Target type of the resource provided. Optional.
    </ResponseField>
    <ResponseField name="time_limit_in_seconds" type="number">
      Maximum duration of the capture session in seconds. Optional.
    </ResponseField>
    <ResponseField name="total_bytes_per_session" type="number">
      Maximum size of the capture output. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

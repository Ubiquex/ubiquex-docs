`azure_search_shared_private_link_resource` creates a Private Endpoint from an Azure AI Search service to another Private Link-enabled Azure service, so its own indexer(s) can reach data sources privately.

## Properties

<ResponseField name="properties" type="object">
  Describes the properties of an existing shared private link resource managed by the Azure AI Search service. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="group_id" type="string">
      The group ID from the provider of resource the shared private link resource is for. Optional.
    </ResponseField>
    <ResponseField name="private_link_resource_id" type="string">
      The resource ID of the resource the shared private link resource is for. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The provisioning state of the shared private link resource. Valid values are Updating, Deleting, Failed, Succeeded or Incomplete. Optional.
    </ResponseField>
    <ResponseField name="request_message" type="string">
      The message for requesting approval of the shared private link resource. Optional.
    </ResponseField>
    <ResponseField name="resource_region" type="string">
      Optional. Can be used to specify the Azure Resource Manager location of the resource for which a shared private link is being created. This is only required for those resources whose DNS configuration are regional (such as Azure Kubernetes Service). Optional.
    </ResponseField>
    <ResponseField name="status" type="string">
      Status of the shared private link resource. Valid values are Pending, Approved, Rejected or Disconnected. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

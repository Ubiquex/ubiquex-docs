`azure_search_search_private_endpoint_connection` represents the connection between a Private Endpoint and an Azure AI Search service, tracking its own approval state.

## Properties

<ResponseField name="properties" type="object">
  Describes the properties of an existing private endpoint connection to the search service. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="group_id" type="string">
      The group ID of the Azure resource for which the private link service is for. Optional.
    </ResponseField>
    <ResponseField name="private_endpoint" type="object">
      The private endpoint resource from Microsoft.Network provider. Optional.
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          The resource ID of the private endpoint resource from Microsoft.Network provider. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="private_link_service_connection_state" type="object">
      Describes the current state of an existing Azure Private Link service connection to the private endpoint. Optional.
      <Expandable title="properties">
        <ResponseField name="actions_required" type="string">
          A description of any extra actions that may be required. Optional.
        </ResponseField>
        <ResponseField name="description" type="string">
          The description for the private link service connection state. Optional.
        </ResponseField>
        <ResponseField name="status" type="string">
          Status of the the private link service connection. Valid values are Pending, Approved, Rejected, or Disconnected. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      The provisioning state of the private link service connection. Valid values are Updating, Deleting, Failed, Succeeded, Incomplete, or Canceled. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_relay_relay_wcf_relay` relays a WCF (Windows Communication Foundation) service through Azure Relay, exposing an on-premises WCF endpoint to internet callers without inbound firewall changes.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Properties

<ResponseField name="location" type="string">
  The geo-location where the resource lives Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties of the WCF relay. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="created_at" type="string">
      The time the WCF relay was created. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="is_dynamic" type="bool">
      Returns true if the relay is dynamic; otherwise, false. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="listener_count" type="number">
      The number of listeners for this relay. Note that min :1 and max:25 are supported. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="relay_type" type="string">
      WCF relay type. Optional.
    </ResponseField>
    <ResponseField name="requires_client_authorization" type="bool">
      Returns true if client authorization is needed for this relay; otherwise, false. Optional.
    </ResponseField>
    <ResponseField name="requires_transport_security" type="bool">
      Returns true if transport security is needed for this relay; otherwise, false. Optional.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      The time the namespace was updated. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="user_metadata" type="string">
      The usermetadata is a placeholder to store user-defined string data for the WCF Relay endpoint. For example, it can be used to store descriptive data, such as list of teams and their contact information. Also, user-defined configuration settings can be stored. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_relay_relay_hybrid_connection` establishes outbound-only relayed connectivity from an on-premises or firewalled service to Azure, without opening inbound firewall ports.

## Properties

<ResponseField name="location" type="string">
  The geo-location where the resource lives Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties of the HybridConnection. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="created_at" type="string">
      The time the hybrid connection was created. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="listener_count" type="number">
      The number of listeners for this hybrid connection. Note that min : 1 and max:25 are supported. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="requires_client_authorization" type="bool">
      Returns true if client authorization is needed for this hybrid connection; otherwise, false. Optional.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      The time the namespace was updated. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="user_metadata" type="string">
      The usermetadata is a placeholder to store user-defined string data for the hybrid connection endpoint. For example, it can be used to store descriptive data, such as a list of teams and their contact information. Also, user-defined configuration settings can be stored. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

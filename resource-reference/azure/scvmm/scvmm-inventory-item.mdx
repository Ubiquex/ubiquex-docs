`azure_scvmm_scvmm_inventory_item` is a discovered SCVMM object (a VM, template, or network) surfaced as an Azure Arc resource once its own management server is onboarded.

## Example

    package main

    import (
    	scvmm "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_scvmm_scvmm/scvmm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    	}))

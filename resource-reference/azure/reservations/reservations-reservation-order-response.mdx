`azure_reservations_reservations_reservation_order_response` is a purchased Azure Reservation (a committed-use discount for compute, database, or other resources), covering one or more individual reservation(s).

## Example

    ```go
    package main

    import (
    	reservations "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/reservations"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own reservations reservation order response"})

    		ubx.Resource(reservations.ReservationOrderResponse, "example", reservations.ReservationOrderResponseConfig{
    			Location: "example",
    			Sku:      map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="location" type="string">
  The Azure region where the reserved resource lives. Optional.
</ResponseField>

<ResponseField name="properties" type="object">
  Properties of reservation purchase request Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="applied_scope_properties" type="object">
      Properties specific to applied scope type. Not required if not applicable. Required and need to provide tenantId and managementGroupId if AppliedScopeType is ManagementGroup Optional.
      <Expandable title="properties">
        <ResponseField name="display_name" type="string">
          Display name Optional.
        </ResponseField>
        <ResponseField name="management_group_id" type="string">
          Fully-qualified identifier of the management group where the benefit must be applied. Optional.
        </ResponseField>
        <ResponseField name="resource_group_id" type="string">
          Fully-qualified identifier of the resource group. Optional.
        </ResponseField>
        <ResponseField name="subscription_id" type="string">
          Fully-qualified identifier of the subscription. Optional.
        </ResponseField>
        <ResponseField name="tenant_id" type="string">
          Tenant ID where the savings plan should apply benefit. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="applied_scope_type" type="string">
      Type of the Applied Scope. Optional.
    </ResponseField>
    <ResponseField name="applied_scopes" type="list(string)">
      List of the subscriptions that the benefit will be applied. Do not specify if AppliedScopeType is Shared. This property will be deprecated and replaced by appliedScopeProperties instead for Single AppliedScopeType. Optional.
    </ResponseField>
    <ResponseField name="billing_plan" type="string">
      Represent the billing plans. Optional.
    </ResponseField>
    <ResponseField name="billing_scope_id" type="string">
      Subscription that will be charged for purchasing reservation or savings plan Optional.
    </ResponseField>
    <ResponseField name="display_name" type="string">
      Friendly name of the reservation Optional.
    </ResponseField>
    <ResponseField name="quantity" type="number">
      Quantity of the skus that are part of the reservation. Optional.
    </ResponseField>
    <ResponseField name="renew" type="bool">
      Setting this to true will automatically purchase a new reservation on the expiration date time. Optional.
    </ResponseField>
    <ResponseField name="reserved_resource_properties" type="object">
      Properties specific to each reserved resource type. Not required if not applicable. Optional.
      <Expandable title="properties">
        <ResponseField name="instance_flexibility" type="string">
          Turning this on will apply the reservation discount to other VMs in the same VM size group. Only specify for VirtualMachines reserved resource type. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="reserved_resource_type" type="string">
      The type of the resource that is being reserved. In addition to below types we have also added the following: OpenAIPTU, MDC, Sentinel. Optional.
    </ResponseField>
    <ResponseField name="review_date_time" type="string">
      This is the date-time when the Azure hybrid benefit needs to be reviewed. Optional.
    </ResponseField>
    <ResponseField name="term" type="string">
      Represent the term of reservation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_iothub_iothub_job_response` reports the status of a bulk IoT Hub job (e.g. a scheduled device twin update or direct method call across many devices).

## Example

## Input properties

<ResponseField name="authentication_type" type="string">
  Specifies authentication type being used for connecting to the storage account. Optional.
</ResponseField>

<ResponseField name="configurations_blob_name" type="string">
  The name of the blob that will be created in the provided output blob container. This blob will contain the exported configurations for the Iot Hub. Optional.
</ResponseField>

<ResponseField name="exclude_keys" type="bool" required>
  The value indicating whether keys should be excluded during export. Required.
</ResponseField>

<ResponseField name="export_blob_container_uri" type="string" required>
  The export blob container URI. Required.
</ResponseField>

<ResponseField name="export_blob_name" type="string">
  The name of the blob that will be created in the provided output blob container. This blob will contain the exported device registry information for the IoT Hub. Optional.
</ResponseField>

<ResponseField name="identity" type="object">
  The properties of the Managed identity. Optional.
  <Expandable title="properties">
    <ResponseField name="user_assigned_identity" type="string">
      The user assigned identity. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="include_configurations" type="bool">
  The value indicating whether configurations should be exported. Optional.
</ResponseField>

## Output properties

<ResponseField name="end_time_utc" type="string">
  The time the job stopped processing. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="failure_reason" type="string">
  If status == failed, this string containing the reason for the failure. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="job_id" type="string">
  The job identifier. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="parent_job_id" type="string">
  The job identifier of the parent job, if any. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="start_time_utc" type="string">
  The start time of the job. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the job. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="status_message" type="string">
  The status message for the job. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="type" type="string">
  The type of the job. Computed by Microsoft Azure after `ship`.
</ResponseField>

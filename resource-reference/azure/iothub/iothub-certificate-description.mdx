`azure_iothub_certificate_description` uploads a CA certificate to an IoT Hub, used to establish trust when verifying connecting device certificates.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iothub "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/iothub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own iothub certificate description"})

    		ubx.Resource(iothub.CertificateDescription, "example", iothub.CertificateDescriptionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

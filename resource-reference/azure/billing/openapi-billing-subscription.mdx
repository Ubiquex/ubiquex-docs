`azure_billing_openapi_billing_subscription` is the billing-side record of an Azure subscription, tracking which invoice section it's billed under and its own product/plan.

    package main

    import (
    	billing "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_billing_openapi/billing"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

## Input properties

<ResponseField name="quantity" type="number">
  The quantity of the source billing subscription that will be merged with the target billing subscription. Optional.
</ResponseField>

<ResponseField name="target_billing_subscription_name" type="string">
  The ID of the target billing subscription that will be merged with the source subscription provided in the request. Optional.
</ResponseField>

`azure_billing_openapi_product` is a purchased Azure offer (e.g. a reservation or a software plan) billed under a billing account, tracked independently of the subscription it's associated with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	billing "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/billing"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi product"})

    		ubx.Resource(billing.OpenapiProduct, "example", billing.OpenapiProductConfig{
    			DestinationInvoiceSectionId: "example",
    		})
    	}))
    }
    ```

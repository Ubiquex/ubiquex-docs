`azure_billing_openapi_billing_role_assignment` grants a principal a specific billing role (e.g. Owner, Contributor, Reader) scoped to a billing account, profile, or invoice section.

## Input properties

<ResponseField name="principal_id" type="string">
  The object id of the user to whom the role was assigned. Optional.
</ResponseField>

<ResponseField name="principal_puid" type="string">
  The principal PUID of the user to whom the role was assigned. Optional.
</ResponseField>

<ResponseField name="principal_tenant_id" type="string">
  The principal tenant id of the user to whom the role was assigned. Optional.
</ResponseField>

<ResponseField name="principal_type" type="string">
  The type of a role Assignment. Optional.
</ResponseField>

<ResponseField name="provisioning_state" type="string">
  The provisioning state of the resource during a long-running operation. Optional.
</ResponseField>

<ResponseField name="role_definition_id" type="string" required>
  The ID of the role definition. Required.
</ResponseField>

<ResponseField name="scope" type="string">
  The scope at which the role was assigned. Optional.
</ResponseField>

<ResponseField name="user_authentication_type" type="string">
  The authentication type of the user, whether Organization or MSA, of the user to whom the role was assigned. This is supported only for billing accounts with agreement type Enterprise Agreement. Optional.
</ResponseField>

<ResponseField name="user_email_address" type="string">
  The email address of the user to whom the role was assigned. This is supported only for billing accounts with agreement type Enterprise Agreement. Optional.
</ResponseField>

`azure_devtestlabs_dtl_environment` is a DevTest Labs environment, a set of resources deployed together from an Azure Resource Manager template (e.g. a multi-VM topology) and managed as a single unit within a lab.

## Example

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dtl environment"})

    		ubx.Resource(devtestlabs.DtlEnvironment, "example", devtestlabs.DtlEnvironmentConfig{
    			Name:       "example",

    		})
    	}))
    }

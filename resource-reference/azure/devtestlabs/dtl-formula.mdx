`azure_devtestlabs_dtl_formula` is a reusable VM creation template within a lab -- a saved set of VM size, image, and artifact choices lab users can create new virtual machines from without re-specifying every setting.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

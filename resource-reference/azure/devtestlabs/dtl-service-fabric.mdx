`azure_devtestlabs_dtl_service_fabric` is a Service Fabric cluster deployed and managed within a DevTest Lab, for testing Service Fabric-hosted applications in an isolated lab environment.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dtl service fabric"})

    		ubx.Resource(devtestlabs.DtlServiceFabric, "example", devtestlabs.DtlServiceFabricConfig{

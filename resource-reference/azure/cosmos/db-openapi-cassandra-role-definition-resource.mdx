`azure_cosmos_db_openapi_cassandra_role_definition_resource` defines a set of data-plane permissions that can be granted to identities accessing a Cosmos DB account through its Cassandra API.

<ResponseField name="properties" type="object">
  Azure Cosmos DB Cassandra Role Definition resource object. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="assignable_scopes" type="list(string)">
      A set of fully qualified Scopes at or below which Cassandra Role Assignments may be created using this Role Definition. This will allow application of this Role Definition on the entire database account or any underlying Database / Collection. Must have at least one element. Scopes higher than Database account are not enforceable as assignable Scopes. Note that resources referenced in assignable Scopes need not exist. Optional.
    </ResponseField>
    <ResponseField name="id" type="string">
      The path id for the Role Definition. Optional.
    </ResponseField>
    <ResponseField name="permissions" type="list(object)">
      The set of operations allowed through this Role Definition. Optional.

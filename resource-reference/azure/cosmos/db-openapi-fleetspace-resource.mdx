`azure_cosmos_db_openapi_fleetspace_resource` is a logical grouping of Cosmos DB account(s) within a fleet, optionally sharing a pooled throughput allocation across every account in the group.

## Properties

<ResponseField name="properties" type="object">
  Properties to update Azure Cosmos DB Fleetspace. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="data_regions" type="list(string)">
      List of data regions assigned to the fleetspace. Eg [westus2] Optional.
    </ResponseField>
    <ResponseField name="fleetspace_api_kind" type="string">
      The kind of API this fleetspace belongs to. Acceptable values: 'NoSQL' Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Enum to indicate current buildout status of the region. Optional.
    </ResponseField>
    <ResponseField name="service_tier" type="string">
      Service Tier for the fleetspace. GeneralPurpose types refers to single write region accounts that can be added to this fleetspace, whereas BusinessCritical refers to multi write region. Optional.
    </ResponseField>
    <ResponseField name="throughput_pool_configuration" type="object">
      Configuration for throughput pool in the fleetspace. Optional.
      <Expandable title="properties">
        <ResponseField name="dedicated_rus" type="number">
          Total dedicated throughput (RU/s) for fleetspace. Represents the sum of all manual provisioned throughput and all autoscale max RU/s across all shared throughput databases and dedicated throughput containers across all accounts in the fleetspace for 1 region. Optional.
        </ResponseField>
        <ResponseField name="max_consumable_rus" type="number">
          Maximum consumable throughput (RU/s) for fleetspace. Represents the maximum throughput that resources in the fleetspace can consume from the fleetspace's pool in 1 region. Optional.
        </ResponseField>
        <ResponseField name="max_throughput" type="number">
          Maximum throughput for the pool. Optional.
        </ResponseField>
        <ResponseField name="min_throughput" type="number">
          Minimum throughput for the pool. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

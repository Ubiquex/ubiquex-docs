`azure_cosmos_db_openapi_gremlin_role_assignment_resource` grants a Gremlin API role definition's own permissions to a specific identity within a Cosmos DB account.

<ResponseField name="properties" type="object">
  Azure Cosmos DB Gremlin Role Assignment resource object. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="principal_id" type="string">
      The unique identifier for the associated AAD principal in the AAD graph to which access is being granted through this Gremlin Role Assignment. Tenant ID for the principal is inferred using the tenant associated with the subscription. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Provisioning state of the resource. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="role_definition_id" type="string">
      The unique identifier for the associated Role Definition. Optional.
    </ResponseField>
    <ResponseField name="scope" type="string">
      The data plane resource path for which access is being granted through this Gremlin Role Assignment. Optional.
    </ResponseField>

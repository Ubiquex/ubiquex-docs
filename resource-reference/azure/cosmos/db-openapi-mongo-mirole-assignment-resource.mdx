`azure_cosmos_db_openapi_mongo_mirole_assignment_resource` grants a MongoDB role definition's own permissions to a specific identity on a Cosmos DB for MongoDB (vCore/MI) instance.

    <ResponseField name="principal_id" type="string">
      The unique identifier for the associated AAD principal in the AAD graph to which access is being granted through this MongoMI Role Assignment. Tenant ID for the principal is inferred using the tenant associated with the subscription. Optional.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">

    <ResponseField name="role_definition_id" type="string">

    </ResponseField>
    <ResponseField name="scope" type="string">

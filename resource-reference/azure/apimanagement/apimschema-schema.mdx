`azure_apimanagement_apimschema_schema` defines the data schema (JSON Schema, XML Schema) for request or response payloads on an API in Azure API Management, shared across operations.

## Example

    package main

    import (
    	apimanagement "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_apimanagement_apimschema/apimanagement"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

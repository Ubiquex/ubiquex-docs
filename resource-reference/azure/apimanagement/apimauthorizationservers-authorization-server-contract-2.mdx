`azure_apimanagement_apimauthorizationservers_authorization_server_contract_2` looks up a real OAuth2 authorization server registered with an Azure API Management instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apimanagement "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/apimanagement"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own apimauthorizationservers authorization server contract 2"})

    		ubx.Resource(apimanagement.ApimauthorizationserversAuthorizationServerContract2, "example", apimanagement.ApimauthorizationserversAuthorizationServerContract2Config{
    			Authsid: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="authsid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="properties" type="object">
  External OAuth authorization server settings Properties. Optional; if omitted, computed by Azure.
  <Expandable title="properties">
    <ResponseField name="authorization_endpoint" type="string" required>
      OAuth authorization endpoint. See http://tools.ietf.org/html/rfc6749#section-3.2. Required.
    </ResponseField>
    <ResponseField name="client_id" type="string" required>
      Client or app id registered with this authorization server. Required.
    </ResponseField>
    <ResponseField name="client_registration_endpoint" type="string" required>
      Optional reference to a page where client or app registration for this authorization server is performed. Contains absolute URL to entity being referenced. Required.
    </ResponseField>
    <ResponseField name="client_secret" type="string">
      Client or app secret registered with this authorization server. This property will not be filled on 'GET' operations! Use '/listSecrets' POST request to get the value. Optional.
    </ResponseField>
    <ResponseField name="display_name" type="string" required>
      User-friendly authorization server name. Required.
    </ResponseField>
    <ResponseField name="grant_types" type="list(string)" required>
      Form of an authorization grant, which the client uses to request the access token. Required.
    </ResponseField>
    <ResponseField name="use_in_api_documentation" type="bool">
      If true, the authorization server will be used in the API documentation in the developer portal. False by default if no value is provided. Optional.
    </ResponseField>
    <ResponseField name="use_in_test_console" type="bool">
      If true, the authorization server may be used in the developer portal test console. True by default if no value is provided. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

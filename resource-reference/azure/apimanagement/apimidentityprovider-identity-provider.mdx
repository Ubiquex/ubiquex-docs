`azure_apimanagement_apimidentityprovider_identity_provider` configures an external identity provider (Microsoft Entra ID, Google, Facebook) developers can sign in to the Azure API Management developer portal with.

## Properties

<ResponseField name="properties" type="object">
  The external Identity Providers like Facebook, Google, Microsoft, Twitter or Azure Active Directory which can be used to enable access to the API Management service developer portal for all users. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="client_id" type="string" required>
      Client Id of the Application in the external Identity Provider. It is App ID for Facebook login, Client ID for Google login, App ID for Microsoft. Required.
    </ResponseField>
    <ResponseField name="client_secret" type="string" required>
      Client secret of the Application in external Identity Provider, used to authenticate login request. For example, it is App Secret for Facebook login, API Key for Google login, Public Key for Microsoft. This property will not be filled on 'GET' operations! Use '/listSecrets' POST request to get the value. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

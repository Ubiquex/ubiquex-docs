`azure_apimanagement_apimpolicyfragments_policy_fragment` is a reusable snippet of policy XML that can be included from multiple policy definitions in Azure API Management.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apimanagement "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/apimanagement"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own apimpolicyfragments policy fragment"})

    		ubx.Resource(apimanagement.ApimpolicyfragmentsPolicyFragment, "example", apimanagement.ApimpolicyfragmentsPolicyFragmentConfig{
    			Id: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="properties" type="object">
  The Logger entity in API Management represents an event sink that you can use to log API Management events. Currently the Logger entity supports logging API Management events to Azure Event Hubs. Optional; if omitted, computed by Azure.
  <Expandable title="properties">
    <ResponseField name="credentials" type="map(string)">
      The name and SendRule connection string of the event hub for azureEventHub logger. Instrumentation key for applicationInsights logger. Optional.
    </ResponseField>
    <ResponseField name="description" type="string">
      Logger description. Optional.
    </ResponseField>
    <ResponseField name="is_buffered" type="bool">
      Whether records are buffered in the logger before publishing. Default is assumed to be true. Optional.
    </ResponseField>
    <ResponseField name="logger_type" type="string" required>
      Logger type. Required.
    </ResponseField>
    <ResponseField name="resource_id" type="string">
      Azure Resource Id of a log target (either Azure Event Hub resource or Azure Application Insights resource). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_eventgrid_eventgrid_client_group` groups related Event Grid MQTT client(s) together by a matching expression, so permission bindings and topic spaces can target the group instead of individual clients.

    package main

    	ubx.Main(ubx.Stack("payments", func() {

    	}))

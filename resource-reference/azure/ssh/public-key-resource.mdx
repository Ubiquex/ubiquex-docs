---
title: "azure_ssh_public_key_resource"
description: "`azure_ssh_public_key_resource` stores an SSH public key in Azure as its own standalone resource, independent of any single VM."
---

Once created (generated fresh as RSA or Ed25519, or uploaded from an existing key you already have), the same stored key can be attached to any number of new VM deployments instead of pasting the raw key text in every time.

## Properties

<ResponseField name="properties" type="object">
  Properties of the SSH public key. Optional; if omitted, computed by Azure.
  <Expandable title="properties">
    <ResponseField name="public_key" type="string">
      SSH public key used to authenticate to a virtual machine through ssh. If this property is not initially provided when the resource is created, the publicKey property will be populated when generateKeyPair is called. If the public key is provided upon resource creation, the provided public key needs to be at least 2048-bit and in ssh-rsa format. Optional.

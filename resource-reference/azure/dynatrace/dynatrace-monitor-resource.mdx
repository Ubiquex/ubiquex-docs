`azure_dynatrace_dynatrace_monitor_resource` is a Dynatrace resource on Azure, the top-level integration that sends Azure telemetry to a linked Dynatrace environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dynatrace "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/dynatrace"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dynatrace monitor resource"})

    		ubx.Resource(dynatrace.MonitorResource, "example", dynatrace.MonitorResourceConfig{
    			Properties: map[string]any{"dynatrace_environment_properties": map[string]any{"account_info": map[string]any{"account_id": "example"}}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

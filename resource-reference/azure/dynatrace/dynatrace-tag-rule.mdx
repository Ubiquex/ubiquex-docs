## Properties

<ResponseField name="properties" type="object" required>
  Properties for the Tag rules resource of a Monitor account. Required.
  <Expandable title="properties">
    <ResponseField name="log_rules" type="object">
      Set of rules for sending logs for the Monitor resource. Optional.
      <Expandable title="properties">
        <ResponseField name="filtering_tags" type="list(object)">
          List of filtering tags to be used for capturing logs. This only takes effect if SendActivityLogs flag is enabled. If empty, all resources will be captured. If only Exclude action is specified, the rules will apply to the list of all available resources. If Include actions are specified, the rules will only include resources with the associated tags. Optional.
          <Expandable title="properties">
            <ResponseField name="action" type="string">
              Whether resources carrying this tag are included in or excluded from log forwarding. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="name" type="string">
              The resource's own name, unique within its parent scope. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value" type="string">
              The tag value this log filtering rule matches. Optional; if omitted, computed by Microsoft Azure. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="send_aad_logs" type="string">
          Indicates whether AAD logs are being sent. Optional.
        </ResponseField>
        <ResponseField name="send_activity_logs" type="string">
          Indicates whether activity logs are being sent. Optional.
        </ResponseField>
        <ResponseField name="send_subscription_logs" type="string">
          Indicates whether subscription logs are being sent. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>

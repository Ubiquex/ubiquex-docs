`azure_recoveryservicessiterecovery_service_vcenter` registers a VMware vCenter Server with Azure Site Recovery, letting it discover and replicate the VM(s) it manages.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service vcenter"})

## Input properties

<ResponseField name="properties" type="object">
  The properties of an add vCenter request. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="friendly_name" type="string">
      The friendly name of the vCenter. Optional.
    </ResponseField>
    <ResponseField name="ip_address" type="string">
      The IP address of the vCenter to be discovered. Optional.
    </ResponseField>
    <ResponseField name="port" type="string">
      The port number for discovery. Optional.
    </ResponseField>
    <ResponseField name="process_server_id" type="string">
      The process server Id from where the discovery is orchestrated. Optional.
    </ResponseField>
    <ResponseField name="run_as_account_id" type="string">
      The account Id which has privileges to discover the vCenter. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_containerservice_managedclusters_snapshot` captures a point-in-time configuration snapshot of an AKS cluster or node pool, usable as a template for creating new ones with the same settings.

## Properties

<ResponseField name="properties" type="object">
  Properties used to configure a node pool snapshot. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="creation_data" type="object">
      Data used when creating a target resource from a source resource. Optional.
      <Expandable title="properties">
        <ResponseField name="source_resource_id" type="string">
          This is the ARM ID of the source object to be used to create the target object. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="enable_fips" type="bool">
      Whether to use a FIPS-enabled OS. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="kubernetes_version" type="string">
      The version of Kubernetes. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="node_image_version" type="string">
      The version of node image. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="os_sku" type="string">
      Specifies the OS SKU used by the agent pool. The default is Ubuntu if OSType is Linux. The default is Windows2019 when Kubernetes &lt;= 1.24 or Windows2022 when Kubernetes &gt;= 1.25 if OSType is Windows. Optional.
    </ResponseField>
    <ResponseField name="os_type" type="string">
      The operating system type. The default is Linux. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="snapshot_type" type="string">
      The type of a snapshot. The default is NodePool. Optional.
    </ResponseField>
    <ResponseField name="vm_size" type="string">
      The size of the VM. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

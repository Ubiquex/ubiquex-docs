`azure_containerservice_managedclusters_run_command_result` reports the output of a command run against a private AKS cluster's own API server via the Run Command feature, without needing direct network access to it.

## Example

    ```go
    // go.mod: replace github.com/ubiquex/ubx-sdk-azure/sdk/go => ./local-sdk/azure_containerservice_managedclusters/sdk/go
    package main

    import (
    	containerservice "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure_containerservice_managedclusters/containerservice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own managedclusters run command result"})

    		ubx.Resource(containerservice.ManagedclustersRunCommandResult, "example", containerservice.ManagedclustersRunCommandResultConfig{
    			Command:      "example",
    			ClusterToken: "example",
    			Context:      "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cluster_token" type="string">
  AuthToken issued for AKS AAD Server App. Optional.
</ResponseField>

<ResponseField name="command" type="string" required>
  The command to run. Required.
</ResponseField>

<ResponseField name="context" type="string">
  A base64 encoded zip file containing the files required by the command. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The command id. Computed by Microsoft Azure after `ship`.
</ResponseField>

<ResponseField name="properties" type="object">
  The results of a run command Computed by Microsoft Azure after `ship`.
  <Expandable title="properties">
    <ResponseField name="exit_code" type="number">
      The exit code of the command Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="finished_at" type="string">
      The time when the command finished. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="logs" type="string">
      The command output. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      provisioning State Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="reason" type="string">
      An explanation of why provisioningState is set to failed (if so). Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="started_at" type="string">
      The time when the command started. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_operationalinsights_openapi_log_analytics_query_pack` is a shareable collection of saved Log Analytics query/queries, reusable across multiple workspace(s) rather than saved to just one.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi log analytics query pack"})

    		ubx.Resource(operationalinsights.OpenapiLogAnalyticsQueryPack, "example", operationalinsights.OpenapiLogAnalyticsQueryPackConfig{
    			Properties: map[string]any{"provisioning_state": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="properties" type="object" required>
  Properties that define a Log Analytics QueryPack resource. Required.
  <Expandable title="properties">
    <ResponseField name="provisioning_state" type="string">
      Current state of this QueryPack: whether or not is has been provisioned within the resource group it is defined. Users cannot change this value but are able to read from it. Values will include Succeeded, Deploying, Canceled, and Failed. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="query_pack_id" type="string">
      The unique ID of your application. This field cannot be changed. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="time_created" type="string">
      Creation Date for the Log Analytics QueryPack, in ISO 8601 format. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="time_modified" type="string">
      Last modified date of the Log Analytics QueryPack, in ISO 8601 format. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

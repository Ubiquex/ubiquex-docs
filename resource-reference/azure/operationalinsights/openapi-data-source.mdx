`azure_operationalinsights_openapi_data_source` configures a legacy Log Analytics data collection source (e.g. Windows event logs) for a connected agent-based machine.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	operationalinsights "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/operationalinsights"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi data source"})

    		ubx.Resource(operationalinsights.OpenapiDataSource, "example", operationalinsights.OpenapiDataSourceConfig{
    			Kind:       "example",
    			Properties: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="etag" type="string">
  The ETag of the data source. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="kind" type="string" required>
  The kind of the DataSource. Required.
</ResponseField>

<ResponseField name="properties" type="any" required>
  The data source properties in raw json format, each kind of data source have it's own schema. Required.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Resource tags. Optional; if omitted, computed by Microsoft Azure.

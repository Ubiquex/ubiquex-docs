`azure_recoveryservicesbackup_bms_tiering_cost_info` reports the estimated cost impact of moving Azure Backup recovery point(s) to a lower-cost storage tier (e.g. Archive).

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

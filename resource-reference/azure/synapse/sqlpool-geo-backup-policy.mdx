## Properties

<ResponseField name="kind" type="string">
  Kind of geo backup policy. This is metadata used for the Azure portal experience. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="location" type="string">
  Backup policy location. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object" required>
  The properties of the geo backup policy. Required.
  <Expandable title="properties">
    <ResponseField name="state" type="string" required>
      The state of the geo backup policy. Required.
    </ResponseField>
    <ResponseField name="storage_type" type="string">
      The storage type of the geo backup policy. Computed by Microsoft Azure after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

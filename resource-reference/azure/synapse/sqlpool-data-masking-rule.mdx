`azure_synapse_sqlpool_data_masking_rule` defines a single dynamic data masking rule (a column and masking function) applied within a Synapse dedicated SQL pool's own masking policy.

## Properties

<ResponseField name="kind" type="string">
  The kind of Data Masking Rule. Metadata, used for Azure portal. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="location" type="string">
  The location of the data masking rule. Optional; if omitted, computed by Microsoft Azure.
</ResponseField>

<ResponseField name="properties" type="object">
  The properties of a Sql pool data masking rule. Optional; if omitted, computed by Microsoft Azure.
  <Expandable title="properties">
    <ResponseField name="alias_name" type="string">
      The alias name. This is a legacy parameter and is no longer used. Optional.
    </ResponseField>
    <ResponseField name="column_name" type="string" required>
      The column name on which the data masking rule is applied. Required.
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique identifier of this synapse sqlpool data masking rule. Computed by Microsoft Azure after `ship`.
    </ResponseField>
    <ResponseField name="masking_function" type="string" required>
      The masking function that is used for the data masking rule. Required.
    </ResponseField>
    <ResponseField name="number_from" type="string">
      The numberFrom property of the masking rule. Required if maskingFunction is set to Number, otherwise this parameter will be ignored. Optional.
    </ResponseField>
    <ResponseField name="number_to" type="string">
      The numberTo property of the data masking rule. Required if maskingFunction is set to Number, otherwise this parameter will be ignored. Optional.
    </ResponseField>
    <ResponseField name="prefix_size" type="string">
      If maskingFunction is set to Text, the number of characters to show unmasked in the beginning of the string. Otherwise, this parameter will be ignored. Optional.
    </ResponseField>
    <ResponseField name="replacement_string" type="string">
      If maskingFunction is set to Text, the character to use for masking the unexposed part of the string. Otherwise, this parameter will be ignored. Optional.
    </ResponseField>
    <ResponseField name="rule_state" type="string">
      The rule state. Used to delete a rule. To delete an existing rule, specify the schemaName, tableName, columnName, maskingFunction, and specify ruleState as disabled. However, if the rule doesn't already exist, the rule will be created with ruleState set to enabled, regardless of the provided value of ruleState. Optional.
    </ResponseField>
    <ResponseField name="schema_name" type="string" required>
      The schema name on which the data masking rule is applied. Required.
    </ResponseField>
    <ResponseField name="suffix_size" type="string">
      If maskingFunction is set to Text, the number of characters to show unmasked at the end of the string. Otherwise, this parameter will be ignored. Optional.
    </ResponseField>
    <ResponseField name="table_name" type="string" required>
      The table name on which the data masking rule is applied. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`azure_privatedns_privatedns_virtual_network_link` links a virtual network to a Private DNS zone, enabling resources in that network to resolve the zone's own record(s) (and optionally register their own via autoregistration).

      The resolution policy on the virtual network link. Only applicable for virtual network links to privatelink zones, and for A,AAAA,CNAME queries.

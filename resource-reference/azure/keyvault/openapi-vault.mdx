`azure_keyvault_openapi_vault` is an Azure Key Vault, the managed store for key(s), secret(s), and certificate(s) with its own access policy and audit logging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	keyvault "github.com/ubiquex/ubx-sdk-azure/sdk/go/azure/keyvault"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own openapi vault"})

    		ubx.Resource(keyvault.OpenapiVault, "example", keyvault.OpenapiVaultConfig{
    			Location:   "example",
    			Properties: map[string]any{"sku": map[string]any{"name": "example-name"}},
    		})
    	}))
    }
    ```

When false, the key vault will use the access policies specified in vault properties, and any policy stored on Azure Resource Manager will be ignored. If null or not specified, the vault is created with the default value of false. Note that management actions are always authorized with RBAC. Optional.

title: "azure_dedicated_host"
description: "`azure_dedicated_host` maps to one physical server in an Azure datacenter..."
---

`azure_dedicated_host` maps to one physical server in an Azure datacenter, allocated entirely to your own subscription -- no other customer's VMs are ever placed on it. Beyond the isolation itself, a dedicated host gives you Azure Hybrid Benefit licensing, control over when platform maintenance actually lands on your hardware, and a say in which of your own workloads share the same physical memory and storage. Each host is created inside a host group and can run multiple VMs at once, as long as they're all from the same size series.

---
title: "azure_dedicated_host_group"
description: "`azure_dedicated_host_group` is the resource that represents a collection of dedicated hosts."
---

It's created in a specific region and, if you want zone-level fault isolation, a specific availability zone -- every host you add to the group inherits that placement. The group also controls whether new VMs get placed onto its hosts automatically or only when you explicitly pick a host.

## Properties

<ResponseField name="properties" type="object">
  Dedicated Host Group Properties. Optional; if omitted, computed by Azure.
  <Expandable title="properties">
    <ResponseField name="additional_capabilities" type="object">
      Enables or disables a capability on the dedicated host group. Minimum api-version: 2022-03-01. Optional.
      <Expandable title="properties">
        <ResponseField name="ultra_ssdenabled" type="bool">
          The flag that enables or disables a capability to have UltraSSD Enabled Virtual Machines on Dedicated Hosts of the Dedicated Host Group. For the Virtual Machines to be UltraSSD Enabled, UltraSSDEnabled flag for the resource needs to be set true as well. The value is defaulted to 'false' when not provided. Please refer to https://docs.microsoft.com/en-us/azure/virtual-machines/disks-enable-ultra-ssd for more details on Ultra SSD feature. **Note:** The ultraSSDEnabled setting can only be enabled for Host Groups that are created as zonal. Minimum api-version: 2022-03-01. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="hosts" type="list(object)">
      A list of references to all dedicated hosts in the dedicated host group. Computed by Azure after `ship`.
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          Optional; if omitted, computed by Azure.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="instance_view" type="object">
      Optional.
      <Expandable title="properties">
        <ResponseField name="hosts" type="list(object)">
          List of instance view of the dedicated hosts under the dedicated host group. Optional.
          <Expandable title="properties">
            <ResponseField name="name" type="string">
              The name of the dedicated host. Optional; if omitted, computed by Azure. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="platform_fault_domain_count" type="number" required>
      Number of fault domains that the host group can span. Required.
    </ResponseField>
    <ResponseField name="support_automatic_placement" type="bool">
      Specifies whether virtual machines or virtual machine scale sets can be placed automatically on the dedicated host group. Automatic placement means resources are allocated on dedicated hosts, that are chosen by Azure, under the dedicated host group. The value is defaulted to 'false' when not provided. Minimum api-version: 2020-06-01. Optional.
    </ResponseField>

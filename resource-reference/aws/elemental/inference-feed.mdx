`aws_elemental_inference_feed` is the top-level real resource in AWS Elemental Inference, a fully managed AI service that transforms live broadcast video in parallel with encoding into vertical crops and highlight clips for mobile and social platforms, TikTok, Instagram Reels, YouTube Shorts among them, in real time. A feed starts in a CREATING state and becomes AVAILABLE once ready to configure outputs against. AWS Elemental Inference reached general availability February 24, 2026, genuinely new enough that this session verified it live rather than trusting a remembered description.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elementalinference "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elementalinference"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own inference feed"})

    		ubx.Resource(elementalinference.Feed, "example", elementalinference.FeedConfig{
    			Name:    "example",
    			Outputs: []map[string]any{{"name": "example-name"}},
    			Tags:    "example",
    		})
    	}))
    }
    ```

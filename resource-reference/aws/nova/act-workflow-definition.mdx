`aws_nova_act_workflow_definition` defines a real, automated browser workflow, combining natural language instructions with Python code, for Amazon Nova Act, an AWS service for building and deploying AI agents that reliably automate production UI workflows, form-filling, search and extraction, shopping and booking, and QA testing, at scale.

## Input properties

<ResponseField name="description" type="string">
  An optional description of the workflow definition's purpose and functionality. Optional.
</ResponseField>

<ResponseField name="export_config" type="object">
  Configuration settings for exporting workflow execution data and logs to Amazon S3. Optional.
  <Expandable title="properties">
    <ResponseField name="s3_bucket_name" type="string" required>
      The name of the Amazon S3 bucket for exporting workflow data. Required.
    </ResponseField>
    <ResponseField name="s3_key_prefix" type="string">
      An optional prefix for Amazon S3 object keys to organize exported data. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the workflow definition. Must be unique within your account and region. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the workflow definition. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when the workflow definition was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the workflow definition. Computed by AWS after `ship`.
</ResponseField>

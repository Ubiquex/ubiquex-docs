`aws_pcaconnector_scep_connector` creates a real connector that lets mobile devices and networking gear enroll for certificates from an `aws_acmpca_certificate_authority` using the Simple Certificate Enrollment Protocol, the mechanism a mobile device management solution typically calls.

## Input properties

<ResponseField name="certificate_authority_arn" type="string" required>
  The ARN of the AWS Private CA (Certificate Authority) that the SCEP connector uses to sign and issue certificates. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="mobile_device_management" type="any">
  This field specifies the mobile device management (MDM) configuration for the SCEP connector, which enables integration with an MDM system like Microsoft Intune by providing the necessary Intune credentials and domain details for challenge password delivery. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

<ResponseField name="vpc_endpoint_id" type="string">
  The ID of the VPC endpoint that this SCEP connector uses to privately receive SCEP traffic within your VPC. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="connector_arn" type="string">

</ResponseField>

<ResponseField name="endpoint" type="string">

<ResponseField name="open_id_configuration" type="object">
  The OpenID Connect (OIDC) configuration for the SCEP connector, containing the issuer URL and JSON Web Key Set (JWKS) endpoint used to authenticate SCEP client requests. Computed by AWS after `ship`. **(AI-inferred)**

    </ResponseField>
    <ResponseField name="subject" type="string">
      The subject claim that must be present in the OpenID Connect token used to authenticate requests to the SCEP connector, enabling validation of the token's 'sub' field. Optional. **(AI-inferred)**

  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">

`aws_pcaconnector_ad_directory_registration` registers a real Active Directory with AWS Private CA Connector for AD, the prerequisite step an `aws_pcaconnector_ad_connector` for that directory depends on.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	pcaconnector "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/pcaconnector"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own ad directory registration"})

    		ubx.Resource(pcaconnector.AdDirectoryRegistration, "ci-runner", pcaconnector.AdDirectoryRegistrationConfig{
    			DirectoryId: "example",
    			Tags:        "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="directory_id" type="string" required>
  The identifier of the AWS Managed Microsoft Active Directory that is registered with the Private CA Connector for Active Directory. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Assigns metadata tags to the PCa Connector for AD directory registration, which can be used for cost allocation, access control, and resource organization. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="directory_registration_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this directory registration within AWS Private CA Connector for Active Directory. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

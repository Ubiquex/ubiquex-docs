`aws_pcaconnector_ad_connector` creates a real connector between an `aws_acmpca_certificate_authority` and an Active Directory domain, letting AWS Private CA act as a drop-in replacement for a self-managed enterprise CA and issue certificates to domain-joined objects through AD's own auto-enrollment and group policy features, without deploying or patching local agents.

## Example

    ```go
    package main

    import (
    	pcaconnectorad "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pcaconnectorad"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ad connector"})

    		ubx.Resource(pcaconnectorad.Connector, "example", pcaconnectorad.ConnectorConfig{
    			CertificateAuthorityArn: "arn:aws:iam::123456789012:policy/example",
    			DirectoryId:             "example",
    			VpcInformation:          map[string]any{"security_group_ids": []string{"example"}},
    			Tags:                    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate_authority_arn" type="string" required>
  The Amazon Resource Name (ARN) of the AWS Private CA certificate authority that will issue certificates for the Active Directory connector. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="directory_id" type="string" required>
  The identifier of the AWS Managed Microsoft AD directory that this connector is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Tags (key-value pairs) to associate with the PCA Connector for Active Directory resource, used for identifying, organizing, and managing the connector. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpc_information" type="object" required>
  The VPC information for the connector, specifying the security groups that allow the connector to communicate with the Active Directory in your VPC. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="ip_address_type" type="string">
      Specifies whether the connector uses only IPv4 addresses or both IPv4 and IPv6 (dual-stack) addresses within the VPC, with allowed values IPV4 and DUALSTACK. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="security_group_ids" type="list(string)" required>
      Specifies the IDs of the security groups that AWS Private CA Connector for Active Directory uses to securely communicate with your directory in the VPC. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

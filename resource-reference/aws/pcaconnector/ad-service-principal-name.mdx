`aws_pcaconnector_ad_service_principal_name` registers a real Kerberos service principal name in Active Directory on behalf of an `aws_pcaconnector_ad_connector`, letting the connector authenticate to the domain the way a domain-joined service would.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	pcaconnector "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/pcaconnector"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own ad service principal name"})

    		ubx.Resource(pcaconnector.AdServicePrincipalName, "ci-runner", pcaconnector.AdServicePrincipalNameConfig{
    			ConnectorArn:             "arn:aws:iam::123456789012:policy/ci",
    			DirectoryRegistrationArn: "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="connector_arn" type="string" required>
  The ARN of the Active Directory connector to which this service principal name is registered. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="directory_registration_arn" type="string" required>
  The ARN of the directory registration that this service principal name belongs to, linking the SPN to the associated AWS Managed Microsoft Active Directory. Required. **(AI-inferred)**

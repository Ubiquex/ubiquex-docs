`aws_data_zone_project_profile` is a real, reusable template an `aws_data_zone_project` can be created from within a domain, standardizing what resources and environments a new project of a given kind starts with rather than every project being configured individually from a blank slate.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datazone "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/datazone"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own project profile"})

    		ubx.Resource(datazone.ProjectProfile, "example", datazone.ProjectProfileConfig{
    			Name:                           "example",
    			AllowCustomProjectResourceTags: true,
    			Description:                    "Managed by ubx.",
    			DomainIdentifier:               "example",
    			DomainUnitIdentifier:           "example",
    			ProjectResourceTags:            []map[string]any{{"is_value_editable": true}},
    			ProjectResourceTagsDescription: "example",
    			Status:                         "example",
    		})
    	}))
    }
    ```
  </Tab>

    def describe():

## Input properties

<ResponseField name="allow_custom_project_resource_tags" type="bool">
  Indicates whether users are allowed to add custom tags to project resources (such as data assets or environments) when using this project profile. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-provided description of the project profile, which helps identify and document the purpose or characteristics of the profile within Amazon DataZone. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_identifier" type="string">
  The identifier of the Amazon DataZone domain in which the project profile is created. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_unit_identifier" type="string">
  The unique identifier of the Amazon DataZone domain unit that this project profile is associated with, used to scope the profile to a specific domain unit. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  Required.
</ResponseField>

<ResponseField name="project_resource_tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="is_value_editable" type="bool">
      This boolean indicates whether the value of the project resource tag is editable by project members, so a value of false enforces a fixed tag value across project resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="key" type="string">
      Specifies the key of a tag applied to resources associated with an Amazon DataZone project profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value for a tag key in a project_resource_tags entry, which assigns a tag to the project resources of this AWS Data Zone project profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="project_resource_tags_description" type="string">
  Optional.
</ResponseField>

<ResponseField name="status" type="string">
  Optional.
</ResponseField>

<ResponseField name="use_default_configurations" type="bool">
  Optional.
</ResponseField>

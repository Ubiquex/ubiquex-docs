`aws_data_zone_form_type` defines a real, structured metadata schema, business glossary terms, custom attributes, attached to assets cataloged inside an `aws_data_zone_domain`, so catalog entries carry consistent, richer context than a bare technical schema alone.

## Input properties

<ResponseField name="description" type="string">
  The description of this Amazon DataZone metadata form type. Optional.
</ResponseField>

<ResponseField name="domain_identifier" type="string" required>
  The ID of the Amazon DataZone domain in which this metadata form type is created. Required.
</ResponseField>

<ResponseField name="model" type="object" required>
  Indicates the smithy model of the API. Required.
  <Expandable title="properties">
    <ResponseField name="smithy" type="string">
      The Smithy model definition that specifies the structure and validation rules for the form type. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of this Amazon DataZone metadata form type. Required.
</ResponseField>

<ResponseField name="owning_project_identifier" type="string" required>
  The ID of the Amazon DataZone project that owns this metadata form type. Required.
</ResponseField>

<ResponseField name="status" type="string">
  The status of this Amazon DataZone metadata form type. Optional.
</ResponseField>

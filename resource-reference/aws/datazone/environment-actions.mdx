`aws_data_zone_environment_actions` defines a real, custom action, a link to an external console or tool, available on an `aws_data_zone_environment`, extending what a data user can do directly from DataZone's own interface.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datazone "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/datazone"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment actions"})

    		ubx.Resource(datazone.EnvironmentActions, "example", datazone.EnvironmentActionsConfig{
    			Name:                  "example",
    			Description:           "Managed by ubx.",
    			DomainIdentifier:      "example",
    			EnvironmentIdentifier: "example",
    			Identifier:            "example",
    			Parameters:            map[string]any{"uri": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the Amazon DataZone environment action. Optional.
</ResponseField>

<ResponseField name="domain_identifier" type="string">
  The identifier of the Amazon DataZone domain in which the environment would be created. Optional.
</ResponseField>

<ResponseField name="environment_identifier" type="string">
  The identifier of the Amazon DataZone environment in which the action is taking place Optional.
</ResponseField>

<ResponseField name="identifier" type="string">
  The ID of the Amazon DataZone environment action. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the environment action. Required.
</ResponseField>

<ResponseField name="parameters" type="object">
  The parameters of the console link specified as part of the environment action Optional.
  <Expandable title="properties">
    <ResponseField name="uri" type="string">
      The URI of the console link specified as part of the environment action. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="domain_id" type="string">
  The identifier of the Amazon DataZone domain in which the environment is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="environment_id" type="string">
  The identifier of the Amazon DataZone environment in which the action is taking place Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the Amazon DataZone environment action. Computed by AWS after `ship`.
</ResponseField>

`aws_data_zone_environment_profile` is a real, reusable configuration template an `aws_data_zone_environment` gets provisioned from, so every project's environment of a given kind is set up consistently rather than configured from scratch each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datazone "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/datazone"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment profile"})

    		ubx.Resource(datazone.EnvironmentProfile, "example", datazone.EnvironmentProfileConfig{
    			AwsAccountId:                   "example",
    			AwsAccountRegion:               "example",
    			DomainIdentifier:               "example",
    			EnvironmentBlueprintIdentifier: "example",
    			Name:                           "example",
    			ProjectIdentifier:              "example",
    			Description:                    "Managed by ubx.",
    			UserParameters:                 []map[string]any{{"name": "example-name"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="aws_account_id" type="string" required>
  The AWS account in which the Amazon DataZone environment is created. Required.
</ResponseField>

<ResponseField name="aws_account_region" type="string" required>
  The AWS region in which this environment profile is created. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of this Amazon DataZone environment profile. Optional.
</ResponseField>

<ResponseField name="domain_identifier" type="string" required>
  The ID of the Amazon DataZone domain in which this environment profile is created. Required.
</ResponseField>

<ResponseField name="environment_blueprint_identifier" type="string" required>
  The ID of the blueprint with which this environment profile is created. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of this Amazon DataZone environment profile. Required.
</ResponseField>

<ResponseField name="project_identifier" type="string" required>
  The identifier of the project in which to create the environment profile. Required.
</ResponseField>

<ResponseField name="user_parameters" type="list(object)">
  The user parameters of this Amazon DataZone environment profile. Optional.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of a user-defined parameter configured in the environment profile, used to match or reference a parameter declared by the associated environment blueprint when provisioning an environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Sets the actual value for a user parameter in the environment profile, which is supplied as the value when the environment is provisioned from this profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

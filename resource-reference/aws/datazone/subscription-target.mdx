`aws_data_zone_subscription_target` is the real, actual destination, a specific Redshift database or S3 location, that data gets delivered to once an `aws_data_zone_project` member's subscription request to an `aws_data_zone_data_source`'s asset is approved.

## Input properties

<ResponseField name="applicable_asset_types" type="list(string)" required>
  The asset types that can be included in the subscription target. Required.
</ResponseField>

<ResponseField name="authorized_principals" type="list(string)" required>
  The authorized principals of the subscription target. Required.
</ResponseField>

<ResponseField name="domain_identifier" type="string" required>
  The ID of the Amazon DataZone domain in which subscription target would be created. Required.
</ResponseField>

<ResponseField name="environment_identifier" type="string" required>
  The ID of the environment in which subscription target would be created. Required.
</ResponseField>

<ResponseField name="manage_access_role" type="string">
  The manage access role that is used to create the subscription target. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the subscription target. Required.
</ResponseField>

<ResponseField name="provider" type="string">
  The provider of the subscription target. Optional.
</ResponseField>

<ResponseField name="subscription_target_config" type="list(object)" required>
  The configuration of the subscription target. Required.
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The JSON-encoded configuration payload for a subscription target form, which contains the target-specific parameters (such as the S3 bucket path, Glue database name, or Redshift cluster) required for delivering subscribed data. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="form_name" type="string">
      The name of the metadata form that defines the schema and parameters for this AWS DataZone subscription target configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of the subscription target. Required.
</ResponseField>

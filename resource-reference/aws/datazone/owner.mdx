`aws_data_zone_owner` assigns real ownership of a domain unit or `aws_data_zone_project` to a specific user or group inside an `aws_data_zone_domain`, the accountable party DataZone's governance workflows route approvals and questions to.

## Input properties

<ResponseField name="domain_identifier" type="string" required>
  The ID of the domain in which you want to add the entity owner. Required.
</ResponseField>

<ResponseField name="entity_identifier" type="string" required>
  The ID of the entity to which you want to add an owner. Required.
</ResponseField>

<ResponseField name="entity_type" type="string" required>
  The type of an entity. Required.
</ResponseField>

<ResponseField name="owner" type="any" required>
  The properties of a domain unit's owner. Required.
</ResponseField>

## Output properties

<ResponseField name="owner_identifier" type="string">
  Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="owner_type" type="string">
  Indicates whether the owner associated with the DataZone resource is a user or a group, as determined by the service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

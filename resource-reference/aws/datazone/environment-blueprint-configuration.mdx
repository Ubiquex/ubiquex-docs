`aws_data_zone_environment_blueprint_configuration` sets domain-wide defaults, IAM roles, regions, for how an `aws_data_zone_environment_profile` and the environments built from it are actually allowed to be provisioned within an `aws_data_zone_domain`.

## Input properties

<ResponseField name="domain_identifier" type="string" required>
  The unique identifier of the Amazon Data Zone domain for which this environment blueprint configuration is defined. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled_regions" type="list(string)" required>
  The list of AWS Regions in which this environment blueprint configuration is enabled and can be used to provision Data Zone environments. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="environment_blueprint_identifier" type="string" required>
  The unique identifier (name or ID) of the Amazon DataZone environment blueprint that this configuration applies to within the domain. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="environment_role_permission_boundary" type="string">
  The ARN of an IAM policy used as the permission boundary for the environment's service role, limiting the maximum permissions that can be granted to the role. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="global_parameters" type="any">
  Region-agnostic environment blueprint parameters. Optional.
</ResponseField>

<ResponseField name="manage_access_role_arn" type="string">
  The ARN of the IAM role that permits Amazon DataZone to manage access to resources created for the environment blueprint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioning_configurations" type="list(object)">
  Specifies the list of AWS regions where environments can be provisioned from this blueprint, along with the IAM environment role ARN to use for each region. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="lake_formation_configuration" type="object">
      Defines the AWS Lake Formation configuration for the environment blueprint, specifying how Data Zone provisions and manages Lake Formation data lake resources, including trusted service principals and location registration settings, when creating environments from the blueprint. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="location_registration_exclude_s3_locations" type="list(string)">
          Defines a list of S3 paths to exclude from Lake Formation location registration when provisioning the environment, preventing those locations from being registered as data lake locations. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="location_registration_role" type="string">
          The ARN of the IAM role that AWS DataZone uses to register data lake locations with Lake Formation for this environment blueprint configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="provisioning_role_arn" type="string">
  The ARN of the IAM role that AWS DataZone assumes to provision and manage resources for environments created from this blueprint configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="regional_parameters" type="list(object)">
  Specifies a list of region-specific parameter settings, where each item contains an AWS Region and a set of key-value configuration parameters applied to the environment blueprint in that region. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="parameters" type="any">
      The parameters map within each regional parameter set provides the blueprint configuration key-value pairs to be used for environments in that specific AWS region, allowing region-specific overrides. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="region" type="string">
      The AWS region (e.g., us-east-1) to which this set of regional blueprint configuration parameters applies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

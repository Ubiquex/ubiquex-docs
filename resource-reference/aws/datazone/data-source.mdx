`aws_data_zone_data_source` publishes real data assets, from the AWS Glue Data Catalog or Amazon Redshift, into an `aws_data_zone_domain`'s own catalog, the actual mechanism by which raw AWS data becomes discoverable and requestable inside DataZone.

## Example

    ```go
    	datazone "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/datazone"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own data source"})

    		ubx.Resource(datazone.DataSource, "example", datazone.DataSourceConfig{
    			DomainIdentifier:     "example",
    			Name:                 "example",
    			ProjectIdentifier:    "example",
    			Type:                 "example",
    			AssetFormsInput:      []map[string]any{{"content": "example"}},
    			Configuration:        map[string]any{"glue_run_configuration": map[string]any{"auto_import_data_quality_result": true}},
    			ConnectionIdentifier: "example",
    			Description:          "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="asset_forms_input" type="list(object)">
  The metadata forms that are to be attached to the assets that this data source works with. Optional.
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The JSON-encoded content of the asset form input, which provides the metadata values to be associated with the asset when the data source is run. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="form_name" type="string">
      The name of the metadata form to associate with each asset ingested through this data source, determining which form schema is applied to the asset metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type_identifier" type="string">
      The identifier of the metadata form type that defines the structure and fields for this asset form input, used when creating or updating assets in Amazon DataZone. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type_revision" type="string">
      The revision identifier of the asset form type to apply, indicating which version of the form schema the data source should use when creating an asset's metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="configuration" type="object">

        </ResponseField>
        <ResponseField name="relational_filter_configurations" type="list(object)">

Optional; if omitted, computed by AWS. **(AI-inferred)**

            <ResponseField name="database_name" type="string">

            <ResponseField name="filter_expressions" type="list(object)">
              List of filter expressions, each containing an expression string and a type (e.g., INCLUDE or EXCLUDE), that determine which database objects (tables or views) in the corresponding relational data source are included in or excluded from metadata ingestion in AWS DataZone. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="expression" type="string">

                <ResponseField name="type" type="string">

              </Expandable>
            </ResponseField>

Optional; if omitted, computed by AWS. **(AI-inferred)**

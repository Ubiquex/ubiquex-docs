`aws_data_zone_project_membership` is the real, actual grant that adds a user or group to an `aws_data_zone_project`, distinct from an `aws_data_zone_owner` in that membership alone doesn't carry ownership-level accountability.

## Input properties

<ResponseField name="designation" type="string" required>
  Designates the role of the member in the DataZone project, determining their access permissions (for example, PROJECT_OWNER or PROJECT_CONTRIBUTOR). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_identifier" type="string" required>
  The unique identifier of the Amazon DataZone domain in which the project and its membership are defined. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="member" type="object" required>
  Specifies the member to be added to the project, including the member's identifier and type (USER or GROUP). Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="group_identifier" type="string">
      Specifies the identifier of the group that is being granted membership to the DataZone project. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="user_identifier" type="string">
      The identifier of the user who is being granted membership to the DataZone project, as recognized by the DataZone domain. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="project_identifier" type="string" required>
  The unique identifier (ID) of the Amazon Data Zone project to which the member (user or group) is granted access. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="member_identifier" type="string">
  The fully qualified identifier of the AWS principal (such as an IAM user ARN, role ARN, or AWS account ID) that is added as a member to the DataZone project. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="member_identifier_type" type="string">
  Specifies whether the member is a user or a group, determining how the member identifier is interpreted for this DataZone project membership. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

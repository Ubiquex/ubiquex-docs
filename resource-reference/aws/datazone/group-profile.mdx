`aws_data_zone_group_profile` registers a real IAM Identity Center group as a recognized identity within an `aws_data_zone_domain`, so group-based permissions and project membership can be managed the same way individual `aws_data_zone_user_profile`s already are.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datazone "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/datazone"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own group profile"})

    		ubx.Resource(datazone.GroupProfile, "example", datazone.GroupProfileConfig{
    			DomainIdentifier: "example",
    			GroupIdentifier:  "example",
    			GroupType:        "example",
    			RolePrincipalArn: "arn:aws:iam::123456789012:policy/example",
    			Status:           "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="domain_identifier" type="string" required>
  The identifier of the Amazon DataZone domain in which the group profile would be created. Required.
</ResponseField>

<ResponseField name="group_identifier" type="string">
  The ID of the group. Optional.
</ResponseField>

<ResponseField name="group_type" type="string">
  The type of the group. Optional.
</ResponseField>

<ResponseField name="role_principal_arn" type="string">
  The ARN of the role principal for the group profile. Optional.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the group profile. Optional.
</ResponseField>

## Output properties

<ResponseField name="domain_id" type="string">
  The identifier of the Amazon DataZone domain in which the group profile is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="group_name" type="string">
  The group-name of the Group Profile. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the Amazon DataZone group profile. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="role_principal_id" type="string">
  The ID of the role principal for the group profile. Computed by AWS after `ship`.
</ResponseField>

`aws_wickr_network` creates a real AWS Wickr network, the top-level, end-to-end-encrypted messaging environment that a Wickr organization's users, data retention bots, and admin API access are all scoped under. AWS Wickr launched admin APIs for programmatic network management in December 2025, roughly eight months ago.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wickr "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/wickr"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own network"})

    		ubx.Resource(wickr.Network, "example", wickr.NetworkConfig{
    			AccessLevel: "example",
    			NetworkName: "example-network-name",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="access_level" type="string" required>
  The access level of the network, which determines available features and capabilities. Required.
</ResponseField>

<ResponseField name="network_name" type="string" required>
  The name of the network. Must be between 1 and 20 characters. Required.
</ResponseField>

## Output properties

<ResponseField name="aws_account_id" type="string">
  The AWS account ID that owns the network. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="migration_state" type="number">
  The SSO redirect URI migration state. Values: 0 (not started), 1 (in progress), or 2 (completed). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="network_arn" type="string">
  The Amazon Resource Name (ARN) of the network. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="network_id" type="string">
  The unique identifier of the network. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="standing" type="number">
  The current standing or status of the network. Computed by AWS after `ship`.
</ResponseField>

`aws_io_twireless_multicast_group` sends the real, same LoRaWAN downlink message to a defined group of `aws_io_twireless_wireless_device`s at once, rather than a caller addressing every device in the group individually.

## Example

<Tabs>

    ```go
    package main

    import (
    	iotwireless "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iotwireless"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own twireless multicast group"})

    		ubx.Resource(iotwireless.MulticastGroup, "example", iotwireless.MulticastGroupConfig{
    			Name:                       "example",
    			AssociateWirelessDevice:    "example",
    			Description:                "Managed by ubx.",
    			DisassociateWirelessDevice: "example",
    			Tags:                       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="associate_wireless_device" type="string">
  Wireless device to associate. Only for update request. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Multicast group description Optional.
</ResponseField>

<ResponseField name="disassociate_wireless_device" type="string">
  Wireless device to disassociate. Only for update request. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  Name of Multicast group Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

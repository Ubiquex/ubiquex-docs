`aws_route53_recovery_readiness_cell` groups real, Region-scoped `aws_route53_recovery_readiness_resource_set`s into a recoverable unit under Route 53 Application Recovery Controller's readiness-checking side, distinct from the routing-control side's `aws_route53_recovery_control_cluster`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53recoveryreadiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53recoveryreadiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cell"})

    		ubx.Resource(route53recoveryreadiness.Cell, "example", route53recoveryreadiness.CellConfig{
    			CellName: "example-cell-name",
    			Cells:    []string{"example"},
    			Tags:     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cell_name" type="string">
  The name of the cell to create. Optional.
</ResponseField>

<ResponseField name="cells" type="list(string)">
  A list of cell Amazon Resource Names (ARNs) contained within this cell, for use in nested cells. For example, Availability Zones within specific Regions. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tags associated with a resource Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the Route 53 Recovery Readiness Cell, used to organize and identify the cell for cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag applied to the Route 53 Recovery Readiness cell, used for organizing, identifying, and managing the cell with custom metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cell_arn" type="string">
  The Amazon Resource Name (ARN) of the cell. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="parent_readiness_scopes" type="list(string)">
  The readiness scope for the cell, which can be a cell Amazon Resource Name (ARN) or a recovery group ARN. This is a list but currently can have only one element. Computed by AWS after `ship`.
</ResponseField>

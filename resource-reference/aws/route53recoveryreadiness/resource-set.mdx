`aws_route53_recovery_readiness_resource_set` defines a real, named set of resources, load balancers, DynamoDB tables, and similar, in one Region that an `aws_route53_recovery_readiness_readiness_check` evaluates for failover readiness.

## Example

    ```go

    import (
    	route53recoveryreadiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53recoveryreadiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource set"})

    		ubx.Resource(route53recoveryreadiness.ResourceSet, "example", route53recoveryreadiness.ResourceSetConfig{
    			ResourceSetType: "example",
    			Resources:       []map[string]any{{"component_id": "example"}},
    			ResourceSetName: "example-resource-set-name",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

</ResponseField>

<ResponseField name="resource_set_type" type="string" required>

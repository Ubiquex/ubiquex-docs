`aws_service_catalog_app_registry_application` creates a real application entity in Service Catalog AppRegistry, a metadata container that groups the AWS resources making up one logical application so they can be discovered, tagged, and reported on together, independent of any specific `aws_service_catalog_portfolio` or `aws_service_catalog_cloud_formation_product`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalogappregistry "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalogappregistry"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog app registry application"})

    		ubx.Resource(servicecatalogappregistry.Application, "example", servicecatalogappregistry.ApplicationConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Tags:        "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the application. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the application. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  Assigns AWS resource tags to the Service Catalog AppRegistry application to help identify, organize, and manage it. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="application_name" type="string">
  The name of the application. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="application_tag_key" type="string">
  The key of the AWS application tag, which is awsApplication. Applications created before 11/13/2023 or applications without the AWS application tag resource group return no value. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="application_tag_value" type="string">
  The value of the AWS application tag, which is the identifier of an associated resource. Applications created before 11/13/2023 or applications without the AWS application tag resource group return no value. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the AppRegistry application, which uniquely identifies it within AWS and is assigned on creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier (ApplicationId) of the AppRegistry application, assigned by AWS and used to reference the application in other AppRegistry resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

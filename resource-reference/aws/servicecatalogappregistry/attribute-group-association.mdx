`aws_service_catalog_app_registry_attribute_group_association` attaches a real `aws_service_catalog_app_registry_attribute_group` to a specific `aws_service_catalog_app_registry_application`, the resource that actually links the two together.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalogappregistry "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalogappregistry"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog app registry attribute group association"})

    		ubx.Resource(servicecatalogappregistry.AttributeGroupAssociation, "example", servicecatalogappregistry.AttributeGroupAssociationConfig{
    			Application:    "example",
    			AttributeGroup: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="application" type="string" required>
  The name or the Id of the Application. Required.
</ResponseField>

<ResponseField name="attribute_group" type="string" required>
  The name or the Id of the AttributeGroup. Required.
</ResponseField>

## Output properties

<ResponseField name="application_arn" type="string">
  The Amazon Resource Name (ARN) of the application associated with the attribute group in this AppRegistry attribute group association. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="attribute_group_arn" type="string">
  The Amazon Resource Name (ARN) of the attribute group that is associated with the application in AWS Service Catalog AppRegistry. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

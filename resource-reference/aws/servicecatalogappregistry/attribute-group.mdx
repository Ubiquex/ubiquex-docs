`aws_service_catalog_app_registry_attribute_group` defines a real, reusable set of custom metadata attributes, cost center, team owner, compliance tags, that can be associated with one or more `aws_service_catalog_app_registry_application`s through an `aws_service_catalog_app_registry_attribute_group_association`.

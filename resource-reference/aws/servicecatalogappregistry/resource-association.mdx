`aws_service_catalog_app_registry_resource_association` attaches a real AWS resource, most commonly a CloudFormation stack, to an `aws_service_catalog_app_registry_application`, the resource that actually associates deployed infrastructure with the application it belongs to.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="application" type="string" required>
  The name or the Id of the Application. Required.
</ResponseField>

<ResponseField name="resource" type="string" required>
  The name or the Id of the Resource. Required.
</ResponseField>

<ResponseField name="resource_type" type="string" required>
  The type of the CFN Resource for now it's enum CFN_STACK. Required.
</ResponseField>

## Output properties

<ResponseField name="application_arn" type="string">
  The ARN of the AWS Service Catalog AppRegistry application that this resource association links the associated resource to, which is automatically set by AWS and read-only. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_arn" type="string">
  The Amazon Resource Name (ARN) of the resource associated with the AppRegistry application, returned by AWS Service Catalog AppRegistry after the association is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_redshift_scheduled_action` schedules a real, recurring Redshift API action, resizing an `aws_redshift_cluster`, pausing it, resuming it, to run automatically on a cron-style schedule rather than being triggered by hand.

## Input properties

<ResponseField name="enable" type="bool">
  If true, the schedule is enabled. If false, the scheduled action does not trigger. Optional.
</ResponseField>

<ResponseField name="end_time" type="string">
  The UTC date and time after which the scheduled action no longer runs; if omitted, the action continues indefinitely until disabled or deleted. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="iam_role" type="string">
  The IAM role to assume to run the target action. Optional.
</ResponseField>

<ResponseField name="schedule" type="string">
  The schedule in `at( )` or `cron( )` format. Optional.
</ResponseField>

<ResponseField name="scheduled_action_description" type="string">
  The description of the scheduled action. Optional.
</ResponseField>

<ResponseField name="scheduled_action_name" type="string" required>
  The name of the scheduled action. The name must be unique within an account. Required.
</ResponseField>

<ResponseField name="start_time" type="string">
  The UTC start time when the scheduled action becomes active, specified in ISO 8601 format. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_action" type="any">
  Configures the specific Redshift cluster operation (such as resize, pause, or resume) that the scheduled action will invoke when it fires. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="next_invocations" type="list(string)">
  List of times when the scheduled action will run. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the scheduled action. Computed by AWS after `ship`.
</ResponseField>

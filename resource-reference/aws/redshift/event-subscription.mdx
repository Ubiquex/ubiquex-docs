`aws_redshift_event_subscription` subscribes a real SNS topic to receive notifications about events occurring on an `aws_redshift_cluster`, such as failovers or configuration changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own event subscription"})

    		ubx.Resource(redshift.EventSubscription, "example", redshift.EventSubscriptionConfig{
    			SubscriptionName: "example-subscription-name",
    			Enabled:          true,
    			EventCategories:  []string{"example"},
    			Severity:         "example",
    			SnsTopicArn:      "arn:aws:iam::123456789012:policy/example",
    			SourceIds:        []string{"example"},
    			SourceType:       "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="enabled" type="bool">
  A boolean value; set to true to activate the subscription, and set to false to create the subscription but not activate it. Optional.
</ResponseField>

<ResponseField name="event_categories" type="list(string)">
  Specifies the Amazon Redshift event categories to be published by the event notification subscription. Optional.
</ResponseField>

<ResponseField name="severity" type="string">
  Specifies the Amazon Redshift event severity to be published by the event notification subscription. Optional.
</ResponseField>

<ResponseField name="sns_topic_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon SNS topic used to transmit the event notifications. Optional.
</ResponseField>

<ResponseField name="source_ids" type="list(string)">
  A list of one or more identifiers of Amazon Redshift source objects. Optional.
</ResponseField>

<ResponseField name="source_type" type="string">
  The type of source that will be generating the events. Optional.
</ResponseField>

<ResponseField name="subscription_name" type="string" required>
  The name of the Amazon Redshift event notification subscription Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key name of a tag assigned to this Redshift event subscription, used for management and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a key-value tag attached to the AWS Redshift event subscription, used for identifying and managing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cust_subscription_id" type="string">
  The name of the Amazon Redshift event notification subscription. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="customer_aws_id" type="string">
  The AWS account associated with the Amazon Redshift event notification subscription. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="event_categories_list" type="list(string)">
  The list of Amazon Redshift event categories specified in the event notification subscription. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="source_ids_list" type="list(string)">
  A list of the sources that publish events to the Amazon Redshift event notification subscription. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the Amazon Redshift event notification subscription. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="subscription_creation_time" type="string">
  The date and time the Amazon Redshift event notification subscription was created. Computed by AWS after `ship`.
</ResponseField>

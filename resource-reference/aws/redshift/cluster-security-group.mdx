---
title: "aws_redshift_cluster_security_group"
description: "`aws_redshift_cluster_security_group` was a real access-control mechanism for Redshift clusters running on the original EC2-Classic network model."
---

EC2-Classic itself was fully retired on August 15, 2023, so this resource has no functioning target left to attach to; modern Redshift deployments use standard VPC security groups instead. This resource describes infrastructure that no longer has anything to provision against, rather than a current option.

Like its parent resource, this targets the EC2-Classic network model, which AWS fully retired on August 15, 2023, so it has no functioning target left to configure.

## Input properties

<ResponseField name="cidrip" type="string">
  The IPv4 CIDR range that is allowed inbound access to the Redshift cluster's security group; you must specify either this value or an EC2 security group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cluster_security_group_name" type="string" required>
  The name of the Redshift cluster security group to which the ingress rule is being added. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_name" type="string">
  The name of the EC2 security group to grant access to the Redshift cluster, allowing inbound traffic from instances associated with that EC2 security group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_owner_id" type="string">
  The AWS account ID of the account that owns the EC2 security group specified in the ingress rule, used to authorize cross-account access to the Redshift cluster. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  This computed attribute is the unique identifier of the Redshift cluster security group ingress rule, used by Terraform to track and reference the rule in its state and dependencies. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

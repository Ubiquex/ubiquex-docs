`aws_redshift_endpoint_access` creates a real Redshift-managed VPC endpoint that lets clients in a different VPC, or a different account, reach an `aws_redshift_cluster` privately without the cluster's own security group being opened up directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint access"})

    		ubx.Resource(redshift.EndpointAccess, "example", redshift.EndpointAccessConfig{
    			ClusterIdentifier:   "example",
    			EndpointName:        "example-endpoint-name",
    			SubnetGroupName:     "example-subnet-group-name",
    			VpcSecurityGroupIds: []string{"example"},
    			ResourceOwner:       "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cluster_identifier" type="string" required>
  A unique identifier for the cluster. You use this identifier to refer to the cluster for any subsequent cluster operations such as deleting or modifying. All alphabetical characters must be lower case, no hypens at the end, no two consecutive hyphens. Cluster name should be unique for all clusters within an AWS account Required.
</ResponseField>

<ResponseField name="endpoint_name" type="string" required>
  The name of the endpoint. Required.
</ResponseField>

<ResponseField name="resource_owner" type="string">
  The AWS account ID of the owner of the cluster. Optional.
</ResponseField>

<ResponseField name="subnet_group_name" type="string" required>
  The subnet group name where Amazon Redshift chooses to deploy the endpoint. Required.
</ResponseField>

<ResponseField name="vpc_security_group_ids" type="list(string)" required>
  A list of vpc security group ids to apply to the created endpoint access. Required.
</ResponseField>

<ResponseField name="endpoint_create_time" type="string">

`aws_redshift_cluster_parameter_group` defines a real set of engine parameters that can be applied to an `aws_redshift_cluster` instead of hand-tuning the cluster individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cluster parameter group"})

    		ubx.Resource(redshift.ClusterParameterGroup, "example", redshift.ClusterParameterGroupConfig{
    			Description:          "Managed by ubx.",
    			ParameterGroupFamily: "example",
    			ParameterGroupName:   "example-parameter-group-name",
    			Parameters:           []map[string]any{{"parameter_name": "example-parameter-name"}},
    			Tags:                 []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="description" type="string" required>
  A description of the parameter group. Required.
</ResponseField>

<ResponseField name="parameter_group_family" type="string" required>
  The Amazon Redshift engine version to which the cluster parameter group applies. The cluster engine version determines the set of parameters. Required.
</ResponseField>

<ResponseField name="parameter_group_name" type="string">
  The name of the cluster parameter group. Optional.
</ResponseField>

<ResponseField name="parameters" type="list(object)">
  An array of parameters to be modified. A maximum of 20 parameters can be modified in a single request. Optional.
  <Expandable title="properties">
    <ResponseField name="parameter_name" type="string">
      The name of a Redshift parameter (e.g., max_connections_per_session) whose value is configured by the sibling parameter_value in the parameter group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameter_value" type="string">
      The value assigned to a specific parameter within the Redshift cluster parameter group, corresponding to the parameter_name key. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag to attach to the Redshift cluster parameter group, enabling metadata-based identification and management of the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_redshift_endpoint_authorization` grants a real other AWS account permission to create an `aws_redshift_endpoint_access` against this account's `aws_redshift_cluster`, the authorization step that has to happen before the other account's endpoint can be created.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint authorization"})

    		ubx.Resource(redshift.EndpointAuthorization, "example", redshift.EndpointAuthorizationConfig{
    			Account:           "example",
    			ClusterIdentifier: "example",
    			Force:             true,
    			VpcIds:            []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="account" type="string" required>
  The AWS account ID of the customer to be authorized to access the Redshift cluster's VPC endpoint. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="cluster_identifier" type="string" required>
  The cluster identifier. Required.
</ResponseField>

<ResponseField name="force" type="bool">
  Indicates whether to force the revoke action. If true, the Redshift-managed VPC endpoints associated with the endpoint authorization are also deleted. Optional.
</ResponseField>

<ResponseField name="vpc_ids" type="list(string)">
  The virtual private cloud (VPC) identifiers to grant or revoke access to. Optional.
</ResponseField>

## Output properties

<ResponseField name="allowed_all_vpcs" type="bool">
  Indicates whether all VPCs in the grantee account are allowed access to the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="allowed_vpcs" type="list(string)">
  The VPCs allowed access to the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="authorize_time" type="string">
  The time (UTC) when the authorization was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="cluster_status" type="string">
  The status of the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint_count" type="number">
  The number of Redshift-managed VPC endpoints created for the authorization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="grantee" type="string">
  The AWS account ID that is granted access to the cluster's endpoint, returned as a computed read-only attribute. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="grantor" type="string">
  The AWS account ID of the cluster owner that grants the cross-account endpoint authorization. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The status of the authorization action. Computed by AWS after `ship`.
</ResponseField>

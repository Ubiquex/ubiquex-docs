`aws_redshift_serverless_namespace` creates a real Redshift Serverless namespace, the collection of database objects, users, and data that automatically scales its own compute, distinct from the manually sized `aws_redshift_cluster`.

## Example

## Input properties

<ResponseField name="admin_password_secret_kms_key_id" type="string">
  The ID of the AWS Key Management Service (KMS) key used to encrypt and store the namespace's admin credentials secret. You can only use this parameter if manageAdminPassword is true. Optional.
</ResponseField>

<ResponseField name="admin_user_password" type="string">
  The password associated with the admin user for the namespace that is being created. Password must be at least 8 characters in length, should be any printable ASCII character. Must contain at least one lowercase letter, one uppercase letter and one decimal digit. You can't use adminUserPassword if manageAdminPassword is true. Optional.
</ResponseField>

<ResponseField name="admin_username" type="string">
  The user name associated with the admin user for the namespace that is being created. Only alphanumeric characters and underscores are allowed. It should start with an alphabet. Optional.
</ResponseField>

<ResponseField name="db_name" type="string">
  The database name associated for the namespace that is being created. Only alphanumeric characters and underscores are allowed. It should start with an alphabet. Optional.
</ResponseField>

<ResponseField name="default_iam_role_arn" type="string">
  The default IAM role ARN for the namespace that is being created. Optional.
</ResponseField>

<ResponseField name="final_snapshot_name" type="string">
  The name of the namespace the source snapshot was created from. Please specify the name if needed before deleting namespace Optional.
</ResponseField>

<ResponseField name="final_snapshot_retention_period" type="number">
  The number of days to retain automated snapshot in the destination region after they are copied from the source region. If the value is -1, the manual snapshot is retained indefinitely. The value must be either -1 or an integer between 1 and 3,653. Optional.
</ResponseField>

<ResponseField name="iam_roles" type="list(string)">
  A list of AWS Identity and Access Management (IAM) roles that can be used by the namespace to access other AWS services. You must supply the IAM roles in their Amazon Resource Name (ARN) format. The Default role limit for each request is 10. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The AWS Key Management Service (KMS) key ID of the encryption key that you want to use to encrypt data in the namespace. Optional.
</ResponseField>

<ResponseField name="log_exports" type="list(string)">
  The collection of log types to be exported provided by the customer. Should only be one of the three supported log types: userlog, useractivitylog and connectionlog Optional.
</ResponseField>

<ResponseField name="manage_admin_password" type="bool">
  If true, Amazon Redshift uses AWS Secrets Manager to manage the namespace's admin credentials. You can't use adminUserPassword if manageAdminPassword is true. If manageAdminPassword is false or not set, Amazon Redshift uses adminUserPassword for the admin user account's password. Optional.
</ResponseField>

<ResponseField name="namespace_name" type="string" required>
  A unique identifier for the namespace. You use this identifier to refer to the namespace for any subsequent namespace operations such as deleting or modifying. All alphabetical characters must be lower case. Namespace name should be unique for all namespaces within an AWS account. Required.
</ResponseField>

<ResponseField name="namespace_resource_policy" type="any">
  The resource policy document that will be attached to the namespace. Optional.
</ResponseField>

<ResponseField name="redshift_idc_application_arn" type="string">
  The ARN for the Redshift application that integrates with IAM Identity Center. Optional.
</ResponseField>

<ResponseField name="snapshot_copy_configurations" type="list(object)">
  The snapshot copy configurations for the namespace. Optional.
  <Expandable title="properties">
    <ResponseField name="destination_kms_key_id" type="string">
      The customer-managed AWS KMS key ID or ARN that encrypts Redshift Serverless snapshot copies sent to the destination region or account defined in this snapshot copy configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="destination_region" type="string">
      The AWS region to which snapshots are copied for this snapshot copy configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="snapshot_retention_period" type="number">
      Specifies the number of days that snapshots copied to the destination AWS Region are retained for this snapshot copy configuration in Redshift Serverless. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The list of tags for the namespace. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag assigned to the Redshift Serverless namespace for resource organization and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a key-value tag applied to the Redshift Serverless namespace, used for organizing, tracking, and managing the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**

`aws_redshift_snapshot_schedule` defines a real, recurring cron-style schedule on which an `aws_redshift_cluster` automatically takes snapshots, beyond Redshift's own default automated backups.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			ScheduleIdentifier:  "example",

    		})
    	}))
    }

## Input properties

<ResponseField name="schedule_definitions" type="list(string)" required>
  The definition of the snapshot schedule. The definition is made up of schedule expressions, for example "cron(30 12 *)" or "rate(12 hours)". Required.
</ResponseField>

<ResponseField name="schedule_description" type="string">
  The description of the snapshot schedule. Optional.
</ResponseField>

<ResponseField name="schedule_identifier" type="string" required>
  A unique identifier for the snapshot schedule. Only alphanumeric characters are allowed. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An optional set of tags for the snapshot schedule. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag applied to the Redshift snapshot schedule, used to organize and identify the schedule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the Redshift snapshot schedule, used for resource organization and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the snapshot schedule. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="associated_cluster_count" type="number">
  The number of clusters associated with the schedule. Computed by AWS after `ship`.
</ResponseField>

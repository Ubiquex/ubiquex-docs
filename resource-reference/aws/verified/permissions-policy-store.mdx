`aws_verified_permissions_policy_store` creates a real, top-level container for an application's Cedar authorization policies and schema, the resource Amazon Verified Permissions evaluates every fine-grained `isAuthorized` request against.

## Input properties

<ResponseField name="deletion_protection" type="object">
  Whether deletion protection is enabled for this policy store, which prevents the policy store from being deleted until the setting is disabled. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="mode" type="string" required>
      Specifies whether deletion protection is enabled (ENABLED) or disabled (DISABLED) for the policy store, controlling whether the policy store can be deleted. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Provides a free-form, human-readable description of the policy store to help identify its purpose or manage it among other stores. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="encryption_settings" type="object">
  Specifies the AWS KMS key (customer-managed or AWS-managed) used to encrypt the policy store's data; if omitted, the store is encrypted with an AWS-managed key. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="default" type="any">
      Specifies the default encryption configuration for the policy store, choosing between AWS-managed encryption and a customer-managed AWS KMS key to protect the policy store's data. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="kms_encryption_settings" type="object">
      Specifies the customer-managed AWS KMS key configuration used to encrypt the policy store, including the KMS key ARN. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="encryption_context" type="any">
          Specifies a map of encryption context key-value pairs that are included as authenticated data in the KMS encryption operation when a customer-managed key encrypts the policy store, providing an extra layer of integrity and auditability. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="key" type="string">
          The Amazon Resource Name (ARN) of the customer managed AWS KMS key used to encrypt the policy store when KMS encryption is configured. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schema" type="object">
  Defines the Cedar schema for the policy store, specifying entity types, their attributes, and actions, which determines the valid policies and authorization requests. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cedar_json" type="string">
      The Cedar schema for the policy store, expressed as a JSON string that defines the entity types and actions used in authorization policies. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to add to the policy store Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that can be assigned to the AWS Verified Permissions policy store to help organize, identify, and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="validation_settings" type="object" required>
  Configures the validation mode (OFF or STRICT) for the Cedar policies stored in the policy store, determining whether and how strictly policies are validated. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="mode" type="string" required>
      Specifies whether the policy store validates policies against its schema, with OFF disabling validation and STRICT enabling strict validation. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying the policy store, assigned by AWS when the policy store is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="encryption_state" type="object">
  The computed encryption_state object describes the policy store's current encryption configuration, distinguishing between AWS-managed encryption and customer-managed KMS encryption and including the KMS key ARN when applicable. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="default" type="any">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="kms_encryption_state" type="object">
      The KMS encryption state configuration for the policy store, containing a status field that indicates whether AWS KMS customer-managed key encryption is enabled (ENABLED) or disabled (DISABLED). Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="encryption_context" type="any">
          Specifies the encryption context (a set of key-value pairs) used as additional authenticated data when encrypting the policy store with AWS KMS. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="key" type="string">
          The `key` attribute specifies the Amazon Resource Name (ARN) of the customer-managed AWS KMS key used to encrypt the Verified Permissions policy store under the KMS encryption configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="policy_store_id" type="string">
  The unique identifier assigned by AWS to the policy store when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

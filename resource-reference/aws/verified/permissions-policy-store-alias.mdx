`aws_verified_permissions_policy_store_alias` creates a real, friendly, stable name for an `aws_verified_permissions_policy_store`, so application code can reference the alias rather than the store's own generated ID.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	verified "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/verified"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own permissions policy store alias"})

    		ubx.Resource(verified.PermissionsPolicyStoreAlias, "ci-runner", verified.PermissionsPolicyStoreAliasConfig{
    			AliasName:     "example-alias-name",
    			PolicyStoreId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="alias_name" type="string" required>
  The alias name provides a friendly, user-defined identifier for the policy store, allowing it to be referenced in authorization requests instead of the raw policy store ID. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="policy_store_id" type="string" required>
  The unique identifier of the Amazon Verified Permissions policy store to which this alias belongs. Required. **(AI-inferred)**
</ResponseField>

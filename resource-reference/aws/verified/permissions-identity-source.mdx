`aws_verified_permissions_identity_source` connects a real identity provider, a Cognito user pool or an OIDC provider, to an `aws_verified_permissions_policy_store`, so a token's own claims can be evaluated as principal attributes in an authorization decision.

## Input properties

<ResponseField name="configuration" type="object" required>

## Output properties

<ResponseField name="details" type="object">
  `details` returns the computed configuration details of the identity source, including the Amazon Cognito user pool client IDs and group configuration settings, as resolved by AWS Verified Permissions. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="client_ids" type="list(string)">
      Specifies the client IDs of the identity provider (such as a Cognito user pool app or OIDC application) that are allowed to use this identity source for Amazon Verified Permissions. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="discovery_url" type="string">
      The URL of the OpenID Connect discovery endpoint for the identity provider, which Verified Permissions uses to automatically fetch the provider's configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="open_id_issuer" type="string">
      The issuer URL of the OpenID Connect provider used for this identity source, which AWS Verified Permissions uses to discover and validate tokens issued by that provider. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="user_pool_arn" type="string">
      The Amazon Resource Name (ARN) of the Amazon Cognito user pool that acts as the identity provider for this identity source. Optional. **(AI-inferred)**

  </Expandable>

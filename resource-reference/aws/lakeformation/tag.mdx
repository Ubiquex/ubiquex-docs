`aws_lake_formation_tag` defines a real LF-Tag, a key with one or more allowed values, such as `department` with values `sales`, `marketing`, `engineering`, used as the building block of Lake Formation's tag-based access control.

## Properties

<ResponseField name="catalog_id" type="string">
  The identifier of the Data Catalog (usually the AWS account ID) where the LF-tag is defined, defaulting to the current account if not specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tag_key" type="string" required>
  The key (name) of the Lake Formation LF-tag, which together with TagValues forms a tag pair used to classify resources. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tag_values" type="list(string)" required>
  The tag_values field specifies the list of possible values for this Lake Formation tag (LF-tag), which can be assigned to data lake resources for attribute-based access control. Required. **(AI-inferred)**
</ResponseField>

`aws_lake_formation_data_lake_settings` configures the real account-level defaults for AWS Lake Formation, including data lake administrators and whether new Data Catalog databases and tables default to Lake Formation's own permission model or fall back to legacy IAM-only access.

## Input properties

<ResponseField name="admins" type="list(object)">
  Specifies the list of data lake administrator principals (e.g., IAM users, roles, or AWS accounts) who are granted administrative permissions on the Lake Formation data catalog and resources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_lake_principal_identifier" type="string">
      Specifies the identifier (such as an IAM user ARN, role ARN, or account ID) of a principal that is granted administrative rights to the data lake settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="allow_external_data_filtering" type="bool">
  Indicates whether third-party query engines are allowed to access the metadata location for external data filtering in Lake Formation. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="allow_full_table_external_data_access" type="bool">
  Determines whether external data access is allowed to read full Lake Formation tables without applying row- or column-level security filters, enabling unfiltered table data to be accessed by external engines. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorized_session_tag_value_list" type="list(string)">
  Specifies the list of session tag values that are authorized for the 'lakeFormation:principal' session tag, controlling which principals can use Lake Formation with those session tags. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="create_database_default_permissions" type="list(object)">
  Specifies the default permissions that Lake Formation automatically grants to principals on newly created databases in the data lake. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="permissions" type="list(string)">
      The list of Lake Formation permissions (such as ALL, ALTER, CREATE_TABLE, DESCRIBE, and DROP) that are granted by default to the specified principal when a new database is created in the data lake. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="principal" type="object">
      Specifies the principal (such as an IAM role, IAM user, or account) that receives the default permissions for newly created databases in the data lake. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="data_lake_principal_identifier" type="string">
          The ARN or identifier of the Lake Formation principal (such as an IAM role or account) to whom the default database creation permissions are granted. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_table_default_permissions" type="list(object)">
  The default permissions granted to principals when new tables are created in the data lake. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="permissions" type="list(string)">
      Specifies the list of Lake Formation table permission strings (such as SELECT, INSERT, ALTER, or DROP) that are granted by default to the principal on newly created tables in the data lake. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="principal" type="object">
      Identifies the principal (such as an IAM user, IAM role, or AWS account) that is granted the default table permissions specified in the Lake Formation data lake settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="data_lake_principal_identifier" type="string">
          Identifies the Lake Formation principal (such as an IAM role, IAM user, or AWS account) to which the default table permissions apply. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="external_data_filtering_allow_list" type="list(object)">
  Specifies the list of data lake principals (AWS accounts or IAM roles) that are allowed to filter data externally in Lake Formation settings, enabling those principals to use external data filtering capabilities. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_lake_principal_identifier" type="string">
      The ARN of an IAM principal permitted to use external data filtering, as an entry in the ExternalDataFilteringAllowList of the Lake Formation data lake settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="mutation_type" type="string">
  Specifies the type of mutation to apply to the data lake settings, with allowed values APPEND, REPLACE, ALLOW, or DROP. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameters" type="any">
  Specifies the Parameters map of the Lake Formation DataLakeSettings object, which carries administrative settings like CROSS_ACCOUNT_VERSION to control the cross-account permission model version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="read_only_admins" type="list(object)">
  A list of Lake Formation principals (such as IAM users or roles) that are granted read-only administrative access to the Data Catalog, allowing them to view data but not modify settings or permissions. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_lake_principal_identifier" type="string">
      The Data Lake principal identifier (typically an IAM role or user ARN) for a principal included in the read-only admins list, granting that principal read-only administrator permissions on the Lake Formation data lake settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="trusted_resource_owners" type="list(string)">
  A list of AWS account IDs that are trusted to register resources into the data lake, allowing these accounts to create and manage data lake resources even though they are not the data lake owner. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

</ResponseField>

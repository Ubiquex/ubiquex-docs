`aws_lake_formation_resource` registers a real S3 location with Lake Formation, the real prerequisite step that brings that storage location under Lake Formation's own permission model rather than leaving access to bucket policies and IAM alone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lakeformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lakeformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource"})

    		ubx.Resource(lakeformation.Resource, "example", lakeformation.ResourceConfig{
    			ResourceArn:          "arn:aws:iam::123456789012:policy/example",
    			UseServiceLinkedRole: true,
    			HybridAccessEnabled:  true,
    			RoleArn:              "arn:aws:iam::123456789012:policy/example",
    			WithFederation:       true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="hybrid_access_enabled" type="bool">
  When true, enables hybrid access for the registered resource, allowing it to be accessed through both Lake Formation permissions and IAM/S3 permissions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The Amazon Resource Name (ARN) of the S3 bucket, database, or table to be registered with AWS Lake Formation. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the IAM role that AWS Lake Formation assumes to access and manage the registered S3 data lake location. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="use_service_linked_role" type="bool" required>
  Indicates whether to use the Lake Formation service-linked role when registering the S3 resource; if false, a custom IAM role must be provided in the RoleArn field. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="with_federation" type="bool">
  When set to true, this flag registers the S3 location as a federated resource in AWS Lake Formation, enabling integration with a federated data catalog for access management. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  This field is the unique identifier of the Lake Formation resource, typically the ARN of the underlying AWS resource (such as an S3 bucket or DynamoDB table) that has been registered. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

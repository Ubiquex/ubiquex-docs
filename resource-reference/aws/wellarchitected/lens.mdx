`aws_well_architected_lens` defines a real, custom set of best-practice questions, beyond the standard Well-Architected Framework pillars, that can be applied to an `aws_well_architected_workload`'s review, for a specific industry or technology an organization wants to assess against.

## Example

    ```go
    package main

    import (
    	wellarchitected "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/wellarchitected"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lens"})

    		ubx.Resource(wellarchitected.Lens, "example", wellarchitected.LensConfig{
    			Jsonstring:  "example",
    			LensVersion: "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="jsonstring" type="string">
  The JSON representation of a lens. Optional.
</ResponseField>

<ResponseField name="lens_version" type="string">
  The version of the lens. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags assigned to the lens. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.

  </Expandable>
</ResponseField>

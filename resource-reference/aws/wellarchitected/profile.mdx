`aws_well_architected_profile` defines a real, reusable set of questions and priorities, tailored to a specific business context, that can be applied to an `aws_well_architected_workload`'s review, layered on top of the standard Well-Architected Framework pillars.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wellarchitected "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/wellarchitected"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own architected profile"})

    		ubx.Resource(wellarchitected.Profile, "example", wellarchitected.ProfileConfig{
    			ProfileDescription: "example",
    			ProfileName:        "example-profile-name",
    			ProfileQuestions:   []map[string]any{{"question_id": "example"}},
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="profile_description" type="string" required>
  The profile description. Required.
</ResponseField>

<ResponseField name="profile_name" type="string" required>
  The name of the profile. Required.
</ResponseField>

<ResponseField name="profile_questions" type="list(object)" required>
  The profile questions. Required.
  <Expandable title="properties">
    <ResponseField name="question_id" type="string">
      The unique identifier of a question from a Well-Architected lens that is included in the profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="selected_choice_ids" type="list(string)">
      Specifies the IDs of the choices selected for a question, defining the answer(s) included in the profile for that question. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags assigned to the profile. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key of a tag attached to the Well-Architected Profile, used to organize and identify the profile in AWS Well-Architected. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the AWS Well-Architected profile, used to identify, organize, or manage the profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

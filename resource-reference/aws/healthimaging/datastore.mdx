`aws_health_imaging_datastore` is the real, central repository AWS HealthImaging stores medical imaging data in, DICOM P10 files imported from S3 and transformed into image sets of metadata and pixel-data image frames, built for petabyte-scale, subsecond image retrieval.

## Example

    ```go
    package main

    import (
    	healthimaging "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/healthimaging"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own datastore"})

    		ubx.Resource(healthimaging.Datastore, "example", healthimaging.DatastoreConfig{
    			DatastoreName: "example-datastore-name",
    			KmsKeyArn:     "arn:aws:iam::123456789012:policy/example",
    			Tags:          "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="datastore_name" type="string">
  User friendly name for Datastore. Optional.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  ARN referencing a KMS key or KMS key alias. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  A Map of key value pairs for Tags. Optional.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The timestamp when the data store was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="datastore_arn" type="string">
  The Datastore's ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="datastore_id" type="string">
  The unique identifier assigned to the datastore by AWS HealthImaging when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="datastore_status" type="string">
  A string to denote the Datastore's state. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp when the data store was created. Computed by AWS after `ship`.
</ResponseField>

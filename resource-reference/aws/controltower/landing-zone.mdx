`aws_control_tower_landing_zone` is the real, enterprise-wide multi-account environment AWS Control Tower orchestrates on a caller's behalf, built on AWS Organizations, Service Catalog, and IAM Identity Center, the container every organizational unit, account, and control a Control Tower deployment governs lives inside.

## Input properties

<ResponseField name="manifest" type="any" required>
  The manifest is a structured JSON document that defines the landing zone configuration, including the version, governed Regions, organizational structure, and security controls, which AWS Control Tower uses to create or update the landing zone. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="remediation_types" type="list(string)">
  Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to associate with the AWS Control Tower landing zone, enabling cost allocation, access control, and resource identification. Optional. **(AI-inferred)**
  <Expandable title="properties">

<ResponseField name="version" type="string" required>

</ResponseField>

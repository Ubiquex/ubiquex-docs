`aws_control_tower_enabled_baseline` applies a real, predefined baseline, a coherent set of resources and configuration for a specific governance purpose, to a target organizational unit in an `aws_control_tower_landing_zone`, Control Tower's newer, more granular alternative to enrolling an entire account through Account Factory.

## Input properties

<ResponseField name="baseline_identifier" type="string" required>
  The ARN of the AWS Control Tower baseline to enable for the specified account. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="baseline_version" type="string" required>
  The version of the baseline to enable, used to specify a particular released version of the baseline identified by BaselineIdentifier. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameters" type="list(object)">
  A list of parameter key-value pairs that customize the configuration of the enabled baseline when it is applied to an account. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a baseline parameter, used to identify a specific configuration parameter defined for the selected baseline in AWS Control Tower. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="any">
      The value of a key-value pair supplied as a configuration parameter to the AWS Control Tower baseline being enabled on an account. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of key-value tags to associate with the AWS Control Tower enabled baseline resource, enabling metadata, cost allocation, and access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the AWS Control Tower enabled baseline, used to categorize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_identifier" type="string" required>
  Specifies the ARN of the target AWS account or organizational unit to which the baseline is applied, such as an account ARN or OU ARN. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="enabled_baseline_identifier" type="string">
  The unique identifier (Amazon Resource Name) of the enabled baseline, assigned by AWS Control Tower when the baseline is enabled on the target account or organizational unit. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

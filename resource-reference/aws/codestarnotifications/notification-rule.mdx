`aws_code_star_notifications_notification_rule` sends real notifications, to Slack via AWS Chatbot, to SNS, to email, when a specific event happens in a CodeCommit, CodeBuild, CodeDeploy, or CodePipeline resource. Despite the shared name, this service was unaffected by CodeStar's own 2024 discontinuation and remains active.

## Input properties

  Specifies the level of detail included in the notifications, with BASIC providing only essential event information and FULL providing complete event details. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="event_type_id" type="string">

<ResponseField name="event_type_ids" type="list(string)" required>
  The list of event type IDs (e.g., codecommit-repository-comments-on-commits or codepipeline-pipeline-stage-execution-failed) that trigger the notification rule, each identifying a specific AWS service event that activates the notification. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the notification rule, which identifies it in the AWS console and API operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource" type="string" required>

</ResponseField>

<ResponseField name="status" type="string">

</ResponseField>

<ResponseField name="tags" type="any">
  Tags (key-value pairs) that can be attached to the notification rule to help identify, organize, and manage it within AWS. Optional. **(AI-inferred)**

<ResponseField name="target_address" type="string">

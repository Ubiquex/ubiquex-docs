`aws_cloud_trail_trail` captures AWS account activity as events and delivers them continuously to an S3 bucket, with optional delivery to CloudWatch Logs and EventBridge, the real, ongoing record of API calls across the console, CLI, and SDKs, as opposed to CloudTrail's own 90-day, no-setup-required Event history.

    			CloudWatchLogsLogGroupArn: "arn:aws:iam::123456789012:policy/example",
    			CloudWatchLogsRoleArn:     "arn:aws:iam::123456789012:policy/example",
    			EnableLogFileValidation:   true,
    			EventSelectors:            []map[string]any{{"data_resources": []map[string]any{{"type": "example"}}}},

<ResponseField name="event_selectors" type="list(object)">
  Use event selectors to further specify the management and data event settings for your trail. By default, trails created without specific event selectors will be configured to log all read and write management events, and no data events. When an event occurs in your account, CloudTrail evaluates the event selector for all trails. For each trail, if the event matches any event selector, the trail processes and logs the event. If the event doesn't match any event selector, the trail doesn't log the event. You can configure up to five event selectors for a trail. Optional.
  <Expandable title="properties">
    <ResponseField name="data_resources" type="list(object)">
      Specifies the S3 buckets or Lambda functions for which to record data events, where each data resource includes a resource type (e.g., AWS::S3::Object or AWS::Lambda::Function) and a list of ARNs or prefixes. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Specifies the AWS resource type (e.g., AWS::S3::Object or AWS::Lambda::Function) for which to log data events within the event selector. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="values" type="list(string)">
          Contains the list of ARNs (for example, S3 object or prefix ARNs in the form arn:aws:s3:::bucket/prefix, or Lambda function ARNs) that identify the specific data resources selected for the event selector. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="exclude_management_event_sources" type="list(string)">

<ResponseField name="is_logging" type="bool" required>
  Whether the CloudTrail is currently logging AWS API calls. Required.

<ResponseField name="is_multi_region_trail" type="bool">
  Specifies whether the trail applies only to the current region or to all regions. The default is false. If the trail exists only in the current region and this value is set to true, shadow trails (replications of the trail) will be created in the other regions. If the trail exists in all regions and this value is set to false, the trail will remain in the region where it was created, and its shadow trails in other regions will be deleted. As a best practice, consider using trails that log events in all regions. Optional.
</ResponseField>

<ResponseField name="is_organization_trail" type="bool">
  Specifies whether the trail is created for all accounts in an organization in AWS Organizations, or only for the current AWS account. The default is false, and cannot be true unless the call is made on behalf of an AWS account that is the master account for an organization in AWS Organizations. Optional.
</ResponseField>

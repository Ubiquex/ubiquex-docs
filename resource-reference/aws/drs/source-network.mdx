`aws_drs_source_network` replicates a real, in-AWS network's own configuration, subnet CIDRs, security groups, route tables, internet gateways, into AWS Elastic Disaster Recovery, so a recovery launch reproduces the source network's actual layout instead of requiring it to be rebuilt from scratch during a failover.

## Input properties

<ResponseField name="origin_account_id" type="string" required>
  The account ID containing the VPC to protect. Required.
</ResponseField>

<ResponseField name="origin_region" type="string" required>
  The region containing the VPC to protect. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A set of tags associated with the Source Network. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined key for a tag on the AWS Elastic Disaster Recovery (DRS) Source Network, used to categorize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The VPC ID to protect. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the Source Network. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="source_network_id" type="string">
  The ID of the Source Network. Computed by AWS after `ship`.
</ResponseField>

`aws_route` defines a real, individual route within an `aws_route_table`, directing traffic for a specific destination CIDR or prefix list to exactly one target, an internet gateway, NAT gateway, instance, peering connection, or similar.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    			AuthorizationType:        "example",
    			AuthorizerId:             "example",
    			ModelSelectionExpression: "example",
    			OperationName:            "example-operation-name",
    		})
    	}))
    }

## Input properties

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="api_key_required" type="bool">
  Specifies whether an API key is required for the route. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="authorization_scopes" type="list(string)">
  The authorization scopes supported by this route. Optional.
</ResponseField>

<ResponseField name="authorization_type" type="string">
  The authorization type for the route. For WebSocket APIs, valid values are ``NONE`` for open access, ``AWS_IAM`` for using AWS IAM permissions, and ``CUSTOM`` for using a Lambda authorizer. For HTTP APIs, valid values are ``NONE`` for open access, ``JWT`` for using JSON Web Tokens, ``AWS_IAM`` for using AWS IAM permissions, and ``CUSTOM`` for using a Lambda authorizer. Optional.
</ResponseField>

<ResponseField name="authorizer_id" type="string">
  The identifier of the ``Authorizer`` resource to be associated with this route. The authorizer identifier is generated by API Gateway when you created the authorizer. Optional.
</ResponseField>

<ResponseField name="model_selection_expression" type="string">
  The model selection expression for the route. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="operation_name" type="string">
  The operation name for the route. Optional.
</ResponseField>

<ResponseField name="request_models" type="any">
  The request models for the route. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="request_parameters" type="any">
  The request parameters for the route. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="route_key" type="string" required>
  The route key for the route. For HTTP APIs, the route key can be either ``$default``, or a combination of an HTTP method and resource path, for example, ``GET /pets``. Required.
</ResponseField>

<ResponseField name="route_response_selection_expression" type="string">
  The route response selection expression for the route. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="target" type="string">
  The target for the route. Optional.
</ResponseField>

## Output properties

<ResponseField name="route_id" type="string">
  Computed by AWS after `ship`.
</ResponseField>

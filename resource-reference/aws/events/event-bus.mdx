`aws_events_event_bus` is the real, actual router events flow through, custom, partner, or the default account event bus, that every `aws_events_rule` is defined against and matches incoming events on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own event bus"})

    		ubx.Resource(events.EventBus, "example", events.EventBusConfig{
    			Name:             "example",
    			DeadLetterConfig: map[string]any{"arn": "example"},
    			Description:      "Managed by ubx.",
    			EventSourceName:  "example-event-source-name",
    			KmsKeyIdentifier: "example",
    			LogConfig:        map[string]any{"include_detail": "example"},
    			Policy:           "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="dead_letter_config" type="object">
  Dead Letter Queue for the event bus. Optional.
  <Expandable title="properties">
    <ResponseField name="arn" type="string">
      Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the event bus. Optional.
</ResponseField>

<ResponseField name="event_source_name" type="string">
  If you are creating a partner event bus, this specifies the partner event source that the new event bus will be matched with. Optional.
</ResponseField>

<ResponseField name="kms_key_identifier" type="string">
  Kms Key Identifier used to encrypt events at rest in the event bus. Optional.
</ResponseField>

<ResponseField name="log_config" type="object">
  The logging configuration settings for vended logs. Optional.
  <Expandable title="properties">
    <ResponseField name="include_detail" type="string">
      Configures whether or not to include event detail, input transformer details, target properties, and target input in the applicable log messages. Optional.
    </ResponseField>
    <ResponseField name="level" type="string">
      Configures the log level of the EventBus and determines which log messages are sent to Ingestion Hub for delivery. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the event bus. Required.
</ResponseField>

<ResponseField name="policy" type="any">
  A JSON string that describes the permission policy statement for the event bus. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the event bus. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag attached to the Amazon EventBridge event bus. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to an Amazon EventBridge event bus, used for metadata, cost allocation, and resource access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) for the event bus. Computed by AWS after `ship`.
</ResponseField>

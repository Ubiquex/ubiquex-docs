`aws_events_endpoint` is a real, global EventBridge endpoint backed by event buses in two Regions, that automatically fails over which Region actually receives events, real multi-Region resiliency for event-driven applications that can't tolerate one Region's event bus being unavailable.

## Example

    ```go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint"})

    		ubx.Resource(events.Endpoint, "example", events.EndpointConfig{
    			EventBuses:        []map[string]any{{"event_bus_arn": "example"}},
    			RoutingConfig:     map[string]any{"failover_config": map[string]any{"primary": map[string]any{"health_check": "example"}}},
    			Name:              "example",
    			Description:       "Managed by ubx.",
    			ReplicationConfig: map[string]any{"state": "example"},
    			RoleArn:           "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-provided description that identifies the purpose of the EventBridge global endpoint, which routes events between event buses across multiple AWS regions for disaster recovery. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="event_buses" type="list(object)" required>
  Specifies the list of EventBridge event buses to which the endpoint sends events, where each entry includes the ARN of the event bus and optionally an IAM role to use for event delivery. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="event_bus_arn" type="string">
      The Amazon Resource Name (ARN) of the EventBridge event bus that the endpoint associates with for routing events. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The unique name you assign to this EventBridge global endpoint, used to identify it when routing events between event buses across regions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_config" type="object">
  Configures multi-Region replication for this EventBridge endpoint, including whether replication is enabled and the list of AWS Regions to which events are replicated. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="state" type="string" required>
      Determines whether EventBridge replicates events from the primary region to secondary regions for this global endpoint, with valid values ENABLED or DISABLED. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the IAM role that EventBridge assumes to replicate events between the event buses associated with this global endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="routing_config" type="object" required>
  Defines how the EventBridge endpoint routes events to regional event buses, including the routing criteria that determines the primary and secondary event bus targets and the failover configuration for health check-based rerouting. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="failover_config" type="object" required>
      Defines the primary and secondary AWS Regions used by the EventBridge endpoint for failover routing. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="primary" type="object" required>
          The primary region configuration for an Amazon EventBridge global endpoint, defined by the HealthCheck ARN that EventBridge monitors to determine if the primary Region is healthy and when to fail over to the secondary Region. Required. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="health_check" type="string" required>
              The ARN of the Route 53 health check that determines whether the primary region is healthy, triggering failover to the secondary region for the EventBridge endpoint. Required. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="secondary" type="object" required>
          Defines the secondary failover target for the EventBridge endpoint, containing the ARN of the regional event bus that receives events when the primary is unavailable. Required. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="route" type="string" required>
              The ARN of the EventBridge event bus in the secondary Region that receives events when the primary Region fails over. Required. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

</ResponseField>

<ResponseField name="endpoint_id" type="string">
  The unique identifier assigned by Amazon EventBridge to the endpoint when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_url" type="string">
  The fully qualified DNS URL assigned to this EventBridge global endpoint, used as the ingestion target for events routed to its configured event buses. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="state" type="string">
  The current lifecycle state of the EventBridge endpoint as reported by the service (e.g., ACTIVE, CREATING, UPDATING, DELETING). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="state_reason" type="string">
  The reason that describes the current state of the EventBridge endpoint, such as error details if the endpoint is in a FAILED state. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

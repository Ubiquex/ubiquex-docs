`aws_events_api_destination` is a real HTTP endpoint target an `aws_events_rule` can invoke directly, the mechanism for routing matched events to a third-party API without a Lambda function in between just to make the HTTP call.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own api destination"})

    		ubx.Resource(events.ApiDestination, "example", events.ApiDestinationConfig{
    			ConnectionArn:                "arn:aws:iam::123456789012:policy/example",
    			HttpMethod:                   "example",
    			InvocationEndpoint:           "example",
    			Name:                         "example",
    			Description:                  "Managed by ubx.",
    			InvocationRateLimitPerSecond: 1,
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.events.api_destination import ApiDestination, ApiDestinationConfig

    def describe():
        ubx.intent("example own api destination")

        ubx.resource(ApiDestination, "example", ApiDestinationConfig(
            connection_arn="arn:aws:iam::123456789012:policy/example",
            http_method="example",
            invocation_endpoint="example",
            name="example",
            description="Managed by ubx.",
            invocation_rate_limit_per_second=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="connection_arn" type="string" required>
  The arn of the connection. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A description for the API destination to create. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="http_method" type="string" required>
  The HTTP method (e.g., GET, POST, PATCH) used when EventBridge invokes the API destination endpoint. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="invocation_endpoint" type="string" required>
  Url endpoint to invoke. Required.
</ResponseField>

<ResponseField name="invocation_rate_limit_per_second" type="number">
  The maximum number of invocations per second that EventBridge allows to the API destination. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Name of the apiDestination. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The arn of the api destination. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="arn_for_policy" type="string">
  The arn of the api destination to be used in IAM policies. Computed by AWS after `ship`.
</ResponseField>

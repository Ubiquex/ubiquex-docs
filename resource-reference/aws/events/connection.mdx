title: "aws_events_connection"
description: "`aws_events_connection` stores the real authorization credentials, API key, OAuth, basic auth..."
---

`aws_events_connection` stores the real authorization credentials, API key, OAuth, basic auth, that an `aws_events_api_destination` uses to actually authenticate its calls, kept separate so the same credentials can be reused across multiple destinations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own connection"})

    		ubx.Resource(events.Connection, "ci-runner", events.ConnectionConfig{
    			Name:              "ci-runner",
    			AuthorizationType: "example",
    			Description:       "Managed by ubx.",
    			KmsKeyIdentifier:  "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="authorization_type" type="string">
  Specifies the authorization type for the EventBridge connection, which can be one of BASIC, OAUTH_CLIENT_CREDENTIALS, or API_KEY, determining how the connection authenticates to the API destination. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Description of the connection. Optional.
</ResponseField>

<ResponseField name="kms_key_identifier" type="string">
  Specifies the AWS KMS key (by ID, ARN, or alias) used to encrypt the connection's credentials and other sensitive parameters, enabling customer-managed encryption instead of the default AWS-owned key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Name of the connection. Optional.
</ResponseField>

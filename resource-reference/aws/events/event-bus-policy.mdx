`aws_events_event_bus_policy` attaches a real resource-based access policy to an `aws_events_event_bus`, controlling which principals, including from other accounts, can put events onto it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own event bus policy"})

    		ubx.Resource(events.EventBusPolicy, "ci-runner", events.EventBusPolicyConfig{
    			StatementId:  "example",
    			Action:       "example",
    			Condition:    map[string]any{"key": "example"},
    			EventBusName: "example-event-bus-name",
    			Principal:    "example",
    			Statement:    "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="action" type="string">
  The action that you are enabling the other account to perform. Optional.
</ResponseField>

<ResponseField name="condition" type="object">
  This parameter enables you to limit the permission to accounts that fulfill a certain condition, such as being a member of a certain AWS organization. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the value for the key. Currently, this must be the ID of the organization. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of condition. Currently the only supported value is StringEquals. Optional.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the key for the condition. Currently the only supported key is aws:PrincipalOrgID. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="event_bus_name" type="string">
  The name of the event bus associated with the rule. If you omit this, the default event bus is used. Optional.
</ResponseField>

<ResponseField name="principal" type="string">
  The 12-digit AWS account ID that you are permitting to put events to your default event bus. Specify "*" to permit any account to put events to your default event bus. Optional.
</ResponseField>

<ResponseField name="statement" type="any">
  A JSON string that describes the permission policy statement. You can include a Policy parameter in the request instead of using the StatementId, Action, Principal, or Condition parameters. Optional.
</ResponseField>

<ResponseField name="statement_id" type="string" required>
  An identifier string for the external account that you are granting permissions to Required.
</ResponseField>

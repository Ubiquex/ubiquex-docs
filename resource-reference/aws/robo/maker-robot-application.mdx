`aws_robo_maker_robot_application` defined a real robotics application, its code and dependent packages, that AWS RoboMaker deployed onto a fleet's robots or ran in simulation. AWS RoboMaker is now fully discontinued, having ended support on September 10, 2025.

## Input properties

<ResponseField name="current_revision_id" type="string">
  The revision ID of robot application. Optional.
</ResponseField>

<ResponseField name="environment" type="string">
  The URI of the Docker image for the robot application. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the robot application. Optional.
</ResponseField>

<ResponseField name="robot_software_suite" type="object" required>
  The robot software suite used by the robot application. Required.
  <Expandable title="properties">
    <ResponseField name="name" type="string" required>
      The name of robot software suite. Required.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of robot software suite. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sources" type="list(object)">
  The sources of the robot application. Optional.
  <Expandable title="properties">
    <ResponseField name="architecture" type="string">
      Specifies the processor architecture (X86_64, ARM64, or ARMHF) that the robot application source bundle is built for, as part of the source's S3 location configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_bucket" type="string">
      The name of the S3 bucket that stores the robot application source archive, which AWS RoboMaker uses to deploy the application to robot devices. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_key" type="string">
      The S3 object key (path) of the robot application source bundle, which combined with the S3 bucket identifies the uploaded application archive for the RoboMaker robot application. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

`aws_robo_maker_simulation_application` defined a real simulation environment, its code and rendering engine bundle, that AWS RoboMaker ran robotics applications against virtually before deploying to physical hardware. This describes the now fully discontinued AWS RoboMaker service, which ended support September 10, 2025.

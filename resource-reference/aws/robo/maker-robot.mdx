## Input properties

<ResponseField name="architecture" type="string" required>
  The target architecture of the robot. Required.
</ResponseField>

<ResponseField name="fleet" type="string">
  The Amazon Resource Name (ARN) of the fleet. Optional.
</ResponseField>

<ResponseField name="greengrass_group_id" type="string" required>
  The Greengrass group id. Required.
</ResponseField>

<ResponseField name="name" type="string">
  The name for the robot. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the AWS RoboMaker robot within your AWS account. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_robo_maker_fleet` created a real logical grouping of physical robots that `aws_robo_maker_robot_application`s were deployed to together in AWS RoboMaker. AWS RoboMaker is now fully discontinued: AWS ended support on September 10, 2025, a date nearly a year in the past, steering customers toward AWS Batch for containerized simulation workloads instead; the project's own GitHub organization was archived in July 2026. This resource describes a service no longer operable rather than a current one.

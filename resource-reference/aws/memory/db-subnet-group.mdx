## Input properties

<ResponseField name="description" type="string">
  An optional description of the subnet group. Optional.
</ResponseField>

<ResponseField name="subnet_group_name" type="string" required>
  The name of the subnet group. This value must be unique as it also serves as the subnet group identifier. Required.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  A list of VPC subnet IDs for the subnet group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this subnet group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag applied to this MemoryDB subnet group, used to organize, identify, and apply IAM-based access controls to the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the subnet group. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="supported_network_types" type="list(string)">
  Supported network types would be a list of network types supported by subnet group and can be either [ipv4] or [ipv4, dual_stack] or [ipv6]. Computed by AWS after `ship`.
</ResponseField>

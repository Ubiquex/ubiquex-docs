`aws_memory_db_user` creates a real authentication identity, its password or IAM authentication method, that is granted permissions through an `aws_memory_db_acl` to connect to a MemoryDB cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	memory "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/memory"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own db user"})

    		ubx.Resource(memory.DbUser, "ci-runner", memory.DbUserConfig{
    			UserName:           "example-user-name",
    			AccessString:       "example",
    			AuthenticationMode: map[string]any{"passwords": []string{"example"}},
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_string" type="string">
  Access permissions string used for this user account. Optional.
</ResponseField>

<ResponseField name="authentication_mode" type="object">
  Specifies the authentication method for the MemoryDB user, including the authentication type and the list of passwords that can be used to access the user's cluster. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="passwords" type="list(string)">
      Passwords used for this user account. You can create up to two passwords for each user. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      Type of authentication strategy for this user. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this user. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of the tag key-value pair applied to the MemoryDB user. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_name" type="string" required>
  The name of the user. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the user account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  Indicates the user status. Can be "active", "modifying" or "deleting". Computed by AWS after `ship`.
</ResponseField>

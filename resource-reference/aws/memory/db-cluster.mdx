`aws_memory_db_cluster` creates a real MemoryDB cluster, a Redis OSS-compatible, durable in-memory database, with multi-AZ replication and a transaction log that makes it safe to use as a primary database rather than only a cache.

## Input properties

<ResponseField name="aclname" type="string" required>
  The name of the Access Control List to associate with the cluster. Required.
</ResponseField>

<ResponseField name="auto_minor_version_upgrade" type="bool">
  A flag that enables automatic minor version upgrade when set to true. You cannot modify the value of AutoMinorVersionUpgrade after the cluster is created. To enable AutoMinorVersionUpgrade on a cluster you must set AutoMinorVersionUpgrade to true when you create a cluster. Optional.
</ResponseField>

<ResponseField name="cluster_name" type="string" required>
  The name of the cluster. This value must be unique as it also serves as the cluster identifier. Required.
</ResponseField>

<ResponseField name="data_tiering" type="string">
  Specifies whether data tiering is enabled for the cluster, a feature that stores infrequently accessed data in Amazon S3 to reduce memory cost and is supported only on r6gd node types, using values 'true' or 'false'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of the cluster. Optional.
</ResponseField>

<ResponseField name="engine" type="string">
  The engine type used by the cluster. Optional.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The Redis engine version used by the cluster. Optional.
</ResponseField>

<ResponseField name="final_snapshot_name" type="string">
  The user-supplied name of a final cluster snapshot. This is the unique name that identifies the snapshot. MemoryDB creates the snapshot, and then deletes the cluster immediately afterward. Optional.
</ResponseField>

<ResponseField name="ip_discovery" type="string">
  Specifies the IP discovery protocol for the MemoryDB cluster, determining whether client connections use IPv4 or IPv6; valid values are 'ipv4' and 'ipv6'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The ID of the KMS key used to encrypt the cluster. Optional.
</ResponseField>

<ResponseField name="maintenance_window" type="string">
  Specifies the weekly time range during which maintenance on the cluster is performed. It is specified as a range in the format ddd:hh24:mi-ddd:hh24:mi (24H Clock UTC). The minimum maintenance window is a 60 minute period. Optional.
</ResponseField>

<ResponseField name="multi_region_cluster_name" type="string">
  The name of the Global Datastore, it is generated by MemoryDB adding a prefix to MultiRegionClusterNameSuffix. Optional.
</ResponseField>

<ResponseField name="network_type" type="string">
  The network type of the MemoryDB cluster, either 'ipv4' or 'dualstack', which determines whether the cluster uses only IPv4 or both IPv4 and IPv6 addressing. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="node_type" type="string" required>
  The compute and memory capacity of the nodes in the cluster. Required.
</ResponseField>

<ResponseField name="num_replicas_per_shard" type="number">
  The number of replicas to apply to each shard. The limit is 5. Optional.
</ResponseField>

<ResponseField name="num_shards" type="number">
  The number of shards the cluster will contain. Optional.
</ResponseField>

<ResponseField name="parameter_group_name" type="string">
  The name of the parameter group associated with the cluster. Optional.
</ResponseField>

<ResponseField name="port" type="number">
  The port number on which each member of the cluster accepts connections. Optional.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  One or more Amazon VPC security groups associated with this cluster. Optional.
</ResponseField>

<ResponseField name="snapshot_arns" type="list(string)">
  A list of Amazon Resource Names (ARN) that uniquely identify the RDB snapshot files stored in Amazon S3. The snapshot files are used to populate the new cluster. The Amazon S3 object name in the ARN cannot contain any commas. Optional.
</ResponseField>

<ResponseField name="snapshot_name" type="string">
  The name of a snapshot from which to restore data into the new cluster. The snapshot status changes to restoring while the new cluster is being created. Optional.
</ResponseField>

<ResponseField name="snapshot_retention_limit" type="number">
  The number of days for which MemoryDB retains automatic snapshots before deleting them. For example, if you set SnapshotRetentionLimit to 5, a snapshot that was taken today is retained for 5 days before being deleted. Optional.
</ResponseField>

<ResponseField name="snapshot_window" type="string">
  The daily time range (in UTC) during which MemoryDB begins taking a daily snapshot of your cluster. Optional.
</ResponseField>

<ResponseField name="sns_topic_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon Simple Notification Service (SNS) topic to which notifications are sent. Optional.
</ResponseField>

<ResponseField name="sns_topic_status" type="string">
  The status of the Amazon SNS notification topic. Notifications are sent only if the status is enabled. Optional.
</ResponseField>

<ResponseField name="subnet_group_name" type="string">
  The name of the subnet group to be used for the cluster. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this cluster. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag applied to the MemoryDB cluster, used for organizing and identifying cluster resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tlsenabled" type="bool">
  A flag that enables in-transit encryption when set to true. You cannot modify the value of TransitEncryptionEnabled after the cluster is created. To enable in-transit encryption on a cluster you must set TransitEncryptionEnabled to true when you create a cluster. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="cluster_endpoint" type="object">
  The DNS hostname and port of the MemoryDB cluster's endpoint, which clients use to connect to the cluster. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="address" type="string">
      The DNS address of the primary read-write node. Optional.
    </ResponseField>
    <ResponseField name="port" type="number">
      The port number that the engine is listening on. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="parameter_group_status" type="string">
  The status of the parameter group used by the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the cluster. For example, Available, Updating, Creating. Computed by AWS after `ship`.
</ResponseField>

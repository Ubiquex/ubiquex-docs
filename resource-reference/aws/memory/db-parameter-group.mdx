`aws_memory_db_parameter_group` defines a real set of engine configuration parameters that can be applied to one or more `aws_memory_db_cluster`s instead of hand-tuning each cluster individually.

## Input properties

<ResponseField name="description" type="string">
  A description of the parameter group. Optional.
</ResponseField>

<ResponseField name="family" type="string" required>
  The name of the parameter group family that this parameter group is compatible with. Required.
</ResponseField>

<ResponseField name="parameter_group_name" type="string" required>
  The name of the parameter group. Required.
</ResponseField>

<ResponseField name="parameters" type="any">
  An map of parameter names and values for the parameter update. You must supply at least one parameter name and value; subsequent arguments are optional. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

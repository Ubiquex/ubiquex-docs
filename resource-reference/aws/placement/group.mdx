`aws_placement_group` creates a real EC2 placement group, a placement strategy, cluster for low-latency networking within an Availability Zone, spread for maximum hardware isolation, or partition for large distributed workloads, that instances are then launched into.

## Input properties

<ResponseField name="parent_group_id" type="string">
  The ID of a parent placement group. Valid for strategies that support parent group linking. Optional.
</ResponseField>

<ResponseField name="partition_count" type="number">
  The number of partitions. Valid only when **Strategy** is set to `partition` Optional.
</ResponseField>

<ResponseField name="spread_level" type="string">
  The Spread Level of Placement Group is an enum where it accepts either host or rack when strategy is spread Optional.
</ResponseField>

<ResponseField name="strategy" type="string">
  The placement strategy. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a user-defined tag applied to the placement group, used to categorize and identify the resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="group_id" type="string">
  The ID of the placement group. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="group_name" type="string">
  The Group Name of Placement Group. Computed by AWS after `ship`.
</ResponseField>

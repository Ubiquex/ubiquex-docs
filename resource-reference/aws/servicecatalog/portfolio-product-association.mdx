`aws_service_catalog_portfolio_product_association` adds a real `aws_service_catalog_cloud_formation_product` to an `aws_service_catalog_portfolio`, the resource that actually makes that product available to anyone with access to the portfolio.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalog "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own portfolio product association"})

    		ubx.Resource(servicecatalog.PortfolioProductAssociation, "example", servicecatalog.PortfolioProductAssociationConfig{
    			AcceptLanguage:    "example",
    			PortfolioId:       "example",
    			ProductId:         "example",
    			SourcePortfolioId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="accept_language" type="string">
  The language code. Optional.
</ResponseField>

<ResponseField name="portfolio_id" type="string">
  The portfolio identifier. Optional.
</ResponseField>

<ResponseField name="product_id" type="string">
  The product identifier. Optional.
</ResponseField>

<ResponseField name="source_portfolio_id" type="string">
  The identifier of the source portfolio. The source portfolio must be a portfolio imported from a different account than the one creating the association. This account must have previously shared this portfolio with the account creating the association. Optional.
</ResponseField>

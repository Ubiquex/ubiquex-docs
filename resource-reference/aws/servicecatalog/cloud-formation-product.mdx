`aws_service_catalog_cloud_formation_product` publishes a real, versioned CloudFormation template as a Service Catalog product, letting end users launch it (as an `aws_service_catalog_cloud_formation_provisioned_product`) through Service Catalog's own governed, self-service interface rather than running `aws cloudformation deploy` directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalog "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cloud formation product"})

    		ubx.Resource(servicecatalog.CloudFormationProduct, "example", servicecatalog.CloudFormationProductConfig{
    			Name:                           "example",
    			Owner:                          "example",
    			AcceptLanguage:                 "example",
    			Description:                    "Managed by ubx.",
    			Distributor:                    "example",
    			ProductType:                    "example",
    			ProvisioningArtifactParameters: []map[string]any{{"name": "example-name"}},
    			ReplaceProvisioningArtifacts:   true,
    		})
    	}))
    }
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.aws.servicecatalog import CloudFormationProduct, CloudFormationProductConfig
    from ubx.aws.servicecatalog.cloud_formation_product import CloudFormationProduct_ProvisioningArtifactParameters

    def describe():
        ubx.intent("example own cloud formation product")

        ubx.resource(CloudFormationProduct, "example", CloudFormationProductConfig(
            name="example",
            owner="example",
            accept_language="example",
            description="Managed by ubx.",
            distributor="example",
            product_type="example",
            provisioning_artifact_parameters=[CloudFormationProduct_ProvisioningArtifactParameters(name="example-name")],
            replace_provisioning_artifacts=True,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="accept_language" type="string">
  The language code. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the product. Optional.
</ResponseField>

<ResponseField name="distributor" type="string">
  The distributor of the product. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the product. Required.
</ResponseField>

<ResponseField name="owner" type="string" required>
  The owner of the product. Required.
</ResponseField>

<ResponseField name="product_type" type="string">
  The type of product. Optional.
</ResponseField>

<ResponseField name="provisioning_artifact_parameters" type="list(object)">
  The configuration of the provisioning artifact (also known as a version). Optional.
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      Provides a user-friendly description of this provisioning artifact (a version of the product's CloudFormation template), which is displayed to end users in the AWS Service Catalog console when they view or launch the product. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="disable_template_validation" type="bool">
      If set to true, disables AWS Service Catalog's validation of the CloudFormation template associated with this provisioning artifact, allowing the product to be created without the service checking the template's syntax or resource definitions. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="info" type="object">
      Specifies the template source information for the provisioning artifact, such as the S3 URL (via the LoadTemplateFromURL key) where the CloudFormation template is stored. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="import_from_physical_id" type="string">
          Specifies the physical ID (such as an Amazon S3 object ARN) of an existing CloudFormation template to import as the provisioning artifact, used instead of a template URL to reference the template directly by its resource identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="load_template_from_url" type="string">
          Specifies the URL from which the CloudFormation template for this provisioning artifact is loaded. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the provisioning artifact, displayed as the version name for this CloudFormation product in Service Catalog. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of provisioning artifact, which can be CLOUD_FORMATION_TEMPLATE, MARKETPLACE, or TERRAFORM, and dictates whether the product template is a CloudFormation template, AWS Marketplace artifact, or Terraform configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="replace_provisioning_artifacts" type="bool">
  This property is turned off by default. If turned off, you can update provisioning artifacts or product attributes (such as description, distributor, name, owner, and more) and the associated provisioning artifacts will retain the same unique identifier. Provisioning artifacts are matched within the CloudFormationProduct resource, and only those that have been updated will be changed. Provisioning artifacts are matched by a combinaton of provisioning artifact template URL and name. Optional.
</ResponseField>

<ResponseField name="source_connection" type="object">
  Defines the connection to an external source repository (such as AWS CodeStar or GitHub) from which the CloudFormation template for the product is retrieved, including repository details, branch, and folder. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="connection_parameters" type="object" required>
      The connection details based on the connection Type. Required.
      <Expandable title="properties">
        <ResponseField name="code_star" type="object">
          Provides the CodeStar-specific connection details (such as the CodeStar connection ARN, repository branch, and repository path) used by the Service Catalog product to import its template from a source repository. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="artifact_path" type="string" required>
              The absolute path where the artifact resides within the repo and branch, formatted as "folder/file.json". Required.
            </ResponseField>
            <ResponseField name="branch" type="string" required>
              The specific branch where the artifact resides. Required.
            </ResponseField>
            <ResponseField name="connection_arn" type="string" required>
              The CodeStar ARN, which is the connection between AWS Service Catalog and the external repository. Required.
            </ResponseField>
            <ResponseField name="repository" type="string" required>
              The specific repository where the product's artifact-to-be-synced resides, formatted as "Account/Repo." Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The only supported SourceConnection type is Codestar. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="support_description" type="string">
  The support information about the product. Optional.
</ResponseField>

<ResponseField name="support_email" type="string">
  The contact email for product support. Optional.
</ResponseField>

<ResponseField name="support_url" type="string">
  The contact URL for product support. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to assign to the Service Catalog CloudFormation product. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Service Catalog CloudFormation product, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

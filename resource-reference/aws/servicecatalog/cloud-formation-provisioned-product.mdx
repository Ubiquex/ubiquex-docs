`aws_service_catalog_cloud_formation_provisioned_product` launches a real, running instance of an `aws_service_catalog_cloud_formation_product`, the resource that actually provisions the underlying CloudFormation stack on an end user's behalf.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalog "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cloud formation provisioned product"})

    		ubx.Resource(servicecatalog.CloudFormationProvisionedProduct, "example", servicecatalog.CloudFormationProvisionedProductConfig{
    			AcceptLanguage:         "example",
    			NotificationArns:       []string{"example"},
    			PathId:                 "example",
    			PathName:               "example-path-name",
    			ProductId:              "example",
    			ProductName:            "example-product-name",
    			ProvisionedProductName: "example-provisioned-product-name",
    			ProvisioningArtifactId: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accept_language" type="string">
  Specifies the language code (such as en or jp) used by AWS Service Catalog for localized responses, error messages, and documentation when managing the provisioned product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="notification_arns" type="list(string)">
  Specifies the Amazon SNS topic ARNs to which AWS Service Catalog sends provisioning event notifications for this provisioned product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="path_id" type="string">
  The unique identifier of the launch path within AWS Service Catalog that determines which portfolio and constraint combination is used to provision this product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="path_name" type="string">
  The name of the Service Catalog provisioning path that identifies the specific product-portfolio association and launch constraints used to provision this product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="product_id" type="string">
  The unique identifier of the Service Catalog product from which this provisioned product is created. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="product_name" type="string">
  The name of the Service Catalog product to provision, used as an alternative to specifying the product ID when provisioning a product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioned_product_name" type="string">
  The user-friendly name of the provisioned product within AWS Service Catalog. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioning_artifact_id" type="string">
  The identifier of the provisioning artifact (product version) to use when provisioning the Service Catalog product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioning_artifact_name" type="string">
  The name of the Service Catalog provisioning artifact (product version) to use when provisioning the product. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioning_parameters" type="list(object)">
  Provides a list of key-value pairs that supply the values for parameters defined in the AWS CloudFormation template of the Service Catalog product being provisioned. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the name of a provisioning parameter for the Service Catalog product, matching the parameter key defined in the product's CloudFormation template or provisioning artifact. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value associated with a provisioning parameter key that is supplied to the AWS CloudFormation template during product provisioning. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="provisioning_preferences" type="object">
  Specifies provisioning preferences for the product, including StackSet accounts and regions, failure tolerance counts, and maximum concurrent operation counts for stack set deployments. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="stack_set_accounts" type="list(string)">
      Specifies the list of AWS account IDs where the associated AWS CloudFormation StackSet deploys when provisioning this Service Catalog product. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stack_set_failure_tolerance_count" type="number">
      Specifies the number of accounts, per Region, for which stack set operation failures are tolerated before the operation is aborted. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stack_set_failure_tolerance_percentage" type="number">
      Specifies the percentage of accounts, per Region, for which a stack set operation can fail before AWS CloudFormation stops the operation and rolls back the stack. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stack_set_max_concurrency_count" type="number">
      The maximum number of accounts in which AWS CloudFormation StackSets can create stacks concurrently during stack set provisioning. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stack_set_max_concurrency_percentage" type="number">
      Specifies the maximum percentage of accounts in which stack instances are created or updated concurrently when AWS Service Catalog provisions the product using a StackSet. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stack_set_operation_type" type="string">
      Specifies whether the AWS CloudFormation StackSet operation performed during provisioning is a create or update operation. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stack_set_regions" type="list(string)">
      Specifies the AWS Regions where CloudFormation StackSet instances are created when the provisioned product is deployed as a stack set. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the list of tags (key-value pairs) to associate with the provisioned product, which are applied to the provisioned CloudFormation stack and its resources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-specified key for a tag that AWS Service Catalog applies to the provisioned product. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag key-value pair that AWS Service Catalog applies to the provisioned product. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cloudformation_stack_arn" type="string">
  The ARN of the CloudFormation stack that AWS Service Catalog provisions for this provisioned product. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="outputs" type="any">
  List of key-value pair outputs. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="provisioned_product_id" type="string">
  The unique identifier (e.g., pp-xxxxxxxx) assigned by AWS Service Catalog to the provisioned product, used to reference and manage the provisioned resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="record_id" type="string">
  The unique identifier of the provisioning record for the provisioned product, which tracks the provisioning operation's status and details in AWS Service Catalog. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

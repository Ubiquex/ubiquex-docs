`aws_arczonal_shift_zonal_autoshift_configuration` enables ARC zonal autoshift for a resource, letting AWS automatically and safely shift its traffic away from an Availability Zone the moment AWS itself detects a potential impairment there, ahead of the caller noticing anything.

## Properties

<ResponseField name="practice_run_configuration" type="object">
  Defines the practice run configuration for zonal autoshift, specifying blocking windows/dates and the outcome alarms that must clear for a practice run to be considered successful. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="blocked_dates" type="list(string)">
      A list of dates in YYYY-MM-DD format on which zonal autoshift practice runs are blocked and cannot occur. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="blocked_windows" type="list(string)">
      A list of cron expressions in UTC that define recurring time windows during which the service will not start a practice run for this zonal autoshift configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="blocking_alarms" type="list(object)">
      Specifies the list of CloudWatch alarms that, when in ALARM state, block the practice run from starting (or continuing) for the zonal autoshift configuration. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="alarm_identifier" type="string">
          The identifier (ARN or name) of a CloudWatch alarm that, when in ALARM state, blocks or stops zonal autoshift practice runs. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies whether the CloudWatch alarm in the blocking alarms list is a 'BLOCKING' type (as opposed to 'OUTCOME'), which is required for blocking alarms to prevent zonal autoshift when the alarm enters ALARM state. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="outcome_alarms" type="list(object)" required>
      Specifies the CloudWatch alarms used to evaluate the outcome of zonal autoshift practice runs, where an alarm entering the ALARM state during a practice run marks it as failed. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="alarm_identifier" type="string">
          The CloudWatch alarm name or ARN that identifies an alarm used to evaluate the outcome of a zonal autoshift practice run. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the type of the outcome alarm control condition, which must be either 'CLOUDWATCH_ALARM' or 'CLOUDWATCH_ALARM_MULTI', to evaluate the success or failure of a zonal autoshift practice run. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resource_identifier" type="string">
  The identifier (such as an ARN) of the resource for which the zonal autoshift configuration is set, enabling automatic traffic shifting away from an Availability Zone for that resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="zonal_autoshift_status" type="string">
  Sets the desired zonal autoshift status for the configuration, with allowed values 'ENABLED' or 'DISABLED'. Optional. **(AI-inferred)**
</ResponseField>

`aws_acmpca_permission` grants a real AWS service, most commonly ACM itself, permission to use an `aws_acmpca_certificate_authority` to issue and renew certificates on an account's behalf.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	acmpca "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/acmpca"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own permission"})

    		ubx.Resource(acmpca.Permission, "example", acmpca.PermissionConfig{
    			Actions:                 []string{"example"},
    			CertificateAuthorityArn: "arn:aws:iam::123456789012:policy/example",
    			Principal:               "example",
    			SourceAccount:           "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="actions" type="list(string)" required>
  The actions that the specified AWS service principal can use. Actions IssueCertificate, GetCertificate and ListPermissions must be provided. Required.
</ResponseField>

<ResponseField name="certificate_authority_arn" type="string" required>
  The Amazon Resource Name (ARN) of the Private Certificate Authority that grants the permission. Required.
</ResponseField>

<ResponseField name="principal" type="string" required>
  The AWS service or identity that receives the permission. At this time, the only valid principal is acm.amazonaws.com. Required.
</ResponseField>

<ResponseField name="source_account" type="string">
  The ID of the calling account. Optional.
</ResponseField>

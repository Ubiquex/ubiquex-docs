`aws_acmpca_certificate_authority_activation` installs a real signed certificate into an `aws_acmpca_certificate_authority`, the step that actually activates a subordinate (non-root) private CA so it can begin issuing its own certificates.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	acmpca "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/acmpca"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own certificate authority activation"})

    		ubx.Resource(acmpca.CertificateAuthorityActivation, "ci-runner", acmpca.CertificateAuthorityActivationConfig{
    			Certificate:             "example",
    			CertificateAuthorityArn: "arn:aws:iam::123456789012:policy/ci",
    			CertificateChain:        "example",
    			Status:                  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate" type="string" required>
  Certificate Authority certificate that will be installed in the Certificate Authority. Required.
</ResponseField>

<ResponseField name="certificate_authority_arn" type="string" required>
  Arn of the Certificate Authority. Required.
</ResponseField>

<ResponseField name="certificate_chain" type="string">
  Certificate chain for the Certificate Authority certificate. Optional.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the Certificate Authority. Optional.
</ResponseField>

## Output properties

<ResponseField name="complete_certificate_chain" type="string">
  The complete certificate chain, including the Certificate Authority certificate. Computed by AWS after `ship`.
</ResponseField>

`aws_kinesis_analytics_application` runs a real, continuous SQL query directly against a streaming data source, Kinesis Data Streams or Firehose, the original, SQL-based Kinesis Data Analytics application type, distinct from the newer Apache Flink-based Kinesis Data Analytics v2 applications.

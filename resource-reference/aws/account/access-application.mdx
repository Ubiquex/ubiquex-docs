`aws_account_access_application` is part of IAM Identity Center's account access manager, which manages applications and entitlements that grant Identity Center principals access to IAM roles across accounts. An application in this context represents one such cross-account access grant, connecting a principal to a real IAM role in a target account without a standalone permission set.

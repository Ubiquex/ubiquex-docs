`aws_well_architected_review_template` defines a real, reusable review configuration, which lenses and pillars to include, that can be applied to an `aws_well_architected_workload`, so a consistent review structure can be reused across many workloads instead of configured individually each time.

## Input properties

<ResponseField name="description" type="string" required>
  The review template description. Required.
</ResponseField>

<ResponseField name="lenses" type="list(string)" required>
  The lenses applied to the review template. Required.
</ResponseField>

<ResponseField name="notes" type="string">
  The notes associated with the review template. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags assigned to the review template. Optional.

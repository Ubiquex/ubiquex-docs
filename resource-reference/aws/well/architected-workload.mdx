`aws_well_architected_workload` registers a real workload, an application or system, in the AWS Well-Architected Tool, the resource that a Well-Architected Framework review is actually conducted and tracked against.

## Example

    import (
    	well "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/well"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

## Input properties

<ResponseField name="account_ids" type="list(string)">
  The list of Amazon Web Services account IDs associated with the workload. Optional.
</ResponseField>

<ResponseField name="architectural_design" type="string">
  The URL of the architectural design for the workload. Optional.
</ResponseField>

<ResponseField name="aws_regions" type="list(string)">
  The list of Amazon Web Services Regions associated with the workload. Optional.
</ResponseField>

<ResponseField name="description" type="string" required>
  The description for the workload. Required.
</ResponseField>

<ResponseField name="discovery_config" type="object">
  Discovery configuration associated to the workload. Optional.
  <Expandable title="properties">
    <ResponseField name="trusted_advisor_integration_status" type="string">
      Discovery integration status in respect to Trusted Advisor for the workload. Optional.
    </ResponseField>
    <ResponseField name="workload_resource_definition" type="list(string)">
      The mode to use for identifying resources associated with the workload. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="environment" type="string" required>
  The environment for the workload. Required.
</ResponseField>

<ResponseField name="industry" type="string">
  The industry for the workload. Optional.
</ResponseField>

<ResponseField name="industry_type" type="string">
  The industry type for the workload. Optional.
</ResponseField>

<ResponseField name="lenses" type="list(string)" required>
  The list of lenses associated with the workload. Required.
</ResponseField>

<ResponseField name="non_aws_regions" type="list(string)">
  The list of non-Amazon Web Services Regions associated with the workload. Optional.
</ResponseField>

<ResponseField name="notes" type="string">
  The notes associated with the workload. Optional.
</ResponseField>

<ResponseField name="review_owner" type="string">
  The review owner of the workload. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with the workload. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Defines the key (name) of a tag attached to the Well-Architected workload, used to organize, identify, and control access to the workload resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag key applied to the AWS Well-Architected workload, used for metadata, cost allocation, or resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="workload_name" type="string" required>
  The name of the workload. Required.
</ResponseField>

## Output properties

<ResponseField name="improvement_status" type="string">
  The improvement status for a workload. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="workload_arn" type="string">
  The ARN for the workload. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="workload_id" type="string">
  The ID assigned to the workload. Computed by AWS after `ship`.
</ResponseField>

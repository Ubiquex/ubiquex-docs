`aws_personalize_solution` trains a real recommendation model against the data in an `aws_personalize_dataset_group`, using either a built-in Personalize recipe or AutoML, the resource that actually produces the model a deployed campaign serves recommendations from.

## Example

    ```go
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/personalize"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own solution"})

    		ubx.Resource(personalize.Solution, "example", personalize.SolutionConfig{
    			DatasetGroupArn: "arn:aws:iam::123456789012:policy/example",

    			EventType:       "example",
    			PerformAutoMl:   true,
    			PerformHpo:      true,
    			RecipeArn:       "arn:aws:iam::123456789012:policy/example",
    			SolutionConfig:  map[string]any{"algorithm_hyper_parameters": "example"},
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="dataset_group_arn" type="string" required>
  The ARN of the dataset group that provides the training data. Required.
</ResponseField>

<ResponseField name="event_type" type="string">
  When your have multiple event types (using an EVENT_TYPE schema field), this parameter specifies which event type (for example, 'click' or 'like') is used for training the model. If you do not provide an eventType, Amazon Personalize will use all interactions for training with equal weight regardless of type. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name for the solution Required.
</ResponseField>

<ResponseField name="perform_auto_ml" type="bool">
  Whether to perform automated machine learning (AutoML). The default is false. For this case, you must specify recipeArn. Optional.
</ResponseField>

<ResponseField name="perform_hpo" type="bool">
  Whether to perform hyperparameter optimization (HPO) on the specified or selected recipe. The default is false. When performing AutoML, this parameter is always true and you should not set it to false. Optional.
</ResponseField>

<ResponseField name="recipe_arn" type="string">
  The ARN of the recipe to use for model training. Only specified when performAutoML is false. Optional.
</ResponseField>

<ResponseField name="solution_config" type="object">
  The configuration to use with the solution. When performAutoML is set to true, Amazon Personalize only evaluates the autoMLConfig section of the solution configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="algorithm_hyper_parameters" type="any">
      Lists the hyperparameter names and ranges. Optional.
    </ResponseField>
    <ResponseField name="auto_mlconfig" type="object">

      <Expandable title="properties">

        </ResponseField>
        <ResponseField name="recipe_list" type="list(string)">
          The list of candidate recipes. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="event_value_threshold" type="string">
      Only events with a value greater than or equal to this threshold are used for training a model. Optional.
    </ResponseField>
    <ResponseField name="feature_transformation_parameters" type="any">
      Lists the feature transformation parameters. Optional.
    </ResponseField>
    <ResponseField name="hpo_config" type="object">

              </Expandable>
            </ResponseField>
            <ResponseField name="continuous_hyper_parameter_ranges" type="list(object)">

                <ResponseField name="max_value" type="number">

                <ResponseField name="min_value" type="number">

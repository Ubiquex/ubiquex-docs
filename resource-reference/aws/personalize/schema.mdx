`aws_personalize_schema` defines a real Avro schema describing the structure of interaction, item, or user data, that one or more `aws_personalize_dataset`s must conform to when imported.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schema"})

    		ubx.Resource(personalize.Schema, "example", personalize.SchemaConfig{
    			Name:   "example",
    			Schema: "example",
    			Domain: "example",
    			Tags:   []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="domain" type="string">
  The domain of a Domain dataset group. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name for the schema. Required.
</ResponseField>

<ResponseField name="schema" type="string" required>
  A schema in Avro JSON format. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags used to organize, track, or control access for this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Personalize schema resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="schema_arn" type="string">
  Arn for the schema. Computed by AWS after `ship`.
</ResponseField>

`aws_personalize_dataset` imports real interaction, item, or user data, conforming to an `aws_personalize_schema`, into an `aws_personalize_dataset_group` for Amazon Personalize to train recommendation models against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dataset"})

    		ubx.Resource(personalize.Dataset, "example", personalize.DatasetConfig{
    			DatasetGroupArn:  "arn:aws:iam::123456789012:policy/example",
    			DatasetType:      "example",
    			Name:             "example",
    			SchemaArn:        "arn:aws:iam::123456789012:policy/example",
    			DatasetImportJob: map[string]any{"data_source": map[string]any{"data_location": "example"}},
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="dataset_group_arn" type="string" required>
  The Amazon Resource Name (ARN) of the dataset group to add the dataset to Required.
</ResponseField>

<ResponseField name="dataset_import_job" type="object">
  Initial DatasetImportJob for the created dataset Optional.
  <Expandable title="properties">
    <ResponseField name="data_source" type="object">
      The Amazon S3 bucket that contains the training data to import. Optional.
      <Expandable title="properties">
        <ResponseField name="data_location" type="string">
          The path to the Amazon S3 bucket where the data that you want to upload to your dataset is stored. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="dataset_arn" type="string">
      The ARN of the dataset that receives the imported data Optional.
    </ResponseField>
    <ResponseField name="dataset_import_job_arn" type="string">
      The ARN of the dataset import job Optional.
    </ResponseField>
    <ResponseField name="job_name" type="string">
      The name for the dataset import job. Optional.
    </ResponseField>
    <ResponseField name="role_arn" type="string">
      The ARN of the IAM role that has permissions to read from the Amazon S3 data source. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dataset_type" type="string" required>
  The type of dataset Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name for the dataset Required.
</ResponseField>

<ResponseField name="schema_arn" type="string" required>
  The ARN of the schema to associate with the dataset. The schema defines the dataset fields. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags used to organize, track, or control access for this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to an Amazon Personalize dataset, used to organize and identify the dataset in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="dataset_arn" type="string">
  The ARN of the dataset Computed by AWS after `ship`.
</ResponseField>

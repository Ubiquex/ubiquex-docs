`aws_personalize_event_tracker` creates a real endpoint that streams live user interaction events, clicks, purchases, views, into an `aws_personalize_dataset_group`, so an already-deployed campaign can incorporate real-time behavior rather than only the data it was originally trained on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own event tracker"})

    		ubx.Resource(personalize.EventTracker, "example", personalize.EventTrackerConfig{
    			DatasetGroupArn: "arn:aws:iam::123456789012:policy/example",
    			Name:            "example",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="dataset_group_arn" type="string" required>
  The Amazon Resource Name (ARN) of the dataset group that receives the event data. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name for the event tracker. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to apply to the event tracker. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag assigned to the Amazon Personalize event tracker, used for metadata and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the Amazon Personalize event tracker, used for categorizing and managing the tracker resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="event_tracker_arn" type="string">
  The Amazon Resource Name (ARN) of the event tracker. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="tracking_id" type="string">
  The ID of the event tracker. Include this ID in requests to the PutEvents API. Computed by AWS after `ship`.
</ResponseField>

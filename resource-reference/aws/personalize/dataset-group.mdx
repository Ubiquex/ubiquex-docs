`aws_personalize_dataset_group` creates a real top-level container that groups the `aws_personalize_dataset`s Amazon Personalize trains an `aws_personalize_solution` from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dataset group"})

    		ubx.Resource(personalize.DatasetGroup, "example", personalize.DatasetGroupConfig{
    			Name:      "example",
    			Domain:    "example",
    			KmsKeyArn: "arn:aws:iam::123456789012:policy/example",
    			RoleArn:   "arn:aws:iam::123456789012:policy/example",
    			Tags:      []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="domain" type="string">
  The domain of a Domain dataset group. Optional.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The Amazon Resource Name(ARN) of a AWS Key Management Service (KMS) key used to encrypt the datasets. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name for the new dataset group. Required.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the AWS Identity and Access Management (IAM) role that has permissions to access the AWS Key Management Service (KMS) key. Supplying an IAM role is only valid when also specifying a KMS key. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags used to organize, track, or control access for this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag (key-value pair) attached to the Amazon Personalize dataset group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="dataset_group_arn" type="string">
  The Amazon Resource Name (ARN) of the dataset group. Computed by AWS after `ship`.
</ResponseField>

`aws_personalize_metric_attribution` configures real, ongoing export of business metrics, click-through rate, conversion, tied back to an `aws_personalize_solution`'s recommendations, so their real-world impact can be measured outside Personalize itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own metric attribution"})

    		ubx.Resource(personalize.MetricAttribution, "example", personalize.MetricAttributionConfig{
    			DatasetGroupArn:     "arn:aws:iam::123456789012:policy/example",
    			Metrics:             []map[string]any{{"event_type": "example"}},
    			MetricsOutputConfig: map[string]any{"role_arn": "example"},
    			Name:                "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="dataset_group_arn" type="string" required>
  The ARN of the destination dataset group. Required.
</ResponseField>

<ResponseField name="metrics" type="list(object)" required>
  A list of metric attributes for the metric attribution. Required.
  <Expandable title="properties">
    <ResponseField name="event_type" type="string">
      The type of user event (such as Purchase or Click) that this metric attribution uses to measure how recommendation results influence that activity. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="expression" type="string">
      Defines a SQL-like expression that computes the metric from event attributes and event types, for example `SUM(IF(event_type = 'click', 1, 0))`. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metric_name" type="string">
      The user-defined name for this metric within the Amazon Personalize metric attribution, used to identify it in the configuration and in the output reports. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metrics_output_config" type="object" required>
  The output configuration details for the metric attribution. Required.
  <Expandable title="properties">
    <ResponseField name="role_arn" type="string" required>
      The ARN of the IAM role for the metric attribution. Required.
    </ResponseField>
    <ResponseField name="s3_data_destination" type="object">
      The configuration details of an Amazon S3 output bucket. Optional.
      <Expandable title="properties">
        <ResponseField name="kms_key_arn" type="string">
          The ARN of the KMS key. Optional.
        </ResponseField>
        <ResponseField name="path" type="string" required>
          The file path of the Amazon S3 bucket. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the metric attribution. Required.
</ResponseField>

## Output properties

<ResponseField name="metric_attribution_arn" type="string">
  The ARN of the metric attribution. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the metric attribution. Computed by AWS after `ship`.
</ResponseField>

`aws_uxc_account_customization` sets real, account-level visual customization for the AWS Management Console under AWS User Experience Customization, an account color, which services are visible, which Regions are visible, so administrators can make different accounts visually distinguishable and reduce clutter for their users. This is a genuinely new AWS service, launched in 2026, so behavior here is verified live rather than assumed from general knowledge.

## Input properties

<ResponseField name="account_color" type="string">
  The color theme assigned to the account for visual identification in the AWS Console. Optional.
</ResponseField>

<ResponseField name="visible_regions" type="list(string)">
  A list of AWS region identifiers visible to the account in the AWS Console. Optional.
</ResponseField>

<ResponseField name="visible_services" type="list(string)">
  A list of AWS service identifiers visible to the account in the AWS Console. Optional.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The AWS account ID that this customization belongs to. This is automatically determined from the caller's identity. Computed by AWS after `ship`.
</ResponseField>

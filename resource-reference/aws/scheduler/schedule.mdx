`aws_scheduler_schedule` creates a real, individual EventBridge Scheduler schedule, a one-time or recurring cron/rate expression paired with a target, the resource EventBridge Scheduler was purpose-built for at a scale (millions of schedules per account) that a plain EventBridge rule was never designed to handle.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	scheduler "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/scheduler"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schedule"})

    		ubx.Resource(scheduler.Schedule, "example", scheduler.ScheduleConfig{
    			FlexibleTimeWindow: map[string]any{"mode": "example"},
    			ScheduleExpression: "example",
    			Target:             map[string]any{"arn": "example"},
    			Name:               "example",
    			Description:        "Managed by ubx.",
    			EndDate:            "example",
    			GroupName:          "example-group-name",
    			KmsKeyArn:          "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="description" type="string">
  The description of the schedule. Optional.
</ResponseField>

<ResponseField name="end_date" type="string">
  The date, in UTC, before which the schedule can invoke its target. Depending on the schedule's recurrence expression, invocations might stop on, or before, the EndDate you specify. Optional.
</ResponseField>

<ResponseField name="flexible_time_window" type="object" required>
  Flexible time window allows configuration of a window within which a schedule can be invoked Required.
  <Expandable title="properties">
    <ResponseField name="maximum_window_in_minutes" type="number">
      The maximum time window during which a schedule can be invoked. Optional.
    </ResponseField>
    <ResponseField name="mode" type="string" required>
      Determines whether the schedule is executed within a flexible time window. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="group_name" type="string">
  The name of the schedule group to associate with this schedule. If you omit this, the default schedule group is used. Optional.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The ARN for a KMS Key that will be used to encrypt customer data. Optional.
</ResponseField>

<ResponseField name="name" type="string">

</ResponseField>

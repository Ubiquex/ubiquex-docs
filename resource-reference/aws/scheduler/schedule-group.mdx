`aws_scheduler_schedule_group` creates a real, named container that `aws_scheduler_schedule`s can be organized under, so a batch of related schedules can be managed, tagged, and deleted together.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	scheduler "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/scheduler"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schedule group"})

    		ubx.Resource(scheduler.ScheduleGroup, "example", scheduler.ScheduleGroupConfig{
    			Name: "example",
    			Tags: []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string">
  The name of the schedule group, which must be unique within your AWS account and Region; if omitted, CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The list of tags to associate with the schedule group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag attached to an AWS EventBridge Scheduler schedule group, used to identify and organize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag attached to the AWS EventBridge Scheduler schedule group, used to define metadata for the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

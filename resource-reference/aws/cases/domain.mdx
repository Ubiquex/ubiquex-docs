`aws_cases_domain` is the container for all Connect Cases data in one Amazon Connect instance, cases, `aws_cases_field`s, `aws_cases_layout`s, and `aws_cases_template`s all live inside exactly one domain, and an instance can be associated with only one.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cases "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain"})

    		ubx.Resource(cases.Domain, "example", cases.DomainConfig{
    			Name: "example",
    			Tags: []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.aws.cases import Domain, DomainConfig
    from ubx.aws.cases.domain import Domain_Tags

    def describe():
        ubx.intent("example own domain")

        ubx.resource(Domain, "example", DomainConfig(
            name="example",
            tags=[Domain_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="name" type="string" required>
  The name for your Cases domain. It must be unique for your AWS account. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags that you attach to this domain. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key for a tag attached to the AWS Cases domain. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value string of a key-value tag applied to the Amazon Connect Cases domain, used to store metadata such as environment or cost center for the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_time" type="string">
  The time at which the domain was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="domain_arn" type="string">
  The Amazon Resource Name (ARN) for the Cases domain. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="domain_id" type="string">
  The unique identifier of the Cases domain. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="domain_status" type="string">
  The current status of the Cases domain. Indicates whether the domain is Active, CreationInProgress, or CreationFailed. Computed by AWS after `ship`.
</ResponseField>

`aws_cases_layout` organizes how an `aws_cases_case`'s fields are actually displayed to an agent, working together with an `aws_cases_template`, which combines a layout with a set of fields into one reusable case structure.

## Example

    			Tags:     []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="content" type="object" required>
  Defines the layout structure and field organization for the case interface. Specifies which fields appear in the top panel and More Info tab, and their display order. Required.
  <Expandable title="properties">
    <ResponseField name="basic" type="object">
      The basic layout configuration for the case layout, defining how case panel and additional information sections are arranged on the page. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="more_info" type="object">
          The 'more_info' object configures the 'More Info' section of a basic layout, defining which case fields are displayed in that additional, separate area of the AWS Cases layout. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="sections" type="list(object)">
              Specifies the list of sections that make up the 'More Info' area of a basic layout in an AWS Cases layout, where each section can contain text or a reference to a case field. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="field_group" type="object">
                  Defines a field group within a section of the 'More Info' area of the basic case layout, containing the ordered list of field items to be displayed together. Optional; if omitted, computed by AWS. **(AI-inferred)**
                  <Expandable title="properties">
                    <ResponseField name="fields" type="list(object)">
                      Specifies the list of case fields to display in this field group within the 'More info' section of the basic layout. Optional; if omitted, computed by AWS. **(AI-inferred)**
                      <Expandable title="properties">
                        <ResponseField name="id" type="string">
                          The id of a field within a field group in the 'more info' section of a layout's basic content, referencing the unique identifier of the Amazon Connect Cases case field to display at that position. Optional; if omitted, computed by AWS. **(AI-inferred)**
                        </ResponseField>
                      </Expandable>
                    </ResponseField>
                    <ResponseField name="name" type="string">
                      The display name of the field group, shown as a heading in the case layout section to visually group related case fields. Optional; if omitted, computed by AWS. **(AI-inferred)**

                  </Expandable>
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="top_panel" type="object">
          Specifies the top panel of the basic layout, defining the sections and field items displayed at the top of the case view. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="sections" type="list(object)">
              Specifies the ordered list of sections in the top panel of the basic layout, where each section groups a set of case fields with an optional title for display in the case details view. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="field_group" type="object">
                  Defines the field group for a section in the top panel of the basic layout, including the group name and the list of case fields to display in that section. Optional; if omitted, computed by AWS. **(AI-inferred)**
                  <Expandable title="properties">
                    <ResponseField name="fields" type="list(object)">
                      Defines the list of fields included in this field group for the layout, each referencing a field from the case template by its identifier. Optional; if omitted, computed by AWS. **(AI-inferred)**

                          The unique identifier of the case field to display, referencing an existing field in the case domain. Optional; if omitted, computed by AWS. **(AI-inferred)**
                        </ResponseField>
                      </Expandable>

                    <ResponseField name="name" type="string">
                      The name of the field group, which serves as the display label for the set of fields grouped within the top panel section of the case layout. Optional; if omitted, computed by AWS. **(AI-inferred)**
                    </ResponseField>
                  </Expandable>

              </Expandable>
            </ResponseField>
          </Expandable>

      </Expandable>

</ResponseField>

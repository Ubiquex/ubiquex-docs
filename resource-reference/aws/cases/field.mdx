`aws_cases_field` defines one piece of data a case can capture, a system field or a custom one, with its own declared data type, created inside an `aws_cases_case` domain and referenced by ID from an `aws_cases_template`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cases "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own field"})

    		ubx.Resource(cases.Field, "example", cases.FieldConfig{
    			Name:        "example",
    			Type:        "example",
    			Attributes:  map[string]any{"text": map[string]any{"is_multiline": true}},
    			Description: "Managed by ubx.",
    			DomainId:    "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    import ubx_sdk as ubx
    from ubx.aws.cases import Field, FieldConfig
    from ubx.aws.cases.field import Field_Attributes, Field_Attributes_Text, Field_Tags

    def describe():
        ubx.intent("example own field")

        ubx.resource(Field, "example", FieldConfig(
            name="example",
            type="example",
            attributes=Field_Attributes(text=Field_Attributes_Text(is_multiline=True)),
            description="Managed by ubx.",
            domain_id="example",
            tags=[Field_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="attributes" type="object">
  Union of field attributes Optional.
  <Expandable title="properties">
    <ResponseField name="text" type="object">
      Field attributes for Text field type Optional.
      <Expandable title="properties">
        <ResponseField name="is_multiline" type="bool" required>
          Attribute that defines rendering component and validation Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A description explaining the purpose and usage of this field in cases. Helps agents and administrators understand what information should be captured in this field. Optional.
</ResponseField>

<ResponseField name="domain_id" type="string">
  The unique identifier of the Cases domain. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The display name of the field as it appears to agents in the case interface. Should be descriptive and user-friendly (e.g., 'Customer Priority Level', 'Issue Category'). Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags that you attach to this field. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS Cases field, used for metadata and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The data type of the field, which determines validation rules, input constraints, and display format. Each type has specific constraints: Text (string input), Number (numeric values), Boolean (true/false), DateTime (date/time picker), SingleSelect (dropdown options), Url (URL validation), User (Amazon Connect user selection). Required.
</ResponseField>

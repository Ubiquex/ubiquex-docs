`aws_cases_template` defines a case's object model, which `aws_cases_field`s it captures and which `aws_cases_layout` displays them, referencing both by ID, so every case created from the template shares the same real structure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cases "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own template"})

    		ubx.Resource(cases.Template, "example", cases.TemplateConfig{
    			Name:                "example",
    			Description:         "Managed by ubx.",
    			DomainId:            "example",
    			LayoutConfiguration: map[string]any{"default_layout": "example"},
    			RequiredFields:      []map[string]any{{"field_id": "example"}},
    			Rules:               []map[string]any{{"case_rule_id": "example"}},
    			Status:              "example",
    			Tags:                []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="description" type="string">
  A description explaining the purpose and use case for this template. Should indicate what types of cases this template is designed for and any specific workflow it supports. Optional.
</ResponseField>

<ResponseField name="domain_id" type="string">
  The unique identifier of the Cases domain. Optional.
</ResponseField>

<ResponseField name="layout_configuration" type="object">
  Specifies the default layout to use when displaying cases created from this template. The layout determines which fields are visible and their arrangement in the agent interface. Optional.
  <Expandable title="properties">
    <ResponseField name="default_layout" type="string">
      The unique identifier of a layout. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the template. It must be unique per domain. Required.
</ResponseField>

<ResponseField name="required_fields" type="list(object)">
  A list of fields that must contain a value for a case to be successfully created with this template. Optional.
  <Expandable title="properties">
    <ResponseField name="field_id" type="string">
      The identifier of the case field that must be included when creating a case using this template. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rules" type="list(object)">
  A list of case rules (also known as case field conditions) on a template. Optional.
  <Expandable title="properties">
    <ResponseField name="case_rule_id" type="string">
      Specifies the unique identifier for a rule within the AWS Cases template, used to reference the rule when defining conditional field requirements. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="field_id" type="string">
      The unique identifier of the case field in Amazon Cases that this rule applies to, matching a field defined in the associated domain. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the template. Active templates can be used to create new cases, while Inactive templates are disabled but preserved for existing cases. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags that you attach to this template. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_time" type="string">
  The time at which the template was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="last_modified_time" type="string">
  The time at which the template was created or last modified. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="template_arn" type="string">
  The Amazon Resource Name (ARN) of the template. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="template_id" type="string">
  The unique identifier of a template. Computed by AWS after `ship`.
</ResponseField>

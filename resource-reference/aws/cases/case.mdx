`aws_cases_case` is one real case record created from an `aws_cases_template` inside an `aws_cases_domain`, holding whatever field values that template defines, and evaluated against any `aws_cases_case_rule`s configured for the domain.

## Example

    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	ubx.Main(ubx.Stack("example", func() {

    			DomainId:   "example",
    			TemplateId: "example",
    			Title:      "example",
    			Tags:       []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="customer_id" type="string" required>
  The full customer profile ARN for the case. Required.
</ResponseField>

<ResponseField name="domain_id" type="string" required>
  The unique identifier of the Cases domain. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags for the case. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag attached to the AWS Cases case, used to store user-defined metadata for organizing, searching, or managing the case. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_id" type="string" required>
  A unique identifier of a template. Required.
</ResponseField>

<ResponseField name="title" type="string" required>
  The title of the case. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the case. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="case_id" type="string">
  A unique identifier of the case. Computed by AWS after `ship`.
</ResponseField>

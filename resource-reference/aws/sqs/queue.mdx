---
title: "aws_sqs_queue"
description: "A standard or FIFO SQS queue."
---

Amazon SQS is a fully managed message queue. `aws_sqs_queue` creates
and configures one, standard or FIFO, with a real, typed binding in
every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import sqs "github.com/ubiquex/ubx-sdk-aws-go/aws/sqs"

    ubx.Resource(sqs.Queue, "pipeline-events", sqs.QueueConfig{
        Name:                    "pipeline-events",
        MessageRetentionSeconds: 1209600,
        FifoQueue:               false,
    })
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Queue } from "jsr:@ubx/sdk-aws/aws/sqs/queue";

    resource(Queue, "pipeline-events", {
      name: "pipeline-events",
      messageRetentionSeconds: 1209600,
      fifoQueue: false,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.aws.sqs import Queue, QueueConfig

    ubx.resource(Queue, "pipeline-events", QueueConfig(
        name="pipeline-events",
        message_retention_seconds=1209600,
        fifo_queue=False,
    ))
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Provision an SQS queue called "pipeline-events", standard,
    messages retained for 14 days.
    ```
  </Tab>
</Tabs>

## Input properties

<ResponseField name="name" type="string">
  The queue's own name. Conflicts with `name_prefix`. For a FIFO queue,
  must end in `.fifo`.
</ResponseField>

<ResponseField name="name_prefix" type="string">
  A prefix, with a generated suffix appended. Conflicts with `name`.
</ResponseField>

<ResponseField name="visibility_timeout_seconds" type="number" default="30">
  How long a received message is hidden from other consumers.
</ResponseField>

<ResponseField name="message_retention_seconds" type="number" default="345600">
  How long a message is kept if never deleted. `60` to `1209600` (14 days).
</ResponseField>

<ResponseField name="max_message_size" type="number" default="262144">
  Largest allowed message, in bytes. `1024` to `262144`.
</ResponseField>

<ResponseField name="delay_seconds" type="number" default="0">
  Delivery delay for every message. `0` to `900`.
</ResponseField>

<ResponseField name="receive_wait_time_seconds" type="number" default="0">
  Long-poll wait time. `0` to `20`.
</ResponseField>

<ResponseField name="policy" type="string (JSON)">
  An IAM policy document controlling access to the queue.
</ResponseField>

<ResponseField name="redrive_policy" type="string (JSON)">
  Dead-letter queue configuration.
  <Expandable title="properties">
    <ResponseField name="deadLetterTargetArn" type="string">
      ARN of the dead-letter queue to send failed messages to.
    </ResponseField>
    <ResponseField name="maxReceiveCount" type="number">
      How many times a message may be received before moving to the dead-letter queue.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="redrive_allow_policy" type="string (JSON)">
  Which source queues may use this queue as their dead-letter target.
</ResponseField>

<ResponseField name="fifo_queue" type="bool" default="false">
  Whether this is a FIFO queue.
</ResponseField>

<ResponseField name="content_based_deduplication" type="bool" default="false">
  FIFO only: derive the deduplication ID from message content.
</ResponseField>

<ResponseField name="kms_master_key_id" type="string">
  A KMS key for server-side encryption, instead of SQS-managed keys.
</ResponseField>

<ResponseField name="kms_data_key_reuse_period_seconds" type="number" default="300">
  How long a data key is reused before re-calling KMS.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The queue's own URL, its real identifier.
</ResponseField>

<ResponseField name="arn" type="string">
  The queue's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="url" type="string">
  Same value as `id`.
</ResponseField>

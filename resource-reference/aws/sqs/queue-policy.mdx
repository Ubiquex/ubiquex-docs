`aws_sqs_queue_policy` attaches a real resource-based access policy to an `aws_sqs_queue`, controlling which principals can send messages to or receive messages from it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sqs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own queue policy"})

    		ubx.Resource(sqs.QueuePolicy, "ci-runner", sqs.QueuePolicyConfig{
    			PolicyDocument: "example",
    			Queues:         []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="policy_document" type="any" required>
  A policy document that contains the permissions for the specified SQS queues. For more information about SQS policies, see [Using custom policies with the access policy language](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/sqs-creating-custom-policies.html) in the *Developer Guide*. Required.
</ResponseField>

<ResponseField name="queues" type="list(string)" required>
  The URLs of the queues to which you want to add the policy. You can use the ``Ref`` function to specify an ``AWS::SQS::Queue`` resource. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of the SQS queue policy is the URL of the queue to which the policy is attached. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

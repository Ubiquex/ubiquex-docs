`aws_sqs_queue_inline_policy` attaches a real access policy directly to an `aws_sqs_queue`'s own resource definition, an alternative to managing the queue's policy as a separate `aws_sqs_queue_policy` resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sqs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own queue inline policy"})

    		ubx.Resource(sqs.QueueInlinePolicy, "ci-runner", sqs.QueueInlinePolicyConfig{
    			PolicyDocument: "example",
    			Queue:          "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="policy_document" type="any" required>
  A policy document that contains permissions to add to the specified SQS queue Required.
</ResponseField>

<ResponseField name="queue" type="string" required>
  The URL of the SQS queue. Required.
</ResponseField>

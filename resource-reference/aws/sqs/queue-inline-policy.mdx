`aws_sqs_queue_inline_policy` attaches a real access policy directly to an `aws_sqs_queue`'s own resource definition, an alternative to managing the queue's policy as a separate `aws_sqs_queue_policy` resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sqs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own queue inline policy"})

    		ubx.Resource(sqs.QueueInlinePolicy, "example", sqs.QueueInlinePolicyConfig{
    			PolicyDocument: "example",
    			Queue:          "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

        ubx.run("example", describe)

## Properties

<ResponseField name="policy_document" type="any" required>
  A policy document that contains permissions to add to the specified SQS queue Required.
</ResponseField>

<ResponseField name="queue" type="string" required>
  The URL of the SQS queue. Required.
</ResponseField>

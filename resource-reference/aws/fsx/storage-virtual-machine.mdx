`aws_fsx_storage_virtual_machine` is a real, independent virtual file server, with its own security style and network endpoint, running inside an `aws_fsx_file_system` (FSx for ONTAP), the NetApp SVM concept AWS FSx exposes directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	fsx "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/fsx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own storage virtual machine"})

    		ubx.Resource(fsx.StorageVirtualMachine, "example", fsx.StorageVirtualMachineConfig{
    			FileSystemId:                 "example",
    			Name:                         "example",
    			ActiveDirectoryConfiguration: map[string]any{"net_bios_name": "example-net-bios-name"},
    			RootVolumeSecurityStyle:      "example",
    			SvmAdminPassword:             "example",
    			Tags:                         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="active_directory_configuration" type="object">
  Specifies the Active Directory configuration for the storage virtual machine to join a domain, including the NetBIOS name and self-managed Active Directory settings such as domain name, organizational unit, and administrator credentials. Optional. **(AI-inferred)**
  <Expandable title="properties">

      Specifies the NetBIOS name of the Active Directory computer object that the FSx storage virtual machine will use when it is joined to a Microsoft Active Directory domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="self_managed_active_directory_configuration" type="object">
      Specifies the self-managed Microsoft Active Directory configuration for joining the storage virtual machine to the domain, including DNS server IP addresses, domain name, service account username and password, and optional organizational unit and administrator group settings. Optional. **(AI-inferred)**

        <ResponseField name="domain_join_service_account_secret" type="string">
          The password for the service account that FSx uses to join the storage virtual machine to the self-managed Active Directory domain. Optional. **(AI-inferred)**
        </ResponseField>

<ResponseField name="file_system_id" type="string" required>
  The unique identifier of the Amazon FSx for NetApp ONTAP file system on which the storage virtual machine is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the storage virtual machine (SVM), which must be unique within the file system. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="root_volume_security_style" type="string">
  Specifies the security style (UNIX, NTFS, or MIXED) for the storage virtual machine's root volume, determining how file permissions are evaluated for files and directories. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="svm_admin_password" type="string">
  Sets the password for the storage virtual machine's administrator (vsadmin) account, which must be at least 8 characters and cannot contain '/', '\', or '@'. Optional. **(AI-inferred)**
</ResponseField>

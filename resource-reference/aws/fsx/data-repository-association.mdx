`aws_fsx_data_repository_association` links an `aws_fsx_file_system` (FSx for Lustre) to a real S3 bucket, automatically and transparently presenting S3 objects as files and syncing changes in either direction, so Lustre can be used as a high-performance compute layer directly over data that lives durably in S3.

    		})

    }

## Input properties

<ResponseField name="batch_import_meta_data_on_create" type="bool">
  A boolean flag indicating whether an import data repository task to import metadata should run after the data repository association is created. The task runs if this flag is set to true. Optional.
</ResponseField>

<ResponseField name="data_repository_path" type="string" required>
  The path to the Amazon S3 data repository that will be linked to the file system. The path can be an S3 bucket or prefix in the format s3://myBucket/myPrefix/ . This path specifies where in the S3 data repository files will be imported from or exported to. Required.
</ResponseField>

<ResponseField name="file_system_id" type="string" required>
  The globally unique ID of the file system, assigned by Amazon FSx. Required.
</ResponseField>

<ResponseField name="file_system_path" type="string" required>
  This path specifies where in your file system files will be exported from or imported to. This file system directory can be linked to only one Amazon S3 bucket, and no other S3 bucket can be linked to the directory. Required.
</ResponseField>

<ResponseField name="imported_file_chunk_size" type="number">
  For files imported from a data repository, this value determines the stripe count and maximum amount of data per file (in MiB) stored on a single physical disk. The maximum number of disks that a single file can be striped across is limited by the total number of disks that make up the file system. Optional.
</ResponseField>

<ResponseField name="s3" type="object">
  The configuration for an Amazon S3 data repository linked to an Amazon FSx Lustre file system with a data repository association. The configuration defines which file events (new, changed, or deleted files or directories) are automatically imported from the linked data repository to the file system or automatically exported from the file system to the data repository. Optional.
  <Expandable title="properties">
    <ResponseField name="auto_export_policy" type="object">
      Specifies the type of updated objects (new, changed, deleted) that will be automatically exported from your file system to the linked S3 bucket. Optional.
      <Expandable title="properties">
        <ResponseField name="events" type="list(string)" required>
          Specifies the file system event types (NEW, CHANGED, DELETED) that trigger automatic export of file data from the FSx for Lustre file system to the linked S3 bucket. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="auto_import_policy" type="object">
      Specifies the type of updated objects (new, changed, deleted) that will be automatically imported from the linked S3 bucket to your file system. Optional.
      <Expandable title="properties">
        <ResponseField name="events" type="list(string)" required>
          Determines which S3 event types (NEW, CHANGED, DELETED) trigger automatic import of object changes from the linked S3 bucket into the FSx file system. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of Tag values, with a maximum of 50 elements. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Amazon FSx data repository association, used to identify and categorize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag key-value pair attached to the FSx data repository association, used to assign custom metadata for organizational and identification purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

---

`aws_fsx_s3_access_point_attachment` exposes an `aws_fsx_file_system`'s data through a real S3 access point, so applications that already speak the S3 API can read and write FSx-backed data without switching to a file protocol like NFS or SMB.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	fsx "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/fsx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own s3 access point attachment"})

    		ubx.Resource(fsx.S3AccessPointAttachment, "example", fsx.S3AccessPointAttachmentConfig{
    			Name:                 "example",
    			Type:                 "example",
    			OntapConfiguration:   map[string]any{"file_system_identity": map[string]any{"type": "example"}},
    			OpenZfsconfiguration: map[string]any{"file_system_identity": map[string]any{"posix_user": map[string]any{"gid": 1}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The name of the S3 access point attachment; also used for the name of the S3 access point. Required.
</ResponseField>

<ResponseField name="ontap_configuration" type="object">
  The ONTAP-specific settings for the S3 access point, defining the FSx for ONTAP volume to attach, the S3 bucket and read/write settings, and an optional alias used to address the access point. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="file_system_identity" type="object" required>
      Identifies the FSx for ONTAP file system and its storage virtual machine (SVM) to which the S3 access point is attached, containing the file system ID and SVM ID. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="type" type="string" required>
          Specifies the FSx for ONTAP user identity type, accepts either UNIX or WINDOWS. Required.
        </ResponseField>
        <ResponseField name="unix_user" type="object">
          Configures the Unix user identity (e.g., user name or UID) that the FSx for ONTAP S3 access point uses to map file system access requests to a specific Unix user's permissions. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="name" type="string" required>
              The name of the UNIX user. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="windows_user" type="object">
          Specifies the Windows user credentials (domain and password) that define the file system's identity when the FSx for ONTAP file system is joined to an Active Directory domain. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="name" type="string" required>
              The name of the Windows user. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="volume_id" type="string" required>
      The ID of the FSx for ONTAP volume that the S3 access point is attached to. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="open_zfsconfiguration" type="object">
  Optional.
  <Expandable title="properties">
    <ResponseField name="file_system_identity" type="object" required>
      Specifies the POSIX user ID and group ID (file system identity) that the OpenZFS file system uses when accessing the attached S3 access point. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="posix_user" type="object" required>
          Defines the POSIX user (UID and GID) on the FSx for OpenZFS file system that is used to map operations from the attached S3 access point. Required. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="gid" type="number" required>
              The GID of the file system user. Required.
            </ResponseField>
            <ResponseField name="secondary_gids" type="list(object)">
              The list of secondary GIDs for the file system user. Optional.
              <Expandable title="properties">
                <ResponseField name="gid" type="number">
                  The numeric secondary group ID (GID) that is added to the POSIX user's secondary group list for the file system identity used by the S3 access point attachment. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="uid" type="number" required>
              The UID of the file system user. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="type" type="string" required>
          Specifies the FSx for OpenZFS user identity type, accepts only POSIX. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="volume_id" type="string" required>
      The ID of the FSx for OpenZFS volume that the S3 access point is attached to. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of Amazon FSx volume that the S3 access point is attached to. Required.
</ResponseField>

## Output properties

<ResponseField name="lifecycle" type="string">
  The lifecycle status of the S3 access point attachment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="s3_access_point" type="object">
  Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="alias" type="string">

    </ResponseField>
    <ResponseField name="policy" type="any">
      The S3 access point's policy. Optional.
    </ResponseField>
    <ResponseField name="resource_arn" type="string">
      The S3 access point's ARN. Optional.
    </ResponseField>
    <ResponseField name="vpc_configuration" type="object">
      Specifies the VPC configuration for the S3 access point, including the VPC ID in which the access point is created and which restricts access to requests originating from that VPC only. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="vpc_id" type="string" required>
          Specifies the virtual private cloud (VPC) for the S3 access point VPC configuration, if one exists. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

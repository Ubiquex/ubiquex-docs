`aws_fsx_snapshot` is a real, point-in-time, incremental backup of an `aws_fsx_file_system` (FSx for OpenZFS), restorable to a new volume or file system without copying unchanged data every time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	fsx "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/fsx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own snapshot"})

    		ubx.Resource(fsx.Snapshot, "example", fsx.SnapshotConfig{
    			Name:     "example",
    			VolumeId: "example",
    			Tags:     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.fsx import Snapshot, SnapshotConfig
    from ubx.aws.fsx.snapshot import Snapshot_Tags

    def describe():
        ubx.intent("example own snapshot")

        ubx.resource(Snapshot, "example", SnapshotConfig(
            name="example",
            volume_id="example",
            tags=[Snapshot_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The user-assigned name of the FSx snapshot, used to identify it within the volume. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Amazon FSx snapshot, used to organize and identify the snapshot within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag attached to the FSx snapshot, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="volume_id" type="string" required>
  The ID of the Amazon FSx volume (file system) from which this snapshot is created. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to this FSx snapshot. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_arn" type="string">
  The Amazon Resource Name (ARN) assigned by AWS to the FSx snapshot, uniquely identifying it across regions and accounts. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

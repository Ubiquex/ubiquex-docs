---

`aws_fsx_volume` is a real, logical storage container, with its own size and data-management policies, created inside an `aws_fsx_file_system` (ONTAP or OpenZFS), the actual unit shares and mount points are exported from rather than the whole file system.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	fsx "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/fsx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own volume"})

    		ubx.Resource(fsx.Volume, "example", fsx.VolumeConfig{
    			Name:                 "example",
    			BackupId:             "example",
    			OntapConfiguration:   map[string]any{"storage_virtual_machine_id": "example"},
    			OpenZfsconfiguration: map[string]any{"parent_volume_id": "example"},
    			Tags:                 []map[string]any{{"key": "example"}},
    			VolumeType:           "example",
    		})
    	}))
    }
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.aws.fsx import Volume, VolumeConfig
    from ubx.aws.fsx.volume import Volume_OntapConfiguration, Volume_OpenZfsconfiguration, Volume_Tags

    def describe():
        ubx.intent("example own volume")

        ubx.resource(Volume, "example", VolumeConfig(
            name="example",
            backup_id="example",
            ontap_configuration=Volume_OntapConfiguration(storage_virtual_machine_id="example"),
            open_zfsconfiguration=Volume_OpenZfsconfiguration(parent_volume_id="example"),
            tags=[Volume_Tags(key="example")],
            volume_type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Output properties

<ResponseField name="resource_arn" type="string">
  The Amazon Resource Name (ARN) of the FSx volume. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="uuid" type="string">
  The system-assigned UUID for an FSx for OpenZFS volume, which serves as the unique mount name that clients use to access the volume and is distinct from the volume's resource ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="volume_id" type="string">
  The unique AWS-assigned identifier for the FSx volume, formatted as `fsvol-` followed by a 17-character hexadecimal string, which is populated after the volume is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

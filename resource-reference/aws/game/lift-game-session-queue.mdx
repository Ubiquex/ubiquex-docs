`aws_game_lift_game_session_queue` routes a real player's game session placement request to whichever `aws_game_lift_fleet`, across multiple fleets and locations, can host it fastest or cheapest, according to the queue's own defined priority order.

## Input properties

<ResponseField name="custom_event_data" type="string">
  Information that is added to all events that are related to this game session queue. Optional.
</ResponseField>

<ResponseField name="destinations" type="list(object)">
  A list of fleets and/or fleet aliases that can be used to fulfill game session placement requests in the queue. Optional.
  <Expandable title="properties">
    <ResponseField name="destination_arn" type="string">
      The ARN of a GameLift fleet or alias that this game session queue uses as a destination for game session placement requests. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="filter_configuration" type="object">
  Filters the locations where the queue can place new game sessions by specifying a list of allowed AWS region codes. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="allowed_locations" type="list(string)">
      A list of locations to allow game session placement in, in the form of AWS Region codes such as us-west-2. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A descriptive label that is associated with game session queue. Queue names must be unique within each Region. Required.
</ResponseField>

<ResponseField name="notification_target" type="string">
  An SNS topic ARN that is set up to receive game session placement notifications. Optional.
</ResponseField>

<ResponseField name="player_latency_policies" type="list(object)">
  A set of policies that act as a sliding cap on player latency. Optional.
  <Expandable title="properties">
    <ResponseField name="maximum_individual_player_latency_milliseconds" type="number">
      Sets the maximum acceptable latency in milliseconds for an individual player to a game location; if the player's latency exceeds this threshold, that location is excluded from consideration for the player's game session placement. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="policy_duration_seconds" type="number">
      The length of time in seconds that this player latency policy remains in effect for the game session placement. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="priority_configuration" type="object">
  Specifies the priority settings for the GameLift session queue, including the order in which locations are used and the order in which placement criteria like latency and cost are prioritized. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="location_order" type="list(string)">
      The prioritization order to use for fleet locations, when the PriorityOrder property includes LOCATION. Optional.
    </ResponseField>
    <ResponseField name="priority_order" type="list(string)">
      The recommended sequence to use when prioritizing where to place new game sessions. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to this GameLift game session queue, used to organize and identify the queue for cost and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag key-value pair applied to the GameLift game session queue for resource organization and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="timeout_in_seconds" type="number">
  The maximum time, in seconds, that a new game session placement request remains in the queue. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that is assigned to a Amazon GameLift game session queue resource and uniquely identifies it. Computed by AWS after `ship`.
</ResponseField>

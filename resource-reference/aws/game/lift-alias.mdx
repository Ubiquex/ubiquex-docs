`aws_game_lift_alias` points a stable, real identifier at a specific `aws_game_lift_fleet`, letting a caller redirect matchmaking and game clients to a new fleet, a blue/green deployment or a fleet in a different Region, without changing anything on the client side.

## Input properties

<ResponseField name="description" type="string">
  A human-readable description of the alias. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A descriptive label that is associated with an alias. Alias names do not need to be unique. Required.
</ResponseField>

<ResponseField name="routing_strategy" type="object" required>
  The routing strategy defines how a GameLift alias directs game session requests to fleets, either by specifying a fleet ID for simple routing or by providing a terminal message to stop routing. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="fleet_id" type="string">
      A unique identifier for a fleet that the alias points to. If you specify SIMPLE for the Type property, you must specify this property. Optional.
    </ResponseField>
    <ResponseField name="message" type="string">
      The message text to be used with a terminal routing strategy. If you specify TERMINAL for the Type property, you must specify this property. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Simple routing strategy. The alias resolves to one specific fleet. Use this type when routing to active fleets. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="alias_arn" type="string">
  The Amazon Resource Name (ARN) that is assigned to a Amazon GameLift Alias resource and uniquely identifies it. ARNs are unique across all Regions. In a GameLift Alias ARN, the resource ID matches the AliasId value. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="alias_id" type="string">
  Unique alias ID Computed by AWS after `ship`.
</ResponseField>

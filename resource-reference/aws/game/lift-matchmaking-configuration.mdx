`aws_game_lift_matchmaking_configuration` defines a real FlexMatch matchmaking pool, including which `aws_game_lift_matchmaking_rule_set` it evaluates candidate players against and which `aws_game_lift_game_session_queue` a completed match gets placed through.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	gamelift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/gamelift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lift matchmaking configuration"})

    		ubx.Resource(gamelift.MatchmakingConfiguration, "example", gamelift.MatchmakingConfigurationConfig{
    			AcceptanceRequired:       true,
    			Name:                     "example",
    			RequestTimeoutSeconds:    7200,
    			RuleSetName:              "example-rule-set-name",
    			AcceptanceTimeoutSeconds: 7200,
    			AdditionalPlayerCount:    1,
    			BackfillMode:             "example",
    			CreationTime:             "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="acceptance_required" type="bool" required>
  A flag that indicates whether a match that was created with this configuration must be accepted by the matched players Required.
</ResponseField>

<ResponseField name="acceptance_timeout_seconds" type="number">
  The length of time (in seconds) to wait for players to accept a proposed match, if acceptance is required. Optional.
</ResponseField>

<ResponseField name="additional_player_count" type="number">
  The number of player slots in a match to keep open for future players. Optional.
</ResponseField>

<ResponseField name="backfill_mode" type="string">
  The method used to backfill game sessions created with this matchmaking configuration. Optional.
</ResponseField>

<ResponseField name="creation_time" type="string">
  A time stamp indicating when this data object was created. Optional.
</ResponseField>

<ResponseField name="custom_event_data" type="string">
  Information to attach to all events related to the matchmaking configuration. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A descriptive label that is associated with matchmaking configuration. Optional.
</ResponseField>

<ResponseField name="flex_match_mode" type="string">
  Indicates whether this matchmaking configuration is being used with Amazon GameLift hosting or as a standalone matchmaking solution. Optional.
</ResponseField>

<ResponseField name="game_properties" type="list(object)">
  A set of custom properties for a game session, formatted as key:value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The identifying key of a custom game property (a key-value pair) that is passed to a matchmade game session to provide custom configuration data. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The string value of a game property key-value pair that is passed to GameLift matchmaking to filter or customize game sessions. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="game_session_data" type="string">
  A set of custom game session properties, formatted as a single string value. Optional.
</ResponseField>

<ResponseField name="game_session_queue_arns" type="list(string)">
  The Amazon Resource Name (ARN) that is assigned to a Amazon GameLift game session queue resource and uniquely identifies it. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A unique identifier for the matchmaking configuration. Required.
</ResponseField>

<ResponseField name="notification_target" type="string">
  An SNS topic ARN that is set up to receive matchmaking notifications. Optional.
</ResponseField>

<ResponseField name="request_timeout_seconds" type="number" required>
  The maximum duration, in seconds, that a matchmaking ticket can remain in process before timing out. Required.
</ResponseField>

<ResponseField name="rule_set_arn" type="string">
  The Amazon Resource Name (ARN) associated with the GameLift matchmaking rule set resource that this configuration uses. Optional.
</ResponseField>

<ResponseField name="rule_set_name" type="string" required>
  A unique identifier for the matchmaking rule set to use with this configuration. Required.
</ResponseField>

    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.

  </Expandable>
</ResponseField>

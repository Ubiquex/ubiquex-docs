`aws_game_lift_location` registers a real, custom location, a caller's own data center or an unsupported AWS Region, that an `aws_game_lift_fleet` running in Anywhere mode can actually be deployed to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	game "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/game"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lift location"})

    		ubx.Resource(game.LiftLocation, "example", game.LiftLocationConfig{
    			LocationName: "example-location-name",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="location_name" type="string" required>
  Specifies the name of the GameLift location, which is typically an AWS Region code (e.g., 'us-east-1') or a custom location name used to identify the location for game hosting. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the GameLift location, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the GameLift location, returned after the location is created and used for referencing it in IAM policies and other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_eks_access_entry` grants a real IAM principal access to an `aws_eks_cluster`'s Kubernetes API, EKS's own current, native authentication and authorization mechanism that replaced the older aws-auth ConfigMap approach.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own access entry"})

    		ubx.Resource(eks.AccessEntry, "example", eks.AccessEntryConfig{
    			ClusterName:      "example-cluster-name",
    			PrincipalArn:     "arn:aws:iam::123456789012:policy/example",
    			AccessPolicies:   []map[string]any{{"access_scope": map[string]any{"namespaces": []string{"example"}}}},
    			KubernetesGroups: []string{"example"},
    			Tags:             []map[string]any{{"key": "example"}},
    			Type:             "example",
    			Username:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_policies" type="list(object)">
  An array of access policies that are associated with the access entry. Optional.
  <Expandable title="properties">
    <ResponseField name="access_scope" type="object">
      Defines the scope of the access policy, either for the entire cluster when the type is 'cluster' or for the specified namespaces when the type is 'namespace'. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="namespaces" type="list(string)">
          The namespaces that the access policy applies to when the access scope type is set to 'namespace', restricting the policy's permissions to those specific Kubernetes namespaces. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies whether the access policy applies to the entire EKS cluster or only to specific Kubernetes namespaces, with allowed values of 'cluster' or 'namespace'. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="policy_arn" type="string">
      The ARN of the IAM access policy that is associated with the access entry for the EKS cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cluster_name" type="string" required>
  The cluster that the access entry is created for. Required.
</ResponseField>

<ResponseField name="kubernetes_groups" type="list(string)">
  The Kubernetes groups that the access entry is associated with. Optional.
</ResponseField>

<ResponseField name="principal_arn" type="string" required>
  The principal ARN that the access entry is created for. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined key for a tag attached to the EKS access entry, used to label and categorize the entry for management and cost tracking in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the EKS access entry, used to categorize or identify the resource for management and access control purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The node type to associate with the access entry. Optional.
</ResponseField>

<ResponseField name="username" type="string">
  The Kubernetes user that the access entry is associated with. Optional.
</ResponseField>

## Output properties

<ResponseField name="access_entry_arn" type="string">
  The ARN of the access entry. Computed by AWS after `ship`.
</ResponseField>

`aws_eks_certificate_authority` retrieves a real `aws_eks_cluster`'s own certificate authority data, the trust root a kubeconfig or OIDC-based IAM role trust policy needs to validate the cluster's API server or service account tokens.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate authority"})

    		ubx.Resource(eks.CertificateAuthority, "example", eks.CertificateAuthorityConfig{
    			ClusterName: "example-cluster-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { CertificateAuthority } from "@ubx/sdk-aws/aws/eks/certificate_authority";

    export default stack("example", () => {
      intent({ summary: "example own certificate authority" });

      resource(CertificateAuthority, "example", {
        clusterName: "example-cluster-name",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.eks import CertificateAuthority, CertificateAuthorityConfig

    def describe():
        ubx.intent("example own certificate authority")

        ubx.resource(CertificateAuthority, "example", CertificateAuthorityConfig(
            cluster_name="example-cluster-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="cluster_name" type="string" required>
  The name of the EKS cluster that the certificate authority belongs to. Required.
</ResponseField>

## Output properties

<ResponseField name="activated_at" type="string">
  The timestamp when the certificate authority was activated. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="activated_by" type="string">
  The entity that activated the certificate authority. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when the certificate authority was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_by" type="string">
  The entity that created the certificate authority. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="data" type="string">
  The Base64 encoded certificate authority data. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="distribution_status" type="string">
  The distribution status of the certificate authority. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier of the certificate authority. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="rollback_available" type="bool">
  Whether activation of this certificate authority can still be rolled back. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="scheduled_events" type="object">
  The scheduled auto-activation events for the certificate authority, computed from its validity window. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="final_auto_activation" type="string">
      The deadline by which EKS will auto-activate this certificate authority (notAfter minus 45 days). Optional.
    </ResponseField>
    <ResponseField name="first_auto_activation" type="string">
      The earliest date EKS may auto-activate this certificate authority (notAfter minus 6 months). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="signing_status" type="string">
  The signing status of the certificate authority. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="validity" type="object">
  The validity period of the certificate authority. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="not_after" type="string">
      The end of the validity period for the certificate authority. Optional.
    </ResponseField>
    <ResponseField name="not_before" type="string">
      The start of the validity period for the certificate authority. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

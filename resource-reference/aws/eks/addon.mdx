`aws_eks_addon` installs and manages a real, EKS-curated operational component, the VPC CNI, CoreDNS, kube-proxy among common ones, on an `aws_eks_cluster`, with its own version tracking and update lifecycle handled by EKS rather than a caller applying manifests and managing upgrades by hand.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own addon"})

    		ubx.Resource(eks.Addon, "example", eks.AddonConfig{
    			AddonName:               "example-addon-name",
    			ClusterName:             "example-cluster-name",
    			AddonVersion:            "example",
    			ConfigurationValues:     "example",
    			NamespaceConfig:         map[string]any{"namespace": "example"},
    			PodIdentityAssociations: []map[string]any{{"role_arn": "example"}},
    			PreserveOnDelete:        true,
    			ResolveConflicts:        "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="addon_name" type="string" required>
  Name of Addon Required.
</ResponseField>

<ResponseField name="addon_version" type="string">
  Version of Addon Optional.
</ResponseField>

<ResponseField name="cluster_name" type="string" required>
  Name of Cluster Required.
</ResponseField>

<ResponseField name="configuration_values" type="string">
  The configuration values to use with the add-on Optional.
</ResponseField>

<ResponseField name="namespace_config" type="object">
  The custom namespace configuration to use with the add-on Optional.
  <Expandable title="properties">
    <ResponseField name="namespace" type="string" required>
      The custom namespace for creating the add-on Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pod_identity_associations" type="list(object)">
  An array of pod identities to apply to this add-on. Optional.
  <Expandable title="properties">
    <ResponseField name="role_arn" type="string">
      The ARN of the IAM role to associate with the Kubernetes service account for the EKS pod identity association, which grants pods that use that service account permissions to call AWS APIs. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="service_account" type="string">
      The name of the Kubernetes service account that the addon's pod identity association will map to the specified IAM role, granting the addon permissions via that role. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="preserve_on_delete" type="bool">
  PreserveOnDelete parameter value Optional.
</ResponseField>

<ResponseField name="resolve_conflicts" type="string">
  Resolve parameter value conflicts Optional.
</ResponseField>

<ResponseField name="service_account_role_arn" type="string">
  IAM role to bind to the add-on's service account Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The string value assigned to a tag key on the EKS addon, used to store arbitrary metadata such as environment or owner identifiers for the addon. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

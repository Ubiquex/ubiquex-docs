`aws_kafka_connect_connector` runs a real, managed Kafka Connect connector, MSK Connect provisioning and scaling the underlying compute, moving data between an Apache Kafka or Amazon MSK cluster and an external system without a caller operating their own Kafka Connect worker cluster.

## Input properties

          The maximum number of workers for a connector. Required.

        </ResponseField>
        <ResponseField name="min_worker_count" type="number" required>

          Information about the scale in policy of the connector. Required.

          Information about the scale out policy of the connector. Required.
          <Expandable title="properties">
            <ResponseField name="cpu_utilization_percentage" type="number" required>

            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>

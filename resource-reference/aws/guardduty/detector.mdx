`aws_guard_duty_detector` turns on GuardDuty for an account and Region, the real, top-level resource that continuously analyzes VPC Flow Logs, DNS logs, and CloudTrail events for threats, every other GuardDuty resource, filters, IP lists, member associations, attaches to a detector.

`aws_health_lake_fhirdatastore` creates a real, managed, FHIR R4-compliant datastore that AWS HealthLake stores and indexes structured health data in, queryable directly through the FHIR API rather than a caller building their own FHIR server.

## Input properties

<ResponseField name="datastore_name" type="string">
  The user-generated name for the Data Store. Optional.
</ResponseField>

<ResponseField name="datastore_type_version" type="string" required>
  The FHIR version. Only R4 version data is supported. Required.
</ResponseField>

<ResponseField name="identity_provider_configuration" type="object">
  The identity provider configuration for the datastore Optional.
  <Expandable title="properties">
    <ResponseField name="authorization_strategy" type="string" required>
      Type of Authorization Strategy. The two types of supported Authorization strategies are SMART_ON_FHIR_V1 and AWS_AUTH. Required.
    </ResponseField>
    <ResponseField name="fine_grained_authorization_enabled" type="bool">
      Flag to indicate if fine-grained authorization will be enabled for the datastore Optional.
    </ResponseField>
    <ResponseField name="idp_lambda_arn" type="string">
      The Amazon Resource Name (ARN) of the Lambda function that will be used to decode the access token created by the authorization server. Optional.
    </ResponseField>
    <ResponseField name="metadata" type="string">
      The JSON metadata elements for identity provider configuration. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="preload_data_config" type="object">
  The preloaded data configuration for the Data Store. Only data preloaded from Synthea is supported. Optional.
  <Expandable title="properties">
    <ResponseField name="preload_data_type" type="string" required>
      The type of preloaded data. Only Synthea preloaded data is supported. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sse_configuration" type="object">
  The server-side encryption key configuration for a customer provided encryption key. Optional.
  <Expandable title="properties">
    <ResponseField name="kms_encryption_config" type="object" required>
      The customer-managed-key (CMK) used when creating a Data Store. If a customer owned key is not specified, an AWS owned key will be used for encryption. Required.
      <Expandable title="properties">
        <ResponseField name="cmk_type" type="string" required>
          The type of customer-managed-key (CMK) used for encryption. The two types of supported CMKs are customer owned CMKs and AWS owned CMKs. Required.
        </ResponseField>
        <ResponseField name="kms_key_id" type="string">
          The KMS encryption key id/alias used to encrypt the Data Store contents at rest. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags (key-value pairs) to attach to the FHIR datastore, used for organizing, identifying, and managing the resource, such as for cost allocation or access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the AWS HealthLake FHIR Data Store, used to organize and identify the datastore for cost allocation and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to an AWS HealthLake FHIR DataStore, used to organize, categorize, and track the datastore for cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_at" type="object">
  The time that a Data Store was created. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="nanos" type="number" required>
      Nanoseconds. Required.
    </ResponseField>
    <ResponseField name="seconds" type="string" required>
      Seconds since epoch. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="datastore_arn" type="string">
  The Amazon Resource Name used in the creation of the Data Store. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="datastore_endpoint" type="string">
  The AWS endpoint for the Data Store. Each Data Store will have it's own endpoint with Data Store ID in the endpoint URL. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="datastore_id" type="string">
  The AWS-generated ID number for the Data Store. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="datastore_status" type="string">
  The status of the Data Store. Possible statuses are 'CREATING', 'ACTIVE', 'DELETING', or 'DELETED'. Computed by AWS after `ship`.
</ResponseField>

`aws_ssmcontacts_plan` defines a real sequence of engagement stages and channels, SMS then voice then email, for an `aws_ssmcontacts_contact`, controlling how and when that contact is actually notified during an incident.

## Input properties

<ResponseField name="contact_id" type="string">
  Contact ID for the AWS SSM Incident Manager Contact to associate the plan. Optional.
</ResponseField>

<ResponseField name="rotation_ids" type="list(string)">
  Rotation Ids to associate with Oncall Contact for engagement. Optional.
</ResponseField>

<ResponseField name="stages" type="list(object)">
  The stages that an escalation plan or engagement plan engages contacts and contact methods in. Optional.
  <Expandable title="properties">
    <ResponseField name="duration_in_minutes" type="number">
      The duration, in minutes, for which this stage of the engagement runs before moving to the next stage or ending the engagement. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="targets" type="list(object)">
      Specifies the contacts or contact channels that are notified when this stage of the on-call escalation plan is reached, based on the escalation time. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="channel_target_info" type="object">
          Specifies the target as a contact channel rather than a contact, detailing the contact channel's identifier and the retry interval in minutes to wait before re-contacting it during the escalation stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="channel_id" type="string">
              The Amazon Resource Name (ARN) of the contact channel to notify when this stage is triggered. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="retry_interval_in_minutes" type="number">
              The number of minutes to wait before retrying the contact channel if the previous attempt fails, as part of the channel target configuration in an SSM Contacts plan stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="contact_target_info" type="object">
          Identifies an SSM Contacts contact as a target for the stage, using its contact ID and an IsEssential flag that determines whether the contact must be reached for the on-call handoff to continue. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="contact_id" type="string">
              The Amazon Resource Name (ARN) of the AWS SSM Contacts contact that this stage targets when the escalation plan is executed. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="is_essential" type="bool">
              A boolean that, when true, marks this contact as essential so that if the contact cannot be reached during an incident, the escalation plan stops and does not continue to subsequent targets. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the contact. Computed by AWS after `ship`.
</ResponseField>

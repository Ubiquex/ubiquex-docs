`aws_ssmcontacts_contact_channel` adds a real delivery channel, an SMS number, phone number, or email address, to an `aws_ssmcontacts_contact`, the resource that actually receives an engagement when Incident Manager pages that contact.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ssmcontacts "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ssmcontacts"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own contact channel"})

    		ubx.Resource(ssmcontacts.ContactChannel, "ci-runner", ssmcontacts.ContactChannelConfig{
    			ChannelAddress:  "example",
    			ChannelName:     "example-channel-name",
    			ChannelType:     "example",
    			ContactId:       "example",
    			DeferActivation: true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="channel_address" type="string">
  The details that SSM Incident Manager uses when trying to engage the contact channel. Optional.
</ResponseField>

<ResponseField name="channel_name" type="string">
  The device name. String of 6 to 50 alphabetical, numeric, dash, and underscore characters. Optional.
</ResponseField>

<ResponseField name="channel_type" type="string">
  Device type, which specify notification channel. Currently supported values: “SMS”, “VOICE”, “EMAIL”, “CHATBOT. Optional.
</ResponseField>

<ResponseField name="contact_id" type="string">
  ARN of the contact resource Optional.
</ResponseField>

<ResponseField name="defer_activation" type="bool">
  If you want to activate the channel at a later time, you can choose to defer activation. SSM Incident Manager can't engage your contact channel until it has been activated. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the engagement to a contact channel. Computed by AWS after `ship`.
</ResponseField>

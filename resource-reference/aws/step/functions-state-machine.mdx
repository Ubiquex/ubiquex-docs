`aws_step_functions_state_machine` defines a real workflow, in Amazon States Language, as a graph of states, tasks, choices, parallel branches, retries, that Step Functions executes and tracks the progress of.

</ResponseField>

<ResponseField name="definition_s3_location" type="object">

      The name of the Amazon S3 bucket that contains the state machine definition file (the JSON or YAML file referenced by the Key in the same DefinitionS3Location property). Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="key" type="string" required>
      The S3 object key of the state machine definition file, located within the bucket specified by the sibling 'bucket' field of the same 'definition_s3_location' object. Required. **(AI-inferred)**

    <ResponseField name="version" type="string">
      The version ID of the S3 object that contains the state machine definition. Optional. **(AI-inferred)**

  </Expandable>
</ResponseField>

<ResponseField name="definition_string" type="string">
  Specifies the Amazon States Language (ASL) definition of the Step Functions state machine as a JSON string. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="definition_substitutions" type="any">
  Provides key-value pairs that substitute variables in the state machine definition string, allowing the same definition to be reused across environments by replacing $&#123;key&#125; placeholders. Optional. **(AI-inferred)**

<ResponseField name="encryption_configuration" type="object">

    </ResponseField>
    <ResponseField name="type" type="string" required>
      Determines whether the state machine uses AWS-owned encryption or a customer-managed KMS key for encrypting execution data at rest. Required. **(AI-inferred)**

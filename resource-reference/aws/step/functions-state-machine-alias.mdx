`aws_step_functions_state_machine_alias` creates a real named pointer to one or two weighted `aws_step_functions_state_machine_version`s, letting new executions be shifted gradually to a new version without changing the ARN callers invoke.

## Example

## Input properties

<ResponseField name="deployment_preference" type="object">
  The settings to enable gradual state machine deployments. Optional.
  <Expandable title="properties">
    <ResponseField name="alarms" type="list(string)">
      A list of CloudWatch alarm names that will be monitored during the deployment. The deployment will fail and rollback if any alarms go into ALARM state. Optional.
    </ResponseField>
    <ResponseField name="interval" type="number">
      The time in minutes between each traffic shifting increment. Optional.
    </ResponseField>
    <ResponseField name="percentage" type="number">
      The percentage of traffic to shift to the new version in each increment. Optional.
    </ResponseField>
    <ResponseField name="state_machine_version_arn" type="string" required>
      The ARN of the state machine version to be deployed as the target of the alias's traffic-shifting deployment preference, to which traffic is gradually shifted according to the selected deployment strategy. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of deployment to perform. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of the alias. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The alias name. Optional.
</ResponseField>

<ResponseField name="routing_configuration" type="list(object)">
  The routing configuration of the alias. One or two versions can be mapped to an alias to split StartExecution requests of the same state machine. Optional.
  <Expandable title="properties">
    <ResponseField name="state_machine_version_arn" type="string">
      The ARN of the state machine version to which a portion of execution traffic is routed when using the alias's routing configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="weight" type="number">
      The percentage of traffic (a weight between 0 and 100) routed to the corresponding state machine version in the alias's routing configuration, where all weights in the routing configuration sum to 100. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state_machine_arn" type="string">
  The Amazon Resource Name (ARN) of the Step Functions state machine that this alias refers to. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the alias. Computed by AWS after `ship`.
</ResponseField>

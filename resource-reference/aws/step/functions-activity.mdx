`aws_step_functions_activity` creates a real named task that external workers, code running outside AWS, on-premises or third-party, poll for work and report results back to, the mechanism an `aws_step_functions_state_machine` uses to include a manual or external step in an otherwise automated workflow.

    	}))
    }

## Input properties

<ResponseField name="encryption_configuration" type="object">
  Optional.
  <Expandable title="properties">
    <ResponseField name="kms_data_key_reuse_period_seconds" type="number">
      Specifies the maximum duration, in seconds, that AWS Step Functions will reuse a customer-managed data key from AWS KMS before requesting a new one for encrypting activity data. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="kms_key_id" type="string">
      The AWS KMS key ID or ARN used to encrypt the activity's data when encryption is configured for the Step Functions activity. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Specifies the type of encryption key used for the activity's data, distinguishing between a customer-managed AWS KMS key (CUSTOMER_MANAGED_KMS_KEY) and an AWS-owned key (AWS_OWNED_KEY). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Step Functions activity, which must be unique within the AWS account and region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the key-value pairs used to tag the Step Functions activity, enabling you to categorize and manage the activity's resources within AWS. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Step Functions activity, used to categorize and manage the activity resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Step Functions activity. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying this AWS Step Functions activity, which is used to reference the activity in state machine definitions. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

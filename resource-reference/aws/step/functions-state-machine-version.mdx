`aws_step_functions_state_machine_version` publishes a real, immutable version of an `aws_step_functions_state_machine`'s current definition, letting an `aws_step_functions_state_machine_alias` or a direct caller pin to a specific, unchanging version.

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own functions state machine version"})

    		ubx.Resource(step.FunctionsStateMachineVersion, "ci-runner", step.FunctionsStateMachineVersionConfig{
    			StateMachineArn:        "arn:aws:iam::123456789012:policy/ci",
    			Description:            "Managed by ubx.",
    			StateMachineRevisionId: "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="description" type="string">
  An optional description of the state machine version, used to provide a human-readable label for the version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="state_machine_arn" type="string" required>
  The Amazon Resource Name (ARN) of the state machine for which this version is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="state_machine_revision_id" type="string">
  Specifies the revision ID of the state machine to create the version from; if omitted, the version is created from the latest revision. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this state machine version, including the state machine name and version number. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

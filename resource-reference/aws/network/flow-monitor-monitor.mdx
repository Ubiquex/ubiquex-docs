`aws_network_flow_monitor_monitor` creates a real Amazon CloudWatch Network Flow Monitor monitor, scoped to local and remote AWS resources by type, EC2 instances, subnets, VPCs, and more, that reports near-real-time network performance metrics, retransmissions and data transferred, for the actual traffic flowing between them. Network Flow Monitor is a comparatively recent CloudWatch capability, launched at re:Invent in December 2024; this entry is verified against AWS's own field-level schema live this session rather than assumed from general knowledge, since it did not turn up a dedicated CloudFormation reference page the way older resources do.

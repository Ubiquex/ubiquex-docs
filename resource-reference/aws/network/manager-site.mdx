`aws_network_manager_site` represents a real physical location, an office or data center, within an `aws_network_manager_global_network` that `aws_network_manager_device`s are associated with.

## Input properties

<ResponseField name="description" type="string">
  The description of the site. Optional.
</ResponseField>

<ResponseField name="global_network_id" type="string" required>
  The ID of the global network. Required.
</ResponseField>

<ResponseField name="location" type="object">
  The location of the site Optional.
  <Expandable title="properties">
    <ResponseField name="address" type="string">
      The physical address. Optional.
    </ResponseField>
    <ResponseField name="latitude" type="string">
      The latitude. Optional.
    </ResponseField>
    <ResponseField name="longitude" type="string">
      The longitude. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the site. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key is a metadata label that can be applied to an AWS Network Manager Site, allowing you to categorize and filter the site within your global network for management and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag applied to the AWS Network Manager site. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

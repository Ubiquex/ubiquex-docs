`aws_network_firewall_firewall` creates a real managed, stateful network firewall attached to a VPC's subnets, enforcing the rules defined by an `aws_network_firewall_firewall_policy` against traffic passing through it.

## Input properties

<ResponseField name="availability_zone_change_protection" type="bool">
  Controls whether the firewall's assigned Availability Zones can be changed, with true preventing any modifications to the Availability Zones associated with the firewall. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="availability_zone_mappings" type="list(object)">
  Specifies the Availability Zones and subnet IDs where the firewall endpoints are created, enabling network traffic filtering in those zones. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="availability_zone" type="string">
      The Availability Zone (e.g., us-east-1a) where the Network Firewall endpoint is deployed, matching the zone of the associated subnet in the mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="delete_protection" type="bool">
  Whether the firewall is protected from deletion, so you cannot delete it without first disabling this setting. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A description of the firewall, as provided by the user, which helps identify the firewall's purpose or context. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled_analysis_types" type="list(string)">
  The types of analysis to enable for the firewall. Can be TLS_SNI, HTTP_HOST, or both. Optional.
</ResponseField>

<ResponseField name="firewall_name" type="string" required>
  A descriptive name for the Network Firewall firewall, used as an identifier for the resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="firewall_policy_arn" type="string" required>
  A resource ARN. Required.
</ResponseField>

<ResponseField name="firewall_policy_change_protection" type="bool">
  When set to true, prevents the firewall policy associated with this firewall from being changed, allowing updates only after this protection is disabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_change_protection" type="bool">
  Indicates whether the firewall's subnet mappings are protected from changes, requiring the protection to be disabled before you can modify the subnets associated with the firewall. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_mappings" type="list(object)">
  Specifies the subnets within the VPC where the Network Firewall endpoint is attached, enabling the firewall to filter traffic for each associated subnet. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="ipaddress_type" type="string">
      Specifies whether the firewall endpoint in the associated subnet uses an IPv4 or IPv6 address, with valid values 'IPV4' or 'IPV6'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="subnet_id" type="string">
      The ID of the subnet in the VPC where the firewall endpoint is deployed. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.

      The key of a tag assigned to the Network Firewall firewall, used to categorize and identify the resource for management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The tag value pairs with a corresponding tag key to label the Network Firewall firewall for resource organization, cost allocation, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="transit_gateway_id" type="string">
  Optional.
</ResponseField>

<ResponseField name="vpc_id" type="string">
  The unique identifier of the Amazon Virtual Private Cloud (VPC) where the AWS Network Firewall firewall is deployed. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="endpoint_ids" type="list(string)">
  The list of VPC endpoint IDs created for the firewall in each of its associated subnets, used to route traffic to the firewall. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="firewall_arn" type="string">
  A resource ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="firewall_id" type="string">
  The unique identifier assigned by AWS to this Network Firewall firewall. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="transit_gateway_attachment_id" type="string">
  The unique identifier of the Transit Gateway attachment that connects the firewall to its VPC, populated after the firewall is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

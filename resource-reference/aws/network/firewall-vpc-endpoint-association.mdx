`aws_network_firewall_vpc_endpoint_association` attaches a real additional subnet-scoped firewall endpoint to an existing `aws_network_firewall_firewall`, letting one firewall protect multiple VPCs or provide multiple endpoints within a single VPC's Availability Zone, a capability AWS Network Firewall added in May 2025.

`aws_network_interface_permission` grants a real cross-account permission on an `aws_network_interface`, letting another AWS account attach that interface to an instance it owns.

## Example

## Input properties

<ResponseField name="aws_account_id" type="string" required>
  The AWS account ID that is granted permission to attach the network interface to an instance or associate it with an Elastic IP. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_interface_id" type="string" required>
  The ID of the Elastic Network Interface (ENI) to which this permission grants cross-account attachment access. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="permission" type="string" required>
  The type of permission to grant on the network interface, either INSTANCE-ATTACH (allows an instance to attach to the interface) or EIP-ASSOCIATE (allows an Elastic IP to be associated with the interface). Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to this network interface permission, used to reference the permission in other API calls. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

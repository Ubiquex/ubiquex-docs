`aws_network_manager_device` registers a real physical or virtual on-premises networking device, a router or firewall, into an `aws_network_manager_global_network` so Network Manager can represent it in its own topology and route analysis.

## Input properties

  The Amazon Web Services location of the device, if applicable. Optional.

    <ResponseField name="zone" type="string">

`aws_network_interface_attachment` attaches a real `aws_network_interface` to a specific EC2 instance at a chosen device index, the resource that actually represents the attach action rather than the interface itself.

## Input properties

<ResponseField name="delete_on_termination" type="bool">
  Whether to delete the network interface when the instance terminates. By default, this value is set to ``true``. Optional.
</ResponseField>

<ResponseField name="device_index" type="string" required>
  The network interface's position in the attachment order. For example, the first attached network interface has a ``DeviceIndex`` of 0. Required.
</ResponseField>

<ResponseField name="ena_queue_count" type="number">
  The number of ENA queues created with the instance. Optional.
</ResponseField>

<ResponseField name="ena_srd_specification" type="object">
  ENA Express uses AWS Scalable Reliable Datagram (SRD) technology to increase the maximum bandwidth used per stream and minimize tail latency of network traffic between EC2 instances. With ENA Express, you can communicate between two EC2 instances in the same subnet within the same account, or in different accounts. Both sending and receiving instances must have ENA Express enabled. To improve the reliability of network packet delivery, ENA Express reorders network packets on the receiving end by default. However, some UDP-based applications are designed to handle network packets that are out of order to reduce the overhead for packet delivery at the network layer. When ENA Express is enabled, you can specify whether UDP network traffic uses it. Optional.
  <Expandable title="properties">
    <ResponseField name="ena_srd_enabled" type="bool">
      Indicates whether ENA Express is enabled for the network interface. Optional.
    </ResponseField>
    <ResponseField name="ena_srd_udp_specification" type="object">
      Configures ENA Express for UDP network traffic. Optional.
      <Expandable title="properties">
        <ResponseField name="ena_srd_udp_enabled" type="bool">
          Enable ENA Express (Scalable Reliable Datagram) for UDP traffic on the network interface attachment, which can improve throughput and reduce latency for UDP workloads. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="instance_id" type="string" required>
  The ID of the instance to which you will attach the ENI. Required.
</ResponseField>

<ResponseField name="network_interface_id" type="string" required>
  The ID of the ENI that you want to attach. Required.
</ResponseField>

## Output properties

<ResponseField name="attachment_id" type="string">
  The unique identifier for the attachment between the network interface and the instance. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

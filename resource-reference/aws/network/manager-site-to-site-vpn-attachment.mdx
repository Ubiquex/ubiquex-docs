`aws_network_manager_site_to_site_vpn_attachment` attaches a real Site-to-Site VPN connection to an `aws_network_manager_core_network`, bringing that VPN's routes into Cloud WAN's centrally managed routing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	networkmanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/networkmanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own manager site to site vpn attachment"})

    		ubx.Resource(networkmanager.SiteToSiteVpnAttachment, "example", networkmanager.SiteToSiteVpnAttachmentConfig{
    			CoreNetworkId:                      "example",
    			VpnConnectionArn:                   "arn:aws:iam::123456789012:policy/example",
    			NetworkFunctionGroupName:           "example-networkmanager-function-group-name",
    			ProposedNetworkFunctionGroupChange: map[string]any{"attachment_policy_rule_number": 1},
    			ProposedSegmentChange:              map[string]any{"attachment_policy_rule_number": 1},
    			RoutingPolicyLabel:                 "example",
    			Tags:                               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="core_network_id" type="string" required>
  The ID of a core network where you're creating a site-to-site VPN attachment. Required.
</ResponseField>

<ResponseField name="network_function_group_name" type="string">
  The name of the network function group attachment. Optional.
</ResponseField>

<ResponseField name="proposed_network_function_group_change" type="object">
  The attachment to move from one network function group to another. Optional.
  <Expandable title="properties">
    <ResponseField name="attachment_policy_rule_number" type="number">
      The rule number in the policy document that applies to this change. Optional.
    </ResponseField>
    <ResponseField name="network_function_group_name" type="string">
      The name of the network function group to change. Optional.
    </ResponseField>
    <ResponseField name="tags" type="list(object)">
      The key-value tags that changed for the network function group. Optional.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key of a tag associated with the proposed network function group change for the Site-to-Site VPN attachment, used to label the network function group change for tracking and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          Optional; if omitted, computed by AWS.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="proposed_segment_change" type="object">
  The attachment to move from one segment to another. Optional.
  <Expandable title="properties">
    <ResponseField name="attachment_policy_rule_number" type="number">
      The rule number in the policy document that applies to this change. Optional.
    </ResponseField>
    <ResponseField name="segment_name" type="string">
      The name of the segment to change. Optional.
    </ResponseField>
    <ResponseField name="tags" type="list(object)">
      The key-value tags that changed for the segment. Optional.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key (name) of a tag to apply to the proposed segment change for the AWS Network Manager site-to-site VPN attachment, used to identify or organize the change metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The value of a tag attached to the proposed segment change for the site-to-site VPN attachment. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="routing_policy_label" type="string">
  Routing policy label Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags for the attachment. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag to assign to the Site-to-Site VPN attachment, used to organize and identify the attachment within AWS Network Manager. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag (key-value pair) applied to the AWS Network Manager site-to-site VPN attachment, used for organization, cost allocation, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpn_connection_arn" type="string" required>
  The ARN of the site-to-site VPN attachment. Required.
</ResponseField>

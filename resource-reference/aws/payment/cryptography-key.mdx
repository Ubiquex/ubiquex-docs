`aws_payment_cryptography_key` creates a real cryptographic key purpose-built for payment processing use cases, PIN translation, card data encryption, key exchange, hosted in a managed, PCI-compliant environment distinct from general-purpose `aws_kms_key`s.

## Input properties

<ResponseField name="derive_key_usage" type="string">
  Specifies the intended cryptographic key usage for a derived key generated from this key. Optional. **(AI-inferred)**
</ResponseField>

  Indicates whether the key is enabled for use in cryptographic operations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="exportable" type="bool" required>

</ResponseField>

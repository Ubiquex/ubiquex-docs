`aws_payment_cryptography_alias` creates a real friendly name for an `aws_payment_cryptography_key`, so application code can reference the alias rather than a key ARN and keep working unchanged when the underlying key is rotated. A key can have multiple aliases, but each alias points to exactly one key at a time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	payment "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/payment"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cryptography alias"})

    		ubx.Resource(payment.CryptographyAlias, "example", payment.CryptographyAliasConfig{
    			AliasName: "example-alias-name",
    			KeyArn:    "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="alias_name" type="string" required>
  Specifies the friendly name for the AWS Payment Cryptography key alias, which must begin with 'alias/' and is used to reference a key in cryptographic operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="key_arn" type="string">
  The ARN of the AWS Payment Cryptography key that this alias is associated with, allowing the alias to serve as a friendly reference to the key for cryptographic operations. Optional. **(AI-inferred)**
</ResponseField>

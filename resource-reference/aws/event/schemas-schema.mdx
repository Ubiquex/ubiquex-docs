`aws_event_schemas_schema` is one real, versioned schema definition, OpenAPI or JSONSchema, inside an `aws_event_schemas_registry`, describing the actual structure of one type of event so code bindings can be generated against it.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			RegistryName: "example-registry-name",
    			Type:         "example",
    			Description:  "Managed by ubx.",
    			SchemaName:   "example-schema-name",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="content" type="string" required>
  The source of the schema definition. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the schema. Optional.
</ResponseField>

<ResponseField name="registry_name" type="string" required>
  The name of the schema registry. Required.
</ResponseField>

<ResponseField name="schema_name" type="string">
  The name of the schema. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags associated with the resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to an EventBridge Schema, used to organize and categorize the schema within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key attached to the EventBridge Schema, used to store arbitrary metadata for the schema resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of schema. Valid types include OpenApi3 and JSONSchemaDraft4. Required.
</ResponseField>

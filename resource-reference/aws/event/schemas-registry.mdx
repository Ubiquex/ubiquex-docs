`aws_event_schemas_registry` is a real, named collection of event schemas, the container every `aws_event_schemas_schema` in one logical group of related events belongs to, separate from the default registry EventBridge maintains automatically.

## Example

    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	event "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/event"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own schemas registry"})

    			Description:  "Managed by ubx.",
    			RegistryName: "example-registry-name",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A description of the registry to be created. Optional.
</ResponseField>

<ResponseField name="registry_name" type="string">
  The name of the schema registry. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags associated with the resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key associated with the EventBridge Schema Registry, used to assign a custom metadata label that helps organize, identify, and filter the registry by their project, environment, or other criteria. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key attached to the EventBridge Schema Registry, used to store arbitrary metadata for resource management and filtering. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="registry_arn" type="string">
  The ARN of the registry. Computed by AWS after `ship`.
</ResponseField>

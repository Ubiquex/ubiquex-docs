`aws_event_schemas_registry_policy` is a real, resource-based access policy controlling which other AWS accounts can view or use the schemas in an `aws_event_schemas_registry`, needed for sharing a schema registry across accounts.

## Input properties

<ResponseField name="policy" type="any" required>
  The JSON resource-based policy document that grants or denies permissions to principals for actions on the EventBridge schema registry and its schemas. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="registry_name" type="string" required>
  The name of the EventBridge Schema Registry to which this resource-based policy is attached, identifying the registry whose access permissions the policy controls. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="revision_id" type="string">
  The revision ID of the registry policy, used for optimistic concurrency control to prevent conflicting updates (you must provide the current revision when updating the policy). Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the registry policy, equal to the name of the registry to which the policy is attached. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

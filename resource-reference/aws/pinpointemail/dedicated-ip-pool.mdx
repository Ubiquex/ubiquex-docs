`aws_pinpoint_email_dedicated_ip_pool` groups real dedicated sending IP addresses under an `aws_pinpoint_email_configuration_set`, so a chosen subset of an account's dedicated IPs is used for a particular category of email, subject to the same October 30, 2026 Pinpoint retirement.

## Example

<Tabs>

    ```go
    package main

    import (
    	pinpointemail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pinpointemail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own email dedicated ip pool"})

    		ubx.Resource(pinpointemail.DedicatedIpPool, "example", pinpointemail.DedicatedIpPoolConfig{
    			PoolName: "example-pool-name",
    			Tags:     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="pool_name" type="string">
  The name of the dedicated IP pool in Amazon Pinpoint, which serves as the unique identifier when referencing the pool in sending configurations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A key in a key-value tag assigned to the Amazon Pinpoint email dedicated IP pool, used to label the pool for cost allocation and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag applied to the Amazon Pinpoint dedicated IP pool, used for labeling, organization, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned to the dedicated IP pool, which is the same as the pool name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_deadline_budget` sets a real spending threshold for rendering activity within an `aws_deadline_farm`, tracked through Deadline Cloud's own cost management and usage explorer, so runaway render costs get flagged before a bill arrives rather than after.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    			Description:            "Managed by ubx.",
    			Tags:                   []map[string]any{{"key": "example"}},
    		})

    import ubx_sdk as ubx
    from ubx.aws.deadline import Budget, BudgetConfig
    from ubx.aws.deadline.budget import Budget_Actions, Budget_Schedule, Budget_Schedule_Fixed, Budget_UsageTrackingResource, Budget_Tags

    def describe():
        ubx.intent("example own budget")

        ubx.resource(Budget, "example", BudgetConfig(
            actions=[Budget_Actions(description="example")],
            approximate_dollar_limit=1,
            display_name="example-display-name",
            farm_id="example",
            schedule=Budget_Schedule(fixed=Budget_Schedule_Fixed(end_time="example", start_time="example")),
            usage_tracking_resource=Budget_UsageTrackingResource(queue_id="example"),
            description="Managed by ubx.",
            tags=[Budget_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="actions" type="list(object)" required>
  The budget actions to specify what happens when the budget runs out. Required.
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      A human-readable description of a budget action, explaining the action taken when the budget threshold is reached. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="threshold_percentage" type="number">
      The percentage of the budget's usage threshold that, when reached, triggers the corresponding budget action (such as stopping or limiting the farm). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Defines the type of budget action to take when the threshold is reached, such as STOP_SESSION_WORKER or STOP_QUEUE. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="approximate_dollar_limit" type="number" required>
  The dollar limit based on consumed usage. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the budget. Optional.
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The display name of the budget. Required.
</ResponseField>

<ResponseField name="farm_id" type="string" required>
  The farm ID. Required.
</ResponseField>

<ResponseField name="schedule" type="object" required>
  The start and end time of the budget. Required.
  <Expandable title="properties">
    <ResponseField name="fixed" type="object" required>
      The details of a fixed budget schedule. Required.
      <Expandable title="properties">
        <ResponseField name="end_time" type="string" required>
          When the budget ends. Required.
        </ResponseField>
        <ResponseField name="start_time" type="string" required>
          When the budget starts. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Deadline budget, used for organizing and managing the budget resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="usage_tracking_resource" type="object" required>
  The usage details of the allotted budget. Required.
  <Expandable title="properties">
    <ResponseField name="queue_id" type="string" required>
      The queue ID. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

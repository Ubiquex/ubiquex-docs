`aws_deadline_storage_profile` describes the real operating system and file-system layout of one workstation or worker configuration, letting Deadline Cloud derive path-mapping rules and transform file paths automatically when a job submitted from one storage profile runs on a worker with a different one.

## Input properties

<ResponseField name="display_name" type="string" required>
  The human-readable name of the storage profile, used to identify it in the Deadline Cloud console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="farm_id" type="string" required>
  The unique identifier of the AWS Deadline Cloud farm to which this storage profile belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="file_system_locations" type="list(object)">
  Defines the list of file system locations (each consisting of a name and a mount path) that this storage profile makes available to worker instances for accessing job data. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The user-defined name for a file system location in the AWS Deadline Cloud storage profile, used to identify the shared or local storage path. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="path" type="string">
      The absolute filesystem path (e.g., a mount point or drive letter) on the worker where the file system location referenced by this storage profile entry is accessible. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      In an AWS Deadline Cloud storage profile, each file system location's `type` indicates whether the location represents a shared file system (accessible to all workers) or a local file system (strictly for a single worker). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="os_family" type="string" required>
  Specifies the operating system family (such as WINDOWS or LINUX) that this AWS Deadline Cloud storage profile is configured for. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="storage_profile_id" type="string">
  The unique identifier assigned by AWS Deadline Cloud to this storage profile. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

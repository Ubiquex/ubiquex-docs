`aws_deadline_farm` is AWS Deadline Cloud's real, top-level container, every `aws_deadline_queue`, `aws_deadline_fleet`, and job for one render or simulation workload belongs to exactly one farm, kept separate from other farms for isolating production from test environments.

    		})
    	}))
    }

## Input properties

<ResponseField name="cost_scale_factor" type="number">
  Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A human-readable description of the Deadline Cloud farm, used to identify the farm's purpose or details. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string" required>
  Specifies the human-readable name for the farm, which is used to identify it in the AWS Deadline Cloud console and API operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The ARN of the AWS KMS key used to encrypt data for the AWS Deadline Cloud farm; if not provided, AWS uses an AWS-managed key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key for a tag attached to the AWS Deadline Cloud farm, used to identify and organize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag applied to the AWS Deadline Farm, allowing you to categorize and manage the farm with custom metadata such as cost allocation or team identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The unique Amazon Resource Name (ARN) of the farm, used to reference the farm across AWS services and in IAM policies. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="farm_id" type="string">
  The unique identifier assigned to the farm by AWS Deadline when the farm is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

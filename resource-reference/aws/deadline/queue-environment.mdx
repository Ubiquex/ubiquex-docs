`aws_deadline_queue_environment` defines real setup and teardown scripts that run on a worker before and after a job from an `aws_deadline_queue`, license checkout, temp file cleanup, rather than every job needing to handle that itself.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Priority:     1,

    			Template:     "example",
    			TemplateType: "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="farm_id" type="string" required>
  The unique identifier of the AWS Deadline Cloud farm that this queue environment is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="priority" type="number" required>
  Controls the order in which this queue environment is applied relative to other queue environments associated with the same queue, with the priority value used to rank the environments. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="queue_id" type="string" required>
  The unique identifier of the Deadline queue that this environment is associated with, used to scope the environment to a specific queue. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="template" type="string" required>
  Defines the queue environment's setup as a structured string (typically JSON), specifying environment variables and script actions that run for jobs using this queue environment. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_type" type="string" required>
  Specifies the template format for the queue environment, either JSON or YAML. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="name" type="string">
  The name of the queue environment, which is derived from the `name` field defined in the environment's template content (YAML or JSON). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="queue_environment_id" type="string">
  The unique identifier assigned by AWS Deadline to this queue environment resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

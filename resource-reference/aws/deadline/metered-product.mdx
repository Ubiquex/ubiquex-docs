`aws_deadline_metered_product` is one real, usage-based-licensed software product made available through an `aws_deadline_license_endpoint`, added so an `aws_deadline_fleet`'s workers can check that specific product's license out for a job.

## Example

    ```go
    package main

    import (
    	deadline "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/deadline"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own metered product"})

    		ubx.Resource(deadline.MeteredProduct, "example", deadline.MeteredProductConfig{
    			LicenseEndpointId: "example",
    			ProductId:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="license_endpoint_id" type="string">
  The unique identifier of the license endpoint with which the metered product is associated in AWS Deadline Cloud. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="product_id" type="string">
  The product_id specifies the unique AWS Marketplace product identifier for the software product that is metered and associated with the Deadline farm. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this Deadline Cloud metered product. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="family" type="string">
  The product family (e.g., 'Arnold' or 'V-Ray') that Deadline Cloud assigns to the metered product, automatically determined and read-only. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="port" type="number">
  The network port number on which the metered product's licensing service listens, returned by Deadline Cloud after the product is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="vendor" type="string">
  The vendor of the metered product, representing the company or provider that offers the software, as assigned by AWS Deadline Cloud. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

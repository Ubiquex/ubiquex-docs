---
title: "aws_deadline_queue_limit_association"
description: "`aws_deadline_queue_limit_association` is the real, actual link between an `aws_deadline_queue` and an `aws_deadline_limit`."
---

A limit defined but never associated with a queue never actually constrains any job.

## Properties

<ResponseField name="farm_id" type="string" required>
  The unique identifier of the farm that contains the queue and limit to be associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="limit_id" type="string" required>
  The unique identifier of the Deadline Cloud limit to associate with the queue. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="queue_id" type="string" required>
  The unique identifier of the Deadline Cloud queue that is associated with the specified limit. Required. **(AI-inferred)**
</ResponseField>

`aws_deadline_fleet` is a real, managed or customer-managed group of worker hosts that actually process jobs from an `aws_deadline_queue`, the core compute infrastructure behind an `aws_deadline_farm`, a single fleet able to serve multiple queues and a single queue able to draw from multiple fleets.

---

`aws_deadline_limit` caps real, concurrent consumption of a constrained resource, a software license seat, a database connection, across every job in an `aws_deadline_farm` that needs it, so jobs are scheduled only when the actual limited resource is available rather than starting and then failing partway through.

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own limit"})

    		ubx.Resource(deadline.Limit, "example", deadline.LimitConfig{
    			AmountRequirementName: "example-amount-requirement-name",
    			DisplayName:           "example-display-name",
    			FarmId:                "example",
    			MaxCount:              1,
    			Description:           "Managed by ubx.",
    		})
    	}))
    }

## Input properties

<ResponseField name="amount_requirement_name" type="string" required>
  Required.
</ResponseField>

<ResponseField name="description" type="string">
  Provides an optional human-readable description for the AWS Deadline Cloud limit, clarifying the limit's purpose or scope. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string" required>
  A human-readable name for the limit, used to identify and display the limit in the AWS Deadline Cloud console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="farm_id" type="string" required>
  The unique identifier of the AWS Deadline Cloud farm to which this limit belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_count" type="number" required>
  The maximum number of resources that the limit permits to be used simultaneously, enforcing a cap on concurrent usage in the Deadline Cloud farm. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="current_count" type="number">
  The current number of resources that are using this limit, as tracked by AWS Deadline Cloud and updated automatically as usage changes. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="limit_id" type="string">
  The unique identifier assigned by AWS Deadline Cloud to this limit resource when it is created, used to refer to the limit in other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_deadline_queue` holds real jobs for scheduling onto an associated `aws_deadline_fleet`, and is Deadline Cloud's own primary permissions boundary, controlling who can see and submit to a given slice of an `aws_deadline_farm` rather than the farm as a whole.

## Input properties

<ResponseField name="allowed_storage_profile_ids" type="list(string)">
  Specifies the list of storage profile IDs that are allowed to be used by this Deadline Cloud queue for job attachments. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_budget_action" type="string">
  Specifies the action Deadline takes when the queue's budget limit is exceeded, with valid values NONE and STOP_SCHEDULING_AND_CANCEL_JOBS. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A human-readable description of the queue, used to provide context about the queue's purpose or contents in AWS Deadline Cloud. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The user-friendly display name of the Deadline Cloud queue, used to identify it in the AWS console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="farm_id" type="string" required>
  The unique identifier of the AWS Deadline Cloud farm to which this queue belongs and is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="job_attachment_settings" type="object">

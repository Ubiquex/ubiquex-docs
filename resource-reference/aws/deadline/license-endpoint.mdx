`aws_deadline_license_endpoint` provisions the real, VPC-hosted endpoint Deadline Cloud's usage-based licensing connects through, letting customer-managed fleets check out real, metered third-party software licenses for a job's duration rather than requiring a permanent per-seat license.

## Input properties

<ResponseField name="security_group_ids" type="list(string)" required>

</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The list of subnet IDs in the VPC where the license endpoint's elastic network interfaces are provisioned to connect to license servers. Required. **(AI-inferred)**
</ResponseField>

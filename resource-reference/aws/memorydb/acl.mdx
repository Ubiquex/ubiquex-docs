`aws_memory_db_acl` defines a real Access Control List, the set of users and permissions, that one or more `aws_memory_db_cluster`s authenticate and authorize connections against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	memorydb "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/memorydb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own acl"})

    		ubx.Resource(memorydb.Acl, "example", memorydb.AclConfig{
    			Aclname:   "example",
    			Tags:      []map[string]any{{"key": "example"}},
    			UserNames: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="aclname" type="string" required>
  The name of the acl. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this cluster. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key name of a tag to associate with the MemoryDB ACL. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The string value of a key-value pair in the tags map for the MemoryDB ACL, allowing users to attach custom metadata to the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_names" type="list(string)">
  List of users associated to this acl. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the acl. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  Indicates acl status. Can be "creating", "active", "modifying", "deleting". Computed by AWS after `ship`.
</ResponseField>

`aws_waf_web_acl` creates a real, top-level web ACL under AWS WAF Classic (global, for CloudFront), evaluating its ordered list of `aws_waf_rule`s against every request and allowing or blocking based on the first match. AWS WAF Classic support ended September 30, 2025, roughly eleven months in the past; AWS's current, actively developed offering is `aws_wafv2_web_acl`.

    ```go
    func main() {

    			MetricName:    "example-metric-name",
    			Name:          "example",
    			Rules:         []map[string]any{{"action": map[string]any{"type": "example"}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="default_action" type="object" required>
  Determines the action (ALLOW or BLOCK) that AWS WAF takes for web requests that do not match any rule in this web ACL. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string" required>
      Specifies the default action, either ALLOW or BLOCK, that AWS WAF applies to web requests that don't match any rule in this web ACL. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metric_name" type="string" required>
  The name of the Amazon CloudWatch metric used to monitor the Web ACL, which must be unique within the region and is displayed in the WAF console and CloudWatch. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The user-defined name of the web ACL, used as its unique identifier within the AWS WAF service. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rules" type="list(object)">
  A list of rule overrides, each specifying a priority, AWS WAF rule identifier, and action (allow, block, or count) that together define the evaluation order and handling of matching requests. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="action" type="object">
      Specifies the action (ALLOW, BLOCK, or COUNT) that AWS WAF takes when a request matches the associated rule in this web ACL. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Specifies how the rule handles matching web requests, with values such as ALLOW, BLOCK, or COUNT. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="priority" type="number">
      The evaluation order for the rule, where lower numbers are evaluated first and each rule in the web ACL must have a unique priority value. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rule_id" type="string">
      The unique identifier of the AWS WAF rule that this web ACL action applies to within the rules list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique AWS-assigned ID of the web ACL, used to reference the web ACL in other resources (e.g., aws_waf_association) and in API calls. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

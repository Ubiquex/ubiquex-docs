---
title: "aws_waf_size_constraint_set"
description: "`aws_waf_size_constraint_set` defines a real condition, matching a request part's size against a threshold, that an `aws_waf_rule` references."
---

Like the rest of AWS WAF Classic, support for this resource ended September 30, 2025.

## Input properties

<ResponseField name="name" type="string" required>
  The name of the WAF size constraint set, which must be unique within your AWS account and region, and is used to identify this set in web ACL rules. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="size_constraints" type="list(object)" required>
  Specifies the size constraints for the set, each defining the part of a request (FieldToMatch), the transformation to apply, comparison operator, and byte size limit that AWS WAF checks for. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="comparison_operator" type="string">
      Specifies how the size of a request component is compared to the target size in the size constraint (allowed values: EQ, NE, LE, LT, GE, GT). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="field_to_match" type="object">
      Specifies the part of the web request to inspect for the size constraint, such as a header, query string, URI, body, or method. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="data" type="string">
          When the field-to-match type is HEADER or QUERY_STRING, this specifies the header name or query string key to inspect in the web request. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the part of a web request to inspect, such as a header, the HTTP method, the query string, the URI, or the body, for the size constraint rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="size" type="number">
      The size, in bytes, to compare against the inspected portion of a web request when evaluating this size constraint, using the constraint's comparison operator (e.g., EQ, GT). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="text_transformation" type="string">
      For an AWS WAF Classic size constraint set, this field specifies the text transformation to apply to the request content before checking its size, with valid values including NONE, COMPRESS_WHITE_SPACE, HTML_ENTITY_DECODE, LOWERCASE, CMD_LINE, and URL_DECODE. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS WAF to the size constraint set. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

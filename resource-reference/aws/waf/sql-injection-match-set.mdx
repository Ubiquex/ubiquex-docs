## Input properties

<ResponseField name="name" type="string" required>
  Specifies a unique, immutable name for the WAF SQL injection match set, used as its friendly identifier in the AWS WAF console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="sql_injection_match_tuples" type="list(object)">
  A list of SQL injection match tuples, each defining a FieldToMatch and TextTransformation that CloudFormation uses to identify SQL injection patterns for the WAF match set. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="field_to_match" type="object">
      Specifies the part of the web request (such as a header, body, query string, or URI) that AWS WAF Classic inspects for SQL injection patterns in this SQL injection match tuple. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="data" type="string">
          The name of the HTTP header to inspect when field_to_match's Type is HEADER; it is empty for other types such as METHOD, QUERY_STRING, BODY, or URI. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the type of web request component to inspect, such as HEADER, QUERY_STRING, BODY, URI, or METHOD, for the SQL injection match condition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="text_transformation" type="string">
      Specifies how the text in the web request is transformed (for example, URL_DECODE or HTML_ENTITY_DECODE) before the SQL injection pattern is checked. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS WAF to this SQL injection match set, used to reference the match set in other resources such as a WebACL. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

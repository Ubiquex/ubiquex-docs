---
title: "aws_waf_ipset"
description: "`aws_waf_ipset` defines a real set of IP addresses or CIDR ranges that an `aws_waf_rule` references as a match condition."
---

Like the rest of AWS WAF Classic, support for this resource ended September 30, 2025, roughly eleven months in the past; AWS's current offering is AWS WAFv2.

## Input properties

<ResponseField name="ipset_descriptors" type="list(object)">
  Defines the list of IP addresses or CIDR ranges for the IPSet, where each descriptor object specifies an IP version (IPv4 or IPv6) and a value representing the address or range. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      Specifies the IP address version (either IPV4 or IPV6) for the CIDR value in this IPSet descriptor. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The IP address or CIDR range to include in the WAF IPSet, such as 192.0.2.0/24 or 10.0.0.1. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The friendly name of the IP set, which cannot be changed after the IP set is created. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to this IP set, used to reference it when associating with AWS WAF rules or updating the set. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

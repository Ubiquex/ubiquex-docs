`aws_waf_byte_match_set` defines a real condition, matching a specific byte sequence in a request part, header, URI, body, that an `aws_waf_rule` references. This is part of AWS WAF Classic (global, for CloudFront), which AWS deprecated: support ended September 30, 2025, roughly eleven months in the past. AWS's current, actively developed offering is AWS WAFv2 (`aws_wafv2_web_acl` and related resources).

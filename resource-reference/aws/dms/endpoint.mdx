---
title: "aws_dms_endpoint"
description: "`aws_dms_endpoint` defines the real connection details, engine type, credentials, and location..."
---

`aws_dms_endpoint` defines the real connection details, engine type, credentials, and location, for one source or target database that an `aws_dms_replication_task` or `aws_dms_replication_config` actually migrates data to or from.

## Example

    ```go

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own endpoint"})

    		ubx.Resource(dms.Endpoint, "ci-runner", dms.EndpointConfig{
    			EndpointType:          "example",

    			DatabaseName:          "example-database-name",
    			DocDbSettings:         map[string]any{"docs_to_investigate": 1},
    			DynamoDbSettings:      map[string]any{"service_access_role_arn": "example"},
    			ElasticsearchSettings: map[string]any{"endpoint_uri": "example"},
    			EndpointIdentifier:    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate_arn" type="string">
  The Amazon Resource Name (ARN) for the certificate. Optional.
</ResponseField>

<ResponseField name="database_name" type="string">
  The name of the endpoint database. For a MySQL source or target endpoint, don't specify DatabaseName. To migrate to a specific database, use this setting and targetDbType. Optional.
</ResponseField>

      Specifies either document or table mode. Optional.

    <ResponseField name="secrets_manager_access_role_arn" type="string">
      The full Amazon Resource Name (ARN) of the IAM role that specifies AWS DMS as the trusted entity and grants the required permissions to access the value in SecretsManagerSecret. The role must allow the iam:PassRole action. SecretsManagerSecret has the value of the AWS Secrets Manager secret that allows access to the DocumentDB endpoint. Optional.
    </ResponseField>
    <ResponseField name="secrets_manager_secret_id" type="string">
      The full Amazon Resource Name (ARN) of the IAM role that specifies AWS DMS as the trusted entity and grants the required permissions to access the value in SecretsManagerSecret.

`aws_dms_replication_instance` is the real, managed compute that actually runs an `aws_dms_replication_task`'s migration or ongoing change-data-capture work between its source and target `aws_dms_endpoint`s.

## Input properties

<ResponseField name="allocated_storage" type="number">
  Specifies the amount of storage (in gigabytes) to allocate for the AWS DMS replication instance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="allow_major_version_upgrade" type="bool">
  Indicates whether major version upgrades are allowed for the replication instance, and must be set to true to permit such upgrades when the engine version is changed. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="auto_minor_version_upgrade" type="bool">
  Indicates whether minor engine version upgrades are applied automatically to the replication instance during the maintenance window. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="availability_zone" type="string">
  Specifies the Availability Zone (AZ) in which the AWS DMS replication instance is created, influencing placement and failover behavior for Multi-AZ deployments. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dns_name_servers" type="string">
  Specifies a comma-separated list of DNS name servers that the AWS DMS replication instance uses to resolve domain names for source and target endpoints. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="engine_version" type="string">
  Specifies the DMS engine version number to use for the replication instance, such as '3.4.4'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  This field specifies the Amazon Resource Name (ARN) or ID of an AWS KMS customer master key (CMK) used to encrypt the storage and data on the DMS replication instance, instead of the default AWS-managed key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="multi_az" type="bool">
  Specifies whether the replication instance is deployed across multiple Availability Zones for high availability. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_type" type="string">
  Specifies whether the replication instance uses IPv4 only (ipv4) or dual-stack IPv4 and IPv6 (dual) for network connectivity. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">
  Specifies the preferred time window (in the format ddd:hh24:mi-ddd:hh24:mi, e.g., 'sun:01:00-sun:02:00') during which AWS may perform maintenance on the replication instance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="publicly_accessible" type="bool">
  Whether the DMS replication instance is publicly accessible, meaning it receives a public IP address and can be reached from the internet, as opposed to being private within the VPC. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_instance_class" type="string" required>
  The compute and memory capacity class for the replication instance, such as dms.t2.small or dms.c4.large, which determines the performance and cost of the instance. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_instance_identifier" type="string">
  Specifies a user-defined name for the replication instance, which must be unique within the AWS account and region and can include letters, numbers, and hyphens. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_subnet_group_identifier" type="string">
  The identifier of an existing DMS replication subnet group that determines the VPC and subnets where the replication instance's network interfaces are placed. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_identifier" type="string">
  Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The Amazon Resource Name (ARN) of the DMS replication instance, generated by AWS and used as the unique Terraform resource identifier. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_instance_private_ip_addresses" type="string">

</ResponseField>

<ResponseField name="replication_instance_public_ip_addresses" type="string">

</ResponseField>

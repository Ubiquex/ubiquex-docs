`aws_dms_replication_config` defines a real, serverless replication, DMS automatically provisions, scales, and manages the underlying compute rather than a caller sizing and managing an `aws_dms_replication_instance` by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dms "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/dms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own replication config"})

    		ubx.Resource(dms.ReplicationConfig, "example", dms.ReplicationConfigConfig{
    			ComputeConfig:               map[string]any{"max_capacity_units": 1},
    			ReplicationConfigIdentifier: "example",
    			ReplicationType:             "example",
    			SourceEndpointArn:           "arn:aws:iam::123456789012:policy/example",
    			TableMappings:               "example",
    			TargetEndpointArn:           "arn:aws:iam::123456789012:policy/example",
    			ReplicationSettings:         "example",
    			ResourceIdentifier:          "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="compute_config" type="object" required>
  Configuration parameters for provisioning a AWS DMS Serverless replication Required.
  <Expandable title="properties">
    <ResponseField name="availability_zone" type="string">
      Specifies the Availability Zone (AZ) in which the AWS DMS replication instance associated with this replication config will be provisioned. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="dns_name_servers" type="string">
      Specifies the custom DNS name servers (as a comma-separated list of IP addresses) that the AWS DMS replication instance uses for name resolution. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="kms_key_id" type="string">
      The ARN or ID of the AWS KMS key used to encrypt data on the storage attached to the AWS DMS replication instance. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="max_capacity_units" type="number" required>
      The maximum number of DMS capacity units that the replication can scale to, defining the upper limit of compute capacity for the AWS DMS replication config. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="min_capacity_units" type="number">
      Sets the minimum number of DMS capacity units to provision for a serverless replication, defining the lower bound for automatic scaling of compute resources. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="multi_az" type="bool">
      Specifies whether to enable Multi-AZ deployment for the AWS DMS replication config's compute environment, providing high availability by provisioning a standby replica in a different Availability Zone. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="preferred_maintenance_window" type="string">
      Specifies the preferred weekly maintenance window (in UTC, format ddd:hh24:mi-ddd:hh24:mi) during which AWS Database Migration Service can perform maintenance on the replication services associated with this replication config. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="replication_subnet_group_id" type="string">
      The identifier of the AWS DMS replication subnet group in which the replication instance for this replication config is deployed. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpc_security_group_ids" type="list(string)">
      Specifies the VPC security group IDs to associate with the compute configuration for the AWS DMS replication, controlling network access to the replication environment. Optional. **(AI-inferred)**

title: "aws_dms_data_provider"
description: "`aws_dms_data_provider` defines the connection details for one real, self-managed or fully managed database engine..."
---

`aws_dms_data_provider` defines the connection details for one real, self-managed or fully managed database engine, usable inside an `aws_dms_migration_project` for AWS DMS Schema Conversion, distinct from an `aws_dms_endpoint`, which serves an actual running `aws_dms_replication_task` instead.

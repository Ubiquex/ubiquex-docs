`aws_dms_event_subscription` sends a real SNS notification when a specific event happens to an `aws_dms_replication_instance` or `aws_dms_replication_task`, a failure, a state change, rather than a caller polling DMS to notice.

## Properties

<ResponseField name="enabled" type="bool">
  Indicates whether to activate the subscription. If you don't specify this property, CloudFormation activates the subscription. Optional.
</ResponseField>

<ResponseField name="event_categories" type="list(string)">
  A list of event categories for a source type that you want to subscribe to. If you don't specify this property, you are notified about all event categories. Optional.
</ResponseField>

<ResponseField name="sns_topic_arn" type="string" required>
  The Amazon Resource Name (ARN) of the Amazon SNS topic created for event notification. The ARN is created by Amazon SNS when you create a topic and subscribe to it. Required.
</ResponseField>

<ResponseField name="source_ids" type="list(string)">
  A list of identifiers for which AWS DMS provides notification events. If you don't specify a value, notifications are provided for all sources. If you specify multiple values, they must be of the same type. For example, if you specify a database instance ID, then all of the other values must be database instance IDs. Optional.
</ResponseField>

<ResponseField name="source_type" type="string">
  The type of AWS DMS resource that generates the events. For example, if you want to be notified of events generated by a replication instance, you set this parameter to replication-instance. If this value isn't specified, all events are returned. Optional.
</ResponseField>

<ResponseField name="subscription_name" type="string">
  The name of the AWS DMS event notification subscription. This name must be less than 255 characters. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags to be assigned to the event subscription. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS DMS event subscription, used to categorize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag applied to the AWS DMS event subscription. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

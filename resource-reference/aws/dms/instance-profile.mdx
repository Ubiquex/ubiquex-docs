`aws_dms_instance_profile` defines a real, reusable network and encryption configuration, VPC, subnet group, KMS key, for DMS Serverless data migrations, referenced by an `aws_dms_data_migration` instead of specifying that configuration inline each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	dms "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/dms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own instance profile"})

    		ubx.Resource(dms.InstanceProfile, "ci-runner", dms.InstanceProfileConfig{
    			AvailabilityZone:          "example",
    			Description:               "Managed by ubx.",
    			InstanceProfileIdentifier: "example",
    			InstanceProfileName:       "example-instance-profile-name",
    			KmsKeyArn:                 "arn:aws:iam::123456789012:policy/ci",
    			NetworkType:               "example",
    			PubliclyAccessible:        true,
    			SubnetGroupIdentifier:     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="availability_zone" type="string">

</ResponseField>

<ResponseField name="description" type="string">
  The optional description of the instance profile. Optional.
</ResponseField>

<ResponseField name="instance_profile_identifier" type="string">
  The property describes an identifier for the instance profile. It is used for describing/deleting/modifying. Can be name/arn Optional.
</ResponseField>

<ResponseField name="instance_profile_name" type="string">
  The property describes a name for the instance profile. Optional.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">

</ResponseField>

<ResponseField name="network_type" type="string">

`aws_dms_replication_task` is the real, actual migration or CDC job that runs on an `aws_dms_replication_instance`, moving data from a source `aws_dms_endpoint` to a target one.

## Example

    	ubx.Main(ubx.Stack("payments", func() {

## Input properties

<ResponseField name="cdc_start_position" type="string">
  Specifies the native source database position (such as a log file number or LSN) from which AWS DMS begins reading change data capture (CDC) changes when starting the replication task. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cdc_start_time" type="number">
  The Unix timestamp in seconds that specifies when Change Data Capture (CDC) should begin for the replication task, defining the starting point for capturing ongoing data changes. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cdc_stop_position" type="string">
  Specifies the point in time (as a Unix timestamp) or LSN (log sequence number) up to which the change data capture (CDC) portion of the replication task should process changes, after which the task stops. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="migration_type" type="string" required>
  Specifies the migration type for the replication task, which can be one of 'full-load', 'cdc', or 'full-load-and-cdc'. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_instance_arn" type="string" required>
  The Amazon Resource Name (ARN) of the AWS DMS replication instance that will run the replication task. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_task_identifier" type="string">
  A user-supplied unique identifier for the DMS replication task within an AWS account, used to reference and manage the task in AWS DMS. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="replication_task_settings" type="string">
  A JSON-format string that configures the AWS DMS replication task's operational settings, such as target table preparation mode, full load behavior, and error handling options. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="source_endpoint_arn" type="string" required>
  The Amazon Resource Name (ARN) of the source database endpoint that the DMS replication task reads data from during migration. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="table_mappings" type="string" required>

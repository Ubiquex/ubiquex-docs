`aws_clean_rooms_id_mapping_table` performs real entity resolution inside AWS Clean Rooms, matching records that represent the same real-world entity across two collaboration members' data, integrated with AWS Entity Resolution, without either party seeing the other's raw identifiers.

    import ubx_sdk as ubx
    from ubx.aws.cleanrooms import IdMappingTable, IdMappingTableConfig
    from ubx.aws.cleanrooms.id_mapping_table import IdMappingTable_InputReferenceConfig, IdMappingTable_Tags

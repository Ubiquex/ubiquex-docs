`aws_clean_rooms_privacy_budget_template` defines the real, mathematically-backed differential privacy budget, how much cumulative query exposure is allowed before results get too noisy to protect individual users, that AWS Clean Rooms enforces automatically across a collaboration's differential-privacy-protected queries.

## Input properties

<ResponseField name="auto_refresh" type="string" required>
  Indicates whether the privacy budget template automatically refreshes at the end of each allocation period, with valid values 'ENABLED' or 'DISABLED'. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="membership_identifier" type="string" required>
  The unique identifier of the AWS Clean Rooms membership that this privacy budget template is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameters" type="object" required>
  Defines the differential privacy parameters for the privacy budget template, specifically the epsilon value and the maximum number of aggregation queries allowed. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="budget_parameters" type="list(object)">
      Optional.
      <Expandable title="properties">
        <ResponseField name="auto_refresh" type="string">
          Indicates whether the privacy budget template automatically refreshes the privacy budget on a recurring schedule (e.g., daily or monthly) to renew the querying allowance without manual intervention. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="budget" type="number">
          The maximum number of privacy budget units allocated to a parameter, determining how much aggregate data can be exposed while preserving differential privacy. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Defines the kind of privacy budget parameter (currently supported value: DIFFERENTIAL_PRIVACY) that determines how the analysis rule enforces differential privacy limits in the template. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="epsilon" type="number">
      Specifies the epsilon value for the differential privacy budget, which limits the amount of privacy loss allowed for queries using this template. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_arn" type="string">
      Optional.
    </ResponseField>
    <ResponseField name="users_noise_per_query" type="number">
      The number of users' worth of noise added to each query in the privacy budget template, controlling the level of differential privacy applied to query results. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="privacy_budget_type" type="string" required>
  The privacy budget type, either 'DIRECT' or 'DIFFERENTIAL_PRIVACY', determines whether the template enforces a direct query budget or a differential-privacy-based budget with noise for members' queries in the collaboration. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An arbitrary set of tags (key-value pairs) for this cleanrooms privacy budget template. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_observability_admin_s3_table_integration` configures a real integration that routes an account's or organization's telemetry data into S3 Tables under CloudWatch Observability Admin, for long-term, queryable storage outside CloudWatch itself.

    	observability "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/observability"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Encryption: map[string]any{"sse_algorithm": "example"},
    			RoleArn:    "arn:aws:iam::123456789012:policy/example",

    		})
    	}))
    }

## Input properties

<ResponseField name="encryption" type="object" required>
  Encryption configuration for the S3 Table Integration Required.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      The ARN of the KMS key used to encrypt the S3 Table Integration Optional.
    </ResponseField>
    <ResponseField name="sse_algorithm" type="string" required>
      The server-side encryption algorithm used to encrypt the S3 Table(s) data Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of the role used to access the S3 Table Integration Required.
</ResponseField>

---
title: "aws_forecast_dataset"
description: "`aws_forecast_dataset` held real historical time-series data inside an `aws_forecast_dataset_group` that Amazon Forecast trained a predictor against."
---

Like the rest of Forecast, closed to new customers since July 29, 2024.

<ResponseField name="dataset_name" type="string" required>

</ResponseField>

</ResponseField>

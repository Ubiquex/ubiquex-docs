`aws_forecast_dataset_group` was the top-level container an `aws_forecast_dataset` belonged to in Amazon Forecast, AWS's managed time-series forecasting service. Amazon Forecast closed to new customers on July 29, 2024; existing customers can continue using it, with AWS recommending Amazon SageMaker Canvas for new time-series forecasting work.

## Input properties

<ResponseField name="dataset_arns" type="list(string)">
  An array of Amazon Resource Names (ARNs) of the datasets that you want to include in the dataset group. Optional.
</ResponseField>

<ResponseField name="dataset_group_name" type="string" required>
  A name for the dataset group. Required.
</ResponseField>

<ResponseField name="domain" type="string" required>
  The domain associated with the dataset group. When you add a dataset to a dataset group, this value and the value specified for the Domain parameter of the CreateDataset operation must match. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">

`aws_kafka_connect_worker_configuration` sets real Kafka Connect worker-level properties applied to an `aws_kafka_connect_connector`'s own underlying runtime, beyond the connector's specific configuration alone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kafkaconnect "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/kafkaconnect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own worker configuration"})

    		ubx.Resource(kafkaconnect.WorkerConfiguration, "example", kafkaconnect.WorkerConfigurationConfig{
    			Name:                  "example",
    			PropertiesFileContent: "example",
    			Description:           "Managed by ubx.",
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.kafkaconnect import WorkerConfiguration, WorkerConfigurationConfig
    from ubx.aws.kafkaconnect.worker_configuration import WorkerConfiguration_Tags

    def describe():
        ubx.intent("example own worker configuration")

        ubx.resource(WorkerConfiguration, "example", WorkerConfigurationConfig(
            name="example",
            properties_file_content="example",
            description="Managed by ubx.",
            tags=[WorkerConfiguration_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  A summary description of the worker configuration. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the worker configuration. Required.
</ResponseField>

<ResponseField name="properties_file_content" type="string" required>
  Base64 encoded contents of connect-distributed.properties file. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tags associated with a resource Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag to attach to this AWS Managed Kafka Connect worker configuration, enabling cost allocation, resource organization, and access control in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag applied to the AWS Kafka Connect worker configuration, used for custom metadata, resource organization, and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="revision" type="number">
  The description of a revision of the worker configuration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="worker_configuration_arn" type="string">
  The Amazon Resource Name (ARN) of the custom configuration. Computed by AWS after `ship`.
</ResponseField>

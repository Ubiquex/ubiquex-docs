---
title: "aws_kinesis_analytics_v2_application"
description: "`aws_kinesis_analytics_v2_application` runs a real Apache Flink stream-processing application..."
---

`aws_kinesis_analytics_v2_application` runs a real Apache Flink stream-processing application, or an interactive Kinesis Data Analytics Studio notebook when its mode is set to INTERACTIVE, distinct from the now-discontinued SQL-based Kinesis Data Analytics application type this v2 generation replaced.

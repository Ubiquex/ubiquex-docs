`aws_kinesis_firehose_delivery_stream` creates a real managed pipeline that acquires, transforms, and delivers streaming data within seconds to a destination such as S3, Redshift, OpenSearch, or a third-party analytics tool. AWS renamed the underlying service from "Amazon Kinesis Data Firehose" to "Amazon Data Firehose" in February 2024; the resource name and behavior are unchanged.

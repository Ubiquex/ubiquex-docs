`aws_kinesis_resource_policy` attaches a real resource-based access policy to an `aws_kinesis_stream`, controlling which principals, including from other accounts, can read from or write to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesis "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/kinesis"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource policy"})

    		ubx.Resource(kinesis.ResourcePolicy, "example", kinesis.ResourcePolicyConfig{
    			ResourceArn:    "example",
    			ResourcePolicy: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.kinesis.resource_policy import ResourcePolicy, ResourcePolicyConfig

    def describe():
        ubx.intent("example own resource policy")

        ubx.resource(ResourcePolicy, "example", ResourcePolicyConfig(
            resource_arn="example",
            resource_policy="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="resource_arn" type="any" required>
  The ARN of the AWS Kinesis resource to which the policy applies. Required.
</ResponseField>

<ResponseField name="resource_policy" type="any" required>
  A policy document containing permissions to add to the specified resource. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. Required.
</ResponseField>

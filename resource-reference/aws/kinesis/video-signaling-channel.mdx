`aws_kinesis_video_signaling_channel` creates a real WebRTC signaling channel that exchanges the SDP offers/answers and ICE candidates needed to establish a peer-to-peer media connection between WebRTC clients, distinct from `aws_kinesis_video_stream`'s own role storing and replaying the actual media.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own video signaling channel"})

    		ubx.Resource(kinesisvideo.SignalingChannel, "example", kinesisvideo.SignalingChannelConfig{
    			Name:              "example",
    			MessageTtlSeconds: 7200,
    			Tags:              []map[string]any{{"key": "example"}},
    			Type:              "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="message_ttl_seconds" type="number">
  The period of time a signaling channel retains undelivered messages before they are discarded. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the Kinesis Video Signaling Channel. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that you can attach to the Kinesis Video Signaling Channel, enabling you to categorize and filter the channel by user-defined metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a user-defined tag attached to the signaling channel, allowing you to store arbitrary metadata (e.g., names, owners, or environments) for resource management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of the Kinesis Video Signaling Channel to create. Currently, SINGLE_MASTER is the only supported channel type. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Kinesis Video Signaling Channel. Computed by AWS after `ship`.
</ResponseField>

`aws_kinesis_analytics_application_reference_data_source` adds a real static reference table, loaded from an S3 object, that an `aws_kinesis_analytics_application`'s SQL can join against incoming stream records. This is scoped to the original SQL-based Kinesis Data Analytics application type, which AWS has fully discontinued: no new applications could be created after October 15, 2025, and all remaining applications were deleted and support ended on January 27, 2026, a date now in the past. The distinct, current generation is `aws_kinesis_analytics_v2_application`, built on Apache Flink.

`aws_aiops_investigation_group` is a one-time setup resource for CloudWatch investigations, the generative AI-assisted incident response capability that correlates signals across an account during an active issue. One investigation group per region holds the central settings, encryption and retention among them, that every investigation in that region inherits.

## Input properties

<ResponseField name="chatbot_notification_channels" type="list(object)">
  An array of key-value pairs of notification channels to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="chat_configuration_arns" type="list(string)">
      The ARNs of the AWS Chatbot configurations that serve as notification channels for the investigation group, enabling alerts to be delivered to configured chat services such as Slack or Microsoft Teams. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="snstopic_arn" type="string">
      The ARN of the Amazon SNS topic that serves as a chatbot notification channel for the investigation group, receiving event notifications and alerts. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cross_account_configurations" type="list(object)">

  <Expandable title="properties">
    <ResponseField name="source_role_arn" type="string">
      The Amazon Resource Name (ARN) of the IAM role in the source account that the investigation group assumes to access data across accounts. Optional; if omitted, computed by AWS. **(AI-inferred)**

  </Expandable>

`aws_key_pair` creates or imports a real SSH key pair, AWS storing the public key and the caller keeping the private key, used to securely retrieve an `aws_instance`'s initial administrator password or authenticate an SSH connection to it.

## Input properties

<ResponseField name="key_format" type="string">
  The format of the key pair. Default: ``pem`` Optional.
</ResponseField>

<ResponseField name="key_name" type="string" required>
  A unique name for the key pair. Constraints: Up to 255 ASCII characters Required.
</ResponseField>

<ResponseField name="key_type" type="string">
  The type of key pair. Note that ED25519 keys are not supported for Windows instances. If the ``PublicKeyMaterial`` property is specified, the ``KeyType`` property is ignored, and the key type is inferred from the ``PublicKeyMaterial`` value. Default: ``rsa`` Optional.
</ResponseField>

<ResponseField name="public_key_material" type="string">
  The public key material. The ``PublicKeyMaterial`` property is used to import a key pair. If this property is not specified, then a new key pair will be created. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to apply to the key pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the EC2 key pair, used to organize and identify the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="key_fingerprint" type="string">
  The SHA-1 digest of the DER-encoded public key for the EC2 key pair, used to verify the key's identity. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="key_pair_id" type="string">
  The unique identifier that AWS assigns to the key pair upon creation, for example 'key-1234567890abcdef0'. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

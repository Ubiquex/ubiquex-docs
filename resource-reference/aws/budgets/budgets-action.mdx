`aws_budgets_budgets_action` attaches a real, automatic response, applying an IAM policy that denies further provisioning, for instance, to an `aws_budgets_budget` crossing its threshold, turning a budget from a passive alert into an enforced spending control.

## Input properties

<ResponseField name="action_threshold" type="object" required>
  Defines the threshold (a numeric value and type, either absolute dollar amount or percentage) that triggers the budget action when the actual or forecasted budget usage exceeds it. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string" required>
      Determines whether the threshold value is interpreted as an absolute dollar amount or as a percentage of the budget. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="number" required>
      The numeric threshold value that triggers the budget action, interpreted according to the sibling threshold type (e.g., as a percentage of the budget limit or as an absolute monetary amount). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="action_type" type="string" required>
  Specifies the type of budget action to execute when a budget threshold is exceeded, such as APPLY_IAM_POLICY, APPLY_SCP_POLICY, or RUN_SSM_DOCUMENT, which determines whether the action applies an IAM policy, a service control policy, or runs an SSM document. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="approval_model" type="string">
  Defines whether the budget action executes automatically or requires manual approval after it is triggered (valid values: AUTOMATIC or MANUAL). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="budget_name" type="string" required>
  The name of the AWS Budgets budget that this action is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="definition" type="object" required>

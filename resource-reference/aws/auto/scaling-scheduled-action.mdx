`aws_auto_scaling_scheduled_action` changes a real `aws_auto_scaling_auto_scaling_group`'s min/max/desired capacity automatically at a specified time or recurring schedule, for predictable load patterns that don't need to wait for a scaling policy's own metric-driven reaction.

## Input properties

<ResponseField name="auto_scaling_group_name" type="string" required>
  The name of the Auto Scaling group. Required.
</ResponseField>

<ResponseField name="desired_capacity" type="number">
  The desired capacity is the initial capacity of the Auto Scaling group after the scheduled action runs and the capacity it attempts to maintain. Optional.
</ResponseField>

<ResponseField name="end_time" type="string">
  The latest scheduled start time to return. If scheduled action names are provided, this parameter is ignored. Optional.
</ResponseField>

<ResponseField name="max_size" type="number">
  The minimum size of the Auto Scaling group. Optional.
</ResponseField>

<ResponseField name="min_size" type="number">
  The minimum size of the Auto Scaling group. Optional.
</ResponseField>

<ResponseField name="recurrence" type="string">
  The recurring schedule for the action, in Unix cron syntax format. When StartTime and EndTime are specified with Recurrence , they form the boundaries of when the recurring action starts and stops. Optional.
</ResponseField>

<ResponseField name="start_time" type="string">
  The earliest scheduled start time to return. If scheduled action names are provided, this parameter is ignored. Optional.
</ResponseField>

<ResponseField name="time_zone" type="string">
  The time zone for the cron expression. Optional.
</ResponseField>

## Output properties

<ResponseField name="scheduled_action_name" type="string">
  Auto-generated unique identifier Computed by AWS after `ship`.
</ResponseField>

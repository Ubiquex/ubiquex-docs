`aws_auto_scaling_plans_scaling_plan` combines target tracking and predictive scaling into one set of instructions applied across a tagged or CloudFormation-scoped group of resources, generating the real, underlying scaling policies on the caller's behalf from a single higher-level strategy like optimize-for-cost or optimize-for-availability.

## Output properties

<ResponseField name="id" type="string">
  The Terraform resource identifier for an Auto Scaling Plan, set to the scale plan's unique name used for state tracking and import. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="scaling_plan_name" type="string">
  The name of the scaling plan, which uniquely identifies it within the AWS account and is used to reference the plan in AWS Auto Scaling APIs and other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="scaling_plan_version" type="string">
  The version number of the scaling plan, which must be provided on updates to ensure you are modifying the latest version of the plan. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

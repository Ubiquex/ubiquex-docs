`aws_logs_metric_filter` defines a real pattern that CloudWatch Logs evaluates against incoming events in an `aws_logs_log_group`, publishing a CloudWatch metric data point each time a log event matches, the mechanism behind turning free-text logs into alarmable numeric metrics.

## Properties

<ResponseField name="apply_on_transformed_logs" type="bool">
  This parameter is valid only for log groups that have an active log transformer. For more information about log transformers, see [PutTransformer](https://docs.aws.amazon.com/AmazonCloudWatchLogs/latest/APIReference/API_PutTransformer.html). If this value is ``true``, the metric filter is applied on the transformed version of the log events instead of the original ingested log events. Optional.
</ResponseField>

<ResponseField name="emit_system_field_dimensions" type="list(string)">
  The list of system fields that are emitted as additional dimensions in the generated metrics. Returns the ``emitSystemFieldDimensions`` value if it was specified when the metric filter was created. Optional.
</ResponseField>

<ResponseField name="field_selection_criteria" type="string">
  The filter expression that specifies which log events are processed by this metric filter based on system fields. Returns the ``fieldSelectionCriteria`` value if it was specified when the metric filter was created. Optional.
</ResponseField>

<ResponseField name="filter_name" type="string">
  The name of the metric filter. Optional.
</ResponseField>

<ResponseField name="filter_pattern" type="string" required>
  A filter pattern for extracting metric data out of ingested log events. For more information, see [Filter and Pattern Syntax](https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/FilterAndPatternSyntax.html). Required.
</ResponseField>

<ResponseField name="log_group_name" type="string" required>
  The name of an existing log group that you want to associate with this metric filter. Required.
</ResponseField>

<ResponseField name="metric_transformations" type="list(object)" required>
  The metric transformations. Required.
  <Expandable title="properties">

    <ResponseField name="dimensions" type="list(object)">

      <Expandable title="properties">
        <ResponseField name="key" type="string">

        </ResponseField>
        <ResponseField name="value" type="string">
          The value of the dimension, which can be a literal string or a JSON path expression (e.g., $.eventType) used to extract a value from the log event and attach it as a dimension to the metric. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="metric_name" type="string">
      The name of the CloudWatch metric that the metric filter publishes matching log events to. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metric_namespace" type="string">
      The CloudWatch namespace under which the extracted metric is published by this metric filter transformation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metric_value" type="string">
      The value to publish for the metric, which can be a literal number or a JSON expression (like '$.field') evaluated from the matched log event and sent to CloudWatch Metrics. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="unit" type="string">

    </ResponseField>
  </Expandable>

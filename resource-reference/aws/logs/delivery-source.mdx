`aws_logs_delivery_source` represents a real AWS resource, such as a VPC or a Route 53 resolver, registered as a source of vended logs through the newer CloudWatch Logs delivery framework, the origin end of an `aws_logs_delivery`.

## Example

    			ResourceArn:                 "arn:aws:iam::123456789012:policy/ci",

    		})
    	}))
    }

## Input properties

<ResponseField name="delivery_source_configuration" type="any">
  A map of key-value pairs to configure the delivery source. Both keys and values must be between 1 and 255 characters in length. Optional.
</ResponseField>

<ResponseField name="log_type" type="string">
  The type of logs being delivered. Only mandatory when the resourceArn could match more than one. In such a case, the error message will contain all the possible options. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The unique name of the Log source. Required.
</ResponseField>

<ResponseField name="resource_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this delivery source. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags that have been assigned to this delivery source. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag attached to the CloudWatch Logs delivery source, used for organizing, identifying, and managing the resource via metadata such as cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this delivery source. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_arns" type="list(string)">
  This array contains the ARN of the AWS resource that sends logs and is represented by this delivery source. Currently, only one ARN can be in the array. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="service" type="string">
  The AWS service that is sending logs. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of this delivery source. The value can be ACTIVE or INACTIVE. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status_reason" type="string">
  The reason for the status of this delivery source, such as RESOURCE_DELETED. Computed by AWS after `ship`.
</ResponseField>

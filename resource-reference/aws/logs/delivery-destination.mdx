`aws_logs_delivery_destination` represents a real AWS service, CloudWatch Logs, S3, Firehose, or X-Ray, configured to receive vended logs through the newer CloudWatch Logs delivery framework, the target end of an `aws_logs_delivery`.

## Input properties

<ResponseField name="delivery_destination_policy" type="object">
  The IAM resource policy attached to the delivery destination, specifying which AWS accounts or services are granted permission to deliver log events to this destination. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="delivery_destination_name" type="string">
      The name of the delivery destination to assign this policy to Optional.
    </ResponseField>
    <ResponseField name="delivery_destination_policy" type="any">
      The contents of the policy attached to the delivery destination Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="delivery_destination_type" type="string">
  Displays whether this delivery destination is CloudWatch Logs, Amazon S3, Kinesis Data Firehose, or XRay. Optional.
</ResponseField>

<ResponseField name="destination_resource_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies a resource. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of this delivery destination. Required.
</ResponseField>

<ResponseField name="output_format" type="string">
  The format of the logs that are sent to this delivery destination. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags that have been assigned to this delivery destination. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      This field specifies the key of a tag applied to the CloudWatch Logs delivery destination, allowing you to categorize and filter the resource for cost tracking and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the CloudWatch Logs delivery destination, used for organizing, categorizing, and controlling access to the destination via IAM policies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies a resource. Computed by AWS after `ship`.
</ResponseField>

`aws_logs_account_policy` defines a real, account-wide CloudWatch Logs policy, a subscription filter or data protection policy applied by default, rather than configuring the same policy on every individual `aws_logs_log_group`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own account policy"})

    		ubx.Resource(logs.AccountPolicy, "example", logs.AccountPolicyConfig{
    			PolicyDocument:    "example",
    			PolicyName:        "example-policy-name",
    			PolicyType:        "example",
    			Scope:             "example",
    			SelectionCriteria: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="policy_document" type="string" required>
  The body of the policy document you want to use for this topic. You can only add one policy per PolicyType. The policy must be in JSON string format. Length Constraints: Maximum length of 30720 Required.
</ResponseField>

<ResponseField name="policy_name" type="string" required>
  The name of the account policy Required.
</ResponseField>

<ResponseField name="policy_type" type="string" required>
  Type of the policy. Required.
</ResponseField>

<ResponseField name="scope" type="string">
  Scope for policy application Optional.
</ResponseField>

<ResponseField name="selection_criteria" type="string">
  Log group selection criteria to apply policy only to a subset of log groups. SelectionCriteria string can be up to 25KB and cloudwatchlogs determines the length of selectionCriteria by using its UTF-8 bytes Optional.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  User account id Computed by AWS after `ship`.
</ResponseField>

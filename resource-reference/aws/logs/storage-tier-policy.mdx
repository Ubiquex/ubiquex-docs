`aws_logs_storage_tier_policy` configures whether an `aws_logs_log_group`'s older log events automatically move to CloudWatch Logs' lower-cost Infrequent Access storage tier after a chosen age, trading slightly slower query performance for reduced storage cost.

## Example

## Input properties

<ResponseField name="storage_tier" type="string" required>
  The storage tier to apply. Only INTELLIGENT_TIERING is accepted for creation. Required.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The AWS account ID that owns this storage tier policy. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="last_updated_time" type="number">
  Timestamp (milliseconds after Jan 1, 1970 00:00:00 UTC) when the storage tier policy was last updated. Computed by AWS after `ship`.
</ResponseField>

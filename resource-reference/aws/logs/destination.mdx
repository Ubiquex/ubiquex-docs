`aws_logs_destination` creates a real cross-account subscription destination, most commonly a Kinesis stream, that another account's log group subscription filter can stream matching log events to. This is the older CloudWatch Logs subscription mechanism, distinct from the newer delivery-source/delivery-destination framework used by `aws_logs_delivery`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own destination"})

    		ubx.Resource(logs.Destination, "example", logs.DestinationConfig{
    			DestinationName:   "example-destination-name",
    			RoleArn:           "arn:aws:iam::123456789012:policy/example",
    			TargetArn:         "arn:aws:iam::123456789012:policy/example",
    			DestinationPolicy: "example",
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="destination_name" type="string" required>
  The name of the destination resource Required.
</ResponseField>

<ResponseField name="destination_policy" type="string">
  An IAM policy document that governs which AWS accounts can create subscription filters against this destination. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of an IAM role that permits CloudWatch Logs to send data to the specified AWS resource Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag to associate with the CloudWatch Logs destination, used to identify and organize the destination resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the CloudWatch Logs destination resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_arn" type="string" required>
  The ARN of the physical target where the log events are delivered (for example, a Kinesis stream) Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this CloudWatch Logs destination, returned after creation and used to reference the destination in other AWS resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

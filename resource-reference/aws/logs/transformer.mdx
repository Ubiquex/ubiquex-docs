title: "aws_logs_transformer"
description: "`aws_logs_transformer` attaches a real ordered pipeline of processors to an `aws_logs_log_group`..."
---

`aws_logs_transformer` attaches a real ordered pipeline of processors to an `aws_logs_log_group`, applying transformations to each log event at ingestion time so that later Logs Insights queries and metric filters can operate on the transformed, structured version rather than the raw text.

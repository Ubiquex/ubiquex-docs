`aws_logs_log_anomaly_detector` creates a real machine-learning detector that regularly scans one or more log groups, learns the recurring text patterns in their log fields, and flags anomalies that break from those learned patterns.

## Input properties

<ResponseField name="account_id" type="string">
  Account ID for owner of detector Optional.
</ResponseField>

<ResponseField name="anomaly_visibility_time" type="number">
  Sets the number of days of historical log data that the anomaly detector uses as a baseline to establish normal behavior and detect deviations, effectively controlling how far back the detector looks for anomalies. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="detector_name" type="string">
  Name of detector Optional.
</ResponseField>

<ResponseField name="evaluation_frequency" type="string">
  How often log group is evaluated Optional.
</ResponseField>

<ResponseField name="filter_pattern" type="string">
  The CloudWatch Logs filter pattern that selects which log events in the associated log groups the anomaly detector analyzes, using standard filter pattern syntax. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The Amazon Resource Name (ARN) of the CMK to use when encrypting log data. Optional.
</ResponseField>

<ResponseField name="log_group_arn_list" type="list(string)">
  List of Arns for the given log group Optional.
</ResponseField>

`aws_logs_subscription_filter` streams real log events matching a pattern from an `aws_logs_log_group` to a destination, a Kinesis stream, Firehose, or Lambda function, in near real time as they're ingested.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own subscription filter"})

    		ubx.Resource(logs.SubscriptionFilter, "example", logs.SubscriptionFilterConfig{
    			DestinationArn:         "arn:aws:iam::123456789012:policy/example",
    			FilterPattern:          "example",
    			LogGroupName:           "example-log-group-name",
    			ApplyOnTransformedLogs: true,
    			Distribution:           "example",
    			EmitSystemFields:       []string{"example"},
    			FieldSelectionCriteria: "example",
    			FilterName:             "example-filter-name",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="apply_on_transformed_logs" type="bool">
  This parameter is valid only for log groups that have an active log transformer. For more information about log transformers, see [PutTransformer](https://docs.aws.amazon.com/AmazonCloudWatchLogs/latest/APIReference/API_PutTransformer.html). If this value is ``true``, the subscription filter is applied on the transformed version of the log events instead of the original ingested log events. Optional.
</ResponseField>

<ResponseField name="destination_arn" type="string" required>
  The Amazon Resource Name (ARN) of the destination. Required.
</ResponseField>

<ResponseField name="distribution" type="string">
  The method used to distribute log data to the destination, which can be either random or grouped by log stream. Optional.
</ResponseField>

<ResponseField name="emit_system_fields" type="list(string)">
  The list of system fields that are included in the log events sent to the subscription destination. Returns the ``emitSystemFields`` value if it was specified when the subscription filter was created. Optional.
</ResponseField>

<ResponseField name="field_selection_criteria" type="string">
  The filter expression that specifies which log events are processed by this subscription filter based on system fields. Returns the ``fieldSelectionCriteria`` value if it was specified when the subscription filter was created. Optional.
</ResponseField>

<ResponseField name="filter_name" type="string">
  The name of the subscription filter. Optional.
</ResponseField>

<ResponseField name="filter_pattern" type="string" required>
  The filtering expressions that restrict what gets delivered to the destination AWS resource. For more information about the filter pattern syntax, see [Filter and Pattern Syntax](https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/FilterAndPatternSyntax.html). Required.
</ResponseField>

<ResponseField name="log_group_name" type="string" required>
  The log group to associate with the subscription filter. All log events that are uploaded to this log group are filtered and delivered to the specified AWS resource if the filter pattern matches the log events. Required.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of an IAM role that grants CWL permissions to deliver ingested log events to the destination stream. You don't need to provide the ARN when you are working with a logical destination for cross-account delivery. Optional.
</ResponseField>

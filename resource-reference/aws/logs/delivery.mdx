`aws_logs_delivery` creates a real, active connection between an `aws_logs_delivery_source` and an `aws_logs_delivery_destination`, the resource that actually turns a configured source and destination into a flowing pipeline of vended logs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own delivery"})

    		ubx.Resource(logs.Delivery, "example", logs.DeliveryConfig{
    			DeliveryDestinationArn:     "arn:aws:iam::123456789012:policy/example",
    			DeliverySourceName:         "example-delivery-source-name",
    			FieldDelimiter:             "example",
    			RecordFields:               []string{"example"},
    			S3EnableHiveCompatiblePath: true,
    			S3SuffixPath:               "example",
    			Tags:                       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="delivery_destination_arn" type="string" required>
  Amazon Resource Name (ARN) that uniquely identify AWS resource. Required.
</ResponseField>

<ResponseField name="delivery_source_name" type="string" required>
  The name of the delivery source that is associated with this delivery. Required.
</ResponseField>

<ResponseField name="field_delimiter" type="string">
  The field delimiter to use between record fields when the final output format of a delivery is in Plain , W3C , or Raw format. Optional.
</ResponseField>

<ResponseField name="record_fields" type="list(string)">
  The list of record fields to be delivered to the destination, in order. If the delivery's log source has mandatory fields, they must be included in this list. Optional.
</ResponseField>

<ResponseField name="s3_enable_hive_compatible_path" type="bool">
  This parameter causes the S3 objects that contain delivered logs to use a prefix structure that allows for integration with Apache Hive. Optional.
</ResponseField>

<ResponseField name="s3_suffix_path" type="string">
  This string allows re-configuring the S3 object prefix to contain either static or variable sections. The valid variables to use in the suffix path will vary by each log source. See ConfigurationTemplate$allowedSuffixPathFields for more info on what values are supported in the suffix path for each log source. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags that have been assigned to this delivery. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to this CloudWatch Logs delivery, used to assign metadata for identifying, organizing, and managing the delivery resource, including cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Amazon Resource Name (ARN) that uniquely identify AWS resource. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="delivery_destination_type" type="string">
  Displays whether the delivery destination associated with this delivery is CloudWatch Logs, Amazon S3, or Kinesis Data Firehose. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="delivery_id" type="string">
  The unique ID that identifies this delivery in your account. Computed by AWS after `ship`.
</ResponseField>

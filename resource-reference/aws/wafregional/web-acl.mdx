`aws_wafregional_web_acl` creates a real, top-level web ACL under AWS WAF Classic Regional, evaluating its `aws_wafregional_rule`s against requests to an associated ALB or API Gateway. Support ended September 30, 2025, roughly eleven months in the past; AWS's current, actively developed offering is `aws_wafv2_web_acl`.

## Input properties

<ResponseField name="default_action" type="object" required>
  The action AWS WAF takes when a web request doesn't match any rule in the web ACL, specified as an object with a Type property that can be ALLOW, BLOCK, or COUNT. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string" required>
      The action that AWS WAF takes when a request doesn't match any rule in the web ACL, either 'ALLOW' or 'BLOCK'. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metric_name" type="string" required>
  The name of the Amazon CloudWatch metric associated with the web ACL, used for monitoring its activity in CloudWatch. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  Required.
</ResponseField>

<ResponseField name="rules" type="list(object)">
  Defines the ordered list of rules for the web ACL, where each rule specifies the rule's ID (referencing an aws_wafregional_rule or aws_wafregional_rule_group resource) and the action (allow, block, or count) that AWS WAF Regional takes when a request matches the rule. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="action" type="object">
      Determines the action (ALLOW, BLOCK, or COUNT) that AWS WAF Regional applies to a web request when the corresponding rule matches. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Specifies the action that AWS WAF takes when a web request matches the conditions of the rule, such as ALLOW, BLOCK, or COUNT. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="priority" type="number">
      Determines the evaluation order of the rule within the web ACL, where rules with lower priority values are evaluated first. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rule_id" type="string">
      Specifies the unique identifier of the AWS WAF Regional rule to associate with this web ACL's rule list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

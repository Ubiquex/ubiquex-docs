## Input properties

<ResponseField name="geo_match_constraints" type="list(object)">
  Defines the list of geographical constraints (country codes) that this WAF Regional geo match set matches against, with each constraint specifying a country to include in the match set. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      Specifies the type of geographic constraint, currently only supporting the value 'Country' for a WAF Regional geo match set. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The two-letter ISO 3166-1 alpha-2 country code (e.g., 'US' for United States) that the geographic match constraint matches when the constraint's type is 'Country'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A friendly name for the geo match set, used as a unique identifier when referencing it in AWS WAF Regional. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier (ID) of the WAF Regional Geo Match Set, as assigned by AWS when the set is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

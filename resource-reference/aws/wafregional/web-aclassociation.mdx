`aws_wafregional_web_aclassociation` attaches a real `aws_wafregional_web_acl` to a specific ALB or API Gateway stage, the resource that actually turns the ACL's rules on for that resource's traffic. Support for AWS WAF Classic ended September 30, 2025.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wafregional "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/wafregional"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own web aclassociation"})

    		ubx.Resource(wafregional.WebAclassociation, "example", wafregional.WebAclassociationConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			WebAclid:    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="resource_arn" type="string" required>
  The ARN of the AWS resource (such as an Application Load Balancer or Amazon API Gateway stage) to associate with the Web ACL. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="web_aclid" type="string" required>
  The unique identifier of the AWS WAF Regional Web ACL that is associated with the specified resource, such as an Application Load Balancer or Amazon API Gateway stage. Required. **(AI-inferred)**
</ResponseField>

`aws_wafregional_ipset` defines a real set of IP addresses or CIDR ranges that an `aws_wafregional_rule` references, the Regional counterpart to `aws_waf_ipset`. Support for AWS WAF Classic ended September 30, 2025.

## Input properties

<ResponseField name="ipset_descriptors" type="list(object)">
  Lists the IP addresses and CIDR ranges in the IPSet, where each descriptor specifies a Type (IPV4 or IPV6) and a Value in CIDR notation. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      Specifies the IP address type (IPV4 or IPV6) for the IP set descriptor. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The IP address or CIDR block to match, such as 192.0.2.0/24 or 2001:db8::/32. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  Sets the friendly name that identifies this AWS WAF Regional IP set, used as a unique label for the set within the AWS WAF service. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier (IPSetId) assigned by AWS to this WAF Regional IP set, used to reference the IP set in AWS WAF rules and other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

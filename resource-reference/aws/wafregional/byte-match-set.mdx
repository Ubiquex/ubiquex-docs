`aws_wafregional_byte_match_set` defines a real condition, matching a specific byte sequence in a request part, that an `aws_wafregional_rule` references, the Regional (ALB/API Gateway) counterpart to `aws_waf_byte_match_set`'s global (CloudFront) scope. This is part of AWS WAF Classic, which AWS deprecated: support ended September 30, 2025, roughly eleven months in the past. AWS's current, actively developed offering is AWS WAFv2.

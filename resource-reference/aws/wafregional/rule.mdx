`aws_wafregional_rule` combines real match conditions into a single rule that an `aws_wafregional_web_acl` evaluates, the Regional (ALB/API Gateway) counterpart to `aws_waf_rule`'s global (CloudFront) scope, under AWS WAF Classic. Support ended September 30, 2025, roughly eleven months in the past; AWS's current, actively developed offering is AWS WAFv2.

## Input properties

<ResponseField name="metric_name" type="string" required>
  The CloudWatch metric name associated with the rule, which is required and must be unique within the region for monitoring rule-level metrics. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The friendly name for the WAF Regional rule, which is required at creation and cannot be changed after creation, used to identify the rule. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="predicates" type="list(object)">
  A list of predicates that define the conditions under which the rule matches requests, each specifying the match type, the data ID of the associated AWS WAF Regional object, and whether the match condition is negated. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_id" type="string">
      The unique identifier of the AWS WAF Regional resource (such as a ByteMatchSet, IPSet, or SqlInjectionMatchSet) that this predicate references for match evaluation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="negated" type="bool">
      Specifies whether to negate the condition defined by the referenced rule, causing the WAF rule to match when that underlying condition is false. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of the WAF Regional rule predicate, indicating the kind of match condition being evaluated, such as IPMatch, ByteMatch, SqlInjectionMatch, XssMatch, SizeConstraint, GeoMatch, or RegexMatch. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique rule ID assigned by AWS WAF Regional when the rule is created, used to reference the rule in other resources such as WebACL rules. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

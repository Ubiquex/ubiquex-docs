## Input properties

<ResponseField name="name" type="string" required>
  The required friendly name of the SQL injection match set, used to identify it within AWS WAF Regional. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="sql_injection_match_tuples" type="list(object)">
  Specifies a list of SQL injection match tuples, each containing a field to match (such as URI or query string) and a text transformation, that together determine which requests are flagged for SQL injection in this AWS WAF Regional match set. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="field_to_match" type="object">
      Identifies the specific portion of the web request (e.g., query string, header, body, or method) that the SQL injection match tuple will inspect for malicious patterns. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="data" type="string">
          The name of the HTTP header to inspect when the field_to_match type is HEADER, as used in the SQL injection match tuple. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the part of the web request to inspect for SQL injection patterns, such as HEADER, QUERY_STRING, BODY, or URI. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="text_transformation" type="string">
      Specifies how the web request component (e.g., the query string or header) is transformed before WAF inspects it for SQL injection patterns, such as 'NONE', 'URL_DECODE', or 'BASE64_DECODE'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

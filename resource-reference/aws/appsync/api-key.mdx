`aws_app_sync_api_key` issues a key-based credential for authorizing requests against an `aws_app_sync_api`, one of several supported authorization modes alongside IAM, Cognito, OpenID Connect, and Lambda authorizers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appsync "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appsync"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sync api key"})

    		ubx.Resource(appsync.ApiKey, "example", appsync.ApiKeyConfig{
    			ApiId:       "example",
    			Description: "Managed by ubx.",
    			Expires:     1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_id" type="string" required>
  The unique identifier of the AppSync GraphQL API that this API key is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  An optional user-provided description that helps identify the purpose or owner of the API key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="expires" type="number">
  The expiration time of the API key, expressed as the number of seconds since the Unix epoch. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="api_key" type="string">
  The generated API key value used for authenticating requests to the AppSync GraphQL API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="api_key_id" type="string">

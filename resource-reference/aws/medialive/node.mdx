`aws_media_live_node` registers a real physical or virtual compute unit into an `aws_media_live_cluster`, the actual hardware or instance that MediaLive Anywhere schedules channel encoding work onto.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	medialive "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/medialive"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own live node"})

    		ubx.Resource(medialive.Node, "example", medialive.NodeConfig{
    			ClusterId:             "example",
    			Name:                  "example",
    			NodeInterfaceMappings: []map[string]any{{"logical_interface_name": "example-logical-interface-name"}},
    			Role:                  "example",
    			SdiSourceMappings:     []map[string]any{{"card_number": 1}},
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cluster_id" type="string" required>
  The ID of the Cluster that the Node belongs to. Required.
</ResponseField>

<ResponseField name="name" type="string">
  The user-specified name of the Node. Optional.
</ResponseField>

<ResponseField name="node_interface_mappings" type="list(object)">
  An array of interface mappings for the Node. Optional.
  <Expandable title="properties">
    <ResponseField name="logical_interface_name" type="string">
      Specifies the logical name (e.g., 'eth0') assigned to a network interface on a MediaLive Anywhere node, used to map that interface to a specific Elastic Network Interface (ENI). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="network_interface_mode" type="string">
      Specifies whether the node's network interface uses DHCP or static IP addressing for its interface mapping in an AWS Elemental MediaLive cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="physical_interface_name" type="string">
      Specifies the name of the physical network interface (such as eth0) on the on-premises MediaLive node that is mapped to a logical interface name for MediaLive Anywhere connectivity. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role" type="string">
  The role of the Node in the Cluster. ACTIVE means the Node is available for encoding. BACKUP means the Node is a redundant Node and might get used if an ACTIVE Node fails. Optional.
</ResponseField>

<ResponseField name="sdi_source_mappings" type="list(object)">
  An array of SDI source mappings. Optional.
  <Expandable title="properties">
    <ResponseField name="card_number" type="number">
      The physical SDI input card number on the MediaLive node to which the corresponding SDI source is mapped. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="channel_number" type="number">
      The logical channel number within the MediaLive multiplex to which the corresponding SDI source (specified in the same mapping) is assigned, identifying which channel the SDI input feeds. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="sdi_source" type="string">
      The SDI source identifier (e.g., the ARN of an AWS::MediaLive::SdiSource resource) that this mapping associates with a logical source name on the node, enabling MediaLive channels to use that physical SDI input. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of key-value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS Elemental MediaLive node, used for metadata organization and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value assigned to a tag on the AWS MediaLive node, used to attach metadata such as environment or cost center for resource management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the Node. It is automatically assigned when the Node is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="channel_placement_groups" type="list(string)">
  An array of IDs. Each ID is one ChannelPlacementGroup that is associated with this Node. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="connection_state" type="string">
  The current connection state of the Node. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique ID of the Node. Unique in the Cluster. The ID is the resource-id portion of the ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="instance_arn" type="string">
  The ARN of the EC2 instance hosting the Node. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The current state of the Node. Computed by AWS after `ship`.
</ResponseField>

`aws_media_live_cluster` creates a real MediaLive Anywhere cluster, the on-premises or Outposts infrastructure grouping that `aws_media_live_channel_placement_group`s and their channels run on, letting MediaLive manage encoding workloads outside AWS's own data centers.

## Input properties

<ResponseField name="cluster_type" type="string">
  The hardware type for the cluster. Optional.
</ResponseField>

<ResponseField name="instance_role_arn" type="string">
  The IAM role your nodes will use. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The user-specified name of the Cluster to be created. Optional.
</ResponseField>

<ResponseField name="network_settings" type="object">
  On premises settings which will have the interface network mappings and default Output logical interface Optional.
  <Expandable title="properties">
    <ResponseField name="default_route" type="string">
      Default value if the customer does not define it in channel Output API Optional.
    </ResponseField>
    <ResponseField name="interface_mappings" type="list(object)">
      Network mappings for the cluster Optional.
      <Expandable title="properties">
        <ResponseField name="logical_interface_name" type="string">
          Specifies the logical name you assign to a physical network interface in a MediaLive cluster's interface mapping, which is used to reference that interface within the cluster's network configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="network_id" type="string">
          In an AWS::MediaLive::Cluster's network settings, the network_id field of each interface mapping specifies the network identifier (such as a VPC or subnet ID) that the associated IP addresses belong to. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of key-value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS MediaLive cluster, used to add custom metadata for identifying, organizing, or managing the cluster in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the Cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="channel_ids" type="list(string)">

</ResponseField>

<ResponseField name="id" type="string">
  The unique ID of the Cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The current state of the Cluster. Computed by AWS after `ship`.
</ResponseField>

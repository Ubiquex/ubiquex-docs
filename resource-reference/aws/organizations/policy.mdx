`aws_organizations_policy` creates a real policy, a service control policy, tag policy, backup policy, AI services opt-out policy, or declarative policy, that can be attached to an AWS Organization, an `aws_organizations_organizational_unit`, or an `aws_organizations_account` to govern what that target and everything under it can do.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own policy"})

    		ubx.Resource(organizations.Policy, "example", organizations.PolicyConfig{
    			Content:     "example",
    			Name:        "example",
    			Type:        "example",
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    			TargetIds:   []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="content" type="any" required>
  The Policy text content. For AWS CloudFormation templates formatted in YAML, you can provide the policy in JSON or YAML format. AWS CloudFormation always converts a YAML policy to JSON format before submitting it. Required.
</ResponseField>

<ResponseField name="description" type="string">
  Human readable description of the policy Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the Policy Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags that you want to attach to the newly created policy. For each tag in the list, you must specify both a tag key and a value. You can set the value to an empty string, but you can't set it to null. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that is attached to the AWS Organizations policy, used to identify the tag's purpose or category. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a tag assigned to the AWS Organizations policy, used to organize and identify the policy. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_ids" type="list(string)">
  List of unique identifiers (IDs) of the root, OU, or account that you want to attach the policy to Optional.
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of policy to create. You can specify one of the following values: AISERVICES_OPT_OUT_POLICY, BACKUP_POLICY, BEDROCK_POLICY, CHATBOT_POLICY, DECLARATIVE_POLICY_EC2, INSPECTOR_POLICY, NETWORK_SECURITY_DIRECTOR_POLICY, RESOURCE_CONTROL_POLICY, S3_POLICY, SECURITYHUB_POLICY, SERVICE_CONTROL_POLICY, TAG_POLICY, UPGRADE_ROLLOUT_POLICY Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  ARN of the Policy Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="aws_managed" type="bool">
  A boolean value that indicates whether the specified policy is an AWS managed policy. If true, then you can attach the policy to roots, OUs, or accounts, but you cannot edit it. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  Id of the Policy Computed by AWS after `ship`.
</ResponseField>

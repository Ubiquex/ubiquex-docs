`aws_organizations_account` creates a real new member AWS account inside an AWS Organization, provisioned and joined to the organization directly rather than invited separately.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own account"})

    		ubx.Resource(organizations.Account, "example", organizations.AccountConfig{
    			AccountName: "example-account-name",
    			Email:       "example",
    			ParentIds:   []string{"example"},
    			RoleName:    "example-role-name",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="account_name" type="string" required>
  The friendly name of the member account. Required.
</ResponseField>

<ResponseField name="email" type="string" required>
  The email address of the owner to assign to the new member account. Required.
</ResponseField>

<ResponseField name="parent_ids" type="list(string)">
  List of parent nodes for the member account. Currently only one parent at a time is supported. Default is root. Optional.
</ResponseField>

<ResponseField name="role_name" type="string">
  The name of an IAM role that AWS Organizations automatically preconfigures in the new member account. Default name is OrganizationAccountAccessRole if not specified. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags that you want to attach to the newly created account. For each tag in the list, you must specify both a tag key and a value. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a key-value tag assigned to the AWS Organizations account, enabling you to categorize and manage the account for cost allocation, access control, or operational purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a key-value tag assigned to the AWS Organizations account. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  If the account was created successfully, the unique identifier (ID) of the new account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="joined_method" type="string">
  The method by which the account joined the organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="joined_timestamp" type="string">
  The date the account became a part of the organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="paths" type="list(string)">
  The paths in the organization where the account exists. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the account in the organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the account in the organization. Computed by AWS after `ship`.
</ResponseField>

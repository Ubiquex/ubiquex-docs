`aws_organizations_resource_policy` attaches a real resource-based policy at the AWS Organizations management account level, a narrower, newer counterpart to the identity- and OU-targeted `aws_organizations_policy`, controlling which principals can call Organizations APIs against the organization itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own resource policy"})

    		ubx.Resource(organizations.ResourcePolicy, "ci-runner", organizations.ResourcePolicyConfig{
    			Content: "example",
    			Tags:    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="content" type="any" required>
  The policy document. For AWS CloudFormation templates formatted in YAML, you can provide the policy in JSON or YAML format. AWS CloudFormation always converts a YAML policy to JSON format before submitting it. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags that you want to attach to the resource policy Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Organizations resource policy. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the AWS Organizations resource policy, used to organize and identify the policy. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the resource policy. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier (ID) associated with this resource policy. Computed by AWS after `ship`.
</ResponseField>

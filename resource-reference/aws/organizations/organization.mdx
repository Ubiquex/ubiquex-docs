`aws_organizations_organization` creates the real AWS Organization itself, the root resource that every `aws_organizations_account`, `aws_organizations_organizational_unit`, and `aws_organizations_policy` in it exists under, and that determines whether the organization runs in consolidated billing or full-features mode.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own organization"})

    		ubx.Resource(organizations.Organization, "example", organizations.OrganizationConfig{
    			FeatureSet: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="feature_set" type="string">
  Specifies the feature set supported by the new organization. Each feature set supports different levels of functionality. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of an organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier (ID) of an organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="management_account_arn" type="string">
  The Amazon Resource Name (ARN) of the account that is designated as the management account for the organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="management_account_email" type="string">
  The email address that is associated with the AWS account that is designated as the management account for the organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="management_account_id" type="string">
  The unique identifier (ID) of the management account of an organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="root_id" type="string">
  The unique identifier (ID) for the root. Computed by AWS after `ship`.
</ResponseField>

`aws_organizations_organizational_unit` creates a real container within an AWS Organization's hierarchy that groups `aws_organizations_account`s and other OUs, so `aws_organizations_policy` resources like service control policies can be attached once and apply to everything nested under it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own organizational unit"})

    		ubx.Resource(organizations.OrganizationalUnit, "example", organizations.OrganizationalUnitConfig{
    			Name:     "example",
    			ParentId: "example",
    			Tags:     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The friendly name of this OU. Required.
</ResponseField>

<ResponseField name="parent_id" type="string" required>
  The unique identifier (ID) of the parent root or OU that you want to create the new OU in. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags that you want to attach to the newly created OU. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key (name) of a tag attached to the organizational unit, used to identify and categorize the unit for resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value for a tag key attached to the organizational unit, used to assign metadata for management and tracking purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of this OU. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier (ID) associated with this OU. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="path" type="string">
  The path in the organization where this OU exists. Computed by AWS after `ship`.
</ResponseField>

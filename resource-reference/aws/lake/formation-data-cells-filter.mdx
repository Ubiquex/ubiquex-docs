`aws_lake_formation_data_cells_filter` defines a real, fine-grained filter, restricting access to specific rows or columns of a table, that Lake Formation enforces on top of its own coarser table- and database-level `aws_lake_formation_permissions` grants.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	lake "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lake"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation data cells filter"})

    		ubx.Resource(lake.FormationDataCellsFilter, "example", lake.FormationDataCellsFilterConfig{
    			DatabaseName:   "example-database-name",
    			Name:           "example",
    			TableCatalogId: "example",
    			TableName:      "example-table-name",
    			ColumnNames:    []string{"example"},
    			ColumnWildcard: map[string]any{"excluded_column_names": []string{"example"}},
    			RowFilter:      map[string]any{"all_rows_wildcard": "example"},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="column_names" type="list(string)">
  A list of column names. Optional.
</ResponseField>

<ResponseField name="column_wildcard" type="object">
  An object representing the Data Cells Filter's Columns. Either Column Names or a Wildcard is required. Optional.
  <Expandable title="properties">
    <ResponseField name="excluded_column_names" type="list(string)">
      A list of column names. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="database_name" type="string" required>
  A string representing a resource's name. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  A string representing a resource's name. Required.
</ResponseField>

<ResponseField name="row_filter" type="object">
  An object representing the Data Cells Filter's Row Filter. Either a Filter Expression or a Wildcard is required. Optional.
  <Expandable title="properties">
    <ResponseField name="all_rows_wildcard" type="any">
      An empty object representing a row wildcard. Optional.
    </ResponseField>
    <ResponseField name="filter_expression" type="string">
      A PartiQL predicate. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="table_catalog_id" type="string" required>
  A string representing the Catalog Id. Required.
</ResponseField>

<ResponseField name="table_name" type="string" required>
  A string representing a resource's name. Required.
</ResponseField>

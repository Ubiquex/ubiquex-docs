`aws_lake_formation_principal_permissions` grants a real Lake Formation permission to a principal on a Data Catalog resource, AWS's current, recommended permission model, which supports both direct resource grants and LF-Tag-based access control for managing permissions across large numbers of databases and tables at once.

## Input properties

<ResponseField name="catalog" type="string">
  Optional.
</ResponseField>

<ResponseField name="permissions" type="list(string)" required>
  The list of Lake Formation permissions to grant to the principal, with allowed values such as ALL, ALTER, CREATE_DATABASE, CREATE_TABLE, DATA_LOCATION_ACCESS, DELETE, DESCRIBE, DROP, INSERT, and SELECT. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="permissions_with_grant_option" type="list(string)" required>
  The list of Lake Formation permissions to grant to the principal, where the principal also receives the ability to grant these permissions to other principals. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="principal" type="object" required>
  The LFlong principal. Required.
  <Expandable title="properties">
    <ResponseField name="data_lake_principal_identifier" type="string">
      Unique identifier for the principal receiving the Lake Formation permissions, such as an AWS account ID, IAM role ARN, or IAM user ARN. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resource" type="object" required>
  A structure for the resource. Required.
  <Expandable title="properties">

      A structure that describes certain columns on certain rows. Optional.

          The name of the Lake Formation database that contains the data cells filter to which the principal permissions are being granted. Required. **(AI-inferred)**

          The name of the AWS Lake Formation Data Cells Filter to which the principal permissions are being granted. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="table_catalog_id" type="string" required>
          The AWS Glue Data Catalog ID (usually the account ID) of the catalog that contains the database and table for which this data cells filter is defined. Required. **(AI-inferred)**

        <ResponseField name="table_name" type="string" required>
          The name of the table in the AWS Glue Data Catalog on which the referenced data cells filter is defined, identifying the specific table resource for this Lake Formation principal permission. Required. **(AI-inferred)**
        </ResponseField>

    <ResponseField name="data_location" type="object">
      A structure for a data location object where permissions are granted or revoked. Optional.

        </ResponseField>
        <ResponseField name="resource_arn" type="string" required>
          The Amazon Resource Name (ARN) of the S3 data location that this principal permission applies to, identifying the exact AWS Lake Formation data location resource for the permission grant. Required. **(AI-inferred)**

      </Expandable>

      A structure for the database object. Optional.
      <Expandable title="properties">

          The identifier of the Data Catalog (typically the AWS account ID) that contains the database, used to specify which database resource the principal permissions apply to. Required. **(AI-inferred)**

        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="lftag" type="object">
      A structure containing an LF-tag key and values for a resource. Optional.
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          The ID of the Data Catalog (typically the AWS account ID) that contains the LF-tag on which the principal permissions are granted. Required. **(AI-inferred)**

          The key of the Lake Formation LF-tag that defines the resource to which the principal permissions apply. Required. **(AI-inferred)**
        </ResponseField>

          The LF-tag values that, combined with the tag key, identify the tag resource to which the principal permissions are granted. Required. **(AI-inferred)**

    </ResponseField>
    <ResponseField name="lftag_policy" type="object">
      A list of LF-tag conditions that define a resource's LF-tag policy. A structure that allows an admin to grant user permissions on certain conditions. For example, granting a role access to all columns that do not have the LF-tag 'PII' in tables that have the LF-tag 'Prod'. Optional.
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          The ID of the Glue Data Catalog (typically the AWS account ID) where the LF-Tag policy is defined. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="expression" type="list(object)" required>
          The expression is a list of LF-tag key-value pairs that define the set of Lake Formation resources (e.g., databases or tables) to which the granted principal permissions apply, requiring the resource to match all specified tag keys and at least one value from each key's allowed list. Required. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="tag_key" type="string">
              The key of the LF-Tag in an LF-Tag policy expression that specifies the set of LF-Tags to which the principal permissions apply. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="tag_values" type="list(string)">
              Specifies the allowable values for the LF-tag key in a tag condition of the LF-tag policy expression that determines resource access. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="resource_type" type="string" required>
          Specifies the resource type for the LF-tag policy, which must be either DATABASE or TABLE, determining the type of Lake Formation resource to which the tag-based permissions apply. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="table" type="object">

      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          The Data Catalog ID (typically the AWS account ID) that contains the table for which the principal permissions are being granted, used to uniquely identify the table resource. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="database_name" type="string" required>
          The name of the AWS Glue Data Catalog database that contains the table for which these Lake Formation principal permissions are being granted. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of the table within the database to which the principal permissions are granted. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="table_wildcard" type="any">
          When set, this field represents a table wildcard, meaning the permission applies to every table under the specified database instead of a single named table. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="table_with_columns" type="object">
      A structure for a table with columns object. This object is only used when granting a SELECT permission. This object must take a value for at least one of ``ColumnsNames``, ``ColumnsIndexes``, or ``ColumnsWildcard``. Optional.
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          The identifier of the Data Catalog, typically the AWS account ID, for the table with columns resource. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="column_names" type="list(string)">
          Specifies the list of column names within the table that the principal's permissions are scoped to, when the resource is set to a TableWithColumns resource. Optional. **(AI-inferred)**

        <ResponseField name="column_wildcard" type="object">

## Output properties

<ResponseField name="principal_identifier" type="string">
  The identifier of the Lake Formation principal (such as an IAM user or role ARN, or an AWS account ID) to which the permissions are granted or revoked. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_identifier" type="string">
  The unique AWS-generated identifier for this Lake Formation principal permission grant, which encapsulates the principal and resource that the permission applies to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

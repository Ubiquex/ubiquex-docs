`aws_lake_formation_permissions` grants a real Lake Formation permission to a principal on a Data Catalog resource (a database or table) using Lake Formation's original, resource-by-resource grant model, the predecessor to the newer `aws_lake_formation_principal_permissions`, which additionally supports LF-Tag-based grants at scale.

## Input properties

<ResponseField name="data_lake_principal" type="object" required>
  The AWS Lake Formation principal (such as an IAM user, role, or account) that receives the granted permissions, identified by its data lake principal identifier. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_lake_principal_identifier" type="string">
      The data lake principal identifier specifies the unique AWS identity (such as an IAM role ARN, IAM user ARN, or AWS account ID) that the Lake Formation permissions are granted to. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="permissions" type="list(string)">
  The list of Lake Formation permissions to grant on the target resource, such as SELECT, ALTER, DROP, or CREATE_TABLE, defining the actions the principal is allowed to perform. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="permissions_with_grant_option" type="list(string)">

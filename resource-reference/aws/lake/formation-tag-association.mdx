`aws_lake_formation_tag_association` attaches a real `aws_lake_formation_tag` to a Data Catalog resource or table column, so that principals granted matching tags, rather than an explicit per-resource grant, gain access to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lake "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lake"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation tag association"})

    		ubx.Resource(lake.FormationTagAssociation, "example", lake.FormationTagAssociationConfig{
    			Lftags:   []map[string]any{{"catalog_id": "example"}},
    			Resource: map[string]any{"catalog": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="lftags" type="list(object)" required>
  The list of LF-Tags (key-value pairs) to associate with the specified resource, where each LF-Tag consists of a tag key and a list of tag values. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="catalog_id" type="string">
      The AWS account ID of the Data Catalog where the LF-tag to associate is defined; if omitted, the current account's Data Catalog is used. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="tag_key" type="string">
      The key of an LF-Tag (Lake Formation tag) that is associated with the resource, which must match an existing tag key in AWS Lake Formation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="tag_values" type="list(string)">
      The list of tag values for a given LF-Tag key in the tag association, specifying which value(s) of that key are applied to the associated Lake Formation resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resource" type="object" required>
  Specifies the Lake Formation resource (database, table, or table with columns) to which the LF-tags are attached, including optional catalog ID and resource identifiers. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="catalog" type="any">
      The unique identifier of the AWS Glue Data Catalog (typically the AWS account ID) in which the target database or table exists, used to locate the resource for the LF-Tag association. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="database" type="object">
      The `database` object defines a database resource in the AWS Lake Formation catalog, specifying the catalog ID and database name, to which the referenced LF-tags are associated. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          The catalog_id property specifies the AWS account ID of the Data Catalog that contains the database to which the tag is being associated. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of the Data Catalog database to which the LF-tag association applies. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="table" type="object">
      The table property of the resource object defines the specific table in the AWS Glue Data Catalog to associate the LF-tags with, supplied via its catalog ID, database name, and table name. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          The catalog ID (typically the AWS account ID) of the Data Catalog where the table resides, used to identify the table for which the LF-tag association is being defined. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="database_name" type="string" required>
          The name of the Glue database that contains the table to which the LF-tag association is applied. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of the table identified in the resource's table property, specifying which table in the referenced database receives the LF-tag association. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="table_wildcard" type="any">
          When set, this indicates the LF-tag association applies to all tables in the database (a table wildcard), rather than a single named table. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="table_with_columns" type="object">
      Specifies the Data Catalog table columns to associate the LF-Tag with, including the catalog ID, database name, table name, and a list of column names. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string" required>
          Specifies the AWS Glue Data Catalog ID (typically the AWS account ID) that contains the table whose columns are being associated with an LF-tag, required when targeting a specific table's columns. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="column_names" type="list(string)" required>
          The names of the columns within the specified table to which the LF-tags will be associated. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="database_name" type="string" required>
          The name of the database in which the table (and optionally its columns) being associated with LF-tags is located. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The name of the table in the Data Catalog to which this tag association applies, as part of the table_with_columns resource identifier. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="resource_identifier" type="string">
  Unique string identifying the resource. Used as primary identifier, which ideally should be a string Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="tags_identifier" type="string">
  Unique string identifying the resource's tags. Used as primary identifier, which ideally should be a string Computed by AWS after `ship`.
</ResponseField>

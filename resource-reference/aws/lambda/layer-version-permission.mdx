`aws_lambda_layer_version_permission` grants a real other AWS account, or the whole account's organization, permission to use a specific `aws_lambda_layer_version`, letting a layer be shared without making it public.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lambda "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lambda"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own layer version permission"})

    		ubx.Resource(lambda.LayerVersionPermission, "ci-runner", lambda.LayerVersionPermissionConfig{
    			Action:          "example",
    			LayerVersionArn: "arn:aws:iam::123456789012:policy/ci",
    			Principal:       "example",
    			OrganizationId:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="action" type="string" required>
  The API action that grants access to the layer. Required.
</ResponseField>

<ResponseField name="layer_version_arn" type="string" required>
  The name or Amazon Resource Name (ARN) of the layer. Required.
</ResponseField>

<ResponseField name="organization_id" type="string">
  With the principal set to *, grant permission to all accounts in the specified organization. Optional.
</ResponseField>

<ResponseField name="principal" type="string" required>
  An account ID, or * to grant layer usage permission to all accounts in an organization, or all AWS accounts (if organizationId is not specified). Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  ID generated by service Computed by AWS after `ship`.
</ResponseField>

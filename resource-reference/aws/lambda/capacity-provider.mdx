`aws_lambda_capacity_provider` provisions a real pool of EC2 instances, with a chosen instance type, networking, and scaling configuration, that Lambda functions run on under Lambda Managed Instances, combining EC2-level compute control with Lambda's own serverless programming model. This is a genuinely new capability, so behavior here is verified live rather than assumed from general knowledge.

## Example

    package main

    import (
    	lambda "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lambda"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own capacity provider"})

    		ubx.Resource(lambda.CapacityProvider, "example", lambda.CapacityProviderConfig{
    			PermissionsConfig:             map[string]any{"capacity_provider_operator_role_arn": "example"},

    			CapacityProviderScalingConfig: map[string]any{"max_vcpu_count": 1},
    			InstanceRequirements:          map[string]any{"allowed_instance_types": []string{"example"}},
    			KmsKeyArn:                     "arn:aws:iam::123456789012:policy/example",
    			PropagateTags:                 map[string]any{"explicit_tags": []map[string]any{{"key": "example"}}},
    			Tags:                          []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="capacity_provider_name" type="string">
  Optional.
</ResponseField>

<ResponseField name="capacity_provider_scaling_config" type="object">
  Configuration that defines how the capacity provider scales compute instances based on demand and policies. Optional.
  <Expandable title="properties">
    <ResponseField name="max_vcpu_count" type="number">
      The maximum number of vCPUs that the capacity provider can provision across all compute instances. Optional.
    </ResponseField>
    <ResponseField name="scaling_mode" type="string">
      The scaling mode for the capacity provider. Optional.
    </ResponseField>
    <ResponseField name="scaling_policies" type="list(object)">
      A list of target tracking scaling policies for the capacity provider. Optional.
      <Expandable title="properties">
        <ResponseField name="predefined_metric_type" type="string">
          Optional; if omitted, computed by AWS.
        </ResponseField>
        <ResponseField name="target_value" type="number">
          Optional; if omitted, computed by AWS.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="instance_requirements" type="object">
  Specifications that define the characteristics and constraints for compute instances used by the capacity provider. Optional.
  <Expandable title="properties">
    <ResponseField name="allowed_instance_types" type="list(string)">
      A list of EC2 instance types that the capacity provider is allowed to use. If not specified, all compatible instance types are allowed. Optional.
    </ResponseField>
    <ResponseField name="architectures" type="list(string)">
      A list of supported CPU architectures for compute instances. Valid values include ``x86_64`` and ``arm64``. Optional.
    </ResponseField>
    <ResponseField name="excluded_instance_types" type="list(string)">
      A list of EC2 instance types that the capacity provider should not use, even if they meet other requirements. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The ARN of the KMS key used to encrypt the capacity provider's resources. Optional.
</ResponseField>

<ResponseField name="permissions_config" type="object" required>
  Configuration that specifies the permissions required for the capacity provider to manage compute resources. Required.
  <Expandable title="properties">
    <ResponseField name="capacity_provider_operator_role_arn" type="string" required>
      The ARN of the IAM role that the capacity provider uses to manage compute instances and other AWS resources. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="propagate_tags" type="object">
  Configuration that defines how tags are propagated to managed resources. Optional.
  <Expandable title="properties">
    <ResponseField name="explicit_tags" type="list(object)">
      A list of tags to explicitly propagate to managed resources. Maximum of 40 tags. Optional.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          Optional; if omitted, computed by AWS.
        </ResponseField>
        <ResponseField name="value" type="string">
          Optional; if omitted, computed by AWS.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="mode" type="string">
      The mode for tag propagation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A key-value pair that provides metadata for the capacity provider. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="telemetry_config" type="object">
  Configuration that specifies the telemetry collection for the capacity provider. Optional.
  <Expandable title="properties">
    <ResponseField name="logging_config" type="object">
      The capacity provider's Amazon CloudWatch Logs configuration settings. Optional.
      <Expandable title="properties">
        <ResponseField name="log_group" type="string">
          The name of the Amazon CloudWatch log group the capacity provider sends logs to. By default, Lambda capacity providers send logs to a default log group named ``/aws/lambda/capacity-provider/&lt;capacity provider name&gt;``. To use a different log group, enter an existing log group or enter a new log group name. Optional.
        </ResponseField>
        <ResponseField name="system_log_level" type="string">
          Set this property to filter the system logs for your capacity provider that Lambda sends to CloudWatch. Lambda only sends system logs at the selected level of detail and lower, where ``DEBUG`` is the highest level and ``WARN`` is the lowest. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_config" type="object" required>
  VPC configuration that specifies the network settings for compute instances managed by the capacity provider. Required.
  <Expandable title="properties">
    <ResponseField name="security_group_ids" type="list(string)" required>
      A list of security group IDs that control network access for compute instances managed by the capacity provider. Required.
    </ResponseField>
    <ResponseField name="subnet_ids" type="list(string)" required>
      A list of subnet IDs where the capacity provider launches compute instances. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The current state of the capacity provider. Indicates whether the provider is being created, is active and ready for use, has failed, or is being deleted. Computed by AWS after `ship`.
</ResponseField>

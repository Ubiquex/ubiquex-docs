`aws_lambda_layer_version` publishes a real immutable version of a Lambda layer, a zip archive of libraries or other dependencies that one or more `aws_lambda_function`s can include without bundling that content into each function's own deployment package.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lambda "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lambda"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own layer version"})

    		ubx.Resource(lambda.LayerVersion, "example", lambda.LayerVersionConfig{
    			Content:                 map[string]any{"s3_bucket": "example"},
    			CompatibleArchitectures: []string{"example"},
    			CompatibleRuntimes:      []string{"example"},
    			Description:             "Managed by ubx.",
    			LayerName:               "example-layer-name",
    			LicenseInfo:             "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="compatible_architectures" type="list(string)">
  A list of compatible instruction set architectures. Optional.
</ResponseField>

<ResponseField name="compatible_runtimes" type="list(string)">
  A list of compatible function runtimes. Used for filtering with ListLayers and ListLayerVersions. Optional.
</ResponseField>

<ResponseField name="content" type="object" required>
  The `content` field specifies the Amazon S3 bucket, key, and optional object version that store the Lambda layer version's deployment package. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="s3_bucket" type="string" required>
      The Amazon S3 bucket of the layer archive. Required.
    </ResponseField>
    <ResponseField name="s3_key" type="string" required>
      The Amazon S3 key of the layer archive. Required.
    </ResponseField>
    <ResponseField name="s3_object_storage_mode" type="string">
      Specifies whether Lambda should copy the deployment package to its internal storage (COPY) or reference it directly from your S3 bucket (REFERENCE). Optional.
    </ResponseField>
    <ResponseField name="s3_object_version" type="string">
      For versioned objects, the version of the layer archive object to use. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the version. Optional.
</ResponseField>

<ResponseField name="layer_name" type="string">
  The name or Amazon Resource Name (ARN) of the layer. Optional.
</ResponseField>

<ResponseField name="license_info" type="string">
  The layer's software license. Optional.
</ResponseField>

## Output properties

<ResponseField name="layer_version_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Lambda layer version. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

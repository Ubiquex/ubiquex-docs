`aws_lambda_permission` grants a real resource-based permission on an `aws_lambda_function` or its alias, allowing a specific AWS service or account to invoke it, the mechanism behind, for example, API Gateway or S3 being allowed to call a function directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lambda "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lambda"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own permission"})

    		ubx.Resource(lambda.Permission, "example", lambda.PermissionConfig{
    			Action:                "example",
    			FunctionName:          "example-function-name",
    			Principal:             "example",
    			EventSourceToken:      "example",
    			FunctionUrlAuthType:   "example",
    			InvokedViaFunctionUrl: true,
    			PrincipalOrgId:        "example",
    			SourceAccount:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="action" type="string" required>
  The action that the principal can use on the function. For example, ``lambda:InvokeFunction`` or ``lambda:GetFunction``. Required.
</ResponseField>

<ResponseField name="event_source_token" type="string">
  For Alexa Smart Home functions, a token that the invoker must supply. Optional.
</ResponseField>

<ResponseField name="function_name" type="string" required>
  The name or ARN of the Lambda function, version, or alias. **Name formats** + *Function name*  --  ``my-function`` (name-only), ``my-function:v1`` (with alias). + *Function ARN*  --  ``arn:aws:lambda:us-west-2:123456789012:function:my-function``. + *Partial ARN*  --  ``123456789012:function:my-function``. You can append a version number or alias to any of the formats. The length constraint applies only to the full ARN. If you specify only the function name, it is limited to 64 characters in length. Required.
</ResponseField>

<ResponseField name="function_url_auth_type" type="string">
  The type of authentication that your function URL uses. Set to ``AWS_IAM`` if you want to restrict access to authenticated users only. Set to ``NONE`` if you want to bypass IAM authentication to create a public endpoint. For more information, see [Control access to Lambda function URLs](https://docs.aws.amazon.com/lambda/latest/dg/urls-auth.html). Optional.
</ResponseField>

<ResponseField name="invoked_via_function_url" type="bool">
  Indicates whether the permission applies when the function is invoked through a function URL. Optional.
</ResponseField>

<ResponseField name="principal" type="string" required>
  The AWS-service, AWS-account, IAM user, or IAM role that invokes the function. If you specify a service, use ``SourceArn`` or ``SourceAccount`` to limit who can invoke the function through that service. Required.
</ResponseField>

<ResponseField name="principal_org_id" type="string">
  The identifier for your organization in AOlong. Use this to grant permissions to all the AWS-accounts under this organization. Optional.
</ResponseField>

<ResponseField name="source_account" type="string">
  For AWS-service, the ID of the AWS-account that owns the resource. Use this together with ``SourceArn`` to ensure that the specified account owns the resource. It is possible for an Amazon S3 bucket to be deleted by its owner and recreated by another account. Optional.
</ResponseField>

<ResponseField name="source_arn" type="string">
  For AWS-services, the ARN of the AWS resource that invokes the function. For example, an Amazon S3 bucket or Amazon SNS topic. Note that Lambda configures the comparison using the ``StringLike`` operator. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier for the Lambda permission, typically a combination of the function name and the statement ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

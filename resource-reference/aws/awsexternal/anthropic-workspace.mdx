`aws_awsexternal_anthropic_workspace` creates a real workspace under Claude Platform on AWS, Anthropic's native Claude Platform experience accessed directly through an AWS account without separate Anthropic credentials, contracts, or billing. A workspace is the primary IAM resource for the platform, separating projects, environments, or teams under centralized AWS billing and administration. Claude Platform on AWS is a genuinely new service, launched in 2026, so behavior here is verified live rather than assumed from general knowledge.

## Input properties

<ResponseField name="data_residency" type="object">
  Data residency configuration for the workspace. WorkspaceGeo is immutable after creation. Optional.
  <Expandable title="properties">
    <ResponseField name="allowed_inference_geos" type="list(string)">
      Permitted inference geo values. Omit to allow all geos (the service default of 'unrestricted'); otherwise list specific geos. Optional.
    </ResponseField>
    <ResponseField name="default_inference_geo" type="string">
      Default inference geo applied when requests omit the parameter. Defaults to 'global' if omitted. Must be a member of AllowedInferenceGeos unless AllowedInferenceGeos is omitted. Optional.
    </ResponseField>
    <ResponseField name="workspace_geo" type="string">
      Geographic region for workspace data storage. Immutable after creation. Defaults to 'us' if omitted. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the workspace. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

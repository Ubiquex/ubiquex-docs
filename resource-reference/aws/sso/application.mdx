`aws_sso_application` registers a real, customer-managed application with an AWS IAM Identity Center instance, so it can participate in Identity Center's single sign-on alongside AWS's own built-in application integrations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sso "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sso"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own application"})

    		ubx.Resource(sso.Application, "ci-runner", sso.ApplicationConfig{
    			ApplicationProviderArn: "arn:aws:iam::123456789012:policy/ci",
    			InstanceArn:            "arn:aws:iam::123456789012:policy/ci",
    			Name:                   "ci-runner",
    			Description:            "Managed by ubx.",
    			PortalOptions:          map[string]any{"sign_in_options": map[string]any{"origin": "example"}},
    			Status:                 "example",
    			Tags:                   []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_provider_arn" type="string" required>
  The ARN of the application provider under which the operation will run Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description information for the Identity Center (SSO) Application Optional.
</ResponseField>

<ResponseField name="instance_arn" type="string" required>
  The ARN of the instance of IAM Identity Center under which the operation will run Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name you want to assign to this Identity Center (SSO) Application Required.
</ResponseField>

<ResponseField name="portal_options" type="object">
  A structure that describes the options for the access portal associated with an application Optional.
  <Expandable title="properties">
    <ResponseField name="sign_in_options" type="object">
      A structure that describes the sign-in options for an application portal Optional.
      <Expandable title="properties">
        <ResponseField name="application_url" type="string">
          The URL that accepts authentication requests for an application, this is a required parameter if the Origin parameter is APPLICATION Optional.
        </ResponseField>
        <ResponseField name="origin" type="string" required>
          This determines how IAM Identity Center navigates the user to the target application Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="visibility" type="string">
      Indicates whether this application is visible in the access portal Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  Specifies whether the application is enabled or disabled Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags to attach to the SSO application, which are key-value pairs that help you identify, organize, and manage the application in AWS IAM Identity Center. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to be attached to the AWS SSO application. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="application_arn" type="string">
  The Application ARN that is returned upon creation of the Identity Center (SSO) Application Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="identity_store_arn" type="string">
  The ARN of the identity store associated with the Identity Center instance Computed by AWS after `ship`.
</ResponseField>

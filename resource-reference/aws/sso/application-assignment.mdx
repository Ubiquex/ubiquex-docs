`aws_sso_application_assignment` grants a real user or group access to an `aws_sso_application`, the resource that actually authorizes that identity to sign in to the customer-managed application through IAM Identity Center.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sso "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sso"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own application assignment"})

    		ubx.Resource(sso.ApplicationAssignment, "ci-runner", sso.ApplicationAssignmentConfig{
    			ApplicationArn: "arn:aws:iam::123456789012:policy/ci",
    			PrincipalId:    "example",
    			PrincipalType:  "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="application_arn" type="string" required>
  The ARN of the application. Required.
</ResponseField>

<ResponseField name="principal_id" type="string" required>
  An identifier for an object in IAM Identity Center, such as a user or group Required.
</ResponseField>

<ResponseField name="principal_type" type="string" required>
  The entity type for which the assignment will be created. Required.
</ResponseField>

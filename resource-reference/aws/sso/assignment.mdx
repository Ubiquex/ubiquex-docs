`aws_sso_assignment` grants a real user or group an `aws_sso_permission_set` in a specific AWS account, the resource that actually provisions that assumable IAM role and authorizes the identity to use it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sso "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sso"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own assignment"})

    		ubx.Resource(sso.Assignment, "example", sso.AssignmentConfig{
    			InstanceArn:      "arn:aws:iam::123456789012:policy/example",
    			PermissionSetArn: "arn:aws:iam::123456789012:policy/example",
    			PrincipalId:      "example",
    			PrincipalType:    "example",
    			TargetId:         "example",
    			TargetType:       "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="instance_arn" type="string" required>
  The sso instance that the permission set is owned. Required.
</ResponseField>

<ResponseField name="permission_set_arn" type="string" required>
  The permission set that the assignment will be assigned Required.
</ResponseField>

<ResponseField name="principal_id" type="string" required>
  The assignee's identifier, user id/group id Required.
</ResponseField>

<ResponseField name="principal_type" type="string" required>
  The assignee's type, user/group Required.
</ResponseField>

<ResponseField name="target_id" type="string" required>
  The account id to be provisioned. Required.
</ResponseField>

<ResponseField name="target_type" type="string" required>
  The type of resource to be provisioned to, only aws account now Required.
</ResponseField>

`aws_lightsail_load_balancer` creates a real load balancer that distributes incoming traffic across multiple Lightsail instances, Lightsail's own simplified counterpart to an Elastic Load Balancing load balancer.

## Example

## Input properties

<ResponseField name="attached_instances" type="list(string)">
  The names of the instances attached to the load balancer. Optional.
</ResponseField>

<ResponseField name="health_check_path" type="string">
  The path you provided to perform the load balancer health check. If you didn't specify a health check path, Lightsail uses the root path of your website (e.g., "/"). Optional.
</ResponseField>

<ResponseField name="instance_port" type="number" required>
  The instance port where you're creating your load balancer. Required.
</ResponseField>

<ResponseField name="ip_address_type" type="string">
  The IP address type for the load balancer. The possible values are ipv4 for IPv4 only, and dualstack for IPv4 and IPv6. The default value is dualstack. Optional.
</ResponseField>

<ResponseField name="load_balancer_name" type="string" required>
  The name of your load balancer. Required.
</ResponseField>

<ResponseField name="session_stickiness_enabled" type="bool">
  Configuration option to enable session stickiness. Optional.
</ResponseField>

<ResponseField name="session_stickiness_lbcookie_duration_seconds" type="string">
  Configuration option to adjust session stickiness cookie duration parameter. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The unique key of a tag attached to the Lightsail load balancer, used to identify, organize, and manage the resource for purposes such as cost tracking, access control, and operational grouping. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag associated with the Lightsail load balancer, allowing you to attach arbitrary metadata to the resource for management and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tls_policy_name" type="string">
  The name of the TLS policy to apply to the load balancer. Optional.
</ResponseField>

## Output properties

<ResponseField name="load_balancer_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this Lightsail load balancer. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

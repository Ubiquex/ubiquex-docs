`aws_lightsail_disk` creates a real, SSD-based block storage volume that can be attached to a Lightsail instance for additional or persistent storage beyond the instance's own bundled disk.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own disk"})

    		ubx.Resource(lightsail.Disk, "example", lightsail.DiskConfig{
    			DiskName:         "example-disk-name",
    			SizeInGb:         1,
    			AddOns:           []map[string]any{{"add_on_type": "example"}},
    			AvailabilityZone: "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    import ubx_sdk as ubx
    from ubx.aws.lightsail import Disk, DiskConfig
    from ubx.aws.lightsail.disk import Disk_AddOns, Disk_Tags

    def describe():
        ubx.intent("example own disk")

        ubx.resource(Disk, "example", DiskConfig(
            disk_name="example-disk-name",
            size_in_gb=1,
            add_ons=[Disk_AddOns(add_on_type="example")],
            availability_zone="example",
            tags=[Disk_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="add_ons" type="list(object)">
  An array of objects representing the add-ons to enable for the new instance. Optional.
  <Expandable title="properties">
    <ResponseField name="add_on_type" type="string">
      Specifies the type of add-on to enable for the Lightsail disk, such as AutoSnapshot for automatic snapshots. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="auto_snapshot_add_on_request" type="object">
      Configures the automatic snapshot add-on for the Lightsail disk, including the daily time (in HH:00 format) at which the snapshot is created. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="snapshot_time_of_day" type="string">
          Specifies the time of day (in 24-hour HH:00 format, e.g., '02:00') when the automatic snapshot of the disk is created for the auto snapshot add-on. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="status" type="string">
      The status of the disk add-on, typically 'Enabled' or 'Disabled', indicating whether the add-on is active on the Lightsail disk. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="availability_zone" type="string">
  The Availability Zone in which to create your instance. Use the following format: us-east-2a (case sensitive). Be sure to add the include Availability Zones parameter to your request. Optional.
</ResponseField>

<ResponseField name="disk_name" type="string" required>
  The names to use for your new Lightsail disk. Required.
</ResponseField>

<ResponseField name="size_in_gb" type="number" required>
  Size of the Lightsail disk Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the Lightsail disk, used to organize and identify the disk resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the tag value in a key-value pair that you attach to the Lightsail disk for metadata and resource management purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_lightsail_disk_snapshot` creates a real point-in-time snapshot of an `aws_lightsail_disk`, which can later be used to create a new disk with the same data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own disk snapshot"})

    		ubx.Resource(lightsail.DiskSnapshot, "example", lightsail.DiskSnapshotConfig{
    			DiskName:         "example-disk-name",
    			DiskSnapshotName: "example-disk-snapshot-name",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="disk_name" type="string" required>
  The name of the source disk from which the snapshot was created. Required.
</ResponseField>

<ResponseField name="disk_snapshot_name" type="string" required>
  The name of the disk snapshot (e.g., my-disk-snapshot). Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag, such as 'Name' or 'Environment', that you can attach to the Lightsail disk snapshot for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag (key-value pair) applied to the AWS Lightsail disk snapshot. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

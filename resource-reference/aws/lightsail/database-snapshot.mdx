`aws_lightsail_database_snapshot` creates a real point-in-time snapshot of an `aws_lightsail_database`, which can later be restored into a new database instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own database snapshot"})

    		ubx.Resource(lightsail.DatabaseSnapshot, "ci-runner", lightsail.DatabaseSnapshotConfig{
    			RelationalDatabaseName:         "example-relational-database-name",
    			RelationalDatabaseSnapshotName: "example-relational-database-snapshot-name",
    			Tags:                           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="relational_database_name" type="string" required>
  The name of the database on which to base your new snapshot. Required.
</ResponseField>

<ResponseField name="relational_database_snapshot_name" type="string" required>
  The name for your new database snapshot. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the Lightsail database snapshot. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Lightsail database snapshot, used to categorize or identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the database snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when the database snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="engine" type="string">
  The software of the database snapshot (for example, MySQL). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The database engine version for the database snapshot (for example, 5.7.23). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="from_relational_database_arn" type="string">
  The Amazon Resource Name (ARN) of the database from which the database snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="from_relational_database_blueprint_id" type="string">
  The blueprint ID of the database from which the database snapshot was created. A blueprint describes the major engine version of a database. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="from_relational_database_bundle_id" type="string">
  The bundle ID of the database from which the database snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="from_relational_database_name" type="string">
  The name of the source database from which the database snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location" type="object">
  The Region name and Availability Zone where the database snapshot is located. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="availability_zone" type="string">
      The Availability Zone where the database snapshot was created. Optional.
    </ResponseField>
    <ResponseField name="region_name" type="string">
      The AWS Region where the database snapshot was created. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the database snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The Lightsail resource type. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="size_in_gb" type="number">
  The size of the disk in GB (for example, 32) for the database snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the database snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="support_code" type="string">
  The support code for the database snapshot. Include this code in your email to support when you have questions about a database snapshot in Lightsail. This code enables our support team to look up your Lightsail information more easily. Computed by AWS after `ship`.
</ResponseField>

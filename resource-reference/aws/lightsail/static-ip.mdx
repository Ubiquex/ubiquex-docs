`aws_lightsail_static_ip` allocates a real static public IP address that can be attached to a Lightsail instance, keeping the instance reachable at a fixed address across stops, starts, and replacements.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own static ip"})

    		ubx.Resource(lightsail.StaticIp, "ci-runner", lightsail.StaticIpConfig{
    			StaticIpName: "example-static-ip-name",
    			AttachedTo:   "example",
    		})
    	}))
    }
    ```
  </Tab>

    from ubx.aws.lightsail import StaticIp, StaticIpConfig

    def describe():

        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)

## Input properties

<ResponseField name="attached_to" type="string">
  The instance where the static IP is attached. Optional.
</ResponseField>

<ResponseField name="static_ip_name" type="string" required>
  The name of the static IP address. Required.
</ResponseField>

## Output properties

<ResponseField name="ip_address" type="string">
  The static IP address. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="is_attached" type="bool">
  A Boolean value indicating whether the static IP is attached. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="static_ip_arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying the Lightsail static IP within AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

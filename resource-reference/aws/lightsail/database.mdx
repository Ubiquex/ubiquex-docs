`aws_lightsail_database` creates a real managed relational database, MySQL or PostgreSQL, at Lightsail's simplified, flat-rate pricing tier, optionally with a High Availability option that runs a standby copy in a second Availability Zone.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			RelationalDatabaseBundleId:    "example",
    			RelationalDatabaseName:        "example-relational-database-name",
    			AvailabilityZone:              "example",
    			BackupRetention:               true,
    			CaCertificateIdentifier:       "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="availability_zone" type="string">
  The Availability Zone in which to create your new database. Use the us-east-2a case-sensitive format. Optional.
</ResponseField>

<ResponseField name="backup_retention" type="bool">
  When true, enables automated backup retention for your database. Updates are applied during the next maintenance window because this can result in an outage. Optional.
</ResponseField>

<ResponseField name="ca_certificate_identifier" type="string">
  Indicates the certificate that needs to be associated with the database. Optional.
</ResponseField>

<ResponseField name="master_database_name" type="string" required>
  The name of the database to create when the Lightsail database resource is created. For MySQL, if this parameter isn't specified, no database is created in the database resource. For PostgreSQL, if this parameter isn't specified, a database named postgres is created in the database resource. Required.
</ResponseField>

<ResponseField name="master_user_password" type="string">
  The password for the master user. The password can include any printable ASCII character except "/", """, or "@". It cannot contain spaces. Optional.
</ResponseField>

<ResponseField name="master_username" type="string" required>
  The name for the master user. Required.
</ResponseField>

<ResponseField name="preferred_backup_window" type="string">
  The daily time range during which automated backups are created for your new database if automated backups are enabled. Optional.
</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">
  The weekly time range during which system maintenance can occur on your new database. Optional.
</ResponseField>

<ResponseField name="publicly_accessible" type="bool">
  Specifies the accessibility options for your new database. A value of true specifies a database that is available to resources outside of your Lightsail account. A value of false specifies a database that is available only to your Lightsail resources in the same region as your database. Optional.
</ResponseField>

<ResponseField name="relational_database_blueprint_id" type="string" required>
  The blueprint ID for your new database. A blueprint describes the major engine version of a database. Required.
</ResponseField>

<ResponseField name="relational_database_bundle_id" type="string" required>
  The bundle ID for your new database. A bundle describes the performance specifications for your database. Required.
</ResponseField>

<ResponseField name="relational_database_name" type="string" required>
  The name to use for your new Lightsail database resource. Required.
</ResponseField>

<ResponseField name="relational_database_parameters" type="list(object)">
  Update one or more parameters of the relational database. Optional.

  When true, the master user password is changed to a new strong password generated by Lightsail. Use the get relational database master user password operation to get the new password. Optional.
</ResponseField>

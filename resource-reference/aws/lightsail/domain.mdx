`aws_lightsail_domain` creates a real DNS zone within Lightsail for a registered domain, letting its DNS records be managed alongside other Lightsail resources rather than in Route 53 directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain"})

    		ubx.Resource(lightsail.Domain, "example", lightsail.DomainConfig{
    			DomainName: "example-domain-name",
    			Tags:       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only aws --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {
      intent({ summary: "example own domain" });

      resource(Domain, "example", {
        domainName: "example-domain-name",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.lightsail import Domain, DomainConfig

    def describe():
        ubx.intent("example own domain")

        ubx.resource(Domain, "example", DomainConfig(
            domain_name="example-domain-name",
            tags=[{"key": "example"}],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="domain_name" type="string" required>
  The name of the domain to manage in Lightsail. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that can be assigned to a Lightsail domain, enabling you to categorize, manage, and control access to the domain. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the domain (read-only). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when the domain was created (read-only). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="domain_entries" type="list(object)">
  An array of key-value pairs containing information about the domain entries. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="is_alias" type="bool">
      Indicates whether the domain entry is an alias record that routes traffic to an AWS resource such as a load balancer or distribution, rather than a standard DNS record with a literal target. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The subdomain or hostname for the DNS record, such as 'www' or '@' for the root domain, that this domain entry defines. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="target" type="string">
      The destination value that this Lightsail domain DNS record resolves to, such as an IPv4 address for an A record or a hostname for a CNAME record. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      The DNS record type for this domain entry, such as A, CNAME, MX, or TXT. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

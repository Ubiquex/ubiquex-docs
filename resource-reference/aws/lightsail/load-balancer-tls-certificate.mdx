`aws_lightsail_load_balancer_tls_certificate` provisions a real TLS certificate attached to an `aws_lightsail_load_balancer`, so traffic reaching the load balancer over HTTPS terminates against a validated certificate.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own load balancer tls certificate"})

    		ubx.Resource(lightsail.LoadBalancerTlsCertificate, "example", lightsail.LoadBalancerTlsCertificateConfig{
    			CertificateDomainName:       "example-certificate-domain-name",
    			CertificateName:             "example-certificate-name",
    			LoadBalancerName:            "example-load-balancer-name",
    			CertificateAlternativeNames: []string{"example"},
    			HttpsRedirectionEnabled:     true,
    			IsAttached:                  true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate_alternative_names" type="list(string)">
  An array of strings listing alternative domains and subdomains for your SSL/TLS certificate. Optional.
</ResponseField>

<ResponseField name="certificate_domain_name" type="string" required>
  The domain name (e.g., example.com ) for your SSL/TLS certificate. Required.
</ResponseField>

<ResponseField name="certificate_name" type="string" required>
  The SSL/TLS certificate name. Required.
</ResponseField>

<ResponseField name="https_redirection_enabled" type="bool">
  A Boolean value that indicates whether HTTPS redirection is enabled for the load balancer. Optional.
</ResponseField>

<ResponseField name="is_attached" type="bool">
  When true, the SSL/TLS certificate is attached to the Lightsail load balancer. Optional.
</ResponseField>

<ResponseField name="load_balancer_name" type="string" required>
  The name of your load balancer. Required.
</ResponseField>

## Output properties

<ResponseField name="load_balancer_tls_certificate_arn" type="string">
  The Amazon Resource Name (ARN) of the Lightsail load balancer TLS certificate, assigned by AWS when the certificate is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The validation status of the SSL/TLS certificate. Computed by AWS after `ship`.
</ResponseField>

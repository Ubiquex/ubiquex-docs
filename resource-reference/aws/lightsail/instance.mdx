`aws_lightsail_instance` creates a real virtual private server, a bundled combination of compute, storage, and a fixed data transfer allowance, at Lightsail's simplified, predictable monthly pricing.

## Example

  <Tab title="Go">
    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own instance"})

    			BlueprintId:      "example",
    			BundleId:         "example",
    			InstanceName:     "example-instance-name",
    			AddOns:           []map[string]any{{"add_on_type": "example"}},
    			AvailabilityZone: "example",
    			KeyPairName:      "example-key-pair-name",
    			Tags:             []map[string]any{{"key": "example"}},
    			UserData:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="add_ons" type="list(object)">
  An array of objects representing the add-ons to enable for the new instance. Optional.
  <Expandable title="properties">
    <ResponseField name="add_on_type" type="string">
      Specifies the type of add-on to attach to the Lightsail instance, with the only supported value being `AutoSnapshot` to enable automatic daily snapshots of the instance. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="auto_snapshot_add_on_request" type="object">
      Configures the automatic snapshot add-on for the Lightsail instance, specifying the daily time of day for the snapshot to be created. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="snapshot_time_of_day" type="string">
          Specifies the time of day (in 24-hour HH:00 format) at which the automatic snapshot is taken for the Lightsail instance when the Auto Snapshot add-on is enabled. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="status" type="string">
      Indicates whether the add-on is enabled or disabled, with values such as 'Enabled' or 'Disabled' for a Lightsail instance add-on. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="availability_zone" type="string">
  The Availability Zone in which to create your instance. Use the following format: us-east-2a (case sensitive). Be sure to add the include Availability Zones parameter to your request. Optional.
</ResponseField>

<ResponseField name="blueprint_id" type="string" required>
  The ID for a virtual private server image (e.g., app_wordpress_4_4 or app_lamp_7_0 ). Use the get blueprints operation to return a list of available images (or blueprints ). Required.
</ResponseField>

<ResponseField name="bundle_id" type="string" required>
  The bundle of specification information for your virtual private server (or instance ), including the pricing plan (e.g., micro_1_0 ). Required.
</ResponseField>

<ResponseField name="instance_name" type="string" required>
  The names to use for your new Lightsail instance. Required.
</ResponseField>

<ResponseField name="key_pair_name" type="string">
  The name of your key pair. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of the tag to associate with the Lightsail instance. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The user-defined value paired with a tag key on the Lightsail instance, used for identifying and organizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_data" type="string">
  A launch script you can create that configures a server with additional user data. For example, you might want to run apt-get -y update. Optional.
</ResponseField>

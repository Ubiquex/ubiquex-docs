`aws_lightsail_certificate` provisions a real SSL/TLS certificate for use with Lightsail resources, such as a content delivery distribution, validated and issued the way an ACM certificate is but managed within Lightsail's own simplified surface.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own certificate"})

    		ubx.Resource(lightsail.Certificate, "ci-runner", lightsail.CertificateConfig{
    			CertificateName:         "example-certificate-name",
    			DomainName:              "example-domain-name",
    			SubjectAlternativeNames: []string{"example"},
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate_name" type="string" required>
  The name for the certificate. Required.
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The domain name (e.g., example.com ) for the certificate. Required.
</ResponseField>

<ResponseField name="subject_alternative_names" type="list(string)">
  An array of strings that specify the alternate domains (e.g., example2.com) and subdomains (e.g., blog.example.com) for the certificate. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Lightsail certificate, used to categorize and identify the certificate in the Lightsail console and API. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag assigned to the AWS Lightsail certificate, used to label, organize, and support cost allocation for the certificate. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="certificate_arn" type="string">
  The Amazon Resource Name (ARN) of the Lightsail certificate, assigned by AWS when the certificate is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The validation status of the certificate. Computed by AWS after `ship`.
</ResponseField>

`aws_lightsail_instance_snapshot` creates a real point-in-time snapshot of an `aws_lightsail_instance`, including its attached disks, which can later be used to launch a new instance with the same state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own instance snapshot"})

    		ubx.Resource(lightsail.InstanceSnapshot, "example", lightsail.InstanceSnapshotConfig{
    			InstanceName:         "example-instance-name",
    			InstanceSnapshotName: "example-instance-snapshot-name",
    			Tags:                 []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="instance_name" type="string" required>
  The instance from which the snapshot was created. Required.
</ResponseField>

<ResponseField name="instance_snapshot_name" type="string" required>
  The name of the snapshot. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag applied to the AWS Lightsail instance snapshot, used for organizing and identifying the snapshot. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="from_instance_arn" type="string">
  The Amazon Resource Name (ARN) of the instance from which the snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="from_instance_name" type="string">
  The instance from which the snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="is_from_auto_snapshot" type="bool">
  A Boolean value indicating whether the snapshot was created from an automatic snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location" type="object">

      The AWS Region name. Optional.

  </Expandable>
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of resource (usually InstanceSnapshot). Computed by AWS after `ship`.

<ResponseField name="state" type="string">

`aws_lightsail_alarm` creates a real CloudWatch-backed alarm scoped to a single Lightsail resource, an instance, database, distribution, or load balancer, notifying when one of that resource's own metrics crosses a threshold.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own alarm"})

    		ubx.Resource(lightsail.Alarm, "example", lightsail.AlarmConfig{
    			AlarmName:             "example-alarm-name",
    			ComparisonOperator:    "example",
    			EvaluationPeriods:     1,
    			MetricName:            "example-metric-name",
    			MonitoredResourceName: "example-monitored-resource-name",
    			Threshold:             1,
    			ContactProtocols:      []string{"example"},
    			DatapointsToAlarm:     1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="alarm_name" type="string" required>
  The name for the alarm. Specify the name of an existing alarm to update, and overwrite the previous configuration of the alarm. Required.
</ResponseField>

<ResponseField name="comparison_operator" type="string" required>
  The arithmetic operation to use when comparing the specified statistic to the threshold. The specified statistic value is used as the first operand. Required.
</ResponseField>

<ResponseField name="contact_protocols" type="list(string)">
  The contact protocols to use for the alarm, such as Email, SMS (text messaging), or both. Optional.
</ResponseField>

<ResponseField name="datapoints_to_alarm" type="number">
  The number of data points that must be not within the specified threshold to trigger the alarm. If you are setting an "M out of N" alarm, this value (datapointsToAlarm) is the M. Optional.
</ResponseField>

<ResponseField name="evaluation_periods" type="number" required>
  The number of most recent periods over which data is compared to the specified threshold. If you are setting an "M out of N" alarm, this value (evaluationPeriods) is the N. Required.
</ResponseField>

<ResponseField name="metric_name" type="string" required>
  The name of the metric to associate with the alarm. Required.
</ResponseField>

<ResponseField name="monitored_resource_name" type="string" required>
  The name of the Lightsail resource that the alarm monitors. Required.
</ResponseField>

<ResponseField name="notification_enabled" type="bool">
  Indicates whether the alarm is enabled. Notifications are enabled by default if you don't specify this parameter. Optional.
</ResponseField>

<ResponseField name="notification_triggers" type="list(string)">
  The alarm states that trigger a notification. Optional.
</ResponseField>

<ResponseField name="threshold" type="number" required>
  The value against which the specified statistic is compared. Required.
</ResponseField>

<ResponseField name="treat_missing_data" type="string">
  Sets how this alarm will handle missing data points. Optional.
</ResponseField>

## Output properties

<ResponseField name="alarm_arn" type="string">
  The Amazon Resource Name (ARN) of the Lightsail alarm, uniquely identifying it in AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="state" type="string">
  The current state of the alarm. Computed by AWS after `ship`.
</ResponseField>

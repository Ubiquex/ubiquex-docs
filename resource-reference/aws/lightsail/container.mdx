`aws_lightsail_container` creates a real Lightsail Container Service, a managed environment that deploys and runs containerized applications, images pushed via Docker, without the operational surface of a full ECS or EKS cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own container"})

    		ubx.Resource(lightsail.Container, "example", lightsail.ContainerConfig{
    			Power:                      "example",
    			Scale:                      1,
    			ServiceName:                "example-service-name",
    			ContainerServiceDeployment: map[string]any{"containers": []map[string]any{{"command": []string{"example"}}}},
    			IsDisabled:                 true,
    			PublicDomainNames:          []map[string]any{{"certificate_name": "example-certificate-name"}},
    			Tags:                       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="container_service_deployment" type="object">
  Describes a container deployment configuration of an Amazon Lightsail container service. Optional.
  <Expandable title="properties">
    <ResponseField name="containers" type="list(object)">
      An object that describes the configuration for the containers of the deployment. Optional.
      <Expandable title="properties">
        <ResponseField name="command" type="list(string)">
          Specifies the command to run inside the container, overriding the default entrypoint or command from the container image, as an array of strings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="container_name" type="string">
          The unique name of the container within the Lightsail container service deployment, used to identify the container in the deployment configuration and when routing traffic from the service's public endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="environment" type="list(object)">
          Defines the environment variables (as key-value pairs) to pass into the container within a Lightsail container service deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="value" type="string">
              Sets the value for an environment variable key in the container, which is passed to the container at runtime in the Lightsail container service deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="variable" type="string">
              The name of an environment variable for the container, paired with its value in the container's environment map. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="image" type="string">
          Specifies the container image (e.g., a Docker Hub image or Amazon ECR repository URI) to use for this container in the Lightsail container service deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="ports" type="list(object)">
          Defines the ports on which the container listens, including the port number and the protocol (HTTP, HTTPS, TCP, or UDP) that the container service routes requests to for each exposed port. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="port" type="string">
              The port number that the container listens on, used by the Lightsail container service to expose the container's application to incoming traffic. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="protocol" type="string">
              The protocol assigned to a container's open port, such as HTTP, HTTPS, TCP, or UDP, defining how traffic reaches the container within an AWS Lightsail container service deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="public_endpoint" type="object">
      Describes the settings of a public endpoint for an Amazon Lightsail container service. Optional.
      <Expandable title="properties">
        <ResponseField name="container_name" type="string">
          The name of the container for the endpoint. Optional.
        </ResponseField>
        <ResponseField name="container_port" type="number">
          The port of the container to which traffic is forwarded to. Optional.
        </ResponseField>
        <ResponseField name="health_check_config" type="object">
          Describes the health check configuration of an Amazon Lightsail container service. Optional.
          <Expandable title="properties">
            <ResponseField name="healthy_threshold" type="number">
              The number of consecutive health checks successes required before moving the container to the Healthy state. The default value is 2. Optional.
            </ResponseField>
            <ResponseField name="interval_seconds" type="number">
              The approximate interval, in seconds, between health checks of an individual container. You can specify between 5 and 300 seconds. The default value is 5. Optional.
            </ResponseField>
            <ResponseField name="path" type="string">
              The path on the container on which to perform the health check. The default value is /. Optional.
            </ResponseField>
            <ResponseField name="success_codes" type="string">
              The HTTP codes to use when checking for a successful response from a container. You can specify values between 200 and 499. You can specify multiple values (for example, 200,202) or a range of values (for example, 200-299). Optional.
            </ResponseField>
            <ResponseField name="timeout_seconds" type="number">
              The amount of time, in seconds, during which no response means a failed health check. You can specify between 2 and 60 seconds. The default value is 2. Optional.
            </ResponseField>
            <ResponseField name="unhealthy_threshold" type="number">
              The number of consecutive health check failures required before moving the container to the Unhealthy state. The default value is 2. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

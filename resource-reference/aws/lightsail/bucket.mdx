`aws_lightsail_bucket` creates a real Lightsail object storage bucket, built on S3, for storing files at Lightsail's simplified, predictable-pricing tier rather than through the full S3 console.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own bucket"})

    		ubx.Resource(lightsail.Bucket, "example", lightsail.BucketConfig{
    			BucketName:               "example-bucket-name",
    			BundleId:                 "example",
    			AccessRules:              map[string]any{"allow_public_overrides": true},
    			ObjectVersioning:         true,
    			ReadOnlyAccessAccounts:   []string{"example"},
    			ResourcesReceivingAccess: []string{"example"},
    			Tags:                     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="access_rules" type="object">
  An object that sets the public accessibility of objects in the specified bucket. Optional.
  <Expandable title="properties">
    <ResponseField name="allow_public_overrides" type="bool">
      A Boolean value that indicates whether the access control list (ACL) permissions that are applied to individual objects override the getObject option that is currently specified. Optional.
    </ResponseField>
    <ResponseField name="get_object" type="string">
      Specifies the anonymous access to all objects in a bucket. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="bucket_name" type="string" required>
  The name for the bucket. Required.
</ResponseField>

<ResponseField name="bundle_id" type="string" required>
  The ID of the bundle to use for the bucket. Required.
</ResponseField>

<ResponseField name="object_versioning" type="bool">
  Specifies whether to enable or disable versioning of objects in the bucket. Optional.
</ResponseField>

<ResponseField name="read_only_access_accounts" type="list(string)">
  An array of strings to specify the AWS account IDs that can access the bucket. Optional.
</ResponseField>

<ResponseField name="resources_receiving_access" type="list(string)">
  The names of the Lightsail resources for which to set bucket access. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to assign to the Lightsail bucket. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Lightsail bucket, used for metadata, identification, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="able_to_update_bundle" type="bool">
  Indicates whether the bundle that is currently applied to a bucket can be changed to another bundle. You can update a bucket's bundle only one time within a monthly AWS billing cycle. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="bucket_arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying the Lightsail bucket, such as arn:aws:lightsail:region:account-id:bucket/bucket-name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="url" type="string">
  The URL of the bucket. Computed by AWS after `ship`.
</ResponseField>

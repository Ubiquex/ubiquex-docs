`aws_application_insights_application` registers an application with CloudWatch Application Insights, which scans its component stack (databases, web and application servers, load balancers, queues) to recommend and set up key metrics, logs, and alarms, then correlates anomalies and errors into automated dashboards pointing at a likely root cause.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			GroupingType:                "example",
    			LogPatternSets:              []map[string]any{{"log_patterns": []map[string]any{{"pattern": "example"}}}},

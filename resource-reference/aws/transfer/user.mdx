`aws_transfer_user` creates a real user identity on an `aws_transfer_server`, its home directory, IAM role, and authentication method, SSH key or password, that a client actually logs in as.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	"encoding/json"

    	transfer "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/transfer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user"})

    		accessPolicy, _ := json.Marshal(map[string]any{
    			"Version": "2012-10-17",
    			"Statement": []map[string]any{{
    				"Effect":   "Allow",
    				"Action":   "*",
    				"Resource": "*",
    			}},
    		})

    		ubx.Resource(transfer.User, "example", transfer.UserConfig{
    			Role:                  "example",
    			ServerId:              "example",
    			UserName:              "example-user-name",
    			HomeDirectory:         "example",
    			HomeDirectoryMappings: []map[string]any{{"entry": "example"}},
    			HomeDirectoryType:     "example",
    			Policy:                string(accessPolicy),
    			PosixProfile:          map[string]any{"gid": 1, "uid": 1},
    		})
    	}))
    }
    ```

    ```python
    import json
    import ubx_sdk as ubx
    from ubx.aws.transfer import User, UserConfig
    from ubx.aws.transfer.user import User_HomeDirectoryMappings, User_PosixProfile

    def describe():
        ubx.intent("example own user")

        access_policy = json.dumps({
            "Version": "2012-10-17",
            "Statement": [{
                "Effect": "Allow",
                "Action": "*",
                "Resource": "*",
            }],
        })

        ubx.resource(User, "example", UserConfig(
            role="example",
            server_id="example",
            user_name="example-user-name",
            home_directory="example",
            home_directory_mappings=[User_HomeDirectoryMappings(entry="example")],
            home_directory_type="example",
            policy=access_policy,
            posix_profile=User_PosixProfile(gid=1, uid=1),
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="home_directory" type="string">
  The landing directory (folder) for the user when they log in to the Transfer Family server, specified as an absolute path or a virtual path that can include the &#123;Transfer:UserName&#125; variable. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="home_directory_mappings" type="list(object)">
  Specifies a set of logical directory mappings that translate a user's home directory path to a target S3 or EFS location, allowing different storage paths to be presented as a single virtual path. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="entry" type="string">
      For each home directory mapping of an AWS Transfer Family user, this field specifies the logical directory path that the user will see, which is paired with a target path to define the mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="target" type="string">
      Specifies the destination absolute or relative path in the Amazon S3 bucket or Amazon EFS file system to which the 'Entry' logical directory is mapped for this AWS Transfer Family user. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies whether the home directory mapping entry maps to a file ('FILE') or a directory ('DIRECTORY') in AWS Transfer Family. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="home_directory_type" type="string">
  Determines whether the user's home directory is defined as a logical directory (LOGICAL) or a direct file system path (PATH), with PATH being the default when this property is not specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="policy" type="string">
  A JSON string specifying an IAM scope-down policy that restricts the permissions of the AWS Transfer Family user, allowing multiple users to share the same IAM role with different access levels. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="posix_profile" type="object">
  Specifies the POSIX user profile, including the UID, GID, and secondary group IDs, used by the AWS Transfer Family user for file system permissions and ownership when operating over SFTP, FTPS, or FTP. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="gid" type="number" required>
      Specifies the POSIX group ID (GID) that maps to the user's group on the file transfer server's backing storage, determining file ownership and access permissions for the associated AWS Transfer Family user. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="secondary_gids" type="list(number)">
      Specifies the secondary group IDs (GIDs) for the user's POSIX profile, granting additional group memberships that affect file and folder access on the AWS Transfer server. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="uid" type="number" required>
      Defines the numeric POSIX user ID (UID) that AWS Transfer Family uses to set file ownership and permission checks for this user on the underlying file system (e.g., Amazon EFS). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role" type="string" required>
  The IAM role that AWS Transfer Family assumes to define the user's permissions for accessing the underlying storage (e.g., Amazon S3) and other resources. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_id" type="string" required>
  The unique identifier of the AWS Transfer Family server to which this user is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="ssh_public_keys" type="list(string)">
  This represents the SSH User Public Keys for CloudFormation resource Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Assigns customizable metadata tags to the AWS Transfer Family user, enabling categorization, cost allocation, and access-control scoping across AWS resources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to an AWS Transfer Family user, used for identifying, organizing, and managing the user resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair applied to the AWS Transfer Family user, used for resource organization and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_name" type="string" required>
  Sets the unique login name for the user in the AWS Transfer Family service, which must be unique within the associated server and is used to identify and authenticate the user during file transfer sessions. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying the AWS Transfer Family user, assigned by AWS when the user is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

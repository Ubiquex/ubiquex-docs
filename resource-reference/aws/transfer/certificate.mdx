`aws_transfer_certificate` imports a real X.509 certificate into AWS Transfer Family, used to sign or encrypt AS2 messages, or to authenticate a client, for an `aws_transfer_agreement` or `aws_transfer_connector`.

## Example

    ```go
    import (
    	transfer "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/transfer"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate"})

    		ubx.Resource(transfer.Certificate, "example", transfer.CertificateConfig{
    			Certificate:      "example",
    			Usage:            "example",
    			ActiveDate:       "example",
    			CertificateChain: "example",
    			Description:      "Managed by ubx.",
    			InactiveDate:     "example",
    			PrivateKey:       "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="active_date" type="string">
  Specifies the active date for the certificate. Optional.
</ResponseField>

<ResponseField name="certificate" type="string" required>
  Specifies the certificate body to be imported. Required.
</ResponseField>

<ResponseField name="certificate_chain" type="string">
  Specifies the certificate chain to be imported. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A textual description for the certificate. Optional.
</ResponseField>

<ResponseField name="inactive_date" type="string">
  Specifies the inactive date for the certificate. Optional.
</ResponseField>

<ResponseField name="private_key" type="string">
  Specifies the private key for the certificate. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Key-value pairs that can be used to group and search for certificates. Tags are metadata attached to certificates for any purpose. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag attached to the AWS Transfer Family certificate, used for identifying and categorizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="usage" type="string" required>
  Specifies the usage type for the certificate. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Specifies the unique Amazon Resource Name (ARN) for the agreement. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="certificate_id" type="string">
  A unique identifier for the certificate. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="not_after_date" type="string">
  Specifies the not after date for the certificate. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="not_before_date" type="string">
  Specifies the not before date for the certificate. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="serial" type="string">
  Specifies Certificate's serial. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  A status description for the certificate. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type" type="string">
  Describing the type of certificate. With or without a private key. Computed by AWS after `ship`.
</ResponseField>

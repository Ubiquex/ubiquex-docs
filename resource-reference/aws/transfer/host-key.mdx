`aws_transfer_host_key` imports a real SSH host key into an `aws_transfer_server`, letting an organization present its own, previously trusted host key fingerprint to clients instead of the one Transfer Family generates by default.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	transfer "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/transfer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own host key"})

    		ubx.Resource(transfer.HostKey, "example", transfer.HostKeyConfig{
    			ServerId:    "example",
    			Description: "Managed by ubx.",
    			HostKeyBody: "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

    def describe():

            server_id="example",
            description="Managed by ubx.",
            host_key_body="example",
            tags=[{"key": "example"}],
        ))

## Input properties

<ResponseField name="description" type="string">
  The text description for this host key. Optional.
</ResponseField>

<ResponseField name="host_key_body" type="string">
  The private key portion of an SSH key pair. Transfer Family accepts RSA, ECDSA, and ED25519 keys. Optional.
</ResponseField>

<ResponseField name="server_id" type="string" required>
  The identifier of the server that contains the host key. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Key-value pairs that can be used to group and search for host keys. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The unique Amazon Resource Name (ARN) for the host key. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="date_imported" type="string">
  The date on which the host key was added to the server. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="host_key_fingerprint" type="string">
  The public key fingerprint, which is a short sequence of bytes used to identify the longer public key. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="host_key_id" type="string">
  A unique identifier for the host key. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type" type="string">
  The encryption algorithm that is used for the host key. Computed by AWS after `ship`.
</ResponseField>

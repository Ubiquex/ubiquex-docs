`aws_transfer_web_app` creates a real, hosted browser-based interface for transferring files to and from S3, backed by its own identity provider, IAM Identity Center or a directory, letting workforce users upload and download files through a web UI rather than an SFTP client talking to an `aws_transfer_server`.

## Input properties

<ResponseField name="access_endpoint" type="string">
  The AccessEndpoint is the URL that you provide to your users for them to interact with the Transfer Family web app. You can specify a custom URL or use the default value. Optional.
</ResponseField>

<ResponseField name="endpoint_details" type="object">

          The IP address type for the VPC endpoint used by the web app. Optional.
        </ResponseField>

          List of security group IDs applied to the VPC endpoint for the web app, controlling inbound and outbound traffic to the endpoint. Optional. **(AI-inferred)**

## Output properties

<ResponseField name="arn" type="string">
  Specifies the unique Amazon Resource Name (ARN) for the web app. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="identity_provider_details" type="object">
  You can provide a structure that contains the details for the identity provider to use with your web app. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="application_arn" type="string">
      The ARN of the AWS Directory Service directory that serves as the identity provider for user authentication for this AWS Transfer Family web app. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="instance_arn" type="string">
      The Amazon Resource Name (ARN) for the IAM Identity Center used for the web app. Optional.
    </ResponseField>
    <ResponseField name="role" type="string">
      The IAM role in IAM Identity Center used for the web app. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_endpoint_id" type="string">
  The unique identifier of the VPC endpoint that the web app is associated with, used when the web app is deployed within a VPC. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="web_app_id" type="string">
  A unique identifier for the web app. Computed by AWS after `ship`.
</ResponseField>

`aws_transfer_profile` defines a real AS2 identity, local or partner, its AS2 ID and `aws_transfer_certificate`s, that an `aws_transfer_agreement` references for both sides of an AS2 exchange.

## Input properties

<ResponseField name="as2_id" type="string" required>
  AS2 identifier agreed with a trading partner. Required.
</ResponseField>

<ResponseField name="certificate_ids" type="list(string)">
  List of the certificate IDs associated with this profile to be used for encryption and signing of AS2 messages. Optional.
</ResponseField>

<ResponseField name="profile_type" type="string" required>
  Enum specifying whether the profile is local or associated with a trading partner. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined string that serves as the key in a tag attached to an AWS Transfer Family profile, enabling resource categorization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value part of a tag attached to this AWS Transfer Family profile, allowing you to categorize and manage the profile with custom metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Specifies the unique Amazon Resource Name (ARN) for the profile. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="profile_id" type="string">
  A unique identifier for the profile Computed by AWS after `ship`.
</ResponseField>

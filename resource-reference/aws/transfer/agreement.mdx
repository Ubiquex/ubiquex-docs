`aws_transfer_agreement` defines a real AS2 trading-partner agreement on an `aws_transfer_server`, referencing a local and partner `aws_transfer_profile`, that governs how AS2 messages are exchanged, signed, and acknowledged between the two parties.

## Input properties

<ResponseField name="access_role" type="string" required>
  Specifies the access role for the agreement. Required.
</ResponseField>

<ResponseField name="base_directory" type="string">
  Specifies the base directory for the agreement. Optional.
</ResponseField>

<ResponseField name="custom_directories" type="object">
  Specifies a separate directory for each type of file to store for an AS2 message. Optional.
  <Expandable title="properties">
    <ResponseField name="failed_files_directory" type="string" required>
      Specifies a location to store the failed files for an AS2 message. Required.
    </ResponseField>
    <ResponseField name="mdn_files_directory" type="string" required>
      Specifies a location to store the MDN file for an AS2 message. Required.
    </ResponseField>
    <ResponseField name="payload_files_directory" type="string" required>
      Specifies a location to store the payload file for an AS2 message. Required.
    </ResponseField>
    <ResponseField name="status_files_directory" type="string" required>
      Specifies a location to store the status file for an AS2 message. Required.
    </ResponseField>
    <ResponseField name="temporary_files_directory" type="string" required>
      Specifies a location to store the temporary processing file for an AS2 message. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A textual description for the agreement. Optional.
</ResponseField>

<ResponseField name="enforce_message_signing" type="string">
  Specifies whether to enforce an AS2 message is signed for this agreement. Optional.
</ResponseField>

<ResponseField name="local_profile_id" type="string" required>
  A unique identifier for the local profile. Required.
</ResponseField>

<ResponseField name="partner_profile_id" type="string" required>
  A unique identifier for the partner profile. Required.
</ResponseField>

<ResponseField name="preserve_filename" type="string">
  Specifies whether to preserve the filename received for this agreement. Optional.
</ResponseField>

<ResponseField name="server_id" type="string" required>
  A unique identifier for the server. Required.
</ResponseField>

<ResponseField name="status" type="string">
  Specifies the status of the agreement. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Key-value pairs that can be used to group and search for agreements. Tags are metadata attached to agreements for any purpose. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to an AWS Transfer Family agreement, used to categorize or identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="agreement_id" type="string">
  A unique identifier for the agreement. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="arn" type="string">
  Specifies the unique Amazon Resource Name (ARN) for the agreement. Computed by AWS after `ship`.
</ResponseField>

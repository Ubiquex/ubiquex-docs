`aws_transfer_server` creates a real, managed file transfer endpoint, SFTP, FTPS, or FTP, backed by S3 or an EFS file system, that `aws_transfer_user`s authenticate against to upload and download files.

## Input properties

<ResponseField name="certificate" type="string">
  The ARN of an AWS Certificate Manager (ACM) certificate used to secure FTPS connections for the AWS Transfer Family server. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain" type="string">
  The storage service (S3 or EFS) that this AWS Transfer Family server is configured to use for file storage and management. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_details" type="object">

  <Expandable title="properties">

      Specifies the list of Elastic IP allocation IDs to associate with the server's VPC endpoint, allowing the Transfer server to have static IP addresses for its endpoint when the endpoint type is VPC. Optional. **(AI-inferred)**

    <ResponseField name="security_group_ids" type="list(string)">
      Specifies the security group IDs attached to the VPC endpoint used by the AWS Transfer Family server, controlling the network traffic allowed to and from the endpoint. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="subnet_ids" type="list(string)">
      Specifies the subnets in your VPC where the AWS Transfer Family server's endpoint is deployed (for VPC or VPC_ENDPOINT endpoint types), allowing the server to be accessed from within your private network. Optional. **(AI-inferred)**

    <ResponseField name="vpc_endpoint_id" type="string">
      The ID of the VPC endpoint that the AWS Transfer Family server is associated with when the server's endpoint type is set to VPC. Optional. **(AI-inferred)**

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) assigned to the Transfer Family server, which uniquely identifies it across AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="as2_service_managed_egress_ip_addresses" type="list(string)">
  The list of egress IP addresses of this server. These IP addresses are only relevant for servers that use the AS2 protocol. They are used for sending asynchronous MDNs. These IP addresses are assigned automatically when you create an AS2 server. Additionally, if you update an existing server and add the AS2 protocol, static IP addresses are assigned as well. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="server_id" type="string">
  The unique server identifier assigned by AWS for this Transfer Family server (e.g., s-1234567890abcdef), used to reference the server in API calls and other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="state" type="string">
  The state of the AWS Transfer Family server, such as ONLINE or OFFLINE, indicating its lifecycle status. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

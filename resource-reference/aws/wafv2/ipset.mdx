`aws_wafv2_ipset` defines a real set of IP addresses or CIDR ranges that an `aws_wafv2_rule_group` or `aws_wafv2_web_acl` rule can match against, AWF WAFv2's current, actively developed counterpart to the deprecated `aws_waf_ipset`/`aws_wafregional_ipset`.

## Input properties

<ResponseField name="addresses" type="list(string)" required>
  List of IPAddresses. Required.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the entity. Optional.
</ResponseField>

<ResponseField name="ipaddress_version" type="string" required>
  Type of addresses in the IPSet, use IPV4 for IPV4 IP addresses, IPV6 for IPV6 address. Required.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the IPSet. Optional.
</ResponseField>

<ResponseField name="scope" type="string" required>
  Use CLOUDFRONT for CloudFront IPSet, use REGIONAL for Application Load Balancer and API Gateway. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">

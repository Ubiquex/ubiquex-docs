`aws_wafv2_web_acl` creates a real, top-level web ACL under AWS WAFv2, evaluating its own inline rules and any referenced `aws_wafv2_rule_group`s against requests to a CloudFront distribution, ALB, API Gateway, AppSync API, Cognito user pool, App Runner service, or Verified Access instance, one unified resource type across scopes that AWS WAF Classic split between global and Regional.

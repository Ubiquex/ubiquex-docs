`aws_wafv2_web_aclassociation` attaches a real `aws_wafv2_web_acl` to a specific protected resource, an ALB, API Gateway stage, or similar, the resource that actually turns the ACL's rules on for that resource's traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wafv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/wafv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own web aclassociation"})

    		ubx.Resource(wafv2.WebAclassociation, "example", wafv2.WebAclassociationConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			WebAclarn:   "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="resource_arn" type="string" required>
  The ARN of the AWS resource (such as an Application Load Balancer, API Gateway, or Amazon CloudFront distribution) that this WAFv2 web ACL is being associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="web_aclarn" type="string" required>
  The ARN of the AWS WAF v2 web ACL to associate with the specified resource. Required. **(AI-inferred)**
</ResponseField>

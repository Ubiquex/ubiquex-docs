`aws_service_catalog_launch_template_constraint` restricts which EC2 instance types, or other launch template values, an end user is allowed to override when launching a product from an `aws_service_catalog_portfolio`.

    			ProductId:      "example",

## Input properties

<ResponseField name="accept_language" type="string">
  The language code. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the constraint. Optional.
</ResponseField>

<ResponseField name="portfolio_id" type="string" required>
  The portfolio identifier. Required.
</ResponseField>

<ResponseField name="product_id" type="string" required>
  The product identifier. Required.
</ResponseField>

<ResponseField name="rules" type="string" required>
  A json encoded string of the template constraint rules Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Unique identifier for the constraint Computed by AWS after `ship`.
</ResponseField>

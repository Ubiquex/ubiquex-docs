`aws_service_catalog_service_action` defines a real, self-service action, running a specific SSM document, that an end user can invoke against a provisioned product, such as restarting an instance, without needing direct IAM permission to call the underlying API themselves.

## Input properties

<ResponseField name="accept_language" type="string">
  Specifies the language code (e.g., 'en' for English) used for localized text such as the service action's name and description when interacting with AWS Service Catalog. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="definition" type="list(object)" required>
  Specifies the definition of the Service Catalog service action, including the AWS Systems Manager automation document name, version, IAM assume role, and parameters. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a definition entry, which specifies the service action definition parameter being set, such as Name, Version, AssumeRole, or Parameters. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of the service action definition, such as the ARN of an AWS Systems Manager automation document or an AWS Lambda function that the action invokes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="definition_type" type="string" required>
  Specifies the type of service action definition, which for AWS Service Catalog service actions must be set to SSM_AUTOMATION to reference an AWS Systems Manager automation document. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-defined, human-readable description of the Service Catalog self-service action, displayed in the AWS Management Console to help users understand the action's purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The human-readable name of the AWS Service Catalog service action, required to uniquely identify and display the action in the Service Catalog console and API. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to the Service Catalog service action, used to reference it across the AWS service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

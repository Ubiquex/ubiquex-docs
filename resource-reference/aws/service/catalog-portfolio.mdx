`aws_service_catalog_portfolio` creates a real, named collection of `aws_service_catalog_cloud_formation_product`s and `aws_service_catalog_service_action`s that specific IAM principals are granted access to, Service Catalog's own unit of governed distribution.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalog "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog portfolio"})

    		ubx.Resource(servicecatalog.Portfolio, "example", servicecatalog.PortfolioConfig{
    			DisplayName:    "example-display-name",
    			ProviderName:   "example-provider-name",
    			AcceptLanguage: "example",
    			Description:    "Managed by ubx.",
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accept_language" type="string">
  Specifies the language code (such as 'en' or 'jp') that AWS Service Catalog uses for localized text when returning portfolio details, ensuring the portfolio's description and related metadata appear in the requested language. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-friendly description of the Service Catalog portfolio, providing additional context about its purpose and contents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The name of the portfolio, as displayed in the AWS Service Catalog console. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="provider_name" type="string" required>
  The name of the person or organization that owns and manages the Service Catalog portfolio. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Service Catalog portfolio, used to organize and identify the portfolio for cost allocation and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value (a string) of a key-value tag that can be assigned to the AWS Service Catalog portfolio for organizational purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique Service Catalog portfolio identifier (e.g., 'port-xxxxxx') assigned by AWS when the portfolio is created, used to reference the portfolio in other resources and API calls. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="portfolio_name" type="string">
  The name of the AWS Service Catalog portfolio, automatically populated from the portfolio's DisplayName attribute when read from AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

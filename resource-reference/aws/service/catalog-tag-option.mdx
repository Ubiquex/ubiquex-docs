`aws_service_catalog_tag_option` defines a real, allowed tag key-value pair that can be associated with an `aws_service_catalog_portfolio` or product, so end users pick from a governed, pre-approved set of tags rather than typing arbitrary ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own catalog tag option"})

    		ubx.Resource(service.CatalogTagOption, "ci-runner", service.CatalogTagOptionConfig{
    			Key:    "example",
    			Value:  "example",
    			Active: true,
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="active" type="bool">
  The TagOption active state. Optional.
</ResponseField>

<ResponseField name="key" type="string" required>
  The TagOption key. Required.
</ResponseField>

<ResponseField name="value" type="string" required>
  The TagOption value. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The TagOption identifier. Computed by AWS after `ship`.

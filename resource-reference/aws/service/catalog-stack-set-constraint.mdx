`aws_service_catalog_stack_set_constraint` configures an `aws_service_catalog_portfolio`'s product to launch as a CloudFormation StackSet across multiple accounts and Regions at once, rather than as a single stack in one account.

## Example

<Tabs>

    ```go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog stack set constraint"})

    		ubx.Resource(service.CatalogStackSetConstraint, "example", service.CatalogStackSetConstraintConfig{
    			AccountList:          []string{"example"},
    			AdminRole:            "example",
    			Description:          "Managed by ubx.",
    			ExecutionRole:        "example",
    			PortfolioId:          "example",
    			ProductId:            "example",
    			RegionList:           []string{"example"},
    			StackInstanceControl: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accept_language" type="string">
  The language code. Optional.
</ResponseField>

<ResponseField name="account_list" type="list(string)" required>
  One or more AWS accounts that will have access to the provisioned product. Required.
</ResponseField>

<ResponseField name="admin_role" type="string" required>
  AdminRole ARN. Required.
</ResponseField>

<ResponseField name="description" type="string" required>
  The description of the constraint. Required.
</ResponseField>

<ResponseField name="execution_role" type="string" required>
  ExecutionRole name. Required.
</ResponseField>

<ResponseField name="portfolio_id" type="string" required>
  The portfolio identifier. Required.
</ResponseField>

<ResponseField name="product_id" type="string" required>
  The product identifier. Required.
</ResponseField>

<ResponseField name="region_list" type="list(string)" required>
  One or more AWS Regions where the provisioned product will be available. Required.
</ResponseField>

<ResponseField name="stack_instance_control" type="string" required>
  Permission to create, update, and delete stack instances. Choose from ALLOWED and NOT_ALLOWED. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Unique identifier for the constraint Computed by AWS after `ship`.
</ResponseField>

---

`aws_service_catalog_portfolio_share` shares a real `aws_service_catalog_portfolio` with another AWS account or an AWS Organizations OU, the resource that actually initiates the share an `aws_service_catalog_accepted_portfolio_share` on the other side accepts.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalog "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicecatalog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog portfolio share"})

    		ubx.Resource(servicecatalog.PortfolioShare, "example", servicecatalog.PortfolioShareConfig{
    			AccountId:       "example",
    			PortfolioId:     "example",
    			AcceptLanguage:  "example",
    			ShareTagOptions: true,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="accept_language" type="string">
  The language code. Optional.
</ResponseField>

<ResponseField name="account_id" type="string" required>
  The AWS account ID. Required.
</ResponseField>

<ResponseField name="portfolio_id" type="string" required>
  The portfolio identifier. Required.
</ResponseField>

<ResponseField name="share_tag_options" type="bool">
  Enables or disables TagOptions sharing when creating the portfolio share. Optional.
</ResponseField>

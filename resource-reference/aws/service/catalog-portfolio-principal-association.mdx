`aws_service_catalog_portfolio_principal_association` grants a real IAM principal, user, group, or role, access to an `aws_service_catalog_portfolio`, the resource that actually authorizes that principal to browse and launch its products.

## Properties

<ResponseField name="accept_language" type="string">
  The language code. Optional.
</ResponseField>

<ResponseField name="portfolio_id" type="string">
  The portfolio identifier. Optional.
</ResponseField>

<ResponseField name="principal_arn" type="string">
  The ARN of the principal (user, role, or group). Optional.
</ResponseField>

<ResponseField name="principal_type" type="string" required>
  The principal type. The supported value is IAM if you use a fully defined Amazon Resource Name (ARN), or IAM_PATTERN if you use an ARN with no accountID, with or without wildcard characters. Required.
</ResponseField>

---

`aws_service_catalog_launch_role_constraint` restricts an `aws_service_catalog_portfolio`'s product launches to assume a specific IAM role, rather than the launching user's own permissions, so end users don't need direct IAM access to whatever the product actually provisions.

## Input properties

<ResponseField name="accept_language" type="string">
  The language code for the constraint. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the launch role constraint. Optional.
</ResponseField>

<ResponseField name="local_role_name" type="string">
  The local IAM role name to use in the launch constraint. Optional.
</ResponseField>

<ResponseField name="portfolio_id" type="string" required>
  The ID of the portfolio to which this launch role constraint applies. Required.
</ResponseField>

<ResponseField name="product_id" type="string" required>
  The ID of the product to which this launch role constraint applies. Required.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the IAM role used for the launch constraint. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier for the launch role constraint. Computed by AWS after `ship`.
</ResponseField>

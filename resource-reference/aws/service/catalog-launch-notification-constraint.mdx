`aws_service_catalog_launch_notification_constraint` configures real SNS notifications for stack events, create, update, delete, whenever an `aws_service_catalog_cloud_formation_product` is provisioned from a specific `aws_service_catalog_portfolio`.

## Input properties

<ResponseField name="accept_language" type="string">
  Specifies the language code (e.g., 'en') used for responses from the AWS Service Catalog API when managing this launch notification constraint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A free-form text description of the Service Catalog launch notification constraint, which specifies an SNS topic that receives notifications for provisioning and termination events. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="notification_arns" type="list(string)" required>
  The list of Amazon SNS topic ARNs that receive stack event notifications when the associated product is launched via this Service Catalog launch notification constraint. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="portfolio_id" type="string" required>
  The identifier of the Service Catalog portfolio to which the launch notification constraint applies. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="product_id" type="string" required>
  The identifier of the Service Catalog product to which this launch notification constraint is associated, controlling which product's stack events trigger the configured SNS notifications. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Unique identifier for the constraint Computed by AWS after `ship`.
</ResponseField>

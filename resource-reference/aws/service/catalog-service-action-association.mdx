`aws_service_catalog_service_action_association` associates a real `aws_service_catalog_service_action` with a specific `aws_service_catalog_cloud_formation_product` and provisioning artifact, the resource that actually makes the action available on that product.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog service action association"})

    			ProductId:              "example",
    			ProvisioningArtifactId: "example",
    			ServiceActionId:        "example",
    		})
    	}))
    }

## Properties

<ResponseField name="product_id" type="string" required>
  The ID (or identifier) of the AWS Service Catalog product to which the self-service action is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioning_artifact_id" type="string" required>
  The ID of the provisioning artifact (product version) that the service action is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_action_id" type="string" required>
  The ID of the AWS Service Catalog service action that this association attaches to the specified provisioning artifact. Required. **(AI-inferred)**
</ResponseField>

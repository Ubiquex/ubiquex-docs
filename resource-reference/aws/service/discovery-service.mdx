`aws_service_discovery_service` defines a real, discoverable service name within a namespace, `aws_service_discovery_http_namespace`, `aws_service_discovery_private_dns_namespace`, or `aws_service_discovery_public_dns_namespace`, that `aws_service_discovery_instance`s register themselves under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own discovery service"})

    		ubx.Resource(service.DiscoveryService, "ci-runner", service.DiscoveryServiceConfig{
    			Name:                    "ci-runner",
    			Description:             "Managed by ubx.",
    			DnsConfig:               map[string]any{"dns_records": []map[string]any{{"ttl": 1}}},
    			HealthCheckConfig:       map[string]any{"type": "example"},
    			HealthCheckCustomConfig: map[string]any{"failure_threshold": 1},
    			NamespaceId:             "example",
    			ServiceAttributes:       "example",
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.service import DiscoveryService, DiscoveryServiceConfig

    def describe():
        ubx.intent("payments own discovery service")

        ubx.resource(DiscoveryService, "ci-runner", DiscoveryServiceConfig(
            name="ci-runner",
            description="Managed by ubx.",
            dns_config={"dns_records": [{"ttl": 1}]},
            health_check_config={"type": "example"},
            health_check_custom_config={"failure_threshold": 1},
            namespace_id="example",
            service_attributes="example",
            tags=[{"key": "example"}],
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)

## Input properties

<ResponseField name="description" type="string">
  A description for the service. Optional.
</ResponseField>

<ResponseField name="dns_config" type="object">
  DNS configuration settings for the service. Optional.
  <Expandable title="properties">
    <ResponseField name="dns_records" type="list(object)" required>
      A list of DNS records associated with the service. Required.
      <Expandable title="properties">
        <ResponseField name="ttl" type="number">
          The time-to-live (TTL) in seconds for the DNS record, controlling how long resolvers cache it before querying AWS Cloud Map again. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the DNS record type (A, AAAA, SRV, or CNAME) for the service's DNS records. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="namespace_id" type="string">
      The ID of the namespace for the DNS configuration. Optional.
    </ResponseField>
    <ResponseField name="routing_policy" type="string">
      The routing policy to use for DNS queries. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="health_check_config" type="object">
  Configuration for health checks for the service. Optional.
  <Expandable title="properties">
    <ResponseField name="failure_threshold" type="number">
      The number of consecutive health check failures that must occur before declaring the service unhealthy. Optional.
    </ResponseField>
    <ResponseField name="resource_path" type="string">
      The path to ping on the service for health checks. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of health check (e.g., HTTP, HTTPS, TCP). Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="health_check_custom_config" type="object">
  Configurations for custom health checks for the service. Optional.
  <Expandable title="properties">
    <ResponseField name="failure_threshold" type="number">
      The number of consecutive health check failures required before the service is considered unhealthy. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the service. Optional.
</ResponseField>

<ResponseField name="namespace_id" type="string">
  The ID of the namespace in which the service is created. Optional.
</ResponseField>

<ResponseField name="service_attributes" type="any">
  A string map that contains attributes and values for the service. You can specify a maximum of 30 key-value pairs. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to associate with the service. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      This key identifies a tag attached to the AWS Cloud Map service, allowing you to assign metadata for cost tracking, access control, or resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the AWS CloudFormation service discovery service, used to organize, identify, or manage the resource through key-value pairs. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of service. Supported values are HTTP or DNS. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the service. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier for the service. Computed by AWS after `ship`.
</ResponseField>

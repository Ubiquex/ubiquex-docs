`aws_service_catalog_accepted_portfolio_share` accepts a real `aws_service_catalog_portfolio_share` from another account, the resource that actually makes the shared portfolio's products usable in the accepting account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog accepted portfolio share"})

    		ubx.Resource(service.CatalogAcceptedPortfolioShare, "example", service.CatalogAcceptedPortfolioShareConfig{
    			PortfolioId:    "example",
    			AcceptLanguage: "example",
    		})
    	}))
    }
    ```
  </Tab>

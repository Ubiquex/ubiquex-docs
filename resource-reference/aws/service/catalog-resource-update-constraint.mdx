`aws_service_catalog_resource_update_constraint` restricts which fields of an already-provisioned product an end user is allowed to change on update, for an `aws_service_catalog_portfolio`'s own products.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	service "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/service"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own catalog resource update constraint"})

    		ubx.Resource(service.CatalogResourceUpdateConstraint, "example", service.CatalogResourceUpdateConstraintConfig{
    			PortfolioId:                   "example",
    			ProductId:                     "example",
    			TagUpdateOnProvisionedProduct: "example",
    			AcceptLanguage:                "example",
    			Description:                   "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accept_language" type="string">
  The language code Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the constraint Optional.
</ResponseField>

<ResponseField name="portfolio_id" type="string" required>
  The portfolio identifier Required.
</ResponseField>

<ResponseField name="product_id" type="string" required>
  The product identifier Required.
</ResponseField>

<ResponseField name="tag_update_on_provisioned_product" type="string" required>
  ALLOWED or NOT_ALLOWED, to permit or prevent changes to the tags on provisioned instances of the specified portfolio / product combination Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Unique identifier for the constraint Computed by AWS after `ship`.
</ResponseField>

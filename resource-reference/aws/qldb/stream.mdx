---
title: "aws_qldb_stream"
description: "`aws_qldb_stream` streamed a real, continuous feed of an `aws_qldb_ledger`'s journal changes to a Kinesis Data Stream."
---

Like the ledger itself, this describes the now fully discontinued Amazon QLDB service, which ended support July 31, 2025.

## Input properties

<ResponseField name="exclusive_end_time" type="string">
  The exclusive_end_time specifies the date and time at which the QLDB journal stream stops delivering data; if omitted, the stream continues indefinitely. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="inclusive_start_time" type="string" required>
  The inclusive start time and date (ISO 8601 timestamp) from which the QLDB stream starts capturing journal data, including all revisions committed at or after that exact moment. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="kinesis_configuration" type="object" required>
  Specifies the Amazon Kinesis Data Streams destination for the QLDB stream, including the ARN of the target Kinesis stream and whether aggregation of records is enabled. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="aggregation_enabled" type="bool">
      Indicates whether to enable aggregation of QLDB stream records before they are delivered to Kinesis Data Streams, which groups multiple records into a single Kinesis record to reduce the number of requests. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stream_arn" type="string">
      The Amazon Resource Name (ARN) of the Kinesis data stream to which QLDB writes journal data. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ledger_name" type="string" required>
  The name of the QLDB ledger from which this stream exports data. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of the IAM role that QLDB assumes to write journal data to the destination Kinesis Data Stream. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="stream_name" type="string" required>
  The user-defined name of the QLDB journal stream, which must be unique within the AWS account and region and is used to identify the stream when creating or managing it. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to an Amazon QLDB stream, used to organize, identify, and manage the stream resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag attached to the Amazon QLDB stream, used to assign metadata to the stream for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

title: "aws_qldb_ledger"
description: "`aws_qldb_ledger` created a real, cryptographically verifiable, append-only ledger database."
---

Amazon QLDB is now fully discontinued: AWS ended support on July 31, 2025, a date well over a year in the past, with little formal notice, recommending migration to Amazon Aurora PostgreSQL's ledger-style extensions, which do not preserve QLDB's own cryptographic verifiability. This resource describes a service no longer operable rather than a current one.

## Input properties

<ResponseField name="deletion_protection" type="bool">
  Enables or disables deletion protection for the ledger, preventing the ledger from being deleted when enabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key" type="string">
  The ARN of a customer-managed AWS KMS key used to encrypt the ledger's data at rest; if omitted, AWS QLDB uses an AWS-owned key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  The name of the QLDB ledger to create; if you do not provide one, AWS CloudFormation generates a unique name for the ledger. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="permissions_mode" type="string" required>
  Sets the permissions mode for the QLDB ledger, which controls whether all IAM principals can access the ledger through IAM policies (ALLOW_ALL) or whether access is restricted by standard QLDB permissions (STANDARD). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the list of key-value tags to attach to the QLDB ledger. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Defines the key of a tag applied to the QLDB ledger, which serves as a user-defined label for identifying and managing the ledger resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the AWS QLDB ledger, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

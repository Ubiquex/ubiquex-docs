`aws_pipes_pipe` creates a real EventBridge Pipes point-to-point integration, pulling events from a single source, SQS, Kinesis, DynamoDB Streams, MSK, self-managed Kafka, or Amazon MQ, optionally filtering, enriching, and transforming them, and delivering the result to a single target, without hand-writing the glue code an equivalent Lambda function would need.

    	ubx.Main(ubx.Stack("example", func() {

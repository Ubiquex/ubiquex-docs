title: "aws_rum_app_monitor"
description: "`aws_rum_app_monitor` creates a real CloudWatch RUM app monitor..."

`aws_rum_app_monitor` creates a real CloudWatch RUM app monitor, a JavaScript snippet embedded in a web application that collects real client-side performance and error data, page load time, JS errors, HTTP request latency, from actual users' browsers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rum "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/rum"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app monitor"})

    		ubx.Resource(rum.AppMonitor, "example", rum.AppMonitorConfig{
    			Name:                       "example",
    			AppMonitorConfiguration:    map[string]any{"allow_cookies": true},
    			CustomEvents:               map[string]any{"status": "example"},
    			CwLogEnabled:               true,
    			DeobfuscationConfiguration: map[string]any{"java_script_source_maps": map[string]any{"status": "example"}},
    			Domain:                     "example",
    			DomainList:                 []string{"example"},
    			Platform:                   "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="app_monitor_configuration" type="object">
  AppMonitor configuration Optional.
  <Expandable title="properties">
    <ResponseField name="allow_cookies" type="bool">
      If you set this to true, the RUM web client sets two cookies, a session cookie and a user cookie. The cookies allow the RUM web client to collect data relating to the number of users an application has and the behavior of the application across a sequence of events. Cookies are stored in the top-level domain of the current page. Optional.
    </ResponseField>
    <ResponseField name="enable_xray" type="bool">
      If you set this to true, RUM enables xray tracing for the user sessions that RUM samples. RUM adds an xray trace header to allowed HTTP requests. It also records an xray segment for allowed HTTP requests. You can see traces and segments from these user sessions in the xray console and the CW ServiceLens console. Optional.
    </ResponseField>
    <ResponseField name="excluded_pages" type="list(string)">
      List of url pages Optional.
    </ResponseField>
    <ResponseField name="favorite_pages" type="list(string)">
      List of favorite pages Optional.
    </ResponseField>
    <ResponseField name="guest_role_arn" type="string">
      Resource ARN Optional.
    </ResponseField>
    <ResponseField name="identity_pool_id" type="string">
      The ID of the identity pool that is used to authorize the sending of data to RUM. Optional.
    </ResponseField>
    <ResponseField name="included_pages" type="list(string)">
      List of url pages Optional.
    </ResponseField>
    <ResponseField name="metric_destinations" type="list(object)">
      An array of structures which define the destinations and the metrics that you want to send. Optional.
      <Expandable title="properties">
        <ResponseField name="destination" type="string">
          The destination service to which CloudWatch RUM sends the extracted metrics, such as CloudWatch or Evidently. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="destination_arn" type="string">
          The ARN of the CloudWatch Logs log group or Evidently project that receives the metrics, used when metric destinations are configured for the app monitor. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="iam_role_arn" type="string">
          The ARN of an IAM role that grants CloudWatch RUM permission to publish metrics to the destination specified in this metric destination definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="metric_definitions" type="list(object)">
          Specifies the list of metric definitions for a metric destination, each defining a metric name and the value expression (such as a JSONPath or regex) used to extract the metric value from RUM event data. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="dimension_keys" type="any">
              A list of event attribute names (dimension keys) from the RUM event JSON that are used as dimensions for the custom metric defined in this metric definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="event_pattern" type="string">
              The JSON event pattern that filters which RUM application events are included in this metric definition, used to match event attributes for extracting metric values. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="name" type="string">
              The name assigned to this metric definition, which is used as the metric name when the extracted value is sent to the configured CloudWatch destination. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="namespace" type="string">
              The CloudWatch namespace where the extracted metric is published, defaulting to 'AWS/RUM' if not specified. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="unit_label" type="string">
              Defines the unit label (e.g., 'Milliseconds' or 'Count') that CloudWatch RUM attaches to the metric generated from this metric definition when it is sent to the destination. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value_key" type="string">
              The value_key property specifies the key in the event data that CloudWatch RUM uses to extract the numerical value for the custom metric defined by this metric definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="session_sample_rate" type="number">
      Specifies the percentage of user sessions to use for RUM data collection. Choosing a higher percentage gives you more data but also incurs more costs. The number you specify is the percentage of user sessions that will be used. If you omit this parameter, the default of 10 is used. Optional.
    </ResponseField>
    <ResponseField name="telemetries" type="list(string)">
      An array that lists the types of telemetry data that this app monitor is to collect. Optional.
    </ResponseField>
  </Expandable>

  </Expandable>

<ResponseField name="cw_log_enabled" type="bool">
  Data collected by RUM is kept by RUM for 30 days and then deleted. This parameter specifies whether RUM sends a copy of this telemetry data to CWLlong in your account. This enables you to keep the telemetry data for more than 30 days, but it does incur CWLlong charges. If you omit this parameter, the default is false Optional.
</ResponseField>

  <Expandable title="properties">

          The S3Uri of the bucket or folder that stores the source map files. It is required if status is ENABLED. Optional.
        </ResponseField>
        <ResponseField name="status" type="string" required>
          Specifies whether JavaScript error stack traces should be unminified for this app monitor. The default is for JavaScript error stack trace unminification to be DISABLED Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_entity_resolution_policy_statement` is a real, resource-based access policy statement controlling which other AWS principals can use an `aws_entity_resolution_matching_workflow` or `aws_entity_resolution_schema_mapping`, needed for cross-account Entity Resolution use, including from within an AWS Clean Rooms collaboration.

## Properties

<ResponseField name="action" type="list(string)">
  The list of AWS Identity and Access Management (IAM) actions, such as entityresolution:CreateMatchingWorkflow, that this policy statement allows or denies for the specified Entity Resolution resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="arn" type="string" required>
  Arn of the resource to which the policy statement is being attached. Required.
</ResponseField>

<ResponseField name="condition" type="string">
  The condition statement (a JSON-formatted string) that specifies when the policy statement takes effect, using IAM condition operators and keys such as aws:SourceAccount or aws:SourceArn. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="effect" type="string">
  Determines whether the policy statement allows or denies the specified actions on the Entity Resolution resource, typically specified as 'Allow' or 'Deny'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="principal" type="list(string)">
  Defines the list of AWS principals (such as IAM role ARNs, IAM user ARNs, or AWS account IDs) that the entity resolution policy statement authorizes, controlling which principals can access the associated Entity Resolution resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="statement_id" type="string" required>
  The Statement Id of the policy statement that is being attached. Required.
</ResponseField>

`aws_entity_resolution_id_mapping_workflow` links real entity IDs across two different `aws_entity_resolution_id_namespace`s, AWS Entity Resolution's dedicated workflow for cross-namespace identity mapping, distinct from `aws_entity_resolution_matching_workflow`'s own general record-matching purpose.

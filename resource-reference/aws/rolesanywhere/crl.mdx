`aws_roles_anywhere_crl` imports a real certificate revocation list into an `aws_roles_anywhere_trust_anchor`, so IAM Roles Anywhere rejects authentication attempts from any certificate that its issuing CA has since revoked.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rolesanywhere "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/rolesanywhere"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own crl"})

    		ubx.Resource(rolesanywhere.Crl, "example", rolesanywhere.CrlConfig{
    			CrlData:        "example",
    			Name:           "example",
    			Enabled:        true,
    			Tags:           []map[string]any{{"key": "example"}},
    			TrustAnchorArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    import ubx_sdk as ubx
    from ubx.aws.rolesanywhere import Crl, CrlConfig
    from ubx.aws.rolesanywhere.crl import Crl_Tags

    def describe():
        ubx.intent("example own crl")

        ubx.resource(Crl, "example", CrlConfig(
            crl_data="example",
            name="example",
            enabled=True,
            tags=[Crl_Tags(key="example")],
            trust_anchor_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="crl_data" type="string" required>
  The PEM-encoded certificate revocation list (CRL) data that is uploaded to AWS Roles Anywhere, containing the list of revoked certificates. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Indicates whether this certificate revocation list (CRL) is enabled for use in revoking certificates in AWS Roles Anywhere. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  Specifies the name of the certificate revocation list (CRL) resource, used to uniquely identify it within AWS Roles Anywhere. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag objects (each with a Key and Value) that you can assign to the AWS Roles Anywhere certificate revocation list to help manage, identify, and control access to it, such as through IAM tag-based policies. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Roles Anywhere certificate revocation list (CRL), used to categorize and manage the CRL resource according to your organization's tagging scheme. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the AWS Roles Anywhere certificate revocation list (CRL), used for organizing or identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="trust_anchor_arn" type="string">
  The ARN of the trust anchor that this certificate revocation list is associated with. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="crl_id" type="string">
  The system-generated unique identifier (UUID) for the certificate revocation list (CRL) in AWS Roles Anywhere, assigned when the CRL is created and used to reference it in subsequent operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

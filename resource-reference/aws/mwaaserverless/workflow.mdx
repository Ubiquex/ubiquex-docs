`aws_mwaaserverless_workflow` defines a real YAML- or Python-based workflow that Amazon MWAA Serverless executes on demand or on a schedule without any continuously running Airflow environment to manage, distinct from the always-on `aws_mwaa_environment`. MWAA Serverless is a genuinely new deployment option, announced November 17, 2025, so behavior here is verified live rather than assumed from general knowledge.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mwaaserverless "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/mwaaserverless"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workflow"})

    		ubx.Resource(mwaaserverless.Workflow, "example", mwaaserverless.WorkflowConfig{
    			DefinitionS3Location:    map[string]any{"bucket": "example"},
    			RoleArn:                 "arn:aws:iam::123456789012:policy/example",
    			Name:                    "example",
    			Code:                    map[string]any{"s3_location": map[string]any{"bucket": "example"}},
    			Description:             "Managed by ubx.",
    			EncryptionConfiguration: map[string]any{"type": "example"},
    			LoggingConfiguration:    map[string]any{"log_group_name": "example-log-group-name"},
    			NetworkConfiguration:    map[string]any{"security_group_ids": []string{"example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="definition_s3_location" type="object" required>
  Required.
  <Expandable title="properties">
    <ResponseField name="bucket" type="string" required>
      The name of the S3 bucket where the workflow definition file (DAG) for this MWAA Serverless workflow is stored. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="object_key" type="string" required>
      The S3 object key (key) identifying the workflow definition file within the bucket specified by the parent definition_s3_location, which is required to load the workflow's DAG from S3. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="version_id" type="string">
      The specific version identifier of the S3 object that contains the workflow definition, used to reference a particular version of the file in the S3 bucket. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Optional.
</ResponseField>

<ResponseField name="encryption_configuration" type="object">
  Specifies the AWS KMS key configuration for encrypting the MWAA environment's data, with the key ARN provided in the nested 'KmsKey' property. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="kms_key_id" type="string">
      Specifies the customer-managed AWS KMS key ID (or ARN/alias) that Amazon MWAA uses to encrypt the serverless workflow's definition and related data at rest. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="logging_configuration" type="object">
  Configures the logging settings for the AWS MWAA serverless workflow, specifying whether to enable logging and the log level (e.g., INFO, WARNING, ERROR, CRITICAL) for each component such as DAG processing, scheduler, task, web server, and worker logs. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="log_group_name" type="string" required>
      Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Optional.
</ResponseField>

<ResponseField name="network_configuration" type="object">
  Defines the VPC network configuration, including the subnet IDs and security group IDs, that the serverless workflow uses to run and access resources within your VPC. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="security_group_ids" type="list(string)">
      A list of security group IDs that AWS MWAA attaches to the VPC network interfaces of the serverless workflow environment, controlling inbound and outbound traffic. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="subnet_ids" type="list(string)">
      Provides the private subnet IDs within your VPC that the serverless workflow's underlying AWS resources are placed in, allowing the workflow to run in your own isolated network. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) of the IAM role that Amazon MWAA (Managed Workflows for Apache Airflow) assumes to access resources in your account, such as S3 buckets and CloudWatch Logs, on behalf of the serverless workflow. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  A map of key-value pairs to be applied as tags Optional.
</ResponseField>

<ResponseField name="trigger_mode" type="string">
  Specifies how the workflow is triggered, with allowed values such as SCHEDULE (for cron-based scheduling) or EVENT (for event-driven execution). Optional. **(AI-inferred)**
</ResponseField>

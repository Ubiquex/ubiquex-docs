`aws_m2_application` defines a real mainframe application, its runtime engine (Micro Focus or Blue Age) and application definition, deployed onto an `aws_m2_environment` under AWS Mainframe Modernization. The Mainframe Modernization managed-runtime-environment experience closed to new customers on November 7, 2025; existing customers can continue using it as normal.

## Input properties

<ResponseField name="definition" type="object">
  Contains the application definition for the AWS M2 mainframe modernization application, supplying the code or configuration either inline or via an S3 location. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The inline application definition content, specified as a string, that contains the application's definition in a format like JSON or YAML to be used for the M2 application. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_location" type="string">
      The S3 URI (e.g., s3://bucket/key) that points to the application definition file stored in Amazon S3, used to specify the application definition when it is not provided inline. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  This optional string supplies a customer-defined description for the AWS Mainframe Modernization application, used to identify the application's purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="engine_type" type="string" required>
  The engine type for the application, which determines the runtime environment (either Micro Focus or Blu Age). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The ID or the Amazon Resource Name (ARN) of the customer managed KMS Key used for encrypting application-related resources. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Specifies the required name for the AWS Mainframe Modernization application, which must be unique across all applications in your AWS account and Region and serves as the human-readable identifier in the M2 console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the IAM role that the application assumes to access other AWS services and resources needed for its operation. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Specifies a map of key-value tags to attach to the AWS Mainframe Modernization application for management and categorization. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="application_arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying the AWS Mainframe Modernization (M2) application, assigned by AWS and used to reference the application in other services, IAM policies, and monitoring tools. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="application_id" type="string">
  The unique identifier assigned by AWS to the Mainframe Modernization application when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_m2_environment` creates a real managed runtime environment, the compute cluster that AWS Mainframe Modernization continually monitors and self-heals, that one or more `aws_m2_application`s run on. Like `aws_m2_application`, this closed to new customers on November 7, 2025; existing customers can continue using it as normal.

## Example

## Input properties

<ResponseField name="description" type="string">
  The description of the environment. Optional.
</ResponseField>

<ResponseField name="engine_type" type="string" required>
  The target platform for the environment. Required.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The version of the runtime engine for the environment. Optional.
</ResponseField>

<ResponseField name="high_availability_config" type="object">
  Defines the details of a high availability configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="desired_capacity" type="number" required>
      The desired number of instances to run in the high availability configuration of the AWS Mainframe Modernization (M2) environment. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  The type of instance underlying the environment. Required.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The ID or the Amazon Resource Name (ARN) of the customer managed KMS Key used for encrypting environment-related resources. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the environment. Required.
</ResponseField>

<ResponseField name="network_type" type="string">
  Specifies the network type for the environment, either 'VPC' for a customer-managed virtual private cloud or 'EDGE' to use the AWS Mainframe Modernization managed network without a VPC. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">
  Configures a desired maintenance window for the environment. If you do not provide a value, a random system-generated value will be assigned. Optional.
</ResponseField>

<ResponseField name="publicly_accessible" type="bool">
  Specifies whether the environment is publicly accessible. Optional.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  The list of security groups for the VPC associated with this environment. Optional.
</ResponseField>

<ResponseField name="storage_configurations" type="list(any)">
  The storage configurations defined for the runtime environment. Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)">
  The unique identifiers of the subnets assigned to this runtime environment. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  Defines tags associated to an environment. Optional.
</ResponseField>

## Output properties

<ResponseField name="environment_arn" type="string">
  The Amazon Resource Name (ARN) of the runtime environment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="environment_id" type="string">
  The unique identifier of the environment. Computed by AWS after `ship`.
</ResponseField>

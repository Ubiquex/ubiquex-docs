`aws_image_builder_image` is the real, actual output, an AMI or container image, produced by running an `aws_image_builder_image_pipeline` once, either on its own recurring schedule or triggered manually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	imagebuilder "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/imagebuilder"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own builder imagebuilder"})

    		ubx.Resource(imagebuilder.Image, "example", imagebuilder.ImageConfig{
    			ContainerRecipeArn:             "arn:aws:iam::123456789012:policy/example",
    			DeletionSettings:               map[string]any{"execution_role": "example"},
    			DistributionConfigurationArn:   "arn:aws:iam::123456789012:policy/example",
    			EnhancedImageMetadataEnabled:   true,
    			ExecutionRole:                  "example",
    			ImagePipelineExecutionSettings: map[string]any{"deployment_id": "example"},
    			ImageRecipeArn:                 "arn:aws:iam::123456789012:policy/example",
    			ImageScanningConfiguration:     map[string]any{"ecr_configuration": map[string]any{"container_tags": []string{"example"}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="container_recipe_arn" type="string">
  The Amazon Resource Name (ARN) of the container recipe that defines how images are configured and tested. Optional.
</ResponseField>

<ResponseField name="deletion_settings" type="object">
  The deletion settings of the image, indicating whether to delete the underlying resources in addition to the image. Optional.
  <Expandable title="properties">
    <ResponseField name="execution_role" type="string" required>
      The execution role to use for deleting the image, as well as underlying resources. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="distribution_configuration_arn" type="string">
  The Amazon Resource Name (ARN) of the distribution configuration. Optional.
</ResponseField>

<ResponseField name="enhanced_image_metadata_enabled" type="bool">
  Collects additional information about the image being created, including the operating system (OS) version and package list. Optional.
</ResponseField>

<ResponseField name="execution_role" type="string">
  The execution role name/ARN for the image build, if provided Optional.
</ResponseField>

<ResponseField name="image_pipeline_execution_settings" type="object">
  The settings for starting an image pipeline execution. Optional.
  <Expandable title="properties">
    <ResponseField name="deployment_id" type="string">
      The deployment ID of the pipeline, used to trigger new image pipeline executions. Optional.
    </ResponseField>
    <ResponseField name="on_update" type="bool">
      Whether to trigger the image pipeline when the pipeline is updated. False by default. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_recipe_arn" type="string">
  The Amazon Resource Name (ARN) of the image recipe that defines how images are configured, tested, and assessed. Optional.
</ResponseField>

<ResponseField name="image_scanning_configuration" type="object">
  Contains settings for Image Builder image resource and container image scans. Optional.
  <Expandable title="properties">
    <ResponseField name="ecr_configuration" type="object">
      Settings for Image Builder to configure the ECR repository and output container images that are scanned. Optional.
      <Expandable title="properties">
        <ResponseField name="container_tags" type="list(string)">
          Tags for Image Builder to apply the output container image that is scanned. Tags can help you identify and manage your scanned images. Optional.
        </ResponseField>
        <ResponseField name="repository_name" type="string">
          The name of the container repository that Amazon Inspector scans to identify findings for your container images. The name includes the path for the repository location. If you don’t provide this information, Image Builder creates a repository in your account named image-builder-image-scanning-repository to use for vulnerability scans for your output container images. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="image_scanning_enabled" type="bool">
      This sets whether Image Builder keeps a snapshot of the vulnerability scans that Amazon Inspector runs against the build instance when you create a new image. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_tests_configuration" type="object">
  The image tests configuration used when creating this image. Optional.
  <Expandable title="properties">
    <ResponseField name="image_tests_enabled" type="bool">
      ImageTestsEnabled Optional.
    </ResponseField>
    <ResponseField name="timeout_minutes" type="number">
      TimeoutMinutes Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="infrastructure_configuration_arn" type="string">
  The Amazon Resource Name (ARN) of the infrastructure configuration. Optional.
</ResponseField>

<ResponseField name="logging_configuration" type="object">
  The logging configuration settings for the image. Optional.
  <Expandable title="properties">
    <ResponseField name="log_group_name" type="string">
      The name of the log group for image build logs. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  The tags associated with the image. Optional.
</ResponseField>

<ResponseField name="workflows" type="list(object)">
  Workflows to define the image build process Optional.
  <Expandable title="properties">
    <ResponseField name="on_failure" type="string">
      Specifies the action to take when this Image Builder workflow fails, with allowed values such as 'Continue' or 'Abort' controlling whether the image build proceeds or stops. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parallel_group" type="string">
      Specifies the name of a parallel group in which to run this workflow, allowing workflows in the same group to execute concurrently during the image build process. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameters" type="list(object)">
      Specifies a list of key-value pairs that Image Builder passes as input parameters to the corresponding workflow when it runs during the image build. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name of the workflow parameter, identifying which input parameter of the Image Builder workflow this value corresponds to. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="list(string)">
          Provides a list of values for a workflow parameter, which is passed to an Image Builder workflow during image creation. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="workflow_arn" type="string">
      The Amazon Resource Name (ARN) of the Image Builder workflow to execute as part of the image creation process. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the image. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="image_id" type="string">
  The AMI ID of the EC2 AMI in current region. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="image_uri" type="string">
  URI for containers created in current Region with default ECR image tag Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="latest_version" type="object">
  The latest version references of the image. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="arn" type="string">
      The latest version ARN of the created image. Optional.
    </ResponseField>
    <ResponseField name="major" type="string">
      The latest version ARN of the created image, with the same major version. Optional.
    </ResponseField>
    <ResponseField name="minor" type="string">
      The latest version ARN of the created image, with the same minor version. Optional.
    </ResponseField>
    <ResponseField name="patch" type="string">
      The latest version ARN of the created image, with the same patch version. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the image. Computed by AWS after `ship`.
</ResponseField>

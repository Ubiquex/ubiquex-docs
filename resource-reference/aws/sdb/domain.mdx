`aws_sdb_domain` creates a real domain, SimpleDB's rough equivalent of a table, in Amazon SimpleDB, AWS's original NoSQL database service, launched in 2007. SimpleDB has never been formally deprecated and existing domains keep working, but AWS has not added features or console support in well over a decade; it's reachable only through the API now, and AWS has steered new development toward DynamoDB since DynamoDB's 2012 launch. This describes a frozen legacy service rather than an actively developed one.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sdb "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sdb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain"})

    		ubx.Resource(sdb.Domain, "example", sdb.DomainConfig{
    			Description: "Managed by ubx.",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Domain } from "@ubx/sdk-aws/aws/sdb/domain";

    export default stack("example", () => {
      intent({ summary: "example own domain" });

      resource(Domain, "example", {
        description: "Managed by ubx.",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.sdb import Domain, DomainConfig

    def describe():
        ubx.intent("example own domain")

        ubx.resource(Domain, "example", DomainConfig(
            description="Managed by ubx.",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  Information about the SimpleDB domain. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The name of the domain to create. Computed by AWS after `ship`.
</ResponseField>

`aws_sdb_domain` creates a real domain, SimpleDB's rough equivalent of a table, in Amazon SimpleDB, AWS's original NoSQL database service, launched in 2007. SimpleDB has never been formally deprecated and existing domains keep working, but AWS has not added features or console support in well over a decade; it's reachable only through the API now, and AWS has steered new development toward DynamoDB since DynamoDB's 2012 launch. This describes a frozen legacy service rather than an actively developed one.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sdb "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sdb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own domain"})

    		ubx.Resource(sdb.Domain, "ci-runner", sdb.DomainConfig{
    			Description: "Managed by ubx.",
    		})
    	}))
    }
    ```

`aws_cur_report_definition` defines a real, recurring AWS Cost and Usage Report, its name, time granularity, file format, compression, and destination S3 bucket, that AWS delivers at least once a day so a caller has line-item-level billing data to analyze rather than only aggregate cost summaries.

## Properties

<ResponseField name="additional_artifacts" type="list(string)">
  A list of manifests that you want Amazon Web Services to create for this report. Optional.
</ResponseField>

<ResponseField name="additional_schema_elements" type="list(string)">
  A list of strings that indicate additional content that Amazon Web Services includes in the report, such as individual resource IDs. Optional.
</ResponseField>

<ResponseField name="billing_view_arn" type="string">
  The Amazon resource name of the billing view. You can get this value by using the billing view service public APIs. Optional.
</ResponseField>

<ResponseField name="compression" type="string" required>
  The compression format that AWS uses for the report. Required.
</ResponseField>

<ResponseField name="format" type="string" required>
  The format that AWS saves the report in. Required.
</ResponseField>

<ResponseField name="refresh_closed_reports" type="bool" required>
  Whether you want Amazon Web Services to update your reports after they have been finalized if Amazon Web Services detects charges related to previous months. These charges can include refunds, credits, or support fees. Required.
</ResponseField>

<ResponseField name="report_name" type="string" required>
  The name of the report that you want to create. The name must be unique, is case sensitive, and can't include spaces. Required.
</ResponseField>

<ResponseField name="report_versioning" type="string" required>
  Whether you want Amazon Web Services to overwrite the previous version of each report or to deliver the report in addition to the previous versions. Required.
</ResponseField>

<ResponseField name="s3_bucket" type="string" required>
  The S3 bucket where AWS delivers the report. Required.
</ResponseField>

<ResponseField name="s3_prefix" type="string" required>
  The prefix that AWS adds to the report name when AWS delivers the report. Your prefix can't include spaces. Required.
</ResponseField>

<ResponseField name="s3_region" type="string" required>
  The region of the S3 bucket that AWS delivers the report into. Required.
</ResponseField>

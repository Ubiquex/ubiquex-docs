`aws_instance` launches a real, virtual server, an EC2 instance, in the AWS Cloud, its instance type determining the actual balance of compute, memory, network, and storage hardware available to it. It's the single most fundamental EC2 resource, the one an AMI, a key pair, a security group, and an EBS volume all ultimately attach to or run on.

`aws_api_gateway_v2_deployment` is a snapshot of an `aws_api_gateway_v2_api`'s routes and integrations at a point in time, the v2 counterpart to a v1 REST API deployment, made reachable once an `aws_api_gateway_v2_stage` points to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigatewayv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apigatewayv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own deployment"})

    		ubx.Resource(apigatewayv2.Deployment, "example", apigatewayv2.DeploymentConfig{
    			ApiId:       "example",
    			Description: "Managed by ubx.",
    			StageName:   "example-stage-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

            stage_name="example-stage-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description for the deployment resource. Optional.
</ResponseField>

<ResponseField name="stage_name" type="string">
  The name of an existing stage to associate with the deployment. Optional.
</ResponseField>

## Output properties

<ResponseField name="deployment_id" type="string">
  The unique identifier assigned by AWS to this API Gateway v2 deployment. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_api_gateway_v2_portal_product` publishes a real API, or a curated group of operations from it, as a self-service product in an API Gateway developer portal, so external or internal developers can discover, subscribe to, and get credentials for it without a support ticket.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigatewayv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apigatewayv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own portal product"})

    		ubx.Resource(apigatewayv2.PortalProduct, "example", apigatewayv2.PortalProductConfig{
    			DisplayName: "example-display-name",
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.apigatewayv2 import PortalProduct, PortalProductConfig
    from ubx.aws.apigatewayv2.portal_product import PortalProduct_Tags

    def describe():
        ubx.intent("example own portal product")

        ubx.resource(PortalProduct, "example", PortalProductConfig(
            display_name="example-display-name",
            description="Managed by ubx.",
            tags=[PortalProduct_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  A description of the portal product. Optional.
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The name of the portal product as it appears in a published portal. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The collection of tags associated with the portal product. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="last_modified" type="string">
  The timestamp when the portal product was last modified. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="portal_product_arn" type="string">
  The ARN of the portal product. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="portal_product_id" type="string">
  The portal product identifier. Computed by AWS after `ship`.
</ResponseField>

`aws_api_gateway_v2_integration` connects an `aws_api_gateway_v2_api`'s routes to a real backend, Lambda, an HTTP endpoint, or another AWS service, the actual mechanism that determines what happens once a request matches a route.

## Input properties

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="connection_id" type="string">
  The ID of the VPC link for a private integration. Supported only for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="connection_type" type="string">
  The type of the network connection to the integration endpoint. Specify INTERNET for connections through the public routable internet or VPC_LINK for private connections between API Gateway and resources in a VPC. The default value is INTERNET. Optional.
</ResponseField>

<ResponseField name="content_handling_strategy" type="string">
  Supported only for WebSocket APIs. Specifies how to handle response payload content type conversions. Supported values are CONVERT_TO_BINARY and CONVERT_TO_TEXT. Optional.
</ResponseField>

<ResponseField name="credentials_arn" type="string">
  Specifies the credentials required for the integration, if any. For AWS integrations, three options are available. To specify an IAM Role for API Gateway to assume, use the role's Amazon Resource Name (ARN). To require that the caller's identity be passed through from the request, specify the string arn:aws:iam::*:user/*. To use resource-based permissions on supported AWS services, don't specify this parameter. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the integration. Optional.
</ResponseField>

<ResponseField name="integration_method" type="string">
  Specifies the integration's HTTP method type. Optional.
</ResponseField>

<ResponseField name="integration_subtype" type="string">
  Supported only for HTTP API AWS_PROXY integrations. Specifies the AWS service action to invoke. Optional.
</ResponseField>

<ResponseField name="integration_type" type="string" required>
  The integration type of an integration. Required.
</ResponseField>

<ResponseField name="integration_uri" type="string">
  For a Lambda integration, specify the URI of a Lambda function. For an HTTP integration, specify a fully-qualified URL. For an HTTP API private integration, specify the ARN of an Application Load Balancer listener, Network Load Balancer listener, or AWS Cloud Map service. Optional.
</ResponseField>

<ResponseField name="passthrough_behavior" type="string">
  Specifies the pass-through behavior for incoming requests based on the Content-Type header in the request, and the available mapping templates specified as the requestTemplates property on the Integration resource. There are three valid values: WHEN_NO_MATCH, WHEN_NO_TEMPLATES, and NEVER. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="payload_format_version" type="string">
  Specifies the format of the payload sent to an integration. Required for HTTP APIs. For HTTP APIs, supported values for Lambda proxy integrations are 1.0 and 2.0 For all other integrations, 1.0 is the only supported value. Optional.
</ResponseField>

<ResponseField name="request_parameters" type="any">
  A key-value map specifying parameters. Optional.
</ResponseField>

<ResponseField name="request_templates" type="any">
  A map of Velocity templates that are applied on the request payload based on the value of the Content-Type header sent by the client. Optional.
</ResponseField>

<ResponseField name="response_parameters" type="any">
  Parameters that transform the HTTP response from a backend integration before returning the response to clients. Supported only for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="template_selection_expression" type="string">
  The template selection expression for the integration. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="timeout_in_millis" type="number">
  Custom timeout between 50 and 29000 milliseconds for WebSocket APIs and between 50 and 30000 milliseconds for HTTP APIs. The default timeout is 29 seconds for WebSocket APIs and 30 seconds for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="tls_config" type="object">
  The TlsConfig property specifies the TLS configuration for a private integration. Supported only for HTTP APIs. Optional.
  <Expandable title="properties">
    <ResponseField name="server_name_to_verify" type="string">
      Defines the server name that API Gateway uses to verify the certificate presented by the target endpoint for a private integration, overriding the target hostname when necessary. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

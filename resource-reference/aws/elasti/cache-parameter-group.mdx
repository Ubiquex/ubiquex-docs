`aws_elasti_cache_parameter_group` sets real, engine-level configuration for an `aws_elasti_cache_cache_cluster` or `aws_elasti_cache_replication_group`, kept as its own resource so the same parameter set can be applied consistently across multiple clusters.

## Input properties

<ResponseField name="cache_parameter_group_family" type="string" required>
  The name of the cache parameter group family that this cache parameter group is compatible with. Required.
</ResponseField>

<ResponseField name="description" type="string" required>
  The description for this cache parameter group. Required.
</ResponseField>

<ResponseField name="properties" type="any">
  A comma-delimited list of parameter name/value pairs. For more information see ModifyCacheParameterGroup in the Amazon ElastiCache API Reference Guide. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags are composed of a Key/Value pair. You can use tags to categorize and track each parameter group. The tag value null is permitted. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a user-defined tag attached to the ElastiCache parameter group, enabling metadata-based organization, cost tracking, and IAM access control on the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cache_parameter_group_name" type="string">
  The name of the Cache Parameter Group. Computed by AWS after `ship`.

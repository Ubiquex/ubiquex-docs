`aws_elasti_cache_serverless_cache` creates a real ElastiCache deployment, Redis OSS, Valkey, or Memcached, that scales storage and compute automatically with actual usage, no node type to pick and no capacity to provision ahead of time the way `aws_elasti_cache_cache_cluster` and `aws_elasti_cache_replication_group` both require.

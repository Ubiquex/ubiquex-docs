`aws_elasti_cache_security_group_ingress` authorizes real network access to an `aws_elasti_cache_cache_cluster` running in the legacy EC2-Classic network model, a mechanism specific to accounts still using EC2-Classic rather than a VPC.

## Input properties

<ResponseField name="cache_security_group_name" type="string" required>
  The name of the existing ElastiCache cache security group to which the ingress rule is applied, allowing access from the specified EC2 security group. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_name" type="string" required>
  The name of the EC2 security group that is permitted to access the associated ElastiCache security group. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_owner_id" type="string">
  The AWS account ID of the owner of the EC2 security group specified in the ingress rule, used when authorizing cross-account access. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The computed unique identifier for this ElastiCache security group ingress rule, composed from the cache security group name, the EC2 security group name, and the EC2 security group owner ID to uniquely represent the authorization. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

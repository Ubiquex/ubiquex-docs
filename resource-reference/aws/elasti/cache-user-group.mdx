`aws_elasti_cache_user_group` collects `aws_elasti_cache_user`s into a real, named group that gets applied to an `aws_elasti_cache_replication_group` together, rather than a caller attaching each user to the replication group individually.

## Input properties

<ResponseField name="engine" type="string" required>
  The target cache engine for the user group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this user. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key that, paired with its value, labels this ElastiCache user group for cost allocation, access control, and operational management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a metadata tag attached to the ElastiCache User Group, used to assign arbitrary identifiers like environment or owner for resource organization and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_group_id" type="string" required>
  The ID of the user group. Required.
</ResponseField>

<ResponseField name="user_ids" type="list(string)" required>
  List of users associated to this user group. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the user account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  Indicates user group status. Can be "creating", "active", "modifying", "deleting". Computed by AWS after `ship`.
</ResponseField>

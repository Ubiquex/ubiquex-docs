`aws_elasti_cache_user` defines a real Redis ACL-based user identity, with its own authentication and permitted commands and key patterns, for an `aws_elasti_cache_replication_group` running Redis's own role-based access control rather than one shared password for every client.

## Input properties

<ResponseField name="access_string" type="string">
  Access permissions string used for this user account. Optional.
</ResponseField>

<ResponseField name="authentication_mode" type="object">
  Specifies the authentication mode for the ElastiCache user, including the type (password or IAM) and, for password mode, the list of passwords used to authenticate. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="passwords" type="list(string)">
      Passwords used for this user account. You can create up to two passwords for each user. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Authentication Type Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="engine" type="string" required>
  The target cache engine for the user. Required.
</ResponseField>

<ResponseField name="no_password_required" type="bool">
  Indicates a password is not required for this user account. Optional.
</ResponseField>

<ResponseField name="passwords" type="list(string)">
  Passwords used for this user account. You can create up to two passwords for each user. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this user. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the ElastiCache user, used to assign metadata for identification and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**

</ResponseField>

<ResponseField name="user_id" type="string" required>

<ResponseField name="user_name" type="string" required>

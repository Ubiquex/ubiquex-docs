`aws_elasti_cache_serverless_cache_snapshot` is a real, point-in-time backup of an `aws_elasti_cache_serverless_cache`, restorable to a new serverless cache, the serverless-cache counterpart to snapshotting a provisioned cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticache "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elasticache"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cache serverless cache snapshot"})

    		ubx.Resource(elasticache.ServerlessCacheSnapshot, "example", elasticache.ServerlessCacheSnapshotConfig{
    			ServerlessCacheName:         "example-serverless-cache-name",
    			ServerlessCacheSnapshotName: "example-serverless-cache-snapshot-name",
    			KmsKeyId:                    "example",
    			Tags:                        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="kms_key_id" type="string">
  The Amazon Resource Name (ARN) of the AWS KMS key used to encrypt the snapshot. Provide the key ARN: the resource returns the key ARN on read, so supplying a bare key ID or alias for this createOnly property may be reported as drift by CloudFormation. Optional.
</ResponseField>

<ResponseField name="serverless_cache_name" type="string" required>
  The name of an existing serverless cache. The snapshot is created from this cache. Required.
</ResponseField>

<ResponseField name="serverless_cache_snapshot_name" type="string" required>
  The name of the serverless cache snapshot. Must be unique for the customer account. This value is stored as a lowercase string. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to be added to the serverless cache snapshot resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined key for a tag attached to this ElastiCache serverless cache snapshot, used for organizing and identifying the resource (e.g., by environment or project). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the serverless cache snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="bytes_used_for_cache" type="string">
  The total size of the serverless cache snapshot, in bytes. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="create_time" type="string">
  The date and time that the source serverless cache's metadata and cache data set was obtained for the snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="serverless_cache_configuration" type="object">
  This read-only object describes the configuration of the serverless cache from which the snapshot was taken, capturing settings such as the cache engine and related parameters at snapshot time. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="engine" type="string">
      The engine that the serverless cache is configured with. Optional.
    </ResponseField>
    <ResponseField name="major_engine_version" type="string">
      The engine version number that the serverless cache is configured with. Optional.
    </ResponseField>
    <ResponseField name="serverless_cache_name" type="string">
      The identifier of the serverless cache. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="snapshot_type" type="string">
  The type of snapshot of the serverless cache. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the serverless cache snapshot. Computed by AWS after `ship`.
</ResponseField>

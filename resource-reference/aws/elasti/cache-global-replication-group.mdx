`aws_elasti_cache_global_replication_group` links `aws_elasti_cache_replication_group`s across multiple AWS Regions with cross-Region replication, real disaster recovery and low-latency global reads that a single-Region replication group can't provide on its own.

## Input properties

<ResponseField name="automatic_failover_enabled" type="bool">
  AutomaticFailoverEnabled Optional.
</ResponseField>

<ResponseField name="cache_node_type" type="string">
  The cache node type of the Global Datastore Optional.
</ResponseField>

<ResponseField name="cache_parameter_group_name" type="string">
  Cache parameter group name to use for the new engine version. This parameter cannot be modified independently. Optional.
</ResponseField>

<ResponseField name="engine" type="string">
  The engine of the Global Datastore. Optional.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The engine version of the Global Datastore. Optional.
</ResponseField>

<ResponseField name="global_node_group_count" type="number">
  Indicates the number of node groups in the Global Datastore. Optional.
</ResponseField>

<ResponseField name="global_replication_group_description" type="string">
  The optional description of the Global Datastore Optional.
</ResponseField>

<ResponseField name="global_replication_group_id_suffix" type="string">
  The suffix name of a Global Datastore. Amazon ElastiCache automatically applies a prefix to the Global Datastore ID when it is created. Each AWS Region has its own prefix. Optional.
</ResponseField>

<ResponseField name="members" type="list(object)" required>
  The replication groups that comprise the Global Datastore. Required.
  <Expandable title="properties">
    <ResponseField name="replication_group_id" type="string">
      The identifier of the ElastiCache replication group that is included as a member of the global replication group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="replication_group_region" type="string">
      Specifies the AWS Region where the member replication group of this global replication group is located. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="role" type="string">
      Indicates whether this member's replication group is the primary (write) or secondary (read) cluster in the global replication group, controlling which cluster accepts writes and acts as the source for replication. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="regional_configurations" type="list(object)">
  Describes the replication group IDs, the AWS regions where they are stored and the shard configuration for each that comprise the Global Datastore Optional.
  <Expandable title="properties">
    <ResponseField name="replication_group_id" type="string">
      Specifies the ID of the ElastiCache replication group that is associated with this regional configuration within the global replication group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="replication_group_region" type="string">
      The AWS Region where the specified ElastiCache replication group resides, identifying one regional member of the global replication group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resharding_configurations" type="list(object)">
      Defines the list of node-group-level resharding settings, including preferred availability zones, for a regional replication group when the ElastiCache global replication group is resharded. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="node_group_id" type="string">
          The identifier of the node group (shard) within the regional replication group that this resharding configuration applies to, used to specify which shard's availability zones or slot mapping are adjusted during a resharding operation. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="preferred_availability_zones" type="list(string)">
          A list of preferred Availability Zones for the nodes in a node group (shard) during a resharding operation on a regional replication group associated with the ElastiCache Global Datastore. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="global_replication_group_id" type="string">
  The name of the Global Datastore, it is generated by ElastiCache adding a prefix to GlobalReplicationGroupIdSuffix. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the Global Datastore Computed by AWS after `ship`.
</ResponseField>

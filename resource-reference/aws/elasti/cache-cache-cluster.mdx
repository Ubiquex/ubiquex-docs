`aws_elasti_cache_cache_cluster` creates a real Memcached or single-node Redis OSS/Valkey cache cluster, ElastiCache's original, foundational deployment model, distinct from `aws_elasti_cache_replication_group`'s own multi-node, automatic-failover architecture.

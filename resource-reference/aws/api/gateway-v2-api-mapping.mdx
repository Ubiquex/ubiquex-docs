`aws_api_gateway_v2_api_mapping` maps an `aws_api_gateway_v2_api` and stage onto a path under an `aws_api_gateway_v2_domain_name`, the v2 equivalent of a v1 base path mapping.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway v2 api mapping"})

    		ubx.Resource(api.GatewayV2ApiMapping, "example", api.GatewayV2ApiMappingConfig{
    			ApiId:         "example",
    			DomainName:    "example-domain-name",
    			Stage:         "example",
    			ApiMappingKey: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="api_mapping_key" type="string">
  The API mapping key. Optional.
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The domain name. Required.
</ResponseField>

<ResponseField name="stage" type="string" required>
  The stage for this API gateway v2 API mapping. Required.
</ResponseField>

## Output properties

<ResponseField name="api_mapping_id" type="string">
  The unique identifier assigned by AWS to this API mapping, used to reference the mapping in API Gateway v2 operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_api_gateway_base_path_mapping_v2` maps a real base path on an `aws_api_gateway_v2_domain_name` to a specific API and stage, the HTTP/WebSocket API counterpart to the REST API's own `aws_api_gateway_base_path_mapping`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own gateway base path mapping v2"})

    		ubx.Resource(api.GatewayBasePathMappingV2, "ci-runner", api.GatewayBasePathMappingV2Config{
    			DomainNameArn: "arn:aws:iam::123456789012:policy/ci",
    			RestApiId:     "example",
    			BasePath:      "example",
    			Stage:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="base_path" type="string">
  The base path name that callers of the API must provide in the URL after the domain name. Optional.
</ResponseField>

<ResponseField name="domain_name_arn" type="string" required>
  The Arn of an AWS::ApiGateway::DomainNameV2 resource. Required.
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>
  The ID of the API. Required.
</ResponseField>

<ResponseField name="stage" type="string">
  The name of the API's stage. Optional.
</ResponseField>

## Output properties

<ResponseField name="base_path_mapping_arn" type="string">
  Amazon Resource Name (ARN) of the resource. Computed by AWS after `ship`.
</ResponseField>

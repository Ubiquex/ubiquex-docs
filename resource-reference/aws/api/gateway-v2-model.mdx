`aws_api_gateway_v2_model` is a JSON Schema definition attached to an `aws_api_gateway_v2_api`, the v2 counterpart to a v1 REST API model, describing the expected shape of a request or response body.

## Input properties

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="content_type" type="string">
  The content-type for the model, for example, "application/json". Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the model. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the model. Required.
</ResponseField>

<ResponseField name="schema" type="any" required>
  The schema for the model. For application/json models, this should be JSON schema draft 4 model. Required.
</ResponseField>

## Output properties

<ResponseField name="model_id" type="string">
  The unique identifier automatically assigned by Amazon API Gateway to this model when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

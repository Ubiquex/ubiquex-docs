`aws_api_gateway_authorizer` attaches a Lambda-, Cognito-, or IAM-based access-control check to an `aws_api_gateway_rest_api`, run before a request reaches its backend integration, so authorization logic lives outside the backend rather than duplicated inside it.

## Input properties

<ResponseField name="auth_type" type="string">
  Specifies the required authentication type (such as 'oauth' or 'openid') for the custom authorizer, which is optional and only relevant when the authorizer type is 'CUSTOM'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorizer_credentials" type="string">
  Specifies the ARN of an IAM role that Amazon API Gateway assumes when invoking the authorizer, used to grant permissions for the authorizer's backend (such as a Lambda function) to be called. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorizer_result_ttl_in_seconds" type="number">
  The number of seconds that API Gateway caches the authorizer result before re-invoking the authorizer Lambda function. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorizer_uri" type="string">
  The URI of the Lambda function that serves as the custom authorizer, typically formatted as arn:aws:apigateway:&#123;region&#125;:lambda:path/2015-03-31/functions/&#123;lambda-arn&#125;/invocations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_source" type="string">
  Defines the request parameter (e.g., method.request.header.Authorization) from which API Gateway extracts the caller's identity token for the custom or token authorizer. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_validation_expression" type="string">
  Specifies a regular expression that AWS API Gateway uses to validate the incoming identity (such as a bearer token) for the authorizer; if the identity does not match the expression, API Gateway rejects the request with a 401 response. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the custom authorizer, which must be unique within the API Gateway REST API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="provider_arns" type="list(string)">
  The list of Amazon Cognito user pool ARNs that this API Gateway authorizer uses to validate tokens for a COGNITO_USER_POOLS authorizer type. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>
  The unique identifier or reference (typically the logical ID of an aws_api_gateway_rest_api resource) of the REST API in API Gateway that this custom authorizer is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="type" type="string" required>
  Specifies the authorizer type, which determines the authorization mechanism for API Gateway requests: valid values are TOKEN, REQUEST, or COGNITO_USER_POOLS, corresponding to Lambda token authorizers, Lambda request authorizers, and Amazon Cognito user pool authorizers respectively. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="authorizer_id" type="string">
  The unique identifier assigned by Amazon API Gateway to the authorizer when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

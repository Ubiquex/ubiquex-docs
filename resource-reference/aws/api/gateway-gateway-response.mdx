`aws_api_gateway_gateway_response` customizes the response API Gateway itself returns for a given error, a 4XX or 5XX that never reached the backend, on an `aws_api_gateway_rest_api`, overriding the default generic error body and headers.

## Input properties

<ResponseField name="response_parameters" type="any">
  Specifies a map of response parameters (such as headers) to customize the API Gateway response, where each key is a parameter name and the value indicates whether the parameter is enabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="response_templates" type="any">
  Maps MIME content types to Velocity templates that generate the response body for this API Gateway gateway response. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="response_type" type="string" required>
  Specifies the type of API Gateway response to customize (e.g., MISSING_AUTHENTICATION_TOKEN, RESOURCE_NOT_FOUND, DEFAULT_4XX), which must be one of the predefined gateway response types. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>
  The identifier of the REST API to which this gateway response is attached. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="status_code" type="string">
  Specifies the HTTP status code that API Gateway returns for this gateway response, allowing you to override the default status code for the corresponding error type. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique physical resource id of the gateway response, formed as a composite of the associated REST API ID and the response type (for example, 'restApiId/DEFAULT_4XX') separated by a slash. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

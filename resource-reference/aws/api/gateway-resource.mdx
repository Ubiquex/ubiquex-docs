`aws_api_gateway_resource` defines one path segment in a REST API's URL tree, nested under an `aws_api_gateway_rest_api` (or under another resource), with one or more `aws_api_gateway_method`s attached to actually handle requests at that path.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway resource"})

    		ubx.Resource(api.GatewayResource, "example", api.GatewayResourceConfig{
    			ParentId:  "example",
    			PathPart:  "example",
    			RestApiId: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="parent_id" type="string" required>
  The identifier of the parent Resource in this REST API's resource hierarchy, determining the path of this resource relative to the API's root resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="path_part" type="string" required>
  The URL path segment (e.g., 'users' or a path parameter like '&#123;userId&#125;') that defines this resource's location in the API's URL hierarchy, appended to the parent resource's path to form the full resource path. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>
  The ID of the parent RestApi in API Gateway to which this resource belongs. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="resource_id" type="string">
  The unique identifier assigned to this API Gateway resource by the service, used to reference the resource in method and integration configurations within the same REST API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_api_gateway_usage_plan` defines throttling and quota limits for one or more REST APIs and stages, and the `aws_api_gateway_api_key`s associated with it are what identify which caller a given request's usage counts against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway usage plan"})

    		ubx.Resource(api.GatewayUsagePlan, "example", api.GatewayUsagePlanConfig{
    			ApiStages:     []map[string]any{{"api_id": "example"}},
    			Description:   "Managed by ubx.",
    			Quota:         map[string]any{"limit": 1},
    			Tags:          []map[string]any{{"key": "example"}},
    			Throttle:      map[string]any{"burst_limit": 1},
    			UsagePlanName: "example-usage-plan-name",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="api_stages" type="list(object)">
  Associates this usage plan with specific API Gateway stages, optionally configuring per-stage throttling and quota limits for those stages. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="api_id" type="string">
      The identifier of the API for which this usage plan stage association is configured, referencing the API Gateway REST API. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stage" type="string">
      In the API Gateway UsagePlan's ApiStages list, this is the name of the deployed stage (such as 'prod') that the usage plan applies to. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="throttle" type="any">
      Defines method-level throttling limits for the associated API stage, mapping individual method paths (e.g., 'GET /resource') to their own burst and rate limits. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  An optional description that provides a friendly label or purpose for the usage plan, helping to distinguish it from other plans in the API Gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="quota" type="object">
  ``QuotaSettings`` is a property of the [AWS::ApiGateway::UsagePlan](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-usageplan.html) resource that specifies a target for the maximum number of requests users can make to your REST APIs. In some cases clients can exceed the targets that you set. Don’t rely on usage plans to control costs. Consider using [](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html) to monitor costs and [](https://docs.aws.amazon.com/waf/latest/developerguide/waf-chapter.html) to manage API requests. Optional.
  <Expandable title="properties">
    <ResponseField name="limit" type="number">
      The maximum number of API requests permitted during a specified quota period (day, week, or month) for the usage plan, as configured in the quota settings. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="offset" type="number">
      Specifies the number of requests that are deducted from the quota limit at the beginning of each period, effectively reducing the total number of requests allowed for that period. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="period" type="string">
      The time period (DAY, WEEK, or MONTH) over which the usage plan's request quota is measured and enforced. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the key-value tags to assign to the usage plan, which AWS uses for cost allocation and resource management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Defines the key of a user-defined tag attached to the API Gateway usage plan, used for metadata, cost allocation, and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The tag value paired with a tag key on the API Gateway usage plan, used for cost allocation, resource organization, and IAM-based access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="throttle" type="object">
  ``ThrottleSettings`` is a property of the [AWS::ApiGateway::UsagePlan](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-usageplan.html) resource that specifies the overall request rate (average requests per second) and burst capacity when users call your REST APIs. Optional.
  <Expandable title="properties">
    <ResponseField name="burst_limit" type="number">
      The maximum API request rate limit over a time-varying window of one second, defining the burst limit for the usage plan's throttling settings. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rate_limit" type="number">
      Sets the steady-state request rate limit (in requests per second) allowed for API requests covered by the usage plan's throttling configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="usage_plan_name" type="string">
  A friendly name for the usage plan, used to identify it in the API Gateway console and API calls. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS API Gateway to this usage plan, used as the resource's id. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

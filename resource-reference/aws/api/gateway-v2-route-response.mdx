`aws_api_gateway_v2_route_response` defines the response a WebSocket API route sends back after its `aws_api_gateway_v2_integration_response` runs, part of the two-way message flow WebSocket APIs support that HTTP APIs don't need.

## Input properties

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="model_selection_expression" type="string">
  The model selection expression for the route response. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="response_models" type="any">
  The response models for the route response. Optional.
</ResponseField>

<ResponseField name="response_parameters" type="any">
  A map of route response parameter names (e.g., header.x-custom-header) to a boolean indicating whether that parameter is required in the route response. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="route_id" type="string" required>
  The route ID for this API gateway v2 route response. Required.
</ResponseField>

<ResponseField name="route_response_key" type="string" required>
  The route response key. Required.
</ResponseField>

## Output properties

<ResponseField name="route_response_id" type="string">
  The unique identifier that AWS API Gateway assigns to the route response upon creation, returned as a read-only value for referencing the route response in subsequent API operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

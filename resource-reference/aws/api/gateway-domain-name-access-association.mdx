`aws_api_gateway_domain_name_access_association` links a real VPC endpoint to an `aws_api_gateway_domain_name`, restricting that private custom domain to be reachable only through the associated endpoint rather than from anywhere with network access.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway domain name access association"})

    		ubx.Resource(api.GatewayDomainNameAccessAssociation, "example", api.GatewayDomainNameAccessAssociationConfig{
    			AccessAssociationSource:     "example",
    			AccessAssociationSourceType: "example",
    			DomainNameArn:               "arn:aws:iam::123456789012:policy/example",
    			Tags:                        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_association_source" type="string" required>
  The source of the domain name access association resource. Required.
</ResponseField>

<ResponseField name="access_association_source_type" type="string" required>
  The source type of the domain name access association resource. Required.
</ResponseField>

<ResponseField name="domain_name_arn" type="string" required>
  The amazon resource name (ARN) of the domain name resource. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of arbitrary tags (key-value pairs) to associate with the domainname access association. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="domain_name_access_association_arn" type="string">
  The amazon resource name (ARN) of the domain name access association resource. Computed by AWS after `ship`.
</ResponseField>

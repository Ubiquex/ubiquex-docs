`aws_api_gateway_request_validator` attaches to an `aws_api_gateway_method` and rejects malformed requests, missing required parameters or a body that doesn't match its `aws_api_gateway_model`, before they ever reach the backend integration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway request validator"})

    		ubx.Resource(api.GatewayRequestValidator, "example", api.GatewayRequestValidatorConfig{
    			RestApiId:                 "example",
    			Name:                      "example",
    			ValidateRequestBody:       true,
    			ValidateRequestParameters: true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string">
  Specifies the name of the API Gateway request validator for identification; if omitted, API Gateway generates a name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>
  The ID of the REST API to which this request validator belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="validate_request_body" type="bool">
  Indicates whether the request validator checks the request body against the configured model schema for the API method. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="validate_request_parameters" type="bool">
  Indicates whether this request validator validates the query string and header parameters of incoming API requests. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="request_validator_id" type="string">
  The unique identifier assigned by API Gateway to the request validator, returned after creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_api_gateway_v2_api_gateway_managed_overrides` lets specific settings on an API Gateway-managed `aws_api_gateway_v2_stage` be overridden without disconnecting the stage from Gateway's own automatic management of it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway v2 api gateway managed overrides"})

    		ubx.Resource(api.GatewayV2ApiGatewayManagedOverrides, "example", api.GatewayV2ApiGatewayManagedOverridesConfig{
    			ApiId:       "example",
    			Integration: map[string]any{"description": "example"},
    			Route:       map[string]any{"authorization_scopes": []string{"example"}},
    			Stage:       map[string]any{"access_log_settings": map[string]any{"destination_arn": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="api_id" type="string" required>
  The ID of the API for which to override the configuration of API Gateway-managed resources. Required.
</ResponseField>

<ResponseField name="integration" type="object">
  The integration property is an object that overrides integration settings, such as integration type, HTTP method, payload format version, and timeout, for all integrations defined in the API's OpenAPI definition. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      The description of the integration. Optional.
    </ResponseField>
    <ResponseField name="integration_method" type="string">
      Specifies the integration's HTTP method type. For WebSocket APIs, if you use a Lambda integration, you must set the integration method to POST. Optional.
    </ResponseField>
    <ResponseField name="payload_format_version" type="string">
      Specifies the format of the payload sent to an integration. Required for HTTP APIs. For HTTP APIs, supported values for Lambda proxy integrations are 1.0 and 2.0. For all other integrations, 1.0 is the only supported value Optional.
    </ResponseField>
    <ResponseField name="timeout_in_millis" type="number">
      Custom timeout between 50 and 29,000 milliseconds for WebSocket APIs and between 50 and 30,000 milliseconds for HTTP APIs. The default timeout is 29 seconds for WebSocket APIs and 30 seconds for HTTP APIs. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="route" type="object">
  Overrides the configuration of a specific Route in an API Gateway v2 (WebSocket or HTTP) API by specifying properties such as authorization settings, request models, and route response selection expression, replacing the managed defaults. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="authorization_scopes" type="list(string)">
      The authorization scopes supported by this route. Optional.
    </ResponseField>
    <ResponseField name="authorization_type" type="string">
      The authorization type for the route. To learn more, see AuthorizationType. Optional.
    </ResponseField>
    <ResponseField name="authorizer_id" type="string">
      The identifier of the Authorizer resource to be associated with this route. The authorizer identifier is generated by API Gateway when you created the authorizer. Optional.
    </ResponseField>
    <ResponseField name="operation_name" type="string">
      The operation name for the route. Optional.
    </ResponseField>
    <ResponseField name="target" type="string">
      For HTTP integrations, specify a fully qualified URL. For Lambda integrations, specify a function ARN. The type of the integration will be HTTP_PROXY or AWS_PROXY, respectively. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

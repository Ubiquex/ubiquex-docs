`aws_api_gateway_base_path_mapping` maps a path segment on an `aws_api_gateway_domain_name` to a specific REST API and stage, the real mechanism that lets one custom domain front several different APIs at different base paths.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own gateway base path mapping"})

    		ubx.Resource(api.GatewayBasePathMapping, "ci-runner", api.GatewayBasePathMappingConfig{
    			DomainName: "example-domain-name",
    			BasePath:   "example",
    			RestApiId:  "example",
    			Stage:      "example",
    		})
    	}))
    }

## Properties

<ResponseField name="base_path" type="string">
  Specifies the base path of the custom domain that maps to the API, such that requests to that path are routed to the associated API and stage; if not set, the API is served at the root of the domain (path '/'). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The custom domain name (e.g., api.example.com) registered in API Gateway to which this base path mapping is attached, matching the DomainName property of an AWS::ApiGateway::DomainName resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string">
  The ID of the API Gateway REST API to which the base path mapping routes traffic. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="stage" type="string">
  The name of the API Gateway stage that the base path mapping targets. Optional. **(AI-inferred)**
</ResponseField>

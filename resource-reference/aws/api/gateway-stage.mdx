---
title: "aws_api_gateway_stage"
description: "`aws_api_gateway_stage` is a named, addressable environment (`prod`, `dev`, and similar) that points at a specific `aws_api_gateway_deployment`."
---

Callers hit a stage's own URL, and promoting a new version means moving the stage to point at a new deployment, not editing the API in place.

## Properties

<ResponseField name="access_log_setting" type="object">
  The ``AccessLogSetting`` property type specifies settings for logging access in this stage. ``AccessLogSetting`` is a property of the [AWS::ApiGateway::Stage](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-stage.html) resource. Optional.
  <Expandable title="properties">
    <ResponseField name="destination_arn" type="string">
      The Amazon Resource Name (ARN) of the CloudWatch Logs log group or Kinesis Data Firehose delivery stream to receive access logs. If you specify a Kinesis Data Firehose delivery stream, the stream name must begin with ``amazon-apigateway-``. This parameter is required to enable access logging. Optional.
    </ResponseField>
    <ResponseField name="format" type="string">
      A single line format of the access logs of data, as specified by selected [$context variables](https://docs.aws.amazon.com/apigateway/latest/developerguide/api-gateway-mapping-template-reference.html#context-variable-reference). The format must include at least ``$context.requestId``. This parameter is required to enable access logging. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cache_cluster_enabled" type="bool">
  Indicates whether a cache cluster is enabled for the API Gateway stage, allowing responses to be cached for performance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cache_cluster_size" type="string">
  Specifies the cache cluster size (in gigabytes) for the API Gateway stage, using string values such as '0.5' or '1.6' when caching is enabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="canary_setting" type="object">
  Configures the canary deployment settings for the stage, including the percentage of traffic to route to the canary deployment, the deployment ID, and optional stage variable overrides and cache usage. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="deployment_id" type="string">
      The ID of the deployment that the canary will route a percentage of traffic to, allowing you to test changes before shifting all traffic to that deployment. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="percent_traffic" type="number">
      Specifies the percentage of traffic that API Gateway routes to the canary deployment. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stage_variable_overrides" type="any">
      A map of stage variable names to values that temporarily override the stage's normal variables for canary traffic in the API Gateway stage, allowing different configuration for the canary version. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="use_stage_cache" type="bool">
      Indicates whether the canary should use the stage cache, enabling the canary's traffic to share the cache configured for the API Gateway stage. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="client_certificate_id" type="string">
  The ID of the client certificate that API Gateway uses to authenticate client requests to the stage. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="deployment_id" type="string">
  The ID of the API Gateway deployment that this stage points to, determining which version of the API is exposed at this stage's endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A description of the API Gateway stage, providing additional context about its purpose or contents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="documentation_version" type="string">
  The identifier of the API documentation version to associate with this stage, controlling which published documentation snapshot is exposed for the stage. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="method_settings" type="list(object)">
  Configures per-method settings for the stage, including throttling, caching, metrics, and logging, keyed by method path. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cache_data_encrypted" type="bool">
      Specifies whether the method-level cache in the API Gateway stage encrypts cached response data before storing it. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="cache_ttl_in_seconds" type="number">
      Specifies the time-to-live (TTL) duration, in seconds, for cached responses for a specific method in the API Gateway stage, controlling how long API Gateway caches a method's response before forwarding a new request to the backend. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="caching_enabled" type="bool">
      Enables or disables API caching for this stage's method, so responses are cached and served from the cache until the cache TTL expires. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="data_trace_enabled" type="bool">
      Enables data tracing for the method, capturing full request and response payloads in execution logs. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="http_method" type="string">
      The HTTP method (for example GET, POST, or *) to which these method settings apply, where * matches all methods. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="logging_level" type="string">
      Specifies the logging level (OFF, ERROR, or INFO) for the method's execution logs in API Gateway. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metrics_enabled" type="bool">
      Enables CloudWatch metrics for the API Gateway method associated with this method setting. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_path" type="string">
      The resource path (e.g., '/pets') in the API Gateway API for which these method settings apply, used together with the HTTP method to identify a specific method on the stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="throttling_burst_limit" type="number">
      Sets the maximum number of requests per second that API Gateway can serve for the method during a burst, used to control throttling behavior. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="throttling_rate_limit" type="number">
      Sets the maximum steady-state request rate (requests per second) allowed for a method's throttling configuration in this API Gateway stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

</ResponseField>

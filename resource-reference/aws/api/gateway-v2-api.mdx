`aws_api_gateway_v2_api` creates an HTTP API or WebSocket API, API Gateway v2's lighter-weight, lower-latency alternative to a v1 REST API, purpose-built for proxying to Lambda or an HTTP backend rather than the full feature set REST APIs offer.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway v2 api"})

    		ubx.Resource(api.GatewayV2Api, "example", api.GatewayV2ApiConfig{
    			Name:                      "example",
    			ApiKeySelectionExpression: "example",
    			BasePath:                  "example",
    			Body:                      "example",
    			BodyS3Location:            map[string]any{"bucket": "example"},
    			CorsConfiguration:         map[string]any{"allow_credentials": true},
    			CredentialsArn:            "arn:aws:iam::123456789012:policy/example",
    			Description:               "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_key_selection_expression" type="string">
  An API key selection expression. Supported only for WebSocket APIs. See [API Key Selection Expressions](https://docs.aws.amazon.com/apigateway/latest/developerguide/apigateway-websocket-api-selection-expressions.html#apigateway-websocket-api-apikey-selection-expressions). Optional.
</ResponseField>

<ResponseField name="base_path" type="string">
  Specifies how to interpret the base path of the API during import. Valid values are ``ignore``, ``prepend``, and ``split``. The default value is ``ignore``. To learn more, see [Set the OpenAPI basePath Property](https://docs.aws.amazon.com/apigateway/latest/developerguide/api-gateway-import-api-basePath.html). Supported only for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="body" type="any">
  The OpenAPI definition. Supported only for HTTP APIs. To import an HTTP API, you must specify a ``Body`` or ``BodyS3Location``. If you specify a ``Body`` or ``BodyS3Location``, don't specify CloudFormation resources such as ``AWS::ApiGatewayV2::Authorizer`` or ``AWS::ApiGatewayV2::Route``. API Gateway doesn't support the combination of OpenAPI and CloudFormation resources. Optional.
</ResponseField>

<ResponseField name="body_s3_location" type="object">
  The ``BodyS3Location`` property specifies an S3 location from which to import an OpenAPI definition. Supported only for HTTP APIs. Optional.
  <Expandable title="properties">
    <ResponseField name="bucket" type="string">
      The S3 bucket that contains the OpenAPI definition to import. Required if you specify a ``BodyS3Location`` for an API. Optional.
    </ResponseField>
    <ResponseField name="etag" type="string">
      The Etag of the S3 object. Optional.
    </ResponseField>
    <ResponseField name="key" type="string">
      The key of the S3 object. Required if you specify a ``BodyS3Location`` for an API. Optional.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of the S3 object. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cors_configuration" type="object">
  The ``Cors`` property specifies a CORS configuration for an API. Supported only for HTTP APIs. See [Configuring CORS](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-cors.html) for more information. Optional.
  <Expandable title="properties">
    <ResponseField name="allow_credentials" type="bool">
      Specifies whether credentials are included in the CORS request. Supported only for HTTP APIs. Optional.
    </ResponseField>
    <ResponseField name="allow_headers" type="list(string)">
      Represents a collection of allowed headers. Supported only for HTTP APIs. Optional.
    </ResponseField>
    <ResponseField name="allow_methods" type="list(string)">
      Represents a collection of allowed HTTP methods. Supported only for HTTP APIs. Optional.
    </ResponseField>
    <ResponseField name="allow_origins" type="list(string)">
      Represents a collection of allowed origins. Supported only for HTTP APIs. Optional.
    </ResponseField>
    <ResponseField name="expose_headers" type="list(string)">
      Represents a collection of exposed headers. Supported only for HTTP APIs. Optional.
    </ResponseField>
    <ResponseField name="max_age" type="number">
      The number of seconds that the browser should cache preflight request results. Supported only for HTTP APIs. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credentials_arn" type="string">
  This property is part of quick create. It specifies the credentials required for the integration, if any. For a Lambda integration, three options are available. To specify an IAM Role for API Gateway to assume, use the role's Amazon Resource Name (ARN). To require that the caller's identity be passed through from the request, specify ``arn:aws:iam::*:user/*``. To use resource-based permissions on supported AWS services, specify ``null``. Currently, this property is not used for HTTP integrations. Supported only for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the API. Optional.
</ResponseField>

<ResponseField name="disable_execute_api_endpoint" type="bool">
  Specifies whether clients can invoke your API by using the default ``execute-api`` endpoint. By default, clients can invoke your API with the default https://&#123;api_id&#125;.execute-api.&#123;region&#125;.amazonaws.com endpoint. To require that clients use a custom domain name to invoke your API, disable the default endpoint. Optional.
</ResponseField>

<ResponseField name="disable_schema_validation" type="bool">
  Avoid validating models when creating a deployment. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="fail_on_warnings" type="bool">
  Specifies whether to rollback the API creation when a warning is encountered. By default, API creation continues if a warning is encountered. Optional.
</ResponseField>

<ResponseField name="ip_address_type" type="string">
  The IP address types that can invoke the API. Use ``ipv4`` to allow only IPv4 addresses to invoke your API, or use ``dualstack`` to allow both IPv4 and IPv6 addresses to invoke your API. Don’t use IP address type for an HTTP API based on an OpenAPI specification. Instead, specify the IP address type in the OpenAPI specification. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the API. Required unless you specify an OpenAPI definition for ``Body`` or ``S3BodyLocation``. Optional.
</ResponseField>

<ResponseField name="protocol_type" type="string">
  The API protocol. Valid values are ``WEBSOCKET`` or ``HTTP``. Required unless you specify an OpenAPI definition for ``Body`` or ``S3BodyLocation``. Optional.
</ResponseField>

<ResponseField name="route_key" type="string">
  This property is part of quick create. If you don't specify a ``routeKey``, a default route of ``$default`` is created. The ``$default`` route acts as a catch-all for any request made to your API, for a particular stage. The ``$default`` route key can't be modified. You can add routes after creating the API, and you can update the route keys of additional routes. Supported only for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="route_selection_expression" type="string">
  The route selection expression for the API. For HTTP APIs, the ``routeSelectionExpression`` must be ``$&#123;request.method&#125; $&#123;request.path&#125;``. If not provided, this will be the default for HTTP APIs. This property is required for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  The collection of tags. Each tag element is associated with a given resource. Optional.
</ResponseField>

<ResponseField name="target" type="string">
  This property is part of quick create. Quick create produces an API with an integration, a default catch-all route, and a default stage which is configured to automatically deploy changes. For HTTP integrations, specify a fully qualified URL. For Lambda integrations, specify a function ARN. The type of the integration will be HTTP_PROXY or AWS_PROXY, respectively. Supported only for HTTP APIs. Optional.
</ResponseField>

<ResponseField name="version" type="string">
  A version identifier for the API. Optional.
</ResponseField>

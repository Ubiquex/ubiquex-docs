`aws_api_gateway_documentation_part` is one documented fragment, a description of a specific method, resource, or parameter, that rolls up into an `aws_api_gateway_documentation_version` for an `aws_api_gateway_rest_api`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway documentation part"})

    		ubx.Resource(api.GatewayDocumentationPart, "example", api.GatewayDocumentationPartConfig{
    			Location:   map[string]any{"name": "example-name"},
    			Properties: "example",
    			RestApiId:  "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="location" type="object" required>
  The ``Location`` property specifies the location of the Amazon API Gateway API entity that the documentation applies to. ``Location`` is a property of the [AWS::ApiGateway::DocumentationPart](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-documentationpart.html) resource. For more information about each property, including constraints and valid values, see [DocumentationPart](https://docs.aws.amazon.com/apigateway/latest/api/API_DocumentationPartLocation.html) in the *Amazon API Gateway REST API Reference*. Required.
  <Expandable title="properties">
    <ResponseField name="method" type="string">
      Specifies the HTTP method (e.g., GET, POST) of the API method that this documentation part applies to, used when the location type is METHOD or a method-specific entity. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the targeted API entity (such as an authorizer, model, path parameter, query parameter, header, or body) that this documentation part applies to, required for location types that identify a specific entity by name. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="path" type="string">
      The URL path of the API resource (e.g., /pets) to which this documentation part applies, used when the location type is PATH or RESOURCE. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="status_code" type="string">
      Specifies the HTTP status code (e.g., 200, 404) of the API response for which this documentation part applies, used when the location type is set to RESPONSE or RESPONSE_BODY. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of API entity (such as API, METHOD, MODEL, RESOURCE, AUTHORIZER, QUERY_PARAMETER, REQUEST_BODY, or HTTP_METHOD) that the documentation part targets, determining which component of the API the documentation describes. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="properties" type="string" required>
  The documentation content (plain text or Markdown) that describes the targeted API entity, as defined by the Location, and is displayed by API Gateway. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>
  The identifier of the API Gateway REST API to which this documentation part belongs. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="documentation_part_id" type="string">
  This read-only attribute contains the unique ID that Amazon API Gateway assigns to the documentation part when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

---
title: "aws_api_gateway_rest_api"
description: "`aws_api_gateway_rest_api` creates the REST API itself, the container for an API Gateway v1 (REST API) deployment."
---

Resources, methods, and deployments all nest inside it, and it's the unit that gets versioned and deployed to a stage as a whole.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway rest apigateway"})

    		ubx.Resource(apigateway.RestApi, "example", apigateway.RestApiConfig{
    			Name:                      "example",
    			ApiKeySourceType:          "example",
    			BinaryMediaTypes:          []string{"example"},
    			Body:                      "example",
    			BodyS3Location:            map[string]any{"bucket": "example"},
    			CloneFrom:                 "example",
    			Description:               "Managed by ubx.",
    			DisableExecuteApiEndpoint: true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_key_source_type" type="string">
  Determines whether API keys are sourced from the request header or from an authorizer, with allowed values HEADER and AUTHORIZER. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="binary_media_types" type="list(string)">
  Defines the binary media types (e.g., image/png, application/octet-stream) that the REST API treats as binary data, enabling API Gateway to handle binary payloads for those content types. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="body" type="any">
  An OpenAPI specification that defines a set of RESTful APIs in JSON format. For YAML templates, you can also provide the specification in YAML format. Optional.
</ResponseField>

<ResponseField name="body_s3_location" type="object">
  ``S3Location`` is a property of the [AWS::ApiGateway::RestApi](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-restapi.html) resource that specifies the Amazon S3 location of a OpenAPI (formerly Swagger) file that defines a set of RESTful APIs in JSON or YAML. On January 1, 2016, the Swagger Specification was donated to the [OpenAPI initiative](https://docs.aws.amazon.com/https://www.openapis.org/), becoming the foundation of the OpenAPI Specification. Optional.
  <Expandable title="properties">
    <ResponseField name="bucket" type="string">
      The name of the S3 bucket where the OpenAPI file is stored. Optional.
    </ResponseField>
    <ResponseField name="etag" type="string">
      The Amazon S3 ETag (a file checksum) of the OpenAPI file. If you don't specify a value, API Gateway skips ETag validation of your OpenAPI file. Optional.
    </ResponseField>
    <ResponseField name="key" type="string">
      The file name of the OpenAPI file (Amazon S3 object name). Optional.
    </ResponseField>
    <ResponseField name="version" type="string">
      For versioning-enabled buckets, a specific version of the OpenAPI file. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="clone_from" type="string">
  The ID of an existing RestApi from which to clone the configuration to create this API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Specifies a user-defined description for the REST API, which is displayed in the API Gateway console to document the API's purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="disable_execute_api_endpoint" type="bool">
  When set to true, disables the default execute-api endpoint for the REST API, so the API is accessible only through custom domain names. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_access_mode" type="string">
  Optional.
</ResponseField>

<ResponseField name="endpoint_configuration" type="object">
  The ``EndpointConfiguration`` property type specifies the endpoint types and IP address types of a REST API. ``EndpointConfiguration`` is a property of the [AWS::ApiGateway::RestApi](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-restapi.html) resource. Optional.
  <Expandable title="properties">
    <ResponseField name="ip_address_type" type="string">
      Specifies the IP address type for the API Gateway REST API endpoint, supporting values of 'ipv4' or 'ipv6' to indicate whether the endpoint uses IPv4 or IPv6 addressing. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="types" type="list(string)">
      The list of endpoint types for the REST API, specifying whether it is deployed at an edge location, in a specific region, or privately, with valid values EDGE, REGIONAL, and PRIVATE. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpc_endpoint_ids" type="list(string)">
      A list of VPC endpoint IDs attached to the REST API, used to create regional or private endpoints that allow access from within those VPC endpoints. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="fail_on_warnings" type="bool">
  When creating or updating the REST API from an OpenAPI definition, setting this to true causes the operation to fail if any warnings are generated, while false (the default) allows warnings to be ignored. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="minimum_compression_size" type="number">
  Sets the minimum threshold in bytes that a response payload must reach before API Gateway applies compression to the response, enabling gzip compression for larger payloads. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="mode" type="string">
  This property applies only when you use OpenAPI to define your REST API. The ``Mode`` determines how API Gateway handles resource updates. Valid values are ``overwrite`` or ``merge``. For ``overwrite``, the new API definition replaces the existing one. The existing API identifier remains unchanged. For ``merge``, the new API definition is merged with the existing API. If you don't specify this property, a default value is chosen. For REST APIs created before March 29, 2021, the default is ``overwrite``. For REST APIs created after March 29, 2021, the new API definition takes precedence, but any container types such as endpoint configurations and binary media types are merged with the existing API. Use the default mode to define top-level ``RestApi`` properties in addition to using OpenAPI. Generally, it's preferred to use API Gateway's OpenAPI extensions to model these properties. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the RestApi. A name is required if the REST API is not based on an OpenAPI specification. Optional.
</ResponseField>

<ResponseField name="parameters" type="any">
  Map of API Gateway configuration parameters for the REST API, supporting the 'endpointConfigurationTypes' (comma-separated list of endpoint types) and 'binaryMediaTypes' (comma-separated list of binary media types) keys. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="policy" type="any">
  A policy document that contains the permissions for the ``RestApi`` resource. To set the ARN for the policy, use the ``!Join`` intrinsic function with ``""`` as delimiter and values of ``"execute-api:/"`` and ``"*"``. Optional.
</ResponseField>

<ResponseField name="security_policy" type="string">
  Specifies the minimum TLS version allowed for the REST API's endpoint, either 'TLS_1_0' or 'TLS_1_2'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Defines a list of key-value pairs to tag the API Gateway REST API, enabling cost allocation, resource-level access control, and management of the API resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A tag key that you assign to this API Gateway REST API, used for cost allocation and organizational metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value for a user-defined tag assigned to the API Gateway REST API, used for metadata and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

</ResponseField>

<ResponseField name="root_resource_id" type="string">
  The unique identifier of the root resource (the top-level path '/') of the API Gateway REST API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

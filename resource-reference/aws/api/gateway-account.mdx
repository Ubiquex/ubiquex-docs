`aws_api_gateway_account` configures account-wide REST API Gateway settings, most notably the IAM role API Gateway assumes to push execution logs to CloudWatch, applying once per account rather than per `aws_api_gateway_rest_api`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway account"})

    		ubx.Resource(api.GatewayAccount, "example", api.GatewayAccountConfig{
    			CloudWatchRoleArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.api import GatewayAccount, GatewayAccountConfig

    def describe():

        ubx.resource(GatewayAccount, "example", GatewayAccountConfig(
            cloud_watch_role_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="cloud_watch_role_arn" type="string">
  The ARN of the IAM role that Amazon API Gateway assumes to write logs and metrics to CloudWatch. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The id is the AWS account ID for which the API Gateway account settings are configured. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

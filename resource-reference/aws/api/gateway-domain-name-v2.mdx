`aws_api_gateway_domain_name_v2` is the newer resource type for the same custom-domain concept as `aws_api_gateway_domain_name`, supporting multi-level base path mappings that the original resource type doesn't.

## Input properties

<ResponseField name="certificate_arn" type="string">
  The ARN of an AWS Certificate Manager (ACM) certificate used to secure the custom domain name's endpoint, such as edge-optimized or regional, for API Gateway v2. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_name" type="string">
  The custom domain name (e.g., api.example.com) that this API Gateway v2 domain name configuration represents, which must be owned by the user and is used as the public endpoint for invoking the associated APIs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_access_mode" type="string">
  Optional.
</ResponseField>

<ResponseField name="endpoint_configuration" type="object">
  Optional.
  <Expandable title="properties">
    <ResponseField name="ip_address_type" type="string">
      Specifies whether the API Gateway custom domain name endpoint uses IPv4 only (IPV4) or both IPv4 and IPv6 (DUALSTACK). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="types" type="list(string)">
      Specifies the endpoint type for the domain name, where 'REGIONAL' is the only supported value in API Gateway v2 to indicate a regional endpoint. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="policy" type="any">
  A JSON string specifying an IAM resource policy that controls access to the API Gateway domain name's endpoints by allowing or denying invoking principals, source IPs, or VPC origins. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="routing_mode" type="string">
  The valid routing modes are [BASE_PATH_MAPPING_ONLY], [ROUTING_RULE_THEN_BASE_PATH_MAPPING] and [ROUTING_RULE_ONLY]. All other inputs are invalid. Optional.
</ResponseField>

<ResponseField name="security_policy" type="string">
  The security_policy field specifies the minimum Transport Layer Security (TLS) protocol version for the API Gateway custom domain name's endpoint, with supported values of 'TLS_1_0' and 'TLS_1_2'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags (list of objects with Key and Value) to associate with the API Gateway v2 domain name, enabling metadata management and cost allocation. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the API Gateway custom domain name, which you can use to categorize the resource for cost allocation and IAM-based access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value for a tag key assigned to the API Gateway domain name v2 resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="domain_name_arn" type="string">
  The amazon resource name (ARN) of the domain name resource. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="domain_name_id" type="string">
  The computed unique identifier for the API Gateway v2 domain name resource, which is the domain name string itself used as the resource's primary key in the service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

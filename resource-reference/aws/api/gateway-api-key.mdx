`aws_api_gateway_api_key` issues a key that identifies a caller against an `aws_api_gateway_usage_plan`, the real mechanism REST APIs use to meter and throttle usage per consumer rather than per IAM identity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own gateway api key"})

    		ubx.Resource(api.GatewayApiKey, "ci-runner", api.GatewayApiKeyConfig{
    			Name:               "ci-runner",
    			CustomerId:         "example",
    			Description:        "Managed by ubx.",
    			Enabled:            true,
    			GenerateDistinctId: true,
    			StageKeys:          []map[string]any{{"rest_api_id": "example"}},
    			Tags:               []map[string]any{{"key": "example"}},
    			Value:              "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="customer_id" type="string">
  Specifies an optional customer identifier that can be associated with the API key for tracking or organizational purposes. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Specifies a user-defined description of the API key, which can be used to provide additional context or metadata about the key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Indicates whether the API key is enabled for use, where setting it to false disables the key so that client requests using the key are rejected by API Gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="generate_distinct_id" type="bool">
  When set to true, it instructs AWS to generate a unique API key value automatically, so you do not need to provide a Value and the resulting key is guaranteed distinct from other API keys. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  A name for the API key. If you don't specify a name, CFN generates a unique physical ID and uses that ID for the API key name. For more information, see [Name Type](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-properties-name.html). If you specify a name, you cannot perform updates that require replacement of this resource. You can perform updates that require no or some interruption. If you must replace the resource, specify a new name. Optional.
</ResponseField>

<ResponseField name="stage_keys" type="list(object)">
  A list of stage keys, each identifying an API Gateway REST API and stage, that associates the API key with those stages so it can be used to access their methods. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="rest_api_id" type="string">
      The ID of the REST API that this API key is tied to for the stage key entry, indicating which API's stage the key can access. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stage_name" type="string">
      The name of the API Gateway stage to which this API key is associated, enabling the key to access APIs in that stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of tags, each containing a Key and Value, to attach to the API Gateway API key for cost allocation and resource management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the API key, which can be used for metadata, cost tracking, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="value" type="string">
  The alphanumeric string value of the API key; if omitted, API Gateway generates a unique value. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="apikey_id" type="string">
  The unique identifier that API Gateway assigns to the API key. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

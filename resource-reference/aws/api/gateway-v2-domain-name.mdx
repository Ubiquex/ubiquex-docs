`aws_api_gateway_v2_domain_name` registers a custom domain for HTTP or WebSocket APIs, provisioning the TLS certificate and endpoint that requests terminate at before an `aws_api_gateway_v2_api_mapping` routes them to a specific API and stage.

## Input properties

<ResponseField name="domain_name" type="string" required>
  The custom domain name for your API in Amazon API Gateway. Uppercase letters and the underscore (``_``) character are not supported. Required.
</ResponseField>

<ResponseField name="domain_name_configurations" type="list(object)">
  The domain name configurations. Optional.
  <Expandable title="properties">
    <ResponseField name="certificate_arn" type="string">
      The ARN of an AWS Certificate Manager certificate that is used to secure the custom domain name's TLS connections. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="certificate_name" type="string">
      Specifies a customer-friendly name for the AWS Certificate Manager (ACM) certificate associated with the API Gateway v2 domain name configuration, used for identification purposes alongside the certificate ARN. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="endpoint_type" type="string">
      Defines the endpoint type for the API Gateway domain name, either 'REGIONAL' or 'EDGE', determining how the domain name is routed within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ip_address_type" type="string">
      Specifies the IP address type (IPv4 or dual-stack) used by the custom domain name's endpoint, controlling whether the domain resolves to IPv4-only or both IPv4 and IPv6 addresses. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ownership_verification_certificate_arn" type="string">
      The Amazon Resource Name (ARN) of an AWS Certificate Manager (ACM) certificate used to verify ownership of the custom domain name in the API Gateway v2 domain name configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="security_policy" type="string">
      Specifies the TLS security policy (TLS_1_0 or TLS_1_2) applied to the custom domain name's API Gateway HTTPS endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="mutual_tls_authentication" type="object">
  If specified, API Gateway performs two-way authentication between the client and the server. Clients must present a trusted certificate to access your API. Optional.
  <Expandable title="properties">
    <ResponseField name="truststore_uri" type="string">
      An Amazon S3 URL that specifies the truststore for mutual TLS authentication, for example, ``s3://bucket-name/key-name``. The truststore can contain certificates from public or private certificate authorities. To update the truststore, upload a new version to S3, and then update your custom domain name to use the new version. To update the truststore, you must have permissions to access the S3 object. Optional.
    </ResponseField>
    <ResponseField name="truststore_version" type="string">
      The version of the S3 object that contains your truststore. To specify a version, you must have versioning enabled for the S3 bucket. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="routing_mode" type="string">
  The routing mode API Gateway uses to route traffic to your APIs. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  The collection of tags associated with a domain name. Optional.
</ResponseField>

## Output properties

<ResponseField name="domain_name_arn" type="string">
  The Amazon Resource Name (ARN) of the API Gateway v2 domain name, used to uniquely identify this domain for IAM policies and resource references. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="regional_domain_name" type="string">
  The regional domain name automatically assigned by API Gateway v2 to this domain name, serving as the regional endpoint target for routing traffic to the API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="regional_hosted_zone_id" type="string">
  The Amazon Route 53 hosted zone ID associated with the regional endpoint of this API Gateway v2 domain name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

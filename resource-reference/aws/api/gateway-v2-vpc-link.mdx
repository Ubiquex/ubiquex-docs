`aws_api_gateway_v2_vpc_link` lets an `aws_api_gateway_v2_api` integration reach a private resource inside a VPC (an internal load balancer, for instance) without that resource being exposed to the public internet, the v2 counterpart to a v1 REST API VPC link.

    		})

## Input properties

<ResponseField name="name" type="string" required>
  The name of the VPC link. Required.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  A list of security group IDs for the VPC link. Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  A list of subnet IDs to include in the VPC link. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  The collection of tags. Each tag element is associated with a given resource. Optional.
</ResponseField>

## Output properties

<ResponseField name="vpc_link_id" type="string">
  The service-generated unique identifier (VpcLinkId) assigned to the VPC link when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

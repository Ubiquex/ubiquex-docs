`aws_api_gateway_vpc_link` lets a REST API's integration reach a private resource inside a VPC, typically a Network Load Balancer in front of an internal service, without that resource ever being exposed publicly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	api "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/api"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own gateway vpc link"})

    		ubx.Resource(api.GatewayVpcLink, "ci-runner", api.GatewayVpcLinkConfig{
    			Name:        "ci-runner",
    			TargetArns:  []string{"example"},
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-defined textual description of the VPC link, used to identify and manage the link in API Gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The user-friendly name of the VPC link, which identifies it within API Gateway. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of arbitrary tags (key-value pairs) to associate with the VPC link. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Identifies the key of a user-defined tag attached to the API Gateway VPC Link, used to organize and categorize the resource via AWS tagging conventions. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value for a tag key attached to the VPC Link, enabling metadata-based management, cost allocation, and access control for the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_arns" type="list(string)" required>
  Specifies the Amazon Resource Names (ARNs) of the Network Load Balancers that the VPC link routes API traffic to, allowing API Gateway to access private resources in a VPC. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="vpc_link_id" type="string">
  The unique identifier (e.g., an alphanumeric string) assigned by AWS to this VPC link, used to reference the link in API Gateway configurations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_api_gateway_v2_stage` is a named, addressable environment for an HTTP or WebSocket API that points at a specific `aws_api_gateway_v2_deployment`, the v2 counterpart to a v1 REST API stage.

## Properties

<ResponseField name="access_log_settings" type="object">
  Configures access logging for the API Gateway stage, including the CloudWatch Logs destination ARN and the log format template. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="destination_arn" type="string">
      Specifies the Amazon Resource Name (ARN) of the CloudWatch Logs log group to which the API Gateway stage sends access logs. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="format" type="string">
      The format string used to customize the access log output for the API Gateway v2 stage, which can include API Gateway context variables such as $context.requestId and $context.identity.sourceIp. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api_id" type="string" required>
  The API identifier. Required.
</ResponseField>

<ResponseField name="auto_deploy" type="bool">
  Specifies whether updates to an API automatically trigger a new deployment. The default value is false. Optional.
</ResponseField>

<ResponseField name="client_certificate_id" type="string">
  The identifier of a client certificate for a Stage. Supported only for WebSocket APIs. Optional.
</ResponseField>

<ResponseField name="default_route_settings" type="object">
  The default route settings for the stage, including throttling, logging, and data trace settings, that apply to all routes unless a specific route overrides them. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_trace_enabled" type="bool">
      Enables detailed tracing (full request/response data capture) for the default route of the API Gateway stage, which is used with integration logging. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="detailed_metrics_enabled" type="bool">
      When true, enables detailed CloudWatch metrics for the default route of the API Gateway v2 stage. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="logging_level" type="string">
      Sets the logging level for the default route in the API Gateway v2 stage, controlling which execution logs are emitted (values such as ERROR, WARN, INFO, or OFF). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="throttling_burst_limit" type="number">
      Sets the throttling burst limit for the default route of the API Gateway v2 stage, controlling the maximum number of requests that can be handled before throttling is applied. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="throttling_rate_limit" type="number">
      Sets the per-second request rate limit for the default route throttling settings of the API Gateway v2 stage, used to control the maximum number of requests per second before throttling occurs. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="deployment_id" type="string">
  The deployment identifier for the API stage. Can't be updated if autoDeploy is enabled. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description for the API stage. Optional.
</ResponseField>

<ResponseField name="route_settings" type="any">
  Route settings for the stage. Optional.
</ResponseField>

<ResponseField name="stage_name" type="string" required>
  The stage name. Stage names can contain only alphanumeric characters, hyphens, and underscores, or be $default. Maximum length is 128 characters. Required.
</ResponseField>

<ResponseField name="stage_variables" type="any">
  A map that defines the stage variables for a Stage. Variable names can have alphanumeric and underscore characters, and the values must match [A-Za-z0-9-._~:/?#&=,]+. Optional.
</ResponseField>

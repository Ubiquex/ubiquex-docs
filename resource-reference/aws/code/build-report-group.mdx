`aws_code_build_report_group` collects real test and code-coverage reports generated by an `aws_code_build_project`'s own builds into one place, so results across many build runs can be reviewed and trended together instead of inspected one build log at a time.

## Input properties

<ResponseField name="delete_reports" type="bool">
  Indicates whether all reports associated with the report group are deleted when the CloudFormation stack deletes the report group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="export_config" type="object" required>
  Configures how test reports are exported from the report group, specifying either an S3 bucket destination or no export, including the S3 bucket, prefix, and encryption settings. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="export_config_type" type="string" required>
      Specifies the type of export destination for the report group's raw test results, which is either S3 or NO_EXPORT. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_destination" type="object">
      Defines the S3 bucket and object path where CodeBuild exports the test reports generated by this report group. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The name of the S3 bucket where CodeBuild exports the report group's test results. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="bucket_owner" type="string">
          The AWS account ID of the S3 bucket owner, used to verify the bucket is owned by the specified account before writing report export artifacts. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="encryption_disabled" type="bool">
          When true, disables encryption for the S3 bucket where CodeBuild exports the report group's artifacts. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="encryption_key" type="string">
          The ARN of the AWS KMS key used to encrypt the exported test report's S3 objects; if omitted, CodeBuild uses the default AWS managed key for Amazon S3. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="packaging" type="string">
          Specifies whether the report is packaged as a ZIP file or not when exported to the S3 destination, with valid values ZIP or NONE. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="path" type="string">
          Specifies the path (prefix) within the S3 bucket where the raw data of the report is exported. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the report group; if not provided, CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to associate with the report group for identifying, organizing, and managing the resource, such as for cost allocation and access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS CodeBuild report group, which can be used to organize, categorize, or track costs and access for the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of report group, which can be either TEST or CODE_COVERAGE, determining the kind of reports this group contains. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the CodeBuild report group, which uniquely identifies it within AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  This field is the Amazon Resource Name (ARN) of the CodeBuild report group, which serves as the unique identifier and is generated by AWS when the report group is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

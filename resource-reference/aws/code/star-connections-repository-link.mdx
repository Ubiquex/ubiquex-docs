`aws_code_star_connections_repository_link` ties a real, specific repository to an `aws_code_star_connections_connection`, a persistent reference CodePipeline's V2 pipeline types and other AWS services use for source actions rather than resolving the repository from the connection alone each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codestarconnections "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/codestarconnections"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own star connections repository link"})

    		ubx.Resource(codestarconnections.RepositoryLink, "example", codestarconnections.RepositoryLinkConfig{
    			ConnectionArn:    "arn:aws:iam::123456789012:policy/example",
    			OwnerId:          "example",
    			RepositoryName:   "example-repository-name",
    			EncryptionKeyArn: "arn:aws:iam::123456789012:policy/example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="connection_arn" type="string" required>
  The Amazon Resource Name (ARN) of the CodeStarConnection. The ARN is used as the connection reference when the connection is shared between AWS services. Required.
</ResponseField>

<ResponseField name="encryption_key_arn" type="string">
  The ARN of the KMS key that the customer can optionally specify to use to encrypt RepositoryLink properties. If not specified, a default key will be used. Optional.
</ResponseField>

<ResponseField name="owner_id" type="string" required>
  the ID of the entity that owns the repository. Required.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The repository for which the link is being created. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags applied to a RepositoryLink. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag key associated with the AWS CodeStar Connections repository link resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="provider_type" type="string">
  The name of the external provider where your third-party code repository is configured. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="repository_link_arn" type="string">
  A unique Amazon Resource Name (ARN) to designate the repository link. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="repository_link_id" type="string">
  A UUID that uniquely identifies the RepositoryLink. Computed by AWS after `ship`.
</ResponseField>

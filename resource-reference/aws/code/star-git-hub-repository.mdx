AWS discontinued creating and viewing CodeStar projects on July 31, 2024; resources CodeStar already created, including this repository, its source repos, pipelines, and builds, continue functioning unaffected.

## Input properties

<ResponseField name="code" type="object">
  Specifies the S3 bucket, key, and optional object version of a ZIP file containing the source code to be initially committed to the GitHub repository. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="s3" type="object" required>
      Specifies the S3 bucket and object key (and optionally object version) of the source code archive that AWS CodeStar uses to populate the GitHub repository. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The name of the S3 bucket that contains the source code archive used to populate the GitHub repository. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="key" type="string" required>
          The S3 object key (file path) of the source code archive in the specified S3 bucket that CodeStar uses to import the GitHub repository. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="object_version" type="string">
          The object version identifier of the S3 object that contains the source code to be committed to the GitHub repository, used to reference a specific version of the object when multiple versions exist in the bucket. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

  The unique identifier for the AWS CodeStar GitHub repository, which CloudFormation returns as the GitHub owner and repository name combined with a slash (e.g., `owner/repo`). Computed by AWS after `ship`. **(AI-inferred)**

---

`aws_code_deploy_deployment_group` is the real, specific set of EC2 instances, an Auto Scaling group, or an ECS service and load balancer, that an `aws_code_deploy_application`'s revisions actually get deployed to, along with when to reroute traffic and when to retire the old version.

  Indicates what happens when new Amazon EC2 instances are launched mid-deployment and do not receive the deployed application revision. If this option is set to UPDATE or is unspecified, CodeDeploy initiates one or more 'auto-update outdated instances' deployments to apply the deployed application revision to the new Amazon EC2 instances.

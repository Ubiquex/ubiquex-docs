`aws_code_star_connections_sync_configuration` configures real, automatic syncing of resources defined in a Git repository, through an `aws_code_star_connections_connection`, into deployed AWS resources whenever the repository changes, without a separate CI/CD pipeline stage to trigger it.

## Example

    ```go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/code"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own star connections sync configuration"})

    		ubx.Resource(code.StarConnectionsSyncConfiguration, "example", code.StarConnectionsSyncConfigurationConfig{
    			Branch:                  "example",
    			ConfigFile:              "example",
    			RepositoryLinkId:        "example",
    			ResourceName:            "example-resource-name",
    			RoleArn:                 "arn:aws:iam::123456789012:policy/example",
    			SyncType:                "example",
    			PublishDeploymentStatus: "example",
    			TriggerResourceUpdateOn: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="branch" type="string" required>
  The name of the branch of the repository from which resources are to be synchronized, Required.
</ResponseField>

<ResponseField name="config_file" type="string" required>
  The source provider repository path of the sync configuration file of the respective SyncType. Required.
</ResponseField>

<ResponseField name="publish_deployment_status" type="string">
  Whether to enable or disable publishing of deployment status to source providers. Optional.
</ResponseField>

<ResponseField name="repository_link_id" type="string" required>
  A UUID that uniquely identifies the RepositoryLink that the SyncConfig is associated with. Required.
</ResponseField>

<ResponseField name="resource_name" type="string" required>
  The name of the resource that is being synchronized to the repository. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The IAM Role that allows AWS to update CloudFormation stacks based on content in the specified repository. Required.
</ResponseField>

<ResponseField name="sync_type" type="string" required>
  The type of resource synchronization service that is to be configured, for example, CFN_STACK_SYNC. Required.
</ResponseField>

<ResponseField name="trigger_resource_update_on" type="string">
  When to trigger Git sync to begin the stack update. Optional.
</ResponseField>

## Output properties

<ResponseField name="owner_id" type="string">
  the ID of the entity that owns the repository. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="provider_type" type="string">
  The name of the external provider where your third-party code repository is configured. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="repository_name" type="string">
  The name of the repository that is being synced to. Computed by AWS after `ship`.
</ResponseField>

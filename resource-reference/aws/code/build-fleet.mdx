`aws_code_build_fleet` reserves a real, persistent pool of CodeBuild compute hosts that stay warm and ready, cutting a build's startup latency versus CodeBuild's default on-demand provisioning, at the cost of paying for the fleet's capacity even while it's idle.

## Input properties

<ResponseField name="base_capacity" type="number">
  The initial number of compute instances allocated to the CodeBuild fleet, serving as the baseline from which the fleet scales toward its maximum capacity. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="compute_configuration" type="object">
  Specifies the compute configuration for the CodeBuild fleet, including the disk size and machine type (e.g., General or ARM) used for build environments. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="disk" type="number">
      Specifies the amount of disk space (in GB) allocated to each compute instance in the code build fleet. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="instance_type" type="string">
      Specifies the EC2 instance type used by the compute fleet's compute configuration, such as m5.large or c5.xlarge, determining the underlying hardware for the build fleet. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="machine_type" type="string">
      The machine type of the CodeBuild fleet's compute configuration, which determines the processor architecture or GPU availability (e.g., GENERAL, ARM, GPU). Optional. **(AI-inferred)**
    </ResponseField>

      Defines the amount of memory allocated to each compute instance in an AWS CodeBuild fleet's compute configuration. Optional. **(AI-inferred)**

      The number of virtual CPUs (vCPUs) to allocate to each compute instance in the CodeBuild fleet. Optional. **(AI-inferred)**

  </Expandable>
</ResponseField>

<ResponseField name="compute_type" type="string">
  The compute type for the fleet's build instances, such as BUILD_GENERAL1_SMALL or BUILD_GENERAL1_LARGE, which determines the CPU and memory allocated to each build. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="environment_type" type="string">

</ResponseField>

        </ResponseField>
        <ResponseField name="type" type="string">

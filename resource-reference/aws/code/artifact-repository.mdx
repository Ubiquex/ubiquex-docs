`aws_code_artifact_repository` stores real software packages, polyglot by default, npm, Maven, PyPI, and others in the same repository, inside an `aws_code_artifact_domain`, either published directly or fetched on demand from a connected public repository like npmjs or Maven Central.

## Input properties

<ResponseField name="description" type="string">
  A text description of the repository. Optional.
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The name of the domain that contains the repository. Required.
</ResponseField>

<ResponseField name="external_connections" type="list(string)">
  A list of external connections associated with the repository. Optional.
</ResponseField>

<ResponseField name="permissions_policy_document" type="any">
  The access control resource policy on the provided repository. Optional.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The name of the repository. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS CodeArtifact repository, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag (key-value pair) applied to an AWS CodeArtifact repository, used to add metadata for organization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="upstreams" type="list(string)">
  A list of upstream repositories associated with the repository. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the repository. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="domain_owner" type="string">
  The 12-digit account ID of the AWS account that owns the domain. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the repository. This is used for GetAtt Computed by AWS after `ship`.
</ResponseField>

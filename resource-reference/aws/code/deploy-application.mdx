`aws_code_deploy_application` is CodeDeploy's own top-level container name, ensuring the correct combination of revision, `aws_code_deploy_deployment_config`, and `aws_code_deploy_deployment_group` gets referenced together each time a real deployment runs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	code "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/code"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own deploy application"})

    		ubx.Resource(code.DeployApplication, "ci-runner", code.DeployApplicationConfig{
    			ApplicationName: "example-application-name",
    			ComputePlatform: "example",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="application_name" type="string">
  A name for the application. If you don't specify a name, AWS CloudFormation generates a unique physical ID and uses that ID for the application name. Optional.
</ResponseField>

<ResponseField name="compute_platform" type="string">
  The compute platform that CodeDeploy deploys the application to. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The metadata that you apply to CodeDeploy applications to help you organize and categorize them. Each tag consists of a key and an optional value, both of which you define. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag attached to the CodeDeploy application. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

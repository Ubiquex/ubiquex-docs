`aws_code_build_source_credential` stores a real access token or app password for a source provider, GitHub, GitHub Enterprise, GitLab, Bitbucket, that an `aws_code_build_project` uses to clone private repositories.

## Input properties

<ResponseField name="auth_type" type="string" required>
  The type of authentication used by the credentials. Valid options are OAUTH, BASIC_AUTH, PERSONAL_ACCESS_TOKEN, CODECONNECTIONS, or SECRETS_MANAGER. Required.
</ResponseField>

<ResponseField name="server_type" type="string" required>
  The type of source provider. The valid options are GITHUB, GITHUB_ENTERPRISE, GITLAB, GITLAB_SELF_MANAGED, or BITBUCKET. Required.
</ResponseField>

<ResponseField name="token" type="string" required>
  For GitHub or GitHub Enterprise, this is the personal access token. For Bitbucket, this is either the access token or the app password. For the authType CODECONNECTIONS, this is the connectionArn. For the authType SECRETS_MANAGER, this is the secretArn. Required.
</ResponseField>

<ResponseField name="username" type="string">
  The Bitbucket username when the authType is BASIC_AUTH. This parameter is not valid for other types of source providers or connections. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the SourceCredential resource. Computed by AWS after `ship`.
</ResponseField>

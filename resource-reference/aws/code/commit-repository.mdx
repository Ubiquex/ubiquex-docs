`aws_code_commit_repository` creates a private, fully managed Git repository in AWS CodeCommit, encrypted at rest and in transit, supporting standard Git commands and tools. AWS CodeCommit stopped onboarding new customers on July 25, 2024; existing customers with a repository can continue creating additional ones and using the service as normal.

## Input properties

<ResponseField name="code" type="object">
  Defines the initial code to be committed to the repository, specifying the S3 source (bucket, key, and optional object version), target branch, and commit message. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="branch_name" type="string">
      The name of the branch in the repository to which the initial code (specified in the Code property) is committed when the repository is created. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3" type="object" required>
      The S3 location (bucket, key, and optional object version) from which AWS CodeCommit imports the code for the repository's initial commit. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The name of the Amazon S3 bucket that contains the source code to be committed to the CodeCommit repository when the repository is created. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="key" type="string" required>
          The S3 object key (file path within the bucket) of a ZIP archive containing the initial code that the CodeCommit repository is populated with when the repository is created, as part of the 'code' configuration's 's3' block. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="object_version" type="string">
          Specifies the version ID of the S3 object that contains the initial code for the repository, enabling you to use a specific version when the object has multiple versions. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The ID of the AWS KMS key used to encrypt the repository contents; if omitted, an AWS-managed key is used. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="repository_description" type="string">
  Specifies the description of the CodeCommit repository, which is displayed in the AWS Management Console and can be up to 1,000 characters long. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  Specifies the name of the AWS CodeCommit repository, which must be unique within the AWS account and region, and is used as the repository's identifier for clone URLs and API operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Defines a list of key-value tag objects to associate with the AWS CodeCommit repository, enabling you to categorize and filter the repository for cost tracking, access management, and resource organization. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to associate with the AWS CodeCommit repository, used for identifying and organizing the repository. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the AWS CodeCommit repository, used to store metadata associated with the corresponding tag key. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="triggers" type="list(object)">
  Defines the list of SNS notification triggers for the repository, where each trigger specifies the SNS topic ARN, the repository events (such as 'all', 'update', 'create', or 'delete') that will fire the trigger, and optionally the branch names that restrict which events are published. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="branches" type="list(string)">
      Specifies the list of branches in the repository for which the trigger's events (such as create, update, or delete) should trigger the associated action (e.g., an SNS notification); if the list is empty, the trigger applies to all branches. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="custom_data" type="string">
      The custom_data field of a trigger is an optional string that AWS CodeCommit includes in the SNS notification payload delivered to the trigger's destination ARN, allowing you to pass arbitrary metadata to downstream consumers. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="destination_arn" type="string">
      The ARN of the SNS topic that receives push notifications from this CodeCommit repository when the trigger condition is met. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="events" type="list(string)">
      Lists the CodeCommit repository events (for example, push, createBranch, deleteBranch, createTag, deleteTag, or updateReference) that activate the trigger. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of an AWS CodeCommit repository trigger, which must be unique within the repository and is used to identify the trigger when configuring and managing repository events. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

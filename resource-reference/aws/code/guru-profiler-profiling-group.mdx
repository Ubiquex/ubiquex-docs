`aws_code_guru_profiler_profiling_group` is the real unit CodeGuru Profiler aggregates and analyzes application performance data under, one or more applications' profiling agents all reporting into the same group so performance issues can be identified across them together rather than per application.

## Input properties

<ResponseField name="agent_permissions" type="object">
  The agent permissions attached to this profiling group. Optional.
  <Expandable title="properties">
    <ResponseField name="principals" type="list(string)" required>
      The principals for the agent permissions. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="anomaly_detection_notification_configuration" type="list(object)">
  Configuration for Notification Channels for Anomaly Detection feature in CodeGuru Profiler which enables customers to detect anomalies in the application profile for those methods that represent the highest proportion of CPU time or latency Optional.
  <Expandable title="properties">
    <ResponseField name="channel_id" type="string">
      The unique identifier assigned by CodeGuru Profiler to an Amazon SNS notification channel used for anomaly detection, which references the channel within the profiling group's configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="channel_uri" type="string">
      The ARN of the SNS topic to which anomaly detection notifications are published for this profiling group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="compute_platform" type="string">
  The compute platform of the profiling group. Optional.
</ResponseField>

<ResponseField name="profiling_group_name" type="string" required>
  The name of the profiling group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with a profiling group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A key in the tags map of an AWS CodeGuru Profiler profiling group, used to attach custom metadata (such as environment or application name) to the profiling group for resource organization, cost allocation, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag assigned to the profiling group, used for cost allocation, resource management, and access control in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_code_artifact_domain` is CodeArtifact's top-level grouping for an organization's own package repositories, one production domain typically holding every `aws_code_artifact_repository` a company uses, so packages can be discovered and shared consistently across development teams.

## Input properties

<ResponseField name="domain_name" type="string" required>
  The name of the domain. Required.
</ResponseField>

<ResponseField name="permissions_policy_document" type="any">
  The access control resource policy on the provided domain. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to an AWS CodeArtifact domain, enabling custom metadata for cost allocation, access control, and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The free-form value of a user-defined tag attached to an AWS CodeArtifact domain, used to add custom metadata for organizing and managing the domain. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the domain. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="encryption_key" type="string">
  The ARN of an AWS Key Management Service (AWS KMS) key associated with a domain. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the domain. This field is used for GetAtt Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="owner" type="string">
  The 12-digit account ID of the AWS account that owns the domain. This field is used for GetAtt Computed by AWS after `ship`.

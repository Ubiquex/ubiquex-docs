`aws_code_connections_host` is a CodeConnections host, a real connection point to a self-managed Git provider (e.g. a GitHub Enterprise Server instance reachable only over a private VPC network) that a `aws_code_connections_connection` can then be created against, since a self-managed provider has no public endpoint CodeConnections can reach directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codeconnections "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/codeconnections"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connections host"})

    		ubx.Resource(codeconnections.Host, "example", codeconnections.HostConfig{
    			Name:             "example",
    			ProviderEndpoint: "example",
    			ProviderType:     "example",
    			Tags:             []map[string]any{{"key": "example"}},
    			VpcConfiguration: map[string]any{"security_group_ids": []string{"example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="name" type="string" required>
  The name of the host. Required.
</ResponseField>

<ResponseField name="provider_endpoint" type="string" required>
  The endpoint of the infrastructure where your provider type is installed. Required.
</ResponseField>

<ResponseField name="provider_type" type="string" required>
  The name of the installed provider to be associated with your connection. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to apply to the host. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_configuration" type="object">
  The VPC configuration provisioned for the host. Optional.
  <Expandable title="properties">
    <ResponseField name="security_group_ids" type="list(string)" required>
      The ID of the security group or security groups associated with the Amazon VPC. Required.
    </ResponseField>
    <ResponseField name="subnet_ids" type="list(string)" required>
      The ID of the subnet or subnets associated with the Amazon VPC. Required.
    </ResponseField>
    <ResponseField name="tls_certificate" type="string">
      The value of the Transport Layer Security (TLS) certificate associated with the infrastructure where your provider type is installed. Optional.
    </ResponseField>
    <ResponseField name="vpc_id" type="string" required>
      The ID of the Amazon VPC connected to the infrastructure where your provider type is installed. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="host_arn" type="string">
  The Amazon Resource Name (ARN) of the host. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="host_id" type="string">
  The server-generated unique identifier for the host. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the host. Computed by AWS after `ship`.
</ResponseField>

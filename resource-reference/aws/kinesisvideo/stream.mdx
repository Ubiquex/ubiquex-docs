`aws_kinesis_video_stream` creates a real stream that captures, stores, and indexes live video and other time-encoded data for playback and downstream analysis.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesisvideo "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/kinesisvideo"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream"})

    		ubx.Resource(kinesisvideo.Stream, "example", kinesisvideo.StreamConfig{
    			Name:                       "example",
    			DataRetentionInHours:       1,
    			DeviceName:                 "example-device-name",
    			KmsKeyId:                   "example",
    			MediaType:                  "example",
    			StreamStorageConfiguration: map[string]any{"default_storage_tier": "example"},
    			Tags:                       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="data_retention_in_hours" type="number">
  The number of hours till which Kinesis Video will retain the data in the stream Optional.
</ResponseField>

<ResponseField name="device_name" type="string">
  The name of the device that is writing to the stream. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  AWS KMS key ID that Kinesis Video Streams uses to encrypt stream data. Optional.
</ResponseField>

<ResponseField name="media_type" type="string">
  The media type of the stream. Consumers of the stream can use this information when processing the stream. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the Kinesis Video stream. Optional.
</ResponseField>

<ResponseField name="stream_storage_configuration" type="object">
  Configuration for the storage tier of the Kinesis Video Stream. Optional.
  <Expandable title="properties">
    <ResponseField name="default_storage_tier" type="string">
      The storage tier for the Kinesis Video Stream. Determines the storage class used for stream data. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs associated with the Kinesis Video Stream. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) portion of a tag attached to the Kinesis Video Stream, used as a unique identifier within the stream's tag set for organizing, managing, and tracking the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the Kinesis video stream, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Kinesis Video stream. Computed by AWS after `ship`.
</ResponseField>

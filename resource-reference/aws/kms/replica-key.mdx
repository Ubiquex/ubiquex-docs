---
title: "aws_kms_replica_key"
description: "`aws_kms_replica_key` creates a real multi-Region replica of an `aws_kms_key` primary key in a different AWS Region."
---

A replica shares its primary's key ID, key material, key spec, key usage, and rotation status, so data encrypted under the key in one Region can be decrypted under the replica in another without a cross-Region call or exposing plaintext in transit.

## Input properties

<ResponseField name="description" type="string">
  A description of the AWS KMS key. Use a description that helps you to distinguish this AWS KMS key from others in the account, such as its intended use. Optional.
</ResponseField>

<ResponseField name="enabled" type="bool">
  Specifies whether the AWS KMS key is enabled. Disabled AWS KMS keys cannot be used in cryptographic operations. Optional.
</ResponseField>

<ResponseField name="key_policy" type="any" required>
  The key policy that authorizes use of the AWS KMS key. The key policy must observe the following rules. Required.
</ResponseField>

<ResponseField name="pending_window_in_days" type="number">
  Specifies the number of days in the waiting period before AWS KMS deletes an AWS KMS key that has been removed from a CloudFormation stack. Enter a value between 7 and 30 days. The default value is 30 days. Optional.
</ResponseField>

<ResponseField name="primary_key_arn" type="string" required>
  Identifies the primary AWS KMS key to create a replica of. Specify the Amazon Resource Name (ARN) of the AWS KMS key. You cannot specify an alias or key ID. For help finding the ARN, see Finding the Key ID and ARN in the AWS Key Management Service Developer Guide. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">

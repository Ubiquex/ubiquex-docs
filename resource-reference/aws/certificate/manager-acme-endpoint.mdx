`aws_certificate_manager_acme_endpoint` creates a real, ACMEv2-compatible endpoint in AWS Certificate Manager, letting any standard ACME client automate public TLS certificate issuance and renewal against ACM rather than only through ACM's own API or console. ACM's ACME support was announced in July 2026, roughly a month ago, AWS's response to industry-wide moves toward shorter certificate lifetimes.

## Input properties

<ResponseField name="authorization_behavior" type="string" required>
  The authorization behavior for the ACME endpoint. Required.
</ResponseField>

<ResponseField name="certificate_authority" type="object" required>
  The certificate authority configuration for the ACME endpoint. Required.
  <Expandable title="properties">
    <ResponseField name="public_certificate_authority" type="object" required>
      Configuration for the public certificate authority. Required.
      <Expandable title="properties">
        <ResponseField name="allowed_key_algorithms" type="list(string)">
          The allowed key algorithms for certificates issued via this endpoint. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="certificate_tags" type="list(object)">
  Tags applied to certificates issued via this endpoint. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contact" type="string">
  Whether contact information is required for the ACME endpoint. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags associated with the ACME endpoint. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="acme_endpoint_arn" type="string">
  The Amazon Resource Name (ARN) of the ACME endpoint. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint_url" type="string">
  The ACME directory URL for the endpoint. Computed by AWS after `ship`.
</ResponseField>

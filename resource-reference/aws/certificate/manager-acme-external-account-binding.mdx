`aws_certificate_manager_acme_external_account_binding` generates a real credential pair, a key identifier and HMAC key, that authorizes a specific ACME client to register an account against an `aws_certificate_manager_acme_endpoint`, with an IAM role controlling exactly what that client is allowed to do.

## Input properties

<ResponseField name="acme_endpoint_arn" type="string" required>
  The ARN of the ACME endpoint this binding is associated with. Required.
</ResponseField>

<ResponseField name="expiration" type="object">
  The expiration configuration for the external account binding. Optional.
  <Expandable title="properties">
    <ResponseField name="type" type="string" required>
      The time unit for the expiration value. Required.
    </ResponseField>
    <ResponseField name="value" type="number" required>
      The expiration value. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The IAM role ARN for cross-account access. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags associated with the external account binding. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="acme_external_account_binding_arn" type="string">
  The Amazon Resource Name (ARN) of the external account binding. Computed by AWS after `ship`.
</ResponseField>

`aws_certificate_manager_certificate` issues or imports a public or private SSL/TLS X.509 certificate for one or more domain names, wildcards included, that ACM then renews automatically for services issued directly through it, a certificate is a regional resource and can't be copied between Regions.

## Input properties

<ResponseField name="certificate_authority_arn" type="string">
  The Amazon Resource Name (ARN) of the private certificate authority (CA) that will be used to issue the certificate. Optional.
</ResponseField>

<ResponseField name="certificate_export" type="string">
  Specifies whether the certificate can be exported. ENABLED allows the certificate to be exported, DISABLED prevents export. Optional.
</ResponseField>

<ResponseField name="certificate_transparency_logging_preference" type="string">
  You can opt out of certificate transparency logging by specifying the DISABLED option. Opt in by specifying ENABLED. Optional.
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The fully qualified domain name (FQDN), such as www.example.com, with which you want to secure an ACM certificate Required.
</ResponseField>

<ResponseField name="domain_validation_options" type="list(object)">
  Domain information that domain name registrars use to verify your identity. Optional.
  <Expandable title="properties">
    <ResponseField name="domain_name" type="string">
      The domain name for which certificate validation options are specified, corresponding to one of the domains in the certificate's Subject Alternative Names. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="hosted_zone_id" type="string">
      The ID of the hosted zone in Route 53 where the DNS validation record for this domain will be created. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="validation_domain" type="string">
      The domain that AWS Certificate Manager will use for validation (e.g., email or DNS checks), which can be a different domain than the one being certified. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="key_algorithm" type="string">
  Specifies the algorithm of the public and private key pair that your certificate uses to encrypt data. Optional.
</ResponseField>

<ResponseField name="subject_alternative_names" type="list(string)">
  Additional FQDNs to be included in the Subject Alternative Name extension of the ACM certificate. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Key-value pairs that can identify the certificate. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS Certificate Manager certificate, used for metadata, cost allocation, and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="validation_method" type="string">
  The method you want to use to validate that you own or control the domain associated with a public certificate. Valid values are DNS, EMAIL or HTTP Optional.
</ResponseField>

## Output properties

<ResponseField name="certificate_arn" type="string">
  The Amazon Resource Name (ARN) of the private certificate authority (CA) that will be used to issue the certificate. Computed by AWS after `ship`.
</ResponseField>

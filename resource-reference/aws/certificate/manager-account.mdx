`aws_certificate_manager_account` configures account-wide ACM settings, specifically how many days before expiry ACM starts sending daily EventBridge events for every `aws_certificate_manager_certificate` in the account, 45 days by default for private and imported certificates, 30 for public ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	certificatemanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/certificatemanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own manager account"})

    		ubx.Resource(certificatemanager.Account, "example", certificatemanager.AccountConfig{
    			ExpiryEventsConfiguration: map[string]any{"days_before_expiry": 1},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="expiry_events_configuration" type="object" required>
  Configures the day-based threshold (DaysBeforeExpiry) at which AWS Certificate Manager emits certificate expiration events, enabling EventBridge notifications for upcoming renewals. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="days_before_expiry" type="number">
      Specifies the number of days before certificate expiration when ACM begins emitting expiry-related events, allowing you to adjust the notification lead time. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The AWS account ID that owns this ACM account-level configuration, automatically derived from the account in which the resource is deployed. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_app_runner_vpc_ingress_connection` restricts an `aws_app_runner_service` to only be reachable from inside a VPC, connecting the service to a VPC interface endpoint so it accepts no traffic from the public internet at all. A service can have at most one of these.

## Example

<Tabs>

    ```go
    package main

    import (
    	apprunner "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apprunner"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpc ingress connection"})

    		ubx.Resource(apprunner.VpcIngressConnection, "example", apprunner.VpcIngressConnectionConfig{
    			IngressVpcConfiguration:  map[string]any{"vpc_endpoint_id": "example", "vpc_id": "example"},
    			ServiceArn:               "arn:aws:iam::123456789012:policy/example",
    			Tags:                     []map[string]any{{"key": "example"}},
    			VpcIngressConnectionName: "example-vpc-ingress-connection-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="ingress_vpc_configuration" type="object" required>
  The configuration of customer’s VPC and related VPC endpoint Required.
  <Expandable title="properties">
    <ResponseField name="vpc_endpoint_id" type="string" required>
      The ID of the VPC endpoint that your App Runner service connects to. Required.
    </ResponseField>
    <ResponseField name="vpc_id" type="string" required>
      The ID of the VPC that the VPC endpoint is used in. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_arn" type="string" required>
  The Amazon Resource Name (ARN) of the service. Required.
</ResponseField>

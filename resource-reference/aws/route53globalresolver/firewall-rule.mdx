`aws_route53_global_resolver_firewall_rule` defines a real action, block, allow, alert, to take when a DNS query through an `aws_route53_global_resolver_global_resolver` matches an `aws_route53_global_resolver_firewall_domain_list`.

## Input properties

<ResponseField name="action" type="string" required>
  Specifies the action taken when a DNS query matches the firewall rule's conditions, accepting values ALLOW, BLOCK, or ALERT to permit, block, or log/alert the query respectively. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="block_override_dns_type" type="string">
  This value specifies the DNS record type (for example, CNAME) that the DNS Firewall rule returns when the block action is set to override, allowing you to point blocked queries to a custom domain. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="block_override_domain" type="string">
  Specifies the custom domain name that Route 53 Resolver returns in the DNS response for a blocked query when the firewall rule action is BLOCK and the block override configuration (e.g., block_override_dns_type) is applied. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="block_override_ttl" type="number">
  BlockOverrideTtl sets the time-to-live (TTL) in seconds for the custom DNS record returned when a DNS Firewall rule blocks a query with the OVERRIDE response action. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="block_response" type="string">
  Specifies the DNS response returned when the firewall rule's action is BLOCK, such as NODATA, NXDOMAIN, or an OVERRIDE response. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_token" type="string">
  This field is an idempotency token that ensures duplicate Route 53 Resolver firewall rules are not created when the same request is retried. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="confidence_threshold" type="string">
  Specifies the minimum confidence threshold (LOW, MEDIUM, or HIGH) that a threat intelligence domain list match must meet for the Route 53 Resolver DNS Firewall rule to apply, filtering which domains are treated as malicious. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Provides an optional description for the Route 53 Resolver firewall rule, used to annotate the rule with its purpose or notes. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dns_advanced_protection" type="string">
  Optional.
</ResponseField>

<ResponseField name="dns_view_id" type="string" required>
  Required.
</ResponseField>

<ResponseField name="firewall_domain_list_id" type="string">
  The unique ID of the firewall domain list that defines the set of domains this resolver firewall rule applies to, associating the rule with that list. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Route 53 Resolver firewall rule, which is a required string that provides a friendly identifier for the rule. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="priority" type="number">
  The priority value that determines the evaluation order of this rule within its firewall rule group, with lower numbers evaluated first. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="qtype" type="string">
  The DNS query type (such as A, AAAA, CNAME, MX, etc.) that this firewall rule matches, allowing the rule to evaluate only queries of that type, while omitting it makes the rule evaluate all supported query types. Optional. **(AI-inferred)**
</ResponseField>

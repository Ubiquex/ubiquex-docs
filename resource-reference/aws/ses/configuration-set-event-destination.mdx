`aws_ses_configuration_set_event_destination` routes real email sending events, opens, bounces, complaints, deliveries, from an `aws_ses_configuration_set` to a destination such as CloudWatch, SNS, or Kinesis Data Firehose.

## Input properties

<ResponseField name="configuration_set_name" type="string" required>
  The name of the configuration set that contains the event destination. Required.
</ResponseField>

<ResponseField name="event_destination" type="object" required>
  The event destination object that specifies which event types (such as send, bounce, or complaint) to publish and to which destination (Amazon SNS, CloudWatch, or Kinesis Firehose). Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cloud_watch_destination" type="object">
      An object that contains the names, default values, and sources of the dimensions associated with an Amazon CloudWatch event destination. Optional.
      <Expandable title="properties">
        <ResponseField name="dimension_configurations" type="list(object)">
          A list of dimensions upon which to categorize your emails when you publish email sending events to Amazon CloudWatch. Optional.
          <Expandable title="properties">
            <ResponseField name="default_dimension_value" type="string">
              Specifies the fallback value for the CloudWatch dimension when the dimension value source (message tag or email header) is not present in the email. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="dimension_name" type="string">
              Sets the name of the CloudWatch dimension that Amazon SES attaches to the metrics it publishes for this configuration set's event destination, allowing the metric to be filtered by that dimension in CloudWatch. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="dimension_value_source" type="string">
              The dimension_value_source field specifies whether the dimension value is derived from an email header ('emailHeader') or from a message tag ('messageTag') when publishing SES event data to CloudWatch. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="enabled" type="bool">
      Sets whether Amazon SES publishes events to this destination when you send an email with the associated configuration set. Set to true to enable publishing to this destination; set to false to prevent publishing to this destination. The default value is false. Optional.
    </ResponseField>
    <ResponseField name="event_bridge_destination" type="object">
      An object that contains Event bus ARN associated with the event bridge destination. Optional.
      <Expandable title="properties">
        <ResponseField name="event_bus_arn" type="string" required>
          The ARN of the Amazon EventBridge bus to which the SES event is delivered. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="kinesis_firehose_destination" type="object">
      An object that contains the delivery stream ARN and the IAM role ARN associated with an Amazon Kinesis Firehose event destination. Optional.
      <Expandable title="properties">
        <ResponseField name="delivery_stream_arn" type="string" required>
          The ARN of the Amazon Kinesis Firehose stream that email sending events should be published to. Required.
        </ResponseField>
        <ResponseField name="iamrole_arn" type="string" required>
          The ARN of the IAM role under which Amazon SES publishes email sending events to the Amazon Kinesis Firehose stream. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="matching_event_types" type="list(string)" required>
      The type of email sending events, send, reject, bounce, complaint, delivery, open, click, renderingFailure, deliveryDelay, and subscription. Required.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the event destination set. Optional.
    </ResponseField>
    <ResponseField name="sns_destination" type="object">
      An object that contains SNS topic ARN associated event destination. Optional.
      <Expandable title="properties">
        <ResponseField name="topic_arn" type="string" required>
          The ARN of the Amazon SNS topic that Amazon SES publishes event notifications to when an email event such as send, bounce, complaint, or delivery occurs. Required. **(AI-inferred)**

      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

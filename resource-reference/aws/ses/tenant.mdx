title: "aws_ses_tenant"

`aws_ses_tenant` creates a real, isolated tenant within an SES account, giving a SaaS platform sending on behalf of many customers its own separated sending identities, reputation, and metrics per tenant rather than one shared pool for the whole account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ses "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ses"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tenant"})

    		ubx.Resource(ses.Tenant, "example", ses.TenantConfig{
    			TenantName:           "example-tenant-name",
    			ResourceAssociations: []map[string]any{{"resource_arn": "example"}},
    			Tags:                 []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    import ubx_sdk as ubx
    from ubx.aws.ses import Tenant, TenantConfig

    def describe():
        ubx.intent("example own tenant")

            tenant_name="example-tenant-name",
            resource_associations=[{"resource_arn": "example"}],
            tags=[{"key": "example"}],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="resource_associations" type="list(object)">
  The list of resources to associate with the tenant. Optional.
  <Expandable title="properties">
    <ResponseField name="resource_arn" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags (keys and values) associated with the tenant. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tenant_name" type="string" required>
  The name of the tenant. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Amazon Resource Name (ARN) of the tenant. Computed by AWS after `ship`.
</ResponseField>

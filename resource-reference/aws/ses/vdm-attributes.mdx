`aws_ses_vdm_attributes` configures account-wide Virtual Deliverability Manager settings, engagement metrics tracking and optimized shared delivery, that apply across every `aws_ses_configuration_set` unless a configuration set overrides them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ses "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ses"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vdm attributes"})

    		ubx.Resource(ses.VdmAttributes, "example", ses.VdmAttributesConfig{
    			DashboardAttributes: map[string]any{"engagement_metrics": "example"},
    			GuardianAttributes:  map[string]any{"optimized_shared_delivery": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="dashboard_attributes" type="object">
  Preferences regarding the Dashboard feature. Optional.
  <Expandable title="properties">
    <ResponseField name="engagement_metrics" type="string">
      Whether emails sent from this account have engagement tracking enabled. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="guardian_attributes" type="object">
  Preferences regarding the Guardian feature. Optional.
  <Expandable title="properties">
    <ResponseField name="optimized_shared_delivery" type="string">
      Whether emails sent from this account have optimized delivery algorithm enabled. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

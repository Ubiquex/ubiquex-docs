`aws_ses_mail_manager_traffic_policy` defines real allow/block policy statements, and a default action, that an `aws_ses_mail_manager_ingress_point` evaluates before an `aws_ses_mail_manager_rule_set` ever runs, the first-line filter for incoming mail.

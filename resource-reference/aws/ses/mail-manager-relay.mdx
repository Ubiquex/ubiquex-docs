`aws_ses_mail_manager_relay` configures a real outbound SMTP relay destination that an `aws_ses_mail_manager_rule_set` can forward accepted email to, for routing filtered mail on to a downstream mail server rather than only delivering it to an S3 archive or another AWS service.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(ses.MailManagerRelay, "example", ses.MailManagerRelayConfig{

    			RelayName:      "example-relay-name",
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="authentication" type="object" required>
  Specifies the authentication mechanism and credentials used by this SES Mail Manager relay to connect to the destination SMTP server, such as basic authentication or no authentication. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="no_authentication" type="any">
      Indicates that the relay does not require any authentication when connecting to the destination SMTP server, as represented by an empty no-authentication configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      The ARN of the AWS Secrets Manager secret containing the SMTP credentials (username and password) used for authentication when the relay connects to the remote mail server. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="relay_name" type="string">
  An optional friendly name that identifies this SMTP relay to make it easier to manage within the SES Mail Manager configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_name" type="string" required>
  The hostname or IP address of the destination SMTP server that this relay uses to forward email. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_port" type="number" required>

</ResponseField>

`aws_ses_configuration_set` defines a real set of rules, IP pool, reputation options, sending options, applied to emails sent through SES that reference it, SES's original configuration mechanism distinct from Mail Manager's own `aws_ses_mail_manager_traffic_policy`.

## Properties

<ResponseField name="archiving_options" type="object">
  An object that defines a MailManager archive that is used to preserve emails that you send using the configuration set. Optional.
  <Expandable title="properties">
    <ResponseField name="archive_arn" type="string">
      The ARN of the MailManager archive to associate with the configuration set. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="delivery_options" type="object">
  An object that defines the dedicated IP pool that is used to send emails that you send using the configuration set. Optional.
  <Expandable title="properties">
    <ResponseField name="max_delivery_seconds" type="number">
      Specifies the maximum time until which SES will retry sending emails Optional.
    </ResponseField>
    <ResponseField name="sending_pool_name" type="string">
      The name of the dedicated IP pool to associate with the configuration set. Optional.
    </ResponseField>
    <ResponseField name="tls_policy" type="string">
      Specifies whether messages that use the configuration set are required to use Transport Layer Security (TLS). If the value is Require , messages are only delivered if a TLS connection can be established. If the value is Optional , messages can be delivered in plain text if a TLS connection can't be established. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the configuration set. Optional.
</ResponseField>

<ResponseField name="reputation_options" type="object">
  An object that defines whether or not Amazon SES collects reputation metrics for the emails that you send that use the configuration set. Optional.
  <Expandable title="properties">
    <ResponseField name="reputation_metrics_enabled" type="bool">
      If true , tracking of reputation metrics is enabled for the configuration set. If false , tracking of reputation metrics is disabled for the configuration set. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sending_options" type="object">

`aws_ses_mail_manager_addon_subscription` subscribes an account to a real, third-party Mail Manager add-on, such as a spam or malware detection engine, the prerequisite before an `aws_ses_mail_manager_addon_instance` of it can be deployed.

## Input properties

<ResponseField name="addon_name" type="string" required>
  The name of the third-party email security or spam filtering add-on that this SES Mail Manager add-on subscription subscribes to, enabling its features for the associated mail managers. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags to apply to the SES Mail Manager Add-On Subscription, where each tag object contains a key and value pair for resource metadata and cost allocation. Optional. **(AI-inferred)**

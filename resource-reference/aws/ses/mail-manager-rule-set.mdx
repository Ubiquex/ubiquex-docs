`aws_ses_mail_manager_rule_set` defines a real, ordered list of rules, evaluated sequentially against each email accepted by an `aws_ses_mail_manager_ingress_point`, that decide what actions, deliver, archive, relay, drop, to take on it.

## Example

    	ubx.Main(ubx.Stack("example", func() {

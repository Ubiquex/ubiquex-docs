`aws_ses_template` creates a real, reusable email template, subject and HTML/text bodies with placeholder variables, that a send call can reference by name instead of specifying content inline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ses "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ses"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own template"})

    		ubx.Resource(ses.Template, "ci-runner", ses.TemplateConfig{
    			Tags:     []map[string]any{{"key": "example"}},
    			Template: map[string]any{"subject_part": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="tags" type="list(object)">
  The tags (keys and values) associated with the email template. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag applied to the Amazon SES email template. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a tag assigned to the SES email template, used for metadata organization and cost allocation in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template" type="object">
  The content of the email, composed of a subject line, an HTML part, and a text-only part Optional.
  <Expandable title="properties">
    <ResponseField name="html_part" type="string">
      The HTML body of the email. Optional.
    </ResponseField>
    <ResponseField name="subject_part" type="string" required>
      The subject line of the email. Required.
    </ResponseField>
    <ResponseField name="template_name" type="string">
      The name of the template. Optional.
    </ResponseField>
    <ResponseField name="text_part" type="string">
      The email body that is visible to recipients whose email clients do not display HTML content. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The id of the aws_ses_template resource is the template name, which uniquely identifies the SES template within the AWS region. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

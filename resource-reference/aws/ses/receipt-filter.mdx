`aws_ses_receipt_filter` defines a real IP address range that SES should Allow or Block at the account level before any `aws_ses_receipt_rule` is even evaluated, SES's original, simpler inbound filtering mechanism predating Mail Manager.

## Input properties

<ResponseField name="filter" type="object" required>
  A structure that describes the IP address filter to create, which consists of a name, an IP address range, and whether to allow or block mail from it. Required.
  <Expandable title="properties">
    <ResponseField name="ip_filter" type="object" required>
      A structure that provides the IP addresses to block or allow, and whether to block or allow incoming mail from them. Required.
      <Expandable title="properties">
        <ResponseField name="cidr" type="string" required>
          A single IP address or a range of IP addresses to block or allow, specified in CIDR notation. Required.
        </ResponseField>
        <ResponseField name="policy" type="string" required>
          Indicates whether to block or allow incoming mail from the specified IP addresses. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the IP address filter. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The name of the SES receipt filter, which serves as the unique Terraform identifier and matches the filter's `name` attribute. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

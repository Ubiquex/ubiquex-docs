`aws_mgn_network_migration_definition` defines a real source network configuration, read from an S3-hosted description of an on-premises or AWS-based network, on-premises or AWS, that AWS's rehosting migration tooling uses to recreate that network's topology in AWS. This resource sits under AWS Application Migration Service, which AWS rebranded to AWS Transform MGN in June 2026; the rebrand changed the service's name and console, not this resource's own behavior.

## Input properties

<ResponseField name="description" type="string">
  A description of the network migration definition. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the network migration definition. Required.
</ResponseField>

<ResponseField name="scope_tags" type="any">
  Scope tags map for the network migration definition. Optional.
</ResponseField>

<ResponseField name="source_configurations" type="list(object)" required>
  A list of source configurations for the network migration. Required.
  <Expandable title="properties">
    <ResponseField name="source_environment" type="string">
      Specifies the environment of the source network (typically 'ON_PREMISES' or 'AWS') for each source configuration in the network migration definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_s3_configuration" type="object">
      Optional; if omitted, computed by AWS.
      <Expandable title="properties">
        <ResponseField name="s3_bucket" type="string">
          The name of the S3 bucket that contains the source network configuration data used by the MGN network migration definition when the source type is S3. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="s3_bucket_owner" type="string">
          Specifies the AWS account ID of the owner of the S3 bucket referenced in the source configuration, enabling MGN to access buckets across accounts for network migration data. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="s3_key" type="string">
          Optional; if omitted, computed by AWS.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the network migration definition. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag attached to the network migration definition, used to label the resource for filtering, cost tracking, and operational management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_deployment" type="string">
  The target deployment configuration for the migrated network. Optional.
</ResponseField>

<ResponseField name="target_network" type="object" required>
  Configuration for the target network topology and addressing. Required.
  <Expandable title="properties">
    <ResponseField name="inbound_cidr" type="string">
      The CIDR block for inbound traffic in the target network. Optional.
    </ResponseField>
    <ResponseField name="inspection_cidr" type="string">
      The CIDR block for inspection traffic in the target network. Optional.
    </ResponseField>
    <ResponseField name="outbound_cidr" type="string">
      The CIDR block for outbound traffic in the target network. Optional.
    </ResponseField>
    <ResponseField name="topology" type="string" required>
      The network topology type for the target environment. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_s3_configuration" type="object" required>
  S3 configuration for storing target network artifacts. Required.
  <Expandable title="properties">
    <ResponseField name="s3_bucket" type="string" required>
      The name of the S3 bucket for target artifacts. Required.
    </ResponseField>
    <ResponseField name="s3_bucket_owner" type="string" required>
      The AWS account ID of the S3 bucket owner. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

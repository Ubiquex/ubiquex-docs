`aws_audit_manager_assessment` creates from an `aws_audit_manager_assessment_framework` the actual, running evidence-collection process, scoped to specific AWS accounts, that continuously gathers audit-ready evidence until the assessment is marked inactive. AWS Audit Manager is no longer open to new customers; existing customers can continue using it as normal.

      The IAM user or role that created this delegation of the assessment. Optional; if omitted, computed by AWS. **(AI-inferred)**

      The unique identifier of the delegation, as assigned by AWS Audit Manager, which allows the assessment to be administered by a different AWS account. Optional; if omitted, computed by AWS. **(AI-inferred)**

`aws_audit_manager_assessment_framework` is a structured collection of controls, prebuilt for standards like PCI DSS, HIPAA, or SOC 2, or built custom, that an `aws_audit_manager_assessment` is created from to define exactly what evidence gets collected and against which requirements.

## Input properties

<ResponseField name="compliance_type" type="string">
  The compliance type that the framework supports, such as CIS or HIPAA. Optional.
</ResponseField>

<ResponseField name="control_sets" type="list(object)" required>
  The control sets that are associated with the framework. Required.
  <Expandable title="properties">
    <ResponseField name="controls" type="list(object)">
      Specifies the list of controls for each control set in the assessment framework, where each control entry includes its name, source type, and mapping details so the framework can evaluate evidence against them. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          The identifier (ARN) of the AWS Audit Manager control to include in the control set of the assessment framework. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="name" type="string">
      Name of the control set within the assessment framework, identifying a group of related controls. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the framework. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the framework. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with the framework. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag attached to the AWS Audit Manager assessment framework, used to identify and categorize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      In AWS Audit Manager, this is the value portion of a tag key-value pair attached to the assessment framework, used for custom metadata and resource identification/filtering. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

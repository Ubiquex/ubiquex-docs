`aws_backup_restore_testing_selection` picks which real recovery points and target resources an `aws_backup_restore_testing_plan` actually restores during a test run, the selection a restore testing plan has no scope without.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own restore testing selection"})

    		ubx.Resource(backup.RestoreTestingSelection, "example", backup.RestoreTestingSelectionConfig{
    			IamRoleArn:                  "arn:aws:iam::123456789012:policy/example",
    			ProtectedResourceType:       "example",
    			RestoreTestingPlanName:      "example-restore-testing-plan-name",
    			RestoreTestingSelectionName: "example-restore-testing-selection-name",
    			ProtectedResourceArns:       []string{"example"},
    			ProtectedResourceConditions: map[string]any{"string_equals": []map[string]any{{"key": "example"}}},

    			ValidationWindowHours:       1,
    		})
    	}))

## Properties

<ResponseField name="iam_role_arn" type="string" required>
  The ARN of the IAM role that AWS Backup assumes to perform restore testing for the resources included in this restore testing selection. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="protected_resource_arns" type="list(string)">
  The ARNs of the protected resources to include in the restore testing selection. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="protected_resource_conditions" type="object">
  Defines the key-value conditions (StringEquals and StringNotEquals) on protected resource attributes, such as tags, to filter which resources are included in the restore testing selection. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="string_equals" type="list(object)">
      Specifies key-value pairs for tag-based filtering, where a protected resource must have a tag whose key and value exactly match a pair in this list to be included in the restore testing selection. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          Specifies the AWS resource tag key (e.g., Environment) that the string_equals condition requires to be present with a matching value on a protected resource for the restore testing selection. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The value that a protected resource's attribute or tag (identified by the corresponding key in the enclosing StringEquals key-value pair) must equal for the resource to match this restore testing selection condition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="string_not_equals" type="list(object)">
      A list of conditions where each specifies a resource attribute (such as a tag key) and a value, and the condition is satisfied when the resource's attribute value does not equal that value, thereby excluding matching protected resources from the restore testing selection. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">

        </ResponseField>
        <ResponseField name="value" type="string">
          For a string_not_equals condition on a protected resource tag, this value is the tag value to compare against; a protected resource is excluded from the restore testing selection if its tag value for the specified key equals this value. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="protected_resource_type" type="string" required>
  Specifies the AWS resource type (e.g., 'EBS', 'S3', or '*') that determines which protected resources are included in the restore testing selection. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="restore_metadata_overrides" type="any">
  A map of restore metadata overrides used to customize the restore job parameters for a restore testing selection. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="restore_testing_plan_name" type="string" required>
  The name of the AWS Backup restore testing plan that this selection is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="restore_testing_selection_name" type="string" required>
  The name of the restore testing selection, which must be unique among all restore testing selections in the same restore testing plan. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="validation_window_hours" type="number">
  The number of hours in the validation window, starting from the beginning of the restore test, within which the restore test must complete successfully or it is considered failed. Optional. **(AI-inferred)**
</ResponseField>

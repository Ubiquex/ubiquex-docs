`aws_backup_legal_hold` places one or more real backups under an indefinite hold that blocks deletion and pauses any lifecycle transition that would remove them, until a user with sufficient permissions releases it, the mechanism AWS Backup provides for litigation and compliance retention that overrides a plan's own lifecycle rules.

`aws_backup_selection` assigns real AWS resources, by tag, by explicit resource ID, or by IAM role, to an `aws_backup_plan`, the actual mechanism that determines which resources a plan's schedule and lifecycle rules apply to. A plan with no selection protects nothing.

## Output properties

<ResponseField name="id" type="string">
  The unique AWS-generated identifier assigned to the backup selection when it is created, used to reference the selection in AWS Backup and IAM policies. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="selection_id" type="string">
  The unique identifier assigned by AWS Backup to the backup selection, used internally to reference the selection within a backup plan. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

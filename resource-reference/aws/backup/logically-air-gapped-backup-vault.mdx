`aws_backup_logically_air_gapped_backup_vault` stores backups in an isolated, service-owned account, locked by default and encrypted with AWS-owned keys, real protection against ransomware that specifically targets and deletes an account's own backup data, without requiring a separate copy of every backup to achieve it.

## Input properties

<ResponseField name="access_policy" type="any">
  The access policy is a JSON resource-based policy that controls which IAM principals can perform actions (such as creating, deleting, or restoring backups) on this logically air-gapped backup vault. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="backup_vault_name" type="string" required>
  The name of the logically air-gapped backup vault, which uniquely identifies it within an AWS account and region and must be provided when creating the vault. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="backup_vault_tags" type="any">
  Specifies the key-value tags to assign to the backup vault, enabling you to organize and manage the logically air-gapped vault in AWS Backup. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="encryption_key_arn" type="string">
  Specifies the AWS KMS key ARN used to encrypt the backups stored in this logically air-gapped backup vault, allowing you to control encryption with a customer-managed key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_retention_days" type="number" required>
  Specifies the maximum retention period in days for backups that can be stored in this logically air-gapped backup vault. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="min_retention_days" type="number" required>
  The minimum number of days that backups in this logically air-gapped vault must be retained before they can be deleted, enforcing a locked retention floor. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="mpa_approval_team_arn" type="string">
  The ARN of the IAM approval team that must authorize the deletion of this logically air-gapped backup vault, enabling multi-party approval (MPA) as a safeguard against accidental or malicious removal. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="notifications" type="object">
  Configures an optional SNS topic and a list of backup vault event types (such as BACKUP_JOB_COMPLETED or RESTORE_JOB_FAILED) that trigger notifications for this logically air-gapped backup vault. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="backup_vault_events" type="list(string)" required>
      Specifies the list of backup vault event types (e.g., BACKUP_JOB_STARTED, BACKUP_JOB_COMPLETED, RESTORE_JOB_STARTED) that trigger an SNS notification when they occur for this logically air-gapped backup vault. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="snstopic_arn" type="string" required>
      The ARN of the Amazon SNS topic that AWS Backup uses to send notifications for events related to this logically air-gapped backup vault. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="backup_vault_arn" type="string">

</ResponseField>

<ResponseField name="vault_state" type="string">
  The current lifecycle state of the logically air-gapped backup vault (e.g., CREATING, AVAILABLE, FAILED), indicating whether it is ready to store recovery points. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="vault_type" type="string">
  The type of the backup vault, which for this logically air-gapped resource is set to LOGICALLY_AIR_GAPPED_BACKUP_VAULT to indicate its immutable, WORM-compliant storage behavior. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_backup_tiering_configuration` automatically moves backup data in an `aws_backup_vault` to a lower-cost storage tier once it reaches a defined age (60 days minimum), while keeping identical restore capability, real, ongoing storage savings without the caller managing the transition by hand.

    			TieringConfigurationName: "example-tiering-configuration-name",
    			TieringConfigurationTags: "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="backup_vault_name" type="string" required>
  The name of the AWS Backup vault to which this tiering configuration is applied. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_selection" type="list(object)" required>
  Required.
  <Expandable title="properties">
    <ResponseField name="resource_type" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="resources" type="list(string)">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="tiering_down_settings_in_days" type="number">
      The number of days after a backup is created that it should be moved to the cold storage tier, controlling the lifecycle transition for the selected resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tiering_configuration_name" type="string" required>
  The name that identifies this tiering configuration, which defines when backups transition to the cold storage tier within an AWS Backup plan. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tiering_configuration_tags" type="any">
  Optional.
</ResponseField>

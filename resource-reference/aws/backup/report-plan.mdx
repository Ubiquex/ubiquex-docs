`aws_backup_report_plan` generates recurring, downloadable AWS Backup Audit Manager reports summarizing compliance against an `aws_backup_framework`'s controls over time, real evidence a caller can hand to an auditor rather than assembling one by hand.

## Input properties

<ResponseField name="report_delivery_channel" type="object" required>
  A structure that contains information about where and how to deliver your reports, specifically your Amazon S3 bucket name, S3 key prefix, and the formats of your reports. Required.
  <Expandable title="properties">
    <ResponseField name="formats" type="list(string)">
      A list of the format of your reports: CSV, JSON, or both. If not specified, the default format is CSV. Optional.
    </ResponseField>
    <ResponseField name="s3_bucket_name" type="string" required>
      The unique name of the S3 bucket that receives your reports. Required.
    </ResponseField>
    <ResponseField name="s3_key_prefix" type="string">
      The prefix for where AWS Backup Audit Manager delivers your reports to Amazon S3. The prefix is this part of the following path: s3://your-bucket-name/prefix/Backup/us-west-2/year/month/day/report-name. If not specified, there is no prefix. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="report_plan_description" type="string">
  An optional description of the report plan with a maximum of 1,024 characters. Optional.
</ResponseField>

<ResponseField name="report_plan_name" type="string">
  The unique name of the report plan. The name must be between 1 and 256 characters, starting with a letter, and consisting of letters (a-z, A-Z), numbers (0-9), and underscores (_). Optional.
</ResponseField>

<ResponseField name="report_plan_tags" type="list(object)">
  Metadata that you can assign to help organize the report plans that you create. Each tag is a key-value pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS Backup report plan, used to categorize and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag attached to the AWS Backup report plan, used for identifying and organizing the report plan. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="report_setting" type="object" required>
  Identifies the report template for the report. Reports are built using a report template. Required.
  <Expandable title="properties">
    <ResponseField name="accounts" type="list(string)">
      The list of AWS accounts that a report covers. Optional.
    </ResponseField>
    <ResponseField name="framework_arns" type="list(string)">
      The Amazon Resource Names (ARNs) of the frameworks a report covers. Optional.
    </ResponseField>
    <ResponseField name="organization_units" type="list(string)">
      The list of AWS organization units that a report covers. Optional.
    </ResponseField>
    <ResponseField name="regions" type="list(string)">
      The list of AWS regions that a report covers. Optional.
    </ResponseField>
    <ResponseField name="report_template" type="string" required>
      Identifies the report template for the report. Reports are built using a report template. The report templates are: `BACKUP_JOB_REPORT | COPY_JOB_REPORT | RESTORE_JOB_REPORT` Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="report_plan_arn" type="string">
  An Amazon Resource Name (ARN) that uniquely identifies a resource. The format of the ARN depends on the resource type. Computed by AWS after `ship`.
</ResponseField>

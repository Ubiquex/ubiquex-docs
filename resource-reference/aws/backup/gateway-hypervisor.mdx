`aws_backup_gateway_hypervisor` connects AWS Backup to an on-premises or VMware Cloud on AWS hypervisor through a deployed gateway appliance, letting AWS Backup discover, snapshot, and restore real virtual machines through vCenter Server without them ever needing to be natively AWS resources.

    ```go
    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway hypervisor"})

    			Name:        "example",
    			Host:        "example",
    			KmsKeyArn:   "arn:aws:iam::123456789012:policy/example",
    			LogGroupArn: "arn:aws:iam::123456789012:policy/example",
    			Password:    "example",
    			Tags:        []map[string]any{{"key": "example"}},
    			Username:    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="host" type="string">
  Specifies the hostname or IP address of the on-premises VMware hypervisor (such as vCenter Server or ESXi) that AWS Backup Gateway connects to for backup operations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The Amazon Resource Name (ARN) of the AWS KMS key used to encrypt the hypervisor. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="log_group_arn" type="string">
  The ARN of the Amazon CloudWatch Logs log group where the hypervisor's logs are delivered. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  An optional friendly name for the hypervisor, used to identify the on-premises VMware environment within AWS Backup Gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="password" type="string">
  The password used to authenticate to the hypervisor management interface (for example, vCenter Server) when registering the on-premises hypervisor with AWS Backup Gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tags to assign to the AWS Backup Gateway hypervisor for resource management, identification, and cost allocation. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key component of a tag assigned to an AWS Backup Gateway hypervisor, used to label and categorize the resource for management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="username" type="string">
  The username used to authenticate with the on-premises hypervisor (for example, VMware vCenter) that AWS Backup Gateway manages. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="hypervisor_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the hypervisor created by AWS Backup Gateway. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

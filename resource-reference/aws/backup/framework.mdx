`aws_backup_framework` is a set of built-in, customizable AWS Backup Audit Manager controls, aligned to an organization's own compliance requirements, that automatically track backup activity and flag resources not yet compliant with those controls.

## Input properties

<ResponseField name="framework_controls" type="list(object)" required>
  Contains detailed information about all of the controls of a framework. Each framework must contain at least one control. Required.
  <Expandable title="properties">
    <ResponseField name="control_input_parameters" type="list(object)">
      Specifies the input parameters for a control within an AWS Backup framework, such as the retention period threshold that the control evaluates. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="parameter_name" type="string">
          Specifies the name of an input parameter for a control in an AWS Backup framework, such as requiredRetentionDays, which is passed to the control to customize its behavior. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="parameter_value" type="string">
          Specifies the value assigned to a control input parameter, customizing the framework control's behavior by providing configuration data such as thresholds, identifiers, or other control-specific settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="control_name" type="string">
      The name of the backup framework control, which identifies the specific compliance rule (for example, BACKUP_RECOVERY_POINT_MANUAL_DELETION or BACKUP_RESOURCES_PROTECTED_BY_BACKUP_PLAN) that this framework control evaluates. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="control_scope" type="object">
      Specifies the resource types and tags that determine which backup resources the framework control applies to. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="compliance_resource_ids" type="list(string)">
          The list of resource IDs (such as ARNs) that the control scope explicitly includes for compliance evaluation in the AWS Backup framework. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="compliance_resource_types" type="list(string)">
          The list of AWS resource types (e.g., 'AWS::Backup::RecoveryPoint') to which the Backup framework control's compliance scope applies, filtering which resources are evaluated by the control. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="tags" type="list(object)">
          Specifies the tag key-value pairs that AWS Backup uses to scope the control, so that only resources matching these tags are included in the framework's compliance evaluation. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="key" type="string">
              The tag key used to define the resource tag scope for a backup framework control, filtering which tagged resources the control applies to. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value" type="string">
              The value of a tag used in the control scope, which restricts the framework control's evaluation to backup resources that carry that tag key-value pair. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="framework_description" type="string">
  An optional description of the framework with a maximum 1,024 characters. Optional.
</ResponseField>

<ResponseField name="framework_name" type="string">
  The unique name of a framework. This name is between 1 and 256 characters, starting with a letter, and consisting of letters (a-z, A-Z), numbers (0-9), and underscores (_). Optional.
</ResponseField>

<ResponseField name="framework_tags" type="list(object)">
  Metadata that you can assign to help organize the frameworks that you create. Each tag is a key-value pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that can be attached to an AWS Backup framework to help identify, organize, or classify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="creation_time" type="string">
  The date and time that a framework is created, in ISO 8601 representation. The value of CreationTime is accurate to milliseconds. For example, 2020-07-10T15:00:00.000-08:00 represents the 10th of July 2020 at 3:00 PM 8 hours behind UTC. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="deployment_status" type="string">
  The deployment status of a framework. The statuses are: `CREATE_IN_PROGRESS | UPDATE_IN_PROGRESS | DELETE_IN_PROGRESS | COMPLETED | FAILED` Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="framework_arn" type="string">
  An Amazon Resource Name (ARN) that uniquely identifies Framework as a resource Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="framework_status" type="string">
  A framework consists of one or more controls. Each control governs a resource, such as backup plans, backup selections, backup vaults, or recovery points. You can also turn AWS Config recording on or off for each resource. The statuses are: `ACTIVE` when recording is turned on for all resources governed by the framework. `PARTIALLY_ACTIVE` when recording is turned off for at least one resource governed by the framework. `INACTIVE` when recording is turned off for all resources governed by the framework. `UNAVAILABLE` when AWS Backup is unable to validate recording status at this time. Computed by AWS after `ship`.
</ResponseField>

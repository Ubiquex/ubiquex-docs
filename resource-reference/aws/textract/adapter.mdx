`aws_textract_adapter` creates a real, custom adapter that plugs into Amazon Textract's pretrained Queries model, trained on an organization's own annotated sample documents to improve extraction accuracy on business-specific document types beyond what the generic pretrained model recognizes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	textract "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/textract"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own adapter"})

    		ubx.Resource(textract.Adapter, "example", textract.AdapterConfig{
    			AdapterName:  "example-adapter-name",
    			FeatureTypes: []string{"example"},
    			AutoUpdate:   "example",
    			Description:  "Managed by ubx.",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="adapter_name" type="string" required>
  The name to be assigned to the adapter being created. Required.
</ResponseField>

<ResponseField name="auto_update" type="string">
  Controls whether or not the adapter should automatically update. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description to be assigned to the adapter being created. Optional.
</ResponseField>

<ResponseField name="feature_types" type="list(string)" required>
  The type of feature that the adapter is being trained on. Currently, supported feature types are: QUERIES Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to be added to the adapter. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="adapter_id" type="string">
  A unique identifier for the adapter resource. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the adapter. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="creation_time" type="string">
  The date and time that the adapter was created. Computed by AWS after `ship`.
</ResponseField>

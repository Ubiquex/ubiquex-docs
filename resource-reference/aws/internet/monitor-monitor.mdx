`aws_internet_monitor_monitor` uses AWS's own global networking data, cross-referenced against a defined set of resources, VPCs, CloudFront distributions, WorkSpaces, to continuously measure real internet performance and availability between an application and its actual end users, and alert on regional disruptions or unusual latency without a caller needing external synthetic monitoring.

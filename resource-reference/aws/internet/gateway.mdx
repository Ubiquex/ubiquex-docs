`aws_internet_gateway` is a real, horizontally scaled, redundant VPC component that allows communication between resources in a VPC and the internet, the actual resource an `aws_route` with a 0.0.0.0/0 destination points traffic at for a subnet to be genuinely public.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	internet "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/internet"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own gateway"})

    		ubx.Resource(internet.Gateway, "ci-runner", internet.GatewayConfig{
    			Tags: []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="tags" type="list(object)">
  Any tags to assign to the internet gateway. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag entry in the tags map for this AWS internet gateway, used to label the gateway with custom metadata such as environment or owner. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag attached to the Internet Gateway, used to store metadata for identification, organization, or cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="internet_gateway_id" type="string">

</ResponseField>

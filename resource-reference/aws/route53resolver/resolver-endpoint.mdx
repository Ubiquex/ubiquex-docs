`aws_route53_resolver_resolver_endpoint` creates a real inbound or outbound DNS resolver endpoint in a VPC, the resource that lets on-premises DNS resolvers forward queries into that VPC, or lets the VPC forward queries out to on-premises DNS servers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53resolver "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53resolver"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resolver resolver endpoint"})

    		ubx.Resource(route53resolver.ResolverEndpoint, "example", route53resolver.ResolverEndpointConfig{
    			Direction:                 "example",
    			IpAddresses:               []map[string]any{{"ip": "example"}},
    			SecurityGroupIds:          []string{"example"},
    			Name:                      "example",
    			Dns64Enabled:              true,
    			Ipv6InternetAccessEnabled: true,
    			OutpostArn:                "arn:aws:iam::123456789012:policy/example",
    			PreferredInstanceType:     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="direction" type="string" required>
  Indicates whether the Resolver endpoint allows inbound or outbound DNS queries: - INBOUND: allows DNS queries to your VPC from your network - OUTBOUND: allows DNS queries from your VPC to your network - INBOUND_DELEGATION: allows DNS queries to your VPC from your network with authoritative answers from private hosted zones Required.
</ResponseField>

<ResponseField name="dns64_enabled" type="bool">
  Specifies whether DNS64 is enabled for the Inbound Resolver Endpoint. When set to true, if a DNS AAAA query is made for a domain that has only an A (IPv4) record, the resolver automatically synthesizes an AAAA (IPv6) response by embedding the IPv4 address into the well-known prefix 64:ff9b::/96. Default is false. Optional.
</ResponseField>

<ResponseField name="ip_addresses" type="list(object)" required>
  The subnets and IP addresses in your VPC that DNS queries originate from (for outbound endpoints) or that you forward DNS queries to (for inbound endpoints). The subnet ID uniquely identifies a VPC. Required.
  <Expandable title="properties">
    <ResponseField name="ip" type="string">
      The specific IP address to assign to the resolver endpoint within the referenced subnet; when not provided, AWS automatically chooses an available IP from that subnet. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ipv6" type="string">
      Specifies the IPv6 address to assign to the Resolver endpoint's elastic network interface (ENI) for this IP address entry, within the given subnet, enabling IPv6-only or dual-stack resolver endpoints. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="subnet_id" type="string">
      The subnet ID where the Route 53 Resolver endpoint's elastic network interface is deployed, defining the VPC subnet from which an IP address is allocated for this resolver endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ipv6_internet_access_enabled" type="bool">
  Specifies whether IPv6 Internet Gateway access is enabled through the Outbound Resolver Endpoint. When set to true, this property allows your Endpoint ENIs to reach public IPv6 target nameservers through an internet gateway. Default is false. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  A friendly name that lets you easily find a configuration in the Resolver dashboard in the Route 53 console. Optional.
</ResponseField>

<ResponseField name="outpost_arn" type="string">
  The ARN (Amazon Resource Name) for the Outpost. Optional.
</ResponseField>

<ResponseField name="preferred_instance_type" type="string">
  The Amazon EC2 instance type. Optional.
</ResponseField>

<ResponseField name="protocols" type="list(string)">
  Protocols used for the endpoint. DoH-FIPS is applicable for inbound endpoints only. Optional.
</ResponseField>

<ResponseField name="resolver_endpoint_type" type="string">
  The Resolver endpoint IP address type. Optional.
</ResponseField>

<ResponseField name="rni_enhanced_metrics_enabled" type="bool">
  Specifies whether RNI enhanced metrics are enabled for the Resolver Endpoints. When set to true, one-minute granular metrics are published in CloudWatch for each RNI associated with this endpoint. When set to false, metrics are not published. Default is false. Optional.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)" required>
  The ID of one or more security groups that control access to this VPC. The security group must include one or more inbound rules (for inbound endpoints) or outbound rules (for outbound endpoints). Inbound and outbound rules must allow TCP and UDP access. For inbound access, open port 53. For outbound access, open the port that you're using for DNS queries on your network. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Route53 Resolver endpoint, enabling you to label the endpoint for filtering, cost tracking, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_name_server_metrics_enabled" type="bool">
  Specifies whether target name server metrics are enabled for the Outbound Resolver Endpoint. When set to true, one-minute granular metrics are published in CloudWatch for each target name server associated with this endpoint. When set to false, metrics are not published. Default is false. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the resolver endpoint, such as arn:aws:route53resolver:us-east-1:123456789012:resolver-endpoint/resolver-endpoint-a1bzhi. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="host_vpcid" type="string">
  The ID of the VPC that you want to create the resolver endpoint in. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ip_address_count" type="string">
  The number of IP addresses that the resolver endpoint can use for DNS queries. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resolver_endpoint_id" type="string">
  The ID of the resolver endpoint. Computed by AWS after `ship`.
</ResponseField>

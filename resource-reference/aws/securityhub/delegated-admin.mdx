`aws_security_hub_delegated_admin` designates a real member account of an AWS Organization as the Security Hub delegated administrator, letting that account manage Security Hub across the whole organization instead of requiring the management account itself to do so.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own delegated admin"})

    		ubx.Resource(securityhub.DelegatedAdmin, "example", securityhub.DelegatedAdminConfig{
    			AdminAccountId: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="admin_account_id" type="string" required>
  The AWS-account identifier of the account to designate as the Security Hub CSPM administrator account. Required.
</ResponseField>

## Output properties

<ResponseField name="delegated_admin_identifier" type="string">
  The AWS account identifier of the delegated Security Hub administrator. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current delegation status of the Security Hub delegated administrator account, typically ENABLED or DISABLED. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

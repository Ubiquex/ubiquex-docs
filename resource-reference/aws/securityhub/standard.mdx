`aws_security_hub_standard` subscribes an account to a real, predefined security standard, such as the AWS Foundational Security Best Practices or CIS AWS Foundations Benchmark, the resource that actually turns on the bundle of individual `aws_security_hub_security_control` checks that standard is made of.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own standard"})

    		ubx.Resource(securityhub.Standard, "example", securityhub.StandardConfig{
    			StandardsArn:              "arn:aws:iam::123456789012:policy/example",
    			DisabledStandardsControls: []map[string]any{{"reason": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.aws.securityhub import Standard, StandardConfig
    from ubx.aws.securityhub.standard import Standard_DisabledStandardsControls

    def describe():
        ubx.intent("example own standard")

        ubx.resource(Standard, "example", StandardConfig(

        ubx.run("example", describe)

## Input properties

<ResponseField name="disabled_standards_controls" type="list(object)">
  Specifies which controls are to be disabled in a standard. *Maximum*: ``100`` Optional.
  <Expandable title="properties">
    <ResponseField name="reason" type="string">
      The user-supplied reason for disabling the specified Security Hub standard control in the DisabledStandardsControls list of the AWS::SecurityHub::Standard resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="standards_control_arn" type="string">
      The Amazon Resource Name (ARN) of the specific Security Hub standard control that is disabled for this standard membership. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="standards_arn" type="string" required>
  The ARN of the standard that you want to enable. To view a list of available ASH standards and their ARNs, use the [DescribeStandards](https://docs.aws.amazon.com/securityhub/1.0/APIReference/API_DescribeStandards.html) API operation. Required.
</ResponseField>

## Output properties

<ResponseField name="standards_subscription_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the subscription to a Security Hub standard. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

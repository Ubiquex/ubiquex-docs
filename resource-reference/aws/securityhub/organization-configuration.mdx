`aws_security_hub_organization_configuration` configures whether Security Hub is enabled automatically for every new account that joins an AWS Organization, managed from the account designated by an `aws_security_hub_delegated_admin`.

## Example

    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own organization configuration"})

    		ubx.Resource(securityhub.OrganizationConfiguration, "example", securityhub.OrganizationConfigurationConfig{
    			AutoEnable:          true,
    			AutoEnableStandards: "example",
    			ConfigurationType:   "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="auto_enable" type="bool" required>
  Whether to automatically enable Security Hub in new member accounts when they join the organization. Required.
</ResponseField>

<ResponseField name="auto_enable_standards" type="string">
  Whether to automatically enable Security Hub default standards in new member accounts when they join the organization. Optional.
</ResponseField>

<ResponseField name="configuration_type" type="string">
  Indicates whether the organization uses local or central configuration. Optional.
</ResponseField>

## Output properties

<ResponseField name="member_account_limit_reached" type="bool">
  Whether the maximum number of allowed member accounts are already associated with the Security Hub administrator account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="organization_configuration_identifier" type="string">
  The identifier of the OrganizationConfiguration being created and assigned as the unique identifier. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  Describes whether central configuration could be enabled as the ConfigurationType for the organization. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status_message" type="string">
  Provides an explanation if the value of Status is equal to FAILED when ConfigurationType is equal to CENTRAL. Computed by AWS after `ship`.
</ResponseField>

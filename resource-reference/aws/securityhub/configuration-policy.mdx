`aws_security_hub_configuration_policy` defines a real, centrally managed configuration, which standards and controls are enabled, applied across many accounts in an AWS Organization through Security Hub's own central configuration feature, rather than configuring each account's Security Hub individually.

## Input properties

<ResponseField name="configuration_policy" type="object" required>
  An object that defines how Security Hub is configured. Required.
  <Expandable title="properties">
    <ResponseField name="security_hub" type="object">
      An object that defines how AWS Security Hub is configured. Optional.
      <Expandable title="properties">
        <ResponseField name="enabled_standard_identifiers" type="list(string)">
          A list that defines which security standards are enabled in the configuration policy. Optional.
        </ResponseField>
        <ResponseField name="security_controls_configuration" type="object">
          An object that defines which security controls are enabled in an AWS Security Hub configuration policy. Optional.
          <Expandable title="properties">
            <ResponseField name="disabled_security_control_identifiers" type="list(string)">
              A list of security controls that are disabled in the configuration policy Optional.
            </ResponseField>
            <ResponseField name="enabled_security_control_identifiers" type="list(string)">
              A list of security controls that are enabled in the configuration policy. Optional.
            </ResponseField>
            <ResponseField name="security_control_custom_parameters" type="list(object)">
              A list of security controls and control parameter values that are included in a configuration policy. Optional.
              <Expandable title="properties">
                <ResponseField name="parameters" type="any">
                  Defines the map of security control parameter names to their ParameterValue objects (containing ValueType and Value, such as custom or default) for the associated control in the Security Hub configuration policy. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="security_control_id" type="string">
                  The identifier of the AWS Security Hub security control (e.g., EC2.1) for which the custom parameter values are specified. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="service_enabled" type="bool">
          Indicates whether Security Hub is enabled in the policy. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

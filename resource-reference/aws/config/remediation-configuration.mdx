`aws_config_remediation_configuration` defines the real, automated action, typically an SSM Automation document, AWS Config runs against a resource an `aws_config_config_rule` has flagged noncompliant, closing the loop from detection to an actual fix rather than only alerting on drift.

## Properties

<ResponseField name="automatic" type="bool">
  When set to true, AWS Config automatically executes the remediation action on noncompliant resources associated with the rule; when false, remediation must be invoked manually. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="config_rule_name" type="string" required>
  The name of the AWS Config rule for which this remediation configuration is defined, associating the remediation actions with that rule. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="execution_controls" type="object">
  Configures the SSM execution controls for the remediation, including the concurrent execution rate percentage and error percentage that limit how many concurrent remediation executions are allowed and the acceptable error rate. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="ssm_controls" type="object">
      Configures the Systems Manager automation controls for the remediation, specifically the concurrent execution rate and error rate percentages that determine how SSM documents are run. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="concurrent_execution_rate_percentage" type="number">
          Specifies the maximum percentage of remediation actions that can run in parallel for the rule's SSM document, throttling concurrent executions (default is 100). Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="error_percentage" type="number">
          The maximum percentage of remediation actions that are allowed to fail before the remediation action is stopped. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="maximum_automatic_attempts" type="number">
  Determines the maximum number of times AWS Config automatically retries the remediation action on a non-compliant resource, with a valid value between 1 and 5. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameters" type="any">
  Specifies the set of parameters passed to the AWS Systems Manager automation document that performs the remediation, mapping each parameter name to a static value or a dynamic value derived from the evaluated resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of AWS resource (e.g., 'AWS::EC2::Instance') that this Config remediation configuration applies to for automatic remediation actions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="retry_attempt_seconds" type="number">
  The maximum time, in seconds, during which AWS Config will make automatic remediation attempts for a noncompliant resource before giving up. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_id" type="string" required>
  The identifier of the remediation target, which is the name of the SSM document or the ARN of the custom action that remediates the noncompliant resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_type" type="string" required>
  The type of target for the remediation action, which must be set to SSM_DOCUMENT because AWS Config currently supports only SSM Automation documents as remediation targets. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_version" type="string">
  Specifies the version of the AWS Systems Manager automation document to use for the remediation action; if not provided, the default version of the document is used. Optional. **(AI-inferred)**
</ResponseField>

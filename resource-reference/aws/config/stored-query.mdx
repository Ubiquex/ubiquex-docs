`aws_config_stored_query` saves a real, reusable SQL-like query against the current configuration state of AWS resources that AWS Config tracks, so a caller doesn't have to rewrite the same advanced query, security group rules open to 0.0.0.0/0, for instance, from scratch each time.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stored query"})

    		ubx.Resource(config.StoredQuery, "example", config.StoredQueryConfig{
    			QueryExpression:  "example",
    			QueryName:        "example-query-name",
    			QueryDescription: "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="query_description" type="string">
  The query_description field provides an optional, human-readable description for the AWS Config stored query, used to document the query's purpose or details. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="query_expression" type="string" required>
  The SQL query expression (in AWS Config query language) that defines the resource configurations to retrieve when this stored query is executed. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="query_name" type="string" required>
  The name of the AWS Config stored query, which must be unique within the AWS account and is used to identify the query resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the stored query. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      For an AWS Config stored query, this field provides the value portion of a user-defined tag (key-value pair) used to organize and identify the query resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

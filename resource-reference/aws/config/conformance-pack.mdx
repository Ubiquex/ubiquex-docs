`aws_config_conformance_pack` bundles a real collection of `aws_config_config_rule`s and remediation actions into one deployable, monitorable unit, so an entire compliance standard's worth of rules gets rolled out and tracked together instead of one rule at a time.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			DeliveryS3Bucket:               "example",
    			DeliveryS3KeyPrefix:            "example",
    			Tags:                           []map[string]any{{"key": "example"}},
    			TemplateBody:                   "example",
    			TemplateS3Uri:                  "example",
    			TemplateSsmdocumentDetails:     map[string]any{"document_name": "example-document-name"},
    		})
    	}))
    }

## Input properties

<ResponseField name="conformance_pack_input_parameters" type="list(object)">
  A list of ConformancePackInputParameter objects. Optional.
  <Expandable title="properties">
    <ResponseField name="parameter_name" type="string">
      The name of an input parameter declared in the conformance pack template, used to provide a value when creating or updating the pack. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameter_value" type="string">
      The value assigned to a specific input parameter defined by the conformance pack template, used to customize the pack's configuration when deployed. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="conformance_pack_name" type="string" required>
  Name of the conformance pack which will be assigned as the unique identifier. Required.
</ResponseField>

<ResponseField name="delivery_s3_bucket" type="string">
  AWS Config stores intermediate files while processing conformance pack template. Optional.
</ResponseField>

<ResponseField name="delivery_s3_key_prefix" type="string">
  The prefix for delivery S3 bucket. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the conformance pack. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to the AWS Config Conformance Pack, used to categorize, organize, or identify the conformance pack resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a tag key-value pair assigned to the Conformance Pack, used for identifying, organizing, and managing the pack in AWS Config. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_body" type="string">
  A string containing full conformance pack template body. You can only specify one of the template body or template S3Uri fields. Optional.
</ResponseField>

<ResponseField name="template_s3_uri" type="string">
  Location of file containing the template body which points to the conformance pack template that is located in an Amazon S3 bucket. You can only specify one of the template body or template S3Uri fields. Optional.
</ResponseField>

<ResponseField name="template_ssmdocument_details" type="object">
  The TemplateSSMDocumentDetails object contains the name of the SSM document and the version of the SSM document. Optional.
  <Expandable title="properties">
    <ResponseField name="document_name" type="string">
      The name of the AWS Systems Manager (SSM) document that contains the conformance pack template. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="document_version" type="string">
      The version of the AWS Systems Manager (SSM) document that provides the conformance pack template; when omitted, the default version of the document is used. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="conformance_pack_arn" type="string">
  Amazon Resource Name (ARN) of the conformance pack. Computed by AWS after `ship`.
</ResponseField>

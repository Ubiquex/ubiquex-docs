`aws_config_delivery_channel` tells AWS Config where to actually deliver what an `aws_config_configuration_recorder` records, a configuration snapshot and history to an S3 bucket, and change notifications to an SNS topic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own delivery channel"})

    		ubx.Resource(config.DeliveryChannel, "example", config.DeliveryChannelConfig{
    			S3BucketName:                     "example-s3-bucket-name",
    			Name:                             "example",
    			ConfigSnapshotDeliveryProperties: map[string]any{"delivery_frequency": "example"},
    			S3KeyPrefix:                      "example",
    			S3KmsKeyArn:                      "arn:aws:iam::123456789012:policy/example",
    			SnsTopicArn:                      "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="config_snapshot_delivery_properties" type="object">
  Specifies how often AWS Config delivers configuration snapshot updates (e.g., every hour, six hours, or twenty-four hours) to the delivery channel's destination. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="delivery_frequency" type="string">
      Specifies the frequency with which AWS Config delivers configuration snapshots to the S3 bucket, accepting values like One_Hour, Three_Hours, Six_Hours, Twelve_Hours, and TwentyFour_Hours. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the AWS Config delivery channel, which must be unique in the account and defaults to 'default' if not specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="s3_bucket_name" type="string" required>
  Specifies the name of the Amazon S3 bucket to which AWS Config delivers configuration snapshots and configuration history files for the account. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="s3_key_prefix" type="string">
  The prefix for the Amazon S3 keys that AWS Config uses to store configuration snapshots and delivery logs in the bucket. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="s3_kms_key_arn" type="string">
  The ARN of the AWS KMS key that AWS Config uses to encrypt the configuration snapshots and configuration history delivered to the Amazon S3 bucket. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="sns_topic_arn" type="string">
  The ARN of the Amazon SNS topic to which AWS Config delivers configuration snapshots and configuration change notifications. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  This field is the name of the AWS Config delivery channel, which serves as its unique identifier and is typically set to 'default' unless otherwise specified. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

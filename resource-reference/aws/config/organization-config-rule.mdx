`aws_config_organization_config_rule` deploys an `aws_config_config_rule` across every account in an AWS Organization at once, the org-wide counterpart to defining and rolling out the same rule to each member account individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own organization config rule"})

    		ubx.Resource(config.OrganizationConfigRule, "example", config.OrganizationConfigRuleConfig{
    			OrganizationConfigRuleName:           "example-organization-config-rule-name",
    			ExcludedAccounts:                     []string{"example"},
    			OrganizationCustomPolicyRuleMetadata: map[string]any{"policy_text": "example"},
    			OrganizationCustomRuleMetadata:       map[string]any{"lambda_function_arn": "example"},
    			OrganizationManagedRuleMetadata:      map[string]any{"rule_identifier": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="excluded_accounts" type="list(string)">
  Specifies the AWS account IDs to exclude from the evaluation of this organization config rule, ensuring the rule does not apply to those accounts. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="organization_config_rule_name" type="string" required>
  The name assigned to the organization config rule, which must be unique within the organization. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="organization_custom_policy_rule_metadata" type="object">

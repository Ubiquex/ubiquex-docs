`aws_config_organization_conformance_pack` deploys an `aws_config_conformance_pack` across every account in an AWS Organization at once, the org-wide counterpart to rolling the same conformance pack out to each member account individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own organization conformance pack"})

    		ubx.Resource(config.OrganizationConformancePack, "example", config.OrganizationConformancePackConfig{
    			OrganizationConformancePackName: "example-organization-conformance-pack-name",
    			ConformancePackInputParameters:  []map[string]any{{"parameter_name": "example-parameter-name"}},
    			DeliveryS3Bucket:                "example",
    			DeliveryS3KeyPrefix:             "example",
    			ExcludedAccounts:                []string{"example"},
    			Tags:                            []map[string]any{{"key": "example"}},
    			TemplateBody:                    "example",
    			TemplateS3Uri:                   "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="conformance_pack_input_parameters" type="list(object)">
  A list of ConformancePackInputParameter objects. Optional.
  <Expandable title="properties">
    <ResponseField name="parameter_name" type="string">
      The name of an input parameter for the conformance pack, used to pass a value into the conformance pack template. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameter_value" type="string">
      The value portion of a key-value input parameter pair (with the associated parameter_key) that is supplied to the AWS Config organization conformance pack template when the conformance pack is deployed or updated. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="delivery_s3_bucket" type="string">
  AWS Config stores intermediate files while processing conformance pack template. Optional.
</ResponseField>

<ResponseField name="delivery_s3_key_prefix" type="string">
  The prefix for the delivery S3 bucket. Optional.
</ResponseField>

<ResponseField name="excluded_accounts" type="list(string)">
  A list of AWS accounts to be excluded from an organization conformance pack while deploying a conformance pack. Optional.
</ResponseField>

<ResponseField name="organization_conformance_pack_name" type="string" required>
  The name of the organization conformance pack. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the organization conformance pack. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the AWS Config organization conformance pack, used for metadata and resource identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_body" type="string">
  A string containing full conformance pack template body. Optional.
</ResponseField>

<ResponseField name="template_s3_uri" type="string">
  Location of file containing the template body. Optional.
</ResponseField>

## Output properties

<ResponseField name="organization_conformance_pack_arn" type="string">
  Amazon Resource Name (ARN) of the organization conformance pack. Computed by AWS after `ship`.
</ResponseField>

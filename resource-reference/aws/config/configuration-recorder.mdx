`aws_config_configuration_recorder` is the real, account-level switch that determines whether and which resource types AWS Config actually records configuration and configuration history for, the foundational resource every other AWS Config capability, rules, aggregation, remediation, depends on being turned on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own configuration recorder"})

    		ubx.Resource(config.ConfigurationRecorder, "example", config.ConfigurationRecorderConfig{
    			RoleArn:        "arn:aws:iam::123456789012:policy/example",
    			Name:           "example",
    			RecordingGroup: map[string]any{"all_supported": true},
    			RecordingMode:  map[string]any{"recording_frequency": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string">
  The name of the configuration recorder, which must be unique within the region and defaults to 'default' if not specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="recording_group" type="object">
  Specifies which AWS resource types are recorded by the configuration recorder, including whether to record all supported resource types and global resource types like IAM resources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="all_supported" type="bool">
      When set to true, AWS Config records configuration changes for all supported AWS resource types in the region. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="exclusion_by_resource_types" type="object">
      Specifies the resource types to exclude from being recorded by AWS Config, allowing you to record all supported types except those listed when allSupported is enabled. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="resource_types" type="list(string)" required>
          Specifies the list of AWS resource types that will be excluded from recording by the configuration recorder. Required. **(AI-inferred)**

      </Expandable>

    <ResponseField name="include_global_resource_types" type="bool">
      Indicates whether AWS Config records configuration changes to global resource types (such as IAM users, groups, roles, and customer managed policies) across all regions. Optional. **(AI-inferred)**

    <ResponseField name="recording_strategy" type="object">

Required. **(AI-inferred)**

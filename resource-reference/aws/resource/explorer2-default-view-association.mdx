`aws_resource_explorer2_default_view_association` sets a real `aws_resource_explorer2_view` as the default for its AWS Region, so a search that doesn't explicitly name a view uses this one automatically.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	resource "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/resource"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own explorer2 default view association"})

    		ubx.Resource(resource.Explorer2DefaultViewAssociation, "ci-runner", resource.Explorer2DefaultViewAssociationConfig{
    			ViewArn: "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="view_arn" type="string" required>
  The ARN of the Resource Explorer view that will be set as the default view for the account. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="associated_aws_principal" type="string">
  The AWS principal that the default view is associated with, used as the unique identifier for this resource. Computed by AWS after `ship`.
</ResponseField>

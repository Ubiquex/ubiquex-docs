`aws_resource_explorer2_view` defines a real, filtered search scope over an `aws_resource_explorer2_index`, the resource that AWS Resource Explorer's own search queries are actually run against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	resource "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/resource"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own explorer2 view"})

    		ubx.Resource(resource.Explorer2View, "example", resource.Explorer2ViewConfig{
    			ViewName:           "example-view-name",
    			Filters:            map[string]any{"filter_string": "example"},
    			IncludedProperties: []map[string]any{{"name": "example-name"}},
    			Scope:              "example",
    			Tags:               "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="filters" type="object">
  Specifies the query filter string that determines which resources are included in this Resource Explorer view. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="filter_string" type="string" required>
      The Resource Explorer query string that defines which resources are included in the view, using the same syntax as the Search API (e.g., filtering by resource type, tags, or resource properties). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="included_properties" type="list(object)">
  Specifies the list of resource property names (each as an 'IncludedProperty' object) to include in the view, controlling which resource properties are returned for resources in the view's search results. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of a single resource property to include in the view's output, such as 'InstanceId' or 'Tags' for an EC2 instance, determining which fields are returned for each resource in the view. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scope" type="string">
  The scope specifies the AWS Region (or the literal value 'global' to include all Regions) whose resources this view can search, defaulting to the Region of the CloudFormation stack when omitted. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  The Tags property specifies custom key-value pairs to attach to this AWS Resource Explorer view, which you can use to categorize, identify, and manage the view within AWS. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="view_name" type="string" required>
  The user-specified name for the Resource Explorer view, which uniquely identifies the view within your account and Region. Required. **(AI-inferred)**
</ResponseField>

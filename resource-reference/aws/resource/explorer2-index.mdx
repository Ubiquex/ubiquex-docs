`aws_resource_explorer2_index` creates a real, per-Region search index for AWS Resource Explorer, the prerequisite that must exist in a Region before an `aws_resource_explorer2_view` can be created there.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	resource "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/resource"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own explorer2 index"})

    		ubx.Resource(resource.Explorer2Index, "example", resource.Explorer2IndexConfig{
    			Type: "example",
    			Tags: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

<ResponseField name="type" type="string" required>
  Specifies the index type, either LOCAL (indexes resources in your account and region) or AGGREGATOR (aggregates indices from multiple accounts and regions). Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Resource Explorer index, assigned by AWS when the index is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="index_state" type="string">
  The current lifecycle state of the index, such as ACTIVE, CREATING, UPDATING, or DELETING, as reported by AWS Resource Explorer. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

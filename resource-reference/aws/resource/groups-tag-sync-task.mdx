`aws_resource_groups_tag_sync_task` continuously syncs a real tag's value from an `aws_resource_groups_group`'s defining query onto every resource that matches it, keeping tags current automatically as group membership changes rather than requiring a separate process to re-tag resources by hand.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	resource "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/resource"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own groups tag sync task"})

    		ubx.Resource(resource.GroupsTagSyncTask, "ci-runner", resource.GroupsTagSyncTaskConfig{
    			Group:    "example",
    			RoleArn:  "arn:aws:iam::123456789012:policy/ci",
    			TagKey:   "example",
    			TagValue: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="group" type="string" required>
  The Amazon resource name (ARN) or name of the application group for which you want to create a tag-sync task Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon resource name (ARN) of the role assumed by the service to tag and untag resources on your behalf. Required.
</ResponseField>

<ResponseField name="tag_key" type="string" required>
  The tag key. Resources tagged with this tag key-value pair will be added to the application. If a resource with this tag is later untagged, the tag-sync task removes the resource from the application. Required.
</ResponseField>

<ResponseField name="tag_value" type="string" required>
  The tag value. Resources tagged with this tag key-value pair will be added to the application. If a resource with this tag is later untagged, the tag-sync task removes the resource from the application. Required.
</ResponseField>

## Output properties

<ResponseField name="group_arn" type="string">

<ResponseField name="group_name" type="string">
  The Name of the application group for which the TagSyncTask is created Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the TagSyncTask Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="task_arn" type="string">
  The ARN of the TagSyncTask resource Computed by AWS after `ship`.
</ResponseField>

`aws_managed_blockchain_node` creates a real peer node running within an `aws_managed_blockchain_member`'s participation in a Hyperledger Fabric network on Amazon Managed Blockchain, the compute that actually executes chaincode and maintains the ledger.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	managedblockchain "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/managedblockchain"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own node"})

    		ubx.Resource(managedblockchain.Node, "example", managedblockchain.NodeConfig{
    			NetworkId:         "example",
    			NodeConfiguration: map[string]any{"availability_zone": "example", "instance_type": "example"},
    			MemberId:          "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="member_id" type="string">
  The unique identifier of the Managed Blockchain member to which this node belongs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_id" type="string" required>
  The unique identifier of the Managed Blockchain network to which the node belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="node_configuration" type="object" required>
  Defines the operational parameters of the Managed Blockchain node, including the required EC2 instance type and optional Availability Zone and log publishing configuration. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="availability_zone" type="string" required>
      Specifies the Availability Zone in which the Amazon Managed Blockchain node is created. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="instance_type" type="string" required>
      The EC2 instance type (e.g., bc.t3.large) that determines the compute, memory, and storage capacity allocated to the Managed Blockchain node. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this Managed Blockchain node. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

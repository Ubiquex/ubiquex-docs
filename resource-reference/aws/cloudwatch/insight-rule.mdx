`aws_cloud_watch_insight_rule` is a Contributor Insights rule, a real, JSON-defined filter and aggregation run against log data to surface the top contributors, the noisiest client IPs, the slowest URLs, to a pattern rather than only an aggregate metric.

## Input properties

<ResponseField name="apply_on_transformed_logs" type="bool">
  When set to true, this boolean indicates that the Contributor Insights rule evaluates logs after they have been processed by a CloudWatch Logs transformation, rather than the original raw logs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="rule_body" type="string" required>
  The JSON rule definition for the Contributor Insights rule, specifying the log filter, aggregation, and metric settings. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rule_name" type="string" required>
  The name of the Contributor Insights rule, which must be unique within your AWS account and is used to identify and reference the rule in CloudWatch. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rule_state" type="string" required>
  Specifies whether the Contributor Insights rule is enabled or disabled, with valid values ENABLED and DISABLED, controlling whether the rule continuously collects and aggregates log data for the specified metrics. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tags to attach to the CloudWatch Contributor Insights rule, enabling you to categorize and manage the rule across your AWS environment. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the CloudWatch Contributor Insights rule, used for resource categorization, cost allocation, and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.

  </Expandable>
</ResponseField>

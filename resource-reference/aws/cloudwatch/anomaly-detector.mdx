`aws_cloud_watch_anomaly_detector` learns a real metric's normal pattern, including seasonal and trend behavior, and computes an expected value band an `aws_cloud_watch_alarm` can alarm against, catching deviations a fixed, static threshold would either miss or false-positive on.

## Input properties

<ResponseField name="configuration" type="object">
  The configuration settings for the anomaly detector, specifying metric characteristics such as the period and evaluation periods (and optionally periodic spacing) that control how the detection model analyzes the metric. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="excluded_time_ranges" type="list(object)">
      Specifies the time ranges, defined by start and end times, during which CloudWatch Anomaly Detector will not perform anomaly detection on the associated metric(s). Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="end_time" type="string">
          Specifies the end time of the excluded time range, in ISO 8601 format, during which the anomaly detector ignores data. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="start_time" type="string">
          The start time (in ISO 8601 format) of a time range to exclude from anomaly detection model training, marking the beginning of a period when the detector will not use data for learning the normal pattern. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="metric_time_zone" type="string">
      Sets the IANA time zone (e.g., 'America/New_York') used by the anomaly detector to evaluate and display metric anomalies, overriding the default UTC. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dimensions" type="list(object)">

  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of a dimension that, along with its value and other dimensions, uniquely identifies the CloudWatch metric for which this anomaly detector is configured. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of the dimension that, combined with the dimension name and metric name, identifies the specific metric for which the CloudWatch anomaly detector is configured. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metric_characteristics" type="object">
  The metric_characteristics object specifies the period (in seconds) and timezone (e.g., 'UTC') used by the CloudWatch anomaly detector for evaluating the metric data. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="periodic_spikes" type="bool">

    </ResponseField>
  </Expandable>
</ResponseField>

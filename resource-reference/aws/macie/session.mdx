`aws_macie_session` enables Macie for an account, the real, account-level resource that must exist before any `aws_macie_findings_filter` or `aws_macie_custom_data_identifier` can be created.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	macie "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/macie"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own session"})

    		ubx.Resource(macie.Session, "example", macie.SessionConfig{
    			FindingPublishingFrequency: "example",
    			Status:                     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="finding_publishing_frequency" type="string">
  A enumeration value that specifies how frequently finding updates are published. Optional.
</ResponseField>

<ResponseField name="status" type="string">
  A enumeration value that specifies the status of the Macie Session. Optional.
</ResponseField>

## Output properties

<ResponseField name="automated_discovery_status" type="string">
  The status of automated sensitive data discovery for the Macie session. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="aws_account_id" type="string">
  AWS account ID of customer Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="service_role" type="string">
  Service role used by Macie Computed by AWS after `ship`.
</ResponseField>

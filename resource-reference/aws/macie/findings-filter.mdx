`aws_macie_findings_filter` defines real custom criteria, severity, finding type, affected resource, that either narrows which Macie findings a query returns or automatically archives findings matching those criteria, so routine noise doesn't have to be triaged by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	macie "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/macie"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own findings filter"})

    		ubx.Resource(macie.FindingsFilter, "ci-runner", macie.FindingsFilterConfig{
    			FindingCriteria: map[string]any{"criterion": "example"},
    			Name:            "ci-runner",
    			Action:          "example",
    			Description:     "Managed by ubx.",
    			Position:        1,
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="action" type="string">
  Specifies the action to take on findings that match the filter's criteria, with allowed values ARCHIVE to archive (suppress) the findings or NOOP to not change them, in AWS Macie. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Findings filter description Optional.
</ResponseField>

<ResponseField name="finding_criteria" type="object" required>
  Defines the matching conditions, evaluated against finding attributes such as severity, type, or other properties, that determine which findings are included in the filter. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="criterion" type="any">
      Map of filter criteria. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  Findings filter name Required.
</ResponseField>

<ResponseField name="position" type="number">
  Findings filter position. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tags associated with a resource Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag that you can attach to the findings filter to help identify and organize it in AWS Macie. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

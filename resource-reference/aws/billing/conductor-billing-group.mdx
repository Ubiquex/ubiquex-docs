`aws_billing_conductor_billing_group` is a set of accounts (or AWS Organizations, for billing-transfer customers) sharing one primary account and one pricing plan in AWS Billing Conductor, the unit a custom, pro forma version of AWS billing data is actually generated and charged back against.

## Input properties

<ResponseField name="account_grouping" type="object" required>

  <Expandable title="properties">
    <ResponseField name="auto_associate" type="bool">

    <ResponseField name="linked_account_ids" type="list(string)">

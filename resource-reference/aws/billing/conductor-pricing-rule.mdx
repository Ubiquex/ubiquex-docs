`aws_billing_conductor_pricing_rule` defines one global or service-specific rate adjustment inside an `aws_billing_conductor_pricing_plan`, the real building block a pricing plan combines several of to produce the rate an end customer actually sees.

## Input properties

<ResponseField name="billing_entity" type="string">
  The seller of services provided by AWS, their affiliates, or third-party providers selling services via AWS Marketplaces. Supported billing entities are AWS, AWS Marketplace, and AISPL. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Pricing rule description Optional.
</ResponseField>

<ResponseField name="modifier_percentage" type="number">
  Pricing rule modifier percentage Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Pricing rule name Required.
</ResponseField>

<ResponseField name="operation" type="string">
  The Operation which a SKU pricing rule is modifying Optional.
</ResponseField>

<ResponseField name="scope" type="string" required>
  A term used to categorize the granularity of a Pricing Rule. Required.
</ResponseField>

<ResponseField name="service" type="string">
  The service which a pricing rule is applied on Optional.
</ResponseField>

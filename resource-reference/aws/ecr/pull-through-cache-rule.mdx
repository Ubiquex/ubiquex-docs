`aws_ecr_pull_through_cache_rule` configures an `aws_ecr_repository` prefix to automatically cache images pulled from an upstream public registry, Docker Hub, Quay, GitHub Container Registry, and more, the first time they're requested, so later pulls are served from ECR itself.

## Properties

<ResponseField name="credential_arn" type="string">
  The Amazon Resource Name (ARN) of the AWS Secrets Manager secret that identifies the credentials to authenticate to the upstream registry. Optional.
</ResponseField>

<ResponseField name="custom_role_arn" type="string">
  The ARN of the IAM role to be assumed by Amazon ECR to authenticate to ECR upstream registry. This role must be in the same account as the registry that you are configuring. Optional.
</ResponseField>

<ResponseField name="ecr_repository_prefix" type="string">
  The ECRRepositoryPrefix is a custom alias for upstream registry url. Optional.
</ResponseField>

<ResponseField name="upstream_registry" type="string">
  The name of the upstream registry. Optional.
</ResponseField>

<ResponseField name="upstream_registry_url" type="string">
  The upstreamRegistryUrl is the endpoint of upstream registry url of the public repository to be cached Optional.
</ResponseField>

<ResponseField name="upstream_repository_prefix" type="string">
  The repository name prefix of upstream registry to match with the upstream repository name. When this field isn't specified, Amazon ECR will use the `ROOT`. Optional.
</ResponseField>

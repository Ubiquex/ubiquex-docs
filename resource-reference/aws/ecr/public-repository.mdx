`aws_ecr_public_repository` creates a real, publicly readable repository in the Amazon ECR Public Gallery, distinct from `aws_ecr_repository`'s own private-by-default model, letting anyone pull an image without AWS credentials.

## Input properties

<ResponseField name="repository_catalog_data" type="object">
  The details about the repository that are publicly visible in the Amazon ECR Public Gallery. For more information, see [Amazon ECR Public repository catalog data](https://docs.aws.amazon.com/AmazonECR/latest/public/public-repository-catalog-data.html) in the *Amazon ECR Public User Guide*. Optional.
  <Expandable title="properties">
    <ResponseField name="about_text" type="string">
      Provide a detailed description of the repository. Identify what is included in the repository, any licensing details, or other relevant information. Optional.
    </ResponseField>
    <ResponseField name="architectures" type="list(string)">
      Select the system architectures that the images in your repository are compatible with. Optional.
    </ResponseField>
    <ResponseField name="operating_systems" type="list(string)">
      Select the operating systems that the images in your repository are compatible with. Optional.
    </ResponseField>
    <ResponseField name="repository_description" type="string">
      The description of the public repository. Optional.
    </ResponseField>
    <ResponseField name="usage_text" type="string">
      Provide detailed information about how to use the images in the repository. This provides context, support information, and additional usage details for users of the repository. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="repository_name" type="string">
  The name to use for the public repository. The repository name may be specified on its own (such as ``nginx-web-app``) or it can be prepended with a namespace to group the repository into a category (such as ``project-a/nginx-web-app``). If you don't specify a name, CFNlong generates a unique physical ID and uses that ID for the repository name. For more information, see [Name Type](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-properties-name.html). If you specify a name, you cannot perform updates that require replacement of this resource. You can perform updates that require no or some interruption. If you must replace the resource, specify a new name. Optional.
</ResponseField>

<ResponseField name="repository_policy_text" type="any">
  The JSON repository policy text to apply to the public repository. For more information, see [Amazon ECR Public repository policies](https://docs.aws.amazon.com/AmazonECR/latest/public/public-repository-policies.html) in the *Amazon ECR Public User Guide*. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the ECR public repository, used to identify, categorize, and organize the repository within your AWS environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

  The Amazon Resource Name (ARN) assigned to the public ECR repository. Computed by AWS after `ship`. **(AI-inferred)**

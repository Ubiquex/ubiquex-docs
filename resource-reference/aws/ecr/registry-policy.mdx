`aws_ecr_registry_policy` attaches a real resource-based access policy to an account's entire ECR registry, controlling cross-account replication and access across every `aws_ecr_repository` in it at once, rather than one repository's own policy at a time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ecr "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ecr"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own registry policy"})

    		ubx.Resource(ecr.RegistryPolicy, "example", ecr.RegistryPolicyConfig{
    			PolicyText: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="policy_text" type="any" required>
  The JSON policy text for your registry. Required.
</ResponseField>

## Output properties

<ResponseField name="registry_id" type="string">
  The registry id. Computed by AWS after `ship`.
</ResponseField>

`aws_ecr_registry_scanning_configuration` sets real, registry-wide image vulnerability scanning rules, basic or enhanced, applied automatically across every `aws_ecr_repository` matching a defined filter, rather than a caller configuring scanning on each repository individually.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

## Input properties

<ResponseField name="rules" type="list(object)" required>
  The scanning rules associated with the registry. A registry scanning configuration may contain a maximum of 2 rules. Required.
  <Expandable title="properties">
    <ResponseField name="repository_filters" type="list(object)">
      Defines which repositories a scanning rule applies to by listing repository filters, each with a filter pattern (e.g., a name or wildcard expression) and a filter type (WILDCARD or EXACT) that tells ECR how to match repository names. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="filter" type="string">
          The repository name pattern (such as 'example' or 'prod/*') that the scanning rule uses to match which repositories it applies to. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="filter_type" type="string">
          Specifies the type of repository filter (e.g., WILDCARD) used to match repository names for the ECR scanning rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="scan_frequency" type="string">
      Specifies the frequency at which ECR scans images in repositories that match this rule, either on each image push (SCAN_ON_PUSH) or continuously (CONTINUOUS_SCAN). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scan_type" type="string" required>
  The type of scanning configured for the registry. Required.
</ResponseField>

## Output properties

<ResponseField name="registry_id" type="string">
  The registry id. Computed by AWS after `ship`.
</ResponseField>

`aws_ecr_signing_configuration` references one or more Signer signing profiles, and optionally repository filters, so ECR automatically signs an image with the identity of whoever pushed it the moment it's pushed, up to 10 signing rules per registry for stronger security boundaries, without a caller signing images manually as a separate step. Launched November 2025.

## Example

## Input properties

<ResponseField name="rules" type="list(object)" required>
  Array of signing rules that define which repositories should be signed and with which signing profiles. Required.
  <Expandable title="properties">
    <ResponseField name="repository_filters" type="list(object)">
      Specifies the repository filters that determine which Amazon ECR repositories this signing configuration rule applies to, matching by prefix or exact repository name. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="filter" type="string">
          The repository name pattern (e.g., a prefix like 'prod/') that selects which ECR repositories this signing rule applies to, with the matching behavior defined by the associated filter type. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="filter_type" type="string">
          Specifies the matching strategy for a repository filter in an ECR signing configuration rule, where 'PREFIX_MATCH' ensures the rule applies to repositories whose names start with the given filter value. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="signing_profile_arn" type="string">
      Specifies the ARN of the AWS Signer signing profile that this rule uses to require signatures on matching container images. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="registry_id" type="string">
  12-digit AWS account ID of the ECR registry. Computed by AWS after `ship`.
</ResponseField>

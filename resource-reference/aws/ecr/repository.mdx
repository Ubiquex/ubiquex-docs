---
title: "aws_ecr_repository"
description: "A private container image repository."
---

`aws_ecr_repository` creates a real, private ECR repository for storing
container images, with real, configurable scanning and mutability
settings.

Every tab below is a complete, runnable program, not a fragment,
real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ecr "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ecr"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own repository"})

    		ubx.Resource(ecr.Repository, "ci-runner", ecr.RepositoryConfig{
    			Name:               "ci-runner",
    			ForceDelete:        true,
    			ImageTagMutability: "example",
    			Tags:               map[string]string{"managed-by": "ubx"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Repository } from "jsr:@ubx/sdk-aws/aws/ecr/repository";

    export default stack("payments", () => {
      intent({ summary: "payments own repository" });

      resource(Repository, "ci-runner", {
        name: "ci-runner",
        forceDelete: true,
        imageTagMutability: "example",
        tags: { "managed-by": "ubx" },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.ecr import Repository, RepositoryConfig

    def describe():
        ubx.intent("payments own repository")

        ubx.resource(Repository, "ci-runner", RepositoryConfig(
            name="ci-runner",
            force_delete=True,
            image_tag_mutability="example",
            tags={"managed-by": "ubx"},
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Create aws_ecr_repository called "ci-runner", with force delete
    true, image tag mutability example, tags a set value.
    ```
  </Tab>
</Tabs>

## Input properties

<ResponseField name="name" type="string" required>
  The repository's own name.
</ResponseField>

<ResponseField name="image_tag_mutability" type="string" default="MUTABLE">
  `MUTABLE` or `IMMUTABLE`.
</ResponseField>

<ResponseField name="force_delete" type="bool" default="false">
  Delete the repository even if it still contains images.
</ResponseField>

<ResponseField name="encryption_configuration" type="object">
  How images are encrypted at rest.
  <Expandable title="properties">
    <ResponseField name="encryption_type" type="string" default="AES256">
      `AES256` or `KMS`.
    </ResponseField>
    <ResponseField name="kms_key" type="string">
      The KMS key to use, only relevant when `encryption_type` is `KMS`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_scanning_configuration" type="object">
  Whether pushed images are automatically scanned.
  <Expandable title="properties">
    <ResponseField name="scan_on_push" type="bool" default="false">
      Automatically scan every image the moment it's pushed.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Same value as `name`.
</ResponseField>

<ResponseField name="arn" type="string">
  The repository's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="registry_id" type="string">
  The real AWS account ID the registry belongs to.
</ResponseField>

<ResponseField name="repository_url" type="string">
  The full URL used to push and pull images.
</ResponseField>

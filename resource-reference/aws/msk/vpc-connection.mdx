`aws_msk_vpc_connection` creates a real private connection from a VPC to an `aws_msk_cluster` using AWS PrivateLink, letting clients in that VPC reach the cluster's brokers without traversing the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	msk "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/msk"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpc connection"})

    		ubx.Resource(msk.VpcConnection, "example", msk.VpcConnectionConfig{
    			Authentication:   "example",
    			ClientSubnets:    []string{"example"},
    			SecurityGroups:   []string{"example"},
    			TargetClusterArn: "arn:aws:iam::123456789012:policy/example",
    			VpcId:            "example",
    			Tags:             "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="authentication" type="string" required>
  The type of private link authentication Required.
</ResponseField>

<ResponseField name="client_subnets" type="list(string)" required>
  Specifies the subnets in the client VPC where the MSK VPC connection is created, enabling network access from those subnets to the cluster. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_groups" type="list(string)" required>
  Specifies the security group IDs to attach to the elastic network interface created for the MSK VPC connection, controlling traffic to and from client resources. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

<ResponseField name="target_cluster_arn" type="string" required>
  The Amazon Resource Name (ARN) of the target cluster Required.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the client VPC that will be connected to the MSK cluster using this VPC connection. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) assigned to the MSK VPC connection. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

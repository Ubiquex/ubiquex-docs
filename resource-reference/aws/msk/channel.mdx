`aws_msk_channel` creates a real, direct delivery pipeline from an MSK Kafka topic into an Apache Iceberg table, configuring the destination catalog, database, table, and partition spec, without a separate Kafka Connect or Firehose hop in between. This is a newer MSK capability for direct-to-Iceberg ingestion, verified live this session against AWS's own field-level schema rather than general knowledge.

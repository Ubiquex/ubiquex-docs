`aws_msk_cluster_policy` attaches a real resource-based access policy to an `aws_msk_cluster`, controlling which principals, including from other accounts, can connect to and manage it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	msk "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/msk"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cluster policy"})

    		ubx.Resource(msk.ClusterPolicy, "example", msk.ClusterPolicyConfig{
    			ClusterArn: "arn:aws:iam::123456789012:policy/example",
    			Policy:     "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="cluster_arn" type="string" required>
  The arn of the cluster for the resource policy. Required.
</ResponseField>

<ResponseField name="policy" type="any" required>
  A policy document containing permissions to add to the specified cluster. Required.
</ResponseField>

## Output properties

<ResponseField name="current_version" type="string">
  The current version of the policy attached to the specified cluster Computed by AWS after `ship`.
</ResponseField>

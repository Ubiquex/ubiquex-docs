`aws_msk_configuration` defines a real set of Kafka broker configuration properties that can be applied to one or more `aws_msk_cluster`s instead of hand-tuning each cluster's brokers individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	msk "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/msk"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own configuration"})

    		ubx.Resource(msk.Configuration, "ci-runner", msk.ConfigurationConfig{
    			Name:              "ci-runner",
    			ServerProperties:  "example",
    			Description:       "Managed by ubx.",
    			KafkaVersionsList: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.msk import Configuration, ConfigurationConfig

    def describe():
        ubx.intent("payments own configuration")

        ubx.resource(Configuration, "ci-runner", ConfigurationConfig(
            name="ci-runner",
            server_properties="example",
            description="Managed by ubx.",
            kafka_versions_list=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-friendly description of the MSK configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kafka_versions_list" type="list(string)">
  Defines the list of Apache Kafka versions that this MSK configuration supports, restricting its use to clusters running one of the specified versions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the MSK configuration, which must be unique within an AWS account and Region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_properties" type="string" required>
  Specifies the Apache Kafka server properties for this MSK configuration, supplied as a string of newline-separated `key=value` pairs that define broker settings such as `auto.create.topics.enable`. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this MSK configuration. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="latest_revision" type="object">

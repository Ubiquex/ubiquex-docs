`aws_msk_batch_scram_secret` associates a real batch of Secrets Manager SASL/SCRAM secrets with an `aws_msk_cluster`, enabling username/password authentication for clients connecting to that cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	msk "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/msk"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own batch scram secret"})

    		ubx.Resource(msk.BatchScramSecret, "example", msk.BatchScramSecretConfig{
    			ClusterArn:    "arn:aws:iam::123456789012:policy/example",
    			SecretArnList: []string{"example"},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="cluster_arn" type="string" required>
  The ARN of the Amazon MSK cluster to which the batch of SASL/SCRAM secrets will be associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="secret_arn_list" type="list(string)">
  The list of AWS Secrets Manager secret ARNs to associate with the MSK cluster for SCRAM authentication. Optional. **(AI-inferred)**
</ResponseField>

`aws_msk_serverless_cluster` creates a real serverless Amazon MSK cluster that scales Kafka capacity automatically with load, reachable privately from up to five VPCs in the same account through AWS PrivateLink without the broker and storage sizing an `aws_msk_cluster` requires.

    }

## Input properties

<ResponseField name="client_authentication" type="object" required>
  Configures client authentication for the MSK Serverless cluster, specifically enabling or disabling AWS IAM access control via the nested Sasl.Iam property. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="sasl" type="object" required>
      Defines the SASL authentication configuration for the MSK Serverless cluster, which must include the Iam property to enable IAM-based client authentication, as serverless clusters support only IAM as the SASL mechanism. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="iam" type="object" required>
          Enables IAM access control for SASL authentication, allowing clients to authenticate to the cluster using AWS Identity and Access Management (IAM) credentials. Required. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="enabled" type="bool" required>
              Enables IAM-based access control for SASL authentication on the MSK Serverless cluster. Required. **(AI-inferred)**

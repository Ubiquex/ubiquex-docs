`aws_sage_maker_data_quality_job_definition` defines a real, scheduled job that compares an `aws_sage_maker_endpoint`'s live inference data against a baseline statistical profile, the configuration an `aws_sage_maker_monitoring_schedule` runs to detect data quality drift.

`aws_sage_maker_app` launches a real running application instance, JupyterLab, Code Editor, RStudio, inside an `aws_sage_maker_domain`, scoped to a specific `aws_sage_maker_user_profile` or `aws_sage_maker_space`.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sage "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sage"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own maker app"})

    		ubx.Resource(sage.MakerApp, "example", sage.MakerAppConfig{
    			AppName:         "example-app-name",
    			AppType:         "example",
    			DomainId:        "example",
    			UserProfileName: "example-user-profile-name",
    			RecoveryMode:    true,
    			ResourceSpec:    map[string]any{"instance_type": "example"},
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="app_name" type="string" required>
  The name of the app. Required.
</ResponseField>

<ResponseField name="app_type" type="string" required>
  The type of app. Required.
</ResponseField>

<ResponseField name="domain_id" type="string" required>
  The domain ID. Required.
</ResponseField>

<ResponseField name="recovery_mode" type="bool">
  Indicates whether the application is launched in recovery mode. Optional.
</ResponseField>

<ResponseField name="resource_spec" type="object">
  Specifies the SageMaker image version ARN and the compute instance type used for this SageMaker app. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="instance_type" type="string">
      The instance type that the image version runs on. Optional.
    </ResponseField>
    <ResponseField name="lifecycle_config_arn" type="string">
      The Amazon Resource Name (ARN) of the Lifecycle Configuration to attach to the Resource. Optional.
    </ResponseField>
    <ResponseField name="sage_maker_image_arn" type="string">
      The ARN of the SageMaker image that the image version belongs to. Optional.
    </ResponseField>
    <ResponseField name="sage_maker_image_version_arn" type="string">
      The ARN of the image version created on the instance. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to apply to the app. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the SageMaker App, used for organizing, cost allocation, and identity-based access control of the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the SageMaker App, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_profile_name" type="string" required>
  The user profile name. Required.
</ResponseField>

## Output properties

<ResponseField name="app_arn" type="string">
  The Amazon Resource Name (ARN) of the app. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="built_in_lifecycle_config_arn" type="string">
  The lifecycle configuration that runs before the default lifecycle configuration. Computed by AWS after `ship`.
</ResponseField>

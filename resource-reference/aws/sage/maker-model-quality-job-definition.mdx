`aws_sage_maker_model_quality_job_definition` defines a real, scheduled job that compares an `aws_sage_maker_endpoint`'s live predictions against ground-truth labels to compute accuracy metrics, the configuration an `aws_sage_maker_monitoring_schedule` runs to detect model quality drift after deployment.

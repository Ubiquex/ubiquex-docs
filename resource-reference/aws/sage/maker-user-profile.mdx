`aws_sage_maker_user_profile` creates a real, individual user's identity and settings within an `aws_sage_maker_domain`, the resource that `aws_sage_maker_app`s and a private `aws_sage_maker_space` are scoped to for that specific person.

    	ubx.Main(ubx.Stack("example", func() {

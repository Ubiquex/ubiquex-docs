`aws_sage_maker_mlflow_app` launches a real, running MLflow UI application against an `aws_sage_maker_mlflow_tracking_server`, the resource that actually serves the interactive tracking-server web interface.

## Input properties

<ResponseField name="artifact_store_uri" type="string" required>
  The S3 URI for a general purpose bucket to use as the MLflow App artifact store. Required.
</ResponseField>

<ResponseField name="model_registration_mode" type="string">
  Whether to enable or disable automatic registration of new MLflow models to the SageMaker Model Registry. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the MLflow App. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) for an IAM role in your account that the MLflow App uses to access the artifact store in Amazon S3. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to associate with the MLflow App. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the SageMaker MLflow App, used to organize, identify, and manage access to the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the SageMaker MLflow App, used to assign metadata such as environment, owner, or cost center for resource management and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="weekly_maintenance_window_start" type="string">
  The day and time of the week in Coordinated Universal Time (UTC) 24-hour standard time that weekly maintenance updates are scheduled. For example: Tue:03:30. Optional.
</ResponseField>

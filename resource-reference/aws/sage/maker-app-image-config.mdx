`aws_sage_maker_app_image_config` defines real configuration, the kernel, file system, and container settings, applied to an `aws_sage_maker_image`'s custom container when it's used to run an `aws_sage_maker_app`.

## Example

## Input properties

<ResponseField name="app_image_config_name" type="string" required>
  The Name of the AppImageConfig. Required.
</ResponseField>

<ResponseField name="code_editor_app_image_config" type="object">
  The configuration for the kernels in a SageMaker image running as a CodeEditor app. Optional.
  <Expandable title="properties">
    <ResponseField name="container_config" type="object">
      The container configuration for a SageMaker image. Optional.
      <Expandable title="properties">
        <ResponseField name="container_arguments" type="list(string)">
          A list of arguments to apply to the container. Optional.
        </ResponseField>
        <ResponseField name="container_entrypoint" type="list(string)">
          The custom entry point to use on container. Optional.
        </ResponseField>
        <ResponseField name="container_environment_variables" type="list(object)">
          A list of variables to apply to the custom container. Optional.
          <Expandable title="properties">
            <ResponseField name="key" type="string">
              Specifies the name (key) of an environment variable to set in the container environment for the SageMaker Code Editor app image configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value" type="string">
              Specifies the value portion of a key-value pair environment variable that is injected into the SageMaker Code Editor app's container when it launches, paired with the corresponding Key in the same ContainerEnvironmentVariables entry. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="jupyter_lab_app_image_config" type="object">
  The configuration for the kernels in a SageMaker image running as a JupyterLab app. Optional.
  <Expandable title="properties">
    <ResponseField name="container_config" type="object">
      The container configuration for a SageMaker image. Optional.
      <Expandable title="properties">
        <ResponseField name="container_arguments" type="list(string)">
          A list of arguments to apply to the container. Optional.
        </ResponseField>
        <ResponseField name="container_entrypoint" type="list(string)">
          The custom entry point to use on container. Optional.
        </ResponseField>
        <ResponseField name="container_environment_variables" type="list(object)">
          A list of variables to apply to the custom container. Optional.
          <Expandable title="properties">
            <ResponseField name="key" type="string">
              The name of an environment variable to set in the container for the JupyterLab app image, as part of the SageMaker AppImageConfig. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value" type="string">
              The value of the environment variable that is set in the container when running a JupyterLab app from this SageMaker image configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kernel_gateway_image_config" type="object">
  The configuration for the file system and kernels in a SageMaker image running as a KernelGateway app. Optional.
  <Expandable title="properties">
    <ResponseField name="file_system_config" type="object">
      The Amazon Elastic File System (EFS) storage configuration for a SageMaker image. Optional.
      <Expandable title="properties">
        <ResponseField name="default_gid" type="number">
          The default POSIX group ID (GID). If not specified, defaults to 100. Optional.
        </ResponseField>
        <ResponseField name="default_uid" type="number">
          The default POSIX user ID (UID). If not specified, defaults to 1000. Optional.
        </ResponseField>
        <ResponseField name="mount_path" type="string">
          The path within the image to mount the user's EFS home directory. The directory should be empty. If not specified, defaults to /home/sagemaker-user. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="kernel_specs" type="list(object)" required>
      The specification of the Jupyter kernels in the image. Required.
      <Expandable title="properties">
        <ResponseField name="display_name" type="string">
          The display name of the kernel as shown in the Jupyter UI for the kernel gateway app. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of the kernel (for example, `python3`) that the SageMaker KernelGateway app uses to launch the kernel specification. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to apply to the AppImageConfig. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag attached to the SageMaker AppImageConfig resource, allowing you to assign custom metadata for identification and organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_sage_maker_model_explainability_job_definition` defines a real, scheduled job that computes real feature-attribution explanations for an `aws_sage_maker_endpoint`'s live predictions, the configuration an `aws_sage_maker_monitoring_schedule` runs to track how a model's own reasoning shifts over time.

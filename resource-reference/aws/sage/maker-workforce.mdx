`aws_sage_maker_workforce` creates a real pool of human labelers or reviewers, private (an organization's own workers), vendor-managed, or Amazon Mechanical Turk, that one or more `aws_sage_maker_workteam`s are drawn from for SageMaker Ground Truth labeling or human-review workflows.

## Input properties

<ResponseField name="cognito_config" type="object">
  The configuration of an Amazon Cognito workforce. A single Cognito workforce is created using and corresponds to a single Amazon Cognito user pool. Optional.
  <Expandable title="properties">
    <ResponseField name="client_id" type="string" required>
      The client ID for your Amazon Cognito user pool. Required.
    </ResponseField>
    <ResponseField name="user_pool" type="string" required>
      The ID for your Amazon Cognito user pool. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ip_address_type" type="string">
  The IP address type for the workforce. IPv4 only or dualstack (IPv4 and IPv6). Optional.
</ResponseField>

<ResponseField name="oidc_config" type="object">
  The configuration of an OIDC Identity Provider (IdP) private workforce. Optional.
  <Expandable title="properties">
    <ResponseField name="authentication_request_extra_params" type="any">
      A string to string map of identifiers specific to the custom identity provider (IdP) being used. Optional.
    </ResponseField>
    <ResponseField name="authorization_endpoint" type="string" required>
      The OIDC IdP authorization endpoint used to configure your private workforce. Required.
    </ResponseField>
    <ResponseField name="client_id" type="string" required>
      The OIDC IdP client ID used to configure your private workforce. Required.
    </ResponseField>
    <ResponseField name="client_secret" type="string">
      The OIDC IdP client secret used to configure your private workforce. Optional.
    </ResponseField>
    <ResponseField name="issuer" type="string" required>
      The OIDC IdP issuer used to configure your private workforce. Required.
    </ResponseField>
    <ResponseField name="jwks_uri" type="string" required>
      The OIDC IdP JSON Web Key Set (Jwks) URI used to configure your private workforce. Required.
    </ResponseField>
    <ResponseField name="logout_endpoint" type="string" required>
      The OIDC IdP logout endpoint used to configure your private workforce. Required.
    </ResponseField>
    <ResponseField name="scope" type="string">
      An array of string identifiers used to refer to the specific pieces of user data or claims that the client application wants to access. Optional.
    </ResponseField>
    <ResponseField name="token_endpoint" type="string" required>
      The OIDC IdP token endpoint used to configure your private workforce. Required.
    </ResponseField>
    <ResponseField name="user_info_endpoint" type="string" required>
      The OIDC IdP user info endpoint used to configure your private workforce. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="source_ip_config" type="object">
  A list of IP address ranges used to access your training data. Optional.
  <Expandable title="properties">
    <ResponseField name="cidrs" type="list(string)" required>
      A list of one to ten Classless Inter-Domain Routing (CIDR) values. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag attached to the SageMaker workforce, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Defines a value for a tag attached to the SageMaker Workforce resource, allowing you to categorize and manage the workforce with custom metadata for cost tracking, access control, and operational governance. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="workforce_name" type="string" required>
  The name of the private workforce. Required.
</ResponseField>

<ResponseField name="workforce_vpc_config" type="object">
  The VPC configuration for the workforce. Optional.
  <Expandable title="properties">
    <ResponseField name="security_group_ids" type="list(string)">
      The VPC security group IDs. Optional.
    </ResponseField>
    <ResponseField name="subnets" type="list(string)">
      The VPC subnets. Optional.
    </ResponseField>
    <ResponseField name="vpc_id" type="string">
      The ID of the VPC. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

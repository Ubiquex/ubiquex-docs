`aws_sage_maker_project` creates a real SageMaker Projects MLOps template instance, provisioning a pre-built CI/CD pipeline, repositories, and permissions for a standardized model-build-and-deploy workflow rather than assembling that tooling by hand.

## Example

    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="project_description" type="string">
  The description of the project. Optional.
</ResponseField>

<ResponseField name="project_name" type="string" required>
  The name of the project. Required.
</ResponseField>

<ResponseField name="service_catalog_provisioned_product_details" type="object">
  Provisioned ServiceCatalog Details Optional.
  <Expandable title="properties">
    <ResponseField name="provisioned_product_id" type="string">
      The identifier of the provisioning artifact (also known as a version). Optional.
    </ResponseField>
    <ResponseField name="provisioned_product_status_message" type="string">
      Provisioned Product Status Message Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_catalog_provisioning_details" type="object">
  Input ServiceCatalog Provisioning Details Optional.
  <Expandable title="properties">
    <ResponseField name="path_id" type="string">
      The path identifier of the product. Optional.
    </ResponseField>
    <ResponseField name="product_id" type="string" required>
      Service Catalog product identifier. Required.
    </ResponseField>
    <ResponseField name="provisioning_artifact_id" type="string">
      The identifier of the provisioning artifact (also known as a version). Optional.
    </ResponseField>
    <ResponseField name="provisioning_parameters" type="list(object)">
      Parameters specified by the administrator that are required for provisioning the product. Optional.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key that identifies a specific provisioning parameter passed to the Service Catalog product when SageMaker provisions the project. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The value for a Service Catalog provisioning parameter key, which SageMaker passes to the provisioned product to configure the project resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag associated with the SageMaker project, used to assign metadata such as cost center or environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_provider_details" type="list(object)">
  An array of template providers associated with the project. Optional.
  <Expandable title="properties">
    <ResponseField name="cfn_template_provider_detail" type="object">
      Specifies the CloudFormation template provider details for the SageMaker project, including the template location and configuration used to provision the project. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="parameters" type="list(object)">
          Specifies key-value pairs of provisioning parameters that are passed to the AWS Service Catalog product used to create the SageMaker project, controlling the configuration of the project's resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="key" type="string">
              The name of a parameter passed to the CloudFormation template used by the SageMaker project's template provider. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value" type="string">
              Provides the value for a CloudFormation template parameter that the SageMaker project passes to the referenced CloudFormation template for provisioning. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="role_arn" type="string">
          The IAM role ARN that SageMaker assumes to create and manage the CloudFormation stack resources for this project. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="template_name" type="string">
          The name of the CloudFormation template used by SageMaker to provision and create the project. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="template_url" type="string">
          The S3 URL of the AWS CloudFormation template that defines the resources to provision for the SageMaker project. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

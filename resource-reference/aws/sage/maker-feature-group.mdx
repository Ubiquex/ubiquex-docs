`aws_sage_maker_feature_group` creates a real, versioned collection of features in the SageMaker Feature Store, storing curated ML input data so it can be reused consistently across both training and real-time inference rather than being recomputed each time.

## Example

<ResponseField name="event_time_feature_name" type="string" required>

<ResponseField name="feature_definitions" type="list(object)" required>

    <ResponseField name="feature_type" type="string">

          The name of the AWS Glue Catalog (commonly 'aws') that contains the database and table used by the feature group's offline store for managing its data catalog entries. Required. **(AI-inferred)**

        <ResponseField name="database" type="string" required>
          The name of the AWS Glue database in which the SageMaker Feature Group's offline store data catalog table is registered. Required. **(AI-inferred)**

        <ResponseField name="table_name" type="string" required>

      </Expandable>

    <ResponseField name="s3_storage_config" type="object" required>

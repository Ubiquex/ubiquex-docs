`aws_sage_maker_human_task_ui` defines a real, reusable worker task template, its HTML layout, that an `aws_sage_maker_workteam`'s human reviewers see when completing a labeling or review task in a SageMaker Ground Truth or human-review workflow.

## Input properties

<ResponseField name="human_task_ui_name" type="string" required>
  The name of the human task user interface. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs that contain metadata to help you categorize and organize a human review workflow user interface. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined tag key that helps identify, organize, and manage costs for this SageMaker human task UI resource, with the value paired in the same tag list entry. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS SageMaker HumanTaskUi resource, used for metadata and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ui_template" type="object">
  The Liquid template for the worker user interface. Optional.
  <Expandable title="properties">
    <ResponseField name="content" type="string" required>
      The content of the Liquid template for the worker user interface. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

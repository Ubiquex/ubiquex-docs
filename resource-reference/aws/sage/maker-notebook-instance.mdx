`aws_sage_maker_notebook_instance` creates a real, standalone managed Jupyter notebook instance, SageMaker's original notebook environment predating SageMaker Studio, optionally cloning an `aws_sage_maker_code_repository` on startup.

## Input properties

<ResponseField name="accelerator_types" type="list(string)">
  Specifies the Elastic Inference accelerator type(s) to attach to the SageMaker notebook instance for accelerating inference workloads. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="additional_code_repositories" type="list(string)">
  Specifies a list of Git repository URLs or names that are cloned into the notebook instance's default SageMaker repository, allowing additional code repositories to be available in the instance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_code_repository" type="string">
  Specifies the default Git repository (as a URL or CodeCommit reference) that SageMaker automatically clones into the notebook instance at creation, making its contents available in the instance and connecting it as the default code repository for the notebook's Git integration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="direct_internet_access" type="string">
  Determines whether the notebook instance has direct access to the internet, accepting 'Enabled' or 'Disabled', where 'Disabled' restricts the instance to resources within its VPC. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_metadata_service_configuration" type="object">
  Configures the instance metadata service (IMDS) on the SageMaker notebook instance, including the minimum IMDS version (such as 1 or 2) that the instance must support. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="minimum_instance_metadata_service_version" type="string" required>
      Specifies the minimum version of the AWS instance metadata service (IMDS) that the SageMaker notebook instance must support (e.g., '1' or '2'), which forces the instance to use that protocol version or higher for metadata requests. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  The ML compute instance type (e.g., ml.t2.medium, ml.m5.xlarge) used for the SageMaker notebook instance. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The ID of an AWS KMS key used by SageMaker to encrypt the data on the notebook instance's attached EBS storage volume. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="lifecycle_config_name" type="string">
  The name of a SageMaker notebook instance lifecycle configuration, which defines shell scripts that run during instance startup and shutdown. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="notebook_instance_name" type="string">
  Specifies a custom name for the SageMaker notebook instance; if omitted, AWS CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="platform_identifier" type="string">
  Specifies the operating system platform for the SageMaker notebook instance, with allowed values 'Linux' (default) and 'Windows'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The IAM role ARN that SageMaker assumes to access AWS services and resources on behalf of the notebook instance. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="root_access" type="string">
  Specifies whether root access is enabled or disabled for the SageMaker notebook instance, with valid values 'Enabled' or 'Disabled'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  Specifies the VPC security group IDs to associate with the SageMaker notebook instance for network access control. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_id" type="string">
  Specifies the ID of the subnet in a customer VPC where the SageMaker notebook instance is launched, enabling network isolation within a chosen subnet. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to associate with the SageMaker notebook instance for organizing and identifying the resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag applied to the SageMaker notebook instance, used to identify and organize the resource for management and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key attached to the SageMaker notebook instance, used to organize, track, and manage AWS resources for billing, access control, and operational purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="volume_size_in_gb" type="number">
  The size in gigabytes of the EBS ML storage volume attached to the SageMaker notebook instance, which can be set between 5 and 16384 GB and determines the available storage for data and code. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the SageMaker notebook instance, which is the same as its name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

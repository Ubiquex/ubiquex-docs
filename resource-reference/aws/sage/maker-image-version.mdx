`aws_sage_maker_image_version` publishes a real, immutable version of an `aws_sage_maker_image`'s underlying container, letting an `aws_sage_maker_app_image_config` or Studio domain pin to a specific, unchanging build.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	sage "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sage"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own maker image version"})

    			BaseImage:   "example",
    			ImageName:   "example-image-name",
    			Alias:       "example",
    			Aliases:     []string{"example"},
    			Horovod:     true,
    			JobType:     "example",
    			Mlframework: "example",
    			Processor:   "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="alias" type="string">
  The alias of the image version. Optional.
</ResponseField>

<ResponseField name="aliases" type="list(string)">
  List of aliases for the image version. Optional.
</ResponseField>

<ResponseField name="base_image" type="string" required>
  The registry path of the container image on which this image version is based. Required.
</ResponseField>

<ResponseField name="horovod" type="bool">
  Indicates Horovod compatibility. Optional.
</ResponseField>

<ResponseField name="image_name" type="string" required>
  The name of the image this version belongs to. Required.
</ResponseField>

<ResponseField name="job_type" type="string">
  Indicates SageMaker job type compatibility. Optional.
</ResponseField>

<ResponseField name="mlframework" type="string">
  The machine learning framework vended in the image version. Optional.
</ResponseField>

<ResponseField name="processor" type="string">
  Indicates CPU or GPU compatibility. Optional.
</ResponseField>

<ResponseField name="programming_lang" type="string">
  The supported programming language and its version. Optional.
</ResponseField>

<ResponseField name="release_notes" type="string">
  The maintainer description of the image version. Optional.
</ResponseField>

<ResponseField name="vendor_guidance" type="string">
  The availability of the image version specified by the maintainer. Optional.
</ResponseField>

## Output properties

<ResponseField name="container_image" type="string">
  The registry path of the container image that contains this image version. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="image_arn" type="string">
  The Amazon Resource Name (ARN) of the parent image. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="image_version_arn" type="string">
  The Amazon Resource Name (ARN) of the image version. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version" type="number">
  The version number of the image version. Computed by AWS after `ship`.
</ResponseField>

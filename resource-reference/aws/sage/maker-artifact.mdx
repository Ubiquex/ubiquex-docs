`aws_sage_maker_artifact` records a real dataset, model, or other tracked entity in SageMaker's ML Lineage Tracking graph, so it can be connected to the `aws_sage_maker_action`s that consumed or produced it.

## Example

    	ubx.Main(ubx.Stack("payments", func() {

    			MetadataProperties: map[string]any{"commit_id": "example"},
    			Properties:         "example",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="artifact_name" type="string">
  The name of the artifact. Must be unique to your account in an AWS Region. Optional.
</ResponseField>

<ResponseField name="artifact_type" type="string" required>
  The artifact type. Required.
</ResponseField>

<ResponseField name="metadata_properties" type="object">
  The metadata properties (such as commit ID, repository, generated by, and project ID) that are associated with the SageMaker artifact. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="commit_id" type="string">
      The commit ID. Optional.
    </ResponseField>
    <ResponseField name="generated_by" type="string">
      The entity this entity was generated by. Optional.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The project ID. Optional.
    </ResponseField>
    <ResponseField name="repository" type="string">
      The repository. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="properties" type="any">
  A list of properties to add to the artifact. Optional.
</ResponseField>

<ResponseField name="source" type="object" required>
  Specifies the origin of the artifact, including the source type (e.g., S3 or ARN) and a source ID that uniquely identifies the artifact's location. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="source_types" type="list(object)">
      A list of source types. Optional.
      <Expandable title="properties">

        </ResponseField>
        <ResponseField name="value" type="string">
          The value for a source type entry (such as an MD5 hash, S3 URI, or custom string) that identifies the origin of the SageMaker artifact. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="source_uri" type="string" required>
      The URI of the source. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to apply to the artifact. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key for a tag attached to the SageMaker artifact, used for metadata and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the SageMaker artifact, used to organize and identify the artifact within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**

  </Expandable>
</ResponseField>

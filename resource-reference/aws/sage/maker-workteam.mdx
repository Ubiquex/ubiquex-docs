`aws_sage_maker_workteam` creates a real, named subset of an `aws_sage_maker_workforce` assigned to specific labeling or human-review jobs, using an `aws_sage_maker_human_task_ui` template to present tasks to its members.

## Input properties

<ResponseField name="description" type="string">
  A description of the SageMaker work team that provides details about the team's purpose or composition. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="member_definitions" type="list(object)">
  Defines the list of workers for the SageMaker work team, where each member definition specifies either an Amazon Cognito user pool or an OIDC identity provider to grant worker access. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cognito_member_definition" type="object">
      Configures the Amazon Cognito user group that is granted access to this work team by specifying the cognito user pool, client app, and user group for the member definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="cognito_client_id" type="string">
          The client ID of the Amazon Cognito app client used to authenticate members of the SageMaker workteam. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="cognito_user_group" type="string">
          Specifies the Cognito user group that is allowed to access this SageMaker work team. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="cognito_user_pool" type="string">
          The ID of the Amazon Cognito user pool that contains the work team members. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="oidc_member_definition" type="object">
      Specifies the OIDC identity provider (IdP) ID and a list of group names that define membership in the SageMaker work team. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="oidc_groups" type="list(string)">
          Specifies the list of OIDC group names that define the members of the workteam for this OIDC member definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="notification_configuration" type="object">
  Specifies the SNS topic ARN (via its `NotificationTopicArn`) that SageMaker uses to send notifications about workteam-related events, such as labeling job updates. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="notification_topic_arn" type="string" required>
      The ARN of the Amazon SNS topic that SageMaker sends workteam lifecycle notifications to, such as when the workteam is created or updated. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies one or more tags (key-value pairs) to assign to the SageMaker Workteam resource, enabling cost allocation and management of the workforce. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key assigned to the SageMaker workteam, used for resource categorization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a user-defined tag applied to the SageMaker workteam, used for metadata such as cost allocation or environment identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="workforce_name" type="string">
  The name of the SageMaker workforce that this workteam is associated with, determining the pool of workers available to the workteam. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="workteam_name" type="string">
  The name of the SageMaker work team, which must be unique within your AWS account and region; if not provided, AWS CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

</ResponseField>

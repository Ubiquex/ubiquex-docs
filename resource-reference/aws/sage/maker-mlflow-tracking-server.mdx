`aws_sage_maker_mlflow_tracking_server` creates a real, fully managed MLflow tracking server, backed by an S3 artifact store, for logging and comparing experiment runs using the open-source MLflow API rather than SageMaker's own native `aws_sage_maker_experiment` tracking.

## Input properties

<ResponseField name="artifact_store_uri" type="string" required>
  The Amazon S3 URI for MLFlow Tracking Server artifacts. Required.
</ResponseField>

<ResponseField name="automatic_model_registration" type="bool">
  A flag to enable Automatic SageMaker Model Registration. Optional.
</ResponseField>

<ResponseField name="mlflow_version" type="string">
  The MLFlow Version used on the MLFlow Tracking Server. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) of an IAM role that enables Amazon SageMaker to perform tasks on behalf of the customer. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key part of a key-value tag attached to the SageMaker MLflow Tracking Server, used to identify and organize the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The arbitrary value for a tag attached to the SageMaker MLflow Tracking Server. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tracking_server_name" type="string" required>
  The name of the MLFlow Tracking Server. Required.
</ResponseField>

<ResponseField name="tracking_server_size" type="string">
  The size of the MLFlow Tracking Server. Optional.
</ResponseField>

<ResponseField name="weekly_maintenance_window_start" type="string">
  The start of the time window for maintenance of the MLFlow Tracking Server in UTC time. Optional.
</ResponseField>

## Output properties

<ResponseField name="tracking_server_arn" type="string">
  The Amazon Resource Name (ARN) of the MLFlow Tracking Server. Computed by AWS after `ship`.
</ResponseField>

`aws_sage_maker_experiment_trial_component` associates a real `aws_sage_maker_trial_component` with an `aws_sage_maker_experiment`, the resource that actually links an individual tracked run into its parent experiment's grouping.

## Input properties

<ResponseField name="display_name" type="string">
  The human-readable display name of the trial component, which can differ from the automatically generated name and is used for identification in the SageMaker console and API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="end_time" type="string">
  The end time of the trial component, specified as an ISO 8601 date-time string (e.g., 2020-06-03T13:45:30Z). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="metadata_properties" type="object">
  Specifies metadata properties for the trial component, such as a Git commit ID, repository, and project identifier. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="commit_id" type="string">
      Specifies the commit ID of the source code repository associated with the trial component, for tracking lineage and reproducibility. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="generated_by" type="string">
      Identifies the entity (such as a training job or pipeline execution) that generated this trial component, typically specified as its Amazon Resource Name (ARN) for provenance tracking. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The unique identifier of the SageMaker project associated with this trial component, used for tracking the component within a project's lineage. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="repository" type="string">
      Specifies the repository URI or URL where the source code for the trial component is stored, as part of the metadata properties. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="start_time" type="string">
  Specifies the starting time of the SageMaker trial component, typically in ISO 8601 format (e.g., 2023-01-01T00:00:00Z), used to record when the component's execution began. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="object">
  Defines the current status of the SageMaker trial component, including a primary status (e.g., InProgress, Completed, Failed) and an optional human-readable message with additional details. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="message" type="string">
      The message field within the trial component's status object, providing human-readable details such as error descriptions or informational notes about the current state of the SageMaker trial component. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="primary_status" type="string">
      The current lifecycle status of the trial component, such as InProgress, Completed, Failed, Stopping, or Stopped, as tracked by SageMaker. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Associates a list of tag objects (each with Key and Value) with the SageMaker trial component for cost allocation, access control, and resource organization. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a user-defined tag attached to the SageMaker Experiment Trial Component, used to categorize or identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the SageMaker experiment trial component, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="trial_component_name" type="string" required>
  The name of the trial component, a user-defined identifier that must be unique within the AWS account and Region. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this SageMaker experiment trial component within AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="creation_time" type="string">
  The ISO 8601 timestamp indicating when the SageMaker trial component was created, returned as a read-only string. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique resource identifier for this SageMaker experiment trial component, which is its name as used in the SageMaker API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="last_modified_time" type="string">
  The timestamp, formatted as a string, indicating when the SageMaker trial component was last modified. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="lineage_group_arn" type="string">

</ResponseField>

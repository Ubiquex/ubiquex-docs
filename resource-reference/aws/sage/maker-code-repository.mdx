`aws_sage_maker_code_repository` registers a real Git repository, hosted in AWS CodeCommit or a self-hosted Git server, that can be associated with an `aws_sage_maker_notebook_instance` so it's automatically cloned and available when the notebook starts.

## Input properties

<ResponseField name="code_repository_name" type="string">
  Specifies the name of the SageMaker code repository, which uniquely identifies the repository within an AWS account and Region and is used to reference it in SageMaker operations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="git_config" type="object" required>
  The Git configuration for the SageMaker code repository, which specifies the repository URL and optionally the ARN of an AWS Secrets Manager secret containing Git credentials. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="branch" type="string">
      The branch of the Git repository that SageMaker uses for this code repository. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="repository_url" type="string" required>
      The URL where the Git repository is located; SageMaker clones this repository for the code repository. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      The ARN of an AWS Secrets Manager secret that stores the credentials, such as a username and password, for accessing the private Git repository specified in the Git configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the list of tags (key-value pairs) to attach to the SageMaker Code Repository, enabling you to categorize and manage this repository resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag that is applied to the AWS SageMaker Code Repository, allowing you to associate metadata for resource organization and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique name of the SageMaker code repository, which serves as the resource's identifier in AWS and Terraform state. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

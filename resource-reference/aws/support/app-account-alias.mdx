`aws_support_app_account_alias` sets a real, friendly alias for an account, shown in AWS Support App notifications so a Slack or Chime channel receiving alerts from many accounts can tell them apart by name instead of account ID.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	supportapp "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/supportapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app account alias"})

    		ubx.Resource(supportapp.AccountAlias, "example", supportapp.AccountAliasConfig{
    			AccountAlias: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { AccountAlias } from "@ubx/sdk-aws/aws/supportapp/account_alias";

    export default stack("example", () => {
      intent({ summary: "example own app account alias" });

      resource(AccountAlias, "example", {
        accountAlias: "example",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.supportapp.account_alias import AccountAlias, AccountAliasConfig

    def describe():
        ubx.intent("example own app account alias")

        ubx.resource(AccountAlias, "example", AccountAliasConfig(
            account_alias="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="account_alias" type="string" required>
  An account alias associated with a customer's account. Required.
</ResponseField>

## Output properties

<ResponseField name="account_alias_resource_id" type="string">
  Unique identifier representing an alias tied to an account Computed by AWS after `ship`.
</ResponseField>

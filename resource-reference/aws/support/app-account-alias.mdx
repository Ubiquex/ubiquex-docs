`aws_support_app_account_alias` sets a real, friendly alias for an account, shown in AWS Support App notifications so a Slack or Chime channel receiving alerts from many accounts can tell them apart by name instead of account ID.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	support "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/support"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app account alias"})

    		ubx.Resource(support.AppAccountAlias, "example", support.AppAccountAliasConfig{
    			AccountAlias: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only aws --lang ts --out ./local-sdk
    ```

    ```python
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="account_alias" type="string" required>
  An account alias associated with a customer's account. Required.
</ResponseField>

## Output properties

<ResponseField name="account_alias_resource_id" type="string">
  Unique identifier representing an alias tied to an account Computed by AWS after `ship`.
</ResponseField>

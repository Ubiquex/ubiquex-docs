`aws_support_app_slack_workspace_configuration` authorizes a real Slack workspace for the AWS Support App, the prerequisite step before any `aws_support_app_slack_channel_configuration` within that workspace can be created.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	support "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/support"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own app slack workspace configuration"})

    		ubx.Resource(support.AppSlackWorkspaceConfiguration, "ci-runner", support.AppSlackWorkspaceConfigurationConfig{
    			TeamId:    "example",
    			VersionId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="team_id" type="string" required>
  The team ID in Slack, which uniquely identifies a workspace. Required.
</ResponseField>

<ResponseField name="version_id" type="string">
  An identifier used to update an existing Slack workspace configuration in AWS CloudFormation. Optional.
</ResponseField>

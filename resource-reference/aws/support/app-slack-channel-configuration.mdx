`aws_support_app_slack_channel_configuration` connects a real Slack channel to the AWS Support App, the resource that actually determines which channel receives new support case notifications and lets users create and manage cases from Slack.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	support "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/support"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own app slack channel configuration"})

    		ubx.Resource(support.AppSlackChannelConfiguration, "ci-runner", support.AppSlackChannelConfigurationConfig{
    			ChannelId:                       "example",
    			ChannelRoleArn:                  "arn:aws:iam::123456789012:policy/ci",
    			NotifyOnCaseSeverity:            "example",
    			TeamId:                          "example",
    			ChannelName:                     "example-channel-name",
    			NotifyOnAddCorrespondenceToCase: true,
    			NotifyOnCreateOrReopenCase:      true,
    			NotifyOnResolveCase:             true,
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="channel_id" type="string" required>
  The channel ID in Slack, which identifies a channel within a workspace. Required.
</ResponseField>

<ResponseField name="channel_name" type="string">
  The channel name in Slack. Optional.
</ResponseField>

<ResponseField name="channel_role_arn" type="string" required>
  The Amazon Resource Name (ARN) of an IAM role that grants the AWS Support App access to perform operations for AWS services. Required.
</ResponseField>

<ResponseField name="notify_on_add_correspondence_to_case" type="bool">
  Whether to notify when a correspondence is added to a case. Optional.
</ResponseField>

<ResponseField name="notify_on_case_severity" type="string" required>
  The severity level of a support case that a customer wants to get notified for. Required.
</ResponseField>

<ResponseField name="notify_on_create_or_reopen_case" type="bool">
  Whether to notify when a case is created or reopened. Optional.
</ResponseField>

<ResponseField name="notify_on_resolve_case" type="bool">
  Whether to notify when a case is resolved. Optional.
</ResponseField>

<ResponseField name="team_id" type="string" required>
  The team ID in Slack, which uniquely identifies a workspace. Required.
</ResponseField>

`aws_dax_parameter_group` sets real, engine-level configuration, TTL and record count limits among them, for an `aws_dax_cluster`, kept as its own resource so the same parameter set can be applied consistently across multiple clusters.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	dax "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/dax"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own parameter group"})

    		ubx.Resource(dax.ParameterGroup, "ci-runner", dax.ParameterGroupConfig{
    			Description:         "Managed by ubx.",
    			ParameterGroupName:  "example-parameter-group-name",
    			ParameterNameValues: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="description" type="string">
  A description of the parameter group. Optional.
</ResponseField>

<ResponseField name="parameter_group_name" type="string">
  The name of the parameter group. Optional.
</ResponseField>

<ResponseField name="parameter_name_values" type="any">
  An array of name-value pairs for the parameters in the group. Each element in the array represents a single parameter. Optional.
</ResponseField>

`aws_dax_subnet_group` defines the real VPC subnets an `aws_dax_cluster`'s nodes are actually placed into, the network-placement configuration a cluster requires before it can be created.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dax "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/dax"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own subnet group"})

    		ubx.Resource(dax.SubnetGroup, "example", dax.SubnetGroupConfig{
    			SubnetIds:       []string{"example"},
    			Description:     "Managed by ubx.",
    			SubnetGroupName: "example-subnet-group-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  An optional user-provided description that identifies the purpose or context of this DAX subnet group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_group_name" type="string">
  The name of this DAX subnet group; if omitted, CloudFormation generates a unique name based on the logical resource ID. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The list of subnet IDs in the VPC where the DAX cluster will be deployed, defining the network locations for the cluster's nodes. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The name of the DAX subnet group, which uniquely identifies the resource within AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

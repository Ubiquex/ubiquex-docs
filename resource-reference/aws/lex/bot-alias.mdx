`aws_lex_bot_alias` creates a real named pointer to a specific `aws_lex_bot_version`, letting a calling application be redirected to a new bot version, for example promoting a tested version to a `PROD` alias, without changing the identifier the application calls.

## Example

<ResponseField name="bot_alias_locale_settings" type="list(object)">

        <ResponseField name="code_hook_specification" type="object">
          Defines the Lambda code hook specification for a particular locale in the bot alias, including the Lambda ARN and code hook interface version that Lex invokes during conversation. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="lambda_code_hook" type="object">
              The `lambda_code_hook` object specifies the Amazon Lex Lambda function and its version that is invoked as the code hook for the bot alias locale, enabling custom logic in the conversation flow. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="code_hook_interface_version" type="string">
                  Specifies the version of the code hook interface that the Lambda function uses, with '1.0' being the supported value for Lex V2 bots. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="lambda_arn" type="string">

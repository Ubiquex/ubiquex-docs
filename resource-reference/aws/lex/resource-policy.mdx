`aws_lex_resource_policy` attaches a real resource-based access policy to an `aws_lex_bot` or its alias, controlling which principals, including from other accounts, can use it in a conversation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lex "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/lex"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own resource policy"})

    		ubx.Resource(lex.ResourcePolicy, "ci-runner", lex.ResourcePolicyConfig{
    			Policy:      "example",
    			ResourceArn: "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="policy" type="any" required>
  A resource policy to add to the resource. The policy is a JSON structure following the IAM syntax that contains one or more statements that define the policy. Required.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The Amazon Resource Name (ARN) of the bot or bot alias that the resource policy is attached to. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The Physical ID of the resource policy. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="revision_id" type="string">
  The current revision of the resource policy. Use the revision ID to make sure that you are updating the most current version of a resource policy when you add a policy statement to a resource, delete a resource, or update a resource. Computed by AWS after `ship`.
</ResponseField>

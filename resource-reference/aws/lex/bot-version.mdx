---
title: "aws_lex_bot_version"
description: "`aws_lex_bot_version` publishes a real, immutable numbered snapshot of an `aws_lex_bot`'s current DRAFT configuration."
---

If the DRAFT is unchanged since the last version was created, Amazon Lex returns that existing version rather than creating a duplicate.

## Input properties

<ResponseField name="bot_id" type="string" required>
  Unique ID of resource Required.
</ResponseField>

<ResponseField name="bot_version_locale_specification" type="list(object)" required>
  Specifies the locales that Amazon Lex adds to this version. You can choose the Draft version or any other previously published version for each locale. Required.
  <Expandable title="properties">
    <ResponseField name="bot_version_locale_details" type="object">
      Specifies the details of a locale in the bot version, including the source bot version from which the locale's version is derived. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="source_bot_version" type="string">
          The version number of the source bot to use as the basis for the locale version in this bot version. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="locale_id" type="string">
      Identifies the locale (such as 'en_US' or 'en_GB') that this bot version locale specification entry applies to, and must match a locale configured on the bot. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A description of the version. Use the description to help identify the version in lists. Optional.
</ResponseField>

## Output properties

<ResponseField name="bot_version" type="string">
  The version of a bot. Computed by AWS after `ship`.
</ResponseField>

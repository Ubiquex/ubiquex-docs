`aws_identity_store_group` creates a real group in the Identity Store, the built-in directory behind IAM Identity Center, that `aws_sso_permission_set` assignments and application access can be granted to collectively rather than user by user.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	identity "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/identity"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own store group"})

    		ubx.Resource(identity.StoreGroup, "example", identity.StoreGroupConfig{
    			DisplayName:     "example-display-name",
    			IdentityStoreId: "example",
    			Description:     "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A string containing the description of the group. Optional.
</ResponseField>

<ResponseField name="display_name" type="string" required>
  A string containing the name of the group. This value is commonly displayed when the group is referenced. Required.
</ResponseField>

<ResponseField name="identity_store_id" type="string" required>
  The globally unique identifier for the identity store. Required.
</ResponseField>

## Output properties

<ResponseField name="group_id" type="string">
  The unique identifier for a group in the identity store. Computed by AWS after `ship`.
</ResponseField>

`aws_identity_store_group_membership` adds a real user as a member of an `aws_identity_store_group`, the resource that actually grants that user whatever access has been assigned to the group.

## Example

<Tabs>

    ```go
    package main

    import (
    	identity "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/identity"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own store group membership"})

    		ubx.Resource(identity.StoreGroupMembership, "example", identity.StoreGroupMembershipConfig{
    			GroupId:         "example",
    			IdentityStoreId: "example",
    			MemberId:        map[string]any{"user_id": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="group_id" type="string" required>
  The unique identifier for a group in the identity store. Required.
</ResponseField>

<ResponseField name="identity_store_id" type="string" required>
  The globally unique identifier for the identity store. Required.
</ResponseField>

<ResponseField name="member_id" type="object" required>
  An object containing the identifier of a group member. Required.
  <Expandable title="properties">
    <ResponseField name="user_id" type="string" required>
      The identifier for a user in the identity store. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="membership_id" type="string">
  The identifier for a GroupMembership in the identity store. Computed by AWS after `ship`.
</ResponseField>

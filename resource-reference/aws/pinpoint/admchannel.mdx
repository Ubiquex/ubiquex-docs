`aws_pinpoint_admchannel` enables a real push-notification channel on an `aws_pinpoint_app` for devices reachable through Amazon Device Messaging (Amazon's own Fire OS push service). Amazon Pinpoint's engagement surface, including its channel resources, is being retired: AWS closed Pinpoint to new customers on May 20, 2025, and the Pinpoint console and its resources become inaccessible after October 30, 2026, a date roughly two months from now. The underlying push-delivery capability itself continues under AWS End User Messaging.

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier of the Amazon Pinpoint application to which the ADM channel is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_id" type="string" required>
  The client ID obtained from your Amazon Device Messaging (ADM) project, required to authorize Pinpoint to send push notifications to Android apps. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_secret" type="string" required>
  The client secret from the Amazon Device Messaging (ADM) service that Amazon Pinpoint uses to authorize and send push notifications through the ADM channel. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Indicates whether the ADM channel is enabled for sending push notifications through Amazon Pinpoint. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Computed by AWS after `ship`.

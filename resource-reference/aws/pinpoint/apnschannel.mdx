---
title: "aws_pinpoint_apnschannel"
description: "`aws_pinpoint_apnschannel` enables a real push-notification channel on an `aws_pinpoint_app` for iOS devices through Apple Push Notification service."
---

Like the rest of Pinpoint's engagement surface, this becomes inaccessible after October 30, 2026 (upcoming, roughly two months out), though APNs push delivery itself continues under AWS End User Messaging.

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier for the Amazon Pinpoint application that the APNS channel is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="bundle_id" type="string">
  The bundle ID that uniquely identifies the app to Apple's Push Notification service (APNs), used as part of the APNs channel configuration in Amazon Pinpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate" type="string">
  The PEM-encoded Apple Push Notification service (APNs) SSL certificate, which is required when authenticating with a certificate instead of a token for sending push notifications through Amazon Pinpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_authentication_method" type="string">
  Specifies the default authentication method for APNs, which must be either 'CERTIFICATE' or 'TOKEN', used to authenticate with Apple Push Notification service for sending push notifications through Amazon Pinpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Specifies whether to enable the APNs (Apple Push Notification service) channel for the associated Amazon Pinpoint application, allowing it to send push notifications to iOS devices. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_key" type="string">
  The PEM-encoded .p8 private key file issued by Apple that Pinpoint uses for token-based authentication with the Apple Push Notification service (APNs). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="team_id" type="string">
  The Apple Team ID used to authenticate with Apple Push Notification Service when the APNs channel uses token-based authentication. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key" type="string">
  The private key (in .p8 format) used to authenticate with Apple Push Notification service, corresponding to the token key ID and team ID. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key_id" type="string">
  The Apple Push Notification service key identifier (kid) from the .p8 private key used to authenticate with APNs via token-based credentials, required when using token authentication. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned to the APNs channel within the Amazon Pinpoint application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

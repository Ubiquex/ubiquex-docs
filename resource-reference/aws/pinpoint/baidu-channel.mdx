`aws_pinpoint_baidu_channel` enables a real push-notification channel on an `aws_pinpoint_app` for Android devices in China reachable through Baidu Cloud Push, subject to the same October 30, 2026 Pinpoint retirement as Pinpoint's other channel resources.

## Input properties

<ResponseField name="api_key" type="string" required>
  The API key from Baidu Cloud Push used to authenticate the Baidu channel with the Baidu Push service. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="application_id" type="string" required>
  The unique ID of the Amazon Pinpoint application to which this Baidu channel belongs and is configured for sending push notifications. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Indicates whether the Baidu channel is enabled for delivering push notifications to the app. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="secret_key" type="string" required>
  The Baidu Cloud Push API secret key, used together with the API key to authenticate Amazon Pinpoint with Baidu's push notification service for this channel. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of the AWS Pinpoint application this Baidu channel is associated with (the ApplicationId returned by Ref). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

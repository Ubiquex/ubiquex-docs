---
title: "aws_pinpoint_voice_channel"
description: "`aws_pinpoint_voice_channel` enables a real voice-messaging channel on an `aws_pinpoint_app`, delivering automated voice calls."
---

Like Pinpoint's other channels, this becomes inaccessible after October 30, 2026 (roughly two months from now), but voice delivery capability itself continues under the rebranded AWS End User Messaging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own voice channel"})

    		ubx.Resource(pinpoint.VoiceChannel, "example", pinpoint.VoiceChannelConfig{
    			ApplicationId: "example",
    			Enabled:       true,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {

      resource(VoiceChannel, "example", {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.pinpoint import VoiceChannel, VoiceChannelConfig

    def describe():
        ubx.intent("example own voice channel")

        ubx.resource(VoiceChannel, "example", VoiceChannelConfig(
            application_id="example",
            enabled=True,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier for the Amazon Pinpoint application that the voice channel is enabled for. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Specifies whether the voice channel is enabled for sending voice messages through Amazon Pinpoint. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the Amazon Pinpoint application that this voice channel belongs to (same value as the ApplicationId). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

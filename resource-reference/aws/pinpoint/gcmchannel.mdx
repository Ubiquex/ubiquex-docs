`aws_pinpoint_gcmchannel` enables a real push-notification channel on an `aws_pinpoint_app` for Android devices through Firebase Cloud Messaging (the successor branding of Google Cloud Messaging), subject to the same October 30, 2026 Pinpoint retirement.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gcmchannel"})

    		ubx.Resource(pinpoint.Gcmchannel, "example", pinpoint.GcmchannelConfig{
    			ApplicationId:               "example",
    			ApiKey:                      "example",
    			DefaultAuthenticationMethod: "example",
    			Enabled:                     true,
    			ServiceJson:                 "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_key" type="string">
  The Google API key used to authorize Amazon Pinpoint to send push notifications through Firebase Cloud Messaging (GCM) to Android apps. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="application_id" type="string" required>
  The unique identifier for the Amazon Pinpoint application that the GCM channel is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_authentication_method" type="string">
  Specifies the default authentication method for the GCM channel, either 'TOKEN' or 'KEY', which determines how Amazon Pinpoint authenticates with Firebase Cloud Messaging (FCM) when sending push notifications to Android apps. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Enables or disables the Google Cloud Messaging (GCM) channel for the associated Amazon Pinpoint application, controlling whether push notifications can be sent to Android devices. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_json" type="string">
  A JSON string containing the Firebase Cloud Messaging (FCM) service account credentials (service account key) that Amazon Pinpoint uses to send push notifications through the GCM channel; when specified, it is used instead of the deprecated API key. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The identifier of the GCM channel, equal to the associated Pinpoint application ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

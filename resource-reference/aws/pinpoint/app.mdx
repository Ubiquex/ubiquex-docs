---
title: "aws_pinpoint_app"
description: "`aws_pinpoint_app` creates a real Pinpoint project, the top-level container that channels, segments, campaigns, and templates are organized under."
---

AWS closed Amazon Pinpoint to new customers on May 20, 2025, and the Pinpoint console and its engagement resources, endpoints, segments, campaigns, journeys, templates, and analytics, become inaccessible after October 30, 2026, a date roughly two months from now. AWS's guidance is to move engagement workloads toward Amazon Connect and other services; SMS, push, voice, and OTP delivery continue under the rebranded AWS End User Messaging, and email delivery continues under Amazon SES.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app"})

    		ubx.Resource(pinpoint.App, "example", pinpoint.AppConfig{
    			Name: "example",
    			Tags: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { App } from "@ubx/sdk-aws/aws/pinpoint/app";

    export default stack("example", () => {
      intent({ summary: "example own app" });

      resource(App, "example", {
        name: "example",
        tags: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.pinpoint import App, AppConfig

    def describe():
        ubx.intent("example own app")

        ubx.resource(App, "example", AppConfig(
            name="example",
            tags="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
  <Tab title="Markdown">


## Input properties

<ResponseField name="name" type="string" required>
  The display name of the Amazon Pinpoint application. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Assigns tags (key-value pairs) to the Amazon Pinpoint application, enabling categorization and management via AWS Resource Groups and cost allocation. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Pinpoint application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier assigned to the Amazon Pinpoint application when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_pinpoint_apnssandbox_channel` enables a real APNs sandbox (development/testing) push channel on an `aws_pinpoint_app`, the narrower, non-production counterpart to `aws_pinpoint_apnschannel`, subject to the same October 30, 2026 Pinpoint retirement.

## Input properties

<ResponseField name="application_id" type="string" required>
  The ID of the Amazon Pinpoint application to which this APNS sandbox channel belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="bundle_id" type="string">
  The bundle identifier (App ID) of the iOS application that will receive push notifications through this APNs sandbox channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate" type="string">
  The Apple Push Notification service (APNs) sandbox certificate, provided in .pem or .p12 format along with its private key, used to authenticate the Pinpoint app with the APNs sandbox endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_authentication_method" type="string">
  Determines the default authentication method (CERTIFICATE or TOKEN) that Amazon Pinpoint uses to authenticate with the APNs sandbox service for this channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Whether the APNs sandbox channel is enabled for sending push notifications. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_key" type="string">
  The private key (from a .p8 file) used to sign APNs authentication tokens when token-based authentication is enabled for the sandbox channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="team_id" type="string">
  The Apple Developer Team ID, a 10-character alphanumeric string, used for APNs authentication with the sandbox channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key" type="string">
  The private key (.p8 file) from Apple used for token-based authentication in the APNs sandbox channel, required when using token credentials instead of a certificate. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key_id" type="string">
  The key ID that Pinpoint uses to identify the private token key when authenticating with the APNs sandbox service. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the Amazon Pinpoint application that this APNs sandbox channel is associated with. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

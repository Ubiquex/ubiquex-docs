`aws_pinpoint_event_stream` streams a real `aws_pinpoint_app`'s app and campaign events to a Kinesis stream or Firehose delivery stream, subject to the same October 30, 2026 Pinpoint retirement as the rest of its analytics surface.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own event stream"})

    		ubx.Resource(pinpoint.EventStream, "ci-runner", pinpoint.EventStreamConfig{
    			ApplicationId:        "example",
    			DestinationStreamArn: "arn:aws:iam::123456789012:policy/ci",
    			RoleArn:              "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier (ID) of the Amazon Pinpoint application that the event stream is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="destination_stream_arn" type="string" required>
  The ARN of the Amazon Kinesis Data Stream or Amazon Data Firehose delivery stream that receives the Pinpoint event stream data. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of the IAM role that authorizes Amazon Pinpoint to write event data to the configured Amazon Kinesis stream. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The application ID of the Amazon Pinpoint application that this event stream is associated with. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

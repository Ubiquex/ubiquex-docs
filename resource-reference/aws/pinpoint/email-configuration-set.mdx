`aws_pinpoint_email_configuration_set` defines a real set of rules, event destinations, dedicated IP pool, reputation options, applied to emails sent through an `aws_pinpoint_app`'s `aws_pinpoint_email_channel`, subject to the same October 30, 2026 Pinpoint retirement, with equivalent configuration-set functionality continuing directly under Amazon SES.

## Input properties

<ResponseField name="delivery_options" type="object">
  Configures delivery options for emails sent from this configuration set, including the dedicated IP pool (SendingPoolName) and the TLS policy (TlsPolicy). Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="sending_pool_name" type="string">
      The name of the dedicated IP pool that Amazon Pinpoint uses to send email for this configuration set. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The unique name of the Amazon Pinpoint email configuration set, used as its identifier when you send email or attach event destinations to it. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="reputation_options" type="object">
  Configures reputation metrics tracking for this configuration set, determining whether Amazon Pinpoint publishes email reputation data such as bounce and complaint rates to Amazon CloudWatch. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="reputation_metrics_enabled" type="bool">
      Enables or disables the publishing of reputation metrics (such as bounce and complaint rates) for email messages sent using this Pinpoint email configuration set. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sending_options" type="object">
  Defines the email sending options for the configuration set, specifically whether email sending is enabled via the SendingEnabled sub-property. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="sending_enabled" type="bool">
      Enables or disables email sending for the configuration set when set to true or false, respectively. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs (Tag objects) to attach to the Amazon Pinpoint email configuration set for identifying, organizing, and managing the resource, including for cost allocation reporting. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Amazon Pinpoint email configuration set, used to identify and categorize the configuration set for management, cost tracking, and resource organization purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of an individual tag key on the Amazon Pinpoint email configuration set, used to store metadata for resource identification, organization, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tracking_options" type="object">
  Specifies the custom redirect domain used for open and click tracking in emails sent using this Pinpoint email configuration set. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="custom_redirect_domain" type="string">
      Defines the custom domain that Amazon Pinpoint uses to rewrite links in emails for tracking opens and clicks, overriding the default tracking domain. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

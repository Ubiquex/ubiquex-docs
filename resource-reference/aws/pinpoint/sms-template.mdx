`aws_pinpoint_sms_template` creates a real, reusable SMS message template that an `aws_pinpoint_campaign` or direct send call can reference, subject to the same October 30, 2026 Pinpoint retirement.

## Example

    ```go
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sms template"})

    		ubx.Resource(pinpoint.SmsTemplate, "example", pinpoint.SmsTemplateConfig{
    			Body:                 "example",
    			TemplateName:         "example-template-name",
    			DefaultSubstitutions: "example",
    			Tags:                 "example",
    			TemplateDescription:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="body" type="string" required>
  The actual text content of the SMS message that Amazon Pinpoint sends to recipients when this template is used in a campaign or journey. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_substitutions" type="string">
  Specifies the default substitution variables for the SMS template, provided as a JSON object (string) of key-value pairs that Pinpoint uses to replace message variables when no custom values are supplied. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  A map of key-value pairs to assign as metadata tags to the SMS template, which can be used to categorize the template for cost allocation and management. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_description" type="string">
  A description of the SMS template, used to provide additional context or details about the template's purpose or content. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_name" type="string" required>
  The name of the SMS message template, which must be unique within your AWS account and is used to identify the template in the Pinpoint API. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying the SMS template in Amazon Pinpoint. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The template name, which serves as the unique identifier for the AWS Pinpoint SMS template. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

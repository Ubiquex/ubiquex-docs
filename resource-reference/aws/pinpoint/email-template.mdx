`aws_pinpoint_email_template` creates a real, reusable email template, subject line, HTML and text bodies, that an `aws_pinpoint_campaign` or direct send call can reference instead of specifying content inline, subject to the same October 30, 2026 Pinpoint retirement.

## Input properties

<ResponseField name="default_substitutions" type="string">
  Defines a JSON object of key-value pairs that specify default values for message variables in the email template, used as fallback substitutions when a send request does not provide them. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="html_part" type="string">
  The HTML body of the email template, used by Amazon Pinpoint to render the email content in rich text format for recipients. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subject" type="string" required>
  The subject line of the email message, which is required and appears on all emails sent using this template. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Assigns key-value pairs to the Amazon Pinpoint email template for organizing and identifying it, with each tag consisting of a key and a value. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_description" type="string">
  A user-defined description of the email template, used to document the template's purpose or content. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_name" type="string" required>
  The name of the email template, used as the unique identifier for the template in Amazon Pinpoint. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="text_part" type="string">
  The plain-text body of the email message defined by this template. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the AWS Pinpoint email template. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique name assigned to the email template in Amazon Pinpoint, which identifies it within the AWS account and region. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_pinpoint_apnsvoip_channel` enables a real VoIP push-notification channel on an `aws_pinpoint_app` through Apple's APNs VoIP service, used to wake a calling app for an incoming call rather than to show a standard notification, subject to the same October 30, 2026 Pinpoint retirement as `aws_pinpoint_apnschannel`.

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier of the Amazon Pinpoint application that the APNs VoIP channel is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="bundle_id" type="string">
  The Apple-assigned bundle identifier (e.g., com.example.app) for the iOS app that receives APNs VoIP push notifications, used in the Pinpoint APNs VoIP channel configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate" type="string">
  The Apple Push Notification service (APNs) VoIP channel certificate (the .pem file content) used for certificate-based authentication with APNs, which must be paired with the PrivateKey to enable sending VoIP push notifications. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_authentication_method" type="string">
  Determines the default authentication method (either certificate-based or token-based) that Amazon Pinpoint uses to authenticate with the Apple Push Notification service (APNs) for sending VoIP messages when both credentials are configured. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Indicates whether the APNs VoIP (Apple Push Notification service for Voice over IP) channel is enabled for the associated Amazon Pinpoint application. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_key" type="string">
  The private key from Apple, paired with the certificate, used to authenticate with Apple Push Notification service for sending VoIP push notifications through this channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="team_id" type="string">
  The Apple Developer Team ID used, along with the token key and key identifier, to authenticate the APNs VoIP channel via token-based authentication for sending push notifications. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key" type="string">
  Specifies the token signing key (a .p8 private key from Apple) that Amazon Pinpoint uses to generate authentication tokens for sending VoIP push notifications through the APNs VoIP channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key_id" type="string">
  The key identifier (kid) of the .p8 private token key that Amazon Pinpoint uses to sign APNs authentication tokens for the VoIP channel when the default authentication method is 'token'. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned to the APNs VoIP channel by Amazon Pinpoint. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

---
title: "aws_pinpoint_smschannel"
description: "`aws_pinpoint_smschannel` enables a real SMS-sending channel on an `aws_pinpoint_app`."
---

Like Pinpoint's other channels, this becomes inaccessible after October 30, 2026 (roughly two months from now), but SMS delivery capability itself continues under the rebranded AWS End User Messaging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own smschannel"})

    		ubx.Resource(pinpoint.Smschannel, "example", pinpoint.SmschannelConfig{
    			ApplicationId: "example",
    			Enabled:       true,
    			SenderId:      "example",
    			ShortCode:     "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier for the Amazon Pinpoint application (project) that the SMS channel is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Specifies whether the SMS channel is enabled for sending text messages through the Amazon Pinpoint application. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="sender_id" type="string">
  A custom alphanumeric sender ID that appears on recipients' devices when they receive SMS messages sent from this Pinpoint SMS channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="short_code" type="string">
  The registered short code to use for sending SMS messages with the Amazon Pinpoint SMS channel. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The `id` is the unique identifier for this SMS channel, set to the Amazon Pinpoint application ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

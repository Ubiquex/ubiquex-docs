`aws_pinpoint_application_settings` configures real account-level defaults, quiet hours, campaign hook, limits, for an `aws_pinpoint_app`, subject to the same October 30, 2026 Pinpoint retirement as the rest of its engagement surface.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own application settings"})

    		ubx.Resource(pinpoint.ApplicationSettings, "example", pinpoint.ApplicationSettingsConfig{
    			ApplicationId:            "example",
    			CampaignHook:             map[string]any{"lambda_function_name": "example-lambda-function-name"},
    			CloudWatchMetricsEnabled: true,
    			Limits:                   map[string]any{"daily": 1},
    			QuietTime:                map[string]any{"end": "example", "start": "example"},
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.pinpoint import ApplicationSettings, ApplicationSettingsConfig
    from ubx.aws.pinpoint.application_settings import ApplicationSettings_CampaignHook, ApplicationSettings_Limits, ApplicationSettings_QuietTime

    def describe():
        ubx.intent("example own application settings")

        ubx.resource(ApplicationSettings, "example", ApplicationSettingsConfig(
            application_id="example",
            campaign_hook=ApplicationSettings_CampaignHook(lambda_function_name="example-lambda-function-name"),
            cloud_watch_metrics_enabled=True,
            limits=ApplicationSettings_Limits(daily=1),
            quiet_time=ApplicationSettings_QuietTime(end="example", start="example"),
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  Specifies the unique identifier (ID) of the Amazon Pinpoint application to which these settings apply. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="campaign_hook" type="object">
  The campaign hook specifies the Lambda function and invocation mode that Amazon Pinpoint invokes when a campaign sends messages, enabling custom logic like message personalization or filtering during send time. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="lambda_function_name" type="string">
      The name or ARN of the Lambda function that Amazon Pinpoint invokes as the campaign hook for this application's campaigns and journeys. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="mode" type="string">
      Specifies whether the associated Lambda function is invoked during campaign filtering (FILTER) or during campaign delivery (DELIVERY). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="web_url" type="string">
      Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cloud_watch_metrics_enabled" type="bool">
  Specifies whether CloudWatch metrics are enabled for the Amazon Pinpoint application. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="limits" type="object">
  Defines quotas for campaign messaging, including the maximum number of messages per day, total messages, per-second send rate, and maximum campaign duration. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="daily" type="number">
      The maximum number of messages that a campaign or journey can send to users in a 24-hour period. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="maximum_duration" type="number">
      The maximum number of seconds that a campaign can run before it is stopped. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="messages_per_second" type="number">
      The maximum number of messages that can be sent per second through the Amazon Pinpoint application, as a rate limit for campaigns and journeys. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="total" type="number">
      The default maximum number of messages that a campaign or journey can send to a single user over the entire duration of the campaign or journey, as configured in the application's limits. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="quiet_time" type="object">
  Defines a daily quiet time window with start and end times (in HH:MM format) during which Amazon Pinpoint does not deliver messages to endpoints in the application. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="end" type="string" required>
      Specifies the time, in 24-hour HH:MM format, when the daily quiet time ends for the application, marking the end of the window during which messages are not sent to users. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="start" type="string" required>
      Specifies the start time of the daily quiet period, formatted as HH:MM in 24-hour clock using the application's timezone, during which Amazon Pinpoint suppresses sending messages to endpoints. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  This field is the unique identifier of the Amazon Pinpoint application that these settings apply to, equal to the value of the `application_id` argument. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

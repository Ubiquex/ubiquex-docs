---
title: "aws_pinpoint_campaign"
description: "`aws_pinpoint_campaign` creates a real, scheduled or triggered messaging campaign targeting an `aws_pinpoint_app` segment."
---

Campaigns are explicitly named among the engagement features AWS is retiring: the Pinpoint console and campaign resources become inaccessible after October 30, 2026, a date roughly two months from now, with AWS recommending Amazon Connect for continued engagement use cases.

    import ubx_sdk as ubx
    from ubx.aws.pinpoint import Campaign, CampaignConfig
    from ubx.aws.pinpoint.campaign import Campaign_AdditionalTreatments_Schedule, Campaign_AdditionalTreatments, Campaign_AdditionalTreatments_CustomDeliveryConfiguration, Campaign_CampaignHook

    def describe():
        ubx.intent("example own campaign")

        ubx.resource(Campaign, "example", CampaignConfig(
            application_id="example",
            name="example",
            schedule=Campaign_AdditionalTreatments_Schedule(end_time="example"),
            segment_id="example",
            additional_treatments=[Campaign_AdditionalTreatments(custom_delivery_configuration=Campaign_AdditionalTreatments_CustomDeliveryConfiguration(delivery_uri="example"))],

    if __name__ == "__main__":
        ubx.run("example", describe)

`aws_pinpoint_apnsvoip_sandbox_channel` enables the real sandbox (development/testing) counterpart to `aws_pinpoint_apnsvoip_channel`, subject to the same October 30, 2026 Pinpoint retirement.

## Example

    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own apnsvoip sandbox channel"})

    		ubx.Resource(pinpoint.ApnsvoipSandboxChannel, "example", pinpoint.ApnsvoipSandboxChannelConfig{
    			ApplicationId:               "example",
    			BundleId:                    "example",
    			Certificate:                 "example",
    			DefaultAuthenticationMethod: "example",
    			Enabled:                     true,
    			PrivateKey:                  "example",
    			TeamId:                      "example",
    			TokenKey:                    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier of the Amazon Pinpoint application that this APNs VoIP sandbox channel is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="bundle_id" type="string">
  Specifies the bundle identifier of the iOS app that receives APNs VoIP notifications via the sandbox channel, used when authenticating with APNs token keys. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate" type="string">
  The PEM-encoded Apple Push Notification service (APNs) certificate that Amazon Pinpoint uses to authenticate with APNs for sending VoIP notifications through the sandbox channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_authentication_method" type="string">
  Specifies which authentication method (Certificate or Token) Amazon Pinpoint uses when sending messages through the APNs VoIP sandbox channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool">
  Specifies whether the APNs VoIP sandbox channel is enabled for the application, allowing it to send VoIP push notifications through Apple's sandbox environment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_key" type="string">
  The private key from the Apple Push Notification service (APNs) .p12 certificate file, used to authenticate with APNs for the VoIP sandbox channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="team_id" type="string">
  The Apple Developer Team ID used to authenticate the APNs VoIP sandbox channel's token signing key with Apple's push notification service. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key" type="string">
  The private key (from a .p8 file) used for token-based authentication with Apple Push Notification service for the VoIP sandbox channel in Amazon Pinpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_key_id" type="string">
  Specifies the Apple APNs token key ID (the 10-character key identifier from the .p8 private key) used for token-based authentication with the APNs VoIP sandbox endpoint. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier for this APNs VoIP sandbox channel, which is a short system-assigned string (such as 'apns_voip_sandbox') that identifies the channel within its Pinpoint application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_work_spaces_web_identity_provider` connects a real SAML or OIDC identity provider to an `aws_work_spaces_web_portal`, so end users authenticate with their existing corporate identity before a secure browsing session starts.

## Input properties

<ResponseField name="identity_provider_details" type="any" required>
  Provides the identity provider-specific configuration details, such as SAML metadata or OIDC client credentials (e.g., clientId, clientSecret, authorizeScopes), required to integrate the provider with WorkSpaces Web. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_provider_name" type="string" required>
  Specifies the user-friendly name for the identity provider used to authenticate users to the WorkSpaces Web portal. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_provider_type" type="string" required>
  Specifies the type of identity provider (SAML or OIDC) used for this WorkSpaces Web identity provider configuration. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="portal_arn" type="string">
  The ARN of the WorkSpaces Web portal to which this identity provider configuration is attached. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">

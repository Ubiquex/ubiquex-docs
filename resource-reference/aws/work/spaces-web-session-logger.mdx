`aws_work_spaces_web_session_logger` configures real session logging, screen recording or event logs delivered to S3, for an `aws_work_spaces_web_portal`, for compliance or security review of what happened during a browsing session.

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  A map of key-value pairs that serve as additional encryption context for the KMS key used to encrypt session log data, providing extra authenticated data to the encryption/decryption process. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="customer_managed_key" type="string">
  Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  Specifies the display name for the session logger, providing a human-readable identifier for this logging configuration in the AWS Management Console and CloudFormation stacks. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="event_filter" type="object" required>
  Required.
  <Expandable title="properties">
    <ResponseField name="all" type="any">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="include" type="list(string)">
      The list of event type strings that the session logger should include in its log output, filtering out any session events not matching these values. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="log_configuration" type="object" required>
  Required.
  <Expandable title="properties">
    <ResponseField name="s3" type="object">
      Configures the S3 bucket and key prefix that serves as the destination for WorkSpaces Web session logs when S3 is the selected log output type. Optional. **(AI-inferred)**
      <Expandable title="properties">

          The name of the S3 bucket that receives WorkSpaces Web session logs. Required. **(AI-inferred)**

        <ResponseField name="bucket_owner" type="string">
          Specifies the AWS account ID of the S3 bucket owner, used to validate access when delivering session logs to an S3 bucket owned by a different account. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="folder_structure" type="string" required>
          Specifies the hierarchical folder layout used to store session log files in the S3 bucket, typically a date-based pattern (e.g., yyyy/MM/dd/HH/) that controls how logs are partitioned in the bucket. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="key_prefix" type="string">
          The S3 object key prefix under which session logger log files are stored in the configured S3 bucket. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="log_file_format" type="string" required>
          Specifies the file format (TEXT or JSON) for WorkSpaces Web session logs delivered to the configured Amazon S3 bucket. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

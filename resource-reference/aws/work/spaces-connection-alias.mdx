`aws_work_spaces_connection_alias` registers a real custom domain name that can be used to connect to an `aws_work_spaces_workspace` across accounts (in a multi-Region resilience or cross-account access setup), instead of connecting through WorkSpaces' own default registration code.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	work "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/work"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own spaces connection alias"})

    		ubx.Resource(work.SpacesConnectionAlias, "example", work.SpacesConnectionAliasConfig{
    			ConnectionString: "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="connection_string" type="string" required>
  The fully qualified domain name (FQDN) that serves as the custom connection string for the WorkSpaces connection alias, such as 'www.example.com', which must be a valid domain you own and that users will use to connect to their WorkSpaces. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tag pairs assigned to the WorkSpaces Connection Alias to help manage, organize, and identify the alias resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the WorkSpaces connection alias. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="alias_id" type="string">
  The unique identifier assigned to the WorkSpaces connection alias when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="associations" type="list(object)">
  Returns the computed list of associations for this WorkSpaces connection alias, detailing the directories or resources it is linked to along with their association state and resource identifiers. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="associated_account_id" type="string">
      The AWS account ID of the account associated with this WorkSpaces connection alias, enabling cross-account redirection for WorkSpaces clients in that account. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="association_status" type="string">
      The status of the association between the WorkSpaces connection alias and its associated directory, indicating whether the association is pending, available, or failed. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="connection_identifier" type="string">
      The unique identifier for a connection alias association, which is assigned by AWS when the connection alias is associated with a WorkSpaces directory. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_id" type="string">
      The unique identifier of the WorkSpaces directory that is associated with the connection alias to enable cross-account access. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="connection_alias_state" type="string">
  The current lifecycle state of the connection alias, such as CREATING, CREATED, or DELETING. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

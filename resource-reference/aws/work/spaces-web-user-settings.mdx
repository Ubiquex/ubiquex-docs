`aws_work_spaces_web_user_settings` defines real, reusable end-user permissions, whether copy/paste, printing, or file transfer is allowed, that an `aws_work_spaces_web_portal` applies to every session.

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  Specifies a map of up to five key-value pairs that are passed as additional encryption context to AWS KMS when the WorkSpaces Web user settings are encrypted using a customer managed key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cookie_synchronization_configuration" type="object">
  Configuration for cookie synchronization across web portal browser sessions, specifying a list of domains that are blocked from having their cookies synchronized. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="allowlist" type="list(object)" required>
      Specifies the allowed cookies that are synchronized across browser sessions, where each item identifies a cookie by name (and optionally domain) to control which cookies are kept in sync. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="domain" type="string">
          Specifies a domain that is allowed for cookie synchronization in the WorkSpaces Web user settings, meaning cookies for that domain will be shared across browser sessions. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of the cookie that is allowed to be synchronized for the associated domain and path in the cookie synchronization allowlist for the WorkSpaces Web user settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="path" type="string">
          Specifies the URL path within the domain for which cookies are synchronized, as part of an allowlist entry in the cookie synchronization configuration for WorkSpaces Web user settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="blocklist" type="list(object)">
      Lists the cookie specifications that are blocked from being synchronized between the user's local browser and the WorkSpaces Web session, so cookies matching these specifications will not be shared. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="domain" type="string">
          The domain name for which cookies are blocked from synchronization across browser sessions in the WorkSpaces Web user settings cookie synchronization configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of the cookie on the blocklist, preventing its value from being synchronized between the user's local browser and the WorkSpaces Web streaming session. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="path" type="string">
          The URL path that the cookie applies to, identifying a cookie in the blocklist of cookies excluded from synchronization for the WorkSpaces Web user settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

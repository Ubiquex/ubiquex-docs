`aws_work_spaces_workspace` creates a real, persistent virtual desktop, Windows or Linux, that a user connects to with a WorkSpaces client, Amazon WorkSpaces' original, full-desktop product distinct from the browser-only `aws_work_spaces_web_portal`.

## Input properties

<ResponseField name="bundle_id" type="string" required>
  The ID of the WorkSpace bundle that defines the operating system, software, and compute resources for the WorkSpace. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="directory_id" type="string" required>
  The identifier of the AWS Directory Service directory in which the WorkSpace is registered. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="root_volume_encryption_enabled" type="bool">
  Specifies whether the root volume (C: drive) of the WorkSpace is encrypted for this WorkSpace. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies key-value tags to associate with the WorkSpace, enabling you to organize, identify, and track the resource for cost allocation and management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the WorkSpace, used to categorize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_name" type="string" required>
  The login name of the user in the directory, for whom the WorkSpace is provisioned and associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_volume_encryption_enabled" type="bool">
  Indicates whether the user volume (the D: drive on Windows or /home on Linux) of the WorkSpace is encrypted. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="volume_encryption_key" type="string">
  The AWS KMS key ARN or ID used to encrypt the user and root storage volumes of the WorkSpace, which is required when volume encryption is enabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="workspace_properties" type="object">
  Specifies the runtime and storage configuration for the WorkSpace, including compute type, running mode, auto-stop timeout, and root/user volume sizes in GiB. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="compute_type_name" type="string">
      The name of the compute type for the WorkSpace (e.g., VALUE, STANDARD, PERFORMANCE, POWER, GRAPHICS), which determines the hardware specifications such as CPU, memory, and storage resources allocated to the virtual desktop. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="root_volume_size_gib" type="number">
      Specifies the size of the root volume (C: drive on Windows, / on Linux) for the WorkSpace, in GiB. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="running_mode" type="string">
      Controls whether the WorkSpace runs continuously (ALWAYS_ON) or automatically stops when idle (AUTO_STOP), affecting billing and availability. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="running_mode_auto_stop_timeout_in_minutes" type="number">
      The number of minutes a WorkSpace in AUTO_STOP running mode remains running after the user disconnects before it is automatically stopped, with valid values from 60 to 720 minutes. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="user_volume_size_gib" type="number">
      The size, in GiB, of the user volume (persistent storage for user data) for the WorkSpace. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique AWS-assigned identifier for the WorkSpace, typically in the form ws- followed by a string, used to reference the workspace within the account. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="workspace_id" type="string">
  The unique identifier assigned by AWS to the WorkSpace, such as 'ws-12345678'. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_work_spaces_web_portal` creates a real Amazon WorkSpaces Secure Browser portal, a fully managed, isolated, in-browser session, that end users connect to instead of a full `aws_work_spaces_workspace` virtual desktop, when only web access, not a whole OS, is what's actually needed.

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  Specifies a map of additional encryption context (key-value pairs) that is included in the encryption context when AWS KMS encrypts the portal's data using a customer-managed key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authentication_type" type="string">
  Specifies the authentication method for the WorkSpaces Web portal, which can be either 'Standard' or 'IAM Identity Center'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="browser_settings_arn" type="string">
  The ARN of the browser settings resource that defines the browser configuration and policies applied to this WorkSpaces Web portal. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="customer_managed_key" type="string">
  The ARN of the customer managed key used to encrypt the portal's data. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_protection_settings_arn" type="string">
  The ARN of the data protection settings resource to associate with the WorkSpaces Web portal, enabling data loss prevention and session monitoring policies for browser sessions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string">
  Specifies the user-visible name for the WorkSpaces Web portal, which appears in the portal's title or header. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_type" type="string">
  Specifies the instance type for the WorkSpaces Web portal's streaming sessions, determining the compute and memory resources available to end users. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ip_access_settings_arn" type="string">
  The ARN of the IP access settings resource that defines the IP allowlist for accessing this WorkSpaces Web portal. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_concurrent_sessions" type="number">
  The maximum number of concurrent user sessions allowed for the WorkSpaces Web portal, capping active sessions to manage resource usage. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_settings_arn" type="string">

`aws_work_spaces_thin_client_environment` creates a real, managed environment for WorkSpaces Thin Client devices, physical, purpose-built hardware for connecting to virtual desktops, controlling their software updates, maintenance windows, and device policies centrally rather than device by device.

## Input properties

<ResponseField name="desired_software_set_id" type="string">
  The ID of the software set to apply. Optional.
</ResponseField>

<ResponseField name="desktop_arn" type="string" required>
  The Amazon Resource Name (ARN) of the desktop to stream from Amazon WorkSpaces, WorkSpaces Web, or AppStream 2.0. Required.
</ResponseField>

<ResponseField name="desktop_endpoint" type="string">
  The URL for the identity provider login (only for environments that use AppStream 2.0). Optional.
</ResponseField>

<ResponseField name="device_creation_tags" type="list(object)">
  An array of key-value pairs to apply to the newly created devices for this environment. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key to apply to each WorkSpaces Thin Client device created from this environment, used to tag provisioned devices. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag that is automatically applied to Thin Client devices created from this environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The Amazon Resource Name (ARN) of the AWS Key Management Service key used to encrypt the environment. Optional.
</ResponseField>

<ResponseField name="maintenance_window" type="object">
  Defines the recurring maintenance window for the environment, specifying the days of the week and the start/end times (in UTC) when AWS can perform maintenance on the thin client environment. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="apply_time_of" type="string">
      The desired time zone maintenance window. Optional.
    </ResponseField>
    <ResponseField name="days_of_the_week" type="list(string)">
      The date of maintenance window. Optional.
    </ResponseField>
    <ResponseField name="end_time_hour" type="number">
      The hour of the day in 24-hour time (0-23) at which a custom maintenance window ends, used when the maintenance window type is set to CUSTOM. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="end_time_minute" type="number">
      The minute (0-59) of the hour at which the maintenance window ends for scheduling maintenance on the Thin Client environment. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="start_time_hour" type="number">
      The hour (0-23) of the day, in 24-hour time, at which the maintenance window for applying updates to the WorkSpaces Thin Client environment begins. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="start_time_minute" type="number">
      The minute of the hour, in UTC, at which the maintenance window starts for this WorkSpaces Thin Client environment. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of maintenance window. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the environment. Optional.
</ResponseField>

<ResponseField name="software_set_update_mode" type="string">
  An option to define which software updates to apply. Optional.
</ResponseField>

<ResponseField name="software_set_update_schedule" type="string">
  An option to define if software updates should be applied within a maintenance window. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to a WorkSpaces Thin Client environment, used for organizing and identifying the environment (e.g., cost allocation, environment management). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="activation_code" type="string">
  Activation code for devices associated with environment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="arn" type="string">
  The environment ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp in unix epoch format when environment was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="desktop_type" type="string">
  The type of VDI. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  Unique identifier of the environment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="pending_software_set_id" type="string">
  The ID of the software set that is pending to be installed. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="pending_software_set_version" type="string">
  The version of the software set that is pending to be installed. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="registered_devices_count" type="number">
  Number of devices registered to the environment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="software_set_compliance_status" type="string">
  Describes if the software currently installed on all devices in the environment is a supported version. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp in unix epoch format when environment was last updated. Computed by AWS after `ship`.
</ResponseField>

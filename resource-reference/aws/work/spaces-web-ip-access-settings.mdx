`aws_work_spaces_web_ip_access_settings` defines a real, reusable allow-list of IP ranges that an `aws_work_spaces_web_portal` restricts session access to, keeping the portal reachable only from expected corporate networks.

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  The additional_encryption_context is a dynamic map of arbitrary key-value pairs that are included as additional encryption context when AWS KMS encrypts the WorkSpaces Web IP access settings using a customer-managed KMS key. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="customer_managed_key" type="string">
  The ARN of a customer-managed KMS key used to encrypt the IP access settings; if not specified, an AWS-managed key is used. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Specifies an optional textual description for the IP access settings, providing a human-readable label to identify the resource in the WorkSpaces Web environment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string">
  A human-readable display name for the IP access settings that helps identify this set of rules in the WorkSpaces Web portal. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ip_rules" type="list(object)" required>
  Specifies the list of IP rules that define allowed or denied client IP address ranges (in CIDR notation) for accessing the WorkSpaces Web portal. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      Specifies a human-readable description for the IP access rule that identifies its purpose or context. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ip_range" type="string">
      The CIDR block (e.g., 192.0.2.0/24) that defines the IP address range this rule allows or denies access from. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">

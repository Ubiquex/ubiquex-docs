`aws_ram_resource_share` creates a real cross-account resource share, listing the specific resource ARNs, principal accounts or organizational units, and permissions involved, the core AWS Resource Access Manager resource that actually grants another account access to a resource without duplicating it.

## Input properties

<ResponseField name="allow_external_principals" type="bool">
  Specifies whether principals outside your organization in AWS Organizations can be associated with a resource share. A value of `true` lets you share with individual AWS accounts that are not in your organization. A value of `false` only has meaning if your account is a member of an AWS Organization. The default value is `true`. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Specifies the name of the resource share. Required.
</ResponseField>

<ResponseField name="permission_arns" type="list(string)">
  Specifies the [Amazon Resource Names (ARNs)](https://docs.aws.amazon.com/general/latest/gr/aws-arns-and-namespaces.html) of the AWS RAM permission to associate with the resource share. If you do not specify an ARN for the permission, AWS RAM automatically attaches the default version of the permission for each resource type. You can associate only one permission with each resource type included in the resource share. Optional.
</ResponseField>

<ResponseField name="principals" type="list(string)">
  Specifies the principals to associate with the resource share. The possible values are: - An AWS account ID - An Amazon Resource Name (ARN) of an organization in AWS Organizations - An ARN of an organizational unit (OU) in AWS Organizations - An ARN of an IAM role - An ARN of an IAM user Optional.
</ResponseField>

<ResponseField name="resource_arns" type="list(string)">
  Specifies a list of one or more ARNs of the resources to associate with the resource share. Optional.
</ResponseField>

<ResponseField name="resource_share_configuration" type="object">
  The configuration for a resource share. Optional.
  <Expandable title="properties">
    <ResponseField name="exclusive_account_access" type="bool">
      The resource share restricts access to an account Optional.
    </ResponseField>
    <ResponseField name="retain_sharing_on_account_leave_organization" type="bool">
      Specifies whether the consumer account retains access to the resource share after leaving the organization. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sources" type="list(string)">
  Specifies from which source accounts the service principal has access to the resources in this resource share. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies one or more tags to attach to the resource share itself. It doesn't attach the tags to the resources associated with the resource share. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS RAM resource share, used for cost allocation and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS RAM resource share, used for categorizing and managing the resource share. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

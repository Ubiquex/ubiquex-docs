`aws_ram_permission` defines a real, reusable managed permission, the specific set of actions a principal is allowed on a shared resource, that an `aws_ram_resource_share` attaches instead of relying only on the resource's own default permission.

## Example

<Tabs>

    ```go
    package main

    import (
    	ram "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ram"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own permission"})

    		ubx.Resource(ram.Permission, "example", ram.PermissionConfig{
    			Name:           "example",
    			PolicyTemplate: "example",
    			ResourceType:   "example",
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The name of the permission. Required.
</ResponseField>

<ResponseField name="policy_template" type="any" required>
  Policy template for the permission. Required.
</ResponseField>

<ResponseField name="resource_type" type="string" required>
  The resource type this permission can be used with. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to associate with the custom RAM permission, used for tagging and categorizing the permission in AWS Resource Access Manager. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the AWS Resource Access Manager (RAM) permission, used for organizing and filtering the permission in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this AWS Resource Access Manager permission, including the AWS account, region, permission name, and version (e.g., arn:aws:ram:us-east-1:123456789012:permission/MyPermission/1). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="is_resource_type_default" type="bool">
  Set to true to use this as the default permission. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="permission_type" type="string">
  Indicates whether the RAM permission is AWS-managed or customer-managed. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="version" type="string">
  Version of the permission. Computed by AWS after `ship`.
</ResponseField>

`aws_secrets_manager_rotation_schedule` configures real, automatic rotation, a schedule and a Lambda rotation function, for an `aws_secrets_manager_secret`, so its credential value is periodically replaced without manual intervention.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	secretsmanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/secretsmanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own rotation schedule"})

    		ubx.Resource(secretsmanager.RotationSchedule, "example", secretsmanager.RotationScheduleConfig{
    			SecretId:                       "example",
    			ExternalSecretRotationMetadata: []map[string]any{{"key": "example"}},
    			ExternalSecretRotationRoleArn:  "arn:aws:iam::123456789012:policy/example",
    			HostedRotationLambda:           map[string]any{"rotation_type": "example"},
    			RotateImmediatelyOnUpdate:      true,
    			RotationLambdaArn:              "arn:aws:iam::123456789012:policy/example",
    			RotationRules:                  map[string]any{"automatically_after_days": 1},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="external_secret_rotation_metadata" type="list(object)">
  The list of metadata needed to successfully rotate a managed external secret. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a key-value pair in the external_secret_rotation_metadata map, which is passed as metadata to an external rotation Lambda function to customize the rotation process. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="external_secret_rotation_role_arn" type="string">
  The ARN of the IAM role that is used by Secrets Manager to rotate a managed external secret. Optional.
</ResponseField>

<ResponseField name="hosted_rotation_lambda" type="object">
  Configuration for a hosted AWS Secrets Manager rotation Lambda function, including the rotation type (e.g., MySQLSingleUser) and optional settings such as VPC configuration and a custom function name, which AWS Secrets Manager provisions and manages automatically to rotate the secret. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="exclude_characters" type="string">
      A string of the characters that you don't want in the password. Optional.
    </ResponseField>
    <ResponseField name="kms_key_arn" type="string">
      The ARN of the KMS key that Secrets Manager uses to encrypt the secret. If you don't specify this value, then Secrets Manager uses the key aws/secretsmanager. If aws/secretsmanager doesn't yet exist, then Secrets Manager creates it for you automatically the first time it encrypts the secret value. Optional.
    </ResponseField>
    <ResponseField name="master_secret_arn" type="string">
      The ARN of the secret that contains superuser credentials, if you use the alternating users rotation strategy. CloudFormation grants the execution role for the Lambda rotation function GetSecretValue permission to the secret in this property. Optional.
    </ResponseField>
    <ResponseField name="master_secret_kms_key_arn" type="string">
      The ARN of the KMS key that Secrets Manager used to encrypt the superuser secret, if you use the alternating users strategy and the superuser secret is encrypted with a customer managed key. You don't need to specify this property if the superuser secret is encrypted using the key aws/secretsmanager. CloudFormation grants the execution role for the Lambda rotation function Decrypt, DescribeKey, and GenerateDataKey permission to the key in this property. Optional.
    </ResponseField>
    <ResponseField name="rotation_lambda_name" type="string">
      The name of the Lambda rotation function. Optional.
    </ResponseField>
    <ResponseField name="rotation_type" type="string" required>
      The type of rotation template to use Required.
    </ResponseField>
    <ResponseField name="runtime" type="string">
      The python runtime associated with the Lambda function Optional.
    </ResponseField>
    <ResponseField name="superuser_secret_arn" type="string">
      The ARN of the secret that contains superuser credentials, if you use the alternating users rotation strategy. CloudFormation grants the execution role for the Lambda rotation function GetSecretValue permission to the secret in this property. Optional.
    </ResponseField>
    <ResponseField name="superuser_secret_kms_key_arn" type="string">
      The ARN of the KMS key that Secrets Manager used to encrypt the superuser secret, if you use the alternating users strategy and the superuser secret is encrypted with a customer managed key. You don't need to specify this property if the superuser secret is encrypted using the key aws/secretsmanager. CloudFormation grants the execution role for the Lambda rotation function Decrypt, DescribeKey, and GenerateDataKey permission to the key in this property. Optional.
    </ResponseField>
    <ResponseField name="vpc_security_group_ids" type="string">
      A comma-separated list of security group IDs applied to the target database. Optional.
    </ResponseField>
    <ResponseField name="vpc_subnet_ids" type="string">
      A comma separated list of VPC subnet IDs of the target database network. The Lambda rotation function is in the same subnet group. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rotate_immediately_on_update" type="bool">
  Specifies whether to rotate the secret immediately or wait until the next scheduled rotation window. Optional.
</ResponseField>

<ResponseField name="rotation_lambda_arn" type="string">
  The ARN of an existing Lambda rotation function. To specify a rotation function that is also defined in this template, use the Ref function. Optional.
</ResponseField>

<ResponseField name="rotation_rules" type="object">
  Defines the rotation schedule for the secret, including how often it rotates (via automatically_after_days or a cron/rate expression) and optionally the rotation window duration. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="automatically_after_days" type="number">
      The number of days between automatic scheduled rotations of the secret. You can use this value to check that your secret meets your compliance guidelines for how often secrets must be rotated. Optional.
    </ResponseField>
    <ResponseField name="duration" type="string">
      The length of the rotation window in hours, for example 3h for a three hour window. Secrets Manager rotates your secret at any time during this window. The window must not extend into the next rotation window or the next UTC day. The window starts according to the ScheduleExpression. If you don't specify a Duration, for a ScheduleExpression in hours, the window automatically closes after one hour. For a ScheduleExpression in days, the window automatically closes at the end of the UTC day. Optional.
    </ResponseField>
    <ResponseField name="schedule_expression" type="string">
      A cron() or rate() expression that defines the schedule for rotating your secret. Secrets Manager rotation schedules use UTC time zone. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="secret_id" type="string" required>
  The ARN or name of the secret to rotate. Required.
</ResponseField>

`aws_dsql_cluster` creates a real Aurora DSQL cluster, a serverless, PostgreSQL-compatible distributed SQL database with independently scaling compute, commit, and storage components and no single leader, built for 99.99% single-Region or 99.999% multi-Region availability without a caller sharding or upgrading instances.

## Input properties

<ResponseField name="deletion_protection_enabled" type="bool">
  Whether deletion protection is enabled in this cluster. Optional.
</ResponseField>

<ResponseField name="kms_encryption_key" type="string">
  The KMS key that encrypts data on the cluster. Optional.
</ResponseField>

<ResponseField name="multi_region_properties" type="object">
  The Multi-region properties associated to this cluster. Optional.
  <Expandable title="properties">
    <ResponseField name="clusters" type="list(string)">
      Specifies the Amazon Resource Names (ARNs) of the linked regional DSQL clusters that form the multi-region cluster. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="witness_region" type="string">
      The witness region in a multi-region cluster. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="policy_document" type="string">
  The IAM policy applied to the cluster resource. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the DSQL cluster, used to organize and identify the cluster for management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the DSQL cluster, used for metadata and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

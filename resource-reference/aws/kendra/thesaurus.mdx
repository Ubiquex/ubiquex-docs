`aws_kendra_thesaurus` teaches an `aws_kendra_index` real synonym relationships, so a search for one term also matches documents using an equivalent term, improving recall beyond exact keyword matching.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own thesaurus"})

    		ubx.Resource(kendra.Thesaurus, "example", kendra.ThesaurusConfig{
    			IndexId:      "example",
    			Name:         "example",
    			RoleArn:      "arn:aws:iam::123456789012:policy/example",
    			SourceS3Path: map[string]any{"bucket": "example"},
    			Description:  "Managed by ubx.",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A description for the thesaurus. Optional.
</ResponseField>

<ResponseField name="index_id" type="string" required>
  The identifier of the index for the thesaurus. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the thesaurus. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  An IAM role that gives Amazon Kendra permissions to access the thesaurus file specified in SourceS3Path. Required.
</ResponseField>

<ResponseField name="source_s3_path" type="object" required>
  Information required to find a specific file in an Amazon S3 bucket. Required.
  <Expandable title="properties">
    <ResponseField name="bucket" type="string" required>
      The name of the S3 bucket that contains the file. Required.
    </ResponseField>
    <ResponseField name="key" type="string" required>
      The name of the file. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that identify or categorize the thesaurus. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to an AWS Kendra thesaurus, used to organize and identify the resource for management and billing. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag entry associated with the AWS Kendra thesaurus, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the thesaurus. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The identifier of the thesaurus. Computed by AWS after `ship`.
</ResponseField>

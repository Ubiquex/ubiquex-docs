`aws_kendra_faq` loads a real, structured set of question-and-answer pairs directly into an `aws_kendra_index`, so an exact FAQ match can be surfaced with high confidence rather than relying only on Kendra's own document-search relevance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own faq"})

    		ubx.Resource(kendra.Faq, "example", kendra.FaqConfig{
    			IndexId:      "example",
    			Name:         "example",
    			RoleArn:      "arn:aws:iam::123456789012:policy/example",
    			S3Path:       map[string]any{"bucket": "example"},
    			Description:  "Managed by ubx.",
    			FileFormat:   "example",
    			LanguageCode: "example",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  Description of the FAQ Optional.
</ResponseField>

<ResponseField name="file_format" type="string">
  Format of the input file Optional.
</ResponseField>

<ResponseField name="index_id" type="string" required>
  Unique ID of Index Required.
</ResponseField>

<ResponseField name="language_code" type="string">
  The code for a language. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the FAQ, a required human-readable identifier used to distinguish this FAQ within Amazon Kendra. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of the IAM role that Amazon Kendra assumes to read the FAQ file from your S3 bucket. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="s3_path" type="object" required>
  The S3 location (bucket and object key) of the FAQ file stored in Amazon S3. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="bucket" type="string" required>
      The name of the S3 bucket that contains the FAQ data file specified for the Kendra FAQ. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="key" type="string" required>
      The S3 object key (file name/path) within the bucket that points to the FAQ file used by the Kendra index. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  List of tags Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">

    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag (a key-value pair) attached to the Amazon Kendra FAQ resource, used for metadata, categorization, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "aws_odb_network"
description: "`aws_odb_network` creates a real network, peered to an Amazon VPC..."
---

`aws_odb_network` creates a real network, peered to an Amazon VPC, that lets EC2 application servers reach Oracle Exadata databases running under Oracle Database@AWS; provisioning an `aws_odb_cloud_vm_cluster` requires an ODB network to already exist.

## Example

    ```go
    	ubx.Main(ubx.Stack("example", func() {

    			ClientSubnetCidr:            "example",
    			CrossRegionS3RestoreSources: []string{"example"},
    			CustomDomainName:            "example-custom-domain-name",
    			DefaultDnsPrefix:            "example",
    			DeleteAssociatedResources:   true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="availability_zone" type="string">
  The AWS Availability Zone (AZ) where the ODB network is located. Optional.
</ResponseField>

<ResponseField name="availability_zone_id" type="string">
  The AZ ID of the AZ where the ODB network is located. Optional.
</ResponseField>

<ResponseField name="backup_subnet_cidr" type="string">
  The CIDR range of the backup subnet in the ODB network. Optional.
</ResponseField>

<ResponseField name="client_subnet_cidr" type="string">
  The CIDR range of the client subnet in the ODB network. Optional.
</ResponseField>

<ResponseField name="cross_region_s3_restore_sources" type="list(string)">
  The cross-Region Amazon S3 restore sources for the ODB network. Optional.
</ResponseField>

<ResponseField name="custom_domain_name" type="string">
  The domain name to use for the resources in the ODB network. Optional.
</ResponseField>

<ResponseField name="default_dns_prefix" type="string">
  The DNS prefix to the default DNS domain name. The default DNS domain name is oraclevcn.com. Optional.
</ResponseField>

<ResponseField name="delete_associated_resources" type="bool">
  Specifies whether to delete associated OCI networking resources along with the ODB network. Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-friendly name of the ODB network. Optional.
</ResponseField>

<ResponseField name="kms_access" type="string">
  The AWS Key Management Service (KMS) access configuration for the ODB network. Optional.
</ResponseField>

<ResponseField name="kms_policy_document" type="string">
  The AWS Key Management Service (KMS) policy document that defines permissions for key usage within the ODB network. Optional.
</ResponseField>

<ResponseField name="s3_access" type="string">
  Specifies the configuration for Amazon S3 access from the ODB network. Optional.
</ResponseField>

<ResponseField name="s3_policy_document" type="string">
  Specifies the endpoint policy for Amazon S3 access from the ODB network. Optional.
</ResponseField>

<ResponseField name="sts_access" type="string">
  The AWS Security Token Service (STS) access configuration for the ODB network. Optional.
</ResponseField>

<ResponseField name="sts_policy_document" type="string">
  The AWS Security Token Service (STS) policy document that defines permissions for token service usage within the ODB network. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the Odb Network. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the network resource, used as the tag's unique identifier within the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="zero_etl_access" type="string">
  Specifies the configuration for Zero-ETL access from the ODB network. Optional.
</ResponseField>

title: "aws_odb_cloud_autonomous_vm_cluster"

---

`aws_odb_cloud_autonomous_vm_cluster` creates a real Autonomous VM cluster on top of an `aws_odb_cloud_exadata_infrastructure`, a set of fully managed Oracle Autonomous Databases that automate their own patching, tuning, and scaling with no manual intervention, the autonomous counterpart to `aws_odb_cloud_vm_cluster`'s own manually administered databases.

## Example

    ```go
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cloud autonomous vm cluster"})

    		ubx.Resource(odb.CloudAutonomousVmCluster, "example", odb.CloudAutonomousVmClusterConfig{
    			AutonomousDataStorageSizeInTbs: 1,
    			CloudExadataInfrastructureId:   "example",
    			CpuCoreCountPerNode:            1,
    			DbServers:                      []string{"example"},
    			Description:                    "Managed by ubx.",
    			DisplayName:                    "example-display-name",
    			IsMtlsEnabledVmCluster:         true,
    			LicenseModel:                   "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="autonomous_data_storage_size_in_tbs" type="number">
  The data storage size allocated for Autonomous Databases in the Autonomous VM cluster, in TB. Optional.
</ResponseField>

<ResponseField name="cloud_exadata_infrastructure_id" type="string">
  The unique identifier of the Cloud Exadata Infrastructure containing this Autonomous VM cluster. Optional.
</ResponseField>

<ResponseField name="cpu_core_count_per_node" type="number">
  The number of CPU cores enabled per node in the Autonomous VM cluster. Optional.
</ResponseField>

<ResponseField name="db_servers" type="list(string)">
  The list of database servers associated with the Autonomous VM cluster. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The user-provided description of the Autonomous VM cluster. Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  The display name of the Autonomous VM cluster. Optional.
</ResponseField>

<ResponseField name="is_mtls_enabled_vm_cluster" type="bool">

</ResponseField>

<ResponseField name="license_model" type="string">
  The Oracle license model that applies to the Autonomous VM cluster. Valid values are LICENSE_INCLUDED or BRING_YOUR_OWN_LICENSE. Optional.

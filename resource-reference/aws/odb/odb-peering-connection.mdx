`aws_odb_odb_peering_connection` establishes a real, private network connection between an `aws_odb_network` and an application's own VPC, the resource that actually lets EC2 application servers reach Oracle Exadata or Autonomous databases running under Oracle Database@AWS.

## Input properties

<ResponseField name="additional_peer_network_cidrs" type="list(string)">
  The additional CIDR blocks for the ODB peering connection. Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  The name of the ODB peering connection. Optional.
</ResponseField>

<ResponseField name="odb_network_id" type="string">
  The unique identifier of the ODB network. Optional.
</ResponseField>

<ResponseField name="peer_network_id" type="string">
  The unique identifier of the peer network. Optional.
</ResponseField>

<ResponseField name="peer_network_route_table_ids" type="list(string)">
  The unique identifier of the VPC route table for which a route to the ODB network is automatically created during peering connection establishment. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the Odb peering connection. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="odb_network_arn" type="string">
  The Amazon Resource Name (ARN) of the ODB network. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="odb_peering_connection_arn" type="string">
  The Amazon Resource Name (ARN) of the ODB peering connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="odb_peering_connection_id" type="string">
  The unique identifier of the ODB peering connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="peer_network_arn" type="string">
  The Amazon Resource Name (ARN) of the peer network. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="peer_network_cidrs" type="list(string)">
  The CIDR blocks for the ODB peering connection. Computed by AWS after `ship`.
</ResponseField>

`aws_bcmdata_exports_export` defines a customized, recurring export from AWS's own cost and usage or cost-optimization-recommendation datasets, the real mechanism for getting billing data out of AWS Billing and Cost Management into a caller's own data warehouse or pipeline on a schedule.

## Input properties

<ResponseField name="tags" type="list(object)">
  Defines the customer-managed tags (key-value pairs) to associate with the BCM data export resource, allowing you to categorize, identify, and filter exports for billing and cost management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key (left side of a key-value pair) applied to the BCM data export, which can be used for cost allocation and resource filtering in AWS Cost Management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value assigned to a tag key on the BCM data export, allowing you to categorize and filter exports by custom metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

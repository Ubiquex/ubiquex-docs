`aws_chatbot_slack_channel_configuration` connects a Slack channel to AWS Chatbot, real SNS topics for notification delivery, an IAM role Chatbot assumes, and optional IAM policy guardrails restricting what commands can run from that channel.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chatbot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/chatbot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own slack channel configuration"})

    		ubx.Resource(chatbot.SlackChannelConfiguration, "example", chatbot.SlackChannelConfigurationConfig{
    			ConfigurationName:         "example-configuration-name",
    			IamRoleArn:                "arn:aws:iam::123456789012:policy/example",
    			SlackChannelId:            "example",
    			SlackWorkspaceId:          "example",
    			CustomizationResourceArns: []string{"example"},
    			GuardrailPolicies:         []string{"example"},
    			LoggingLevel:              "example",
    			SnsTopicArns:              []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="configuration_name" type="string" required>
  The name of the configuration Required.
</ResponseField>

<ResponseField name="customization_resource_arns" type="list(string)">
  ARNs of Custom Actions to associate with notifications in the provided chat channel. Optional.
</ResponseField>

<ResponseField name="guardrail_policies" type="list(string)">
  The list of IAM policy ARNs that are applied as channel guardrails. The AWS managed 'AdministratorAccess' policy is applied as a default if this is not set. Optional.
</ResponseField>

<ResponseField name="iam_role_arn" type="string" required>
  The ARN of the IAM role that defines the permissions for AWS Chatbot Required.
</ResponseField>

<ResponseField name="logging_level" type="string">
  Specifies the logging level for this configuration:ERROR,INFO or NONE. This property affects the log entries pushed to Amazon CloudWatch logs Optional.
</ResponseField>

<ResponseField name="slack_channel_id" type="string" required>
  The id of the Slack channel Required.
</ResponseField>

<ResponseField name="slack_workspace_id" type="string" required>
  The id of the Slack workspace Required.
</ResponseField>

<ResponseField name="sns_topic_arns" type="list(string)">
  ARNs of SNS topics which delivers notifications to AWS Chatbot, for example CloudWatch alarm notifications. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to add to the configuration Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to an AWS Chatbot Slack channel configuration, enabling cost allocation tracking and resource categorization within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag that can be attached to the AWS Chatbot Slack channel configuration for resource organization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_role_required" type="bool">
  Enables use of a user role requirement in your chat configuration Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Amazon Resource Name (ARN) of the configuration Computed by AWS after `ship`.
</ResponseField>

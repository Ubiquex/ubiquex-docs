`aws_chatbot_microsoft_teams_channel_configuration` connects a Microsoft Teams channel to AWS Chatbot, the Teams counterpart to `aws_chatbot_slack_channel_configuration`, with its own real team and tenant ID, SNS topics, IAM role, and guardrail policies.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chatbot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/chatbot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own microsoft teams channel configuration"})

    		ubx.Resource(chatbot.MicrosoftTeamsChannelConfiguration, "example", chatbot.MicrosoftTeamsChannelConfigurationConfig{
    			ConfigurationName:         "example-configuration-name",
    			IamRoleArn:                "arn:aws:iam::123456789012:policy/example",
    			TeamId:                    "example",
    			TeamsChannelId:            "example",
    			TeamsTenantId:             "example",
    			CustomizationResourceArns: []string{"example"},
    			GuardrailPolicies:         []string{"example"},
    			LoggingLevel:              "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="configuration_name" type="string" required>
  The name of the configuration Required.
</ResponseField>

<ResponseField name="customization_resource_arns" type="list(string)">
  ARNs of Custom Actions to associate with notifications in the provided chat channel. Optional.
</ResponseField>

<ResponseField name="guardrail_policies" type="list(string)">
  The list of IAM policy ARNs that are applied as channel guardrails. The AWS managed 'AdministratorAccess' policy is applied as a default if this is not set. Optional.
</ResponseField>

<ResponseField name="iam_role_arn" type="string" required>
  The ARN of the IAM role that defines the permissions for AWS Chatbot Required.
</ResponseField>

<ResponseField name="logging_level" type="string">
  Specifies the logging level for this configuration:ERROR,INFO or NONE. This property affects the log entries pushed to Amazon CloudWatch logs Optional.
</ResponseField>

<ResponseField name="sns_topic_arns" type="list(string)">
  ARNs of SNS topics which delivers notifications to AWS Chatbot, for example CloudWatch alarm notifications. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to add to the configuration Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key for a tag attached to an AWS Chatbot Microsoft Teams channel configuration, used for organizing, filtering, and cost-tracking the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The tag value for a key-value pair applied to the AWS Chatbot Microsoft Teams channel configuration resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="team_id" type="string" required>
  The id of the Microsoft Teams team Required.
</ResponseField>

<ResponseField name="teams_channel_id" type="string" required>
  The id of the Microsoft Teams channel Required.
</ResponseField>

<ResponseField name="teams_channel_name" type="string">
  The name of the Microsoft Teams channel Optional.
</ResponseField>

<ResponseField name="teams_tenant_id" type="string" required>
  The id of the Microsoft Teams tenant Required.
</ResponseField>

<ResponseField name="user_role_required" type="bool">
  Enables use of a user role requirement in your chat configuration Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Amazon Resource Name (ARN) of the configuration Computed by AWS after `ship`.
</ResponseField>

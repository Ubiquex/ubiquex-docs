`aws_health_lake_data_transformation_profile` defines the real, AI-assisted mapping rules HealthLake's Data Transformation Agent uses to convert legacy healthcare data, C-CDA documents or relational data, into FHIR R4 resources, created as a mutable draft and promoted to an immutable, published version once ready. Announced in preview in March 2026, genuinely new enough that this session verified it live rather than trusting a remembered description.

## Input properties

<ResponseField name="kms_key_id" type="string">
  The identifier (key ID or ARN) of a customer-managed KMS key used to encrypt the profile's template content at rest. If omitted, an AWS owned key is used. Optional.
</ResponseField>

<ResponseField name="profile_description" type="string">
  A human-readable description of the profile's purpose. Optional.
</ResponseField>

<ResponseField name="profile_name" type="string" required>
  The human-readable name of the profile. Required.
</ResponseField>

<ResponseField name="source" type="object">
  The source from which to create the profile's initial template content. Exactly one of the members must be specified. Use StarterProfile (C-CDA only), ProfileMapping (C-CDA or CSV), or ExistingVersionedProfileId to clone an existing profile. Each produces a published profile. Optional.
  <Expandable title="properties">
    <ResponseField name="existing_versioned_profile_id" type="object">
      Create the profile by cloning a specific version of an existing profile. Optional.
      <Expandable title="properties">
        <ResponseField name="profile_id" type="string" required>
          The unique identifier of the source profile to clone. Required.
        </ResponseField>
        <ResponseField name="version" type="number" required>
          The version number of the source profile to clone. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="profile_mapping" type="object">
      Create the profile from raw Velocity template mapping content. Optional.
      <Expandable title="properties">
        <ResponseField name="profile_mapping" type="any" required>
          Map of template file paths to their Velocity template content. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="starter_profile" type="object">
      Create the profile from a predefined starter profile of transformation templates. Optional.
      <Expandable title="properties">
        <ResponseField name="starter_profile_name" type="string" required>
          The name of the starter profile to seed the profile from. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="source_format" type="string" required>
  The source format that this profile converts from. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this profile. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS HealthLake data transformation profile, used to identify, organize, and manage the profile among AWS resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a key-value tag attached to the AWS HealthLake data transformation profile, used to assign arbitrary string metadata for resource identification, organization, and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the data transformation profile. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="profile_id" type="string">
  The unique, server-generated identifier of the profile (32-character lowercase hexadecimal). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="target_format" type="string">
  The target format that this profile converts to. Always FHIR_R4. Computed by AWS after `ship`.
</ResponseField>

`aws_panorama_package` defined a real container of the model, code, and assets that ran as an `aws_panorama_application_instance` on an AWS Panorama appliance. Like the rest of AWS Panorama, this is fully discontinued: closed to new customers May 20, 2025, with AWS ending support entirely on May 31, 2026, a date now in the past.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	panorama "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/panorama"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own package"})

    		ubx.Resource(panorama.Package, "example", panorama.PackageConfig{
    			PackageName: "example-package-name",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="package_name" type="string" required>
  The unique name of the Panorama package that identifies it within your AWS account and is used when creating or referencing the package in the AWS Panorama console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag objects (each with a Key and Value) to attach to the AWS Panorama package, enabling cost allocation, access control, and resource organization. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag to attach to the AWS Panorama package for resource identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag that can be attached to the Panorama package, used for metadata and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

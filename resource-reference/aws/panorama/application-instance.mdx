AWS Panorama is now fully discontinued: it closed to new customers on May 20, 2025, and AWS ended support entirely on May 31, 2026, a date now in the past, after which the console, its resources, and the Panorama Appliances customers purchased all stopped functioning. This resource describes a service no longer operable rather than a current one.

## Input properties

<ResponseField name="application_instance_id_to_replace" type="string">
  The unique ID of a previously deployed AWS Panorama application instance that this new instance should replace, enabling a replacement deployment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_runtime_context_device" type="string" required>
  The ID or ARN of the AWS Panorama device that this application instance is deployed to and runs on. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-specified description that provides a human-readable label for the application instance, typically used to identify it in the AWS Panorama console and APIs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="manifest_overrides_payload" type="object">
  Parameter overrides for an application instance. This is a JSON document that has a single key (``PayloadData``) where the value is an escaped string representation of the overrides document. Optional.
  <Expandable title="properties">
    <ResponseField name="payload_data" type="string">
      The JSON payload data that overrides the application manifest for this AWS Panorama application instance, enabling device-specific customization of the deployment. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="manifest_payload" type="object" required>
  A application verion's manifest file. This is a JSON document that has a single key (``PayloadData``) where the value is an escaped string representation of the application manifest (``graph.json``). This file is located in the ``graphs`` folder in your application source. Required.
  <Expandable title="properties">
    <ResponseField name="payload_data" type="string">
      The application manifest payload as a JSON-formatted string, which defines the AWS Panorama application's graph, pipelines, and runtime configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  A user-defined name for the application instance, used for identification in the AWS Panorama console and API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="runtime_role_arn" type="string">
  The ARN of the IAM role that the application instance assumes to access AWS services during runtime. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  List of tags Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag attached to the AWS Panorama application instance, allowing users to assign arbitrary metadata for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="application_instance_id" type="string">
  The unique identifier assigned by AWS to this Panorama application instance. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Panorama application instance. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_time" type="number">
  The Unix epoch timestamp in seconds indicating when the AWS Panorama application instance was created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_runtime_context_device_name" type="string">
  The name of the AWS Panorama device (appliance) that serves as the default runtime context for this application instance, returned as a computed read-only attribute by CloudFormation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="health_status" type="string">
  The health status of the application instance on its device, indicating whether the deployed application is operating normally (e.g., HEALTHY, UNHEALTHY, or NOT_AVAILABLE) and populated by AWS after the instance is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="last_updated_time" type="number">
  The Unix epoch timestamp indicating when the application instance was last updated, as reported by the AWS Panorama service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current deployment status of the application instance, indicating whether it is pending, in progress, succeeded, failed, or running on the AWS Panorama device. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status_description" type="string">
  Provides a human-readable description of the current status of the application instance, including error details when the instance is in a failed state. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

## Input properties

<ResponseField name="mark_latest" type="bool">
  Whether to mark the new version as the latest version. Optional.
</ResponseField>

<ResponseField name="owner_account" type="string">
  The AWS account ID that owns the package version, used to identify the package owner when registering a package version for a package shared from another account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="package_id" type="string" required>
  The ID of the AWS Panorama package to which this package version belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="package_version" type="string" required>
  The package version identifier for the AWS Panorama package, used to distinguish this release from other versions of the same package. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="patch_version" type="string" required>
  Specifies the patch version of the Panorama package, which combined with the package name and package version uniquely identifies a specific package version release in AWS Panorama. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="updated_latest_patch_version" type="string">
  Determines whether the package version is updated to the latest available patch version for the specified package, enabling automatic updates to the newest patch release. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="is_latest_patch" type="bool">
  Indicates whether this patch version is the latest available patch for the package version. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="package_arn" type="string">
  The Amazon Resource Name (ARN) of the Panorama package that this package version belongs to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="package_name" type="string">
  The name of the AWS Panorama package to which this package version belongs, uniquely identifying the package within the account. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="registered_time" type="number">
  The Unix epoch timestamp (in seconds) when this Panorama package version was registered by the service, as returned by AWS Panorama. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The service-assigned lifecycle status of the Panorama package version, indicating whether it is registered, active, deleting, or failed, and updated automatically as the package version transitions through its lifecycle. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status_description" type="string">
  The package version's status description, providing contextual details about the current state (such as progress or error information) of the AWS Panorama package version. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_braket_spending_limit` caps real, cumulative spend on Amazon Braket's on-demand and hybrid-job quantum processing unit tasks, validating every task creation request against the configured limit and rejecting it outright if its estimated cost would exceed what remains, with an optional time window scoping when submissions are even allowed.

## Input properties

<ResponseField name="device_arn" type="string" required>
  The Amazon Resource Name (ARN) of the quantum device to apply the spending limit to. Required.
</ResponseField>

<ResponseField name="spending_limit" type="string" required>
  The maximum amount that can be spent on the specified device, in USD. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to apply to the spending limit. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a tag key-value pair attached to the AWS::Braket::SpendingLimit resource, used to categorize and manage the spending limit with arbitrary metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="time_period" type="object">
  Defines a time range for spending limits, specifying when the limit is active. Optional.
  <Expandable title="properties">
    <ResponseField name="end_at" type="string" required>
      The end date and time for the spending limit period, in ISO 8601 format. Required.
    </ResponseField>
    <ResponseField name="start_at" type="string" required>
      The start date and time for the spending limit period, in ISO 8601 format. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time when the spending limit was created, in ISO 8601 format. Computed by AWS after `ship`.

<ResponseField name="queued_spend" type="string">

</ResponseField>

<ResponseField name="spending_limit_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the spending limit. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="total_spend" type="string">

</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time when the spending limit was last modified, in ISO 8601 format. Computed by AWS after `ship`.
</ResponseField>

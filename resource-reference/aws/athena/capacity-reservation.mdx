`aws_athena_capacity_reservation` reserves dedicated Data Processing Units for Athena queries at a fixed price, an alternative to Athena's standard pay-per-data-scanned model, with one or more `aws_athena_work_group`s assigned to the reservation so their queries run on guaranteed capacity instead of queuing behind other tenants.

## Input properties

<ResponseField name="capacity_assignment_configuration" type="object">
  Assignment configuration to assign workgroups to a reservation Optional.
  <Expandable title="properties">
    <ResponseField name="capacity_assignments" type="list(object)" required>
      List of capacity assignments Required.
      <Expandable title="properties">
        <ResponseField name="workgroup_names" type="list(string)">
          Specifies the list of Athena workgroup names assigned to this capacity reservation for query processing. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The reservation name. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of an arbitrary user-defined tag key assigned to an AWS Athena capacity reservation, allowing metadata-based management and categorization of the reservation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_dpus" type="number" required>
  The number of DPUs to request to be allocated to the reservation. Required.
</ResponseField>

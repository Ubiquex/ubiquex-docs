`aws_athena_data_catalog` registers a metadata catalog, the AWS Glue Data Catalog, a Hive metastore, or a federated Lambda-backed source, that Athena queries against to resolve which tables and schemas a SQL query can actually see.

## Properties

<ResponseField name="connection_type" type="string">
  The type of connection for a FEDERATED data catalog Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the data catalog to be created. Optional.
</ResponseField>

<ResponseField name="error" type="string">
  Text of the error that occurred during data catalog creation or deletion. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the data catalog to create. The catalog name must be unique for the AWS account and can use a maximum of 128 alphanumeric, underscore, at sign, or hyphen characters. Required.
</ResponseField>

<ResponseField name="parameters" type="any">
  Specifies the Lambda function or functions to use for creating the data catalog. This is a mapping whose values depend on the catalog type. Optional.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the creation or deletion of the data catalog. LAMBDA, GLUE, and HIVE data catalog types are created synchronously. Their status is either CREATE_COMPLETE or CREATE_FAILED. The FEDERATED data catalog type is created asynchronously. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the key-value tags to attach to the Athena data catalog for metadata management, cost allocation, and access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value string of a user-defined tag attached to the Athena data catalog, used for resource organization and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of data catalog to create: LAMBDA for a federated catalog, GLUE for AWS Glue Catalog, or HIVE for an external hive metastore. FEDERATED is a federated catalog for which Athena creates the connection and the Lambda function for you based on the parameters that you pass. Required.
</ResponseField>

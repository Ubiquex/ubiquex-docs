---

`aws_athena_work_group` isolates a set of Athena users, teams, or applications, with its own query history, data usage limits, and encryption settings, so cost and access can be tracked and controlled per workgroup rather than pooled across every Athena user in the account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own work group"})

    		ubx.Resource(athena.WorkGroup, "example", athena.WorkGroupConfig{
    			Name:                  "example",
    			Description:           "Managed by ubx.",
    			RecursiveDeleteOption: true,
    			State:                 "example",
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The workgroup description. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The workGroup name. Required.
</ResponseField>

<ResponseField name="recursive_delete_option" type="bool">
  The option to delete the workgroup and its contents even if the workgroup contains any named queries. Optional.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the workgroup: ENABLED or DISABLED. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags to attach to the Athena work group, which can be used for cost tracking, resource organization, and IAM-based access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Athena work group, used to categorize and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The user-defined value string paired with a tag key on the Athena work group, used for organizing, cost allocation, and tag-based access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

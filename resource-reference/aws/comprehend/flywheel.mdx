`aws_comprehend_flywheel` orchestrates the continuous retraining of a custom Comprehend classification or entity-recognition model, storing every version's training and test data in a real, managed data lake, so a caller can add new labeled data periodically, run an iteration that evaluates and trains a new model version, and promote it once its metrics improve on the active version.

## Input properties

<ResponseField name="active_model_arn" type="string">
  The Amazon Resource Name (ARN) of the model that is currently active for the flywheel, used for performing inference and can be updated to switch to a different trained model version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_access_role_arn" type="string" required>
  The ARN of the IAM role that allows Amazon Comprehend to access the data (e.g., S3 buckets) used for training and evaluating models in the flywheel. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_lake_s3_uri" type="string" required>
  The S3 URI of the data lake that the flywheel uses as its central repository for training data and documents during model training and continuous learning. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_security_config" type="object">
  Configures encryption and network isolation for the flywheel by specifying optional KMS key ARNs for the model, volume, and data lake, along with an optional VPC configuration for private VPC access. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_lake_kms_key_id" type="string">
      The AWS KMS key ID used to encrypt the data lake S3 bucket that stores flywheel training data and model artifacts. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="model_kms_key_id" type="string">
      Specifies the AWS KMS key ARN or ID used to encrypt the model artifacts (trained models) associated with the flywheel. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="volume_kms_key_id" type="string">
      The AWS KMS key ID used to encrypt the storage volume attached to the compute resources for the flywheel's training and evaluation jobs. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpc_config" type="object">
      Specifies the VPC configuration (subnets and security group IDs) for the flywheel, enabling it to access resources within a private network for secure data processing and storage. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="security_group_ids" type="list(string)" required>
          A list of security group IDs to associate with the VPC configuration for the AWS Comprehend Flywheel, controlling network access to the resources used by the flywheel. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="subnets" type="list(string)" required>
          The list of subnet IDs within the specified VPC where the Amazon Comprehend flywheel launches its resources to enable private, secure communication with other AWS services. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="flywheel_name" type="string" required>
  The unique name that identifies the Amazon Comprehend flywheel. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="model_type" type="string">
  Specifies the type of custom model the flywheel is configured for, either DOCUMENT_CLASSIFIER for document classification or ENTITY_RECOGNIZER for entity recognition. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags (key-value pairs) to assign to the flywheel for metadata and cost tracking, as supported by AWS Comprehend. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Amazon Comprehend flywheel, used to identify and organize the resource, optionally for cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="task_config" type="object">
  Specifies the configuration for the natural language processing task that the flywheel will support, including the language code and task-specific settings such as document classification or entity recognition configurations. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="document_classification_config" type="object">
      This object configures the document classification task of the flywheel, specifying the classification mode (MULTI_CLASS or MULTI_LABEL) and, for multi-label mode, the delimiter used to separate labels in the training data. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="labels" type="list(string)">
          Defines the list of labels (classes) that the flywheel's document classification task uses to categorize input documents, such as in a custom classifier. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="mode" type="string" required>
          Specifies the document classification mode, either MULTI_CLASS to assign exactly one class per document or MULTI_LABEL to assign one or more labels per document. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="entity_recognition_config" type="object">
      This object configures the entity recognition task for the flywheel, specifying the custom entity types that the model is trained to detect. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="entity_types" type="list(object)">
          For this flywheel's entity recognition task, defines the list of custom entity types (e.g., PRODUCT, PERSON) that the model will recognize or be trained to extract from text. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="type" type="string">
              Optional; if omitted, computed by AWS.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="language_code" type="string" required>
      The language code (e.g., 'en') that specifies the language of the input data for the flywheel's configured task, such as document classification or entity recognition. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the dedicated flywheel, automatically assigned by AWS when the flywheel is created and used to reference this flywheel in IAM policies, resource relationships, and Amazon Comprehend API operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

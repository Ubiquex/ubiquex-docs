`aws_comprehend_document_classifier` trains a real, custom model on caller-labeled documents, plain text, PDF, Word, or images, to categorize new documents into the caller's own classes, single-label or multi-label, run synchronously in real time or as a batch job against a whole document set.

## Input properties

<ResponseField name="data_access_role_arn" type="string" required>
  The ARN of the IAM role that Amazon Comprehend assumes to access the training documents in the S3 bucket specified as the input data source for the document classifier. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="document_classifier_name" type="string" required>
  The unique name of the document classifier, which identifies it within your AWS account and region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="input_data_config" type="object" required>
  Specifies the S3 location and format of the training data (documents and labels) used to train the document classifier, including the S3 URI, data format, and optional test data location. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="augmented_manifests" type="list(object)">
      Specifies the augmented manifest files from Amazon SageMaker Ground Truth that provide labeled training data for the document classifier. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="attribute_names" type="list(string)">
          Lists the attribute names (JSON keys) in each augmented manifest line that contain the document text and, optionally, the class label used as training data for the document classifier. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="s3_uri" type="string">
          Specifies the S3 URI of the augmented manifest file that contains the labeled documents used to train the document classifier. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="split" type="string">
          The split of the augmented manifest data set, which determines whether the documents are used for training or testing the document classifier. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="data_format" type="string">
      Specifies the format of the training data for the document classifier, either COMPREHEND_CSV (default) for a CSV file or AUGMENTED_MANIFEST for an augmented manifest file. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="document_reader_config" type="object">
      Specifies the Amazon Textract document reader settings (document read action, read mode, and feature types) used to extract text from input PDF or Word documents for the document classifier. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="document_read_action" type="string" required>
          Specifies the Amazon Textract document reading action to apply to input documents, either TEXTRACT_DETECT_DOCUMENT_TEXT for text extraction or TEXTRACT_ANALYZE_DOCUMENT for extraction including forms and tables. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="document_read_mode" type="string">
          Specifies whether the document reader uses the service default text extraction behavior (SERVICE_DEFAULT) or forces the Textract action defined in the document reader configuration (FORCE_DOCUMENT_READ_ACTION). Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="feature_types" type="list(string)">
          Specifies a list of feature types (such as TABLES or FORMS) that Amazon Textract should extract from input documents when the document reader processes them, allowing the document classifier to leverage those additional extracted elements. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="document_type" type="string">
      Specifies the format of the training data (either COMPREHEND_CSV or AUGMENTED_MANIFEST) for the document classifier. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="documents" type="object">
      Provides the S3 URIs for the training documents (and optionally test documents) used to train the document classifier. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="s3_uri" type="string" required>
          The S3 URI of the training documents (e.g., a CSV or augmented manifest file) used to train the Amazon Comprehend document classifier. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="test_s3_uri" type="string">
          The S3 URI of the test documents used to evaluate the trained document classifier model. Optional. **(AI-inferred)**

      </Expandable>

    <ResponseField name="label_delimiter" type="string">
      The single character that separates the label from the text in each line of the training data files for the document classifier (e.g., a pipe '|'). Optional. **(AI-inferred)**
    </ResponseField>

    </ResponseField>

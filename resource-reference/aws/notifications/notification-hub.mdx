`aws_notifications_notification_hub` designates a real AWS Region where AWS User Notifications stores, processes, and replicates an account's notification data, an account-level setting rather than a per-notification resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	notifications "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/notifications"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own notification hub"})

    		ubx.Resource(notifications.NotificationHub, "example", notifications.NotificationHubConfig{
    			Region: "example",
    		})
    	}))
    }
    ```
  </Tab>

  Region that NotificationHub is present in. Required.
</ResponseField>

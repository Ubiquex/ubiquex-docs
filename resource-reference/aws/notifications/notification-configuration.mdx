`aws_notifications_notification_configuration` creates a real, named notification configuration in AWS User Notifications, the top-level resource that `aws_notifications_event_rule`s attach to and that ties event matching to delivery channels and aggregation settings.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	notifications "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/notifications"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own notification configuration"})

    		ubx.Resource(notifications.NotificationConfiguration, "ci-runner", notifications.NotificationConfigurationConfig{
    			Description:         "Managed by ubx.",
    			Name:                "ci-runner",
    			AggregationDuration: "example",
    			Tags:                []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="aggregation_duration" type="string">
  Controls how long the notification configuration collects related events before delivering them as one aggregated notification, balancing timeliness against notification volume. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string" required>
  The Description property is a required string that provides a human-readable description of the notification configuration, enabling users to identify and distinguish configurations within AWS User Notifications. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The user-defined name for the notification configuration, used to identify and display the configuration in the AWS Management Console and APIs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags that are attached to the role. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key part of a tag applied to the notification configuration, used to label and categorize the AWS resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

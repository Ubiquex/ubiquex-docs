`aws_notifications_event_rule` defines a real EventBridge event pattern under an `aws_notifications_notification_configuration`, matching against AWS-service-sourced events so User Notifications generates a notification whenever a matching event occurs.

## Example

    			NotificationConfigurationArn: "arn:aws:iam::123456789012:policy/example",

    			Source:                       "example",
    			EventPattern:                 "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="event_pattern" type="string">
  Specifies a JSON string containing the event pattern that determines which events trigger this rule, such as matching AWS service, event type, or resource attributes. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="event_type" type="string" required>
  Specifies the event type from the source AWS service that this notification rule matches (for example, a named event such as an EC2 instance state-change notification). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="notification_configuration_arn" type="string" required>
  The ARN of the notification configuration to which this event rule belongs, determining the channel and settings used for delivering notifications from matched events. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="regions" type="list(string)" required>
  Specifies the AWS Regions in which the event rule is active and should apply. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="source" type="string" required>
  Specifies the AWS service or event source (such as aws.ec2) that the notification rule monitors for events, acting as the source of the triggering events. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this AWS Notifications event rule, used to reference the rule in IAM policies, cross-service resource sharing, and API operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="creation_time" type="string">
  The timestamp indicating when the event rule was created, formatted as an ISO 8601 date-time string. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="managed_rules" type="list(string)">
  The list of Amazon EventBridge managed rule ARNs that AWS automatically creates and manages for this notification event rule. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status_summary_by_region" type="any">
  This computed field provides a region-by-region summary of the event rule's status, indicating for each region whether the rule is active or has an error condition. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_notifications_channel_association` links a real delivery channel, an email address, chat channel, or mobile push endpoint, to an `aws_notifications_notification_configuration`, the resource that actually determines where a matching notification gets delivered.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	notifications "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/notifications"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own channel association"})

    		ubx.Resource(notifications.ChannelAssociation, "ci-runner", notifications.ChannelAssociationConfig{
    			Arn:                          "arn:aws:iam::123456789012:policy/ci",
    			NotificationConfigurationArn: "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="arn" type="string" required>
  ARN identifier of the channel. Example: arn:aws:chatbot::123456789012:chat-configuration/slack-channel/security-ops Required.
</ResponseField>

<ResponseField name="notification_configuration_arn" type="string" required>
  ARN identifier of the NotificationConfiguration. Example: arn:aws:notifications::123456789012:configuration/a01jes88qxwkbj05xv9c967pgm1 Required.
</ResponseField>

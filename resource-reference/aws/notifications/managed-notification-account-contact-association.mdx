`aws_notifications_managed_notification_account_contact_association` associates one of an account's built-in AWS contacts, primary, billing, operations, or security, with an AWS-managed notification configuration, so that contact automatically receives AWS's own pre-built notifications for a given category without a custom `aws_notifications_notification_configuration` being built by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	notifications "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/notifications"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own managed notification account contact association"})

    		ubx.Resource(notifications.ManagedNotificationAccountContactAssociation, "example", notifications.ManagedNotificationAccountContactAssociationConfig{
    			ContactIdentifier:                   "example",
    			ManagedNotificationConfigurationArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

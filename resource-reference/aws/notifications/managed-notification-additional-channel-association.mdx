`aws_notifications_managed_notification_additional_channel_association` adds a real, additional delivery channel beyond an account's default contacts to an AWS-managed notification configuration, extending who receives one of AWS's own pre-built notifications.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	notifications "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/notifications"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own managed notification additional channel association"})

    		ubx.Resource(notifications.ManagedNotificationAdditionalChannelAssociation, "ci-runner", notifications.ManagedNotificationAdditionalChannelAssociationConfig{
    			ChannelArn:                          "arn:aws:iam::123456789012:policy/ci",
    			ManagedNotificationConfigurationArn: "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="channel_arn" type="string" required>
  ARN identifier of the channel. Example: arn:aws:chatbot::123456789012:chat-configuration/slack-channel/security-ops Required.
</ResponseField>

<ResponseField name="managed_notification_configuration_arn" type="string" required>
  ARN identifier of the Managed Notification. Example: arn:aws:notifications::381491923782:managed-notification-configuration/category/AWS-Health/sub-category/Billing Required.
</ResponseField>

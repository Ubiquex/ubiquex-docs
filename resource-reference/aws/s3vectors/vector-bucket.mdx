`aws_s3_vectors_vector_bucket` creates a real S3 Vectors bucket, the top-level container that an `aws_s3_vectors_index` is created inside, scaling to up to 10,000 vector indexes per bucket at general availability.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3vectors "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/s3vectors"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vector bucket"})

    		ubx.Resource(s3vectors.VectorBucket, "example", s3vectors.VectorBucketConfig{
    			EncryptionConfiguration: map[string]any{"kms_key_arn": "example"},
    			Tags:                    []map[string]any{{"key": "example"}},
    			VectorBucketName:        "example-vector-bucket-name",
    		})
    	}))
    }
    ```
  </Tab>

    def describe():
        ubx.intent("example own vector bucket")

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="encryption_configuration" type="object">
  The encryption configuration for the vector bucket. Optional.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      AWS Key Management Service (KMS) customer managed key ID to use for the encryption configuration. This parameter is allowed if and only if sseType is set to aws:kms Optional.
    </ResponseField>
    <ResponseField name="sse_type" type="string">
      The server-side encryption type to use for the encryption configuration of the vector bucket. By default, if you don't specify, all new vectors in Amazon S3 vector buckets use server-side encryption with Amazon S3 managed keys (SSE-S3), specifically AES256. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  User tags (key-value pairs) to associate with the vector bucket. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vector_bucket_name" type="string">
  The name of the vector bucket. Optional.
</ResponseField>

## Output properties

<ResponseField name="creation_time" type="string">
  Date and time when the vector bucket was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vector_bucket_arn" type="string">
  The Amazon Resource Name (ARN) of the vector bucket. Computed by AWS after `ship`.
</ResponseField>

---
title: "aws_network_manager_core_network_prefix_list_association"
description: "`aws_network_manager_core_network_prefix_list_association` associates a real managed prefix list with an `aws_network_manager_core_network`..."
---

`aws_network_manager_core_network_prefix_list_association` associates a real managed prefix list with an `aws_network_manager_core_network`, letting Cloud WAN routing policies reference the prefix list's own set of CIDRs by name instead of listing them individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	networkmanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/networkmanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own manager core networkmanager prefix list association"})

    		ubx.Resource(networkmanager.CoreNetworkPrefixListAssociation, "example", networkmanager.CoreNetworkPrefixListAssociationConfig{
    			CoreNetworkId:   "example",
    			PrefixListAlias: "example",
    			PrefixListArn:   "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

`aws_network_manager_transit_gateway_peering` peers a real existing EC2 Transit Gateway with an `aws_network_manager_core_network`, letting workloads on a legacy Transit Gateway reach resources across Cloud WAN.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	networkmanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/networkmanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own transit gateway peering"})

    		ubx.Resource(networkmanager.TransitGatewayPeering, "example", networkmanager.TransitGatewayPeeringConfig{
    			CoreNetworkId:     "example",
    			TransitGatewayArn: "arn:aws:iam::123456789012:policy/example",
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="core_network_id" type="string" required>
  The Id of the core network that you want to peer a transit gateway to. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a user-defined tag applied to the transit gateway peering, used to categorize and identify the resource for cost tracking, access control, and organizational purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the AWS Network Manager transit gateway peering, used for metadata and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="transit_gateway_arn" type="string" required>
  The ARN (Amazon Resource Name) of the transit gateway that you will peer to a core network Required.
</ResponseField>

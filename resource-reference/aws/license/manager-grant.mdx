`aws_license_manager_grant` shares a real `aws_license_manager_license`'s entitlements with a specific AWS account, organizational unit, or organization, the mechanism a license owner uses to let another account consume a license it granted from AWS Marketplace or a direct seller integration.

<ResponseField name="allowed_operations" type="list(string)">

<ResponseField name="license_arn" type="string">

</ResponseField>

<ResponseField name="principals" type="list(string)">

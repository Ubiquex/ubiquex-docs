`aws_license_manager_license_asset_rule_set` defines a real named set of rules that govern how an `aws_license_manager_license`'s usage is tracked and enforced against the physical or virtual assets consuming it. This resource type has only thin official documentation, an API reference entry rather than a full guide, verified live this session rather than assumed from general knowledge.

`aws_smsvoice_resource_policy` attaches a real resource-based access policy to an `aws_smsvoice_phone_number` or pool, controlling which principals, including from other accounts, can send through it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	smsvoice "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/smsvoice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own resource policy"})

    		ubx.Resource(smsvoice.ResourcePolicy, "ci-runner", smsvoice.ResourcePolicyConfig{
    			PolicyDocument: "example",
    			ResourceArn:    "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="policy_document" type="any" required>
  The JSON formatted resource-based policy to attach. Required.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The Amazon Resource Name (ARN) of the AWS End User Messaging SMS and Voice resource to attach the resource-based policy to. Required.
</ResponseField>

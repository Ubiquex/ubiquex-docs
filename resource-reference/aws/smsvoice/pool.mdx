`aws_smsvoice_pool` groups real `aws_smsvoice_phone_number`s or sender IDs that share common settings, keywords, opt-out list, message type, so a send request can draw from the pool with automatic failover rather than being tied to one specific number.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			OriginationIdentities:     []string{"example"},
    			DeletionProtectionEnabled: true,
    			OptOutListName:            "example-opt-out-list-name",
    			OptionalKeywords:          []map[string]any{{"action": "example"}},
    			SelfManagedOptOutsEnabled: true,
    			SharedRoutesEnabled:       true,
    			Tags:                      []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="deletion_protection_enabled" type="bool">
  When set to true the pool can't be deleted. By default this is set to false. Optional.
</ResponseField>

<ResponseField name="mandatory_keywords" type="object" required>
  A keyword is a word that you can search for on a particular phone number or pool. It is also a specific word or phrase that an end user can send to your number to elicit a response, such as an informational message or a special offer. When your number receives a message that begins with a keyword, AWS End User Messaging SMS and Voice responds with a customizable message. Keywords "HELP" and "STOP" are mandatory keywords Required.

When your number receives a message that begins with a keyword, AWS End User Messaging SMS and Voice responds with a customizable message. Optional.

    <ResponseField name="message" type="string">

</ResponseField>

<ResponseField name="origination_identities" type="list(string)" required>
  The origination identity to use such as a PhoneNumberId, PhoneNumberArn, SenderId or SenderIdArn and it's IsoCountryCode. Required.
</ResponseField>

<ResponseField name="self_managed_opt_outs_enabled" type="bool">
  By default this is set to false. When an end recipient sends a message that begins with HELP or STOP to one of your dedicated numbers, AWS End User Messaging SMS and Voice automatically replies with a customizable message and adds the end recipient to the OptOutList. When set to true you're responsible for responding to HELP and STOP requests. You're also responsible for tracking and honoring opt-out requests. Optional.
</ResponseField>

<ResponseField name="shared_routes_enabled" type="bool">

  <Expandable title="properties">

`aws_smsvoice_sender_id` registers a real, alphanumeric sender ID, a recognizable brand name shown as the message sender instead of a phone number, for use in countries that support it, under an `aws_smsvoice_configuration_set`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	smsvoice "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/smsvoice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sender id"})

    		ubx.Resource(smsvoice.SenderId, "example", smsvoice.SenderIdConfig{
    			IsoCountryCode:            "example",
    			SenderId:                  "example",
    			DeletionProtectionEnabled: true,
    			Tags:                      []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="deletion_protection_enabled" type="bool">
  When set to true the sender ID can't be deleted. By default this is set to false. Optional.
</ResponseField>

<ResponseField name="iso_country_code" type="string" required>
  The two-character code, in ISO 3166-1 alpha-2 format, for the country or region. Required.
</ResponseField>

<ResponseField name="sender_id" type="string" required>
  The sender ID string to request. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) associated with the SenderId. Computed by AWS after `ship`.
</ResponseField>

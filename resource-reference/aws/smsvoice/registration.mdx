`aws_smsvoice_registration` submits a real regulatory registration, the paperwork and supporting documents required by a specific country or carrier, needed before an `aws_smsvoice_phone_number` of certain types can send production SMS traffic there.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	smsvoice "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/smsvoice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own registration"})

    		ubx.Resource(smsvoice.Registration, "example", smsvoice.RegistrationConfig{
    			RegistrationType: "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="registration_type" type="string" required>
  The type of registration form to create. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of tags (key and value pairs) to associate with the registration. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to an AWS SMS Voice registration, which you can use to store arbitrary metadata such as environments, cost centers, or owners for the registration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_timestamp" type="string">
  The time when the registration was created, in UNIX epoch time format. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="current_version_number" type="number">
  The current version number of the registration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="registration_arn" type="string">
  The Amazon Resource Name (ARN) for the registration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="registration_id" type="string">
  The unique identifier for the registration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="registration_status" type="string">
  The status of the registration. Computed by AWS after `ship`.
</ResponseField>

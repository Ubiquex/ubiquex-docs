`aws_smsvoice_registration` submits a real regulatory registration, the paperwork and supporting documents required by a specific country or carrier, needed before an `aws_smsvoice_phone_number` of certain types can send production SMS traffic there.

## Example

    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	smsvoice "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/smsvoice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own registration"})

    		ubx.Resource(smsvoice.Registration, "ci-runner", smsvoice.RegistrationConfig{
    			RegistrationType: "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="registration_type" type="string" required>
  The type of registration form to create. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of tags (key and value pairs) to associate with the registration. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to an AWS SMS Voice registration, which you can use to store arbitrary metadata such as environments, cost centers, or owners for the registration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

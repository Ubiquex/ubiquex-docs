`aws_smsvoice_configuration_set` defines a real set of event destinations and options applied to messages sent through AWS End User Messaging SMS and Voice (the rebranded successor to the original Pinpoint SMS/Voice v1 APIs), referenced when sending through an `aws_smsvoice_phone_number` or `aws_smsvoice_pool`.

## Input properties

</ResponseField>

<ResponseField name="default_sender_id" type="string">
  The default sender ID to set for the ConfigurationSet. Optional.
</ResponseField>

<ResponseField name="event_destinations" type="list(object)">
  An event destination is a location where you send message events. Optional.
  <Expandable title="properties">

      The CloudWatchLogsDestination object within an event destination of an AWS::SMSVoice::ConfigurationSet specifies the Amazon CloudWatch Logs destination for voice message events, including the IAM role ARN and log group ARN to which the events are delivered. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">

`aws_neptune_dbcluster` creates a real Neptune Database cluster, a managed, serverless-capable graph database engine supporting Gremlin, openCypher, and SPARQL, built for transactional graph workloads like fraud detection and social-network queries, distinct from the memory-optimized analytics engine behind `aws_neptune_graph_graph`.

## Input properties

<ResponseField name="associated_roles" type="list(object)">
  Provides a list of the AWS Identity and Access Management (IAM) roles that are associated with the DB cluster. IAM roles that are associated with a DB cluster grant permission for the DB cluster to access other AWS services on your behalf. Optional.
  <Expandable title="properties">
    <ResponseField name="feature_name" type="string">
      The name of the Neptune feature (for example, `FullTextSearch`) that the associated IAM role enables for the DB cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="role_arn" type="string">
      The ARN of an IAM role to associate with the Neptune DB cluster, granting the cluster permissions to access other AWS services such as S3 for data loading or SageMaker for machine learning. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="availability_zones" type="list(string)">
  Provides the list of EC2 Availability Zones that instances in the DB cluster can be created in. Optional.
</ResponseField>

<ResponseField name="backup_retention_period" type="number">
  Specifies the number of days for which automatic DB snapshots are retained. Optional.
</ResponseField>

<ResponseField name="copy_tags_to_snapshot" type="bool">
  A value that indicates whether to copy all tags from the DB cluster to snapshots of the DB cluster. The default behaviour is not to copy them. Optional.
</ResponseField>

<ResponseField name="dbcluster_identifier" type="string">
  The DB cluster identifier. Contains a user-supplied DB cluster identifier. This identifier is the unique key that identifies a DB cluster stored as a lowercase string. Optional.
</ResponseField>

<ResponseField name="dbcluster_parameter_group_name" type="string">
  Provides the name of the DB cluster parameter group. Optional.
</ResponseField>

<ResponseField name="dbinstance_parameter_group_name" type="string">
  The name of the DB parameter group to apply to all instances of the DB cluster. Used only in case of a major EngineVersion upgrade request. Optional.
</ResponseField>

<ResponseField name="dbport" type="number">
  The port number on which the DB instances in the DB cluster accept connections. If not specified, the default port used is `8182`. Note: `Port` property will soon be deprecated from this resource. Please update existing templates to rename it with new property `DBPort` having same functionalities. Optional.
</ResponseField>

<ResponseField name="dbsubnet_group_name" type="string">
  Specifies information on the subnet group associated with the DB cluster, including the name, description, and subnets in the subnet group. Optional.
</ResponseField>

<ResponseField name="deletion_protection" type="bool">
  Indicates whether or not the DB cluster has deletion protection enabled. The database can't be deleted when deletion protection is enabled. Optional.
</ResponseField>

<ResponseField name="enable_cloudwatch_logs_exports" type="list(string)">
  Specifies a list of log types that are enabled for export to CloudWatch Logs. Optional.
</ResponseField>

<ResponseField name="engine_version" type="string">
  Indicates the database engine version. Optional.
</ResponseField>

<ResponseField name="global_cluster_identifier" type="string">
  The ID of the Neptune global database to which this new DB cluster should be added. Optional.
</ResponseField>

<ResponseField name="iam_auth_enabled" type="bool">
  True if mapping of Amazon Identity and Access Management (IAM) accounts to database accounts is enabled, and otherwise false. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The Amazon Resource Name (ARN) of the AWS KMS key that is used to encrypt the database instances in the DB cluster, such as arn:aws:kms:us-east-1:012345678910:key/abcd1234-a123-456a-a12b-a123b4cd56ef. If you enable the StorageEncrypted property but don't specify this property, the default KMS key is used. If you specify this property, you must set the StorageEncrypted property to true. Optional.
</ResponseField>

<ResponseField name="network_type" type="string">
  The network type of the DB cluster. Optional.
</ResponseField>

<ResponseField name="preferred_backup_window" type="string">
  Specifies the daily time range during which automated backups are created if automated backups are enabled, as determined by the BackupRetentionPeriod. Optional.
</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">
  Specifies the weekly time range during which system maintenance can occur, in Universal Coordinated Time (UTC). Optional.
</ResponseField>

<ResponseField name="restore_to_time" type="string">
  Creates a new DB cluster from a DB snapshot or DB cluster snapshot. If a DB snapshot is specified, the target DB cluster is created from the source DB snapshot with a default configuration and default security group. If a DB cluster snapshot is specified, the target DB cluster is created from the source DB cluster restore point with the same configuration as the original source DB cluster, except that the new DB cluster is created with the default security group. Optional.
</ResponseField>

<ResponseField name="restore_type" type="string">
  Creates a new DB cluster from a DB snapshot or DB cluster snapshot. If a DB snapshot is specified, the target DB cluster is created from the source DB snapshot with a default configuration and default security group. If a DB cluster snapshot is specified, the target DB cluster is created from the source DB cluster restore point with the same configuration as the original source DB cluster, except that the new DB cluster is created with the default security group. Optional.
</ResponseField>

<ResponseField name="serverless_scaling_configuration" type="object">
  Contains the scaling configuration of an Neptune Serverless DB cluster. Optional.
  <Expandable title="properties">
    <ResponseField name="max_capacity" type="number" required>
      The maximum number of Neptune capacity units (NCUs) for a DB instance in an Neptune Serverless cluster. You can specify NCU values in half-step increments, such as 40, 40.5, 41, and so on. The smallest value you can use is 2.5, whereas the largest is 128. Required.
    </ResponseField>
    <ResponseField name="min_capacity" type="number" required>
      The minimum number of Neptune capacity units (NCUs) for a DB instance in an Neptune Serverless cluster. You can specify NCU values in half-step increments, such as 8, 8.5, 9, and so on. The smallest value you can use is 1, whereas the largest is 128. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="snapshot_identifier" type="string">
  Specifies the identifier for a DB cluster snapshot. Must match the identifier of an existing snapshot. After you restore a DB cluster using a SnapshotIdentifier, you must specify the same SnapshotIdentifier for any future updates to the DB cluster. When you specify this property for an update, the DB cluster is not restored from the snapshot again, and the data in the database is not changed. However, if you don't specify the SnapshotIdentifier, an empty DB cluster is created, and the original DB cluster is deleted. If you specify a property that is different from the previous snapshot restore property, the DB cluster is restored from the snapshot specified by the SnapshotIdentifier, and the original DB cluster is deleted. Optional.
</ResponseField>

<ResponseField name="source_dbcluster_identifier" type="string">
  Creates a new DB cluster from a DB snapshot or DB cluster snapshot. If a DB snapshot is specified, the target DB cluster is created from the source DB snapshot with a default configuration and default security group. If a DB cluster snapshot is specified, the target DB cluster is created from the source DB cluster restore point with the same configuration as the original source DB cluster, except that the new DB cluster is created with the default security group. Optional.
</ResponseField>

<ResponseField name="storage_encrypted" type="bool">
  Indicates whether the DB cluster is encrypted. If you specify the KmsKeyId property, then you must enable encryption and set this property to true. If you enable the StorageEncrypted property but don't specify KmsKeyId property, then the default KMS key is used. If you specify KmsKeyId property, then that KMS Key is used to encrypt the database instances in the DB cluster. If you specify the SourceDBClusterIdentifier property and don't specify this property or disable it. The value is inherited from the source DB cluster, and if the DB cluster is encrypted, the KmsKeyId property from the source cluster is used. If you specify the DBSnapshotIdentifier and don't specify this property or disable it. The value is inherited from the snapshot, and the specified KmsKeyId property from the snapshot is used. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags assigned to this cluster. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key for a tag assigned to the Neptune DB cluster, enabling custom categorization and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag applied to the Neptune DB cluster, used for resource identification and organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="use_latest_restorable_time" type="bool">
  Creates a new DB cluster from a DB snapshot or DB cluster snapshot. If a DB snapshot is specified, the target DB cluster is created from the source DB snapshot with a default configuration and default security group. If a DB cluster snapshot is specified, the target DB cluster is created from the source DB cluster restore point with the same configuration as the original source DB cluster, except that the new DB cluster is created with the default security group. Optional.
</ResponseField>

<ResponseField name="vpc_security_group_ids" type="list(string)">
  Provides a list of VPC security groups that the DB cluster belongs to. Optional.
</ResponseField>

## Output properties

  The resource id for the DB cluster. For example: `cluster-ABCD1234EFGH5678IJKL90MNOP`. The cluster ID uniquely identifies the cluster and is used in things like IAM authentication policies. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The connection endpoint for the DB cluster. For example: `mystack-mydbcluster-1apw1j4phylrk.cg034hpkmmjt.us-east-2.rds.amazonaws.com` Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="port" type="string">
  The port number on which the DB cluster accepts connections. For example: `8182`. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="read_endpoint" type="string">
  The reader endpoint for the DB cluster. For example: `mystack-mydbcluster-ro-1apw1j4phylrk.cg034hpkmmjt.us-east-2.rds.amazonaws.com` Computed by AWS after `ship`.
</ResponseField>

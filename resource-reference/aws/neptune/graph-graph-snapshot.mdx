`aws_neptune_graph_graph_snapshot` creates a real point-in-time snapshot of an `aws_neptune_graph_graph`, which can later be used to create a new graph with the same data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	neptune "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/neptune"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own graph graph snapshot"})

    		ubx.Resource(neptune.GraphGraphSnapshot, "example", neptune.GraphGraphSnapshotConfig{
    			GraphIdentifier: "example",
    			SnapshotName:    "example-snapshot-name",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="graph_identifier" type="string" required>
  The unique identifier of the Neptune Analytics graph to create the snapshot from. Required.
</ResponseField>

<ResponseField name="snapshot_name" type="string" required>
  The snapshot name. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag (a key-value pair) attached to the Neptune Graph snapshot, used for identifying, organizing, or managing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value string paired with a tag key in the tags list for the Neptune graph snapshot, used for resource organization and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the graph snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier of the graph snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="kms_key_identifier" type="string">
  The ID of the KMS key used to encrypt and decrypt the snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="snapshot_create_time" type="string">
  The time when the snapshot was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the graph snapshot. Computed by AWS after `ship`.
</ResponseField>

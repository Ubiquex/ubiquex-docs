`aws_neptune_dbcluster_parameter_group` defines a real set of cluster-level engine parameters that can be applied to an `aws_neptune_dbcluster` instead of hand-tuning the cluster individually.

## Properties

<ResponseField name="description" type="string" required>
  Provides the customer-specified description for this DB cluster parameter group. Required.
</ResponseField>

<ResponseField name="family" type="string" required>
  Must be neptune1 for engine versions prior to 1.2.0.0, or neptune1.2 for engine version 1.2.0.0 and higher. Required.
</ResponseField>

<ResponseField name="name" type="string">
  Provides the name of the DB cluster parameter group. Optional.
</ResponseField>

<ResponseField name="parameters" type="any" required>
  An array of parameters to be modified. A maximum of 20 parameters can be modified in a single request. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The list of tags for the cluster parameter group. Optional.
  <Expandable title="properties">

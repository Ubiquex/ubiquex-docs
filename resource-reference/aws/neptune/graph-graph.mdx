`aws_neptune_graph_graph` creates a real Neptune Analytics graph, a memory-optimized engine built for fast, large-scale graph analytics, data-science workloads, and generative-AI use cases like recommendations, rather than the transactional, always-on database role `aws_neptune_dbcluster` serves; data can be loaded into it from a Neptune Database graph or snapshot.

## Input properties

<ResponseField name="deletion_protection" type="bool">
  Value that indicates whether the Graph has deletion protection enabled. The graph can't be deleted when deletion protection is enabled. _Default_: If not specified, the default value is true. Optional.
</ResponseField>

<ResponseField name="graph_name" type="string">
  Contains a user-supplied name for the Graph. If you don't specify a name, we generate a unique Graph Name using a combination of Stack Name and a UUID comprising of 4 characters. _Important_: If you specify a name, you cannot perform updates that require replacement of this resource. You can perform updates that require no or some interruption. If you must replace the resource, specify a new name. Optional.
</ResponseField>

<ResponseField name="kms_key_identifier" type="string">
  The ARN of the KMS key used to encrypt data in the Neptune Analytics graph. If not specified, the graph is encrypted with an AWS managed key. Optional.
</ResponseField>

<ResponseField name="provisioned_memory" type="number" required>
  Memory for the Graph. Required.
</ResponseField>

<ResponseField name="public_connectivity" type="bool">
  Specifies whether the Graph can be reached over the internet. Access to all graphs requires IAM authentication. When the Graph is publicly reachable, its Domain Name System (DNS) endpoint resolves to the public IP address from the internet. When the Graph isn't publicly reachable, you need to create a PrivateGraphEndpoint in a given VPC to ensure the DNS name resolves to a private IP address that is reachable from the VPC. _Default_: If not specified, the default value is false. Optional.
</ResponseField>

<ResponseField name="replica_count" type="number">
  Specifies the number of replicas you want when finished. All replicas will be provisioned in different availability zones. Replica Count should always be less than or equal to 2. _Default_: If not specified, the default value is 1. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with this graph. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Neptune Analytics graph, used to identify the tag within the resource's tag set. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vector_search_configuration" type="object">
  The vector search configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="vector_search_dimension" type="number" required>
      The vector search dimension Required.
    </ResponseField>
  </Expandable>
</ResponseField>

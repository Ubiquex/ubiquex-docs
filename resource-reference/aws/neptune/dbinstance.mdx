## Input properties

<ResponseField name="allow_major_version_upgrade" type="bool">
  Indicates that major version upgrades are allowed. Changing this parameter doesn't result in an outage and the change is asynchronously applied as soon as possible. This parameter must be set to true when specifying a value for the EngineVersion parameter that is a different major version than the DB instance's current version. Optional.
</ResponseField>

<ResponseField name="auto_minor_version_upgrade" type="bool">
  Indicates that minor version patches are applied automatically. When updating this property, some interruptions may occur. Optional.
</ResponseField>

<ResponseField name="availability_zone" type="string">
  Specifies the name of the Availability Zone the DB instance is located in. Optional.
</ResponseField>

<ResponseField name="dbcluster_identifier" type="string">
  If the DB instance is a member of a DB cluster, contains the name of the DB cluster that the DB instance is a member of. Optional.
</ResponseField>

<ResponseField name="dbinstance_class" type="string" required>
  Contains the name of the compute and memory capacity class of the DB instance. If you update this property, some interruptions may occur. Required.
</ResponseField>

<ResponseField name="dbinstance_identifier" type="string">
  Contains a user-supplied database identifier. This identifier is the unique key that identifies a DB instance. Optional.
</ResponseField>

<ResponseField name="dbparameter_group_name" type="string">
  The name of an existing DB parameter group or a reference to an AWS::Neptune::DBParameterGroup resource created in the template. If any of the data members of the referenced parameter group are changed during an update, the DB instance might need to be restarted, which causes some interruption. If the parameter group contains static parameters, whether they were changed or not, an update triggers a reboot. Optional.
</ResponseField>

<ResponseField name="dbsnapshot_identifier" type="string">
  This parameter is not supported. `AWS::Neptune::DBInstance` does not support restoring from snapshots. `AWS::Neptune::DBCluster` does support restoring from snapshots. Optional.
</ResponseField>

<ResponseField name="dbsubnet_group_name" type="string">
  A DB subnet group to associate with the DB instance. If you update this value, the new subnet group must be a subnet group in a new virtual private cloud (VPC). Optional.
</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">
  Specifies the weekly time range during which system maintenance can occur, in Universal Coordinated Time (UTC). Optional.
</ResponseField>

<ResponseField name="publicly_accessible" type="bool">
  Indicates that public accessibility is enabled. This should be enabled in combination with IAM Auth enabled on the DBCluster Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An arbitrary set of tags (key-value pairs) for this DB instance. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of an arbitrary tag attached to the Neptune DB instance, used to identify the tag for resource organization, cost tracking, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Value of the tag key assigned to the Neptune DB instance, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="endpoint" type="string">
  The connection endpoint for the database. For example: `mystack-mydb-1apw1j4phylrk.cg034hpkmmjt.us-east-2.rds.amazonaws.com`. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="port" type="string">
  The port number on which the database accepts connections. For example: `8182`. Computed by AWS after `ship`.
</ResponseField>

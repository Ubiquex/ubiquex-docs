`aws_neptune_graph_private_graph_endpoint` creates a real, VPC-private endpoint for an `aws_neptune_graph_graph`, letting resources inside that VPC query the graph without traffic leaving AWS's own private network.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	neptune "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/neptune"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own graph private graph endpoint"})

    		ubx.Resource(neptune.GraphPrivateGraphEndpoint, "ci-runner", neptune.GraphPrivateGraphEndpointConfig{
    			GraphIdentifier:  "example",
    			VpcId:            "example",
    			SecurityGroupIds: []string{"example"},
    			SubnetIds:        []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="graph_identifier" type="string" required>
  The auto-generated Graph Id assigned by the service. Required.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  The security group Ids associated with the VPC where you want the private graph endpoint to be created, ie, the graph will be reachable from within the VPC. Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)">
  The subnet Ids associated with the VPC where you want the private graph endpoint to be created, ie, the graph will be reachable from within the VPC. Optional.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The VPC where you want the private graph endpoint to be created, ie, the graph will be reachable from within the VPC. Required.
</ResponseField>

## Output properties

<ResponseField name="private_graph_endpoint_identifier" type="string">
  PrivateGraphEndpoint resource identifier generated by concatenating the associated GraphIdentifier and VpcId with an underscore separator. For example, if GraphIdentifier is `g-12a3bcdef4` and VpcId is `vpc-0a12bc34567de8f90`, the generated PrivateGraphEndpointIdentifier will be `g-12a3bcdef4_vpc-0a12bc34567de8f90` Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_endpoint_id" type="string">
  VPC endpoint that provides a private connection between the Graph and specified VPC. Computed by AWS after `ship`.
</ResponseField>

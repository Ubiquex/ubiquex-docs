`aws_neptune_global_cluster` creates a real multi-Region Neptune deployment, coordinating a primary `aws_neptune_dbcluster` and up to five read-only secondary clusters in other Regions with fast replication and disaster-recovery failover.

  The cluster identifier of the global database cluster. Optional.
</ResponseField>

<ResponseField name="source_dbcluster_identifier" type="string">
  The Amazon Resource Name (ARN) of an existing Neptune DB cluster to use as the primary cluster of the new global database. Optional.
</ResponseField>

<ResponseField name="storage_encrypted" type="bool">
  Whether the global database cluster is storage encrypted. Optional.

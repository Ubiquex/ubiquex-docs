`aws_neptune_event_subscription` subscribes a real SNS topic to receive notifications about events, failovers, backups, configuration changes, occurring on an `aws_neptune_dbcluster` and its instances.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	neptune "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/neptune"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own event subscription"})

    		ubx.Resource(neptune.EventSubscription, "example", neptune.EventSubscriptionConfig{
    			SnsTopicArn:      "arn:aws:iam::123456789012:policy/example",
    			Enabled:          true,
    			EventCategories:  []string{"example"},
    			SourceIds:        []string{"example"},
    			SourceType:       "example",
    			SubscriptionName: "example-subscription-name",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="enabled" type="bool">
  A Boolean value; set to true to activate the subscription, set to false to create the subscription but not active it. Optional.
</ResponseField>

<ResponseField name="event_categories" type="list(string)">
  A list of event categories for a SourceType that you want to subscribe to. You can see a list of the categories for a given SourceType in the Events topic in the Amazon Neptune User Guide or by using the DescribeEventCategories action. Optional.
</ResponseField>

<ResponseField name="sns_topic_arn" type="string" required>
  The Amazon Resource Name (ARN) of the SNS topic created for event notification. The ARN is created by Amazon SNS when you create a topic and subscribe to it. Required.
</ResponseField>

<ResponseField name="source_ids" type="list(string)">
  The list of identifiers of the event sources for which events will be returned. If not specified, then all sources are included in the response. An identifier must begin with a letter and must contain only ASCII letters, digits, and hyphens; it cannot end with a hyphen or contain two consecutive hyphens. Optional.
</ResponseField>

<ResponseField name="source_type" type="string">
  The type of source that will be generating the events. For example, if you want to be notified of events generated by a DB instance, you would set this parameter to db-instance. if this value is not specified, all events are returned. Optional.
</ResponseField>

<ResponseField name="subscription_name" type="string">
  The name of the subscription. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Neptune event subscription, used to organize, categorize, and identify the subscription for cost allocation and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**

    <ResponseField name="value" type="string">
      The value of a tag attached to the Neptune event subscription, used for metadata such as environment, owner, or cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

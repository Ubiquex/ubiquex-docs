`aws_dev_ops_agent_private_connection` establishes a real private network path, rather than a public internet connection, between an `aws_dev_ops_agent_agent_space` and one of its associated services, for environments that require it to stay off the public internet.

## Example

    	ubx.Main(ubx.Stack("payments", func() {

    			Name:                    "ci-runner",

    		})
    	}))
    }

## Input properties

<ResponseField name="certificate" type="string">
  Certificate for the Private Connection. Optional.
</ResponseField>

<ResponseField name="connection_configuration" type="any" required>
  The connection configuration, either SelfManaged or ServiceManaged. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  Unique name for this Private Connection within the account. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Private Connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="certificate_expiry_time" type="string">
  The expiry time of the certificate associated with the Private Connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the Private Connection. Computed by AWS after `ship`.
</ResponseField>

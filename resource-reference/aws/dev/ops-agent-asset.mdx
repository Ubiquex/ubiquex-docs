`aws_dev_ops_agent_asset` attaches a real, supporting file or document, runbooks, architecture diagrams, to an `aws_dev_ops_agent_agent_space`, giving AWS DevOps Agent's own operator app additional real context to reason from. AWS DevOps Agent reached general availability in March 2026, roughly five months ago, so behavior here is verified live rather than assumed from general knowledge.

## Input properties

<ResponseField name="agent_space_id" type="string" required>
  The unique identifier of the parent Agent Space. The asset is created as a child of this agent space. Required.
</ResponseField>

<ResponseField name="asset_type" type="string" required>
  The type of asset. The Asset API treats this as an open string; call ListAssetTypes for the current authoritative set of supported types. As of launch, customer-creatable types include skill, agents_md, and attachment. Required.
</ResponseField>

<ResponseField name="files" type="list(object)">
  Inline file list. Mutually exclusive with Zip; enforced by the handler at Create/Update time. Write-only: not repopulated by Read. Optional.
  <Expandable title="properties">
    <ResponseField name="content_bytes" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="content_text" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="metadata" type="any">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="path" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="any">
  Asset metadata document. Required and optional keys depend on AssetType. Values may be strings, numbers, booleans, or lists of any of those - validated server-side; see the public Asset API docs for the per-type metadata schema. Optional.
</ResponseField>

<ResponseField name="zip" type="string">
  Base64-encoded zip bundle containing all files for the asset. Mutually exclusive with Files; enforced by the handler at Create/Update time. Write-only: not repopulated by Read. Server treats a zip as 'replace all files' (max 6 MiB). Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the asset. Nested under the parent Agent Space: arn:&lt;partition&gt;:aidevops:&lt;region&gt;:&lt;account-id&gt;:agentspace/&lt;agentspace-id&gt;/asset/&lt;asset-id&gt;. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="asset_id" type="string">
  The unique identifier of the asset (assigned by the service on Create). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when the asset was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp when the asset was last updated. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version" type="number">
  The current asset version. Server-managed; bumps on every successful Update (including no-op updates). This is the drift signal for change detection. Computed by AWS after `ship`.
</ResponseField>

`aws_dev_ops_guru_resource_collection` scopes which real AWS resources, identified by CloudFormation stack or by tag, DevOps Guru actually analyzes CloudWatch metrics and CloudTrail events for, so anomaly detection covers the resources that matter rather than every resource in the account indiscriminately.

## Input properties

<ResponseField name="resource_collection_filter" type="object" required>
  Information about a filter used to specify which AWS resources are analyzed for anomalous behavior by DevOps Guru. Required.
  <Expandable title="properties">
    <ResponseField name="cloud_formation" type="object">
      CloudFormation resource for DevOps Guru to monitor Optional.
      <Expandable title="properties">
        <ResponseField name="stack_names" type="list(string)">
          An array of CloudFormation stack names. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="tags" type="list(object)">
      Tagged resources for DevOps Guru to monitor Optional.
      <Expandable title="properties">
        <ResponseField name="app_boundary_key" type="string">
          The tag key (AppBoundaryKey) that DevOps Guru uses to define the application boundary for selecting which tagged AWS resources are included in the resource collection. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="tag_values" type="list(string)">
          Specifies the list of tag values for the tag key in the parent `tags` filter, used to match which AWS resources are included in the DevOps Guru resource collection. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_dev_ops_agent_service` defines a real, specific service integration configuration, such as a GitHub App installation or a Slack workspace connection, that an `aws_dev_ops_agent_association` then attaches to an `aws_dev_ops_agent_agent_space`.

## Input properties

<ResponseField name="exchange_url_private_connection_name" type="string">
  The name of the private connection to use for OAuth token exchange requests only. Cannot be specified when PrivateConnectionName is provided. Optional.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The ARN of the KMS key to use for encryption. Optional.
</ResponseField>

<ResponseField name="private_connection_name" type="string">
  The name of the private connection to use for VPC connectivity. Optional.
</ResponseField>

<ResponseField name="service_details" type="any">
  Service-specific configuration details - MCPServerSigV4 supports in-place updates; GitLab (TokenValue), MCPServer (ApiKey or BearerToken credential rotation), MCPServerNewRelic (ApiKey rotation), and MCPServerGrafana (BearerToken rotation) support in-place credential rotation; all other service types and fields require replacement when modified Optional.
</ResponseField>

<ResponseField name="service_type" type="string" required>
  The type of service being registered Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_url_private_connection_name" type="string">
  The name of the private connection to use for API calls (target URL) only. Cannot be specified when PrivateConnectionName is provided. Optional.
</ResponseField>

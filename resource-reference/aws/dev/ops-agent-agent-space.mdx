`aws_dev_ops_agent_agent_space` is a real, logical container defining the AWS account access, third-party integrations, and user permissions that AWS DevOps Agent, AWS's always-available operations teammate for incident response and reliability, is scoped to. AWS DevOps Agent launched in preview in December 2025 and became generally available in March 2026, genuinely new enough that its own resources are worth verifying live rather than assumed.

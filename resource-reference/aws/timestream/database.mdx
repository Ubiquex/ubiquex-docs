`aws_timestream_database` creates a real Timestream for LiveAnalytics database, the top-level container that `aws_timestream_table`s storing time-series data are organized under.

## Example

  <Tab title="Go">

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	timestream "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/timestream"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own database"})

    		ubx.Resource(timestream.Database, "example", timestream.DatabaseConfig{
    			DatabaseName: "example-database-name",
    			KmsKeyId:     "example",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="database_name" type="string">
  The name for the database. If you don't specify a name, AWS CloudFormation generates a unique physical ID and uses that ID for the database name. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The KMS key for the database. If the KMS key is not specified, the database will be encrypted with a Timestream managed KMS key located in your account. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Timestream database, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a tag applied to the Timestream database, which holds an arbitrary string for resource categorization and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Timestream database, which uniquely identifies it within AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

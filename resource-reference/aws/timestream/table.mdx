`aws_timestream_table` creates a real time-series table within an `aws_timestream_database`, with its own memory- and magnetic-store retention periods controlling how long recent versus historical data stays queryable.

## Example

## Input properties

<ResponseField name="database_name" type="string" required>
  The name for the database which the table to be created belongs to. Required.
</ResponseField>

<ResponseField name="magnetic_store_write_properties" type="object">
  The properties that determine whether magnetic store writes are enabled. Optional.
  <Expandable title="properties">
    <ResponseField name="enable_magnetic_store_writes" type="bool" required>
      Boolean flag indicating whether magnetic store writes are enabled. Required.
    </ResponseField>
    <ResponseField name="magnetic_store_rejected_data_location" type="object">
      Location to store information about records that were asynchronously rejected during magnetic store writes. Optional.
      <Expandable title="properties">
        <ResponseField name="s3_configuration" type="object">
          S3 configuration for location to store rejections from magnetic store writes Optional.
          <Expandable title="properties">
            <ResponseField name="bucket_name" type="string" required>
              The bucket name used to store the data. Required.
            </ResponseField>
            <ResponseField name="encryption_option" type="string" required>
              Either SSE_KMS or SSE_S3. Required.
            </ResponseField>
            <ResponseField name="kms_key_id" type="string">
              Must be provided if SSE_KMS is specified as the encryption option Optional.
            </ResponseField>
            <ResponseField name="object_key_prefix" type="string">
              String used to prefix all data in the bucket. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="retention_properties" type="object">
  The retention duration of the memory store and the magnetic store. Optional.
  <Expandable title="properties">
    <ResponseField name="magnetic_store_retention_period_in_days" type="string">
      The duration for which data must be stored in the magnetic store. Optional.
    </ResponseField>
    <ResponseField name="memory_store_retention_period_in_hours" type="string">
      The duration for which data must be stored in the memory store. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schema" type="object">
  A Schema specifies the expected data model of the table. Optional.
  <Expandable title="properties">
    <ResponseField name="composite_partition_key" type="list(object)">
      A list of partition keys defining the attributes used to partition the table data. The order of the list determines the partition hierarchy. The name and type of each partition key as well as the partition key order cannot be changed after the table is created. However, the enforcement level of each partition key can be changed. Optional.
      <Expandable title="properties">
        <ResponseField name="enforcement_in_record" type="string">
          Specifies whether this partition key must be present in every record, with allowed values 'REQUIRED' or 'OPTIONAL'. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          Specifies the name of the dimension attribute used as the composite partition key for an AWS Timestream table when the partition key type is DIMENSION. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the type of the composite partition key, either DIMENSION for a dimension column or MEASURE for the measure name, controlling how Timestream partitions the table's data. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="table_name" type="string">
  The name for the table. If you don't specify a name, AWS CloudFormation generates a unique physical ID and uses that ID for the table name. Optional.
</ResponseField>

`aws_timestream_influx_dbinstance` creates a real, fully managed InfluxDB instance under Amazon Timestream for InfluxDB, optionally with a synchronous standby in a second Availability Zone, running the open-source InfluxDB engine and API rather than Timestream's own native LiveAnalytics engine.

## Example

    ```go
    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own influx dbinstance"})

    		ubx.Resource(timestream.InfluxDbinstance, "example", timestream.InfluxDbinstanceConfig{
    			Name:                       "example",
    			AllocatedStorage:           1,
    			Bucket:                     "example",
    			DbInstanceType:             "example",
    			DbParameterGroupIdentifier: "example",
    			DbStorageType:              "example",
    			DeploymentType:             "example",
    			LogDeliveryConfiguration:   map[string]any{"s3_configuration": map[string]any{"bucket_name": "example-bucket-name", "enabled": true}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="allocated_storage" type="number">
  The allocated storage for the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="bucket" type="string">
  The bucket for the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="db_instance_type" type="string">
  The compute instance of the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="db_parameter_group_identifier" type="string">
  The name of an existing InfluxDB parameter group. Optional.
</ResponseField>

<ResponseField name="db_storage_type" type="string">
  The storage type of the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="deployment_type" type="string">
  Deployment type of the InfluxDB Instance. Optional.
</ResponseField>

<ResponseField name="log_delivery_configuration" type="object">
  Configuration for sending logs to customer account from the InfluxDB instance. Optional.
  <Expandable title="properties">
    <ResponseField name="s3_configuration" type="object" required>
      S3 configuration for sending logs to customer account from the InfluxDB instance. Required.
      <Expandable title="properties">
        <ResponseField name="bucket_name" type="string" required>
          The bucket name for logs to be sent from the InfluxDB instance Required.
        </ResponseField>
        <ResponseField name="enabled" type="bool" required>
          Specifies whether logging to customer specified bucket is enabled. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="maintenance_schedule" type="object">
  The maintenance schedule for the InfluxDB instance. Optional.
  <Expandable title="properties">
    <ResponseField name="preferred_maintenance_window" type="string" required>
      The preferred maintenance window in format ddd:HH:MM-ddd:HH:MM. Required.
    </ResponseField>
    <ResponseField name="timezone" type="string" required>
      The IANA timezone identifier for the maintenance schedule. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The unique name that is associated with the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="network_type" type="string">
  Network type of the InfluxDB Instance. Optional.
</ResponseField>

<ResponseField name="organization" type="string">
  The organization for the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="password" type="string">
  The password for the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="port" type="number">
  The port number on which InfluxDB accepts connections. Optional.
</ResponseField>

<ResponseField name="publicly_accessible" type="bool">
  Attach a public IP to the customer ENI. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An arbitrary set of tags (key-value pairs) for this DB instance. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key (name) for a metadata tag attached to the Timestream for InfluxDB database instance, used to identify, categorize, and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag attached to the Timestream for InfluxDB DB instance, used for cost allocation, resource categorization, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="username" type="string">
  The username for the InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="vpc_security_group_ids" type="list(string)">
  A list of Amazon EC2 VPC security groups to associate with this InfluxDB instance. Optional.
</ResponseField>

<ResponseField name="vpc_subnet_ids" type="list(string)">
  A list of EC2 subnet IDs for this InfluxDB instance. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that is associated with the InfluxDB instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="availability_zone" type="string">
  The Availability Zone (AZ) where the InfluxDB instance is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The connection endpoint for the InfluxDB instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The service generated unique identifier for InfluxDB instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="influx_auth_parameters_secret_arn" type="string">
  The Auth parameters secret Amazon Resource name (ARN) that is associated with the InfluxDB instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="next_maintenance_time" type="string">
  The timestamp of the next scheduled maintenance event. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="secondary_availability_zone" type="string">
  The Secondary Availability Zone (AZ) where the InfluxDB instance is created, if DeploymentType is set as WITH_MULTIAZ_STANDBY. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the InfluxDB Instance. Computed by AWS after `ship`.
</ResponseField>

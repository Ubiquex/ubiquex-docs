`aws_timestream_scheduled_query` runs a real, recurring SQL query against an `aws_timestream_database`'s tables on a schedule, writing its results, often pre-aggregated rollups, back into another `aws_timestream_table` automatically.

## Input properties

<ResponseField name="client_token" type="string">
  Using a ClientToken makes the call to CreateScheduledQuery idempotent, in other words, making the same request repeatedly will produce the same result. Making multiple identical CreateScheduledQuery requests has the same effect as making a single request. If CreateScheduledQuery is called without a ClientToken, the Query SDK generates a ClientToken on your behalf. After 8 hours, any request with the same ClientToken is treated as a new request. Optional.
</ResponseField>

<ResponseField name="error_report_configuration" type="object" required>
  Configuration for error reporting. Error reports will be generated when a problem is encountered when writing the query results. Required.
  <Expandable title="properties">
    <ResponseField name="s3_configuration" type="object" required>
      Details on S3 location for error reports that result from running a query. Required.
      <Expandable title="properties">
        <ResponseField name="bucket_name" type="string" required>
          Name of the S3 bucket under which error reports will be created. Required.
        </ResponseField>
        <ResponseField name="encryption_option" type="string">
          Encryption at rest options for the error reports. If no encryption option is specified, Timestream will choose SSE_S3 as default. Optional.
        </ResponseField>
        <ResponseField name="object_key_prefix" type="string">
          Prefix for error report keys. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The Amazon KMS key used to encrypt the scheduled query resource, at-rest. If the Amazon KMS key is not specified, the scheduled query resource will be encrypted with a Timestream owned Amazon KMS key. To specify a KMS key, use the key ID, key ARN, alias name, or alias ARN. When using an alias name, prefix the name with alias/. If ErrorReportConfiguration uses SSE_KMS as encryption type, the same KmsKeyId is used to encrypt the error report at rest. Optional.
</ResponseField>

<ResponseField name="notification_configuration" type="object" required>
  Notification configuration for the scheduled query. A notification is sent by Timestream when a query run finishes, when the state is updated or when you delete it. Required.
  <Expandable title="properties">
    <ResponseField name="sns_configuration" type="object" required>
      SNS configuration for notification upon scheduled query execution. Required.
      <Expandable title="properties">
        <ResponseField name="topic_arn" type="string" required>
          SNS topic ARN that the scheduled query status notifications will be sent to. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="query_string" type="string" required>
  The query string to run. Parameter names can be specified in the query string @ character followed by an identifier. The named Parameter @scheduled_runtime is reserved and can be used in the query to get the time at which the query is scheduled to run. The timestamp calculated according to the ScheduleConfiguration parameter, will be the value of @scheduled_runtime paramater for each query run. For example, consider an instance of a scheduled query executing on 2021-12-01 00:00:00. For this instance, the @scheduled_runtime parameter is initialized to the timestamp 2021-12-01 00:00:00 when invoking the query. Required.
</ResponseField>

<ResponseField name="schedule_configuration" type="object" required>
  Configuration for when the scheduled query is executed. Required.
  <Expandable title="properties">
    <ResponseField name="schedule_expression" type="string" required>
      An expression that denotes when to trigger the scheduled query run. This can be a cron expression or a rate expression. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scheduled_query_execution_role_arn" type="string" required>
  The ARN for the IAM role that Timestream will assume when running the scheduled query. Required.
</ResponseField>

<ResponseField name="scheduled_query_name" type="string">
  The name of the scheduled query. Scheduled query names must be unique within each Region. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to label the scheduled query. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key, which is the name of the tag assigned to the Timestream scheduled query. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value string associated with a tag key for the Timestream scheduled query, used for organizing and identifying the query resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

              </Expandable>

          Column from query result that should be used as the time column in destination table. Column type for this should be TIMESTAMP. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>

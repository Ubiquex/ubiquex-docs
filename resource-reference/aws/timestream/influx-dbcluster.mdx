`aws_timestream_influx_dbcluster` creates a real, multi-node Timestream for InfluxDB 3 cluster, distributing nodes automatically across multiple Availability Zones for high availability, distinct from a single `aws_timestream_influx_dbinstance`'s simpler primary/standby Multi-AZ deployment model.

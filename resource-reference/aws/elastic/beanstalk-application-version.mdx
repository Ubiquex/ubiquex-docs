`aws_elastic_beanstalk_application_version` is one real, specific, immutable build of an `aws_elastic_beanstalk_application`'s own code, stored in S3, that an `aws_elastic_beanstalk_environment` actually deploys.

## Example

<Tabs>
  <Tab title="Go">

    ```go
    package main

    import (
    	elastic "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/elastic"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own beanstalk application version"})

    		ubx.Resource(elastic.BeanstalkApplicationVersion, "example", elastic.BeanstalkApplicationVersionConfig{
    			ApplicationName: "example-application-name",
    			SourceBundle:    map[string]any{"s3_bucket": "example"},
    			Description:     "Managed by ubx.",
    		})
    	}))
    }
    ```

</ResponseField>

<ResponseField name="description" type="string">
  A description of this application version. Optional.
</ResponseField>

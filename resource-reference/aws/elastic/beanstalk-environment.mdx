`aws_elastic_beanstalk_environment` is the real, actual running deployment, provisioning and managing the underlying EC2 instances, load balancer, and Auto Scaling group on a caller's behalf, that an `aws_elastic_beanstalk_application_version` gets deployed into.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticbeanstalk "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elasticbeanstalk"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own beanstalk environment"})

    		ubx.Resource(elasticbeanstalk.Environment, "example", elasticbeanstalk.EnvironmentConfig{
    			ApplicationName:   "example-application-name",
    			Cnameprefix:       "example",
    			Description:       "Managed by ubx.",
    			EnvironmentName:   "example-environment-name",
    			OperationsRole:    "example",
    			OptionSettings:    []map[string]any{{"namespace": "example"}},
    			PlatformArn:       "arn:aws:iam::123456789012:policy/example",
    			SolutionStackName: "example-solution-stack-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_name" type="string" required>
  The name of the application that is associated with this environment. Required.
</ResponseField>

<ResponseField name="cnameprefix" type="string">
  If specified, the environment attempts to use this value as the prefix for the CNAME in your Elastic Beanstalk environment URL. If not specified, the CNAME is generated automatically by appending a random alphanumeric string to the environment name. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Your description for this environment. Optional.
</ResponseField>

<ResponseField name="environment_name" type="string">
  A unique name for the environment. Optional.
</ResponseField>

<ResponseField name="operations_role" type="string">
  The Amazon Resource Name (ARN) of an existing IAM role to be used as the environment's operations role. Optional.
</ResponseField>

<ResponseField name="option_settings" type="list(object)">
  Key-value pairs defining configuration options for this environment, such as the instance type. Optional.
  <Expandable title="properties">
    <ResponseField name="namespace" type="string">
      Specifies the AWS Elastic Beanstalk configuration namespace (e.g., 'aws:autoscaling:asg', 'aws:ec2:instances') that groups related option settings for the environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="option_name" type="string">
      The name of the Elastic Beanstalk configuration option (e.g., 'IamInstanceProfile' or 'InstanceType') that this option setting defines within the specified namespace. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_name" type="string">
      Specifies the name of a specific resource (such as an Amazon RDS DB instance or an Auto Scaling group) in the Elastic Beanstalk environment that this option setting applies to, used when the option namespace supports multiple resources of the same type. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the actual value to apply for the given Elastic Beanstalk configuration option, controlling environment settings such as instance type, load balancing, or health checks. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="platform_arn" type="string">
  The Amazon Resource Name (ARN) of the custom platform to use with the environment. Optional.
</ResponseField>

<ResponseField name="solution_stack_name" type="string">
  The name of an Elastic Beanstalk solution stack (platform version) to use with the environment. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags applied to resources in the environment. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag assigned to the Elastic Beanstalk environment, used to categorize and filter the resource for cost allocation, access control, and operational management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the Elastic Beanstalk environment, used to categorize and manage the environment as an AWS resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_name" type="string">
  The name of the Elastic Beanstalk configuration template to use with the environment. Optional.
</ResponseField>

<ResponseField name="tier" type="object">
  Specifies the environment tier (such as WebServer or Worker) including its name, type, and version, determining whether the Elastic Beanstalk environment runs a web server or a background worker. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of this environment tier. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of this environment tier. Optional.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of this environment tier. When you don't set a value to it, Elastic Beanstalk uses the latest compatible worker tier version. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="version_label" type="string">
  The name of the application version to deploy. Optional.
</ResponseField>

## Output properties

<ResponseField name="endpoint_url" type="string">
  The endpoint URL for the environment, which is the CNAME of the load balancer for load-balanced environments or the public DNS address for single-instance environments, used to access the running application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_elastic_load_balancing_v2_trust_store_revocation` loads a real certificate revocation list into an `aws_elastic_load_balancing_v2_trust_store`, so a client certificate that's been revoked is rejected during mutual TLS even if it still chains to a trusted CA.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticloadbalancingv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elasticloadbalancingv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own load balancing v2 trust store revocation"})

    		ubx.Resource(elasticloadbalancingv2.TrustStoreRevocation, "example", elasticloadbalancingv2.TrustStoreRevocationConfig{
    			RevocationContents: []map[string]any{{"revocation_type": "example"}},
    			TrustStoreArn:      "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="revocation_contents" type="list(object)">
  The attributes required to create a trust store revocation. Optional.
  <Expandable title="properties">
    <ResponseField name="revocation_type" type="string">
      Specifies the type of certificate revocation list (CRL) being added, with supported values like `CRL` and `CRL2` for the AWS Elastic Load Balancing v2 trust store revocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_bucket" type="string">
      The name of the S3 bucket that contains the certificate revocation list (CRL) file to be added to the trust store for this revocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_key" type="string">
      The S3 object key (file path) of the revocation list file in the S3 bucket, used by the trust store revocation to load the certificate revocation data. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_object_version" type="string">
      The version ID of the S3 object containing the revocation list to be added to the trust store. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="trust_store_arn" type="string">
  The Amazon Resource Name (ARN) of the trust store. Optional.
</ResponseField>

## Output properties

<ResponseField name="revocation_id" type="number">
  The ID associated with the revocation. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="trust_store_revocations" type="list(object)">
  The data associated with a trust store revocation Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="number_of_revoked_entries" type="number">
      The number of revoked certificate authority (CA) certificates contained in the trust store revocation, as reported by the AWS Elastic Load Balancing v2 API. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="revocation_id" type="string">
      The unique identifier assigned by AWS to each certificate revocation entry within the trust store's revocation list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="revocation_type" type="string">
      Specifies the revocation type for the trust store revocation, either CRL (certificate revocation list) or CERTIFICATE_AUTHORITY (indicating the content is a CA certificate to be revoked). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="trust_store_arn" type="string">
      The Amazon Resource Name (ARN) of the trust store to which this revocation applies, identifying the target trust store for the revocation operation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

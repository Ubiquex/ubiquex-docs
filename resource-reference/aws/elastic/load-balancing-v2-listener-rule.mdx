`aws_elastic_load_balancing_v2_listener_rule` routes a real, matching request, by path, host header, or other condition, on an `aws_elastic_load_balancing_v2_listener` to a specific `aws_elastic_load_balancing_v2_target_group`, letting one listener serve several different backend services.

`aws_elastic_load_balancing_v2_trust_store` is a real repository of CA certificates an `aws_elastic_load_balancing_v2_listener` validates client certificates against for mutual TLS, the ALB-side equivalent of a CloudFront trust store.

## Input properties

<ResponseField name="ca_certificates_bundle_s3_bucket" type="string">
  The name of the S3 bucket to fetch the CA certificate bundle from. Optional.
</ResponseField>

<ResponseField name="ca_certificates_bundle_s3_key" type="string">
  The name of the S3 object to fetch the CA certificate bundle from. Optional.
</ResponseField>

<ResponseField name="ca_certificates_bundle_s3_object_version" type="string">
  The version of the S3 bucket that contains the CA certificate bundle. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the trust store. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the trust store. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag key-value pair attached to the trust store, enabling you to categorize and filter this trust store for operational and cost management within your Elastic Load Balancing v2 configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="number_of_ca_certificates" type="number">
  The number of certificates associated with the trust store. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the trust store, could be either of ACTIVE or CREATING. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="trust_store_arn" type="string">
  The Amazon Resource Name (ARN) of the trust store. Computed by AWS after `ship`.
</ResponseField>

`aws_quick_sight_folder` creates a real folder that organizes `aws_quick_sight_data_set`s, dashboards, analyses, and other QuickSight/Amazon Quick assets, and that permissions can be applied to in bulk rather than per asset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	quick "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/quick"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own sight folder"})

    		ubx.Resource(quick.SightFolder, "ci-runner", quick.SightFolderConfig{
    			Name:            "ci-runner",
    			AwsAccountId:    "example",
    			FolderId:        "example",
    			FolderType:      "example",
    			ParentFolderArn: "arn:aws:iam::123456789012:policy/ci",
    			Permissions:     []map[string]any{{"actions": []string{"example"}}},
    			SharingModel:    "example",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="aws_account_id" type="string">
  The AWS account ID that owns the QuickSight folder; if omitted, the account ID from the AWS credentials is used. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="folder_id" type="string">
  Specifies the unique identifier (FolderId) for the QuickSight folder, which AWS uses to reference the folder in API calls and as a component of the folder's ARN. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="folder_type" type="string">
  Specifies the type of QuickSight folder, with 'SHARED' being the only supported value, determining that the folder can be shared with other QuickSight users. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the QuickSight folder, which defaults to the folder's ID if not provided. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parent_folder_arn" type="string">
  The ARN of the parent QuickSight folder under which this folder is created, enabling nested folder hierarchies; if omitted, the folder is created at the root level. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="permissions" type="list(object)">
  Specifies a list of resource permissions for the folder, each granting an IAM principal a set of actions such as quicksight:DescribeFolder or quicksight:UpdateFolder. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="actions" type="list(string)">
      Specifies the list of QuickSight actions (e.g., 'quickSight:DescribeFolder', 'quickSight:UpdateFolder') that this permission entry grants to the specified principal on the folder. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="principal" type="string">
      The ARN of the QuickSight user or group to which the folder permissions are granted. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sharing_model" type="string">
  Determines the sharing scope of the folder, either across the entire AWS account (ACCOUNT) or only within a specific namespace (NAMESPACE), controlling which users can access it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag key-value pairs to associate with the QuickSight folder, used for managing and organizing resources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

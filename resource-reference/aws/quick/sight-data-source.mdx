`aws_quick_sight_data_source` defines a real connection to an external system, a database, S3, or a SaaS application, that one or more `aws_quick_sight_data_set`s pull data from.

## Input properties

<ResponseField name="alternate_data_source_parameters" type="list(object)">
  &lt;p&gt;A set of alternate data source parameters that you want to share for the credentials stored with this data source. The credentials are applied in tandem with the data source parameters when you copy a data source by using a create or update request. The API operation compares the &lt;code&gt;DataSourceParameters&lt;/code&gt; structure that's in the request with the structures in the &lt;code&gt;AlternateDataSourceParameters&lt;/code&gt; allow list. If the structures are an exact match, the request is allowed to use the credentials from this existing data source. If the &lt;code&gt;AlternateDataSourceParameters&lt;/code&gt; list is null, the &lt;code&gt;Credentials&lt;/code&gt; originally used with this &lt;code&gt;DataSourceParameters&lt;/code&gt; are automatically allowed.&lt;/p&gt; Optional.

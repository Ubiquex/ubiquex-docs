`aws_quick_sight_oauth_client_application` registers a real OAuth client that an `aws_quick_sight_action_connector` uses to authenticate to the external system it connects to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sight oauth client application"})

    		ubx.Resource(quicksight.OauthClientApplication, "example", quicksight.OauthClientApplicationConfig{
    			Name:                                    "example",
    			OauthClientApplicationId:                "example",
    			OauthClientAuthenticationType:           "example",
    			OauthTokenEndpointUrl:                   "example",
    			ClientId:                                "example",
    			ClientSecret:                            "example",
    			DataSourceType:                          "example",
    			IdentityProviderVpcConnectionProperties: map[string]any{"vpc_connection_arn": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="client_id" type="string">
  The OAuth client ID that identifies the third-party client application being registered with Amazon QuickSight for embedded analytics. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_secret" type="string">
  The client secret associated with the OAuth client application, used by QuickSight to authenticate the application when requesting access tokens from the OAuth authorization server. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_source_type" type="string">
  Specifies the type of the external data source (for example, Salesforce) for which this QuickSight OAuth client application provides authentication. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_provider_vpc_connection_properties" type="object">
  This object specifies the VPC connection properties that allow Amazon QuickSight to reach the identity provider's OAuth endpoints over a private network. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="vpc_connection_arn" type="string" required>
      The ARN of the VPC connection used by the identity provider for the OAuth client application, enabling the app to reach the identity provider over a private network. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the OAuth client application, which is required to identify the external application when registering it with QuickSight. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="oauth_authorization_endpoint_url" type="string">
  The URL of the OAuth authorization endpoint to which users are redirected to authenticate for the QuickSight OAuth client application. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="oauth_client_application_id" type="string" required>
  The identifier of the OAuth client application being registered with Amazon QuickSight. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="oauth_client_authentication_type" type="string" required>
  Specifies the authentication method used by the OAuth client application, with allowed values such as CLIENT_SECRET or JWT_BEARER, which determines how the client authenticates to QuickSight during token exchange. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="oauth_scopes" type="string">
  The OAuth scopes that define the permissions granted to the QuickSight OAuth client application, specifying which QuickSight API actions it can perform on the user's behalf. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="oauth_token_endpoint_url" type="string" required>
  The URL of the OAuth token endpoint where the QuickSight OAuth client application exchanges authorization codes or refreshes tokens to obtain access tokens. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  This property defines a list of tag objects (each containing a Key and Value) to attach to the Amazon QuickSight OAuth client application, used for resource management, cost allocation, and metadata. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that can be assigned to this AWS QuickSight OAuth client application for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the registered OAuth client application, which uniquely identifies it for use in IAM policies and QuickSight APIs. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_time" type="string">
  The creation timestamp of the QuickSight OAuth client application, returned as a string in ISO 8601 date-time format. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="last_updated_time" type="string">
  The timestamp of the last update to this QuickSight OAuth client application, returned as a read-only string. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

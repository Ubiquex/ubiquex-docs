`aws_quick_sight_refresh_schedule` schedules real, recurring refreshes of an `aws_quick_sight_data_set`'s underlying data, on a daily, weekly, monthly, or custom cadence.

## Input properties

<ResponseField name="aws_account_id" type="string">
  The AWS account ID that contains the dataset(s) associated with this refresh schedule; if not specified, the provider's default account is used. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_set_id" type="string">
  The unique identifier of the QuickSight dataset that this refresh schedule is associated with and will refresh. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="schedule" type="object">
  The schedule object configures when and how the QuickSight dataset is refreshed, specifying the refresh type (full or incremental), the frequency interval (hourly, daily, weekly, monthly), and the time-of-day and timezone for the refresh. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="refresh_type" type="string">
      Specifies whether the scheduled refresh is a FULL_REFRESH or an INCREMENTAL_REFRESH of the QuickSight dataset. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="schedule_frequency" type="object">
      &lt;p&gt;Information about the schedule frequency.&lt;/p&gt; Optional.
      <Expandable title="properties">
        <ResponseField name="interval" type="string">
          The interval of the QuickSight refresh schedule frequency, which must be one of 'DAILY', 'WEEKLY', or 'MONTHLY', and determines how often the dataset is refreshed. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="refresh_on_day" type="object">
          &lt;p&gt;The day scheduled for refresh.&lt;/p&gt; Optional.
          <Expandable title="properties">
            <ResponseField name="day_of_month" type="string">
              &lt;p&gt;The Day Of Month for scheduled refresh.&lt;/p&gt; Optional.
            </ResponseField>
            <ResponseField name="day_of_week" type="string">
              Specifies the day of the week (for example, SUNDAY) on which the QuickSight dataset refresh runs when the schedule frequency is set to WEEKLY. Optional. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="time_of_the_day" type="string">
          &lt;p&gt;The time of the day for scheduled refresh.&lt;/p&gt; Optional.
        </ResponseField>
        <ResponseField name="time_zone" type="string">
          &lt;p&gt;The timezone for scheduled refresh.&lt;/p&gt; Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="schedule_id" type="string">
      &lt;p&gt;An unique identifier for the refresh schedule.&lt;/p&gt; Optional.
    </ResponseField>
    <ResponseField name="start_after_date_time" type="string">
      &lt;p&gt;The date time after which refresh is to be scheduled&lt;/p&gt; Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

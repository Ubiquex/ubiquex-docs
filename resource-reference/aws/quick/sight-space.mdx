`aws_quick_sight_space` creates a real Quick Space, a collaborative workspace within Amazon Quick where files, chat, and knowledge bases are shared among a defined group of users, part of the AI-workspace capabilities QuickSight evolved into.

## Example

    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	quick "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/quick"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own sight space"})

    			AwsAccountId: "example",
    			Name:         "ci-runner",
    			SpaceId:      "example",
    			Description:  "Managed by ubx.",
    			Permissions:  []map[string]any{{"actions": []string{"example"}}},
    			Resources:    []map[string]any{{"resource_arn": "example"}},
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="aws_account_id" type="string" required>
  The ID of the Amazon Web Services account where the space is being created. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the space. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The display name of the space. Required.
</ResponseField>

<ResponseField name="permissions" type="list(object)">
  A list of permissions granted on the space. Optional.
  <Expandable title="properties">
    <ResponseField name="actions" type="list(string)">
      The list of QuickSight actions, such as quicksight:DescribeSpace, that the principal in the containing permission entry is allowed to perform on this QuickSight space. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="principal" type="string">
      Specifies the ARN of the IAM user, group, or role that is granted the permissions defined in this entry for the QuickSight space. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resources" type="list(object)">
  A list of QuickSight resources attached to the space. Optional.
  <Expandable title="properties">
    <ResponseField name="resource_arn" type="string">
      The ARN of a QuickSight asset (such as a dashboard, analysis, or dataset) that is associated with and managed within this QuickSight space. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_type" type="string">
      The type of QuickSight asset (e.g., DATASET or DASHBOARD) that is included in this space, indicating which resource the entry refers to. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="space_id" type="string" required>
  The unique identifier for the space. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to associate with the space resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a key-value tag attached to the QuickSight space, used for cost allocation, access control, and resource identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the space. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The date and time the space was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_by" type="string">
  The user name of the principal who created the space. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time the space was last updated. Computed by AWS after `ship`.
</ResponseField>

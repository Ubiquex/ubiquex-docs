`aws_ground_station_mission_profile` combines one or more `aws_ground_station_config`s into a real, reusable, complete contact plan, antenna, tracking, and dataflow settings together, that a caller schedules an actual satellite contact against.

## Input properties

<ResponseField name="contact_post_pass_duration_seconds" type="number">
  Post-pass time needed after the contact. Optional.
</ResponseField>

<ResponseField name="contact_pre_pass_duration_seconds" type="number">
  Pre-pass time needed before the contact. Optional.
</ResponseField>

<ResponseField name="dataflow_edges" type="list(object)" required>
  Specifies the list of dataflow edges that define how data moves between satellite and ground station endpoints, with each edge containing source and destination configuration references. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="destination" type="string">
      The destination is the ARN or ID of the Ground Station config that receives data from the source in this dataflow edge, defining the next step in the mission profile's dataflow path. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source" type="string">
      Specifies the source config for a dataflow edge in the mission profile, identifying where the data stream originates before flowing to the destination config. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="minimum_viable_contact_duration_seconds" type="number" required>
  Visibilities with shorter duration than the specified minimum viable contact duration will be ignored when searching for available contacts. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name used to identify a mission profile. Required.
</ResponseField>

<ResponseField name="streams_kms_key" type="object">
  The AWS KMS key (specified as an ARN or alias) used to encrypt data streams produced by this mission profile, enabling customer-controlled encryption of downlinked satellite data. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="kms_alias_arn" type="string">
      The alias ARN of the AWS KMS key used to encrypt the mission profile's data streams, as an alternative to specifying the KMS key ARN directly. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="kms_alias_name" type="string">
      Specifies the alias name of the AWS KMS key used to encrypt the data streams (uplink and downlink) associated with this Ground Station mission profile. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="kms_key_arn" type="string">
      The Amazon Resource Name (ARN) of the AWS KMS key used to encrypt the satellite data streams processed by the mission profile. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="streams_kms_role" type="string">
  The ARN of the KMS Key or Alias Key role used to define permissions on KMS Key usage. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Assigns a list of tag objects (key-value pairs) to the AWS Ground Station mission profile, which can be used for cost allocation and resource management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key (name) of a tag attached to the AWS Ground Station mission profile, used for resource identification and organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Ground Station mission profile, used for identifying and organizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="telemetry_sink_config_arn" type="string">
  ARN of a Config resource of type TelemetrySinkConfig used for telemetry data sink configuration. Optional.
</ResponseField>

<ResponseField name="tracking_config_arn" type="string" required>
  ARN of the tracking config resource that defines how the ground station antenna tracks the satellite during the mission profile. Required. **(AI-inferred)**
</ResponseField>

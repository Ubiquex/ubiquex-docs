`aws_ground_station_dataflow_endpoint_group_v2` is the newer resource type for the same real concept as `aws_ground_station_dataflow_endpoint_group`, restricted specifically to AWS Ground Station Agent-based endpoints rather than the original's broader mix of endpoint types, endpoints within one group must all be the same type either way.

</ResponseField>

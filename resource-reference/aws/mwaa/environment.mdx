`aws_mwaa_environment` creates a real, provisioned Amazon Managed Workflows for Apache Airflow environment, its own Airflow web server, scheduler, and workers running continuously, for orchestrating DAGs stored in S3.

## Example

    ```go
    	mwaa "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/mwaa"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment"})

    		ubx.Resource(mwaa.Environment, "example", mwaa.EnvironmentConfig{
    			Name:                        "example",
    			AirflowConfigurationOptions: "example",
    			AirflowVersion:              "example",
    			DagS3Path:                   "example",
    			EndpointManagement:          "example",
    			EnvironmentClass:            "example",
    			ExecutionRoleArn:            "arn:aws:iam::123456789012:policy/example",
    			KmsKey:                      "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="airflow_configuration_options" type="any">
  Key/value pairs representing Airflow configuration variables. Keys are prefixed by their section: [core] dags_folder=&#123;AIRFLOW_HOME&#125;/dags Would be represented as "core.dags_folder": "&#123;AIRFLOW_HOME&#125;/dags" Optional.
</ResponseField>

<ResponseField name="airflow_version" type="string">
  Version of airflow to deploy to the environment. Optional.
</ResponseField>

<ResponseField name="dag_s3_path" type="string">
  Represents an S3 prefix relative to the root of an S3 bucket. Optional.
</ResponseField>

<ResponseField name="endpoint_management" type="string">
  Defines whether the VPC endpoints configured for the environment are created, and managed, by the customer or by Amazon MWAA. Optional.
</ResponseField>

<ResponseField name="environment_class" type="string">
  Templated configuration for airflow processes and backing infrastructure. Optional.
</ResponseField>

<ResponseField name="execution_role_arn" type="string">
  IAM role to be used by tasks. Optional.
</ResponseField>

<ResponseField name="kms_key" type="string">
  The identifier of the AWS Key Management Service (AWS KMS) customer master key (CMK) to use for MWAA data encryption. You can specify the CMK using any of the following: Key ID. For example, key/1234abcd-12ab-34cd-56ef-1234567890ab. Key alias. For example, alias/ExampleAlias. Key ARN. For example, arn:aws:kms:us-east-1:012345678910:key/abcd1234-a123-456a-a12b-a123b4cd56ef. Alias ARN. For example, arn:aws:kms:us-east-1:012345678910:alias/ExampleAlias. AWS authenticates the CMK asynchronously. Therefore, if you specify an ID, alias, or ARN that is not valid, the action can appear to complete, but eventually fails. Optional.
</ResponseField>

<ResponseField name="max_webservers" type="number">
  Maximum webserver compute units. Optional.
</ResponseField>

<ResponseField name="max_workers" type="number">
  Maximum worker compute units. Optional.
</ResponseField>

<ResponseField name="min_webservers" type="number">
  Minimum webserver compute units. Optional.
</ResponseField>

<ResponseField name="min_workers" type="number">
  Minimum worker compute units. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Customer-defined identifier for the environment, unique per customer region. Required.
</ResponseField>

<ResponseField name="network_configuration" type="object">
  Configures the network resources of the environment. Optional.
  <Expandable title="properties">
    <ResponseField name="security_group_ids" type="list(string)">
      A list of security groups to use for the environment. Optional.
    </ResponseField>
    <ResponseField name="subnet_ids" type="list(string)">
      A list of subnets to use for the environment. These must be private subnets, in the same VPC, in two different availability zones. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="plugins_s3_object_version" type="string">
  Represents an version ID for an S3 object. Optional.
</ResponseField>

<ResponseField name="plugins_s3_path" type="string">
  Represents an S3 prefix relative to the root of an S3 bucket. Optional.
</ResponseField>

<ResponseField name="requirements_s3_object_version" type="string">
  Represents an version ID for an S3 object. Optional.
</ResponseField>

<ResponseField name="requirements_s3_path" type="string">
  Represents an S3 prefix relative to the root of an S3 bucket. Optional.
</ResponseField>

<ResponseField name="schedulers" type="number">
  Scheduler compute units. Optional.
</ResponseField>

<ResponseField name="source_bucket_arn" type="string">
  ARN for the AWS S3 bucket to use as the source of DAGs and plugins for the environment. Optional.
</ResponseField>

<ResponseField name="startup_script_s3_object_version" type="string">
  Represents an version ID for an S3 object. Optional.
</ResponseField>

<ResponseField name="startup_script_s3_path" type="string">
  Represents an S3 prefix relative to the root of an S3 bucket. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  A map of tags for the environment. Optional.
</ResponseField>

<ResponseField name="webserver_access_mode" type="string">
  Choice for mode of webserver access including over public internet or via private VPC endpoint. Optional.
</ResponseField>

<ResponseField name="weekly_maintenance_window_start" type="string">
  Start time for the weekly maintenance window. Optional.
</ResponseField>

<ResponseField name="worker_replacement_strategy" type="string">
  The worker replacement strategy to use when updating the environment. Valid values: `FORCED`, `GRACEFUL`. FORCED means Apache Airflow workers will be stopped and replaced without waiting for tasks to complete before an update. GRACEFUL means Apache Airflow workers will be able to complete running tasks for up to 12 hours during an update before being stopped and replaced. Optional.
</ResponseField>

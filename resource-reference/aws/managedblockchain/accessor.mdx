`aws_managed_blockchain_accessor` creates a real token-based access credential for Amazon Managed Blockchain's Ethereum node JSON-RPC APIs, an alternative to signing every request with SigV4 that instead authenticates with a bearer token.

## Example

<Tabs>

    ```go
    package main

    import (
    	managedblockchain "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/managedblockchain"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own blockchain accessor"})

    		ubx.Resource(managedblockchain.Accessor, "example", managedblockchain.AccessorConfig{
    			AccessorType: "example",
    			NetworkType:  "example",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accessor_type" type="string" required>
  Specifies the accessor type (BILLING_TOKEN, ETHEREUM_GOERLI, or ETHEREUM_MAINNET), which determines whether the accessor is a billing token or grants access to a specific Ethereum network. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_type" type="string">
  Specifies the Ethereum network type that the Managed Blockchain accessor connects to, such as ETHEREUM_MAINNET for the public mainnet or ETHEREUM_TESTNET for a public test network. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Managed Blockchain Accessor, used to organize, identify, and manage accessor resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

</ResponseField>

<ResponseField name="creation_date" type="string">

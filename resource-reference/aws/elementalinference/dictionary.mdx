`aws_elemental_inference_dictionary` defines a real, custom vocabulary, team names, product names, brand names, that an `aws_elemental_inference_feed` applies to improve accuracy when its AI-generated live subtitles encounter domain-specific terms a general model wouldn't recognize correctly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elementalinference "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elementalinference"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dictionary"})

    		ubx.Resource(elementalinference.Dictionary, "example", elementalinference.DictionaryConfig{
    			Language: "example",
    			Name:     "example",
    			Entries:  "example",
    			Tags:     "example",
    		})
    	}))
    }
    ```
  </Tab>

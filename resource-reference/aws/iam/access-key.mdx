`aws_iam_access_key` issues a real, long-lived programmatic credential, an access key ID and secret, for an `aws_iam_user`, the actual credential used for CLI and SDK calls made as that user rather than through a browser session.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own access key"})

    		ubx.Resource(iam.AccessKey, "example", iam.AccessKeyConfig{
    			UserName: "example-user-name",
    			Serial:   1,
    			Status:   "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="serial" type="number">
  The serial number for the access key, which must be unique among all access keys belonging to the same IAM user; it allows CloudFormation to create and manage multiple access keys for that user. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  Specifies the status of the IAM access key, either Active or Inactive, controlling whether the key can be used for programmatic calls. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_name" type="string" required>
  The name of the IAM user to which this access key belongs. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The AWS access key ID (e.g., AKIA...) that uniquely identifies the IAM access key. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="secret_access_key" type="string">
  The secret access key that is paired with the access key ID and is returned only when the IAM access key is first created, after which it cannot be retrieved again. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

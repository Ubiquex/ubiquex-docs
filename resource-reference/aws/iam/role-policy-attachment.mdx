---
title: "aws_iam_role_policy_attachment"
description: "Attach a managed policy to a role."
---

`aws_iam_role_policy_attachment` is the actual grant, it attaches an
existing, standalone policy to an existing role. Neither the role nor
the policy alone grants anything, this attachment is what connects
them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import iam "github.com/ubiquex/ubx-sdk-aws-go/aws/iam"

    cfg := iam.RolePolicyAttachmentConfig{
        Role:      role.Field("name"),
        PolicyArn: policy.Field("arn"),
    }
    ubx.Resource(iam.RolePolicyAttachment, "attach", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { RolePolicyAttachment } from
      "jsr:@ubx/sdk-aws/aws/iam/role_policy_attachment";

    resource(RolePolicyAttachment, "attach", {
      role: role.name,
      policyArn: policy.arn,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.aws.iam import (
        RolePolicyAttachment,
        RolePolicyAttachmentConfig,
    )

    cfg = RolePolicyAttachmentConfig(
        role=role.name,
        policy_arn=policy.arn,
    )
    ubx.resource(RolePolicyAttachment, "attach", cfg)
    ```
  </Tab>
  <Tab title="Diagram">

  </Tab>
</Tabs>

## Input properties

<ResponseField name="role" type="string" required>
  The name of the role to attach the policy to.
</ResponseField>

<ResponseField name="policy_arn" type="string" required>
  The ARN of the policy to attach.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  A computed identifier combining the role name and policy ARN.
</ResponseField>

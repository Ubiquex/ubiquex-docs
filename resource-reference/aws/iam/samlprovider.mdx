`aws_iam_samlprovider` establishes real trust between IAM and an external SAML 2.0 identity provider, a corporate Active Directory Federation Services setup, for instance, so a workforce user can federate into an `aws_iam_role` using their existing enterprise credentials rather than a separate IAM identity.

## Input properties

<ResponseField name="add_private_key" type="string">
  The private key from your external identity provider Optional.
</ResponseField>

<ResponseField name="assertion_encryption_mode" type="string">
  The encryption setting for the SAML provider Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the SAML provider, which serves as the unique identifier in IAM and is appended to the provider ARN; if omitted, CloudFormation derives it from the resource's logical ID. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_key_list" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key_id" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="timestamp" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="remove_private_key" type="string">
  The Key ID of the private key to remove Optional.
</ResponseField>

<ResponseField name="saml_metadata_document" type="string">
  The SAML 2.0 metadata document (XML) that contains the identity provider's entity ID, signing certificate, and other configuration needed for IAM to trust the external SAML identity provider. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that can be attached to the SAML provider to help identify, categorize, and manage the provider, and can be used in IAM policies for attribute-based access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the IAM SAML provider, which can be used in IAM policies via the aws:ResourceTag condition key to enforce tag-based access control on the provider. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag attached to the AWS IAM SAML provider, allowing you to label or categorize the provider for organizational and management purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

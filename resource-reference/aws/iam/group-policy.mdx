`aws_iam_group_policy` attaches a real inline IAM policy directly to an `aws_iam_group`, embedded in the group itself rather than existing as a separate, reusable `aws_iam_policy` that could also be attached elsewhere.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own group policy"})

    		ubx.Resource(iam.GroupPolicy, "example", iam.GroupPolicyConfig{
    			GroupName:      "example-group-name",
    			PolicyName:     "example-policy-name",
    			PolicyDocument: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="group_name" type="string" required>
  The name of the group to associate the policy with. This parameter allows (through its [regex pattern](https://docs.aws.amazon.com/http://wikipedia.org/wiki/regex)) a string of characters consisting of upper and lowercase alphanumeric characters with no spaces. You can also include any of the following characters: _+=,.@-. Required.
</ResponseField>

<ResponseField name="policy_document" type="any">
  The policy document. You must provide policies in JSON format in IAM. However, for CFN templates formatted in YAML, you can provide the policy in JSON or YAML format. CFN always converts a YAML policy to JSON format before submitting it to IAM. The [regex pattern](https://docs.aws.amazon.com/http://wikipedia.org/wiki/regex) used to validate this parameter is a string of characters consisting of the following: + Any printable ASCII character ranging from the space character (``\u0020``) through the end of the ASCII character range + The printable characters in the Basic Latin and Latin-1 Supplement character set (through ``\u00FF``) + The special characters tab (``\u0009``), line feed (``\u000A``), and carriage return (``\u000D``) Optional.
</ResponseField>

<ResponseField name="policy_name" type="string" required>
  The name of the policy document. This parameter allows (through its [regex pattern](https://docs.aws.amazon.com/http://wikipedia.org/wiki/regex)) a string of characters consisting of upper and lowercase alphanumeric characters with no spaces. You can also include any of the following characters: _+=,.@- Required.
</ResponseField>

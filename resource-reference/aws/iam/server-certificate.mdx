`aws_iam_server_certificate` uploads a real X.509 certificate and private key to IAM for use with a Classic Load Balancer or CloudFront, IAM's original, legacy certificate storage from before AWS Certificate Manager existed to handle this instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own server certificate"})

    		ubx.Resource(iam.ServerCertificate, "example", iam.ServerCertificateConfig{
    			CertificateBody:       "example",
    			CertificateChain:      "example",
    			Path:                  "/example/",
    			PrivateKey:            "example",
    			ServerCertificateName: "example-server-certificate-name",
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate_body" type="string">
  The PEM-encoded certificate body (the public key certificate) for the IAM server certificate, used to enable TLS/SSL connections for AWS services. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_chain" type="string">
  Specifies the PEM-encoded certificate chain of intermediate certificates that must be included when the server certificate is presented to clients, establishing trust back to a root CA. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="path" type="string">
  Specifies the IAM path under which the server certificate is stored, used to organize and identify the certificate within the AWS account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_key" type="string">
  The PEM-encoded private key that pairs with the uploaded server certificate, allowing AWS services such as Elastic Load Balancing to terminate SSL/TLS traffic. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_certificate_name" type="string">
  Specifies the name of the server certificate, which must be unique within the AWS account; if omitted, AWS CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of tag key-value pairs to attach to the IAM server certificate for identification, organization, and cost allocation. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the IAM server certificate, used to identify and categorize the certificate. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key attached to the IAM server certificate, used to store custom metadata that helps identify, organize, or manage the certificate within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

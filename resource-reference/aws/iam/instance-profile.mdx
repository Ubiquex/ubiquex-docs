`aws_iam_instance_profile` wraps an `aws_iam_role` in the real container EC2 actually requires to attach that role's permissions to a running instance, an instance can't assume a role directly without one.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own instance profile"})

    		ubx.Resource(iam.InstanceProfile, "ci-runner", iam.InstanceProfileConfig{
    			Roles:               []string{"example"},
    			InstanceProfileName: "example-instance-profile-name",
    			Path:                "/ci/",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="instance_profile_name" type="string">
  The name of the instance profile to create. This parameter allows (through its [regex pattern](https://docs.aws.amazon.com/http://wikipedia.org/wiki/regex)) a string of characters consisting of upper and lowercase alphanumeric characters with no spaces. You can also include any of the following characters: _+=,.@- Optional.
</ResponseField>

<ResponseField name="path" type="string">
  The path to the instance profile. For more information about paths, see [IAM Identifiers](https://docs.aws.amazon.com/IAM/latest/UserGuide/Using_Identifiers.html) in the *IAM User Guide*. This parameter is optional. If it is not included, it defaults to a slash (/). This parameter allows (through its [regex pattern](https://docs.aws.amazon.com/http://wikipedia.org/wiki/regex)) a string of characters consisting of either a forward slash (/) by itself or a string that must begin and end with forward slashes. In addition, it can contain any ASCII character from the ! (``\u0021``) through the DEL character (``\u007F``), including most punctuation characters, digits, and upper and lowercased letters. Optional.
</ResponseField>

<ResponseField name="roles" type="list(string)" required>
  The name of the role to associate with the instance profile. Only one role can be assigned to an EC2 instance at a time, and all applications on the instance share the same role and permissions. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the IAM instance profile, which uniquely identifies the profile across AWS and is used when attaching the profile to an EC2 instance or referencing it in IAM policies. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

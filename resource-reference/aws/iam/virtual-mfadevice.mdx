`aws_iam_virtual_mfadevice` registers a real, software-based MFA device, an authenticator app rather than a physical hardware token, that gets assigned to an `aws_iam_user` or the account root user to require a second factor at sign-in.

## Input properties

<ResponseField name="path" type="string">
  The IAM path under which the virtual MFA device is stored, which controls the device's location in the IAM hierarchy and must follow IAM path syntax (e.g., '/division/') to organize and identify the device. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Adds metadata tags to the virtual MFA device, which can be used to organize and identify the device in IAM. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key for a virtual MFA device in IAM, which identifies a tag applied to the device for organizational or access-control purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the IAM virtual MFA device, used as an arbitrary metadata label for organizing, identifying, or managing the device. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="users" type="list(string)" required>
  Specifies the list of IAM users that are associated with this virtual MFA device. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="virtual_mfa_device_name" type="string">
  Assigns a name to the virtual MFA device, which is used to identify the device within AWS IAM. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="serial_number" type="string">
  The ARN (Amazon Resource Name) of the virtual MFA device, which serves as its unique serial number. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

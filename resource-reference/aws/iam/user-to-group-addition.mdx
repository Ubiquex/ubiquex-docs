---
title: "aws_iam_user_to_group_addition"
description: "`aws_iam_user_to_group_addition` is the real, actual membership grant adding an `aws_iam_user` to an `aws_iam_group`."
---

Neither existing alone makes a user a group member, this addition is what connects them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user to group addition"})

    		ubx.Resource(iam.UserToGroupAddition, "example", iam.UserToGroupAdditionConfig{
    			GroupName: "example-group-name",
    			Users:     []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="group_name" type="string" required>
  The name of the IAM group that the user is added to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="users" type="list(string)" required>
  Specifies the list of existing IAM user names to add to the group specified in the GroupName property. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">

`aws_transcribe_vocabulary_filter` defines a real list of words that Amazon Transcribe should mask, remove, or flag whenever they appear in a transcription's output, used for profanity filtering or redacting sensitive terms.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	transcribe "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/transcribe"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vocabulary filter"})

    		ubx.Resource(transcribe.VocabularyFilter, "example", transcribe.VocabularyFilterConfig{
    			LanguageCode:            "example",
    			VocabularyFilterName:    "example-vocabulary-filter-name",
    			DataAccessRoleArn:       "arn:aws:iam::123456789012:policy/example",
    			Tags:                    []map[string]any{{"key": "example"}},
    			VocabularyFilterFileUri: "example",
    			Words:                   []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="data_access_role_arn" type="string">
  The Amazon Resource Name (ARN) of an IAM role that has permissions to access the Amazon S3 bucket that contains your input files. Optional.
</ResponseField>

<ResponseField name="language_code" type="string" required>
  The language code that represents the language of the entries in your vocabulary filter. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags associated with the vocabulary filter. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key name for a tag assigned to this Amazon Transcribe vocabulary filter, allowing you to categorize and manage the resource by purpose, owner, or environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag attached to the Amazon Transcribe vocabulary filter for organizing and managing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vocabulary_filter_file_uri" type="string">
  The Amazon S3 location of the text file that contains your custom vocabulary filter terms. Optional.
</ResponseField>

<ResponseField name="vocabulary_filter_name" type="string" required>
  A unique name, chosen by you, for your custom vocabulary filter. Required.
</ResponseField>

<ResponseField name="words" type="list(string)">
  Use this parameter if you want to create your custom vocabulary filter by including all desired terms, as comma-separated values, within your request. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the vocabulary filter. Computed by AWS after `ship`.
</ResponseField>

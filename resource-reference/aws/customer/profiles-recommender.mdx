`aws_customer_profiles_recommender` generates real, personalized recommendations from an `aws_customer_profiles_domain`'s own unified profile data, surfaced back through the Customer Profiles API rather than a caller building a separate recommendation pipeline against the same data.

## Example

## Input properties

        </ResponseField>
      </Expandable>

  </Expandable>

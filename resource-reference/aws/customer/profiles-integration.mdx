`aws_customer_profiles_integration` connects an `aws_customer_profiles_domain` to a real external system, Salesforce, ServiceNow, an ERP, through a pre-built AppFlow connector, so third-party customer data merges automatically into Connect's own contact history rather than being manually imported.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

`aws_customer_profiles_calculated_attribute_definition` turns raw, real customer profile data into an actionable, derived metric, lifetime spend, days since last contact, inside an `aws_customer_profiles_domain`, used by segments and other Customer Profiles features rather than every consumer recomputing it independently.

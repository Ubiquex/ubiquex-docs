`aws_customer_profiles_domain` is where Amazon Connect Customer Profiles' real, unified customer data actually lives, the top-level container every `aws_customer_profiles_object_type`, integration, and profile inside one Customer Profiles deployment belongs to.

## Example

    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	customer "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/customer"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    			DomainName:            "example-domain-name",
    			DeadLetterQueueUrl:    "example",
    			DefaultEncryptionKey:  "example",
    			Matching:              map[string]any{"enabled": true},

    		})
    	}))
    }

After the Identity Resolution Job completes, use the GetMatches API to return and review the results. Or, if you have configured ExportingConfig in the MatchingRequest, you can download the results from S3. Optional.

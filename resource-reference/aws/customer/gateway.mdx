`aws_customer_gateway` tells AWS the real, public-facing details, IP address among them, of an on-premises VPN device, the AWS-side resource a Site-to-Site VPN connection's two tunnels terminate against. It does not configure the physical or software device itself, a caller sets that up independently to match.

## Input properties

<ResponseField name="bgp_asn" type="number">
  For customer gateway devices that support BGP, specify the device's ASN. You must specify either ``BgpAsn`` or ``BgpAsnExtended`` when creating the customer gateway. If the ASN is larger than ``2,147,483,647``, you must use ``BgpAsnExtended``. Default: 65000 Valid values: ``1`` to ``2,147,483,647`` Optional.
</ResponseField>

<ResponseField name="bgp_asn_extended" type="number">
  For customer gateway devices that support BGP, specify the device's ASN. You must specify either ``BgpAsn`` or ``BgpAsnExtended`` when creating the customer gateway. If the ASN is larger than ``2,147,483,647``, you must use ``BgpAsnExtended``. Valid values: ``2,147,483,648`` to ``4,294,967,295`` Optional.
</ResponseField>

<ResponseField name="certificate_arn" type="string">
  The Amazon Resource Name (ARN) for the customer gateway certificate. Optional.
</ResponseField>

<ResponseField name="device_name" type="string">
  The name of customer gateway device. Optional.
</ResponseField>

<ResponseField name="ip_address" type="string" required>
  The IP address for the customer gateway device's outside interface. The address must be static. If ``OutsideIpAddressType`` in your VPN connection options is set to ``PrivateIpv4``, you can use an RFC6598 or RFC1918 private IPv4 address. If ``OutsideIpAddressType`` is set to ``Ipv6``, you can use an IPv6 address. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags for the customer gateway. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key for a tag assigned to the AWS Customer Gateway resource, used for identification and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag assigned to the customer gateway, used for arbitrary metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of VPN connection that this customer gateway supports (``ipsec.1``). Required.
</ResponseField>

## Output properties

<ResponseField name="customer_gateway_id" type="string">
  The unique identifier assigned by AWS to the customer gateway, such as cgw-0a1b2c3d4e5f6g7h8. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

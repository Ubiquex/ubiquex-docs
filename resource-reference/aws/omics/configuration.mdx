---
title: "aws_omics_configuration"
description: "`aws_omics_configuration` sets real account-level default run configuration for AWS HealthOmics workflow runs..."
---

`aws_omics_configuration` sets real account-level default run configuration for AWS HealthOmics workflow runs, such as default VPC subnet and security group settings, so individual `aws_omics_workflow` runs don't need to specify that configuration every time.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own configuration"})

    		ubx.Resource(omics.Configuration, "ci-runner", omics.ConfigurationConfig{
    			Name:              "ci-runner",
    			RunConfigurations: map[string]any{"vpc_config": map[string]any{"security_group_ids": []string{"example"}}},
    			Description:       "Managed by ubx.",
    			Tags:              "example",
    		})
    	}))
    }
    ```

            name="ci-runner",

            description="Managed by ubx.",
            tags="example",

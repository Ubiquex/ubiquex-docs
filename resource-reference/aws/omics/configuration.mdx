---
title: "aws_omics_configuration"
description: "`aws_omics_configuration` sets real account-level default run configuration for AWS HealthOmics workflow runs..."
---

`aws_omics_configuration` sets real account-level default run configuration for AWS HealthOmics workflow runs, such as default VPC subnet and security group settings, so individual `aws_omics_workflow` runs don't need to specify that configuration every time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own configuration"})

    		ubx.Resource(omics.Configuration, "example", omics.ConfigurationConfig{
    			Name:              "example",
    			RunConfigurations: map[string]any{"vpc_config": map[string]any{"security_group_ids": []string{"example"}}},
    			Description:       "Managed by ubx.",
    			Tags:              "example",
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.omics import Configuration, ConfigurationConfig
    from ubx.aws.omics.configuration import Configuration_RunConfigurations, Configuration_RunConfigurations_VpcConfig

    def describe():
        ubx.intent("example own configuration")

        ubx.resource(Configuration, "example", ConfigurationConfig(
            name="example",
            run_configurations=Configuration_RunConfigurations(vpc_config=Configuration_RunConfigurations_VpcConfig(security_group_ids=["example"])),
            description="Managed by ubx.",
            tags="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

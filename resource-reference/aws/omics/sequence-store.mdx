`aws_omics_sequence_store` creates a real store, backed by S3, for raw genomic sequence files, such as FASTQ, BAM, or CRAM, that AWS HealthOmics workflows read from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sequence store"})

    		ubx.Resource(omics.SequenceStore, "example", omics.SequenceStoreConfig{
    			Name:                   "example",
    			AccessLogLocation:      "example",
    			Description:            "Managed by ubx.",
    			EtagAlgorithmFamily:    "example",
    			FallbackLocation:       "example",
    			PropagatedSetLevelTags: []string{"example"},
    			S3AccessPolicy:         "example",
    			SseConfig:              map[string]any{"type": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_log_location" type="string">
  Location of the access logs. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description for the store. Optional.
</ResponseField>

<ResponseField name="etag_algorithm_family" type="string">
  Specifies the ETag algorithm family (e.g., MD5 or SHA256) used to compute ETags for sequence files in this AWS Omics sequence store. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="fallback_location" type="string">
  An S3 location that is used to store files that have failed a direct upload. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the store. Required.
</ResponseField>

<ResponseField name="propagated_set_level_tags" type="list(string)">
  The tags keys to propagate to the S3 objects associated with read sets in the sequence store. Optional.
</ResponseField>

<ResponseField name="s3_access_policy" type="any">
  The resource policy that controls S3 access on the store Optional.
</ResponseField>

<ResponseField name="sse_config" type="object">
  Server-side encryption (SSE) settings for a store. Optional.
  <Expandable title="properties">
    <ResponseField name="key_arn" type="string">
      An encryption key ARN. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Specifies the server-side encryption type for the sequence store; when set to 'KMS', data is encrypted using an AWS KMS key. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The store's ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="creation_time" type="string">
  When the store was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="s3_access_point_arn" type="string">
  This is ARN of the access point associated with the S3 bucket storing read sets. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="s3_uri" type="string">
  The S3 URI of the sequence store. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="sequence_store_id" type="string">
  The unique AWS-generated identifier for the sequence store, used to reference the store in other Omics operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current lifecycle status of the Omics sequence store, such as CREATING, ACTIVE, DELETING, or FAILED. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status_message" type="string">
  The status message of the sequence store. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="update_time" type="string">
  The last-updated time of the sequence store. Computed by AWS after `ship`.
</ResponseField>

`aws_omics_run_group` defines a real named limit, on compute or duration, that one or more AWS HealthOmics workflow runs are grouped under and constrained by.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own run group"})

    		ubx.Resource(omics.RunGroup, "example", omics.RunGroupConfig{
    			Name:        "example",
    			MaxCpus:     1,
    			MaxDuration: 7200,
    			MaxGpus:     1,
    			MaxRuns:     1,
    			Tags:        "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="max_cpus" type="number">
  The maximum number of CPUs that can be used by all runs within this run group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_duration" type="number">
  Specifies the maximum duration in seconds that a run can run in this group, after which the run is automatically terminated. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_gpus" type="number">
  Sets the maximum number of GPUs that a single workflow run within this run group can use. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_runs" type="number">
  The maximum number of concurrently running workflows that this run group is allowed to have. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  The user-specified name for the run group, used to identify the run group within the AWS account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  A map of resource tags Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this Omics run group. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="creation_time" type="string">
  The time (in ISO 8601 format) when the run group was created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier automatically assigned by AWS Omics to the run group. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_omics_annotation_store` creates a real store for genomic annotation data, such as variant effect predictions, that AWS HealthOmics workflows can read from and write to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own annotation store"})

    		ubx.Resource(omics.AnnotationStore, "example", omics.AnnotationStoreConfig{
    			Name:         "example",
    			StoreFormat:  "example",
    			Description:  "Managed by ubx.",
    			Reference:    map[string]any{"reference_arn": "example"},
    			SseConfig:    map[string]any{"type": "example"},
    			StoreOptions: map[string]any{"tsv_store_options": map[string]any{"annotation_type": "example"}},
    			Tags:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-supplied description of the annotation store, providing optional additional context about the store's purpose or contents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the annotation store, which must be unique within the AWS account and region and serves as the primary identifier for the store. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="reference" type="object">
  The reference property specifies the reference genome (such as GRCh38) that the annotation store is associated with, by providing either the ARN or the ID of an existing AWS Omics reference. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="reference_arn" type="string" required>
      The Amazon Resource Name (ARN) of the AWS Omics reference that defines the coordinate system against which the annotations in the store are interpreted. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sse_config" type="object">
  Specifies the server-side encryption (SSE) configuration for the annotation store, including the encryption type (such as KMS) and the AWS KMS key ARN to use for encrypting data at rest. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key_arn" type="string">
      The ARN of the AWS KMS key used to encrypt the annotation store with server-side encryption. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The server-side encryption type for the annotation store, specifying whether to use Amazon S3 managed keys (SSE-S3) or AWS KMS managed keys (SSE-KMS). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="store_format" type="string" required>
  Specifies the file format of the annotation data stored in the annotation store, which is either TSV or VCF and determines the required store options. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="store_options" type="object">
  StoreOptions specifies the format and schema for the annotation store, allowing you to choose either TSV options (which require a schema for each column) or VCF options (which configure how variant call files are interpreted). Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="tsv_store_options" type="object">
      Configures the TSV-format-specific options for the annotation store, including the annotation type (generic or chromosome-position) and the schema that defines the tab-separated column headers and data types. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="annotation_type" type="string">
          Specifies whether the TSV annotation store contains chromosome-position-aware data (CHR_POS) or generic annotations (GENERIC), which determines how the store parses the schema and interprets genomic coordinates. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="format_to_header" type="any">
          Indicates whether the first line of the TSV file is treated as a header row containing column names. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="schema" type="list(any)">
          Specifies the schema of the TSV annotation store, listing each column's name and data type (such as STRING or LONG) to validate and parse the annotation files. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

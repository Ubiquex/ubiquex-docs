## Input properties

<ResponseField name="description" type="string">
  A user-supplied description of the variant store, providing human-readable context for the resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the variant store, which is required, must be unique within the AWS account and region, and serves as the primary identifier for the resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="reference" type="object" required>
  Configures the reference genome for the variant store, specifying either the ARN or the alias of the reference sequence used for variant annotation. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="reference_arn" type="string" required>
      The Amazon Resource Name (ARN) of the reference genome that the variants in this variant store are aligned to, typically from an AWS HealthOmics reference store. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sse_config" type="object">
  Specifies the server-side encryption configuration for the variant store, including the encryption type (KMS or S3) and the KMS key ARN when using KMS. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key_arn" type="string">
      The ARN of the AWS KMS customer-managed key used to encrypt the variant store data at rest. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Specifies the server-side encryption type for the variant store, which must be either 'KMS' (use a customer-managed key specified in KeyArn) or 'S3' (use S3-managed encryption). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  Tags to assign to the variant store for cost allocation, access control, and resource management in AWS Omics. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="creation_time" type="string">
  The timestamp when the variant store was created, in ISO 8601 format. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique ID of the variant store, which is the same as the store's name and is the identifier used by the AWS Omics API to reference the store. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current lifecycle status of the variant store, such as CREATING, ACTIVE, UPDATING, DELETING, or FAILED. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status_message" type="string">
  The status message provides additional details about the current state of the variant store, such as the reason for a failure during creation or updates. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="store_arn" type="string">
  The Amazon Resource Name (ARN) of the Omics variant store, assigned by AWS when the store is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="store_size_bytes" type="number">
  The total size of the variant store in bytes, computed and reported by AWS after the store is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="update_time" type="string">
  The timestamp indicating when the variant store was last updated, typically in ISO 8601 format. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

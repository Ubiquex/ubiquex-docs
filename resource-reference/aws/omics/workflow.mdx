`aws_omics_workflow` defines a real bioinformatics workflow, its WDL, Nextflow, or CWL definition and parameters, that AWS HealthOmics runs against genomic data in an `aws_omics_sequence_store` or `aws_omics_reference_store`.

## Example

    ```go
    package main

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/omics"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workflow"})

    		ubx.Resource(omics.Workflow, "example", omics.WorkflowConfig{
    			Name:                    "example",
    			Accelerators:            "example",
    			ContainerRegistryMap:    map[string]any{"image_mappings": []map[string]any{{"destination_image": "example"}}},
    			ContainerRegistryMapUri: "example",
    			DefinitionRepository:    map[string]any{"connection_arn": "example"},
    			DefinitionUri:           "example",
    			Description:             "Managed by ubx.",
    			Engine:                  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accelerators" type="string">
  The accelerators property specifies the type of compute accelerator (such as GPU) to use for the workflow run. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="container_registry_map" type="object">
  A map of container image names to their fully-qualified registry image URIs, used to override the default container registries from which the workflow's container images are pulled. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="image_mappings" type="list(object)">
      Specifies a list of container image mappings that map original image URIs in the workflow definition to replacement URIs (e.g., private registry copies) for the corresponding container registry key. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="destination_image" type="string">
          The destination container image URI that replaces the source image when the Omics workflow pulls its containers, redirecting to an alternate registry or repository. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="source_image" type="string">
          The original container image URI as referenced in the workflow definition, which is mapped to an alternative image URI for execution via the container registry map. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="registry_mappings" type="list(object)">
      Specifies a list of container registry mappings, each mapping a registry name to an image URI, so that the workflow can use custom or private container images for its tasks. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="ecr_account_id" type="string">
          The AWS account ID of a private Amazon ECR registry mapped to the Omics workflow, allowing the workflow to pull container images from that account's ECR repositories. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="ecr_repository_prefix" type="string">
          Specifies the Amazon ECR repository prefix used for a given container registry mapping, allowing the Omics workflow to substitute a custom ECR repository for the default registry when building and running workflow container images. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="upstream_registry_url" type="string">
          Specifies the URL of the upstream container registry that the workflow uses to pull container images, allowing registry mappings to redirect image pulls to a private or alternate registry. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="upstream_repository_prefix" type="string">
          Specifies the upstream repository prefix that AWS HealthOmics prepends to container image paths when pulling images from the corresponding registry mapping, allowing the workflow to use an alternate repository for container images. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="container_registry_map_uri" type="string">
  Optional.
</ResponseField>

<ResponseField name="definition_repository" type="object">
  Specifies the source control repository (type, URI, and version) from which AWS HealthOmics retrieves the workflow definition file when it is not provided inline or via an S3 URI. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="connection_arn" type="string">
      The ARN of the AWS CodeStar Connections connection used to access the Git repository that provides the workflow definition. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="exclude_file_patterns" type="list(string)">
      A list of glob-style file patterns that specify which files in the workflow definition repository should be excluded when the workflow source is fetched and packaged. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="full_repository_id" type="string">
      The full repository ID (e.g., 'owner/repository' for GitHub) of the Git repository that contains the workflow definition, used when the workflow source is a repository rather than an S3 URI or ZIP. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_reference" type="object">
      Specifies the S3 URI or GitHub repository path from which the workflow definition is retrieved. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Specifies the type of the source repository (S3 or GIT) that stores the workflow definition for this AWS Omics workflow. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The `value` field of `source_reference` within `definition_repository` is the actual repository reference (for example, a Git branch, tag, commit hash, or S3 URI) that points to the workflow definition to be used. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="definition_uri" type="string">
  The S3 URI of the workflow definition file (WDL or Nextflow) that defines this AWS Omics workflow. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-provided description that is stored with the workflow and displayed in the AWS Omics console to help identify the workflow. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="engine" type="string">
  The engine used to run the workflow, such as WDL, NEXTFLOW, or CWL. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="main" type="string">
  Specifies the relative path to the main workflow definition file (the entry point) within the provided workflow package, used when the workflow is defined as a collection of files. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  A user-provided name that identifies the workflow within AWS Omics, used for display in the console and for filtering and looking up the workflow. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameter_template" type="any">
  Defines the workflow's input parameters as a map, where each key is a parameter name and the value contains properties such as whether the parameter is optional and its description, used to customize workflow runs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameter_template_path" type="string">
  Path to the primary workflow parameter template JSON file inside the repository Optional.
</ResponseField>

<ResponseField name="readme_markdown" type="string">
  The markdown content for the workflow's README file. This provides documentation and usage information for users of the workflow. Optional.
</ResponseField>

<ResponseField name="readme_path" type="string">
  The path to the workflow README markdown file within the repository. This file provides documentation and usage information for the workflow. If not specified, the README.md file from the root directory of the repository will be used. Optional.
</ResponseField>

<ResponseField name="readme_uri" type="string">
  The S3 URI of the README file for the workflow. This file provides documentation and usage information for the workflow. The S3 URI must begin with s3://USER-OWNED-BUCKET/. The requester must have access to the S3 bucket and object. The max README content length is 500 KiB. Optional.
</ResponseField>

<ResponseField name="storage_capacity" type="number">
  Specifies the storage capacity (in gigabytes) to allocate for the workflow's run environment, controlling the disk space available to tasks during execution. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="storage_type" type="string">
  The type of storage used for the workflow run, either 'STATIC' for a fixed storage capacity or 'DYNAMIC' for storage that scales with input data. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  A map of resource tags Optional.
</ResponseField>

<ResponseField name="workflow_bucket_owner_id" type="string">
  Optional workflow bucket owner ID to verify the workflow bucket Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Omics workflow. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="creation_time" type="string">
  The read-only timestamp indicating when the workflow was created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier (workflow ID) assigned to the Omics workflow by AWS upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current lifecycle status of the Omics workflow, indicating whether it is being created, active, being updated, being deleted, or has failed. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="type" type="string">
  The read-only workflow type, which is set to either 'WDL' or 'NEXTFLOW' by the service based on the workflow's engine. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="uuid" type="string">
  The read-only UUID assigned by AWS to uniquely identify this Omics workflow. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

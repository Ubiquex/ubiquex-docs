`aws_omics_run_cache` configures a real cache location for an `aws_omics_workflow`'s task outputs, letting a later run reuse a previous run's completed task results instead of recomputing them.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own run cache"})

    		ubx.Resource(omics.RunCache, "example", omics.RunCacheConfig{
    			Name:               "example",
    			CacheBehavior:      "example",
    			CacheBucketOwnerId: "example",
    			CacheS3Location:    "example",
    			Description:        "Managed by ubx.",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cache_behavior" type="string">
  The default cache behavior for runs using this cache. Optional.
</ResponseField>

<ResponseField name="cache_bucket_owner_id" type="string">
  The AWS account ID of the expected owner of the S3 bucket for the run cache. Optional.
</ResponseField>

<ResponseField name="cache_s3_location" type="string">
  The S3 location for storing the cached task outputs. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the run cache. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  A name for the run cache. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags for the run cache. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag (key-value pair) applied to the AWS Omics run cache. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

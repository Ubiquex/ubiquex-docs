`aws_omics_reference_store` creates a real store for reference genome sequences that `aws_omics_sequence_store` data and `aws_omics_workflow` runs are aligned against.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	omics "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/omics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own reference store"})

    		ubx.Resource(omics.ReferenceStore, "example", omics.ReferenceStoreConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			SseConfig:   map[string]any{"type": "example"},
    			Tags:        "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A description for the store. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the store. Required.
</ResponseField>

<ResponseField name="sse_config" type="object">
  Server-side encryption (SSE) settings for a store. Optional.
  <Expandable title="properties">
    <ResponseField name="key_arn" type="string">
      An encryption key ARN. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of server-side encryption applied to the reference store, which must be either 'KMS' for a customer-managed AWS KMS key or 'S3' for Amazon S3-managed encryption. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  A map of key-value tags to assign to the reference store for organizing, identifying, and managing it within AWS Omics. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The store's ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="creation_time" type="string">
  When the store was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="reference_store_id" type="string">
  The unique identifier assigned to the reference store by AWS when it is created. Computed by AWS after `ship`. **(AI-inferred)**

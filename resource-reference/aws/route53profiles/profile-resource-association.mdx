`aws_route53_profiles_profile_association` associates a real DNS resource, a Resolver rule or DNS Firewall rule group, with an `aws_route53_profiles_profile`, the resource that actually bundles that DNS configuration into the profile applied across many VPCs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53profiles "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53profiles"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own profile resource association"})

    		ubx.Resource(route53profiles.ProfileResourceAssociation, "example", route53profiles.ProfileResourceAssociationConfig{
    			Name:               "example",
    			ProfileId:          "example",
    			ResourceArn:        "arn:aws:iam::123456789012:policy/example",
    			ResourceProperties: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The name of an association between the Profile and resource. Required.
</ResponseField>

<ResponseField name="profile_id" type="string" required>
  The ID of the profile that you associated the resource to that is specified by ResourceArn. Required.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The arn of the resource that you associated to the Profile. Required.
</ResponseField>

<ResponseField name="resource_properties" type="string">
  A JSON-formatted string with key-value pairs specifying the properties of the associated resource. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Primary Identifier for Profile Resource Association Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of the resource associated to the Profile. Computed by AWS after `ship`.
</ResponseField>

`aws_route53_profiles_profile_association` attaches a real `aws_route53_profiles_profile` to a specific VPC, the resource that actually applies the profile's bundled DNS configuration to that VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53profiles "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53profiles"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own profile association"})

    		ubx.Resource(route53profiles.ProfileAssociation, "example", route53profiles.ProfileAssociationConfig{
    			Name:       "example",
    			ProfileId:  "example",
    			ResourceId: "example",
    			Arn:        "arn:aws:iam::123456789012:policy/example",
    			Tags:       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the profile association. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of an association between a Profile and a VPC. Required.
</ResponseField>

<ResponseField name="profile_id" type="string" required>
  The ID of the profile that you associated with the resource that is specified by ResourceId. Required.
</ResponseField>

<ResponseField name="resource_id" type="string" required>
  The resource that you associated the profile with. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">

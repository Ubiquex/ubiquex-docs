`aws_io_tsite_wise_computation_model` defines a real, reusable computation, a transform, metric, or anomaly-detection model, that binds to asset or asset-model properties through a named data-binding configuration, so the same calculation logic can be shared and applied consistently across `aws_io_tsite_wise_asset_model`s rather than redefined inside each one individually. Verified live against AWS's own CloudFormation reference this session, resolving last session's flagged, unverified version of this entry.

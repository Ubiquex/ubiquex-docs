`aws_io_ttwin_maker_workspace` is the real, top-level AWS IoT TwinMaker container an `aws_io_ttwin_maker_entity`, `aws_io_ttwin_maker_component_type`, and `aws_io_ttwin_maker_scene` all belong to, the digital twin project every other TwinMaker resource is scoped inside.

## Input properties

<ResponseField name="description" type="string">
  The description of the workspace. Optional.
</ResponseField>

<ResponseField name="role" type="string" required>
  The ARN of the execution role associated with the workspace. Required.
</ResponseField>

<ResponseField name="s3_location" type="string" required>
  The ARN of the S3 bucket where resources associated with the workspace are stored. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  A map of key-value pairs to associate with a resource. Optional.
</ResponseField>

<ResponseField name="workspace_id" type="string" required>
  The ID of the workspace. Required.
</ResponseField>

`aws_io_twireless_device_profile` is a real, reusable template of LoRaWAN device capabilities, supported data rates, class type, applied to an `aws_io_twireless_wireless_device` rather than every device's radio characteristics being configured individually.

## Input properties

<ResponseField name="lo_ra_wan" type="object">

    </ResponseField>
    <ResponseField name="factory_preset_freqs_list" type="list(number)">

    <ResponseField name="mac_version" type="string">
      The LoRaWAN MAC version of the device profile, such as 1.0.3 or 1.1, which determines the LoRaWAN specification compliance for the device. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="max_duty_cycle" type="number">
      Sets the maximum duty cycle, as a percentage of time the LoRaWAN device may transmit, to limit channel occupancy. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="max_eirp" type="number">
      The maximum Effective Isotropic Radiated Power (EIRP) in dBm that the LoRaWAN device is permitted to transmit with, as configured in the LoRaWAN device profile. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ping_slot_dr" type="number">
      Ping slot data rate for the LoRaWAN Class B mode, determining the transmission data rate used in the device's periodic ping slots. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ping_slot_freq" type="number">
      Sets the frequency (in MHz) used by the LoRaWAN Class B mode for the periodic ping slot on the device profile. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ping_slot_period" type="number">
      Sets the periodicity of LoRaWAN Class B ping slots in the device profile, controlling how frequently the device opens receive windows for downlink messages. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="reg_params_revision" type="string">
      The revision of the regional parameters document used by the LoRaWAN device profile (e.g., '2017-01-01' or '2020-04-15'), which determines the applicable regional LoRaWAN specification version for the device. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rf_region" type="string">
      Specifies the RF region (e.g., US915, EU868) for the LoRaWAN radio, defining the frequency band used for device communication in the device profile. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rx_data_rate2" type="number">
      Configures the data rate index for the second receive window (RX2) in LoRaWAN, which the device uses for downlink traffic when it does not receive a response in the first receive window. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rx_delay1" type="number">
      Sets the RX1 delay (in seconds) for the LoRaWAN device profile, which determines how long after an uplink transmission the device opens its first receive window for downlink messages. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rx_dr_offset1" type="number">
      Sets the data rate offset for the first receive window (RX1) in LoRaWAN, used to compute the RX1 downlink data rate from the uplink data rate in adaptive data rate mode. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rx_freq2" type="number">
      The frequency (in Hz) for the second receive window (RX2) in LoRaWAN, used for downlink transmissions when the device uses this receive window. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="supports32_bit_fcnt" type="bool">
      Indicates whether the LoRaWAN device profile supports 32-bit frame counters, allowing devices to use a larger frame counter value for reliable over-the-air activation and message integrity. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="supports_class_b" type="bool">
      Indicates whether the LoRaWAN device profile supports Class B, enabling scheduled downlink communication using beacon synchronization. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="supports_class_c" type="bool">
      Specifies whether the LoRaWAN device profile supports Class C mode, allowing the device to continuously listen for downlink communications rather than opening receive windows only after uplink transmissions. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="supports_join" type="bool">

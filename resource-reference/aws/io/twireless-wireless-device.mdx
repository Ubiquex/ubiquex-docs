`aws_io_twireless_wireless_device` registers a real, individual LoRaWAN or Amazon Sidewalk device with AWS IoT Wireless, the actual endpoint that connects through an `aws_io_twireless_wireless_gateway` to AWS IoT Core.

## Input properties

<ResponseField name="description" type="string">
  Wireless device description Optional.
</ResponseField>

<ResponseField name="destination_name" type="string" required>
  Wireless device destination name Required.
</ResponseField>

<ResponseField name="last_uplink_received_at" type="string">
  The date and time when the most recent uplink was received. Optional.
</ResponseField>

<ResponseField name="lo_ra_wan" type="object">

        </ResponseField>

            <ResponseField name="app_skey" type="string" required>

            </ResponseField>
            <ResponseField name="nwk_skey" type="string" required>

          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>

        <ResponseField name="session_keys" type="object" required>

            <ResponseField name="snwk_sint_key" type="string" required>

</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Wireless device arn. Returned after successful create. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  Wireless device Id. Returned after successful create. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="thing_name" type="string">
  Thing Arn. If there is a Thing created, this can be returned with a Get call. Computed by AWS after `ship`.
</ResponseField>

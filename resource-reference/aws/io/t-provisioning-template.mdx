`aws_io_t_provisioning_template` defines the real resources, an `aws_io_t_thing`, a certificate, policy attachments, that AWS IoT Fleet Provisioning automatically creates the first time a new device connects, so a device can be manufactured with generic bootstrap credentials rather than a unique certificate burned in at the factory.

`aws_io_t_topic_rule_destination` registers a real HTTPS endpoint an `aws_io_t_topic_rule` can send matched messages to, requiring the endpoint to confirm ownership before AWS IoT will actually deliver any traffic to it.

## Input properties

<ResponseField name="http_url_properties" type="object">
  Specifies the HTTP destination's confirmation URL, which AWS IoT uses to verify ownership of the endpoint before activating the topic rule destination. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="confirmation_url" type="string">
      The URL of the HTTP endpoint where AWS IoT sends a confirmation message to verify the destination's ownership. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  Sets the desired status (ENABLED or DISABLED) of the AWS IoT topic rule destination, controlling whether it can be used by IoT rule actions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpc_properties" type="object">

      The ARN of the IAM role that AWS IoT assumes to access the VPC for the topic rule destination's VPC configuration. Optional. **(AI-inferred)**

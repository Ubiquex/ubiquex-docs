`aws_io_tfleet_wise_signal_catalog` is a real, comprehensive catalog of every vehicle signal, engine RPM, door status, that an `aws_io_tfleet_wise_model_manifest` selects a relevant subset from for one specific vehicle model. Part of AWS IoT FleetWise, which is no longer open to new customers.

## Input properties

<ResponseField name="dashboard_definition" type="string" required>
  The dashboard definition specified in a JSON literal. Required.
</ResponseField>

<ResponseField name="dashboard_description" type="string" required>
  A description for the dashboard. Required.
</ResponseField>

<ResponseField name="dashboard_name" type="string" required>
  A friendly name for the dashboard. Required.
</ResponseField>

<ResponseField name="project_id" type="string">
  The ID of the project in which to create the dashboard. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the dashboard. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key that identifies a tag applied to the AWS IoT SiteWise dashboard, used for metadata and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag (a key-value pair) attached to the AWS IoT SiteWise dashboard, allowing you to categorize and manage the dashboard resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_io_t_role_alias` lets a real, authenticated device exchange its `aws_io_t_certificate` for temporary AWS credentials tied to a specific IAM role, through the IoT credentials provider, without embedding a long-lived AWS access key on the device itself.

## Input properties

<ResponseField name="credential_duration_seconds" type="number">
  Specifies the duration, in seconds, for which the temporary credentials returned by the AWS IoT role alias remain valid when the role is assumed via the alias. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_alias" type="string">
  The unique name for the role alias, used in IoT policies and API calls to refer to the IAM role associated with this alias. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) of the IAM role that the role alias points to, which devices assume when authenticating through the AWS IoT credentials provider. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Defines the list of tag objects to attach to the AWS IoT role alias, which can be used to organize, identify, and control access to the alias resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key of a tag attached to the AWS IoT Role Alias, used for metadata, cost tracking, and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value portion of a tag attached to an AWS IoT Role Alias, used for organizing and identifying the alias with custom metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="role_alias_arn" type="string">
  The Amazon Resource Name (ARN) of the IoT role alias, automatically assigned by AWS when the alias is created. Computed by AWS after `ship`. **(AI-inferred)**

`aws_io_twireless_task_definition` is the real, reusable firmware update definition, the actual image and update parameters, that an `aws_io_twireless_fuota_task` deploys.

## Input properties

<ResponseField name="auto_create_tasks" type="bool" required>
  Whether to automatically create tasks using this task definition for all gateways with the specified current version. If false, the task must me created by calling CreateWirelessGatewayTask. Required.
</ResponseField>

<ResponseField name="lo_ra_wanupdate_gateway_task_entry" type="object">

    <ResponseField name="current_version" type="object">

      <Expandable title="properties">
        <ResponseField name="model" type="string">
          Specifies the model name or identifier of the LoRaWAN gateway that this task definition version is intended for. Optional. **(AI-inferred)**

        <ResponseField name="package_version" type="string">
          The package version of the LoRaWAN gateway's current firmware, used to identify the existing firmware state before an update task is applied. Optional. **(AI-inferred)**

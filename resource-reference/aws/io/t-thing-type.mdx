`aws_io_t_thing_type` defines a real, reusable template of common attributes and searchable metadata for a category of `aws_io_t_thing`s, temperature sensors versus door locks, for instance, rather than every thing's attributes being defined from scratch.

## Input properties

<ResponseField name="deprecate_thing_type" type="bool">
  Indicates whether the thing type should be deprecated, which prevents new things from being associated with it after the type is created. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value part of a tag key-value pair used to label the AWS IoT Thing Type. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="thing_type_name" type="string">
  Specifies a user-defined name for the AWS IoT thing type, which must be unique within the AWS account and is used to identify the thing type in IoT Core operations; if omitted, AWS IoT automatically generates a name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="thing_type_properties" type="object">
  Configures the properties of the AWS IoT thing type, including a human-readable description and a list of searchable attributes used to search for things of this type. Optional. **(AI-inferred)**

      <Expandable title="properties">

            <ResponseField name="connection_attribute" type="string">
              Specifies the MQTT5 connection attribute (e.g., SourceIp, ThingName, or ThingTypeName) whose value is propagated into the CONNECT message's user properties for devices of this thing type. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="thing_attribute" type="string">
              The name of the thing attribute that will be propagated to MQTT5 messages for the AWS IoT Thing Type. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="user_property_key" type="string">
              Specifies the key of the MQTT5 user property that carries the value of the associated thing attribute when messages are published. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="searchable_attributes" type="list(string)">
      Specifies a list of thing attribute names that can be used to search for things of this thing type in AWS IoT. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="thing_type_description" type="string">
      An optional human-readable description that provides additional context about the purpose or characteristics of the AWS IoT thing type. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

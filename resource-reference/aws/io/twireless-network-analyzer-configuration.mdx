`aws_io_twireless_network_analyzer_configuration` defines a real, live traffic-tracing session scoped to specific `aws_io_twireless_wireless_device`s or gateways, for debugging LoRaWAN connectivity issues as they actually happen rather than after the fact from logs alone.

<ResponseField name="trace_content" type="object">
  Trace content for your wireless gateway and wireless device resources Optional.
  <Expandable title="properties">
    <ResponseField name="log_level" type="string">

    </ResponseField>
    <ResponseField name="wireless_device_frame_info" type="string">
      Specifies whether frame-level information for wireless devices is captured in the network analyzer trace, enabling or disabling wireless device frame tracing. Optional. **(AI-inferred)**

  </Expandable>

<ResponseField name="wireless_gateways" type="list(string)">

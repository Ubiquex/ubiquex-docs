`aws_io_tfleet_wise_campaign` defines real, specific data collection rules, which signals, at what rate, under what trigger condition, deployed to an `aws_io_tfleet_wise_vehicle` or `aws_io_tfleet_wise_fleet`'s own Edge Agent. Part of AWS IoT FleetWise, which is no longer open to new customers.

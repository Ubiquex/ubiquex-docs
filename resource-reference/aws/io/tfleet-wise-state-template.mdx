`aws_io_tfleet_wise_state_template` tracks a real, defined set of signals' current state on a vehicle, reported on change or on a periodic interval by the Edge Agent, distinct from an `aws_io_tfleet_wise_campaign`'s own bulk data-collection model. Part of AWS IoT FleetWise, which is no longer open to new customers.

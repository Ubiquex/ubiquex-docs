`aws_io_t_cacertificate` registers a real, caller-owned certificate authority with AWS IoT, so device certificates the caller's own CA issues, rather than only ones AWS IoT itself issues, can be trusted to authenticate an `aws_io_t_thing`'s connection.

## Input properties

<ResponseField name="auto_registration_status" type="string">
  Controls whether certificates signed by this CA certificate are automatically registered with AWS IoT upon first use, with allowed values such as 'ENABLE' and 'DISABLE'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cacertificate_pem" type="string" required>
  The PEM-encoded CA certificate content that AWS IoT uses to register device certificates and verify their authenticity. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_mode" type="string">
  Specifies whether the CA certificate is used for device authentication (DEFAULT) or TLS client authentication (SNI_ONLY) in AWS IoT. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="registration_config" type="object">
  Specifies the registration configuration for this CA certificate, including the registration template body and the IAM role that AWS IoT uses to provision device certificates. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="role_arn" type="string">
      The ARN of the AWS IoT role that grants permission to register the CA certificate during device certificate registration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="template_body" type="string">
      The body of the AWS IoT provisioning template used to automatically register device certificates signed by this CA certificate. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="template_name" type="string">
      The name of the AWS IoT provisioning template used during certificate registration to define the resources and policies automatically created when a device certificate is registered under this CA certificate. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="remove_auto_registration" type="bool">
  When set to true, this boolean removes the auto-registration for device certificates signed by this CA certificate when the CA certificate is deleted from AWS IoT. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string" required>
  Specifies the operational status of the CA certificate, which must be either 'ACTIVE' or 'INACTIVE', controlling whether the certificate is enabled for device authentication in AWS IoT. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag attached to the AWS IoT CA certificate, used to identify and categorize the certificate within AWS resource tagging systems. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS IoT CA certificate, used to categorize or identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="verification_certificate_pem" type="string">
  The private key verification certificate. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that AWS assigns to the CA certificate when it is registered in AWS IoT. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier of the CA certificate, assigned by AWS IoT when the CA certificate is registered. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_io_tevents_alarm_model` is a real, pre-built alarm pattern, built on the same underlying state-machine mechanism as an `aws_io_tevents_detector_model`, purpose-built for the common case of a threshold-based alarm rather than a caller designing a full custom state machine for it.

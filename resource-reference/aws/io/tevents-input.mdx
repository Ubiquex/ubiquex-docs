`aws_io_tevents_input` defines the real message attributes an `aws_io_tevents_detector_model` actually evaluates, the structured data a detector model's states and transitions are written in terms of.

<ResponseField name="input_definition" type="object" required>
  The definition of the input. Required.
  <Expandable title="properties">
    <ResponseField name="attributes" type="list(object)" required>
      The attributes from the JSON payload that are made available by the input. Inputs are derived from messages sent to the ITE system using ``BatchPutMessage``. Each such message contains a JSON payload, and those attributes (and their paired values) specified here are available for use in the ``condition`` expressions used by detectors that monitor this input. Required.

`aws_io_ttwin_maker_scene` composes a real, 3D visualization of an `aws_io_ttwin_maker_workspace`'s own entities, tagging real-time data onto a 3D model rather than only viewing entity data as raw numbers.

## Input properties

<ResponseField name="capabilities" type="list(string)">
  A list of capabilities that the scene uses to render. Optional.
</ResponseField>

<ResponseField name="content_location" type="string" required>
  The relative path that specifies the location of the content definition file. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the scene. Optional.
</ResponseField>

<ResponseField name="scene_id" type="string" required>
  The ID of the scene. Required.
</ResponseField>

<ResponseField name="scene_metadata" type="any">
  A key-value pair of scene metadata for the scene. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

<ResponseField name="workspace_id" type="string" required>
  The ID of the scene. Required.
</ResponseField>

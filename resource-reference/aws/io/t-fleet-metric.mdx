`aws_io_t_fleet_metric` aggregates a real CloudWatch metric across every device in an `aws_io_t_thing_group`, fleet-wide visibility, average battery level across a whole product line, for instance, rather than only per-device metrics.

## Input properties

<ResponseField name="aggregation_field" type="string">
  The aggregation field to perform aggregation and metric emission Optional.
</ResponseField>

<ResponseField name="aggregation_type" type="object">
  Aggregation types supported by Fleet Indexing Optional.
  <Expandable title="properties">
    <ResponseField name="name" type="string" required>
      Fleet Indexing aggregation type names such as Statistics, Percentiles and Cardinality Required.
    </ResponseField>
    <ResponseField name="values" type="list(string)" required>
      Fleet Indexing aggregation type values Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of a fleet metric Optional.
</ResponseField>

<ResponseField name="index_name" type="string">
  The index name of a fleet metric Optional.
</ResponseField>

<ResponseField name="metric_name" type="string" required>
  The name of the fleet metric Required.
</ResponseField>

<ResponseField name="period" type="number">
  The period of metric emission in seconds Optional.
</ResponseField>

<ResponseField name="query_string" type="string">
  The Fleet Indexing query used by a fleet metric Optional.
</ResponseField>

<ResponseField name="query_version" type="string">
  The version of a Fleet Indexing query used by a fleet metric Optional.
</ResponseField>

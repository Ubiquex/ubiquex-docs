`aws_io_tsite_wise_dataset` links a real, external structured dataset, maintenance records, work orders, to `aws_io_tsite_wise_asset` data, so operational context beyond raw sensor readings can be queried and visualized alongside it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iotsitewise "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iotsitewise"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tsite wise dataset"})

    		ubx.Resource(iotsitewise.Dataset, "example", iotsitewise.DatasetConfig{
    			DatasetName:        "example-dataset-name",
    			DatasetSource:      map[string]any{"source_format": "example"},
    			DatasetDescription: "example",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="dataset_description" type="string">
  A description about the dataset, and its functionality. Optional.
</ResponseField>

<ResponseField name="dataset_name" type="string" required>
  The name of the dataset. Required.
</ResponseField>

<ResponseField name="dataset_source" type="object" required>
  Specifies the source configuration for the IoT SiteWise dataset, including the Amazon S3 location (bucket and prefix) of the data files and the file format for importing data into the dataset. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="source_detail" type="object">
      Provides source-specific configuration details (such as an Amazon Kendra index or AWS IoT SiteWise source) for the dataset source, as defined by the DatasetSource property of an AWS::IoTSiteWise::Dataset resource. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="kendra" type="object">
          The Kendra source detail that specifies the Amazon Kendra index ARN and an IAM role ARN used by the IoT SiteWise dataset to retrieve and ingest data from that index. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="knowledge_base_arn" type="string" required>
              The knowledgeBaseArn details for the Kendra dataset source. Required.
            </ResponseField>
            <ResponseField name="role_arn" type="string" required>
              The roleARN details for the Kendra dataset source. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="source_format" type="string" required>

    <ResponseField name="source_type" type="string" required>

  </Expandable>
</ResponseField>

`aws_io_t_topic_rule` is a real, SQL-like rule the AWS IoT Rules Engine evaluates against every message published to a matching MQTT topic, routing matching messages to a real target, Lambda, S3, DynamoDB, an `aws_io_tanalytics_channel`, and dozens of other AWS services.

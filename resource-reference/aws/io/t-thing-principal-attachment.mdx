---
title: "aws_io_t_thing_principal_attachment"
description: "`aws_io_t_thing_principal_attachment` is the real, actual link between an `aws_io_t_thing` and its `aws_io_t_certificate`."
---

A certificate with no thing attachment can still authenticate an MQTT connection but has no thing identity behind it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own t thing principal attachment"})

    		ubx.Resource(iot.ThingPrincipalAttachment, "example", iot.ThingPrincipalAttachmentConfig{
    			Principal:          "example",
    			ThingName:          "example-thing-name",
    			ThingPrincipalType: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="principal" type="string" required>
  The ARN of the AWS IoT certificate or Amazon Cognito identity that is attached as a principal to the IoT thing. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="thing_name" type="string" required>
  The name of the AWS IoT thing to which the principal (certificate or Cognito identity) is attached. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="thing_principal_type" type="string">
  Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Computed by AWS after `ship`.
</ResponseField>

`aws_io_t_security_profile` defines real, expected behavior for a group of devices, connection frequency, message size, authorization failures, that Device Defender's Detect capability continuously measures live device behavior against, alerting when a device deviates from its own defined profile.

## Input properties

<ResponseField name="additional_metrics_to_retain_v2" type="list(object)">
  A list of metrics whose data is retained (stored). By default, data is retained for any metric used in the profile's behaviors, but it is also retained for any metric specified here. Optional.
  <Expandable title="properties">
    <ResponseField name="export_metric" type="bool">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="metric" type="string">
      The name of the AWS IoT device metric to retain for the security profile, as part of the MetricToRetain object in AdditionalMetricsToRetainV2. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metric_dimension" type="object">
      Specifies the named dimension (e.g., a thing group or device attribute) and operator (IN or NOT_IN) that scopes the additional metric to be retained by the AWS IoT security profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="dimension_name" type="string">
          The name of the AWS IoT Device Defender metric dimension (such as a device or topic filter) that defines the scope for the metric to retain in the security profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="operator" type="string">
          The operator (IN or NOT_IN) that determines whether the metric applies to values that are in or not in the specified dimension. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

  <Expandable title="properties">

        <ResponseField name="comparison_operator" type="string">

Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="consecutive_datapoints_to_alarm" type="number">
          The number of consecutive datapoints that must violate the behavior's criteria before an alarm is triggered. Optional; if omitted, computed by AWS. **(AI-inferred)**

        <ResponseField name="consecutive_datapoints_to_clear" type="number">

          Specifies the time period (in seconds) over which the behavior metric is measured and compared against the configured value to detect a violation. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="ml_detection_config" type="object">

          <Expandable title="properties">

          </Expandable>

        <ResponseField name="statistical_threshold" type="object">

            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="value" type="object">

            <ResponseField name="cidrs" type="list(string)">
              Specifies the list of IPv4 or IPv6 CIDR blocks (e.g., '192.168.1.0/24') that define the allowed network address range for the security profile behavior's metric value, used in AWS IoT Device Defender to monitor device network connection locations. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="count" type="string">
              The numeric threshold (specified as a string) for the number of times the metric can occur within the evaluation window before the security profile behavior triggers an alert. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="number" type="number">

            <ResponseField name="numbers" type="list(number)">
              Optional; if omitted, computed by AWS.
            </ResponseField>
            <ResponseField name="ports" type="list(number)">
              The list of allowed destination port numbers for the behavior's criteria, used when the metric is `aws:message-by-ports`. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>

      The name of the AWS IoT Device Defender metric (such as 'aws:message-byte-size' or 'aws:all') that this behavior monitors, where the behavior's criteria will be evaluated against metric values reported by devices. Optional; if omitted, computed by AWS. **(AI-inferred)**

    <ResponseField name="metric_dimension" type="object">

        <ResponseField name="operator" type="string">

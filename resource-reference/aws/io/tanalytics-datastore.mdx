`aws_io_tanalytics_datastore` holds the real, processed output of an `aws_io_tanalytics_pipeline`, the actual data an `aws_io_tanalytics_dataset`'s query or container runs against.

## Example

    	ubx.Main(ubx.Stack("example", func() {

`aws_io_t_policy` is a real, JSON-based document defining exactly which MQTT topics and AWS IoT actions a connected device is actually allowed to publish, subscribe to, or invoke, attached to an `aws_io_t_certificate` through an `aws_io_t_policy_principal_attachment`.

## Input properties

<ResponseField name="policy_document" type="any" required>
  A JSON-formatted policy document that defines the permissions for the AWS IoT policy, specifying allowed or denied actions and resources for IoT principals. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="policy_name" type="string">
  The name of the AWS IoT policy; if omitted, CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to attach to the IoT policy, used for labeling and organizing the policy in AWS. Optional. **(AI-inferred)**
  <Expandable title="properties">

</ResponseField>

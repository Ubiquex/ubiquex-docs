`aws_io_tanalytics_channel` is the real entry point AWS IoT Analytics ingests raw device messages into, typically fed directly by an `aws_io_t_topic_rule`, and holds the unprocessed data an `aws_io_tanalytics_pipeline` reads from.

## Input properties

<ResponseField name="channel_name" type="string">
  The name of the AWS IoT Analytics channel; if omitted, CloudFormation generates a unique name for the channel. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="channel_storage" type="object">
  Configures the storage destination for the channel's message data, choosing between an AWS IoT Analytics service-managed S3 bucket or a customer-managed S3 bucket. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="customer_managed_s3" type="object">
      Specifies the customer-managed S3 bucket configuration where the IoT Analytics channel stores its data, including the bucket name and optional key prefix. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The name of the S3 bucket in which the channel's data is stored when using customer-managed S3 storage. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="key_prefix" type="string">
          Specifies the key prefix for objects stored in the customer-managed S3 bucket in the IoT Analytics channel's storage, used to organize or filter the channel data. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="role_arn" type="string" required>
          The ARN of the IAM role that AWS IoT Analytics assumes to access the customer-managed S3 bucket for storing channel data. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="service_managed_s3" type="any">
      Specifies that AWS IoT Analytics uses a service-managed S3 bucket for channel storage, indicated by the presence of this empty object. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="retention_period" type="object">
  Specifies how long message data is kept in the channel, either as a finite number of days or indefinitely. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="number_of_days" type="number">
      Specifies the number of days that message data in the channel is retained, after which it is automatically deleted. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="unlimited" type="bool">
      When set to true, the channel retains its data indefinitely with no automatic expiration, and when false you must supply a finite retention period in days using the `numberOfDays` field of the same `retentionPeriod` object. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags are key-value pairs that you can attach to an AWS IoT Analytics channel to help identify and organize the channel, and they can be used for resource-level access control and cost tracking. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag associated with an AWS IoT Analytics channel, used to assign metadata for resource tracking and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

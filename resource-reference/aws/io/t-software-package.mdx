`aws_io_t_software_package` is a real, named entry in the AWS IoT Software Package Catalog, an inventory of firmware, OS updates, or applications, whose `aws_io_t_software_package_version`s get associated with things and deployed through an `aws_io_t_job`. Reached general availability in 2023.

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Description: "Managed by ubx.",
    			PackageName: "example-package-name",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="description" type="string">
  A free-form text description of the software package (up to 1024 characters) that provides details about its purpose or contents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="package_name" type="string">
  The user-defined name for the AWS IoT software package, which must be unique within your AWS account and can be omitted for AWS IoT to auto-generate a name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS IoT software package. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair assigned to the AWS IoT Software Package, used as metadata to identify, organize, and search for the package. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="package_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the AWS IoT software package in this account and Region. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

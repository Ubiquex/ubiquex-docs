`aws_io_t_certificate_provider` runs a real, caller-defined Lambda function during Fleet Provisioning to issue a device's `aws_io_t_certificate` dynamically, using a custom or third-party CA, rather than relying only on AWS IoT's own certificate issuance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	io "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/io"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own t certificate provider"})

    		ubx.Resource(io.TCertificateProvider, "example", io.TCertificateProviderConfig{
    			AccountDefaultForOperations: []string{"example"},
    			LambdaFunctionArn:           "arn:aws:iam::123456789012:policy/example",
    			CertificateProviderName:     "example-certificate-provider-name",
    			Tags:                        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="account_default_for_operations" type="list(string)" required>
  The AWS::IoT::CertificateProvider account default for operations property specifies the list of certificate provider operations (RegisterCertificate or RegisterCertificateWithoutCA) for which this certificate provider is the default provider in the AWS account. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_provider_name" type="string">
  Specifies the unique name of the AWS IoT certificate provider, which identifies it within the AWS account and region and is referenced when associating CA certificates with this provider. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="lambda_function_arn" type="string" required>
  The ARN of the Lambda function that AWS IoT invokes to perform custom certificate signing or validation for this certificate provider. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">

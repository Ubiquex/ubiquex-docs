`aws_io_tfleet_wise_decoder_manifest` translates a real vehicle's raw CAN bus or OBD messages into the named signals an `aws_io_tfleet_wise_model_manifest` defines, the actual decoding logic the Edge Agent applies on the vehicle itself. Part of AWS IoT FleetWise, which is no longer open to new customers.

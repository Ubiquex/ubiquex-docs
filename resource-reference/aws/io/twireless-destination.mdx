`aws_io_twireless_destination` routes a real, decoded LoRaWAN or Sidewalk message from an `aws_io_twireless_wireless_device` to an `aws_io_t_topic_rule`, the actual bridge from AWS IoT Wireless into the rest of AWS IoT Core.

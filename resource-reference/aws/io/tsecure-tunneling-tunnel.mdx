`aws_io_tsecure_tunneling_tunnel` is an AWS IoT Secure Tunneling tunnel, a real, temporary bidirectional communication channel to a remote device (e.g. one behind a firewall or NAT with no open inbound ports) for troubleshooting or remote access, brokered entirely by AWS IoT rather than requiring inbound connectivity to the device itself.

    			Tags:              []map[string]any{{"key": "example"}},

    		})
    	}))
    }

## Input properties

<ResponseField name="description" type="string">
  A short text description of the tunnel. Optional.
</ResponseField>

<ResponseField name="destination_config" type="object">
  The destination configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="services" type="list(string)" required>
      A list of service names that identify the target application. Required.
    </ResponseField>
    <ResponseField name="thing_name" type="string">
      The name of the IoT thing to which you want to connect. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tag metadata. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="timeout_config" type="object">
  Tunnel timeout configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="max_lifetime_timeout_minutes" type="number">
      The maximum amount of time (in minutes) a tunnel can remain open. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="status" type="string">
  The status of the tunnel. Valid values are OPEN and CLOSED. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="tunnel_arn" type="string">
  The Amazon Resource Name (ARN) of the tunnel. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="tunnel_id" type="string">
  A unique alpha-numeric tunnel ID. Computed by AWS after `ship`.
</ResponseField>

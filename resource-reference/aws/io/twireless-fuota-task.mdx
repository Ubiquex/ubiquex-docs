`aws_io_twireless_fuota_task` runs a real firmware-update-over-the-air campaign across a group of LoRaWAN `aws_io_twireless_wireless_device`s, using multicast delivery to update many devices' firmware efficiently rather than one at a time.

## Input properties

<ResponseField name="associate_multicast_group" type="string">
  Multicast group to associate. Only for update request. Optional.
</ResponseField>

<ResponseField name="associate_wireless_device" type="string">
  Wireless device to associate. Only for update request. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  FUOTA task description Optional.
</ResponseField>

<ResponseField name="disassociate_multicast_group" type="string">
  Multicast group to disassociate. Only for update request. Optional.
</ResponseField>

<ResponseField name="disassociate_wireless_device" type="string">
  Wireless device to disassociate. Only for update request. Optional.
</ResponseField>

<ResponseField name="firmware_update_image" type="string" required>
  FUOTA task firmware update image binary S3 link Required.
</ResponseField>

<ResponseField name="firmware_update_role" type="string" required>
  FUOTA task firmware IAM role for reading S3 Required.
</ResponseField>

<ResponseField name="name" type="string">
  Name of FUOTA task Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

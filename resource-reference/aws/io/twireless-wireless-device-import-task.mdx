`aws_io_twireless_wireless_device_import_task` bulk-imports real Sidewalk devices from a manufacturer-provided list into AWS IoT Wireless as `aws_io_twireless_wireless_device`s, rather than a caller registering each device one at a time.

## Example

    ```go
    package main

    import (
    	io "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/io"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own twireless wireless device import task"})

    		ubx.Resource(io.TwirelessWirelessDeviceImportTask, "example", io.TwirelessWirelessDeviceImportTaskConfig{
    			DestinationName: "example-destination-name",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="destination_name" type="string" required>
  Destination Name for import task Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag applied to the AWS IoT Wireless device import task, used for organizing, identifying, and managing the import task via AWS tagging. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

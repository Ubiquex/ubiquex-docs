`aws_io_twireless_partner_account` links a real Amazon Sidewalk partner account to AWS IoT Wireless, required before a caller's own Sidewalk `aws_io_twireless_wireless_device`s can be managed through the service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iotwireless "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iotwireless"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own twireless partner account"})

    		ubx.Resource(iotwireless.PartnerAccount, "example", iotwireless.PartnerAccountConfig{
    			AccountLinked:    true,
    			PartnerAccountId: "example",
    			PartnerType:      "example",
    			Sidewalk:         map[string]any{"app_server_private_key": "example"},
    			SidewalkResponse: map[string]any{"amazon_id": "example"},
    			SidewalkUpdate:   map[string]any{"app_server_private_key": "example"},
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="account_linked" type="bool">
  Whether the partner account is linked to the AWS account. Optional.
</ResponseField>

<ResponseField name="partner_account_id" type="string">
  The partner account ID to disassociate from the AWS account Optional.
</ResponseField>

<ResponseField name="partner_type" type="string">
  The partner type Optional.
</ResponseField>

<ResponseField name="sidewalk" type="object">
  This optional object configures the Sidewalk partner account credentials, including the application server private key used for authenticating with the Sidewalk network. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="app_server_private_key" type="string" required>
      The sidewalk block's app_server_private_key specifies the Sidewalk application server private key that AWS IoT Wireless uses to encrypt and authenticate messages exchanged with your backend application server for the partner account. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sidewalk_response" type="object">
  The Sidewalk account response information returned by AWS IoT Wireless, including the assigned Amazon client ID and the cryptographic fingerprint used to authenticate the partner account. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="amazon_id" type="string">
      The Amazon ID assigned by AWS to the Sidewalk partner account, returned in the sidewalk response. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="arn" type="string">
      The Amazon Resource Name (ARN) of the Sidewalk partner account, which uniquely identifies the partner account within AWS. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="fingerprint" type="string">
      The fingerprint returned by AWS IoT Wireless in the Sidewalk response after creating a partner account, which you provide to Sidewalk to validate and link the device. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sidewalk_update" type="object">
  The sidewalk_update property specifies updated Sidewalk credentials, including the application server private key and device certificates, to associate with the partner account. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="app_server_private_key" type="string">
      Specifies the private key of the Sidewalk application server, used to authenticate and encrypt communication between the application server and AWS IoT Wireless for the partner account. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the destination. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag assigned to the IoT Wireless Partner Account, used to organize and identify the tag for cost allocation and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the AWS IoT Wireless Partner Account, allowing you to manage and categorize the resource with custom metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  PartnerAccount arn. Returned after successful create. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="fingerprint" type="string">
  The fingerprint of the Sidewalk application server private key. Computed by AWS after `ship`.
</ResponseField>

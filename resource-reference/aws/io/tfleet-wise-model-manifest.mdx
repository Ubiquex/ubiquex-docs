`aws_io_tfleet_wise_model_manifest` selects the real, specific signals from an `aws_io_tfleet_wise_signal_catalog` that apply to one vehicle model, the actual signal set an `aws_io_tfleet_wise_vehicle` of that model can report. Part of AWS IoT FleetWise, which is no longer open to new customers.

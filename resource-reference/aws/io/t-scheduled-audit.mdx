`aws_io_t_scheduled_audit` runs Device Defender's real, configured audit checks on a recurring schedule, defined by an `aws_io_t_account_audit_configuration`, real, ongoing compliance checking rather than a one-time manual review.

## Input properties

<ResponseField name="day_of_month" type="string">
  The day of the month on which the scheduled audit takes place. Can be 1 through 31 or LAST. This field is required if the frequency parameter is set to MONTHLY. Optional.
</ResponseField>

<ResponseField name="day_of_week" type="string">
  The day of the week on which the scheduled audit takes place. Can be one of SUN, MON, TUE,WED, THU, FRI, or SAT. This field is required if the frequency parameter is set to WEEKLY or BIWEEKLY. Optional.
</ResponseField>

<ResponseField name="frequency" type="string" required>
  How often the scheduled audit takes place. Can be one of DAILY, WEEKLY, BIWEEKLY, or MONTHLY. Required.
</ResponseField>

<ResponseField name="scheduled_audit_name" type="string">
  The name you want to give to the scheduled audit. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the AWS IoT scheduled audit resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a user-defined tag attached to the AWS IoT scheduled audit, used to attach metadata like environment or owner to the audit resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_check_names" type="list(string)" required>
  Which checks are performed during the scheduled audit. Checks must be enabled for your account. Required.
</ResponseField>

## Output properties

<ResponseField name="scheduled_audit_arn" type="string">
  The ARN (Amazon resource name) of the scheduled audit. Computed by AWS after `ship`.
</ResponseField>

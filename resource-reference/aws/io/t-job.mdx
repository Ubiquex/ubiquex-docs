`aws_io_t_job` defines a real, remote operation, a firmware update, a config change, a reboot command, deployed to and tracked across one or more real `aws_io_t_thing`s or `aws_io_t_thing_group`s, with per-device execution status reported back to AWS IoT.

## Input properties

<ResponseField name="abort_config" type="object">
  The criteria that determine when and how a job abort takes place. Optional.
  <Expandable title="properties">
    <ResponseField name="criteria_list" type="list(object)" required>
      The list of criteria that determine when and how to abort the job. Required.
      <Expandable title="properties">
        <ResponseField name="action" type="string">
          Specifies the abort action (CANCEL or CONTINUE) to perform when the job's abort criteria are met. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="failure_type" type="string">
          The type of job execution failure that triggers the abort criteria for an AWS IoT job, such as FAILED, TIMED_OUT, or ALL. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="min_number_of_executed_things" type="number">
          The minimum number of things that must have completed the job execution before the abort criteria can be evaluated, allowing the abort action to trigger only after a certain number of executions have occurred. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="threshold_percentage" type="number">
          The percentage of the total number of things in the job that must experience the specified failure type before the abort criteria triggers the abort action, when combined with the minimum number of executed things. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A short text description of the job. Optional.
</ResponseField>

<ResponseField name="destination_package_versions" type="list(string)">
  The package version Amazon Resource Names (ARNs) that are installed on the device when the job successfully completes. Optional.
</ResponseField>

<ResponseField name="document" type="string">
  The job document. Required if you don't specify a value for documentSource. Optional.
</ResponseField>

<ResponseField name="document_parameters" type="any">
  Parameters of an Amazon Web Services managed template that you can specify to create the job document. Optional.
</ResponseField>

<ResponseField name="document_source" type="string">
  An S3 link, or S3 object URL, to the job document. The link is an Amazon S3 object URL and is required if you don't specify a value for document. Optional.
</ResponseField>

<ResponseField name="job_executions_retry_config" type="object">
  The configuration that determines how many retries are allowed for each failure type for a job. Optional.
  <Expandable title="properties">
    <ResponseField name="criteria_list" type="list(object)" required>
      The list of criteria that determines how many retries are allowed for each failure type for a job. Required.
      <Expandable title="properties">
        <ResponseField name="failure_type" type="string">
          Specifies the type of job execution failure (e.g., FAILED, TIMED_OUT, or ALL) that this retry criterion applies to, determining which failures trigger the configured retry count. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="number_of_retries" type="number">
          The maximum number of retry attempts for a job execution that fails with the associated failure type before the execution is marked as failed. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="job_executions_rollout_config" type="object">
  Allows you to create a staged rollout of a job. Optional.
  <Expandable title="properties">
    <ResponseField name="exponential_rate" type="object">
      Allows you to create an exponential rate of rollout for a job. Optional.
      <Expandable title="properties">
        <ResponseField name="base_rate_per_minute" type="number" required>
          The minimum number of things that will be notified of a pending job, per minute at the start of job rollout. Required.
        </ResponseField>
        <ResponseField name="increment_factor" type="number" required>
          The exponential factor to increase the rate of rollout for a job. Required.
        </ResponseField>
        <ResponseField name="rate_increase_criteria" type="object" required>
          Allows you to define a criteria to initiate the increase in rate of rollout for a job. Required.
          <Expandable title="properties">
            <ResponseField name="number_of_notified_things" type="number">
              The threshold for number of notified things that will initiate the increase in rate of rollout. Optional.
            </ResponseField>
            <ResponseField name="number_of_succeeded_things" type="number">
              The threshold for number of succeeded things that will initiate the increase in rate of rollout. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="maximum_per_minute" type="number">
      The maximum number of things that will be notified of a pending job, per minute. This parameter allows you to create a staged rollout. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="job_id" type="string" required>
  A job identifier which must be unique for your AWS account. We recommend using a UUID. Alpha-numeric characters, '-' and '_' are valid for use here. Required.
</ResponseField>

<ResponseField name="job_template_arn" type="string">
  The ARN of the job template used to create the job. Optional.
</ResponseField>

<ResponseField name="presigned_url_config" type="object">
  Configuration for pre-signed S3 URLs. Optional.
  <Expandable title="properties">
    <ResponseField name="expires_in_sec" type="number">
      How long (in seconds) pre-signed URLs are valid. Valid values are 60 - 3600, the default value is 3600 seconds. Optional.
    </ResponseField>
    <ResponseField name="role_arn" type="string">
      The ARN of an IAM role that grants permission to download files from the S3 bucket where the job data/updates are stored. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scheduling_config" type="object">
  Specifies the date and time that a job will begin the rollout of the job document to all devices in the target group. Optional.
  <Expandable title="properties">
    <ResponseField name="end_behavior" type="string">
      Specifies the end behavior for all job executions after a job reaches the selected endTime. Optional.
    </ResponseField>
    <ResponseField name="end_time" type="string">
      The time a job will stop rollout of the job document to all devices in the target group for a job. Optional.
    </ResponseField>
    <ResponseField name="maintenance_windows" type="list(object)">
      An optional configuration within the SchedulingConfig to setup a recurring maintenance window. Optional.
      <Expandable title="properties">
        <ResponseField name="duration_in_minutes" type="number">
          Specifies the length of each maintenance window, in minutes, during which the AWS IoT job is allowed to run before the window closes and job executions are paused. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="start_time" type="string">
          The start time of the maintenance window, in ISO 8601 format, during which the AWS IoT job execution can be started. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="start_time" type="string">
      The time a job will begin rollout of the job document to all devices in the target group for a job. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Metadata which can be used to manage the job. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag to attach to the AWS IoT job, allowing you to categorize, organize, and manage the job resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS IoT Job, used to categorize the job and enable resource-level access control via IAM condition keys such as aws:ResourceTag. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_selection" type="string">
  Specifies whether the job will continue to run (CONTINUOUS), or will be complete after all those things specified as targets have completed the job (SNAPSHOT). Optional.
</ResponseField>

<ResponseField name="targets" type="list(string)" required>
  A list of things and thing groups to which the job should be sent. Required.
</ResponseField>

<ResponseField name="timeout_config" type="object">
  Specifies the amount of time each device has to finish its execution of the job. Optional.
  <Expandable title="properties">
    <ResponseField name="in_progress_timeout_in_minutes" type="number">
      Specifies the amount of time, in minutes, this device has to finish execution of this job. The timeout interval can be anywhere between 1 minute and 7 days (1 to 10080 minutes). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the job. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The time when the job was created, in ISO 8601 date-time format. Computed by AWS after `ship`.
</ResponseField>

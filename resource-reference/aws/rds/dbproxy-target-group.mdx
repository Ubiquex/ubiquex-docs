`aws_rds_dbproxy_target_group` configures a real connection-pooling and failover behavior for the specific `aws_rds_dbcluster` or instances an `aws_rds_dbproxy` routes to.

## Example

    	ubx.Main(ubx.Stack("payments", func() {

    			TargetGroupName:                 "example-target-group-name",

## Input properties

<ResponseField name="connection_pool_configuration_info" type="object">
  Configures the connection pool for the DB proxy target group, including maximum connections percentage, maximum idle connections percentage, connection borrow timeout, and session pinning filters. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="connection_borrow_timeout" type="number">
      The number of seconds for a proxy to wait for a connection to become available in the connection pool. Optional.
    </ResponseField>
    <ResponseField name="init_query" type="string">
      One or more SQL statements for the proxy to run when opening each new database connection. Optional.
    </ResponseField>
    <ResponseField name="max_connections_percent" type="number">
      The maximum size of the connection pool for each target in a target group. Optional.
    </ResponseField>
    <ResponseField name="max_idle_connections_percent" type="number">
      Controls how actively the proxy closes idle database connections in the connection pool. Optional.
    </ResponseField>
    <ResponseField name="session_pinning_filters" type="list(string)">
      Each item in the list represents a class of SQL operations that normally cause all later statements in a session using a proxy to be pinned to the same underlying database connection. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dbcluster_identifiers" type="list(string)">
  A list of identifiers of Aurora DB clusters that this RDS Proxy target group is associated with, enabling the proxy to route database connections to the specified clusters. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbinstance_identifiers" type="list(string)">
  Specifies the list of identifiers for the RDS DB instances that are associated with this DB proxy target group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbproxy_name" type="string" required>
  The identifier for the proxy. Required.
</ResponseField>

<ResponseField name="target_group_name" type="string" required>
  The identifier for the DBProxyTargetGroup Required.
</ResponseField>

## Output properties

<ResponseField name="target_group_arn" type="string">
  The Amazon Resource Name (ARN) representing the target group. Computed by AWS after `ship`.
</ResponseField>

`aws_rds_dbproxy` creates a real, fully managed connection pooler in front of one or more `aws_rds_dbinstance`s or an `aws_rds_dbcluster`, absorbing bursts of application connections without exhausting the database's own native connection limit.

## Example

    ```go
    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(rds.Dbproxy, "example", rds.DbproxyConfig{
    			DbproxyName:         "example-dbproxy-name",
    			EngineFamily:        "example",
    			RoleArn:             "arn:aws:iam::123456789012:policy/example",
    			VpcSubnetIds:        []string{"example"},
    			Auth:                []map[string]any{{"auth_scheme": "example"}},
    			DebugLogging:        true,
    			DefaultAuthScheme:   "example",
    			EndpointNetworkType: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="auth" type="list(object)">
  The authorization mechanism that the proxy uses. Optional.
  <Expandable title="properties">
    <ResponseField name="auth_scheme" type="string">
      Specifies the authentication scheme the RDS proxy uses when connecting to the database engine, such as SECRETS for AWS Secrets Manager-based credentials. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="client_password_auth_type" type="string">
      Specifies the password authentication method the DB proxy uses for client connections, such as MYSQL_NATIVE_PASSWORD or MYSQL_CACHING_SHA2_PASSWORD for MySQL, or POSTGRES_SCRAM_SHA_256 for PostgreSQL, enabling compatibility with the client's password hashing scheme. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="description" type="string">
      A user-supplied description for this authentication entry, helping identify the purpose of the IAM role or secret used to connect to the DB proxy. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="iamauth" type="string">
      Indicates whether IAM authentication is required or disabled for connections to the DB proxy using this authentication configuration, with allowed values 'REQUIRED' or 'DISABLED'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      Specifies the Amazon Resource Name (ARN) of the AWS Secrets Manager secret that stores the database user credentials used by this auth configuration for the RDS proxy. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dbproxy_name" type="string" required>
  The identifier for the proxy. This name must be unique for all proxies owned by your AWS account in the specified AWS Region. Required.
</ResponseField>

<ResponseField name="debug_logging" type="bool">
  Whether the proxy includes detailed information about SQL statements in its logs. Optional.
</ResponseField>

<ResponseField name="default_auth_scheme" type="string">
  The default authentication scheme that the proxy uses for client connections to the proxy and connections from the proxy to the underlying database. Optional.
</ResponseField>

<ResponseField name="endpoint_network_type" type="string">
  The network type of the DB proxy endpoint. The network type determines the IP version that the proxy endpoint supports. Optional.
</ResponseField>

<ResponseField name="engine_family" type="string" required>
  The kinds of databases that the proxy can connect to. Required.
</ResponseField>

<ResponseField name="idle_client_timeout" type="number">
  The number of seconds that a connection to the proxy can be inactive before the proxy disconnects it. Optional.
</ResponseField>

<ResponseField name="require_tls" type="bool">
  A Boolean parameter that specifies whether Transport Layer Security (TLS) encryption is required for connections to the proxy. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) of the IAM role that the proxy uses to access secrets in AWS Secrets Manager. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An optional set of key-value pairs to associate arbitrary data of your choosing with the proxy. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag attached to the RDS DB proxy, used for organizing and identifying the resource (e.g., by environment or cost center). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_connection_network_type" type="string">
  The network type that the proxy uses to connect to the target database. The network type determines the IP version that the proxy uses for connections to the database. Optional.
</ResponseField>

<ResponseField name="vpc_security_group_ids" type="list(string)">
  VPC security group IDs to associate with the new proxy. Optional.
</ResponseField>

<ResponseField name="vpc_subnet_ids" type="list(string)" required>
  VPC subnet IDs to associate with the new proxy. Required.
</ResponseField>

## Output properties

<ResponseField name="dbproxy_arn" type="string">
  The Amazon Resource Name (ARN) for the proxy. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The endpoint that you can use to connect to the proxy. You include the endpoint value in the connection string for a database client application. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_id" type="string">
  VPC ID to associate with the new DB proxy. Computed by AWS after `ship`.
</ResponseField>

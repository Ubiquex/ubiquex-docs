---
title: "aws_db_subnet_group"
description: "The real set of subnets an RDS instance is allowed to live in."
---

`aws_db_subnet_group` names a real, specific set of subnets, spanning
at least two availability zones, that an RDS instance is placed into.
Every `aws_db_instance` references one, by name.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import db "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/db"

    subnetIds := []string{publicA.Field("id"), publicB.Field("id")}

    ubx.Resource(db.SubnetGroup, "db", db.SubnetGroupConfig{
        Name:      "payments-db-subnets",
        SubnetIds: subnetIds,
    })
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { SubnetGroup } from "jsr:@ubx/sdk-aws/aws/db/subnet_group";

    resource(SubnetGroup, "db", {
      name: "payments-db-subnets",
      subnetIds: [publicA.id, publicB.id],
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.aws.db import SubnetGroup, SubnetGroupConfig

    ubx.resource(SubnetGroup, "db", SubnetGroupConfig(
        name="payments-db-subnets",
        subnet_ids=[public_a.id, public_b.id],
    ))
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Create a DB subnet group called "payments-db-subnets" spanning
    the public-a and public-b subnets.
    ```
  </Tab>
</Tabs>

## Input properties

<ResponseField name="name" type="string">
  The subnet group's own name. Conflicts with `name_prefix`.
</ResponseField>

<ResponseField name="name_prefix" type="string">
  A prefix, with a generated suffix appended. Conflicts with `name`.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  Real subnet IDs, spanning at least two availability zones.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the subnet group.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Same value as `name`.
</ResponseField>

<ResponseField name="arn" type="string">
  The subnet group's real ARN, computed, known only after ship.
</ResponseField>

---
title: "aws_db_instance"
description: "A managed relational database instance."
---

`aws_db_instance` provisions a real, managed RDS instance, Postgres,
MySQL, or any other real RDS-supported engine.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import db "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/db"

    pw := ubx.Secret("aws_secrets_manager", "db-password")

    ubx.Resource(db.Instance, "db", db.InstanceConfig{
        Engine:           "postgres",
        InstanceClass:    "db.t3.small",
        AllocatedStorage: 20,
        DbName:           "payments",
        Username:         "payments_admin",
        Password:         pw,
    })
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Instance } from "jsr:@ubx/sdk-aws/aws/db/instance";
    import { secret } from "@ubx/sdk";

    const pw = secret("aws_secrets_manager", "db-password");

    resource(Instance, "db", {
      engine: "postgres",
      instanceClass: "db.t3.small",
      allocatedStorage: 20,
      dbName: "payments",
      username: "payments_admin",
      password: pw,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.db import Instance, InstanceConfig

    pw = ubx.secret("aws_secrets_manager", "db-password")

    ubx.resource(Instance, "db", InstanceConfig(
        engine="postgres",
        instance_class="db.t3.small",
        allocated_storage=20,
        db_name="payments",
        username="payments_admin",
        password=pw,
    ))
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Provision a Postgres database for payments, small instance,
    20GB storage.
    ```
  </Tab>
</Tabs>

## Input properties

<ResponseField name="engine" type="string" required>
  The real database engine: `postgres`, `mysql`, `mariadb`, and others.
</ResponseField>

<ResponseField name="engine_version" type="string">
  A specific engine version. Defaults to the latest supported by AWS.
</ResponseField>

<ResponseField name="instance_class" type="string" required>
  The real instance size, e.g. `db.t3.small`.
</ResponseField>

<ResponseField name="allocated_storage" type="number" required>
  Storage size, in GB.
</ResponseField>

<ResponseField name="storage_type" type="string" default="gp2">
  `gp2`, `gp3`, `io1`, or `standard`.
</ResponseField>

<ResponseField name="db_name" type="string">
  The name of the real, initial database created inside the instance.
</ResponseField>

<ResponseField name="username" type="string" required>
  The real master username.
</ResponseField>

<ResponseField name="password" type="string" required>
  The real master password. Always a `$secret` reference in practice,
  never a literal.
</ResponseField>

<ResponseField name="multi_az" type="bool" default="false">
  Real, automatic failover to a standby in a second availability zone.
</ResponseField>

<ResponseField name="publicly_accessible" type="bool" default="false">
  Whether the instance gets a real, public endpoint.
</ResponseField>

<ResponseField name="vpc_security_group_ids" type="list(string)">
  Real security group IDs controlling network access.
</ResponseField>

<ResponseField name="db_subnet_group_name" type="string">
  Which real subnet group the instance is placed into.
</ResponseField>

<ResponseField name="backup_retention_period" type="number" default="7">
  How many days of real, automatic backups are retained.
</ResponseField>

<ResponseField name="skip_final_snapshot" type="bool" default="false">
  Skip taking a real, final snapshot on destroy.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The instance's own real identifier.
</ResponseField>

<ResponseField name="arn" type="string">
  The instance's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The real connection endpoint, `address:port`.
</ResponseField>

<ResponseField name="address" type="string">
  The real hostname, without the port.
</ResponseField>

<ResponseField name="port" type="number">
  The real port the engine listens on.
</ResponseField>

<ResponseField name="status" type="string">
  The instance's real, current lifecycle status.
</ResponseField>

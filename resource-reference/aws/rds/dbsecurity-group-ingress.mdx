title: "aws_rds_dbsecurity_group_ingress"
description: "`aws_rds_dbsecurity_group_ingress` added a real ingress rule to an `aws_rds_dbsecurity_group`."
---

Like its parent resource, this targets the EC2-Classic network model, which AWS fully retired on August 15, 2023, so it has no functioning target left to configure.

## Input properties

<ResponseField name="cidrip" type="string">
  The CIDR IP range (in the form x.x.x.x/x) that is authorized to access instances in the DB security group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbsecurity_group_name" type="string" required>
  The name of the DB security group to which this ingress rule is added. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_id" type="string">
  Specifies the ID of the EC2 security group whose traffic is authorized for ingress to the associated RDS DB security group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_name" type="string">
  The name of the EC2 security group to authorize for ingress to the RDS DB security group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ec2_security_group_owner_id" type="string">
  The AWS account ID of the owner of the EC2 security group referenced by the EC2SecurityGroupName property, used when the security group belongs to a different AWS account. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Computed by AWS after `ship`.
</ResponseField>

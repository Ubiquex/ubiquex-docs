## Input properties

<ResponseField name="dbinstance_identifier" type="string" required>
  The identifier of the DB instance that you want to create the snapshot of. Required.
</ResponseField>

<ResponseField name="dbsnapshot_identifier" type="string" required>
  The identifier for the DB snapshot. Must contain from 1 to 255 letters, numbers, or hyphens. First character must be a letter. Can't end with a hyphen or contain two consecutive hyphens. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to be assigned to the DB snapshot. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the RDS DB snapshot, used to assign metadata for resource identification, cost tracking, and IAM-based access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag applied to this RDS DB snapshot, providing arbitrary metadata to classify or manage the snapshot. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="allocated_storage" type="number">
  The allocated storage size in gibibytes (GiB). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="availability_zone" type="string">
  The name of the Availability Zone the DB instance was located in at the time of the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="dbi_resource_id" type="string">
  The identifier for the source DB instance, which is unique to an AWS Region. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="dbsnapshot_arn" type="string">
  The Amazon Resource Name (ARN) for the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="encrypted" type="bool">
  Indicates whether the DB snapshot is encrypted. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="engine" type="string">
  The name of the database engine. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The version of the database engine. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="iamdatabase_authentication_enabled" type="bool">
  Indicates whether mapping of AWS IAM accounts to database accounts is enabled. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="instance_create_time" type="string">
  The time when the DB instance was created, in UTC. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="iops" type="number">
  The Provisioned IOPS value of the DB instance at the time of the snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  If Encrypted is true, the AWS KMS key identifier for the encrypted DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="license_model" type="string">
  License model information for the restored DB instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="master_username" type="string">
  The master username for the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="option_group_name" type="string">
  The option group name for the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="original_snapshot_create_time" type="string">
  The time of the CreateDBSnapshot operation in UTC. Doesn't change when the snapshot is copied. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="port" type="number">
  The port that the database engine was listening on at the time of the snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="snapshot_create_time" type="string">
  The time when the snapshot was taken, in UTC. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="snapshot_type" type="string">
  The type of the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of this DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="storage_throughput" type="number">
  The storage throughput for the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="storage_type" type="string">
  The storage type associated with the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_id" type="string">
  The VPC ID associated with the DB snapshot. Computed by AWS after `ship`.
</ResponseField>

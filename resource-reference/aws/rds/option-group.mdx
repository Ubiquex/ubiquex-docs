title: "aws_rds_option_group"
description: "`aws_rds_option_group` defines a real set of database engine options..."

`aws_rds_option_group` defines a real set of database engine options, such as Oracle's native network encryption or SQL Server's Transparent Data Encryption, that can be enabled on an `aws_rds_dbinstance` beyond what standard engine parameters cover.

## Example

    func main() {

    			OptionGroupName:        "example-option-group-name",

    		})
    	}))
    }

## Properties

<ResponseField name="engine_name" type="string" required>
  Specifies the name of the engine that this option group should be associated with. Valid Values: + ``mariadb`` + ``mysql`` + ``oracle-ee`` + ``oracle-ee-cdb`` + ``oracle-se2`` + ``oracle-se2-cdb`` + ``postgres`` + ``sqlserver-ee`` + ``sqlserver-se`` + ``sqlserver-ex`` + ``sqlserver-web`` Required.
</ResponseField>

<ResponseField name="major_engine_version" type="string" required>
  Specifies the major version of the engine that this option group should be associated with. Required.
</ResponseField>

<ResponseField name="option_configurations" type="list(object)">
  A list of all available options for an option group. Optional.
  <Expandable title="properties">
    <ResponseField name="dbsecurity_group_memberships" type="list(string)">
      Specifies the names of DB security groups that are allowed to use the option in this option configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="option_name" type="string">
      The name of the option to be enabled in the RDS option group, such as 'MEMCACHED' or 'IAM'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="option_settings" type="list(object)">
      A list of key-value settings that configure the selected option for the DB engine, with each setting containing a Name and a Value. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name of an option setting, which identifies the specific engine parameter to configure within the corresponding option configuration for the RDS option group. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The value of a key-value option setting that tunes the behavior of the option within the RDS option group, where the setting's name (the 'name' field) determines what this value means (for example, a timeout or a port number). Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="option_version" type="string">
      Specifies the version of the option to apply, when multiple versions are available for that option in the RDS option group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="port" type="number">
      Specifies the port number on which the option (such as Oracle Enterprise Manager) communicates with the database. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpc_security_group_memberships" type="list(string)">
      Provides a list of VPC security group IDs that are associated with an individual option configuration, governing network access for the option within the VPC. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="option_group_description" type="string" required>
  The description of the option group. Required.
</ResponseField>

<ResponseField name="option_group_name" type="string">
  The name of the option group to be created. Constraints: + Must be 1 to 255 letters, numbers, or hyphens + First character must be a letter + Can't end with a hyphen or contain two consecutive hyphens Example: ``myoptiongroup`` If you don't specify a value for ``OptionGroupName`` property, a name is automatically created for the option group. This value is stored as a lowercase string. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the option group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag assigned to the option group, used to categorize or identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

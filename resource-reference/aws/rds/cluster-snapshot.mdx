## Input properties

<ResponseField name="dbcluster_identifier" type="string" required>
  The identifier of the DB cluster to create a snapshot for. Required.
</ResponseField>

<ResponseField name="dbcluster_snapshot_identifier" type="string" required>
  The identifier for the DB cluster snapshot. Must contain from 1 to 63 letters, numbers, or hyphens. First character must be a letter. Can't end with a hyphen or contain two consecutive hyphens. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to be assigned to the DB cluster snapshot. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to this RDS cluster snapshot, used for organizing, identifying, and managing the snapshot within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key assigned to the RDS cluster snapshot, used for resource categorization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="allocated_storage" type="number">
  The allocated storage size of the DB cluster snapshot in gibibytes (GiB). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="availability_zones" type="list(string)">
  The list of Availability Zones where instances in the DB cluster snapshot can be restored. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="cluster_create_time" type="string">
  The time when the DB cluster was created, in Universal Coordinated Time (UTC). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="db_cluster_resource_id" type="string">
  The resource ID of the DB cluster that this DB cluster snapshot was created from. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="dbcluster_snapshot_arn" type="string">
  The Amazon Resource Name (ARN) for the DB cluster snapshot. Computed by AWS after `ship`.
</ResponseField>

</ResponseField>

<ResponseField name="engine_mode" type="string">

</ResponseField>

<ResponseField name="engine_version" type="string">

</ResponseField>

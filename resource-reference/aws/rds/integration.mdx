`aws_rds_integration` creates a real, zero-ETL integration that continuously replicates an `aws_rds_dbcluster`'s data into Amazon Redshift, so it can be queried for analytics within seconds of being written without a separate extract-load pipeline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rds "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/rds"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own integration"})

    		ubx.Resource(rds.Integration, "example", rds.IntegrationConfig{
    			SourceArn:                   "arn:aws:iam::123456789012:policy/example",
    			TargetArn:                   "arn:aws:iam::123456789012:policy/example",
    			AdditionalEncryptionContext: "example",
    			DataFilter:                  "example",
    			Description:                 "Managed by ubx.",
    			IntegrationName:             "example-integration-name",
    			KmskeyId:                    "example",
    			Tags:                        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  An optional set of non-secret key -- value pairs that contains additional contextual information about the data. Optional.
</ResponseField>

<ResponseField name="data_filter" type="string">
  Data filters for the integration. These filters determine which tables from the source database are sent to the target Amazon Redshift data warehouse. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the integration. Optional.
</ResponseField>

<ResponseField name="integration_name" type="string">
  The name of the integration. Optional.
</ResponseField>

<ResponseField name="kmskey_id" type="string">
  The AWS Key Management System (AWS KMS) key identifier for the key to use to encrypt the integration. If you don't specify an encryption key, RDS uses a default AWS owned key. Optional.
</ResponseField>

<ResponseField name="source_arn" type="string" required>
  The Amazon Resource Name (ARN) of the database to use as the source for replication. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags. For more information, see [Tagging Amazon RDS Resources](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_Tagging.html) in the *Amazon RDS User Guide.*. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a resource tag attached to the AWS RDS integration, used to categorize or identify the integration for cost allocation and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_arn" type="string" required>
  The ARN of the Redshift data warehouse to use as the target for replication. Required.
</ResponseField>

## Output properties

<ResponseField name="create_time" type="string">
  The time the integration was created, in ISO 8601 format (e.g., 2023-01-01T00:00:00Z). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="integration_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this RDS integration, returned by AWS after creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

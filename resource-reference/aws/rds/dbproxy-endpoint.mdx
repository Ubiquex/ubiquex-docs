`aws_rds_dbproxy_endpoint` adds a real additional, separately addressable endpoint to an `aws_rds_dbproxy`, letting different applications or read/write splits reach the same proxy through different connection strings.

## Input properties

<ResponseField name="dbproxy_endpoint_name" type="string" required>
  The identifier for the DB proxy endpoint. This name must be unique for all DB proxy endpoints owned by your AWS account in the specified AWS Region. Required.
</ResponseField>

<ResponseField name="dbproxy_name" type="string" required>
  The identifier for the proxy. This name must be unique for all proxies owned by your AWS account in the specified AWS Region. Required.
</ResponseField>

<ResponseField name="endpoint_network_type" type="string">
  The network type of the DB proxy endpoint. The network type determines the IP version that the proxy endpoint supports. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An optional set of key-value pairs to associate arbitrary data of your choosing with the DB proxy endpoint. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag assigned to the RDS DB Proxy endpoint for identification and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_role" type="string">
  A value that indicates whether the DB proxy endpoint can be used for read/write or read-only operations. Optional.
</ResponseField>

<ResponseField name="vpc_security_group_ids" type="list(string)">
  VPC security group IDs to associate with the new DB proxy endpoint. Optional.
</ResponseField>

<ResponseField name="vpc_subnet_ids" type="list(string)" required>
  VPC subnet IDs to associate with the new DB proxy endpoint. Required.
</ResponseField>

## Output properties

<ResponseField name="dbproxy_endpoint_arn" type="string">
  The Amazon Resource Name (ARN) for the DB proxy endpoint. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The endpoint that you can use to connect to the DB proxy. You include the endpoint value in the connection string for a database client application. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="is_default" type="bool">
  A value that indicates whether this endpoint is the default endpoint for the associated DB proxy. Default DB proxy endpoints always have read/write capability. Other endpoints that you associate with the DB proxy can be either read/write or read-only. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_id" type="string">
  VPC ID to associate with the new DB proxy endpoint. Computed by AWS after `ship`.
</ResponseField>

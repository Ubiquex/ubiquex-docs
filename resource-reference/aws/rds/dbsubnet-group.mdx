`aws_rds_dbsubnet_group` defines a real set of VPC subnets that an `aws_rds_dbinstance` or `aws_rds_dbcluster` is allowed to place its network interfaces into.

## Input properties

<ResponseField name="dbsubnet_group_description" type="string" required>
  The description for the DB subnet group. Required.
</ResponseField>

<ResponseField name="dbsubnet_group_name" type="string">
  The name for the DB subnet group. This value is stored as a lowercase string. Constraints: + Must contain no more than 255 letters, numbers, periods, underscores, spaces, or hyphens. + Must not be default. + First character must be a letter. Example: ``mydbsubnetgroup`` Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The EC2 Subnet IDs for the DB subnet group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the DB subnet group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.

    <ResponseField name="value" type="string">

  </Expandable>
</ResponseField>

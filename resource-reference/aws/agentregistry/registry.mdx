---
title: "aws_agent_registry_registry"
description: "`aws_agent_registry_registry` creates a private, governed catalog for discovering agents, tools, skills, and MCP servers inside Bedrock AgentCore."
---

It's the container that org-wide publishing and discovery of these resources happens through, rather than each team maintaining its own ad hoc list.

## Example

    ```go

    import (
    	agentregistry "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/agentregistry"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="approval_configuration" type="object">
  Configuration for the registry's record approval workflow. Optional.
  <Expandable title="properties">
    <ResponseField name="auto_approval_rules" type="list(string)">
      The rules that determine which registry records are automatically approved on submission. When omitted or empty, submitted records require manual review. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="authorizer_type" type="string">
  The type of authorizer that controls how consumers access the registry's search and MCP invoke operations. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the registry. Optional.
</ResponseField>

<ResponseField name="discovery_configuration" type="object">
  Discovery configuration for the registry. Controls how consumers are authorized to search the registry and invoke its MCP endpoint. Optional.
  <Expandable title="properties">
    <ResponseField name="authorizer_configuration" type="object">
      The authorizer configuration for the registry. This is a union - specify exactly one member. Optional.
      <Expandable title="properties">
        <ResponseField name="custom_jwtauthorizer" type="object" required>
          Configuration for a custom JWT authorizer that validates inbound bearer tokens against an OpenID Connect identity provider. Required.
          <Expandable title="properties">
            <ResponseField name="allowed_audience" type="list(string)">
              The audience values accepted during JWT validation. Optional.
            </ResponseField>
            <ResponseField name="allowed_clients" type="list(string)">
              The client identifiers accepted during JWT validation. Optional.
            </ResponseField>
            <ResponseField name="allowed_scopes" type="list(string)">
              The scopes accepted during JWT validation. Optional.
            </ResponseField>
            <ResponseField name="custom_claims" type="list(object)">
              Additional custom claim validations applied to the inbound JWT. Optional.
              <Expandable title="properties">
                <ResponseField name="authorizing_claim_match_value" type="object">
                  Optional; if omitted, computed by AWS.
                  <Expandable title="properties">
                    <ResponseField name="claim_match_operator" type="string">
                      Optional; if omitted, computed by AWS.
                    </ResponseField>
                    <ResponseField name="claim_match_value" type="object">
                      Specifies the expected value that the custom JWT claim must equal in order for the custom JWT authorizer to authorize a request, as part of the authorizing claim match value configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
                      <Expandable title="properties">
                        <ResponseField name="match_value_string" type="string">
                          Optional; if omitted, computed by AWS.
                        </ResponseField>
                        <ResponseField name="match_value_string_list" type="list(string)">
                          Optional; if omitted, computed by AWS.
                        </ResponseField>
                      </Expandable>
                    </ResponseField>
                  </Expandable>
                </ResponseField>
                <ResponseField name="inbound_token_claim_name" type="string">
                  The name of the claim in the incoming JWT token that the custom authorizer extracts to evaluate as a custom claim for access control decisions. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="inbound_token_claim_value_type" type="string">
                  Optional; if omitted, computed by AWS.
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="discovery_url" type="string" required>
              The OpenID Connect discovery URL used to retrieve the identity provider's metadata and signing keys. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the registry. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the registry. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

  The timestamp when the registry was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="registry_arn" type="string">
  The Amazon Resource Name (ARN) of the registry. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="registry_id" type="string">
  The unique identifier of the registry. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the registry. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp when the registry was last updated. Computed by AWS after `ship`.
</ResponseField>

`aws_resilience_hub_v2_user_journey` describes a real, critical business path, the sequence of services and steps a user actually depends on, through an `aws_resilience_hub_v2_system`, letting resilience be assessed against outcomes that matter to users rather than only individual services in isolation.

    			Name:             "example",
    			SystemIdentifier: "example",
    			Description:      "Managed by ubx.",
    			PolicyArn:        "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }

## Input properties

<ResponseField name="description" type="string">
  The description of the user journey. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the user journey. Required.
</ResponseField>

<ResponseField name="policy_arn" type="string">
  The ARN of the resilience policy to associate with this user journey. Optional.
</ResponseField>

<ResponseField name="system_identifier" type="string" required>
  The system ARN or system ID that owns this user journey. Required.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The timestamp when the user journey was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp when the user journey was last updated. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="user_journey_id" type="string">
  The server-generated user journey ID. Computed by AWS after `ship`.
</ResponseField>

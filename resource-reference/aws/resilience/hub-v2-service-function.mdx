`aws_resilience_hub_v2_service_function` registers a real, specific function or component, a Lambda function, a container, within an `aws_resilience_hub_v2_service`, giving the next-generation Resilience Hub model visibility down to individual pieces of a deployable unit rather than only the unit as a whole.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resiliencehubv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/resiliencehubv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hub v2 service function"})

    		ubx.Resource(resiliencehubv2.ServiceFunction, "example", resiliencehubv2.ServiceFunctionConfig{
    			Criticality: "example",
    			Name:        "example",
    			ServiceArn:  "arn:aws:iam::123456789012:policy/example",
    			Description: "Managed by ubx.",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="criticality" type="string" required>
  The criticality of the service function. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the service function. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the service function. Required.
</ResponseField>

<ResponseField name="service_arn" type="string" required>
  The ARN of the parent service. Required.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The timestamp when the service function was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_count" type="number">
  The number of resources associated with this function. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="service_function_id" type="string">
  The server-generated service function ID. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="source" type="string">
  The source of the service function. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp when the service function was last updated. Computed by AWS after `ship`.
</ResponseField>

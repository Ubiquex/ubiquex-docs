`aws_resilience_hub_v2_system` represents a real business application under the next-generation AWS Resilience Hub model (relaunched May 2026), the top-level resource that `aws_resilience_hub_v2_service`s and `aws_resilience_hub_v2_user_journey`s are organized under and that an `aws_resilience_hub_v2_policy` is ultimately assessed against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	resiliencehubv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/resiliencehubv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hub v2 system"})

    		ubx.Resource(resiliencehubv2.System, "example", resiliencehubv2.SystemConfig{
    			Name:           "example",
    			Description:    "Managed by ubx.",
    			KmsKeyId:       "example",
    			SharingEnabled: true,
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the system. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The KMS key ID for encrypting system data. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the system. Required.
</ResponseField>

<ResponseField name="sharing_enabled" type="bool">
  Whether the system is enabled to be shared with other members of the Organization. Only applicable if the system owner is a management account or delegated admin. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags assigned to the system. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

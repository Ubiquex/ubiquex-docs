`aws_location_apikey` creates a real API key for authenticating requests to Amazon Location Service resources, maps, places, routes, trackers, an alternative to IAM credentials introduced for Location Service in January 2024 for simpler client-side and mobile use.

## Example

    			ForceUpdate:  true,
    			NoExpiry:     true,

## Input properties

<ResponseField name="description" type="string">
  An optional user-provided description that annotates or identifies the API key in AWS Location Service. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="expire_time" type="string">
  The datetime value in ISO 8601 format. The timezone is always UTC. (YYYY-MM-DDThh:mm:ss.sssZ) Optional.
</ResponseField>

<ResponseField name="force_delete" type="bool">
  Controls whether the API key can be deleted even when it is still referenced by AWS Location Service resources such as trackers or geofences. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="force_update" type="bool">
  When true, forces the update of the API key so that you can modify its attributes (such as description) without providing the existing restrictions in the update request. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="key_name" type="string" required>
  The name of the API key, which is used to identify and refer to the key in AWS Location Service resources and operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="no_expiry" type="bool">
  Controls whether the Amazon Location API key is exempt from expiration, where true disables expiration so the key never expires, and false (or omitted) allows the key to expire according to its expiration time. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="restrictions" type="object" required>
  Defines the access control rules for the API key, specifying which actions and resources are allowed or denied via the AllowActions, AllowResources, DenyActions, and DenyResources properties. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="allow_actions" type="list(string)" required>
      Specifies the list of action strings (such as geo:GetMap* or geo:SearchPlaceIndexForText) that the API key is permitted to invoke, defining the allowed Amazon Location Service operations for the API key. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="allow_android_apps" type="list(object)">
      List of Android application package names (application IDs) that are allowed to use the API key, defining the set of Android apps permitted to call AWS Location services with this key. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="certificate_fingerprint" type="string">
          The SHA-1 certificate fingerprint of an Android app that is allowed to use this AWS Location API key, as part of the restriction rules for Android applications. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="package" type="string">
          The Android application package name (e.g., com.example.myapp) that is allowed to use the API key when this restriction applies. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="allow_apple_apps" type="list(object)">
      This restriction specifies the list of Apple app bundle identifiers (for example, com.example.app) that are allowed to use the AWS Location API key when making requests. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bundle_id" type="string">
          The bundle identifier (bundle ID) of an Apple iOS app, such as com.example.myapp, that is explicitly allowed to use the API key when the allow_apple_apps restriction is applied. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="allow_referers" type="list(string)">
      List of allowed HTTP referer strings that can use this API key, restricting requests based on the originating website. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="allow_resources" type="list(string)" required>
      Specifies the list of AWS Location Service resource ARNs (or wildcard patterns) that this API key is allowed to access. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the AWS Location Service API key, used to categorize, filter, and control access to the key via IAM policies and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

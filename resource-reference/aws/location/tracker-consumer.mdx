`aws_location_tracker_consumer` links a real `aws_location_tracker` to an `aws_location_geofence_collection` as its consumer, the association that lets a tracker's incoming location updates be evaluated against that collection's geofences.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	location "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/location"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tracker consumer"})

    		ubx.Resource(location.TrackerConsumer, "example", location.TrackerConsumerConfig{
    			ConsumerArn: "arn:aws:iam::123456789012:policy/example",
    			TrackerName: "example-tracker-name",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="consumer_arn" type="string" required>
  The Amazon Resource Name (ARN) of the consumer resource (such as an EventBridge rule) that will receive location updates from the tracker. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tracker_name" type="string" required>
  The name of the Amazon Location Service tracker that the consumer (such as a geofence collection) is associated with, linking the consumer to receive position updates from that tracker. Required. **(AI-inferred)**
</ResponseField>

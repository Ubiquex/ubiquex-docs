`aws_location_place_index` creates a real place index resource in Amazon Location Service, used to search for and geocode addresses, points of interest, and other place data against a chosen data provider.

## Example

    import (
    	location "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/location"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own place index"})

    		ubx.Resource(location.PlaceIndex, "example", location.PlaceIndexConfig{
    			DataSource:              "example",
    			IndexName:               "example-index-name",
    			DataSourceConfiguration: map[string]any{"intended_use": "example"},
    			Description:             "Managed by ubx.",
    			PricingPlan:             "example",
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="data_source" type="string" required>
  The data provider (such as Esri, Here, or Grab) that supplies the location data for the place index and is required when creating the resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="data_source_configuration" type="object">
  Specifies the data storage options for the place index, including the intended use, such as single-use queries versus persistent storage of location data. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="intended_use" type="string">
      Sets the intended use of the place index to either SingleUse (geocode without storing results) or Storage (store results for later use), affecting how AWS Location Service handles query data. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  An optional user-supplied description of the place index, used to identify or note its purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="index_name" type="string" required>
  The custom name assigned to the place index, which must be unique within an AWS account and region and is used as the resource identifier in its ARN. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="pricing_plan" type="string">
  The pricing plan (RequestBasedUsage or MobileAssetTracking) for the place index, which determines the billing model for geocoding and reverse geocoding requests. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Amazon Location Service place index resource, used to identify and organize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value for a tag assigned to the Amazon Location Service place index, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

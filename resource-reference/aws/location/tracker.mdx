`aws_location_tracker` creates a real tracker resource in Amazon Location Service that ingests and stores the near-real-time location of devices, so their movement can be visualized on a map and evaluated against geofences.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	location "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/location"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tracker"})

    		ubx.Resource(location.Tracker, "example", location.TrackerConfig{
    			TrackerName:                   "example-tracker-name",
    			Description:                   "Managed by ubx.",
    			EventBridgeEnabled:            true,
    			KmsKeyEnableGeospatialQueries: true,
    			KmsKeyId:                      "example",
    			PositionFiltering:             "example",
    			PricingPlan:                   "example",
    			PricingPlanDataSource:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The optional description string for the AWS Location Service tracker, allowing users to attach a human-readable note to the resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="event_bridge_enabled" type="bool">
  Specifies whether the tracker publishes geofence and location events to Amazon EventBridge for downstream processing. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_enable_geospatial_queries" type="bool">
  When set to true, enables the tracker to encrypt and perform geospatial queries (e.g., search by polygon) using the specified AWS KMS key, rather than only simple positional updates. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The ID of an AWS KMS customer-managed key used to encrypt the tracker's location data; if not specified, an AWS-owned key encrypts the data. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="position_filtering" type="string">
  Specifies how incoming device position updates are filtered for storage, with valid values being TimeBased, DistanceBased, or AccuracyBased. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="pricing_plan" type="string">
  Specifies the pricing plan for the tracker, which determines the billing rate and feature set, with valid values such as 'RequestBasedUsage', 'MobileAssetTracking', and 'MobileAssetManagement'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="pricing_plan_data_source" type="string">

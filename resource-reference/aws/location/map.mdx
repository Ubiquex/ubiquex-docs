`aws_location_map` creates a real map resource in Amazon Location Service, backed by a chosen map style and data provider, for rendering interactive or static map imagery in an application.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	location "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/location"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own map"})

    		ubx.Resource(location.Map, "example", location.MapConfig{
    			Configuration: map[string]any{"style": "example"},
    			MapName:       "example-map-name",
    			Description:   "Managed by ubx.",
    			PricingPlan:   "example",
    			Tags:          []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="configuration" type="object" required>
  Specifies the map style (e.g., VectorEsriStreets or RasterEsriImagery) used by the map resource. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="custom_layers" type="list(string)">
      Specifies the list of custom layers to include in the map configuration, allowing additional data layers to be displayed on top of the base map style. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="political_view" type="string">
      Sets the ISO 3166-1 alpha-3 country code that determines the political view of the map, controlling which country's rendering of borders, labels, and contested territories is used. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="style" type="string" required>
      Specifies the map style (e.g., 'VectorEsriStreets' or 'VectorHereExplore') that determines the visual appearance and data provider for the AWS Location map resource. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Optional.
</ResponseField>

<ResponseField name="map_name" type="string" required>
  A user-defined name for the Amazon Location Service map resource, used to identify it within the AWS account and in API calls. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="pricing_plan" type="string">
  Specifies the pricing plan for the map, such as RequestBasedUsage, which determines how the map's usage is billed. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Location Service map, used to identify and categorize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag attached to an AWS Location Service map, used for cost allocation and resource identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

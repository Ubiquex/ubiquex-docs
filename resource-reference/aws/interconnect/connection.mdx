`aws_interconnect_connection` (AWS::DirectConnect::Interconnect) is a real, physical connection, over standard Ethernet fiber, between an AWS Direct Connect Partner's own network and a Direct Connect location, that the partner uses to provision and resell hosted Direct Connect connections to their own customers, rather than each customer needing a direct physical link to AWS themselves.

## Input properties

<ResponseField name="activation_key" type="string">
  The activation key for accepting a connection proposal from a partner CSP. Mutually exclusive with EnvironmentId. Optional.
</ResponseField>

<ResponseField name="attach_point" type="object" required>
  The logical attachment point in your AWS network where the managed connection will be connected. Required.
  <Expandable title="properties">
    <ResponseField name="arn" type="string">
      The ARN of the resource to attach to. Optional.
    </ResponseField>
    <ResponseField name="direct_connect_gateway" type="string">
      The ID of the Direct Connect Gateway to attach to. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="bandwidth" type="string">
  The bandwidth of the connection (e.g., 50Mbps, 1Gbps). Required when creating a connection through AWS. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the connection. Optional.
</ResponseField>

<ResponseField name="environment_id" type="string">
  The ID of the environment for the connection. Required when creating a connection through AWS. Mutually exclusive with ActivationKey. Optional.
</ResponseField>

<ResponseField name="remote_account" type="object">
  The remote account identifier for the connection. Required when creating a connection through AWS. Replaces RemoteOwnerAccount. Optional.
  <Expandable title="properties">
    <ResponseField name="identifier" type="string" required>
      The identifier of the remote account. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="remote_owner_account" type="string">
  Deprecated. Use RemoteAccount instead. The account ID of the remote owner. Required when creating a connection through AWS. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a key-value tag applied to the AWS Direct Connect connection (interconnect) resource, used to store arbitrary metadata for organizing and managing the connection. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="billing_tier" type="number">
  The billing tier for the connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="connection_id" type="string">
  The unique identifier for the connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="owner_account" type="string">
  The AWS account ID of the connection owner. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="provider" type="object">

  <Expandable title="properties">
    <ResponseField name="cloud_service_provider" type="string">
      The name of the cloud service provider. Optional.
    </ResponseField>
    <ResponseField name="last_mile_provider" type="string">
      The name of the last mile provider. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="shared_id" type="string">
  The shared identifier for the connection pairing. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The current state of the connection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type" type="string">
  The type of managed connection. Computed by AWS after `ship`.
</ResponseField>

`aws_io_tsite_wise_gateway` is real, on-premises software that collects data from industrial protocols, OPC-UA among them, and streams it into an `aws_io_tsite_wise_asset`'s properties, the actual bridge between a factory floor and SiteWise's own cloud-based asset model.

## Input properties

<ResponseField name="gateway_capability_summaries" type="list(object)">
  A list of gateway capability summaries that each contain a namespace and status. Optional.
  <Expandable title="properties">
    <ResponseField name="capability_configuration" type="string">
      The configuration JSON string for the gateway capability, which defines how the capability is configured (e.g., OPC-UA server endpoint settings) and is validated by the capability's schema. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="capability_namespace" type="string">
      The namespace that uniquely identifies this IoT SiteWise gateway capability, for example 'iotsitewise:gateway:opcua'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="gateway_name" type="string" required>
  A unique, friendly name for the gateway. Required.
</ResponseField>

<ResponseField name="gateway_platform" type="object" required>
  Contains a gateway's platform information. Required.
  <Expandable title="properties">
    <ResponseField name="greengrass_v2" type="object">
      Contains the CoreDeviceThingName of AWS IoT Greengrass Group V2 that the gateway runs on. Optional.
      <Expandable title="properties">
        <ResponseField name="core_device_operating_system" type="string">
          The operating system of the core device in AWS IoT Greengrass V2. Optional.
        </ResponseField>
        <ResponseField name="core_device_thing_name" type="string" required>
          The name of the CoreDevice in GreenGrass V2. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="siemens_ie" type="object">
      Contains the IotCoreThingName of AWS IoT Thing that the gateway runs on. Optional.
      <Expandable title="properties">
        <ResponseField name="iot_core_thing_name" type="string" required>
          The name of the IoT Core Thing. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="gateway_version" type="string">
  The version of the gateway you want to create. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the gateway. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key portion of a key-value tag applied to an AWS IoT SiteWise gateway, allowing categorization and filtering of gateway resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag key-value pair assigned to the AWS IoT SiteWise Gateway, used for metadata such as cost allocation, access control, and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="gateway_id" type="string">
  The ID of the gateway device. Computed by AWS after `ship`.
</ResponseField>

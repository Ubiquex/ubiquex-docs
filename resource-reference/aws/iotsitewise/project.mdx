`aws_io_tsite_wise_project` groups a real set of `aws_io_tsite_wise_asset`s and `aws_io_tsite_wise_dashboard`s inside an `aws_io_tsite_wise_portal`, organizing what a specific team or use case actually sees when they open the portal.

## Input properties

<ResponseField name="asset_ids" type="list(string)">
  The IDs of the assets to be associated to the project. Optional.
</ResponseField>

<ResponseField name="portal_id" type="string" required>
  The ID of the portal in which to create the project. Required.
</ResponseField>

<ResponseField name="project_description" type="string">
  A description for the project. Optional.
</ResponseField>

<ResponseField name="project_name" type="string" required>
  A friendly name for the project. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the project. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag, a user-defined label used to identify, organize, and manage AWS IoT SiteWise projects in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a tag key-value pair applied to the AWS IoT SiteWise project, used for resource organization, cost allocation, and IAM access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

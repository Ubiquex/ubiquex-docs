`aws_io_tsite_wise_portal` is a real, managed web application, with its own users and access control, through which SiteWise data actually gets visualized, the container an `aws_io_tsite_wise_project` and its dashboards live inside.

## Input properties

<ResponseField name="alarms" type="object">
  Contains the configuration information of an alarm created in an AWS IoT SiteWise Monitor portal. You can use the alarm to monitor an asset property and get notified when the asset property value is outside a specified range. Optional.
  <Expandable title="properties">
    <ResponseField name="alarm_role_arn" type="string">
      The ARN of the IAM role that allows the alarm to perform actions and access AWS resources and services, such as AWS IoT Events. Optional.
    </ResponseField>
    <ResponseField name="notification_lambda_arn" type="string">
      The ARN of the AWS Lambda function that manages alarm notifications. For more information, see Managing alarm notifications in the AWS IoT Events Developer Guide. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="notification_sender_email" type="string">
  The email address that sends alarm notifications. Optional.
</ResponseField>

<ResponseField name="portal_auth_mode" type="string">
  The service to use to authenticate users to the portal. Choose from SSO or IAM. You can't change this value after you create a portal. Optional.
</ResponseField>

<ResponseField name="portal_contact_email" type="string" required>
  The AWS administrator's contact email address. Required.
</ResponseField>

<ResponseField name="portal_description" type="string">
  A description for the portal. Optional.
</ResponseField>

<ResponseField name="portal_name" type="string" required>
  A friendly name for the portal. Required.
</ResponseField>

<ResponseField name="portal_type" type="string">
  The type of portal Optional.
</ResponseField>

<ResponseField name="portal_type_configuration" type="any">
  Map to associate detail of configuration related with a PortalType. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of a service role that allows the portal's users to access your AWS IoT SiteWise resources on your behalf. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the portal. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a key-value tag that you assign to the AWS IoT SiteWise portal to help organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="portal_arn" type="string">
  The ARN of the portal, which has the following format. Computed by AWS after `ship`.
</ResponseField>

</ResponseField>

  The ID of the portal. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="portal_start_url" type="string">

</ResponseField>

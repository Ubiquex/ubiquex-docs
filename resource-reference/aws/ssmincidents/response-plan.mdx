`aws_ssmincidents_response_plan` defines a real, pre-built response, which `aws_ssmcontacts_contact`s to engage, a runbook to launch, a chat channel to create, that Incident Manager executes automatically the moment a matching incident is declared, under an account's `aws_ssmincidents_replication_set`.

## Input properties

<ResponseField name="actions" type="list(object)">
  The list of actions. Optional.
  <Expandable title="properties">
    <ResponseField name="ssm_automation" type="object">
      Specifies the AWS Systems Manager (SSM) automation document to execute as an action when an incident is created, including the document name, the role assumed for execution, and any input parameters. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="document_name" type="string">
          The name of the SSM automation document (runbook) that the response plan executes as part of the automation action. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="document_version" type="string">
          Specifies the version of the SSM Automation document (runbook) to run when the response plan triggers this automation action. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="dynamic_parameters" type="list(object)">
          Defines dynamic parameter key-value pairs to pass to the SSM automation document run as part of the response plan, with each value dynamically derived from incident context (e.g., incident ARN) rather than a static value. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="key" type="string">
              In the SSM automation action of an Incident Manager response plan, the key in a dynamic_parameters mapping identifies the name of the automation document parameter whose value will be dynamically set from incident data. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="value" type="object">
              The runtime value assigned to a specific SSM automation document parameter, allowing the response plan to pass incident details or other dynamic values into the automation execution. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="variable" type="string">
                  Specifies the dynamic incident variable (such as an incident ARN or severity) that will be resolved at runtime and used as the value for this SSM automation document parameter. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="parameters" type="list(object)">
          Specifies the input parameters to pass to the SSM automation runbook when this response plan action is executed. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="key" type="string">
              The name of the parameter to pass to the SSM automation document when the response plan triggers the runbook. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="values" type="list(string)">
              The list of values to assign to the corresponding SSM automation document parameter when the response plan triggers the automation run. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="role_arn" type="string">
          The ARN of the IAM role that AWS Systems Manager Automation assumes when executing the automation runbook as part of this response plan's SSM automation action. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="target_account" type="string">
          Specifies which AWS account the SSM automation document should run in, either the account that was impacted by the incident (IMPACTED_ACCOUNT) or a different, specifically selected account (SPECIFIC_ACCOUNT). Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

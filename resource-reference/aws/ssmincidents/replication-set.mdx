`aws_ssmincidents_replication_set` creates the real, required Region-replication configuration that must exist before Incident Manager can be used in an account, replicating incident data across the chosen Regions for resilience during a regional outage.

## Input properties

<ResponseField name="deletion_protected" type="bool">
  Configures the ReplicationSet deletion protection. Optional.
</ResponseField>

<ResponseField name="regions" type="list(object)" required>
  The regions list specifies the AWS Regions in which incident records are replicated for this replication set, with each object defining a Region name and an optional customer-managed KMS key for encryption. Required. **(AI-inferred)**

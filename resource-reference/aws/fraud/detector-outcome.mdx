`aws_fraud_detector_outcome` defined a real possible result, approve, review, block, that an `aws_fraud_detector_detector`'s own business rules could return for an evaluated event. Closed to new customers along with the rest of Fraud Detector since November 7, 2025.

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    	}))
    }

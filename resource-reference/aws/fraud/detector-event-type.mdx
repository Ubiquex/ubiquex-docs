`aws_fraud_detector_event_type` defined the real structure, entity type, variables, labels, of one category of event, a login, a transaction, that an `aws_fraud_detector_detector` was configured to actually evaluate. Like the rest of Fraud Detector, closed to new customers since November 7, 2025.

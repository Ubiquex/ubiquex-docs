`aws_fraud_detector_detector` was the real, top-level Amazon Fraud Detector resource combining an `aws_fraud_detector_event_type`, a trained model, and business rules to actually score real-time fraud risk. Amazon Fraud Detector closed to new customers on November 7, 2025; existing customers can continue using it, with AWS pointing to Amazon SageMaker, AutoGluon, or AWS WAF Fraud Control for new fraud-detection work.

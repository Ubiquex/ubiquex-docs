`aws_pcs_compute_node_group` defines a real group of compute nodes, statically scaled login nodes or elastically scaled worker nodes, attached to an `aws_pcs_cluster`, the resource that actually runs submitted HPC jobs.

## Example

## Input properties

<ResponseField name="ami_id" type="string">
  The ID of the Amazon Machine Image (AMI) that AWS PCS uses to launch instances. If not provided, AWS PCS uses the AMI ID specified in the custom launch template. Optional.
</ResponseField>

<ResponseField name="cluster_id" type="string" required>
  The ID of the cluster of the compute node group. Required.
</ResponseField>

<ResponseField name="custom_launch_template" type="object" required>
  An Amazon EC2 launch template AWS PCS uses to launch compute nodes. Required.
  <Expandable title="properties">
    <ResponseField name="template_id" type="string">
      The ID of the EC2 launch template to use to provision instances. Optional.
    </ResponseField>
    <ResponseField name="version" type="string" required>
      The version of the EC2 launch template to use to provision instances. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="iam_instance_profile_arn" type="string" required>
  The Amazon Resource Name (ARN) of the IAM instance profile used to pass an IAM role when launching EC2 instances. The role contained in your instance profile must have pcs:RegisterComputeNodeGroupInstance permissions attached to provision instances correctly. Required.
</ResponseField>

<ResponseField name="instance_configs" type="list(object)" required>
  A list of EC2 instance configurations that AWS PCS can provision in the compute node group. Required.
  <Expandable title="properties">
    <ResponseField name="instance_type" type="string">
      Specifies the EC2 instance type (for example, `c5.large`) that the compute nodes in this instance configuration will use within the compute node group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name that identifies the compute node group. Optional.
</ResponseField>

<ResponseField name="node_lifecycle_actions" type="object">
  Custom scripts that run at defined points in a compute node's lifecycle. Optional.
  <Expandable title="properties">
    <ResponseField name="script_caching_policy" type="string">
      Controls whether lifecycle scripts are downloaded once at first boot (CACHE_ONCE) or re-downloaded on every reboot (REFRESH_ON_REBOOT). Defaults to CACHE_ONCE. Optional.
    </ResponseField>
    <ResponseField name="stages" type="object" required>
      The ordered scripts to run at each compute node lifecycle stage. Required.
      <Expandable title="properties">
        <ResponseField name="node_bootstrapped" type="list(object)">
          Scripts to run after the node is bootstrapped, once the PCS configuration phase completes and before slurmd starts. Optional.
          <Expandable title="properties">
            <ResponseField name="arguments" type="list(string)">
              The list of argument strings passed to the custom node lifecycle action script that runs when a compute node in the group completes its bootstrap process, allowing the bootstrap script to be parameterized with specific values. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="execution_policy" type="string">
              The execution policy for the node bootstrapped lifecycle stage, determining whether the compute node continues or fails if the bootstrap script exits with a non-zero code. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="name" type="string">
              Specifies the name of the node bootstrapped stage in the compute node group's lifecycle actions configuration, identifying this lifecycle stage uniquely. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="on_error" type="string">
              The script or command that AWS PCS runs on a compute node if the node bootstrapping lifecycle stage fails, allowing custom error handling such as logging or node cleanup in the compute node group. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="script_source" type="object">
              Specifies the source (such as an S3 location or URI) from which the bootstrap script is retrieved and executed on a compute node when it reaches the node bootstrapped lifecycle stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="checksum" type="string">
                  The checksum (e.g., SHA256) of the bootstrap script content in the script source, used to verify the integrity of the script during node bootstrapping in AWS PCS compute node groups. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="s3_version_id" type="string">
                  The version ID of the S3 object that supplies the bootstrap script for the node bootstrapped lifecycle stage, used to pin to a specific version of the script. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="script_location" type="string">
                  The Amazon S3 URI of the script that AWS PCS runs during the node bootstrapped stage of the compute node group's lifecycle actions. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="node_ready" type="list(object)">
          Scripts to execute when the node becomes ready (every boot). Optional.
          <Expandable title="properties">
            <ResponseField name="arguments" type="list(string)">
              The list of command-line arguments to pass to the script executed by the node_ready lifecycle action for compute nodes in this AWS PCS compute node group. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="execution_policy" type="string">
              Specifies whether the node-ready lifecycle action is mandatory or optional, controlling how failures of the action script are handled when a compute node transitions to the ready state. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="name" type="string">
              Optional; if omitted, computed by AWS.
            </ResponseField>
            <ResponseField name="on_error" type="string">
              Specifies the error-handling action to take when a node fails to reach the ready state during the node_ready lifecycle stage, with allowed values such as CONTINUE or FAIL, controlling whether the node is retained or removed. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="script_source" type="object">
              Defines the source of the script to execute when a compute node becomes ready, typically an S3 object reference that AWS PCS retrieves and runs as part of the lifecycle action. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="checksum" type="string">
                  The checksum (typically SHA256) used to validate the integrity of the script fetched from the script source before it is executed during the node-ready lifecycle stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="s3_version_id" type="string">
                  The version ID of the S3 object that holds the script to execute when a compute node reaches the ready lifecycle stage within AWS Parallel Computing Service. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="script_location" type="string">
                  Specifies the S3 URI or local filesystem path of the script to execute on compute nodes at the 'node ready' lifecycle stage. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="purchase_option" type="string">
  Specifies how EC2 instances are purchased on your behalf. AWS PCS supports On-Demand, Spot, Capacity Block, and Interruptible Capacity Reservation instances. For more information, see Instance purchasing options in the Amazon Elastic Compute Cloud User Guide. If you don't provide this option, it defaults to On-Demand. Optional.
</ResponseField>

<ResponseField name="scaling_configuration" type="object" required>
  Specifies the boundaries of the compute node group auto scaling. Required.
  <Expandable title="properties">
    <ResponseField name="max_instance_count" type="number" required>
      The upper bound of the number of instances allowed in the compute fleet. Required.
    </ResponseField>
    <ResponseField name="min_instance_count" type="number" required>
      The lower bound of the number of instances allowed in the compute fleet. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="slurm_configuration" type="object">
  Additional options related to the Slurm scheduler. Optional.
  <Expandable title="properties">
    <ResponseField name="scale_down_idle_time_in_seconds" type="number">
      The time before an idle node is scaled down. Optional.
    </ResponseField>
    <ResponseField name="slurm_custom_settings" type="list(object)">
      Additional Slurm-specific configuration that directly maps to Slurm settings. Optional.
      <Expandable title="properties">
        <ResponseField name="parameter_name" type="string">
          The name of a Slurm configuration parameter to apply to the compute node group's slurm_custom_settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="parameter_value" type="string">
          The value associated with a custom Slurm configuration parameter key for the compute node group, which overrides or augments the default Slurm configuration on the cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="spot_options" type="object">
  Additional configuration when you specify SPOT as the purchase option. Optional.
  <Expandable title="properties">
    <ResponseField name="allocation_strategy" type="string">
      The Amazon EC2 allocation strategy AWS PCS uses to provision EC2 instances. AWS PCS supports lowest price, capacity optimized, and price capacity optimized. If you don't provide this option, it defaults to price capacity optimized. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The list of subnet IDs where instances are provisioned by the compute node group. The subnets must be in the same VPC as the cluster. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  1 or more tags added to the resource. Each tag consists of a tag key and tag value. The tag value is optional and can be an empty string. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The unique Amazon Resource Name (ARN) of the compute node group. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="error_info" type="list(object)">
  The list of errors that occurred during compute node group provisioning. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="code" type="string">
      A machine-readable code that identifies the specific error encountered while AWS PCS was provisioning or managing this compute node group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="message" type="string">
      The message text that describes the error condition affecting the compute node group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="id" type="string">
  The generated unique ID of the compute node group. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The provisioning status of the compute node group. The provisioning status doesn't indicate the overall health of the compute node group. Computed by AWS after `ship`.
</ResponseField>

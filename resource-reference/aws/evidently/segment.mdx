`aws_evidently_segment` defined a real, named subset of users, by attribute, that an `aws_evidently_experiment` or `aws_evidently_launch` could target inside an `aws_evidently_project`. Discontinued along with the rest of CloudWatch Evidently on October 17, 2025.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	evidently "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/evidently"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own segment"})

    		ubx.Resource(evidently.Segment, "example", evidently.SegmentConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Pattern:     "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.evidently import Segment, SegmentConfig
    from ubx.aws.evidently.segment import Segment_Tags

    def describe():
        ubx.intent("example own segment")

        ubx.resource(Segment, "example", SegmentConfig(
            name="example",
            description="Managed by ubx.",
            pattern="example",
            tags=[Segment_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-supplied text description of the segment, used to clarify its purpose or contents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The user-defined name of the audience segment, used to identify it within Evidently experiments and launches. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="pattern" type="string">
  The JSON pattern that defines the conditions under which a user matches this segment, used to target audiences for Evidently experiments and launches. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the Evidently segment, used for metadata, resource organization, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Evidently segment. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

---
title: "aws_evidently_feature"
description: "`aws_evidently_feature` defined a real feature flag with its own variations inside an `aws_evidently_project`."
---

Like every other Evidently resource, it stopped being accessible when AWS discontinued the service on October 17, 2025.

## Input properties

<ResponseField name="default_variation" type="string">
  Specifies the variation used as the default for an Evidently feature when no targeting rules match or no other overrides apply. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of the Evidently feature, used to convey the feature's purpose or intended behavior to viewers in the console. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="entity_overrides" type="list(object)">
  Specifies a list of entity overrides, where each override assigns a specific variation to a given entity (such as a user or session) for this feature. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="entity_id" type="string">
      The unique identifier of the user or session for which this entity override sets a specific feature variation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="variation" type="string">
      The name of the variation to assign to the overridden entity in an entity override. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="evaluation_strategy" type="string">
  Determines whether the feature is evaluated as a feature flag using allocation rules (ALL_RULES) or as an experiment that exposes the feature to a percentage of users (AFFECTED_USERS). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the feature, which must be unique within the Evidently project and can contain only letters, numbers, underscores, and hyphens. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="project" type="string" required>
  The name or ARN of the Evidently project that this feature belongs to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key for a tag attached to the Evidently feature, enabling you to categorize and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Evidently feature, used to assign custom metadata for resource organization, cost allocation, and access control in AWS Evidently. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="variations" type="list(object)" required>
  Specifies the list of variations for the feature, where each variation defines a name and a value that the feature can serve to users, enabling A/B testing and experimentation. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="boolean_value" type="bool">
      In a feature variation, when the variation type is boolean, this field specifies the true/false value that is served for that variation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="double_value" type="number">
      The numeric double value assigned to this variation of the feature, used when the variation's value type is set to double. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="long_value" type="number">
      Sets the numeric (long) value for this feature variation, which Evidently returns as the variation's value when the feature is evaluated for a user or session. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="string_value" type="string">
      For a variation of the Evidently feature, this defines the string-typed value that is returned when the feature is evaluated and this variation is selected. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="variation_name" type="string">
      The user-defined name for a variation of the Evidently feature, used to reference this variation when defining traffic allocation or feature evaluation rules. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

  The Amazon Resource Name (ARN) uniquely identifying this Evidently feature in AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

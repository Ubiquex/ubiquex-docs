`aws_evidently_launch` gradually rolled out an `aws_evidently_feature`'s variations to an increasing percentage of real traffic inside an `aws_evidently_project`. Discontinued along with the rest of CloudWatch Evidently on October 17, 2025.

## Input properties

<ResponseField name="description" type="string">
  Provides an optional human-readable description of the launch to help identify its purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="execution_status" type="object">
  Configures the execution state of an Amazon CloudWatch Evidently launch by specifying a target status (such as RUNNING or CANCELLED) and an optional status reason, which is used when updating the launch resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="desired_state" type="string">
      Provide CANCELLED or COMPLETED as the launch desired state. Defaults to Completed if not provided. Optional.
    </ResponseField>
    <ResponseField name="reason" type="string">
      Provide a reason for stopping the launch. Defaults to empty if not provided. Optional.
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Provide START or STOP action to apply on a launch Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="groups" type="list(object)" required>
  Specifies the launch groups that define how traffic is allocated to feature variations in this Evidently launch. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      A human-readable description of the launch group, specifying the purpose or context of the traffic segment in the Evidently launch. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="feature" type="string">
      The name or ARN of the feature that this launch group uses to serve a variation to the assigned traffic. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="group_name" type="string">
      The name of a group in an AWS Evidently launch, which identifies a feature variation and the percentage of traffic allocated to that group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="variation" type="string">
      The name of the variation that this launch group is allocated, determining which feature variant is served to users in this group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metric_monitors" type="list(object)">
  This list specifies the CloudWatch metrics that Evidently monitors to evaluate the launch's performance, where each monitor defines the metric name, entity ID key, value key, event pattern, and unit label used to measure the launch's success. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="entity_id_key" type="string">
      For an AWS Evidently launch metric monitor, this specifies the event attribute name (e.g., `userId`) that identifies the entity the metric is measured for. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="event_pattern" type="string">
      The CloudWatch Events event pattern, specified as a JSON string, that defines which application events are counted for this metric monitor in an Evidently launch, used to extract metric values. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metric_name" type="string">
      The metric_name field is the human-readable name of a metric that the Evidently launch monitors, used by Evidently to identify the metric in console views and when reporting metric values. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="unit_label" type="string">
      The human-readable label that describes the unit of measurement for the metric being monitored by this metric monitor (for example, 'requests' or 'errors'). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value_key" type="string">
      The JSON path or key in the event payload that holds the numeric value used to evaluate the metric for the AWS Evidently launch's metric monitor. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Evidently launch. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="project" type="string" required>
  The name or ARN of the Evidently project in which this launch is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="randomization_salt" type="string">
  A string hashing salt that Evidently uses to compute deterministic assignment of evaluation units to variations, allowing you to change the randomization behavior of the launch. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="scheduled_splits_config" type="list(object)" required>
  A list of scheduled split configurations that define how traffic is allocated to each feature variation at specified start times, enabling a gradual time-based rollout for the launch. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="group_weights" type="list(object)">
      The group_weights list assigns a traffic weight to each launch group (variation) for the scheduled split, determining what percentage of user traffic that variation receives during that time segment. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="group_name" type="string">
          The name of the feature variation (group) to which the corresponding weight is assigned in this scheduled traffic split for the AWS Evidently launch. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="split_weight" type="number">
          Sets the proportion of traffic allocated to the corresponding variation group for a scheduled split in the Amazon CloudWatch Evidently launch. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="segment_overrides" type="list(object)">
      Configures traffic-split overrides for specific audience segments during a scheduled split, letting you direct different proportions of a segment's users to the launch's variations. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="evaluation_order" type="number">
          The order in which this segment override is evaluated relative to other segment overrides in the same scheduled split, with lower numbers evaluated first. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="segment" type="string">
          Specifies the name or ARN of the Evidently segment to which the override applies, enabling different traffic allocation or variation choices for users matching that segment during the launch step. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="weights" type="list(object)">
          Specifies the traffic percentage allocated to each feature variation for a given audience segment override in a scheduled split of the Evidently launch. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="group_name" type="string">
              In a segment override for a scheduled split, this value is the name of an existing launch group whose traffic allocation is being overridden by the associated split weight for that segment. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="split_weight" type="number">
              Sets the percentage of traffic from the segment that is allocated to a feature variation, where the collection of weights across variations determines the split for that segment override. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="start_time" type="string">
      The UTC timestamp that marks the start of this step in a scheduled split launch, after which the specified group weights apply. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">

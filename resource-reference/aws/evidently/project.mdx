`aws_evidently_project` was the top-level CloudWatch Evidently resource that an `aws_evidently_feature`, `aws_evidently_experiment`, `aws_evidently_launch`, and `aws_evidently_segment` all belonged to. AWS discontinued CloudWatch Evidently on October 17, 2025; the console and Evidently resources are no longer accessible, and AWS directs customers who need feature-flag and A/B-experiment capability to AWS AppConfig instead.

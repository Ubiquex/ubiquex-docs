title: "aws_evidently_experiment"
description: "`aws_evidently_experiment` ran a real A/B test..."
---

`aws_evidently_experiment` ran a real A/B test, splitting traffic across an `aws_evidently_feature`'s variations and measuring the effect on defined metrics, inside an `aws_evidently_project`. Discontinued along with the rest of CloudWatch Evidently on October 17, 2025.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	evidently "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/evidently"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own experiment"})

    		ubx.Resource(evidently.Experiment, "example", evidently.ExperimentConfig{
    			MetricGoals:       []map[string]any{{"desired_change": "example"}},
    			Name:              "example",
    			OnlineAbConfig:    map[string]any{"control_treatment_name": "example-control-treatment-name"},
    			Project:           "example",
    			Treatments:        []map[string]any{{"description": "example"}},
    			Description:       "Managed by ubx.",
    			RandomizationSalt: "example",
    			RemoveSegment:     true,
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx
    from ubx.aws.evidently import Experiment, ExperimentConfig
    from ubx.aws.evidently.experiment import Experiment_MetricGoals, Experiment_OnlineAbConfig, Experiment_Treatments

    def describe():
        ubx.intent("example own experiment")

        ubx.resource(Experiment, "example", ExperimentConfig(
            metric_goals=[Experiment_MetricGoals(desired_change="example")],
            name="example",
            online_ab_config=Experiment_OnlineAbConfig(control_treatment_name="example-control-treatment-name"),
            project="example",
            treatments=[Experiment_Treatments(description="example")],

            remove_segment=True,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="description" type="string">
  Provides an optional, human-readable description of the experiment to convey its purpose or context. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="metric_goals" type="list(object)" required>
  Metric goals define the success metrics of the experiment, each specifying the metric to monitor (via a metric name or a CloudWatch metric definition), the desired change direction (increase or decrease), and the entity ID and value extraction keys used to evaluate results from event data. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="desired_change" type="string">
      Specifies whether the experiment aims to increase or decrease the value of the metric, with allowed values of 'INCREASE' or 'DECREASE'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="entity_id_key" type="string">
      The key in the experiment event data that identifies the entity (e.g., user or session) for which the metric goal is evaluated. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="event_pattern" type="string">
      Defines the CloudWatch Events event pattern (as a JSON string) that selects which events Evidently counts for this metric goal in the experiment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metric_name" type="string">
      The name of the metric that this experiment goal tracks, typically the CloudWatch metric name used to evaluate experiment results. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="unit_label" type="string">
      The unit label is a human-readable label for the units of measurement associated with the metric goal (e.g., 'requests', 'users', 'conversions'), used for display in the Evidently console and experiment analysis. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value_key" type="string">
      The name of the field in the event data that Evidently reads to obtain the numeric value for the experiment's metric goal, which is the value the service measures for the goal. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the experiment, which must be unique within the project. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="online_ab_config" type="object" required>
  The online_ab_config object configures the online A/B experiment, specifying the control treatment name and the percentage of traffic allocated to each treatment variant. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="control_treatment_name" type="string">
      The name of the treatment that serves as the control group within the online A/B experiment, against which all other treatment variations are compared and measured. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="treatment_weights" type="list(object)">
      Defines the traffic allocation percentages for each treatment in the experiment, where each object maps a treatment name to a weight (0-100) representing the percentage of traffic to send to that treatment in the online AB experiment. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="split_weight" type="number">
          In an online AB experiment, split_weight is the proportion of traffic allocated to this treatment, expressed as an integer weight out of 100000 total (e.g., 10000 means 10%), and the weights across all treatments must sum to 100000. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="treatment" type="string">
          The name of the treatment in the experiment that this weight applies to, used to allocate traffic among treatments in the online AB configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="project" type="string" required>
  The name or ARN of the Evidently project that contains this experiment. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="randomization_salt" type="string">
  Sets the randomization salt used by Evidently to hash the entity ID, determining the variation assignment for a given user or entity in the experiment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="remove_segment" type="bool">
  When set to true during an update, removes the segment currently associated with the Evidently experiment, so the experiment no longer targets that audience segment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="running_status" type="object">
  RunningStatus is an object that lets you control the experiment's current lifecycle state, such as setting it to RUNNING to start the experiment or COMPLETED to stop it. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="analysis_complete_time" type="string">
      Provide the analysis Completion time for an experiment Optional.
    </ResponseField>
    <ResponseField name="desired_state" type="string">
      Provide CANCELLED or COMPLETED desired state when stopping an experiment Optional.
    </ResponseField>
    <ResponseField name="reason" type="string">
      Reason is a required input for stopping the experiment Optional.
    </ResponseField>
    <ResponseField name="status" type="string">
      Provide START or STOP action to apply on an experiment Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sampling_rate" type="number">
  The percentage (0-100) of the audience that is randomly allocated to the experiment, determining the proportion of incoming traffic that is subject to the experiment's treatment variants. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="segment" type="string">
  The name or ARN of an Evidently segment that restricts the experiment to a defined user audience; if omitted, the experiment runs on the full eligible population. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a key-value tag applied to the Evidently experiment, used for metadata and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="treatments" type="list(object)" required>
  Defines the list of treatments (variants) for the experiment, each specifying the feature to vary, a treatment name, and an optional description, which the Evidently service uses to split traffic and evaluate results. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      A human-readable description of the treatment, explaining its purpose or the variation it represents within the Evidently experiment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="feature" type="string">
      The name of the feature that this treatment applies to, which must reference an existing feature in the Evidently project. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="treatment_name" type="string">
      The name of a treatment (variation) in the Evidently experiment, used to identify the treatment among the experiment's variations and when viewing analysis results. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="variation" type="string">
      The name of the feature variation that this treatment uses in the experiment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the experiment, which uniquely identifies it in AWS Evidently. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

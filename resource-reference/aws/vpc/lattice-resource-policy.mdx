`aws_vpc_lattice_resource_policy` attaches a real resource-based policy to an `aws_vpc_lattice_service_network`, controlling which principals or accounts can associate their own VPCs or services with it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vpc "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/vpc"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lattice resource policy"})

    		ubx.Resource(vpc.LatticeResourcePolicy, "example", vpc.LatticeResourcePolicyConfig{
    			Policy:      "example",
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="policy" type="any" required>
  The JSON policy document that defines the permissions for the VPC Lattice resource, such as a service network or service, controlling which principals can access the resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The Amazon Resource Name (ARN) of the VPC Lattice resource (such as a service or service network) to which this resource policy is attached. Required. **(AI-inferred)**

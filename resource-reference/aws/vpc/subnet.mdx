---
title: "aws_subnet"
description: "A real IP address range inside a VPC, tied to one availability zone."
---

`aws_subnet` carves a real, smaller IP range out of a VPC's own CIDR
block, placed in one specific availability zone. Every real, networked
resource lives inside a subnet, never directly inside a VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import subnet "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/subnet"

    ubx.Resource(subnet.Subnet, "public-a", subnet.SubnetConfig{
        VpcId:            mainVpc.Field("id"),
        CidrBlock:        "10.0.1.0/24",
        AvailabilityZone: "us-east-1a",
    })
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="vpc_id" type="string" required>
  The real VPC this subnet belongs to.
</ResponseField>

<ResponseField name="cidr_block" type="string" required>
  This subnet's own, smaller IP range, in CIDR notation.
</ResponseField>

<ResponseField name="availability_zone" type="string">
  Which real AWS availability zone this subnet lives in.
</ResponseField>

<ResponseField name="map_public_ip_on_launch" type="bool" default="false">
  Whether instances launched here get a real public IP automatically.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The subnet's own real identifier.
</ResponseField>

<ResponseField name="arn" type="string">
  The subnet's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="availability_zone_id" type="string">
  The real, stable ID for this availability zone (unlike the name,
  consistent across accounts).
</ResponseField>

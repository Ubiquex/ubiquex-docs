---
title: "aws_vpc"
description: "An isolated virtual network."
---

`aws_vpc` creates a real, isolated virtual network, the real
foundation every other real networked resource, subnets, security
groups, route tables, gets placed inside.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import vpc "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/vpc"

    ubx.Resource(vpc.Vpc, "main", vpc.VpcConfig{
        CidrBlock: "10.0.0.0/16",
    })
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Vpc } from "jsr:@ubx/sdk-aws/aws/vpc/vpc";

    resource(Vpc, "main", {
      cidrBlock: "10.0.0.0/16",
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.aws.vpc import Vpc, VpcConfig

    ubx.resource(Vpc, "main", VpcConfig(
        cidr_block="10.0.0.0/16",
    ))
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Create a VPC called "main" with CIDR block 10.0.0.0/16.
    ```
  </Tab>
</Tabs>

## Input properties

<ResponseField name="cidr_block" type="string" required>
  The real IP address range for this VPC, in CIDR notation.
</ResponseField>

<ResponseField name="enable_dns_support" type="bool" default="true">
  Whether real DNS resolution works inside this VPC.
</ResponseField>

<ResponseField name="enable_dns_hostnames" type="bool" default="false">
  Whether instances get real, public DNS hostnames.
</ResponseField>

<ResponseField name="instance_tenancy" type="string" default="default">
  `default` (shared hardware) or `dedicated`.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The VPC's own real identifier.
</ResponseField>

<ResponseField name="arn" type="string">
  The VPC's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="default_route_table_id" type="string">
  The real, automatically-created default route table.
</ResponseField>

<ResponseField name="default_security_group_id" type="string">
  The real, automatically-created default security group.
</ResponseField>

<ResponseField name="default_network_acl_id" type="string">
  The real, automatically-created default network ACL.
</ResponseField>

<ResponseField name="main_route_table_id" type="string">
  The real ID of the main route table.
</ResponseField>

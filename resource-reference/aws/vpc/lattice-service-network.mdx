`aws_vpc_lattice_service_network` creates a real, logical boundary that `aws_vpc_lattice_service`s are published into and VPCs are associated with, the resource that actually lets services and consuming VPCs across separate accounts and VPCs discover and reach each other.

## Input properties

<ResponseField name="auth_type" type="string">
  Determines the authentication method for the service network, accepting either NONE to allow open access or AWS_IAM to require IAM authentication for client requests. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Specifies the name of the VPC Lattice service network, which must be unique within the account; if omitted, AWS CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="sharing_config" type="object">
  Defines the sharing configuration for the service network, with an 'enabled' toggle that allows the network to be shared with other AWS accounts through AWS Resource Access Manager. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool" required>
      Whether the service network can be shared with other AWS accounts via AWS Resource Access Manager (RAM). Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">

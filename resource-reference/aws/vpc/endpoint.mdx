---
title: "aws_vpc_endpoint"
description: "`aws_vpc_endpoint` creates a real, named private connectivity endpoint scoped to a VPC, its own subnets and security groups."
---

Its real, live field schema (name, vpc_id, subnet_ids, security_group_ids) is notably simpler than the classic `aws_ec2_vpcendpoint`'s own service_name/policy_document-driven shape, and no dedicated public documentation page for this specific, newer resource type turned up despite searching -- verified as real via its own live CFN field schema this session rather than a fetched overview, and flagged here as thinly documented rather than presented as fully understood.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	vpc "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/vpc"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint"})

    		ubx.Resource(vpc.Endpoint, "example", vpc.EndpointConfig{
    			Name:             "example",
    			SubnetIds:        []string{"example"},
    			VpcId:            "example",
    			SecurityGroupIds: []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The name of the VPC Endpoint Required.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  The ID of one or more security groups to associate with the endpoint network interface Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The ID of one or more subnets in which to create an endpoint network interface Required.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC in which the endpoint will be used. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The identifier of the VPC Endpoint Computed by AWS after `ship`.
</ResponseField>

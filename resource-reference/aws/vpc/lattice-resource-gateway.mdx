`aws_vpc_lattice_resource_gateway` creates a real, VPC-scoped gateway that an `aws_vpc_lattice_resource_configuration` routes through to actually reach its underlying non-service resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vpclattice "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/vpclattice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lattice resource gateway"})

    		ubx.Resource(vpclattice.ResourceGateway, "example", vpclattice.ResourceGatewayConfig{
    			Name:                        "example",
    			SubnetIds:                   []string{"example"},
    			VpcIdentifier:               "example",
    			IpAddressType:               "example",
    			Ipv4AddressesPerEni:         1,
    			ResourceConfigDnsResolution: "example",
    			SecurityGroupIds:            []string{"example"},
    			Tags:                        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="ip_address_type" type="string">
  Specifies the IP address type (IPv4 or IPv6) that the resource gateway uses for network traffic to and from its associated resources. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ipv4_addresses_per_eni" type="number">
  The number of IPv4 addresses to allocate per ENI for the resource gateway Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Specifies the name of the VPC Lattice resource gateway, which must be unique across all resource gateways in the same AWS account and region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_config_dns_resolution" type="string">
  Specifies the DNS resolution type for the resource gateway's resource configuration, controlling whether DNS names resolve to IPv4, IPv6, or both address types. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_group_ids" type="list(any)">
  The ID of one or more security groups to associate with the endpoint network interface. Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The ID of one or more subnets in which to create an endpoint network interface. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags (key-value pairs) to attach to the VPC Lattice resource gateway, enabling categorization, cost allocation, and access control for the gateway. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag assigned to this VPC Lattice resource gateway, providing user-defined metadata used to identify and organize the gateway. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_identifier" type="string" required>
  The ID of the VPC in which the resource gateway is deployed. Required. **(AI-inferred)**
</ResponseField>

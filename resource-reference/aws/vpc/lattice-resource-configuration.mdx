`aws_vpc_lattice_resource_configuration` registers a real, non-service resource, an RDS database or another single endpoint, with VPC Lattice, extending Lattice's own application-networking model to targets that aren't themselves an `aws_vpc_lattice_service`.

## Example

    			ResourceConfigurationType:                "example",

    			CustomDomainName:                         "example-custom-domain-name",
    			DomainVerificationId:                     "example",
    			GroupDomain:                              "example",
    			PortRanges:                               []string{"example"},

## Input properties

<ResponseField name="allow_association_to_sharable_service_network" type="bool">
  Specifies whether this resource configuration can be associated with a service network that is shared across AWS accounts, typically via AWS Resource Access Manager (RAM). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="custom_domain_name" type="string">
  Specifies a custom DNS domain name for the resource configuration, allowing the associated resource to be accessed through that hostname via VPC Lattice. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_verification_id" type="string">
  The domain_verification_id supplies the token that you add as a CNAME record in your DNS provider to prove ownership of the custom domain name for the VPC Lattice resource configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="group_domain" type="string">
  The domain name of the resource configuration group to which this resource configuration belongs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the VPC Lattice resource configuration, which must be unique within the AWS account and Region and serves as the identifier when managing the configuration. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="port_ranges" type="list(string)">
  The port ranges (for example, "80-80" or "443") that the resource configuration allows for inbound traffic to the associated resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="protocol_type" type="string">

<ResponseField name="resource_configuration_auth_type" type="string">

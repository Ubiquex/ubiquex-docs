`aws_io_tevents_detector_model` is a real state machine, defined states and the events that transition between them, that AWS IoT Events runs one instance of per real, tracked entity, an individual piece of equipment, a process, evaluating incoming data against it continuously to detect real operational states like a stuck valve or an overheating motor.

`aws_elastic_load_balancing_v2_load_balancer` creates a real Application Load Balancer or Network Load Balancer, ELB's current generation, that an `aws_elastic_load_balancing_v2_listener` actually receives and routes traffic through.

## Example

    func main() {

## Input properties

<ResponseField name="enable_capacity_reservation_provision_stabilize" type="bool">
  Indicates whether to enable stabilization when creating or updating an LCU reservation. This ensures that the final stack status reflects the status of the LCU reservation. The default is ``false``. Optional.
</ResponseField>

<ResponseField name="enable_prefix_for_ipv6_source_nat" type="string">
  [Network Load Balancers with UDP listeners] Indicates whether to use an IPv6 prefix from each subnet for source NAT. The IP address type must be ``dualstack``. The default value is ``off``. Optional.
</ResponseField>

<ResponseField name="enforce_security_group_inbound_rules_on_private_link_traffic" type="string">
  Indicates whether to evaluate inbound security group rules for traffic sent to a Network Load Balancer through privatelink. The default is ``on``. You can't configure this property on a Network Load Balancer unless you associated a security group with the load balancer when you created it. Optional.
</ResponseField>

<ResponseField name="ip_address_type" type="string">
  The IP address type. Internal load balancers must use ``ipv4``. [Application Load Balancers] The possible values are ``ipv4`` (IPv4 addresses), ``dualstack`` (IPv4 and IPv6 addresses), and ``dualstack-without-public-ipv4`` (public IPv6 addresses and private IPv4 and IPv6 addresses). Application Load Balancer authentication supports IPv4 addresses only when connecting to an Identity Provider (IdP) or Amazon Cognito endpoint. Without a public IPv4 address the load balancer can't complete the authentication process, resulting in HTTP 500 errors. [Network Load Balancers and Gateway Load Balancers] The possible values are ``ipv4`` (IPv4 addresses) and ``dualstack`` (IPv4 and IPv6 addresses). Optional.
</ResponseField>

<ResponseField name="ipv4_ipam_pool_id" type="string">
  The ID of the IPv4 IPAM pool. Optional.
</ResponseField>

<ResponseField name="load_balancer_attributes" type="list(object)">
  The load balancer attributes. Attributes that you do not modify retain their current values. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The name of the load balancer attribute, such as 'access_logs.s3.enabled' or 'idle_timeout.timeout_seconds'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Holds the value for a load balancer attribute in the LoadBalancerAttributes list, where the companion key determines the attribute being configured, e.g., deletion_protection.enabled or idle_timeout.timeout_seconds. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="minimum_load_balancer_capacity" type="object">
  The minimum capacity for a load balancer. Optional.
  <Expandable title="properties">
    <ResponseField name="capacity_units" type="number" required>
      The number of capacity units. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the load balancer. This name must be unique per region per account, can have a maximum of 32 characters, must contain only alphanumeric characters or hyphens, must not begin or end with a hyphen, and must not begin with "internal-". If you don't specify a name, AWS CloudFormation generates a unique physical ID for the load balancer. If you specify a name, you cannot perform updates that require replacement of this resource, but you can perform other updates. To replace the resource, specify a new name. Optional.
</ResponseField>

<ResponseField name="scheme" type="string">
  The nodes of an Internet-facing load balancer have public IP addresses. The DNS name of an Internet-facing load balancer is publicly resolvable to the public IP addresses of the nodes. Therefore, Internet-facing load balancers can route requests from clients over the internet. The nodes of an internal load balancer have only private IP addresses. The DNS name of an internal load balancer is publicly resolvable to the private IP addresses of the nodes. Therefore, internal load balancers can route requests only from clients with access to the VPC for the load balancer. The default is an Internet-facing load balancer. You can't specify a scheme for a Gateway Load Balancer. Optional.
</ResponseField>

<ResponseField name="security_groups" type="list(string)">
  [Application Load Balancers and Network Load Balancers] The IDs of the security groups for the load balancer. Optional.
</ResponseField>

<ResponseField name="subnet_mappings" type="list(object)">
  The IDs of the subnets. You can specify only one subnet per Availability Zone. You must specify either subnets or subnet mappings, but not both. [Application Load Balancers] You must specify subnets from at least two Availability Zones. You can't specify Elastic IP addresses for your subnets. [Application Load Balancers on Outposts] You must specify one Outpost subnet. [Application Load Balancers on Local Zones] You can specify subnets from one or more Local Zones. [Network Load Balancers] You can specify subnets from one or more Availability Zones. You can specify one Elastic IP address per subnet if you need static IP addresses for your internet-facing load balancer. For internal load balancers, you can specify one private IP address per subnet from the IPv4 range of the subnet. For internet-facing load balancer, you can specify one IPv6 address per subnet. [Gateway Load Balancers] You can specify subnets from one or more Availability Zones. You can't specify Elastic IP addresses for your subnets. Optional.
  <Expandable title="properties">
    <ResponseField name="allocation_id" type="string">
      The allocation ID of an Elastic IP (EIP) to associate with the specified subnet for the Network Load Balancer, providing a fixed public IP address for that subnet mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ipv6_address" type="string">
      The specific IPv6 address from the subnet's IPv6 CIDR range that the load balancer will use for that subnet mapping, enabling the load balancer to be reachable via IPv6. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="private_ipv4_address" type="string">
      Specifies the private IPv4 address to assign to the load balancer for a particular subnet mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_nat_ipv6_prefix" type="string">
      Sets the IPv6 source NAT prefix (CIDR) for a subnet mapping, which the Network Load Balancer uses as the source IP range when sending traffic to targets in that subnet. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="subnet_id" type="string">
      The subnet ID in which the load balancer's elastic network interface is created, as part of a SubnetMappings entry that defines an Availability Zone and subnet for the load balancer. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subnets" type="list(string)">
  The IDs of the subnets. You can specify only one subnet per Availability Zone. You must specify either subnets or subnet mappings, but not both. To specify an Elastic IP address, specify subnet mappings instead of subnets. [Application Load Balancers] You must specify subnets from at least two Availability Zones. [Application Load Balancers on Outposts] You must specify one Outpost subnet. [Application Load Balancers on Local Zones] You can specify subnets from one or more Local Zones. [Network Load Balancers and Gateway Load Balancers] You can specify subnets from one or more Availability Zones. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the load balancer. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Application Load Balancer. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value half of a key-value tag attached to the Elastic Load Balancer, which you can use to organize, identify, and control access to the load balancer through IAM conditions and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of load balancer. The default is ``application``. Optional.
</ResponseField>

## Output properties

<ResponseField name="canonical_hosted_zone_id" type="string">
  The canonical hosted zone ID of the load balancer, which is used when creating an alias resource record set in Amazon Route 53 to point to the load balancer's DNS name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="dnsname" type="string">
  The public DNS name of the load balancer, which resolves to the load balancer nodes and is used to route traffic to the application or network load balancer. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="load_balancer_arn" type="string">
  The Amazon Resource Name (ARN) assigned by AWS to the load balancer when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="load_balancer_full_name" type="string">
  This read-only attribute returns the unique full name of the load balancer, such as 'app/my-load-balancer/50dc6c495c0c9188', which identifies the load balancer within its account and region. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="load_balancer_name" type="string">
  The actual friendly name assigned to this Application or Network Load Balancer, which is either the user-specified name or a unique name auto-generated by AWS when none was provided. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

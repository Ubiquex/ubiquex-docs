`aws_elastic_load_balancing_v2_target_group` is the real, actual set of EC2 instances, IP addresses, or Lambda functions an `aws_elastic_load_balancing_v2_listener_rule` routes matching traffic to, with its own health checks determining which targets are currently eligible to receive it.

## Input properties

<ResponseField name="health_check_enabled" type="bool">
  Indicates whether health checks are enabled. If the target type is lambda, health checks are disabled by default but can be enabled. If the target type is instance, ip, or alb, health checks are always enabled and cannot be disabled. Optional.
</ResponseField>

<ResponseField name="health_check_interval_seconds" type="number">
  The approximate amount of time, in seconds, between health checks of an individual target. Optional.
</ResponseField>

<ResponseField name="health_check_path" type="string">
  [HTTP/HTTPS health checks] The destination for health checks on the targets. [HTTP1 or HTTP2 protocol version] The ping path. The default is /. [GRPC protocol version] The path of a custom health check method with the format /package.service/method. The default is /AWS.ALB/healthcheck. Optional.
</ResponseField>

<ResponseField name="health_check_port" type="string">
  The port the load balancer uses when performing health checks on targets. Optional.
</ResponseField>

<ResponseField name="health_check_protocol" type="string">
  The protocol the load balancer uses when performing health checks on targets. Optional.
</ResponseField>

<ResponseField name="health_check_timeout_seconds" type="number">
  The amount of time, in seconds, during which no response from a target means a failed health check. Optional.
</ResponseField>

<ResponseField name="healthy_threshold_count" type="number">
  The number of consecutive health checks successes required before considering an unhealthy target healthy. Optional.
</ResponseField>

<ResponseField name="ip_address_type" type="string">

</ResponseField>

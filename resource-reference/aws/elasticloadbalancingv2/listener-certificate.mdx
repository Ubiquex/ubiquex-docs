`aws_elastic_load_balancing_v2_listener_certificate` attaches an additional real TLS certificate to an `aws_elastic_load_balancing_v2_listener` beyond its own default certificate, needed when a listener must serve multiple domain names with SNI.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticloadbalancingv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elasticloadbalancingv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own listener certificate"})

    		ubx.Resource(elasticloadbalancingv2.ListenerCertificate, "example", elasticloadbalancingv2.ListenerCertificateConfig{
    			Certificates: []map[string]any{{"certificate_arn": "example"}},
    			ListenerArn:  "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx

## Input properties

<ResponseField name="certificates" type="list(object)" required>
  Specifies the list of ACM certificate ARNs to attach to the listener, allowing the load balancer to present these certificates during TLS handshakes. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="certificate_arn" type="string">
      The ARN of the certificate (from AWS Certificate Manager or IAM) to associate with the listener for TLS/SSL termination. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="listener_arn" type="string" required>
  Specifies the ARN of the Application Load Balancer or Network Load Balancer listener to which the certificate is associated. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier for the listener certificate, composed of the listener ARN and certificate ARN. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

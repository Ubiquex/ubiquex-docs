`aws_elastic_load_balancing_v2_listener` checks for real connection requests on a specific port and protocol against an `aws_elastic_load_balancing_v2_load_balancer`, the actual entry point that `aws_elastic_load_balancing_v2_listener_rule`s route matching traffic from.

`aws_ssmquick_setup_lifecycle_automation` configures real, automatic ongoing maintenance, keeping the resources an `aws_ssmquick_setup_configuration_manager` deployed up to date as its underlying best-practice configuration evolves.

## Input properties

<ResponseField name="automation_document" type="string" required>
  The name of the Automation document to execute Required.
</ResponseField>

<ResponseField name="automation_parameters" type="any" required>
  Parameters to be passed to the Automation Document Required.
</ResponseField>

<ResponseField name="resource_key" type="string" required>
  A unique identifier used for generating a unique logical ID for the custom resource Required.
</ResponseField>

<ResponseField name="tags" type="any">
  A map of key-value pairs to assign to the SSM Quick Setup lifecycle automation resource for tracking and management. Optional. **(AI-inferred)**
</ResponseField>

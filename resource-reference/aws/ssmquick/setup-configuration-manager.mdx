`aws_ssmquick_setup_configuration_manager` deploys a real, pre-packaged best-practice configuration, patch management, resource scheduling, or similar operational setup, across an account or organization through Systems Manager Quick Setup, without hand-assembling the underlying SSM associations and documents.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssmquick "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ssmquick"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own setup configuration manager"})

    		ubx.Resource(ssmquick.SetupConfigurationManager, "example", ssmquick.SetupConfigurationManagerConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Tags:        "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-provided free-form description for the SSM Quick Setup configuration manager. Optional. **(AI-inferred)**
</ResponseField>

## Input properties

<ResponseField name="application" type="string" required>
  The Amazon Resource Name (ARN) or name of the AWS RoboMaker robot application for which this version is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="current_revision_id" type="string">
  The revision ID of robot application. Optional.
</ResponseField>

## Output properties

<ResponseField name="application_version" type="string">
  The version of the robot application, automatically generated by AWS RoboMaker when the version is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="arn" type="string">
  The unique Amazon Resource Name (ARN) that identifies this RoboMaker robot application version. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

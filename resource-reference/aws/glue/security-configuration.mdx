`aws_glue_security_configuration` sets real encryption settings, at rest and in transit, applied to an `aws_glue_job`, `aws_glue_crawler`, or development endpoint when it runs, kept as its own reusable resource rather than repeated per job.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own security configuration"})

    		ubx.Resource(glue.SecurityConfiguration, "example", glue.SecurityConfigurationConfig{
    			EncryptionConfiguration: map[string]any{"cloud_watch_encryption": map[string]any{"cloud_watch_encryption_mode": "example"}},
    			Name:                    "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    ```

    ```python
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="encryption_configuration" type="object" required>
  The encryption configuration for the security configuration. Required.
  <Expandable title="properties">
    <ResponseField name="cloud_watch_encryption" type="object">
      The encryption configuration for Amazon CloudWatch. Optional.
      <Expandable title="properties">
        <ResponseField name="cloud_watch_encryption_mode" type="string">
          Specifies whether CloudWatch Logs encryption is disabled or uses SSE-KMS for the Glue security configuration, with allowed values 'DISABLED' and 'SSE-KMS'. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="kms_key_arn" type="string">
          The ARN of the AWS KMS key used to encrypt CloudWatch log data for the Glue security configuration. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="job_bookmarks_encryption" type="object">
      The encryption configuration for job bookmarks. Optional.
      <Expandable title="properties">
        <ResponseField name="job_bookmarks_encryption_mode" type="string">
          Sets the encryption mode for job bookmark data to either DISABLED (no encryption) or CSE-KMS (client-side encryption via an AWS KMS key specified in the same job_bookmarks_encryption block). Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="kms_key_arn" type="string">
          The ARN of the AWS KMS key used to encrypt job bookmark data when job bookmark encryption is enabled for the Glue security configuration. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="s3_encryptions" type="list(object)">
      The encryption configuration for Amazon Simple Storage Service (Amazon S3) data. Optional.
      <Expandable title="properties">
        <ResponseField name="kms_key_arn" type="string">
          The ARN of the AWS KMS key used to encrypt data in Amazon S3 when the encryption mode is set to SSE-KMS, as part of a Glue security configuration's S3 encryption settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="s3_encryption_mode" type="string">
          Specifies the S3 encryption mode for the Glue security configuration, which can be 'DISABLED', 'SSE-S3', or 'SSE-KMS' to control how data in S3 is encrypted. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name for the security configuration. Required.
</ResponseField>

`aws_glue_custom_entity_type` defines a real, custom sensitive-data pattern, a regular expression, that AWS Glue's sensitive data detection can recognize during a crawl or ETL job beyond its own built-in entity types.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom entity type"})

    		ubx.Resource(glue.CustomEntityType, "example", glue.CustomEntityTypeConfig{
    			Name:         "example",
    			ContextWords: []string{"example"},
    			RegexString:  "example",
    			Tags:         "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="context_words" type="list(string)">
  A list of context words. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the custom entity type. Optional.
</ResponseField>

<ResponseField name="regex_string" type="string">
  A regular expression string that is used for detecting sensitive data in a custom pattern. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  Tags to associate with the custom entity type. Optional.
</ResponseField>

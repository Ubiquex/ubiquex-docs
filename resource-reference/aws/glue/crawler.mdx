title: "aws_glue_crawler"
description: "`aws_glue_crawler` scans a real data source, S3, a JDBC database, DynamoDB..."
---

`aws_glue_crawler` scans a real data source, S3, a JDBC database, DynamoDB, and automatically infers and populates an `aws_glue_table`'s own schema in the Glue Data Catalog, rather than a caller writing that schema by hand.

## Example

    			CrawlerSecurityConfiguration: "example",

    	}))
    }

## Properties

<ResponseField name="classifiers" type="list(string)">
  A list of UTF-8 strings that specify the names of custom classifiers that are associated with the crawler. Optional.
</ResponseField>

<ResponseField name="configuration" type="string">
  Crawler configuration information. This versioned JSON string allows users to specify aspects of a crawler's behavior. Optional.
</ResponseField>

<ResponseField name="crawler_security_configuration" type="string">
  The name of the SecurityConfiguration structure to be used by this crawler. Optional.
</ResponseField>

<ResponseField name="database_name" type="string">
  The name of the database in which the crawler's output is stored. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the crawler. Optional.
</ResponseField>

<ResponseField name="lake_formation_configuration" type="object">
  Specifies AWS Lake Formation configuration settings for the crawler Optional.
  <Expandable title="properties">
    <ResponseField name="account_id" type="string">
      Required for cross account crawls. For same account crawls as the target data, this can be left as null. Optional.
    </ResponseField>
    <ResponseField name="use_lake_formation_credentials" type="bool">
      Specifies whether to use AWS Lake Formation credentials for the crawler instead of the IAM role credentials. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the crawler. Optional.
</ResponseField>

<ResponseField name="recrawl_policy" type="object">
  When crawling an Amazon S3 data source after the first crawl is complete, specifies whether to crawl the entire dataset again or to crawl only folders that were added since the last crawler run. For more information, see Incremental Crawls in AWS Glue in the developer guide. Optional.
  <Expandable title="properties">
    <ResponseField name="recrawl_behavior" type="string">
      Specifies whether to crawl the entire dataset again or to crawl only folders that were added since the last crawler run. A value of CRAWL_EVERYTHING specifies crawling the entire dataset again. A value of CRAWL_NEW_FOLDERS_ONLY specifies crawling only folders that were added since the last crawler run. A value of CRAWL_EVENT_MODE specifies crawling only the changes identified by Amazon S3 events. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role" type="string" required>
  The Amazon Resource Name (ARN) of an IAM role that's used to access customer resources, such as Amazon Simple Storage Service (Amazon S3) data. Required.
</ResponseField>

<ResponseField name="schedule" type="object">
  A scheduling object using a cron statement to schedule an event. Optional.
  <Expandable title="properties">
    <ResponseField name="schedule_expression" type="string">
      A cron expression used to specify the schedule. For more information, see Time-Based Schedules for Jobs and Crawlers. For example, to run something every day at 12:15 UTC, specify cron(15 12 * * ? *). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schema_change_policy" type="object">
  The policy that specifies update and delete behaviors for the crawler. The policy tells the crawler what to do in the event that it detects a change in a table that already exists in the customer's database at the time of the crawl. The SchemaChangePolicy does not affect whether or how new tables and partitions are added. New tables and partitions are always created regardless of the SchemaChangePolicy on a crawler. The SchemaChangePolicy consists of two components, UpdateBehavior and DeleteBehavior. Optional.
  <Expandable title="properties">
    <ResponseField name="delete_behavior" type="string">
      The deletion behavior when the crawler finds a deleted object. A value of LOG specifies that if a table or partition is found to no longer exist, do not delete it, only log that it was found to no longer exist. A value of DELETE_FROM_DATABASE specifies that if a table or partition is found to have been removed, delete it from the database. A value of DEPRECATE_IN_DATABASE specifies that if a table has been found to no longer exist, to add a property to the table that says 'DEPRECATED' and includes a timestamp with the time of deprecation. Optional.
    </ResponseField>
    <ResponseField name="update_behavior" type="string">
      The update behavior when the crawler finds a changed schema. A value of LOG specifies that if a table or a partition already exists, and a change is detected, do not update it, only log that a change was detected. Add new tables and new partitions (including on existing tables). A value of UPDATE_IN_DATABASE specifies that if a table or partition already exists, and a change is detected, update it. Add new tables and partitions. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="table_prefix" type="string">
  The prefix added to the names of tables that are created. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  The tags to use with this crawler. Optional.
</ResponseField>

<ResponseField name="targets" type="object" required>
  Specifies data stores to crawl. Required.
  <Expandable title="properties">
    <ResponseField name="catalog_targets" type="list(object)">
      Specifies AWS Glue Data Catalog targets. Optional.
      <Expandable title="properties">
        <ResponseField name="connection_name" type="string">
          The name of an existing AWS Glue connection that the crawler uses to access the catalog target database when the target requires network access through a connection (for example, for a Redshift or JDBC target catalog). Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="database_name" type="string">
          The name of the AWS Glue Data Catalog database whose tables the crawler targets when processing this catalog target. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="dlq_event_queue_arn" type="string">
          Specifies the ARN of the Amazon SQS dead-letter queue to use as a destination for events that fail to be processed from the event queue for this catalog target, enabling change tracking in the crawler. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="event_queue_arn" type="string">
          The ARN of an Amazon SQS queue that the crawler subscribes to so it can receive data catalog event notifications for the specified catalog target tables, enabling event-driven re-crawling. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="tables" type="list(string)">

        </ResponseField>
      </Expandable>

    <ResponseField name="delta_targets" type="list(object)">

      <Expandable title="properties">

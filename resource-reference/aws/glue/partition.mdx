`aws_glue_partition` registers one real, physical subdivision of an `aws_glue_table`'s data, a specific date or Region's worth of files, for instance, so a query engine can skip reading partitions that don't match a query's filter instead of scanning the entire table.

## Input properties

<ResponseField name="catalog_id" type="string" required>
  The identifier of the AWS Glue Data Catalog (typically the AWS account ID) that contains the database and table where this partition is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="database_name" type="string" required>

`aws_glue_database` is a real, logical grouping of `aws_glue_table`s inside an `aws_glue_catalog`, organizing related tables the way a schema organizes tables in a traditional relational database.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own database"})

    		ubx.Resource(glue.Database, "example", glue.DatabaseConfig{
    			CatalogId:     "example",
    			DatabaseInput: map[string]any{"name": "example-name"},
    			DatabaseName:  "example-database-name",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="catalog_id" type="string" required>
  The AWS account ID for the account in which to create the catalog object. Required.
</ResponseField>

<ResponseField name="database_input" type="object" required>
  The structure used to create or update a database. Required.
  <Expandable title="properties">
    <ResponseField name="create_table_default_permissions" type="list(object)">
      Creates a set of default permissions on the table for principals. Used by AWS Lake Formation. Not used in the normal course of AWS Glue operations. Optional.
      <Expandable title="properties">
        <ResponseField name="permissions" type="list(string)">
          For each entry in create_table_default_permissions, the list of permissions (e.g., ALL, ALTER, CREATE_TABLE) granted to the specified principal for tables created in the database. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="principal" type="object">
          Specifies the IAM principal (such as a user, role, or federated user) to which the default permissions on tables created in this database apply, identified by its data lake principal identifier (for example, an IAM ARN). Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="data_lake_principal_identifier" type="string">
              The unique identifier of the data lake principal (such as an IAM role ARN or an AWS account ID) that is granted the default permissions on tables created in this Glue database. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>

        </ResponseField>

    </ResponseField>

`aws_glue_data_quality_ruleset` defines a real set of data quality rules, in Glue's own DQDL language, that can be evaluated against a table in an `aws_glue_catalog` to score completeness, accuracy, and consistency.

## Properties

<ResponseField name="client_token" type="string">
  A unique token for idempotency. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the data quality ruleset. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A unique name for the data quality ruleset. Required.
</ResponseField>

<ResponseField name="ruleset" type="string">
  A Data Quality Definition Language (DQDL) ruleset. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  A map of key-value pairs to apply to this resource. Optional.
</ResponseField>

<ResponseField name="target_table" type="object">
  An object representing an AWS Glue table. Optional.
  <Expandable title="properties">
    <ResponseField name="database_name" type="string" required>
      The name of the database where the AWS Glue table exists. Required.
    </ResponseField>
    <ResponseField name="table_name" type="string" required>
      The name of the AWS Glue table. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

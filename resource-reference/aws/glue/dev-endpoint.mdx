`aws_glue_dev_endpoint` provisions a real, persistent development environment for interactively writing and testing an `aws_glue_job`'s own ETL script before running it as an actual, scheduled job.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own dev endpoint"})

    		ubx.Resource(glue.DevEndpoint, "ci-runner", glue.DevEndpointConfig{
    			RoleArn:               "arn:aws:iam::123456789012:policy/ci",
    			Arguments:             "example",
    			EndpointName:          "example-endpoint-name",
    			ExtraJarsS3Path:       "example",
    			ExtraPythonLibsS3Path: "example",
    			GlueVersion:           "example",
    			NumberOfNodes:         1,
    			NumberOfWorkers:       1,
    		})
    	}))
    }
    ```

    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.glue import DevEndpoint, DevEndpointConfig

    def describe():
        ubx.intent("payments own dev endpoint")

        ubx.resource(DevEndpoint, "ci-runner", DevEndpointConfig(
            role_arn="arn:aws:iam::123456789012:policy/ci",
            arguments="example",
            endpoint_name="example-endpoint-name",
            extra_jars_s3_path="example",
            extra_python_libs_s3_path="example",
            glue_version="example",
            number_of_nodes=1,
            number_of_workers=1,
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Input properties

<ResponseField name="arguments" type="any">
  A map of key-value pairs that specify configuration arguments passed to the Apache Spark environment of the development endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_name" type="string">
  Specifies a user-defined name for this AWS Glue development endpoint, which AWS Glue uses to identify it; if omitted, CloudFormation automatically generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="extra_jars_s3_path" type="string">
  The S3 path to one or more Java JAR files that provide custom jars to be used by the Glue development endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="extra_python_libs_s3_path" type="string">
  The S3 path to a Python library (or set of libraries) that AWS Glue installs on the development endpoint for use by your ETL scripts. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="glue_version" type="string">
  Specifies the AWS Glue version (such as '1.0' or '2.0') that defines the Apache Spark and Python runtime environment for this development endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="number_of_nodes" type="number">
  Specifies the number of compute nodes for the development endpoint, which determines its processing capacity and parallelism. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="number_of_workers" type="number">
  The number of worker nodes allocated to this AWS Glue development endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="public_key" type="string">
  The SSH public key that AWS Glue uses to authenticate connections to the development endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="public_keys" type="list(string)">
  A list of SSH public keys used to authenticate to the dev endpoint for secure access. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of the IAM role that the development endpoint assumes to access resources such as data stores and scripts. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_configuration" type="string">
  The name of an AWS Glue security configuration to attach to this development endpoint, which defines encryption and other security settings. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  List of security group IDs to attach to the Glue dev endpoint for VPC networking. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_id" type="string">
  The subnet ID within a VPC where the AWS Glue development endpoint is provisioned, used when the endpoint needs access to resources in a Virtual Private Cloud. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Specifies a set of key-value tags to attach to the AWS Glue development endpoint, used for resource organization, cost allocation, and access control. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="worker_type" type="string">
  The worker type for the development endpoint, such as Standard, G.1X, or G.2X, which determines the compute capacity of each worker. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier for the Glue development endpoint, which is the same as the endpoint's name and is used as the Terraform resource ID for import and state tracking. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_glue_usage_profile` sets real, preventative cost-control limits, worker count, session parameters, that apply automatically to every Glue job or interactive session an assigned IAM user or role creates, letting an admin give a test user a tighter cap than a production data engineer without either having to self-police. Reached general availability June 2024.

    package main

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own usage profile"})

    		ubx.Resource(glue.UsageProfile, "example", glue.UsageProfileConfig{
    			Name:          "example",
    			Configuration: "example",
    			Description:   "Managed by ubx.",
    			Tags:          []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="configuration" type="any">
  The configuration for the Glue usage profile, defining the profile's data access permissions, usage limits, and other settings as a JSON object. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  The description of the UsageProfile. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the UsageProfile. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to be applied to this UsageProfiles. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

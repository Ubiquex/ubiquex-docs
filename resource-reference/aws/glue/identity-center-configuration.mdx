title: "aws_glue_identity_center_configuration"

---

`aws_glue_identity_center_configuration` connects a real IAM Identity Center instance to AWS Glue, enabling trusted identity propagation so a user's own real identity, not just a shared execution role, flows from a Glue interactive session through to downstream services like S3 Access Grants, Lake Formation, and Redshift.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own identity center configuration"})

    		ubx.Resource(glue.IdentityCenterConfiguration, "ci-runner", glue.IdentityCenterConfigurationConfig{
    			InstanceArn:                   "arn:aws:iam::123456789012:policy/ci",
    			Scopes:                        []string{"example"},
    			UserBackgroundSessionsEnabled: true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="instance_arn" type="string" required>
  The IAM identity center instance arn Required.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  The downstream scopes that Glue identity center configuration can access Optional.
</ResponseField>

<ResponseField name="user_background_sessions_enabled" type="bool">
  Enable or disable user background sessions for Glue Identity Center Optional.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The identifier for the specified AWS account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="application_arn" type="string">
  The Glue IAM identity center application arn Computed by AWS after `ship`.
</ResponseField>

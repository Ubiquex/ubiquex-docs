`aws_glue_user_defined_function` registers a real, custom function, callable from Athena or Spark SQL, in an `aws_glue_catalog`, extending what a query engine can compute beyond its own built-in functions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own user defined function"})

    		ubx.Resource(glue.UserDefinedFunction, "ci-runner", glue.UserDefinedFunctionConfig{
    			DatabaseName: "example-database-name",
    			FunctionName: "example-function-name",
    			ClassName:    "example-class-name",
    			FunctionType: "example",
    			OwnerName:    "example-owner-name",
    			OwnerType:    "example",
    			ResourceUris: []map[string]any{{"resource_type": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="class_name" type="string">
  The Java class that contains the function code. Optional.
</ResponseField>

<ResponseField name="database_name" type="string" required>
  The name of the catalog database in which the function is located. Required.
</ResponseField>

<ResponseField name="function_name" type="string" required>
  The name of the function. Required.
</ResponseField>

<ResponseField name="function_type" type="string">
  The type of the function. Optional.
</ResponseField>

<ResponseField name="owner_name" type="string">
  The owner of the function. Optional.
</ResponseField>

<ResponseField name="owner_type" type="string">
  The owner type. Optional.
</ResponseField>

<ResponseField name="resource_uris" type="list(object)">
  The resource URIs for the function. Optional.
  <Expandable title="properties">
    <ResponseField name="resource_type" type="string">
      Specifies the type of resource stored at the URI, such as 'JAR', 'FILE', or 'ARCHIVE', for the user-defined function's resource URIs. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI (typically an S3 path or similar location) of the resource (e.g., jar, archive, or file) associated with the user-defined function. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the user-defined function. Computed by AWS after `ship`.
</ResponseField>

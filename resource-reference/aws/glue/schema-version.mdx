`aws_glue_schema_version` publishes a real, immutable version of an `aws_glue_schema`'s definition, letting a Kafka or Kinesis producer/consumer pin to a specific, compatible schema version rather than the schema's current, evolving definition.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schema version"})

    		ubx.Resource(glue.SchemaVersion, "example", glue.SchemaVersionConfig{
    			Schema:           map[string]any{"registry_name": "example-registry-name"},
    			SchemaDefinition: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="schema" type="object" required>
  Identifier for the schema where the schema version will be created. Required.
  <Expandable title="properties">
    <ResponseField name="registry_name" type="string">
      Name of the registry to identify where the Schema is located. Optional.
    </ResponseField>
    <ResponseField name="schema_arn" type="string">
      Amazon Resource Name for the Schema. This attribute can be used to uniquely represent the Schema. Optional.
    </ResponseField>
    <ResponseField name="schema_name" type="string">
      Name of the schema. This parameter requires RegistryName to be provided. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schema_definition" type="string" required>
  Complete definition of the schema in plain-text. Required.
</ResponseField>

## Output properties

<ResponseField name="version_id" type="string">
  Represents the version ID associated with the schema version. Computed by AWS after `ship`.
</ResponseField>

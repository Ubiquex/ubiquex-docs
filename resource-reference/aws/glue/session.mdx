`aws_glue_session` is an AWS Glue interactive session, an on-demand, serverless Spark runtime a notebook or IDE connects to for building and testing ETL scripts interactively, without waiting for a full Glue job's own cold-start time on every change.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own session"})

    		ubx.Resource(glue.Session, "ci-runner", glue.SessionConfig{
    			Command:          map[string]any{"name": "example-name"},
    			Id:               "example",
    			Role:             "example",
    			Connections:      map[string]any{"connections": []string{"example"}},
    			DefaultArguments: "example",
    			Description:      "Managed by ubx.",
    			GlueVersion:      "example",
    			IdleTimeout:      1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="command" type="object" required>
  The SessionCommand that runs the job. Required.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Specifies the name of the SessionCommand. Can be 'glueetl' or 'gluestreaming'. Optional.
    </ResponseField>
    <ResponseField name="python_version" type="string">
      Specifies the Python version. The Python version indicates the version supported for jobs of type Spark. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="connections" type="object">
  Specifies the connections used by the session. Optional.
  <Expandable title="properties">
    <ResponseField name="connections" type="list(string)">
      A list of connection names used by the session. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="default_arguments" type="any">
  A map array of key-value pairs. Max is 75 pairs. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the session. Optional.
</ResponseField>

<ResponseField name="glue_version" type="string">
  The Glue version determines the versions of Apache Spark and Python that Glue supports. The GlueVersion must be greater than 2.0. Optional.
</ResponseField>

<ResponseField name="id" type="string" required>
  The ID of the session. Required.
</ResponseField>

<ResponseField name="idle_timeout" type="number">
  The number of minutes when idle before session times out. Default is the value of Timeout. Optional.
</ResponseField>

<ResponseField name="max_capacity" type="number">
  The number of Glue data processing units (DPUs) that can be allocated when the job runs. Optional.
</ResponseField>

<ResponseField name="number_of_workers" type="number">
  The number of workers of a defined WorkerType to use for the session. Optional.
</ResponseField>

<ResponseField name="request_origin" type="string">
  The origin of the request. Optional.
</ResponseField>

<ResponseField name="role" type="string" required>
  The IAM Role ARN. Required.
</ResponseField>

<ResponseField name="security_configuration" type="string">
  The name of the SecurityConfiguration structure to be used with the session. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags belonging to the session. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="timeout" type="number">
  The number of minutes before session times out. Optional.
</ResponseField>

<ResponseField name="worker_type" type="string">
  The type of predefined worker that is allocated when a session runs. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the session. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_on" type="string">
  The time and date when the session was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="progress" type="number">
  The code execution progress of the session. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The session status. Computed by AWS after `ship`.
</ResponseField>

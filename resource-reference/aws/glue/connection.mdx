`aws_glue_connection` stores the real, actual connection details, JDBC URL, credentials, network placement, an `aws_glue_crawler` or `aws_glue_job` uses to reach a data source outside the Glue Data Catalog itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connection"})

    		ubx.Resource(glue.Connection, "example", glue.ConnectionConfig{
    			CatalogId:       "example",
    			ConnectionInput: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    ```

    ```python
    import ubx_sdk as ubx

        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="catalog_id" type="string" required>
  The identifier of the AWS Data Catalog (typically the AWS account ID) in which the Glue connection is stored or referenced. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="connection_input" type="object" required>
  Configuration object that defines the properties of an AWS Glue connection, including connection type, connection properties, and physical connection requirements for the target data store. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="athena_properties" type="any">

        <ResponseField name="basic_authentication_credentials" type="object">
          Specifies the username and password used for basic authentication when connecting to the data source for this AWS Glue connection. Optional. **(AI-inferred)**

        <ResponseField name="custom_authentication_credentials" type="any">

`aws_glue_table_optimizer` automatically runs real, background maintenance, compacting small files, expiring old snapshots, deleting orphaned files, against an Apache Iceberg `aws_glue_table`, storage and query-performance upkeep a caller would otherwise have to schedule and run manually.

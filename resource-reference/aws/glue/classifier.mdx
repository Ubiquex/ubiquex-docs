`aws_glue_classifier` tells an `aws_glue_crawler` how to actually recognize and parse a real data format, CSV with a specific delimiter, a custom log format, beyond the built-in classifiers Glue already provides.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own classifier"})

    		ubx.Resource(glue.Classifier, "example", glue.ClassifierConfig{
    			CsvClassifier:  map[string]any{"name": "example-name"},
    			GrokClassifier: map[string]any{"name": "example-name"},
    			JsonClassifier: map[string]any{"name": "example-name"},
    			Xmlclassifier:  map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="csv_classifier" type="object">
  Defines the configuration for an AWS Glue classifier that parses CSV files, including the delimiter, quote symbol, header detection, and whether to treat a single column as a valid CSV format. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="allow_single_column" type="bool">
      Enables the processing of files that contain only one column. Optional.
    </ResponseField>
    <ResponseField name="contains_custom_datatype" type="list(string)">
      Indicates whether the CSV file contains custom data types. Optional.
    </ResponseField>
    <ResponseField name="contains_header" type="string">
      Indicates whether the CSV file contains a header. A value of UNKNOWN specifies that the classifier will detect whether the CSV file contains headings. A value of PRESENT specifies that the CSV file contains headings. A value of ABSENT specifies that the CSV file does not contain headings. Optional.
    </ResponseField>
    <ResponseField name="custom_datatype_configured" type="bool">
      Enables the configuration of custom data types. Optional.
    </ResponseField>
    <ResponseField name="delimiter" type="string">
      A custom symbol to denote what separates each column entry in the row. Optional.
    </ResponseField>
    <ResponseField name="disable_value_trimming" type="bool">
      Specifies not to trim values before identifying the type of column values. The default value is true. Optional.
    </ResponseField>
    <ResponseField name="header" type="list(string)">
      A list of strings representing column names. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the classifier. Optional.
    </ResponseField>
    <ResponseField name="quote_symbol" type="string">
      A custom symbol to denote what combines content into a single column value. It must be different from the column delimiter. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="grok_classifier" type="object">
  Configures a Grok classifier in AWS Glue, specifying the grok pattern used to parse log or unstructured data, custom pattern definitions, and the classification name applied to matched data. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="classification" type="string" required>
      An identifier of the data format that the classifier matches, such as Twitter, JSON, Omniture logs, and so on. Required.
    </ResponseField>
    <ResponseField name="custom_patterns" type="string">
      Optional custom grok patterns defined by this classifier. Optional.
    </ResponseField>
    <ResponseField name="grok_pattern" type="string" required>
      The grok pattern applied to a data store by this classifier. Required.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the classifier. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="json_classifier" type="object">
  Specifies a JSON classifier for AWS Glue that uses a JSON path to identify the JSON data structure within input records. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="json_path" type="string" required>
      A JsonPath string defining the JSON data for the classifier to classify. AWS Glue supports a subset of JsonPath, as described in Writing JsonPath Custom Classifiers. Required.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the classifier. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="xmlclassifier" type="object">
  Defines the row tag and optional classification for an XML classifier, used by AWS Glue to parse XML data and infer its schema. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="classification" type="string" required>
      An identifier of the data format that the classifier matches. Required.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the classifier. Optional.
    </ResponseField>
    <ResponseField name="row_tag" type="string" required>
      The XML tag designating the element that contains each record in an XML document being parsed. This can't identify a self-closing element (closed by /&gt;). An empty row element that contains only attributes can be parsed as long as it ends with a closing tag (for example, &lt;row item_a="A" item_b="B"&gt;&lt;/row&gt; is okay, but &lt;row item_a="A" item_b="B" /&gt; is not). Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="name" type="string">
  One of XMLClassifier/Name, GrokClassifier/Name, JsonClassifier/Name or CsvClassifier/Name Computed by AWS after `ship`.
</ResponseField>

`aws_glue_data_catalog_encryption_settings` configures real, account-wide encryption defaults, at-rest KMS encryption and password encryption, for every table and connection in an `aws_glue_catalog`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own data catalog encryption settings"})

    		ubx.Resource(glue.DataCatalogEncryptionSettings, "example", glue.DataCatalogEncryptionSettingsConfig{
    			CatalogId:                     "example",
    			DataCatalogEncryptionSettings: map[string]any{"connection_password_encryption": map[string]any{"kms_key_id": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="catalog_id" type="string" required>
  The ID of the Data Catalog in which the settings are created. Required.
</ResponseField>

<ResponseField name="data_catalog_encryption_settings" type="object" required>
  Contains configuration information for maintaining Data Catalog security. Required.
  <Expandable title="properties">
    <ResponseField name="connection_password_encryption" type="object">
      When connection password protection is enabled, the Data Catalog uses a customer-provided key to encrypt the password as part of CreateConnection or UpdateConnection and store it in the ENCRYPTED_PASSWORD field in the connection properties. You can enable catalog encryption or only password encryption. Optional.
      <Expandable title="properties">
        <ResponseField name="kms_key_id" type="string">
          An AWS KMS key that is used to encrypt the connection password. Optional.
        </ResponseField>
        <ResponseField name="return_connection_password_encrypted" type="bool">
          When the ReturnConnectionPasswordEncrypted flag is set to 'true', passwords remain encrypted in the responses of GetConnection and GetConnections. This encryption takes effect independently from catalog encryption. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="encryption_at_rest" type="object">
      Specifies the encryption-at-rest configuration for the Data Catalog. Optional.
      <Expandable title="properties">
        <ResponseField name="catalog_encryption_mode" type="string">
          The encryption-at-rest mode for encrypting Data Catalog data. Optional.
        </ResponseField>
        <ResponseField name="catalog_encryption_service_role" type="string">
          The role that AWS Glue assumes to encrypt and decrypt the Data Catalog objects on the caller's behalf. Optional.
        </ResponseField>
        <ResponseField name="sse_aws_kms_key_id" type="string">
          The ID of the AWS KMS key to use for encryption at rest. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

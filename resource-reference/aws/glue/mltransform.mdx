`aws_glue_mltransform` trains a real, managed machine-learning model, FindMatches, that an `aws_glue_job` can use to deduplicate or link records that don't match exactly, fuzzy matching a rule-based transform can't express.

## Input properties

  A user-defined, long-form description text for the machine learning transform. Optional.

<ResponseField name="glue_version" type="string">
  The version of AWS Glue this machine learning transform is compatible with. Optional.
</ResponseField>

<ResponseField name="input_record_tables" type="object" required>
  A list of AWS Glue table definitions used by the transform. Required.
  <Expandable title="properties">
    <ResponseField name="glue_tables" type="list(object)">
      The database and table in the AWS Glue Data Catalog that is used for input or output data. Optional.
      <Expandable title="properties">
        <ResponseField name="catalog_id" type="string">
          The identifier of the AWS Glue Data Catalog in which the specified input table resides; if omitted, the current AWS account's catalog ID is used. Optional; if omitted, computed by AWS. **(AI-inferred)**

        <ResponseField name="connection_name" type="string">
          The name of an AWS Glue connection used to access the source table, required when the table resides in an external data store such as JDBC rather than being purely stored in the Glue Data Catalog. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="database_name" type="string">
          The name of the AWS Glue Data Catalog database that contains the table used as an input record source for the machine learning transform. Optional; if omitted, computed by AWS. **(AI-inferred)**

          The name of the Glue Data Catalog table that supplies the input records for the ML transform. Optional; if omitted, computed by AWS. **(AI-inferred)**

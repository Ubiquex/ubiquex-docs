`aws_glue_table` registers the real schema, columns, types, storage format and location, of one dataset in the Glue Data Catalog, metadata a query engine reads to know how to actually read the underlying data in S3 or elsewhere.

## Example

    	ubx.Main(ubx.Stack("example", func() {

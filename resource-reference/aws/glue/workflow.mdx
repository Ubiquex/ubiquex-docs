`aws_glue_workflow` orchestrates a real, directed graph of Glue jobs, crawlers, and triggers as a single, coordinated ETL pipeline, so dependent steps run in the right order without a separate external scheduler.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workflow"})

    		ubx.Resource(glue.Workflow, "example", glue.WorkflowConfig{
    			Name:                 "example",
    			DefaultRunProperties: "example",
    			Description:          "Managed by ubx.",
    			MaxConcurrentRuns:    1,
    			Tags:                 "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.glue import Workflow, WorkflowConfig

    def describe():
        ubx.intent("example own workflow")

        ubx.resource(Workflow, "example", WorkflowConfig(
            name="example",
            default_run_properties="example",
            description="Managed by ubx.",
            max_concurrent_runs=1,
            tags="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="default_run_properties" type="any">
  A collection of properties to be used as part of each execution of the workflow Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the workflow Optional.
</ResponseField>

<ResponseField name="max_concurrent_runs" type="number">
  You can use this parameter to prevent unwanted multiple updates to data, to control costs, or in some cases, to prevent exceeding the maximum number of concurrent runs of any of the component jobs. If you leave this parameter blank, there is no limit to the number of concurrent workflow runs. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the workflow representing the flow Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  The tags to use with this workflow. Optional.
</ResponseField>

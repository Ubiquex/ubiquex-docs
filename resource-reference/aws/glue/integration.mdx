`aws_glue_integration` defines a real, zero-ETL integration from a source, Aurora, RDS, DynamoDB, to a target like Redshift or OpenSearch, replicating and keeping data in sync without a caller writing or scheduling any ETL job themselves. AWS Glue added CloudFormation and CDK support for zero-ETL integrations in November 2025.

## Example

    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own integration"})

    		ubx.Resource(glue.Integration, "example", glue.IntegrationConfig{
    			IntegrationName:             "example-integration-name",
    			SourceArn:                   "arn:aws:iam::123456789012:policy/example",
    			TargetArn:                   "arn:aws:iam::123456789012:policy/example",
    			AdditionalEncryptionContext: "example",
    			DataFilter:                  "example",
    			Description:                 "Managed by ubx.",
    			IntegrationConfig:           map[string]any{"continuous_sync": true},
    			KmsKeyId:                    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  An optional set of non-secret key value pairs that contains additional contextual information about the data. Optional.
</ResponseField>

<ResponseField name="data_filter" type="string">
  Specifies a SQL query string that filters the source data to be included in the Glue integration, such as selecting specific columns or rows from a source table. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Optional.
</ResponseField>

<ResponseField name="integration_config" type="object">
  The configuration settings for the integration. Optional.
  <Expandable title="properties">
    <ResponseField name="continuous_sync" type="bool">
      Enables continuous synchronization for on-demand data extractions. Optional.
    </ResponseField>
    <ResponseField name="refresh_interval" type="string">
      Specifies the frequency at which CDC (Change Data Capture) pulls or incremental loads should occur. Optional.
    </ResponseField>
    <ResponseField name="source_properties" type="any">
      A collection of key-value pairs that specify additional properties for the integration source. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="integration_name" type="string" required>
  The name of the integration. Required.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  An KMS key identifier for the key to use to encrypt the integration. If you don't specify an encryption key, the default AWS owned KMS key is used. Optional.
</ResponseField>

<ResponseField name="source_arn" type="string" required>
  The Amazon Resource Name (ARN) of the database to use as the source for replication Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of the tag assigned to the Glue integration, used with the tag key to attach metadata for cost allocation, access control, and resource identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_arn" type="string" required>
  The Amazon Resource Name (ARN) of the Glue data warehouse to use as the target for replication Required.
</ResponseField>

## Output properties

<ResponseField name="create_time" type="string">
  The time (UTC) when the integration was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="integration_arn" type="string">
  The Amazon Resource Name (ARN) of the integration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the integration. Computed by AWS after `ship`.
</ResponseField>

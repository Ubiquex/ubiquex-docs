title: "aws_amplify_app"
description: "`aws_amplify_app` creates the top-level Amplify Hosting application..."
---

`aws_amplify_app` creates the top-level Amplify Hosting application, the Git-connected project that Amplify's managed CI/CD pipeline builds and deploys from. Branches, domains, and build settings all attach to this app rather than standing alone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	amplify "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/amplify"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app"})

    		ubx.Resource(amplify.App, "example", amplify.AppConfig{
    			Name:                     "example",
    			AccessToken:              "example",
    			AutoBranchCreationConfig: map[string]any{"auto_branch_creation_patterns": []string{"example"}},
    			BasicAuthConfig:          map[string]any{"enable_basic_auth": true},
    			BuildSpec:                "example",
    			CacheConfig:              map[string]any{"type": "example"},
    			ComputeRoleArn:           "arn:aws:iam::123456789012:policy/example",
    			CustomHeaders:            "example",
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.amplify import App, AppConfig
    from ubx.aws.amplify.app import App_AutoBranchCreationConfig, App_AutoBranchCreationConfig_BasicAuthConfig, App_CacheConfig

    def describe():
        ubx.intent("example own app")

        ubx.resource(App, "example", AppConfig(
            name="example",
            access_token="example",
            auto_branch_creation_config=App_AutoBranchCreationConfig(auto_branch_creation_patterns=["example"]),
            basic_auth_config=App_AutoBranchCreationConfig_BasicAuthConfig(enable_basic_auth=True),
            build_spec="example",
            cache_config=App_CacheConfig(type="example"),
            compute_role_arn="arn:aws:iam::123456789012:policy/example",
            custom_headers="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="access_token" type="string">
  GitHub personal access token Amplify uses to authenticate and pull the source repository linked to this app. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="auto_branch_creation_config" type="object">
  Configures which Git branches are automatically created in Amplify and the build/render settings (such as build spec, environment variables, and stage) applied to those branches. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="auto_branch_creation_patterns" type="list(string)">
      Specifies the branch name patterns that automatically trigger creation of matching branches in the Amplify app. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="basic_auth_config" type="object">
      Configures basic authentication credentials (username and password) that are automatically applied to branches created according to the auto branch creation patterns. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="enable_basic_auth" type="bool">
          Whether to enable basic authentication for automatically created branches, requiring a username and password to access them. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="password" type="string">
          The password to use for basic authentication when automatically creating branches for this Amplify app. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="username" type="string">
          Specifies the username used for basic authentication on branches that are automatically created by Amplify. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="build_spec" type="string">
      The build specification (buildspec) content, in YAML or JSON format, that AWS Amplify uses to run the build for branches created automatically via the auto branch creation configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enable_auto_branch_creation" type="bool">
      Indicates whether Amplify automatically creates a new app branch for every branch in the connected repository that matches the configured auto branch creation patterns. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enable_auto_build" type="bool">
      Enables automated build and deployment of branches that are automatically created for this app when they match the auto-branch-creation pattern. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enable_performance_mode" type="bool">
      Enables Amplify's performance mode for automatically created branches, which applies performance optimizations such as caching to the deployed app. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enable_pull_request_preview" type="bool">
      Enables pull request previews for branches that are automatically created by Amplify, allowing you to preview changes from pull requests before merging. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="environment_variables" type="list(object)">
      Specifies the environment variables (as key-value pairs) that are applied to branches automatically created for the Amplify app. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name of the environment variable to configure for automatically created branches in the Amplify app. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The value of the environment variable that is automatically set for branches created via auto branch creation in the Amplify app. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="framework" type="string">
      The framework (e.g., React, Angular, Next.js) that AWS Amplify uses to configure the build process for automatically created branches of the app. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="pull_request_environment_name" type="string">
      Sets the name of the environment (for example, 'pr') used for pull request preview deployments in the Amplify app's automatic branch creation configuration, so that pull request branches are built and deployed to a separate preview environment. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stage" type="string">
      The stage (e.g., PRODUCTION, BETA, DEVELOPMENT) assigned to branches created automatically by the Amplify app's auto branch creation configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="basic_auth_config" type="object">
  Configures basic authorization for the Amplify app, including an enable flag and the username and password used to protect access. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enable_basic_auth" type="bool">
      When true, this enables basic authentication for the Amplify app, requiring users to enter the configured username and password to access the app. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="password" type="string">
      The password used for basic authentication to the Amplify app, paired with the username in the basic_auth_config block. Optional. **(AI-inferred)**

      The username used for basic authentication to protect access to the Amplify app's branches. Optional. **(AI-inferred)**

  </Expandable>

<ResponseField name="build_spec" type="string">

  <Expandable title="properties">

    <ResponseField name="source" type="string">
      The source pattern that matches incoming request URLs to trigger the custom rewrite or redirect rule. Optional; if omitted, computed by AWS. **(AI-inferred)**

    <ResponseField name="target" type="string">

## Output properties

<ResponseField name="app_id" type="string">
  The unique ID that AWS Amplify assigns to the app upon creation, used to reference the app in Amplify console and API operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="app_name" type="string">
  The read-only name assigned to the Amplify app, which identifies the application in the Amplify console and is returned by the Amplify service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Amplify app, uniquely identifying it within AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_domain" type="string">
  The default domain automatically assigned to the Amplify app (e.g., a unique subdomain under amplifyapp.com), served as the primary URL for the app. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

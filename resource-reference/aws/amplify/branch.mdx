`aws_amplify_branch` connects one Git branch of an `aws_amplify_app` to its own real, independently deployed environment, so pushing to `main` and pushing to a feature branch produce two separate, live URLs rather than one shared deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	amplify "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/amplify"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own branch"})

    		ubx.Resource(amplify.Branch, "example", amplify.BranchConfig{
    			AppId:           "example",
    			BranchName:      "example-branch-name",
    			Backend:         map[string]any{"stack_arn": "example"},
    			BasicAuthConfig: map[string]any{"password": "example", "username": "example"},
    			BuildSpec:       "example",
    			ComputeRoleArn:  "arn:aws:iam::123456789012:policy/example",
    			Description:     "Managed by ubx.",
    			EnableAutoBuild: true,
    		})
    	}))
    }
    ```

    def describe():
        ubx.intent("example own branch")

## Input properties

<ResponseField name="app_id" type="string" required>
  The unique ID of the Amplify app that this branch belongs to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="backend" type="object">
  The backend configuration for the subdomain, represented as a nested object that contains the ARN of the AWS CloudFormation stack providing the linked backend environment for the branch. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="stack_arn" type="string">
      Specifies the Amazon Resource Name (ARN) of the CloudFormation stack that provides the backend environment for this Amplify branch, associating the branch with the corresponding backend resources. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="basic_auth_config" type="object">
  Configures basic authentication settings (username and password) for the branch, allowing per-branch overrides of the app-level basic auth configuration. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enable_basic_auth" type="bool">
      Enables basic authorization for the Amplify branch, requiring users to enter a username and password to access the branch's app. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="password" type="string" required>
      The password used for basic authentication to access the branch, which must be at least 8 characters and at most 128 characters long. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="username" type="string" required>
      The username for basic authentication that protects access to the Amplify branch's app. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="branch_name" type="string" required>
  The name of the branch in the Amplify app, such as 'main' or 'dev', which uniquely identifies the branch within the Amplify service. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="build_spec" type="string">
  Sets the branch's build specification (buildspec) as a YAML/JSON string, which overrides the app-level build settings for the Amplify branch. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="compute_role_arn" type="string">
  The ARN of the IAM service role that AWS Amplify uses to deploy the branch. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  An optional free-form string that describes the purpose or content of the Amplify branch. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_auto_build" type="bool">
  Indicates whether automatic builds are enabled for the branch, causing Amplify to build the branch automatically every time a code change is pushed to the repository. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_performance_mode" type="bool">
  Optional.
</ResponseField>

<ResponseField name="enable_pull_request_preview" type="bool">
  Indicates whether Amplify automatically generates a preview of the branch for every pull request, enabling you to test changes before merging them into the main branch. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_skew_protection" type="bool">
  When set to true, enables skew protection for the Amplify branch, which redirects users to the correct version of the app when the frontend and backend deployments are out of sync. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="environment_variables" type="list(object)">
  Defines custom environment variables (name/value pairs) available to the Amplify branch for builds and other operations. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name (key) of an environment variable to set for the Amplify branch, which is used to override or provide configuration to the build process. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value assigned to the environment variable key for the Amplify branch. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="framework" type="string">
  Specifies the web framework used to build the application branch, such as React, Next.js, or Angular. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="pull_request_environment_name" type="string">
  Specifies the name of the Amplify backend environment that is used for pull request preview deployments for this branch. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="stage" type="string">
  Configures the deployment stage for the branch, which determines its environment type in AWS Amplify (e.g., PRODUCTION, BETA, DEVELOPMENT, EXPERIMENTAL). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that assign metadata tags to the Amplify branch, which can be used for organizing and managing branch resources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag to attach to the Amplify branch resource for organization and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Amplify branch, used to label the branch with arbitrary metadata such as environment, owner, or cost center. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Amplify branch, assigned by AWS upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

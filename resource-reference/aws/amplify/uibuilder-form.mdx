`aws_amplify_uibuilder_form` is Amplify Studio's form-building counterpart to `aws_amplify_uibuilder_component`, a generated, data-bound form definition rather than a hand-assembled one, wired to an app's real data model.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	ubx.Main(ubx.Stack("example", func() {

    			Fields:          "example",

    		})

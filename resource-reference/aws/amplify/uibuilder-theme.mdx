`aws_amplify_uibuilder_theme` defines the shared visual styling, colors, typography, spacing, that Amplify Studio applies consistently across an app's generated components and forms, so design changes happen in one place rather than per component.

## Input properties

<ResponseField name="app_id" type="string">
  The unique ID of the Amplify application that this UI Builder theme belongs to. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="environment_name" type="string">
  The name of the Amplify backend environment (e.g., dev, prod) to which this UI Builder theme belongs, scoping the theme to that environment within the Amplify app. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable name assigned to the Amplify UI Builder theme, used to identify it in the Amplify console and through the Amplify UI Builder APIs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="overrides" type="list(object)">
  Specifies a list of theme value overrides that supersede the base theme values for the Amplify UI Builder theme. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (unique name) of a single override in the Amplify UI Builder theme's overrides list, which selects the specific theme value to be overridden. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="object">
      For each entry in the `overrides` list, the `value` field holds the concrete string value (such as a color, spacing token, or other style primitive) that is applied in place of the theme's base value when rendering an Amplify UI component. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="children" type="list(any)">
          Optional; if omitted, computed by AWS.
        </ResponseField>
        <ResponseField name="value" type="string">
          The string value of a theme override entry, specifying the actual design-token value (such as a color, spacing, or font size) that replaces the default theme value. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

<ResponseField name="values" type="list(object)">
  Defines the list of theme value objects (key-value pairs) that create design tokens for the Amplify UI Builder theme, where each object can also contain nested children for grouped tokens. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The name of a theme variable (e.g., 'colorPrimary' or 'spacingLarge') defined in the Amplify UI Builder theme's values list, used to reference the variable in generated UI components. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="object">
      In the list of theme tokens, the `value` object holds the actual design token definition, which can be a simple string value or a nested list of child token values that together style Amplify UI components. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="children" type="list(any)">
          This list defines the nested child theme values that branch off the current value, enabling themes to represent hierarchical design token trees. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The theme token value (e.g., a color hex code, size, or other design token string) paired with its key in an AWS Amplify UI Builder theme's values collection. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time (in ISO 8601 format) when the theme was created, automatically set by AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier for this Amplify UI Builder theme, generated by the service upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="modified_at" type="string">
  The timestamp (in ISO 8601 format) indicating when the theme resource was last modified, set automatically by AWS Amplify UI Builder. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

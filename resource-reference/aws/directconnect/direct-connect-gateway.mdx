`aws_direct_connect_direct_connect_gateway` is a real, global resource that lets a single Direct Connect connection reach multiple VPCs across different AWS accounts and Regions, aggregating what would otherwise need a separate connection or virtual interface per VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	directconnect "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/directconnect"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own direct connect gateway"})

    		ubx.Resource(directconnect.DirectConnectGateway, "example", directconnect.DirectConnectGatewayConfig{
    			DirectConnectGatewayName: "example-direct-connect-gateway-name",
    			AmazonSideAsn:            "example",
    			Tags:                     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="amazon_side_asn" type="string">
  The autonomous system number (ASN) for the Amazon side of the connection. Optional.
</ResponseField>

<ResponseField name="direct_connect_gateway_name" type="string" required>
  The name of the Direct Connect gateway. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with the Direct Connect gateway. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Direct Connect gateway, used to categorize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag key attached to the Direct Connect gateway, used for identifying and categorizing the gateway resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="direct_connect_gateway_arn" type="string">
  The ARN of the Direct Connect gateway. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="direct_connect_gateway_id" type="string">
  The ID of the Direct Connect gateway. Computed by AWS after `ship`.
</ResponseField>

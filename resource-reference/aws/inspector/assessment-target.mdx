`aws_inspector_assessment_target` defined a real, tag-based group of EC2 instances that an `aws_inspector_assessment_template` ran a security assessment against, in Amazon Inspector Classic, the original architecture Amazon Inspector shipped with. Inspector Classic is no longer available to new accounts, or to accounts that haven't run an assessment in the last 6 months, and reaches full end of support on May 20, 2026; the redesigned Amazon Inspector (Inspector v2) is the current, actively developed service.

    ```go
    package main

    import (
    	inspector "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/inspector"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own assessment target"})

    		ubx.Resource(inspector.AssessmentTarget, "example", inspector.AssessmentTargetConfig{
    			AssessmentTargetName: "example-assessment-target-name",
    			ResourceGroupArn:     "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="assessment_target_name" type="string">
  The user-defined name for the Amazon Inspector assessment target, used to identify the collection of EC2 instances being assessed. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_group_arn" type="string">
  The ARN of an AWS Resource Groups group that defines the set of EC2 instances to include in this Inspector assessment target. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of this Inspector assessment target, used as a reference when creating Inspector assessment templates. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_inspector_v2_code_security_integration` connects Amazon Inspector to a real source-code platform, GitHub or GitLab, so Inspector's Code Security capability can scan up to 100,000 real repositories' default branches for vulnerabilities directly in the source, shifting detection left of a deployed, running resource. Launched June 2025.

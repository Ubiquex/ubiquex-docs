`aws_inspector_assessment_template` defined the real rules packages and duration for a security assessment run against an `aws_inspector_assessment_target` in Amazon Inspector Classic. Reaches full end of support May 20, 2026, alongside the rest of Inspector Classic.

## Input properties

<ResponseField name="assessment_target_arn" type="string" required>
  The ARN of the AWS Inspector assessment target that this template will run assessments against. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="assessment_template_name" type="string">
  A user-defined name for the assessment template, which must be unique within the AWS Region and is used to identify the template in the Inspector console and API; if omitted, AWS generates a default name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="duration_in_seconds" type="number" required>
  Specifies the duration (in seconds) for which the Inspector assessment run will be executed. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rules_package_arns" type="list(string)" required>
  The list of Amazon Inspector rules package ARNs that define the security checks run against the assessment targets. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_attributes_for_findings" type="list(object)">
  Specifies user-defined key-value pairs (tags) that are assigned to every finding generated by the assessment template, enabling you to filter or categorize findings by these attributes. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined key-value pair that is assigned to findings generated by this assessment template. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined attribute (key-value pair) attached to findings generated by this assessment template, used to categorize or filter findings in Amazon Inspector. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

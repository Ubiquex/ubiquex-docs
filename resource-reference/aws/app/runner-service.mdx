`aws_app_runner_service` deploys source code or a container image directly to a running, scalable, load-balanced web service, without the caller provisioning or choosing underlying compute, App Runner builds and operates it end to end.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    			ObservabilityConfiguration:  map[string]any{"observability_enabled": true},

`aws_app_stream_application` contains the information needed to actually launch one application to a streaming user, referencing the `aws_app_stream_app_block` or image that holds its real files.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appstream "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appstream"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream application"})

    		ubx.Resource(appstream.Application, "example", appstream.ApplicationConfig{
    			AppBlockArn:        "arn:aws:iam::123456789012:policy/example",
    			IconS3Location:     map[string]any{"s3_bucket": "example"},
    			InstanceFamilies:   []string{"example"},
    			LaunchPath:         "example",
    			Name:               "example",
    			Platforms:          []string{"example"},
    			AttributesToDelete: []string{"example"},
    			Description:        "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="app_block_arn" type="string" required>
  The Amazon Resource Name (ARN) of the app block that the application is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="attributes_to_delete" type="list(string)">
  A list of application attribute names to delete from the AppStream application when the CloudFormation stack is updated, used to remove properties that were omitted from the updated template. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-facing description of the AppStream 2.0 application that is displayed to end users when browsing available applications. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string">
  A user-friendly name for the application that is displayed in the AppStream 2.0 application catalog. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="icon_s3_location" type="object" required>
  Specifies the S3 bucket and key where the application's icon image file is stored. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="s3_bucket" type="string" required>
      The S3 bucket that holds the application icon image file for the AppStream application. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_key" type="string" required>
      The S3 object key (path) of the application icon image within the S3 bucket specified by the parent IconS3Location property. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="instance_families" type="list(string)" required>
  Specifies the list of AppStream 2.0 instance families (e.g., GENERAL_PURPOSE, MEMORY_OPTIMIZED) that this application supports, determining which fleet instance types can launch it. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="launch_parameters" type="string">
  The command-line arguments (parameters) passed to the application when it is launched in an AppStream 2.0 streaming session. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="launch_path" type="string" required>
  The path to the executable file of the application that AppStream 2.0 launches on the streaming instance. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The unique name of the AppStream 2.0 application, which serves as its identifier within the AWS account and region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="platforms" type="list(string)" required>
  Identifies the operating system platforms on which the AppStream 2.0 application can be launched, with valid values including WINDOWS and AMAZON_LINUX. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="tag_key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="tag_value" type="string">
      The value of a tag assigned to the AppStream application, paired with the corresponding tag key in the tags list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value for the specified tag key, which can be used to categorize and manage the AppStream application resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="working_directory" type="string">
  Specifies the working directory that the application uses when launched on a streaming instance. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the AppStream 2.0 application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_time" type="string">
  The timestamp when the AppStream application was created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

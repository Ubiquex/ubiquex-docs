`aws_app_runner_auto_scaling_configuration` sets the minimum and maximum provisioned instance count and per-instance concurrency an `aws_app_runner_service` scales within, letting a service scale down to its floor when traffic is low rather than running fixed capacity.

## Example

## Input properties

<ResponseField name="auto_scaling_configuration_name" type="string">
  The customer-provided auto scaling configuration name. When you use it for the first time in an AWS Region, App Runner creates revision number 1 of this name. When you use the same name in subsequent calls, App Runner creates incremental revisions of the configuration. The auto scaling configuration name can be used in multiple revisions of a configuration. Optional.
</ResponseField>

<ResponseField name="max_concurrency" type="number">
  The maximum number of concurrent requests that an instance processes. If the number of concurrent requests exceeds this limit, App Runner scales the service up to use more instances to process the requests. Optional.
</ResponseField>

<ResponseField name="max_size" type="number">
  The maximum number of instances that an App Runner service scales up to. At most MaxSize instances actively serve traffic for your service. Optional.
</ResponseField>

<ResponseField name="min_size" type="number">
  The minimum number of instances that App Runner provisions for a service. The service always has at least MinSize provisioned instances. Some of them actively serve traffic. The rest of them (provisioned and inactive instances) are a cost-effective compute capacity reserve and are ready to be quickly activated. You pay for memory usage of all the provisioned instances. You pay for CPU usage of only the active subset. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of metadata items that you can associate with your auto scaling configuration resource. A tag is a key-value pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to apply to this AWS App Runner auto scaling configuration, used for resource organization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**

    <ResponseField name="value" type="string">
      The value of a tag attached to the App Runner auto scaling configuration, which is a user-defined key-value pair used for labeling and managing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="auto_scaling_configuration_arn" type="string">
  The Amazon Resource Name (ARN) of this auto scaling configuration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="auto_scaling_configuration_revision" type="number">
  The revision of this auto scaling configuration. It's unique among all the active configurations ("Status": "ACTIVE") that share the same AutoScalingConfigurationName. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="latest" type="bool">
  It's set to true for the configuration with the highest Revision among all configurations that share the same AutoScalingConfigurationName. It's set to false otherwise. App Runner temporarily doubles the number of provisioned instances during deployments, to maintain the same capacity for both old and new code. Computed by AWS after `ship`.
</ResponseField>

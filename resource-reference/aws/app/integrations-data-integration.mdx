`aws_app_integrations_data_integration` configures a bulk or bidirectional data connection to an external application, defining what data AppIntegrations pulls in and how it's kept current, distinct from the real-time streaming an `aws_app_integrations_event_integration` handles.

## Input properties

<ResponseField name="description" type="string">
  The data integration description. Optional.
</ResponseField>

<ResponseField name="file_configuration" type="object">
  The configuration for what files should be pulled from the source. Optional.
  <Expandable title="properties">
    <ResponseField name="filters" type="any">
      Restrictions for what files should be pulled from the source. Optional.
    </ResponseField>
    <ResponseField name="folders" type="list(string)" required>
      Identifiers for the source folders to pull all files from recursively. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kms_key" type="string" required>
  The KMS key of the data integration. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the data integration. Required.
</ResponseField>

<ResponseField name="object_configuration" type="any">
  The configuration for what data should be pulled from the source. Optional.
</ResponseField>

<ResponseField name="schedule_config" type="object">
  Defines the schedule for data integration runs, specifying a cron expression for the schedule, the first execution timestamp, and the owner of the source data object. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="first_execution_from" type="string">
      The start date for objects to import in the first flow run. Epoch or ISO timestamp format is supported. Optional.
    </ResponseField>
    <ResponseField name="object" type="string">
      The name of the object to pull from the data source. Optional.
    </ResponseField>
    <ResponseField name="schedule_expression" type="string" required>
      How often the data should be pulled from data source. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="source_uri" type="string" required>
  The URI of the data source. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags (keys and values) associated with the data integration. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="data_integration_arn" type="string">
  The Amazon Resource Name (ARN) of the data integration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifer of the data integration. Computed by AWS after `ship`.
</ResponseField>

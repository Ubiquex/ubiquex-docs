`aws_app_runner_vpc_connector` gives an `aws_app_runner_service` outbound access into a VPC, specifying the subnets and security groups it uses, so the service can reach a private database or internal API that isn't exposed to the public internet.

## Input properties

<ResponseField name="security_groups" type="list(string)">
  A list of IDs of security groups that App Runner should use for access to AWS resources under the specified subnets. If not specified, App Runner uses the default security group of the Amazon VPC. The default security group allows all outbound traffic. Optional.
</ResponseField>

<ResponseField name="subnets" type="list(string)" required>
  A list of IDs of subnets that App Runner should use when it associates your service with a custom Amazon VPC. Specify IDs of subnets of a single Amazon VPC. App Runner determines the Amazon VPC from the subnets you specify. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of metadata items that you can associate with your VPC connector resource. A tag is a key-value pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag that can be attached to the AWS App Runner VPC connector for identification and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair that can be assigned to the App Runner VPC connector for resource organization, access control, and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_connector_name" type="string">
  A name for the VPC connector. If you don't specify a name, AWS CloudFormation generates a name for your VPC connector. Optional.
</ResponseField>

## Output properties

<ResponseField name="vpc_connector_arn" type="string">
  The Amazon Resource Name (ARN) of this VPC connector. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_connector_revision" type="number">
  The revision of this VPC connector. It's unique among all the active connectors ("Status": "ACTIVE") that share the same Name. Computed by AWS after `ship`.
</ResponseField>

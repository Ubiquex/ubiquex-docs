`aws_app_stream_stack` bundles an `aws_app_stream_fleet`, user access policies, and storage configuration into the unit that actually streams applications to users. Users are entitled to stacks, not directly to fleets.

## Input properties

<ResponseField name="access_endpoints" type="list(object)">
  The list of virtual private cloud (VPC) interface endpoint objects. Users of the stack can connect to AppStream 2.0 only through the specified endpoints. Optional.
  <Expandable title="properties">
    <ResponseField name="endpoint_type" type="string">
      Determines the type of access endpoint for the AppStream stack, either APPSTREAM for the AppStream 2.0 streaming interface or INTERNET for a public internet interface. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpce_id" type="string">
      The VPC endpoint ID that AppStream 2.0 uses for this access endpoint, enabling controlled streaming access through a private VPC endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="agent_access_config" type="object">
  The configuration for agent access on a stack. Agent access enables AI agents to interact with desktop applications during streaming sessions. Optional.
  <Expandable title="properties">
    <ResponseField name="s3_bucket_arn" type="string">
      The Amazon Resource Name (ARN) of the Amazon S3 bucket where agent screenshots are stored. Required when ScreenshotsUploadEnabled is true. Optional.
    </ResponseField>
    <ResponseField name="screen_image_format" type="string" required>
      The image format for agent screen captures. Required.
    </ResponseField>
    <ResponseField name="screen_resolution" type="string" required>
      The screen resolution for the agent streaming environment. Required.
    </ResponseField>
    <ResponseField name="screenshots_upload_enabled" type="bool">
      Indicates whether screenshot uploads to Amazon S3 are enabled for agent sessions. Optional.
    </ResponseField>
    <ResponseField name="settings" type="list(object)" required>
      The list of agent access settings that define permissions for each agent action. You must specify at least one setting. Required.
      <Expandable title="properties">
        <ResponseField name="agent_action" type="string">
          Specifies whether to allow or deny access to the AppStream 2.0 agent version indicated by the corresponding version setting, where the action can be 'ALLOW' or 'DENY'. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="permission" type="string">
          Specifies whether the AppStream 2.0 stack permits agent access during streaming sessions, with the permission value controlling the enabled/disabled state of the agent access configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="user_control_mode" type="string">
      The user control mode for agent sessions. This setting determines how users can interact with agent sessions. Valid values are VIEW_ONLY, VIEW_STOP, and DISABLED. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="application_settings" type="object">
  The persistent application settings for users of a stack. Optional.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool" required>
      Enables or disables persistent application settings for users during their streaming sessions. Required.
    </ResponseField>
    <ResponseField name="settings_group" type="string">
      The path prefix for the S3 bucket where users' persistent application settings are stored. You can allow the same persistent application settings to be used across multiple stacks by specifying the same settings group for each stack. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="attributes_to_delete" type="list(string)">
  The stack attributes to delete. Optional.
</ResponseField>

<ResponseField name="content_redirection" type="object">
  The content redirection settings for the stack. Optional.
  <Expandable title="properties">
    <ResponseField name="host_to_client" type="object">
      The configuration for URL redirection. Optional.
      <Expandable title="properties">
        <ResponseField name="allowed_urls" type="list(string)">
          The URLs that are allowed for redirection. Optional.
        </ResponseField>
        <ResponseField name="denied_urls" type="list(string)">
          The URLs that are denied for redirection. Optional.
        </ResponseField>
        <ResponseField name="enabled" type="bool" required>
          Specifies whether URL redirection is enabled or disabled. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="delete_storage_connectors" type="bool">
  This parameter has been deprecated. Deletes the storage connectors currently enabled for the stack. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description to display. Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  The stack name to display. Optional.
</ResponseField>

<ResponseField name="embed_host_domains" type="list(string)">
  The domains where AppStream 2.0 streaming sessions can be embedded in an iframe. You must approve the domains that you want to host embedded AppStream 2.0 streaming sessions. Optional.
</ResponseField>

<ResponseField name="feedback_url" type="string">
  The URL that users are redirected to after they click the Send Feedback link. If no URL is specified, no Send Feedback link is displayed. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the stack. Optional.
</ResponseField>

<ResponseField name="redirect_url" type="string">
  The URL that users are redirected to after their streaming session ends. Optional.
</ResponseField>

<ResponseField name="streaming_experience_settings" type="object">
  The streaming protocol that you want your stack to prefer. This can be UDP or TCP. Currently, UDP is only supported in the Windows native client. Optional.
  <Expandable title="properties">
    <ResponseField name="preferred_protocol" type="string">
      The preferred protocol that you want to use while streaming your application. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS AppStream stack, used to organize and identify the stack for cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of an AWS tag applied to the AppStream 2.0 stack, used for organizing and identifying the stack in cost allocation and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_settings" type="list(object)">
  The actions that are enabled or disabled for users during their streaming sessions. By default, these actions are enabled. Optional.
  <Expandable title="properties">
    <ResponseField name="action" type="string">
      The AppStream 2.0 user action (such as CLIPBOARD_COPY_FROM_LOCAL_DEVICE or FILE_UPLOAD) to which the permission setting applies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="maximum_length" type="number">
      For each entry in the stack's user settings, this field defines the maximum clipboard data size (in bytes) allowed for actions that copy clipboard content to or from the local device. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="permission" type="string">
      Specifies whether the user action (identified by the sibling 'action' field) is enabled or disabled for the AppStream 2.0 stack, with valid values being 'ENABLED' or 'DISABLED'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="storage_connectors" type="list(object)">
  The storage connectors to enable. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="connector_type" type="string">
      The type of storage connector to enable for this AppStream stack, such as HOMEFOLDERS, GOOGLE_DRIVE, or ONE_DRIVE. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="domains" type="list(string)">
      Specifies the list of domains (e.g., Google Drive or OneDrive) that this storage connector is allowed to use, restricting the connector to those domains for file access and synchronization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_identifier" type="string">
      The ResourceIdentifier for a storage connector specifies the backing resource: for HOME_FOLDERS it is the ARN of the Amazon S3 bucket that stores home folders, while for GOOGLE_DRIVE or ONE_DRIVE it is the domain name of the user's cloud storage account. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

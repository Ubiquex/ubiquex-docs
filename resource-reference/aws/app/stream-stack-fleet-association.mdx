---
title: "aws_app_stream_stack_fleet_association"
description: "`aws_app_stream_stack_fleet_association` links an `aws_app_stream_stack` to the `aws_app_stream_fleet` that actually runs its streaming instances."
---

A stack with no fleet association has user access policies and storage configured but nothing to stream from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appstream "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appstream"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream stack fleet association"})

    		ubx.Resource(appstream.StackFleetAssociation, "example", appstream.StackFleetAssociationConfig{
    			FleetName: "example-fleet-name",
    			StackName: "example-stack-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="fleet_name" type="string" required>
  The name of the AppStream 2.0 fleet to associate with the stack. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The name of the AppStream stack that the fleet will be associated with. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  This computed identifier uniquely identifies the AppStream 2.0 stack-fleet association and is formed from the stack name and fleet name separated by a comma. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_app_sync_graph_qlapi` is the CloudFormation resource type for the same underlying concept as `aws_app_sync_api`, an AppSync GraphQL API, present as a distinct, older resource type in the CFN registry rather than a functionally different resource.

## Example

    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sync graph qlapi"})

    		ubx.Resource(app.SyncGraphQlapi, "example", app.SyncGraphQlapiConfig{
    			AuthenticationType:                "example",

    		})
    	}))

## Input properties

<ResponseField name="additional_authentication_providers" type="list(object)">
  A list of additional authentication providers for the GraphqlApi API. Optional.
  <Expandable title="properties">
    <ResponseField name="authentication_type" type="string">
      Defines the AWS AppSync authentication method (e.g., API_KEY, AWS_IAM, AMAZON_COGNITO_USER_POOLS, OPENID_CONNECT, or AWS_LAMBDA) that this additional authentication provider uses to authorize requests to the GraphQL API. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="lambda_authorizer_config" type="object">
      Configures the Lambda authorizer settings, such as the authorizer URI and identity validation expression, for the additional authentication provider on the AppSync GraphQL API. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="authorizer_result_ttl_in_seconds" type="number">
          Specifies the time-to-live (TTL) in seconds for caching the Lambda authorizer result, after which AppSync discards the cached authorization response and invokes the Lambda authorizer again for the next request. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="authorizer_uri" type="string">
          The ARN of the AWS Lambda function that serves as the custom authorizer for this additional AppSync authentication provider, invoked by AppSync to authorize requests. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="identity_validation_expression" type="string">
          Specifies a regular expression that AppSync uses to validate the identity token before invoking the Lambda authorizer function. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="open_idconnect_config" type="object">
      Configuration for an OpenID Connect (OIDC) authentication provider, including the issuer URL, client ID, and optional token TTL settings, used when adding an additional authentication provider to the GraphQL API. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="auth_ttl" type="number">
          The number of milliseconds that an OpenID Connect token remains valid after being issued to a user, controlling token expiration for authentication in AppSync. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="client_id" type="string">
          The client identifier (audience) that AWS AppSync expects in the 'aud' claim of JWT tokens from the configured OpenID Connect provider, used to validate tokens presented by client applications. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="iat_ttl" type="number">
          The number of milliseconds that a token issued by the OpenID Connect provider remains valid after its 'issued at' (iat) time, controlling how long an issued token can be used for authentication. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="issuer" type="string">
          The issuer URL for the OpenID Connect provider, which identifies the OIDC provider issuing the authentication tokens for this additional authentication provider. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="user_pool_config" type="object">
      Configures the Amazon Cognito user pool settings for an additional authentication provider, specifying the user pool ID, AWS region, and default action for authentication. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="app_id_client_regex" type="string">
          A regular expression used to validate the app client ID of the Amazon Cognito user pool that is allowed to authenticate through this additional authentication provider. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="aws_region" type="string">
          The AWS Region in which the specified Amazon Cognito user pool for this additional authentication provider is located. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="user_pool_id" type="string">
          The ID of the Amazon Cognito user pool that this additional authentication provider uses to authenticate requests for the AppSync GraphQL API. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>

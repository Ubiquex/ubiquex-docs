`aws_app_stream_directory_config` stores the details AppStream needs to join image builders and fleet instances to an Active Directory domain, in a specific organizational unit, so streamed sessions can authenticate against a real corporate directory.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream directory config"})

    		ubx.Resource(app.StreamDirectoryConfig, "example", app.StreamDirectoryConfigConfig{
    			DirectoryName:                        "example-directory-name",
    			OrganizationalUnitDistinguishedNames: []string{"example"},
    			ServiceAccountCredentials:            map[string]any{"account_name": "example-account-name"},
    			CertificateBasedAuthProperties:       map[string]any{"certificate_authority_arn": "example"},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="certificate_based_auth_properties" type="object">
  Configures certificate-based authentication for the AppStream 2.0 directory configuration, specifying the status (enabled/disabled) and the ARN of the certificate authority used to issue and validate user certificates. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="certificate_authority_arn" type="string">
      The ARN of the AWS Certificate Manager Private CA that AppStream 2.0 uses to issue certificates for certificate-based authentication in this directory configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="status" type="string">
      Indicates whether certificate-based authentication is enabled or disabled for the AppStream directory configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="directory_name" type="string" required>
  The fully qualified name of the Active Directory domain (for example, corp.example.com) that the AppStream 2.0 directory configuration connects to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="organizational_unit_distinguished_names" type="list(string)" required>
  Specifies the list of organizational unit (OU) distinguished names in the Active Directory where computer objects for streaming instances are created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_account_credentials" type="object" required>
  The service account credentials (account name and password) that AppStream 2.0 uses to join streaming instances to the Active Directory domain. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="account_name" type="string" required>

    </ResponseField>
    <ResponseField name="account_password" type="string" required>
      The password for the service account that AppStream 2.0 uses to join streaming instances to the Active Directory domain. Required. **(AI-inferred)**

  </Expandable>
</ResponseField>

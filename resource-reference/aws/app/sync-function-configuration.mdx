title: "aws_app_sync_function_configuration"
description: "`aws_app_sync_function_configuration` defines a real, reusable unit of resolver logic..."
---

`aws_app_sync_function_configuration` defines a real, reusable unit of resolver logic, a request/response mapping or JavaScript handler against a specific `aws_app_sync_data_source`, that an `aws_app_sync_resolver` can chain together with others in a pipeline resolver instead of duplicating the same logic across multiple resolvers.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sync function configuration"})

    		ubx.Resource(app.SyncFunctionConfiguration, "example", app.SyncFunctionConfigurationConfig{
    			ApiId:           "example",
    			DataSourceName:  "example-data-source-name",
    			Name:            "example",
    			Code:            "example",
    			CodeS3Location:  "example",
    			Description:     "Managed by ubx.",
    			FunctionVersion: "example",
    			MaxBatchSize:    1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_id" type="string" required>
  The AWS AppSync GraphQL API that you want to attach using this function. Required.
</ResponseField>

<ResponseField name="code" type="string">
  The resolver code that contains the request and response functions. When code is used, the runtime is required. The runtime value must be APPSYNC_JS. Optional.
</ResponseField>

<ResponseField name="code_s3_location" type="string">
  The Amazon S3 endpoint (where the code is located??). Optional.
</ResponseField>

<ResponseField name="data_source_name" type="string" required>
  The name of data source this function will attach. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The function description. Optional.
</ResponseField>

<ResponseField name="function_version" type="string">
  The version of the request mapping template. Currently, only the 2018-05-29 version of the template is supported. Optional.
</ResponseField>

<ResponseField name="max_batch_size" type="number">
  The maximum number of resolver request inputs that will be sent to a single AWS Lambda function in a BatchInvoke operation. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the function. Required.
</ResponseField>

<ResponseField name="request_mapping_template" type="string">
  The Function request mapping template. Functions support only the 2018-05-29 version of the request mapping template. Optional.
</ResponseField>

<ResponseField name="request_mapping_template_s3_location" type="string">
  Describes a Sync configuration for a resolver. Contains information on which Conflict Detection, as well as Resolution strategy, should be performed when the resolver is invoked. Optional.
</ResponseField>

<ResponseField name="response_mapping_template" type="string">
  The Function response mapping template. Optional.
</ResponseField>

<ResponseField name="response_mapping_template_s3_location" type="string">
  The location of a response mapping template in an Amazon S3 bucket. Use this if you want to provision with a template file in Amazon S3 rather than embedding it in your CloudFormation template. Optional.
</ResponseField>

<ResponseField name="runtime" type="object">
  Describes a runtime used by an AWS AppSync pipeline resolver or AWS AppSync function. Specifies the name and version of the runtime to use. Note that if a runtime is specified, code must also be specified. Optional.
  <Expandable title="properties">
    <ResponseField name="name" type="string" required>
      The name of the runtime to use. Currently, the only allowed value is APPSYNC_JS. Required.
    </ResponseField>
    <ResponseField name="runtime_version" type="string" required>
      The version of the runtime to use. Currently, the only allowed version is 1.0.0. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sync_config" type="object">
  Describes a Sync configuration for a resolver. Specifies which Conflict Detection strategy and Resolution strategy to use when the resolver is invoked. Optional.
  <Expandable title="properties">
    <ResponseField name="conflict_detection" type="string" required>
      The Conflict Detection strategy to use. Required.
    </ResponseField>
    <ResponseField name="conflict_handler" type="string">
      The Conflict Resolution strategy to perform in the event of a conflict. Optional.
    </ResponseField>
    <ResponseField name="lambda_conflict_handler_config" type="object">
      The LambdaConflictHandlerConfig when configuring LAMBDA as the Conflict Handler. Optional.
      <Expandable title="properties">
        <ResponseField name="lambda_conflict_handler_arn" type="string">
          The Amazon Resource Name (ARN) for the Lambda function to use as the Conflict Handler. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

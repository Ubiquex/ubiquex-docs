`aws_app_integrations_event_integration` streams events from a partner application into an EventBridge event bus, with its own filters and event sources, so downstream AWS services can react to changes in an external system in near real time rather than polling for them.

## Input properties

<ResponseField name="description" type="string">
  The event integration description. Optional.
</ResponseField>

<ResponseField name="event_bridge_bus" type="string" required>
  The Amazon Eventbridge bus for the event integration. Required.
</ResponseField>

<ResponseField name="event_filter" type="object" required>

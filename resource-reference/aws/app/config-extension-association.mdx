`aws_app_config_extension_association` attaches an `aws_app_config_extension` to a specific AppConfig resource, an application or a configuration profile, and is what actually invokes the extension at its defined lifecycle points. An extension defined but never associated never runs.

## Input properties

<ResponseField name="extension_identifier" type="string">
  The name, ID, or Amazon Resource Name (ARN) of the AWS AppConfig extension to associate with the target resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="extension_version_number" type="number">
  The version number of the extension to associate with the resource; if not specified, the latest version of the extension is used. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameters" type="any">
  Specifies the key-value pairs of parameters defined by the AppConfig extension that are passed to the extension when it runs for the associated resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_identifier" type="string">
  The ARN of the AppConfig application, environment, or configuration profile to which the extension is associated and will be applied. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the AppConfig extension association, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the AppConfig extension association, where the tag key is the map key in the tags block. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

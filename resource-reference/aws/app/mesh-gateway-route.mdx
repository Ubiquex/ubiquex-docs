`aws_app_mesh_gateway_route` matches incoming traffic at an `aws_app_mesh_virtual_gateway` and directs it to a virtual service inside the mesh, the ingress counterpart to the routes an `aws_app_mesh_virtual_router` uses for traffic already inside the mesh.

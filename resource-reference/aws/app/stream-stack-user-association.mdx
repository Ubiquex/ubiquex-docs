`aws_app_stream_stack_user_association` grants a real AppStream 2.0 user access to an `aws_app_stream_stack`, the resource that actually authorizes that specific user to launch streaming sessions from it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own stream stack user association"})

    		ubx.Resource(app.StreamStackUserAssociation, "ci-runner", app.StreamStackUserAssociationConfig{
    			AuthenticationType:    "example",
    			StackName:             "example-stack-name",
    			UserName:              "example-user-name",
    			SendEmailNotification: true,
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="authentication_type" type="string" required>
  The authentication type for the user who is associated with the stack. You must specify USERPOOL. Required.
</ResponseField>

<ResponseField name="send_email_notification" type="bool">
  Specifies whether a welcome email is sent to a user after the user is created in the user pool. Optional.
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The name of the stack that is associated with the user. Required.
</ResponseField>

<ResponseField name="user_name" type="string" required>
  The name of the user who is associated with the stack. Required.
</ResponseField>

---
title: "aws_app_stream_user"
description: "`aws_app_stream_user` creates a real AppStream 2.0 user identity..."
---

`aws_app_stream_user` creates a real AppStream 2.0 user identity, managed directly by AppStream rather than federated from an external identity provider, that an `aws_app_stream_stack_user_association` can then grant stack access to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appstream "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appstream"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream user"})

    		ubx.Resource(appstream.User, "example", appstream.UserConfig{
    			AuthenticationType: "example",
    			UserName:           "example-user-name",
    			FirstName:          "example-first-name",
    			LastName:           "example-last-name",
    			MessageAction:      "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="authentication_type" type="string" required>
  The authentication type for the user. Required.
</ResponseField>

<ResponseField name="first_name" type="string">
  The first name, or given name, of the user. Optional.
</ResponseField>

<ResponseField name="last_name" type="string">
  The last name, or surname, of the user. Optional.
</ResponseField>

<ResponseField name="message_action" type="string">
  The action to take for the welcome email that is sent to a user after the user is created in the user pool. If you specify SUPPRESS, no email is sent. If you specify RESEND, do not specify the first name or last name of the user. If the value is null, the email is sent. Optional.
</ResponseField>

<ResponseField name="user_name" type="string" required>
  The email address of the user. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Returns the Amazon Resource Name (ARN) for the Amazon AppStream User resource. Computed by AWS after `ship`.
</ResponseField>

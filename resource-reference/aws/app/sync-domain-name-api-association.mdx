---
title: "aws_app_sync_domain_name_api_association"
description: "`aws_app_sync_domain_name_api_association` is the actual link between an `aws_app_sync_domain_name` and the `aws_app_sync_api` it should route to."
---

A registered domain with no association routes nowhere.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own sync domain name api association"})

    		ubx.Resource(app.SyncDomainNameApiAssociation, "ci-runner", app.SyncDomainNameApiAssociationConfig{
    			ApiId:      "example",
    			DomainName: "example-domain-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_id" type="string" required>
  The ID of the AppSync API to associate with the custom domain name. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  The custom domain name (e.g., api.example.com) that is associated with the AWS AppSync API. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="api_association_identifier" type="string">
  The unique identifier that AWS AppSync assigns to the domain name -- API association, usable to reference the association in API calls and automation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

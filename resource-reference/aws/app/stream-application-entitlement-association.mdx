`aws_app_stream_application_entitlement_association` links a specific `aws_app_stream_application` to an `aws_app_stream_entitlement`, the actual grant that makes that one application, rather than every application in the stack, subject to that entitlement's SAML-based access rule.

## Example

    ```go
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream application entitlement association"})

    		ubx.Resource(app.StreamApplicationEntitlementAssociation, "example", app.StreamApplicationEntitlementAssociationConfig{
    			ApplicationIdentifier: "example",
    			EntitlementName:       "example-entitlement-name",
    			StackName:             "example-stack-name",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="application_identifier" type="string" required>
  The ARN of the AppStream application that is being associated with the entitlement. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="entitlement_name" type="string" required>
  The name of the AppStream 2.0 entitlement that the application is being associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The name of the AppStream 2.0 stack to which the application and entitlement association is attached. Required. **(AI-inferred)**
</ResponseField>

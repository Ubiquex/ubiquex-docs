`aws_app_stream_application_fleet_association` links an `aws_app_stream_application` to the `aws_app_stream_fleet` it's actually streamed from, real for the app-block model where an application isn't already baked into a fleet's own image.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream application fleet association"})

    		ubx.Resource(app.StreamApplicationFleetAssociation, "example", app.StreamApplicationFleetAssociationConfig{
    			ApplicationArn: "arn:aws:iam::123456789012:policy/example",
    			FleetName:      "example-fleet-name",
    		})
    	}))
    }
    ```
  </Tab>

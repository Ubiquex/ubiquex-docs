`aws_app_sync_graph_qlschema` is the GraphQL schema document attached to an `aws_app_sync_graph_qlapi`, the real type definitions AppSync validates queries and mutations against and routes to resolvers.

## Input properties

<ResponseField name="api_id" type="string" required>
  The unique identifier (API ID) of the AWS AppSync GraphQL API to which this schema definition is attached. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="definition" type="string">
  The GraphQL schema definition text, which defines the types, queries, mutations, and subscriptions for the AppSync GraphQL API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="definition_s3_location" type="string">
  The S3 URI (e.g., s3://bucket/key) of the GraphQL schema definition file, used as an alternative to providing the schema inline via the `definition` argument. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The id is the GraphQL API ID that this schema is attached to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_app_sync_resolver` maps one GraphQL field to a real operation against an `aws_app_sync_data_source`, written in JavaScript/TypeScript or Velocity Template Language, the actual logic that turns a GraphQL query into a request against a real backend and shapes its response back into the schema.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	app "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/app"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sync resolver"})

    		ubx.Resource(app.SyncResolver, "example", app.SyncResolverConfig{
    			ApiId:          "example",
    			FieldName:      "example-field-name",
    			TypeName:       "example-type-name",
    			CachingConfig:  map[string]any{"ttl": 1},
    			Code:           "example",
    			CodeS3Location: "example",
    			DataSourceName: "example-data-source-name",
    			Kind:           "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_id" type="string" required>
  The APSYlong GraphQL API to which you want to attach this resolver. Required.
</ResponseField>

<ResponseField name="caching_config" type="object">
  The caching configuration for a resolver that has caching activated. Optional.
  <Expandable title="properties">
    <ResponseField name="caching_keys" type="list(string)">
      The caching keys for a resolver that has caching activated. Valid values are entries from the ``$context.arguments``, ``$context.source``, and ``$context.identity`` maps. Optional.
    </ResponseField>
    <ResponseField name="ttl" type="number" required>
      The TTL in seconds for a resolver that has caching activated. Valid values are 1 -- 3,600 seconds. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="code" type="string">
  The ``resolver`` code that contains the request and response functions. When code is used, the ``runtime`` is required. The runtime value must be ``APPSYNC_JS``. Optional.
</ResponseField>

<ResponseField name="code_s3_location" type="string">
  The Amazon S3 endpoint. Optional.
</ResponseField>

<ResponseField name="data_source_name" type="string">
  The resolver data source name. Optional.
</ResponseField>

<ResponseField name="field_name" type="string" required>
  The GraphQL field on a type that invokes the resolver. Required.
</ResponseField>

<ResponseField name="kind" type="string">
  The resolver type. + *UNIT*: A UNIT resolver type. A UNIT resolver is the default resolver type. You can use a UNIT resolver to run a GraphQL query against a single data source. + *PIPELINE*: A PIPELINE resolver type. You can use a PIPELINE resolver to invoke a series of ``Function`` objects in a serial manner. You can use a pipeline resolver to run a GraphQL query against multiple data sources. Optional.
</ResponseField>

<ResponseField name="max_batch_size" type="number">
  The maximum number of resolver request inputs that will be sent to a single LAMlong function in a ``BatchInvoke`` operation. Optional.
</ResponseField>

<ResponseField name="metrics_config" type="string">
  Enables or disables enhanced resolver metrics for specified resolvers. Note that ``MetricsConfig`` won't be used unless the ``resolverLevelMetricsBehavior`` value is set to ``PER_RESOLVER_METRICS``. If the ``resolverLevelMetricsBehavior`` is set to ``FULL_REQUEST_RESOLVER_METRICS`` instead, ``MetricsConfig`` will be ignored. However, you can still set its value. Optional.
</ResponseField>

<ResponseField name="pipeline_config" type="object">
  Use the ``PipelineConfig`` property type to specify ``PipelineConfig`` for an APSYlong resolver. ``PipelineConfig`` is a property of the [AWS::AppSync::Resolver](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-appsync-resolver.html) resource. Optional.
  <Expandable title="properties">
    <ResponseField name="functions" type="list(string)">
      A list of ``Function`` objects. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="request_mapping_template" type="string">
  The request mapping template. Request mapping templates are optional when using a Lambda data source. For all other data sources, a request mapping template is required. Optional.
</ResponseField>

<ResponseField name="request_mapping_template_s3_location" type="string">
  The location of a request mapping template in an S3 bucket. Use this if you want to provision with a template file in S3 rather than embedding it in your CFNshort template. Optional.
</ResponseField>

<ResponseField name="response_mapping_template" type="string">
  The response mapping template. Optional.
</ResponseField>

<ResponseField name="response_mapping_template_s3_location" type="string">
  The location of a response mapping template in an S3 bucket. Use this if you want to provision with a template file in S3 rather than embedding it in your CFNshort template. Optional.
</ResponseField>

<ResponseField name="runtime" type="object">
  Describes a runtime used by an APSYlong resolver or APSYlong function. Specifies the name and version of the runtime to use. Note that if a runtime is specified, code must also be specified. Optional.
  <Expandable title="properties">
    <ResponseField name="name" type="string" required>
      The ``name`` of the runtime to use. Currently, the only allowed value is ``APPSYNC_JS``. Required.
    </ResponseField>
    <ResponseField name="runtime_version" type="string" required>
      The ``version`` of the runtime to use. Currently, the only allowed version is ``1.0.0``. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sync_config" type="object">
  Describes a Sync configuration for a resolver. Specifies which Conflict Detection strategy and Resolution strategy to use when the resolver is invoked. Optional.
  <Expandable title="properties">
    <ResponseField name="conflict_detection" type="string" required>
      The Conflict Detection strategy to use. + *VERSION*: Detect conflicts based on object versions for this resolver. + *NONE*: Do not detect conflicts when invoking this resolver. Required.
    </ResponseField>
    <ResponseField name="conflict_handler" type="string">
      The Conflict Resolution strategy to perform in the event of a conflict. + *OPTIMISTIC_CONCURRENCY*: Resolve conflicts by rejecting mutations when versions don't match the latest version at the server. + *AUTOMERGE*: Resolve conflicts with the Automerge conflict resolution strategy. + *LAMBDA*: Resolve conflicts with an LAMlong function supplied in the ``LambdaConflictHandlerConfig``. Optional.
    </ResponseField>
    <ResponseField name="lambda_conflict_handler_config" type="object">
      The ``LambdaConflictHandlerConfig`` when configuring LAMBDA as the Conflict Handler. Optional.
      <Expandable title="properties">
        <ResponseField name="lambda_conflict_handler_arn" type="string">
          The Amazon Resource Name (ARN) for the Lambda function to use as the Conflict Handler. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type_name" type="string" required>
  The GraphQL type that invokes this resolver. Required.
</ResponseField>

## Output properties

</ResponseField>

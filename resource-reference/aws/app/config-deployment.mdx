`aws_app_config_deployment` starts the actual rollout of a specific configuration version to an `aws_app_config_environment`, following a chosen `aws_app_config_deployment_strategy` and validated against any validators the `aws_app_config_configuration_profile` defines, with automatic CloudWatch-alarm-triggered rollback if something breaks mid-rollout.

## Input properties

<ResponseField name="application_id" type="string" required>
  The application ID. Required.
</ResponseField>

<ResponseField name="configuration_profile_id" type="string" required>
  The configuration profile ID. Required.
</ResponseField>

<ResponseField name="configuration_version" type="string" required>
  The configuration version to deploy. If deploying an AWS AppConfig hosted configuration version, you can specify either the version number or version label. For all other configurations, you must specify the version number. Required.
</ResponseField>

<ResponseField name="deployment_strategy_id" type="string" required>
  The deployment strategy ID. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the deployment. Optional.
</ResponseField>

<ResponseField name="dynamic_extension_parameters" type="list(object)">
  A list of key-value pairs that specify dynamic parameter values to be passed to the AppConfig extension hooks (e.g., Lambda functions) when the deployment is executed. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="extension_reference" type="string">
      The name of the AppConfig extension that consumes this dynamic parameter during deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameter_name" type="string">
      The name of the dynamic extension parameter being set for the AppConfig deployment, used to pass custom configuration to an extension (such as a Lambda function) during a deployment event. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameter_value" type="string">
      Provides the dynamic value supplied to an extension parameter at deployment time, overriding the extension's default parameter value for this deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="environment_id" type="string" required>

`aws_app_sync_source_api_association` links a source `aws_app_sync_api` into a merged API, AppSync's federation feature for combining multiple independently-owned GraphQL APIs into one endpoint that a client queries as if it were a single schema.

## Input properties

<ResponseField name="description" type="string">
  Description of the SourceApiAssociation. Optional.
</ResponseField>

<ResponseField name="merged_api_identifier" type="string">
  Identifier of the Merged GraphQLApi to associate. It could be either GraphQLApi ApiId or ARN Optional.
</ResponseField>

<ResponseField name="source_api_association_config" type="any">
  The configuration for this AppSync source API association, including the merge type (AUTO_MERGE or MANUAL_MERGE) that controls how the source API's schema is merged into the associated merged API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="source_api_identifier" type="string">
  Identifier of the Source GraphQLApi to associate. It could be either GraphQLApi ApiId or ARN Optional.
</ResponseField>

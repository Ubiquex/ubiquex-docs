---
title: "aws_app_stream_image_builder"
description: "`aws_app_stream_image_builder` is a virtual machine used to install, configure, and test applications before capturing them into an immutable image."
---

Once an image is created it can't be edited in place, changing it means building a new image from a fresh image builder.

## Example

    func main() {

    		})
    	}))
    }

## Input properties

<ResponseField name="access_endpoints" type="list(object)">
  Specifies the VPC endpoints (via endpoint type and VPC endpoint ID) used for the image builder's streaming sessions, controlling the network access for the image builder. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="endpoint_type" type="string">
      Specifies whether the VPC endpoint for this access endpoint is used for AppStream 2.0 streaming or desktop sessions, with valid values such as AppStream.Streaming and AppStream.Desktop. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpce_id" type="string">
      The ID of the VPC endpoint used as a private access endpoint for the image builder's streaming session. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="appstream_agent_version" type="string">
  Specifies the version of the AppStream 2.0 agent to install on the image builder, such as a date-based version string (e.g., '01-04-2022') or 'LATEST' to use the latest version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-provided description of the AppStream 2.0 image builder. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string">
  The display name of the image builder, which is a user-friendly name shown in the AppStream 2.0 console. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_join_info" type="object">
  Specifies the Active Directory domain and service account credentials used to join the image builder to a domain. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="directory_name" type="string">
      The fully qualified name of the Active Directory domain (e.g., example.com) that the image builder joins via the domain join configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="organizational_unit_distinguished_name" type="string">
      The distinguished name of the organizational unit in the Active Directory domain where the image builder computer account is created. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="enable_default_internet_access" type="bool">
  Whether the image builder has default internet access enabled, allowing it to connect to the internet without a custom VPC configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="iam_role_arn" type="string">
  The ARN of the IAM role that AppStream 2.0 assumes to grant the image builder permissions to access AWS services and resources on your behalf. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="image_arn" type="string">
  The ARN of the AppStream image to use as the base for this image builder. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="image_name" type="string">
  The name of the AppStream 2.0 image used as the base for the image builder. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  The Amazon EC2 instance type (e.g., stream.standard.medium) used to launch the AppStream 2.0 image builder, determining the compute and memory resources available during image creation. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the AppStream 2.0 image builder, which must be unique within the AWS account and is used to identify the image builder in AppStream 2.0. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="root_volume_config" type="object">
  Specifies the size and encryption settings for the root volume of the AppStream 2.0 image builder, including the volume size in gigabytes and an optional AWS KMS key for encryption. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="volume_size_in_gb" type="number">
      Specifies the size of the root volume of the image builder in gigabytes. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="softwares_to_install" type="list(string)">
  A list of software applications to install on the image builder during initial setup, enabling common applications like Chrome or Firefox to be pre-installed for customized images. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="softwares_to_uninstall" type="list(string)">
  Specifies a list of software to uninstall from the base image when creating the AppStream image builder, letting you remove pre-installed applications to customize the image for your needs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the list of key-value tags to attach to the AppStream 2.0 image builder resource. Optional. **(AI-inferred)**
  <Expandable title="properties">

    <ResponseField name="value" type="string">

  </Expandable>
</ResponseField>

<ResponseField name="vpc_config" type="object">

  <Expandable title="properties">

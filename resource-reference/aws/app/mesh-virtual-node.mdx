---
title: "aws_app_mesh_virtual_node"
description: "`aws_app_mesh_virtual_node` is a logical pointer to one real, discoverable service (an ECS service, a Kubernetes deployment) inside an `aws_app_mesh_mesh`."
---

The proxy deployed alongside that real service reads its virtual node's configuration to decide how to route outbound traffic.

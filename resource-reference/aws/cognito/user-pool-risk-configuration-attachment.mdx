`aws_cognito_user_pool_risk_configuration_attachment` configures real adaptive authentication for an `aws_cognito_user_pool`, scoring each sign-in for risk based on IP address, device, and behavioral factors, and requiring extra MFA or blocking the attempt outright at higher risk levels.

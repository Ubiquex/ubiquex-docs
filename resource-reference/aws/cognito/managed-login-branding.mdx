`aws_cognito_managed_login_branding` applies real visual branding, logo, colors, layout, to an `aws_cognito_user_pool`'s managed login pages through a no-code visual editor or a large set of programmatic style options, rather than every sign-in page looking like Cognito's own unbranded default.

## Input properties

<ResponseField name="assets" type="list(object)">
  Specifies the list of image assets (such as logos, icons, and email graphics) to associate with the managed login branding, where each asset defines a category, resource identifier, and optional file URI. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="bytes" type="string">
      Base64-encoded binary data for the brand asset, such as a logo, icon, or favicon, used in the Cognito managed login branding configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="category" type="string">
      Specifies the type of the managed login brand asset, such as FAVICON, LOGO, BACKGROUND, or CSS, which determines where and how the asset is applied to the user pool's managed login pages. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="color_mode" type="string">
      Indicates the display theme (light or dark) for which an asset in the managed login branding is intended, so the appropriate asset variant is served when the login page renders in that color mode. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="extension" type="string">
      The file extension (e.g., png, jpg, ico, svg) of a brand asset used in the managed login branding, indicating the image format of the asset's binary content. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_id" type="string">
      The unique identifier for a custom branding asset (such as a logo or icon) within the Cognito managed login branding, used to reference or update that specific asset in subsequent operations. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="client_id" type="string">
  The unique identifier of the Amazon Cognito app client to which this managed login branding is applied. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="return_merged_resources" type="bool">
  Indicates whether the API should return the merged branding resources (combination of user pool and client branding settings) after applying managed login branding, rather than only the explicitly provided values. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="settings" type="any">
  The JSON object containing the customizable branding settings (such as colors, logo, and layout) that are applied to the managed login pages of the associated user pool app client. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="use_cognito_provided_values" type="bool">
  Indicates whether to use the preset branding provided by Amazon Cognito for the managed login experience, rather than the custom values you supply for the branding configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The ID of the user pool for which managed login branding is configured. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="managed_login_branding_id" type="string">
  The unique identifier assigned by Amazon Cognito to this managed login branding configuration. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

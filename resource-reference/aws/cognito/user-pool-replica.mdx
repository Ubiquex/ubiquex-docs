`aws_cognito_user_pool_replica` creates a real, secondary copy of an `aws_cognito_user_pool` in another AWS Region for multi-Region failover, supporting a growing subset of authentication and session operations locally depending on whether the replica is active or inactive.

## Properties

<ResponseField name="region_name" type="string" required>
  Specifies the AWS region where the Cognito user pool replica is created, which must be different from the primary pool's region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The ID of the original user pool in the primary region that this replica is created from, which is required to set up the cross-region replica. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_pool_tags_at_create" type="any">
  Sets the initial tags on the user pool replica at creation, which are key-value pairs that help manage, identify, and categorize the resource. Optional. **(AI-inferred)**
</ResponseField>

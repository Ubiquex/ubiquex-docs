`aws_cognito_identity_pool_principal_tag` maps an `aws_cognito_identity_pool`'s real claims from one specific identity provider into IAM principal tags on a user's temporary AWS STS session, enabling attribute-based access control policies keyed on those tags.

## Properties

<ResponseField name="identity_pool_id" type="string" required>
  The unique identifier of the Cognito identity pool to which these principal tags are associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_provider_name" type="string" required>
  The name of the identity provider (such as 'Facebook', 'Google', or a custom provider) that this principal tag configuration applies to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="principal_tags" type="any">
  A map of key-value pairs that define the principal tags to attach to the identity pool's principal for the specified identity provider. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="use_defaults" type="bool">
  Indicates whether to use the default principal tag mappings for the identity provider, causing Cognito to automatically apply its standard tags (such as 'role') instead of the custom principal tags you specify. Optional. **(AI-inferred)**
</ResponseField>

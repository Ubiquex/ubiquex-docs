`aws_cognito_user_pool_resource_server` defines a real API an `aws_cognito_user_pool` can issue OAuth access tokens scoped to, the mechanism behind machine-to-machine authorization and fine-grained API access control in Cognito rather than a single, undifferentiated access token.

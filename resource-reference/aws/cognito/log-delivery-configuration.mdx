`aws_cognito_log_delivery_configuration` routes an `aws_cognito_user_pool`'s own real audit and activity logs, sign-in events, user notifications, by event source and log level, to a specific CloudWatch Logs log group, rather than that activity going unrecorded outside CloudTrail's own API-call logging.

    }

## Input properties

<ResponseField name="log_configurations" type="list(object)">
  Specifies the list of log delivery configurations for the user pool, each defining the event source (e.g., userNotification, userAuthEvents), the log level (e.g., ERROR, INFO), and the destination CloudWatch log group to which Amazon Cognito delivers user activity logs. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cloud_watch_logs_configuration" type="object">
      Specifies the CloudWatch Logs log group (via its ARN) that receives Cognito user pool audit logs for the corresponding event source in the log delivery configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="log_group_arn" type="string">
          The ARN of the CloudWatch Logs log group where Cognito user pool logs are delivered when CloudWatch Logs is the log destination. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="event_source" type="string">
      Identifies which event source within the Cognito user pool (userNotification or userAuthEvents) this log configuration applies to, controlling which activity is delivered to the associated CloudWatch log group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="firehose_configuration" type="object">
      Specifies the Amazon Data Firehose delivery stream destination for a given log type, including the ARN of the delivery stream to which logs are delivered. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="stream_arn" type="string">
          The Amazon Resource Name (ARN) of the Kinesis Data Firehose delivery stream that receives the specified user pool log events for this log delivery configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="log_level" type="string">
      Determines the verbosity of logs (either ERROR or INFO) that are delivered to CloudWatch Logs for a specific event source in the user pool's log delivery configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_configuration" type="object">
      Specifies the Amazon S3 bucket destination (by bucket ARN) for delivering a particular log level from a Cognito user pool, used within one log configuration entry. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bucket_arn" type="string">
          The ARN of the Amazon S3 bucket to which Amazon Cognito user pool logs are delivered for this log configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The ID of the Amazon Cognito user pool to which this log delivery configuration applies. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the user pool to which this log delivery configuration belongs, acting as the resource's primary identifier. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

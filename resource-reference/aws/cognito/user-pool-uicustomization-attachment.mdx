`aws_cognito_user_pool_uicustomization_attachment` applies CSS and logo customization to an `aws_cognito_user_pool`'s legacy Hosted UI (classic) sign-in pages, the older customization mechanism that `aws_cognito_managed_login_branding` supersedes for user pools on managed login.

## Properties

<ResponseField name="client_id" type="string" required>
  The unique ID of the user pool app client to which this UI customization is attached. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="css" type="string">
  The CSS string that defines the custom styling for the user pool's hosted UI pages. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The user_pool_id specifies the unique identifier of the Amazon Cognito User Pool where the UI customization will be applied. Required. **(AI-inferred)**
</ResponseField>

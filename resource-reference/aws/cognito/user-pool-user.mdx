`aws_cognito_user_pool_user` is a real, individual user record created directly inside an `aws_cognito_user_pool`, administrator-created rather than self-registered, with its own attributes and initial credential state.

## Properties

<ResponseField name="client_metadata" type="any">
  A map of custom key-value pairs that are passed to AWS Lambda triggers (such as PreSignUp, PostConfirmation, etc.) when a user is created in the Cognito user pool. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="desired_delivery_mediums" type="list(string)">
  Specifies the delivery channels (email, SMS, or both) through which the newly created Cognito user receives the temporary password and invitation to set their password. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="force_alias_creation" type="bool">
  If set to true, this property allows the user to be created even when the specified username or an alias (such as email or phone number) already exists in the user pool, suppressing the error that would otherwise occur. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="message_action" type="string">
  When creating a user in the Cognito user pool, this optional value controls the invitation message behavior: 'RESEND' resends the invitation message, while 'SUPPRESS' suppresses it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_attributes" type="list(object)">
  Specifies the custom attributes for the user, where each attribute provides a name and value, used to set user information during user creation in the Cognito user pool. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Specifies the name of a user attribute (e.g., 'email', 'phone_number', or a custom attribute prefixed with 'custom:') for a user in an Amazon Cognito user pool. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The actual value for a user pool user attribute (e.g., an email address or phone number), paired with the attribute's Name in the same UserAttributes entry. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The ID of the Cognito User Pool in which the user is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="username" type="string">
  Specifies the username for the user in the Cognito user pool, which can be an email address, phone number, or custom string used for sign-in. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="validation_data" type="list(object)">
  Validation data (key-value pairs) provided by the caller to validate the user's attributes during user creation, which is passed to pre-sign-up Lambda triggers for custom validation and is not stored as persistent user attributes. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of a temporary custom attribute included in the validation data for the user pool user, which is passed to the pre sign-up Lambda trigger for validation and then discarded. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a name-value pair in the validation data for the user, such as an email address or phone number, used to temporarily verify ownership during user creation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_cognito_identity_pool_role_attachment` maps real IAM roles to an `aws_cognito_identity_pool`, by default role, by rules against a user's claims, or by their `aws_cognito_user_pool_group` membership, the actual configuration that determines which role a user gets credentials for.

## Input properties

<ResponseField name="identity_pool_id" type="string" required>
  The unique identifier of the Cognito identity pool to which this role attachment configuration applies. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_mappings" type="any">
  Specifies the mapping of identity providers to role-mapping configurations, determining which IAM role a user authenticated through a given provider is assigned based on token claims or rule-based conditions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="roles" type="any">
  Specifies a mapping of identity pool role types (such as 'authenticated' or 'unauthenticated') to the IAM role ARNs that define the permissions for users in each category. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the Amazon Cognito identity pool that this role attachment configuration applies to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

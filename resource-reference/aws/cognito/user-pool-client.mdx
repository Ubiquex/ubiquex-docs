`aws_cognito_user_pool_client` registers a real, specific application, a web app, a mobile app, a backend service, against an `aws_cognito_user_pool`, with its own allowed OAuth flows, callback URLs, and token settings, the actual identity a caller authenticates as when it talks to the user pool.

## Input properties

<ResponseField name="access_token_validity" type="number">
  The validity duration, in minutes, for access tokens issued by this Cognito user pool client, after which they expire. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="allowed_oauth_flows" type="list(string)">
  The list of allowed OAuth flows (such as code, implicit, or client_credentials) for the user pool client, which determines how tokens can be obtained via the hosted UI or API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="allowed_oauth_flows_user_pool_client" type="bool">
  This boolean enables the OAuth 2.0 authorization flows (such as authorization code, implicit, and client credentials) for this user pool client, allowing it to be used with the hosted UI and OAuth tokens. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="allowed_oauth_scopes" type="list(string)">
  Defines the list of OAuth 2.0 scopes that the user pool client is allowed to request (e.g., email, phone, openid, profile, or custom scopes), controlling the access scope granted during the authorization code or implicit OAuth flows. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="analytics_configuration" type="object">
  Configures the Amazon Pinpoint analytics settings for the user pool client, including the Pinpoint application ID, IAM role ARN, external ID, and whether user data is shared, to enable tracking of user events. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="application_arn" type="string">
      The ARN of the Amazon Pinpoint project or Amazon Kinesis Data Firehose delivery stream used by the user pool client's analytics configuration to send user activity data. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="application_id" type="string">
      The Amazon Pinpoint application ID that receives user pool client analytics data. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="external_id" type="string">
      Specifies the external ID that Amazon Cognito uses when it assumes the IAM role defined in the analytics configuration to send user activity data to the analytics application. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="role_arn" type="string">
      The ARN of the IAM role that Amazon Cognito assumes to publish analytics events to Amazon Pinpoint for this user pool client. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="user_data_shared" type="bool">
      Indicates whether user data from the user pool client is shared with the configured Amazon Pinpoint analytics provider. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="auth_session_validity" type="number">
  The number of minutes (1-15) that an authentication session remains valid before expiring, controlling how long a user can complete the interactive sign-in flow without restarting. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="callback_urls" type="list(string)">
  List of allowed callback URLs for the Cognito user pool client's OAuth 2.0 authorization endpoints, which Cognito redirects to after authentication. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_name" type="string">
  The name of the user pool client, used to identify the client application in the AWS Management Console and in API responses. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_redirect_uri" type="string">
  The URI that the user is redirected to after sign-in or sign-out if no redirect_uri parameter is supplied in the authorization request. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_propagate_additional_user_context_data" type="bool">
  Indicates whether the user pool client propagates additional user context data (such as device fingerprints) to the user pool for advanced security risk evaluation. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_token_revocation" type="bool">
  Enable token revocation for the user pool client, allowing Cognito to revoke refresh tokens (e.g., after a password change or user disablement) so they can no longer be used. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="explicit_auth_flows" type="list(string)">
  Lists the authentication flows explicitly enabled for this user pool client (e.g., ALLOW_USER_SRP_AUTH, ALLOW_REFRESH_TOKEN_AUTH, ALLOW_CUSTOM_AUTH, ALLOW_ADMIN_USER_PASSWORD_AUTH), overriding the default set of allowed flows for the app client. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="generate_secret" type="bool">
  Indicates whether the app client will have a generated client secret, used for confidential clients to authenticate to the token endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="id_token_validity" type="number">
  The number of minutes that an ID token issued by the user pool client remains valid before it expires. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="logout_urls" type="list(string)">
  Specifies the list of allowed logout redirect URIs to which Cognito may redirect users after signing out from the user pool client. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="prevent_user_existence_errors" type="string">
  Indicates whether the user pool client prevents user enumeration by returning a generic error when a user does not exist, with allowed values 'ENABLED' or 'LEGACY'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="read_attributes" type="list(string)">
  Specifies the user pool attributes that the app client can read from the user's profile. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="refresh_token_rotation" type="object">
  Optional.
  <Expandable title="properties">
    <ResponseField name="feature" type="string">
      Determines whether refresh token rotation is enabled for the user pool client, with valid values being 'ENABLED' or 'DISABLED'. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="retry_grace_period_seconds" type="number">
      Sets the retry grace period, in seconds, during which an old refresh token remains valid after it has been rotated for a new one, allowing clients that still present the previous token to successfully obtain new tokens before the old token is revoked. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="refresh_token_validity" type="number">
  The number of days that a refresh token remains valid before the user must re-authenticate. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="supported_identity_providers" type="list(string)">
  A list of identity provider names (e.g., COGNITO, Facebook, Google, LoginWithAmazon, or custom SAML/OIDC providers) that are enabled for this app client, controlling which IdPs can be used for sign-in. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_validity_units" type="object">
  Specifies the time units (such as seconds, minutes, hours, or days) for the expiration of access, ID, and refresh tokens issued by the user pool client, enabling separate validity durations for each token type. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="access_token" type="string">
      Specifies the time unit (e.g., seconds, minutes, hours, or days) used to interpret the numeric value of the access token validity period for the Cognito user pool client. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="id_token" type="string">
      Specifies the unit of time (e.g., seconds, minutes, hours, days) used for the ID token's validity period in the user pool client. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="refresh_token" type="string">
      Specifies the time unit (e.g., seconds, minutes, hours, or days) used for the refresh token's validity period in the user pool client. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The unique ID of the Amazon Cognito user pool to which this app client belongs, used to link the client configuration to its parent pool. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="write_attributes" type="list(string)">
  Specifies the list of user pool attributes that the app client is allowed to update (write) for users, controlling which profile fields can be modified through the client. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="client_id" type="string">
  The unique identifier (ID) of the user pool client, assigned by Amazon Cognito when the client is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_secret" type="string">
  The client secret that this app client uses to authenticate with the Cognito User Pool service, generated by Cognito and exposed as a read-only attribute after creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  This attribute returns the name of the Cognito user pool application client, as originally specified in the ClientName parameter during client creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

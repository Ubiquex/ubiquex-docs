`aws_cognito_user_pool_group` creates a real, logical grouping of users inside an `aws_cognito_user_pool`, listed in the ID and access tokens Cognito issues, and usable to map a user to a specific IAM role when a token is passed to an `aws_cognito_identity_pool`.

## Properties

<ResponseField name="description" type="string">
  A description of the user pool group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="group_name" type="string">
  The name of the Cognito user pool group, which serves as the group's unique identifier within the user pool and is referenced in IAM policies and app client authentication flows. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="precedence" type="number">
  Defines the numerical precedence of the group, which determines the IAM role that Cognito applies when a user belongs to multiple groups, with lower numbers having higher priority. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string">
  The Amazon Resource Name (ARN) of the IAM role that is associated with the user pool group and applied to its users. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="user_pool_id" type="string" required>
  The ID of the Cognito user pool that this group belongs to. Required. **(AI-inferred)**
</ResponseField>

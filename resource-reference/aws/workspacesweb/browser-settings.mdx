`aws_work_spaces_web_browser_settings` defines real, reusable browser policy settings, extensions, bookmarks, download behavior, that an `aws_work_spaces_web_portal` applies to every browsing session under Amazon WorkSpaces Secure Browser, a separate, browser-only product from classic `aws_work_spaces_workspace` full desktops.

## Input properties

<ResponseField name="additional_encryption_context" type="any">
  Adds key-value pairs to the AWS KMS encryption context used to encrypt the browser settings resource, enabling additional contextual information for auditing and access control. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="browser_policy" type="string">
  The JSON-formatted string that defines the browser policy, which controls the browser features and behaviors available to WorkSpaces Web users. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="customer_managed_key" type="string">
  The ARN of a customer-managed KMS key used to encrypt the browser settings, with AWS-managed encryption applied when this optional field is left empty. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="web_content_filtering_policy" type="object">
  Specifies the web content filtering policy for WorkSpaces Web browser settings, defining rules that allow or block web content by category (such as adult content, social media, or advertising) in browser sessions. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="allowed_urls" type="list(string)">
      Specifies a list of allowed URL patterns that users are permitted to access when the web content filtering policy is enabled, with all other URLs being blocked. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="blocked_categories" type="list(string)">
      The list of web content category identifiers to block, which prevents users from accessing websites that belong to the specified categories in this WorkSpaces Web browser settings. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="blocked_urls" type="list(string)">
      The list of URLs that are blocked by the web content filtering policy, preventing end users from accessing those sites in the WorkSpaces Web browser. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="associated_portal_arns" type="list(string)">
  The list of Amazon Resource Names (ARNs) of the WorkSpaces Web portals that are linked to these browser settings, automatically assigned by the service when a portal is associated. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="browser_settings_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the browser settings resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_launch_wizard_deployment` deploys a real, sized and configured workload, third-party software such as SQL Server or SAP, or a supported AWS workload pattern, using AWS Launch Wizard's own guided, Well-Architected-aligned automation rather than a hand-built template.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	launchwizard "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/launchwizard"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own deployment"})

    		ubx.Resource(launchwizard.Deployment, "example", launchwizard.DeploymentConfig{
    			DeploymentPatternName: "example-deployment-pattern-name",
    			Name:                  "example",
    			WorkloadName:          "example-workload-name",
    			Specifications:        "example",
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx

## Input properties

<ResponseField name="deployment_pattern_name" type="string" required>
  Workload deployment pattern name Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of LaunchWizard deployment Required.
</ResponseField>

<ResponseField name="specifications" type="any">
  The map of key-value pairs that define the application and infrastructure parameters (for example, instance types, subnet IDs, and security group names) used to configure the deployment for the chosen Launch Wizard pattern. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags for LaunchWizard deployment Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Launch Wizard deployment, allowing you to assign arbitrary metadata to the deployment for organizational or cost-tracking purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the AWS Launch Wizard deployment, which lets you attach arbitrary metadata to the deployment for categorization, access control, and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="workload_name" type="string" required>
  Workload Name for LaunchWizard deployment Required.
</ResponseField>

`aws_ecs_express_gateway_service` deploys a production-ready, HTTPS-reachable containerized web application from just a container image and two IAM roles, ECS Express Mode automatically provisioning and configuring the Application Load Balancer, target group, security group, and auto-scaling policy a caller would otherwise assemble by hand, with an AWS-provided domain name available immediately. Announced November 2025 at re:Invent.

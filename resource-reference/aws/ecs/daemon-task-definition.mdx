---

`aws_ecs_daemon_task_definition` runs exactly one real task on every active EC2 container instance in an `aws_ecs_cluster` that meets its placement constraints, prioritized to launch first and stop last among that instance's tasks, ECS's own managed-daemon pattern for agents like security or observability tooling that every instance needs running.

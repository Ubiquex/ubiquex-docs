`aws_ecs_task_set` is a real, specific version of an `aws_ecs_service`'s own tasks and its deployment configuration, the actual mechanism behind blue/green deployments where two task sets run side by side before traffic shifts fully to the new one.

## Input properties

<ResponseField name="capacity_provider_strategy" type="list(object)">
  Specifies the capacity provider strategy for the task set, defining which capacity providers to use and the weights and base values that govern how tasks are distributed among them. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="base" type="number">
      The minimum number of tasks to run on this capacity provider before the task set's weight-based scaling applies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="capacity_provider" type="string">
      The name of the capacity provider, as registered in the ECS cluster, that this task set should use for running tasks. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="weight" type="number">
      The relative weight assigned to a capacity provider in the strategy, determining what proportion of tasks from the task set are placed on that provider. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cluster" type="string" required>
  The short name or full Amazon Resource Name (ARN) of the cluster that hosts the service to create the task set in. Required.
</ResponseField>

<ResponseField name="external_id" type="string">
  An optional non-unique tag that identifies this task set in external systems. If the task set is associated with a service discovery registry, the tasks in this task set will have the ECS_TASK_SET_EXTERNAL_ID AWS Cloud Map attribute set to the provided value. Optional.
</ResponseField>

<ResponseField name="launch_type" type="string">
  The launch type that new tasks in the task set will use. For more information, see https://docs.aws.amazon.com/AmazonECS/latest/developerguide/launch_types.html in the Amazon Elastic Container Service Developer Guide. Optional.
</ResponseField>

<ResponseField name="load_balancers" type="list(object)">
  Configures the load balancer or target groups that route traffic to the tasks in this ECS task set, specifying the container and port to receive traffic. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="container_name" type="string">
      The name of the container, as defined in the task definition, to which the load balancer routes traffic for this task set. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="container_port" type="number">
      The container port on which the task set's containers receive traffic from the associated load balancer or target group, used to route incoming requests to the correct container port. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="target_group_arn" type="string">
      The Amazon Resource Name (ARN) of the target group to which the ECS task set's tasks are registered for load balancing. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="network_configuration" type="object">
  An object representing the network configuration for a task or service. Optional.
  <Expandable title="properties">
    <ResponseField name="aws_vpc_configuration" type="object">
      The VPC subnets and security groups associated with a task. All specified subnets and security groups must be from the same VPC. Optional.
      <Expandable title="properties">
        <ResponseField name="assign_public_ip" type="string">
          Whether the task's elastic network interface receives a public IP address. The default value is DISABLED. Optional.
        </ResponseField>
        <ResponseField name="security_groups" type="list(string)">
          The security groups associated with the task or service. If you do not specify a security group, the default security group for the VPC is used. There is a limit of 5 security groups that can be specified per AwsVpcConfiguration. Optional.
        </ResponseField>
        <ResponseField name="subnets" type="list(string)" required>
          The subnets associated with the task or service. There is a limit of 16 subnets that can be specified per AwsVpcConfiguration. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="platform_version" type="string">
  The platform version that the tasks in the task set should use. A platform version is specified only for tasks using the Fargate launch type. If one isn't specified, the LATEST platform version is used by default. Optional.
</ResponseField>

<ResponseField name="scale" type="object">
  Specifies the scaling configuration for the task set, including the unit (e.g., PERCENT) and value that determine the target number of tasks for the task set. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="unit" type="string">
      The unit of measure for the scale value. Optional.
    </ResponseField>
    <ResponseField name="value" type="number">
      The value, specified as a percent total of a service's desiredCount, to scale the task set. Accepted values are numbers between 0 and 100. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service" type="string" required>
  The short name or full Amazon Resource Name (ARN) of the service to create the task set in. Required.
</ResponseField>

<ResponseField name="service_registries" type="list(object)">
  The details of the service discovery registries to assign to this task set. For more information, see https://docs.aws.amazon.com/AmazonECS/latest/developerguide/service-discovery.html. Optional.
  <Expandable title="properties">
    <ResponseField name="container_name" type="string">
      Specifies the container name from the task definition to use for the service discovery (Cloud Map) registry, and if not provided, the default container in the task definition is used. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="container_port" type="number">
      Specifies the container port that the Amazon ECS task set's service registry uses for service discovery with AWS Cloud Map. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="port" type="number">
      The port number that the service discovery service uses for the task's registry entry, which overrides the container's port mapping if specified. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="registry_arn" type="string">
      The ARN of the AWS Cloud Map service registry in which the task set's tasks are registered for service discovery. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that can be assigned to the ECS task set for organizational or identification purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a user-defined tag attached to the ECS task set, which can be used for resource categorization, cost allocation, and operational management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="task_definition" type="string" required>
  The short name or full Amazon Resource Name (ARN) of the task definition for the tasks in the task set to use. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of the task set. Computed by AWS after `ship`.
</ResponseField>

`aws_ecs_daemon` deploys a real `aws_ecs_daemon_task_definition` across every eligible container instance in an ECS cluster, exactly one task per instance, the resource that actually runs the daemon scheduling strategy rather than only defining what it would run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own daemon"})

    		ubx.Resource(ecs.Daemon, "ci-runner", ecs.DaemonConfig{
    			CapacityProviderArns:    []string{"example"},
    			ClusterArn:              "arn:aws:iam::123456789012:policy/ci",
    			DaemonName:              "example-daemon-name",
    			DaemonTaskDefinitionArn: "arn:aws:iam::123456789012:policy/ci",
    			DeploymentConfiguration: map[string]any{"alarms": map[string]any{"alarm_names": []string{"example"}}},
    			EnableEcsmanagedTags:    true,
    			EnableExecuteCommand:    true,
    			PropagateTags:           "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="capacity_provider_arns" type="list(string)">
  The Amazon Resource Names (ARNs) of the capacity providers associated with the daemon. Optional.
</ResponseField>

<ResponseField name="cluster_arn" type="string">
  The Amazon Resource Name (ARN) of the cluster that the daemon is running in. Optional.
</ResponseField>

<ResponseField name="daemon_name" type="string">
  Optional.
</ResponseField>

<ResponseField name="daemon_task_definition_arn" type="string">
  The Amazon Resource Name (ARN) of the daemon task definition used by this revision. Optional.
</ResponseField>

<ResponseField name="deployment_configuration" type="object">
  Optional deployment parameters that control how a daemon rolls out updates across container instances. Optional.
  <Expandable title="properties">
    <ResponseField name="alarms" type="object">
      The CloudWatch alarm configuration for a daemon. When enabled, CloudWatch alarms determine whether a daemon deployment has failed. Optional.
      <Expandable title="properties">
        <ResponseField name="alarm_names" type="list(string)">
          The CloudWatch alarm names to monitor during a daemon deployment. Optional.
        </ResponseField>
        <ResponseField name="enable" type="bool">
          Determines whether to use the CloudWatch alarm option in the daemon deployment process. The default value is ``false``. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="bake_time_in_minutes" type="number">
      The amount of time (in minutes) to wait after a successful deployment step before proceeding. This allows time to monitor for issues before continuing. The default value is 0. Optional.
    </ResponseField>
    <ResponseField name="drain_percent" type="number">
      The percentage of container instances to drain simultaneously during a daemon deployment. Valid values are between 0.0 and 100.0. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="enable_ecsmanaged_tags" type="bool">
  Specifies whether Amazon ECS managed tags are turned on for the daemon tasks. Optional.
</ResponseField>

<ResponseField name="enable_execute_command" type="bool">
  Specifies whether the execute command functionality is turned on for the daemon tasks. Optional.
</ResponseField>

<ResponseField name="propagate_tags" type="string">
  Specifies whether tags are propagated from the daemon to the daemon tasks. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

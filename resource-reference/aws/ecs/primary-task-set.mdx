`aws_ecs_primary_task_set` designates a real task set as the primary, live one for an `aws_ecs_service`, the resource that actually shifts production traffic to a new task set during an external (blue/green) deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ecs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ecs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own primary task set"})

    		ubx.Resource(ecs.PrimaryTaskSet, "ci-runner", ecs.PrimaryTaskSetConfig{
    			Cluster:   "example",
    			Service:   "example",
    			TaskSetId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="cluster" type="string" required>
  The short name or full Amazon Resource Name (ARN) of the cluster that hosts the service to create the task set in. Required.
</ResponseField>

<ResponseField name="service" type="string" required>
  The short name or full Amazon Resource Name (ARN) of the service to create the task set in. Required.
</ResponseField>

<ResponseField name="task_set_id" type="string" required>
  The ID or full Amazon Resource Name (ARN) of the task set. Required.
</ResponseField>

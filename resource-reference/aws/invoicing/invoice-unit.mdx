`aws_invoicing_invoice_unit` groups a real, mutually exclusive set of member accounts into one business entity, a subsidiary, a legal entity, a cost center, so AWS issues that entity its own separate invoice rather than one combined invoice for an entire AWS Organization. Reached general availability December 2024.

## Input properties

<ResponseField name="description" type="string">
  The description field provides an optional, user-defined textual description for the invoice unit, allowing you to record the purpose or context of this billing grouping. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="invoice_receiver" type="string" required>
  The AWS account ID of the account that receives the consolidated invoice for this invoice unit. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  Sets the unique name of this invoice unit, a logical group of accounts used to consolidate and customize AWS billing invoices. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_tags" type="list(object)">
  The resource_tags field defines a list of tag objects (each containing a key and value) to associate with the invoice unit, enabling you to categorize and manage the invoice unit resource within AWS Invoicing. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key part of a resource tag attached to the AWS Invoicing invoice unit, used to define custom metadata for organizing, filtering, and managing the invoice unit. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a resource tag (key-value pair) that can be attached to this invoice unit for cost allocation and organizational purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rule" type="object" required>
  Defines which AWS accounts are included in the invoice unit for consolidated invoicing and which account is designated as the invoice receiver. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="linked_accounts" type="list(string)" required>
      Specifies the list of linked account IDs (as strings) that are included under this invoice unit's rule when grouping accounts for invoicing. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tax_inheritance_disabled" type="bool">
  When set to true, this disables the invoice unit's inheritance of tax configuration from the payer account, forcing the invoice unit to use its own tax settings. Optional. **(AI-inferred)**
</ResponseField>

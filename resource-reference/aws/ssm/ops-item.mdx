`aws_ssm_ops_item` creates a real, trackable operational issue, an incident, change request, or general to-do, in OpsCenter, with its own status, priority, and related resources, for centralizing operational work instead of tracking it in a separate ticketing system.

    			Priority:    1,

</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags for the OpsItem. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Key of a user-defined tag attached to the OpsItem, which can be used to categorize, search, and manage operational work items in AWS Systems Manager OpsCenter. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The user-defined value for a tag key on the OpsItem, used to add metadata for identifying, organizing, or filtering the OpsItem in AWS Systems Manager. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

  The title of the OpsItem. Required.
</ResponseField>

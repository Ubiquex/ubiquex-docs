`aws_ssm_document` defines a real, reusable automation, command, or policy document, in JSON or YAML, that Systems Manager runs against target instances, either directly or through an `aws_ssm_association`.

## Example

## Properties

<ResponseField name="attachments" type="list(object)">
  A list of key and value pairs that describe attachments to a version of a document. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key name of an attachment entry, such as 'SourceUrl' or 'Script', that specifies the attachment's purpose within an Automation document. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="values" type="list(string)">
      Provides the list of source URLs (such as Amazon S3 file URLs) that define the actual content locations for an SSM document attachment, matched with the attachment's key to specify the type of source. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="content" type="any" required>
  The content for the Systems Manager document in JSON, YAML or String format. Required.
</ResponseField>

<ResponseField name="document_format" type="string">
  Specify the document format for the request. The document format can be either JSON or YAML. JSON is the default format. Optional.
</ResponseField>

<ResponseField name="document_type" type="string">
  The type of document to create. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  A name for the Systems Manager document. Optional.
</ResponseField>

<ResponseField name="requires" type="list(object)">
  A list of SSM documents required by a document. For example, an ApplicationConfiguration document requires an ApplicationConfigurationSchema document. Optional.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of the AWS Systems Manager document that this document requires as a dependency. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of another SSM document that this document requires as a dependency, specified in the 'requires' block of the aws_ssm_document resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional metadata that you assign to a resource. Tags enable you to categorize a resource in different ways, such as by purpose, owner, or environment. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key to assign to the SSM document, used for identifying and managing the document in AWS Systems Manager. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag attached to an SSM document, used to add metadata that supports resource identification, organization, and access control in AWS Systems Manager. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_type" type="string">
  Specify a target type to define the kinds of resources the document can run on. Optional.
</ResponseField>

<ResponseField name="update_method" type="string">
  Update method - when set to 'Replace', the update will replace the existing document; when set to 'NewVersion', the update will create a new version. Optional.
</ResponseField>

<ResponseField name="version_name" type="string">
  An optional field specifying the version of the artifact you are creating with the document. This value is unique across all versions of a document, and cannot be changed. Optional.
</ResponseField>

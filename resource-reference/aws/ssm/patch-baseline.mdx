`aws_ssm_patch_baseline` defines a real set of rules, auto-approval delays, severity filters, an explicit approved or rejected patch list, that determines which OS patches Systems Manager Patch Manager treats as approved for a given set of instances.

## Example

    ```go
    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ssm"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own patch baseline"})

    		ubx.Resource(ssm.PatchBaseline, "example", ssm.PatchBaselineConfig{
    			Name:                                     "example",
    			ApprovalRules:                            map[string]any{"patch_rules": []map[string]any{{"approve_after_days": 1}}},
    			ApprovedPatches:                          []string{"example"},
    			ApprovedPatchesComplianceLevel:           "example",
    			ApprovedPatchesEnableNonSecurity:         true,
    			AvailableSecurityUpdatesComplianceStatus: "example",
    			DefaultBaseline:                          true,
    			Description:                              "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="approval_rules" type="object">
  A set of rules defining the approval rules for a patch baseline. Optional.
  <Expandable title="properties">
    <ResponseField name="patch_rules" type="list(object)">
      A list of patch rules that define which patches are approved for the baseline, including patch filters, approval delay, and compliance level. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="approve_after_days" type="number">
          Specifies the number of days after a patch's release date that it is automatically approved for installation in the patch baseline. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="approve_until_date" type="string">
          The date (in YYYY-MM-DD format) after which the patch is no longer automatically approved for this rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="compliance_level" type="string">
          Specifies the compliance severity level (e.g., CRITICAL, HIGH, MEDIUM, LOW, INFORMATIONAL, or UNSPECIFIED) assigned to patches that match this rule for reporting and compliance purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="enable_non_security" type="bool">
          Indicates whether this approval rule also applies to patches that are not classified as security updates, allowing non-security patches to be approved based on the same schedule and filters. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="patch_filter_group" type="object">
          The patch_filter_group object within a patch rule defines the set of patch filter criteria (e.g., product, severity, classification) that a patch must match for the rule to approve it, with all specified filters required to match (AND logic). Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="patch_filters" type="list(object)">
              Defines the patch filters (each with a key and values) that determine which patches this approval rule applies to, such as by product, severity, or classification. Optional; if omitted, computed by AWS. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="key" type="string">
                  The name of the patch attribute to filter on, such as PRODUCT, CLASSIFICATION, or MSRC_SEVERITY, for the approval rule's patch filter group. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="values" type="list(string)">
                  The list of values used to match patches for the associated patch filter key (e.g., product, classification, or severity) in an AWS SSM patch baseline approval rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="approved_patches" type="list(string)">
  A list of explicitly approved patches for the baseline. Optional.
</ResponseField>

<ResponseField name="approved_patches_compliance_level" type="string">
  Defines the compliance level for approved patches. This means that if an approved patch is reported as missing, this is the severity of the compliance violation. The default value is UNSPECIFIED. Optional.
</ResponseField>

<ResponseField name="approved_patches_enable_non_security" type="bool">
  Indicates whether the list of approved patches includes non-security updates that should be applied to the instances. The default value is 'false'. Applies to Linux instances only. Optional.
</ResponseField>

<ResponseField name="available_security_updates_compliance_status" type="string">
  The compliance status for vendor recommended security updates that are not approved by this patch baseline. Optional.
</ResponseField>

<ResponseField name="default_baseline" type="bool">
  Set the baseline as default baseline. Only registering to default patch baseline is allowed. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the patch baseline. Optional.
</ResponseField>

<ResponseField name="global_filters" type="object">
  The patch filter group that defines the criteria for the rule. Optional.
  <Expandable title="properties">
    <ResponseField name="patch_filters" type="list(object)">
      Defines the list of patch filters that determine which patches are included or excluded from the patch baseline, with each filter specifying a key (e.g., PRODUCT, CLASSIFICATION, MSRC_SEVERITY) and a list of values. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key of the patch filter (e.g., PRODUCT, CLASSIFICATION, MSRC_SEVERITY) that identifies which patch attribute is used for filtering globally across the patch baseline. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="values" type="list(string)">
          Specifies the list of allowed values for the corresponding patch filter key (such as product, classification, or severity), which is used to match patches that are included in or excluded from the patch baseline. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the patch baseline. Required.
</ResponseField>

<ResponseField name="operating_system" type="string">
  Defines the operating system the patch baseline applies to. The Default value is WINDOWS. Optional.
</ResponseField>

<ResponseField name="patch_groups" type="list(string)">
  PatchGroups is used to associate instances with a specific patch baseline Optional.
</ResponseField>

<ResponseField name="rejected_patches" type="list(string)">
  A list of explicitly rejected patches for the baseline. Optional.
</ResponseField>

<ResponseField name="rejected_patches_action" type="string">
  The action for Patch Manager to take on patches included in the RejectedPackages list. Optional.
</ResponseField>

<ResponseField name="sources" type="list(object)">

    <ResponseField name="name" type="string">
      The name of the patch source, such as 'Amazon Linux 2' or 'Ubuntu', which identifies the repository configured for this patch baseline. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="products" type="list(string)">
      Specifies the operating system product versions (e.g., 'AmazonLinux2012.03', 'RedhatEnterpriseLinux7') that this patch source repository applies to in the patch baseline. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

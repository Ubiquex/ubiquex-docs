`aws_ssm_service_setting` updates a real, account-wide Systems Manager service setting, such as which parameter tier is used by default, rather than a setting scoped to any individual resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service setting"})

    		ubx.Resource(ssm.ServiceSetting, "example", ssm.ServiceSettingConfig{
    			SettingId:    "example",
    			SettingValue: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { ServiceSetting } from "@ubx/sdk-aws/aws/ssm/service_setting";

    export default stack("example", () => {
      intent({ summary: "example own service setting" });

      resource(ServiceSetting, "example", {
        settingId: "example",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.ssm import ServiceSetting, ServiceSettingConfig

    def describe():
        ubx.intent("example own service setting")

        ubx.resource(ServiceSetting, "example", ServiceSettingConfig(
            setting_id="example",
            setting_value="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="setting_id" type="string" required>
  The ID of the service setting, such as /ssm/parameter-store/high-throughput-enabled. Required.
</ResponseField>

<ResponseField name="setting_value" type="string" required>
  The value of the service setting. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the service setting. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="last_modified_date" type="string">
  The last time the service setting was modified. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="last_modified_user" type="string">
  The ARN of the last modified user. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the service setting. The value can be Default, Customized or PendingUpdate. Computed by AWS after `ship`.
</ResponseField>

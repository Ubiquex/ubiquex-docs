`aws_ssm_cloud_connector` connects a real non-AWS cloud account, an Azure subscription, for example, to AWS Systems Manager, letting Systems Manager extend its own management and visibility to resources outside AWS. This resource has only thin official documentation, verified live this session against AWS's own field-level schema rather than assumed from general knowledge, since it did not turn up a dedicated conceptual guide page the way Systems Manager's older resources do.

## Example

    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cloud connector"})

    		ubx.Resource(ssm.CloudConnector, "example", ssm.CloudConnectorConfig{
    			ConfigConnectorArn: "arn:aws:iam::123456789012:policy/example",
    			Configuration:      map[string]any{"azure_configuration": map[string]any{"application_id": "example"}},
    			DisplayName:        "example-display-name",
    			RoleArn:            "arn:aws:iam::123456789012:policy/example",
    			Description:        "Managed by ubx.",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="config_connector_arn" type="string" required>
  The ARN of the AWS Config connector. Required.
</ResponseField>

<ResponseField name="configuration" type="object" required>
  The configuration for the cloud connector. Currently supports Azure. Required.
  <Expandable title="properties">
    <ResponseField name="azure_configuration" type="object" required>
      Configuration for connecting to Azure. Required.
      <Expandable title="properties">
        <ResponseField name="application_display_name" type="string">
          The display name of the Azure AD application. Optional.
        </ResponseField>
        <ResponseField name="application_id" type="string" required>
          The Azure AD application ID. Required.
        </ResponseField>
        <ResponseField name="targets" type="object">
          The targets for the cloud connector. If omitted, the entire tenant is targeted. Optional.
          <Expandable title="properties">
            <ResponseField name="subscriptions" type="list(object)" required>
              List of Azure subscriptions. Required.
              <Expandable title="properties">
                <ResponseField name="display_name" type="string">
                  The display name of an Azure subscription targeted by the SSM Cloud Connector's Azure configuration, identifying the subscription by its human-readable name. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="id" type="string">
                  The unique Azure subscription ID that the SSM Cloud Connector is configured to manage as part of its Azure connection targets. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="tenant_display_name" type="string">
          The display name of the Azure AD tenant. Optional.
        </ResponseField>
        <ResponseField name="tenant_id" type="string" required>
          The Azure AD tenant ID. Cannot be changed after creation. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the cloud connector. Optional.
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The display name of the cloud connector. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The IAM role ARN used by the cloud connector. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to apply to the cloud connector. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cloud_connector_arn" type="string">
  The ARN of the cloud connector. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="cloud_connector_id" type="string">
  The unique identifier of the cloud connector. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when the cloud connector was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp when the cloud connector was last updated. Computed by AWS after `ship`.
</ResponseField>

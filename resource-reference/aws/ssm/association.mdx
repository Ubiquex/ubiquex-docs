`aws_ssm_association` attaches a real `aws_ssm_document` to a set of target instances or resources on a recurring schedule, the resource that actually turns a document's defined actions into ongoing, applied state rather than a one-time run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own association"})

    		ubx.Resource(ssm.Association, "example", ssm.AssociationConfig{
    			Name:                          "example",
    			ApplyOnlyAtCronInterval:       true,
    			AssociationDispatchAssumeRole: "example",
    			AssociationName:               "example-association-name",
    			AutomationTargetParameterName: "example-automation-target-parameter-name",
    			CalendarNames:                 []string{"example"},
    			ComplianceSeverity:            "example",
    			DocumentVersion:               "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="apply_only_at_cron_interval" type="bool">
  When true, the SSM association is applied only at the interval specified by its cron schedule, and it will not also run during a configured maintenance window. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="association_dispatch_assume_role" type="string">
  A role used by association to take actions on your behalf. Optional.
</ResponseField>

<ResponseField name="association_name" type="string">
  The name of the association. Optional.
</ResponseField>

<ResponseField name="automation_target_parameter_name" type="string">
  Specifies the name of the parameter in the Automation document that receives the target instance IDs or resource identifiers defined in the association's Targets property. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="calendar_names" type="list(string)">
  Specifies the names or ARNs of Change Calendar resources that define the schedule window during which the SSM association is allowed to run. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="compliance_severity" type="string">
  Sets the compliance severity level for the association, which determines how the association's compliance status is reported in Systems Manager Compliance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="document_version" type="string">
  The version of the SSM document to associate with the target. Optional.
</ResponseField>

<ResponseField name="instance_id" type="string">
  The ID of the instance that the SSM document is associated with. Optional.
</ResponseField>

<ResponseField name="max_concurrency" type="string">
  Specifies the maximum number or percentage of targets that can run the association concurrently, used to control the rate at which state manager applies the document to instances. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_errors" type="string">
  Specifies the maximum number of errors (or, when expressed as a percentage, the maximum portion of the target set) that can occur before the SSM association stops sending requests to run on additional targets. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the SSM document. Required.
</ResponseField>

<ResponseField name="output_location" type="object">
  Specifies the S3 bucket location where the execution output of the SSM association is stored, allowing log and result data to be saved to a user-defined S3 bucket. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="s3_location" type="object">
      Specifies the S3 bucket, key prefix, and AWS region for storing the output of the association's command execution. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="output_s3_bucket_name" type="string">
          The name of the S3 bucket where the output (such as execution logs) from the SSM association is stored when an output location is configured. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="output_s3_key_prefix" type="string">
          Specifies the S3 key prefix under which the association's output files are stored in the output S3 bucket, enabling logical grouping or folder structure for the results. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="output_s3_region" type="string">
          Specifies the AWS Region where the output S3 bucket resides, so that the association's execution results are written to the correct regional bucket. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="parameters" type="any">
  Parameter values that the SSM document uses at runtime. Optional.
</ResponseField>

<ResponseField name="schedule_expression" type="string">
  A Cron or Rate expression that specifies when the association is applied to the target. Optional.
</ResponseField>

<ResponseField name="schedule_offset" type="number">
  Specifies the number of minutes to wait after the scheduled time before the association runs, allowing you to delay execution from the cron or rate schedule defined for the association. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="sync_compliance" type="string">
  Indicates whether compliance for the association is automatically synced with AWS Systems Manager (AUTO) or manually synced (MANUAL). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A key-value pair to associate with a resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag assigned to the SSM association, used to organize, identify, and filter the association within AWS Systems Manager. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Systems Manager association, which aids in organizing, identifying, and managing the association through AWS tagging policies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="targets" type="list(object)">
  The targets that the SSM document sends commands to. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of the target filter (e.g., 'InstanceIds' or a tag key) used to select the managed instances to which the SSM association applies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="values" type="list(any)">
      Values for the target key, such as EC2 instance IDs when the key is 'InstanceIds' or tag values when the key is a tag-based key like 'tag:Environment'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="wait_for_success_timeout_seconds" type="number">
  Specifies the maximum time in seconds that the provider will wait for the SSM association to reach a successful state after creation or update, after which it returns an error. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="association_id" type="string">
  Unique identifier of the association. Computed by AWS after `ship`.
</ResponseField>

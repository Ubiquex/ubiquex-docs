`aws_ssm_resource_policy` attaches a real resource-based access policy to an `aws_ssm_parameter`, controlling which principals, including from other accounts, can read or write it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource policy"})

    		ubx.Resource(ssm.ResourcePolicy, "example", ssm.ResourcePolicyConfig{
    			Policy:      "example",
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { ResourcePolicy } from "@ubx/sdk-aws/aws/ssm/resource_policy";

    export default stack("example", () => {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.ssm.resource_policy import ResourcePolicy, ResourcePolicyConfig

    def describe():
        ubx.intent("example own resource policy")

        ubx.resource(ResourcePolicy, "example", ResourcePolicyConfig(
            policy="example",
            resource_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="policy" type="any" required>
  Actual policy statement. Required.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  Arn of OpsItemGroup etc. Required.
</ResponseField>

## Output properties

<ResponseField name="policy_hash" type="string">
  A snapshot identifier for the policy over time. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="policy_id" type="string">
  An unique identifier within the policies of a resource. Computed by AWS after `ship`.
</ResponseField>

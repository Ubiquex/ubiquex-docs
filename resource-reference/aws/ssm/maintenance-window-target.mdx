`aws_ssm_maintenance_window_target` registers a real set of instances or resources, selected by tag or ID, as eligible targets for an `aws_ssm_maintenance_window`'s tasks.

## Input properties

<ResponseField name="description" type="string">
  A description for the target. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name for the maintenance window target. Optional.
</ResponseField>

<ResponseField name="owner_information" type="string">
  A user-provided value that will be included in any Amazon CloudWatch Events events that are raised while running tasks for these targets in this maintenance window. Optional.
</ResponseField>

<ResponseField name="resource_type" type="string" required>
  The type of target that is being registered with the maintenance window. Required.
</ResponseField>

<ResponseField name="targets" type="list(object)" required>
  The targets to register with the maintenance window. Required.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the type of target, such as 'InstanceIds' to match EC2 instance IDs or a tag key in the format 'tag:key' to match instances by tag, which determines how the associated Values are interpreted. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="values" type="list(string)">
      Specifies the values for the maintenance window target key, such as EC2 instance IDs when the key is 'InstanceIds' or resource group names when the key is 'ResourceGroup'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="window_id" type="string" required>
  The ID of the maintenance window to register the target with. Required.
</ResponseField>

## Output properties

<ResponseField name="window_target_id" type="string">
  The ID of the target. Computed by AWS after `ship`.
</ResponseField>

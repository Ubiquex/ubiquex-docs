---
title: "aws_elasticsearch_domain"
description: "`aws_elasticsearch_domain` provisions a search and analytics domain using the legacy `AWS::Elasticsearch::Domain` CloudFormation resource type."
---

Amazon Elasticsearch Service was renamed Amazon OpenSearch Service on September 8, 2021; this legacy resource type still functions and supports open-source Elasticsearch, but AWS recommends the newer `AWS::OpenSearchService::Domain` resource, which supports both OpenSearch and Elasticsearch, for new domains.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticsearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/elasticsearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain"})

    		ubx.Resource(elasticsearch.Domain, "example", elasticsearch.DomainConfig{
    			AccessPolicies:             "example",
    			AdvancedOptions:            "example",
    			AdvancedSecurityOptions:    map[string]any{"anonymous_auth_enabled": true},
    			CognitoOptions:             map[string]any{"enabled": true},
    			DomainEndpointOptions:      map[string]any{"custom_endpoint": "example"},
    			DomainName:                 "example-domain-name",
    			Ebsoptions:                 map[string]any{"ebsenabled": true},
    			ElasticsearchClusterConfig: map[string]any{"cold_storage_options": map[string]any{"enabled": true}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_policies" type="any">
  The access_policies field specifies the IAM policy document in JSON format that controls access to the Amazon Elasticsearch domain, defining which principals can perform allowed actions on the domain. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="advanced_options" type="any">
  Sets domain-specific advanced Elasticsearch parameters, such as whether explicit index names are allowed in REST requests. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="advanced_security_options" type="object">
  Configures fine-grained access control for the Elasticsearch domain, including enabling the feature, setting up the internal user database, defining master user credentials, and optionally configuring SAML authentication. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="anonymous_auth_enabled" type="bool">
      Enables anonymous (unauthenticated) access to the Elasticsearch domain's endpoints, allowing requests without credentials. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enabled" type="bool">
      Indicates whether advanced security options (fine-grained access control, user authentication, and authorization) are enabled for the Amazon Elasticsearch domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="internal_user_database_enabled" type="bool">
      Enables the internal user database for fine-grained access control in Amazon Elasticsearch Service, allowing users to be managed within the domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="master_user_options" type="object">
      Specifies the master user for the Elasticsearch domain when advanced security is enabled, defining either an IAM role ARN (MasterUserARN) or internal user credentials (MasterUserName and MasterUserPassword) for fine-grained access control. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="master_user_arn" type="string">
          The ARN of the IAM identity (IAM user or role) that serves as the master user for fine-grained access control in the Amazon Elasticsearch Service domain. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="master_user_name" type="string">
          The username for the master user, used to authenticate with fine-grained access control when advanced security is enabled on the Elasticsearch domain. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="master_user_password" type="string">
          Sets the password for the master user used with fine-grained access control (advanced security) in the Amazon Elasticsearch domain, required when specifying a master user name for the internal user database. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cognito_options" type="object">
  Configures Amazon Cognito authentication for Kibana on the Elasticsearch domain, including the enabled flag, Cognito user pool ID, identity pool ID, and the IAM role ARN that grants access. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Specifies whether Amazon Cognito authentication for Kibana is enabled, and when true the accompanying user_pool_id, identity_pool_id, and role_arn are used to authenticate users. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="identity_pool_id" type="string">
      The ID of the Amazon Cognito identity pool that is used for authentication to the Elasticsearch domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="role_arn" type="string">
      The ARN of the IAM role that Amazon Cognito assumes to access the user pool and identity pool, enabling authenticated Kibana/OpenSearch Dashboards via Cognito for the domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="user_pool_id" type="string">
      The ID of the Amazon Cognito user pool that is used to authenticate users to Kibana for this Elasticsearch domain. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="domain_endpoint_options" type="object">
  Configures the domain endpoint for the Amazon Elasticsearch Service domain, including enforcing HTTPS, specifying the TLS security policy, and optionally enabling a custom endpoint with its certificate ARN. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="custom_endpoint" type="string">
      The fully qualified domain name to use as the custom endpoint for the Elasticsearch domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="custom_endpoint_certificate_arn" type="string">
      The Amazon Resource Name (ARN) of the AWS Certificate Manager (ACM) certificate to use for the custom endpoint for the Elasticsearch domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="custom_endpoint_enabled" type="bool">
      Enables a custom endpoint for the Elasticsearch domain, allowing you to use a custom domain name instead of the default endpoint. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enforce_https" type="bool">
      Whether to require HTTPS for all traffic to the domain, disabling plain HTTP access. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="tlssecurity_policy" type="string">
      The TLS security policy for the Elasticsearch domain endpoint, specifying the minimum TLS version required for connections (e.g., 'Policy-Min-TLS-1-0-2019-07' or 'Policy-Min-TLS-1-2-2019-07'). Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="domain_name" type="string">
  The name of the Elasticsearch domain, which must be unique within the AWS account and region and is used as the domain identifier in the endpoint URL. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ebsoptions" type="object">
  Configures the Amazon EBS volumes attached to the data nodes of the Elasticsearch domain, including whether EBS is enabled, volume type, size, and IOPS. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="ebsenabled" type="bool">
      Enables EBS volumes on the Elasticsearch domain's data nodes, allowing storage configuration when set to true. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="iops" type="number">
      The provisioned IOPS (I/O operations per second) for the EBS volume attached to the Elasticsearch domain, applicable when the volume type is provisioned IOPS (io1). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="volume_size" type="number">
      The size in GiB of the EBS volume attached to each data node in the Elasticsearch domain. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="volume_type" type="string">
      The EBS volume type (e.g., 'standard', 'gp2', 'io1') to provision for the Amazon Elasticsearch Service domain's data nodes. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Elasticsearch domain. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Elasticsearch domain. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_endpoint" type="string">
  The fully qualified domain endpoint (e.g., https://search-&lt;domain-name&gt;-&lt;unique-id&gt;.&lt;region&gt;.es.amazonaws.com) automatically assigned to the Elasticsearch domain after creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier of the Elasticsearch domain, which is its domain name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

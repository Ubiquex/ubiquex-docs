`aws_qbusiness_data_accessor` grants a real external ISV application cross-account access to query an `aws_qbusiness_application`'s index through the SearchRelevantContent API, so that ISV's own product can surface an organization's Q Business content without duplicating it. This inherits Q Business's own closed-to-new-customers status as of July 31, 2026.

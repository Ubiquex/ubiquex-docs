`aws_qbusiness_web_experience` creates a real, hosted chat front end for an `aws_qbusiness_application`, so end users can interact with it directly in a browser rather than only through the API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	qbusiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/qbusiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own web experience"})

    		ubx.Resource(qbusiness.WebExperience, "example", qbusiness.WebExperienceConfig{
    			ApplicationId:                 "example",
    			BrowserExtensionConfiguration: map[string]any{"enabled_browser_extensions": []string{"example"}},
    			CustomizationConfiguration:    map[string]any{"custom_cssurl": "example"},
    			IdentityProviderConfiguration: map[string]any{"open_idconnect_configuration": map[string]any{"secrets_arn": "example"}},
    			Origins:                       []string{"example"},
    			RoleArn:                       "arn:aws:iam::123456789012:policy/example",
    			SamplePromptsControlMode:      "example",
    			Subtitle:                      "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier of the AWS QBusiness application to which this web experience is attached. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="browser_extension_configuration" type="object">
  Configures the browser extension for the web experience, including whether the extension is enabled and the extension name used to access the QBusiness assistant from a supported browser. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled_browser_extensions" type="list(string)" required>
      Specifies the browsers (such as Chrome, Firefox, and Edge) for which the AWS Q Business browser extension is enabled in the web experience. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="customization_configuration" type="object">
  Specifies the custom CSS and JavaScript URLs used to customize the appearance and behavior of the AWS Q Business web experience. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="custom_cssurl" type="string">
      The URL of a custom CSS file that overrides the default styling of the QBusiness web experience to match your organization's branding. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="favicon_url" type="string">
      Specifies the URL of a custom favicon that replaces the default QBusiness icon for the web experience. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="font_url" type="string">
      Defines the URL of a custom font that replaces the default font for the Amazon Q Business web experience. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="logo_url" type="string">
      The URL of a custom logo image that Amazon Q Business displays on the web experience's chat interface. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="identity_provider_configuration" type="object">
  Defines the identity provider configuration for the web experience, allowing you to specify either SAML or OIDC settings for user authentication. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="open_idconnect_configuration" type="object">
      Specifies the OpenID Connect (OIDC) configuration for users to authenticate to the web experience, referencing the AWS Secrets Manager secret that stores OIDC client credentials and the IAM role used to retrieve them. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="secrets_arn" type="string">
          The ARN of an AWS Secrets Manager secret that stores the client secret for the OpenID Connect configuration, which the web experience uses to authenticate with the OIDC identity provider. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="secrets_role" type="string">
          The ARN of an IAM role that Amazon Q Business assumes to retrieve the OIDC client secret from AWS Secrets Manager for authenticating users to the web experience. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="saml_configuration" type="object">
      Configures SAML-based single sign-on for the web experience by specifying the IdP metadata document, the IAM role ARN, and optional user/group attribute mappings for authentication. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="authentication_url" type="string">
          The URL of the identity provider's authentication endpoint to which users are redirected for SAML single sign-on. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="origins" type="list(string)">
  A list of allowed origin URLs (e.g., 'https://example.com') that can embed or access this Amazon Q Business web experience, enabling secure integration with your own web applications while controlling cross-origin access. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string">
  The Amazon Resource Name (ARN) of the IAM role that the web experience assumes to access AWS services and resources. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="sample_prompts_control_mode" type="string">
  Determines whether sample prompts are shown to users in the AWS Q Business web experience, with allowed values ENABLED or DISABLED. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subtitle" type="string">
  The subtitle for the AWS QBusiness web experience, typically displayed under the title in the chat interface. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag objects (each with a key and value) that are attached to the Amazon Q Business web experience for resource identification, cost allocation, and access management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Defines the tag key for a key-value pair assigned to an AWS Q Business web experience, enabling resource categorization, cost management, and access control through AWS tagging. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="title" type="string">
  The title of the web experience, which is displayed to users in the browser tab and as the heading of the web experience interface. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="welcome_message" type="string">
  The custom message that Amazon Q Business displays to users when they first open the web experience chat interface. Optional. **(AI-inferred)**
</ResponseField>

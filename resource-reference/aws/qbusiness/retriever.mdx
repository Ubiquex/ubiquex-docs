title: "aws_qbusiness_retriever"
description: "`aws_qbusiness_retriever` adds a real retrieval configuration to an `aws_qbusiness_application`..."
---

`aws_qbusiness_retriever` adds a real retrieval configuration to an `aws_qbusiness_application`, pointing it at either its own native `aws_qbusiness_index` or an existing Amazon Kendra index as the source of grounding content for its generated answers.

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier of the Amazon Q Business application to which this retriever belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="configuration" type="object" required>
  Defines the retriever type-specific configuration, which specifies either the Amazon Kendra index configuration (KendraIndexConfiguration) or the native QBusiness index configuration (NativeIndexConfiguration), determining how documents are retrieved. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="kendra_index_configuration" type="object">
      Specifies the configuration for using an Amazon Kendra index as the retriever, including the identifier of the Kendra index. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="index_id" type="string">
          The unique identifier of the Amazon Kendra index to be used as the retriever in the Amazon Q Business retriever configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="native_index_configuration" type="object">
      Configures the retriever to use a native Amazon Q Business index, specifying the index ID and optional metadata handling settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="index_id" type="string">
          Specifies the unique identifier of the Amazon Q Business native index that the retriever is configured to use for performing searches. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The human-readable name for the retriever, used to identify it in the AWS Q Business console and API responses. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of an IAM role that grants Amazon Q Business permissions to access the data source associated with this retriever. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Defines the AWS tags (key-value pairs) applied to the Amazon Q Business retriever resource, which can be used for cost allocation, access control, and metadata organization. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the Amazon Q Business retriever resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of retriever, either NATIVE_INDEX for the Amazon Q Business native index or KENDRA_INDEX for an Amazon Kendra index. Required. **(AI-inferred)**
</ResponseField>

`aws_qbusiness_index` creates a real search index within an `aws_qbusiness_application` that one or more `aws_qbusiness_data_source`s populate and that an `aws_qbusiness_retriever` reads from to ground the application's generative answers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	qbusiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/qbusiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own index"})

    		ubx.Resource(qbusiness.Index, "ci-runner", qbusiness.IndexConfig{
    			ApplicationId:                   "example",
    			DisplayName:                     "example-display-name",
    			CapacityConfiguration:           map[string]any{"units": 1},
    			Description:                     "Managed by ubx.",
    			DocumentAttributeConfigurations: []map[string]any{{"name": "example-name"}},
    			Tags:                            []map[string]any{{"key": "example"}},
    			Type:                            "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The unique identifier of the AWS QBusiness application that this index belongs to, required when creating the index. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="capacity_configuration" type="object">
  Specifies the capacity configuration for the index, selecting either the ENTERPRISE or STARTER index type and the number of capacity units to allocate. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="units" type="number">
      The number of capacity units to allocate to the Amazon Q Business index, where each unit adds a fixed amount of storage and query capacity. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A description for the Amazon Q Business index. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The display name of the Amazon Q Business index, which is a required, user-visible name that identifies the index in the Q Business console and API operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="document_attribute_configurations" type="list(object)">
  Defines which document metadata attributes the index will index and how they can be used for querying and filtering, by specifying each attribute's name, type, and usage configuration. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The unique name of the document attribute that this configuration applies to, used to match metadata fields in ingested documents and reference the attribute in data source schemas. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="search" type="string">
      Determines whether the document attribute can be used in search queries, with allowed values ENABLED or DISABLED. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the data type of the document attribute in the index configuration, such as STRING, NUMBER, or DATE, which determines how the attribute is indexed and searched. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tag objects to attach to the Amazon Q Business index, used for organizing, managing, and identifying the resource in AWS. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag pair attached to the Amazon Q Business index, enabling resource categorization and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  Specifies whether the Amazon Q Business index is an ENTERPRISE index for general enterprise search or an ANALYTICS index for analytical and data-intensive workloads. Optional. **(AI-inferred)**
</ResponseField>

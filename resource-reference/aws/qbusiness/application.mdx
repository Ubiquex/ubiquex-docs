`aws_qbusiness_application` creates a real Amazon Q Business application, the top-level container for an enterprise's own indexed data, retrievers, plugins, and web experience in this generative-AI assistant service. Amazon Q Business closed to new customers on July 31, 2026, a date roughly three weeks in the past from now; existing customers keep full support, security patches, and bug fixes, but no new features, and AWS is steering new use cases toward Amazon Quick, the evolution of what was Amazon QuickSight.

## Input properties

<ResponseField name="attachments_configuration" type="object">
  Configures whether users can attach files to conversations in the Q Business application, controlled by the AttachmentsControlMode setting (either ENABLED or DISABLED). Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="attachments_control_mode" type="string" required>
      Determines whether users can use attachments in the application's chat sessions, with a required value of either ENABLED or DISABLED. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="auto_subscription_configuration" type="object">
  Determines whether new users are automatically subscribed to the Amazon Q Business application and, if enabled, specifies the default subscription type (ENTERPRISE or STARTER) assigned to them. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="auto_subscribe" type="string" required>
      Determines whether AWS Q Business automatically subscribes new users to a default subscription tier (e.g., Q Business Lite or Pro) configured via the default_subscription_type field, with allowed values ENABLED or DISABLED. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="default_subscription_type" type="string">
      Specifies the default subscription type (either 'PLUS' or 'ENTERPRISE') that AWS QBusiness automatically assigns to users when auto-subscription is enabled for the application. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="client_ids_for_oidc" type="list(string)">
  Specifies the list of OAuth 2.0 client IDs that an Amazon Q Business application accepts from its OIDC identity provider for authenticating users. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Specifies a user-provided description for the Amazon Q Business application, used to convey its purpose or context to administrators. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string" required>

</ResponseField>

<ResponseField name="encryption_configuration" type="object">

<ResponseField name="iam_identity_provider_arn" type="string">

</ResponseField>

<ResponseField name="identity_center_instance_arn" type="string">

  <Expandable title="properties">
    <ResponseField name="personalization_control_mode" type="string" required>
      Controls whether personalization is enabled for the Amazon Q Business application, accepting values such as 'ENABLED' or 'DISABLED' to turn the feature on or off. Required. **(AI-inferred)**

## Output properties

<ResponseField name="application_arn" type="string">
  The Amazon Resource Name (ARN) of the Q Business application, assigned by AWS when the application is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="application_id" type="string">
  The unique identifier that AWS QBusiness automatically assigns to the application when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp of when the QBusiness application was created, computed by AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="identity_center_application_arn" type="string">

</ResponseField>

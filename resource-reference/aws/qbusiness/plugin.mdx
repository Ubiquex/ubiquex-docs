`aws_qbusiness_plugin` connects a real third-party or custom action, such as creating a ticket or updating a record in another system, to an `aws_qbusiness_application`, letting its assistant take actions rather than only answer questions.

## Example

    ```go
    	qbusiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/qbusiness"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own plugin"})

    			AuthConfiguration:         map[string]any{"basic_auth_configuration": map[string]any{"role_arn": "example"}},

    			Type:                      "example",
    			ApplicationId:             "example",
    			CustomPluginConfiguration: map[string]any{"api_schema": map[string]any{"payload": "example"}, "api_schema_type": "example", "description": "example"},
    			ServerUrl:                 "example",
    			State:                     "example",
    			Tags:                      []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.aws.qbusiness import Plugin, PluginConfig
    from ubx.aws.qbusiness.plugin import Plugin_AuthConfiguration, Plugin_AuthConfiguration_BasicAuthConfiguration, Plugin_CustomPluginConfiguration, Plugin_CustomPluginConfiguration_ApiSchema, Plugin_Tags

    def describe():
        ubx.intent("example own plugin")

        ubx.resource(Plugin, "example", PluginConfig(
            auth_configuration=Plugin_AuthConfiguration(basic_auth_configuration=Plugin_AuthConfiguration_BasicAuthConfiguration(role_arn="example")),
            display_name="example-display-name",
            type="example",
            application_id="example",

            server_url="example",
            state="example",
            tags=[Plugin_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="application_id" type="string">
  The unique identifier of the Amazon Q Business application that this plugin is attached to. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="auth_configuration" type="object" required>
  Specifies the authentication configuration for the plugin, defining whether it uses basic or OAuth 2.0 authentication along with the necessary credentials and endpoint details. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="basic_auth_configuration" type="object">
      Specifies the basic authentication settings for the AWS QBusiness plugin by providing the ARN of the AWS Secrets Manager secret that stores the credentials used for authentication. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="role_arn" type="string">
          The ARN of the IAM role that AWS QBusiness assumes to retrieve the basic authentication credentials stored in AWS Secrets Manager. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="secret_arn" type="string">
          The ARN of the AWS Secrets Manager secret that stores the username and password credentials used for basic authentication to the external application configured for the QBusiness plugin. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="no_auth_configuration" type="any">
      Configures the QBusiness plugin to require no authentication credentials, indicating that the plugin's external service calls do not need user or API keys. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="oauth2_client_credential_configuration" type="object">
      Defines the OAuth 2.0 client credential settings for the plugin, including the authorization URL, client ID, client secret, and scope, enabling the plugin to authenticate with the external service. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="authorization_url" type="string">
          The authorization URL to which users are redirected for authentication when using the OAuth 2.0 client credential configuration for the plugin. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="role_arn" type="string">
          The ARN of the IAM role that AWS Q Business assumes to retrieve the OAuth2 client credentials stored in AWS Secrets Manager for this plugin's authentication. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="secret_arn" type="string">
          The ARN of the AWS Secrets Manager secret that stores the client secret used for the OAuth2 client credential authentication flow. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="token_url" type="string">
          The URL of the OAuth2 token endpoint that the AWS QBusiness plugin calls to exchange its client credentials for an access token. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="custom_plugin_configuration" type="object">
  Defines the API schema and source code repository settings for a custom plugin in Amazon Q Business when the plugin type is CUSTOM. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="api_schema" type="object" required>
      Specifies the OpenAPI 3.0 schema that defines the API operations and data structures for the custom plugin, provided either inline as a JSON/YAML payload or as a reference to an S3 object. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="payload" type="string">
          Contains the inline API schema, in JSON or YAML format, that describes the custom plugin's endpoints and operations for Amazon Q Business to invoke. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="s3" type="object">
          Configures the Amazon S3 location (bucket and object key) where the OpenAPI schema file for the custom plugin is stored. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="bucket" type="string">
              The name of the S3 bucket that stores the OpenAPI schema file defining the plugin's API, as referenced by the custom plugin configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="key" type="string">
              The S3 object key (file name) of the OpenAPI schema file that defines the custom plugin's API, stored in the S3 bucket specified by the parent s3 configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="api_schema_type" type="string" required>
      Specifies the type of API schema for the custom plugin, either an S3 object or an inline OpenAPI 3.0 payload, with allowed values S3 and OPEN_API_V3. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="description" type="string" required>
      Provides a description of the custom plugin, helping users understand its purpose and functionality. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The human-readable name of the plugin, used to identify it in the Amazon Q Business console and APIs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_url" type="string">
  The URL of the external server or application that the plugin connects to, serving as the endpoint for its configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="state" type="string">
  Indicates the current status of the plugin, such as ENABLED or DISABLED, which determines whether the plugin is active for use in Amazon Q Business applications. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags (key-value pairs) to attach to the QBusiness plugin resource for cost allocation, organization, and identification. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the QBusiness plugin, used to store arbitrary metadata for identifying or categorizing the plugin. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  Specifies the type of the third-party application the plugin integrates with, which determines the required authentication and configuration schema (e.g., SERVICE_NOW, SALESFORCE, JIRA, ZENDESK, or CUSTOM). Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="build_status" type="string">
  The current build status of the Amazon Q Business plugin, indicating whether it is ready to use (e.g., READY), still being created (CREATING), or has failed (FAILED). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp indicating when the plugin was created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="plugin_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the plugin in AWS QBusiness. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="plugin_id" type="string">
  The unique identifier assigned by AWS to the plugin in Amazon Q Business when it is created, used to reference the plugin in other APIs and resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp (in ISO 8601 format) indicating when the plugin was last updated, set automatically by AWS QBusiness. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

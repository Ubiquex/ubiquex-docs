`aws_qbusiness_permission` grants a real resource-based permission on an `aws_qbusiness_application`'s index to a specific external account, the mechanism underlying an `aws_qbusiness_data_accessor`'s cross-account read access.

## Properties

<ResponseField name="actions" type="list(string)" required>
  Lists the Amazon Q Business API actions (e.g., 'qbusiness:Query') that the principal is authorized to perform on the associated Q Business application. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="application_id" type="string" required>
  The unique identifier of the Amazon Q Business application to which this permission applies. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="conditions" type="list(object)">
  A list of condition objects, each specifying a condition key (like a user or document attribute) and its allowed values, that restrict the application of the Q Business permission to matching principals and documents. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="condition_key" type="string">
      In an AWS::QBusiness::Permission policy statement, the condition_key field names the contextual key that the permission condition evaluates against the request's context to determine whether the granted actions apply to the principal. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="condition_operator" type="string">
      This field specifies the IAM condition operator (such as StringEquals, StringLike, or Bool) used to compare a condition key against its value in a permission policy entry for Amazon Q Business. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="condition_values" type="list(string)">
      For each condition entry in the Q Business permission policy, this list contains the values that must match the condition key to apply the permission, allowing context-based restrictions such as organization IDs or tags. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="principal" type="string" required>
  The ARN of the IAM principal (user, role, or group) to which the Q Business application permission is granted. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="statement_id" type="string" required>
  The unique identifier for a permission statement that grants the Amazon Q Business application access to a specified action and resource. Required. **(AI-inferred)**
</ResponseField>

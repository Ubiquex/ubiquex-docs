`aws_ivs_stage` is Amazon IVS's real, low-latency, multi-participant video collaboration resource, up to several hosts and guests interacting live together, distinct from an `aws_ivs_channel`'s own single-broadcaster-to-many-viewers model.

## Input properties

<ResponseField name="auto_participant_recording_configuration" type="object">
  Configuration object for individual participant recording, to attach to the new stage. Optional.
  <Expandable title="properties">
    <ResponseField name="hls_configuration" type="object">
      HLS configuration object for individual participant recording. Optional.
      <Expandable title="properties">
        <ResponseField name="participant_recording_hls_configuration" type="object">
          An object representing a configuration of participant HLS recordings for individual participant recording. Optional.
          <Expandable title="properties">
            <ResponseField name="target_segment_duration_seconds" type="number">
              Defines the target duration for recorded segments generated when recording a stage participant. Segments may have durations longer than the specified value when needed to ensure each segment begins with a keyframe. Default: 6. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="media_types" type="list(string)">
      Types of media to be recorded. Default: AUDIO_VIDEO. Optional.
    </ResponseField>
    <ResponseField name="recording_reconnect_window_seconds" type="number">
      If a stage publisher disconnects and then reconnects within the specified interval, the multiple recordings will be considered a single recording and merged together. The default value is 0, which disables merging. Optional.
    </ResponseField>
    <ResponseField name="storage_configuration_arn" type="string" required>
      ARN of the StorageConfiguration resource to use for individual participant recording. Required.
    </ResponseField>
    <ResponseField name="thumbnail_configuration" type="object">
      A complex type that allows you to enable/disable the recording of thumbnails for individual participant recording and modify the interval at which thumbnails are generated for the live session. Optional.
      <Expandable title="properties">
        <ResponseField name="participant_thumbnail_configuration" type="object">
          An object representing a configuration of thumbnails for recorded video from an individual participant. Optional.
          <Expandable title="properties">
            <ResponseField name="recording_mode" type="string">
              Thumbnail recording mode. Default: DISABLED. Optional.
            </ResponseField>
            <ResponseField name="storage" type="list(string)">
              Indicates the format in which thumbnails are recorded. SEQUENTIAL records all generated thumbnails in a serial manner, to the media/thumbnails/high directory. LATEST saves the latest thumbnail in media/latest_thumbnail/high/thumb.jpg and overwrites it at the interval specified by targetIntervalSeconds. You can enable both SEQUENTIAL and LATEST. Default: SEQUENTIAL. Optional.
            </ResponseField>
            <ResponseField name="target_interval_seconds" type="number">
              The targeted thumbnail-generation interval in seconds. This is configurable only if recordingMode is INTERVAL. Default: 60. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

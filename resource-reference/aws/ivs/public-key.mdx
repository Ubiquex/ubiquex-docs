`aws_ivs_public_key` registers a real public key IVS validates participant tokens for an `aws_ivs_stage` against, the Real-Time Streaming counterpart to `aws_ivs_playback_key_pair`'s own channel-playback authorization.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ivs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ivs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own public key"})

    		ubx.Resource(ivs.PublicKey, "ci-runner", ivs.PublicKeyConfig{
    			Name:              "ci-runner",
    			PublicKeyMaterial: "example",
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="name" type="string">
  Name of the public key to be imported. The value does not need to be unique. Optional.
</ResponseField>

<ResponseField name="public_key_material" type="string">
  The public portion of a customer-generated key pair. This field is required to create the AWS::IVS::PublicKey resource. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the asset model. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value associated with a tag key attached to the AWS IVS public key, used for organizing or identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

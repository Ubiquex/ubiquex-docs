`aws_ivs_playback_restriction_policy` restricts real playback of an `aws_ivs_channel` by geography or origin domain, blocking viewers outside an allowed country list or a site that isn't the caller's own from embedding the stream.

## Input properties

<ResponseField name="allowed_countries" type="list(string)">
  A list of country codes that control geoblocking restriction. Allowed values are the officially assigned ISO 3166-1 alpha-2 codes. Default: All countries (an empty array). Optional.
</ResponseField>

<ResponseField name="allowed_origins" type="list(string)">
  A list of origin sites that control CORS restriction. Allowed values are the same as valid values of the Origin header defined at https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Origin Optional.
</ResponseField>

<ResponseField name="enable_strict_origin_enforcement" type="bool">
  Whether channel playback is constrained by origin site. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  Playback-restriction-policy name. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

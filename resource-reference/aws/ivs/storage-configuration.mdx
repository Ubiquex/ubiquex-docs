`aws_ivs_storage_configuration` defines a real S3 destination that an `aws_ivs_stage`'s own composite recording gets written to, the stage counterpart to `aws_ivs_recording_configuration`'s channel-level recording.

## Input properties

<ResponseField name="name" type="string">
  Storage Configuration Name. Optional.
</ResponseField>

<ResponseField name="s3" type="object" required>
  A complex type that describes an S3 location where recorded videos will be stored. Required.
  <Expandable title="properties">
    <ResponseField name="bucket_name" type="string" required>
      Location (S3 bucket name) where recorded videos will be stored. Note that the StorageConfiguration and S3 bucket must be in the same region as the Composition. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the asset model. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag to associate with the IVS storage configuration, used for resource categorization and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      A user-defined tag value (the 'value' part of a key-value tag) applied to this IVS storage configuration for resource identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Storage Configuration ARN is automatically generated on creation and assigned as the unique identifier. Computed by AWS after `ship`.
</ResponseField>

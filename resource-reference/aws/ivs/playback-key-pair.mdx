`aws_ivs_playback_key_pair` signs real, private playback tokens for an `aws_ivs_channel` configured to require authorization, restricting viewing to clients that present a token signed by this specific key pair.

## Example

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    			Name:              "ci-runner",
    			PublicKeyMaterial: "example",

    		})
    	}))
    }

## Input properties

<ResponseField name="name" type="string">
  An arbitrary string (a nickname) assigned to a playback key pair that helps the customer identify that resource. The value does not need to be unique. Optional.
</ResponseField>

<ResponseField name="public_key_material" type="string">
  The public portion of a customer-generated key pair. This field is required to create the AWS::IVS::PlaybackKeyPair resource. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the asset model. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag attached to the IVS playback key pair, used to label and organize the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the Amazon IVS playback key pair, used for metadata management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

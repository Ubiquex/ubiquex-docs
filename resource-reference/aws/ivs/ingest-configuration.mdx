`aws_ivs_ingest_configuration` specifies a real, named ingest protocol, RTMP or RTMPS, for broadcasting into a specific `aws_ivs_stage`'s real-time stage, including whether insecure RTMP ingest is allowed and an optional customer-assigned user ID used to link the ingest participant to the customer's own systems. Verified live against AWS's own CloudFormation reference this session, resolving last session's flagged, unverified version of this entry.

## Input properties

  Ingest Protocol. Optional.
</ResponseField>

<ResponseField name="insecure_ingest" type="bool">
  Whether ingest configuration allows insecure ingest. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  IngestConfiguration Optional.
</ResponseField>

<ResponseField name="stage_arn" type="string">
  Stage ARN. A value other than an empty string indicates that stage is linked to IngestConfiguration. Default: "" (recording is disabled). Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

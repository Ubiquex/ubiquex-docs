`aws_ivs_stream_key` is the real, secret credential streaming software uses to authenticate and publish video to a specific `aws_ivs_channel`, distinct from the channel's own public ingest endpoint URL.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ivs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ivs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own stream key"})

    		ubx.Resource(ivs.StreamKey, "ci-runner", ivs.StreamKeyConfig{
    			ChannelArn: "arn:aws:iam::123456789012:policy/ci",
    			Tags:       []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="channel_arn" type="string" required>
  Channel ARN for the stream. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs that contain metadata for the asset model. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag assigned to the AWS IVS stream key, used for identifying and categorizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

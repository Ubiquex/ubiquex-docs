`aws_ivs_encoder_configuration` sets real encoding parameters, resolution, bitrate, for Amazon IVS Real-Time Streaming, applied to participants in an `aws_ivs_stage` rather than a single broadcast `aws_ivs_channel`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ivs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ivs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own encoder configuration"})

    		ubx.Resource(ivs.EncoderConfiguration, "ci-runner", ivs.EncoderConfigurationConfig{
    			Name:  "ci-runner",
    			Tags:  []map[string]any{{"key": "example"}},
    			Video: map[string]any{"bitrate": 1},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string">
  Encoder configuration name. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined tag key to associate with the IVS encoder configuration, used for resource management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="video" type="object">
  Video configuration. Default: video resolution 1280x720, bitrate 2500 kbps, 30 fps Optional.
  <Expandable title="properties">
    <ResponseField name="bitrate" type="number">
      Bitrate for generated output, in bps. Default: 2500000. Optional.
    </ResponseField>
    <ResponseField name="framerate" type="number">
      Video frame rate, in fps. Default: 30. Optional.
    </ResponseField>
    <ResponseField name="height" type="number">
      Video-resolution height. This must be an even number. Note that the maximum value is determined by width times height, such that the maximum total pixels is 2073600 (1920x1080 or 1080x1920). Default: 720. Optional.
    </ResponseField>
    <ResponseField name="width" type="number">
      Video-resolution width. This must be an even number. Note that the maximum value is determined by width times height, such that the maximum total pixels is 2073600 (1920x1080 or 1080x1920). Default: 1280. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Encoder configuration identifier. Computed by AWS after `ship`.
</ResponseField>

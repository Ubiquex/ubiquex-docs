`aws_security_agent_security_requirement_pack` defines a real, reusable set of organizational security requirements that AWS Security Agent evaluates an `aws_security_agent_application` against during its automated reviews and penetration tests.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityagent "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/securityagent"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent securityagent requirement pack"})

    		ubx.Resource(securityagent.SecurityRequirementPack, "example", securityagent.SecurityRequirementPackConfig{
    			Name:                 "example",
    			Description:          "Managed by ubx.",
    			KmsKeyId:             "example",
    			SecurityRequirements: []map[string]any{{"name": "example-name"}},
    			Status:               "example",
    			Tags:                 []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  Description of the pack Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  KMS key for client-side encryption of pack contents Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the security requirement pack Required.
</ResponseField>

<ResponseField name="security_requirements" type="list(object)">
  Security requirements within this pack Optional.
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      Provides a human-readable description of the security requirement, explaining the specific security control or configuration the requirement addresses. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="domain" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="evaluation" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="name" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="remediation" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  Whether the pack is enabled or disabled Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags for the security requirement pack Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="pack_id" type="string">
  Unique identifier of the security requirement pack Computed by AWS after `ship`.
</ResponseField>

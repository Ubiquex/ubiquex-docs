`aws_workspaces_instances_volume` creates a real EBS volume attached to an `aws_workspaces_instances_workspace_instance`, under WorkSpaces Core's newer, EC2-based managed-instance architecture, distinct from classic `aws_work_spaces_workspace`'s own bundled storage model.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	workspacesinstances "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/workspacesinstances"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own volume"})

    		ubx.Resource(workspacesinstances.Volume, "example", workspacesinstances.VolumeConfig{
    			AvailabilityZone:  "example",
    			Encrypted:         true,
    			Iops:              1,
    			KmsKeyId:          "example",
    			SizeInGb:          1,
    			SnapshotId:        "example",
    			TagSpecifications: []map[string]any{{"resource_type": "example"}},
    			Throughput:        1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="availability_zone" type="string" required>
  The Availability Zone in which to create the volume Required.
</ResponseField>

<ResponseField name="encrypted" type="bool">
  Indicates whether the volume should be encrypted Optional.
</ResponseField>

<ResponseField name="iops" type="number">
  The number of I/O operations per second (IOPS) Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The identifier of the AWS Key Management Service (AWS KMS) customer master key (CMK) to use for Amazon EBS encryption Optional.
</ResponseField>

<ResponseField name="size_in_gb" type="number">
  The size of the volume, in GiBs Optional.
</ResponseField>

<ResponseField name="snapshot_id" type="string">
  The snapshot from which to create the volume Optional.
</ResponseField>

<ResponseField name="tag_specifications" type="list(object)">
  The tags passed to EBS volume Optional.
  <Expandable title="properties">
    <ResponseField name="resource_type" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="tags" type="list(object)">
      The tags block within a tag specification, used to define key-value pairs that are attached to the WorkSpaces instance volume for identification and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          Optional; if omitted, computed by AWS.
        </ResponseField>
        <ResponseField name="value" type="string">
          The value of a tag assigned to the WorkSpaces volume within the tag specification, used to categorize and manage the volume. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="throughput" type="number">
  The throughput to provision for a volume, with a maximum of 1,000 MiB/s Optional.
</ResponseField>

<ResponseField name="volume_type" type="string">
  The volume type Optional.
</ResponseField>

## Output properties

<ResponseField name="volume_id" type="string">
  Unique identifier for the volume Computed by AWS after `ship`.
</ResponseField>

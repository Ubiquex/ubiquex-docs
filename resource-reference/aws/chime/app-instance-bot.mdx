`aws_chime_app_instance_bot` registers an automated, non-human participant inside an `aws_chime_app_instance`, able to send and receive channel messages the same way an `aws_chime_app_instance_user` does, the real identity behind an AI or automated assistant integrated into Chime SDK messaging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chime "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/chime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app instance bot"})

    		ubx.Resource(chime.AppInstanceBot, "example", chime.AppInstanceBotConfig{
    			AppInstanceArn: "arn:aws:iam::123456789012:policy/example",
    			Configuration:  map[string]any{"lex": map[string]any{"lex_bot_alias_arn": "example"}},
    			Name:           "example",
    			Metadata:       "example",
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="app_instance_arn" type="string" required>
  The ARN of the AppInstance. Required.
</ResponseField>

<ResponseField name="configuration" type="object" required>
  A structure that contains configuration data. Required.
  <Expandable title="properties">
    <ResponseField name="lex" type="object" required>
      The configuration for an Amazon Lex V2 bot. Required.
      <Expandable title="properties">
        <ResponseField name="invoked_by" type="object">
          Specifies the type of message that triggers a bot. Optional.
          <Expandable title="properties">
            <ResponseField name="standard_messages" type="string" required>
              Sets standard messages as the bot trigger. Required.
            </ResponseField>
            <ResponseField name="targeted_messages" type="string" required>
              Sets targeted messages as the bot trigger. Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="lex_bot_alias_arn" type="string" required>
          The ARN of the Amazon Lex V2 bot's alias. Required.
        </ResponseField>
        <ResponseField name="locale_id" type="string" required>
          Identifies the Amazon Lex V2 bot's language and locale. Required.
        </ResponseField>
        <ResponseField name="responds_to" type="string">
          Determines whether the Amazon Lex V2 bot responds to all standard messages. Control messages are not supported. Optional.
        </ResponseField>
        <ResponseField name="welcome_intent" type="string">
          The name of the welcome intent configured in the Amazon Lex V2 bot. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="string">
  The metadata of the AppInstanceBot. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the AppInstanceBot. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags assigned to the AppInstanceBot. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AppInstanceBot, used to categorize and manage the resource (e.g., environment, project) in AWS Chime. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined metadata tag attached to the Amazon Chime App Instance Bot. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="app_instance_bot_arn" type="string">
  The ARN of the AppInstanceBot. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_timestamp" type="string">
  The time at which the AppInstanceBot was created, as an ISO 8601 timestamp. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="last_updated_timestamp" type="string">
  The time at which the AppInstanceBot was last updated, as an ISO 8601 timestamp. Computed by AWS after `ship`.
</ResponseField>

`aws_chime_app_instance` creates the top-level messaging container in Amazon Chime SDK Identity, the real resource every `aws_chime_app_instance_user` and `aws_chime_app_instance_bot` for a messaging application belongs to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	chime "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/chime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app instance"})

    		ubx.Resource(chime.AppInstance, "example", chime.AppInstanceConfig{
    			Name:     "example",
    			Metadata: "example",
    			Tags:     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="metadata" type="string">
  The metadata of the AppInstance. Limited to a 1KB string in UTF-8. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the AppInstance. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags assigned to the AppInstance. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that is attached to the Amazon Chime AppInstance resource for identification and organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag key-value pair attached to the Chime AppInstance, used to categorize and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

`aws_chime_channel_flow` defines an ordered sequence of processors, Lambda functions among them, that Chime SDK messaging invokes on a message before it's delivered to a channel, the real mechanism for moderation, translation, or other automated processing applied consistently to every message sent.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chime "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/chime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own channel flow"})

    		ubx.Resource(chime.ChannelFlow, "example", chime.ChannelFlowConfig{
    			AppInstanceArn: "arn:aws:iam::123456789012:policy/example",
    			Name:           "example",
    			Processors:     []map[string]any{{"name": "example-name"}},
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

        ubx.intent("example own channel flow")

## Input properties

<ResponseField name="app_instance_arn" type="string" required>
  The ARN of the app instance. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the channel flow. Required.
</ResponseField>

<ResponseField name="processors" type="list(object)" required>
  Information about the processor Lambda functions. Required.
  <Expandable title="properties">
    <ResponseField name="configuration" type="object">
      Defines the configuration for a processor in the channel flow, specifying the Lambda function ARN and the invocation role ARN used when the processor type is Lambda. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="lambda" type="object">
          The configuration block for a Lambda processor in a Chime channel flow, specifying the Lambda function ARN and the IAM role ARN used to invoke it. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="invocation_type" type="string">
              Specifies whether the Lambda function is invoked asynchronously (ASYNC) or synchronously (SYNC) for this processor in the channel flow. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="resource_arn" type="string">
              The ARN of the AWS Lambda function that the Amazon Chime channel flow invokes to process messages for this processor. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="execution_order" type="number">
      The integer execution order of this processor within the channel flow, which determines the sequence in which processors are invoked during message processing. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="fallback_action" type="string">
      The action to execute if the processor's primary action fails, such as 'SEND' or 'DELETE'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The user-defined name that identifies this processor within the channel flow's processor list, used for configuration and runtime reference. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the channel flow. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Chime ChannelFlow resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_chime_app_instance_user` registers a real, addressable participant, typically created the first time a person signs in, inside an `aws_chime_app_instance`, the identity that Chime SDK messaging attaches as the sender of a message or the member of a channel.

## Example

    ```go
    package main

    import (
    	chime "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/chime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app instance user"})

    		ubx.Resource(chime.AppInstanceUser, "example", chime.AppInstanceUserConfig{
    			AppInstanceArn:     "arn:aws:iam::123456789012:policy/example",
    			AppInstanceUserId:  "example",
    			Name:               "example",
    			ExpirationSettings: map[string]any{"expiration_criterion": "example", "expiration_days": 1},
    			Metadata:           "example",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="app_instance_arn" type="string" required>
  The ARN of the Amazon Chime AppInstance in which this user is created, uniquely identifying the parent app instance for the user. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="app_instance_user_id" type="string" required>
  The client-supplied unique identifier for the user within the specified Amazon Chime AppInstance, which is required at creation and is used to form the user's ARN. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="expiration_settings" type="object">
  Configures automatic deletion of the AppInstanceUser after a specified number of days from its creation timestamp, using an expiration criterion and day count. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="expiration_criterion" type="string" required>
      Specifies whether the expiration date for the AppInstanceUser is calculated from the user's creation timestamp (CREATED_TIMESTAMP) or their last activity timestamp (LAST_ACTIVE_TIMESTAMP). Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="expiration_days" type="number" required>
      The number of days after which the Amazon Chime AppInstanceUser account automatically expires and is deleted. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="string">
  An optional user-defined metadata string (up to 1000 characters) attached to the AppInstanceUser for app-specific information. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Sets the display name for the AppInstanceUser, which is used to identify the user within the Amazon Chime app instance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of tags to associate with the App Instance User, used for organizing and managing the user in AWS Chime. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a key-value tag attached to the Amazon Chime AppInstanceUser, used to label and categorize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag attached to an Amazon Chime AppInstanceUser, used to add user-defined metadata to the identity for management and tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="app_instance_user_arn" type="string">
  The Amazon Resource Name (ARN) of the AppInstanceUser, assigned by AWS when the user is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

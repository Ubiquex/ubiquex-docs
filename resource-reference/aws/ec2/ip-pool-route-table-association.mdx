`aws_ec2_ip_pool_route_table_association` associates a real `aws_route_table` with an IPAM pool's own address space, letting IPAM propagate routes for that pool's CIDRs automatically rather than requiring each route to be added by hand.

## Example

    		})

## Input properties

<ResponseField name="public_ipv4_pool" type="string" required>
  The ID of the public IPv4 pool. Required.
</ResponseField>

<ResponseField name="route_table_id" type="string" required>
  The ID of the route table. Required.
</ResponseField>

## Output properties

<ResponseField name="association_id" type="string">
  The route table association ID. Computed by AWS after `ship`.
</ResponseField>

`aws_ec2_transit_gateway_multicast_group_source` registers a real network interface as the sending source of a multicast group within an `aws_ec2_transit_gateway_multicast_domain`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own transit gateway multicast group source"})

    		ubx.Resource(ec2.TransitGatewayMulticastGroupSource, "example", ec2.TransitGatewayMulticastGroupSourceConfig{
    			GroupIpAddress:                  "example",
    			NetworkInterfaceId:              "example",
    			TransitGatewayMulticastDomainId: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="group_ip_address" type="string" required>
  The IP address assigned to the transit gateway multicast group. Required.
</ResponseField>

<ResponseField name="network_interface_id" type="string" required>
  The ID of the transit gateway attachment. Required.
</ResponseField>

<ResponseField name="transit_gateway_multicast_domain_id" type="string" required>
  The ID of the transit gateway multicast domain. Required.
</ResponseField>

## Output properties

<ResponseField name="group_member" type="bool">
  Indicates that the resource is a transit gateway multicast group member. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="group_source" type="bool">
  Indicates that the resource is a transit gateway multicast group member. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_id" type="string">
  The ID of the resource. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of resource, for example a VPC attachment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="source_type" type="string">
  The source type. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="subnet_id" type="string">
  The ID of the subnet. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="transit_gateway_attachment_id" type="string">
  The ID of the transit gateway attachment. Computed by AWS after `ship`.
</ResponseField>

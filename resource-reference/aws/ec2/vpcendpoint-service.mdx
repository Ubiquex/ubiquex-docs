`aws_ec2_vpcendpoint_service` exposes a caller's own real application as a PrivateLink service that other accounts' `aws_ec2_vpcendpoint`s can connect to, the provider side of the same PrivateLink connection.

## Example

    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpcendpoint service"})

    			AcceptanceRequired:         true,
    			ContributorInsightsEnabled: true,

    			SupportedIpAddressTypes:    []string{"example"},

    		})

    }
    ```

## Input properties

<ResponseField name="acceptance_required" type="bool">
  Indicates whether acceptance of connection requests to the VPC endpoint service is required from the service consumer. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="contributor_insights_enabled" type="bool">
  Optional.
</ResponseField>

<ResponseField name="gateway_load_balancer_arns" type="list(string)">
  The ARNs of one or more Gateway Load Balancers to associate with the endpoint service, routing traffic from the service to these load balancers. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_load_balancer_arns" type="list(string)">
  The ARNs of one or more Network Load Balancers (NLBs) that will be associated with the VPC endpoint service to route traffic from consumer VPC endpoints to your service. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="payer_responsibility" type="string">
  Indicates which party is responsible for the costs of the VPC endpoint (either 'ServiceOwner' or 'ServiceConsumer'), allowing the service provider to choose whether the endpoint consumer pays for the endpoint connections. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="private_dns_name" type="string">
  Specifies a custom private DNS name for the VPC endpoint service, which consumers use to access the service over PrivateLink instead of the default service name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="supported_ip_address_types" type="list(string)">
  Specify which Ip Address types are supported for VPC endpoint service. Optional.
</ResponseField>

<ResponseField name="supported_regions" type="list(string)">
  The Regions from which service consumers can access the service. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to add to the VPC endpoint service. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="private_dns_name_configuration" type="object">
  Provides the details of the private DNS name configuration associated with the VPC endpoint service, including the private DNS name, its type, value, and the current verification state. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The private DNS name (e.g., subdomain.example.com) that AWS uses to create a verification record for the VPC endpoint service's private DNS configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="state" type="string">
      Indicates the current verification state of the private DNS name associated with the VPC endpoint service, such as pendingVerification, verified, or failed. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of private DNS name configuration for the VPC endpoint service, with valid values `service` or `interface`, indicating whether the DNS name applies to the service itself or to the endpoint's network interface. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The resolved private DNS name value for the VPC endpoint service, which consumers use to access the service via a private DNS name. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_id" type="string">
  The unique identifier assigned by AWS to the VPC endpoint service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

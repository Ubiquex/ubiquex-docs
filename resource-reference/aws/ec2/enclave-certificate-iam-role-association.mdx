`aws_ec2_enclave_certificate_iam_role_association` associates a real ACM certificate with an IAM role, granting an EC2 instance running an AWS Nitro Enclave permission to retrieve that certificate's private key material inside the enclave at launch.

## Input properties

<ResponseField name="certificate_arn" type="string" required>
  The Amazon Resource Name (ARN) of the ACM certificate with which to associate the IAM role. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) of the IAM role to associate with the ACM certificate. You can associate up to 16 IAM roles with an ACM certificate. Required.
</ResponseField>

## Output properties

<ResponseField name="certificate_s3_bucket_name" type="string">
  The name of the Amazon S3 bucket to which the certificate was uploaded. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="certificate_s3_object_key" type="string">
  The Amazon S3 object key where the certificate, certificate chain, and encrypted private key bundle are stored. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="encryption_kms_key_id" type="string">
  The ID of the AWS KMS CMK used to encrypt the private key of the certificate. Computed by AWS after `ship`.
</ResponseField>

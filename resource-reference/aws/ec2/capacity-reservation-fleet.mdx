`aws_ec2_capacity_reservation_fleet` groups several `aws_ec2_capacity_reservation`s across instance types into one, real fleet-level target capacity, so a caller reserves a total amount of compute rather than managing each individual reservation by hand.

## Input properties

<ResponseField name="allocation_strategy" type="string">
  Determines how the Capacity Reservation Fleet allocates capacity across the specified instance types, either by spreading evenly across them (diversified) or by honoring the priority order you set (prioritized). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="end_date" type="string">
  Specifies the date and time at which the Capacity Reservation Fleet expires. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_match_criteria" type="string">
  Determines how instances are matched to the capacity reservation fleet: 'open' (default) allows any matching instance to use the reserved capacity, while 'targeted' requires instances to explicitly target the fleet. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_type_specifications" type="list(object)">
  Defines the list of instance type specifications for the capacity reservation fleet, each indicating an instance type, the number of instances to reserve, and the weight used to calculate total capacity. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="availability_zone" type="string">
      The Availability Zone in which the capacity reservation for this instance type specification is allocated, enabling the fleet to target capacity across specific zones. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="availability_zone_id" type="string">
      Specifies the unique identifier of the Availability Zone where capacity for the given instance type is reserved, allowing the fleet to target an AZ by its ID rather than its name. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ebs_optimized" type="bool">
      Specifies whether instances launched in this capacity reservation are EBS-optimized for enhanced performance. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="instance_platform" type="string">
      The operating system platform (e.g., Linux/UNIX, Windows, Red Hat Enterprise Linux, SUSE Linux) for the instance type specification within the EC2 Capacity Reservation Fleet. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="instance_type" type="string">
      Specifies the EC2 instance type (e.g., `m5.large`, `c5.xlarge`) for which this individual capacity reservation specification within the fleet will reserve capacity. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="priority" type="number">
      The priority of this instance type in the capacity reservation fleet, where lower values indicate higher priority for fulfilling the reservation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="weight" type="number">
      The weight value for an instance type in a Capacity Reservation Fleet determines how much of the fleet's total target capacity each instance of that type consumes when calculating the number of instances needed. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="no_remove_end_date" type="bool">
  Setting this to true indicates the Capacity Reservation Fleet has no end date, so it does not expire and automatically release its capacity reservations, remaining active until explicitly deleted. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="remove_end_date" type="bool">
  When set to true, this removes the configured end date for the capacity reservation fleet, causing it to remain active indefinitely. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tag_specifications" type="list(object)">
  Specifies the tags to apply to the Capacity Reservation Fleet during creation, enabling resource management and cost allocation through key-value pairs. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="resource_type" type="string">
      Specifies the type of resource to tag; for a Capacity Reservation Fleet the only valid value is `capacity-reservation-fleet` (the fleet itself). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="tags" type="list(object)">
      The list of tags to apply to the resources identified by the parent tag specification, such as the capacity reservation fleet itself, when creating or managing the fleet. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key of a user-defined tag applied to an EC2 Capacity Reservation Fleet for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The tag value to associate with the Capacity Reservation Fleet, used for identifying, organizing, and managing the fleet through resource grouping and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tenancy" type="string">
  The tenancy of the Capacity Reservation Fleet, which indicates whether instances launched in the fleet run on shared (default) or dedicated hardware. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="total_target_capacity" type="number">
  The total amount of capacity, in units (each instance counts as one unit unless you apply instance type weights), that the Capacity Reservation Fleet aims to reserve across all instance types and Availability Zones. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="capacity_reservation_fleet_id" type="string">
  The unique identifier assigned by AWS to the EC2 Capacity Reservation Fleet. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_ec2_transit_gateway_policy_table_association` associates a real transit gateway attachment with an `aws_ec2_transit_gateway_policy_table`, the resource that actually makes that attachment's traffic subject to the policy table's rules.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own transit gateway policy table association"})

    			TransitGatewayAttachmentId:  "example",
    			TransitGatewayPolicyTableId: "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="transit_gateway_attachment_id" type="string" required>
  The ID of transit gateway attachment. Required.
</ResponseField>

<ResponseField name="transit_gateway_policy_table_id" type="string" required>
  The ID of transit gateway policy table. Required.
</ResponseField>

## Output properties

<ResponseField name="state" type="string">
  The state of the transit gateway policy table association. Computed by AWS after `ship`.
</ResponseField>

`aws_ec2_vpnconcentrator` aggregates up to 100 real, low-bandwidth (under 100 Mbps each) Site-to-Site VPN connections through a single, BGP-only resource attached to an `aws_ec2_transit_gateway`, built for connecting a large number of small remote sites, retail locations, branch offices, rather than provisioning a separate `aws_ec2_vpnconnection` for each one. Launched November 2025.

## Input properties

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the VPN concentrator. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="transit_gateway_id" type="string" required>
  The ID of the transit gateway associated with the VPN concentrator. Required.
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of VPN concentrator. Required.
</ResponseField>

## Output properties

<ResponseField name="transit_gateway_attachment_id" type="string">
  The unique identifier of the transit gateway attachment that is automatically provisioned when the VPN connection is associated with a transit gateway. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpn_concentrator_id" type="string">
  The unique identifier automatically assigned by AWS to the VPN concentrator when it is created, used for referencing the resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_ec2_vpnconnection_route` defines a real static route for a specific CIDR over an `aws_ec2_vpnconnection`, used when the connection isn't using BGP for dynamic route exchange.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpnconnection route"})

    		ubx.Resource(ec2.VpnconnectionRoute, "example", ec2.VpnconnectionRouteConfig{
    			DestinationCidrBlock: "example",
    			VpnConnectionId:      "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx

            destination_cidr_block="example",

        ))
    ```

## Properties

<ResponseField name="destination_cidr_block" type="string" required>
  The CIDR block associated with the local subnet of the customer network. Required.
</ResponseField>

<ResponseField name="vpn_connection_id" type="string" required>
  The ID of the VPN connection. Required.
</ResponseField>

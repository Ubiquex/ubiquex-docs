`aws_ec2_ipampool` is a real, defined group of CIDR ranges within an `aws_ec2_ipam` scope that VPCs and subnets actually allocate their own address space from, rather than a caller assigning CIDRs by hand and risking an overlap.

## Example

    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ipampool"})

    		ubx.Resource(ec2.Ipampool, "example", ec2.IpampoolConfig{
    			AddressFamily:                  "example",
    			IpamScopeId:                    "example",
    			AllocationDefaultNetmaskLength: 1,
    			AllocationMaxNetmaskLength:     1,
    			AllocationMinNetmaskLength:     1,
    			AllocationResourceTags:         []map[string]any{{"key": "example"}},
    			AutoImport:                     true,
    			AwsService:                     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="address_family" type="string" required>
  The address family of the address space in this pool. Either IPv4 or IPv6. Required.
</ResponseField>

<ResponseField name="allocation_default_netmask_length" type="number">
  The default netmask length for allocations made from this pool. This value is used when the netmask length of an allocation isn't specified. Optional.
</ResponseField>

<ResponseField name="allocation_max_netmask_length" type="number">
  The maximum allowed netmask length for allocations made from this pool. Optional.
</ResponseField>

<ResponseField name="allocation_min_netmask_length" type="number">
  The minimum allowed netmask length for allocations made from this pool. Optional.
</ResponseField>

<ResponseField name="allocation_resource_tags" type="list(object)">
  When specified, an allocation will not be allowed unless a resource has a matching set of tags. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that is automatically applied to resources allocated from this IPAM pool, as part of the allocation_resource_tags map. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag that will be applied to resources that receive CIDR allocations from this IPAM pool. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="auto_import" type="bool">
  Determines what to do if IPAM discovers resources that haven't been assigned an allocation. If set to true, an allocation will be made automatically. Optional.
</ResponseField>

<ResponseField name="aws_service" type="string">
  Limits which service in Amazon Web Services that the pool can be used in. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Sets a user-defined descriptive text for the EC2 IPAM pool, used to identify the pool's purpose and displayed in IPAM management views and API responses. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ipam_scope_id" type="string" required>
  The Id of the scope this pool is a part of. Required.
</ResponseField>

<ResponseField name="locale" type="string">
  The region of this pool. If not set, this will default to "None" which will disable non-custom allocations. If the locale has been specified for the source pool, this value must match. Optional.
</ResponseField>

<ResponseField name="provisioned_cidrs" type="list(object)">
  A list of cidrs representing the address space available for allocation in this pool. Optional.
  <Expandable title="properties">
    <ResponseField name="cidr" type="string">
      The CIDR block (in CIDR notation) that is provisioned to the IPAM pool, defining a specific address range added to the pool's managed address space. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="public_ip_source" type="string">
  The IP address source for pools in the public scope. Only used for provisioning IP address CIDRs to pools in the public scope. Default is `byoip`. Optional.
</ResponseField>

<ResponseField name="publicly_advertisable" type="bool">
  Determines whether or not address space from this pool is publicly advertised. Must be set if and only if the pool is IPv6. Optional.
</ResponseField>

<ResponseField name="source_ipam_pool_id" type="string">
  The Id of this pool's source. If set, all space provisioned in this pool must be free space provisioned in the parent pool. Optional.
</ResponseField>

<ResponseField name="source_resource" type="object">
  The resource associated with this pool's space. Depending on the ResourceType, setting a SourceResource changes which space can be provisioned in this pool and which types of resources can receive allocations Optional.
  <Expandable title="properties">
    <ResponseField name="resource_id" type="string" required>
      The resource ID of the source resource (such as a VPC) that provides CIDRs to be allocated to the IPAM pool. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_owner" type="string" required>
      The AWS account ID of the source resource (such as a VPC or another IPAM pool) that this IPAM pool uses as the origin for its CIDR provisioning, required when defining a source resource for the pool. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_region" type="string" required>
      Specifies the AWS region in which the source resource (such as a VPC or subnet) that provides the CIDR block for this IPAM pool resides. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_type" type="string" required>
      The type of the source resource being admitted into the IPAM pool, such as 'vpc' or 'subnet', which is paired with the source resource ID to identify the originating VPC or subnet. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag to associate with the IPAM pool, used for identifying and organizing the pool. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the IPAM Pool. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_arn" type="string">
  The Amazon Resource Name (ARN) of the IPAM this pool is a part of. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_pool_id" type="string">
  Id of the IPAM Pool. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_scope_arn" type="string">
  The Amazon Resource Name (ARN) of the scope this pool is a part of. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_scope_type" type="string">
  Determines whether this scope contains publicly routable space or space for a private network Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="pool_depth" type="number">
  The depth of this pool in the source pool hierarchy. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of this pool. This can be one of the following values: "create-in-progress", "create-complete", "modify-in-progress", "modify-complete", "delete-in-progress", or "delete-complete" Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state_message" type="string">
  An explanation of how the pool arrived at it current state. Computed by AWS after `ship`.
</ResponseField>

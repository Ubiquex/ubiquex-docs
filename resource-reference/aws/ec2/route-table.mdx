## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own table"})

    		ubx.Resource(ec2.RouteTable, "example", ec2.RouteTableConfig{
    			VpcId: "example",
    			Tags:  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the route table. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag key associated with the route table, used to organize and identify the route table within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC. Required.
</ResponseField>

## Output properties

<ResponseField name="route_table_id" type="string">
  The unique identifier of the route table, assigned by AWS (e.g., rtb-xxxxxxxx). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

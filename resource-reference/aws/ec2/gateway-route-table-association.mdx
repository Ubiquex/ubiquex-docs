`aws_ec2_gateway_route_table_association` associates a real `aws_route_table` with an internet gateway or virtual private gateway, the resource that actually controls routing for traffic entering or leaving a VPC through that gateway.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway route table association"})

    		ubx.Resource(ec2.GatewayRouteTableAssociation, "example", ec2.GatewayRouteTableAssociationConfig{
    			GatewayId:    "example",
    			RouteTableId: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="gateway_id" type="string" required>
  The ID of the gateway. Required.
</ResponseField>

<ResponseField name="route_table_id" type="string" required>
  The ID of the route table. Required.
</ResponseField>

## Output properties

<ResponseField name="association_id" type="string">
  The route table association ID. Computed by AWS after `ship`.
</ResponseField>

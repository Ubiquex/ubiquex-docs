`aws_ec2_ipamresource_discovery` finds and tracks real, existing IP-address-consuming resources, VPCs, subnets, Elastic IPs, across an organization's accounts for an `aws_ec2_ipam` to actually monitor, including resources IPAM didn't itself allocate the address space for.

## Input properties

<ResponseField name="description" type="string">
  Specifies a custom description for the IPAM resource discovery, which is used to provide human-readable context or identification for the discovery resource within the AWS EC2 IPAM service. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="operating_regions" type="list(object)">
  The regions Resource Discovery is enabled for. Allows resource discoveries to be created in these regions, as well as enabling monitoring Optional.
  <Expandable title="properties">
    <ResponseField name="region_name" type="string">
      Specifies the AWS Region (e.g., us-east-1) in which the IPAM resource discovery operates. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="organizational_unit_exclusions" type="list(object)">
  A set of organizational unit (OU) exclusions for this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="organizations_entity_path" type="string">
      Defines the AWS Organizations entity path (e.g., 'o-1234567890abcdef0') of an organizational unit to exclude from IPAM resource discovery, preventing resources in that OU from being discovered. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">

`aws_ec2_transit_gateway_multicast_domain_association` associates a real VPC attachment and subnet with an `aws_ec2_transit_gateway_multicast_domain`, the resource that actually makes that subnet's resources eligible to send or receive multicast traffic through the domain.

## Input properties

<ResponseField name="subnet_id" type="string" required>
  The IDs of the subnets to associate with the transit gateway multicast domain. Required.
</ResponseField>

<ResponseField name="transit_gateway_attachment_id" type="string" required>
  The ID of the transit gateway attachment. Required.
</ResponseField>

<ResponseField name="transit_gateway_multicast_domain_id" type="string" required>
  The ID of the transit gateway multicast domain. Required.
</ResponseField>

## Output properties

<ResponseField name="resource_id" type="string">
  The ID of the resource. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of resource, for example a VPC attachment. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the subnet association. Computed by AWS after `ship`.
</ResponseField>

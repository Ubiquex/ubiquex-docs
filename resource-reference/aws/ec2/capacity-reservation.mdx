`aws_ec2_capacity_reservation` reserves real EC2 capacity for a specific instance type and Availability Zone, guaranteeing it's available when needed regardless of what else is running in that zone, independent of any particular Reserved Instance or Savings Plan billing commitment.

## Input properties

<ResponseField name="availability_zone" type="string">
  The Availability Zone where the capacity reservation is created, used to reserve compute capacity in that specific zone for EC2 instances. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="availability_zone_id" type="string">
  Specifies the ID of the Availability Zone (such as use1-az1) in which to create the Capacity Reservation, serving as an alternative to specifying the Availability Zone by name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ebs_optimized" type="bool">
  Indicates whether the capacity reservation is EBS-optimized, which provides dedicated throughput for Amazon EBS I/O. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="end_date" type="string">
  The date and time (in ISO 8601 format) when the Capacity Reservation expires, after which the reserved capacity is released and any instances running in the reservation are automatically stopped or terminated. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="end_date_type" type="string">
  Determines whether the Capacity Reservation has a specific end date/time (limited) or persists indefinitely (unlimited). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ephemeral_storage" type="bool">
  A Boolean value indicating whether the Capacity Reservation supports instances that use ephemeral (instance store) storage. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_count" type="number" required>
  The number of instances for which to reserve capacity in the Capacity Reservation. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_match_criteria" type="string">
  Determines how the capacity reservation matches instances: 'open' allows any matching instance to use the reservation automatically, while 'targeted' requires instances to explicitly specify the reservation ID to use it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_platform" type="string" required>
  Specifies the operating system platform (e.g., Linux/UNIX, Windows, Red Hat Enterprise Linux, SUSE Linux) that the capacity reservation will support, matching the platform of the AMI used to launch instances. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  The EC2 instance type for which to reserve capacity, such as m5.large or c5.xlarge. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="out_post_arn" type="string">
  The Amazon Resource Name (ARN) of the Outpost on which to create the Capacity Reservation. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="placement_group_arn" type="string">
  The ARN of the cluster placement group in which to create the capacity reservation. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

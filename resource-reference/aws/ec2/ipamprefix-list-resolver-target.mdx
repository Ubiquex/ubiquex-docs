`aws_ec2_ipamprefix_list_resolver_target` is the real, actual association between a specific customer-managed prefix list and an `aws_ec2_ipamprefix_list_resolver`, the resolver's selected CIDRs have nowhere to actually be synchronized to without one.

## Input properties

<ResponseField name="desired_version" type="number">
  The desired version of the Prefix List Resolver that this Target should synchronize with. Optional.
</ResponseField>

<ResponseField name="ipam_prefix_list_resolver_id" type="string" required>
  The Id of the IPAM Prefix List Resolver associated with this Target. Required.
</ResponseField>

<ResponseField name="prefix_list_id" type="string" required>
  The Id of the Managed Prefix List. Required.
</ResponseField>

<ResponseField name="prefix_list_region" type="string" required>
  The region that the Managed Prefix List is located in. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag assigned to the IPAM prefix list resolver target, used for organizing and managing the resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="track_latest_version" type="bool" required>
  Indicates whether this Target automatically tracks the latest version of the Prefix List Resolver. Required.
</ResponseField>

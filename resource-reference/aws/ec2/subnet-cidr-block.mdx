`aws_ec2_subnet_cidr_block` associates a real, additional CIDR block, most commonly an IPv6 range, with an `aws_subnet` beyond the one it was originally created with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own subnet cidr block"})

    		ubx.Resource(ec2.SubnetCidrBlock, "ci-runner", ec2.SubnetCidrBlockConfig{
    			SubnetId:          "example",
    			Ipv6CidrBlock:     "example",
    			Ipv6IpamPoolId:    "example",
    			Ipv6NetmaskLength: 1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="ipv6_cidr_block" type="string">
  The IPv6 network range for the subnet, in CIDR notation. The subnet size must use a /64 prefix length Optional.
</ResponseField>

<ResponseField name="ipv6_ipam_pool_id" type="string">
  The ID of an IPv6 Amazon VPC IP Address Manager (IPAM) pool from which to allocate, to get the subnet's CIDR Optional.
</ResponseField>

<ResponseField name="ipv6_netmask_length" type="number">
  The netmask length of the IPv6 CIDR to allocate to the subnet from an IPAM pool Optional.
</ResponseField>

<ResponseField name="subnet_id" type="string" required>
  The ID of the subnet Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Information about the IPv6 association. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ip_source" type="string">
  The IP Source of an IPv6 Subnet CIDR Block. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipv6_address_attribute" type="string">
  The value denoting whether an IPv6 Subnet CIDR Block is public or private. Computed by AWS after `ship`.
</ResponseField>

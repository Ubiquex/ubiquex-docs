`aws_ec2_dhcpoptions` defines the real DNS servers, domain name, and NTP servers that EC2 instances in an associated VPC receive automatically through DHCP, rather than every instance requiring manual network configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dhcpoptions"})

    		ubx.Resource(ec2.Dhcpoptions, "example", ec2.DhcpoptionsConfig{
    			DomainName:                    "example-domain-name",
    			DomainNameServers:             []string{"example"},
    			Ipv6AddressPreferredLeaseTime: 1,
    			NetbiosNameServers:            []string{"example"},
    			NetbiosNodeType:               1,
    			NtpServers:                    []string{"example"},
    			Tags:                          []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="domain_name" type="string">
  This value is used to complete unqualified DNS hostnames. Optional.
</ResponseField>

<ResponseField name="domain_name_servers" type="list(string)">
  The IPv4 addresses of up to four domain name servers, or AmazonProvidedDNS. Optional.
</ResponseField>

<ResponseField name="ipv6_address_preferred_lease_time" type="number">
  The preferred Lease Time for ipV6 address in seconds. Optional.
</ResponseField>

<ResponseField name="netbios_name_servers" type="list(string)">
  The IPv4 addresses of up to four NetBIOS name servers. Optional.
</ResponseField>

<ResponseField name="netbios_node_type" type="number">
  The NetBIOS node type (1, 2, 4, or 8). Optional.
</ResponseField>

<ResponseField name="ntp_servers" type="list(string)">
  The IPv4 addresses of up to four Network Time Protocol (NTP) servers. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the DHCP options set. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag assigned to the DHCP options set, used to identify and organize the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a user-defined tag attached to the DHCP options set, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="dhcp_options_id" type="string">
  The unique identifier (DHCP options ID) that AWS assigns to the DHCP options set when it is created, and which is used to associate the set with a VPC or subnet. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_ec2_traffic_mirror_session` is the real, actual mirroring in progress, pairing a source network interface with an `aws_ec2_traffic_mirror_filter` and an `aws_ec2_traffic_mirror_target` the filtered traffic actually gets sent to.

## Input properties

<ResponseField name="description" type="string">
  The description of the Traffic Mirror session. Optional.
</ResponseField>

<ResponseField name="network_interface_id" type="string" required>
  The ID of the source network interface. Required.
</ResponseField>

<ResponseField name="owner_id" type="string">
  The ID of the account that owns the Traffic Mirror session. Optional.
</ResponseField>

<ResponseField name="packet_length" type="number">
  The number of bytes in each packet to mirror. Optional.
</ResponseField>

<ResponseField name="session_number" type="number" required>
  The session number determines the order in which sessions are evaluated when an interface is used by multiple sessions. The first session with a matching filter is the one that mirrors the packets. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags assigned to the Traffic Mirror session. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag key attached to the EC2 Traffic Mirror Session, which you can use to organize, identify, and manage the resource within your AWS environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="traffic_mirror_filter_id" type="string" required>
  The ID of a Traffic Mirror filter. Required.
</ResponseField>

<ResponseField name="traffic_mirror_target_id" type="string" required>
  The ID of a Traffic Mirror target. Required.
</ResponseField>

<ResponseField name="virtual_network_id" type="number">
  The VXLAN ID for the Traffic Mirror session. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of a Traffic Mirror session. Computed by AWS after `ship`.

`aws_ec2_ipam` is the real, top-level IP Address Manager resource, planning, tracking, and monitoring IP address usage across an AWS organization's accounts and Regions from one place rather than each account managing its own address space independently.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ipam"})

    		ubx.Resource(ec2.Ipam, "example", ec2.IpamConfig{
    			DefaultResourceDiscoveryOrganizationalUnitExclusions: []map[string]any{{"organizations_entity_path": "example"}},
    			Description:      "Managed by ubx.",
    			EnablePrivateGua: true,
    			MeteredAccount:   "example",
    			OperatingRegions: []map[string]any{{"region_name": "example-region-name"}},
    			Tags:             []map[string]any{{"key": "example"}},
    			Tier:             "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="default_resource_discovery_organizational_unit_exclusions" type="list(object)">
  A set of organizational unit (OU) exclusions for the default resource discovery, created with this IPAM. Optional.
  <Expandable title="properties">
    <ResponseField name="organizations_entity_path" type="string">
      Sets the AWS Organizations entity path (the OU path, e.g., 'ou-1234-abcdefgh') for an organizational unit to exclude from the IPAM default resource discovery, preventing resources in that OU from being automatically discovered. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A user-specified, free-form text description of the IP address manager (IPAM) used to identify it in the AWS console and APIs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_private_gua" type="bool">
  Enable provisioning of GUA space in private pools. Optional.
</ResponseField>

<ResponseField name="metered_account" type="string">
  A metered account is an account that is charged for active IP addresses managed in IPAM Optional.
</ResponseField>

<ResponseField name="operating_regions" type="list(object)">
  The regions IPAM is enabled for. Allows pools to be created in these regions, as well as enabling monitoring Optional.
  <Expandable title="properties">
    <ResponseField name="region_name" type="string">
      The name of the AWS Region in which the IPAM operates, defining one of the operating regions for the IPAM. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to the EC2 IPAM resource, used to categorize or identify the IPAM with custom metadata (e.g., 'Name' or 'Environment'). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a user-defined tag key assigned to the EC2 IPAM resource for organizational or management purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tier" type="string">
  The tier of the IPAM. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="default_resource_discovery_association_id" type="string">
  The Id of the default association to the default resource discovery, created with this IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="default_resource_discovery_id" type="string">
  The Id of the default resource discovery, created with this IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_id" type="string">
  Id of the IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="private_default_scope_id" type="string">
  The Id of the default scope for publicly routable IP space, created with this IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="public_default_scope_id" type="string">
  The Id of the default scope for publicly routable IP space, created with this IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_discovery_association_count" type="number">
  The count of resource discoveries associated with this IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="scope_count" type="number">
  The number of scopes that currently exist in this IPAM. Computed by AWS after `ship`.
</ResponseField>

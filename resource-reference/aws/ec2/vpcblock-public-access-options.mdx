`aws_ec2_vpcblock_public_access_options` sets a real, account- or VPC-level default for blocking internet access to resources in a VPC, the account-wide counterpart to an individual `aws_ec2_vpcblock_public_access_exclusion`'s own opt-out.

## Input properties

<ResponseField name="internet_gateway_block_mode" type="string" required>
  The desired Block Public Access mode for Internet Gateways in your account. We do not allow to create in a off mode as this is the default value Required.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The identifier for the specified AWS account. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="exclusions_allowed" type="string">
  Determines if exclusions are allowed. If you have enabled VPC BPA at the Organization level, exclusions may be not-allowed. Otherwise, they are allowed. Computed by AWS after `ship`.
</ResponseField>

`aws_ec2_ipamresource_discovery_association` is the real, actual link between an `aws_ec2_ipamresource_discovery` and the specific `aws_ec2_ipam` it feeds discovered resource data into, needed since a resource discovery can in principle serve more than one IPAM.

## Example

    ```go

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ipamresource discovery association"})

    		ubx.Resource(ec2.IpamresourceDiscoveryAssociation, "example", ec2.IpamresourceDiscoveryAssociationConfig{
    			IpamId:                  "example",
    			IpamResourceDiscoveryId: "example",
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="ipam_id" type="string" required>
  The Id of the IPAM this Resource Discovery is associated to. Required.
</ResponseField>

<ResponseField name="ipam_resource_discovery_id" type="string" required>
  The Amazon Resource Name (ARN) of the IPAM Resource Discovery Association. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the IPAM resource discovery association, used to organize and identify the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a tag key attached to the IPAM resource discovery association, used to organize and identify the association for purposes like cost allocation and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="ipam_arn" type="string">
  Arn of the IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_region" type="string">
  The home region of the IPAM. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_resource_discovery_association_arn" type="string">
  The Amazon Resource Name (ARN) of the resource discovery association is a part of. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipam_resource_discovery_association_id" type="string">
  Id of the IPAM Resource Discovery Association. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="is_default" type="bool">
  If the Resource Discovery Association exists due as part of CreateIpam. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="owner_id" type="string">
  The AWS Account ID for the account where the shared IPAM exists. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="resource_discovery_status" type="string">
  The status of the resource discovery. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The operational state of the Resource Discovery Association. Related to Create/Delete activities. Computed by AWS after `ship`.
</ResponseField>

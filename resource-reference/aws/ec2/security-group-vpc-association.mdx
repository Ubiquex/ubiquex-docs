`aws_ec2_security_group_vpc_association` shares an existing security group across additional VPCs in the same Region, a real, direct alternative to recreating the same rule set in every VPC that needs it.

## Input properties

<ResponseField name="group_id" type="string" required>
  The group ID of the specified security group. Required.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC in the security group vpc association. Required.
</ResponseField>

## Output properties

<ResponseField name="state" type="string">
  The current state of the security group's association with the VPC, which can be one of 'associating', 'associated', 'association-failed', 'disassociating', or 'disassociated'. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="state_reason" type="string">
  The reason for the state of the security group vpc association. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_owner_id" type="string">
  The owner of the VPC in the security group vpc association. Computed by AWS after `ship`.
</ResponseField>

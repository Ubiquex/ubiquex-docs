`aws_ec2_transit_gateway_vpc_attachment` is the real, specific `aws_ec2_transit_gateway_attachment` type connecting a VPC to an `aws_ec2_transit_gateway`, the most common way traffic actually reaches a transit gateway from inside a VPC.

## Input properties

<ResponseField name="add_subnet_ids" type="list(string)">
  Specifies a list of subnet IDs to add to the transit gateway VPC attachment during an update, expanding the set of subnets used by the attachment for routing traffic. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="options" type="object">
  The options for the transit gateway vpc attachment. Optional.
  <Expandable title="properties">
    <ResponseField name="appliance_mode_support" type="string">
      Indicates whether to enable Ipv6 Support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
    <ResponseField name="dns_support" type="string">
      Indicates whether to enable DNS Support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
    <ResponseField name="ipv6_support" type="string">
      Indicates whether to enable Ipv6 Support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
    <ResponseField name="security_group_referencing_support" type="string">
      Indicates whether to enable Security Group referencing support for Vpc Attachment. Valid values: enable | disable Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="remove_subnet_ids" type="list(string)">
  Specifies the list of subnet IDs to remove from the transit gateway VPC attachment during an update, enabling you to detach specific subnets from the attachment without recreating the resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  The IDs of the subnets in the VPC that the transit gateway attachment routes traffic to and from, with at least one subnet per Availability Zone used by the attachment. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies one or more tags to apply to the transit gateway VPC attachment, with each tag consisting of a key and an optional value. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the EC2 Transit Gateway VPC Attachment, used for adding metadata like 'Name' or 'Environment' to identify and manage the attachment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag on the EC2 Transit Gateway VPC Attachment, used for metadata, cost allocation, and IAM resource-level access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="transit_gateway_id" type="string" required>
  The ID of the transit gateway to which the VPC is attached, creating a VPC attachment in that transit gateway. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC to attach to the transit gateway, which must be in the same AWS account and region as the transit gateway. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The AWS-assigned unique identifier for the transit gateway VPC attachment (e.g., tgw-attach-...). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_ec2_security_group_ingress` adds a real inbound rule to an `aws_security_group`, the resource that actually grants a specific source, port, and protocol permission to reach resources protected by that group.

## Input properties

<ResponseField name="cidr_ip" type="string">
  The IPv4 ranges Optional.
</ResponseField>

<ResponseField name="cidr_ipv6" type="string">
  [VPC only] The IPv6 ranges Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Updates the description of an ingress (inbound) security group rule. You can replace an existing description, or add a description to a rule that did not have one previously Optional.
</ResponseField>

<ResponseField name="from_port" type="number">
  The start of port range for the TCP and UDP protocols, or an ICMP/ICMPv6 type number. A value of -1 indicates all ICMP/ICMPv6 types. If you specify all ICMP/ICMPv6 types, you must specify all codes. Use this for ICMP and any protocol that uses ports. Optional.
</ResponseField>

<ResponseField name="group_id" type="string">
  The ID of the security group. You must specify either the security group ID or the security group name in the request. For security groups in a nondefault VPC, you must specify the security group ID. You must specify the GroupName property or the GroupId property. For security groups that are in a VPC, you must use the GroupId property. Optional.
</ResponseField>

<ResponseField name="group_name" type="string">
  The name of the security group. Optional.
</ResponseField>

<ResponseField name="ip_protocol" type="string" required>
  The IP protocol name (tcp, udp, icmp, icmpv6) or number (see Protocol Numbers). [VPC only] Use -1 to specify all protocols. When authorizing security group rules, specifying -1 or a protocol number other than tcp, udp, icmp, or icmpv6 allows traffic on all ports, regardless of any port range you specify. For tcp, udp, and icmp, you must specify a port range. For icmpv6, the port range is optional; if you omit the port range, traffic for all types and codes is allowed. Required.
</ResponseField>

<ResponseField name="source_prefix_list_id" type="string">
  [EC2-VPC only] The ID of a prefix list. Optional.
</ResponseField>

<ResponseField name="source_security_group_id" type="string">
  The ID of the security group. You must specify either the security group ID or the security group name. For security groups in a nondefault VPC, you must specify the security group ID. Optional.
</ResponseField>

<ResponseField name="source_security_group_name" type="string">
  [EC2-Classic, default VPC] The name of the source security group. You must specify the GroupName property or the GroupId property. For security groups that are in a VPC, you must use the GroupId property. Optional.
</ResponseField>

<ResponseField name="source_security_group_owner_id" type="string">
  [nondefault VPC] The AWS account ID that owns the source security group. You can't specify this property with an IP address range. If you specify SourceSecurityGroupName or SourceSecurityGroupId and that security group is owned by a different account than the account creating the stack, you must specify the SourceSecurityGroupOwnerId; otherwise, this property is optional. Optional.
</ResponseField>

<ResponseField name="to_port" type="number">
  The end of port range for the TCP and UDP protocols, or an ICMP/ICMPv6 code. A value of -1 indicates all ICMP/ICMPv6 codes for the specified ICMP type. If you specify all ICMP/ICMPv6 types, you must specify all codes. Use this for ICMP and any protocol that uses ports. Optional.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The Security Group Rule Id Computed by AWS after `ship`.
</ResponseField>

`aws_ec2_transit_gateway_policy_table` routes traffic on an `aws_ec2_transit_gateway` by matching real packet attributes, not just destination CIDR the way an `aws_ec2_transit_gateway_route_table` does, policy-based routing for cases where source, protocol, or port need to influence the path.

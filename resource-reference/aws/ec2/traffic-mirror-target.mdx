`aws_ec2_traffic_mirror_target` is the real destination, a network interface, a Network Load Balancer, that an `aws_ec2_traffic_mirror_session`'s mirrored, filtered traffic actually gets delivered to for analysis by an intrusion-detection or packet-inspection tool.

## Input properties

<ResponseField name="description" type="string">
  The description of the Traffic Mirror target. Optional.
</ResponseField>

<ResponseField name="gateway_load_balancer_endpoint_id" type="string">
  The ID of the Gateway Load Balancer endpoint. Optional.
</ResponseField>

<ResponseField name="network_interface_id" type="string">
  The network interface ID that is associated with the target. Optional.
</ResponseField>

<ResponseField name="network_load_balancer_arn" type="string">
  The Amazon Resource Name (ARN) of the Network Load Balancer that is associated with the target. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

`aws_ec2_local_gateway_route` defines a real route in an `aws_ec2_local_gateway_route_table`, directing traffic for a specific CIDR to an Outposts local gateway rather than back into the parent AWS Region.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own local gateway route"})

    		ubx.Resource(ec2.LocalGatewayRoute, "ci-runner", ec2.LocalGatewayRouteConfig{
    			DestinationCidrBlock:                "example",
    			LocalGatewayRouteTableId:            "example",
    			LocalGatewayVirtualInterfaceGroupId: "example",
    			NetworkInterfaceId:                  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="destination_cidr_block" type="string">
  The CIDR block used for destination matches. Optional.
</ResponseField>

<ResponseField name="local_gateway_route_table_id" type="string">
  The ID of the local gateway route table. Optional.
</ResponseField>

<ResponseField name="local_gateway_virtual_interface_group_id" type="string">
  The ID of the virtual interface group. Optional.
</ResponseField>

<ResponseField name="network_interface_id" type="string">
  The ID of the network interface. Optional.
</ResponseField>

## Output properties

<ResponseField name="state" type="string">
  The state of the route. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type" type="string">
  The route type. Computed by AWS after `ship`.
</ResponseField>

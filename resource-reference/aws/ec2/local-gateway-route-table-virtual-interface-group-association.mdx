`aws_ec2_local_gateway_route_table_virtual_interface_group_association` is the real, actual link between an `aws_ec2_local_gateway_route_table` and an `aws_ec2_local_gateway_virtual_interface_group`, determining which physical interfaces that route table's routes apply across.

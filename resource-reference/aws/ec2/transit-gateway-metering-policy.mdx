`aws_ec2_transit_gateway_metering_policy` creates a real, named container of `aws_ec2_transit_gateway_metering_policy_entry` rules on an `aws_ec2_transit_gateway`, tracking data transfer for cost allocation or chargeback across the attachments it applies to.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own transit gateway metering policy"})

    		ubx.Resource(ec2.TransitGatewayMeteringPolicy, "example", ec2.TransitGatewayMeteringPolicyConfig{
    			TransitGatewayId:       "example",
    			MiddleboxAttachmentIds: []string{"example"},
    			Tags:                   []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="middlebox_attachment_ids" type="list(string)">
  Middle box attachment Ids Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.

    <ResponseField name="key" type="string">

  The Id of transit gateway Required.

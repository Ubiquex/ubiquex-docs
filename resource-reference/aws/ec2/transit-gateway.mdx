`aws_ec2_transit_gateway` is a real, central hub that VPCs, VPN connections, and Direct Connect gateways attach to, letting traffic route between all of them through one managed device instead of a full mesh of individual peering connections.

## Input properties

<ResponseField name="amazon_side_asn" type="number">
  The private Autonomous System Number (ASN) for the Amazon side of a BGP session, used when the transit gateway is attached to a Direct Connect gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="association_default_route_table_id" type="string">
  The ID of the default route table to which new attachments (such as VPCs, VPN connections) are automatically associated when attached to the transit gateway. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="auto_accept_shared_attachments" type="string">
  Indicates whether attachment requests from other accounts that share the transit gateway are automatically accepted (enable) or require manual acceptance (disable). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_route_table_association" type="string">
  Controls whether transit gateway attachments are automatically associated with the transit gateway's default route table, accepting 'enable' or 'disable', with a default of 'enable'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="default_route_table_propagation" type="string">
  The ID of the default route table to which all new attachments propagate routes. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Optional.
</ResponseField>

<ResponseField name="dns_support" type="string">
  Indicates whether to enable or disable DNS support for the transit gateway, with valid values being 'enable' (default) or 'disable'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="encryption_support" type="string">
  Optional.
</ResponseField>

<ResponseField name="multicast_support" type="string">
  Indicates whether multicast support is enabled for the transit gateway, with valid values 'enable' or 'disable' and defaulting to disabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="propagation_default_route_table_id" type="string">
  The propagation_default_route_table_id is the ID of the default route table that is automatically created by the transit gateway and used to propagate routes from attached resources when DefaultRouteTablePropagation is enabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_group_referencing_support" type="string">
  Controls whether the transit gateway supports security group referencing, which allows VPC attachments to reference security groups in their route tables; valid values are 'enable' (default) or 'disable'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Attaches the specified tags to the EC2 Transit Gateway, which are key-value pairs used for identification and cost allocation. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Defines the key of a tag applied to the transit gateway, allowing you to categorize and manage the resource with custom metadata. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the user-defined value portion of a tag attached to the EC2 Transit Gateway, allowing you to categorize or identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="transit_gateway_cidr_blocks" type="list(string)">
  Specifies the IPv4 CIDR blocks that the transit gateway uses as its internal network range, enabling it to route traffic without conflicting with the CIDRs of attached VPCs and on-premises networks. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpn_ecmp_support" type="string">
  Indicates whether Equal Cost Multipath (ECMP) routing is enabled for VPN connections attached to this transit gateway, accepting values 'enable' or 'disable' (default 'enable'). Optional. **(AI-inferred)**
</ResponseField>

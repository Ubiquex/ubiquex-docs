`aws_subnet` creates a real subnet within a VPC, a range of IP addresses in a single Availability Zone that other resources, instances, load balancers, RDS instances, are actually launched into.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ec2"})

    		ubx.Resource(ec2.Subnet, "example", ec2.SubnetConfig{
    			VpcId:                       "example",
    			AssignIpv6AddressOnCreation: true,
    			AvailabilityZone:            "example",
    			AvailabilityZoneId:          "example",
    			CidrBlock:                   "example",
    			EnableDns64:                 true,
    			EnableLniAtDeviceIndex:      1,
    			Ipv4IpamPoolId:              "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="assign_ipv6_address_on_creation" type="bool">
  Indicates whether a network interface created in this subnet receives an IPv6 address. The default value is ``false``. If you specify ``AssignIpv6AddressOnCreation``, you must also specify an IPv6 CIDR block. Optional.
</ResponseField>

<ResponseField name="availability_zone" type="string">
  The Availability Zone of the subnet. If you update this property, you must also update the ``CidrBlock`` property. Optional.
</ResponseField>

<ResponseField name="availability_zone_id" type="string">
  The AZ ID of the subnet. Optional.
</ResponseField>

<ResponseField name="cidr_block" type="string">
  The IPv4 CIDR block assigned to the subnet. If you update this property, we create a new subnet, and then delete the existing one. Optional.
</ResponseField>

<ResponseField name="enable_dns64" type="bool">
  Indicates whether DNS queries made to the Amazon-provided DNS Resolver in this subnet should return synthetic IPv6 addresses for IPv4-only destinations. You must first configure a NAT gateway in a public subnet (separate from the subnet containing the IPv6-only workloads). For example, the subnet containing the NAT gateway should have a ``0.0.0.0/0`` route pointing to the internet gateway. For more information, see [Configure DNS64 and NAT64](https://docs.aws.amazon.com/vpc/latest/userguide/nat-gateway-nat64-dns64.html#nat-gateway-nat64-dns64-walkthrough) in the *User Guide*. Optional.
</ResponseField>

<ResponseField name="enable_lni_at_device_index" type="number">
  Indicates the device position for local network interfaces in this subnet. For example, ``1`` indicates local network interfaces in this subnet are the secondary network interface (eth1). Optional.
</ResponseField>

<ResponseField name="ipv4_ipam_pool_id" type="string">
  An IPv4 IPAM pool ID for the subnet. Optional.
</ResponseField>

<ResponseField name="ipv4_netmask_length" type="number">
  An IPv4 netmask length for the subnet. Optional.
</ResponseField>

<ResponseField name="ipv6_cidr_block" type="string">
  The IPv6 CIDR block. If you specify ``AssignIpv6AddressOnCreation``, you must also specify an IPv6 CIDR block. Optional.
</ResponseField>

<ResponseField name="ipv6_ipam_pool_id" type="string">
  An IPv6 IPAM pool ID for the subnet. Optional.
</ResponseField>

<ResponseField name="ipv6_native" type="bool">
  Indicates whether this is an IPv6 only subnet. For more information, see [Subnet basics](https://docs.aws.amazon.com/vpc/latest/userguide/VPC_Subnets.html#subnet-basics) in the *User Guide*. Optional.
</ResponseField>

<ResponseField name="ipv6_netmask_length" type="number">
  An IPv6 netmask length for the subnet. Optional.
</ResponseField>

<ResponseField name="map_public_ip_on_launch" type="bool">
  Indicates whether instances launched in this subnet receive a public IPv4 address. The default value is ``false``. AWS charges for all public IPv4 addresses, including public IPv4 addresses associated with running instances and Elastic IP addresses. For more information, see the *Public IPv4 Address* tab on the [VPC pricing page](https://docs.aws.amazon.com/vpc/pricing/). Optional.
</ResponseField>

<ResponseField name="outpost_arn" type="string">
  The Amazon Resource Name (ARN) of the Outpost. Optional.
</ResponseField>

<ResponseField name="private_dns_name_options_on_launch" type="object">
  The hostname type for EC2 instances launched into this subnet and how DNS A and AAAA record queries to the instances should be handled. For more information, see [Amazon EC2 instance hostname types](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-instance-naming.html) in the *User Guide*. Available options: + EnableResourceNameDnsAAAARecord (true | false) + EnableResourceNameDnsARecord (true | false) + HostnameType (ip-name | resource-name) Optional.
  <Expandable title="properties">
    <ResponseField name="enable_resource_name_dns_aaaarecord" type="bool">
      Indicates whether to enable Resource Name DNS AAAA (IPv6) record for instances launched in this subnet, affecting how instance hostnames resolve in the VPC's private DNS. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enable_resource_name_dns_arecord" type="bool">
      Specifies whether to enable the automatic creation of an A record for the resource-based name (private DNS name) of instances launched in this subnet, mapping that name to the instance's private IPv4 address within the VPC's private hosted zone. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="hostname_type" type="string">
      Specifies the type of hostname (ip-name or resource-name) that EC2 instances launched in this subnet will receive for their private DNS hostnames, as part of the subnet's PrivateDnsNameOptionsOnLaunch configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the subnet. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The case-sensitive key of a tag applied to the subnet, used to identify and categorize the resource for cost allocation, access control, and operational management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC the subnet is in. If you update this property, you must also update the ``CidrBlock`` property. Required.
</ResponseField>

## Output properties

<ResponseField name="block_public_access_states" type="object">
  The effective Block Public Access configuration for the subnet, reporting the current state (`allow` or `block`) for both inbound and outbound traffic via `inbound` and `outbound` keys. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="internet_gateway_block_mode" type="string">
      The mode of VPC BPA. Options here are off, block-bidirectional, block-ingress Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ipv6_cidr_blocks" type="list(string)">
  The list of IPv6 CIDR blocks associated with the subnet, automatically populated by AWS as read-only values. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_acl_association_id" type="string">
  The unique identifier of the network ACL association attached to this subnet, which represents the association between the subnet and its network ACL (either the default or a custom ACL). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_id" type="string">
  The unique identifier assigned by AWS when the subnet is created (e.g., 'subnet-1234567890abcdef0'), which is used to refer to the subnet in other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

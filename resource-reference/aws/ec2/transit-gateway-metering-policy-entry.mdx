`aws_ec2_transit_gateway_metering_policy_entry` defines a real, ordered rule that attributes an `aws_ec2_transit_gateway`'s own metered usage for matching traffic, by attachment type, CIDR, protocol, and port, to a specific AWS account, so cross-account cost allocation for shared transit gateway traffic reflects who actually used it rather than defaulting entirely to the transit gateway owner.

## Input properties

<ResponseField name="destination_cidr_block" type="string">
  The list of IP addresses of the instances receiving traffic from the transit gateway Optional.
</ResponseField>

<ResponseField name="destination_port_range" type="string">
  The list of ports on destination instances receiving traffic from the transit gateway Optional.
</ResponseField>

<ResponseField name="destination_transit_gateway_attachment_id" type="string">
  The ID of the source attachment through which traffic leaves a transit gateway Optional.
</ResponseField>

<ResponseField name="destination_transit_gateway_attachment_type" type="string">
  Optional.
</ResponseField>

<ResponseField name="metered_account" type="string" required>
  The AWS account ID of the account whose traffic traversing the transit gateway is metered under this metering policy entry. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="policy_rule_number" type="number" required>
  The rule number of the metering policy entry Required.
</ResponseField>

<ResponseField name="protocol" type="string">
  The protocol of the traffic Optional.
</ResponseField>

<ResponseField name="source_cidr_block" type="string">
  The list of IP addresses of the instances sending traffic to the transit gateway for which the metering policy entry is applicable Optional.
</ResponseField>

<ResponseField name="source_port_range" type="string">
  The list of ports on source instances sending traffic to the transit gateway Optional.
</ResponseField>

<ResponseField name="source_transit_gateway_attachment_id" type="string">
  The ID of the source attachment through which traffic enters a transit gateway Optional.
</ResponseField>

<ResponseField name="source_transit_gateway_attachment_type" type="string">
  Optional.
</ResponseField>

<ResponseField name="transit_gateway_metering_policy_id" type="string" required>
  The ID of the transit gateway metering policy for which the entry is being created Required.
</ResponseField>

## Output properties

  State of the transit gateway metering policy Computed by AWS after `ship`.

<ResponseField name="update_effective_at" type="string">
  The timestamp at which the latest action performed on the metering policy entry will become effective Computed by AWS after `ship`.

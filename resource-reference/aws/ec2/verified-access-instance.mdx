`aws_ec2_verified_access_instance` is the real, top-level AWS Verified Access resource that `aws_ec2_verified_access_trust_provider`s attach to, evaluating every request against zero-trust policies instead of relying on a traditional VPN for private application access.

## Example

    ```go
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own verified access instance"})

    		ubx.Resource(ec2.VerifiedAccessInstance, "example", ec2.VerifiedAccessInstanceConfig{
    			CidrEndpointsCustomSubDomain:   "example",
    			Description:                    "Managed by ubx.",
    			FipsEnabled:                    true,
    			LoggingConfigurations:          map[string]any{"cloud_watch_logs": map[string]any{"enabled": true}},
    			Tags:                           []map[string]any{{"key": "example"}},
    			VerifiedAccessTrustProviderIds: []string{"example"},
    			VerifiedAccessTrustProviders:   []map[string]any{{"description": "example"}},
    		})
    	}))
    }
    ```

  AWS Verified Access trust providers. Optional.
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      A user-provided free-form text that describes the associated AWS Verified Access trust provider for this Verified Access instance, helping identify its purpose or configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="device_trust_provider_type" type="string">
      Indicates the type of device trust provider (such as Jamf or CrowdStrike) used by this Verified Access trust provider to assess device trust. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="trust_provider_type" type="string">
      Indicates whether the associated Verified Access trust provider is a user trust provider or a device trust provider, thereby determining how the instance evaluates user identity versus device health for access decisions. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="user_trust_provider_type" type="string">
      Specifies the type of the user trust provider (e.g., IAM Identity Center or OIDC) used by the Verified Access instance for user-based authentication. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="verified_access_trust_provider_id" type="string">
      The unique ID of the AWS Verified Access trust provider that is associated with this Verified Access instance as part of its configured trust provider list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

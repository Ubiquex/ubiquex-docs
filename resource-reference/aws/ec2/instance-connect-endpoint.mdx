`aws_ec2_instance_connect_endpoint` lets a caller SSH or RDP into a real EC2 instance in a private subnet, no public IP, no bastion host, no VPN, needed, connecting through the endpoint from the console or CLI instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own instance connect endpoint"})

    		ubx.Resource(ec2.InstanceConnectEndpoint, "example", ec2.InstanceConnectEndpointConfig{
    			SubnetId:         "example",
    			ClientToken:      "example",
    			PreserveClientIp: true,
    			SecurityGroupIds: []string{"example"},
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

</ResponseField>

<ResponseField name="preserve_client_ip" type="bool">
  Indicates whether your client's IP address is preserved as the source when you connect to a resource. Optional.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">

<ResponseField name="subnet_id" type="string" required>

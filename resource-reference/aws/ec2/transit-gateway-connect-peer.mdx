`aws_ec2_transit_gateway_connect_peer` establishes a real BGP peering session over an `aws_ec2_transit_gateway_connect` attachment, the actual routing adjacency an SD-WAN appliance needs beyond the GRE tunnel itself.

## Output properties

<ResponseField name="connect_peer_configuration" type="object">
  The computed configuration of the transit gateway Connect peer, including the tunnel protocol, inside CIDR blocks, the transit gateway and peer addresses, and BGP configuration options. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="bgp_configurations" type="list(object)">
      The BGP configuration details. Optional.
      <Expandable title="properties">
        <ResponseField name="bgp_status" type="string">
          BGP status of the Connect Peer's BGP session, indicating whether the Border Gateway Protocol session is up or down. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="peer_address" type="string">
          The IP address of the BGP peer used for establishing BGP sessions with the Transit Gateway Connect Peer. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="peer_asn" type="number">
          Specifies the autonomous system number (ASN) of the BGP peer for the Connect peer, which is used to configure BGP peering between the transit gateway and the Connect attachment. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="transit_gateway_address" type="string">
          Specifies the IP address on the Transit Gateway side that will be used as the local endpoint for the BGP session with the Connect peer. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="transit_gateway_asn" type="number">
          The autonomous system number (ASN) that the transit gateway uses for the BGP session with the Connect peer. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="inside_cidr_blocks" type="list(string)" required>
      The range of interior BGP peer IP addresses. Required.
    </ResponseField>
    <ResponseField name="peer_address" type="string" required>
      The peer IP address (GRE outer IP address) on the appliance side of the Connect peer. Required.
    </ResponseField>
    <ResponseField name="protocol" type="string">
      The tunnel protocol. Optional.
    </ResponseField>
    <ResponseField name="transit_gateway_address" type="string">
      The Connect peer IP address on the transit gateway side of the tunnel. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="creation_time" type="string">

  The state of the Connect peer. Computed by AWS after `ship`.

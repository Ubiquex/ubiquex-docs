`aws_ec2_network_insights_access_scope` defines a real, broader set of network paths and conditions to evaluate together, going beyond one `aws_ec2_network_insights_path`'s single source-destination pair to check an entire access boundary, everything that should or shouldn't be reachable from the internet, for instance, at once.

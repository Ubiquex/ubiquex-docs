`aws_ec2_vpcblock_public_access_exclusion` exempts a specific real VPC or subnet from the account's own VPC Block Public Access mode, bidirectionally or egress-only, so that one exception doesn't disrupt traffic when block-public-access is turned on account-wide.

</ResponseField>

<ResponseField name="subnet_id" type="string">

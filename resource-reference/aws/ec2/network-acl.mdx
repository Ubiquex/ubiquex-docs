`aws_network_acl` creates a real, stateless network access control list scoped to a VPC, a numbered set of allow/deny rules evaluated in order per subnet, distinct from a security group's stateful, instance-scoped rules.

## Example

    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own network acl"})

    		ubx.Resource(ec2.NetworkAcl, "example", ec2.NetworkAclConfig{
    			VpcId: "example",
    			Tags:  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="tags" type="list(object)">
  The tags for the network ACL. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the network ACL, used to label and organize the resource for identification and management within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag applied to the network ACL, used to assign metadata such as purpose or ownership to the ACL. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC for the network ACL. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The AWS-assigned identifier for the network ACL, which uses the format acl-xxxxxxxx. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_ec2_vpcendpoint_service_permissions` controls which real AWS principals are actually allowed to create an `aws_ec2_vpcendpoint` against an `aws_ec2_vpcendpoint_service`, an allowlist a service owner manages rather than leaving their PrivateLink service open to any account that discovers it.

    			AllowedPrincipals: []string{"example"},
    		})
    	}))
    }

## Properties

<ResponseField name="allowed_principals" type="list(string)">
  Specifies the ARNs of principals (IAM users, roles, or AWS accounts) that are allowed to create interface VPC endpoints to the VPC endpoint service. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_id" type="string" required>
  The ID of the VPC endpoint service to which the permissions are granted. Required. **(AI-inferred)**
</ResponseField>

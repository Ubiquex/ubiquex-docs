`aws_ec2_capacity_manager_data_export` configures a real, scheduled export of EC2 Capacity Manager's own usage data, On-Demand, Spot, and Capacity Reservation metrics across an organization's accounts and Regions, to an S3 bucket. Amazon EC2 Capacity Manager reached general availability October 17, 2025, roughly ten months ago.

## Input properties

<ResponseField name="output_format" type="string" required>
  The format of the exported capacity manager data. Choose 'csv' for comma-separated values or 'parquet' for optimized columnar storage format. Required.
</ResponseField>

<ResponseField name="s3_bucket_name" type="string" required>
  The name of the Amazon S3 bucket where the capacity manager data export will be stored. The bucket must exist and be accessible by EC2 Capacity Manager service. Required.
</ResponseField>

<ResponseField name="s3_bucket_prefix" type="string">
  The prefix for the S3 bucket location where exported files will be placed. If not specified, files will be placed in the root of the bucket. Optional.
</ResponseField>

<ResponseField name="schedule" type="string" required>
  The schedule for the capacity manager data export. Currently supports hourly exports that provide periodic snapshots of capacity manager data. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to the capacity manager data export. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="capacity_manager_data_export_id" type="string">
  The unique identifier of the capacity manager data export. Computed by AWS after `ship`.
</ResponseField>

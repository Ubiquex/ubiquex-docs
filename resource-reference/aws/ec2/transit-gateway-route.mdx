`aws_ec2_transit_gateway_route` defines a real route in an `aws_ec2_transit_gateway`'s route table, directing traffic for a specific CIDR to a chosen attachment, VPC, VPN, Direct Connect, or peering.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own transit gateway route"})

    		ubx.Resource(ec2.TransitGatewayRoute, "example", ec2.TransitGatewayRouteConfig{
    			DestinationCidrBlock:       "example",
    			TransitGatewayRouteTableId: "example",
    			Blackhole:                  true,
    			TransitGatewayAttachmentId: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="blackhole" type="bool">
  Indicates whether to drop traffic that matches this route. Optional.
</ResponseField>

<ResponseField name="destination_cidr_block" type="string" required>
  The CIDR range used for destination matches. Routing decisions are based on the most specific match. Required.
</ResponseField>

<ResponseField name="transit_gateway_attachment_id" type="string">
  The ID of transit gateway attachment. Optional.
</ResponseField>

<ResponseField name="transit_gateway_route_table_id" type="string" required>
  The ID of transit gateway route table. Required.
</ResponseField>

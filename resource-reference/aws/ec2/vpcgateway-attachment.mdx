`aws_ec2_vpcgateway_attachment` attaches a real `aws_internet_gateway` or virtual private gateway to a VPC, the resource that actually connects that gateway's own external network path into the VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpcgateway attachment"})

    		ubx.Resource(ec2.VpcgatewayAttachment, "example", ec2.VpcgatewayAttachmentConfig{
    			VpcId:             "example",
    			InternetGatewayId: "example",
    			VpnGatewayId:      "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="internet_gateway_id" type="string">
  The ID of the internet gateway. You must specify either InternetGatewayId or VpnGatewayId, but not both. Optional.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC. Required.
</ResponseField>

<ResponseField name="vpn_gateway_id" type="string">
  The ID of the virtual private gateway. You must specify either InternetGatewayId or VpnGatewayId, but not both. Optional.
</ResponseField>

## Output properties

<ResponseField name="attachment_type" type="string">
  Used to identify if this resource is an Internet Gateway or Vpn Gateway Attachment Computed by AWS after `ship`.
</ResponseField>

`aws_ec2_transit_gateway_attachment` is the real, general resource connecting a VPC, VPN, Direct Connect gateway, or another transit gateway to an `aws_ec2_transit_gateway`, the actual link every specific attachment type shares the same underlying mechanism for.

## Input properties

<ResponseField name="options" type="object">
  The options for the transit gateway vpc attachment. Optional.
  <Expandable title="properties">
    <ResponseField name="appliance_mode_support" type="string">
      Indicates whether to enable Ipv6 Support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
    <ResponseField name="dns_support" type="string">
      Indicates whether to enable DNS Support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
    <ResponseField name="ipv6_support" type="string">
      Indicates whether to enable Ipv6 Support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
    <ResponseField name="security_group_referencing_support" type="string">
      Indicates whether to enable Security Group referencing support for Vpc Attachment. Valid Values: enable | disable Optional.
    </ResponseField>
  </Expandable>

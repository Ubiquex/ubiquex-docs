`aws_ec2_vpccidr_block` associates a real, additional CIDR block, IPv4 secondary range or IPv6, with an `aws_vpc` beyond the one it was originally created with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpccidr block"})

    		ubx.Resource(ec2.VpccidrBlock, "example", ec2.VpccidrBlockConfig{
    			VpcId:                           "example",
    			AmazonProvidedIpv6CidrBlock:     true,
    			CidrBlock:                       "example",
    			Ipv4IpamPoolId:                  "example",
    			Ipv4NetmaskLength:               1,
    			Ipv6CidrBlock:                   "example",
    			Ipv6CidrBlockNetworkBorderGroup: "example",
    			Ipv6IpamPoolId:                  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="amazon_provided_ipv6_cidr_block" type="bool">
  Requests an Amazon-provided IPv6 CIDR block with a /56 prefix length for the VPC. You cannot specify the range of IPv6 addresses, or the size of the CIDR block. Optional.
</ResponseField>

<ResponseField name="cidr_block" type="string">
  An IPv4 CIDR block to associate with the VPC. Optional.
</ResponseField>

<ResponseField name="ipv4_ipam_pool_id" type="string">
  The ID of the IPv4 IPAM pool to Associate a CIDR from to a VPC. Optional.
</ResponseField>

<ResponseField name="ipv4_netmask_length" type="number">
  The netmask length of the IPv4 CIDR you would like to associate from an Amazon VPC IP Address Manager (IPAM) pool. Optional.
</ResponseField>

<ResponseField name="ipv6_cidr_block" type="string">
  An IPv6 CIDR block from the IPv6 address pool. Optional.
</ResponseField>

<ResponseField name="ipv6_cidr_block_network_border_group" type="string">
  The name of the location from which we advertise the IPV6 CIDR block. Optional.
</ResponseField>

<ResponseField name="ipv6_ipam_pool_id" type="string">
  The ID of the IPv6 IPAM pool to Associate a CIDR from to a VPC. Optional.
</ResponseField>

<ResponseField name="ipv6_netmask_length" type="number">
  The netmask length of the IPv6 CIDR you would like to associate from an Amazon VPC IP Address Manager (IPAM) pool. Optional.
</ResponseField>

<ResponseField name="ipv6_pool" type="string">
  The ID of an IPv6 address pool from which to allocate the IPv6 CIDR block. Optional.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The Id of the VPC associated CIDR Block. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ip_source" type="string">
  The IP Source of an IPv6 VPC CIDR Block. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipv6_address_attribute" type="string">
  The value denoting whether an IPv6 VPC CIDR Block is public or private. Computed by AWS after `ship`.
</ResponseField>

`aws_ec2_client_vpn_authorization_rule` grants a real, specific group of connected users access to a defined network CIDR through an `aws_ec2_client_vpn_endpoint`, without it, a connected client reaches nothing regardless of network association.

## Input properties

<ResponseField name="access_group_id" type="string">
  The ID of the Active Directory group that is allowed access to the network; if omitted, all users in the directory are permitted. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorize_all_groups" type="bool">
  Indicates whether to authorize access to all groups, so when set to true, the rule applies to every Active Directory group, and when false, you must specify target groups via the GroupId field. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_vpn_endpoint_id" type="string" required>
  The ID of the Client VPN endpoint to which this authorization rule applies. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A brief, optional description that identifies the purpose of the Client VPN authorization rule. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_network_cidr" type="string" required>
  The CIDR block of the target network that this authorization rule grants access to for the specified clients or groups. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">

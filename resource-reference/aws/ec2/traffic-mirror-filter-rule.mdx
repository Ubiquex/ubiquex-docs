`aws_ec2_traffic_mirror_filter_rule` is one real, specific accept or reject rule inside an `aws_ec2_traffic_mirror_filter`, the actual, individually addressable rule resource within a filter's broader rule set.

## Input properties

<ResponseField name="description" type="string">
  The description of the Traffic Mirror Filter rule. Optional.
</ResponseField>

<ResponseField name="destination_cidr_block" type="string" required>
  The destination CIDR block to assign to the Traffic Mirror rule. Required.
</ResponseField>

<ResponseField name="destination_port_range" type="object">
  Specifies the range of destination ports that the traffic mirror filter rule applies to, defining the destination port interval for mirroring traffic. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="from_port" type="number" required>
      The first port in the Traffic Mirror port range. Required.
    </ResponseField>
    <ResponseField name="to_port" type="number" required>
      The last port in the Traffic Mirror port range. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="protocol" type="number">
  The number of protocol, for example 17 (UDP), to assign to the Traffic Mirror rule. Optional.
</ResponseField>

<ResponseField name="rule_action" type="string" required>
  The action to take on the filtered traffic. Required.
</ResponseField>

<ResponseField name="rule_number" type="number" required>
  The number of the Traffic Mirror rule. Required.
</ResponseField>

<ResponseField name="source_cidr_block" type="string" required>
  The source CIDR block to assign to the Traffic Mirror Filter rule. Required.
</ResponseField>

<ResponseField name="source_port_range" type="object">
  The range of source ports (from and to) that the traffic mirror filter rule uses to match mirrored traffic based on the packet's source port. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="from_port" type="number" required>
      The first port in the Traffic Mirror port range. Required.
    </ResponseField>
    <ResponseField name="to_port" type="number" required>
      The last port in the Traffic Mirror port range. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the Traffic Mirror Filter rule. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair assigned to the traffic mirror filter rule, used to organize and identify the rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="traffic_direction" type="string" required>
  The type of traffic. Required.
</ResponseField>

<ResponseField name="traffic_mirror_filter_id" type="string" required>
  The ID of the filter that this rule is associated with. Required.
</ResponseField>

## Output properties

<ResponseField name="traffic_mirror_filter_rule_id" type="string">
  The ID of the Traffic Mirror Filter rule. Computed by AWS after `ship`.
</ResponseField>

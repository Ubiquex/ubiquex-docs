`aws_ec2_route_server_endpoint` is a real BGP peering point for VPC Route Server, AWS-managed BGP infrastructure that speaks with third-party routing appliances inside a VPC and dynamically updates the VPC's own route tables, an alternative to static routing for workloads that need dynamic, fault-tolerant routing entirely inside a VPC.

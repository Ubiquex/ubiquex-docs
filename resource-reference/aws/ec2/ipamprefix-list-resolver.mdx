`aws_ec2_ipamprefix_list_resolver` automatically selects real CIDRs out of an `aws_ec2_ipam`'s own advanced-tier address database based on defined matching rules, and keeps a customer-managed prefix list synchronized with the result, so a prefix list used in a security group or route table stays current with IPAM's own data instead of being updated by hand.

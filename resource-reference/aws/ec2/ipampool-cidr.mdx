`aws_ec2_ipampool_cidr` provisions a real CIDR block into an `aws_ec2_ipampool`, the actual address space that instances and subnets can then allocate from within that pool.

## Example

    		})
    	}))
    }

## Input properties

<ResponseField name="cidr" type="string">
  Represents a single IPv4 or IPv6 CIDR Optional.
</ResponseField>

<ResponseField name="ipam_pool_id" type="string" required>
  Id of the IPAM Pool. Required.
</ResponseField>

<ResponseField name="netmask_length" type="number">
  The desired netmask length of the provision. If set, IPAM will choose a block of free space with this size and return the CIDR representing it. Optional.
</ResponseField>

## Output properties

<ResponseField name="ipam_pool_cidr_id" type="string">
  Id of the IPAM Pool Cidr. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  Provisioned state of the cidr. Computed by AWS after `ship`.
</ResponseField>

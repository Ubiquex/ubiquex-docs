`aws_ec2_subnet_route_table_association` is the real, actual link between a subnet and the route table whose routes govern traffic leaving it, a subnet uses its VPC's main route table unless a specific association like this one overrides it.

## Input properties

<ResponseField name="route_table_id" type="string" required>
  The ID of the route table. The physical ID changes when the route table ID is changed. Required.
</ResponseField>

<ResponseField name="subnet_id" type="string" required>
  The ID of the subnet. Required.
</ResponseField>

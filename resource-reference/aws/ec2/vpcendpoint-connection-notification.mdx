`aws_ec2_vpcendpoint_connection_notification` configures a real SNS notification for connection state changes, accept, reject, on an `aws_ec2_vpcendpoint`, most relevant for interface endpoints connecting to a VPC endpoint service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpcendpoint connection notification"})

    		ubx.Resource(ec2.VpcendpointConnectionNotification, "example", ec2.VpcendpointConnectionNotificationConfig{
    			ConnectionEvents:          []string{"example"},
    			ConnectionNotificationArn: "arn:aws:iam::123456789012:policy/example",
    			ServiceId:                 "example",
    			VpcendpointId:             "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="connection_events" type="list(string)" required>
  The endpoint events for which to receive notifications. Required.
</ResponseField>

<ResponseField name="connection_notification_arn" type="string" required>
  The ARN of the SNS topic for the notifications. Required.
</ResponseField>

<ResponseField name="service_id" type="string">
  The ID of the endpoint service. Optional.
</ResponseField>

<ResponseField name="vpcendpoint_id" type="string">
  The ID of the endpoint. Optional.
</ResponseField>

## Output properties

<ResponseField name="vpcendpoint_connection_notification_id" type="string">
  VPC Endpoint Connection ID generated by service Computed by AWS after `ship`.
</ResponseField>

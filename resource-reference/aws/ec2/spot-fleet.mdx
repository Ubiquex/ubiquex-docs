`aws_ec2_spot_fleet` launches and maintains a real target amount of Spot Instance capacity across multiple instance types and Availability Zones, automatically requesting replacement capacity if Spot Instances are interrupted, the Spot-focused predecessor to the more general `aws_ec2_fleet`.

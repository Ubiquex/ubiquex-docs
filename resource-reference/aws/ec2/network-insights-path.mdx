`aws_ec2_network_insights_path` defines a real source and destination for VPC Reachability Analyzer to trace, the actual path definition an `aws_ec2_network_insights_analysis` runs its point-in-time check against.

    	ubx.Main(ubx.Stack("payments", func() {

An endpoint with no target network association has nowhere to actually route connected clients' traffic.

## Input properties

<ResponseField name="availability_zone" type="string">
  The availability zone of the subnet that the Client VPN endpoint is associated with, automatically derived from the specified subnet. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="availability_zone_id" type="string">
  This field contains the unique identifier of the Availability Zone where the target network's subnet resides; it is automatically populated from the associated subnet and cannot be independently set. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="client_vpn_endpoint_id" type="string" required>
  The ID of the Client VPN endpoint to which the target network is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_id" type="string">
  The ID of the subnet to associate with the Client VPN endpoint, enabling the endpoint to route traffic to and from that subnet's network. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique association ID assigned by AWS to the target network (subnet) when it is associated with the Client VPN endpoint. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

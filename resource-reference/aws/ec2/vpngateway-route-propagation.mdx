`aws_ec2_vpngateway_route_propagation` automatically propagates real routes learned over an `aws_ec2_vpngateway`'s BGP session into a specific route table, so a caller doesn't have to add static routes by hand every time the VPN's own advertised routes change.

## Example

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			VpnGatewayId:  "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="route_table_ids" type="list(string)" required>
  The ID of the route table. The routing table must be associated with the same VPC that the virtual private gateway is attached to Required.
</ResponseField>

<ResponseField name="vpn_gateway_id" type="string" required>
  The ID of the virtual private gateway that is attached to a VPC. The virtual private gateway must be attached to the same VPC that the routing tables are associated with Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier for this VPN gateway route propagation resource, formed by joining the route table ID and the VPN gateway ID with a colon (e.g., rtb-12345678:vgw-12345678). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

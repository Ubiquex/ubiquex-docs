`aws_ec2_network_performance_metric_subscription` subscribes an account to real Infrastructure Performance metrics between two specified subregions or an AWS Region and the public internet, published as CloudWatch metrics for capacity planning and troubleshooting network latency and packet loss.

## Properties

<ResponseField name="destination" type="string" required>
  The target Region or Availability Zone for the metric to subscribe to. Required.
</ResponseField>

<ResponseField name="metric" type="string" required>
  The metric type to subscribe to. Required.
</ResponseField>

<ResponseField name="source" type="string" required>
  The starting Region or Availability Zone for metric to subscribe to. Required.
</ResponseField>

<ResponseField name="statistic" type="string" required>
  The statistic to subscribe to. Required.
</ResponseField>

`aws_ec2_ipamscope` partitions an `aws_ec2_ipam`'s address space into a real, distinct pool of CIDRs, public, private, or a caller-defined custom scope, kept separate so address planning for internet-routable and private ranges don't overlap or interfere.

## Input properties

<ResponseField name="description" type="string">
  A user-defined description for the IPAM scope. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="external_authority_configuration" type="object">
  External service configuration to connect your AWS IPAM scope. Optional.
  <Expandable title="properties">
    <ResponseField name="external_resource_identifier" type="string" required>
      Resource identifier of the scope in the external service connecting to your AWS IPAM scope. Required.
    </ResponseField>
    <ResponseField name="ipam_scope_external_authority_type" type="string" required>
      An external service connecting to your AWS IPAM scope. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ipam_id" type="string" required>
  The Id of the IPAM this scope is a part of. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="arn" type="string">

</ResponseField>

<ResponseField name="ipam_arn" type="string">

</ResponseField>

`aws_ec2_client_vpn_route` adds a real, specific route to an `aws_ec2_client_vpn_endpoint`'s own route table, directing connected clients' traffic for a given destination, beyond the routes that get created automatically from its network associations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own client vpn route"})

    		ubx.Resource(ec2.ClientVpnRoute, "example", ec2.ClientVpnRouteConfig{
    			ClientVpnEndpointId:  "example",
    			DestinationCidrBlock: "example",
    			Description:          "Managed by ubx.",
    			TargetVpcSubnetId:    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="client_vpn_endpoint_id" type="string" required>
  The ID of the Client VPN endpoint to which this route is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A user-defined description for the route, often used to identify its purpose or destination in the Client VPN endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="destination_cidr_block" type="string" required>
  The IPv4 CIDR block (e.g., 10.0.0.0/16) of the destination network that this Client VPN route forwards traffic through the VPN tunnel. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_vpc_subnet_id" type="string">
  The ID of the VPC subnet to which the Client VPN endpoint routes traffic for the destination CIDR block. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The computed unique identifier for the Client VPN route, formatted as the client VPN endpoint ID, destination CIDR block, and target subnet ID separated by colons. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_ec2_verified_access_group` collects `aws_ec2_verified_access_endpoint`s with real, similar security requirements under one shared Verified Access policy, so a caller manages one policy per group of applications instead of one per individual endpoint.

## Input properties

<ResponseField name="description" type="string">
  A description for the AWS Verified Access group. Optional.
</ResponseField>

<ResponseField name="policy_document" type="string">
  The AWS Verified Access policy document. Optional.
</ResponseField>

<ResponseField name="policy_enabled" type="bool">
  The status of the Verified Access policy. Optional.
</ResponseField>

<ResponseField name="sse_specification" type="object">
  The configuration options for customer provided KMS encryption. Optional.
  <Expandable title="properties">
    <ResponseField name="customer_managed_key_enabled" type="bool">
      Whether to encrypt the policy with the provided key or disable encryption Optional.
    </ResponseField>
    <ResponseField name="kms_key_arn" type="string">
      KMS Key Arn used to encrypt the group policy Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the EC2 Verified Access Group, used to organize and identify the resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="verified_access_instance_id" type="string" required>
  The ID of the AWS Verified Access instance. Required.
</ResponseField>

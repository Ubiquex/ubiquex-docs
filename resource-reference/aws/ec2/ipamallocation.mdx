`aws_ec2_ipamallocation` is a real, specific CIDR reservation carved out of an `aws_ec2_ipampool`, tracked so IPAM knows that range is spoken for even before a real resource like a VPC is actually created to use it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ipamallocation"})

    		ubx.Resource(ec2.Ipamallocation, "example", ec2.IpamallocationConfig{
    			IpamPoolId:    "example",
    			Cidr:          "example",
    			Description:   "Managed by ubx.",
    			NetmaskLength: 1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cidr" type="string">
  Represents an IPAM custom allocation of a single IPv4 or IPv6 CIDR Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A user-defined free-form text description that annotates the IPAM allocation, typically used to record the purpose, owner, or other identifying information for the allocated CIDR block. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ipam_pool_id" type="string" required>
  Id of the IPAM Pool. Required.
</ResponseField>

<ResponseField name="netmask_length" type="number">
  The desired netmask length of the allocation. If set, IPAM will choose a block of free space with this size and return the CIDR representing it. Optional.
</ResponseField>

## Output properties

<ResponseField name="ipam_pool_allocation_id" type="string">
  Id of the allocation. Computed by AWS after `ship`.
</ResponseField>

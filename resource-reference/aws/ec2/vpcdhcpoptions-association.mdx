`aws_ec2_vpcdhcpoptions_association` associates a real `aws_ec2_dhcpoptions` set with a specific VPC, the resource that actually applies that DHCP configuration, domain name, DNS servers, to instances launched in it.

## Properties

<ResponseField name="dhcp_options_id" type="string" required>
  The ID of the DHCP options set, or default to associate no DHCP options with the VPC. Required.
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC. Required.
</ResponseField>

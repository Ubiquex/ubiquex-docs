`aws_ec2_host` allocates a real, physical EC2 server, a Dedicated Host, dedicated entirely to a caller's own use, needed for software that's licensed per physical core or socket, or for regulatory requirements around instance isolation that shared hardware doesn't satisfy.

## Input properties

<ResponseField name="asset_id" type="string">
  The ID of the Outpost hardware asset. Optional.
</ResponseField>

<ResponseField name="auto_placement" type="string">
  Indicates whether the host accepts any untargeted instance launches that match its instance type configuration, or if it only accepts Host tenancy instance launches that specify its unique host ID. Optional.
</ResponseField>

<ResponseField name="availability_zone" type="string" required>
  The Availability Zone in which to allocate the Dedicated Host. Required.
</ResponseField>

<ResponseField name="host_maintenance" type="string">
  Automatically allocates a new dedicated host and moves your instances on to it if a degradation is detected on your current host. Optional.
</ResponseField>

<ResponseField name="host_recovery" type="string">
  Indicates whether to enable or disable host recovery for the Dedicated Host. Host recovery is disabled by default. Optional.
</ResponseField>

<ResponseField name="instance_family" type="string">
  Specifies the instance family to be supported by the Dedicated Hosts. If you specify an instance family, the Dedicated Hosts support multiple instance types within that instance family. Optional.
</ResponseField>

<ResponseField name="instance_type" type="string">
  Specifies the instance type to be supported by the Dedicated Hosts. If you specify an instance type, the Dedicated Hosts support instances of the specified instance type only. Optional.
</ResponseField>

<ResponseField name="outpost_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon Web Services Outpost on which to allocate the Dedicated Host. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the Host. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag assigned to the EC2 Dedicated Host. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag attached to the EC2 Dedicated Host. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="host_id" type="string">
  ID of the host created. Computed by AWS after `ship`.
</ResponseField>

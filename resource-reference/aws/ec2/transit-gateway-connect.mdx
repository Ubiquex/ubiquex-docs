`aws_ec2_transit_gateway_connect` is a real, GRE-based attachment type on an `aws_ec2_transit_gateway` built for connecting third-party SD-WAN appliances, supporting higher bandwidth per attachment than a standard VPN attachment.

</ResponseField>

<ResponseField name="tags" type="list(object)">

  <Expandable title="properties">
    <ResponseField name="key" type="string">

    </ResponseField>
  </Expandable>

  The ID of the attachment from which the Connect attachment was created. Required.

`aws_ec2_local_gateway_virtual_interface_group` bundles multiple `aws_ec2_local_gateway_virtual_interface`s together, the real grouping an `aws_ec2_local_gateway_route_table_virtual_interface_group_association` actually references rather than each interface being wired to a route table individually.

## Input properties

</ResponseField>

  The extended 32-bit ASN for the local BGP configuration Optional.
</ResponseField>

<ResponseField name="local_gateway_id" type="string" required>

`aws_application_signals_grouping_configuration` defines custom attributes, telemetry, AWS tags, or predefined mappings, that determine how CloudWatch Application Signals groups services in its console and APIs, overriding Application Signals's own default grouping by service dependency graph.

## Input properties

<ResponseField name="grouping_attribute_definitions" type="list(object)" required>
  Required.
  <Expandable title="properties">
    <ResponseField name="default_grouping_value" type="string">
      Specifies the fallback value used to group telemetry under a particular application or service when the source attribute defined by this grouping attribute definition is missing from the telemetry data. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="grouping_name" type="string">
      The name of the grouping attribute (used as the key in a grouping attribute definition) that identifies how telemetry is grouped in Application Signals, such as an environment or service name. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="grouping_source_keys" type="list(string)">
      Specifies the list of source telemetry attribute keys (e.g., service.name, environment) that are combined to derive the value of the corresponding grouping attribute in this grouping attribute definition, determining how Application Signals groups telemetry into applications or services. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

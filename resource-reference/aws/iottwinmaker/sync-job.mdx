`aws_io_ttwin_maker_sync_job` keeps an `aws_io_ttwin_maker_workspace`'s own entities automatically synchronized with a real, external source of truth, so a digital twin doesn't drift out of date with the physical or logical system it represents.

## Input properties

<ResponseField name="sync_role" type="string" required>
  The IAM Role that execute SyncJob. Required.
</ResponseField>

<ResponseField name="sync_source" type="string" required>
  The source of the SyncJob. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

<ResponseField name="workspace_id" type="string" required>
  The ID of the workspace. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the SyncJob. Computed by AWS after `ship`.

`aws_oam_link` creates a real cross-account link from a source account into a monitoring account under CloudWatch Observability Access Manager, sharing a filtered set of that source account's logs, metrics, and traces so they can be viewed centrally without switching accounts.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	oam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/oam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own link"})

    		ubx.Resource(oam.Link, "example", oam.LinkConfig{
    			ResourceTypes:     []string{"example"},
    			SinkIdentifier:    "example",
    			LabelTemplate:     "example",
    			LinkConfiguration: map[string]any{"log_group_configuration": map[string]any{"filter": "example"}},
    			Tags:              "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="label_template" type="string">
  Defines a template that generates the label for the link, which is used to identify the linked observability data within the monitoring account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="link_configuration" type="object">
  Specifies the configuration for the link, including filter settings for the log groups and metrics that will be shared from the source to the monitoring account. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="log_group_configuration" type="object">
      Specifies the configuration for sharing log groups through the link, including a filter pattern that determines which log groups are included. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="filter" type="string" required>
          Specifies a filter expression (such as a regex or a 'LogGroupName = ...' condition) that determines which CloudWatch Logs log groups in the source account are shared with the monitoring account through the OAM link. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="metric_configuration" type="object">
      Specifies the configuration for sharing metric data from the source account, including a filter that defines which metric namespaces to include. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="filter" type="string" required>
          Specifies the comma-separated list of CloudWatch metric namespaces (e.g., AWS/EC2,AWS/S3) that the source account shares with the monitoring account via this OAM link for metric sharing. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resource_types" type="list(string)" required>
  Specifies the AWS resource types to share with the monitoring account via this link, such as AWS::CloudWatch::Metric, AWS::CloudWatch::Alarm, or AWS::CloudWatch::LogGroup. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="sink_identifier" type="string" required>
  The ARN of the sink in the monitoring account that this link sends observability data to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Tags to apply to the link Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Observability Access Manager link. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="label" type="string">
  The unique label generated by AWS for the link, which is used to identify this source account when configuring cross-account observability in the monitoring (sink) account. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

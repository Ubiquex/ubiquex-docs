`aws_cloud_watch_metric_stream` continuously streams real, near real-time CloudWatch metric updates to a destination like Kinesis Data Firehose, an ongoing feed for a third-party observability tool rather than that tool polling the CloudWatch API on an interval.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudwatch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloudwatch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own watch metric stream"})

    		ubx.Resource(cloudwatch.MetricStream, "example", cloudwatch.MetricStreamConfig{
    			Name:                         "example",
    			ExcludeFilters:               []map[string]any{{"metric_names": []string{"example"}}},
    			FirehoseArn:                  "arn:aws:iam::123456789012:policy/example",
    			IncludeFilters:               []map[string]any{{"metric_names": []string{"example"}}},
    			IncludeLinkedAccountsMetrics: true,
    			OutputFormat:                 "example",
    			RoleArn:                      "arn:aws:iam::123456789012:policy/example",
    			StatisticsConfigurations:     []map[string]any{{"additional_statistics": []string{"example"}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="exclude_filters" type="list(object)">
  Define which metrics will be not streamed. Metrics matched by multiple instances of MetricStreamFilter are joined with an OR operation by default. If both IncludeFilters and ExcludeFilters are omitted, all metrics in the account will be streamed. IncludeFilters and ExcludeFilters are mutually exclusive. Default to null. Optional.
  <Expandable title="properties">
    <ResponseField name="metric_names" type="list(string)">
      The list of metric names within the specified namespace to exclude from the metric stream. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="namespace" type="string">
      Defines the CloudWatch namespace (e.g., AWS/EC2) whose metrics are excluded from the metric stream when matched by this exclusion filter. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="firehose_arn" type="string">
  The ARN of the Kinesis Firehose where to stream the data. Optional.
</ResponseField>

<ResponseField name="include_filters" type="list(object)">
  Define which metrics will be streamed. Metrics matched by multiple instances of MetricStreamFilter are joined with an OR operation by default. If both IncludeFilters and ExcludeFilters are omitted, all metrics in the account will be streamed. IncludeFilters and ExcludeFilters are mutually exclusive. Default to null. Optional.
  <Expandable title="properties">
    <ResponseField name="metric_names" type="list(string)">
      The names of the metrics in the specified namespace to include in the metric stream; if omitted, all metrics in the namespace are included. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="namespace" type="string">
      The namespace of the AWS service whose metrics must match this filter for them to be included in the metric stream (e.g., AWS/EC2). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="include_linked_accounts_metrics" type="bool">
  If you are creating a metric stream in a monitoring account, specify true to include metrics from source accounts that are linked to this monitoring account, in the metric stream. The default is false. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the metric stream. Optional.
</ResponseField>

<ResponseField name="output_format" type="string">
  The output format of the data streamed to the Kinesis Firehose. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the role that provides access to the Kinesis Firehose. Optional.
</ResponseField>

<ResponseField name="statistics_configurations" type="list(object)">
  By default, a metric stream always sends the MAX, MIN, SUM, and SAMPLECOUNT statistics for each metric that is streamed. You can use this parameter to have the metric stream also send additional statistics in the stream. This array can have up to 100 members. Optional.
  <Expandable title="properties">
    <ResponseField name="additional_statistics" type="list(string)">
      Specifies additional statistics (such as percentiles like p99) to include in the metric stream for metrics that match the namespace and metric name of this statistics configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="include_metrics" type="list(object)">
      Specifies the list of metrics (namespace and metric name) to which the corresponding statistics configuration's allowed statistics apply, controlling which metric streams include the configured statistics. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="metric_name" type="string">
          The name of the CloudWatch metric for which the specified additional statistics are included in the metric stream. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="namespace" type="string">
          The name of the AWS service or custom application namespace (e.g., AWS/EC2, AWS/Lambda) whose metrics are included in this statistics configuration, filtering which metric namespaces are sent to the stream. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A set of tags to assign to the delivery stream. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the CloudWatch metric stream, used for identifying and organizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

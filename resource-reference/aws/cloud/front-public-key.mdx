`aws_cloud_front_public_key` registers the real public half of a signing key pair with CloudFront, used inside an `aws_cloud_front_key_group` to validate signed URLs and signed cookies for private content.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own front public key"})

    		ubx.Resource(cloud.FrontPublicKey, "example", cloud.FrontPublicKeyConfig{
    			PublicKeyConfig: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="public_key_config" type="object" required>
  Configuration information about a public key that you can use with [signed URLs and signed cookies](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/PrivateContent.html), or with [field-level encryption](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/field-level-encryption.html). CloudFront supports signed URLs and signed cookies with RSA 2048 or ECDSA 256 key signatures. Field-level encryption is only compatible with RSA 2048 key signatures. Required.
  <Expandable title="properties">
    <ResponseField name="caller_reference" type="string" required>
      A string included in the request to help make sure that the request can't be replayed. Required.
    </ResponseField>
    <ResponseField name="comment" type="string">
      A comment to describe the public key. The comment cannot be longer than 128 characters. Optional.
    </ResponseField>
    <ResponseField name="encoded_key" type="string" required>
      The public key that you can use with [signed URLs and signed cookies](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/PrivateContent.html), or with [field-level encryption](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/field-level-encryption.html). Required.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      A name to help identify the public key. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_cloud_front_function` runs lightweight JavaScript at CloudFront edge locations against viewer requests and responses, URL rewrites, header manipulation, simple validation, with submillisecond startup, cheaper and faster than Lambda@Edge for logic that doesn't need a full Lambda runtime.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own front function"})

    			FunctionConfig: map[string]any{"comment": "example"},
    			Name:           "ci-runner",
    			AutoPublish:    true,
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="auto_publish" type="bool">
  A flag that determines whether to automatically publish the function to the ``LIVE`` stage when it’s created. To automatically publish to the ``LIVE`` stage, set this property to ``true``. Optional.
</ResponseField>

<ResponseField name="function_code" type="string" required>
  The function code. For more information about writing a CloudFront function, see [Writing function code for CloudFront Functions](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/writing-function-code.html) in the *Amazon CloudFront Developer Guide*. Required.
</ResponseField>

<ResponseField name="function_config" type="object" required>
  Contains configuration information about a CloudFront function. Required.
  <Expandable title="properties">
    <ResponseField name="comment" type="string" required>
      A comment to describe the function. The comment cannot be longer than 128 characters. Required.
    </ResponseField>
    <ResponseField name="key_value_store_associations" type="list(object)">
      The configuration for the key value store associations. Optional.
      <Expandable title="properties">
        <ResponseField name="key_value_store_arn" type="string">
          The ARN of the CloudFront KeyValueStore to associate with this function, enabling the function to read data from the key value store at runtime. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="runtime" type="string" required>
      The function's runtime environment version. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A name to identify the function. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A complex type that contains zero or more ``Tag`` elements. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key (e.g., 'environment') assigned to the CloudFront function for metadata and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="function_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the CloudFront function, assigned by AWS upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="function_metadata" type="object">
  Contains metadata about a CloudFront function. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="function_arn" type="string">
      The Amazon Resource Name (ARN) of the function. The ARN uniquely identifies the function. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="stage" type="string">
  The CloudFront function's stage, which is read-only and indicates whether the function is in the 'DEVELOPMENT' or 'LIVE' lifecycle stage as managed by AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_cloud_formation_custom_resource` runs a caller's own real logic, typically a Lambda function, as part of an `aws_cloud_formation_stack`'s create, update, and delete lifecycle, letting a stack manage something CloudFormation itself has no native resource type for.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation custom resource"})

    		ubx.Resource(cloud.FormationCustomResource, "example", cloud.FormationCustomResourceConfig{
    			ServiceToken:   "example",
    			ServiceTimeout: 1,
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.cloud import FormationCustomResource, FormationCustomResourceConfig

    def describe():
        ubx.intent("example own formation custom resource")

        ubx.resource(FormationCustomResource, "example", FormationCustomResourceConfig(
            service_token="example",
            service_timeout=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="service_timeout" type="number">
  The maximum amount of time (in seconds) that AWS CloudFormation waits for the custom resource provider to respond before considering the resource operation failed. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_token" type="string" required>
  The Amazon Resource Name (ARN) of the AWS Lambda function or Amazon Simple Notification Service (SNS) topic that implements the custom resource's provisioning logic. Required. **(AI-inferred)**
</ResponseField>

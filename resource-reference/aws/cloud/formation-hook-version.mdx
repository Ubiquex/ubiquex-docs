`aws_cloud_formation_hook_version` is a specific, registered version of a custom Hook extension, an `aws_cloud_formation_guard_hook` or `aws_cloud_formation_lambda_hook`, in the CloudFormation registry, the real mechanism that lets a Hook's own logic be updated and rolled out without breaking stacks already relying on an earlier version.

## Example

    ```go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation hook version"})

    		ubx.Resource(cloud.FormationHookVersion, "example", cloud.FormationHookVersionConfig{
    			SchemaHandlerPackage: "example",
    			TypeName:             "example-type-name",
    			ExecutionRoleArn:     "arn:aws:iam::123456789012:policy/example",
    			LoggingConfig:        map[string]any{"log_group_name": "example-log-group-name"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="execution_role_arn" type="string">
  The Amazon Resource Name (ARN) of the IAM execution role to use to register the type. If your resource type calls AWS APIs in any of its handlers, you must create an IAM execution role that includes the necessary permissions to call those AWS APIs, and provision that execution role in your account. CloudFormation then assumes that execution role to provide your resource type with the appropriate credentials. Optional.
</ResponseField>

<ResponseField name="logging_config" type="object">
  Configures the logging destination for the hook version, specifying the CloudWatch Logs log group and IAM role where the hook's execution logs are sent. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="log_group_name" type="string">
      The Amazon CloudWatch log group to which CloudFormation sends error logging information when invoking the type's handlers. Optional.
    </ResponseField>
    <ResponseField name="log_role_arn" type="string">
      The ARN of the role that CloudFormation should assume when sending log entries to CloudWatch logs. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schema_handler_package" type="string" required>
  A url to the S3 bucket containing the schema handler package that contains the schema, event handlers, and associated files for the type you want to register. For information on generating a schema handler package for the type you want to register, see submit in the CloudFormation CLI User Guide. Required.
</ResponseField>

<ResponseField name="type_name" type="string" required>
  The name of the type being registered. We recommend that type names adhere to the following pattern: company_or_organization::service::type. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the type, here the HookVersion. This is used to uniquely identify a HookVersion resource Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="is_default_version" type="bool">
  Indicates if this type version is the current default version Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type_arn" type="string">
  The Amazon Resource Name (ARN) of the type without the versionID. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version_id" type="string">
  The ID of the version of the type represented by this hook instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="visibility" type="string">
  The scope at which the type is visible and usable in CloudFormation operations. Valid values include: PRIVATE: The type is only visible and usable within the account in which it is registered. Currently, AWS CloudFormation marks any types you register as PRIVATE. PUBLIC: The type is publically visible and usable within any Amazon account. Computed by AWS after `ship`.
</ResponseField>

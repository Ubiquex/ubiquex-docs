`aws_cloud_front_continuous_deployment_policy` routes a real, configurable percentage of an `aws_cloud_front_distribution`'s production traffic to a staging distribution, letting a configuration change be tested against live traffic and incrementally rolled out before it fully replaces the primary distribution's own configuration.

## Example

    package main

    import (
    	cloudfront "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloudfront"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own front continuous deployment policy"})

    		ubx.Resource(cloudfront.ContinuousDeploymentPolicy, "example", cloudfront.ContinuousDeploymentPolicyConfig{
    			ContinuousDeploymentPolicyConfig: map[string]any{"enabled": true},
    		})
    	}))
    }

## Input properties

<ResponseField name="continuous_deployment_policy_config" type="object" required>
  Contains the configuration for a continuous deployment policy. Required.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool" required>
      A Boolean that indicates whether this continuous deployment policy is enabled (in effect). When this value is ``true``, this policy is enabled and in effect. When this value is ``false``, this policy is not enabled and has no effect. Required.
    </ResponseField>
    <ResponseField name="single_header_policy_config" type="object">
      This configuration determines which HTTP requests are sent to the staging distribution. If the HTTP request contains a header and value that matches what you specify here, the request is sent to the staging distribution. Otherwise the request is sent to the primary distribution. Optional.
      <Expandable title="properties">
        <ResponseField name="header" type="string" required>
          The HTTP header name that CloudFront inspects to route requests to the staging distribution in this continuous deployment policy. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string" required>
          The header value that CloudFront uses to route requests to the staging distribution in the continuous deployment policy. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="single_weight_policy_config" type="object">
      This configuration determines the percentage of HTTP requests that are sent to the staging distribution. Optional.
      <Expandable title="properties">
        <ResponseField name="session_stickiness_config" type="object">
          Session stickiness provides the ability to define multiple requests from a single viewer as a single session. This prevents the potentially inconsistent experience of sending some of a given user's requests to your staging distribution, while others are sent to your primary distribution. Define the session duration using TTL values. Optional.
          <Expandable title="properties">
            <ResponseField name="idle_ttl" type="number" required>
              The amount of time after which you want sessions to cease if no requests are received. Allowed values are 300 -- 3600 seconds (5 -- 60 minutes). Required.

            <ResponseField name="maximum_ttl" type="number" required>
              The maximum amount of time to consider requests from the viewer as being part of the same session. Allowed values are 300 -- 3600 seconds (5 -- 60 minutes). Required.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="weight" type="number" required>
          Specifies the percentage of traffic to route to the staging distribution, with a value between 0 and 100, where 100 sends all traffic to the staging distribution. Required. **(AI-inferred)**

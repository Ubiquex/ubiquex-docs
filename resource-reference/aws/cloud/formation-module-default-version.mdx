`aws_cloud_formation_module_default_version` designates which registered `aws_cloud_formation_module_version` CloudFormation uses by default whenever a template references that module without pinning to a specific version.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own formation module default version"})

    		ubx.Resource(cloud.FormationModuleDefaultVersion, "ci-runner", cloud.FormationModuleDefaultVersionConfig{
    			Arn:        "arn:aws:iam::123456789012:policy/ci",
    			ModuleName: "example-module-name",
    			VersionId:  "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the module version to set as the default version. Optional.
</ResponseField>

<ResponseField name="module_name" type="string">
  The name of a module existing in the registry. Optional.
</ResponseField>

<ResponseField name="version_id" type="string">
  The ID of an existing version of the named module to set as the default. Optional.
</ResponseField>

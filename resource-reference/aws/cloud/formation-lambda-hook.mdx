`aws_cloud_formation_lambda_hook` implements a CloudFormation Hook, real, custom code that inspects a resource's configuration before it's provisioned and either blocks or warns on non-compliant configurations, using a Lambda function to run the actual evaluation logic in any Lambda-supported language.

## Input properties

<ResponseField name="alias" type="string" required>
  The typename alias for the hook. Required.
</ResponseField>

<ResponseField name="auto_update" type="bool">
  Whether to automatically update the extension in this account and Region when a new minor version is published by the extension publisher. Optional.
</ResponseField>

<ResponseField name="execution_role" type="string" required>
  The execution role for this cloud formation lambda hook. Required.
</ResponseField>

<ResponseField name="failure_mode" type="string" required>
  Attribute to specify CloudFormation behavior on hook failure. Required.
</ResponseField>

<ResponseField name="hook_status" type="string" required>
  Attribute to specify which stacks this hook applies to or should get invoked for Required.
</ResponseField>

<ResponseField name="lambda_function" type="string" required>
  Amazon Resource Name (ARN), Partial ARN, name, version, or alias of the Lambda function to invoke with this hook. Required.
</ResponseField>

<ResponseField name="logging_config" type="object">
  Contains logging configuration information for an extension. Optional.
  <Expandable title="properties">
    <ResponseField name="log_group_name" type="string" required>
      The Amazon CloudWatch Logs group to which CloudFormation sends error logging information when invoking the extension's handlers. Required.
    </ResponseField>
    <ResponseField name="log_role_arn" type="string" required>
      The ARN of the role that CloudFormation should assume when sending log entries to CloudWatch Logs. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="stack_filters" type="object">
  Filters to allow hooks to target specific stack attributes Optional.
  <Expandable title="properties">
    <ResponseField name="filtering_criteria" type="string" required>
      Attribute to specify the filtering behavior. ANY will make the Hook pass if one filter matches. ALL will make the Hook pass if all filters match Required.
    </ResponseField>
    <ResponseField name="stack_names" type="object">
      List of stack names as filters Optional.
      <Expandable title="properties">
        <ResponseField name="exclude" type="list(string)">
          List of stack names that the hook is going to be excluded from Optional.
        </ResponseField>
        <ResponseField name="include" type="list(string)">
          List of stack names that the hook is going to target Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="stack_roles" type="object">
      List of stack roles that are performing the stack operations. Optional.
      <Expandable title="properties">
        <ResponseField name="exclude" type="list(any)">
          List of stack roles that the hook is going to be excluded from Optional.
        </ResponseField>
        <ResponseField name="include" type="list(any)">
          List of stack roles that the hook is going to target Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_filters" type="object">
  Attribute to specify which targets should invoke the hook Optional.
  <Expandable title="properties">
    <ResponseField name="actions" type="list(string)">
      Specifies the list of CloudFormation change actions (e.g., Create, Update, Delete) that trigger the Lambda hook invocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="invocation_points" type="list(string)">
      Specifies the list of CloudFormation hook invocation points (such as BEFORE_CREATE, BEFORE_UPDATE, BEFORE_DELETE) at which the Lambda hook is triggered for the matching target resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="target_names" type="list(string)">
      Specifies the list of AWS resource type names (e.g., AWS::S3::Bucket) that this Lambda hook targets, controlling which resource types trigger the hook. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="targets" type="list(object)">
      The list of target objects that define which CloudFormation resources this Lambda hook is triggered for, where each target specifies a resource type (e.g., AWS::S3::Bucket) and optionally a specific resource name to narrow the hook's scope. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="action" type="string">
          Specifies the CloudFormation action (e.g., CREATE, UPDATE, DELETE) that triggers the Lambda hook for the targeted resource types. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="invocation_point" type="string">
          Specifies the invocation timing relative to the targeted CloudFormation operation (e.g., `BEFORE` or `AFTER`), determining whether the Lambda hook runs before or after the action on the matched resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="target_name" type="string">
          The name of the resource type (e.g., AWS::S3::Bucket) or logical resource ID that the CloudFormation Lambda hook's target filter matches, depending on whether the target type is RESOURCE_TYPE or RESOURCE_NAME. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_operations" type="list(string)" required>
  Which operations should this Hook run against? Resource changes, stacks or change sets. Required.
</ResponseField>

  The Amazon Resource Name (ARN) of the activated hook Computed by AWS after `ship`.

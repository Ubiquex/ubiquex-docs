`aws_cloud_trail_resource_policy` attaches a real resource-based access policy to an `aws_cloud_trail_trail` or `aws_cloud_trail_event_data_store`, controlling which principals, including from other accounts, can deliver events to or read from it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own trail resource policy"})

    		ubx.Resource(cloud.TrailResourcePolicy, "ci-runner", cloud.TrailResourcePolicyConfig{
    			ResourceArn:    "arn:aws:iam::123456789012:policy/ci",
    			ResourcePolicy: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="resource_arn" type="string" required>
  The ARN of the AWS CloudTrail resource to which the policy applies. Required.
</ResponseField>

<ResponseField name="resource_policy" type="any" required>
  A policy document containing permissions to add to the specified resource. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. Required.
</ResponseField>

`aws_cloud_front_realtime_log_config` streams an `aws_cloud_front_distribution`'s access logs to Kinesis Data Streams within seconds of each request, real-time visibility into edge traffic rather than the batched, delayed delivery of CloudFront's standard access logs.

## Example

    ```go
    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(cloud.FrontRealtimeLogConfig, "example", cloud.FrontRealtimeLogConfigConfig{

    			Fields:       []string{"example"},
    			Name:         "example",
    			SamplingRate: 1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="end_points" type="list(object)" required>
  Contains information about the Amazon Kinesis data stream where you are sending real-time log data for this real-time log configuration. Required.
  <Expandable title="properties">
    <ResponseField name="kinesis_stream_config" type="object">
      This object specifies the configuration for the Amazon Kinesis Data Streams destination of a real-time log endpoint, including the stream's Amazon Resource Name (ARN) and the IAM role ARN that CloudFront assumes to publish log records to the stream. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="role_arn" type="string">
          The ARN of an IAM role that CloudFront assumes to send real-time log data to the associated Kinesis data stream. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="stream_arn" type="string">
          The Amazon Resource Name (ARN) of the Kinesis data stream to which CloudFront delivers real-time log data. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="stream_type" type="string">
      Specifies the streaming service type for a real-time log configuration endpoint, and the only supported value is 'Kinesis'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="fields" type="list(string)" required>
  A list of fields that are included in each real-time log record. In an API response, the fields are provided in the same order in which they are sent to the Amazon Kinesis data stream. For more information about fields, see [Real-time log configuration fields](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/real-time-logs.html#understand-real-time-log-config-fields) in the *Amazon CloudFront Developer Guide*. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The unique name of this real-time log configuration. Required.
</ResponseField>

<ResponseField name="sampling_rate" type="number" required>
  The sampling rate for this real-time log configuration. The sampling rate determines the percentage of viewer requests that are represented in the real-time log data. The sampling rate is an integer between 1 and 100, inclusive. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the CloudFront real-time log configuration. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

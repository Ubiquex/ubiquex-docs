`aws_cloud_trail_channel` is the real integration point CloudTrail Lake uses to ingest events from an outside source, a CloudTrail partner integration or a caller's own application, into an `aws_cloud_trail_event_data_store` alongside native AWS activity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudtrail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloudtrail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own trail channel"})

    		ubx.Resource(cloudtrail.Channel, "example", cloudtrail.ChannelConfig{
    			Name:         "example",
    			Destinations: []map[string]any{{"location": "example"}},
    			Source:       "example",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="destinations" type="list(object)">
  One or more resources to which events arriving through a channel are logged and stored. Optional.
  <Expandable title="properties">
    <ResponseField name="location" type="string">
      The ARN of the destination resource (e.g., an event data store ARN) where the CloudTrail channel delivers events. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of destination for the CloudTrail channel, which can be either `EVENT_DATA_STORE` (for a CloudTrail Lake event data store) or `AWS_SERVICE` (for an AWS service such as Amazon S3, CloudWatch Logs, or EventBridge). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the channel. Optional.
</ResponseField>

<ResponseField name="source" type="string">
  The ARN of an on-premises storage solution or application, or a partner event source. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to the CloudTrail channel for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the CloudTrail channel, used for organizing, identifying, and managing the channel resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="channel_arn" type="string">
  The Amazon Resource Name (ARN) of a channel. Computed by AWS after `ship`.
</ResponseField>

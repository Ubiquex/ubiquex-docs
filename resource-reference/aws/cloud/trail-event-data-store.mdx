`aws_cloud_trail_event_data_store` is an immutable, queryable collection of events in CloudTrail Lake, converted to columnar Apache ORC storage for fast retrieval and retained for up to 10 years, real, long-term audit data queried directly rather than exported and reprocessed elsewhere.

## Input properties

<ResponseField name="advanced_event_selectors" type="list(object)">
  The advanced event selectors that were used to select events for the data store. Optional.
  <Expandable title="properties">
    <ResponseField name="field_selectors" type="list(object)">
      Defines the list of field selectors within an advanced event selector that specify conditions on event fields, such as eventCategory or eventName, to determine which events are delivered to the event data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="ends_with" type="list(string)">
          Matches events where the selected field's value ends with any of the specified string suffixes, defining a condition in the CloudTrail event data store's advanced event selector. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="equals" type="list(string)">
          For each field selector in a CloudTrail event data store's advanced event selector, `equals` specifies the list of exact values that the named event field must match for an event to be delivered to the data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="field" type="string">
          The name of the event attribute (e.g., eventCategory, readOnly, resources.type) that the field selector evaluates to filter which events are ingested into the event data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="not_ends_with" type="list(string)">
          For each advanced event selector field, this list of suffixes defines a `not endsWith` condition: an event matches only if the field's value does not end with any of the specified suffix strings. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="not_equals" type="list(string)">
          Defines a list of values that, if any matches the event field specified by the adjacent field selector, will cause the event to be excluded from the CloudTrail event data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="not_starts_with" type="list(string)">
          For an advanced event selector on an event data store, this list contains string prefixes; events whose corresponding field value begins with any listed prefix are excluded from matching the selector. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="starts_with" type="list(string)">
          Specifies a list of string prefixes that the value of the selected event field must start with for an event to match this advanced event selector and be included in the event data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="name" type="string">
      Provides a friendly name for the advanced event selector, used to identify it when managing multiple selectors in the CloudTrail event data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>

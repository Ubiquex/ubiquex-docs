`aws_cloud_formation_module_version` registers a real CloudFormation module, a plain template fragment packaging a set of resources as a single, reusable, versioned building block, making it available for other templates in the account and Region to reference like a built-in resource type.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own formation module version"})

    		ubx.Resource(cloud.FormationModuleVersion, "ci-runner", cloud.FormationModuleVersionConfig{
    			ModuleName:    "example-module-name",
    			ModulePackage: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="module_name" type="string" required>
  The name of the module being registered. Recommended module naming pattern: company_or_organization::service::type::MODULE. Required.
</ResponseField>

<ResponseField name="module_package" type="string" required>
  The url to the S3 bucket containing the schema and template fragment for the module you want to register. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the module. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the registered module. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="documentation_url" type="string">
  The URL of a page providing detailed documentation for this module. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="is_default_version" type="bool">
  Indicator of whether this module version is the current default version Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="schema" type="string">
  The schema defining input parameters to and resources generated by the module. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="time_created" type="string">
  The time that the specified module version was registered. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version_id" type="string">
  The version ID of the module represented by this module instance. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="visibility" type="string">
  The scope at which the type is visible and usable in CloudFormation operations. The only allowed value at present is: PRIVATE: The type is only visible and usable within the account in which it is registered. Currently, AWS CloudFormation marks any types you register as PRIVATE. Computed by AWS after `ship`.
</ResponseField>

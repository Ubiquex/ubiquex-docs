`aws_cloud_formation_stack` is CloudFormation's own fundamental unit, a collection of AWS resources managed together as one, created, updated, and deleted as a single operation from a real template.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own formation stack"})

    		ubx.Resource(cloud.FormationStack, "ci-runner", cloud.FormationStackConfig{
    			StackName:                   "example-stack-name",
    			Capabilities:                []string{"example"},
    			Description:                 "Managed by ubx.",
    			DisableRollback:             true,
    			EnableTerminationProtection: true,
    			NotificationArns:            []string{"example"},
    			Parameters:                  "example",
    			RoleArn:                     "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="capabilities" type="list(string)">
  A list of capability values (e.g., CAPABILITY_IAM, CAPABILITY_NAMED_IAM, CAPABILITY_AUTO_EXPAND) that the stack operation requires to acknowledge creation or modification of IAM resources or to expand macros. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Provides a freely formed text description for the AWS CloudFormation stack, which is passed to the AWS CloudFormation service and helps identify the stack's purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="disable_rollback" type="bool">
  Disables rollback of the stack if stack creation fails, allowing the stack to remain in a failed state for troubleshooting. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_termination_protection" type="bool">
  When set to true, enables termination protection on the CloudFormation stack, preventing the stack from being deleted until this setting is disabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="notification_arns" type="list(string)">
  The Amazon SNS topic ARNs to which CloudFormation sends stack event notifications, such as resource creation or deletion events. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="parameters" type="any">
  A map of input parameters to pass to the CloudFormation stack, matching the Parameters declared in the stack's template. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="role_arn" type="string">
  ARN of the IAM role that AWS CloudFormation assumes to create, update, or delete the stack's resources. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The name of the CloudFormation stack, which must be unique within an AWS region and is used to identify the stack in operations. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_policy_body" type="any">
  Specifies the JSON body of a stack policy, which defines permissions that protect stack resources from accidental updates or deletions during stack operations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_policy_url" type="string">
  The URL to the stack policy file, which restricts updates to specific resources within the CloudFormation stack during a stack update. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_status_reason" type="string">
  The reason provided by AWS CloudFormation for the stack's current status, such as why a create, update, or delete operation failed. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the list of key-value tags to associate with the CloudFormation stack, which are used to identify, organize, and manage the stack, and which are propagated to tag-supporting resources created by the stack. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key to associate with the CloudFormation stack, used to organize and identify the stack for cost allocation and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the CloudFormation stack, used for cost allocation, access control, and organizing stack resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_body" type="any">
  The CloudFormation template body, in JSON or YAML format, that defines the stack's resources and properties; you can use this instead of providing a template URL. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_url" type="string">
  The URL of a file (typically in Amazon S3) that contains the CloudFormation template body, used instead of inline template_body. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="timeout_in_minutes" type="number">
  The maximum number of minutes that CloudFormation allows for the stack creation to complete before the stack creation fails. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="change_set_id" type="string">
  The unique ID of the change set that was last executed to create or update the stack, useful for tracking which changes were applied. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="creation_time" type="string">
  The timestamp indicating when the CloudFormation stack was created, typically in ISO 8601 format. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="last_update_time" type="string">
  The timestamp of when the CloudFormation stack was last updated, provided as a string. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="outputs" type="list(object)">
  A list of the CloudFormation stack's output entries, each containing a key and value from the Outputs section of the stack template, as returned by AWS. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      The description of a CloudFormation stack output, as defined in the stack template, providing human-readable context for the output value. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="export_name" type="string">
      The export name for a stack output, which makes the output value available to other CloudFormation stacks via Fn::ImportValue. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="output_key" type="string">
      Specifies the name of an output exported by the AWS CloudFormation stack, used to identify the corresponding output value within the stack's list of outputs. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="output_value" type="string">
      The actual value of a CloudFormation stack output, returned after the stack has been created or updated. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="parent_id" type="string">
  The unique identifier of the parent CloudFormation stack that this stack is nested within, or an empty string if this is a root-level stack. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="root_id" type="string">
  The root stack ID of a CloudFormation stack, which is the unique identifier of the top-level stack that this stack belongs to (equal to the stack's own ID for a top-level stack). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_id" type="string">
  The unique Amazon Resource Name (ARN) assigned to the CloudFormation stack by AWS when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_status" type="string">
  The current status of the CloudFormation stack as reported by AWS, such as CREATE_COMPLETE, UPDATE_COMPLETE, or DELETE_COMPLETE, and is read-only since it is determined by the service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

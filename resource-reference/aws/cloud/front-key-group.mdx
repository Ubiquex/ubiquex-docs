`aws_cloud_front_key_group` holds one or more `aws_cloud_front_public_key`s that CloudFront validates signed URLs or signed cookies against, the real, required grouping an `aws_cloud_front_distribution`'s trusted-signer configuration references rather than a bare public key directly.

## Input properties

<ResponseField name="key_group_config" type="object" required>
  A key group configuration. A key group contains a list of public keys that you can use with [CloudFront signed URLs and signed cookies](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/PrivateContent.html). Required.
  <Expandable title="properties">
    <ResponseField name="comment" type="string">
      A comment to describe the key group. The comment cannot be longer than 128 characters. Optional.
    </ResponseField>
    <ResponseField name="items" type="list(string)" required>
      A list of the identifiers of the public keys in the key group. Required.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      A name to identify the key group. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

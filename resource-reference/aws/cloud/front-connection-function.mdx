`aws_cloud_front_connection_function` is a specialized `aws_cloud_front_function` that runs during the TLS handshake of a mutual TLS connection rather than against a viewer HTTP request, with access to client certificate details and revocation-check results for custom certificate validation logic like organizational-unit checks or IP-based certificate policy.

## Input properties

<ResponseField name="auto_publish" type="bool">
  A flag that determines whether to automatically publish the function to the ``LIVE`` stage when it’s created. To automatically publish to the ``LIVE`` stage, set this property to ``true``. Optional.
</ResponseField>

<ResponseField name="connection_function_code" type="string" required>
  The code for the connection function. Required.
</ResponseField>

<ResponseField name="connection_function_config" type="object" required>
  Contains configuration information about a CloudFront function. Required.
  <Expandable title="properties">
    <ResponseField name="comment" type="string" required>
      A comment to describe the function. The comment cannot be longer than 128 characters. Required.
    </ResponseField>
    <ResponseField name="key_value_store_associations" type="list(object)">
      The configuration for the key value store associations. Optional.
      <Expandable title="properties">
        <ResponseField name="key_value_store_arn" type="string">
          The ARN of the CloudFront key value store to associate with the function, granting the function read access to that store's data during invocation at the edge. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="runtime" type="string" required>
      The function's runtime environment version. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The connection function name. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A complex type that contains zero or more ``Tag`` elements. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

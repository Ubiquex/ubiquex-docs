`aws_cloud_formation_wait_condition_handle` generates the real, pre-signed URL an external process signals success or failure to, referenced by an `aws_cloud_formation_wait_condition`'s own Handle property. AWS now recommends a stack resource's CreationPolicy attribute over this mechanism for new templates.

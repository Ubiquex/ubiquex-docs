`aws_cloud_watch_composite_alarm` combines the state of multiple `aws_cloud_watch_alarm`s with a real boolean expression (AND, OR, NOT), alarming only on the actual combined condition rather than firing separately, and noisily, for every individual underlying alarm.

## Input properties

<ResponseField name="actions_enabled" type="bool">
  Indicates whether actions should be executed during any changes to the alarm state. The default is TRUE. Optional.
</ResponseField>

<ResponseField name="actions_suppressor" type="string">
  Actions will be suppressed if the suppressor alarm is in the ALARM state. ActionsSuppressor can be an AlarmName or an Amazon Resource Name (ARN) from an existing alarm. Optional.
</ResponseField>

<ResponseField name="actions_suppressor_extension_period" type="number">
  Actions will be suppressed if WaitPeriod is active. The length of time that actions are suppressed is in seconds. Optional.
</ResponseField>

<ResponseField name="actions_suppressor_wait_period" type="number">
  Actions will be suppressed if ExtensionPeriod is active. The length of time that actions are suppressed is in seconds. Optional.
</ResponseField>

<ResponseField name="alarm_actions" type="list(string)">
  The list of actions to execute when this alarm transitions into an ALARM state from any other state. Specify each action as an Amazon Resource Name (ARN). Optional.
</ResponseField>

<ResponseField name="alarm_description" type="string">
  The description of the alarm Optional.
</ResponseField>

<ResponseField name="alarm_name" type="string">
  The name of the Composite Alarm Optional.
</ResponseField>

<ResponseField name="alarm_rule" type="string" required>
  Expression which aggregates the state of other Alarms (Metric or Composite Alarms) Required.
</ResponseField>

<ResponseField name="insufficient_data_actions" type="list(string)">
  The actions to execute when this alarm transitions to the INSUFFICIENT_DATA state from any other state. Each action is specified as an Amazon Resource Name (ARN). Optional.
</ResponseField>

<ResponseField name="okactions" type="list(string)">
  The actions to execute when this alarm transitions to the OK state from any other state. Each action is specified as an Amazon Resource Name (ARN). Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to associate with the composite alarm. You can associate as many as 50 tags with an alarm. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the CloudWatch composite alarm, used to identify, categorize, and manage the alarm in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag attached to the CloudWatch Composite Alarm, used for organizing, identifying, and managing the alarm resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

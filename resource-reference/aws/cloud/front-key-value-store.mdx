`aws_cloud_front_key_value_store` is a globally replicated, low-latency key-value datastore an `aws_cloud_front_function` reads from at the edge, letting a function's data, an allowlist, an A/B test assignment, be updated independently of redeploying the function's own code.

## Input properties

<ResponseField name="comment" type="string">
  A comment to describe the Key Value Store. Omitting ``Comment`` from the template during updates will clear the existing comment (set to empty string). To preserve an existing comment, you must explicitly include it in the template. Optional.
</ResponseField>

<ResponseField name="import_source" type="object">
  The import source for the key value store. Optional.
  <Expandable title="properties">
    <ResponseField name="source_arn" type="string" required>
      The Amazon Resource Name (ARN) of the import source for the key value store. Required.
    </ResponseField>
    <ResponseField name="source_type" type="string" required>
      The source type of the import source for the key value store. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the key value store. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A complex type that contains zero or more ``Tag`` elements. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the CloudFront key value store, used to identify the tag within the tag set. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the CloudFront key value store. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to this CloudFront KeyValueStore, used to reference the store in other resources such as CloudFront functions. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the CloudFront KeyValueStore, such as CREATING or READY, indicating whether the store is ready for use. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

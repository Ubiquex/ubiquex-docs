`aws_cloud_formation_change_set` computes a real, previewable set of changes that updating an `aws_cloud_formation_stack` to a new template or parameters would make, without actually applying them, so the changes can be reviewed before anything is modified.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own formation change set"})

    		ubx.Resource(cloud.FormationChangeSet, "ci-runner", cloud.FormationChangeSetConfig{
    			ChangeSetName:           "example-change-set-name",
    			StackName:               "example-stack-name",
    			Capabilities:            []string{"example"},
    			ChangeSetType:           "example",
    			DeploymentMode:          "example",
    			Description:             "Managed by ubx.",
    			ImportExistingResources: true,
    			IncludeNestedStacks:     true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="capabilities" type="list(string)">
  The capabilities that are allowed in the stack. Optional.
</ResponseField>

<ResponseField name="change_set_name" type="string" required>
  The name of the change set. Must be unique among all change sets associated with the specified stack. Required.
</ResponseField>

<ResponseField name="change_set_type" type="string">
  The type of change set operation. Optional.
</ResponseField>

<ResponseField name="deployment_mode" type="string">
  Determines how CloudFormation handles configuration drift during deployment. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description to help you identify this change set. Optional.
</ResponseField>

<ResponseField name="import_existing_resources" type="bool">
  Indicates if the change set imports resources that already exist. Optional.
</ResponseField>

<ResponseField name="include_nested_stacks" type="bool">
  Creates a change set for all nested stacks specified in the template. Optional.
</ResponseField>

<ResponseField name="notification_arns" type="list(string)">
  The ARNs of Amazon SNS topics that CloudFormation associates with the stack. Optional.
</ResponseField>

<ResponseField name="on_stack_failure" type="string">
  Determines what action will be taken if stack creation fails. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of an IAM role that CloudFormation assumes when executing the change set. Optional.
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The name or unique ID of the stack for which you are creating a change set. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Key-value pairs to associate with the change set. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_body" type="string">
  A structure that contains the body of the revised template. Optional.
</ResponseField>

<ResponseField name="template_url" type="string">
  The URL of the file that contains the revised template. Optional.
</ResponseField>

<ResponseField name="use_previous_template" type="bool">
  Whether to reuse the template associated with the stack to create the change set. Optional.
</ResponseField>

## Output properties

<ResponseField name="change_set_id" type="string">
  The ARN of the change set. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="creation_time" type="string">
  The time the change set was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="stack_id" type="string">
  The unique ID of the stack. Computed by AWS after `ship`.
</ResponseField>

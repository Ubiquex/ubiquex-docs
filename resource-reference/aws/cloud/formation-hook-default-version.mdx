`aws_cloud_formation_hook_default_version` designates which registered version of an `aws_cloud_formation_lambda_hook` CloudFormation actually invokes by default, when multiple versions of the same hook have been registered.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own formation hook default version"})

    		ubx.Resource(cloud.FormationHookDefaultVersion, "ci-runner", cloud.FormationHookDefaultVersionConfig{
    			TypeName:       "example-type-name",
    			TypeVersionArn: "arn:aws:iam::123456789012:policy/ci",
    			VersionId:      "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="type_name" type="string">
  The name of the type being registered. We recommend that type names adhere to the following pattern: company_or_organization::service::type. Optional.
</ResponseField>

<ResponseField name="type_version_arn" type="string">
  The Amazon Resource Name (ARN) of the type version. Optional.
</ResponseField>

<ResponseField name="version_id" type="string">
  The ID of an existing version of the hook to set as the default. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the type. This is used to uniquely identify a HookDefaultVersion Computed by AWS after `ship`.
</ResponseField>

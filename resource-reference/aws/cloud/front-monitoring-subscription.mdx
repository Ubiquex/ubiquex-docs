`aws_cloud_front_monitoring_subscription` enables real, additional CloudWatch metrics, at one-minute granularity, for an `aws_cloud_front_distribution`, beyond the default metrics CloudFront reports out of the box.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own front monitoring subscription"})

    		ubx.Resource(cloud.FrontMonitoringSubscription, "example", cloud.FrontMonitoringSubscriptionConfig{
    			DistributionId:         "example",
    			MonitoringSubscription: map[string]any{"realtime_metrics_subscription_config": map[string]any{"realtime_metrics_subscription_status": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="distribution_id" type="string" required>
  The ID of the distribution that you are enabling metrics for. Required.
</ResponseField>

<ResponseField name="monitoring_subscription" type="object" required>
  A monitoring subscription. This structure contains information about whether additional CloudWatch metrics are enabled for a given CloudFront distribution. Required.
  <Expandable title="properties">
    <ResponseField name="realtime_metrics_subscription_config" type="object">
      A subscription configuration for additional CloudWatch metrics. Optional.
      <Expandable title="properties">
        <ResponseField name="realtime_metrics_subscription_status" type="string" required>
          A flag that indicates whether additional CloudWatch metrics are enabled for a given CloudFront distribution. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

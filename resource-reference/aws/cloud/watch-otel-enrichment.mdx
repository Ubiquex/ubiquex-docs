`aws_cloud_watch_otel_enrichment` configures real, automatic AWS-context enrichment of metrics ingested through OpenTelemetry into CloudWatch, so OTel-native metrics carry the same AWS metadata as CloudWatch's own vended metrics and can be queried together with PromQL from one place. This is a genuinely new 2026 capability, so behavior here is verified live rather than assumed from general knowledge.

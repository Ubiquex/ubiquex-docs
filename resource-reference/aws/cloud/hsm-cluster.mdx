`aws_cloud_hsm_cluster` creates a real cluster of dedicated, single-tenant hardware security modules, FIPS 140-2 validated, that an application generates and stores its own cryptographic keys in directly, under AWS CloudHSM.

## Input properties

<ResponseField name="backup_retention_policy" type="object">
  A policy that defines how the service retains backups. Optional.
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      The type of backup retention policy. Optional.
    </ResponseField>
    <ResponseField name="value" type="string">
      Use a value between 7 - 379. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="hsm_type" type="string" required>
  The type of HSM to use in the cluster. Required.
</ResponseField>

<ResponseField name="mode" type="string">
  The mode to use in the cluster. Optional.
</ResponseField>

<ResponseField name="network_type" type="string">
  The NetworkType to create a cluster with. Optional.
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)">
  The identifiers (IDs) of the subnets where the cluster is created. You must specify at least one subnet. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to apply to the CloudHSM cluster. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="backup_policy" type="string">
  The cluster's backup policy. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="cluster_id" type="string">
  The cluster's identifier (ID). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="security_group" type="string">
  The identifier (ID) of the cluster's security group. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The cluster's state. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="subnet_mapping" type="any">
  A map from availability zone to the cluster's subnet in that availability zone. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="vpc_id" type="string">
  The identifier (ID) of the virtual private cloud (VPC) that contains the cluster. Computed by AWS after `ship`.
</ResponseField>

`aws_cloud_watch_dashboard` is a real, customizable, unified visualization of metrics and logs, shareable across accounts and Regions, that a caller builds by hand or gets automatically curated for many AWS services without building one from scratch.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own watch dashboard"})

    		ubx.Resource(cloud.WatchDashboard, "example", cloud.WatchDashboardConfig{
    			DashboardBody: "example",
    			DashboardName: "example-dashboard-name",
    			Tags:          []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="dashboard_body" type="string" required>
  The detailed information about the dashboard in JSON format, including the widgets to include and their location on the dashboard Required.
</ResponseField>

<ResponseField name="dashboard_name" type="string">
  The name of the dashboard. The name must be between 1 and 255 characters. If you do not specify a name, one will be generated automatically. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value pairs to associate with the cloudwatch dashboard. You can associate up to 50 tags with a dashboard Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the CloudWatch dashboard, used to identify and categorize the dashboard for resource management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value for a tag key applied to the CloudWatch dashboard for resource organization and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

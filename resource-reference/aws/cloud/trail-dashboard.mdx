`aws_cloud_trail_dashboard` visualizes real, aggregated trends from an `aws_cloud_trail_event_data_store`, CloudTrail Lake's own built-in analytics view rather than a caller writing and re-running the underlying queries by hand each time.

## Example

## Input properties

<ResponseField name="name" type="string">
  The name of the dashboard. Optional.
</ResponseField>

<ResponseField name="refresh_schedule" type="object">
  Configures the automatic refresh schedule for the dashboard. Includes the frequency unit (DAYS or HOURS) and value, as well as the status (ENABLED or DISABLED) of the refresh schedule. Optional.
  <Expandable title="properties">
    <ResponseField name="frequency" type="object">
      Defines the automatic refresh frequency for the CloudTrail dashboard, expressed as a unit-value pair (e.g., HOURS with a value of 6 for a six-hour refresh interval). Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="unit" type="string" required>
          The frequency unit. Supported values are HOURS and DAYS. Required.
        </ResponseField>
        <ResponseField name="value" type="number" required>
          The frequency value. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="status" type="string">
      The status of the schedule. Supported values are ENABLED and DISABLED. Optional.
    </ResponseField>
    <ResponseField name="time_of_day" type="string">
      StartTime of the automatic schedule refresh. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag objects (each containing a key and value) to attach to the CloudTrail dashboard, enabling resource identification, cost allocation, and AWS resource management. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the CloudTrail dashboard, used to assign custom metadata for identifying, organizing, and controlling access to the dashboard (e.g., via IAM conditions and cost allocation tags). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="termination_protection_enabled" type="bool">
  Indicates whether the dashboard is protected from termination. Optional.
</ResponseField>

<ResponseField name="widgets" type="list(object)">
  List of widgets on the dashboard Optional.
  <Expandable title="properties">
    <ResponseField name="query_parameters" type="list(string)">
      For each widget in an AWS CloudTrail dashboard, this list of strings supplies the query parameter values that are substituted into the widget's query to filter or scope the displayed data. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="query_statement" type="string">
      The SQL query statement that a widget in an AWS CloudTrail dashboard uses to fetch and display data from the CloudTrail event data store. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="view_properties" type="any">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_timestamp" type="string">
  The timestamp, in ISO 8601 format, indicating when the CloudTrail dashboard was created, as returned by the CloudTrail DescribeDashboard API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="dashboard_arn" type="string">
  The ARN of the dashboard. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the dashboard. Values are CREATING, CREATED, UPDATING, UPDATED and DELETING. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type" type="string">
  The type of the dashboard. Values are CUSTOM and MANAGED. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_timestamp" type="string">
  The timestamp indicating when the CloudTrail dashboard was last updated. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

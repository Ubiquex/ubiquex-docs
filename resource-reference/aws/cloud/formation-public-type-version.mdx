`aws_cloud_formation_public_type_version` publishes a real, specific version of a resource type through an `aws_cloud_formation_type_activation`-eligible public registry listing, so other accounts can activate and pin to that exact version rather than only the type's latest.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation public type version"})

    		ubx.Resource(cloud.FormationPublicTypeVersion, "example", cloud.FormationPublicTypeVersionConfig{
    			Arn:                 "arn:aws:iam::123456789012:policy/example",
    			LogDeliveryBucket:   "example",
    			PublicVersionNumber: "example",
    			Type:                "example",
    			TypeName:            "example-type-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="arn" type="string">
  The Amazon Resource Number (ARN) of the extension. Optional.
</ResponseField>

<ResponseField name="log_delivery_bucket" type="string">
  A url to the S3 bucket where logs for the testType run will be available Optional.
</ResponseField>

<ResponseField name="public_version_number" type="string">
  The version number of a public third-party extension Optional.
</ResponseField>

<ResponseField name="type" type="string">
  The kind of extension Optional.
</ResponseField>

<ResponseField name="type_name" type="string">
  The name of the type being registered. We recommend that type names adhere to the following pattern: company_or_organization::service::type. Optional.
</ResponseField>

## Output properties

<ResponseField name="public_type_arn" type="string">
  The Amazon Resource Number (ARN) assigned to the public extension upon publication Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="publisher_id" type="string">
  The reserved publisher id for this type, or the publisher id assigned by CloudFormation for publishing in this region. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="type_version_arn" type="string">
  The Amazon Resource Number (ARN) of the extension with the versionId. Computed by AWS after `ship`.
</ResponseField>

`aws_cloud_front_trust_store` is the real repository of CA certificates an `aws_cloud_front_distribution` validates client certificates against during mutual TLS, defining which certificate authorities are trusted to have issued a valid client certificate.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    	}))
    }

`aws_cloud_watch_alarm_mute_rule` automatically mutes up to 100 named `aws_cloud_watch_alarm`s' own actions, SNS notifications, Auto Scaling triggers, during a real, defined recurring or one-time window, planned maintenance, a deployment, without stopping the alarms themselves from evaluating and changing state.

## Input properties

<ResponseField name="description" type="string">
  The description of the AlarmMuteRule Optional.
</ResponseField>

<ResponseField name="expire_date" type="string">
  The date, with the same timezone offset as "ScheduleTimezone" after which the alarm mute rule will be expired. Optional.
</ResponseField>

<ResponseField name="mute_targets" type="object">
  Targets to be muted Optional.
  <Expandable title="properties">
    <ResponseField name="alarm_names" type="list(string)" required>
      The alarm names to be mute by the AlarmMuteRule Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the AlarmMuteRule Optional.
</ResponseField>

<ResponseField name="rule" type="object" required>
  The rule for the mute Required.
  <Expandable title="properties">
    <ResponseField name="schedule" type="object" required>
      Schedule for the mute to be active Required.
      <Expandable title="properties">
        <ResponseField name="duration" type="string" required>
          The duration of the schedule when it triggers Required.
        </ResponseField>
        <ResponseField name="expression" type="string" required>
          The expression of the schedule Required.
        </ResponseField>
        <ResponseField name="timezone" type="string">
          The timezone of the schedule Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="start_date" type="string">
  The date, with the same timezone offset as "ScheduleTimezone", after which the alarm mute rule will become active. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

  </Expandable>
</ResponseField>

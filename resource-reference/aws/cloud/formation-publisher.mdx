`aws_cloud_formation_publisher` registers a real account as a CloudFormation Registry publisher, verified against a linked Bitbucket, GitHub, or GitLab identity, the prerequisite before that account can publish a resource type or module to the public CloudFormation Registry for other accounts to use.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation publisher"})

    		ubx.Resource(cloud.FormationPublisher, "example", cloud.FormationPublisherConfig{
    			AcceptTermsAndConditions: true,
    			ConnectionArn:            "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accept_terms_and_conditions" type="bool" required>
  Whether you accept the terms and conditions for publishing extensions in the CloudFormation registry. You must accept the terms and conditions in order to publish public extensions to the CloudFormation registry. The terms and conditions can be found at https://cloudformation-registry-documents.s3.amazonaws.com/Terms_and_Conditions_for_AWS_CloudFormation_Registry_Publishers.pdf Required.
</ResponseField>

<ResponseField name="connection_arn" type="string">
  If you are using a Bitbucket or GitHub account for identity verification, the Amazon Resource Name (ARN) for your connection to that account. Optional.
</ResponseField>

## Output properties

<ResponseField name="identity_provider" type="string">
  The type of account used as the identity provider when registering this publisher with CloudFormation. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="publisher_id" type="string">
  The reserved publisher id for this type, or the publisher id assigned by CloudFormation for publishing in this region. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="publisher_profile" type="string">
  The URL to the publisher's profile with the identity provider. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="publisher_status" type="string">
  Whether the publisher is verified. Computed by AWS after `ship`.
</ResponseField>

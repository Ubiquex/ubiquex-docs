`aws_cloud_front_origin_request_policy` defines what values, headers, cookies, query strings, CloudFront actually forwards to the origin on a cache miss, kept separate from an `aws_cloud_front_cache_policy` so what's cached and what's sent to origin can be controlled independently.

## Input properties

<ResponseField name="origin_request_policy_config" type="object" required>
  An origin request policy configuration. This configuration determines the values that CloudFront includes in requests that it sends to the origin. Each request that CloudFront sends to the origin includes the following: + The request body and the URL path (without the domain name) from the viewer request. + The headers that CloudFront automatically includes in every origin request, including ``Host``, ``User-Agent``, and ``X-Amz-Cf-Id``. + All HTTP headers, cookies, and URL query strings that are specified in the cache policy or the origin request policy. These can include items from the viewer request and, in the case of headers, additional ones that are added by CloudFront. CloudFront sends a request when it can't find an object in its cache that matches the request. If you want to send values to the origin and also include them in the cache key, use ``CachePolicy``. Required.
  <Expandable title="properties">
    <ResponseField name="comment" type="string">
      A comment to describe the origin request policy. The comment cannot be longer than 128 characters. Optional.
    </ResponseField>
    <ResponseField name="cookies_config" type="object" required>
      An object that determines whether any cookies in viewer requests (and if so, which cookies) are included in requests that CloudFront sends to the origin. Required.
      <Expandable title="properties">
        <ResponseField name="cookie_behavior" type="string" required>
          Determines whether cookies in viewer requests are included in requests that CloudFront sends to the origin. Valid values are: + ``none``  --  No cookies in viewer requests are included in requests that CloudFront sends to the origin. Even when this field is set to ``none``, any cookies that are listed in a ``CachePolicy``*are* included in origin requests. + ``whitelist``  --  Only the cookies in viewer requests that are listed in the ``CookieNames`` type are included in requests that CloudFront sends to the origin. + ``all``  --  All cookies in viewer requests are included in requests that CloudFront sends to the origin. + ``allExcept``  --  All cookies in viewer requests are included in requests that CloudFront sends to the origin, *except* for those listed in the ``CookieNames`` type, which are not included. Required.
        </ResponseField>
        <ResponseField name="cookies" type="list(string)">
          Contains a list of cookie names. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="headers_config" type="object" required>
      An object that determines whether any HTTP headers (and if so, which headers) are included in requests that CloudFront sends to the origin. Required.
      <Expandable title="properties">
        <ResponseField name="header_behavior" type="string" required>
          Determines whether any HTTP headers are included in requests that CloudFront sends to the origin. Valid values are: + ``none``  --  No HTTP headers in viewer requests are included in requests that CloudFront sends to the origin. Even when this field is set to ``none``, any headers that are listed in a ``CachePolicy``*are* included in origin requests. + ``whitelist``  --  Only the HTTP headers that are listed in the ``Headers`` type are included in requests that CloudFront sends to the origin. + ``allViewer``  --  All HTTP headers in viewer requests are included in requests that CloudFront sends to the origin. + ``allViewerAndWhitelistCloudFront``  --  All HTTP headers in viewer requests and the additional CloudFront headers that are listed in the ``Headers`` type are included in requests that CloudFront sends to the origin. The additional headers are added by CloudFront. + ``allExcept``  --  All HTTP headers in viewer requests are included in requests that CloudFront sends to the origin, *except* for those listed in the ``Headers`` type, which are not included. Required.
        </ResponseField>

      </Expandable>

      A unique name to identify the origin request policy. Required.
    </ResponseField>

Required.

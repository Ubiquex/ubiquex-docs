`aws_cloud_front_vpc_origin` connects an `aws_cloud_front_distribution` directly to an Application Load Balancer, Network Load Balancer, or EC2 instance in a private VPC subnet through an AWS-managed ENI, so the real origin never needs a public IP or to be reachable from the open internet at all.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cloud "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cloud"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own front vpc origin"})

    		ubx.Resource(cloud.FrontVpcOrigin, "example", cloud.FrontVpcOriginConfig{
    			VpcOriginEndpointConfig: map[string]any{"name": "example-name"},
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="tags" type="list(object)">
  A complex type that contains zero or more ``Tag`` elements. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to the CloudFront VPC origin, used for metadata and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_origin_endpoint_config" type="object" required>
  An Amazon CloudFront VPC origin endpoint configuration. Required.
  <Expandable title="properties">
    <ResponseField name="arn" type="string" required>
      The ARN of the CloudFront VPC origin endpoint configuration. Required.
    </ResponseField>
    <ResponseField name="httpport" type="number">
      The HTTP port for the CloudFront VPC origin endpoint configuration. The default value is ``80``. Optional.
    </ResponseField>
    <ResponseField name="httpsport" type="number">
      The HTTPS port of the CloudFront VPC origin endpoint configuration. The default value is ``443``. Optional.
    </ResponseField>
    <ResponseField name="ip_address_type" type="string">
      Specifies whether the CloudFront VPC origin endpoint uses IPv4 or IPv6 addresses, with allowed values 'IPv4' or 'IPv6'. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string" required>
      The name of the CloudFront VPC origin endpoint configuration. Required.
    </ResponseField>
    <ResponseField name="origin_protocol_policy" type="string">
      The origin protocol policy for the CloudFront VPC origin endpoint configuration. Optional.
    </ResponseField>
    <ResponseField name="origin_sslprotocols" type="list(string)">
      Specifies the minimum SSL/TLS protocol that CloudFront uses when connecting to your origin over HTTPS. Valid values include ``SSLv3``, ``TLSv1``, ``TLSv1.1``, and ``TLSv1.2``. For more information, see [Minimum Origin SSL Protocol](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/DownloadDistValuesOrigin.html#DownloadDistValuesOriginSSLProtocols) in the *Amazon CloudFront Developer Guide*. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The account ID of the AWS account that owns the CloudFront VPC origin, automatically populated by CloudFront and read-only. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) uniquely identifying this CloudFront VPC origin, automatically generated by AWS upon creation and used to reference the origin in other AWS services and IAM policies. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_time" type="string">
  The date and time when the CloudFront VPC origin was created, returned as a read-only string. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to the VPC origin, used to reference this origin when configuring CloudFront distributions. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="last_modified_time" type="string">
  The date and time when the CloudFront VPC origin was last modified. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The current deployment status of the CloudFront VPC origin, such as 'InProgress' or 'Deployed', indicating whether the origin is fully provisioned and ready for use. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

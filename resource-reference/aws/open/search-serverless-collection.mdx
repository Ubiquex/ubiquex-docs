`aws_open_search_serverless_collection` creates a real OpenSearch Serverless collection, a set of indexes for search, time-series, or vector-search workloads that scales its own OpenSearch Compute Units automatically without cluster management.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	open "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/open"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own search serverless collection"})

    		ubx.Resource(open.SearchServerlessCollection, "example", open.SearchServerlessCollectionConfig{
    			Name:                "example",
    			CollectionGroupName: "example-collection-group-name",
    			DeletionProtection:  "example",
    			Description:         "Managed by ubx.",
    			EncryptionConfig:    map[string]any{"awsowned_key": true},
    			StandbyReplicas:     "example",
    			Tags:                []map[string]any{{"key": "example"}},
    			Type:                "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="collection_group_name" type="string">
  The name of the collection group to associate with the collection. Optional.
</ResponseField>

<ResponseField name="deletion_protection" type="string">
  The deletion protection state of the collection Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the collection Optional.
</ResponseField>

<ResponseField name="encryption_config" type="object">
  Encryption settings for the collection Optional.
  <Expandable title="properties">
    <ResponseField name="awsowned_key" type="bool">
      Indicates whether to use an AWS owned key for encryption. Optional.
    </ResponseField>
    <ResponseField name="kms_key_arn" type="string">
      Key Management Service key used to encrypt the collection. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the collection. The name must meet the following criteria: Unique to your account and AWS Region Starts with a lowercase letter Contains only lowercase letters a-z, the numbers 0-9 and the hyphen (-) Contains between 3 and 64 characters Required.
</ResponseField>

<ResponseField name="standby_replicas" type="string">
  The possible standby replicas for the collection Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  List of tags to be added to the resource Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A tag key is a case-sensitive string up to 128 characters (and cannot start with 'aws:') that, when paired with a tag value, attaches metadata to the OpenSearch Serverless collection for management and identification purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag attached to the OpenSearch Serverless collection, allowing you to categorize and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The possible types for the collection Optional.
</ResponseField>

<ResponseField name="vector_options" type="object">
  Vector search configuration options for the collection Optional.
  <Expandable title="properties">
    <ResponseField name="serverless_vector_acceleration" type="string">
      Indicates whether GPU acceleration is enabled for vector indexing Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the collection. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="collection_endpoint" type="string">

<ResponseField name="fips_endpoints" type="object">

    <ResponseField name="collection_endpoint" type="string">

    <ResponseField name="dashboard_endpoint" type="string">
      The FIPS-compliant URL endpoint for accessing the OpenSearch Dashboards (formerly Kibana) interface for the OpenSearch Serverless collection. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_open_search_serverless_security_policy` defines a real network or encryption policy, which VPCs or IPs can reach an `aws_open_search_serverless_collection`, or which KMS key encrypts it, OpenSearch Serverless's own infrastructure-level security layer distinct from its data-access policies.

    			Type:        "example",

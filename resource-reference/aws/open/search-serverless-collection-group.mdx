`aws_open_search_serverless_collection_group` creates a real group of `aws_open_search_serverless_collection`s that share OpenSearch Compute Units at the group level, even across collections encrypted with different KMS keys, reducing cost versus provisioning capacity per collection. Collection groups are a recent addition to OpenSearch Serverless's next-generation architecture, introduced in February 2026.

## Input properties

<ResponseField name="capacity_limits" type="object">
  Defines the maximum indexing and search capacity in OpenSearch Compute Units (OCUs) that the collection group is allowed to use, effectively limiting the total capacity available to all collections within the group. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="max_indexing_capacity_in_ocu" type="number">
      The maximum indexing capacity for collections in the group. Optional.
    </ResponseField>
    <ResponseField name="max_search_capacity_in_ocu" type="number">
      The maximum search capacity for collections in the group. Optional.
    </ResponseField>
    <ResponseField name="min_indexing_capacity_in_ocu" type="number">
      The minimum indexing capacity for collections in the group. Optional.
    </ResponseField>
    <ResponseField name="min_search_capacity_in_ocu" type="number">
      The minimum search capacity for collections in the group. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the collection group. Optional.
</ResponseField>

<ResponseField name="generation" type="string">
  The generation of Amazon OpenSearch Serverless for the collection group. Valid values are CLASSIC and NEXTGEN. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the collection group. Required.
</ResponseField>

<ResponseField name="standby_replicas" type="string" required>

`aws_storage_gateway_tape_pool` defines a real, custom storage class and retention policy, including optional Tape Retention Lock, for virtual tapes archived through a Storage Gateway Tape Gateway, controlling which S3 storage tier, Glacier or Glacier Deep Archive, archived tapes are moved into.

## Input properties

<ResponseField name="pool_name" type="string" required>
  The name of the custom tape pool. Required.
</ResponseField>

<ResponseField name="retention_lock_time_in_days" type="number">
  Tape retention lock time in days (up to 36,500 days / 100 years). Optional.
</ResponseField>

<ResponseField name="retention_lock_type" type="string">
  Tape retention lock type. Governance mode allows authorized removal; compliance mode prevents all removal. Optional.
</ResponseField>

<ResponseField name="storage_class" type="string" required>
  The storage class associated with the custom pool (S3 Glacier or S3 Glacier Deep Archive). Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of up to 50 tags for the tape pool. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key (e.g., 'Environment') that names a metadata tag attached to the tape pool. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag associated with the Storage Gateway tape pool, used to organize and identify the resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="pool_arn" type="string">
  The Amazon Resource Name (ARN) of the custom tape pool. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="pool_id" type="string">
  The unique identifier of the custom tape pool, extracted from the ARN. Computed by AWS after `ship`.
</ResponseField>

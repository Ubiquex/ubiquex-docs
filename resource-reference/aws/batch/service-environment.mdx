`aws_batch_service_environment` holds the SageMaker AI-specific configuration, including maximum concurrent training instances, that lets AWS Batch queue, schedule, and prioritize real SageMaker Training jobs using the same queuing engine it uses for containerized batch workloads.

    func main() {

    			ServiceEnvironmentName: "example-service-environment-name",

    		})
    	}))
    }

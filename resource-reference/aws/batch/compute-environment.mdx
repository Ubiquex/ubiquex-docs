`aws_batch_compute_environment` provisions the real compute, EC2, Fargate, or Spot, that AWS Batch runs jobs on, managed or unmanaged, the layer an `aws_batch_job_queue` submits work into once a job is scheduled.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	batch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/batch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own compute environment"})

    		ubx.Resource(batch.ComputeEnvironment, "example", batch.ComputeEnvironmentConfig{
    			Type:                      "example",
    			ComputeEnvironmentName:    "example-compute-environment-name",
    			Context:                   "example",
    			EcsSettings:               map[string]any{"container_insights": "example"},
    			EksConfiguration:          map[string]any{"eks_cluster_arn": "example", "kubernetes_namespace": "example"},
    			ReplaceComputeEnvironment: true,
    			ServiceRole:               "example",
    			State:                     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="compute_environment_name" type="string">
  The name for the AWS Batch compute environment, which must be unique within the region and can contain letters, numbers, hyphens, and underscores; if omitted, AWS CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="context" type="string">
  Optional.
</ResponseField>

<ResponseField name="eks_configuration" type="object">
  Specifies the Amazon EKS cluster and optional Kubernetes namespace that the Batch compute environment uses when it is of type EKS. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="eks_cluster_arn" type="string" required>
      The Amazon Resource Name (ARN) of the Amazon EKS cluster that this compute environment uses to run Batch jobs. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="kubernetes_namespace" type="string" required>
      Specifies the Kubernetes namespace on the Amazon EKS cluster where the AWS Batch compute environment runs its job pods. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="replace_compute_environment" type="bool">
  Specifies whether the compute environment is replaced with a new one when updating this resource, allowing changes to properties that require replacement to take effect. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_role" type="string">
  The ARN of the IAM role that AWS Batch assumes to make calls to other AWS services on your behalf when creating and managing the compute environment (required for managed compute environments). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="state" type="string">
  Specifies whether the compute environment is enabled for job submission, with allowed values 'ENABLED' or 'DISABLED'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

<ResponseField name="type" type="string" required>
  Specifies whether the compute environment is managed or unmanaged by AWS Batch, with valid values being MANAGED or UNMANAGED. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="unmanagedv_cpus" type="number">
  The number of vCPUs to allocate to the unmanaged compute environment, used when the compute environment type is set to UNMANAGED. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="update_policy" type="object">
  Configures the update policy for the compute environment, controlling whether in-progress jobs are terminated and the maximum time to wait for jobs to finish before an update is applied. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="job_execution_timeout_minutes" type="number">
      The maximum time in minutes that a job in the compute environment can run before AWS Batch terminates it when the compute environment's update policy is applied. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="terminate_jobs_on_update" type="bool">
      If true, AWS Batch terminates running jobs in the compute environment whenever the compute environment is updated. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

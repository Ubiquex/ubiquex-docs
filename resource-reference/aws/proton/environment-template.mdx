`aws_proton_environment_template` defines a real, reusable infrastructure template, the shared networking, cluster, or platform resources that one or more services deploy onto, in AWS Proton's own template-driven provisioning model. AWS Proton is being discontinued: closed to new customers October 7, 2025, with support ending October 7, 2026, a date roughly a month and a half from now; deployed infrastructure keeps running after that date even though the Proton console and API stop being accessible.

    ```go
    package main

    import (
    	proton "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/proton"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment template"})

    		ubx.Resource(proton.EnvironmentTemplate, "example", proton.EnvironmentTemplateConfig{
    			Name:          "example",
    			Description:   "Managed by ubx.",
    			DisplayName:   "example-display-name",
    			EncryptionKey: "example",
    			Provisioning:  "example",
    			Tags:          []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  &lt;p&gt;A description of the environment template.&lt;/p&gt; Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  &lt;p&gt;The environment template name as displayed in the developer interface.&lt;/p&gt; Optional.
</ResponseField>

<ResponseField name="encryption_key" type="string">
  &lt;p&gt;A customer provided encryption key that Proton uses to encrypt data.&lt;/p&gt; Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the environment template, used to identify it within AWS Proton. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="provisioning" type="string">
  The provisioning engine used for the environment template, which can be either 'CLOUDFORMATION' or 'TERRAFORM'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  &lt;p&gt;An optional list of metadata items that you can associate with the Proton environment template. A tag is a key-value pair.&lt;/p&gt; &lt;p&gt;For more information, see &lt;a href="https://docs.aws.amazon.com/proton/latest/userguide/resources.html"&gt;Proton resources and tagging&lt;/a&gt; in the &lt;i&gt;Proton User Guide&lt;/i&gt;.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Proton environment template, which can be used to categorize and identify the template for cost allocation and management within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

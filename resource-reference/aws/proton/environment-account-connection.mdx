`aws_proton_environment_account_connection` establishes a real cross-account IAM role that lets an AWS Proton management account provision an `aws_proton_environment_template`'s resources into a separate target account, without the target account's own credentials being shared. AWS Proton is being discontinued: it closed to new customers on October 7, 2025, and AWS will end support on October 7, 2026, a date roughly a month and a half from now.

## Example

    ```go
    package main

    import (
    	proton "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/proton"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment account connection"})

    		ubx.Resource(proton.EnvironmentAccountConnection, "example", proton.EnvironmentAccountConnectionConfig{
    			CodebuildRoleArn:     "arn:aws:iam::123456789012:policy/example",
    			ComponentRoleArn:     "arn:aws:iam::123456789012:policy/example",
    			EnvironmentAccountId: "example",
    			EnvironmentName:      "example-environment-name",
    			ManagementAccountId:  "example",
    			RoleArn:              "arn:aws:iam::123456789012:policy/example",
    			Tags:                 []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="codebuild_role_arn" type="string">
  The Amazon Resource Name (ARN) of an IAM service role in the environment account. AWS Proton uses this role to provision infrastructure resources using CodeBuild-based provisioning in the associated environment account. Optional.
</ResponseField>

<ResponseField name="component_role_arn" type="string">
  The Amazon Resource Name (ARN) of the IAM service role that AWS Proton uses when provisioning directly defined components in the associated environment account. It determines the scope of infrastructure that a component can provision in the account. Optional.
</ResponseField>

<ResponseField name="environment_account_id" type="string">
  The environment account that's connected to the environment account connection. Optional.
</ResponseField>

<ResponseField name="environment_name" type="string">
  The name of the AWS Proton environment that's created in the associated management account. Optional.
</ResponseField>

<ResponseField name="management_account_id" type="string">
  The ID of the management account that accepts or rejects the environment account connection. You create an manage the AWS Proton environment in this account. If the management account accepts the environment account connection, AWS Proton can use the associated IAM role to provision environment infrastructure resources in the associated environment account. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The Amazon Resource Name (ARN) of the IAM service role that's created in the environment account. AWS Proton uses this role to provision infrastructure resources in the associated environment account. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  &lt;p&gt;An optional list of metadata items that you can associate with the Proton environment account connection.   <Expandable title="properties">

  </Expandable>
</ResponseField>

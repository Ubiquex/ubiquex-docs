`aws_signer_signing_profile` creates a real, reusable code-signing configuration, its signing platform and certificate validity, that AWS Signer uses to produce a verifiable, tamper-evident signature over deployment artifacts such as Lambda code or IoT firmware.

## Input properties

<ResponseField name="platform_id" type="string" required>
  The platform ID that determines the signing platform (e.g., AWSLambda or Notation) and the cryptographic algorithm used by the signing profile. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="signature_validity_period" type="object">
  Specifies the time period for which signatures generated with this signing profile remain valid, using a period type (days, months, or years) and a numeric value. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      Specifies the time unit (DAYS, MONTHS, or YEARS) for the validity period of signatures generated by this signing profile. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="number">
      The numeric value that, together with the signature_validity_period.type (e.g., DAYS, MONTHS, YEARS), defines how long signatures created with this profile remain valid. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags associated with the signing profile. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A tag key that, with its corresponding value, assigns a user-defined label to the signing profile for easier identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the signing profile, used for categorization and access control in AWS Signer. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this signing profile in AWS Signer. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="profile_name" type="string">
  The unique name of the signing profile, as returned by AWS Signer after the profile is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="profile_version" type="string">
  The version identifier of the signing profile, which automatically changes each time the profile is updated and is used to reference a specific revision of the profile. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="profile_version_arn" type="string">
  Computed after creation, this attribute holds the ARN (Amazon Resource Name) of the specific version of the signing profile, which uniquely identifies that version for use in signing jobs. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

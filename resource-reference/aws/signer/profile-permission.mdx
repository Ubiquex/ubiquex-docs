`aws_signer_profile_permission` grants a real cross-account or service permission to use an `aws_signer_signing_profile`, letting another account or an AWS service like Lambda invoke it to sign code on this account's behalf.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	signer "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/signer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own profile permission"})

    		ubx.Resource(signer.ProfilePermission, "example", signer.ProfilePermissionConfig{
    			Action:         "example",
    			Principal:      "example",
    			ProfileName:    "example-profile-name",
    			StatementId:    "example",
    			ProfileVersion: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="action" type="string" required>
  Specifies the AWS Signer operation (such as 'signer:StartSigningJob' or 'signer:GetSigningProfile') that the principal is allowed to perform on the signing profile. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="principal" type="string" required>
  The AWS account ID or IAM principal (such as an IAM role or user ARN) that is granted signing-profile access by this profile permission. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="profile_name" type="string" required>
  The name of the AWS Signer signing profile to which the permission is granted. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="profile_version" type="string">
  The version of the signing profile to which this cross-account permission is scoped; when omitted, the permission applies without version-specific restriction. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="statement_id" type="string" required>
  A unique identifier for this signing profile permission statement, used to reference the setting in later updates or removal operations. Required. **(AI-inferred)**
</ResponseField>

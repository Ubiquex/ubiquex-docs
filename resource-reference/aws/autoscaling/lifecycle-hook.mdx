`aws_auto_scaling_lifecycle_hook` pauses a real `aws_auto_scaling_auto_scaling_group` instance in a Pending or Terminating state until a custom action, running configuration software or draining connections, completes, instead of the group immediately putting the instance into service or destroying it.

## Example

    			HeartbeatTimeout:      1,
    			LifecycleHookName:     "example-lifecycle-hook-name",
    			NotificationMetadata:  "example",
    			NotificationTargetArn: "arn:aws:iam::123456789012:policy/example",
    			RoleArn:               "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }

## Properties

<ResponseField name="auto_scaling_group_name" type="string" required>
  The name of the Auto Scaling group for the lifecycle hook. Required.
</ResponseField>

<ResponseField name="default_result" type="string">
  The action the Auto Scaling group takes when the lifecycle hook timeout elapses or if an unexpected failure occurs. The valid values are CONTINUE and ABANDON (default). Optional.
</ResponseField>

<ResponseField name="heartbeat_timeout" type="number">
  The maximum time, in seconds, that can elapse before the lifecycle hook times out. The range is from 30 to 7200 seconds. The default value is 3600 seconds (1 hour). If the lifecycle hook times out, Amazon EC2 Auto Scaling performs the action that you specified in the DefaultResult property. Optional.
</ResponseField>

<ResponseField name="lifecycle_hook_name" type="string">
  The name of the lifecycle hook. Optional.
</ResponseField>

<ResponseField name="lifecycle_transition" type="string" required>
  The instance state to which you want to attach the lifecycle hook. Required.
</ResponseField>

<ResponseField name="notification_metadata" type="string">
  Additional information that is included any time Amazon EC2 Auto Scaling sends a message to the notification target. Optional.
</ResponseField>

<ResponseField name="notification_target_arn" type="string">
  The Amazon Resource Name (ARN) of the notification target that Amazon EC2 Auto Scaling uses to notify you when an instance is in the transition state for the lifecycle hook. You can specify an Amazon SQS queue or an Amazon SNS topic. The notification message includes the following information: lifecycle action token, user account ID, Auto Scaling group name, lifecycle hook name, instance ID, lifecycle transition, and notification metadata. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string">
  The ARN of the IAM role that allows the Auto Scaling group to publish to the specified notification target, for example, an Amazon SNS topic or an Amazon SQS queue. Optional.
</ResponseField>

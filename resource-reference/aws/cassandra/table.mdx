---
title: "aws_cassandra_table"
description: "`aws_cassandra_table` creates a real table inside an `aws_cassandra_keyspace`..."
---

`aws_cassandra_table` creates a real table inside an `aws_cassandra_keyspace`, using the same CQL data model and application code an existing Cassandra workload already uses, with Amazon Keyspaces scaling its throughput and storage automatically rather than the caller provisioning nodes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cassandra "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/cassandra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own table"})

    		ubx.Resource(cassandra.Table, "example", cassandra.TableConfig{
    			KeyspaceName:                "example-keyspace-name",
    			PartitionKeyColumns:         []map[string]any{{"column_name": "example-column-name"}},
    			AutoScalingSpecifications:   map[string]any{"read_capacity_auto_scaling": map[string]any{"auto_scaling_disabled": true}},
    			BillingMode:                 map[string]any{"mode": "example"},
    			CdcSpecification:            map[string]any{"status": "example"},
    			ClientSideTimestampsEnabled: true,
    			ClusteringKeyColumns:        []map[string]any{{"column": map[string]any{"column_name": "example-column-name"}}},
    			DefaultTimeToLive:           1,
    		})
    	}))
    }
    ```

        ))

`aws_cassandra_type` is a user-defined type, a named grouping of fields and data types usable as a single column, created inside an `aws_cassandra_keyspace` with CQL's `CREATE TYPE` and available to every `aws_cassandra_table` in that same keyspace.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cassandra "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cassandra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own type"})

    		ubx.Resource(cassandra.Type, "example", cassandra.TypeConfig{
    			Fields:       []map[string]any{{"field_name": "example-field-name"}},
    			KeyspaceName: "example-keyspace-name",
    			TypeName:     "example-type-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="fields" type="list(object)" required>
  Field definitions of the User-Defined Type Required.
  <Expandable title="properties">
    <ResponseField name="field_name" type="string">
      The name of a field within a user-defined Cassandra type in Amazon Keyspaces, defining the structure of the type. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="field_type" type="string">
      The Cassandra data type assigned to this field within the custom type definition, specified as a string such as 'int' or 'text'. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="keyspace_name" type="string" required>
  Name of the Keyspace which contains the User-Defined Type. Required.
</ResponseField>

<ResponseField name="type_name" type="string" required>
  Name of the User-Defined Type. Required.
</ResponseField>

## Output properties

<ResponseField name="direct_parent_types" type="list(string)">
  List of parent User-Defined Types that directly reference the User-Defined Type in their fields. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="direct_referring_tables" type="list(string)">
  List of Tables that directly reference the User-Defined Type in their columns. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="keyspace_arn" type="string">
  ARN of the Keyspace which contains the User-Defined Type. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="last_modified_timestamp" type="number">
  Timestamp of the last time the User-Defined Type's meta data was modified. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="max_nesting_depth" type="number">
  Maximum nesting depth of the User-Defined Type across the field types. Computed by AWS after `ship`.
</ResponseField>

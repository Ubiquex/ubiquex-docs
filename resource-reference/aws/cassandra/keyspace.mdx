`aws_cassandra_keyspace` creates the top-level namespace in Amazon Keyspaces (for Apache Cassandra), the serverless, Cassandra-compatible database, that every `aws_cassandra_table` and user-defined `aws_cassandra_type` in it belongs to.

## Properties

<ResponseField name="client_side_timestamps_enabled" type="bool">
  Indicates whether client-side timestamps are enabled (true) or disabled (false) for all tables in the keyspace. To add a Region to a single-Region keyspace with at least one table, the value must be set to true. After you enabled client-side timestamps for a table, you can’t disable it again. Optional.
</ResponseField>

<ResponseField name="keyspace_name" type="string">
  Name for Cassandra keyspace Optional.
</ResponseField>

<ResponseField name="replication_specification" type="object">
  Specifies the replication strategy (single or multi-Region) and the list of Regions for a multi-Region Amazon Keyspaces keyspace. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="region_list" type="list(string)">
      A list of AWS regions where the keyspace is replicated for Multi-Region Replication, enabling data availability across those regions. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="replication_strategy" type="string">
      Specifies the replication strategy for the keyspace, either SINGLE_REGION for single-region replication or MULTI_REGION for replicating data across multiple AWS regions. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Assigns a list of key-value metadata tags to the Cassandra keyspace, which can be used for categorization and cost tracking. Optional. **(AI-inferred)**

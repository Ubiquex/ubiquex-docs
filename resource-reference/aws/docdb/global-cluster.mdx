`aws_doc_db_global_cluster` links `aws_doc_db_dbcluster`s across multiple AWS Regions with fast, storage-based replication, real cross-Region disaster recovery and low-latency global reads that a single-Region cluster can't provide on its own.

## Input properties

<ResponseField name="deletion_protection" type="bool">
  Indicates whether the global cluster has deletion protection enabled. The global cluster can't be deleted when deletion protection is enabled. Optional.
</ResponseField>

<ResponseField name="engine" type="string">
  The database engine to use for this global cluster. Optional.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The engine version to use for this global cluster. Optional.
</ResponseField>

<ResponseField name="global_cluster_identifier" type="string" required>
  The cluster identifier of the global cluster. Required.
</ResponseField>

<ResponseField name="source_dbcluster_identifier" type="any">
  The Amazon Resource Name (ARN) to use as the primary cluster of the global cluster. You may also choose to instead specify the DBClusterIdentifier. If you provide a value for this parameter, don't specify values for the following settings because Amazon DocumentDB uses the values from the specified source DB cluster: Engine, EngineVersion, StorageEncrypted Optional.
</ResponseField>

<ResponseField name="storage_encrypted" type="bool">
  Indicates whether the global cluster has storage encryption enabled. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to be assigned to the Amazon DocumentDB resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a user-defined tag attached to the Amazon DocumentDB global cluster, used for metadata, cost allocation, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the DocumentDB global cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="global_cluster_arn" type="string">
  The Amazon Resource Name (ARN) for the global cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="global_cluster_resource_id" type="string">
  The AWS Region-unique, immutable identifier for the global database cluster. This identifier is found in AWS CloudTrail log entries whenever the AWS KMS key for the DB cluster is accessed. Computed by AWS after `ship`.
</ResponseField>

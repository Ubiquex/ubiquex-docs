`aws_doc_db_dbinstance` adds real compute capacity to an `aws_doc_db_dbcluster`, the actual instance that serves reads and, for the primary instance, writes against the cluster's own shared storage.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	docdb "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/docdb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dbinstance"})

    		ubx.Resource(docdb.Dbinstance, "example", docdb.DbinstanceConfig{
    			DbclusterIdentifier:        "example",
    			DbinstanceClass:            "example",
    			AutoMinorVersionUpgrade:    true,
    			AvailabilityZone:           "example",
    			CacertificateIdentifier:    "example",
    			CertificateRotationRestart: true,
    			DbinstanceIdentifier:       "example",
    			EnablePerformanceInsights:  true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="auto_minor_version_upgrade" type="bool">
  Indicates whether minor engine version upgrades are applied automatically to the DB instance during its maintenance window. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="availability_zone" type="string">
  Specifies the Availability Zone (AZ) where the Amazon DocumentDB DB instance is provisioned, for example, us-east-1a. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="cacertificate_identifier" type="string">
  Specifies the identifier of the CA certificate used for the DocumentDB DB instance's server certificate, allowing you to rotate the certificate used for TLS connections. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_rotation_restart" type="bool">
  Whether the DocumentDB instance is restarted automatically when the CA certificate for the instance is rotated, allowing the new certificate to take effect without manual action. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbcluster_identifier" type="string" required>
  The identifier of the DocumentDB cluster this instance will belong to, defining the cluster in which the instance is created and replicated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbinstance_class" type="string" required>
  The compute and memory capacity class of the Amazon DocumentDB instance (e.g., db.r5.large), which determines its performance characteristics and pricing. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbinstance_identifier" type="string">
  The user-supplied unique identifier for the DocumentDB DB instance, which must be unique within an AWS account and Region; if not provided, CloudFormation generates one automatically. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_performance_insights" type="bool">
  A boolean flag that when true enables Performance Insights, a database performance monitoring and tuning feature, for the Amazon DocumentDB DB instance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">
  Specifies the weekly time range (in UTC) during which Amazon DocumentDB performs system maintenance on this DB instance, using the format ddd:hh24:mi-ddd:hh24:mi (e.g., sun:05:00-sun:06:00). Optional. **(AI-inferred)**
</ResponseField>

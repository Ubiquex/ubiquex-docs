`aws_bedrock_agent_core_code_interpreter_custom` configures AgentCore's Code Interpreter with a caller's own network mode (sandboxed, public internet, or a specific VPC) and execution role, letting an agent write and run real Python, JavaScript, or TypeScript code with access scoped beyond AgentCore's own default isolated sandbox.

          The ARN of the AWS Secrets Manager secret that stores the certificate for a custom certificate location, used by the AWS Bedrock Agent Core code interpreter custom resource to secure TLS connections. Optional; if omitted, computed by AWS. **(AI-inferred)**

`aws_bedrock_agent_core_workload_identity` ties a real AgentCore agent's own identity to an enterprise identity provider, Cognito, Okta, Entra ID, or Auth0, so the agent authenticates to external services as a real, governed identity rather than a shared, static credential, regardless of whether it runs on ECS, EKS, Lambda, or on-premises.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	bedrockagentcore "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/bedrockagentcore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workload identity"})

    		ubx.Resource(bedrockagentcore.WorkloadIdentity, "example", bedrockagentcore.WorkloadIdentityConfig{
    			Name:                            "example",
    			AllowedResourceOauth2ReturnUrls: []string{"example"},
    			Tags:                            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx

    def describe():
        ubx.intent("example own workload identity")

            tags=[WorkloadIdentity_Tags(key="example")],

## Input properties

<ResponseField name="allowed_resource_oauth2_return_urls" type="list(string)">
  The list of allowed OAuth2 return URLs for resources associated with this workload identity. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the workload identity. The name must be unique within your account. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_time" type="number">

<ResponseField name="workload_identity_arn" type="string">
  The Amazon Resource Name (ARN) of the workload identity. Computed by AWS after `ship`.

`aws_bedrock_agent_core_browser_profile` defines a real, reusable configuration, session persistence, network access, that an `aws_bedrock_agent_core_browser_custom` uses when an AgentCore agent needs to control a real, isolated browser session.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	bedrockagentcore "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/bedrockagentcore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent core browser profile"})

    		ubx.Resource(bedrockagentcore.BrowserProfile, "example", bedrockagentcore.BrowserProfileConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Tags:        "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the browser profile. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the browser profile. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  A map of tag keys and values Optional.
</ResponseField>

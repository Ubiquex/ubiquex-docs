`aws_bedrock_agent_core_policy_engine` creates a real, centralized governance layer for AgentCore that gates every agent-to-tool call, authored in natural language and automatically converted to Cedar, the same open-source policy language `aws_verified_permissions_policy_store` uses, evaluated outside the agent's own code so a policy change doesn't require redeploying the agent.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	bedrockagentcore "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/bedrockagentcore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent core policy engine"})

    		ubx.Resource(bedrockagentcore.PolicyEngine, "example", bedrockagentcore.PolicyEngineConfig{
    			Name:             "example",
    			Description:      "Managed by ubx.",
    			EncryptionKeyArn: "arn:aws:iam::123456789012:policy/example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A human-readable description of the policy engine's purpose and scope Optional.
</ResponseField>

<ResponseField name="encryption_key_arn" type="string">
  The ARN of the KMS key used to encrypt the policy engine data Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The customer-assigned immutable name for the policy engine Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to assign to the policy engine. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

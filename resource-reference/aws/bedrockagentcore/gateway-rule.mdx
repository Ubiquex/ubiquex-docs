`aws_bedrock_agent_core_gateway_rule` defines the OAuth- or IAM-based condition an `aws_bedrock_agent_core_gateway_rate_limit` actually applies under, the real matching logic a rate limit's request, token, and connection caps are scoped by.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

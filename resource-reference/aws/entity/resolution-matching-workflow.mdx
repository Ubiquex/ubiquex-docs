`aws_entity_resolution_matching_workflow` is the real, actual sequence AWS Entity Resolution runs to match records from an `aws_entity_resolution_schema_mapping`-defined input, using rule-based, machine-learning, or data-service-provider matching, and write consolidated, linked output to S3.

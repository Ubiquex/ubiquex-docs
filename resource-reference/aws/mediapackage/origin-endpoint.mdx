`aws_media_package_origin_endpoint` defines a real packaging configuration, HLS, DASH, CMAF, and more, on an `aws_media_package_channel`, the endpoint players actually request the packaged stream from.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own origin endpoint"})

    		ubx.Resource(mediapackage.OriginEndpoint, "example", mediapackage.OriginEndpointConfig{

---

`aws_security_hub_insight` defines a real, saved query, a grouping attribute and filter criteria, that Security Hub evaluates against current findings to surface a specific pattern, such as the resources with the most high-severity findings, rather than being re-built by hand each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hub insight"})

    		ubx.Resource(security.HubInsight, "example", security.HubInsightConfig{
    			Filters:          map[string]any{"aws_account_id": []map[string]any{{"comparison": "example"}}},
    			GroupByAttribute: "example",
    			Name:             "example",
    		})
    	}))
    }
    ```

`aws_security_agent_application` registers a real application, its source repository and deployed endpoints, with AWS Security Agent, the target that `aws_security_agent_pentest`s and code reviews are run against. This is part of the same recently launched (GA March 2026) autonomous penetration-testing service as `aws_security_agent_agent_space`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent application"})

    		ubx.Resource(security.AgentApplication, "example", security.AgentApplicationConfig{
    			DefaultKmsKeyId: "example",
    			RoleArn:         "arn:aws:iam::123456789012:policy/example",
    			Tags:            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

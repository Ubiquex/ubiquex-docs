`aws_security_agent_artifact` stores a real output, a report, a scan result, produced by AWS Security Agent's own penetration test or code review of an `aws_security_agent_application`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent artifact"})

    		ubx.Resource(security.AgentArtifact, "example", security.AgentArtifactConfig{
    			AgentSpaceId:    "example",
    			ArtifactType:    "example",
    			FileName:        "example-file-name",
    			ArtifactContent: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="agent_space_id" type="string" required>
  The unique identifier of the agent space to add the artifact to. Required.
</ResponseField>

<ResponseField name="artifact_content" type="string">
  The binary content of the artifact to upload, encoded as a Base64 string. Optional.
</ResponseField>

<ResponseField name="artifact_type" type="string" required>
  The file type of the artifact. Required.
</ResponseField>

<ResponseField name="file_name" type="string" required>
  The file name of the artifact. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the artifact. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="artifact_id" type="string">
  The unique identifier assigned to the uploaded artifact. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time the artifact was last updated, in ISO 8601 format. Computed by AWS after `ship`.
</ResponseField>

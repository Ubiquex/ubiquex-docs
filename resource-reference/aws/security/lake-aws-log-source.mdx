`aws_security_lake_aws_log_source` enables collection of a specific AWS log or event type, CloudTrail, VPC Flow Logs, Route 53 resolver logs, into an `aws_security_lake_data_lake`, the resource that actually turns on ingestion for that one source rather than the data lake as a whole.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own lake aws log source"})

    		ubx.Resource(security.LakeAwsLogSource, "ci-runner", security.LakeAwsLogSourceConfig{
    			DataLakeArn:   "arn:aws:iam::123456789012:policy/ci",
    			SourceName:    "example-source-name",
    			SourceVersion: "example",
    			Accounts:      []string{"example"},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="accounts" type="list(string)">
  AWS account where you want to collect logs from. Optional.
</ResponseField>

<ResponseField name="data_lake_arn" type="string" required>
  The ARN for the data lake. Required.
</ResponseField>

<ResponseField name="source_name" type="string" required>
  The name for a AWS source. This must be a Regionally unique value. Required.
</ResponseField>

<ResponseField name="source_version" type="string" required>
  The version for a AWS source. This must be a Regionally unique value. Required.
</ResponseField>

`aws_security_lake_subscriber_notification` configures real, automatic notifications, through SQS or an HTTPS endpoint, that tell an `aws_security_lake_subscriber` when new data matching its subscription has landed in the data lake, rather than the subscriber having to poll for it.

    		})
    	}))
    }

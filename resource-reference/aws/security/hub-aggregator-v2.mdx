`aws_security_hub_aggregator_v2` configures real cross-Region and cross-account aggregation of findings and risk data under Security Hub's next-generation (HubV2) model, the V2 counterpart to the original `aws_security_hub_finding_aggregator`. Security Hub's major relaunch, unifying findings across GuardDuty, Inspector, Macie, and Security Hub CSPM with near-real-time risk analytics, was announced at re:Invent in December 2025, roughly eight months ago.

## Input properties

<ResponseField name="linked_regions" type="list(string)" required>
  The list of included Regions Required.
</ResponseField>

<ResponseField name="region_linking_mode" type="string" required>
  Indicates to link a list of included Regions Required.
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with the Security Hub V2 resource. Optional.
</ResponseField>

## Output properties

<ResponseField name="aggregation_region" type="string">
  The AWS Region to which Security Hub aggregates findings from all linked Regions in the cross-Region aggregation configuration. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="aggregator_v2_arn" type="string">
  The ARN of the AggregatorV2 being created and assigned as the unique identifier Computed by AWS after `ship`.
</ResponseField>

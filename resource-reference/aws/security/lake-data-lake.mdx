`aws_security_lake_data_lake` creates a real, per-Region Security Lake data lake, centralizing an account or organization's security log and event data from AWS services and other sources into a single, OCSF-normalized S3-based store.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lake data lake"})

    		ubx.Resource(security.LakeDataLake, "example", security.LakeDataLakeConfig{
    			EncryptionConfiguration:  map[string]any{"kms_key_id": "example"},
    			LifecycleConfiguration:   map[string]any{"expiration": map[string]any{"days": 1}},
    			MetaStoreManagerRoleArn:  "arn:aws:iam::123456789012:policy/example",
    			ReplicationConfiguration: map[string]any{"regions": []string{"example"}},
    			Tags:                     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="encryption_configuration" type="object">
  Provides encryption details of Amazon Security Lake object. Optional.
  <Expandable title="properties">
    <ResponseField name="kms_key_id" type="string">
      The id of KMS encryption key used by Amazon Security Lake to encrypt the Security Lake object. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="lifecycle_configuration" type="object">
  Provides lifecycle details of Amazon Security Lake object. Optional.
  <Expandable title="properties">
    <ResponseField name="expiration" type="object">
      Provides data expiration details of Amazon Security Lake object. Optional.
      <Expandable title="properties">
        <ResponseField name="days" type="number">
          Number of days before data expires in the Amazon Security Lake object. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="transitions" type="list(object)">
      Provides data storage transition details of Amazon Security Lake object. Optional.
      <Expandable title="properties">
        <ResponseField name="days" type="number">
          The number of days after object creation that the lifecycle transition moves the data to the storage class defined in the parent transition rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="storage_class" type="string">
          The S3 storage class (e.g., STANDARD_IA, GLACIER) that this lifecycle transition moves the data lake's objects to after the specified transition_days. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta_store_manager_role_arn" type="string">
  The Amazon Resource Name (ARN) used to index AWS Glue table partitions that are generated by the ingestion and normalization of AWS log sources and custom sources. Optional.
</ResponseField>

<ResponseField name="replication_configuration" type="object">
  Provides replication details of Amazon Security Lake object. Optional.
  <Expandable title="properties">
    <ResponseField name="regions" type="list(string)">
      Replication enables automatic, asynchronous copying of objects across Amazon S3 buckets. Amazon S3 buckets that are configured for object replication can be owned by the same AWS account or by different accounts. You can replicate objects to a single destination bucket or to multiple destination buckets. The destination buckets can be in different AWS Regions or within the same Region as the source bucket. Optional.
    </ResponseField>
    <ResponseField name="role_arn" type="string">
      Replication settings for the Amazon S3 buckets. This parameter uses the AWS Identity and Access Management (IAM) role you created that is managed by Security Lake, to ensure the replication setting is correct. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag objects (each with a key and value) assigned to the AWS Security Lake data lake, used for metadata organization, cost allocation, and access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag in the Tags map that attaches user-defined metadata to the AWS Security Lake data lake, commonly used for cost allocation and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag assigned to the AWS Security Lake data lake, used to attach arbitrary metadata for resource management and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

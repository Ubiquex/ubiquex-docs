`aws_security_hub_connector` connects a real external, non-AWS security tool's findings into the original Security Hub model, so third-party findings appear alongside AWS-native ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connector"})

    		ubx.Resource(securityhub.Connector, "example", securityhub.ConnectorConfig{
    			Name:        "example",
    			Provider:    map[string]any{"azure": map[string]any{"awsconfig_connector_arn": "example", "azure_regions": []string{"example"}, "scope_configuration": map[string]any{"scope_type": "example"}}},
    			Description: "Managed by ubx.",
    			Tags:        "example",
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.securityhub import Connector, ConnectorConfig
    from ubx.aws.securityhub.connector import Connector_Provider, Connector_Provider_Azure, Connector_Provider_Azure_ScopeConfiguration

    def describe():
        ubx.intent("example own connector")

        ubx.resource(Connector, "example", ConnectorConfig(
            name="example",
            provider=Connector_Provider(azure=Connector_Provider_Azure(awsconfig_connector_arn="example", azure_regions=["example"], scope_configuration=Connector_Provider_Azure_ScopeConfiguration(scope_type="example"))),
            description="Managed by ubx.",
            tags="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the connector. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the connector. Required.
</ResponseField>

<ResponseField name="provider" type="object" required>
  Specifies the provider configuration for the Security Hub connector, including the provider type (for example, AWS or a partner) that determines how the connector is set up to ingest findings into Security Hub. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="azure" type="object" required>
      The configuration for connecting to an Azure environment. Required.
      <Expandable title="properties">
        <ResponseField name="awsconfig_connector_arn" type="string" required>
          The ARN of the multi-cloud configuration connector used to establish the connection to Azure. Required.
        </ResponseField>
        <ResponseField name="azure_regions" type="list(string)" required>
          The list of Azure regions to monitor. Required.
        </ResponseField>
        <ResponseField name="scope_configuration" type="object" required>
          The scope configuration for an Azure connector, defining the tenant or subscription scope. Required.
          <Expandable title="properties">
            <ResponseField name="scope_type" type="string" required>
              The type of scope. Valid values are ``tenant`` and ``subscription``. Required.
            </ResponseField>
            <ResponseField name="scope_values" type="list(string)">
              The list of scope values, such as subscription IDs, when the scope type is ``subscription``. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  A key-value pair to associate with a resource. Optional.
</ResponseField>

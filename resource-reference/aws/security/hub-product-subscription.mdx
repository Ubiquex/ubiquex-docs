`aws_security_hub_product_subscription` subscribes an `aws_security_hub_hub` to receive findings from a specific third-party security product in the AWS Partner Network, so that product's own findings appear alongside AWS-native ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hub product subscription"})

    		ubx.Resource(security.HubProductSubscription, "example", security.HubProductSubscriptionConfig{
    			ProductArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.aws.security import HubProductSubscription, HubProductSubscriptionConfig

    def describe():

            product_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="product_arn" type="string" required>
  The generic ARN of the product being subscribed to Required.
</ResponseField>

## Output properties

<ResponseField name="product_subscription_arn" type="string">
  The ARN of the product subscription for the account Computed by AWS after `ship`.
</ResponseField>

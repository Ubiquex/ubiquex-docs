`aws_security_hub_product_subscription` subscribes an `aws_security_hub_hub` to receive findings from a specific third-party security product in the AWS Partner Network, so that product's own findings appear alongside AWS-native ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own hub product subscription"})

    		ubx.Resource(security.HubProductSubscription, "ci-runner", security.HubProductSubscriptionConfig{
    			ProductArn: "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="product_arn" type="string" required>
  The generic ARN of the product being subscribed to Required.
</ResponseField>

## Output properties

<ResponseField name="product_subscription_arn" type="string">
  The ARN of the product subscription for the account Computed by AWS after `ship`.
</ResponseField>

`aws_security_group` creates a real, stateful virtual firewall scoped to specific EC2 instances or other ENI-attached resources, evaluating all its allow rules regardless of order, distinct from a `aws_network_acl`'s stateless, subnet-wide, ordered rule evaluation.

## Input properties

<ResponseField name="group_description" type="string" required>
  A description for the security group. Required.
</ResponseField>

<ResponseField name="group_name" type="string">
  The name of the security group. Optional.
</ResponseField>

<ResponseField name="security_group_egress" type="list(object)">
  [VPC only] The outbound rules associated with the security group. There is a short interruption during which you cannot connect to the security group. Optional.
  <Expandable title="properties">
    <ResponseField name="cidr_ip" type="string">
      The IPv4 address range, in CIDR form, that is allowed as the destination for outbound traffic in this security group egress rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="cidr_ipv6" type="string">
      The destination IPv6 CIDR block for the outbound traffic allowed by this security group egress rule, such as ::/0 for all IPv6 addresses. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="description" type="string">
      A human-readable description for the outbound (egress) rule, used to document the rule's purpose or context. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="destination_prefix_list_id" type="string">
      The ID of the destination prefix list that the egress rule applies to, allowing traffic to the CIDR blocks defined by that prefix list (e.g., for VPC endpoints or managed prefix lists). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="destination_security_group_id" type="string">
      The ID of the destination security group for this egress rule, which allows outbound traffic to that security group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="from_port" type="number">
      The starting port number of the port range for this outbound (egress) rule, defining the lower bound of destination ports permitted for the specified protocol. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ip_protocol" type="string">
      Specifies the IP protocol name or number (such as tcp, udp, icmp, or -1 for all protocols) that this egress rule applies to. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="to_port" type="number">
      The end of the port range (inclusive) for the destination port in this outbound security group rule; for a single port, set it equal to from_port. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="security_group_ingress" type="list(object)">
  The inbound rules associated with the security group. There is a short interruption during which you cannot connect to the security group. Optional.
  <Expandable title="properties">
    <ResponseField name="cidr_ip" type="string">
      The IPv4 CIDR block from which inbound traffic is allowed by this security group ingress rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="cidr_ipv6" type="string">
      The IPv6 CIDR block (e.g., 2001:db8::/32) that is allowed to send inbound traffic to the security group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="description" type="string">
      A brief, human-readable description for the security group ingress rule, used to document its purpose or source, with a maximum length of 255 characters. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="from_port" type="number">
      The starting port number for the inbound rule's port range, or the ICMP type number when the protocol is ICMP. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ip_protocol" type="string">
      Specifies the IP protocol name (such as tcp, udp, or icmp), a protocol number, or ' -1 ' to represent all protocols, for the ingress rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_prefix_list_id" type="string">
      The ID of an AWS prefix list (such as a managed prefix list for AWS services or VPC endpoints) that serves as the source of the inbound traffic permitted by this ingress rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_security_group_id" type="string">
      Specifies the ID of the source security group (in the same VPC or a peer VPC) whose instances are allowed to send inbound traffic to this security group, used as the SourceSecurityGroupId property of a security group ingress rule. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_security_group_name" type="string">
      The name of the source security group whose members are allowed inbound access by this ingress rule; this is used for EC2-Classic rules, whereas VPC security groups usually reference the source by its `SourceSecurityGroupId` instead. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_security_group_owner_id" type="string">
      The AWS account ID of the owner of the referenced source security group, required when the source security group belongs to a different AWS account. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="to_port" type="number">
      The ending port number of the range for this ingress rule; for a single port, specify the same value as from_port. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags assigned to the security group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the security group, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_id" type="string">
  The ID of the VPC for the security group. Optional.
</ResponseField>

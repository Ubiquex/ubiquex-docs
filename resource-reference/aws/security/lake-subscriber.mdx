`aws_security_lake_subscriber` grants a real external service or account read access to an `aws_security_lake_data_lake`'s normalized data, either by direct query or by subscription notification, without duplicating the underlying data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lake subscriber"})

    		ubx.Resource(security.LakeSubscriber, "example", security.LakeSubscriberConfig{
    			AccessTypes:           []string{"example"},
    			DataLakeArn:           "arn:aws:iam::123456789012:policy/example",
    			Sources:               []string{"example"},
    			SubscriberIdentity:    map[string]any{"external_id": "example"},
    			SubscriberName:        "example-subscriber-name",
    			SubscriberDescription: "example",
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_types" type="list(string)" required>
  The Amazon S3 or AWS Lake Formation access type. Required.
</ResponseField>

<ResponseField name="data_lake_arn" type="string" required>
  The ARN for the data lake. Required.
</ResponseField>

<ResponseField name="sources" type="list(any)" required>
  The supported AWS services from which logs and events are collected. Required.
</ResponseField>

<ResponseField name="subscriber_description" type="string">
  The description for your subscriber account in Security Lake. Optional.
</ResponseField>

<ResponseField name="subscriber_identity" type="object" required>
  The AWS identity used to access your data. Required.
  <Expandable title="properties">
    <ResponseField name="external_id" type="string" required>
      The external ID used to establish trust relationship with the AWS identity. Required.
    </ResponseField>
    <ResponseField name="principal" type="string" required>
      The AWS identity principal. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subscriber_name" type="string" required>
  The name of your Security Lake subscriber account. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of objects, one for each tag to associate with the subscriber. For each tag, you must specify both a tag key and a tag value. A tag value cannot be null, but it can be an empty string. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Security Lake subscriber, used to define the tag's name for organizing and identifying the subscriber resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="resource_share_arn" type="string">
  The Amazon Resource Name (ARN) of the AWS Resource Access Manager (RAM) resource share that grants the subscriber access to the Security Lake data lake. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_share_name" type="string">
  The name of the AWS Resource Access Manager (RAM) resource share automatically created to grant the subscriber access to Security Lake data. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="s3_bucket_arn" type="string">
  For S3 subscribers, the ARN of the S3 bucket where Security Lake delivers data, computed and returned after the subscriber resource is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="subscriber_arn" type="string">
  The Amazon Resource Name (ARN) of the Security Lake subscriber, automatically assigned by AWS when the subscriber is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="subscriber_role_arn" type="string">
  The ARN of the IAM role that the subscriber uses to access the data lake, assigned by Security Lake when the subscriber is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_security_agent_agent_space` creates a real, isolated workspace that AWS Security Agent's autonomous penetration-testing and application-security agents operate within, scoped to a specific `aws_security_agent_application`. AWS Security Agent reached general availability for on-demand penetration testing on March 31, 2026, roughly five months ago, so behavior here is verified live rather than assumed from general knowledge.

`aws_security_agent_target_domain` registers a real, in-scope domain or endpoint that AWS Security Agent is authorized to test against for an `aws_security_agent_application`, the resource that bounds what the agent's autonomous pentesting is actually allowed to touch.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent target domain"})

    		ubx.Resource(security.AgentTargetDomain, "example", security.AgentTargetDomainConfig{
    			TargetDomainName:   "example-target-domain-name",
    			VerificationMethod: "example",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="tags" type="list(object)">
  Tags for the target domain Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_domain_name" type="string" required>
  Domain name of the target domain Required.
</ResponseField>

<ResponseField name="verification_method" type="string" required>
  Verification method for the target domain Required.
</ResponseField>

## Output properties

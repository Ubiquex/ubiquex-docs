`aws_observability_admin_telemetry_enrichment` configures real, additional AWS context, resource tags or account metadata, automatically attached to telemetry data governed by an `aws_observability_admin_telemetry_rule`, without each individual signal needing to carry that context itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	observabilityadmin "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/observabilityadmin"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own telemetry enrichment"})

    		ubx.Resource(observabilityadmin.TelemetryEnrichment, "example", observabilityadmin.TelemetryEnrichmentConfig{
    			Scope: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.aws.observabilityadmin import TelemetryEnrichment, TelemetryEnrichmentConfig

    def describe():
        ubx.intent("example own telemetry enrichment")

        ubx.resource(TelemetryEnrichment, "example", TelemetryEnrichmentConfig(
            scope="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="scope" type="string" required>
  Scope of the Telemetry Enrichment Required.
</ResponseField>

## Output properties

<ResponseField name="status" type="string">
  Current status of the resource tags for telemetry feature (Running, Stopped, or Impaired). Computed by AWS after `ship`.
</ResponseField>

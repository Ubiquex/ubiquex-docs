`aws_global_accelerator_endpoint_group` is the real, specific set of endpoints, ALBs, NLBs, EC2 instances, Elastic IPs, in one AWS Region that an `aws_global_accelerator_listener` routes matching traffic to, with health checks determining which endpoints actually receive it.

## Input properties

<ResponseField name="endpoint_configurations" type="list(object)">
  The list of endpoint objects. Optional.
  <Expandable title="properties">
    <ResponseField name="attachment_arn" type="string">
      The ARN of the AWS resource (such as an Application Load Balancer, Network Load Balancer, or EC2 instance) that is attached as an endpoint in this endpoint group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="client_ippreservation_enabled" type="bool">
      Indicates whether client IP address preservation is enabled for this endpoint, which keeps the original client IP address in the packet headers forwarded by Global Accelerator to the endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="endpoint_id" type="string">
      The ARN of the endpoint resource (such as an Application Load Balancer, Network Load Balancer, EC2 instance, or Elastic IP address) that Global Accelerator routes traffic to for this endpoint configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="weight" type="number">
      The weight assigned to the endpoint, controlling the proportion of traffic routed to it relative to other endpoints in the group (values 0-255, higher means more traffic). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="endpoint_group_region" type="string" required>
  The name of the AWS Region where the endpoint group is located Required.
</ResponseField>

<ResponseField name="health_check_interval_seconds" type="number">
  The time in seconds between each health check for an endpoint. Must be a value of 10 or 30 Optional.
</ResponseField>

<ResponseField name="health_check_path" type="string">
  The URI path that AWS Global Accelerator uses to perform health checks against endpoints in the endpoint group, such as '/health' or '/'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="health_check_port" type="number">
  The port that AWS Global Accelerator uses to check the health of endpoints in this endpoint group. Optional.
</ResponseField>

<ResponseField name="health_check_protocol" type="string">
  The protocol that AWS Global Accelerator uses to check the health of endpoints in this endpoint group. Optional.
</ResponseField>

<ResponseField name="listener_arn" type="string" required>
  The Amazon Resource Name (ARN) of the listener Required.
</ResponseField>

<ResponseField name="port_overrides" type="list(object)">
  A list of port overrides that map a listener port to a different endpoint port for the endpoint group, allowing traffic to be redirected to a custom port on the endpoint. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="endpoint_port" type="number">
      The actual port on the endpoint that receives traffic when this port override is applied, replacing the listener port for the mapped endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="listener_port" type="number">
      Specifies the original port on the accelerator listener that this port override maps to the endpoint port, redirecting traffic received on that listener port to the endpoint's configured port. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="threshold_count" type="number">
  The number of consecutive health checks required to set the state of the endpoint to unhealthy. Optional.
</ResponseField>

<ResponseField name="traffic_dial_percentage" type="number">
  The percentage of traffic to sent to an AWS Region Optional.
</ResponseField>

## Output properties

<ResponseField name="endpoint_group_arn" type="string">
  The Amazon Resource Name (ARN) of the endpoint group Computed by AWS after `ship`.
</ResponseField>

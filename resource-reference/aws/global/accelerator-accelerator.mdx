`aws_global_accelerator_accelerator` creates two real, static anycast IP addresses that route traffic over AWS's own global network backbone to the closest healthy endpoint, real, consistent public entry points independent of the endpoints' own Regions or IP addresses changing behind them.

## Input properties

<ResponseField name="enabled" type="bool">
  Indicates whether an accelerator is enabled. The value is true or false. Optional.
</ResponseField>

<ResponseField name="flow_logs_enabled" type="bool">
  Indicates whether flow logs are enabled for the accelerator. Optional.
</ResponseField>

<ResponseField name="flow_logs_s3_bucket" type="string">
  The name of the Amazon S3 bucket for the flow logs. Optional.
</ResponseField>

<ResponseField name="flow_logs_s3_prefix" type="string">
  The prefix for the location in the Amazon S3 bucket for the flow logs. Optional.
</ResponseField>

<ResponseField name="ip_address_type" type="string">
  IP Address type. Optional.
</ResponseField>

<ResponseField name="ip_addresses" type="list(string)">
  The IP addresses from BYOIP Prefix pool. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of accelerator. Required.
</ResponseField>

## Output properties

<ResponseField name="accelerator_arn" type="string">
  The Amazon Resource Name (ARN) of the accelerator. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="dns_name" type="string">
  The Domain Name System (DNS) name that Global Accelerator creates that points to your accelerator's static IPv4 addresses. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="dual_stack_dns_name" type="string">
  The Domain Name System (DNS) name that Global Accelerator creates that points to your accelerator's static IPv4 and IPv6 addresses. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipv4_addresses" type="list(string)">
  The IPv4 addresses assigned to the accelerator. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="ipv6_addresses" type="list(string)">
  The IPv6 addresses assigned if the accelerator is dualstack Computed by AWS after `ship`.
</ResponseField>

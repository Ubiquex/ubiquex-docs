`aws_global_accelerator_listener` checks for real connection requests on a specific port and protocol against an `aws_global_accelerator_accelerator`, the entry point `aws_global_accelerator_endpoint_group`s route matching traffic from.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Protocol:       "example",
    			ClientAffinity: "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="accelerator_arn" type="string" required>
  The Amazon Resource Name (ARN) of the accelerator. Required.
</ResponseField>

<ResponseField name="client_affinity" type="string">
  Client affinity lets you direct all requests from a user to the same endpoint. Optional.
</ResponseField>

<ResponseField name="port_ranges" type="list(object)" required>
  Defines the list of port ranges (each with a `from` and `to` port) that the listener forwards traffic on. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="from_port" type="number">
      The first port in the inclusive range of ports (from_port to to_port) that the AWS Global Accelerator listener accepts and forwards traffic on. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="to_port" type="number">
      The inclusive ending port number of the range for the listener. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="protocol" type="string" required>
  The protocol for the listener. Required.
</ResponseField>

## Output properties

<ResponseField name="listener_arn" type="string">
  The Amazon Resource Name (ARN) of the listener. Computed by AWS after `ship`.
</ResponseField>

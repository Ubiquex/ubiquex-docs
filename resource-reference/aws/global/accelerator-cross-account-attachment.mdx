`aws_global_accelerator_cross_account_attachment` authorizes a real, specific set of endpoint resources owned by another AWS account to be added to this account's own `aws_global_accelerator_accelerator`, a real cross-account grant rather than every accelerator needing to live in the same account as every endpoint it targets.

    }

## Input properties

<ResponseField name="name" type="string" required>
  The Friendly identifier of the attachment. Required.
</ResponseField>

<ResponseField name="principals" type="list(string)">
  Principals to share the resources with. Optional.
</ResponseField>

<ResponseField name="resources" type="list(object)">
  Resources shared using the attachment. Optional.
  <Expandable title="properties">
    <ResponseField name="cidr" type="string">
      Specifies the IP address range in CIDR notation (e.g., '10.0.0.0/8') for a resource being attached, used when the resource is an IP range rather than an endpoint ID in this cross-account attachment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="endpoint_id" type="string">
      The ARN or resource identifier of the AWS resource (such as a Network Load Balancer, Application Load Balancer, or Elastic IP) that is attached to the accelerator from a different AWS account. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="region" type="string">
      The AWS Region where the resource being added to the cross-account attachment is located, such as when the resource is a regional endpoint group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of key-value tags to attach to the cross-account attachment, which can be used for resource identification, cost allocation, and tag-based access control in AWS Global Accelerator. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to the AWS Global Accelerator cross-account attachment, allowing you to attach custom metadata such as cost center or environment for identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag key-value pair that you attach to an AWS Global Accelerator cross-account attachment for metadata and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

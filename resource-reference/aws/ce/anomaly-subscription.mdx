`aws_ce_anomaly_subscription` attaches real alert recipients and a notification channel to an `aws_ce_anomaly_monitor`, the actual delivery mechanism a monitor's own detected anomalies have no way to reach anyone without.

## Input properties

<ResponseField name="frequency" type="string" required>
  The frequency at which anomaly reports are sent over email. Required.
</ResponseField>

<ResponseField name="monitor_arn_list" type="list(string)" required>
  A list of cost anomaly monitors. Required.
</ResponseField>

<ResponseField name="resource_tags" type="list(object)">
  Tags to assign to subscription. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a resource tag attached to the AWS Cost Explorer anomaly subscription, used to identify or categorize the subscription within a key-value pair. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a key-value tag applied to the AWS Cost Explorer anomaly subscription, used for organizing, filtering, and controlling access to the subscription resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subscription_name" type="string" required>
  The name of the subscription. Required.
</ResponseField>

<ResponseField name="threshold" type="number">
  The dollar value that triggers a notification if the threshold is exceeded. Optional.
</ResponseField>

<ResponseField name="threshold_expression" type="string">
  An Expression object in JSON String format used to specify the anomalies that you want to generate alerts for. Optional.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  The account ID for this ce anomaly subscription. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="subscribers" type="list(object)">
  A list of subscriber Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="address" type="string">
      The email address or Amazon SNS topic ARN that receives notifications for this anomaly subscription. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="status" type="string">
      The subscription status of the subscriber, indicating whether the subscriber has confirmed or declined the anomaly alert subscription. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of AWS Cost Explorer anomaly subscription subscriber, either EMAIL or SNS_TOPIC. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subscription_arn" type="string">
  Subscription ARN Computed by AWS after `ship`.
</ResponseField>

`aws_ce_anomaly_monitor` watches spend segmented by AWS service, linked account, cost allocation tag, or `aws_ce_cost_category`, using machine learning to detect unusual patterns against that segment's own normal spend, the real detection engine an `aws_ce_anomaly_subscription`'s alerts are triggered by.

## Input properties

<ResponseField name="monitor_dimension" type="string">
  The dimensions to evaluate Optional.
</ResponseField>

<ResponseField name="monitor_name" type="string" required>
  The name of the monitor. Required.
</ResponseField>

<ResponseField name="monitor_specification" type="string">
  A JSON-formatted string that defines the custom monitoring criteria for the cost anomaly monitor, such as filtering by services, linked accounts, or cost categories, used when the monitor type is CUSTOM. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="monitor_type" type="string" required>
  Specifies whether the anomaly monitor is a DIMENSIONAL monitor (which watches a specific dimension like service or linked account) or a CUSTOM monitor (which uses a custom threshold on the anomaly score). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_tags" type="list(object)">
  Tags to assign to monitor. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key for a resource tag applied to the Cost Explorer anomaly monitor, used for identifying and organizing the monitor among AWS resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a resource tag attached to the AWS Cost Explorer anomaly monitor, used for tagging and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_ce_cost_category` groups AWS costs by custom, rule-based categories, mapping accounts, tags, or services into a caller's own real business dimensions, engineering versus marketing spend, for instance, so Cost Explorer and cost anomaly monitors can analyze and alert on those groupings directly rather than only on AWS's native billing dimensions.

## Input properties

<ResponseField name="default_value" type="string">
  The default value for the cost category Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the cost category, which must be unique within your AWS account and is used to identify the cost category in the AWS Cost Management console and APIs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rule_version" type="string" required>
  Specifies the version of the cost category rule syntax, which must be set to 'CostCategoryExpression.v1' for the rule expressions. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rules" type="string" required>
  JSON array format of Expression in Billing and Cost Management API Required.
</ResponseField>

<ResponseField name="split_charge_rules" type="string">
  Json array format of CostCategorySplitChargeRule in Billing and Cost Management API Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the cost category. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag applied to the AWS Cost Category. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value portion of a user-defined tag (key-value pair) applied to the AWS Cost Category, used to categorize and track cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

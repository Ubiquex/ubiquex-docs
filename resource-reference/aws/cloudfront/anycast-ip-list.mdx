`aws_cloud_front_anycast_ip_list` reserves a real, static set of Anycast IP addresses (up to 21) dedicated to an account, that an `aws_cloud_front_distribution` can be assigned so viewers, network providers, or outbound firewalls can allowlist a fixed, known set of IPs instead of CloudFront's normal, dynamically assigned address space.

## Input properties

<ResponseField name="ip_address_type" type="string">
  Specifies whether the anycast IP list contains IPv4 or IPv6 addresses, determining which type of IPs can be included in the IpList property. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ip_count" type="number" required>
  The number of IP addresses in the Anycast static IP list. Required.
</ResponseField>

<ResponseField name="ipam_cidr_configs" type="list(object)">
  Specifies the IPAM pool CIDR allocations (each including an IPAM pool ID and netmask length) that define the IP address ranges CloudFront will advertise as anycast for this IP list. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cidr" type="string">
      The CIDR block, specified within an IPAM CIDR configuration, that determines the IP address range used for the CloudFront anycast IP list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ipam_pool_arn" type="string">
      The ARN of the IPAM pool that supplies the CIDR block for this anycast IP list configuration in CloudFront. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Anycast static IP list. Required.
</ResponseField>

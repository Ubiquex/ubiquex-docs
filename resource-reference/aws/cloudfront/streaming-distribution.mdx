`aws_cloud_front_streaming_distribution` is CloudFront's legacy RTMP media-streaming distribution type, a narrower, deprecated predecessor to the general-purpose `aws_cloud_front_distribution` that AWS has directed customers away from for years in favor of HTTP-based streaming.

## Input properties

<ResponseField name="streaming_distribution_config" type="object" required>
  The required configuration object for the CloudFront streaming distribution, specifying the S3 origin, enabled flag, optional aliases, comment, logging settings, and trusted signers for RTMP streaming. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="aliases" type="list(string)">
      List of alternate domain names (CNAMEs) that can be used to access the streaming distribution in addition to the default cloudfront.net domain name. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="comment" type="string" required>
      The required string comment that describes the CloudFront streaming distribution, which must be provided in the streaming distribution configuration. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enabled" type="bool" required>
      Determines whether the CloudFront streaming distribution is enabled to accept and serve viewer requests. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="logging" type="object">
      Configures access logging for the streaming distribution, specifying whether logging is enabled, the S3 bucket where logs are stored, and the log file prefix. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The Amazon S3 bucket to which CloudFront delivers access logs for the streaming distribution. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="enabled" type="bool" required>
          Specifies whether CloudFront writes access logs for the streaming distribution to the S3 bucket named in the logging bucket property. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="prefix" type="string" required>
          This string specifies the prefix that CloudFront adds to the beginning of the access log file names for this streaming distribution when it writes logs to the configured Amazon S3 bucket. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="price_class" type="string">
      Specifies the price class for the CloudFront streaming distribution, which determines the geographic set of edge locations used and the associated pricing tier (e.g., PriceClass_100, PriceClass_200, or PriceClass_All). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="s3_origin" type="object" required>
      Specifies the S3 bucket (domain_name) and CloudFront origin access identity used to authorize access for the streaming distribution's origin. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="domain_name" type="string" required>
          The domain name of the S3 bucket that acts as the origin for the CloudFront streaming distribution, typically formatted as `&lt;bucket-name&gt;.s3.amazonaws.com`. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="origin_access_identity" type="string" required>
          The CloudFront origin access identity (OAI) to associate with the S3 origin for the streaming distribution, which permits CloudFront to access private S3 content. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="trusted_signers" type="object" required>
      Specifies the AWS account IDs (or 'self' for the owner account) that are permitted to create signed URLs for private content served by this CloudFront streaming distribution, including an Enabled flag indicating whether the trusted signer list is active. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="aws_account_numbers" type="list(string)">
          Specifies the AWS account numbers of trusted signers (accounts with CloudFront key pairs) allowed to create signed URLs or signed cookies for this streaming distribution. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="enabled" type="bool" required>
          Indicates whether trusted signers are enabled for the streaming distribution, so that when true, the accounts in the AwsAccountNumbers list can create signed URLs, and when false, only the creating AWS account can create signed URLs. Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)" required>
  Configures the list of tag objects (each with a Key and Value) that are attached to the CloudFront streaming distribution for organization, cost tracking, and access management. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A tag key used to assign a custom metadata label to the CloudFront streaming distribution for organization, cost allocation, or access control purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag applied to the CloudFront streaming distribution, allowing you to associate arbitrary metadata such as environment or cost center with the resource for tracking and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="domain_name" type="string">
  The domain name (such as d111111abcdef8.cloudfront.net) that CloudFront assigns to the streaming distribution and that clients use to request content. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier assigned to the CloudFront streaming distribution by AWS, used as the distribution ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_image_builder_image_recipe` defines the real base AMI and the ordered build and test components applied to it, that an `aws_image_builder_image_pipeline` runs to actually produce a new, hardened, updated AMI.

## Input properties

<ResponseField name="additional_instance_configuration" type="object">
  Specify additional settings and launch scripts for your build instances. Optional.
  <Expandable title="properties">
    <ResponseField name="systems_manager_agent" type="object">
      Contains settings for the SSM agent on your build instance. Optional.
      <Expandable title="properties">
        <ResponseField name="uninstall_after_build" type="bool">
          Controls whether the SSM agent is removed from your final build image, prior to creating the new AMI. If this is set to true, then the agent is removed from the final image. If it's set to false, then the agent is left in, so that it is included in the new AMI. The default value is false. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="user_data_override" type="string">
      Use this property to provide commands or a command script to run when you launch your build instance. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ami_tags" type="any">
  The tags to apply to the AMI created by this image recipe. Optional.
</ResponseField>

<ResponseField name="ami_watermarks" type="list(string)">
  The AMI watermark names to attach to the output AMI from this recipe. AMI watermarks are lineage markers that automatically propagate to derivative AMIs when the source AMI is copied or distributed. Optional.
</ResponseField>

<ResponseField name="block_device_mappings" type="list(object)">
  The block device mappings to apply when creating images from this recipe. Optional.
  <Expandable title="properties">
    <ResponseField name="device_name" type="string">
      The device name (e.g., /dev/xvda) that identifies the block device mapping to the instance in the Image Builder image recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ebs" type="object">
      Specifies the Amazon EBS-specific block device mapping settings, including encryption, volume size, volume type, IOPS, throughput, snapshot ID, KMS key ID, and delete-on-termination behavior, for the corresponding block device in the image recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="delete_on_termination" type="bool">
          Indicates whether the EBS volume should be deleted when the associated EC2 instance is terminated, as part of the block device mapping configuration for the image recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="encrypted" type="bool">
          Specifies whether the EBS volume created from this block device mapping should be encrypted; when set to true, AWS encrypts the volume at rest using the default EBS encryption key or the KMS key specified in the same EBS configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="iops" type="number">
          The number of I/O operations per second (IOPS) to provision for the EBS volume, applied when the volume type is io1, io2, or gp3, to control the volume's performance level. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="kms_key_id" type="string">
          The identifier of the AWS KMS key used to encrypt the EBS volume for this block device mapping in the image recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="snapshot_id" type="string">
          The ID of the snapshot to use as the source for the EBS volume in the block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="throughput" type="number">
          The throughput in MiB/s to provision for the EBS volume, applicable when the volume type is gp3. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="volume_size" type="number">
          Specifies the size, in GiB, of the EBS volume used by the block device mapping in the EC2 Image Builder image recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="volume_type" type="string">
          Specifies the EBS volume type (e.g., gp2, gp3, io1) for the block device in the image recipe's block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="no_device" type="string">
      When set, this field removes the corresponding device from the image's block device mapping, overriding a device that was present in the base image. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="virtual_name" type="string">
      The virtual device name (e.g., 'ephemeral0') for an ephemeral (instance store) block device mapped to the image recipe, used when the mapping specifies a non-EBS virtual storage device. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="components" type="list(object)">
  The components of the image recipe. Optional.
  <Expandable title="properties">
    <ResponseField name="component_arn" type="string">
      The Amazon Resource Name (ARN) of a component (a software configuration) that is included as a step in the image recipe's build process. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameters" type="list(object)">
      Specifies the list of parameter name-value pairs to pass to the component when the image recipe runs, overriding any default parameter values defined in the component document. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name (key) of a parameter to pass to the component, which must match a parameter name defined in the component's recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="list(string)">
          The value (or list of values) to assign to a named build component parameter, which is passed to that component when AWS Image Builder uses the recipe to build an image. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the image recipe. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the image recipe. Required.
</ResponseField>

<ResponseField name="parent_image" type="string" required>
  The parent image of the image recipe. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  The tags of the image recipe. Optional.
</ResponseField>

<ResponseField name="version" type="string" required>
  The version of the image recipe. Required.
</ResponseField>

<ResponseField name="working_directory" type="string">
  The working directory to be used during build and test workflows. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the image recipe. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="latest_version" type="object">
  The latest version references of the image recipe. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="arn" type="string">
      The latest version ARN of the created image recipe. Optional.
    </ResponseField>
    <ResponseField name="major" type="string">
      The latest version ARN of the created image recipe, with the same major version. Optional.
    </ResponseField>
    <ResponseField name="minor" type="string">
      The latest version ARN of the created image recipe, with the same minor version. Optional.
    </ResponseField>
    <ResponseField name="patch" type="string">
      The latest version ARN of the created image recipe, with the same patch version. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

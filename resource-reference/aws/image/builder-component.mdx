`aws_image_builder_component` defines a real, reusable build or test step, install a package, run a script, validate a setting, in YAML or JSON, that an EC2 Image Builder image pipeline assembles together to produce a custom AMI or container image.

## Example

## Input properties

<ResponseField name="change_description" type="string">
  The change description of the component. Optional.
</ResponseField>

<ResponseField name="data" type="string">
  The data of the component. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the component. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The KMS key identifier used to encrypt the component. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the component. Required.
</ResponseField>

<ResponseField name="platform" type="string" required>
  The platform of the component. Required.
</ResponseField>

<ResponseField name="supported_os_versions" type="list(string)">
  The operating system (OS) version supported by the component. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  The tags associated with the component. Optional.
</ResponseField>

<ResponseField name="uri" type="string">
  The uri of the component. Optional.
</ResponseField>

<ResponseField name="version" type="string" required>
  The version of the component. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the component. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="encrypted" type="bool">
  The encryption status of the component. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="latest_version" type="object">
  The latest version references of the component. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="arn" type="string">
      The latest version ARN of the created component. Optional.
    </ResponseField>
    <ResponseField name="major" type="string">
      The latest version ARN of the created component, with the same major version. Optional.
    </ResponseField>
    <ResponseField name="minor" type="string">
      The latest version ARN of the created component, with the same minor version. Optional.
    </ResponseField>
    <ResponseField name="patch" type="string">
      The latest version ARN of the created component, with the same patch version. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of the component denotes whether the component is used to build the image or only to test it. Computed by AWS after `ship`.
</ResponseField>

`aws_image_builder_infrastructure_configuration` defines the real EC2 environment, instance type, subnet, IAM instance profile, that Image Builder launches temporary build instances into while assembling an image from `aws_image_builder_component`s.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	image "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/image"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own builder infrastructure configuration"})

    		ubx.Resource(image.BuilderInfrastructureConfiguration, "example", image.BuilderInfrastructureConfigurationConfig{
    			InstanceProfileName:     "example-instance-profile-name",
    			Name:                    "example",
    			Description:             "Managed by ubx.",
    			InstanceMetadataOptions: map[string]any{"http_put_response_hop_limit": 1},
    			InstanceTypes:           []string{"example"},
    			KeyPair:                 "example",
    			Logging:                 map[string]any{"s3_logs": map[string]any{"s3_bucket_name": "example-s3-bucket-name"}},
    			Placement:               map[string]any{"availability_zone": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the infrastructure configuration. Optional.
</ResponseField>

<ResponseField name="instance_metadata_options" type="object">
  The instance metadata option settings for the infrastructure configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="http_put_response_hop_limit" type="number">
      Limit the number of hops that an instance metadata request can traverse to reach its destination. Optional.
    </ResponseField>
    <ResponseField name="http_tokens" type="string">
      Indicates whether a signed token header is required for instance metadata retrieval requests. The values affect the response as follows: Optional.

</ResponseField>

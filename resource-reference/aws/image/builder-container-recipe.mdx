`aws_image_builder_container_recipe` defines the real base container image and the ordered build and test components applied to it, that an `aws_image_builder_image_pipeline` runs to actually produce a new container image, the container-image counterpart to `aws_image_builder_image_recipe`.

## Input properties

<ResponseField name="components" type="list(object)">
  Components for build and test that are included in the container recipe. Optional.
  <Expandable title="properties">
    <ResponseField name="component_arn" type="string">
      The Amazon Resource Name (ARN) of the Image Builder component to apply as part of this container recipe's build configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameters" type="list(object)">
      Defines the list of parameter name/value pairs to supply to an Image Builder component (referenced by the containing components list entry) when the container recipe is used to build a container image, overriding default values defined in the component document. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name (key) of a parameter that is passed to the Image Builder component when building the container image, matching a parameter defined in that component. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="list(string)">
          Specifies a list of values to assign to the named build component parameter when this container recipe is used to build an image. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="container_type" type="string">
  Specifies the type of container, such as Docker. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the container recipe. Optional.
</ResponseField>

<ResponseField name="dockerfile_template_data" type="string">
  Dockerfiles are text documents that are used to build Docker containers, and ensure that they contain all of the elements required by the application running inside. The template data consists of contextual variables where Image Builder places build information or scripts, based on your container image recipe. Optional.
</ResponseField>

<ResponseField name="dockerfile_template_uri" type="string">
  The S3 URI for the Dockerfile that will be used to build your container image. Optional.
</ResponseField>

<ResponseField name="image_os_version_override" type="string">
  Specifies the operating system version for the source image. Optional.
</ResponseField>

<ResponseField name="instance_configuration" type="object">
  A group of options that can be used to configure an instance for building and testing container images. Optional.
  <Expandable title="properties">
    <ResponseField name="block_device_mappings" type="list(object)">
      Defines the block devices to attach for building an instance from this Image Builder AMI. Optional.
      <Expandable title="properties">
        <ResponseField name="device_name" type="string">
          The device name (e.g., /dev/sda1) for a block device attached to the EC2 instance used by Image Builder to build the container image. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="ebs" type="object">
          Specifies the Amazon EBS volume settings for a block device mapping in the instance configuration, including volume size, volume type, IOPS, encrypted flag, and snapshot identifier. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="delete_on_termination" type="bool">
              Whether the EBS volume should be deleted when the associated EC2 instance is terminated, as part of the block device mapping for the build instance in the Image Builder container recipe. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="encrypted" type="bool">
              Determines whether the EBS volume in this block device mapping is encrypted on the build instance used by the container recipe, matching the standard EC2 block device mapping encryption setting. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="iops" type="number">
              Specifies the IOPS (input/output operations per second) rate for the EBS volume, used only when the volume type is io1, io2, or gp3 in the block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="kms_key_id" type="string">
              The KMS key ID used to encrypt the EBS volume defined in this block device mapping, enabling a customer-managed encryption key for the volume created during the image build. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="snapshot_id" type="string">
              Specifies the ID of an existing EBS snapshot to use as the source for the EBS volume defined in this block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="throughput" type="number">
              The throughput in MB/s to provision for the EBS gp3 volume defined in a block device mapping for the instance configuration of the Image Builder container recipe, used to set the performance characteristics of the attached volume during build and test. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="volume_size" type="number">
              For a block device in the container recipe's build instance configuration, the size in GiB of the EBS volume to attach. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="volume_type" type="string">
              Defines the Amazon EBS volume type for the block device mapped to the build instance, where valid values include gp2, gp3, io1, io2, sc1, st1, and standard. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="no_device" type="string">
          Indicates whether to suppress this block device mapping so that no device is exposed to the instance, overriding any device mapping from the base image. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="virtual_name" type="string">
          Specifies the virtual device name (e.g., ephemeral0) for an ephemeral instance store volume in the block device mapping of the instance used to build the container, matching EC2 ephemeral device naming conventions. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="image" type="string">
      The AMI ID to use as the base image for a container build and test instance. If not specified, Image Builder will use the appropriate ECS-optimized AMI as a base image. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  Identifies which KMS key is used to encrypt the container image. Optional.
</ResponseField>

  The name of the container recipe. Optional.
</ResponseField>

<ResponseField name="platform_override" type="string">

</ResponseField>

<ResponseField name="tags" type="any">
  Tags that are attached to the container recipe. Optional.
</ResponseField>

<ResponseField name="target_repository" type="object">
  The container repository where the output container image is stored. Optional.
  <Expandable title="properties">
    <ResponseField name="repository_name" type="string">
      The name of the container repository where the output container image is stored. This name is prefixed by the repository location. Optional.
    </ResponseField>
    <ResponseField name="service" type="string">
      Specifies the service in which this image was registered. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="version" type="string">
  The semantic version of the container recipe (&lt;major&gt;.&lt;minor&gt;.&lt;patch&gt;). Optional.
</ResponseField>

  The working directory to be used during build and test workflows. Optional.
</ResponseField>

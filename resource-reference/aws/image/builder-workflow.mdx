`aws_image_builder_workflow` defines a real, custom sequence of build, test, and distribution steps for EC2 Image Builder, an alternative to its own default workflow when a pipeline needs steps in a different order or with custom logic between them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	image "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/image"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own builder workflow"})

    		ubx.Resource(image.BuilderWorkflow, "example", image.BuilderWorkflowConfig{
    			Name:              "example",
    			Type:              "example",
    			Version:           "example",
    			ChangeDescription: "example",
    			Data:              "example",
    			Description:       "Managed by ubx.",
    			KmsKeyId:          "example",
    			Tags:              "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="change_description" type="string">
  The change description of the workflow. Optional.
</ResponseField>

<ResponseField name="data" type="string">
  The data of the workflow. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the workflow. Optional.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The KMS key identifier used to encrypt the workflow. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the workflow. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  The tags associated with the workflow. Optional.
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of the workflow denotes whether the workflow is used to build, test, or distribute. Required.
</ResponseField>

<ResponseField name="uri" type="string">
  The uri of the workflow. Optional.
</ResponseField>

<ResponseField name="version" type="string" required>
  The version of the workflow. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the workflow. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="latest_version" type="object">
  The latest version references of the workflow. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="arn" type="string">

    <ResponseField name="major" type="string">

    </ResponseField>

    </ResponseField>

    </ResponseField>
  </Expandable>
</ResponseField>

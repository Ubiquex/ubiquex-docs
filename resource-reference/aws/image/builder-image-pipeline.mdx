`aws_image_builder_image_pipeline` automates the recurring build, test, and distribution of a real machine image or container image, combining an `aws_image_builder_image_recipe` or `aws_image_builder_container_recipe` with build infrastructure and an `aws_image_builder_distribution_configuration` into one scheduled, repeatable process.

## Input properties

<ResponseField name="container_recipe_arn" type="string">
  The Amazon Resource Name (ARN) of the container recipe that defines how images are configured and tested. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the image pipeline. Optional.
</ResponseField>

<ResponseField name="distribution_configuration_arn" type="string">
  The Amazon Resource Name (ARN) of the distribution configuration associated with this image pipeline. Optional.
</ResponseField>

<ResponseField name="enhanced_image_metadata_enabled" type="bool">
  Collects additional information about the image being created, including the operating system (OS) version and package list. Optional.
</ResponseField>

<ResponseField name="execution_role" type="string">
  The execution role name/ARN for the image build, if provided Optional.
</ResponseField>

<ResponseField name="image_recipe_arn" type="string">
  The Amazon Resource Name (ARN) of the image recipe that defines how images are configured, tested, and assessed. Optional.
</ResponseField>

<ResponseField name="image_scanning_configuration" type="object">
  Determines if tests should run after building the image. Image Builder defaults to enable tests to run following the image build, before image distribution. Optional.
  <Expandable title="properties">
    <ResponseField name="ecr_configuration" type="object">
      Settings for Image Builder to configure the ECR repository and output container images that are scanned. Optional.
      <Expandable title="properties">
        <ResponseField name="container_tags" type="list(string)">
          Tags for Image Builder to apply the output container image that is scanned. Tags can help you identify and manage your scanned images. Optional.
        </ResponseField>
        <ResponseField name="repository_name" type="string">
          The name of the container repository that Amazon Inspector scans to identify findings for your container images. The name includes the path for the repository location. If you don't provide this information, Image Builder creates a repository in your account named image-builder-image-scanning-repository to use for vulnerability scans for your output container images. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="image_scanning_enabled" type="bool">
      This sets whether Image Builder keeps a snapshot of the vulnerability scans that Amazon Inspector runs against the build instance when you create a new image. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_tags" type="any">
  The tags to be applied to images created by this pipeline. Optional.
</ResponseField>

<ResponseField name="image_tests_configuration" type="object">
  Image tests configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="image_tests_enabled" type="bool">
      Defines if tests should be executed when building this image. Optional.
    </ResponseField>
    <ResponseField name="timeout_minutes" type="number">
      The maximum time in minutes that tests are permitted to run. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="infrastructure_configuration_arn" type="string">
  The Amazon Resource Name (ARN) of the infrastructure configuration associated with this image pipeline. Optional.
</ResponseField>

<ResponseField name="logging_configuration" type="object">
  The logging configuration settings for the image pipeline. Optional.
  <Expandable title="properties">
    <ResponseField name="image_log_group_name" type="string">
      The name of the log group for image build logs. Optional.
    </ResponseField>
    <ResponseField name="pipeline_log_group_name" type="string">
      The name of the log group for pipeline execution logs. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the image pipeline. Optional.
</ResponseField>

<ResponseField name="schedule" type="object">
  The schedule of the image pipeline. Optional.
  <Expandable title="properties">
    <ResponseField name="auto_disable_policy" type="object">
      The auto-disable policy configuration for the image pipeline. Optional.
      <Expandable title="properties">
        <ResponseField name="failure_count" type="number" required>
          The number of consecutive failures after which the pipeline should be automatically disabled. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="pipeline_execution_start_condition" type="string">
      The condition configures when the pipeline should trigger a new image build. Optional.
    </ResponseField>
    <ResponseField name="schedule_expression" type="string">
      The expression determines how often EC2 Image Builder evaluates your pipelineExecutionStartCondition. Optional.
    </ResponseField>
    <ResponseField name="timezone" type="string">
      The timezone that applies to the scheduling expression, for example "Etc/UTC" or "America/Los_Angeles" in IANA timezone format. If not specified, this defaults to UTC. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  The status of the image pipeline. Optional.
</ResponseField>

<ResponseField name="tags" type="any">
  The tags of this image pipeline. Optional.
</ResponseField>

<ResponseField name="workflows" type="list(object)">
  Workflows to define the image build process Optional.
  <Expandable title="properties">
    <ResponseField name="on_failure" type="string">
      Specifies the action to take when this workflow fails; valid values are CONTINUE or ABORT. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parallel_group" type="string">
      The parallel group name for this workflow; multiple workflows with the same parallel group are executed concurrently during the image build process. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameters" type="list(object)">
      Specifies the list of parameter name/value pairs to pass to a workflow attached to this image pipeline, controlling how that workflow runs during the image build and test process. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name of an individual input parameter passed to an Image Builder workflow configured for this image pipeline, serving as the key that the workflow definition uses to reference the parameter value. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="list(string)">
          Defines the list of string values for a given workflow parameter key in the Image Builder image pipeline's workflow configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="workflow_arn" type="string">
      The ARN of an Image Builder workflow to associate with the image pipeline, defining a custom build/test step sequence. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

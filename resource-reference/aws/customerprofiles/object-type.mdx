`aws_customer_profiles_object_type` defines the real schema for one category of customer data, a purchase, a support ticket, that an `aws_customer_profiles_integration` ingests and Customer Profiles merges into a unified profile.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own profiles object type"})

    			EncryptionKey:        "example",

`aws_refactor_spaces_application` registers a real monolith application, its proxy and default route, inside an `aws_refactor_spaces_environment`, the resource that `aws_refactor_spaces_service`s are incrementally carved out of and routed to. Like the rest of Refactor Spaces, this closed to new customers November 7, 2025, with AWS recommending AWS Transform for new work.

## Input properties

<ResponseField name="api_gateway_proxy" type="object">
  Defines the Amazon API Gateway proxy configuration, including the endpoint type and stage name, for the Refactor Spaces application. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="endpoint_type" type="string">
      Specifies the endpoint type (REGIONAL or PRIVATE) for the API Gateway proxy that Refactor Spaces creates for the application, determining whether the API is publicly accessible or reachable only within a VPC. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="stage_name" type="string">
      The stage name for the API Gateway proxy endpoint that Refactor Spaces creates for the application, controlling the API Gateway deployment stage. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="environment_identifier" type="string" required>
  Specifies the ID of the AWS Refactor Spaces environment that contains this application. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The user-defined name that identifies the Refactor Spaces application within its environment. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="proxy_type" type="string" required>
  Specifies the type of proxy that fronts the application, which must be set to API_GATEWAY to route traffic through an API Gateway proxy. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Metadata that you can assign to help organize the frameworks that you create. Each tag is a key-value pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag attached to the AWS Refactor Spaces application, used to categorize the resource for cost allocation, access control, and operational management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the VPC in which the Refactor Spaces application's services and API Gateway proxy are deployed, required for routing and resource association. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="api_gateway_id" type="string">
  The read-only identifier of the Amazon API Gateway proxy that AWS Refactor Spaces associates with this application, serving as the endpoint for incoming traffic. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="application_identifier" type="string">
  A unique, system-assigned identifier for the Refactor Spaces application, used to reference the application in API calls and other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Refactor Spaces application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="nlb_arn" type="string">
  The Amazon Resource Name (ARN) of the Network Load Balancer (NLB) that AWS Refactor Spaces provisions for this application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="nlb_name" type="string">
  The name of the Network Load Balancer (NLB) that serves as the endpoint for the AWS Refactor Spaces application, automatically generated by the service when the application is provisioned. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="proxy_url" type="string">
  The API Gateway proxy endpoint URL that AWS Refactor Spaces creates for this application. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="stage_name" type="string">
  The read-only name of the API Gateway stage that fronts the Refactor Spaces application when its proxy type is API_GATEWAY. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpc_link_id" type="string">
  The ID of the VPC link that the Refactor Spaces application uses to connect to the VPC. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

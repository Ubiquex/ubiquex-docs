`aws_osis_pipeline` creates a real, fully managed OpenSearch Ingestion pipeline, a serverless Data Prepper configuration (in YAML) that filters, transforms, and routes data from a source such as S3 into an OpenSearch domain or collection without infrastructure to manage.

## Example

  Key-value pairs to configure encryption at rest. Optional.
  <Expandable title="properties">

</ResponseField>

<ResponseField name="log_publishing_options" type="object">

  The Pipeline Role (ARN) for the pipeline. Optional.

---

`aws_workspaces_instances_workspace_instance` launches a real EC2 instance directly into the calling account as a managed WorkSpaces Core desktop, under WorkSpaces Core Managed Instances' newer architecture, which places compute in the customer's own account rather than an account owned by the WorkSpaces service the way classic `aws_work_spaces_workspace` does.

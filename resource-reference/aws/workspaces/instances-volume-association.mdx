`aws_workspaces_instances_volume_association` attaches a real `aws_workspaces_instances_volume` to a specific `aws_workspaces_instances_workspace_instance`, the resource that actually represents the attach action rather than the volume itself.

## Example

    ```go
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    	workspaces "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/workspaces"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own instances volume association"})

    		ubx.Resource(workspaces.InstancesVolumeAssociation, "example", workspaces.InstancesVolumeAssociationConfig{
    			Device:              "example",
    			VolumeId:            "example",
    			WorkspaceInstanceId: "example",
    			DisassociateMode:    "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="device" type="string" required>
  The device name for the volume attachment Required.
</ResponseField>

<ResponseField name="disassociate_mode" type="string">
  Mode to use when disassociating the volume Optional.
</ResponseField>

<ResponseField name="volume_id" type="string" required>
  ID of the volume to attach to the workspace instance Required.
</ResponseField>

<ResponseField name="workspace_instance_id" type="string" required>
  ID of the workspace instance to associate with the volume Required.
</ResponseField>

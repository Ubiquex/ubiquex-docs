## Input properties

<ResponseField name="group_desc" type="string">
  The description of the group. Optional.
</ResponseField>

<ResponseField name="group_name" type="string" required>
  The name of the group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the IP access control group. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag attached to the WorkSpaces IP group, used for metadata and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user_rules" type="list(object)">
  The rules for the IP access control group. Optional.
  <Expandable title="properties">
    <ResponseField name="ip_rule" type="string">
      Specifies the IP address range in CIDR notation (e.g., 203.0.113.0/24) that defines which client IP addresses are permitted or denied access to WorkSpaces in this IP access control group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="rule_desc" type="string">
      A human-readable description for the IP access rule, used to label or explain the purpose of the rule within the WorkSpaces IP group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_emr_cluster` provisions a real, managed Hadoop/Spark cluster, EC2 instances running the actual big-data processing frameworks, that an `aws_emr_step` or an EMR Studio notebook runs work against.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Applications:          []map[string]any{{"name": "example-name"}},

    	}))
    }

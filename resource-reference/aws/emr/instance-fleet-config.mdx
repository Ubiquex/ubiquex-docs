`aws_emr_instance_fleet_config` defines a real, flexible mix of instance types and purchasing options, On-Demand and Spot together, for one role inside an `aws_emr_cluster`, EMR's newer, more flexible alternative to `aws_emr_instance_group_config`'s single-instance-type model.

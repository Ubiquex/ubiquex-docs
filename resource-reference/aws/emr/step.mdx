## Input properties

<ResponseField name="action_on_failure" type="string" required>
  This specifies what action to take when the cluster step fails. Possible values are CANCEL_AND_WAIT and CONTINUE. Required.
</ResponseField>

<ResponseField name="encryption_key_arn" type="string">
  The KMS key ARN to encrypt the logs published to the given Amazon S3 destination. When omitted, EMR falls back to cluster-level logging behavior. Optional.
</ResponseField>

<ResponseField name="hadoop_jar_step" type="object" required>
  Defines the Hadoop JAR step configuration for the EMR step, including the JAR location, main class, arguments, and custom properties. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="args" type="list(string)">
      A list of arguments to pass to the main class of the Hadoop JAR step. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="jar" type="string" required>
      The Amazon S3 location or full path to the JAR file that contains the main code for the EMR step. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="main_class" type="string">
      Specifies the name of the main class in the supplied JAR file that the EMR step will execute. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="step_properties" type="list(object)">
      This is a list of key-value objects that specify custom properties for the Hadoop JAR step, which are passed to the Hadoop framework during step execution. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          This key specifies a property name to pass to the Hadoop JAR step as part of the step's configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="string">
          The value of a property entry in the step_properties map of the Hadoop JAR step, used to pass custom configuration to the JAR when the step executes on the EMR cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="job_flow_id" type="string" required>
  A string that uniquely identifies the cluster (job flow). Required.
</ResponseField>

<ResponseField name="log_uri" type="string">
  The Amazon S3 destination URI for log publishing. When omitted, EMR falls back to cluster-level logging behavior. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the cluster step. Required.
</ResponseField>

  ID generated by service Computed by AWS after `ship`.

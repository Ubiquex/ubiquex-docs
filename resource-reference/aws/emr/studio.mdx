`aws_emr_studio` provisions a real, web-based integrated development environment for data scientists and analysts to develop, visualize, and debug data engineering and analytics applications, connecting to `aws_emr_cluster`s and EMR on EKS virtual clusters as compute backends.

## Input properties

<ResponseField name="auth_mode" type="string" required>
  Specifies whether the Studio authenticates users using single sign-on (SSO) or IAM. Amazon EMR Studio currently only supports SSO authentication. Required.
</ResponseField>

<ResponseField name="default_s3_location" type="string" required>
  The default Amazon S3 location to back up EMR Studio Workspaces and notebook files. A Studio user can select an alternative Amazon S3 location when creating a Workspace. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A detailed description of the Studio. Optional.
</ResponseField>

<ResponseField name="encryption_key_arn" type="string">
  The ARN of an AWS KMS key used to encrypt data within the EMR Studio workspace, such as notebooks and artifacts. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="engine_security_group_id" type="string" required>
  The ID of the Amazon EMR Studio Engine security group. The Engine security group allows inbound network traffic from the Workspace security group, and it must be in the same VPC specified by VpcId. Required.
</ResponseField>

<ResponseField name="idc_instance_arn" type="string">
  The ARN of the IAM Identity Center instance to create the Studio application. Optional.
</ResponseField>

<ResponseField name="idc_user_assignment" type="string">
  Specifies whether IAM Identity Center user assignment is REQUIRED or OPTIONAL. If the value is set to REQUIRED, users must be explicitly assigned to the Studio application to access the Studio. Optional.
</ResponseField>

<ResponseField name="idp_auth_url" type="string">
  Your identity provider's authentication endpoint. Amazon EMR Studio redirects federated users to this endpoint for authentication when logging in to a Studio with the Studio URL. Optional.
</ResponseField>

<ResponseField name="idp_relay_state_parameter_name" type="string">
  The name of relay state parameter for external Identity Provider. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A descriptive name for the Amazon EMR Studio. Required.
</ResponseField>

<ResponseField name="service_role" type="string" required>
  The IAM role that EMR Studio assumes to call AWS services on your behalf. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="subnet_ids" type="list(string)" required>
  A list of up to 5 subnet IDs to associate with the Studio. The subnets must belong to the VPC specified by VpcId. Studio users can create a Workspace in any of the specified subnets. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tags to attach to the EMR Studio, used for organizing, managing, and cost allocation of the resource in AWS. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Defines a user-defined tag key for the Amazon EMR Studio, which can be used for cost allocation, access control, and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag applied to the EMR Studio, used to categorize, identify, or manage the studio resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="trusted_identity_propagation_enabled" type="bool">
  A Boolean indicating whether to enable Trusted identity propagation for the Studio. The default value is false. Optional.
</ResponseField>

<ResponseField name="user_role" type="string">
  The IAM role that EMR Studio users assume, granting permissions for their studio work within the EMR Studio environment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpc_id" type="string" required>
  The ID of the Amazon Virtual Private Cloud (Amazon VPC) to associate with the Studio. Required.
</ResponseField>

<ResponseField name="workspace_security_group_id" type="string" required>
  The ID of the Amazon EMR Studio Workspace security group. The Workspace security group allows outbound network traffic to resources in the Engine security group, and it must be in the same VPC specified by VpcId. Required.
</ResponseField>

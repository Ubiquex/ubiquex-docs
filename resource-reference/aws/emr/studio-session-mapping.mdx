`aws_emr_studio_session_mapping` maps a real IAM Identity Center user or group to an `aws_emr_studio`, with an attached session policy refining exactly what that user or group can do inside the Studio.

## Example

    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own studio session mapping"})

    			IdentityName:     "example-identity-name",
    			IdentityType:     "example",
    			SessionPolicyArn: "arn:aws:iam::123456789012:policy/example",
    			StudioId:         "example",
    		})
    	}))
    }

## Properties

<ResponseField name="identity_name" type="string" required>
  The name of the user or group. For more information, see UserName and DisplayName in the AWS SSO Identity Store API Reference. Either IdentityName or IdentityId must be specified. Required.
</ResponseField>

<ResponseField name="identity_type" type="string" required>
  Specifies whether the identity to map to the Studio is a user or a group. Required.
</ResponseField>

<ResponseField name="session_policy_arn" type="string" required>
  The ARN of the IAM policy that defines the permissions for the EMR Studio session assigned to the mapped user or group. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="studio_id" type="string" required>
  The ID of the Amazon EMR Studio to which the user or group will be mapped. Required.
</ResponseField>

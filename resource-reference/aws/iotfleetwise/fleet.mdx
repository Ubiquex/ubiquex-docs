`aws_io_tfleet_wise_fleet` is a real, logical grouping of `aws_io_tfleet_wise_vehicle`s that an `aws_io_tfleet_wise_campaign` can target together rather than every vehicle being addressed individually. Part of AWS IoT FleetWise, which is no longer open to new customers.

`aws_io_tfleet_wise_vehicle` registers a real, individual vehicle running the AWS IoT FleetWise Edge Agent, the actual entity an `aws_io_tfleet_wise_campaign` and `aws_io_tfleet_wise_state_template` get associated with to collect data from. AWS IoT FleetWise is no longer open to new customers; existing customers can continue using it, with AWS pointing to its Guidance for Connected Mobility on AWS for equivalent new capability.

`aws_secrets_manager_resource_policy` attaches a real resource-based access policy to an `aws_secrets_manager_secret`, controlling which principals, including from other accounts, can retrieve or manage it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	secretsmanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/secretsmanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own manager resource policy"})

    		ubx.Resource(secretsmanager.ResourcePolicy, "example", secretsmanager.ResourcePolicyConfig{
    			ResourcePolicy:    "example",
    			SecretId:          "example",
    			BlockPublicPolicy: true,
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="block_public_policy" type="bool">
  Specifies whether to block resource-based policies that allow broad access to the secret. Optional.
</ResponseField>

<ResponseField name="resource_policy" type="string" required>
  A JSON-formatted string for an AWS resource-based policy. Required.
</ResponseField>

<ResponseField name="secret_id" type="string" required>
  The ARN or name of the secret to attach the resource-based policy. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The Arn of the secret. Computed by AWS after `ship`.
</ResponseField>

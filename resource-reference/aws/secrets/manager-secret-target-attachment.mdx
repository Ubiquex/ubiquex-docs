`aws_secrets_manager_secret_target_attachment` links an `aws_secrets_manager_secret` to a specific database or cluster resource it holds credentials for, the association Secrets Manager needs in place before it can rotate that secret using one of its built-in database rotation templates.

## Input properties

<ResponseField name="secret_id" type="string" required>
  The ARN or name of the AWS Secrets Manager secret to attach to the specified target (such as an RDS or Redshift cluster). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_id" type="string" required>
  The ARN of the AWS service resource (such as an Amazon RDS database instance or Amazon Redshift cluster) that the secret is attached to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="target_type" type="string" required>
  Specifies the AWS service type of the target that the secret is attached to, such as an RDS DB instance or Redshift cluster. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ARN of the secret that serves as the unique identifier for this attachment resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_route53_recovery_control_control_panel` groups real routing controls under an `aws_route53_recovery_control_cluster`, the container that `aws_route53_recovery_control_safety_rule`s are evaluated against when a routing control is toggled during failover.

## Example

    import (
    	route53recoverycontrol "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53recoverycontrol"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Name:       "example",
    			ClusterArn: "arn:aws:iam::123456789012:policy/example",

    		})
    	}))
    }

## Output properties

<ResponseField name="control_panel_arn" type="string">
  The Amazon Resource Name (ARN) of the cluster. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="default_control_panel" type="bool">
  A flag that Amazon Route 53 Application Recovery Controller sets to true to designate the default control panel for a cluster. When you create a cluster, Amazon Route 53 Application Recovery Controller creates a control panel, and sets this flag for that control panel. If you create a control panel yourself, this flag is set to false. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="routing_control_count" type="number">
  Count of associated routing controls Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The deployment status of control panel. Status can be one of the following: PENDING, DEPLOYED, PENDING_DELETION. Computed by AWS after `ship`.
</ResponseField>

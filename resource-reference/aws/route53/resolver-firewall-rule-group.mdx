`aws_route53_resolver_firewall_rule_group` groups real DNS firewall rules, each matching an `aws_route53_resolver_firewall_domain_list` with an allow, block, or alert action, that an `aws_route53_resolver_firewall_rule_group_association` applies to a VPC's outbound DNS traffic.

`aws_route53_recovery_control_cluster` creates a real, highly available cluster of Route 53 Application Recovery Controller endpoints across five AWS Regions, the redundant control plane that `aws_route53_recovery_control_control_panel`s and their routing controls depend on staying reachable during a regional outage.

## Input properties

<ResponseField name="name" type="string" required>
  Name of a Cluster. You can use any non-white space character in the name Required.
</ResponseField>

<ResponseField name="network_type" type="string">
  Cluster supports IPv4 endpoints and Dual-stack IPv4 and IPv6 endpoints. NetworkType can be IPV4 or DUALSTACK. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tags associated with a resource Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key for a tag attached to the Route53 Recovery Control Cluster, used to categorize and manage the cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Route 53 Recovery Control cluster. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

  The Amazon Resource Name (ARN) of the cluster. Computed by AWS after `ship`.

<ResponseField name="cluster_endpoints" type="list(object)">
  Endpoints for the cluster. Computed by AWS after `ship`.
  <Expandable title="properties">

  </Expandable>

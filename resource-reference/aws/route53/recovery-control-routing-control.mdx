`aws_route53_recovery_control_routing_control` creates a real, individual on/off switch within an `aws_route53_recovery_control_control_panel`, the resource an operator or an automated health check actually toggles during failover to redirect traffic.

## Example

  <Tab title="Go">

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own recovery control routing control"})

    		ubx.Resource(route53.RecoveryControlRoutingControl, "example", route53.RecoveryControlRoutingControlConfig{
    			Name:            "example",
    			ClusterArn:      "arn:aws:iam::123456789012:policy/example",
    			ControlPanelArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cluster_arn" type="string">
  Arn associated with Control Panel Optional.
</ResponseField>

<ResponseField name="control_panel_arn" type="string">
  The Amazon Resource Name (ARN) of the control panel. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the routing control. You can use any non-white space character in the name. Required.
</ResponseField>

## Output properties

<ResponseField name="routing_control_arn" type="string">
  The Amazon Resource Name (ARN) of the routing control. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The deployment status of the routing control. Status can be one of the following: PENDING, DEPLOYED, PENDING_DELETION. Computed by AWS after `ship`.
</ResponseField>

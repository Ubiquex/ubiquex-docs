`aws_route53_health_check` creates a real, recurring health check against an endpoint, an IP address, domain, or CloudWatch alarm, that DNS failover routing and `aws_route53_record_set` health-check associations rely on to detect an unhealthy target.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own health check"})

    		ubx.Resource(route53.HealthCheck, "example", route53.HealthCheckConfig{
    			HealthCheckConfig: map[string]any{"type": "example"},
    			HealthCheckTags:   []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="health_check_config" type="object" required>
  A complex type that contains information about the health check. Required.
  <Expandable title="properties">
    <ResponseField name="alarm_identifier" type="object">
      A complex type that identifies the CloudWatch alarm that you want Amazon Route 53 health checkers to use to determine whether the specified health check is healthy. Optional.
      <Expandable title="properties">
        <ResponseField name="name" type="string" required>
          The name of the CloudWatch alarm that you want Amazon Route 53 health checkers to use to determine whether this health check is healthy. Required.
        </ResponseField>
        <ResponseField name="region" type="string" required>
          For the CloudWatch alarm that you want Route 53 health checkers to use to determine whether this health check is healthy, the region that the alarm was created in. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="child_health_checks" type="list(string)">
      For a calculated health check, this field lists the health check IDs that Route 53 evaluates to determine the calculated health check's overall status. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enable_sni" type="bool">
      Indicates whether the health check uses Server Name Indication (SNI) when checking an HTTPS endpoint. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="failure_threshold" type="number">
      The number of consecutive health check failures that Amazon Route 53 must observe before marking the endpoint as unhealthy, as part of the health check configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="fully_qualified_domain_name" type="string">
      Specifies the fully qualified domain name of the endpoint (such as 'example.com') that Route 53 sends health check requests to, used when the health check targets a domain name instead of an IP address. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="health_threshold" type="number">
      The number of individual health checks that must be healthy for a calculated health check to be considered healthy. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="insufficient_data_health_status" type="string">
      Sets the health check status that Route 53 reports when CloudWatch does not have sufficient data to determine the endpoint's health, with allowed values of Healthy, Unhealthy, or LastKnownStatus. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="inverted" type="bool">
      When true, inverts the health check result so that a failed check is reported as healthy and a successful check is reported as unhealthy. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ipaddress" type="string">
      The IPv4 or IPv6 address of the endpoint that Route 53 health checks, used when the health check is configured to check a specific IP rather than a domain name. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="measure_latency" type="bool">
      Indicates whether Route 53 should measure latency between health checkers in different AWS regions and include the resulting latency data in the health check report. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="port" type="number">
      Specifies the port on the endpoint that Route 53 performs health checks against, with defaults of 80 for TCP/HTTP and 443 for HTTPS when omitted. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="regions" type="list(string)">
      Specifies the list of AWS regions from which Route 53 health checkers will issue requests to the endpoint being checked. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="request_interval" type="number">
      How often Route 53 sends a health check request to the endpoint; can be either 10 or 30 seconds, with 10 enabling fast health checks. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="resource_path" type="string">
      The URL path that Route 53 requests from the endpoint when performing an HTTP or HTTPS health check (for example, '/' or '/health'). Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="routing_control_arn" type="string">
      The ARN of the Route 53 Application Recovery Controller routing control that this health check is associated with, allowing the health check status to determine the routing control's state. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="search_string" type="string">
      Specifies the string that must appear in the response body for the health check to pass; used with HTTP/HTTPS health checks where the HealthCheckType is HTTP_STR_MATCH or HTTPS_STR_MATCH. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of health check to create (e.g., HTTP, HTTPS, TCP, HTTP_STR_MATCH, or CALCULATED), which determines the protocol or method used to evaluate the endpoint's health. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="health_check_tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a user-defined tag to associate with the Route 53 health check. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag on the Route 53 health check, providing arbitrary metadata associated with the resource for identification or categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_route53_resolver_resolver_config` configures a real, account-level Resolver setting, most commonly whether autodefined DNS rules for the AWS-provided DNS in a VPC are enabled, distinct from the per-endpoint settings on an `aws_route53_resolver_resolver_endpoint`.

## Input properties

<ResponseField name="autodefined_reverse_flag" type="string" required>
  Represents the desired status of AutodefinedReverse. The only supported value on creation is DISABLE. Deletion of this resource will return AutodefinedReverse to its default value (ENABLED). Required.
</ResponseField>

<ResponseField name="resource_id" type="string" required>
  The unique identifier of this route53 resolver resolver config. Required.
</ResponseField>

## Output properties

<ResponseField name="autodefined_reverse" type="string">
  ResolverAutodefinedReverseStatus, possible values are ENABLING, ENABLED, DISABLING AND DISABLED. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier of this route53 resolver resolver config. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="owner_id" type="string">
  The owner ID for this route53 resolver resolver config. Computed by AWS after `ship`.
</ResponseField>

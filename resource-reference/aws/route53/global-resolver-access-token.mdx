`aws_route53_global_resolver_access_token` issues a real credential that an authorized client uses to query an `aws_route53_global_resolver_global_resolver` from outside AWS, on-premises or over the internet, without a VPN or regional forwarding infrastructure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own global resolver access token"})

    		ubx.Resource(route53.GlobalResolverAccessToken, "example", route53.GlobalResolverAccessTokenConfig{
    			DnsViewId:   "example",
    			Name:        "example",
    			ClientToken: "example",
    			ExpiresAt:   "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="client_token" type="string">
  An optional caller-supplied token that ensures idempotent creation of the Route 53 Global Resolver access token by uniquely identifying the Create request, allowing safe retries without duplicating the token. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dns_view_id" type="string" required>
  Specifies the DNS view ID that this access token is scoped to, which the global resolver uses to authorize DNS resolution requests for that view. Required. **(AI-inferred)**
</ResponseField>

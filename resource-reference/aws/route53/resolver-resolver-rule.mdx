`aws_route53_resolver_resolver_rule` defines a real forwarding rule that sends DNS queries for a specific domain out through an `aws_route53_resolver_resolver_endpoint` to a specified on-premises or other DNS server, rather than resolving them through Route 53's own default resolution.

## Input properties

<ResponseField name="delegation_record" type="string">
  The name server domain for queries to be delegated to if a query matches the delegation record. Optional.
</ResponseField>

<ResponseField name="domain_name" type="string">
  DNS queries for this domain name are forwarded to the IP addresses that are specified in TargetIps Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name for the Resolver rule Optional.
</ResponseField>

<ResponseField name="resolver_endpoint_id" type="string">
  The ID of the endpoint that the rule is associated with. Optional.
</ResponseField>

<ResponseField name="rule_type" type="string" required>
  When you want to forward DNS queries for specified domain name to resolvers on your network, specify FORWARD. When you have a forwarding rule to forward DNS queries for a domain to your network and you want Resolver to process queries for a subdomain of that domain, specify SYSTEM. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to assign to the Route 53 Resolver rule for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Route 53 Resolver rule, used to assign metadata for identifying, organizing, or cost-allocation purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_ips" type="list(object)">
  An array that contains the IP addresses and ports that an outbound endpoint forwards DNS queries to. Typically, these are the IP addresses of DNS resolvers on your network. Specify IPv4 addresses. IPv6 is not supported. Optional.
  <Expandable title="properties">
    <ResponseField name="ip" type="string">
      The IP address to which DNS queries matching this resolver rule are forwarded. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ipv6" type="string">
      Specifies the IPv6 address of the target Resolver endpoint that this Resolver rule forwards DNS queries to. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="port" type="string">
      The port on the target IP address to which the Resolver Rule forwards DNS queries (defaults to 53 if not specified). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="protocol" type="string">
      The protocol used to forward DNS queries to the target IP address, either 'Do53' for standard DNS over port 53 or 'DoH' for DNS over HTTPS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="server_name_indication" type="string">
      The Server Name Indication (SNI) value to include in the TLS handshake when the resolver forwards DNS queries to this target IP using the DoH or DoT protocol. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

</ResponseField>

<ResponseField name="resolver_rule_id" type="string">
  The ID of the endpoint that the rule is associated with. Computed by AWS after `ship`.
</ResponseField>

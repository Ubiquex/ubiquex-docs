`aws_route53_recovery_readiness_recovery_group` groups real `aws_route53_recovery_readiness_cell`s together, the top-level unit that Route 53 Application Recovery Controller reports overall multi-Region readiness for.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53recoveryreadiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53recoveryreadiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own recovery readiness recovery group"})

    		ubx.Resource(route53recoveryreadiness.RecoveryGroup, "example", route53recoveryreadiness.RecoveryGroupConfig{
    			Cells:             []string{"example"},
    			RecoveryGroupName: "example-recovery-group-name",
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cells" type="list(string)">
  A list of the cell Amazon Resource Names (ARNs) in the recovery group. Optional.
</ResponseField>

<ResponseField name="recovery_group_name" type="string">
  The name of the recovery group to create. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tags associated with a resource. Optional.
  <Expandable title="properties">

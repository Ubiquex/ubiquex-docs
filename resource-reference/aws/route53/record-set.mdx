`aws_route53_record_set` creates a real DNS record, A, CNAME, MX, and more, including alias records that point at other AWS resources, within an `aws_route53_hosted_zone`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own record set"})

    		ubx.Resource(route53.RecordSet, "example", route53.RecordSetConfig{
    			Name:              "example",
    			Type:              "example",
    			AliasTarget:       map[string]any{"dnsname": "example", "hosted_zone_id": "example"},
    			CidrRoutingConfig: map[string]any{"collection_id": "example", "location_name": "example-location-name"},
    			Comment:           "example",
    			Failover:          "example",
    			GeoLocation:       map[string]any{"continent_code": "example"},
    			HealthCheckId:     "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="alias_target" type="object">
  Specifies alias record properties, enabling the record set to route traffic to an AWS resource (e.g., Elastic Load Balancer, CloudFront distribution, or S3 bucket) by providing the target's hosted zone ID and DNS name, with an optional evaluate-target-health flag. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="dnsname" type="string" required>
      The value that you specify depends on where you want to route queries. Required.
    </ResponseField>
    <ResponseField name="evaluate_target_health" type="bool">
      When EvaluateTargetHealth is true, an alias resource record set inherits the health of the referenced AWS resource, such as an ELB load balancer or another resource record set in the hosted zone. Optional.
    </ResponseField>
    <ResponseField name="hosted_zone_id" type="string" required>
      The hosted zone ID of the AWS resource (such as an Elastic Load Balancer, CloudFront distribution, or S3 website bucket) that this alias record points to. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cidr_routing_config" type="object">
  Configures CIDR-based routing for the record set by specifying the CIDR collection ID and location name that determine which traffic is directed to this record. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="collection_id" type="string" required>
      The CIDR collection ID. Required.
    </ResponseField>
    <ResponseField name="location_name" type="string" required>
      The CIDR collection location name. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="comment" type="string">
  Specifies an optional human-readable comment that provides descriptive information about the record set, useful for identifying the purpose of the record. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="failover" type="string">
  Indicates whether this record set is the primary or secondary resource for a Route 53 failover routing policy, controlling which record answers queries based on health check status. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="geo_location" type="object">
  Specifies the geographic location (continent, country, or subdivision) that this Route 53 record set serves, enabling geolocation routing so DNS queries from that location are answered with this record. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="continent_code" type="string">
      For geolocation resource record sets, a two-letter abbreviation that identifies a continent. Optional.
    </ResponseField>
    <ResponseField name="country_code" type="string">
      For geolocation resource record sets, the two-letter code for a country. Optional.
    </ResponseField>
    <ResponseField name="subdivision_code" type="string">
      For geolocation resource record sets, the two-letter code for a state of the United States. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="health_check_id" type="string">
  The ID of the Amazon Route 53 health check associated with this record set, which Route 53 uses to monitor the health of the resource and determine whether to include the record in DNS responses for failover or latency-based routing. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="hosted_zone_id" type="string">
  The ID of the hosted zone in which to create the record set, allowing you to specify the zone by its unique identifier instead of its domain name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="hosted_zone_name" type="string">
  The DNS name of an existing Route 53 hosted zone (such as example.com) in which to create the record set; when provided, it is used as an alternative to the hosted zone ID to identify the zone. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="multi_value_answer" type="bool">
  When enabled, this record set uses multivalue answer routing, allowing Route 53 to return multiple healthy values (e.g., IP addresses) in response to DNS queries. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The DNS record name (fully qualified domain name) such as 'www.example.com', which defines the domain name that the record set answers queries for in Amazon Route 53. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="region" type="string">
  Specifies the AWS Region where the resource referenced by this record set resides, which Route 53 uses to route DNS queries to the closest region when the routing policy is set to latency-based routing. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_records" type="list(string)">
  The list of values for the record set, such as IP addresses for A records, hostnames for CNAME records, or text strings for TXT records, and cannot be set when an alias target is specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="set_identifier" type="string">
  Specifies a unique identifier for the record set, used to distinguish it from other record sets with the same DNS name and type when the routing policy is weighted, latency, geolocation, multivalue, or failover. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="ttl" type="string">
  The time-to-live (TTL) in seconds that DNS resolvers cache this record before requesting an updated value from Route 53. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="type" type="string" required>
  The DNS record type (e.g., A, AAAA, CNAME, MX) for the Route 53 record set. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="weight" type="number">
  The relative weight to assign to this record set when using the weighted routing policy, controlling the proportion of DNS responses that point to this record. Optional. **(AI-inferred)**
</ResponseField>

`aws_route53_global_resolver_firewall_domain_list` defines a real list of domains that an `aws_route53_global_resolver_firewall_rule` matches DNS queries against on an `aws_route53_global_resolver_global_resolver`, the Global Resolver counterpart to `aws_route53_resolver_firewall_domain_list`.

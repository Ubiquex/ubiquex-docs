`aws_route53_profiles_profile` creates a real Route 53 Profile, a reusable bundle of DNS configuration, private hosted zone associations, Resolver rules, DNS Firewall rules, that can be applied consistently across many VPCs at once rather than configured VPC by VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own profiles profile"})

    		ubx.Resource(route53.ProfilesProfile, "example", route53.ProfilesProfileConfig{
    			Name: "example",
    			Tags: []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="name" type="string" required>
  The name of the profile. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Route 53 Profiles profile, used to identify and categorize the profile in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag assigned to the Route 53 Profile, used to organize, identify, and manage access to the profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

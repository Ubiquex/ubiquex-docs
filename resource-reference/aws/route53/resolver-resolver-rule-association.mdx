`aws_route53_resolver_resolver_rule_association` associates a real `aws_route53_resolver_resolver_rule` with a specific VPC, the resource that actually turns the rule's forwarding behavior on for that VPC's DNS queries.

## Input properties

<ResponseField name="name" type="string">
  The name of an association between a Resolver rule and a VPC. The name can be up to 64 characters long and can contain letters (a-z, A-Z), numbers (0-9), hyphens (-), underscores (_), and spaces. The name cannot consist of only numbers. Optional.
</ResponseField>

<ResponseField name="resolver_rule_id" type="string" required>
  The ID of the Resolver rule that you associated with the VPC that is specified by ``VPCId``. Required.
</ResponseField>

<ResponseField name="vpcid" type="string" required>
  The ID of the VPC that you associated the Resolver rule with. Required.
</ResponseField>

## Output properties

<ResponseField name="resolver_rule_association_id" type="string">
  The unique ID assigned by AWS to this Resolver rule association, returned by the service to identify the association between a VPC and a Resolver rule. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

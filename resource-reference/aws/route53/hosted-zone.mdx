`aws_route53_hosted_zone` creates a real container for DNS records for a domain, public (resolvable on the internet) or private (resolvable only inside associated VPCs), that `aws_route53_record_set`s are created within.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hosted zone"})

    		ubx.Resource(route53.HostedZone, "example", route53.HostedZoneConfig{
    			Name:               "example",
    			HostedZoneConfig:   map[string]any{"comment": "example"},
    			HostedZoneFeatures: map[string]any{"enable_accelerated_recovery": true},
    			HostedZoneTags:     []map[string]any{{"key": "example"}},
    			QueryLoggingConfig: map[string]any{"cloud_watch_logs_log_group_arn": "example"},
    			Vpcs:               []map[string]any{{"vpcid": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="hosted_zone_config" type="object">
  A complex type that contains an optional comment about your hosted zone. If you don't want to specify a comment, omit both the ``HostedZoneConfig`` and ``Comment`` elements. Optional.
  <Expandable title="properties">
    <ResponseField name="comment" type="string">
      Any comments that you want to include about the hosted zone. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="hosted_zone_features" type="object">
  Represents the features configuration for a hosted zone, including the status of various features and any associated failure reasons. Optional.
  <Expandable title="properties">
    <ResponseField name="enable_accelerated_recovery" type="bool">
      Enables accelerated recovery for the hosted zone, which allows Amazon Route 53 Application Recovery Controller to more quickly update DNS records during a failover event. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="hosted_zone_tags" type="list(object)">
  Adds, edits, or deletes tags for a health check or a hosted zone. For information about using tags for cost allocation, see [Using Cost Allocation Tags](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html) in the *User Guide*. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Route53 hosted zone, used to organize and identify the hosted zone within your AWS environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag in the HostedZoneTags list, which provides an arbitrary string that, together with the tag key, helps identify and manage the Route 53 hosted zone. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the domain. Specify a fully qualified domain name, for example, *www.example.com*. The trailing dot is optional; Amazon Route 53 assumes that the domain name is fully qualified. This means that Route 53 treats *www.example.com* (without a trailing dot) and *www.example.com.* (with a trailing dot) as identical. If you're creating a public hosted zone, this is the name you have registered with your DNS registrar. If your domain name is registered with a registrar other than Route 53, change the name servers for your domain to the set of ``NameServers`` that are returned by the ``Fn::GetAtt`` intrinsic function. Optional.
</ResponseField>

<ResponseField name="query_logging_config" type="object">
  A complex type that contains information about a configuration for DNS query logging. Optional.
  <Expandable title="properties">
    <ResponseField name="cloud_watch_logs_log_group_arn" type="string" required>
      The Amazon Resource Name (ARN) of the CloudWatch Logs log group that Amazon Route 53 is publishing logs to. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpcs" type="list(object)">
  *Private hosted zones:* A complex type that contains information about the VPCs that are associated with the specified hosted zone. For public hosted zones, omit ``VPCs``, ``VPCId``, and ``VPCRegion``. Optional.
  <Expandable title="properties">
    <ResponseField name="vpcid" type="string">
      The ID of the VPC that is associated with this private hosted zone, which authorizes the VPC to use the hosted zone for DNS resolution. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpcregion" type="string">
      Specifies the AWS Region where the VPC that you want to associate with this private hosted zone is located, as required when associating a VPC by ID. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by Route 53 to the hosted zone, such as Z1234567890ABCDEF. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="name_servers" type="list(string)">
  The list of four authoritative Route 53 name servers assigned to the hosted zone for DNS resolution. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

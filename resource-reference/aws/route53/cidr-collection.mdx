`aws_route53_cidr_collection` defines a real, named collection of CIDR blocks that an `aws_route53_resolver_resolver_rule` or routing policy can reference by name, instead of listing raw IP ranges inline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own cidr collection"})

    		ubx.Resource(route53.CidrCollection, "ci-runner", route53.CidrCollectionConfig{
    			Name:      "ci-runner",
    			Locations: []map[string]any{{"cidr_list": []string{"example"}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="locations" type="list(object)">
  A complex type that contains information about the list of CIDR locations. Optional.
  <Expandable title="properties">
    <ResponseField name="cidr_list" type="list(string)">
      Specifies the list of CIDR blocks (such as '192.0.2.0/24') that define the IP address ranges for this location within the Route 53 CIDR collection, which are then used for DNS routing policies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="location_name" type="string">
      The name of the CIDR location within the CIDR collection, serving as a unique identifier for associating the location's CIDR blocks with routing rules. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A unique name for the CIDR collection. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon resource name (ARN) to uniquely identify the AWS resource. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  UUID of the CIDR collection. Computed by AWS after `ship`.
</ResponseField>

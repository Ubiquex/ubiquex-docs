`aws_route53_global_resolver_global_resolver` creates a real, internet-reachable anycast DNS resolver that resolves both public internet domains and an account's own Route 53 private hosted zones for authorized clients anywhere, on-premises data centers, branch offices, remote workers, without a VPN or per-Region forwarding setup. Route 53 Global Resolver reached general availability on March 9, 2026, roughly five months ago, so behavior here is verified live rather than assumed from general knowledge; resources must be managed in the US East (Ohio) Region regardless of where clients actually query from.

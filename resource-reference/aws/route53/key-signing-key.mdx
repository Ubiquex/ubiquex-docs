`aws_route53_key_signing_key` creates a real cryptographic key pair used to sign an `aws_route53_hosted_zone`'s own DNS records, the key an `aws_route53_dnssec` configuration actually signs with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own key signing key"})

    		ubx.Resource(route53.KeySigningKey, "ci-runner", route53.KeySigningKeyConfig{
    			HostedZoneId:            "example",
    			KeyManagementServiceArn: "arn:aws:iam::123456789012:policy/ci",
    			Name:                    "ci-runner",
    			Status:                  "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="hosted_zone_id" type="string" required>
  The unique string (ID) used to identify a hosted zone. Required.
</ResponseField>

<ResponseField name="key_management_service_arn" type="string" required>
  The Amazon resource name (ARN) for a customer managed key (CMK) in AWS Key Management Service (KMS). The KeyManagementServiceArn must be unique for each key signing key (KSK) in a single hosted zone. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  An alphanumeric string used to identify a key signing key (KSK). Name must be unique for each key signing key in the same hosted zone. Required.
</ResponseField>

<ResponseField name="status" type="string" required>
  A string specifying the initial status of the key signing key (KSK). You can set the value to ACTIVE or INACTIVE. Required.
</ResponseField>

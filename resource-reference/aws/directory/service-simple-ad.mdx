`aws_directory_service_simple_ad` provisions Simple AD, a Samba-based, lower-cost, feature-limited directory compared to `aws_directory_service_microsoft_ad`, suited to workloads needing basic AD compatibility rather than full Microsoft AD fidelity. Simple AD closed to new customers on July 30, 2026; existing directories and integrated workloads continue functioning, with AWS pointing new customers to AWS Managed Microsoft AD or AD Connector instead.

## Input properties

</ResponseField>

<ResponseField name="enable_sso" type="bool">
  Whether to enable single sign-on for a Simple Active Directory in AWS. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The fully qualified domain name for the AWS Managed Simple AD directory. Required.
</ResponseField>

<ResponseField name="password" type="string">
  The password for the default administrative user named Admin. Optional.
</ResponseField>

<ResponseField name="short_name" type="string">
  The NetBIOS name for your domain. Optional.
</ResponseField>

<ResponseField name="size" type="string" required>
  The size of the directory. Required.
</ResponseField>

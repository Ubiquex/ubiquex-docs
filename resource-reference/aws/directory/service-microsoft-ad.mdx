`aws_directory_service_microsoft_ad` provisions AWS Managed Microsoft AD, a real, actual Windows Server Active Directory running on AWS with Group Policy, trusts, schema extensions, and Kerberos authentication, rather than an AD-compatible but limited-feature substitute.

## Input properties

<ResponseField name="create_alias" type="bool">
  If set to true, AWS Directory Service creates a public alias for the Microsoft AD directory (used in the directory's access URL), and when omitted the default is true. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="edition" type="string">
  Specifies the edition of the Microsoft Active Directory, either Standard (default) or Enterprise, which determines the directory's feature set and scaling capabilities. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_sso" type="bool">
  Enables single sign-on (SSO) for the AWS Managed Microsoft AD directory, allowing users to access supported applications using their existing Active Directory credentials. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The fully qualified domain name (FQDN) for the Microsoft Active Directory, such as corp.example.com. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="password" type="string" required>
  The password for the directory administrator account, which must meet the complexity and length requirements for AWS Managed Microsoft AD. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="short_name" type="string">
  Specifies the short name (NetBIOS name) of the Active Directory domain, which is a single-label name that can be used in place of the fully qualified domain name (FQDN) when referring to the domain. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="vpc_settings" type="object" required>
  Specifies the VPC and subnets (two in different Availability Zones) where the Microsoft AD directory is deployed. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="subnet_ids" type="list(string)" required>
      The identifiers of two subnets in different Availability Zones where the directory's domain controllers will be deployed. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="vpc_id" type="string" required>
      The ID of the VPC in which the Microsoft Active Directory is created. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="alias" type="string">
  The DNS alias automatically generated by AWS for the Microsoft Active Directory, used to uniquely identify the directory when connecting to it. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="dns_ip_addresses" type="list(string)">
  The automatically assigned IP addresses of the DNS servers for the Microsoft Active Directory directory, returned by AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier of the AWS Managed Microsoft AD directory, assigned by AWS upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

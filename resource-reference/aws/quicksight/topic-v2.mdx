`aws_quick_sight_topic_v2` defines a newer-generation version of an `aws_quick_sight_topic`, Amazon Quick's current natural-language topic configuration, superseding the original topic resource's schema for new topics.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sight topic v2"})

    		ubx.Resource(quicksight.TopicV2, "example", quicksight.TopicV2Config{
    			Name:               "example",
    			AwsAccountId:       "example",
    			CustomInstructions: map[string]any{"custom_instructions_string": "example"},
    			DataSetRelations:   []map[string]any{{"left": map[string]any{"column_names": []string{"example"}}}},
    			DataSets:           []map[string]any{{"data_set_arn": "example"}},
    			Description:        "Managed by ubx.",
    			FolderArns:         []string{"example"},
    			Permissions:        []map[string]any{{"actions": []string{"example"}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="aws_account_id" type="string">
  The AWS account ID in which the QuickSight topic is created or managed; defaults to the account associated with the provider credentials if not specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="custom_instructions" type="object">
  Optional.
  <Expandable title="properties">
    <ResponseField name="custom_instructions_string" type="string" required>
      The textual content of the custom instruction to associate with the QuickSight topic, which is displayed to users as guidance when they interact with the topic. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="data_set_relations" type="list(object)">
  Specifies the relationships among the datasets associated with the QuickSight topic, enabling the topic to understand how to join or relate data from different sources. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="left" type="object">
      The left-hand dataset reference in a data set relation, which identifies the dataset on the left side of a relationship defined in a QuickSight topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="column_names" type="list(string)">
          The list of column names on the left side of a dataset relation in a QuickSight topic, which are matched to the right-side columns to define the join relationship. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="data_set_arn" type="string">
          The Amazon Resource Name (ARN) of the dataset that acts as the left side of a relationship between two datasets in the QuickSight topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="right" type="object">
      The right object identifies the right-side field reference in a dataset relation, containing the dataset ARN and field name needed to link that dataset to the left-side field in the QuickSight topic semantic model. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="column_names" type="list(string)">
          The list of column names on the right-side dataset that are used as join keys to establish a data set relation in a QuickSight topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="data_set_arn" type="string">
          The ARN of the right-side dataset participating in a data set relation within an Amazon QuickSight topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="data_sets" type="list(object)">
  Defines the list of datasets that comprise this QuickSight topic, with each dataset object specifying the dataset ARN and name (and other optional attributes) that the topic uses to build its semantic model. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_set_arn" type="string">
      Specifies the Amazon Resource Name (ARN) of the QuickSight dataset to include in the topic's data set collection. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="data_set_name" type="string">
      The name of the QuickSight dataset that the topic's data set definition refers to, used to identify the dataset among the topic's data sets. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The human-readable summary of the Amazon QuickSight topic, describing its purpose or the data it represents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="folder_arns" type="list(string)">
  The folder_arns field specifies the list of Amazon QuickSight folder ARNs to which this topic is associated, allowing the topic to be organized within folders. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Sets the display name of the QuickSight topic, which is the human-readable label used to identify the topic in the QuickSight console. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="permissions" type="list(object)">
  A list of resource permissions that grant or revoke access to the QuickSight topic for specific principals (users, groups, or folders), each specifying allowed actions. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="actions" type="list(string)">
      The list of IAM QuickSight actions (e.g., quickSight:DescribeTopic, quickSight:UpdateTopic, quickSight:DeleteTopic) that the permission entry grants to the specified principal. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="principal" type="string">
      The Amazon Resource Name (ARN) of the principal (QuickSight user, group, or IAM role) that the associated permission actions apply to for this QuickSight topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topic_id" type="string">
  The unique identifier for the QuickSight topic, used when importing an existing topic or to reference the topic in other resources. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the QuickSight topic, assigned by AWS when the topic is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

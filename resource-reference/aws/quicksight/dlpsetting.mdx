`aws_quick_sight_dlpsetting` configures real data loss prevention enforcement for Amazon Quick, applying Microsoft Purview sensitivity labels to control (block, warn, or allow) how files are handled across Quick's spaces, chat, and knowledge bases. This is a genuinely new integration, announced in August 2026, so behavior here is verified live rather than assumed from general knowledge.

<ResponseField name="provider_config" type="object" required>

        <ResponseField name="credentials" type="object">

        <ResponseField name="label_action_mappings" type="list(object)">
          Maps Microsoft Purview sensitivity labels to configured actions (e.g., masking or blocking) that QuickSight applies to protect data in dashboards and analyses. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="action" type="string">

            </ResponseField>
            <ResponseField name="label_id" type="string">
              The identifier of a Microsoft Purview sensitivity label that is mapped to a DLP action in the QuickSight DLP settings provider configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="label_name" type="string">
              The label_name specifies the name of a Microsoft Purview sensitivity label that this mapping applies to in the DLP provider configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**

          </Expandable>
        </ResponseField>
        <ResponseField name="unmapped_action" type="string">

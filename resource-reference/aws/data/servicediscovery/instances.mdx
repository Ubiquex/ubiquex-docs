---
title: "aws_servicediscovery_instances"
description: "`data_aws_servicediscovery_instances` looks up a real, already-existing `aws_service_discovery_instance`."
---

It registers a real, discoverable endpoint, an IP address or ARN plus custom attributes, under an `aws_service_discovery_service`, the actual instance that discovery queries against that service return.

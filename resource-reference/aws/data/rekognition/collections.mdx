---
title: "aws_rekognition_collections"
description: "`data_aws_rekognition_collections` looks up a real, already-existing `aws_rekognition_collection`."
---

It creates a real container of indexed face vectors that Rekognition's face-search operations compare newly detected faces against, independent of any specific `aws_rekognition_project`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rekognition "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/rekognition"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_rekognition_collections"})

    		ubx.Data(rekognition.Collections, "example", rekognition.CollectionsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.rekognition import Collections, CollectionsConfig

    def describe():
        ubx.intent("look up aws_rekognition_collections")

        ubx.data(Collections, "example", CollectionsConfig(
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="collection_ids" type="list(string)">
  The real, unique identifiers of the collections this request is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="face_model_versions" type="list(string)">
  The real versions of the face model included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_rekognition_stream_processors"
description: "`data_aws_rekognition_stream_processors` looks up a real, already-existing `aws_rekognition_stream_processor`."
---

It creates a real processor that analyzes a live Kinesis video stream in near real time, detecting faces or labels frame by frame and publishing matches, distinct from Rekognition's own batch image and video analysis APIs.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			MaxResults: 1,
    		})
    	}))
    }

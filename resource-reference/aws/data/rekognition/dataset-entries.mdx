---
title: "aws_rekognition_dataset_entries"
description: "`data_aws_rekognition_dataset_entries` looks up a real, already-existing `aws_rekognition_dataset`."
---

It imports a real set of labeled training or test images into an `aws_rekognition_project`, the data Custom Labels actually trains and evaluates a model against.

## Lookup arguments

<ResponseField name="contains_labels" type="list(string)">
  Restricts results to objects containing these labels. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="dataset_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the dataset this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="has_errors" type="bool">
  Whether this object encountered errors. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="labeled" type="bool">
  Whether this object has been labeled. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="source_ref_contains" type="string">
  Restricts results to source references containing this substring. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="dataset_entries" type="list(string)">
  The real dataset entries included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rekognition "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/rekognition"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_rekognition_faces"})

    		ubx.Data(rekognition.Faces, "example", rekognition.FacesConfig{
    			CollectionId: "example",
    			FaceIds:      []string{"example"},
    			MaxResults:   1,
    			UserId:       "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="collection_id" type="string" required>
  The real, unique identifier of the collection this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="face_ids" type="list(string)">
  The real, unique identifiers of the faces this request is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="user_id" type="string">
  The real, unique identifier of the user this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="face_model_version" type="string">
  The real version of the face model. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="faces" type="list(object)">
  The real faces detected in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

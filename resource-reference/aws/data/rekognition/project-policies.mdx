---
title: "aws_rekognition_project_policies"
description: "`data_aws_rekognition_project_policies` looks up a real, already-existing `aws_rekognition_project`."
---

It creates a real Rekognition Custom Labels project, the container that groups the `aws_rekognition_dataset`s and trained model versions built to detect a customer's own custom labels rather than Rekognition's built-in label set.

---
title: "aws_rekognition_dataset_labels"
description: "`data_aws_rekognition_dataset_labels` looks up a real, already-existing `aws_rekognition_dataset`."
---

It imports a real set of labeled training or test images into an `aws_rekognition_project`, the data Custom Labels actually trains and evaluates a model against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rekognition "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/rekognition"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_rekognition_dataset_labels"})

    		ubx.Data(rekognition.DatasetLabels, "example", rekognition.DatasetLabelsConfig{
    			DatasetArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="dataset_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the dataset this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="dataset_label_descriptions" type="list(object)">
  The real, described labels for this dataset. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

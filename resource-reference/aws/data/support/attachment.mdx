## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	support "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/support"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_support_attachment"})

    		ubx.Data(support.Attachment, "example", support.AttachmentConfig{
    			AttachmentId: "example",
    		})
    	}))
    }
    ```

    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH

    from ubx.aws.data.support import Attachment, AttachmentConfig

    def describe():
        ubx.intent("look up aws_support_attachment")

        ubx.data(Attachment, "example", AttachmentConfig(
            attachment_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="attachment_id" type="string" required>
  The real, unique identifier of the attachment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="attachment" type="object">
  &lt;p&gt;An attachment to a case communication. The attachment consists of the file name and the content of the file. Each attachment file size should not exceed 5 MB. File types that are supported include the following: pdf, jpeg,.doc, .log, .text &lt;/p&gt; Returned by the lookup.

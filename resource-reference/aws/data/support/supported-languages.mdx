## Example

    ```go
    package main

    import (
    	support "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/support"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_support_supported_languages"})

    		ubx.Data(support.SupportedLanguages, "example", support.SupportedLanguagesConfig{
    			CategoryCode: "example",
    			IssueType:    "example",
    			ServiceCode:  "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="category_code" type="string" required>
  The real code identifying the category. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="issue_type" type="string" required>
  The real, discriminating type of the issue this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="service_code" type="string" required>
  The real, unique code identifying the AWS service this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="supported_languages" type="list(object)">
  The real languages supported by this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

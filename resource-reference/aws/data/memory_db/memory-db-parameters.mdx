---
title: "aws_memory_db_parameters"
description: "`data_aws_memory_db_parameters` looks up a real, already-existing `aws_memory_db_parameter_group`."
---

It defines a real set of engine configuration parameters that can be applied to one or more `aws_memory_db_cluster`s instead of hand-tuning each cluster individually.

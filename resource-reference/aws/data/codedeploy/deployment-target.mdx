---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codedeploy "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codedeploy"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codedeploy_deployment_target"})

    		ubx.Data(codedeploy.DeploymentTarget, "example", codedeploy.DeploymentTargetConfig{
    			DeploymentId: "example",
    			TargetId:     "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="deployment_id" type="string" required>
  The real, unique identifier of the deployment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="target_id" type="string" required>
  The real, unique identifier of the target this action applies to. **(AI-inferred)** Required lookup argument.
</ResponseField>

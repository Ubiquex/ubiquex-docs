## Lookup arguments

<ResponseField name="connection_token" type="string" required>
  The real, opaque token identifying this connection. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="contact_id" type="string">
  The real, unique identifier of the contact this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="scan_direction" type="string">
  The real direction (forward or backward) this scan reads in. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_order" type="string">
  The real order (ascending or descending) results are sorted in. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="start_position" type="object">
  &lt;p&gt;A filtering option for where to start. For example, if you sent 100 messages, start with message 50. &lt;/p&gt; Optional lookup argument.

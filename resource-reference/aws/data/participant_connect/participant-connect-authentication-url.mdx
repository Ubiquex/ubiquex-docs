## Lookup arguments

<ResponseField name="connection_token" type="string" required>
  The real, opaque token identifying this connection. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="redirect_uri" type="string" required>
  The real, resolvable URI of the redirect this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="session_id" type="string" required>
  The real, unique identifier of the session this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="authentication_url" type="string">
  The real, resolvable URL of the authentication this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

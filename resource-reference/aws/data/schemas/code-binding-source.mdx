`aws_schemas_code_binding_source` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go

    import (
    	schemas "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/schemas"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_schemas_code_binding_source"})

    		ubx.Data(schemas.CodeBindingSource, "example", schemas.CodeBindingSourceConfig{
    			Language:      "example",
    			RegistryName:  "example-registry-name",
    			SchemaName:    "example-schema-name",
    			SchemaVersion: "example",
    		})
    	}))
    }
    ```

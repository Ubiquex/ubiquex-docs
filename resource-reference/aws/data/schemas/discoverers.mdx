## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	schemas "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/schemas"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_schemas_discoverers"})

    		ubx.Data(schemas.Discoverers, "example", schemas.DiscoverersConfig{
    			DiscovererIdPrefix: "example",
    			Limit:              1,
    			SourceArnPrefix:    "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="discoverer_id_prefix" type="string">
  The real S3 key prefix used for the discoverer id. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="source_arn_prefix" type="string">
  The real S3 key prefix used for the source arn. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="discoverers" type="list(object)">
  The real AWS Glue Schema Registry discoverers included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

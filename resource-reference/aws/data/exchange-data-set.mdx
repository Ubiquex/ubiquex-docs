`aws_data_exchange_data_set` is the real, curated resource a data provider assembles in AWS Data Exchange, files, an API, Redshift, S3, or Lake Formation data, that a receiver gains access to once they accept a real data grant or subscribe to a Marketplace data product built around it.

## Input properties

<ResponseField name="asset_type" type="string" required>
  The type of asset that is added to a data set. Required.
</ResponseField>

<ResponseField name="description" type="string" required>
  A description for the data set. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the data set. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags for the data set. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (name) of a tag attached to the AWS Data Exchange data set, used to organize, identify, and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN for the data set. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The date and time that the data set was created, in ISO 8601 format. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier for the data set. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="origin" type="string">
  A property that defines the data set as OWNED by the account (for providers) or ENTITLED to the account (for subscribers). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The date and time that the data set was last updated, in ISO 8601 format. Computed by AWS after `ship`.
</ResponseField>

---
title: "aws_ivs_stream_keys"
description: "`data_aws_ivs_stream_keys` looks up a real, already-existing `aws_ivs_stream_key`."
---

It is the real, secret credential streaming software uses to authenticate and publish video to a specific `aws_ivs_channel`, distinct from the channel's own public ingest endpoint URL.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ivs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/ivs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ivs_stream_keys"})

    		ubx.Data(ivs.StreamKeys, "example", ivs.StreamKeysConfig{
    			ChannelArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="channel_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the channel this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="stream_keys" type="list(object)">
  The real, unique keys of the streams included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_ivs_playback_key_pair"
description: "`data_aws_ivs_playback_key_pair` looks up a real, already-existing `aws_ivs_playback_key_pair`."
---

It signs real, private playback tokens for an `aws_ivs_channel` configured to require authorization, restricting viewing to clients that present a token signed by this specific key pair.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ivs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/ivs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ivs_playback_key_pair"})

    		ubx.Data(ivs.PlaybackKeyPair, "example", ivs.PlaybackKeyPairConfig{
    			Arn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

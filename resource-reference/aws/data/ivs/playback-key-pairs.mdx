---
title: "aws_ivs_playback_key_pairs"
description: "`data_aws_ivs_playback_key_pairs` looks up a real, already-existing `aws_ivs_playback_key_pair`."
---

It signs real, private playback tokens for an `aws_ivs_channel` configured to require authorization, restricting viewing to clients that present a token signed by this specific key pair.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ivs_playback_key_pairs"})

    		ubx.Data(ivs.PlaybackKeyPairs, "example", ivs.PlaybackKeyPairsConfig{
    			MaxResults: 1,
    		})
    	}))
    }

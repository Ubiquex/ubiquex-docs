---
title: "aws_backup_report_plans"
description: "`data_aws_backup_report_plans` looks up a real, already-existing `aws_backup_report_plan`."
---

It generates recurring, downloadable AWS Backup Audit Manager reports summarizing compliance against an `aws_backup_framework`'s controls over time, real evidence a caller can hand to an auditor rather than assembling one by hand.

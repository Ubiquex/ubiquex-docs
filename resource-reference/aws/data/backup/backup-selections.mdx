---
title: "aws_backup_backup_selections"
description: "`data_aws_backup_backup_selections` looks up a real, already-existing `aws_backup_selection`."
---

It assigns real AWS resources, by tag, by explicit resource ID, or by IAM role, to an `aws_backup_plan`, the actual mechanism that determines which resources a plan's schedule and lifecycle rules apply to. A plan with no selection protects nothing.

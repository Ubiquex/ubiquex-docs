---
title: "aws_backup_backup_plans"
description: "`data_aws_backup_backup_plans` looks up a real, already-existing `aws_backup_plan`."
---

It defines a backup policy, schedule, lifecycle, and target `aws_backup_vault`, that gets applied to AWS resources through an `aws_backup_selection`, the real, centrally managed alternative to writing custom per-service backup scripts.

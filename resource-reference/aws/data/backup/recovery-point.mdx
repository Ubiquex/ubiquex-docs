## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	backup "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/backup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_backup_recovery_point"})

    		ubx.Data(backup.RecoveryPoint, "example", backup.RecoveryPointConfig{
    			BackupVaultName:      "example-backup-vault-name",
    			RecoveryPointArn:     "arn:aws:iam::123456789012:policy/example",
    			BackupVaultAccountId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="backup_vault_account_id" type="string">
  The real AWS account ID that owns the AWS Backup vault this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="backup_vault_name" type="string" required>
  The real name of the AWS Backup vault this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="recovery_point_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the AWS Backup recovery point this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

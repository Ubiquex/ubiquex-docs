---
title: "aws_backup_backup_vaults"
description: "`data_aws_backup_backup_vaults` looks up a real, already-existing `aws_backup_vault`."
---

It is where AWS Backup actually stores backups, separated from their source resources so a backup survives even if the original EC2 instance or EBS volume is deleted, with its own encryption key and resource-based access policy controlling who can read or restore from it.

## Lookup arguments

<ResponseField name="by_shared" type="bool">
  Restricts results to shared objects. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="by_vault_type" type="string">
  The real, discriminating type of the by vault this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="backup_vault_list" type="list(object)">

---
title: "aws_backup_frameworks"
description: "`data_aws_backup_frameworks` looks up a real, already-existing `aws_backup_framework`."
---

It is a set of built-in, customizable AWS Backup Audit Manager controls, aligned to an organization's own compliance requirements, that automatically track backup activity and flag resources not yet compliant with those controls.

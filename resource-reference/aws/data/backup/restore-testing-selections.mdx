---
title: "aws_backup_restore_testing_selections"
description: "`data_aws_backup_restore_testing_selections` looks up a real, already-existing `aws_backup_restore_testing_selection`."
---

It picks which real recovery points and target resources an `aws_backup_restore_testing_plan` actually restores during a test run, the selection a restore testing plan has no scope without.

## Example

    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	backup "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/backup"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_backup_restore_testing_selections"})

    		ubx.Data(backup.RestoreTestingSelections, "example", backup.RestoreTestingSelectionsConfig{
    			RestoreTestingPlanName: "example-restore-testing-plan-name",
    			MaxResults:             1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="restore_testing_plan_name" type="string" required>
  The real name of the restore testing plan this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

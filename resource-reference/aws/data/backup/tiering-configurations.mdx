---
title: "aws_backup_tiering_configurations"
description: "`data_aws_backup_tiering_configurations` looks up a real, already-existing `aws_backup_tiering_configuration`."
---

It automatically moves backup data in an `aws_backup_vault` to a lower-cost storage tier once it reaches a defined age (60 days minimum), while keeping identical restore capability, real, ongoing storage savings without the caller managing the transition by hand.

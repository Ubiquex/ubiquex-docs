---
title: "aws_frauddetector_outcomes"
description: "`data_aws_frauddetector_outcomes` looks up a real, already-existing `aws_fraud_detector_outcome`."
---

It defined a real possible result, approve, review, block, that an `aws_fraud_detector_detector`'s own business rules could return for an evaluated event. Closed to new customers along with the rest of Fraud Detector since November 7, 2025.

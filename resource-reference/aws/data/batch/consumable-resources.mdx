---
title: "aws_batch_consumable_resources"
description: "`data_aws_batch_consumable_resources` looks up a real, already-existing `aws_batch_consumable_resource`."
---

It defines a real constraint beyond vCPU, GPU, or memory, a third-party license token pool, a database connection limit, an API rate cap, that AWS Batch's resource-aware scheduling checks before starting a job, so a job doesn't launch, consume compute time, and then fail discovering the real resource it needed was unavailable.

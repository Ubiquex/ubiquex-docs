---
title: "aws_batch_jobs"
description: "`data_aws_batch_jobs` looks up a real, already-existing `aws_batch_job_definition`."
---

It is the real template AWS Batch launches a job from, the container image, vCPU and memory requirements, command, and retry strategy, submitted against an `aws_batch_job_queue` each time a job actually runs.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

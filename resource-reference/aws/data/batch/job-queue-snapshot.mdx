---
title: "aws_batch_job_queue_snapshot"
description: "`data_aws_batch_job_queue_snapshot` looks up a real, already-existing `aws_batch_job_queue`."
---

It holds submitted jobs until an `aws_batch_compute_environment` has capacity to run them, ordered either FIFO by default or by an attached `aws_batch_scheduling_policy`'s fair-share rules across multiple users or workloads.

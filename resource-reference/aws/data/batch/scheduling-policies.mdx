---
title: "aws_batch_scheduling_policies"
description: "`data_aws_batch_scheduling_policies` looks up a real, already-existing `aws_batch_scheduling_policy`."
---

It defines fair-share scheduling for an `aws_batch_job_queue`, assigning share identifiers, decay time, and weight factors so one user or workload can't monopolize a queue's compute, real logic a queue defaults to plain FIFO without.

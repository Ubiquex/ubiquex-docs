---
title: "aws_batch_service_job"
description: "`aws_batch_service_job` looks up one real AWS Batch service job, running a task against another AWS service (such as SageMaker) rather than a container."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	batch "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/batch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_batch_service_job"})

    		ubx.Data(batch.ServiceJob, "example", batch.ServiceJobConfig{
    			JobId: "example",
    		})
    	}))
    }
    ```
  </Tab>

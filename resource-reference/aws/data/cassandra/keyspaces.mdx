---
title: "aws_cassandra_keyspaces"
description: "`data_aws_cassandra_keyspaces` looks up a real, already-existing `aws_cassandra_keyspace`."
---

It creates the top-level namespace in Amazon Keyspaces (for Apache Cassandra), the serverless, Cassandra-compatible database, that every `aws_cassandra_table` and user-defined `aws_cassandra_type` in it belongs to.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cassandra_keyspaces"})

    			MaxResults: 1,
    		})
    	}))
    }

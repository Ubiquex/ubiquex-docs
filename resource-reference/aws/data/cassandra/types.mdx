---
title: "aws_cassandra_types"
description: "`data_aws_cassandra_types` looks up a real, already-existing `aws_cassandra_type`."
---

It is a user-defined type, a named grouping of fields and data types usable as a single column, created inside an `aws_cassandra_keyspace` with CQL's `CREATE TYPE` and available to every `aws_cassandra_table` in that same keyspace.

---
title: "aws_cassandra_tables"
description: "`data_aws_cassandra_tables` looks up a real, already-existing `aws_cassandra_table`."
---

It creates a real table inside an `aws_cassandra_keyspace`, using the same CQL data model and application code an existing Cassandra workload already uses, with Amazon Keyspaces scaling its throughput and storage automatically rather than the caller provisioning nodes.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cassandra "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cassandra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cassandra_tables"})

    		ubx.Data(cassandra.Tables, "example", cassandra.TablesConfig{
    			KeyspaceName: "example-keyspace-name",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="keyspace_name" type="string" required>
  The real name of the Amazon Keyspaces keyspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

</ResponseField>

<ResponseField name="tables" type="list(object)">
  The real tables included in this result. **(AI-inferred)** Returned by the lookup.

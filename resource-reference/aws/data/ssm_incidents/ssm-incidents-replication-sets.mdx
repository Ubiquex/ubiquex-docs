---
title: "aws_ssm_incidents_replication_sets"
description: "`data_aws_ssm_incidents_replication_sets` looks up a real, already-existing `aws_ssmincidents_replication_set`."
---

It creates the real, required Region-replication configuration that must exist before Incident Manager can be used in an account, replicating incident data across the chosen Regions for resilience during a regional outage.

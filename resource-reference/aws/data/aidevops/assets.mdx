## Lookup arguments

<ResponseField name="agent_space_id" type="string" required>
  The real, unique identifier of the agent space this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="asset_type" type="string">
  &lt;p&gt;The type of asset (e.g. skill, artifact)&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="updated_after" type="string">
  The earliest real last-updated timestamp to include in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="updated_before" type="string">
  The latest real last-updated timestamp to include in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

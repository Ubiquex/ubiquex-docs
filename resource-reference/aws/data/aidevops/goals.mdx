## Lookup arguments

<ResponseField name="agent_space_id" type="string" required>
  The real, unique identifier of the agent space this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="goal_type" type="string">
  &lt;p&gt;Type of goal based on its origin&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  &lt;p&gt;Possible states of a goal throughout its lifecycle&lt;/p&gt; Optional lookup argument.
</ResponseField>

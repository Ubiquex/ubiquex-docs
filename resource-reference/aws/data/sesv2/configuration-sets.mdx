---
title: "aws_sesv2_configuration_sets"
description: "`data_aws_sesv2_configuration_sets` looks up a real, already-existing `aws_ses_configuration_set`."
---

It defines a real set of rules, IP pool, reputation options, sending options, applied to emails sent through SES that reference it, SES's original configuration mechanism distinct from Mail Manager's own `aws_ses_mail_manager_traffic_policy`.

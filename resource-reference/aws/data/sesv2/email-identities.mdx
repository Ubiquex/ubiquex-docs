---
title: "aws_sesv2_email_identities"
description: "`data_aws_sesv2_email_identities` looks up a real, already-existing `aws_ses_email_identity`."
---

It verifies a real sending domain or individual email address with SES, the identity-verification step required before SES will send mail from it, and the resource DKIM and custom MAIL FROM settings are configured against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sesv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/sesv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sesv2_email_identities"})

    		ubx.Data(sesv2.EmailIdentities, "example", sesv2.EmailIdentitiesConfig{
    			PageSize: 1,
    		})
    	}))
    }
    ```

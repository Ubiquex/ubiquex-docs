## Lookup arguments

<ResponseField name="reputation_entity_reference" type="string" required>
  &lt;p&gt;The unique identifier for a reputation entity. For resource-type entities, this is the Amazon Resource Name (ARN) of the resource.&lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="reputation_entity_type" type="string" required>
  &lt;p&gt;The type of reputation entity. Currently, only &lt;code&gt;RESOURCE&lt;/code&gt; type entities are supported, which represent resources in your Amazon SES account that have reputation tracking capabilities.&lt;/p&gt; Required lookup argument.
</ResponseField>

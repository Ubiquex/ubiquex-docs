## Lookup arguments

<ResponseField name="import_destination_type" type="string">
  &lt;p&gt;The destination of the import job, which can be used to list import jobs that have a certain &lt;code&gt;ImportDestinationType&lt;/code&gt;.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="import_jobs" type="list(object)">

</ResponseField>

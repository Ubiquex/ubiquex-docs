---
title: "aws_sesv2_contacts"
description: "`data_aws_sesv2_contacts` looks up a real, already-existing `aws_ses_contact_list`."
---

It creates a real, managed list of email contacts and their topic subscription preferences, that SES's own bulk and marketing-email sending features send to and respect unsubscribes against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sesv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/sesv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sesv2_contacts"})

    		ubx.Data(sesv2.Contacts, "example", sesv2.ContactsConfig{
    			ContactListName: "example-contact-list-name",
    			Filter:          map[string]any{"filtered_status": "example"},
    			PageSize:        1,
    		})
    	}))
    }
    ```
  </Tab>

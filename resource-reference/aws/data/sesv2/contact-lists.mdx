---
title: "aws_sesv2_contact_lists"
description: "`data_aws_sesv2_contact_lists` looks up a real, already-existing `aws_ses_contact_list`."
---

It creates a real, managed list of email contacts and their topic subscription preferences, that SES's own bulk and marketing-email sending features send to and respect unsubscribes against.

## Example

    package main

    import (
    	sesv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/sesv2"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sesv2_contact_lists"})

    		})
    	}))
    }

---
title: "aws_sesv2_dedicated_ip"
description: "`data_aws_sesv2_dedicated_ip` looks up a real, already-existing `aws_ses_dedicated_ip_pool`."
---

It groups real dedicated sending IP addresses under an `aws_ses_configuration_set`, so a chosen subset of an account's dedicated IPs is used for a particular category of email, keeping sending reputations isolated between categories.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sesv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/sesv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sesv2_dedicated_ip"})

    		ubx.Data(sesv2.DedicatedIp, "example", sesv2.DedicatedIpConfig{
    			Ip: "example",
    		})
    	}))
    }
    ```
  </Tab>

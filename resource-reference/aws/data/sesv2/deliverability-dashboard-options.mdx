## Result properties

<ResponseField name="account_status" type="string">
  &lt;p&gt;The current status of your Deliverability dashboard subscription. If this value is &lt;code&gt;PENDING_EXPIRATION&lt;/code&gt;, your subscription is scheduled to expire at the end of the current calendar month.&lt;/p&gt; Returned by the lookup.
</ResponseField>

<ResponseField name="active_subscribed_domains" type="list(object)">
  &lt;p&gt;An object that contains information about the Deliverability dashboard subscription for a verified domain that you use to send email and currently has an active Deliverability dashboard subscription. If a Deliverability dashboard subscription is active for a domain, you gain access to reputation, inbox placement, and other metrics for the domain.&lt;/p&gt; Returned by the lookup.
</ResponseField>

<ResponseField name="dashboard_enabled" type="bool">
  Whether the dashboard is currently enabled. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_xray_resource_policies"
description: "`data_aws_xray_resource_policies` looks up a real, already-existing `aws_xray_resource_policy`."
---

It attaches a real resource-based access policy to X-Ray, controlling which principals, including from other accounts, can send trace data into it.

## Example

    	ubx.Main(ubx.Stack("example", func() {

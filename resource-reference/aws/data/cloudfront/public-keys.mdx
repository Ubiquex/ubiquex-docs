## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudfront "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudfront"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudfront_public_keys"})

    		ubx.Data(cloudfront.PublicKeys, "example", cloudfront.PublicKeysConfig{
    			Marker:   "example",
    			MaxItems: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_items" type="number">
  The maximum number of items to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

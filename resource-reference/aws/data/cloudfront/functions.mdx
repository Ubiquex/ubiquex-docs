## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudfront "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/cloudfront"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudfront_functions"})

    		ubx.Data(cloudfront.Functions, "example", cloudfront.FunctionsConfig{
    			Marker:   "example",
    			MaxItems: 1,
    			Stage:    "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Functions } from "@ubx/sdk-aws/aws/data/cloudfront/functions";

    export default stack("example", () => {
      intent({ summary: "look up aws_cloudfront_functions" });

      data(Functions, "example", {
        marker: "example",
        maxItems: 1,
        stage: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.cloudfront import Functions, FunctionsConfig

    def describe():
        ubx.intent("look up aws_cloudfront_functions")

        ubx.data(Functions, "example", FunctionsConfig(
            marker="example",
            max_items=1,
            stage="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_items" type="number">
  The maximum number of items to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stage" type="string">
  The real deployment stage this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="alias" type="string" required>
  The real, human-readable alias for this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="distribution_id" type="string" required>
  The real, unique identifier of the distribution this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_items" type="number">
  The maximum number of items to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="conflicting_aliases_list" type="object">
  &lt;p&gt;A list of aliases (also called CNAMEs) and the CloudFront standard distributions and Amazon Web Services accounts that they are associated with. In the list, the standard distribution and account IDs are partially hidden, which allows you to identify the standard distributions and accounts that you own, but helps to protect the information of ones that you don't own.&lt;/p&gt; Returned by the lookup.

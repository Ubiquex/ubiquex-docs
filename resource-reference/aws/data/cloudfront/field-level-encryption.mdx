`aws_cloudfront_field_level_encryption` looks up a real CloudFront field-level encryption configuration, encrypting specific sensitive request fields end-to-end.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudfront "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/cloudfront"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudfront_field_level_encryption"})

    		ubx.Data(cloudfront.FieldLevelEncryption, "example", cloudfront.FieldLevelEncryptionConfig{
    			Id: "example",
    		})
    	}))
    }
    ```

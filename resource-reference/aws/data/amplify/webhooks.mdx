---
title: "aws_amplify_webhooks"
description: "`data_aws_amplify_webhooks` looks up a real, already-existing `aws_amplify_webhook`."
---

It creates a real, callable URL that triggers a new build of an `aws_amplify_branch` when invoked, letting an external system kick off a deployment without needing a full source-provider Git integration.

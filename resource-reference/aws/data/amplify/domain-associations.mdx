---
title: "aws_amplify_domain_associations"
description: "`data_aws_amplify_domain_associations` looks up a real, already-existing `aws_amplify_domain`."
---

It attaches a custom domain to an `aws_amplify_app` and maps its subdomains to specific branches, real DNS and SSL provisioning included, rather than leaving the app reachable only at its default `amplifyapp.com` URL.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	amplify "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/amplify"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_amplify_domain_associations"})

    		ubx.Data(amplify.DomainAssociations, "example", amplify.DomainAssociationsConfig{
    			AppId:      "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The real, unique identifier of the app this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="domain_associations" type="list(object)">

</ResponseField>

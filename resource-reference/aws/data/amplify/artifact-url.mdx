## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	amplify "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/amplify"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_amplify_artifact_url"})

    		ubx.Data(amplify.ArtifactUrl, "example", amplify.ArtifactUrlConfig{
    			ArtifactId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ArtifactUrl } from "@ubx/sdk-aws/aws/data/amplify/artifact_url";

    export default stack("example", () => {
      intent({ summary: "look up aws_amplify_artifact_url" });

      data(ArtifactUrl, "example", {
        artifactId: "example",
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.amplify import ArtifactUrl, ArtifactUrlConfig

    def describe():
        ubx.intent("look up aws_amplify_artifact_url")

        ubx.data(ArtifactUrl, "example", ArtifactUrlConfig(
            artifact_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="artifact_id" type="string" required>
  The real, unique identifier of the artifact this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="artifact_url" type="string">
  The real, resolvable URL of the artifact this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	amplify "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/amplify"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_amplify_artifacts"})

    		ubx.Data(amplify.Artifacts, "example", amplify.ArtifactsConfig{
    			AppId:      "example",
    			BranchName: "example-branch-name",
    			JobId:      "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The real, unique identifier of the app this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="branch_name" type="string" required>
  The real name of the Amplify branch this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_id" type="string" required>
  The real, unique identifier of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="artifacts" type="list(object)">
  The real artifacts included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_logs_query_results"
description: "`data_aws_logs_query_results` looks up a real, already-existing `aws_logs_query_definition`."
---

It saves a real, named CloudWatch Logs Insights query for reuse from the console or API, rather than re-typing it for every ad hoc investigation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_query_results"})

    		ubx.Data(logs.QueryResults, "example", logs.QueryResultsConfig{
    			QueryId:  "example",
    			MaxItems: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.logs import QueryResults, QueryResultsConfig

    def describe():
        ubx.intent("look up aws_logs_query_results")

        ubx.data(QueryResults, "example", QueryResultsConfig(
            query_id="example",
            max_items=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

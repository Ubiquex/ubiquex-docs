---
title: "aws_logs_account_policies"
description: "`data_aws_logs_account_policies` looks up a real, already-existing `aws_logs_account_policy`."
---

It defines a real, account-wide CloudWatch Logs policy, a subscription filter or data protection policy applied by default, rather than configuring the same policy on every individual `aws_logs_log_group`.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_account_policies"})

    		ubx.Data(logs.AccountPolicies, "example", logs.AccountPoliciesConfig{
    			PolicyType:         "example",
    			AccountIdentifiers: []string{"example"},
    			PolicyName:         "example-policy-name",
    		})
    	}))
    }

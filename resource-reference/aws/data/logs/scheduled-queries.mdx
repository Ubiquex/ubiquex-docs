---
title: "aws_logs_scheduled_queries"
description: "`data_aws_logs_scheduled_queries` looks up a real, already-existing `aws_logs_scheduled_query`."
---

It runs a real `aws_logs_query_definition`-style Logs Insights query on a recurring schedule and delivers its results automatically to a configured destination, such as an S3 bucket or an EventBridge event bus.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_scheduled_queries"})

    		ubx.Data(logs.ScheduledQueries, "example", logs.ScheduledQueriesConfig{
    			MaxResults:   1,
    			ScheduleType: "example",
    			State:        "example",
    		})
    	}))
    }

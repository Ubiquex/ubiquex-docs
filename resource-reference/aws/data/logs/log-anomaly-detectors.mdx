---
title: "aws_logs_log_anomaly_detectors"
description: "`data_aws_logs_log_anomaly_detectors` looks up a real, already-existing `aws_logs_log_anomaly_detector`."
---

It creates a real machine-learning detector that regularly scans one or more log groups, learns the recurring text patterns in their log fields, and flags anomalies that break from those learned patterns.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_log_anomaly_detectors"})

    		ubx.Data(logs.LogAnomalyDetectors, "example", logs.LogAnomalyDetectorsConfig{
    			FilterLogGroupArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:             1,
    		})
    	}))
    }
    ```

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_log_fields"})

    		ubx.Data(logs.LogFields, "example", logs.LogFieldsConfig{
    			DataSourceName: "example-data-source-name",
    			DataSourceType: "example",
    		})
    	}))
    }
    ```

            data_source_name="example-data-source-name",
            data_source_type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="data_source_name" type="string" required>
  The real name of the data source this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="data_source_type" type="string" required>
  The real, discriminating type of the data source this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="log_fields" type="list(object)">

</ResponseField>

---
title: "aws_logs_query_definitions"
description: "`data_aws_logs_query_definitions` looks up a real, already-existing `aws_logs_query_definition`."
---

It saves a real, named CloudWatch Logs Insights query for reuse from the console or API, rather than re-typing it for every ad hoc investigation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_query_definitions"})

    		ubx.Data(logs.QueryDefinitions, "example", logs.QueryDefinitionsConfig{
    			MaxResults:                1,
    			QueryDefinitionNamePrefix: "example",
    			QueryLanguage:             "example",
    		})
    	}))
    }
    ```
  </Tab>

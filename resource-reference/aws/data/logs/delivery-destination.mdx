`aws_logs_delivery_destination` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

  &lt;p&gt;This structure contains information about one &lt;i&gt;delivery destination&lt;/i&gt; in your account. A delivery destination is an Amazon Web Services resource that represents an Amazon Web Services service that logs can be sent to. CloudWatch Logs, Amazon S3, Firehose, and X-Ray are supported as delivery destinations.&lt;/p&gt; &lt;p&gt;To configure logs delivery between a supported Amazon Web Services service and a destination, you must do the following:&lt;/p&gt; &lt;ul&gt; &lt;li&gt; &lt;p&gt;Create a delivery source, which is a logical object that represents the resource that is actually sending the logs. For more information, see &lt;a href="https://docs.aws.amazon.com/AmazonCloudWatchLogs/latest/APIReference/API_PutDeliverySource.html"&gt;PutDeliverySource&lt;/a&gt;.&lt;/p&gt; &lt;/li&gt; &lt;li&gt; &lt;p&gt;Create a &lt;i&gt;delivery destination&lt;/i&gt;, which is a logical object that represents the actual delivery destination. &lt;/p&gt; &lt;/li&gt; &lt;li&gt; &lt;p&gt;If you are delivering logs cross-account, you must use &lt;a href="https://docs.aws.amazon.com/AmazonCloudWatchLogs/latest/APIReference/API_PutDeliveryDestinationPolicy.html"&gt;PutDeliveryDestinationPolicy&lt;/a&gt; in the destination account to assign an IAM policy to the destination. This policy allows delivery to that destination. &lt;/p&gt; &lt;/li&gt; &lt;li&gt; &lt;p&gt;Create a &lt;i&gt;delivery&lt;/i&gt; by pairing exactly one delivery source and one delivery destination. For more information, see &lt;a href="https://docs.aws.amazon.com/AmazonCloudWatchLogs/latest/APIReference/API_CreateDelivery.html"&gt;CreateDelivery&lt;/a&gt;.&lt;/p&gt; &lt;/li&gt; &lt;/ul&gt; &lt;p&gt;You can configure a single delivery source to send logs to multiple destinations by creating multiple deliveries. You can also create multiple deliveries to configure multiple delivery sources to send logs to the same delivery destination.&lt;/p&gt; Returned by the lookup.

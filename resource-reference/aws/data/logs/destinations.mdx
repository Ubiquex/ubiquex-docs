---
title: "aws_logs_destinations"
description: "`data_aws_logs_destinations` looks up a real, already-existing `aws_logs_destination`."
---

It creates a real cross-account subscription destination, most commonly a Kinesis stream, that another account's log group subscription filter can stream matching log events to. This is the older CloudWatch Logs subscription mechanism, distinct from the newer delivery-source/delivery-destination framework used by `aws_logs_delivery`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_destinations"})

    		ubx.Data(logs.Destinations, "example", logs.DestinationsConfig{
    			DestinationNamePrefix: "example",
    			Limit:                 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="destination_name_prefix" type="string">
  The real S3 key prefix used for the destination name. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="destinations" type="list(object)">
  The real destinations included in this result. **(AI-inferred)** Returned by the lookup.

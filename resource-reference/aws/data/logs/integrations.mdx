---
title: "aws_logs_integrations"
description: "`data_aws_logs_integrations` looks up a real, already-existing `aws_logs_integration`."
---

It creates a real, zero-ETL integration between CloudWatch Logs and Amazon OpenSearch Service, currently the only supported integration type, enabling curated vended-log dashboards powered by OpenSearch analytics without a separate ingestion pipeline. Only one integration is currently supported per account, and an existing integration cannot be modified in place.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_integrations"})

    		ubx.Data(logs.Integrations, "example", logs.IntegrationsConfig{
    			IntegrationNamePrefix: "example",
    			IntegrationStatus:     "example",
    			IntegrationType:       "example",
    		})
    	}))
    }
    ```

    from ubx.aws.data.logs import Integrations, IntegrationsConfig

    def describe():
        ubx.intent("look up aws_logs_integrations")

        ubx.data(Integrations, "example", IntegrationsConfig(
            integration_name_prefix="example",
            integration_status="example",
            integration_type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="integration_name_prefix" type="string">
  The real S3 key prefix used for the integration name. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="integration_status" type="string">
  The real, current status of the integration this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="integration_type" type="string">
  The real, discriminating type of the integration this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

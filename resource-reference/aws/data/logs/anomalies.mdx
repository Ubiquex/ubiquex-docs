## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_anomalies"})

    		ubx.Data(logs.Anomalies, "example", logs.AnomaliesConfig{
    			AnomalyDetectorArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:              1,
    			SuppressionState:   "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="anomaly_detector_arn" type="string">
  The real Amazon Resource Name (ARN) of the anomaly detector this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="suppression_state" type="string">
  The real, current state of the suppression this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="anomalies" type="list(object)">

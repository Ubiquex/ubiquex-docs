---
title: "aws_logs_log_groups_for_query"
description: "`data_aws_logs_log_groups_for_query` looks up a real, already-existing `aws_logs_log_group`."
---

It creates a real CloudWatch Logs log group, the container that log streams are organized under and that retention, encryption, and access settings are configured against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_log_groups_for_query"})

    		ubx.Data(logs.LogGroupsForQuery, "example", logs.LogGroupsForQueryConfig{
    			QueryId:    "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

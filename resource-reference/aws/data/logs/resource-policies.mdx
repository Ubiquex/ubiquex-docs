---
title: "aws_logs_resource_policies"
description: "`data_aws_logs_resource_policies` looks up a real, already-existing `aws_logs_resource_policy`."
---

It attaches a real resource-based access policy scoped to specific `aws_logs_log_group`s, controlling which other AWS services or accounts can write log events into them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_resource_policies"})

    		ubx.Data(logs.ResourcePolicies, "example", logs.ResourcePoliciesConfig{
    			Limit:       1,
    			PolicyScope: "example",
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

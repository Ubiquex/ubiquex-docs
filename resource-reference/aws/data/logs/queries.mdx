---
title: "aws_logs_queries"
description: "`data_aws_logs_queries` looks up a real, already-existing `aws_logs_query_definition`."
---

It saves a real, named CloudWatch Logs Insights query for reuse from the console or API, rather than re-typing it for every ad hoc investigation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_queries"})

    		ubx.Data(logs.Queries, "example", logs.QueriesConfig{
    			LogGroupName:  "example-log-group-name",
    			MaxResults:    1,
    			QueryLanguage: "example",
    			Status:        "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.logs import Queries, QueriesConfig

    def describe():
        ubx.intent("look up aws_logs_queries")

        ubx.data(Queries, "example", QueriesConfig(
            log_group_name="example-log-group-name",
            max_results=1,
            query_language="example",
            status="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

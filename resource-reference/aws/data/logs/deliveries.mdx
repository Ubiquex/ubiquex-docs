---
title: "aws_logs_deliveries"
description: "`data_aws_logs_deliveries` looks up a real, already-existing `aws_logs_delivery`."
---

It creates a real, active connection between an `aws_logs_delivery_source` and an `aws_logs_delivery_destination`, the resource that actually turns a configured source and destination into a flowing pipeline of vended logs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_deliveries"})

    		ubx.Data(logs.Deliveries, "example", logs.DeliveriesConfig{
    			Limit: 1,
    		})
    	}))
    }
    ```

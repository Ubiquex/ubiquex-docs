---
title: "aws_logs_storage_tier_policy"
description: "`data_aws_logs_storage_tier_policy` looks up a real, already-existing `aws_logs_storage_tier_policy`."
---

It configures whether an `aws_logs_log_group`'s older log events automatically move to CloudWatch Logs' lower-cost Infrequent Access storage tier after a chosen age, trading slightly slower query performance for reduced storage cost.

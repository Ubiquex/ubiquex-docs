---
title: "aws_logs_subscription_filters"
description: "`data_aws_logs_subscription_filters` looks up a real, already-existing `aws_logs_subscription_filter`."
---

It streams real log events matching a pattern from an `aws_logs_log_group` to a destination, a Kinesis stream, Firehose, or Lambda function, in near real time as they're ingested.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_subscription_filters"})

    		ubx.Data(logs.SubscriptionFilters, "example", logs.SubscriptionFiltersConfig{
    			LogGroupName:     "example-log-group-name",
    			FilterNamePrefix: "example",
    			Limit:            1,
    		})
    	}))
    }
    ```
  </Tab>

        ubx.data(SubscriptionFilters, "example", SubscriptionFiltersConfig(

            filter_name_prefix="example",

## Lookup arguments

<ResponseField name="filter_name_prefix" type="string">
  The real S3 key prefix used for the filter name. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="log_group_name" type="string" required>
  The real name of the CloudWatch Logs log group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  &lt;p&gt;The token for the next set of items to return. The token expires after 24 hours.&lt;/p&gt; Returned by the lookup.
</ResponseField>

<ResponseField name="subscription_filters" type="list(object)">
  The real CloudWatch Logs subscription filters included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

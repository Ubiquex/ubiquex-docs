## Example

    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/logs"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_import_task_batches"})

    		ubx.Data(logs.ImportTaskBatches, "example", logs.ImportTaskBatchesConfig{
    			ImportId:          "example",
    			BatchImportStatus: []string{"example"},
    			Limit:             1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="batch_import_status" type="list(string)">
  The real, current status of the batch import this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="import_id" type="string" required>
  The real, unique identifier of the import this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="import_batches" type="list(object)">
  The real import batches included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="import_source_arn" type="string">
  The real Amazon Resource Name (ARN) of the import source this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

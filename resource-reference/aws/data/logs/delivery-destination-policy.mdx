---
title: "aws_logs_delivery_destination_policy"
description: "`data_aws_logs_delivery_destination_policy` looks up a real, already-existing `aws_logs_delivery_destination`."
---

It represents a real AWS service, CloudWatch Logs, S3, Firehose, or X-Ray, configured to receive vended logs through the newer CloudWatch Logs delivery framework, the target end of an `aws_logs_delivery`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_delivery_destination_policy"})

    		ubx.Data(logs.DeliveryDestinationPolicy, "example", logs.DeliveryDestinationPolicyConfig{
    			DeliveryDestinationName: "example-delivery-destination-name",
    		})
    	}))
    }
    ```
  </Tab>

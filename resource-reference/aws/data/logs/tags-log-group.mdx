---
title: "aws_logs_tags_log_group"
description: "`data_aws_logs_tags_log_group` looks up a real, already-existing `aws_logs_log_group`."
---

It creates a real CloudWatch Logs log group, the container that log streams are organized under and that retention, encryption, and access settings are configured against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	logs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/logs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_tags_log_group"})

    		ubx.Data(logs.TagsLogGroup, "example", logs.TagsLogGroupConfig{
    			LogGroupName: "example-log-group-name",
    		})
    	}))
    }
    ```

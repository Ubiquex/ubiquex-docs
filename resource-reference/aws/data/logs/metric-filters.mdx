---
title: "aws_logs_metric_filters"
description: "`data_aws_logs_metric_filters` looks up a real, already-existing `aws_logs_metric_filter`."
---

It defines a real pattern that CloudWatch Logs evaluates against incoming events in an `aws_logs_log_group`, publishing a CloudWatch metric data point each time a log event matches, the mechanism behind turning free-text logs into alarmable numeric metrics.

    		})

## Lookup arguments

<ResponseField name="filter_name_prefix" type="string">
  The real S3 key prefix used for the filter name. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="log_group_name" type="string">
  The real name of the CloudWatch Logs log group this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="metric_name" type="string">
  &lt;p&gt;The name of the CloudWatch metric to which the monitored log information should be published. For example, you might publish to a metric named ErrorCount.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="metric_namespace" type="string">
  The real namespace this metric belongs to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

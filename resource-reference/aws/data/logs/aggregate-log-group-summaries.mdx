---
title: "aws_logs_aggregate_log_group_summaries"
description: "`data_aws_logs_aggregate_log_group_summaries` looks up a real, already-existing `aws_logs_log_group`."
---

It creates a real CloudWatch Logs log group, the container that log streams are organized under and that retention, encryption, and access settings are configured against.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_logs_aggregate_log_group_summaries"})

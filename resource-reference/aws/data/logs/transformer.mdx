---
title: "aws_logs_transformer"
description: "`data_aws_logs_transformer` looks up a real, already-existing `aws_logs_transformer`."
---

It attaches a real ordered pipeline of processors to an `aws_logs_log_group`, applying transformations to each log event at ingestion time so that later Logs Insights queries and metric filters can operate on the transformed, structured version rather than the raw text.

    import ubx_sdk as ubx
    from ubx.aws.logs import Transformer, TransformerConfig
    from ubx.aws.logs.transformer import Transformer_TransformerConfig, Transformer_TransformerConfig_AddKeys, Transformer_TransformerConfig_AddKeys_Entries

    def describe():
        ubx.intent("example own transformer")

        ubx.resource(Transformer, "example", TransformerConfig(
            log_group_identifier="example",
            transformer_config=[Transformer_TransformerConfig(add_keys=Transformer_TransformerConfig_AddKeys(entries=[Transformer_TransformerConfig_AddKeys_Entries(key="example")]))],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

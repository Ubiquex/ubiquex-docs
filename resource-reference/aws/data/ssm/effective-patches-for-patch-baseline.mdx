---
title: "aws_ssm_effective_patches_for_patch_baseline"
description: "`data_aws_ssm_effective_patches_for_patch_baseline` looks up a real, already-existing `aws_ssm_patch_baseline`."
---

It defines a real set of rules, auto-approval delays, severity filters, an explicit approved or rejected patch list, that determines which OS patches Systems Manager Patch Manager treats as approved for a given set of instances.

---
title: "aws_ssm_maintenance_window_task"
description: "`data_aws_ssm_maintenance_window_task` looks up a real, already-existing `aws_ssm_maintenance_window_task`."
---

It schedules a real Systems Manager task, running an `aws_ssm_document`, a Lambda function, or a Step Functions state machine, against an `aws_ssm_maintenance_window`'s registered targets whenever its window opens.

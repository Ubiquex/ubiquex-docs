title: "aws_ssm_associations"
description: "`data_aws_ssm_associations` looks up a real, already-existing `aws_ssm_association`."

It attaches a real `aws_ssm_document` to a set of target instances or resources on a recurring schedule, the resource that actually turns a document's defined actions into ongoing, applied state rather than a one-time run.

---
title: "aws_ssm_resource_policies"
description: "`data_aws_ssm_resource_policies` looks up a real, already-existing `aws_ssm_resource_policy`."
---

It attaches a real resource-based access policy to an `aws_ssm_parameter`, controlling which principals, including from other accounts, can read or write it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ssm_resource_policies"})

    		ubx.Data(ssm.ResourcePolicies, "example", ssm.ResourcePoliciesConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults:  1,
    		})
    	}))
    }
    ```

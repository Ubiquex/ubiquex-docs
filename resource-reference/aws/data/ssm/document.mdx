---
title: "aws_ssm_document"
description: "`data_aws_ssm_document` looks up a real, already-existing `aws_ssm_document`."
---

It defines a real, reusable automation, command, or policy document, in JSON or YAML, that Systems Manager runs against target instances, either directly or through an `aws_ssm_association`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ssm_document"})

    		ubx.Data(ssm.Document, "example", ssm.DocumentConfig{
    			Name:            "example",
    			DocumentVersion: "example",
    			VersionName:     "example-version-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Document } from "@ubx/sdk-aws/aws/data/ssm/document";

    export default stack("example", () => {
      intent({ summary: "look up aws_ssm_document" });

      data(Document, "example", {
        name: "example",
        documentVersion: "example",
        versionName: "example-version-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.ssm import Document, DocumentConfig

    def describe():
        ubx.intent("look up aws_ssm_document")

        ubx.data(Document, "example", DocumentConfig(
            name="example",
            document_version="example",
            version_name="example-version-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="document_version" type="string">
  The real version of the document. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="name" type="string" required>
  The real, given name of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="version_name" type="string">
  The real name of the version this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "aws_ssm_parameter"
description: "`data_aws_ssm_parameter` looks up a real, already-existing `aws_ssm_parameter`."
---

It stores a real string, string list, or secure string value in Parameter Store, that applications and other AWS resources reference by name at runtime instead of hardcoding configuration or (for SecureString) secrets directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ssm_parameter"})

    		ubx.Data(ssm.Parameter, "example", ssm.ParameterConfig{
    			Name:           "example",
    			WithDecryption: true,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Parameter } from "@ubx/sdk-aws/aws/data/ssm/parameter";

    export default stack("example", () => {
      intent({ summary: "look up aws_ssm_parameter" });

      data(Parameter, "example", {
        name: "example",
        withDecryption: true,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.ssm import Parameter, ParameterConfig

    def describe():
        ubx.intent("look up aws_ssm_parameter")

        ubx.data(Parameter, "example", ParameterConfig(
            name="example",
            with_decryption=True,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

---
title: "aws_ssm_documents"
description: "`data_aws_ssm_documents` looks up a real, already-existing `aws_ssm_document`."
---

It defines a real, reusable automation, command, or policy document, in JSON or YAML, that Systems Manager runs against target instances, either directly or through an `aws_ssm_association`.

## Example

<Tabs>

    ```go
    package main

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/ssm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ssm_documents"})

    		ubx.Data(ssm.Documents, "example", ssm.DocumentsConfig{
    			DocumentFilterList: []map[string]any{{"key": "example"}},
    			Filters:            []map[string]any{{"key": "example"}},
    			MaxResults:         1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="document_filter_list" type="list(object)">
  The real document filters included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filters" type="list(object)">
  Real filter criteria restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="document_identifiers" type="list(object)">
  The real, unique identifiers of the documents this request is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

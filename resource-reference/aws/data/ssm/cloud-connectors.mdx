---
title: "aws_ssm_cloud_connectors"
description: "`data_aws_ssm_cloud_connectors` looks up a real, already-existing `aws_ssm_cloud_connector`."
---

It connects a real non-AWS cloud account, an Azure subscription, for example, to AWS Systems Manager, letting Systems Manager extend its own management and visibility to resources outside AWS. This resource has only thin official documentation, verified live this session against AWS's own field-level schema rather than assumed from general knowledge, since it did not turn up a dedicated conceptual guide page the way Systems Manager's older resources do.

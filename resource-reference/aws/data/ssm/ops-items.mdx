`aws_ssm_ops_items` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    import (
    	ssm "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/ssm"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ssm_ops_items"})

    		ubx.Data(ssm.OpsItems, "example", ssm.OpsItemsConfig{
    			MaxResults:     1,
    			OpsItemFilters: []map[string]any{{"key": "example"}},
    		})
    	}))
    }

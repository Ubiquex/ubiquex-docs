---
title: "aws_ssm_maintenance_windows"
description: "`data_aws_ssm_maintenance_windows` looks up a real, already-existing `aws_ssm_maintenance_window`."
---

It defines a real, recurring time window during which `aws_ssm_maintenance_window_task`s are allowed to run against `aws_ssm_maintenance_window_target`s, so disruptive operations like patching only happen when they're actually scheduled to.

`aws_network_firewall_tlsinspection_configurations` looks up a real Network Firewall TLS inspection configuration, decrypting traffic for inspection before re-encrypting it.

## Example

<Tabs>
  <Tab title="Go">

    ```go
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_network_firewall_tlsinspection_configurations"})

    		ubx.Data(network_firewall.NetworkFirewallTlsinspectionConfigurations, "example", network_firewall.NetworkFirewallTlsinspectionConfigurationsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

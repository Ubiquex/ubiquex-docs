---
title: "aws_resiliencehubv2_services"
description: "`data_aws_resiliencehubv2_services` looks up a real, already-existing `aws_resilience_hub_v2_service`."
---

It registers a real deployable unit, its resources discovered from a CloudFormation stack, Terraform state, or an EKS cluster, under the next-generation AWS Resilience Hub model (launched May 2026), the counterpart to the original model's `aws_resilience_hub_app`, assessed against an `aws_resilience_hub_v2_policy`.

    func main() {

    	}))
    }

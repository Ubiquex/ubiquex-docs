---
title: "aws_auditmanager_assessment_frameworks"
description: "`data_aws_auditmanager_assessment_frameworks` looks up a real, already-existing `aws_audit_manager_assessment_framework`."
---

It is a structured collection of controls, prebuilt for standards like PCI DSS, HIPAA, or SOC 2, or built custom, that an `aws_audit_manager_assessment` is created from to define exactly what evidence gets collected and against which requirements.

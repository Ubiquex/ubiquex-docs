## Lookup arguments

<ResponseField name="assessment_id" type="string" required>
  The real, unique identifier of the assessment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="control_set_id" type="string" required>
  The real, unique identifier of the control set this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="evidence_folder_id" type="string" required>
  The real, unique identifier of the evidence folder this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "aws_auditmanager_assessments"
description: "`data_aws_auditmanager_assessments` looks up a real, already-existing `aws_audit_manager_assessment`."
---

It creates from an `aws_audit_manager_assessment_framework` the actual, running evidence-collection process, scoped to specific AWS accounts, that continuously gathers audit-ready evidence until the assessment is marked inactive. AWS Audit Manager is no longer open to new customers; existing customers can continue using it as normal.

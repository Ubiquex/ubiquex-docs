`aws_redshift_serverless_credentials` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	redshift_serverless "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/redshift_serverless"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_serverless_credentials"})

    		ubx.Data(redshift_serverless.RedshiftServerlessCredentials, "example", redshift_serverless.RedshiftServerlessCredentialsConfig{
    			CustomDomainName: "example-custom-domain-name",
    			DbName:           "example-db-name",
    			DurationSeconds:  7200,
    			WorkgroupName:    "example-workgroup-name",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="track" type="object">
  &lt;p&gt;Defines a track that determines which Amazon Redshift version to apply after a new version is released. If the value for &lt;code&gt;ServerlessTrack&lt;/code&gt; is &lt;code&gt;current&lt;/code&gt;, the workgroup is updated to the most recently certified release. If the value is &lt;code&gt;trailing&lt;/code&gt;, the workgroup is updated to the previously certified release.&lt;/p&gt; Returned by the lookup.

      Optional lookup argument.
    </ResponseField>
    <ResponseField name="workgroup_version" type="string">
      Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_eventbridge_api_destinations` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	eventbridge "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/eventbridge"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eventbridge_api_destinations"})

    		ubx.Data(eventbridge.ApiDestinations, "example", eventbridge.ApiDestinationsConfig{
    			ConnectionArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:         1,
    			NamePrefix:    "example",
    		})
    	}))
    }
    ```

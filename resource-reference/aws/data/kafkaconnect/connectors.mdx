---
title: "aws_kafkaconnect_connectors"
description: "`data_aws_kafkaconnect_connectors` looks up a real, already-existing `aws_kafka_connect_connector`."
---

It runs a real, managed Kafka Connect connector, MSK Connect provisioning and scaling the underlying compute, moving data between an Apache Kafka or Amazon MSK cluster and an external system without a caller operating their own Kafka Connect worker cluster.

    // ubx sdk gen --only aws --lang go --out ./local-sdk

    	}))
    }

---
title: "aws_kafkaconnect_custom_plugins"
description: "`data_aws_kafkaconnect_custom_plugins` looks up a real, already-existing `aws_kafka_connect_custom_plugin`."
---

It uploads the real connector code, a JDBC sink, an S3 source, that an `aws_kafka_connect_connector` actually runs, MSK Connect's own way of using a connector implementation that isn't AWS-provided.

---
title: "aws_kafkaconnect_worker_configurations"
description: "`data_aws_kafkaconnect_worker_configurations` looks up a real, already-existing `aws_kafka_connect_worker_configuration`."
---

It sets real Kafka Connect worker-level properties applied to an `aws_kafka_connect_connector`'s own underlying runtime, beyond the connector's specific configuration alone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kafkaconnect "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kafkaconnect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kafkaconnect_worker_configurations"})

    		ubx.Data(kafkaconnect.WorkerConfigurations, "example", kafkaconnect.WorkerConfigurationsConfig{
    			MaxResults: 1,
    			NamePrefix: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<ResponseField name="max_results" type="number">

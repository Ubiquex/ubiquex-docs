`aws_voice_chime_voice_connector_streaming_configuration` reads the real, real-time media streaming (Kinesis Video Streams) configuration of a Chime Voice Connector.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	voice_chime "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/voice_chime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_voice_chime_voice_connector_streaming_configuration"})

    		ubx.Data(voice_chime.VoiceChimeVoiceConnectorStreamingConfiguration, "example", voice_chime.VoiceChimeVoiceConnectorStreamingConfigurationConfig{
    			VoiceConnectorId: "example",
    		})
    	}))
    }
    ```
  </Tab>

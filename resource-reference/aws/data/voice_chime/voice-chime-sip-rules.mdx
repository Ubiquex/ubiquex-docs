## Lookup arguments

<ResponseField name="max_results" type="number">

</ResponseField>

<ResponseField name="sip_media_application_id" type="string">
  The real, unique identifier of the sip media application this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

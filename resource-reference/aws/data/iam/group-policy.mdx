---
title: "aws_iam_group_policy"
description: "`data_aws_iam_group_policy` looks up a real, already-existing `aws_iam_group_policy`."
---

It attaches a real inline IAM policy directly to an `aws_iam_group`, embedded in the group itself rather than existing as a separate, reusable `aws_iam_policy` that could also be attached elsewhere.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_group_policy"})

    		ubx.Data(iam.GroupPolicy, "example", iam.GroupPolicyConfig{
    			GroupName:  "example-group-name",
    			PolicyName: "example-policy-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { GroupPolicy } from "@ubx/sdk-aws/aws/data/iam/group_policy";

    export default stack("example", () => {
      intent({ summary: "look up aws_iam_group_policy" });

      data(GroupPolicy, "example", {
        groupName: "example-group-name",
        policyName: "example-policy-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.iam import GroupPolicy, GroupPolicyConfig

    def describe():
        ubx.intent("look up aws_iam_group_policy")

        ubx.data(GroupPolicy, "example", GroupPolicyConfig(
            group_name="example-group-name",
            policy_name="example-policy-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="group_name" type="string" required>
  The real name of the group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="policy_name" type="string" required>
  The real name of the policy this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="policy_document" type="string">
  The real, JSON-formatted policy document attached to this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

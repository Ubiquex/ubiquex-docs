---
title: "aws_iam_samlprovider_tags"
description: "`data_aws_iam_samlprovider_tags` looks up a real, already-existing `aws_iam_samlprovider`."
---

It establishes real trust between IAM and an external SAML 2.0 identity provider, a corporate Active Directory Federation Services setup, for instance, so a workforce user can federate into an `aws_iam_role` using their existing enterprise credentials rather than a separate IAM identity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_samlprovider_tags"})

    		ubx.Data(iam.SamlproviderTags, "example", iam.SamlproviderTagsConfig{
    			SamlproviderArn: "arn:aws:iam::123456789012:policy/example",
    			MaxItems:        1,
    		})
    	}))
    }
    ```

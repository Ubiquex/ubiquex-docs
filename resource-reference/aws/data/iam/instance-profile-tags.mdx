---
title: "aws_iam_instance_profile_tags"
description: "`data_aws_iam_instance_profile_tags` looks up a real, already-existing `aws_iam_instance_profile`."
---

It wraps an `aws_iam_role` in the real container EC2 actually requires to attach that role's permissions to a running instance, an instance can't assume a role directly without one.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_instance_profile_tags"})

    		ubx.Data(iam.InstanceProfileTags, "example", iam.InstanceProfileTagsConfig{
    			InstanceProfileName: "example-instance-profile-name",
    			MaxItems:            1,
    		})
    	}))
    }
    ```
  </Tab>

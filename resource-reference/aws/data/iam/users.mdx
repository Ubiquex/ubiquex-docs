---
title: "aws_iam_users"
description: "`data_aws_iam_users` looks up a real, already-existing `aws_iam_user`."
---

It creates a real, individual IAM identity, distinct from an `aws_iam_role`, meant for a long-lived person or application that needs its own durable credentials rather than assuming temporary ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_users"})

    		ubx.Data(iam.Users, "example", iam.UsersConfig{
    			MaxItems:   1,
    			PathPrefix: "example",
    		})
    	}))
    }
    ```

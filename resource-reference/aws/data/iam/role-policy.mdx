---
title: "aws_iam_role_policy"
description: "`data_aws_iam_role_policy` looks up a real, already-existing `aws_iam_role_policy`."
---

It attaches a real inline IAM policy directly to an `aws_iam_role`, embedded in the role itself rather than existing as a separate, reusable `aws_iam_policy` that could also be attached elsewhere.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_role_policy"})

    		ubx.Data(iam.RolePolicy, "example", iam.RolePolicyConfig{
    			PolicyName: "example-policy-name",
    			RoleName:   "example-role-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { RolePolicy } from "@ubx/sdk-aws/aws/data/iam/role_policy";

    export default stack("example", () => {
      intent({ summary: "look up aws_iam_role_policy" });

      data(RolePolicy, "example", {
        policyName: "example-policy-name",
        roleName: "example-role-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.iam import RolePolicy, RolePolicyConfig

    def describe():
        ubx.intent("look up aws_iam_role_policy")

        ubx.data(RolePolicy, "example", RolePolicyConfig(
            policy_name="example-policy-name",
            role_name="example-role-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="policy_name" type="string" required>
  The real name of the policy this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="role_name" type="string" required>
  The real name of the IAM role this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="policy_document" type="string">
  The real, JSON-formatted policy document attached to this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

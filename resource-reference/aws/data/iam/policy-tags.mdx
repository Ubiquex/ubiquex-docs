---
title: "aws_iam_policy_tags"
description: "`data_aws_iam_policy_tags` looks up a real, already-existing `aws_iam_policy`."
---

It creates a standalone, reusable IAM policy, a real JSON document describing what's allowed. It grants nothing on its own, attach it to a role or user with `aws_iam_role_policy_attachment` to actually apply it.

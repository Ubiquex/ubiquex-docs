`data_aws_iam_role_tags` looks up a real, already-existing `aws_iam_role`: An IAM role grants a set of permissions to whatever's allowed to assume it, an EC2 instance, a Lambda function, another AWS account. `aws_iam_role` creates the role and its trust policy, real permissions are attached separately, via `aws_iam_role_policy_attachment`.

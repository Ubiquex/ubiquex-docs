---
title: "aws_iam_mfadevice"
description: "`data_aws_iam_mfadevice` looks up a real, already-existing `aws_iam_virtual_mfadevice`."
---

It registers a real, software-based MFA device, an authenticator app rather than a physical hardware token, that gets assigned to an `aws_iam_user` or the account root user to require a second factor at sign-in.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_mfadevice"})

    		ubx.Data(iam.Mfadevice, "example", iam.MfadeviceConfig{
    			SerialNumber: "example",
    		})
    	}))
    }
    ```

---
title: "aws_iam_server_certificate_tags"
description: "`data_aws_iam_server_certificate_tags` looks up a real, already-existing `aws_iam_server_certificate`."
---

It uploads a real X.509 certificate and private key to IAM for use with a Classic Load Balancer or CloudFront, IAM's original, legacy certificate storage from before AWS Certificate Manager existed to handle this instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_server_certificate_tags"})

    		ubx.Data(iam.ServerCertificateTags, "example", iam.ServerCertificateTagsConfig{
    			ServerCertificateName: "example-server-certificate-name",
    			MaxItems:              1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

            server_certificate_name="example-server-certificate-name",

    if __name__ == "__main__":
        ubx.run("example", describe)

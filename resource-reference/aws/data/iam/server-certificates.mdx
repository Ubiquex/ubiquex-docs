---
title: "aws_iam_server_certificates"
description: "`data_aws_iam_server_certificates` looks up a real, already-existing `aws_iam_server_certificate`."
---

It uploads a real X.509 certificate and private key to IAM for use with a Classic Load Balancer or CloudFront, IAM's original, legacy certificate storage from before AWS Certificate Manager existed to handle this instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_server_certificates"})

    		ubx.Data(iam.ServerCertificates, "example", iam.ServerCertificatesConfig{
    			MaxItems:   1,
    			PathPrefix: "example",
    		})
    	}))
    }
    ```
  </Tab>

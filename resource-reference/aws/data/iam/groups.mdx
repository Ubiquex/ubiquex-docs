---
title: "aws_iam_groups"
description: "`data_aws_iam_groups` looks up a real, already-existing `aws_iam_group`."
---

It creates a real, named collection of IAM users, letting a caller attach a policy once to the group and have it apply to every current and future user added to it, rather than attaching the same policy to each user individually.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_groups"})

    		ubx.Data(iam.Groups, "example", iam.GroupsConfig{

    			PathPrefix: "example",
    		})
    	}))
    }

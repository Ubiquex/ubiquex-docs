---
title: "aws_iam_attached_group_policies"
description: "`data_aws_iam_attached_group_policies` looks up a real, already-existing `aws_iam_group_policy`."
---

It attaches a real inline IAM policy directly to an `aws_iam_group`, embedded in the group itself rather than existing as a separate, reusable `aws_iam_policy` that could also be attached elsewhere.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_attached_group_policies"})

    		ubx.Data(iam.AttachedGroupPolicies, "example", iam.AttachedGroupPoliciesConfig{
    			GroupName:  "example-group-name",
    			MaxItems:   1,
    			PathPrefix: "example",
    		})
    	}))
    }
    ```

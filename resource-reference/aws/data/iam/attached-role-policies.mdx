---
title: "aws_iam_attached_role_policies"
description: "`data_aws_iam_attached_role_policies` looks up a real, already-existing `aws_iam_role_policy`."
---

It attaches a real inline IAM policy directly to an `aws_iam_role`, embedded in the role itself rather than existing as a separate, reusable `aws_iam_policy` that could also be attached elsewhere.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_attached_role_policies"})

    		ubx.Data(iam.AttachedRolePolicies, "example", iam.AttachedRolePoliciesConfig{
    			RoleName:   "example-role-name",
    			MaxItems:   1,
    			PathPrefix: "example",
    		})
    	}))
    }

`aws_iam_context_keys_for_principal_policy` reads the real context keys referenced by all policies attached to an IAM principal, for use in a policy simulation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_context_keys_for_principal_policy"})

    		ubx.Data(iam.ContextKeysForPrincipalPolicy, "example", iam.ContextKeysForPrincipalPolicyConfig{
    			PolicySourceArn: "arn:aws:iam::123456789012:policy/example",
    			PolicyInputList: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

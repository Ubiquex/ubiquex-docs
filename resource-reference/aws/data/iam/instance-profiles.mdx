---
title: "aws_iam_instance_profiles"
description: "`data_aws_iam_instance_profiles` looks up a real, already-existing `aws_iam_instance_profile`."
---

It wraps an `aws_iam_role` in the real container EC2 actually requires to attach that role's permissions to a running instance, an instance can't assume a role directly without one.

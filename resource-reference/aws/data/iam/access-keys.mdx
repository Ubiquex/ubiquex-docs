---
title: "aws_iam_access_keys"
description: "`data_aws_iam_access_keys` looks up a real, already-existing `aws_iam_access_key`."
---

It issues a real, long-lived programmatic credential, an access key ID and secret, for an `aws_iam_user`, the actual credential used for CLI and SDK calls made as that user rather than through a browser session.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iam "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iam"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iam_access_keys"})

    		ubx.Data(iam.AccessKeys, "example", iam.AccessKeysConfig{
    			MaxItems: 1,
    			UserName: "example-user-name",
    		})
    	}))
    }
    ```
  </Tab>

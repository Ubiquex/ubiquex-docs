---
title: "aws_ram_permissions"
description: "`data_aws_ram_permissions` looks up a real, already-existing `aws_ram_permission`."
---

It defines a real, reusable managed permission, the specific set of actions a principal is allowed on a shared resource, that an `aws_ram_resource_share` attaches instead of relying only on the resource's own default permission.

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="permission_type" type="string">
  The real, discriminating type of the permission this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The real, discriminating type of AWS resource this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

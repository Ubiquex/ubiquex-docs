---
title: "aws_ram_resource_share_permissions"
description: "`data_aws_ram_resource_share_permissions` looks up a real, already-existing `aws_ram_resource_share`."
---

It creates a real cross-account resource share, listing the specific resource ARNs, principal accounts or organizational units, and permissions involved, the core AWS Resource Access Manager resource that actually grants another account access to a resource without duplicating it.

---
title: "aws_ram_permission_associations"
description: "`data_aws_ram_permission_associations` looks up a real, already-existing `aws_ram_permission`."
---

It defines a real, reusable managed permission, the specific set of actions a principal is allowed on a shared resource, that an `aws_ram_resource_share` attaches instead of relying only on the resource's own default permission.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chatbot "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/chatbot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_chatbot_associations"})

    		ubx.Data(chatbot.Associations, "example", chatbot.AssociationsConfig{
    			ChatConfiguration: "example",
    			MaxResults:        1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="chat_configuration" type="string" required>
  The real configuration of the chat. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="associations" type="list(object)">
  The real associations included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

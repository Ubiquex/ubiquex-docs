---
title: "aws_chatbot_microsoft_teams_channel_configurations"
description: "`data_aws_chatbot_microsoft_teams_channel_configurations` looks up a real, already-existing `aws_chatbot_microsoft_teams_channel_configuration`."
---

It connects a Microsoft Teams channel to AWS Chatbot, the Teams counterpart to `aws_chatbot_slack_channel_configuration`, with its own real team and tenant ID, SNS topics, IAM role, and guardrail policies.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_chatbot_microsoft_teams_channel_configurations"})

    		ubx.Data(chatbot.MicrosoftTeamsChannelConfigurations, "example", chatbot.MicrosoftTeamsChannelConfigurationsConfig{

    			TeamId:     "example",
    		})
    	}))
    }

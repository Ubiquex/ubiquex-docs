---
title: "aws_waf_regex_pattern_sets"
description: "`data_aws_waf_regex_pattern_sets` looks up a real, already-existing `aws_wafregional_regex_pattern_set`."
---

It defines a real set of regular expressions that an `aws_wafregional_rule` references as a match condition. Support for AWS WAF Classic ended September 30, 2025.

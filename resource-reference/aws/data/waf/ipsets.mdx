---
title: "aws_waf_ipsets"
description: "`data_aws_waf_ipsets` looks up a real, already-existing `aws_waf_ipset`."
---

It defines a real set of IP addresses or CIDR ranges that an `aws_waf_rule` references as a match condition. Like the rest of AWS WAF Classic, support for this resource ended September 30, 2025, roughly eleven months in the past; AWS's current offering is AWS WAFv2.

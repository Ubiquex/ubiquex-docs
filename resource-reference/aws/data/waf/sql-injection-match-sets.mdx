---
title: "aws_waf_sql_injection_match_sets"
description: "`data_aws_waf_sql_injection_match_sets` looks up a real, already-existing `aws_waf_sql_injection_match_set`."
---

It defines a real condition, matching SQL-injection-like patterns in a request part, that an `aws_waf_rule` references. Like the rest of AWS WAF Classic, support for this resource ended September 30, 2025.

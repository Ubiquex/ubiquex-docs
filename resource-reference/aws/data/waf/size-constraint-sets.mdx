---
title: "aws_waf_size_constraint_sets"
description: "`data_aws_waf_size_constraint_sets` looks up a real, already-existing `aws_waf_size_constraint_set`."
---

It defines a real condition, matching a request part's size against a threshold, that an `aws_waf_rule` references. Like the rest of AWS WAF Classic, support for this resource ended September 30, 2025.

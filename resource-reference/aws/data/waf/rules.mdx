---
title: "aws_waf_rules"
description: "`data_aws_waf_rules` looks up a real, already-existing `aws_waf_rule`."
---

It combines real match conditions, byte, IP set, size constraint, SQL injection, XSS, into a single rule that an `aws_waf_web_acl` evaluates against incoming requests, under AWS WAF Classic (global, for CloudFront). AWS WAF Classic support ended September 30, 2025, roughly eleven months in the past; AWS's current, actively developed offering is AWS WAFv2.

---
title: "aws_waf_rate_based_rule_managed_keys"
description: "`data_aws_waf_rate_based_rule_managed_keys` looks up a real, already-existing `aws_wafregional_rate_based_rule`."
---

It defines a real rule under AWS WAF Classic Regional that automatically tracks request rate per source IP and blocks addresses that exceed a configured threshold, distinct from `aws_wafregional_rule`'s own static, condition-based matching. Support for AWS WAF Classic ended September 30, 2025, roughly eleven months in the past; AWS's current offering, AWS WAFv2, has its own built-in rate-based rule statement type.

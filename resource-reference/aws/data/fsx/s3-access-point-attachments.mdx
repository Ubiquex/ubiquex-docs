---
title: "aws_fsx_s3_access_point_attachments"
description: "`data_aws_fsx_s3_access_point_attachments` looks up a real, already-existing `aws_fsx_s3_access_point_attachment`."
---

It exposes an `aws_fsx_file_system`'s data through a real S3 access point, so applications that already speak the S3 API can read and write FSx-backed data without switching to a file protocol like NFS or SMB.

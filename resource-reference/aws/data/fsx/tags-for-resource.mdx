## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	fsx "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/fsx"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_fsx_tags_for_resource"})

    		ubx.Data(fsx.TagsForResource, "example", fsx.TagsForResourceConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.fsx import TagsForResource, TagsForResourceConfig

    def describe():
        ubx.intent("look up aws_fsx_tags_for_resource")

        ubx.data(TagsForResource, "example", TagsForResourceConfig(
            resource_arn="arn:aws:iam::123456789012:policy/example",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  &lt;p&gt;The maximum number of resources to return in the response. This value must be an integer greater than zero.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  &lt;p&gt;The Amazon Resource Name (ARN) for a given resource. ARNs uniquely identify Amazon Web Services resources. We require an ARN when you need to specify a resource unambiguously across all of Amazon Web Services. For more information, see &lt;a href="https://docs.aws.amazon.com/general/latest/gr/aws-arns-and-namespaces.html"&gt;Amazon Resource Names (ARNs)&lt;/a&gt; in the &lt;i&gt;Amazon Web Services General Reference&lt;/i&gt;.&lt;/p&gt; Required lookup argument.
</ResponseField>

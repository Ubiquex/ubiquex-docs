It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Lookup arguments

<ResponseField name="client_request_token" type="string">
  &lt;p&gt;(Optional) An idempotency token for resource creation, in a string of up to 63 ASCII characters. This token is automatically filled on your behalf when you use the Command Line Interface (CLI) or an Amazon Web Services SDK.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="file_system_id" type="string" required>
  &lt;p&gt;The globally unique ID of the file system, assigned by Amazon FSx.&lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt;The maximum number of resources to return in the response. This value must be an integer greater than zero.&lt;/p&gt; Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="aliases" type="list(object)">
  &lt;p&gt;An array of one or more DNS aliases that are currently associated with the Amazon FSx file system. Aliases allow you to use existing DNS names to access the data in your Amazon FSx file system. You can associate up to 50 aliases with a file system at any time. You can associate additional DNS aliases after you create the file system using the AssociateFileSystemAliases operation. You can remove DNS aliases from the file system after it is created using the DisassociateFileSystemAliases operation. You only need to specify the alias name in the request payload. For more information, see &lt;a href="https://docs.aws.amazon.com/fsx/latest/WindowsGuide/managing-dns-aliases.html"&gt;Managing DNS aliases&lt;/a&gt;.&lt;/p&gt; Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  &lt;p&gt;(Optional) Opaque pagination token returned from a previous operation (String). If present, this token indicates from what point you can continue processing the request, where the previous &lt;code&gt;NextToken&lt;/code&gt; value left off.&lt;/p&gt; Returned by the lookup.
</ResponseField>

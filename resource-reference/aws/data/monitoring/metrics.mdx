`aws_monitoring_metrics` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	monitoring "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/monitoring"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_monitoring_metrics"})

    		ubx.Data(monitoring.Metrics, "example", monitoring.MetricsConfig{
    			Dimensions:            []map[string]any{{"name": "example-name"}},
    			IncludeLinkedAccounts: true,
    			MetricName:            "example-metric-name",
    			Namespace:             "example",
    			OwningAccount:         "example",
    			RecentlyActive:        "example",
    		})
    	}))
    }
    ```

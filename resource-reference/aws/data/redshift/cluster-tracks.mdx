---
title: "aws_redshift_cluster_tracks"
description: "`data_aws_redshift_cluster_tracks` looks up a real, already-existing `aws_redshift_cluster`."
---

It creates a real, provisioned Amazon Redshift data warehouse cluster, its leader and compute nodes, the original Redshift architecture distinct from the auto-scaling `aws_redshift_serverless_namespace`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_cluster_tracks"})

    		ubx.Data(redshift.ClusterTracks, "example", redshift.ClusterTracksConfig{
    			MaintenanceTrackName: "example-maintenance-track-name",
    			MaxRecords:           1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="maintenance_track_name" type="string">
  The real name of the maintenance track this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="maintenance_tracks" type="list(object)">
  The real, available maintenance tracks for this Redshift cluster. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

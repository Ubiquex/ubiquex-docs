`aws_redshift_data_shares` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/redshift"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_data_shares"})

    		ubx.Data(redshift.DataShares, "example", redshift.DataSharesConfig{
    			DataShareArn: "arn:aws:iam::123456789012:policy/example",
    			MaxRecords:   1,
    		})
    	}))
    }

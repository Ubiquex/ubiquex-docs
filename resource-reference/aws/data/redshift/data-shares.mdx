## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_data_shares"})

    		ubx.Data(redshift.DataShares, "example", redshift.DataSharesConfig{
    			DataShareArn: "arn:aws:iam::123456789012:policy/example",
    			MaxRecords:   1,
    		})
    	}))
    }
    ```
  </Tab>

    def describe():

        ubx.data(DataShares, "example", DataSharesConfig(

## Lookup arguments

<ResponseField name="data_share_arn" type="string">
  The real Amazon Resource Name (ARN) of the data share this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data_shares" type="list(object)">
  The real Redshift data shares included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

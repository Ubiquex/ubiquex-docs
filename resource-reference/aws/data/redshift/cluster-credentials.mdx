---
title: "aws_redshift_cluster_credentials"
description: "`data_aws_redshift_cluster_credentials` looks up a real, already-existing `aws_redshift_cluster`."
---

It creates a real, provisioned Amazon Redshift data warehouse cluster, its leader and compute nodes, the original Redshift architecture distinct from the auto-scaling `aws_redshift_serverless_namespace`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_cluster_credentials"})

    		ubx.Data(redshift.ClusterCredentials, "example", redshift.ClusterCredentialsConfig{
    			DbUser:            "example",
    			AutoCreate:        true,
    			ClusterIdentifier: "example",
    			CustomDomainName:  "example-custom-domain-name",
    			DbGroups:          []string{"example"},
    			DbName:            "example-db-name",
    			DurationSeconds:   7200,
    		})
    	}))
    }
    ```

---
title: "aws_redshift_default_cluster_parameters"
description: "`data_aws_redshift_default_cluster_parameters` looks up a real, already-existing `aws_redshift_cluster_parameter_group`."
---

It defines a real set of engine parameters that can be applied to an `aws_redshift_cluster` instead of hand-tuning the cluster individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_default_cluster_parameters"})

    		ubx.Data(redshift.DefaultClusterParameters, "example", redshift.DefaultClusterParametersConfig{
    			ParameterGroupFamily: "example",
    			Marker:               "example",
    			MaxRecords:           1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="parameter_group_family" type="string" required>
  The real parameter group family. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "aws_redshift_cluster_parameters"
description: "`data_aws_redshift_cluster_parameters` looks up a real, already-existing `aws_redshift_cluster_parameter_group`."
---

It defines a real set of engine parameters that can be applied to an `aws_redshift_cluster` instead of hand-tuning the cluster individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_cluster_parameters"})

    		ubx.Data(redshift.ClusterParameters, "example", redshift.ClusterParametersConfig{
    			ParameterGroupName: "example-parameter-group-name",
    			MaxRecords:         1,
    			Source:             "example",
    		})
    	}))
    }
    ```
  </Tab>

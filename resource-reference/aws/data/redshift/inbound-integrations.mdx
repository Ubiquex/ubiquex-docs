---
title: "aws_redshift_inbound_integrations"
description: "`data_aws_redshift_inbound_integrations` looks up a real, already-existing `aws_redshift_integration`."
---

It creates a real, zero-ETL integration that continuously replicates data from a source such as an RDS or Aurora cluster into Amazon Redshift, so it can be queried for analytics within seconds of being written.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/redshift"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_inbound_integrations"})

    		ubx.Data(redshift.InboundIntegrations, "example", redshift.InboundIntegrationsConfig{
    			IntegrationArn: "arn:aws:iam::123456789012:policy/example",
    			MaxRecords:     1,
    			TargetArn:      "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

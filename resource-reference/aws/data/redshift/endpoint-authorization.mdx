---
title: "aws_redshift_endpoint_authorization"
description: "`data_aws_redshift_endpoint_authorization` looks up a real, already-existing `aws_redshift_endpoint_authorization`."
---

It grants a real other AWS account permission to create an `aws_redshift_endpoint_access` against this account's `aws_redshift_cluster`, the authorization step that has to happen before the other account's endpoint can be created.

---
title: "aws_redshift_cluster_versions"
description: "`data_aws_redshift_cluster_versions` looks up a real, already-existing `aws_redshift_cluster`."
---

It creates a real, provisioned Amazon Redshift data warehouse cluster, its leader and compute nodes, the original Redshift architecture distinct from the auto-scaling `aws_redshift_serverless_namespace`.

## Example

    ```go

    import (
    	redshift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/redshift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_redshift_cluster_versions"})

    		ubx.Data(redshift.ClusterVersions, "example", redshift.ClusterVersionsConfig{
    			ClusterParameterGroupFamily: "example",
    			ClusterVersion:              "example",
    			MaxRecords:                  1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="cluster_parameter_group_family" type="string">
  The real cluster parameter group family. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="cluster_version" type="string">
  The real version of the cluster. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="cluster_versions" type="list(object)">

</ResponseField>

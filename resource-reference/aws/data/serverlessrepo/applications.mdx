---
title: "aws_serverlessrepo_applications"
description: "`data_aws_serverlessrepo_applications` looks up a real, already-existing `aws_serverless_repo_application`."
---

It publishes a real SAM application to the AWS Serverless Application Repository, packaging its template and code so other accounts can discover, review, and deploy it directly from the repository rather than copying source by hand.

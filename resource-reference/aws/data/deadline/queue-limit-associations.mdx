---
title: "aws_deadline_queue_limit_associations"
description: "`data_aws_deadline_queue_limit_associations` looks up a real, already-existing `aws_deadline_queue_limit_association`."
---

It is the real, actual link between an `aws_deadline_queue` and an `aws_deadline_limit`. A limit defined but never associated with a queue never actually constrains any job.

---
title: "aws_deadline_available_metered_products"
description: "`data_aws_deadline_available_metered_products` looks up a real, already-existing `aws_deadline_metered_product`."
---

It is one real, usage-based-licensed software product made available through an `aws_deadline_license_endpoint`, added so an `aws_deadline_fleet`'s workers can check that specific product's license out for a job.

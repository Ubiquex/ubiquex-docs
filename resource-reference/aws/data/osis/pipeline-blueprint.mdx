---
title: "aws_osis_pipeline_blueprint"
description: "`data_aws_osis_pipeline_blueprint` looks up a real, already-existing `aws_osis_pipeline`."
---

It creates a real, fully managed OpenSearch Ingestion pipeline, a serverless Data Prepper configuration (in YAML) that filters, transforms, and routes data from a source such as S3 into an OpenSearch domain or collection without infrastructure to manage.

## Example

<Tabs>

    package main

    import (
    	osis "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/osis"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_osis_pipeline_blueprint"})

    		ubx.Data(osis.PipelineBlueprint, "example", osis.PipelineBlueprintConfig{
    			BlueprintName: "example-blueprint-name",
    		})
    	}))
    }

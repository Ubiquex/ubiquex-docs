`aws_data_sync_location_smb` registers a real, on-premises SMB file share as a DataSync transfer endpoint, the Windows-share counterpart to `aws_data_sync_location_nfs`.

## Example

    ```go
    	data "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sync location smb"})

    		ubx.Resource(data.SyncLocationSmb, "example", data.SyncLocationSmbConfig{
    			AgentArns:          []string{"example"},
    			AuthenticationType: "example",
    			CustomSecretConfig: map[string]any{"secret_access_role_arn": "example"},
    			DnsIpAddresses:     []string{"example"},
    			Domain:             "example",
    			KerberosKeytab:     "example",
    			KerberosKrb5Conf:   "example",
    			KerberosPrincipal:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="agent_arns" type="list(string)" required>
  The Amazon Resource Names (ARNs) of agents to use for a Simple Message Block (SMB) location. Required.
</ResponseField>

<ResponseField name="authentication_type" type="string">
  The authentication mode used to determine identity of user. Optional.
</ResponseField>

<ResponseField name="custom_secret_config" type="object">
  Specifies configuration information for a customer-managed secret, such as a password or set of credentials that DataSync uses to access a specific transfer location, and an IAM role that DataSync can assume and access the customer-managed secret. Optional.
  <Expandable title="properties">
    <ResponseField name="secret_access_role_arn" type="string" required>
      Specifies the ARN for the AWS Identity and Access Management role that DataSync uses to access the secret specified for SecretArn. Required.
    </ResponseField>
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for a customer created AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dns_ip_addresses" type="list(string)">
  Specifies the IPv4 addresses for the DNS servers that your SMB file server belongs to. This parameter applies only if AuthenticationType is set to KERBEROS. If you have multiple domains in your environment, configuring this parameter makes sure that DataSync connects to the right SMB file server. Optional.
</ResponseField>

<ResponseField name="domain" type="string">
  The name of the Windows domain that the SMB server belongs to. Optional.
</ResponseField>

<ResponseField name="kerberos_keytab" type="string">
  The Base64 string representation of the Keytab file. Specifies your Kerberos key table (keytab) file, which includes mappings between your service principal name (SPN) and encryption keys. To avoid task execution errors, make sure that the SPN in the keytab file matches exactly what you specify for KerberosPrincipal and in your krb5.conf file. Optional.
</ResponseField>

<ResponseField name="kerberos_krb5_conf" type="string">
  The string representation of the Krb5Conf file, or the presigned URL to access the Krb5.conf file within an S3 bucket. Specifies a Kerberos configuration file (krb5.conf) that defines your Kerberos realm configuration. To avoid task execution errors, make sure that the service principal name (SPN) in the krb5.conf file matches exactly what you specify for KerberosPrincipal and in your keytab file. Optional.
</ResponseField>

<ResponseField name="kerberos_principal" type="string">
  Specifies a service principal name (SPN), which is an identity in your Kerberos realm that has permission to access the files, folders, and file metadata in your SMB file server. SPNs are case sensitive and must include a prepended cifs/. For example, an SPN might look like cifs/kerberosuser@EXAMPLE.COM. Your task execution will fail if the SPN that you provide for this parameter doesn't match exactly what's in your keytab or krb5.conf files. Optional.
</ResponseField>

<ResponseField name="mount_options" type="object">
  The mount options used by DataSync to access the SMB server. Optional.
  <Expandable title="properties">
    <ResponseField name="version" type="string">
      The specific SMB version that you want DataSync to use to mount your SMB share. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="password" type="string">
  The password of the user who can mount the share and has the permissions to access files and folders in the SMB share. Optional.
</ResponseField>

<ResponseField name="server_hostname" type="string">
  The name of the SMB server. This value is the IP address or Domain Name Service (DNS) name of the SMB server. Optional.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  The subdirectory in the SMB file system that is used to read data from the SMB source location or write data to the SMB destination Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to assign to the DataSync SMB location, used to categorize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user" type="string">
  The user who can mount the share, has the permissions to access files and folders in the SMB share. Optional.
</ResponseField>

## Output properties

<ResponseField name="cmk_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as a password or set of credentials that DataSync uses to access a specific transfer location, and a customer-managed AWS KMS key. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      Specifies the ARN for the customer-managed AWS KMS key used to encrypt the secret specified for SecretArn. DataSync provides this key to AWS Secrets Manager. Optional.
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      Specifies the ARN for an AWS Secrets Manager secret, managed by DataSync. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the SMB location that is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the SMB location that was described. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="managed_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as a password or set of credentials that DataSync uses to access a specific transfer location. DataSync uses the default AWS-managed KMS key to encrypt this secret in AWS Secrets Manager. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for an AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "aws_bedrock_agent_resource_policy"
description: "`data_aws_bedrock_agent_resource_policy` looks up a real, already-existing `aws_bedrock_resource_policy`."
---

It attaches a real resource-based access policy to a Bedrock resource, controlling which principals, including from other accounts, can invoke or manage it, the general-purpose counterpart to resource-specific policies like `aws_bedrock_knowledge_base_policy`.

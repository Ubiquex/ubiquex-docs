<ResponseField name="scope" type="object">
  &lt;p&gt;Describes the scope of a recommendation preference.&lt;/p&gt; &lt;p&gt;Recommendation preferences can be created at the organization level (for management accounts of an organization only), account level, and resource level. For more information, see &lt;a href="https://docs.aws.amazon.com/compute-optimizer/latest/ug/enhanced-infrastructure-metrics.html"&gt;Activating enhanced infrastructure metrics&lt;/a&gt; in the &lt;i&gt;Compute Optimizer User Guide&lt;/i&gt;.&lt;/p&gt; &lt;note&gt; &lt;p&gt;You cannot create recommendation preferences for Auto Scaling groups at the organization and account levels. You can create recommendation preferences for Auto Scaling groups only at the resource level by specifying a scope name of &lt;code&gt;ResourceArn&lt;/code&gt; and a scope value of the Auto Scaling group Amazon Resource Name (ARN). This will configure the preference for all instances that are part of the specified Auto Scaling group. You also cannot create recommendation preferences at the resource level for instances that are part of an Auto Scaling group. You can create recommendation preferences at the resource level only for standalone instances.&lt;/p&gt; &lt;/note&gt; Optional lookup argument.

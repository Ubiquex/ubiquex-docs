## Lookup arguments

<ResponseField name="max_results" type="number">
  &lt;p&gt;The maximum number of results to return for each paginated request.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="query_id" type="string" required>
  &lt;p&gt;The unique identifier for a query execution.&lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="workspace_name" type="string" required>
  The real name of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

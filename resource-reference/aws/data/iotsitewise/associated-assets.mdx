## Lookup arguments

</ResponseField>

<ResponseField name="hierarchy_id" type="string">
  The real, unique identifier of the hierarchy this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="traversal_direction" type="string">

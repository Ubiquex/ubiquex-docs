`aws_data_zone_domain` is Amazon DataZone's top-level real container for cataloging, governing, and sharing data, the resource every `aws_data_zone_project`, `aws_data_zone_environment`, and business glossary in one DataZone deployment belongs to.

## Input properties

<ResponseField name="description" type="string">
  The description of the Amazon DataZone domain. Optional.
</ResponseField>

<ResponseField name="domain_execution_role" type="string">
  The domain execution role that is created when an Amazon DataZone domain is created. The domain execution role is created in the AWS account that houses the Amazon DataZone domain. Optional.
</ResponseField>

<ResponseField name="domain_version" type="string">
  The version of the domain. Optional.
</ResponseField>

<ResponseField name="kms_key_identifier" type="string">
  The identifier of the AWS Key Management Service (KMS) key that is used to encrypt the Amazon DataZone domain, metadata, and reporting data. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Amazon DataZone domain. Required.
</ResponseField>

<ResponseField name="service_role" type="string">
  The service role of the domain that is created. Optional.
</ResponseField>

<ResponseField name="single_sign_on" type="object">
  The single-sign on configuration of the Amazon DataZone domain. Optional.
  <Expandable title="properties">
    <ResponseField name="idc_instance_arn" type="string">
      The ARN of the AWS Identity Center instance. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of single sign-on in Amazon DataZone. Optional.
    </ResponseField>
    <ResponseField name="user_assignment" type="string">
      The single sign-on user assignment in Amazon DataZone. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags specified for the Amazon DataZone domain. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key (e.g., 'Environment') of a tag to attach to the Amazon DataZone domain, used to organize and manage the domain resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag applied to the DataZone domain, which can be used for resource identification, categorization, and cost tracking. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

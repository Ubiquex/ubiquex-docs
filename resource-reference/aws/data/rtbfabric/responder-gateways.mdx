---
title: "aws_rtbfabric_responder_gateways"
description: "`data_aws_rtbfabric_responder_gateways` looks up a real, already-existing `aws_rtbfabric_responder_gateway`."
---

It creates a real gateway within AWS RTB Fabric that receives real-time bidding requests and returns bid responses, the side of the fabric a bidder's own infrastructure sits behind.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rtbfabric "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/rtbfabric"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_rtbfabric_responder_gateways"})

    		ubx.Data(rtbfabric.ResponderGateways, "example", rtbfabric.ResponderGatewaysConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

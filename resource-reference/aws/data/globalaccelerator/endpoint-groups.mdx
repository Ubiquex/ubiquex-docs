---
title: "aws_globalaccelerator_endpoint_groups"
description: "`data_aws_globalaccelerator_endpoint_groups` looks up a real, already-existing `aws_global_accelerator_endpoint_group`."
---

It is the real, specific set of endpoints, ALBs, NLBs, EC2 instances, Elastic IPs, in one AWS Region that an `aws_global_accelerator_listener` routes matching traffic to, with health checks determining which endpoints actually receive it.

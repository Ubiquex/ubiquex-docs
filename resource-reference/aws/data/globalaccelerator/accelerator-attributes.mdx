---
title: "aws_globalaccelerator_accelerator_attributes"
description: "`data_aws_globalaccelerator_accelerator_attributes` looks up a real, already-existing `aws_global_accelerator_accelerator`."
---

It creates two real, static anycast IP addresses that route traffic over AWS's own global network backbone to the closest healthy endpoint, real, consistent public entry points independent of the endpoints' own Regions or IP addresses changing behind them.

## Example

    ```go

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_globalaccelerator_accelerator_attributes"})

    		ubx.Data(globalaccelerator.AcceleratorAttributes, "example", globalaccelerator.AcceleratorAttributesConfig{
    			AcceleratorArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

---
title: "aws_globalaccelerator_cross_account_attachments"
description: "`data_aws_globalaccelerator_cross_account_attachments` looks up a real, already-existing `aws_global_accelerator_cross_account_attachment`."
---

It authorizes a real, specific set of endpoint resources owned by another AWS account to be added to this account's own `aws_global_accelerator_accelerator`, a real cross-account grant rather than every accelerator needing to live in the same account as every endpoint it targets.

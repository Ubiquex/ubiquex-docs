---
title: "aws_globalaccelerator_listeners"
description: "`data_aws_globalaccelerator_listeners` looks up a real, already-existing `aws_global_accelerator_listener`."
---

It checks for real connection requests on a specific port and protocol against an `aws_global_accelerator_accelerator`, the entry point `aws_global_accelerator_endpoint_group`s route matching traffic from.

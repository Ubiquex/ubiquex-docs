---
title: "aws_comprehend_document_classifiers"
description: "`data_aws_comprehend_document_classifiers` looks up a real, already-existing `aws_comprehend_document_classifier`."
---

It trains a real, custom model on caller-labeled documents, plain text, PDF, Word, or images, to categorize new documents into the caller's own classes, single-label or multi-label, run synchronously in real time or as a batch job against a whole document set.

---
title: "aws_comprehend_flywheel_iteration"
description: "`data_aws_comprehend_flywheel_iteration` looks up a real, already-existing `aws_comprehend_flywheel`."
---

It orchestrates the continuous retraining of a custom Comprehend classification or entity-recognition model, storing every version's training and test data in a real, managed data lake, so a caller can add new labeled data periodically, run an iteration that evaluates and trains a new model version, and promote it once its metrics improve on the active version.

    func main() {

    		ubx.Data(comprehend.FlywheelIteration, "example", comprehend.FlywheelIterationConfig{
    			FlywheelArn:         "arn:aws:iam::123456789012:policy/example",
    			FlywheelIterationId: "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="flywheel_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the flywheel this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="flywheel_iteration_id" type="string" required>
  The real, unique identifier of the flywheel iteration this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "aws_comprehend_flywheels"
description: "`data_aws_comprehend_flywheels` looks up a real, already-existing `aws_comprehend_flywheel`."
---

It orchestrates the continuous retraining of a custom Comprehend classification or entity-recognition model, storing every version's training and test data in a real, managed data lake, so a caller can add new labeled data periodically, run an iteration that evaluates and trains a new model version, and promote it once its metrics improve on the active version.

`aws_mediaconvert_endpoints` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	mediaconvert "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/mediaconvert"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_mediaconvert_endpoints"})

    		ubx.Data(mediaconvert.Endpoints, "example", mediaconvert.EndpointsConfig{
    			MaxResults: 1,
    			Mode:       "example",
    		})
    	}))
    }
    ```

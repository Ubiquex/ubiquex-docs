---
title: "aws_qbusiness_plugin_actions"
description: "`data_aws_qbusiness_plugin_actions` looks up a real, already-existing `aws_qbusiness_plugin`."
---

It connects a real third-party or custom action, such as creating a ticket or updating a record in another system, to an `aws_qbusiness_application`, letting its assistant take actions rather than only answer questions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	qbusiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/qbusiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_qbusiness_plugin_actions"})

    		ubx.Data(qbusiness.PluginActions, "example", qbusiness.PluginActionsConfig{
    			ApplicationId: "example",
    			PluginId:      "example",
    			MaxResults:    1,
    		})
    	}))
    }
    ```

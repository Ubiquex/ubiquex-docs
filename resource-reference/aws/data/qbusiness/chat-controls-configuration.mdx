`aws_qbusiness_chat_controls_configuration` reads the real, configured guardrails (blocked topics, response scope) applied to an Amazon Q Business application's own chat.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	qbusiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/qbusiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_qbusiness_chat_controls_configuration"})

    		ubx.Data(qbusiness.ChatControlsConfiguration, "example", qbusiness.ChatControlsConfigurationConfig{
    			ApplicationId: "example",
    			MaxResults:    1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

`aws_qbusiness_media` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	qbusiness "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/qbusiness"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_qbusiness_media"})

    		ubx.Data(qbusiness.Media, "example", qbusiness.MediaConfig{
    			ApplicationId:  "example",
    			ConversationId: "example",
    			MediaId:        "example",
    			MessageId:      "example",
    		})
    	}))
    }
    ```

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datasync "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/datasync"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_datasync_agents"})

    		ubx.Data(datasync.Agents, "example", datasync.AgentsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.datasync import Agents, AgentsConfig

    def describe():
        ubx.intent("look up aws_datasync_agents")

        ubx.data(Agents, "example", AgentsConfig(
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="agents" type="list(object)">
  The real agents included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

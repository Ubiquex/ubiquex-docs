`aws_mturk_requester_review_policy_results_for_hit` reads the real results of an automated review policy applied to a Mechanical Turk HIT's own assignments.

## Lookup arguments

<ResponseField name="hitid" type="string" required>
  The real, unique identifier of the Amazon Mechanical Turk HIT this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="policy_levels" type="list(string)">
  The real levels this policy applies at. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="retrieve_actions" type="bool">
  Whether actions are retrieved alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="retrieve_results" type="bool">
  Whether results are retrieved alongside this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

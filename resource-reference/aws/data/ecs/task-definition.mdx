---
title: "aws_ecs_task_definition"
description: "`data_aws_ecs_task_definition` looks up a real, already-existing `aws_ecs_task_definition`."
---

It is the real blueprint, container images, CPU and memory, networking mode, IAM roles, that an `aws_ecs_service` or a standalone task actually launches from.

## Example

<Tabs>
  <Tab title="Go">

    package main

    import (
    	ecs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/ecs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ecs_task_definition"})

    		ubx.Data(ecs.TaskDefinition, "example", ecs.TaskDefinitionConfig{
    			TaskDefinition: "example",
    			Include:        []string{"example"},
    		})
    	}))
    }

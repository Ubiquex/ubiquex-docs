---
title: "aws_rbin_rules"
description: "`data_aws_rbin_rules` looks up a real, already-existing `aws_rbin_rule`."
---

It creates a real Recycle Bin retention rule that intercepts deletion of a matching resource, an EBS snapshot or EBS-backed AMI, retaining it in the bin for a configured period so it can be recovered instead of being permanently deleted immediately.

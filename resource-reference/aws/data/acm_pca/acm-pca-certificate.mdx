## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	acm_pca "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/acm_pca"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_acm_pca_certificate"})

    		ubx.Data(acm_pca.AcmPcaCertificate, "example", acm_pca.AcmPcaCertificateConfig{
    			CertificateArn:          "arn:aws:iam::123456789012:policy/example",
    			CertificateAuthorityArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="certificate_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the certificate this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="certificate_authority_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the certificate authority this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="certificate" type="string">
  The real certificate this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="certificate_chain" type="string">
  The real, full certificate chain for this certificate. **(AI-inferred)** Returned by the lookup.
</ResponseField>

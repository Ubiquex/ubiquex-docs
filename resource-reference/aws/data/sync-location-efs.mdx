`aws_data_sync_location_efs` registers a real Amazon EFS file system as a DataSync transfer endpoint, the same real endpoint role as `aws_data_sync_location_s3` but for EFS instead of S3.

## Input properties

<ResponseField name="access_point_arn" type="string">
  The Amazon Resource Name (ARN) for the Amazon EFS Access point that DataSync uses when accessing the EFS file system. Optional.
</ResponseField>

<ResponseField name="ec2_config" type="object" required>
  The subnet and security group that DataSync uses to access target EFS file system. Required.
  <Expandable title="properties">
    <ResponseField name="security_group_arns" type="list(string)" required>
      The Amazon Resource Names (ARNs) of the security groups that are configured for the Amazon EC2 resource. Required.
    </ResponseField>
    <ResponseField name="subnet_arn" type="string" required>
      The ARN of the subnet that DataSync uses to access the target EFS file system. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="efs_filesystem_arn" type="string">
  The Amazon Resource Name (ARN) for the Amazon EFS file system. Optional.
</ResponseField>

<ResponseField name="file_system_access_role_arn" type="string">
  The Amazon Resource Name (ARN) of the AWS IAM role that the DataSync will assume when mounting the EFS file system. Optional.
</ResponseField>

<ResponseField name="in_transit_encryption" type="string">
  Protocol that is used for encrypting the traffic exchanged between the DataSync Agent and the EFS file system. Optional.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  A subdirectory in the location's path. This subdirectory in the EFS file system is used to read data from the EFS source location or write data to the EFS destination. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to this AWS DataSync EFS location, used to identify and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair attached to this AWS DataSync location for EFS, used for metadata and resource categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon EFS file system location that is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the EFS location that was described. Computed by AWS after `ship`.
</ResponseField>

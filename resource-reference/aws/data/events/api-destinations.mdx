---
title: "aws_events_api_destinations"
description: "`data_aws_events_api_destinations` looks up a real, already-existing `aws_events_api_destination`."
---

It is a real HTTP endpoint target an `aws_events_rule` can invoke directly, the mechanism for routing matched events to a third-party API without a Lambda function in between just to make the HTTP call.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_events_api_destinations"})

    		ubx.Data(events.ApiDestinations, "example", events.ApiDestinationsConfig{
    			ConnectionArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:         1,
    			NamePrefix:    "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="connection_arn" type="string">
  The real Amazon Resource Name (ARN) of the connection this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="name_prefix" type="string">
  Restricts results to objects whose name starts with this prefix. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="api_destinations" type="list(object)">
  The real EventBridge API destinations included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

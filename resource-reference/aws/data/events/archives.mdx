`aws_events_archives` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	events "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/events"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_events_archives"})

    		ubx.Data(events.Archives, "example", events.ArchivesConfig{
    			EventSourceArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:          1,
    			NamePrefix:     "example",
    			State:          "example",
    		})
    	}))
    }
    ```

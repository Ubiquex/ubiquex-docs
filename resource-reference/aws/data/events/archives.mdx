---
title: "aws_events_archives"
description: "`data_aws_events_archives` looks up a real, already-existing `aws_events_archive`."
---

It continuously and automatically saves real events flowing through an `aws_events_event_bus`, matching an optional filter, so they can be replayed back onto the bus later, real event replay rather than events being lost the moment they're processed once.

    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

## Lookup arguments

<ResponseField name="event_source_arn" type="string">
  The real Amazon Resource Name (ARN) of the event source this object was derived from. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="name_prefix" type="string">
  Restricts results to objects whose name starts with this prefix. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="state" type="string">
  The real, current state of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="archives" type="list(object)">
  The real EventBridge archives included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

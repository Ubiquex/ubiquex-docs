---
title: "aws_events_rule"
description: "`data_aws_events_rule` looks up a real, already-existing `aws_events_rule`."
---

It matches real events flowing through an `aws_events_event_bus` against a defined pattern, or fires on a schedule, and routes matching events to one or more real targets, a Lambda function, an SQS queue, a Step Functions state machine.

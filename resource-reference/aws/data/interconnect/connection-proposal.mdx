---
title: "aws_interconnect_connection_proposal"
description: "`data_aws_interconnect_connection_proposal` looks up a real, already-existing `aws_interconnect_connection`."
---

It (AWS::DirectConnect::Interconnect) is a real, physical connection, over standard Ethernet fiber, between an AWS Direct Connect Partner's own network and a Direct Connect location, that the partner uses to provision and resell hosted Direct Connect connections to their own customers, rather than each customer needing a direct physical link to AWS themselves.

---
title: "aws_sqs_queues"
description: "`data_aws_sqs_queues` looks up a real, already-existing `aws_sqs_queue`: Amazon SQS is a fully managed message queue."
---

`aws_sqs_queue` creates and configures one, standard or FIFO, with a real, typed binding in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/sqs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sqs_queues"})

    		ubx.Data(sqs.Queues, "example", sqs.QueuesConfig{
    			MaxResults:      1,
    			QueueNamePrefix: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.sqs import Queues, QueuesConfig

    def describe():
        ubx.intent("look up aws_sqs_queues")

        ubx.data(Queues, "example", QueuesConfig(
            max_results=1,
            queue_name_prefix="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="queue_name_prefix" type="string">
  The real S3 key prefix used for the queue name. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="queue_urls" type="list(string)">
  The real, resolvable URLs of the queues included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_sqs_queue_url"
description: "`data_aws_sqs_queue_url` looks up a real, already-existing `aws_sqs_queue`: Amazon SQS is a fully managed message queue."
---

`aws_sqs_queue` creates and configures one, standard or FIFO, with a real, typed binding in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/sqs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sqs_queue_url"})

    		ubx.Data(sqs.QueueUrl, "example", sqs.QueueUrlConfig{
    			QueueName:              "example-queue-name",
    			QueueOwnerAwsaccountId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { QueueUrl } from "@ubx/sdk-aws/aws/data/sqs/queue_url";

    export default stack("example", () => {
      intent({ summary: "look up aws_sqs_queue_url" });

      data(QueueUrl, "example", {
        queueName: "example-queue-name",
        queueOwnerAwsaccountId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.sqs import QueueUrl, QueueUrlConfig

    def describe():
        ubx.intent("look up aws_sqs_queue_url")

        ubx.data(QueueUrl, "example", QueueUrlConfig(
            queue_name="example-queue-name",
            queue_owner_awsaccount_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="queue_name" type="string" required>
  The real name of the queue this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="queue_owner_awsaccount_id" type="string">
  The real, unique identifier of the queue owner awsaccount this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="queue_url" type="string">
  The real, resolvable URL of the queue this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

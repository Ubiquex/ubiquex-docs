---
title: "aws_cloud9_environments"
description: "`data_aws_cloud9_environments` looks up a real, already-existing `aws_cloud9_environment_ec2`."
---

It provisions an EC2-backed Cloud9 IDE environment, a browser-based development environment with a real EC2 instance behind it. AWS Cloud9 is no longer available to new customers as of July 25, 2024; AWS recommends AWS IDE Toolkits and AWS CloudShell going forward, with existing Cloud9 customers able to continue using the service as normal.

---
title: "aws_networkmanager_link_associations"
description: "`data_aws_networkmanager_link_associations` looks up a real, already-existing `aws_network_manager_link_association`."
---

It associates a real `aws_network_manager_link` with a specific device in an `aws_network_manager_global_network`, the resource that actually attaches that network connection to a device in Network Manager's own topology.

title: "aws_networkmanager_core_networks"
description: "`data_aws_networkmanager_core_networks` looks up a real, already-existing `aws_network_manager_core_network`."

It creates a real, centrally managed global network backbone, the core resource behind AWS Cloud WAN, that VPCs, Direct Connect gateways, and Site-to-Site VPNs attach to and route through.

---
title: "aws_networkmanager_customer_gateway_associations"
description: "`data_aws_networkmanager_customer_gateway_associations` looks up a real, already-existing `aws_network_manager_customer_gateway_association`."
---

It associates a real `aws_customer_gateway` with a device and site in an `aws_network_manager_global_network`, so Network Manager can represent that on-premises VPN endpoint in its own topology.

---
title: "aws_networkmanager_connect_peers"
description: "`data_aws_networkmanager_connect_peers` looks up a real, already-existing `aws_network_manager_connect_peer`."
---

It establishes a real BGP peering session over an `aws_network_manager_connect_attachment`, exchanging routes between the core network and an external or on-premises device.

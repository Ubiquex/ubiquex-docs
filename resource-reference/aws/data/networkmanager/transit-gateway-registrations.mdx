---
title: "aws_networkmanager_transit_gateway_registrations"
description: "`data_aws_networkmanager_transit_gateway_registrations` looks up a real, already-existing `aws_network_manager_transit_gateway_registration`."
---

It registers a real, existing EC2 Transit Gateway with an `aws_network_manager_global_network`, so Network Manager can represent and monitor it alongside an organization's other network infrastructure.

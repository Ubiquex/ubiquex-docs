## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_blueprints"})

    		ubx.Data(lightsail.Blueprints, "example", lightsail.BlueprintsConfig{
    			AppCategory:     "example",
    			IncludeInactive: true,
    			PageToken:       "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="app_category" type="string">
  The real category of the app this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="include_inactive" type="bool">
  Whether inactive objects are included in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="blueprints" type="list(object)">
  The real blueprints included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_page_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_lightsail_alarms"
description: "`data_aws_lightsail_alarms` looks up a real, already-existing `aws_lightsail_alarm`."
---

It creates a real CloudWatch-backed alarm scoped to a single Lightsail resource, an instance, database, distribution, or load balancer, notifying when one of that resource's own metrics crosses a threshold.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_alarms"})

    		ubx.Data(lightsail.Alarms, "example", lightsail.AlarmsConfig{
    			AlarmName:             "example-alarm-name",
    			MonitoredResourceName: "example-monitored-resource-name",
    			PageToken:             "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="alarm_name" type="string">
  The real name of the alarm this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="monitored_resource_name" type="string">
  The real name of the monitored resource this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

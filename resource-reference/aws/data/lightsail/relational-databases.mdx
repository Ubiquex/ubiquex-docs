---
title: "aws_lightsail_relational_databases"
description: "`data_aws_lightsail_relational_databases` looks up a real, already-existing `aws_lightsail_database`."
---

It creates a real managed relational database, MySQL or PostgreSQL, at Lightsail's simplified, flat-rate pricing tier, optionally with a High Availability option that runs a standby copy in a second Availability Zone.

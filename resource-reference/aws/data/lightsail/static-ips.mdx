---
title: "aws_lightsail_static_ips"
description: "`data_aws_lightsail_static_ips` looks up a real, already-existing `aws_lightsail_static_ip`."
---

It allocates a real static public IP address that can be attached to a Lightsail instance, keeping the instance reachable at a fixed address across stops, starts, and replacements.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_static_ips"})

    		ubx.Data(lightsail.StaticIps, "example", lightsail.StaticIpsConfig{
    			PageToken: "example",
    		})
    	}))
    }
    ```

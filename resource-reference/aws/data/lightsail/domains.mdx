---
title: "aws_lightsail_domains"
description: "`data_aws_lightsail_domains` looks up a real, already-existing `aws_lightsail_domain`."
---

It creates a real DNS zone within Lightsail for a registered domain, letting its DNS records be managed alongside other Lightsail resources rather than in Route 53 directly.

## Example

    // ubx sdk gen --only aws --lang go --out ./local-sdk

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

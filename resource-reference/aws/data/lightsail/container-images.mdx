---
title: "aws_lightsail_container_images"
description: "`data_aws_lightsail_container_images` looks up a real, already-existing `aws_lightsail_container`."
---

It creates a real Lightsail Container Service, a managed environment that deploys and runs containerized applications, images pushed via Docker, without the operational surface of a full ECS or EKS cluster.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_container_images"})

    		ubx.Data(lightsail.ContainerImages, "example", lightsail.ContainerImagesConfig{
    			ServiceName: "example-service-name",
    		})
    	}))
    }
    ```

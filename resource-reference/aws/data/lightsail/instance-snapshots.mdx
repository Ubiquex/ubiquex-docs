---
title: "aws_lightsail_instance_snapshots"
description: "`data_aws_lightsail_instance_snapshots` looks up a real, already-existing `aws_lightsail_instance_snapshot`."
---

It creates a real point-in-time snapshot of an `aws_lightsail_instance`, including its attached disks, which can later be used to launch a new instance with the same state.

---
title: "aws_lightsail_load_balancer_metric_data"
description: "`data_aws_lightsail_load_balancer_metric_data` looks up a real, already-existing `aws_lightsail_load_balancer`."
---

It creates a real load balancer that distributes incoming traffic across multiple Lightsail instances, Lightsail's own simplified counterpart to an Elastic Load Balancing load balancer.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_load_balancer_metric_data"})

    		ubx.Data(lightsail.LoadBalancerMetricData, "example", lightsail.LoadBalancerMetricDataConfig{
    			EndTime:          "example",

    			Period:           1,
    			StartTime:        "example",

    		})
    	}))
    }

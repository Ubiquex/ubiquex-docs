---
title: "aws_lightsail_disk_snapshots"
description: "`data_aws_lightsail_disk_snapshots` looks up a real, already-existing `aws_lightsail_disk_snapshot`."
---

It creates a real point-in-time snapshot of an `aws_lightsail_disk`, which can later be used to create a new disk with the same data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_disk_snapshots"})

    		ubx.Data(lightsail.DiskSnapshots, "example", lightsail.DiskSnapshotsConfig{
    			PageToken: "example",
    		})
    	}))
    }
    ```

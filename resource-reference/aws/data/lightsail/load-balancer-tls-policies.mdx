---
title: "aws_lightsail_load_balancer_tls_policies"
description: "`data_aws_lightsail_load_balancer_tls_policies` looks up a real, already-existing `aws_lightsail_load_balancer_tls_certificate`."
---

It provisions a real TLS certificate attached to an `aws_lightsail_load_balancer`, so traffic reaching the load balancer over HTTPS terminates against a validated certificate.

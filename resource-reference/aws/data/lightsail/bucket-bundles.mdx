---
title: "aws_lightsail_bucket_bundles"
description: "`data_aws_lightsail_bucket_bundles` looks up a real, already-existing `aws_lightsail_bucket`."
---

It creates a real Lightsail object storage bucket, built on S3, for storing files at Lightsail's simplified, predictable-pricing tier rather than through the full S3 console.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_bucket_bundles"})

    		ubx.Data(lightsail.BucketBundles, "example", lightsail.BucketBundlesConfig{
    			IncludeInactive: true,
    		})
    	}))
    }
    ```

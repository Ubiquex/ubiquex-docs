---
title: "aws_lightsail_bucket_metric_data"
description: "`data_aws_lightsail_bucket_metric_data` looks up a real, already-existing `aws_lightsail_bucket`."
---

It creates a real Lightsail object storage bucket, built on S3, for storing files at Lightsail's simplified, predictable-pricing tier rather than through the full S3 console.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_bucket_metric_data"})

    		ubx.Data(lightsail.BucketMetricData, "example", lightsail.BucketMetricDataConfig{
    			BucketName: "example-bucket-name",
    			EndTime:    "example",
    			MetricName: "example-metric-name",
    			Period:     1,
    			StartTime:  "example",
    			Statistics: []string{"example"},
    			Unit:       "example",
    		})
    	}))
    }
    ```

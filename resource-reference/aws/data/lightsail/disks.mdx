---
title: "aws_lightsail_disks"
description: "`data_aws_lightsail_disks` looks up a real, already-existing `aws_lightsail_disk`."
---

It creates a real, SSD-based block storage volume that can be attached to a Lightsail instance for additional or persistent storage beyond the instance's own bundled disk.

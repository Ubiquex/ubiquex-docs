---
title: "aws_lightsail_instance_state"
description: "`data_aws_lightsail_instance_state` looks up a real, already-existing `aws_lightsail_instance`."
---

It creates a real virtual private server, a bundled combination of compute, storage, and a fixed data transfer allowance, at Lightsail's simplified, predictable monthly pricing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lightsail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/lightsail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lightsail_instance_state"})

    		ubx.Data(lightsail.InstanceState, "example", lightsail.InstanceStateConfig{
    			InstanceName: "example-instance-name",
    		})
    	}))
    }
    ```
  </Tab>

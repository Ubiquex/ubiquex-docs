`aws_kafka_replicators` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    package main

    import (
    	kafka "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kafka"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kafka_replicators"})

    		ubx.Data(kafka.Replicators, "example", kafka.ReplicatorsConfig{
    			MaxResults:           1,
    			ReplicatorNameFilter: "example",
    		})
    	}))
    }

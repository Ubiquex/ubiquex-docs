## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesis "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kinesis"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kinesis_shards"})

    		ubx.Data(kinesis.Shards, "example", kinesis.ShardsConfig{
    			ExclusiveStartShardId:   "example",
    			MaxResults:              1,
    			ShardFilter:             map[string]any{"type": "example"},
    			StreamArn:               "arn:aws:iam::123456789012:policy/example",
    			StreamCreationTimestamp: "example",
    			StreamId:                "example",
    			StreamName:              "example-stream-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="exclusive_start_shard_id" type="string">
  The real, unique identifier of the exclusive start shard this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

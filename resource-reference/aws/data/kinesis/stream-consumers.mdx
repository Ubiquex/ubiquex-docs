---
title: "aws_kinesis_stream_consumers"
description: "`data_aws_kinesis_stream_consumers` looks up a real, already-existing `aws_kinesis_stream_consumer`."
---

It registers a real dedicated-throughput consumer on an `aws_kinesis_stream` using enhanced fan-out, so this one consumer gets its own 2 MB/sec-per-shard read pipe instead of sharing the stream's default throughput with every other reader.

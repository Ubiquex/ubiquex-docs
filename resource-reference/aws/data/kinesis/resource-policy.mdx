---
title: "aws_kinesis_resource_policy"
description: "`data_aws_kinesis_resource_policy` looks up a real, already-existing `aws_kinesis_resource_policy`."
---

It attaches a real resource-based access policy to an `aws_kinesis_stream`, controlling which principals, including from other accounts, can read from or write to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesis "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kinesis"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kinesis_resource_policy"})

    		ubx.Data(kinesis.ResourcePolicy, "example", kinesis.ResourcePolicyConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			StreamId:    "example",
    		})
    	}))
    }
    ```
  </Tab>

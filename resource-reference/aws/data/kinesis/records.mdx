## Example

    package main

    import (
    	kinesis "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kinesis"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kinesis_records"})

    			ShardIterator: "example",
    			Limit:         1,
    			StreamArn:     "arn:aws:iam::123456789012:policy/example",
    			StreamId:      "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="shard_iterator" type="string" required>
  An opaque iterator identifying a real position within a Kinesis shard. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="stream_arn" type="string">
  The real Amazon Resource Name (ARN) of the stream this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stream_id" type="string">
  The real, unique identifier of the stream this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="child_shards" type="list(object)">
  The real Kinesis child shards included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="millis_behind_latest" type="number">
  The real number of milliseconds this consumer is behind the latest record. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_shard_iterator" type="string">
  An opaque iterator identifying the next real position within the Kinesis shard. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="records" type="list(object)">
  The real records included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

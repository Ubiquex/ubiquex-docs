`aws_kinesis_records` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesis "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kinesis"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kinesis_records"})

    		ubx.Data(kinesis.Records, "example", kinesis.RecordsConfig{
    			ShardIterator: "example",
    			Limit:         1,
    			StreamArn:     "arn:aws:iam::123456789012:policy/example",
    			StreamId:      "example",
    		})
    	}))
    }
    ```

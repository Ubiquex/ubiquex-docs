---
title: "aws_kinesis_stream_consumer"
description: "`data_aws_kinesis_stream_consumer` looks up a real, already-existing `aws_kinesis_stream_consumer`."
---

It registers a real dedicated-throughput consumer on an `aws_kinesis_stream` using enhanced fan-out, so this one consumer gets its own 2 MB/sec-per-shard read pipe instead of sharing the stream's default throughput with every other reader.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesis "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kinesis"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kinesis_stream_consumer"})

    		ubx.Data(kinesis.StreamConsumer, "example", kinesis.StreamConsumerConfig{
    			ConsumerArn:  "arn:aws:iam::123456789012:policy/example",
    			ConsumerName: "example-consumer-name",
    			StreamArn:    "arn:aws:iam::123456789012:policy/example",
    			StreamId:     "example",
    		})
    	}))
    }
    ```

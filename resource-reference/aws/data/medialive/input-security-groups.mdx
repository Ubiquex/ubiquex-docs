`aws_medialive_input_security_groups` looks up a real MediaLive input security group, an allow list of CIDR ranges permitted to push into a MediaLive input.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	medialive "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/medialive"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_medialive_input_security_groups"})

    		ubx.Data(medialive.InputSecurityGroups, "example", medialive.InputSecurityGroupsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>

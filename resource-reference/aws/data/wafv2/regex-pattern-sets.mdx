---
title: "aws_wafv2_regex_pattern_sets"
description: "`data_aws_wafv2_regex_pattern_sets` looks up a real, already-existing `aws_wafv2_regex_pattern_set`."
---

It defines a real set of regular expressions that an `aws_wafv2_rule_group` or `aws_wafv2_web_acl` rule can match a request part against.

---
title: "aws_wafv2_ipsets"
description: "`data_aws_wafv2_ipsets` looks up a real, already-existing `aws_wafv2_ipset`."
---

It defines a real set of IP addresses or CIDR ranges that an `aws_wafv2_rule_group` or `aws_wafv2_web_acl` rule can match against, AWF WAFv2's current, actively developed counterpart to the deprecated `aws_waf_ipset`/`aws_wafregional_ipset`.

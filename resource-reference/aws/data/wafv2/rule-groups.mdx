---
title: "aws_wafv2_rule_groups"
description: "`data_aws_wafv2_rule_groups` looks up a real, already-existing `aws_wafv2_rule_group`."
---

It defines a real, reusable, named set of WAFv2 rules that can be referenced from one or more `aws_wafv2_web_acl`s, so the same rule logic doesn't have to be redefined in every ACL that needs it.

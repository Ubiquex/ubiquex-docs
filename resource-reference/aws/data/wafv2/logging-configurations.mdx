---
title: "aws_wafv2_logging_configurations"
description: "`data_aws_wafv2_logging_configurations` looks up a real, already-existing `aws_wafv2_logging_configuration`."
---

It streams a real log of every request an `aws_wafv2_web_acl` evaluates, along with which rule matched, to a CloudWatch Logs group, S3 bucket, or Firehose delivery stream.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wafv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/wafv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_wafv2_logging_configurations"})

    		ubx.Data(wafv2.LoggingConfigurations, "example", wafv2.LoggingConfigurationsConfig{
    			Scope:    "example",
    			Limit:    1,
    			LogScope: "example",
    		})
    	}))
    }
    ```

---
title: "aws_wafv2_web_acls"
description: "`data_aws_wafv2_web_acls` looks up a real, already-existing `aws_wafv2_web_acl`."
---

It creates a real, top-level web ACL under AWS WAFv2, evaluating its own inline rules and any referenced `aws_wafv2_rule_group`s against requests to a CloudFront distribution, ALB, API Gateway, AppSync API, Cognito user pool, App Runner service, or Verified Access instance, one unified resource type across scopes that AWS WAF Classic split between global and Regional.

---
title: "aws_wafv2_logging_configuration"
description: "`data_aws_wafv2_logging_configuration` looks up a real, already-existing `aws_wafv2_logging_configuration`."
---

It streams a real log of every request an `aws_wafv2_web_acl` evaluates, along with which rule matched, to a CloudWatch Logs group, S3 bucket, or Firehose delivery stream.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wafv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/wafv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_wafv2_logging_configuration"})

    		ubx.Data(wafv2.LoggingConfiguration, "example", wafv2.LoggingConfigurationConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			LogScope:    "example",
    			LogType:     "example",
    		})
    	}))
    }
    ```

  &lt;p&gt;Defines an association between logging destinations and a web ACL resource, for logging from WAF. As part of the association, you can specify parts of the standard logging fields to keep out of the logs and you can specify filters so that you log only a subset of the logging records. &lt;/p&gt; &lt;p&gt;If you configure data protection for the web ACL, the protection applies to the data that WAF sends to the logs. &lt;/p&gt; &lt;note&gt; &lt;p&gt;You can define one logging destination per web ACL.&lt;/p&gt; &lt;/note&gt; &lt;p&gt;You can access information about the traffic that WAF inspects using the following steps:&lt;/p&gt; &lt;ol&gt; &lt;li&gt; &lt;p&gt;Create your logging destination. You can use an Amazon CloudWatch Logs log group, an Amazon Simple Storage Service (Amazon S3) bucket, or an Amazon Kinesis Data Firehose. &lt;/p&gt; &lt;p&gt;The name that you give the destination must start with &lt;code&gt;aws-waf-logs-&lt;/code&gt;. Depending on the type of destination, you might need to configure additional settings or permissions. &lt;/p&gt; &lt;p&gt;For configuration requirements and pricing information for each destination type, see &lt;a href="https://docs.aws.amazon.com/waf/latest/developerguide/logging.html"&gt;Logging web ACL traffic&lt;/a&gt; in the &lt;i&gt;WAF Developer Guide&lt;/i&gt;.&lt;/p&gt; &lt;/li&gt; &lt;li&gt; &lt;p&gt;Associate your logging destination to your web ACL using a &lt;code&gt;PutLoggingConfiguration&lt;/code&gt; request.&lt;/p&gt; &lt;/li&gt; &lt;/ol&gt; &lt;p&gt;When you successfully enable logging using a &lt;code&gt;PutLoggingConfiguration&lt;/code&gt; request, WAF creates an additional role or policy that is required to write logs to the logging destination. For an Amazon CloudWatch Logs log group, WAF creates a resource policy on the log group. For an Amazon S3 bucket, WAF creates a bucket policy. For an Amazon Kinesis Data Firehose, WAF creates a service-linked role.&lt;/p&gt; &lt;p&gt;For additional information about web ACL logging, see &lt;a href="https://docs.aws.amazon.com/waf/latest/developerguide/logging.html"&gt;Logging web ACL traffic information&lt;/a&gt; in the &lt;i&gt;WAF Developer Guide&lt;/i&gt;.&lt;/p&gt; Returned by the lookup.

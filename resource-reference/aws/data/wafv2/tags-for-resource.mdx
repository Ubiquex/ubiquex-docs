## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wafv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/wafv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_wafv2_tags_for_resource"})

    		ubx.Data(wafv2.TagsForResource, "example", wafv2.TagsForResourceConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:       1,
    		})
    	}))
    }
    ```

Typically, the tag key represents a category, such as "environment", and the tag value represents a specific value within that category, such as "test," "development," or "production". Or you might set the tag key to "customer" and the value to the customer name or ID.

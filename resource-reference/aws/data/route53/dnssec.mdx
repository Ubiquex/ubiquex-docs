---
title: "aws_route53_dnssec"
description: "`data_aws_route53_dnssec` looks up a real, already-existing `aws_route53_dnssec`."
---

It enables DNSSEC signing for an `aws_route53_hosted_zone`, the resource that actually turns on cryptographic signing of that zone's DNS responses so resolvers can verify they haven't been tampered with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_route53_dnssec"})

    		ubx.Data(route53.Dnssec, "example", route53.DnssecConfig{
    			HostedZoneId: "example",
    		})
    	}))
    }
    ```

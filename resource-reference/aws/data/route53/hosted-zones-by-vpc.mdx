---
title: "aws_route53_hosted_zones_by_vpc"
description: "`data_aws_route53_hosted_zones_by_vpc` looks up a real, already-existing `aws_route53_hosted_zone`."
---

It creates a real container for DNS records for a domain, public (resolvable on the internet) or private (resolvable only inside associated VPCs), that `aws_route53_record_set`s are created within.

## Lookup arguments

<ResponseField name="vpcid" type="string" required>
  &lt;p&gt;(Private hosted zones only) The ID of an Amazon VPC. &lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="vpcregion" type="string" required>
  The real AWS region this VPC is located in. **(AI-inferred)** Required lookup argument.
</ResponseField>

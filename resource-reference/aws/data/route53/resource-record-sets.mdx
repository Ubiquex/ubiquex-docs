---
title: "aws_route53_resource_record_sets"
description: "`data_aws_route53_resource_record_sets` looks up a real, already-existing `aws_route53_record_set`."
---

It creates a real DNS record, A, CNAME, MX, and more, including alias records that point at other AWS resources, within an `aws_route53_hosted_zone`.

## Example

<Tabs>
  <Tab title="Go">
    ```go

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/route53"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_route53_resource_record_sets"})

    		ubx.Data(route53.ResourceRecordSets, "example", route53.ResourceRecordSetsConfig{
    			HostedZoneId:          "example",
    			StartRecordIdentifier: "example",
    			StartRecordName:       "example-start-record-name",
    			StartRecordType:       "example",
    		})
    	}))
    }
    ```

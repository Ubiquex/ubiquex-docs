---
title: "aws_route53_health_check_status"
description: "`data_aws_route53_health_check_status` looks up a real, already-existing `aws_route53_health_check`."
---

It creates a real, recurring health check against an endpoint, an IP address, domain, or CloudWatch alarm, that DNS failover routing and `aws_route53_record_set` health-check associations rely on to detect an unhealthy target.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_route53_health_check_status"})

    		ubx.Data(route53.HealthCheckStatus, "example", route53.HealthCheckStatusConfig{
    			HealthCheckId: "example",
    		})
    	}))
    }
    ```

---
title: "aws_route53_hosted_zones_by_name"
description: "`data_aws_route53_hosted_zones_by_name` looks up a real, already-existing `aws_route53_hosted_zone`."
---

It creates a real container for DNS records for a domain, public (resolvable on the internet) or private (resolvable only inside associated VPCs), that `aws_route53_record_set`s are created within.

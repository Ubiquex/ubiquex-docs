title: "aws_route53_query_logging_configs"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/route53"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_route53_query_logging_configs"})

    		ubx.Data(route53.QueryLoggingConfigs, "example", route53.QueryLoggingConfigsConfig{
    			HostedZoneId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="hosted_zone_id" type="string">
  The real, unique identifier of the Route 53 hosted zone this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="query_logging_configs" type="list(object)">
  The real Route 53 Resolver query logging configurations included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

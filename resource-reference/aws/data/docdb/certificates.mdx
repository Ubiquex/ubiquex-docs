## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	docdb "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/docdb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_docdb_certificates"})

    		ubx.Data(docdb.Certificates, "example", docdb.CertificatesConfig{
    			CertificateIdentifier: "example",
    			Filters:               []map[string]any{{"name": "example-name"}},
    			MaxRecords:            1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="certificate_identifier" type="string">
  The real, unique identifier of the certificate this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filters" type="list(object)">
  Real filter criteria restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

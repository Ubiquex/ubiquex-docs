---
title: "aws_sms_voice_sender_ids"
description: "`data_aws_sms_voice_sender_ids` looks up a real, already-existing `aws_smsvoice_sender_id`."
---

It registers a real, alphanumeric sender ID, a recognizable brand name shown as the message sender instead of a phone number, for use in countries that support it, under an `aws_smsvoice_configuration_set`.

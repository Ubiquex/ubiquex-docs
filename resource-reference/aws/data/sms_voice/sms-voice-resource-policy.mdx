---
title: "aws_sms_voice_resource_policy"
description: "`data_aws_sms_voice_resource_policy` looks up a real, already-existing `aws_smsvoice_resource_policy`."
---

It attaches a real resource-based access policy to an `aws_smsvoice_phone_number` or pool, controlling which principals, including from other accounts, can send through it.

## Example

<Tabs>
  <Tab title="Go">

    ```go
    package main

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sms_voice_resource_policy"})

    		ubx.Data(sms_voice.SmsVoiceResourcePolicy, "example", sms_voice.SmsVoiceResourcePolicyConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

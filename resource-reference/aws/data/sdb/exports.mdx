## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sdb "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/sdb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sdb_exports"})

    		ubx.Data(sdb.Exports, "example", sdb.ExportsConfig{
    			DomainName: "example-domain-name",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.sdb import Exports, ExportsConfig

    def describe():
        ubx.intent("look up aws_sdb_exports")

        ubx.data(Exports, "example", ExportsConfig(
            domain_name="example-domain-name",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="domain_name" type="string">
  The domain name that uniquely identifies a SimpleDB domain within your account. Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single response. Note: The actual number of results returned might be less than the specified maxResults. Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="export_summaries" type="list(object)">
  List of export summaries containing export ARN, status, creation timestamp, and associated domain name. Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  A pagination token used for retrieving subsequent pages of results. Returned by the lookup.
</ResponseField>

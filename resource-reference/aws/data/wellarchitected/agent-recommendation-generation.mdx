`aws_wellarchitected_agent_recommendation_generation` reads the real, current status of a Well-Architected generative-AI agent recommendation generation run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wellarchitected "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/wellarchitected"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_wellarchitected_agent_recommendation_generation"})

    		ubx.Data(wellarchitected.AgentRecommendationGeneration, "example", wellarchitected.AgentRecommendationGenerationConfig{
    			GenerationId: "example",
    			ProfileArn:   "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

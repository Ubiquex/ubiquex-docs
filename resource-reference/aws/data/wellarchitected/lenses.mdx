`aws_wellarchitected_lenses` looks up a real Well-Architected lens, a set of best-practice questions (the core framework or a custom lens) applied to a workload review.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	wellarchitected "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/wellarchitected"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_wellarchitected_lenses"})

    		ubx.Data(wellarchitected.Lenses, "example", wellarchitected.LensesConfig{
    			LensName:   "example-lens-name",
    			LensStatus: "example",
    			LensType:   "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="lens_name" type="string">
  &lt;p&gt;The full name of the lens.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="lens_status" type="string">
  The real, current status of the lens this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="lens_type" type="string">
  The real, discriminating type of the lens this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt;The maximum number of results to return for this request.&lt;/p&gt; Optional lookup argument.
</ResponseField>

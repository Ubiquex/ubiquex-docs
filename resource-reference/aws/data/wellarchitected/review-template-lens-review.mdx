---
title: "aws_wellarchitected_review_template_lens_review"
description: "`data_aws_wellarchitected_review_template_lens_review` looks up a real, already-existing `aws_well_architected_review_template`."
---

It defines a real, reusable review configuration, which lenses and pillars to include, that can be applied to an `aws_well_architected_workload`, so a consistent review structure can be reused across many workloads instead of configured individually each time.

## Lookup arguments

<ResponseField name="lens_alias" type="string" required>
  &lt;p&gt;The alias of the lens.&lt;/p&gt; &lt;p&gt;For Amazon Web Services official lenses, this is either the lens alias, such as &lt;code&gt;serverless&lt;/code&gt;, or the lens ARN, such as &lt;code&gt;arn:aws:wellarchitected:us-east-1::lens/serverless&lt;/code&gt;. Note that some operations (such as ExportLens and CreateLensShare) are not permitted on Amazon Web Services official lenses.&lt;/p&gt; &lt;p&gt;For custom lenses, this is the lens ARN, such as &lt;code&gt;arn:aws:wellarchitected:us-west-2:123456789012:lens/0123456789abcdef01234567890abcdef&lt;/code&gt;. &lt;/p&gt; &lt;p&gt;Each lens is identified by its &lt;a&gt;LensSummary$LensAlias&lt;/a&gt;.&lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="template_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the template this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "aws_eks_clusters"
description: "`data_aws_eks_clusters` looks up a real, already-existing `aws_eks_cluster`."
---

It runs the real, managed Kubernetes control plane, API server, etcd, scheduler, that every `aws_eks_nodegroup` and Fargate profile in an EKS deployment runs its actual workloads against.

## Example

<Tabs>

    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_clusters"})

    		ubx.Data(eks.Clusters, "example", eks.ClustersConfig{
    			Include:    []string{"example"},
    			MaxResults: 1,
    		})
    	}))
    }
    ```

---
title: "aws_eks_pod_identity_associations"
description: "`data_aws_eks_pod_identity_associations` looks up a real, already-existing `aws_eks_pod_identity_association`."
---

It maps a real IAM role to a Kubernetes service account in an `aws_eks_cluster`, giving pods using that service account automatically rotated, temporary AWS credentials without the OIDC-provider setup IAM roles for service accounts requires.

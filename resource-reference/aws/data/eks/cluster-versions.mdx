---
title: "aws_eks_cluster_versions"
description: "`data_aws_eks_cluster_versions` looks up a real, already-existing `aws_eks_cluster`."
---

It runs the real, managed Kubernetes control plane, API server, etcd, scheduler, that every `aws_eks_nodegroup` and Fargate profile in an EKS deployment runs its actual workloads against.

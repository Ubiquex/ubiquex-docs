---
title: "aws_eks_identity_provider_config"
description: "`data_aws_eks_identity_provider_config` looks up a real, already-existing `aws_eks_identity_provider_config`."
---

It federates an `aws_eks_cluster`'s Kubernetes API with an external OIDC identity provider, letting a caller authenticate to the cluster with their own organization's existing identity system instead of only IAM.

## Example

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/eks"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_identity_provider_config"})

    		ubx.Data(eks.IdentityProviderConfig, "example", eks.IdentityProviderConfigConfig{
    			ClusterName:            "example-cluster-name",
    			IdentityProviderConfig: map[string]any{"name": "example-name", "type": "example"},
    		})
    	}))
    }

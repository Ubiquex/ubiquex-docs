---
title: "aws_eks_nodegroups"
description: "`data_aws_eks_nodegroups` looks up a real, already-existing `aws_eks_nodegroup`."
---

It provisions and manages a real group of EC2 worker nodes, patched and scaled by EKS itself, that join an `aws_eks_cluster` to actually run pods, an alternative to Fargate for workloads that need EC2-level control.

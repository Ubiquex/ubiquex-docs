---
title: "aws_eks_certificate_authorities"
description: "`data_aws_eks_certificate_authorities` looks up a real, already-existing `aws_eks_certificate_authority`."
---

It retrieves a real `aws_eks_cluster`'s own certificate authority data, the trust root a kubeconfig or OIDC-based IAM role trust policy needs to validate the cluster's API server or service account tokens.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_certificate_authorities"})

    		ubx.Data(eks.CertificateAuthorities, "example", eks.CertificateAuthoritiesConfig{
    			ClusterName: "example-cluster-name",
    			MaxResults:  1,
    		})
    	}))
    }
    ```

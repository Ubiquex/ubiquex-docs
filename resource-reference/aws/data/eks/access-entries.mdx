---
title: "aws_eks_access_entries"
description: "`data_aws_eks_access_entries` looks up a real, already-existing `aws_eks_access_entry`."
---

It grants a real IAM principal access to an `aws_eks_cluster`'s Kubernetes API, EKS's own current, native authentication and authorization mechanism that replaced the older aws-auth ConfigMap approach.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_access_entries"})

    		ubx.Data(eks.AccessEntries, "example", eks.AccessEntriesConfig{
    			ClusterName:         "example-cluster-name",
    			AssociatedPolicyArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults:          1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="associated_policy_arn" type="string">
  The real Amazon Resource Name (ARN) of the associated policy this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="cluster_name" type="string" required>
  The real name of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

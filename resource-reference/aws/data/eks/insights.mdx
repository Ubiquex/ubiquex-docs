`aws_eks_insights` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_insights"})

    		ubx.Data(eks.Insights, "example", eks.InsightsConfig{
    			ClusterName: "example-cluster-name",
    			Filter:      map[string]any{"categories": []string{"example"}},
    			MaxResults:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

---
title: "aws_eks_fargate_profiles"
description: "`data_aws_eks_fargate_profiles` looks up a real, already-existing `aws_eks_fargate_profile`."
---

It matches real pods in an `aws_eks_cluster`, by namespace and label selector, to run on Fargate rather than an `aws_eks_nodegroup`'s own EC2 worker nodes, no node to provision or patch for the pods it covers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_fargate_profiles"})

    		ubx.Data(eks.FargateProfiles, "example", eks.FargateProfilesConfig{
    			ClusterName: "example-cluster-name",
    			MaxResults:  1,
    		})
    	}))
    }
    ```

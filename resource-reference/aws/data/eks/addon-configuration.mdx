---
title: "aws_eks_addon_configuration"
description: "`data_aws_eks_addon_configuration` looks up a real, already-existing `aws_eks_addon`."
---

It installs and manages a real, EKS-curated operational component, the VPC CNI, CoreDNS, kube-proxy among common ones, on an `aws_eks_cluster`, with its own version tracking and update lifecycle handled by EKS rather than a caller applying manifests and managing upgrades by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	eks "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/eks"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_eks_addon_configuration"})

    		ubx.Data(eks.AddonConfiguration, "example", eks.AddonConfigurationConfig{
    			AddonName:    "example-addon-name",
    			AddonVersion: "example",
    		})
    	}))
    }
    ```

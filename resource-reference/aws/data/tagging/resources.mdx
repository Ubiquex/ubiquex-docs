## Lookup arguments

<ResponseField name="exclude_compliant_resources" type="bool">
  Whether compliant resources are excluded from the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="include_compliance_details" type="bool">
  The real, detailed information about the include compliance. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="resource_arnlist" type="list(string)">
  The real Amazon Resource Names (ARNs) included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="resource_type_filters" type="list(string)">
  Restricts results to these resource types. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="resources_per_page" type="number">
  The real, maximum number of resources to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tag_filters" type="list(object)">
  The real filters applied to the tags in this request. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tags_per_page" type="number">
  The real, maximum number of tags to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "aws_ivschat_logging_configurations"
description: "`data_aws_ivschat_logging_configurations` looks up a real, already-existing `aws_ivschat_logging_configuration`."
---

It streams a real `aws_ivschat_room`'s chat messages to a destination, CloudWatch Logs, Kinesis Data Firehose, or S3, for moderation review or analytics rather than messages existing only transiently in the room.

---
title: "aws_ivschat_rooms"
description: "`data_aws_ivschat_rooms` looks up a real, already-existing `aws_ivschat_room`."
---

It creates a real, managed chat room, typically paired alongside an `aws_ivs_channel`'s live stream, that Amazon IVS Chat handles message fan-out, moderation, and connection scaling for.

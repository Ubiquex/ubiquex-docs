`aws_data_brew_schedule` runs an `aws_data_brew_job` automatically on a real, recurring cadence, so a dataset stays continuously cleaned and transformed rather than requiring a caller to trigger every run by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	data "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own brew schedule"})

    		ubx.Resource(data.BrewSchedule, "example", data.BrewScheduleConfig{
    			CronExpression: "example",
    			Name:           "example",
    			JobNames:       []string{"example"},
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

<ResponseField name="cron_expression" type="string" required>

</ResponseField>

<ResponseField name="job_names" type="list(string)">
  The list of DataBrew job names that this schedule will start when it fires. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of this data brew schedule. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the DataBrew schedule, where each tag consists of a key and an optional value used to categorize and manage the schedule. Optional. **(AI-inferred)**

---
title: "aws_codepipeline_pipeline_state"
description: "`data_aws_codepipeline_pipeline_state` looks up a real, already-existing `aws_code_pipeline_pipeline`."
---

It models the real, automated stages, source, build, test, deploy, that a code change moves through on its way to release, the core, top-level resource every other CodePipeline resource attaches to.

## Lookup arguments

<ResponseField name="client_token" type="string" required>
  A real, caller-supplied token guaranteeing this request's own idempotency. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_id" type="string" required>
  The real, unique identifier of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

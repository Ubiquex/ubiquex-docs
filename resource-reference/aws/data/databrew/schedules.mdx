---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databrew "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/databrew"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_databrew_schedules"})

    		ubx.Data(databrew.Schedules, "example", databrew.SchedulesConfig{
    			JobName:    "example-job-name",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.aws.data.databrew import Schedules, SchedulesConfig

    def describe():
        ubx.intent("look up aws_databrew_schedules")

        ubx.data(Schedules, "example", SchedulesConfig(
            job_name="example-job-name",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="job_name" type="string">
  The real name of the job this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="schedules" type="list(object)">
  The real schedules included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

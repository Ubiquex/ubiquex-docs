## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="thing_name" type="string" required>
  The real name of the AWS IoT thing this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="thing_principal_type" type="string">
  The real, discriminating type of the thing principal this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

</ResponseField>

<ResponseField name="thing_principal_objects" type="list(object)">

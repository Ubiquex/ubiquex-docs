`aws_iot_security_profiles` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iot"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_security_profiles"})

    		ubx.Data(iot.SecurityProfiles, "example", iot.SecurityProfilesConfig{
    			DimensionName: "example-dimension-name",
    			MaxResults:    1,
    			MetricName:    "example-metric-name",
    		})
    	}))
    }

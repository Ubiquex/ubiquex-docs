## Lookup arguments

<ResponseField name="ascending_order" type="bool">
  Whether results are returned in ascending order. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="principal" type="string" required>
  The real IAM principal this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_marker" type="string">

</ResponseField>

<ResponseField name="policies" type="list(object)">
  The real access policies attached to this object. **(AI-inferred)** Returned by the lookup.

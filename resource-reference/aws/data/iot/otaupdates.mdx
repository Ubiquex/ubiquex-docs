## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_otaupdates"})

    		ubx.Data(iot.Otaupdates, "example", iot.OtaupdatesConfig{
    			MaxResults:      1,
    			OtaUpdateStatus: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ota_update_status" type="string">
  The real, current status of the ota update this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="ota_updates" type="list(object)">
  The real AWS IoT over-the-air (OTA) updates included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

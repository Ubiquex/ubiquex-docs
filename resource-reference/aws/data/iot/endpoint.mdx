`aws_iot_endpoint` reads the real, account-specific endpoint address a device connects to for a given IoT Core service (data, credential provider, or Jobs).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_endpoint"})

    		ubx.Data(iot.Endpoint, "example", iot.EndpointConfig{
    			EndpointType: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

    ```python
    import ubx_sdk as ubx
    ```

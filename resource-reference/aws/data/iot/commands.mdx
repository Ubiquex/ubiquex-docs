## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_commands"})

    		ubx.Data(iot.Commands, "example", iot.CommandsConfig{
    			CommandParameterName: "example-command-parameter-name",
    			MaxResults:           1,
    			Namespace:            "example",
    			SortOrder:            "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="command_parameter_name" type="string">
  The real name of the command parameter this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="namespace" type="string">
  The real namespace this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_order" type="string">
  The real order (ascending or descending) results are sorted in. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="commands" type="list(object)">
  The real commands included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

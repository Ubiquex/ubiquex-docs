---
title: "aws_iot_default_authorizer"
description: "`aws_iot_default_authorizer` reads which real custom authorizer is used by default when a device connection doesn't specify one."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_default_authorizer"})

    		ubx.Data(iot.DefaultAuthorizer, "example", iot.DefaultAuthorizerConfig{})
    	}))
    }
    ```

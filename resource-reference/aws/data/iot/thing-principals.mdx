## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_thing_principals"})

    		ubx.Data(iot.ThingPrincipals, "example", iot.ThingPrincipalsConfig{
    			ThingName:  "example-thing-name",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="thing_name" type="string" required>
  The real name of the AWS IoT thing this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="principals" type="list(string)">
  The real IAM principals included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

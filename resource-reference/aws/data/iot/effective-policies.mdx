## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_effective_policies"})

    		ubx.Data(iot.EffectivePolicies, "example", iot.EffectivePoliciesConfig{
    			CognitoIdentityPoolId: "example",
    			Principal:             "example",
    			ThingName:             "example-thing-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="cognito_identity_pool_id" type="string">
  The real, unique identifier of the cognito identity pool this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="principal" type="string">
  The real IAM principal this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="thing_name" type="string">
  The real name of the AWS IoT thing this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="effective_policies" type="list(object)">
  The real effective policies attached to this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

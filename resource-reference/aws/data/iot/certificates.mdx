## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_certificates"})

    		ubx.Data(iot.Certificates, "example", iot.CertificatesConfig{
    			AscendingOrder: true,
    			Marker:         "example",
    			PageSize:       1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="ascending_order" type="bool">
  Whether results are returned in ascending order. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="certificates" type="list(object)">
  The real certificates included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.

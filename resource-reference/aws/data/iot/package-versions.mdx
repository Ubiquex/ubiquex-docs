## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iot_package_versions"})

    		ubx.Data(iot.PackageVersions, "example", iot.PackageVersionsConfig{
    			PackageName: "example-package-name",
    			MaxResults:  1,
    			Status:      "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="package_name" type="string" required>
  The real name of the package this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  The real, current status of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="package_version_summaries" type="list(object)">
  The real, summarized package versions included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

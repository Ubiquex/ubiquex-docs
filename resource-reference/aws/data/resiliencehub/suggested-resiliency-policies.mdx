---
title: "aws_resiliencehub_suggested_resiliency_policies"
description: "`data_aws_resiliencehub_suggested_resiliency_policies` looks up a real, already-existing `aws_resilience_hub_resiliency_policy`."
---

It defines real recovery time and recovery point objectives that an `aws_resilience_hub_app` is assessed against, the target Resilience Hub measures the application's actual architecture against to produce a resiliency score.

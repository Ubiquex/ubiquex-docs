---
title: "aws_resiliencehub_apps"
description: "`data_aws_resiliencehub_apps` looks up a real, already-existing `aws_resilience_hub_app`."
---

It registers a real application in AWS Resilience Hub, its component resources discovered from CloudFormation, Terraform state, or an EKS cluster, that an `aws_resilience_hub_resiliency_policy` is then assessed against.

`aws_data_sync_location_fsx_lustre` registers a real Amazon FSx for Lustre file system as a DataSync transfer endpoint, used for high-performance computing and machine learning workloads that need Lustre's own throughput.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="fsx_filesystem_arn" type="string">
  The Amazon Resource Name (ARN) for the FSx for Lustre file system. Optional.
</ResponseField>

<ResponseField name="security_group_arns" type="list(string)" required>
  The ARNs of the security groups that are to use to configure the FSx for Lustre file system. Required.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  A subdirectory in the location's path. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to apply to the DataSync location for an FSx for Lustre file system, used for identifying and organizing the location. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon FSx for Lustre file system location that is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the FSx for Lustre location that was described. Computed by AWS after `ship`.
</ResponseField>

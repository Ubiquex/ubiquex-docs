---
title: "aws_codeartifact_package_groups"
description: "`data_aws_codeartifact_package_groups` looks up a real, already-existing `aws_code_artifact_package_group`."
---

It applies real origin control and configuration consistently across every package in an `aws_code_artifact_domain` whose name matches the group's pattern, rather than a caller setting the same policy on each individual package by hand.

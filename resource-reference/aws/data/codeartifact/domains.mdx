---
title: "aws_codeartifact_domains"
description: "`data_aws_codeartifact_domains` looks up a real, already-existing `aws_code_artifact_domain`."
---

It is CodeArtifact's top-level grouping for an organization's own package repositories, one production domain typically holding every `aws_code_artifact_repository` a company uses, so packages can be discovered and shared consistently across development teams.

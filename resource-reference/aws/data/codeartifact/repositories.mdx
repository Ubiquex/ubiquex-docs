---
title: "aws_codeartifact_repositories"
description: "`data_aws_codeartifact_repositories` looks up a real, already-existing `aws_code_artifact_repository`."
---

It stores real software packages, polyglot by default, npm, Maven, PyPI, and others in the same repository, inside an `aws_code_artifact_domain`, either published directly or fetched on demand from a connected public repository like npmjs or Maven Central.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codeartifact "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codeartifact"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codeartifact_repositories"})

    		ubx.Data(codeartifact.Repositories, "example", codeartifact.RepositoriesConfig{
    			MaxResults:       1,
    			RepositoryPrefix: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repository_prefix" type="string">
  The real S3 key prefix used for the repository. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="repositories" type="list(object)">
  The real repositories included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_athena_table_metadata"})

    		ubx.Data(athena.TableMetadata, "example", athena.TableMetadataConfig{
    			CatalogName:  "example-catalog-name",
    			DatabaseName: "example-database-name",
    			TableName:    "example-table-name",
    			WorkGroup:    "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="catalog_name" type="string" required>
  The real name of the catalog this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="database_name" type="string" required>
  The real name of the database this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="table_name" type="string" required>
  The real name of the table this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="work_group" type="string">
  The real Amazon Athena workgroup this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_athena_executors"})

    		ubx.Data(athena.Executors, "example", athena.ExecutorsConfig{
    			SessionId:           "example",
    			ExecutorStateFilter: "example",
    			MaxResults:          1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="executor_state_filter" type="string">
  Restricts results to this executor state. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="session_id" type="string" required>
  The real, unique identifier of the session this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="executors_summary" type="list(object)">
  The real, summarized executors. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

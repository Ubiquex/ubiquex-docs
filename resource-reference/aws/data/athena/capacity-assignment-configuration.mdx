## Result properties

<ResponseField name="capacity_assignment_configuration" type="object">
  &lt;p&gt;Assigns Athena workgroups (and hence their queries) to capacity reservations. A capacity reservation can have only one capacity assignment configuration, but the capacity assignment configuration can be made up of multiple individual assignments. Each assignment specifies how Athena queries can consume capacity from the capacity reservation that their workgroup is mapped to.&lt;/p&gt; Returned by the lookup.

---
title: "aws_athena_named_queries"
description: "`data_aws_athena_named_queries` looks up a real, already-existing `aws_athena_named_query`."
---

It saves a real, named SQL query against an `aws_athena_work_group`, for reuse from the console or API instead of re-typing it for every ad hoc analysis.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_athena_named_queries"})

    		ubx.Data(athena.NamedQueries, "example", athena.NamedQueriesConfig{
    			MaxResults: 1,
    			WorkGroup:  "example",
    		})
    	}))
    }
    ```

---
title: "aws_athena_data_catalogs"
description: "`data_aws_athena_data_catalogs` looks up a real, already-existing `aws_athena_data_catalog`."
---

It registers a metadata catalog, the AWS Glue Data Catalog, a Hive metastore, or a federated Lambda-backed source, that Athena queries against to resolve which tables and schemas a SQL query can actually see.

## Example

    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_athena_data_catalogs"})

    		ubx.Data(athena.DataCatalogs, "example", athena.DataCatalogsConfig{
    			MaxResults: 1,
    			WorkGroup:  "example",
    		})
    	}))
    }

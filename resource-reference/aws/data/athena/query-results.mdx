---
title: "aws_athena_query_results"
description: "`data_aws_athena_query_results` looks up a real, already-existing `aws_athena_named_query`."
---

It saves a real, named SQL query against an `aws_athena_work_group`, for reuse from the console or API instead of re-typing it for every ad hoc analysis.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_athena_query_results"})

    		ubx.Data(athena.QueryResults, "example", athena.QueryResultsConfig{
    			QueryExecutionId: "example",
    			MaxResults:       1,
    			QueryResultType:  "example",
    		})
    	}))
    }
    ```

    from ubx.aws.data.athena import QueryResults, QueryResultsConfig

    def describe():
        ubx.intent("look up aws_athena_query_results")

        ubx.data(QueryResults, "example", QueryResultsConfig(
            query_execution_id="example",
            max_results=1,
            query_result_type="example",

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="query_execution_id" type="string" required>
  The real, unique identifier of the query execution this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="query_result_type" type="string">
  The real, discriminating type of the query result this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "aws_athena_capacity_reservations"
description: "`data_aws_athena_capacity_reservations` looks up a real, already-existing `aws_athena_capacity_reservation`."
---

It reserves dedicated Data Processing Units for Athena queries at a fixed price, an alternative to Athena's standard pay-per-data-scanned model, with one or more `aws_athena_work_group`s assigned to the reservation so their queries run on guaranteed capacity instead of queuing behind other tenants.

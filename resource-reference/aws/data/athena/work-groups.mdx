---
title: "aws_athena_work_groups"
description: "`data_aws_athena_work_groups` looks up a real, already-existing `aws_athena_work_group`."
---

It isolates a set of Athena users, teams, or applications, with its own query history, data usage limits, and encryption settings, so cost and access can be tracked and controlled per workgroup rather than pooled across every Athena user in the account.

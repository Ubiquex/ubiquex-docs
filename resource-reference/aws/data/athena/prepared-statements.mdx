---
title: "aws_athena_prepared_statements"
description: "`data_aws_athena_prepared_statements` looks up a real, already-existing `aws_athena_prepared_statement`."
---

It saves a real, parameterized SQL statement under an `aws_athena_work_group`, so the same query shape can be executed repeatedly with different real parameter values substituted in.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	athena "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/athena"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_athena_prepared_statements"})

    		ubx.Data(athena.PreparedStatements, "example", athena.PreparedStatementsConfig{
    			WorkGroup:  "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

    from ubx.aws.data.athena import PreparedStatements, PreparedStatementsConfig

    def describe():
        ubx.intent("look up aws_athena_prepared_statements")

        ubx.data(PreparedStatements, "example", PreparedStatementsConfig(
            work_group="example",
            max_results=1,

    if __name__ == "__main__":

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="work_group" type="string" required>
  The real Amazon Athena workgroup this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="prepared_statements" type="list(object)">
  The real prepared SQL statements included in this result. **(AI-inferred)** Returned by the lookup.

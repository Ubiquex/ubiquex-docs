`aws_grafana_versions` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	grafana "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/grafana"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_grafana_versions"})

    		ubx.Data(grafana.Versions, "example", grafana.VersionsConfig{
    			MaxResults:  1,
    			WorkspaceId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

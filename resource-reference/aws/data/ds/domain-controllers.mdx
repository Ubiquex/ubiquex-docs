## Lookup arguments

<ResponseField name="directory_id" type="string" required>
  The real, unique identifier of the directory this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="domain_controller_ids" type="list(string)">
  The real, unique identifiers of the domain controllers this request is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="domain_controllers" type="list(object)">
  The real Directory Service domain controllers included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

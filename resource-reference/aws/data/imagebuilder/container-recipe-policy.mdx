---
title: "aws_imagebuilder_container_recipe_policy"
description: "`data_aws_imagebuilder_container_recipe_policy` looks up a real, already-existing `aws_image_builder_container_recipe`."
---

It defines the real base container image and the ordered build and test components applied to it, that an `aws_image_builder_image_pipeline` runs to actually produce a new container image, the container-image counterpart to `aws_image_builder_image_recipe`.

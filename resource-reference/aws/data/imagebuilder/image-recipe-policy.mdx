---
title: "aws_imagebuilder_image_recipe_policy"
description: "`data_aws_imagebuilder_image_recipe_policy` looks up a real, already-existing `aws_image_builder_image_recipe`."
---

It defines the real base AMI and the ordered build and test components applied to it, that an `aws_image_builder_image_pipeline` runs to actually produce a new, hardened, updated AMI.

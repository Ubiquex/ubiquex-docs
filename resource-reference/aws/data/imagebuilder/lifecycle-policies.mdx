---
title: "aws_imagebuilder_lifecycle_policies"
description: "`data_aws_imagebuilder_lifecycle_policies` looks up a real, already-existing `aws_image_builder_lifecycle_policy`."
---

It automatically deprecates or deletes an `aws_image_builder_image_pipeline`'s older real output images on a defined schedule, real cleanup that keeps old, unpatched AMIs from accumulating indefinitely.

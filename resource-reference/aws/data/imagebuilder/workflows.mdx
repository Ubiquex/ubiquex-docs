---
title: "aws_imagebuilder_workflows"
description: "`data_aws_imagebuilder_workflows` looks up a real, already-existing `aws_image_builder_workflow`."
---

It defines a real, custom sequence of build, test, and distribution steps for EC2 Image Builder, an alternative to its own default workflow when a pipeline needs steps in a different order or with custom logic between them.

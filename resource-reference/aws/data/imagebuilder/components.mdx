---
title: "aws_imagebuilder_components"
description: "`data_aws_imagebuilder_components` looks up a real, already-existing `aws_image_builder_component`."
---

It defines a real, reusable build or test step, install a package, run a script, validate a setting, in YAML or JSON, that an EC2 Image Builder image pipeline assembles together to produce a custom AMI or container image.

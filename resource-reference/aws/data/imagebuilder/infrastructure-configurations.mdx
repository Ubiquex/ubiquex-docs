---
title: "aws_imagebuilder_infrastructure_configurations"
description: "`data_aws_imagebuilder_infrastructure_configurations` looks up a real, already-existing `aws_image_builder_infrastructure_configuration`."
---

It defines the real EC2 environment, instance type, subnet, IAM instance profile, that Image Builder launches temporary build instances into while assembling an image from `aws_image_builder_component`s.

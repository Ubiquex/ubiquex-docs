---
title: "aws_secretsmanager_resource_policy"
description: "`data_aws_secretsmanager_resource_policy` looks up a real, already-existing `aws_secrets_manager_resource_policy`."
---

It attaches a real resource-based access policy to an `aws_secrets_manager_secret`, controlling which principals, including from other accounts, can retrieve or manage it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	secretsmanager "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/secretsmanager"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_secretsmanager_resource_policy"})

    		ubx.Data(secretsmanager.ResourcePolicy, "example", secretsmanager.ResourcePolicyConfig{
    			SecretId: "example",
    		})
    	}))
    }
    ```
  </Tab>

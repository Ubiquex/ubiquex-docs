---
title: "aws_secretsmanager_secrets"
description: "`data_aws_secretsmanager_secrets` looks up a real, already-existing `aws_secrets_manager_secret`."
---

It creates a real, encrypted secret, a credential, API key, or other sensitive value, that applications retrieve at runtime instead of hardcoding it, with access controlled through IAM and every retrieval auditable through CloudTrail.

    	ubx.Main(ubx.Stack("example", func() {

## Lookup arguments

<ResponseField name="key_id" type="string" required>
  The real, unique identifier of the encryption key this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="wrapping_algorithm" type="string" required>
  The real algorithm used to wrap this key material. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="wrapping_key_spec" type="string" required>
  The real cryptographic configuration (key spec) of the wrapping key. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="import_token" type="string">
  The real, opaque import token. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="parameters_valid_to" type="string">
  The real timestamp these parameters are valid until. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="public_key" type="string">
  The real, unique key of the public this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

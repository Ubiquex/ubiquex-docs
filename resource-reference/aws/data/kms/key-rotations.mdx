---
title: "aws_kms_key_rotations"
description: "`data_aws_kms_key_rotations` looks up a real, already-existing `aws_kms_key`."
---

It creates a real cryptographic key in AWS Key Management Service, symmetric encryption keys, asymmetric encryption or signing keys, or symmetric HMAC keys, and can create the multi-Region primary key that an `aws_kms_replica_key` replicates from. Changing a key's spec, usage, origin, or multi-Region setting on an existing key is blocked outright, a deliberate guard against silently destroying key material.

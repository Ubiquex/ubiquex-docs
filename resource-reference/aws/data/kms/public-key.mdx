---
title: "aws_kms_public_key"
description: "`data_aws_kms_public_key` looks up a real, already-existing `aws_kms_key`."
---

It creates a real cryptographic key in AWS Key Management Service, symmetric encryption keys, asymmetric encryption or signing keys, or symmetric HMAC keys, and can create the multi-Region primary key that an `aws_kms_replica_key` replicates from. Changing a key's spec, usage, origin, or multi-Region setting on an existing key is blocked outright, a deliberate guard against silently destroying key material.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kms "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kms_public_key"})

    		ubx.Data(kms.PublicKey, "example", kms.PublicKeyConfig{
    			KeyId:       "example",
    			GrantTokens: []string{"example"},
    		})
    	}))
    }
    ```

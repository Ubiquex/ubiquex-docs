`aws_kms_public_key` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kms "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kms_public_key"})

    		ubx.Data(kms.PublicKey, "example", kms.PublicKeyConfig{
    			KeyId:       "example",
    			GrantTokens: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

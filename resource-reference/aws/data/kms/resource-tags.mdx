## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kms "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kms_resource_tags"})

    		ubx.Data(kms.ResourceTags, "example", kms.ResourceTagsConfig{
    			KeyId:  "example",
    			Limit:  1,
    			Marker: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="key_id" type="string" required>
  The real, unique identifier of the encryption key this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The real tags applied to this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="truncated" type="bool">
  Whether the result was truncated and more real data is available on a subsequent page. **(AI-inferred)** Returned by the lookup.
</ResponseField>

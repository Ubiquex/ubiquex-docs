title: "aws_datapipeline_pipeline_definition"
description: "`data_aws_datapipeline_pipeline_definition` looks up a real, already-existing `aws_data_pipeline_pipeline`."
---

It defines a scheduled, real data-movement and transformation workflow between AWS storage and compute services. AWS Data Pipeline stopped onboarding new customers on July 25, 2024; existing customers can continue using it, with AWS recommending AWS Glue, AWS Step Functions, or Amazon MWAA for new data-integration work.

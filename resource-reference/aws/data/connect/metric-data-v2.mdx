---
title: "aws_connect_metric_data_v2"
description: "`data_aws_connect_metric_data_v2` looks up a real, already-existing `aws_connect_metric`."
---

It defines a real, custom real-time or historical metric, built with advanced filters and functions on Connect's own metric primitives, for use in dashboards and the metrics API, beyond the fixed set of metrics Connect provides out of the box.

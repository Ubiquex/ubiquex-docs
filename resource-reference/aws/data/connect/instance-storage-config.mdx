---
title: "aws_connect_instance_storage_config"
description: "`data_aws_connect_instance_storage_config` looks up a real, already-existing `aws_connect_instance_storage_config`."
---

It configures where an `aws_connect_instance` stores a specific category of real data, call recordings, chat transcripts, contact trace records, in S3, Kinesis, or Kinesis Firehose.

## Lookup arguments

<ResponseField name="cluster_id" type="string" required>
  The real, unique identifier of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="session_states" type="list(string)">
  The real, current states of the sessions included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

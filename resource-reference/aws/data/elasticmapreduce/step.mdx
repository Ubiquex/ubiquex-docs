## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticmapreduce "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/elasticmapreduce"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_elasticmapreduce_step"})

    		ubx.Data(elasticmapreduce.Step, "example", elasticmapreduce.StepConfig{
    			ClusterId: "example",
    			StepId:    "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="cluster_id" type="string" required>
  The real, unique identifier of the cluster this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="step_id" type="string" required>
  The real, unique identifier of the step this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

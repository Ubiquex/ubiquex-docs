---
title: "aws_glue_catalogs"
description: "`data_aws_glue_catalogs` looks up a real, already-existing `aws_glue_catalog`."
---

It is a real, top-level metadata catalog, the container every `aws_glue_database` and `aws_glue_table` in one Glue Data Catalog deployment actually belongs to, queryable directly by Athena, Redshift Spectrum, and EMR without a caller copying the same metadata into each service separately.

---
title: "aws_glue_job_runs"
description: "`data_aws_glue_job_runs` looks up a real, already-existing `aws_glue_job`."
---

It defines a real, actual ETL script, Spark or Python, that transforms data read from a source into a target, run on demand, on a schedule via `aws_glue_trigger`, or as part of a larger workflow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_job_runs"})

    		ubx.Data(glue.JobRuns, "example", glue.JobRunsConfig{
    			JobName:    "example-job-name",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.aws.data.glue import JobRuns, JobRunsConfig

    def describe():
        ubx.intent("look up aws_glue_job_runs")

        ubx.data(JobRuns, "example", JobRunsConfig(
            job_name="example-job-name",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="job_name" type="string" required>
  The real name of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="job_runs" type="list(object)">
  The real job runs included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_glue_data_quality_result"
description: "`data_aws_glue_data_quality_result` looks up a real, already-existing `aws_glue_data_quality_ruleset`."
---

It defines a real set of data quality rules, in Glue's own DQDL language, that can be evaluated against a table in an `aws_glue_catalog` to score completeness, accuracy, and consistency.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_data_quality_result"})

    		ubx.Data(glue.DataQualityResult, "example", glue.DataQualityResultConfig{
    			ResultId: "example",
    		})
    	}))
    }
    ```

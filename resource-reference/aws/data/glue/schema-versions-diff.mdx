---
title: "aws_glue_schema_versions_diff"
description: "`data_aws_glue_schema_versions_diff` looks up a real, already-existing `aws_glue_schema_version`."
---

It publishes a real, immutable version of an `aws_glue_schema`'s definition, letting a Kafka or Kinesis producer/consumer pin to a specific, compatible schema version rather than the schema's current, evolving definition.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_schema_versions_diff"})

    		ubx.Data(glue.SchemaVersionsDiff, "example", glue.SchemaVersionsDiffConfig{
    			FirstSchemaVersionNumber:  map[string]any{"latest_version": true},
    			SchemaDiffType:            "example",
    			SchemaId:                  map[string]any{"registry_name": "example-registry-name"},
    			SecondSchemaVersionNumber: map[string]any{"latest_version": true},
    		})
    	}))
    }
    ```
  </Tab>

---
title: "aws_glue_sessions"
description: "`data_aws_glue_sessions` looks up a real, already-existing `aws_glue_session`."
---

It is an AWS Glue interactive session, an on-demand, serverless Spark runtime a notebook or IDE connects to for building and testing ETL scripts interactively, without waiting for a full Glue job's own cold-start time on every change.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_sessions"})

    		ubx.Data(glue.Sessions, "example", glue.SessionsConfig{
    			MaxResults:    1,
    			RequestOrigin: "example",
    			Tags:          map[string]string{"managed-by": "ubx"},
    		})
    	}))
    }
    ```

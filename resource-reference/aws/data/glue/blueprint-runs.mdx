---
title: "aws_glue_blueprint_runs"
description: "`data_aws_glue_blueprint_runs` looks up a real, already-existing `aws_glue_blueprint`."
---

It packages a real, reusable workflow template, generating a full set of `aws_glue_job`s, crawlers, and triggers from a small set of caller-provided parameters, rather than a caller assembling the same recurring pipeline shape by hand each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_blueprint_runs"})

    		ubx.Data(glue.BlueprintRuns, "example", glue.BlueprintRunsConfig{
    			BlueprintName: "example-blueprint-name",
    			MaxResults:    1,
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.aws.data.glue import BlueprintRuns, BlueprintRunsConfig

    def describe():
        ubx.intent("look up aws_glue_blueprint_runs")

        ubx.data(BlueprintRuns, "example", BlueprintRunsConfig(
            blueprint_name="example-blueprint-name",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="blueprint_name" type="string" required>
  The real name of the blueprint this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="blueprint_runs" type="list(object)">
  The real AWS Glue DataBrew blueprint runs included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

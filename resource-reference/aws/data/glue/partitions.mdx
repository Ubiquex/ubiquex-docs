---
title: "aws_glue_partitions"
description: "`data_aws_glue_partitions` looks up a real, already-existing `aws_glue_partition`."
---

It registers one real, physical subdivision of an `aws_glue_table`'s data, a specific date or Region's worth of files, for instance, so a query engine can skip reading partitions that don't match a query's filter instead of scanning the entire table.

---
title: "aws_glue_custom_entity_types"
description: "`data_aws_glue_custom_entity_types` looks up a real, already-existing `aws_glue_custom_entity_type`."
---

It defines a real, custom sensitive-data pattern, a regular expression, that AWS Glue's sensitive data detection can recognize during a crawl or ETL job beyond its own built-in entity types.

    	ubx.Main(ubx.Stack("example", func() {

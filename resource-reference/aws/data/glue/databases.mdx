---
title: "aws_glue_databases"
description: "`data_aws_glue_databases` looks up a real, already-existing `aws_glue_database`."
---

It is a real, logical grouping of `aws_glue_table`s inside an `aws_glue_catalog`, organizing related tables the way a schema organizes tables in a traditional relational database.

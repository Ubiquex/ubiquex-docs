---
title: "aws_glue_integration_resource_properties"
description: "`data_aws_glue_integration_resource_properties` looks up a real, already-existing `aws_glue_integration_resource_property`."
---

It sets a real, shared configuration property applied to every `aws_glue_integration` built from the same underlying resource, changing it affects every integration that resource is a part of rather than one integration individually.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_integration_resource_properties"})

    		})
    	}))
    }

---
title: "aws_glue_user_defined_functions"
description: "`data_aws_glue_user_defined_functions` looks up a real, already-existing `aws_glue_user_defined_function`."
---

It registers a real, custom function, callable from Athena or Spark SQL, in an `aws_glue_catalog`, extending what a query engine can compute beyond its own built-in functions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_user_defined_functions"})

    		ubx.Data(glue.UserDefinedFunctions, "example", glue.UserDefinedFunctionsConfig{
    			Pattern:      "example",
    			CatalogId:    "example",
    			DatabaseName: "example-database-name",
    			FunctionType: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

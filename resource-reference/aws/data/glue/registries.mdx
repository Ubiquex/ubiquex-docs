title: "aws_glue_registries"
description: "`data_aws_glue_registries` looks up a real, already-existing `aws_glue_registry`."

It is a real, named collection of related `aws_glue_schema`s in the Glue Schema Registry, organizing schemas the way an `aws_glue_catalog` organizes tables.

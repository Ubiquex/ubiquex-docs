---
title: "aws_glue_crawlers"
description: "`data_aws_glue_crawlers` looks up a real, already-existing `aws_glue_crawler`."
---

It scans a real data source, S3, a JDBC database, DynamoDB, and automatically infers and populates an `aws_glue_table`'s own schema in the Glue Data Catalog, rather than a caller writing that schema by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_crawlers"})

    		ubx.Data(glue.Crawlers, "example", glue.CrawlersConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.glue import Crawlers, CrawlersConfig

    def describe():
        ubx.intent("look up aws_glue_crawlers")

        ubx.data(Crawlers, "example", CrawlersConfig(
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="crawlers" type="list(object)">
  The real AWS Glue crawlers included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

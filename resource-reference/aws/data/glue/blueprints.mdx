---
title: "aws_glue_blueprints"
description: "`data_aws_glue_blueprints` looks up a real, already-existing `aws_glue_blueprint`."
---

It packages a real, reusable workflow template, generating a full set of `aws_glue_job`s, crawlers, and triggers from a small set of caller-provided parameters, rather than a caller assembling the same recurring pipeline shape by hand each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_blueprints"})

    		ubx.Data(glue.Blueprints, "example", glue.BlueprintsConfig{
    			MaxResults: 1,
    			Tags:       map[string]string{"managed-by": "ubx"},
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.aws.data.glue import Blueprints, BlueprintsConfig

    def describe():
        ubx.intent("look up aws_glue_blueprints")

        ubx.data(Blueprints, "example", BlueprintsConfig(
            max_results=1,
            tags={"managed-by": "ubx"},
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  The real tags applied to this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="blueprints" type="list(string)">
  The real blueprints included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_glue_jobs"
description: "`data_aws_glue_jobs` looks up a real, already-existing `aws_glue_job`."
---

It defines a real, actual ETL script, Spark or Python, that transforms data read from a source into a target, run on demand, on a schedule via `aws_glue_trigger`, or as part of a larger workflow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_jobs"})

    		ubx.Data(glue.Jobs, "example", glue.JobsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

  <Tab title="Python">
    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.glue import Jobs, JobsConfig

    def describe():
        ubx.intent("look up aws_glue_jobs")

        ubx.data(Jobs, "example", JobsConfig(
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="jobs" type="list(object)">
  The real jobs included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_glue_data_catalog_encryption_settings"
description: "`data_aws_glue_data_catalog_encryption_settings` looks up a real, already-existing `aws_glue_data_catalog_encryption_settings`."
---

It configures real, account-wide encryption defaults, at-rest KMS encryption and password encryption, for every table and connection in an `aws_glue_catalog`.

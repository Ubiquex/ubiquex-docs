---
title: "aws_glue_classifiers"
description: "`data_aws_glue_classifiers` looks up a real, already-existing `aws_glue_classifier`."
---

It tells an `aws_glue_crawler` how to actually recognize and parse a real data format, CSV with a specific delimiter, a custom log format, beyond the built-in classifiers Glue already provides.

    	ubx.Main(ubx.Stack("example", func() {

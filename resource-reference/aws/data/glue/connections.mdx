---
title: "aws_glue_connections"
description: "`data_aws_glue_connections` looks up a real, already-existing `aws_glue_connection`."
---

It stores the real, actual connection details, JDBC URL, credentials, network placement, an `aws_glue_crawler` or `aws_glue_job` uses to reach a data source outside the Glue Data Catalog itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_connections"})

    		ubx.Data(glue.Connections, "example", glue.ConnectionsConfig{
    			CatalogId:    "example",
    			Filter:       map[string]any{"connection_schema_version": 1},
    			HidePassword: true,
    			MaxResults:   1,
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx
    from ubx.aws.data.glue import Connections, ConnectionsConfig
    from ubx.aws.data.glue.connections import Connections_Filter

    def describe():
        ubx.intent("look up aws_glue_connections")

        ubx.data(Connections, "example", ConnectionsConfig(
            catalog_id="example",
            filter=Connections_Filter(connection_schema_version=1),
            hide_password=True,
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="catalog_id" type="string">
  The real, unique identifier of the catalog this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filter" type="object">
  &lt;p&gt;Filters the connection definitions that are returned by the &lt;code&gt;GetConnections&lt;/code&gt; API operation.&lt;/p&gt; Optional lookup argument.
  <Expandable title="properties">
    <ResponseField name="connection_schema_version" type="number">
      Optional lookup argument.
    </ResponseField>

      Optional lookup argument.
    </ResponseField>
    <ResponseField name="match_criteria" type="list(string)">
      Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="hide_password" type="bool">

</ResponseField>

  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="connection_list" type="list(object)">

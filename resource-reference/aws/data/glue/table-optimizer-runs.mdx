---
title: "aws_glue_table_optimizer_runs"
description: "`data_aws_glue_table_optimizer_runs` looks up a real, already-existing `aws_glue_table_optimizer`."
---

It automatically runs real, background maintenance, compacting small files, expiring old snapshots, deleting orphaned files, against an Apache Iceberg `aws_glue_table`, storage and query-performance upkeep a caller would otherwise have to schedule and run manually.

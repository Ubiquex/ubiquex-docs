---
title: "aws_glue_schema_version"
description: "`data_aws_glue_schema_version` looks up a real, already-existing `aws_glue_schema_version`."
---

It publishes a real, immutable version of an `aws_glue_schema`'s definition, letting a Kafka or Kinesis producer/consumer pin to a specific, compatible schema version rather than the schema's current, evolving definition.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_schema_version"})

    		ubx.Data(glue.SchemaVersion, "example", glue.SchemaVersionConfig{
    			SchemaId:            map[string]any{"registry_name": "example-registry-name"},
    			SchemaVersionNumber: map[string]any{"latest_version": true},
    		})
    	}))
    }
    ```

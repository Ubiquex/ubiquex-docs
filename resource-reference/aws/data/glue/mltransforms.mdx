---
title: "aws_glue_mltransforms"
description: "`data_aws_glue_mltransforms` looks up a real, already-existing `aws_glue_mltransform`."
---

It trains a real, managed machine-learning model, FindMatches, that an `aws_glue_job` can use to deduplicate or link records that don't match exactly, fuzzy matching a rule-based transform can't express.

---
title: "aws_glue_session_endpoint"
description: "`data_aws_glue_session_endpoint` looks up a real, already-existing `aws_glue_session`."
---

It is an AWS Glue interactive session, an on-demand, serverless Spark runtime a notebook or IDE connects to for building and testing ETL scripts interactively, without waiting for a full Glue job's own cold-start time on every change.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_session_endpoint"})

    		ubx.Data(glue.SessionEndpoint, "example", glue.SessionEndpointConfig{
    			SessionId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SessionEndpoint } from "@ubx/sdk-aws/aws/data/glue/session_endpoint";

    export default stack("example", () => {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.glue import SessionEndpoint, SessionEndpointConfig

    def describe():
        ubx.intent("look up aws_glue_session_endpoint")

        ubx.data(SessionEndpoint, "example", SessionEndpointConfig(
            session_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

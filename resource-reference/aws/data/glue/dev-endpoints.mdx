---
title: "aws_glue_dev_endpoints"
description: "`data_aws_glue_dev_endpoints` looks up a real, already-existing `aws_glue_dev_endpoint`."
---

It provisions a real, persistent development environment for interactively writing and testing an `aws_glue_job`'s own ETL script before running it as an actual, scheduled job.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_dev_endpoints"})

    		ubx.Data(glue.DevEndpoints, "example", glue.DevEndpointsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

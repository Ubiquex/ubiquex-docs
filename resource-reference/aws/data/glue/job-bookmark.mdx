---
title: "aws_glue_job_bookmark"
description: "`data_aws_glue_job_bookmark` looks up a real, already-existing `aws_glue_job`."
---

It defines a real, actual ETL script, Spark or Python, that transforms data read from a source into a target, run on demand, on a schedule via `aws_glue_trigger`, or as part of a larger workflow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_job_bookmark"})

    		ubx.Data(glue.JobBookmark, "example", glue.JobBookmarkConfig{
    			JobName: "example-job-name",
    			RunId:   "example",
    		})
    	}))
    }
    ```

---
title: "aws_glue_job_run"
description: "`data_aws_glue_job_run` looks up a real, already-existing `aws_glue_job`."
---

It defines a real, actual ETL script, Spark or Python, that transforms data read from a source into a target, run on demand, on a schedule via `aws_glue_trigger`, or as part of a larger workflow.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_job_run"})

    		ubx.Data(glue.JobRun, "example", glue.JobRunConfig{
    			JobName:              "example-job-name",
    			RunId:                "example",
    			PredecessorsIncluded: true,
    		})
    	}))
    }
    ```

    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.glue import JobRun, JobRunConfig

    def describe():
        ubx.intent("look up aws_glue_job_run")

        ubx.data(JobRun, "example", JobRunConfig(
            job_name="example-job-name",
            run_id="example",
            predecessors_included=True,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="job_name" type="string" required>
  The real name of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="predecessors_included" type="bool">
  Whether predecessor objects are included in the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="run_id" type="string" required>
  The real, unique identifier of the run this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

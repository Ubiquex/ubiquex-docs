---
title: "aws_glue_blueprint_run"
description: "`data_aws_glue_blueprint_run` looks up a real, already-existing `aws_glue_blueprint`."
---

It packages a real, reusable workflow template, generating a full set of `aws_glue_job`s, crawlers, and triggers from a small set of caller-provided parameters, rather than a caller assembling the same recurring pipeline shape by hand each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_blueprint_run"})

    		ubx.Data(glue.BlueprintRun, "example", glue.BlueprintRunConfig{
    			BlueprintName: "example-blueprint-name",
    			RunId:         "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.glue import BlueprintRun, BlueprintRunConfig

    def describe():
        ubx.intent("look up aws_glue_blueprint_run")

        ubx.data(BlueprintRun, "example", BlueprintRunConfig(
            blueprint_name="example-blueprint-name",
            run_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="blueprint_name" type="string" required>
  The real name of the blueprint this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="run_id" type="string" required>
  The real, unique identifier of the run this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

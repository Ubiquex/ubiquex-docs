---
title: "aws_glue_triggers"
description: "`data_aws_glue_triggers` looks up a real, already-existing `aws_glue_trigger`."
---

It starts an `aws_glue_job` or `aws_glue_crawler` on a real, defined schedule, on demand, or when another job or crawler completes, the actual mechanism that turns standalone Glue resources into a chained pipeline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_triggers"})

    		ubx.Data(glue.Triggers, "example", glue.TriggersConfig{
    			DependentJobName: "example-dependent-job-name",
    			MaxResults:       1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="dependent_job_name" type="string">
  The real name of the dependent job this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">

</ResponseField>

<ResponseField name="triggers" type="list(object)">
  The real triggers included in this result. **(AI-inferred)** Returned by the lookup.

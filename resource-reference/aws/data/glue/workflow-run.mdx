---
title: "aws_glue_workflow_run"
description: "`data_aws_glue_workflow_run` looks up a real, already-existing `aws_glue_workflow`."
---

It orchestrates a real, directed graph of Glue jobs, crawlers, and triggers as a single, coordinated ETL pipeline, so dependent steps run in the right order without a separate external scheduler.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	glue "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/glue"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_glue_workflow_run"})

    		ubx.Data(glue.WorkflowRun, "example", glue.WorkflowRunConfig{
    			Name:         "example",
    			RunId:        "example",
    			IncludeGraph: true,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="include_graph" type="bool">
  Whether the related dependency graph is included in the response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="name" type="string" required>
  The real, given name of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="run_id" type="string" required>
  The real, unique identifier of the run this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

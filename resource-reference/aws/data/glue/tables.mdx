---
title: "aws_glue_tables"
description: "`data_aws_glue_tables` looks up a real, already-existing `aws_glue_table`."
---

It registers the real schema, columns, types, storage format and location, of one dataset in the Glue Data Catalog, metadata a query engine reads to know how to actually read the underlying data in S3 or elsewhere.

---
title: "aws_codebuild_build_batches_for_project"
description: "`data_aws_codebuild_build_batches_for_project` looks up a real, already-existing `aws_code_build_project`."
---

It defines a real, fully managed build, its source, build environment, and buildspec, that AWS CodeBuild compiles, tests, and packages into deployable artifacts, run standalone or as a stage in an `aws_code_pipeline_pipeline`.

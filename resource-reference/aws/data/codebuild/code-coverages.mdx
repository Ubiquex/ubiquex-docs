## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codebuild "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codebuild"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codebuild_code_coverages"})

    		ubx.Data(codebuild.CodeCoverages, "example", codebuild.CodeCoveragesConfig{
    			ReportArn:                 "arn:aws:iam::123456789012:policy/example",
    			MaxLineCoveragePercentage: 1,
    			MaxResults:                1,
    			MinLineCoveragePercentage: 1,
    			SortBy:                    "example",
    			SortOrder:                 "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="max_line_coverage_percentage" type="number">
  The real, maximum line coverage percentage for this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="min_line_coverage_percentage" type="number">
  The real, minimum line coverage percentage for this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="report_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the report this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sort_by" type="string">
  The real field results are sorted by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_order" type="string">
  The real order (ascending or descending) results are sorted in. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="code_coverages" type="list(object)">
  The real code coverage reports included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_translate_parallel_data"
description: "`data_aws_translate_parallel_data` looks up a real, already-existing `aws_translate_parallel_data`."
---

It imports a real set of source-and-target sentence pairs that Amazon Translate uses to customize its own translation output, favoring an organization's preferred terminology and phrasing over the engine's generic default translations.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	translate "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/translate"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_translate_parallel_data"})

    		ubx.Data(translate.ParallelData, "example", translate.ParallelDataConfig{
    			MaxResults: 1,
    		})
    	}))
    }

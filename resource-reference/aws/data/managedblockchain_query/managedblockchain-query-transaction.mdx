## Lookup arguments

<ResponseField name="network" type="string" required>
  The real network this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="transaction_hash" type="string">
  The real, cryptographic hash of this transaction. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="transaction_id" type="string">
  The real, unique identifier of the transaction this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

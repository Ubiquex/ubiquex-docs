## Lookup arguments

<ResponseField name="component_path" type="string">
  The real path of the component. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="entity_id" type="string" required>
  The real, unique identifier of this entity. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="workspace_id" type="string" required>
  The real, unique identifier of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Example

    package main

    import (
    	iottwinmaker "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/iottwinmaker"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_iottwinmaker_scenes"})

    		ubx.Data(iottwinmaker.Scenes, "example", iottwinmaker.ScenesConfig{
    			WorkspaceId: "example",
    			MaxResults:  1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="workspace_id" type="string" required>
  The real, unique identifier of the workspace this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="scene_summaries" type="list(object)">

---
title: "aws_dynamodb_backups"
description: "`data_aws_dynamodb_backups` looks up a real, already-existing `aws_dynamo_db_backup`."
---

It creates a real, on-demand backup of an `aws_dynamo_db_table`'s data at a specific point in time, stored independently of the table's own continuous point-in-time recovery window until explicitly deleted.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dynamodb "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/dynamodb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dynamodb_backups"})

    		ubx.Data(dynamodb.Backups, "example", dynamodb.BackupsConfig{
    			BackupType:              "example",
    			ExclusiveStartBackupArn: "arn:aws:iam::123456789012:policy/example",
    			Limit:                   1,
    			TableName:               "example-table-name",
    			TimeRangeLowerBound:     "example",
    			TimeRangeUpperBound:     "example",
    		})
    	}))
    }
    ```

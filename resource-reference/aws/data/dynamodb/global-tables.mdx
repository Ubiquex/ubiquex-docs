---
title: "aws_dynamodb_global_tables"
description: "`data_aws_dynamodb_global_tables` looks up a real, already-existing `aws_dynamo_db_global_table`."
---

It replicates an `aws_dynamo_db_table`'s own data across multiple AWS Regions with active-active, multi-Region writes, real low-latency global access and Regional failover that a single-Region table doesn't provide.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	dynamodb "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/dynamodb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dynamodb_global_tables"})

    		ubx.Data(dynamodb.GlobalTables, "example", dynamodb.GlobalTablesConfig{
    			ExclusiveStartGlobalTableName: "example-exclusive-start-global-table-name",
    			Limit:                         1,
    			RegionName:                    "example-region-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="exclusive_start_global_table_name" type="string">
  The real name of the exclusive start global table this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="region_name" type="string">
  The real name of the region this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="global_tables" type="list(object)">
  The real DynamoDB global tables included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="last_evaluated_global_table_name" type="string">
  The real name of the last evaluated global table this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

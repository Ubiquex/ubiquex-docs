---
title: "aws_dynamodb_tables"
description: "`data_aws_dynamodb_tables` looks up a real, already-existing `aws_dynamo_db_table`."
---

It creates a real, single-Region DynamoDB table, AWS's managed key-value and document database, with automatically scaling throughput and no servers for a caller to provision or patch.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	dynamodb "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/dynamodb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dynamodb_tables"})

    		ubx.Data(dynamodb.Tables, "example", dynamodb.TablesConfig{
    			ExclusiveStartTableName: "example-exclusive-start-table-name",
    			Limit:                   1,
    		})
    	}))
    }
    ```

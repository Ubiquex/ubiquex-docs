## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dynamodb "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/dynamodb"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dynamodb_imports"})

    		ubx.Data(dynamodb.Imports, "example", dynamodb.ImportsConfig{
    			PageSize: 1,
    			TableArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.dynamodb import Imports, ImportsConfig

    def describe():
        ubx.intent("look up aws_dynamodb_imports")

        ubx.data(Imports, "example", ImportsConfig(
            page_size=1,
            table_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="table_arn" type="string">
  The real Amazon Resource Name (ARN) of the table this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="import_summary_list" type="list(object)">
  The real import summarys included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_bedrock_data_automation_data_automation_library_entity"
description: "`data_aws_bedrock_data_automation_data_automation_library_entity` looks up a real, already-existing `aws_bedrock_data_automation_library`."
---

It stores domain-specific entities and, currently, custom vocabulary that improve Bedrock Data Automation's extraction accuracy for audio and video content once associated with an `aws_bedrock_data_automation_project`, applied automatically to every job that project runs without per-job configuration.

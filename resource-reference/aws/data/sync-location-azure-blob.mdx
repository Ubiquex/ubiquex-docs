`aws_data_sync_location_azure_blob` registers a real Microsoft Azure Blob Storage container as a DataSync transfer endpoint, one of several non-AWS cloud storage systems, alongside Google Cloud Storage and others, DataSync can transfer to or from directly.

## Input properties

<ResponseField name="agent_arns" type="list(string)">
  Specifies the Amazon Resource Name (ARN) of the DataSync agent that can connect with your Azure Blob Storage container. If you are setting up an agentless cross-cloud transfer, you do not need to specify a value for this parameter. Optional.
</ResponseField>

<ResponseField name="azure_access_tier" type="string">
  Specifies an access tier for the objects you're transferring into your Azure Blob Storage container. Optional.
</ResponseField>

<ResponseField name="azure_blob_authentication_type" type="string" required>
  The specific authentication type that you want DataSync to use to access your Azure Blob Container. Required.
</ResponseField>

<ResponseField name="azure_blob_container_url" type="string">
  The URL of the Azure Blob container that was described. Optional.
</ResponseField>

<ResponseField name="azure_blob_sas_configuration" type="object">
  Specifies the shared access signature (SAS) that DataSync uses to access your Azure Blob Storage container. Optional.
  <Expandable title="properties">
    <ResponseField name="azure_blob_sas_token" type="string" required>
      Specifies the shared access signature (SAS) token, which indicates the permissions DataSync needs to access your Azure Blob Storage container. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="azure_blob_type" type="string">
  Specifies a blob type for the objects you're transferring into your Azure Blob Storage container. Optional.
</ResponseField>

<ResponseField name="custom_secret_config" type="object">
  Specifies configuration information for a customer-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and an IAM role that DataSync can assume and access the customer-managed secret. Optional.
  <Expandable title="properties">
    <ResponseField name="secret_access_role_arn" type="string" required>
      Specifies the ARN for the AWS Identity and Access Management role that DataSync uses to access the secret specified for SecretArn. Required.
    </ResponseField>
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for a customer created AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subdirectory" type="string">
  The subdirectory in the Azure Blob Container that is used to read data from the Azure Blob Source Location. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a key-value tag assigned to this AWS DataSync location for Azure Blob storage, used to identify and organize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cmk_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and a customer-managed AWS KMS key. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      Specifies the ARN for the customer-managed AWS KMS key used to encrypt the secret specified for SecretArn. DataSync provides this key to AWS Secrets Manager. Optional.
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      Specifies the ARN for an AWS Secrets Manager secret, managed by DataSync. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the Azure Blob Location that is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the Azure Blob Location that was described. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="managed_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location. DataSync uses the default AWS-managed KMS key to encrypt this secret in AWS Secrets Manager. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for an AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

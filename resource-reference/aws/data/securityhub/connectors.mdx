---
title: "aws_securityhub_connectors"
description: "`data_aws_securityhub_connectors` looks up a real, already-existing `aws_security_hub_connector`."
---

It connects a real external, non-AWS security tool's findings into the original Security Hub model, so third-party findings appear alongside AWS-native ones.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_securityhub_connectors"})

    		ubx.Data(securityhub.Connectors, "example", securityhub.ConnectorsConfig{
    			ConnectorStatus:  "example",
    			EnablementStatus: "example",
    			MaxResults:       1,
    			ProviderName:     "example-provider-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

<ResponseField name="connector_status" type="string">

</ResponseField>

<ResponseField name="enablement_status" type="string">
  &lt;p&gt;The enablement status of a CSPM connector. Indicates the lifecycle state of the connector resource.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">

</ResponseField>

<ResponseField name="provider_name" type="string">
  &lt;p&gt;The name of the cloud provider for a CSPM connector.&lt;/p&gt; Optional lookup argument.
</ResponseField>

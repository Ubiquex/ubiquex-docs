---
title: "aws_securityhub_configuration_policy_association"
description: "`data_aws_securityhub_configuration_policy_association` looks up a real, already-existing `aws_security_hub_configuration_policy`."
---

It defines a real, centrally managed configuration, which standards and controls are enabled, applied across many accounts in an AWS Organization through Security Hub's own central configuration feature, rather than configuring each account's Security Hub individually.

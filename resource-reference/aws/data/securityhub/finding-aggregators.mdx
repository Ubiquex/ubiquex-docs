---
title: "aws_securityhub_finding_aggregators"
description: "`data_aws_securityhub_finding_aggregators` looks up a real, already-existing `aws_security_hub_finding_aggregator`."
---

It configures real cross-Region aggregation of findings into a single Region under the original Security Hub model, so findings from every enabled Region can be viewed and acted on from one place.

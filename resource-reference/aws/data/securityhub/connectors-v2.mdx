---
title: "aws_securityhub_connectors_v2"
description: "`data_aws_securityhub_connectors_v2` looks up a real, already-existing `aws_security_hub_connector_v2`."
---

It connects a real external, non-AWS security tool's findings into Security Hub's next-generation (HubV2) model, launched at re:Invent in December 2025, the V2 counterpart to `aws_security_hub_connector`.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_securityhub_connectors_v2"})

    		ubx.Data(securityhub.ConnectorsV2, "example", securityhub.ConnectorsV2Config{
    			ConnectorStatus:  "example",
    			EnablementStatus: "example",
    			MaxResults:       1,
    			ProviderName:     "example-provider-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="connector_status" type="string">
  The real, current status of the connector this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="enablement_status" type="string">
  The real, current status of the enablement this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="provider_name" type="string">
  The real name of the provider this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "aws_securityhub_insight_results"
description: "`data_aws_securityhub_insight_results` looks up a real, already-existing `aws_security_hub_insight`."
---

It defines a real, saved query, a grouping attribute and filter criteria, that Security Hub evaluates against current findings to surface a specific pattern, such as the resources with the most high-severity findings, rather than being re-built by hand each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/securityhub"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_securityhub_insight_results"})

    		ubx.Data(securityhub.InsightResults, "example", securityhub.InsightResultsConfig{
    			InsightArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

---
title: "aws_securityhub_standards"
description: "`data_aws_securityhub_standards` looks up a real, already-existing `aws_security_hub_standard`."
---

It subscribes an account to a real, predefined security standard, such as the AWS Foundational Security Best Practices or CIS AWS Foundations Benchmark, the resource that actually turns on the bundle of individual `aws_security_hub_security_control` checks that standard is made of.

## Example

    	ubx.Main(ubx.Stack("example", func() {

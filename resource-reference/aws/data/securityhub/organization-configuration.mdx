---
title: "aws_securityhub_organization_configuration"
description: "`data_aws_securityhub_organization_configuration` looks up a real, already-existing `aws_security_hub_organization_configuration`."
---

It configures whether Security Hub is enabled automatically for every new account that joins an AWS Organization, managed from the account designated by an `aws_security_hub_delegated_admin`.

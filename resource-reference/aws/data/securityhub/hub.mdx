---
title: "aws_securityhub_hub"
description: "`data_aws_securityhub_hub` looks up a real, already-existing `aws_security_hub_hub`."
---

It enables Security Hub's original model in an account and Region, the resource that must exist before `aws_security_hub_standard`s, `aws_security_hub_insight`s, or `aws_security_hub_finding_aggregator`s can be created, and the predecessor `aws_security_hub_hub_v2`'s own December 2025 relaunch built alongside rather than replacing outright.

---
title: "aws_securityhub_security_control_definitions"
description: "`data_aws_securityhub_security_control_definitions` looks up a real, already-existing `aws_security_hub_security_control`."
---

It enables or disables a real, individual security control, and can override its default severity, within an `aws_security_hub_standard`, letting a specific check be turned off account-wide without disabling the whole standard.

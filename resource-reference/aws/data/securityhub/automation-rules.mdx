---
title: "aws_securityhub_automation_rules"
description: "`data_aws_securityhub_automation_rules` looks up a real, already-existing `aws_security_hub_automation_rule`."
---

It defines a real rule that automatically updates matching findings, suppressing, reprioritizing, adding notes, in the original Security Hub model, without a human triaging each one individually.

## Example

  <Tab title="Go">

    package main

    import (
    	securityhub "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/securityhub"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_securityhub_automation_rules"})

    		ubx.Data(securityhub.AutomationRules, "example", securityhub.AutomationRulesConfig{
    			MaxResults: 1,
    		})
    	}))
    }

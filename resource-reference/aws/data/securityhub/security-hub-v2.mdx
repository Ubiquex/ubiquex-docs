---
title: "aws_securityhub_security_hub_v2"
description: "`data_aws_securityhub_security_hub_v2` looks up a real, already-existing `aws_security_hub_hub_v2`."
---

It enables Security Hub's next-generation (HubV2) model in an account and Region, the resource behind its December 2025 relaunch delivering near-real-time risk analytics and unified findings across GuardDuty, Inspector, Macie, and Security Hub CSPM, up to one year of historical trend data, and the V2 counterpart to the original `aws_security_hub_hub`. Only one HubV2 resource can exist per account per Region.

`aws_data_sync_location_hdfs` registers a real Hadoop Distributed File System cluster as a DataSync transfer endpoint, letting an `aws_data_sync_task` move data out of an on-premises big-data cluster into AWS storage.

## Example

    ```go
    import (
    	data "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sync location hdfs"})

    		ubx.Resource(data.SyncLocationHdfs, "example", data.SyncLocationHdfsConfig{
    			AgentArns:          []string{"example"},

    			NameNodes:          []map[string]any{{"hostname": "example"}},
    			BlockSize:          1,
    			CustomSecretConfig: map[string]any{"secret_access_role_arn": "example"},
    			KerberosKeytab:     "example",
    			KerberosKrb5Conf:   "example",
    			KerberosPrincipal:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="agent_arns" type="list(string)" required>
  ARN(s) of the agent(s) to use for an HDFS location. Required.
</ResponseField>

<ResponseField name="authentication_type" type="string" required>
  The authentication mode used to determine identity of user. Required.
</ResponseField>

<ResponseField name="block_size" type="number">
  Size of chunks (blocks) in bytes that the data is divided into when stored in the HDFS cluster. Optional.
</ResponseField>

<ResponseField name="custom_secret_config" type="object">
  Specifies configuration information for a customer-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and an IAM role that DataSync can assume and access the customer-managed secret. Optional.
  <Expandable title="properties">
    <ResponseField name="secret_access_role_arn" type="string" required>
      Specifies the ARN for the AWS Identity and Access Management role that DataSync uses to access the secret specified for SecretArn. Required.
    </ResponseField>
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for a customer created AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kerberos_keytab" type="string">
  The Base64 string representation of the Keytab file. Optional.
</ResponseField>

<ResponseField name="kerberos_krb5_conf" type="string">
  The string representation of the Krb5Conf file, or the presigned URL to access the Krb5.conf file within an S3 bucket. Optional.
</ResponseField>

<ResponseField name="kerberos_principal" type="string">
  The unique identity, or principal, to which Kerberos can assign tickets. Optional.
</ResponseField>

<ResponseField name="kms_key_provider_uri" type="string">
  The identifier for the Key Management Server where the encryption keys that encrypt data inside HDFS clusters are stored. Optional.
</ResponseField>

<ResponseField name="name_nodes" type="list(object)" required>
  An array of Name Node(s) of the HDFS location. Required.
  <Expandable title="properties">
    <ResponseField name="hostname" type="string">
      The hostname or IP address of the HDFS NameNode to which AWS DataSync connects, part of the name_nodes list for the HDFS location. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="port" type="number">
      The port number on which the HDFS NameNode service is listening for connections. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="qop_configuration" type="object">
  Configuration information for RPC Protection and Data Transfer Protection. These parameters can be set to AUTHENTICATION, INTEGRITY, or PRIVACY. The default value is PRIVACY. Optional.
  <Expandable title="properties">
    <ResponseField name="data_transfer_protection" type="string">
      Configuration for Data Transfer Protection. Optional.
    </ResponseField>
    <ResponseField name="rpc_protection" type="string">
      Configuration for RPC Protection. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="replication_factor" type="number">
  Number of copies of each block that exists inside the HDFS cluster. Optional.
</ResponseField>

<ResponseField name="simple_user" type="string">
  The user name that has read and write permissions on the specified HDFS cluster. Optional.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  The subdirectory in HDFS that is used to read data from the HDFS source location or write data to the HDFS destination. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value tag that you assign to this AWS DataSync HDFS location, used for metadata and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cmk_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and a customer-managed AWS KMS key. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      Specifies the ARN for the customer-managed AWS KMS key used to encrypt the secret specified for SecretArn. DataSync provides this key to AWS Secrets Manager. Optional.
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      Specifies the ARN for an AWS Secrets Manager secret, managed by DataSync. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the HDFS location. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the HDFS location that was described. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="managed_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location. DataSync uses the default AWS-managed KMS key to encrypt this secret in AWS Secrets Manager. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for an AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

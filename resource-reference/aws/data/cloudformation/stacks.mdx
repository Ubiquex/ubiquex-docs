---
title: "aws_cloudformation_stacks"
description: "`data_aws_cloudformation_stacks` looks up a real, already-existing `aws_cloud_formation_stack`."
---

It is CloudFormation's own fundamental unit, a collection of AWS resources managed together as one, created, updated, and deleted as a single operation from a real template.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudformation_stacks"})

    		ubx.Data(cloudformation.Stacks, "example", cloudformation.StacksConfig{
    			StackStatusFilter: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.cloudformation import Stacks, StacksConfig

    def describe():
        ubx.intent("look up aws_cloudformation_stacks")

        ubx.data(Stacks, "example", StacksConfig(
            stack_status_filter=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="stack_status_filter" type="list(string)">
  Restricts results to this CloudFormation stack status. **(AI-inferred)** Optional lookup argument.
</ResponseField>

</ResponseField>

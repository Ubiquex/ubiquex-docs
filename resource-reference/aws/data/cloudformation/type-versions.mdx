---
title: "aws_cloudformation_type_versions"
description: "`data_aws_cloudformation_type_versions` looks up a real, already-existing `aws_cloud_formation_public_type_version`."
---

It publishes a real, specific version of a resource type through an `aws_cloud_formation_type_activation`-eligible public registry listing, so other accounts can activate and pin to that exact version rather than only the type's latest.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

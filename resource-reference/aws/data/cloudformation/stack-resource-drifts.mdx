`aws_cloudformation_stack_resource_drifts` reads the real, detected drift between a CloudFormation stack's own template and each resource's real, live configuration.

    	ubx.Main(ubx.Stack("example", func() {

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The real name of the CloudFormation stack this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="stack_resource_drift_status_filters" type="list(string)">
  Restricts results to these CloudFormation stack resource drift statuses. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "aws_cloudformation_publisher"
description: "`data_aws_cloudformation_publisher` looks up a real, already-existing `aws_cloud_formation_publisher`."
---

It registers a real account as a CloudFormation Registry publisher, verified against a linked Bitbucket, GitHub, or GitLab identity, the prerequisite before that account can publish a resource type or module to the public CloudFormation Registry for other accounts to use.

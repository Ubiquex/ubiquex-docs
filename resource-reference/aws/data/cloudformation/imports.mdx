## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudformation_imports"})

    		ubx.Data(cloudformation.Imports, "example", cloudformation.ImportsConfig{
    			ExportName: "example-export-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Imports } from "@ubx/sdk-aws/aws/data/cloudformation/imports";

    export default stack("example", () => {
      intent({ summary: "look up aws_cloudformation_imports" });

      data(Imports, "example", {
        exportName: "example-export-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.cloudformation import Imports, ImportsConfig

    def describe():
        ubx.intent("look up aws_cloudformation_imports")

        ubx.data(Imports, "example", ImportsConfig(
            export_name="example-export-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="export_name" type="string" required>
  The real name of the export this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="imports" type="list(string)">
  The real imports included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

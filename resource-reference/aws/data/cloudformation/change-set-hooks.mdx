---
title: "aws_cloudformation_change_set_hooks"
description: "`data_aws_cloudformation_change_set_hooks` looks up a real, already-existing `aws_cloud_formation_change_set`."
---

It computes a real, previewable set of changes that updating an `aws_cloud_formation_stack` to a new template or parameters would make, without actually applying them, so the changes can be reviewed before anything is modified.

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stack_refactor_id" type="string" required>
  The real, unique identifier of the stack refactor this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="stack_refactor_actions" type="list(object)">
  The real CloudFormation stack refactor actions included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudformation_stack_resources"})

    		ubx.Data(cloudformation.StackResources, "example", cloudformation.StackResourcesConfig{
    			LogicalResourceId:  "example",
    			PhysicalResourceId: "example",
    			StackName:          "example-stack-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="logical_resource_id" type="string">

<ResponseField name="physical_resource_id" type="string">
  The real, unique identifier of the physical resource this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stack_name" type="string">
  The real name of the CloudFormation stack this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stack_resources" type="list(object)">

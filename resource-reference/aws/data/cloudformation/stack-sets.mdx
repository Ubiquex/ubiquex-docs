---
title: "aws_cloudformation_stack_sets"
description: "`data_aws_cloudformation_stack_sets` looks up a real, already-existing `aws_cloud_formation_stack_set`."
---

It deploys the same `aws_cloud_formation_stack` template consistently across many AWS accounts and Regions from one operation, the real mechanism for organization-wide infrastructure rollout rather than manually repeating a stack deployment account by account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudformation_template"})

    		ubx.Data(cloudformation.Template, "example", cloudformation.TemplateConfig{
    			ChangeSetName: "example-change-set-name",
    			StackName:     "example-stack-name",
    			TemplateStage: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.cloudformation import Template, TemplateConfig

    def describe():
        ubx.intent("look up aws_cloudformation_template")

        ubx.data(Template, "example", TemplateConfig(
            change_set_name="example-change-set-name",
            stack_name="example-stack-name",
            template_stage="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="change_set_name" type="string">
  The real name of the change set this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="stack_name" type="string">
  The real name of the CloudFormation stack this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="template_stage" type="string">
  The real deployment stage this template applies to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="stages_available" type="list(string)">
  The real, available deployment stages for this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="template_body" type="string">
  The real, raw body of the template. **(AI-inferred)** Returned by the lookup.
</ResponseField>

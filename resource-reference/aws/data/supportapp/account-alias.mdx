---
title: "aws_supportapp_account_alias"
description: "`data_aws_supportapp_account_alias` looks up a real, already-existing `aws_support_app_account_alias`."
---

It sets a real, friendly alias for an account, shown in AWS Support App notifications so a Slack or Chime channel receiving alerts from many accounts can tell them apart by name instead of account ID.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	supportapp "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/supportapp"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_supportapp_account_alias"})

    		ubx.Data(supportapp.AccountAlias, "example", supportapp.AccountAliasConfig{})
    	}))
    }
    ```

---
title: "aws_uxc_account_customizations"
description: "`data_aws_uxc_account_customizations` looks up a real, already-existing `aws_uxc_account_customization`."
---

It sets real, account-level visual customization for the AWS Management Console under AWS User Experience Customization, an account color, which services are visible, which Regions are visible, so administrators can make different accounts visually distinguishable and reduce clutter for their users. This is a genuinely new AWS service, launched in 2026, so behavior here is verified live rather than assumed from general knowledge.

---
title: "aws_personalize_solutions"
description: "`data_aws_personalize_solutions` looks up a real, already-existing `aws_personalize_solution`."
---

It trains a real recommendation model against the data in an `aws_personalize_dataset_group`, using either a built-in Personalize recipe or AutoML, the resource that actually produces the model a deployed campaign serves recommendations from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_personalize_solutions"})

    		ubx.Data(personalize.Solutions, "example", personalize.SolutionsConfig{
    			DatasetGroupArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults:      1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="dataset_group_arn" type="string">
  The real Amazon Resource Name (ARN) of the dataset group this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="solutions" type="list(object)">
  The real Amazon Personalize solutions included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

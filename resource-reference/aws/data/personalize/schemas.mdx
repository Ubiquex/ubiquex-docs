---
title: "aws_personalize_schemas"
description: "`data_aws_personalize_schemas` looks up a real, already-existing `aws_personalize_schema`."
---

It defines a real Avro schema describing the structure of interaction, item, or user data, that one or more `aws_personalize_dataset`s must conform to when imported.

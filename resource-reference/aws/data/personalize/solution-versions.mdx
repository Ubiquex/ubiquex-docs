---
title: "aws_personalize_solution_versions"
description: "`data_aws_personalize_solution_versions` looks up a real, already-existing `aws_personalize_solution`."
---

It trains a real recommendation model against the data in an `aws_personalize_dataset_group`, using either a built-in Personalize recipe or AutoML, the resource that actually produces the model a deployed campaign serves recommendations from.

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="solution_arn" type="string">
  The real Amazon Resource Name (ARN) of the solution this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="solution_versions" type="list(object)">
  The real versions of the solution included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

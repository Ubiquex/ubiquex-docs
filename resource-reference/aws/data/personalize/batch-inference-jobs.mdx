    		})

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="solution_version_arn" type="string">
  The real Amazon Resource Name (ARN) of the solution version this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="batch_inference_jobs" type="list(object)">
  The real Amazon Personalize batch inference jobs included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_personalize_dataset_groups"
description: "`data_aws_personalize_dataset_groups` looks up a real, already-existing `aws_personalize_dataset_group`."
---

It creates a real top-level container that groups the `aws_personalize_dataset`s Amazon Personalize trains an `aws_personalize_solution` from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_personalize_dataset_groups"})

    		ubx.Data(personalize.DatasetGroups, "example", personalize.DatasetGroupsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

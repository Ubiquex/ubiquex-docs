---
title: "aws_personalize_metric_attribution_metrics"
description: "`data_aws_personalize_metric_attribution_metrics` looks up a real, already-existing `aws_personalize_metric_attribution`."
---

It configures real, ongoing export of business metrics, click-through rate, conversion, tied back to an `aws_personalize_solution`'s recommendations, so their real-world impact can be measured outside Personalize itself.

## Example

    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/personalize"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_personalize_metric_attribution_metrics"})

    		ubx.Data(personalize.MetricAttributionMetrics, "example", personalize.MetricAttributionMetricsConfig{
    			MaxResults:           1,
    			MetricAttributionArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="metric_attribution_arn" type="string">
  The real Amazon Resource Name (ARN) of the metric attribution this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="metrics" type="list(object)">
  The real metrics included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.

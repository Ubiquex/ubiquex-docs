---
title: "aws_personalize_datasets"
description: "`data_aws_personalize_datasets` looks up a real, already-existing `aws_personalize_dataset`."
---

It imports real interaction, item, or user data, conforming to an `aws_personalize_schema`, into an `aws_personalize_dataset_group` for Amazon Personalize to train recommendation models against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	personalize "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/personalize"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_personalize_datasets"})

    		ubx.Data(personalize.Datasets, "example", personalize.DatasetsConfig{
    			DatasetGroupArn: "arn:aws:iam::123456789012:policy/example",
    			MaxResults:      1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="dataset_group_arn" type="string">
  The real Amazon Resource Name (ARN) of the dataset group this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="datasets" type="list(object)">
  The real datasets included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

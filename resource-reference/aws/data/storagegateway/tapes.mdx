`aws_storagegateway_tapes` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	storagegateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/storagegateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_storagegateway_tapes"})

    		ubx.Data(storagegateway.Tapes, "example", storagegateway.TapesConfig{
    			Limit:    1,
    			TapeArns: []string{"example"},
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="limit" type="number">
  Optional lookup argument.
</ResponseField>

<ResponseField name="tape_arns" type="list(string)">
  &lt;p&gt;The Amazon Resource Name (ARN) of each of the tapes you want to list. If you don't specify a tape ARN, the response lists all tapes in both your VTL and VTS.&lt;/p&gt; Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="marker" type="string">
  Returned by the lookup.
</ResponseField>

<ResponseField name="tape_infos" type="list(object)">
  &lt;p&gt;An array of &lt;a&gt;TapeInfo&lt;/a&gt; objects, where each object describes a single tape. If there are no tapes in the tape library or VTS, then the &lt;code&gt;TapeInfos&lt;/code&gt; is an empty array.&lt;/p&gt; Returned by the lookup.
</ResponseField>

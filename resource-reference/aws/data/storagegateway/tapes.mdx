## Lookup arguments

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="tape_arns" type="list(string)">
  &lt;p&gt;The Amazon Resource Name (ARN) of each of the tapes you want to list. If you don't specify a tape ARN, the response lists all tapes in both your VTL and VTS.&lt;/p&gt; Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="marker" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="tape_infos" type="list(object)">
  &lt;p&gt;An array of &lt;a&gt;TapeInfo&lt;/a&gt; objects, where each object describes a single tape. If there are no tapes in the tape library or VTS, then the &lt;code&gt;TapeInfos&lt;/code&gt; is an empty array.&lt;/p&gt; Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	storagegateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/storagegateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_storagegateway_smbsettings"})

    		ubx.Data(storagegateway.Smbsettings, "example", storagegateway.SmbsettingsConfig{
    			GatewayArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="gateway_arn" type="string" required>
  &lt;p&gt;The Amazon Resource Name (ARN) of the gateway. Use the &lt;a&gt;ListGateways&lt;/a&gt; operation to return a list of gateways for your account and Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="active_directory_status" type="string">
  The real, current status of the active directory this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="domain_name" type="string">
  The real domain name this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="file_shares_visible" type="bool">
  Whether file shares are visible for this gateway. **(AI-inferred)** Returned by the lookup.
</ResponseField>

</ResponseField>

<ResponseField name="smblocal_groups" type="object">

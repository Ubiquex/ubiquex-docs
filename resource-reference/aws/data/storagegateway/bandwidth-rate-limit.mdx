## Lookup arguments

<ResponseField name="gateway_arn" type="string" required>
  &lt;p&gt;The Amazon Resource Name (ARN) of the gateway. Use the &lt;a&gt;ListGateways&lt;/a&gt; operation to return a list of gateways for your account and Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="average_download_rate_limit_in_bits_per_sec" type="number">
  The real, average download rate limit for this gateway, in bits per second. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="average_upload_rate_limit_in_bits_per_sec" type="number">
  The real, average upload rate limit for this gateway, in bits per second. **(AI-inferred)** Returned by the lookup.
</ResponseField>

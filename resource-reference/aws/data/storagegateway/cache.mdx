## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	storagegateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/storagegateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_storagegateway_cache"})

    		ubx.Data(storagegateway.Cache, "example", storagegateway.CacheConfig{
    			GatewayArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="gateway_arn" type="string" required>
  &lt;p&gt;The Amazon Resource Name (ARN) of the gateway. Use the &lt;a&gt;ListGateways&lt;/a&gt; operation to return a list of gateways for your account and Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="cache_allocated_in_bytes" type="number">
  The real size of the cache allocated in, in bytes. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="cache_dirty_percentage" type="number">
  The real percentage of cached data pending write to disk. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="cache_hit_percentage" type="number">
  The real percentage of requests served from cache. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="cache_miss_percentage" type="number">
  The real percentage of requests not served from cache. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="cache_used_percentage" type="number">
  The real percentage of cache capacity currently in use. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="disk_ids" type="list(string)">
  The real, unique identifiers of the disks this request is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_pinpoint_email_configuration_sets"
description: "`data_aws_pinpoint_email_configuration_sets` looks up a real, already-existing `aws_pinpoint_email_configuration_set`."
---

It defines a real set of rules, event destinations, dedicated IP pool, reputation options, applied to emails sent through an `aws_pinpoint_app`'s `aws_pinpoint_email_channel`, subject to the same October 30, 2026 Pinpoint retirement, with equivalent configuration-set functionality continuing directly under Amazon SES.

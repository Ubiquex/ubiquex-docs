  &lt;p&gt;The current status of your Deliverability dashboard subscription. If this value is &lt;code&gt;PENDING_EXPIRATION&lt;/code&gt;, your subscription is scheduled to expire at the end of the current calendar month.&lt;/p&gt; Returned by the lookup.
</ResponseField>

<ResponseField name="active_subscribed_domains" type="list(object)">

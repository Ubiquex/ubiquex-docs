---
title: "aws_pinpoint_email_email_identities"
description: "`data_aws_pinpoint_email_email_identities` looks up a real, already-existing `aws_pinpoint_email_identity`."
---

It verifies a real sending domain or email address for use with an `aws_pinpoint_email_channel`, the SES-backed identity-verification step required before Pinpoint (or SES directly) will send mail from it.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_email_email_identities"})

    		})
    	}))
    }

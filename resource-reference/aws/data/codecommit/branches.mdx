## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	codecommit "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codecommit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codecommit_branches"})

    		ubx.Data(codecommit.Branches, "example", codecommit.BranchesConfig{
    			RepositoryName: "example-repository-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only aws --lang ts --out ./local-sdk
    import { Branches } from "./local-sdk/aws/sdk/typescript/aws/data/codecommit/branches.ts";

    export default stack("example", () => {
      intent({ summary: "look up aws_codecommit_branches" });

      data(Branches, "example", {
        repositoryName: "example-repository-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.codecommit import Branches, BranchesConfig

    def describe():
        ubx.intent("look up aws_codecommit_branches")

        ubx.data(Branches, "example", BranchesConfig(
            repository_name="example-repository-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="branches" type="list(string)">
  The real source-control branches included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

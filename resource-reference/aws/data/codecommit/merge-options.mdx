## Lookup arguments

<ResponseField name="conflict_detail_level" type="string">
  The real level of detail returned for merge conflicts. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="conflict_resolution_strategy" type="string">
  The real strategy used to resolve merge conflicts. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="destination_commit_specifier" type="string" required>
  The real, resolvable reference identifying the destination commit. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="source_commit_specifier" type="string" required>
  The real, resolvable reference identifying the source commit. **(AI-inferred)** Required lookup argument.
</ResponseField>

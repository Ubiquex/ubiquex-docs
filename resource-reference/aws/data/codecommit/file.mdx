---
title: "aws_codecommit_file"
description: "`aws_codecommit_file` reads the real content of a file at a specific commit in a CodeCommit repository."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codecommit "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codecommit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codecommit_file"})

    		ubx.Data(codecommit.File, "example", codecommit.FileConfig{
    			FilePath:        "example",
    			RepositoryName:  "example-repository-name",
    			CommitSpecifier: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    export default stack("example", () => {

      });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.codecommit import File, FileConfig

    def describe():
        ubx.intent("look up aws_codecommit_file")

        ubx.data(File, "example", FileConfig(
            file_path="example",
            repository_name="example-repository-name",
            commit_specifier="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="commit_specifier" type="string">
  The real specifier identifying the commit. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="file_path" type="string" required>
  The real path of the file. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="blob_id" type="string">
  The real, unique identifier of the blob this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="commit_id" type="string">
  The real, unique identifier of the commit this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="file_content" type="string">
  The real content of the file. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="file_mode" type="string">
  The real POSIX file mode of this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="file_size" type="number">
  The real size of the file. **(AI-inferred)** Returned by the lookup.
</ResponseField>

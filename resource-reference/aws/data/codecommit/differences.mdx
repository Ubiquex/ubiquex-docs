    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			RepositoryName:        "example-repository-name",
    			AfterPath:             "example",
    			BeforeCommitSpecifier: "example",
    			BeforePath:            "example",
    			MaxResults:            1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="after_commit_specifier" type="string" required>
  The real specifier identifying the after commit. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="after_path" type="string">
  The real path of the after. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before_commit_specifier" type="string">
  The real specifier identifying the before commit. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="before_path" type="string">
  The real path of the before. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="differences" type="list(object)">
  The real differences included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

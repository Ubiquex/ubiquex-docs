## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	codecommit "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codecommit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codecommit_folder"})

    		ubx.Data(codecommit.Folder, "example", codecommit.FolderConfig{
    			FolderPath:      "example",
    			RepositoryName:  "example-repository-name",
    			CommitSpecifier: "example",
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.codecommit import Folder, FolderConfig

    def describe():
        ubx.intent("look up aws_codecommit_folder")

        ubx.data(Folder, "example", FolderConfig(
            folder_path="example",
            repository_name="example-repository-name",
            commit_specifier="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="commit_specifier" type="string">
  The real specifier identifying the commit. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="folder_path" type="string" required>
  The real path of the folder. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="commit_id" type="string">
  The real, unique identifier of the commit this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="files" type="list(object)">
  The real files included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="sub_folders" type="list(object)">
  The real sub-folders included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="sub_modules" type="list(object)">
  The real sub-modules included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="symbolic_links" type="list(object)">
  The real symbolic links included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="tree_id" type="string">
  The real, unique identifier of the tree this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

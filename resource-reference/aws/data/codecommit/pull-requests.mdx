## Lookup arguments

<ResponseField name="author_arn" type="string">
  The real Amazon Resource Name (ARN) of the author this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="pull_request_status" type="string">
  The real, current status of the pull request this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="pull_request_ids" type="list(string)">
  The real, unique identifiers of the pull requests this request is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

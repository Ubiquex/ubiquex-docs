<ResponseField name="before_commit_id" type="string">
  The real, unique identifier of the before commit this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="pull_request_id" type="string" required>
  The real, unique identifier of the pull request this lookup is scoped to. **(AI-inferred)** Required lookup argument.

  The real name of the repository this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

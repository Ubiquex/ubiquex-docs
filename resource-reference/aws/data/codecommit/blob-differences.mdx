## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codecommit "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codecommit"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codecommit_blob_differences"})

    		ubx.Data(codecommit.BlobDifferences, "example", codecommit.BlobDifferencesConfig{
    			AfterBlobId:      "example",
    			RepositoryName:   "example-repository-name",
    			BeforeBlobId:     "example",
    			ContextLines:     1,
    			IgnoreWhitespace: true,
    			MaxResults:       1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="after_blob_id" type="string" required>
  The real, unique identifier of the after blob this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="before_blob_id" type="string">
  The real, unique identifier of the before blob this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="context_lines" type="number">
  The real, number of surrounding context lines included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ignore_whitespace" type="bool">
  Whether whitespace differences are ignored when comparing objects. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The real name of the repository this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="after_blob_size" type="number">

<ResponseField name="before_blob_size" type="number">

## Lookup arguments

<ResponseField name="comment_id" type="string" required>
  The real, unique identifier of the comment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="reaction_user_arn" type="string">
  The real Amazon Resource Name (ARN) of the reaction user this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

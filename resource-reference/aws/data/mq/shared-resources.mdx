## Example

    package main

    import (
    	mq "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/mq"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_mq_shared_resources"})

    		ubx.Data(mq.SharedResources, "example", mq.SharedResourcesConfig{
    			BrokerId:   "example",
    			MaxResults: 1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="broker_id" type="string" required>
  The real, unique identifier of the broker this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="next_token" type="string">

</ResponseField>

<ResponseField name="shared_resources" type="list(object)">

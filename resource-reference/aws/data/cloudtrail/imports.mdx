## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudtrail "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/cloudtrail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudtrail_imports"})

    		ubx.Data(cloudtrail.Imports, "example", cloudtrail.ImportsConfig{
    			Destination:  "example",
    			ImportStatus: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="destination" type="string">
  The real destination of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="import_status" type="string">
  The real, current status of the import. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="imports" type="list(object)">
  The real imports included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

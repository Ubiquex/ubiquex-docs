## Lookup arguments

<ResponseField name="event_data_store" type="string">
  The real CloudTrail event data store this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="trail_name" type="string">
  The real name of the trail this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="event_data_store_arn" type="string">
  The real Amazon Resource Name (ARN) of the event data store this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="insight_selectors" type="list(object)">
  The real CloudTrail Insights event selectors included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="insights_destination" type="string">
  The real destination configured for AWS Health insights. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="trail_arn" type="string">
  The real Amazon Resource Name (ARN) of the trail this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

`aws_cloudtrail_trails` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudtrail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudtrail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudtrail_trails"})

    		ubx.Data(cloudtrail.Trails, "example", cloudtrail.TrailsConfig{
    			IncludeShadowTrails: true,
    			TrailNameList:       []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    def describe():

        ubx.data(Trails, "example", TrailsConfig(

            trail_name_list=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

---
title: "aws_cloudtrail_trail_status"
description: "`data_aws_cloudtrail_trail_status` looks up a real, already-existing `aws_cloud_trail_trail`."
---

It captures AWS account activity as events and delivers them continuously to an S3 bucket, with optional delivery to CloudWatch Logs and EventBridge, the real, ongoing record of API calls across the console, CLI, and SDKs, as opposed to CloudTrail's own 90-day, no-setup-required Event history.

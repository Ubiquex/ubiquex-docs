---
title: "aws_cloudtrail_import"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudtrail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudtrail"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudtrail_import"})

    		ubx.Data(cloudtrail.Import, "example", cloudtrail.ImportConfig{
    			ImportId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Import } from "@ubx/sdk-aws/aws/data/cloudtrail/import";

    export default stack("example", () => {
      intent({ summary: "look up aws_cloudtrail_import" });

      data(Import, "example", {
        importId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.cloudtrail import Import, ImportConfig

    def describe():
        ubx.intent("look up aws_cloudtrail_import")

        ubx.data(Import, "example", ImportConfig(
            import_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="import_id" type="string" required>
  The real, unique identifier of the import this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

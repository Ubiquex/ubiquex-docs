`aws_cloudsearch_index_fields` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudsearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudsearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudsearch_index_fields"})

    		ubx.Data(cloudsearch.IndexFields, "example", cloudsearch.IndexFieldsConfig{
    			DomainName: "example-domain-name",
    			Deployed:   true,
    			FieldNames: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

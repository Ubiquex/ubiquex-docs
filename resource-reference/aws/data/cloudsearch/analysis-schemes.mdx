    func main() {

    			DomainName:          "example-domain-name",

    		})
    	}))
    }

## Lookup arguments

<ResponseField name="analysis_scheme_names" type="list(string)">
  The real names of the analysis schemes included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="deployed" type="bool">
  Whether this object has been deployed. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;A string that represents the name of a domain. Domain names are unique across the domains owned by an account within an AWS region. Domain names start with a letter or number and can contain the following characters: a-z (lowercase), 0-9, and - (hyphen).&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="analysis_schemes" type="list(object)">
  &lt;p&gt;A list of the analysis schemes configured for a domain.&lt;/p&gt; Returned by the lookup.
</ResponseField>

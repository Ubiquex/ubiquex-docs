`aws_cloudsearch_scaling_parameters` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudsearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cloudsearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cloudsearch_scaling_parameters"})

    		ubx.Data(cloudsearch.ScalingParameters, "example", cloudsearch.ScalingParametersConfig{
    			DomainName: "example-domain-name",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;A string that represents the name of a domain. Domain names are unique across the domains owned by an account within an AWS region. Domain names start with a letter or number and can contain the following characters: a-z (lowercase), 0-9, and - (hyphen).&lt;/p&gt; Required lookup argument.
</ResponseField>

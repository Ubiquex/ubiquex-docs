---
title: "aws_identitystore_group_membership_id"
description: "`data_aws_identitystore_group_membership_id` looks up a real, already-existing `aws_identity_store_group_membership`."
---

It adds a real user as a member of an `aws_identity_store_group`, the resource that actually grants that user whatever access has been assigned to the group.

## Example

<Tabs>
  <Tab title="Go">

    ```go
    package main

    import (
    	identitystore "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/identitystore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_identitystore_group_membership_id"})

    		ubx.Data(identitystore.GroupMembershipId, "example", identitystore.GroupMembershipIdConfig{
    			GroupId:         "example",
    			IdentityStoreId: "example",
    			MemberId:        map[string]any{"user_id": "example"},
    		})
    	}))
    }
    ```

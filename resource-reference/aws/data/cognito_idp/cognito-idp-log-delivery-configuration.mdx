---
title: "aws_cognito_idp_log_delivery_configuration"
description: "`data_aws_cognito_idp_log_delivery_configuration` looks up a real, already-existing `aws_cognito_log_delivery_configuration`."
---

It routes an `aws_cognito_user_pool`'s own real audit and activity logs, sign-in events, user notifications, by event source and log level, to a specific CloudWatch Logs log group, rather than that activity going unrecorded outside CloudTrail's own API-call logging.

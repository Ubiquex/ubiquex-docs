---
title: "aws_cognito_idp_user_pools"
description: "`data_aws_cognito_idp_user_pools` looks up a real, already-existing `aws_cognito_user_pool`."
---

It is a real, standalone user directory and OIDC identity provider, sign-up, sign-in, and federation with third-party IdPs, that issues JWTs directly to an app, independent of whether an `aws_cognito_identity_pool` is ever used alongside it.

title: "aws_cognito_idp_user_pool_clients"

It registers a real, specific application, a web app, a mobile app, a backend service, against an `aws_cognito_user_pool`, with its own allowed OAuth flows, callback URLs, and token settings, the actual identity a caller authenticates as when it talks to the user pool.

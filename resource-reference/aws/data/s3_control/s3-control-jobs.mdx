## Lookup arguments

<ResponseField name="account_id" type="string" required>
  The real, unique identifier of the AWS account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_statuses" type="list(string)">
  The real, current statuses of the jobs included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

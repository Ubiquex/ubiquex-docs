---
title: "aws_s3_control_bucket_policy"
description: "`data_aws_s3_control_bucket_policy` looks up a real, already-existing `aws_s3_bucket_policy`."
---

It attaches a real resource-based access policy to an `aws_s3_bucket`, controlling which principals, including from other accounts, can read from or write to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3_control "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/s3_control"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3_control_bucket_policy"})

    		ubx.Data(s3_control.S3ControlBucketPolicy, "example", s3_control.S3ControlBucketPolicyConfig{
    			AccountId: "example",
    			Bucket:    "example",
    		})
    	}))
    }
    ```

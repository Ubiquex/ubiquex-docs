---
title: "aws_s3_control_access_grants_instances"
description: "`data_aws_s3_control_access_grants_instances` looks up a real, already-existing `aws_s3_access_grants_instance`."
---

It creates a real, account-level S3 Access Grants instance, the resource that an `aws_s3_access_grants_location` and individual `aws_s3_access_grant`s are registered under to vend temporary, prefix-scoped S3 credentials.

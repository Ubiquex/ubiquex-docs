## Lookup arguments

<ResponseField name="account_id" type="string" required>
  The real, unique identifier of the AWS account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="replication_configuration" type="object">
  &lt;p&gt;A container for one or more replication rules. A replication configuration must have at least one rule and you can add up to 100 rules. The maximum size of a replication configuration is 128 KB.&lt;/p&gt; Returned by the lookup.

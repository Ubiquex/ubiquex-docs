---
title: "aws_s3_control_storage_lens_groups"
description: "`data_aws_s3_control_storage_lens_groups` looks up a real, already-existing `aws_s3_storage_lens_group`."
---

It defines a real, filtered subset of objects, by prefix, tag, size, or age, within an `aws_s3_storage_lens` configuration, so its metrics can be broken out for just that subset instead of only whole-bucket totals.

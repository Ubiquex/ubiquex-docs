---
title: "aws_organizations_accounts"
description: "`data_aws_organizations_accounts` looks up a real, already-existing `aws_organizations_account`."
---

It creates a real new member AWS account inside an AWS Organization, provisioned and joined to the organization directly rather than invited separately.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_organizations_accounts"})

    		ubx.Data(organizations.Accounts, "example", organizations.AccountsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

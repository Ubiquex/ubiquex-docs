---
title: "aws_organizations_resource_policy"
description: "`data_aws_organizations_resource_policy` looks up a real, already-existing `aws_organizations_resource_policy`."
---

It attaches a real resource-based policy at the AWS Organizations management account level, a narrower, newer counterpart to the identity- and OU-targeted `aws_organizations_policy`, controlling which principals can call Organizations APIs against the organization itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	organizations "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/organizations"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource policy"})

    		ubx.Resource(organizations.ResourcePolicy, "example", organizations.ResourcePolicyConfig{
    			Content: "example",
    			Tags:    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.aws.organizations import ResourcePolicy, ResourcePolicyConfig
    from ubx.aws.organizations.resource_policy import ResourcePolicy_Tags

            content="example",
            tags=[ResourcePolicy_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

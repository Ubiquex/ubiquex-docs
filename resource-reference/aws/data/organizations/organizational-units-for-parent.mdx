---
title: "aws_organizations_organizational_units_for_parent"
description: "`data_aws_organizations_organizational_units_for_parent` looks up a real, already-existing `aws_organizations_organizational_unit`."
---

It creates a real container within an AWS Organization's hierarchy that groups `aws_organizations_account`s and other OUs, so `aws_organizations_policy` resources like service control policies can be attached once and apply to everything nested under it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	discovery "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/discovery"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_discovery_agents"})

    		ubx.Data(discovery.Agents, "example", discovery.AgentsConfig{
    			AgentIds:   []string{"example"},
    			Filters:    []map[string]any{{"name": "example-name"}},
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="agent_ids" type="list(string)">
  The real, unique identifiers of the agents this request is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filters" type="list(object)">
  Real filter criteria restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

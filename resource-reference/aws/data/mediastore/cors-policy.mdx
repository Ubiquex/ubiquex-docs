`aws_mediastore_cors_policy` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    package main

    import (
    	mediastore "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/mediastore"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_mediastore_cors_policy"})

    		ubx.Data(mediastore.CorsPolicy, "example", mediastore.CorsPolicyConfig{
    			ContainerName: "example-container-name",
    		})
    	}))
    }

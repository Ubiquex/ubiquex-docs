## Lookup arguments

_This lookup takes no arguments._

## Result properties

<ResponseField name="deletion_protection" type="object">
  &lt;p&gt;A parameter to configure deletion protection. Deletion protection prevents a user from deleting a configuration profile or an environment if AppConfig has called either &lt;a href="https://docs.aws.amazon.com/appconfig/2019-10-09/APIReference/API_appconfigdata_GetLatestConfiguration.html"&gt;GetLatestConfiguration&lt;/a&gt; or for the configuration profile or from the environment during the specified interval.&lt;/p&gt; &lt;p&gt;The default interval specified by &lt;code&gt;ProtectionPeriodInMinutes&lt;/code&gt; is 60. &lt;code&gt;DeletionProtectionCheck&lt;/code&gt; skips configuration profiles and environments that were created in the past hour.&lt;/p&gt; Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Optional lookup argument.
    </ResponseField>
    <ResponseField name="protection_period_in_minutes" type="number">
      Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vended_metrics" type="object">
  &lt;p&gt;The configuration settings for vended metrics in your AppConfig account.&lt;/p&gt; Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

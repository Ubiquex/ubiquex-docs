---
title: "aws_refactor_spaces_services"
description: "`data_aws_refactor_spaces_services` looks up a real, already-existing `aws_refactor_spaces_service`."
---

It registers a real extracted microservice, and the routing rule that sends its share of an `aws_refactor_spaces_application`'s traffic to it, the mechanism Refactor Spaces uses to migrate traffic incrementally rather than all at once. Like the rest of Refactor Spaces, this closed to new customers November 7, 2025.

## Example

  <Tab title="Go">

    ```go
    package main

    import (
    	refactor_spaces "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/refactor_spaces"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_refactor_spaces_services"})

    		ubx.Data(refactor_spaces.RefactorSpacesServices, "example", refactor_spaces.RefactorSpacesServicesConfig{
    			ApplicationIdentifier: "example",
    			EnvironmentIdentifier: "example",
    			MaxResults:            1,
    		})
    	}))
    }
    ```

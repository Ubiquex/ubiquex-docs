---
title: "aws_refactor_spaces_environments"
description: "`data_aws_refactor_spaces_environments` looks up a real, already-existing `aws_refactor_spaces_environment`."
---

It creates a real top-level container, a shared transit gateway and default settings, that `aws_refactor_spaces_application`s under AWS Migration Hub Refactor Spaces are organized inside while an application is incrementally strangled apart into microservices. Refactor Spaces closed to new customers on November 7, 2025, a date roughly nine months in the past; existing customers can continue their migrations, with AWS maintaining security and reliability but adding no new features, and pointing new work toward AWS Transform (launched May 2025) instead.

---
title: "aws_refactor_spaces_applications"
description: "`data_aws_refactor_spaces_applications` looks up a real, already-existing `aws_refactor_spaces_application`."
---

It registers a real monolith application, its proxy and default route, inside an `aws_refactor_spaces_environment`, the resource that `aws_refactor_spaces_service`s are incrementally carved out of and routed to. Like the rest of Refactor Spaces, this closed to new customers November 7, 2025, with AWS recommending AWS Transform for new work.

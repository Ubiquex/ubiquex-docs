`aws_cleanrooms_ml_collaboration_trained_models` looks up a real Clean Rooms ML trained model, trained jointly across collaboration members without sharing raw data.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	cleanrooms_ml "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/cleanrooms_ml"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_cleanrooms_ml_collaboration_trained_models"})

    		ubx.Data(cleanrooms_ml.CleanroomsMlCollaborationTrainedModels, "example", cleanrooms_ml.CleanroomsMlCollaborationTrainedModelsConfig{
    			CollaborationIdentifier: "example",
    			MaxResults:              1,
    		})
    	}))
    }
    ```

## Lookup arguments

</ResponseField>

  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

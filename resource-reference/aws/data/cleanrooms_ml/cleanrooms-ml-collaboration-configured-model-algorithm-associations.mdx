`data_aws_cleanrooms_ml_collaboration_configured_model_algorithm_associations` looks up a real, already-existing `aws_clean_rooms_ml_configured_model_algorithm_association`. It associates an `aws_clean_rooms_ml_configured_model_algorithm` with a specific collaboration membership, the real grant that makes a configured algorithm usable inside one collaboration.

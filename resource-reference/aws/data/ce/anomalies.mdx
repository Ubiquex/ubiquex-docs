---
title: "aws_ce_anomalies"
description: "`data_aws_ce_anomalies` looks up a real, already-existing `aws_ce_anomaly_monitor`."
---

It watches spend segmented by AWS service, linked account, cost allocation tag, or `aws_ce_cost_category`, using machine learning to detect unusual patterns against that segment's own normal spend, the real detection engine an `aws_ce_anomaly_subscription`'s alerts are triggered by.

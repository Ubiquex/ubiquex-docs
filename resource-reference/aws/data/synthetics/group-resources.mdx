---
title: "aws_synthetics_group_resources"
description: "`data_aws_synthetics_group_resources` looks up a real, already-existing `aws_synthetics_group`."
---

It groups real `aws_synthetics_canary`s together, so their combined pass/fail status and metrics can be viewed and alarmed on as one unit rather than canary by canary.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_synthetics_group_resources"})

    		ubx.Data(synthetics.GroupResources, "example", synthetics.GroupResourcesConfig{

    			MaxResults:      1,
    		})
    	}))

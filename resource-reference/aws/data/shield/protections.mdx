---
title: "aws_shield_protections"
description: "`data_aws_shield_protections` looks up a real, already-existing `aws_shield_protection`."
---

It enables real AWS Shield Advanced protection, enhanced DDoS detection and automatic mitigation with cost protection, for a specific resource, a CloudFront distribution, Global Accelerator, ELB, or Elastic IP, beyond the automatic Shield Standard coverage every AWS customer already has.

## Example

## Lookup arguments

<ResponseField name="inclusion_filters" type="object">
  &lt;p&gt;Narrows the set of protections that the call retrieves. You can retrieve a single protection by providing its name or the ARN (Amazon Resource Name) of its protected resource. You can also retrieve all protections for a specific resource type. You can provide up to one criteria per filter type. Shield Advanced returns protections that exactly match all of the filter criteria that you provide.&lt;/p&gt; Optional lookup argument.

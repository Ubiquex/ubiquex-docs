`aws_shield_attacks` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	shield "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/shield"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_shield_attacks"})

    		ubx.Data(shield.Attacks, "example", shield.AttacksConfig{
    			EndTime:      map[string]any{"from_inclusive": "example"},
    			MaxResults:   1,
    			ResourceArns: []string{"example"},
    			StartTime:    map[string]any{"from_inclusive": "example"},
    		})
    	}))
    }
    ```

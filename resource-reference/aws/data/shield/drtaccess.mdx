---
title: "aws_shield_drtaccess"
description: "`data_aws_shield_drtaccess` looks up a real, already-existing `aws_shield_drtaccess`."
---

It grants the real AWS DDoS Response Team access to an account's resources and, optionally, its own support cases and account details, so the DRT can assist directly during an active `aws_shield_protection` incident under AWS Shield Advanced.

---
title: "aws_neptune_dbcluster_snapshots"
description: "`data_aws_neptune_dbcluster_snapshots` looks up a real, already-existing `aws_neptune_dbcluster`."
---

It creates a real Neptune Database cluster, a managed, serverless-capable graph database engine supporting Gremlin, openCypher, and SPARQL, built for transactional graph workloads like fraud detection and social-network queries, distinct from the memory-optimized analytics engine behind `aws_neptune_graph_graph`.

---
title: "aws_entityresolution_schema_mappings"
description: "`data_aws_entityresolution_schema_mappings` looks up a real, already-existing `aws_entity_resolution_schema_mapping`."
---

It defines which real input fields from an AWS Glue table an `aws_entity_resolution_matching_workflow` actually uses for matching, either a caller's own custom schema or one brought directly from an existing Glue input.

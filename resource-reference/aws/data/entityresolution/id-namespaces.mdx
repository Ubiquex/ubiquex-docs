---
title: "aws_entityresolution_id_namespaces"
description: "`data_aws_entityresolution_id_namespaces` looks up a real, already-existing `aws_entity_resolution_id_namespace`."
---

It defines a real, distinct source of entity identifiers, one party's own customer ID space, for instance, that an `aws_entity_resolution_id_mapping_workflow` maps against another namespace's own identifiers.

---
title: "aws_waf_regional_web_acls"
description: "`data_aws_waf_regional_web_acls` looks up a real, already-existing `aws_waf_web_acl`."
---

It creates a real, top-level web ACL under AWS WAF Classic (global, for CloudFront), evaluating its ordered list of `aws_waf_rule`s against every request and allowing or blocking based on the first match. AWS WAF Classic support ended September 30, 2025, roughly eleven months in the past; AWS's current, actively developed offering is `aws_wafv2_web_acl`.

---
title: "aws_bcm_dashboards_dashboards"
description: "`data_aws_bcm_dashboards_dashboards` looks up a real, already-existing `aws_bcm_dashboard`."
---

It combines multiple real cost data visualizations, Cost Explorer, Savings Plans, and Reserved Instance metrics among them, into one shareable dashboard, built and permissioned programmatically rather than reassembled by hand each time in the console.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	bcm_dashboards "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/bcm_dashboards"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_bcm_dashboards_dashboards"})

    		ubx.Data(bcm_dashboards.BcmDashboardsDashboards, "example", bcm_dashboards.BcmDashboardsDashboardsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.bcm_dashboards import BcmDashboardsDashboards, BcmDashboardsDashboardsConfig

    def describe():
        ubx.intent("look up aws_bcm_dashboards_dashboards")

        ubx.data(BcmDashboardsDashboards, "example", BcmDashboardsDashboardsConfig(
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">

<ResponseField name="dashboards" type="list(object)">

</ResponseField>

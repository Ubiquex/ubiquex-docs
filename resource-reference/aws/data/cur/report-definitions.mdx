---
title: "aws_cur_report_definitions"
description: "`data_aws_cur_report_definitions` looks up a real, already-existing `aws_cur_report_definition`."
---

It defines a real, recurring AWS Cost and Usage Report, its name, time granularity, file format, compression, and destination S3 bucket, that AWS delivers at least once a day so a caller has line-item-level billing data to analyze rather than only aggregate cost summaries.

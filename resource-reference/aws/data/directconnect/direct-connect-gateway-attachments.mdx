---
title: "aws_directconnect_direct_connect_gateway_attachments"
description: "`data_aws_directconnect_direct_connect_gateway_attachments` looks up a real, already-existing `aws_direct_connect_direct_connect_gateway`."
---

It is a real, global resource that lets a single Direct Connect connection reach multiple VPCs across different AWS accounts and Regions, aggregating what would otherwise need a separate connection or virtual interface per VPC.

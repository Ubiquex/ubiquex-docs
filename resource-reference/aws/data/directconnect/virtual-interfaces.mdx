---
title: "aws_directconnect_virtual_interfaces"
description: "`data_aws_directconnect_virtual_interfaces` looks up a real, already-existing `aws_direct_connect_private_virtual_interface`."
---

It carries real, private traffic over an `aws_direct_connect_connection` directly into a specific VPC, using a private, not public, ASN and IP addressing on the AWS side.

## Lookup arguments

<ResponseField name="connection_id" type="string">
  The real, unique identifier of the connection this lookup is scoped to. **(AI-inferred)** Optional lookup argument.

<ResponseField name="max_results" type="number">

</ResponseField>

<ResponseField name="virtual_interface_id" type="string">
  The real, unique identifier of the AWS Direct Connect virtual interface this lookup is scoped to. **(AI-inferred)** Optional lookup argument.

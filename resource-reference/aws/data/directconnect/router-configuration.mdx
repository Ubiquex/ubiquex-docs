`aws_directconnect_router_configuration` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	directconnect "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/directconnect"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_directconnect_router_configuration"})

    		ubx.Data(directconnect.RouterConfiguration, "example", directconnect.RouterConfigurationConfig{
    			VirtualInterfaceId:   "example",
    			RouterTypeIdentifier: "example",
    		})
    	}))
    }
    ```

---
title: "aws_textract_adapters"
description: "`data_aws_textract_adapters` looks up a real, already-existing `aws_textract_adapter`."
---

It creates a real, custom adapter that plugs into Amazon Textract's pretrained Queries model, trained on an organization's own annotated sample documents to improve extraction accuracy on business-specific document types beyond what the generic pretrained model recognizes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	textract "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/textract"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_textract_adapters"})

    		ubx.Data(textract.Adapters, "example", textract.AdaptersConfig{
    			AfterCreationTime:  "example",
    			BeforeCreationTime: "example",
    			MaxResults:         1,
    		})
    	}))
    }
    ```

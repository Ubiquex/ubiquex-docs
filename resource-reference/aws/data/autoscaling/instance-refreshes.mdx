`aws_autoscaling_instance_refreshes` reads the real, current status of an Auto Scaling group instance refresh, gradually replacing instances with an updated configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	autoscaling "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/autoscaling"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_autoscaling_instance_refreshes"})

    		ubx.Data(autoscaling.InstanceRefreshes, "example", autoscaling.InstanceRefreshesConfig{
    			AutoScalingGroupName: "example-auto-scaling-group-name",
    			InstanceRefreshIds:   []string{"example"},
    			MaxRecords:           1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="auto_scaling_group_name" type="string" required>

<ResponseField name="instance_refresh_ids" type="list(string)">

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

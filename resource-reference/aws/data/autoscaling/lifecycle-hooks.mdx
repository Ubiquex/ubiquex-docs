    		})
    	}))
    }

## Lookup arguments

<ResponseField name="auto_scaling_group_name" type="string" required>
  The real name of the Auto Scaling group this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="lifecycle_hook_names" type="list(string)">
  The real names of the lifecycle hooks included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="lifecycle_hooks" type="list(object)">
  The real Auto Scaling lifecycle hooks included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	autoscaling "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/autoscaling"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_autoscaling_load_balancers"})

    		ubx.Data(autoscaling.LoadBalancers, "example", autoscaling.LoadBalancersConfig{
    			AutoScalingGroupName: "example-auto-scaling-group-name",
    			MaxRecords:           1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="auto_scaling_group_name" type="string" required>

  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

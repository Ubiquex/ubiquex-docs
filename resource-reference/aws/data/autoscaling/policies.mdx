## Lookup arguments

<ResponseField name="auto_scaling_group_name" type="string">
  The real name of the Auto Scaling group this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="policy_names" type="list(string)">
  The real names of the policies included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="policy_types" type="list(string)">
  The real, discriminating types of policys this request is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

</ResponseField>

<ResponseField name="scaling_policies" type="list(object)">

</ResponseField>

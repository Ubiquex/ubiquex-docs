title: "aws_macie2_custom_data_identifiers"
description: "`data_aws_macie2_custom_data_identifiers` looks up a real, already-existing `aws_macie_custom_data_identifier`."

It defines a real, custom sensitive-data pattern, a regular expression with optional keyword and proximity rules, that Macie checks for during a scan beyond its own built-in managed data identifiers.

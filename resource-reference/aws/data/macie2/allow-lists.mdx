---
title: "aws_macie2_allow_lists"
description: "`data_aws_macie2_allow_lists` looks up a real, already-existing `aws_macie_allow_list`."
---

It defines a real list of text patterns or exact values, stored as an S3 object, that Amazon Macie should ignore when scanning for sensitive data, keeping known-benign content out of Macie's findings.

## Example

    	ubx.Main(ubx.Stack("example", func() {

---
title: "aws_macie2_findings_filters"
description: "`data_aws_macie2_findings_filters` looks up a real, already-existing `aws_macie_findings_filter`."
---

It defines real custom criteria, severity, finding type, affected resource, that either narrows which Macie findings a query returns or automatically archives findings matching those criteria, so routine noise doesn't have to be triaged by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	macie2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/macie2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_macie2_findings_filters"})

    		ubx.Data(macie2.FindingsFilters, "example", macie2.FindingsFiltersConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

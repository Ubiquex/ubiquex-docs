`aws_macie2_findings` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	macie2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/macie2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_macie2_findings"})

    		ubx.Data(macie2.Findings, "example", macie2.FindingsConfig{
    			FindingIds:   []string{"example"},
    			SortCriteria: map[string]any{"attribute_name": "example-attribute-name"},
    		})
    	}))
    }
    ```

`data_aws_route53resolver_resolver_query_log_config_association` looks up a real, already-existing `aws_route53_resolver_resolver_query_logging_config_association`. It associates a VPC with an `aws_route53_resolver_resolver_query_logging_config`, the resource that actually turns query logging on for that specific VPC's DNS traffic.

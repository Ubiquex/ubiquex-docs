---
title: "aws_route53resolver_resolver_dnssec_config"
description: "`data_aws_route53resolver_resolver_dnssec_config` looks up a real, already-existing `aws_route53_resolver_resolver_config`."
---

It configures a real, account-level Resolver setting, most commonly whether autodefined DNS rules for the AWS-provided DNS in a VPC are enabled, distinct from the per-endpoint settings on an `aws_route53_resolver_resolver_endpoint`.

---
title: "aws_route53resolver_resolver_endpoints"
description: "`data_aws_route53resolver_resolver_endpoints` looks up a real, already-existing `aws_route53_resolver_resolver_endpoint`."
---

It creates a real inbound or outbound DNS resolver endpoint in a VPC, the resource that lets on-premises DNS resolvers forward queries into that VPC, or lets the VPC forward queries out to on-premises DNS servers.

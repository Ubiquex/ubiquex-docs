---
title: "aws_route53resolver_resolver_rules"
description: "`data_aws_route53resolver_resolver_rules` looks up a real, already-existing `aws_route53_resolver_resolver_rule`."
---

It defines a real forwarding rule that sends DNS queries for a specific domain out through an `aws_route53_resolver_resolver_endpoint` to a specified on-premises or other DNS server, rather than resolving them through Route 53's own default resolution.

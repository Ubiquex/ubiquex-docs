---
title: "aws_route53resolver_resolver_rule_association"

---

It associates a real `aws_route53_resolver_resolver_rule` with a specific VPC, the resource that actually turns the rule's forwarding behavior on for that VPC's DNS queries.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_route53resolver_resolver_rule_association"})

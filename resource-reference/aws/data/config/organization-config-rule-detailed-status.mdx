---
title: "aws_config_organization_config_rule_detailed_status"
description: "`data_aws_config_organization_config_rule_detailed_status` looks up a real, already-existing `aws_config_organization_config_rule`."
---

It deploys an `aws_config_config_rule` across every account in an AWS Organization at once, the org-wide counterpart to defining and rolling out the same rule to each member account individually.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

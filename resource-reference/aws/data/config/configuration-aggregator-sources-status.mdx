---
title: "aws_config_configuration_aggregator_sources_status"
description: "`data_aws_config_configuration_aggregator_sources_status` looks up a real, already-existing `aws_config_configuration_aggregator`."
---

It pulls real AWS Config configuration and compliance data from multiple accounts and Regions into one, centralized account and Region, so a caller gets one unified inventory and compliance view instead of checking each account and Region separately.

---
title: "aws_config_stored_query"
description: "`data_aws_config_stored_query` looks up a real, already-existing `aws_config_stored_query`."
---

It saves a real, reusable SQL-like query against the current configuration state of AWS resources that AWS Config tracks, so a caller doesn't have to rewrite the same advanced query, security group rules open to 0.0.0.0/0, for instance, from scratch each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stored query"})

    		ubx.Resource(config.StoredQuery, "example", config.StoredQueryConfig{
    			QueryExpression:  "example",
    			QueryName:        "example-query-name",
    			QueryDescription: "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.config import StoredQuery, StoredQueryConfig
    from ubx.aws.config.stored_query import StoredQuery_Tags

    def describe():
        ubx.intent("example own stored query")

        ubx.resource(StoredQuery, "example", StoredQueryConfig(
            query_expression="example",
            query_name="example-query-name",
            query_description="example",
            tags=[StoredQuery_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

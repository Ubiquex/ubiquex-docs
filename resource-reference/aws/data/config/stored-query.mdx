---
title: "aws_config_stored_query"
description: "`data_aws_config_stored_query` looks up a real, already-existing `aws_config_stored_query`."
---

It saves a real, reusable SQL-like query against the current configuration state of AWS resources that AWS Config tracks, so a caller doesn't have to rewrite the same advanced query, security group rules open to 0.0.0.0/0, for instance, from scratch each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_stored_query"})

    		ubx.Data(config.StoredQuery, "example", config.StoredQueryConfig{
    			QueryName: "example-query-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    export default stack("example", () => {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.config import StoredQuery, StoredQueryConfig

    def describe():
        ubx.intent("look up aws_config_stored_query")

        ubx.data(StoredQuery, "example", StoredQueryConfig(
            query_name="example-query-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

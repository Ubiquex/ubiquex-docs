`aws_config_discovered_resources` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_discovered_resources"})

    		ubx.Data(config.DiscoveredResources, "example", config.DiscoveredResourcesConfig{
    			ResourceType:            "example",
    			IncludeDeletedResources: true,
    			Limit:                   1,
    			ResourceIds:             []string{"example"},
    			ResourceName:            "example-resource-name",
    		})
    	}))
    }
    ```

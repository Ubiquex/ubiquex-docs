---
title: "aws_config_delivery_channels"
description: "`data_aws_config_delivery_channels` looks up a real, already-existing `aws_config_delivery_channel`."
---

It tells AWS Config where to actually deliver what an `aws_config_configuration_recorder` records, a configuration snapshot and history to an S3 bucket, and change notifications to an SNS topic.

## Example

    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_delivery_channels"})

    		})
    	}))
    }

    import ubx_sdk as ubx
    from ubx.aws.data.config import DeliveryChannels, DeliveryChannelsConfig

    def describe():
        ubx.intent("look up aws_config_delivery_channels")

        ubx.data(DeliveryChannels, "example", DeliveryChannelsConfig(
            delivery_channel_names=["example"],

    if __name__ == "__main__":
        ubx.run("example", describe)

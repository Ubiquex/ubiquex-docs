---
title: "aws_config_conformance_packs"
description: "`data_aws_config_conformance_packs` looks up a real, already-existing `aws_config_conformance_pack`."
---

It bundles a real collection of `aws_config_config_rule`s and remediation actions into one deployable, monitorable unit, so an entire compliance standard's worth of rules gets rolled out and tracked together instead of one rule at a time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_conformance_packs"})

    		ubx.Data(config.ConformancePacks, "example", config.ConformancePacksConfig{
    			ConformancePackNames: []string{"example"},
    			Limit:                1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="conformance_pack_names" type="list(string)">
  The real names of the conformance packs included in this result. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="conformance_pack_details" type="list(object)">
  The real, detailed information about the conformance pack. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

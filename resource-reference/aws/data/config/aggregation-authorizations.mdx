---
title: "aws_config_aggregation_authorizations"
description: "`data_aws_config_aggregation_authorizations` looks up a real, already-existing `aws_config_aggregation_authorization`."
---

It grants a real, specific source account and Region permission to aggregate this account's AWS Config data into their own `aws_config_configuration_aggregator`, the authorization step required before cross-account aggregation can actually collect this account's data.

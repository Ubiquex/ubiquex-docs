---
title: "aws_config_connectors"
description: "`data_aws_config_connectors` looks up a real, already-existing `aws_config_connector`."
---

It connects a real third-party cloud provider's own resources to AWS Config, extending Config's compliance evaluation and configuration history beyond AWS's own resources to a genuinely multi-cloud inventory.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_connectors"})

    		ubx.Data(config.Connectors, "example", config.ConnectorsConfig{
    			Filters:    []map[string]any{{"filter_name": "example-filter-name"}},
    			MaxResults: 1,
    		})
    	}))
    }
    ```

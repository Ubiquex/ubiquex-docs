---
title: "aws_config_organization_conformance_pack_detailed_status"
description: "`data_aws_config_organization_conformance_pack_detailed_status` looks up a real, already-existing `aws_config_organization_conformance_pack`."
---

It deploys an `aws_config_conformance_pack` across every account in an AWS Organization at once, the org-wide counterpart to rolling the same conformance pack out to each member account individually.

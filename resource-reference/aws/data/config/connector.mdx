---
title: "aws_config_connector"
description: "`data_aws_config_connector` looks up a real, already-existing `aws_config_connector`."
---

It connects a real third-party cloud provider's own resources to AWS Config, extending Config's compliance evaluation and configuration history beyond AWS's own resources to a genuinely multi-cloud inventory.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_connector"})

    		ubx.Data(config.Connector, "example", config.ConnectorConfig{
    			Arn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

    if __name__ == "__main__":

---
title: "aws_config_compliance_details_by_config_rule"
description: "`data_aws_config_compliance_details_by_config_rule` looks up a real, already-existing `aws_config_config_rule`."
---

It evaluates a real AWS resource's configuration against a defined condition every time it's created, changed, or deleted, flagging the resource noncompliant and sending a notification the moment it violates the rule rather than requiring a caller to poll for drift.

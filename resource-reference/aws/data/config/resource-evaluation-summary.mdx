`aws_config_resource_evaluation_summary` reads a real, summarized result of proactively evaluating a resource's own configuration against Config rules before deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/config"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_resource_evaluation_summary"})

    		ubx.Data(config.ResourceEvaluationSummary, "example", config.ResourceEvaluationSummaryConfig{
    			ResourceEvaluationId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

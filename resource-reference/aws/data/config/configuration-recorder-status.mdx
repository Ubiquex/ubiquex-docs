---
title: "aws_config_configuration_recorder_status"
description: "`data_aws_config_configuration_recorder_status` looks up a real, already-existing `aws_config_configuration_recorder`."
---

It is the real, account-level switch that determines whether and which resource types AWS Config actually records configuration and configuration history for, the foundational resource every other AWS Config capability, rules, aggregation, remediation, depends on being turned on.

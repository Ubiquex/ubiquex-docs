---
title: "aws_config_remediation_configurations"
description: "`data_aws_config_remediation_configurations` looks up a real, already-existing `aws_config_remediation_configuration`."
---

It defines the real, automated action, typically an SSM Automation document, AWS Config runs against a resource an `aws_config_config_rule` has flagged noncompliant, closing the loop from detection to an actual fix rather than only alerting on drift.

    		})
    	}))
    }

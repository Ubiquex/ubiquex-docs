`aws_config_config_rules` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    import (
    	config "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/config"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_config_config_rules"})

    			ConfigRuleNames: []string{"example"},
    			Filters:         map[string]any{"evaluation_mode": "example"},
    		})
    	}))
    }

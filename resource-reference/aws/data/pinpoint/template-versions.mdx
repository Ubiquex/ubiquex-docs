## Lookup arguments

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="string">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="template_name" type="string" required>
  The real name of the template this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="template_type" type="string" required>
  The real, discriminating type of the template this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "aws_pinpoint_apps"
description: "`data_aws_pinpoint_apps` looks up a real, already-existing `aws_pinpoint_app`."
---

It creates a real Pinpoint project, the top-level container that channels, segments, campaigns, and templates are organized under. AWS closed Amazon Pinpoint to new customers on May 20, 2025, and the Pinpoint console and its engagement resources, endpoints, segments, campaigns, journeys, templates, and analytics, become inaccessible after October 30, 2026, a date roughly two months from now. AWS's guidance is to move engagement workloads toward Amazon Connect and other services; SMS, push, voice, and OTP delivery continue under the rebranded AWS End User Messaging, and email delivery continues under Amazon SES.

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_apps"})

    		ubx.Data(pinpoint.Apps, "example", pinpoint.AppsConfig{
    			PageSize: "example",
    			Token:    "example",
    		})
    	}))
    }
    ```

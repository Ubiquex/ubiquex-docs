## Lookup arguments

<ResponseField name="application_id" type="string" required>
  The real, unique identifier of the application this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page_size" type="string">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="token" type="string">
  An opaque pagination or continuation token from a previous response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

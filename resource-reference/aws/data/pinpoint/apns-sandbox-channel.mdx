---
title: "aws_pinpoint_apns_sandbox_channel"
description: "`data_aws_pinpoint_apns_sandbox_channel` looks up a real, already-existing `aws_pinpoint_apnsvoip_sandbox_channel`."
---

It enables the real sandbox (development/testing) counterpart to `aws_pinpoint_apnsvoip_channel`, subject to the same October 30, 2026 Pinpoint retirement.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_apns_sandbox_channel"})

    		ubx.Data(pinpoint.ApnsSandboxChannel, "example", pinpoint.ApnsSandboxChannelConfig{
    			ApplicationId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

---
title: "aws_pinpoint_channels"
description: "`data_aws_pinpoint_channels` looks up a real, already-existing `aws_pinpoint_apnssandbox_channel`."
---

It enables a real APNs sandbox (development/testing) push channel on an `aws_pinpoint_app`, the narrower, non-production counterpart to `aws_pinpoint_apnschannel`, subject to the same October 30, 2026 Pinpoint retirement.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_channels"})

    		ubx.Data(pinpoint.Channels, "example", pinpoint.ChannelsConfig{
    			ApplicationId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx

        ubx.intent("look up aws_pinpoint_channels")

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

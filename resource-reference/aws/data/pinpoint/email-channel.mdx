---
title: "aws_pinpoint_email_channel"
description: "`data_aws_pinpoint_email_channel` looks up a real, already-existing `aws_pinpoint_email_channel`."
---

It enables a real email-sending channel on an `aws_pinpoint_app`, backed by Amazon SES. Like Pinpoint's other channels, this becomes inaccessible after October 30, 2026 (roughly two months from now), but ongoing email sending capability continues directly under Amazon SES, which AWS recommends as the migration target for Pinpoint email workloads.

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/pinpoint"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_email_channel"})

    		ubx.Data(pinpoint.EmailChannel, "example", pinpoint.EmailChannelConfig{
    			ApplicationId: "example",
    		})
    	}))
    }

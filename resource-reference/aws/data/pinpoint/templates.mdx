---
title: "aws_pinpoint_templates"
description: "`data_aws_pinpoint_templates` looks up a real, already-existing `aws_pinpoint_email_template`."
---

It creates a real, reusable email template, subject line, HTML and text bodies, that an `aws_pinpoint_campaign` or direct send call can reference instead of specifying content inline, subject to the same October 30, 2026 Pinpoint retirement.

## Lookup arguments

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="string">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="prefix" type="string">
  Restricts results to objects whose key starts with this prefix. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="template_type" type="string">
  The real, discriminating type of the template this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

---
title: "aws_pinpoint_application_settings"
description: "`data_aws_pinpoint_application_settings` looks up a real, already-existing `aws_pinpoint_application_settings`."
---

It configures real account-level defaults, quiet hours, campaign hook, limits, for an `aws_pinpoint_app`, subject to the same October 30, 2026 Pinpoint retirement as the rest of its engagement surface.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_application_settings"})

    		ubx.Data(pinpoint.ApplicationSettings, "example", pinpoint.ApplicationSettingsConfig{
    			ApplicationId: "example",
    		})
    	}))
    }
    ```
  </Tab>

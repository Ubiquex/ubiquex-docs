---
title: "aws_pinpoint_in_app_messages"
description: "`data_aws_pinpoint_in_app_messages` looks up a real, already-existing `aws_pinpoint_in_app_template`."
---

It creates a real, reusable in-app message template, layout and content shown inside an application's own UI rather than as a push notification, subject to the same October 30, 2026 Pinpoint retirement.

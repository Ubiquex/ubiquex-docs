---
title: "aws_pinpoint_voice_channel"
description: "`data_aws_pinpoint_voice_channel` looks up a real, already-existing `aws_pinpoint_voice_channel`."
---

It enables a real voice-messaging channel on an `aws_pinpoint_app`, delivering automated voice calls. Like Pinpoint's other channels, this becomes inaccessible after October 30, 2026 (roughly two months from now), but voice delivery capability itself continues under the rebranded AWS End User Messaging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	pinpoint "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/pinpoint"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_pinpoint_voice_channel"})

    		ubx.Data(pinpoint.VoiceChannel, "example", pinpoint.VoiceChannelConfig{
    			ApplicationId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.pinpoint import VoiceChannel, VoiceChannelConfig

    def describe():
        ubx.intent("look up aws_pinpoint_voice_channel")

        ubx.data(VoiceChannel, "example", VoiceChannelConfig(
            application_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

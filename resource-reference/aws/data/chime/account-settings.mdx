## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	chime "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/chime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_chime_account_settings"})

    		ubx.Data(chime.AccountSettings, "example", chime.AccountSettingsConfig{
    			AccountId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

    def describe():
        ubx.intent("look up aws_chime_account_settings")

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="account_id" type="string" required>
  The real, unique identifier of the AWS account this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="account_settings" type="object">
  &lt;p&gt;Settings related to the Amazon Chime account. This includes settings that start or stop remote control of shared screens, or start or stop the dial-out option in the Amazon Chime web application. For more information about these settings, see &lt;a href="https://docs.aws.amazon.com/chime/latest/ag/policies.html"&gt;Use the Policies Page&lt;/a&gt; in the &lt;i&gt;Amazon Chime Administration Guide&lt;/i&gt;.&lt;/p&gt; Returned by the lookup.

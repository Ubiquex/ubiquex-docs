---
title: "aws_lambda_resource_policy"
description: "`data_aws_lambda_resource_policy` looks up a real, already-existing `aws_lambda_resource_policy`."
---

It attaches a real resource-based access policy directly to an `aws_lambda_function`, a lower-level, full-document alternative to granting individual permissions one at a time through `aws_lambda_permission`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lambda "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/lambda"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lambda_resource_policy"})

    		ubx.Data(lambda.ResourcePolicy, "example", lambda.ResourcePolicyConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

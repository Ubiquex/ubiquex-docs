---
title: "aws_transfer_host_keys"
description: "`data_aws_transfer_host_keys` looks up a real, already-existing `aws_transfer_host_key`."
---

It imports a real SSH host key into an `aws_transfer_server`, letting an organization present its own, previously trusted host key fingerprint to clients instead of the one Transfer Family generates by default.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	transfer "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/transfer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_transfer_host_keys"})

    		ubx.Data(transfer.HostKeys, "example", transfer.HostKeysConfig{
    			ServerId:   "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

<ResponseField name="server_id" type="string" required>

## Result properties

<ResponseField name="host_keys" type="list(object)">

</ResponseField>

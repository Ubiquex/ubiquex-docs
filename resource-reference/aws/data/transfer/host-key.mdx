`aws_transfer_host_key` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    ```go
    package main

    import (
    	transfer "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/transfer"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_transfer_host_key"})

    		ubx.Data(transfer.HostKey, "example", transfer.HostKeyConfig{
    			HostKeyId: "example",
    			ServerId:  "example",
    		})
    	}))
    }
    ```

---
title: "aws_transfer_host_key"
description: "`data_aws_transfer_host_key` looks up a real, already-existing `aws_transfer_host_key`."
---

It imports a real SSH host key into an `aws_transfer_server`, letting an organization present its own, previously trusted host key fingerprint to clients instead of the one Transfer Family generates by default.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	transfer "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/transfer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_transfer_host_key"})

    		ubx.Data(transfer.HostKey, "example", transfer.HostKeyConfig{
    			HostKeyId: "example",
    			ServerId:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { HostKey } from "@ubx/sdk-aws/aws/data/transfer/host_key";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.transfer import HostKey, HostKeyConfig

    def describe():
        ubx.intent("look up aws_transfer_host_key")

        ubx.data(HostKey, "example", HostKeyConfig(
            host_key_id="example",
            server_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="host_key_id" type="string" required>

  The real, unique identifier of the server this lookup is scoped to. **(AI-inferred)** Required lookup argument.

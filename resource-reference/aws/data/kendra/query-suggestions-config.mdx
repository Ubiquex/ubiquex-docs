---
title: "aws_kendra_query_suggestions_config"
description: "`data_aws_kendra_query_suggestions_config` looks up a real, already-existing `aws_kendra_query_suggestions_block_list`."
---

It blocks specific real terms from appearing in an `aws_kendra_index`'s own autocomplete query suggestions, without removing the underlying documents that contain them from search results entirely.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kendra_query_suggestions_config"})

    		ubx.Data(kendra.QuerySuggestionsConfig, "example", kendra.QuerySuggestionsConfigConfig{
    			IndexId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.kendra import QuerySuggestionsConfig, QuerySuggestionsConfigConfig

    def describe():

        ubx.data(QuerySuggestionsConfig, "example", QuerySuggestionsConfigConfig(
            index_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

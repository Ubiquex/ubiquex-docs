---
title: "aws_kendra_query_suggestions"
description: "`data_aws_kendra_query_suggestions` looks up a real, already-existing `aws_kendra_query_suggestions_block_list`."
---

It blocks specific real terms from appearing in an `aws_kendra_index`'s own autocomplete query suggestions, without removing the underlying documents that contain them from search results entirely.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kendra_query_suggestions"})

    		ubx.Data(kendra.QuerySuggestions, "example", kendra.QuerySuggestionsConfig_{
    			IndexId:                    "example",
    			QueryText:                  "example",
    			AttributeSuggestionsConfig: map[string]any{"additional_response_attributes": []string{"example"}},
    			MaxSuggestionsCount:        1,
    			SuggestionTypes:            []string{"example"},
    		})
    	}))
    }
    ```

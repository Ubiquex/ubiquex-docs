---
title: "aws_kendra_data_sources"
description: "`data_aws_kendra_data_sources` looks up a real, already-existing `aws_kendra_data_source`."
---

It connects a real content repository, S3, SharePoint, Confluence, a website, to an `aws_kendra_index`, so Kendra can crawl and index its content rather than a caller uploading documents by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kendra_data_sources"})

    		ubx.Data(kendra.DataSources, "example", kendra.DataSourcesConfig{
    			IndexId:    "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.kendra import DataSources, DataSourcesConfig

    def describe():
        ubx.intent("look up aws_kendra_data_sources")

        ubx.data(DataSources, "example", DataSourcesConfig(
            index_id="example",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

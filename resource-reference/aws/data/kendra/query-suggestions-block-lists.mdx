---
title: "aws_kendra_query_suggestions_block_lists"
description: "`data_aws_kendra_query_suggestions_block_lists` looks up a real, already-existing `aws_kendra_query_suggestions_block_list`."
---

It blocks specific real terms from appearing in an `aws_kendra_index`'s own autocomplete query suggestions, without removing the underlying documents that contain them from search results entirely.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kendra_query_suggestions_block_lists"})

    		ubx.Data(kendra.QuerySuggestionsBlockLists, "example", kendra.QuerySuggestionsBlockListsConfig{
    			IndexId:    "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

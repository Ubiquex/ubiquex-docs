    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kendra_snapshots"})

    			Interval:   "example",
    			MetricType: "example",
    			MaxResults: 1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="index_id" type="string" required>
  The real, unique identifier of the index this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="interval" type="string" required>
  The real time interval results are aggregated over. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="metric_type" type="string" required>
  The real, discriminating type of the metric this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

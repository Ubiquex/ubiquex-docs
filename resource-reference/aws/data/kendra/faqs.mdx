---
title: "aws_kendra_faqs"
description: "`data_aws_kendra_faqs` looks up a real, already-existing `aws_kendra_faq`."
---

It loads a real, structured set of question-and-answer pairs directly into an `aws_kendra_index`, so an exact FAQ match can be surfaced with high confidence rather than relying only on Kendra's own document-search relevance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kendra "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/kendra"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_kendra_faqs"})

    		ubx.Data(kendra.Faqs, "example", kendra.FaqsConfig{
    			IndexId:    "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Faqs } from "@ubx/sdk-aws/aws/data/kendra/faqs";

    export default stack("example", () => {
      intent({ summary: "look up aws_kendra_faqs" });

      data(Faqs, "example", {
        indexId: "example",
        maxResults: 1,

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.kendra import Faqs, FaqsConfig

    def describe():
        ubx.intent("look up aws_kendra_faqs")

        ubx.data(Faqs, "example", FaqsConfig(
            index_id="example",
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="index_id" type="string" required>
  The real, unique identifier of the index this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="faq_summary_items" type="list(object)">
  The real, summarized frequently asked question entries included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

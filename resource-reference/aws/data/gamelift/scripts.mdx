---
title: "aws_gamelift_scripts"
description: "`data_aws_gamelift_scripts` looks up a real, already-existing `aws_game_lift_script`."
---

It uploads real server-side logic for GameLift Realtime Servers, a lighter-weight alternative to `aws_game_lift_build`'s full custom executable for game logic that fits GameLift's own managed network layer.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gamelift "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/gamelift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_gamelift_scripts"})

    		ubx.Data(gamelift.Scripts, "example", gamelift.ScriptsConfig{
    			Limit: 1,
    		})
    	}))
    }
    ```

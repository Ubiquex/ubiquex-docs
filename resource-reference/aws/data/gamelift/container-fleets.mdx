---
title: "aws_gamelift_container_fleets"
description: "`data_aws_gamelift_container_fleets` looks up a real, already-existing `aws_game_lift_container_fleet`."
---

It runs real, containerized game server applications, defined by an `aws_game_lift_container_group_definition`, on managed EC2 instances, GameLift's container-native alternative to `aws_game_lift_fleet`'s own executable-based deployment model.

---
title: "aws_gamelift_game_session_details"
description: "`data_aws_gamelift_game_session_details` looks up a real, already-existing `aws_game_lift_game_session_queue`."
---

It routes a real player's game session placement request to whichever `aws_game_lift_fleet`, across multiple fleets and locations, can host it fastest or cheapest, according to the queue's own defined priority order.

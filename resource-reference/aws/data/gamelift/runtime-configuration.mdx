`aws_gamelift_runtime_configuration` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="runtime_configuration" type="object">
  &lt;p&gt;A set of instructions that define the set of server processes to run on computes in a fleet. Server processes run either an executable in a custom game build or a Amazon GameLift Servers Realtime script. Amazon GameLift Servers launches the processes, manages their life cycle, and replaces them as needed. Computes check regularly for an updated runtime configuration. &lt;/p&gt; &lt;p&gt;An Amazon GameLift Servers instance is limited to 50 processes running concurrently. To calculate the total number of processes defined in a runtime configuration, add the values of the &lt;code&gt;ConcurrentExecutions&lt;/code&gt; parameter for each server process. Learn more about &lt;a href="https://docs.aws.amazon.com/gamelift/latest/developerguide/fleets-multiprocess.html"&gt; Running Multiple Processes on a Fleet&lt;/a&gt;.&lt;/p&gt; Returned by the lookup.

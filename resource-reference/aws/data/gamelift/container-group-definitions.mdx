---
title: "aws_gamelift_container_group_definitions"
description: "`data_aws_gamelift_container_group_definitions` looks up a real, already-existing `aws_game_lift_container_group_definition`."
---

It is the real, versioned blueprint an `aws_game_lift_container_fleet` deploys from, which container images to run per instance and how, game-server containers plus any supporting per-instance containers like logging or background services.

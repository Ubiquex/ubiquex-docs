## Result properties

<ResponseField name="game_session_placement" type="object">
  &lt;p&gt;Represents a potential game session placement, including the full details of the original placement request and the current status. &lt;/p&gt; &lt;note&gt; &lt;p&gt;If the game session placement status is &lt;code&gt;PENDING&lt;/code&gt;, the properties for game session ID/ARN, region, IP address/DNS, and port aren't final. A game session is not active and ready to accept players until placement status reaches &lt;code&gt;FULFILLED&lt;/code&gt;. When the placement is in &lt;code&gt;PENDING&lt;/code&gt; status, Amazon GameLift Servers may attempt to place a game session multiple times before succeeding. With each attempt it creates a &lt;a href="https://docs.aws.amazon.com/gamelift/latest/apireference/API_GameSession"&gt;https://docs.aws.amazon.com/gamelift/latest/apireference/API_GameSession&lt;/a&gt; object and updates this placement object with the new game session properties.&lt;/p&gt; &lt;/note&gt; Returned by the lookup.

---
title: "aws_gamelift_game_servers"
description: "`data_aws_gamelift_game_servers` looks up a real, already-existing `aws_game_lift_game_server_group`."
---

It runs GameLift FleetIQ on top of a real, self-managed EC2 Auto Scaling group, optimizing for Spot Instance savings while protecting instances that are still hosting active game sessions from early termination.

---
title: "aws_gamelift_fleets"
description: "`data_aws_gamelift_fleets` looks up a real, already-existing `aws_game_lift_fleet`."
---

It provisions real EC2 instances running an `aws_game_lift_build`'s game server executable, GameLift's original, EC2-based compute model for hosting multiplayer game sessions at scale.

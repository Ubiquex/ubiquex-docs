---
title: "aws_gamelift_builds"
description: "`data_aws_gamelift_builds` looks up a real, already-existing `aws_game_lift_build`."
---

It uploads a real, packaged game server executable and its dependencies to GameLift, the actual software an `aws_game_lift_fleet`'s EC2 instances run to host game sessions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gamelift "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/gamelift"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_gamelift_builds"})

    		ubx.Data(gamelift.Builds, "example", gamelift.BuildsConfig{
    			Limit:  1,
    			Status: "example",
    		})
    	}))
    }
    ```

## Example

    package main

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_opensearch_packages_for_domain"})

    		ubx.Data(opensearch.PackagesForDomain, "example", opensearch.PackagesForDomainConfig{

    			MaxResults: 1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;The name of an OpenSearch Service domain. Domain names are unique across the domains owned by an account within an Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt;An optional parameter that specifies the maximum number of results to return for a given request.&lt;/p&gt; Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="domain_package_details_list" type="list(object)">
  The real, detailed domain packages included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  &lt;p&gt;When &lt;code&gt;nextToken&lt;/code&gt; is returned, there are more results available. The value of &lt;code&gt;nextToken&lt;/code&gt; is a unique pagination token for each page. Send the request again using the returned token to retrieve the next page.&lt;/p&gt; Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	opensearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/opensearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_opensearch_domain_nodes"})

    		ubx.Data(opensearch.DomainNodes, "example", opensearch.DomainNodesConfig{
    			DomainName: "example-domain-name",
    		})
    	}))
    }
    ```

        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;The name of an OpenSearch Service domain. Domain names are unique across the domains owned by an account within an Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="domain_nodes_status_list" type="list(object)">
  &lt;p&gt;List of &lt;code&gt;DomainNodesStatus&lt;/code&gt; with details about nodes on the requested domain.&lt;/p&gt; Returned by the lookup.
</ResponseField>

---
title: "aws_opensearch_versions"
description: "`aws_opensearch_versions` reads the real OpenSearch or Elasticsearch versions available for creating a new domain."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	opensearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/opensearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_opensearch_versions"})

    		ubx.Data(opensearch.Versions, "example", opensearch.VersionsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Versions } from "@ubx/sdk-aws/aws/data/opensearch/versions";

    export default stack("example", () => {
      intent({ summary: "look up aws_opensearch_versions" });

      data(Versions, "example", {
        maxResults: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.opensearch import Versions, VersionsConfig

    def describe():
        ubx.intent("look up aws_opensearch_versions")

        ubx.data(Versions, "example", VersionsConfig(
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="max_results" type="number">
  &lt;p&gt;An optional parameter that specifies the maximum number of results to return for a given request.&lt;/p&gt; Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  &lt;p&gt;When &lt;code&gt;nextToken&lt;/code&gt; is returned, there are more results available. The value of &lt;code&gt;nextToken&lt;/code&gt; is a unique pagination token for each page. Send the request again using the returned token to retrieve the next page.&lt;/p&gt; Returned by the lookup.
</ResponseField>

<ResponseField name="versions" type="list(string)">
  &lt;p&gt;List of supported OpenSearch versions.&lt;/p&gt; Returned by the lookup.
</ResponseField>

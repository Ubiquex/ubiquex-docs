---
title: "aws_opensearch_tags"
description: "`aws_opensearch_tags` reads the real tags applied to an OpenSearch resource."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	opensearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/opensearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_opensearch_tags"})

    		ubx.Data(opensearch.Tags, "example", opensearch.TagsConfig{
    			Arn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Tags } from "@ubx/sdk-aws/aws/data/opensearch/tags";

    export default stack("example", () => {
      intent({ summary: "look up aws_opensearch_tags" });

      data(Tags, "example", {
        arn: "arn:aws:iam::123456789012:policy/example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.opensearch import Tags, TagsConfig

    def describe():
        ubx.intent("look up aws_opensearch_tags")

        ubx.data(Tags, "example", TagsConfig(
            arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="arn" type="string" required>
  &lt;p&gt;The Amazon Resource Name (ARN) of the domain. See &lt;a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/index.html"&gt;Identifiers for IAM Entities &lt;/a&gt; in &lt;i&gt;Using Amazon Web Services Identity and Access Management&lt;/i&gt; for more information. &lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="tag_list" type="list(object)">
  &lt;p&gt;A list of tags attached to a domain.&lt;/p&gt; Returned by the lookup.
</ResponseField>

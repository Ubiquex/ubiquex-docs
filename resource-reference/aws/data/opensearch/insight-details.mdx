## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	opensearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/opensearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_opensearch_insight_details"})

    		ubx.Data(opensearch.InsightDetails, "example", opensearch.InsightDetailsConfig{
    			Entity:          map[string]any{"type": "example"},
    			InsightId:       "example",
    			ShowHtmlContent: true,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="entity" type="object" required>
  &lt;p&gt;Specifies the entity for which to retrieve insights. An entity can be an Amazon OpenSearch Service domain or an Amazon Web Services account.&lt;/p&gt; Required lookup argument.
  <Expandable title="properties">
    <ResponseField name="type" type="string" required>
      &lt;p&gt;The type of entity for which to retrieve insights. Possible values are &lt;code&gt;Account&lt;/code&gt; and &lt;code&gt;DomainName&lt;/code&gt;.&lt;/p&gt; Required lookup argument.
    </ResponseField>
    <ResponseField name="value" type="string">
      &lt;p&gt;The value of the entity, such as a domain name or Amazon Web Services account ID.&lt;/p&gt; Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="insight_id" type="string" required>
  The real, unique identifier of the insight this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="show_html_content" type="bool">
  The real content of the show html. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="fields" type="list(object)">
  &lt;p&gt;A list of insight fields.&lt;/p&gt; Returned by the lookup.
</ResponseField>

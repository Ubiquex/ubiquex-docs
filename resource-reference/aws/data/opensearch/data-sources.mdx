## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	opensearch "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/opensearch"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_opensearch_data_sources"})

    		ubx.Data(opensearch.DataSources, "example", opensearch.DataSourcesConfig{
    			DomainName: "example-domain-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.opensearch import DataSources, DataSourcesConfig

    def describe():
        ubx.intent("look up aws_opensearch_data_sources")

        ubx.data(DataSources, "example", DataSourcesConfig(
            domain_name="example-domain-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;The name of an OpenSearch Service domain. Domain names are unique across the domains owned by an account within an Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data_sources" type="list(object)">
  The real data sources included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

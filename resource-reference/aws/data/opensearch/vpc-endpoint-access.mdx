## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;The name of an OpenSearch Service domain. Domain names are unique across the domains owned by an account within an Amazon Web Services Region.&lt;/p&gt; Required lookup argument.
</ResponseField>

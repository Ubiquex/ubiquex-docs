---
title: "aws_servicequotas_services"
description: "`data_aws_servicequotas_services` looks up a real, already-existing `aws_service_discovery_service`."
---

It defines a real, discoverable service name within a namespace, `aws_service_discovery_http_namespace`, `aws_service_discovery_private_dns_namespace`, or `aws_service_discovery_public_dns_namespace`, that `aws_service_discovery_instance`s register themselves under.

## Example

    import (
    	servicequotas "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/servicequotas"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_servicequotas_services"})

    		ubx.Data(servicequotas.Services, "example", servicequotas.ServicesConfig{
    			MaxResults: 1,
    		})
    	}))
    }

`data_aws_observabilityadmin_centralization_rules_for_organization` looks up a real, already-existing `aws_observability_admin_organization_centralization_rule`. It defines a real, organization-wide rule that routes telemetry, logs by source and type, from member accounts to a chosen central destination account, with granular control over which data centralizes versus stays local.

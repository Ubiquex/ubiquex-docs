---
title: "aws_observabilityadmin_telemetry_enrichment_status"
description: "`data_aws_observabilityadmin_telemetry_enrichment_status` looks up a real, already-existing `aws_observability_admin_telemetry_enrichment`."
---

It configures real, additional AWS context, resource tags or account metadata, automatically attached to telemetry data governed by an `aws_observability_admin_telemetry_rule`, without each individual signal needing to carry that context itself.

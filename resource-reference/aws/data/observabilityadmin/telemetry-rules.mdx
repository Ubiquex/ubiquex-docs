---
title: "aws_observabilityadmin_telemetry_rules"
description: "`data_aws_observabilityadmin_telemetry_rules` looks up a real, already-existing `aws_observability_admin_telemetry_rule`."
---

It defines a real rule specifying which AWS resources, by type and selection criteria, should have telemetry collection enabled and how, giving CloudWatch Observability Admin a way to audit and enforce telemetry configuration across an account.

    func main() {

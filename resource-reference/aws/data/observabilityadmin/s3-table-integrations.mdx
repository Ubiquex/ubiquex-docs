---
title: "aws_observabilityadmin_s3_table_integrations"
description: "`data_aws_observabilityadmin_s3_table_integrations` looks up a real, already-existing `aws_observability_admin_s3_table_integration`."
---

It configures a real integration that routes an account's or organization's telemetry data into S3 Tables under CloudWatch Observability Admin, for long-term, queryable storage outside CloudWatch itself.

---
title: "aws_s3_object_attributes"
description: "`aws_s3_object_attributes` reads real, selected attributes (ETag, size, checksum, parts) of an S3 object without fetching its full content."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3_object_attributes"})

    		ubx.Data(s3.ObjectAttributes, "example", s3.ObjectAttributesConfig{
    			Bucket:               "example",
    			Key:                  "example",
    			ObjectAttributes:     []string{"example"},
    			ExpectedBucketOwner:  "example",
    			MaxParts:             1,
    			PartNumberMarker:     "example",
    			RequestPayer:         "example",
    			SsecustomerAlgorithm: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The real AWS account ID expected to own the S3 bucket, for cross-account request validation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="key" type="string" required>
  The real, unique key of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_parts" type="number">
  The real, maximum number of parts to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="object_attributes" type="list(string)" required>
  The real, structured attributes of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="part_number_marker" type="string">
  An opaque pagination token, requesting the next page of upload part results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="request_payer" type="string">
  &lt;p&gt;Confirms that the requester knows that they will be charged for the request. Bucket owners need not specify this parameter in their requests. If either the source or destination S3 bucket has Requester Pays enabled, the requester will pay for the corresponding charges. For information about downloading objects from Requester Pays buckets, see &lt;a href="https://docs.aws.amazon.com/AmazonS3/latest/dev/ObjectsinRequesterPaysBuckets.html"&gt;Downloading Objects in Requester Pays Buckets&lt;/a&gt; in the &lt;i&gt;Amazon S3 User Guide&lt;/i&gt;.&lt;/p&gt; &lt;note&gt; &lt;p&gt;This functionality is not supported for directory buckets.&lt;/p&gt; &lt;/note&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="ssecustomer_algorithm" type="string">
  The real server-side encryption algorithm used with the customer-provided key. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ssecustomer_key" type="string">
  The real, unique key of the ssecustomer this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="ssecustomer_key_md5" type="string">
  The real, base64-encoded MD5 digest of the customer-provided server-side encryption key. **(AI-inferred)** Optional lookup argument.
</ResponseField>

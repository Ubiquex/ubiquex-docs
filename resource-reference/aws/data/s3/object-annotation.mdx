## Lookup arguments

<ResponseField name="annotation_name" type="string" required>
  The real name of the annotation this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="checksum_mode" type="string">
  The real, requested mode for including this object's own checksum in the response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The real AWS account ID expected to own the S3 bucket, for cross-account request validation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="key" type="string" required>
  The real, unique key of this object. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="request_payer" type="string">
  &lt;p&gt;Confirms that the requester knows that they will be charged for the request. Bucket owners need not specify this parameter in their requests. If either the source or destination S3 bucket has Requester Pays enabled, the requester will pay for the corresponding charges. For information about downloading objects from Requester Pays buckets, see &lt;a href="https://docs.aws.amazon.com/AmazonS3/latest/dev/ObjectsinRequesterPaysBuckets.html"&gt;Downloading Objects in Requester Pays Buckets&lt;/a&gt; in the &lt;i&gt;Amazon S3 User Guide&lt;/i&gt;.&lt;/p&gt; &lt;note&gt; &lt;p&gt;This functionality is not supported for directory buckets.&lt;/p&gt; &lt;/note&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="version_id" type="string">
  The real, unique version identifier of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

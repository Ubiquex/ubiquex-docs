## Example

  <Tab title="Go">
    ```go
    package main

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3_bucket_lifecycle_configuration"})

    		ubx.Data(s3.BucketLifecycleConfiguration, "example", s3.BucketLifecycleConfigurationConfig{
    			Bucket:              "example",
    			ExpectedBucketOwner: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The real AWS account ID expected to own the S3 bucket, for cross-account request validation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="rules" type="list(object)">
  The real rules included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="transition_default_minimum_object_size" type="string">
  The real size of the transition default minimum object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

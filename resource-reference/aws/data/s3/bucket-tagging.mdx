---
title: "aws_s3_bucket_tagging"
description: "`data_aws_s3_bucket_tagging` looks up a real, already-existing `aws_s3_bucket`."
---

It creates the bucket itself. Versioning, encryption, public-access blocking, and lifecycle rules are each their own separate resource, attached to this bucket by reference, real Terraform provider behavior since v4.

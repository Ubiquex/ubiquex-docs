---
title: "aws_s3_bucket_policy_status"
description: "`data_aws_s3_bucket_policy_status` looks up a real, already-existing `aws_s3_bucket_policy`."
---

It attaches a real resource-based access policy to an `aws_s3_bucket`, controlling which principals, including from other accounts, can read from or write to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3_bucket_policy_status"})

    		ubx.Data(s3.BucketPolicyStatus, "example", s3.BucketPolicyStatusConfig{
    			Bucket:              "example",
    			ExpectedBucketOwner: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The real AWS account ID expected to own the S3 bucket, for cross-account request validation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

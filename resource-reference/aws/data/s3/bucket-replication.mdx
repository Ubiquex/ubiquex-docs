---
title: "aws_s3_bucket_replication"
description: "`data_aws_s3_bucket_replication` looks up a real, already-existing `aws_s3_bucket`."
---

It creates the bucket itself. Versioning, encryption, public-access blocking, and lifecycle rules are each their own separate resource, attached to this bucket by reference, real Terraform provider behavior since v4.

## Example

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/s3"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3_bucket_replication"})

    		ubx.Data(s3.BucketReplication, "example", s3.BucketReplicationConfig{
    			Bucket:              "example",
    			ExpectedBucketOwner: "example",
    		})

    }

## Lookup arguments

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The real AWS account ID expected to own the S3 bucket, for cross-account request validation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

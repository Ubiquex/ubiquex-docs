---
title: "aws_s3_buckets"
description: "`data_aws_s3_buckets` looks up a real, already-existing `aws_s3_bucket`."
---

It creates the bucket itself. Versioning, encryption, public-access blocking, and lifecycle rules are each their own separate resource, attached to this bucket by reference, real Terraform provider behavior since v4.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3_buckets"})

    		ubx.Data(s3.Buckets, "example", s3.BucketsConfig{
    			BucketRegion: "example",
    			MaxBuckets:   1,
    		})
    	}))
    }
    ```

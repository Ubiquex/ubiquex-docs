## Lookup arguments

<ResponseField name="bucket" type="string" required>
  The real name of the S3 bucket this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The real AWS account ID expected to own the S3 bucket, for cross-account request validation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

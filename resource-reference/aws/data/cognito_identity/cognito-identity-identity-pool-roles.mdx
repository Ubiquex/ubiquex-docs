---
title: "aws_cognito_identity_identity_pool_roles"
description: "`data_aws_cognito_identity_identity_pool_roles` looks up a real, already-existing `aws_cognito_identity_pool_role_attachment`."
---

It maps real IAM roles to an `aws_cognito_identity_pool`, by default role, by rules against a user's claims, or by their `aws_cognito_user_pool_group` membership, the actual configuration that determines which role a user gets credentials for.

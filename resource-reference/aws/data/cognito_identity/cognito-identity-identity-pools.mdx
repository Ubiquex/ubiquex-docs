---
title: "aws_cognito_identity_identity_pools"
description: "`data_aws_cognito_identity_identity_pools` looks up a real, already-existing `aws_cognito_identity_pool`."
---

It issues real, temporary AWS credentials, via AWS STS, to authenticated or guest users, accepting claims from an `aws_cognito_user_pool`, a SAML 2.0 provider, or a social identity provider, independent of whether a user pool is used alongside it.

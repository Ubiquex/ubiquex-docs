## Lookup arguments

<ResponseField name="hide_disabled" type="bool">
  Whether disabled items are hidden from the results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="identity_pool_id" type="string" required>
  The real, unique identifier of the Amazon Cognito identity pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number" required>
  The maximum number of results to return in a single page. **(AI-inferred)** Required lookup argument.
</ResponseField>

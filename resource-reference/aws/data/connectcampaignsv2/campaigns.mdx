---
title: "aws_connectcampaignsv2_campaigns"
description: "`data_aws_connectcampaignsv2_campaigns` looks up a real, already-existing `aws_connect_campaigns_v2_campaign`."
---

It is Outbound Campaigns V2, the real, actively developed successor to `aws_connect_campaigns_campaign` with multi-channel (voice, SMS, email, WhatsApp) and visual journey-builder support that V1 doesn't have.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	connectcampaignsv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/connectcampaignsv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_connectcampaignsv2_campaigns"})

    		ubx.Data(connectcampaignsv2.Campaigns, "example", connectcampaignsv2.CampaignsConfig{
    			Filters:    map[string]any{"instance_id_filter": map[string]any{"operator": "example", "value": "example"}},
    			MaxResults: 1,
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx
    from ubx.aws.data.connectcampaignsv2 import Campaigns, CampaignsConfig
    from ubx.aws.data.connectcampaignsv2.campaigns import Campaigns_Filters, Campaigns_Filters_InstanceIdFilter

    def describe():
        ubx.intent("look up aws_connectcampaignsv2_campaigns")

        ubx.data(Campaigns, "example", CampaignsConfig(
            filters=Campaigns_Filters(instance_id_filter=Campaigns_Filters_InstanceIdFilter(operator="example", value="example")),
            max_results=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="filters" type="object">
  Filter model by type Optional lookup argument.
  <Expandable title="properties">
    <ResponseField name="instance_id_filter" type="object">
      Connect instance identifier filter Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="operator" type="string" required>
          Operators for Connect instance identifier filter Required lookup argument.
        </ResponseField>
        <ResponseField name="value" type="string" required>
          Amazon Connect Instance Id Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return per page. Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="campaign_summary_list" type="list(object)">
  A list of Amazon Connect campaigns. Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  The token for the next set of results. Returned by the lookup.
</ResponseField>

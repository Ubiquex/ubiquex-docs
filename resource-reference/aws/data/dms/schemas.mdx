## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dms "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/dms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dms_schemas"})

    		ubx.Data(dms.Schemas, "example", dms.SchemasConfig{
    			EndpointArn: "arn:aws:iam::123456789012:policy/example",
    			MaxRecords:  1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    import ubx_sdk as ubx
    from ubx.aws.data.dms import Schemas, SchemasConfig

    def describe():
        ubx.intent("look up aws_dms_schemas")

        ubx.data(Schemas, "example", SchemasConfig(
            endpoint_arn="arn:aws:iam::123456789012:policy/example",
            max_records=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="endpoint_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the endpoint this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

</ResponseField>

<ResponseField name="schemas" type="list(string)">

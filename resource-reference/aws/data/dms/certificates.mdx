---
title: "aws_dms_certificates"
description: "`data_aws_dms_certificates` looks up a real, already-existing `aws_dms_certificate`."
---

It imports a real SSL certificate into AWS DMS, used by an `aws_dms_endpoint` to encrypt its connection to a source or target database that requires certificate-based authentication.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dms "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/dms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dms_certificates"})

    		ubx.Data(dms.Certificates, "example", dms.CertificatesConfig{
    			Filters:    []map[string]any{{"name": "example-name"}},
    			MaxRecords: 1,
    		})
    	}))
    }
    ```

---
title: "aws_dms_endpoint_settings"
description: "`data_aws_dms_endpoint_settings` looks up a real, already-existing `aws_dms_endpoint`."
---

It defines the real connection details, engine type, credentials, and location, for one source or target database that an `aws_dms_replication_task` or `aws_dms_replication_config` actually migrates data to or from.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_dms_endpoint_settings"})

    		ubx.Data(dms.EndpointSettings, "example", dms.EndpointSettingsConfig{
    			EngineName: "example-engine-name",
    			MaxRecords: 1,
    		})
    	}))
    }

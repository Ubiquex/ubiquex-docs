---
title: "aws_dms_replication_instance_task_logs"
description: "`data_aws_dms_replication_instance_task_logs` looks up a real, already-existing `aws_dms_replication_instance`."
---

It is the real, managed compute that actually runs an `aws_dms_replication_task`'s migration or ongoing change-data-capture work between its source and target `aws_dms_endpoint`s.

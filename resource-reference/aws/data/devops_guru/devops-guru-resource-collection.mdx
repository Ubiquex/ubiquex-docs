---
title: "aws_devops_guru_resource_collection"
description: "`data_aws_devops_guru_resource_collection` looks up a real, already-existing `aws_dev_ops_guru_resource_collection`."
---

It scopes which real AWS resources, identified by CloudFormation stack or by tag, DevOps Guru actually analyzes CloudWatch metrics and CloudTrail events for, so anomaly detection covers the resources that matter rather than every resource in the account indiscriminately.

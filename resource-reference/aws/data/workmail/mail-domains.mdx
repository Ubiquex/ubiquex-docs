`aws_workmail_mail_domains` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    import (
    	workmail "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/workmail"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_workmail_mail_domains"})

    		ubx.Data(workmail.MailDomains, "example", workmail.MailDomainsConfig{
    			OrganizationId: "example",
    			MaxResults:     1,
    		})
    	}))
    }

title: "aws_emr_containers_virtual_clusters"
description: "`data_aws_emr_containers_virtual_clusters` looks up a real, already-existing `aws_emrcontainers_virtual_cluster`."
---

It registers a real Amazon EKS namespace as an EMR on EKS virtual cluster, the actual target Spark and Hive jobs submitted through EMR on EKS run against, using the underlying Kubernetes cluster's own compute rather than dedicated EMR instances.

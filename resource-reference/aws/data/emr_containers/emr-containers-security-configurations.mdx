---
title: "aws_emr_containers_security_configurations"
description: "`data_aws_emr_containers_security_configurations` looks up a real, already-existing `aws_emr_security_configuration`."
---

It defines a real, reusable set of encryption and authentication settings, at-rest, in-transit, Kerberos, that an `aws_emr_cluster` references instead of specifying that configuration inline on every cluster that needs it.

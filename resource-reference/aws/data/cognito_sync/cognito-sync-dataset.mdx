    		})
    	}))
    }

## Lookup arguments

<ResponseField name="dataset_name" type="string" required>
  The real name of the dataset this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="identity_id" type="string" required>
  The real, unique identifier of the identity this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="identity_pool_id" type="string" required>
  The real, unique identifier of the Amazon Cognito identity pool this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="dataset" type="object">
  A collection of data for an identity pool. An identity pool can have multiple datasets. A dataset is per identity and can be general or associated with a particular entity in an application (like a saved game). Datasets are automatically created if they don't exist. Data is synced by dataset, and a dataset can hold up to 1MB of key-value pairs. Returned by the lookup.

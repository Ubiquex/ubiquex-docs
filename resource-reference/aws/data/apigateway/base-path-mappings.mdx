---
title: "aws_apigateway_base_path_mappings"
description: "`data_aws_apigateway_base_path_mappings` looks up a real, already-existing `aws_api_gateway_base_path_mapping`."
---

It maps a path segment on an `aws_api_gateway_domain_name` to a specific REST API and stage, the real mechanism that lets one custom domain front several different APIs at different base paths.

---
title: "aws_apigateway_client_certificate"
description: "`data_aws_apigateway_client_certificate` looks up a real, already-existing `aws_api_gateway_client_certificate`."
---

It generates a certificate an `aws_api_gateway_rest_api` presents to its own backend, so the backend can verify requests genuinely came through API Gateway rather than directly from the internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_client_certificate"})

    		ubx.Data(apigateway.ClientCertificate, "example", apigateway.ClientCertificateConfig{
    			ClientCertificateId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    import ubx_sdk as ubx
    from ubx.aws.data.apigateway import ClientCertificate, ClientCertificateConfig

    def describe():
        ubx.intent("look up aws_apigateway_client_certificate")

        ubx.data(ClientCertificate, "example", ClientCertificateConfig(
            client_certificate_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

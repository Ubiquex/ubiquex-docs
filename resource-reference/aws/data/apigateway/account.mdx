---
title: "aws_apigateway_account"
description: "`data_aws_apigateway_account` looks up a real, already-existing `aws_api_gateway_account`."
---

It configures account-wide REST API Gateway settings, most notably the IAM role API Gateway assumes to push execution logs to CloudWatch, applying once per account rather than per `aws_api_gateway_rest_api`.

---
title: "aws_apigateway_resources"
description: "`data_aws_apigateway_resources` looks up a real, already-existing `aws_api_gateway_resource`."
---

It defines one path segment in a REST API's URL tree, nested under an `aws_api_gateway_rest_api` (or under another resource), with one or more `aws_api_gateway_method`s attached to actually handle requests at that path.

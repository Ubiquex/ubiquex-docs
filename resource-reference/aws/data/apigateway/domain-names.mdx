---
title: "aws_apigateway_domain_names"
description: "`data_aws_apigateway_domain_names` looks up a real, already-existing `aws_api_gateway_domain_name`."
---

It registers a custom domain for REST APIs (API Gateway v1), provisioning the TLS certificate and edge or regional endpoint that requests to that domain terminate at, before `aws_api_gateway_base_path_mapping` routes them to a specific API.

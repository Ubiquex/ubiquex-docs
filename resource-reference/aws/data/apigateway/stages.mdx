---
title: "aws_apigateway_stages"
description: "`data_aws_apigateway_stages` looks up a real, already-existing `aws_api_gateway_stage`."
---

It is a named, addressable environment (`prod`, `dev`, and similar) that points at a specific `aws_api_gateway_deployment`. Callers hit a stage's own URL, and promoting a new version means moving the stage to point at a new deployment, not editing the API in place.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_stages"})

    		ubx.Data(apigateway.Stages, "example", apigateway.StagesConfig{
    			RestApiId:    "example",
    			DeploymentId: "example",
    		})
    	}))
    }
    ```

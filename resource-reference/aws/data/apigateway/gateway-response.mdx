---
title: "aws_apigateway_gateway_response"
description: "`data_aws_apigateway_gateway_response` looks up a real, already-existing `aws_api_gateway_gateway_response`."
---

It customizes the response API Gateway itself returns for a given error, a 4XX or 5XX that never reached the backend, on an `aws_api_gateway_rest_api`, overriding the default generic error body and headers.

## Example

<Tabs>
  <Tab title="Go">

    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_gateway_response"})

    		ubx.Data(apigateway.GatewayResponse, "example", apigateway.GatewayResponseConfig{
    			ResponseType: "example",
    			RestApiId:    "example",
    		})
    	}))
    }

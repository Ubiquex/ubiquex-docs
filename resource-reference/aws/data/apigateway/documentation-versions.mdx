---
title: "aws_apigateway_documentation_versions"
description: "`data_aws_apigateway_documentation_versions` looks up a real, already-existing `aws_api_gateway_documentation_version`."
---

It snapshots an `aws_api_gateway_rest_api`'s documentation parts at a point in time, kept versioned separately from the API's own deployments so docs and API behavior can each move independently.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_documentation_versions"})

    		ubx.Data(apigateway.DocumentationVersions, "example", apigateway.DocumentationVersionsConfig{
    			RestApiId: "example",
    			Limit:     1,
    		})
    	}))
    }

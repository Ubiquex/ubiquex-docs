---
title: "aws_apigateway_client_certificates"
description: "`data_aws_apigateway_client_certificates` looks up a real, already-existing `aws_api_gateway_client_certificate`."
---

It generates a certificate an `aws_api_gateway_rest_api` presents to its own backend, so the backend can verify requests genuinely came through API Gateway rather than directly from the internet.

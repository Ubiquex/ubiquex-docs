`aws_apigateway_integration_response` looks up a real API Gateway integration response, transforming a backend's own response before returning it to the client.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_integration_response"})

    		ubx.Data(apigateway.IntegrationResponse, "example", apigateway.IntegrationResponseConfig{
    			HttpMethod: "example",
    			ResourceId: "example",
    			RestApiId:  "example",
    			StatusCode: "example",
    		})
    	}))
    }
    ```

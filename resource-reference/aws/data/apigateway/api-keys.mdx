---
title: "aws_apigateway_api_keys"
description: "`data_aws_apigateway_api_keys` looks up a real, already-existing `aws_api_gateway_api_key`."
---

It issues a key that identifies a caller against an `aws_api_gateway_usage_plan`, the real mechanism REST APIs use to meter and throttle usage per consumer rather than per IAM identity.

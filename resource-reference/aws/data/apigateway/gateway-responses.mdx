---
title: "aws_apigateway_gateway_responses"
description: "`data_aws_apigateway_gateway_responses` looks up a real, already-existing `aws_api_gateway_gateway_response`."
---

It customizes the response API Gateway itself returns for a given error, a 4XX or 5XX that never reached the backend, on an `aws_api_gateway_rest_api`, overriding the default generic error body and headers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_gateway_responses"})

    		ubx.Data(apigateway.GatewayResponses, "example", apigateway.GatewayResponsesConfig{
    			RestApiId: "example",
    			Limit:     1,
    		})
    	}))
    }
    ```

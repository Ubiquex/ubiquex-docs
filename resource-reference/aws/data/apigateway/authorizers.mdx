---
title: "aws_apigateway_authorizers"
description: "`data_aws_apigateway_authorizers` looks up a real, already-existing `aws_api_gateway_authorizer`."
---

It attaches a Lambda-, Cognito-, or IAM-based access-control check to an `aws_api_gateway_rest_api`, run before a request reaches its backend integration, so authorization logic lives outside the backend rather than duplicated inside it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigateway_authorizers"})

    		ubx.Data(apigateway.Authorizers, "example", apigateway.AuthorizersConfig{
    			RestApiId: "example",
    			Limit:     1,
    		})
    	}))
    }
    ```
  </Tab>

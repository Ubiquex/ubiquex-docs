---
title: "aws_apigateway_vpc_links"
description: "`data_aws_apigateway_vpc_links` looks up a real, already-existing `aws_api_gateway_vpc_link`."
---

It lets a REST API's integration reach a private resource inside a VPC, typically a Network Load Balancer in front of an internal service, without that resource ever being exposed publicly.

## Lookup arguments

<ResponseField name="key_material_type" type="string" required>
  The real, discriminating type of the key material this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="reuse_last_generated_token" type="bool">
  The real, opaque reuse last generated token. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="wrapping_key_algorithm" type="string" required>
  The real algorithm of the wrapping key. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="channel_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the channel this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="chime_bearer" type="string" required>
  The real Amazon Chime App Instance user ARN this request is authorized as. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="message_id" type="string" required>
  The real, unique identifier of the message this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sub_channel_id" type="string">
  The real, unique identifier of the sub-channel this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

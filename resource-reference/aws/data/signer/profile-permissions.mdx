---
title: "aws_signer_profile_permissions"
description: "`data_aws_signer_profile_permissions` looks up a real, already-existing `aws_signer_profile_permission`."
---

It grants a real cross-account or service permission to use an `aws_signer_signing_profile`, letting another account or an AWS service like Lambda invoke it to sign code on this account's behalf.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	signer "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/signer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_signer_profile_permissions"})

    		ubx.Data(signer.ProfilePermissions, "example", signer.ProfilePermissionsConfig{
    			ProfileName: "example-profile-name",
    		})
    	}))
    }
    ```
  </Tab>

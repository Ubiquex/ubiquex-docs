## Lookup arguments

<ResponseField name="certificate_hashes" type="list(string)" required>
  The real hashes of the certificates included in this result. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="job_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="platform_id" type="string" required>
  The real, unique identifier of the platform this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="profile_version_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the profile version this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="signature_timestamp" type="string" required>
  The real timestamp of the signature. **(AI-inferred)** Required lookup argument.
</ResponseField>

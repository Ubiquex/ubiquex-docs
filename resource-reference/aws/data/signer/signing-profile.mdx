---
title: "aws_signer_signing_profile"
description: "`data_aws_signer_signing_profile` looks up a real, already-existing `aws_signer_signing_profile`."
---

It creates a real, reusable code-signing configuration, its signing platform and certificate validity, that AWS Signer uses to produce a verifiable, tamper-evident signature over deployment artifacts such as Lambda code or IoT firmware.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	signer "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/signer"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_signer_signing_profile"})

    		ubx.Data(signer.SigningProfile, "example", signer.SigningProfileConfig{
    			ProfileName:  "example-profile-name",
    			ProfileOwner: "example",
    		})
    	}))
    }
    ```

    from ubx.aws.data.signer import SigningProfile, SigningProfileConfig

    def describe():
        ubx.intent("look up aws_signer_signing_profile")

        ubx.data(SigningProfile, "example", SigningProfileConfig(
            profile_name="example-profile-name",
            profile_owner="example",
        ))

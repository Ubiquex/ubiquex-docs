`aws_route53domains_domain_detail` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	route53domains "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/route53domains"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_route53domains_domain_detail"})

    		ubx.Data(route53domains.DomainDetail, "example", route53domains.DomainDetailConfig{
    			DomainName: "example-domain-name",
    		})
    	}))
    }
    ```

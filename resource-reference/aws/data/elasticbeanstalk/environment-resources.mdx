`aws_elasticbeanstalk_environment_resources` reads the real AWS resources (EC2 instances, Load Balancer, Auto Scaling group) provisioned by an Elastic Beanstalk environment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	elasticbeanstalk "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/elasticbeanstalk"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_elasticbeanstalk_environment_resources"})

    		ubx.Data(elasticbeanstalk.EnvironmentResources, "example", elasticbeanstalk.EnvironmentResourcesConfig{
    			EnvironmentId:   "example",
    			EnvironmentName: "example-environment-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

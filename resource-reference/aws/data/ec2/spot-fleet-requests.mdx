---
title: "aws_ec2_spot_fleet_requests"
description: "`data_aws_ec2_spot_fleet_requests` looks up a real, already-existing `aws_ec2_spot_fleet`."
---

It launches and maintains a real target amount of Spot Instance capacity across multiple instance types and Availability Zones, automatically requesting replacement capacity if Spot Instances are interrupted, the Spot-focused predecessor to the more general `aws_ec2_fleet`.

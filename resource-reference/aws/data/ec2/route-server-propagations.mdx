---
title: "aws_ec2_route_server_propagations"
description: "`data_aws_ec2_route_server_propagations` looks up a real, already-existing `aws_ec2_route_server_propagation`."
---

It enables a real `aws_ec2_route_server`'s learned BGP routes to be propagated into a specific VPC route table, the resource that actually applies the route server's routing decisions to real traffic.

---
title: "aws_ec2_route_server_associations"
description: "`data_aws_ec2_route_server_associations` looks up a real, already-existing `aws_ec2_route_server_association`."
---

It attaches an `aws_ec2_route_server` to a real VPC, the resource that actually turns the route server's BGP-learned routes into candidates for that VPC's own route tables.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ec2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/ec2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_ec2_route_server_associations"})

    		ubx.Data(ec2.RouteServerAssociations, "example", ec2.RouteServerAssociationsConfig{
    			RouteServerId: "example",
    			DryRun:        true,
    		})
    	}))
    }
    ```

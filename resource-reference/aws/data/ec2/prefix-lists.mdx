---
title: "aws_ec2_prefix_lists"
description: "`data_aws_ec2_prefix_lists` looks up a real, already-existing `aws_ec2_prefix_list`."
---

It is a real, named, reusable set of CIDR blocks a caller manages once and references from security group rules and route tables, so updating the underlying IP ranges doesn't mean editing every rule that uses them individually.

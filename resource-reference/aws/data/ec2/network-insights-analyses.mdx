---
title: "aws_ec2_network_insights_analyses"
description: "`data_aws_ec2_network_insights_analyses` looks up a real, already-existing `aws_ec2_network_insights_analysis`."
---

It runs a real, point-in-time check of an `aws_ec2_network_insights_path`, tracing every hop, security group, route table, network ACL, and reporting exactly where connectivity actually breaks if it does.

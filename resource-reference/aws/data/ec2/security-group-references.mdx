title: "aws_ec2_security_group_references"
description: "`data_aws_ec2_security_group_references` looks up a real, already-existing `aws_ec2_security_group_egress`."

It defines one real, specific outbound traffic rule on a security group, the actual, individually addressable rule resource, as distinct from managing a security group's entire rule set as one inline block.

---
title: "aws_ec2_local_gateways"
description: "`data_aws_ec2_local_gateways` looks up a real, already-existing `aws_ec2_local_gateway_route`."
---

It defines a real route in an `aws_ec2_local_gateway_route_table`, directing traffic for a specific CIDR to an Outposts local gateway rather than back into the parent AWS Region.

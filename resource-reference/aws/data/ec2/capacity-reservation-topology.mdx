---
title: "aws_ec2_capacity_reservation_topology"
description: "`data_aws_ec2_capacity_reservation_topology` looks up a real, already-existing `aws_ec2_capacity_reservation`."
---

It reserves real EC2 capacity for a specific instance type and Availability Zone, guaranteeing it's available when needed regardless of what else is running in that zone, independent of any particular Reserved Instance or Savings Plan billing commitment.

---
title: "aws_ec2_host_reservations"
description: "`data_aws_ec2_host_reservations` looks up a real, already-existing `aws_ec2_host`."
---

It allocates a real, physical EC2 server, a Dedicated Host, dedicated entirely to a caller's own use, needed for software that's licensed per physical core or socket, or for regulatory requirements around instance isolation that shared hardware doesn't satisfy.

---
title: "aws_ec2_verified_access_endpoint_policy"
description: "`data_aws_ec2_verified_access_endpoint_policy` looks up a real, already-existing `aws_ec2_verified_access_endpoint`."
---

It is the real, actual application Verified Access provides access to, an IP address, load balancer, or network interface, evaluated against its `aws_ec2_verified_access_group`'s policy on every request before traffic is allowed through.

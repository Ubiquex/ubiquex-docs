---
title: "aws_ec2_security_groups_for_vpc"
description: "`data_aws_ec2_security_groups_for_vpc` looks up a real, already-existing `aws_ec2_security_group_vpc_association`."
---

It shares an existing security group across additional VPCs in the same Region, a real, direct alternative to recreating the same rule set in every VPC that needs it.

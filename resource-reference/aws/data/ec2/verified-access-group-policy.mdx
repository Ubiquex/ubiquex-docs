---
title: "aws_ec2_verified_access_group_policy"
description: "`data_aws_ec2_verified_access_group_policy` looks up a real, already-existing `aws_ec2_verified_access_group`."
---

It collects `aws_ec2_verified_access_endpoint`s with real, similar security requirements under one shared Verified Access policy, so a caller manages one policy per group of applications instead of one per individual endpoint.

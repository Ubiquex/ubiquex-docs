---
title: "aws_ec2_route_server_routing_database"
description: "`data_aws_ec2_route_server_routing_database` looks up a real, already-existing `aws_ec2_route_server`."
---

It creates a real, BGP-based dynamic routing resource for a VPC, automatically updating VPC and internet gateway route tables with preferred routes rather than requiring routes to be maintained by hand, giving fault-tolerant, software-defined-network-style routing inside a VPC.

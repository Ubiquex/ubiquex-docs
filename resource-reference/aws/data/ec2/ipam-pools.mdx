description: "`data_aws_ec2_ipam_pools` looks up a real, already-existing `aws_ec2_ipam`."

It is the real, top-level IP Address Manager resource, planning, tracking, and monitoring IP address usage across an AWS organization's accounts and Regions from one place rather than each account managing its own address space independently.

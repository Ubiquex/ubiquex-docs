---
title: "aws_fms_resource_set"
description: "`data_aws_fms_resource_set` looks up a real, already-existing `aws_fms_resource_set`."
---

It is a real, named collection of specific resources that an `aws_fms_policy` can reference directly, scoping a policy to an explicit resource list rather than only a broader tag- or account-based filter.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	fms "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/fms"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource set"})

    		ubx.Resource(fms.ResourceSet, "example", fms.ResourceSetConfig{
    			Name:             "example",
    			ResourceTypeList: []string{"example"},
    			Description:      "Managed by ubx.",
    			Resources:        []string{"example"},
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.fms import ResourceSet, ResourceSetConfig
    from ubx.aws.fms.resource_set import ResourceSet_Tags

    def describe():
        ubx.intent("example own resource set")

        ubx.resource(ResourceSet, "example", ResourceSetConfig(
            name="example",
            resource_type_list=["example"],
            description="Managed by ubx.",
            resources=["example"],
            tags=[ResourceSet_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

---
title: "aws_fms_resource_set"
description: "`data_aws_fms_resource_set` looks up a real, already-existing `aws_fms_resource_set`."
---

It is a real, named collection of specific resources that an `aws_fms_policy` can reference directly, scoping a policy to an explicit resource list rather than only a broader tag- or account-based filter.

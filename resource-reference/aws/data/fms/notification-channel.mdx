---
title: "aws_fms_notification_channel"
description: "`data_aws_fms_notification_channel` looks up a real, already-existing `aws_fms_notification_channel`."
---

It configures a real SNS topic that AWS Firewall Manager publishes notifications to about an `aws_fms_policy`'s own compliance status changes across an organization's accounts.

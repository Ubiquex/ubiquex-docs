---
title: "aws_fms_policies"
description: "`data_aws_fms_policies` looks up a real, already-existing `aws_fms_policy`."
---

It defines a real, centrally managed security policy, WAF rules, security group settings, Shield Advanced protection, that AWS Firewall Manager automatically applies and keeps enforced across every account and resource in an AWS Organization matching the policy's scope.

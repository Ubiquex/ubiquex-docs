---
title: "aws_es_tags"
description: "`aws_es_tags` reads the real tags applied to an Elasticsearch resource."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	es "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/es"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_es_tags"})

    		ubx.Data(es.Tags, "example", es.TagsConfig{
    			Arn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Tags } from "@ubx/sdk-aws/aws/data/es/tags";

    export default stack("example", () => {
      intent({ summary: "look up aws_es_tags" });

      data(Tags, "example", {
        arn: "arn:aws:iam::123456789012:policy/example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.es import Tags, TagsConfig

    def describe():
        ubx.intent("look up aws_es_tags")

        ubx.data(Tags, "example", TagsConfig(
            arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="arn" type="string" required>
  &lt;p&gt;The Amazon Resource Name (ARN) of the Elasticsearch domain. See &lt;a href="http://docs.aws.amazon.com/IAM/latest/UserGuide/index.html?Using_Identifiers.html" target="_blank"&gt;Identifiers for IAM Entities&lt;/a&gt; in &lt;i&gt;Using AWS Identity and Access Management&lt;/i&gt; for more information.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="tag_list" type="list(object)">
  &lt;p&gt;A list of &lt;code&gt;Tag&lt;/code&gt; &lt;/p&gt; Returned by the lookup.
</ResponseField>

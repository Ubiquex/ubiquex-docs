## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	es "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/es"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_es_upgrade_status"})

    			DomainName: "example-domain-name",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;The name of an Elasticsearch domain. Domain names are unique across the domains owned by an account within an AWS region. Domain names start with a letter or number and can contain the following characters: a-z (lowercase), 0-9, and - (hyphen).&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="step_status" type="string">
  The real, current status of the step this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="upgrade_name" type="string">
  The real name of the upgrade this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="upgrade_step" type="string">
  The real, current step of this upgrade. **(AI-inferred)** Returned by the lookup.
</ResponseField>

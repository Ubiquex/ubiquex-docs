## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  &lt;p&gt;The name of an Elasticsearch domain. Domain names are unique across the domains owned by an account within an AWS region. Domain names start with a letter or number and can contain the following characters: a-z (lowercase), 0-9, and - (hyphen).&lt;/p&gt; Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt; Set this value to limit the number of results returned. &lt;/p&gt; Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="auto_tunes" type="list(object)">

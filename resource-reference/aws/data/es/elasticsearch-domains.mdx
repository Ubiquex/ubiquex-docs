title: "aws_es_elasticsearch_domains"

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	es "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/es"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_es_elasticsearch_domains"})

    		ubx.Data(es.ElasticsearchDomains, "example", es.ElasticsearchDomainsConfig{
    			DomainNames: []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ElasticsearchDomains } from "@ubx/sdk-aws/aws/data/es/elasticsearch_domains";

    export default stack("example", () => {
      intent({ summary: "look up aws_es_elasticsearch_domains" });

      data(ElasticsearchDomains, "example", {
        domainNames: ["example"],
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.es import ElasticsearchDomains, ElasticsearchDomainsConfig

    def describe():
        ubx.intent("look up aws_es_elasticsearch_domains")

        ubx.data(ElasticsearchDomains, "example", ElasticsearchDomainsConfig(
            domain_names=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="domain_names" type="list(string)" required>
  &lt;p&gt;A list of Elasticsearch domain names.&lt;/p&gt; Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="domain_status_list" type="list(object)">
  &lt;p&gt;A list that contains the status of each requested Elasticsearch domain.&lt;/p&gt; Returned by the lookup.
</ResponseField>

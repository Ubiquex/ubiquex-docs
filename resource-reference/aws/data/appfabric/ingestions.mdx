## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appfabric "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/appfabric"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_appfabric_ingestions"})

    		ubx.Data(appfabric.Ingestions, "example", appfabric.IngestionsConfig{
    			AppBundleIdentifier: "example",
    			MaxResults:          1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="app_bundle_identifier" type="string" required>
  The real, unique identifier of the app bundle this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="ingestions" type="list(object)">
  The real ingestions included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

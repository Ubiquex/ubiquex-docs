---
title: "aws_outposts_site_address"
description: "`data_aws_outposts_site_address` looks up a real, already-existing `aws_outposts_site`."
---

It registers a real physical location, its address and operating hours, where an AWS Outposts rack or server will be installed, extending AWS infrastructure and APIs into that on-premises facility.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	outposts "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/outposts"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_outposts_site_address"})

    		ubx.Data(outposts.SiteAddress, "example", outposts.SiteAddressConfig{
    			AddressType: "example",
    			SiteId:      "example",
    		})
    	}))
    }
    ```
  </Tab>

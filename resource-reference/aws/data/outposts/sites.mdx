---
title: "aws_outposts_sites"
description: "`data_aws_outposts_sites` looks up a real, already-existing `aws_outposts_site`."
---

It registers a real physical location, its address and operating hours, where an AWS Outposts rack or server will be installed, extending AWS infrastructure and APIs into that on-premises facility.

## Example

    ```go
    	outposts "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/outposts"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_outposts_sites"})

    		ubx.Data(outposts.Sites, "example", outposts.SitesConfig{
    			MaxResults:                          1,
    			OperatingAddressCityFilter:          []string{"example"},
    			OperatingAddressCountryCodeFilter:   []string{"example"},
    			OperatingAddressStateOrRegionFilter: []string{"example"},
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="max_results" type="number">
  &lt;p&gt;The maximum page size.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="operating_address_city_filter" type="list(string)">
  Restricts results to this operating address city. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="operating_address_country_code_filter" type="list(string)">
  Restricts results to this operating address country code. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="operating_address_state_or_region_filter" type="list(string)">
  Restricts results to this operating address state or region. **(AI-inferred)** Optional lookup argument.
</ResponseField>

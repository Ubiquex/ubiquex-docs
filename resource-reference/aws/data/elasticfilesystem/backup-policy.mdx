## Example

<Tabs>

    ```go
    package main

    import (
    	elasticfilesystem "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/elasticfilesystem"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_elasticfilesystem_backup_policy"})

    		ubx.Data(elasticfilesystem.BackupPolicy, "example", elasticfilesystem.BackupPolicyConfig{
    			FileSystemId: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="file_system_id" type="string" required>
  The real, unique identifier of the file system this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="backup_policy" type="object">
  &lt;p&gt;The backup policy for the file system used to create automatic daily backups. If status has a value of &lt;code&gt;ENABLED&lt;/code&gt;, the file system is being automatically backed up. For more information, see &lt;a href="https://docs.aws.amazon.com/efs/latest/ug/awsbackup.html#automatic-backups"&gt;Automatic backups&lt;/a&gt;.&lt;/p&gt; Returned by the lookup.

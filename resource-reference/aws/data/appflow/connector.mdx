## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appflow "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/appflow"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_appflow_connector"})

    		ubx.Data(appflow.Connector, "example", appflow.ConnectorConfig{
    			ConnectorType:  "example",
    			ConnectorLabel: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Connector } from "@ubx/sdk-aws/aws/data/appflow/connector";

    export default stack("example", () => {
      intent({ summary: "look up aws_appflow_connector" });

      data(Connector, "example", {
        connectorType: "example",
        connectorLabel: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.appflow import Connector, ConnectorConfig

    def describe():
        ubx.intent("look up aws_appflow_connector")

        ubx.data(Connector, "example", ConnectorConfig(
            connector_type="example",
            connector_label="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="connector_label" type="string">
  The real, human-readable label of the connector. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="connector_type" type="string" required>
  The real, discriminating type of the connector this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "aws_guardduty_trusted_entity_sets"
description: "`data_aws_guardduty_trusted_entity_sets` looks up a real, already-existing `aws_guard_duty_trusted_entity_set`."
---

It is GuardDuty's newer, broader trusted list, covering domains as well as IP addresses, that an `aws_guard_duty_detector` never generates findings against, GuardDuty's recommended replacement for the IP-only `aws_guard_duty_ipset`. Introduced September 2025.

---
title: "aws_guardduty_threat_intel_sets"
description: "`data_aws_guardduty_threat_intel_sets` looks up a real, already-existing `aws_guard_duty_threat_intel_set`."
---

It is a real, custom list of known-malicious IP addresses that an `aws_guard_duty_detector` generates findings against, extending GuardDuty's own built-in threat intelligence with a caller's own data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	guardduty "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/guardduty"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_guardduty_threat_intel_sets"})

    		ubx.Data(guardduty.ThreatIntelSets, "example", guardduty.ThreatIntelSetsConfig{
    			DetectorId: "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="detector_id" type="string" required>
  The real, unique identifier of the detector this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="threat_intel_set_ids" type="list(string)">
  The real, unique identifiers of the threat intel sets this request is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

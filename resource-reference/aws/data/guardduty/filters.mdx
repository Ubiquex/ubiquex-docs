---
title: "aws_guardduty_filters"
description: "`data_aws_guardduty_filters` looks up a real, already-existing `aws_guard_duty_filter`."
---

It automatically suppresses or auto-archives real findings matching a defined criteria from an `aws_guard_duty_detector`, cutting down alert noise from findings a caller has already determined aren't actionable.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	guardduty "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/guardduty"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_guardduty_filters"})

    		ubx.Data(guardduty.Filters, "example", guardduty.FiltersConfig{
    			DetectorId: "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="detector_id" type="string" required>
  The real, unique identifier of the detector this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="filter_names" type="list(string)">
  The real names of the filters included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

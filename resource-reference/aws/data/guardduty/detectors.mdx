---
title: "aws_guardduty_detectors"
description: "`data_aws_guardduty_detectors` looks up a real, already-existing `aws_guard_duty_detector`."
---

It turns on GuardDuty for an account and Region, the real, top-level resource that continuously analyzes VPC Flow Logs, DNS logs, and CloudTrail events for threats, every other GuardDuty resource, filters, IP lists, member associations, attaches to a detector.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	guardduty "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/guardduty"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_guardduty_detectors"})

    		ubx.Data(guardduty.Detectors, "example", guardduty.DetectorsConfig{
    			MaxResults: 1,
    		})
    	}))
    }
    ```

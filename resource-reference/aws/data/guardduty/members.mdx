---
title: "aws_guardduty_members"
description: "`data_aws_guardduty_members` looks up a real, already-existing `aws_guard_duty_member`."
---

It associates another real AWS account's own `aws_guard_duty_detector` as a member under an administrator account, so a security team can view and manage GuardDuty findings across every member account from one central place.

## Example

    package main

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_guardduty_members"})

    		ubx.Data(guardduty.Members, "example", guardduty.MembersConfig{
    			DetectorId:     "example",
    			MaxResults:     1,
    			OnlyAssociated: "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="detector_id" type="string" required>
  The real, unique identifier of the detector this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="only_associated" type="string">
  Whether the response is restricted to objects that are currently associated. **(AI-inferred)** Optional lookup argument.
</ResponseField>

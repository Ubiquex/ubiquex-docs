---
title: "aws_guardduty_ipsets"
description: "`data_aws_guardduty_ipsets` looks up a real, already-existing `aws_guard_duty_ipset`."
---

It is a real, trusted list of IP addresses an `aws_guard_duty_detector` never generates findings against, for a caller's own known-safe scanners or internal tools that would otherwise look like malicious activity.

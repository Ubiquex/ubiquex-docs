---
title: "aws_guardduty_threat_entity_sets"
description: "`data_aws_guardduty_threat_entity_sets` looks up a real, already-existing `aws_guard_duty_threat_entity_set`."
---

It is GuardDuty's newer, broader entity list, IP addresses, domain names, and SHA-256 file hashes together rather than IP addresses alone, that an `aws_guard_duty_detector` generates findings against, GuardDuty's recommended replacement for the IP-only `aws_guard_duty_threat_intel_set`. Introduced September 2025.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	guardduty "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/guardduty"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_guardduty_threat_entity_sets"})

    		ubx.Data(guardduty.ThreatEntitySets, "example", guardduty.ThreatEntitySetsConfig{
    			DetectorId: "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="detector_id" type="string" required>
  The real, unique identifier of the detector this lookup is scoped to. **(AI-inferred)** Required lookup argument.

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.

---
title: "aws_guardduty_publishing_destinations"
description: "`data_aws_guardduty_publishing_destinations` looks up a real, already-existing `aws_guard_duty_publishing_destination`."
---

It exports an `aws_guard_duty_detector`'s own findings continuously to a real S3 bucket, for long-term retention or for feeding a caller's own SIEM rather than only viewing findings in the GuardDuty console.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	guardduty "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/guardduty"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_guardduty_publishing_destinations"})

    		ubx.Data(guardduty.PublishingDestinations, "example", guardduty.PublishingDestinationsConfig{
    			DetectorId: "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="detector_id" type="string" required>
  The real, unique identifier of the detector this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="destinations" type="list(object)">
  The real destinations included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

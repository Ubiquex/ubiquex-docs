## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appsync "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/appsync"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_appsync_graphql_apis"})

    		ubx.Data(appsync.GraphqlApis, "example", appsync.GraphqlApisConfig{
    			ApiType:    "example",
    			MaxResults: 1,
    			Owner:      "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.appsync import GraphqlApis, GraphqlApisConfig

    def describe():
        ubx.intent("look up aws_appsync_graphql_apis")

        ubx.data(GraphqlApis, "example", GraphqlApisConfig(
            api_type="example",
            max_results=1,
            owner="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="api_type" type="string">
  The real, discriminating type of the api this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="owner" type="string">
  The real owner of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="graphql_apis" type="list(object)">
  The real AWS AppSync GraphQL APIs included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

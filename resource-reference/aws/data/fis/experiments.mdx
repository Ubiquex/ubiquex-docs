---
title: "aws_fis_experiments"
description: "`data_aws_fis_experiments` looks up a real, already-existing `aws_fis_experiment_template`."
---

It defines a real chaos engineering experiment for AWS Fault Injection Service, which actions to inject, terminating instances, throttling an API, spiking CPU, against which real targets, and what stop conditions abort the experiment automatically if things go wrong.

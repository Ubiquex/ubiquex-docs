---
title: "aws_fis_experiment_target_account_configuration"
description: "`data_aws_fis_experiment_target_account_configuration` looks up a real, already-existing `aws_fis_target_account_configuration`."
---

It registers a real member account, and the IAM role FIS should assume in it, as an eligible target for an `aws_fis_experiment_template` run from a different, orchestrating account.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    }

## Lookup arguments

<ResponseField name="account_id" type="string" required>
  The real, unique identifier of the AWS account this lookup is scoped to. **(AI-inferred)** Required lookup argument.

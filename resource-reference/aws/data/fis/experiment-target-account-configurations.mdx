---
title: "aws_fis_experiment_target_account_configurations"
description: "`data_aws_fis_experiment_target_account_configurations` looks up a real, already-existing `aws_fis_target_account_configuration`."
---

It registers a real member account, and the IAM role FIS should assume in it, as an eligible target for an `aws_fis_experiment_template` run from a different, orchestrating account.

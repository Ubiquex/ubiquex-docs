---
title: "aws_apigatewayv2_vpc_links"
description: "`data_aws_apigatewayv2_vpc_links` looks up a real, already-existing `aws_api_gateway_v2_vpc_link`."
---

It lets an `aws_api_gateway_v2_api` integration reach a private resource inside a VPC (an internal load balancer, for instance) without that resource being exposed to the public internet, the v2 counterpart to a v1 REST API VPC link.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

---
title: "aws_apigatewayv2_route_responses"
description: "`data_aws_apigatewayv2_route_responses` looks up a real, already-existing `aws_api_gateway_v2_route_response`."
---

It defines the response a WebSocket API route sends back after its `aws_api_gateway_v2_integration_response` runs, part of the two-way message flow WebSocket APIs support that HTTP APIs don't need.

## Example

    import (
    	apigatewayv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigatewayv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigatewayv2_route_responses"})

    		ubx.Data(apigatewayv2.RouteResponses, "example", apigatewayv2.RouteResponsesConfig{
    			ApiId:      "example",
    			RouteId:    "example",
    			MaxResults: "example",
    		})
    	}))
    }

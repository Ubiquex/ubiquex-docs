---
title: "aws_apigatewayv2_routing_rules"
description: "`data_aws_apigatewayv2_routing_rules` looks up a real, already-existing `aws_api_gateway_v2_routing_rule`."
---

It defines additional request-matching logic for an `aws_api_gateway_v2_api`'s routes beyond the basic method-and-path match, used to route the same path differently based on request content.

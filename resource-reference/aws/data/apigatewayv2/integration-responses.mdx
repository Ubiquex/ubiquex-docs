---
title: "aws_apigatewayv2_integration_responses"
description: "`data_aws_apigatewayv2_integration_responses` looks up a real, already-existing `aws_api_gateway_v2_integration`."
---

It connects an `aws_api_gateway_v2_api`'s routes to a real backend, Lambda, an HTTP endpoint, or another AWS service, the actual mechanism that determines what happens once a request matches a route.

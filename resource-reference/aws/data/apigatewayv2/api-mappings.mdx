---
title: "aws_apigatewayv2_api_mappings"
description: "`data_aws_apigatewayv2_api_mappings` looks up a real, already-existing `aws_api_gateway_v2_api_mapping`."
---

It maps an `aws_api_gateway_v2_api` and stage onto a path under an `aws_api_gateway_v2_domain_name`, the v2 equivalent of a v1 base path mapping.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigatewayv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/apigatewayv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_apigatewayv2_api_mappings"})

    		ubx.Data(apigatewayv2.ApiMappings, "example", apigatewayv2.ApiMappingsConfig{
    			DomainName: "example-domain-name",
    			MaxResults: "example",
    		})
    	}))
    }
    ```

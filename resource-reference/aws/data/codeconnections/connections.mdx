---
title: "aws_codeconnections_connections"
description: "`data_aws_codeconnections_connections` looks up a real, already-existing `aws_code_connections_connection`."
---

It links AWS to an external source provider, GitHub, GitLab, Bitbucket, once authorized, so a real `aws_code_pipeline_pipeline` or other AWS service can pull code without re-authenticating per use. AWS CodeConnections is the March 2024 rename of AWS CodeStar Connections; the older `aws_code_star_connections_connection` resource type continues to work.

## Example

    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	codeconnections "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/codeconnections"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codeconnections_connections"})

    		ubx.Data(codeconnections.Connections, "example", codeconnections.ConnectionsConfig{
    			HostArnFilter:      "example",
    			MaxResults:         1,
    			ProviderTypeFilter: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="host_arn_filter" type="string">
  Restricts results to this host's Amazon Resource Name (ARN). **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="provider_type_filter" type="string">
  Restricts results to this provider type. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="connections" type="list(object)">
  The real connections included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

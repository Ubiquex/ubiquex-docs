`aws_codeconnections_sync_configurations` looks up a real CodeConnections sync configuration, keeping a target resource continuously synced from a repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	codeconnections "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/codeconnections"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_codeconnections_sync_configurations"})

    		ubx.Data(codeconnections.SyncConfigurations, "example", codeconnections.SyncConfigurationsConfig{
    			RepositoryLinkId: "example",
    			SyncType:         "example",
    			MaxResults:       1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="repository_link_id" type="string" required>
  The real, unique identifier of the repository link this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="sync_type" type="string" required>
  The real type of synchronization this request performs. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="sync_configurations" type="list(object)">
  The real sync configurations included in this result. **(AI-inferred)** Returned by the lookup.

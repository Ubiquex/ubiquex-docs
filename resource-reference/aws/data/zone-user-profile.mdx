`aws_data_zone_user_profile` represents one real, individual user's own identity and settings inside an `aws_data_zone_domain`, distinct from `aws_data_zone_project_membership`, which is that user's specific access to one project.

## Input properties

<ResponseField name="domain_identifier" type="string" required>
  The identifier of the Amazon DataZone domain in which the user profile would be created. Required.
</ResponseField>

<ResponseField name="session_name" type="string">
  The session name of the user profile. Optional.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the user profile. Optional.
</ResponseField>

<ResponseField name="user_identifier" type="string" required>
  The ID of the user. Required.
</ResponseField>

<ResponseField name="user_type" type="string">
  The type of the user. Optional.
</ResponseField>

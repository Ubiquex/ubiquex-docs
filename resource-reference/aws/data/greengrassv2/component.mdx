---
title: "aws_greengrassv2_component"
description: "`data_aws_greengrassv2_component` looks up a real, already-existing `aws_greengrass_v2_component_version`."
---

It is a real, versioned software module, AWS-provided or a caller's own, deployed to AWS IoT Greengrass V2 core devices through an `aws_greengrass_v2_deployment`, V2's software-component model that replaced V1's separate function, connector, and resource definitions with one unified concept.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	greengrassv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/greengrassv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_greengrassv2_component"})

    		ubx.Data(greengrassv2.Component, "example", greengrassv2.ComponentConfig{
    			Arn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

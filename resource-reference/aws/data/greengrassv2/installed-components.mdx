---
title: "aws_greengrassv2_installed_components"
description: "`data_aws_greengrassv2_installed_components` looks up a real, already-existing `aws_greengrass_v2_component_version`."
---

It is a real, versioned software module, AWS-provided or a caller's own, deployed to AWS IoT Greengrass V2 core devices through an `aws_greengrass_v2_deployment`, V2's software-component model that replaced V1's separate function, connector, and resource definitions with one unified concept.

## Lookup arguments

<ResponseField name="core_device_thing_name" type="string" required>
  The real name of the AWS IoT Greengrass core device's own thing this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="topology_filter" type="string">
  Restricts results to this network topology. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="installed_components" type="list(object)">
  The real components installed on this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_greengrassv2_effective_deployments"
description: "`data_aws_greengrassv2_effective_deployments` looks up a real, already-existing `aws_greengrass_v2_deployment`."
---

It pushes a real, defined set of `aws_greengrass_v2_component_version`s to a target group of Greengrass V2 core devices, with rollout and rollback configuration, the actual mechanism that gets software running on real edge devices.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_greengrassv2_effective_deployments"})

    		ubx.Data(greengrassv2.EffectiveDeployments, "example", greengrassv2.EffectiveDeploymentsConfig{
    			CoreDeviceThingName: "example-core-device-thing-name",
    			MaxResults:          1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="core_device_thing_name" type="string" required>
  The real name of the AWS IoT Greengrass core device's own thing this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="effective_deployments" type="list(object)">
  The real, currently effective deployments for this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="next_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

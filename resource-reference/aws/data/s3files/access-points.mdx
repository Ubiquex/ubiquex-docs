---
title: "aws_s3files_access_points"
description: "`data_aws_s3files_access_points` looks up a real, already-existing `aws_s3_access_point`."
---

It creates a real, named network endpoint with its own access policy for an `aws_s3_bucket`, letting different applications reach the same bucket through different access points instead of managing one increasingly complex bucket policy.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3files "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/s3files"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3files_access_points"})

    		ubx.Data(s3files.AccessPoints, "example", s3files.AccessPointsConfig{
    			FileSystemId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="file_system_id" type="string" required>
  The real, unique identifier of the file system this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="access_points" type="list(object)">

</ResponseField>

<ResponseField name="next_token" type="string">

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3files "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/s3files"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_s3files_file_systems"})

    		ubx.Data(s3files.FileSystems, "example", s3files.FileSystemsConfig{
    			Bucket:     "example",
    			MaxResults: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="bucket" type="string">

</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="file_systems" type="list(object)">

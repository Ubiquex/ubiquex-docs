---
title: "aws_greengrass_function_definitions"
description: "`data_aws_greengrass_function_definitions` looks up a real, already-existing `aws_greengrass_function_definition`."
---

It lists the real Lambda functions an `aws_greengrass_group`'s core device runs locally, at the edge, rather than in the AWS Cloud. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

    		})

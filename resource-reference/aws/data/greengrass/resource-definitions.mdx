---
title: "aws_greengrass_resource_definitions"
description: "`data_aws_greengrass_resource_definitions` looks up a real, already-existing `aws_greengrass_resource_definition`."
---

It gives an `aws_greengrass_group`'s Lambda functions real, controlled access to local resources, a machine learning model, a device volume, a secret, that live on the core device itself rather than in the cloud. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

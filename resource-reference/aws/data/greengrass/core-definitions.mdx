---
title: "aws_greengrass_core_definitions"
description: "`data_aws_greengrass_core_definitions` looks up a real, already-existing `aws_greengrass_core_definition`."
---

It registers the real primary device, running the actual AWS IoT Greengrass V1 core software, that hosts an `aws_greengrass_group`'s local compute and connects it to AWS IoT Core. Part of Greengrass V1's maintenance-only lifecycle since June 2023, ahead of its October 2026 end of support.

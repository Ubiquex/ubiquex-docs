---
title: "aws_greengrass_group_versions"
description: "`data_aws_greengrass_group_versions` looks up a real, already-existing `aws_greengrass_group_version`."
---

It is a real, specific, versioned snapshot of an `aws_greengrass_group`'s own configuration, the actual deployable unit pushed to a core device, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

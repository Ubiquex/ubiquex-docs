title: "aws_greengrass_groups"
description: "`data_aws_greengrass_groups` looks up a real, already-existing `aws_greengrass_group`."
---

It is the real, top-level container in AWS IoT Greengrass V1 that a core device, its Lambda functions, subscriptions, and other local resources all belong to, deployed together as one unit. AWS IoT Greengrass V1 entered its extended-life, maintenance-only phase on June 30, 2023 (no further feature, enhancement, or security updates) and reaches full end of support on October 7, 2026; devices already running V1 continue operating and connecting to the cloud in the meantime, and AWS recommends migrating to AWS IoT Greengrass V2 for new work.

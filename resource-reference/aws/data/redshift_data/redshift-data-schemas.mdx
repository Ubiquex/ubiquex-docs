## Lookup arguments

<ResponseField name="cluster_identifier" type="string">
  The real, unique identifier of the cluster this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="connected_database" type="string">
  The real database this connection is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="database" type="string" required>
  The real database this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="db_user" type="string">
  The real database user this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return in a single page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="schema_pattern" type="string">
  Restricts results to schemas matching this pattern. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="secret_arn" type="string">
  The real Amazon Resource Name (ARN) of the Secrets Manager secret this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="workgroup_name" type="string">
  The real name of the workgroup this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

</ResponseField>

<ResponseField name="schemas" type="list(string)">
  The real schemas included in this result. **(AI-inferred)** Returned by the lookup.

---
title: "aws_ivsrealtime_encoder_configurations"
description: "`data_aws_ivsrealtime_encoder_configurations` looks up a real, already-existing `aws_ivs_encoder_configuration`."
---

It sets real encoding parameters, resolution, bitrate, for Amazon IVS Real-Time Streaming, applied to participants in an `aws_ivs_stage` rather than a single broadcast `aws_ivs_channel`.

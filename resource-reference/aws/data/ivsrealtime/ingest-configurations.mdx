It specifies a real, named ingest protocol, RTMP or RTMPS, for broadcasting into a specific `aws_ivs_stage`'s real-time stage, including whether insecure RTMP ingest is allowed and an optional customer-assigned user ID used to link the ingest participant to the customer's own systems.

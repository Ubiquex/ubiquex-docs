---
title: "aws_ivsrealtime_stage_session"
description: "`data_aws_ivsrealtime_stage_session` looks up a real, already-existing `aws_ivs_stage`."
---

It is Amazon IVS's real, low-latency, multi-participant video collaboration resource, up to several hosts and guests interacting live together, distinct from an `aws_ivs_channel`'s own single-broadcaster-to-many-viewers model.

## Result properties

<ResponseField name="stage_session" type="object">
  &lt;p&gt;A stage session begins when the first participant joins a stage and ends after the last participant leaves the stage. A stage session helps with debugging stages by grouping events and participants into shorter periods of time (i.e., a session), which is helpful when stages are used over long periods of time.&lt;/p&gt; Returned by the lookup.

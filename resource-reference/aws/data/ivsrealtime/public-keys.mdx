---
title: "aws_ivsrealtime_public_keys"
description: "`data_aws_ivsrealtime_public_keys` looks up a real, already-existing `aws_ivs_public_key`."
---

It registers a real public key IVS validates participant tokens for an `aws_ivs_stage` against, the Real-Time Streaming counterpart to `aws_ivs_playback_key_pair`'s own channel-playback authorization.

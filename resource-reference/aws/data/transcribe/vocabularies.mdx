---
title: "aws_transcribe_vocabularies"
description: "`data_aws_transcribe_vocabularies` looks up a real, already-existing `aws_transcribe_vocabulary_filter`."
---

It defines a real list of words that Amazon Transcribe should mask, remove, or flag whenever they appear in a transcription's output, used for profanity filtering or redacting sensitive terms.

## Example

    package main

    import (
    	transcribe "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/transcribe"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_transcribe_vocabularies"})

    		ubx.Data(transcribe.Vocabularies, "example", transcribe.VocabulariesConfig{
    			MaxResults:   1,
    			NameContains: "example",
    			StateEquals:  "example",
    		})
    	}))
    }

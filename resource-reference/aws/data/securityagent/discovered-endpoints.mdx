## Lookup arguments

<ResponseField name="agent_space_id" type="string" required>
  The real, unique identifier of the agent space this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt;Maximum results for pagination.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="pentest_job_id" type="string" required>
  The real, unique identifier of the pentest job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="prefix" type="string">
  Restricts results to objects whose key starts with this prefix. **(AI-inferred)** Optional lookup argument.
</ResponseField>

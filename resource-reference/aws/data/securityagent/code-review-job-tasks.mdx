## Lookup arguments

<ResponseField name="agent_space_id" type="string" required>
  The real, unique identifier of the agent space this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="category_name" type="string">
  The real name of the category this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="code_review_job_id" type="string">
  The real, unique identifier of the code review job this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt;Maximum results for pagination.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="step_name" type="string">
  &lt;p&gt;Pentest job step names.&lt;/p&gt; Optional lookup argument.
</ResponseField>

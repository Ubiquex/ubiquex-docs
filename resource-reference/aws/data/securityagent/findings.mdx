## Lookup arguments

<ResponseField name="agent_space_id" type="string" required>
  The real, unique identifier of the agent space this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="code_review_job_id" type="string">
  The real, unique identifier of the code review job this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="confidence" type="string">
  &lt;p&gt;Finding confidence level.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  &lt;p&gt;Maximum results for pagination.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="name" type="string">
  The real, given name of this object. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="pentest_job_id" type="string">
  The real, unique identifier of the pentest job this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="risk_level" type="string">
  &lt;p&gt;Risk severity level.&lt;/p&gt; Optional lookup argument.
</ResponseField>

<ResponseField name="risk_type" type="string">
  The real, discriminating type of the risk this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  &lt;p&gt;Finding status.&lt;/p&gt; Optional lookup argument.
</ResponseField>

`aws_appstream2_images` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against AWS's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appstream2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/appstream2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_appstream2_images"})

    		ubx.Data(appstream2.Images, "example", appstream2.ImagesConfig{
    			Arns:       []string{"example"},
    			MaxResults: 1,
    			Names:      []string{"example"},
    			Type:       "example",
    		})
    	}))
    }
    ```

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	forecast "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/forecast"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_forecast_accuracy_metrics"})

    		ubx.Data(forecast.AccuracyMetrics, "example", forecast.AccuracyMetricsConfig{
    			PredictorArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Lookup arguments

</ResponseField>

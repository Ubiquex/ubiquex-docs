---
title: "aws_forecast_datasets"
description: "`data_aws_forecast_datasets` looks up a real, already-existing `aws_forecast_dataset`."
---

It held real historical time-series data inside an `aws_forecast_dataset_group` that Amazon Forecast trained a predictor against. Like the rest of Forecast, closed to new customers since July 29, 2024.

`aws_data_brew_project` is DataBrew's real, interactive workspace, a grid view of an `aws_data_brew_dataset` where a caller explores value distributions and builds up an `aws_data_brew_recipe` of point-and-click transformations without writing code.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    			Name:        "example",
    			RecipeName:  "example-recipe-name",
    			RoleArn:     "arn:aws:iam::123456789012:policy/example",
    			Sample:      map[string]any{"type": "example"},

    		})
    	}))
    }

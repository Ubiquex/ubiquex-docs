---
title: "aws_license_manager_access_token"
description: "`data_aws_license_manager_access_token` looks up a real, already-existing `aws_license_manager_license`."
---

It represents a real granted license for a product purchased from AWS Marketplace or from a seller integrated with AWS License Manager's managed entitlements, tracking the license's entitlements, validity period, and consumption rules.

---
title: "aws_managedblockchain_members"
description: "`data_aws_managedblockchain_members` looks up a real, already-existing `aws_managed_blockchain_member`."
---

It creates a real member identity within a Hyperledger Fabric network on Amazon Managed Blockchain, the account-level participant that peer nodes, `aws_managed_blockchain_node`, are created under.

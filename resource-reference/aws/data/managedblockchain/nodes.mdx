---
title: "aws_managedblockchain_nodes"
description: "`data_aws_managedblockchain_nodes` looks up a real, already-existing `aws_managed_blockchain_node`."
---

It creates a real peer node running within an `aws_managed_blockchain_member`'s participation in a Hyperledger Fabric network on Amazon Managed Blockchain, the compute that actually executes chaincode and maintains the ledger.

---
title: "aws_billing_billing_views"
description: "`data_aws_billing_billing_views` looks up a real, already-existing `aws_billing_view`."
---

It defines a segment of AWS cost and usage data, either the account's own default primary view or a custom, filtered view built and shared, via AWS Resource Access Manager, with other accounts so they see only the cost data the view's filter actually exposes.

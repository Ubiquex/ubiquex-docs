---
title: "aws_workspaces_connection_alias_permissions"
description: "`data_aws_workspaces_connection_alias_permissions` looks up a real, already-existing `aws_work_spaces_connection_alias`."
---

It registers a real custom domain name that can be used to connect to an `aws_work_spaces_workspace` across accounts (in a multi-Region resilience or cross-account access setup), instead of connecting through WorkSpaces' own default registration code.

## Example

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})

    }

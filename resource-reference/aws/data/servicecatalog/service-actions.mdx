`aws_servicecatalog_service_actions` looks up a real Service Catalog self-service action, a predefined operation end users can run against a provisioned product.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicecatalog "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/servicecatalog"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_servicecatalog_service_actions"})

    		ubx.Data(servicecatalog.ServiceActions, "example", servicecatalog.ServiceActionsConfig{
    			AcceptLanguage: "example",
    			PageSize:       1,
    			PageToken:      "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="accept_language" type="string">
  The real, requested language for human-readable text in the response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_size" type="number">
  The number of results per page, for a paginated response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="next_page_token" type="string">
  An opaque pagination token from a previous response, requesting the next page of results. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="service_action_summaries" type="list(object)">
  The real, summarized service actions included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

---
title: "aws_rds_option_group_options"
description: "`data_aws_rds_option_group_options` looks up a real, already-existing `aws_rds_option_group`."
---

It defines a real set of database engine options, such as Oracle's native network encryption or SQL Server's Transparent Data Encryption, that can be enabled on an `aws_rds_dbinstance` beyond what standard engine parameters cover.

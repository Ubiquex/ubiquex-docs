---
title: "aws_rds_dbsnapshots"
description: "`data_aws_rds_dbsnapshots` looks up a real, already-existing `aws_rds_dbsnapshot`."
---

It creates a real point-in-time snapshot of an `aws_rds_dbinstance`, which can later be restored into a new instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	rds "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/rds"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_rds_dbsnapshots"})

    		ubx.Data(rds.Dbsnapshots, "example", rds.DbsnapshotsConfig{
    			DbiResourceId:        "example",
    			DbinstanceIdentifier: "example",
    			DbsnapshotIdentifier: "example",
    			Filters:              []map[string]any{{"name": "example-name"}},
    			IncludePublic:        true,
    			IncludeShared:        true,
    			MaxRecords:           1,
    			SnapshotType:         "example",
    		})
    	}))
    }
    ```

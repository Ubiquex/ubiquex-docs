## Lookup arguments

<ResponseField name="dbinstance_identifier" type="string" required>
  The real, unique identifier of the database instance this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="file_last_written" type="number">
  The real timestamp this file was last written. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="file_size" type="number">
  The real size of the file. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filename_contains" type="string">
  Restricts results to files whose name contains this substring. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="filters" type="list(object)">
  Real filter criteria restricting which results are returned. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="max_records" type="number">
  The maximum number of records to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="describe_dblog_files" type="list(object)">

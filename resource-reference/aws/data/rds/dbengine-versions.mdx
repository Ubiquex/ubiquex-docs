---
title: "aws_rds_dbengine_versions"
description: "`data_aws_rds_dbengine_versions` looks up a real, already-existing `aws_rds_custom_dbengine_version`."
---

It registers a real custom database engine version, a customer-provided installation image, for use with RDS Custom, letting an `aws_rds_dbinstance` run a specific, customer-controlled engine build rather than only AWS's own standard RDS engine versions.

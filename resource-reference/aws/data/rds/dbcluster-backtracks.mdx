---
title: "aws_rds_dbcluster_backtracks"
description: "`data_aws_rds_dbcluster_backtracks` looks up a real, already-existing `aws_rds_dbcluster`."
---

It creates a real Aurora (or Multi-AZ) database cluster, the storage and coordination layer that one or more `aws_rds_dbinstance`s attach to for compute.

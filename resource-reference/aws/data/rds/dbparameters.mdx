---
title: "aws_rds_dbparameters"
description: "`data_aws_rds_dbparameters` looks up a real, already-existing `aws_rds_dbparameter_group`."
---

It defines a real set of instance-level engine parameters that can be applied to an `aws_rds_dbinstance` instead of hand-tuning the instance individually.

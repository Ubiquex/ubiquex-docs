---
title: "aws_dax_parameters"
description: "`data_aws_dax_parameters` looks up a real, already-existing `aws_dax_parameter_group`."
---

It sets real, engine-level configuration, TTL and record count limits among them, for an `aws_dax_cluster`, kept as its own resource so the same parameter set can be applied consistently across multiple clusters.

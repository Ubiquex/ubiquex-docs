## Lookup arguments

<ResponseField name="datastore_id" type="string" required>
  The identifier of a data store. Required lookup argument.
</ResponseField>

<ResponseField name="job_name" type="string">
  The human-readable name of a job. Optional lookup argument.
</ResponseField>

<ResponseField name="job_status" type="string">
  The status of a job. Optional lookup argument.
</ResponseField>

<ResponseField name="max_results" type="number">
  The maximum number of results to return per page. Optional lookup argument.
</ResponseField>

<ResponseField name="submitted_after" type="string">
  A timestamp value. Optional lookup argument.
</ResponseField>

<ResponseField name="submitted_before" type="string">
  A timestamp value. Optional lookup argument.
</ResponseField>

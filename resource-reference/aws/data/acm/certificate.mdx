---
title: "aws_acm_certificate"
description: "`data_aws_acm_certificate` looks up a real, already-existing `aws_acmpca_certificate`."
---

It is a certificate issued by an `aws_acmpca_certificate_authority`. AWS Private CA issues it against the CA's own signing key and policy, the certificate itself carries no independent configuration beyond what its issuing CA allows.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	acm "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/acm"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_acm_certificate"})

    		ubx.Data(acm.Certificate, "example", acm.CertificateConfig{
    			CertificateArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx
    from ubx.aws.data.acm import Certificate, CertificateConfig

    def describe():

            certificate_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

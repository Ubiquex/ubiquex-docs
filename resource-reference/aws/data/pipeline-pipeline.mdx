AWS Data Pipeline stopped onboarding new customers on July 25, 2024; existing customers can continue using it, with AWS recommending AWS Glue, AWS Step Functions, or Amazon MWAA for new data-integration work.

## Input properties

<ResponseField name="activate" type="bool">
  Indicates whether to validate and start the pipeline or stop an active pipeline. By default, the value is set to true. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the pipeline. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the pipeline. Required.
</ResponseField>

<ResponseField name="parameter_objects" type="list(object)">
  The parameter objects used with the pipeline. Optional.
  <Expandable title="properties">
    <ResponseField name="attributes" type="list(object)">
      Defines the list of key-value attribute pairs (ParameterAttribute) that specify the configuration of a parameter object, such as its default value and description, in the AWS Data Pipeline pipeline definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The name of the attribute within a parameter object in an AWS Data Pipeline pipeline definition, used to specify parameter metadata such as 'description' or 'type'. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="string_value" type="string">
          The string value of an attribute within a parameter object, used to define a parameter's value in the pipeline definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique identifier for this parameter object within the pipeline's parameter definitions, used to reference it from pipeline expressions and resources. Optional; if omitted, computed by AWS. **(AI-inferred)**

  </Expandable>
</ResponseField>

<ResponseField name="parameter_values" type="list(object)">
  The parameter values used with the pipeline. Optional.
  <Expandable title="properties">

      The identifier of a parameter defined in the pipeline's ParameterObjects list, used to map this value to that parameter. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="string_value" type="string">

  </Expandable>
</ResponseField>

<ResponseField name="pipeline_objects" type="list(object)">
  The objects that define the pipeline. These objects overwrite the existing pipeline definition. Not all objects, fields, and values can be updated. For information about restrictions, see Editing Your Pipeline in the AWS Data Pipeline Developer Guide. Optional.
  <Expandable title="properties">
    <ResponseField name="fields" type="list(object)">
      Defines the properties of each pipeline object via a list of key-value pairs (Field objects), which specify attributes such as name, type, schedule, and dependencies, either as literal values or references to other pipeline objects. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          The key is the name of the field in a Data Pipeline object definition, such as 'name', 'type', or 'schedule'. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="ref_value" type="string">
          The reference to another pipeline object's ID, used to link objects within the pipeline definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="string_value" type="string">
          Sets the literal string value for a field in a Data Pipeline object definition, used when the field holds a direct string rather than a reference to another pipeline object. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique identifier for this pipeline object within the pipeline definition, used to reference it from other objects. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The user-defined name of a pipeline object within the AWS Data Pipeline definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pipeline_tags" type="list(object)">

  <Expandable title="properties">

    <ResponseField name="value" type="string">

    </ResponseField>
  </Expandable>
</ResponseField>

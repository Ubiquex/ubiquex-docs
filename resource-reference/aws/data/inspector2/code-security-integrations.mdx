---
title: "aws_inspector2_code_security_integrations"
description: "`data_aws_inspector2_code_security_integrations` looks up a real, already-existing `aws_inspector_v2_code_security_integration`."
---

It connects Amazon Inspector to a real source-code platform, GitHub or GitLab, so Inspector's Code Security capability can scan up to 100,000 real repositories' default branches for vulnerabilities directly in the source, shifting detection left of a deployed, running resource. Launched June 2025.

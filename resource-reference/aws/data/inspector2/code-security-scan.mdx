---
title: "aws_inspector2_code_security_scan"
description: "`data_aws_inspector2_code_security_scan` looks up a real, already-existing `aws_inspector_v2_code_security_scan_configuration`."
---

It defines real scanning rules, applied by default to every new repository or scoped to specific ones by tag, under an `aws_inspector_v2_code_security_integration`, up to three default configurations per project.

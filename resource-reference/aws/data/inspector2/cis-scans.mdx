---
title: "aws_inspector2_cis_scans"
description: "`data_aws_inspector2_cis_scans` looks up a real, already-existing `aws_inspector_v2_cis_scan_configuration`."
---

It schedules real, recurring CIS benchmark compliance scans against EC2 instances, checking actual operating-system configuration against a defined CIS standard rather than the vulnerability scanning Inspector v2 otherwise focuses on.

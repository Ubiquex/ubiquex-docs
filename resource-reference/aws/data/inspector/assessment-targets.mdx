---
title: "aws_inspector_assessment_targets"
description: "`data_aws_inspector_assessment_targets` looks up a real, already-existing `aws_inspector_assessment_target`."
---

It defined a real, tag-based group of EC2 instances that an `aws_inspector_assessment_template` ran a security assessment against, in Amazon Inspector Classic, the original architecture Amazon Inspector shipped with. Inspector Classic is no longer available to new accounts, or to accounts that haven't run an assessment in the last 6 months, and reaches full end of support on May 20, 2026; the redesigned Amazon Inspector (Inspector v2) is the current, actively developed service.

---
title: "aws_inspector_assessment_templates"
description: "`data_aws_inspector_assessment_templates` looks up a real, already-existing `aws_inspector_assessment_template`."
---

It defined the real rules packages and duration for a security assessment run against an `aws_inspector_assessment_target` in Amazon Inspector Classic. Reaches full end of support May 20, 2026, alongside the rest of Inspector Classic.

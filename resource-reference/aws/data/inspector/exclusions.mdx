## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	inspector "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/inspector"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_inspector_exclusions"})

    		ubx.Data(inspector.Exclusions, "example", inspector.ExclusionsConfig{
    			ExclusionArns: []string{"example"},
    			Locale:        "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.data.inspector import Exclusions, ExclusionsConfig

    def describe():
        ubx.intent("look up aws_inspector_exclusions")

        ubx.data(Exclusions, "example", ExclusionsConfig(
            exclusion_arns=["example"],
            locale="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="exclusion_arns" type="list(string)" required>
  The real Amazon Resource Names (ARNs) of the exclusions this request is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="locale" type="string">
  The real locale this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="exclusions" type="map(object)">
  The real exclusions included in this result. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="failed_items" type="map(object)">
  The real items that failed to process, in this batch request. **(AI-inferred)** Returned by the lookup.

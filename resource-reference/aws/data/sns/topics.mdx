---
title: "aws_sns_topics"
description: "`data_aws_sns_topics` looks up a real, already-existing `aws_sns_topic`."
---

It creates a real pub/sub topic that fans a published message out to every one of its subscribed endpoints, SQS queues, Lambda functions, HTTP(S) endpoints, email, SMS, at once.

## Example

<Tabs>

    package main

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sns_topics"})

    		ubx.Data(sns.Topics, "example", sns.TopicsConfig{})
    	}))
    }

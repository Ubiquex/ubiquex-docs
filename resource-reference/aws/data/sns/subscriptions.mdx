---
title: "aws_sns_subscriptions"
description: "`data_aws_sns_subscriptions` looks up a real, already-existing `aws_sns_subscription`."
---

It subscribes a real endpoint, an SQS queue, Lambda function, HTTPS URL, email, or phone number, to an `aws_sns_topic`, the resource that actually receives every message the topic publishes.

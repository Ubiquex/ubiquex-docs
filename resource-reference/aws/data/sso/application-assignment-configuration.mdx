---
title: "aws_sso_application_assignment_configuration"
description: "`data_aws_sso_application_assignment_configuration` looks up a real, already-existing `aws_sso_application_assignment`."
---

It grants a real user or group access to an `aws_sso_application`, the resource that actually authorizes that identity to sign in to the customer-managed application through IAM Identity Center.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sso "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/sso"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sso_application_assignment_configuration"})

    		ubx.Data(sso.ApplicationAssignmentConfiguration, "example", sso.ApplicationAssignmentConfigurationConfig{
    			ApplicationArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

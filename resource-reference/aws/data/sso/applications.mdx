---
title: "aws_sso_applications"
description: "`data_aws_sso_applications` looks up a real, already-existing `aws_sso_application`."
---

It registers a real, customer-managed application with an AWS IAM Identity Center instance, so it can participate in Identity Center's single sign-on alongside AWS's own built-in application integrations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sso "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/sso"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_sso_applications"})

    		ubx.Data(sso.Applications, "example", sso.ApplicationsConfig{
    			InstanceArn: "arn:aws:iam::123456789012:policy/example",
    			Filter:      map[string]any{"application_account": "example"},
    			MaxResults:  1,
    		})
    	}))
    }
    ```
  </Tab>

---
title: "aws_sso_permissions_boundary_for_permission_set"
description: "`data_aws_sso_permissions_boundary_for_permission_set` looks up a real, already-existing `aws_sso_permission_set`."
---

It defines a real, reusable collection of IAM policies, managed, inline, and a permissions boundary, that an IAM Identity Center instance provisions as an assumable IAM role in each AWS account a user or group is assigned access to.

## Lookup arguments

<ResponseField name="instance_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the instance this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="permission_set_arn" type="string" required>
  The real Amazon Resource Name (ARN) of the permission set this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="permissions_boundary" type="object">
  &lt;p&gt;Specifies the configuration of the Amazon Web Services managed or customer managed policy that you want to set as a permissions boundary. Specify either &lt;code&gt;CustomerManagedPolicyReference&lt;/code&gt; to use the name and path of a customer managed policy, or &lt;code&gt;ManagedPolicyArn&lt;/code&gt; to use the ARN of an Amazon Web Services managed policy. A permissions boundary represents the maximum permissions that any policy can grant your role. For more information, see &lt;a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/access_policies_boundaries.html"&gt;Permissions boundaries for IAM entities&lt;/a&gt; in the &lt;i&gt;IAM User Guide&lt;/i&gt;.&lt;/p&gt; &lt;important&gt; &lt;p&gt;Policies used as permissions boundaries don't provide permissions. You must also attach an IAM policy to the role. To learn how the effective permissions for a role are evaluated, see &lt;a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_evaluation-logic.html"&gt;IAM JSON policy evaluation logic&lt;/a&gt; in the &lt;i&gt;IAM User Guide&lt;/i&gt;.&lt;/p&gt; &lt;/important&gt; Returned by the lookup.

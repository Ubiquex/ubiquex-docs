  &lt;p&gt;Specifies the configuration of the Amazon Web Services managed or customer managed policy that you want to set as a permissions boundary. Specify either &lt;code&gt;CustomerManagedPolicyReference&lt;/code&gt; to use the name and path of a customer managed policy, or &lt;code&gt;ManagedPolicyArn&lt;/code&gt; to use the ARN of an Amazon Web Services managed policy. A permissions boundary represents the maximum permissions that any policy can grant your role. For more information, see &lt;a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/access_policies_boundaries.html"&gt;Permissions boundaries for IAM entities&lt;/a&gt; in the &lt;i&gt;IAM User Guide&lt;/i&gt;.&lt;/p&gt; &lt;important&gt; &lt;p&gt;Policies used as permissions boundaries don't provide permissions. You must also attach an IAM policy to the role.

---
title: "aws_sso_permission_sets"
description: "`data_aws_sso_permission_sets` looks up a real, already-existing `aws_sso_permission_set`."
---

It defines a real, reusable collection of IAM policies, managed, inline, and a permissions boundary, that an IAM Identity Center instance provisions as an assumable IAM role in each AWS account a user or group is assigned access to.

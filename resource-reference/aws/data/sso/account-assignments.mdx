---
title: "aws_sso_account_assignments"
description: "`data_aws_sso_account_assignments` looks up a real, already-existing `aws_sso_assignment`."
---

It grants a real user or group an `aws_sso_permission_set` in a specific AWS account, the resource that actually provisions that assumable IAM role and authorizes the identity to use it.

    	ubx.Main(ubx.Stack("example", func() {

---
title: "aws_lakeformation_data_lake_settings"
description: "`data_aws_lakeformation_data_lake_settings` looks up a real, already-existing `aws_lake_formation_data_lake_settings`."
---

It configures the real account-level defaults for AWS Lake Formation, including data lake administrators and whether new Data Catalog databases and tables default to Lake Formation's own permission model or fall back to legacy IAM-only access.

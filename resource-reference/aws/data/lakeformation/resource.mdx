---
title: "aws_lakeformation_resource"
description: "`data_aws_lakeformation_resource` looks up a real, already-existing `aws_lake_formation_resource`."
---

It registers a real S3 location with Lake Formation, the real prerequisite step that brings that storage location under Lake Formation's own permission model rather than leaving access to bucket policies and IAM alone.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	lakeformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/lakeformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_lakeformation_resource"})

    		ubx.Data(lakeformation.Resource, "example", lakeformation.ResourceConfig{
    			ResourceArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Resource } from "@ubx/sdk-aws/aws/data/lakeformation/resource";

    export default stack("example", () => {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.data.lakeformation import Resource, ResourceConfig

    def describe():
        ubx.intent("look up aws_lakeformation_resource")

        ubx.data(Resource, "example", ResourceConfig(
            resource_arn="arn:aws:iam::123456789012:policy/example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

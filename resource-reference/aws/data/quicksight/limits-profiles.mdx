---
title: "aws_quicksight_limits_profiles"
description: "`data_aws_quicksight_limits_profiles` looks up a real, already-existing `aws_quick_sight_limits_profile`."
---

It defines a real set of usage limits, embedding session counts, API rate limits, that can be applied to control consumption of QuickSight/Amazon Quick resources within an account or by a specific group of users.

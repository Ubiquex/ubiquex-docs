---
title: "aws_quicksight_dashboards"
description: "`data_aws_quicksight_dashboards` looks up a real, already-existing `aws_quick_sight_dashboard`."
---

It publishes a real, read-only, shareable view of an `aws_quick_sight_analysis`, the resource end users actually open to view visuals rather than edit them. Like Analysis and Template, its own visualization-definition schema is real but too deeply nested for individual field-level AI description, a documented exclusion in this corpus.

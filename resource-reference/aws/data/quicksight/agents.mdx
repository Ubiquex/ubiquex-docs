---
title: "aws_quicksight_agents"
description: "`data_aws_quicksight_agents` looks up a real, already-existing `aws_quick_sight_agent`."
---

It creates a real, purpose-built AI agent within Amazon Quick, backed by an `aws_quick_sight_action_connector` for taking real actions and a knowledge source for grounding, the entity an end user or an embedded chat experience actually converses with.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_agents"})

    		ubx.Data(quicksight.Agents, "example", quicksight.AgentsConfig{
    			AwsAccountId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

---
title: "aws_quicksight_topic_permissions_v2"
description: "`data_aws_quicksight_topic_permissions_v2` looks up a real, already-existing `aws_quick_sight_topic_v2`."
---

It defines a newer-generation version of an `aws_quick_sight_topic`, Amazon Quick's current natural-language topic configuration, superseding the original topic resource's schema for new topics.

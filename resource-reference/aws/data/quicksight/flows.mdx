---
title: "aws_quicksight_flows"
description: "`data_aws_quicksight_flows` looks up a real, already-existing `aws_quick_sight_flow`."
---

It defines a real Quick Flow, an automated, multi-step workflow within Amazon Quick, part of the AI-workspace capabilities QuickSight evolved into after its October 2025 rename to Amazon Quick Suite (shortened to Amazon Quick in 2026).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_flows"})

    		ubx.Data(quicksight.Flows, "example", quicksight.FlowsConfig{
    			AwsAccountId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

---
title: "aws_quicksight_spaces"
description: "`data_aws_quicksight_spaces` looks up a real, already-existing `aws_quick_sight_space`."
---

It creates a real Quick Space, a collaborative workspace within Amazon Quick where files, chat, and knowledge bases are shared among a defined group of users, part of the AI-workspace capabilities QuickSight evolved into.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_spaces"})

    			MaxResults:   1,
    		})
    	}))
    }

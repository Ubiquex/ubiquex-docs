---
title: "aws_quicksight_data_sources"
description: "`data_aws_quicksight_data_sources` looks up a real, already-existing `aws_quick_sight_data_source`."
---

It defines a real connection to an external system, a database, S3, or a SaaS application, that one or more `aws_quick_sight_data_set`s pull data from.

## Example

<Tabs>
  <Tab title="Go">

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_data_sources"})

    		ubx.Data(quicksight.DataSources, "example", quicksight.DataSourcesConfig{

    		})
    	}))
    }

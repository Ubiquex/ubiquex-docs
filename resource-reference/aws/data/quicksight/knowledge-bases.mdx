---
title: "aws_quicksight_knowledge_bases"
description: "`data_aws_quicksight_knowledge_bases` looks up a real, already-existing `aws_quick_sight_knowledge_base`."
---

It connects a real content source, SharePoint, OneDrive, and similar, into Amazon Quick's Quick Index component, so its agents can ground answers in that organization's own documents.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_knowledge_bases"})

    		ubx.Data(quicksight.KnowledgeBases, "example", quicksight.KnowledgeBasesConfig{
    			AwsAccountId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

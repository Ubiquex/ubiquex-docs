---
title: "aws_quicksight_data_sets"
description: "`data_aws_quicksight_data_sets` looks up a real, already-existing `aws_quick_sight_data_set`."
---

It defines a real, queryable dataset, built from one or more `aws_quick_sight_data_source`s with its own joins, calculated fields, and row-level security, that dashboards and analyses in QuickSight/Amazon Quick are built against.

---
title: "aws_quicksight_folders"
description: "`data_aws_quicksight_folders` looks up a real, already-existing `aws_quick_sight_folder`."
---

It creates a real folder that organizes `aws_quick_sight_data_set`s, dashboards, analyses, and other QuickSight/Amazon Quick assets, and that permissions can be applied to in bulk rather than per asset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/data/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_folders"})

    		ubx.Data(quicksight.Folders, "example", quicksight.FoldersConfig{
    			AwsAccountId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

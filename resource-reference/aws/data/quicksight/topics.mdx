---
title: "aws_quicksight_topics"
description: "`data_aws_quicksight_topics` looks up a real, already-existing `aws_quick_sight_topic`."
---

It defines a real natural-language topic, an `aws_quick_sight_data_set` plus curated field synonyms and calculations, that QuickSight/Amazon Quick's Q&A feature answers plain-English questions against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_topics"})

    		ubx.Data(quicksight.Topics, "example", quicksight.TopicsConfig{
    			AwsAccountId: "example",
    			MaxResults:   1,
    		})
    	}))
    }
    ```

---
title: "aws_quicksight_refresh_schedules"
description: "`data_aws_quicksight_refresh_schedules` looks up a real, already-existing `aws_quick_sight_refresh_schedule`."
---

It schedules real, recurring refreshes of an `aws_quick_sight_data_set`'s underlying data, on a daily, weekly, monthly, or custom cadence.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_refresh_schedules"})

    		ubx.Data(quicksight.RefreshSchedules, "example", quicksight.RefreshSchedulesConfig{
    			AwsAccountId: "example",
    			DataSetId:    "example",
    		})
    	}))
    }
    ```

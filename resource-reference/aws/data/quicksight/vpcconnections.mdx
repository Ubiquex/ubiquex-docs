---
title: "aws_quicksight_vpcconnections"
description: "`data_aws_quicksight_vpcconnections` looks up a real, already-existing `aws_quick_sight_vpcconnection`."
---

It creates a real, persistent elastic network interface into a VPC that an `aws_quick_sight_data_source` can route through to reach a database that isn't publicly reachable.

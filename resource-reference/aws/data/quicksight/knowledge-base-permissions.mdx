---
title: "aws_quicksight_knowledge_base_permissions"
description: "`data_aws_quicksight_knowledge_base_permissions` looks up a real, already-existing `aws_quick_sight_knowledge_base`."
---

It connects a real content source, SharePoint, OneDrive, and similar, into Amazon Quick's Quick Index component, so its agents can ground answers in that organization's own documents.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_knowledge_base_permissions"})

    		ubx.Data(quicksight.KnowledgeBasePermissions, "example", quicksight.KnowledgeBasePermissionsConfig{
    			AwsAccountId:    "example",
    			KnowledgeBaseId: "example",
    		})
    	}))
    }

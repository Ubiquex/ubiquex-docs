---
title: "aws_quicksight_themes"
description: "`data_aws_quicksight_themes` looks up a real, already-existing `aws_quick_sight_theme`."
---

It defines a real, reusable set of colors, fonts, and layout options that can be applied to dashboards in QuickSight/Amazon Quick, so visual styling stays consistent without configuring it dashboard by dashboard.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	quicksight "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/data/quicksight"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up aws_quicksight_themes"})

    		ubx.Data(quicksight.Themes, "example", quicksight.ThemesConfig{
    			AwsAccountId: "example",
    			MaxResults:   1,
    			Type:         "example",
    		})
    	}))
    }
    ```

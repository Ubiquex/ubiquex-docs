## Lookup arguments

<ResponseField name="resource_arn" type="string" required>
  ARN of a taggable Agent Registry resource. Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="tags" type="map(string)">
  A map of tag keys to tag values returned by read operations (may be empty). Returned by the lookup.
</ResponseField>

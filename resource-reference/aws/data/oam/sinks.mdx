---
title: "aws_oam_sinks"
description: "`data_aws_oam_sinks` looks up a real, already-existing `aws_oam_sink`."
---

It creates a real attachment point in a monitoring account under CloudWatch Observability Access Manager, the resource that an `aws_oam_link` from a source account actually connects to; a sink is managed by the monitoring account, one per Region, and must exist along with its own sink policy before any source account can link to it.

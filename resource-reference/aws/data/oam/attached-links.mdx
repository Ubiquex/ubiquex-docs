---
title: "aws_oam_attached_links"
description: "`data_aws_oam_attached_links` looks up a real, already-existing `aws_oam_link`."
---

It creates a real cross-account link from a source account into a monitoring account under CloudWatch Observability Access Manager, sharing a filtered set of that source account's logs, metrics, and traces so they can be viewed centrally without switching accounts.

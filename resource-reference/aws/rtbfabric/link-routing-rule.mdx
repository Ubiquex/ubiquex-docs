`aws_rtbfabric_link_routing_rule` defines a real routing rule on an `aws_rtbfabric_link`, controlling how real-time bidding traffic flowing across that link is directed.

    <ResponseField name="host_header" type="string">
      Exact host match  --  RFC 3986 unreserved characters. Mutually exclusive with HostHeaderWildcard. Optional.
    </ResponseField>
    <ResponseField name="host_header_wildcard" type="string">
      Wildcard host pattern (e.g., *.example.com)  --  RFC 3986 unreserved characters plus *. Mutually exclusive with HostHeader. Optional.
    </ResponseField>
    <ResponseField name="path_exact" type="string">
      Exact path match  --  must start with /. Mutually exclusive with PathPrefix. Optional.

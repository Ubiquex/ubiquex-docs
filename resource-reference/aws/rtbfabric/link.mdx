`aws_rtbfabric_link` creates a real, AWS-managed bidirectional connection component within AWS RTB Fabric, linking an `aws_rtbfabric_requester_gateway` to an `aws_rtbfabric_responder_gateway` for real-time bidding (RTB) advertising-exchange traffic. AWS RTB Fabric reached general availability in October 2025, roughly ten months ago, so behavior here is verified live rather than assumed from general knowledge.

`aws_rtbfabric_inbound_external_link` connects a real external bidder or exchange into an `aws_rtbfabric_responder_gateway`, the inbound counterpart within AWS RTB Fabric, manageable only through the RTB Fabric API, CLI, or CloudFormation rather than the console.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})
    	}))
    }

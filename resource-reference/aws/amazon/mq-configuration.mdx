`aws_amazon_mq_configuration` defines the engine-specific settings (XML for ActiveMQ, a config file for RabbitMQ) that an `aws_amazon_mq_broker` runs with, kept as a separate, versioned resource so the same configuration can be validated and reused across brokers instead of being edited in place on each one.

## Example

    package main

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Name:                   "example",
    			AuthenticationStrategy: "example",
    			Data:                   "example",
    			Description:            "Managed by ubx.",
    			EngineVersion:          "example",
    			Tags:                   []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="authentication_strategy" type="string">
  The authentication strategy associated with the configuration. The default is SIMPLE. Optional.
</ResponseField>

<ResponseField name="data" type="string">
  The base64-encoded XML configuration. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the configuration. Optional.
</ResponseField>

<ResponseField name="engine_type" type="string" required>
  The type of broker engine. Note: Currently, Amazon MQ only supports ACTIVEMQ for creating and editing broker configurations. Required.
</ResponseField>

<ResponseField name="engine_version" type="string">
  The version of the broker engine. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the configuration. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Create tags when creating the configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Amazon MQ configuration, used to identify and organize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon MQ configuration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the Amazon MQ configuration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="revision" type="string">
  The revision number of the configuration. Computed by AWS after `ship`.
</ResponseField>

---
title: "aws_amazon_mq_configuration_association"
description: "`aws_amazon_mq_configuration_association` is the real link between an `aws_amazon_mq_configuration` and the `aws_amazon_mq_broker` it applies to."
---

A configuration on its own changes nothing, this association is what actually applies a given configuration revision to a running broker.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    			Configuration: map[string]any{"id": "example"},
    		})

    }

## Input properties

<ResponseField name="broker" type="string" required>
  ID of the Broker that the configuration should be applied to Required.
</ResponseField>

<ResponseField name="configuration" type="object" required>
  Specifies the Amazon MQ configuration (ID and revision) to associate with the broker in a ConfigurationAssociation resource. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="id" type="string" required>
      ID of the Configuration to apply to a Broker Required.
    </ResponseField>
    <ResponseField name="revision" type="number" required>
      Revision of the Configuration to apply to a Broker Required.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of the ConfigurationAssociation Resource Computed by AWS after `ship`.
</ResponseField>

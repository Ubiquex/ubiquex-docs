`aws_s3_express_directory_bucket` creates a real S3 Express One Zone bucket, storing data in a single Availability Zone with a directory-bucket structure for consistent, single-digit-millisecond request latency, distinct from a standard, multi-AZ `aws_s3_bucket`.

## Input properties

<ResponseField name="bucket_encryption" type="object">
  Specifies default encryption for a bucket using server-side encryption with Amazon S3 managed keys (SSE-S3) or AWS KMS keys (SSE-KMS). Optional.
  <Expandable title="properties">
    <ResponseField name="server_side_encryption_configuration" type="list(object)" required>
      Specifies the default server-side-encryption configuration. Required.
      <Expandable title="properties">
        <ResponseField name="bucket_key_enabled" type="bool">
          Enables or disables an S3 Bucket Key for the directory bucket's default SSE-KMS encryption, reducing per-request AWS KMS costs. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="server_side_encryption_by_default" type="object">
          Defines the default server-side encryption configuration for the S3 Express Directory Bucket, choosing either SSE-S3 or SSE-KMS with an optional KMS key ID that is applied to objects written without an explicit encryption header. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="kmsmaster_key_id" type="any">
              The AWS KMS customer master key (CMK) ID or ARN used for default server-side encryption with KMS (SSE-KMS) for the S3 Express directory bucket, effective when the SSE algorithm is set to 'aws:kms'. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="ssealgorithm" type="string">
              Specifies the default server-side encryption algorithm (such as AES256 or aws:kms) for objects stored in the S3 Express directory bucket, used when encryption is not specified at upload time. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="bucket_name" type="string">
  Specifies a name for the bucket. The bucket name must contain only lowercase letters, numbers, and hyphens (-). A directory bucket name must be unique in the chosen Availability Zone or Local Zone. The bucket name must also follow the format 'bucket_base_name--zone_id--x-s3'. The zone_id can be the ID of an Availability Zone or a Local Zone. If you don't specify a name, AWS CloudFormation generates a unique physical ID and uses that ID for the bucket name. Optional.
</ResponseField>

<ResponseField name="data_redundancy" type="string" required>
  Specifies the number of Availability Zone or Local Zone that's used for redundancy for the bucket. Required.
</ResponseField>

        <ResponseField name="expiration_in_days" type="number">

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the specified bucket. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="availability_zone_name" type="string">
  Returns the code for the Availability Zone or Local Zone where the directory bucket was created. An example for the code of an Availability Zone is 'us-east-1f'. Computed by AWS after `ship`.
</ResponseField>

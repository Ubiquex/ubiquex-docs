`aws_s3_express_bucket_policy` attaches a real resource-based access policy to an `aws_s3_express_directory_bucket`, controlling which principals can access that S3 Express One Zone bucket.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3express "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/s3express"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own bucket policy"})

    		ubx.Resource(s3express.BucketPolicy, "example", s3express.BucketPolicyConfig{
    			Bucket:         "example",
    			PolicyDocument: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="bucket" type="string" required>
  The name of the S3 directory bucket to which the policy applies. Required.
</ResponseField>

<ResponseField name="policy_document" type="any" required>
  A policy document containing permissions to add to the specified bucket. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. Required.
</ResponseField>

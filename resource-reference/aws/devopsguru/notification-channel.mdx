`aws_dev_ops_guru_notification_channel` sends a real SNS notification, filterable by severity, the moment DevOps Guru creates a new insight, up to two topics configurable so the right people or systems find out about a detected operational anomaly without polling the console.

## Example

    ```go
    package main

    import (
    	devopsguru "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/devopsguru"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own notification channel"})

    		ubx.Resource(devopsguru.NotificationChannel, "example", devopsguru.NotificationChannelConfig{
    			Config: map[string]any{"filters": map[string]any{"message_types": []string{"example"}}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="config" type="object" required>
  Information about notification channels you have configured with DevOps Guru. Required.
  <Expandable title="properties">
    <ResponseField name="filters" type="object">
      Information about filters of a notification channel configured in DevOpsGuru to filter for insights. Optional.
      <Expandable title="properties">
        <ResponseField name="message_types" type="list(string)">
          DevOps Guru message types to filter for Optional.
        </ResponseField>
        <ResponseField name="severities" type="list(string)">
          DevOps Guru insight severities to filter for Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="sns" type="object">
      Information about a notification channel configured in DevOps Guru to send notifications when insights are created. Optional.
      <Expandable title="properties">
        <ResponseField name="topic_arn" type="string">
          The ARN of the Amazon SNS topic that DevOps Guru publishes notification messages to for this channel. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of a notification channel. Computed by AWS after `ship`.
</ResponseField>

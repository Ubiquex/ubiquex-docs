`aws_fms_resource_set` is a real, named collection of specific resources that an `aws_fms_policy` can reference directly, scoping a policy to an explicit resource list rather than only a broader tag- or account-based filter.

## Input properties

<ResponseField name="description" type="string">
  An optional, user-defined text field that describes the purpose or contents of the AWS Firewall Manager resource set, aiding in identification and management. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Firewall Manager resource set, which must be unique within the account and is used to identify the resource set in AWS Firewall Manager. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_type_list" type="list(string)" required>
  Specifies the list of AWS resource types (such as AWS::S3::Bucket or AWS::EC2::Instance) that are included in the resource set, which Firewall Manager uses to identify the resources to apply policies to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resources" type="list(string)">
  Specifies the list of resource identifiers (such as ARNs) that make up this Firewall Manager resource set, which can then be associated with a Firewall Manager policy. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">

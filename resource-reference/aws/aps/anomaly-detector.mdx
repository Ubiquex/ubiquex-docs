`aws_aps_anomaly_detector` runs machine learning, specifically the Random Cut Forest algorithm, against a metric in an `aws_aps_workspace` to learn its normal pattern and flag deviations, producing new anomaly and confidence-score time series that can drive alerting rules or be visualized alongside the original metric.

## Input properties

<ResponseField name="alias" type="string" required>
  The AnomalyDetector alias. Required.
</ResponseField>

<ResponseField name="configuration" type="object" required>
  Configures the anomaly detector with a PromQL-based metric definition and optional dimension filters that determine which metric time series are analyzed for anomalous behavior. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="random_cut_forest" type="object" required>
      Defines the configuration for the Random Cut Forest algorithm used by this anomaly detector to identify anomalous patterns in Prometheus metric data. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="ignore_near_expected_from_above" type="any">
          Controls the Random Cut Forest anomaly detection sensitivity by specifying whether to ignore data points that are close to the expected value from above, reducing false positives for minor upper-side deviations. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="ignore_near_expected_from_below" type="any">
          When enabled, this parameter instructs the Random Cut Forest anomaly detector to ignore deviations that are below but very close to the expected value, preventing them from being flagged as anomalies. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="query" type="string" required>
          The PromQL query that selects the time series data to be analyzed for anomalies by the random cut forest algorithm in the anomaly detector. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="sample_size" type="number">
          In the Random Cut Forest configuration of an AWS APS anomaly detector, sample_size specifies the number of data points from the input time series used to train the model, balancing training accuracy against computational cost. Optional. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="shingle_size" type="number">
          The number of consecutive time series data points grouped into a single shingle (feature vector) that the Random Cut Forest model considers when evaluating anomalies. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>

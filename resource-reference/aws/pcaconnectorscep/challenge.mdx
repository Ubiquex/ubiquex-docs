`aws_pcaconnector_scep_challenge` creates a real, static SCEP password that a device or mobile device management system presents to an `aws_pcaconnector_scep_connector` to authenticate its certificate enrollment request.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	pcaconnectorscep "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/pcaconnectorscep"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own challenge"})

    		ubx.Resource(pcaconnectorscep.Challenge, "example", pcaconnectorscep.ChallengeConfig{
    			ConnectorArn: "arn:aws:iam::123456789012:policy/example",
    			Tags:         "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="connector_arn" type="string" required>
  The Amazon Resource Name (ARN) of the connector that this SCEP challenge belongs to, required to create the challenge under that connector. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

## Output properties

<ResponseField name="challenge_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the SCEP challenge within AWS Private CA Connector for SCEP, assigned by AWS when the challenge is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

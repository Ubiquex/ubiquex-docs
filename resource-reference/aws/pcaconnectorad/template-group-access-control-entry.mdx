`aws_pcaconnector_ad_template_group_access_control_entry` grants a real AD security group permission to enroll for certificates against an `aws_pcaconnector_ad_template`, controlling who can actually request a certificate from that template.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			GroupSecurityIdentifier: "example",

    		})

## Properties

<ResponseField name="access_rights" type="object" required>
  Specifies the permissions for the group on the certificate template, including which operations are allowed or denied (such as enroll and autoenroll) via nested Allow and Deny blocks. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="auto_enroll" type="string">
      Specifies whether the group is granted permission to automatically enroll for certificates, with allowed values 'ALLOW' or 'DENY'. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="enroll" type="string">
      Sets whether the associated Active Directory group is allowed to enroll for certificates using the configured certificate template, forming the enroll access right in this template group access control entry. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="group_display_name" type="string" required>
  Specifies the display name of the Active Directory security group that this template access control entry grants certificate enrollment permissions to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="group_security_identifier" type="string" required>
  Specifies the security identifier (SID) of the Active Directory group to which this access control entry grants permissions for the associated template. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="template_arn" type="string" required>
  The Amazon Resource Name (ARN) of the AWS Private CA Connector for Active Directory template that this group access control entry applies to. Required. **(AI-inferred)**
</ResponseField>

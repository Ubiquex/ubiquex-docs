`aws_mpa_approval_team` creates a real, named group of approvers under AWS Multi-party approval, so that specific sensitive actions elsewhere in AWS require multiple people from this team to approve before they take effect. A team created this way starts in a pending-activation state; if an invited approver declines or the 24-hour response window expires, activation fails and the stack rolls back, deleting the team. Multi-party approval is a comparatively new AWS service, so behavior here is verified live rather than assumed from general knowledge.

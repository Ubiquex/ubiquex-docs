`aws_mpa_identity_source` registers a real source of approver identities, such as an IAM Identity Center instance, that an `aws_mpa_approval_team` draws its members from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	mpa "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/mpa"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own identity source"})

    		ubx.Resource(mpa.IdentitySource, "example", mpa.IdentitySourceConfig{
    			Tags: []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

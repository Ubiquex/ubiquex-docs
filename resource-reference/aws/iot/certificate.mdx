`aws_io_t_certificate` is a real X.509 certificate AWS IoT issues or registers for device authentication, the actual credential an `aws_io_t_thing` presents to authenticate its MQTT or HTTPS connection to AWS IoT Core.

## Example

    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="cacertificate_pem" type="string">
  The PEM-encoded CA certificate that signed the device certificate, used when registering the certificate with a certificate authority. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_mode" type="string">
  Specifies the certificate mode (DEFAULT or SNI_ONLY) for the AWS IoT certificate, determining whether it is used with the standard IoT endpoint or only with SNI-based custom domains. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_pem" type="string">
  The PEM-encoded certificate data that AWS IoT registers when you import an existing certificate rather than creating one from a certificate signing request. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="certificate_signing_request" type="string">
  The PEM-encoded certificate signing request (CSR) used to create the certificate, allowing the certificate to be issued from an existing key pair rather than generating a new one. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string" required>
  Specifies the operational status of the AWS IoT certificate, such as ACTIVE, INACTIVE, REVOKED, PENDING_TRANSFER, or PENDING_ACTIVATION, which determines whether the certificate can be used for authentication. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) assigned to the IoT certificate, used to uniquely identify it within AWS IoT and IAM policies. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique certificate ID (a UUID-like string) generated by AWS IoT for the certificate, serving as the resource's primary identifier. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

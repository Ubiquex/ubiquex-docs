`aws_io_t_logging` configures real, account-wide CloudWatch Logs delivery for AWS IoT Core activity, connection attempts, rule executions, errors, at a defined verbosity level.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own logging"})

    		ubx.Resource(iot.Logging, "example", iot.LoggingConfig{
    			AccountId:           "example",
    			DefaultLogLevel:     "example",
    			RoleArn:             "arn:aws:iam::123456789012:policy/example",
    			EventConfigurations: []map[string]any{{"event_type": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="account_id" type="string" required>
  Your 12-digit account ID (used as the primary identifier for the CloudFormation resource). Required.
</ResponseField>

<ResponseField name="default_log_level" type="string" required>
  The log level to use. Valid values are: ERROR, WARN, INFO, DEBUG, or DISABLED. Required.
</ResponseField>

<ResponseField name="event_configurations" type="list(object)">
  Configurations for event-based logging that specifies which event types to log and their logging settings. Overrides account-level logging for the specified event Optional.
  <Expandable title="properties">
    <ResponseField name="event_type" type="string">
      The AWS IoT event type (such as MqttActivity, Connections, or DeviceShadowOperations) that this logging configuration applies to within the event configurations map. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="log_destination" type="string">
      The destination ARN (e.g., an Amazon CloudWatch Logs log group or Amazon S3 bucket) to which AWS IoT delivers logs for the corresponding event configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="log_level" type="string">
      For each event type in the AWS IoT logging event configurations, this property sets the log level (e.g., DEBUG, INFO, ERROR, WARN, or DISABLED) that controls how detailed the IoT logs are for that event type. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The ARN of the role that allows IoT to write to Cloudwatch logs. Required.
</ResponseField>

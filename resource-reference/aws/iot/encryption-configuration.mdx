`aws_io_t_encryption_configuration` sets a real, caller-managed KMS key that AWS IoT Core uses to encrypt data at rest account-wide, in place of AWS's own default encryption key.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own encryption configuration"})

    		ubx.Resource(iot.EncryptionConfiguration, "example", iot.EncryptionConfigurationConfig{
    			EncryptionType:   "example",
    			KmsAccessRoleArn: "arn:aws:iam::123456789012:policy/example",
    			KmsKeyArn:        "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="encryption_type" type="string" required>
  Specifies the type of encryption key used for AWS IoT data encryption, either AWS-owned (AWS_OWNED) or customer-managed (CUSTOMER_MANAGED), determining whether you use an AWS-managed key or your own KMS key. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_access_role_arn" type="string">
  The ARN of the IAM role that AWS IoT assumes to access the customer-managed KMS key used for encrypting device data, required when the encryption type is CUSTOMER_MANAGED_KMS_KEY. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The ARN of a customer-managed AWS KMS key used to encrypt IoT data; when omitted, AWS IoT uses an AWS-managed key. Optional. **(AI-inferred)**
</ResponseField>

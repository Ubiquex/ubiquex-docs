`aws_io_t_mitigation_action` defines a real, automated remediation, revoking a certificate, adding a device to a quarantine thing group, that an `aws_io_t_scheduled_audit`'s findings can trigger automatically rather than requiring a human to act on every audit finding.

    func main() {

    	}))
    }

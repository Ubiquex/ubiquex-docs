`aws_io_t_thing` registers a real device or logical entity in the AWS IoT registry, the actual identity an `aws_io_t_certificate` gets attached to and an `aws_io_t_policy` ultimately governs the permissions of.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own thing"})

    		ubx.Resource(iot.Thing, "example", iot.ThingConfig{
    			AttributePayload: map[string]any{"attributes": "example"},
    			ThingName:        "example-thing-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="attribute_payload" type="object">
  Specifies the thing's attribute payload, including a map of attribute names to values and whether to merge with existing attributes on update. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="attributes" type="any">
      A map of key-value pairs defining the AWS IoT thing's attribute payload, which is used to store and manage the device's metadata attributes. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="thing_name" type="string">
  The unique name to assign to this AWS IoT thing; if omitted, CloudFormation generates a name. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the IoT thing within AWS IoT, used for referencing the thing in IAM policies and other AWS services. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  For an AWS IoT Thing, the computed id is the thing's name, which is the resource's unique identifier within the AWS IoT registry and its CloudFormation physical ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_io_t_authorizer` runs a real, caller-defined Lambda function to authenticate and authorize a device's connection using a custom token scheme, rather than the X.509 certificate model `aws_io_t_certificate` and `aws_io_t_policy` provide.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own t authorizer"})

    		ubx.Resource(iot.Authorizer, "example", iot.AuthorizerConfig{
    			AuthorizerFunctionArn:  "arn:aws:iam::123456789012:policy/example",
    			AuthorizerName:         "example-authorizer-name",
    			EnableCachingForHttp:   true,
    			SigningDisabled:        true,
    			Status:                 "example",
    			Tags:                   []map[string]any{{"key": "example"}},
    			TokenKeyName:           "example-token-key-name",
    			TokenSigningPublicKeys: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="authorizer_function_arn" type="string" required>
  The Amazon Resource Name (ARN) of the Lambda function that AWS IoT invokes to authorize device connections for this authorizer. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorizer_name" type="string">
  The name of the custom IoT authorizer, serving as a unique identifier within the AWS account; if not provided, CloudFormation generates a unique name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_caching_for_http" type="bool">
  Determines whether AWS IoT caches the authorization results for HTTP requests made to this custom authorizer. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="signing_disabled" type="bool">
  Determines whether token signing is disabled for this custom authorizer; when set to true, AWS IoT Core will not require or verify the signature of the authorization token. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The status of the IoT authorizer, indicating whether it is ACTIVE or INACTIVE, which determines if the authorizer is used for authorization. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tags to associate with the AWS IoT Authorizer for organizing and identifying the resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag to attach to the AWS IoT authorizer, used for organizing and identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS IoT authorizer, used to store arbitrary metadata for the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="token_key_name" type="string">
  The name of the HTTP header in the incoming request that contains the authentication token used by this custom authorizer. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="token_signing_public_keys" type="any">
  Specifies a map of public keys, each identified by a logical name, that AWS IoT uses to verify the digital signature of the authorization token. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this AWS IoT authorizer. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

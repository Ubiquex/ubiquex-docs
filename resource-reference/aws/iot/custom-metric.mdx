`aws_io_t_custom_metric` defines a real, caller-specific metric, beyond AWS IoT's own built-in ones, that a device reports and an `aws_io_t_security_profile` can evaluate as part of Device Defender's behavioral detection.

## Input properties

<ResponseField name="display_name" type="string">
  Field represents a friendly name in the console for the custom metric; it doesn't have to be unique. Don't use this name as the metric identifier in the device metric report. Can be updated once defined. Optional.
</ResponseField>

<ResponseField name="metric_name" type="string">
  The name of the custom metric. This will be used in the metric report submitted from the device/thing. Shouldn't begin with aws: . Cannot be updated once defined. Optional.
</ResponseField>

<ResponseField name="metric_type" type="string" required>
  The type of the custom metric. Types include string-list, ip-address-list, number-list, and number. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Represents the key of a tag attached to an AWS IoT Custom Metric, enabling metadata-based identification and management of the metric. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="metric_arn" type="string">
  The Amazon Resource Number (ARN) of the custom metric. Computed by AWS after `ship`.
</ResponseField>

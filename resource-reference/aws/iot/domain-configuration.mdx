`aws_io_t_domain_configuration` lets devices connect to AWS IoT Core over a real, custom domain name and TLS configuration instead of the default AWS-provided IoT endpoint.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	iot "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/iot"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain configuration"})

    		ubx.Resource(iot.DomainConfiguration, "example", iot.DomainConfigurationConfig{
    			ApplicationProtocol:       "example",
    			AuthenticationType:        "example",
    			AuthorizerConfig:          map[string]any{"allow_authorizer_override": true},
    			ClientCertificateConfig:   map[string]any{"client_certificate_callback_arn": "example"},
    			DomainConfigurationName:   "example-domain-configuration-name",
    			DomainConfigurationStatus: "example",
    			DomainName:                "example-domain-name",
    			ServerCertificateArns:     []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx

    from ubx.aws.iot.domain_configuration import DomainConfiguration_AuthorizerConfig, DomainConfiguration_ClientCertificateConfig

            application_protocol="example",

## Input properties

<ResponseField name="application_protocol" type="string">
  Specifies the application protocol (SECURE_MQTT or HTTPS) that the domain configuration is used for, determining which protocol traffic it serves. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authentication_type" type="string">
  Specifies the authentication type (e.g., AWS_X509, AWS_SIGV4, CUSTOM_AUTH, or AWS_IOT_CORE) used by the AWS IoT domain configuration for TLS client authentication. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="authorizer_config" type="object">
  Configures the AWS IoT authorizer used by this domain configuration, including the authorizer name and whether authorizer override is allowed. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="allow_authorizer_override" type="bool">
      When true, allows a client's specific authorizer to override the domain configuration's default authorizer for authentication. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="default_authorizer_name" type="string">
      Specifies the name of the default AWS IoT authorizer used to authenticate requests sent to this domain configuration, overriding the account-level default authorizer. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="client_certificate_config" type="object">
  Configures client certificate authentication for the domain by specifying the ARN of the Lambda function that AWS IoT calls to validate client certificates. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="client_certificate_callback_arn" type="string">
      The ARN of the Lambda function that AWS IoT invokes when a client certificate is presented for authentication, enabling custom certificate validation for this domain configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="domain_configuration_name" type="string">
  The name of the AWS IoT domain configuration, which uniquely identifies the domain configuration within your AWS account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_configuration_status" type="string">
  The desired status (ENABLED or DISABLED) for the domain configuration, which determines whether the domain configuration is active for IoT connections. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_name" type="string">
  The domain name (e.g., 'example.com') to associate with this AWS IoT domain configuration, required when setting up a custom domain for AWS IoT and omitted for AWS-managed endpoint configurations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_certificate_arns" type="list(string)">
  Specifies the ARNs of the AWS Certificate Manager (ACM) certificates used as the server certificates for the IoT domain configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_certificate_config" type="object">
  Configures the server certificate behavior for the IoT domain, specifically enabling Online Certificate Status Protocol (OCSP) stapling checks and optionally specifying a Lambda function ARN for OCSP response handling. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enable_ocspcheck" type="bool">
      Enables or disables the Online Certificate Status Protocol (OCSP) check for the server certificate used by the domain configuration. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ocsp_authorized_responder_arn" type="string">
      The ARN of an OCSP (Online Certificate Status Protocol) authorized responder used by AWS IoT to perform certificate revocation checks for the domain's server certificate. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ocsp_lambda_arn" type="string">
      The ARN of the Lambda function that acts as a custom OCSP responder for validating the server certificate in this AWS IoT domain configuration. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_type" type="string">
  Specifies the type of AWS IoT service (DATA, CREDENTIAL_PROVIDER, or JOBS) that the domain configuration's endpoint is for, determining which service's traffic the domain applies to. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tag objects (key-value pairs) to associate with the IoT domain configuration, which AWS IoT uses for labeling, cost allocation, and access control. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The tag key used to identify a custom metadata label assigned to this AWS IoT domain configuration, enabling resource categorization and filtering. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key applied to the AWS IoT domain configuration, allowing you to attach arbitrary metadata for cost allocation and management. Optional; if omitted, computed by AWS. **(AI-inferred)**

  </Expandable>
</ResponseField>

<ResponseField name="tls_config" type="object">

  <Expandable title="properties">
    <ResponseField name="security_policy" type="string">

    </ResponseField>
  </Expandable>

<ResponseField name="validation_certificate_arn" type="string">

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the IoT domain configuration. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_type" type="string">
  The type of the domain configuration, indicating whether the domain is AWS-managed (AWS_MANAGED) or customer-managed (CUSTOMER_MANAGED). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_certificates" type="list(object)">
  The computed list of server certificates attached to the IoT domain configuration, each containing the certificate ARN and its status. Computed by AWS after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="server_certificate_arn" type="string">
      The Amazon Resource Name (ARN) of an AWS Certificate Manager (ACM) server certificate that AWS IoT uses to secure TLS connections on this custom domain configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="server_certificate_status" type="string">
      Indicates the current status of a server certificate associated with the AWS IoT domain configuration, such as ACTIVE or INACTIVE, reflecting whether the certificate is actively used for TLS termination. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="server_certificate_status_detail" type="string">
      The server certificate status detail, providing a human-readable reason or additional information about the status of the server certificate used by the AWS IoT domain configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

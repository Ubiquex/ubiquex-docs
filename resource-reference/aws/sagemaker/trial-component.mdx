`aws_sage_maker_trial_component` records a real, individual tracked step, a training job, processing job, or transform job, within an `aws_sage_maker_experiment`, capturing its parameters, metrics, and artifacts for later comparison.

## Input properties

<ResponseField name="display_name" type="string">
  The name of the component as displayed. If DisplayName isn't specified, TrialComponentName is displayed. Optional.
</ResponseField>

<ResponseField name="input_artifacts" type="any">
  The input artifacts for the component. Optional.
</ResponseField>

<ResponseField name="metadata_properties" type="object">
  Metadata properties of the tracking entity, trial, or trial component. Optional.
  <Expandable title="properties">
    <ResponseField name="commit_id" type="string">
      The commit ID. Optional.
    </ResponseField>
    <ResponseField name="generated_by" type="string">
      The entity this entity was generated by. Optional.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The project ID. Optional.
    </ResponseField>
    <ResponseField name="repository" type="string">
      The repository. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="output_artifacts" type="any">
  The output artifacts for the component. Optional.
</ResponseField>

<ResponseField name="parameters" type="any">
  The hyperparameters for the component. Optional.
</ResponseField>

<ResponseField name="status" type="object">
  The status of the trial component. Optional.
  <Expandable title="properties">
    <ResponseField name="message" type="string">
      If the component failed, a message describing why. Optional.
    </ResponseField>
    <ResponseField name="primary_status" type="string">
      The status of the trial component. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to associate with the trial component. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag applied to the SageMaker trial component, used to categorize resources for cost allocation and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag applied to the SageMaker trial component, forming a key-value pair used to organize, identify, and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="trial_component_name" type="string" required>
  The name of the trial component. Must be unique in your AWS account and is not case-sensitive. Required.
</ResponseField>

## Output properties

</ResponseField>

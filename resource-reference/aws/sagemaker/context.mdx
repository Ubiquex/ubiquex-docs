`aws_sage_maker_context` groups a real set of related `aws_sage_maker_artifact`s and `aws_sage_maker_action`s in SageMaker's ML Lineage Tracking graph under a single logical grouping, such as all the entities belonging to one `aws_sage_maker_endpoint` deployment.

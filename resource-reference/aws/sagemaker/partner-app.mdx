`aws_sage_maker_partner_app` deploys a real, third-party ML or generative-AI application, such as Comet's experiment tracking, Deepchecks' LLM evaluation, or Fiddler's model observability, directly inside a SageMaker environment under Partner AI Apps, with the partner's own software running against an account's data without that data ever leaving its security boundary.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sagemaker "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sagemaker"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own partner app"})

    		ubx.Resource(sagemaker.PartnerApp, "example", sagemaker.PartnerAppConfig{
    			AuthType:          "example",
    			ExecutionRoleArn:  "arn:aws:iam::123456789012:policy/example",
    			Name:              "example",
    			Tier:              "example",
    			Type:              "example",
    			AppVersion:        "example",
    			ApplicationConfig: map[string]any{"admin_users": []string{"example"}},
    			ClientToken:       "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="app_version" type="string">
  The version of the PartnerApp. Optional.
</ResponseField>

<ResponseField name="application_config" type="object">
  A collection of configuration settings for the PartnerApp. Optional.
  <Expandable title="properties">
    <ResponseField name="admin_users" type="list(string)">
      A list of users with administrator privileges for the PartnerApp. Optional.
    </ResponseField>
    <ResponseField name="arguments" type="any">
      A list of arguments to pass to the PartnerApp. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="auth_type" type="string" required>
  The Auth type of PartnerApp. Required.
</ResponseField>

<ResponseField name="client_token" type="string">
  The client token for the PartnerApp. Optional.
</ResponseField>

<ResponseField name="enable_auto_minor_version_upgrade" type="bool">
  Enables automatic minor version upgrades for the PartnerApp. Optional.
</ResponseField>

<ResponseField name="enable_iam_session_based_identity" type="bool">
  Enables IAM Session based Identity for PartnerApp. Optional.
</ResponseField>

<ResponseField name="execution_role_arn" type="string" required>
  The execution role for the user. Required.
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The AWS KMS customer managed key used to encrypt the data associated with the PartnerApp. Optional.
</ResponseField>

<ResponseField name="maintenance_config" type="object">
  A collection of settings that specify the maintenance schedule for the PartnerApp. Optional.
  <Expandable title="properties">
    <ResponseField name="maintenance_window_start" type="string" required>
      The maintenance window start day and time for the PartnerApp. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the PartnerApp. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to apply to the PartnerApp. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tier" type="string" required>
  The tier of the PartnerApp. Required.
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of PartnerApp. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the created PartnerApp. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="base_url" type="string">
  The AppServerUrl based on app and account-info. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="current_version_eol_date" type="string">
  The end-of-life date for the current version of the PartnerApp. Computed by AWS after `ship`.
</ResponseField>

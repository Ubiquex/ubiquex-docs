`aws_sage_maker_experiment` creates a real top-level container that groups related `aws_sage_maker_trial_component`s, so multiple training runs exploring the same problem can be organized, compared, and tracked together.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sagemaker "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sagemaker"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own maker experiment"})

    		ubx.Resource(sagemaker.Experiment, "example", sagemaker.ExperimentConfig{
    			ExperimentName: "example-experiment-name",
    			Description:    "Managed by ubx.",
    			DisplayName:    "example-display-name",
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="description" type="string">
  The description of the experiment. Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  The name of the experiment as displayed. The name does not need to be unique. Optional.
</ResponseField>

<ResponseField name="experiment_name" type="string" required>
  The name of the experiment. Must be unique in your AWS account and is not case-sensitive. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to associate with the experiment. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag applied to the SageMaker experiment, used to assign custom metadata for organizing, searching, and managing the experiment resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value part of a user-defined key-value tag attached to an Amazon SageMaker experiment, used for labeling, categorization, and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

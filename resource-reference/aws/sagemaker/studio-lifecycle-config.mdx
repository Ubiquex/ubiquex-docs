`aws_sage_maker_studio_lifecycle_config` defines real shell scripts that run automatically when an `aws_sage_maker_app` inside an `aws_sage_maker_domain` starts or a JupyterServer app is created, for installing packages or applying custom setup across every user without baking a custom image.

## Input properties

<ResponseField name="studio_lifecycle_config_app_type" type="string" required>
  The App type that the Lifecycle Configuration is attached to. Required.
</ResponseField>

<ResponseField name="studio_lifecycle_config_content" type="string" required>
  The content of your Amazon SageMaker Studio Lifecycle Configuration script. This content must be base64 encoded. Required.
</ResponseField>

<ResponseField name="studio_lifecycle_config_name" type="string" required>
  The name of the Amazon SageMaker Studio Lifecycle Configuration. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to be associated with the Lifecycle Configuration. Each tag consists of a key and an optional value. Tag keys must be unique per resource. Tags are searchable using the Search API. Optional.

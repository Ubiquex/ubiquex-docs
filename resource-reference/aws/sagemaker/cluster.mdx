`aws_sage_maker_cluster` creates a real SageMaker HyperPod cluster, a persistent, purpose-built pool of accelerated compute instances with built-in resiliency (automatic faulty-node detection and job resumption) for large-scale distributed model training, distinct from the on-demand compute behind a `aws_sage_maker_processing_job` or `aws_sage_maker_pipeline` step.

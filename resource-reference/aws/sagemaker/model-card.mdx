`aws_sage_maker_model_card` documents a real `aws_sage_maker_model`'s intended use, training data, evaluation results, risk considerations, and ethical considerations in a single, structured, shareable record.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			SecurityConfig:  map[string]any{"kms_key_id": "example"},

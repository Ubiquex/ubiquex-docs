`aws_sage_maker_endpoint` deploys a real, hosted inference endpoint from an `aws_sage_maker_endpoint_config`, the resource that actually serves live predictions from a deployed `aws_sage_maker_model`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sagemaker "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sagemaker"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own maker endpoint"})

    		ubx.Resource(sagemaker.Endpoint, "example", sagemaker.EndpointConfig_{
    			EndpointConfigName:               "example-endpoint-config-name",
    			DeploymentConfig:                 map[string]any{"auto_rollback_configuration": map[string]any{"alarms": []map[string]any{{"alarm_name": "example-alarm-name"}}}},
    			ExcludeRetainedVariantProperties: []map[string]any{{"variant_property_type": "example"}},
    			RetainAllVariantProperties:       true,
    			RetainDeploymentConfig:           true,
    			Tags:                             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="deployment_config" type="object">
  Configures how the SageMaker endpoint is deployed or updated, including rolling update policies such as blue/green or canary deployments. Optional. **(AI-inferred)**
  <Expandable title="properties">

      <Expandable title="properties">
        <ResponseField name="alarms" type="list(object)" required>
          List of CloudWatch alarms to monitor during the deployment. If any alarm goes off, the deployment is rolled back. Required.
          <Expandable title="properties">
            <ResponseField name="alarm_name" type="string">
              The name of the CloudWatch alarm that SageMaker monitors during a deployment to trigger an automatic rollback of the endpoint to the previous configuration if the alarm enters an alarm state. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="blue_green_update_policy" type="object">

          The maximum time allowed for the blue/green update, in seconds. Optional.

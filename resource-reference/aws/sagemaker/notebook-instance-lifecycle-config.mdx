`aws_sage_maker_notebook_instance_lifecycle_config` defines real shell scripts that run automatically when an `aws_sage_maker_notebook_instance` is created or started, for installing packages or applying custom setup without baking a custom image.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own maker notebook instance lifecycle config"})

    		ubx.Resource(sagemaker.NotebookInstanceLifecycleConfig, "example", sagemaker.NotebookInstanceLifecycleConfigConfig{
    			NotebookInstanceLifecycleConfigName: "example-notebook-instance-lifecycle-config-name",
    			OnCreate:                            []map[string]any{{"content": "example"}},
    			OnStart:                             []map[string]any{{"content": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="notebook_instance_lifecycle_config_name" type="string">
  The name of the lifecycle configuration, which uniquely identifies it within your AWS account and is used when associating the lifecycle configuration with a notebook instance. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="on_create" type="list(object)">
  Specifies the lifecycle hooks that run when the notebook instance is created, containing base64-encoded shell script content that executes during instance creation. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The base64-encoded shell script that SageMaker executes on the notebook instance during the creation ('onCreate') lifecycle event, allowing custom setup before the instance becomes available. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="on_start" type="list(object)">
  Specifies a list of lifecycle configuration scripts (each a base64-encoded shell script) that Amazon SageMaker runs when the notebook instance starts. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The shell script content that AWS SageMaker runs when the notebook instance starts, as defined in the OnStart lifecycle hook of the lifecycle configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The computed name (identifier) of the SageMaker notebook instance lifecycle configuration, used as the CloudFormation physical resource ID. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_sage_maker_device` registers a real edge device, its name and description, as a member of an `aws_sage_maker_device_fleet`, so SageMaker Edge Manager can track the models deployed to it.

## Example

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(sagemaker.Device, "example", sagemaker.DeviceConfig{

    	}))

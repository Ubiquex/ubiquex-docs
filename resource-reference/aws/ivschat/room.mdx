`aws_ivschat_room` creates a real, managed chat room, typically paired alongside an `aws_ivs_channel`'s live stream, that Amazon IVS Chat handles message fan-out, moderation, and connection scaling for.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ivschat "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/ivschat"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own room"})

    		ubx.Resource(ivschat.Room, "example", ivschat.RoomConfig{
    			Name:                            "example",
    			LoggingConfigurationIdentifiers: []string{"example"},
    			MaximumMessageLength:            1,
    			MaximumMessageRatePerSecond:     1,
    			MessageReviewHandler:            map[string]any{"fallback_result": "example"},
    			Tags:                            []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="logging_configuration_identifiers" type="list(string)">
  Array of logging configuration identifiers attached to the room. Optional.
</ResponseField>

<ResponseField name="maximum_message_length" type="number">
  The maximum number of characters in a single message. Optional.
</ResponseField>

<ResponseField name="maximum_message_rate_per_second" type="number">
  The maximum number of messages per second that can be sent to the room. Optional.
</ResponseField>

<ResponseField name="message_review_handler" type="object">
  Configuration information for optional review of messages. Optional.
  <Expandable title="properties">
    <ResponseField name="fallback_result" type="string">
      Specifies the fallback behavior if the handler does not return a valid response, encounters an error, or times out. Optional.
    </ResponseField>
    <ResponseField name="uri" type="string">
      Identifier of the message review handler. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the room. The value does not need to be unique. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the IVS Chat Room, used to organize and identify the resource (e.g., 'Environment' or 'Owner'). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Room ARN is automatically generated on creation and assigned as the unique identifier. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The system-generated ID of the room. Computed by AWS after `ship`.
</ResponseField>

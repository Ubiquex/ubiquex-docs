`aws_ivschat_logging_configuration` streams a real `aws_ivschat_room`'s chat messages to a destination, CloudWatch Logs, Kinesis Data Firehose, or S3, for moderation review or analytics rather than messages existing only transiently in the room.

## Example

<Tabs>

    ```go
    package main

    import (
    	ivschat "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/ivschat"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own logging configuration"})

    		ubx.Resource(ivschat.LoggingConfiguration, "example", ivschat.LoggingConfigurationConfig{
    			DestinationConfiguration: map[string]any{"cloud_watch_logs": map[string]any{"log_group_name": "example-log-group-name"}},
    			Name:                     "example",
    			Tags:                     []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="destination_configuration" type="object" required>
  Destination configuration for IVS Chat logging. Required.
  <Expandable title="properties">
    <ResponseField name="cloud_watch_logs" type="object">
      CloudWatch destination configuration for IVS Chat logging. Optional.
      <Expandable title="properties">
        <ResponseField name="log_group_name" type="string" required>
          Name of the Amazon CloudWatch Logs log group where chat activity will be logged. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="firehose" type="object">
      Kinesis Firehose destination configuration for IVS Chat logging. Optional.
      <Expandable title="properties">
        <ResponseField name="delivery_stream_name" type="string" required>
          Name of the Amazon Kinesis Firehose delivery stream where chat activity will be logged. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="s3" type="object">
      S3 destination configuration for IVS Chat logging. Optional.
      <Expandable title="properties">
        <ResponseField name="bucket_name" type="string" required>
          Name of the Amazon S3 bucket where chat activity will be logged. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the logging configuration. The value does not need to be unique. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  LoggingConfiguration ARN is automatically generated on creation and assigned as the unique identifier. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The system-generated ID of the logging configuration. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the logging configuration. When the state is ACTIVE, the configuration is ready to log chat content. Computed by AWS after `ship`.
</ResponseField>

`aws_greengrass_resource_definition` gives an `aws_greengrass_group`'s Lambda functions real, controlled access to local resources, a machine learning model, a device volume, a secret, that live on the core device itself rather than in the cloud. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/greengrass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource definition"})

    		ubx.Resource(greengrass.ResourceDefinition, "example", greengrass.ResourceDefinitionConfig{
    			Name:           "example",
    			InitialVersion: map[string]any{"resources": []map[string]any{{"name": "example-name"}}},
    			Tags:           "example",
    		})
    	}))
    }
    ```

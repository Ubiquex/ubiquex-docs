`aws_greengrass_subscription_definition_version` is a real, specific version of an `aws_greengrass_subscription_definition`, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

## Input properties

<ResponseField name="subscription_definition_id" type="string" required>
  The ID of the Greengrass subscription definition that this subscription definition version belongs to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="subscriptions" type="list(object)" required>
  The subscriptions field defines the list of MQTT message routing rules for this subscription definition version, each specifying a source, target, and topic filter that controls how messages are passed between Greengrass devices, functions, and connectors. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The subscriptions.id is a required, user-defined unique identifier for each subscription within the AWS Greengrass subscription definition version, used to distinguish and reference individual subscription entries. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source" type="string">
      Specifies the ARN of the source device or Lambda function that publishes messages to the target on the given topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="subject" type="string">
      The MQTT topic filter that determines which messages are routed from the source to the target in this subscription. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="target" type="string">
      Specifies the target of the subscription as an ARN (for example, a Greengrass device, Lambda function, or connector ARN) that receives messages published to the subscription's subject from the source. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

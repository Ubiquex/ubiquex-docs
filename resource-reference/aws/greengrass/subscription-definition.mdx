`aws_greengrass_subscription_definition` defines real, local MQTT-style publish/subscribe routes between an `aws_greengrass_group`'s core, its devices, its Lambda functions, and the cloud, the actual message-routing rules the group runs on. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

## Input properties

<ResponseField name="initial_version" type="object">
  The initial subscription definition version, which contains a list of subscription objects (each specifying a source, target, and subject) that define how MQTT messages are routed between devices, functions, and connectors in the Greengrass group. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="subscriptions" type="list(object)" required>
      Defines the list of subscriptions to include in the initial version of the Greengrass subscription definition, where each subscription specifies a source, target, and topic. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          A user-defined alphanumeric identifier for the subscription, used to uniquely reference it within the Greengrass subscription definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="source" type="string">
          The ARN of the device, Lambda function, or connector that publishes messages to the MQTT topic in this Greengrass subscription. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="subject" type="string">
          Specifies the MQTT topic filter (subject) for a Greengrass subscription, which defines the topic, normally with wildcards, that messages are routed on from the source to the target. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="target" type="string">
          The ARN of the target destination (a Greengrass core, device, or Lambda function) that receives messages published to the subscription's subject topic. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

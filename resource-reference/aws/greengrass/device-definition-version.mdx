`aws_greengrass_device_definition_version` is a real, specific version of an `aws_greengrass_device_definition`, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/greengrass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own device definition version"})

    		ubx.Resource(greengrass.DeviceDefinitionVersion, "example", greengrass.DeviceDefinitionVersionConfig{
    			DeviceDefinitionId: "example",
    			Devices:            []map[string]any{{"certificate_arn": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="device_definition_id" type="string" required>
  The ID of the Greengrass device definition to which this version belongs, required to scope the version resource within a specific device definition. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="devices" type="list(object)" required>
  Defines the list of AWS IoT devices (things) included in this Greengrass device definition version, each specifying the device's ID, thing ARN, certificate ARN, and whether local shadow synchronization is enabled. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="certificate_arn" type="string">
      The ARN of the AWS IoT certificate used to authenticate the Greengrass device when it connects to the AWS Greengrass core. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="id" type="string">
      The device ID, which must be unique within the device definition version and is used to identify the device in this version. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="sync_shadow" type="bool">
      Indicates whether the device's shadow is synchronized with the AWS IoT shadow. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="thing_arn" type="string">
      The Amazon Resource Name (ARN) of the AWS IoT thing that this device represents in the Greengrass device definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS to this Greengrass device definition version, used as a computed resource identifier. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_greengrass_function_definition_version` is a real, specific version of an `aws_greengrass_function_definition`, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own function definition version"})

    		})
    	}))

`aws_greengrass_connector_definition` deploys a real, pre-built AWS integration, connecting to a local ML model or a serial port, for instance, to an `aws_greengrass_group`'s core device without a caller writing that integration logic themselves. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/greengrass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connector definition"})

    		ubx.Resource(greengrass.ConnectorDefinition, "example", greengrass.ConnectorDefinitionConfig{
    			Name:           "example",
    			InitialVersion: map[string]any{"connectors": []map[string]any{{"connector_arn": "example"}}},
    			Tags:           "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="initial_version" type="object">
  Specifies the initial connector definition version that contains the list of connectors and their parameter configurations to be deployed with this Greengrass connector definition. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="connectors" type="list(object)" required>
      Specifies the connectors that compose the initial version of the AWS Greengrass connector definition, each providing a connector ARN, a unique ID, and optional parameters for the connector. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="connector_arn" type="string">
          The ARN of the AWS Greengrass connector to include in the connector definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**

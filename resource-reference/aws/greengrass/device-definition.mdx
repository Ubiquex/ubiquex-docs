`aws_greengrass_device_definition` registers real, local IoT devices, connected to an `aws_greengrass_group`'s core rather than directly to AWS IoT Core, that can communicate with the core and each other even when internet connectivity is lost. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/greengrass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own device definition"})

    		ubx.Resource(greengrass.DeviceDefinition, "example", greengrass.DeviceDefinitionConfig{
    			Name:           "example",
    			InitialVersion: map[string]any{"devices": []map[string]any{{"certificate_arn": "example"}}},
    			Tags:           "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="initial_version" type="object">
  Specifies the initial version of the device definition, containing a list of devices (each with an ID, certificate ARN, and optional sync shadow setting) that is created when the device definition is first created. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="devices" type="list(object)" required>
      A list of devices (each with a device ID, Thing ARN, Certificate ARN, and optional SyncShadow flag) that comprise the initial version of the AWS Greengrass device definition. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="certificate_arn" type="string">
          The ARN of the AWS IoT certificate that identifies and authenticates the Greengrass device within the device definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="id" type="string">
          The user-defined identifier that uniquely identifies each device within the Greengrass device definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="sync_shadow" type="bool">
          Indicates whether the device's shadow is synchronized with AWS IoT for this device in the Greengrass device definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="thing_arn" type="string">
          The Amazon Resource Name (ARN) of the AWS IoT thing representing the Greengrass device to include in the initial version of this device definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  Specifies a user-friendly name for the AWS IoT Greengrass device definition, required to identify the definition in the console and API. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Tags are user-defined key-value pairs that can be attached to the AWS IoT Greengrass device definition resource for organizing, identifying, and managing it within AWS. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this AWS Greengrass device definition, used to reference it in IAM policies and other AWS services. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The service-assigned unique identifier for this AWS IoT Greengrass device definition, used to reference the definition in other resources. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="latest_version_arn" type="string">
  The Amazon Resource Name (ARN) of the latest version of this AWS IoT Greengrass device definition. Computed by AWS after `ship`. **(AI-inferred)**

`aws_greengrass_logger_definition` configures real, local logging, destination and log level, for an `aws_greengrass_group`'s core device and its Lambda functions. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/greengrass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own logger definition"})

    		ubx.Resource(greengrass.LoggerDefinition, "example", greengrass.LoggerDefinitionConfig{
    			Name:           "example",
    			InitialVersion: map[string]any{"loggers": []map[string]any{{"component": "example"}}},
    			Tags:           "example",
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    import ubx_sdk as ubx
    from ubx.aws.greengrass import LoggerDefinition, LoggerDefinitionConfig
    from ubx.aws.greengrass.logger_definition import LoggerDefinition_InitialVersion, LoggerDefinition_InitialVersion_Loggers

    def describe():
        ubx.intent("example own logger definition")

        ubx.resource(LoggerDefinition, "example", LoggerDefinitionConfig(
            name="example",
            initial_version=LoggerDefinition_InitialVersion(loggers=[LoggerDefinition_InitialVersion_Loggers(component="example")]),
            tags="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="initial_version" type="object">
  Specifies the initial version of the logger definition, which consists of a set of loggers that define how Greengrass components write logs to CloudWatch or the local file system. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="loggers" type="list(object)" required>
      Specifies the list of logger configuration objects for the initial version of the AWS Greengrass logger definition, each defining the component to log (e.g., GreengrassSystem or Lambda), the log output type (e.g., FileSystem or AWSCloudWatch), log level, and (for file-based logging) the disk space limit. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="component" type="string">
          Specifies the component type the logger applies to (e.g., GreengrassSystem or Lambda) in an AWS Greengrass logger definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="id" type="string">
          A unique identifier for this logger within the Greengrass logger definition version, used to reference the logger when configuring logging for a Greengrass group. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="level" type="string">
          Specifies the log severity threshold for the logger, with allowed values such as DEBUG, INFO, WARN, ERROR, and FATAL, determining which messages are recorded. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="space" type="number">
          Specifies the maximum amount of log data (in kilobytes) that the logger can store for the associated Greengrass component. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies whether this logger applies to Greengrass system components or user-defined Lambda/component loggers, with allowed values 'GreengrassSystem' and 'Component'. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_greengrass_group` is the real, top-level container in AWS IoT Greengrass V1 that a core device, its Lambda functions, subscriptions, and other local resources all belong to, deployed together as one unit. AWS IoT Greengrass V1 entered its extended-life, maintenance-only phase on June 30, 2023 (no further feature, enhancement, or security updates) and reaches full end of support on October 7, 2026; devices already running V1 continue operating and connecting to the cloud in the meantime, and AWS recommends migrating to AWS IoT Greengrass V2 for new work.

## Input properties

<ResponseField name="initial_version" type="object">
  Specifies the initial version of the Greengrass group, which includes references to the core, devices, functions, loggers, subscriptions, and resource definitions that define the group's initial configuration. Optional. **(AI-inferred)**

    </ResponseField>
    <ResponseField name="core_definition_version_arn" type="string">
      The Amazon Resource Name (ARN) of the core definition version to associate with the initial Greengrass group version. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="device_definition_version_arn" type="string">
      The Amazon Resource Name (ARN) of the device definition version to include in the initial group version when the group is created. Optional. **(AI-inferred)**

      The ARN of the function definition version that defines the Lambda functions for the Greengrass group, included in the initial group version configuration. Optional. **(AI-inferred)**
    </ResponseField>

    </ResponseField>
    <ResponseField name="resource_definition_version_arn" type="string">
      This field specifies the Amazon Resource Name (ARN) of the resource definition version that defines the local resources available to the Greengrass group's initial group version, which is used when the group is first created. Optional. **(AI-inferred)**

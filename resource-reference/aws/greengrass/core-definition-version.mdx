`aws_greengrass_core_definition_version` is a real, specific version of an `aws_greengrass_core_definition`, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

    ```go
    package main

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/greengrass"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own core definition version"})

    		ubx.Resource(greengrass.CoreDefinitionVersion, "example", greengrass.CoreDefinitionVersionConfig{
    			CoreDefinitionId: "example",
    			Cores:            []map[string]any{{"certificate_arn": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="core_definition_id" type="string" required>
  The unique ID of the AWS Greengrass core definition that this core definition version is associated with. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="cores" type="list(object)" required>
  The cores list specifies the Greengrass core devices for this core definition version, where each object includes the core device's Thing ARN, its associated certificate ARN, and an optional flag to enable shadow synchronization. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="certificate_arn" type="string">
      The Amazon Resource Name (ARN) of the AWS IoT certificate that identifies the Greengrass core device when it connects to AWS IoT. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="id" type="string">
      The logical ID assigned to this core within the Greengrass core definition version, used to uniquely identify the core among the list of cores. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="sync_shadow" type="bool">
      Indicates whether the Greengrass core device's shadow is synchronized with the cloud. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="thing_arn" type="string">
      The ARN of the AWS IoT Thing that acts as the Greengrass core device in this core definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique AWS-assigned version ID (typically a UUID) for the Greengrass core definition version, returned after creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_greengrass_core_definition` registers the real primary device, running the actual AWS IoT Greengrass V1 core software, that hosts an `aws_greengrass_group`'s local compute and connects it to AWS IoT Core. Part of Greengrass V1's maintenance-only lifecycle since June 2023, ahead of its October 2026 end of support.

## Input properties

<ResponseField name="initial_version" type="object">
  Defines the initial version of the core definition by specifying a list of Greengrass core devices, each identified by its AWS IoT thing ARN and associated certificate ARN, that are used when the definition is first created. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cores" type="list(object)" required>
      Specifies the list of core devices (each with a thing ARN and certificate ARN) that make up the initial version of this AWS Greengrass core definition. Required. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="certificate_arn" type="string">
          The ARN of the AWS IoT certificate that authenticates the core device in the Greengrass group. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="id" type="string">
          The user-defined identifier for this core within the Greengrass core definition version, used to reference the core in the group configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="sync_shadow" type="bool">
          Indicates whether the Greengrass core device's shadow sync is enabled with the AWS IoT cloud, allowing the local shadow to be synchronized with the cloud-shadow service. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="thing_arn" type="string">
          The ARN of the AWS IoT thing that this Greengrass core represents. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_greengrass_function_definition` lists the real Lambda functions an `aws_greengrass_group`'s core device runs locally, at the edge, rather than in the AWS Cloud. Part of Greengrass V1's maintenance-only lifecycle since June 2023.

## Example

    ```go
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own function definition"})

    		ubx.Resource(greengrass.FunctionDefinition, "example", greengrass.FunctionDefinitionConfig{
    			Name:           "example",
    			InitialVersion: map[string]any{"functions": []map[string]any{{"function_arn": "example"}}},
    			Tags:           "example",
    		})
    	}))
    }
    ```

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the function definition. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique ID that AWS IoT Greengrass assigns to this function definition, returned as a read-only attribute after the resource is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="latest_version_arn" type="string">
  The Amazon Resource Name (ARN) of the latest version of the Greengrass function definition, automatically assigned by AWS and updated whenever a new version is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

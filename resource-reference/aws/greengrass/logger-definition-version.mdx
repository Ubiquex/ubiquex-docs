`aws_greengrass_logger_definition_version` is a real, specific version of an `aws_greengrass_logger_definition`, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

    import (
    	greengrass "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/greengrass"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    }

## Input properties

<ResponseField name="logger_definition_id" type="string" required>
  The ID of the Greengrass logger definition that this version belongs to, required when creating a logger definition version. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="loggers" type="list(object)" required>
  Specifies a list of logger configuration objects, each for an AWS Greengrass component, that determine where logs are sent (CloudWatch Logs or local file system) and the minimum log level to record. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="component" type="string">
      Specifies the component that writes the logs captured by this logger, typically the literal value `GreengrassSystem` for system components or the ARN of a Lambda function for lambda components. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique identifier used to reference this logger component within the logger definition version. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="level" type="string">
      The log level for this Greengrass logger, determining the minimum severity (e.g., DEBUG, INFO, WARN, ERROR, FATAL) of log messages that will be recorded. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="space" type="number">
      The maximum amount of file space (in kilobytes) that the logger can use for storing log files, applicable to file-system based loggers in a Greengrass logger definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      The logger destination type: AWSCloudWatch for logs published to Amazon CloudWatch Logs, or FileSystem for logs written to the local file system. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The id is the unique ARN assigned by AWS to this Greengrass logger definition version, used to reference the version in other resources and API calls. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_greengrass_group_version` is a real, specific, versioned snapshot of an `aws_greengrass_group`'s own configuration, the actual deployable unit pushed to a core device, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

## Input properties

<ResponseField name="connector_definition_version_arn" type="string">
  The ARN of the connector definition version to associate with this Greengrass group version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="core_definition_version_arn" type="string">
  The ARN of the core definition version to associate with this Greengrass group version, which defines the core device for the group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="device_definition_version_arn" type="string">
  The ARN of the device definition version to include in this Greengrass group version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="function_definition_version_arn" type="string">
  The Amazon Resource Name (ARN) of the function definition version that this group version references, which determines the Lambda functions included in the group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="group_id" type="string" required>
  The unique identifier of the AWS Greengrass group that this group version belongs to and whose configuration this version specifies. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="logger_definition_version_arn" type="string">
  The ARN of the logger definition version to associate with this Greengrass group version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_definition_version_arn" type="string">
  The Amazon Resource Name (ARN) of the resource definition version to associate with this Greengrass group version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="subscription_definition_version_arn" type="string">
  The Amazon Resource Name (ARN) of the subscription definition version that this Greengrass group version references for its MQTT subscription routing configuration. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique identifier of the Greengrass group version, assigned by AWS upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

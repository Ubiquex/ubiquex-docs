`aws_greengrass_v2_component_version` is a real, versioned software module, AWS-provided or a caller's own, deployed to AWS IoT Greengrass V2 core devices through an `aws_greengrass_v2_deployment`, V2's software-component model that replaced V1's separate function, connector, and resource definitions with one unified concept.

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the AWS IoT Greengrass V2 component version, used to reference it in other AWS operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="component_name" type="string">
  The name of the Greengrass component (e.g., 'com.example.HelloWorld') as specified in the component recipe, returned as a read-only attribute of the created component version. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="component_version" type="string">
  The version string (e.g., 1.0.0) that AWS IoT Greengrass assigns to the created component version. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

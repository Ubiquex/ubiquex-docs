`aws_greengrass_connector_definition_version` is a real, specific version of an `aws_greengrass_connector_definition`, part of AWS IoT Greengrass V1's maintenance-only lifecycle since June 2023.

## Input properties

<ResponseField name="connector_definition_id" type="string" required>
  Specifies the ID of the Greengrass connector definition to which this version belongs, linking the version to its parent ConnectorDefinition resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="connectors" type="list(object)" required>
  Defines the list of connectors that make up this Greengrass connector definition version, where each connector specifies its connector ARN and configuration parameters. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="connector_arn" type="string">
      The ARN of the AWS IoT Greengrass connector that this connector definition version includes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="id" type="string">
      The user-defined unique identifier for each connector within the Greengrass connector definition version, used to reference the connector in the group configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="parameters" type="any">
      Specifies the configuration parameters for the Greengrass connector, passed as key-value pairs to the connector's Lambda function. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique version UUID that AWS IoT Greengrass assigns to this connector definition version, returned by the CreateConnectorDefinitionVersion API. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_lookout_equipment_inference_scheduler` schedules real, recurring inference runs against a trained Amazon Lookout for Equipment model, feeding it fresh sensor data on a cadence and surfacing predicted anomalies. Lookout for Equipment closed to new customers on October 7, 2025, and AWS has stated it will be fully discontinued on October 7, 2026, a date roughly six weeks from now; existing customers can keep using it as normal until then, with AWS continuing security, availability, and performance investment but no new features.

## Input properties

<ResponseField name="data_delay_offset_in_minutes" type="number">
  A period of time (in minutes) by which inference on the data is delayed after the data starts. Optional.
</ResponseField>

<ResponseField name="data_input_configuration" type="object" required>
  Specifies configuration information for the input data for the inference scheduler, including delimiter, format, and dataset location. Required.
  <Expandable title="properties">
    <ResponseField name="inference_input_name_configuration" type="object">
      Specifies configuration information for the input data for the inference, including timestamp format and delimiter. Optional.
      <Expandable title="properties">
        <ResponseField name="component_timestamp_delimiter" type="string">
          Indicates the delimiter character used between items in the data. Optional.
        </ResponseField>
        <ResponseField name="timestamp_format" type="string">
          The format of the timestamp, whether Epoch time, or standard, with or without hyphens (-). Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="input_time_zone_offset" type="string">
      Indicates the difference between your time zone and Greenwich Mean Time (GMT). Optional.
    </ResponseField>
    <ResponseField name="s3_input_configuration" type="object" required>
      Specifies configuration information for the input data for the inference, including input data S3 location. Required.
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The name of the S3 bucket that contains the sensor or equipment data used as input for the inference scheduler. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="prefix" type="string">
          The S3 key prefix under the input bucket that identifies the sensor data files used by the inference scheduler for running model inferences. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="data_output_configuration" type="object" required>
  Specifies configuration information for the output results for the inference scheduler, including the S3 location for the output. Required.
  <Expandable title="properties">
    <ResponseField name="kms_key_id" type="string">
      The ID number for the AWS KMS key used to encrypt the inference output. Optional.
    </ResponseField>
    <ResponseField name="s3_output_configuration" type="object" required>
      Specifies configuration information for the output results from the inference, including output S3 location. Required.
      <Expandable title="properties">
        <ResponseField name="bucket" type="string" required>
          The name of the S3 bucket where the inference scheduler outputs its inference results and monitoring data. Required. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="prefix" type="string">
          The S3 key prefix (folder path) under the specified S3 bucket where the inference scheduler stores its inference output files (results). Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="data_upload_frequency" type="string" required>
  How often data is uploaded to the source S3 bucket for the input data. Required.
</ResponseField>

<ResponseField name="inference_scheduler_name" type="string">
  The name of the inference scheduler being created. Optional.
</ResponseField>

<ResponseField name="model_name" type="string" required>
  The name of the previously trained ML model being used to create the inference scheduler. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) of a role with permission to access the data source being used for the inference. Required.
</ResponseField>

<ResponseField name="server_side_kms_key_id" type="string">
  Provides the identifier of the AWS KMS customer master key (CMK) used to encrypt inference scheduler data by Amazon Lookout for Equipment. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Any tags associated with the inference scheduler. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag attached to the inference scheduler. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag key-value pair that can be attached to the Lookout for Equipment inference scheduler, used for custom metadata, resource grouping, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="inference_scheduler_arn" type="string">
  The Amazon Resource Name (ARN) of the inference scheduler being created. Computed by AWS after `ship`.
</ResponseField>

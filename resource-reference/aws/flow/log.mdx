`aws_flow_log` captures real IP traffic metadata, source, destination, port, protocol, accept or reject, flowing through a VPC, subnet, or individual network interface, delivered to S3 or CloudWatch Logs, real, ongoing network visibility for troubleshooting and security analysis without capturing packet contents themselves.

## Input properties

<ResponseField name="deliver_cross_account_role" type="string">
  The ARN of the IAM role that allows Amazon EC2 to publish flow logs across accounts. Optional.
</ResponseField>

<ResponseField name="deliver_logs_permission_arn" type="string">
  The ARN for the IAM role that permits Amazon EC2 to publish flow logs to a CloudWatch Logs log group in your account. If you specify LogDestinationType as s3 or kinesis-data-firehose, do not specify DeliverLogsPermissionArn or LogGroupName. Optional.
</ResponseField>

<ResponseField name="destination_options" type="object">
  Specifies the destination options for the flow log, such as the file format (plain-text or parquet), whether to enable Hive-compatible partitions, and whether to partition logs by hour, when delivering to an Amazon S3 bucket. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="file_format" type="string" required>
      Specifies the file format (plain-text or parquet) used to store VPC flow log records in the destination S3 bucket. Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="hive_compatible_partitions" type="bool" required>
      Whether to enable Hive-compatible partitioning (e.g., year=2023/month=01/day=01/hour=00) for the S3 destination of the flow log, instead of the default partition format (e.g., 2023/01/01/00). Required. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="per_hour_partition" type="bool" required>
      Indicates whether to partition flow log records in the S3 destination into separate hourly folders, creating a new partition for each hour. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="log_destination" type="string">
  Specifies the destination to which the flow log data is to be published. Flow log data can be published to a CloudWatch Logs log group, an Amazon S3 bucket, or a Kinesis Firehose stream. The value specified for this parameter depends on the value specified for LogDestinationType. Optional.
</ResponseField>

<ResponseField name="log_destination_type" type="string">
  Specifies the type of destination to which the flow log data is to be published. Flow log data can be published to CloudWatch Logs or Amazon S3. Optional.
</ResponseField>

<ResponseField name="log_format" type="string">
  The fields to include in the flow log record, in the order in which they should appear. Optional.
</ResponseField>

<ResponseField name="log_group_name" type="string">
  The name of a new or existing CloudWatch Logs log group where Amazon EC2 publishes your flow logs. If you specify LogDestinationType as s3 or kinesis-data-firehose, do not specify DeliverLogsPermissionArn or LogGroupName. Optional.
</ResponseField>

<ResponseField name="max_aggregation_interval" type="number">
  The maximum interval of time during which a flow of packets is captured and aggregated into a flow log record. You can specify 60 seconds (1 minute) or 600 seconds (10 minutes). Optional.
</ResponseField>

<ResponseField name="resource_id" type="string" required>
  The ID of the subnet, network interface, or VPC for which you want to create a flow log. Required.
</ResponseField>

<ResponseField name="resource_type" type="string" required>
  The type of resource for which to create the flow log. For example, if you specified a VPC ID for the ResourceId property, specify VPC for this property. Required.
</ResponseField>

<ResponseField name="tag_field_specifications" type="list(object)">
  The resource types and associated tags for EC2 resources associated with the EC2 Tags feature for log enrichment. Optional.
  <Expandable title="properties">
    <ResponseField name="resource_type" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="tag_keys" type="list(string)">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to apply to the flow logs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the VPC flow log, used to organize and identify the log resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a key-value tag applied to the AWS Flow Log, used for resource identification and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="traffic_type" type="string">
  The type of traffic to log. You can log traffic that the resource accepts or rejects, or all traffic. Optional.
</ResponseField>

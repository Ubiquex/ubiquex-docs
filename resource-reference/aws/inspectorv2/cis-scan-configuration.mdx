`aws_inspector_v2_cis_scan_configuration` schedules real, recurring CIS benchmark compliance scans against EC2 instances, checking actual operating-system configuration against a defined CIS standard rather than the vulnerability scanning Inspector v2 otherwise focuses on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	inspectorv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/inspectorv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2 cis scan configuration"})

    		ubx.Resource(inspectorv2.CisScanConfiguration, "example", inspectorv2.CisScanConfigurationConfig{
    			ScanName:      "example-scan-name",
    			Schedule:      "example",
    			SecurityLevel: "example",
    			Targets:       "example",
    			Tags:          "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="scan_name" type="string" required>
  Name of the scan Required.
</ResponseField>

<ResponseField name="schedule" type="any" required>
  Choose a Schedule cadence Required.
</ResponseField>

<ResponseField name="security_level" type="string" required>
  The CIS benchmark security level (e.g., LEVEL_1 or LEVEL_2) that this scan configuration is applied against. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  The tags to assign to the CIS scan configuration resource, used for organizing and identifying it in AWS. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="targets" type="any" required>
  Specifies the AWS accounts and resource tags that the CIS scan targets, determining which resources are included in the scan. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  CIS Scan configuration unique identifier Computed by AWS after `ship`.

`aws_wisdom_assistant` creates a real Wisdom assistant, the top-level container that `aws_wisdom_knowledge_base`s, `aws_wisdom_aiagent`s, and `aws_wisdom_message_template`s are organized under, typically associated with an Amazon Connect instance to power agent assist or Amazon Q in Connect.

## Input properties

<ResponseField name="description" type="string">
  Specifies a human-readable description for the Wisdom Assistant, providing context about its purpose or use case. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the Amazon Wisdom assistant, which is a required, user-defined identifier for the assistant resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="server_side_encryption_configuration" type="object">
  Specifies the server-side encryption configuration, including the KMS key ARN used to encrypt the Wisdom assistant's data at rest. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="kms_key_id" type="string">
      The ARN of the KMS key used to encrypt the Wisdom assistant's data; if left unspecified, Amazon Connect Wisdom uses an AWS managed key. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of tags to associate with the Wisdom assistant, which can be used to manage access and identify the resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Wisdom assistant, used for identifying and categorizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag assigned to the Wisdom assistant, allowing you to attach custom metadata such as environment or project labels to the assistant resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  Sets the type of the Wisdom assistant, which must be either AGENT or ASSISTANT, controlling whether it serves contact center agents or end users. Required. **(AI-inferred)**
</ResponseField>

`aws_wisdom_message_template_version` publishes a real, immutable version of an `aws_wisdom_message_template`'s content, letting a reference to it pin to a specific, unchanging version rather than the template's editable draft.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	wisdom "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/wisdom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own message template version"})

    		ubx.Resource(wisdom.MessageTemplateVersion, "ci-runner", wisdom.MessageTemplateVersionConfig{
    			MessageTemplateArn:           "arn:aws:iam::123456789012:policy/ci",
    			MessageTemplateContentSha256: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="message_template_arn" type="string" required>
  The unqualified Amazon Resource Name (ARN) of the message template. Required.
</ResponseField>

<ResponseField name="message_template_content_sha256" type="string">
  The content SHA256 of the message template. Optional.
</ResponseField>

## Output properties

<ResponseField name="message_template_version_arn" type="string">
  The unqualified Amazon Resource Name (ARN) of the message template version. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="message_template_version_number" type="number">
  Current version number of the message template. Computed by AWS after `ship`.
</ResponseField>

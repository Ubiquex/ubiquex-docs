`aws_wisdom_aiguardrail` defines real content and behavior restrictions, denied topics, word filters, that an `aws_wisdom_aiagent` enforces on its generated responses, Amazon Q in Connect's own responsible-AI guardrail layer.

## Example

## Input properties

<ResponseField name="assistant_id" type="string" required>
  The identifier of the Amazon Wisdom assistant to which this AI guardrail is associated. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="blocked_input_messaging" type="string" required>
  Messaging for when violations are detected in text Required.
</ResponseField>

<ResponseField name="blocked_outputs_messaging" type="string" required>
  Messaging for when violations are detected in text Required.
</ResponseField>

<ResponseField name="content_policy_config" type="object">
  Content policy config for a guardrail. Optional.
  <Expandable title="properties">
    <ResponseField name="filters_config" type="list(object)" required>
      List of content filter configs in content policy. Required.
      <Expandable title="properties">
        <ResponseField name="input_strength" type="string">
          Sets the moderation intensity for filtering user-provided input for this content filter, using an allowed value of NONE, LOW, MEDIUM, or HIGH to control how strictly the guardrail blocks or modifies incoming messages. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="output_strength" type="string">
          Specifies the strength of the content filter applied to the model's output, with allowed values such as NONE, LOW, MEDIUM, or HIGH, determining how aggressively the guardrail blocks or modifies generated content. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          The category of harmful content that this filter targets, with allowed values such as PROFANITY, VIOLENCE, SEXUAL, HATE, INSULTS, and MISCONDUCT. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contextual_grounding_policy_config" type="object">
  Contextual grounding policy config for a guardrail. Optional.
  <Expandable title="properties">
    <ResponseField name="filters_config" type="list(object)" required>
      List of contextual grounding filter configs. Required.
      <Expandable title="properties">
        <ResponseField name="threshold" type="number">
          Sets the confidence threshold (0 to 1) at which the contextual grounding filter considers a response grounded in the source, with higher values increasing strictness and blocking more outputs that lack grounding. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          The type of the contextual grounding filter, which determines whether the filter validates that the response is grounded in the source information (GROUNDING) or is relevant to the user's query (RELEVANCE). Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Description of the guardrail or its version Optional.
</ResponseField>

<ResponseField name="name" type="string">
  Sets the friendly name for the AI guardrail, used to identify it in Amazon Q Business console and API operations. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="sensitive_information_policy_config" type="object">
  Sensitive information policy config for a guardrail. Optional.
  <Expandable title="properties">
    <ResponseField name="pii_entities_config" type="list(object)">
      List of entities. Optional.
      <Expandable title="properties">
        <ResponseField name="action" type="string">
          The action to take on a detected PII entity, either BLOCK to deny the interaction or ANONYMIZE to replace the entity with a placeholder. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          This field specifies the type of PII entity to detect and protect against, such as EMAIL or PHONE_NUMBER. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="regexes_config" type="list(object)">
      List of regex. Optional.
      <Expandable title="properties">
        <ResponseField name="action" type="string">
          Specifies the enforcement action applied to content matching the regex pattern, such as blocking the content or anonymizing the detected sensitive data. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="description" type="string">
          Provides a descriptive note for a regex configuration in the AI guardrail's sensitive information policy, explaining what kind of sensitive data the regex pattern is intended to detect. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of a regex configuration within the sensitive information policy, uniquely identifying the regular expression pattern used by the Wisdom AI guardrail. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="pattern" type="string">
          The regular expression pattern used to define a custom regex-based rule for detecting sensitive information in the AI guardrail's sensitive information policy. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

<ResponseField name="topic_policy_config" type="object">
  Topic policy config for a guardrail. Optional.
  <Expandable title="properties">
    <ResponseField name="topics_config" type="list(object)" required>
      List of topic configs in topic policy. Required.
      <Expandable title="properties">
        <ResponseField name="definition" type="string">
          The natural-language definition of the topic, used by the guardrail to match user input and decide whether to allow or deny it according to the topic's type. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="examples" type="list(string)">
          The examples field specifies a list of representative phrases for a topic, which the guardrail uses to identify and apply the configured topic policy when input matches those phrases. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          Name of the topic entry in the topic policy configuration, used to identify the specific topic that the AI guardrail will allow or deny in conversations. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="type" type="string">
          Specifies the type of the topic, with the only supported value being 'DENY', which causes the guardrail to block any conversation that matches the topic's definition. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

  Word policy config for a guardrail. Optional.

      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Specifies whether this managed word list is the built-in profanity list (PROFANITY) or a custom list (CUSTOM) that you define in the same object. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="words_config" type="list(object)">
      List of custom word configs. Optional.
      <Expandable title="properties">

        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="aiguardrail_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the AI guardrail. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="aiguardrail_id" type="string">
  The unique identifier assigned by AWS Wisdom for this AI guardrail resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon Q (Wisdom) assistant to which this AI guardrail is attached, returned by the service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="modified_time_seconds" type="number">

</ResponseField>

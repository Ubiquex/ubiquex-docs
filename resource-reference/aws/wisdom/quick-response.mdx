`aws_wisdom_quick_response` creates a real, short, reusable response, a canned answer to a common question, that an `aws_wisdom_assistant` surfaces to a contact center agent to insert into a conversation instead of typing it by hand each time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	wisdom "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/wisdom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own quick response"})

    		ubx.Resource(wisdom.QuickResponse, "example", wisdom.QuickResponseConfig{
    			Content:               map[string]any{"content": "example"},
    			KnowledgeBaseArn:      "arn:aws:iam::123456789012:policy/example",
    			Name:                  "example",
    			Channels:              []string{"example"},
    			ContentType:           "example",
    			Description:           "Managed by ubx.",
    			GroupingConfiguration: map[string]any{"criteria": "example"},
    			IsActive:              true,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="channels" type="list(string)">
  The Amazon Connect contact channels this quick response applies to. Optional.
</ResponseField>

<ResponseField name="content" type="object" required>
  The container of quick response content. Required.
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The content of the quick response. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="content_type" type="string">
  The media type of the quick response content. - Use application/x.quickresponse;format=plain for quick response written in plain text. - Use application/x.quickresponse;format=markdown for quick response written in richtext. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the quick response. Optional.
</ResponseField>

<ResponseField name="grouping_configuration" type="object">
  The configuration information of the user groups that the quick response is accessible to. Optional.
  <Expandable title="properties">
    <ResponseField name="criteria" type="string" required>
      The criteria used for grouping Amazon Q in Connect users. Required.
    </ResponseField>
    <ResponseField name="values" type="list(string)" required>
      The list of values that define different groups of Amazon Q in Connect users. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="is_active" type="bool">
  Whether the quick response is active. Optional.
</ResponseField>

<ResponseField name="knowledge_base_arn" type="string" required>
  The Amazon Resource Name (ARN) of the knowledge base. Required.
</ResponseField>

<ResponseField name="language" type="string">
  The language code value for the language in which the quick response is written. The supported language codes include de_DE, en_US, es_ES, fr_FR, id_ID, it_IT, ja_JP, ko_KR, pt_BR, zh_CN, zh_TW Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the quick response. Required.
</ResponseField>

<ResponseField name="shortcut_key" type="string">
  The shortcut key of the quick response. The value should be unique across the knowledge base. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_wisdom_assistant_association` links a real `aws_wisdom_assistant` to an external resource, most commonly an `aws_wisdom_knowledge_base`, that it should draw on, the resource that actually wires the two together.

## Input properties

<ResponseField name="assistant_id" type="string" required>
  The unique identifier of the Wisdom assistant to which this association connects, linking the assistant to the associated knowledge base or integration. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="association" type="object" required>
  Defines the target of the assistant association by providing the knowledge base identifier for the knowledge base to associate with the Wisdom assistant. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="external_bedrock_knowledge_base_config" type="object">
      Optional; if omitted, computed by AWS.
      <Expandable title="properties">
        <ResponseField name="access_role_arn" type="string">
          The ARN of the IAM role that grants Amazon Wisdom permission to access the associated Amazon Bedrock knowledge base. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="bedrock_knowledge_base_arn" type="string">
          The ARN of the Amazon Bedrock knowledge base that the Amazon Q in Connect (Wisdom) assistant associates with for an external Bedrock knowledge base association. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="knowledge_base_id" type="string">
      Identifier of the Amazon Wisdom knowledge base to associate with the assistant, required when the association type is set to KNOWLEDGE_BASE. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="association_type" type="string" required>
  The type of resource being associated with the Wisdom assistant, with the only supported value being KNOWLEDGE_BASE for associating a knowledge base. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Wisdom assistant association, serving as the unique identifier for the tag within the resource's tag set. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the Wisdom assistant association, used to organize and identify the resource for cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="assistant_arn" type="string">
  The ARN of the Amazon Wisdom assistant to which this association is attached. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_association_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the Wisdom assistant association, assigned by AWS upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_association_id" type="string">

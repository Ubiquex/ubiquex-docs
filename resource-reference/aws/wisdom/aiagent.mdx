`aws_wisdom_aiagent` configures a real AI agent within an `aws_wisdom_assistant`, wiring together which `aws_wisdom_aiprompt`s and `aws_wisdom_aiguardrail`s it uses, under the generative-AI layer of Amazon Connect Wisdom (marketed as Amazon Q in Connect), for tasks like answer generation or self-service query handling.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own aiagent"})

    	}))
    }

`aws_wisdom_aiagent_version` publishes a real, immutable version of an `aws_wisdom_aiagent`'s configuration, letting a specific, unchanging version be referenced rather than always using the agent's current, editable configuration.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    	ubx.Main(ubx.Stack("example", func() {

    }

## Input properties

<ResponseField name="aiagent_id" type="string" required>
  The unique identifier of the Wisdom AI agent for which this version is created. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_id" type="string" required>
  The identifier of the Amazon Wisdom assistant to which the AI agent version belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="modified_time_seconds" type="number">
  The Unix epoch time in seconds when the AI agent version was last modified, providing a timestamp to track changes to the version. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="aiagent_arn" type="string">
  The Amazon Resource Name (ARN) of the Wisdom AI agent that this version belongs to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="aiagent_version_id" type="string">
  The unique identifier assigned to the AI agent version when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_arn" type="string">
  The Amazon Resource Name (ARN) of the Wisdom assistant to which this AI agent version belongs, exposed as a computed read-only attribute after the resource is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="version_number" type="number">
  The version number of the AI agent version, automatically assigned by the service. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

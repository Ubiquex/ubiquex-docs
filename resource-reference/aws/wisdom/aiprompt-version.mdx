`aws_wisdom_aiprompt_version` publishes a real, immutable version of an `aws_wisdom_aiprompt`'s text, letting a specific, unchanging version be referenced by an `aws_wisdom_aiagent`.

## Input properties

<ResponseField name="aiprompt_id" type="string" required>
  The unique identifier of the AI prompt in Amazon Wisdom that this version belongs to and whose content is versioned. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_id" type="string" required>
  The unique identifier of the Amazon Q in Connect (Wisdom) assistant to which this AI prompt version belongs. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="modified_time_seconds" type="number">
  The modified_time_seconds field records the Unix epoch time (in seconds) at which the Wisdom AI prompt version was last updated. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="aiprompt_arn" type="string">
  The Amazon Resource Name (ARN) of the Wisdom AI prompt that this version belongs to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="aiprompt_version_id" type="string">
  The unique identifier assigned by Amazon Wisdom to the created version of the AI prompt, returned as a read-only attribute after the resource is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_arn" type="string">
  The Amazon Resource Name (ARN) of the Wisdom assistant that this AI prompt version belongs to. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="version_number" type="number">
  The version number of this AI prompt version, as assigned by AWS Wisdom, which uniquely identifies the version within the parent AI prompt. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

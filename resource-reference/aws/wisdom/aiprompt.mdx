`aws_wisdom_aiprompt` defines a real, customized prompt template, for a specific purpose such as answer generation, case summarization, or email response, that an `aws_wisdom_aiagent` uses instead of Amazon Q in Connect's own built-in default prompt for that purpose.

## Example

    ```go
    import (
    	wisdom "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/wisdom"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own aiprompt"})

    		ubx.Resource(wisdom.Aiprompt, "example", wisdom.AipromptConfig{
    			ApiFormat:             "example",
    			ModelId:               "example",
    			TemplateConfiguration: map[string]any{"text_full_aiprompt_edit_template_configuration": map[string]any{"text": "example"}},
    			TemplateType:          "example",
    			Type:                  "example",
    			Name:                  "example",
    			AssistantId:           "example",
    			Description:           "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="api_format" type="string" required>
  The API format for the AI prompt, indicating whether the model invocation uses TEXT for a single-turn prompt or CHAT for a chat-based multi-turn conversation. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_id" type="string">
  The unique identifier of the Amazon Wisdom assistant with which this AI prompt is associated. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  The description field provides an optional, free-text summary of the AI prompt's intended purpose, which can be used for identification and display within Amazon Q in Connect (Wisdom). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="model_id" type="string" required>
  The model_id field specifies the identifier (such as an ARN) of the underlying model that the Wisdom AI prompt uses to generate responses. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  The user-friendly name assigned to the AI prompt, which is used to identify and reference the prompt within the Amazon Wisdom service and its console. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

<ResponseField name="template_configuration" type="object" required>
  Defines the prompt template settings for the AI prompt, allowing you to specify either a simple text prompt or a full prompt template with its corresponding type. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="text_full_aiprompt_edit_template_configuration" type="object">
      Configuration object for the text-based full AI prompt editing template, which contains the prompt text string used as the template content in AWS Wisdom AI prompts. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="text" type="string">
          The prompt template text used in the full AI prompt edit configuration, defining the instructions or content for the AI prompt. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template_type" type="string" required>
  Defines whether the AI prompt uses a plain text template or a chat-based template, determining the expected configuration format for the prompt. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="type" type="string" required>
  Required.
</ResponseField>

## Output properties

<ResponseField name="aiprompt_arn" type="string">
  This read-only attribute holds the Amazon Resource Name (ARN) that uniquely identifies the AWS Wisdom AI prompt resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="aiprompt_id" type="string">
  The unique identifier that AWS Wisdom assigns to the AI prompt, returned by the service after the resource is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon Wisdom assistant associated with this AI prompt, provided as a read-only computed attribute. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="modified_time_seconds" type="number">
  The Unix epoch time, in seconds, when the AI prompt was last modified. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

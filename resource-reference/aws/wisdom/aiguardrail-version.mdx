`aws_wisdom_aiguardrail_version` publishes a real, immutable version of an `aws_wisdom_aiguardrail`'s configuration, letting a specific, unchanging version be referenced by an `aws_wisdom_aiagent`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	wisdom "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/wisdom"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own aiguardrail version"})

    		ubx.Resource(wisdom.AiguardrailVersion, "example", wisdom.AiguardrailVersionConfig{
    			AiguardrailId:       "example",
    			AssistantId:         "example",
    			ModifiedTimeSeconds: 7200,
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="aiguardrail_id" type="string" required>
  The unique identifier of the AI guardrail for which this version is created, linking the version to its parent guardrail resource. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_id" type="string" required>
  The unique identifier of the Amazon Connect Wisdom assistant that owns the AI guardrail version. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="modified_time_seconds" type="number">
  The Unix epoch timestamp (in seconds) when this AI guardrail version was last modified. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="aiguardrail_arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies this AI guardrail version in Amazon Wisdom. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="aiguardrail_version_id" type="string">
  The unique identifier assigned by AWS to this specific version of the AI guardrail, used as a read-only reference to the version resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="assistant_arn" type="string">
  The Amazon Resource Name (ARN) of the Wisdom assistant to which this AI Guardrail version belongs. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="version_number" type="number">
  The version number assigned by the AWS Wisdom service to this AI Guardrail version, uniquely identifying this version within its guardrail. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

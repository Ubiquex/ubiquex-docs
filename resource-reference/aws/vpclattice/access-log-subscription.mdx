`aws_vpc_lattice_access_log_subscription` streams a real log of every request handled by an `aws_vpc_lattice_service_network` or service to a CloudWatch Logs group, S3 bucket, or Firehose delivery stream.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	vpclattice "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/vpclattice"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lattice access log subscription"})

    		ubx.Resource(vpclattice.AccessLogSubscription, "example", vpclattice.AccessLogSubscriptionConfig{
    			DestinationArn:        "arn:aws:iam::123456789012:policy/example",
    			ResourceIdentifier:    "example",
    			ServiceNetworkLogType: "example",
    			Tags:                  []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="destination_arn" type="string" required>
  The Amazon Resource Name (ARN) of the destination (an S3 bucket, CloudWatch Logs log group, or Kinesis Data Firehose delivery stream) to which VPC Lattice access logs are delivered. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_identifier" type="string">
  Specifies the ID or ARN of the service network or service that the access log subscription is associated with, determining which resource's access logs are delivered to the destination. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_network_log_type" type="string">
  Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

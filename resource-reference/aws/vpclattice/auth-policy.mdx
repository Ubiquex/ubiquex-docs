`aws_vpc_lattice_auth_policy` attaches a real IAM-based authorization policy to an `aws_vpc_lattice_service`, controlling which principals are allowed to call it, independent of network-level `aws_vpc_lattice_service_network_vpc_association` reachability.

## Input properties

<ResponseField name="policy" type="any" required>
  The JSON policy document that defines the authentication and authorization rules for the associated VPC Lattice service or service network, specifying allowed principals, actions, and conditions. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_identifier" type="string" required>
  The resource identifier specifies the ID or ARN of the VPC Lattice service or service network that this auth policy is associated with. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="state" type="string">
  Returns the current state of the VPC Lattice auth policy, indicating whether the policy is active or inactive. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_vpc_lattice_service_network_resource_association` associates a real `aws_vpc_lattice_resource_configuration` with an `aws_vpc_lattice_service_network`, making that non-service resource reachable to everything else connected to the network.

## Example

    import (

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service network resource association"})

    		ubx.Resource(vpclattice.ServiceNetworkResourceAssociation, "example", vpclattice.ServiceNetworkResourceAssociationConfig{
    			PrivateDnsEnabled:       true,
    			ResourceConfigurationId: "example",
    			ServiceNetworkId:        "example",
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="private_dns_enabled" type="bool">
  When enabled, this generates a private DNS hostname for the associated resource within the VPC Lattice service network, allowing it to be accessed via DNS resolution from associated VPCs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_configuration_id" type="string">
  The unique identifier of the resource configuration (such as a VPC or AWS service) to associate with the service network. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_network_id" type="string">
  The unique ID of the VPC Lattice service network that this resource association attaches the specified resource to. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">

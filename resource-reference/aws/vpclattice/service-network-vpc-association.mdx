`aws_vpc_lattice_service_network_vpc_association` associates a real VPC with an `aws_vpc_lattice_service_network`, the resource that actually lets resources inside that VPC reach every service published to the network.

    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="dns_options" type="object">
  DNS options for the VPC association, specifying the DNS type (IPv4 or IPv6) used to resolve service network domains within the associated VPC. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="private_dns_preference" type="string">
      Determines whether private DNS resolution is enabled for the VPC associated with the service network, accepting values 'enabled' or 'disabled' to control the private DNS preference. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="private_dns_specified_domains" type="list(string)">
      The `dns_options.private_dns_specified_domains` field specifies the list of private DNS domain names that the associated VPC will use to resolve service endpoints in the service network, enabling private DNS resolution for the association. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="private_dns_enabled" type="bool">
  Indicates whether private DNS is enabled for the VPC association, allowing service network endpoints to be resolved using private DNS in the associated VPC. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)">
  Specifies the list of security group IDs to optionally associate with this VPC Lattice service network VPC association, which control traffic between the VPC and the service network. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="service_network_identifier" type="string">
  The ID or ARN of the Amazon VPC Lattice service network that the VPC association targets. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Assigns a list of key-value tags to the service network VPC association to help manage and identify it. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.

    <ResponseField name="value" type="string">
      The value component of a tag attached to the AWS VPC Lattice service network VPC association, used for metadata, identification, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_identifier" type="string">
  The ID of the VPC that is associated with the service network. Optional. **(AI-inferred)**
</ResponseField>

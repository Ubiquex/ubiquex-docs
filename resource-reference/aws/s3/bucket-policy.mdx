`aws_s3_bucket_policy` attaches a real resource-based access policy to an `aws_s3_bucket`, controlling which principals, including from other accounts, can read from or write to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own bucket policy"})

    		ubx.Resource(s3.BucketPolicy, "example", s3.BucketPolicyConfig{
    			Bucket:         "example",
    			PolicyDocument: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="bucket" type="string" required>
  The name of the Amazon S3 bucket to which the policy applies. Required.
</ResponseField>

<ResponseField name="policy_document" type="any" required>
  A policy document containing permissions to add to the specified bucket. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. For more information, see the AWS::IAM::Policy [PolicyDocument](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-iam-policy.html#cfn-iam-policy-policydocument) resource description in this guide and [Access Policy Language Overview](https://docs.aws.amazon.com/AmazonS3/latest/dev/access-policy-language-overview.html) in the *Amazon S3 User Guide*. Required.
</ResponseField>

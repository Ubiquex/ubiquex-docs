`aws_s3_outposts_endpoint` creates a real network endpoint on an AWS Outposts rack's local network that lets on-premises applications reach an `aws_s3_outposts_bucket` without traffic leaving the Outpost.

## Example

<Tabs>

    ```go
    	s3outposts "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/s3outposts"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own outposts endpoint"})

    		ubx.Resource(s3outposts.Endpoint, "example", s3outposts.EndpointConfig{

    			SubnetId:              "example",
    			AccessType:            "example",
    			CustomerOwnedIpv4Pool: "example",
    			FailedReason:          map[string]any{"error_code": "example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="access_type" type="string">
  The type of access for the on-premise network connectivity for the Outpost endpoint. To access endpoint from an on-premises network, you must specify the access type and provide the customer owned Ipv4 pool. Optional.
</ResponseField>

<ResponseField name="customer_owned_ipv4_pool" type="string">
  The ID of the customer-owned IPv4 pool for the Endpoint. IP addresses will be allocated from this pool for the endpoint. Optional.
</ResponseField>

<ResponseField name="failed_reason" type="object">
  The failure reason for the S3 on Outposts endpoint, providing an error code and message if endpoint creation failed. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="error_code" type="string">
      The failure code, if any, for a create or delete endpoint operation. Optional.
    </ResponseField>
    <ResponseField name="message" type="string">
      Additional error details describing the endpoint failure and recommended action. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="outpost_id" type="string" required>
  The id of the customer outpost on which the bucket resides. Required.
</ResponseField>

<ResponseField name="security_group_id" type="string" required>
  The ID of the security group to use with the endpoint. Required.
</ResponseField>

<ResponseField name="subnet_id" type="string" required>
  The ID of the subnet in the selected VPC. The subnet must belong to the Outpost. Required.
</ResponseField>

## Output properties

</ResponseField>

<ResponseField name="cidr_block" type="string">

  The ID of the endpoint. Computed by AWS after `ship`.

`aws_s3_tables_table_policy` attaches a real resource-based access policy to an individual `aws_s3_tables_table`, controlling which principals can read or write that specific Iceberg table's data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3tables "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/s3tables"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tables table policy"})

    		ubx.Resource(s3tables.TablePolicy, "example", s3tables.TablePolicyConfig{
    			ResourcePolicy: "example",
    			TableArn:       "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx

    def describe():

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="resource_policy" type="any" required>
  A policy document containing permissions to add to the specified table. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. Required.
</ResponseField>

<ResponseField name="table_arn" type="string" required>
  The Amazon Resource Name (ARN) of the specified table. Required.
</ResponseField>

## Output properties

<ResponseField name="namespace" type="string">
  The namespace that the table belongs to. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="table_bucket_arn" type="string">
  The Amazon Resource Name (ARN) of the specified table bucket. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="table_name" type="string">
  The name for the table. Computed by AWS after `ship`.
</ResponseField>

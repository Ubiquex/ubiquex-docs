`aws_s3_access_grant` grants a real IAM principal or an IAM Identity Center user or group temporary, credential-vended access to a specific S3 prefix through an `aws_s3_access_grants_instance`, without writing or maintaining a bucket policy for that grant.

## Input properties

<ResponseField name="access_grants_location_configuration" type="object">
  Configures the S3 sub-prefix (S3SubPrefix) within the associated access grants location, restricting the access grant's permission scope to that prefix. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="s3_sub_prefix" type="string" required>
      The S3 sub prefix of a registered location in your S3 Access Grants instance Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="access_grants_location_id" type="string" required>
  The custom S3 location to be accessed by the grantee Required.
</ResponseField>

<ResponseField name="application_arn" type="string">
  The ARN of the application grantees will use to access the location Optional.
</ResponseField>

<ResponseField name="grantee" type="object" required>
  Defines the entity that receives the access grant, including its type (such as an IAM principal, directory user, or directory group) and its identifier (e.g., an ARN or directory ID). Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="grantee_identifier" type="string" required>
      The unique identifier of the Grantee Required.
    </ResponseField>
    <ResponseField name="grantee_type" type="string" required>
      Configures the transfer acceleration state for an Amazon S3 bucket. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="permission" type="string" required>
  The level of access to be afforded to the grantee Required.
</ResponseField>

<ResponseField name="s3_prefix_type" type="string">
  The type of S3SubPrefix. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">

    <ResponseField name="key" type="string">

    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value for a given tag key applied to the S3 Access Grant, which is used for organizing, identifying, and managing the resource in AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="access_grant_arn" type="string">
  the Amazon Resource Name (ARN) of the specified access grant. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="access_grant_id" type="string">
  The ID assigned to this access grant. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="grant_scope" type="string">
  The S3 path of the data to which you are granting access. It is a combination of the S3 path of the registered location and the subprefix. Computed by AWS after `ship`.
</ResponseField>

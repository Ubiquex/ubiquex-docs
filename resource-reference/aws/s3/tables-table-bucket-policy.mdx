`aws_s3_tables_table_bucket_policy` attaches a real resource-based access policy to an `aws_s3_tables_table_bucket`, controlling which principals can create or list tables and namespaces within it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tables table bucket policy"})

    		ubx.Resource(s3.TablesTableBucketPolicy, "example", s3.TablesTableBucketPolicyConfig{
    			ResourcePolicy: "example",
    			TableBucketArn: "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="resource_policy" type="any" required>
  A policy document containing permissions to add to the specified table bucket. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. Required.
</ResponseField>

<ResponseField name="table_bucket_arn" type="string" required>
  The Amazon Resource Name (ARN) of the table bucket to which the policy applies. Required.
</ResponseField>

---
title: "aws_s3_bucket"
description: "An S3 bucket, the base resource other S3 configuration attaches to."
---

`aws_s3_bucket` creates the bucket itself. Versioning, encryption,
public-access blocking, and lifecycle rules are each their own separate
resource, attached to this bucket by reference, real Terraform provider
behavior since v4.

Every tab below is a complete, runnable program, not a fragment,
real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own bucket"})

    		ubx.Resource(s3.Bucket, "ci-runner", s3.BucketConfig{
    			ForceDestroy: true,
    			Tags:         map[string]string{"managed-by": "ubx"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Bucket } from "jsr:@ubx/sdk-aws/aws/s3/bucket";

    export default stack("payments", () => {
      intent({ summary: "payments own bucket" });

      resource(Bucket, "ci-runner", {
        forceDestroy: true,
        tags: { "managed-by": "ubx" },
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.s3 import Bucket, BucketConfig

    def describe():
        ubx.intent("payments own bucket")

        ubx.resource(Bucket, "ci-runner", BucketConfig(
            force_destroy=True,
            tags={"managed-by": "ubx"},
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```
  </Tab>

## Input properties

<ResponseField name="bucket" type="string">
  The bucket's own globally-unique name. Conflicts with `bucket_prefix`.
</ResponseField>

<ResponseField name="bucket_prefix" type="string">
  A prefix, with a generated suffix appended. Conflicts with `bucket`.
</ResponseField>

<ResponseField name="force_destroy" type="bool" default="false">
  Destroy the bucket even if it still contains real objects.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Real, arbitrary tags.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Same value as `bucket`.
</ResponseField>

<ResponseField name="arn" type="string">
  The bucket's real ARN, computed, known only after ship.
</ResponseField>

<ResponseField name="bucket_domain_name" type="string">
  The bucket's real S3 domain name.
</ResponseField>

<ResponseField name="bucket_regional_domain_name" type="string">
  The bucket's real, region-specific S3 domain name.
</ResponseField>

<ResponseField name="region" type="string">
  The real AWS region the bucket was created in.
</ResponseField>

<ResponseField name="hosted_zone_id" type="string">
  The real Route 53 hosted zone ID for this bucket's region.
</ResponseField>

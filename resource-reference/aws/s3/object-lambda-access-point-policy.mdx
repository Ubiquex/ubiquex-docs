`aws_s3_object_lambda_access_point_policy` attaches a real resource-based access policy to an `aws_s3_object_lambda_access_point`, controlling which principals can invoke it to retrieve transformed object data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own object lambda access point policy"})

    		ubx.Resource(s3.ObjectLambdaAccessPointPolicy, "example", s3.ObjectLambdaAccessPointPolicyConfig{
    			ObjectLambdaAccessPoint: "example",
    			PolicyDocument:          "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="object_lambda_access_point" type="string" required>
  The name of the Amazon S3 ObjectLambdaAccessPoint to which the policy applies. Required.
</ResponseField>

<ResponseField name="policy_document" type="any" required>
  A policy document containing permissions to add to the specified ObjectLambdaAccessPoint. For more information, see Access Policy Language Overview (https://docs.aws.amazon.com/AmazonS3/latest/dev/access-policy-language-overview.html) in the Amazon Simple Storage Service Developer Guide. Required.
</ResponseField>

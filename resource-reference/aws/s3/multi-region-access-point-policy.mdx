`aws_s3_multi_region_access_point_policy` attaches a real resource-based access policy to an `aws_s3_multi_region_access_point`, controlling which principals can use that single global endpoint to reach the underlying replicated buckets.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own multi region access point policy"})

    		ubx.Resource(s3.MultiRegionAccessPointPolicy, "example", s3.MultiRegionAccessPointPolicyConfig{
    			MrapName: "example-mrap-name",
    			Policy:   "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="mrap_name" type="string" required>
  The name of the Multi Region Access Point to apply policy Required.
</ResponseField>

<ResponseField name="policy" type="any" required>
  Policy document to apply to a Multi Region Access Point Required.
</ResponseField>

## Output properties

<ResponseField name="policy_status" type="object">
  The Policy Status associated with this Multi Region Access Point Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="is_public" type="string" required>
      Specifies whether the policy is public or not. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_s3_vectors_vector_bucket_policy` attaches a real resource-based access policy to an `aws_s3_vectors_vector_bucket`, controlling which principals can create, query, or manage vector indexes within it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own vectors vector bucket policy"})

    		ubx.Resource(s3.VectorsVectorBucketPolicy, "ci-runner", s3.VectorsVectorBucketPolicyConfig{
    			Policy:           "example",
    			VectorBucketArn:  "arn:aws:iam::123456789012:policy/ci",
    			VectorBucketName: "example-vector-bucket-name",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="policy" type="any" required>
  A policy document containing permissions to add to the specified vector bucket. In IAM, you must provide policy documents in JSON format. However, in CloudFormation you can provide the policy in JSON or YAML format because CloudFormation converts YAML to JSON before submitting it to IAM. Required.
</ResponseField>

<ResponseField name="vector_bucket_arn" type="string">
  The Amazon Resource Name (ARN) of the vector bucket. Optional.
</ResponseField>

<ResponseField name="vector_bucket_name" type="string">
  The name of the vector bucket Optional.
</ResponseField>

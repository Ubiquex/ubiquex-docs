`aws_s3_outposts_bucket_policy` attaches a real resource-based access policy to an `aws_s3_outposts_bucket`, controlling which principals on the local Outpost network can access it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own outposts bucket policy"})

    		ubx.Resource(s3.OutpostsBucketPolicy, "example", s3.OutpostsBucketPolicyConfig{
    			Bucket:         "example",
    			PolicyDocument: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="bucket" type="string" required>
  The Amazon Resource Name (ARN) of the specified bucket. Required.
</ResponseField>

<ResponseField name="policy_document" type="any" required>
  A policy document containing permissions to add to the specified bucket. Required.
</ResponseField>

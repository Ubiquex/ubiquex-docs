`aws_s3_outposts_access_point` creates a real access point scoped to an `aws_s3_outposts_bucket`, controlling which VPC and principals can reach that Outposts bucket.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	s3 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/s3"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own outposts access point"})

    		ubx.Resource(s3.OutpostsAccessPoint, "ci-runner", s3.OutpostsAccessPointConfig{
    			Bucket:           "example",
    			Name:             "ci-runner",
    			VpcConfiguration: map[string]any{"vpc_id": "example"},
    			Policy:           "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="bucket" type="string" required>
  The Amazon Resource Name (ARN) of the bucket you want to associate this AccessPoint with. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the AccessPoint. Required.
</ResponseField>

<ResponseField name="policy" type="any">
  The access point policy associated with this access point. Optional.
</ResponseField>

<ResponseField name="vpc_configuration" type="object" required>
  The VPC configuration that specifies the virtual private cloud (VPC) in which the S3 on Outposts access point is accessible, containing the required VPC ID. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="vpc_id" type="string">
      Virtual Private Cloud (VPC) Id from which AccessPoint will allow requests. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the specified AccessPoint. Computed by AWS after `ship`.
</ResponseField>

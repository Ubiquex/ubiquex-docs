## Input properties

<ResponseField name="client_token" type="string">
  (optional) A string of up to 64 ASCII characters that Amazon EFS uses to ensure idempotent creation. Optional.
</ResponseField>

<ResponseField name="file_system_id" type="string" required>
  The ID of the S3 Files file system that the access point provides access to. Required.
</ResponseField>

<ResponseField name="posix_user" type="object">
  Defines the POSIX user ID (UID) and group ID (GID) for the S3 on Outposts access point, controlling file-level permissions for NFS access. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="gid" type="string" required>
      The POSIX group ID used for all file system operations using this access point. Required.
    </ResponseField>
    <ResponseField name="secondary_gids" type="list(string)">
      Secondary POSIX group IDs used for all file system operations using this access point. Optional.
    </ResponseField>
    <ResponseField name="uid" type="string" required>
      The POSIX user ID used for all file system operations using this access point. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="root_directory" type="object">
  Specifies the root directory path within the S3 bucket that the access point is restricted to, so requests through the access point can only access objects under that prefix (supported for S3 on Outposts buckets). Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="creation_permissions" type="object">
      Optional.
      <Expandable title="properties">
        <ResponseField name="owner_gid" type="string" required>
          Specifies the POSIX group ID to apply to the RootDirectory. Accepts values from 0 to 2^32 (4294967295). Required.
        </ResponseField>
        <ResponseField name="owner_uid" type="string" required>
          Specifies the POSIX user ID to apply to the RootDirectory. Accepts values from 0 to 2^32 (4294967295). Required.
        </ResponseField>
        <ResponseField name="permissions" type="string" required>
          Specifies the POSIX permissions to apply to the RootDirectory, in the format of an octal number representing the file's mode bits. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="path" type="string">
      Specifies the path on the EFS file system to expose as the root directory to NFS clients using the access point to access the EFS file system. A path can have up to four subdirectories. If the specified path does not exist, you are required to provide the CreationPermissions. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the S3 file access point, used for identifying and organizing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="access_point_arn" type="string">
  The Amazon Resource Name (ARN) of the S3 access point, which uniquely identifies the access point and is used for making requests to S3 through the access point. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="access_point_id" type="string">
  Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="owner_id" type="string">

</ResponseField>

<ResponseField name="status" type="string">
  Computed by AWS after `ship`.
</ResponseField>

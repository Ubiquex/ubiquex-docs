`aws_clean_rooms_ml_configured_model_algorithm` makes a container training image available for use inside AWS Clean Rooms ML, the real, deployable model logic an `aws_clean_rooms_ml_training_dataset` gets trained against without either collaboration member sharing raw training data with the other.

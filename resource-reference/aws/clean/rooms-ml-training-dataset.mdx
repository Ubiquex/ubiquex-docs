`aws_clean_rooms_ml_training_dataset` points AWS Clean Rooms ML at the real AWS Glue table, and its user, item, and timestamp columns, used to train a lookalike model, Clean Rooms ML reads metadata about the location rather than copying the underlying training data itself.

`aws_ssmgui_connect_preferences` configures real, account-level session recording preferences, which S3 bucket recordings are stored in, for AWS Systems Manager GUI Connect, the Fleet Manager feature that lets administrators reach Windows Server EC2 instances over RDP directly from the Systems Manager console. This is a comparatively recent capability, so behavior here is verified live rather than assumed from general knowledge.

## Input properties

<ResponseField name="connection_recording_preferences" type="object">
  The set of preferences used for recording RDP connections in the requesting AWS account and AWS Region. This includes details such as which S3 bucket recordings are stored in. Optional.
  <Expandable title="properties">
    <ResponseField name="kmskey_arn" type="string" required>
      The ARN of a AWS KMS key that is used to encrypt data while it is being processed by the service. This key must exist in the same AWS Region as the node you start an RDP connection to. Required.
    </ResponseField>
    <ResponseField name="recording_destinations" type="object" required>
      Determines where recordings of RDP connections are stored. Required.
      <Expandable title="properties">
        <ResponseField name="s3_buckets" type="list(object)" required>
          The S3 bucket where RDP connection recordings are stored. Required.
          <Expandable title="properties">
            <ResponseField name="bucket_name" type="string">
              The name of the S3 bucket used as a destination where connection recording sessions are stored. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="bucket_owner" type="string">
              Optional; if omitted, computed by AWS.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

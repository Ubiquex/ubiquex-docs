---
title: "aws_synthetics_group"
description: "`aws_synthetics_group` groups real `aws_synthetics_canary`s together..."
---

`aws_synthetics_group` groups real `aws_synthetics_canary`s together, so their combined pass/fail status and metrics can be viewed and alarmed on as one unit rather than canary by canary.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	synthetics "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/synthetics"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own group"})

    		ubx.Resource(synthetics.Group, "example", synthetics.GroupConfig{
    			Name:         "example",
    			ResourceArns: []string{"example"},
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  Name of the group. Required.
</ResponseField>

<ResponseField name="resource_arns" type="list(string)">
  Specifies the ARNs of the Synthetics canaries to associate with this group, making them members of the group. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags are metadata labels (key-value pairs) that you can assign to the Synthetics group to help organize, identify, and manage it, with each tag defined by a key and optional value. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key part of a key-value tag, used to assign metadata to the canary group for identification and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the Synthetics canary group, which is a user-defined string that helps manage and identify the group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  Id of the group. Computed by AWS after `ship`.
</ResponseField>

---
title: "aws_app_mesh_mesh"
description: "`aws_app_mesh_mesh` creates the service mesh itself, the logical boundary for all network traffic between the services registered inside it."
---

Every other App Mesh resource, virtual nodes, routers, services, gateways, belongs to exactly one mesh.

## Input properties

<ResponseField name="mesh_name" type="string">
  The name of the App Mesh service mesh; if omitted, CloudFormation generates a unique name, and this name serves as the mesh's resource identifier. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="spec" type="object">
  Defines the mesh's EgressFilter and optional IpPreference settings, which govern outbound traffic handling and IP protocol preference for the mesh. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="egress_filter" type="object">
      Specifies the egress filter type that controls whether outbound traffic from the mesh to external services is allowed (ALLOW_ALL) or blocked (DROP_ALL). Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="type" type="string" required>
          Specifies the egress filter type for the service mesh, either allowing all outbound traffic (ALLOW_ALL) or dropping all outbound traffic (DROP_ALL). Required. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="service_discovery" type="object">
      Defines mesh-wide service discovery settings, specifically the IP preference (IPv4 or IPv6) used for DNS resolution of virtual service endpoints. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="ip_preference" type="string">
          Determines the IP preference for DNS service discovery in the mesh, controlling whether DNS queries return only IPv4 addresses, only IPv6 addresses, or prefer one type when both are available. Optional. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags (key-value metadata) to attach to the AWS App Mesh mesh resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS App Mesh mesh, used for resource grouping and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the App Mesh mesh, used for categorizing, cost allocation, and IAM-based access control of the mesh resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the App Mesh mesh. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The computed `id` field contains the name of the App Mesh mesh, which serves as the unique identifier for the resource within AWS and in Terraform's state, and is also the primary key used when importing the resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="mesh_owner" type="string">
  The AWS account ID that owns the mesh, automatically assigned by AWS and read-only. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="resource_owner" type="string">
  The AWS account ID of the mesh owner, which is the account that created the App Mesh mesh resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="uid" type="string">
  Computed by AWS after `ship`.
</ResponseField>

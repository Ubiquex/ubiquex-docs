`aws_api_gateway_client_certificate` generates a certificate an `aws_api_gateway_rest_api` presents to its own backend, so the backend can verify requests genuinely came through API Gateway rather than directly from the internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own client certificate"})

    		ubx.Resource(apigateway.ClientCertificate, "example", apigateway.ClientCertificateConfig{
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { ClientCertificate } from "@ubx/sdk-aws/aws/apigateway/client_certificate";

    export default stack("example", () => {

      resource(ClientCertificate, "example", {

      });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.apigateway import ClientCertificate, ClientCertificateConfig
    from ubx.aws.apigateway.client_certificate import ClientCertificate_Tags

    def describe():
        ubx.intent("example own client certificate")

        ubx.resource(ClientCertificate, "example", ClientCertificateConfig(
            description="Managed by ubx.",
            tags=[ClientCertificate_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  A user-provided description for the client certificate, used to annotate or identify it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Associates a list of key-value tag pairs with the API Gateway client certificate, enabling cost allocation, access control, and resource categorization. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of an individual tag assigned to the API Gateway client certificate, used for metadata and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="client_certificate_id" type="string">
  The unique identifier assigned by Amazon API Gateway to the client certificate, used to reference this certificate in other API Gateway resources (e.g., domain names) and returned automatically upon creation. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

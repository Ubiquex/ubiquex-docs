title: "aws_api_gateway_domain_name"
description: "`aws_api_gateway_domain_name` registers a custom domain for REST APIs (API Gateway v1)..."
---

`aws_api_gateway_domain_name` registers a custom domain for REST APIs (API Gateway v1), provisioning the TLS certificate and edge or regional endpoint that requests to that domain terminate at, before `aws_api_gateway_base_path_mapping` routes them to a specific API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway domain name"})

    		ubx.Resource(apigateway.DomainName, "example", apigateway.DomainNameConfig{
    			CertificateArn:                      "arn:aws:iam::123456789012:policy/example",
    			DomainName:                          "example-domain-name",
    			EndpointAccessMode:                  "example",
    			EndpointConfiguration:               map[string]any{"ip_address_type": "example"},
    			MutualTlsAuthentication:             map[string]any{"truststore_uri": "example"},
    			OwnershipVerificationCertificateArn: "arn:aws:iam::123456789012:policy/example",
    			RegionalCertificateArn:              "arn:aws:iam::123456789012:policy/example",
    			RoutingMode:                         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="certificate_arn" type="string">
  The ARN of an AWS Certificate Manager (ACM) certificate used to secure the edge-optimized domain name's TLS/SSL connections. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_name" type="string">
  The custom domain name (e.g., api.example.com) that API Gateway serves for this domain name resource, which must be registered and associated with an ACM certificate. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_access_mode" type="string">
  This field sets the endpoint access mode for the API Gateway custom domain name, either PUBLIC for internet access or PRIVATE to restrict access to private VPC endpoints. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint_configuration" type="object">
  The ``EndpointConfiguration`` property type specifies the endpoint types and IP address types of an Amazon API Gateway domain name. ``EndpointConfiguration`` is a property of the [AWS::ApiGateway::DomainName](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-apigateway-domainname.html) resource. Optional.
  <Expandable title="properties">
    <ResponseField name="ip_address_type" type="string">
      Determines the IP address version (IPv4 or IPv6) used by the regional API Gateway custom domain name when the endpoint type is REGIONAL. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="types" type="list(string)">
      Specifies the list of endpoint types (EDGE, REGIONAL, or PRIVATE) that determine how the API Gateway domain name is exposed and routed across AWS regions and VPCs. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="mutual_tls_authentication" type="object">
  Configures mutual TLS (mTLS) for the API Gateway domain name by providing the truststore URI and version used to validate client certificates. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="truststore_uri" type="string">
      The Amazon S3 URI of the truststore containing the trusted CA certificates used for mutual TLS authentication on the API Gateway domain name. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="truststore_version" type="string">
      The version of the S3 object that contains the truststore for mutual TLS authentication. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ownership_verification_certificate_arn" type="string">
  The ARN of the public certificate issued by ACM to validate ownership of your custom domain. Only required when configuring mutual TLS and using an ACM imported or private CA certificate ARN as the RegionalCertificateArn. Optional.
</ResponseField>

<ResponseField name="regional_certificate_arn" type="string">
  Specifies the ARN of an AWS Certificate Manager (ACM) certificate to use for the domain name's regional API endpoint, which serves requests for a specific AWS region. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="routing_mode" type="string">
  Optional.
</ResponseField>

<ResponseField name="security_policy" type="string">
  Specifies the minimum TLS version (e.g., 'TLS_1_0' or 'TLS_1_2') that API Gateway uses for the custom domain name's HTTPS connections. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the list of key-value tags to attach to the API Gateway domain name. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="distribution_domain_name" type="string">
  The CloudFront distribution domain name that API Gateway assigns to the custom domain name, used as the target for a Route 53 alias record or CNAME to point the custom domain to the API endpoints. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="distribution_hosted_zone_id" type="string">
  The Route 53 hosted zone ID of the CloudFront distribution associated with this API Gateway custom domain name (used for edge-optimized endpoints). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_name_arn" type="string">
  The Amazon Resource Name (ARN) of the API Gateway domain name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="regional_domain_name" type="string">
  The auto-generated regional domain name (e.g., d-xxxxxxxx.execute-api.region.amazonaws.com) that API Gateway assigns to this custom domain name when configured for a regional endpoint, which is used as the DNS target for routing traffic to API Gateway. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="regional_hosted_zone_id" type="string">
  The Route 53 hosted zone ID for the regional API Gateway endpoint, used to configure DNS alias records pointing to the regional domain name. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

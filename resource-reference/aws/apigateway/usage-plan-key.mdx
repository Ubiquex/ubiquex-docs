---
title: "aws_api_gateway_usage_plan_key"
description: "`aws_api_gateway_usage_plan_key` is the actual association between an `aws_api_gateway_api_key` and an `aws_api_gateway_usage_plan`."
---

An API key on its own is subject to no limits, this association is what puts it under a specific plan's throttling and quota.

## Example

## Input properties

<ResponseField name="key_id" type="string" required>
  The Id of the UsagePlanKey resource. Required.
</ResponseField>

<ResponseField name="key_type" type="string" required>
  Indicates the type of the API key associated with the usage plan, either 'API_KEY' for a standard API Gateway key or 'CUSTOM' for a custom imported key. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="usage_plan_id" type="string" required>
  The Id of the UsagePlan resource representing the usage plan containing the UsagePlanKey resource representing a plan customer. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The unique resource identifier in Terraform, formed by joining the usage plan ID and the API key ID with a colon. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

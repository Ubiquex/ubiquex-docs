`aws_api_gateway_documentation_version` snapshots an `aws_api_gateway_rest_api`'s documentation parts at a point in time, kept versioned separately from the API's own deployments so docs and API behavior can each move independently.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apigateway "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/apigateway"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own documentation version"})

    		ubx.Resource(apigateway.DocumentationVersion, "example", apigateway.DocumentationVersionConfig{
    			DocumentationVersion: "example",
    			RestApiId:            "example",
    			Description:          "Managed by ubx.",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="description" type="string">
  Provides a human-readable description for the documentation version snapshot, typically indicating the changes or purpose of that version. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="documentation_version" type="string" required>
  The version identifier of the API documentation snapshot that this documentation version represents. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="rest_api_id" type="string" required>

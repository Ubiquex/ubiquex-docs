---
title: "aws_cloud9_environment_ec2"
description: "`aws_cloud9_environment_ec2` provisions an EC2-backed Cloud9 IDE environment, a browser-based development environment with a real EC2 instance behind it."
---

AWS Cloud9 is no longer available to new customers as of July 25, 2024; AWS recommends AWS IDE Toolkits and AWS CloudShell going forward, with existing Cloud9 customers able to continue using the service as normal.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloud9 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloud9"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment ec2"})

    		ubx.Resource(cloud9.EnvironmentEc2, "example", cloud9.EnvironmentEc2Config{
    			ImageId:                  "example",
    			InstanceType:             "example",
    			Name:                     "example",
    			AutomaticStopTimeMinutes: 1,
    			ConnectionType:           "example",
    			Description:              "Managed by ubx.",
    			OwnerArn:                 "arn:aws:iam::123456789012:policy/example",
    			Repositories:             []map[string]any{{"path_component": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="automatic_stop_time_minutes" type="number">
  The number of minutes of inactivity after which AWS Cloud9 automatically stops the environment's EC2 instance, shutting down the environment when this time is reached. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="connection_type" type="string">
  Specifies whether AWS Cloud9 connects to the environment's Amazon EC2 instance via SSH (CONNECT_SSH, the default) or AWS Systems Manager (CONNECT_SSM). Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  An optional description that provides additional non-identifying context about the Cloud9 environment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="image_id" type="string" required>
  The image_id specifies the Amazon Machine Image (AMI) ID used to launch the Amazon EC2 instance that hosts the Cloud9 environment. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  Specifies the EC2 instance type (e.g., t2.micro, m5.large) that the AWS Cloud9 environment runs on, determining the compute and memory resources available. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Specifies the name of the Cloud9 development environment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="owner_arn" type="string">
  The Amazon Resource Name (ARN) of the environment owner; if not specified, the environment is owned by the user who created it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="repositories" type="list(object)">
  A list of repositories to clone into the environment, each containing the repository URL and the path component where it should be cloned. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="path_component" type="string">
      The relative path component within the AWS Cloud9 environment where the source repository will be cloned, serving as the directory name for the repository. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="repository_url" type="string">
      The URL of the source code repository to clone into the Cloud9 environment when the environment is created. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subnet_id" type="string">
  The ID of the subnet in which the Cloud9 environment's EC2 instance is launched, allowing the environment to reside in a specific VPC and network configuration. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of tag key-value pairs to associate with the Cloud9 EC2 environment. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value for a tag key on the AWS Cloud9 EC2 environment, allowing you to add arbitrary metadata for identifying or organizing the environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the Cloud9 EC2 development environment. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier assigned by AWS Cloud9 to the environment, such as 'env-1234567890abcdef0'. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

---

`aws_launch_template` defines a real, versioned template of instance launch parameters, AMI, instance type, key pair, security groups, and more, that EC2, Auto Scaling groups, EC2 Fleet, and Spot Fleet all launch instances from. It is the current, actively developed successor to the deprecated `aws_launch_configuration`, adding version history and support for the latest EC2 features.

`aws_launch_configuration` defines a real, legacy Auto Scaling launch template predecessor: instance type, AMI, and instance-level settings for instances an Auto Scaling group launches. AWS deprecated launch configurations in favor of `aws_launch_template`: no new EC2 features have been added to launch configurations since January 2023, and as of October 1, 2024 new AWS accounts cannot create a launch configuration through any method, console, API, CLI, or CloudFormation. Existing launch configurations in older accounts continue to function.

## Properties

<ResponseField name="associate_public_ip_address" type="bool">
  For Auto Scaling groups that are running in a virtual private cloud (VPC), specifies whether to assign a public IP address to the group's instances. Optional.
</ResponseField>

<ResponseField name="block_device_mappings" type="list(object)">
  Specifies how block devices are exposed to the instance. You can specify virtual devices and EBS volumes. Optional.
  <Expandable title="properties">
    <ResponseField name="device_name" type="string">
      The device name (e.g., /dev/xvda, /dev/sdb) exposed to the EC2 instance for this block device mapping in the launch configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="ebs" type="object">
      The EBS-specific settings (e.g., volume size, type, IOPS, snapshot, encryption, delete-on-termination) for the volume attached via this block device mapping in the Auto Scaling launch configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="delete_on_termination" type="bool">
          Controls whether the EBS volume defined in this block device mapping is automatically deleted when the EC2 instance terminates. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="encrypted" type="bool">
          Whether the EBS volume in this block device mapping is encrypted, using the default AWS KMS key or the one specified by kms_key_id. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="iops" type="number">
          The number of I/O operations per second (IOPS) to provision for the EBS volume, which is required when the volume type is `io1` (provisioned IOPS SSD) in the launch configuration's block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="snapshot_id" type="string">
          The ID of the snapshot to use as the source for the EBS volume in this block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="throughput" type="number">
          The throughput (in MiB/s) to provision for the EBS volume, which is applicable only when the volume type is gp3. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="volume_size" type="number">
          The size of the Amazon EBS volume, in GiB, for the block device mapping in the Auto Scaling launch configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="volume_type" type="string">
          Specifies the Amazon EBS volume type (e.g., gp2, gp3, io1, st1, sc1, standard) for the block device mapped in the launch configuration, affecting performance and cost. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="no_device" type="bool">
      When set to true, suppresses the block device mapping for the specified device name, so the launch configuration does not attach that device to instances launched from it. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="virtual_name" type="string">
      Specifies the virtual device name (such as ephemeral0 or ephemeral1) for an ephemeral (instance store) block device in the launch configuration's block device mapping. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="classic_link_vpcid" type="string">
  The ID of a ClassicLink-enabled VPC to link your EC2-Classic instances to. Optional.
</ResponseField>

<ResponseField name="classic_link_vpcsecurity_groups" type="list(string)">
  The IDs of one or more security groups for the VPC that you specified in the ClassicLinkVPCId property. Optional.
</ResponseField>

<ResponseField name="ebs_optimized" type="bool">
  Specifies whether the launch configuration is optimized for EBS I/O (true) or not (false). Optional.
</ResponseField>

<ResponseField name="iam_instance_profile" type="string">
  Provides the name or the Amazon Resource Name (ARN) of the instance profile associated with the IAM role for the instance. The instance profile contains the IAM role. Optional.
</ResponseField>

<ResponseField name="image_id" type="string" required>
  Provides the unique ID of the Amazon Machine Image (AMI) that was assigned during registration. Required.
</ResponseField>

<ResponseField name="instance_id" type="string">
  The ID of the Amazon EC2 instance you want to use to create the launch configuration. Optional.
</ResponseField>

<ResponseField name="instance_monitoring" type="bool">
  Controls whether instances in this group are launched with detailed (true) or basic (false) monitoring. Optional.
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  Specifies the instance type of the EC2 instance. Required.
</ResponseField>

<ResponseField name="kernel_id" type="string">
  Provides the ID of the kernel associated with the EC2 AMI. Optional.
</ResponseField>

<ResponseField name="key_name" type="string">
  Provides the name of the EC2 key pair. Optional.
</ResponseField>

<ResponseField name="launch_configuration_name" type="string">
  The name of the launch configuration. This name must be unique per Region per account. Optional.
</ResponseField>

<ResponseField name="metadata_options" type="object">
  MetadataOptions is a property of AWS::AutoScaling::LaunchConfiguration that describes metadata options for the instances. Optional.
  <Expandable title="properties">
    <ResponseField name="http_endpoint" type="string">
      This parameter enables or disables the HTTP metadata endpoint on your instances. Optional.
    </ResponseField>
    <ResponseField name="http_put_response_hop_limit" type="number">
      The desired HTTP PUT response hop limit for instance metadata requests. Optional.
    </ResponseField>
    <ResponseField name="http_tokens" type="string">
      The state of token usage for your instance metadata requests. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="placement_tenancy" type="string">
  The tenancy of the instance, either default or dedicated. Optional.
</ResponseField>

<ResponseField name="ram_disk_id" type="string">
  The ID of the RAM disk to select. Optional.
</ResponseField>

<ResponseField name="security_groups" type="list(any)">
  A list that contains the security groups to assign to the instances in the Auto Scaling group. Optional.
</ResponseField>

<ResponseField name="spot_price" type="string">
  The maximum hourly price you are willing to pay for any Spot Instances launched to fulfill the request. Optional.
</ResponseField>

<ResponseField name="user_data" type="string">
  The Base64-encoded user data to make available to the launched EC2 instances. Optional.
</ResponseField>

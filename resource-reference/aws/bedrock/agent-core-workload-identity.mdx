`aws_bedrock_agent_core_workload_identity` ties a real AgentCore agent's own identity to an enterprise identity provider, Cognito, Okta, Entra ID, or Auth0, so the agent authenticates to external services as a real, governed identity rather than a shared, static credential, regardless of whether it runs on ECS, EKS, Lambda, or on-premises.

## Input properties

<ResponseField name="allowed_resource_oauth2_return_urls" type="list(string)">
  The list of allowed OAuth2 return URLs for resources associated with this workload identity. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the workload identity. The name must be unique within your account. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

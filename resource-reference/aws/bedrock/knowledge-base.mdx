---
title: "aws_bedrock_knowledge_base"
description: "`aws_bedrock_knowledge_base` is Amazon Bedrock's managed Retrieval Augmented Generation capability..."
---

`aws_bedrock_knowledge_base` is Amazon Bedrock's managed Retrieval Augmented Generation capability, converting ingested documents into vector embeddings in a real vector store (OpenSearch Serverless by default, or Aurora, Neptune Analytics, MongoDB, Pinecone, and others), so an `aws_bedrock_agent` or a direct query can retrieve relevant context to ground a model's response in real data rather than its training alone.

`aws_bedrock_knowledge_base_policy` attaches a real resource-based access policy to an `aws_bedrock_knowledge_base`, controlling which principals, including from other accounts, can query or manage it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	bedrock "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/bedrock"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own knowledge base policy"})

    		ubx.Resource(bedrock.KnowledgeBasePolicy, "ci-runner", bedrock.KnowledgeBasePolicyConfig{
    			KnowledgeBaseId: "example",
    			PolicyDocument:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="knowledge_base_id" type="string" required>
  The unique identifier of the knowledge base Required.
</ResponseField>

<ResponseField name="policy_document" type="any" required>
  The IAM policy document defining access permissions for the knowledge base Required.
</ResponseField>

## Output properties

<ResponseField name="revision_id" type="string">
  The revision identifier for the policy, used for optimistic concurrency control Computed by AWS after `ship`.
</ResponseField>

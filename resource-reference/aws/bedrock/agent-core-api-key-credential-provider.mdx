`aws_bedrock_agent_core_api_key_credential_provider` registers a real, stored API key that an AgentCore agent can retrieve at runtime to authenticate to an external tool or service, a simpler counterpart to `aws_bedrock_agent_core_oauth2_credential_provider`'s own OAuth-based flow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	bedrockagentcore "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/bedrockagentcore"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent core api key credential provider"})

    		ubx.Resource(bedrockagentcore.ApiKeyCredentialProvider, "example", bedrockagentcore.ApiKeyCredentialProviderConfig{
    			Name:               "example",
    			ApiKey:             "example",
    			ApiKeySecretConfig: map[string]any{"json_key": "example"},
    			ApiKeySecretSource: "example",
    			Tags:               []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="api_key" type="string">
  The API key to use for authentication Optional.
</ResponseField>

<ResponseField name="api_key_secret_config" type="object">
  A reference to a customer-provided secret stored in AWS Secrets Manager Optional.
  <Expandable title="properties">
    <ResponseField name="json_key" type="string" required>
      The JSON key within the secret that contains the credential value Required.
    </ResponseField>
    <ResponseField name="secret_id" type="string" required>
      The ID or ARN of the secret in AWS Secrets Manager Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api_key_secret_source" type="string">
  The source of the API key secret. Use MANAGED for service-managed secrets or EXTERNAL for customer-provided secrets. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the API key credential provider Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to assign to the API key credential provider Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

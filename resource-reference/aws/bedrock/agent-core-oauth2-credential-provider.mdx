---
title: "aws_bedrock_agent_core_oauth2_credential_provider"
description: "`aws_bedrock_agent_core_oauth2_credential_provider` configures AgentCore Identity to obtain and store OAuth 2.0 tokens..."
---

`aws_bedrock_agent_core_oauth2_credential_provider` configures AgentCore Identity to obtain and store OAuth 2.0 tokens, user-delegated or machine-to-machine, from an external authorization server, with a unique callback URL per provider to bind a session and prevent cross-provider replay, real credential management an agent doesn't otherwise have to build itself.

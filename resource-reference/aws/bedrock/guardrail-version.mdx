`aws_bedrock_guardrail_version` publishes a real, immutable version of an `aws_bedrock_guardrail`'s current configuration, letting an application pin to a specific, unchanging set of content filters and denied topics rather than the guardrail's editable draft.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	bedrock "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/bedrock"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own guardrail version"})

    		ubx.Resource(bedrock.GuardrailVersion, "ci-runner", bedrock.GuardrailVersionConfig{
    			GuardrailIdentifier: "example",
    			Description:         "Managed by ubx.",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="description" type="string">
  Description of the Guardrail version Optional.
</ResponseField>

<ResponseField name="guardrail_identifier" type="string" required>
  Identifier (GuardrailId or GuardrailArn) for the guardrail Required.
</ResponseField>

## Output properties

<ResponseField name="guardrail_arn" type="string">
  Arn representation for the guardrail Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="guardrail_id" type="string">
  Unique id for the guardrail Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version" type="string">
  Guardrail version Computed by AWS after `ship`.
</ResponseField>

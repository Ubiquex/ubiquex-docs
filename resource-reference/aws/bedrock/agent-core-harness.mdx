`aws_bedrock_agent_core_harness` defines an agent with a single CreateHarness call and runs it with a single InvokeHarness call, AgentCore's fastest path from an agent definition to a running one, without separately wiring runtime, gateway, and memory resources by hand.

## Example

    	ubx.Main(ubx.Stack("example", func() {

`aws_bedrock_application_inference_profile` defines a foundation model and the Region or Regions its invocation requests can route to, giving Amazon Bedrock a real, trackable identity to attach CloudWatch usage metrics and cost allocation to, separate from tracking usage against the underlying model ID directly.

## Example

    ```go
    package main

    import (
    	bedrock "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/bedrock"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(bedrock.ApplicationInferenceProfile, "example", bedrock.ApplicationInferenceProfileConfig{
    			InferenceProfileName: "example-inference-profile-name",
    			Description:          "Managed by ubx.",
    			ModelSource:          map[string]any{"copy_from": "example"},
    			Tags:                 []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  Description of the inference profile Optional.
</ResponseField>

<ResponseField name="inference_profile_name" type="string" required>
  The name of the inference profile, which must be unique within the AWS account and Region, used to identify the profile when submitting inference requests. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="model_source" type="object">
  Various ways to encode a list of models in a CreateInferenceProfile request Optional.
  <Expandable title="properties">
    <ResponseField name="copy_from" type="string">
      The Amazon Resource Name (ARN) of an existing Bedrock inference profile to copy from; when this is set, the new application inference profile inherits the model configuration of that source profile instead of specifying a model ARN directly. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  List of Tags Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the Bedrock application inference profile, used for organizing, identifying, and managing the resource within AWS. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag key attached to the Bedrock Application Inference Profile, used to store arbitrary metadata for resource identification, filtering, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

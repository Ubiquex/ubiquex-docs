`aws_bedrock_agent_core_evaluator` scores an `aws_bedrock_agent_core_harness`'s real execution traces, built-in LLM-as-a-judge evaluators for helpfulness, faithfulness, and safety, or a caller's own custom evaluator, quantifying agent quality rather than relying on spot-checking transcripts by hand.

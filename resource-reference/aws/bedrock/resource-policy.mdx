`aws_bedrock_resource_policy` attaches a real resource-based access policy to a Bedrock resource, controlling which principals, including from other accounts, can invoke or manage it, the general-purpose counterpart to resource-specific policies like `aws_bedrock_knowledge_base_policy`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	bedrock "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/bedrock"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own resource policy"})

    		ubx.Resource(bedrock.ResourcePolicy, "ci-runner", bedrock.ResourcePolicyConfig{
    			PolicyDocument: "example",
    			ResourceArn:    "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```
  </Tab>

        ))

## Properties

<ResponseField name="policy_document" type="any" required>
  The IAM policy document defining access permissions for the guardrail and guardrail profile resources Required.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The ARN of the Bedrock Guardrail or Guardrail Profile resource Required.
</ResponseField>

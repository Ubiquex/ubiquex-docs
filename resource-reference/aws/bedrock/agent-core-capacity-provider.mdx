`aws_bedrock_agent_core_capacity_provider` defines the EC2 infrastructure, operating system, instance types, VPC and subnets, storage, IAM roles, that AgentCore Runtime instances provision on, patch, and scale automatically, an alternative to the microVM-based runtime for agents that need persistent, dedicated compute.

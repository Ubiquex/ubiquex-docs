`aws_bedrock_agent_core_gateway_rate_limit` caps how much traffic, requests per second or minute, tokens per minute for inference, or concurrent connections, an individual user can consume through an `aws_bedrock_agent_core_gateway`, fine-grained, per-caller control rather than one limit applied to the gateway as a whole.

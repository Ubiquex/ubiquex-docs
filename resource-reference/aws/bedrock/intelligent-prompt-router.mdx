`aws_bedrock_intelligent_prompt_router` predicts, per request, which model in a family is likely to give an acceptable response at the lowest cost, and routes the request there automatically, sending easier prompts to a cheaper model and harder ones to a more capable one without the caller choosing per call.

## Input properties

<ResponseField name="description" type="string">
  Description of the Prompt Router. Optional.
</ResponseField>

<ResponseField name="fallback_model" type="object" required>
  Model configuration Required.
  <Expandable title="properties">
    <ResponseField name="model_arn" type="string" required>
      Arn of underlying model which are added in the Prompt Router. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="models" type="list(object)" required>
  List of model configuration Required.
  <Expandable title="properties">
    <ResponseField name="model_arn" type="string">
      The ARN of a Bedrock foundation model that the intelligent prompt router can select among, defining a candidate model in the router's `models` list for routing prompts. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="prompt_router_name" type="string" required>
  Name of the Prompt Router. Required.
</ResponseField>

<ResponseField name="routing_criteria" type="object" required>
  Represents the criteria used for routing requests. Required.
  <Expandable title="properties">
    <ResponseField name="response_quality_difference" type="number" required>
      The minimum difference in predicted response quality between the larger and smaller models that the intelligent prompt router uses as a threshold to decide whether to route the prompt to the larger model. Required. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  List of Tags Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

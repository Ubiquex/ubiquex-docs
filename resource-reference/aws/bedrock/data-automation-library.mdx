`aws_bedrock_data_automation_library` stores domain-specific entities and, currently, custom vocabulary that improve Bedrock Data Automation's extraction accuracy for audio and video content once associated with an `aws_bedrock_data_automation_project`, applied automatically to every job that project runs without per-job configuration.

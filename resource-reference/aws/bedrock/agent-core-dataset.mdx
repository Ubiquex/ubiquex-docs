`aws_bedrock_agent_core_dataset` is a fixed set of test scenarios AgentCore runs an agent against in one call, invoking it, waiting for telemetry, and scoring the results with an `aws_bedrock_agent_core_evaluator`, real regression testing for agent behavior instead of manually invoking and checking each scenario.

## Input properties

<ResponseField name="dataset_name" type="string" required>
  Human-readable name for the dataset. Unique within the account (case-insensitive). Immutable after creation. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the dataset. Optional.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  Optional AWS KMS key ARN for SSE-KMS on service S3 writes. Optional.
</ResponseField>

<ResponseField name="schema_type" type="string" required>
  Versioned schema type governing the structure of examples. Immutable after creation. Required.
</ResponseField>

<ResponseField name="source" type="object">
  Source of initial examples. Provide either inline examples or an S3 URI pointing to a JSONL file. Optional.

    </ResponseField>

`aws_bedrock_agent` orchestrates a foundation model, instructions, action groups (API operations or Lambda functions the agent can invoke), and knowledge bases into an agent that interprets user input, decides what to call, and iterates until it can return a final response. Amazon Bedrock Agents (now Bedrock Agents Classic) is no longer open to new customers; Amazon Bedrock AgentCore is its successor for new work.

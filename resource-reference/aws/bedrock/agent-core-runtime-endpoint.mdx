`aws_bedrock_agent_core_runtime_endpoint` is a stable, versioned entry point for invoking an `aws_bedrock_agent_core_runtime`, letting a caller manage and route to different runtime configurations by ARN rather than a single, unversioned invocation target.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	bedrock "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/bedrock"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent core runtime endpoint"})

    		ubx.Resource(bedrock.AgentCoreRuntimeEndpoint, "example", bedrock.AgentCoreRuntimeEndpointConfig{
    			AgentRuntimeId:      "example",
    			Name:                "example",
    			AgentRuntimeVersion: "example",
    			Description:         "Managed by ubx.",
    			Tags:                "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="agent_runtime_id" type="string" required>
  The ID of the parent Agent Runtime Required.
</ResponseField>

<ResponseField name="agent_runtime_version" type="string">
  The version of the Bedrock Agent runtime to use for the endpoint, which controls the runtime behavior and feature set available when invoking the agent through this core runtime endpoint. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Required.
</ResponseField>

<ResponseField name="tags" type="any">
  A map of tag keys and values Optional.

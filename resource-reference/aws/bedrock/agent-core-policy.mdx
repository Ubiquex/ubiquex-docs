`aws_bedrock_agent_core_policy` defines a real, individual Cedar policy statement within an `aws_bedrock_agent_core_policy_engine`, controlling which tool an agent may call, under which conditions, with which arguments.

## Input properties

<ResponseField name="definition" type="object" required>
  The definition structure for policies. Encapsulates different policy formats. Required.
  <Expandable title="properties">
    <ResponseField name="cedar" type="object">
      A Cedar policy statement within the AgentCore Policy system. Optional.
      <Expandable title="properties">
        <ResponseField name="statement" type="string" required>
          The Cedar policy statement that defines the authorization logic. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="policy" type="object">
      A policy statement within the AgentCore Policy system. Optional.
      <Expandable title="properties">
        <ResponseField name="statement" type="string" required>
          The policy statement. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A human-readable description of the policy's purpose and functionality. Optional.
</ResponseField>

<ResponseField name="enforcement_mode" type="string">
  Whether the policy contributes to the enforce decision returned to Gateway. LOG_ONLY policies are still evaluated but their decisions are observed only, allowing customers to validate a policy against real traffic before promoting it. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The customer-assigned immutable name for the policy. Must be unique within the policy engine. Required.
</ResponseField>

<ResponseField name="policy_engine_id" type="string" required>
  The identifier of the policy engine which contains this policy. Required.
</ResponseField>

<ResponseField name="validation_mode" type="string">
  The validation mode for the policy. Determines how Cedar analyzer validation results are handled. Optional.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">

<ResponseField name="policy_arn" type="string">

</ResponseField>

<ResponseField name="policy_id" type="string">

</ResponseField>

<ResponseField name="status" type="string">

</ResponseField>

  The timestamp when the policy was last updated. Computed by AWS after `ship`.
</ResponseField>

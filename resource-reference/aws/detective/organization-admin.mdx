`aws_detective_organization_admin` designates a real member account of an AWS Organization as the Detective delegated administrator, letting that account manage an `aws_detective_graph` across the whole organization instead of requiring the management account itself to do so.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	detective "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/detective"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own organization admin"})

    		ubx.Resource(detective.OrganizationAdmin, "example", detective.OrganizationAdminConfig{
    			AccountId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { OrganizationAdmin } from "@ubx/sdk-aws/aws/detective/organization_admin";

    export default stack("example", () => {
      intent({ summary: "example own organization admin" });

      resource(OrganizationAdmin, "example", {
        accountId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.detective import OrganizationAdmin, OrganizationAdminConfig

    def describe():
        ubx.intent("example own organization admin")

        ubx.resource(OrganizationAdmin, "example", OrganizationAdminConfig(
            account_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Input properties

<ResponseField name="account_id" type="string" required>
  The account ID of the account that should be registered as your Organization's delegated administrator for Detective Required.
</ResponseField>

## Output properties

<ResponseField name="graph_arn" type="string">
  The Detective graph ARN Computed by AWS after `ship`.
</ResponseField>

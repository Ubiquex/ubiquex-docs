`aws_detective_member_invitation` invites a real member account to join an `aws_detective_graph`, the resource that actually sends the invitation an account must accept before its own findings and telemetry are included in the graph's behavior analysis.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	detective "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/detective"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own member invitation"})

    		ubx.Resource(detective.MemberInvitation, "example", detective.MemberInvitationConfig{
    			GraphArn:                 "arn:aws:iam::123456789012:policy/example",
    			MemberEmailAddress:       "example",
    			MemberId:                 "example",
    			DisableEmailNotification: true,
    			Message:                  "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="disable_email_notification" type="bool">
  When set to true, invitation emails are not sent to the member accounts. Member accounts must still accept the invitation before they are added to the behavior graph. Updating this field has no effect. Optional.
</ResponseField>

<ResponseField name="graph_arn" type="string" required>
  The ARN of the graph to which the member account will be invited Required.
</ResponseField>

<ResponseField name="member_email_address" type="string" required>
  The root email address for the account to be invited, for validation. Updating this field has no effect. Required.
</ResponseField>

<ResponseField name="member_id" type="string" required>
  The AWS account ID to be invited to join the graph as a member Required.
</ResponseField>

<ResponseField name="message" type="string">
  A message to be included in the email invitation sent to the invited account. Updating this field has no effect. Optional.
</ResponseField>

`aws_detective_graph` is Amazon Detective's real behavior graph, built continuously from CloudTrail, VPC Flow Logs, GuardDuty, and Security Hub findings across one or more linked accounts, correlating entities and their relationships over time so a security investigation can trace what happened rather than searching raw logs by hand.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	detective "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/detective"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own graph"})

    		ubx.Resource(detective.Graph, "example", detective.GraphConfig{
    			AutoEnableMembers: true,
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="auto_enable_members" type="bool">
  Indicates whether to automatically enable new organization accounts as member accounts in the organization behavior graph. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The list of tags to attach to the Detective graph, where each tag consists of a key and a value to help organize, identify, and manage the resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Detective graph, used to organize, identify, and manage access to the graph through resource-level permissions and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Detective graph, used to categorize, manage, and control access to the graph alongside other AWS resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

  The Detective graph ARN Computed by AWS after `ship`.

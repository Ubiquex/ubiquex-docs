`aws_arcregion_switch_plan` defines a Region switch plan in Amazon Application Recovery Controller, the workflows, steps, and execution blocks that orchestrate moving a multi-Region application's traffic and data from one AWS Region to another in a coordinated, observable, automated way rather than as a manual runbook.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

`aws_doc_dbelastic_cluster` creates a real, hash-sharded DocumentDB deployment that scales to millions of reads and writes per second and petabytes of storage without the caller choosing, managing, or upgrading individual instances the way an `aws_doc_db_dbcluster` requires.

    ```go
    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(docdbelastic.Cluster, "example", docdbelastic.ClusterConfig{

    			AuthType:              "example",

    			ShardCapacity:         1,
    			ShardCount:            1,

    }
    ```

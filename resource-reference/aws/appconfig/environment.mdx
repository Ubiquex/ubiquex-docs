`aws_app_config_environment` is a logical deployment target inside an `aws_app_config_application`, Beta or Production for the whole app, or Web, Mobile, and Backend for its subcomponents, with its own CloudWatch alarms that AppConfig monitors during a deployment and rolls back on if one trips.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appconfig "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appconfig"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own config environment"})

    		ubx.Resource(appconfig.Environment, "example", appconfig.EnvironmentConfig{
    			ApplicationId:           "example",
    			Name:                    "example",
    			DeletionProtectionCheck: "example",
    			Description:             "Managed by ubx.",
    			Monitors:                []map[string]any{{"alarm_arn": "example"}},
    			Tags:                    []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The application ID. Required.
</ResponseField>

<ResponseField name="deletion_protection_check" type="string">
  On resource deletion this controls whether the Deletion Protection check should be applied, bypassed, or (the default) whether the behavior should be controlled by the account-level Deletion Protection setting. See https://docs.aws.amazon.com/appconfig/latest/userguide/deletion-protection.html Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the environment. Optional.
</ResponseField>

<ResponseField name="monitors" type="list(object)">
  Amazon CloudWatch alarms to monitor during the deployment process. Optional.
  <Expandable title="properties">
    <ResponseField name="alarm_arn" type="string">
      The ARN of the Amazon CloudWatch alarm that AppConfig monitors for this environment to detect potential issues during configuration deployments. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="alarm_role_arn" type="string">
      The ARN of the IAM role that AWS AppConfig assumes to evaluate the CloudWatch alarm for this monitor during a deployment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the environment. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Metadata to assign to the environment. Tags help organize and categorize your AWS AppConfig resources. Each tag consists of a key and an optional value, both of which you define. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag applied to the AWS AppConfig environment, used for resource organization and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag (key-value pair) attached to the AWS AppConfig environment, used for managing and identifying the resource (e.g., cost allocation or categorization). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="environment_id" type="string">
  The environment ID. Computed by AWS after `ship`.
</ResponseField>

`aws_app_config_hosted_configuration_version` publishes a real, immutable version of configuration content, stored directly in AppConfig rather than an external source, under an `aws_app_config_configuration_profile`, the version an `aws_app_config_deployment` actually rolls out.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appconfig "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appconfig"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hosted configuration version"})

    		ubx.Resource(appconfig.HostedConfigurationVersion, "example", appconfig.HostedConfigurationVersionConfig{
    			ApplicationId:          "example",
    			ConfigurationProfileId: "example",
    			Content:                "example",
    			ContentType:            "example",
    			Description:            "Managed by ubx.",
    			LatestVersionNumber:    1,
    			VersionLabel:           "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_id" type="string" required>
  The application ID. Required.
</ResponseField>

<ResponseField name="configuration_profile_id" type="string" required>
  The configuration profile ID. Required.
</ResponseField>

<ResponseField name="content" type="string" required>
  The content of the configuration or the configuration data. Required.
</ResponseField>

<ResponseField name="content_type" type="string" required>
  A standard MIME type describing the format of the configuration content. Required.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the hosted configuration version. Optional.
</ResponseField>

<ResponseField name="latest_version_number" type="number">
  An optional locking token used to prevent race conditions from overwriting configuration updates when creating a new version. To ensure your data is not overwritten when creating multiple hosted configuration versions in rapid succession, specify the version number of the latest hosted configuration version. Optional.
</ResponseField>

<ResponseField name="version_label" type="string">
  A user-defined label for an AWS AppConfig hosted configuration version. Optional.
</ResponseField>

## Output properties

<ResponseField name="version_number" type="string">
  Current version number of hosted configuration version. Computed by AWS after `ship`.
</ResponseField>

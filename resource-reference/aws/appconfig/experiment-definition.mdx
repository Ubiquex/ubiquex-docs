`aws_app_config_experiment_definition` runs a real A/B test or gradual rollout on production traffic, built directly on top of AppConfig's own feature-flag configuration profiles rather than a separate experimentation stack, splitting traffic between variants and tracking operational metrics through CloudWatch as exposure increases.

    ```go
    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			AudienceRule:                   "example",
    			ConfigurationProfileIdentifier: "example",
    			EnvironmentIdentifier:          "example",
    			FlagKey:                        "example",
    			Name:                           "example",
    			AudienceDescription:            "example",
    			Hypothesis:                     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="application_identifier" type="string" required>
  The application ID, name, or ARN. Required.
</ResponseField>

<ResponseField name="audience_description" type="string">
  Human-readable description of the audience. Optional.
</ResponseField>

<ResponseField name="audience_rule" type="string" required>
  Rule expression defining the experiment audience. Required.
</ResponseField>

<ResponseField name="configuration_profile_identifier" type="string" required>
  The configuration profile ID, name, or ARN. Required.
</ResponseField>

<ResponseField name="environment_identifier" type="string" required>
  The environment ID, name, or ARN. Required.
</ResponseField>

<ResponseField name="flag_key" type="string" required>
  The key of the existing flag in the configuration profile to experiment on. Required.
</ResponseField>

<ResponseField name="hypothesis" type="string">
  The hypothesis of the experiment. Optional.
</ResponseField>

<ResponseField name="launch_criteria" type="string">
  Criteria for launching the experiment. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the experiment definition. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Tags to associate with the experiment definition. Optional.

      Optional; if omitted, computed by AWS.

    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.

  </Expandable>
</ResponseField>

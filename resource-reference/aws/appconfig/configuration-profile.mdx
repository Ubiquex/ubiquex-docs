`aws_app_config_configuration_profile` defines how AppConfig locates and manages one piece of configuration data, either a feature-flag profile or a free-form configuration sourced from S3, SSM Parameter Store, Secrets Manager, or AppConfig's own hosted store, with optional validators that block a bad deployment before it ships.

## Input properties

<ResponseField name="application_id" type="string" required>
  The application ID. Required.
</ResponseField>

<ResponseField name="deletion_protection_check" type="string">
  On resource deletion this controls whether the Deletion Protection check should be applied, bypassed, or (the default) whether the behavior should be controlled by the account-level Deletion Protection setting. See https://docs.aws.amazon.com/appconfig/latest/userguide/deletion-protection.html Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the configuration profile. Optional.
</ResponseField>

<ResponseField name="kms_key_identifier" type="string">
  The AWS Key Management Service key identifier (key ID, key alias, or key ARN) provided when the resource was created or updated. Optional.
</ResponseField>

<ResponseField name="location_uri" type="string" required>
  A URI to locate the configuration. You can specify the AWS AppConfig hosted configuration store, Systems Manager (SSM) document, an SSM Parameter Store parameter, or an Amazon S3 object. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  A name for the configuration profile. Required.
</ResponseField>

<ResponseField name="retrieval_role_arn" type="string">
  The ARN of an IAM role with permission to access the configuration at the specified LocationUri. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Metadata to assign to the configuration profile. Tags help organize and categorize your AWS AppConfig resources. Each tag consists of a key and an optional value, both of which you define. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag to attach to the AppConfig configuration profile, used for categorizing or identifying the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key-value pair applied to the AppConfig configuration profile, used for resource categorization and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of configurations contained in the profile. When calling this API, enter one of the following values for Type: AWS.AppConfig.FeatureFlags, AWS.Freeform Optional.
</ResponseField>

<ResponseField name="validators" type="list(object)">
  A list of methods for validating the configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="content" type="string">
      The content of the validator, which is a JSON schema when the validator type is JSON_SCHEMA or the Amazon Resource Name (ARN) of an AWS Lambda function when the validator type is LAMBDA. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of the validator, which determines whether it validates the configuration using a JSON schema (JSON_SCHEMA) or a custom AWS Lambda function (LAMBDA). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="configuration_profile_id" type="string">
  The configuration profile ID Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="kms_key_arn" type="string">
  The Amazon Resource Name of the AWS Key Management Service key to encrypt new configuration data versions in the AWS AppConfig hosted configuration store. This attribute is only used for hosted configuration types. To encrypt data managed in other configuration stores, see the documentation for how to specify an AWS KMS key for that particular service. Computed by AWS after `ship`.
</ResponseField>

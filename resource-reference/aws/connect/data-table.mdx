`aws_connect_data_table` is a real, no-code, JSON-like data structure an administrator manages directly, then reads from or writes to inside an `aws_connect_contact_flow` via the Data Table flow block, dynamic configuration, agent extension routing, seasonal messaging, that changes contact center behavior without a code deployment.

  The name of the Data Table Required.

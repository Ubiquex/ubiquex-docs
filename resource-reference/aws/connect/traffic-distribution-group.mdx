`aws_connect_traffic_distribution_group` links `aws_connect_instance`s in different AWS Regions and distributes real inbound traffic to phone numbers attached to the group between them, the mechanism behind multi-Region resiliency and disaster recovery for a contact center.

## Example

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/connect"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(connect.TrafficDistributionGroup, "example", connect.TrafficDistributionGroupConfig{
    			InstanceArn: "arn:aws:iam::123456789012:policy/example",
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="description" type="string">
  A description for the traffic distribution group. Optional.
</ResponseField>

<ResponseField name="instance_arn" type="string" required>
  The identifier of the Amazon Connect instance that has been replicated. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name for the traffic distribution group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.

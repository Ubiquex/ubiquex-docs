`aws_connect_prompt` registers a real, uploaded audio file as a named prompt an `aws_connect_contact_flow` can play back, IVR greetings, hold messages, configurable and reusable rather than referencing a raw audio file inline.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/connect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own prompt"})

    		ubx.Resource(connect.Prompt, "example", connect.PromptConfig{
    			InstanceArn: "arn:aws:iam::123456789012:policy/example",
    			Name:        "example",
    			Description: "Managed by ubx.",
    			S3Uri:       "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  The description of the prompt. Optional.
</ResponseField>

<ResponseField name="instance_arn" type="string" required>
  The identifier of the Amazon Connect instance. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the prompt. Required.
</ResponseField>

<ResponseField name="s3_uri" type="string">
  S3 URI of the customer's audio file for creating prompts resource.. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the AWS Connect prompt, used for identifying and categorizing the prompt resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="prompt_arn" type="string">
  The Amazon Resource Name (ARN) for the prompt. Computed by AWS after `ship`.
</ResponseField>

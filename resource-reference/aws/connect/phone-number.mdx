`aws_connect_phone_number` claims a real phone number, direct-dial or toll-free, and assigns it to an `aws_connect_instance`, the number a caller actually dials to reach that contact center.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/connect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own phone number"})

    		ubx.Resource(connect.PhoneNumber, "ci-runner", connect.PhoneNumberConfig{
    			TargetArn:            "arn:aws:iam::123456789012:policy/ci",
    			CountryCode:          "example",
    			Description:          "Managed by ubx.",
    			Prefix:               "example",
    			SourcePhoneNumberArn: "arn:aws:iam::123456789012:policy/ci",
    			Tags:                 []map[string]any{{"key": "example"}},
    			Type:                 "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="country_code" type="string">
  The phone number country code. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the phone number. Optional.
</ResponseField>

<ResponseField name="prefix" type="string">
  The phone number prefix. Optional.
</ResponseField>

<ResponseField name="source_phone_number_arn" type="string">
  The source phone number arn. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="target_arn" type="string" required>
  The ARN of the target the phone number is claimed to. Required.
</ResponseField>

<ResponseField name="type" type="string">
  The phone number type Optional.
</ResponseField>

## Output properties

<ResponseField name="address" type="string">
  The phone number e164 address. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="phone_number_arn" type="string">
  The phone number ARN Computed by AWS after `ship`.
</ResponseField>

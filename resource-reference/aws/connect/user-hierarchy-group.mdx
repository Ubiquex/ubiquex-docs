`aws_connect_user_hierarchy_group` organizes `aws_connect_user`s into a real, nested reporting structure, teams, regions, business units, used for filtered reporting and access scoping beyond what an `aws_connect_security_profile` alone controls.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

<ResponseField name="instance_arn" type="string" required>
  The identifier of the Amazon Connect instance. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the user hierarchy group. Required.
</ResponseField>

<ResponseField name="parent_group_arn" type="string">
  The Amazon Resource Name (ARN) for the User hierarchy group. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags. Optional.

`aws_connect_instance_storage_config` configures where an `aws_connect_instance` stores a specific category of real data, call recordings, chat transcripts, contact trace records, in S3, Kinesis, or Kinesis Firehose.

## Input properties

<ResponseField name="instance_arn" type="string" required>
  Connect Instance ID with which the storage config will be associated Required.
</ResponseField>

<ResponseField name="kinesis_firehose_config" type="object">

`aws_connect_metric` defines a real, custom real-time or historical metric, built with advanced filters and functions on Connect's own metric primitives, for use in dashboards and the metrics API, beyond the fixed set of metrics Connect provides out of the box.

## Example

    ```go

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own metric"})

    			Name:                   "ci-runner",
    			Description:            "Managed by ubx.",
    			MetricCalculation:      map[string]any{"calculation": "example"},
    			PositiveTrendIndicator: "example",
    			Status:                 "example",
    			Tags:                   []map[string]any{{"key": "example"}},
    			Unit:                   "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="instance_arn" type="string" required>

</ResponseField>

<ResponseField name="metric_calculation" type="object">

        <ResponseField name="alias" type="string">

        </ResponseField>
        <ResponseField name="metric_filters" type="list(object)">

          <Expandable title="properties">
            <ResponseField name="boolean_condition" type="object">

              <Expandable title="properties">
                <ResponseField name="comparison" type="string">

                </ResponseField>

            </ResponseField>
            <ResponseField name="metric_filter_key" type="string">
              Optional; if omitted, computed by AWS.
            </ResponseField>
            <ResponseField name="negate" type="bool">

            </ResponseField>
            <ResponseField name="number_condition" type="object">

              <Expandable title="properties">

                </ResponseField>
                <ResponseField name="values" type="list(number)">

                </ResponseField>
              </Expandable>

            <ResponseField name="string_condition" type="object">

            </ResponseField>
          </Expandable>
        </ResponseField>

          Optional; if omitted, computed by AWS.

      </Expandable>

`aws_connect_queue` holds real, waiting contacts until an agent, matched by an `aws_connect_routing_profile`, becomes available, the actual point contacts sit at between entering an `aws_connect_contact_flow` and being answered.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

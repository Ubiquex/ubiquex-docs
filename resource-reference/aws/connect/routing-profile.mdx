`aws_connect_routing_profile` assigns an `aws_connect_user` to one or more `aws_connect_queue`s with real priority and channel concurrency settings, the mechanism that determines which queues an agent actually receives contacts from and how many at once.

## Example

## Input properties

<ResponseField name="agent_availability_timer" type="string">
  Whether agents with this routing profile will have their routing order calculated based on longest idle time or time since their last inbound contact. Optional.
</ResponseField>

<ResponseField name="default_outbound_queue_arn" type="string" required>
  The identifier of the default outbound queue for this routing profile. Required.
</ResponseField>

<ResponseField name="description" type="string" required>
  The description of the routing profile. Required.
</ResponseField>

<ResponseField name="instance_arn" type="string" required>
  The identifier of the Amazon Connect instance. Required.
</ResponseField>

<ResponseField name="manual_assignment_queue_configs" type="list(object)">
  The manual assignment queues to associate with this routing profile. Optional.
  <Expandable title="properties">
    <ResponseField name="queue_reference" type="object">
      Specifies the queue and its contact channel (such as VOICE or CHAT) that manual assignment uses to route contacts, containing the queue ID and channel type. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="channel" type="string">
          Specifies the contact channel (VOICE, CHAT, or TASK) for the queue reference in this manual assignment queue configuration, determining which channel the queue handles for manual assignment in the routing profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="queue_arn" type="string">
          The Amazon Resource Name (ARN) of the Amazon Connect queue that is included in the routing profile's manual assignment queue configuration, allowing agents to manually assign contacts to that queue. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="media_concurrencies" type="list(object)" required>
  The channels agents can handle in the Contact Control Panel (CCP) for this routing profile. Required.
  <Expandable title="properties">
    <ResponseField name="channel" type="string">
      Specifies the contact channel type (e.g., VOICE, CHAT, or TASK) to which the media concurrency limit applies in the Amazon Connect routing profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="concurrency" type="number">
      The maximum number of concurrent contacts of the channel (e.g., VOICE, CHAT) that an agent assigned to this routing profile can handle at the same time. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="cross_channel_behavior" type="object">
      Specifies how contacts from other channels are routed when this channel's concurrency limit is reached, with a `behavior_type` value (`ROUTE_CURRENT_CHANNEL_ONLY` or `ROUTE_ANY_CHANNEL`) controlling whether only the current channel or any channel can be routed to the agent. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="behavior_type" type="string">
          Determines whether contacts from other channels are allowed to be routed to the agent while the agent is handling a contact on this media channel, with valid values ALLOW or DENY. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the routing profile. Required.
</ResponseField>

<ResponseField name="queue_configs" type="list(object)">
  The queues to associate with this routing profile. Optional.
  <Expandable title="properties">
    <ResponseField name="delay" type="number">
      Specifies the delay in seconds that a contact waits in this queue before the routing profile attempts to route the contact to a lower-priority queue (or to an available agent, if no other queues are configured). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="priority" type="number">
      The priority assigned to a specific queue in the routing profile, where lower numbers indicate higher routing priority and contact distribution order. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="queue_reference" type="object">
      Specifies the Amazon Connect queue to which this routing profile queue configuration applies, identified by its queue ID or ARN. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="channel" type="string">
          Specifies the contact channel (VOICE, CHAT, or TASK) associated with the queue in the routing profile's queue configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="queue_arn" type="string">
          The Amazon Resource Name (ARN) of the Amazon Connect queue that this routing profile configuration references, identifying the queue to which contacts are routed. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The user-defined key of a tag that can be attached to an Amazon Connect routing profile to add custom metadata for resource management and categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">

  </Expandable>
</ResponseField>

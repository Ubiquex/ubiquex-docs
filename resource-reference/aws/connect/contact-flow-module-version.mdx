`aws_connect_contact_flow_module_version` publishes a real, immutable version of an `aws_connect_contact_flow_module`'s current definition, letting an `aws_connect_contact_flow_module_alias` or a calling flow pin to a specific, unchanging version.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/connect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own contact flow module version"})

    		ubx.Resource(connect.ContactFlowModuleVersion, "example", connect.ContactFlowModuleVersionConfig{
    			ContactFlowModuleId: "example",
    			Description:         "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="contact_flow_module_id" type="string" required>
  The identifier of the contact flow module (ARN) this version is tied to. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the version. Optional.
</ResponseField>

## Output properties

<ResponseField name="contact_flow_module_version_arn" type="string">
  The identifier of the contact flow module version (ARN). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="flow_module_content_sha256" type="string">
  Indicates the checksum value of the latest published flow module content Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version" type="number">
  The version number of this revision Computed by AWS after `ship`.
</ResponseField>

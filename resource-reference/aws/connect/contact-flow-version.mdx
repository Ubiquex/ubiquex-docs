`aws_connect_contact_flow_version` publishes a real, immutable version of an `aws_connect_contact_flow`'s current definition, letting a routing profile or phone number pin to a specific, unchanging version rather than the flow's editable draft.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/connect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own contact flow version"})

    		ubx.Resource(connect.ContactFlowVersion, "ci-runner", connect.ContactFlowVersionConfig{
    			ContactFlowId: "example",
    			Description:   "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="contact_flow_id" type="string" required>
  The ARN of the contact flow this version is tied to. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the version. Optional.
</ResponseField>

## Output properties

<ResponseField name="contact_flow_version_arn" type="string">
  The identifier of the contact flow version (ARN). Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="flow_content_sha256" type="string">
  Indicates the checksum value of the latest published flow content Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="version" type="number">
  The version number of this revision Computed by AWS after `ship`.
</ResponseField>

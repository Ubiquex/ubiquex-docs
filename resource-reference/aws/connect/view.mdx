`aws_connect_view` defines a real, custom UI template, built with HTML or JSX, that an `aws_connect_contact_flow`'s Show View block displays inside the agent workspace, guiding an agent through a task with a purpose-built screen instead of a generic one.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/connect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own view"})

    		ubx.Resource(connect.View, "example", connect.ViewConfig{
    			Actions:     []string{"example"},
    			InstanceArn: "arn:aws:iam::123456789012:policy/example",
    			Name:        "example",
    			Template:    "example",
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="actions" type="list(string)" required>
  The actions of the view in an array. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the view. Optional.
</ResponseField>

<ResponseField name="instance_arn" type="string" required>
  The Amazon Resource Name (ARN) of the instance. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the view. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a single tag assigned to the Amazon Connect view resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag attached to the AWS Connect view, used to categorize or identify the view for cost allocation and access management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="template" type="any" required>
  The template of the view as JSON. Required.
</ResponseField>

## Output properties

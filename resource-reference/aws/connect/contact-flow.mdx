`aws_connect_contact_flow` defines the real logic, IVR menus, routing decisions, Lambda invocations, that determines what happens to a contact, a call, a chat, a task, from the moment it enters an `aws_connect_instance` to the moment it's resolved.

    	ubx.Main(ubx.Stack("example", func() {

## Input properties

<ResponseField name="content" type="string" required>
  The content of the contact flow in JSON format. Required.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the contact flow. Optional.
</ResponseField>

<ResponseField name="instance_arn" type="string" required>
  The identifier of the Amazon Connect instance (ARN). Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the contact flow. Required.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the contact flow. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tags. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key portion of a tag applied to an Amazon Connect contact flow, used to categorize the resource and enforce tag-based access control in IAM policies. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of an individual tag assigned to the Amazon Connect contact flow. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The type of the contact flow. Required.
</ResponseField>

## Output properties

<ResponseField name="contact_flow_arn" type="string">

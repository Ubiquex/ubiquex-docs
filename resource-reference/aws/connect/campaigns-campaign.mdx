`aws_connect_campaigns_campaign` defines a real, high-volume outbound campaign, appointment reminders, telemarketing, debt collection, run through an `aws_connect_instance`. Outbound Campaigns V1 isn't supported in every Region; `aws_connect_campaigns_v2_campaign` is the newer, multi-channel version AWS points new campaigns toward.

`aws_connect_view_version` publishes a real, immutable version of an `aws_connect_view`'s current layout, letting a contact flow pin to a specific, unchanging version of a custom agent-workspace view.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/connect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own view version"})

    		ubx.Resource(connect.ViewVersion, "example", connect.ViewVersionConfig{
    			ViewArn:            "arn:aws:iam::123456789012:policy/example",
    			VersionDescription: "example",
    			ViewContentSha256:  "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="version_description" type="string">
  The description for the view version. Optional.
</ResponseField>

<ResponseField name="view_arn" type="string" required>
  The Amazon Resource Name (ARN) of the view for which a version is being created. Required.
</ResponseField>

<ResponseField name="view_content_sha256" type="string">
  The view content hash to be checked. Optional.
</ResponseField>

## Output properties

<ResponseField name="version" type="number">
  The version of the view. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="view_version_arn" type="string">
  The Amazon Resource Name (ARN) of the created view version. Computed by AWS after `ship`.
</ResponseField>

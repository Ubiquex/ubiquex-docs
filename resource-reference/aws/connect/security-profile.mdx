`aws_connect_security_profile` defines a real set of permissions, which parts of the Connect instance and which actions, that gets attached to an `aws_connect_user`, the actual access-control mechanism behind what an agent, supervisor, or administrator can see and do.

## Input properties

<ResponseField name="allowed_access_control_hierarchy_group_id" type="string">
  The identifier of the hierarchy group that a security profile uses to restrict access to resources in Amazon Connect. Optional.
</ResponseField>

<ResponseField name="allowed_access_control_tags" type="list(object)">
  The list of tags that a security profile uses to restrict access to resources in Amazon Connect. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag entry in the allowed_access_control_tags map, which specifies a tag key that this security profile is permitted to use for access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag key that, when present on an AWS Connect resource, grants the user access to that resource according to the tag-based access control rules defined in the security profile. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="allowed_flow_modules" type="list(object)">
  The list of flow-module resources to be linked to a security profile in Amazon Connect. Optional.
  <Expandable title="properties">
    <ResponseField name="flow_module_id" type="string">
      The identifier of an Amazon Connect flow module that this security profile is permitted to use. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="applications" type="list(object)">
  A list of third-party applications that the security profile will give access to. Optional.
  <Expandable title="properties">
    <ResponseField name="application_permissions" type="list(string)">
      Specifies the list of permission keys that define the actions a user with this security profile can perform within the associated application namespace (for example, making outbound calls or managing contacts in the agent application). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="namespace" type="string">
      Specifies the namespace of an Amazon Connect application (for example, 'amazon_connect') for which the security profile grants functional permissions, effectively limiting access to that application's resources. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Defines the type of application (e.g., Amazon Connect or Contact Lens) that the security profile's permissions apply to within the Applications list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  The description of the security profile. Optional.
</ResponseField>

<ResponseField name="granular_access_control_configuration" type="object">
  Specifies the granular access control settings for the security profile, including the allowed access control tags and whether access is restricted by the agent's hierarchy group. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data_table_access_control_configuration" type="object">
      Defines the access control configuration for data tables. Optional.
      <Expandable title="properties">
        <ResponseField name="primary_attribute_access_control_configuration" type="object">
          Contains the configuration for record-based access control. Optional.
          <Expandable title="properties">
            <ResponseField name="primary_attribute_values" type="list(object)">
              An array of PrimaryAttributeValue objects. Optional.
              <Expandable title="properties">
                <ResponseField name="access_type" type="string">
                  Specifies the type of access (read, write, or both) that the security profile has to data table entries matching the associated primary attribute value in the AWS Connect granular access control configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="attribute_name" type="string">
                  The name of the primary attribute (e.g., a contact or customer attribute) whose allowed values are defined in this configuration to restrict access to a data table in Amazon Connect. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="values" type="list(string)">
                  The list of primary attribute values (such as queue IDs or other defined attributes) that determine which data records are accessible for the given data table in the security profile's granular access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

title: "aws_connect_user"

---

`aws_connect_user` creates a real, individual agent, supervisor, or administrator account inside an `aws_connect_instance`, with an attached `aws_connect_security_profile` and `aws_connect_routing_profile` determining what they can do and what contacts they receive.

## Example

<Tabs>
  <Tab title="Go">
    ```go

    import (
    	connect "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/connect"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user"})

    		ubx.Resource(connect.User, "example", connect.UserConfig{
    			InstanceArn:             "arn:aws:iam::123456789012:policy/example",
    			RoutingProfileArn:       "arn:aws:iam::123456789012:policy/example",
    			SecurityProfileArns:     []string{"example"},
    			Username:                "example",
    			AfterContactWorkConfigs: []map[string]any{{"after_contact_work_config": map[string]any{"after_contact_work_mode": "example"}}},
    			AutoAcceptConfigs:       []map[string]any{{"agent_first_callback_auto_accept": true}},
    			DirectoryUserId:         "example",
    			HierarchyGroupArn:       "arn:aws:iam::123456789012:policy/example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="after_contact_work_configs" type="list(object)">
  After Contact Work configurations of a user. Optional.
  <Expandable title="properties">
    <ResponseField name="after_contact_work_config" type="object">
      Configures a specific after-contact work task for the user, such as AGENT_CALL or AGENT_GREETING, and the duration in seconds allowed for that task. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="after_contact_work_mode" type="string">
          Sets the after contact work (ACW) mode for the user, with valid values typically DEFAULT to use the default ACW duration or CUSTOM to allow specifying a custom timeout. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="after_contact_work_time_limit" type="number">
          The maximum time in seconds an agent is allowed to spend on after-contact work (ACW) before being marked unavailable, as configured for this Amazon Connect user. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="agent_first_callback_after_contact_work_config" type="object">
      Configures the agent-first-callback feature, which determines whether an agent's first interaction after completing after-contact work is a callback from the previous contact, including whether it is enabled and the timeout period. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="after_contact_work_mode" type="string">
          Specifies the after-contact work mode for the agent first callback configuration, controlling whether the agent takes a callback before completing after-contact work (e.g., AGENT_FIRST_CALLBACK) or completes after-contact work before taking a callback (e.g., CALLBACK_FIRST). Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="after_contact_work_time_limit" type="number">
          The duration in seconds an agent has to complete after-contact work before the system offers their first callback. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="channel" type="string">
      The contact channel (e.g., VOICE, CHAT, or TASK) to which this after-contact-work configuration applies for the user. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="auto_accept_configs" type="list(object)">
  Auto-accept configurations of a user. Optional.
  <Expandable title="properties">
    <ResponseField name="agent_first_callback_auto_accept" type="bool">
      Indicates whether the agent will automatically accept the first callback in Amazon Connect. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="auto_accept" type="bool">
      When set to true, this Amazon Connect user automatically accepts incoming contacts (such as phone calls) without requiring the agent to manually accept them, as configured by the auto-accept settings. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="channel" type="string">
      The contact channel (e.g., VOICE or CHAT) for which this auto-accept configuration applies, enabling automatic acceptance of incoming contacts on that channel. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

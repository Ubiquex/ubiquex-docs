`aws_kinesis_analytics_v2_application_output` adds a real external destination, a Kinesis data stream, a Firehose delivery stream, or a Lambda function, that an `aws_kinesis_analytics_v2_application` writes its processed results to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kinesisanalyticsv2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/kinesisanalyticsv2"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own application output"})

    		ubx.Resource(kinesisanalyticsv2.ApplicationOutput, "example", kinesisanalyticsv2.ApplicationOutputConfig{
    			ApplicationName: "example-application-name",
    			Output:          map[string]any{"destination_schema": map[string]any{"record_format_type": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

        ubx.intent("example own application output")

## Input properties

<ResponseField name="application_name" type="string" required>
  The name of the Kinesis Data Analytics application to which this output is attached. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="output" type="object" required>
  Specifies the output destination (Kinesis data stream, Kinesis Data Firehose delivery stream, or AWS Lambda function) and the destination schema for the application's SQL results. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="destination_schema" type="object" required>

      <Expandable title="properties">
        <ResponseField name="record_format_type" type="string">

    <ResponseField name="kinesis_firehose_output" type="object">

`aws_guard_duty_threat_entity_set` is GuardDuty's newer, broader entity list, IP addresses, domain names, and SHA-256 file hashes together rather than IP addresses alone, that an `aws_guard_duty_detector` generates findings against, GuardDuty's recommended replacement for the IP-only `aws_guard_duty_threat_intel_set`. Introduced September 2025.

## Input properties

<ResponseField name="activate" type="bool">
  Specifies whether to activate the threat intel set after it is created, so that GuardDuty begins using it to generate findings. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="detector_id" type="string">
  The ID of the GuardDuty detector to which this threat entity set belongs, used to associate the set with a specific detector. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The AWS account ID of the owner of the S3 bucket that stores the threat entity set file, used by GuardDuty to verify bucket ownership and prevent accessing objects from an unintended bucket. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="format" type="string" required>
  Specifies the format of the uploaded threat intelligence set file, which for AWS GuardDuty must be one of TXT, STIX, OTX_CSV, or ALIEN_VAULT. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="location" type="string" required>
  The S3 URI (for example, s3://bucket/prefix/object) of the file that contains the threat intelligence set, which GuardDuty retrieves and imports as the indicators for this set. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  A user-friendly name for the GuardDuty threat intel set, used to identify it in the GuardDuty console; if omitted, GuardDuty automatically generates a name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the tags (key-value pairs) to attach to the GuardDuty threat intel set, which can be used for identifying and organizing the resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  The date and time when the GuardDuty threat entity set was created, provided as a computed read-only attribute. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="error_details" type="string">
  If the threat intelligence set is in an error state, this attribute provides the detailed error message describing why the set could not be created, activated, or updated. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">

</ResponseField>

<ResponseField name="updated_at" type="string">
  The timestamp of the most recent update to the GuardDuty threat intelligence set, returned by AWS after the set is created or modified. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

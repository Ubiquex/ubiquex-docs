`aws_guard_duty_ipset` is a real, trusted list of IP addresses an `aws_guard_duty_detector` never generates findings against, for a caller's own known-safe scanners or internal tools that would otherwise look like malicious activity.

## Input properties

<ResponseField name="activate" type="bool">
  Indicates whether the GuardDuty IP set is activated (enabled) for use in threat detection, where true activates the set and false deactivates it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="detector_id" type="string">
  The detector_id specifies the unique ID of the Amazon GuardDuty detector to which this IPSet is associated, identifying the GuardDuty account and region context for the IP set. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  The AWS account ID of the owner of the S3 bucket where the GuardDuty IPSet file is stored, used to validate that the bucket is owned by the expected account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="format" type="string" required>
  Specifies the format of the file that contains the IP set, such as TXT, STIX, OTX_CSV, ALIEN_VAULT, or PROOF_POINT. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="location" type="string" required>
  The URI (typically an S3 object URL) of the file that contains the IP addresses used by this GuardDuty IPSet. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  The friendly name of the GuardDuty IP set, used to identify it in the GuardDuty console and API. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to apply to the GuardDuty IPSet, which can be used for organizing, identifying, and controlling access to the resource via IAM policies. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">

    <ResponseField name="value" type="string">

    </ResponseField>
  </Expandable>
</ResponseField>

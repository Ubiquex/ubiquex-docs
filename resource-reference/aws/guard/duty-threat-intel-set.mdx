`aws_guard_duty_threat_intel_set` is a real, custom list of known-malicious IP addresses that an `aws_guard_duty_detector` generates findings against, extending GuardDuty's own built-in threat intelligence with a caller's own data.

## Input properties

<ResponseField name="activate" type="bool">
  Whether the threat intel set is activated (enabled) for use by GuardDuty, as opposed to being created but inactive. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="detector_id" type="string">
  The ID of the GuardDuty detector to which this threat intel set belongs, or the default detector if not specified. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="expected_bucket_owner" type="string">
  Specifies the AWS account ID expected to own the S3 bucket that holds the threat intel set file, allowing GuardDuty to verify the bucket owner before accessing it. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="format" type="string" required>
  The format of the threat intelligence set file (e.g., TXT, STIX, OTX_CSV, or ALIEN_VAULT) that GuardDuty uses to parse the uploaded list. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="location" type="string" required>
  The URI (typically an S3 object URL) of the file that contains the threat intelligence set content. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  A friendly name for the threat intel set, used for identification and display in GuardDuty. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies the key-value tags to attach to the GuardDuty threat intel set for managing and identifying the resource. Optional. **(AI-inferred)**

`aws_guard_duty_trusted_entity_set` is GuardDuty's newer, broader trusted list, covering domains as well as IP addresses, that an `aws_guard_duty_detector` never generates findings against, GuardDuty's recommended replacement for the IP-only `aws_guard_duty_ipset`. Introduced September 2025.

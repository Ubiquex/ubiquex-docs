`aws_guard_duty_member` associates another real AWS account's own `aws_guard_duty_detector` as a member under an administrator account, so a security team can view and manage GuardDuty findings across every member account from one central place.

## Example

    ```go
    package main

    import (
    	guard "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/guard"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own duty member"})

    		ubx.Resource(guard.DutyMember, "example", guard.DutyMemberConfig{
    			Email:                    "example",
    			DetectorId:               "example",
    			DisableEmailNotification: true,
    			MemberId:                 "example",
    			Message:                  "example",
    			Status:                   "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="detector_id" type="string">
  The ID of the GuardDuty detector in the administrator account that the member account is associated with. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="disable_email_notification" type="bool">
  Whether to disable the email notification sent to the member account when it is invited to GuardDuty. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="email" type="string" required>
  The email address of the AWS account that is being added as a GuardDuty member, used to identify the account when creating the association. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="member_id" type="string">
  The AWS account ID of the member account being added to the GuardDuty administrator account. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="message" type="string">
  The custom message included in the invitation sent to the member account when inviting them to join Amazon GuardDuty. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The status of the GuardDuty member account, which can be one of Created, Invited, Disabled, or Enabled, and is used to manage the member's association with the GuardDuty administrator account. Optional. **(AI-inferred)**
</ResponseField>

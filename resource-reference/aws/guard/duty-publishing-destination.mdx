`aws_guard_duty_publishing_destination` exports an `aws_guard_duty_detector`'s own findings continuously to a real S3 bucket, for long-term retention or for feeding a caller's own SIEM rather than only viewing findings in the GuardDuty console.

## Input properties

<ResponseField name="destination_properties" type="object" required>
  Configures the GuardDuty publishing destination by specifying the ARN of the Amazon S3 bucket to receive findings and the ARN of the AWS KMS key used to encrypt those findings. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="destination_arn" type="string">
      The ARN of the resource to publish to. Optional.
    </ResponseField>
    <ResponseField name="kms_key_arn" type="string">
      The ARN of the KMS key to use for encryption. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="destination_type" type="string" required>
  The type of resource for the publishing destination. Currently only Amazon S3 buckets are supported. Required.
</ResponseField>

<ResponseField name="detector_id" type="string" required>
  The ID of the GuardDuty detector associated with the publishing destination. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of key-value tags to attach to the GuardDuty publishing destination for organizing and identifying the resource. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the GuardDuty publishing destination, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a user-defined tag that is associated with the GuardDuty publishing destination, used for resource organization, cost tracking, and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ID of the publishing destination. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="publishing_failure_start_timestamp" type="string">
  The time, in epoch millisecond format, at which GuardDuty was first unable to publish findings to the destination. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the publishing destination. Computed by AWS after `ship`.
</ResponseField>

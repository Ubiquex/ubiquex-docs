`aws_xray_group` defines a real, named filter expression over X-Ray trace data, so traces matching specific criteria, an error rate threshold or a particular service, can be viewed and alarmed on as their own group rather than sifted out of the account's full trace volume by hand.

## Input properties

<ResponseField name="filter_expression" type="string">
  The filter expression defining criteria by which to group traces. Optional.
</ResponseField>

<ResponseField name="group_name" type="string" required>
  The case-sensitive name of the new group. Names must be unique. Required.
</ResponseField>

<ResponseField name="insights_configuration" type="object">
  Configures whether X-Ray Insights is enabled for the group, and whether email notifications for insight events are sent. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="insights_enabled" type="bool">
      Set the InsightsEnabled value to true to enable insights or false to disable insights. Optional.
    </ResponseField>
    <ResponseField name="notifications_enabled" type="bool">
      Set the NotificationsEnabled value to true to enable insights notifications. Notifications can only be enabled on a group with InsightsEnabled set to true. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key of a tag assigned to the AWS X-Ray group, enabling you to categorize and manage the group within your AWS environment. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="group_arn" type="string">
  The ARN of the group that was generated on creation. Computed by AWS after `ship`.
</ResponseField>

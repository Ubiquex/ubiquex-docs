`aws_xray_transaction_search_config` enables X-Ray Transaction Search, ingesting spans into a dedicated CloudWatch Logs group (aws/spans) so CloudWatch Application Signals can generate a curated APM experience from them. This sits alongside, not instead of, the older X-Ray SDK/Daemon stack, which enters maintenance mode February 25, 2026 and reaches end of support February 25, 2027, with AWS steering new instrumentation toward OpenTelemetry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	xray "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/xray"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own transaction search config"})

    		ubx.Resource(xray.TransactionSearchConfig, "ci-runner", xray.TransactionSearchConfigConfig{
    			IndexingPercentage: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only aws --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("payments", () => {

        indexingPercentage: 1,

    });
    ```
  </Tab>

    ```python
    # ubx sdk gen --only aws --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/aws/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.aws.xray import TransactionSearchConfig, TransactionSearchConfigConfig

    def describe():
        ubx.intent("payments own transaction search config")

        ubx.resource(TransactionSearchConfig, "ci-runner", TransactionSearchConfigConfig(
            indexing_percentage=1,
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Input properties

<ResponseField name="indexing_percentage" type="number">
  Determines the percentage of traces indexed from CloudWatch Logs to X-Ray Optional.
</ResponseField>

## Output properties

<ResponseField name="account_id" type="string">
  User account id, used as the primary identifier for the resource Computed by AWS after `ship`.
</ResponseField>

`aws_cloud_formation_hook_type_config` supplies real, account-level configuration data, target stack filters, failure mode, to an `aws_cloud_formation_lambda_hook`, controlling how it behaves across every stack operation it's invoked for.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hook type config"})

    		ubx.Resource(cloudformation.HookTypeConfig, "example", cloudformation.HookTypeConfigConfig{
    			Configuration:      "example",
    			ConfigurationAlias: "example",
    			TypeArn:            "arn:aws:iam::123456789012:policy/example",
    			TypeName:           "example-type-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.aws.cloudformation import HookTypeConfig, HookTypeConfigConfig

    def describe():

        ubx.resource(HookTypeConfig, "example", HookTypeConfigConfig(

            configuration_alias="example",
            type_arn="arn:aws:iam::123456789012:policy/example",
            type_name="example-type-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="configuration" type="string">
  The configuration data for the extension, in this account and region. Optional.
</ResponseField>

<ResponseField name="configuration_alias" type="string">
  An alias by which to refer to this extension configuration data. Optional.
</ResponseField>

<ResponseField name="type_arn" type="string">
  The Amazon Resource Name (ARN) of the type without version number. Optional.
</ResponseField>

<ResponseField name="type_name" type="string">
  The name of the type being registered. We recommend that type names adhere to the following pattern: company_or_organization::service::type. Optional.
</ResponseField>

## Output properties

<ResponseField name="configuration_arn" type="string">
  The Amazon Resource Name (ARN) for the configuration data, in this account and region. Computed by AWS after `ship`.
</ResponseField>

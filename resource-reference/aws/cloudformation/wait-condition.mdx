`aws_cloud_formation_wait_condition` pauses an `aws_cloud_formation_stack`'s creation until it receives a real success signal, or times out, from an external process, the mechanism for coordinating stack creation with configuration work that happens outside CloudFormation itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own formation wait condition"})

    		ubx.Resource(cloudformation.WaitCondition, "example", cloudformation.WaitConditionConfig{
    			Count:   1,
    			Handle:  "example",
    			Timeout: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="count" type="number">
  The number of success signals that must be received by the CloudFormation wait condition before it is considered complete, matching the Count property of the associated CloudFormation WaitCondition. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="handle" type="string">
  The handle property is the pre-signed URL (from the associated WaitConditionHandle) that a signal is sent to, marking the wait as complete and allowing CloudFormation to finish creating this WaitCondition resource. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="timeout" type="string">
  The number of seconds to wait for the required number of signals to arrive before the wait condition times out. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="data" type="any">
  The map of data returned by the signaled resource or application once the wait condition is fulfilled, providing the payload sent via the signal URL. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  Computed by AWS after `ship`.
</ResponseField>

`aws_cloud_formation_type_activation` activates a public third-party extension, a resource type or module, from the CloudFormation registry for use in an account and Region's own stack templates, with real control over which major and minor version updates apply automatically.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cloudformation "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/cloudformation"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own type activation"})

    		ubx.Resource(cloudformation.TypeActivation, "example", cloudformation.TypeActivationConfig{
    			AutoUpdate:       true,
    			ExecutionRoleArn: "arn:aws:iam::123456789012:policy/example",
    			LoggingConfig:    map[string]any{"log_group_name": "example-log-group-name"},
    			MajorVersion:     "example",
    			PublicTypeArn:    "arn:aws:iam::123456789012:policy/example",
    			PublisherId:      "example",
    			Type:             "example",
    			TypeName:         "example-type-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="auto_update" type="bool">
  Whether to automatically update the extension in this account and region when a new minor version is published by the extension publisher. Major versions released by the publisher must be manually updated. Optional.
</ResponseField>

<ResponseField name="execution_role_arn" type="string">
  The Amazon Resource Name (ARN) of the IAM execution role to use to register the type. If your resource type calls AWS APIs in any of its handlers, you must create an IAM execution role that includes the necessary permissions to call those AWS APIs, and provision that execution role in your account. CloudFormation then assumes that execution role to provide your resource type with the appropriate credentials. Optional.
</ResponseField>

<ResponseField name="logging_config" type="object">
  Specifies the Amazon CloudWatch Logs log group name and IAM role ARN used to deliver logs for the registered resource type. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="log_group_name" type="string">
      The Amazon CloudWatch log group to which CloudFormation sends error logging information when invoking the type's handlers. Optional.
    </ResponseField>
    <ResponseField name="log_role_arn" type="string">
      The ARN of the role that CloudFormation should assume when sending log entries to CloudWatch logs. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="major_version" type="string">
  The Major Version of the type you want to enable Optional.
</ResponseField>

<ResponseField name="public_type_arn" type="string">
  The Amazon Resource Number (ARN) assigned to the public extension upon publication Optional.
</ResponseField>

<ResponseField name="publisher_id" type="string">
  The reserved publisher id for this type, or the publisher id assigned by CloudFormation for publishing in this region. Optional.
</ResponseField>

<ResponseField name="type" type="string">
  The kind of extension Optional.
</ResponseField>

<ResponseField name="type_name" type="string">
  The name of the type being registered. We recommend that type names adhere to the following pattern: company_or_organization::service::type. Optional.
</ResponseField>

<ResponseField name="type_name_alias" type="string">
  An alias to assign to the public extension in this account and region. If you specify an alias for the extension, you must then use the alias to refer to the extension in your templates. Optional.
</ResponseField>

<ResponseField name="version_bump" type="string">
  Manually updates a previously-enabled type to a new major or minor version, if available. You can also use this parameter to update the value of AutoUpdateEnabled Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the extension. Computed by AWS after `ship`.
</ResponseField>

`aws_access_analyzer_archive_rule` defines a real filter rule on an `aws_access_analyzer_analyzer` that automatically archives new findings matching it, so already-reviewed, expected access patterns don't have to be manually dismissed every time the analyzer re-reports them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	access "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/access"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own analyzer archive rule"})

    		ubx.Resource(access.AnalyzerArchiveRule, "ci-runner", access.AnalyzerArchiveRuleConfig{
    			AnalyzerName: "example-analyzer-name",
    			Filter:       "example",
    			RuleName:     "example-rule-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="analyzer_name" type="string" required>
  The name of the analyzer for the archive rule. Required.
</ResponseField>

<ResponseField name="filter" type="any" required>
  The criteria for the archive rule. A map of filter criteria property names to their criterion values. Required.
</ResponseField>

<ResponseField name="rule_name" type="string" required>
  The name of the archive rule. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the archive rule. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The time at which the archive rule was created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The time at which the archive rule was last updated. Computed by AWS after `ship`.
</ResponseField>

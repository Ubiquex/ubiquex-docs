`aws_b2_bi_profile` stores an organization's own business contact information in AWS B2B Data Interchange, the foundation every `aws_b2_bi_partnership` is built on, since a partnership always ties a profile to a trading partner's capability.

## Example

    package main

    	b2 "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/b2"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		ubx.Resource(b2.BiProfile, "example", b2.BiProfileConfig{

    			Name:         "example",
    			Phone:        "example",
    			Email:        "example",
    			Tags:         []map[string]any{{"key": "example"}},
    		})
    	}))
    }

## Input properties

</ResponseField>

<ResponseField name="email" type="string">

</ResponseField>

<ResponseField name="logging" type="string" required>
  Determines whether CloudWatch logging is enabled for the profile, with valid values ENABLED or DISABLED, governing the capture of API activity and transaction events. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>

</ResponseField>

<ResponseField name="phone" type="string" required>

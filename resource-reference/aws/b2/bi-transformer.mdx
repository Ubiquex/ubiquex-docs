`aws_b2_bi_transformer` defines the mapping logic AWS B2B Data Interchange uses to convert EDI documents (X12, EDIFACT, HL7v2) to and from JSON or XML, the actual transformation a `aws_b2_bi_capability` then connects to real S3 input and output locations.

`aws_direct_connect_connection` is the real, physical dedicated network connection between a caller's own network and an AWS Direct Connect location, the foundational resource every `aws_direct_connect_lag` and virtual interface ultimately runs over.

## Example

## Input properties

<ResponseField name="bandwidth" type="string" required>
  The bandwidth of the connection. Required.
</ResponseField>

<ResponseField name="connection_name" type="string" required>
  The name of the connection. Required.
</ResponseField>

<ResponseField name="lag_id" type="any">
  The ID or ARN of the LAG to associate the connection with. Optional.
</ResponseField>

<ResponseField name="location" type="string" required>
  The location of the connection. Required.
</ResponseField>

<ResponseField name="provider_name" type="string">
  The name of the service provider associated with the requested connection. Optional.
</ResponseField>

<ResponseField name="request_macsec" type="bool">
  Indicates whether you want the connection to support MAC Security (MACsec). Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with the connection. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value for a tag assigned to the Direct Connect connection, used to store arbitrary metadata or cost-allocation information. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

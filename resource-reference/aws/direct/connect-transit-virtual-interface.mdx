`aws_direct_connect_transit_virtual_interface` carries real traffic over an `aws_direct_connect_connection` into an EC2 Transit Gateway rather than directly into one VPC, letting a single Direct Connect connection reach every VPC attached to that transit gateway.

## Example

    ```go
    package main

    import (
    	direct "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/direct"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connect transit virtual interface"})

    		ubx.Resource(direct.ConnectTransitVirtualInterface, "example", direct.ConnectTransitVirtualInterfaceConfig{
    			ConnectionId:                           "example",
    			DirectConnectGatewayId:                 "example",
    			VirtualInterfaceName:                   "example-virtual-interface-name",
    			Vlan:                                   1,
    			AllocateTransitVirtualInterfaceRoleArn: "arn:aws:iam::123456789012:policy/example",
    			EnableSiteLink:                         true,
    			Mtu:                                    1,
    			RateLimit:                              "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="allocate_transit_virtual_interface_role_arn" type="string">
  The Amazon Resource Name (ARN) of the role to allocate the TransitVifAllocation. Needs directconnect:AllocateTransitVirtualInterface permissions and tag permissions if applicable. Optional.
</ResponseField>

<ResponseField name="connection_id" type="any" required>
  The ID or ARN of the connection or LAG. Required.
</ResponseField>

<ResponseField name="direct_connect_gateway_id" type="any" required>
  The ID or ARN of the Direct Connect gateway. Required.
</ResponseField>

<ResponseField name="enable_site_link" type="bool">
  Indicates whether to enable or disable SiteLink. Optional.
</ResponseField>

<ResponseField name="mtu" type="number">
  The maximum transmission unit (MTU), in bytes. The supported values are 1500 and 9001. The default value is 1500. Optional.
</ResponseField>

<ResponseField name="rate_limit" type="string">
  The rate limit (bandwidth allocation) for the virtual interface. The value must be one of the supported bandwidth values (e.g., 50Mbps, 1Gbps, 10Gbps) and cannot exceed the bandwidth of the parent connection or LAG. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with the private virtual interface. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag (e.g., 'Name') applied to the Direct Connect Transit Virtual Interface, used to filter, organize, and control access to the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag applied to this AWS Direct Connect transit virtual interface, used for arbitrary metadata such as cost allocation or ownership. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="virtual_interface_name" type="string" required>
  The name of the virtual interface assigned by the customer network. The name has a maximum of 100 characters. The following are valid characters: a-z, 0-9 and a hyphen (-). Required.
</ResponseField>

<ResponseField name="vlan" type="number" required>
  The ID of the VLAN. Required.
</ResponseField>

## Output properties

  <Expandable title="properties">

    </ResponseField>
    <ResponseField name="amazon_address" type="string">
      The IPv4 address on the Amazon side of the BGP peering session for a Direct Connect transit virtual interface, used to establish BGP connectivity with the customer's router. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="asn" type="string">
      The autonomous system number (ASN) of the BGP peer used to establish the BGP session for the transit virtual interface. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="auth_key" type="string">
      The MD5 authentication key used for BGP peering on this transit virtual interface, enabling authenticated BGP sessions with the on-premises router. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="bgp_peer_id" type="string">

    </ResponseField>
    <ResponseField name="customer_address" type="string">

    </ResponseField>

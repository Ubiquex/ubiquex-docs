`aws_direct_connect_direct_connect_gateway_association` attaches a real VPC's virtual private gateway, or a Transit Gateway, to an `aws_direct_connect_direct_connect_gateway`, the resource that actually extends that gateway's on-premises connectivity to the attached VPC or Transit Gateway.

## Input properties

<ResponseField name="accept_direct_connect_gateway_association_proposal_role_arn" type="string">
  The Amazon Resource Name (ARN) of the role to accept the Direct Connect Gateway association proposal. Needs directconnect:AcceptDirectConnectGatewayAssociationProposal permissions. Optional.
</ResponseField>

<ResponseField name="allowed_prefixes_to_direct_connect_gateway" type="list(string)">
  The Amazon VPC prefixes to advertise to the Direct Connect gateway. This parameter is required when you create an association to a transit gateway. Optional.
</ResponseField>

<ResponseField name="associated_gateway_id" type="any" required>
  The ID or ARN of the virtual private gateway or transit gateway. Required.
</ResponseField>

<ResponseField name="direct_connect_gateway_id" type="any" required>
  The ID or ARN of the Direct Connect gateway. Required.
</ResponseField>

## Output properties

<ResponseField name="association_id" type="string">
  The ID of the Direct Connect gateway association. Computed by AWS after `ship`.
</ResponseField>

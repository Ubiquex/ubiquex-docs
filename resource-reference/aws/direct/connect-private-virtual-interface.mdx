`aws_direct_connect_private_virtual_interface` carries real, private traffic over an `aws_direct_connect_connection` directly into a specific VPC, using a private, not public, ASN and IP addressing on the AWS side.

## Input properties

<ResponseField name="allocate_private_virtual_interface_role_arn" type="string">
  The Amazon Resource Name (ARN) of the role to allocate the private virtual interface. Needs directconnect:AllocatePrivateVirtualInterface permissions and tag permissions if applicable. Optional.
</ResponseField>

<ResponseField name="connection_id" type="any" required>
  The ID or ARN of the connection or LAG. Required.
</ResponseField>

<ResponseField name="direct_connect_gateway_id" type="any">
  The ID or ARN of the Direct Connect gateway. Optional.
</ResponseField>

<ResponseField name="enable_site_link" type="bool">
  Indicates whether to enable or disable SiteLink. Optional.
</ResponseField>

<ResponseField name="mtu" type="number">
  The maximum transmission unit (MTU), in bytes. The supported values are 1500 and 9001. The default value is 1500. Optional.
</ResponseField>

<ResponseField name="rate_limit" type="string">
  The rate limit (bandwidth allocation) for the virtual interface. The value must be one of the supported bandwidth values (e.g., 50Mbps, 1Gbps, 10Gbps) and cannot exceed the bandwidth of the parent connection or LAG. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags associated with the private virtual interface. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the Direct Connect private virtual interface, used to identify the tag in a key-value pair. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="virtual_gateway_id" type="string">
  The ID or ARN of the virtual private gateway. Optional.
</ResponseField>

<ResponseField name="virtual_interface_name" type="string" required>
  The name of the virtual interface assigned by the customer network. The name has a maximum of 100 characters. The following are valid characters: a-z, 0-9 and a hyphen (-). Required.
</ResponseField>

<ResponseField name="vlan" type="number" required>
  The ID of the VLAN. Required.
</ResponseField>

## Output properties

    <ResponseField name="amazon_address" type="string">

    </ResponseField>
    <ResponseField name="auth_key" type="string">
      The MD5 authentication key (BGP password) used for BGP peering on this Direct Connect private virtual interface. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>

    </ResponseField>

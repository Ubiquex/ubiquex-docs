`aws_game_lift_game_server_group` runs GameLift FleetIQ on top of a real, self-managed EC2 Auto Scaling group, optimizing for Spot Instance savings while protecting instances that are still hosting active game sessions from early termination.

## Input properties

<ResponseField name="auto_scaling_policy" type="object">
  Configuration settings to define a scaling policy for the Auto Scaling group that is optimized for game hosting. Updating this game server group property will not take effect for the created EC2 Auto Scaling group, please update the EC2 Auto Scaling group directly after creating the resource. Optional.
  <Expandable title="properties">
    <ResponseField name="estimated_instance_warmup" type="number">
      Length of time, in seconds, it takes for a new instance to start new game server processes and register with GameLift FleetIQ. Optional.
    </ResponseField>
    <ResponseField name="target_tracking_configuration" type="object" required>
      Settings for a target-based scaling policy applied to Auto Scaling group. Required.
      <Expandable title="properties">
        <ResponseField name="target_value" type="number" required>
          Desired value to use with a game server group target-based scaling policy. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="balancing_strategy" type="string">
  The fallback balancing method to use for the game server group when Spot Instances in a Region become unavailable or are not viable for game hosting. Optional.
</ResponseField>

<ResponseField name="delete_option" type="string">
  The type of delete to perform. Optional.
</ResponseField>

<ResponseField name="game_server_group_name" type="string" required>
  An identifier for the new game server group. Required.
</ResponseField>

<ResponseField name="game_server_protection_policy" type="string">
  A flag that indicates whether instances in the game server group are protected from early termination. Optional.
</ResponseField>

<ResponseField name="instance_definitions" type="list(object)" required>
  A set of EC2 instance types to use when creating instances in the group. Required.
  <Expandable title="properties">
    <ResponseField name="instance_type" type="string">
      The EC2 instance type (e.g., c5.large, m5.large) that GameLift uses to launch instances in this game server group's underlying fleet. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="weighted_capacity" type="string">
      Sets the relative weighting that this instance type contributes to the game server group's total capacity, used by Amazon GameLift to determine how many instances of each type are needed to meet the group's target capacity. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="launch_template" type="object">
  The EC2 launch template that contains configuration settings and game server code to be deployed to all instances in the game server group. Updating this game server group property will not take effect for the created EC2 Auto Scaling group, please update the EC2 Auto Scaling group directly after creating the resource. Optional.
  <Expandable title="properties">
    <ResponseField name="launch_template_id" type="string">
      A unique identifier for an existing EC2 launch template. Optional.
    </ResponseField>
    <ResponseField name="launch_template_name" type="string">
      A readable identifier for an existing EC2 launch template. Optional.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of the EC2 launch template to use. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="max_size" type="number">
  The maximum number of instances allowed in the EC2 Auto Scaling group. Updating this game server group property will not take effect for the created EC2 Auto Scaling group, please update the EC2 Auto Scaling group directly after creating the resource. Optional.
</ResponseField>

<ResponseField name="min_size" type="number">
  The minimum number of instances allowed in the EC2 Auto Scaling group. Updating this game server group property will not take effect for the created EC2 Auto Scaling group, please update the EC2 Auto Scaling group directly after creating the resource. Optional.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  The Amazon Resource Name (ARN) for an IAM role that allows Amazon GameLift to access your EC2 Auto Scaling groups. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of labels to assign to the new game server group resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to this GameLift game server group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of an arbitrary tag key assigned to the GameLift GameServerGroup, used for resource organization, cost allocation, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_subnets" type="list(string)">
  A list of virtual private cloud (VPC) subnets to use with instances in the game server group. Updating this game server group property will not take effect for the created EC2 Auto Scaling group, please update the EC2 Auto Scaling group directly after creating the resource. Optional.
</ResponseField>

## Output properties

<ResponseField name="auto_scaling_group_arn" type="string">
  A generated unique ID for the EC2 Auto Scaling group that is associated with this game server group. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="game_server_group_arn" type="string">
  A generated unique ID for the game server group. Computed by AWS after `ship`.
</ResponseField>

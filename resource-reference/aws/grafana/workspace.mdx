`aws_grafana_workspace` provisions a real, managed Grafana server, Amazon Managed Grafana, with its own authentication, data source connections, and dashboards, without a caller running and patching Grafana on their own compute.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	grafana "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/grafana"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workspace"})

    		ubx.Resource(grafana.Workspace, "example", grafana.WorkspaceConfig{
    			AccountAccessType:       "example",
    			AuthenticationProviders: []string{"example"},
    			PermissionType:          "example",
    			Name:                    "example",
    			ClientToken:             "example",
    			DataSources:             []string{"example"},
    			Description:             "Managed by ubx.",
    			GrafanaVersion:          "example",
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="account_access_type" type="string" required>
  These enums represent valid account access types. Specifically these enums determine whether the workspace can access AWS resources in the AWS account only, or whether it can also access resources in other accounts in the same organization. If the value CURRENT_ACCOUNT is used, a workspace role ARN must be provided. If the value is ORGANIZATION, a list of organizational units must be provided. Required.
</ResponseField>

<ResponseField name="authentication_providers" type="list(string)" required>
  List of authentication providers to enable. Required.
</ResponseField>

<ResponseField name="client_token" type="string">
  A unique, case-sensitive, user-provided identifier to ensure the idempotency of the request. Optional.
</ResponseField>

<ResponseField name="data_sources" type="list(string)">
  List of data sources on the service managed IAM role. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Description of a workspace. Optional.
</ResponseField>

<ResponseField name="grafana_version" type="string">
  The version of Grafana to support in your workspace. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The user friendly name of a workspace. Optional.
</ResponseField>

<ResponseField name="network_access_control" type="object">
  The configuration settings for Network Access Control. Optional.
  <Expandable title="properties">
    <ResponseField name="prefix_list_ids" type="list(string)">
      The list of prefix list IDs. A prefix list is a list of CIDR ranges of IP addresses. The IP addresses specified are allowed to access your workspace. If the list is not included in the configuration then no IP addresses will be allowed to access the workspace. Optional.
    </ResponseField>
    <ResponseField name="vpce_ids" type="list(string)">
      The list of Amazon VPC endpoint IDs for the workspace. If a NetworkAccessConfiguration is specified then only VPC endpoints specified here will be allowed to access the workspace. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="notification_destinations" type="list(string)">
  List of notification destinations on the customers service managed IAM role that the Grafana workspace can query. Optional.
</ResponseField>

<ResponseField name="organization_role_name" type="string">
  The name of an IAM role that already exists to use with AWS Organizations to access AWS data sources and notification channels in other accounts in an organization. Optional.
</ResponseField>

<ResponseField name="organizational_units" type="list(string)">
  List of Organizational Units containing AWS accounts the Grafana workspace can pull data from. Optional.
</ResponseField>

<ResponseField name="permission_type" type="string" required>
  These enums represent valid permission types to use when creating or configuring a Grafana workspace. The SERVICE_MANAGED permission type means the Managed Grafana service will create a workspace IAM role on your behalf. The CUSTOMER_MANAGED permission type means that the customer is expected to provide an IAM role that the Grafana workspace can use to query data sources. Required.
</ResponseField>

<ResponseField name="plugin_admin_enabled" type="bool">
  Allow workspace admins to install plugins Optional.
</ResponseField>

<ResponseField name="role_arn" type="string">
  IAM Role that will be used to grant the Grafana workspace access to a customers AWS resources. Optional.
</ResponseField>

<ResponseField name="saml_configuration" type="object">
  SAML configuration data associated with an AMG workspace. Optional.
  <Expandable title="properties">
    <ResponseField name="allowed_organizations" type="list(string)">
      List of SAML organizations allowed to access Grafana. Optional.
    </ResponseField>
    <ResponseField name="assertion_attributes" type="object">
      Maps Grafana friendly names to the IdPs SAML attributes. Optional.
      <Expandable title="properties">
        <ResponseField name="email" type="string">
          Name of the attribute within the SAML assert to use as the users email in Grafana. Optional.
        </ResponseField>
        <ResponseField name="groups" type="string">
          Name of the attribute within the SAML assert to use as the users groups in Grafana. Optional.
        </ResponseField>
        <ResponseField name="login" type="string">
          Name of the attribute within the SAML assert to use as the users login handle in Grafana. Optional.
        </ResponseField>
        <ResponseField name="name" type="string">
          Name of the attribute within the SAML assert to use as the users name in Grafana. Optional.
        </ResponseField>
        <ResponseField name="org" type="string">
          Name of the attribute within the SAML assert to use as the users organizations in Grafana. Optional.
        </ResponseField>
        <ResponseField name="role" type="string">
          Name of the attribute within the SAML assert to use as the users roles in Grafana. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="idp_metadata" type="object" required>
      IdP Metadata used to configure SAML authentication in Grafana. Required.
      <Expandable title="properties">
        <ResponseField name="url" type="string">
          URL that vends the IdPs metadata. Optional.
        </ResponseField>
        <ResponseField name="xml" type="string">
          XML blob of the IdPs metadata. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="login_validity_duration" type="number">
      The maximum lifetime an authenticated user can be logged in (in minutes) before being required to re-authenticate. Optional.
    </ResponseField>
    <ResponseField name="role_values" type="object">
      Maps SAML roles to the Grafana Editor and Admin roles. Optional.
      <Expandable title="properties">
        <ResponseField name="admin" type="list(string)">
          List of SAML roles which will be mapped into the Grafana Admin role. Optional.
        </ResponseField>
        <ResponseField name="editor" type="list(string)">
          List of SAML roles which will be mapped into the Grafana Editor role. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="stack_set_name" type="string">
  The name of the AWS CloudFormation stack set to use to generate IAM roles to be used for this workspace. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The list of tags associated with the workspace. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value assigned to a tag key for the Grafana workspace, used to categorize, organize, and track the resource for cost and management purposes. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_configuration" type="object">
  The configuration settings for an Amazon VPC that contains data sources for your Grafana workspace to connect to. Optional.
  <Expandable title="properties">
    <ResponseField name="security_group_ids" type="list(string)" required>
      The list of Amazon EC2 security group IDs attached to the Amazon VPC for your Grafana workspace to connect. Required.
    </ResponseField>
    <ResponseField name="subnet_ids" type="list(string)" required>
      The list of Amazon EC2 subnet IDs created in the Amazon VPC for your Grafana workspace to connect. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_sns_subscription` subscribes a real endpoint, an SQS queue, Lambda function, HTTPS URL, email, or phone number, to an `aws_sns_topic`, the resource that actually receives every message the topic publishes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sns "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/sns"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own subscription"})

    		ubx.Resource(sns.Subscription, "example", sns.SubscriptionConfig{
    			Protocol:           "example",
    			TopicArn:           "arn:aws:iam::123456789012:policy/example",
    			DeliveryPolicy:     "example",
    			Endpoint:           "example",
    			FilterPolicy:       "example",
    			FilterPolicyScope:  "example",
    			RawMessageDelivery: true,
    			RedrivePolicy:      "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="delivery_policy" type="any">
  The delivery policy JSON assigned to the subscription. Enables the subscriber to define the message delivery retry strategy in the case of an HTTP/S endpoint subscribed to the topic. Optional.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The subscription's endpoint. The endpoint value depends on the protocol that you specify. Optional.
</ResponseField>

<ResponseField name="filter_policy" type="any">
  The filter policy JSON assigned to the subscription. Enables the subscriber to filter out unwanted messages. Optional.
</ResponseField>

<ResponseField name="filter_policy_scope" type="string">
  This attribute lets you choose the filtering scope by using one of the following string value types: MessageAttributes (default) and MessageBody. Optional.
</ResponseField>

<ResponseField name="protocol" type="string" required>
  The subscription's protocol. Required.
</ResponseField>

<ResponseField name="raw_message_delivery" type="bool">
  When set to true, enables raw message delivery. Raw messages don't contain any JSON formatting and can be sent to Amazon SQS and HTTP/S endpoints. Optional.
</ResponseField>

<ResponseField name="redrive_policy" type="any">
  When specified, sends undeliverable messages to the specified Amazon SQS dead-letter queue. Messages that can't be delivered due to client errors are held in the dead-letter queue for further analysis or reprocessing. Optional.
</ResponseField>

<ResponseField name="region" type="string">
  For cross-region subscriptions, the region in which the topic resides.If no region is specified, AWS CloudFormation uses the region of the caller as the default. Optional.
</ResponseField>

<ResponseField name="replay_policy" type="any">
  Specifies whether Amazon SNS resends the notification to the subscription when a message's attribute changes. Optional.
</ResponseField>

<ResponseField name="subscription_role_arn" type="string">
  This property applies only to Amazon Data Firehose delivery stream subscriptions. Optional.
</ResponseField>

<ResponseField name="topic_arn" type="string" required>
  The ARN of the topic to subscribe to. Required.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  Arn of the subscription Computed by AWS after `ship`.
</ResponseField>

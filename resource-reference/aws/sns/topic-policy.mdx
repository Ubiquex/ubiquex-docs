## Input properties

<ResponseField name="policy_document" type="any" required>
  A policy document that contains permissions to add to the specified SNS topics. Required.
</ResponseField>

<ResponseField name="topics" type="list(string)" required>
  The Amazon Resource Names (ARN) of the topics to which you want to add the policy. You can use the ``Ref`` function to specify an ``AWS::SNS::Topic`` resource. Required.
</ResponseField>

## Output properties

<ResponseField name="id" type="string">
  The ARN of the SNS topic that this policy is attached to, which serves as the unique identifier for the aws_sns_topic_policy resource. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_sns_topic_inline_policy` attaches a real access policy directly to an `aws_sns_topic`'s own resource definition, an alternative to managing the topic's policy as a separate `aws_sns_topic_policy` resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	sns "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sns"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own topic inline policy"})

    		ubx.Resource(sns.TopicInlinePolicy, "ci-runner", sns.TopicInlinePolicyConfig{
    			PolicyDocument: "example",
    			TopicArn:       "arn:aws:iam::123456789012:policy/ci",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="policy_document" type="any" required>
  A policy document that contains permissions to add to the specified SNS topics. Required.
</ResponseField>

<ResponseField name="topic_arn" type="string" required>
  The Amazon Resource Name (ARN) of the topic to which you want to add the policy. Required.
</ResponseField>

`aws_data_sync_location_fsx_windows` registers a real Amazon FSx for Windows File Server file system as a DataSync transfer endpoint, the managed Windows-file-server counterpart to `aws_data_sync_location_smb`.

## Input properties

<ResponseField name="custom_secret_config" type="object">
  Specifies configuration information for a customer-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and an IAM role that DataSync can assume and access the customer-managed secret. Optional.
  <Expandable title="properties">
    <ResponseField name="secret_access_role_arn" type="string" required>
      Specifies the ARN for the AWS Identity and Access Management role that DataSync uses to access the secret specified for SecretArn. Required.
    </ResponseField>
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for a customer created AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="domain" type="string">
  The name of the Windows domain that the FSx for Windows server belongs to. Optional.
</ResponseField>

<ResponseField name="fsx_filesystem_arn" type="string">
  The Amazon Resource Name (ARN) for the FSx for Windows file system. Optional.
</ResponseField>

<ResponseField name="password" type="string">
  The password of the user who has the permissions to access files and folders in the FSx for Windows file system. Optional.
</ResponseField>

<ResponseField name="security_group_arns" type="list(string)" required>
  The ARNs of the security groups that are to use to configure the FSx for Windows file system. Required.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  A subdirectory in the location's path. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag that you can assign to the DataSync location for FSx for Windows File Server, used to identify and manage the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value of a user-defined tag applied to the FSx for Windows File Server DataSync location, used for cost allocation and resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="user" type="string" required>
  The user who has the permissions to access files and folders in the FSx for Windows file system. Required.
</ResponseField>

## Output properties

<ResponseField name="cmk_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and a customer-managed AWS KMS key. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      Specifies the ARN for the customer-managed AWS KMS key used to encrypt the secret specified for SecretArn. DataSync provides this key to AWS Secrets Manager. Optional.
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      Specifies the ARN for an AWS Secrets Manager secret, managed by DataSync. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon FSx for Windows file system location that is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the FSx for Windows location that was described. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="managed_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location. DataSync uses the default AWS-managed KMS key to encrypt this secret in AWS Secrets Manager. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for an AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_data_sync_location_s3` registers a real Amazon S3 bucket and prefix as a DataSync transfer endpoint, usable as either the source or destination of an `aws_data_sync_task`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	datasync "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/datasync"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own location s3"})

    		ubx.Resource(datasync.LocationS3, "example", datasync.LocationS3Config{
    			S3Config:       map[string]any{"bucket_access_role_arn": "example"},
    			S3BucketArn:    "arn:aws:iam::123456789012:policy/example",
    			S3StorageClass: "example",
    			Subdirectory:   "example",
    			Tags:           []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="s3_bucket_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon S3 bucket. Optional.
</ResponseField>

<ResponseField name="s3_config" type="object" required>
  The Amazon Resource Name (ARN) of the AWS IAM role that is used to access an Amazon S3 bucket. Required.
  <Expandable title="properties">
    <ResponseField name="bucket_access_role_arn" type="string" required>
      The ARN of the IAM role of the Amazon S3 bucket. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="s3_storage_class" type="string">
  The Amazon S3 storage class you want to store your files in when this location is used as a task destination. Optional.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  A subdirectory in the Amazon S3 bucket. This subdirectory in Amazon S3 is used to read data from the S3 source location or write data to the S3 destination. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag attached to the AWS DataSync S3 location, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a tag attached to this DataSync S3 location, used to identify or categorize the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the Amazon S3 bucket location. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the S3 location that was described. Computed by AWS after `ship`.
</ResponseField>

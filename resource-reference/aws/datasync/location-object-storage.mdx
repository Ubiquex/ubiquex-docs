`aws_data_sync_location_object_storage` registers a real, self-managed or third-party S3-compatible object storage system as a DataSync transfer endpoint, distinct from the AWS-managed `aws_data_sync_location_s3`.

## Input properties

<ResponseField name="access_key" type="string">
  Optional. The access key is used if credentials are required to access the self-managed object storage server. Optional.
</ResponseField>

<ResponseField name="agent_arns" type="list(string)">
  Specifies the Amazon Resource Names (ARNs) of the DataSync agents that can connect with your object storage system. If you are setting up an agentless cross-cloud transfer, you do not need to specify a value for this parameter. Optional.
</ResponseField>

<ResponseField name="bucket_name" type="string">
  The name of the bucket on the self-managed object storage server. Optional.
</ResponseField>

<ResponseField name="custom_secret_config" type="object">
  Specifies configuration information for a customer-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and an IAM role that DataSync can assume and access the customer-managed secret. Optional.
  <Expandable title="properties">
    <ResponseField name="secret_access_role_arn" type="string" required>
      Specifies the ARN for the AWS Identity and Access Management role that DataSync uses to access the secret specified for SecretArn. Required.
    </ResponseField>
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for a customer created AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="secret_key" type="string">
  Optional. The secret key is used if credentials are required to access the self-managed object storage server. Optional.
</ResponseField>

<ResponseField name="server_certificate" type="string">
  X.509 PEM content containing a certificate authority or chain to trust. Optional.
</ResponseField>

<ResponseField name="server_hostname" type="string">
  The name of the self-managed object storage server. This value is the IP address or Domain Name Service (DNS) name of the object storage server. Optional.
</ResponseField>

<ResponseField name="server_port" type="number">
  The port that your self-managed server accepts inbound network traffic on. Optional.
</ResponseField>

<ResponseField name="server_protocol" type="string">
  The protocol that the object storage server uses to communicate. Optional.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  The subdirectory in the self-managed object storage server that is used to read data from. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to the DataSync object storage location, used to organize and identify the location for cost tracking and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to this AWS DataSync location for object storage, used for identifying, categorizing, or managing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="cmk_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location, and a customer-managed AWS KMS key. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="kms_key_arn" type="string">
      Specifies the ARN for the customer-managed AWS KMS key used to encrypt the secret specified for SecretArn. DataSync provides this key to AWS Secrets Manager. Optional.
    </ResponseField>
    <ResponseField name="secret_arn" type="string">
      Specifies the ARN for an AWS Secrets Manager secret, managed by DataSync. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the location that is created. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the object storage location that was described. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="managed_secret_config" type="object">
  Specifies configuration information for a DataSync-managed secret, such as an authentication token or set of credentials that DataSync uses to access a specific transfer location. DataSync uses the default AWS-managed KMS key to encrypt this secret in AWS Secrets Manager. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="secret_arn" type="string" required>
      Specifies the ARN for an AWS Secrets Manager secret. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

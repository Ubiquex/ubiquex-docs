`aws_data_sync_location_nfs` registers a real, on-premises NFS file share as a DataSync transfer endpoint, letting an `aws_data_sync_task` migrate or replicate data to or from on-premises storage rather than only between AWS services.

## Input properties

<ResponseField name="mount_options" type="object">
  The NFS mount options that DataSync can use to mount your NFS share. Optional.
  <Expandable title="properties">
    <ResponseField name="version" type="string">
      The specific NFS version that you want DataSync to use to mount your NFS share. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="on_prem_config" type="object" required>
  Contains a list of Amazon Resource Names (ARNs) of agents that are used to connect an NFS server. Required.
  <Expandable title="properties">
    <ResponseField name="agent_arns" type="list(string)" required>
      ARN(s) of the agent(s) to use for an NFS location. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="server_hostname" type="string">
  The name of the NFS server. This value is the IP address or DNS name of the NFS server. Optional.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  The subdirectory in the NFS file system that is used to read data from the NFS source location or write data to the NFS destination. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to this AWS DataSync location for NFS, used for metadata, identification, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="location_arn" type="string">
  The Amazon Resource Name (ARN) of the NFS location. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="location_uri" type="string">
  The URL of the NFS location that was described. Computed by AWS after `ship`.
</ResponseField>

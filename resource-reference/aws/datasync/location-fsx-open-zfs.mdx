`aws_data_sync_location_fsx_open_zfs` registers a real Amazon FSx for OpenZFS file system as a DataSync transfer endpoint, the OpenZFS-compatible counterpart among DataSync's several managed FSx location types.

## Example

    ```go
    package main

    import (
    	datasync "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/datasync"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own location fsx open zfs"})

    		ubx.Resource(datasync.LocationFsxOpenZfs, "example", datasync.LocationFsxOpenZfsConfig{
    			Protocol:          map[string]any{"nfs": map[string]any{"mount_options": map[string]any{"version": "example"}}},
    			SecurityGroupArns: []string{"example"},
    			FsxFilesystemArn:  "arn:aws:iam::123456789012:policy/example",
    			Subdirectory:      "example",
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="fsx_filesystem_arn" type="string">
  The Amazon Resource Name (ARN) for the FSx OpenZFS file system. Optional.
</ResponseField>

<ResponseField name="protocol" type="object" required>
  Configuration settings for an NFS or SMB protocol, currently only support NFS Required.
  <Expandable title="properties">
    <ResponseField name="nfs" type="object">
      FSx OpenZFS file system NFS protocol information Optional.
      <Expandable title="properties">
        <ResponseField name="mount_options" type="object" required>
          The NFS mount options that DataSync can use to mount your NFS share. Required.
          <Expandable title="properties">

              The specific NFS version that you want DataSync to use to mount your NFS share. Optional.
            </ResponseField>

    </ResponseField>
  </Expandable>

## Output properties

<ResponseField name="location_arn" type="string">

</ResponseField>

`aws_data_sync_location_fsx_ontap` registers a real Amazon FSx for NetApp ONTAP file system as a DataSync transfer endpoint, for migrating or replicating data to or from an existing NetApp-based storage environment.

## Input properties

<ResponseField name="security_group_arns" type="list(string)" required>
  The ARNs of the security groups that are to use to configure the FSx ONTAP file system. Required.
</ResponseField>

<ResponseField name="storage_virtual_machine_arn" type="string" required>
  The Amazon Resource Name (ARN) for the FSx ONTAP SVM. Required.
</ResponseField>

<ResponseField name="subdirectory" type="string">
  A subdirectory in the location's path. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a key-value tag applied to the FSx for ONTAP DataSync location, used to organize and identify the location for management and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

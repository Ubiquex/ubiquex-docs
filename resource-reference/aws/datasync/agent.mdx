`aws_data_sync_agent` activates a real DataSync agent, a virtual machine or hardware appliance deployed close to on-premises data, that an `aws_data_sync_task` reads from or writes to as one endpoint of its transfer.

## Example

<Tabs>
  <Tab title="Go">

    ```go
    package main

    import (
    	datasync "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/datasync"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own agent"})

    		ubx.Resource(datasync.Agent, "example", datasync.AgentConfig{
    			ActivationKey:     "example",
    			AgentName:         "example-agent-name",
    			SecurityGroupArns: []string{"example"},
    			SubnetArns:        []string{"example"},
    			Tags:              []map[string]any{{"key": "example"}},
    			VpcEndpointId:     "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="activation_key" type="string">
  Activation key of the Agent. Optional.
</ResponseField>

<ResponseField name="agent_name" type="string">
  The name configured for the agent. Text reference used to identify the agent in the console. Optional.
</ResponseField>

<ResponseField name="security_group_arns" type="list(string)">
  The ARNs of the security group used to protect your data transfer task subnets. Optional.
</ResponseField>

<ResponseField name="subnet_arns" type="list(string)">
  The ARNs of the subnets in which DataSync will create elastic network interfaces for each data transfer task. Optional.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  An array of key-value pairs to apply to this resource. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc_endpoint_id" type="string">
  The ID of the VPC endpoint that the agent has access to. Optional.
</ResponseField>

## Output properties

<ResponseField name="agent_arn" type="string">
  The DataSync Agent ARN. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="endpoint_type" type="string">
  The service endpoints that the agent will connect to. Computed by AWS after `ship`.
</ResponseField>

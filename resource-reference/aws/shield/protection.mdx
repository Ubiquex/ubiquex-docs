`aws_shield_protection` enables real AWS Shield Advanced protection, enhanced DDoS detection and automatic mitigation with cost protection, for a specific resource, a CloudFront distribution, Global Accelerator, ELB, or Elastic IP, beyond the automatic Shield Standard coverage every AWS customer already has.

## Input properties

<ResponseField name="application_layer_automatic_response_configuration" type="object">
  The automatic application layer DDoS mitigation settings for a Protection. This configuration determines whether Shield Advanced automatically manages rules in the web ACL in order to respond to application layer events that Shield Advanced determines to be DDoS attacks. Optional.
  <Expandable title="properties">
    <ResponseField name="action" type="object" required>
      Specifies the action setting that Shield Advanced should use in the AWS WAF rules that it creates on behalf of the protected resource in response to DDoS attacks. You specify this as part of the configuration for the automatic application layer DDoS mitigation feature, when you enable or update automatic mitigation. Shield Advanced creates the AWS WAF rules in a Shield Advanced-managed rule group, inside the web ACL that you have associated with the resource. Required.
      <Expandable title="properties">
        <ResponseField name="block" type="any">
          When present, this marker block selects 'block' as the Shield Advanced automatic application-layer response action, causing the detected malicious request to be blocked. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="count" type="any">
          Sets the automatic application-layer DDoS mitigation action to 'Count', causing AWS Shield Advanced to count matching requests without blocking them so you can observe traffic before enforcing a block. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Indicates whether automatic application layer DDoS mitigation is enabled for the protection. Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="health_check_arns" type="list(string)">
  The Amazon Resource Names (ARNs) of the health check to associate with the protection. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  Friendly name for the Protection. Required.
</ResponseField>

<ResponseField name="resource_arn" type="string" required>
  The ARN (Amazon Resource Name) of the resource to be protected. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  One or more tag key-value pairs for the Protection object. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value component of a tag key-value pair attached to an AWS Shield Advanced protection resource, used to store metadata such as owner, environment, or cost center for resource organization and identity. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

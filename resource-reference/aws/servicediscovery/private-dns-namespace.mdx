`aws_service_discovery_private_dns_namespace` creates a real Cloud Map namespace backed by a private Route 53 hosted zone, resolvable only inside its associated VPCs, so `aws_service_discovery_service` names resolve to real DNS records rather than only being queryable through the API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicediscovery "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicediscovery"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own discovery private dns namespace"})

    		ubx.Resource(servicediscovery.PrivateDnsNamespace, "example", servicediscovery.PrivateDnsNamespaceConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Properties:  map[string]any{"dns_properties": map[string]any{"soa": map[string]any{"ttl": 1}}},
    			Tags:        []map[string]any{{"key": "example"}},
    			Vpc:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  A description of the namespace. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name that you want to assign to this namespace. When you create a private DNS namespace, AWS Cloud Map automatically creates an Amazon Route 53 private hosted zone that has the same name as the namespace. Required.
</ResponseField>

<ResponseField name="properties" type="object">
  Optional.
  <Expandable title="properties">
    <ResponseField name="dns_properties" type="object">
      Defines the DNS properties for the private namespace, specifically the SOA (Start of Authority) record settings that control the default DNS behavior for the namespace. Optional. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="soa" type="object">
          Configures the start of authority (SOA) record settings for the private DNS namespace, allowing you to set the time-to-live (TTL) for the SOA record. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="ttl" type="number">
              Specifies the time-to-live (TTL) in seconds for the SOA (Start of Authority) record of the private DNS namespace, controlling how long DNS resolvers cache the SOA information. Optional. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags for the namespace. Each tag consists of a key and an optional value, both of which you define. Tag keys can have a maximum character length of 128 characters, and tag values can have a maximum length of 256 characters. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vpc" type="string">
  The ID of the Amazon VPC that you want to associate the namespace with. Optional.
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the private namespace. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="hosted_zone_id" type="string">
  The ID for the Route 53 hosted zone that AWS Cloud Map creates when you create a namespace. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the private namespace. Computed by AWS after `ship`.
</ResponseField>

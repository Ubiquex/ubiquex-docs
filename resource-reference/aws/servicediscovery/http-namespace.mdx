`aws_service_discovery_http_namespace` creates a real Cloud Map namespace that supports only the HTTP discovery API, not DNS, for service discovery through the DiscoverInstances API call rather than a resolvable domain name, commonly used with ECS Service Connect.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	servicediscovery "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/servicediscovery"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own http namespace"})

    		ubx.Resource(servicediscovery.HttpNamespace, "example", servicediscovery.HttpNamespaceConfig{
    			Name:        "example",
    			Description: "Managed by ubx.",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.aws.servicediscovery import HttpNamespace, HttpNamespaceConfig
    from ubx.aws.servicediscovery.http_namespace import HttpNamespace_Tags

    def describe():
        ubx.intent("example own http namespace")

        ubx.resource(HttpNamespace, "example", HttpNamespaceConfig(
            name="example",
            description="Managed by ubx.",
            tags=[HttpNamespace_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="description" type="string">
  Provides an optional human-readable description for the HTTP namespace, helping to identify its purpose or distinguish it from other namespaces in service discovery. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the HTTP namespace, which must be unique within the AWS account and can contain up to 1024 characters. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Specifies a list of key-value tags to associate with the HTTP namespace, enabling you to organize, identify, and manage cost allocation for the namespace. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key (name) of a tag applied to the AWS CloudFormation Service Discovery HTTP namespace, forming the key half of a key-value tag pair. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) that uniquely identifies the HTTP namespace in AWS. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the HTTP namespace, assigned by AWS Cloud Map when the namespace is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

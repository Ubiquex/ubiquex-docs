`aws_doc_db_dbcluster_parameter_group` sets real, engine-level configuration for an `aws_doc_db_dbcluster`, kept as its own resource so the same parameter set can be applied consistently across multiple clusters.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	doc "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/doc"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own db dbcluster parameter group"})

    		ubx.Resource(doc.DbDbclusterParameterGroup, "example", doc.DbDbclusterParameterGroupConfig{
    			Description: "Managed by ubx.",
    			Family:      "example",
    			Parameters:  "example",
    			Name:        "example",
    			Tags:        []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="description" type="string" required>
  The description for the DB cluster parameter group. Required.
</ResponseField>

<ResponseField name="family" type="string" required>
  The DB cluster parameter group family name (e.g. docdb5.0). Required.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the DB cluster parameter group. If omitted, CloudFormation generates a unique name. The name is stored as lowercase. Optional.
</ResponseField>

<ResponseField name="parameters" type="any" required>
  An object containing key-value pairs of parameters to set for the DB cluster parameter group. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">

`aws_doc_db_event_subscription` subscribes a real SNS topic to receive notifications about events, failovers, backups, occurring on an `aws_doc_db_dbcluster` and its instances.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	doc "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/doc"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own db event subscription"})

    		ubx.Resource(doc.DbEventSubscription, "ci-runner", doc.DbEventSubscriptionConfig{
    			SnsTopicArn:      "arn:aws:iam::123456789012:policy/ci",
    			Enabled:          true,
    			EventCategories:  []string{"example"},
    			SourceIds:        []string{"example"},
    			SourceType:       "example",
    			SubscriptionName: "example-subscription-name",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="enabled" type="bool">
  A Boolean value; set to true to activate the subscription, set to false to create the subscription but not active it. Optional.
</ResponseField>

<ResponseField name="event_categories" type="list(string)">
  A list of event categories for a SourceType that you want to subscribe to. Optional.
</ResponseField>

<ResponseField name="sns_topic_arn" type="string" required>
  The Amazon Resource Name (ARN) of the SNS topic created for event notification. Amazon SNS creates the ARN when you create a topic and subscribe to it. Required.
</ResponseField>

<ResponseField name="source_ids" type="list(string)">
  The list of identifiers of the event sources for which events are returned Optional.
</ResponseField>

<ResponseField name="source_type" type="string">
  The type of source that is generating the events. Optional.
</ResponseField>

<ResponseField name="subscription_name" type="string">
  The name of the subscription. Optional.
</ResponseField>

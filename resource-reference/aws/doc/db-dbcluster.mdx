`aws_doc_db_dbcluster` creates a real Amazon DocumentDB cluster, MongoDB-API-compatible, with storage automatically replicated across Availability Zones, the container every `aws_doc_db_dbinstance` in a cluster-based deployment belongs to.

## Input properties

<ResponseField name="availability_zones" type="list(string)">
  The list of Availability Zones where the cluster's instances are distributed, enabling multi-AZ deployment for high availability. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="backup_retention_period" type="number">
  The number of days for which automated backups of the DocumentDB cluster are retained. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="copy_tags_to_snapshot" type="bool">
  Indicates whether to copy all tags from the DB cluster to snapshots of the cluster, so that the snapshots inherit the cluster's tags. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbcluster_identifier" type="string">
  Specifies a unique identifier for the DB cluster, which is stored as a lowercase string and used as the cluster's name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbcluster_parameter_group_name" type="string">
  The name of the DocumentDB cluster parameter group to associate with this DB cluster, which contains engine configuration values applied to all instances in the cluster. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dbsubnet_group_name" type="string">
  The name of the DB subnet group the DocumentDB cluster uses, which must contain subnets in at least two Availability Zones. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="deletion_protection" type="bool">
  When set to true, deletion protection is enabled for this DocumentDB cluster, preventing the cluster from being deleted via the AWS Management Console or API until deletion protection is explicitly disabled. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="enable_cloudwatch_logs_exports" type="list(string)">
  Specifies the log types (for example, 'audit' or 'profiler') that the DocumentDB cluster exports to Amazon CloudWatch Logs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="engine_version" type="string">
  Specifies the version number of the database engine (e.g., '4.0', '5.0') to use for the DocumentDB cluster. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="global_cluster_identifier" type="string">
  The identifier of the Amazon DocumentDB global cluster to which this DB cluster belongs, used to join a cluster to a global cluster that spans multiple regions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="kms_key_id" type="string">
  The AWS KMS key ID or ARN used to encrypt the storage for this DocumentDB cluster. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="manage_master_user_password" type="bool">
  Indicates whether the master user password is managed by AWS Secrets Manager, enabling automatic rotation and secure retrieval. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="master_user_password" type="string">

</ResponseField>

<ResponseField name="master_user_secret_kms_key_id" type="string">

</ResponseField>

<ResponseField name="master_username" type="string">
  The master username for the DocumentDB cluster, used to authenticate as the administrative user. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_type" type="string">
  Specifies the network type for the cluster, either IPV4 for IPv4 only or DUAL to support both IPv4 and IPv6 addressing. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="port" type="number">
  The port number on which the DocumentDB DB cluster accepts connections, defaulting to 27017. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="preferred_backup_window" type="string">

</ResponseField>

<ResponseField name="preferred_maintenance_window" type="string">

<ResponseField name="restore_to_time" type="string">

## Output properties

<ResponseField name="cluster_resource_id" type="string">
  The unique cluster resource identifier assigned by AWS when the DocDB cluster is created, used to construct the cluster ARN. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="endpoint" type="string">
  The endpoint is the read-only primary connection hostname for the DocumentDB cluster, used to connect applications to the cluster's primary instance. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  The cluster's unique identifier, which corresponds to the DB cluster's name as specified at creation time. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="read_endpoint" type="string">
  The reader endpoint for the DocumentDB cluster, which routes read connections to available replica instances. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

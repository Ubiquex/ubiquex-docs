`aws_refactor_spaces_environment` creates a real top-level container, a shared transit gateway and default settings, that `aws_refactor_spaces_application`s under AWS Migration Hub Refactor Spaces are organized inside while an application is incrementally strangled apart into microservices. Refactor Spaces closed to new customers on November 7, 2025, a date roughly nine months in the past; existing customers can continue their migrations, with AWS maintaining security and reliability but adding no new features, and pointing new work toward AWS Transform (launched May 2025) instead.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	refactorspaces "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/refactorspaces"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment"})

    		ubx.Resource(refactorspaces.Environment, "example", refactorspaces.EnvironmentConfig{
    			Name:              "example",
    			Description:       "Managed by ubx.",
    			NetworkFabricType: "example",
    			Tags:              []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

    import ubx_sdk as ubx
    from ubx.aws.refactorspaces import Environment, EnvironmentConfig
    from ubx.aws.refactorspaces.environment import Environment_Tags

    def describe():
        ubx.intent("example own environment")

        ubx.resource(Environment, "example", EnvironmentConfig(
            name="example",
            description="Managed by ubx.",
            network_fabric_type="example",
            tags=[Environment_Tags(key="example")],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="description" type="string">
  The description field is an optional string that holds a user-defined, human-readable description of the Refactor Spaces environment, used to provide additional context about the environment's purpose or contents. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  An optional friendly name for the environment; if you don't provide one, AWS Refactor Spaces automatically generates a unique name for the environment. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="network_fabric_type" type="string">
  Specifies the network fabric type for the Refactor Spaces environment, using either 'TRANSIT_GATEWAY' to create a transit gateway for service connectivity or 'NONE' to operate without a network fabric. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Metadata that you can assign to help organize the frameworks that you create. Each tag is a key-value pair. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined tag key to assign to the Refactor Spaces environment for metadata, cost allocation, and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag key attached to the AWS Refactor Spaces environment, typically used to store metadata such as environment purpose, owner, or cost center. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the AWS Migration Hub Refactor Spaces environment. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="environment_identifier" type="string">
  The unique identifier assigned by AWS Refactor Spaces to the environment when it is created. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="transit_gateway_id" type="string">
  The unique identifier of the transit gateway associated with this Refactor Spaces environment, assigned by AWS and returned as a read-only attribute after environment creation (relevant when the environment uses a transit gateway network fabric). Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_media_live_cloud_watch_alarm_template` defines a real reusable CloudWatch alarm configuration for MediaLive resources, which can be applied consistently across channels rather than hand-configured per channel.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own live cloud watch alarm template"})

    		ubx.Resource(media.LiveCloudWatchAlarmTemplate, "example", media.LiveCloudWatchAlarmTemplateConfig{
    			ComparisonOperator: "example",
    			EvaluationPeriods:  1,
    			MetricName:         "example-metric-name",
    			Name:               "example",
    			Period:             1,
    			Statistic:          "example",
    			TargetResourceType: "example",
    			Threshold:          1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="comparison_operator" type="string" required>
  The comparison operator used to compare the specified statistic and the threshold. Required.
</ResponseField>

<ResponseField name="datapoints_to_alarm" type="number">
  The number of datapoints within the evaluation period that must be breaching to trigger the alarm. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  A resource's optional description. Optional.
</ResponseField>

<ResponseField name="evaluation_periods" type="number" required>
  The number of periods over which data is compared to the specified threshold. Required.
</ResponseField>

<ResponseField name="group_identifier" type="string">
  A cloudwatch alarm template group's identifier. Can be either be its id or current name. Optional.
</ResponseField>

<ResponseField name="metric_name" type="string" required>
  The name of the metric associated with the alarm. Must be compatible with targetResourceType. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  A resource's name. Names must be unique within the scope of a resource type in a specific region. Required.
</ResponseField>

<ResponseField name="period" type="number" required>
  The period, in seconds, over which the specified statistic is applied. Required.
</ResponseField>

<ResponseField name="statistic" type="string" required>
  The statistic to apply to the alarm's metric data. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  Represents the tags associated with a resource. Optional.
</ResponseField>

<ResponseField name="target_resource_type" type="string" required>
  The resource type this template should dynamically generate cloudwatch metric alarms for. Required.
</ResponseField>

<ResponseField name="threshold" type="number" required>
  The threshold value to compare with the specified statistic. Required.
</ResponseField>

<ResponseField name="treat_missing_data" type="string" required>
  Specifies how missing data points are treated when evaluating the alarm's condition. Required.
</ResponseField>

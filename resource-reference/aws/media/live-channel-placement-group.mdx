`aws_media_live_channel_placement_group` organizes a real group of `aws_media_live_channel`s within an `aws_media_live_cluster`, so channels running on the same on-premises or Outposts infrastructure can be managed and allocated together.

## Input properties

<ResponseField name="cluster_id" type="string">
  The ID of the cluster the node is on. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the channel placement group. Optional.
</ResponseField>

<ResponseField name="nodes" type="list(string)">

</ResponseField>

<ResponseField name="tags" type="list(object)">

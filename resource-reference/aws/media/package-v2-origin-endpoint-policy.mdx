`aws_media_package_v2_origin_endpoint_policy` attaches a real resource-based access policy to an `aws_media_package_v2_origin_endpoint`, controlling which principals can retrieve the packaged output from that endpoint.

    <ResponseField name="cdn_identifier_secret_arns" type="list(string)" required>
      &lt;p&gt;The ARN for the secret in Secrets Manager that your CDN uses for authorization to access the endpoint.&lt;/p&gt; Required.
    </ResponseField>
    <ResponseField name="secrets_role_arn" type="string" required>
      &lt;p&gt;The ARN for the IAM role that gives MediaPackage read access to Secrets Manager and KMS for CDN authorization.&lt;/p&gt; Required.
    </ResponseField>
  </Expandable>
</ResponseField>

  Specifies the name of the MediaPackage v2 channel group that contains the origin endpoint to which this policy is attached. Required. **(AI-inferred)**

<ResponseField name="channel_name" type="string" required>

</ResponseField>

<ResponseField name="origin_endpoint_name" type="string" required>
  The name of the MediaPackage v2 origin endpoint that this resource attaches the IAM resource policy to. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="policy" type="any" required>

</ResponseField>

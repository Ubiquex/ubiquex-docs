`aws_media_tailor_live_source` registers a real live content feed under an `aws_media_tailor_source_location`, for use in MediaTailor channel assembly alongside video-on-demand sources.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tailor live source"})

    		ubx.Resource(media.TailorLiveSource, "example", media.TailorLiveSourceConfig{
    			HttpPackageConfigurations: []map[string]any{{"path": "example"}},
    			LiveSourceName:            "example-live-source-name",
    			SourceLocationName:        "example-source-location-name",
    			Tags:                      []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="http_package_configurations" type="list(object)" required>
  &lt;p&gt;A list of HTTP package configuration parameters for this live source.&lt;/p&gt; Required.
  <Expandable title="properties">
    <ResponseField name="path" type="string">
      Specifies the relative path to the HTTP media package, which MediaTailor appends to the source location's base URL to fetch the live content. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_group" type="string">
      Specifies the name of the source group to which this HTTP package configuration belongs, allowing MediaTailor to route playback requests to the correct source for a given package type (e.g., DASH or HLS). Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the streaming format (e.g., DASH or HLS) for this HTTP package configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="live_source_name" type="string" required>
  The name that uniquely identifies this live source within its MediaTailor source location. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="source_location_name" type="string" required>
  The name of the source location that contains this live source. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the live source. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Specifies the key for a tag associated with the AWS MediaTailor live source, enabling metadata-based resource management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The user-defined value portion of a tag key-value pair attached to the MediaTailor LiveSource, used for resource metadata, identification, and cost allocation. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_media_live_multiplex` creates a real MPEG-TS multiplex, a single transport stream that carries multiple encoded programs bundled together for broadcast delivery, distinct from an `aws_media_live_channel`'s single-program encoding role.

## Input properties

<ResponseField name="availability_zones" type="list(string)" required>
  A list of availability zones for the multiplex. Required.
</ResponseField>

<ResponseField name="destinations" type="list(object)">
  A list of the multiplex output destinations. Optional.
  <Expandable title="properties">

    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="multiplex_settings" type="object" required>
  A key-value pair to associate with a resource. Required.
  <Expandable title="properties">

      Maximum video buffer delay in milliseconds. Optional.

    <ResponseField name="transport_stream_bitrate" type="number" required>

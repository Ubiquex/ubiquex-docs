`aws_media_package_asset` ingests a real video-on-demand asset through an `aws_media_package_channel`, the original MediaPackage architecture's VOD counterpart to its live-streaming role.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own package asset"})

    		ubx.Resource(media.PackageAsset, "example", media.PackageAssetConfig{
    			Id:               "example",
    			PackagingGroupId: "example",
    			SourceArn:        "arn:aws:iam::123456789012:policy/example",
    			SourceRoleArn:    "arn:aws:iam::123456789012:policy/example",
    			ResourceId:       "example",
    			Tags:             []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="id" type="string" required>
  The unique identifier for the Asset. Required.
</ResponseField>

<ResponseField name="packaging_group_id" type="string" required>
  The ID of the PackagingGroup for the Asset. Required.
</ResponseField>

<ResponseField name="resource_id" type="string">
  The resource ID to include in SPEKE key requests. Optional.
</ResponseField>

<ResponseField name="source_arn" type="string" required>
  ARN of the source object in S3. Required.
</ResponseField>

<ResponseField name="source_role_arn" type="string" required>
  The IAM role_arn used to access the source S3 bucket. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of tags associated with a resource Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The ARN of the Asset. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The time the Asset was initially submitted for Ingest. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="egress_endpoints" type="list(object)">
  The list of egress endpoints available for the Asset. Computed by AWS after `ship`.
  <Expandable title="properties">
    <ResponseField name="packaging_configuration_id" type="string">
      The identifier of the AWS Elemental MediaPackage packaging configuration that defines how the asset is packaged (e.g., HLS or DASH) for delivery through this egress endpoint. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="url" type="string">
      The URL for this egress endpoint, which AWS Elemental MediaPackage generates to provide a streaming or download URL for the asset via the associated packaging configuration. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

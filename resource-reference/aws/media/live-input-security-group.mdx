`aws_media_live_input_security_group` defines a real set of allowed CIDR ranges that an `aws_media_live_input` accepts push-based input from, MediaLive's equivalent of a security group scoped to incoming video traffic.

## Input properties

<ResponseField name="tags" type="any">
  Optional.
</ResponseField>

<ResponseField name="whitelist_rules" type="list(object)">
  Specifies the list of IPv4 CIDR blocks (with optional descriptions) that are allowed to access the input security group, controlling which source IPs can send media content. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="cidr" type="string">
      The CIDR block that is allowed to send input requests to the MediaLive input security group. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

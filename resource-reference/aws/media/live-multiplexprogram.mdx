`aws_media_live_multiplexprogram` adds a real encoded program, video, audio, and metadata settings, into an `aws_media_live_multiplex`'s combined transport stream.

## Example

<Tabs>

    ```go

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own live multiplexprogram"})

    		ubx.Resource(media.LiveMultiplexprogram, "example", media.LiveMultiplexprogramConfig{
    			MultiplexId:              "example",
    			MultiplexProgramSettings: map[string]any{"program_number": 1},
    			PacketIdentifiersMap:     map[string]any{"audio_pids": []string{"example"}},
    			PipelineDetails:          []map[string]any{{"active_channel_pipeline": "example"}},
    			PreferredChannelPipeline: "example",
    			ProgramName:              "example-program-name",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="multiplex_id" type="string">
  The ID of the multiplex that the program belongs to. Optional.
</ResponseField>

<ResponseField name="multiplex_program_settings" type="object">
  Multiplex Program settings configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="preferred_channel_pipeline" type="string">
      Indicates which pipeline is preferred by the multiplex for program ingest. If set to \"PIPELINE_0\" or \"PIPELINE_1\" and an unhealthy ingest causes the multiplex to switch to the non-preferred pipeline, it will switch back once that ingest is healthy again. If set to \"CURRENTLY_ACTIVE\", it will not switch back to the other pipeline based on it recovering to a healthy state, it will only switch if the active pipeline becomes unhealthy. Optional.
    </ResponseField>
    <ResponseField name="program_number" type="number" required>
      Unique program number. Required.
    </ResponseField>
    <ResponseField name="service_descriptor" type="object">
      Transport stream service descriptor configuration for the Multiplex program. Optional.
      <Expandable title="properties">
        <ResponseField name="provider_name" type="string" required>
          Name of the provider. Required.
        </ResponseField>
        <ResponseField name="service_name" type="string" required>
          Name of the service. Required.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="video_settings" type="object">
      The video configuration for each program in a multiplex. Optional.
      <Expandable title="properties">
        <ResponseField name="constant_bitrate" type="number">
          The constant bitrate in bits per second for the video output of the MediaLive multiplex program, defining the fixed bitrate when the program's video settings use constant-bitrate encoding. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="statmux_settings" type="object">
          Specifies statistical multiplexing (statmux) settings for the program's video, including priority and minimum/maximum bitrate limits that control how bandwidth is dynamically allocated among programs within the MediaLive multiplex. Optional; if omitted, computed by AWS. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="maximum_bitrate" type="number">
              Specifies the maximum bitrate in bits per second that the video may use for this program when statistical multiplexing (statmux) is enabled, capping the bandwidth allocated to this program within the multiplex. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="minimum_bitrate" type="number">
              The minimum bitrate in bits per second that the video encoder will target for this multiplex program when statistical multiplexing is enabled, ensuring the program does not fall below this rate during allocation of multiplex bandwidth. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="priority" type="number">
              Sets the relative priority of this program's video within the statistical multiplex (statmux) group, where higher numbers cause the multiplexer to allocate bandwidth to this program before lower-priority programs when the total multiplex bandwidth is constrained. Optional; if omitted, computed by AWS. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="packet_identifiers_map" type="object">
  Packet identifiers map for a given Multiplex program. Optional.
  <Expandable title="properties">
    <ResponseField name="audio_pids" type="list(number)">
      Specifies the packet identifiers (PIDs) for the audio elementary streams in the MediaLive multiplex program. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="dvb_sub_pids" type="list(number)">
      Specifies the DVB Subtitle packet identifiers (PIDs) to associate with the multiplex program, used for delivering DVB subtitle streams through the multiplex. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="dvb_teletext_pid" type="number">
      Sets the DVB Teletext packet identifier (PID) used by the multiplex program's packet identifiers map. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="etv_platform_pid" type="number">
      Specifies the packet identifier (PID) for the Enhanced TV (ETV) platform service within the MPEG-2 transport stream of the MediaLive multiplex program. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="etv_signal_pid" type="number">
      Specifies the packet identifier (PID) for the Enhanced TV (ETV) signal within the multiplex program's packet identifiers map, used to carry ETV metadata in the MPEG-2 transport stream. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="klv_data_pids" type="list(number)">
      Configures the KLV (Key-Length-Value) data packet identifiers (PIDs) in the multiplex program's packet identifier map, specifying which PIDs carry KLV metadata in the output transport stream. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="pcr_pid" type="number">
      The Packet Identifier (PID) for the Program Clock Reference (PCR) stream, which carries timing information for the program in the MediaLive multiplex. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="pmt_pid" type="number">
      Specifies the packet identifier (PID) for the Program Map Table (PMT) in the multiplex program's MPEG-TS packet identifiers map. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="private_metadata_pid" type="number">
      Sets the packet identifier (PID) for the private metadata stream within the MPEG-2 transport stream of this MediaLive multiplex program. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="scte27_pids" type="list(number)">
      Specifies the packet identifiers (PIDs) used for SCTE-27 cue messages in the multiplex output. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="scte35_pid" type="number">
      The packet identifier (PID) for SCTE-35 messages in the multiplex program, used to carry ad insertion signaling. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="timed_metadata_pid" type="number">
      The packet identifier (PID) assigned for timed metadata (e.g., ID3 timed metadata) in the MPEG-TS output of the MediaLive multiplex program. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="video_pid" type="number">
      The PID (packet identifier) assigned to the video elementary stream in the MPEG-2 transport stream output of the MediaLive multiplex program. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pipeline_details" type="list(object)">
  Contains information about the current sources for the specified program in the specified multiplex. Keep in mind that each multiplex pipeline connects to both pipelines in a given source channel (the channel identified by the program). But only one of those channel pipelines is ever active at one time. Optional.
  <Expandable title="properties">
    <ResponseField name="active_channel_pipeline" type="string">
      Identifies which MediaLive channel pipeline (PIPELINE_0 or PIPELINE_1) is currently active for the multiplex program pipeline. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="pipeline_id" type="string">
      Identifies the MediaLive pipeline (0 or 1) for which the settings in this pipeline detail object apply. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="preferred_channel_pipeline" type="string">
  Indicates which pipeline is preferred by the multiplex for program ingest. If set to \"PIPELINE_0\" or \"PIPELINE_1\" and an unhealthy ingest causes the multiplex to switch to the non-preferred pipeline, it will switch back once that ingest is healthy again. If set to \"CURRENTLY_ACTIVE\", it will not switch back to the other pipeline based on it recovering to a healthy state, it will only switch if the active pipeline becomes unhealthy. Optional.
</ResponseField>

<ResponseField name="program_name" type="string">
  The name of the multiplex program. Optional.
</ResponseField>

## Output properties

<ResponseField name="channel_id" type="string">
  The MediaLive channel associated with the program. Computed by AWS after `ship`.
</ResponseField>

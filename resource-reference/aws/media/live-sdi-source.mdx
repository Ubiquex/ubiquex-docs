`aws_media_live_sdi_source` defines a real SDI (Serial Digital Interface) video input, hardware-connected rather than network-streamed, for MediaLive Anywhere to encode from an on-premises `aws_media_live_cluster`.

## Input properties

<ResponseField name="mode" type="string">
  The current state of the SdiSource. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the SdiSource. Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of key-value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a user-defined tag applied to the SDI source. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string" required>
  The interface mode of the SdiSource. Required.
</ResponseField>

`aws_media_convert_queue` creates a real queue that MediaConvert transcoding jobs are submitted to and processed from, in ACTIVE or PAUSED state, with jobs of equal priority processed in the order they were submitted.

## Input properties

<ResponseField name="concurrent_jobs" type="number">
  The maximum number of concurrent transcoding jobs that this MediaConvert queue can process at the same time. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  An optional user-defined description of the MediaConvert queue, used to identify its purpose in the AWS Elemental MediaConvert console. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="maximum_concurrent_feeds" type="number">
  Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the MediaConvert queue; if omitted, AWS Elemental MediaConvert automatically generates a unique queue name. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="pricing_plan" type="string">
  The pricing plan for the queue, either ON_DEMAND or RESERVED, which determines how you are billed for MediaConvert jobs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="status" type="string">
  The status of the MediaConvert queue, either ACTIVE or PAUSED, which controls whether it can accept and process new jobs. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="any">
  Assigns key-value tags to the MediaConvert queue, enabling cost allocation, access control, and resource categorization. Optional. **(AI-inferred)**
</ResponseField>

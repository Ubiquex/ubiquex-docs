`aws_media_convert_preset` saves real, reusable encoding settings for a single output within an `aws_media_convert_job_template` or job, letting the same output configuration, resolution, codec, bitrate, be applied across multiple jobs and overridden per job when needed.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    			Name:         "example",

    			Tags:         "example",
    		})
    	}))
    }

## Input properties

<ResponseField name="category" type="string">
  The new category for the preset, if you are changing it. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  The new description for the preset, if you are changing it. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the preset that you are modifying. Optional.
</ResponseField>

<ResponseField name="settings_json" type="any" required>
  Specify, in JSON format, the transcoding job settings for this output preset. This specification must conform to the AWS Elemental MediaConvert job validation. For information about forming this specification, see the Remarks section later in this topic. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  Defines the key-value tags applied to the MediaConvert preset, which can be used for categorizing, organizing, and tracking costs associated with the resource. Optional. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  The Amazon Resource Name (ARN) of the output preset, such as arn:aws:mediaconvert:us-west-2:123456789012 Computed by AWS after `ship`.
</ResponseField>

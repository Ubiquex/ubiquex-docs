`aws_media_tailor_channel_policy` attaches a real resource-based access policy to an `aws_media_tailor_channel`, controlling which principals can retrieve its assembled output.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tailor channel policy"})

    		ubx.Resource(media.TailorChannelPolicy, "example", media.TailorChannelPolicyConfig{
    			ChannelName: "example-channel-name",
    			Policy:      "example",
    		})
    	}))
    }
    ```

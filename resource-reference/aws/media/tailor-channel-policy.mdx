`aws_media_tailor_channel_policy` attaches a real resource-based access policy to an `aws_media_tailor_channel`, controlling which principals can retrieve its assembled output.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only aws --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-aws/sdk/go => ./local-sdk/aws/sdk/go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own tailor channel policy"})

    		ubx.Resource(media.TailorChannelPolicy, "ci-runner", media.TailorChannelPolicyConfig{
    			ChannelName: "example-channel-name",
    			Policy:      "example",
    		})
    	}))
    }
    ```

`aws_media_connect_flow_vpc_interface` attaches a real elastic network interface inside a VPC to an `aws_media_connect_flow`, letting the flow send or receive video privately within that VPC instead of over the public internet.

## Input properties

<ResponseField name="flow_arn" type="string" required>
  The Amazon Resource Name (ARN), a unique identifier for any AWS resource, of the flow. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  Immutable and has to be a unique against other VpcInterfaces in this Flow. Required.
</ResponseField>

<ResponseField name="role_arn" type="string" required>
  Role Arn MediaConnect can assume to create ENIs in customer's account. Required.
</ResponseField>

<ResponseField name="security_group_ids" type="list(string)" required>
  Security Group IDs to be used on ENI. Required.
</ResponseField>

<ResponseField name="subnet_id" type="string" required>
  Subnet must be in the AZ of the Flow Required.
</ResponseField>

<ResponseField name="tags" type="list(object)">
  Key-value pairs that can be used to tag and organize this VPC network interface. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag attached to the AWS Elemental MediaConnect flow VPC interface, used to organize and identify the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a tag assigned to the MediaConnect flow VPC interface, used for resource metadata and categorization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="network_interface_ids" type="list(string)">
  IDs of the network interfaces created in customer's account by MediaConnect. Computed by AWS after `ship`.
</ResponseField>

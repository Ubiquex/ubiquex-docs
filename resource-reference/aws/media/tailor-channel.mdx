`aws_media_tailor_channel` creates a real linear, assembled streaming channel under MediaTailor's channel assembly workflow, stitching together video-on-demand and live sources with personalized ad insertion into one continuous stream.

</ResponseField>

<ResponseField name="filler_slate" type="object">

      &lt;p&gt;The slate VOD source name. The VOD source must already exist in a source location before it can be used for slate.&lt;/p&gt; Optional.

<ResponseField name="log_configuration" type="object">

      &lt;p&gt;The log types.&lt;/p&gt; Optional.
    </ResponseField>
  </Expandable>

<ResponseField name="outputs" type="list(object)" required>
  &lt;p&gt;The channel's output properties.&lt;/p&gt; Required.
  <Expandable title="properties">
    <ResponseField name="dash_playlist_settings" type="object">
      Specifies the DASH manifest settings for the output, including the manifest window duration, minimum buffer time, and suggested presentation delay that MediaTailor uses when generating DASH content. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="manifest_window_seconds" type="number">
          Specifies the total duration in seconds of each DASH manifest window for this MediaTailor channel output. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="min_buffer_time_seconds" type="number">
          Specifies the minimum buffer time in seconds for DASH playlists generated by this MediaTailor channel. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="min_update_period_seconds" type="number">
          In an AWS MediaTailor channel's DASH output settings, this field sets the minimum update period in seconds for the DASH manifest, determining the lowest frequency at which MediaTailor can refresh the manifest. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="suggested_presentation_delay_seconds" type="number">
          Sets the suggested presentation delay duration (in seconds) for the DASH manifest of this MediaTailor channel output. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="hls_playlist_settings" type="object">
      The HLS playlist settings for this output, which define the ad marker formatting (such as DATERANGE or EXT-X-CUE-OUT) utilized in the generated HLS playlists. Optional; if omitted, computed by AWS. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="ad_markup_type" type="list(string)">
          Specifies the ad markup types for the HLS playlist output, with valid values of DATERANGE or SCTE35_ENHANCED, which determine how ad markers are represented in the channel's HLS playlists. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="manifest_window_seconds" type="number">
          The duration in seconds of the HLS manifest window for this output, controlling how much playback history is available in the playlist. Optional; if omitted, computed by AWS. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="manifest_name" type="string">
      The manifest name for this output, which appears as the filename in the playback manifest URL (e.g., index.m3u8 or index.mpd) that MediaTailor generates for the channel's output. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_group" type="string">
      The name of the source group that this output uses, matching one of the source groups defined in the channel's sources list. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="playback_mode" type="string" required>
  Specifies whether the MediaTailor channel plays content in a continuous loop (LOOP) or according to a linear schedule (LINEAR). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the channel. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      The key of a tag assigned to this MediaTailor channel, used to organize and identify the channel for cost allocation and access control. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag attached to the MediaTailor channel, used to categorize and identify the channel for cost allocation and management. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tier" type="string">
  The pricing tier for the channel, which determines the feature set and cost, with allowed values `basic` and `standard`. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="time_shift_configuration" type="object">
  &lt;p&gt;The configuration for time-shifted viewing.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="max_time_delay_seconds" type="number" required>
      &lt;p&gt;The maximum time delay for time-shifted viewing. The minimum allowed maximum time delay is 0 seconds, and the maximum allowed maximum time delay is 21600 seconds (6 hours).&lt;/p&gt; Required.
    </ResponseField>
  </Expandable>
</ResponseField>

`aws_media_connect_gateway` creates a real on-premises software gateway that connects local infrastructure to AWS Elemental MediaConnect, the component an `aws_media_connect_bridge` uses to actually reach a data center.

## Example

## Input properties

<ResponseField name="egress_cidr_blocks" type="list(string)" required>
  The range of IP addresses that contribute content or initiate output requests for flows communicating with this gateway. These IP addresses should be in the form of a Classless Inter-Domain Routing (CIDR) block; for example, 10.0.0.0/16. Required.
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the gateway. This name can not be modified after the gateway is created. Required.
</ResponseField>

<ResponseField name="networks" type="list(object)" required>
  The list of networks in the gateway. Required.
  <Expandable title="properties">
    <ResponseField name="cidr_block" type="string">
      CIDR block of the subnet where the gateway's network interface resides, used to define the network's IP address range. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the network interface, used to identify it within the gateway. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="gateway_arn" type="string">
  The Amazon Resource Name (ARN) of the gateway. Computed by AWS after `ship`.
</ResponseField>

<ResponseField name="gateway_state" type="string">
  The current status of the gateway. Computed by AWS after `ship`.
</ResponseField>

`aws_media_live_signal_map` discovers and visualizes a real media supply chain, MediaLive channels, MediaConnect flows, and related resources, starting from a chosen entry point ARN, and can attach `aws_media_live_cloud_watch_alarm_template`s and `aws_media_live_event_bridge_rule_template`s across everything it discovers.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own live signal map"})

    		ubx.Resource(media.LiveSignalMap, "example", media.LiveSignalMapConfig{
    			DiscoveryEntryPointArn:                  "arn:aws:iam::123456789012:policy/example",
    			Name:                                    "example",
    			CloudWatchAlarmTemplateGroupIdentifiers: []string{"example"},
    			Description:                             "Managed by ubx.",
    			EventBridgeRuleTemplateGroupIdentifiers: []string{"example"},
    			ForceRediscovery:                        true,
    			Tags:                                    "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cloud_watch_alarm_template_group_identifiers" type="list(string)">
  Specifies the list of CloudWatch alarm template group identifiers (typically ARNs) that this MediaLive signal map references, so that the alarms defined in those template groups are applied to the signal map for monitoring. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  A resource's optional description. Optional.
</ResponseField>

<ResponseField name="discovery_entry_point_arn" type="string" required>
  A top-level supported AWS resource ARN to discovery a signal map from. Required.
</ResponseField>

<ResponseField name="event_bridge_rule_template_group_identifiers" type="list(string)">
  Specifies the list of EventBridge rule template group identifiers to associate with this AWS Elemental MediaLive signal map, enabling the signal map to use the event rules from those groups for monitoring and alerting. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="force_rediscovery" type="bool">
  If true, will force a rediscovery of a signal map if an unchanged discoveryEntryPointArn is provided. Optional.
</ResponseField>

<ResponseField name="name" type="string" required>
  A resource's name. Names must be unique within the scope of a resource type in a specific region. Required.
</ResponseField>

<ResponseField name="tags" type="any">
  Represents the tags associated with a resource. Optional.
</ResponseField>

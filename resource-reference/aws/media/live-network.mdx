`aws_media_live_network` defines a real network configuration, IP pools and routes, that MediaLive Anywhere uses so channels running on an `aws_media_live_cluster` can reach on-premises or Outposts network resources.

## Example

    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own live network"})

    			Name:    "example",
    			Routes:  []map[string]any{{"cidr": "example"}},

    		})
    	}))
    }

## Input properties

<ResponseField name="ip_pools" type="list(object)" required>
  The list of IP address cidr pools for the network Required.
  <Expandable title="properties">
    <ResponseField name="cidr" type="string">
      Specifies the CIDR block address range for an IP pool in the MediaLive network, defining the subnet of IP addresses that can be used. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The user-specified name of the Network to be created. Required.
</ResponseField>

<ResponseField name="routes" type="list(object)">
  The routes for the network Optional.
  <Expandable title="properties">
    <ResponseField name="cidr" type="string">
      The destination CIDR block (e.g., '10.0.0.0/16') for a static route in the MediaLive network, used to direct matching traffic to the associated gateway. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="gateway" type="string">
      The IPv4 gateway address (next hop) used by the MediaLive network route to reach the destination CIDR for network traffic. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A collection of key-value pairs. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag applied to the AWS MediaLive network, allowing you to attach arbitrary metadata such as environment, team, or cost center for resource organization and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

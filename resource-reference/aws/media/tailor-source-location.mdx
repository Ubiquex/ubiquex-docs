`aws_media_tailor_source_location` registers a real origin server, an S3 bucket, web server, CDN, or packaging origin such as MediaPackage, that MediaTailor fetches content manifests from to assemble its own sliding manifest window.

## Input properties

<ResponseField name="access_configuration" type="object">
  &lt;p&gt;Access configuration parameters.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="access_type" type="string">
      Determines the access method for the source location, with valid values `S3_SIGV4` for authenticated Amazon S3 access and `STREAMING` for streaming-based access. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="secrets_manager_access_token_configuration" type="object">
      &lt;p&gt;AWS Secrets Manager access token configuration parameters. For information about Secrets Manager access token authentication, see &lt;a href="https://docs.aws.amazon.com/mediatailor/latest/ug/channel-assembly-access-configuration-access-token.html"&gt;Working with AWS Secrets Manager access token authentication&lt;/a&gt;.&lt;/p&gt; Optional.
      <Expandable title="properties">
        <ResponseField name="header_name" type="string">
          &lt;p&gt;The name of the HTTP header used to supply the access token in requests to the source location.&lt;/p&gt; Optional.
        </ResponseField>
        <ResponseField name="secret_arn" type="string">
          &lt;p&gt;The Amazon Resource Name (ARN) of the AWS Secrets Manager secret that contains the access token.&lt;/p&gt; Optional.
        </ResponseField>
        <ResponseField name="secret_string_key" type="string">
          &lt;p&gt;The AWS Secrets Manager &lt;a href="https://docs.aws.amazon.com/secretsmanager/latest/apireference/API_CreateSecret.html#SecretsManager-CreateSecret-request-SecretString.html"&gt;SecretString&lt;/a&gt; key associated with the access token. MediaTailor uses the key to look up SecretString key and value pair containing the access token.&lt;/p&gt; Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="default_segment_delivery_configuration" type="object">
  &lt;p&gt;The optional configuration for a server that serves segments. Use this if you want the segment delivery server to be different from the source location server. For example, you can configure your source location server to be an origination server, such as MediaPackage, and the segment delivery server to be a content delivery network (CDN), such as CloudFront. If you don't specify a segment delivery server, then the source location server is used.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="base_url" type="string">
      &lt;p&gt;The hostname of the server that will be used to serve segments. This string must include the protocol, such as &lt;b&gt;https://&lt;/b&gt;.&lt;/p&gt; Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="http_configuration" type="object" required>
  &lt;p&gt;The HTTP configuration for the source location.&lt;/p&gt; Required.
  <Expandable title="properties">
    <ResponseField name="base_url" type="string" required>
      &lt;p&gt;The base URL for the source location host server. This string must include the protocol, such as &lt;b&gt;https://&lt;/b&gt;.&lt;/p&gt; Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="segment_delivery_configurations" type="list(object)">
  &lt;p&gt;A list of the segment delivery configurations associated with this resource.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="base_url" type="string">
      Specifies the base URL from which MediaTailor retrieves content segments for the source location, serving as the origin for segment delivery. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the segment delivery configuration, which uniquely identifies this configuration within the source location. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="source_location_name" type="string" required>
  The unique name that identifies this AWS Elemental MediaTailor source location, required when creating the resource and used to reference it in other MediaTailor APIs and resources. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the source location. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A user-defined tag key assigned to this AWS MediaTailor source location for resource organization and identification. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value portion of a key-value user-defined tag applied to the MediaTailor source location, used for identifying, organizing, and managing the resource. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

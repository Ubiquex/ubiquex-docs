---
title: "aws_media_store_container"
description: "`aws_media_store_container` was a real storage container for live video origination in AWS Elemental MediaStore."
---

MediaStore is now fully discontinued: AWS ended access to the MediaStore console and MediaStore resources on November 13, 2025, a date now in the past, recommending migration to S3 for simple live-streaming workflows or to MediaPackage for advanced ones. This resource describes a service no longer operable rather than a current one.

`aws_media_package_v2_channel` creates a real entry point that receives a live video stream from an encoder such as MediaLive, MediaPackage v2's redesigned channel resource, which supports low-latency HLS and ingesting via the CMAF-ingest protocol in addition to HLS, distinct from the original `aws_media_package_channel`.

## Input properties

<ResponseField name="channel_group_name" type="string" required>
  The name of the MediaPackage v2 channel group that this channel belongs to, used as part of the channel's identifier and required when creating or referencing the channel. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="channel_name" type="string" required>
  The human-readable name of the AWS MediaPackage v2 channel, which must be unique within an AWS account and is incorporated into the channel's Amazon Resource Name (ARN). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string">
  &lt;p&gt;Enter any descriptive text that helps you to identify the channel.&lt;/p&gt; Optional.
</ResponseField>

<ResponseField name="input_switch_configuration" type="object">
  &lt;p&gt;The configuration for input switching based on the media quality confidence score (MQCS) as provided from AWS Elemental MediaLive.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="mqcsinput_switching" type="bool">
      &lt;p&gt;When true, AWS Elemental MediaPackage performs input switching based on the MQCS. Default is false. This setting is valid only when &lt;code&gt;InputType&lt;/code&gt; is &lt;code&gt;CMAF&lt;/code&gt;.&lt;/p&gt; Optional.
    </ResponseField>
    <ResponseField name="preferred_input" type="number">
      &lt;p&gt;For CMAF inputs, indicates which input MediaPackage should prefer when both inputs have equal MQCS scores. Select &lt;code&gt;1&lt;/code&gt; to prefer the first ingest endpoint, or &lt;code&gt;2&lt;/code&gt; to prefer the second ingest endpoint. If you don't specify a preferred input, MediaPackage uses its default switching behavior when MQCS scores are equal.&lt;/p&gt; Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="input_type" type="string">
  Specifies the input type of the channel, which determines whether incoming content is in HLS or CMAF format, with allowed values 'HLS' and 'CMAF'. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="output_header_configuration" type="object">
  &lt;p&gt;The settings for what common media server data (CMSD) headers AWS Elemental MediaPackage includes in responses to the CDN.&lt;/p&gt; Optional.
  <Expandable title="properties">
    <ResponseField name="publish_mqcs" type="bool">
      &lt;p&gt;When true, AWS Elemental MediaPackage includes the MQCS in responses to the CDN. This setting is valid only when &lt;code&gt;InputType&lt;/code&gt; is &lt;code&gt;CMAF&lt;/code&gt;.&lt;/p&gt; Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="output_locking_mode" type="string">
  Specifies the output locking mode of the MediaPackage v2 channel, which enforces consistent segment timing and alignment across all of the channel's packaging endpoints to enable synchronized downstream playback and failover. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  A list of Tag objects (each with Key and Value) that you can attach to a MediaPackage v2 channel to add metadata for organization, access control, and cost tracking. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Optional; if omitted, computed by AWS.
    </ResponseField>
    <ResponseField name="value" type="string">
      Specifies the value part of a tag assigned to the MediaPackage v2 channel, allowing custom metadata to be associated with the channel. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

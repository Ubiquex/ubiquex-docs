`aws_media_tailor_vod_source` registers a real video-on-demand asset under an `aws_media_tailor_source_location`, for use in MediaTailor channel assembly alongside live sources.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	media "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/media"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tailor vod source"})

    		ubx.Resource(media.TailorVodSource, "example", media.TailorVodSourceConfig{
    			HttpPackageConfigurations: []map[string]any{{"path": "example"}},
    			SourceLocationName:        "example-source-location-name",
    			VodSourceName:             "example-vod-source-name",
    			Tags:                      []map[string]any{{"key": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="http_package_configurations" type="list(object)" required>
  &lt;p&gt;A list of HTTP package configuration parameters for this VOD source.&lt;/p&gt; Required.
  <Expandable title="properties">
    <ResponseField name="path" type="string">
      The relative path to the manifest file (e.g., /path/to/index.m3u8) for the HTTP package configuration of the VOD source. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="source_group" type="string">
      The source group name that groups this HTTP package configuration with others in the same VOD source, used by MediaTailor to select the appropriate manifest during playback. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="type" type="string">
      Specifies the type of media packaging for this HTTP package configuration, which must be either HLS or DASH. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="source_location_name" type="string" required>
  The name of the MediaTailor source location that this VOD source is associated with; the source location defines the origin server and delivery settings for the media content. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(object)">
  The tags to assign to the VOD source. Optional.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      A key in the user-defined tag map applied to the MediaTailor VOD source resource, used for metadata and resource organization. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The value of a user-defined tag assigned to the MediaTailor VOD source, serving as the value portion of a key-value metadata pair. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vod_source_name" type="string" required>
  A unique identifier for the VOD source within its MediaTailor location, used when referencing the source in playback configurations and other resources. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="arn" type="string">
  &lt;p&gt;The ARN of the VOD source.&lt;/p&gt; Computed by AWS after `ship`.
</ResponseField>

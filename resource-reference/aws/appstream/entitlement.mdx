`aws_app_stream_entitlement` controls access to specific applications in an AppStream stack based on SAML assertions from the identity provider, letting access to individual applications, not just to a stack as a whole, be driven by real group membership or attributes asserted at sign-in.

## Example

    ```go
    package main

    import (
    	appstream "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appstream"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entitlement"})

    		ubx.Resource(appstream.Entitlement, "example", appstream.EntitlementConfig{
    			AppVisibility: "example",
    			Attributes:    []map[string]any{{"name": "example-name"}},
    			Name:          "example",
    			StackName:     "example-stack-name",
    			Description:   "Managed by ubx.",
    		})
    	}))
    }
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.aws.appstream import Entitlement, EntitlementConfig
    from ubx.aws.appstream.entitlement import Entitlement_Attributes

    def describe():
        ubx.intent("example own entitlement")

        ubx.resource(Entitlement, "example", EntitlementConfig(
            app_visibility="example",
            attributes=[Entitlement_Attributes(name="example-name")],
            name="example",
            stack_name="example-stack-name",
            description="Managed by ubx.",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="app_visibility" type="string" required>
  Specifies whether the entitlement grants access to all applications in the stack ('ALL') or only to applications explicitly associated with the entitlement ('ASSOCIATED'). Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="attributes" type="list(object)" required>
  A list of key-value attribute pairs that define the entitlement's user-specific settings, such as a user group membership or rule, which AppStream matches against the user's identity to determine which applications they can access. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The unique name assigned to the AppStream 2.0 entitlement, used to reference the entitlement within its stack. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The 'Value' field of a single attribute in the list of attributes attached to an AWS AppStream 2.0 entitlement, providing the string value associated with the attribute's Name. Optional; if omitted, computed by AWS. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A text description of the entitlement that helps administrators identify its purpose or usage within the AppStream 2.0 stack. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  Specifies the unique name for the AppStream 2.0 entitlement, used as the primary identifier within its parent stack. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="stack_name" type="string" required>
  The name of the AppStream stack that this entitlement is associated with, specifying which stack the entitlement grants access to. Required. **(AI-inferred)**
</ResponseField>

`aws_app_stream_fleet` provisions the streaming instances, EC2 instances made available one-per-user for the duration of a session, that run the applications and desktops an `aws_app_stream_stack` streams. The instance is terminated automatically once the session ends.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	appstream "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/appstream"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream fleet"})

    		ubx.Resource(appstream.Fleet, "example", appstream.FleetConfig{
    			InstanceType:               "example",
    			Name:                       "example",
    			ComputeCapacity:            map[string]any{"desired_instances": 1},
    			Description:                "Managed by ubx.",
    			DisableImdsv1:              true,
    			DisconnectTimeoutInSeconds: 7200,
    			DisplayName:                "example-display-name",
    			DomainJoinInfo:             map[string]any{"directory_name": "example-directory-name"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="compute_capacity" type="object">
  Configures the compute capacity for the fleet by specifying the desired number of streaming instances. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="desired_instances" type="number">
      The desired number of streaming instances that AppStream 2.0 maintains in the fleet. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="desired_sessions" type="number">
      Specifies the desired number of concurrent streaming sessions for an On-Demand AppStream 2.0 fleet, which AppStream uses to scale the fleet's capacity. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A user-provided description that clarifies the purpose or use of the AppStream 2.0 fleet. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="disable_imdsv1" type="bool">
  When true, disables the use of the EC2 Instance Metadata Service version 1 (IMDSv1) on the streaming instances of this AppStream 2.0 fleet, forcing IMDSv2 for instance metadata access. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="disconnect_timeout_in_seconds" type="number">
  The maximum time in seconds that a streaming session remains active after a user disconnects before the session is terminated. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="display_name" type="string">
  A user-friendly name for the fleet that is displayed in the AppStream 2.0 console and to end users. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="domain_join_info" type="object">
  Specifies the Active Directory domain and organizational unit (OU) that the fleet's streaming instances will join, including the directory name and OU distinguished name, to enable domain authentication. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="directory_name" type="string">
      Specifies the fully qualified name of the Active Directory domain (e.g., corp.example.com) that the AppStream 2.0 streaming instances will join when the fleet is launched. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="organizational_unit_distinguished_name" type="string">
      The distinguished name of the organizational unit (OU) in Active Directory where the computer accounts for the streaming instances are created when they join the domain. Optional. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="enable_default_internet_access" type="bool">
  Indicates whether the fleet's streaming instances are given a default internet gateway, enabling users to access the internet from their streaming sessions. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="fleet_type" type="string">
  Specifies whether the AppStream 2.0 fleet uses Always On instances that run continuously or On Demand instances that start only when a user connects, governing instance provisioning and cost. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="iam_role_arn" type="string">
  The ARN of the IAM role that AppStream 2.0 assumes to call AWS APIs on behalf of the fleet's streaming instances. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="idle_disconnect_timeout_in_seconds" type="number">
  Specifies the number of seconds a user can remain idle in an AppStream 2.0 streaming session before being automatically disconnected, where 0 means no idle timeout is applied. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="image_arn" type="string">
  The ARN of the AppStream 2.0 image that the fleet uses to launch streaming instances. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="image_name" type="string">
  The name of the AppStream 2.0 image to use for the fleet's streaming instances, specified as an alternative to ImageArn. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="instance_type" type="string" required>
  The Amazon EC2 instance type (e.g., stream.standard.medium) that specifies the compute and memory resources for the streaming instances in the AppStream 2.0 fleet. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_concurrent_sessions" type="number">
  The maximum number of concurrent sessions that the fleet can support, limiting how many users can stream simultaneously. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_sessions_per_instance" type="number">
  Specifies the maximum number of concurrent streaming sessions that a single fleet instance can host, which AppStream 2.0 uses to determine how many instances to start and stop to meet capacity. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="max_user_duration_in_seconds" type="number">

</ResponseField>

<ResponseField name="name" type="string" required>
  The required name of the AppStream 2.0 fleet, which must be unique within the AWS account and Region. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="platform" type="string">
  Specifies the operating system platform for the fleet's streaming instances, with valid values of WINDOWS or AMAZON_LINUX2. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="root_volume_config" type="object">

  <Expandable title="properties">

</ResponseField>

<ResponseField name="session_script_s3_location" type="object">

`aws_verified_permissions_policy_template` defines a real, reusable Cedar policy template with placeholders for principal and resource, within an `aws_verified_permissions_policy_store`, so many similar policies (grant this specific user access to this specific document) can be instantiated from one template instead of writing each one out individually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	verifiedpermissions "github.com/ubiquex/ubx-sdk-aws/sdk/go/v2/aws/verifiedpermissions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own policy template"})

    		ubx.Resource(verifiedpermissions.PolicyTemplate, "example", verifiedpermissions.PolicyTemplateConfig{
    			PolicyStoreId: "example",
    			Statement:     "example",
    			Name:          "example",
    			Description:   "Managed by ubx.",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="description" type="string">
  Specifies an optional text description for the policy template, used to provide context about the template's intended purpose. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string">
  Optional.
</ResponseField>

<ResponseField name="policy_store_id" type="string" required>
  The ID of the policy store in which this policy template is created, associating the template with a specific Cedar policy store. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="statement" type="string" required>
  The Cedar policy statement, written in the Cedar policy language, that defines the authorization rules for this policy template, optionally using placeholders like ?principal and ?resource. Required. **(AI-inferred)**
</ResponseField>

## Output properties

<ResponseField name="policy_template_id" type="string">
  The unique identifier (UUID) assigned by Amazon Verified Permissions to the policy template, used to reference the template in policies and API operations. Computed by AWS after `ship`. **(AI-inferred)**
</ResponseField>

`aws_roles_anywhere_trust_anchor` establishes real trust in a certificate authority, an AWS Private CA or an external CA, so that on-premises servers holding a certificate issued by it can authenticate to AWS and assume an `aws_roles_anywhere_profile`'s IAM role without long-lived access keys.

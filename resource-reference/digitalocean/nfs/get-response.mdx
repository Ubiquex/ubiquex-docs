`digitalocean_nfs_get_response` looks up a real, already-provisioned NFS share -- a network file-storage volume, its performance tier, size, and the VPCs allowed to mount it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	nfs "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/nfs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own get response"})

    		ubx.Resource(nfs.GetResponse, "example", nfs.GetResponseConfig{
    			Name:            "example",
    			NfsId:           "example",
    			Region:          "example",
    			SizeGib:         1,
    			VpcIds:          []string{"example"},
    			PerformanceTier: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  The human-readable name of the share. Required.
</ResponseField>

<ResponseField name="nfs_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="performance_tier" type="string">
  The performance tier of the share. Optional.
</ResponseField>

<ResponseField name="region" type="string" required>
  The DigitalOcean region slug (e.g., nyc2, atl1) where the NFS share resides. Required.
</ResponseField>

<ResponseField name="size_gib" type="number" required>
  The desired/provisioned size of the share in GiB (Gibibytes). Must be &gt;= 50. Required.
</ResponseField>

<ResponseField name="vpc_ids" type="list(string)" required>
  List of VPC IDs that should be able to access the share. Required.
</ResponseField>

`digitalocean_image` looks up a real, already-available image -- a Droplet base OS, a DigitalOcean-provided one-click application, or a custom snapshot/backup image usable to create new Droplets.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	images "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/images"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own image"})

    		ubx.Resource(images.Image, "example", images.ImageConfig{
    			ImageId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Image } from "@ubx/sdk-digitalocean/digitalocean/images/image";

    export default stack("example", () => {
      intent({ summary: "example own image" });

      resource(Image, "example", {
        imageId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.images import Image, ImageConfig

    def describe():

            image_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="image_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="image" type="object">
  The image's own real, current representation. Computed by DigitalOcean after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="created_at" type="string">
      A time value given in ISO8601 combined date and time format that represents when the image was created. Optional.
    </ResponseField>
    <ResponseField name="description" type="string">
      An optional free-form text field to describe an image. Optional.
    </ResponseField>
    <ResponseField name="distribution" type="string">
      The name of a custom image's distribution. Currently, the valid values are `Arch Linux`, `CentOS`, `CoreOS`, `Debian`, `Fedora`, `Fedora Atomic`, `FreeBSD`, `Gentoo`, `openSUSE`, `RancherOS`, `Rocky Linux`, `Ubuntu`, and `Unknown`. Any other value will be accepted but ignored, and `Unknown` will be used in its place. Optional.
    </ResponseField>
    <ResponseField name="error_message" type="string">
      A string containing information about errors that may occur when importing a custom image. Optional.
    </ResponseField>
    <ResponseField name="id" type="number">
      A unique number that can be used to identify and reference a specific image. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="min_disk_size" type="number">
      The minimum disk size in GB required for a Droplet to use this image. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name that has been given to an image. This is what is shown in the control panel and is generally a descriptive title for the image in question. Optional.
    </ResponseField>
    <ResponseField name="public" type="bool">
      This is a boolean value that indicates whether the image in question is public or not. An image that is public is available to all accounts. A non-public image is only accessible from your account. Optional.
    </ResponseField>
    <ResponseField name="regions" type="list(string)">
      This attribute is an array of the regions that the image is available in. The regions are represented by their identifying slug values. Optional.
    </ResponseField>
    <ResponseField name="size_gigabytes" type="number">
      The size of the image in gigabytes. Optional.
    </ResponseField>
    <ResponseField name="slug" type="string">
      A uniquely identifying string that is associated with each of the DigitalOcean-provided public images. These can be used to reference a public image as an alternative to the numeric id. Optional.
    </ResponseField>
    <ResponseField name="status" type="string">
      A status string indicating the state of a custom image. This may be `NEW`, `available`, `pending`, `deleted`, or `retired`. Optional.
    </ResponseField>
    <ResponseField name="tags" type="list(string)">
      A flat array of tag names as strings to be applied to the resource. Tag names may be for either existing or new tags. &lt;br&gt;&lt;br&gt;Requires `tag:create` scope. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      Describes the kind of image. It may be one of `base`, `snapshot`, `backup`, `custom`, or `admin`. Respectively, this specifies whether an image is a DigitalOcean base OS image, user-generated Droplet snapshot, automatically created Droplet backup, user-provided virtual machine image, or an image used for DigitalOcean managed resources (e.g. DOKS worker nodes). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`digitalocean_byoip_prefix` looks up a real, already-registered Bring Your Own IP prefix -- an IP range an account owns outside DigitalOcean, brought into a region under DigitalOcean's own routing after a signed ownership attestation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	byoipprefixes "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/byoipprefixes"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own byoip prefix"})

    		ubx.Resource(byoipprefixes.ByoipPrefix, "example", byoipprefixes.ByoipPrefixConfig{
    			ByoipPrefixUuid: "example",
    			Prefix:          "example",
    			Region:          "example",
    			Signature:       "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="byoip_prefix_uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="prefix" type="string" required>
  The IP prefix in CIDR notation to bring Required.
</ResponseField>

<ResponseField name="region" type="string" required>
  The region where the prefix will be created Required.
</ResponseField>

<ResponseField name="signature" type="string" required>
  The signature hash for the prefix creation request Required.
</ResponseField>

`digitalocean_record` looks up a real, already-created DNS record inside a domain's own zone -- one A, CNAME, MX, TXT, or other record DigitalOcean's name servers actually serve.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	domainrecords "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/domainrecords"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own record"})

    		ubx.Resource(domainrecords.Record, "example", domainrecords.RecordConfig{
    			DomainName:     "example-domain-name",
    			DomainRecordId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Output properties

<ResponseField name="domain_record" type="object">
  The DNS record's own real, current representation. Computed by DigitalOcean after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="data" type="string">
      Variable data depending on record type. For example, the "data" value for an A record would be the IPv4 address to which the domain will be mapped. For a CAA record, it would contain the domain name of the CA being granted permission to issue certificates. Optional.
    </ResponseField>
    <ResponseField name="flags" type="number">
      An unsigned integer between 0-255 used for CAA records. Optional.
    </ResponseField>
    <ResponseField name="id" type="number">
      A unique identifier for each domain record. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="name" type="string">
      The host name, alias, or service being defined by the record. Optional.
    </ResponseField>
    <ResponseField name="port" type="number">
      The port for SRV records. Optional.
    </ResponseField>
    <ResponseField name="priority" type="number">
      The priority for SRV and MX records. Optional.
    </ResponseField>
    <ResponseField name="tag" type="string">
      The parameter tag for CAA records. Valid values are "issue", "issuewild", or "iodef" Optional.
    </ResponseField>
    <ResponseField name="ttl" type="number">
      This value is the time to live for the record, in seconds. This defines the time frame that clients can cache queried information before a refresh should be requested. Optional.
    </ResponseField>
    <ResponseField name="type" type="string" required>
      The type of the DNS record. For example: A, CNAME, TXT, ... Required.
    </ResponseField>
    <ResponseField name="weight" type="number">
      The weight for SRV records. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

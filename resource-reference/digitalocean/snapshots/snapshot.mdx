`digitalocean_snapshot` looks up a real, already-created snapshot -- a point-in-time image of a Droplet or a block storage volume, usable to create a new Droplet or volume from that exact saved state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	snapshots "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/snapshots"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own snapshot"})

    		ubx.Resource(snapshots.Snapshot, "example", snapshots.SnapshotConfig{
    			Name:       "example",
    			SnapshotId: "example",
    			VolumeId:   "example",
    			Tags:       []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="name" type="string" required>
  A human-readable name for the volume snapshot. Required.
</ResponseField>

<ResponseField name="snapshot_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="tags" type="list(string)">
  A flat array of tag names as strings to be applied to the resource. Tag names may be for either existing or new tags. &lt;br&gt;&lt;br&gt;Requires `tag:create` scope. Optional.
</ResponseField>

<ResponseField name="volume_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

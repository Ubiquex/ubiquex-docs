`digitalocean_config` looks up a real, already-set configuration value for a managed database cluster's own Kafka schema registry -- the compatibility level enforced for a given schema subject.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own config"})

    		ubx.Resource(databases.Config, "example", databases.ConfigConfig{
    			CompatibilityLevel:  "example",
    			DatabaseClusterUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Config } from "@ubx/sdk-digitalocean/digitalocean/databases/config";

    export default stack("example", () => {
      intent({ summary: "example own config" });

      resource(Config, "example", {
        compatibilityLevel: "example",
        databaseClusterUuid: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.databases import Config, ConfigConfig

    def describe():
        ubx.intent("example own config")

        ubx.resource(Config, "example", ConfigConfig(
            compatibility_level="example",
            database_cluster_uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="compatibility_level" type="string" required>
  The compatibility level of the schema registry. Required.
</ResponseField>

<ResponseField name="database_cluster_uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="subject_name" type="string">
  The name of the schema subject. Computed by DigitalOcean after `ship`.
</ResponseField>

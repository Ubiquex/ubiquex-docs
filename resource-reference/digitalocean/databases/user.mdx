`digitalocean_user` looks up a real, already-created database user inside a managed database cluster -- the credential a client authenticates with, distinct from the cluster's own default admin user.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user"})

    		ubx.Resource(databases.User, "example", databases.UserConfig{
    			DatabaseClusterUuid: "example",
    			Username:            "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only digitalocean --lang ts --out ./local-sdk

    export default stack("example", () => {
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.databases import User, UserConfig

            username="example",

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

<ResponseField name="user" type="object">

          A string specifying the authentication method to be used for connections to the MySQL user account. The valid values are `mysql_native_password` or `caching_sha2_password`. If excluded when creating a new user, the default for the version of MySQL in use will be used. As of MySQL 8.0, the default is `caching_sha2_password`. Required.
        </ResponseField>

    <ResponseField name="name" type="string" required>
      The name of a database user. Required.

            <ResponseField name="role" type="string">

Optional.

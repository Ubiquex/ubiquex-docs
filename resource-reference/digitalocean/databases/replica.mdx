`digitalocean_replica` looks up a real, already-created read-only replica of a managed database cluster -- a separate connection endpoint serving read traffic without adding load to the primary.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own replica"})

    		ubx.Resource(databases.Replica, "example", databases.ReplicaConfig{
    			DatabaseClusterUuid: "example",
    			ReplicaName:         "example-replica-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

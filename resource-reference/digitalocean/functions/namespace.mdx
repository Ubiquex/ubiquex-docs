`digitalocean_namespace` looks up a real, already-created Functions namespace -- the deployment boundary a set of related serverless functions is grouped and versioned under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	functions "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/functions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own namespace"})

    		ubx.Resource(functions.Namespace, "example", functions.NamespaceConfig{
    			Label:       "example",
    			NamespaceId: "example",
    			Region:      "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.functions import Namespace, NamespaceConfig

    def describe():

        ubx.resource(Namespace, "example", NamespaceConfig(
            label="example",
            namespace_id="example",
            region="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="label" type="string" required>
  The namespace's unique name. Required.
</ResponseField>

<ResponseField name="namespace_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="region" type="string" required>
  The [datacenter region](https://docs.digitalocean.com/products/platform/availability-matrix/#available-datacenters) in which to create the namespace. Required.
</ResponseField>

## Output properties

<ResponseField name="namespace" type="object">
  The Functions namespace's own real, current representation. Computed by DigitalOcean after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="api_host" type="string">
      The namespace's API hostname. Each function in a namespace is provided an endpoint at the namespace's hostname. Optional.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      UTC time string. Optional.
    </ResponseField>
    <ResponseField name="key" type="string">
      A random alpha numeric string. This key is used in conjunction with the namespace's UUID to authenticate a user to use the namespace via `doctl`, DigitalOcean's official CLI. Optional.
    </ResponseField>
    <ResponseField name="label" type="string">
      The namespace's unique name. Optional.
    </ResponseField>
    <ResponseField name="namespace" type="string">
      A unique string format of UUID with a prefix fn-. Optional.
    </ResponseField>
    <ResponseField name="region" type="string">
      The namespace's datacenter region. Optional.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      UTC time string. Optional.
    </ResponseField>
    <ResponseField name="uuid" type="string">
      The namespace's Universally Unique Identifier. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

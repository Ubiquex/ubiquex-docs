`digitalocean_autoscale` looks up a real, already-created Droplet autoscale pool -- the scaling configuration (resource-utilization-based or static) and Droplet template that governs how many Droplets a pool runs at any given time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dropletautoscalepools "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/dropletautoscalepools"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own autoscale"})

    		ubx.Resource(dropletautoscalepools.Autoscale, "example", dropletautoscalepools.AutoscaleConfig{
    			AutoscalePoolId: "example",
    			Config:          map[string]any{"cooldown_minutes": 1},
    			DropletTemplate: map[string]any{"image": "example", "region": "example", "size": "example", "ssh_keys": []string{"example"}},
    			Name:            "example",
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx
    from ubx.digitalocean.dropletautoscalepools import Autoscale, AutoscaleConfig
    from ubx.digitalocean.dropletautoscalepools.autoscale import Autoscale_AutoscalePool_Config, Autoscale_AutoscalePool_DropletTemplate

        ubx.intent("example own autoscale")

    if __name__ == "__main__":
        ubx.run("example", describe)

## Input properties

<ResponseField name="autoscale_pool_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="config" type="object" required>
  The scaling configuration for an autoscale pool, which is how the pool scales up and down (either by resource utilization or static configuration). Required.
  <Expandable title="properties">
    <ResponseField name="cooldown_minutes" type="number">
      Optional; if omitted, computed by DigitalOcean.
    </ResponseField>
    <ResponseField name="max_instances" type="number">
      Optional; if omitted, computed by DigitalOcean.
    </ResponseField>
    <ResponseField name="min_instances" type="number">
      Optional; if omitted, computed by DigitalOcean.
    </ResponseField>
    <ResponseField name="target_cpu_utilization" type="number">
      Optional; if omitted, computed by DigitalOcean.
    </ResponseField>
    <ResponseField name="target_memory_utilization" type="number">
      Optional; if omitted, computed by DigitalOcean.
    </ResponseField>
    <ResponseField name="target_number_instances" type="number">
      Optional; if omitted, computed by DigitalOcean.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="droplet_template" type="object" required>
  The real Droplet configuration new pool members are created from. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="image" type="string" required>
      The Droplet image to be used for all Droplets in the autoscale pool. You may specify the slug or the image ID. Required.
    </ResponseField>
    <ResponseField name="ipv6" type="bool">
      Assigns a unique IPv6 address to each of the Droplets in the autoscale pool. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name(s) to be applied to all Droplets in the autoscale pool. Optional.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The project that the Droplets in the autoscale pool will belong to. Requires `project:read` scope. Optional.
    </ResponseField>
    <ResponseField name="public_networking" type="bool">
      An optional boolean indicating whether the Droplets should be created with public networking or not. By default, all Droplets are created with public networking available. If explicitly set to `false`, only private networking will be enabled, and public networking will be disabled; currently this means that it will not have any public static or Reserved IPv4 or IPv6 address, nor can one be assigned later. If explicitly set to `false`, `ipv6` must also be `false`. Optional.
    </ResponseField>
    <ResponseField name="region" type="string" required>
      The datacenter in which all of the Droplets will be created. Required.
    </ResponseField>
    <ResponseField name="size" type="string" required>
      The Droplet size to be used for all Droplets in the autoscale pool. Required.
    </ResponseField>
    <ResponseField name="ssh_keys" type="list(string)" required>
      The SSH keys to be installed on the Droplets in the autoscale pool. You can either specify the key ID or the fingerprint. Requires `ssh_key:read` scope. Required.
    </ResponseField>
    <ResponseField name="tags" type="list(string)">
      The tags to apply to each of the Droplets in the autoscale pool. Requires `tag:read` scope. Optional.
    </ResponseField>
    <ResponseField name="user_data" type="string">
      A string containing user data that cloud-init consumes to configure a Droplet on first boot. User data is often a cloud-config file or Bash script. It must be plain text and may not exceed 64 KiB in size. Optional.
    </ResponseField>
    <ResponseField name="vpc_uuid" type="string">
      The VPC where the Droplets in the autoscale pool will be created. The VPC must be in the region where you want to create the Droplets. Requires `vpc:read` scope. Optional.
    </ResponseField>
    <ResponseField name="with_droplet_agent" type="bool">
      Installs the Droplet agent. This must be set to true to monitor Droplets for resource utilization scaling. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string" required>
  The human-readable name of the autoscale pool. This field cannot be updated Required.
</ResponseField>

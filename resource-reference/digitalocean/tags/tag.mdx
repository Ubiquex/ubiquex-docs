`digitalocean_tag` looks up a real, already-created tag -- the label attachable to Droplets, images, volumes, snapshots, and database clusters, along with the real, current count of resources it's applied to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	tags "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/tags"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tag"})

    		ubx.Resource(tags.Tag, "example", tags.TagConfig{
    			TagId: "example",
    			Name:  "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string">
  The name of the tag. Tags may contain letters, numbers, colons, dashes, and underscores. There is a limit of 255 characters per tag. **Note:** Tag names are case stable, which means the capitalization you use when you first create a tag is canonical. When working with tags in the API, you must use the tag's canonical capitalization. For example, if you create a tag named "PROD", the URL to add that tag to a resource would be `https://api.digitalocean.com/v2/tags/PROD/resources` (not `/v2/tags/prod/resources`). Tagged resources in the control panel will always display the canonical capitalization. For example, if you create a tag named "PROD", you can tag resources in the control panel by entering "prod". The tag will still display with its canonical capitalization, "PROD". Optional.
</ResponseField>

<ResponseField name="tag_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

This will only include resources that you are authorized to see. For example, to see tagged Droplets, include the `droplet:read` scope. Computed by DigitalOcean after `ship`.

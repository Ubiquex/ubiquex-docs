`digitalocean_vpc_peering` looks up a real, already-created VPC peering connection -- a private link routing traffic directly between two VPCs without traversing the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	vpcpeerings "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/vpcpeerings"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own vpc peering"})

    		ubx.Resource(vpcpeerings.VpcPeering, "example", vpcpeerings.VpcPeeringConfig{
    			VpcPeeringId: "example",
    		})
    	}))
    }
    ```
  </Tab>

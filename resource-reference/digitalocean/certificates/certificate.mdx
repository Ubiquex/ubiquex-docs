`digitalocean_certificate` looks up a real, already-uploaded or Let's Encrypt-issued TLS certificate, usable by a Load Balancer or CDN endpoint for the domains it covers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	certificates "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/certificates"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate"})

    		ubx.Resource(certificates.Certificate, "example", certificates.CertificateConfig{
    			CertificateId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only digitalocean --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";
    import { Certificate } from "./local-sdk/digitalocean/sdk/typescript/digitalocean/certificates/certificate.ts";

    export default stack("example", () => {
      intent({ summary: "example own certificate" });

      resource(Certificate, "example", {
        certificateId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only digitalocean --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/digitalocean/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.digitalocean.certificates import Certificate, CertificateConfig

    def describe():
        ubx.intent("example own certificate")

        ubx.resource(Certificate, "example", CertificateConfig(
            certificate_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="certificate_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="certificate" type="object">
  The certificate's own real, current representation. Computed by DigitalOcean after `ship`. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="created_at" type="string">
      A time value given in ISO8601 combined date and time format that represents when the certificate was created. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="dns_names" type="list(string)">
      An array of fully qualified domain names (FQDNs) for which the certificate was issued. Optional.
    </ResponseField>
    <ResponseField name="id" type="string">
      A unique ID that can be used to identify and reference a certificate. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="name" type="string">
      A unique human-readable name referring to a certificate. Optional.
    </ResponseField>
    <ResponseField name="not_after" type="string">
      A time value given in ISO8601 combined date and time format that represents the certificate's expiration date. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="sha1_fingerprint" type="string">
      A unique identifier generated from the SHA-1 fingerprint of the certificate. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="state" type="string">
      A string representing the current state of the certificate. It may be `pending`, `verified`, or `error`. Computed by DigitalOcean after `ship`.
    </ResponseField>
    <ResponseField name="type" type="string">
      A string representing the type of the certificate. The value will be `custom` for a user-uploaded certificate or `lets_encrypt` for one automatically generated with Let's Encrypt. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

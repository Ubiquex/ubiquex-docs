`digitalocean_alert` looks up a real, already-configured monitoring alert policy -- the threshold, comparison, and window that decide when DigitalOcean's own Monitoring service fires a notification for a tagged set of Droplets or other monitored entities.

## Input properties

<ResponseField name="alert_uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="alerts" type="object" required>
  The real conditions that trigger this alert policy. Required. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="email" type="list(string)" required>
      An email to notify on an alert trigger. Required.
    </ResponseField>
    <ResponseField name="slack" type="list(object)" required>
      Slack integration details. Required.
      <Expandable title="properties">
        <ResponseField name="channel" type="string">
          Optional; if omitted, computed by DigitalOcean.
        </ResponseField>
        <ResponseField name="url" type="string">
          Optional; if omitted, computed by DigitalOcean.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="compare" type="string" required>
  The real comparison operator (greater than or less than) used against the threshold value. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="description" type="string" required>
  A real, human-readable description of the alert policy. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="enabled" type="bool" required>
  Whether the alert policy is currently active. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="entities" type="list(string)" required>
  The real IDs of the entities this alert policy monitors. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="tags" type="list(string)" required>
  The real tags this alert policy applies to, in addition to any explicitly listed entities. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="type" type="string" required>
  The real type of metric this alert policy monitors. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="value" type="number" required>
  The real threshold value that triggers this alert. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="window" type="string" required>
  The real time window the metric is evaluated over before triggering. Required. **(AI-inferred)**
</ResponseField>

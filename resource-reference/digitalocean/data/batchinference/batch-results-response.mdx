## Example

    package main

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_batch_results_response"})

    		ubx.Data(batchinference.BatchResultsResponse, "example", batchinference.BatchResultsResponseConfig{
    			BatchId: "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="batch_id" type="string" required>
  The ID of the batch inference job to retrieve results for. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="error_file_url" type="string">
  Presigned URL for the error sidecar JSONL, if any. Returned by the lookup.
</ResponseField>

<ResponseField name="expires_at" type="string">
  When the presigned URLs expire. Returned by the lookup.
</ResponseField>

<ResponseField name="output_file_url" type="string">
  Presigned URL for the main results JSONL. Returned by the lookup.
</ResponseField>

<ResponseField name="result_available" type="bool">
  When `false`, keep polling batch status and retry later. Returned by the lookup.
</ResponseField>

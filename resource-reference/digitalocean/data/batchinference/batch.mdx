`data_digitalocean_batch` lists the real, already-submitted Gradient AI Platform batch inference jobs, paginated with cursor-based `after`/`first_id`/`last_id` navigation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	batchinference "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/batchinference"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_batch"})

    		ubx.Data(batchinference.Batch, "example", batchinference.BatchConfig{
    			After:  "example",
    			Limit:  1,
    			Status: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="after" type="string">
  Returns batch jobs created after this real cursor ID, for pagination. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of batch jobs to return in one page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  Filters batch jobs by their real, current status. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="data" type="list(object)">
  Batch jobs on this page, ordered newest first. Returned by the lookup.
</ResponseField>

<ResponseField name="first_id" type="string">
  ID of the first batch on this page. Null when the page is empty. Returned by the lookup.
</ResponseField>

<ResponseField name="has_more" type="bool">
  Whether additional batches exist beyond this page. Returned by the lookup.
</ResponseField>

<ResponseField name="last_id" type="string">
  ID of the last batch on this page. Pass as `after` to fetch the next page. Returned by the lookup.
</ResponseField>

<ResponseField name="object" type="string">
  The object type, always `list`. Returned by the lookup.
</ResponseField>

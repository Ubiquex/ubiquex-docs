## Example

    package main

    import (
    	domains "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/domains"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_domain"})

    		ubx.Data(domains.Domain, "example", domains.DomainConfig{
    			DomainName: "example-domain-name",
    			Name:       "example",
    			Page:       1,
    			PerPage:    1,
    			Type:       "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="domain_name" type="string" required>
  The name of the domain to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="name" type="string">
  Filters domains by their real, exact name. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string">
  Filters domains by real record type present in the zone. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The ID of the App Platform application this job belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="deployment_id" type="string">
  The ID of the deployment this job invocation ran under. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="job_names" type="list(string)">
  Filters results to invocations of these real job component names only. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

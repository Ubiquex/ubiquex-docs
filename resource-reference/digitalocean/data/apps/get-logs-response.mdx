`data_digitalocean_apps_get_logs_response` retrieves real log URLs for a specific App Platform component -- both a historical archive and, when following, a live-tailing URL.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apps "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/apps"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_apps_get_logs_response"})

    		ubx.Data(apps.GetLogsResponse, "example", apps.GetLogsResponseConfig{
    			AppId:                "example",
    			ComponentName:        "example-component-name",
    			Type:                 "example",
    			Follow:               true,
    			PodConnectionTimeout: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The ID of the App Platform application to retrieve logs for. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="component_name" type="string" required>
  The name of the application component to retrieve logs for. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="follow" type="bool">
  Whether to include a live-tailing URL for real-time log streaming. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="pod_connection_timeout" type="string">
  The real timeout, in seconds, for the underlying log connection. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string" required>
  The real type of logs to retrieve (build, deploy, or run). **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="historic_urls" type="list(string)">
  Real URLs for previously archived log content. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="live_url" type="string">
  A URL of the real-time live logs. This URL may use either the `https://` or `wss://` protocols and will keep pushing live logs as they become available. Returned by the lookup.
</ResponseField>

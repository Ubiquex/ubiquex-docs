`data_digitalocean_apps_deployments_response` lists the real, already-triggered deployments of a specific App Platform application, paginated and filterable by deployment type.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_apps_deployments_response"})

    		ubx.Data(apps.DeploymentsResponse, "example", apps.DeploymentsResponseConfig{
    			AppId:           "example",
    			DeploymentTypes: []string{"example"},
    			Page:            1,
    			PerPage:         1,
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The ID of the App Platform application these deployments belong to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="deployment_types" type="list(string)">
  Filters deployments by their real trigger type. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

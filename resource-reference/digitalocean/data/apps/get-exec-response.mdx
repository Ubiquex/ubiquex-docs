`data_digitalocean_apps_get_exec_response` generates a real websocket URL for opening an interactive console session into a specific running App Platform component instance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apps "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/apps"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_apps_get_exec_response"})

    		ubx.Data(apps.GetExecResponse, "example", apps.GetExecResponseConfig{
    			AppId:         "example",
    			ComponentName: "example-component-name",
    			InstanceName:  "example-instance-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

    def describe():
        ubx.intent("look up digitalocean_apps_get_exec_response")

        ubx.data(GetExecResponse, "example", GetExecResponseConfig(
            app_id="example",
            component_name="example-component-name",
            instance_name="example-instance-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="app_id" type="string" required>
  The ID of the App Platform application this console session is for. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="component_name" type="string" required>
  The name of the application component to open a console session into. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="instance_name" type="string">
  The name of the specific running instance to open a console session into. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="url" type="string">
  A websocket URL that allows sending/receiving console input and receiving console output. Returned by the lookup.
</ResponseField>

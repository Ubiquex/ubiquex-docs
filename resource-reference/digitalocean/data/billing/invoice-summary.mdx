`data_digitalocean_invoice_summary` reads the real, high-level summary of a specific invoice -- its total amount, billing period, and the real breakdown across charges, overages, taxes, and credits.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	billing "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/billing"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_invoice_summary"})

    		ubx.Data(billing.InvoiceSummary, "example", billing.InvoiceSummaryConfig{
    			InvoiceUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { InvoiceSummary } from "@ubx/sdk-digitalocean/digitalocean/data/billing/invoice_summary";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_invoice_summary" });

      data(InvoiceSummary, "example", {
        invoiceUuid: "example",
      });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.billing import InvoiceSummary, InvoiceSummaryConfig

    def describe():
        ubx.intent("look up digitalocean_invoice_summary")

        ubx.data(InvoiceSummary, "example", InvoiceSummaryConfig(
            invoice_uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="invoice_uuid" type="string" required>
  The UUID of the invoice to summarize. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="amount" type="string">
  Total amount of the invoice, in USD. This will reflect month-to-date usage in the invoice preview. Returned by the lookup.
</ResponseField>

<ResponseField name="billing_period" type="string">
  Billing period of usage for which the invoice is issued, in `YYYY-MM` format. Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="account_urn" type="string" required>
  The uniform resource name (URN) of the account these billing data points belong to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="end_date" type="string" required>
  The end of the real date range to retrieve billing data points for. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="start_date" type="string" required>
  The start of the real date range to retrieve billing data points for. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="current_page" type="number">
  Current page number Returned by the lookup.
</ResponseField>

<ResponseField name="data_points" type="list(object)">
  Array of billing data points, which are day-over-day changes in billing resource usage based on nightly invoice item estimates, for the requested period Returned by the lookup.
</ResponseField>

<ResponseField name="total_items" type="number">
  Total number of items available across all pages Returned by the lookup.
</ResponseField>

<ResponseField name="total_pages" type="number">
  Total number of pages available Returned by the lookup.
</ResponseField>

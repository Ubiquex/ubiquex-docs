`data_digitalocean_v2` reads the real, current DigitalOcean account associated with the API token in use -- the same real data `data_digitalocean_account` exposes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	account "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/account"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_v2"})

    		ubx.Data(account.V2, "example", account.V2Config{})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

_This lookup takes no arguments._

## Result properties

<ResponseField name="account" type="object">
  The account's own real, current representation. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="droplet_limit" type="number" required>
      The total number of Droplets current user or team may have active at one time. &lt;br&gt;&lt;br&gt;Requires `droplet:read` scope. Required lookup argument.
    </ResponseField>
    <ResponseField name="email" type="string" required>
      The email address used by the current user to register for DigitalOcean. Required lookup argument.
    </ResponseField>
    <ResponseField name="email_verified" type="bool" required>
      If true, the user has verified their account via email. False otherwise. Required lookup argument.
    </ResponseField>
    <ResponseField name="floating_ip_limit" type="number" required>
      The total number of Floating IPs the current user or team may have. &lt;br&gt;&lt;br&gt;Requires `reserved_ip:read` scope. Required lookup argument.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name for the current user. Optional lookup argument.
    </ResponseField>
    <ResponseField name="status" type="string" required>
      This value is one of "active", "warning" or "locked". Required lookup argument.
    </ResponseField>
    <ResponseField name="status_message" type="string" required>
      A human-readable message giving more details about the status of the account. Required lookup argument.
    </ResponseField>
    <ResponseField name="team" type="object">
      When authorized in a team context, includes information about the current team. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="name" type="string">
          The name for the current team. Optional lookup argument.
        </ResponseField>
        <ResponseField name="uuid" type="string">
          The unique universal identifier for the current team. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="uuid" type="string" required>
      The unique universal identifier for the current user. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

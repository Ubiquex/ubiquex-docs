`data_digitalocean_access_key` lists the real, already-registered access keys for a namespace's own storage or credential set, with the real, current total count.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	functions "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/functions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_access_key"})

    		ubx.Data(functions.AccessKey, "example", functions.AccessKeyConfig{
    			NamespaceId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.digitalocean.data.functions import AccessKey, AccessKeyConfig

    def describe():
        ubx.intent("look up digitalocean_access_key")

        ubx.data(AccessKey, "example", AccessKeyConfig(
            namespace_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="namespace_id" type="string" required>
  The ID of the namespace these access keys belong to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="access_keys" type="list(object)">
  The list of real, matching access keys. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="count" type="number">
  Total number of access keys Returned by the lookup.
</ResponseField>

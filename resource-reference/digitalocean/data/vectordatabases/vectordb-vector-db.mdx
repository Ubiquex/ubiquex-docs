`data_digitalocean_vectordb_vector_db` lists the real, already-provisioned Gradient AI Platform vector databases on the account, paginated, with the real, current total count.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	vectordatabases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/vectordatabases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_vectordb_vector_db"})

    		ubx.Data(vectordatabases.VectordbVectorDb, "example", vectordatabases.VectordbVectorDbConfig{
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="total" type="number">
  The real, current total count of vector databases matching this request. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="vector_dbs" type="list(object)">
  The list of real, already-provisioned vector databases. **(AI-inferred)** Returned by the lookup.
</ResponseField>

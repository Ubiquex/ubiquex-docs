`data_digitalocean_vectordb_get_restore_status_response` reads the real, current status of an in-progress or completed vector database restore from a specific backup.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_vectordb_get_restore_status_response"})

    		ubx.Data(vectordatabases.VectordbGetRestoreStatusResponse, "example", vectordatabases.VectordbGetRestoreStatusResponseConfig{
    			BackupId: "example",
    			Id:       "example",
    		})
    	}))
    }

## Lookup arguments

<ResponseField name="backup_id" type="string" required>
  The ID of the backup this restore is being performed from. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="id" type="string" required>
  The ID of the vector database this restore belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="error" type="string">
  Error message if the restore failed. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  Current status: STARTED, TRANSFERRING, TRANSFERRED, FINALIZING, SUCCESS, FAILED, CANCELLING, CANCELED. Returned by the lookup.
</ResponseField>

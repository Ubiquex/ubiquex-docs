`data_digitalocean_uptime` lists the real, already-configured Uptime checks on the account, paginated -- the same real list `data_digitalocean_check` exposes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	uptime "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/uptime"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_uptime"})

    		ubx.Data(uptime.Uptime, "example", uptime.UptimeConfig{
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

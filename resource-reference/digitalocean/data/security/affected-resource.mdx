## Lookup arguments

<ResponseField name="finding_uuid" type="string" required>
  The UUID of the security scan finding. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="scan_id" type="string" required>
  The ID of the security scan this finding belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="affected_resources" type="list(object)">
  The list of real resources affected by the finding. **(AI-inferred)** Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	security "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/security"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_scan"})

    		ubx.Data(security.Scan, "example", security.ScanConfig{
    			Page:     1,
    			PerPage:  1,
    			Severity: "example",
    			Type:     "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="severity" type="string">
  Filters security scans by real, current severity. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string">
  Filters security scans by real, current type. **(AI-inferred)** Optional lookup argument.
</ResponseField>

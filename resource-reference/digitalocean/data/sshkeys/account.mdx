`data_digitalocean_account` reads the real, current DigitalOcean account associated with the API token in use -- its own real limits, status, and identifying details.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	sshkeys "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/sshkeys"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_account"})

    		ubx.Data(sshkeys.Account, "example", sshkeys.AccountConfig{
    			Page:    1,
    			PerPage: 1,
    		})
    	}))
    }
    ```

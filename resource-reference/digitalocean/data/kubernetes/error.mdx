`data_digitalocean_error` describes the real error shape DigitalOcean's own API returns on a failed request -- the identifying error type, a human-readable message, and an optional request ID for support.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kubernetes "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/kubernetes"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_error"})

    		ubx.Data(kubernetes.Error, "example", kubernetes.ErrorConfig{
    			ClusterId:     "example",
    			ExpirySeconds: 7200,
    			Type:          "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="cluster_id" type="string" required>
  The ID of the Kubernetes cluster associated with this error, when applicable. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expiry_seconds" type="number">
  The real, requested lifetime, in seconds, for a related access token. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string">
  The real, machine-readable error type. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="id" type="string">
  A short identifier corresponding to the HTTP status code returned. For example, the ID for a response returning a 404 status code would be "not_found." Returned by the lookup.
</ResponseField>

<ResponseField name="message" type="string">
  A message providing additional information about the error, including details to help resolve it when possible. Returned by the lookup.
</ResponseField>

<ResponseField name="request_id" type="string">
  Optionally, some endpoints may include a request ID that should be provided when reporting bugs or opening support tickets to help identify the issue. Returned by the lookup.

`data_digitalocean_credentials` retrieves the real, current credentials (token or client certificate, plus the API server URL) needed to authenticate against a Kubernetes cluster's own control plane.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kubernetes "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/kubernetes"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_credentials"})

    		ubx.Data(kubernetes.Credentials, "example", kubernetes.CredentialsConfig{
    			ClusterId:     "example",
    			ExpirySeconds: 7200,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Credentials } from "@ubx/sdk-digitalocean/digitalocean/data/kubernetes/credentials";
    ```

  <Tab title="Python">

    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.kubernetes import Credentials, CredentialsConfig

    def describe():
        ubx.intent("look up digitalocean_credentials")

        ubx.data(Credentials, "example", CredentialsConfig(
            cluster_id="example",
            expiry_seconds=7200,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="cluster_id" type="string" required>
  The ID of the Kubernetes cluster this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="expiry_seconds" type="number">
  The real, requested lifetime, in seconds, for the generated access token. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="certificate_authority_data" type="string">
  A base64 encoding of bytes representing the certificate authority data for accessing the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="client_certificate_data" type="string">
  A base64 encoding of bytes representing the x509 client certificate data for access the cluster. This is only returned for clusters without support for token-based authentication. Newly created Kubernetes clusters do not return credentials using certificate-based authentication. For additional information, [see here](https://docs.digitalocean.com/products/kubernetes/how-to/connect-to-cluster/#authenticate). Returned by the lookup.
</ResponseField>

<ResponseField name="client_key_data" type="string">
  A base64 encoding of bytes representing the x509 client key data for access the cluster. This is only returned for clusters without support for token-based authentication. Newly created Kubernetes clusters do not return credentials using certificate-based authentication. For additional information, [see here](https://docs.digitalocean.com/products/kubernetes/how-to/connect-to-cluster/#authenticate). Returned by the lookup.
</ResponseField>

<ResponseField name="expires_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when the access token expires. Returned by the lookup.
</ResponseField>

<ResponseField name="server" type="string">
  The URL used to access the cluster API server. Returned by the lookup.
</ResponseField>

<ResponseField name="token" type="string">
  An access token used to authenticate with the cluster. This is only returned for clusters with support for token-based authentication. Returned by the lookup.
</ResponseField>

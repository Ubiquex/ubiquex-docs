`data_digitalocean_clusterlint_results` reads the real, most recent clusterlint diagnostic results for a Kubernetes cluster -- the potential misconfigurations DigitalOcean's own linting run against it found.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kubernetes "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/kubernetes"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_clusterlint_results"})

    		ubx.Data(kubernetes.ClusterlintResults, "example", kubernetes.ClusterlintResultsConfig{
    			ClusterId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.kubernetes import ClusterlintResults, ClusterlintResultsConfig

    def describe():
        ubx.intent("look up digitalocean_clusterlint_results")

        ubx.data(ClusterlintResults, "example", ClusterlintResultsConfig(
            cluster_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="cluster_id" type="string" required>
  The ID of the Kubernetes cluster this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="completed_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when the schedule clusterlint run request was completed. Returned by the lookup.
</ResponseField>

<ResponseField name="diagnostics" type="list(object)">
  An array of diagnostics reporting potential problems for the given cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="requested_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when the schedule clusterlint run request was made. Returned by the lookup.
</ResponseField>

<ResponseField name="run_id" type="string">
  The ID of the specific clusterlint run to look up results for. **(AI-inferred)** Returned by the lookup.
</ResponseField>

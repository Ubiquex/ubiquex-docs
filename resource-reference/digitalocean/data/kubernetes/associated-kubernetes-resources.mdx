`data_digitalocean_associated_kubernetes_resources` lists the real load balancers, volumes, and volume snapshots a Kubernetes cluster's own workloads created, that would also be destroyed if the cluster itself is deleted with cascading cleanup.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	kubernetes "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/kubernetes"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_associated_kubernetes_resources"})

    		ubx.Data(kubernetes.AssociatedKubernetesResources, "example", kubernetes.AssociatedKubernetesResourcesConfig{
    			ClusterId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="cluster_id" type="string" required>
  The ID of the Kubernetes cluster to list associated resources for. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="load_balancers" type="list(object)">
  A list of names and IDs for associated load balancers that can be destroyed along with the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="volume_snapshots" type="list(object)">
  A list of names and IDs for associated volume snapshots that can be destroyed along with the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="volumes" type="list(object)">
  A list of names and IDs for associated volumes that can be destroyed along with the cluster. Returned by the lookup.
</ResponseField>

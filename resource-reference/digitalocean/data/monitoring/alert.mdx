## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	monitoring "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/monitoring"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_alert"})

    		ubx.Data(monitoring.Alert, "example", monitoring.AlertConfig{
    			AlertId: "example",
    			CheckId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

      data(Alert, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.monitoring import Alert, AlertConfig

    def describe():
        ubx.intent("look up digitalocean_alert")

        ubx.data(Alert, "example", AlertConfig(
            alert_id="example",
            check_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="alert_id" type="string" required>
  The ID of the alert policy to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="check_id" type="string" required>
  The ID of the Uptime check this alert policy belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

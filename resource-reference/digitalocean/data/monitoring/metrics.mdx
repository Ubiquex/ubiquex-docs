## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	monitoring "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/monitoring"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_metrics"})

    		ubx.Data(monitoring.Metrics, "example", monitoring.MetricsConfig{
    			AppId:        "example",
    			End:          "example",
    			Start:        "example",
    			AppComponent: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="app_component" type="string">
  The name of the application component to retrieve metrics for. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="app_id" type="string" required>
  The ID of the App Platform application these metrics belong to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="end" type="string" required>
  The end of the real time range to retrieve metrics for. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="start" type="string" required>
  The start of the real time range to retrieve metrics for. **(AI-inferred)** Required lookup argument.
</ResponseField>

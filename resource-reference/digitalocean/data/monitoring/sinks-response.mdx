---
title: "digitalocean_sinks_response"
description: "`data_digitalocean_sinks_response` lists the real sinks currently forwarding data for a specific resource, identified by their own URNs."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	monitoring "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/monitoring"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_sinks_response"})

    		ubx.Data(monitoring.SinksResponse, "example", monitoring.SinksResponseConfig{
    			ResourceId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SinksResponse } from "@ubx/sdk-digitalocean/digitalocean/data/monitoring/sinks_response";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_sinks_response" });

      data(SinksResponse, "example", {
        resourceId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.monitoring import SinksResponse, SinksResponseConfig

    def describe():
        ubx.intent("look up digitalocean_sinks_response")

        ubx.data(SinksResponse, "example", SinksResponseConfig(
            resource_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="resource_id" type="string">
  The uniform resource name (URN) for the resource in the format do:resource_type:resource_id. Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="sinks" type="list(object)">
  List of sinks identified by their URNs. Returned by the lookup.
</ResponseField>

`data_digitalocean_action` looks up a real, already-recorded action by ID -- the same async operation record `digitalocean_action` exposes, scoped here to a specific Droplet's own action history.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	actions "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/actions"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_action"})

    		ubx.Data(actions.Action, "example", actions.ActionConfig{
    			ActionId:  1,
    			DropletId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Action } from "@ubx/sdk-digitalocean/digitalocean/data/actions/action";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_action" });

      data(Action, "example", {
        actionId: 1,
        dropletId: 1,
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.actions import Action, ActionConfig

    def describe():
        ubx.intent("look up digitalocean_action")

        ubx.data(Action, "example", ActionConfig(
            action_id=1,
            droplet_id=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="action_id" type="number" required>
  The ID of the action to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="droplet_id" type="number" required>
  The ID of the Droplet this action belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="action" type="object">
  The action's own real, current representation. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="completed_at" type="string">
      A time value given in ISO8601 combined date and time format that represents when the action was completed. Optional lookup argument.
    </ResponseField>
    <ResponseField name="id" type="number">
      A unique numeric ID that can be used to identify and reference an action. Optional lookup argument.
    </ResponseField>
    <ResponseField name="region" type="object">
      Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="available" type="bool" required>
          This is a boolean value that represents whether new Droplets can be created in this region. Required lookup argument.
        </ResponseField>
        <ResponseField name="features" type="list(string)" required>
          This attribute is set to an array which contains features available in this region Required lookup argument.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The display name of the region. This will be a full name that is used in the control panel and other interfaces. Required lookup argument.
        </ResponseField>
        <ResponseField name="sizes" type="list(string)" required>
          This attribute is set to an array which contains the identifying slugs for the sizes available in this region. sizes:read is required to view. Required lookup argument.
        </ResponseField>
        <ResponseField name="slug" type="string" required>
          A human-readable string that is used as a unique identifier for each region. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="region_slug" type="string">
      A human-readable string that is used as a unique identifier for each region. Optional lookup argument.
    </ResponseField>
    <ResponseField name="resource_id" type="number">
      A unique identifier for the resource that the action is associated with. Optional lookup argument.
    </ResponseField>
    <ResponseField name="resource_type" type="string">
      The type of resource that the action is associated with. Optional lookup argument.
    </ResponseField>
    <ResponseField name="started_at" type="string">
      A time value given in ISO8601 combined date and time format that represents when the action was initiated. Optional lookup argument.
    </ResponseField>
    <ResponseField name="status" type="string">
      The current status of the action. This can be "in-progress", "completed", or "errored". Optional lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string">
      This is the type of action that the object represents. For example, this could be "transfer" to represent the state of an image transfer action. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

`data_digitalocean_access_point_get_response` looks up a real, already-created NFS access point by ID -- the mount configuration granting a specific network access to an NFS share.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	nfs "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/nfs"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_access_point_get_response"})

    		ubx.Data(nfs.AccessPointGetResponse, "example", nfs.AccessPointGetResponseConfig{
    			AccessPointId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

    ```python
    import ubx_sdk as ubx

        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="access_point_id" type="string" required>
  The ID of the NFS access point. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="access_point" type="object">
  Represents an NFS access point resource. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="access_policy" type="object" required>
      Provider-agnostic NFS access policy for an access point. Network CIDRs are managed by attach, detach, and managed-access workflows and are not part of this policy. Required lookup argument.
      <Expandable title="properties">
        <ResponseField name="anongid" type="number" required>
          GID used for squashed users. Currently only 65534 is supported. Required lookup argument.
        </ResponseField>
        <ResponseField name="anonuid" type="number" required>
          UID used for squashed users. Currently only 65534 is supported. Required lookup argument.
        </ResponseField>
        <ResponseField name="identity_enforcement_enabled" type="bool" required>
          Whether identity enforcement is enabled for this export. Required lookup argument.
        </ResponseField>
        <ResponseField name="protocols" type="list(string)" required>
          Allowed NFS protocols for this export. Required lookup argument.
        </ResponseField>
        <ResponseField name="squash_config" type="string" required>
          The squash mode applied to the access point export. Required lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="created_at" type="string">
      The timestamp when the access point was created. Returned by the lookup.
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique identifier of the access point. Returned by the lookup.
    </ResponseField>
    <ResponseField name="is_default" type="bool">
      Whether this is the share's default access point. Returned by the lookup.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      The human-readable name of the access point. Must be unique per share. Required lookup argument.
    </ResponseField>
    <ResponseField name="path" type="string" required>
      The export sub-path for this access point (always starts with `/`). Required lookup argument.
    </ResponseField>
    <ResponseField name="share_id" type="string">
      The unique identifier of the share this access point belongs to. Returned by the lookup.
    </ResponseField>
    <ResponseField name="status" type="string">
      The current lifecycle status of an access point. There is no ACCESS_POINT_DELETING state: DELETE soft-deletes the access point synchronously (mirroring share deletion); the response of a delete request returns the access point already in ACCESS_POINT_DELETED. Returned by the lookup.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      The timestamp when the access point was last updated. May be empty while the access point is still being created. Returned by the lookup.
    </ResponseField>
    <ResponseField name="vpc_id" type="string">
      The VPC this access point is pinned to. Omitted on the default access point. Every non-default access point owns its own storage gateway in this VPC and is independent of the parent share's VPC lifecycle. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

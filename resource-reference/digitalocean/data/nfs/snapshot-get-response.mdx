## Lookup arguments

<ResponseField name="nfs_snapshot_id" type="string" required>
  The ID of the NFS snapshot to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="region" type="string">
  The real region the NFS snapshot belongs to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="snapshot" type="object">
  Represents an NFS snapshot. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="created_at" type="string" required>
      The timestamp when the snapshot was created. Required lookup argument.
    </ResponseField>
    <ResponseField name="id" type="string" required>
      The unique identifier of the snapshot. Required lookup argument.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      The human-readable name of the snapshot. Required lookup argument.
    </ResponseField>
    <ResponseField name="region" type="string" required>
      The DigitalOcean region slug where the snapshot is located. Required lookup argument.
    </ResponseField>
    <ResponseField name="share_id" type="string" required>
      The unique identifier of the share from which this snapshot was created. Required lookup argument.
    </ResponseField>
    <ResponseField name="size_gib" type="number" required>
      The size of the snapshot in GiB. Required lookup argument.
    </ResponseField>
    <ResponseField name="status" type="string" required>
      The current status of the snapshot. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

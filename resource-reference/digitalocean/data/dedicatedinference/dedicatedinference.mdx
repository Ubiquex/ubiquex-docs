`data_digitalocean_dedicated_inference` lists the real, already-provisioned Gradient AI Platform dedicated inference deployments on the account, paginated and filterable by region.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dedicatedinference "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/dedicatedinference"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_dedicated_inference"})

    		ubx.Data(dedicatedinference.Dedicatedinference, "example", dedicatedinference.DedicatedinferenceConfig{
    			Page:    1,
    			PerPage: 1,
    			Region:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="region" type="string">
  Filters dedicated inference deployments by real, current region. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="dedicated_inferences" type="list(object)">
  Array of Dedicated Inference instances. Returned by the lookup.
</ResponseField>

<ResponseField name="links" type="object">
  Pagination links to other pages of results. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="pages" type="map(string)">
      Pagination links (first, prev, next, last). Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Metadata about the result set, such as the total count. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="total" type="number" required>
      Total number of results. Required lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

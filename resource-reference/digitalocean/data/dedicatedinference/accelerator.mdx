`data_digitalocean_dedicated_inference_accelerator` looks up a real, already-provisioned GPU accelerator attached to a specific dedicated inference deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	dedicatedinference "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/dedicatedinference"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_dedicated_inference_accelerator"})

    		ubx.Data(dedicatedinference.Accelerator, "example", dedicatedinference.AcceleratorConfig{
    			AcceleratorId:        "example",
    			DedicatedInferenceId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

## Lookup arguments

<ResponseField name="accelerator_id" type="string" required>
  The ID of the accelerator to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="dedicated_inference_id" type="string" required>
  The ID of the dedicated inference deployment this accelerator belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="created_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when this was created. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  Unique ID of the accelerator. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the accelerator. Returned by the lookup.
</ResponseField>

<ResponseField name="role" type="string">
  Role of the accelerator (e.g. prefill_decode). Returned by the lookup.
</ResponseField>

<ResponseField name="slug" type="string">
  DigitalOcean GPU slug. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the accelerator. Returned by the lookup.
</ResponseField>

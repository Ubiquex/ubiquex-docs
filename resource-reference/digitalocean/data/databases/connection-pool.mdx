## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_connection_pool"})

    		ubx.Data(databases.ConnectionPool, "example", databases.ConnectionPoolConfig{
    			DatabaseClusterUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">

    import ubx_sdk as ubx
    from ubx.digitalocean.data.databases import ConnectionPool, ConnectionPoolConfig

    def describe():
        ubx.intent("look up digitalocean_connection_pool")

        ubx.data(ConnectionPool, "example", ConnectionPoolConfig(
            database_cluster_uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="database_cluster_uuid" type="string" required>
  The UUID of the managed database cluster this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="pools" type="list(object)">
  An array of connection pool objects. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_sql_mode"})

    		ubx.Data(databases.SqlMode, "example", databases.SqlModeConfig{
    			DatabaseClusterUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SqlMode } from "@ubx/sdk-digitalocean/digitalocean/data/databases/sql_mode";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_sql_mode" });

      data(SqlMode, "example", {
        databaseClusterUuid: "example",
      });
    ```

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.databases import SqlMode, SqlModeConfig

    def describe():
        ubx.intent("look up digitalocean_sql_mode")

        ubx.data(SqlMode, "example", SqlModeConfig(
            database_cluster_uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="database_cluster_uuid" type="string" required>
  The UUID of the managed database cluster this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="sql_mode" type="string">
  A string specifying the configured SQL modes for the MySQL cluster. Returned by the lookup.
</ResponseField>

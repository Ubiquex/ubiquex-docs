## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_version"})

    		ubx.Data(databases.Version, "example", databases.VersionConfig{
    			DatabaseClusterUuid: "example",
    			SubjectName:         "example-subject-name",
    			Version:             "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="database_cluster_uuid" type="string" required>
  The UUID of the managed database cluster this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="subject_name" type="string" required>
  The name of the schema subject to look up a version for. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="version" type="string" required>
  The real, specific schema version number to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

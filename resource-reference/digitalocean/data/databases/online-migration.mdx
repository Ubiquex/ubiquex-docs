## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_online_migration"})

    		ubx.Data(databases.OnlineMigration, "example", databases.OnlineMigrationConfig{
    			DatabaseClusterUuid: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="database_cluster_uuid" type="string" required>
  The UUID of the managed database cluster to check migration status for. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="created_at" type="string">
  The time the migration was initiated, in ISO 8601 format. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the most recent migration. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the migration. Returned by the lookup.
</ResponseField>

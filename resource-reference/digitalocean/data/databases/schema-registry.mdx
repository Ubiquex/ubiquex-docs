---
title: "digitalocean_schema_registry"
description: "`data_digitalocean_schema_registry` reads the real, current compatibility level configured for a managed database cluster's own Kafka schema registry."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_schema_registry"})

    		ubx.Data(databases.SchemaRegistry, "example", databases.SchemaRegistryConfig{
    			DatabaseClusterUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { SchemaRegistry } from "@ubx/sdk-digitalocean/digitalocean/data/databases/schema_registry";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_schema_registry" });

      data(SchemaRegistry, "example", {
        databaseClusterUuid: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.databases import SchemaRegistry, SchemaRegistryConfig

    def describe():
        ubx.intent("look up digitalocean_schema_registry")

        ubx.data(SchemaRegistry, "example", SchemaRegistryConfig(
            database_cluster_uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="database_cluster_uuid" type="string" required>
  The UUID of the managed database cluster this schema registry belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="compatibility_level" type="string">
  The compatibility level of the schema registry. Returned by the lookup.
</ResponseField>

`data_digitalocean_backup` reads the real, current backup configuration and history for a managed database cluster, including any backup currently in progress.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	databases "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/databases"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_backup"})

    		ubx.Data(databases.Backup, "example", databases.BackupConfig{
    			DatabaseClusterUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="database_cluster_uuid" type="string" required>
  The UUID of the managed database cluster this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="backup_progress" type="string">
  If a backup is currently in progress, this attribute shows the percentage of completion. If no backup is in progress, this attribute will be hidden. Returned by the lookup.
</ResponseField>

<ResponseField name="backups" type="list(object)">
  The list of real, already-completed backups. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="scheduled_backup_time" type="object">
  The real, current time of day the next scheduled backup will run. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="backup_hour" type="number">
      The hour of the day when the backup is scheduled (in UTC). Optional lookup argument.
    </ResponseField>
    <ResponseField name="backup_interval_hours" type="number">
      The frequency, in hours, at which backups are taken. Optional lookup argument.
    </ResponseField>
    <ResponseField name="backup_minute" type="number">
      The minute of the hour when the backup is scheduled. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

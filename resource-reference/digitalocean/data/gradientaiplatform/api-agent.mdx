## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_agent"})

    		ubx.Data(gradientaiplatform.ApiAgent, "example", gradientaiplatform.ApiAgentConfig{
    			Uuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ApiAgent } from "@ubx/sdk-digitalocean/digitalocean/data/gradientaiplatform/api_agent";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_api_agent" });

      data(ApiAgent, "example", {
        uuid: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.gradientaiplatform import ApiAgent, ApiAgentConfig

    def describe():
        ubx.intent("look up digitalocean_api_agent")

        ubx.data(ApiAgent, "example", ApiAgentConfig(
            uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="uuid" type="string" required>
  The UUID of the parent Gradient AI Platform agent. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="children" type="list(object)">
  Child agents Returned by the lookup.
</ResponseField>

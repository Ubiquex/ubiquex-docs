`data_digitalocean_api_get_model_evaluation_run_results_download_urloutput` generates a real, time-limited presigned URL for downloading a model evaluation run's own full, compressed results file.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Lookup arguments

<ResponseField name="eval_run_uuid" type="string" required>
  The UUID of the model evaluation run to generate a results download URL for. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="download_url" type="string">
  The presigned URL to download the gzip-compressed JSON results file (.json.gz). Returned by the lookup.
</ResponseField>

<ResponseField name="expires_at" type="string">
  The time the URL expires at. Returned by the lookup.
</ResponseField>

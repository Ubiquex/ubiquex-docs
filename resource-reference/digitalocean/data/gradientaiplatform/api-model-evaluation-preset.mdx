`data_digitalocean_api_model_evaluation_preset` lists the real, already-saved model evaluation presets -- reusable dataset/judge/metric configurations for scoring model evaluation runs.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_model_evaluation_preset"})

    	}))
    }

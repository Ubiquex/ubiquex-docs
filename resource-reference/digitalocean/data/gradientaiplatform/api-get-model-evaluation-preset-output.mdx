`data_digitalocean_api_get_model_evaluation_preset_output` looks up a real, already-saved model evaluation preset by ID -- a reusable dataset/judge/metric configuration for scoring model evaluation runs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_get_model_evaluation_preset_output"})

    		ubx.Data(gradientaiplatform.ApiGetModelEvaluationPresetOutput, "example", gradientaiplatform.ApiGetModelEvaluationPresetOutputConfig{
    			EvalPresetUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    export default stack("example", () => {
    ```

## Lookup arguments

<ResponseField name="eval_preset_uuid" type="string" required>
  The UUID of the model evaluation preset to look up. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="preset" type="object">
  Model Evaluation Preset - a saved, reusable configuration for model evaluation runs. Each section (dataset, judge, metrics, candidate, system prompt) is independent and may be empty; sections the preset omits must be supplied inline on the run that references it. Use `saved_sections` to tell "section saved with empty value" apart from "section not saved at all"  --  each section's scalar fields are left empty when the section was not saved. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="candidate_inference_config" type="object">
      Inference configuration for the candidate model during evaluation. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="max_tokens" type="number">
          Optional lookup argument.
        </ResponseField>
        <ResponseField name="stop_token" type="string">
          Optional lookup argument.
        </ResponseField>
        <ResponseField name="system_prompt" type="string">
          Optional lookup argument.
        </ResponseField>
        <ResponseField name="temperature" type="number">
          Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="candidate_model_name" type="string">
      Model slug used to call the candidate model API. Empty when the CANDIDATE section was not saved. Optional lookup argument.
    </ResponseField>
    <ResponseField name="candidate_model_source" type="string">
      Whether inference runs against the serverless platform, a dedicated deployment, or a model router. Optional lookup argument.
    </ResponseField>
    <ResponseField name="candidate_model_uuid" type="string">
      UUID of the candidate model stored on this preset. Empty when the CANDIDATE section was not saved. For DEDICATED candidates this is the dedicated inference deployment UUID. Optional lookup argument.
    </ResponseField>
    <ResponseField name="candidate_system_prompt" type="string">
      System prompt / instructions to send to the candidate model. Empty when the SYSTEM_PROMPT section was not saved (check `saved_sections`). Optional lookup argument.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Timestamp when the preset was created. Optional lookup argument.
    </ResponseField>
    <ResponseField name="dataset_name" type="string">
      Display name of the dataset stored on this preset. Empty when the DATASET section was not saved or the dataset no longer exists. Optional lookup argument.
    </ResponseField>
    <ResponseField name="dataset_uuid" type="string">
      UUID of the dataset stored on this preset. Empty when the DATASET section was not saved (check `saved_sections`). Optional lookup argument.
    </ResponseField>
    <ResponseField name="eval_preset_uuid" type="string">
      UUID of the evaluation preset. Optional lookup argument.
    </ResponseField>
    <ResponseField name="judge_model_name" type="string">
      Display name of the judge model stored on this preset. Empty when the JUDGE section was not saved or the model no longer exists. Optional lookup argument.
    </ResponseField>
    <ResponseField name="judge_model_uuid" type="string">
      UUID of the judge model stored on this preset. Empty when the JUDGE section was not saved (check `saved_sections`). Optional lookup argument.
    </ResponseField>
    <ResponseField name="metrics" type="list(object)">
      Metrics selected for this preset. Empty when the METRICS section was not saved. Optional lookup argument.
    </ResponseField>
    <ResponseField name="name" type="string">
      Name of the evaluation preset. Optional lookup argument.
    </ResponseField>
    <ResponseField name="saved_sections" type="list(string)">
      Sections of the inline evaluation config that were persisted when this preset was created. Use this to tell "section was saved with an empty value" apart from "section was not saved"  --  scalar fields like `dataset_uuid` or `candidate_system_prompt` are always emitted as the empty string when the section was not saved. Optional lookup argument.
    </ResponseField>

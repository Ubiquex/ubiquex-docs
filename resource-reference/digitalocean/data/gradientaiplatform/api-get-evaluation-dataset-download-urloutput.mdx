`data_digitalocean_api_get_evaluation_dataset_download_urloutput` generates a real, time-limited presigned URL for downloading a specific evaluation dataset's own file.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_get_evaluation_dataset_download_urloutput"})

    		ubx.Data(gradientaiplatform.ApiGetEvaluationDatasetDownloadUrloutput, "example", gradientaiplatform.ApiGetEvaluationDatasetDownloadUrloutputConfig{
    			DatasetUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

## Lookup arguments

<ResponseField name="dataset_uuid" type="string" required>
  The UUID of the evaluation dataset to generate a download URL for. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="download_url" type="string">
  The presigned URL to download the dataset file. Returned by the lookup.
</ResponseField>

<ResponseField name="expires_at" type="string">
  The time the URL expires at. Returned by the lookup.
</ResponseField>

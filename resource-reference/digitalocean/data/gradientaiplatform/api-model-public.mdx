`data_digitalocean_api_model_public` lists the real, publicly available models in the Gradient AI Platform, along with the real use cases a client can filter by.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_model_public"})

    		ubx.Data(gradientaiplatform.ApiModelPublic, "example", gradientaiplatform.ApiModelPublicConfig{
    			Page:       1,
    			PerPage:    1,
    			PublicOnly: true,
    			Usecases:   []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="public_only" type="bool">
  Whether to restrict results to only publicly available models. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="usecases" type="list(string)">
  Filters the model list by real, intended use case. **(AI-inferred)** Optional lookup argument.
</ResponseField>

`data_digitalocean_api_custom_model` lists the real, already-imported custom models for the Gradient AI Platform, along with the real maximum a team's own tier allows.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_custom_model"})

    		ubx.Data(gradientaiplatform.ApiCustomModel, "example", gradientaiplatform.ApiCustomModelConfig{
    			Page:    1,
    			PerPage: 1,
    			Status:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    ```

## Lookup arguments

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  Filters the list of custom models by their real, current status. **(AI-inferred)** Optional lookup argument.
</ResponseField>

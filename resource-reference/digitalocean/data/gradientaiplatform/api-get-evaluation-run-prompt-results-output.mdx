## Lookup arguments

<ResponseField name="evaluation_run_uuid" type="string" required>
  The UUID of the evaluation run these prompt results belong to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="prompt_id" type="number" required>
  The ID of this specific prompt result. **(AI-inferred)** Required lookup argument.
</ResponseField>

`data_digitalocean_api_generate_oauth2_urloutput` generates a real OAuth2 authorization URL for connecting an external provider's own credentials to the Gradient AI Platform.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_generate_oauth2_urloutput"})

    		ubx.Data(gradientaiplatform.ApiGenerateOauth2Urloutput, "example", gradientaiplatform.ApiGenerateOauth2UrloutputConfig{
    			RedirectUrl: "example",
    			Type:        "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.gradientaiplatform import ApiGenerateOauth2Urloutput, ApiGenerateOauth2UrloutputConfig

    def describe():
        ubx.intent("look up digitalocean_api_generate_oauth2_urloutput")

        ubx.data(ApiGenerateOauth2Urloutput, "example", ApiGenerateOauth2UrloutputConfig(
            redirect_url="example",
            type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="redirect_url" type="string">
  The URL to redirect the user back to once the OAuth2 authorization completes. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="type" type="string">
  The type of external provider this OAuth2 authorization is for. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="url" type="string">
  The oauth2 url Returned by the lookup.
</ResponseField>

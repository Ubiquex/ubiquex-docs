`data_digitalocean_api_knowledge_base_data_source` lists the real, already-attached data sources for a specific Gradient AI Platform knowledge base, paginated.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_knowledge_base_data_source"})

    		ubx.Data(gradientaiplatform.ApiKnowledgeBaseDataSource, "example", gradientaiplatform.ApiKnowledgeBaseDataSourceConfig{
    			KnowledgeBaseUuid: "example",
    			Page:              1,
    			PerPage:           1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";

    import ubx_sdk as ubx
    from ubx.digitalocean.data.gradientaiplatform import ApiKnowledgeBaseDataSource, ApiKnowledgeBaseDataSourceConfig

    def describe():
        ubx.intent("look up digitalocean_api_knowledge_base_data_source")

        ubx.data(ApiKnowledgeBaseDataSource, "example", ApiKnowledgeBaseDataSourceConfig(
            knowledge_base_uuid="example",
            page=1,
            per_page=1,
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="knowledge_base_uuid" type="string" required>
  The UUID of the knowledge base these data sources belong to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

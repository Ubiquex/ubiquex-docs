`data_digitalocean_api_list_model_catalog_output` lists the real, available models in the Gradient AI Platform's own model catalog, along with the real filter values (provider, badge, type, sort) a client can offer.

## Lookup arguments

<ResponseField name="availability" type="list(string)">
  Filters the model catalog by real, current deployment availability. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="badges" type="list(string)">
  Filters the model catalog by real badge value (such as "new" or "featured"). **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of items to return. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="model_type" type="list(string)">
  Filters the model catalog by real model type. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="provider" type="list(string)">
  Filters the model catalog by real upstream model provider. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="search" type="string">
  A free-text search query to filter results by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_by" type="string">
  The field to sort results by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_direction" type="string">
  The direction to sort results in, ascending or descending. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="use_case" type="string">
  Filters the model catalog by real, intended use case. **(AI-inferred)** Optional lookup argument.
</ResponseField>

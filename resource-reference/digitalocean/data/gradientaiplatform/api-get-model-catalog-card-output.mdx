`data_digitalocean_api_get_model_catalog_card_output` looks up the real, detailed catalog card for a specific model in the Gradient AI Platform's own model catalog.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_get_model_catalog_card_output"})

    		ubx.Data(gradientaiplatform.ApiGetModelCatalogCardOutput, "example", gradientaiplatform.ApiGetModelCatalogCardOutputConfig{
    			Id:      "example",
    			ModelId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ApiGetModelCatalogCardOutput } from "@ubx/sdk-digitalocean/digitalocean/data/gradientaiplatform/api_get_model_catalog_card_output";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_api_get_model_catalog_card_output" });

      data(ApiGetModelCatalogCardOutput, "example", {
        id: "example",
        modelId: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.gradientaiplatform import ApiGetModelCatalogCardOutput, ApiGetModelCatalogCardOutputConfig

    def describe():
        ubx.intent("look up digitalocean_api_get_model_catalog_card_output")

        ubx.data(ApiGetModelCatalogCardOutput, "example", ApiGetModelCatalogCardOutputConfig(
            id="example",
            model_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="id" type="string" required>
  The ID of this catalog card entry. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="model_id" type="string">
  The ID of the model this catalog card describes. **(AI-inferred)** Optional lookup argument.
</ResponseField>

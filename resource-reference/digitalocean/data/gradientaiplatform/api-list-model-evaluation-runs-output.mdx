`data_digitalocean_api_list_model_evaluation_runs_output` lists the real, already-executed model evaluation runs, along with the real filter values (candidate type, status) a client can offer.

## Lookup arguments

<ResponseField name="candidate_types" type="list(string)">
  Filters evaluation runs by the real candidate model source type (serverless, dedicated, or model router). **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="eval_preset_uuid" type="string">
  The UUID of the model evaluation preset. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="search" type="string">
  A free-text search query to filter results by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_by" type="string">
  The field to sort results by. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="sort_direction" type="string">
  The direction to sort results in, ascending or descending. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="status" type="string">
  Filters evaluation runs by a single real, current status. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="statuses" type="list(string)">
  Filters evaluation runs by a real set of current statuses. **(AI-inferred)** Optional lookup argument.
</ResponseField>

`data_digitalocean_api_evaluation_dataset` lists the real, already-uploaded evaluation datasets available to the Gradient AI Platform's own model and agent evaluation tooling.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_evaluation_dataset"})

    		ubx.Data(gradientaiplatform.ApiEvaluationDataset, "example", gradientaiplatform.ApiEvaluationDatasetConfig{
    			DatasetType: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ApiEvaluationDataset } from "@ubx/sdk-digitalocean/digitalocean/data/gradientaiplatform/api_evaluation_dataset";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_api_evaluation_dataset" });

      data(ApiEvaluationDataset, "example", {
        datasetType: "example",

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.gradientaiplatform import ApiEvaluationDataset, ApiEvaluationDatasetConfig

    def describe():
        ubx.intent("look up digitalocean_api_evaluation_dataset")

        ubx.data(ApiEvaluationDataset, "example", ApiEvaluationDatasetConfig(
            dataset_type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="dataset_type" type="string">
  Filters evaluation datasets by their real type. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="evaluation_datasets" type="list(object)">
  The list of evaluation datasets. Returned by the lookup.
</ResponseField>

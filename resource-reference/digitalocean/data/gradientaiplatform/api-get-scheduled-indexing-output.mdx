`data_digitalocean_api_get_scheduled_indexing_output` looks up the real, current scheduled indexing configuration for a specific Gradient AI Platform knowledge base.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_api_get_scheduled_indexing_output"})

    		ubx.Data(gradientaiplatform.ApiGetScheduledIndexingOutput, "example", gradientaiplatform.ApiGetScheduledIndexingOutputConfig{
    			KnowledgeBaseUuid: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ApiGetScheduledIndexingOutput } from "@ubx/sdk-digitalocean/digitalocean/data/gradientaiplatform/api_get_scheduled_indexing_output";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_api_get_scheduled_indexing_output" });

      data(ApiGetScheduledIndexingOutput, "example", {
        knowledgeBaseUuid: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.gradientaiplatform import ApiGetScheduledIndexingOutput, ApiGetScheduledIndexingOutputConfig

    def describe():
        ubx.intent("look up digitalocean_api_get_scheduled_indexing_output")

        ubx.data(ApiGetScheduledIndexingOutput, "example", ApiGetScheduledIndexingOutputConfig(
            knowledge_base_uuid="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="knowledge_base_uuid" type="string" required>
  The UUID of the knowledge base this scheduled indexing configuration belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="indexing_info" type="object">
  Metadata for scheduled indexing entries Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="created_at" type="string">
      Created at timestamp Optional lookup argument.
    </ResponseField>
    <ResponseField name="days" type="list(number)">
      Days for execution (day is represented same as in a cron expression, e.g. Monday begins with 1 ) Optional lookup argument.
    </ResponseField>
    <ResponseField name="deleted_at" type="string">
      Deleted at timestamp (if soft deleted) Optional lookup argument.
    </ResponseField>
    <ResponseField name="is_active" type="bool">
      Whether the schedule is currently active Optional lookup argument.
    </ResponseField>
    <ResponseField name="knowledge_base_uuid" type="string">
      Knowledge base uuid associated with this schedule Optional lookup argument.
    </ResponseField>
    <ResponseField name="last_ran_at" type="string">
      Last time the schedule was executed Optional lookup argument.
    </ResponseField>
    <ResponseField name="next_run_at" type="string">
      Next scheduled run Optional lookup argument.
    </ResponseField>
    <ResponseField name="time" type="string">
      Scheduled time of execution (HH:MM:SS format) Optional lookup argument.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      Updated at timestamp Optional lookup argument.
    </ResponseField>
    <ResponseField name="uuid" type="string">
      Unique identifier for the scheduled indexing entry Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

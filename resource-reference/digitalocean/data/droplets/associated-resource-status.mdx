`data_digitalocean_associated_resource_status` reads the real, current progress of a cascading resource-deletion request triggered alongside a Droplet's own destruction.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	droplets "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/droplets"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_associated_resource_status"})

    		ubx.Data(droplets.AssociatedResourceStatus, "example", droplets.AssociatedResourceStatusConfig{
    			DropletId: 1,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="droplet_id" type="number" required>
  The ID of the Droplet whose cascading resource deletion is being checked. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="completed_at" type="string">
  A time value given in ISO8601 combined date and time format indicating when the requested action was completed. Returned by the lookup.
</ResponseField>

<ResponseField name="droplet" type="object">
  An object containing information about a resource scheduled for deletion. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="destroyed_at" type="string">
      A time value given in ISO8601 combined date and time format indicating when the resource was destroyed if the request was successful. Optional lookup argument.
    </ResponseField>
    <ResponseField name="error_message" type="string">
      A string indicating that the resource was not successfully destroyed and providing additional information. Optional lookup argument.
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique identifier for the resource scheduled for deletion. Optional lookup argument.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the resource scheduled for deletion. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="failures" type="number">
  A count of the associated resources that failed to be destroyed, if any. Returned by the lookup.
</ResponseField>

<ResponseField name="resources" type="object">
  An object containing additional information about resource related to a Droplet requested to be destroyed. Returned by the lookup.

      Optional lookup argument.
    </ResponseField>
    <ResponseField name="volume_snapshots" type="list(object)">
      Optional lookup argument.
    </ResponseField>
    <ResponseField name="volumes" type="list(object)">
      Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

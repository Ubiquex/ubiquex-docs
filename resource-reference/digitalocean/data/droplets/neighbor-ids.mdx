`data_digitalocean_neighbor_ids` lists the real Droplets that physically share a host server with a given Droplet -- useful for spreading redundant workloads across genuinely separate hardware.

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_neighbor_ids"})

    	}))

## Lookup arguments

_This lookup takes no arguments._

## Result properties

<ResponseField name="neighbor_ids" type="list(list(number))">
  An array of arrays. Each array will contain a set of Droplet IDs for Droplets that share a physical server. Returned by the lookup.
</ResponseField>

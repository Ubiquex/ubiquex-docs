## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	containerregistries "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/containerregistries"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_repository"})

    		ubx.Data(containerregistries.Repository, "example", containerregistries.RepositoryConfig{
    			RegistryName:   "example-registry-name",
    			RepositoryName: "example-repository-name",
    			Page:           1,
    			PerPage:        1,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="page" type="number">
  The page number to return, for a paginated list of results. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="per_page" type="number">
  The number of items to return per page. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="registry_name" type="string" required>
  The name of the container registry this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="repository_name" type="string" required>
  The name of the repository to list image tags for. **(AI-inferred)** Required lookup argument.
</ResponseField>

`data_digitalocean_docker_credentials` generates real, Docker-compatible registry credentials (an `auths` block) for authenticating against a container registry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	containerregistries "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/data/containerregistries"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up digitalocean_docker_credentials"})

    		ubx.Data(containerregistries.DockerCredentials, "example", containerregistries.DockerCredentialsConfig{
    			RegistryName: "example-registry-name",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { DockerCredentials } from "@ubx/sdk-digitalocean/digitalocean/data/containerregistries/docker_credentials";

    export default stack("example", () => {
      intent({ summary: "look up digitalocean_docker_credentials" });

      data(DockerCredentials, "example", {
        registryName: "example-registry-name",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.data.containerregistries import DockerCredentials, DockerCredentialsConfig

    def describe():
        ubx.intent("look up digitalocean_docker_credentials")

        ubx.data(DockerCredentials, "example", DockerCredentialsConfig(
            registry_name="example-registry-name",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="registry_name" type="string" required>
  The name of the container registry this belongs to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="auths" type="object">
  The real, Docker-compatible authentication block for the registry. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="registry_digitalocean_com" type="object">
      Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="auth" type="string">
          A base64 encoded string containing credentials for the container registry. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

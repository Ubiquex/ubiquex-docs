`digitalocean_domain` looks up a real, already-registered DNS domain managed through DigitalOcean's own name servers -- the zone itself, distinct from the individual DNS records inside it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	domains "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/domains"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain"})

    		ubx.Resource(domains.Domain, "example", domains.DomainConfig{
    			DomainName: "example-domain-name",
    			Name:       "example",
    			IpAddress:  "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="domain_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="ip_address" type="string">
  This optional attribute may contain an IP address. When provided, an A record will be automatically created pointing to the apex domain. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the domain itself. This should follow the standard domain format of domain.TLD. For instance, `example.com` is a valid domain name. Optional.
</ResponseField>

## Output properties

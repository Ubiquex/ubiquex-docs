`digitalocean_key` looks up a real, already-registered SSH key -- the public key material DigitalOcean can embed into a Droplet's own `authorized_keys` file at creation time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	sshkeys "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/sshkeys"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key"})

    		ubx.Resource(sshkeys.Key, "example", sshkeys.KeyConfig{
    			Name:             "example",
    			PublicKey:        "example",
    			SshKeyIdentifier: "example",
    		})
    	}))
    }
    ```
  </Tab>

        ))

        ubx.run("example", describe)

## Input properties

<ResponseField name="name" type="string" required>
  A human-readable display name for this key, used to easily identify the SSH keys when they are displayed. Required.
</ResponseField>

<ResponseField name="public_key" type="string" required>
  The entire public key string that was uploaded. Embedded into the root user's `authorized_keys` file if you include this key during Droplet creation. Required.
</ResponseField>

<ResponseField name="ssh_key_identifier" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="fingerprint" type="string">
  A unique identifier that differentiates this key from other keys using a format that SSH recognizes. The fingerprint is created when the key is added to your account. Computed by DigitalOcean after `ship`.
</ResponseField>

<ResponseField name="id" type="number">
  A unique identification number for this key. Can be used to embed a specific SSH key into a Droplet. Computed by DigitalOcean after `ship`.
</ResponseField>

<ResponseField name="ssh_key" type="object">

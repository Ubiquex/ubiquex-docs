`digitalocean_reserved_ipv6` looks up a real, already-reserved IPv6 address -- the IPv6 counterpart to a reserved IP, tied to a specific region rather than a specific Droplet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	reservedipv6 "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/reservedipv6"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own reservedipv6"})

    		ubx.Resource(reservedipv6.Reservedipv6, "example", reservedipv6.Reservedipv6Config{
    			RegionSlug:       "example",
    			ReservedIpv6Path: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Input properties

<ResponseField name="region_slug" type="string" required>
  The slug identifier for the region the reserved IPv6 will be reserved to. Required.
</ResponseField>

<ResponseField name="reserved_ipv6_path" type="string" required>
  path parameter, not part of the API's own resource representation (renamed from "reserved_ipv6": that name is already used by a differently-typed, real response attribute) Required.
</ResponseField>

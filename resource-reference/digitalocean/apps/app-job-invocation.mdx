`digitalocean_app_job_invocation` looks up a real, already-run invocation of an App Platform job component -- a one-off task run, its phase, and its real start/completion timestamps.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	apps "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/apps"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own app job invocation"})

    		ubx.Resource(apps.AppJobInvocation, "example", apps.AppJobInvocationConfig{
    			AppId:           "example",
    			JobInvocationId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { AppJobInvocation } from "@ubx/sdk-digitalocean/digitalocean/apps/app_job_invocation";

    export default stack("example", () => {
    ```

    ```python
    import ubx_sdk as ubx
    from ubx.digitalocean.apps import AppJobInvocation, AppJobInvocationConfig

        ubx.resource(AppJobInvocation, "example", AppJobInvocationConfig(
            app_id="example",
            job_invocation_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="app_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="job_invocation_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

## Output properties

<ResponseField name="completed_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when this job invocation completed. Computed by DigitalOcean after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="created_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when this was created. Computed by DigitalOcean after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="deployment_id" type="string">
  The ID of the deployment this job invocation ran under. Computed by DigitalOcean after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="id" type="string">
  A unique ID for this job invocation. Computed by DigitalOcean after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="job_name" type="string">
  The real name of the job component that was invoked. Computed by DigitalOcean after `ship`. **(AI-inferred)**
</ResponseField>

<ResponseField name="phase" type="string">
  The phase of the job invocation Computed by DigitalOcean after `ship`.
</ResponseField>

<ResponseField name="started_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when this job invocation started. Computed by DigitalOcean after `ship`. **(AI-inferred)**
</ResponseField>

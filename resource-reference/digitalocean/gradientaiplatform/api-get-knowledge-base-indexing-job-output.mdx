`digitalocean_api_get_knowledge_base_indexing_job_output` looks up a real, already-running or completed indexing job -- the background process that ingests a knowledge base's own data sources so a Gradient AI Platform agent can retrieve from them.

## Input properties

<ResponseField name="data_source_uuids" type="list(string)">
  List of data source ids to index, if none are provided, all data sources will be indexed Optional.

  Knowledge base id Optional.
</ResponseField>

<ResponseField name="uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

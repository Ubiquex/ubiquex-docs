`digitalocean_api_get_evaluation_run_output` looks up a real, already-executed Gradient AI Platform evaluation run -- one pass of an agent or model against a test case, scored for review.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/gradientaiplatform"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own api get evaluation run output"})

    		ubx.Resource(gradientaiplatform.ApiGetEvaluationRunOutput, "example", gradientaiplatform.ApiGetEvaluationRunOutputConfig{
    			EvaluationRunUuid:    "example",
    			AgentDeploymentNames: []string{"example"},
    			AgentUuids:           []string{"example"},
    			RunName:              "example-run-name",
    			TestCaseUuid:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="agent_deployment_names" type="list(string)">
  Agent deployment names to run the test case against (ADK agent workspaces). Optional.
</ResponseField>

<ResponseField name="agent_uuids" type="list(string)">
  Agent UUIDs to run the test case against (legacy agents). Optional.
</ResponseField>

<ResponseField name="evaluation_run_uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="run_name" type="string">
  The name of the run. Optional.
</ResponseField>

<ResponseField name="test_case_uuid" type="string">
  Test-case UUID to run Optional.
</ResponseField>

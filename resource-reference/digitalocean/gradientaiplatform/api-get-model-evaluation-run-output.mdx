---

`digitalocean_api_get_model_evaluation_run_output` looks up a real, already-executed model evaluation run -- a candidate model scored against a dataset by a judge model, for comparing model choices before committing to one in production.

## Example

    ```go

    import (
    	gradientaiplatform "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/gradientaiplatform"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own api get model evaluation run output"})

    		ubx.Resource(gradientaiplatform.ApiGetModelEvaluationRunOutput, "example", gradientaiplatform.ApiGetModelEvaluationRunOutputConfig{
    			EvalRunUuid:              "example",
    			Name:                     "example",
    			CandidateInferenceConfig: map[string]any{"max_tokens": 1},
    			CandidateModelName:       "example-candidate-model-name",
    			CandidateModelSource:     "example",
    			CandidateModelUuid:       "example",
    			DatasetUuid:              "example",
    			EvalPresetUuid:           "example",
    		})
    	}))
    }
    ```

<ResponseField name="candidate_model_name" type="string">

  UUID of the dataset to use for evaluation. Optional.

  The UUID of the evaluation preset this run was executed with, if any. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="eval_run_uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="judge_model_uuid" type="string">
  UUID of the judge model used to score responses. Optional.
</ResponseField>

<ResponseField name="metric_uuids" type="list(string)">
  UUIDs of metrics to evaluate (selected from ListModelEvaluationMetrics). Optional.
</ResponseField>

<ResponseField name="name" type="string">
  A real, human-readable name for the evaluation run. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="preset_name" type="string">
  The real name of the evaluation preset this run was executed with, if any. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="preset_save_sections" type="list(string)">
  Which sections of this run's resolved configuration to persist as a reusable preset. Each selected section saves only its own fields; the remaining sections stay empty on the preset and must be supplied inline on future runs that reference it. Empty means do not save a preset (unless the deprecated `save_as_preset` boolean is true, in which case all sections are saved). Ignored when `eval_preset_uuid` is set. Use `preset_name` to label the saved preset. Optional.
</ResponseField>

<ResponseField name="save_as_preset" type="bool">
  Deprecated: use `preset_save_sections`. When `true` and `preset_save_sections` is empty, all five sections of the resolved configuration are saved as a reusable preset (legacy behavior). Ignored when `eval_preset_uuid` is set. Optional.
</ResponseField>

<ResponseField name="source" type="string">
  Source of the run creation (api, sdk, cli). Optional.
</ResponseField>

<ResponseField name="star_metric" type="object">
  The real, primary metric highlighted for this run's own results. Optional. **(AI-inferred)**

      Optional.

      The success threshold for the star metric. This is a value that the metric must reach to be considered successful. Optional.
    </ResponseField>
    <ResponseField name="success_threshold_pct" type="number">
      The success threshold for the star metric. This is a percentage value between 0 and 100. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`digitalocean_api_get_evaluation_test_case_output` looks up a real, already-defined evaluation test case -- the dataset, metrics, and expected behavior an agent or model is scored against in the Gradient AI Platform.

## Input properties

<ResponseField name="agent_workspace_name" type="string">
  The real name of the agent workspace this test case is scoped to. Optional. **(AI-inferred)**
</ResponseField>

<ResponseField name="dataset_uuid" type="string">
  Dataset against which the test‑case is executed. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the test case. Optional.
</ResponseField>

<ResponseField name="metrics" type="list(string)">
  Full metric list to use for evaluation test case. Optional.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the test case. Optional.
</ResponseField>

<ResponseField name="star_metric" type="object">
  The real, primary metric highlighted for this test case's own results. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="metric_uuid" type="string">
      Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      Optional.
    </ResponseField>
    <ResponseField name="success_threshold" type="number">
      The success threshold for the star metric. This is a value that the metric must reach to be considered successful. Optional.
    </ResponseField>
    <ResponseField name="success_threshold_pct" type="number">
      The success threshold for the star metric. This is a percentage value between 0 and 100. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="test_case_uuid" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="workspace_uuid" type="string">
  The workspace uuid. Optional.
</ResponseField>

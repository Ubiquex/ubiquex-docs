`digitalocean_api_get_knowledge_base_output` looks up a real, already-created Gradient AI Platform knowledge base -- the managed OpenSearch-backed store of indexed data sources an agent can query for retrieval-augmented answers.

    	ubx.Main(ubx.Stack("example", func() {

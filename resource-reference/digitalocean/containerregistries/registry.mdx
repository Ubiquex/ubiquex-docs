`digitalocean_registry` looks up a real, already-created container registry -- the account-wide, globally unique image store and its subscription tier, distinct from the individual repositories and tags stored inside it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only digitalocean --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-digitalocean/sdk/go => ./local-sdk/digitalocean/sdk/go
    package main

    import (
    	containerregistries "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/containerregistries"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own registry"})

    		ubx.Resource(containerregistries.Registry, "example", containerregistries.RegistryConfig{
    			Name:                 "example",
    			RegistryName:         "example-registry-name",
    			Region:               "example",
    			SubscriptionTierSlug: "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="name" type="string" required>
  A globally unique name for the container registry. Must be lowercase and be composed only of numbers, letters and `-`, up to a limit of 63 characters. Required.
</ResponseField>

<ResponseField name="region" type="string">
  Slug of the region where registry data is stored. When not provided, a region will be selected. Optional.
</ResponseField>

<ResponseField name="registry_name" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="subscription_tier_slug" type="string">
  The slug of the subscription tier to sign up for. Valid values can be retrieved using the options endpoint. Optional.
</ResponseField>

`digitalocean_endpoint` looks up a real, already-created CDN endpoint -- the fully qualified domain name DigitalOcean's own edge network serves cached content from, backed by a Space or a custom origin.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	cdnendpoints "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/cdnendpoints"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint"})

    		ubx.Resource(cdnendpoints.Endpoint, "example", cdnendpoints.EndpointConfig{
    			CdnId:         "example",
    			Origin:        "example",
    			CertificateId: "example",
    			CustomDomain:  "example",
    			Ttl:           1,
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="cdn_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="certificate_id" type="string">
  The ID of a DigitalOcean managed TLS certificate used for SSL when a custom subdomain is provided. Optional.
</ResponseField>

<ResponseField name="custom_domain" type="string">
  The fully qualified domain name (FQDN) of the custom subdomain used with the CDN endpoint. Optional.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The fully qualified domain name (FQDN) from which the CDN-backed content is served. Optional; if omitted, computed by DigitalOcean.
</ResponseField>

<ResponseField name="origin" type="string" required>
  The fully qualified domain name (FQDN) for the origin server which provides the content for the CDN. This is currently restricted to a Space. Required.
</ResponseField>

<ResponseField name="ttl" type="number">
  The amount of time the content is cached by the CDN's edge servers in seconds. TTL must be one of 60, 600, 3600, 86400, or 604800. Defaults to 3600 (one hour) when excluded. Optional.
</ResponseField>

## Output properties

<ResponseField name="created_at" type="string">
  A time value given in ISO8601 combined date and time format that represents when the CDN endpoint was created. Computed by DigitalOcean after `ship`.
</ResponseField>

<ResponseField name="endpoint" type="string">
  The fully qualified domain name (FQDN) from which the CDN-backed content is served. Optional; if omitted, computed by DigitalOcean.
</ResponseField>

<ResponseField name="id" type="string">
  A unique ID that can be used to identify and reference a CDN endpoint. Computed by DigitalOcean after `ship`.
</ResponseField>

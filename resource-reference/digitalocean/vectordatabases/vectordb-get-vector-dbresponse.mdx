`digitalocean_vectordb_get_vector_dbresponse` looks up a real, already-provisioned Gradient AI Platform vector database -- the managed store used for embedding-based retrieval, sized and regioned independently of any one knowledge base or agent.

## Input properties

<ResponseField name="id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Human-readable name for the database. Optional.
</ResponseField>

<ResponseField name="project_id" type="string">
  Required. ID of the project to create the vector database in. Optional.
</ResponseField>

<ResponseField name="region" type="string">
  Required. Region slug where the database will be provisioned. Optional.
</ResponseField>

<ResponseField name="size" type="string">
  Required. Resource tier: small, medium, or large. Optional.
</ResponseField>

<ResponseField name="tags" type="list(string)">
  A set of arbitrary tags to organize your vector database Optional.
</ResponseField>

`digitalocean_attachment` looks up a real, already-created Partner Network Connect attachment -- a private BGP-peered link from a third-party network-as-a-service provider into a DigitalOcean VPC, bypassing the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	partnernetworkconnect "github.com/ubiquex/ubx-sdk-digitalocean/sdk/go/digitalocean/partnernetworkconnect"
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own attachment"})

    		ubx.Resource(partnernetworkconnect.Attachment, "example", partnernetworkconnect.AttachmentConfig{
    			ConnectionBandwidthInMbps: 1,
    			NaasProvider:              "example",
    			Name:                      "example",
    			PaId:                      "example",
    			Region:                    "example",
    			VpcIds:                    []string{"example"},
    			Bgp:                       map[string]any{"auth_key": "example", "local_router_ip": "example", "peer_router_asn": 1, "peer_router_ip": "example"},
    			ParentUuid:                "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="bgp" type="object">
  Optional BGP configurations Optional.
  <Expandable title="properties">
    <ResponseField name="auth_key" type="string" required>
      BGP Auth Key Required.
    </ResponseField>
    <ResponseField name="local_router_ip" type="string" required>
      IP of the DO router Required.
    </ResponseField>
    <ResponseField name="peer_router_asn" type="number" required>
      ASN of the peer router Required.
    </ResponseField>
    <ResponseField name="peer_router_ip" type="string" required>
      IP of the Naas Provider router Required.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="connection_bandwidth_in_mbps" type="number" required>
  Bandwidth (in Mbps) of the connection. Required.
</ResponseField>

<ResponseField name="naas_provider" type="string" required>
  The real network-as-a-service provider this Partner Network Connect attachment connects through. Required. **(AI-inferred)**
</ResponseField>

<ResponseField name="name" type="string" required>
  The name of the partner attachment. Must be unique and may only contain alphanumeric characters, dashes, and periods. Required.
</ResponseField>

<ResponseField name="pa_id" type="string" required>
  path parameter, not part of the API's own resource representation Required.
</ResponseField>

<ResponseField name="parent_uuid" type="string">
  Optional associated partner attachment UUID Optional.
</ResponseField>

<ResponseField name="redundancy_zone" type="string">
  Optional redundancy zone for the partner attachment. Optional.
</ResponseField>

<ResponseField name="region" type="string" required>
  The region to create the partner attachment. Required.
</ResponseField>

<ResponseField name="vpc_ids" type="list(string)" required>
  An array of VPCs IDs. Required.
</ResponseField>

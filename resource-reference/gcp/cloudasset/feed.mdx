---
title: "google_cloudasset_feed"
description: "`google_cloudasset_feed` continuously streams matching Cloud Asset Inventory change(s) (resource or IAM policy updates) to a Pub/Sub topic as they occur."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudasset "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudasset"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own feed"})

    		ubx.Resource(cloudasset.Feed, "example", cloudasset.FeedConfig{
    			Feed:   map[string]any{"name": "example-name"},
    			FeedId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

    export default stack("example", () => {

      resource(Feed, "example", {
        feed: { name: "example-name" },

    ```

    ```python
    import ubx_sdk as ubx
    from ubx.google.cloudasset import Feed, FeedConfig
    from ubx.google.cloudasset.feed import Feed_Feed

    def describe():
        ubx.intent("example own feed")

        ubx.resource(Feed, "example", FeedConfig(
            feed=Feed_Feed(name="example-name"),
            feed_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="feed" type="object">
  An asset feed used to export asset updates to a destinations. An asset feed filter controls what updates are exported. The asset feed must be created within a project, organization, or folder. Supported destinations are: Pub/Sub topics. Optional.
  <Expandable title="properties">
    <ResponseField name="asset_names" type="list(string)">
      A list of the full names of the assets to receive updates. You must specify either or both of asset_names and asset_types. Only asset updates matching specified asset_names or asset_types are exported to the feed. Example: `//compute.googleapis.com/projects/my_project_123/zones/zone1/instances/instance1`. For a list of the full names for supported asset types, see [Resource name format](/asset-inventory/docs/resource-name-format). Optional.
    </ResponseField>
    <ResponseField name="asset_types" type="list(string)">
      A list of types of the assets to receive updates. You must specify either or both of asset_names and asset_types. Only asset updates matching specified asset_names or asset_types are exported to the feed. Example: `"compute.googleapis.com/Disk"` For a list of all supported asset types, see [Supported asset types](/asset-inventory/docs/supported-asset-types). Optional.
    </ResponseField>
    <ResponseField name="condition" type="object">
      Represents a textual expression in the Common Expression Language (CEL) syntax. CEL is a C-like expression language. The syntax and semantics of CEL are documented at https://github.com/google/cel-spec. Example (Comparison): title: "Summary size limit" description: "Determines if a summary is less than 100 chars" expression: "document.summary.size() &lt; 100" Example (Equality): title: "Requestor is owner" description: "Determines if requestor is the document owner" expression: "document.owner == request.auth.claims.email" Example (Logic): title: "Public documents" description: "Determine whether the document should be publicly visible" expression: "document.type != 'private' && document.type != 'internal'" Example (Data Manipulation): title: "Notification string" description: "Create a notification string with a timestamp." expression: "'New message received at ' + string(document.create_time)" The exact variables and functions that may be referenced within an expression are determined by the service that evaluates it. See the service documentation for additional information. Optional.
      <Expandable title="properties">
        <ResponseField name="description" type="string">
          Optional. Description of the expression. This is a longer text which describes the expression, e.g. when hovered over it in a UI. Optional.
        </ResponseField>
        <ResponseField name="expression" type="string">
          Textual representation of an expression in Common Expression Language syntax. Optional.
        </ResponseField>
        <ResponseField name="location" type="string">
          Optional. String indicating the location of the expression for error reporting, e.g. a file name and a position in the file. Optional.
        </ResponseField>
        <ResponseField name="title" type="string">
          Optional. Title for the expression, i.e. a short string describing its purpose. This can be used e.g. in UIs which allow to enter the expression. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="content_type" type="string">
      Asset content type. If not specified, no content but the asset name and type will be returned. Optional.
    </ResponseField>
    <ResponseField name="feed_output_config" type="object">
      Output configuration for asset feed destination. Optional.
      <Expandable title="properties">
        <ResponseField name="pubsub_destination" type="object">
          A Pub/Sub destination. Optional.
          <Expandable title="properties">
            <ResponseField name="topic" type="string">
              The name of the Pub/Sub topic to publish to. Example: `projects/PROJECT_ID/topics/TOPIC_ID`. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="name" type="string">
      Required. The format will be projects/&#123;project_number&#125;/feeds/&#123;client-assigned_feed_identifier&#125; or folders/&#123;folder_number&#125;/feeds/&#123;client-assigned_feed_identifier&#125; or organizations/&#123;organization_number&#125;/feeds/&#123;client-assigned_feed_identifier&#125; The client-assigned feed identifier must be unique within the parent project/folder/organization. Optional.
    </ResponseField>
    <ResponseField name="relationship_types" type="list(string)">
      A list of relationship types to output, for example: `INSTANCE_TO_INSTANCEGROUP`. This field should only be specified if content_type=RELATIONSHIP. * If specified: it outputs specified relationship updates on the [asset_names] or the [asset_types]. It returns an error if any of the [relationship_types] doesn't belong to the supported relationship types of the [asset_names] or [asset_types], or any of the [asset_names] or the [asset_types] doesn't belong to the source types of the [relationship_types]. * Otherwise: it outputs the supported relationships of the types of [asset_names] and [asset_types] or returns an error if any of the [asset_names] or the [asset_types] has no replationship support. See [Introduction to Cloud Asset Inventory](https://cloud.google.com/asset-inventory/docs/overview) for all supported asset types and relationship types. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="feed_id" type="string">
  Required. This is the client-assigned asset feed identifier and it needs to be unique under a specific parent project/folder/organization. Optional.
</ResponseField>

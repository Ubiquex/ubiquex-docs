title: "google_privateca_certificate"

---

`google_privateca_certificate` is an X.509 certificate issued by a Certificate Authority Service CA, either directly requested or generated from a Certificate Manager Google-managed certificate.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_privateca --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_privateca/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	privateca "github.com/ubiquex/ubx-sdk-google/sdk/go/google_privateca/privateca"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own certificate"})

    		ubx.Resource(privateca.PrivatecaCertificate, "ci-runner", privateca.PrivatecaCertificateConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

`google_privateca_certificate_template` constrains and pre-fills the fields a Certificate Authority Service CA is permitted to issue certificates with, enforcing organizational certificate policy.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	privateca "github.com/ubiquex/ubx-sdk-google/sdk/go/google/privateca"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate template"})

    		ubx.Resource(privateca.CertificateTemplate, "example", privateca.CertificateTemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

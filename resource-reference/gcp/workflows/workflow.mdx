`google_workflows_workflow` defines a Workflows definition, an orchestration of ordered step(s) calling HTTP endpoints or Google Cloud APIs, executed as a managed serverless workflow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workflows "github.com/ubiquex/ubx-sdk-google/sdk/go/google/workflows"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workflow"})

    		ubx.Resource(workflows.Workflow, "example", workflows.WorkflowConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="all_kms_keys" type="list(string)">
  Output only. A list of all KMS crypto keys used to encrypt or decrypt the data associated with the workflow. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="all_kms_keys_versions" type="list(string)">
  Output only. A list of all KMS crypto key versions used to encrypt or decrypt the data associated with the workflow. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="call_log_level" type="string">
  Optional. Describes the level of platform logging to apply to calls and call responses during executions of this workflow. If both the workflow and the execution specify a logging level, the execution level takes precedence. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp for when the workflow was created. This is a workflow-wide field and is not tied to a specific revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="crypto_key_name" type="string">
  Optional. The resource name of a KMS crypto key used to encrypt or decrypt the data associated with the workflow. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyRing&#125;/cryptoKeys/&#123;cryptoKey&#125; Using `-` as a wildcard for the `&#123;project&#125;` or not providing one at all will infer the project from the account. If not provided, data associated with the workflow will not be CMEK-encrypted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="crypto_key_version" type="string">
  Output only. The resource name of a KMS crypto key version used to encrypt or decrypt the data associated with the workflow. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyRing&#125;/cryptoKeys/&#123;cryptoKey&#125;/cryptoKeyVersions/&#123;cryptoKeyVersion&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the workflow provided by the user. Must be at most 1000 Unicode characters long. This is a workflow-wide field and is not tied to a specific revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="execution_history_level" type="string">
  Optional. Describes the execution history level to apply to this workflow. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels associated with this workflow. Labels can contain at most 64 entries. Keys and values can be no longer than 63 characters and can only contain lowercase letters, numeric characters, underscores, and dashes. Label keys must start with a letter. International characters are allowed. This is a workflow-wide field and is not tied to a specific revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the workflow. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/workflows/&#123;workflow&#125;. This is a workflow-wide field and is not tied to a specific revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="revision_create_time" type="string">
  Output only. The timestamp for the latest revision of the workflow's creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="revision_id" type="string">
  Output only. The revision of the workflow. A new revision of a workflow is created as a result of updating the following properties of a workflow: - Service account - Workflow code to be executed The format is "000001-a4d", where the first six characters define the zero-padded revision ordinal number. They are followed by a hyphen and three hexadecimal random characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_account" type="string">
  The service account associated with the latest workflow version. This service account represents the identity of the workflow and determines what permissions the workflow has. Format: projects/&#123;project&#125;/serviceAccounts/&#123;account&#125; or &#123;account&#125; Using `-` as a wildcard for the `&#123;project&#125;` or not providing one at all will infer the project from the account. The `&#123;account&#125;` value can be the `email` address or the `unique_id` of the service account. If not provided, workflow will use the project's default service account. Modifying this field for an existing workflow results in a new workflow revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_contents" type="string">
  Workflow code to be executed. The size limit is 128KB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the workflow deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_error" type="object">
  Describes an error related to the current state of the workflow. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="details" type="string">
      Provides specifics about the error. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of this state error. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Optional. Input only. Immutable. Tags associated with this workflow. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp for when the workflow was last updated. This is a workflow-wide field and is not tied to a specific revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_env_vars" type="map(string)">
  Optional. User-defined environment variables associated with this workflow revision. This map has a maximum length of 20. Each string can take up to 4KiB. Keys cannot be empty strings and cannot start with "GOOGLE" or "WORKFLOWS". Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_workflows_v1beta_workflow` defines a Workflows definition, an orchestration of ordered step(s) calling HTTP endpoints or Google Cloud APIs, executed as a managed serverless workflow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workflows "github.com/ubiquex/ubx-sdk-google/sdk/go/google/workflows"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta workflow"})

    		ubx.Resource(workflows.V1betaWorkflow, "example", workflows.V1betaWorkflowConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp of when the workflow was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the workflow provided by the user. Must be at most 1000 unicode characters long. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels associated with this workflow. Labels can contain at most 64 entries. Keys and values can be no longer than 63 characters and can only contain lowercase letters, numeric characters, underscores and dashes. Label keys must start with a letter. International characters are allowed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the workflow. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/workflows/&#123;workflow&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="revision_create_time" type="string">
  Output only. The timestamp that the latest revision of the workflow was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="revision_id" type="string">
  Output only. The revision of the workflow. A new revision of a workflow is created as a result of updating the following properties of a workflow: - Service account - Workflow code to be executed The format is "000001-a4d", where the first 6 characters define the zero-padded revision ordinal number. They are followed by a hyphen and 3 hexadecimal random characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_account" type="string">
  The service account associated with the latest workflow version. This service account represents the identity of the workflow and determines what permissions the workflow has. Format: projects/&#123;project&#125;/serviceAccounts/&#123;account&#125; or &#123;account&#125; Using `-` as a wildcard for the `&#123;project&#125;` or not providing one at all will infer the project from the account. The `&#123;account&#125;` value can be the `email` address or the `unique_id` of the service account. If not provided, workflow will use the project's default service account. Modifying this field for an existing workflow results in a new workflow revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_contents" type="string">
  Workflow code to be executed. The size limit is 128KB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the workflow deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last update timestamp of the workflow. Optional; if omitted, computed by Google Cloud.
</ResponseField>

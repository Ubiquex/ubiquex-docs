`google_translate_adaptive_mt_dataset` is a Cloud Translation Adaptive Translation dataset, a real, small set of example translations combined with a large language model at request time to produce nuanced, style-consistent translations without training or maintaining a full custom model.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	translate "github.com/ubiquex/ubx-sdk-google/sdk/go/google/translate"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own adaptive mt dataset"})

    		ubx.Resource(translate.AdaptiveMtDataset, "example", translate.AdaptiveMtDatasetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this dataset was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The name of the dataset to show in the interface. The name can be up to 32 characters long and can consist only of ASCII Latin letters A-Z and a-z, underscores (_), and ASCII digits 0-9. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="example_count" type="number">
  The number of examples in the dataset. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the dataset, in form of `projects/&#123;project-number-or-id&#125;/locations/&#123;location_id&#125;/adaptiveMtDatasets/&#123;dataset_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_language_code" type="string">
  The BCP-47 language code of the source language. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_language_code" type="string">
  The BCP-47 language code of the target language. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this dataset was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

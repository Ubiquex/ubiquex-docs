`google_translate_dataset` is a Cloud Translation custom-model training dataset, the real, managed collection of source/target text pairs used to train a custom `google_translate_model`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	translate "github.com/ubiquex/ubx-sdk-google/sdk/go/google/translate"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dataset"})

    		ubx.Resource(translate.Dataset, "example", translate.DatasetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {

      resource(Dataset, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.translate import Dataset, DatasetConfig

    def describe():
        ubx.intent("example own dataset")

        ubx.resource(Dataset, "example", DatasetConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this dataset was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The name of the dataset to show in the interface. The name can be up to 32 characters long and can consist only of ASCII Latin letters A-Z and a-z, underscores (_), and ASCII digits 0-9. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="example_count" type="number">
  Output only. The number of examples in the dataset. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the dataset, in form of `projects/&#123;project-number-or-id&#125;/locations/&#123;location_id&#125;/datasets/&#123;dataset_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_language_code" type="string">
  The BCP-47 language code of the source language. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_language_code" type="string">
  The BCP-47 language code of the target language. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="test_example_count" type="number">
  Output only. Number of test examples (sentence pairs). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="train_example_count" type="number">
  Output only. Number of training examples (sentence pairs). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this dataset was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="validate_example_count" type="number">
  Output only. Number of validation examples (sentence pairs). Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_translate_glossary` is a Cloud Translation glossary, a real custom dictionary of domain-specific terms and their required translations, applied so Cloud Translation renders those terms correctly and consistently instead of using its own default choice.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	translate "github.com/ubiquex/ubx-sdk-google/sdk/go/google/translate"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own glossary"})

    		ubx.Resource(translate.Glossary, "example", translate.GlossaryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.google.translate.glossary import Glossary, GlossaryConfig

    def describe():
        ubx.intent("example own glossary")

        ubx.resource(Glossary, "example", GlossaryConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="display_name" type="string">
  Optional. The display name of the glossary. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Output only. When the glossary creation was finished. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="entry_count" type="number">
  Output only. The number of entries defined in the glossary. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="input_config" type="object">
  Input configuration for glossaries. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="gcs_source" type="object">
      The Google Cloud Storage location for the input content. Optional.
      <Expandable title="properties">
        <ResponseField name="input_uri" type="string">
          Required. Source data URI. For example, `gs://my_bucket/my_object`. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="language_codes_set" type="object">
  Used with equivalent term set glossaries. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="language_codes" type="list(string)">
      Optional. The ISO-639 language code(s) for terms defined in the glossary. All entries are unique. The list contains at least two entries. Expected to be an exact match for GlossaryTerm.language_code. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="language_pair" type="object">
  Used with unidirectional glossaries. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="source_language_code" type="string">
      Required. The ISO-639 language code of the input text, for example, "en-US". Expected to be an exact match for GlossaryTerm.language_code. Optional.
    </ResponseField>
    <ResponseField name="target_language_code" type="string">
      Required. The ISO-639 language code for translation output, for example, "zh-CN". Expected to be an exact match for GlossaryTerm.language_code. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the glossary. Glossary names have the form `projects/&#123;project-number-or-id&#125;/locations/&#123;location-id&#125;/glossaries/&#123;glossary-id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="submit_time" type="string">
  Output only. When CreateGlossary was called. Optional; if omitted, computed by Google Cloud.
</ResponseField>

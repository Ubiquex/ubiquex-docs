`google_translate_glossary_entry` is one real term-and-translation pair inside a `google_translate_glossary`, the individual mapping Cloud Translation enforces when that source term appears in text to translate.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_translate --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_translate/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	translate "github.com/ubiquex/ubx-sdk-google/sdk/go/google_translate/translate"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own glossary entry"})

    		ubx.Resource(translate.TranslateGlossaryEntry, "ci-runner", translate.TranslateGlossaryEntryConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="description" type="string">
  Describes the glossary entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the entry. Format: `projects/*/locations/*/glossaries/*/glossaryEntries/*` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="terms_pair" type="object">
  Represents a single entry for an unidirectional glossary. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="source_term" type="object">
      Represents a single glossary term Optional.
      <Expandable title="properties">
        <ResponseField name="language_code" type="string">
          The language for this glossary term. Optional.
        </ResponseField>
        <ResponseField name="text" type="string">
          The text for the glossary term. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="target_term" type="object">
      Represents a single glossary term Optional.
      <Expandable title="properties">
        <ResponseField name="language_code" type="string">
          The language for this glossary term. Optional.
        </ResponseField>
        <ResponseField name="text" type="string">
          The text for the glossary term. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="terms_set" type="object">
  Represents a single entry for an equivalent term set glossary. This is used for equivalent term sets where each term can be replaced by the other terms in the set. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="terms" type="list(object)">
      Each term in the set represents a term that can be replaced by the other terms. Optional.
      <Expandable title="properties">
        <ResponseField name="language_code" type="string">
          The real BCP-47 language code this glossary term is written in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="text" type="string">
          The real, literal term text in this glossary entry's own language-specific term set. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

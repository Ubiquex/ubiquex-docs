`google_logging_view` restricts a principal's own access within a Cloud Logging log bucket to a defined filtered subset of its log entries, for role-based data isolation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	logging "github.com/ubiquex/ubx-sdk-google/sdk/go/google/logging"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own view"})

    		ubx.Resource(logging.View, "example", logging.ViewConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp of the view. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Describes this view. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter" type="string">
  Optional. Filter that restricts which log entries in a bucket are visible in this view.Filters must be logical conjunctions that use the AND operator, and they can use any of the following qualifiers: SOURCE(), which specifies a project, folder, organization, or billing account of origin. resource.type, which specifies the resource type. LOG_ID(), which identifies the log.They can also use the negations of these qualifiers with the NOT operator.For example:SOURCE("projects/myproject") AND resource.type = "gce_instance" AND NOT LOG_ID("stdout") Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the view.For example:projects/my-project/locations/global/buckets/my-bucket/views/my-view Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last update timestamp of the view. Optional; if omitted, computed by Google Cloud.
</ResponseField>

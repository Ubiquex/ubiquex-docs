`hashicorp/google` provider schema, in every SDK language.

real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	logging "github.com/ubiquex/ubx-sdk-google/sdk/go/google/logging"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own metric"})

    		ubx.Resource(logging.Metric, "ci-runner", logging.MetricConfig{
    			Filter:          "example",
    			Name:            "ci-runner",
    			BucketName:      "example-bucket-name",
    			Description:     "Managed by ubx.",
    			Disabled:        true,
    			LabelExtractors: map[string]string{"managed-by": "ubx"},
    			ValueExtractor:  "example",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="deletion_policy" type="string">
  Whether Terraform will be prevented from destroying the instance. Defaults to "DELETE". When a 'terraform destroy' or 'terraform apply' would delete the instance, the command will fail if this field is set to "PREVENT" in Terraform state. When set to "ABANDON", the command will remove the resource from Terraform management without updating or deleting the resource in the API. When set to "DELETE", deleting the resource is allowed. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="description" type="string">
  A description of this metric, which is used in documentation. The maximum length of the description is 8000 characters. Optional.
</ResponseField>

<ResponseField name="disabled" type="bool">
  If set to True, then this metric is disabled and it does not generate any points. Optional.
</ResponseField>

<ResponseField name="filter" type="string" required>
  An advanced logs filter (https://cloud.google.com/logging/docs/view/advanced-filters) which is used to match log entries. Required.
</ResponseField>

<ResponseField name="id" type="string">

</ResponseField>

<ResponseField name="label_extractors" type="map(string)">
  A map from a label key string to an extractor expression which is used to extract data from a log entry field and assign as the label value. Each label key specified in the LabelDescriptor must have an associated extractor expression in this map. The syntax of the extractor expression is the same as for the valueExtractor field. Optional.
</ResponseField>

<ResponseField name="value_extractor" type="string">
  A valueExtractor is required when using a distribution logs-based metric to extract the values to record from a log entry. Two functions are supported for value extraction - EXTRACT(field) or REGEXP_EXTRACT(field, regex). The argument are 1. field - The name of the log entry field from which the value is to be extracted. 2. regex - A regular expression using the Google RE2 syntax (https://github.com/google/re2/wiki/Syntax) with a single capture group to extract data from the specified log entry field. The value of the field is converted to a string before applying the regex. It is an error to specify a regex that does not include exactly one capture group. Optional.
</ResponseField>

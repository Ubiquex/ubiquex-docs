`google_logging_bucket` is a Cloud Logging log bucket, the storage container ingested log entries are retained in for a configured retention period and made queryable from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	logging "github.com/ubiquex/ubx-sdk-google/sdk/go/google/logging"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own bucket"})

    		ubx.Resource(logging.Bucket, "example", logging.BucketConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

`google_logging_exclusion` filters out matching log entries before they're ingested into a Cloud Logging sink or bucket, reducing storage cost and noise for logs that don't need to be kept.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	logging "github.com/ubiquex/ubx-sdk-google/sdk/go/google/logging"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own exclusion"})

    		ubx.Resource(logging.Exclusion, "example", logging.ExclusionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp of the exclusion.This field may not be present for older exclusions. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of this exclusion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. If set to True, then this exclusion is disabled and it does not exclude any log entries. You can update an exclusion to change the value of this field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter" type="string">
  Required. An advanced logs filter (https://docs.cloud.google.com/logging/docs/view/building-queries#queries-by-expression) that matches the log entries to be excluded. By using the sample function (https://docs.cloud.google.com/logging/docs/view/logging-query-language#sample), you can exclude less than 100% of the matching log entries.For example, the following query matches 99% of low-severity log entries from Google Cloud Storage buckets:resource.type=gcs_bucket severity&lt;ERROR sample(insertId, 0.99) Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Optional. A client-assigned identifier, such as "load-balancer-exclusion". Identifiers are limited to 100 characters and can include only letters, digits, underscores, hyphens, and periods. First character has to be alphanumeric. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last update timestamp of the exclusion.This field may not be present for older exclusions. Optional; if omitted, computed by Google Cloud.
</ResponseField>

title: "google_logging_link"

---

`google_logging_link` links a Cloud Logging log bucket to a BigQuery dataset, enabling that bucket's own log data to be queried directly with SQL via BigQuery's own analytics engine.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_logging --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_logging/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	logging "github.com/ubiquex/ubx-sdk-google/sdk/go/google_logging/logging"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own link"})

    		ubx.Resource(logging.LoggingLink, "example", logging.LoggingLinkConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_logging --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {
      intent({ summary: "example own link" });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_logging --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_logging/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_logging.logging import LoggingLink, LoggingLinkConfig

    def describe():
        ubx.intent("example own link")

        ubx.resource(LoggingLink, "example", LoggingLinkConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="bigquery_dataset" type="object">
  Describes a BigQuery dataset that was created by a link. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dataset_id" type="string">
      Output only. The full resource name of the BigQuery dataset. The DATASET_ID will match the ID of the link, so the link must match the naming restrictions of BigQuery datasets (alphanumeric characters and underscores only).The dataset will have a resource path of "bigquery.googleapis.com/projects/PROJECT_ID/datasets/DATASET_ID" Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp of the link. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Describes this link.The maximum length of the description is 8000 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="lifecycle_state" type="string">
  Output only. The resource lifecycle state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the link. The name can have up to 100 characters. A valid link id (at the end of the link name) must only have alphanumeric characters and underscores within it. "projects/[PROJECT_ID]/locations/[LOCATION_ID]/buckets/[BUCKET_ID]/links/[LINK_ID]" "organizations/[ORGANIZATION_ID]/locations/[LOCATION_ID]/buckets/[BUCKET_ID]/links/[LINK_ID]" "billingAccounts/[BILLING_ACCOUNT_ID]/locations/[LOCATION_ID]/buckets/[BUCKET_ID]/links/[LINK_ID]" "folders/[FOLDER_ID]/locations/[LOCATION_ID]/buckets/[BUCKET_ID]/links/[LINK_ID]" For example:`projects/my-project/locations/global/buckets/my-bucket/links/my_link Optional; if omitted, computed by Google Cloud.
</ResponseField>

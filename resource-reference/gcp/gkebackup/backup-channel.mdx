`google_gkebackup_backup_channel` establishes cross-project connectivity letting a GKE backup plan back up a cluster running in a different project than the backup itself is stored in.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	gkebackup "github.com/ubiquex/ubx-sdk-google/sdk/go/google/gkebackup"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own backup channel"})

    		ubx.Resource(gkebackup.BackupChannel, "example", gkebackup.BackupChannelConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this BackupChannel resource was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. User specified descriptive string for this BackupChannel. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination_project" type="string">
  Required. Immutable. The project where Backups are allowed to be stored. The format is `projects/&#123;projectId&#125;` or `projects/&#123;projectNumber&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination_project_id" type="string">
  Output only. The project_id where Backups are allowed to be stored. Example Project ID: "my-project-id". This will be an OUTPUT_ONLY field to return the project_id of the destination project. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. `etag` is used for optimistic concurrency control as a way to help prevent simultaneous updates of a BackupChannel from overwriting each other. It is strongly suggested that systems make use of the 'etag' in the read-modify-write cycle to perform BackupChannel updates in order to avoid race conditions: An `etag` is returned in the response to `GetBackupChannel`, and systems are expected to put that etag in the request to `UpdateBackupChannel` or `DeleteBackupChannel` to ensure that their change will be applied to the same version of the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. A set of custom labels supplied by user. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The fully qualified name of the BackupChannel. `projects/*/locations/*/backupChannels/*` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Server generated global unique identifier of [UUID](https://en.wikipedia.org/wiki/Universally_unique_identifier) format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when this BackupChannel resource was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

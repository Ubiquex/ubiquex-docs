`google_bigqueryreservation_capacity_commitment` purchases a fixed amount of BigQuery slot capacity for a committed term (e.g. one or three years) at a discounted rate versus on-demand pricing.

## Properties

<ResponseField name="commitment_end_time" type="string">
  Output only. The end of the current commitment period. It is applicable only for ACTIVE capacity commitments. Note after renewal, commitment_end_time is the time the renewed commitment expires. So itwould be at a time after commitment_start_time + committed period, because we don't change commitment_start_time , Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="commitment_start_time" type="string">
  Output only. The start of the current commitment period. It is applicable only for ACTIVE capacity commitments. Note after the commitment is renewed, commitment_start_time won't be changed. It refers to the start time of the original commitment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="edition" type="string">
  Optional. Edition of the capacity commitment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_flat_rate" type="bool">
  Output only. If true, the commitment is a flat-rate commitment, otherwise, it's an edition commitment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="multi_region_auxiliary" type="bool">
  Applicable only for commitments located within one of the BigQuery multi-regions (US or EU). If set to true, this commitment is placed in the organization's secondary region which is designated for disaster recovery purposes. If false, this commitment is placed in the organization's default region. NOTE: this is a preview feature. Project must be allow-listed in order to set this field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the capacity commitment, e.g., `projects/myproject/locations/US/capacityCommitments/123` The commitment_id must only contain lower case alphanumeric characters or dashes. It must start with a letter and must not end with a dash. Its maximum length is 64 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="plan" type="string">
  Optional. Capacity commitment commitment plan. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="renewal_plan" type="string">
  Optional. The plan this capacity commitment is converted to after commitment_end_time passes. Once the plan is changed, committed period is extended according to commitment plan. Only applicable for ANNUAL and TRIAL commitments. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="slot_count" type="string">
  Optional. Number of slots in this commitment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the commitment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

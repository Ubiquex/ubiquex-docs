`google_sql_database` -- real, typed bindings generated directly from the
`hashicorp/google` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-google-go/google/sql"
    )

    cfg := sql.DatabaseConfig{
        Instance: "example",
        Name: "example-name",
    }
    ubx.Resource(sql.Database, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Database } from
      "jsr:@ubx/sdk-google/google/sql/database";

    resource(Database, "example", {
      instance: "example",
      name: "example-name",
    });
    ```
  </Tab>
  <Tab title="Python">

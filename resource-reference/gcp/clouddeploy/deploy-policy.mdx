`google_clouddeploy_deploy_policy` restricts when and how Cloud Deploy rollouts are permitted to run against a target, e.g. blocking deployments outside an approved change window.

## Example

  <Tab title="Go">
    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_clouddeploy/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	clouddeploy "github.com/ubiquex/ubx-sdk-google/sdk/go/google_clouddeploy/clouddeploy"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own deploy policy"})

    		ubx.Resource(clouddeploy.ClouddeployDeployPolicy, "ci-runner", clouddeploy.ClouddeployDeployPolicyConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

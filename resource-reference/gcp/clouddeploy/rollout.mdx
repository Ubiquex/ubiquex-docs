`google_clouddeploy_rollout` is the actual deployment of a Cloud Deploy release to one specific target in the delivery pipeline, the unit that succeeds, fails, or is rolled back.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	clouddeploy "github.com/ubiquex/ubx-sdk-google/sdk/go/google/clouddeploy"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own rollout"})

    		ubx.Resource(clouddeploy.Rollout, "example", clouddeploy.RolloutConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

`google_clouddeploy_custom_target_type` defines a Cloud Deploy target type for a deployment destination not natively supported (e.g. a custom Kubernetes operator or a non-Google runtime), via a caller-supplied Skaffold custom action.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	clouddeploy "github.com/ubiquex/ubx-sdk-google/sdk/go/google/clouddeploy"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom target type"})

    		ubx.Resource(clouddeploy.CustomTargetType, "example", clouddeploy.CustomTargetTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

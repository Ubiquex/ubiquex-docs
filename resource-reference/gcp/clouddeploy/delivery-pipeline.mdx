`google_clouddeploy_delivery_pipeline` defines the ordered sequence of target(s) (e.g. dev, staging, prod) a Cloud Deploy release progressively rolls out through.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	clouddeploy "github.com/ubiquex/ubx-sdk-google/sdk/go/google/clouddeploy"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own delivery pipeline"})

    		ubx.Resource(clouddeploy.DeliveryPipeline, "example", clouddeploy.DeliveryPipelineConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_cloudresourcemanager_v2beta1_folder` groups project(s) and other folder(s) together in the Google Cloud resource hierarchy, letting IAM policy and organization policy be applied to the whole group at once.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudresourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudresourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 folder"})

    		ubx.Resource(cloudresourcemanager.V2beta1Folder, "example", cloudresourcemanager.V2beta1FolderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="configured_capabilities" type="list(string)">
  Output only. Optional capabilities configured for this folder (via UpdateCapability API). Example: `folders/123/capabilities/app-management`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Timestamp when the Folder was created. Assigned by the server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The folder's display name. A folder's display name must be unique amongst its siblings, e.g. no two folders with the same parent can share the same display name. The display name must start and end with a letter or digit, may contain letters, digits, spaces, hyphens and underscores and can be no longer than 30 characters. This is captured by the regular expression: `[\p&#123;L&#125;\p&#123;N&#125;]([\p&#123;L&#125;\p&#123;N&#125;_- ]&#123;0,28&#125;[\p&#123;L&#125;\p&#123;N&#125;])?`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="lifecycle_state" type="string">
  Output only. The lifecycle state of the folder. Updates to the lifecycle_state must be performed via DeleteFolder and UndeleteFolder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="management_project" type="string">
  Output only. Management Project associated with this folder (if app-management capability is enabled). Example: `projects/google-mp-123` OUTPUT ONLY. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the Folder. Its format is `folders/&#123;folder_id&#125;`, for example: "folders/1234". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent" type="string">
  Required. The Folder's parent's resource name. Updates to the folder's parent must be performed via MoveFolder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Optional. Input only. Immutable. Tag keys/values directly bound to this folder. Each item in the map must be expressed as " : ". For example: "123/environment" : "production", "123/costCenter" : "marketing" Note: Currently this field is in Preview. Optional; if omitted, computed by Google Cloud.
</ResponseField>

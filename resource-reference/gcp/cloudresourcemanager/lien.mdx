`google_cloudresourcemanager_lien` blocks a Google Cloud project from being deleted until the lien is explicitly removed, a safeguard against accidental deletion of a project something else depends on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudresourcemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudresourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudresourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudresourcemanager/cloudresourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own lien"})

    		ubx.Resource(cloudresourcemanager.CloudresourcemanagerLien, "example", cloudresourcemanager.CloudresourcemanagerLienConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  The creation time of this Lien. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  A system-generated unique identifier for this Lien. Example: `liens/1234abcd` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="origin" type="string">
  A stable, user-visible/meaningful string identifying the origin of the Lien, intended to be inspected programmatically. Maximum length of 200 characters. Example: 'compute.googleapis.com' Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent" type="string">
  A reference to the resource this Lien is attached to. The server will validate the parent against those for which Liens are supported. Example: `projects/1234` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reason" type="string">
  Concise user-visible strings indicating why an action cannot be performed on a resource. Maximum length of 200 characters. Example: 'Holds production API key' Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="restrictions" type="list(string)">
  The types of operations which should be blocked as a result of this Lien. Each value should correspond to an IAM permission. The server will validate the permissions against those for which Liens are supported. An empty list is meaningless and will be rejected. Example: ['resourcemanager.projects.delete'] Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_cloudresourcemanager_tag_value` defines a specific permitted value (e.g. `production`) under a resource tag key, that can be attached to resources and referenced by conditional IAM bindings or organization policy.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudresourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudresourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudresourcemanager/cloudresourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tag value"})

    		ubx.Resource(cloudresourcemanager.CloudresourcemanagerTagValue, "example", cloudresourcemanager.CloudresourcemanagerTagValueConfig{
    			Name: "example",
    		})
    	}))
    }

## Properties

<ResponseField name="create_time" type="string">
  Output only. Creation time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. User-assigned description of the TagValue. Must not exceed 256 characters. Read-write. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Entity tag which users can pass to prevent race conditions. This field is always set in server responses. See UpdateTagValueRequest for details. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Resource name for TagValue in the format `tagValues/456`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="namespaced_name" type="string">
  Output only. The namespaced name of the TagValue. Can be in the form `&#123;organization_id&#125;/&#123;tag_key_short_name&#125;/&#123;tag_value_short_name&#125;` or `&#123;project_id&#125;/&#123;tag_key_short_name&#125;/&#123;tag_value_short_name&#125;` or `&#123;project_number&#125;/&#123;tag_key_short_name&#125;/&#123;tag_value_short_name&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent" type="string">
  Immutable. The resource name of the new TagValue's parent TagKey. Must be of the form `tagKeys/&#123;tag_key_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="short_name" type="string">
  Required. Immutable. User-assigned short name for TagValue. The short name should be unique for TagValues within the same parent TagKey. The short name must be 256 characters or less, beginning and ending with an alphanumeric character ([a-z0-9A-Z]) with dashes (-), underscores (_), dots (.), and alphanumerics between. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

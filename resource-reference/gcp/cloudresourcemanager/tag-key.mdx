`google_cloudresourcemanager_tag_key` defines a named key (e.g. `environment`) for Google Cloud resource tags, that specific tag value(s) are created underneath and attached to resources for organization policy and access-control targeting.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudresourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudresourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tag key"})

    		ubx.Resource(cloudresourcemanager.TagKey, "example", cloudresourcemanager.TagKeyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="allowed_values_regex" type="string">
  Optional. Regular expression constraint for freeform tag values. If present, it implicitly allows freeform values (constrained by the regex). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. User-assigned description of the TagKey. Must not exceed 256 characters. Read-write. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Entity tag which users can pass to prevent race conditions. This field is always set in server responses. See UpdateTagKeyRequest for details. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name for a TagKey. Must be in the format `tagKeys/&#123;tag_key_id&#125;`, where `tag_key_id` is the generated numeric id for the TagKey. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="namespaced_name" type="string">
  Output only. Immutable. Namespaced name of the TagKey. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent" type="string">
  Immutable. The resource name of the TagKey's parent. A TagKey can be parented by an Organization or a Project. For a TagKey parented by an Organization, its parent must be in the form `organizations/&#123;org_id&#125;`. For a TagKey parented by a Project, its parent can be in the form `projects/&#123;project_id&#125;` or `projects/&#123;project_number&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="purpose" type="string">
  Optional. A purpose denotes that this Tag is intended for use in policies of a specific policy engine, and will involve that policy engine in management operations involving this Tag. A purpose does not grant a policy engine exclusive rights to the Tag, and it may be referenced by other policy engines. A purpose cannot be changed once set. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="purpose_data" type="map(string)">
  Optional. Purpose data corresponds to the policy system that the tag is intended for. See documentation for `Purpose` for formatting of this field. Purpose data cannot be changed once set. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="short_name" type="string">
  Required. Immutable. The user friendly name for a TagKey. The short name should be unique for TagKeys within the same tag namespace. The short name must be 1-256 characters, beginning and ending with an alphanumeric character ([a-z0-9A-Z]) with dashes (-), underscores (_), dots (.), and alphanumerics between. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

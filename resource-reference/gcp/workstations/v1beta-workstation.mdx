`google_workstations_v1beta_workstation` is a single Cloud Workstations development environment instance -- a remote VM running a preconfigured IDE and toolchain -- provisioned from a workstation configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workstations "github.com/ubiquex/ubx-sdk-google/sdk/go/google/workstations"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta workstation"})

    		ubx.Resource(workstations.V1betaWorkstation, "example", workstations.V1betaWorkstationConfig_{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="etag" type="string">
  Optional. Checksum computed by the server. May be sent on update and delete requests to make sure that the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="host" type="string">
  Output only. Host to which clients can send HTTPS traffic that will be received by the workstation. Authorized traffic will be received to the workstation as HTTP on port 80. To send traffic to a different port, clients may prefix the host with the destination port in the format `&#123;port&#125;-&#123;host&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kms_key" type="string">
  Output only. The name of the Google Cloud KMS encryption key used to encrypt this workstation. The KMS key can only be configured in the WorkstationConfig. The expected format is `projects/*/locations/*/keyRings/*/cryptoKeys/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_contactcenterinsights_revision` is a saved, versioned snapshot of a QA scorecard's own question set, letting past assessments remain tied to the exact scorecard version they were scored against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_contactcenterinsights --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_contactcenterinsights/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google_contactcenterinsights/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own revision"})

    		ubx.Resource(contactcenterinsights.ContactcenterinsightsRevision, "ci-runner", contactcenterinsights.ContactcenterinsightsRevisionConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="alternate_ids" type="list(string)">
  Output only. Alternative IDs for this revision of the scorecard, e.g., `latest`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp that the revision was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the scorecard revision. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/qaScorecards/&#123;qa_scorecard&#125;/revisions/&#123;revision&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="snapshot" type="object">
  A QaScorecard represents a collection of questions to be scored during analysis. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="create_time" type="string">
      Output only. The time at which this scorecard was created. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="description" type="string">
      A text description explaining the intent of the scorecard. Optional.
    </ResponseField>
    <ResponseField name="display_name" type="string">
      The user-specified display name of the scorecard. Optional.
    </ResponseField>
    <ResponseField name="is_default" type="bool">
      Whether the scorecard is the default one for the project. A default scorecard cannot be deleted and will always appear first in scorecard selector. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      Identifier. The scorecard name. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/qaScorecards/&#123;qa_scorecard&#125; Optional.
    </ResponseField>
    <ResponseField name="source" type="string">
      Output only. The source of the scorecard. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="update_time" type="string">
      Output only. The most recent time at which the scorecard was updated. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the scorecard revision, indicating whether it's ready to be used in analysis. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_contactcenterinsights_qa_question` defines a single quality-assurance question (e.g. `Did the agent greet the customer?`) within a QA scorecard, either scored manually or automatically.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own qa question"})

    		ubx.Resource(contactcenterinsights.QaQuestion, "example", contactcenterinsights.QaQuestionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="abbreviation" type="string">
  Short, descriptive string, used in the UI where it's not practical to display the full question body. E.g., "Greeting". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="answer_choices" type="list(object)">
  A list of valid answers to the question, which the LLM must choose from. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="bool_value" type="bool">
      A `true`/`false` value, populated when this field's own type is boolean. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="key" type="string">
      The key of this key/value pair. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="na_value" type="bool">
      Marks this QA answer as not applicable, rather than providing a real value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="num_value" type="number">
      A numeric value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="score" type="number">
      The numeric score this evaluation produced. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="str_value" type="string">
      A text value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="answer_instructions" type="string">
  Instructions describing how to determine the answer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this question was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metrics" type="object">
  A wrapper representing metrics calculated against a test-set on a LLM that was fine tuned for this question. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="accuracy" type="number">
      Output only. Accuracy of the model. Measures the percentage of correct answers the model gave on the test set. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the question. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/qaScorecards/&#123;qa_scorecard&#125;/revisions/&#123;revision&#125;/qaQuestions/&#123;qa_question&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="order" type="number">
  Defines the order of the question within its parent scorecard revision. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="predefined_question_config" type="object">
  Configuration for a predefined question. This field will only be set if the Question Type is predefined. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      The type of the predefined question. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="qa_question_data_options" type="object">
  Options for configuring the data used to generate the QA question. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="conversation_data_options" type="object">
      Options for configuring what metadata is included in the conversation data used in QAI and Discovery Engine. Optional.
      <Expandable title="properties">
        <ResponseField name="include_dialogflow_interaction_data" type="bool">
          Whether to include the per turn Dialogflow interaction data in conversation transcript. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="question_body" type="string">
  Question text. E.g., "Did the agent greet the customer?" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="question_type" type="string">
  The type of question. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tags" type="list(string)">
  Questions are tagged for categorization and scoring. Tags can either be: - Default Tags: These are predefined categories. They are identified by their string value (e.g., "BUSINESS", "COMPLIANCE", and "CUSTOMER"). - Custom Tags: These are user-defined categories. They are identified by their full resource name (e.g., projects/&#123;project&#125;/locations/&#123;location&#125;/qaQuestionTags/&#123;qa_question_tag&#125;). Both default and custom tags are used to group questions and to influence the scoring of each question. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tuning_metadata" type="object">
  Metadata about the tuning operation for the question. Will only be set if a scorecard containing this question has been tuned. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dataset_validation_warnings" type="list(string)">
      A list of any applicable data validation warnings about the question's feedback labels. Optional.
    </ResponseField>
    <ResponseField name="total_valid_label_count" type="string">
      Total number of valid labels provided for the question at the time of tuining. Optional.
    </ResponseField>
    <ResponseField name="tuning_error" type="string">
      Error status of the tuning operation for the question. Will only be set if the tuning operation failed. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which the question was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

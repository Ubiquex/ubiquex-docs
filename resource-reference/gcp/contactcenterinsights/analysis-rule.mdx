`google_contactcenterinsights_analysis_rule` automatically triggers a Contact Center AI Insights analysis on conversation(s) matching a defined filter, instead of requiring each analysis to be requested manually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own analysis rule"})

    		ubx.Resource(contactcenterinsights.AnalysisRule, "example", contactcenterinsights.AnalysisRuleConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="active" type="bool">
  If true, apply this rule to conversations. Otherwise, this rule is inactive and saved as a draft. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="analysis_percentage" type="number">
  Percentage of conversations that we should apply this analysis setting automatically, between [0, 1]. For example, 0.1 means 10%. Conversations are sampled in a determenestic way. The original runtime_percentage & upload percentage will be replaced by defining filters on the conversation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="annotator_selector" type="object">
  Selector of all available annotators and phrase matchers to run. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="issue_models" type="list(string)">
      The issue model to run. If not provided, the most recently deployed topic model will be used. The provided issue model will only be used for inference if the issue model is deployed and if run_issue_model_annotator is set to true. If more than one issue model is provided, only the first provided issue model will be used for inference. Optional.
    </ResponseField>
    <ResponseField name="phrase_matchers" type="list(string)">
      The list of phrase matchers to run. If not provided, all active phrase matchers will be used. If inactive phrase matchers are provided, they will not be used. Phrase matchers will be run only if run_phrase_matcher_annotator is set to true. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/phraseMatchers/&#123;phrase_matcher&#125; Optional.
    </ResponseField>
    <ResponseField name="qa_config" type="object">
      Configuration for the QA feature. Optional.
      <Expandable title="properties">
        <ResponseField name="scorecard_list" type="object">
          Container for a list of scorecards. Optional.
          <Expandable title="properties">
            <ResponseField name="qa_scorecard_revisions" type="list(string)">
              List of QaScorecardRevisions. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="run_auto_labeling_annotator" type="bool">
      Optional. Whether to run the auto-labeling annotator. If true, the auto-labeling annotator will be run. This is a non-billable operation designed for fixing or backfilling custom labels. Optional.
    </ResponseField>
    <ResponseField name="run_entity_annotator" type="bool">
      Whether to run the entity annotator. Optional.
    </ResponseField>
    <ResponseField name="run_intent_annotator" type="bool">
      Whether to run the intent annotator. Optional.
    </ResponseField>
    <ResponseField name="run_interruption_annotator" type="bool">
      Whether to run the interruption annotator. Optional.
    </ResponseField>
    <ResponseField name="run_issue_model_annotator" type="bool">
      Whether to run the issue model annotator. A model should have already been deployed for this to take effect. Optional.
    </ResponseField>
    <ResponseField name="run_phrase_matcher_annotator" type="bool">
      Whether to run the active phrase matcher annotator(s). Optional.
    </ResponseField>
    <ResponseField name="run_qa_annotator" type="bool">
      Whether to run the QA annotator. Optional.
    </ResponseField>
    <ResponseField name="run_sentiment_annotator" type="bool">
      Whether to run the sentiment annotator. Optional.
    </ResponseField>
    <ResponseField name="run_silence_annotator" type="bool">
      Whether to run the silence annotator. Optional.
    </ResponseField>
    <ResponseField name="run_summarization_annotator" type="bool">
      Whether to run the summarization annotator. Optional.
    </ResponseField>
    <ResponseField name="summarization_config" type="object">
      Configuration for summarization. Optional.
      <Expandable title="properties">
        <ResponseField name="conversation_profile" type="string">
          Resource name of the Dialogflow conversation profile. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/conversationProfiles/&#123;conversation_profile&#125; Optional.
        </ResponseField>
        <ResponseField name="generator" type="string">
          The resource name of the existing created generator. Format: projects//locations//generators/ Optional.
        </ResponseField>
        <ResponseField name="summarization_model" type="string">
          Default summarization model to be used. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="conversation_filter" type="string">
  Filter for the conversations that should apply this analysis rule. An empty filter means this analysis rule applies to all conversations. Refer to https://cloud.google.com/contact-center/insights/docs/filtering for details. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this analysis rule was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Display Name of the analysis rule. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the analysis rule. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/analysisRules/&#123;analysis_rule&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which this analysis rule was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

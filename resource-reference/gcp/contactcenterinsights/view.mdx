`google_contactcenterinsights_view` defines a saved, reusable filter over Contact Center AI Insights conversation data, used to scope dashboards, exports, or bulk analysis to a specific subset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_contactcenterinsights --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_contactcenterinsights/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google_contactcenterinsights/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own view"})

    		ubx.Resource(contactcenterinsights.ContactcenterinsightsView, "ci-runner", contactcenterinsights.ContactcenterinsightsViewConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which this view was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The human-readable display name of the view. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the view. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/views/&#123;view&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which the view was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="value" type="string">
  A filter to reduce conversation results to a specific subset. Refer to https://cloud.google.com/contact-center/insights/docs/filtering for details. Optional; if omitted, computed by Google Cloud.
</ResponseField>

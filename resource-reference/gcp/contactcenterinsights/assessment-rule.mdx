`google_contactcenterinsights_assessment_rule` automatically assigns quality assurance assessment(s) to conversation(s) matching a defined filter, for scheduled or sampled agent review.

## Properties

<ResponseField name="active" type="bool">
  If true, apply this rule to conversations. Otherwise, this rule is inactive. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this assessment rule was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Display Name of the assessment rule. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the assessment rule. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/assessmentRules/&#123;assessment_rule&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sample_rule" type="object">
  Message for sampling conversations. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="conversation_filter" type="string">
      To specify the filter for the conversions that should apply this sample rule. An empty filter means this sample rule applies to all conversations. Optional.
    </ResponseField>
    <ResponseField name="dimension" type="string">
      Optional. Group by dimension to sample the conversation. If no dimension is provided, the sampling will be applied to the project level. Current supported dimensions is 'quality_metadata.agent_info.agent_id'. Optional.
    </ResponseField>
    <ResponseField name="sample_percentage" type="number">
      Percentage of conversations that we should sample based on the dimension between [0, 100]. Optional.
    </ResponseField>
    <ResponseField name="sample_row" type="string">
      Number of the conversations that we should sample based on the dimension. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schedule_info" type="object">
  Message for schedule info. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="end_time" type="string">
      End time of the schedule. If not specified, will keep scheduling new pipelines for execution util the schedule is no longer active or deleted. Optional.
    </ResponseField>
    <ResponseField name="schedule" type="string">
      The groc expression. Format: `every number [synchronized]` Time units can be: minutes, hours Synchronized is optional and indicates that the schedule should be synchronized to the start of the interval: every 5 minutes synchronized means 00:00, 00:05 ... Otherwise the start time is random within the interval. Example: `every 5 minutes` could be 00:02, 00:07, 00:12, ... Optional.
    </ResponseField>
    <ResponseField name="start_time" type="string">
      Start time of the schedule. If not specified, will start as soon as the schedule is created. Optional.
    </ResponseField>
    <ResponseField name="time_zone" type="string">
      The timezone to use for the groc expression. If not specified, defaults to UTC. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which this assessment rule was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_contactcenterinsights_feedback_label` records a human-assigned ground-truth label on a conversation, used to evaluate and improve Contact Center AI Insights' own model accuracy.

## Example

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_contactcenterinsights/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google_contactcenterinsights/contactcenterinsights"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own feedback label"})

    		ubx.Resource(contactcenterinsights.ContactcenterinsightsFeedbackLabel, "ci-runner", contactcenterinsights.ContactcenterinsightsFeedbackLabelConfig{

    		})

    }

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time of the label. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="label" type="string">
  String label used for Topic Modeling. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labeled_resource" type="string">
  Name of the resource to be labeled. Supported resources are: * `projects/&#123;project&#125;/locations/&#123;location&#125;/qaScorecards/&#123;scorecard&#125;/revisions/&#123;revision&#125;/qaQuestions/&#123;question&#125;` * `projects/&#123;project&#125;/locations/&#123;location&#125;/issueModels/&#123;issue_model&#125;` * `projects/&#123;project&#125;/locations/&#123;location&#125;/generators/&#123;generator_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Resource name of the FeedbackLabel. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/conversations/&#123;conversation&#125;/feedbackLabels/&#123;feedback_label&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="qa_answer_label" type="object">
  Message for holding the value of a QaAnswer. QaQuestion.AnswerChoice defines the possible answer values for a question. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="bool_value" type="bool">
      Boolean value. Optional.
    </ResponseField>
    <ResponseField name="key" type="string">
      A short string used as an identifier. Matches the value used in QaQuestion.AnswerChoice.key. Optional.
    </ResponseField>
    <ResponseField name="na_value" type="bool">
      A value of "Not Applicable (N/A)". Should only ever be `true`. Optional.
    </ResponseField>
    <ResponseField name="normalized_score" type="number">
      Output only. Normalized score of the questions. Calculated as score / potential_score. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="num_value" type="number">
      Numerical value. Optional.
    </ResponseField>
    <ResponseField name="potential_score" type="number">
      Output only. The maximum potential score of the question. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="score" type="number">
      Output only. Numerical score of the answer. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="skip_value" type="bool">
      Output only. A value of "Skip". If provided, this field may only be set to `true`. If a question receives this answer, it will be excluded from any score calculations. This would mean that the question was not evaluated. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="str_value" type="string">
      String value. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time of the label. Optional; if omitted, computed by Google Cloud.
</ResponseField>

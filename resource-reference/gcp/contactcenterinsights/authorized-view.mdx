`google_contactcenterinsights_authorized_view` restricts a principal's own access within Contact Center AI Insights to a defined subset of conversation data, for role-based data isolation.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Properties

<ResponseField name="conversation_filter" type="string">
  A filter to reduce conversation results to a specific subset. The AuthorizedView's assigned permission (read/write) could be applied to the subset of conversations. If conversation_filter is empty, there is no restriction on the conversations that the AuthorizedView can access. Having *authorizedViews.get* access to the AuthorizedView means having the same read/write access to the Conversations (as well as metadata/annotations linked to the conversation) that this AuthorizedView has. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the authorized view was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Display Name. Limit 64 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the AuthorizedView. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/authorizedViewSets/&#123;authorized_view_set&#125;/authorizedViews/&#123;authorized_view&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which the authorized view was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

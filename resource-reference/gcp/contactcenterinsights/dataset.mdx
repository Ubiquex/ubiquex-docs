`google_contactcenterinsights_dataset` is a named collection of conversation(s) grouped together in Contact Center AI Insights, e.g. for training an issue model or running a bulk analysis.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dataset"})

    		ubx.Resource(contactcenterinsights.Dataset, "example", contactcenterinsights.DatasetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

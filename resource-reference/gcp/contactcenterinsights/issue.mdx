`google_contactcenterinsights_issue` is a single, automatically discovered topic or theme (e.g. `billing dispute`) within a Contact Center AI Insights issue model, that conversations are classified against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own issue"})

    		ubx.Resource(contactcenterinsights.Issue, "example", contactcenterinsights.IssueConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which this issue was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_description" type="string">
  Representative description of the issue. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The representative name for the issue. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the issue. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/issueModels/&#123;issue_model&#125;/issues/&#123;issue&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sample_utterances" type="list(string)">
  Output only. Resource names of the sample representative utterances that match to this issue. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time that this issue was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_contactcenterinsights_issue_model` trains an ML model over a set of conversations to automatically discover and classify the recurring issue(s) customers are calling about.

## Example

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which this issue model was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The representative name for the issue model. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="input_data_config" type="object">
  Configs for the input data used to create the issue model. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="filter" type="string">
      A filter to reduce the conversations used for training the model to a specific subset. Refer to https://cloud.google.com/contact-center/insights/docs/filtering for details. Optional.
    </ResponseField>
    <ResponseField name="medium" type="string">
      Medium of conversations used in training data. This field is being deprecated. To specify the medium to be used in training a new issue model, set the `medium` field on `filter`. Optional.
    </ResponseField>
    <ResponseField name="training_conversations_count" type="string">
      Output only. Number of conversations used in training. Output only. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="issue_count" type="string">
  Output only. Number of issues in this issue model. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="language_code" type="string">
  Language of the model. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="model_type" type="string">
  Type of the model. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the issue model. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/issueModels/&#123;issue_model&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the model. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="training_stats" type="object">
  Aggregated statistics about an issue model. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="analyzed_conversations_count" type="string">
      Number of conversations the issue model has analyzed at this point in time. Optional.
    </ResponseField>
    <ResponseField name="issue_stats" type="map(object)">
      Statistics on each issue. Key is the issue's resource name. Optional.
      <Expandable title="properties">
        <ResponseField name="display_name" type="string">
          A mutable, user-settable, human-readable name for this resource, shown in the console UI. Not required to be unique. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="issue" type="string">
          A reference to the detected issue this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="labeled_conversations_count" type="string">
          How many conversations have been manually labeled for this dataset. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="unclassified_conversations_count" type="string">
      Number of analyzed conversations for which no issue was applicable at this point in time. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which the issue model was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which this scorecard was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A text description explaining the intent of the scorecard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-specified display name of the scorecard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_default" type="bool">
  Whether the scorecard is the default one for the project. A default scorecard cannot be deleted and will always appear first in scorecard selector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The scorecard name. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/qaScorecards/&#123;qa_scorecard&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source" type="string">
  Output only. The source of the scorecard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which the scorecard was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_contactcenterinsights_auto_labeling_rule` automatically assigns a feedback label to conversation(s) matching a defined condition, building a labeled dataset without manual tagging.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own auto labeling rule"})

## Properties

<ResponseField name="active" type="bool">
  Whether the rule is active. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="conditions" type="list(object)">
  Conditions to apply for auto-labeling the label_key. Representing sequential block of if .. else if .. else statements. The value of the first matching condition will be used. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="condition" type="string">
      A boolean expression that must evaluate `true` for this to apply. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The literal value of this field. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this rule was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the rule. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-provided display name of the rule. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="label_key" type="string">
  The label key. This is also the &#123;auto_labeling_rule&#125; in the resource name. Only settable if label_key_type is LABEL_KEY_TYPE_CUSTOM. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="label_key_type" type="string">
  The type of the label key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the auto-labeling rule. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/autoLabelingRules/&#123;auto_labeling_rule&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recent time at which the rule was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_file --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_file/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	file "github.com/ubiquex/ubx-sdk-google/sdk/go/google_file/file"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own snapshot"})

    		ubx.Resource(file.FileSnapshot, "ci-runner", file.FileSnapshotConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_file --lang ts --out ./local-sdk

    export default stack("payments", () => {
    ```

  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_file --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_file/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_file.file import FileSnapshot, FileSnapshotConfig

    def describe():
        ubx.intent("payments own snapshot")

        ubx.resource(FileSnapshot, "ci-runner", FileSnapshotConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the snapshot was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the snapshot with 2048 characters or less. Requests with longer descriptions will be rejected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filesystem_used_bytes" type="string">
  Output only. The amount of bytes needed to allocate a full copy of the snapshot content Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the snapshot, in the format `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/instances/&#123;instance_id&#125;/snapshots/&#123;snapshot_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The snapshot state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

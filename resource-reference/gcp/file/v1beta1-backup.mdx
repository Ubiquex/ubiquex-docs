title: "google_file_v1beta1_backup"
description: "`google_file_v1beta1_backup` is a point-in-time backup of a Filestore instance's own file share, restorable to a new instance."
---

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_file_backup`.
</Warning>

## Properties

<ResponseField name="capacity_gb" type="string">
  Output only. Capacity of the source file share when the backup was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the backup was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the backup with 2048 characters or less. Requests with longer descriptions will be rejected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="download_bytes" type="string">
  Output only. Amount of bytes that will be downloaded if the backup is restored Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="file_system_protocol" type="string">
  Output only. The file system protocol of the source Filestore instance that this backup is created from. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kms_key_name" type="string">
  Immutable. KMS key name used for data encryption. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the backup, in the format `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/backups/&#123;backup_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_file_share" type="string">
  Name of the file share in the source Filestore instance that the backup is created from. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_instance" type="string">
  The resource name of the source Filestore instance, in the format `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/instances/&#123;instance_id&#125;`, used to create this backup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_instance_tier" type="string">
  Output only. The service tier of the source Filestore instance that this backup is created from. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The backup state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="storage_bytes" type="string">
  Output only. The size of the storage used by the backup. As backups share storage, this number is expected to change with backup creation/deletion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_file_v1beta1_share` is a real NFS share exported by a Filestore instance -- its own capacity_gb, mount_name, and nfs_export_options, with an optional backup source -- so a single Filestore instance can expose multiple, independently-sized and independently-configured shares rather than one fixed volume per instance.

## Properties

<ResponseField name="backup" type="string">
  Immutable. Full name of the Cloud Filestore Backup resource that this Share is restored from, in the format of projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/backups/&#123;backup_id&#125;. Empty, if the Share is created from scratch and not restored from a backup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="capacity_gb" type="string">
  File share capacity in gigabytes (GB). Filestore defines 1 GB as 1024^3 bytes. Must be greater than 0. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the share was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the share with 2048 characters or less. Requests with longer descriptions will be rejected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="mount_name" type="string">
  The mount name of the share. Must be 63 characters or less and consist of uppercase or lowercase letters, numbers, and underscores. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the share, in the format `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/instances/&#123;instance_id&#125;/shares/&#123;share_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

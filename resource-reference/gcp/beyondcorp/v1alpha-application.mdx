<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_beyondcorp_application`.

`google_beyondcorp_v1alpha_application` registers a private application under BeyondCorp Enterprise's own context-aware access policy, the resource IAM and access level(s) are granted against.

Each EndpointMatcher must contain a hostname pattern, such as "example.com", and one or more port numbers specified as a string, such as "443".

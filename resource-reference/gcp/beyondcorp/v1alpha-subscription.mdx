  This is Google Cloud's own **v1alpha** release channel (alpha). `google_beyondcorp_v1alpha_subscription` is a real BeyondCorp Enterprise subscription -- its own sku, seat_count, billing_account, and start_time/end_time -- tracking a customer's own licensed capacity for BeyondCorp Enterprise rather than that capacity being implicit in billing records alone.

## Properties

<ResponseField name="auto_renew_enabled" type="bool">
  Output only. Represents that, if subscription will renew or end when the term ends. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="billing_account" type="string">
  Optional. Name of the billing account in the format. e.g. billingAccounts/123456-123456-123456 Required if Subscription is of Paid type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time of the subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="csg_customer" type="bool">
  Optional. Whether the subscription is being created as part of the Citrix flow. If this field is set to true, the subscription should have both the start_time and end_time set in the request and the billing account used will be the Citrix master billing account regardless of what its set to in the request. This field can only be set to true in create requests. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Optional. End time of the subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Unique resource name of the Subscription. The name is ignored when creating a subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="seat_count" type="string">
  Optional. Number of seats in the subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="signup_source" type="string">
  Optional. Input only. The source from which the subscription was initiated, for example "admin-console-browser-overview" or "admin-console-security-insights". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sku" type="string">
  Required. SKU of subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  Optional. Start time of the subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subscriber_type" type="string">
  Output only. Type of subscriber. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Required. Type of subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.

`google_beyondcorp_v1alpha_connection` is a real BeyondCorp Enterprise connection between a private application (application_endpoint) and BeyondCorp's own access proxy (gateway), with its own connectors handling the actual network path -- so a private, on-prem or VPC-only application can be reached through BeyondCorp's zero-trust access model without a traditional VPN.

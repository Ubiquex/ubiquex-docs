<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_beyondcorp_v1alpha_connector` is a real, deployed BeyondCorp connector -- the agent that actually establishes the network path a connection depends on -- tracked by its own principal_info (its service identity) and resource_info (what it's running on), so a connection's own underlying network path can be inspected and managed as a distinct resource.

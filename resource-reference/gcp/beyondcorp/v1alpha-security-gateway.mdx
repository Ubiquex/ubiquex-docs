<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_beyondcorp_security_gateway`.
</Warning>

`google_beyondcorp_v1alpha_security_gateway` is BeyondCorp Enterprise's own secure web gateway resource, applying zero-trust access policy to web traffic without requiring a per-app connector.

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_appengine_version`.
</Warning>

`google_appengine_v1beta_version` is a specific, deployable version of an App Engine service, containing the actual application code and its own scaling and resource configuration.

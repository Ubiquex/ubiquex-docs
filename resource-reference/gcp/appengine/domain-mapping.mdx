title: "google_appengine_domain_mapping"
description: "`google_appengine_domain_mapping` maps a custom domain to an App Engine application, routing that domain's own traffic to the app."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	appengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/appengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own domain mapping"})

    		ubx.Resource(appengine.DomainMapping, "example", appengine.DomainMappingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

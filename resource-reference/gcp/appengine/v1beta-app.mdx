<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_appengine_app`.
</Warning>

`google_appengine_v1beta_app` is the single, per-project App Engine application resource -- once created, a project can have exactly one, and every App Engine service and version belongs to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_appengine_v1beta --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_appengine_v1beta/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	appengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google_appengine_v1beta/appengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta app"})

    		ubx.Resource(appengine.V1betaAppengineV1betaApp, "example", appengine.V1betaAppengineV1betaAppConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

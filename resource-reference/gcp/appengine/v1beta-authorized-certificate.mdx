title: "google_appengine_v1beta_authorized_certificate"
description: "`google_appengine_v1beta_authorized_certificate` uploads a caller-managed SSL certificate for use with a custom domain mapped to an App Engine application."
---

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_appengine_authorized_certificate`.
</Warning>

## Properties

<ResponseField name="certificate_raw_data" type="object">
  An SSL certificate obtained from a certificate authority. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="private_key" type="string">
      Unencrypted PEM encoded RSA private key. This field is set once on certificate creation and then encrypted. The key size must be 2048 bits or fewer. Must include the header and footer. Example: -----BEGIN RSA PRIVATE KEY----- -----END RSA PRIVATE KEY----- @InputOnly Optional.
    </ResponseField>
    <ResponseField name="public_certificate" type="string">
      PEM encoded x.509 public key certificate. This field is set once on certificate creation. Must include the header and footer. Example: -----BEGIN CERTIFICATE----- -----END CERTIFICATE----- Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-specified display name of the certificate. This is not guaranteed to be unique. Example: My Certificate. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="domain_mappings_count" type="number">
  Aggregate count of the domain mappings with this certificate mapped. This count includes domain mappings on applications for which the user does not have VIEWER permissions.Only returned by GET or LIST requests when specifically requested by the view=FULL_CERTIFICATE option.@OutputOnly Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="domain_names" type="list(string)">
  Output only. Topmost applicable domains of this certificate. This certificate applies to these domains and their subdomains. Example: example.com.@OutputOnly Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  The time when this certificate expires. To update the renewal time on this certificate, upload an SSL certificate with a different expiration time using AuthorizedCertificates.UpdateAuthorizedCertificate.@OutputOnly Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  Output only. Relative name of the certificate. This is a unique value autogenerated on AuthorizedCertificate resource creation. Example: 12345.@OutputOnly Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="managed_certificate" type="object">
  A certificate managed by App Engine. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="last_renewal_time" type="string">
      Time at which the certificate was last renewed. The renewal process is fully managed. Certificate renewal will automatically occur before the certificate expires. Renewal errors can be tracked via ManagementStatus.@OutputOnly Optional.
    </ResponseField>
    <ResponseField name="status" type="string">
      Status of certificate management. Refers to the most recent certificate acquisition or renewal attempt.@OutputOnly Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Full path to the AuthorizedCertificate resource in the API. Example: apps/myapp/authorizedCertificates/12345.@OutputOnly Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="visible_domain_mappings" type="list(string)">
  Output only. The full paths to user visible Domain Mapping resources that have this certificate mapped. Example: apps/myapp/domainMappings/example.com.This may not represent the full list of mapped domain mappings if the user does not have VIEWER permissions on all of the applications that have this certificate mapped. See domain_mappings_count for a complete count.Only returned by GET or LIST requests when specifically requested by the view=FULL_CERTIFICATE option.@OutputOnly Optional; if omitted, computed by Google Cloud.

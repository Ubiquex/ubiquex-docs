`google_workloadmanager_deployment` registers a running SAP or other enterprise workload with Workload Manager for automated best-practice evaluation and validation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_workloadmanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_workloadmanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workloadmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_workloadmanager/workloadmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own deployment"})

    		ubx.Resource(workloadmanager.WorkloadmanagerDeployment, "example", workloadmanager.WorkloadmanagerDeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

      intent({ summary: "example own deployment" });
    ```

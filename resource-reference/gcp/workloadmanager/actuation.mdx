`google_workloadmanager_actuation` is a single Workload Manager operation actively evaluating or reconfiguring a workload's own deployment against best practices.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workloadmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/workloadmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own actuation"})

    		ubx.Resource(workloadmanager.Actuation, "example", workloadmanager.ActuationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="actuation_output" type="object">
  Message for output of actuation. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="actuate_logs" type="string">
      A link to the Cloud Storage file that stores build logs. Optional.
    </ResponseField>
    <ResponseField name="ansible_error" type="string">
      Output only. Error message returned from Ansible. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="ansible_failed_task" type="list(string)">
      Output only. Failed task name returned from Ansible. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="blueprint_id" type="string">
      Reference to the Blueprint Controller deployment and revision resource. Optional.
    </ResponseField>
    <ResponseField name="cloudbuild_id" type="string">
      Cloud Build instance UUID associated with this revision, without any suffix or prefix Optional.
    </ResponseField>
    <ResponseField name="error_code" type="string">
      Output only. Code describing any errors that may have occurred. If not specified, there is no error in actuation. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="error_logs" type="string">
      A link to the actuation Cloud Build log. Optional.
    </ResponseField>
    <ResponseField name="has_user_facing_error_msg" type="bool">
      Output only. Whether the error message is user facing. If true, the error message will be shown in the UI. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="terraform_error" type="string">
      Output only. Error message returned from Terraform. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="terraform_template" type="string">
      Reference to the Terraform template used. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

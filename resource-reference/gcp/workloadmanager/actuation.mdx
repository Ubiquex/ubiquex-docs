`google_workloadmanager_actuation` is a single Workload Manager operation actively evaluating or reconfiguring a workload's own deployment against best practices.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_workloadmanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_workloadmanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workloadmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_workloadmanager/workloadmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own actuation"})

    		ubx.Resource(workloadmanager.WorkloadmanagerActuation, "ci-runner", workloadmanager.WorkloadmanagerActuationConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

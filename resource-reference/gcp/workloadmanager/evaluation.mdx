`google_workloadmanager_evaluation` runs a Workload Manager assessment of a registered deployment against a defined rule set (e.g. SAP on Google Cloud best practices), producing a compliance report.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workloadmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/workloadmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own evaluation"})

    		ubx.Resource(workloadmanager.Evaluation, "example", workloadmanager.EvaluationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

      Optional. Destination dataset to save evaluation results. Optional.
    </ResponseField>
  </Expandable>

<ResponseField name="create_time" type="string">
  Output only. [Output only] Create time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="custom_rules_bucket" type="string">
  The Cloud Storage bucket name for custom rules. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the Evaluation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="evaluation_type" type="string">
  Evaluation type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kms_key" type="string">
  Optional. Immutable. Customer-managed encryption key name, in the format projects/*/locations/*/keyRings/*/cryptoKeys/*. The key will be used for CMEK encryption of the evaluation resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels as key value pairs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Name of resource that has the form `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/evaluations/&#123;evaluation_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_filter" type="object">
  Resource filter for an evaluation defining the scope of resources to be evaluated. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="gce_instance_filter" type="object">
      A filter for matching Compute Engine instances. Optional.
      <Expandable title="properties">
        <ResponseField name="service_accounts" type="list(string)">
          If non-empty, only Compute Engine instances associated with at least one of the provided service accounts will be included in the evaluation. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="inclusion_labels" type="map(string)">
      Labels to filter resources by. Each key-value pair in the map must exist on the resource for it to be included (e.g. VM instance labels). For example, specifying `&#123; "env": "prod", "database": "nosql" &#125;` will only include resources that have labels `env=prod` and `database=nosql`. Optional.
    </ResponseField>
    <ResponseField name="resource_id_patterns" type="list(string)">
      The pattern to filter resources by their id For example, a pattern of ".*prod-cluster.*" will match all resources that contain "prod-cluster" in their ID. Optional.
    </ResponseField>
    <ResponseField name="scopes" type="list(string)">
      The scopes of evaluation resource. Format: * `projects/&#123;project_id&#125;` * `folders/&#123;folder_id&#125;` * `organizations/&#123;organization_id&#125;` Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resource_status" type="object">
  The lifecycle status of an Evaluation resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="state" type="string">
      State of the Evaluation resource. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rule_names" type="list(string)">
  The names of the rules used for this evaluation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schedule" type="string">
  Crontab format schedule for scheduled evaluation, currently only supports the following fixed schedules: * `0 */1 * * *` # Hourly * `0 */6 * * *` # Every 6 hours * `0 */12 * * *` # Every 12 hours * `0 0 */1 * *` # Daily * `0 0 */7 * *` # Weekly * `0 0 */14 * *` # Every 14 days * `0 0 1 */1 *` # Monthly Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. [Output only] Update time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

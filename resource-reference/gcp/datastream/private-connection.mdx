`google_datastream_private_connection` establishes private connectivity (via VPC peering) between Datastream and a source database that isn't reachable over the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datastream "github.com/ubiquex/ubx-sdk-google/sdk/go/google/datastream"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own private connection"})

    		ubx.Resource(datastream.PrivateConnection, "example", datastream.PrivateConnectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

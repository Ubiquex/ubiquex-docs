<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_datastream_stream`.
</Warning>

`google_datastream_v1alpha1_stream` is a Datastream change-data-capture pipeline that continuously replicates data from a source connection profile to a destination.

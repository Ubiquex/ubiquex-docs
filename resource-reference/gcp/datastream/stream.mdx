`google_datastream_stream` is a Datastream change-data-capture pipeline that continuously replicates data from a source connection profile to a destination.

## Example

<Tabs>
  <Tab title="Go">

    package main

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own stream"})

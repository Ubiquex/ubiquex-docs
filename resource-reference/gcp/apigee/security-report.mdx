## Input properties

<ResponseField name="csv_delimiter" type="string">
  Delimiter used in the CSV file, if `outputFormat` is set to `csv`. Defaults to the `,` (comma) character. Supported delimiter characters include comma (`,`), pipe (`|`), and tab (`\t`). Optional.
</ResponseField>

<ResponseField name="dimensions" type="list(string)">
  A list of dimensions. https://docs.apigee.com/api-platform/analytics/analytics-reference#dimensions Optional.
</ResponseField>

<ResponseField name="display_name" type="string">
  Security Report display name which users can specify. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="envgroup_hostname" type="string">
  Hostname needs to be specified if query intends to run at host level. This field is only allowed when query is submitted by CreateHostSecurityReport where analytics data will be grouped by organization and hostname. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter" type="string">
  Boolean expression that can be used to filter data. Filter expressions can be combined using AND/OR terms and should be fully parenthesized to avoid ambiguity. See Analytics metrics, dimensions, and filters reference https://docs.apigee.com/api-platform/analytics/analytics-reference for more information on the fields available to filter on. For more information on the tokens that you use to build filter expressions, see Filter expression syntax. https://docs.apigee.com/api-platform/analytics/asynch-reports-api#filter-expression-syntax Optional.
</ResponseField>

<ResponseField name="group_by_time_unit" type="string">
  Time unit used to group the result set. Valid values include: second, minute, hour, day, week, or month. If a query includes groupByTimeUnit, then the result is an aggregation based on the specified time unit and the resultant timestamp does not include milliseconds precision. If a query omits groupByTimeUnit, then the resultant timestamp includes milliseconds precision. Optional.
</ResponseField>

<ResponseField name="limit" type="number">
  Maximum number of rows that can be returned in the result. Optional.
</ResponseField>

<ResponseField name="metrics" type="list(object)">
  A list of Metrics. Optional.
  <Expandable title="properties">
    <ResponseField name="aggregation_function" type="string">
      How values are combined across a time window, e.g. sum or average. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="alias" type="string">
      A reference to a key/certificate alias in a keystore. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The resource name or identifier of this object. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="operator" type="string">
      How this condition's own operands are compared. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The literal value of this field. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="mime_type" type="string">
  Valid values include: `csv` or `json`. Defaults to `json`. Note: Configure the delimiter for CSV output using the csvDelimiter property. Optional.
</ResponseField>

<ResponseField name="report_definition_id" type="string">
  Report Definition ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="time_range" type="any">
  Required. Time range for the query. Can use the following predefined strings to specify the time range: `last60minutes` `last24hours` `last7days` Or, specify the timeRange as a structure describing start and end timestamps in the ISO format: yyyy-mm-ddThh:mm:ssZ. Example: "timeRange": &#123; "start": "2018-07-29T00:13:00Z", "end": "2018-08-01T00:18:00Z" &#125; Optional.
</ResponseField>

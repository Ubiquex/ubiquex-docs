`google_apigee_security_feedback` records a human reviewer's own correction to an Advanced API Security finding (e.g. marking a flagged IP address as a false positive), used to refine future detection.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own security feedback"})

    		ubx.Resource(apigee.SecurityFeedback, "example", apigee.SecurityFeedbackConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

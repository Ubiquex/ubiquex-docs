`google_apigee_archive_deployment` deploys a bundled archive of static configuration or resource file(s) to an Apigee environment, for use by proxy logic at runtime.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own archive deployment"})

    		ubx.Resource(apigee.ApigeeArchiveDeployment, "ci-runner", apigee.ApigeeArchiveDeploymentConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="created_at" type="string">
  Output only. The time at which the Archive Deployment was created in milliseconds since the epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="gcs_uri" type="string">
  Input only. The Google Cloud Storage signed URL returned from GenerateUploadUrl and used to upload the Archive zip file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  User-supplied key-value pairs used to organize ArchiveDeployments. Label keys must be between 1 and 63 characters long, have a UTF-8 encoding of maximum 128 bytes, and must conform to the following PCRE regular expression: \p&#123;Ll&#125;\p&#123;Lo&#125;&#123;0,62&#125; Label values must be between 1 and 63 characters long, have a UTF-8 encoding of maximum 128 bytes, and must conform to the following PCRE regular expression: [\p&#123;Ll&#125;\p&#123;Lo&#125;\p&#123;N&#125;_-]&#123;0,63&#125; No more than 64 labels can be associated with a given store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the Archive Deployment in the following format: `organizations/&#123;org&#125;/environments/&#123;env&#125;/archiveDeployments/&#123;id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="operation" type="string">
  Output only. A reference to the LRO that created this Archive Deployment in the following format: `organizations/&#123;org&#125;/operations/&#123;id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Output only. The time at which the Archive Deployment was updated in milliseconds since the epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_apigee_environment` is a named runtime execution context (e.g. `test` or `prod`) within an Apigee organization that API proxies are deployed into, each with its own configuration and traffic isolation.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own environment"})

    		ubx.Resource(apigee.Environment, "example", apigee.EnvironmentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="deployment_type" type="string">

When you enable archive deployment, you will be **prevented from performing** a [subset of actions](/apigee/docs/api-platform/local-development/overview#prevented-actions) within the environment, including: * Managing the deployment of API proxy or shared flow revisions * Creating, updating, or deleting resource files * Creating, updating, or deleting target servers Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="forward_proxy_uri" type="string">
  Optional. URI of the forward proxy to be applied to the runtime instances in this environment. Must be in the format of &#123;scheme&#125;://&#123;hostname&#125;:&#123;port&#125;. Note that the only supported scheme is "http". The port must be supplied. To remove a forward proxy setting, update the field to an empty value. Note: At this time, PUT operations to add forwardProxyUri to an existing environment fail if the environment has nodeConfig set up. To successfully add the forwardProxyUri setting in this case, include the NodeConfig details with the request. Optional; if omitted, computed by Google Cloud.
</ResponseField>

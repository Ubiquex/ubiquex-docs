`google_apigee_keystore` holds the TLS certificate and private key entries an Apigee proxy or target endpoint presents for inbound or outbound TLS connections.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own keystore"})

    		ubx.Resource(apigee.Keystore, "example", apigee.KeystoreConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

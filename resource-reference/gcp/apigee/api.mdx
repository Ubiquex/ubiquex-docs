`google_apigee_api` registers a standalone OpenAPI specification document with Apigee's own API hub/catalog, independent of any specific deployed proxy revision.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own api"})

    		ubx.Resource(apigee.ApigeeApi, "ci-runner", apigee.ApigeeApiConfig{
    			ContentType: "example",
    			Data:        "example",
    			Extensions:  []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript

      intent({ summary: "payments own api" });

        extensions: ["example"],
      });
    ```

  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_apigee --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_apigee/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_apigee.apigee import ApigeeApi, ApigeeApiConfig

    def describe():
        ubx.intent("payments own api")

        ubx.resource(ApigeeApi, "ci-runner", ApigeeApiConfig(
            content_type="example",
            data="example",
            extensions=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Input properties

<ResponseField name="content_type" type="string">
  The HTTP Content-Type header value specifying the content type of the body. Optional.
</ResponseField>

<ResponseField name="data" type="string">
  The HTTP request/response body as raw binary. Optional.
</ResponseField>

<ResponseField name="extensions" type="list(map(any))">
  Application specific response metadata. Must be set in the first response for streaming APIs. Optional.
</ResponseField>

## Output properties

<ResponseField name="api_proxy_type" type="string">
  Output only. The type of the API proxy. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  User labels applied to this API Proxy. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="latest_revision_id" type="string">
  Output only. The id of the most recently created revision for this api proxy. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="meta_data" type="object">
  Metadata common to many entities in this API. Computed by Google Cloud after `ship`.
  <Expandable title="properties">
    <ResponseField name="created_at" type="string">
      Time at which the API proxy was created, in milliseconds since epoch. Optional.
    </ResponseField>
    <ResponseField name="last_modified_at" type="string">
      Time at which the API proxy was most recently modified, in milliseconds since epoch. Optional.
    </ResponseField>
    <ResponseField name="sub_type" type="string">
      The type of entity described Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the API proxy. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="read_only" type="bool">
  Output only. Whether this proxy is read-only. A read-only proxy cannot have new revisions created through calls to CreateApiProxyRevision. A proxy is read-only if it was generated by an archive. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="revision" type="list(string)">
  Output only. List of revisions defined for the API proxy. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="space" type="string">
  Optional. The id of the space this proxy is associated with. Any IAM policies applied to the space will control access to this proxy. To learn how Spaces can be used to manage resources, read the [Apigee Spaces Overview](https://cloud.google.com/apigee/docs/api-platform/system-administration/spaces/apigee-spaces-overview). Computed by Google Cloud after `ship`.
</ResponseField>

`google_apigee_endpoint_attachment` establishes a Private Service Connect endpoint an Apigee proxy's own target endpoint can privately reach a backend service through, without traversing the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own endpoint attachment"})

    		ubx.Resource(apigee.ApigeeEndpointAttachment, "ci-runner", apigee.ApigeeEndpointAttachmentConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="connection_state" type="string">
  Output only. State of the endpoint attachment connection to the service attachment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="host" type="string">
  Output only. Host that can be used in either the HTTP target endpoint directly or as the host in target server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="location" type="string">
  Required. Location of the endpoint attachment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the endpoint attachment. Use the following structure in your request: `organizations/&#123;org&#125;/endpointAttachments/&#123;endpoint_attachment&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_attachment" type="string">
  Format: projects/*/regions/*/serviceAttachments/* Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the endpoint attachment. Values other than `ACTIVE` mean the resource is not ready to use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

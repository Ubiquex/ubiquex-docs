`google_apigee_rateplan` defines the monetization pricing (per-transaction fees, revenue share, recurring charges) applied to a developer app's own usage of a monetized Apigee API product.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own rateplan"})

    		ubx.Resource(apigee.Rateplan, "example", apigee.RateplanConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="apiproduct" type="string">
  Name of the API product that the rate plan is associated with. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="billing_period" type="string">
  Frequency at which the customer will be billed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="consumption_pricing_rates" type="list(object)">
  API call volume ranges and the fees charged when the total number of API calls is within a given range. The method used to calculate the final fee depends on the selected pricing model. For example, if the pricing model is `BANDED` and the ranges are defined as follows: ``` &#123; "start": 1, "end": 100, "fee": 2 &#125;, &#123; "start": 101, "end": 200, "fee": 1.50 &#125;, &#123; "start": 201, "end": 0, "fee": 1 &#125;, &#125; ``` Then the following fees would be charged based on the total number of API calls (assuming the currency selected is `USD`): * 50 calls cost 50 x $2 = $100 * 150 calls cost 100 x $2 + 50 x $1.5 = $275 * 250 calls cost 100 x $2 + 100 x $1.5 + 50 x $1 = $400 * 500 calls cost 100 x $2 + 100 x $1.5 + 300 x $1 = $650 Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="end" type="string">
      Where this range ends. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="fee" type="object">
      A monetary charge applied. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="currency_code" type="string">
          The ISO 4217 currency code monetary values are expressed in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="nanos" type="number">
          The sub-second, nanosecond component of a time value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="units" type="string">
          The unit this measurement is expressed in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="start" type="string">
      Where this range starts. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="consumption_pricing_type" type="string">
  Pricing model used for consumption-based charges. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="created_at" type="string">
  Output only. Time that the rate plan was created in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="currency_code" type="string">
  Currency to be used for billing. Consists of a three-letter code as defined by the [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) standard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the rate plan. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Display name of the rate plan. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Time when the rate plan will expire in milliseconds since epoch. Set to 0 or `null` to indicate that the rate plan should never expire. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fixed_fee_frequency" type="number">
  Frequency at which the fixed fee is charged. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fixed_recurring_fee" type="object">
  Represents an amount of money with its currency type. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="currency_code" type="string">
      The three-letter currency code defined in ISO 4217. Optional.
    </ResponseField>
    <ResponseField name="nanos" type="number">
      Number of nano (10^-9) units of the amount. The value must be between -999,999,999 and +999,999,999 inclusive. If `units` is positive, `nanos` must be positive or zero. If `units` is zero, `nanos` can be positive, zero, or negative. If `units` is negative, `nanos` must be negative or zero. For example $-1.75 is represented as `units`=-1 and `nanos`=-750,000,000. Optional.
    </ResponseField>
    <ResponseField name="units" type="string">
      The whole units of the amount. For example if `currencyCode` is `"USD"`, then 1 unit is one US dollar. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. Time the rate plan was last modified in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the rate plan. Optional; if omitted, computed by Google Cloud.
</ResponseField>

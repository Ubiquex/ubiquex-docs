`google_apigee_security_action` defines an automated response (allow, deny, or flag) Apigee Advanced API Security applies to traffic matching a specific condition, e.g. blocking requests from an IP address flagged as abusive.

## Properties

<ResponseField name="allow" type="any">
  Message that should be set in case of an Allow Action. This does not have any fields. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="api_proxies" type="list(string)">
  Optional. If unset, this would apply to all proxies in the environment. If set, this action is enforced only if at least one proxy in the repeated list is deployed at the time of enforcement. If set, several restrictions are enforced on SecurityActions. There can be at most 100 enabled actions with proxies set in an env. Several other restrictions apply on conditions and are detailed later. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="condition_config" type="object">
  The following are a list of conditions. A valid SecurityAction must contain at least one condition. Within a condition, each element is ORed. Across conditions elements are ANDed. For example if a SecurityAction has the following: ip_address_ranges: ["ip1", "ip2"] and bot_reasons: ["Flooder", "Robot Abuser"] then this is interpreted as: enforce the action if the incoming request has ((ip_address_ranges = "ip1" OR ip_address_ranges = "ip2") AND (bot_reasons="Flooder" OR bot_reasons="Robot Abuser")). Conditions other than ip_address_ranges and bot_reasons cannot be ANDed. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="access_tokens" type="list(string)">
      Optional. A list of access_tokens. Limit 1000 per action. Optional.
    </ResponseField>
    <ResponseField name="api_keys" type="list(string)">
      Optional. A list of API keys. Limit 1000 per action. Optional.
    </ResponseField>
    <ResponseField name="api_products" type="list(string)">
      Optional. A list of API Products. Limit 1000 per action. Optional.
    </ResponseField>
    <ResponseField name="asns" type="list(string)">
      Optional. A list of ASN numbers to act on, e.g. 23. https://en.wikipedia.org/wiki/Autonomous_system_(Internet) This uses int64 instead of uint32 because of https://linter.aip.dev/141/forbidden-types. Optional.
    </ResponseField>
    <ResponseField name="bot_reasons" type="list(string)">
      Optional. A list of Bot Reasons. Current options: Flooder, Brute Guessor, Static Content Scraper, OAuth Abuser, Robot Abuser, TorListRule, Advanced Anomaly Detection, Advanced API Scraper, Search Engine Crawlers, Public Clouds, Public Cloud AWS, Public Cloud Azure, and Public Cloud Google. Optional.
    </ResponseField>
    <ResponseField name="developer_apps" type="list(string)">
      Optional. A list of developer apps. Limit 1000 per action. Optional.
    </ResponseField>
    <ResponseField name="developers" type="list(string)">
      Optional. A list of developers. Limit 1000 per action. Optional.
    </ResponseField>
    <ResponseField name="http_methods" type="list(string)">
      Optional. Act only on particular HTTP methods. E.g. A read-only API can block POST/PUT/DELETE methods. Accepted values are: GET, HEAD, POST, PUT, DELETE, CONNECT, OPTIONS, TRACE and PATCH. Optional.
    </ResponseField>
    <ResponseField name="ip_address_ranges" type="list(string)">
      Optional. A list of IP addresses. This could be either IPv4 or IPv6. Limited to 100 per action. Optional.
    </ResponseField>
    <ResponseField name="region_codes" type="list(string)">
      Optional. A list of countries/region codes to act on, e.g. US. This follows https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2. Optional.
    </ResponseField>
    <ResponseField name="user_agents" type="list(string)">
      Optional. A list of user agents to deny. We look for exact matches. Limit 50 per action. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

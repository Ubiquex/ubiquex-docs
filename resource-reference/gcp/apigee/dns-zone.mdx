## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dns zone"})

    		ubx.Resource(apigee.DnsZone, "example", apigee.DnsZoneConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time that this resource was created on the server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Required. Description of the resource. String of at most 1024 characters associated with this resource for the user's convenience. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="domain" type="string">
  Required. The domain name for hosts in this private zone, for instance "example.com.". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Unique name for the resource. Defined by the server Format: "organizations/&#123;organization&#125;/dnsZones/&#123;dns_zone&#125;". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peering_config" type="object">
  Fields for DNS PEERING zone. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="target_network_id" type="string">
      Required. The VPC network where the records for that private DNS zone's namespace are available. Apigee will be performing DNS peering with this VPC network. Optional.
    </ResponseField>
    <ResponseField name="target_project_id" type="string">
      Required. The ID of the project that contains the producer VPC network. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the DNS Peering. Values other than `ACTIVE` mean the resource is not ready to use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">

</ResponseField>

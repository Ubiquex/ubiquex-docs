`google_apigee_reference` is a named pointer inside an Apigee environment to another resource (e.g. a keystore), letting proxy configuration reference it indirectly so the underlying target can change without editing every proxy that uses it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own reference"})

    		ubx.Resource(apigee.ApigeeReference, "ci-runner", apigee.ApigeeReferenceConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_apigee --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_apigee --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_apigee/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_apigee.apigee import ApigeeReference, ApigeeReferenceConfig

    def describe():
        ubx.intent("payments own reference")

        ubx.resource(ApigeeReference, "ci-runner", ApigeeReferenceConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="description" type="string">
  Optional. A human-readable description of this reference. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. The resource id of this reference. Values must match the regular expression [\w\s\-.]+. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="refers" type="string">
  Required. The id of the resource to which this reference refers. Must be the id of a resource that exists in the parent environment and is of the given resource_type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_type" type="string">
  The type of resource referred to by this reference. Valid values are 'KeyStore' or 'TrustStore'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_apigee_sharedflow` packages a reusable sequence of Apigee policy steps that multiple different API proxies can invoke, avoiding duplicating the same policy logic across proxies.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sharedflow"})

    		ubx.Resource(apigee.Sharedflow, "example", apigee.SharedflowConfig{
    			ContentType: "example",
    			Data:        "example",
    			Extensions:  []string{"example"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.apigee.sharedflow import Sharedflow, SharedflowConfig

    def describe():
        ubx.intent("example own sharedflow")

        ubx.resource(Sharedflow, "example", SharedflowConfig(
            content_type="example",
            data="example",
            extensions=["example"],
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="content_type" type="string">
  The HTTP Content-Type header value specifying the content type of the body. Optional.
</ResponseField>

<ResponseField name="data" type="string">
  The HTTP request/response body as raw binary. Optional.
</ResponseField>

<ResponseField name="extensions" type="list(map(any))">
  Application specific response metadata. Must be set in the first response for streaming APIs. Optional.
</ResponseField>

## Output properties

<ResponseField name="latest_revision_id" type="string">
  The id of the most recently created revision for this shared flow. Computed by Google Cloud after `ship`.
</ResponseField>

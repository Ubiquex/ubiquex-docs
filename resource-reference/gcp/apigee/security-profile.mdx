`google_apigee_security_profile` is a named collection of Advanced API Security assessment checks that deployed proxies in an Apigee environment are evaluated against, producing a security score.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own security profile"})

    		ubx.Resource(apigee.SecurityProfile, "example", apigee.SecurityProfileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own apidoc"})

    		ubx.Resource(apigee.ApigeeApidoc, "ci-runner", apigee.ApigeeApidocConfig{
    			AnonAllowed:              true,
    			ApiProductName:           "example-api-product-name",
    			CategoryIds:              []string{"example"},
    			Description:              "Managed by ubx.",
    			EdgeApiproductName:       "example-edge-apiproduct-name",
    			GraphqlEndpointUrl:       "example",
    			GraphqlSchema:            "example",
    			GraphqlSchemaDisplayName: "example-graphql-schema-display-name",
    		})
    	}))
    }
    ```

            api_product_name="example-api-product-name",

        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)

## Input properties

<ResponseField name="anon_allowed" type="bool">
  Optional. Boolean flag that manages user access to the catalog item. When true, the catalog item has public visibility and can be viewed anonymously; otherwise, only registered users may view it. Note: when the parent portal is enrolled in the [audience management feature](https://cloud.google.com/apigee/docs/api-platform/publish/portal/portal-audience#enrolling_in_the_beta_release_of_the_audience_management_feature), and this flag is set to false, visibility is set to an indeterminate state and must be explicitly specified in the management UI (see [Manage the visibility of an API in your portal](https://cloud.google.com/apigee/docs/api-platform/publish/portal/publish-apis#visibility)). Additionally, when enrolled in the audience management feature, updates to this flag will be ignored as visibility permissions must be updated in the management UI. Optional.
</ResponseField>

<ResponseField name="api_product_name" type="string">
  Required. Immutable. The `name` field of the associated [API product](/apigee/docs/reference/apis/apigee/rest/v1/organizations.apiproducts). A portal may have only one catalog item associated with a given API product. Optional.
</ResponseField>

<ResponseField name="category_ids" type="list(string)">
  Optional. The IDs of the API categories to which this catalog item belongs. Optional.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the catalog item. Max length is 10,000 characters. Optional.
</ResponseField>

<ResponseField name="edge_apiproduct_name" type="string">
  Optional. Immutable. DEPRECATED: use the `apiProductName` field instead Optional.
</ResponseField>

<ResponseField name="graphql_endpoint_url" type="string">
  Optional. DEPRECATED: manage documentation through the `getDocumentation` and `updateDocumentation` methods Optional.
</ResponseField>

<ResponseField name="graphql_schema" type="string">
  Optional. DEPRECATED: manage documentation through the `getDocumentation` and `updateDocumentation` methods Optional.
</ResponseField>

<ResponseField name="graphql_schema_display_name" type="string">
  Optional. DEPRECATED: manage documentation through the `getDocumentation` and `updateDocumentation` methods Optional.
</ResponseField>

<ResponseField name="image_url" type="string">
  Optional. Location of the image used for the catalog item in the catalog. This can be either an image with an external URL or a file path for [image files stored in the portal](/apigee/docs/api-platform/publish/portal/portal-files"), for example, `/files/book-tree.jpg`. When specifying the URL of an external image, the image won't be uploaded to your assets; additionally, loading the image in the integrated portal will be subject to its availability, which may be blocked or restricted by [content security policies](/apigee/docs/api-platform/publish/portal/csp). Max length of file path is 2,083 characters. Optional.
</ResponseField>

<ResponseField name="published" type="bool">
  Optional. Denotes whether the catalog item is published to the portal or is in a draft state. When the parent portal is enrolled in the [audience management feature](https://cloud.google.com/apigee/docs/api-platform/publish/portal/portal-audience#enrolling_in_the_beta_release_of_the_audience_management_feature), the visibility can be set to public on creation by setting the anonAllowed flag to true or further managed in the management UI (see [Manage the visibility of an API in your portal](https://cloud.google.com/apigee/docs/api-platform/publish/portal/publish-apis#visibility)) before it can be visible to any users. If not enrolled in the audience management feature, the visibility is managed by the `anonAllowed` flag. Optional.
</ResponseField>

<ResponseField name="require_callback_url" type="bool">
  Optional. Whether a callback URL is required when this catalog item's API product is enabled in a developer app. When true, a portal user will be required to input a URL when managing the app (this is typically used for the app's OAuth flow). Optional.
</ResponseField>

<ResponseField name="spec_id" type="string">
  Optional. DEPRECATED: DO NOT USE Optional.
</ResponseField>

<ResponseField name="title" type="string">
  Required. The user-facing name of the catalog item. `title` must be a non-empty string with a max length of 255 characters. Optional.
</ResponseField>

<ResponseField name="visibility" type="bool">
  Optional. DEPRECATED: use the `published` field instead Optional.
</ResponseField>

Through this link, portal users can create and manage developer apps linked to one or more API products. Computed by Google Cloud after `ship`.

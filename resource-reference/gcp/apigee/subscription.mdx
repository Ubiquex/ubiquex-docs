## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own subscription"})

    		ubx.Resource(apigee.ApigeeSubscription, "example", apigee.ApigeeSubscriptionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="apiproduct" type="string">
  Required. Name of the API product for which the appgroup is purchasing a subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="created_at" type="string">
  Output only. Time when the API product subscription was created in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Output only. Time when the API product subscription ends in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. Time when the API product subscription was last modified in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the API product subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  Output only. Time when the API product subscription starts in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

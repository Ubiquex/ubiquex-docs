`google_apigee_security_profiles_v2` is the current-generation Advanced API Security profile resource, the v2 API surface for the same security-profile assessment concept as `google_apigee_security_profile`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own security profiles v2"})

    		ubx.Resource(apigee.ApigeeSecurityProfilesV2, "example", apigee.ApigeeSecurityProfilesV2Config{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time of the security profile creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the security profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="google_defined" type="bool">
  Output only. Whether the security profile is google defined. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the security profile v2 resource. Format: organizations/&#123;org&#125;/securityProfilesV2/&#123;profile&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

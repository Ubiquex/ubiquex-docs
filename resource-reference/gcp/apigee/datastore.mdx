`google_apigee_datastore` registers an external storage target (e.g. a Cloud Storage bucket or BigQuery dataset) Apigee analytics data or archived audit log export is written to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own datastore"})

    		ubx.Resource(apigee.Datastore, "example", apigee.DatastoreConfig{
    			CreateTime: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Datastore create time, in milliseconds since the epoch of 1970-01-01T00:00:00Z Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="datastore_config" type="object">
  Configuration detail for datastore Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="bucket_name" type="string">
      Name of the Cloud Storage bucket. Required for `gcs` target_type. Optional.
    </ResponseField>
    <ResponseField name="dataset_name" type="string">
      BigQuery dataset name Required for `bigquery` target_type. Optional.
    </ResponseField>
    <ResponseField name="path" type="string">
      Path of Cloud Storage bucket Required for `gcs` target_type. Optional.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      Required. Google Cloud project in which the datastore exists Optional.
    </ResponseField>
    <ResponseField name="table_prefix" type="string">
      Prefix of BigQuery table Required for `bigquery` target_type. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Display name in UI Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_update_time" type="string">
  Output only. Datastore last update time, in milliseconds since the epoch of 1970-01-01T00:00:00Z Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="org" type="string">
  Output only. Organization that the datastore belongs to Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self" type="string">
  Output only. Resource link of Datastore. Example: `/organizations/&#123;org&#125;/analytics/datastores/&#123;uuid&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_type" type="string">
  Destination storage type. Supported types `gcs` or `bigquery`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

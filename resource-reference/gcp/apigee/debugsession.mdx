`google_apigee_debugsession` captures a short-lived, detailed trace of requests flowing through a deployed Apigee proxy revision, used to step through policy execution while diagnosing an issue.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own debugsession"})

    		ubx.Resource(apigee.ApigeeDebugsession, "ci-runner", apigee.ApigeeDebugsessionConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="count" type="number">
  Optional. The number of request to be traced. Min = 1, Max = 15, Default = 10. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The first transaction creation timestamp, recorded by UAP. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter" type="string">
  Optional. A conditional statement which is evaluated against the request message to determine if it should be traced. Syntax matches that of on API Proxy bundle flow Condition. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  A unique ID for this DebugSession. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="timeout" type="string">
  Optional. The time in seconds after which this DebugSession should end. This value will override the value in query param, if both are provided. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tracesize" type="number">
  Optional. The maximum number of bytes captured from the response payload. Min = 0, Max = 5120, Default = 5120. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="validity" type="number">
  Optional. The length of time, in seconds, that this debug session is valid, starting from when it's received in the control plane. Min = 1, Max = 15, Default = 10. Optional; if omitted, computed by Google Cloud.
</ResponseField>

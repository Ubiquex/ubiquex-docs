`google_apigee_instance` is a physical Apigee runtime deployment -- a set of message processors and routers provisioned in a specific region -- that environment(s) are attached to in order to actually serve API traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    }
    ```

## Properties

<ResponseField name="access_logging_config" type="object">
  Access logging configuration enables customers to ship the access logs from the tenant projects to their own project's cloud logging. The feature is at the instance level ad disabled by default. It can be enabled during CreateInstance or UpdateInstance. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Optional. Boolean flag that specifies whether the customer access log feature is enabled. Optional.
    </ResponseField>
    <ResponseField name="filter" type="string">
      Optional. Ship the access log entries that match the status_code defined in the filter. The status_code is the only expected/supported filter field. (Ex: status_code) The filter will parse it to the Common Expression Language semantics for expression evaluation to build the filter condition. (Ex: "filter": status_code &gt;= 200 && status_code &lt; 300 ) Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="consumer_accept_list" type="list(string)">
  Optional. Customer accept list represents the list of projects (id/number) on customer side that can privately connect to the service attachment. It is an optional field which the customers can provide during the instance creation. By default, the customer project associated with the Apigee organization will be included to the list. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="created_at" type="string">
  Output only. Time the instance was created in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disk_encryption_key_name" type="string">
  Optional. Customer Managed Encryption Key (CMEK) used for disk and volume encryption. If not specified, a Google-Managed encryption key will be used. Use the following format: `projects/([^/]+)/locations/([^/]+)/keyRings/([^/]+)/cryptoKeys/([^/]+)` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. Display name for the instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="host" type="string">
  Output only. Internal hostname or IP address of the Apigee endpoint used by clients to connect to the service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ip_range" type="string">
  Optional. Comma-separated list of CIDR blocks of length 22 and/or 28 used to create the Apigee instance. Providing CIDR ranges is optional. You can provide just /22 or /28 or both (or neither). Ranges you provide should be freely available as part of a larger named range you have allocated to the Service Networking peering. If this parameter is not provided, Apigee automatically requests an available /22 and /28 CIDR block from Service Networking. Use the /22 CIDR block for configuring your firewall needs to allow traffic from Apigee. Input formats: `a.b.c.d/22` or `e.f.g.h/28` or `a.b.c.d/22,e.f.g.h/28` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_version_locked" type="bool">
  Output only. Indicates whether the instance is version locked. If true, the instance will not be updated by automated runtime rollouts. This is only supported for Apigee X instances. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. Time the instance was last modified in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="location" type="string">
  Required. Compute Engine location where the instance resides. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="maintenance_update_policy" type="object">
  MaintenanceUpdatePolicy specifies the preferred window to perform maintenance on the instance (day of the week and time of day). Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="maintenance_channel" type="string">
      Optional. Maintenance channel to specify relative scheduling for maintenance. Optional.
    </ResponseField>
    <ResponseField name="maintenance_windows" type="list(object)">
      Optional. Preferred windows to perform maintenance. Currently limited to 1. Optional.
      <Expandable title="properties">
        <ResponseField name="day" type="string">
          The day-of-month component of a date. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="start_time" type="object">
          When this event or window started. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="hours" type="number">
              The hour component of a time value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="minutes" type="number">
              The minute component of a time value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="nanos" type="number">
              The sub-second, nanosecond component of a time value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="seconds" type="number">
              The second component of a time value. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Required. Resource ID of the instance. Values must match the regular expression `^a-z&#123;0,30&#125;[a-z\d]$`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peering_cidr_range" type="string">
  Optional. Size of the CIDR block range that will be reserved by the instance. PAID organizations support `SLASH_16` to `SLASH_20` and defaults to `SLASH_16`. Evaluation organizations support only `SLASH_23`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="port" type="string">
  Output only. Port number of the exposed Apigee endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="runtime_version" type="string">
  Output only. Version of the runtime system running in the instance. The runtime system is the set of components that serve the API Proxy traffic in your Environments. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scheduled_maintenance" type="object">
  Scheduled maintenance information for an instance. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="start_time" type="string">
      Output only. The start time (UTC) of the scheduled maintenance. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_attachment" type="string">
  Output only. Resource name of the service attachment created for the instance in the format: `projects/*/regions/*/serviceAttachments/*` Apigee customers can privately forward traffic to this service attachment using the PSC endpoints. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the instance. Values other than `ACTIVE` means the resource is not ready to use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

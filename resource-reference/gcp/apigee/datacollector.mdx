`google_apigee_datacollector` defines a named, typed variable that Apigee proxy logic can write custom analytics data into, later queryable alongside Apigee's own built-in analytics dimensions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own datacollector"})

    		ubx.Resource(apigee.ApigeeDatacollector, "ci-runner", apigee.ApigeeDatacollectorConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="created_at" type="string">
  Output only. The time at which the data collector was created in milliseconds since the epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the data collector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. The time at which the Data Collector was last updated in milliseconds since the epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  ID of the data collector. Must begin with `dc_`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Immutable. The type of data this data collector will collect. Optional; if omitted, computed by Google Cloud.
</ResponseField>

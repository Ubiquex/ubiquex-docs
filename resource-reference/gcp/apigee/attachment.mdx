`google_apigee_attachment` attaches an Apigee environment group to a specific Apigee instance, controlling which runtime instance(s) actually serve traffic for that environment group's own hostnames.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own attachment"})

    		ubx.Resource(apigee.Attachment, "example", apigee.AttachmentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Attachment } from "@ubx/sdk-google/google/apigee/attachment";

    export default stack("example", () => {
      intent({ summary: "example own attachment" });

      resource(Attachment, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.apigee.attachment import Attachment, AttachmentConfig

    def describe():
        ubx.intent("example own attachment")

        ubx.resource(Attachment, "example", AttachmentConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="created_at" type="string">
  Output only. The time at which the environment group attachment was created as milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="environment" type="string">
  Required. ID of the attached environment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="environment_group_id" type="string">
  Output only. ID of the environment group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  ID of the environment group attachment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

---
title: "google_apigee_developer"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own developer"})

    		ubx.Resource(apigee.Developer, "example", apigee.DeveloperConfig{
    			AccessType: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Developer } from "@ubx/sdk-google/google/apigee/developer";

    export default stack("example", () => {
      intent({ summary: "example own developer" });

      resource(Developer, "example", {
        accessType: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.apigee import Developer, DeveloperConfig

    def describe():
        ubx.intent("example own developer")

        ubx.resource(Developer, "example", DeveloperConfig(
            access_type="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Properties

<ResponseField name="access_type" type="string">
  Access type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="app_family" type="string">
  Developer app family. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="apps" type="list(string)">
  List of apps associated with the developer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="attributes" type="list(object)">
  Optional. Developer attributes (name/value pairs). The custom attribute limit is 18. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The resource name or identifier of this object. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="string">
      The literal value of this field. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="companies" type="list(string)">
  List of companies associated with the developer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="created_at" type="string">
  Output only. Time at which the developer was created in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="developer_id" type="string">
  ID of the developer. **Note**: IDs are generated internally by Apigee and are not guaranteed to stay the same over time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="email" type="string">
  Required. Email address of the developer. This value is used to uniquely identify the developer in Apigee hybrid. Note that the email address has to be in lowercase only. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="first_name" type="string">
  Required. First name of the developer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. Time at which the developer was last modified in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_name" type="string">
  Required. Last name of the developer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="organization_name" type="string">
  Output only. Name of the Apigee organization in which the developer resides. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status" type="string">
  Output only. Status of the developer. Valid values are `active` and `inactive`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_name" type="string">
  Required. User name of the developer. Not used by Apigee hybrid. Optional; if omitted, computed by Google Cloud.
</ResponseField>

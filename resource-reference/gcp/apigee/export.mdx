    			CsvDelimiter: "example",

    		})
    	}))
    }

## Input properties

<ResponseField name="csv_delimiter" type="string">
  Optional. Delimiter used in the CSV file, if `outputFormat` is set to `csv`. Defaults to the `,` (comma) character. Supported delimiter characters include comma (`,`), pipe (`|`), and tab (`\t`). Optional.
</ResponseField>

<ResponseField name="datastore_name" type="string">
  Required. Name of the preconfigured datastore. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="date_range" type="object">
  Date range of the data to export. Optional.
  <Expandable title="properties">
    <ResponseField name="end" type="string">
      Required. End date (exclusive) of the data to export in the format `yyyy-mm-dd`. The date range ends at 00:00:00 UTC on the end date- which will not be in the output. Optional.
    </ResponseField>
    <ResponseField name="start" type="string">
      Required. Start date of the data to export in the format `yyyy-mm-dd`. The date range begins at 00:00:00 UTC on the start date. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the export job. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Display name of the export job. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="output_format" type="string">
  Optional. Output format of the export. Valid values include: `csv` or `json`. Defaults to `json`. Note: Configure the delimiter for CSV output using the `csvDelimiter` property. Optional.
</ResponseField>

## Output properties

<ResponseField name="created" type="string">
  Output only. Time the export job was created. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="datastore_name" type="string">
  Required. Name of the preconfigured datastore. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the export job. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="error" type="string">
  Output only. Error is set when export fails Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="execution_time" type="string">
  Output only. Execution time for this export job. If the job is still in progress, it will be set to the amount of time that has elapsed since`created`, in seconds. Else, it will set to (`updated` - `created`), in seconds. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Display name of the export job. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self" type="string">
  Output only. Self link of the export job. A URI that can be used to retrieve the status of an export job. Example: `/organizations/myorg/environments/myenv/analytics/exports/9cfc0d85-0f30-46d6-ae6f-318d0cb961bd` Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Status of the export job. Valid values include `enqueued`, `running`, `completed`, and `failed`. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="updated" type="string">
  Output only. Time the export job was last updated. Computed by Google Cloud after `ship`.
</ResponseField>

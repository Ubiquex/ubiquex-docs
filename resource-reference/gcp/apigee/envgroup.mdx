`google_apigee_envgroup` (Environment Group) binds a set of hostnames to one or more Apigee environments, determining which environment's own deployed proxies handle traffic for a given incoming hostname.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own envgroup"})

    		ubx.Resource(apigee.Envgroup, "example", apigee.EnvgroupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="created_at" type="string">
  Output only. The time at which the environment group was created as milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hostnames" type="list(string)">
  Required. Host names for this environment group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. The time at which the environment group was last updated as milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  ID of the environment group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the environment group. Values other than ACTIVE means the resource is not ready to use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key"})

    		ubx.Resource(apigee.Key, "example", apigee.KeyConfig{})
    	}))
    }
    ```

  Immutable. Consumer key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="consumer_secret" type="string">
  Secret key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expires_at" type="string">
  Output only. Time the AppGroup app expires in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expires_in_seconds" type="string">
  Immutable. Expiration time, in seconds, for the consumer key. If not set or left to the default value of `-1`, the API key never expires. The expiration time can't be updated after it is set. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="issued_at" type="string">
  Output only. Time the AppGroup app was created in milliseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Scopes to apply to the app. The specified scope names must already be defined for the API product that you associate with the app. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the credential. Valid values include `approved` or `revoked`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

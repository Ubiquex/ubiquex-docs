`google_apigee_nat_address` reserves a static outbound IP address an Apigee instance uses for NAT when its proxies make outbound calls to backend targets, so those targets can allowlist a known, stable source IP.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own nat address"})

    		ubx.Resource(apigee.ApigeeNatAddress, "ci-runner", apigee.ApigeeNatAddressConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="ip_address" type="string">
  Output only. The static IPV4 address. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Resource ID of the NAT address. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the nat address. Optional; if omitted, computed by Google Cloud.
</ResponseField>

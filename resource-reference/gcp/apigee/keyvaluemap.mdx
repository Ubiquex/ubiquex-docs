`google_apigee_keyvaluemap` is a named, persistent key/value store Apigee proxy policy logic reads and writes at runtime, for caching or configuration data outside the proxy bundle itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apigee --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apigee/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apigee/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own keyvaluemap"})

    		ubx.Resource(apigee.ApigeeKeyvaluemap, "example", apigee.ApigeeKeyvaluemapConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="encrypted" type="bool">
  Required. Flag that specifies whether entry values will be encrypted. This field is retained for backward compatibility and the value of encrypted will always be `true`. Apigee X and hybrid do not support unencrypted key value maps. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="masked_values" type="bool">
  Optional. Flag that specifies whether entry values will be masked when returned. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. ID of the key value map. Optional; if omitted, computed by Google Cloud.
</ResponseField>

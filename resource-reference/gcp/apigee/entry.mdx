title: "google_apigee_entry"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entry"})

    		ubx.Resource(apigee.Entry, "example", apigee.EntryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Entry } from "@ubx/sdk-google/google/apigee/entry";

    export default stack("example", () => {
      intent({ summary: "example own entry" });

      resource(Entry, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.apigee import Entry, EntryConfig

    def describe():
        ubx.intent("example own entry")

        ubx.resource(Entry, "example", EntryConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
  <Tab title="Markdown">

## Properties

<ResponseField name="name" type="string">
  Resource URI that can be used to identify the scope of the key value map entries. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="value" type="string">
  Required. Data or payload that is being retrieved and associated with the unique key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_biglake_catalog` is the top-level BigLake metastore container that database(s) and table(s) are organized within, for open-format (Iceberg, Parquet) data managed under BigLake.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_biglake --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_biglake/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	biglake "github.com/ubiquex/ubx-sdk-google/sdk/go/google_biglake/biglake"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own catalog"})

    		ubx.Resource(biglake.BiglakeCatalog, "ci-runner", biglake.BiglakeCatalogConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation time of the catalog. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. The deletion time of the catalog. Only set after the catalog is deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The time when this catalog is considered expired. Only set after the catalog is deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/catalogs/&#123;catalog_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">

</ResponseField>

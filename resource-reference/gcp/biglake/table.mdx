`google_biglake_table` registers an open-format table (e.g. Apache Iceberg) in BigLake's own metastore, making it queryable from BigQuery and open-source engines alike with unified governance.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	biglake "github.com/ubiquex/ubx-sdk-google/sdk/go/google/biglake"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own table"})

    		ubx.Resource(biglake.Table, "example", biglake.TableConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation time of the table. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. The deletion time of the table. Only set after the table is deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  The checksum of a table object computed by the server based on the value of other fields. It may be sent on update requests to ensure the client has an up-to-date value before proceeding. It is only checked for update table operations. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The time when this table is considered expired. Only set after the table is deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hive_options" type="object">
  Options of a Hive table. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="parameters" type="map(string)">
      Stores user supplied Hive table parameters. Optional.
    </ResponseField>
    <ResponseField name="storage_descriptor" type="object">
      Stores physical storage information of the data. Optional.
      <Expandable title="properties">
        <ResponseField name="input_format" type="string">
          The fully qualified Java class name of the input format. Optional.
        </ResponseField>
        <ResponseField name="location_uri" type="string">
          Cloud Storage folder URI where the table data is stored, starting with "gs://". Optional.
        </ResponseField>
        <ResponseField name="output_format" type="string">
          The fully qualified Java class name of the output format. Optional.
        </ResponseField>
        <ResponseField name="serde_info" type="object">
          Serializer and deserializer information. Optional.
          <Expandable title="properties">
            <ResponseField name="serialization_lib" type="string">
              The fully qualified Java class name of the serialization library. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="table_type" type="string">
      Hive table type. For example, MANAGED_TABLE, EXTERNAL_TABLE. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/catalogs/&#123;catalog_id&#125;/databases/&#123;database_id&#125;/tables/&#123;table_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  The table type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last modification time of the table. Optional; if omitted, computed by Google Cloud.
</ResponseField>

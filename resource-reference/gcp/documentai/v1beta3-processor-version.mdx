`google_documentai_v1beta3_processor_version` imports a specific, versioned snapshot of a Document AI processor's own extraction model, ready to be deployed or evaluated independently of the processor's current default version.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	documentai "github.com/ubiquex/ubx-sdk-google/sdk/go/google/documentai"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta3 processor version"})

    		ubx.Resource(documentai.V1beta3ProcessorVersion, "example", documentai.V1beta3ProcessorVersionConfig{
    			ExternalProcessorVersionSource: map[string]any{"processor_version": "example"},
    			ProcessorVersionSource:         "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="external_processor_version_source" type="object">
  The external source processor version. Optional.
  <Expandable title="properties">
    <ResponseField name="processor_version" type="string">
      Required. The processor version name. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/processors/&#123;processor&#125;/processorVersions/&#123;processorVersion&#125;` Optional.
    </ResponseField>
    <ResponseField name="service_endpoint" type="string">
      Optional. The Document AI service endpoint. For example, 'https://us-documentai.googleapis.com' Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="processor_version_source" type="string">
  The source processor version to import from. The source processor version and destination processor need to be in the same environment and region. Optional.
</ResponseField>

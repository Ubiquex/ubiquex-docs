`google_documentai_processor` is a Document AI processor instance -- a specific document-parsing model (e.g. invoice or form parser) -- that document(s) are sent to for extraction.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	documentai "github.com/ubiquex/ubx-sdk-google/sdk/go/google/documentai"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own processor"})

    		ubx.Resource(documentai.Processor, "example", documentai.ProcessorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

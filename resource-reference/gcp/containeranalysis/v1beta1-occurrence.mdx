<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_containeranalysis_occurrence`.
</Warning>

`google_containeranalysis_v1beta1_occurrence` records a single instance of metadata (e.g. one detected vulnerability) about a specific container image resource, conforming to a Container Analysis note's own schema.

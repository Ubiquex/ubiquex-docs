`google_containeranalysis_v1beta1_note` defines a kind of metadata (e.g. a vulnerability or build provenance type) that Container Analysis occurrence(s) can be recorded against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	containeranalysis "github.com/ubiquex/ubx-sdk-google/sdk/go/google/containeranalysis"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 note"})

    		ubx.Resource(containeranalysis.V1beta1Note, "example", containeranalysis.V1beta1NoteConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  Note kind that represents a logical attestation "role" or "authority". For example, an organization might have one `Authority` for "QA" and one for "build". This note is intended to act strictly as a grouping mechanism for the attached occurrences (Attestations). This grouping mechanism also provides a security boundary, since IAM ACLs gate the ability for a principle to attach an occurrence to a given note. It also provides a single point of lookup to find all attached attestation occurrences, even if they don't all live in the same project. Optional; if omitted, computed by Google Cloud.

Note that these hints should not be used to look up authorities in security sensitive contexts, such as when looking up attestations to verify. Optional.

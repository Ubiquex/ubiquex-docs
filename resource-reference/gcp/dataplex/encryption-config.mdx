## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own encryption config"})

    		ubx.Resource(dataplex.EncryptionConfig, "example", dataplex.EncryptionConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the Encryption configuration was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enable_metastore_encryption" type="bool">
  Optional. Represent the state of CMEK opt-in for metastore. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encryption_state" type="string">
  Output only. The state of encryption of the databases. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Etag of the EncryptionConfig. This is a strong etag. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="failure_details" type="object">
  Details of the failure if anything related to Cmek db fails. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="error_code" type="string">
      Output only. The error code for the failure. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="error_message" type="string">
      Output only. The error message will be shown to the user. Set only if the error code is REQUIRE_USER_ACTION. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="key" type="string">
  Optional. If a key is chosen, it means that the customer is using CMEK. If a key is not chosen, it means that the customer is using Google managed encryption. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the EncryptionConfig. Format: organizations/&#123;organization&#125;/locations/&#123;location&#125;/encryptionConfigs/&#123;encryption_config&#125; Global location is not supported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the Encryption configuration was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

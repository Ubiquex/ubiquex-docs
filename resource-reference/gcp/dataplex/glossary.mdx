`google_dataplex_glossary` is a business glossary in Dataplex Universal Catalog -- a hierarchical structure of business term(s) and category/categories that can be linked to real catalog entries for shared, governed terminology.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own glossary"})

    		ubx.Resource(dataplex.Glossary, "example", dataplex.GlossaryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="category_count" type="number">
  Output only. The number of GlossaryCategories in the Glossary. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the Glossary was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The user-mutable description of the Glossary. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. User friendly display name of the Glossary. This is user-mutable. This will be same as the GlossaryId, if not specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Needed for resource freshness validation. This checksum is computed by the server based on the value of other fields, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels for the Glossary. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. The resource name of the Glossary. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/glossaries/&#123;glossary_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="term_count" type="number">
  Output only. The number of GlossaryTerms in the Glossary. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System generated unique id for the Glossary. This ID will be different if the Glossary is deleted and re-created with the same name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the Glossary was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

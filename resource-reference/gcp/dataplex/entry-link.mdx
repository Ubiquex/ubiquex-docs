`google_dataplex_entry_link` defines a typed relationship between two Dataplex catalog entries, e.g. connecting a business glossary term to the specific table column it defines.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entry link"})

    		ubx.Resource(dataplex.EntryLink, "example", dataplex.EntryLinkConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_dataplex_binding` grants IAM role(s) to principal(s) scoped to a specific set of resources within Dataplex Universal Catalog (rebranded Knowledge Catalog as of April 2026), narrower than a project-level IAM binding.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dataplex --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dataplex/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dataplex/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own binding"})

    		ubx.Resource(dataplex.DataplexBinding, "ci-runner", dataplex.DataplexBindingConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.google_dataplex.dataplex import DataplexBinding, DataplexBindingConfig

    def describe():
        ubx.intent("payments own binding")

            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the DataDomainBinding was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The relative resource name of the DataDomainBinding. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location&#125;/dataDomains/&#123;data_domain_id&#125;/bindings/&#123;binding_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource" type="string">
  Required. Immutable. The full resource name of the Google Cloud resource to be bound (i.e. included together with its contents) to the DataDomain.Format: IAM Full resource name (https://docs.cloud.google.com/iam/docs/full-resource-names) Examples: - GCP Project: //cloudresourcemanager.googleapis.com/projects/&#123;project-id&#125; - BigQuery Dataset: //bigquery.googleapis.com/projects/&#123;project-id&#125;/datasets/&#123;dataset-id&#125; - BigQuery Table: //bigquery.googleapis.com/projects/&#123;project-id&#125;/datasets/&#123;dataset-id&#125;/tables/&#123;table-id&#125; - Dataplex Data Product: //dataplex.googleapis.com/projects/&#123;project-number&#125;/locations/&#123;location&#125;/dataProducts/&#123;data-product-id&#125;Authorization: the resource to be bound must first grant an IAM role with the resource-specific setIamPolicy permission to the DataDomain. Example: - resource: //bigquery.googleapis.com/projects/&#123;project-id&#125;/datasets/&#123;dataset-id&#125; - IAM role: with bigquery.datasets.setIamPolicy permission (e.g. roles/owner) - IAM member: principal://dataplex.googleapis.com/projects/&#123;project-number&#125;/name/locations/&#123;location&#125;/dataDomains/&#123;data-domain-id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System-generated unique ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

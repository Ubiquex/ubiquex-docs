`google_dataplex_data_asset` is a curated data asset packaged as part of a Dataplex Data Product -- one of the underlying dataset(s), table(s), or view(s) that make up a governed, business-ready data offering.

## Example

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

For providing multiple predefined IAM roles, wrap them in a custom IAM role as per https://cloud.google.com/iam/docs/creating-custom-roles. Optional; if omitted, computed by Google Cloud.

<ResponseField name="create_time" type="string">
  Output only. The time at which the data asset was created. Optional; if omitted, computed by Google Cloud.

<ResponseField name="etag" type="string">
  Optional. This checksum is computed by the server based on the value of other fields, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels for the data asset.Example: &#123; "environment": "production", "billing": "marketing-department" &#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the data asset. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/dataProducts/&#123;data_product_id&#125;/dataAssets/&#123;data_asset_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource" type="string">
  Required. Immutable. Full resource name of the cloud resource represented by the data asset. This must follow https://cloud.google.com/iam/docs/full-resource-names. Example: //bigquery.googleapis.com/projects/my_project_123/datasets/dataset_456/tables/table_789 Only BigQuery tables and datasets are currently supported. Data asset creator must have getIamPolicy and setIamPolicy permissions on the resource. Data asset creator must also have resource specific get permission, for instance, bigquery.tables.get for BigQuery tables. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System generated globally unique ID for the data asset. This ID will be different if the data asset is deleted and re-created with the same name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the data asset was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

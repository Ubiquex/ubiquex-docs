`google_dataplex_aspect_type` defines a reusable, structured schema for a business or technical metadata facet (e.g. a data quality score or a PII classification) that can be attached to any Dataplex catalog entry as an aspect.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own aspect type"})

    		ubx.Resource(dataplex.AspectType, "example", dataplex.AspectTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

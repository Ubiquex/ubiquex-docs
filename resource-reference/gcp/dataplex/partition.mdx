## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dataplex --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dataplex/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dataplex/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own partition"})

    		ubx.Resource(dataplex.DataplexPartition, "example", dataplex.DataplexPartitionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="etag" type="string">
  Optional. The etag for this partition. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="location" type="string">
  Required. Immutable. The location of the entity data within the partition, for example, gs://bucket/path/to/entity/key1=value1/key2=value2. Or projects//datasets//tables/ Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Partition values used in the HTTP URL must be double encoded. For example, url_encode(url_encode(value)) can be used to encode "US:CA/CA#Sunnyvale so that the request URL ends with "/partitions/US%253ACA/CA%2523Sunnyvale". The name field in the response retains the encoded format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="values" type="list(string)">
  Required. Immutable. The set of values representing the partition, which correspond to the partition schema defined in the parent entity. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_dataplex_term` is a single business term defined within a Dataplex Universal Catalog glossary, e.g. a shared definition of `Customer Lifetime Value`.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dataplex --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dataplex/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dataplex/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own term"})

    		ubx.Resource(dataplex.DataplexTerm, "example", dataplex.DataplexTermConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_dataplex --lang ts --out ./local-sdk
    ```

    ```python
    # ubx sdk gen --only google_dataplex --lang py --out ./local-sdk

    import ubx_sdk as ubx
    from ubx.google_dataplex.dataplex import DataplexTerm, DataplexTermConfig

    def describe():
        ubx.intent("example own term")

            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the GlossaryTerm was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The user-mutable description of the GlossaryTerm. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. User friendly display name of the GlossaryTerm. This is user-mutable. This will be same as the GlossaryTermId, if not specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels for the GlossaryTerm. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. The resource name of the GlossaryTerm. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/glossaries/&#123;glossary_id&#125;/terms/&#123;term_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent" type="string">
  Required. The immediate parent of the GlossaryTerm in the resource-hierarchy. It can either be a Glossary or a GlossaryCategory. Format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/glossaries/&#123;glossary_id&#125; OR projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/glossaries/&#123;glossary_id&#125;/categories/&#123;category_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System generated unique id for the GlossaryTerm. This ID will be different if the GlossaryTerm is deleted and re-created with the same name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the GlossaryTerm was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

---
title: "google_dataplex_task"
description: "`google_dataplex_task` schedules a recurring or one-off Spark job (a notebook or custom script) to run against data managed within a Dataplex lake."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own task"})

    		ubx.Resource(dataplex.Task, "example", dataplex.TaskConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Task } from "@ubx/sdk-google/google/dataplex/task";

    export default stack("example", () => {
      intent({ summary: "example own task" });

      resource(Task, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.dataplex import Task, TaskConfig

    def describe():
        ubx.intent("example own task")

        ubx.resource(Task, "example", TaskConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

<ResponseField name="trigger_spec" type="object">
  Task scheduling and trigger settings. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="disabled" type="bool">
      Optional. Prevent the task from executing. This does not cancel already running tasks. It is intended to temporarily disable RECURRING tasks. Optional.
    </ResponseField>
    <ResponseField name="max_retries" type="number">
      Optional. Number of retry attempts before aborting. Set to zero to never attempt to retry a failed task. Optional.
    </ResponseField>
    <ResponseField name="schedule" type="string">
      Optional. Cron schedule (https://en.wikipedia.org/wiki/Cron) for running tasks periodically. To explicitly set a timezone to the cron tab, apply a prefix in the cron tab: "CRON_TZ=$&#123;IANA_TIME_ZONE&#125;" or "TZ=$&#123;IANA_TIME_ZONE&#125;". The $&#123;IANA_TIME_ZONE&#125; may only be a valid string from IANA time zone database. For example, CRON_TZ=America/New_York 1 * * * *, or TZ=America/New_York 1 * * * *. This field is required for RECURRING tasks. Optional.
    </ResponseField>
    <ResponseField name="start_time" type="string">
      Optional. The first run of the task will be after this time. If not specified, the task will run shortly after being submitted if ON_DEMAND and based on the schedule if RECURRING. Optional.

    <ResponseField name="type" type="string">
      Required. Immutable. Trigger type of the user-specified Task. Optional.
    </ResponseField>

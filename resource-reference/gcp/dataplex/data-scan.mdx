`google_dataplex_data_scan` runs an automated data quality or data profiling scan against a BigQuery table or Cloud Storage dataset, producing rule-level pass/fail results and column-level statistics.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own data scan"})

    		ubx.Resource(dataplex.DataScan, "example", dataplex.DataScanConfig{

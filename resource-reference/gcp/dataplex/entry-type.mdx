`google_dataplex_entry_type` defines the schema (which aspect types are required or allowed) that catalog entries of a given kind must conform to in Dataplex Universal Catalog.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entry type"})

    		ubx.Resource(dataplex.EntryType, "example", dataplex.EntryTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_dataplex_metadata_feed` triggers automatic Dataplex Catalog entry updates whenever a linked resource's own metadata (e.g. a BigQuery table's schema) changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataplex "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataplex"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own metadata feed"})

    		ubx.Resource(dataplex.MetadataFeed, "example", dataplex.MetadataFeedConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the feed was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filters" type="object">
  Filters defines the type of changes that you want to listen to. You can have multiple entry type filters and multiple aspect type filters. All of the entry type filters are OR'ed together. All of the aspect type filters are OR'ed together. All of the entry type filters and aspect type filters are AND'ed together. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="aspect_types" type="list(string)">
      Optional. The aspect types that you want to listen to. Depending on how the aspect is attached to the entry, in the format: projects/&#123;project_id_or_number&#125;/locations/&#123;location&#125;/aspectTypes/&#123;aspect_type_id&#125;. Optional.
    </ResponseField>
    <ResponseField name="change_types" type="list(string)">
      Optional. The type of change that you want to listen to. If not specified, all changes are published. Optional.
    </ResponseField>
    <ResponseField name="entry_types" type="list(string)">
      Optional. The entry types that you want to listen to, specified as relative resource names in the format projects/&#123;project_id_or_number&#125;/locations/&#123;location&#125;/entryTypes/&#123;entry_type_id&#125;. Only entries that belong to the specified entry types are published. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the metadata feed, in the format projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/metadataFeeds/&#123;metadata_feed_id&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pubsub_topic" type="string">
  Optional. The pubsub topic that you want the metadata feed messages to publish to. Please grant Dataplex service account the permission to publish messages to the topic. The service account is: service-&#123;PROJECT_NUMBER&#125;@gcp-sa-dataplex.iam.gserviceaccount.com. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scope" type="object">
  Scope defines the scope of the metadata feed. Scopes are exclusive. Only one of the scopes can be specified. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="entry_groups" type="list(string)">
      Optional. The entry groups whose entries you want to listen to. Must be in the format: projects/&#123;project_id_or_number&#125;/locations/&#123;location_id&#125;/entryGroups/&#123;entry_group_id&#125;. Optional.
    </ResponseField>
    <ResponseField name="organization_level" type="bool">
      Optional. Whether the metadata feed is at the organization-level. If true, all changes happened to the entries in the same organization as the feed are published. If false, you must specify a list of projects or a list of entry groups whose entries you want to listen to.The default is false. Optional.
    </ResponseField>
    <ResponseField name="projects" type="list(string)">
      Optional. The projects whose entries you want to listen to. Must be in the same organization as the feed. Must be in the format: projects/&#123;project_id_or_number&#125;. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. A system-generated, globally unique ID for the metadata job. If the metadata job is deleted and then re-created with the same name, this ID is different. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the feed was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

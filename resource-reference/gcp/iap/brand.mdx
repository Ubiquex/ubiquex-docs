`google_iap_brand` configures the OAuth consent screen branding (app name, support email) shown to users authenticating through Identity-Aware Proxy for a project.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_iap --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_iap/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iap "github.com/ubiquex/ubx-sdk-google/sdk/go/google_iap/iap"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own brand"})

    		ubx.Resource(iap.IapBrand, "ci-runner", iap.IapBrandConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_iap --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";
    import { IapBrand } from "./local-sdk/google_iap/sdk/typescript/google_iap/iap/iap_brand.ts";

    export default stack("payments", () => {
      intent({ summary: "payments own brand" });

      resource(IapBrand, "ci-runner", {
        name: "ci-runner",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_iap --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_iap/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_iap.iap import IapBrand, IapBrandConfig

    def describe():
        ubx.intent("payments own brand")

        ubx.resource(IapBrand, "ci-runner", IapBrandConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="application_title" type="string">
  Application name displayed on OAuth consent screen. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier of the brand. NOTE: GCP project number achieves the same brand identification purpose as only one brand per project can be created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="org_internal_only" type="bool">
  Output only. Whether the brand is only intended for usage inside the G Suite organization only. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="support_email" type="string">
  Support email displayed on the OAuth consent screen. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_iap_brand` configures the OAuth consent screen branding (app name, support email) shown to users authenticating through Identity-Aware Proxy for a project.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iap "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iap"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own brand"})

    		ubx.Resource(iap.Brand, "example", iap.BrandConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Brand } from "@ubx/sdk-google/google/iap/brand";

    export default stack("example", () => {
      intent({ summary: "example own brand" });

      resource(Brand, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.iap import Brand, BrandConfig

    def describe():
        ubx.intent("example own brand")

        ubx.resource(Brand, "example", BrandConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="application_title" type="string">
  Application name displayed on OAuth consent screen. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier of the brand. NOTE: GCP project number achieves the same brand identification purpose as only one brand per project can be created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="org_internal_only" type="bool">
  Output only. Whether the brand is only intended for usage inside the G Suite organization only. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="support_email" type="string">
  Support email displayed on the OAuth consent screen. Optional; if omitted, computed by Google Cloud.
</ResponseField>

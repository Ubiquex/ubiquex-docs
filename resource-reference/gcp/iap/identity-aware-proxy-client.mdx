`google_iap_identity_aware_proxy_client` is an additional OAuth client registered under an Identity-Aware Proxy brand, letting more than one client application authenticate through the same IAP-protected resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iap "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iap"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own identity aware proxy client"})

    		ubx.Resource(iap.IdentityAwareProxyClient, "example", iap.IdentityAwareProxyClientConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="display_name" type="string">
  Human-friendly name given to the OAuth client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Unique identifier of the OAuth client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="secret" type="string">
  Output only. Client secret of the OAuth client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

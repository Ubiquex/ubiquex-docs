`google_iap_settings` -- real, typed bindings generated directly from the
`hashicorp/google` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iap"
    )

    cfg := iap.SettingsConfig{
        Name: "example-name",
    }
    ubx.Resource(iap.Settings, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Settings } from
      "jsr:@ubx/sdk-google/google/iap/settings";

    resource(Settings, "example", {
      name: "example-name",
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.google.iap import Settings, SettingsConfig

    cfg = SettingsConfig(
        name="example-name",
    )
    ubx.resource(Settings, "example", cfg)
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Provision google_iap_settings with name.
    ```
  </Tab>
</Tabs>

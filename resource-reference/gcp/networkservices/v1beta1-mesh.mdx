`google_networkservices_v1beta1_mesh` is the top-level Cloud Service Mesh resource that gRPC and HTTP route(s) are attached to, defining the logical service mesh workloads participate in.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 mesh"})

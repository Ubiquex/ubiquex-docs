`google_networkservices_v1beta1_tls_route` defines routing rule(s) for TLS traffic within a Cloud Service Mesh, matching on SNI and directing matching connections to a specific backend without terminating TLS.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 tls route"})

    		ubx.Resource(networkservices.V1beta1TlsRoute, "example", networkservices.V1beta1TlsRouteConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_networkservices_v1beta1_wasm_plugin` deploys a caller-authored WebAssembly module as a Service Extension, running custom request/response processing logic inline on a load balancer or service mesh's own data path.

## Example

<Tabs>

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 wasm plugin"})

    		ubx.Resource(networkservices.V1beta1WasmPlugin, "example", networkservices.V1beta1WasmPluginConfig{
    			Name: "example",
    		})
    	}))
    }

<ResponseField name="kms_key_name" type="string">
  Optional. The name of the customer-managed [CryptoKey](https://cloud.google.com/kms/docs/reference/rest/v1/projects.locations.keyRings.cryptoKeys) to be used to encrypt the `WasmPlugin` image (provided by image_uri) and configuration (provided by plugin_config_data or plugin_config_uri) that are stored by the `Service Extensions` product at rest. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyring&#125;/cryptoKeys/&#123;key&#125;` By default, Google Cloud automatically encrypts all data at rest using Google-owned and Google-managed encryption keys. If you need ownership and control of the keys that protect your data at rest, you can specify a customer-managed encryption key (CMEK) to encrypt your `WasmPlugin` data. For more information, see [Using customer-managed encryption keys](https://cloud.google.com/service-extensions/docs/cmek). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kms_key_version" type="string">
  Output only. The name of the specific [CryptoKeyVersion](https://cloud.google.com/kms/docs/reference/rest/v1/projects.locations.keyRings.cryptoKeys.cryptoKeyVersions) used to encrypt the `WasmPlugin` data, if the kms_key_name field is set. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyring&#125;/cryptoKeys/&#123;key&#125;/cryptoKeyVersions/&#123;version&#125;` This is a read-only field. `WasmPlugin` data is automatically encrypted using the most recent `CryptoKeyVersion` of the `CryptoKey` provided in the `kms_key_name` field. See [Cloud KMS resources](https://cloud.google.com/kms/docs/resource-hierarchy) for more information. Optional; if omitted, computed by Google Cloud.
</ResponseField>

The value of the field must be between `0` and `1` (inclusive). This field can be specified only if logging is enabled for this plugin. Optional.

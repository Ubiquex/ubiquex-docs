<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networkservices_agent_connectivity_template`.
</Warning>

`google_networkservices_v1beta1_agent_connectivity_template` defines a reusable connectivity configuration (ingress/egress mode, policy defaults) that Agent Gateway deployments on the Gemini Enterprise Agent Platform are created from.

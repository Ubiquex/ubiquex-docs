`google_networkservices_authz_extension` calls out to an external authorization service as part of a Cloud Service Mesh or load balancer request path, letting a custom service decide whether to allow or deny each request.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own authz extension"})

    		ubx.Resource(networkservices.AuthzExtension, "example", networkservices.AuthzExtensionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="authority" type="string">
  Optional. The `:authority` header in the gRPC request sent from Envoy to the extension service. It is required when the `service` field points to a backend service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the resource was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A human-readable description of the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fail_open" type="bool">
  Optional. Determines how the proxy behaves if the call to the extension fails or times out. When set to `TRUE`, request or response processing continues without error. Any subsequent extensions in the extension chain are also executed. When set to `FALSE` or the default setting of `FALSE` is used, one of the following happens: * If response headers have not been delivered to the downstream client, a generic 500 error is returned to the client. The error response can be tailored by configuring a custom error response in the load balancer. * If response headers have been delivered, then the HTTP stream to the downstream client is reset. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="forward_attributes" type="list(string)">
  Optional. List of the Envoy attributes to forward to the extension server. The attributes provided here are included as part of the `ProcessingRequest.attributes` field (of type `map`), where the keys are the attribute names. Refer to the [documentation](https://cloud.google.com/service-extensions/docs/cel-matcher-language-reference#attributes) for the names of attributes that can be forwarded. If omitted, no attributes are sent. Each element is a string indicating the attribute name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="forward_headers" type="list(string)">
  Optional. List of the HTTP headers to forward to the extension (from the client). If omitted, all headers are sent. Each element is a string indicating the header name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of labels associated with the `AuthzExtension` resource. The format must comply with [the requirements for labels](https://cloud.google.com/compute/docs/labeling-resources#requirements) for Google Cloud resources. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="load_balancing_scheme" type="string">
  Optional. All backend services and forwarding rules referenced by this extension must share the same load balancing scheme. The supported values are `INTERNAL_MANAGED` and `EXTERNAL_MANAGED`. You can omit this field for `AuthzExtensions` resources that don't reference a backend service. For more information, see [Backend services overview](https://cloud.google.com/load-balancing/docs/backend-service). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="map(any)">
  Optional. The metadata provided here is included as part of the `metadata_context` (of type `google.protobuf.Struct`) in the `ProcessingRequest` message sent to the extension server. The metadata is available under the namespace `com.google.authz_extension.`. The following variables are supported in the metadata Struct: `&#123;forwarding_rule_id&#125;` - substituted with the forwarding rule's fully qualified resource name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Identifier. Name of the `AuthzExtension` resource in the following format: `projects/&#123;project&#125;/locations/&#123;location&#125;/authzExtensions/&#123;authz_extension&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service" type="string">
  Required. The reference to the service that runs the extension. To configure a callout extension: For global AuthzExtension, `service` must be a fully-qualified reference to a [backend service](https://cloud.google.com/compute/docs/reference/rest/v1/backendServices) in the format: `https://www.googleapis.com/compute/v1/projects/&#123;project&#125;/global/backendServices/&#123;backendService&#125;`. For regional AuthzExtension, `service` must be a fully-qualified reference to one of the following: * a [backend service](https://cloud.google.com/compute/docs/reference/rest/v1/backendServices) in the format: `https://www.googleapis.com/compute/v1/projects/&#123;project&#125;/regions/&#123;region&#125;/backendServices/&#123;backendService&#125;`. * a fully qualified domain name that can be resolved by the Google Cloud DNS. * `iap.googleapis.com` and it can only be referenced by an AuthzPolicy with the policyProfile set to REQUEST_AUTHZ. * `modelarmor..rep.googleapis.com` and it can only be referenced by an AuthzPolicy with the policyProfile set to CONTENT_AUTHZ. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="timeout" type="string">
  Required. Specifies the timeout for each individual message on the stream. The timeout must be between 10-10000 milliseconds. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the resource was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="wire_format" type="string">
  Optional. The format of communication supported by the callout extension. This field is supported only for regional `AuthzExtension` resources. If not specified, the default value `EXT_PROC_GRPC` is used. Global `AuthzExtension` resources use the `EXT_PROC_GRPC` wire format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_networkservices_multicast_consumer_association` grants a specific VPC network permission to consume (receive) traffic from a Cloud Multicast group range, part of Google Cloud's own real IP multicast support for VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own multicast consumer association"})

    		ubx.Resource(networkservices.MulticastConsumerAssociation, "example", networkservices.MulticastConsumerAssociationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. [Output only] The timestamp when the multicast consumer association was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. An optional text description of the multicast consumer association. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key-value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="multicast_domain_activation" type="string">
  Optional. The resource name of the multicast domain activation that is in the same zone as this multicast consumer association. Use the following format: `projects/*/locations/*/multicastDomainActivations/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the multicast consumer association. Use the following format: `projects/*/locations/*/multicastConsumerAssociations/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Required. The resource name of the multicast consumer VPC network. Use following format: `projects/&#123;project&#125;/locations/global/networks/&#123;network&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="placement_policy" type="string">
  Output only. [Output only] A Compute Engine (placement policy)[https://cloud.google.com/compute/docs/instances/placement-policies-overview] that can be used to place virtual machine (VM) instances as multicast consumers close to the multicast infrastructure created for this domain, on a best effort basis. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_state" type="string">
  Output only. [Deprecated] The resource state of the multicast consumer association. Use the state field instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="object">
  The multicast resource's state. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="state" type="string">
      Optional. The state of the multicast resource. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="unique_id" type="string">
  Output only. [Output only] The Google-generated UUID for the resource. This value is unique across all multicast consumer association resources. If a consumer association is deleted and another with the same name is created, the new consumer association is assigned a different unique_id. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. [Output only] The timestamp when the Multicast Consumer Association was most recently updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

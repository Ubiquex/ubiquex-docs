`google_networkservices_v1beta1_service_lb_policy` configures load-balancing behavior (e.g. auto-capacity draining, isolation) applied across the backend(s) of a Cloud Service Mesh or load-balanced backend service.

## Properties

<ResponseField name="auto_capacity_drain" type="object">
  Option to specify if an unhealthy IG/NEG should be considered for global load balancing and traffic routing. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="enable" type="bool">
      Optional. If set to 'True', an unhealthy IG/NEG will be set as drained. - An IG/NEG is considered unhealthy if less than 25% of the instances/endpoints in the IG/NEG are healthy. - This option will never result in draining more than 50% of the configured IGs/NEGs for the Backend Service. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this resource was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A free-text description of the resource. Max length 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="failover_config" type="object">
  Option to specify health based failover behavior. This is not related to Network load balancer FailoverPolicy. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="failover_health_threshold" type="number">
      Optional. The percentage threshold that a load balancer will begin to send traffic to failover backends. If the percentage of endpoints in a MIG/NEG is smaller than this value, traffic would be sent to failover backends if possible. This field should be set to a value between 1 and 99. The default value is 50 for Global external HTTP(S) load balancer (classic) and Proxyless service mesh, and 70 for others. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="isolation_config" type="object">
  Configuration to provide isolation support for the associated Backend Service. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="isolation_granularity" type="string">
      Optional. The isolation granularity of the load balancer. Optional.
    </ResponseField>
    <ResponseField name="isolation_mode" type="string">
      Optional. The isolation mode of the load balancer. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of label tags associated with the ServiceLbPolicy resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="load_balancing_algorithm" type="string">
  Optional. The type of load balancing algorithm to be used. The default behavior is WATERFALL_BY_REGION. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the ServiceLbPolicy resource. It matches pattern `projects/&#123;project&#125;/locations/&#123;location&#125;/serviceLbPolicies/&#123;service_lb_policy_name&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when this resource was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_networkservices_v1beta1_lb_tcp_extension` is a real Cloud Service Mesh TCP load balancer extension -- its own extension_chains, load_balancing_scheme, and the networks it applies to -- letting custom processing be inserted into a TCP load balancer's own traffic path without modifying the load balancer's own core configuration.

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networkservices_lb_traffic_extension`.
</Warning>

`google_networkservices_v1beta1_lb_traffic_extension` runs a Service Extension against a load balancer's own traffic before routing, letting external logic inspect or modify requests and responses passing through.

The following variables are supported in the metadata: `&#123;forwarding_rule_id&#125;` - substituted with the forwarding rule's fully qualified resource name. This field must not be set if at least one of the extension chains contains plugin extensions. Setting it results in a validation error.

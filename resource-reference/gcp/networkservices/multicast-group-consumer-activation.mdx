`google_networkservices_multicast_group_consumer_activation` activates a previously associated consumer VPC network to actually start receiving traffic from a specific Cloud Multicast group.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own multicast group consumer activation"})

    		ubx.Resource(networkservices.MulticastGroupConsumerActivation, "example", networkservices.MulticastGroupConsumerActivationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. [Output only] The timestamp when the multicast group consumer activation was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. An optional text description of the multicast group consumer activation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key-value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="log_config" type="object">
  The logging configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Optional. Whether to enable logging or not. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="multicast_consumer_association" type="string">
  Required. The resource name of the multicast consumer association that is in the same zone as this multicast group consumer activation. Use the following format: `projects/*/locations/*/multicastConsumerAssociations/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="multicast_group" type="string">
  Optional. The resource name of the multicast group created by the admin in the same zone as this multicast group consumer activation. Use the following format: // `projects/*/locations/*/multicastGroups/*`. This field is deprecated. Use multicast_group_range_activation instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="multicast_group_range_activation" type="string">
  Required. The resource name of the multicast group range activation created by the admin in the same zone as this multicast group consumer activation. Use the following format: // `projects/*/locations/*/multicastGroupRangeActivations/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the multicast group consumer activation. Use the following format: `projects/*/locations/*/multicastGroupConsumerActivations/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_state" type="string">
  Output only. [Deprecated] The resource state of the multicast group consumer activation. Use the state field instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="object">
  The multicast resource's state. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="state" type="string">
      Optional. The state of the multicast resource. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="unique_id" type="string">
  Output only. [Output only] The Google-generated UUID for the resource. This value is unique across all multicast group consumer activation resources. If a group consumer activation is deleted and another with the same name is created, the new group consumer activation is assigned a different unique_id. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. [Output only] The timestamp when the multicast group consumer activation was most recently updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_networkservices_endpoint_policy` configures the traffic behavior (mTLS, logging) a proxyless gRPC or sidecar-based workload applies to inbound connections in a Cloud Service Mesh.

## Properties

<ResponseField name="authorization_policy" type="string">
  Optional. This field specifies the URL of AuthorizationPolicy resource that applies authorization policies to the inbound traffic at the matched endpoints. Refer to Authorization. If this field is not specified, authorization is disabled(no authz checks) for this endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="client_tls_policy" type="string">
  Optional. Deprecated: This field is not used and is a no-op. A URL referring to a ClientTlsPolicy resource. ClientTlsPolicy can be set to specify the authentication for traffic from the proxy to the actual endpoints. More specifically, it is applied to the outgoing traffic from the proxy to the endpoint. This is typically used for sidecar model where the proxy identifies itself as endpoint to the control plane, with the connection between sidecar and endpoint requiring authentication. If this field is not set, authentication is disabled(open). Applicable only when EndpointPolicyType is SIDECAR_PROXY. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the resource was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A free-text description of the resource. Max length 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="endpoint_matcher" type="object">
  A definition of a matcher that selects endpoints to which the policies should be applied. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="metadata_label_matcher" type="object">
      The matcher that is based on node metadata presented by xDS clients. Optional.
      <Expandable title="properties">
        <ResponseField name="metadata_label_match_criteria" type="string">
          Specifies how matching should be done. Supported values are: MATCH_ANY: At least one of the Labels specified in the matcher should match the metadata presented by xDS client. MATCH_ALL: The metadata presented by the xDS client should contain all of the labels specified here. The selection is determined based on the best match. For example, suppose there are three EndpointPolicy resources P1, P2 and P3 and if P1 has a the matcher as MATCH_ANY , P2 has MATCH_ALL , and P3 has MATCH_ALL . If a client with label connects, the config from P1 will be selected. If a client with label connects, the config from P2 will be selected. If a client with label connects, the config from P3 will be selected. If there is more than one best match, (for example, if a config P4 with selector exists and if a client with label connects), pick up the one with older creation time. Optional.
        </ResponseField>
        <ResponseField name="metadata_labels" type="list(object)">
          The list of label value pairs that must match labels in the provided metadata based on filterMatchCriteria This list can have at most 64 entries. The list can be empty if the match criteria is MATCH_ANY, to specify a wildcard match (i.e this matches any client). Optional.
          <Expandable title="properties">
            <ResponseField name="label_name" type="string">
              The name of the label this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="label_value" type="string">
              The value of the label this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of label tags associated with the EndpointPolicy resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the EndpointPolicy resource. It matches pattern `projects/&#123;project&#125;/locations/*/endpointPolicies/&#123;endpoint_policy&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="server_tls_policy" type="string">
  Optional. A URL referring to ServerTlsPolicy resource. ServerTlsPolicy is used to determine the authentication policy to be applied to terminate the inbound traffic at the identified backends. If this field is not set, authentication is disabled(open) for this endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="traffic_port_selector" type="object">
  Specification of a port-based selector. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="ports" type="list(string)">
      Optional. A list of ports. Can be port numbers or port range (example, [80-90] specifies all ports from 80 to 90, including 80 and 90) or named ports or * to specify all ports. If the list is empty, all ports are selected. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  Required. The type of endpoint policy. This is primarily used to validate the configuration. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the resource was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

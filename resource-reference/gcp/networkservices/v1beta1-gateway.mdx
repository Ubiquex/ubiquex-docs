`google_networkservices_v1beta1_gateway` is the Traffic Director/Cloud Service Mesh resource defining a data-plane listener (address, port, routing type) that traffic enters through before being matched to a route.

## Properties

<ResponseField name="addresses" type="list(string)">
  Optional. Zero or one IPv4 or IPv6 address on which the Gateway will receive the traffic. When no address is provided, an IP from the subnetwork is allocated This field only applies to gateways of type 'SECURE_WEB_GATEWAY'. Gateways of type 'OPEN_MESH' listen on 0.0.0.0 for IPv4 and :: for IPv6. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="all_ports" type="bool">
  Optional. If true, the Gateway will listen on all ports. This is mutually exclusive with the `ports` field. This field only applies to gateways of type 'SECURE_WEB_GATEWAY'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="allow_global_access" type="bool">
  Optional. If true, the gateway will allow traffic from clients outside of the region where the gateway is located. This field is configurable only for gateways of type SECURE_WEB_GATEWAY. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="certificate_urls" type="list(string)">
  Optional. A fully-qualified Certificates URL reference. The proxy presents a Certificate (selected based on SNI) when establishing a TLS connection. This feature only applies to gateways of type 'SECURE_WEB_GATEWAY'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the resource was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A free-text description of the resource. Max length 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="envoy_headers" type="string">
  Optional. Determines if envoy will insert internal debug headers into upstream requests. Other Envoy headers may still be injected. By default, envoy will not insert any debug headers. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="gateway_security_policy" type="string">
  Optional. A fully-qualified GatewaySecurityPolicy URL reference. Defines how a server should apply security policy to inbound (VM to Proxy) initiated connections. For example: `projects/*/locations/*/gatewaySecurityPolicies/swg-policy`. This policy is specific to gateways of type 'SECURE_WEB_GATEWAY'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ip_version" type="string">
  Optional. The IP Version that will be used by this gateway. Valid options are IPV4 or IPV6. Default is IPV4. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of label tags associated with the Gateway resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the Gateway resource. It matches pattern `projects/*/locations/*/gateways/`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Optional. The relative resource name identifying the VPC network that is using this configuration. For example: `projects/*/global/networks/network-1`. Currently, this field is specific to gateways of type 'SECURE_WEB_GATEWAY'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ports" type="list(number)">
  Required. One or more port numbers (1-65535), on which the Gateway will receive traffic. The proxy binds to the specified ports. Gateways of type 'SECURE_WEB_GATEWAY' are limited to 5 ports. Gateways of type 'OPEN_MESH' listen on 0.0.0.0 for IPv4 and :: for IPv6 and support multiple ports. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="routing_mode" type="string">
  Optional. The routing mode of the Gateway. This field is configurable only for gateways of type SECURE_WEB_GATEWAY. This field is required for gateways of type SECURE_WEB_GATEWAY. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scope" type="string">
  Optional. Scope determines how configuration across multiple Gateway instances are merged. The configuration for multiple Gateway instances with the same scope will be merged as presented as a single configuration to the proxy/load balancer. Max length 64 characters. Scope should start with a letter and can only have letters, numbers, hyphens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self_link" type="string">
  Output only. Server-defined URL of this resource Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="server_tls_policy" type="string">
  Optional. A fully-qualified ServerTLSPolicy URL reference. Specifies how TLS traffic is terminated. If empty, TLS termination is disabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subnetwork" type="string">
  Optional. The relative resource name identifying the subnetwork in which this SWG is allocated. For example: `projects/*/regions/us-central1/subnetworks/network-1` Currently, this field is specific to gateways of type 'SECURE_WEB_GATEWAY". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Immutable. The type of the customer managed gateway. This field is required. If unspecified, an error is returned. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the resource was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

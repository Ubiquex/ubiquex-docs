`google_networkservices_service_binding` links a Cloud Service Mesh route to a Service Directory service entry, resolving mesh traffic to endpoints registered outside Google Cloud's own native compute.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_networkservices --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_networkservices/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google_networkservices/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own service binding"})

    		ubx.Resource(networkservices.NetworkservicesServiceBinding, "ci-runner", networkservices.NetworkservicesServiceBindingConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

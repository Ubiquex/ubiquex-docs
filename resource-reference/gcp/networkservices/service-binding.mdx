`google_networkservices_service_binding` links a Cloud Service Mesh route to a Service Directory service entry, resolving mesh traffic to endpoints registered outside Google Cloud's own native compute.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkservices "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkservices"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service binding"})

    		ubx.Resource(networkservices.ServiceBinding, "example", networkservices.ServiceBindingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the resource was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A free-text description of the resource. Max length 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of label tags associated with the ServiceBinding resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the ServiceBinding resource. It matches pattern `projects/*/locations/*/serviceBindings/`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service" type="string">
  Optional. The full Service Directory Service name of the format `projects/*/locations/*/namespaces/*/services/*`. This field is for Service Directory integration which will be deprecated soon. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_id" type="string">
  Output only. The unique identifier of the Service Directory Service against which the ServiceBinding resource is validated. This is populated when the Service Binding resource is used in another resource (like Backend Service). This is of the UUID4 format. This field is for Service Directory integration which will be deprecated soon. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the resource was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

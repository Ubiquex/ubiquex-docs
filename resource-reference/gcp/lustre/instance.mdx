`google_lustre_instance` provisions a Google Cloud Managed Lustre instance, a fully managed, high-throughput parallel file system used for HPC and AI training workloads.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	lustre "github.com/ubiquex/ubx-sdk-google/sdk/go/google/lustre"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own instance"})

    		ubx.Resource(lustre.Instance, "example", lustre.InstanceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="access_rules_options" type="object">
  IP-based access rules for the Managed Lustre instance. These options define the root user squash configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="access_rules" type="list(object)">
      Optional. The access rules for the instance. Optional.
      <Expandable title="properties">
        <ResponseField name="ip_address_ranges" type="list(string)">
          The IP address range(s) this access rule grants access to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          A caller-chosen name for this access rule. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="squash_mode" type="string">
          How client root privileges are handled: `NO_SQUASH` (client root keeps root on the filesystem) or `ROOT_SQUASH` (client root is mapped to an unprivileged user). Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="default_squash_gid" type="number">
      Optional. The user squash GID for the default access rule. This user squash GID applies to all root users connecting from clients that are not matched by any of the access rules. If not set, the default is 0 (no GID squash). Optional.
    </ResponseField>
    <ResponseField name="default_squash_mode" type="string">
      Required. The squash mode for the default access rule. Optional.
    </ResponseField>
    <ResponseField name="default_squash_uid" type="number">
      Optional. The user squash UID for the default access rule. This user squash UID applies to all root users connecting from clients that are not matched by any of the access rules. If not set, the default is 0 (no UID squash). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="per_unit_storage_throughput" type="string">
  Optional. The throughput of the instance in MBps per TiB. Valid values are 0, 125, 250, 500, 1000.

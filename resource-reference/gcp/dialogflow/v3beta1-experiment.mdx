<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_experiment`.
</Warning>

`google_dialogflow_v3beta1_experiment` runs an A/B test between two versions of a Dialogflow agent's own flow, routing a portion of live traffic to the variant to measure which performs better.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dialogflow_v3beta1 --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dialogflow_v3beta1/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dialogflow_v3beta1/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v3beta1 experiment"})

    		ubx.Resource(dialogflow.V3beta1DialogflowV3beta1Experiment, "example", dialogflow.V3beta1DialogflowV3beta1ExperimentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

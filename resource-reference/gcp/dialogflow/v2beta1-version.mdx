`google_dialogflow_v2beta1_version` is an immutable, named snapshot of a Dialogflow agent's own configuration at a point in time, deployable to an environment independently of ongoing draft changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 version"})

    		ubx.Resource(dialogflow.V2beta1Version, "example", dialogflow.V2beta1VersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

<Warning>
  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_version`.
</Warning>

`google_dialogflow_v2beta1_version` is an immutable, named snapshot of a Dialogflow agent's own configuration at a point in time, deployable to an environment independently of ongoing draft changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dialogflow_v2beta1 --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dialogflow_v2beta1/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dialogflow_v2beta1/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 version"})

    		ubx.Resource(dialogflow.V2beta1DialogflowV2beta1Version, "example", dialogflow.V2beta1DialogflowV2beta1VersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

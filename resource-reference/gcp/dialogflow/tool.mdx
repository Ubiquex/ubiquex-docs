`google_dialogflow_tool` registers an external function, API, or data store a Dialogflow CX playbook can call during a conversation to fetch information or take an action outside the agent itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tool"})

    		ubx.Resource(dialogflow.Tool, "example", dialogflow.ToolConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Tool } from "@ubx/sdk-google/google/dialogflow/tool";

    export default stack("example", () => {

      resource(Tool, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">

    import ubx_sdk as ubx

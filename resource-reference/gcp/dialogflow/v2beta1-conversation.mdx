<Warning>
  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_dialogflow_v2beta1_conversation` is a real, ongoing conversation session tracked by Dialogflow -- its own lifecycle_state, phone_number (for telephony), and conversation_profile -- so a multi-turn exchange (human or automated) can be managed and inspected as one resource rather than a raw stream of individual messages.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 conversation"})

    		ubx.Resource(dialogflow.V2beta1Conversation, "example", dialogflow.V2beta1ConversationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

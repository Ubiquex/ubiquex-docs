## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own intent"})

    		ubx.Resource(dialogflow.Intent, "ci-runner", dialogflow.IntentConfig{
    			DisplayName:              "example-display-name",
    			DefaultResponsePlatforms: []string{"example"},
    			Events:                   []string{"example"},
    			InputContextNames:        []string{"example"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="action" type="string">
  The name of the action associated with the intent. Note: The action name must not contain whitespaces. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="default_response_platforms" type="list(string)">
  The list of platforms for which the first responses will be copied from the messages in PLATFORM_UNSPECIFIED (i.e. default platform). Possible values: ["FACEBOOK", "SLACK", "TELEGRAM", "KIK", "SKYPE", "LINE", "VIBER", "ACTIONS_ON_GOOGLE", "GOOGLE_HANGOUTS"] Optional.
</ResponseField>

<ResponseField name="deletion_policy" type="string">
  Whether Terraform will be prevented from destroying the instance. Defaults to "DELETE". When a 'terraform destroy' or 'terraform apply' would delete the instance, the command will fail if this field is set to "PREVENT" in Terraform state. When set to "ABANDON", the command will remove the resource from Terraform management without updating or deleting the resource in the API. When set to "DELETE", deleting the resource is allowed. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="display_name" type="string" required>
  The name of this intent to be displayed on the console. Required.
</ResponseField>

<ResponseField name="events" type="list(string)">
  The collection of event names that trigger the intent. If the collection of input contexts is not empty, all of the contexts must be present in the active user session for an event to trigger this intent. See the [events reference](https://cloud.google.com/dialogflow/docs/events-overview) for more details. Optional.
</ResponseField>

<ResponseField name="id" type="string">

<ResponseField name="input_context_names" type="list(string)">

<ResponseField name="is_fallback" type="bool">

<ResponseField name="ml_disabled" type="bool">

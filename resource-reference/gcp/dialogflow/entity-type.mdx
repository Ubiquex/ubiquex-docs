`google_dialogflow_entity_type` defines a category of value (e.g. a city name or product SKU) a Dialogflow agent can extract from user input, along with its own synonyms and matching behavior.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entity type"})

    		ubx.Resource(dialogflow.EntityType, "example", dialogflow.EntityTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

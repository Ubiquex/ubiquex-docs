`google_dialogflow_generator` defines a reusable LLM prompt template a Dialogflow CX agent invokes mid-conversation to generate dynamic content, e.g. a summary or a suggested response.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own generator"})

    		ubx.Resource(dialogflow.Generator, "example", dialogflow.GeneratorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    <ResponseField name="max_decode_steps" type="number">
      The maximum number of tokens the model may generate. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="temperature" type="number">
      Controls the randomness of the model's own output -- higher values produce more varied, less predictable results. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="top_k" type="number">
      Restricts sampling to the K most probable next tokens at each step. Optional. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="top_p" type="number">
      Restricts sampling to the smallest set of most-probable next tokens whose combined probability reaches this threshold. Optional. **(AI-inferred)**
    </ResponseField>

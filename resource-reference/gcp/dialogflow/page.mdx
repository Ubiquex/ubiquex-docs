title: "google_dialogflow_page"
description: "`google_dialogflow_page` is a single conversational state within a Dialogflow CX flow..."
---

`google_dialogflow_page` is a single conversational state within a Dialogflow CX flow, defining what the agent says and which transition(s) it evaluates based on user input while in that state.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own page"})

    		ubx.Resource(dialogflow.Page, "example", dialogflow.PageConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Page } from "@ubx/sdk-google/google/dialogflow/page";

    export default stack("example", () => {
      intent({ summary: "example own page" });

      resource(Page, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.dialogflow import Page, PageConfig

    def describe():

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

<Warning>
  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_dialogflow_v2beta1_context` holds real, structured parameters (its own parameters map) that persist across a Dialogflow conversation for a limited window (lifespan_count), letting later turns in the same conversation reference values collected earlier without the caller re-sending them on every request.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 context"})

    		ubx.Resource(dialogflow.V2beta1Context, "example", dialogflow.V2beta1ContextConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_test_case`.
</Warning>

`google_dialogflow_v3beta1_test_case` defines a scripted conversation with expected agent response(s), used to automatically verify a Dialogflow agent's own behavior hasn't regressed after a change.

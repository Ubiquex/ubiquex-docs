`google_dialogflow_version` is an immutable, named snapshot of a Dialogflow agent's own configuration at a point in time, deployable to an environment independently of ongoing draft changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own version"})

    		ubx.Resource(dialogflow.Version, "example", dialogflow.VersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<Warning>
  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_dialogflow_v2beta1_document` is a real piece of content (content, content_uri, or raw_content) ingested into a Dialogflow knowledge base, with its own mime_type and knowledge_types describing how it should be used, so an agent can answer from real, curated source material instead of only its own trained model.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dialogflow_v2beta1 --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dialogflow_v2beta1/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dialogflow_v2beta1/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 document"})

    		ubx.Resource(dialogflow.V2beta1DialogflowV2beta1Document, "example", dialogflow.V2beta1DialogflowV2beta1DocumentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

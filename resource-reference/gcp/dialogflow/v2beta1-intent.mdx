`google_dialogflow_v2beta1_intent` maps a category of user input (defined by training phrases) to a specific meaning a Dialogflow agent should recognize and act on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 intent"})

    		ubx.Resource(dialogflow.V2beta1Intent, "example", dialogflow.V2beta1IntentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

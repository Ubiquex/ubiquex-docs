<Warning>
  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_dialogflow_v2beta1_sip_trunk` connects a real SIP telephony trunk to Dialogflow (its own connections, expected_hostname, peer_hostnames, and google_root_cert_file), so phone calls routed through that trunk can reach a Dialogflow conversation rather than needing a separate telephony integration layer.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dialogflow_v2beta1 --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dialogflow_v2beta1/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dialogflow_v2beta1/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 sip trunk"})

    		ubx.Resource(dialogflow.V2beta1DialogflowV2beta1SipTrunk, "example", dialogflow.V2beta1DialogflowV2beta1SipTrunkConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

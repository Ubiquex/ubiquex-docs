<Warning>
  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_dialogflow_v2beta1_participant` is a real participant in a Dialogflow conversation -- human agent, end user, or automated agent (its own role) -- with an obfuscated_external_user_id and documents_metadata_filters scoping what knowledge that participant's own responses may draw from.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 participant"})

    		ubx.Resource(dialogflow.V2beta1Participant, "example", dialogflow.V2beta1ParticipantConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_entity_type`.
</Warning>

`google_dialogflow_v3beta1_entity_type` defines a category of value (e.g. a city name or product SKU) a Dialogflow agent can extract from user input, along with its own synonyms and matching behavior.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v3beta1 entity type"})

    		ubx.Resource(dialogflow.V3beta1EntityType, "example", dialogflow.V3beta1EntityTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

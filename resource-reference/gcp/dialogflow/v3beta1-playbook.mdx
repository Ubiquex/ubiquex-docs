<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_playbook`.
</Warning>

`google_dialogflow_v3beta1_playbook` defines a Dialogflow CX agent's own conversational behavior using natural-language instructions and goals for an LLM to follow, the generative alternative to hand-built flow/page state machines.

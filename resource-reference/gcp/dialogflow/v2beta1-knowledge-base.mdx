  This is Google Cloud's own **v2beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.

`google_dialogflow_v2beta1_knowledge_base` is a real collection of documents (its own display_name and language_code) that a Dialogflow agent can draw answers from, grouping related source material under one resource rather than referencing individual documents ad hoc.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 knowledge base"})

    		ubx.Resource(dialogflow.V2beta1KnowledgeBase, "example", dialogflow.V2beta1KnowledgeBaseConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

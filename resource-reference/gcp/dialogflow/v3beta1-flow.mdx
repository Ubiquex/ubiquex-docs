<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_flow`.
</Warning>

`google_dialogflow_v3beta1_flow` is a self-contained conversational module (a directed graph of page(s) and transition(s)) within a Dialogflow CX agent, typically handling one topic or task.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v3beta1 flow"})

    		ubx.Resource(dialogflow.V3beta1Flow, "example", dialogflow.V3beta1FlowConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

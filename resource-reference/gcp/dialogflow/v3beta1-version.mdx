<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_version`.
</Warning>

`google_dialogflow_v3beta1_version` is an immutable, named snapshot of a Dialogflow agent's own configuration at a point in time, deployable to an environment independently of ongoing draft changes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v3beta1 version"})

    		ubx.Resource(dialogflow.V3beta1Version, "example", dialogflow.V3beta1VersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

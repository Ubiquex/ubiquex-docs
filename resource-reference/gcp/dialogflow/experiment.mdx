`google_dialogflow_experiment` runs an A/B test between two versions of a Dialogflow agent's own flow, routing a portion of live traffic to the variant to measure which performs better.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dialogflow --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dialogflow/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dialogflow/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own experiment"})

    		ubx.Resource(dialogflow.DialogflowExperiment, "ci-runner", dialogflow.DialogflowExperimentConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

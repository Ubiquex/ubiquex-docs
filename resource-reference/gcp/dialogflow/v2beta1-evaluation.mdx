---

`google_dialogflow_v2beta1_evaluation` is a real evaluation run against a Dialogflow generator or conversation flow, recording its own evaluation_status and summarization_metrics against a real generator_evaluation_config, so generator quality can be measured on real data rather than judged only by manual spot-checking.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2beta1 evaluation"})

    		ubx.Resource(dialogflow.V2beta1Evaluation, "example", dialogflow.V2beta1EvaluationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

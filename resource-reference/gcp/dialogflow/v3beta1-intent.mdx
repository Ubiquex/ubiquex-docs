<Warning>
  This is Google Cloud's own **v3beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dialogflow_intent`.
</Warning>

`google_dialogflow_v3beta1_intent` maps a category of user input (defined by training phrases) to a specific meaning a Dialogflow agent should recognize and act on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dialogflow_v3beta1 --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dialogflow_v3beta1/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dialogflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dialogflow_v3beta1/dialogflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v3beta1 intent"})

    		ubx.Resource(dialogflow.V3beta1DialogflowV3beta1Intent, "example", dialogflow.V3beta1DialogflowV3beta1IntentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sourcerepo "github.com/ubiquex/ubx-sdk-google/sdk/go/google/sourcerepo"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own repo"})

    		ubx.Resource(sourcerepo.Repo, "example", sourcerepo.RepoConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="mirror_config" type="object">
  Configuration to automatically mirror a repository from another hosting service, for example GitHub or Bitbucket. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="deploy_key_id" type="string">
      ID of the SSH deploy key at the other hosting service. Removing this key from the other service would deauthorize Google Cloud Source Repositories from mirroring. Optional.
    </ResponseField>
    <ResponseField name="url" type="string">
      URL of the main repository at the other hosting service. Optional.
    </ResponseField>
    <ResponseField name="webhook_id" type="string">
      ID of the webhook listening to updates to trigger mirroring. Removing this webhook from the other hosting service will stop Google Cloud Source Repositories from receiving notifications, and thereby disabling mirroring. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Resource name of the repository, of the form `projects//repos/`. The repo name may contain slashes. eg, `projects/myproject/repos/name/with/slash` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pubsub_configs" type="map(object)">
  How this repository publishes a change in the repository through Cloud Pub/Sub. Keyed by the topic names. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="message_format" type="string">
      The encoding of the Pub/Sub messages this repository publishes on push: `PROTOBUF` (a serialized `SourceRepoEvent` protocol buffer) or `JSON` (the same event as a JSON string). Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="service_account_email" type="string">
      The service account Cloud Source Repositories uses to publish to `topic`. Must be in the same project as this Pub/Sub config and needs `iam.serviceAccounts.actAs` granted to the caller; defaults to the project's Compute Engine default service account when unset. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="topic" type="string">
      The Pub/Sub topic push events are published to, in the form `projects/&#123;project&#125;/topics/&#123;topic&#125;`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="size" type="string">
  The disk usage of the repo, in bytes. Read-only field. Size is only returned by GetRepo. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="url" type="string">
  URL to clone the repository from Google Cloud Source Repositories. Read-only field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

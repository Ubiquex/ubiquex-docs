`google_servicemanagement_rollout` publishes a specific Service Management configuration version live, making it the active configuration serving traffic for a managed API.

## Example

<Tabs>

    ```go
    // ubx sdk gen --only google_servicemanagement --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_servicemanagement/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicemanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google_servicemanagement/servicemanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own rollout"})

    		ubx.Resource(servicemanagement.ServicemanagementRollout, "ci-runner", servicemanagement.ServicemanagementRolloutConfig{})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Creation time of the rollout. Readonly. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="created_by" type="string">
  The user who created the Rollout. Readonly. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_service_strategy" type="any">
  Strategy used to delete a service. This strategy is a placeholder only used by the system generated rollout to delete a service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="rollout_id" type="string">
  Optional. Unique identifier of this Rollout. Must be no longer than 63 characters and only lower case letters, digits, '.', '_' and '-' are allowed. If not specified by client, the server will generate one. The generated id will have the form of , where "date" is the create date in ISO 8601 format. "revision number" is a monotonically increasing positive number that is reset every day for each service. An example of the generated rollout_id is '2016-02-16r1' Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_name" type="string">
  The name of the service associated with this Rollout. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status" type="string">
  The status of this rollout. Readonly. In case of a failed rollout, the system will automatically rollback to the current Rollout version. Readonly. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="traffic_percent_strategy" type="object">

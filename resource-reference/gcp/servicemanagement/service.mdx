`google_servicemanagement_service` registers a managed API with Service Management/Service Infrastructure, the underlying system that Google's own and many third-party Google Cloud APIs (including Endpoints-managed APIs) run on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_servicemanagement --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_servicemanagement/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicemanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google_servicemanagement/servicemanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own service"})

    		ubx.Resource(servicemanagement.ServicemanagementService, "ci-runner", servicemanagement.ServicemanagementServiceConfig{})
    	}))
    }
    ```
  </Tab>

`google_servicemanagement_service` registers a managed API with Service Management/Service Infrastructure, the underlying system that Google's own and many third-party Google Cloud APIs (including Endpoints-managed APIs) run on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicemanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/servicemanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service"})

    		ubx.Resource(servicemanagement.Service, "example", servicemanagement.ServiceConfig{
    			ProducerProjectId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.servicemanagement import Service, ServiceConfig

    def describe():
        ubx.intent("example own service")

        ubx.resource(Service, "example", ServiceConfig(
            producer_project_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="producer_project_id" type="string">
  ID of the project that produces and owns this service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_name" type="string">
  The name of the service. See the [overview](https://cloud.google.com/service-infrastructure/docs/overview) for naming requirements. Optional; if omitted, computed by Google Cloud.
</ResponseField>

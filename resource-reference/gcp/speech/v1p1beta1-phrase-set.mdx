<Warning>
  This is Google Cloud's own **v1p1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_speech_phrase_set`.
</Warning>

`google_speech_v1p1beta1_phrase_set` is a Cloud Speech-to-Text phrase set, a real, reusable collection of phrases and boost values (which can embed `google_speech_custom_class` entries) that hints the recognition model toward expected words and phrases in an audio request.

## Input properties

<ResponseField name="phrase_set" type="object">
  Provides "hints" to the speech recognizer to favor specific words and phrases in the results. Optional.
  <Expandable title="properties">
    <ResponseField name="annotations" type="map(string)">
      Output only. Allows users to store small amounts of arbitrary data. Both the key and the value must be 63 characters or less each. At most 100 annotations. This field is not used. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="boost" type="number">
      Hint Boost. Positive value will increase the probability that a specific phrase will be recognized over other similar sounding phrases. The higher the boost, the higher the chance of false positive recognition as well. Negative boost values would correspond to anti-biasing. Anti-biasing is not enabled, so negative boost will simply be ignored. Though `boost` can accept a wide range of positive values, most use cases are best served with values between 0 (exclusive) and 20. We recommend using a binary search approach to finding the optimal value for your use case as well as adding phrases both with and without boost to your requests. Optional.
    </ResponseField>
    <ResponseField name="delete_time" type="string">
      Output only. The time at which this resource was requested for deletion. This field is not used. Computed by Google Cloud after `ship`.

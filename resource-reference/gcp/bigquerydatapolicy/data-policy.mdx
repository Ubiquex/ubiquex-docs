`google_bigquerydatapolicy_data_policy` applies column-level data masking or access restriction to matching BigQuery table column(s), based on a policy tag classification.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_bigquerydatapolicy --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_bigquerydatapolicy/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	bigquerydatapolicy "github.com/ubiquex/ubx-sdk-google/sdk/go/google_bigquerydatapolicy/bigquerydatapolicy"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own data policy"})

    		ubx.Resource(bigquerydatapolicy.BigquerydatapolicyDataPolicy, "example", bigquerydatapolicy.BigquerydatapolicyDataPolicyConfig{
    			DataPolicy: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="data_policy" type="object">
  Represents the label-policy binding. Optional.
  <Expandable title="properties">
    <ResponseField name="data_governance_tag" type="object">
      This is a namespaced name specifying the key and the value. For example: `project-id/pii/sensitive`. Optional.
      <Expandable title="properties">
        <ResponseField name="key" type="string">
          Optional. Tag keys are globally unique. Tag key is expected to be in the namespaced format, for example `parent-id/pii` where `parent-id` is the ID of the parent organization or project resource for this tag key. Optional.
        </ResponseField>
        <ResponseField name="value" type="string">
          Optional. Specifies the tag value as the short name, for example `sensitive`. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="data_masking_policy" type="object">
      The policy used to specify data masking rule. Optional.
      <Expandable title="properties">
        <ResponseField name="predefined_expression" type="string">
          Optional. A predefined masking expression. Optional.
        </ResponseField>
        <ResponseField name="routine" type="string">
          Optional. The name of the BigQuery routine that contains the custom masking routine, in the format of `projects/&#123;project_number&#125;/datasets/&#123;dataset_id&#125;/routines/&#123;routine_id&#125;`. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="data_policy_id" type="string">
      Output only. User-assigned (human readable) ID of the data policy that needs to be unique within a project. Used as &#123;data_policy_id&#125; in part of the resource name. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="data_policy_type" type="string">
      Required. Type of data policy. Optional.
    </ResponseField>
    <ResponseField name="etag" type="string">
      The etag for this Data Policy. This field is used for UpdateDataPolicy calls. If Data Policy exists, this field is required and must match the server's etag. It will also be populated in the response of GetDataPolicy, CreateDataPolicy, and UpdateDataPolicy calls. Optional.
    </ResponseField>
    <ResponseField name="grantees" type="list(string)">
      Optional. The list of IAM principals that have Fine Grained Access to the underlying data goverened by this data policy. Uses the [IAM V2 principal syntax](https://cloud.google.com/iam/docs/principal-identifiers#v2) Only supports principal types users, groups, serviceaccounts, cloudidentity. This field is supported in V2 Data Policy only. In case of V1 data policies (i.e. verion = 1 and policy_tag is set), this field is not populated. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      Identifier. Resource name of this data policy, in the format of `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/dataPolicies/&#123;data_policy_id&#125;`. Optional.
    </ResponseField>
    <ResponseField name="policy_tag" type="string">
      Output only. Policy tag resource name, in the format of `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/taxonomies/&#123;taxonomy_id&#125;/policyTags/&#123;policyTag_id&#125;`. policy_tag is supported only for V1 data policies. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="version" type="string">
      Output only. The version of the Data Policy resource. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

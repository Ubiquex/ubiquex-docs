---
title: "google_firebasedatabase_instance"
description: "`google_firebasedatabase_instance` is a real Firebase Realtime Database instance."
---

Every project gets one default instance it can't delete; projects on the Blaze plan can create additional instances to scale beyond a single database's limits or isolate workloads.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firebasedatabase --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firebasedatabase/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebasedatabase "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firebasedatabase/firebasedatabase"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own instance"})

    		ubx.Resource(firebasedatabase.FirebasedatabaseInstance, "example", firebasedatabase.FirebasedatabaseInstanceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="database_url" type="string">
  Output only. Output Only. The globally unique hostname of the database. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The fully qualified resource name of the database instance, in the form: `projects/&#123;project-number&#125;/locations/&#123;location-id&#125;/instances/&#123;database-id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="project" type="string">
  Output only. The resource name of the project this instance belongs to. For example: `projects/&#123;project-number&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The database's lifecycle state. Read-only. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Immutable. The database instance type. On creation only USER_DATABASE is allowed, which is also the default when omitted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

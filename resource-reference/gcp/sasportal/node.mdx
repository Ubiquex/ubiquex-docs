`google_sasportal_node` is an organizational node in the Google SAS Portal's real device hierarchy, used alongside deployments to structure how CBRS devices and access are managed at scale.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_sasportal --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_sasportal/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sasportal "github.com/ubiquex/ubx-sdk-google/sdk/go/google_sasportal/sasportal"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own node"})

    		ubx.Resource(sasportal.SasportalNode, "example", sasportal.SasportalNodeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

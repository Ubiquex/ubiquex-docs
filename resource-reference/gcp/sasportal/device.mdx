`google_sasportal_device` is a real Citizens Broadband Radio Service Device (CBSD) registered and managed through the Google SAS Portal, requiring installation by a Certified Professional Installer before it's authorized to transmit on CBRS spectrum.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sasportal "github.com/ubiquex/ubx-sdk-google/sdk/go/google/sasportal"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own device"})

    		ubx.Resource(sasportal.Device, "example", sasportal.DeviceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

    <ResponseField name="installation_params" type="object">
      Information about the device installation parameters. Optional.
      <Expandable title="properties">
        <ResponseField name="antenna_azimuth" type="number">
          Boresight direction of the horizontal plane of the antenna in degrees with respect to true north. The value of this parameter is an integer with a value between 0 and 359 inclusive. A value of 0 degrees means true north; a value of 90 degrees means east. This parameter is optional for Category A devices and conditional for Category B devices. Optional.
        </ResponseField>
        <ResponseField name="antenna_beamwidth" type="number">
          3-dB antenna beamwidth of the antenna in the horizontal-plane in degrees. This parameter is an unsigned integer having a value between 0 and 360 (degrees) inclusive; it is optional for Category A devices and conditional for Category B devices. Optional.
        </ResponseField>
        <ResponseField name="antenna_downtilt" type="number">
          Antenna downtilt in degrees and is an integer with a value between -90 and +90 inclusive; a negative value means the antenna is tilted up (above horizontal). This parameter is optional for Category A devices and conditional for Category B devices. Optional.
        </ResponseField>
        <ResponseField name="antenna_gain" type="number">
          Peak antenna gain in dBi. This parameter is a double with a value between -127 and +128 (dBi) inclusive. Part of Release 2 to support floating-point value Optional.
        </ResponseField>
        <ResponseField name="antenna_model" type="string">
          If an external antenna is used, the antenna model is optionally provided in this field. The string has a maximum length of 128 octets. Optional.
        </ResponseField>
        <ResponseField name="cpe_cbsd_indication" type="bool">
          If present, this parameter specifies whether the CBSD is a CPE-CBSD or not. Optional.
        </ResponseField>
        <ResponseField name="eirp_capability" type="number">
          This parameter is the maximum device EIRP in units of dBm/10MHz and is an integer with a value between -127 and +47 (dBm/10 MHz) inclusive. If not included, SAS interprets it as maximum allowable EIRP in units of dBm/10MHz for device category. Optional.
        </ResponseField>
        <ResponseField name="height" type="number">
          Device antenna height in meters. When the `heightType` parameter value is "AGL", the antenna height should be given relative to ground level. When the `heightType` parameter value is "AMSL", it is given with respect to WGS84 datum. Optional.
        </ResponseField>
        <ResponseField name="height_type" type="string">
          Specifies how the height is measured. Optional.
        </ResponseField>
        <ResponseField name="horizontal_accuracy" type="number">
          A positive number in meters to indicate accuracy of the device antenna horizontal location. This optional parameter should only be present if its value is less than the FCC requirement of 50 meters. Optional.
        </ResponseField>
        <ResponseField name="indoor_deployment" type="bool">
          Whether the device antenna is indoor or not. `true`: indoor. `false`: outdoor. Optional.
        </ResponseField>
        <ResponseField name="latitude" type="number">
          Latitude of the device antenna location in degrees relative to the WGS 84 datum. The allowed range is from -90.000000 to +90.000000. Positive values represent latitudes north of the equator; negative values south of the equator. Optional.
        </ResponseField>
        <ResponseField name="longitude" type="number">
          Longitude of the device antenna location in degrees relative to the WGS 84 datum. The allowed range is from -180.000000 to +180.000000. Positive values represent longitudes east of the prime meridian; negative values west of the prime meridian. Optional.
        </ResponseField>
        <ResponseField name="vertical_accuracy" type="number">
          A positive number in meters to indicate accuracy of the device antenna vertical location. This optional parameter should only be present if its value is less than the FCC requirement of 3 meters. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>

`google_sasportal_deployment` is a real organizational grouping of CBRS devices in the Google SAS Portal (Spectrum Access System), identified by a unique user ID; a SAS organization can contain multiple deployments, each typically holding multiple `google_sasportal_device` entries.

## Example

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own deployment"})

    		ubx.Resource(sasportal.Deployment, "example", sasportal.DeploymentConfig{
    			Name: "example",
    		})
    	}))
    }

## Properties

<ResponseField name="display_name" type="string">
  The deployment's display name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="frns" type="list(string)">
  Output only. The FCC Registration Numbers (FRNs) copied from its direct parent. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Resource name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sas_user_ids" type="list(string)">
  User ID used by the devices belonging to this deployment. Each deployment should be associated with one unique user ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

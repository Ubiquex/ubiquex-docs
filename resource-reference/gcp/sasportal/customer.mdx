`google_sasportal_customer` is an organization onboarded to the Google SAS Portal (Spectrum Access System), the top-level account CBRS deployments and devices are managed underneath.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sasportal "github.com/ubiquex/ubx-sdk-google/sdk/go/google/sasportal"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own customer"})

    		ubx.Resource(sasportal.Customer, "example", sasportal.CustomerConfig{
    			NewDeploymentDisplayName:   "example-new-deployment-display-name",
    			NewOrganizationDisplayName: "example-new-organization-display-name",
    			OrganizationId:             "example",
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="new_deployment_display_name" type="string">
  Optional. If this field is set, and a new SAS Portal Deployment needs to be created, its display name will be set to the value of this field. Optional.
</ResponseField>

<ResponseField name="new_organization_display_name" type="string">
  Optional. If this field is set, and a new SAS Portal Organization needs to be created, its display name will be set to the value of this field. Optional.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Optional. If this field is set then a new deployment will be created under the organization specified by this id. Optional.
</ResponseField>

## Output properties

<ResponseField name="display_name" type="string">
  Required. Name of the organization that the customer entity represents. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Resource name of the customer. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="sas_user_ids" type="list(string)">
  User IDs used by the devices belonging to this customer. Computed by Google Cloud after `ship`.
</ResponseField>

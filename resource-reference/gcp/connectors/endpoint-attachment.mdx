`google_connectors_endpoint_attachment` is a Private Service Connect endpoint Integration Connectors uses to privately reach a backend that isn't exposed to the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	connectors "github.com/ubiquex/ubx-sdk-google/sdk/go/google/connectors"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint attachment"})

    		ubx.Resource(connectors.EndpointAttachment, "example", connectors.EndpointAttachmentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

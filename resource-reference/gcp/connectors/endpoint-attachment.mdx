`google_connectors_endpoint_attachment` is a Private Service Connect endpoint Integration Connectors uses to privately reach a backend that isn't exposed to the public internet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_connectors --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_connectors/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	connectors "github.com/ubiquex/ubx-sdk-google/sdk/go/google_connectors/connectors"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own endpoint attachment"})

    		ubx.Resource(connectors.ConnectorsEndpointAttachment, "ci-runner", connectors.ConnectorsEndpointAttachmentConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_connectors --lang ts --out ./local-sdk
    ```

`google_connectors_connection` is an Integration Connectors connection, a managed link to a third-party or Google Cloud system (e.g. Salesforce, BigQuery, a JDBC database) that other services like Application Integration and Apigee can invoke without hand-building the underlying API client.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	connectors "github.com/ubiquex/ubx-sdk-google/sdk/go/google/connectors"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connection"})

    		ubx.Resource(connectors.Connection, "example", connectors.ConnectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

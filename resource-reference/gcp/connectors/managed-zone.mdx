`google_connectors_managed_zone` is a private DNS zone Integration Connectors uses to resolve a backend's own hostname when connecting over a private network path.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	connectors "github.com/ubiquex/ubx-sdk-google/sdk/go/google/connectors"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own managed zone"})

    		ubx.Resource(connectors.ManagedZone, "example", connectors.ManagedZoneConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

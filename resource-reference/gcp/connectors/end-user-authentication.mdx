`google_connectors_end_user_authentication` configures per-end-user OAuth credentials for a connection used in an end-user authentication (rather than a single shared service-account) flow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	connectors "github.com/ubiquex/ubx-sdk-google/sdk/go/google/connectors"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own end user authentication"})

    		ubx.Resource(connectors.EndUserAuthentication, "example", connectors.EndUserAuthenticationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_alloydb_cluster`.

`google_alloydb_v1beta_cluster` is the top-level AlloyDB resource, a PostgreSQL-compatible database cluster that primary and read pool instance(s) belong to.

<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_alloydb_v1alpha_endpoint` is a real network access endpoint for one or more AlloyDB instances -- its own endpoint_type and dns_config, with target_instances/effective_target_instances recording which instances it currently routes to -- so connectivity can be managed as its own resource rather than a fixed property of a single instance.

`google_recaptchaenterprise_key` registers a site or app with reCAPTCHA Enterprise, the credential used to request and validate risk assessment(s) for its own traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	recaptchaenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/recaptchaenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key"})

    		ubx.Resource(recaptchaenterprise.Key, "example", recaptchaenterprise.KeyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

`google_recaptchaenterprise_firewallpolicy` defines a rule reCAPTCHA Enterprise's WAF integration applies to matching request(s), e.g. blocking traffic below a risk-score threshold.

## Properties

<ResponseField name="actions" type="list(object)">
  Optional. The actions that the caller should take regarding user access. There should be at most one terminal action. A terminal action is any action that forces a response, such as `AllowAction`, `BlockAction` or `SubstituteAction`. Zero or more non-terminal actions such as `SetHeader` might be specified. A single policy can contain up to 16 actions. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="allow" type="any">
      Lets the matching request through unmodified. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="block" type="any">
      Blocks the matching request outright. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="include_recaptcha_script" type="any">
      Injects the reCAPTCHA client-side script into the matching response, without otherwise altering it. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="redirect" type="any">
      Redirects the matching request to reCAPTCHA's own interstitial challenge page. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="set_header" type="object">
      Adds or overwrites a header on the matching request before forwarding it. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="key" type="string">

    </ResponseField>
  </Expandable>

<ResponseField name="condition" type="string">
  Optional. A CEL (Common Expression Language) conditional expression that specifies if this policy applies to an incoming user request. If this condition evaluates to true and the requested path matched the path pattern, the associated actions should be executed by the caller. The condition string is checked for CEL syntax correctness on creation. For more information, see the [CEL spec](https://github.com/google/cel-spec) and its [language definition](https://github.com/google/cel-spec/blob/master/doc/langdef.md). A condition has a max length of 500 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of what this policy aims to achieve, for convenience purposes. The description can at most include 256 UTF-8 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name for the FirewallPolicy in the format `projects/&#123;project&#125;/firewallpolicies/&#123;firewallpolicy&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="path" type="string">
  Optional. The path for which this policy applies, specified as a glob pattern. For more information on glob, see the [manual page](https://man7.org/linux/man-pages/man7/glob.7.html). A path has a max length of 200 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

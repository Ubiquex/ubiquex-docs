`google_securityposture_report` is a Security Command Center report of infrastructure-as-code resources that violate an organization's own defined security posture, generated by validating a Terraform plan or similar declarative configuration ahead of deployment rather than after the fact.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securityposture --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securityposture/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securityposture "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securityposture/securityposture"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own report"})

    		ubx.Resource(securityposture.SecuritypostureReport, "ci-runner", securityposture.SecuritypostureReportConfig{
    			Iac: map[string]any{"tf_plan": "example"},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="iac" type="object">
  Details of an infrastructure-as-code (IaC) configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="tf_plan" type="string">
      Optional. A Terraform plan file, formatted as a stringified JSON object. To learn how to generate a Terraform plan file in JSON format, see [JSON output format](https://developer.hashicorp.com/terraform/internals/json-format) in the Terraform documentation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the report was created. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="iac_validation_report" type="object">
  Details of an infrastructure-as-code (IaC) validation report. Computed by Google Cloud after `ship`.
  <Expandable title="properties">
    <ResponseField name="note" type="string">
      Additional information about the report. Optional.
    </ResponseField>
    <ResponseField name="violations" type="list(object)">
      A list of every Violation found in the IaC configuration. Optional.
      <Expandable title="properties">
        <ResponseField name="asset_id" type="string">
          A reference to the specific infrastructure-as-code resource this violation was found in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="next_steps" type="string">
          Guidance for resolving this violation. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="policy_id" type="string">
          A reference to the policy this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="severity" type="string">
          How serious this finding is. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="violated_asset" type="object">
          The specific resource, as declared in the infrastructure-as-code source, that violates this policy. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="asset" type="string">
              A reference to the violating resource itself. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="asset_type" type="string">
              The type of the violating resource. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="violated_policy" type="object">
          The specific policy constraint that was violated. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="compliance_standards" type="list(string)">
              The compliance standard(s) (and their own control IDs) this policy maps to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="constraint" type="string">
              A reference to the constraint this policy enforces. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="constraint_type" type="string">
              The kind of constraint that was violated. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="description" type="string">
              A human-readable explanation of this schema's own meaning and intended use. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="violated_posture" type="object">
          The security posture (and its own deployment) this violation was found against. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="policy_set" type="string">
              The named group of policies this posture's own constraint belongs to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="posture" type="string">
              A reference to the security posture this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="posture_deployment" type="string">
              A reference to the specific deployment of this posture this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="posture_deployment_target_resource" type="string">
              The resource this posture deployment's own policies are enforced against. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="posture_revision_id" type="string">
              The specific revision of the posture this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Required. The name of the report, in the format `organizations/&#123;organization&#125;/locations/global/reports/&#123;report_id&#125;`. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the report was last updated. Computed by Google Cloud after `ship`.
</ResponseField>

`google_securityposture_posture_deployment` applies a specific Security Posture posture version to a target organization, folder, or project, activating its own bundled policy and detector configuration there.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securityposture --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securityposture/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securityposture "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securityposture/securityposture"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own posture deployment"})

    		ubx.Resource(securityposture.SecurityposturePostureDeployment, "example", securityposture.SecurityposturePostureDeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="annotations" type="map(string)">
  Optional. The user-specified annotations for the posture deployment. For details about the values you can use in an annotation, see [AIP-148: Standard fields](https://google.aip.dev/148#annotations). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="categories" type="list(string)">
  Output only. The categories that the posture deployment belongs to, as determined by the Security Posture API. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the posture deployment was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of the posture deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="desired_posture_id" type="string">
  Output only. The posture ID that was specified for the deployment. Present only if the posture deployment is in a failed state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="desired_posture_revision_id" type="string">
  Output only. The revision ID of the posture that was specified for the deployment. Present only if the deployment is in a failed state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. An opaque identifier for the current version of the posture deployment. To prevent concurrent updates from overwriting each other, always provide the `etag` when you update a posture deployment. You can also provide the `etag` when you delete a posture deployment, to help ensure that you're deleting the intended posture deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="failure_message" type="string">
  Output only. A description of why the posture deployment failed. Present only if the deployment is in a failed state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Identifier. The name of the posture deployment, in the format `organizations/&#123;organization&#125;/locations/global/postureDeployments/&#123;deployment_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="posture_id" type="string">
  Required. The posture used in the deployment, in the format `organizations/&#123;organization&#125;/locations/global/postures/&#123;posture_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="posture_revision_id" type="string">
  Required. The revision ID of the posture used in the deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reconciling" type="bool">
  Output only. Whether the posture deployment is in the process of being updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the posture deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_resource" type="string">
  Required. The organization, folder, or project where the posture is deployed. Uses one of the following formats: * `organizations/&#123;organization_number&#125;` * `folders/&#123;folder_number&#125;` * `projects/&#123;project_number&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the posture deployment was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

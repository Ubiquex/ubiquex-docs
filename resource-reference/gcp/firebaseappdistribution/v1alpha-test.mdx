<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_firebaseappdistribution_v1alpha_test` is a real, automated test run against a distributed app build -- its own login_credential, ai_instructions, and results_bucket, tracking device_executions and its own test_state -- optionally driven by a real test_case, so app testing before distribution can be automated rather than performed manually on each release.

`google_firebaseappdistribution_group` is a tester group in Firebase App Distribution, used to manage access to pre-release app builds for many testers at once. Adding or removing a tester from the group grants or revokes their access to every release distributed to it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firebaseappdistribution --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firebaseappdistribution/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebaseappdistribution "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firebaseappdistribution/firebaseappdistribution"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own group"})

    		ubx.Resource(firebaseappdistribution.FirebaseappdistributionGroup, "ci-runner", firebaseappdistribution.FirebaseappdistributionGroupConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

</ResponseField>

  The name of the group resource. Format: `projects/&#123;project_number&#125;/groups/&#123;group_alias&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="release_count" type="number">
  Output only. The number of releases this group is permitted to access. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tester_count" type="number">
  Output only. The number of testers who are members of this group. Optional; if omitted, computed by Google Cloud.

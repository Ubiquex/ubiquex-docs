`google_firebaseappdistribution_v1alpha_test_case` is a real, reusable test case (its own ai_instructions) that a test run can execute, with dependent_test_cases and prerequisite_test_case declaring real ordering constraints, so a suite of related test cases can be composed and sequenced rather than run independently.

`google_bigqueryconnection_connection` defines credentials and configuration BigQuery uses to query an external data source (Cloud SQL, Spanner, or a remote function endpoint) via a federated query or connection.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	bigqueryconnection "github.com/ubiquex/ubx-sdk-google/sdk/go/google/bigqueryconnection"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connection"})

    		ubx.Resource(bigqueryconnection.Connection, "example", bigqueryconnection.ConnectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="cloud_resource" type="object">
  Container for connection properties for delegation of access to GCP resources. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="service_account_id" type="string">
      Output only. The account ID of the service created for the purpose of this connection. The service account does not have any permissions associated with it when it is created. After creation, customers delegate permissions to the service account. When the connection is used in the context of an operation in BigQuery, the service account will be used to connect to the desired resources in GCP. The account ID is in the form of: @gcp-sa-bigquery-cloudresource.iam.gserviceaccount.com Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cloud_spanner" type="object">
  Connection properties specific to Cloud Spanner. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="database" type="string">
      Cloud Spanner database in the form `project/instance/database' Optional.
    </ResponseField>
    <ResponseField name="database_role" type="string">
      Optional. Cloud Spanner database role for fine-grained access control. The Cloud Spanner admin should have provisioned the database role with appropriate permissions, such as `SELECT` and `INSERT`. Other users should only use roles provided by their Cloud Spanner admins. For more details, see [About fine-grained access control] (https://cloud.google.com/spanner/docs/fgac-about). REQUIRES: The database role name must start with a letter, and can only contain letters, numbers, and underscores. Optional.
    </ResponseField>
    <ResponseField name="max_parallelism" type="number">
      Allows setting max parallelism per query when executing on Spanner independent compute resources. If unspecified, default values of parallelism are chosen that are dependent on the Cloud Spanner instance configuration. REQUIRES: `use_parallelism` must be set. REQUIRES: `use_data_boost` must be set. Optional.
    </ResponseField>
    <ResponseField name="use_data_boost" type="bool">
      If set, the request will be executed via Spanner independent compute resources. REQUIRES: `use_parallelism` must be set. Optional.
    </ResponseField>
    <ResponseField name="use_parallelism" type="bool">
      If parallelism should be used when reading from Cloud Spanner Optional.
    </ResponseField>
    <ResponseField name="use_serverless_analytics" type="bool">
      Deprecated: prefer use_data_boost instead. If the serverless analytics service should be used to read data from Cloud Spanner. Note: `use_parallelism` must be set when using serverless analytics. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

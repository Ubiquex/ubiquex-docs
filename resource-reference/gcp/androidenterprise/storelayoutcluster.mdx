`google_androidenterprise_storelayoutcluster` is a cluster of apps within a custom managed Google Play store page for an Android Enterprise, one of the building blocks (alongside `google_androidenterprise_storelayoutpage`) used to organize which approved apps end users see and how.

## Properties

<ResponseField name="id" type="string">
  Unique ID of this cluster. Assigned by the server. Immutable once assigned. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="list(object)">
  Ordered list of localized strings giving the name of this page. The text displayed is the one that best matches the user locale, or the first entry if there is no good match. There needs to be at least one entry. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="locale" type="string">
      The real BCP-47 locale this store layout cluster's own localized `name` is written in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="text" type="string">
      The real, localized display text for this store layout cluster's own name, in the paired `locale`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="order_in_page" type="string">
  String (US-ASCII only) used to determine order of this cluster within the parent page's elements. Page elements are sorted in lexicographic order of this field. Duplicated values are allowed, but ordering between elements with duplicate order is undefined. The value of this field is never visible to a user, it is used solely for the purpose of defining an ordering. Maximum length is 256 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="product_id" type="list(string)">
  List of products in the order they are displayed in the cluster. There should not be duplicates within a cluster. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_androidenterprise_webapp` is a web app published to an Android Enterprise's managed Google Play store, letting an EMM distribute a URL-based application to enrolled devices the same way it distributes native APKs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/androidenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own webapp"})

    		ubx.Resource(androidenterprise.Webapp, "example", androidenterprise.WebappConfig{
    			DisplayMode: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="display_mode" type="string">
  The display mode of the web app. Possible values include: - "minimalUi", the device's status bar, navigation bar, the app's URL, and a refresh button are visible when the app is open. For HTTP URLs, you can only select this option. - "standalone", the device's status bar and navigation bar are visible when the app is open. - "fullScreen", the app opens in full screen mode, hiding the device's status and navigation bars. All browser UI elements, page URL, system status bar and back button are not visible, and the web app takes up the entirety of the available display area. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="icons" type="list(object)">
  A list of icons representing this website. If absent, a default icon (for create) or the current icon (for update) will be used. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="image_data" type="string">
      The real, base64-encoded image bytes for this web app's own icon. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="is_published" type="bool">
  A flag whether the app has been published to the Play store yet. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_url" type="string">
  The start URL, i.e. the URL that should load when the user opens the application. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="title" type="string">
  The title of the web app as displayed to the user (e.g., amongst a list of other applications, or as a label for an icon). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version_code" type="string">
  The current version of the app. Note that the version can automatically increase during the lifetime of the web app, while Google does internal housekeeping to keep the web app up-to-date. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="web_app_id" type="string">
  The ID of the application. A string of the form "app:&lt;package name&gt;" where the package name always starts with the prefix "com.google.enterprise.webapp." followed by a random id. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_androidenterprise_user` is a managed user account within an Android Enterprise, provisioned through the Google Play EMM API so an EMM can grant that person access to the enterprise's approved app catalog.

## Properties

<ResponseField name="account_identifier" type="string">
  A unique identifier you create for this user, such as "user342" or "asset#44418". Do not use personally identifiable information (PII) for this property. Must always be set for EMM-managed users. Not set for Google-managed users. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="account_type" type="string">
  The type of account that this user represents. A userAccount can be installed on multiple devices, but a deviceAccount is specific to a single device. An EMM-managed user (emmManaged) can be either type (userAccount, deviceAccount), but a Google-managed user (googleManaged) is always a userAccount. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The name that will appear in user interfaces. Setting this property is optional when creating EMM-managed users. If you do set this property, use something generic about the organization (such as "Example, Inc.") or your name (as EMM). Not used for Google-managed user accounts. @mutable androidenterprise.users.update Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  The unique ID for the user. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="management_type" type="string">
  The entity that manages the user. With googleManaged users, the source of truth is Google so EMMs have to make sure a Google Account exists for the user. With emmManaged users, the EMM is in charge. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="primary_email" type="string">
  The user's primary email address, for example, "jsmith@example.com". Will always be set for Google managed users and not set for EMM managed users. Optional; if omitted, computed by Google Cloud.
</ResponseField>

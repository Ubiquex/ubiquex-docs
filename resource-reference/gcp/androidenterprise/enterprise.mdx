`google_androidenterprise_enterprise` represents a real, bound Android Enterprise (managed Google Play) organization under the Google Play EMM API, the top-level resource every store layout, user, and web app in the enterprise is scoped underneath.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/androidenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own enterprise"})

    		ubx.Resource(androidenterprise.Enterprise, "example", androidenterprise.EnterpriseConfig{
    			ManagedConfigurations: map[string]any{"enabled": true},
    			Parent:                "example",
    			Permission:            []string{"example"},
    			PlaySearch:            map[string]any{"approve_apps": true},
    			PrivateApps:           map[string]any{"enabled": true},
    			StoreBuilder:          map[string]any{"enabled": true},
    			WebApps:               map[string]any{"enabled": true},
    			ZeroTouch:             map[string]any{"enabled": true},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="managed_configurations" type="object">
  Real settings controlling whether this enterprise supports app-level managed configurations. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Whether the Managed Configuration page is displayed. Default is true. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="parent" type="string">
  The URI of the parent frame hosting the iframe. To prevent XSS, the iframe may not be hosted at other URIs. This URI must be https. Use whitespaces to separate multiple parent URIs. Optional.
</ResponseField>

<ResponseField name="permission" type="list(string)">
  Deprecated. Use PlaySearch.approveApps. Optional.
</ResponseField>

<ResponseField name="play_search" type="object">
  Real settings controlling whether users in this enterprise can search all of Google Play, not just the approved catalog. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="approve_apps" type="bool">
      Allow access to the iframe in approve mode. Default is false. Optional.
    </ResponseField>
    <ResponseField name="enabled" type="bool">
      Whether the managed Play Search apps page is displayed. Default is true. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="private_apps" type="object">
  Real settings controlling whether this enterprise can publish private, org-internal apps to its own managed Google Play store. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Whether the Private Apps page is displayed. Default is true. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="store_builder" type="object">
  Real settings controlling whether this enterprise's own managed Google Play store can be customized via the Store Layout APIs. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Whether the Organize apps page is displayed. Default is true. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="web_apps" type="object">
  Real settings controlling whether this enterprise supports publishing web apps to its own managed Google Play store. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Whether the Web Apps page is displayed. Default is true. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="zero_touch" type="object">
  Real settings controlling whether this enterprise supports Android zero-touch enrollment. Optional. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="enabled" type="bool">
      Whether zero-touch embedded UI is usable with this token. If enabled, the admin can link zero-touch customers to this enterprise. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

## Output properties

<ResponseField name="administrator" type="list(object)">
  Admins of the enterprise. This is only supported for enterprises created via the EMM-initiated flow. Computed by Google Cloud after `ship`.
  <Expandable title="properties">
    <ResponseField name="email" type="string">
      The real email address of this enterprise's own designated administrator. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="enterprise_type" type="string">
  The type of the enterprise. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="google_authentication_settings" type="object">
  Contains settings for Google-provided user authentication. Computed by Google Cloud after `ship`.
  <Expandable title="properties">
    <ResponseField name="google_authentication_required" type="string">
      Whether Google authentication is required. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="id" type="string">
  The unique ID for the enterprise. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="managed_google_domain_type" type="string">
  The type of managed Google domain Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the enterprise, for example, "Example, Inc". Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="primary_domain" type="string">
  The enterprise's primary domain, such as "example.com". Computed by Google Cloud after `ship`.
</ResponseField>

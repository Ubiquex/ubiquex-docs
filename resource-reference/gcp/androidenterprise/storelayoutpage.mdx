`google_androidenterprise_storelayoutpage` is a single page of an Android Enterprise's custom managed Google Play store, holding up to 30 `google_androidenterprise_storelayoutcluster` clusters; a store can have up to 100 pages.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

## Properties

<ResponseField name="id" type="string">
  Unique ID of this page. Assigned by the server. Immutable once assigned. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="link" type="list(string)">
  Ordered list of pages a user should be able to reach from this page. The list can't include this page. It is recommended that the basic pages are created first, before adding the links between pages. The API doesn't verify that the pages exist or the pages are reachable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="list(object)">
  Ordered list of localized strings giving the name of this page. The text displayed is the one that best matches the user locale, or the first entry if there is no good match. There needs to be at least one entry. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="locale" type="string">
      The real BCP-47 locale this store layout cluster's own localized `name` is written in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="text" type="string">
      The real, localized display text for this store layout cluster's own name, in the paired `locale`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`google_cloudcontrolspartner_customer` represents a Sovereign Controls by Partners customer relationship, giving a sovereignty partner real, read visibility into that customer's own Assured Workloads (onboarding status, workload metadata) without granting control over the workload itself.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudcontrolspartner "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudcontrolspartner"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own customer"})

    		ubx.Resource(cloudcontrolspartner.Customer, "example", cloudcontrolspartner.CustomerConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="customer_onboarding_state" type="object">
  Container for customer onboarding steps Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="onboarding_steps" type="list(object)">
      List of customer onboarding steps Optional.
      <Expandable title="properties">
        <ResponseField name="completion_state" type="string">
          The real, current completion status (`PENDING`, `SUCCEEDED`, `FAILED`, `NOT_APPLICABLE`) of this customer onboarding step. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="completion_time" type="string">
          The real timestamp when this customer onboarding step completed, if it has. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="start_time" type="string">
          The real timestamp when this customer onboarding step started. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="step" type="string">
          The real, specific onboarding step (`KAJ_ENROLLMENT` or `CUSTOMER_ENVIRONMENT`) this status entry describes. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Display name for the customer Optional; if omitted, computed by Google Cloud.
</ResponseField>

  Output only. Indicates whether a customer is fully onboarded Optional; if omitted, computed by Google Cloud.

  Identifier. Format: `organizations/&#123;organization&#125;/locations/&#123;location&#125;/customers/&#123;customer&#125;` Optional; if omitted, computed by Google Cloud.

<ResponseField name="organization_domain" type="string">
  Output only. The customer organization domain, extracted from CRM Organization’s display_name field. e.g. "google.com" Optional; if omitted, computed by Google Cloud.
</ResponseField>

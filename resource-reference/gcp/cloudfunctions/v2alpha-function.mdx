`google_cloudfunctions_v2alpha_function` is a Cloud Function, a single-purpose piece of code deployed to run in response to an HTTP request or an event trigger.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudfunctions "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudfunctions"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v2alpha function"})

    		ubx.Resource(cloudfunctions.V2alphaFunction, "example", cloudfunctions.V2alphaFunctionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

`google_compute_https_health_check` is the legacy HTTPS counterpart to the original HTTP health check, used the same way by target pools and network load balancers rather than the newer, general health check resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own https health check"})

    		ubx.Resource(compute.HttpsHealthCheck, "example", compute.HttpsHealthCheckConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="check_interval_sec" type="number">
  How often (in seconds) to send a health check. The default value is 5 seconds. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="creation_timestamp" type="string">
  [Output Only] Creation timestamp inRFC3339 text format. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of this resource. Provide this property when you create the resource. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="healthy_threshold" type="number">
  A so-far unhealthy instance will be marked healthy after this many consecutive successes. The default value is 2. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="host" type="string">
  The value of the host header in the HTTPS health check request. If left empty (default value), the public IP on behalf of which this health check is performed will be used. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="id" type="string">
  [Output Only] The unique identifier for the resource. This identifier is defined by the server. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="kind" type="string">
  Output only. Type of the resource. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the resource. Provided by the client when the resource is created. The name must be 1-63 characters long, and comply withRFC1035. Specifically, the name must be 1-63 characters long and match the regular expression `[a-z]([-a-z0-9]*[a-z0-9])?` which means the first character must be a lowercase letter, and all following characters must be a dash, lowercase letter, or digit, except the last character, which cannot be a dash. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="port" type="number">
  The TCP port number for the HTTPS health check request. The default value is 443. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="request_path" type="string">
  The request path of the HTTPS health check request. The default value is "/". Must comply withRFC3986. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="self_link" type="string">
  [Output Only] Server-defined URL for the resource. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="timeout_sec" type="number">
  How long (in seconds) to wait before claiming failure. The default value is 5 seconds. It is invalid for timeoutSec to have a greater value than checkIntervalSec. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="unhealthy_threshold" type="number">
  A so-far healthy instance will be marked unhealthy after this many consecutive failures. The default value is 2. Optional; if omitted, computed by GCP.
</ResponseField>

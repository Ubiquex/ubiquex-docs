<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_instance`.
</Warning>

`google_compute_beta_instance` is a real, running virtual machine in Compute Engine -- its machine type, boot disk, network interfaces, and metadata all defined here, the core compute resource everything else in this reference ultimately supports.

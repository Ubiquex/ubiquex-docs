<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_http_health_check`.
</Warning>

`google_compute_beta_http_health_check` is the original, legacy HTTP health check type used specifically by target pools and network load balancers -- superseded for newer load balancer types by the general, protocol-agnostic health check resource, but still real, live API surface for the older ones.

<ResponseField name="check_interval_sec" type="number">

</ResponseField>

<ResponseField name="creation_timestamp" type="string">
  [Output Only] Creation timestamp inRFC3339 text format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of this resource. Provide this property when you create the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="healthy_threshold" type="number">
  A so-far unhealthy instance will be marked healthy after this many consecutive successes. The default value is 2. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="host" type="string">
  The value of the host header in the HTTP health check request. If left empty (default value), the public IP on behalf of which this health check is performed will be used. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  [Output Only] The unique identifier for the resource. This identifier is defined by the server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  Output only. [Output Only] Type of the resource. Alwayscompute#httpHealthCheck for HTTP health checks. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the resource. Provided by the client when the resource is created. The name must be 1-63 characters long, and comply withRFC1035. Specifically, the name must be 1-63 characters long and match the regular expression `[a-z]([-a-z0-9]*[a-z0-9])?` which means the first character must be a lowercase letter, and all following characters must be a dash, lowercase letter, or digit, except the last character, which cannot be a dash. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="port" type="number">
  The TCP port number for the HTTP health check request. The default value is80. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="request_path" type="string">
  The request path of the HTTP health check request. The default value is/. This field does not support query parameters. Must comply withRFC3986. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self_link" type="string">
  [Output Only] Server-defined URL for the resource. Optional; if omitted, computed by Google Cloud.

<ResponseField name="timeout_sec" type="number">

<ResponseField name="unhealthy_threshold" type="number">

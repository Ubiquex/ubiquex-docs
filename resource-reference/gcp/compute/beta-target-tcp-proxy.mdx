<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_target_tcp_proxy`.
</Warning>

`google_compute_beta_target_tcp_proxy` proxies real TCP traffic straight through to a backend service without terminating TLS at all, for protocols that need to keep their own encryption intact end to end.

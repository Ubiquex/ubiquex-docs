`google_compute_wire_group` configures real bandwidth and traffic settings on top of a Cross-Site Interconnect connection -- VLAN or port mode, unmetered bandwidth, optional MACsec encryption -- the resource that actually carries traffic across a cross-site network.

## Properties

<ResponseField name="admin_enabled" type="bool">
  Indicates whether the wires in the wire group are enabled. When false, the wires in the wire group are disabled. When true and when there is simultaneously no wire-specific override of `adminEnabled` to false, a given wire is enabled. Defaults to true. Optional; if omitted, computed by Google Cloud.
</ResponseField>

</ResponseField>

<ResponseField name="wire_properties" type="object">
  The properties of a wire. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="bandwidth_allocation" type="string">
      The configuration of the bandwidth allocation, one of the following: - ALLOCATE_PER_WIRE: configures a separate unmetered bandwidth allocation (and associated charges) for each wire in the group. - SHARED_WITH_WIRE_GROUP: this is the default behavior, which configures one unmetered bandwidth allocation for the wire group. The unmetered bandwidth is divided equally across each wire in the group, but dynamic throttling reallocates unused unmetered bandwidth from unused or underused wires to other wires in the group. Optional.
    </ResponseField>
    <ResponseField name="bandwidth_unmetered" type="string">
      The unmetered bandwidth in Gigabits per second, using decimal units. `10` is 10 Gbps, `100` is 100 Gbps. The bandwidth must be greater than 0. Optional.
    </ResponseField>
    <ResponseField name="fault_response" type="string">
      Response when a fault is detected in a pseudowire: - NONE: default. - DISABLE_PORT: set the port line protocol down when inline probes detect a fault. This setting is only permitted on port mode pseudowires. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_compute_alpha_folder_zone_vm_extension_policy` is the zone-restricted counterpart to a folder's own global VM extension policy (managed_by_global/global_resource_link link the two together) -- it applies VM extensions only to instances in its own zone, for a folder that needs per-zone control rather than a single folder-wide policy. No stable, generally-available equivalent is published yet -- this is preview-only right now.

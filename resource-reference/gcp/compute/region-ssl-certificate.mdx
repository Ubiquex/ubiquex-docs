`google_compute_region_ssl_certificate` is the regional counterpart to a global SSL certificate, usable by a regional HTTPS or SSL proxy load balancer to actually terminate TLS.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own region ssl certificate"})

    		ubx.Resource(compute.RegionSslCertificate, "example", compute.RegionSslCertificateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="certificate" type="string">
  A value read into memory from a certificate file. The certificate file must be in PEM format. The certificate chain must be no greater than 5 certs long. The chain must include at least one intermediate cert. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="creation_timestamp" type="string">
  [Output Only] Creation timestamp inRFC3339 text format. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of this resource. Provide this property when you create the resource. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. [Output Only] Expire time of the certificate. RFC3339 Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="id" type="string">
  [Output Only] The unique identifier for the resource. This identifier is defined by the server. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="kind" type="string">
  Output only. [Output Only] Type of the resource. Alwayscompute#sslCertificate for SSL certificates. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="managed" type="object">
  Configuration and status of a managed SSL certificate. Optional; if omitted, computed by GCP.
  <Expandable title="properties">
    <ResponseField name="domain_status" type="map(string)">
      Output only. [Output only] Detailed statuses of the domains specified for managed certificate resource. Computed by GCP after `ship`.

    <ResponseField name="domains" type="list(string)">
      The domains for which a managed SSL certificate will be generated. Each Google-managed SSL certificate supports up to the [maximum number of domains per Google-managed SSL certificate](https://cloud.google.com/load-balancing/docs/quotas#ssl_certificates). Optional.
    </ResponseField>
    <ResponseField name="status" type="string">
      Output only. [Output only] Status of the managed certificate resource. Computed by GCP after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Name of the resource. Provided by the client when the resource is created. The name must be 1-63 characters long, and comply withRFC1035. Specifically, the name must be 1-63 characters long and match the regular expression `[a-z]([-a-z0-9]*[a-z0-9])?` which means the first character must be a lowercase letter, and all following characters must be a dash, lowercase letter, or digit, except the last character, which cannot be a dash. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="private_key" type="string">
  A value read into memory from a write-only private key file. The private key file must be in PEM format. For security, only insert requests include this field. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="region" type="string">
  Output only. [Output Only] URL of the region where the regional SSL Certificate resides. This field is not applicable to global SSL Certificate. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="self_link" type="string">
  [Output only] Server-defined URL for the resource. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="self_managed" type="object">
  Configuration and status of a self-managed SSL certificate. Optional; if omitted, computed by GCP.
  <Expandable title="properties">
    <ResponseField name="certificate" type="string">
      A local certificate file. The certificate must be in PEM format. The certificate chain must be no greater than 5 certs long. The chain must include at least one intermediate cert. Optional.
    </ResponseField>
    <ResponseField name="private_key" type="string">
      A write-only private key in PEM format. Only insert requests will include this field. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subject_alternative_names" type="list(string)">
  Output only. [Output Only] Domains associated with the certificate via Subject Alternative Name. Optional; if omitted, computed by GCP.
</ResponseField>

<ResponseField name="type" type="string">
  (Optional) Specifies the type of SSL certificate, either "SELF_MANAGED" or "MANAGED". If not specified, the certificate is self-managed and the fieldscertificate and private_key are used. Optional; if omitted, computed by GCP.
</ResponseField>

<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_storage_pool`.
</Warning>

`google_compute_beta_storage_pool` is a real, shared pool of Hyperdisk capacity and performance that multiple individual disks draw from together, instead of each disk provisioning and paying for its own dedicated capacity separately.

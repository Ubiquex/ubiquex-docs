  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_region_target_http_proxy`.

`google_compute_beta_region_target_http_proxy` is the regional counterpart to a global target HTTP proxy -- routing real, unencrypted HTTP traffic to a backend service via a regional URL map.

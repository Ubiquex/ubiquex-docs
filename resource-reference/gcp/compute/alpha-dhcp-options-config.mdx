<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_compute_alpha_dhcp_options_config` defines the DHCP options (DNS servers, search domain, lease time, and PXE boot file location) served to instances associated with it, letting network-level client configuration be managed centrally instead of per-instance. No stable, generally-available equivalent is published yet -- this is preview-only right now.

<ResponseField name="boot_file_ipv4_name" type="string">
  The file path and name of the boot image/file on the TFTP server that the client VM guest OS should download and execute during network boot. Used when the standard DHCP header 'file' field is overloaded. Corresponds to DHCPv4 Option 67. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="boot_file_ipv6_parameters" type="list(string)">

</ResponseField>

<ResponseField name="boot_file_ipv6_url" type="string">

Corresponds to DHCPv6 Option 59. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dns_search_paths" type="list(string)">
  An ordered list of domain suffixes (search paths) that the client VM guest OS should append to resolve hostnames that are not fully qualified. Applies to both DHCPv4 Option 119 and DHCPv6 Option 24. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dns_server_ipv4_addresses" type="list(string)">

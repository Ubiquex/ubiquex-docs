<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_network_firewall_policy`.
</Warning>

`google_compute_beta_network_firewall_policy` is a global, real, reusable set of firewall rules attachable to a VPC network -- the network-scoped counterpart to a hierarchical (organization/folder-level) firewall policy.

  Indicates the source of this Firewall Policy. This field is optional on creation and defaults to USER_DEFINED. The USER_DEFINED value indicates a regular firewall policy.

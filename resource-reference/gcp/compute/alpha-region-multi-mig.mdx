`google_compute_alpha_region_multi_mig` groups several regional managed instance groups (MIGs) under one resource so they can be managed, scaled, or targeted together within a region, with its own resource policies and status distinct from any single member MIG's own. No stable, generally-available equivalent is published yet -- this is preview-only right now.

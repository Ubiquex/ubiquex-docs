`google_compute_route` tells a VPC network's own routing table where to actually send traffic matching a specific real destination IP range -- to a gateway, an instance, or another real next hop.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own route"})

    		ubx.Resource(compute.Route, "example", compute.RouteConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

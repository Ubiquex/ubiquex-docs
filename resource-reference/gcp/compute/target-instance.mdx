`google_compute_target_instance` designates a single real VM instance as the destination for a forwarding rule -- a real, simple target for traffic that doesn't need a full load balancer in front of it.

Real, typed bindings generated directly from real Google Discovery Documents, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own target instance"})

    		ubx.Resource(compute.TargetInstance, "ci-runner", compute.TargetInstanceConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_network_attachment`.
</Warning>

`google_compute_alpha_network_attachment` lets another VPC network connect into your own network via Private Service Connect, without you having to know or manage that other network's own IP ranges -- the producer-side resource a real, cross-project PSC connection is built on.

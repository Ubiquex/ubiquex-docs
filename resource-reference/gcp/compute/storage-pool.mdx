`google_compute_storage_pool` is a real, shared pool of Hyperdisk capacity and performance that multiple individual disks draw from together, instead of each disk provisioning and paying for its own dedicated capacity separately.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own storage pool"})

    		ubx.Resource(compute.StoragePool, "ci-runner", compute.StoragePoolConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

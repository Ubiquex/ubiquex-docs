`google_compute_public_delegated_prefix` carves a real, smaller, regional block of addresses out of an already-registered public advertised prefix, delegating that specific slice for actual use within one region.

Real, typed bindings generated directly from real Google Discovery Documents, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

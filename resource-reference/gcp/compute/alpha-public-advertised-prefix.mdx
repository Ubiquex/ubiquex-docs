<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_public_advertised_prefix`.
</Warning>

`google_compute_alpha_public_advertised_prefix` registers a real, top-level block of your own public IP addresses with Google, the first real step before any smaller delegated prefix carved out of it can be used on Google Cloud.

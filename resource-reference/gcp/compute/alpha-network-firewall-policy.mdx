Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. `google_compute_alpha_network_firewall_policy` is a global, real, reusable set of firewall rules attachable to a VPC network -- the network-scoped counterpart to a hierarchical (organization/folder-level) firewall policy.

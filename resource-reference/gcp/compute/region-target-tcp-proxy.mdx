`google_compute_region_target_tcp_proxy` is the regional counterpart to a global target TCP proxy, routing real TCP traffic to a backend service scoped to one region.

Real, typed bindings generated directly from real Google Discovery Documents, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_region_instance_group_manager`.

`google_compute_beta_region_instance_group_manager` is the regional counterpart to a zonal instance group manager -- managing a managed instance group whose real instances are spread across multiple zones in one region for higher availability.

<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_router`.
</Warning>

`google_compute_beta_router` runs real, dynamic BGP routing for a VPC network -- exchanging routes with an on-premises network over Cloud VPN or Interconnect rather than relying on static routes alone.

    </ResponseField>
    <ResponseField name="keepalive_interval" type="number">
      The interval in seconds between BGP keepalive messages that are sent to the peer. Hold time is three times the interval at which keepalive messages are sent, and the hold time is the maximum number of seconds allowed to elapse between successive keepalive messages that BGP receives from a peer. BGP will use the smaller of either the local hold time value or the peer's hold time value as the hold time for the BGP connection between the two peers. If set, this value must be between 20 and 60. The default is 20. Optional.
    </ResponseField>

<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_network_endpoint_group`.
</Warning>

`google_compute_beta_network_endpoint_group` groups real backend endpoints a load balancer can route to -- individual VM IP:port pairs, serverless services, or endpoints outside Google Cloud -- a more granular real target than pointing a load balancer at a whole instance group.

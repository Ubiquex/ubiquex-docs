<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_region_commitment`.
</Warning>

`google_compute_alpha_region_commitment` is a regional committed-use discount -- a real, one- or three-year commitment to a specific amount of vCPU, memory, or GPU usage in one region, in exchange for a lower real hourly rate than on-demand pricing.

## Properties

<ResponseField name="auto_renew" type="bool">
  Specifies whether to automatically renew the commitment at the end of its current term. The default value is false. If you set the field to true, each time your commitment reaches the end of its term, Compute Engine automatically renews it for another term. You can update this field anytime before the commitment expires. For example, if the commitment is set to expire at 12 AM UTC-8 on January 3, 2027, you can update this field until 11:59 PM UTC-8 on January 2, 2027. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="category" type="string">
  The category of the commitment; specifies whether the commitment is for hardware or software resources. Category MACHINE specifies that you are committing to hardware machine resources such asVCPU or MEMORY, listed in resources. Category LICENSE specifies that you are committing to software licenses, listed in licenseResources. Note that if you specify MACHINE commitments, then you must also specify a type to indicate the machine series of the hardware resource that you are committing to. Optional; if omitted, computed by Google Cloud.
</ResponseField>

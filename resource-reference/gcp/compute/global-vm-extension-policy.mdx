`google_compute_global_vm_extension_policy` declares which VM extensions -- agents and other post-boot software -- VM Extension Manager should install across every matching VM in a project, across every zone and region at once rather than one location at a time.

Real, typed bindings generated directly from real Google Discovery Documents, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

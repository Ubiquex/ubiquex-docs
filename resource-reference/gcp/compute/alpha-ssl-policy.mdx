<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_ssl_policy`.
</Warning>

`google_compute_alpha_ssl_policy` controls which real TLS versions and cipher suites a global load balancer accepts, letting you enforce a stricter real minimum than the platform default.

<ResponseField name="post_quantum_key_exchange" type="string">
  One of DEFAULT, ENABLED, orDEFERRED. Controls whether the load balancer negotiates X25519MLKEM768 key exchange when clients advertise support for it. When set to DEFAULT, or if no SSL Policy is attached to the target proxy, the load balancer disallows X25519MLKEM768 key exchange before October 2026, and allows it afterward. When set to ENABLED, the load balancer allows X25519MLKEM768 key exchange. When set toDEFERRED, the load balancer disallows X25519MLKEM768 key exchange until October 2027, and allows it afterward. Optional; if omitted, computed by Google Cloud.
</ResponseField>

Optional; if omitted, computed by Google Cloud.

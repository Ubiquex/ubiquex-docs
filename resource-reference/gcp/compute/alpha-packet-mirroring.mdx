<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_packet_mirroring`.
</Warning>

`google_compute_alpha_packet_mirroring` clones real network traffic to and from a set of instances and sends the copy to a collector, without disrupting the original traffic at all -- used for real, out-of-band security monitoring and intrusion detection.

      One or more IPv4 or IPv6 CIDR ranges that apply as filters on the source (ingress) or destination (egress) IP in the IP header. If no ranges are specified, all IPv4 traffic that matches the specified IPProtocols is mirrored. If neither cidrRanges nor IPProtocols is specified, all IPv4 traffic is mirrored. To mirror all IPv4 and IPv6 traffic, use "0.0.0.0/0,::/0". Optional.

    <ResponseField name="direction" type="string">
      Direction of traffic to mirror, either INGRESS, EGRESS, or BOTH. The default is BOTH. Optional.
    </ResponseField>
    <ResponseField name="ipprotocols" type="list(string)">
      Protocols that apply as filter on mirrored traffic. If no protocols are specified, all traffic that matches the specified CIDR ranges is mirrored. If neither cidrRanges nor IPProtocols is specified, all IPv4 traffic is mirrored. Optional.

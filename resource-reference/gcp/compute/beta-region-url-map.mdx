The stable, generally-available equivalent is `google_compute_region_url_map`.

`google_compute_beta_region_url_map` is the regional counterpart to a global URL map -- the real, host- and path-based routing rules a regional HTTP(S) load balancer uses to decide which backend service handles a given request.

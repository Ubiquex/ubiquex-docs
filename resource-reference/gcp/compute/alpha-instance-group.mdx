<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_instance_group`.
</Warning>

`google_compute_alpha_instance_group` is an unmanaged collection of existing instances grouped together so they can be referenced as one unit -- by a load balancer, for instance -- without Compute Engine automatically creating, healing, or scaling any of them the way a managed instance group does.

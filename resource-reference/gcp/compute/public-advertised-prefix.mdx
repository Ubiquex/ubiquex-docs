`google_compute_public_advertised_prefix` registers a real, top-level block of your own public IP addresses with Google, the first real step before any smaller delegated prefix carved out of it can be used on Google Cloud.

Real, typed bindings generated directly from real Google Discovery Documents, in every SDK language -- every tab below is a complete, runnable program, not a fragment, real enough to save and run exactly as shown.

## Example

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own public advertised prefix"})

    		ubx.Resource(compute.PublicAdvertisedPrefix, "ci-runner", compute.PublicAdvertisedPrefixConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

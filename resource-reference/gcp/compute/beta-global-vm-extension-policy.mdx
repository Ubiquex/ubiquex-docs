<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_global_vm_extension_policy`.
</Warning>

`google_compute_beta_global_vm_extension_policy` declares which VM extensions -- agents and other post-boot software -- VM Extension Manager should install across every matching VM in a project, across every zone and region at once rather than one location at a time.

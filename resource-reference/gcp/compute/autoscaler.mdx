`google_compute_autoscaler` adjusts a zonal managed instance group's own size automatically based on real load -- CPU utilization, a custom metric, load balancing capacity -- adding instances under pressure and removing them once it passes.

  Cloud Autoscaler policy. Optional; if omitted, computed by GCP.
  <Expandable title="properties">
    <ResponseField name="cool_down_period_sec" type="number">
      The number of seconds that your application takes to initialize on a VM instance. This is referred to as the [initialization period](https://cloud.google.com/compute/docs/autoscaler#cool_down_period). Specifying an accurate initialization period improves autoscaler decisions. For example, when scaling out, the autoscaler ignores data from VMs that are still initializing because those VMs might not yet represent normal usage of your application. The default initialization period is 60 seconds. Initialization periods might vary because of numerous factors. We recommend that you test how long your application takes to initialize. To do this, create a VM and time your application's startup process. Optional.
    </ResponseField>
    <ResponseField name="cpu_utilization" type="object">

      <Expandable title="properties">
        <ResponseField name="predictive_method" type="string">
          Indicates whether predictive autoscaling based on CPU metric is enabled. Valid values are: * NONE (default). No predictive method is used. The autoscaler scales the group to meet current demand based on real-time metrics. * OPTIMIZE_AVAILABILITY. Predictive autoscaling improves availability by monitoring daily and weekly load patterns and scaling out ahead of anticipated demand. Optional.
        </ResponseField>
        <ResponseField name="utilization_target" type="number">
          The target CPU utilization that the autoscaler maintains. Must be a float value in the range (0, 1]. If not specified, the default is0.6. If the CPU level is below the target utilization, the autoscaler scales in the number of instances until it reaches the minimum number of instances you specified or until the average CPU of your instances reaches the target utilization. If the average CPU is above the target utilization, the autoscaler scales out until it reaches the maximum number of instances you specified or until the average utilization reaches the target utilization. Optional.

<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_network`.
</Warning>

`google_compute_alpha_network` is a real Virtual Private Cloud network -- a global, software-defined network that a project's own subnets, firewall rules, and routes all live inside, the top-level container every other real networking resource here is scoped underneath.

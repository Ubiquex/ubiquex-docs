  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_compute_alpha_ha_controller` manages high-availability failover for a named instance across a set of real zone_configurations and backend_services, tracking its own failover_initiation and networking_auto_configuration so a workload can fail over between zones without the operator scripting the failover themselves. No stable, generally-available equivalent is published yet -- this is preview-only right now.

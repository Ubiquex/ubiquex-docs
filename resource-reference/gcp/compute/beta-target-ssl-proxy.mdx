<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_target_ssl_proxy`.
</Warning>

`google_compute_beta_target_ssl_proxy` terminates real TLS for non-HTTP TCP traffic and forwards the decrypted stream to a backend service, the SSL-proxy counterpart to a target HTTPS proxy.

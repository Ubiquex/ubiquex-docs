<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_node_group`.
</Warning>

`google_compute_beta_node_group` is a real collection of sole-tenant nodes -- physical servers dedicated entirely to your own project -- that VMs can be placed onto for real, dedicated hardware isolation.

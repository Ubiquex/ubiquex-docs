<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_region_health_check_service`.
</Warning>

`google_compute_beta_region_health_check_service` is the regional configuration tying a health check to the real notification endpoints that should be told when a monitored resource's own health status actually changes.

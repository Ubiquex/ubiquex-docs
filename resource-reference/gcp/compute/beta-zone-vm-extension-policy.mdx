<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_zone_vm_extension_policy`.
</Warning>

`google_compute_beta_zone_vm_extension_policy` is the zonal counterpart to a global VM extension policy -- declaring which extensions VM Extension Manager should install on matching VMs within one specific zone rather than across every zone and region at once.

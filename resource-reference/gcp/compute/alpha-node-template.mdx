<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_node_template`.
</Warning>

`google_compute_alpha_node_template` defines the real hardware specification -- node type, CPU overcommit settings -- that a sole-tenant node group uses to actually provision the physical nodes inside it.

`google_compute_alpha_node_group` is a real collection of sole-tenant nodes -- physical servers dedicated entirely to your own project -- that VMs can be placed onto for real, dedicated hardware isolation.

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

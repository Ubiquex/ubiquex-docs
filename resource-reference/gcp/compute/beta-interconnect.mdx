`google_compute_beta_interconnect` represents a real, physical connection between your own network and Google's network at a real colocation facility -- the dedicated, private link Cloud Interconnect is actually built on top of.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own beta interconnect"})

    		ubx.Resource(compute.BetaInterconnect, "example", compute.BetaInterconnectConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

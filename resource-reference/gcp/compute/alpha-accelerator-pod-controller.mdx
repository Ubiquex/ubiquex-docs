<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_compute_alpha_accelerator_pod_controller` manages an accelerator pod (a tightly-networked group of TPU/GPU accelerators) within a zone, exposing the pod's own management interfaces and its real target so the pod can be administered as a single unit rather than accelerator by accelerator. No stable, generally-available equivalent is published yet -- this is preview-only right now.

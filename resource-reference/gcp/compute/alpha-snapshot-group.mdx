<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_compute_alpha_snapshot_group` is a set of disk snapshots captured together as one consistent point-in-time group, typically sourced from an instant snapshot group, so a multi-disk workload can be restored from a single, mutually-consistent moment rather than disks that were each snapshotted independently. No stable, generally-available equivalent is published yet -- this is preview-only right now.

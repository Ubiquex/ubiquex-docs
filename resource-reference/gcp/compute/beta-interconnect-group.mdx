<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_interconnect_group`.
</Warning>

`google_compute_beta_interconnect_group` groups multiple real Interconnect connections together -- typically for redundancy across different physical facilities -- so their combined resilience can be validated and monitored as a real, single unit.

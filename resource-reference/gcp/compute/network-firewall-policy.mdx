`google_compute_network_firewall_policy` is a global, real, reusable set of firewall rules attachable to a VPC network -- the network-scoped counterpart to a hierarchical (organization/folder-level) firewall policy.

This field is not applicable to network firewall policies. This name must be set on creation and cannot be changed. The name must be 1-63 characters long, and comply with RFC1035. Specifically, the name must be 1-63 characters long and match the regular expression `[a-z]([-a-z0-9]*[a-z0-9])?` which means the first character must be a lowercase letter, and all following characters must be a dash, lowercase letter, or digit, except the last character, which cannot be a dash. Optional; if omitted, computed by Google Cloud.
</ResponseField>

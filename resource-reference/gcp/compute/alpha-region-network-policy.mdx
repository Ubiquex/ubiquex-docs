<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_compute_alpha_region_network_policy` is a regional policy that classifies traffic against a set of real, ordered rules (traffic_classification_rules) and tracks how many resources (associations) currently reference it, used to tag or route traffic within a region without editing every individual resource's own configuration. No stable, generally-available equivalent is published yet -- this is preview-only right now.

<Warning>
  This is Google Cloud Compute's own **alpha** release channel -- earlier and less stable than beta. Google may change or remove alpha endpoints at any time, with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_machine_image`.
</Warning>

`google_compute_alpha_machine_image` captures a real, complete instance -- boot disk, any additional disks, and its own instance configuration -- as one reusable artifact, unlike a plain image which only captures the boot disk.

<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_ssl_certificate`.
</Warning>

`google_compute_beta_ssl_certificate` holds a real TLS certificate and private key a global HTTPS or SSL proxy load balancer uses to actually terminate encrypted connections.

## Properties

<ResponseField name="certificate" type="string">
  A value read into memory from a certificate file. The certificate file must be in PEM format. The certificate chain must be no greater than 5 certs long. The chain must include at least one intermediate cert. Optional; if omitted, computed by Google Cloud.
</ResponseField>

</ResponseField>

</ResponseField>

<Warning>
  This is Google Cloud Compute's own **beta** release channel. Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_compute_instance_group_manager_resize_request`.
</Warning>

`google_compute_beta_instance_group_manager_resize_request` asks a managed instance group to add a real, specific number of instances all at once rather than incrementally -- used to get high-demand resources like GPUs allocated together, and to avoid paying for a partially-fulfilled scale-up while waiting on the rest.

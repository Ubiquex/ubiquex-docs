`google_certificatemanager_certificate_issuance_config` defines which Certificate Authority Service CA pool and key algorithm Certificate Manager uses when issuing a Google-managed certificate against a private CA.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	certificatemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/certificatemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate issuance config"})

    		ubx.Resource(certificatemanager.CertificateIssuanceConfig, "example", certificatemanager.CertificateIssuanceConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="name" type="string">
  Identifier. A user-defined name of the certificate issuance config. CertificateIssuanceConfig names must be unique globally and match pattern `projects/*/locations/*/certificateIssuanceConfigs/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="rotation_window_percentage" type="number">
  Required. Specifies the percentage of elapsed time of the certificate lifetime to wait before renewing the certificate. Must be a number between 1-99, inclusive. Optional; if omitted, computed by Google Cloud.
</ResponseField>

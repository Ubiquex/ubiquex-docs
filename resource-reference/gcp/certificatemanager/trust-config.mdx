`google_certificatemanager_trust_config` defines a set of trusted root and intermediate CA certificates Certificate Manager uses to validate client certificates during mutual TLS.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	certificatemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/certificatemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own trust config"})

    		ubx.Resource(certificatemanager.TrustConfig, "example", certificatemanager.TrustConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

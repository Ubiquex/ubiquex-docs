`google_certificatemanager_dns_authorization` proves domain ownership to Certificate Manager via a DNS CNAME record, letting it issue a Google-managed certificate for that domain.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	certificatemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/certificatemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dns authorization"})

    		ubx.Resource(certificatemanager.DnsAuthorization, "example", certificatemanager.DnsAuthorizationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp of a DnsAuthorization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. One or more paragraphs of text description of a DnsAuthorization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dns_resource_record" type="object">
  The structure describing the DNS Resource Record that needs to be added to DNS configuration for the authorization to be usable by certificate. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="data" type="string">
      Output only. Data of the DNS Resource Record. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Output only. Fully qualified name of the DNS Resource Record. e.g. `_acme-challenge.example.com` Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="type" type="string">
      Output only. Type of the DNS Resource Record. Currently always set to "CNAME". Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="domain" type="string">
  Required. Immutable. A domain that is being authorized. A DnsAuthorization resource covers a single domain and its wildcard, e.g. authorization for `example.com` can be used to issue certificates for `example.com` and `*.example.com`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of labels associated with a DnsAuthorization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. A user-defined name of the dns authorization. DnsAuthorization names must be unique globally and match pattern `projects/*/locations/*/dnsAuthorizations/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Optional. Input only. Immutable. Tag keys/values directly bound to this resource. For example: "123/environment": "production", "123/costCenter": "marketing" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Optional. Immutable. Type of DnsAuthorization. If unset during resource creation the following default will be used: - in location `global`: FIXED_RECORD, - in other locations: PER_PROJECT_RECORD. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last update timestamp of a DnsAuthorization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

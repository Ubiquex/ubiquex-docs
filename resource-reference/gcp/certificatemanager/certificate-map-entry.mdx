`google_certificatemanager_certificate_map_entry` maps a specific hostname pattern to the certificate(s) served for it within a Certificate Manager certificate map.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_certificatemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_certificatemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	certificatemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_certificatemanager/certificatemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate map entry"})

    		ubx.Resource(certificatemanager.CertificatemanagerCertificateMapEntry, "example", certificatemanager.CertificatemanagerCertificateMapEntryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="certificates" type="list(string)">
  Optional. A set of Certificates defines for the given `hostname`. There can be defined up to four certificates in each Certificate Map Entry. Each certificate must match pattern `projects/*/locations/*/certificates/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp of a Certificate Map Entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. One or more paragraphs of text description of a certificate map entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hostname" type="string">
  A Hostname (FQDN, e.g. `example.com`) or a wildcard hostname expression (`*.example.com`) for a set of hostnames with common suffix. Used as Server Name Indication (SNI) for selecting a proper certificate. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Set of labels associated with a Certificate Map Entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="matcher" type="string">
  A predefined matcher for particular cases, other than SNI selection. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. A user-defined name of the Certificate Map Entry. Certificate Map Entry names must be unique globally and match pattern `projects/*/locations/*/certificateMaps/*/certificateMapEntries/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. A serving state of this Certificate Map Entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The update timestamp of a Certificate Map Entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

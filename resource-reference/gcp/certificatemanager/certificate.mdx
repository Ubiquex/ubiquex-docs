`google_certificatemanager_certificate` is a TLS certificate managed by Certificate Manager, either Google-managed (auto-provisioned and renewed) or self-managed (caller-uploaded).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	certificatemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/certificatemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own certificate"})

    		ubx.Resource(certificatemanager.Certificate, "example", certificatemanager.CertificateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

---
title: "google_chromemanagement_connector_config"
description: "`google_chromemanagement_connector_config` configures a real Chrome Enterprise Connectors provider..."
---

`google_chromemanagement_connector_config` configures a real Chrome Enterprise Connectors provider, letting a Super Admin route Chrome browser events (like malware transfers or unsafe site visits) to a third-party security or data-integration service, gated behind an active Chrome Enterprise Core subscription.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_chromemanagement --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_chromemanagement/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	chromemanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google_chromemanagement/chromemanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own connector config"})

    		ubx.Resource(chromemanagement.ChromemanagementConnectorConfig, "ci-runner", chromemanagement.ChromemanagementConnectorConfigConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

    </ResponseField>
    <ResponseField name="update_time" type="string">
      Output only. Field recording time of most recent modification of the status. For `ENABLED`, this is the time the status was changed to `ENABLED`.     </ResponseField>

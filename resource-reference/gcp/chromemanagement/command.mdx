`google_chromemanagement_command` issues a remote administrative command (via the Chrome Management API) to a managed Chrome device or browser, such as a reboot or a fetch of diagnostic data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_chromemanagement --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_chromemanagement/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	chromemanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google_chromemanagement/chromemanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own command"})

    		ubx.Resource(chromemanagement.ChromemanagementCommand, "example", chromemanagement.ChromemanagementCommandConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="command_result" type="object">
  Result of the execution of a command. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="client_execution_time" type="string">
      Output only. Timestamp of the client execution of the remote command. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="result_code" type="string">
      Output only. Result code that indicates the type of error or success of the command. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="result_type" type="string">
      Output only. Result type of the remote command. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="command_state" type="string">
  Output only. State of the remote command. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="command_type" type="string">
  Required. Type of the remote command. The only supported command_type is "clearBrowsingData". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="issue_time" type="string">
  Output only. Timestamp of the issurance of the remote command. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Format: customers/&#123;customer_id&#125;/profiles/&#123;profile_permanent_id&#125;/commands/&#123;command_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="payload" type="map(any)">
  Required. Payload of the remote command. The payload for "clearBrowsingData" command supports: - fields "clearCache" and "clearCookies" - values of boolean type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="valid_duration" type="string">
  Output only. Valid duration of the remote command. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_contentwarehouse_synonym_set` defines custom, business- or industry-specific synonyms (like acronyms or alternate terms) so Document AI Warehouse search can find content using the familiar words an organization actually uses, not just literal matches.

## Example

<Tabs>

    ```go
    // ubx sdk gen --only google_contentwarehouse --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_contentwarehouse/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contentwarehouse "github.com/ubiquex/ubx-sdk-google/sdk/go/google_contentwarehouse/contentwarehouse"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own synonym set"})

    		ubx.Resource(contentwarehouse.ContentwarehouseSynonymSet, "ci-runner", contentwarehouse.ContentwarehouseSynonymSetConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="context" type="string">
  This is a freeform field. Example contexts can be "sales," "engineering," "real estate," "accounting," etc. The context can be supplied during search requests. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the SynonymSet This is mandatory for google.api.resource. Format: projects/&#123;project_number&#125;/locations/&#123;location&#125;/synonymSets/&#123;context&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="synonyms" type="list(object)">
  List of Synonyms for the context. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="words" type="list(string)">
      The real, individual synonym words that make up one entry in a `google_contentwarehouse_synonym_set`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

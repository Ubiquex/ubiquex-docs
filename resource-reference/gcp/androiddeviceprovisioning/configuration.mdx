`google_androiddeviceprovisioning_configuration` is a real Android zero-touch enrollment configuration, combining the EMM device policy controller, the EMM policies to enforce, and the on-device setup metadata that gets applied automatically to a customer's registered devices the first time they boot or are factory reset.

## Example

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androiddeviceprovisioning "github.com/ubiquex/ubx-sdk-google/sdk/go/google/androiddeviceprovisioning"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own configuration"})

    		ubx.Resource(androiddeviceprovisioning.Configuration, "example", androiddeviceprovisioning.ConfigurationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="company_name" type="string">
  Required. The name of the organization. Zero-touch enrollment shows this organization name to device users during device provisioning. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="configuration_id" type="string">
  Output only. The ID of the configuration. Assigned by the server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="configuration_name" type="string">
  Required. A short name that describes the configuration's purpose. For example, _Sales team_ or _Temporary employees_. The zero-touch enrollment portal displays this name to IT admins. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="contact_email" type="string">
  Required. The email address that device users can contact to get help. Zero-touch enrollment shows this email address to device users before device provisioning. The value is validated on input. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="contact_phone" type="string">
  Required. The telephone number that device users can call, using another device, to get help. Zero-touch enrollment shows this number to device users before device provisioning. Accepts numerals, spaces, the plus sign, hyphens, and parentheses. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="custom_message" type="string">
  A message, containing one or two sentences, to help device users get help or give them more details about what’s happening to their device. Zero-touch enrollment shows this message before the device is provisioned. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dpc_extras" type="string">
  The JSON-formatted EMM provisioning extras that are passed to the DPC. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dpc_resource_path" type="string">
  Required. The resource name of the selected DPC (device policy controller) in the format `customers/[CUSTOMER_ID]/dpcs/*`. To list the supported DPCs, call `customers.dpcs.list`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="forced_reset_time" type="string">
  Optional. The timeout before forcing factory reset the device if the device doesn't go through provisioning in the setup wizard, usually due to lack of network connectivity during setup wizard. Ranges from 0-6 hours, with 2 hours being the default if unset. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_default" type="bool">
  Required. Whether this is the default configuration that zero-touch enrollment applies to any new devices the organization purchases in the future. Only one customer configuration can be the default. Setting this value to `true`, changes the previous default configuration's `isDefault` value to `false`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The API resource name in the format `customers/[CUSTOMER_ID]/configurations/[CONFIGURATION_ID]`. Assigned by the server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_firebasedataconnect_connector` defines a set of GraphQL queries and mutations exposed to client apps through Firebase Data Connect, generated into a typed client SDK.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebasedataconnect "github.com/ubiquex/ubx-sdk-google/sdk/go/google/firebasedataconnect"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connector"})

    		ubx.Resource(firebasedataconnect.Connector, "example", firebasedataconnect.ConnectorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="client_cache" type="object">
  Client caching settings of a connector. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="entity_id_included" type="bool">
      Optional. A field that, if true, means that responses served by this connector will include entityIds in GraphQL response extensions. This helps the client SDK cache responses in an improved way, known as "normalized caching", if caching is enabled on the client. Each entityId is a stable key based on primary key values. Therefore, this field should only be set to true if the primary keys of accessed tables do not contain sensitive information. Optional.
    </ResponseField>
    <ResponseField name="strict_validation_enabled" type="bool">
      Optional. A field that, if true, enables stricter validation on the connector source code to make sure the operation response shapes are suitable for client-side caching. This can include additional errors and warnings. For example, using the same alias for different fields is disallowed, as it may cause conflicts or confusion with normalized caching. (This field is off by default for compatibility, but enabling it is highly recommended to catch common caching pitfalls.) Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_firebasedataconnect_schema`.

`google_firebasedataconnect_v1beta_schema` defines the GraphQL data model backing a Firebase Data Connect service, mapped onto its own underlying Cloud SQL PostgreSQL database.

`google_blockchainnodeengine_blockchain_node` provisions a fully managed blockchain node (e.g. Ethereum) through Blockchain Node Engine, without the caller having to operate node infrastructure themselves.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	blockchainnodeengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/blockchainnodeengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own blockchain node"})

    		ubx.Resource(blockchainnodeengine.BlockchainNode, "example", blockchainnodeengine.BlockchainNodeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

    def describe():

            name="example",

        ubx.run("example", describe)

## Properties

<ResponseField name="blockchain_type" type="string">
  Immutable. The blockchain type of the node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="connection_info" type="object">
  The connection information through which to interact with a blockchain node. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="endpoint_info" type="object">
      Contains endpoint information through which to interact with a blockchain node. Optional.
      <Expandable title="properties">
        <ResponseField name="json_rpc_api_endpoint" type="string">
          Output only. The assigned URL for the node JSON-RPC API endpoint. Computed by Google Cloud after `ship`.
        </ResponseField>
        <ResponseField name="websockets_api_endpoint" type="string">
          Output only. The assigned URL for the node WebSockets API endpoint. Computed by Google Cloud after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="service_attachment" type="string">
      Output only. A service attachment that exposes a node, and has the following format: projects/&#123;project&#125;/regions/&#123;region&#125;/serviceAttachments/&#123;service_attachment_name&#125; Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp at which the blockchain node was first created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

        <ResponseField name="execution_client_prometheus_metrics_api_endpoint" type="string">

          An Ethereum address which the beacon client will send fee rewards to if no recipient is configured in the validator client. See https://lighthouse-book.sigmaprime.io/suggested-fee-recipient.html or https://docs.prylabs.network/docs/execution-node/fee-recipient for examples of how this is used. Note that while this is often described as "suggested", as we run the execution node we can trust the execution node, and therefore this is considered enforced. Optional.

        </ResponseField>

      </Expandable>

<ResponseField name="name" type="string">
  Output only. The fully qualified name of the blockchain node. e.g. `projects/my-project/locations/us-central1/blockchainNodes/my-node`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="private_service_connect_enabled" type="bool">
  Optional. When true, the node is only accessible via Private Service Connect; no public endpoints are exposed. Otherwise, the node is only accessible via public endpoints. Warning: These nodes are deprecated, please use public endpoints instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. A status representing the state of the node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp at which the blockchain node was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

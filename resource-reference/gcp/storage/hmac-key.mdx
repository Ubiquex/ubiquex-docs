`google_storage_hmac_key` is an HMAC credential pair for a Cloud Storage service account, used to authenticate requests through Cloud Storage's own S3-compatible XML API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storage "github.com/ubiquex/ubx-sdk-google/sdk/go/google/storage"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hmac key"})

    		ubx.Resource(storage.HmacKey, "example", storage.HmacKeyConfig{
    			AccessId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Output properties

<ResponseField name="access_id" type="string">
  The ID of the HMAC Key. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="etag" type="string">
  HTTP 1.1 Entity tag for the HMAC key. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the HMAC key, including the Project ID and the Access ID. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="kind" type="string">
  The kind of item this is. For HMAC Key metadata, this is always storage#hmacKeyMetadata. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="project_id" type="string">
  Project ID owning the service account to which the key authenticates. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="self_link" type="string">
  The link to this resource. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="service_account_email" type="string">
  The email address of the key's associated service account. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="state" type="string">
  The state of the key. Can be one of ACTIVE, INACTIVE, or DELETED. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="time_created" type="string">
  The creation time of the HMAC key in RFC 3339 format. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="updated" type="string">
  The last modification time of the HMAC key metadata in RFC 3339 format. Computed by Google Cloud after `ship`.
</ResponseField>

`google_storage_folder` is a real, hierarchical folder within a Cloud Storage bucket that has hierarchical namespace enabled, distinct from the flat, prefix-simulated "folders" of a standard bucket.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_storage --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_storage/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storage "github.com/ubiquex/ubx-sdk-google/sdk/go/google_storage/storage"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own folder"})

    		ubx.Resource(storage.StorageFolder, "example", storage.StorageFolderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    // ubx sdk gen --only google_storage --lang ts --out ./local-sdk

## Properties

<ResponseField name="bucket" type="string">
  The name of the bucket containing this folder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  The creation time of the folder in RFC 3339 format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the folder, including the bucket name, folder name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  The kind of item this is. For folders, this is always storage#folder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metageneration" type="string">
  The version of the metadata for this folder. Used for preconditions and for detecting changes in metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the folder. Required if not specified by URL parameter. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pending_rename_info" type="object">
  Only present if the folder is part of an ongoing rename folder operation. Contains information which can be used to query the operation status. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="operation_id" type="string">
      The ID of the rename folder operation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="self_link" type="string">
  The link to this folder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  The modification time of the folder metadata in RFC 3339 format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

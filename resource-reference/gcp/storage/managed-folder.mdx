`google_storage_managed_folder` defines a folder-like path prefix within a Cloud Storage bucket that its own IAM policy can be scoped to, letting different teams manage access to different prefixes within the same bucket.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storage "github.com/ubiquex/ubx-sdk-google/sdk/go/google/storage"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own managed folder"})

    		ubx.Resource(storage.ManagedFolder, "example", storage.ManagedFolderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="bucket" type="string">
  The name of the bucket containing this managed folder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  The creation time of the managed folder in RFC 3339 format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the managed folder, including the bucket name and managed folder name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  The kind of item this is. For managed folders, this is always storage#managedFolder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metageneration" type="string">
  The version of the metadata for this managed folder. Used for preconditions and for detecting changes in metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the managed folder. Required if not specified by URL parameter. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="rapid_cache_config" type="object">
  Configuration options for the rapid cache of a managed folder. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="policies" type="map(object)">
      A map of rapid cache IDs to the corresponding `RapidCachePolicy` configurations for a managed folder. Optional.
      <Expandable title="properties">
        <ResponseField name="ingest_on_write" type="string">
          Whether this bucket ingests written objects for rapid analytics access as they land. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="rapid_cache_id" type="string">
          The identifier of the rapid storage cache this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="self_link" type="string">
  The link to this managed folder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  The last update time of the managed folder metadata in RFC 3339 format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

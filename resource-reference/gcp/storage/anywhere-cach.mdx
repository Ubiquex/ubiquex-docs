`google_storage_anywhere_cach` (Anywhere Cache) is a zonal, SSD-backed read cache for a Cloud Storage bucket, recently renamed Rapid Cache as part of the Cloud Storage Rapid family announced at Google Cloud Next '26 -- accelerating reads for AI training and analytics workloads without changing application code.

</ResponseField>

</ResponseField>

<ResponseField name="kind" type="string">

</ResponseField>

<ResponseField name="state" type="string">

<ResponseField name="ttl" type="string">

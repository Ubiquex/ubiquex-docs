`google_storage_rapid_cach` (Rapid Cache, formerly Anywhere Cache) is a zonal, SSD-backed read cache for a Cloud Storage bucket, part of the Cloud Storage Rapid family announced at Google Cloud Next '26 -- accelerating reads for AI training, inference, and analytics workloads without requiring application code changes.

## Input properties

<ResponseField name="bucket" type="string" required>
  The name of the bucket. Required.
</ResponseField>

<ResponseField name="custom_attributes" type="map(string)">
  A set of key/value attribute pairs to attach to each Cloud Pub/Sub message published for this notification subscription. Optional.
</ResponseField>

<ResponseField name="event_types" type="set(string)">
  List of event type filters for this notification config. If not specified, Cloud Storage will send notifications for all event types. The valid types are: "OBJECT_FINALIZE", "OBJECT_METADATA_UPDATE", "OBJECT_DELETE", "OBJECT_ARCHIVE" Optional.
</ResponseField>

<ResponseField name="object_name_prefix" type="string">
  Specifies a prefix path filter for this notification config. Cloud Storage will only send notifications for objects in this bucket whose names begin with the specified prefix. Optional.
</ResponseField>

<ResponseField name="payload_format" type="string" required>
  The desired content of the Payload. One of "JSON_API_V1" or "NONE". Required.
</ResponseField>

<ResponseField name="topic" type="string" required>
  The Cloud Pub/Sub topic to which this subscription publishes. Required.
</ResponseField>

`google_storage_notification` configures a Cloud Storage bucket to publish a Pub/Sub message whenever a specified object event (create, delete, and similar) occurs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storage "github.com/ubiquex/ubx-sdk-google/sdk/go/google/storage"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own notification"})

    		ubx.Resource(storage.Notification, "example", storage.NotificationConfig{
    			CustomAttributes: map[string]string{"managed-by": "ubx"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Notification } from "@ubx/sdk-google/google/storage/notification";

    export default stack("example", () => {
      intent({ summary: "example own notification" });

      resource(Notification, "example", {
        customAttributes: { "managed-by": "ubx" },

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.storage import Notification, NotificationConfig

    def describe():

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="custom_attributes" type="map(string)">
  An optional list of additional attributes to attach to each Cloud PubSub message published for this notification subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  HTTP 1.1 Entity tag for this subscription notification. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="event_types" type="list(string)">
  If present, only send notifications about listed event types. If empty, sent notifications for all event types. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the notification. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  The kind of item this is. For notifications, this is always storage#notification. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="object_name_prefix" type="string">
  If present, only apply this notification configuration to object names that begin with this prefix. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="payload_format" type="string">
  The desired content of the Payload. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self_link" type="string">
  The canonical URL of this notification. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="topic" type="string">
  The Cloud PubSub topic to which this subscription publishes. Formatted as: '//pubsub.googleapis.com/projects/&#123;project-identifier&#125;/topics/&#123;my-topic&#125;' Optional; if omitted, computed by Google Cloud.
</ResponseField>

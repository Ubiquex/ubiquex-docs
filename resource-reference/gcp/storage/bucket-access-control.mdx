`google_storage_bucket_access_control` grants a specific access role (e.g. reader or owner) to an entity (a user, group, or `allUsers`) on an entire Cloud Storage bucket, via bucket-level ACLs.

## Properties

<ResponseField name="bucket" type="string">
  The name of the bucket. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="domain" type="string">
  The domain associated with the entity, if any. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="email" type="string">
  The email address associated with the entity, if any. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="entity" type="string">
  The entity holding the permission, in one of the following forms: - user-userId - user-email - group-groupId - group-email - domain-domain - project-team-projectId - allUsers - allAuthenticatedUsers Examples: - The user liz@example.com would be user-liz@example.com. - The group example@googlegroups.com would be group-example@googlegroups.com. - To refer to all members of the Google Apps for Business domain example.com, the entity would be domain-example.com. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="entity_id" type="string">
  The ID for the entity, if any. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  HTTP 1.1 Entity tag for the access-control entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the access-control entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  The kind of item this is. For bucket access control entries, this is always storage#bucketAccessControl. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="project_team" type="object">
  The project team associated with the entity, if any. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="project_number" type="string">
      The project number. Optional.
    </ResponseField>
    <ResponseField name="team" type="string">
      The team for the storage bucket access control's project team. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role" type="string">
  The access permission for the entity. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self_link" type="string">
  The link to this access-control entry. Optional; if omitted, computed by Google Cloud.
</ResponseField>

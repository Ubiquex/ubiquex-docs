<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networksecurity_dns_threat_detector`.
</Warning>

`google_networksecurity_v1beta1_dns_threat_detector` enables DNS Armor, which sends a project's own internet-bound DNS query logs to a managed Infoblox threat-detection engine to flag malicious domains in real time.

  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networksecurity_sac_realm`.

`google_networksecurity_v1beta1_sac_realm` is the global Secure Access Connect resource linking a Google Cloud project to a security service edge (SSE) provider, the parent resource its own regional attachments are created under.

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when the realm was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Optional list of labels applied to the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name, in the form `projects/&#123;project&#125;/locations/global/sacRealms/&#123;sacRealm&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pairing_key" type="object">
  Key to be shared with SSE service provider to establish global handshake. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="expire_time" type="string">
      Output only. Timestamp in UTC of when this resource is considered expired. It expires 7 days after creation. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="key" type="string">
      Output only. Key value. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="security_service" type="string">
  Immutable. SSE service provider associated with the realm. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the realm. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="symantec_options" type="object">
  Fields specific to realms using Symantec Cloud SWG. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="available_symantec_sites" type="list(string)">
      Output only. Symantec site IDs which the user can choose to connect to. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="secret_path" type="string">
      Optional. API Key used to call Symantec APIs on the user's behalf. Required if using Symantec Cloud SWG. P4SA account needs permissions granted to read this secret. A secret ID, secret name, or secret URI can be specified, but it will be parsed and stored as a secret URI in the form `projects/&#123;project_number&#125;/secrets/my-secret`. Optional.
    </ResponseField>
    <ResponseField name="symantec_connection_state" type="string">
      Output only. Connection status to Symantec API. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when the realm was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networksecurity_address_group`.
</Warning>

`google_networksecurity_v1beta1_address_group` is a named, reusable list of IP address(es) or CIDR range(s) that Cloud Firewall or Cloud Armor policy rules can reference by name instead of enumerating addresses inline.

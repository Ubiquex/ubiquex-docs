`google_networksecurity_intercept_endpoint_group_association` attaches a VPC network to an intercept endpoint group, enabling Network Security Integration traffic interception for that network.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networksecurity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networksecurity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own intercept endpoint group association"})

    		ubx.Resource(networksecurity.InterceptEndpointGroupAssociation, "example", networksecurity.InterceptEndpointGroupAssociationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_networksecurity_v1beta1_wildfire_verdict_change_request` is a real request to override Cloud Next Generation Firewall's own WildFire malware verdict for a specific file (identified by its sha256) -- recording the old_verdict, the requested new_verdict, a comment justifying the change, and the resulting final_verdict once resolved -- so a false-positive or false-negative malware classification can be corrected through a real, auditable process rather than by disabling scanning.

  Required. The justification for the verdict change request. Max length 2048 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">

</ResponseField>

  Output only. The file name of the Malware Sample. Optional; if omitted, computed by Google Cloud.
</ResponseField>

  Output only. The file type of the Malware Sample. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="final_verdict" type="string">

</ResponseField>

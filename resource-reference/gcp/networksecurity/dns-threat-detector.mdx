`google_networksecurity_dns_threat_detector` enables DNS Armor, which sends a project's own internet-bound DNS query logs to a managed Infoblox threat-detection engine to flag malicious domains in real time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networksecurity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networksecurity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dns threat detector"})

    		ubx.Resource(networksecurity.DnsThreatDetector, "example", networksecurity.DnsThreatDetectorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="excluded_networks" type="list(string)">
  Optional. A list of network resource names which aren't monitored by this DnsThreatDetector. Example: `projects/PROJECT_ID/global/networks/NETWORK_NAME`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Any labels associated with the DnsThreatDetector, listed as key value pairs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Identifier. Name of the DnsThreatDetector resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="provider" type="string">
  Required. The provider used for DNS threat analysis. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

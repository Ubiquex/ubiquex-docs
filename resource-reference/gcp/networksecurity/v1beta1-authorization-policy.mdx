`google_networksecurity_v1beta1_authorization_policy` defines an allow/deny access-control rule for traffic reaching a load balancer or service mesh backend, evaluated based on the caller's own authenticated identity.

<ResponseField name="rules" type="list(object)">
  Optional. List of rules to match. Note that at least one of the rules must match in order for the action specified in the 'action' field to be taken. A rule is a match if there is a matching source and destination. If left blank, the action specified in the `action` field will be applied on every request. Optional; if omitted, computed by Google Cloud.

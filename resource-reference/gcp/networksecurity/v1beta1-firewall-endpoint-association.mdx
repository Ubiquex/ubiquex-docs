<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networksecurity_firewall_endpoint_association`.
</Warning>

`google_networksecurity_v1beta1_firewall_endpoint_association` attaches a VPC network to a firewall endpoint, enabling Cloud NGFW intrusion prevention inspection for that network's own traffic.

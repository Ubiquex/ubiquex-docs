`google_networksecurity_firewall_endpoint_association` attaches a VPC network to a firewall endpoint, enabling Cloud NGFW intrusion prevention inspection for that network's own traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_networksecurity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_networksecurity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networksecurity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_networksecurity/networksecurity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own firewall endpoint association"})

    		ubx.Resource(networksecurity.NetworksecurityFirewallEndpointAssociation, "example", networksecurity.NetworksecurityFirewallEndpointAssociationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time stamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Whether the association is disabled. True indicates that traffic won't be intercepted Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="firewall_endpoint" type="string">
  Required. The URL of the FirewallEndpoint that is being associated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Identifier. name of resource Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Required. The URL of the network that is being associated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reconciling" type="bool">
  Output only. Whether reconciling is in progress, recommended per https://google.aip.dev/128. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Current state of the association. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tls_inspection_policy" type="string">
  Optional. The URL of the TlsInspectionPolicy that is being associated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

  Output only. Update time stamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networksecurity_security_profile`.
</Warning>

`google_networksecurity_v1beta1_security_profile` defines the inspection behavior (threat prevention settings, custom signatures) applied by a Cloud NGFW intrusion prevention or Secure Web Proxy security profile group.

Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networksecurity_backend_authentication_config`.

`google_networksecurity_v1beta1_backend_authentication_config` configures a load balancer to authenticate itself to backend services via mutual TLS, referencing the client certificate presented on outbound connections.

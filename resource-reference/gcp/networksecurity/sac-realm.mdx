`google_networksecurity_sac_realm` is the global Secure Access Connect resource linking a Google Cloud project to a security service edge (SSE) provider, the parent resource its own regional attachments are created under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_networksecurity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_networksecurity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networksecurity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_networksecurity/networksecurity"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own sac realm"})

    		ubx.Resource(networksecurity.NetworksecuritySacRealm, "ci-runner", networksecurity.NetworksecuritySacRealmConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when the realm was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Optional list of labels applied to the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name, in the form `projects/&#123;project&#125;/locations/global/sacRealms/&#123;sacRealm&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pairing_key" type="object">
  Key to be shared with SSE service provider to establish global handshake. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="expire_time" type="string">
      Output only. Timestamp in UTC of when this resource is considered expired. It expires 7 days after creation. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="key" type="string">
      Output only. Key value. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="security_service" type="string">
  Immutable. SSE service provider associated with the realm. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the realm. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when the realm was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

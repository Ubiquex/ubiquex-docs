Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. `google_networksecurity_v1beta1_mirroring_endpoint_group_association` attaches a VPC network to a mirroring endpoint group, enabling packet mirroring under Network Security Integration for that network's own traffic.

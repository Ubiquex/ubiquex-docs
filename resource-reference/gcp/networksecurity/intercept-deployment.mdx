`google_networksecurity_intercept_deployment` is a zonal instance of a third-party network security appliance deployed under Google Cloud's Network Security Integration framework, that intercepted traffic is forwarded to for inspection.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networksecurity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networksecurity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own intercept deployment"})

    		ubx.Resource(networksecurity.InterceptDeployment, "example", networksecurity.InterceptDeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

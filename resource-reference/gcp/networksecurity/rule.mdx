`google_networksecurity_rule` is a single match-and-action rule within a Cloud NGFW gateway security policy or address group, evaluated against matching traffic.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_networksecurity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_networksecurity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networksecurity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_networksecurity/networksecurity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own rule"})

    		ubx.Resource(networksecurity.NetworksecurityRule, "example", networksecurity.NetworksecurityRuleConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="application_matcher" type="string">
  Optional. CEL expression for matching on L7/application level criteria. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="basic_profile" type="string">
  Required. Profile which tells what the primitive action should be. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Time when the rule was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Free-text description of the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enabled" type="bool">
  Required. Whether the rule is enforced. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Immutable. Name of the resource. ame is the full resource name so projects/&#123;project&#125;/locations/&#123;location&#125;/gatewaySecurityPolicies/&#123;gateway_security_policy&#125;/rules/&#123;rule&#125; rule should match the pattern: (^[a-z]([a-z0-9-]&#123;0,61&#125;[a-z0-9])?$). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="priority" type="number">
  Required. Priority of the rule. Lower number corresponds to higher precedence. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="session_matcher" type="string">
  Required. CEL expression for matching on session criteria. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tls_inspection_enabled" type="bool">
  Optional. Flag to enable TLS inspection of traffic matching on , can only be true if the parent GatewaySecurityPolicy references a TLSInspectionConfig. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Time when the rule was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

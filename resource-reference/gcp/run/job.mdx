---
title: "google_run_job"
description: "`google_run_job` runs a Cloud Run container to completion for a batch or scheduled task..."
---

`google_run_job` runs a Cloud Run container to completion for a batch or scheduled task, rather than serving ongoing request traffic like a Cloud Run service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	run "github.com/ubiquex/ubx-sdk-google/sdk/go/google/run"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own job"})

    		ubx.Resource(run.Job, "example", run.JobConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Job } from "@ubx/sdk-google/google/run/job";

    export default stack("example", () => {
      intent({ summary: "example own job" });

      resource(Job, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.run.job import Job, JobConfig

    def describe():
        ubx.intent("example own job")

        ubx.resource(Job, "example", JobConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
  <Tab title="Markdown">
    ```
    Create google_run_job called "example", with .
    ```
  </Tab>
</Tabs>

<ResponseField name="reconciling" type="bool">
  Output only. Returns true if the Job is currently being acted upon by the system to bring it into the desired state. When a new Job is created, or an existing one is updated, Cloud Run will asynchronously perform all necessary steps to bring the Job to the desired state. This process is called reconciliation. While reconciliation is in process, `observed_generation` and `latest_succeeded_execution`, will have transient values that might mismatch the intended state: Once reconciliation is over (and this field is false), there are two possible outcomes: reconciliation succeeded and the state matches the Job, or there was an error, and reconciliation failed. This state can be found in `terminal_condition.state`. If reconciliation succeeded, the following fields will match: `observed_generation` and `generation`, `latest_succeeded_execution` and `latest_created_execution`. If reconciliation failed, `observed_generation` and `latest_succeeded_execution` will have the state of the last succeeded execution or empty for newly created Job. Additional information on the failure can be found in `terminal_condition` and `conditions`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

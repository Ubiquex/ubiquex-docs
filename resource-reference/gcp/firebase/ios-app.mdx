## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebase "github.com/ubiquex/ubx-sdk-google/sdk/go/google/firebase"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ios app"})

    		ubx.Resource(firebase.IosApp, "example", firebase.IosAppConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="api_key_id" type="string">
  The globally unique, Google-assigned identifier (UID) for the Firebase API key associated with the `IosApp`. Be aware that this value is the UID of the API key, _not_ the [`keyString`](https://cloud.google.com/api-keys/docs/reference/rest/v2/projects.locations.keys#Key.FIELDS.key_string) of the API key. The `keyString` is the value that can be found in the App's [configuration artifact](../../rest/v1beta1/projects.iosApps/getConfig). If `api_key_id` is not set in requests to [`iosApps.Create`](../../rest/v1beta1/projects.iosApps/create), then Firebase automatically associates an `api_key_id` with the `IosApp`. This auto-associated key may be an existing valid key or, if no valid key exists, a new one will be provisioned. In patch requests, `api_key_id` cannot be set to an empty value, and the new UID must have no restrictions or only have restrictions that are valid for the associated `IosApp`. We recommend using the [Google Cloud Console](https://console.cloud.google.com/apis/credentials) to manage API keys. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="app_id" type="string">
  Output only. Immutable. The globally unique, Firebase-assigned identifier for the `IosApp`. This identifier should be treated as an opaque token, as the data format is not specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="app_store_id" type="string">
  The automatically generated Apple ID assigned to the iOS app by Apple in the iOS App Store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="bundle_id" type="string">
  Immutable. The canonical bundle ID of the iOS app as it would appear in the iOS AppStore. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-assigned display name for the `IosApp`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  This checksum is computed by the server based on the value of other fields, and it may be sent with update requests to ensure the client has an up-to-date value before proceeding. Learn more about `etag` in Google's [AIP-154 standard](https://google.aip.dev/154#declarative-friendly-resources). This etag is strongly validated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. If the App has been removed from the Project, this is the timestamp of when the App is considered expired and will be permanently deleted. After this time, the App cannot be undeleted (that is, restored to the Project). This value is only provided if the App is in the `DELETED` state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the IosApp, in the format: projects/PROJECT_IDENTIFIER /iosApps/APP_ID * PROJECT_IDENTIFIER: the parent Project's [`ProjectNumber`](../projects#FirebaseProject.FIELDS.project_number) ***(recommended)*** or its [`ProjectId`](../projects#FirebaseProject.FIELDS.project_id). Learn more about using project identifiers in Google's [AIP 2510 standard](https://google.aip.dev/cloud/2510). Note that the value for PROJECT_IDENTIFIER in any response body will be the `ProjectId`. * APP_ID: the globally unique, Firebase-assigned identifier for the App (see [`appId`](../projects.iosApps#IosApp.FIELDS.app_id)). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="project_id" type="string">
  Output only. Immutable. A user-assigned unique identifier of the parent FirebaseProject for the `IosApp`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The lifecycle state of the App. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="team_id" type="string">
  The Apple Developer Team ID associated with the App in the App Store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_cloudidentity_inbound_sso_assignment` assigns a specific group or org unit of Cloud Identity users to authenticate through a particular configured inbound SSO profile.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudidentity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudidentity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudidentity/cloudidentity"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own inbound sso assignment"})

    		ubx.Resource(cloudidentity.CloudidentityInboundSsoAssignment, "example", cloudidentity.CloudidentityInboundSsoAssignmentConfig{

    		})
    	}))
    }
    ```

## Properties

<ResponseField name="customer" type="string">
  Immutable. The customer. For example: `customers/C0123abc`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. [Resource name](https://cloud.google.com/apis/design/resource_names) of the Inbound SSO Assignment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="oidc_sso_info" type="object">
  Details that are applicable when `sso_mode` is set to `OIDC_SSO`. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="inbound_oidc_sso_profile" type="string">
      Required. Name of the `InboundOidcSsoProfile` to use. Must be of the form `inboundOidcSsoProfiles/&#123;inbound_oidc_sso_profile&#125;`. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rank" type="number">
  Must be zero (which is the default value so it can be omitted) for assignments with `target_org_unit` set and must be greater-than-or-equal-to one for assignments with `target_group` set. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="saml_sso_info" type="object">
  Details that are applicable when `sso_mode` == `SAML_SSO`. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="inbound_saml_sso_profile" type="string">
      Required. Name of the `InboundSamlSsoProfile` to use. Must be of the form `inboundSamlSsoProfiles/&#123;inbound_saml_sso_profile&#125;`. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sign_in_behavior" type="object">
  Controls sign-in behavior. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="redirect_condition" type="string">
      When to redirect sign-ins to the IdP. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sso_mode" type="string">
  Inbound SSO behavior. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_group" type="string">
  Immutable. Must be of the form `groups/&#123;group&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_org_unit" type="string">
  Immutable. Must be of the form `orgUnits/&#123;org_unit&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

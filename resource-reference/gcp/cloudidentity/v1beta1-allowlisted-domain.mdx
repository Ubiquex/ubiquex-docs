<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_cloudidentity_allowlisted_domain`.
</Warning>

`google_cloudidentity_v1beta1_allowlisted_domain` permits a specific external Cloud Identity domain to have its own users provisioned or referenced (e.g. as group members) from within the calling organization.

## Example

    	ubx.Main(ubx.Stack("example", func() {

    		})

    }

## Properties

<ResponseField name="domain" type="string">
  Required. Immutable. Name of the domain that is in the allowlist. e.g. "google.com" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. Resource name of the domain in the allowlist e.g. "allowlistedDomains/0184mhaj1smlusv" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_cloudidentity_policy`.
</Warning>

`google_cloudidentity_v1beta1_policy` defines a Cloud Identity administrative policy (e.g. a group creation or membership restriction) applied across an organization or a specific org unit.

## Properties

<ResponseField name="customer" type="string">
  Immutable. Customer that the Policy belongs to. The value is in the format 'customers/&#123;customerId&#125;'. The `customerId` must begin with "C" To find your customer ID in Admin Console see https://support.google.com/a/answer/10070793. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. The [resource name](https://cloud.google.com/apis/design/resource_names) of the Policy. Format: policies/&#123;policy&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="policy_query" type="object">
  PolicyQuery Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="group" type="string">
      Immutable. The group that the query applies to. This field is only set if there is a single value for group that satisfies all clauses of the query. If no group applies, this will be the empty string. Optional.
    </ResponseField>
    <ResponseField name="org_unit" type="string">
      Required. Immutable. Non-empty default. The OrgUnit the query applies to. This field is only set if there is a single value for org_unit that satisfies all clauses of the query. Optional.
    </ResponseField>
    <ResponseField name="query" type="string">
      Immutable. The CEL query that defines which entities the Policy applies to (ex. a User entity). For details about CEL see https://opensource.google.com/projects/cel. The OrgUnits the Policy applies to are represented by a clause like so: entity.org_units.exists(org_unit, org_unit.org_unit_id == orgUnitId('&#123;orgUnitId&#125;')) The Group the Policy applies to are represented by a clause like so: entity.groups.exists(group, group.group_id == groupId('&#123;groupId&#125;')) The Licenses the Policy applies to are represented by a clause like so: entity.licenses.exists(license, license in ['/product/&#123;productId&#125;/sku/&#123;skuId&#125;']) **Note:** The licenses clause is not supported in mutate endpoints. The above clauses can be present in any combination, and used in conjunction with the &&, || and ! operators. The org_unit and group fields below are helper fields that contain the corresponding value(s) as the query to make the query easier to use. Optional.
    </ResponseField>
    <ResponseField name="sort_order" type="number">
      Output only. The decimal sort order of this PolicyQuery. The value is relative to all other policies with the same setting type for the customer. (There are no duplicates within this set). Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="setting" type="object">
  Setting Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="type" type="string">
      Required. Immutable. The type of the Setting. Optional.
    </ResponseField>
    <ResponseField name="value" type="map(any)">
      Required. The value of the Setting. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  Output only. The type of the policy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

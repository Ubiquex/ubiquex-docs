`google_cloudidentity_allowlisted_domain` permits a specific external Cloud Identity domain to have its own users provisioned or referenced (e.g. as group members) from within the calling organization.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudidentity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudidentity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudidentity/cloudidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own allowlisted domain"})

    		ubx.Resource(cloudidentity.CloudidentityAllowlistedDomain, "ci-runner", cloudidentity.CloudidentityAllowlistedDomainConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="domain" type="string">
  Required. Immutable. Name of the domain that is in the allowlist. e.g. "google.com" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. Resource name of the domain in the allowlist e.g. "allowlistedDomains/0184mhaj1smlusv" Optional; if omitted, computed by Google Cloud.
</ResponseField>

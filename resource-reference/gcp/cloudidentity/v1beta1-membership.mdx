<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_cloudidentity_membership`.
</Warning>

`google_cloudidentity_v1beta1_membership` adds a user, group, or service account as a member of a Cloud Identity group, with a specified role (owner, manager, or member).

<ResponseField name="member_key" type="object">
  A unique identifier for an entity in the Cloud Identity Groups API. An entity can represent either a group with an optional `namespace` or a user without a `namespace`. The combination of `id` and `namespace` must be unique; however, the same `id` can be used with different `namespace`s. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The ID of the entity. For Google-managed entities, the `id` must be the email address of an existing group or user. For external-identity-mapped entities, the `id` must be a string conforming to the Identity Source's requirements. Must be unique within a `namespace`. Optional.
    </ResponseField>
    <ResponseField name="namespace" type="string">
      The namespace in which the entity exists. If not specified, the `EntityKey` represents a Google-managed entity such as a Google user or a Google Group. If specified, the `EntityKey` represents an external-identity-mapped group. The namespace must correspond to an identity source created in Admin Console and must be in the form of `identitysources/&#123;identity_source_id&#125;`. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_cloudidentity_membership` adds a user, group, or service account as a member of a Cloud Identity group, with a specified role (owner, manager, or member).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudidentity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudidentity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudidentity/cloudidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own membership"})

    		ubx.Resource(cloudidentity.CloudidentityMembership, "ci-runner", cloudidentity.CloudidentityMembershipConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

<ResponseField name="preferred_member_key" type="object">
  A unique identifier for an entity in the Cloud Identity Groups API. An entity can represent either a group with an optional `namespace` or a user without a `namespace`. The combination of `id` and `namespace` must be unique; however, the same `id` can be used with different `namespace`s. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The ID of the entity. For Google-managed entities, the `id` should be the email address of an existing group or user. Email addresses need to adhere to [name guidelines for users and groups](https://support.google.com/a/answer/9193374). For external-identity-mapped entities, the `id` must be a string conforming to the Identity Source's requirements. Must be unique within a `namespace`. Optional.
    </ResponseField>
    <ResponseField name="namespace" type="string">
      The namespace in which the entity exists. If not specified, the `EntityKey` represents a Google-managed entity such as a Google user or a Google Group. If specified, the `EntityKey` represents an external-identity-mapped group. The namespace must correspond to an identity source created in Admin Console and must be in the form of `identitysources/&#123;identity_source&#125;`. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

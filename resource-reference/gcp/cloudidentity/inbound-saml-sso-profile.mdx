`google_cloudidentity_inbound_saml_sso_profile` configures Cloud Identity to accept single sign-on from an external SAML identity provider, letting users authenticate with their own third-party IdP credentials.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudidentity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudidentity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudidentity/cloudidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own inbound saml sso profile"})

    		ubx.Resource(cloudidentity.CloudidentityInboundSamlSsoProfile, "example", cloudidentity.CloudidentityInboundSamlSsoProfileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="customer" type="string">
  Immutable. The customer. For example: `customers/C0123abc`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Human-readable name of the SAML SSO profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="idp_config" type="object">
  SAML IDP (identity provider) configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="change_password_uri" type="string">
      The **Change Password URL** of the identity provider. Users will be sent to this URL when changing their passwords at `myaccount.google.com`. This takes precedence over the change password URL configured at customer-level. Must use `HTTPS`. Optional.
    </ResponseField>
    <ResponseField name="entity_id" type="string">
      Required. The SAML **Entity ID** of the identity provider. Optional.
    </ResponseField>
    <ResponseField name="logout_redirect_uri" type="string">
      The **Logout Redirect URL** (sign-out page URL) of the identity provider. When a user clicks the sign-out link on a Google page, they will be redirected to this URL. This is a pure redirect with no attached SAML `LogoutRequest` i.e. SAML single logout is not supported. Must use `HTTPS`. Optional.
    </ResponseField>
    <ResponseField name="single_sign_on_service_uri" type="string">
      Required. The `SingleSignOnService` endpoint location (sign-in page URL) of the identity provider. This is the URL where the `AuthnRequest` will be sent. Must use `HTTPS`. Assumed to accept the `HTTP-Redirect` binding. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. [Resource name](https://cloud.google.com/apis/design/resource_names) of the SAML SSO profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sp_config" type="object">
  SAML SP (service provider) configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="assertion_consumer_service_uri" type="string">
      Output only. The SAML **Assertion Consumer Service (ACS) URL** to be used for the IDP-initiated login. Assumed to accept response messages via the `HTTP-POST` binding. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="entity_id" type="string">
      Output only. The SAML **Entity ID** for this service provider. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_cloudidentity_inbound_oidc_sso_profile` configures Cloud Identity to accept single sign-on from an external OpenID Connect identity provider, letting users authenticate with their own third-party IdP credentials.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own inbound oidc sso profile"})

    		ubx.Resource(cloudidentity.InboundOidcSsoProfile, "example", cloudidentity.InboundOidcSsoProfileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="customer" type="string">
  Immutable. The customer. For example: `customers/C0123abc`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Human-readable name of the OIDC SSO profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="idp_config" type="object">
  OIDC IDP (identity provider) configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="change_password_uri" type="string">
      The **Change Password URL** of the identity provider. Users will be sent to this URL when changing their passwords at `myaccount.google.com`. This takes precedence over the change password URL configured at customer-level. Must use `HTTPS`. Optional.
    </ResponseField>
    <ResponseField name="issuer_uri" type="string">
      Required. The Issuer identifier for the IdP. Must be a URL. The discovery URL will be derived from this as described in Section 4 of [the OIDC specification](https://openid.net/specs/openid-connect-discovery-1_0.html). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. [Resource name](https://cloud.google.com/apis/design/resource_names) of the OIDC SSO profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="rp_config" type="object">
  OIDC RP (relying party) configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="client_id" type="string">
      OAuth2 client ID for OIDC. Optional.
    </ResponseField>
    <ResponseField name="client_secret" type="string">
      Input only. OAuth2 client secret for OIDC. Optional.
    </ResponseField>
    <ResponseField name="redirect_uris" type="list(string)">
      Output only. The URL(s) that this client may use in authentication requests. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_observability_trace_scope` defines a named set of project(s) whose own trace data can be jointly searched together in Cloud Trace, for cross-project distributed tracing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_observability --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_observability/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	observability "github.com/ubiquex/ubx-sdk-google/sdk/go/google_observability/observability"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own trace scope"})

    		ubx.Resource(observability.ObservabilityTraceScope, "ci-runner", observability.ObservabilityTraceScopeConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp of the trace scope. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Describes this trace scope. The maximum length of the description is 8000 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the trace scope. For example: projects/my-project/locations/global/traceScopes/my-trace-scope Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_names" type="list(string)">
  Required. Names of the projects that are included in this trace scope. * `projects/[PROJECT_ID]` A trace scope can include a maximum of 20 projects. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last update timestamp of the trace scope. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v2beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_deploymentmanager_v2beta_type_provider` registers a real external API (its own descriptor_url and credential) as a usable Deployment Manager type source, with collection_overrides and options controlling how that API's own resources map onto Deployment Manager's model -- so a non-Google API can be managed through Deployment Manager the same way a native GCP resource is.

`google_deploymentmanager_alpha_deployment` applies a Deployment Manager configuration -- Google Cloud's original, now-legacy declarative infrastructure templating service, largely superseded by Infrastructure Manager for new work.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	deploymentmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/deploymentmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own alpha deployment"})

    		ubx.Resource(deploymentmanager.AlphaDeployment, "example", deploymentmanager.AlphaDeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="fingerprint" type="string">
  Provides a fingerprint to use in requests to modify a deployment, such as `update()`, `stop()`, and `cancelPreview()` requests. A fingerprint is a randomly generated value that must be provided with `update()`, `stop()`, and `cancelPreview()` requests to perform optimistic locking. This ensures optimistic concurrency so that only one request happens at a time. The fingerprint is initially generated by Deployment Manager and changes after every request to modify data. To get the latest fingerprint value, perform a `get()` request to a deployment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

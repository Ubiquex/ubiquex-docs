`google_deploymentmanager_alpha_composite_type` is a real, reusable Deployment Manager type built by composing existing types (its own template_contents), letting a team define a higher-level, named building block once and reference it from many deployments rather than repeating the same template contents everywhere.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	deploymentmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/deploymentmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own alpha composite type"})

    		ubx.Resource(deploymentmanager.AlphaCompositeType, "example", deploymentmanager.AlphaCompositeTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

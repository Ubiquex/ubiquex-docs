## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_datalineage --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_datalineage/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datalineage "github.com/ubiquex/ubx-sdk-google/sdk/go/google_datalineage/datalineage"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own lineage event"})

    		ubx.Resource(datalineage.DatalineageLineageEvent, "ci-runner", datalineage.DatalineageLineageEventConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="end_time" type="string">
  Optional. The end of the transformation which resulted in this lineage event. For streaming scenarios, it should be the end of the period from which the lineage is being reported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="links" type="list(object)">
  Optional. List of source-target pairs. Can't contain more than 100 tuples. Optional; if omitted, computed by Google Cloud.

        <ResponseField name="dependency_type" type="string">

<ResponseField name="name" type="string">
  Immutable. The resource name of the lineage event. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/processes/&#123;process&#125;/runs/&#123;run&#125;/lineageEvents/&#123;lineage_event&#125;`. Can be specified or auto-assigned. &#123;lineage_event&#125; must be not longer than 200 characters and only contain characters in a set: `a-zA-Z0-9_-:.` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  Required. The beginning of the transformation which resulted in this lineage event. For streaming scenarios, it should be the beginning of the period from which the lineage is being reported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

## Properties

<ResponseField name="end_time" type="string">
  Optional. The end of the transformation which resulted in this lineage event. For streaming scenarios, it should be the end of the period from which the lineage is being reported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="links" type="list(object)">
  Optional. List of source-target pairs. Can't contain more than 100 tuples. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dependency_info" type="object">
      Describes how the `target` entity in this link depends on the `source` entity -- e.g. whether the target is an exact copy of the source. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="dependency_type" type="string">
          The kind of dependency the target has on the source: `EXACT_COPY` (the target's data is copied unchanged from the source) or `OTHER` (any other transformation). Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="source" type="object">
      A reference to the upstream entity data flowed from in this lineage link. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="field" type="list(string)">
          The specific field(s) of the source entity this link traces data from, when the lineage is tracked at field level rather than whole-entity level. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="fully_qualified_name" type="string">
          The fully qualified name identifying the source entity (e.g. a BigQuery table's own `project.dataset.table` path). Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="target" type="object">
      A reference to the downstream entity data flowed to in this lineage link. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="field" type="list(string)">
          The specific field(s) of the target entity this link traces data into, when the lineage is tracked at field level rather than whole-entity level. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="fully_qualified_name" type="string">
          The fully qualified name identifying the target entity (e.g. a BigQuery table's own `project.dataset.table` path). Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the lineage event. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/processes/&#123;process&#125;/runs/&#123;run&#125;/lineageEvents/&#123;lineage_event&#125;`. Can be specified or auto-assigned. &#123;lineage_event&#125; must be not longer than 200 characters and only contain characters in a set: `a-zA-Z0-9_-:.` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  Required. The beginning of the transformation which resulted in this lineage event. For streaming scenarios, it should be the beginning of the period from which the lineage is being reported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_datalineage --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_datalineage/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datalineage "github.com/ubiquex/ubx-sdk-google/sdk/go/google_datalineage/datalineage"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own process"})

    		ubx.Resource(datalineage.DatalineageProcess, "ci-runner", datalineage.DatalineageProcessConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="attributes" type="map(any)">
  Optional. The attributes of the process. Should only be used for the purpose of non-semantic management (classifying, describing or labeling the process). Up to 100 attributes are allowed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. A human-readable name you can set to display in a user interface. Must be not longer than 200 characters and only contain UTF-8 letters or numbers, spaces or characters like `_-:&.` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the lineage process. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/processes/&#123;process&#125;`. Can be specified or auto-assigned. &#123;process&#125; must be not longer than 200 characters and only contain characters in a set: `a-zA-Z0-9_-:.` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="origin" type="object">
  Origin of a process. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      If the source_type isn't CUSTOM, the value of this field should be a Google Cloud resource name of the system, which reports lineage. The project and location parts of the resource name must match the project and location of the lineage resource being created. Examples: - `&#123;source_type: COMPOSER, name: "projects/foo/locations/us/environments/bar"&#125;` - `&#123;source_type: BIGQUERY, name: "projects/foo/locations/eu"&#125;` - `&#123;source_type: CUSTOM, name: "myCustomIntegration"&#125;` Optional.
    </ResponseField>
    <ResponseField name="source_type" type="string">
      Type of the source. Use of a source_type other than `CUSTOM` for process creation or updating is highly discouraged. It might be restricted in the future without notice. There will be increase in cost if you use any of the source types other than `CUSTOM`. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

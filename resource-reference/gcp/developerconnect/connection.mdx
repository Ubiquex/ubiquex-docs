title: "google_developerconnect_connection"
description: "`google_developerconnect_connection` establishes a Developer Connect link to a third-party source code platform (GitHub, GitLab, and similar)..."
---

`google_developerconnect_connection` establishes a Developer Connect link to a third-party source code platform (GitHub, GitLab, and similar), the resource git repository links are created under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	developerconnect "github.com/ubiquex/ubx-sdk-google/sdk/go/google/developerconnect"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connection"})

    		ubx.Resource(developerconnect.Connection, "example", developerconnect.ConnectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {

      resource(Connection, "example", {
        name: "example",
      });
    });
    ```

`google_developerconnect_account_connector` links a Google Cloud project to a developer's own OAuth-authorized account on an external platform (e.g. GitHub), the credential Developer Connect connections are created under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	developerconnect "github.com/ubiquex/ubx-sdk-google/sdk/go/google/developerconnect"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own account connector"})

    		ubx.Resource(developerconnect.AccountConnector, "example", developerconnect.AccountConnectorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

      Required. The host URI of the OAuth application. Optional.

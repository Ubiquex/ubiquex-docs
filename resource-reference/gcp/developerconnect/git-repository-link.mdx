`google_developerconnect_git_repository_link` links a specific external Git repository into Google Cloud through a Developer Connect connection, enabling CI/CD and AI-assisted development integrations against it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_developerconnect --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_developerconnect/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	developerconnect "github.com/ubiquex/ubx-sdk-google/sdk/go/google_developerconnect/developerconnect"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own git repository link"})

    		ubx.Resource(developerconnect.DeveloperconnectGitRepositoryLink, "ci-runner", developerconnect.DeveloperconnectGitRepositoryLinkConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="annotations" type="map(string)">
  Optional. Allows clients to store small amounts of arbitrary data. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="clone_uri" type="string">
  Required. Git Clone URI. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. [Output only] Create timestamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. [Output only] Delete timestamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. This checksum is computed by the server based on the value of other fields, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="git_proxy_uri" type="string">
  Output only. URI to access the linked repository through the Git Proxy. This field is only populated if the git proxy is enabled for the connection. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the repository, in the format `projects/*/locations/*/connections/*/gitRepositoryLinks/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reconciling" type="bool">
  Output only. Set to true when the connection is being set up or updated in the background. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. A system-assigned unique identifier for the GitRepositoryLink. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. [Output only] Update timestamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="webhook_id" type="string">
  Output only. External ID of the webhook created for the repository. Optional; if omitted, computed by Google Cloud.
</ResponseField>

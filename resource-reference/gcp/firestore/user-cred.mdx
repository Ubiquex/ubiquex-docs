`google_firestore_user_cred` is a database-scoped credential Firestore issues for authenticating directly to a specific database, independent of and narrower in scope than a Google Cloud IAM principal.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firestore --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firestore/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firestore "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firestore/firestore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user cred"})

    		ubx.Resource(firestore.FirestoreUserCred, "example", firestore.FirestoreUserCredConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time the user creds were created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the UserCreds. Format: `projects/&#123;project&#125;/databases/&#123;database&#125;/userCreds/&#123;user_creds&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_identity" type="object">
  Describes a Resource Identity principal. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="principal" type="string">
      Output only. Principal identifier string. See: https://cloud.google.com/iam/docs/principal-identifiers Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="secure_password" type="string">
  Output only. The plaintext server-generated password for the user creds. Only populated in responses for CreateUserCreds and ResetUserPassword. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Whether the user creds are enabled or disabled. Defaults to ENABLED on creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the user creds were last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_firestore_change_stream` continuously streams a Firestore database's own document changes (creates, updates, deletes) for a collection group or the whole database, for change-data-capture style integrations.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firestore --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firestore/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firestore "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firestore/firestore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own change stream"})

    		ubx.Resource(firestore.FirestoreChangeStream, "example", firestore.FirestoreChangeStreamConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="collection_group_scope" type="object">
  The change stream is scoped to a collection group. Only events associated with the given collection group are visible to the Change Stream. Only a single change stream can be enabled per collection group. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="collection_group_id" type="string">
      Required. The collection group name. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the Change Stream was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="database_scope" type="any">
  The change stream is scoped to the entire database. All events in the database are visible to the Change Stream. One Database scope Change Stream is allowed per database. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. An etag used to determine which version of the configuration is being edited. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The external resource name of the change stream. Format `projects/&#123;project&#125;/databases/&#123;database&#125;/changeStreams/&#123;change_stream&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="retention_period" type="string">
  Required. The retention period of the change stream. This is the amount of time a change event is available on the change stream. Must be from 1 to 7 days, inclusive. The retention_period must be in day granularity, i.e. it must be a multiple of 24 hours. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  Output only. The time the Change Stream started recording events. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the Change Stream was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

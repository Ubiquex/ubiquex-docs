`google_firestore_index` defines a composite or single-field index on a Firestore database, required for certain query shapes (e.g. filtering and sorting on different fields) to run efficiently.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firestore --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firestore/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firestore "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firestore/firestore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own index"})

    		ubx.Resource(firestore.FirestoreIndex, "example", firestore.FirestoreIndexConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="api_scope" type="string">
  The API scope supported by this index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="density" type="string">
  Immutable. The density configuration of the index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fields" type="list(object)">
  The fields supported by this index. At most 100 fields may be specified. In Standard edition databases only: - At least 2 fields must be specified. - The last field entry is always for the field path `__name__`. If, on creation, `__name__` was not specified as the last field, it will be added automatically with the same direction as that of the last field defined. If the final field in the index is not directional, the `__name__` will be ordered ASCENDING (unless explicitly specified). Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

    <ResponseField name="field_path" type="string">
      The document field this index entry covers, in dot notation. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="order" type="string">
      The sort direction this index supports for `field_path`: `ASCENDING` or `DESCENDING`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="search_config" type="object">
      Configures `field_path` as a full-text or geo search index, rather than a standard ordered/array index. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**

          <Expandable title="properties">

<ResponseField name="multikey" type="bool">
  Optional. Whether the index is multikey. By default, the index is not multikey. For non-multikey indexes, none of the paths in the index definition reach or traverse an array, except via an explicit array index. For multikey indexes, at most one of the paths in the index definition reach or traverse an array, except via an explicit array index. Violations will result in errors. Note this field only applies to index with MONGODB_COMPATIBLE_API ApiScope. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  A server-defined name for this index. Output only. When used in the google.firestore.admin.v1.Index resource, the value is of the form: `projects/&#123;project_id&#125;/databases/&#123;database_id&#125;/collectionGroups/&#123;collection_id&#125;/indexes/&#123;index_id&#125;` When used in the google.firestore.admin.v1.Field resource, the value is empty. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="query_scope" type="string">
  Indexes with a collection query scope specified allow queries against a collection that is the child of a specific document, specified at query time, and that has the same collection ID. Indexes with a collection group query scope specified allow queries against all collections descended from a specific document, specified at query time, and that have the same collection ID as this index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="search_index_options" type="object">
  Options for search indexes at the definition level. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="text_language" type="string">
      Optional. The language to use for text search indexes. Used as the default language if not overridden at the document level by specifying the `text_language_override_field`. The language is specified as a BCP 47 language code. For indexes with MONGODB_COMPATIBLE_API ApiScope: If unspecified, the default language is English. For indexes with `ANY_API` ApiScope: If unspecified, the default behavior is autodetect. Optional.
    </ResponseField>
    <ResponseField name="text_language_override_field_path" type="string">
      Optional. The field in the document that specifies which language to use for that specific document. For indexes with MONGODB_COMPATIBLE_API ApiScope: if unspecified, the language is taken from the "language" field if it exists or from `text_language` if it does not. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="shard_count" type="number">
  Optional. The number of shards for the index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The serving state of the index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="unique" type="bool">
  Optional. Whether it is an unique index. Unique index ensures all values for the indexed field(s) are unique across documents. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_firestore_index` -- real, typed bindings generated directly from the
`hashicorp/google` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-google/sdk/go/google/firestore"
    )

    cfg := firestore.IndexConfig{
        Collection: "example",
        ApiScope: "example",
        Database: "example",
    }
    ubx.Resource(firestore.Index, "example", cfg)
    ```

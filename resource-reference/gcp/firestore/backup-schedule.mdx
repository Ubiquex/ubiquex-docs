`google_firestore_backup_schedule` automates recurring Firestore database backups on a defined cadence, instead of requiring each backup to be triggered manually.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firestore --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firestore/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firestore "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firestore/firestore"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own backup schedule"})

    		ubx.Resource(firestore.FirestoreBackupSchedule, "ci-runner", firestore.FirestoreBackupScheduleConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp at which this backup schedule was created and effective since. No backups will be created for this schedule before this time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="daily_recurrence" type="any">
  Represents a recurring schedule that runs every day. The time zone is UTC. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The unique backup schedule identifier across all locations and databases for the given project. This will be auto-assigned. Format is `projects/&#123;project&#125;/databases/&#123;database&#125;/backupSchedules/&#123;backup_schedule&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="retention" type="string">
  At what relative time in the future, compared to its creation time, the backup should be deleted, e.g. keep backups for 7 days. The maximum supported retention period is 14 weeks. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp at which this backup schedule was most recently updated. When a backup schedule is first created, this is the same as create_time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="weekly_recurrence" type="object">
  Represents a recurring schedule that runs on a specified day of the week. The time zone is UTC. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="day" type="string">
      The day of week to run. DAY_OF_WEEK_UNSPECIFIED is not allowed. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

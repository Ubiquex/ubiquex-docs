`google_firestore_field` -- real, typed bindings generated directly from the
`hashicorp/google` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-google-go/google/firestore"
    )

    cfg := firestore.FieldConfig{
        Collection: "example",
        Field: "example",
        Database: "example",
        SkipWait: true,
    }
    ubx.Resource(firestore.Field, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Field } from
      "jsr:@ubx/sdk-google/google/firestore/field";

    resource(Field, "example", {
      collection: "example",
      field: "example",
      database: "example",
      skipWait: true,
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.google.firestore import Field, FieldConfig

    cfg = FieldConfig(
        collection="example",
        field="example",
        database="example",
        skip_wait=True,
    )
    ubx.resource(Field, "example", cfg)
    ```
  </Tab>

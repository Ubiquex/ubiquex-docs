`google_healthcare_dataset` is the top-level container in the Cloud Healthcare API that FHIR, DICOM, and HL7v2 store(s) are created within, grouping related health data under shared location and access policy.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	healthcare "github.com/ubiquex/ubx-sdk-google/sdk/go/google/healthcare"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dataset"})

    		ubx.Resource(healthcare.Dataset, "example", healthcare.DatasetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="encryption_spec" type="object">
  Represents a customer-managed encryption key spec that can be applied to a resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_name" type="string">
      Required. The resource name of customer-managed encryption key that is used to secure a resource and its sub-resources. Only the key in the same location as this Dataset is allowed to be used for encryption. Format is: `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyRing&#125;/cryptoKeys/&#123;key&#125;` Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the dataset, of the form `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/datasets/&#123;dataset_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Whether the dataset satisfies zone isolation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Whether the dataset satisfies zone separation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="time_zone" type="string">
  Optional. The default timezone used by this dataset. Must be a either a valid IANA time zone name such as "America/New_York" or empty, which defaults to UTC. This is used for parsing times in resources, such as HL7 messages, where no explicit timezone is specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_healthcare_user_data_mapping`.
</Warning>

`google_healthcare_v1beta1_user_data_mapping` links a specific piece of health data to the patient user it belongs to, within a Cloud Healthcare API consent store, so consent decisions can be evaluated per patient.

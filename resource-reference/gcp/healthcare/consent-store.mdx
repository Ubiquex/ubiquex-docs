`google_healthcare_consent_store` holds patient consent record(s) and their own supporting artifact(s), letting Cloud Healthcare API data access be automatically checked against recorded patient consent.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	healthcare "github.com/ubiquex/ubx-sdk-google/sdk/go/google/healthcare"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own consent store"})

    		ubx.Resource(healthcare.ConsentStore, "example", healthcare.ConsentStoreConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="default_consent_ttl" type="string">
  Optional. Default time to live for Consents created in this store. Must be at least 24 hours. Updating this field will not affect the expiration time of existing consents. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enable_consent_create_on_update" type="bool">
  Optional. If `true`, UpdateConsent creates the Consent if it does not already exist. If unspecified, defaults to `false`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-supplied key-value pairs used to organize consent stores. Label keys must be between 1 and 63 characters long, have a UTF-8 encoding of maximum 128 bytes, and must conform to the following PCRE regular expression: \p&#123;Ll&#125;\p&#123;Lo&#125;&#123;0,62&#125;. Label values must be between 1 and 63 characters long, have a UTF-8 encoding of maximum 128 bytes, and must conform to the following PCRE regular expression: [\p&#123;Ll&#125;\p&#123;Lo&#125;\p&#123;N&#125;_-]&#123;0,63&#125;. No more than 64 labels can be associated with a given store. For more information: https://cloud.google.com/healthcare/docs/how-tos/labeling-resources Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the consent store, of the form `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/datasets/&#123;dataset_id&#125;/consentStores/&#123;consent_store_id&#125;`. Cannot be changed after creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

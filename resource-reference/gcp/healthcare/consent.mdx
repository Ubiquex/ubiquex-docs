`google_healthcare_consent` records a single patient's own consent decision (granted or revoked) for a defined use of their health data, managed within a Cloud Healthcare API consent store.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	healthcare "github.com/ubiquex/ubx-sdk-google/sdk/go/google/healthcare"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own consent"})

    		ubx.Resource(healthcare.Consent, "example", healthcare.ConsentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_healthcare_message`.
</Warning>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	healthcare "github.com/ubiquex/ubx-sdk-google/sdk/go/google/healthcare"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 message"})

    		ubx.Resource(healthcare.V1beta1Message, "example", healthcare.V1beta1MessageConfig{
    			Message: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="message" type="object">
  A complete HL7v2 message. See [Introduction to HL7 Standards] (https://www.hl7.org/implement/standards/index.cfm?ref=common) for details on the standard. Optional.
  <Expandable title="properties">
    <ResponseField name="create_time" type="string">
      Output only. The datetime when the message was created. Set by the server. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="data" type="string">
      Required. Raw message bytes. Optional.
    </ResponseField>
    <ResponseField name="labels" type="map(string)">
      User-supplied key-value pairs used to organize HL7v2 stores. Label keys must be between 1 and 63 characters long, have a UTF-8 encoding of maximum 128 bytes, and must conform to the following PCRE regular expression: \p&#123;Ll&#125;\p&#123;Lo&#125;&#123;0,62&#125; Label values are optional, must be between 1 and 63 characters long, have a UTF-8 encoding of maximum 128 bytes, and must conform to the following PCRE regular expression: [\p&#123;Ll&#125;\p&#123;Lo&#125;\p&#123;N&#125;_-]&#123;0,63&#125; No more than 64 labels can be associated with a given store. Optional.
    </ResponseField>
    <ResponseField name="message_type" type="string">
      The message type for this message. MSH-9.1. Optional.
    </ResponseField>

    </ResponseField>

`google_healthcare_v1beta1_consent_artifact` is the immutable record of evidence (e.g. a signed consent form) supporting a specific consent decision in a Cloud Healthcare API consent store.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	healthcare "github.com/ubiquex/ubx-sdk-google/sdk/go/google/healthcare"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 consent artifact"})

    		ubx.Resource(healthcare.V1beta1ConsentArtifact, "example", healthcare.V1beta1ConsentArtifactConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

      <Expandable title="properties">
        <ResponseField name="gcs_uri" type="string">
          Input only. Points to a Cloud Storage URI containing the consent artifact content. The URI must be in the following format: `gs://&#123;bucket_id&#125;/&#123;object_id&#125;`. The Cloud Healthcare API service account must have the `roles/storage.objectViewer` Cloud IAM role for this Cloud Storage location. The consent artifact content at this URI is copied to a Cloud Storage location managed by the Cloud Healthcare API. Responses to fetching requests return the consent artifact content in raw_bytes. Optional.
        </ResponseField>
        <ResponseField name="raw_bytes" type="string">
          Consent artifact content represented as a stream of bytes. This field is populated when returned in GetConsentArtifact response, but not included in CreateConsentArtifact and ListConsentArtifact response. Optional.

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_healthcare_attribute_definition`.
</Warning>

`google_healthcare_v1beta1_attribute_definition` defines a named consent attribute (e.g. a patient's own opt-in category) that consent artifacts in a Cloud Healthcare API consent store can be evaluated against.

## Properties

<ResponseField name="allowed_values" type="list(string)">
  Required. Possible values for the attribute. The number of allowed values must not exceed 500. An empty list is invalid. The list can only be expanded after creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="category" type="string">
  Required. The category of the attribute. The value of this field cannot be changed after creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="consent_default_values" type="list(string)">
  Optional. Default values of the attribute in Consents. If no default values are specified, it defaults to an empty value. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="data_mapping_default_value" type="string">
  Optional. Default value of the attribute in User data mappings. If no default value is specified, it defaults to an empty value. This field is only applicable to attributes of the category `RESOURCE`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of the attribute. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the Attribute definition, of the form `projects/&#123;project_id&#125;/locations/&#123;location_id&#125;/datasets/&#123;dataset_id&#125;/consentStores/&#123;consent_store_id&#125;/attributeDefinitions/&#123;attribute_definition_id&#125;`. Cannot be changed after creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

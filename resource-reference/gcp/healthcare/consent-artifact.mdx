`google_healthcare_consent_artifact` is the immutable record of evidence (e.g. a signed consent form) supporting a specific consent decision in a Cloud Healthcare API consent store.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_healthcare --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_healthcare/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	healthcare "github.com/ubiquex/ubx-sdk-google/sdk/go/google_healthcare/healthcare"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own consent artifact"})

    		ubx.Resource(healthcare.HealthcareConsentArtifact, "example", healthcare.HealthcareConsentArtifactConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_healthcare_dataset`.
</Warning>

`google_healthcare_v1beta1_dataset` is the top-level container in the Cloud Healthcare API that FHIR, DICOM, and HL7v2 store(s) are created within, grouping related health data under shared location and access policy.

`google_bigquery_row_access_policy` restricts which row(s) of a BigQuery table a given principal can see, filtering query results based on the row's own data.

## Properties

<ResponseField name="creation_time" type="string">
  Output only. The time when this row access policy was created, in milliseconds since the epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. A hash of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter_predicate" type="string">
  Required. A SQL boolean expression that represents the rows defined by this row access policy, similar to the boolean expression in a WHERE clause of a SELECT query on a table. References to other tables, routines, and temporary functions are not supported. Examples: region="EU" date_field = CAST('2019-9-27' as DATE) nullable_field is not NULL numeric_field BETWEEN 1.0 AND 5.0 Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="grantees" type="list(string)">
  Optional. Input only. The optional list of iam_member users or groups that specifies the initial members that the row-level access policy should be created with. grantees types: - "user:alice@example.com": An email address that represents a specific Google account. - "serviceAccount:my-other-app@appspot.gserviceaccount.com": An email address that represents a service account. - "group:admins@example.com": An email address that represents a Google group. - "domain:example.com":The Google Workspace domain (primary) that represents all the users of that domain. - "allAuthenticatedUsers": A special identifier that represents all service accounts and all users on the internet who have authenticated with a Google Account. This identifier includes accounts that aren't connected to a Google Workspace or Cloud Identity domain, such as personal Gmail accounts. Users who aren't authenticated, such as anonymous visitors, aren't included. - "allUsers":A special identifier that represents anyone who is on the internet, including authenticated and unauthenticated users. Because BigQuery requires authentication before a user can access the service, allUsers includes only authenticated users. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_modified_time" type="string">
  Output only. The time when this row access policy was last modified, in milliseconds since the epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="row_access_policy_reference" type="object">
  Id path of a row access policy. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dataset_id" type="string">
      Required. The ID of the dataset containing this row access policy. Optional.
    </ResponseField>
    <ResponseField name="policy_id" type="string">
      Required. The ID of the row access policy. The ID must contain only letters (a-z, A-Z), numbers (0-9), or underscores (_). The maximum length is 256 characters. Optional.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      Required. The ID of the project containing this row access policy. Optional.
    </ResponseField>
    <ResponseField name="table_id" type="string">
      Required. The ID of the table containing this row access policy. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

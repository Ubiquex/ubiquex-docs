## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_datafusion --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_datafusion/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datafusion "github.com/ubiquex/ubx-sdk-google/sdk/go/google_datafusion/datafusion"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own instance"})

    		ubx.Resource(datafusion.DatafusionInstance, "ci-runner", datafusion.DatafusionInstanceConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

  Network configuration for a Data Fusion instance. These configurations are used for peering with the customer network. Configurations are optional when a public Data Fusion instance is to be created. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="connection_type" type="string">

    </ResponseField>
    <ResponseField name="ip_allocation" type="string">
      Optional. The IP range in CIDR notation to use for the managed Data Fusion instance nodes. This range must not overlap with any other ranges used in the Data Fusion instance network.     </ResponseField>
    <ResponseField name="network" type="string">
      Optional. Name of the network in the customer project with which the Tenant Project will be peered for executing pipelines. In case of shared VPC where the network resides in another host project the network should specified in the form of projects/&#123;host-project-id&#125;/global/networks/&#123;network&#125;. This is only required for connectivity type VPC_PEERING. Optional.
    </ResponseField>

        </ResponseField>
        <ResponseField name="network_attachment" type="string">
          Required. The reference to the network attachment used to establish private connectivity. It will be of the form projects/&#123;project-id&#125;/regions/&#123;region&#125;/networkAttachments/&#123;network-attachment-id&#125;. Optional.
        </ResponseField>
        <ResponseField name="unreachable_cidr_block" type="string">
          Optional. Input only. The CIDR block to which the CDF instance can't route traffic to in the consumer project VPC. The size of this block should be at least /25. This range should not overlap with the primary address range of any subnetwork used by the network attachment. This range can be used for other purposes in the consumer VPC as long as there is no requirement for CDF to reach destinations using these addresses. If this value is not provided, the server chooses a non RFC 1918 address range. The format of this field is governed by RFC 4632. Example: 192.168.0.0/25 Optional.

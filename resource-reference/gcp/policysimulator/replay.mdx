`google_policysimulator_replay` is a Policy Simulator replay, re-evaluating real past IAM access attempts under both a resource's current policy and a proposed policy change, then comparing the two results to show exactly how a member's access would change if the proposed policy were applied.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own replay"})

    		ubx.Resource(policysimulator.Replay, "example", policysimulator.ReplayConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

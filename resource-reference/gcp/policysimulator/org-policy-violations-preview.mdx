title: "google_policysimulator_org_policy_violations_preview"
description: "`google_policysimulator_org_policy_violations_preview` previews the real resources that would violate a proposed organization policy change before it's..."
---

`google_policysimulator_org_policy_violations_preview` previews the real resources that would violate a proposed organization policy change before it's enforced, listing every affected resource so it can be fixed, excepted, or the policy's own scope adjusted, without any actual enforcement or downtime.

<ResponseField name="resource_counts" type="object">
  A summary of the state of all resources scanned for compliance with the changed OrgPolicy. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="compliant" type="number">
      Output only. Number of scanned resources with zero violations. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="errors" type="number">
      Output only. Number of resources that returned an error when scanned. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="noncompliant" type="number">
      Output only. Number of scanned resources with at least one violation. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="scanned" type="number">
      Output only. Number of resources checked for compliance. Must equal: unenforced + noncompliant + compliant + error Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="unenforced" type="number">
      Output only. Number of resources where the constraint was not enforced, i.e. the Policy set `enforced: false` for that resource. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the `OrgPolicyViolationsPreview`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="violations_count" type="number">
  Output only. The number of OrgPolicyViolations in this `OrgPolicyViolationsPreview`. This count may differ from `resource_summary.noncompliant_count` because each OrgPolicyViolation is specific to a resource **and** constraint. If there are multiple constraints being evaluated (i.e. multiple policies in the overlay), a single resource may violate multiple constraints. Optional; if omitted, computed by Google Cloud.
</ResponseField>

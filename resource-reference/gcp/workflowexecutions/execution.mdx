`google_workflowexecutions_execution` is a real, running or completed instance of a Google Cloud Workflows workflow, carrying the execution's own start/end timing, state, JSON input and output, and any error that caused it to finish prematurely.

## Example

  <Tab title="Go">
    ```go

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workflowexecutions "github.com/ubiquex/ubx-sdk-google/sdk/go/google_workflowexecutions/workflowexecutions"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own execution"})

    		ubx.Resource(workflowexecutions.WorkflowexecutionsExecution, "example", workflowexecutions.WorkflowexecutionsExecutionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="argument" type="string">
  Input parameters of the execution represented as a JSON string. The size limit is 32KB. *Note*: If you are using the REST API directly to run your workflow, you must escape any JSON string value of `argument`. Example: `'&#123;"argument":"&#123;\"firstName\":\"FIRST\",\"lastName\":\"LAST\"&#125;"&#125;'` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="call_log_level" type="string">
  The call logging level associated to this execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Marks the creation of the execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disable_concurrency_quota_overflow_buffering" type="bool">
  Optional. If set to true, the execution will not be backlogged when the concurrency quota is exhausted. The backlog execution starts when the concurrency quota becomes available. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="duration" type="string">
  Output only. Measures the duration of the execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Output only. Marks the end of execution, successful or not. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="error" type="object">
  Error describes why the execution was abnormally terminated. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="context" type="string">
      Human-readable stack trace string. Optional.
    </ResponseField>
    <ResponseField name="payload" type="string">
      Error message and data returned represented as a JSON string. Optional.
    </ResponseField>
    <ResponseField name="stack_trace" type="object">
      A collection of stack elements (frames) where an error occurred. Optional.
      <Expandable title="properties">
        <ResponseField name="elements" type="list(object)">
          An array of stack elements. Optional.
          <Expandable title="properties">
            <ResponseField name="position" type="object">
              The real, source-code position (line, column, length) this stack trace element points at. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
              <Expandable title="properties">
                <ResponseField name="column" type="string">
                  The real, zero-based column number this stack trace position points at. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="length" type="string">
                  The real number of characters this stack trace position spans. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
                </ResponseField>
                <ResponseField name="line" type="string">
                  The real, one-based line number this stack trace position points at. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="routine" type="string">
              The real, named workflow step or subworkflow this stack trace element was executing in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="step" type="string">
              The real, named step within the `routine` this stack trace element points at. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="execution_history_level" type="string">
  Optional. Describes the execution history level to apply to this execution. If not specified, the execution history level is determined by its workflow's execution history level. If the levels are different, the executionHistoryLevel overrides the workflow's execution history level for this execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels associated with this execution. Labels can contain at most 64 entries. Keys and values can be no longer than 63 characters and can only contain lowercase letters, numeric characters, underscores, and dashes. Label keys must start with a letter. International characters are allowed. By default, labels are inherited from the workflow but are overridden by any labels associated with the execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the execution. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/workflows/&#123;workflow&#125;/executions/&#123;execution&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="result" type="string">
  Output only. Output of the execution represented as a JSON string. The value can only be present if the execution's state is `SUCCEEDED`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  Output only. Marks the beginning of execution. Note that this will be the same as `createTime` for executions that start immediately. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Current state of the execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_error" type="object">
  Describes an error related to the current state of the Execution resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="details" type="string">
      Provides specifics about the error. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      The type of this state error. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="object">
  Represents the current status of this execution. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="current_steps" type="list(object)">
      A list of currently executing or last executed step names for the workflow execution currently running. If the workflow has succeeded or failed, this is the last attempted or executed step. Presently, if the current step is inside a subworkflow, the list only includes that step. In the future, the list will contain items for each step in the call stack, starting with the outermost step in the `main` subworkflow, and ending with the most deeply nested step. Optional.
      <Expandable title="properties">
        <ResponseField name="routine" type="string">
          The real, named workflow step or subworkflow this stack trace element was executing in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="step" type="string">
          The real, named step within the `routine` this stack trace element points at. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="workflow_revision_id" type="string">
  Output only. Revision of the workflow this execution is using. Optional; if omitted, computed by Google Cloud.
</ResponseField>

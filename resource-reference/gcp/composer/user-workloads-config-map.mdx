`google_composer_user_workloads_config_map` is a Kubernetes ConfigMap deployed into a Cloud Composer environment's own underlying GKE cluster, made available to user Airflow task workloads.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	composer "github.com/ubiquex/ubx-sdk-google/sdk/go/google/composer"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own user workloads config map"})

    		ubx.Resource(composer.UserWorkloadsConfigMap, "example", composer.UserWorkloadsConfigMapConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

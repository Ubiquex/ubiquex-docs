`google_networkconnectivity_gateway_advertised_route` is a route a Network Connectivity Center gateway advertises out to its own connected spoke(s), controlling what destinations the hub tells other spokes are reachable.

## Example

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own gateway advertised route"})

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time the gateway advertised route was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of the gateway advertised route. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ip_range" type="string">
  Immutable. This route's advertised IP address range. Must be a valid CIDR-formatted prefix. If an IP address is provided without a subnet mask, it is interpreted as, for IPv4, a `/32` singular IP address range, and, for IPv6, `/128`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional labels in key-value pair format. For more information about labels, see [Requirements for labels](https://cloud.google.com/resource-manager/docs/creating-managing-labels#requirements). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the gateway advertised route. Route names must be unique and use the following form: `projects/&#123;project_number&#125;/locations/&#123;region&#125;/spokes/&#123;spoke&#125;/gatewayAdvertisedRoutes/&#123;gateway_advertised_route_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="priority" type="number">
  Optional. The priority of this advertised route. You can choose a value from `0` to `65335`. If you don't provide a value, Google Cloud assigns a priority of `100` to the ranges. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="recipient" type="string">
  Optional. The recipient of this advertised route. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current lifecycle state of this gateway advertised route. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="unique_id" type="string">
  Output only. The Google-generated UUID for the gateway advertised route. This value is unique across all gateway advertised route resources. If a gateway advertised route is deleted and another with the same name is created, the new route is assigned a different `unique_id`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the gateway advertised route was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

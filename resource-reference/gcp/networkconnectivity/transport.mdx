`google_networkconnectivity_transport` defines the underlying transport-layer resource (e.g. a specific interconnect or VPN tunnel) a Network Connectivity Center spoke's own connectivity is actually carried over.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own transport"})

    		ubx.Resource(networkconnectivity.Transport, "example", networkconnectivity.TransportConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="advertised_routes" type="list(string)">
  Optional. List of IP Prefixes that will be advertised to the remote provider. Both IPv4 and IPv6 addresses are supported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="bandwidth" type="string">
  Optional. Bandwidth of the Transport. This must be one of the supported bandwidths for the remote profile, and must be set when no activation key is being provided. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the Transport. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="generated_activation_key" type="string">
  Output only. Google-generated activation key. This is only output if the selected profile supports an OUTPUT key flow. Inputting this to the provider is only valid while the resource is in a PENDING_KEY state. Once the provider has accepted the key, the resource will move to the CONFIGURING state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="mtu_limit" type="number">
  Output only. The maximum transmission unit (MTU) of a packet that can be sent over this transport. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Optional. Immutable. Resource URI of the Network that will be peered with this Transport. This field must be provided during resource creation and cannot be changed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peering_network" type="string">
  Output only. VPC Network URI that was created for the VPC Peering connection to the provided `network`. If VPC Peering is disconnected, this can be used to re-establish. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="provided_activation_key" type="string">
  Optional. Immutable. Key used for establishing a connection with the remote transport. This key can only be provided if the profile supports an INPUT key flow and the resource is in the PENDING_KEY state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="remote_account_id" type="string">
  Optional. Immutable. The user supplied account id for the CSP associated with the remote profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="remote_profile" type="string">
  Optional. Immutable. Name of the remoteTransportProfile that this Transport is connecting to. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="stack_type" type="string">
  Optional. IP version stack for the established connectivity. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the underlying connectivity. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

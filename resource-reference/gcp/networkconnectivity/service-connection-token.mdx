`google_networkconnectivity_service_connection_token` is a one-time credential a service producer issues to authorize a specific consumer network to establish a Private Service Connect connection to its own service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service connection token"})

    		ubx.Resource(networkconnectivity.ServiceConnectionToken, "example", networkconnectivity.ServiceConnectionTokenConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

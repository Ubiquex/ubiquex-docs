`google_networkconnectivity_hub` is the central resource in Network Connectivity Center that VPC network(s), VPN/interconnect connections, and other spoke(s) attach to, enabling any-to-any connectivity across them.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time the hub was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. An optional description of the hub. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="export_psc" type="bool">
  Optional. Whether Private Service Connect connection propagation is enabled for the hub. If true, Private Service Connect endpoints in VPC spokes attached to the hub are made accessible to other VPC spokes attached to the hub. The default value is false. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional labels in key-value pair format. For more information about labels, see [Requirements for labels](https://cloud.google.com/resource-manager/docs/creating-managing-labels#requirements). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The name of the hub. Hub names must be unique. They use the following form: `projects/&#123;project_number&#125;/locations/global/hubs/&#123;hub_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="policy_mode" type="string">
  Optional. The policy mode of this hub. This field can be either PRESET or CUSTOM. If unspecified, the policy_mode defaults to PRESET. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="preset_topology" type="string">
  Optional. The topology implemented in this hub. Currently, this field is only used when policy_mode = PRESET. The available preset topologies are MESH and STAR. If preset_topology is unspecified and policy_mode = PRESET, the preset_topology defaults to MESH. When policy_mode = CUSTOM, the preset_topology is set to PRESET_TOPOLOGY_UNSPECIFIED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="route_tables" type="list(string)">
  Output only. The route tables that belong to this hub. They use the following form: `projects/&#123;project_number&#125;/locations/global/hubs/&#123;hub_id&#125;/routeTables/&#123;route_table_id&#125;` This field is read-only. Network Connectivity Center automatically populates it based on the route tables nested under the hub. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="routing_vpcs" type="list(object)">
  Output only. The VPC networks associated with this hub's spokes. This field is read-only. Network Connectivity Center automatically populates it based on the set of spokes attached to the hub. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

</ResponseField>

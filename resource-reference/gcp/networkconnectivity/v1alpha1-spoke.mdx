<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_networkconnectivity_spoke`.
</Warning>

`google_networkconnectivity_v1alpha1_spoke` attaches a single network resource (a VPC network, VPN tunnel, interconnect attachment, or router appliance) to a Network Connectivity Center hub, making it part of that hub's own any-to-any topology.

    func main() {

    		})
    	}))
    }

## Properties

<ResponseField name="create_time" type="string">
  The time when the Spoke was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Short description of the spoke resource Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hub" type="string">
  The resource URL of the hub resource that the spoke is attached to Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  User-defined labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="linked_interconnect_attachments" type="list(string)">
  The URIs of linked interconnect attachment resources Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">

</ResponseField>

<ResponseField name="unique_id" type="string">

</ResponseField>

`google_networkconnectivity_spoke` attaches a single network resource (a VPC network, VPN tunnel, interconnect attachment, or router appliance) to a Network Connectivity Center hub, making it part of that hub's own any-to-any topology.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own spoke"})

    		ubx.Resource(networkconnectivity.Spoke, "example", networkconnectivity.SpokeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

`google_networkconnectivity_psc_authorization_policy` restricts which consumer project(s) or network(s) are permitted to establish a Private Service Connect connection to a service published behind a Network Connectivity Center hub.

## Properties

<ResponseField name="authorization_mode" type="string">
  Required. The authorization mode. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="authorized_client_resources" type="list(string)">
  Required. List of authorized consumer resources allowed to connect. Supported values are: 1. Project resource name (e.g., `projects/&#123;project_id&#125;`) 2. Wildcard `"*"` (grants global ingress authorization to the target). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the PscAuthorizationPolicy was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. The etag of the PscAuthorizationPolicy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the PscAuthorizationPolicy. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/pscAuthorizationPolicies/&#123;psc_authorization_policy&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_resource_uri" type="string">
  Required. The full absolute URI of the targeted resource governed by this policy. For example, for an AgentRegistry resource, the format is: `//agentregistry.googleapis.com/projects/&#123;project&#125;/locations/&#123;location&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The unique identifier of the PscAuthorizationPolicy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the PscAuthorizationPolicy was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

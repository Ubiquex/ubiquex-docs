`google_networkconnectivity_automated_dns_record` is a DNS record Network Connectivity Center automatically creates and manages for a Private Service Connect connection, resolving a service's own domain name to the connection's private address.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own automated dns record"})

    		ubx.Resource(networkconnectivity.AutomatedDnsRecord, "example", networkconnectivity.AutomatedDnsRecordConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="dns_suffix" type="string">
  Required. Immutable. The dns suffix for this record to use in longest-suffix matching. Requires a trailing dot. Example: "example.com." Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dns_zone" type="string">
  Output only. DnsZone is the DNS zone managed by automation. Format: projects/&#123;project&#125;/managedZones/&#123;managedZone&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. The etag is computed by the server, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fqdn" type="string">
  Output only. The FQDN created by combining the hostname and dns suffix. Should include a trailing dot. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hostname" type="string">
  Required. Immutable. The hostname for the DNS record. This value will be prepended to the `dns_suffix` to create the full domain name (FQDN) for the record. For example, if `hostname` is "corp.db" and `dns_suffix` is "example.com.", the resulting record will be "corp.db.example.com.". Should not include a trailing dot. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

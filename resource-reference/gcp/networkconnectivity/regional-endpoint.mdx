`google_networkconnectivity_regional_endpoint` creates a regional Private Service Connect endpoint for reaching a Google API or a published service, an alternative to a zonal or global endpoint for regionally-scoped connectivity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_networkconnectivity --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_networkconnectivity/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google_networkconnectivity/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own regional endpoint"})

    		ubx.Resource(networkconnectivity.NetworkconnectivityRegionalEndpoint, "ci-runner", networkconnectivity.NetworkconnectivityRegionalEndpointConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="access_type" type="string">
  Required. The access type of this regional endpoint. This field is reflected in the PSC Forwarding Rule configuration to enable global access. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="address" type="string">
  Optional. The IP Address of the Regional Endpoint. When no address is provided, an IP from the subnetwork is allocated. Use one of the following formats: * IPv4 address as in `10.0.0.1` * Address resource URI as in `projects/&#123;project&#125;/regions/&#123;region&#125;/addresses/&#123;address_name&#125;` for an IPv4 or IPv6 address. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Time when the RegionalEndpoint was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ip_address" type="string">
  Output only. The literal IP address of the PSC Forwarding Rule created on behalf of the customer. This field is deprecated. Use address instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  User-defined labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of a RegionalEndpoint. Pattern: `projects/&#123;project&#125;/locations/&#123;location&#125;/regionalEndpoints/^[-a-z0-9](?:[-a-z0-9]&#123;0,44&#125;)[a-z0-9]$`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Optional. The name of the VPC network for this private regional endpoint. Format: `projects/&#123;project&#125;/global/networks/&#123;network&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="psc_forwarding_rule" type="string">
  Output only. The resource reference of the PSC Forwarding Rule created on behalf of the customer. Format: `//compute.googleapis.com/projects/&#123;project&#125;/regions/&#123;region&#125;/forwardingRules/&#123;forwarding_rule_name&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subnetwork" type="string">
  Optional. The name of the subnetwork from which the IP address will be allocated. Format: `projects/&#123;project&#125;/regions/&#123;region&#125;/subnetworks/&#123;subnetwork&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_google_api" type="string">
  Required. The service endpoint this private regional endpoint connects to. Format: `&#123;apiname&#125;.&#123;region&#125;.p.rep.googleapis.com` Example: "cloudkms.us-central1.p.rep.googleapis.com". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Time when the RegionalEndpoint was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

title: "google_pubsub_topic"

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_pubsub --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_pubsub/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	pubsub "github.com/ubiquex/ubx-sdk-google/sdk/go/google_pubsub/pubsub"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own topic"})

    		ubx.Resource(pubsub.PubsubTopic, "ci-runner", pubsub.PubsubTopicConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="message_retention_duration" type="string">
  Optional. Indicates the minimum duration to retain a message after it is published to the topic. If this field is set, messages published to the topic in the last `message_retention_duration` are always available to subscribers. For instance, it allows any attached subscription to [seek to a timestamp](https://cloud.google.com/pubsub/docs/replay-overview#seek_to_a_time) that is up to `message_retention_duration` in the past. If this field is not set, message retention is controlled by settings on individual subscriptions. Cannot be more than 31 days or less than 10 minutes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="message_storage_policy" type="object">

  <Expandable title="properties">
    <ResponseField name="allowed_persistence_regions" type="list(string)">
      Optional. A list of IDs of Google Cloud regions where messages that are published to the topic may be persisted in storage. Messages published by publishers running in non-allowed Google Cloud regions (or running outside of Google Cloud altogether) are routed for storage in one of the allowed regions. An empty list means that no regions are allowed, and is not a valid configuration. Optional.
    </ResponseField>
    <ResponseField name="enforce_in_transit" type="bool">
      Optional. If true, `allowed_persistence_regions` is also used to enforce in-transit guarantees for messages. That is, Pub/Sub will fail Publish operations on this topic and subscribe operations on any subscription attached to this topic in any region that is not in `allowed_persistence_regions`. Optional.
    </ResponseField>
  </Expandable>

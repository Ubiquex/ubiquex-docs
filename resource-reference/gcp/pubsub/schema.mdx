## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_pubsub --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_pubsub/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	pubsub "github.com/ubiquex/ubx-sdk-google/sdk/go/google_pubsub/pubsub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schema"})

    		ubx.Resource(pubsub.PubsubSchema, "example", pubsub.PubsubSchemaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">


    ```python
    # ubx sdk gen --only google_pubsub --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_pubsub/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_pubsub.pubsub import PubsubSchema, PubsubSchemaConfig

    def describe():
        ubx.intent("example own schema")

        ubx.resource(PubsubSchema, "example", PubsubSchemaConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="definition" type="string">
  The definition of the schema. This should contain a string representing the full definition of the schema that is a valid schema definition of the type specified in `type`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Name of the schema. Format is `projects/&#123;project&#125;/schemas/&#123;schema&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="revision_create_time" type="string">
  Output only. The timestamp that the revision was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="revision_id" type="string">
  Output only. Immutable. The revision ID of the schema. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  The type of the schema definition. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_pubsub_schema` -- real, typed bindings generated directly from the
`hashicorp/google` provider schema, in every SDK language.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    import (
        "github.com/ubiquex/ubx-sdk-google/sdk/go/google/pubsub"
    )

    cfg := pubsub.SchemaConfig{
        Name: "example-name",
        Definition: "example",
        Type: "example",
    }
    ubx.Resource(pubsub.Schema, "example", cfg)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Schema } from
      "jsr:@ubx/sdk-google/google/pubsub/schema";

    resource(Schema, "example", {
      name: "example-name",
      definition: "example",
      type: "example",
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from ubx.google.pubsub import Schema, SchemaConfig

    cfg = SchemaConfig(
        name="example-name",
        definition="example",
        type="example",
    )
    ubx.resource(Schema, "example", cfg)
    ```

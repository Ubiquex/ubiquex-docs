<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_discoveryengine_v1alpha_evaluation` is a real evaluation run against a Vertex AI Search app, recording its own quality_metrics and any error_samples against a real evaluation_spec, so search relevance and quality can be measured on real queries rather than judged only by manual spot-checking.

<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_identity_mapping_store`.

`google_discoveryengine_v1alpha_identity_mapping_store` holds the mapping between a caller's own external user identities and the access-control principal used to filter Discovery Engine search results to only the documents that user is permitted to see.

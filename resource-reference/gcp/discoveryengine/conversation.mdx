`google_discoveryengine_conversation` is a single multi-turn conversation session against a Discovery Engine search app, holding the exchanged query/reply pairs so follow-up questions retain context.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own conversation"})

    		ubx.Resource(discoveryengine.Conversation, "example", discoveryengine.ConversationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

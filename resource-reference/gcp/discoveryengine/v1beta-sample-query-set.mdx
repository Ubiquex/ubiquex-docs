  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.

`google_discoveryengine_v1beta_sample_query_set` is a real, named collection of sample queries (its own display_name and description) used as a consistent, reusable input set for evaluating a Vertex AI Search app's own quality over time.

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp the SampleQuerySet was created at. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the SampleQuerySet. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The sample query set display name. This field must be a UTF-8 encoded string with a length limit of 128 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The full resource name of the SampleQuerySet, in the format of `projects/&#123;project&#125;/locations/&#123;location&#125;/sampleQuerySets/&#123;sample_query_set&#125;`. This field must be a UTF-8 encoded string with a length limit of 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_discoveryengine_v1alpha_sample_query` is a single real sample query (its own query_entry) used to build or evaluate a sample_query_set, so a representative real query can be captured and reused across evaluation runs instead of retyped each time.

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp the SampleQuery was created at. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The full resource name of the sample query, in the format of `projects/&#123;project&#125;/locations/&#123;location&#125;/sampleQuerySets/&#123;sample_query_set&#125;/sampleQueries/&#123;sample_query&#125;`. This field must be a UTF-8 encoded string with a length limit of 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

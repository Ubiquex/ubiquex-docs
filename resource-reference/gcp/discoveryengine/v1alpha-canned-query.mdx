<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_discoveryengine_v1alpha_canned_query` is a real, pre-defined query (its own default_texts and localized_texts) a search experience can surface to users directly, optionally google_defined rather than customer-authored, with required_capabilities declaring what the serving search app must support to run it.

<ResponseField name="display_name" type="string">
  The display name of the canned query. It must be a UTF-8 encoded string with a length limit of 128 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enabled" type="bool">
  Whether this canned query is enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="google_defined" type="bool">

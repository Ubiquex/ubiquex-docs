`google_discoveryengine_v1alpha_canned_query` is a real, pre-defined query (its own default_texts and localized_texts) a search experience can surface to users directly, optionally google_defined rather than customer-authored, with required_capabilities declaring what the serving search app must support to run it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha canned query"})

    		ubx.Resource(discoveryengine.V1alphaCannedQuery, "example", discoveryengine.V1alphaCannedQueryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="default_texts" type="object">
  The text pieces for the canned query, which can be localized. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="prefix" type="string">
      Optional. The prefix that `suggested_prompts` should start with. Optional.
    </ResponseField>
    <ResponseField name="suggested_prompts" type="list(object)">
      Required. The prompts the canned query will offer to the user. Optional.
      <Expandable title="properties">
        <ResponseField name="prompt_text" type="string">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="title" type="string">
      Required. The title that is for the end user. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  The display name of the canned query. It must be a UTF-8 encoded string with a length limit of 128 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enabled" type="bool">
  Whether this canned query is enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="google_defined" type="bool">
  Output only. Whether this is a Google-defined, read-only canned query. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="localized_texts" type="map(object)">
  Optional. The translations of the text attributes. The keys should be BCP-47 language codes. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="prefix" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="suggested_prompts" type="list(object)">
      Optional; if omitted, computed by Google Cloud.
      <Expandable title="properties">
        <ResponseField name="prompt_text" type="string">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="title" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Resource name of the canned query. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/collections/&#123;collection&#125;/engines/&#123;engine&#125;/assistants/&#123;assistant&#125;/cannedQueries/&#123;canned_query&#125;` It must be a UTF-8 encoded string with a length limit of 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="required_capabilities" type="list(object)">
  Optional. The capabilities the Assistant needs to have to use this canned query. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="action_name" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
  </Expandable>
</ResponseField>

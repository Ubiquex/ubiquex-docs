<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_discoveryengine_v1alpha_authorization` defines a real OAuth2 authorization configuration (server_side_oauth2) an agent can use to access a protected external resource on a user's behalf, so an agent's own access grants can be managed as one resource rather than embedded in every tool definition that needs them.

## Properties

<ResponseField name="display_name" type="string">
  Required. The display name of the authorization. It must be a UTF-8 encoded string with a length limit of 128 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the authorization. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/authorizations/&#123;authorization&#125;` It must be a UTF-8 encoded string with a length limit of 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="server_side_oauth2" type="object">
  OAuth2 configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="authorization_uri" type="string">
      Required. The URI the user is directed to when they need to authorize. Should include everything required for a successful authorization: OAuth ID, extra flags, etc. Example: `https://accounts.google.com/o/oauth2/v2/auth?client_id=OAUTH_ID&scope=https://www.googleapis.com/auth/calendar.events&response_type=code&access_type=offline&prompt=consent` The `redirect_uri` parameter will be overwritten by the Vertex AI Search frontend. Optional.
    </ResponseField>
    <ResponseField name="client_id" type="string">
      Required. The OAuth2 client ID. Optional.
    </ResponseField>
    <ResponseField name="client_secret" type="string">
      Required. The OAuth2 client secret. Encrypted at rest. Optional.
    </ResponseField>
    <ResponseField name="pkce_verification_enabled" type="bool">
      Optional. Whether to enable PKCE verification. https://datatracker.ietf.org/doc/html/rfc7636#section-3.1/ Optional.
    </ResponseField>
    <ResponseField name="scopes" type="list(string)">
      Optional. The scopes to request. Example: `https://www.googleapis.com/auth/calendar.events` If omitted, no additional scopes are requested beyond those required by the authorization uri. If set, it will overwrite the scopes in the authorization uri when acquiring user authorization. Optional.
    </ResponseField>
    <ResponseField name="token_uri" type="string">
      Required. The HTTP endpoint that exchanges a client authorization for an access token. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

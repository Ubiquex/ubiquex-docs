`google_discoveryengine_v1alpha_project` provisions a caller's own Google Cloud project for Vertex AI Search (Discovery Engine), the one-time setup step before an engine or data store can be created in it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha project"})

    		ubx.Resource(discoveryengine.V1alphaProject, "example", discoveryengine.V1alphaProjectConfig{
    			AcceptDataUseTerms:  true,
    			DataUseTermsVersion: "example",
    			SaasParams:          map[string]any{"accept_biz_qos": true},
    		})
    	}))
    }
    ```

## Input properties

<ResponseField name="accept_data_use_terms" type="bool">
  Required. Set to `true` to specify that caller has read and would like to give consent to the [Terms for data use](https://cloud.google.com/retail/data-use-terms). Optional.
</ResponseField>

<ResponseField name="data_use_terms_version" type="string">
  Required. The version of the [Terms for data use](https://cloud.google.com/retail/data-use-terms) that caller has read and would like to give consent to. Acceptable version is `2022-11-23`, and this may change over time. Optional.
</ResponseField>

<ResponseField name="saas_params" type="object">
  Parameters for Agentspace. Optional.
  <Expandable title="properties">
    <ResponseField name="accept_biz_qos" type="bool">
      Optional. Set to `true` to specify that caller has read and would like to give consent to the [Terms for Agent Space quality of service]. Optional.
    </ResponseField>
    <ResponseField name="is_biz" type="bool">
      Optional. Indicates if the current request is for Biz edition (= true) or not (= false). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_discoveryengine_v1alpha_agent` is a configured conversational agent within Vertex AI Search -- its own dialogflow_agent_definition, a2a_agent_definition, or adk_agent_definition selecting which real agent framework backs it, with authorization_config controlling what it can access, so a search experience can be fronted by a real, managed conversational layer.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha agent"})

    		ubx.Resource(discoveryengine.V1alphaAgent, "example", discoveryengine.V1alphaAgentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

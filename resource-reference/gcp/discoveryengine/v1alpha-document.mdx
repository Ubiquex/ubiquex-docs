`google_discoveryengine_v1alpha_document` is a single indexed item (a webpage, a structured record, a file) within a Discovery Engine data store, the unit search and recommendation results are returned as.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha document"})

    		ubx.Resource(discoveryengine.V1alphaDocument, "example", discoveryengine.V1alphaDocumentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="content" type="object">
  Unstructured data linked to this document. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="mime_type" type="string">
      The MIME type of the content. Supported types: * `application/pdf` (PDF, only native PDFs are supported for now) * `text/html` (HTML) * `text/plain` (TXT) * `application/xml` or `text/xml` (XML) * `application/json` (JSON) * `application/vnd.openxmlformats-officedocument.wordprocessingml.document` (DOCX) * `application/vnd.openxmlformats-officedocument.presentationml.presentation` (PPTX) * `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` (XLSX) * `application/vnd.ms-excel.sheet.macroenabled.12` (XLSM) The following types are supported only if layout parser is enabled in the data store: * `image/bmp` (BMP) * `image/gif` (GIF) * `image/jpeg` (JPEG) * `image/png` (PNG) * `image/tiff` (TIFF) See https://www.iana.org/assignments/media-types/media-types.xhtml. Optional.
    </ResponseField>
    <ResponseField name="raw_bytes" type="string">
      The content represented as a stream of bytes. The maximum length is 1,000,000 bytes (1 MB / ~0.95 MiB). Note: As with all `bytes` fields, this field is represented as pure binary in Protocol Buffers and base64-encoded string in JSON. For example, `abc123!?$*&()'-=@~` should be represented as `YWJjMTIzIT8kKiYoKSctPUB+` in JSON. See https://developers.google.com/protocol-buffers/docs/proto3#json. Optional.
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI of the content. Only Cloud Storage URIs (e.g. `gs://bucket-name/path/to/file`) are supported. The maximum file size is 2.5 MB for text-based formats, 200 MB for other formats. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="index_time" type="string">
  Output only. The time when the document was last indexed. If this field is populated, it means the document has been indexed. While documents typically become searchable within seconds of indexing, it can sometimes take up to a few hours. If this field is not populated, it means the document has never been indexed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="json_data" type="string">
  The JSON string representation of the document. It should conform to the registered Schema or an `INVALID_ARGUMENT` error is thrown. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The full resource name of the document. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/collections/&#123;collection&#125;/dataStores/&#123;data_store&#125;/branches/&#123;branch&#125;/documents/&#123;document_id&#125;`. This field must be a UTF-8 encoded string with a length limit of 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent_document_id" type="string">
  The identifier of the parent document. Currently supports at most two level document hierarchy. Id should conform to [RFC-1034](https://tools.ietf.org/html/rfc1034) standard with a length limit of 63 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_id" type="string">

</ResponseField>

<ResponseField name="struct_data" type="map(any)">

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_identity_mapping_store`.
</Warning>

`google_discoveryengine_v1beta_identity_mapping_store` holds the mapping between a caller's own external user identities and the access-control principal used to filter Discovery Engine search results to only the documents that user is permitted to see.

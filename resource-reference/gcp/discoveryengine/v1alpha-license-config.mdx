<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_license_config`.
</Warning>

`google_discoveryengine_v1alpha_license_config` defines a named license tier used to track and assign per-user Discovery Engine / Agent Search entitlements within an organization.

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_schema`.
</Warning>

`google_discoveryengine_v1beta_schema` defines the field structure (names, types) that structured documents in a Discovery Engine data store must conform to.

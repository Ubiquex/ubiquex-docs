`google_discoveryengine_v1alpha_target_site` registers a specific website (or a URL pattern within one) to be crawled and indexed into a Discovery Engine data store's own website search content.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha target site"})

    		ubx.Resource(discoveryengine.V1alphaTargetSite, "example", discoveryengine.V1alphaTargetSiteConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="exact_match" type="bool">
  Immutable. If set to false, a uri_pattern is generated to include all pages whose address contains the provided_uri_pattern. If set to true, an uri_pattern is generated to try to be an exact match of the provided_uri_pattern or just the specific page if the provided_uri_pattern is a specific one. provided_uri_pattern is always normalized to generate the URI pattern to be used by the search engine. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="failure_reason" type="object">
  Site search indexing failure reasons. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="quota_failure" type="object">
      Failed due to insufficient quota. Optional.
      <Expandable title="properties">
        <ResponseField name="total_required_quota" type="string">
          This number is an estimation on how much total quota this project needs to successfully complete indexing. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="generated_uri_pattern" type="string">
  Output only. This is system-generated based on the provided_uri_pattern. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="indexing_status" type="string">
  Output only. Indexing status. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The fully qualified resource name of the target site. `projects/&#123;project&#125;/locations/&#123;location&#125;/collections/&#123;collection&#125;/dataStores/&#123;data_store&#125;/siteSearchEngine/targetSites/&#123;target_site&#125;` The `target_site_id` is system-generated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="provided_uri_pattern" type="string">
  Required. Input only. The user provided URI pattern from which the `generated_uri_pattern` is generated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="root_domain_uri" type="string">
  Output only. Root domain of the provided_uri_pattern. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="site_verification_info" type="object">
  Verification information for target sites in advanced site search. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="site_verification_state" type="string">
      Site verification state indicating the ownership and validity. Optional.
    </ResponseField>
    <ResponseField name="verify_time" type="string">
      Latest site verification time. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="type" type="string">
  The type of the target site, e.g., whether the site is to be included or excluded. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The target site's last updated time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

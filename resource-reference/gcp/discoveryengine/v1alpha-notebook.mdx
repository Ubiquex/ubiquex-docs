<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_discoveryengine_v1alpha_notebook` is a real notebook resource within Vertex AI Search -- its own title, emoji, sources, and cmek_config -- grouping a set of source material and notes under one identified, encryptable resource rather than loose, untracked files.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha notebook"})

    		ubx.Resource(discoveryengine.V1alphaNotebook, "example", discoveryengine.V1alphaNotebookConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

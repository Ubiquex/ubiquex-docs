`google_discoveryengine_assistant` configures a conversational assistant experience (grounded answers, follow-up suggestions) built on top of a Discovery Engine (recently rebranded Agent Search) data store or engine.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own assistant"})

    		ubx.Resource(discoveryengine.Assistant, "example", discoveryengine.AssistantConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

      Configuration for customer defined Model Armor templates to be used for sanitizing user prompts and assistant responses. Optional.

<ResponseField name="default_web_grounding_toggle_off" type="bool">
  Optional. This field controls the default web grounding toggle for end users if `web_grounding_type` is set to `WEB_GROUNDING_TYPE_GOOGLE_SEARCH` or `WEB_GROUNDING_TYPE_ENTERPRISE_WEB_SEARCH`. By default, this field is set to false. If `web_grounding_type` is `WEB_GROUNDING_TYPE_GOOGLE_SEARCH` or `WEB_GROUNDING_TYPE_ENTERPRISE_WEB_SEARCH`, end users will have web grounding enabled by default on UI. If true, grounding toggle will be disabled by default on UI. End users can still enable web grounding in the UI if web grounding is enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description for additional information. Expected to be shown on the configuration UI, not to the users of the assistant. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The assistant display name. It must be a UTF-8 encoded string with a length limit of 128 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

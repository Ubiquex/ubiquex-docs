<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_discoveryengine_v1alpha_alpha_evolve_experiment` is a real AlphaEvolve experiment -- an automated program-improvement run that starts from an initial_alpha_evolve_program and iterates against a real config, tracking its own state and stats, so an evolving-program search can be managed and inspected as one resource rather than a raw sequence of individual program runs.

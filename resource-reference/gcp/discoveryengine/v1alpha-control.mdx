<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_control`.

`google_discoveryengine_v1alpha_control` defines a rule that adjusts search or recommendation behavior for matching queries, e.g. boosting, burying, or redirecting results for a specific search term.

## Properties

<ResponseField name="associated_serving_config_ids" type="list(string)">
  Output only. List of all ServingConfig IDs this control is attached to. May take up to 10 minutes to update after changes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="boost_action" type="object">
  Adjusts order of products in returned list. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="boost" type="number">
      Strength of the boost, which should be in [-1, 1]. Negative boost means demotion. Default is 0.0 (No-op). Optional.
    </ResponseField>
    <ResponseField name="data_store" type="string">
      Required. Specifies which data store's documents can be boosted by this control. Full data store name e.g. projects/123/locations/global/collections/default_collection/dataStores/default_data_store Optional.
    </ResponseField>
    <ResponseField name="filter" type="string">
      Required. Specifies which products to apply the boost to. If no filter is provided all products will be boosted (No-op). Syntax documentation: https://cloud.google.com/retail/docs/filter-and-order Maximum length is 5000 characters. Otherwise an INVALID ARGUMENT error is thrown. Optional.
    </ResponseField>
    <ResponseField name="fixed_boost" type="number">
      Optional. Strength of the boost, which should be in [-1, 1]. Negative boost means demotion. Default is 0.0 (No-op). Optional.
    </ResponseField>
    <ResponseField name="interpolation_boost_spec" type="object">
      Specification for custom ranking based on customer specified attribute value. It provides more controls for customized ranking than the simple (condition, boost) combination above. Optional.
      <Expandable title="properties">
        <ResponseField name="attribute_type" type="string">
          Optional. The attribute type to be used to determine the boost amount. The attribute value can be derived from the field value of the specified field_name. In the case of numerical it is straightforward i.e. attribute_value = numerical_field_value. In the case of freshness however, attribute_value = (time.now() - datetime_field_value). Optional.
        </ResponseField>
        <ResponseField name="control_points" type="list(object)">
          Optional. The control points used to define the curve. The monotonic function (defined through the interpolation_type above) passes through the control points listed here. Optional.
          <Expandable title="properties">
            <ResponseField name="attribute_value" type="string">
              Optional; if omitted, computed by Google Cloud.
            </ResponseField>
            <ResponseField name="boost_amount" type="number">
              Optional; if omitted, computed by Google Cloud.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="field_name" type="string">
          Optional. The name of the field whose value will be used to determine the boost amount. Optional.
        </ResponseField>
        <ResponseField name="interpolation_type" type="string">
          Optional. The interpolation type to be applied to connect the control points listed below. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="conditions" type="list(object)">
  Determines when the associated action will trigger. Omit to always apply the action. Currently only a single condition may be specified. Otherwise an INVALID ARGUMENT error is thrown. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="active_time_range" type="list(object)">
      Optional; if omitted, computed by Google Cloud.
      <Expandable title="properties">
        <ResponseField name="end_time" type="string">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
        <ResponseField name="start_time" type="string">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="query_regex" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="query_terms" type="list(object)">
      Optional; if omitted, computed by Google Cloud.
      <Expandable title="properties">
        <ResponseField name="full_match" type="bool">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
        <ResponseField name="value" type="string">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Human readable name. The identifier used in UI views. Must be UTF-8 encoded string. Length limit is 128 characters. Otherwise an INVALID ARGUMENT error is thrown. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter_action" type="object">
  Specified which products may be included in results. Uses same filter as boost. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="data_store" type="string">
      Required. Specifies which data store's documents can be filtered by this control. Full data store name e.g. projects/123/locations/global/collections/default_collection/dataStores/default_data_store Optional.
    </ResponseField>
    <ResponseField name="filter" type="string">
      Required. A filter to apply on the matching condition results. Required Syntax documentation: https://cloud.google.com/retail/docs/filter-and-order Maximum length is 5000 characters. Otherwise an INVALID ARGUMENT error is thrown. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Fully qualified name `projects/*/locations/global/dataStore/*/controls/*` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="promote_action" type="object">
  Promote certain links based on some trigger queries. Example: Promote shoe store link when searching for `shoe` keyword. The link can be outside of associated data store. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="data_store" type="string">
      Required. Data store with which this promotion is attached to. Optional.
    </ResponseField>
    <ResponseField name="search_link_promotion" type="object">
      Promotion proto includes uri and other helping information to display the promotion. Optional.
      <Expandable title="properties">
        <ResponseField name="description" type="string">
          Optional. The Promotion description. Maximum length: 200 characters. Optional.
        </ResponseField>
        <ResponseField name="document" type="string">
          Optional. The Document the user wants to promote. For site search, leave unset and only populate uri. Can be set along with uri. Optional.
        </ResponseField>
        <ResponseField name="enabled" type="bool">
          Optional. The enabled promotion will be returned for any serving configs associated with the parent of the control this promotion is attached to. This flag is used for basic site search only. Optional.
        </ResponseField>
        <ResponseField name="image_uri" type="string">
          Optional. The promotion thumbnail image url. Optional.
        </ResponseField>
        <ResponseField name="title" type="string">
          Required. The title of the promotion. Maximum length: 160 characters. Optional.
        </ResponseField>
        <ResponseField name="uri" type="string">
          Optional. The URL for the page the user wants to promote. Must be set for site search. For other verticals, this is optional. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="redirect_action" type="object">
  Redirects a shopper to the provided URI. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="redirect_uri" type="string">
      Required. The URI to which the shopper will be redirected. Required. URI must have length equal or less than 2000 characters. Otherwise an INVALID ARGUMENT error is thrown. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="solution_type" type="string">
  Required. Immutable. What solution the control belongs to. Must be compatible with vertical of resource. Otherwise an INVALID ARGUMENT error is thrown. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="synonyms_action" type="object">
  Creates a set of terms that will act as synonyms of one another. Example: "happy" will also be considered as "glad", "glad" will also be considered as "happy". Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="synonyms" type="list(string)">
      Defines a set of synonyms. Can specify up to 100 synonyms. Must specify at least 2 synonyms. Otherwise an INVALID ARGUMENT error is thrown. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="use_cases" type="list(string)">
  Specifies the use case for the control. Affects what condition fields can be set. Only applies to SOLUTION_TYPE_SEARCH. Currently only allow one use case per control. Must be set when solution_type is SolutionType.SOLUTION_TYPE_SEARCH. Optional; if omitted, computed by Google Cloud.
</ResponseField>

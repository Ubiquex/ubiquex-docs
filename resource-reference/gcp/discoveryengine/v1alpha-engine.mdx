<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_engine`.
</Warning>

`google_discoveryengine_v1alpha_engine` is the deployable search, recommendation, or chat application built on top of one or more Discovery Engine data stores, the resource a serving config is created under.

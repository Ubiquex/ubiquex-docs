---
title: "google_discoveryengine_schema"
description: "`google_discoveryengine_schema` defines the field structure (names, types) that structured documents in a Discovery Engine data store must conform to."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schema"})

    		ubx.Resource(discoveryengine.Schema, "example", discoveryengine.SchemaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Schema } from "@ubx/sdk-google/google/discoveryengine/schema";

    export default stack("example", () => {
      intent({ summary: "example own schema" });

      resource(Schema, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.discoveryengine import Schema, SchemaConfig

    def describe():
        ubx.intent("example own schema")

        ubx.resource(Schema, "example", SchemaConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Properties

<ResponseField name="json_schema" type="string">
  The JSON representation of the schema. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The full resource name of the schema, in the format of `projects/&#123;project&#125;/locations/&#123;location&#125;/collections/&#123;collection&#125;/dataStores/&#123;data_store&#125;/schemas/&#123;schema&#125;`. This field must be a UTF-8 encoded string with a length limit of 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="struct_schema" type="map(any)">
  The structured representation of the schema. Optional; if omitted, computed by Google Cloud.
</ResponseField>

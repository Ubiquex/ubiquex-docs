<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_schema`.
</Warning>

`google_discoveryengine_v1alpha_schema` defines the field structure (names, types) that structured documents in a Discovery Engine data store must conform to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha schema"})

    		ubx.Resource(discoveryengine.V1alphaSchema, "example", discoveryengine.V1alphaSchemaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

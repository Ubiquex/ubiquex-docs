`google_discoveryengine_push_notification_config` configures an endpoint Discovery Engine sends push notification(s) to when a relevant event (e.g. a new matching document) occurs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own push notification config"})

    		ubx.Resource(discoveryengine.PushNotificationConfig, "example", discoveryengine.PushNotificationConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="name" type="string">
  The resource name of the config. Format: tasks/&#123;task_id&#125;/pushNotificationConfigs/&#123;config_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="push_notification_config" type="object">
  Configuration for setting up push notifications for task updates. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="authentication" type="object">
      Defines authentication details, used for push notifications. Optional.
      <Expandable title="properties">
        <ResponseField name="credentials" type="string">
          Optional credentials Optional.
        </ResponseField>
        <ResponseField name="schemes" type="list(string)">
          Supported authentication schemes - e.g. Basic, Bearer, etc Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="id" type="string">
      A unique identifier (e.g. UUID) for this push notification. Optional.
    </ResponseField>
    <ResponseField name="token" type="string">
      Token unique for this task/session Optional.
    </ResponseField>
    <ResponseField name="url" type="string">
      Url to send the notification too Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_discoveryengine_conversation`.
</Warning>

`google_discoveryengine_v1beta_conversation` is a single multi-turn conversation session against a Discovery Engine search app, holding the exchanged query/reply pairs so follow-up questions retain context.

## Example

    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_discoveryengine_v1beta/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google_discoveryengine_v1beta/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta conversation"})

    		ubx.Resource(discoveryengine.V1betaDiscoveryengineV1betaConversation, "example", discoveryengine.V1betaDiscoveryengineV1betaConversationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

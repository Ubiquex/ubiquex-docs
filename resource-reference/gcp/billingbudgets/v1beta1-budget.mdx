`google_billingbudgets_v1beta1_budget` sets a spending threshold on a Cloud Billing account and triggers notification(s) when actual or forecasted spend crosses it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	billingbudgets "github.com/ubiquex/ubx-sdk-google/sdk/go/google/billingbudgets"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 budget"})

    		ubx.Resource(billingbudgets.V1beta1Budget, "example", billingbudgets.V1beta1BudgetConfig{
    			Budget: map[string]any{"all_updates_rule": map[string]any{"disable_default_iam_recipients": true}},
    		})
    	}))
    }
    ```
  </Tab>

## Input properties

<ResponseField name="budget" type="object">
  A budget is a plan that describes what you expect to spend on Cloud projects, plus the rules to execute as spend is tracked against that plan, (for example, send an alert when 90% of the target spend is met). The budget time period is configurable, with options such as month (default), quarter, year, or custom time period. Optional.
  <Expandable title="properties">
    <ResponseField name="all_updates_rule" type="object">
      AllUpdatesRule defines notifications that are sent based on budget spend and thresholds. Optional.
      <Expandable title="properties">
        <ResponseField name="disable_default_iam_recipients" type="bool">
          Optional. When set to true, disables default notifications sent when a threshold is exceeded. Default notifications are sent to those with Billing Account Administrator and Billing Account User IAM roles for the target account. Optional.
        </ResponseField>
        <ResponseField name="enable_project_level_recipients" type="bool">
          Optional. When set to true, and when the budget has a single project configured, notifications will be sent to project level recipients of that project. This field will be ignored if the budget has multiple or no project configured. Currently, project level recipients are the users with `Owner` role on a cloud project. Optional.
        </ResponseField>
        <ResponseField name="monitoring_notification_channels" type="list(string)">
          Optional. Targets to send notifications to when a threshold is exceeded. This is in addition to default recipients who have billing account IAM roles. The value is the full REST resource name of a monitoring notification channel with the form `projects/&#123;project_id&#125;/notificationChannels/&#123;channel_id&#125;`. A maximum of 5 channels are allowed. See https://cloud.google.com/billing/docs/how-to/budgets-notification-recipients for more details. Optional.
        </ResponseField>
        <ResponseField name="pubsub_topic" type="string">
          Optional. The name of the Pub/Sub topic where budget related messages will be published, in the form `projects/&#123;project_id&#125;/topics/&#123;topic_id&#125;`. Updates are sent at regular intervals to the topic. The topic needs to be created before the budget is created; see https://cloud.google.com/billing/docs/how-to/budgets-programmatic-notifications for more details. Caller is expected to have `pubsub.topics.setIamPolicy` permission on the topic when it's set for a budget, otherwise, the API call will fail with PERMISSION_DENIED. See https://cloud.google.com/billing/docs/how-to/budgets-programmatic-notifications#permissions_required_for_this_task for more details on Pub/Sub roles and permissions. Optional.
        </ResponseField>
        <ResponseField name="schema_version" type="string">
          Optional. Required when AllUpdatesRule.pubsub_topic is set. The schema version of the notification sent to AllUpdatesRule.pubsub_topic. Only "1.0" is accepted. It represents the JSON schema as defined in https://cloud.google.com/billing/docs/how-to/budgets-programmatic-notifications#notification_format. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="amount" type="object">
      The budgeted amount for each usage period. Optional.
      <Expandable title="properties">
        <ResponseField name="last_period_amount" type="any">
          Describes a budget amount targeted to the last Filter.calendar_period spend. At this time, the amount is automatically 100% of the last calendar period's spend; that is, there are no other options yet. Future configuration options will be described here (for example, configuring a percentage of last period's spend). LastPeriodAmount cannot be set for a budget configured with a Filter.custom_period. Optional.
        </ResponseField>
        <ResponseField name="specified_amount" type="object">
          Represents an amount of money with its currency type. Optional.
          <Expandable title="properties">
            <ResponseField name="currency_code" type="string">
              The three-letter currency code defined in ISO 4217. Optional.
            </ResponseField>
            <ResponseField name="nanos" type="number">
              Number of nano (10^-9) units of the amount. The value must be between -999,999,999 and +999,999,999 inclusive. If `units` is positive, `nanos` must be positive or zero. If `units` is zero, `nanos` can be positive, zero, or negative. If `units` is negative, `nanos` must be negative or zero. For example $-1.75 is represented as `units`=-1 and `nanos`=-750,000,000. Optional.
            </ResponseField>
            <ResponseField name="units" type="string">
              The whole units of the amount. For example if `currencyCode` is `"USD"`, then 1 unit is one US dollar. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="budget_filter" type="object">
      A filter for a budget, limiting the scope of the cost to calculate. Optional.
      <Expandable title="properties">
        <ResponseField name="calendar_period" type="string">
          Optional. Specifies to track usage for recurring calendar period. For example, assume that CalendarPeriod.QUARTER is set. The budget will track usage from April 1 to June 30, when the current calendar month is April, May, June. After that, it will track usage from July 1 to September 30 when the current calendar month is July, August, September, so on. Optional.
        </ResponseField>
        <ResponseField name="credit_types" type="list(string)">
          Optional. If Filter.credit_types_treatment is INCLUDE_SPECIFIED_CREDITS, this is a list of credit types to be subtracted from gross cost to determine the spend for threshold calculations. See [a list of acceptable credit type values](https://cloud.google.com/billing/docs/how-to/export-data-bigquery-tables#credits-type). If Filter.credit_types_treatment is **not** INCLUDE_SPECIFIED_CREDITS, this field must be empty. Optional.
        </ResponseField>
        <ResponseField name="credit_types_treatment" type="string">
          Optional. If not set, default behavior is `INCLUDE_ALL_CREDITS`. Optional.
        </ResponseField>
        <ResponseField name="custom_period" type="object">
          All date times begin at 12 AM US and Canadian Pacific Time (UTC-8). Optional.
          <Expandable title="properties">
            <ResponseField name="end_date" type="object">

Related types: * google.type.TimeOfDay * google.type.DateTime * google.protobuf.Timestamp Optional.

The date is relative to the Gregorian Calendar. This can represent one of the following: * A full date, with non-zero year, month, and day values. * A month and day, with a zero year (for example, an anniversary). * A year on its own, with a zero month and a zero day. * A year and month, with a zero day (for example, a credit card expiration date). Related types: * google.type.TimeOfDay * google.type.DateTime * google.protobuf.Timestamp Optional.
              <Expandable title="properties">
                <ResponseField name="day" type="number">
                  Day of a month. Must be from 1 to 31 and valid for the year and month, or 0 to specify a year by itself or a year and month where the day isn't significant. Optional.
                </ResponseField>
                <ResponseField name="month" type="number">
                  Month of a year. Must be from 1 to 12, or 0 to specify a year without a month and day. Optional.
                </ResponseField>
                <ResponseField name="year" type="number">
                  Year of the date. Must be from 1 to 9999, or 0 to specify a date without a year. Optional.
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="labels" type="map(list(any))">
          Optional. A single label and value pair specifying that usage from only this set of labeled resources should be included in the budget. If omitted, the report will include all labeled and unlabeled usage. An object containing a single `"key": value` pair. Example: `&#123; "name": "wrench" &#125;`. _Currently, multiple entries or multiple values per entry are not allowed._ Optional.
        </ResponseField>
        <ResponseField name="projects" type="list(string)">
          Optional. A set of projects of the form `projects/&#123;project&#125;`, specifying that usage from only this set of projects should be included in the budget. If omitted, the report will include all usage for the billing account, regardless of which project the usage occurred on. Optional.
        </ResponseField>
        <ResponseField name="resource_ancestors" type="list(string)">
          Optional. A set of folder and organization names of the form `folders/&#123;folderId&#125;` or `organizations/&#123;organizationId&#125;`, specifying that usage from only this set of folders and organizations should be included in the budget. If omitted, the budget includes all usage that the billing account pays for. If the folder or organization contains projects that are paid for by a different Cloud Billing account, the budget *doesn't* apply to those projects. Optional.
        </ResponseField>
        <ResponseField name="services" type="list(string)">
          Optional. A set of services of the form `services/&#123;service_id&#125;`, specifying that usage from only this set of services should be included in the budget. If omitted, the report will include usage for all the services. The service names are available through the Catalog API: https://cloud.google.com/billing/v1/how-tos/catalog-api. Optional.
        </ResponseField>
        <ResponseField name="subaccounts" type="list(string)">
          Optional. A set of subaccounts of the form `billingAccounts/&#123;account_id&#125;`, specifying that usage from only this set of subaccounts should be included in the budget. If a subaccount is set to the name of the parent account, usage from the parent account will be included. If omitted, the report will include usage from the parent account and all subaccounts, if they exist. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>

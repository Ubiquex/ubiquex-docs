`google_managedkafka_connect_cluster` provisions a managed Kafka Connect cluster, the runtime connector(s) execute on to move data between a Managed Kafka cluster and external systems.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedkafka "github.com/ubiquex/ubx-sdk-google/sdk/go/google/managedkafka"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connect cluster"})

    		ubx.Resource(managedkafka.ConnectCluster, "example", managedkafka.ConnectClusterConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="capacity_config" type="object">
  A capacity configuration of a Kafka cluster. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="memory_bytes" type="string">
      Required. The memory to provision for the cluster in bytes. The CPU:memory ratio (vCPU:GiB) must be between 1:1 and 1:8. Minimum: 3221225472 (3 GiB). Optional.
    </ResponseField>
    <ResponseField name="vcpu_count" type="string">
      Required. The number of vCPUs to provision for the cluster. Minimum: 3. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="config" type="map(string)">
  Optional. Reserved for future use. This field is meant for worker config overrides, but is unsupported for now. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the cluster was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="gcp_config" type="object">
  Configuration properties for a Kafka Connect cluster deployed to Google Cloud Platform. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="access_config" type="object">
      The configuration of access to the Kafka Connect cluster. Optional.
      <Expandable title="properties">
        <ResponseField name="network_configs" type="list(object)">
          Required. Virtual Private Cloud (VPC) networks that must be granted direct access to the Kafka Connect cluster. Minimum of 1 network is required. Maximum 10 networks can be specified. Optional.
          <Expandable title="properties">
            <ResponseField name="additional_subnets" type="list(string)">
              Additional subnet(s), beyond `primary_subnet`, this Connect cluster is reachable from. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="dns_domain_names" type="list(string)">
              The DNS domain name(s) this Connect cluster is resolvable under from within the configured network. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="primary_subnet" type="string">
              The primary subnet this Connect cluster is reachable from. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="secret_paths" type="list(string)">
      Optional. Secrets to load into workers. Exact SecretVersions from Secret Manager must be provided -- aliases are not supported. Up to 32 secrets may be loaded into one cluster. Format: projects//secrets//versions/ Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="kafka_cluster" type="string">
  Required. Immutable. The name of the Kafka cluster this Kafka Connect cluster is attached to. Structured like: projects/&#123;project&#125;/locations/&#123;location&#125;/clusters/&#123;cluster&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the Kafka Connect cluster. Structured like: projects/&#123;project_number&#125;/locations/&#123;location&#125;/connectClusters/&#123;connect_cluster_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the Kafka Connect cluster. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the cluster was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

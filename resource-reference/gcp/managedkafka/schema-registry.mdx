`google_managedkafka_schema_registry` is a managed Kafka schema registry, storing and versioning the message schema(s) producers and consumers on a Managed Kafka cluster validate against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedkafka "github.com/ubiquex/ubx-sdk-google/sdk/go/google/managedkafka"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own schema registry"})

    		ubx.Resource(managedkafka.SchemaRegistry, "example", managedkafka.SchemaRegistryConfig{
    			SchemaRegistry:   map[string]any{"name": "example-name"},
    			SchemaRegistryId: "example",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="schema_registry_id" type="string">
  Required. The schema registry instance ID to use for this schema registry. The ID must contain only letters (a-z, A-Z), numbers (0-9), and underscores (-). The maximum length is 63 characters. The ID must not start with a number. Optional.
</ResponseField>

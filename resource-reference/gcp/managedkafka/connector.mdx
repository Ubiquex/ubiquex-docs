`google_managedkafka_connector` configures a single Kafka Connect source or sink connector running on a Managed Kafka Connect cluster, moving data between Kafka and an external system.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedkafka "github.com/ubiquex/ubx-sdk-google/sdk/go/google/managedkafka"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connector"})

    		ubx.Resource(managedkafka.Connector, "example", managedkafka.ConnectorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="configs" type="map(string)">
  Optional. Connector config as keys/values. The keys of the map are connector property names, for example: `connector.class`, `tasks.max`, `key.converter`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the connector. Structured like: projects/&#123;project&#125;/locations/&#123;location&#125;/connectClusters/&#123;connect_cluster&#125;/connectors/&#123;connector&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the connector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="task_restart_policy" type="object">
  Task Retry Policy is implemented on a best-effort basis. The default policy retries tasks with a minimum_backoff of 60 seconds, and a maximum_backoff of 12 hours. You can disable the policy by setting the task_retry_disabled field to true. Retry delay will be exponential based on provided minimum and maximum backoffs. https://en.wikipedia.org/wiki/Exponential_backoff. Note that the delay between consecutive task restarts may not always precisely match the configured settings. This can happen when the ConnectCluster is in rebalancing state or if the ConnectCluster is unresponsive etc. The default values for minimum and maximum backoffs are 60 seconds and 12 hours respectively. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="maximum_backoff" type="string">
      Optional. The maximum amount of time to wait before retrying a failed task. This sets an upper bound for the backoff delay. Optional.
    </ResponseField>
    <ResponseField name="minimum_backoff" type="string">
      Optional. The minimum amount of time to wait before retrying a failed task. This sets a lower bound for the backoff delay. Optional.
    </ResponseField>
    <ResponseField name="task_retry_disabled" type="bool">
      Optional. If true, task retry is disabled. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

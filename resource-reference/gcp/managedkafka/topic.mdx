`google_managedkafka_topic` is a Kafka topic within a Managed Service for Apache Kafka cluster, the named stream producers publish to and consumers read from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedkafka "github.com/ubiquex/ubx-sdk-google/sdk/go/google/managedkafka"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own topic"})

    		ubx.Resource(managedkafka.Topic, "example", managedkafka.TopicConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="configs" type="map(string)">
  Optional. Configurations for the topic that are overridden from the cluster defaults. The key of the map is a Kafka topic property name, for example: `cleanup.policy`, `compression.type`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the topic. The `topic` segment is used when connecting directly to the cluster. Structured like: projects/&#123;project&#125;/locations/&#123;location&#125;/clusters/&#123;cluster&#125;/topics/&#123;topic&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="partition_count" type="number">
  Required. The number of partitions this topic has. The partition count can only be increased, not decreased. Please note that if partitions are increased for a topic that has a key, the partitioning logic or the ordering of the messages will be affected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="replication_factor" type="number">
  Required. Immutable. The number of replicas of each partition. A replication factor of 3 is recommended for high availability. Optional; if omitted, computed by Google Cloud.
</ResponseField>

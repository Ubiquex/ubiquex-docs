`google_managedkafka_acl` defines a Kafka access control list entry restricting which principal(s) may perform a given operation (read, write, and similar) against a resource in a Managed Service for Apache Kafka cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedkafka "github.com/ubiquex/ubx-sdk-google/sdk/go/google/managedkafka"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own acl"})

    		ubx.Resource(managedkafka.Acl, "example", managedkafka.AclConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="acl_entries" type="list(object)">
  Required. The ACL entries that apply to the resource pattern. The maximum number of allowed entries 100. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="host" type="string">
      The host this ACL entry applies to; Google Cloud Managed Service for Apache Kafka requires this be the wildcard `*`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="operation" type="string">
      The Kafka operation this ACL entry grants or denies, e.g. `READ`, `WRITE`, or `ALL`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="permission_type" type="string">
      Whether this ACL entry `ALLOW`s or `DENY`s the matching operation. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="principal" type="string">
      The identity this ACL entry applies to, in the form `User:&#123;email&#125;`, or `User:*` for any principal. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. `etag` is used for concurrency control. An `etag` is returned in the response to `GetAcl` and `CreateAcl`. Callers are required to put that etag in the request to `UpdateAcl` to ensure that their change will be applied to the same version of the acl that exists in the Kafka Cluster. A terminal 'T' character in the etag indicates that the AclEntries were truncated; more entries for the Acl exist on the Kafka Cluster, but can't be returned in the Acl due to repeated field limits. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name for the acl. Represents a single Resource Pattern. Structured like: projects/&#123;project&#125;/locations/&#123;location&#125;/clusters/&#123;cluster&#125;/acls/&#123;acl_id&#125; The structure of `acl_id` defines the Resource Pattern (resource_type, resource_name, pattern_type) of the acl. `acl_id` is structured like one of the following: For acls on the cluster: `cluster` For acls on a single resource within the cluster: `topic/&#123;resource_name&#125;` `consumerGroup/&#123;resource_name&#125;` `transactionalId/&#123;resource_name&#125;` For acls on all resources that match a prefix: `topicPrefixed/&#123;resource_name&#125;` `consumerGroupPrefixed/&#123;resource_name&#125;` `transactionalIdPrefixed/&#123;resource_name&#125;` For acls on all resources of a given type (i.e. the wildcard literal "*"): `allTopics` (represents `topic/*`) `allConsumerGroups` (represents `consumerGroup/*`) `allTransactionalIds` (represents `transactionalId/*`) Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pattern_type" type="string">
  Output only. The ACL pattern type derived from the name. One of: LITERAL, PREFIXED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_name" type="string">
  Output only. The ACL resource name derived from the name. For cluster resource_type, this is always "kafka-cluster". Can be the wildcard literal "*". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_type" type="string">
  Output only. The ACL resource type derived from the name. One of: CLUSTER, TOPIC, GROUP, TRANSACTIONAL_ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

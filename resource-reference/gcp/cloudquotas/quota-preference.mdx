`google_cloudquotas_quota_preference` requests a specific quota limit for a Google Cloud service, submitted through Cloud Quotas' own centralized request-and-adjustment workflow.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudquotas "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudquotas"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own quota preference"})

    		ubx.Resource(cloudquotas.QuotaPreference, "example", cloudquotas.QuotaPreferenceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="contact_email" type="string">
  Input only. An email address that can be used to contact the user, in case Google Cloud needs more information to make a decision before additional quota can be granted. When requesting a quota increase, the email address is required. When requesting a quota decrease, the email address is optional. For example, the email address is optional when the `QuotaConfig.preferred_value` is smaller than the `QuotaDetails.reset_value`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time stamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dimensions" type="map(string)">
  Immutable. The dimensions that this quota preference applies to. The key of the map entry is the name of a dimension, such as `region`, `zone`, `network_id`, and the value of the map entry is the dimension value. If a dimension is missing from the map of dimensions, the quota preference applies to all the dimension values except for those that have other quota preferences configured for the specific value. Note: QuotaPreferences can only be applied across all values of `user` and `resource` dimension. Do not set values for `user` or `resource` in the dimension map. For example: `&#123;"provider" : "Example Organization"&#125;` where `provider` is a service-specific quota dimension and `Example Organization` is the provider name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. The current etag of the quota preference. If an etag is provided on update and does not match the current server's etag of the quota preference, the request will be blocked and an ABORTED error will be returned. See https://google.aip.dev/134#etags for more details on etags. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="justification" type="string">
  The reason / justification for this quota preference. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required except in the CREATE requests. The resource name of the quota preference. The path that follows `/locations` must be `/global`. For example: `projects/123/locations/global/quotaPreferences/my-config-for-us-east1` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="quota_config" type="object">
  The preferred quota configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="annotations" type="map(string)">
      Optional. The annotations map for clients to store small amounts of arbitrary data. Do not put PII or other sensitive information here. See https://google.aip.dev/128#annotations Optional.
    </ResponseField>
    <ResponseField name="granted_value" type="string">
      Output only. Granted quota value. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="preferred_value" type="string">
      Required. The preferred value. Must be greater than or equal to -1. If set to -1, it means the value is "unlimited". Optional.
    </ResponseField>
    <ResponseField name="request_origin" type="string">
      Output only. The origin of the quota preference request. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="state_detail" type="string">
      Output only. Optional details about the state of this quota preference. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="trace_id" type="string">
      Output only. The trace id that the Google Cloud uses to provision the requested quota. This trace id may be used by the client to contact Cloud support to track the state of a quota preference request. The trace id is only produced for increase requests and is unique for each request. The quota decrease requests do not have a trace id. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="quota_id" type="string">
  Required. The id of the quota to which the quota preference is applied. A quota name is unique in the service. For example, `CpusPerProjectPerRegion` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reconciling" type="bool">
  Output only. Is the quota preference pending Google Cloud approval and fulfillment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service" type="string">
  Required. The name of the service to which the quota preference is applied. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time stamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

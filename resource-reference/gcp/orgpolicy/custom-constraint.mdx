`google_orgpolicy_custom_constraint` defines a caller-written Organization Policy constraint restricting a specific resource field's own permitted value(s), beyond the built-in constraint library.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	orgpolicy "github.com/ubiquex/ubx-sdk-google/sdk/go/google/orgpolicy"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom constraint"})

    		ubx.Resource(orgpolicy.CustomConstraint, "example", orgpolicy.CustomConstraintConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="action_type" type="string">
  Allow or deny type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="condition" type="string">
  A Common Expression Language (CEL) condition which is used in the evaluation of the constraint. For example: `resource.instanceName.matches("(production|test)_(.+_)?[\d]+")` or, `resource.management.auto_upgrade == true` The max length of the condition is 1000 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Detailed information about this custom policy constraint. The max length of the description is 2000 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  One line display name for the UI. The max length of the display_name is 200 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="method_types" type="list(string)">
  All the operations being applied for this constraint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Name of the constraint. This is unique within the organization. The name must be of the form: * `organizations/&#123;organization_id&#125;/customConstraints/&#123;custom_constraint_id&#125;` Example: `organizations/123/customConstraints/custom.createOnlyE2TypeVms` The max length is 71 characters and the minimum length is 1. Note that the prefix `organizations/&#123;organization_id&#125;/customConstraints/custom.` is not counted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_types" type="list(string)">
  Immutable. The resource instance type on which this policy applies. Format will be of the form : `/` Example: * `compute.googleapis.com/Instance`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last time this custom constraint was updated. This represents the last time that the `CreateCustomConstraint` or `UpdateCustomConstraint` methods were called. Optional; if omitted, computed by Google Cloud.
</ResponseField>

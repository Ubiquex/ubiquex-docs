`google_orgpolicy_policy` applies an Organization Policy constraint (built-in or custom) at a specific organization, folder, or project scope, restricting what configuration is permitted underneath.

## Example

  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_orgpolicy --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_orgpolicy/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	orgpolicy "github.com/ubiquex/ubx-sdk-google/sdk/go/google_orgpolicy/orgpolicy"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own policy"})

    		ubx.Resource(orgpolicy.OrgpolicyPolicy, "example", orgpolicy.OrgpolicyPolicyConfig{
    			Name: "example",
    		})
    	}))
    }

If it is false, then no rules are inherited, and this policy becomes the new root for evaluation. This field can be set only for policies that configure list constraints. Optional.

Optional.

Must be one of the following forms, where `constraint_name` is the name of the constraint that this policy configures: * `projects/&#123;project_number&#125;/policies/&#123;constraint_name&#125;` * `folders/&#123;folder_number&#125;/policies/&#123;constraint_name&#125;` * `organizations/&#123;organization_number&#125;/policies/&#123;constraint_name&#125;` For example, `projects/123/policies/compute.disableSerialPortAccess`. Note: `projects/&#123;project_id&#125;/policies/&#123;constraint_name&#125;` is also an acceptable name for API requests, but responses will return the name using the equivalent project number. Optional; if omitted, computed by Google Cloud.
</ResponseField>

title: "google_toolresults_execution"
description: "`google_toolresults_execution` is a Tool Results API execution..."
---

`google_toolresults_execution` is a Tool Results API execution, one real run of a test (for example one Firebase Test Lab test matrix run) within a `google_toolresults_history`, made up of one or more `google_toolresults_step` entries.

<ResponseField name="state" type="string">
  The initial state is IN_PROGRESS. The only legal state transitions is from IN_PROGRESS to COMPLETE. A PRECONDITION_FAILED will be returned if an invalid transition is requested. The state can only be set to COMPLETE once. A FAILED_PRECONDITION will be returned if the state is set to COMPLETE multiple times. If the state is set to COMPLETE, all the in-progress steps within the execution will be set as COMPLETE. If the outcome of the step is not set, the outcome will be set to INCONCLUSIVE. - In response always set - In create/update request: optional Optional; if omitted, computed by Google Cloud.
</ResponseField>

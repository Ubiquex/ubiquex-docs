`google_toolresults_history` is a Tool Results API history, the top-level container grouping every `google_toolresults_execution` that belongs to the same logical test target (such as one app) over time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_toolresults --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_toolresults/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	toolresults "github.com/ubiquex/ubx-sdk-google/sdk/go/google_toolresults/toolresults"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own history"})

    		ubx.Resource(toolresults.ToolresultsHistory, "ci-runner", toolresults.ToolresultsHistoryConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_toolresults --lang ts --out ./local-sdk
    ```

  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_toolresults --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_toolresults/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_toolresults.toolresults import ToolresultsHistory, ToolresultsHistoryConfig

        ubx.intent("payments own history")

            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="display_name" type="string">
  A short human-readable (plain text) name to display in the UI. Maximum of 100 characters. - In response: present if set during create. - In create request: optional Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="history_id" type="string">
  A unique identifier within a project for this History. Returns INVALID_ARGUMENT if this field is set or overwritten by the caller. - In response always set - In create request: never set Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  A name to uniquely identify a history within a project. Maximum of 200 characters. - In response always set - In create request: always set Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="test_platform" type="string">
  The platform of the test history. - In response: always set. Returns the platform of the last execution if unknown. Optional; if omitted, computed by Google Cloud.
</ResponseField>

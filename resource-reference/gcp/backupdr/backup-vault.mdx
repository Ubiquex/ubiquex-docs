`google_backupdr_backup_vault` is the immutable, access-controlled storage container Backup and DR writes backup data into, protected against accidental or malicious deletion.

## Properties

<ResponseField name="access_restriction" type="string">
  Optional. Restricts access to certain sources and destinations for data being sent into, or restored from, the backup vault. Defaults to WITHIN_ORGANIZATION if not provided during creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="annotations" type="map(string)">
  Optional. User annotations. See https://google.aip.dev/128#annotations Stores small amounts of arbitrary data. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="backup_count" type="string">
  Output only. The number of backups in this backup vault. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="backup_minimum_enforced_retention_duration" type="string">
  Required. The default and minimum enforced retention for each backup within the backup vault. The enforced retention for each backup can be extended. Note: Longer minimum enforced retention period impacts potential storage costs post introductory trial. We recommend starting with a short duration of 3 days or less. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="backup_retention_inheritance" type="string">
  Optional. Setting for how a backup's enforced retention end time is inherited. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the instance was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="deletable" type="bool">
  Output only. Set to true when there are no backups nested under this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the BackupVault instance (2048 characters or less). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="effective_time" type="string">
  Optional. Time after which the BackupVault resource is locked. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encryption_config" type="object">
  Message describing the EncryptionConfig of backup vault. This determines how data within the vault is encrypted at rest. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_name" type="string">
      Optional. The Cloud KMS key name to encrypt backups in this backup vault. Must be in the same region as the vault. Some workload backups like compute disk backups may use their inherited source key instead. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;ring&#125;/cryptoKeys/&#123;key&#125; Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Server specified ETag for the backup vault resource to prevent simultaneous updates from overwiting each other. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels to represent user provided metadata. No labels currently defined: Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. Name of the backup vault to create. It must have the format`"projects/&#123;project&#125;/locations/&#123;location&#125;/backupVaults/&#123;backupvault&#125;"`. `&#123;backupvault&#125;` cannot be changed after creation. It must be between 3-63 characters long and must be unique within the project and location. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_account" type="string">
  Output only. Service account used by the BackupVault Service for this BackupVault. The user should grant this account permissions in their workload project to enable the service to run backups and restores there. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The BackupVault resource instance state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="total_stored_bytes" type="string">
  Output only. Total size of the storage used by all backup resources. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Immutable after resource creation until resource deletion. Optional; if omitted, computed by Google Cloud.

`google_backupdr_backup_plan_association` attaches a specific workload (e.g. a Compute Engine VM) to a Backup and DR backup plan, activating scheduled backups for it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	backupdr "github.com/ubiquex/ubx-sdk-google/sdk/go/google/backupdr"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own backup plan association"})

    		ubx.Resource(backupdr.BackupPlanAssociation, "example", backupdr.BackupPlanAssociationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_cloudsupport_case` is a real Google Cloud technical support case, created and managed through the Cloud Support API, available to Customer Care customers on Standard, Enhanced, or Premium support.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudsupport --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudsupport/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudsupport "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudsupport/cloudsupport"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own case"})

    		ubx.Resource(cloudsupport.CloudsupportCase, "ci-runner", cloudsupport.CloudsupportCaseConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="classification" type="object">
  A Case Classification represents the topic that a case is about. It's very important to use accurate classifications, because they're used to route your cases to specialists who can help you. A classification always has an ID that is its unique identifier. A valid ID is required when creating a case. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="display_name" type="string">
      A display name for the classification. The display name is not static and can change. To uniquely and consistently identify classifications, use the `CaseClassification.id` field. Optional.
    </ResponseField>
    <ResponseField name="id" type="string">
      The unique ID for a classification. Must be specified for case creation. To retrieve valid classification IDs for case creation, use `caseClassifications.search`. Classification IDs returned by `caseClassifications.search` are guaranteed to be valid for at least 6 months. If a given classification is deactiveated, it will immediately stop being returned. After 6 months, `case.create` requests using the classification ID will fail. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contact_email" type="string">
  A user-supplied email address to send case update notifications for. This should only be used in BYOID flows, where we cannot infer the user's email address directly from their EUCs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time this case was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="creator" type="object">
  An Actor represents an entity that performed an action. For example, an actor could be a user who posted a comment on a support case, a user who uploaded an attachment, or a service account that created a support case. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="display_name" type="string">
      The name to display for the actor. If not provided, it is inferred from credentials supplied during case creation. When an email is provided, a display name must also be provided. This will be obfuscated if the user is a Google Support agent. Optional.
    </ResponseField>
    <ResponseField name="email" type="string">
      The email address of the actor. If not provided, it is inferred from the credentials supplied during case creation. When a name is provided, an email must also be provided. If the user is a Google Support agent, this is obfuscated. This field is deprecated. Use `username` instead. Optional.
    </ResponseField>
    <ResponseField name="google_support" type="bool">
      Output only. Whether the actor is a Google support actor. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="username" type="string">
      Output only. The username of the actor. It may look like an email or other format provided by the identity provider. If not provided, it is inferred from the credentials supplied. When a name is provided, a username must also be provided. If the user is a Google Support agent, this will not be set. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  A broad description of the issue. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The short summary of the issue reported in this case. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="escalated" type="bool">
  Whether the case is currently escalated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="language_code" type="string">
  The language the user has requested to receive support in. This should be a BCP 47 language code (e.g., `"en"`, `"zh-CN"`, `"zh-TW"`, `"ja"`, `"ko"`). If no language or an unsupported language is specified, this field defaults to English (en). Language selection during case creation may affect your available support options. For a list of supported languages and their support working hours, see: https://cloud.google.com/support/docs/language-working-hours Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name for the case. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="priority" type="string">
  The priority of this case. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current status of the support case. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subscriber_email_addresses" type="list(string)">
  The email addresses to receive updates on this case. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="test_case" type="bool">
  Whether this case was created for internal API testing and should not be acted on by the support team. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="time_zone" type="string">
  The timezone of the user who created the support case. It should be in a format IANA recognizes: https://www.iana.org/time-zones. There is no additional validation done by the API. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time this case was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_cloudsupport_support_event_subscription` subscribes a set of email addresses to updates on a Cloud Support case or asset, automatically CC'ing them on new cases raised under that asset and on updates to cases they're subscribed to.

## Example

    ```go
    // ubx sdk gen --only google_cloudsupport --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudsupport/sdk/go
    package main

    import (

    	cloudsupport "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudsupport/cloudsupport"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own support event subscription"})

    		ubx.Resource(cloudsupport.CloudsupportSupportEventSubscription, "ci-runner", cloudsupport.CloudsupportSupportEventSubscriptionConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the subscription was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. The time at which the subscription was deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="failure_reason" type="string">
  Output only. Reason why subscription is failing. State of subscription must be FAILING in order for this to have a value. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the support event subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pub_sub_topic" type="string">
  Required. The name of the Pub/Sub topic to publish notifications to. Format: projects/&#123;project&#125;/topics/&#123;topic&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="purge_time" type="string">
  Output only. The time at which the subscription will be purged. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the subscription. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the subscription was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

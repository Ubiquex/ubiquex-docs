`google_tpu_v1alpha1_node` is a real, provisioned Cloud TPU node, the accelerator instance ML training and inference workloads run on, created directly or allocated through a `google_tpu_queued_resource` request.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	tpu "github.com/ubiquex/ubx-sdk-google/sdk/go/google/tpu"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha1 node"})

    		ubx.Resource(tpu.V1alpha1Node, "example", tpu.V1alpha1NodeConfig{

    		})
    	}))
    ```

## Properties

<ResponseField name="accelerator_type" type="string">
  Required. The type of hardware accelerators associated with this node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="api_version" type="string">
  Output only. The API version that created this Node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="cidr_block" type="string">
  The CIDR block that the TPU node will use when selecting an IP address. This CIDR block must be a /29 block; the Compute Engine networks API forbids a smaller block, and using a larger block would be wasteful (a node can only consume one IP address). Errors will occur if the CIDR block has already been used for a currently existing TPU node, the CIDR block conflicts with any subnetworks in the user's provided network, or the provided network is peered with another network that is using that CIDR block. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the node was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The user-supplied description of the TPU. Maximum of 512 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="health" type="string">
  The health status of the TPU node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="health_description" type="string">
  Output only. If this field is populated, it contains a description of why the TPU Node is unhealthy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ip_address" type="string">
  Output only. DEPRECATED! Use network_endpoints instead. The network address for the TPU Node as visible to Compute Engine instances. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user-provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Immutable. The name of the TPU Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  The name of a network they wish to peer the TPU node to. It must be a preexisting Compute Engine network inside of the project on which this API has been activated. If none is provided, "default" will be used. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network_endpoints" type="list(object)">
  Output only. The network endpoints where TPU workers can be accessed and sent work. It is recommended that Tensorflow clients of the node reach out to the 0th entry in this map first. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="ip_address" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="port" type="number">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="port" type="string">
  Output only. DEPRECATED! Use network_endpoints instead. The network port for the TPU Node as visible to Compute Engine instances. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scheduling_config" type="object">
  DEPRECATED: Please use TPU API v2alpha1 instead. Sets the scheduling options for this node. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="preemptible" type="bool">
      Defines whether the node is preemptible. Optional.
    </ResponseField>
    <ResponseField name="reserved" type="bool">
      Whether the node is created under a reservation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_account" type="string">
  Output only. The service account used to run the tensor flow services within the node. To share resources, including Google Cloud Storage data, with the Tensorflow job running in the Node, this account must have permissions to that data. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state for the TPU Node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="symptoms" type="list(object)">
  Output only. The Symptoms that have occurred to the TPU Node. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="create_time" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="details" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="symptom_type" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="worker_id" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tensorflow_version" type="string">
  Required. The version of Tensorflow running in the Node. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="use_service_networking" type="bool">
  Whether the VPC peering for the node is set up through Service Networking API. The VPC Peering should be set up before provisioning the node. If this field is set, cidr_block field should not be specified. If the network, that you want to peer the TPU Node to, is Shared VPC networks, the node must be created with this this field enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_tpu_node` is a real, provisioned Cloud TPU node, the accelerator instance ML training and inference workloads run on, created directly or allocated through a `google_tpu_queued_resource` request.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_tpu --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_tpu/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	tpu "github.com/ubiquex/ubx-sdk-google/sdk/go/google_tpu/tpu"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own node"})

    		ubx.Resource(tpu.TpuNode, "example", tpu.TpuNodeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="cidr_block" type="string">
  The CIDR block that the TPU node will use when selecting an IP address. This CIDR block must be a /29 block; the Compute Engine networks API forbids a smaller block, and using a larger block would be wasteful (a node can only consume one IP address). Errors will occur if the CIDR block has already been used for a currently existing TPU node, the CIDR block conflicts with any subnetworks in the user's provided network, or the provided network is peered with another network that is using that CIDR block. Optional; if omitted, computed by Google Cloud.
</ResponseField>

title: "google_tpu_queued_resource"
description: "`google_tpu_queued_resource` is a real Cloud TPU queued resource request..."
---

`google_tpu_queued_resource` is a real Cloud TPU queued resource request, letting a workload ask for TPU capacity (optionally against a reservation) and have the actual `google_tpu_node` allocated once that capacity becomes available, rather than failing immediately if it isn't free yet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_tpu --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_tpu/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	tpu "github.com/ubiquex/ubx-sdk-google/sdk/go/google_tpu/tpu"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own queued resource"})

    		ubx.Resource(tpu.TpuQueuedResource, "ci-runner", tpu.TpuQueuedResourceConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

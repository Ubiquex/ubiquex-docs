`google_parallelstore_instance` provisions a Parallelstore instance, a fully managed, DAOS-based parallel file system optimized for AI/ML training throughput.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_parallelstore --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_parallelstore/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	parallelstore "github.com/ubiquex/ubx-sdk-google/sdk/go/google_parallelstore/parallelstore"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own instance"})

    		ubx.Resource(parallelstore.ParallelstoreInstance, "ci-runner", parallelstore.ParallelstoreInstanceConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_parallelstore --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";
    ```

## Properties

<ResponseField name="access_points" type="list(string)">
  Output only. A list of IPv4 addresses used for client side configuration. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="capacity_gib" type="string">
  Required. Immutable. The instance's storage capacity in Gibibytes (GiB). Allowed values are between 12000 and 100000, in multiples of 4000; e.g., 12000, 16000, 20000, ... Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the instance was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="daos_version" type="string">
  Output only. Deprecated: The version of DAOS software running in the instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="deployment_type" type="string">
  Optional. Immutable. The deployment type of the instance. Allowed values are: * `SCRATCH`: the instance is a scratch instance. * `PERSISTENT`: the instance is a persistent instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the instance. 2048 characters or less. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="directory_stripe_level" type="string">
  Optional. Immutable. Stripe level for directories. Allowed values are: * `DIRECTORY_STRIPE_LEVEL_MIN`: recommended when directories contain a small number of files. * `DIRECTORY_STRIPE_LEVEL_BALANCED`: balances performance for workloads involving a mix of small and large directories. * `DIRECTORY_STRIPE_LEVEL_MAX`: recommended for directories with a large number of files. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="effective_reserved_ip_range" type="string">
  Output only. Immutable. The ID of the IP address range being used by the instance's VPC network. This field is populated by the service and contains the value currently used by the service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="file_stripe_level" type="string">
  Optional. Immutable. Stripe level for files. Allowed values are: * `FILE_STRIPE_LEVEL_MIN`: offers the best performance for small size files. * `FILE_STRIPE_LEVEL_BALANCED`: balances performance for workloads involving a mix of small and large files. * `FILE_STRIPE_LEVEL_MAX`: higher throughput performance for larger files. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Cloud Labels are a flexible and lightweight mechanism for organizing cloud resources into groups that reflect a customer's organizational needs and deployment strategies. See https://cloud.google.com/resource-manager/docs/labels-overview for details. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the instance, in the format `projects/&#123;project&#125;/locations/&#123;location&#125;/instances/&#123;instance_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Optional. Immutable. The name of the Compute Engine [VPC network](https://cloud.google.com/vpc/docs/vpc) to which the instance is connected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reserved_ip_range" type="string">
  Optional. Immutable. The ID of the IP address range being used by the instance's VPC network. See [Configure a VPC network](https://cloud.google.com/parallelstore/docs/vpc#create_and_configure_the_vpc). If no ID is provided, all ranges are considered. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The instance state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the instance was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

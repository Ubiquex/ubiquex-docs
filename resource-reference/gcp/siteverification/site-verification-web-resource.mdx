`google_siteverification_site_verification_web_resource` records a verified website or domain, confirming that the owner controls it via one of Google Site Verification real methods (a hosted file, an HTML meta tag, Google Analytics, Google Tag Manager, a DNS TXT record, or a DNS CNAME record). Verification unlocks access to other Google services (e.g. Search Console) that require confirmed site or domain ownership, and each resource can list additional owner accounts beyond the one that performed the original verification.

## Properties

<ResponseField name="id" type="string">
  The string used to identify this site. This value should be used in the "id" portion of the REST URL for the Get, Update, and Delete operations. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="owners" type="list(string)">
  The email addresses of all verified owners. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="site" type="object">
  The address and type of a site that is verified or will be verified. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="identifier" type="string">
      The site identifier. If the type is set to SITE, the identifier is a URL. If the type is set to INET_DOMAIN, the site identifier is a domain name. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      The site type. Can be SITE or INET_DOMAIN (domain name). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

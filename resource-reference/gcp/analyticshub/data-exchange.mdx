`google_analyticshub_data_exchange` is a BigQuery Analytics Hub data exchange, a real container that organizes a set of `google_analyticshub_listing` entries so an organization can publish and share BigQuery datasets internally, with partners, or publicly, without moving the underlying data.

## Example

    }

## Properties

<ResponseField name="description" type="string">
  Optional. Description of the data exchange. The description must not contain Unicode non-characters as well as C0 and C1 control codes except tabs (HT), new lines (LF), carriage returns (CR), and page breaks (FF). Default value is an empty string. Max length: 2000 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="discovery_type" type="string">
  Optional. Type of discovery on the discovery page for all the listings under this exchange. Updating this field also updates (overwrites) the discovery_type field for all the listings under this exchange. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Human-readable display name of the data exchange. The display name must contain only Unicode letters, numbers (0-9), underscores (_), dashes (-), spaces ( ), ampersands (&) and must not start or end with spaces. Default value is an empty string. Max length: 63 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="documentation" type="string">
  Optional. Documentation describing the data exchange. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="icon" type="string">
  Optional. Base64 encoded image representing the data exchange. Max Size: 3.0MiB Expected image dimensions are 512x512 pixels, however the API only performs validation on size of the encoded data. Note: For byte fields, the content of the fields are base64-encoded (which increases the size of the data by 33-36%) when using JSON on the wire. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="listing_count" type="number">
  Output only. Number of listings contained in the data exchange. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="log_linked_dataset_query_user_email" type="bool">
  Optional. By default, false. If true, the DataExchange has an email sharing mandate enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the data exchange. e.g. `projects/myproject/locations/us/dataExchanges/123`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="primary_contact" type="string">
  Optional. Email or URL of the primary point of contact of the data exchange. Max Length: 1000 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sharing_environment_config" type="object">
  Sharing environment is a behavior model for sharing data within a data exchange. This option is configurable for a data exchange. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dcr_exchange_config" type="object">
      Data Clean Room (DCR), used for privacy-safe and secured data sharing. Optional.
      <Expandable title="properties">
        <ResponseField name="single_linked_dataset_per_cleanroom" type="bool">
          Output only. If True, when subscribing to this DCR, it will create only one linked dataset containing all resources shared within the cleanroom. If False, when subscribing to this DCR, it will create 1 linked dataset per listing. This is not configurable, and by default, all new DCRs will have the restriction set to True. Computed by Google Cloud after `ship`.
        </ResponseField>
        <ResponseField name="single_selected_resource_sharing_restriction" type="bool">
          Output only. If True, this DCR restricts the contributors to sharing only a single resource in a Listing. And no two resources should have the same IDs. So if a contributor adds a view with a conflicting name, the CreateListing API will reject the request. if False, the data contributor can publish an entire dataset (as before). This is not configurable, and by default, all new DCRs will have the restriction set to True. Computed by Google Cloud after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="default_exchange_config" type="any">
      Default Analytics Hub data exchange, used for secured data sharing. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_analyticshub_listing` is a BigQuery Analytics Hub listing, a reference to one shared BigQuery dataset published inside a `google_analyticshub_data_exchange`. Subscribing to a listing creates a real, read-only linked dataset in the subscriber's own BigQuery project, with no data copy.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	analyticshub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/analyticshub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own listing"})

    		ubx.Resource(analyticshub.Listing, "example", analyticshub.ListingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="allow_only_metadata_sharing" type="bool">
  Optional. If true, the listing is only available to get the resource metadata. Listing is non subscribable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="bigquery_dataset" type="object">
  A reference to a shared dataset. It is an existing BigQuery dataset with a collection of objects such as tables and views that you want to share with subscribers. When subscriber's subscribe to a listing, Analytics Hub creates a linked dataset in the subscriber's project. A Linked dataset is an opaque, read-only BigQuery dataset that serves as a _symbolic link_ to a shared dataset. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dataset" type="string">
      Optional. Resource name of the dataset source for this listing. e.g. `projects/myproject/datasets/123` Optional.
    </ResponseField>
    <ResponseField name="effective_replicas" type="list(object)">
      Output only. Server-owned effective state of replicas. Contains both primary and secondary replicas. Each replica includes a system-computed (output-only) state and primary designation. Computed by Google Cloud after `ship`.
      <Expandable title="properties">
        <ResponseField name="location" type="string">
          The real Google Cloud region this listing's own dataset replica is hosted in. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="primary_state" type="string">
          Whether this replica is real, the primary (source of truth) copy of the shared dataset. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="replica_state" type="string">
          The real, current availability (`READY_TO_USE` or `UNAVAILABLE`) of this dataset replica. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="replica_locations" type="list(string)">
      Optional. A list of regions where the publisher has created shared dataset replicas. Optional.
    </ResponseField>
    <ResponseField name="restricted_export_policy" type="object">
      Restricted export policy used to configure restricted export on linked dataset. Optional.
      <Expandable title="properties">
        <ResponseField name="enabled" type="bool">
          Optional. If true, enable restricted export. Optional.
        </ResponseField>
        <ResponseField name="restrict_direct_table_access" type="bool">
          Optional. If true, restrict direct table access (read api/tabledata.list) on linked table. Optional.
        </ResponseField>
        <ResponseField name="restrict_query_result" type="bool">
          Optional. If true, restrict export of query result derived from restricted linked dataset table. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="selected_resources" type="list(object)">
      Optional. Resource in this dataset that is selectively shared. This field is required for data clean room exchanges. Optional.
      <Expandable title="properties">
        <ResponseField name="routine" type="string">
          The real, fully-qualified BigQuery routine (a stored procedure or function) this listing selectively shares, instead of an entire dataset. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="table" type="string">
          The real, fully-qualified BigQuery table this listing selectively shares, instead of an entire dataset. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

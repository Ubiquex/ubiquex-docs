<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_analyticshub_listing`.
</Warning>

`google_analyticshub_v1beta1_listing` is a BigQuery Analytics Hub listing, a reference to one shared BigQuery dataset published inside a `google_analyticshub_data_exchange`. Subscribing to a listing creates a real, read-only linked dataset in the subscriber's own BigQuery project, with no data copy.

## Properties

<ResponseField name="allow_only_metadata_sharing" type="bool">
  Optional. If true, the listing is only available to get the resource metadata. Listing is non subscribable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="bigquery_dataset" type="object">
  A reference to a shared dataset. It is an existing BigQuery dataset with a collection of objects such as tables and views that you want to share with subscribers. When subscriber's subscribe to a listing, Analytics Hub creates a linked dataset in the subscriber's project. A Linked dataset is an opaque, read-only BigQuery dataset that serves as a _symbolic link_ to a shared dataset. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="dataset" type="string">
      Resource name of the dataset source for this listing. e.g. `projects/myproject/datasets/123` Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="categories" type="list(string)">
  Optional. Categories of the listing. Up to five categories are allowed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="data_provider" type="object">
  Contains details of the data provider. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Optional. Name of the data provider. Optional.
    </ResponseField>
    <ResponseField name="primary_contact" type="string">
      Optional. Email or URL of the data provider. Max Length: 1000 bytes. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Short description of the listing. The description must not contain Unicode non-characters and C0 and C1 control codes except tabs (HT), new lines (LF), carriage returns (CR), and page breaks (FF). Default value is an empty string. Max length: 2000 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Human-readable display name of the listing. The display name must contain only Unicode letters, numbers (0-9), underscores (_), dashes (-), spaces ( ), ampersands (&) and can't start or end with spaces. Default value is an empty string. Max length: 63 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="documentation" type="string">
  Optional. Documentation describing the listing. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="icon" type="string">
  Optional. Base64 encoded image representing the listing. Max Size: 3.0MiB Expected image dimensions are 512x512 pixels, however the API only performs validation on size of the encoded data. Note: For byte fields, the contents of the field are base64-encoded (which increases the size of the data by 33-36%) when using JSON on the wire. Optional; if omitted, computed by Google Cloud.
</ResponseField>

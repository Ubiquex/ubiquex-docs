`google_analyticshub_query_template` is a saved, reusable SQL query attached to a BigQuery Analytics Hub data exchange or listing, published so subscribers can run a pre-built, provider-authored query against the shared dataset instead of writing their own.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	analyticshub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/analyticshub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own query template"})

    		ubx.Resource(analyticshub.QueryTemplate, "example", analyticshub.QueryTemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when the QueryTemplate was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Short description of the QueryTemplate. The description must not contain Unicode non-characters and C0 and C1 control codes except tabs (HT), new lines (LF), carriage returns (CR), and page breaks (FF). Default value is an empty string. Max length: 2000 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Human-readable display name of the QueryTemplate. The display name must contain only Unicode letters, numbers (0-9), underscores (_), dashes (-), spaces ( ), ampersands (&) and can't start or end with spaces. Default value is an empty string. Max length: 63 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="documentation" type="string">
  Optional. Documentation describing the QueryTemplate. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the QueryTemplate. e.g. `projects/myproject/locations/us/dataExchanges/123/queryTemplates/456` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="primary_contact" type="string">
  Optional. Email or URL of the primary point of contact of the QueryTemplate. Max Length: 1000 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="proposer" type="string">
  Optional. Deprecated: Use `primary_contact` instead. Email or URL of the primary point of contact of the QueryTemplate. Max Length: 1000 bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

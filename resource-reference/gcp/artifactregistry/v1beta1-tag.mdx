  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_artifactregistry_tag`.

`google_artifactregistry_v1beta1_tag` is a human-readable alias (e.g. `latest`) pointing at a specific version of an artifact stored in an Artifact Registry repository.

## Example

## Properties

<ResponseField name="name" type="string">
  The name of the tag, for example: "projects/p1/locations/us-central1/repositories/repo1/packages/pkg1/tags/tag1". If the package part contains slashes, the slashes are escaped. The tag part can only have characters in [a-zA-Z0-9\-._~:@], anything else must be URL encoded. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version" type="string">
  The name of the version the tag refers to, for example: `projects/p1/locations/us-central1/repositories/repo1/packages/pkg1/versions/sha256:5243811` If the package or version ID parts contain slashes, the slashes are escaped. Optional; if omitted, computed by Google Cloud.
</ResponseField>

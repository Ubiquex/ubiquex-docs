`google_artifactregistry_attachment` associates supplementary metadata (e.g. an SBOM or a build attestation) with a specific artifact version stored in Artifact Registry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_artifactregistry --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_artifactregistry/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google_artifactregistry/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own attachment"})

    		ubx.Resource(artifactregistry.ArtifactregistryAttachment, "ci-runner", artifactregistry.ArtifactregistryAttachmentConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_artifactregistry --lang ts --out ./local-sdk
    ```

## Properties

<ResponseField name="annotations" type="map(string)">
  Optional. User annotations. These attributes can only be set and used by the user, and not by Artifact Registry. See https://google.aip.dev/128#annotations for more details such as format and size limitations. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="attachment_namespace" type="string">
  The namespace this attachment belongs to. E.g. If an attachment is created by artifact analysis, namespace is set to `artifactanalysis.googleapis.com`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the attachment was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="files" type="list(string)">
  Required. The files that belong to this attachment. If the file ID part contains slashes, they are escaped. E.g. `projects/p1/locations/us-central1/repositories/repo1/files/sha:`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the attachment. E.g. `projects/p1/locations/us/repositories/repo/attachments/sbom`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="oci_version_name" type="string">
  Output only. The name of the OCI version that this attachment created. Only populated for Docker attachments. E.g. `projects/p1/locations/us-central1/repositories/repo1/packages/p1/versions/v1`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target" type="string">
  Required. The target the attachment is for, can be a Version, Package or Repository. E.g. `projects/p1/locations/us-central1/repositories/repo1/packages/p1/versions/v1`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Type of attachment. E.g. `application/vnd.spdx+json` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the attachment was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_artifactregistry_v1beta1_repository` is an Artifact Registry repository, storing container image(s), language package(s), or other artifact(s) of a specific format.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 repository"})

    		ubx.Resource(artifactregistry.V1beta1Repository, "example", artifactregistry.V1beta1RepositoryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the repository was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The user-provided description of the repository. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="format" type="string">
  Optional. The format of packages that are stored in the repository. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kms_key_name" type="string">
  The Cloud KMS resource name of the customer managed encryption key that's used to encrypt the contents of the Repository. Has the form: `projects/my-project/locations/my-region/keyRings/my-kr/cryptoKeys/my-key`. This value may not be changed after the Repository has been created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels with user-defined metadata. This field may contain up to 64 entries. Label keys and values may be no longer than 63 characters. Label keys must begin with a lowercase letter and may only contain lowercase letters, numeric characters, underscores, and dashes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the repository, for example: `projects/p1/locations/us-central1/repositories/repo1`. For each location in a project, repository names must be unique. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Whether or not this repository satisfies PZI. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Whether or not this repository satisfies PZS. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="size_bytes" type="string">
  Output only. The size, in bytes, of all artifact storage in this repository. Repositories that are generally available or in public preview use this to calculate storage costs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the repository was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_artifactregistry_tag` is a human-readable alias (e.g. `latest`) pointing at a specific version of an artifact stored in an Artifact Registry repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_artifactregistry --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_artifactregistry/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google_artifactregistry/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tag"})

    		ubx.Resource(artifactregistry.ArtifactregistryTag, "example", artifactregistry.ArtifactregistryTagConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="name" type="string">
  The name of the tag, for example: "projects/p1/locations/us-central1/repositories/repo1/packages/pkg1/tags/tag1". If the package part contains slashes, the slashes are escaped. The tag part can only have characters in [a-zA-Z0-9\-._~:@], anything else must be URL encoded. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version" type="string">
  The name of the version the tag refers to, for example: `projects/p1/locations/us-central1/repositories/repo1/packages/pkg1/versions/sha256:5243811` If the package or version ID parts contain slashes, the slashes are escaped. Optional; if omitted, computed by Google Cloud.
</ResponseField>

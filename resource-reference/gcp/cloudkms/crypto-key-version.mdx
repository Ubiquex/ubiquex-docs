`google_cloudkms_crypto_key_version` is a single generation of key material behind a Cloud KMS crypto key, created fresh on each rotation while older versions remain available to decrypt data encrypted under them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own crypto key version"})

    		ubx.Resource(cloudkms.CryptoKeyVersion, "example", cloudkms.CryptoKeyVersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="algorithm" type="string">
  Output only. The CryptoKeyVersionAlgorithm that this CryptoKeyVersion supports. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="attestation" type="object">
  Contains an HSM-generated attestation about a key operation. For more information, see [Verifying attestations] (https://cloud.google.com/kms/docs/attest-key). Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="cert_chains" type="object">
      Certificate chains needed to verify the attestation. Certificates in chains are PEM-encoded and are ordered based on https://tools.ietf.org/html/rfc5246#section-7.4.2. Optional.
      <Expandable title="properties">
        <ResponseField name="cavium_certs" type="list(string)">
          Cavium certificate chain corresponding to the attestation. Optional.
        </ResponseField>
        <ResponseField name="google_card_certs" type="list(string)">
          Google card certificate chain corresponding to the attestation. Optional.
        </ResponseField>
        <ResponseField name="google_partition_certs" type="list(string)">
          Google partition certificate chain corresponding to the attestation. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="content" type="string">
      Output only. The attestation data provided by the HSM when the key operation was performed. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="format" type="string">
      Output only. The format of the attestation data. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this CryptoKeyVersion was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destroy_event_time" type="string">
  Output only. The time this CryptoKeyVersion's key material was destroyed. Only present if state is DESTROYED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destroy_time" type="string">
  Output only. The time this CryptoKeyVersion's key material is scheduled for destruction. Only present if state is DESTROY_SCHEDULED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="external_destruction_failure_reason" type="string">
  Output only. The root cause of the most recent external destruction failure. Only present if state is EXTERNAL_DESTRUCTION_FAILED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="external_protection_level_options" type="object">
  ExternalProtectionLevelOptions stores a group of additional fields for configuring a CryptoKeyVersion that are specific to the EXTERNAL protection level and EXTERNAL_VPC protection levels. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="ekm_connection_backend_override" type="string">
      Optional. The resource name of the backend environment where the key material of CryptoKeyVersions is associated with. Setting this field overrides the CryptoKeyBackend. This field may be set when CryptoKeyVersions is set to EXTERNAL_VPC. Format: `projects/*/locations/*/ekmConnections/*`. Optional.
    </ResponseField>
    <ResponseField name="ekm_connection_key_path" type="string">
      Optional. The path to the external key material on the EKM when using EkmConnection e.g., "v0/my/key". Set this field instead of external_key_uri when using an EkmConnection. Optional.
    </ResponseField>
    <ResponseField name="external_key_uri" type="string">
      Optional. The URI for an external resource that this CryptoKeyVersion represents. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="generate_time" type="string">
  Output only. The time this CryptoKeyVersion's key material was generated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="generation_failure_reason" type="string">
  Output only. The root cause of the most recent generation failure. Only present if state is GENERATION_FAILED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hsm_trusted" type="bool">
  Output only. Field indicating that the key wrapping key is trusted. This field is only valid for key purpose AES_256_WRAPPING, and protection level HSM_SINGLE_TENANT. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="import_failure_reason" type="string">
  Output only. The root cause of the most recent import failure. Only present if state is IMPORT_FAILED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="import_job" type="string">
  Output only. The name of the ImportJob used in the most recent import of this CryptoKeyVersion. Only present if the underlying key material was imported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="import_time" type="string">
  Output only. The time at which this CryptoKeyVersion's key material was most recently imported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name for this CryptoKeyVersion in the format `projects/*/locations/*/keyRings/*/cryptoKeys/*/cryptoKeyVersions/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="protection_level" type="string">
  Output only. The ProtectionLevel describing how crypto operations are performed with this CryptoKeyVersion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reimport_eligible" type="bool">
  Output only. Whether or not this key version is eligible for reimport, by being specified as a target in ImportCryptoKeyVersionRequest.crypto_key_version. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  The current state of the CryptoKeyVersion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="trusted_wrapping_enabled" type="bool">
  Immutable. Field indicating that the key may be wrapped by a trusted key. This field can be set for all key purposes except ENCRYPT_DECRYPT, and is only valid for keys with protection level HSM_SINGLE_TENANT. This field can only be set at creation or import time via CreateCryptoKeyVersion, or ImportCryptoKeyVersion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

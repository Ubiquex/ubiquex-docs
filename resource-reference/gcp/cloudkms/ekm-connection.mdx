`google_cloudkms_ekm_connection` configures Cloud External Key Manager connectivity to an external key management partner, letting Cloud KMS use key material that physically stays outside Google's own infrastructure.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ekm connection"})

    		ubx.Resource(cloudkms.EkmConnection, "example", cloudkms.EkmConnectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the EkmConnection was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="crypto_space_path" type="string">
  Optional. Identifies the EKM Crypto Space that this EkmConnection maps to. Note: This field is required if KeyManagementMode is CLOUD_KMS. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Etag of the currently stored EkmConnection. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="key_management_mode" type="string">
  Optional. Describes who can perform control plane operations on the EKM. If unset, this defaults to MANUAL. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name for the EkmConnection in the format `projects/*/locations/*/ekmConnections/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_resolvers" type="list(object)">
  Optional. A list of ServiceResolvers where the EKM can be reached. There should be one ServiceResolver per EKM replica. Currently, only a single ServiceResolver is supported. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

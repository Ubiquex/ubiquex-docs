`google_cloudkms_proposal` is a quorum-based, time-limited request for a sensitive Single-tenant Cloud HSM operation (e.g. registering a new control key), which must be approved by enough administrators signing with their own control keys before it can run.

## Example

## Properties

<ResponseField name="add_quorum_member" type="object">
  Add a quorum member to the SingleTenantHsmInstance. This will increase the total_approver_count by 1. The SingleTenantHsmInstance must be in the ACTIVE state to perform this operation. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="two_factor_public_key_pem" type="string">
      Required. The public key associated with the 2FA key for the new quorum member to add. Public keys must be associated with RSA 2048 keys. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the SingleTenantHsmInstanceProposal was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_single_tenant_hsm_instance" type="any">
  Delete the SingleTenantHsmInstance. Deleting a SingleTenantHsmInstance will make all CryptoKeys attached to the SingleTenantHsmInstance unusable. The SingleTenantHsmInstance must not be in the DELETING or DELETED state to perform this operation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. The time at which the SingleTenantHsmInstanceProposal was deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disable_single_tenant_hsm_instance" type="any">
  Disable the SingleTenantHsmInstance. The SingleTenantHsmInstance must be in the ACTIVE state to perform this operation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enable_single_tenant_hsm_instance" type="any">
  Enable the SingleTenantHsmInstance. The SingleTenantHsmInstance must be in the DISABLED state to perform this operation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  The time at which the SingleTenantHsmInstanceProposal will expire if not approved and executed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="failure_reason" type="string">
  Output only. The root cause of the most recent failure. Only present if state is FAILED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name for this SingleTenantHsmInstance in the format `projects/*/locations/*/singleTenantHsmInstances/*/proposals/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="purge_time" type="string">
  Output only. The time at which the soft-deleted SingleTenantHsmInstanceProposal will be permanently purged. This field is only populated when the state is DELETED and will be set a time after expiration of the proposal, i.e. &gt;= expire_time or (create_time + ttl). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="quorum_parameters" type="object">
  Parameters of quorum approval for the SingleTenantHsmInstanceProposal. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="approved_two_factor_public_key_pems" type="list(string)">
      Output only. The public keys associated with the 2FA keys that have already approved the SingleTenantHsmInstanceProposal by signing the challenge. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="challenges" type="list(object)">
      Output only. The challenges to be signed by 2FA keys for quorum auth. M of N of these challenges are required to be signed to approve the operation. Computed by Google Cloud after `ship`.
      <Expandable title="properties">
        <ResponseField name="challenge" type="string">
          The cryptographic challenge value a quorum participant must sign to approve this proposal. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="public_key_pem" type="string">
          The PEM-encoded public key used to verify a quorum participant's own signed response to `challenge`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="required_approver_count" type="number">
      Output only. The required numbers of approvers. This is the M value used for M of N quorum auth. It is less than the number of public keys. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="refresh_single_tenant_hsm_instance" type="any">
  Refreshes the SingleTenantHsmInstance. This operation must be performed periodically to keep the SingleTenantHsmInstance active. This operation must be performed before unrefreshed_duration_until_disable has passed. The SingleTenantHsmInstance must be in the ACTIVE state to perform this operation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="register_two_factor_auth_keys" type="object">
  Register 2FA keys for the SingleTenantHsmInstance. This operation requires all Challenges to be signed by 2FA keys. The SingleTenantHsmInstance must be in the PENDING_TWO_FACTOR_AUTH_REGISTRATION state to perform this operation. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="required_approver_count" type="number">
      Required. The required numbers of approvers to set for the SingleTenantHsmInstance. This is the M value used for M of N quorum auth. Must be greater than or equal to 2 and less than or equal to total_approver_count - 1. Optional.
    </ResponseField>
    <ResponseField name="two_factor_public_key_pems" type="list(string)">
      Required. The public keys associated with the 2FA keys for M of N quorum auth. Public keys must be associated with RSA 2048 keys. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="remove_quorum_member" type="object">
  Remove a quorum member from the SingleTenantHsmInstance. This will reduce total_approver_count by 1. The SingleTenantHsmInstance must be in the ACTIVE state to perform this operation. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="two_factor_public_key_pem" type="string">
      Required. The public key associated with the 2FA key for the quorum member to remove. Public keys must be associated with RSA 2048 keys. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="required_action_quorum_parameters" type="object">
  Parameters for an approval that has both required challenges and a quorum. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="approved_two_factor_public_key_pems" type="list(string)">
      Output only. The public keys associated with the 2FA keys that have already approved the SingleTenantHsmInstanceProposal by signing the challenge. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="quorum_challenges" type="list(object)">
      Output only. The challenges to be signed by 2FA keys for quorum auth. M of N of these challenges are required to be signed to approve the operation. Computed by Google Cloud after `ship`.
      <Expandable title="properties">
        <ResponseField name="challenge" type="string">
          The cryptographic challenge value a quorum participant must sign to approve the required action. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="public_key_pem" type="string">
          The PEM-encoded public key used to verify a quorum participant's own signed response to `challenge`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="required_approver_count" type="number">
      Output only. The required number of quorum approvers. This is the M value used for M of N quorum auth. It is less than the number of public keys. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="required_challenges" type="list(object)">
      Output only. A list of specific challenges that must be signed. For some operations, this will contain a single challenge. Computed by Google Cloud after `ship`.
      <Expandable title="properties">
        <ResponseField name="challenge" type="string">
          The cryptographic challenge value that must be signed to satisfy this required action. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="public_key_pem" type="string">
          The PEM-encoded public key used to verify a signed response to `challenge`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the SingleTenantHsmInstanceProposal. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ttl" type="string">
  Input only. The TTL for the SingleTenantHsmInstanceProposal. Proposals will expire after this duration. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="upgrade_key_trust" type="object">
  Promotes a key with the AES_WRAPPING purpose to a trusted wrapping key. The key must be in the ACTIVE state to perform this operation. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Required. The name of the CryptoKeyVersion to promote. Optional.
    </ResponseField>
    <ResponseField name="two_factor_public_key_pem" type="string">
      Required. The public key associated with the 2FA key that will sign the login nonce for this operation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

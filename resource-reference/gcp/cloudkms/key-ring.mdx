## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key ring"})

    		ubx.Resource(cloudkms.KeyRing, "example", cloudkms.KeyRingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

        ubx.run("example", describe)

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which this KeyRing was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name for the KeyRing in the format `projects/*/locations/*/keyRings/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

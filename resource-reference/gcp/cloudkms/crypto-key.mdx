`google_cloudkms_crypto_key` is a named Cloud KMS key -- the logical resource applications encrypt, decrypt, or sign against -- whose own underlying key material is versioned and rotated over time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudkms --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudkms/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudkms/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own crypto key"})

    		ubx.Resource(cloudkms.CloudkmsCryptoKey, "ci-runner", cloudkms.CloudkmsCryptoKeyConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which this CryptoKey was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="crypto_key_backend" type="string">
  Immutable. The resource name of the backend environment where the key material for all CryptoKeyVersions associated with this CryptoKey reside and where all related cryptographic operations are performed. Only applicable if CryptoKeyVersions have a ProtectionLevel of EXTERNAL_VPC, with the resource name in the format `projects/*/locations/*/ekmConnections/*`. Only applicable if CryptoKeyVersions have a ProtectionLevel of HSM_SINGLE_TENANT, with the resource name in the format `projects/*/locations/*/singleTenantHsmInstances/*`. Note, this list is non-exhaustive and may apply to additional ProtectionLevels in the future. Optional; if omitted, computed by Google Cloud.
</ResponseField>

</ResponseField>

<ResponseField name="import_only" type="bool">

</ResponseField>

<ResponseField name="next_rotation_time" type="string">
  At next_rotation_time, the Key Management Service will automatically: 1. Create a new version of this CryptoKey. 2. Mark the new version as primary. Key rotations performed manually via CreateCryptoKeyVersion and UpdateCryptoKeyPrimaryVersion do not affect next_rotation_time. Keys with purpose ENCRYPT_DECRYPT support automatic rotation. For other keys, this field must be omitted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

  next_rotation_time will be advanced by this period when the service automatically rotates a key. Must be at least 24 hours and at most 876,000 hours.

`google_cloudkms_key_handle` is an Autokey-managed reference used to request a Cloud KMS key on demand from a resource's own IAM policy, letting Autokey provision and manage the underlying key automatically.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key handle"})

    		ubx.Resource(cloudkms.KeyHandle, "example", cloudkms.KeyHandleConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="kms_key" type="string">
  Output only. Name of a CryptoKey that has been provisioned for Customer Managed Encryption Key (CMEK) use in the KeyHandle project and location for the requested resource type. The CryptoKey project will reflect the value configured in the AutokeyConfig on the resource project's ancestor folder at the time of the KeyHandle creation. If more than one ancestor folder has a configured AutokeyConfig, the nearest of these configurations is used. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the KeyHandle resource, e.g. `projects/&#123;PROJECT_ID&#125;/locations/&#123;LOCATION&#125;/keyHandles/&#123;KEY_HANDLE_ID&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="resource_type_selector" type="string">
  Required. Indicates the resource type that the resulting CryptoKey is meant to protect, e.g. `&#123;SERVICE&#125;.googleapis.com/&#123;TYPE&#125;`. See documentation for supported resource types. Optional; if omitted, computed by Google Cloud.
</ResponseField>

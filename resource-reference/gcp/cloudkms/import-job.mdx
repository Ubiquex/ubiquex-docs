`google_cloudkms_import_job` sets up a secure channel for importing caller-generated key material into Cloud KMS, rather than having Cloud KMS generate the key itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own import job"})

    		ubx.Resource(cloudkms.ImportJob, "example", cloudkms.ImportJobConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="attestation" type="object">
  Contains an HSM-generated attestation about a key operation. For more information, see [Verifying attestations] (https://cloud.google.com/kms/docs/attest-key). Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="cert_chains" type="object">
      Certificate chains needed to verify the attestation. Certificates in chains are PEM-encoded and are ordered based on https://tools.ietf.org/html/rfc5246#section-7.4.2. Optional.
      <Expandable title="properties">
        <ResponseField name="cavium_certs" type="list(string)">
          Cavium certificate chain corresponding to the attestation. Optional.
        </ResponseField>
        <ResponseField name="google_card_certs" type="list(string)">
          Google card certificate chain corresponding to the attestation. Optional.
        </ResponseField>
        <ResponseField name="google_partition_certs" type="list(string)">
          Google partition certificate chain corresponding to the attestation. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="content" type="string">
      Output only. The attestation data provided by the HSM when the key operation was performed. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="format" type="string">
      Output only. The format of the attestation data. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this ImportJob was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="crypto_key_backend" type="string">
  Immutable. The resource name of the backend environment where the key material for the wrapping key resides and where all related cryptographic operations are performed. Currently, this field is only populated for keys stored in HSM_SINGLE_TENANT. Note, this list is non-exhaustive and may apply to additional ProtectionLevels in the future. Supported resources: * `"projects/*/locations/*/singleTenantHsmInstances/*"` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_event_time" type="string">
  Output only. The time this ImportJob expired. Only present if state is EXPIRED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The time at which this ImportJob is scheduled for expiration and can no longer be used to import key material. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="generate_time" type="string">
  Output only. The time this ImportJob's key material was generated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="import_method" type="string">
  Required. Immutable. The wrapping method to be used for incoming key material. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name for this ImportJob in the format `projects/*/locations/*/keyRings/*/importJobs/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="protection_level" type="string">
  Required. Immutable. The protection level of the ImportJob. This must match the protection_level of the version_template on the CryptoKey you attempt to import into. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="public_key" type="object">
  The public key component of the wrapping key. For details of the type of key this public key corresponds to, see the ImportMethod. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="data" type="string">
      Output only. Contains the public key, formatted according to the PublicKey.PublicKeyFormat specified in the KeyManagementService.GetImportJob request. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="pem" type="string">
      The public key, encoded in PEM format. For more information, see the [RFC 7468](https://tools.ietf.org/html/rfc7468) sections for [General Considerations](https://tools.ietf.org/html/rfc7468#section-2) and [Textual Encoding of Subject Public Key Info] (https://tools.ietf.org/html/rfc7468#section-13). This field gets populated by default for RSA-based import methods, if no public_key_format is specified in the request. If you want to retrieve the wrapping key of an ImportJob in some other format, use KeyManagementService.GetImportJob and set the public_key_format to the desired public key format. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="public_key_format" type="string">
  Output only. Specifies the WrappingPublicKey format provided by the customer in the KeyManagementService.GetImportJob request. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the ImportJob, indicating if it can be used. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_cloudkms_single_tenant_hsm_instance` provisions a dedicated, single-tenant Cloud HSM cluster with quorum-based administrative control, for workloads that require exclusive, non-shared hardware security module capacity.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the SingleTenantHsmInstance was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. The time at which the SingleTenantHsmInstance was deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disable_time" type="string">
  Output only. The time at which the instance will be automatically disabled if not refreshed. This field is updated upon creation and after each successful refresh operation and enable. A RefreshSingleTenantHsmInstance operation must be made via a SingleTenantHsmInstanceProposal before this time otherwise the SingleTenantHsmInstance will become disabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="key_portability_enabled" type="bool">
  Optional. Immutable. Indicates whether key portability is enabled for the SingleTenantHsmInstance. This can only be set at creation time. Key portability features are disabled by default. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name for this SingleTenantHsmInstance in the format `projects/*/locations/*/singleTenantHsmInstances/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="quorum_auth" type="object">
  Configuration for M of N quorum auth. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="required_approver_count" type="number">
      Output only. The required numbers of approvers. The M value used for M of N quorum auth. Must be greater than or equal to 2 and less than or equal to total_approver_count - 1. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="total_approver_count" type="number">
      Required. The total number of approvers. This is the N value used for M of N quorum auth. Must be greater than or equal to 3 and less than or equal to 16. Optional.
    </ResponseField>
    <ResponseField name="two_factor_public_key_pems" type="list(string)">
      Output only. The public keys associated with the 2FA keys for M of N quorum auth. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the SingleTenantHsmInstance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="unrefreshed_duration_until_disable" type="string">
  Output only. The system-defined duration that an instance can remain unrefreshed until it is automatically disabled. This will have a value of 730 days. Optional; if omitted, computed by Google Cloud.
</ResponseField>

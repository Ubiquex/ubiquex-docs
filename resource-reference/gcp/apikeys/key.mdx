## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apikeys --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apikeys/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apikeys "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apikeys/apikeys"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own key"})

    		ubx.Resource(apikeys.ApikeysKey, "ci-runner", apikeys.ApikeysKeyConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

For example: `projects/123456867718/locations/global/keys/b7ff1f9f-8275-410a-94dd-3855ee9b5dd2` NOTE: Key is a global resource; hence the only supported value for location is `global`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

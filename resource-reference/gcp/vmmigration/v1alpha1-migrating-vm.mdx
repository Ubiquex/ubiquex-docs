`google_vmmigration_v1alpha1_migrating_vm` is the real, central VM Migration resource representing one source VM's entire migration lifecycle end to end, from initial replication through `google_vmmigration_clone_job` validation to final `google_vmmigration_cutover_job`.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha1 migrating vm"})

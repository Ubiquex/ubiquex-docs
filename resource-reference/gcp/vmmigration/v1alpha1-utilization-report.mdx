<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_vmmigration_utilization_report`.
</Warning>

`google_vmmigration_v1alpha1_utilization_report` is a real, generated report of a source environment's own resource utilization (CPU, memory, disk), used to right-size the migrated VM's machine type in Google Cloud before cutover.

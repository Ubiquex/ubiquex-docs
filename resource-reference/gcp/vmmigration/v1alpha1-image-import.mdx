<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_vmmigration_image_import`.
</Warning>

`google_vmmigration_v1alpha1_image_import` imports a real, existing disk image into VM Migration's own managed image format, a source for creating migrated VMs from an image rather than from a live, running source VM.

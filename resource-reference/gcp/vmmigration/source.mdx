`google_vmmigration_source` is the real, registered origin environment (an on-premises vCenter, AWS, or Azure environment) VM Migration discovers and replicates VMs from, the parent every `google_vmmigration_migrating_vm` in that environment is scoped under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmmigration "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vmmigration"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own source"})

    		ubx.Resource(vmmigration.Source, "example", vmmigration.SourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_vmmigration_clone_job`.
</Warning>

`google_vmmigration_v1alpha1_clone_job` is a real VM Migration test-clone job, creating a copy of the source VM in the defined landing zone so it can be validated in Google Cloud before a real cutover is performed.

`google_vmmigration_v1alpha1_target_project` is the real Google Cloud project VM Migration lands a migrated VM's Persistent Disk volumes and Compute Engine instance into, configurable up until the actual clone or cutover is executed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmmigration "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vmmigration"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha1 target project"})

    		ubx.Resource(vmmigration.V1alpha1TargetProject, "example", vmmigration.V1alpha1TargetProjectConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time this target project resource was created (not related to when the Compute Engine project it points to was created). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The target project's description. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of the target project. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="project" type="string">
  Required. The target project ID (number) or project name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last time the target project resource was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

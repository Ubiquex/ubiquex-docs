<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_vmmigration_group`.
</Warning>

`google_vmmigration_v1alpha1_group` is a real VM Migration group, letting related `google_vmmigration_migrating_vm` resources be managed together (for example migrated or cut over as one coordinated batch) rather than one at a time.

## Example

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmmigration "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vmmigration"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha1 group"})

    		ubx.Resource(vmmigration.V1alpha1Group, "example", vmmigration.V1alpha1GroupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

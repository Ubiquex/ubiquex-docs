`google_vpcaccess_connector` provisions a Serverless VPC Access connector, letting App Engine, Cloud Functions, or Cloud Run reach resources inside a VPC network by their own internal IP address.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vpcaccess "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vpcaccess"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connector"})

    		ubx.Resource(vpcaccess.Connector, "example", vpcaccess.ConnectorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="connected_projects" type="list(string)">
  Output only. List of projects using the connector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ip_cidr_range" type="string">
  Optional. The range of internal addresses that follows RFC 4632 notation. Example: `10.132.0.0/28`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="machine_type" type="string">
  Machine type of VM Instance underlying connector. Default is e2-micro Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="max_instances" type="number">
  Maximum value of instances in autoscaling group underlying the connector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="max_throughput" type="number">
  Maximum throughput of the connector in Mbps. Refers to the expected throughput when using an `e2-micro` machine type. Value must be a multiple of 100 from 300 through 1000. Must be higher than the value specified by --min-throughput. If both max-throughput and max-instances are provided, max-instances takes precedence over max-throughput. The use of `max-throughput` is discouraged in favor of `max-instances`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="min_instances" type="number">
  Minimum value of instances in autoscaling group underlying the connector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="min_throughput" type="number">
  Minimum throughput of the connector in Mbps. Refers to the expected throughput when using an `e2-micro` machine type. Value must be a multiple of 100 from 200 through 900. Must be lower than the value specified by --max-throughput. If both min-throughput and min-instances are provided, min-instances takes precedence over min-throughput. The use of `min-throughput` is discouraged in favor of `min-instances`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name in the format `projects/*/locations/*/connectors/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Optional. Name of a VPC network. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the VPC access connector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subnet" type="object">
  The subnet in which to house the connector Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Optional. Subnet name (relative, not fully qualified). E.g. if the full subnet selfLink is https://compute.googleapis.com/compute/v1/projects/&#123;project&#125;/regions/&#123;region&#125;/subnetworks/&#123;subnetName&#125; the correct input for this field would be &#123;subnetName&#125; Optional.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      Optional. Project in which the subnet exists. If not set, this project is assumed to be the project for which the connector create request was issued. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

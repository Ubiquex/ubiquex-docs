`google_ids_endpoint` provisions a Cloud IDS (Intrusion Detection System) endpoint, mirroring a VPC network's own traffic to a managed Palo Alto Networks threat-detection engine.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	ids "github.com/ubiquex/ubx-sdk-google/sdk/go/google/ids"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint"})

    		ubx.Resource(ids.Endpoint, "example", ids.EndpointConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {

      resource(Endpoint, "example", {
        name: "example",
      });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.ids.endpoint import Endpoint, EndpointConfig

    def describe():
        ubx.intent("example own endpoint")

        ubx.resource(Endpoint, "example", EndpointConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The create time timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  User-provided description of the endpoint Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="endpoint_forwarding_rule" type="string">
  Output only. The fully qualified URL of the endpoint's ILB Forwarding Rule. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="endpoint_ip" type="string">
  Output only. The IP address of the IDS Endpoint's ILB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels of the endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of the endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Required. The fully qualified URL of the network to which the IDS Endpoint is attached. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. [Output Only] Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. [Output Only] Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="severity" type="string">
  Required. Lowest threat severity that this endpoint will alert on. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Current state of the endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="threat_exceptions" type="list(string)">
  List of threat IDs to be excepted from generating alerts. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="traffic_logs" type="bool">
  Whether the endpoint should report traffic logs in addition to threat logs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The update time timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_bigquerydatatransfer_transfer_config` schedules BigQuery Data Transfer Service to automatically and recurringly load data from a supported source (e.g. Google Ads, YouTube, or another BigQuery dataset) into BigQuery.

## Properties

<ResponseField name="data_refresh_window_days" type="number">
  The number of days to look back to automatically refresh the data. For example, if `data_refresh_window_days = 10`, then every day BigQuery reingests data for [today-10, today-1], rather than ingesting data for just [today-1]. Only valid if the data source supports the feature. Set the value to 0 to use the default value. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="data_source_id" type="string">
  Data source ID. This cannot be changed once data transfer is created. The full list of available data source IDs can be returned through an API call: https://cloud.google.com/bigquery-transfer/docs/reference/datatransfer/rest/v1/projects.locations.dataSources/list Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dataset_region" type="string">
  Output only. Region in which BigQuery dataset is located. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination_dataset_id" type="string">
  The BigQuery target dataset id. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Is this config disabled. When set to true, no runs will be scheduled for this transfer config. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  User specified display name for the data transfer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

  Identifier. The resource name of the transfer config. The name is ignored when creating a transfer config. Optional; if omitted, computed by Google Cloud.

</ResponseField>

<ResponseField name="params" type="map(any)">
  Parameters specific to each data source. For more information see the bq tab in the 'Setting up a data transfer' section for each data source. For example the parameters for Cloud Storage transfers are listed here: https://cloud.google.com/bigquery-transfer/docs/cloud-storage-transfer#bq Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schedule" type="string">
  Data transfer schedule. If the data source does not support a custom schedule, this should be empty. If it is empty, the default value for the data source will be used. The specified times are in UTC. Examples of valid format: `1st,3rd monday of month 15:30`, `every wed,fri of jan,jun 13:15`, and `first sunday of quarter 00:00`. See more explanation about the format here: https://cloud.google.com/appengine/docs/flexible/python/scheduling-jobs-with-cron-yaml#the_schedule_format NOTE: The minimum interval time between recurring transfers depends on the data source; refer to the documentation for your data source. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schedule_options" type="object">
  Options customizing the data transfer schedule. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="disable_auto_scheduling" type="bool">
      If true, automatic scheduling of data transfer runs for this configuration will be disabled. The runs can be started on ad-hoc basis using StartManualTransferRuns API. When automatic scheduling is disabled, the TransferConfig.schedule field will be ignored. Optional.
    </ResponseField>
    <ResponseField name="end_time" type="string">
      Defines time to stop scheduling transfer runs. A transfer run cannot be scheduled at or after the end time. The end time can be changed at any moment. The time when a data transfer can be triggered manually is not limited by this option. Optional.
    </ResponseField>
    <ResponseField name="start_time" type="string">
      Specifies time to start scheduling transfer runs. The first run will be scheduled at or after the start time according to a recurrence pattern defined in the schedule string. The start time can be changed at any moment. The time when a data transfer can be triggered manually is not limited by this option. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="schedule_options_v2" type="object">

ScheduleOptionsV2 cannot be used together with ScheduleOptions/Schedule. Optional; if omitted, computed by Google Cloud.

The specified times are in UTC. Examples of valid format: `1st,3rd monday of month 15:30`, `every wed,fri of jan,jun 13:15`, and `first sunday of quarter 00:00`. See more explanation about the format here: https://cloud.google.com/appengine/docs/flexible/python/scheduling-jobs-with-cron-yaml#the_schedule_format NOTE: The minimum interval time between recurring transfers depends on the data source; refer to the documentation for your data source. Optional.
        </ResponseField>
        <ResponseField name="start_time" type="string">
          Specifies time to start scheduling transfer runs. The first run will be scheduled at or after the start time according to a recurrence pattern defined in the schedule string. The start time can be changed at any moment. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

`google_aiplatform_v1beta1_feature_monitor_job` is a single run of a feature monitor, comparing the current feature values against a real drift baseline (drift_base_feature_monitor_job_id, drift_base_snapshot_time) and recording its own final_status and job_summary, so one specific monitoring run can be inspected independently of the monitor's own ongoing schedule.

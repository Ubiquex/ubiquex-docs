`google_aiplatform_evaluation_set` is a reusable, named collection of evaluation input cases (prompts, reference outputs, or both) that a Vertex AI Gen AI Evaluation Service evaluation run is executed against.

    	ubx.Main(ubx.Stack("example", func() {

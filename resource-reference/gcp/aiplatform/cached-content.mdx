---
title: "google_aiplatform_cached_content"
description: "`google_aiplatform_cached_content` stores a large..."
---

`google_aiplatform_cached_content` stores a large, reusable prompt payload (e.g. a lengthy document or video) on the server side so repeated Gemini API calls referencing it avoid re-uploading and re-processing the same content, lowering latency and cost.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cached content"})

    		ubx.Resource(aiplatform.CachedContent, "example", aiplatform.CachedContentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

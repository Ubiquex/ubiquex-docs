<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_reasoning_engine`.
</Warning>

`google_aiplatform_v1beta1_reasoning_engine` deploys an agent (built with a framework like LangChain or the Agent Development Kit) onto Vertex AI Agent Engine's own managed runtime, giving it a servable endpoint without the caller having to manage the underlying infrastructure.

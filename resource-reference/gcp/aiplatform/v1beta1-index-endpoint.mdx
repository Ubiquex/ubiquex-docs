<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_index_endpoint`.
</Warning>

`google_aiplatform_v1beta1_index_endpoint` is the deployed, servable target a Vertex AI Vector Search index is attached to, handling nearest-neighbor query traffic against the index's own embeddings.

`google_aiplatform_time_sery` (a TimeSeries) is a single named sequence of scalar or tensor data points -- e.g. one training run's own loss curve -- logged to a Vertex AI TensorBoard for visualization.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_aiplatform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_aiplatform/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_aiplatform/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own time sery"})

    		ubx.Resource(aiplatform.AiplatformTimeSery, "ci-runner", aiplatform.AiplatformTimeSeryConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this TensorboardTimeSeries was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of this TensorboardTimeSeries. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. User provided name of this TensorboardTimeSeries. This value should be unique among all TensorboardTimeSeries resources belonging to the same TensorboardRun resource (parent resource). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Used to perform a consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="object">
  Describes metadata for a TensorboardTimeSeries. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="max_blob_sequence_length" type="string">
      Output only. The largest blob sequence length (number of blobs) of all data points in this time series, if its ValueType is BLOB_SEQUENCE. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="max_step" type="string">
      Output only. Max step index of all data points within a TensorboardTimeSeries. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="max_wall_time" type="string">
      Output only. Max wall clock timestamp of all data points within a TensorboardTimeSeries. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the TensorboardTimeSeries. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="plugin_data" type="string">
  Data of the current plugin, with the size limited to 65KB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="plugin_name" type="string">
  Immutable. Name of the plugin this time series pertain to. Such as Scalar, Tensor, Blob Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this TensorboardTimeSeries was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="value_type" type="string">
  Required. Immutable. Type of TensorboardTimeSeries value. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_aiplatform_v1beta1_rag_data_schema` defines the real schema (schema_details) that data ingested into a Retrieval-Augmented Generation (RAG) corpus must conform to, keyed by a real key, so a RAG pipeline can validate and structure incoming data consistently rather than accepting arbitrary shapes.

## Properties

<ResponseField name="key" type="string">
  Required. The key of this data schema. This key should be matching the key of user specified metadata and unique inside corpus. This value can be up to 63 characters, and valid characters are /a-z-/. The first character must be a letter, the last could be a letter or a number. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of the data schema in the form of: `projects/&#123;project_number&#125;/locations/&#123;location&#125;/ragCorpora/&#123;rag_corpus&#125;/ragDataSchemas/&#123;rag_data_schema&#125;` where the &#123;rag_data_schema&#125; part should be the same as the `key` field below. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_details" type="object">
  Data schema details indicates the data type and the data struct corresponding to the key of user specified metadata. Optional; if omitted, computed by Google Cloud.

`google_aiplatform_feature` defines a single named, typed ML feature (e.g. `age` or `click_count`) within a Vertex AI Feature Store's own feature group or legacy entity type.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own feature"})

    		ubx.Resource(aiplatform.Feature, "example", aiplatform.FeatureConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Only applicable for Vertex AI Feature Store (Legacy). Timestamp when this EntityType was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the Feature. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disable_monitoring" type="bool">
  Optional. Only applicable for Vertex AI Feature Store (Legacy). If not set, use the monitoring_config defined for the EntityType this Feature belongs to. Only Features with type (Feature.ValueType) BOOL, STRING, DOUBLE or INT64 can enable monitoring. If set to true, all types of data monitoring are disabled despite the config on EntityType. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Used to perform a consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. The labels with user-defined metadata to organize your Features. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. See https://goo.gl/xmQnxf for more information on and examples of labels. No more than 64 user labels can be associated with one Feature (System labels are excluded)." System reserved label keys are prefixed with "aiplatform.googleapis.com/" and are immutable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="monitoring_stats_anomalies" type="list(object)">
  Output only. Only applicable for Vertex AI Feature Store (Legacy). The list of historical stats and anomalies with specified objectives. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="feature_stats_anomaly" type="object">
      Detail about one detected anomaly in this feature's own statistics. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="anomaly_detection_threshold" type="number">
          The deviation threshold that was crossed to trigger this anomaly. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="anomaly_uri" type="string">
          A URI with further detail about this detected anomaly. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="distribution_deviation" type="number">
          How far this feature's own current value distribution has deviated from its baseline. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="end_time" type="string">
          When this operation, run, or window ended. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="score" type="number">
          The numeric score this evaluation produced. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="start_time" type="string">
          When this operation, run, or window started. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="stats_uri" type="string">
          A URI with the full statistics this anomaly was detected from. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="objective" type="string">
      Which kind of analysis produced this result, e.g. `IMPORT_FEATURE_ANALYSIS` or `SNAPSHOT_ANALYSIS`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Name of the Feature. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/featurestores/&#123;featurestore&#125;/entityTypes/&#123;entity_type&#125;/features/&#123;feature&#125;` `projects/&#123;project&#125;/locations/&#123;location&#125;/featureGroups/&#123;feature_group&#125;/features/&#123;feature&#125;` The last part feature is assigned by the client. The feature can be up to 64 characters long and can consist only of ASCII Latin letters A-Z and a-z, underscore(_), and ASCII digits 0-9 starting with a letter. The value will be unique given an entity type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="point_of_contact" type="string">
  Entity responsible for maintaining this feature. Can be comma separated list of email addresses or URIs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Only applicable for Vertex AI Feature Store (Legacy). Timestamp when this EntityType was most recently updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="value_type" type="string">
  Immutable. Only applicable for Vertex AI Feature Store (Legacy). Type of Feature value. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version_column_name" type="string">
  Only applicable for Vertex AI Feature Store. The name of the BigQuery Table/View column hosting data for this version. If no value is provided, will use feature_id. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_aiplatform_v1beta1_a2a_task` is a single running task within a Vertex AI Agent2Agent (A2A) conversation -- it tracks the task's own state, its output artifacts, and its event history (next_event_sequence_number, history), scoped to a real context_id, so an agent-to-agent exchange can be resumed or inspected mid-conversation rather than only observed at completion.

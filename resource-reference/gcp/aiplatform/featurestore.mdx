`google_aiplatform_featurestore` is the top-level container in Vertex AI's legacy Feature Store, holding the entity type(s) and their own feature definitions used for both training and online serving.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own featurestore"})

    		ubx.Resource(aiplatform.Featurestore, "example", aiplatform.FeaturestoreConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this Featurestore was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encryption_spec" type="object">
  Represents a customer-managed encryption key specification that can be applied to a Vertex AI resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_name" type="string">
      Required. Resource name of the Cloud KMS key used to protect the resource. The Cloud KMS key must be in the same region as the resource. It must have the format `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;key_ring&#125;/cryptoKeys/&#123;crypto_key&#125;`. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. The labels with user-defined metadata to organize your Featurestore. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. See https://goo.gl/xmQnxf for more information on and examples of labels. No more than 64 user labels can be associated with one Featurestore(System labels are excluded)." System reserved label keys are prefixed with "aiplatform.googleapis.com/" and are immutable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the Featurestore. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/featurestores/&#123;featurestore&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="online_serving_config" type="object">
  OnlineServingConfig specifies the details for provisioning online serving resources. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="fixed_node_count" type="number">
      The number of nodes for the online store. The number of nodes doesn't scale automatically, but you can manually update the number of nodes. If set to 0, the featurestore will not have an online store and cannot be used for online serving. Optional.
    </ResponseField>
    <ResponseField name="scaling" type="object">
      Online serving scaling configuration. If min_node_count and max_node_count are set to the same value, the cluster will be configured with the fixed number of node (no auto-scaling). Optional.
      <Expandable title="properties">
        <ResponseField name="cpu_utilization_target" type="number">
          Optional. The cpu utilization that the Autoscaler should be trying to achieve. This number is on a scale from 0 (no utilization) to 100 (total utilization), and is limited between 10 and 80. When a cluster's CPU utilization exceeds the target that you have set, Bigtable immediately adds nodes to the cluster. When CPU utilization is substantially lower than the target, Bigtable removes nodes. If not set or set to 0, default to 50. Optional.
        </ResponseField>
        <ResponseField name="max_node_count" type="number">
          The maximum number of nodes to scale up to. Must be greater than min_node_count, and less than or equal to 10 times of 'min_node_count'. Optional.
        </ResponseField>
        <ResponseField name="min_node_count" type="number">
          Required. The minimum number of nodes to scale down to. Must be greater than or equal to 1. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="online_storage_ttl_days" type="number">
  Optional. TTL in days for feature values that will be stored in online serving storage. The Feature Store online storage periodically removes obsolete feature values older than `online_storage_ttl_days` since the feature generation time. Note that `online_storage_ttl_days` should be less than or equal to `offline_storage_ttl_days` for each EntityType under a featurestore. If not set, default to 4000 days Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the featurestore. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this Featurestore was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

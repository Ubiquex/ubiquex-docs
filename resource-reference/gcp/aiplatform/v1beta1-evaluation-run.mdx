<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_evaluation_run`.
</Warning>

`google_aiplatform_v1beta1_evaluation_run` is a single execution of the Vertex AI Gen AI Evaluation Service against a dataset or evaluation set, producing scored results per item across the configured metric(s).

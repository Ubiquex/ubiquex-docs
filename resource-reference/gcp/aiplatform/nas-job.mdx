---
title: "google_aiplatform_nas_job"
description: "`google_aiplatform_nas_job` runs Vertex AI Neural Architecture Search..."
---

`google_aiplatform_nas_job` runs Vertex AI Neural Architecture Search, which automatically searches a defined space of possible model architectures to find one that best optimizes a chosen objective (e.g. accuracy under a latency budget).

## Example

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

    }

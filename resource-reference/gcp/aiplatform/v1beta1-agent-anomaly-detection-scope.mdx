No stable, generally-available equivalent is published yet.

`google_aiplatform_v1beta1_agent_anomaly_detection_scope` defines the scope an agent's own anomaly detection watches -- a real set of log buckets and observability buckets -- so anomaly detection can be pointed at exactly the logs and telemetry that matter for a given agent, not the account's entire log volume.

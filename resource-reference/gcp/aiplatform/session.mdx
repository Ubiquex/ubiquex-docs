`google_aiplatform_session` is a single, stateful conversation between a user and an agent deployed on Vertex AI Agent Engine, holding the chronological sequence of message(s) and action(s) exchanged during that interaction.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own session"})

    		ubx.Resource(aiplatform.Session, "example", aiplatform.SessionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when the session was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. The display name of the session. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Optional. Timestamp of when this session is considered expired. This is *always* provided on output, regardless of what was sent on input. The minimum value is 24 hours from the time of creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize your Sessions. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. See https://goo.gl/xmQnxf for more information and examples of labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the session. Format: 'projects/&#123;project&#125;/locations/&#123;location&#125;/reasoningEngines/&#123;reasoning_engine&#125;/sessions/&#123;session&#125;'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="session_state" type="map(any)">
  Optional. Session specific memory which stores key conversation points. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ttl" type="string">
  Optional. Input only. The TTL for this session. The minimum value is 24 hours. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when the session was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_id" type="string">
  Required. Immutable. String id provided by the user Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_aiplatform_v1beta1_sandbox_environment_template` defines the reusable configuration (base image, resource limits) a Vertex AI Agent Engine sandbox environment is created from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 sandbox environment template"})

    		ubx.Resource(aiplatform.V1beta1SandboxEnvironmentTemplate, "example", aiplatform.V1beta1SandboxEnvironmentTemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this SandboxEnvironmentTemplate was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="custom_container_environment" type="object">
  The customized sandbox runtime environment for BYOC. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="custom_container_spec" type="object">
      Specification for deploying from a custom container image. Optional.
      <Expandable title="properties">
        <ResponseField name="image_uri" type="string">
          Required. The Artifact Registry Docker image URI (e.g., us-central1-docker.pkg.dev/my-project/my-repo/my-image:tag) of the container image that is to be run on each worker replica. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="ports" type="list(object)">
      Ports to expose from the container. Optional.
      <Expandable title="properties">
        <ResponseField name="port" type="number">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
        <ResponseField name="protocol" type="string">
          Optional; if omitted, computed by Google Cloud.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="resources" type="object">
      Message to define resource requests and limits (mirroring Kubernetes) for each sandbox instance created from this template. Optional.
      <Expandable title="properties">
        <ResponseField name="limits" type="map(string)">
          Optional. The maximum amounts of compute resources allowed. Keys are resource names (e.g., "cpu", "memory"). Values are quantities (e.g., "500m", "1Gi"). Optional.
        </ResponseField>
        <ResponseField name="requests" type="map(string)">
          Optional. The requested amounts of compute resources. Keys are resource names (e.g., "cpu", "memory"). Values are quantities (e.g., "250m", "512Mi"). Optional.

      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

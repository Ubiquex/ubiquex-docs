<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_cached_content`.
</Warning>

`google_aiplatform_v1beta1_cached_content` stores a large, reusable prompt payload (e.g. a lengthy document or video) on the server side so repeated Gemini API calls referencing it avoid re-uploading and re-processing the same content, lowering latency and cost.

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_endpoint`.
</Warning>

`google_aiplatform_v1beta1_endpoint` is the deployed, servable HTTP target a Vertex AI model is attached to for online prediction, handling request routing and traffic splitting across one or more deployed model versions.

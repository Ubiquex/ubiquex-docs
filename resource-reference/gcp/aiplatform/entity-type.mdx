`google_aiplatform_entity_type` defines a category of entity (e.g. `user` or `product`) within a legacy Vertex AI Feature Store, grouping the feature(s) computed for every instance of that entity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entity type"})

    		ubx.Resource(aiplatform.EntityType, "example", aiplatform.EntityTypeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this EntityType was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the EntityType. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Used to perform a consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. The labels with user-defined metadata to organize your EntityTypes. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. See https://goo.gl/xmQnxf for more information on and examples of labels. No more than 64 user labels can be associated with one EntityType (System labels are excluded)." System reserved label keys are prefixed with "aiplatform.googleapis.com/" and are immutable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="monitoring_config" type="object">
  Configuration of how features in Featurestore are monitored. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="categorical_threshold_config" type="object">
      The config for Featurestore Monitoring threshold. Optional.
      <Expandable title="properties">
        <ResponseField name="value" type="number">
          Specify a threshold value that can trigger the alert. 1. For categorical feature, the distribution distance is calculated by L-inifinity norm. 2. For numerical feature, the distribution distance is calculated by Jensen -- Shannon divergence. Each feature must have a non-zero threshold if they need to be monitored. Otherwise no alert will be triggered for that feature. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="import_features_analysis" type="object">
      Configuration of the Featurestore's ImportFeature Analysis Based Monitoring. This type of analysis generates statistics for values of each Feature imported by every ImportFeatureValues operation. Optional.
      <Expandable title="properties">
        <ResponseField name="anomaly_detection_baseline" type="string">
          The baseline used to do anomaly detection for the statistics generated by import features analysis. Optional.
        </ResponseField>
        <ResponseField name="state" type="string">
          Whether to enable / disable / inherite default hebavior for import features analysis. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="numerical_threshold_config" type="object">
      The config for Featurestore Monitoring threshold. Optional.
      <Expandable title="properties">
        <ResponseField name="value" type="number">
          Specify a threshold value that can trigger the alert. 1. For categorical feature, the distribution distance is calculated by L-inifinity norm. 2. For numerical feature, the distribution distance is calculated by Jensen -- Shannon divergence. Each feature must have a non-zero threshold if they need to be monitored. Otherwise no alert will be triggered for that feature. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="snapshot_analysis" type="object">
      Configuration of the Featurestore's Snapshot Analysis Based Monitoring. This type of analysis generates statistics for each Feature based on a snapshot of the latest feature value of each entities every monitoring_interval. Optional.
      <Expandable title="properties">
        <ResponseField name="disabled" type="bool">
          The monitoring schedule for snapshot analysis. For EntityType-level config: unset / disabled = true indicates disabled by default for Features under it; otherwise by default enable snapshot analysis monitoring with monitoring_interval for Features under it. Feature-level config: disabled = true indicates disabled regardless of the EntityType-level config; unset monitoring_interval indicates going with EntityType-level config; otherwise run snapshot analysis monitoring with monitoring_interval regardless of the EntityType-level config. Explicitly Disable the snapshot analysis based monitoring. Optional.
        </ResponseField>
        <ResponseField name="monitoring_interval_days" type="number">
          Configuration of the snapshot analysis based monitoring pipeline running interval. The value indicates number of days. Optional.
        </ResponseField>
        <ResponseField name="staleness_days" type="number">
          Customized export features time window for snapshot analysis. Unit is one day. Default value is 3 weeks. Minimum value is 1 day. Maximum value is 4000 days. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Name of the EntityType. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/featurestores/&#123;featurestore&#125;/entityTypes/&#123;entity_type&#125;` The last part entity_type is assigned by the client. The entity_type can be up to 64 characters long and can consist only of ASCII Latin letters A-Z and a-z and underscore(_), and ASCII digits 0-9 starting with a letter. The value will be unique given a featurestore. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="offline_storage_ttl_days" type="number">
  Optional. Config for data retention policy in offline storage. TTL in days for feature values that will be stored in offline storage. The Feature Store offline storage periodically removes obsolete feature values older than `offline_storage_ttl_days` since the feature generation time. If unset (or explicitly set to 0), default to 4000 days TTL. Optional; if omitted, computed by Google Cloud.
</ResponseField>

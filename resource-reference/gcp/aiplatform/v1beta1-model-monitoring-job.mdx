<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_aiplatform_v1beta1_model_monitoring_job` is a single run of a model monitor, executed on a real schedule (schedule, schedule_time) against the monitor's own model_monitoring_spec, recording its own job_execution_detail and state, so one specific monitoring run can be inspected independently of the monitor's own ongoing schedule.

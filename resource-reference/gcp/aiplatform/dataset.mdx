`google_aiplatform_dataset` represents a managed collection of training data (image, tabular, text, or video) that Vertex AI's own AutoML and custom training jobs can reference directly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dataset"})

    		ubx.Resource(aiplatform.Dataset, "example", aiplatform.DatasetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize your Datasets. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. No more than 64 user labels can be associated with one Dataset (System labels are excluded). See https://goo.gl/xmQnxf for more information and examples of labels. System reserved label keys are prefixed with "aiplatform.googleapis.com/" and are immutable. Following system labels exist for each Dataset: * "aiplatform.googleapis.com/dataset_metadata_schema": output only, its value is the metadata_schema's title. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="any">
  Required. Additional information about the Dataset. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata_artifact" type="string">
  Output only. The resource name of the Artifact that was created in MetadataStore when creating the Dataset. The Artifact resource name pattern is `projects/&#123;project&#125;/locations/&#123;location&#125;/metadataStores/&#123;metadata_store&#125;/artifacts/&#123;artifact&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata_schema_uri" type="string">
  Required. Points to a YAML file stored on Google Cloud Storage describing additional information about the Dataset. The schema is defined as an OpenAPI 3.0.2 Schema Object. The schema files that can be used here are found in gs://google-cloud-aiplatform/schema/dataset/metadata/. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="model_reference" type="string">

</ResponseField>

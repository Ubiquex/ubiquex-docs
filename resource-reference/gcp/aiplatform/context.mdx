`google_aiplatform_context` groups related Vertex AI ML Metadata artifacts and executions together under one logical unit, e.g. all the artifacts produced across a single experiment run or pipeline execution.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_aiplatform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_aiplatform/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_aiplatform/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own context"})

    		ubx.Resource(aiplatform.AiplatformContext, "ci-runner", aiplatform.AiplatformContextConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_aiplatform --lang ts --out ./local-sdk
    ```

  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_aiplatform --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_aiplatform/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_aiplatform.aiplatform import AiplatformContext, AiplatformContextConfig

    def describe():
        ubx.intent("payments own context")

        ubx.resource(AiplatformContext, "ci-runner", AiplatformContextConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this Context was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the Context Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  User provided display name of the Context. May be up to 128 Unicode characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  An eTag used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize your Contexts. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. No more than 64 user labels can be associated with one Context (System labels are excluded). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="map(any)">
  Properties of the Context. Top level metadata keys' heading and trailing spaces will be trimmed. The size of this field should not exceed 200KB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the Context. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent_contexts" type="list(string)">
  Output only. A list of resource names of Contexts that are parents of this Context. A Context may have at most 10 parent_contexts. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_title" type="string">
  The title of the schema describing the metadata. Schema title and version is expected to be registered in earlier Create Schema calls. And both are used together as unique identifiers to identify schemas within the local metadata store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_version" type="string">
  The version of the schema in schema_name to use. Schema title and version is expected to be registered in earlier Create Schema calls. And both are used together as unique identifiers to identify schemas within the local metadata store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this Context was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

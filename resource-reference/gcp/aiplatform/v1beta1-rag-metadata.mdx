`google_aiplatform_v1beta1_rag_metadata` is arbitrary, user-specified metadata (user_specified_metadata) attached to a RAG resource, letting a team record their own real, application-specific context alongside a RAG corpus without Vertex AI needing to model that context itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 rag metadata"})

    		ubx.Resource(aiplatform.V1beta1RagMetadata, "example", aiplatform.V1beta1RagMetadataConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="name" type="string">
  Identifier. Resource name of the RagMetadata. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/ragCorpora/&#123;rag_corpus&#125;/ragFiles/&#123;rag_file&#125;/ragMetadata/&#123;rag_metadata&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_specified_metadata" type="object">
  Metadata provided by users. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="key" type="string">
      Required. Key of the metadata. The key must be set with type by CreateRagDataSchema. Optional.
    </ResponseField>
    <ResponseField name="value" type="object">
      Value of Metadata, including all types available in data schema. Optional.
      <Expandable title="properties">
        <ResponseField name="bool_value" type="bool">
          Value of boolean type metadata. Optional.
        </ResponseField>
        <ResponseField name="datetime_value" type="string">
          Value of date time type metadata. Optional.
        </ResponseField>
        <ResponseField name="float_value" type="number">
          Value of float type metadata. Optional.
        </ResponseField>
        <ResponseField name="int_value" type="string">
          Value of int type metadata. Optional.
        </ResponseField>
        <ResponseField name="list_value" type="object">

          Value of string type metadata. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

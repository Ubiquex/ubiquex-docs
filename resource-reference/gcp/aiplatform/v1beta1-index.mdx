`google_aiplatform_v1beta1_index` is a Vertex AI Vector Search index built over a set of embedding vectors, enabling fast approximate nearest-neighbor lookup once deployed to an index endpoint.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

    		})

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_sandbox_environment`.
</Warning>

`google_aiplatform_v1beta1_sandbox_environment` is an isolated, managed execution environment Vertex AI Agent Engine's Code Execution capability runs caller- or agent-generated code inside, so it can't affect anything outside its own sandbox.

      Output only. The hostname of the load balancer. Computed by Google Cloud after `ship`.

    <ResponseField name="load_balancer_ip" type="string">
      Output only. The IP address of the load balancer. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="routing_token" type="string">
      Output only. The routing token for the SandboxEnvironment. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="sandbox_internal_ip" type="string">
      Output only. The internal IP address of the SandboxEnvironment. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="service_attachment" type="string">
      Output only. The name of the PSC-E service attachment created for private ingress to this SandboxEnvironment. Only populated when the template enables private ingress (see SandboxEnvironmentTemplate.ingress_control_config). VPC-SC customers use this to create a PSC endpoint in their VPC. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this SandboxEnvironment was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The display name of the SandboxEnvironment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Optional. Timestamp in UTC of when this SandboxEnvironment is considered expired. This is *always* provided on output, regardless of what `expiration` was sent on input. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="latest_sandbox_environment_snapshot" type="string">
  Output only. The resource name of the latest snapshot taken for this SandboxEnvironment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the SandboxEnvironment. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="owner" type="string">
  Optional. Owner information for this sandbox environment. A Sandbox can only be restored from a snapshot that belongs to the same owner. If not set, sandbox will be created as the default owner. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sandbox_environment_snapshot" type="string">
  Optional. The resource name of the SandboxEnvironmentSnapshot to use for creating this SandboxEnvironment. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/reasoningEngines/&#123;reasoning_engine&#125;/sandboxEnvironmentSnapshots/&#123;sandbox_environment_snapshot&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sandbox_environment_template" type="string">
  Optional. The name of the SandboxEnvironmentTemplate specified in the parent Agent Engine resource that this SandboxEnvironment is created from. Optional; if omitted, computed by Google Cloud.

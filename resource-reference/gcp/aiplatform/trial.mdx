`google_aiplatform_trial` is a single parameter combination evaluated as part of a Vertex AI Vizier study or hyperparameter tuning job, recording the parameter values tried and the resulting objective metric value.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own trial"})

    		ubx.Resource(aiplatform.Trial, "example", aiplatform.TrialConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="client_id" type="string">
  Output only. The identifier of the client that originally requested this Trial. Each client is identified by a unique client_id. When a client asks for a suggestion, Vertex AI Vizier will assign it a Trial. The client should evaluate the Trial, complete it, and report back to Vertex AI Vizier. If suggestion is asked again by same client_id before the Trial is completed, the same Trial will be returned. Multiple clients with different client_ids can ask for suggestions simultaneously, each of them will get their own Trial. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="custom_job" type="string">
  Output only. The CustomJob name linked to the Trial. It's set for a HyperparameterTuningJob's Trial. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Output only. Time when the Trial's status changed to `SUCCEEDED` or `INFEASIBLE`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="final_measurement" type="object">
  A message representing a Measurement of a Trial. A Measurement contains the Metrics got by executing a Trial using suggested hyperparameter values. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="elapsed_duration" type="string">
      Output only. Time that the Trial has been running at the point of this Measurement. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="metrics" type="list(object)">
      Output only. A list of metrics got by evaluating the objective functions using suggested Parameter values. Computed by Google Cloud after `ship`.
      <Expandable title="properties">
        <ResponseField name="metric_id" type="string">
          An identifier for this metric, unique within its own containing evaluation. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="number">
          The literal value of this field. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="step_count" type="string">
      Output only. The number of steps the machine learning model has been trained for. Must be non-negative. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="id" type="string">
  Output only. The identifier of the Trial assigned by the service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="infeasible_reason" type="string">
  Output only. A human readable string describing why the Trial is infeasible. This is set only if Trial state is `INFEASIBLE`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="measurements" type="list(object)">
  Output only. A list of measurements that are strictly lexicographically ordered by their induced tuples (steps, elapsed_duration). These are used for early stopping computations. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="elapsed_duration" type="string">
      How long this operation has been running, or took to complete. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="metrics" type="list(object)">
      The metric value(s) recorded for this measurement. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="metric_id" type="string">
          An identifier for this metric, unique within its own containing evaluation. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="number">
          The literal value of this field. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="step_count" type="string">
      How many steps this job or trial ran for. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Resource name of the Trial assigned by the service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parameters" type="list(object)">
  Output only. The parameters of the Trial. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="parameter_id" type="string">
      The name of this hyperparameter, unique within its own study. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="value" type="any">
      The literal value of this field. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="start_time" type="string">
  Output only. Time when the Trial was started. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The detailed state of the Trial. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="web_access_uris" type="map(string)">
  Output only. URIs for accessing [interactive shells](https://cloud.google.com/vertex-ai/docs/training/monitor-debug-interactive-shell) (one URI for each training node). Only available if this trial is part of a HyperparameterTuningJob and the job's trial_job_spec.enable_web_access field is `true`. The keys are names of each node used for the trial; for example, `workerpool0-0` for the primary node, `workerpool1-0` for the first node in the second worker pool, and `workerpool1-1` for the second node in the second worker pool. The values are the URIs for each node's interactive shell. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_evaluation_set`.
</Warning>

`google_aiplatform_v1beta1_evaluation_set` is a reusable, named collection of evaluation input cases (prompts, reference outputs, or both) that a Vertex AI Gen AI Evaluation Service evaluation run is executed against.

`google_aiplatform_v1beta1_example_store` is a store of curated examples (its own example_store_config) used to ground or few-shot a model, so a team can maintain one real, shared set of examples rather than embedding them ad hoc in every prompt.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 example store"})

    		ubx.Resource(aiplatform.V1beta1ExampleStore, "example", aiplatform.V1beta1ExampleStoreConfig{
    			CreateTime: "example",
    		})
    	}))
    }
    ```

## Output properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this ExampleStore was created. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the ExampleStore. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Display name of the ExampleStore. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="example_store_config" type="object">
  Configuration for the Example Store. Computed by Google Cloud after `ship`.
  <Expandable title="properties">
    <ResponseField name="vertex_embedding_model" type="string">
      Required. The embedding model to be used for vector embedding. Immutable. Supported models: * "text-embedding-005" * "text-multilingual-embedding-002" Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the ExampleStore. This is a unique identifier. Format: projects/&#123;project&#125;/locations/&#123;location&#125;/exampleStores/&#123;example_store&#125; Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this ExampleStore was most recently updated. Computed by Google Cloud after `ship`.
</ResponseField>

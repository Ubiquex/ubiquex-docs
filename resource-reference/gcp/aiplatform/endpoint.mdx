`google_aiplatform_endpoint` is the deployed, servable HTTP target a Vertex AI model is attached to for online prediction, handling request routing and traffic splitting across one or more deployed model versions.

## Example

<Tabs>

    ```go

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_aiplatform/aiplatform"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint"})

    		ubx.Resource(aiplatform.AiplatformEndpoint, "example", aiplatform.AiplatformEndpointConfig{

    	}))
    }
    ```

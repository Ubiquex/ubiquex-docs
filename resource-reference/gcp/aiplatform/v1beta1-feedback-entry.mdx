`google_aiplatform_v1beta1_feedback_entry` is a single piece of feedback (feedback_text, feedback_type, feedback_labels) tied to a real event_id and session_id, optionally attributed to a user_id, so feedback on an agent's own output can be collected and analyzed per-session rather than only in aggregate.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the entry was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="custom_metadata" type="map(string)">
  Optional. Additional key-value metadata associated with the feedback. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="event_id" type="string">
  Required. The ID of the event within the session that the feedback relates to. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="feedback_labels" type="list(string)">
  Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="feedback_text" type="string">
  Optional. Qualitative free-form comments provided by the user. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="feedback_type" type="string">
  Required. The coarse-grained type of feedback provided by the user. Must be set to a value other than `FEEDBACK_TYPE_UNSPECIFIED`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name. Assigned by the server on create. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/reasoningEngines/&#123;reasoning_engine&#125;/feedbackEntries/&#123;feedback_entry&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="session_id" type="string">
  Required. The ID of the session that the feedback relates to. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source" type="string">
  Optional. The surface that the feedback originated from. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the entry was most recently updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_id" type="string">
  Optional. A caller-supplied identifier for the user who provided the feedback. The semantics of this field (for example whether it is an opaque token, a hashed value, or a user-visible identifier) are determined by the calling application. Optional; if omitted, computed by Google Cloud.
</ResponseField>

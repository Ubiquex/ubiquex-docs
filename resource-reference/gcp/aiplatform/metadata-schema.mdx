`google_aiplatform_metadata_schema` defines the structure (field names and types) that Vertex AI ML Metadata artifacts, executions, or contexts of a given type must conform to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own metadata schema"})

    		ubx.Resource(aiplatform.MetadataSchema, "example", aiplatform.MetadataSchemaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this MetadataSchema was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the Metadata Schema Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the MetadataSchema. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema" type="string">
  Required. The raw YAML string representation of the MetadataSchema. The combination of [MetadataSchema.version] and the schema name given by `title` in [MetadataSchema.schema] must be unique within a MetadataStore. The schema is defined as an OpenAPI 3.0.2 [MetadataSchema Object](https://github.com/OAI/OpenAPI-Specification/blob/master/versions/3.0.2.md#schemaObject) Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_type" type="string">
  The type of the MetadataSchema. This is a property that identifies which metadata types will use the MetadataSchema. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_version" type="string">
  The version of the MetadataSchema. The version's format must match the following regular expression: `^[0-9]+.+.+$`, which would allow to order/compare different versions. Example: 1.0.0, 1.0.1, etc. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_aiplatform_v1beta1_schedule` triggers a Vertex AI Pipelines pipeline job to run automatically on a recurring cron-style schedule, instead of only on manual or event-driven invocation.

## Example

    	ubx.Main(ubx.Stack("example", func() {

<ResponseField name="allow_queueing" type="bool">
  Optional. Whether new scheduled runs can be queued when max_concurrent_runs limit is reached. If set to true, new runs will be queued instead of skipped. Default to false. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="catch_up" type="bool">
  Output only. Whether to backfill missed runs when the schedule is resumed from PAUSED state. If set to true, all missed runs will be scheduled. New runs will be scheduled after the backfill is complete. Default to false. Optional; if omitted, computed by Google Cloud.
</ResponseField>

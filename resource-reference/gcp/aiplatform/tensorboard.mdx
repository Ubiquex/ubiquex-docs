`google_aiplatform_tensorboard` is a managed Vertex AI TensorBoard instance, the hosted service used to visualize training metrics (loss curves, scalars, embeddings) logged across one or more experiment runs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tensorboard"})

    		ubx.Resource(aiplatform.Tensorboard, "example", aiplatform.TensorboardConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

</ResponseField>

  Description of this Tensorboard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">

</ResponseField>

<ResponseField name="etag" type="string">
  Used to perform a consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_default" type="bool">
  Used to indicate if the TensorBoard instance is the default one. Each project & region can have at most one default TensorBoard instance. Creation of a default TensorBoard instance and updating an existing TensorBoard instance to be default will mark all other TensorBoard instances (if any) as non default. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize your Tensorboards. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. No more than 64 user labels can be associated with one Tensorboard (System labels are excluded). See https://goo.gl/xmQnxf for more information and examples of labels. System reserved label keys are prefixed with "aiplatform.googleapis.com/" and are immutable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the Tensorboard. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/tensorboards/&#123;tensorboard&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="run_count" type="number">
  Output only. The number of Runs stored in this Tensorboard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">

</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">

</ResponseField>

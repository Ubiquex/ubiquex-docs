`google_aiplatform_specialist_pool` defines a named pool of human reviewer(s) (Google-managed or customer-managed) available to a Vertex AI data labeling job for annotating training data.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own specialist pool"})

    		ubx.Resource(aiplatform.SpecialistPool, "example", aiplatform.SpecialistPoolConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="display_name" type="string">
  Required. The user-defined name of the SpecialistPool. The name can be up to 128 characters long and can consist of any UTF-8 characters. This field should be unique on project-level. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. The resource name of the SpecialistPool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pending_data_labeling_jobs" type="list(string)">
  Output only. The resource name of the pending data labeling jobs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="specialist_manager_emails" type="list(string)">
  The email addresses of the managers in the SpecialistPool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="specialist_managers_count" type="number">
  Output only. The number of managers in this SpecialistPool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="specialist_worker_emails" type="list(string)">
  The email addresses of workers in the SpecialistPool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

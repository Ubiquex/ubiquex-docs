<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_rag_corpora`.
</Warning>

`google_aiplatform_v1beta1_rag_corpora` is a RagCorpus in Vertex AI's RAG Engine, a container holding the imported document(s) (RagFiles) a retrieval-augmented generation application retrieves grounding context from.

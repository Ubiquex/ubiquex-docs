<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_artifact`.
</Warning>

`google_aiplatform_v1beta1_artifact` records a single, versioned piece of data (a dataset snapshot, a model file, a metric report) produced or consumed by a Vertex AI ML Metadata pipeline, so lineage between pipeline steps can be traced.

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this Artifact was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the Artifact Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  User provided display name of the Artifact. May be up to 128 Unicode characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  An eTag used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize your Artifacts. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. No more than 64 user labels can be associated with one Artifact (System labels are excluded). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="map(any)">
  Properties of the Artifact. Top level metadata keys' heading and trailing spaces will be trimmed. The size of this field should not exceed 200KB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the Artifact. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_title" type="string">
  The title of the schema describing the metadata. Schema title and version is expected to be registered in earlier Create Schema calls. And both are used together as unique identifiers to identify schemas within the local metadata store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_version" type="string">
  The version of the schema in schema_name to use. Schema title and version is expected to be registered in earlier Create Schema calls. And both are used together as unique identifiers to identify schemas within the local metadata store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  The state of this Artifact. This is a property of the Artifact, and does not imply or capture any ongoing process. This property is managed by clients (such as Vertex AI Pipelines), and the system does not prescribe or check the validity of state transitions. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this Artifact was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uri" type="string">
  The uniform resource identifier of the artifact file. May be empty if there is no actual artifact file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

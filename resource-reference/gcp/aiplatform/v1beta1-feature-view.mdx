<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_feature_view`.
</Warning>

`google_aiplatform_v1beta1_feature_view` defines which feature(s), from which feature group(s), are synced into a specific Vertex AI Feature Online Store for serving.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 feature view"})

    		ubx.Resource(aiplatform.V1beta1FeatureView, "example", aiplatform.V1beta1FeatureViewConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

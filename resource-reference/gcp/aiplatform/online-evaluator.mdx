`google_aiplatform_online_evaluator` configures the Vertex AI Gen AI Evaluation Service to continuously score a live, running application's own conversation sessions against a set of evaluation metrics, rather than a one-off offline evaluation run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own online evaluator"})

    		ubx.Resource(aiplatform.OnlineEvaluator, "example", aiplatform.OnlineEvaluatorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_aiplatform_v1beta1_serving_profile` is a profile that controls how a model gets served -- its own encryption configuration (cmek_config) and scope -- so serving behavior for a given deployment can be defined once and referenced, rather than repeated across every deployment that needs the same real serving policy.

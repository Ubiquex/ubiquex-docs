`google_aiplatform_v1beta1_agent` registers a deployable AI agent within Vertex AI's Agent Builder surface (now documented under the Gemini Enterprise Agent Platform), the unit an Agent Engine deployment or the Agent Studio low-code builder operates on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 agent"})

    		ubx.Resource(aiplatform.V1beta1Agent, "example", aiplatform.V1beta1AgentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="base_agent" type="string">
  Required. Immutable. The base agent for the agent. Supported values: * `antigravity-preview-05-2026` Immutable: `UpdateAgent` rejects a change, including clearing it. The kind of agent this is gets derived from this field when the agent is created and is recorded then; nothing recomputes it afterwards, so a later change would leave the agent described as one kind and behaving as another. Create a new agent instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="base_environment" type="any">
  Optional. The base environment configuration for the agent. Valid types: * A string value for the environment ID, or `remote` for the default. * A struct value for the `environment_config`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="created" type="string">
  Output only. The time the agent was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the agent. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  Immutable. The user-specified ID for the agent. This ID becomes the final component of the agent resource name. If not provided, Vertex AI will generate a value for this ID. The ID can be up to 63 characters and must match the regular expression `[a-z]([a-z0-9-]&#123;0,61&#125;[a-z0-9])?`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="map(string)">
  Optional. The metadata for the agent. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the agent. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/agents/&#123;agent&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="object" type="string">
  Output only. The object type of the resource. For agents, the value is `agent`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="system_instruction" type="string">
  Optional. The instructions for the agent to follow. These instructions are passed to the LLM as a system instruction. Optional; if omitted, computed by Google Cloud.
</ResponseField>

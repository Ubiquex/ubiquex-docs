<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_online_evaluator`.
</Warning>

`google_aiplatform_v1beta1_online_evaluator` configures the Vertex AI Gen AI Evaluation Service to continuously score a live, running application's own conversation sessions against a set of evaluation metrics, rather than a one-off offline evaluation run.

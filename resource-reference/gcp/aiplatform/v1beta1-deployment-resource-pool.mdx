<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_deployment_resource_pool`.
</Warning>

`google_aiplatform_v1beta1_deployment_resource_pool` is a shared pool of compute nodes that more than one model deployment can be co-located on, so several models can share the same underlying machines instead of each needing its own dedicated endpoint capacity.

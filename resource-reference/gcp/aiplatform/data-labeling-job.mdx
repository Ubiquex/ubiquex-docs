`google_aiplatform_data_labeling_job` sends a dataset out to human labelers (Google's own workforce or a caller-specified one) to annotate, producing the labeled training data a supervised model is trained on.

## Example

## Properties

<ResponseField name="active_learning_config" type="object">
  Parameters that configure the active learning pipeline. Active learning will label the data incrementally by several iterations. For every iteration, it will select a batch of data based on the sampling strategy. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="max_data_item_count" type="string">
      Max number of human labeled DataItems. Optional.
    </ResponseField>
    <ResponseField name="max_data_item_percentage" type="number">
      Max percent of total DataItems for human labeling. Optional.
    </ResponseField>
    <ResponseField name="sample_config" type="object">
      Active learning data sampling config. For every active learning labeling iteration, it will select a batch of data based on the sampling strategy. Optional.
      <Expandable title="properties">
        <ResponseField name="following_batch_sample_percentage" type="number">
          The percentage of data needed to be labeled in each following batch (except the first batch). Optional.
        </ResponseField>
        <ResponseField name="initial_batch_sample_percentage" type="number">
          The percentage of data needed to be labeled in the first batch. Optional.
        </ResponseField>
        <ResponseField name="sample_strategy" type="string">
          Field to choose sampling strategy. Sampling strategy will decide which data should be selected for human labeling in every batch. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="training_config" type="object">
      CMLE training config. For every active learning labeling iteration, system will train a machine learning model on CMLE. The trained model will be used by data sampling algorithm to select DataItems. Optional.
      <Expandable title="properties">
        <ResponseField name="timeout_training_milli_hours" type="string">
          The timeout hours for the CMLE training job, expressed in milli hours i.e. 1,000 value in this field means 1 hour. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

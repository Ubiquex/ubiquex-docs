`google_aiplatform_v1beta1_skill` is a packaged, installable capability an agent can use, distributed as a real zipped filesystem bundle (zipped_filesystem) with its own compatibility declaration, license, and sha256 checksum, so agent capabilities can be versioned and distributed the way a software package is, not hand-wired into an agent's own configuration.

## Example

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 skill"})

    		ubx.Resource(aiplatform.V1beta1Skill, "example", aiplatform.V1beta1SkillConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="compatibility" type="string">
  Optional. Specifies the compatibility of the Skill. Indicates environment requirements (intended product, system packages, network access, etc.). This should align with `compatibility` in the `SKILL.md` file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this Skill was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Required. Describes the Skill. Should describe both what the skill does and when to use it. Should include specific keywords that help agents identify relevant tasks. This should align with `description` in the `SKILL.md` file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. Provides the display name of the Skill. This should align with `name` in the `SKILL.md` file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize Skills. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="license" type="string">
  Optional. Specifies the license of the Skill. This should be an SPDX license identifier (e.g., "MIT", "Apache-2.0"). See https://spdx.org/licenses/. This should align with `license` in the `SKILL.md` file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the Skill. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/skills/&#123;skill&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="sha256" type="string">
  Output only. The SHA256 checksum of the zipped filesystem. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="skill_source" type="string">
  Output only. The source of the Skill. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the Skill. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this Skill was most recently updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="zipped_filesystem" type="string">
  Required. Provides the zipped filesystem of the Skill. This should contain the `SKILL.md` file at the root of the zip and optional directories for scripts, references, and assets. Directory should align with the directory structure specified at https://agentskills.io/specification#directory-structure. Optional; if omitted, computed by Google Cloud.
</ResponseField>

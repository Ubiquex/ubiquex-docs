`google_aiplatform_rag_corpora` is a RagCorpus in Vertex AI's RAG Engine, a container holding the imported document(s) (RagFiles) a retrieval-augmented generation application retrieves grounding context from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own rag corpora"})

    		ubx.Resource(aiplatform.RagCorpora, "example", aiplatform.RagCorporaConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_aiplatform_v1beta1_feature` defines a single named, typed ML feature (e.g. `age` or `click_count`) within a Vertex AI Feature Store's own feature group or legacy entity type.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 feature"})

    		ubx.Resource(aiplatform.V1beta1Feature, "example", aiplatform.V1beta1FeatureConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

  Optional. The labels with user-defined metadata to organize your Features. <ResponseField name="name" type="string">
  Immutable. Name of the Feature. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/featurestores/&#123;featurestore&#125;/entityTypes/&#123;entity_type&#125;/features/&#123;feature&#125;` `projects/&#123;project&#125;/locations/&#123;location&#125;/featureGroups/&#123;feature_group&#125;/features/&#123;feature&#125;` The last part feature is assigned by the client. The feature can be up to 64 characters long and can consist only of ASCII Latin letters A-Z and a-z, underscore(_), and ASCII digits 0-9 starting with a letter.

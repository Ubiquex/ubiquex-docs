`google_aiplatform_execution` records a single run of a step (a training job, a data transformation) within Vertex AI's own ML Metadata lineage graph, connecting the artifact(s) it consumed to the artifact(s) it produced.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_aiplatform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_aiplatform/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_aiplatform/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own execution"})

    		ubx.Resource(aiplatform.AiplatformExecution, "example", aiplatform.AiplatformExecutionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    # ubx sdk gen --only google_aiplatform --lang py --out ./local-sdk

    import ubx_sdk as ubx
    from ubx.google_aiplatform.aiplatform import AiplatformExecution, AiplatformExecutionConfig

    def describe():
        ubx.intent("example own execution")

        ubx.resource(AiplatformExecution, "example", AiplatformExecutionConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this Execution was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the Execution Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  User provided display name of the Execution. May be up to 128 Unicode characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  An eTag used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  The labels with user-defined metadata to organize your Executions. Label keys and values can be no longer than 64 characters (Unicode codepoints), can only contain lowercase letters, numeric characters, underscores and dashes. International characters are allowed. No more than 64 user labels can be associated with one Execution (System labels are excluded). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="map(any)">
  Properties of the Execution. Top level metadata keys' heading and trailing spaces will be trimmed. The size of this field should not exceed 200KB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the Execution. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_title" type="string">
  The title of the schema describing the metadata. Schema title and version is expected to be registered in earlier Create Schema calls. And both are used together as unique identifiers to identify schemas within the local metadata store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schema_version" type="string">
  The version of the schema in `schema_title` to use. Schema title and version is expected to be registered in earlier Create Schema calls. And both are used together as unique identifiers to identify schemas within the local metadata store. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  The state of this Execution. This is a property of the Execution, and does not imply or capture any ongoing process. This property is managed by clients (such as Vertex AI Pipelines) and the system does not prescribe or check the validity of state transitions. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this Execution was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_aiplatform_memory`.
</Warning>

`google_aiplatform_v1beta1_memory` is a single stored memory (a durable fact or preference extracted from past conversations) held in Vertex AI Agent Engine's own Memory Bank, retrievable to personalize a future agent interaction.

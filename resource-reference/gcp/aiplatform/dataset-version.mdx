`google_aiplatform_dataset_version` is a specific, immutable snapshot of a Vertex AI dataset's own contents at a point in time, letting a training job pin to exactly the data it was trained on even as the dataset itself keeps changing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_aiplatform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_aiplatform/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_aiplatform/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own dataset version"})

    		ubx.Resource(aiplatform.AiplatformDatasetVersion, "ci-runner", aiplatform.AiplatformDatasetVersionConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="big_query_dataset_name" type="string">
  Output only. Name of the associated BigQuery dataset. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this DatasetVersion was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-defined name of the DatasetVersion. The name can be up to 128 characters long and can consist of any UTF-8 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="any">
  Required. Output only. Additional information about the DatasetVersion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="model_reference" type="string">
  Output only. Reference to the public base model last used by the dataset version. Only set for prompt dataset versions. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. The resource name of the DatasetVersion. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/datasets/&#123;dataset&#125;/datasetVersions/&#123;dataset_version&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Reserved for future use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when this DatasetVersion was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

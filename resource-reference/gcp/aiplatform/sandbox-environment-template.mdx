`google_aiplatform_sandbox_environment_template` defines the reusable configuration (base image, resource limits) a Vertex AI Agent Engine sandbox environment is created from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own sandbox environment template"})

    		ubx.Resource(aiplatform.SandboxEnvironmentTemplate, "example", aiplatform.SandboxEnvironmentTemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

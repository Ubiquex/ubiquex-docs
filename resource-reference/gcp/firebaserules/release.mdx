`google_firebaserules_release` publishes a specific Firebase Security Rules ruleset live for a project's own Firestore, Realtime Database, or Cloud Storage resource.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firebaserules --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firebaserules/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebaserules "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firebaserules/firebaserules"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own release"})

    		ubx.Resource(firebaserules.FirebaserulesRelease, "example", firebaserules.FirebaserulesReleaseConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Time the release was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Format: `projects/&#123;project_id&#125;/releases/&#123;release_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ruleset_name" type="string">
  Required. Name of the `Ruleset` referred to by this `Release`. The `Ruleset` must exist for the `Release` to be created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Time the release was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

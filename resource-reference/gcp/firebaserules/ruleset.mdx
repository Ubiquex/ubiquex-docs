`google_firebaserules_ruleset` is an immutable, compiled set of Firebase Security Rules, the access-control logic enforced against reads and writes once released.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_firebaserules --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_firebaserules/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebaserules "github.com/ubiquex/ubx-sdk-google/sdk/go/google_firebaserules/firebaserules"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own ruleset"})

    		ubx.Resource(firebaserules.FirebaserulesRuleset, "ci-runner", firebaserules.FirebaserulesRulesetConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="attachment_point" type="string">
  Immutable. Intended resource to which this Ruleset should be released. May be left blank to signify the resource associated with the default release. Expected format: firestore.googleapis.com/projects//databases/ Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Time the `Ruleset` was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="object">
  Metadata for a Ruleset. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="services" type="list(string)">
      Services that this ruleset has declarations for (e.g., "cloud.firestore"). There may be 0+ of these. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Name of the `Ruleset`. The ruleset_id is auto generated by the service. Format: `projects/&#123;project_id&#125;/rulesets/&#123;ruleset_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source" type="object">
  `Source` is one or more `File` messages comprising a logical set of rules. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="files" type="list(object)">
      Required. `File` set constituting the `Source` bundle. Optional.
      <Expandable title="properties">
        <ResponseField name="content" type="string">
          The raw text content of this Rules source file (Firestore/Realtime Database/Cloud Storage security rules syntax). Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="fingerprint" type="string">
          A checksum/version identifier for this file's own content, used to detect whether the file changed between requests. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          A file name, unique within this Ruleset's own source, used for diagnostic messages when a rule fails to compile. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

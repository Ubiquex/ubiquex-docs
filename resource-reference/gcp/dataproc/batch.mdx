title: "google_dataproc_batch"
description: "`google_dataproc_batch` runs a single Spark, PySpark, or SparkR workload on serverless Dataproc..."
---

`google_dataproc_batch` runs a single Spark, PySpark, or SparkR workload on serverless Dataproc, without the caller having to provision or manage a persistent cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dataproc --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dataproc/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataproc "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dataproc/dataproc"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own batch"})

    		ubx.Resource(dataproc.DataprocBatch, "ci-runner", dataproc.DataprocBatchConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_dataproc --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";

      intent({ summary: "payments own batch" });

      resource(DataprocBatch, "ci-runner", {

      });

    ```

`google_dataproc_session` is an interactive, serverless Spark session on Dataproc, letting a notebook or client run multiple Spark statements against shared, live compute without a persistent cluster.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataproc "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataproc"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own session"})

    		ubx.Resource(dataproc.Session, "example", dataproc.SessionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

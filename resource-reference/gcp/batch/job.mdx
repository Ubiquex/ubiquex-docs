`google_batch_job` is a Google Cloud Batch job, a real batch-processing workload made up of one or more task groups, each running one or more scripts or containers (runnables) across allocated compute resources, with the service managing scheduling, retries, and logging.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	batch "github.com/ubiquex/ubx-sdk-google/sdk/go/google/batch"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own job"})

    		ubx.Resource(batch.Job, "example", batch.JobConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

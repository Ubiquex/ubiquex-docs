`google_config_deployment_group` groups related Infrastructure Manager deployments together, for coordinated multi-deployment operations like ordered updates.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_config --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_config/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	config "github.com/ubiquex/ubx-sdk-google/sdk/go/google_config/config"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own deployment group"})

    		ubx.Resource(config.ConfigDeploymentGroup, "ci-runner", config.ConfigDeploymentGroupConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

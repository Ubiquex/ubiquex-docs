`google_config_preview` runs a dry-run (plan-only) evaluation of an Infrastructure Manager Terraform configuration, showing the change(s) it would make without actually applying them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_config --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_config/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	config "github.com/ubiquex/ubx-sdk-google/sdk/go/google_config/config"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own preview"})

    		ubx.Resource(config.ConfigPreview, "example", config.ConfigPreviewConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_config --lang ts --out ./local-sdk
    ```

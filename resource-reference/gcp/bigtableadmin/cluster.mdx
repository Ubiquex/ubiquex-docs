`google_bigtableadmin_cluster` is a single zonal deployment of compute nodes within a Bigtable instance, serving that instance's own tables from a specific zone -- an instance with more than one cluster replicates data across them.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	bigtableadmin "github.com/ubiquex/ubx-sdk-google/sdk/go/google/bigtableadmin"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cluster"})

    		ubx.Resource(bigtableadmin.Cluster, "example", bigtableadmin.ClusterConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="cluster_config" type="object">
  Configuration for a cluster. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="cluster_autoscaling_config" type="object">
      Autoscaling config for a cluster. Optional.
      <Expandable title="properties">
        <ResponseField name="autoscaling_limits" type="object">
          Limits for the number of nodes a Cluster can autoscale up/down to. Optional.
          <Expandable title="properties">
            <ResponseField name="max_serve_nodes" type="number">
              Required. Maximum number of nodes to scale up to. Optional.
            </ResponseField>
            <ResponseField name="min_serve_nodes" type="number">
              Required. Minimum number of nodes to scale down to. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="autoscaling_targets" type="object">
          The Autoscaling targets for a Cluster. These determine the recommended nodes. Optional.
          <Expandable title="properties">
            <ResponseField name="cpu_utilization_percent" type="number">
              The cpu utilization that the Autoscaler should be trying to achieve. This number is on a scale from 0 (no utilization) to 100 (total utilization), and is limited between 10 and 80, otherwise it will return INVALID_ARGUMENT error. Optional.
            </ResponseField>
            <ResponseField name="storage_utilization_gib_per_node" type="number">
              The storage utilization that the Autoscaler should be trying to achieve. This number is limited between 2560 (2.5TiB) and 5120 (5TiB) for a SSD cluster and between 8192 (8TiB) and 16384 (16TiB) for an HDD cluster, otherwise it will return INVALID_ARGUMENT error. If this value is set to 0, it will be treated as if it were set to the default value: 2560 for SSD, 8192 for HDD. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="default_storage_type" type="string">
  Immutable. The type of storage used by this cluster to serve its parent instance's tables, unless explicitly overridden. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encryption_config" type="object">
  Cloud Key Management Service (Cloud KMS) settings for a CMEK-protected cluster. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_name" type="string">
      Describes the Cloud KMS encryption key that will be used to protect the destination Bigtable cluster. The requirements for this key are: 1) The Cloud Bigtable service account associated with the project that contains this cluster must be granted the `cloudkms.cryptoKeyEncrypterDecrypter` role on the CMEK key. 2) Only regional keys can be used and the region of the CMEK key must match the region of the cluster. Values are of the form `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyring&#125;/cryptoKeys/&#123;key&#125;` Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location" type="string">
  Immutable. The location where this cluster's nodes and storage reside. For best performance, clients should be located as close as possible to this cluster. Currently only zones are supported, so values should be of the form `projects/&#123;project&#125;/locations/&#123;zone&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The unique name of the cluster. Values are of the form `projects/&#123;project&#125;/instances/&#123;instance&#125;/clusters/a-z*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="node_scaling_factor" type="string">
  Immutable. The node scaling factor of this cluster. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="serve_nodes" type="number">
  The number of nodes in the cluster. If no value is set, Cloud Bigtable automatically allocates nodes based on your data footprint and optimized for 50% storage utilization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the cluster. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_bigtableadmin_logical_view` defines a saved, reusable SQL query over one or more Bigtable table(s), exposing a virtual, read-only table computed from that query.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_bigtableadmin --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_bigtableadmin/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	bigtableadmin "github.com/ubiquex/ubx-sdk-google/sdk/go/google_bigtableadmin/bigtableadmin"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own logical view"})

    		ubx.Resource(bigtableadmin.BigtableadminLogicalView, "ci-runner", bigtableadmin.BigtableadminLogicalViewConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="deletion_protection" type="bool">
  Optional. Set to true to make the LogicalView protected against deletion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. The etag for this logical view. This may be sent on update requests to ensure that the client has an up-to-date value before proceeding. The server returns an ABORTED error on a mismatched etag. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The unique name of the logical view. Format: `projects/&#123;project&#125;/instances/&#123;instance&#125;/logicalViews/&#123;logical_view&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="query" type="string">
  Required. The logical view's select query. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_bigtableadmin_authorized_view` restricts access to a defined subset of a Bigtable table's own rows and column families, letting IAM grant a caller visibility into only that subset rather than the whole table.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_bigtableadmin --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_bigtableadmin/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	bigtableadmin "github.com/ubiquex/ubx-sdk-google/sdk/go/google_bigtableadmin/bigtableadmin"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own authorized view"})

    		ubx.Resource(bigtableadmin.BigtableadminAuthorizedView, "ci-runner", bigtableadmin.BigtableadminAuthorizedViewConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="deletion_protection" type="bool">
  Set to true to make the AuthorizedView protected against deletion. The parent Table and containing Instance cannot be deleted if an AuthorizedView has this bit set. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  The etag for this AuthorizedView. If this is provided on update, it must match the server's etag. The server returns ABORTED error on a mismatched etag. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of this AuthorizedView. Values are of the form `projects/&#123;project&#125;/instances/&#123;instance&#125;/tables/&#123;table&#125;/authorizedViews/&#123;authorized_view&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subset_view" type="object">
  Defines a simple AuthorizedView that is a subset of the underlying Table. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="family_subsets" type="map(object)">
      Map from column family name to the columns in this family to be included in the AuthorizedView. Optional.
      <Expandable title="properties">
        <ResponseField name="qualifier_prefixes" type="list(string)">
          Restricts this rule to columns whose own qualifier starts with one of these prefixes. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="qualifiers" type="list(string)">
          The specific column qualifier(s) this rule applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="row_prefixes" type="list(string)">
      Row prefixes to be included in the AuthorizedView. To provide access to all rows, include the empty string as a prefix (""). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_bigtableadmin_materialized_view` defines a Bigtable view whose own query results are precomputed and kept incrementally up to date, trading storage and write cost for faster, cheaper reads than a logical view.

## Properties

<ResponseField name="cluster_states" type="map(object)">
  Output only. Map from cluster ID to per-cluster materialized view state. If it could not be determined whether or not the materialized view has data in a particular cluster (for example, if its zone is unavailable), then there will be an entry for the cluster with `STATE_NOT_KNOWN` state. Views: `REPLICATION_VIEW`, `FULL`. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="replication_state" type="string">
      The current replication status of this cluster relative to the rest of the instance. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="deletion_protection" type="bool">
  Set to true to make the MaterializedView protected against deletion. Views: `SCHEMA_VIEW`, `REPLICATION_VIEW`, `FULL`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. The etag for this materialized view. This may be sent on update requests to ensure that the client has an up-to-date value before proceeding. The server returns an ABORTED error on a mismatched etag. Views: `SCHEMA_VIEW`, `REPLICATION_VIEW`, `FULL`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The unique name of the materialized view. Format: `projects/&#123;project&#125;/instances/&#123;instance&#125;/materializedViews/&#123;materialized_view&#125;` Views: `SCHEMA_VIEW`, `REPLICATION_VIEW`, `FULL`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="query" type="string">
  Required. Immutable. The materialized view's select query. Views: `SCHEMA_VIEW`, `FULL`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

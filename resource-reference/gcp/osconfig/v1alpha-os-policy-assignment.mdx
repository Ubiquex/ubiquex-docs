---

`google_osconfig_v1alpha_os_policy_assignment` assigns a real set of OS policies (os_policies) to instances matching its own instance_filter, with a real rollout controlling how the assignment reaches those instances and revision_id/revision_create_time tracking its own change history, so OS-level configuration can be declared once and enforced across a fleet rather than configured host by host.

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_osconfig_v1beta_patch_deployment` is a real, scheduled patch deployment -- its own patch_config, instance_filter, and either a one_time_schedule or recurring_schedule -- with a real rollout controlling how quickly patches reach matching instances, so OS patching happens on a defined cadence instead of only when triggered manually.

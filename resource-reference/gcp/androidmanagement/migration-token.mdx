`google_androidmanagement_migration_token` lets a device already enrolled under a different EMM be migrated to Android Management API management without a factory reset, preserving its work profile or fully-managed state across the switch.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/androidmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own migration token"})

    		ubx.Resource(androidmanagement.MigrationToken, "example", androidmanagement.MigrationTokenConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="additional_data" type="string">
  Immutable. Optional EMM-specified additional data. Once the device is migrated this will be populated in the migrationAdditionalData field of the Device resource. This must be at most 1024 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Time when this migration token was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="device" type="string">
  Output only. Once this migration token is used to migrate a device, the name of the resulting Device resource will be populated here, in the form enterprises/&#123;enterprise&#125;/devices/&#123;device&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="device_id" type="string">
  Required. Immutable. The id of the device, as in the Play EMM API. This corresponds to the deviceId parameter in Play EMM API's Devices.get (https://developers.google.com/android/work/play/emm-api/v1/devices/get#parameters) call. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Immutable. The time when this migration token expires. This can be at most seven days from the time of creation. The migration token is deleted seven days after it expires. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="management_mode" type="string">
  Required. Immutable. The management mode of the device or profile being migrated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of the migration token, which is generated by the server during creation, in the form enterprises/&#123;enterprise&#125;/migrationTokens/&#123;migration_token&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="policy" type="string">
  Required. Immutable. The name of the policy initially applied to the enrolled device, in the form enterprises/&#123;enterprise&#125;/policies/&#123;policy&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ttl" type="string">
  Input only. The time that this migration token is valid for. This is input-only, and for returning a migration token the server will populate the expireTime field. This can be at most seven days. The default is seven days. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_id" type="string">
  Required. Immutable. The user id of the Managed Google Play account on the device, as in the Play EMM API. This corresponds to the userId parameter in Play EMM API's Devices.get (https://developers.google.com/android/work/play/emm-api/v1/devices/get#parameters) call. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="value" type="string">
  Output only. The value of the migration token. Optional; if omitted, computed by Google Cloud.
</ResponseField>

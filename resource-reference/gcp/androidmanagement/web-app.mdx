`google_androidmanagement_web_app` publishes a URL-based web app to an Android Management API enterprise's managed app catalog, distributed to devices the same way a native app policy would be.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_androidmanagement --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_androidmanagement/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google_androidmanagement/androidmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own web app"})

    		ubx.Resource(androidmanagement.AndroidmanagementWebApp, "ci-runner", androidmanagement.AndroidmanagementWebAppConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_androidmanagement --lang ts --out ./local-sdk
    ```

  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_androidmanagement --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_androidmanagement/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_androidmanagement.androidmanagement import AndroidmanagementWebApp, AndroidmanagementWebAppConfig

    def describe():
        ubx.intent("payments own web app")

        ubx.resource(AndroidmanagementWebApp, "ci-runner", AndroidmanagementWebAppConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="display_mode" type="string">
  The display mode of the web app. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="icons" type="list(object)">
  A list of icons for the web app. Must have at least one element. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="image_data" type="string">
      The real, base64-encoded image bytes for this web app's own icon. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The name of the web app, which is generated by the server during creation in the form enterprises/&#123;enterpriseId&#125;/webApps/&#123;packageName&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_url" type="string">
  The start URL, i.e. the URL that should load when the user opens the application. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="title" type="string">
  The title of the web app as displayed to the user (e.g., amongst a list of other applications, or as a label for an icon). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version_code" type="string">
  The current version of the app.Note that the version can automatically increase during the lifetime of the web app, while Google does internal housekeeping to keep the web app up-to-date. Optional; if omitted, computed by Google Cloud.
</ResponseField>

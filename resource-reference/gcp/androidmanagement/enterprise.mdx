`google_androidmanagement_enterprise` is the top-level Android Management API resource representing one organization's managed Android device fleet, the parent every enrollment token, migration token, and web app in that fleet is created under.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/androidmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own enterprise"})

    		ubx.Resource(androidmanagement.Enterprise, "example", androidmanagement.EnterpriseConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="google_authentication_settings" type="object">
  Contains settings for Google-provided user authentication. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="google_authentication_required" type="string">
      Output only. Whether users need to be authenticated by Google during the enrollment process. IT admin can specify if Google authentication is enabled for the enterprise for knowledge worker devices. This value can be set only via the Google Admin Console. Google authentication can be used with signin_url In the case where Google authentication is required and a signin_url is specified, Google authentication will be launched before signin_url. This value is overridden by EnrollmentToken.googleAuthenticationOptions and SigninDetail.googleAuthenticationOptions, if they are set. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="logo" type="object">
  Data hosted at an external location. The data is to be downloaded by Android Device Policy and verified against the hash. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="sha256_hash" type="string">
      The base-64 encoded SHA-256 hash of the content hosted at url. If the content doesn't match this hash, Android Device Policy won't use the data. Optional.
    </ResponseField>
    <ResponseField name="url" type="string">
      The absolute URL to the data, which must use either the http or https scheme. Android Device Policy doesn't provide any credentials in the GET request, so the URL must be publicly accessible. Including a long, random component in the URL may be used to prevent attackers from discovering the URL. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="managed_google_domain_type" type="string">
  Output only. The type of managed Google domain. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="managed_google_play_accounts_enterprise_type" type="string">
  Output only. The type of a managed Google Play Accounts enterprise. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the enterprise which is generated by the server during creation, in the form enterprises/&#123;enterpriseId&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="primary_color" type="number">
  A color in RGB format that indicates the predominant color to display in the device management app UI. The color components are stored as follows: (red &lt;&lt; 16) | (green &lt;&lt; 8) | blue, where the value of each component is between 0 and 255, inclusive. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pubsub_topic" type="string">
  The topic which Pub/Sub notifications are published to, in the form projects/&#123;project&#125;/topics/&#123;topic&#125;. This field is only required if Pub/Sub notifications are enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_apigateway_config`.
</Warning>

`google_apigateway_v1beta_config` is an immutable API Gateway configuration created by uploading an OpenAPI definition; each upload produces a new config rather than modifying an existing one, and a `google_apigateway_gateway` deploys exactly one config at a time.

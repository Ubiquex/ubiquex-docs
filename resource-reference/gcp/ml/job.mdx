title: "google_ml_job"

`google_ml_job` runs a training or batch prediction job on the legacy AI Platform (ML Engine) service, the predecessor to Vertex AI's own custom training and batch prediction.

## Example

    // ubx sdk gen --only google_ml --lang go --out ./local-sdk

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    	ubx.Main(ubx.Stack("example", func() {

<ResponseField name="etag" type="string">
  `etag` is used for optimistic concurrency control as a way to help prevent simultaneous updates of a job from overwriting each other. It is strongly suggested that systems make use of the `etag` in the read-modify-write cycle to perform job updates in order to avoid race conditions: An `etag` is returned in the response to `GetJob`, and systems are expected to put that etag in the request to `UpdateJob` to ensure that their change will be applied to the same version of the job. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="job_id" type="string">
  Required. The user-specified id of the job. Optional; if omitted, computed by Google Cloud.

<ResponseField name="job_position" type="string">
  Output only. It's only effect when the job is in QUEUED state. If it's positive, it indicates the job's position in the job scheduler. It's 0 when the job is already scheduled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

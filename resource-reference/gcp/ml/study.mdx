`google_ml_study` is the top-level configuration for a legacy AI Platform hyperparameter tuning study, defining the parameter search space and objective its trial(s) are evaluated against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_ml --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_ml/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	ml "github.com/ubiquex/ubx-sdk-google/sdk/go/google_ml/ml"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own study"})

    		ubx.Resource(ml.MlStudy, "example", ml.MlStudyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Time at which the study was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="inactive_reason" type="string">
  Output only. A human readable reason why the Study is inactive. This should be empty if a study is ACTIVE or COMPLETED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of a study. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The detailed state of a study. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="study_config" type="object">

  <Expandable title="properties">
    <ResponseField name="algorithm" type="string">

    </ResponseField>
    <ResponseField name="automated_stopping_config" type="object">
      Configuration for Automated Early Stopping of Trials. If no implementation_config is set, automated early stopping will not be run. Optional.
      <Expandable title="properties">
        <ResponseField name="decay_curve_stopping_config" type="object">
          Configuration for stopping trials early using a decay-curve prediction of their own final performance. Optional. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="use_elapsed_time" type="bool">
              If true, measurement.elapsed_time is used as the x-axis of each Trials Decay Curve. Otherwise, Measurement.steps will be used as the x-axis. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="median_automated_stopping_config" type="object">
          The median automated stopping rule stops a pending trial if the trial's best objective_value is strictly below the median 'performance' of all completed trials reported up to the trial's last measurement. Currently, 'performance' refers to the running average of the objective values reported by the trial in each measurement. Optional.
          <Expandable title="properties">
            <ResponseField name="use_elapsed_time" type="bool">
              If true, the median automated stopping rule applies to measurement.use_elapsed_time, which means the elapsed_time field of the current trial's latest measurement is used to compute the median objective value for each completed trial. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>

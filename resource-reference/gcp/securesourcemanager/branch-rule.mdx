`google_securesourcemanager_branch_rule` enforces protections (required reviews, status checks, restricted force-push) on branch(es) matching a pattern within a Secure Source Manager repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own branch rule"})

    		ubx.Resource(securesourcemanager.BranchRule, "example", securesourcemanager.BranchRuleConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="allow_stale_reviews" type="bool">
  Optional. Determines if allow stale reviews or approvals before merging to the branch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="annotations" type="map(string)">
  Optional. User annotations. These attributes can only be set and used by the user. See https://google.aip.dev/128#annotations for more details such as format and size limitations. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Determines if the branch rule is disabled or not. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. This checksum is computed by the server based on the value of other fields, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="include_pattern" type="string">
  Optional. The pattern of the branch that can match to this BranchRule. Specified as regex. .* for all branches. Examples: main, (main|release.*). Current MVP phase only support `.*` for wildcard. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="minimum_approvals_count" type="number">
  Optional. The minimum number of approvals required for the branch rule to be matched. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="minimum_reviews_count" type="number">
  Optional. The minimum number of reviews required for the branch rule to be matched. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. A unique identifier for a BranchRule. The name should be of the format: `projects/&#123;project&#125;/locations/&#123;location&#125;/repositories/&#123;repository&#125;/branchRules/&#123;branch_rule&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="require_code_owner_approval" type="bool">
  Optional. Determines if code owners must approve before merging to the branch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="require_comments_resolved" type="bool">
  Optional. Determines if require comments resolved before merging to the branch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="require_linear_history" type="bool">
  Optional. Determines if require linear history before merging to the branch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="require_pull_request" type="bool">
  Optional. Determines if the branch rule requires a pull request or not. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="required_status_checks" type="list(object)">
  Optional. List of required status checks before merging to the branch. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="context" type="string">
      The name of the status check that must report success before a pull request targeting a protected branch can be merged, matching the check's own reported context/name. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Unique identifier of the repository. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

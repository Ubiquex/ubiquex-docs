`google_securesourcemanager_branch_rule` enforces protections (required reviews, status checks, restricted force-push) on branch(es) matching a pattern within a Secure Source Manager repository.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securesourcemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securesourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securesourcemanager/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own branch rule"})

    		ubx.Resource(securesourcemanager.SecuresourcemanagerBranchRule, "ci-runner", securesourcemanager.SecuresourcemanagerBranchRuleConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own issue comment"})

    		ubx.Resource(securesourcemanager.IssueComment, "example", securesourcemanager.IssueCommentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="body" type="string">
  Required. The comment body. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Unique identifier for an issue comment. The comment id is generated by the server. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/repositories/&#123;repository&#125;/issues/&#123;issue&#125;/issueComments/&#123;comment_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last updated timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

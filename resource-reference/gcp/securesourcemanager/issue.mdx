`google_securesourcemanager_issue` is a tracked issue within a Secure Source Manager repository, used for bug and task tracking alongside the source code itself.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own issue"})

    		ubx.Resource(securesourcemanager.Issue, "example", securesourcemanager.IssueConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="body" type="string">
  Optional. Issue body. Provides a detailed description of the issue. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="close_time" type="string">
  Output only. Close timestamp (if closed). Cleared when is re-opened. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. This checksum is computed by the server based on the value of other fields, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Unique identifier for an issue. The issue id is generated by the server. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/repositories/&#123;repository&#125;/issues/&#123;issue_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the issue. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="title" type="string">
  Required. Issue title. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last updated timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

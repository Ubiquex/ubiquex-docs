`google_securesourcemanager_pull_request` proposes merging one branch into another within a Secure Source Manager repository, the unit code review and CI checks are attached to before merge.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securesourcemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securesourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securesourcemanager/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own pull request"})

    		ubx.Resource(securesourcemanager.SecuresourcemanagerPullRequest, "example", securesourcemanager.SecuresourcemanagerPullRequestConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="base" type="object">
  Branch represents a branch involved in a pull request. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="ref" type="string">
      Required. Name of the branch. Optional.
    </ResponseField>
    <ResponseField name="sha" type="string">
      Output only. The commit at the tip of the branch. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="body" type="string">
  Optional. The pull request body. Provides a detailed description of the changes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="close_time" type="string">
  Output only. Close timestamp (if closed or merged). Cleared when pull request is re-opened. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

    </ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. A unique identifier for a PullRequest. The number appended at the end is generated by the server. </ResponseField>

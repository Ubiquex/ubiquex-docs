`google_securesourcemanager_instance` is the top-level, privately hosted Secure Source Manager deployment that repository/repositories are created within, isolated to a single Google Cloud project and VPC.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securesourcemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securesourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securesourcemanager/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own instance"})

    		ubx.Resource(securesourcemanager.SecuresourcemanagerInstance, "ci-runner", securesourcemanager.SecuresourcemanagerInstanceConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="name" type="string">
  Identifier. A unique identifier for an instance. The name should be of the format: `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/instances/&#123;instance_id&#125;` `project_number`: Maps to a unique int64 id assigned to each project. `location_id`: Refers to the region where the instance will be deployed. Since Secure Source Manager is a regional service, it must be one of the valid GCP regions. `instance_id`: User provided name for the instance, must be unique for a project_number and location_id combination. Optional; if omitted, computed by Google Cloud.
</ResponseField>

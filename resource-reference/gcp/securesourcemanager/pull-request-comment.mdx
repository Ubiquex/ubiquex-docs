`google_securesourcemanager_pull_request_comment` is a single review comment posted on a Secure Source Manager pull request, either general or attached to a specific line of the diff.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securesourcemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securesourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securesourcemanager/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own pull request comment"})

    		ubx.Resource(securesourcemanager.SecuresourcemanagerPullRequestComment, "ci-runner", securesourcemanager.SecuresourcemanagerPullRequestCommentConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="code" type="object">
  The comment on a code line. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="body" type="string">
      Required. The comment body. Optional.
    </ResponseField>
    <ResponseField name="effective_commit_sha" type="string">
      Output only. The effective commit sha this code comment is pointing to. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="effective_root_comment" type="string">
      Output only. The root comment of the conversation, derived from the reply field. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="position" type="object">
      The position of the code comment. Optional.
      <Expandable title="properties">
        <ResponseField name="line" type="string">
          Required. The line number of the comment. Positive value means it's on the new side of the diff, negative value means it's on the old side. Optional.
        </ResponseField>
        <ResponseField name="path" type="string">
          Required. The path of the file. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="reply" type="string">
      Optional. Input only. The PullRequestComment resource name that this comment is replying to. Optional.
    </ResponseField>
    <ResponseField name="resolved" type="bool">
      Output only. Boolean indicator if the comment is resolved. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="comment" type="object">
  The general pull request comment. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="body" type="string">
      Required. The comment body. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">

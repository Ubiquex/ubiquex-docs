`google_securesourcemanager_hook` configures a webhook that Secure Source Manager calls out to on repository events (pushes, pull request changes), integrating with external CI/CD or notification systems.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_securesourcemanager --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_securesourcemanager/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securesourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google_securesourcemanager/securesourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hook"})

    		ubx.Resource(securesourcemanager.SecuresourcemanagerHook, "example", securesourcemanager.SecuresourcemanagerHookConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Determines if the hook disabled or not. Set to true to stop sending traffic. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="events" type="list(string)">
  Optional. The events that trigger hook on. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. A unique identifier for a Hook. The name should be of the format: `projects/&#123;project&#125;/locations/&#123;location_id&#125;/repositories/&#123;repository_id&#125;/hooks/&#123;hook_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="push_option" type="object">
  Configuration for which push events this webhook fires on and what payload it sends -- the per-hook counterpart to a branch rule's own trigger settings. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
  <Expandable title="properties">
    <ResponseField name="branch_filter" type="string">
      Optional. Trigger hook for matching branches only. Specified as glob pattern. If empty or *, events for all branches are reported. Examples: main, &#123;main,release*&#125;. See https://pkg.go.dev/github.com/gobwas/glob documentation. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sensitive_query_string" type="string">
  Optional. The sensitive query string to be appended to the target URI. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_uri" type="string">
  Required. The target URI to which the payloads will be delivered. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Unique identifier of the hook. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

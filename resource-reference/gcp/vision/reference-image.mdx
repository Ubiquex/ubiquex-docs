`google_vision_reference_image` is one real image associated with a `google_vision_product` in Cloud Vision Product Search, visually describing that product from one viewpoint so the matching model has something concrete to compare a query image against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vision "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vision"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own reference image"})

    		ubx.Resource(vision.ReferenceImage, "example", vision.ReferenceImageConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="bounding_polys" type="list(object)">
  Optional. Bounding polygons around the areas of interest in the reference image. If this field is empty, the system will try to detect regions of interest. At most 10 bounding polygons will be used. The provided shape is converted into a non-rotated rectangle. Once converted, the small edge of the rectangle must be greater than or equal to 300 pixels. The aspect ratio must be 1:4 or less (i.e. 1:3 is ok; 1:5 is not). Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="normalized_vertices" type="list(object)">
      The real polygon vertices bounding the product within this reference image, normalized to `[0, 1]` relative to the image's own dimensions. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="x" type="number">
          The horizontal coordinate of one vertex in a bounding polygon. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="y" type="number">
          The vertical coordinate of one vertex in a bounding polygon. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="vertices" type="list(object)">
      The real polygon vertices bounding the product within this reference image, in the image's own real pixel coordinate space. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="x" type="number">
          The horizontal coordinate of one vertex in a bounding polygon. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="y" type="number">
          The vertical coordinate of one vertex in a bounding polygon. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the reference image. Format is: `projects/PROJECT_ID/locations/LOC_ID/products/PRODUCT_ID/referenceImages/IMAGE_ID`. This field is ignored when creating a reference image. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uri" type="string">
  Required. The Google Cloud Storage URI of the reference image. The URI must start with `gs://`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

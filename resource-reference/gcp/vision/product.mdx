`google_vision_product` is a Cloud Vision Product Search product, a real catalog item (with a display name, category, and custom labels) that one or more `google_vision_reference_image` entries are attached to, and that gets grouped into a `google_vision_product_set` for matching.

## Example

<Tabs>

    ```go
    // ubx sdk gen --only google_vision --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_vision/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vision "github.com/ubiquex/ubx-sdk-google/sdk/go/google_vision/vision"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own product"})

    		ubx.Resource(vision.VisionProduct, "ci-runner", vision.VisionProductConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="description" type="string">
  User-provided metadata to be stored with this product. Must be at most 4096 characters long. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-provided name for this Product. Must not be empty. Must be at most 4096 characters long. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the product. Format is: `projects/PROJECT_ID/locations/LOC_ID/products/PRODUCT_ID`. This field is ignored when creating a product. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="product_category" type="string">
  Immutable. The category for the product identified by the reference image. This should be one of "homegoods-v2", "apparel-v2", "toys-v2", "packagedgoods-v1" or "general-v1". The legacy categories "homegoods", "apparel", and "toys" are still supported, but these should not be used for new products. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="product_labels" type="list(object)">
  Key-value pairs that can be attached to a product. At query time, constraints can be specified based on the product_labels. Note that integer values can be provided as strings, e.g. "1199". Only strings with integer values can match a range-based restriction which is to be supported soon. Multiple values can be assigned to the same key. One product may have up to 500 product_labels. Notice that the total number of distinct product_labels over all products in one ProductSet cannot exceed 1M, otherwise the product search pipeline will refuse to work for that ProductSet. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="key" type="string">

    <ResponseField name="value" type="string">
      The real value of this product label, paired with its own `key`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

`google_vision_product_set` is a Cloud Vision Product Search product set, a real, named collection of `google_vision_product` entries a query image gets visually matched against, used to scope and speed up product search.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vision "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vision"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own product set"})

    		ubx.Resource(vision.ProductSet, "example", vision.ProductSetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

`google_saasservicemgmt_v1beta1_release` is an App Lifecycle Manager (formerly SaaS Runtime) release, a real, versioned bundle of changes to a SaaS offering that gets deployed to `google_saasservicemgmt_unit`s via a `google_saasservicemgmt_rollout`.

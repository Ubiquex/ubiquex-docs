`google_saasservicemgmt_v1beta1_unit_group_operation` is a real, tracked operation performed against a unit_group -- its own uid and labels record which operation this is -- so a long-running or bulk change applied to a unit group can be inspected and audited as its own resource rather than only observed indirectly through the group's own eventual state.

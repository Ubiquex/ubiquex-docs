`google_saasservicemgmt_v1beta1_flag_release` is a real, point-in-time release bundling a set of flags' own revisions together (flag_revisions, flag_revisions_release, flag_sets_release) -- effective_flag_revisions records what was actually live -- so a coordinated set of flag changes can be released and audited as one unit instead of each flag changing independently.

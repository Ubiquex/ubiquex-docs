`google_networkmanagement_vpc_flow_logs_config` configures VPC Flow Logs for a network, subnet, or interconnect attachment at a project-wide organizational level, controlling sampling and aggregation.

## Properties

<ResponseField name="aggregation_interval" type="string">
  Optional. The aggregation interval for the logs. Default value is INTERVAL_5_SEC. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the config was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="cross_project_metadata" type="string">
  Optional. Determines whether to include cross project annotations in the logs. This field is available only for organization configurations. If not specified in org configs will be set to CROSS_PROJECT_METADATA_ENABLED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The user-supplied description of the VPC Flow Logs configuration. Maximum of 512 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter_expr" type="string">
  Optional. Export filter used to define which VPC Flow Logs should be logged. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="flow_sampling" type="number">
  Optional. The value of the field must be in (0, 1]. The sampling rate of VPC Flow Logs where 1.0 means all collected logs are reported. Setting the sampling rate to 0.0 is not allowed. If you want to disable VPC Flow Logs, use the state field instead. Default value is 1.0. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="interconnect_attachment" type="string">
  Traffic will be logged from the Interconnect Attachment. Format: projects/&#123;project_id&#125;/regions/&#123;region&#125;/interconnectAttachments/&#123;name&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels to represent user-provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata" type="string">
  Optional. Configures whether all, none or a subset of metadata fields should be added to the reported VPC flow logs. Default value is INCLUDE_ALL_METADATA. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="metadata_fields" type="list(string)">
  Optional. Custom metadata fields to include in the reported VPC flow logs. Can only be specified if "metadata" was set to CUSTOM_METADATA. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Unique name of the configuration. The name can have one of the following forms: - For project-level configurations: `projects/&#123;project_id&#125;/locations/global/vpcFlowLogsConfigs/&#123;vpc_flow_logs_config_id&#125;` - For organization-level configurations: `organizations/&#123;organization_id&#125;/locations/global/vpcFlowLogsConfigs/&#123;vpc_flow_logs_config_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Traffic will be logged from VMs, VPN tunnels and Interconnect Attachments within the network. Format: projects/&#123;project_id&#125;/global/networks/&#123;name&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Optional. The state of the VPC Flow Log configuration. Default value is ENABLED. When creating a new configuration, it must be enabled. Setting state=DISABLED will pause the log generation for this config. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="subnet" type="string">
  Traffic will be logged from VMs within the subnetwork. Format: projects/&#123;project_id&#125;/regions/&#123;region&#125;/subnetworks/&#123;name&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_resource_state" type="string">
  Output only. Describes the state of the configured target resource for diagnostic purposes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the config was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="vpn_tunnel" type="string">
  Traffic will be logged from the VPN Tunnel. Format: projects/&#123;project_id&#125;/regions/&#123;region&#125;/vpnTunnels/&#123;name&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

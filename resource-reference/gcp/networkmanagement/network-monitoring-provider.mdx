`google_networkmanagement_network_monitoring_provider` registers a monitoring data source (e.g. a specific region's own telemetry) that Network Intelligence Center draws performance data from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/networkmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own network monitoring provider"})

    		ubx.Resource(networkmanagement.NetworkMonitoringProvider, "example", networkmanagement.NetworkMonitoringProviderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="create_time" type="string">
  Output only. The time the NetworkMonitoringProvider was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="errors" type="list(string)">
  Output only. The list of error messages detected for the NetworkMonitoringProvider. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. Name of the resource. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/networkMonitoringProviders/&#123;network_monitoring_provider&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="provider_type" type="string">
  Required. Type of the NetworkMonitoringProvider. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="provider_uri" type="string">

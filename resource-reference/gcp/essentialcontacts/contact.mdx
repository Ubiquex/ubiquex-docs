`google_essentialcontacts_contact` registers an email address to receive specific categories of Google Cloud notification (e.g. billing or security alerts) for an organization, folder, or project.

## Example

<Tabs>

    ```go

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own contact"})
    ```

## Properties

<ResponseField name="email" type="string">
  Required. The email address to send notifications to. The email address does not need to be a Google Account. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="language_tag" type="string">
  Required. The preferred language for notifications, as a ISO 639-1 language code. See [Supported languages](https://cloud.google.com/resource-manager/docs/managing-notification-contacts#supported-languages) for a list of supported languages. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The identifier for the contact. Format: &#123;resource_type&#125;/&#123;resource_id&#125;/contacts/&#123;contact_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="notification_category_subscriptions" type="list(string)">
  Required. The categories of notifications that the contact will receive communications for. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="validate_time" type="string">
  Output only. The last time the validation_state was updated, either manually or automatically. A contact is considered stale if its validation state was updated more than 1 year ago. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="validation_state" type="string">
  Output only. The validity of the contact. A contact is considered valid if it is the correct recipient for notifications for a particular resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

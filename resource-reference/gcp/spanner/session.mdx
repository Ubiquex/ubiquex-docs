`google_spanner_session` is a connection context Spanner client libraries create to execute reads, writes, and transactions against a database, pooled and reused across requests for efficiency.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_spanner --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_spanner/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	spanner "github.com/ubiquex/ubx-sdk-google/sdk/go/google_spanner/spanner"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own session"})

    		ubx.Resource(spanner.SpannerSession, "ci-runner", spanner.SpannerSessionConfig{
    			Session: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    from ubx.google_spanner.spanner import SpannerSession, SpannerSessionConfig

        ubx.run("payments", describe)

## Input properties

<ResponseField name="session" type="object">
  A session in the Cloud Spanner API. Optional.
  <Expandable title="properties">
    <ResponseField name="approximate_last_use_time" type="string">
      Output only. The approximate timestamp when the session is last used. It's typically earlier than the actual last use time. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="create_time" type="string">
      Output only. The timestamp when the session is created. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="creator_role" type="string">
      The database role which created this session. Optional.
    </ResponseField>
    <ResponseField name="labels" type="map(string)">
      The labels for the session. * Label keys must be between 1 and 63 characters long and must conform to the following regular expression: `[a-z]([-a-z0-9]*[a-z0-9])?`. * Label values must be between 0 and 63 characters long and must conform to the regular expression `([a-z]([-a-z0-9]*[a-z0-9])?)?`. * No more than 64 labels can be associated with a given session. See https://goo.gl/xmQnxf for more information on and examples of labels. Optional.
    </ResponseField>
    <ResponseField name="multiplexed" type="bool">
      Optional. If `true`, specifies a multiplexed session. Use a multiplexed session for multiple, concurrent operations including any combination of read-only and read-write transactions. Use `sessions.create` to create multiplexed sessions. Don't use BatchCreateSessions to create a multiplexed session. You can't delete or list multiplexed sessions. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      Output only. The name of the session. This is always system-assigned. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

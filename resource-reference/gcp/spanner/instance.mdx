`google_spanner_instance` is the top-level Spanner resource that provisions compute capacity (nodes or processing units) database(s) run on, and defines the region(s) data is replicated across.

## Example

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	spanner "github.com/ubiquex/ubx-sdk-google/sdk/go/google_spanner/spanner"

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {

`google_spanner_instance_partition` reserves a dedicated slice of compute capacity within a Spanner instance for a specific database or set of databases, isolating its own performance from the rest of the instance.

## Example

    ```go
    // ubx sdk gen --only google_spanner --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_spanner/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	spanner "github.com/ubiquex/ubx-sdk-google/sdk/go/google_spanner/spanner"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own instance partition"})

    		ubx.Resource(spanner.SpannerInstancePartition, "example", spanner.SpannerInstancePartitionConfig{
    			InstancePartition:   map[string]any{"name": "example-name"},
    			InstancePartitionId: "example",
    		})
    	}))
    }
    ```

If not specified or set to 0, the autoscaler skips scaling based on high priority CPU utilization. Optional.

            <ResponseField name="storage_utilization_percent" type="number">
              Required. The target storage utilization percentage that the autoscaler should be trying to achieve for the instance. This number is on a scale from 0 (no utilization) to 100 (full utilization). The valid range is [10, 99] inclusive. Optional.
            </ResponseField>

If not specified or set to 0, the autoscaler skips scaling based on total CPU utilization. If both `high_priority_cpu_utilization_percent` and `total_cpu_utilization_percent` are specified, the autoscaler provisions the larger of the two required compute capacities to satisfy both targets. Optional.

    <ResponseField name="create_time" type="string">
      Output only. The time at which the instance partition was created. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="display_name" type="string">
      Required. The descriptive name for this instance partition as it appears in UIs. Must be unique per project and between 4 and 30 characters in length. Optional.
    </ResponseField>
    <ResponseField name="etag" type="string">
      Used for optimistic concurrency control as a way to help prevent simultaneous updates of a instance partition from overwriting each other. It is strongly suggested that systems make use of the etag in the read-modify-write cycle to perform instance partition updates in order to avoid race conditions: An etag is returned in the response which contains instance partitions, and systems are expected to put that etag in the request to update instance partitions to ensure that their change will be applied to the same version of the instance partition. If no etag is provided in the call to update instance partition, then the existing instance partition is overwritten blindly. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      Required. A unique identifier for the instance partition. Values are of the form `projects//instances//instancePartitions/a-z*[a-z0-9]`. The final segment of the name must be between 2 and 64 characters in length. An instance partition's name cannot be changed after the instance partition is created. Optional.
    </ResponseField>
    <ResponseField name="node_count" type="number">
      The number of nodes allocated to this instance partition. Users can set the `node_count` field to specify the target number of nodes allocated to the instance partition. If autoscaling is enabled, node_count is treated as an OUTPUT_ONLY field and reflects the current number of nodes allocated to the instance partition. This may be zero in API responses for instance partitions that are not yet in state `READY`. Optional.
    </ResponseField>
    <ResponseField name="processing_units" type="number">
      The number of processing units allocated to this instance partition. Users can set the `processing_units` field to specify the target number of processing units allocated to the instance partition. If autoscaling is enabled, processing_units is treated as an OUTPUT_ONLY field and reflects the current number of processing units allocated to the instance partition. This might be zero in API responses for instance partitions that are not yet in the `READY` state. Optional.
    </ResponseField>
    <ResponseField name="referencing_backups" type="list(string)">
      Output only. Deprecated: This field is not populated. Output only. The names of the backups that reference this instance partition. Referencing backups should share the parent instance. The existence of any referencing backup prevents the instance partition from being deleted. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="referencing_databases" type="list(string)">
      Output only. The names of the databases that reference this instance partition. Referencing databases should share the parent instance. The existence of any referencing database prevents the instance partition from being deleted. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="state" type="string">
      Output only. The current instance partition state. Computed by Google Cloud after `ship`.

      Output only. The time at which the instance partition was most recently updated. Computed by Google Cloud after `ship`.

`google_netapp_backup_policy` defines the automated backup schedule (frequency, retention) applied to Google Cloud NetApp Volumes volume(s) it's attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	netapp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/netapp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own backup policy"})

    		ubx.Resource(netapp.BackupPolicy, "example", netapp.BackupPolicyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="assigned_volume_count" type="number">
  Output only. The total number of volumes assigned by this backup policy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the backup policy was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="daily_backup_limit" type="number">
  Number of daily backups to keep. Note that the minimum daily backup limit is 2. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the backup policy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enabled" type="bool">
  If enabled, make backups automatically according to the schedules. This will be applied to all volumes that have this policy attached and enforced on volume level. If not specified, default is true. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="monthly_backup_limit" type="number">
  Number of monthly backups to keep. Note that the sum of daily, weekly and monthly backups should be greater than 1. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the backup policy. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;/backupPolicies/&#123;backup_policy_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The backup policy state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="weekly_backup_limit" type="number">
  Number of weekly backups to keep. Note that the sum of daily, weekly and monthly backups should be greater than 1. Optional; if omitted, computed by Google Cloud.
</ResponseField>

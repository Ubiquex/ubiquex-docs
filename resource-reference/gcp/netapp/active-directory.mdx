`google_netapp_active_directory` registers an Active Directory domain connection Google Cloud NetApp Volumes uses to authenticate SMB and Kerberized NFS access to its own volumes.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	netapp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/netapp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own active directory"})

    		ubx.Resource(netapp.ActiveDirectory, "example", netapp.ActiveDirectoryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="administrators" type="list(string)">
  Optional. Users to be added to the Built-in Admininstrators group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="aes_encryption" type="bool">
  If enabled, AES encryption will be enabled for SMB communication. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="backup_operators" type="list(string)">
  Optional. Users to be added to the Built-in Backup Operator active directory group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time of the active directory. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the active directory. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dns" type="string">
  Required. Comma separated list of DNS server IP addresses for the Active Directory domain. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="domain" type="string">
  Required. Name of the Active Directory domain Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encrypt_dc_connections" type="bool">
  If enabled, traffic between the SMB server to Domain Controller (DC) will be encrypted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kdc_hostname" type="string">
  Name of the active directory machine. This optional parameter is used only while creating kerberos volume Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kdc_ip" type="string">
  KDC server IP address for the active directory machine. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels for the active directory. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ldap_signing" type="bool">
  Specifies whether or not the LDAP traffic needs to be signed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the active directory. Format: `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/activeDirectories/&#123;active_directory_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="net_bios_prefix" type="string">
  Required. NetBIOSPrefix is used as a prefix for SMB server name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="nfs_users_with_ldap" type="bool">
  If enabled, will allow access to local users and LDAP users. If access is needed for only LDAP users, it has to be disabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="organizational_unit" type="string">
  The Organizational Unit (OU) within the Windows Active Directory the user belongs to. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="password" type="string">
  Required. Password of the Active Directory domain administrator. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="security_operators" type="list(string)">
  Optional. Domain users to be given the SeSecurityPrivilege. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="site" type="string">
  The Active Directory site the service will limit Domain Controller discovery too. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the AD. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. The state details of the Active Directory. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="username" type="string">
  Required. Username of the Active Directory domain administrator. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_netapp_replication` configures cross-region or cross-zone replication of a Google Cloud NetApp Volumes volume to a destination volume, for disaster recovery.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	netapp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/netapp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own replication"})

    		ubx.Resource(netapp.Replication, "example", netapp.ReplicationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="cluster_location" type="string">
  Optional. Location of the user cluster. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Replication create time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description about this replication relationship. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination_volume" type="string">
  Output only. Full name of destination volume resource. Example : "projects/&#123;project&#125;/locations/&#123;location&#125;/volumes/&#123;volume_id&#125;" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination_volume_parameters" type="object">
  DestinationVolumeParameters specify input parameters used for creating destination volume. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="description" type="string">
      Description for the destination volume. Optional.
    </ResponseField>
    <ResponseField name="share_name" type="string">
      Destination volume's share name. If not specified, source volume's share name will be used. Optional.
    </ResponseField>
    <ResponseField name="storage_pool" type="string">
      Required. Existing destination StoragePool name. Optional.
    </ResponseField>
    <ResponseField name="tiering_policy" type="object">
      Defines tiering policy for the volume. Optional.
      <Expandable title="properties">
        <ResponseField name="cooling_threshold_days" type="number">
          Optional. Time in days to mark the volume's data block as cold and make it eligible for tiering, can be range from 2-183. Default is 31. Optional.
        </ResponseField>
        <ResponseField name="hot_tier_bypass_mode_enabled" type="bool">
          Optional. Flag indicating that the hot tier bypass mode is enabled. Default is false. This is only applicable to Flex service level. Optional.
        </ResponseField>
        <ResponseField name="tier_action" type="string">
          Optional. Flag indicating if the volume has tiering policy enable/pause. Default is PAUSED. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="volume_id" type="string">
      Desired destination volume resource id. If not specified, source volume's resource id will be used. This value must start with a lowercase letter followed by up to 62 lowercase letters, numbers, or hyphens, and cannot end with a hyphen. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="healthy" type="bool">
  Output only. Condition of the relationship. Can be one of the following: - true: The replication relationship is healthy. It has not missed the most recent scheduled transfer. - false: The replication relationship is not healthy. It has missed the most recent scheduled transfer. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hybrid_peering_details" type="object">
  HybridPeeringDetails contains details about the hybrid peering. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="command" type="string">
      Output only. Copy-paste-able commands to be used on user's ONTAP to accept peering requests. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="command_expiry_time" type="string">
      Output only. Expiration time for the peering command to be executed on user's ONTAP. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="passphrase" type="string">
      Output only. Temporary passphrase generated to accept cluster peering command. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="peer_cluster_name" type="string">
      Output only. Name of the user's local source cluster to be peered with the destination cluster. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="peer_svm_name" type="string">
      Output only. Name of the user's local source vserver svm to be peered with the destination vserver svm. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="peer_volume_name" type="string">
      Output only. Name of the user's local source volume to be peered with the destination volume. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="subnet_ip" type="string">
      Output only. IP address of the subnet. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="hybrid_replication_type" type="string">
  Output only. Type of the hybrid replication. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hybrid_replication_user_commands" type="object">
  UserCommands contains the commands to be executed by the customer. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="commands" type="list(string)">
      Output only. List of commands to be executed by the customer. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="mirror_state" type="string">
  Output only. Indicates the state of mirroring. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the Replication. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;/volumes/&#123;volume_id&#125;/replications/&#123;replication_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="replication_schedule" type="string">
  Required. Indicates the schedule for replication. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="role" type="string">
  Output only. Indicates whether this points to source or destination. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_volume" type="string">
  Output only. Full name of source volume resource. Example : "projects/&#123;project&#125;/locations/&#123;location&#125;/volumes/&#123;volume_id&#125;" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the replication. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. State details of the replication. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="transfer_stats" type="object">
  TransferStats reports all statistics related to replication transfer. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="lag_duration" type="string">
      Lag duration indicates the duration by which Destination region volume content lags behind the primary region volume content. Optional.
    </ResponseField>
    <ResponseField name="last_transfer_bytes" type="string">
      Last transfer size in bytes. Optional.
    </ResponseField>
    <ResponseField name="last_transfer_duration" type="string">
      Time taken during last transfer. Optional.
    </ResponseField>
    <ResponseField name="last_transfer_end_time" type="string">
      Time when last transfer completed. Optional.
    </ResponseField>
    <ResponseField name="last_transfer_error" type="string">
      A message describing the cause of the last transfer failure. Optional.
    </ResponseField>
    <ResponseField name="total_transfer_duration" type="string">
      Cumulative time taken across all transfers for the replication relationship. Optional.
    </ResponseField>
    <ResponseField name="transfer_bytes" type="string">
      Cumulative bytes transferred so far for the replication relationship. Optional.
    </ResponseField>
    <ResponseField name="update_time" type="string">
      Time when progress was updated last. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

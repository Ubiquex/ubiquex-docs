<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_netapp_snapshot`.
</Warning>

`google_netapp_v1beta1_snapshot` is a point-in-time, storage-efficient snapshot of a Google Cloud NetApp Volumes volume, restorable in place or usable as the source for a new volume clone.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the snapshot was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the snapshot with 2048 characters or less. Requests with longer descriptions will be rejected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the snapshot. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;/volumes/&#123;volume_id&#125;/snapshots/&#123;snapshot_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The snapshot state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. State details of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="used_bytes" type="number">
  Output only. Current storage usage for the snapshot in bytes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

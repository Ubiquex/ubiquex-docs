`google_netapp_storage_pool` is the underlying provisioned capacity and performance tier in Google Cloud NetApp Volumes that individual volume(s) are carved out of.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	netapp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/netapp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own storage pool"})

    		ubx.Resource(netapp.StoragePool, "example", netapp.StoragePoolConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="active_directory" type="string">
  Optional. Specifies the Active Directory to be used for creating a SMB volume. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="allow_auto_tiering" type="bool">
  Optional. True if the storage pool supports Auto Tiering enabled volumes. Default is false. Auto-tiering can be enabled after storage pool creation but it can't be disabled once enabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="available_throughput_mibps" type="number">
  Output only. Available throughput of the storage pool (in MiB/s). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="capacity_gib" type="string">
  Required. Capacity in GIB of the pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="cold_tier_size_used_gib" type="string">
  Output only. Total cold tier data rounded down to the nearest GiB used by the storage pool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="custom_performance_enabled" type="bool">
  Optional. True if using Independent Scaling of capacity and performance (Hyperdisk) By default set to false Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enable_hot_tier_auto_resize" type="bool">
  Optional. Flag indicating that the hot-tier threshold will be auto-increased by 10% of the hot-tier when it hits 100%. Default is true. The increment will kick in only if the new size after increment is still less than or equal to storage pool size. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encryption_type" type="string">
  Output only. Specifies the current pool encryption key source. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="global_access_allowed" type="bool">
  Deprecated. Used to allow SO pool to access AD or DNS server from other regions. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hot_tier_size_gib" type="string">
  Optional. Total hot tier capacity for the Storage Pool. It is applicable only to Flex service level. It should be less than the minimum storage pool size and cannot be more than the current storage pool size. It cannot be decreased once set. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hot_tier_size_used_gib" type="string">
  Output only. Total hot tier data rounded down to the nearest GiB used by the storage pool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kms_config" type="string">
  Optional. Specifies the KMS config to be used for volume encryption. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ldap_enabled" type="bool">
  Optional. Flag indicating if the pool is NFS LDAP enabled or not. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="mode" type="string">
  Optional. Mode of the storage pool. This field is used to control whether the user can perform ONTAP operations on the storage pool using the GCNV ONTAP Mode APIs. If not specified during creation, it defaults to `DEFAULT`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Required. VPC Network name. Format: projects/&#123;project&#125;/global/networks/&#123;network&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="psa_range" type="string">
  Optional. This field is not implemented. The values provided in this field are ignored. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="qos_type" type="string">
  Optional. QoS (Quality of Service) Type of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="replica_zone" type="string">
  Optional. Specifies the replica zone for regional storagePool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Reserved for future use Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Reserved for future use Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scale_type" type="string">
  Optional. The scale type of the storage pool. Defaults to `SCALE_TYPE_DEFAULT` if not specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_level" type="string">
  Required. Service level of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. State details of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="total_iops" type="string">
  Optional. Custom Performance Total IOPS of the pool if not provided, it will be calculated based on the total_throughput_mibps Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="total_throughput_mibps" type="string">
  Optional. Custom Performance Total Throughput of the pool (in MiBps) Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Optional. Type of the storage pool. This field is used to control whether the pool supports `FILE` based volumes only or `UNIFIED` (both `FILE` and `BLOCK`) volumes. If not specified during creation, it defaults to `FILE`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="volume_capacity_gib" type="string">
  Output only. Allocated size of all volumes in GIB in the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="volume_count" type="number">
  Output only. Volume count of the storage pool Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="zone" type="string">
  Optional. Specifies the active zone for regional storagePool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

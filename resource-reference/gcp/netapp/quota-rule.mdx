`google_netapp_quota_rule` sets a per-user or per-group storage quota on a Google Cloud NetApp Volumes volume, limiting how much space or how many files that user or group may consume.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	netapp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/netapp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own quota rule"})

    		ubx.Resource(netapp.QuotaRule, "example", netapp.QuotaRuleConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time of the quota rule Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the quota rule Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disk_limit_mib" type="number">
  Required. The maximum allowed disk space in MiB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels of the quota rule Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the quota rule. Format: `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/volumes/volumes/&#123;volume_id&#125;/quotaRules/&#123;quota_rule_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the quota rule Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. State details of the quota rule Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target" type="string">
  Optional. The quota rule applies to the specified user or group, identified by a Unix UID/GID, Windows SID, or null for default. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Required. The type of quota rule. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_netapp_backup`.
</Warning>

`google_netapp_v1beta1_backup` is a single point-in-time backup of a Google Cloud NetApp Volumes volume, stored independently of the volume's own snapshot history for longer-term retention.

## Properties

<ResponseField name="backup_region" type="string">
  Output only. Region in which backup is stored. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="backup_type" type="string">
  Output only. Type of backup, manually created or created by a backup policy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="chain_storage_bytes" type="string">
  Output only. Total size of all backups in a chain in bytes = baseline backup size + sum(incremental backup size) Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the backup was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the backup with 2048 characters or less. Requests with longer descriptions will be rejected. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enforced_retention_end_time" type="string">
  Output only. The time until which the backup is not deletable. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the backup. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;/backupVaults/&#123;backup_vault_id&#125;/backups/&#123;backup_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ontap_source" type="object">
  Represents ONTAP source details. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="snapshot_uuid" type="string">
      Optional. The UUID of the ONTAP source snapshot. Optional.
    </ResponseField>
    <ResponseField name="storage_pool" type="string">
      Required. Name of the storage pool. This must be specified for creating backups for ONTAP mode volumes. Format: `projects/&#123;projects_id&#125;/locations/&#123;location&#125;/storagePools/&#123;storage_pool_id&#125;` Optional.
    </ResponseField>
    <ResponseField name="volume_uuid" type="string">
      Required. The UUID of the ONTAP source volume. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. Reserved for future use Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. Reserved for future use Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_snapshot" type="string">
  If specified, backup will be created from the given snapshot. If not specified, there will be a new snapshot taken to initiate the backup creation. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;/volumes/&#123;volume_id&#125;/snapshots/&#123;snapshot_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_volume" type="string">
  The resource name of the volume that this backup belongs to. You must provide either `source_volume` or `ontap_source`. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;/volumes/&#123;volume_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The backup state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="volume_region" type="string">
  Output only. Region of the volume from which the backup was created. Format: `projects/&#123;project_id&#125;/locations/&#123;location&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="volume_usage_bytes" type="string">
  Output only. Size of the file system when the backup was created. When creating a new volume from the backup, the volume capacity will have to be at least as big. Optional; if omitted, computed by Google Cloud.
</ResponseField>

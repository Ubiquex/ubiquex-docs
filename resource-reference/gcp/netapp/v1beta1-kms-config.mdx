<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_netapp_kms_config`.
</Warning>

`google_netapp_v1beta1_kms_config` configures the Cloud KMS customer-managed encryption key Google Cloud NetApp Volumes uses to encrypt a storage pool's own volume(s).

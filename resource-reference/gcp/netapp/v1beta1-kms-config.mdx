`google_netapp_v1beta1_kms_config` configures the Cloud KMS customer-managed encryption key Google Cloud NetApp Volumes uses to encrypt a storage pool's own volume(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	netapp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/netapp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 kms config"})

    		ubx.Resource(netapp.V1beta1KmsConfig, "example", netapp.V1beta1KmsConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time of the KmsConfig. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="crypto_key_name" type="string">
  Required. Customer-managed crypto key resource full name. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;key_ring&#125;/cryptoKeys/&#123;crypto_key&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the KmsConfig. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="instructions" type="string">
  Output only. Instructions to provide the access to the customer provided encryption key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels as key value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Name of the `KmsConfig`. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/kmsConfigs/&#123;kms_config&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_account" type="string">
  Output only. The Service account which will have access to the customer provided encryption key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the KmsConfig. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. State details of the KmsConfig. Optional; if omitted, computed by Google Cloud.
</ResponseField>

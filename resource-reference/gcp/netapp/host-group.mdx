## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time of the host group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the host group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hosts" type="list(string)">
  Required. The list of hosts associated with the host group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels of the host group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the host group. Format: `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/hostGroups/&#123;host_group_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="os_type" type="string">
  Required. The OS type of the host group. It indicates the type of operating system used by all of the hosts in the HostGroup. All hosts in a HostGroup must be of the same OS type. This can be set only when creating a HostGroup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the host group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Required. Type of the host group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

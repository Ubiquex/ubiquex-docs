`google_agentidentity_v1alpha_auth_provider` registers an external OAuth or API-key credential source with Agent Identity's own auth manager, letting agents authenticate to outbound tool(s) via that provider's own credential flow.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/agentidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha auth provider"})

    		ubx.Resource(agentidentity.V1alphaAuthProvider, "example", agentidentity.V1alphaAuthProviderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="allowed_scopes" type="list(string)">
  Optional. List of scopes that are allowed to be requested for this auth provider. If this list is non-empty, only scopes within this list may be requested. If this list is empty, all scopes may be requested. Scopes appearing in `blocked_scopes` are disallowed even if they appear in `allowed_scopes`. The number of allowed scopes is limited to 200. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="auth_provider_type_params" type="object">
  Required. Parameters specific to the auth provider type. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="api_key" type="object">
      Configuration for API key authentication. Optional.
      <Expandable title="properties">
        <ResponseField name="api_key" type="string">
          Optional. Input only. The API key for this auth provider. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="ge_auth_provider" type="any">
      Configuration for Gemini Enterprise authentication. Optional.
    </ResponseField>
    <ResponseField name="three_legged_oauth" type="object">
      Configuration for 3-legged OAuth (3LO) authentication. Optional.
      <Expandable title="properties">
        <ResponseField name="authorization_url" type="string">
          Optional. The authorization endpoint to send users to for consenting to delegate to the agent. For example, "https://auth.atlassian.com/authorize". Optional.
        </ResponseField>
        <ResponseField name="client_id" type="string">
          Optional. The client ID of the OAuth client. Optional.
        </ResponseField>
        <ResponseField name="client_secret" type="string">
          Optional. Input only. The client secret of the OAuth client. Optional.
        </ResponseField>
        <ResponseField name="default_continue_uri" type="string">
          Optional. The default continue URI for the 3LO flow, used when no continue URI is provided in the RetrieveCredentials request. Optional.
        </ResponseField>
        <ResponseField name="enable_pkce" type="bool">
          Optional. Enables Proof Key for Code Exchange (PKCE) for the OAuth flow to prevent authorization code interception attacks. Optional.
        </ResponseField>
        <ResponseField name="redirect_url" type="string">
          Output only. The redirect URL this auth provider uses for the OAuth exchange. This is deterministic based on the name of the auth provider. Computed by Google Cloud after `ship`.
        </ResponseField>
        <ResponseField name="token_url" type="string">
          Optional. The token endpoint for requesting tokens on behalf of an end user. For example, "https://auth.atlassian.com/oauth/token". Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="two_legged_oauth" type="object">
      Configuration for 2-legged OAuth (2LO) authentication. Optional.
      <Expandable title="properties">
        <ResponseField name="client_id" type="string">
          Optional. The client ID of the OAuth client. Optional.
        </ResponseField>
        <ResponseField name="client_secret" type="string">
          Optional. Input only. The client secret of the OAuth client. Optional.
        </ResponseField>
        <ResponseField name="token_url" type="string">
          Optional. The token endpoint of the OAuth client. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="blocked_scopes" type="list(string)">
  Optional. List of scopes that are blocked from being requested for this auth provider. If a scope appears in this list, it will not be requested, even if it also appears in `allowed_scopes`. `blocked_scopes` takes precedence over `allowed_scopes`. The number of blocked scopes is limited to 200. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">

<ResponseField name="deleted" type="bool">

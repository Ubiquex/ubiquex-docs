`google_agentregistry_v1alpha_revision` is a single, immutable revision of an Agent Registry skill's own uploaded content -- its own gcs_source or archive_upload_source, sha256_hash, and size_bytes -- so a skill's own version history is a real, addressable sequence of revisions rather than the latest upload silently overwriting the one before it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/agentregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha revision"})

    		ubx.Resource(agentregistry.V1alphaRevision, "example", agentregistry.V1alphaRevisionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

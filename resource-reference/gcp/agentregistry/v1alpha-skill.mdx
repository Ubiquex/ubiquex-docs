<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_agentregistry_v1alpha_skill` is a real, published skill in the Agent Registry -- its own publisher, type, and frontmatter, with default_revision and initial_revision pointing at specific real revisions -- so an agent capability can be discovered and installed by skill_id the way a package is, not hand-wired into an agent's own configuration.

<ResponseField name="name" type="string">
  Identifier. Resource name of the Skill. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/skills/&#123;skill&#125;` The `&#123;skill&#125;` segment acts as the resource ID. If the skill is associated with a Publisher, this segment typically uses a hyphenated namespace prefix corresponding to the publisher (e.g., `google-workspace-create-docs`). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="publisher" type="string">
  Optional. The publisher resource associated with this skill. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/publishers/&#123;publisher&#125;` The publisher dictates the allowed namespace prefixes for the skill's name and logical `skill_id` (e.g., Publisher `google` authorizes the `google-*` prefix). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="skill_id" type="string">
  Output only. A stable, globally unique logical identifier for the skill. It is securely constructed by the backend by combining the associated `publisher`'s verified namespace and the skill's resource ID to enforce strict ownership. For example, the prefix `google-` is reserved exclusively for first-party Google publishers to prevent namespace squatting. Example: `urn:skill:google-workspace:create-docs` Optional; if omitted, computed by Google Cloud.
</ResponseField>

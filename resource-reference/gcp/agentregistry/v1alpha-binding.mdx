<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_agentregistry_binding`.
</Warning>

`google_agentregistry_v1alpha_binding` establishes an explicit connection from a source agent to a target resource (another agent, an MCP server, or an endpoint) registered in Agent Registry, letting an orchestrator agent reach that downstream capability.

    func main() {

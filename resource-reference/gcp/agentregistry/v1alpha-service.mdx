`google_agentregistry_v1alpha_service` registers a discoverable agent or MCP server with Agent Registry, part of the Gemini Enterprise Agent Platform's own catalog for finding and connecting to agentic capabilities.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/agentregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha service"})

    		ubx.Resource(agentregistry.V1alphaService, "example", agentregistry.V1alphaServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="agent_spec" type="object">
  The spec of the agent. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="content" type="map(any)">
      Optional. The content of the Agent spec in the JSON format. This payload is validated against the schema for the specified type. The content size is limited to `10KB`. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      Required. The type of the agent spec content. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">

</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. User-defined display name for the Service. Can have a maximum length of `63` characters. Optional; if omitted, computed by Google Cloud.

`google_dataform_folder` organizes code asset(s) (repositories holding SQLX transformations, notebooks, saved queries) into a hierarchical structure within Dataform, similar to folders in a file system.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dataform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dataform/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dataform/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own folder"})

    		ubx.Resource(dataform.DataformFolder, "ci-runner", dataform.DataformFolderConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="containing_folder" type="string">
  Optional. The containing Folder resource name. This should take the format: projects/&#123;project&#125;/locations/&#123;location&#125;/folders/&#123;folder&#125;, projects/&#123;project&#125;/locations/&#123;location&#125;/teamFolders/&#123;teamFolder&#125;, or just "" if this is a root Folder. This field can only be updated through MoveFolder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp of when the Folder was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="creator_iam_principal" type="string">
  Output only. The IAM principal identifier of the creator of the Folder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The Folder's user-friendly name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="internal_metadata" type="string">
  Output only. All the metadata information that is used internally to serve the resource. For example: timestamps, flags, status fields, etc. The format of this field is a JSON string. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The Folder's name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="team_folder_name" type="string">
  Output only. The resource name of the TeamFolder that this Folder is associated with. This should take the format: projects/&#123;project&#125;/locations/&#123;location&#125;/teamFolders/&#123;teamFolder&#125;. If this is not set, the Folder is not associated with a TeamFolder and is a UserFolder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp of when the Folder was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

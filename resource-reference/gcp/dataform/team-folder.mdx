`google_dataform_team_folder` is a shared-drive-like Dataform folder designed for team collaboration on code assets, distinct from a personal folder scoped to a single user.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own team folder"})

    		ubx.Resource(dataform.TeamFolder, "example", dataform.TeamFolderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp of when the TeamFolder was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="creator_iam_principal" type="string">
  Output only. The IAM principal identifier of the creator of the TeamFolder. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The TeamFolder's user-friendly name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="internal_metadata" type="string">
  Output only. All the metadata information that is used internally to serve the resource. For example: timestamps, flags, status fields, etc. The format of this field is a JSON string. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The TeamFolder's name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp of when the TeamFolder was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

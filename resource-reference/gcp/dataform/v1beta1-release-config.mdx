<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dataform_release_config`.
</Warning>

`google_dataform_v1beta1_release_config` schedules Dataform to automatically compile a repository's own code from a specific Git reference on a recurring basis, producing a fresh compilation result ready for workflow execution.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 release config"})

    		ubx.Resource(dataform.V1beta1ReleaseConfig, "example", dataform.V1beta1ReleaseConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="release_compilation_result" type="string">
  Optional. The name of the currently released compilation result for this release config. This value is updated when a compilation result is automatically created from this release config (using cron_schedule), or when this resource is updated by API call (perhaps to roll back to an earlier release). The compilation result must have been created using this release config. Must be in the format `projects/*/locations/*/repositories/*/compilationResults/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

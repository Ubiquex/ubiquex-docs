<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dataform_compilation_result`.
</Warning>

`google_dataform_v1beta1_compilation_result` is the compiled output of a Dataform repository's own SQLX source code at a specific commit, resolving all references and configuration into the actual executable SQL graph a workflow invocation runs.

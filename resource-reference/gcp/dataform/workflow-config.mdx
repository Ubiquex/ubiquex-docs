---
title: "google_dataform_workflow_config"
description: "`google_dataform_workflow_config` schedules a Dataform workflow invocation to run automatically on a recurring basis against a specific compilation result."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workflow config"})

    		ubx.Resource(dataform.WorkflowConfig, "example", dataform.WorkflowConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp of when the WorkflowConfig was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="cron_schedule" type="string">
  Optional. Optional schedule (in cron format) for automatic execution of this workflow config. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Disables automatic creation of workflow invocations. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="internal_metadata" type="string">
  Output only. All the metadata information that is used internally to serve the resource. For example: timestamps, flags, status fields, etc. The format of this field is a JSON string. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="invocation_config" type="object">
  Includes various configuration options for a workflow invocation. If both `included_targets` and `included_tags` are unset, all actions will be included. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="fully_refresh_incremental_tables_enabled" type="bool">
      Optional. When set to true, any incremental tables will be fully refreshed. Optional.
    </ResponseField>
    <ResponseField name="included_tags" type="list(string)">
      Optional. The set of tags to include. Optional.
    </ResponseField>
    <ResponseField name="included_targets" type="list(object)">
      Optional. The set of action identifiers to include. Optional.
      <Expandable title="properties">
        <ResponseField name="database" type="string">
          The database (BigQuery project) this included target table belongs to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of this included target table. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="schema" type="string">
          The schema (BigQuery dataset) this included target table belongs to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="query_priority" type="string">
      Optional. Specifies the priority for query execution in BigQuery. More information can be found at https://cloud.google.com/bigquery/docs/running-queries#queries. Optional.
    </ResponseField>
    <ResponseField name="service_account" type="string">
      Optional. The service account to run workflow invocations under. Optional.
    </ResponseField>
    <ResponseField name="transitive_dependencies_included" type="bool">
      Optional. When set to true, transitive dependencies of included actions will be executed. Optional.
    </ResponseField>
    <ResponseField name="transitive_dependents_included" type="bool">
      Optional. When set to true, transitive dependents of included actions will be executed. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The workflow config's name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="recent_scheduled_execution_records" type="list(object)">
  Output only. Records of the 10 most recent scheduled execution attempts, ordered in descending order of `execution_time`. Updated whenever automatic creation of a workflow invocation is triggered by cron_schedule. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="error_status" type="object">
      The error this scheduled workflow execution failed with, if it didn't succeed. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
      <Expandable title="properties">
        <ResponseField name="code" type="number">
          The error's own numeric status code. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="details" type="list(map(any))">
          Additional structured detail about the error. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="message" type="string">
          A human-readable description of the error. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="execution_time" type="string">
      When this scheduled workflow execution occurred. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="workflow_invocation" type="string">
      The workflow invocation this scheduled execution produced. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="release_config" type="string">
  Required. The name of the release config whose release_compilation_result should be executed. Must be in the format `projects/*/locations/*/repositories/*/releaseConfigs/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="time_zone" type="string">
  Optional. Specifies the time zone to be used when interpreting cron_schedule. Must be a time zone name from the [time zone database](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones). If left unspecified, the default is `UTC`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp of when the WorkflowConfig was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

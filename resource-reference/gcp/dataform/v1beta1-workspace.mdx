`google_dataform_v1beta1_workspace` is a personal, uncommitted development workspace within a Dataform repository, where a developer edits SQLX code before pushing it to the shared Git history.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 workspace"})

    		ubx.Resource(dataform.V1beta1Workspace, "example", dataform.V1beta1WorkspaceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp of when the workspace was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="data_encryption_state" type="object">
  Describes encryption state of a resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_version_name" type="string">
      Required. The KMS key version name with which data of a resource is encrypted. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="depth" type="number">
  Optional. Input only. Immutable. The maximum depth of the Git repository to checkout for this workspace. If defined and greater than 0, the Git repository will be created as a shallow clone with the given depth, otherwise a full clone will be performed. This field is available only for GitHub, Gitlab and 1p repositories with enabled branch management. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disable_moves" type="bool">
  Optional. If set to true, workspaces will not be moved if its linked Repository is moved. Instead, it will be deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enable_branch_management" type="bool">
  Immutable. Controls the enablement of branch checkout for the workspace. When set to True, the workspace will be allowed to checkout branches. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="internal_metadata" type="string">
  Output only. All the metadata information that is used internally to serve the resource. For example: timestamps, flags, status fields, etc. The format of this field is a JSON string. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The workspace's name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="original_branch" type="string">
  Optional. Input only. Immutable. The name of the default upstream branch for all pull/push operations in the remote repository for this workspace. If empty, the HEAD branch from repository will be used. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="private_resource_metadata" type="object">
  Metadata used to identify if a resource is user scoped. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="user_scoped" type="bool">
      Output only. If true, this resource is user-scoped, meaning it is either a workspace or sourced from a workspace. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="shallow" type="bool">
  Output only. If set to true, the workspace was created as a shallow clone. Will be set to true if the depth field is set to a value greater than 0, otherwise it will be set to false. Optional; if omitted, computed by Google Cloud.
</ResponseField>

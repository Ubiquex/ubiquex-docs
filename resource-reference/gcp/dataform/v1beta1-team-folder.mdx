<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dataform_team_folder`.
</Warning>

`google_dataform_v1beta1_team_folder` is a shared-drive-like Dataform folder designed for team collaboration on code assets, distinct from a personal folder scoped to a single user.

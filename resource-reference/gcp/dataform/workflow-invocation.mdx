`google_dataform_workflow_invocation` is a single execution of a Dataform compilation result's own SQL graph, running the data transformation(s) it defines against the target data warehouse.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workflow invocation"})

    		ubx.Resource(dataform.WorkflowInvocation, "example", dataform.WorkflowInvocationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="compilation_result" type="string">
  Immutable. The name of the compilation result to use for this invocation. Must be in the format `projects/*/locations/*/repositories/*/compilationResults/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="data_encryption_state" type="object">
  Describes encryption state of a resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_version_name" type="string">
      Required. The KMS key version name with which data of a resource is encrypted. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="internal_metadata" type="string">
  Output only. All the metadata information that is used internally to serve the resource. For example: timestamps, flags, status fields, etc. The format of this field is a JSON string. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="invocation_config" type="object">
  Includes various configuration options for a workflow invocation. If both `included_targets` and `included_tags` are unset, all actions will be included. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="fully_refresh_incremental_tables_enabled" type="bool">
      Optional. When set to true, any incremental tables will be fully refreshed. Optional.
    </ResponseField>
    <ResponseField name="included_tags" type="list(string)">
      Optional. The set of tags to include. Optional.
    </ResponseField>
    <ResponseField name="included_targets" type="list(object)">
      Optional. The set of action identifiers to include. Optional.
      <Expandable title="properties">
        <ResponseField name="database" type="string">
          The database (BigQuery project) this included target table belongs to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The name of this included target table. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="schema" type="string">
          The schema (BigQuery dataset) this included target table belongs to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="query_priority" type="string">
      Optional. Specifies the priority for query execution in BigQuery. More information can be found at https://cloud.google.com/bigquery/docs/running-queries#queries. Optional.
    </ResponseField>
    <ResponseField name="service_account" type="string">
      Optional. The service account to run workflow invocations under. Optional.
    </ResponseField>
    <ResponseField name="transitive_dependencies_included" type="bool">
      Optional. When set to true, transitive dependencies of included actions will be executed. Optional.
    </ResponseField>
    <ResponseField name="transitive_dependents_included" type="bool">
      Optional. When set to true, transitive dependents of included actions will be executed. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="invocation_timing" type="object">
  Represents a time interval, encoded as a Timestamp start (inclusive) and a Timestamp end (exclusive). The start must be less than or equal to the end. When the start equals the end, the interval is empty (matches no time). When both start and end are unspecified, the interval matches any time. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="end_time" type="string">
      Optional. Exclusive end of the interval. If specified, a Timestamp matching this interval will have to be before the end. Optional.
    </ResponseField>
    <ResponseField name="start_time" type="string">
      Optional. Inclusive start of the interval. If specified, a Timestamp matching this interval will have to be the same or after the start. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The workflow invocation's name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pipeline_config" type="object">
  Defines the pipeline type and path within the Git repository. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="path" type="string">
      Required. The relative path within the Git repository where the pipeline is defined. For example, for a Dataform pipeline, it is a path to the folder where `workflow_settings.yaml` or `dataform.json` is located. Optional.
    </ResponseField>
    <ResponseField name="pipeline_type" type="string">
      Required. The type of the pipeline. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="private_resource_metadata" type="object">
  Metadata used to identify if a resource is user scoped. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="user_scoped" type="bool">
      Output only. If true, this resource is user-scoped, meaning it is either a workspace or sourced from a workspace. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resolved_compilation_result" type="string">
  Output only. The resolved compilation result that was used to create this invocation. Will be in the format `projects/*/locations/*/repositories/*/compilationResults/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. This workflow invocation's current state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="workflow_config" type="string">
  Immutable. The name of the workflow config to invoke. Must be in the format `projects/*/locations/*/repositories/*/workflowConfigs/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

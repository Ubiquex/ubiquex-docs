<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dataform_workflow_config`.
</Warning>

`google_dataform_v1beta1_workflow_config` schedules a Dataform workflow invocation to run automatically on a recurring basis against a specific compilation result.

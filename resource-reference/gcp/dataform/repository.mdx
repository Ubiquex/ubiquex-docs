`google_dataform_repository` is a single Git-backed Dataform repository containing one code asset -- typically a set of SQLX data transformation definitions, but also a notebook, saved query, or similar asset.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_dataform --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_dataform/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataform "github.com/ubiquex/ubx-sdk-google/sdk/go/google_dataform/dataform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own repository"})

    		ubx.Resource(dataform.DataformRepository, "example", dataform.DataformRepositoryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="containing_folder" type="string">
  Optional. The name of the containing folder of the repository. The field is immutable and it can be modified via a MoveRepository operation. Format: `projects/*/locations/*/folders/*`. or `projects/*/locations/*/teamFolders/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp of when the repository was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="git_remote_settings" type="object">
  Controls Git remote configuration for a repository. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

    </ResponseField>
    <ResponseField name="default_branch" type="string">
      Optional. The Git remote's default branch name. If not set, `main` will be used. Optional.

    <ResponseField name="effective_default_branch" type="string">
      Output only. The Git remote's effective default branch name. This is the default branch name of the Git remote if it is set, otherwise it is `main`. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="git_repository_link" type="string">
      Optional. Resource name for the `GitRepositoryLink` used for machine credentials. Must be in the format `projects/*/locations/*/connections/*/gitRepositoryLinks/*` Optional.

      Configures fields for performing SSH authentication. Optional.

          Required. Content of a public SSH key to verify an identity of a remote Git host. Optional.

        <ResponseField name="user_private_key_secret_version" type="string">
          Required. The name of the Secret Manager secret version to use as a ssh private key for Git operations. Must be in the format `projects/*/secrets/*/versions/*`. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>

  </Expandable>

<ResponseField name="team_folder_name" type="string">

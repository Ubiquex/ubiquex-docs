title: "google_storagebatchoperations_job"
description: "`google_storagebatchoperations_job` runs a single bulk metadata or storage-class change operation across many Cloud Storage objects at once..."
---

`google_storagebatchoperations_job` runs a single bulk metadata or storage-class change operation across many Cloud Storage objects at once, rather than making individual per-object API calls.

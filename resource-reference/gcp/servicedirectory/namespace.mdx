`google_servicedirectory_namespace` is a container grouping related service(s) together within Service Directory, Google Cloud's own managed service registry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicedirectory "github.com/ubiquex/ubx-sdk-google/sdk/go/google/servicedirectory"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own namespace"})

    		ubx.Resource(servicedirectory.Namespace, "example", servicedirectory.NamespaceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels associated with this namespace. No more than 64 user labels can be associated with a given resource. Label keys and values can be no longer than 63 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name for the namespace in the format `projects/*/locations/*/namespaces/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The globally unique identifier of the namespace in the UUID4 format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

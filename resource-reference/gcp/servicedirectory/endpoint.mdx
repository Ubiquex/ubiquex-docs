## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicedirectory "github.com/ubiquex/ubx-sdk-google/sdk/go/google/servicedirectory"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own endpoint"})

    		ubx.Resource(servicedirectory.Endpoint, "example", servicedirectory.EndpointConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="address" type="string">
  Optional. An IPv4 or IPv6 address. Service Directory rejects bad addresses like: * `8.8.8` * `8.8.8.8:53` * `test:bad:address` * `[::1]` * `[::1]:8080` Limited to 45 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="annotations" type="map(string)">
  Optional. Annotations for the endpoint. This data can be consumed by service clients. Restrictions: * The entire annotations dictionary may contain up to 512 characters, spread accoss all key-value pairs. Annotations that go beyond this limit are rejected * Valid annotation keys have two segments: an optional prefix and name, separated by a slash (/). The name segment is required and must be 63 characters or less, beginning and ending with an alphanumeric character ([a-z0-9A-Z]) with dashes (-), underscores (_), dots (.), and alphanumerics between. The prefix is optional. If specified, the prefix must be a DNS subdomain: a series of DNS labels separated by dots (.), not longer than 253 characters in total, followed by a slash (/) Annotations that fails to meet these requirements are rejected. Note: This field is equivalent to the `metadata` field in the v1beta1 API. They have the same syntax and read/write to the same location in Service Directory. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name for the endpoint in the format `projects/*/locations/*/namespaces/*/services/*/endpoints/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Immutable. The Google Compute Engine network (VPC) of the endpoint in the format `projects//locations/global/networks/*`. The project must be specified by project number (project id is rejected). Incorrectly formatted networks are rejected, we also check to make sure that you have the servicedirectory.networks.attach permission on the project specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="port" type="number">
  Optional. Service Directory rejects values outside of `[0, 65535]`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The globally unique identifier of the endpoint in the UUID4 format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

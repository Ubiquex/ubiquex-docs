`google_servicedirectory_v1beta1_service` registers a logical service within Service Directory, that endpoint(s) advertising where it's actually reachable are attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicedirectory "github.com/ubiquex/ubx-sdk-google/sdk/go/google/servicedirectory"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 service"})

    		ubx.Resource(servicedirectory.V1beta1Service, "example", servicedirectory.V1beta1ServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="metadata" type="map(string)">
  Optional. Metadata for the service. This data can be consumed by service clients. Restrictions: * The entire metadata dictionary may contain up to 2000 characters, spread accoss all key-value pairs. Metadata that goes beyond this limit are rejected * Valid metadata keys have two segments: an optional prefix and name, separated by a slash (/). The name segment is required and must be 63 characters or less, beginning and ending with an alphanumeric character ([a-z0-9A-Z]) with dashes (-), underscores (_), dots (.), and alphanumerics between. The prefix is optional. If specified, the prefix must be a DNS subdomain: a series of DNS labels separated by dots (.), not longer than 253 characters in total, followed by a slash (/). Metadata that fails to meet these requirements are rejected Note: This field is equivalent to the `annotations` field in the v1 API. They have the same syntax and read/write to the same location in Service Directory. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name for the service in the format `projects/*/locations/*/namespaces/*/services/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. A globally unique identifier (in UUID4 format) for this service. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the service was last updated. Note: endpoints being created/deleted/updated within the service are not considered service updates for the purpose of this timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

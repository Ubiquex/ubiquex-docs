`google_servicedirectory_v1beta1_namespace` is a container grouping related service(s) together within Service Directory, Google Cloud's own managed service registry.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	servicedirectory "github.com/ubiquex/ubx-sdk-google/sdk/go/google/servicedirectory"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 namespace"})

    		ubx.Resource(servicedirectory.V1beta1Namespace, "example", servicedirectory.V1beta1NamespaceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the namespace was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels associated with this namespace. No more than 64 user labels can be associated with a given resource. Label keys and values can be no longer than 63 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name for the namespace in the format `projects/*/locations/*/namespaces/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. A globally unique identifier (in UUID4 format) for this namespace. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the namespace was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

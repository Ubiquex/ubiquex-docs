`google_dlp_connection` registers credentials Sensitive Data Protection uses to connect to and scan an external or non-native data source (e.g. a JDBC database) for sensitive data discovery.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dlp "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dlp"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own connection"})

    		ubx.Resource(dlp.Connection, "example", dlp.ConnectionConfig{
    			Connection: map[string]any{"name": "example-name"},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {

      resource(Connection, "example", {

    ```
  </Tab>
  <Tab title="Python">

## Input properties

<ResponseField name="connection" type="object">
  A data connection to allow the DLP API to profile data in locations that require additional configuration. Optional.
  <Expandable title="properties">
    <ResponseField name="cloud_sql" type="object">
      Cloud SQL connection properties. Optional.
      <Expandable title="properties">
        <ResponseField name="cloud_sql_iam" type="any">
          Use IAM authentication to connect. This requires the Cloud SQL IAM feature to be enabled on the instance, which is not the default for Cloud SQL. See https://docs.cloud.google.com/sql/docs/postgres/authentication and https://docs.cloud.google.com/sql/docs/mysql/authentication. Optional.
        </ResponseField>
        <ResponseField name="connection_name" type="string">
          Optional. Immutable. The Cloud SQL instance for which the connection is defined. Only one connection per instance is allowed. This can only be set at creation time, and cannot be updated. It is an error to use a connection_name from different project or region than the one that holds the connection. For example, a Connection resource for Cloud SQL connection_name `project-id:us-central1:sql-instance` must be created under the parent `projects/project-id/locations/us-central1` Optional.
        </ResponseField>
        <ResponseField name="database_engine" type="string">
          Required. The database engine used by the Cloud SQL instance that this connection configures. Optional.
        </ResponseField>
        <ResponseField name="max_connections" type="number">
          Required. The DLP API will limit its connections to max_connections. Must be 2 or greater. Optional.
        </ResponseField>
        <ResponseField name="username_password" type="object">
          A credential consisting of a username and password, where the password is stored in a Secret Manager resource. Note: Secret Manager [charges apply](https://cloud.google.com/secret-manager/pricing). Optional.
          <Expandable title="properties">
            <ResponseField name="password_secret_version_name" type="string">
              Required. The name of the Secret Manager resource that stores the password, in the form `projects/project-id/secrets/secret-name/versions/version`. Optional.
            </ResponseField>
            <ResponseField name="username" type="string">
              Required. The username. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="errors" type="list(object)">
      Output only. Set if status == ERROR, to provide additional details. Will store the last 10 errors sorted with the most recent first. Computed by Google Cloud after `ship`.
      <Expandable title="properties">
        <ResponseField name="details" type="object">
          Additional detail explaining this result. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="code" type="number">
              A machine-readable code identifying this result or error. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="details" type="list(map(any))">
              Additional detail explaining this result. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="message" type="string">
              A human-readable description of this result or error. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="extra_info" type="string">
          Additional detail about this event. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="timestamps" type="list(string)">
          The timestamp(s) recorded for this event. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="name" type="string">
      Output only. Name of the connection: `projects/&#123;project&#125;/locations/&#123;location&#125;/connections/&#123;name&#125;`. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="state" type="string">
      Required. The connection's state in its lifecycle. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_monitoring_uptime_check_config` configures Cloud Monitoring to periodically probe an HTTP, HTTPS, or TCP endpoint from multiple global locations, reporting the results as uptime and latency data.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	monitoring "github.com/ubiquex/ubx-sdk-google/sdk/go/google/monitoring"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own uptime check config"})

    		ubx.Resource(monitoring.UptimeCheckConfig, "example", monitoring.UptimeCheckConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_monitoring_service` represents a logical service (e.g. one microservice or app) within Cloud Monitoring, the entity a service level objective is defined and measured against.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_monitoring --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_monitoring/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	monitoring "github.com/ubiquex/ubx-sdk-google/sdk/go/google_monitoring/monitoring"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own service"})

    		ubx.Resource(monitoring.MonitoringService, "example", monitoring.MonitoringServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

`google_monitoring_group` is a saved, dynamic grouping of monitored resources (e.g. all VMs matching a name pattern) that Cloud Monitoring dashboards and alerts can be scoped to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_monitoring --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_monitoring/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	monitoring "github.com/ubiquex/ubx-sdk-google/sdk/go/google_monitoring/monitoring"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own group"})

    		ubx.Resource(monitoring.MonitoringGroup, "example", monitoring.MonitoringGroupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="display_name" type="string">
  A user-assigned name for this group, used only for display purposes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="filter" type="string">
  The filter used to determine which monitored resources belong to this group. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_cluster" type="bool">
  If true, the members of this group are considered to be a cluster. The system can perform additional analysis on groups that are clusters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of this group. The format is: projects/[PROJECT_ID_OR_NUMBER]/groups/[GROUP_ID] When creating a group, this field is ignored and a new name is created consisting of the project specified in the call to CreateGroup and a unique [GROUP_ID] that is generated automatically. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent_name" type="string">
  The name of the group's parent, if it has one. The format is: projects/[PROJECT_ID_OR_NUMBER]/groups/[GROUP_ID] For groups with no parent, parent_name is the empty string, "". Optional; if omitted, computed by Google Cloud.
</ResponseField>

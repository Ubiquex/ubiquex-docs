<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_datacatalog_entry_group`.

`google_datacatalog_v1beta1_entry_group` is a logical container of related entries within Data Catalog, typically grouping entries that share the same source system.

Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. `google_datacatalog_v1beta1_taxonomy` is a hierarchical classification scheme (a tree of policy tag nodes) Data Catalog uses to tag data with sensitivity or business categories for governance.

## Properties

<ResponseField name="activated_policy_types" type="list(string)">
  Optional. A list of policy types that are activated for this taxonomy. If not set, defaults to an empty list. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of this taxonomy. It must: contain only unicode characters, tabs, newlines, carriage returns and page breaks; and be at most 2000 bytes long when encoded in UTF-8. If not set, defaults to an empty description. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. User defined name of this taxonomy. It must: contain only unicode letters, numbers, underscores, dashes and spaces; not start or end with spaces; and be at most 200 bytes long when encoded in UTF-8. The taxonomy display name must be unique within an organization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of this taxonomy, whose format is: "projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/taxonomies/&#123;id&#125;". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="policy_tag_count" type="number">
  Output only. Number of policy tags contained in this taxonomy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service" type="object">
  The source system of the Taxonomy. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="identity" type="string">
      The service agent for the service. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      The Google Cloud service name. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="taxonomy_timestamps" type="object">
  Timestamps about this resource according to a particular system. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

    <ResponseField name="expire_time" type="string">

    </ResponseField>
    <ResponseField name="update_time" type="string">
      The last-modified time of the resource within the given system. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_datacatalog_tag_template` defines the schema (field names and types) for a reusable kind of tag that can be attached to Data Catalog entries, e.g. a `data_governance` tag with an `owner` field.

## Example

    	ubx.Main(ubx.Stack("payments", func() {

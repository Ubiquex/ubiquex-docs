`google_datacatalog_v1beta1_policy_tag` defines a data classification node within a Data Catalog policy tag taxonomy, used to enforce BigQuery column-level access control based on sensitivity.

## Properties

<ResponseField name="child_policy_tags" type="list(string)">
  Output only. Resource names of child policy tags of this policy tag. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of this policy tag. It must: contain only unicode characters, tabs, newlines, carriage returns and page breaks; and be at most 2000 bytes long when encoded in UTF-8. If not set, defaults to an empty description. If not set, defaults to an empty description. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. User defined name of this policy tag. It must: be unique within the parent taxonomy; contain only unicode letters, numbers, underscores, dashes and spaces; not start or end with spaces; and be at most 200 bytes long when encoded in UTF-8. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of this policy tag, whose format is: "projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/taxonomies/&#123;taxonomy_id&#125;/policyTags/&#123;id&#125;". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent_policy_tag" type="string">
  Resource name of this policy tag's parent policy tag (e.g. for the "LatLong" policy tag in the example above, this field contains the resource name of the "Geolocation" policy tag). If empty, it means this policy tag is a top level policy tag (e.g. this field is empty for the "Geolocation" policy tag in the example above). If not set, defaults to an empty string. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_datacatalog_entry`.
</Warning>

`google_datacatalog_v1beta1_entry` is a single cataloged item in Data Catalog -- a table, file set, or other real or logical asset -- carrying its own searchable metadata and tag(s).

## Example

<ResponseField name="user_specified_type" type="string">
  Entry type if it does not fit any of the input-allowed values listed in `EntryType` enum above. When creating an entry, users should check the enum values first, if nothing matches the entry to be created, then provide a custom value, for example "my_special_type". `user_specified_type` strings must begin with a letter or underscore and can only contain letters, numbers, and underscores; are case insensitive; must be at least 1 character and at most 64 characters long. Currently, only FILESET enum value is allowed. All other entries created through Data Catalog must use `user_specified_type`. Optional; if omitted, computed by Google Cloud.

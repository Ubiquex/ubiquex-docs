`google_datacatalog_policy_tag` defines a data classification node within a Data Catalog policy tag taxonomy, used to enforce BigQuery column-level access control based on sensitivity.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datacatalog "github.com/ubiquex/ubx-sdk-google/sdk/go/google/datacatalog"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own policy tag"})

    		ubx.Resource(datacatalog.PolicyTag, "example", datacatalog.PolicyTagConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="child_policy_tags" type="list(string)">
  Output only. Resource names of child policy tags of this policy tag. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Description of this policy tag. If not set, defaults to empty. The description must contain only Unicode characters, tabs, newlines, carriage returns and page breaks, and be at most 2000 bytes long when encoded in UTF-8. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. User-defined name of this policy tag. The name can't start or end with spaces and must be unique within the parent taxonomy, contain only Unicode letters, numbers, underscores, dashes and spaces, and be at most 200 bytes long when encoded in UTF-8. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of this policy tag in the URL format. The policy tag manager generates unique taxonomy IDs and policy tag IDs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent_policy_tag" type="string">
  Resource name of this policy tag's parent policy tag. If empty, this is a top level tag. If not set, defaults to an empty string. For example, for the "LatLong" policy tag in the example above, this field contains the resource name of the "Geolocation" policy tag, and, for "Geolocation", this field is empty. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_datacatalog_taxonomy` is a hierarchical classification scheme (a tree of policy tag nodes) Data Catalog uses to tag data with sensitivity or business categories for governance.

## Example

  <Tab title="Go">
    ```go

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_datacatalog/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datacatalog "github.com/ubiquex/ubx-sdk-google/sdk/go/google_datacatalog/datacatalog"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own taxonomy"})
    ```

## Properties

<ResponseField name="activated_policy_types" type="list(string)">
  Optional. A list of policy types that are activated for this taxonomy. If not set, defaults to an empty list. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of this taxonomy. If not set, defaults to empty. The description must contain only Unicode characters, tabs, newlines, carriage returns, and page breaks, and be at most 2000 bytes long when encoded in UTF-8. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. User-defined name of this taxonomy. The name can't start or end with spaces, must contain only Unicode letters, numbers, underscores, dashes, and spaces, and be at most 200 bytes long when encoded in UTF-8. The taxonomy display name must be unique within an organization. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name of this taxonomy in URL format. Note: Policy tag manager generates unique taxonomy IDs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="policy_tag_count" type="number">
  Output only. Number of policy tags in this taxonomy. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service" type="object">
  The source system of the Taxonomy. Optional; if omitted, computed by Google Cloud.

  </Expandable>
</ResponseField>

`google_managedidentities_peering` peers a Managed Microsoft AD domain's own VPC network with another VPC network, extending domain connectivity to resources there.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_managedidentities --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_managedidentities/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedidentities "github.com/ubiquex/ubx-sdk-google/sdk/go/google_managedidentities/managedidentities"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own peering"})

    		ubx.Resource(managedidentities.ManagedidentitiesPeering, "example", managedidentities.ManagedidentitiesPeeringConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="authorized_network" type="string">
  Required. The full names of the Google Compute Engine [networks](https://cloud.google.com/compute/docs/networks-and-firewalls#networks) to which the instance is connected. Caller needs to make sure that CIDR subnets do not overlap between networks, else peering creation will fail. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the instance was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="domain_resource" type="string">
  Required. Full domain resource path for the Managed AD Domain involved in peering. The resource path should be in the form: `projects/&#123;project_id&#125;/locations/global/domains/&#123;domain_name&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels to represent user-provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Unique name of the peering in this scope including projects and location using the form: `projects/&#123;project_id&#125;/locations/global/peerings/&#123;peering_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of this Peering. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status_message" type="string">
  Output only. Additional information about the current status of this peering, if available. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last update time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

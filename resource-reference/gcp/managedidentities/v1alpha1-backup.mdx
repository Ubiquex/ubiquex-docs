## Properties

<ResponseField name="create_time" type="string">
  Output only. The time the backups was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A short description of the backup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels to represent user provided metadata. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The unique name of the Backup in the form of projects/&#123;project_id&#125;/locations/global/domains/&#123;domain_name&#125;/backups/&#123;name&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the backup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status_message" type="string">
  Output only. Additional information about the current status of this backup, if available. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Output only. Indicates whether it’s an on-demand backup or scheduled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last update time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

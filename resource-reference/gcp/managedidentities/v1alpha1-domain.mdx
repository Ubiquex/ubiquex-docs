`google_managedidentities_v1alpha1_domain` provisions a fully managed Microsoft Active Directory domain through Managed Microsoft AD, without the caller having to run domain controllers themselves.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	managedidentities "github.com/ubiquex/ubx-sdk-google/sdk/go/google/managedidentities"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha1 domain"})

    		ubx.Resource(managedidentities.V1alpha1Domain, "example", managedidentities.V1alpha1DomainConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="audit_logs_enabled" type="bool">
  Optional. Configuration for audit logs. True if audit logs are enabled, else false. Default is audit logs disabled. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="authorized_networks" type="list(string)">
  Optional. The full names of the Google Compute Engine [networks](/compute/docs/networks-and-firewalls#networks) to which the instance is connected. Network can be added using UpdateDomain later. Domain is only available on network part of authorized_networks. Caller needs to make sure that CIDR subnets do not overlap between networks, else domain creation will fail. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the instance was created. Synthetic field is populated automatically by CCFE. go/ccfe-synthetic-field-user-guide Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fqdn" type="string">
  Output only. Fully-qualified domain name of the exposed domain used by clients to connect to the service. Similar to what would be chosen for an Active Directory that is set up on an internal network. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels to represent user provided metadata Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="locations" type="list(string)">
  Required. Locations where domain needs to be provisioned. regions e.g. us-west1 or us-east4 Service supports up to 4 locations at once. Each location will use a /26 block. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="managed_identities_admin_name" type="string">
  Optional. Name of customer-visible admin used to perform Active Directory operations. If not specified `setupadmin` would be used. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Unique name of the domain in this scope including projects and location using the form: `projects/&#123;project_id&#125;/locations/global/domains/&#123;domain_name&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reserved_ip_range" type="string">
  Required. The CIDR range of internal addresses that are reserved for this domain. Reserved networks must be /24 or larger. Ranges must be unique and non-overlapping with existing subnets in [Domain].[authorized_networks]. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of this domain. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status_message" type="string">
  Output only. Additional information about the current status of this domain, if available. Optional; if omitted, computed by Google Cloud.
</ResponseField>

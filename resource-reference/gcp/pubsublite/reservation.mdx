`google_pubsublite_reservation` purchases a fixed pool of Pub/Sub Lite throughput capacity that topic(s) draw from, for predictable, capacity-based pricing.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_pubsublite --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_pubsublite/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	pubsublite "github.com/ubiquex/ubx-sdk-google/sdk/go/google_pubsublite/pubsublite"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own reservation"})

    		ubx.Resource(pubsublite.PubsubliteReservation, "example", pubsublite.PubsubliteReservationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="name" type="string">
  The name of the reservation. Structured like: projects/&#123;project_number&#125;/locations/&#123;location&#125;/reservations/&#123;reservation_id&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="throughput_capacity" type="string">
  The reserved throughput capacity. Every unit of throughput capacity is equivalent to 1 MiB/s of published messages or 2 MiB/s of subscribed messages. Any topics which are declared as using capacity from a Reservation will consume resources from this reservation instead of being charged individually. Optional; if omitted, computed by Google Cloud.
</ResponseField>

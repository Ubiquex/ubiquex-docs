`google_pubsublite_subscription` attaches to a Pub/Sub Lite topic and delivers its own published messages to a consumer, tracking read position per partition.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_pubsublite --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_pubsublite/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	pubsublite "github.com/ubiquex/ubx-sdk-google/sdk/go/google_pubsublite/pubsublite"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own subscription"})

    		ubx.Resource(pubsublite.PubsubliteSubscription, "ci-runner", pubsublite.PubsubliteSubscriptionConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

<ResponseField name="export_config" type="object">
  Configuration for a Pub/Sub Lite subscription that writes messages to a destination. User subscriber clients must not connect to this subscription. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="current_state" type="string">
      Output only. The current state of the export, which may be different to the desired state due to errors. This field is output only. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="dead_letter_topic" type="string">
      Optional. The name of an optional Pub/Sub Lite topic to publish messages that can not be exported to the destination. For example, the message can not be published to the Pub/Sub service because it does not satisfy the constraints documented at https://cloud.google.com/pubsub/docs/publisher. Structured like: projects/&#123;project_number&#125;/locations/&#123;location&#125;/topics/&#123;topic_id&#125;. Must be within the same project and location as the subscription. The topic may be changed or removed. Optional.
    </ResponseField>
    <ResponseField name="desired_state" type="string">
      The desired state of this export. Setting this to values other than `ACTIVE` and `PAUSED` will result in an error. Optional.
    </ResponseField>
    <ResponseField name="pubsub_config" type="object">
      Configuration for exporting to a Pub/Sub topic. Optional.
      <Expandable title="properties">
        <ResponseField name="topic" type="string">
          The name of the Pub/Sub topic. Structured like: projects/&#123;project_number&#125;/topics/&#123;topic_id&#125;. The topic may be changed. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

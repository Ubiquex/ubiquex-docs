<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_websecurityscanner_scan_config`.
</Warning>

`google_websecurityscanner_v1beta_scan_config` is a Web Security Scanner scan configuration, real config specifying the starting URL, authentication method, excluded URL patterns, and Security Command Center export settings a vulnerability scan runs against.

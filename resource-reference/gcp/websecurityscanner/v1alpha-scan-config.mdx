<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_websecurityscanner_scan_config`.
</Warning>

`google_websecurityscanner_v1alpha_scan_config` is a Web Security Scanner scan configuration, real config specifying the starting URL, authentication method, excluded URL patterns, and Security Command Center export settings a vulnerability scan runs against.

## Properties

<ResponseField name="authentication" type="object">
  Scan authentication configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="custom_account" type="object">
      Describes authentication configuration that uses a custom account. Optional.
      <Expandable title="properties">
        <ResponseField name="login_url" type="string">
          Required. The login form URL of the website. Optional.
        </ResponseField>
        <ResponseField name="password" type="string">
          Required. Input only. The password of the custom account. The credential is stored encrypted and not returned in any response nor included in audit logs. Optional.
        </ResponseField>
        <ResponseField name="username" type="string">
          Required. The user name of the custom account. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="google_account" type="object">
      Describes authentication configuration that uses a Google account. Optional.
      <Expandable title="properties">
        <ResponseField name="password" type="string">
          Required. Input only. The password of the Google account. The credential is stored encrypted and not returned in any response nor included in audit logs. Optional.
        </ResponseField>
        <ResponseField name="username" type="string">
          Required. The user name of the Google account. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="blacklist_patterns" type="list(string)">
  The excluded URL patterns as described in https://cloud.google.com/security-command-center/docs/how-to-use-web-security-scanner#excluding_urls Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The user provided display name of the ScanConfig. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="latest_run" type="object">
  A ScanRun is a output-only resource representing an actual run of the scan. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="end_time" type="string">
      The time at which the ScanRun reached termination state - that the ScanRun is either finished or stopped by user. Optional.
    </ResponseField>
    <ResponseField name="execution_state" type="string">
      The execution state of the ScanRun. Optional.
    </ResponseField>
    <ResponseField name="has_vulnerabilities" type="bool">
      Whether the scan run has found any vulnerabilities. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      The resource name of the ScanRun. The name follows the format of 'projects/&#123;projectId&#125;/scanConfigs/&#123;scanConfigId&#125;/scanRuns/&#123;scanRunId&#125;'. The ScanRun IDs are generated by the system. Optional.
    </ResponseField>
    <ResponseField name="progress_percent" type="number">
      The percentage of total completion ranging from 0 to 100. If the scan is in queue, the value is 0. If the scan is running, the value ranges from 0 to 100. If the scan is finished, the value is 100. Optional.
    </ResponseField>
    <ResponseField name="result_state" type="string">
      The result state of the ScanRun. This field is only available after the execution state reaches "FINISHED". Optional.
    </ResponseField>
    <ResponseField name="start_time" type="string">
      The time at which the ScanRun started. Optional.
    </ResponseField>
    <ResponseField name="urls_crawled_count" type="string">
      The number of URLs crawled during this ScanRun. If the scan is in progress, the value represents the number of URLs crawled up to now. Optional.
    </ResponseField>
    <ResponseField name="urls_tested_count" type="string">
      The number of URLs tested during this ScanRun. If the scan is in progress, the value represents the number of URLs tested up to now. The number of URLs tested is usually larger than the number URLS crawled because typically a crawled URL is tested with multiple test payloads. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="max_qps" type="number">
  The maximum QPS during scanning. A valid value ranges from 5 to 20 inclusively. If the field is unspecified or its value is set 0, server will default to 15. Other values outside of [5, 20] range will be rejected with INVALID_ARGUMENT error. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name of the ScanConfig. The name follows the format of 'projects/&#123;projectId&#125;/scanConfigs/&#123;scanConfigId&#125;'. The ScanConfig IDs are generated by the system. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="schedule" type="object">
  Scan schedule configuration. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="interval_duration_days" type="number">
      Required. The duration of time between executions in days. Optional.
    </ResponseField>
    <ResponseField name="schedule_time" type="string">
      A timestamp indicates when the next run will be scheduled. The value is refreshed by the server after each run. If unspecified, it will default to current server time, which means the scan will be scheduled to start immediately. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="starting_urls" type="list(string)">
  Required. The starting URLs from which the scanner finds site pages. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="target_platforms" type="list(string)">
  Set of Google Cloud platforms targeted by the scan. If empty, APP_ENGINE will be used as a default. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="user_agent" type="string">
  The user agent used during scanning. Optional; if omitted, computed by Google Cloud.
</ResponseField>

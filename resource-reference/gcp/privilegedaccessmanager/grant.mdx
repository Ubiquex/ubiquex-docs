`google_privilegedaccessmanager_grant` is a single, time-bound activation of a Privileged Access Manager entitlement, giving a principal the underlying access for a limited window after approval.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	privilegedaccessmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/privilegedaccessmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own grant"})

    		ubx.Resource(privilegedaccessmanager.Grant, "example", privilegedaccessmanager.GrantConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="externally_modified" type="bool">
  Output only. Flag set by the PAM system to indicate that policy bindings made by this grant have been modified from outside PAM. After it is set, this flag remains set forever irrespective of the grant state. A `true` value here indicates that PAM no longer has any certainty on the access a user has because of this grant. Optional; if omitted, computed by Google Cloud.
</ResponseField>

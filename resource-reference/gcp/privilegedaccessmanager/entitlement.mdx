`google_privilegedaccessmanager_entitlement` defines a role or permission grant that eligible principal(s) can request temporary, approval-gated access to through Privileged Access Manager, instead of holding it permanently.

  <Expandable title="properties">
    <ResponseField name="manual_approvals" type="object">
      A manual approval workflow where users who are designated as approvers need to call the `ApproveGrant`/`DenyGrant` APIs for a grant. The workflow can consist of multiple serial steps where each step defines who can act as approver in that step and how many of those users should approve before the workflow moves to the next step. This can be used to create approval workflows such as: * Require an approval from any user in a group G. * Require an approval from any k number of users from a Group G. * Require an approval from any user in a group G and then from a user U. A single user might be part of the `approvers` ACL for multiple steps in this workflow, but they can only approve once and that approval is only considered to satisfy the approval step at which it was granted. Optional.

<ResponseField name="etag" type="string">
  An `etag` is used for optimistic concurrency control as a way to prevent simultaneous updates to the same entitlement. An `etag` is returned in the response to `GetEntitlement` and the caller should put the `etag` in the request to `UpdateEntitlement` so that their change is applied on the same version. If this field is omitted or if there is a mismatch while updating an entitlement, then the server rejects the request. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="max_request_duration" type="string">
  Required. The maximum amount of time that access is granted for a request. A requester can ask for a shorter duration but never a longer one. The supported range is between 30 minutes and 168 hours (7 days). Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_apphub_v1alpha_service` registers an underlying Google Cloud resource (e.g. a load balancer) as a discoverable network-facing service within an App Hub application.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apphub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apphub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha service"})

    		ubx.Resource(apphub.V1alphaService, "example", apphub.V1alphaServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

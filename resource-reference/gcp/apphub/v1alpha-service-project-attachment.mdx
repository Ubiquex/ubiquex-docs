  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_apphub_service_project_attachment`.

`google_apphub_v1alpha_service_project_attachment` attaches a Google Cloud project as a source of discoverable service(s) and workload(s) that App Hub can register into an application.

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of a ServiceProjectAttachment. Format: `"projects/&#123;host-project-id&#125;/locations/global/serviceProjectAttachments/&#123;service-project-id&#125;."` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_project" type="string">
  Required. Immutable. Service project name in the format: `"projects/abc"` or `"projects/123"`. As input, project name with either project id or number are accepted. As output, this field will contain project number. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. ServiceProjectAttachment state. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. A globally unique identifier (in UUID4 format) for the `ServiceProjectAttachment`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

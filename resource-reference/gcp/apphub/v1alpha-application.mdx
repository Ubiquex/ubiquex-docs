<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_apphub_application`.
</Warning>

`google_apphub_v1alpha_application` groups related service(s) and workload(s) together under a single logical application in App Hub, letting them be reasoned about and managed as one unit rather than individually.

## Example

    package main

    import (

    	apphub "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apphub_v1alpha/apphub"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha application"})

    		ubx.Resource(apphub.V1alphaApphubV1alphaApplication, "example", apphub.V1alphaApphubV1alphaApplicationConfig{

    		})
    	}))
    }

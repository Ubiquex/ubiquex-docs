<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_apphub_workload`.
</Warning>

`google_apphub_v1alpha_workload` registers an underlying Google Cloud resource (e.g. a GKE deployment or Compute Engine instance group) as a discoverable compute workload within an App Hub application.

## Example

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1alpha workload"})

    		})
    	}))
    }

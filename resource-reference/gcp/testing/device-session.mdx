`google_testing_device_session` is a real Firebase Test Lab device session, an interactive connection to a physical or virtual test device used for exploratory, hands-on testing rather than an automated instrumentation or Robo test run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	testing "github.com/ubiquex/ubx-sdk-google/sdk/go/google/testing"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own device session"})

    		ubx.Resource(testing.DeviceSession, "example", testing.DeviceSessionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="active_start_time" type="string">
  Output only. The timestamp that the session first became ACTIVE. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="android_device" type="object">
  A single Android device. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="android_model_id" type="string">
      Required. The id of the Android device to be used. Use the TestEnvironmentDiscoveryService to get supported options. Optional.
    </ResponseField>
    <ResponseField name="android_version_id" type="string">
      Required. The id of the Android OS version to be used. Use the TestEnvironmentDiscoveryService to get supported options. Optional.
    </ResponseField>
    <ResponseField name="locale" type="string">
      Required. The locale the test device used for testing. Use the TestEnvironmentDiscoveryService to get supported options. Optional.
    </ResponseField>
    <ResponseField name="orientation" type="string">
      Required. How the device is oriented during the test. Use the TestEnvironmentDiscoveryService to get supported options. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time that the Session was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Output only. The title of the DeviceSession to be presented in the UI. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Optional. If the device is still in use at this time, any connections will be ended and the SessionState will transition from ACTIVE to FINISHED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="inactivity_timeout" type="string">
  Output only. The interval of time that this device must be interacted with before it transitions from ACTIVE to TIMEOUT_INACTIVITY. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Optional. Name of the DeviceSession, e.g. "projects/&#123;project_id&#125;/deviceSessions/&#123;session_id&#125;" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Current state of the DeviceSession. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_histories" type="list(object)">
  Output only. The historical state transitions of the session_state message including the current session state. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="event_time" type="string">
      The real timestamp when this device session or test execution entered its own current state. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="session_state" type="string">
      The real, current lifecycle state (e.g. `ACTIVE`, `EXPIRED`, `FINISHED`) of this device session. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="state_message" type="string">
      Real, additional detail explaining this device session's or test execution's own current state. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ttl" type="string">
  Optional. The amount of time that a device will be initially allocated for. This can eventually be extended with the UpdateDeviceSession RPC. Default: 15 minutes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

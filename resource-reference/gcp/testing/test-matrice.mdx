`google_testing_test_matrice` is a Firebase Test Lab test matrix, a real test run executed against every combination of the device dimensions (model, OS version, locale, orientation) specified for it, covering instrumentation, Robo, and Game Loop test types alike.

To guarantee at least one test case for each shard, the number of shards will not exceed the number of test cases.

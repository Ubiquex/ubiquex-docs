`google_datamigration_mapping_rule` customizes how a specific source database object is converted within a conversion workspace, overriding the default mapping.

## Example

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own mapping rule"})

    		ubx.Resource(datamigration.MappingRule, "example", datamigration.MappingRuleConfig{

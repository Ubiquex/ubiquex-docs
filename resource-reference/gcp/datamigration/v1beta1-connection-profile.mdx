`google_datamigration_v1beta1_connection_profile` stores the connection detail (host, credentials, network path) Database Migration Service uses to reach a source or destination database.

<ResponseField name="mysql" type="object">
  Specifies connection parameters required specifically for MySQL databases. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

      If the source is a Cloud SQL database, use this field to provide the Cloud SQL instance ID of the source. Optional.
    </ResponseField>
    <ResponseField name="host" type="string">
      Required. The IP or hostname of the source MySQL database. Optional.
    </ResponseField>
    <ResponseField name="password" type="string">
      Required. Input only. The password for the user that Database Migration Service will be using to connect to the database. This field is not returned on request, and the value is encrypted when stored in Database Migration Service. Optional.
    </ResponseField>
    <ResponseField name="password_set" type="bool">
      Output only. Indicates If this connection profile password is stored. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="port" type="number">
      Required. The network port of the source MySQL database. Optional.
    </ResponseField>
    <ResponseField name="ssl" type="object">
      SSL configuration information. Optional.
      <Expandable title="properties">
        <ResponseField name="ca_certificate" type="string">
          Required. Input only. The x509 PEM-encoded certificate of the CA that signed the source database server's certificate. The replica will use this certificate to verify it's connecting to the right host. Optional.
        </ResponseField>
        <ResponseField name="client_certificate" type="string">
          Input only. The x509 PEM-encoded certificate that will be used by the replica to authenticate against the source database server.If this field is used then the 'client_key' field is mandatory. Optional.

        <ResponseField name="client_key" type="string">

        <ResponseField name="type" type="string">

---
title: "google_datamigration_migration_job"
description: "`google_datamigration_migration_job` runs a Database Migration Service migration..."
---

`google_datamigration_migration_job` runs a Database Migration Service migration, moving (and optionally continuously replicating) data from a source connection profile to a destination.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_datamigration --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_datamigration/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datamigration "github.com/ubiquex/ubx-sdk-google/sdk/go/google_datamigration/datamigration"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own migration job"})

    		ubx.Resource(datamigration.DatamigrationMigrationJob, "ci-runner", datamigration.DatamigrationMigrationJobConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```

  The CMEK (customer-managed encryption key) fully qualified key name used for the migration job. This field supports all migration jobs types except for: * Mysql to Mysql (use the cmek field in the cloudsql connection profile instead). * PostrgeSQL to PostgreSQL (use the cmek field in the cloudsql connection profile instead). * PostgreSQL to AlloyDB (use the kms_key_name field in the alloydb connection profile instead). Each Cloud CMEK key has the following format: projects/[PROJECT]/locations/[REGION]/keyRings/[RING]/cryptoKeys/[KEY_NAME] Optional; if omitted, computed by Google Cloud.

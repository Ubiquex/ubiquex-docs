`google_datamigration_v1beta1_migration_job` runs a Database Migration Service migration, moving (and optionally continuously replicating) data from a source connection profile to a destination.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datamigration "github.com/ubiquex/ubx-sdk-google/sdk/go/google/datamigration"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 migration job"})

    		ubx.Resource(datamigration.V1beta1MigrationJob, "example", datamigration.V1beta1MigrationJobConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the migration job resource was created. A timestamp in RFC3339 UTC "Zulu" format, accurate to nanoseconds. Example: "2014-10-02T15:01:23.045123456Z". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination" type="string">
  Required. The resource name (URI) of the destination connection profile. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="destination_database" type="object">

  <Expandable title="properties">

    </ResponseField>
    <ResponseField name="provider" type="string">
      The database provider. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  The migration job display name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="dump_path" type="string">
  The path to the dump file in Google Cloud Storage, in the format: (gs://[BUCKET_NAME]/[OBJECT_NAME]). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="duration" type="string">
  Output only. The duration of the migration job (in seconds). A duration in seconds with up to nine fractional digits, terminated by 's'. Example: "3.5s". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Output only. If the migration job is completed, the time when it was completed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="reverse_ssh_connectivity" type="object">
  The details needed to configure a reverse SSH tunnel between the source and destination databases. These details will be used when calling the generateSshScript method (see https://cloud.google.com/database-migration/docs/reference/rest/v1beta1/projects.locations.migrationJobs/generateSshScript) to produce the script that will help set up the reverse SSH tunnel, and to set up the VPC peering between the Cloud SQL private network and the VPC. Optional; if omitted, computed by Google Cloud.

      The name of the virtual machine (Compute Engine) used as the bastion server for the SSH tunnel. Optional.

    <ResponseField name="vm_ip" type="string">
      Required. The IP of the virtual machine (Compute Engine) used as the bastion server for the SSH tunnel. Optional.
    </ResponseField>
    <ResponseField name="vm_port" type="number">
      Required. The forwarding port of the virtual machine (Compute Engine) used as the bastion server for the SSH tunnel. Optional.

      The name of the VPC to peer with the Cloud SQL private network. Optional.

</ResponseField>

<ResponseField name="vpc_peering_connectivity" type="object">
  The details of the VPC where the source database is located in Google Cloud. We will use this information to set up the VPC peering connection between Cloud SQL and this VPC. Optional; if omitted, computed by Google Cloud.

    <ResponseField name="vpc" type="string">
      The name of the VPC network to peer with the Cloud SQL private network. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

`google_securitycenter_notification_config` streams matching Security Command Center finding(s) to a Pub/Sub topic in real time as they're created or updated.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securitycenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securitycenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own notification config"})

    		ubx.Resource(securitycenter.NotificationConfig, "example", securitycenter.NotificationConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_securitycenter_mute_config` automatically mutes matching Security Command Center finding(s), suppressing them from active alerting while keeping them recorded.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securitycenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securitycenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own mute config"})

    		ubx.Resource(securitycenter.MuteConfig, "example", securitycenter.MuteConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

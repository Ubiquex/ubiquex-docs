<Warning>
  This is Google Cloud's own **v1beta1** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_securitycenter_source`.
</Warning>

`google_securitycenter_v1beta1_source` registers an external or custom detector as a finding source within Security Command Center, letting it publish its own finding(s) alongside Google's built-in detectors.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securitycenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securitycenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta1 source"})

    		ubx.Resource(securitycenter.V1beta1Source, "example", securitycenter.V1beta1SourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

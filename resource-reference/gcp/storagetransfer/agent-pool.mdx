`google_storagetransfer_agent_pool` groups Storage Transfer Service agent(s) together, used when transferring data from an on-premises or non-cloud source that needs a local agent to read from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_storagetransfer --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_storagetransfer/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storagetransfer "github.com/ubiquex/ubx-sdk-google/sdk/go/google_storagetransfer/storagetransfer"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own agent pool"})

    		ubx.Resource(storagetransfer.StoragetransferAgentPool, "ci-runner", storagetransfer.StoragetransferAgentPoolConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="bandwidth_limit" type="object">
  Specifies a bandwidth limit for an agent pool. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="limit_mbps" type="string">
      Bandwidth rate in megabytes per second, distributed across all the agents in the pool. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  Specifies the client-specified AgentPool description. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Specifies a unique string that identifies the agent pool. Format: `projects/&#123;project_id&#125;/agentPools/&#123;agent_pool_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Specifies the state of the AgentPool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

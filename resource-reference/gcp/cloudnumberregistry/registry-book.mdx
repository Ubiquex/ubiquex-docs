`google_cloudnumberregistry_registry_book` is a container for IP address management records in Cloud Number Registry; a `default` book is created automatically per IPAM admin scope and auto-populated with discovered address ranges, and additional books can be created to organize resources further.

  Aggregated data for the RegistryBook. Optional; if omitted, computed by Google Cloud.

    </ResponseField>
    <ResponseField name="discovered_ranges_count" type="number">
      Output only. Number of DiscoveredRanges in the RegistryBook. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="discovered_realms_count" type="number">

      Output only. Number of scopes unique to the RegistryBook. Computed by Google Cloud after `ship`.

<ResponseField name="claimed_scopes" type="list(string)">
  Optional. List of scopes claimed by the RegistryBook. In Preview, Only project scope is supported. Each scope is in the format of projects/&#123;project&#125;. Each scope can only be claimed once. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">

`google_cloudnumberregistry_realm` is a real organizational grouping within Cloud Number Registry used to segment IP address management data, listed and managed via the `gcloud alpha number-registry realms` surface.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudnumberregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudnumberregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own realm"})

    		ubx.Resource(cloudnumberregistry.Realm, "example", cloudnumberregistry.RealmConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

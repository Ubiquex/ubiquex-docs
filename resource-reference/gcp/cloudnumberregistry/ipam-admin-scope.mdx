`google_cloudnumberregistry_ipam_admin_scope` defines the real organizational or folder-level scope Cloud Number Registry's IP address management operates over, the boundary within which discovered and custom IP ranges get tracked and organized into registry books.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the IpamAdminScope was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enabled_addon_platforms" type="list(string)">
  Required. Add-on platforms that are enabled for this IpamAdminScope. Cloud Number Registry only discovers the IP addresses from the enabled platforms. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. User-defined labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. Identifier. The resource name of the IpamAdminScope. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Required. Administrative scopes enabled for IP address discovery and management. For example, "organizations/1234567890". Minimum of 1 scope is required. In preview, only one organization scope is allowed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of resource discovery pipeline. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the IpamAdminScope was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

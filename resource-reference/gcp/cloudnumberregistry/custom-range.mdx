`google_cloudnumberregistry_custom_range` is a manually declared IP address range tracked in Cloud Number Registry, used alongside auto-discovered ranges so an organization's real IPAM inventory reflects address space it manages outside of what Google Cloud can discover on its own.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudnumberregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudnumberregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own custom range"})

    		ubx.Resource(cloudnumberregistry.CustomRange, "example", cloudnumberregistry.CustomRangeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

</ResponseField>

<ResponseField name="parent_range" type="string">
  Optional. The resource name of the parent CustomRange, in the format `projects/&#123;project&#125;/locations/&#123;location&#125;/customRanges/&#123;custom_range&#125;`. If specified, the parent CustomRange must be in the same RegistryBook. This field is mutually exclusive with the `realm` field, as the Realm is inherited from the parent CustomRange. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="realm" type="string">
  Optional. The resource name of the Realm associated with the CustomRange, in the format `projects/&#123;project&#125;/locations/&#123;location&#125;/realms/&#123;realm&#125;`. The Realm must be in the same project as the CustomRange. This field must not be set if the `parent_range` field is set, as the Realm will be inherited from the parent CustomRange. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="registry_book" type="string">
  Output only. The RegistryBook of the CustomRange. This field is inherited from the Realm or parent CustomRange depending on which one is specified. Optional; if omitted, computed by Google Cloud.
</ResponseField>

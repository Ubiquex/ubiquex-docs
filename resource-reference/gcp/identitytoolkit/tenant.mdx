`google_identitytoolkit_tenant` is an Identity Platform tenant, an isolated user pool and authentication configuration within a project -- used to keep separate customer populations (e.g. different organizations in a multi-tenant SaaS product) from seeing each other's users.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	identitytoolkit "github.com/ubiquex/ubx-sdk-google/sdk/go/google/identitytoolkit"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own tenant"})

    		ubx.Resource(identitytoolkit.Tenant, "example", identitytoolkit.TenantConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

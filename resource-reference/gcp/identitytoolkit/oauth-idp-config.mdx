`google_identitytoolkit_oauth_idp_config` configures a custom OpenID Connect (OIDC) identity provider Identity Platform accepts sign-ins from, for providers not covered by a built-in default configuration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_identitytoolkit --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_identitytoolkit/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	identitytoolkit "github.com/ubiquex/ubx-sdk-google/sdk/go/google_identitytoolkit/identitytoolkit"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own oauth idp config"})

    		ubx.Resource(identitytoolkit.IdentitytoolkitOauthIdpConfig, "ci-runner", identitytoolkit.IdentitytoolkitOauthIdpConfigConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="client_id" type="string">
  The client id of an OAuth client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="client_secret" type="string">
  The client secret of the OAuth client, to enable OIDC code flow. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  The config's display name set by developers. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enabled" type="bool">
  True if allows the user to sign in with the provider. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="issuer" type="string">
  For OIDC Idps, the issuer identifier. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the OAuthIdpConfig resource, for example: 'projects/my-awesome-project/oauthIdpConfigs/oauth-config-id'. Ignored during create requests. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="response_type" type="object">
  The response type to request for in the OAuth authorization flow. You can set either `id_token` or `code` to true, but not both. Setting both types to be simultaneously true (`&#123;code: true, id_token: true&#125;`) is not yet supported. See https://openid.net/specs/openid-connect-core-1_0.html#Authentication for a mapping of response type to OAuth 2.0 flow. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="code" type="bool">
      If true, authorization code is returned from IdP's authorization endpoint. Optional.
    </ResponseField>
    <ResponseField name="id_token" type="bool">
      If true, ID token is returned from IdP's authorization endpoint. Optional.
    </ResponseField>
    <ResponseField name="token" type="bool">
      Do not use. The `token` response type is not supported at the moment. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

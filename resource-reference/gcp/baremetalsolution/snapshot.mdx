`google_baremetalsolution_snapshot` is a point-in-time snapshot of a Bare Metal Solution storage volume, usable to restore that volume to its state at the time the snapshot was taken.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_baremetalsolution --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_baremetalsolution/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	baremetalsolution "github.com/ubiquex/ubx-sdk-google/sdk/go/google_baremetalsolution/baremetalsolution"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own snapshot"})

    		ubx.Resource(baremetalsolution.BaremetalsolutionSnapshot, "ci-runner", baremetalsolution.BaremetalsolutionSnapshotConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The creation time of the snapshot. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the snapshot. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="id" type="string">
  Output only. An identifier for the snapshot, generated by the backend. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the snapshot. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="storage_volume" type="string">
  Output only. The name of the volume which this snapshot belongs to. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Output only. The type of the snapshot which indicates whether it was scheduled or manual/ad-hoc. Optional; if omitted, computed by Google Cloud.
</ResponseField>

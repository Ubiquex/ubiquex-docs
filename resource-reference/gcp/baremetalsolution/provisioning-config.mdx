`google_baremetalsolution_provisioning_config` is a Bare Metal Solution provisioning request, real config describing the dedicated servers, storage, and networking Google should physically provision for a customer's bare metal environment before it goes live.

## Example

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own provisioning config"})

    		ubx.Resource(baremetalsolution.ProvisioningConfig, "example", baremetalsolution.ProvisioningConfigConfig{

    		})

    }

`google_baremetalsolution_nfs_share` is a real NFS file share provisioned for a Bare Metal Solution environment, giving the dedicated bare metal servers file-level storage reachable over the environment's own services subnet.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	baremetalsolution "github.com/ubiquex/ubx-sdk-google/sdk/go/google/baremetalsolution"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own nfs share"})

    		ubx.Resource(baremetalsolution.NfsShare, "example", baremetalsolution.NfsShareConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="allowed_clients" type="list(object)">
  List of allowed access points. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="allow_dev" type="bool">
      Whether this NFS-allowed client is permitted to access device files on the share. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="allow_suid" type="bool">
      Whether this NFS-allowed client is permitted to use set-user-ID and set-group-ID bits on the share. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="allowed_clients_cidr" type="string">
      The real CIDR range of client IP addresses this NFS share access rule applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="mount_permissions" type="string">
      The real mount access level (`READ` or `READ_WRITE`) this NFS-allowed client is granted. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="network" type="string">
      The VPC network this resource is attached to, in the form `projects/&#123;project&#125;/global/networks/&#123;network&#125;`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="nfs_path" type="string">
      The real, exported NFS path clients matching this rule can mount. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="no_root_squash" type="bool">
      Whether this NFS-allowed client is exempt from root squashing, letting a client's own root user act as root on the share. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="share_ip" type="string">
      The real IP address this NFS share is served from. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="id" type="string">
  Output only. An identifier for the NFS share, generated by the backend. This is the same value as nfs_share_id and will replace it in the future. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels as key value pairs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The name of the NFS share. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="nfs_share_id" type="string">
  Output only. An identifier for the NFS share, generated by the backend. This field will be deprecated in the future, use `id` instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pod" type="string">
  Immutable. Pod name. Pod is an independent part of infrastructure. NFSShare can only be connected to the assets (networks, instances) allocated in the same pod. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="requested_size_gib" type="string">
  The requested size, in GiB. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the NFS share. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="storage_type" type="string">
  Immutable. The storage type of the underlying volume. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="volume" type="string">
  Output only. The underlying volume of the share. Created automatically during provisioning. Optional; if omitted, computed by Google Cloud.
</ResponseField>

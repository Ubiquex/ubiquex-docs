`google_artifactregistry_docker_image` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_artifactregistry_docker_image"})

    		ubx.Data(artifactregistry.DockerImage, "example", artifactregistry.DockerImageConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="artifact_type" type="string">
  ArtifactType of this image, e.g. "application/vnd.example+type". If the `subject_digest` is set and no `artifact_type` is given, the `media_type` will be considered as the `artifact_type`. This field is returned as the `metadata.artifactType` field in the Version resource. Returned by the lookup.
</ResponseField>

<ResponseField name="build_time" type="string">
  The time this image was built. This field is returned as the 'metadata.buildTime' field in the Version resource. The build time is returned to the client as an RFC 3339 string, which can be easily used with the JavaScript Date constructor. Returned by the lookup.
</ResponseField>

<ResponseField name="image_manifests" type="list(object)">
  Optional. For multi-arch images (manifest lists), this field contains the list of image manifests. Returned by the lookup.
</ResponseField>

<ResponseField name="image_size_bytes" type="string">
  Calculated size of the image. This field is returned as the 'metadata.imageSizeBytes' field in the Version resource. Returned by the lookup.
</ResponseField>

<ResponseField name="media_type" type="string">
  Media type of this image, e.g. "application/vnd.docker.distribution.manifest.v2+json". This field is returned as the 'metadata.mediaType' field in the Version resource. Returned by the lookup.
</ResponseField>

<ResponseField name="tags" type="list(string)">
  Tags attached to this image. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the docker image was last updated. Returned by the lookup.
</ResponseField>

<ResponseField name="upload_time" type="string">
  Time the image was uploaded. Returned by the lookup.
</ResponseField>

<ResponseField name="uri" type="string">
  Required. URL to access the image. Example: us-west4-docker.pkg.dev/test-project/test-repo/nginx@sha256:e9954c1fc875017be1c3e36eca16be2d9e9bccc4bf072163515467d6a823c7cf Returned by the lookup.
</ResponseField>

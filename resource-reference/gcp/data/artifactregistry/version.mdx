## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_artifactregistry_version"})

    		ubx.Data(artifactregistry.Version, "example", artifactregistry.VersionConfig{
    			Name: "example",
    			View: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="view" type="string">
  The real, requested view (which fields to include) of this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="annotations" type="map(string)">
  Optional. Client specified annotations. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  The time when the version was created. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the version, as specified in its metadata. Returned by the lookup.
</ResponseField>

<ResponseField name="fingerprints" type="list(object)">
  Output only. Immutable reference for the version, calculated based on the version's content. Currently we only support dirsum_sha256 hash algorithm. Additional hash algorithms may be added in the future. Returned by the lookup.
</ResponseField>

<ResponseField name="metadata" type="map(any)">
  Output only. Repository-specific Metadata stored against this version. The fields returned are defined by the underlying repository-specific resource. Currently, the resources could be: DockerImage MavenArtifact Returned by the lookup.
</ResponseField>

<ResponseField name="related_tags" type="list(object)">
  Output only. A list of related tags. Will contain up to 100 tags that reference this version. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  The time when the version was last updated. Returned by the lookup.
</ResponseField>

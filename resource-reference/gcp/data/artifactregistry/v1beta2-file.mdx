`google_artifactregistry_v1beta2_file` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_artifactregistry_v1beta2_file"})

    		ubx.Data(artifactregistry.V1beta2File, "example", artifactregistry.V1beta2FileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

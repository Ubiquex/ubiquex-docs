## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_artifactregistry_maven_artifact"})

    		ubx.Data(artifactregistry.MavenArtifact, "example", artifactregistry.MavenArtifactConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only google --lang ts --out ./local-sdk
    import { MavenArtifact } from "./local-sdk/google/sdk/typescript/google/data/artifactregistry/maven_artifact.ts";

    export default stack("example", () => {
      intent({ summary: "look up google_artifactregistry_maven_artifact" });

      data(MavenArtifact, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.artifactregistry import MavenArtifact, MavenArtifactConfig

    def describe():
        ubx.intent("look up google_artifactregistry_maven_artifact")

        ubx.data(MavenArtifact, "example", MavenArtifactConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="artifact_id" type="string">
  Artifact ID for the artifact. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Time the artifact was created. Returned by the lookup.
</ResponseField>

<ResponseField name="group_id" type="string">
  Group ID for the artifact. Example: com.google.guava Returned by the lookup.
</ResponseField>

<ResponseField name="pom_uri" type="string">
  Required. URL to access the pom file of the artifact. Example: us-west4-maven.pkg.dev/test-project/test-repo/com/google/guava/guava/31.0/guava-31.0.pom Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Time the artifact was updated. Returned by the lookup.
</ResponseField>

<ResponseField name="version" type="string">
  Version of this artifact. Returned by the lookup.
</ResponseField>

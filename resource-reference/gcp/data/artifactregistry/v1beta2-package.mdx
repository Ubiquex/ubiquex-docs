title: "google_artifactregistry_v1beta2_package"
description: "`data_artifactregistry_v1beta2_package` looks up a real package stored in an Artifact Registry repository, via the v1beta2 API."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_artifactregistry_v1beta2_package"})

    		ubx.Data(artifactregistry.V1beta2Package, "example", artifactregistry.V1beta2PackageConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

</ResponseField>

<ResponseField name="display_name" type="string">
  The display name of the package. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">

</ResponseField>

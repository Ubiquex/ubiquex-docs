## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	artifactregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/artifactregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_artifactregistry_v1beta1_file"})

    		ubx.Data(artifactregistry.V1beta1File, "example", artifactregistry.V1beta1FileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only google --lang ts --out ./local-sdk
    import { V1beta1File } from "./local-sdk/google/sdk/typescript/google/data/artifactregistry/v1beta1_file.ts";

    export default stack("example", () => {
      intent({ summary: "look up google_artifactregistry_v1beta1_file" });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.artifactregistry import V1beta1File, V1beta1FileConfig

    def describe():
        ubx.intent("look up google_artifactregistry_v1beta1_file")

        ubx.data(V1beta1File, "example", V1beta1FileConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The time when the File was created. Returned by the lookup.
</ResponseField>

<ResponseField name="hashes" type="list(object)">
  The hashes of the file content. Returned by the lookup.
</ResponseField>

<ResponseField name="owner" type="string">
  The name of the Package or Version that owns this file, if any. Returned by the lookup.
</ResponseField>

<ResponseField name="size_bytes" type="string">
  The size of the File in bytes. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the File was last updated. Returned by the lookup.
</ResponseField>

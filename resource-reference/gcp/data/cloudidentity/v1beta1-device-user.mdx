---
title: "google_cloudidentity_v1beta1_device_user"
description: "`data_cloudidentity_v1beta1_device_user` looks up a real, already-existing `google_cloudidentity_device`."
---

It represents an end-user device (a phone, laptop) enrolled in Cloud Identity's own device management, tracked for compliance and access-control purposes.

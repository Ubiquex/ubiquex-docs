`google_iam_role` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_iam_role"})

    		ubx.Data(iam.Role, "example", iam.RoleConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Role } from "@ubx/sdk-google/google/data/iam/role";

    export default stack("example", () => {
      intent({ summary: "look up google_iam_role" });

      data(Role, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.iam import Role, RoleConfig

    def describe():
        ubx.intent("look up google_iam_role")

        ubx.data(Role, "example", RoleConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

<ResponseField name="name" type="string" required>
  Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="deleted" type="bool">
  The current deleted state of the role. This field is read only. It will be ignored in calls to CreateRole and UpdateRole. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A human-readable description for the role. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Used to perform a consistent read-modify-write. Returned by the lookup.
</ResponseField>

<ResponseField name="included_permissions" type="list(string)">
  The names of the permissions this role grants when bound in an IAM policy. Returned by the lookup.
</ResponseField>

<ResponseField name="stage" type="string">
  The current launch stage of the role. If the `ALPHA` launch stage has been selected for a role, the `stage` field will not be included in the returned definition for the role. Returned by the lookup.
</ResponseField>

<ResponseField name="title" type="string">
  Optional. A human-readable title for the role. Typically this is limited to 100 UTF-8 bytes. Returned by the lookup.
</ResponseField>

---
title: "google_iam_role"
description: "`data_iam_role` looks up a real, already-existing `google_iam_role`."
---

It is a custom IAM role, a named, project- or organization-scoped bundle of permissions defined when none of Google Cloud's own predefined roles fit exactly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own role"})

    		ubx.Resource(iam.Role, "example", iam.RoleConfig{
    			Role:   map[string]any{"name": "example-name"},
    			RoleId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.iam import Role, RoleConfig
    from ubx.google.iam.role import Role_Role

    def describe():
        ubx.intent("example own role")

        ubx.resource(Role, "example", RoleConfig(
            role=Role_Role(name="example-name"),
            role_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="deleted" type="bool">
  The current deleted state of the role. This field is read only. It will be ignored in calls to CreateRole and UpdateRole. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A human-readable description for the role. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Used to perform a consistent read-modify-write. Returned by the lookup.
</ResponseField>

<ResponseField name="included_permissions" type="list(string)">
  The names of the permissions this role grants when bound in an IAM policy. Returned by the lookup.
</ResponseField>

<ResponseField name="stage" type="string">
  The current launch stage of the role. If the `ALPHA` launch stage has been selected for a role, the `stage` field will not be included in the returned definition for the role. Returned by the lookup.
</ResponseField>

<ResponseField name="title" type="string">
  Optional. A human-readable title for the role. Typically this is limited to 100 UTF-8 bytes. Returned by the lookup.
</ResponseField>

`data_bigquerydatatransfer_data_source` looks up a real, supported external data source (such as Google Ads or Salesforce) available to BigQuery Data Transfer Service.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	bigquerydatatransfer "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/bigquerydatatransfer"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_bigquerydatatransfer_data_source"})

    		ubx.Data(bigquerydatatransfer.DataSource, "example", bigquerydatatransfer.DataSourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.bigquerydatatransfer import DataSource, DataSourceConfig

    def describe():
        ubx.intent("look up google_bigquerydatatransfer_data_source")

        ubx.data(DataSource, "example", DataSourceConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="authorization_type" type="string">
  Indicates the type of authorization. Returned by the lookup.
</ResponseField>

<ResponseField name="client_id" type="string">
  Data source client id which should be used to receive refresh token. Returned by the lookup.
</ResponseField>

<ResponseField name="data_refresh_type" type="string">
  Specifies whether the data source supports automatic data refresh for the past few days, and how it's supported. For some data sources, data might not be complete until a few days later, so it's useful to refresh data automatically. Returned by the lookup.
</ResponseField>

<ResponseField name="data_source_id" type="string">
  Data source id. Returned by the lookup.
</ResponseField>

<ResponseField name="default_data_refresh_window_days" type="number">
  Default data refresh window on days. Only meaningful when `data_refresh_type` = `SLIDING_WINDOW`. Returned by the lookup.
</ResponseField>

<ResponseField name="default_schedule" type="string">
  Default data transfer schedule. Examples of valid schedules include: `1st,3rd monday of month 15:30`, `every wed,fri of jan,jun 13:15`, and `first sunday of quarter 00:00`. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  User friendly data source description string. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  User friendly data source name. Returned by the lookup.
</ResponseField>

<ResponseField name="help_url" type="string">
  Url for the help document for this data source. Returned by the lookup.
</ResponseField>

<ResponseField name="manual_runs_disabled" type="bool">
  Disables backfilling and manual run scheduling for the data source. Returned by the lookup.
</ResponseField>

<ResponseField name="minimum_schedule_interval" type="string">
  The minimum interval for scheduler to schedule runs. Returned by the lookup.
</ResponseField>

<ResponseField name="parameters" type="list(object)">
  Data source parameters. Returned by the lookup.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Api auth scopes for which refresh token needs to be obtained. These are scopes needed by a data source to prepare data and ingest them into BigQuery, e.g., https://www.googleapis.com/auth/bigquery Returned by the lookup.
</ResponseField>

<ResponseField name="supports_custom_schedule" type="bool">
  Specifies whether the data source supports a user defined schedule, or operates on the default schedule. When set to `true`, user can override default schedule. Returned by the lookup.
</ResponseField>

<ResponseField name="supports_multiple_transfers" type="bool">
  Deprecated. This field has no effect. Returned by the lookup.
</ResponseField>

<ResponseField name="transfer_type" type="string">
  Deprecated. This field has no effect. Returned by the lookup.
</ResponseField>

<ResponseField name="update_deadline_seconds" type="number">
  The number of seconds to wait for an update from the data source before the Data Transfer Service marks the transfer as FAILED. Returned by the lookup.
</ResponseField>

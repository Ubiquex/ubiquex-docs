---
title: "google_oracledatabase_database"
description: "`data_oracledatabase_database` looks up a real, already-existing `google_oracledatabase_autonomous_database`."
---

It provisions a self-managing Oracle Autonomous Database instance through Oracle Database@Google Cloud, running on Oracle Cloud Infrastructure but integrated into a Google Cloud project.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentregistry "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/agentregistry"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_agentregistry_agent"})

    		ubx.Data(agentregistry.Agent, "example", agentregistry.AgentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only google --lang ts --out ./local-sdk

    export default stack("example", () => {
      intent({ summary: "look up google_agentregistry_agent" });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.agentregistry import Agent, AgentConfig

    def describe():
        ubx.intent("look up google_agentregistry_agent")

        ubx.data(Agent, "example", AgentConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="agent_id" type="string">
  Output only. A stable, globally unique identifier for agents. Returned by the lookup.
</ResponseField>

<ResponseField name="attributes" type="map(map(any))">
  Output only. Attributes of the Agent. Valid values: * `agentregistry.googleapis.com/system/Framework`: &#123;"framework": "google-adk"&#125; - the agent framework used to develop the Agent. Example values: "google-adk", "langchain", "custom". * `agentregistry.googleapis.com/system/RuntimeIdentity`: &#123;"principal": "principal://..."&#125; - the runtime identity associated with the Agent. * `agentregistry.googleapis.com/system/RuntimeReference`: &#123;"uri": "//..."&#125; - the URI of the underlying resource hosting the Agent, for example, the Reasoning Engine URI. Returned by the lookup.
</ResponseField>

<ResponseField name="card" type="object">
  Full Agent Card payload, often obtained from the A2A Agent Card. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="content" type="map(any)">
      Output only. The content of the agent card. Returned by the lookup.
    </ResponseField>
    <ResponseField name="type" type="string">
      Output only. The type of agent card. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Output only. The description of the Agent, often obtained from the A2A Agent Card. Empty if Agent Card has no description. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Output only. The display name of the agent, often obtained from the A2A Agent Card. Returned by the lookup.
</ResponseField>

<ResponseField name="location" type="string">
  Output only. The location where agent is hosted. The value is defined by the hosting environment (i.e. cloud provider). Returned by the lookup.
</ResponseField>

<ResponseField name="protocols" type="list(object)">
  Output only. The connection details for the Agent. Returned by the lookup.
</ResponseField>

<ResponseField name="skills" type="list(object)">
  Output only. Skills the agent possesses, often obtained from the A2A Agent Card. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. A universally unique identifier for the Agent. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update time. Returned by the lookup.
</ResponseField>

<ResponseField name="version" type="string">
  Output only. The version of the Agent, often obtained from the A2A Agent Card. Empty if Agent Card has no version or agent is not an A2A Agent. Returned by the lookup.
</ResponseField>

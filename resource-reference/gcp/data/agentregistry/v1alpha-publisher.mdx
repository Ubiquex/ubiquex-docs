`google_agentregistry_v1alpha_publisher` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="display_name" type="string">
  Optional. Human readable display name of the publisher. Returned by the lookup.
</ResponseField>

<ResponseField name="documentation_uri" type="string">
  Optional. URI pointing to official publisher documentation. Returned by the lookup.
</ResponseField>

<ResponseField name="publisher_tier" type="string">
  Output only. The curation tier of the publisher. Returned by the lookup.
</ResponseField>

<ResponseField name="support_uri" type="string">
  Optional. URI pointing to the support portal or email. Returned by the lookup.
</ResponseField>

<ResponseField name="verified_prefix" type="string">
  Required. The verified prefix (e.g. "snowflake-", "google-") associated with this publisher. The system uses this prefix to enforce name-squatting rules during Skill registration. Must be globally unique across all publishers. Returned by the lookup.
</ResponseField>

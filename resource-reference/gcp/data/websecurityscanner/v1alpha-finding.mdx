`google_websecurityscanner_v1alpha_finding` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	websecurityscanner "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/websecurityscanner"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_websecurityscanner_v1alpha_finding"})

    		ubx.Data(websecurityscanner.V1alphaFinding, "example", websecurityscanner.V1alphaFindingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="body" type="string">
  The body of the request that triggered the vulnerability. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the vulnerability. Returned by the lookup.
</ResponseField>

<ResponseField name="final_url" type="string">
  The URL where the browser lands when the vulnerability is detected. Returned by the lookup.
</ResponseField>

<ResponseField name="finding_type" type="string">
  The type of the Finding. Returned by the lookup.
</ResponseField>

<ResponseField name="frame_url" type="string">
  If the vulnerability was originated from nested IFrame, the immediate parent IFrame is reported. Returned by the lookup.
</ResponseField>

<ResponseField name="fuzzed_url" type="string">
  The URL produced by the server-side fuzzer and used in the request that triggered the vulnerability. Returned by the lookup.
</ResponseField>

<ResponseField name="http_method" type="string">
  The http method of the request that triggered the vulnerability, in uppercase. Returned by the lookup.
</ResponseField>

<ResponseField name="outdated_library" type="object">
  Information reported for an outdated library. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="learn_more_urls" type="list(string)">
      URLs to learn more information about the vulnerabilities in the library. Optional lookup argument.
    </ResponseField>
    <ResponseField name="library_name" type="string">
      The name of the outdated library. Optional lookup argument.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version number. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="reproduction_url" type="string">
  The URL containing human-readable payload that user can leverage to reproduce the vulnerability. Returned by the lookup.
</ResponseField>

<ResponseField name="tracking_id" type="string">
  The tracking ID uniquely identifies a vulnerability instance across multiple ScanRuns. Returned by the lookup.
</ResponseField>

<ResponseField name="violating_resource" type="object">
  Information regarding any resource causing the vulnerability such as JavaScript sources, image, audio files, etc. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="content_type" type="string">
      The MIME type of this resource. Optional lookup argument.
    </ResponseField>
    <ResponseField name="resource_url" type="string">
      URL of this violating resource. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vulnerable_headers" type="object">
  Information about vulnerable or missing HTTP Headers. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="headers" type="list(object)">
      List of vulnerable headers. Optional lookup argument.
    </ResponseField>
    <ResponseField name="missing_headers" type="list(object)">
      List of missing headers. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vulnerable_parameters" type="object">
  Information about vulnerable request parameters. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="parameter_names" type="list(string)">
      The vulnerable parameter names. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="xss" type="object">
  Information reported for an XSS. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="error_message" type="string">
      An error message generated by a javascript breakage. Optional lookup argument.
    </ResponseField>
    <ResponseField name="stack_traces" type="list(string)">
      Stack traces leading to the point where the XSS occurred. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

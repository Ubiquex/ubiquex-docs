`google_websecurityscanner_v1beta_scan_run` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_websecurityscanner_v1beta_scan_run"})

## Result properties

<ResponseField name="end_time" type="string">
  The time at which the ScanRun reached termination state - that the ScanRun is either finished or stopped by user. Returned by the lookup.
</ResponseField>

<ResponseField name="error_trace" type="object">
  Output only. Defines an error trace message for a ScanRun. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="code" type="string">
      Indicates the error reason code. Optional lookup argument.
    </ResponseField>
    <ResponseField name="most_common_http_error_code" type="number">
      If the scan encounters TOO_MANY_HTTP_ERRORS, this field indicates the most common HTTP error code, if such is available. For example, if this code is 404, the scan has encountered too many NOT_FOUND responses. Optional lookup argument.
    </ResponseField>
    <ResponseField name="scan_config_error" type="object">
      Defines a custom error message used by CreateScanConfig and UpdateScanConfig APIs when scan configuration validation fails. It is also reported as part of a ScanRunErrorTrace message if scan validation fails due to a scan configuration error. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="code" type="string">
          Indicates the reason code for a configuration failure. Optional lookup argument.
        </ResponseField>
        <ResponseField name="field_name" type="string">
          Indicates the full name of the ScanConfig field that triggers this error, for example "scan_config.max_qps". This field is provided for troubleshooting purposes only and its actual value can change in the future. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="execution_state" type="string">
  The execution state of the ScanRun. Returned by the lookup.
</ResponseField>

<ResponseField name="has_vulnerabilities" type="bool">
  Whether the scan run has found any vulnerabilities. Returned by the lookup.
</ResponseField>

<ResponseField name="progress_percent" type="number">
  The percentage of total completion ranging from 0 to 100. If the scan is in queue, the value is 0. If the scan is running, the value ranges from 0 to 100. If the scan is finished, the value is 100. Returned by the lookup.
</ResponseField>

<ResponseField name="result_state" type="string">
  The result state of the ScanRun. This field is only available after the execution state reaches "FINISHED". Returned by the lookup.
</ResponseField>

<ResponseField name="start_time" type="string">
  The time at which the ScanRun started. Returned by the lookup.
</ResponseField>

<ResponseField name="urls_crawled_count" type="string">
  The number of URLs crawled during this ScanRun. If the scan is in progress, the value represents the number of URLs crawled up to now. Returned by the lookup.
</ResponseField>

<ResponseField name="urls_tested_count" type="string">
  The number of URLs tested during this ScanRun. If the scan is in progress, the value represents the number of URLs tested up to now. The number of URLs tested is usually larger than the number URLS crawled because typically a crawled URL is tested with multiple test payloads. Returned by the lookup.
</ResponseField>

<ResponseField name="warning_traces" type="list(object)">
  A list of warnings, if such are encountered during this scan run. Returned by the lookup.
</ResponseField>

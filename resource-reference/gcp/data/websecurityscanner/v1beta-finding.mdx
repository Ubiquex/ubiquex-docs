`google_websecurityscanner_v1beta_finding` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	websecurityscanner "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/websecurityscanner"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_websecurityscanner_v1beta_finding"})

    		ubx.Data(websecurityscanner.V1betaFinding, "example", websecurityscanner.V1betaFindingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="body" type="string">
  The body of the request that triggered the vulnerability. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the vulnerability. Returned by the lookup.
</ResponseField>

<ResponseField name="final_url" type="string">
  The URL where the browser lands when the vulnerability is detected. Returned by the lookup.
</ResponseField>

<ResponseField name="finding_type" type="string">
  The type of the Finding. Detailed and up-to-date information on findings can be found here: https://cloud.google.com/security-command-center/docs/how-to-remediate-web-security-scanner Returned by the lookup.
</ResponseField>

<ResponseField name="form" type="object">
  ! Information about a vulnerability with an HTML. Returned by the lookup.

    <ResponseField name="action_uri" type="string">
      ! The URI where to send the form when it's submitted. Optional lookup argument.
    </ResponseField>

      ! The names of form fields related to the vulnerability. Optional lookup argument.
    </ResponseField>

</ResponseField>

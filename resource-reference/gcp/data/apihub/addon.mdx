## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apihub_addon"})

    		ubx.Data(apihub.Addon, "example", apihub.AddonConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Result properties

<ResponseField name="config" type="object">
  Configuration for the addon. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="all_data_addon_config" type="object">
      Configuration for addons which act on all data in the API hub. This is used to specify if the addon is enabled for all data in the API hub. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="enabled" type="bool">
          Required. If true, the addon is enabled for all data in the API hub. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="gateway_plugin_addon_config" type="object">
      Configuration for gateway plugin addons. This is used to specify the list of gateway plugin configs for which the addon is enabled. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="gateway_plugin_configs" type="list(object)">
          Required. The list of gateway plugin configs for which the addon is enabled. Each gateway plugin config should have a unique plugin instance. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the addon was created. Returned by the lookup.
</ResponseField>

<ResponseField name="data_source" type="string">
  Required. The data source on which the addon operates. This determines which field in the `config` oneof is used. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the addon. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The display name of the addon. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the addon. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the addon was last updated. Returned by the lookup.
</ResponseField>

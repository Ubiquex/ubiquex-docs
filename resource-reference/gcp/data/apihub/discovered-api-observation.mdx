## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apihub_discovered_api_observation"})

    		ubx.Data(apihub.DiscoveredApiObservation, "example", apihub.DiscoveredApiObservationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="api_operation_count" type="string">
  Optional. The number of observed API Operations. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time stamp of the observation in API Hub. Returned by the lookup.
</ResponseField>

<ResponseField name="hostname" type="string">
  Optional. The hostname of requests processed for this Observation. Returned by the lookup.
</ResponseField>

<ResponseField name="known_operations_count" type="string">
  Output only. The number of known API Operations. Returned by the lookup.
</ResponseField>

<ResponseField name="last_event_detected_time" type="string">
  Optional. Last event detected time stamp Returned by the lookup.
</ResponseField>

<ResponseField name="origin" type="string">
  Optional. For an observation pushed from a Google Cloud resource, this would be the Google Cloud project id. Returned by the lookup.
</ResponseField>

<ResponseField name="server_ips" type="list(string)">
  Optional. The IP address (IPv4 or IPv6) of the origin server that the request was sent to. This field can include port information. Examples: `"192.168.1.1"`, `"10.0.0.1:80"`, `"FE80::0202:B3FF:FE1E:8329"`. Returned by the lookup.
</ResponseField>

<ResponseField name="source_locations" type="list(string)">
  Optional. The location of the observation source. Returned by the lookup.
</ResponseField>

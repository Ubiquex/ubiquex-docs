title: "google_apihub_definition"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apihub_definition"})

    		ubx.Data(apihub.Definition, "example", apihub.DefinitionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only google --lang ts --out ./local-sdk
    import { Definition } from "./local-sdk/google/sdk/typescript/google/data/apihub/definition.ts";

    export default stack("example", () => {
      intent({ summary: "look up google_apihub_definition" });

      data(Definition, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.apihub import Definition, DefinitionConfig

    def describe():
        ubx.intent("look up google_apihub_definition")

        ubx.data(Definition, "example", DefinitionConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="attributes" type="map(object)">
  Optional. The list of user defined attributes associated with the definition resource. The key is the attribute name. It will be of the format: `projects/&#123;project&#125;/locations/&#123;location&#125;/attributes/&#123;attribute&#125;`. The value is the attribute values associated with the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the definition was created. Returned by the lookup.
</ResponseField>

<ResponseField name="schema" type="object">
  The schema details derived from the spec. Currently, this entity is supported for OpenAPI spec only. For OpenAPI spec, this maps to the schema defined in the `definitions` section for OpenAPI 2.0 version and in `components.schemas` section for OpenAPI 3.0 and 3.1 version. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="display_name" type="string">
      Output only. The display name of the schema. This will map to the name of the schema in the spec. Returned by the lookup.
    </ResponseField>
    <ResponseField name="raw_value" type="string">
      Output only. The raw value of the schema definition corresponding to the schema name in the spec. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="spec" type="string">
  Output only. The name of the spec from where the definition was parsed. Format is `projects/&#123;project&#125;/locations/&#123;location&#125;/apis/&#123;api&#125;/versions/&#123;version&#125;/specs/&#123;spec&#125;` Returned by the lookup.
</ResponseField>

<ResponseField name="type" type="string">
  Output only. The type of the definition. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the definition was last updated. Returned by the lookup.
</ResponseField>

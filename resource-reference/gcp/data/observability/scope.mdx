`google_observability_scope` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	observability "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/observability"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_observability_scope"})

    		ubx.Data(observability.Scope, "example", observability.ScopeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Scope } from "@ubx/sdk-google/google/data/observability/scope";

    export default stack("example", () => {
      intent({ summary: "look up google_observability_scope" });

      data(Scope, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.observability import Scope, ScopeConfig

    def describe():
        ubx.intent("look up google_observability_scope")

        ubx.data(Scope, "example", ScopeConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Result properties

<ResponseField name="log_scope" type="string">
  Required. The full resource name of the `LogScope`. For example: //logging.googleapis.com/projects/myproject/locations/global/logScopes/my-log-scope Returned by the lookup.
</ResponseField>

<ResponseField name="trace_scope" type="string">
  Required. The resource name of the `TraceScope`. For example: projects/myproject/locations/global/traceScopes/my-trace-scope Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update timestamp. Note: The Update timestamp for the default scope is initially unset. Returned by the lookup.
</ResponseField>

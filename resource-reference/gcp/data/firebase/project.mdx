## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebase "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/firebase"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_firebase_project"})

    		ubx.Data(firebase.Project, "example", firebase.ProjectConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Project } from "@ubx/sdk-google/google/data/firebase/project";

    export default stack("example", () => {
      intent({ summary: "look up google_firebase_project" });

      data(Project, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.firebase import Project, ProjectConfig

    def describe():
        ubx.intent("look up google_firebase_project")

        ubx.data(Project, "example", ProjectConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Result properties

<ResponseField name="annotations" type="map(string)">
  A set of user-defined annotations for the FirebaseProject. Learn more about annotations in Google's [AIP-128 standard](https://google.aip.dev/128#annotations). These annotations are intended solely for developers and client-side tools. Firebase services will not mutate this annotations set. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user-assigned display name of the Project. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  This checksum is computed by the server based on the value of other fields, and it may be sent with update requests to ensure the client has an up-to-date value before proceeding. Learn more about `etag` in Google's [AIP-154 standard](https://google.aip.dev/154#declarative-friendly-resources). This etag is strongly validated. Returned by the lookup.
</ResponseField>

<ResponseField name="project_id" type="string">
  Output only. Immutable. A user-assigned unique identifier for the Project. This identifier may appear in URLs or names for some Firebase resources associated with the Project, but it should generally be treated as a convenience alias to reference the Project. Returned by the lookup.
</ResponseField>

<ResponseField name="project_number" type="string">
  Output only. Immutable. The globally unique, Google-assigned canonical identifier for the Project. Use this identifier when configuring integrations and/or making API calls to Firebase or third-party services. Returned by the lookup.
</ResponseField>

`data_cloudresourcemanager_effective_tag_binding_collection` looks up the real, effective set of resource-manager tags applied to a resource, including tags inherited from its own ancestor folders and organization.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudresourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/cloudresourcemanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_cloudresourcemanager_effective_tag_binding_collection"})

    		ubx.Data(cloudresourcemanager.EffectiveTagBindingCollection, "example", cloudresourcemanager.EffectiveTagBindingCollectionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="effective_tags" type="map(string)">
  Tag keys/values effectively bound to this resource, specified in namespaced format. For example: "123/environment": "production" Returned by the lookup.
</ResponseField>

<ResponseField name="full_resource_name" type="string">
  The full resource name of the resource the TagBindings are bound to. E.g. `//cloudresourcemanager.googleapis.com/projects/123` Returned by the lookup.
</ResponseField>

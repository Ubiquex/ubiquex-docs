## Example

    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (

    	cloudresourcemanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/cloudresourcemanager"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_cloudresourcemanager_tag_binding_collection"})

    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="etag" type="string">
  Optional. A checksum based on the current bindings which can be passed to prevent race conditions. This field is always set in server responses. Returned by the lookup.
</ResponseField>

<ResponseField name="full_resource_name" type="string">
  The full resource name of the resource the TagBindings are bound to. E.g. `//cloudresourcemanager.googleapis.com/projects/123` Returned by the lookup.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Tag keys/values directly bound to this resource, specified in namespaced format. For example: "123/environment": "production" Returned by the lookup.
</ResponseField>

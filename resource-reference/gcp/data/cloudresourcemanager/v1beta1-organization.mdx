`google_cloudresourcemanager_v1beta1_organization` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

## Result properties

<ResponseField name="creation_time" type="string">
  Timestamp when the Organization was created. Assigned by the server. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  A human-readable string that refers to the Organization in the Google Cloud console. This string is set by the server and cannot be changed. The string will be set to the primary domain (for example, "google.com") of the G Suite customer that owns the organization. Returned by the lookup.
</ResponseField>

<ResponseField name="lifecycle_state" type="string">
  The organization's current lifecycle state. Assigned by the server. Returned by the lookup.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Returned by the lookup.
</ResponseField>

<ResponseField name="owner" type="object">
  The entity that owns an Organization. The lifetime of the Organization and all of its descendants are bound to the `OrganizationOwner`. If the `OrganizationOwner` is deleted, the Organization and all its descendants will be deleted. Returned by the lookup.
  <Expandable title="properties">

    </ResponseField>
  </Expandable>
</ResponseField>

title: "google_bigquery_model"
description: "`google_bigquery_model` is a real, live lookup against Google Cloud, generated from google's own real schema -- read-only, never created or destroyed."
---

`google_bigquery_model` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

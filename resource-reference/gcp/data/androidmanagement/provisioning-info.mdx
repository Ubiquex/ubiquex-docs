`google_androidmanagement_provisioning_info` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidmanagement_provisioning_info"})

    		ubx.Data(androidmanagement.ProvisioningInfo, "example", androidmanagement.ProvisioningInfoConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="api_level" type="number">
  The API level of the Android platform version running on the device. Returned by the lookup.
</ResponseField>

<ResponseField name="authenticated_user_email" type="string">
  The email address of the authenticated user (only present for Google Account provisioning method). Returned by the lookup.
</ResponseField>

<ResponseField name="brand" type="string">
  The brand of the device. For example, Google. Returned by the lookup.
</ResponseField>

<ResponseField name="enterprise" type="string">
  The name of the enterprise in the form enterprises/&#123;enterprise&#125;. Returned by the lookup.
</ResponseField>

<ResponseField name="imei" type="string">
  For corporate-owned devices, IMEI number of the GSM device. For example, A1000031212. Returned by the lookup.
</ResponseField>

<ResponseField name="management_mode" type="string">
  The management mode of the device or profile. Returned by the lookup.
</ResponseField>

<ResponseField name="meid" type="string">
  For corporate-owned devices, MEID number of the CDMA device. For example, A00000292788E1. Returned by the lookup.
</ResponseField>

<ResponseField name="model" type="string">
  The model of the device. For example, Asus Nexus 7. Returned by the lookup.
</ResponseField>

<ResponseField name="ownership" type="string">
  Ownership of the managed device. Returned by the lookup.
</ResponseField>

<ResponseField name="serial_number" type="string">
  For corporate-owned devices, The device serial number. Returned by the lookup.
</ResponseField>

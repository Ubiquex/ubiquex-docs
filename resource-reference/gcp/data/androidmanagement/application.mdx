`data_androidmanagement_application` looks up a real app's own metadata as known to Android Management API, Google's modern EMM API for managing Android devices.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidmanagement_application"})

    		ubx.Data(androidmanagement.Application, "example", androidmanagement.ApplicationConfig{
    			Name:         "example",
    			LanguageCode: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Application } from "@ubx/sdk-google/google/data/androidmanagement/application";

    export default stack("example", () => {
      intent({ summary: "look up google_androidmanagement_application" });

      data(Application, "example", {
        name: "example",
        languageCode: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.androidmanagement import Application, ApplicationConfig

    def describe():
        ubx.intent("look up google_androidmanagement_application")

        ubx.data(Application, "example", ApplicationConfig(
            name="example",
            language_code="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="language_code" type="string">
  The real, BCP-47 language code this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="app_pricing" type="string">
  Whether this app is free, free with in-app purchases, or paid. If the pricing is unspecified, this means the app is not generally available anymore (even though it might still be available to people who own it). Returned by the lookup.
</ResponseField>

<ResponseField name="app_tracks" type="list(object)">
  Application tracks visible to the enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="app_versions" type="list(object)">
  Versions currently available for this app. Returned by the lookup.
</ResponseField>

<ResponseField name="author" type="string">
  The name of the author of the apps (for example, the app developer). Returned by the lookup.
</ResponseField>

<ResponseField name="available_countries" type="list(string)">
  The countries which this app is available in as per ISO 3166-1 alpha-2. Returned by the lookup.
</ResponseField>

<ResponseField name="category" type="string">
  The app category (e.g. RACING, SOCIAL, etc.) Returned by the lookup.
</ResponseField>

<ResponseField name="content_rating" type="string">
  The content rating for this app. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  The localized promotional description, if available. Returned by the lookup.
</ResponseField>

<ResponseField name="distribution_channel" type="string">
  How and to whom the package is made available. Returned by the lookup.
</ResponseField>

<ResponseField name="features" type="list(string)">
  Noteworthy features (if any) of this app. Returned by the lookup.
</ResponseField>

<ResponseField name="full_description" type="string">
  Full app description, if available. Returned by the lookup.
</ResponseField>

<ResponseField name="icon_url" type="string">
  A link to an image that can be used as an icon for the app. This image is suitable for use up to a pixel size of 512 x 512. Returned by the lookup.
</ResponseField>

<ResponseField name="managed_properties" type="list(object)">
  The set of managed properties available to be pre-configured for the app. Returned by the lookup.
</ResponseField>

<ResponseField name="min_android_sdk_version" type="number">
  The minimum Android SDK necessary to run the app. Returned by the lookup.
</ResponseField>

<ResponseField name="permissions" type="list(object)">
  The permissions required by the app. Returned by the lookup.
</ResponseField>

<ResponseField name="play_store_url" type="string">
  A link to the (consumer) Google Play details page for the app. Returned by the lookup.
</ResponseField>

<ResponseField name="recent_changes" type="string">
  A localised description of the recent changes made to the app. Returned by the lookup.
</ResponseField>

<ResponseField name="screenshot_urls" type="list(string)">
  A list of screenshot links representing the app. Returned by the lookup.
</ResponseField>

<ResponseField name="small_icon_url" type="string">
  A link to a smaller image that can be used as an icon for the app. This image is suitable for use up to a pixel size of 128 x 128. Returned by the lookup.
</ResponseField>

<ResponseField name="title" type="string">
  The title of the app. Localized. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The approximate time (within 7 days) the app was last published. Returned by the lookup.
</ResponseField>

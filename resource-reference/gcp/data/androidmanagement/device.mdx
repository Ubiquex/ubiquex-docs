title: "google_androidmanagement_device"
description: "`google_androidmanagement_device` is a real, live lookup against Google Cloud, generated from google's own real schema -- read-only, never created or destroyed."
---

`google_androidmanagement_device` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidmanagement_device"})

    		ubx.Data(androidmanagement.Device, "example", androidmanagement.DeviceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Device } from "@ubx/sdk-google/google/data/androidmanagement/device";

    export default stack("example", () => {
      intent({ summary: "look up google_androidmanagement_device" });

      data(Device, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.androidmanagement import Device, DeviceConfig

    def describe():
        ubx.intent("look up google_androidmanagement_device")

            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="client_operation_id" type="string">
  A real, caller-supplied identifier used to track this asynchronous operation. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="digest_type" type="string">
  The real DNSSEC digest algorithm this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="dns_key_id" type="string" required>
  The real, unique identifier of the DNSSEC key this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="managed_zone" type="string" required>
  The real Cloud DNS managed zone this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="algorithm" type="string">
  String mnemonic specifying the DNSSEC algorithm of this key. Immutable after creation time. Returned by the lookup.
</ResponseField>

<ResponseField name="creation_time" type="string">
  The time that this resource was created in the control plane. This is in RFC3339 text format. Output only. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  A mutable string of at most 1024 characters associated with this resource for the user's convenience. Has no effect on the resource's function. Returned by the lookup.
</ResponseField>

<ResponseField name="digests" type="list(object)">
  Cryptographic hashes of the DNSKEY resource record associated with this DnsKey. These digests are needed to construct a DS record that points at this DNS key. Output only. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  Unique identifier for the resource; defined by the server (output only). Returned by the lookup.
</ResponseField>

<ResponseField name="is_active" type="bool">
  Active keys are used to sign subsequent changes to the ManagedZone. Inactive keys are still present as DNSKEY Resource Records for the use of resolvers validating existing signatures. Returned by the lookup.
</ResponseField>

<ResponseField name="key_length" type="number">
  Length of the key in bits. Specified at creation time, and then immutable. Returned by the lookup.
</ResponseField>

<ResponseField name="key_tag" type="number">
  The key tag is a non-cryptographic hash of the a DNSKEY resource record associated with this DnsKey. The key tag can be used to identify a DNSKEY more quickly (but it is not a unique identifier). In particular, the key tag is used in a parent zone's DS record to point at the DNSKEY in this child ManagedZone. The key tag is a number in the range [0, 65535] and the algorithm to calculate it is specified in RFC4034 Appendix B. Output only. Returned by the lookup.
</ResponseField>

<ResponseField name="kind" type="string">
  The real, discriminating kind of this object. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="public_key" type="string">
  Base64 encoded public half of this key. Output only. Returned by the lookup.
</ResponseField>

<ResponseField name="type" type="string">
  One of "KEY_SIGNING" or "ZONE_SIGNING". Keys of type KEY_SIGNING have the Secure Entry Point flag set and, when active, are used to sign only resource record sets of type DNSKEY. Otherwise, the Secure Entry Point flag is cleared, and this key is used to sign only resource record sets of other types. Immutable after creation time. Returned by the lookup.
</ResponseField>

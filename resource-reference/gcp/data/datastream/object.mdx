---
title: "google_datastream_object"
description: "`data_datastream_object` looks up a real source database object (such as a table) tracked by a Datastream stream."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datastream "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/datastream"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_datastream_object"})

    		ubx.Data(datastream.Object, "example", datastream.ObjectConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Object } from "@ubx/sdk-google/google/data/datastream/object";

    export default stack("example", () => {
      intent({ summary: "look up google_datastream_object" });

      data(Object, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.datastream import Object, ObjectConfig

    def describe():
        ubx.intent("look up google_datastream_object")

        ubx.data(Object, "example", ObjectConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="backfill_job" type="object">
  Represents a backfill job on a specific stream object. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="errors" type="list(object)">
      Output only. Errors which caused the backfill job to fail. Returned by the lookup.
    </ResponseField>
    <ResponseField name="event_filter" type="object">
      Represents a filter for included data on a stream object. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="sql_where_clause" type="string">
          An SQL-query Where clause selecting which data should be included, not including the "WHERE" keyword. e.g., `t.key1 = 'value1' AND t.key2 = 'value2'` Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="last_end_time" type="string">
      Output only. Backfill job's end time. Returned by the lookup.
    </ResponseField>
    <ResponseField name="last_start_time" type="string">
      Output only. Backfill job's start time. Returned by the lookup.
    </ResponseField>
    <ResponseField name="state" type="string">
      Output only. Backfill job state. Returned by the lookup.
    </ResponseField>
    <ResponseField name="trigger" type="string">
      Backfill job's triggering reason. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation time of the object. Returned by the lookup.
</ResponseField>

<ResponseField name="customization_rules" type="list(object)">
  Output only. The customization rules for the object. These rules are derived from the parent Stream's `rule_sets` and represent the intended configuration for the object. Returned by the lookup.
</ResponseField>

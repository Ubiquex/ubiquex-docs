## Example

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_networkconnectivity_group"})

    		})
    	}))
    }

## Result properties

<ResponseField name="auto_accept" type="object">
  The auto-accept setting for a group controls whether proposed spokes are automatically attached to the hub. If auto-accept is enabled, the spoke immediately is attached to the hub and becomes part of the group. In this case, the new spoke is in the ACTIVE state. If auto-accept is disabled, the spoke goes to the INACTIVE state, and it must be reviewed and accepted by a hub administrator. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="auto_accept_projects" type="list(string)">
      Optional. A list of project ids or project numbers for which you want to enable auto-accept. The auto-accept setting is applied to spokes being created or updated in these projects. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the group was created. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the group. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels in key-value pair format. For more information about labels, see [Requirements for labels](https://cloud.google.com/resource-manager/docs/creating-managing-labels#requirements). Returned by the lookup.
</ResponseField>

<ResponseField name="route_table" type="string">
  Output only. The name of the route table that corresponds to this group. They use the following form: `projects/&#123;project_number&#125;/locations/global/hubs/&#123;hub_id&#125;/routeTables/&#123;route_table_id&#125;` Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current lifecycle state of this group. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The Google-generated UUID for the group. This value is unique across all group resources. If a group is deleted and another with the same name is created, the new route table is assigned a different unique_id. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the group was last updated. Returned by the lookup.
</ResponseField>

title: "google_networkconnectivity_route"

---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_networkconnectivity_route"})

    		ubx.Data(networkconnectivity.Route, "example", networkconnectivity.RouteConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Route } from "@ubx/sdk-google/google/data/networkconnectivity/route";

    export default stack("example", () => {
      intent({ summary: "look up google_networkconnectivity_route" });

      data(Route, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.networkconnectivity import Route, RouteConfig

    def describe():
        ubx.intent("look up google_networkconnectivity_route")

        ubx.data(Route, "example", RouteConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The time the route was created. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of the route. Returned by the lookup.
</ResponseField>

<ResponseField name="ip_cidr_range" type="string">
  The destination IP address range. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional labels in key-value pair format. For more information about labels, see [Requirements for labels](https://cloud.google.com/resource-manager/docs/creating-managing-labels#requirements). Returned by the lookup.
</ResponseField>

<ResponseField name="location" type="string">
  Output only. The origin location of the route. Uses the following form: "projects/&#123;project&#125;/locations/&#123;location&#125;" Example: projects/1234/locations/us-central1 Returned by the lookup.
</ResponseField>

<ResponseField name="next_hop_interconnect_attachment" type="object">
  A route next hop that leads to an interconnect attachment resource. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="site_to_site_data_transfer" type="bool">
      Indicates whether site-to-site data transfer is allowed for this interconnect attachment resource. Data transfer is available only in [supported locations](https://cloud.google.com/network-connectivity/docs/network-connectivity-center/concepts/locations). Optional lookup argument.
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI of the interconnect attachment resource. Optional lookup argument.
    </ResponseField>
    <ResponseField name="vpc_network" type="string">
      The VPC network where this interconnect attachment is located. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_hop_router_appliance_instance" type="object">
  A route next hop that leads to a Router appliance instance. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="site_to_site_data_transfer" type="bool">
      Indicates whether site-to-site data transfer is allowed for this Router appliance instance resource. Data transfer is available only in [supported locations](https://cloud.google.com/network-connectivity/docs/network-connectivity-center/concepts/locations). Optional lookup argument.
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI of the Router appliance instance. Optional lookup argument.
    </ResponseField>
    <ResponseField name="vpc_network" type="string">
      The VPC network where this VM is located. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_hop_spoke" type="object">
  A route next hop that leads to a spoke resource. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="site_to_site_data_transfer" type="bool">
      Indicates whether site-to-site data transfer is allowed for this spoke resource. Data transfer is available only in [supported locations](https://cloud.google.com/network-connectivity/docs/network-connectivity-center/concepts/locations). Whether this route is accessible to other hybrid spokes with site-to-site data transfer enabled. If this is false, the route is only accessible to VPC spokes of the connected Hub. Optional lookup argument.
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI of the spoke resource. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_hop_vpc_network" type="object">
  The real VPC network this route's own next hop points to. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="uri" type="string">
      The URI of the VPC network resource Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_hop_vpn_tunnel" type="object">
  A route next hop that leads to a VPN tunnel resource. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="site_to_site_data_transfer" type="bool">
      Indicates whether site-to-site data transfer is allowed for this VPN tunnel resource. Data transfer is available only in [supported locations](https://cloud.google.com/network-connectivity/docs/network-connectivity-center/concepts/locations). Optional lookup argument.
    </ResponseField>
    <ResponseField name="uri" type="string">
      The URI of the VPN tunnel resource. Optional lookup argument.
    </ResponseField>
    <ResponseField name="vpc_network" type="string">
      The VPC network where this VPN tunnel is located. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="priority" type="string">
  Output only. The priority of this route. Priority is used to break ties in cases where a destination matches more than one route. In these cases the route with the lowest-numbered priority value wins. Returned by the lookup.
</ResponseField>

<ResponseField name="spoke" type="string">
  Immutable. The spoke that this route leads to. Example: projects/12345/locations/global/spokes/SPOKE Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current lifecycle state of the route. Returned by the lookup.
</ResponseField>

<ResponseField name="type" type="string">
  Output only. The route's type. Its type is determined by the properties of its IP address range. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The Google-generated UUID for the route. This value is unique across all Network Connectivity Center route resources. If a route is deleted and another with the same name is created, the new route is assigned a different `uid`. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the route was last updated. Returned by the lookup.
</ResponseField>

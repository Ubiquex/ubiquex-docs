## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkconnectivity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/networkconnectivity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_networkconnectivity_route_table"})

    		ubx.Data(networkconnectivity.RouteTable, "example", networkconnectivity.RouteTableConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.networkconnectivity import RouteTable, RouteTableConfig

    def describe():
        ubx.intent("look up google_networkconnectivity_route_table")

        ubx.data(RouteTable, "example", RouteTableConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The time the route table was created. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  An optional description of the route table. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional labels in key-value pair format. For more information about labels, see [Requirements for labels](https://cloud.google.com/resource-manager/docs/creating-managing-labels#requirements). Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current lifecycle state of this route table. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The Google-generated UUID for the route table. This value is unique across all route table resources. If a route table is deleted and another with the same name is created, the new route table is assigned a different `uid`. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the route table was last updated. Returned by the lookup.
</ResponseField>

`data_discoveryengine_v1beta_cmek_config` looks up a real customer-managed encryption key configuration for a Discovery Engine data store, via the v1beta API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_discoveryengine_v1beta_cmek_config"})

    		ubx.Data(discoveryengine.V1betaCmekConfig, "example", discoveryengine.V1betaCmekConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

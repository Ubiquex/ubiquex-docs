`google_discoveryengine_v1alpha_project` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="configurable_billing_status" type="object">
  Represents the currently effective configurable billing parameters. These values are derived from the customer's subscription history stored internally and reflect the thresholds actively being used for billing purposes at the time of the GetProject call. This includes the start_time of the subscription and may differ from the values in `customer_provided_config` due to billing rules (e.g., scale-downs taking effect only at the start of a new month). We also include the update type to indicate the type of update performed on the configurable billing configuration in the UpdateProject operation. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="agent_search_token_subscription_statuses" type="list(object)">
      Output only. Per-model Agent Search TPM subscription status. Returned by the lookup.
    </ResponseField>
    <ResponseField name="effective_indexing_core_threshold" type="string">
      Optional. The currently effective Indexing Core threshold. This is the threshold against which Indexing Core usage is compared for overage calculations. Optional lookup argument.
    </ResponseField>
    <ResponseField name="effective_search_qpm_threshold" type="string">
      Optional. The currently effective Search QPM threshold in queries per minute. This is the threshold against which QPM usage is compared for overage calculations. Optional lookup argument.
    </ResponseField>
    <ResponseField name="indexing_core_threshold_next_update_time" type="string">
      Output only. The earliest next update time for the indexing core subscription threshold. This is based on the next_update_time returned by the underlying Cloud Billing Subscription V3 API. This field is populated only if an update indexing core subscription threshold request is succeeded. Returned by the lookup.
    </ResponseField>
    <ResponseField name="search_qpm_threshold_next_update_time" type="string">
      Output only. The earliest next update time for the search QPM subscription threshold. This is based on the next_update_time returned by the underlying Cloud Billing Subscription V3 API. This field is populated only if an update QPM subscription threshold request is succeeded. Returned by the lookup.
    </ResponseField>
    <ResponseField name="start_time" type="string">
      Optional. The start time of the currently active billing subscription. Optional lookup argument.
    </ResponseField>
    <ResponseField name="terminate_time" type="string">
      Output only. The latest terminate effective time of search qpm and indexing core subscriptions. Returned by the lookup.
    </ResponseField>
    <ResponseField name="update_type" type="string">
      Output only. The type of update performed in this operation. This field is populated in the response of UpdateProject. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

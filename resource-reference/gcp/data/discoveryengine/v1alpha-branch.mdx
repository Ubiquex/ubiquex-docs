`google_discoveryengine_v1alpha_branch` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_discoveryengine_v1alpha_branch"})

    		ubx.Data(discoveryengine.V1alphaBranch, "example", discoveryengine.V1alphaBranchConfig{
    			Name: "example",
    			View: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="branch_stats" type="object">
  Statistics describing a branch. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="document_counts" type="map(string)">
      The number of documents in a given branch. The key is a group representing a set of documents, and the value is the number of document in that group. Note: keys in this map may change over time. Supported keys: ['all']. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="display_name" type="string">
  Output only. Human readable name of the branch to display in the UI. Returned by the lookup.
</ResponseField>

<ResponseField name="is_default" type="bool">
  Output only. Indicates whether this branch is set as the default branch of its parent data store. Returned by the lookup.
</ResponseField>

<ResponseField name="last_document_import_time" type="string">
  Output only. Timestamp of last import through DocumentService.ImportDocuments. Empty value means no import has been made to this branch. Returned by the lookup.
</ResponseField>

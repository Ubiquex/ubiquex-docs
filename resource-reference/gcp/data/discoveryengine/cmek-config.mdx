`google_discoveryengine_cmek_config` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	discoveryengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/discoveryengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_discoveryengine_cmek_config"})

    		ubx.Data(discoveryengine.CmekConfig, "example", discoveryengine.CmekConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

## Result properties

<ResponseField name="is_default" type="bool">
  Output only. The default CmekConfig for the Customer. Returned by the lookup.
</ResponseField>

<ResponseField name="kms_key" type="string">
  Required. KMS key resource name which will be used to encrypt resources `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyRing&#125;/cryptoKeys/&#123;keyId&#125;`. Returned by the lookup.
</ResponseField>

<ResponseField name="kms_key_version" type="string">
  Output only. KMS key version resource name which will be used to encrypt resources `/cryptoKeyVersions/&#123;keyVersion&#125;`. Returned by the lookup.
</ResponseField>

<ResponseField name="last_rotation_timestamp_micros" type="string">
  Output only. The timestamp of the last key rotation. Returned by the lookup.
</ResponseField>

<ResponseField name="notebooklm_state" type="string">
  Output only. Whether the NotebookLM Corpus is ready to be used. Returned by the lookup.
</ResponseField>

<ResponseField name="single_region_keys" type="list(object)">
  Optional. Single-regional CMEKs that are required for some VAIS features. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The states of the CmekConfig. Returned by the lookup.
</ResponseField>

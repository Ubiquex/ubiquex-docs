## Example

    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_vmwareengine_announcement"})

    		ubx.Data(vmwareengine.Announcement, "example", vmwareengine.AnnouncementConfig{
    			Name: "example",
    		})
    	}))
    }

## Result properties

<ResponseField name="activity_type" type="string">
  Optional. Activity type of the announcement There can be only one active announcement for a given activity type and target resource. Returned by the lookup.
</ResponseField>

<ResponseField name="cluster" type="string">
  A Cluster resource name. Returned by the lookup.
</ResponseField>

<ResponseField name="code" type="string">
  Required. Code of the announcement. Indicates the presence of a VMware Engine related announcement and corresponds to a related message in the `description` field. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">

</ResponseField>

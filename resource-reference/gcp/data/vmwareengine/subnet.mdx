## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmwareengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/vmwareengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_vmwareengine_subnet"})

    		ubx.Data(vmwareengine.Subnet, "example", vmwareengine.SubnetConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="gateway_ip" type="string">
  The IP address of the gateway of this subnet. Must fall within the IP prefix defined above. Returned by the lookup.
</ResponseField>

<ResponseField name="ip_cidr_range" type="string">
  The IP address range of the subnet in CIDR format '10.0.0.0/24'. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="type" type="string">
  Output only. The type of the subnet. For example "management" or "userDefined". Returned by the lookup.
</ResponseField>

<ResponseField name="vlan_id" type="number">
  Output only. VLAN ID of the VLAN on which the subnet is configured Returned by the lookup.
</ResponseField>

## Result properties

<ResponseField name="available_custom_core_counts" type="list(number)">
  Output only. List of possible values of custom core count. Returned by the lookup.
</ResponseField>

<ResponseField name="capabilities" type="list(string)">
  Output only. Capabilities of this node type. Returned by the lookup.
</ResponseField>

<ResponseField name="disk_size_gb" type="number">
  Output only. The amount of storage available, defined in GB. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Output only. The friendly name for this node type. For example: ve1-standard-72 Returned by the lookup.
</ResponseField>

<ResponseField name="families" type="list(string)">
  Output only. Families of the node type. For node types to be in the same cluster they must share at least one element in the `families`. Returned by the lookup.
</ResponseField>

<ResponseField name="kind" type="string">
  Output only. The type of the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="memory_gb" type="number">
  Output only. The amount of physical memory available, defined in GB. Returned by the lookup.
</ResponseField>

<ResponseField name="node_type_id" type="string">
  Output only. The canonical identifier of the node type (corresponds to the `NodeType`). For example: standard-72. Returned by the lookup.
</ResponseField>

<ResponseField name="total_core_count" type="number">
  Output only. The total number of CPU cores in a single node. Returned by the lookup.
</ResponseField>

<ResponseField name="virtual_cpu_count" type="number">
  Output only. The total number of virtual CPUs in a single node. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	deploymentmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/deploymentmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_deploymentmanager_v2beta_manifest"})

    		ubx.Data(deploymentmanager.V2betaManifest, "example", deploymentmanager.V2betaManifestConfig{
    			Deployment:                "example",
    			Manifest:                  "example",
    			Project:                   "example",
    			HeaderBypassBillingFilter: true,
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="deployment" type="string" required>
  The real deployment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="header_bypass_billing_filter" type="bool">
  Whether the request bypasses billing-related filtering via a special header. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="manifest" type="string" required>
  The real, expanded manifest describing this deployment's own resources. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

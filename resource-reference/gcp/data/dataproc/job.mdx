## Lookup arguments

<ResponseField name="job_id" type="string" required>
  The real, unique identifier of the job this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project_id" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="region" type="string" required>
  The real Google Cloud region this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="done" type="bool">
  Output only. Indicates whether the job is completed. If the value is false, the job is still in progress. If true, the job is completed, and status.state field will indicate if it was successful, failed, or cancelled. Returned by the lookup.
</ResponseField>

<ResponseField name="driver_control_files_uri" type="string">
  Output only. If present, the location of miscellaneous control files which can be used as part of job setup and handling. If not present, control files might be placed in the same location as driver_output_uri. Returned by the lookup.
</ResponseField>

<ResponseField name="driver_output_resource_uri" type="string">
  Output only. A URI pointing to the location of the stdout of the job's driver program. Returned by the lookup.
</ResponseField>

<ResponseField name="driver_scheduling_config" type="object">
  Driver scheduling configuration. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="memory_mb" type="number">
      Required. The amount of memory in MB the driver is requesting. Optional lookup argument.
    </ResponseField>
    <ResponseField name="vcores" type="number">
      Required. The number of vCPUs the driver is requesting. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

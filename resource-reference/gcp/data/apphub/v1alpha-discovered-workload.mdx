---
title: "google_apphub_v1alpha_discovered_workload"
description: "`data_apphub_v1alpha_discovered_workload` looks up a real, already-existing `google_apphub_workload`."
---

It registers an underlying Google Cloud resource (e.g. a GKE deployment or Compute Engine instance group) as a discoverable compute workload within an App Hub application.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apphub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apphub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apphub_v1alpha_discovered_workload"})

    		ubx.Data(apphub.V1alphaDiscoveredWorkload, "example", apphub.V1alphaDiscoveredWorkloadConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { V1alphaDiscoveredWorkload } from "@ubx/sdk-google/google/data/apphub/v1alpha_discovered_workload";

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.apphub import V1alphaDiscoveredWorkload, V1alphaDiscoveredWorkloadConfig

    def describe():
        ubx.intent("look up google_apphub_v1alpha_discovered_workload")

        ubx.data(V1alphaDiscoveredWorkload, "example", V1alphaDiscoveredWorkloadConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="workload_properties" type="object">
  Properties of an underlying compute resource represented by the Workload. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="extended_metadata" type="map(object)">
      Output only. Additional metadata specific to the resource type. The key is a string that identifies the type of metadata and the value is the metadata contents specific to that type. Key format: `apphub.googleapis.com/&#123;metadataType&#125;` Returned by the lookup.
    </ResponseField>
    <ResponseField name="functional_type" type="object">
      The functional type of a service or workload. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Output only. The functional type of a service or workload. Returned by the lookup.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="gcp_project" type="string">
      Output only. The service project identifier that the underlying cloud resource resides in. Empty for non-cloud resources. Returned by the lookup.
    </ResponseField>
    <ResponseField name="identity" type="object">
      The identity associated with a service or workload. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="principal" type="string">
          Output only. The principal of the identity. Supported formats: * `sa://my-sa@PROJECT_ID.iam.gserviceaccount.com` for GCP Service Account * `principal://POOL_ID.global.PROJECT_NUMBER.workload.id.goog/ns/NAMESPACE_ID/sa/MANAGED_IDENTITY_ID` for Managed Workload Identity Returned by the lookup.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="location" type="string">
      Output only. The location that the underlying compute resource resides in (for example, us-west1). Returned by the lookup.
    </ResponseField>
    <ResponseField name="zone" type="string">
      Output only. The location that the underlying compute resource resides in if it is zonal (for example, us-west1-a). Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="workload_reference" type="object">
  Reference of an underlying compute resource represented by the Workload. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="uri" type="string">
      Output only. The underlying compute resource uri. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "google_apphub_discovered_service"
description: "`data_apphub_discovered_service` looks up a real, already-existing `google_apphub_service`."
---

It registers an underlying Google Cloud resource (e.g. a load balancer) as a discoverable network-facing service within an App Hub application.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apphub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apphub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apphub_discovered_service"})

    		ubx.Data(apphub.DiscoveredService, "example", apphub.DiscoveredServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { DiscoveredService } from "@ubx/sdk-google/google/data/apphub/discovered_service";

    export default stack("example", () => {
      intent({ summary: "look up google_apphub_discovered_service" });

      data(DiscoveredService, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.apphub import DiscoveredService, DiscoveredServiceConfig

    def describe():
        ubx.intent("look up google_apphub_discovered_service")

        ubx.data(DiscoveredService, "example", DiscoveredServiceConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="service_properties" type="object">
  Properties of an underlying cloud resource that can comprise a Service. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="extended_metadata" type="map(object)">
      Output only. Additional metadata specific to the resource type. The key is a string that identifies the type of metadata and the value is the metadata contents specific to that type. Key format: `apphub.googleapis.com/&#123;metadataType&#125;` Returned by the lookup.
    </ResponseField>
    <ResponseField name="functional_type" type="object">
      The functional type of a service or workload. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Output only. The functional type of a service or workload. Returned by the lookup.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="gcp_project" type="string">
      Output only. The service project identifier that the underlying cloud resource resides in. Returned by the lookup.
    </ResponseField>
    <ResponseField name="identity" type="object">
      The identity associated with a service or workload. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="principal" type="string">
          Output only. The principal of the identity. Supported formats: * `sa://my-sa@PROJECT_ID.iam.gserviceaccount.com` for GCP Service Account * `principal://POOL_ID.global.PROJECT_NUMBER.workload.id.goog/ns/NAMESPACE_ID/sa/MANAGED_IDENTITY_ID` for Managed Workload Identity Returned by the lookup.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="location" type="string">
      Output only. The location that the underlying resource resides in, for example, us-west1. Returned by the lookup.
    </ResponseField>
    <ResponseField name="registration_type" type="object">
      The registration type of a service. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="type" type="string">
          Output only. The registration type of a service. Returned by the lookup.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="zone" type="string">
      Output only. The location that the underlying resource resides in if it is zonal, for example, us-west1-a). Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_reference" type="object">
  Reference to an underlying networking resource that can comprise a Service. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="uri" type="string">
      Output only. The underlying resource URI. For example, URI of Forwarding Rule, URL Map, and Backend Service. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

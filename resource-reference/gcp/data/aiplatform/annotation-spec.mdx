## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="read_mask" type="string">
  The real field mask restricting which fields are returned in the response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this AnnotationSpec was created. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The user-defined name of the AnnotationSpec. The name can be up to 128 characters long and can consist of any UTF-8 characters. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when AnnotationSpec was last updated. Returned by the lookup.
</ResponseField>

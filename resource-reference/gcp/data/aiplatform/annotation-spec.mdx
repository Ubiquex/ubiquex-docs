`google_aiplatform_annotation_spec` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_aiplatform_annotation_spec"})

    		ubx.Data(aiplatform.AnnotationSpec, "example", aiplatform.AnnotationSpecConfig{
    			Name:     "example",
    			ReadMask: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this AnnotationSpec was created. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The user-defined name of the AnnotationSpec. The name can be up to 128 characters long and can consist of any UTF-8 characters. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Optional. Used to perform consistent read-modify-write updates. If not set, a blind "overwrite" update happens. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when AnnotationSpec was last updated. Returned by the lookup.
</ResponseField>

---
title: "google_aiplatform_nas_trial_detail"
description: "`data_aiplatform_nas_trial_detail` looks up a real, already-existing `google_aiplatform_trial`."
---

It is a single parameter combination evaluated as part of a Vertex AI Vizier study or hyperparameter tuning job, recording the parameter values tried and the resulting objective metric value.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_aiplatform_nas_trial_detail"})

    		ubx.Data(aiplatform.NasTrialDetail, "example", aiplatform.NasTrialDetailConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { NasTrialDetail } from "@ubx/sdk-google/google/data/aiplatform/nas_trial_detail";

    export default stack("example", () => {
      intent({ summary: "look up google_aiplatform_nas_trial_detail" });

      data(NasTrialDetail, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.aiplatform import NasTrialDetail, NasTrialDetailConfig

    def describe():
        ubx.intent("look up google_aiplatform_nas_trial_detail")

        ubx.data(NasTrialDetail, "example", NasTrialDetailConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Result properties

<ResponseField name="parameters" type="string">
  The parameters for the NasJob NasTrial. Returned by the lookup.
</ResponseField>

<ResponseField name="search_trial" type="object">
  Represents a uCAIP NasJob trial. Returned by the lookup.
  <Expandable title="properties">

    <ResponseField name="final_measurement" type="object">
      A message representing a Measurement of a Trial. A Measurement contains the Metrics got by executing a Trial using suggested hyperparameter values. Optional lookup argument.
      <Expandable title="properties">

          Output only. A list of metrics got by evaluating the objective functions using suggested Parameter values. Returned by the lookup.

          Output only. The number of steps the machine learning model has been trained for. Must be non-negative. Returned by the lookup.

---
title: "google_aiplatform_v1beta1_analyzed_session"
description: "`data_aiplatform_v1beta1_analyzed_session` looks up a real, already-existing `google_aiplatform_session`."
---

It is a single, stateful conversation between a user and an agent deployed on Vertex AI Agent Engine, holding the chronological sequence of message(s) and action(s) exchanged during that interaction.

## Example

    ```go

    import (

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="view" type="string">
  The real, requested view (which fields to include) of this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="agent_display_name" type="string">
  Output only. The human-readable display name of the MonitoredAgent that owns this session. May be empty when the session's agent is not enrolled as a MonitoredAgent; the `agent_resource_name` is always present and can be used as a fallback identifier. Returned by the lookup.
</ResponseField>

<ResponseField name="agent_resource_name" type="string">
  Output only. The resource name or identifier of the agent that ran this session. Matches `AgentResource.agent` on the corresponding `MonitoredAgent`, so the format depends on that agent's `AgentResource.agent_type`: * `REASONING_ENGINE`: `projects/&#123;project&#125;/locations/&#123;location&#125;/reasoningEngines/&#123;reasoning_engine&#125;` * `CLOUD_RUN_SERVICE`, `GKE_WORKLOAD`, `GCE_INSTANCE`: the resource name of the agent's runtime. * `AGENT_TYPE_OTHER`: a stable identifier for the agent. Returned by the lookup.
</ResponseField>

<ResponseField name="agent_state" type="string">
  Output only. The current enablement state of the MonitoredAgent that owns this session (for example, ACTIVE, DISABLED, or ENABLING). Defaults to ENABLEMENT_STATE_UNSPECIFIED when the agent is not enrolled or its state is unknown. Returned by the lookup.
</ResponseField>

<ResponseField name="agent_type" type="string">
  Output only. The runtime that the agent which ran this session is hosted on (for example, `CLOUD_RUN_SERVICE`). `AGENT_TYPE_UNSPECIFIED` means the runtime is unknown to this service -- the agent is not enrolled as a `MonitoredAgent`, or was enrolled before its runtime was recorded. That is distinct from `AGENT_TYPE_OTHER`, which means the runtime is known and is not one of the enumerated Google Cloud runtimes. Returned by the lookup.
</ResponseField>

<ResponseField name="assessment" type="object">
  Contains the detailed assessment for an analyzed session. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="detector_findings" type="list(object)">
      The list of detector findings. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation time of the session. Returned by the lookup.
</ResponseField>

<ResponseField name="latest_analyzed_time" type="string">
  Output only. The latest analyzed time of the session. Returned by the lookup.
</ResponseField>

<ResponseField name="location" type="string">
  Output only. The Google Cloud location (region) of the agent that ran this session (for example, `us-central1`). Empty when the agent is not enrolled or its location is unknown. Returned by the lookup.
</ResponseField>

<ResponseField name="session_id" type="string">
  Output only. The session ID. Returned by the lookup.
</ResponseField>

<ResponseField name="session_state" type="string">
  Output only. The state of the session. Returned by the lookup.
</ResponseField>

<ResponseField name="severities" type="map(object)">
  Output only. Map of severity counts for listing analyzed sessions. The key is the string representation of Severity. Populated in BASIC view only. Returned by the lookup.
</ResponseField>

<ResponseField name="user_id" type="string">
  Output only. The user ID. Returned by the lookup.
</ResponseField>

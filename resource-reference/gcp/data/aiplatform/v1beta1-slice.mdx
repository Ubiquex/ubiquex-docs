`google_aiplatform_v1beta1_slice` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this ModelEvaluationSlice was created. Returned by the lookup.
</ResponseField>

<ResponseField name="metrics" type="any">
  Output only. Sliced evaluation metrics of the Model. The schema of the metrics is stored in metrics_schema_uri Returned by the lookup.
</ResponseField>

<ResponseField name="metrics_schema_uri" type="string">
  Output only. Points to a YAML file stored on Google Cloud Storage describing the metrics of this ModelEvaluationSlice. The schema is defined as an OpenAPI 3.0.2 [Schema Object](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.0.2.md#schemaObject). Returned by the lookup.
</ResponseField>

<ResponseField name="model_explanation" type="object">
  Aggregated explanation metrics for a Model over a set of instances. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="mean_attributions" type="list(object)">
      Output only. Aggregated attributions explaining the Model's prediction outputs over the set of instances. The attributions are grouped by outputs. For Models that predict only one output, such as regression Models that predict only one score, there is only one attibution that explains the predicted output. For Models that predict multiple outputs, such as multiclass Models that predict multiple classes, each element explains one specific item. Attribution.output_index can be used to identify which output this attribution is explaining. The baselineOutputValue, instanceOutputValue and featureAttributions fields are averaged over the test data. NOTE: Currently AutoML tabular classification Models produce only one attribution, which averages attributions over all the classes it predicts. Attribution.approximation_error is not populated. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="slice" type="object">
  Definition of a slice. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="dimension" type="string">
      Output only. The dimension of the slice. Well-known dimensions are: * `annotationSpec`: This slice is on the test data that has either ground truth or prediction with AnnotationSpec.display_name equals to value. * `slice`: This slice is a user customized slice defined by its SliceSpec. Returned by the lookup.
    </ResponseField>
    <ResponseField name="slice_spec" type="object">
      Specification for how the data should be sliced. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="configs" type="map(object)">
          Mapping configuration for this SliceSpec. The key is the name of the feature. By default, the key will be prefixed by "instance" as a dictionary prefix for Vertex Batch Predictions output format. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="value" type="string">
      Output only. The value of the dimension in this slice. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

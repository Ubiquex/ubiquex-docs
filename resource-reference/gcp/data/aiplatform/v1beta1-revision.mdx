## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="create_time" type="string">
  Output only. Represents the timestamp when this Memory Revision was created. Returned by the lookup.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. Represents the timestamp of when this resource is considered expired. Returned by the lookup.
</ResponseField>

<ResponseField name="extracted_memories" type="list(object)">
  Output only. Represents the extracted memories from the source content before consolidation when the memory was updated via GenerateMemories. This information was used to modify an existing Memory via Consolidation. Returned by the lookup.
</ResponseField>

<ResponseField name="fact" type="string">
  Output only. Represents the fact of the Memory Revision. This corresponds to the `fact` field of the parent Memory at the time of revision creation. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Output only. Represents the labels of the Memory Revision. These labels are applied to the MemoryRevision when it is created based on `GenerateMemoriesRequest.revision_labels`. Returned by the lookup.
</ResponseField>

<ResponseField name="structured_data" type="map(any)">
  Output only. Represents the structured value of the memory at the time of revision creation. Returned by the lookup.
</ResponseField>

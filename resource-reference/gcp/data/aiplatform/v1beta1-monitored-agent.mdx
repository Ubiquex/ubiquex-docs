---
title: "google_aiplatform_v1beta1_monitored_agent"
description: "`data_aiplatform_v1beta1_monitored_agent` looks up a real, already-existing `google_aiplatform_agent`."
---

It registers a deployable AI agent within Vertex AI's Agent Builder surface (now documented under the Gemini Enterprise Agent Platform), the unit an Agent Engine deployment or the Agent Studio low-code builder operates on.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	aiplatform "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/aiplatform"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_aiplatform_v1beta1_monitored_agent"})

    		ubx.Data(aiplatform.V1beta1MonitoredAgent, "example", aiplatform.V1beta1MonitoredAgentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="agent_resource" type="object">
  Defines the identity of an agent being monitored. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="agent" type="string">
      Required. The resource name or identifier of the agent to monitor. The format depends on `agent_type`: * `REASONING_ENGINE`: `projects/&#123;project&#125;/locations/&#123;location&#125;/reasoningEngines/&#123;reasoning_engine&#125;` * `CLOUD_RUN_SERVICE`, `GKE_WORKLOAD`, `GCE_INSTANCE`: the resource name of the agent's runtime. * `AGENT_TYPE_OTHER`: a stable identifier for the agent. Optional lookup argument.
    </ResponseField>
    <ResponseField name="agent_framework" type="string">
      Optional. The framework used to build the agent, orthogonal to the runtime `agent_type`. Optional lookup argument.
    </ResponseField>
    <ResponseField name="agent_type" type="string">
      Required. The runtime type of the agent. Optional lookup argument.
    </ResponseField>
    <ResponseField name="location" type="string">
      Output only. The Google Cloud location (region) of the agent resource (for example, `us-central1`). Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the MonitoredAgent was created. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. The display name of the MonitoredAgent. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the agent's enablement. Returned by the lookup.
</ResponseField>

<ResponseField name="status_message" type="string">
  Output only. A brief message explaining the current state. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the MonitoredAgent was last updated. Returned by the lookup.
</ResponseField>

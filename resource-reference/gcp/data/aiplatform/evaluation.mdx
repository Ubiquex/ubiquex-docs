## Result properties

<ResponseField name="annotation_schema_uri" type="string">
  Points to a YAML file stored on Google Cloud Storage describing EvaluatedDataItemView.predictions, EvaluatedDataItemView.ground_truths, EvaluatedAnnotation.predictions, and EvaluatedAnnotation.ground_truths. The schema is defined as an OpenAPI 3.0.2 [Schema Object](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.0.2.md#schemaObject). This field is not populated if there are neither EvaluatedDataItemViews nor EvaluatedAnnotations under this ModelEvaluation. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Timestamp when this ModelEvaluation was created. Returned by the lookup.
</ResponseField>

<ResponseField name="data_item_schema_uri" type="string">
  Points to a YAML file stored on Google Cloud Storage describing EvaluatedDataItemView.data_item_payload and EvaluatedAnnotation.data_item_payload. The schema is defined as an OpenAPI 3.0.2 [Schema Object](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.0.2.md#schemaObject). This field is not populated if there are neither EvaluatedDataItemViews nor EvaluatedAnnotations under this ModelEvaluation. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  The display name of the ModelEvaluation. Returned by the lookup.
</ResponseField>

<ResponseField name="explanation_specs" type="list(object)">
  Describes the values of ExplanationSpec that are used for explaining the predicted values on the evaluated data. Returned by the lookup.
</ResponseField>

<ResponseField name="metadata" type="any">
  The metadata of the ModelEvaluation. For the ModelEvaluation uploaded from Managed Pipeline, metadata contains a structured value with keys of "pipeline_job_id", "evaluation_dataset_type", "evaluation_dataset_path", "row_based_metrics_path". Returned by the lookup.
</ResponseField>

<ResponseField name="metrics" type="any">
  Evaluation metrics of the Model. The schema of the metrics is stored in metrics_schema_uri Returned by the lookup.
</ResponseField>

<ResponseField name="metrics_schema_uri" type="string">
  Points to a YAML file stored on Google Cloud Storage describing the metrics of this ModelEvaluation. The schema is defined as an OpenAPI 3.0.2 [Schema Object](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.0.2.md#schemaObject). Returned by the lookup.
</ResponseField>

<ResponseField name="model_explanation" type="object">
  Aggregated explanation metrics for a Model over a set of instances. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="mean_attributions" type="list(object)">
      Output only. Aggregated attributions explaining the Model's prediction outputs over the set of instances. The attributions are grouped by outputs. For Models that predict only one output, such as regression Models that predict only one score, there is only one attibution that explains the predicted output. For Models that predict multiple outputs, such as multiclass Models that predict multiple classes, each element explains one specific item. Attribution.output_index can be used to identify which output this attribution is explaining. The baselineOutputValue, instanceOutputValue and featureAttributions fields are averaged over the test data. NOTE: Currently AutoML tabular classification Models produce only one attribution, which averages attributions over all the classes it predicts. Attribution.approximation_error is not populated. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="slice_dimensions" type="list(string)">
  All possible dimensions of ModelEvaluationSlices. The dimensions can be used as the filter of the ModelService.ListModelEvaluationSlices request, in the form of `slice.dimension = `. Returned by the lookup.
</ResponseField>

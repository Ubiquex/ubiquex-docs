---
title: "google_aiplatform_v1beta1_feature_view_sync"
description: "`data_aiplatform_v1beta1_feature_view_sync` looks up a real, already-existing `google_aiplatform_feature_view`."
---

It defines which feature(s), from which feature group(s), are synced into a specific Vertex AI Feature Online Store for serving.

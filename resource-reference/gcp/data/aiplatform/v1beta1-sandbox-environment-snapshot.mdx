title: "google_aiplatform_v1beta1_sandbox_environment_snapshot"

It is an isolated, managed execution environment Vertex AI Agent Engine's Code Execution capability runs caller- or agent-generated code inside, so it can't affect anything outside its own sandbox.

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this SandboxEnvironmentSnapshot was created. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The display name of the SandboxEnvironmentSnapshot. Returned by the lookup.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Optional. Timestamp in UTC of when this SandboxEnvironmentSnapshot is considered expired. This is *always* provided on output, regardless of what `expiration` was sent on input. Returned by the lookup.
</ResponseField>

<ResponseField name="owner" type="string">
  Optional. Owner information for this sandbox snapshot. Different owners will have isolations on snapshot storage and identity. If not set, snapshot will be created as the default owner. Returned by the lookup.
</ResponseField>

<ResponseField name="parent_snapshot" type="string">
  Output only. The resource name of the parent SandboxEnvironmentSnapshot. Empty if this is a root Snapshot (the first snapshot from a newly created sandbox). Can be used to reconstruct the whole ancestry tree of snapshots. Returned by the lookup.
</ResponseField>

<ResponseField name="post_snapshot_action" type="string">
  Optional. Input only. Action to take on the source SandboxEnvironment after the snapshot is taken. This field is only used in CreateSandboxEnvironmentSnapshotRequest and it is not stored in the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="size_bytes" type="string">
  Optional. Output only. Size of the snapshot data in bytes. Returned by the lookup.
</ResponseField>

<ResponseField name="source_sandbox_environment" type="string">
  Required. The resource name of the source SandboxEnvironment this snapshot was taken from. Returned by the lookup.
</ResponseField>

<ResponseField name="ttl" type="string">
  Optional. Input only. The TTL for the sandbox environment snapshot. The expiration time is computed: now + TTL. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when this SandboxEnvironment was most recently updated. Returned by the lookup.
</ResponseField>

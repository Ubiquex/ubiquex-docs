---
title: "google_documentai_processor_version"
description: "`data_documentai_processor_version` looks up a real, already-existing `google_documentai_processor`."
---

It is a Document AI processor instance -- a specific document-parsing model (e.g. invoice or form parser) -- that document(s) are sent to for extraction.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	documentai "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/documentai"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_documentai_processor_version"})

    		ubx.Data(documentai.ProcessorVersion, "example", documentai.ProcessorVersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    ```

  </Tab>
  <Tab title="Python">

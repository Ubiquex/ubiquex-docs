---
title: "google_vmmigration_v1alpha1_image_import_job"
description: "`data_vmmigration_v1alpha1_image_import_job` looks up a real, already-existing `google_vmmigration_image_import`."
---

It imports a real, existing disk image into VM Migration's own managed image format, a source for creating migrated VMs from an image rather than from a live, running source VM.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmmigration "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/vmmigration"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_vmmigration_v1alpha1_image_import_job"})

    		ubx.Data(vmmigration.V1alpha1ImageImportJob, "example", vmmigration.V1alpha1ImageImportJobConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

---
title: "google_compute_beta_snapshot_setting"
description: "`data_compute_beta_snapshot_setting` looks up a real, already-existing `google_compute_beta_snapshot`."
---

It is a real, durable, incremental point-in-time backup of a persistent disk, storable and restorable across zones and regions -- the standard mechanism for real disk backup and disaster recovery.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_compute_beta_snapshot_setting"})

    		ubx.Data(compute.BetaSnapshotSetting, "example", compute.BetaSnapshotSettingConfig{
    			Project: "example",
    		})
    	}))
    }
    ```

    </ResponseField>

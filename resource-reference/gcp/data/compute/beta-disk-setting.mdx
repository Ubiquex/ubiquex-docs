---
title: "google_compute_beta_disk_setting"
description: "`data_compute_beta_disk_setting` looks up a real, already-existing `google_compute_beta_disk`."
---

It is a zonal persistent block storage volume attached to a Compute Engine instance -- the real, durable storage a VM's own root filesystem or extra data volumes actually live on, independent of the instance's own lifecycle.

## Lookup arguments

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="zone" type="string" required>
  The real Google Cloud zone this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="access_location" type="object">
  AccessLocation is only used for regional snapshot. It contains which regions are allowed to create a regional snapshot from disks located in the given region/zone. It includes key-value pairs designed to store the following structure. The keys should match their corresponding values, which must be provided: access_location: &#123; locations &#123; us-central1 &#123; region: "us-central1" &#125;, asia-west2 &#123; region: "asia-west2" &#125; &#125; &#125; Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="locations" type="map(object)">
      List of regions that can create a regional snapshot from the current region Optional lookup argument.
    </ResponseField>
    <ResponseField name="policy" type="string">
      Policy of which location is allowed to access snapshot. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

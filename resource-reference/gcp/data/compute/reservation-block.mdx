---
title: "google_compute_reservation_block"
description: "`data_compute_reservation_block` looks up a real, already-existing `google_compute_alpha_reservation`."
---

It sets aside real compute capacity -- a specific machine type and count, in a specific zone -- guaranteeing it's actually available for your own VMs to consume, rather than competing for capacity with every other customer at boot time.

## Lookup arguments

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="reservation" type="string" required>
  The real capacity reservation this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="reservation_block" type="string" required>
  The real reservation block this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="view" type="string">
  The real, requested view (which fields to include) of this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="zone" type="string" required>
  The real Google Cloud zone this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

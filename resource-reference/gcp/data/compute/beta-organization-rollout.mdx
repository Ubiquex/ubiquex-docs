## Lookup arguments

<ResponseField name="organization" type="string" required>
  The real Google Cloud organization this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="rollout" type="string" required>
  The real, in-progress or completed rollout this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

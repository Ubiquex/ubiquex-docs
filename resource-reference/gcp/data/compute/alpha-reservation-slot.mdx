---
title: "google_compute_alpha_reservation_slot"
description: "`data_compute_alpha_reservation_slot` looks up a real, already-existing `google_compute_alpha_reservation`."
---

It sets aside real compute capacity -- a specific machine type and count, in a specific zone -- guaranteeing it's actually available for your own VMs to consume, rather than competing for capacity with every other customer at boot time.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_compute_alpha_reservation_slot"})

    		ubx.Data(compute.AlphaReservationSlot, "example", compute.AlphaReservationSlotConfig{
    			ParentName:      "example-parent-name",
    			Project:         "example",
    			ReservationSlot: "example",
    			Zone:            "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="parent_name" type="string" required>
  The real, fully-qualified resource name of this object's own parent. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="reservation_slot" type="string" required>
  The real reservation slot this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="zone" type="string" required>
  The real Google Cloud zone this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

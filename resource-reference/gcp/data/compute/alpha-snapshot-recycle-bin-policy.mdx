`data_compute_alpha_snapshot_recycle_bin_policy` looks up a real, project-level policy controlling how deleted Compute Engine snapshots are retained in the recycle bin, via the Alpha API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_compute_alpha_snapshot_recycle_bin_policy"})

    		ubx.Data(compute.AlphaSnapshotRecycleBinPolicy, "example", compute.AlphaSnapshotRecycleBinPolicyConfig{
    			Project: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="rules" type="map(object)">
  The rules for the snapshot recycle bin policy. The key is either 'default' or namespacedName of the TagValue which can be in the format: `&#123;organization_id&#125;/&#123;tag_key_short_name&#125;/&#123;tag_value_short_name&#125;` or `&#123;project_id&#125;/&#123;tag_key_short_name&#125;/&#123;tag_value_short_name&#125;` or `&#123;project_number&#125;/&#123;tag_key_short_name&#125;/&#123;tag_value_short_name&#125;`. The default rule is applied if snapshots do not have any of these tags. The value is the rule for the key. Returned by the lookup.
</ResponseField>

<ResponseField name="system_rules" type="map(object)">
  Output only. The system rules for snapshot recycle bin policy. Defines the default rule that applies if no customer-defined rule matches. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_compute_alpha_project"})

    		ubx.Data(compute.AlphaProject, "example", compute.AlphaProjectConfig{
    			Project: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="cloud_armor_tier" type="string">
  Output only. [Output Only] The Cloud Armor tier for this project. It can be one of the following values: CA_STANDARD,CA_ENTERPRISE_PAYGO. If this field is not specified, it is assumed to beCA_STANDARD. Returned by the lookup.
</ResponseField>

<ResponseField name="common_instance_metadata" type="object">
  A metadata key/value entry. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="fingerprint" type="string">
      Specifies a fingerprint for this request, which is essentially a hash of the metadata's contents and used for optimistic locking. The fingerprint is initially generated by Compute Engine and changes after every request to modify or update metadata. You must always provide an up-to-date fingerprint hash in order to update or change metadata, otherwise the request will fail with error412 conditionNotMet. To see the latest fingerprint, make a get() request to retrieve the resource. Optional lookup argument.
    </ResponseField>
    <ResponseField name="items" type="list(object)">
      Array of key/value pairs. The total size of all keys and values must be less than 512 KB. Optional lookup argument.
    </ResponseField>
    <ResponseField name="kind" type="string">
      Output only. [Output Only] Type of the resource. Always compute#metadata for metadata. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="creation_timestamp" type="string">
  [Output Only] Creation timestamp inRFC3339 text format. Returned by the lookup.
</ResponseField>

<ResponseField name="default_network_tier" type="string">
  This signifies the default network tier used for configuring resources of the project and can only take the following values:PREMIUM, STANDARD. Initially the default network tier is PREMIUM. Returned by the lookup.
</ResponseField>

<ResponseField name="default_service_account" type="string">
  [Output Only] Default service account used by VMs running in this project. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  An optional textual description of the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="enabled_features" type="list(string)">
  An optional list of restricted features enabled for use on this project. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  [Output Only] The unique identifier for the resource. This identifier is defined by the server. This is *not* the project ID, and is just a unique ID used by Compute Engine to identify resources. Returned by the lookup.
</ResponseField>

<ResponseField name="kind" type="string">
  Output only. [Output Only] Type of the resource. Always compute#project for projects. Returned by the lookup.
</ResponseField>

<ResponseField name="managed_protection_tier" type="string">
  Output only. [Output Only] The Cloud Armor Managed Protection (CAMP) tier for this project. It can be one of the following values:CA_STANDARD, CAMP_PLUS_PAYGO. If this field is not specified, it is assumed to beCA_STANDARD. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The project ID. For example: my-example-project. Use the project ID to make requests to Compute Engine. Returned by the lookup.
</ResponseField>

<ResponseField name="quotas" type="list(object)">
  [Output Only] Quotas assigned to this project. Returned by the lookup.
</ResponseField>

<ResponseField name="self_link" type="string">
  [Output Only] Server-defined URL for the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="usage_export_location" type="object">
  The location in Cloud Storage and naming method of the daily usage report. Contains bucket_name and report_name prefix. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="bucket_name" type="string">
      The name of an existing bucket in Cloud Storage where the usage report object is stored. The Google Service Account is granted write access to this bucket. This can either be the bucket name by itself, such asexample-bucket, or the bucket name with gs:// or https://storage.googleapis.com/ in front of it, such as gs://example-bucket. Optional lookup argument.
    </ResponseField>
    <ResponseField name="report_name_prefix" type="string">
      An optional prefix for the name of the usage report object stored inbucketName. If not supplied, defaults tousage_gce. The report is stored as a CSV file namedreport_name_prefix_gce_YYYYMMDD.csv whereYYYYMMDD is the day of the usage according to Pacific Time. If you supply a prefix, it should conform to Cloud Storageobject naming conventions. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vm_dns_setting" type="string">
  Output only. [Output Only] Default internal DNS setting used by VMs running in this project. Returned by the lookup.
</ResponseField>

<ResponseField name="xpn_project_status" type="string">
  [Output Only] The role this project has in a shared VPC configuration. Currently, only projects with the host role, which is specified by the value HOST, are differentiated. Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="preview_feature" type="string" required>
  The real Compute Engine preview feature this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

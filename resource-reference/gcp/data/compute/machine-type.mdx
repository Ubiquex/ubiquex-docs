## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	compute "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/compute"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_compute_machine_type"})

    		ubx.Data(compute.MachineType, "example", compute.MachineTypeConfig{
    			MachineType: "example",
    			Project:     "example",
    			Zone:        "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="machine_type" type="string" required>
  The real Compute Engine machine type this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="zone" type="string" required>
  The real Google Cloud zone this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

---
title: "google_config_resource_drift"
description: "`data_config_resource_drift` looks up a real, detected drift between a resource's own live state and its Infrastructure Manager-declared configuration."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	config "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/config"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_config_resource_drift"})

    		ubx.Data(config.ResourceDrift, "example", config.ResourceDriftConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { ResourceDrift } from "@ubx/sdk-google/google/data/config/resource_drift";

    export default stack("example", () => {
      intent({ summary: "look up google_config_resource_drift" });

      data(ResourceDrift, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.config import ResourceDrift, ResourceDriftConfig

    def describe():
        ubx.intent("look up google_config_resource_drift")

        ubx.data(ResourceDrift, "example", ResourceDriftConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="property_drifts" type="list(object)">
  Output only. The property drifts of the resource drift. Returned by the lookup.
</ResponseField>

<ResponseField name="terraform_info" type="object">
  Terraform info of a ResourceChange. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="address" type="string">
      Output only. The address of the drifted resource. Returned by the lookup.
    </ResponseField>
    <ResponseField name="provider" type="string">
      Output only. The provider of the drifted resource. Returned by the lookup.
    </ResponseField>
    <ResponseField name="resource_name" type="string">
      Output only. TF resource name. Returned by the lookup.
    </ResponseField>
    <ResponseField name="type" type="string">
      Output only. The type of the drifted resource. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "google_eventarc_provider"
description: "`data_eventarc_provider` looks up a real event provider (a Google Cloud service that can emit events) supported by Eventarc."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	eventarc "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/eventarc"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_eventarc_provider"})

    		ubx.Data(eventarc.Provider, "example", eventarc.ProviderConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Provider } from "@ubx/sdk-google/google/data/eventarc/provider";

    export default stack("example", () => {
      intent({ summary: "look up google_eventarc_provider" });

      data(Provider, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.eventarc import Provider, ProviderConfig

    def describe():
        ubx.intent("look up google_eventarc_provider")

        ubx.data(Provider, "example", ProviderConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="display_name" type="string">
  Output only. Human friendly name for the Provider. For example "Cloud Storage". Returned by the lookup.
</ResponseField>

<ResponseField name="event_types" type="list(object)">
  Output only. Event types for this provider. Returned by the lookup.
</ResponseField>

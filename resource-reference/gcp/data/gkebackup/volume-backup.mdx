---
title: "google_gkebackup_volume_backup"
description: "`data_gkebackup_volume_backup` looks up a real, already-existing `google_gkebackup_backup`."
---

It is a point-in-time backup of a GKE cluster's own workload configuration and (optionally) persistent volume data, created from a backup plan.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	gkebackup "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/gkebackup"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_gkebackup_volume_backup"})

    		ubx.Data(gkebackup.VolumeBackup, "example", gkebackup.VolumeBackupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="complete_time" type="string">
  Output only. The timestamp when the associated underlying volume backup operation completed. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this VolumeBackup resource was created. Returned by the lookup.
</ResponseField>

<ResponseField name="disk_size_bytes" type="string">
  Output only. The minimum size of the disk to which this VolumeBackup can be restored. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. `etag` is used for optimistic concurrency control as a way to help prevent simultaneous updates of a volume backup from overwriting each other. It is strongly suggested that systems make use of the `etag` in the read-modify-write cycle to perform volume backup updates in order to avoid race conditions. Returned by the lookup.
</ResponseField>

<ResponseField name="format" type="string">
  Output only. The format used for the volume backup. Returned by the lookup.
</ResponseField>

<ResponseField name="satisfies_pzi" type="bool">
  Output only. [Output Only] Reserved for future use. Returned by the lookup.
</ResponseField>

<ResponseField name="satisfies_pzs" type="bool">
  Output only. [Output Only] Reserved for future use. Returned by the lookup.
</ResponseField>

<ResponseField name="source_pvc" type="object">
  A reference to a namespaced resource in Kubernetes. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      Optional. The name of the Kubernetes resource. Optional lookup argument.

    <ResponseField name="namespace" type="string">
      Optional. The Namespace of the Kubernetes resource. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of this VolumeBackup. Returned by the lookup.
</ResponseField>

<ResponseField name="state_message" type="string">
  Output only. A human readable message explaining why the VolumeBackup is in its current state. This field is only meant for human consumption and should not be used programmatically as this field is not guaranteed to be consistent. Returned by the lookup.
</ResponseField>

<ResponseField name="storage_bytes" type="string">
  Output only. The aggregate size of the underlying artifacts associated with this VolumeBackup in the backup storage. This may change over time when multiple backups of the same volume share the same backup storage location. In particular, this is likely to increase in size when the immediately preceding backup of the same volume is deleted. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Server generated global unique identifier of [UUID](https://en.wikipedia.org/wiki/Universally_unique_identifier) format. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when this VolumeBackup resource was last updated. Returned by the lookup.
</ResponseField>

<ResponseField name="volume_backup_handle" type="string">
  Output only. A storage system-specific opaque handle to the underlying volume backup. Returned by the lookup.
</ResponseField>

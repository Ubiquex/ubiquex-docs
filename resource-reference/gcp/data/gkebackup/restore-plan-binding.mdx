---
title: "google_gkebackup_restore_plan_binding"
description: "`data_gkebackup_restore_plan_binding` looks up a real, already-existing `google_gkebackup_restore_plan`."
---

It defines how a GKE backup is restored -- which target cluster and what conflict-resolution/transformation rules apply -- when a restore is executed.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	gkebackup "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/gkebackup"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_gkebackup_restore_plan_binding"})

    		ubx.Data(gkebackup.RestorePlanBinding, "example", gkebackup.RestorePlanBindingConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="backup_plan" type="string">
  Output only. The fully qualified name of the BackupPlan bound to the specified RestorePlan. `projects/*/locations/*/backukpPlans/&#123;backup_plan&#125;` Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp when this binding was created. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. `etag` is used for optimistic concurrency control as a way to help prevent simultaneous updates of a RestorePlanBinding from overwriting each other. It is strongly suggested that systems make use of the 'etag' in the read-modify-write cycle to perform RestorePlanBinding updates in order to avoid race conditions: An `etag` is returned in the response to `GetRestorePlanBinding`, and systems are expected to put that etag in the request to `UpdateRestorePlanBinding` or `DeleteRestorePlanBinding` to ensure that their change will be applied to the same version of the resource. Returned by the lookup.
</ResponseField>

<ResponseField name="restore_plan" type="string">
  Output only. The fully qualified name of the RestorePlan bound to this RestoreChannel. `projects/*/locations/*/restorePlans/&#123;restore_plan&#125;` Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">

</ResponseField>

<ResponseField name="update_time" type="string">

</ResponseField>

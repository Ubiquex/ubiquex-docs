## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	baremetalsolution "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/baremetalsolution"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_baremetalsolution_lun"})

    		ubx.Data(baremetalsolution.Lun, "example", baremetalsolution.LunConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="boot_lun" type="bool">
  Display if this LUN is a boot LUN. Returned by the lookup.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. Time after which LUN will be fully deleted. It is filled only for LUNs in COOL_OFF state. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  An identifier for the LUN, generated by the backend. Returned by the lookup.
</ResponseField>

<ResponseField name="instances" type="list(string)">
  Output only. Instances this Lun is attached to. Returned by the lookup.
</ResponseField>

<ResponseField name="multiprotocol_type" type="string">
  The LUN multiprotocol type ensures the characteristics of the LUN are optimized for each operating system. Returned by the lookup.
</ResponseField>

<ResponseField name="shareable" type="bool">
  Display if this LUN can be shared between multiple physical servers. Returned by the lookup.
</ResponseField>

<ResponseField name="size_gb" type="string">
  The size of this LUN, in GiB. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  The state of this storage volume. Returned by the lookup.
</ResponseField>

<ResponseField name="storage_type" type="string">
  The storage type for this LUN. Returned by the lookup.
</ResponseField>

<ResponseField name="storage_volume" type="string">
  Display the storage volume for this LUN. Returned by the lookup.
</ResponseField>

<ResponseField name="wwid" type="string">
  The WWID for this LUN. Returned by the lookup.
</ResponseField>

`google_baremetalsolution_instance` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	baremetalsolution "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/baremetalsolution"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_baremetalsolution_instance"})

    		ubx.Data(baremetalsolution.Instance, "example", baremetalsolution.InstanceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Instance } from "@ubx/sdk-google/google/data/baremetalsolution/instance";

    export default stack("example", () => {
      intent({ summary: "look up google_baremetalsolution_instance" });

      data(Instance, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.baremetalsolution import Instance, InstanceConfig

    def describe():
        ubx.intent("look up google_baremetalsolution_instance")

        ubx.data(Instance, "example", InstanceConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Result properties

<ResponseField name="create_time" type="string">
  Output only. Create a time stamp. Returned by the lookup.
</ResponseField>

<ResponseField name="firmware_version" type="string">
  Output only. The firmware version for the instance. Returned by the lookup.
</ResponseField>

<ResponseField name="hyperthreading_enabled" type="bool">
  True if you enable hyperthreading for the server, otherwise false. The default value is false. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  Output only. An identifier for the `Instance`, generated by the backend. Returned by the lookup.
</ResponseField>

<ResponseField name="interactive_serial_console_enabled" type="bool">
  Output only. True if the interactive serial console feature is enabled for the instance, false otherwise. The default value is false. Returned by the lookup.
</ResponseField>

<ResponseField name="kms_key_version" type="string">
  Optional. Name of the KMS crypto key version used to encrypt the initial passwords. The key has to have ASYMMETRIC_DECRYPT purpose. Format is `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;keyring&#125;/cryptoKeys/&#123;key&#125;/cryptoKeyVersions/&#123;version&#125;`. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels as key value pairs. Returned by the lookup.
</ResponseField>

<ResponseField name="logical_interfaces" type="list(object)">
  List of logical interfaces for the instance. The number of logical interfaces will be the same as number of hardware bond/nic on the chosen network template. For the non-multivlan configurations (for eg, existing servers) that use existing default network template (bondaa-bondaa), both the Instance.networks field and the Instance.logical_interfaces fields will be filled to ensure backward compatibility. For the others, only Instance.logical_interfaces will be filled. Returned by the lookup.
</ResponseField>

<ResponseField name="login_info" type="string">
  Output only. Text field about info for logging in. Returned by the lookup.
</ResponseField>

<ResponseField name="luns" type="list(object)">
  Immutable. List of LUNs associated with this server. Returned by the lookup.
</ResponseField>

<ResponseField name="machine_type" type="string">
  Immutable. The server type. [Available server types](https://cloud.google.com/bare-metal/docs/bms-planning#server_configurations) Returned by the lookup.
</ResponseField>

<ResponseField name="network_template" type="string">
  Instance network template name. For eg, bondaa-bondaa, bondab-nic, etc. Generally, the template name follows the syntax of "bond" or "nic". Returned by the lookup.
</ResponseField>

<ResponseField name="networks" type="list(object)">
  Output only. List of networks associated with this server. Returned by the lookup.
</ResponseField>

<ResponseField name="os_image" type="string">
  The OS image currently installed on the server. Returned by the lookup.
</ResponseField>

<ResponseField name="pod" type="string">
  Immutable. Pod name. Pod is an independent part of infrastructure. Instance can only be connected to the assets (networks, volumes) allocated in the same pod. Returned by the lookup.
</ResponseField>

<ResponseField name="ssh_keys" type="list(string)">
  Optional. List of SSH Keys used during instance provisioning. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the server. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Update a time stamp. Returned by the lookup.
</ResponseField>

<ResponseField name="volumes" type="list(object)">
  Input only. List of Volumes to attach to this Instance on creation. This field won't be populated in Get/List responses. Returned by the lookup.
</ResponseField>

<ResponseField name="workload_profile" type="string">
  The workload profile for the instance. Returned by the lookup.
</ResponseField>

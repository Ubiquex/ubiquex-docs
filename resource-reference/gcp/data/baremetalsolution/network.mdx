## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	baremetalsolution "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/baremetalsolution"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_baremetalsolution_network"})

    		ubx.Data(baremetalsolution.Network, "example", baremetalsolution.NetworkConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Network } from "@ubx/sdk-google/google/data/baremetalsolution/network";

    export default stack("example", () => {
      intent({ summary: "look up google_baremetalsolution_network" });

      data(Network, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.baremetalsolution import Network, NetworkConfig

    def describe():
        ubx.intent("look up google_baremetalsolution_network")

        ubx.data(Network, "example", NetworkConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="cidr" type="string">
  The cidr of the Network. Returned by the lookup.
</ResponseField>

<ResponseField name="gateway_ip" type="string">
  Output only. Gateway ip address. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  An identifier for the `Network`, generated by the backend. Returned by the lookup.
</ResponseField>

<ResponseField name="ip_address" type="string">
  IP address configured. Returned by the lookup.
</ResponseField>

<ResponseField name="jumbo_frames_enabled" type="bool">
  Whether network uses standard frames or jumbo ones. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Labels as key value pairs. Returned by the lookup.
</ResponseField>

<ResponseField name="mac_address" type="list(string)">
  List of physical interfaces. Returned by the lookup.
</ResponseField>

<ResponseField name="mount_points" type="list(object)">
  Input only. List of mount points to attach the network to. Returned by the lookup.
</ResponseField>

<ResponseField name="pod" type="string">
  Immutable. Pod name. Pod is an independent part of infrastructure. Network can only be connected to the assets (instances, nfsshares) allocated in the same pod. Returned by the lookup.
</ResponseField>

<ResponseField name="reservations" type="list(object)">
  List of IP address reservations in this network. When updating this field, an error will be generated if a reservation conflicts with an IP address already allocated to a physical server. Returned by the lookup.
</ResponseField>

<ResponseField name="services_cidr" type="string">
  IP range for reserved for services (e.g. NFS). Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  The Network state. Returned by the lookup.
</ResponseField>

<ResponseField name="type" type="string">
  The type of this network. Returned by the lookup.
</ResponseField>

<ResponseField name="vlan_id" type="string">
  The vlan id of the Network. Returned by the lookup.
</ResponseField>

<ResponseField name="vrf" type="object">
  A network VRF. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The name of the VRF. Optional lookup argument.
    </ResponseField>
    <ResponseField name="qos_policy" type="object">
      QOS policy parameters. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="bandwidth_gbps" type="number">
          The bandwidth permitted by the QOS policy, in gbps. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="state" type="string">
      The possible state of VRF. Optional lookup argument.
    </ResponseField>
    <ResponseField name="vlan_attachments" type="list(object)">
      The list of VLAN attachments for the VRF. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vrf_attachment" type="string">
  Optional. The name of a pre-existing Vrf that the network should be attached to. Format is `vrfs/&#123;vrf&#125;`. Returned by the lookup.
</ResponseField>

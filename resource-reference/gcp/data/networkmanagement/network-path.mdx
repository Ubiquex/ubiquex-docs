## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	networkmanagement "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/networkmanagement"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_networkmanagement_network_path"})

    		ubx.Data(networkmanagement.NetworkPath, "example", networkmanagement.NetworkPathConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The time the NetworkPath was created. Returned by the lookup.
</ResponseField>

<ResponseField name="destination" type="string">
  Output only. IP address or hostname of the network path destination. Returned by the lookup.
</ResponseField>

<ResponseField name="destination_geo_location" type="object">
  The geographical location of the MonitoringPoint. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="formatted_address" type="string">
      Formatted address. Optional lookup argument.
    </ResponseField>
    <ResponseField name="region_code" type="string">
      Unicode CLDR region code. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="destination_monitoring_point_id" type="string">
  Output only. Provider's UUID of the destination MonitoringPoint. This id may not point to a resource in the Google Cloud. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Output only. The display name of the network path. Returned by the lookup.
</ResponseField>

<ResponseField name="dual_ended" type="bool">
  Output only. Indicates if the network path is dual ended. When true, the network path is measured both: from both source to destination, and from destination to source. When false, the network path is measured from the source through the destination back to the source (round trip measurement). Returned by the lookup.
</ResponseField>

<ResponseField name="monitoring_enabled" type="bool">
  Output only. Is monitoring enabled for the network path. Returned by the lookup.
</ResponseField>

<ResponseField name="monitoring_policy_display_name" type="string">
  Output only. Display name of the monitoring policy. Returned by the lookup.
</ResponseField>

<ResponseField name="monitoring_policy_id" type="string">
  Output only. ID of monitoring policy. Returned by the lookup.
</ResponseField>

<ResponseField name="monitoring_status" type="string">
  Output only. The monitoring status of the network path. Returned by the lookup.
</ResponseField>

<ResponseField name="network_protocol" type="string">
  Output only. The network protocol of the network path. Returned by the lookup.
</ResponseField>

<ResponseField name="provider_tags" type="list(object)">
  Output only. The provider tags of the network path. Returned by the lookup.
</ResponseField>

<ResponseField name="provider_ui_uri" type="string">
  Output only. Link to provider's UI; link shows the NetworkPath. Returned by the lookup.
</ResponseField>

<ResponseField name="source_monitoring_point_id" type="string">
  Output only. Provider's UUID of the source MonitoringPoint. This id may not point to a resource in the Google Cloud. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the NetworkPath was updated. Returned by the lookup.
</ResponseField>

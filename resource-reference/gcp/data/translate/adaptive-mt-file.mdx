---
title: "google_translate_adaptive_mt_file"
description: "`data_translate_adaptive_mt_file` looks up a real, already-existing `google_translate_adaptive_mt_dataset`."
---

It is a Cloud Translation Adaptive Translation dataset, a real, small set of example translations combined with a large language model at request time to produce nuanced, style-consistent translations without training or maintaining a full custom model.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	translate "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/translate"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_translate_adaptive_mt_file"})

    		ubx.Data(translate.AdaptiveMtFile, "example", translate.AdaptiveMtFileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { AdaptiveMtFile } from "@ubx/sdk-google/google/data/translate/adaptive_mt_file";

    export default stack("example", () => {
      intent({ summary: "look up google_translate_adaptive_mt_file" });

      data(AdaptiveMtFile, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.translate import AdaptiveMtFile, AdaptiveMtFileConfig

    def describe():
        ubx.intent("look up google_translate_adaptive_mt_file")

        ubx.data(AdaptiveMtFile, "example", AdaptiveMtFileConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudcontrolspartner "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/cloudcontrolspartner"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_cloudcontrolspartner_v1beta_violation"})

    		ubx.Data(cloudcontrolspartner.V1betaViolation, "example", cloudcontrolspartner.V1betaViolationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="begin_time" type="string">
  Output only. Time of the event which triggered the Violation. Returned by the lookup.
</ResponseField>

<ResponseField name="category" type="string">
  Output only. Category under which this violation is mapped. e.g. Location, Service Usage, Access, Encryption, etc. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Output only. Description for the Violation. e.g. OrgPolicy gcp.resourceLocations has non compliant value. Returned by the lookup.
</ResponseField>

<ResponseField name="folder_id" type="string">
  The folder_id of the violation Returned by the lookup.
</ResponseField>

<ResponseField name="non_compliant_org_policy" type="string">
  Output only. Immutable. Name of the OrgPolicy which was modified with non-compliant change and resulted this violation. Format: `projects/&#123;project_number&#125;/policies/&#123;constraint_name&#125;` `folders/&#123;folder_id&#125;/policies/&#123;constraint_name&#125;` `organizations/&#123;organization_id&#125;/policies/&#123;constraint_name&#125;` Returned by the lookup.
</ResponseField>

<ResponseField name="remediation" type="object">
  Represents remediation guidance to resolve compliance violation for AssuredWorkload Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="compliant_values" type="list(string)">
      Values that can resolve the violation For example: for list org policy violations, this will either be the list of allowed or denied values Optional lookup argument.
    </ResponseField>
    <ResponseField name="instructions" type="object">
      Instructions to remediate violation Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="console_instructions" type="object">
          Remediation instructions to resolve violation via cloud console Optional lookup argument.
          <Expandable title="properties">
            <ResponseField name="additional_links" type="list(string)">
              Additional urls for more information about steps Optional lookup argument.
            </ResponseField>
            <ResponseField name="console_uris" type="list(string)">
              Link to console page where violations can be resolved Optional lookup argument.
            </ResponseField>
            <ResponseField name="steps" type="list(string)">
              Steps to resolve violation via cloud console Optional lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="gcloud_instructions" type="object">
          Remediation instructions to resolve violation via gcloud cli Optional lookup argument.
          <Expandable title="properties">
            <ResponseField name="additional_links" type="list(string)">
              Additional urls for more information about steps Optional lookup argument.
            </ResponseField>
            <ResponseField name="gcloud_commands" type="list(string)">
              Gcloud command to resolve violation Optional lookup argument.
            </ResponseField>
            <ResponseField name="steps" type="list(string)">
              Steps to resolve violation via gcloud cli Optional lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="remediation_type" type="string">
      Output only. Remediation type based on the type of org policy values violated Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="resolve_time" type="string">
  Output only. Time of the event which fixed the Violation. If the violation is ACTIVE this will be empty. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the violation Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last time when the Violation record was updated. Returned by the lookup.
</ResponseField>

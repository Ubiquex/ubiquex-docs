## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workflowexecutions "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/workflowexecutions"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_workflowexecutions_step_entry"})

    		ubx.Data(workflowexecutions.StepEntry, "example", workflowexecutions.StepEntryConfig{
    			Name: "example",
    			View: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="view" type="string">
  The real, requested view (which fields to include) of this response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The creation time of the step entry. Returned by the lookup.
</ResponseField>

<ResponseField name="entry_id" type="string">
  Output only. The numeric ID of this step entry, used for navigation. Returned by the lookup.
</ResponseField>

<ResponseField name="exception" type="object">
  Exception describes why the step entry failed. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="payload" type="string">
      Error message represented as a JSON string. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="navigation_info" type="object">
  NavigationInfo describes what steps if any come before or after this step, or what steps are parents or children of this step. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="children" type="list(string)">
      Step entries that can be reached by "stepping into" e.g. a subworkflow call. Optional lookup argument.
    </ResponseField>
    <ResponseField name="next" type="string">
      The index of the next step in the current workflow, if any. Optional lookup argument.
    </ResponseField>
    <ResponseField name="parent" type="string">
      The step entry, if any, that can be reached by "stepping out" of the current workflow being executed. Optional lookup argument.
    </ResponseField>
    <ResponseField name="previous" type="string">
      The index of the previous step in the current workflow, if any. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="routine" type="string">
  Output only. The name of the routine this step entry belongs to. A routine name is the subworkflow name defined in the YAML source code. The top level routine name is `main`. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the step entry. Returned by the lookup.
</ResponseField>

<ResponseField name="step" type="string">
  Output only. The name of the step this step entry belongs to. Returned by the lookup.
</ResponseField>

<ResponseField name="step_entry_metadata" type="object">
  StepEntryMetadata contains metadata information about this step. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="expected_iteration" type="string">
      Expected iteration represents the expected number of iterations in the step's progress. Optional lookup argument.
    </ResponseField>
    <ResponseField name="progress_number" type="string">
      Progress number represents the current state of the current progress. eg: A step entry represents the 4th iteration in a progress of PROGRESS_TYPE_FOR. Note: This field is only populated when an iteration exists and the starting value is 1. Optional lookup argument.
    </ResponseField>
    <ResponseField name="progress_type" type="string">
      Progress type of this step entry. Optional lookup argument.
    </ResponseField>
    <ResponseField name="thread_id" type="string">
      Child thread id that this step entry belongs to. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="step_type" type="string">
  Output only. The type of the step this step entry belongs to. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The most recently updated time of the step entry. Returned by the lookup.
</ResponseField>

<ResponseField name="variable_data" type="object">
  VariableData contains the variable data for this step. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="variables" type="map(any)">
      Variables that are associated with this step. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

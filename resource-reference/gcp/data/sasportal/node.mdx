---
title: "google_sasportal_node"
description: "`data_sasportal_node` looks up a real, already-existing `google_sasportal_node`."
---

It is an organizational node in the Google SAS Portal's real device hierarchy, used alongside deployments to structure how CBRS devices and access are managed at scale.

## Example

    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sasportal "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/sasportal"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_sasportal_node"})

    		ubx.Data(sasportal.Node, "example", sasportal.NodeConfig{
    			Name: "example",
    		})
    	}))
    }

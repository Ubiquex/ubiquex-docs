`google_sasportal_deployment` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sasportal "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/sasportal"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_sasportal_deployment"})

    		ubx.Data(sasportal.Deployment, "example", sasportal.DeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="display_name" type="string">
  The deployment's display name. Returned by the lookup.
</ResponseField>

<ResponseField name="frns" type="list(string)">
  Output only. The FCC Registration Numbers (FRNs) copied from its direct parent. Returned by the lookup.
</ResponseField>

<ResponseField name="sas_user_ids" type="list(string)">
  User ID used by the devices belonging to this deployment. Each deployment should be associated with one unique user ID. Returned by the lookup.
</ResponseField>

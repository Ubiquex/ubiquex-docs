---
title: "google_sasportal_deployment"
description: "`data_sasportal_deployment` looks up a real, already-existing `google_sasportal_deployment`."
---

It is a real organizational grouping of CBRS devices in the Google SAS Portal (Spectrum Access System), identified by a unique user ID; a SAS organization can contain multiple deployments, each typically holding multiple `google_sasportal_device` entries.

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go

    		})
    	}))
    }

## Lookup arguments

## Result properties

<ResponseField name="display_name" type="string">
  The deployment's display name. Returned by the lookup.
</ResponseField>

<ResponseField name="frns" type="list(string)">
  Output only. The FCC Registration Numbers (FRNs) copied from its direct parent. Returned by the lookup.
</ResponseField>

<ResponseField name="sas_user_ids" type="list(string)">
  User ID used by the devices belonging to this deployment. Each deployment should be associated with one unique user ID. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	testing "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/testing"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_testing_test_environment_catalog"})

    		ubx.Data(testing.TestEnvironmentCatalog, "example", testing.TestEnvironmentCatalogConfig{
    			EnvironmentType:       "example",
    			IncludeViewableModels: true,
    			ProjectId:             "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="environment_type" type="string" required>
  The real type of environment this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="include_viewable_models" type="bool">
  Whether models the caller only has view access to are included in the response. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="project_id" type="string">
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

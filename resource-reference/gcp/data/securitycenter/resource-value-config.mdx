`data_securitycenter_resource_value_config` looks up a real configuration Security Command Center uses to weight a resource's own business value in risk scoring.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securitycenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google/securitycenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own resource value config"})

    		ubx.Resource(securitycenter.ResourceValueConfig, "example", securitycenter.ResourceValueConfigConfig{
    			Requests: []map[string]any{{"parent": "example"}},
    		})
    	}))
    }
    ```
  </Tab>

    import ubx_sdk as ubx

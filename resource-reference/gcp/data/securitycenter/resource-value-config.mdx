`data_securitycenter_resource_value_config` looks up a real configuration Security Command Center uses to weight a resource's own business value in risk scoring.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securitycenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/securitycenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_securitycenter_resource_value_config"})

    		ubx.Data(securitycenter.ResourceValueConfig, "example", securitycenter.ResourceValueConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

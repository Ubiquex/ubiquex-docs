`data_storagetransfer_google_service_account` looks up the real, project-scoped Google-managed service account Storage Transfer Service uses to move data on the project's own behalf.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storagetransfer "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/storagetransfer"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_storagetransfer_google_service_account"})

    		ubx.Data(storagetransfer.GoogleServiceAccount, "example", storagetransfer.GoogleServiceAccountConfig{
    			ProjectId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.storagetransfer import GoogleServiceAccount, GoogleServiceAccountConfig

    def describe():
        ubx.intent("look up google_storagetransfer_google_service_account")

        ubx.data(GoogleServiceAccount, "example", GoogleServiceAccountConfig(
            project_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="project_id" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="account_email" type="string">
  Email address of the service account. Returned by the lookup.
</ResponseField>

<ResponseField name="subject_id" type="string">
  Unique identifier for the service account. Returned by the lookup.
</ResponseField>

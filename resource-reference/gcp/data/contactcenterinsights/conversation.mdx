---
title: "google_contactcenterinsights_conversation"
description: "`data_contactcenterinsights_conversation` looks up a real, already-existing `google_contactcenterinsights_conversation`."
---

It is a single imported customer interaction (a call transcript or chat log) that Contact Center AI Insights analyzes for sentiment, topics, and quality signals.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	contactcenterinsights "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/contactcenterinsights"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_contactcenterinsights_conversation"})

    		ubx.Data(contactcenterinsights.Conversation, "example", contactcenterinsights.ConversationConfig{
    			Name: "example",
    			View: "example",
    		})
    	}))
    }
    ```
  </Tab>

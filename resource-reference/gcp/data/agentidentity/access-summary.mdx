## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/agentidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_agentidentity_access_summary"})

    		ubx.Data(agentidentity.AccessSummary, "example", agentidentity.AccessSummaryConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="auth_provider" type="string">
  Output only. The auth provider that this access summary is associated with. Returned by the lookup.
</ResponseField>

<ResponseField name="auth_provider_type" type="string">
  Output only. The auth provider type used to create this access summary. Returned by the lookup.
</ResponseField>

<ResponseField name="first_access_time" type="string">
  Output only. The first time this user interacted with this workload, rounded to the previous hour. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key-value pairs. Returned by the lookup.
</ResponseField>

<ResponseField name="last_access_time" type="string">
  Output only. The most recent time this user interacted with this workload, rounded to the previous hour. Returned by the lookup.
</ResponseField>

<ResponseField name="purge_time" type="string">
  Output only. The time when this access summary is permanently deleted. Returned by the lookup.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Output only. All scopes that have been used by this user with this workload. The number of scopes is limited to 200. Returned by the lookup.
</ResponseField>

<ResponseField name="token_url" type="string">
  Output only. The URL of the authentication server that was accessed. Returned by the lookup.
</ResponseField>

<ResponseField name="user_id" type="string">
  Output only. The user ID provided by the workload application for this user. Not verified by Google. Returned by the lookup.
</ResponseField>

<ResponseField name="workload_id" type="string">
  Output only. The identity bound to the workload that this user interacted with to produce this access summary. Typically an agentic SPIFFE ID. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/agentidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_agentidentity_v1alpha_authorization"})

    		ubx.Data(agentidentity.V1alphaAuthorization, "example", agentidentity.V1alphaAuthorizationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.agentidentity import V1alphaAuthorization, V1alphaAuthorizationConfig

    def describe():
        ubx.intent("look up google_agentidentity_v1alpha_authorization")

        ubx.data(V1alphaAuthorization, "example", V1alphaAuthorizationConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="client_user_id" type="string">
  Output only. The client user ID provided by the client application for their end user. Not verified by Google. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp. Returned by the lookup.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Output only. The scopes actually granted by the end user during the consent flow. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the authorization. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The update timestamp. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	agentidentity "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/agentidentity"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_agentidentity_authorization"})

    		ubx.Data(agentidentity.Authorization, "example", agentidentity.AuthorizationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only google --lang ts --out ./local-sdk
    import { Authorization } from "./local-sdk/google/sdk/typescript/google/data/agentidentity/authorization.ts";

    export default stack("example", () => {
      intent({ summary: "look up google_agentidentity_authorization" });

      data(Authorization, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.agentidentity import Authorization, AuthorizationConfig

    def describe():
        ubx.intent("look up google_agentidentity_authorization")

        ubx.data(Authorization, "example", AuthorizationConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="client_user_id" type="string">
  Output only. The client user ID provided by the client application for their end user. Not verified by Google. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation timestamp. Returned by the lookup.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Output only. The scopes actually granted by the end user during the consent flow. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the authorization. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The update timestamp. Returned by the lookup.
</ResponseField>

`google_osconfig_v1alpha_instance_ospolicies_compliance` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="detailed_state" type="string">
  Output only. Detailed compliance state of the VM. This field is populated only when compliance state is `UNKNOWN`. It may contain one of the following values: * `no-compliance-data`: Compliance data is not available for this VM. * `no-agent-detected`: OS Config agent is not detected for this VM. * `config-not-supported-by-agent`: The version of the OS Config agent running on this VM does not support configuration management. * `inactive`: VM is not running. * `internal-service-errors`: There were internal service errors encountered while enforcing compliance. * `agent-errors`: OS config agent encountered errors while enforcing compliance. Returned by the lookup.
</ResponseField>

<ResponseField name="detailed_state_reason" type="string">
  Output only. The reason for the `detailed_state` of the VM (if any). Returned by the lookup.
</ResponseField>

<ResponseField name="instance" type="string">
  Output only. The Compute Engine VM instance name. Returned by the lookup.
</ResponseField>

<ResponseField name="last_compliance_check_time" type="string">
  Output only. Timestamp of the last compliance check for the VM. Returned by the lookup.
</ResponseField>

<ResponseField name="last_compliance_run_id" type="string">
  Output only. Unique identifier for the last compliance run. This id will be logged by the OS config agent during a compliance run and can be used for debugging and tracing purpose. Returned by the lookup.
</ResponseField>

<ResponseField name="os_policy_compliances" type="list(object)">
  Output only. Compliance data for each `OSPolicy` that is applied to the VM. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Compliance state of the VM. Returned by the lookup.
</ResponseField>

`google_osconfig_v1alpha_inventory` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	osconfig "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/osconfig"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_osconfig_v1alpha_inventory"})

    		ubx.Data(osconfig.V1alphaInventory, "example", osconfig.V1alphaInventoryConfig{
    			Name: "example",
    			View: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  Required lookup argument.
</ResponseField>

<ResponseField name="view" type="string">
  Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="items" type="map(object)">
  Output only. Inventory items related to the VM keyed by an opaque unique identifier for each inventory item. The identifier is unique to each distinct and addressable inventory item and will change, when there is a new package version. Returned by the lookup.
</ResponseField>

<ResponseField name="os_info" type="object">
  Operating system information for the VM. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="architecture" type="string">
      The system architecture of the operating system. Optional lookup argument.
    </ResponseField>
    <ResponseField name="hostname" type="string">
      The VM hostname. Optional lookup argument.
    </ResponseField>
    <ResponseField name="kernel_release" type="string">
      The kernel release of the operating system. Optional lookup argument.
    </ResponseField>
    <ResponseField name="kernel_version" type="string">
      The kernel version of the operating system. Optional lookup argument.
    </ResponseField>
    <ResponseField name="long_name" type="string">
      The operating system long name. For example 'Debian GNU/Linux 9' or 'Microsoft Window Server 2019 Datacenter'. Optional lookup argument.
    </ResponseField>
    <ResponseField name="osconfig_agent_version" type="string">
      The current version of the OS Config agent running on the VM. Optional lookup argument.
    </ResponseField>
    <ResponseField name="short_name" type="string">
      The operating system short name. For example, 'windows' or 'debian'. Optional lookup argument.
    </ResponseField>
    <ResponseField name="version" type="string">
      The version of the operating system. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp of the last reported inventory for the VM. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	osconfig "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/osconfig"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_osconfig_v1alpha_report"})

    		ubx.Data(osconfig.V1alphaReport, "example", osconfig.V1alphaReportConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="instance" type="string">
  The Compute Engine VM instance name. Returned by the lookup.
</ResponseField>

<ResponseField name="last_run_id" type="string">
  Unique identifier of the last attempted run to apply the OS policies associated with this assignment on the VM. This ID is logged by the OS Config agent while applying the OS policies associated with this assignment on the VM. NOTE: If the service is unable to successfully connect to the agent for this run, then this id will not be available in the agent logs. Returned by the lookup.
</ResponseField>

<ResponseField name="os_policy_assignment" type="string">
  Reference to the `OSPolicyAssignment` API resource that the `OSPolicy` belongs to. Format: `projects/&#123;project_number&#125;/locations/&#123;location&#125;/osPolicyAssignments/&#123;os_policy_assignment_id@revision_id&#125;` Returned by the lookup.
</ResponseField>

<ResponseField name="os_policy_compliances" type="list(object)">
  Compliance data for each `OSPolicy` that is applied to the VM. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Timestamp for when the report was last generated. Returned by the lookup.
</ResponseField>

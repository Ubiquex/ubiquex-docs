`google_dataflow_snapshot` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dataflow "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/dataflow"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_dataflow_snapshot"})

    		ubx.Data(dataflow.Snapshot, "example", dataflow.SnapshotConfig{
    			Location:   "example",
    			ProjectId:  "example",
    			SnapshotId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Result properties

<ResponseField name="creation_time" type="string">
  The time this snapshot was created. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  User specified description of the snapshot. Maybe empty. Returned by the lookup.
</ResponseField>

<ResponseField name="disk_size_bytes" type="string">
  The disk byte size of the snapshot. Only available for snapshots in READY state. Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  The unique ID of this snapshot. Returned by the lookup.
</ResponseField>

<ResponseField name="pubsub_metadata" type="list(object)">
  Pub/Sub snapshot metadata. Returned by the lookup.
</ResponseField>

<ResponseField name="region" type="string">
  Cloud region where this snapshot lives in, e.g., "us-central1". Returned by the lookup.
</ResponseField>

<ResponseField name="source_job_id" type="string">
  The job this snapshot was created from. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  State of the snapshot. Returned by the lookup.
</ResponseField>

<ResponseField name="ttl" type="string">
  The time after which this snapshot will be automatically deleted. Returned by the lookup.
</ResponseField>

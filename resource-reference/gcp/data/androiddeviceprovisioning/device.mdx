## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androiddeviceprovisioning "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androiddeviceprovisioning"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androiddeviceprovisioning_device"})

    		ubx.Data(androiddeviceprovisioning.Device, "example", androiddeviceprovisioning.DeviceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="claims" type="list(object)">
  Output only. The provisioning claims for a device. Devices claimed for zero-touch enrollment have a claim with the type `SECTION_TYPE_ZERO_TOUCH`. Call `partners.devices.unclaim` or `partners.devices.unclaimAsync` to remove the device from zero-touch enrollment. Returned by the lookup.
</ResponseField>

<ResponseField name="configuration" type="string">
  Not available to resellers. Returned by the lookup.
</ResponseField>

<ResponseField name="device_id" type="string">
  Output only. The ID of the device. Assigned by the server. Returned by the lookup.
</ResponseField>

<ResponseField name="device_identifier" type="object">
  Encapsulates hardware and product IDs to identify a manufactured device. To understand requirements on identifier sets, read [Identifiers](https://developers.google.com/zero-touch/guides/identifiers). Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="chrome_os_attested_device_id" type="string">
      An identifier provided by OEMs, carried through the production and sales process. Only applicable to Chrome OS devices. Optional lookup argument.
    </ResponseField>
    <ResponseField name="device_type" type="string">
      The type of the device Optional lookup argument.
    </ResponseField>
    <ResponseField name="imei" type="string">
      The device’s IMEI number. Validated on input. Optional lookup argument.
    </ResponseField>
    <ResponseField name="imei2" type="string">
      The device’s second IMEI number. Optional lookup argument.
    </ResponseField>
    <ResponseField name="manufacturer" type="string">
      The device manufacturer’s name. Matches the device's built-in value returned from `android.os.Build.MANUFACTURER`. Allowed values are listed in [Android manufacturers](/zero-touch/resources/manufacturer-names#manufacturers-names). Optional lookup argument.
    </ResponseField>
    <ResponseField name="meid" type="string">
      The device’s MEID number. Optional lookup argument.
    </ResponseField>
    <ResponseField name="meid2" type="string">
      The device’s second MEID number. Optional lookup argument.
    </ResponseField>
    <ResponseField name="model" type="string">
      The device model's name. Allowed values are listed in [Android models](/zero-touch/resources/manufacturer-names#model-names) and [Chrome OS models](https://support.google.com/chrome/a/answer/10130175#identify_compatible). Optional lookup argument.
    </ResponseField>
    <ResponseField name="serial_number" type="string">
      The manufacturer's serial number for the device. This value might not be unique across different device models. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="device_metadata" type="object">
  Metadata entries that can be attached to a `Device`. To learn more, read [Device metadata](https://developers.google.com/zero-touch/guides/metadata). Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="entries" type="map(string)">
      Metadata entries recorded as key-value pairs. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

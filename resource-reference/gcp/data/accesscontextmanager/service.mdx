## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	accesscontextmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/accesscontextmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_accesscontextmanager_service"})

    		ubx.Data(accesscontextmanager.Service, "example", accesscontextmanager.ServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

        ubx.run("example", describe)

## Result properties

<ResponseField name="available_on_restricted_vip" type="bool">
  True if the service is available on the restricted VIP. Services on the restricted VIP typically either support VPC Service Controls or are core infrastructure services required for the functioning of Google Cloud. Returned by the lookup.
</ResponseField>

<ResponseField name="known_limitations" type="bool">
  True if the service is supported with some limitations. Check [documentation](https://cloud.google.com/vpc-service-controls/docs/supported-products) for details. Returned by the lookup.
</ResponseField>

<ResponseField name="service_support_stage" type="string">
  The support stage of the service. Returned by the lookup.
</ResponseField>

<ResponseField name="support_stage" type="string">
  The support stage of the service. Returned by the lookup.
</ResponseField>

<ResponseField name="supported_methods" type="list(object)">
  The list of the supported methods. This field exists only in response to GetSupportedService Returned by the lookup.
</ResponseField>

<ResponseField name="title" type="string">
  The name of the supported product, such as 'Cloud Product API'. Returned by the lookup.
</ResponseField>

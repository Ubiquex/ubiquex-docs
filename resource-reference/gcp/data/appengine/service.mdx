`google_appengine_service` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	appengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/appengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_appengine_service"})

    		ubx.Data(appengine.Service, "example", appengine.ServiceConfig{
    			AppsId:     "example",
    			ServicesId: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Result properties

<ResponseField name="generated_customer_metadata" type="map(any)">
  Additional Google Generated Customer Metadata, this field won't be provided by default and can be requested by setting the IncludeExtraData field in GetServiceRequest Returned by the lookup.
</ResponseField>

<ResponseField name="id" type="string">
  Output only. Relative name of the service within the application. Example: default.@OutputOnly Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  A set of labels to apply to this service. Labels are key/value pairs that describe the service and all resources that belong to it (e.g., versions). The labels can be used to search and group resources, and are propagated to the usage and billing reports, enabling fine-grain analysis of costs. An example of using labels is to tag resources belonging to different environments (e.g., "env=prod", "env=qa"). Label keys and values can be no longer than 63 characters and can only contain lowercase letters, numeric characters, underscores, dashes, and international characters. Label keys must start with a lowercase letter or an international character. Each service can have at most 32 labels. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Full path to the Service resource in the API. Example: apps/myapp/services/default.@OutputOnly Returned by the lookup.
</ResponseField>

<ResponseField name="network_settings" type="object">
  A NetworkSettings resource is a container for ingress settings for a version or service. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="ingress_traffic_allowed" type="string">
      The ingress settings for version or service. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="split" type="object">
  Traffic routing configuration for versions within a single service. Traffic splits define how traffic directed to the service is assigned to versions. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="allocations" type="map(number)">
      Mapping from version IDs within the service to fractional (0.000, 1] allocations of traffic for that version. Each version can be specified only once, but some versions in the service may not have any traffic allocation. Services that have traffic allocated cannot be deleted until either the service is deleted or their traffic allocation is removed. Allocations must sum to 1. Up to two decimal place precision is supported for IP-based splits and up to three decimal places is supported for cookie-based splits. Optional lookup argument.
    </ResponseField>
    <ResponseField name="shard_by" type="string">
      Mechanism used to determine which version a request is sent to. The traffic selection algorithm will be stable for either type until allocations are changed. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

---
title: "google_secretmanager_version"
description: "`data_secretmanager_version` looks up a real, specific version of a Secret Manager secret, holding one immutable copy of its own secret payload."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	secretmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/secretmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_secretmanager_version"})

    		ubx.Data(secretmanager.Version, "example", secretmanager.VersionConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="client_specified_payload_checksum" type="bool">
  Output only. True if payload checksum specified in SecretPayload object has been received by SecretManagerService on SecretManagerService.AddSecretVersion. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which the SecretVersion was created. Returned by the lookup.
</ResponseField>

<ResponseField name="customer_managed_encryption" type="object">
  Describes the status of customer-managed encryption. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="kms_key_version_name" type="string">
      Required. The resource name of the Cloud KMS CryptoKeyVersion used to encrypt the secret payload, in the following format: `projects/*/locations/*/keyRings/*/cryptoKeys/*/versions/*`. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="destroy_time" type="string">
  Output only. The time this SecretVersion was destroyed. Only present if state is DESTROYED. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. Etag of the currently stored SecretVersion. Returned by the lookup.
</ResponseField>

<ResponseField name="replication_status" type="object">
  The replication status of a SecretVersion. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="automatic" type="object">
      The replication status of a SecretVersion using automatic replication. Only populated if the parent Secret has an automatic replication policy. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="customer_managed_encryption" type="object">
          Describes the status of customer-managed encryption. Optional lookup argument.
          <Expandable title="properties">
            <ResponseField name="kms_key_version_name" type="string">
              Required. The resource name of the Cloud KMS CryptoKeyVersion used to encrypt the secret payload, in the following format: `projects/*/locations/*/keyRings/*/cryptoKeys/*/versions/*`. Optional lookup argument.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="user_managed" type="object">
      The replication status of a SecretVersion using user-managed replication. Only populated if the parent Secret has a user-managed replication policy. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="replicas" type="list(object)">
          Output only. The list of replica statuses for the SecretVersion. Returned by the lookup.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scheduled_destroy_time" type="string">
  Optional. Output only. Scheduled destroy time for secret version. This is a part of the Delayed secret version destroy feature. For a Secret with a valid version destroy TTL, when a secert version is destroyed, version is moved to disabled state and it is scheduled for destruction Version is destroyed only after the scheduled_destroy_time. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the SecretVersion. Returned by the lookup.
</ResponseField>

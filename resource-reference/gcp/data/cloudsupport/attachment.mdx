`google_cloudsupport_attachment` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudsupport "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/cloudsupport"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_cloudsupport_attachment"})

    		ubx.Data(cloudsupport.Attachment, "example", cloudsupport.AttachmentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the attachment was created. Returned by the lookup.
</ResponseField>

<ResponseField name="creator" type="object">
  An Actor represents an entity that performed an action. For example, an actor could be a user who posted a comment on a support case, a user who uploaded an attachment, or a service account that created a support case. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="display_name" type="string">
      The name to display for the actor. If not provided, it is inferred from credentials supplied during case creation. When an email is provided, a display name must also be provided. This will be obfuscated if the user is a Google Support agent. Optional lookup argument.
    </ResponseField>
    <ResponseField name="email" type="string">
      The email address of the actor. If not provided, it is inferred from the credentials supplied during case creation. When a name is provided, an email must also be provided. If the user is a Google Support agent, this is obfuscated. This field is deprecated. Use `username` instead. Optional lookup argument.
    </ResponseField>
    <ResponseField name="google_support" type="bool">
      Output only. Whether the actor is a Google support actor. Returned by the lookup.
    </ResponseField>
    <ResponseField name="username" type="string">
      Output only. The username of the actor. It may look like an email or other format provided by the identity provider. If not provided, it is inferred from the credentials supplied. When a name is provided, a username must also be provided. If the user is a Google Support agent, this will not be set. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="filename" type="string">
  The filename of the attachment (e.g. `"graph.jpg"`). Returned by the lookup.
</ResponseField>

<ResponseField name="mime_type" type="string">
  Output only. The MIME type of the attachment (e.g. text/plain). Returned by the lookup.
</ResponseField>

<ResponseField name="size_bytes" type="string">
  Output only. The size of the attachment in bytes. Returned by the lookup.
</ResponseField>

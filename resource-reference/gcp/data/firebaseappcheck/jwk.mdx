`google_firebaseappcheck_jwk` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebaseappcheck "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/firebaseappcheck"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_firebaseappcheck_jwk"})

    		ubx.Data(firebaseappcheck.Jwk, "example", firebaseappcheck.JwkConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

`google_firebaseappcheck_device_check_config` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="key_id" type="string">
  Required. The key identifier of a private key enabled with DeviceCheck, created in your Apple Developer account. Returned by the lookup.
</ResponseField>

<ResponseField name="private_key" type="string">
  Required. Input only. The contents of the private key (`.p8`) file associated with the key specified by `key_id`. For security reasons, this field will never be populated in any response. Returned by the lookup.
</ResponseField>

<ResponseField name="private_key_set" type="bool">
  Output only. Whether the `private_key` field was previously set. Since we will never return the `private_key` field, this field is the only way to find out whether it was previously set. Returned by the lookup.
</ResponseField>

<ResponseField name="token_ttl" type="string">
  Specifies the duration for which App Check tokens exchanged from DeviceCheck tokens will be valid. If unset, a default value of 1 hour is assumed. Must be between 30 minutes and 7 days, inclusive. Returned by the lookup.
</ResponseField>

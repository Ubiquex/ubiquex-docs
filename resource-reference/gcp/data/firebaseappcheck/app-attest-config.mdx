## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebaseappcheck "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/firebaseappcheck"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_firebaseappcheck_app_attest_config"})

    		ubx.Data(firebaseappcheck.AppAttestConfig, "example", firebaseappcheck.AppAttestConfigConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

  Specifies the duration for which App Check tokens exchanged from App Attest artifacts will be valid. If unset, a default value of 1 hour is assumed. Must be between 30 minutes and 7 days, inclusive. Returned by the lookup.

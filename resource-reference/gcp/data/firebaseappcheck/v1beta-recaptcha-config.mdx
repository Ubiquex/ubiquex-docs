## Result properties

<ResponseField name="min_valid_score" type="number">
  Specifies a minimum score required for a reCAPTCHA token to be considered valid. If its score is greater than or equal to this value, it will be accepted; otherwise, it will be rejected. The value must be between 0.0 and 1.0. The default value is 0.5. Returned by the lookup.
</ResponseField>

<ResponseField name="site_secret" type="string">
  Required. Input only. The site secret used to identify your service for reCAPTCHA v3 verification. For security reasons, this field will never be populated in any response. Returned by the lookup.
</ResponseField>

<ResponseField name="site_secret_set" type="bool">
  Output only. Whether the `site_secret` field was previously set. Since we will never return the `site_secret` field, this field is the only way to find out whether it was previously set. Returned by the lookup.
</ResponseField>

<ResponseField name="token_ttl" type="string">
  Specifies the duration for which App Check tokens exchanged from reCAPTCHA tokens will be valid. If unset, a default value of 1 day is assumed. Must be between 30 minutes and 7 days, inclusive. Returned by the lookup.
</ResponseField>

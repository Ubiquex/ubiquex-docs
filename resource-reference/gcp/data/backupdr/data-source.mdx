title: "google_backupdr_data_source"
description: "`google_backupdr_data_source` is a real, live lookup against Google Cloud, generated from google's own real schema -- read-only, never created or destroyed."
---

`google_backupdr_data_source` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	backupdr "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/backupdr"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_backupdr_data_source"})

    		ubx.Data(backupdr.DataSource, "example", backupdr.DataSourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { DataSource } from "@ubx/sdk-google/google/data/backupdr/data_source";

    export default stack("example", () => {
      intent({ summary: "look up google_backupdr_data_source" });

      data(DataSource, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.backupdr import DataSource, DataSourceConfig

    def describe():
        ubx.intent("look up google_backupdr_data_source")

        ubx.data(DataSource, "example", DataSourceConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

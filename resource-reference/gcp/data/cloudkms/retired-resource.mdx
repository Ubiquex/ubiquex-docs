`google_cloudkms_retired_resource` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudkms "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/cloudkms"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_cloudkms_retired_resource"})

    		ubx.Data(cloudkms.RetiredResource, "example", cloudkms.RetiredResourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { RetiredResource } from "@ubx/sdk-google/google/data/cloudkms/retired_resource";

    export default stack("example", () => {
      intent({ summary: "look up google_cloudkms_retired_resource" });

      data(RetiredResource, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.cloudkms import RetiredResource, RetiredResourceConfig

    def describe():
        ubx.intent("look up google_cloudkms_retired_resource")

        ubx.data(RetiredResource, "example", RetiredResourceConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Result properties

<ResponseField name="delete_time" type="string">
  Output only. The time at which the original resource was deleted and this RetiredResource record was created. Returned by the lookup.
</ResponseField>

<ResponseField name="original_resource" type="string">
  Output only. The full resource name of the original CryptoKey that was deleted in the format `projects/*/locations/*/keyRings/*/cryptoKeys/*`. Returned by the lookup.
</ResponseField>

<ResponseField name="resource_type" type="string">
  Output only. The resource type of the original deleted resource. Returned by the lookup.
</ResponseField>

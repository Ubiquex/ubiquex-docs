## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	gkehub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/gkehub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_gkehub_v1beta_rollout"})

    		ubx.Data(gkehub.V1betaRollout, "example", gkehub.V1betaRolloutConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="complete_time" type="string">
  Output only. The timestamp at which the Rollout was completed. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The timestamp at which the Rollout was created. Returned by the lookup.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. The timestamp at the Rollout was deleted. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. Human readable display name of the Rollout. Returned by the lookup.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. etag of the Rollout Ex. abc1234 Returned by the lookup.
</ResponseField>

<ResponseField name="ignore_cluster_disruption_budgets" type="bool">
  Optional. If set to true, the rollout will ignore the disruption budgets of the clusters. Returned by the lookup.
</ResponseField>

<ResponseField name="ignore_maintenance_policies" type="bool">
  Optional. If set to true, the rollout will ignore any maintenance policies (Maintenance Windows and Maintenance Exclusions) set on the clusters. Returned by the lookup.
</ResponseField>

<ResponseField name="intent" type="string">
  Output only. The intent of the rollout. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels for this Rollout. Returned by the lookup.
</ResponseField>

<ResponseField name="membership_states" type="map(object)">
  Output only. States of upgrading control plane or node pool targets of a single cluster (GKE Hub membership) that's part of this Rollout. The key is the membership name of the cluster. The value is the state of the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="rollout_sequence" type="string">
  Optional. Immutable. The full, unique resource name of the rollout sequence that initiatied this Rollout. In the format of `projects/&#123;project&#125;/locations/global/rolloutSequences/&#123;rollout_sequence&#125;`. Returned by the lookup.
</ResponseField>

<ResponseField name="stage_soak_duration_overrides" type="map(string)">
  Optional. Overrides the soak durations for specific stages of the rollout. Key is the stage number, value is the desired soak duration. Stages omitted from the map will receive the standard soak duration configured on the sequence for that stage. Returned by the lookup.
</ResponseField>

<ResponseField name="stages" type="list(object)">
  Output only. The stages of the Rollout. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State specifies various states of the Rollout. Returned by the lookup.
</ResponseField>

<ResponseField name="state_reason" type="string">
  Output only. A human-readable description explaining the reason for the current state. Returned by the lookup.
</ResponseField>

<ResponseField name="state_reason_type" type="string">
  Output only. StateReasonType specifies the reason type of the Rollout state. Returned by the lookup.
</ResponseField>

<ResponseField name="trigger" type="string">
  Output only. The trigger of the rollout. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Google-generated UUID for this resource. This is unique across all Rollout resources. If a Rollout resource is deleted and another resource with the same name is created, it gets a different uid. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp at which the Rollout was last updated. Returned by the lookup.
</ResponseField>

<ResponseField name="version_upgrade" type="object">
  Config for version upgrade of clusters. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="desired_version" type="string">
      Optional. Desired version of the component. Optional lookup argument.
    </ResponseField>
    <ResponseField name="type" type="string">
      Optional. Type of version upgrade specifies which component should be upgraded. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

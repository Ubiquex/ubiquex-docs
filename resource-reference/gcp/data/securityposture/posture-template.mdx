`google_securityposture_posture_template` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	securityposture "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/securityposture"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_securityposture_posture_template"})

    		ubx.Data(securityposture.PostureTemplate, "example", securityposture.PostureTemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<ResponseField name="name" type="string" required>
  Required lookup argument.

## Result properties

<ResponseField name="categories" type="list(string)">
  Output only. The categories that the posture template belongs to, as determined by the Security Posture API. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Output only. A description of the posture template. Returned by the lookup.
</ResponseField>

<ResponseField name="policy_sets" type="list(object)">
  Output only. The PolicySet resources that the posture template includes. Returned by the lookup.
</ResponseField>

<ResponseField name="revision_id" type="string">
  Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the posture template at the specified `revision_id`. Returned by the lookup.
</ResponseField>

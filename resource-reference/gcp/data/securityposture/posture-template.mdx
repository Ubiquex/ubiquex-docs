---
title: "google_securityposture_posture_template"
description: "`data_securityposture_posture_template` looks up a real, already-existing `google_securityposture_posture`."
---

It defines a versioned bundle of Organization Policy constraint(s) and Security Health Analytics module setting(s) that Security Posture management can deploy as a unit.

## Result properties

<ResponseField name="categories" type="list(string)">
  Output only. The categories that the posture template belongs to, as determined by the Security Posture API. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Output only. A description of the posture template. Returned by the lookup.
</ResponseField>

<ResponseField name="policy_sets" type="list(object)">
  Output only. The PolicySet resources that the posture template includes. Returned by the lookup.
</ResponseField>

<ResponseField name="revision_id" type="string">
  The real, unique identifier of the revision this lookup is scoped to. **(AI-inferred)** Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the posture template at the specified `revision_id`. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	sqladmin "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/sqladmin"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_sqladmin_v1beta4_connect"})

    		ubx.Data(sqladmin.V1beta4Connect, "example", sqladmin.V1beta4ConnectConfig{
    			Instance: "example",
    			Project:  "example",
    			ReadTime: "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="instance" type="string" required>
  The real instance this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="project" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="read_time" type="string">
  The real point in time this read is evaluated as of. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="backend_type" type="string">
  `SECOND_GEN`: Cloud SQL database instance. `EXTERNAL`: A database server that is not managed by Google. This property is read-only; use the `tier` property in the `settings` object to determine the database type. Returned by the lookup.
</ResponseField>

<ResponseField name="connection_name" type="string">
  Optional. Output only. Connection name of the Cloud SQL instance used in connection strings, in the format project:region:instance. Returned by the lookup.
</ResponseField>

<ResponseField name="custom_subject_alternative_names" type="list(string)">
  Custom subject alternative names for the server certificate. Returned by the lookup.
</ResponseField>

<ResponseField name="database_version" type="string">
  The database engine type and version. The `databaseVersion` field cannot be changed after instance creation. MySQL instances: `MYSQL_8_0`, `MYSQL_5_7` (default), or `MYSQL_5_6`. PostgreSQL instances: `POSTGRES_9_6`, `POSTGRES_10`, `POSTGRES_11` or `POSTGRES_12` (default), `POSTGRES_13`, or `POSTGRES_14`. SQL Server instances: `SQLSERVER_2017_STANDARD` (default), `SQLSERVER_2017_ENTERPRISE`, `SQLSERVER_2017_EXPRESS`, `SQLSERVER_2017_WEB`, `SQLSERVER_2019_STANDARD`, `SQLSERVER_2019_ENTERPRISE`, `SQLSERVER_2019_EXPRESS`, or `SQLSERVER_2019_WEB`. Returned by the lookup.
</ResponseField>

<ResponseField name="dns_name" type="string">
  The dns name of the instance. Returned by the lookup.
</ResponseField>

<ResponseField name="dns_names" type="list(object)">
  Output only. The list of DNS names used by this instance. Returned by the lookup.
</ResponseField>

<ResponseField name="ip_addresses" type="list(object)">
  The assigned IP addresses for the instance. Returned by the lookup.
</ResponseField>

<ResponseField name="kind" type="string">
  This is always `sql#connectSettings`. Returned by the lookup.
</ResponseField>

<ResponseField name="mdx_protocol_support" type="list(string)">
  Optional. Output only. mdx_protocol_support controls how the client uses metadata exchange when connecting to the instance. The values in the list representing parts of the MDX protocol that are supported by this instance. When the list is empty, the instance does not support MDX, so the client must not send an MDX request. The default is empty. Returned by the lookup.
</ResponseField>

<ResponseField name="node_count" type="number">
  The number of read pool nodes in a read pool. Returned by the lookup.
</ResponseField>

<ResponseField name="nodes" type="list(object)">
  Output only. Entries containing information about each read pool node of the read pool. Returned by the lookup.
</ResponseField>

<ResponseField name="psc_enabled" type="bool">
  Whether PSC connectivity is enabled for this instance. Returned by the lookup.
</ResponseField>

<ResponseField name="region" type="string">
  The cloud region for the instance. e.g. `us-central1`, `europe-west1`. The region cannot be changed after instance creation. Returned by the lookup.
</ResponseField>

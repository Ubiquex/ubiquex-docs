`data_storage_service_account` looks up the real, project-scoped Google-managed service account Cloud Storage uses for Pub/Sub notifications and encryption.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	storage "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/storage"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_storage_service_account"})

    		ubx.Data(storage.ServiceAccount, "example", storage.ServiceAccountConfig{
    			ProjectId:   "example",
    			UserProject: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.storage import ServiceAccount, ServiceAccountConfig

    def describe():
        ubx.intent("look up google_storage_service_account")

        ubx.data(ServiceAccount, "example", ServiceAccountConfig(
            project_id="example",
            user_project="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>

## Lookup arguments

<ResponseField name="project_id" type="string" required>
  The real Google Cloud project ID this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="user_project" type="string">
  The real Google Cloud project to bill and authorize this request against. **(AI-inferred)** Optional lookup argument.
</ResponseField>

## Result properties

<ResponseField name="email_address" type="string">
  The ID of the notification. Returned by the lookup.
</ResponseField>

<ResponseField name="kind" type="string">
  The kind of item this is. For notifications, this is always storage#notification. Returned by the lookup.
</ResponseField>

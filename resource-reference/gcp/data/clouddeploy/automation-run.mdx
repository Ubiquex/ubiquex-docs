---
title: "google_clouddeploy_automation_run"
description: "`data_clouddeploy_automation_run` looks up a real, already-existing `google_clouddeploy_automation`."
---

It configures Cloud Deploy to automatically run action(s) (e.g. promoting a release to the next stage, or repeating a rollout) when a defined event occurs in a delivery pipeline, without a human triggering it.

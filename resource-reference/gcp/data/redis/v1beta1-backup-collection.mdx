## Result properties

<ResponseField name="cluster" type="string">
  Output only. The full resource path of the cluster the backup collection belongs to. Example: projects/&#123;project&#125;/locations/&#123;location&#125;/clusters/&#123;cluster&#125; Returned by the lookup.
</ResponseField>

<ResponseField name="cluster_uid" type="string">
  Output only. The cluster uid of the backup collection. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the backup collection was created. Returned by the lookup.
</ResponseField>

<ResponseField name="kms_key" type="string">
  Output only. The KMS key used to encrypt the backups under this backup collection. Returned by the lookup.
</ResponseField>

<ResponseField name="last_backup_time" type="string">
  Output only. The last time a backup was created in the backup collection. Returned by the lookup.
</ResponseField>

<ResponseField name="total_backup_count" type="string">
  Output only. Total number of backups in the backup collection. Returned by the lookup.
</ResponseField>

<ResponseField name="total_backup_size_bytes" type="string">
  Output only. Total size of all backups in the backup collection. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System assigned unique identifier of the backup collection. Returned by the lookup.
</ResponseField>

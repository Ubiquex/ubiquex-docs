## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	redis "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/redis"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_redis_backup"})

    		ubx.Data(redis.Backup, "example", redis.BackupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="backup_files" type="list(object)">
  Output only. List of backup files of the backup. Returned by the lookup.
</ResponseField>

<ResponseField name="backup_type" type="string">
  Output only. Type of the backup. Returned by the lookup.
</ResponseField>

<ResponseField name="cluster" type="string">
  Output only. Cluster resource path of this backup. Returned by the lookup.
</ResponseField>

<ResponseField name="cluster_uid" type="string">
  Output only. Cluster uid of this backup. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time when the backup was created. Returned by the lookup.
</ResponseField>

<ResponseField name="encryption_info" type="object">
  EncryptionInfo describes the encryption information of a cluster or a backup. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="encryption_type" type="string">
      Output only. Type of encryption. Returned by the lookup.
    </ResponseField>
    <ResponseField name="kms_key_primary_state" type="string">
      Output only. The state of the primary version of the KMS key perceived by the system. This field is not populated in backups. Returned by the lookup.
    </ResponseField>
    <ResponseField name="kms_key_versions" type="list(string)">
      Output only. KMS key versions that are being used to protect the data at-rest. Returned by the lookup.
    </ResponseField>
    <ResponseField name="last_update_time" type="string">
      Output only. The most recent time when the encryption info was updated. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="engine_version" type="string">
  Output only. redis-7.2, valkey-7.5 Returned by the lookup.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The time when the backup will expire. Returned by the lookup.
</ResponseField>

<ResponseField name="node_type" type="string">
  Output only. Node type of the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="replica_count" type="number">
  Output only. Number of replicas for the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="shard_count" type="number">
  Output only. Number of shards for the cluster. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the backup. Returned by the lookup.
</ResponseField>

<ResponseField name="total_size_bytes" type="string">
  Output only. Total size of the backup in bytes. Returned by the lookup.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System assigned unique identifier of the backup. Returned by the lookup.
</ResponseField>

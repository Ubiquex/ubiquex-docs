---
title: "google_workloadmanager_health"
description: "`data_workloadmanager_health` looks up the real, current health evaluation of a workload tracked by Workload Manager."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	workloadmanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/workloadmanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_workloadmanager_health"})

    		ubx.Data(workloadmanager.Health, "example", workloadmanager.HealthConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    import { Health } from "@ubx/sdk-google/google/data/workloadmanager/health";

    export default stack("example", () => {
      intent({ summary: "look up google_workloadmanager_health" });

      data(Health, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.data.workloadmanager import Health, HealthConfig

    def describe():
        ubx.intent("look up google_workloadmanager_health")

        ubx.data(Health, "example", HealthConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="check_time" type="string">
  The time when the health check was performed. Returned by the lookup.
</ResponseField>

<ResponseField name="components_health" type="list(object)">
  The detailed condition reports of each component. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The health state of the workload. Returned by the lookup.
</ResponseField>

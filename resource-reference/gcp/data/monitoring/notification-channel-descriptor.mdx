## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="description" type="string">
  A human-readable description of the notification channel type. The description may include a description of the properties of the channel and pointers to external documentation. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  A human-readable name for the notification channel type. This form of the name is suitable for a user interface. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="list(object)">
  The set of labels that must be defined to identify a particular channel of the corresponding type. Each label includes a description for how that field should be populated. Returned by the lookup.
</ResponseField>

<ResponseField name="launch_stage" type="string">
  The product launch stage for channels of this type. Returned by the lookup.
</ResponseField>

<ResponseField name="supported_tiers" type="list(string)">
  The tiers that support this notification channel; the project service tier must be one of the supported_tiers. Returned by the lookup.
</ResponseField>

<ResponseField name="type" type="string">
  The type of notification channel, such as "email" and "sms". To view the full list of channels, see Channel descriptors (https://cloud.google.com/monitoring/alerts/using-channels-api#ncd). Notification channel types are globally unique. Returned by the lookup.
</ResponseField>

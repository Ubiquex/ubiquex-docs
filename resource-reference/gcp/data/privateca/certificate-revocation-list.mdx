---
title: "google_privateca_certificate_revocation_list"
description: "`data_privateca_certificate_revocation_list` looks up a real, already-existing `google_privateca_certificate`."
---

It is an X.509 certificate issued by a Certificate Authority Service CA, either directly requested or generated from a Certificate Manager Google-managed certificate.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	privateca "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/privateca"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_privateca_certificate_revocation_list"})

    		ubx.Data(privateca.CertificateRevocationList, "example", privateca.CertificateRevocationListConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="access_url" type="string">
  Output only. The location where 'pem_crl' can be accessed. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time at which this CertificateRevocationList was created. Returned by the lookup.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels with user-defined metadata. Returned by the lookup.
</ResponseField>

<ResponseField name="pem_crl" type="string">
  Output only. The PEM-encoded X.509 CRL. Returned by the lookup.
</ResponseField>

<ResponseField name="revision_id" type="string">
  Output only. The revision ID of this CertificateRevocationList. A new revision is committed whenever a new CRL is published. The format is an 8-character hexadecimal string. Returned by the lookup.
</ResponseField>

<ResponseField name="revoked_certificates" type="list(object)">
  Output only. The revoked serial numbers that appear in pem_crl. Returned by the lookup.
</ResponseField>

<ResponseField name="sequence_number" type="string">
  Output only. The CRL sequence number that appears in pem_crl. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The State for this CertificateRevocationList. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which this CertificateRevocationList was updated. Returned by the lookup.
</ResponseField>

`google_firestore_v1beta2_field` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firestore "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/firestore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_firestore_v1beta2_field"})

    		ubx.Data(firestore.V1beta2Field, "example", firestore.V1beta2FieldConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Result properties

<ResponseField name="index_config" type="object">
  The index configuration for this field. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="ancestor_field" type="string">
      Output only. Specifies the resource name of the `Field` from which this field's index configuration is set (when `uses_ancestor_config` is true), or from which it *would* be set if this field had no index configuration (when `uses_ancestor_config` is false). Optional lookup argument.
    </ResponseField>
    <ResponseField name="indexes" type="list(object)">
      The indexes supported for this field. Optional lookup argument.
    </ResponseField>
    <ResponseField name="reverting" type="bool">
      Output only When true, the `Field`'s index configuration is in the process of being reverted. Once complete, the index config will transition to the same state as the field specified by `ancestor_field`, at which point `uses_ancestor_config` will be `true` and `reverting` will be `false`. Optional lookup argument.
    </ResponseField>
    <ResponseField name="uses_ancestor_config" type="bool">
      Output only. When true, the `Field`'s index configuration is set from the configuration specified by the `ancestor_field`. When false, the `Field`'s index configuration is defined explicitly. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

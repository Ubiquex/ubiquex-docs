## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firestore "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/firestore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_firestore_backup"})

    		ubx.Data(firestore.Backup, "example", firestore.BackupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    import ubx_sdk as ubx

        ubx.intent("look up google_firestore_backup")

        ubx.run("example", describe)

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="database" type="string">
  Output only. Name of the Firestore database that the backup is from. Format is `projects/&#123;project&#125;/databases/&#123;database&#125;`. Returned by the lookup.
</ResponseField>

<ResponseField name="database_uid" type="string">
  Output only. The system-generated UUID4 for the Firestore database that the backup is from. Returned by the lookup.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The timestamp at which this backup expires. Returned by the lookup.
</ResponseField>

<ResponseField name="snapshot_time" type="string">
  Output only. The backup contains an externally consistent copy of the database at this time. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the backup. Returned by the lookup.
</ResponseField>

<ResponseField name="stats" type="object">
  Backup specific statistics. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="document_count" type="string">
      Output only. The total number of documents contained in the backup. Returned by the lookup.
    </ResponseField>
    <ResponseField name="index_count" type="string">
      Output only. The total number of index entries contained in the backup. Returned by the lookup.
    </ResponseField>
    <ResponseField name="size_bytes" type="string">
      Output only. Summation of the size of all documents and index entries in the backup, measured in bytes. Returned by the lookup.
    </ResponseField>
  </Expandable>
</ResponseField>

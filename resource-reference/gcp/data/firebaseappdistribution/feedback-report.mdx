`google_firebaseappdistribution_feedback_report` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Result properties

<ResponseField name="create_time" type="string">
  Output only. The time when the feedback report was created. Returned by the lookup.
</ResponseField>

<ResponseField name="firebase_console_uri" type="string">
  Output only. A link to the Firebase console displaying the feedback report. Returned by the lookup.
</ResponseField>

<ResponseField name="screenshot_uri" type="string">
  Output only. A signed link (which expires in one hour) that lets you directly download the screenshot. Returned by the lookup.
</ResponseField>

<ResponseField name="tester" type="string">
  Output only. The resource name of the tester who submitted the feedback report. Returned by the lookup.
</ResponseField>

<ResponseField name="text" type="string">
  Output only. The text of the feedback report. Returned by the lookup.
</ResponseField>

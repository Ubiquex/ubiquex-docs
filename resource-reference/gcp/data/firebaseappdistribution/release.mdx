`google_firebaseappdistribution_release` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	firebaseappdistribution "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/firebaseappdistribution"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_firebaseappdistribution_release"})

    		ubx.Data(firebaseappdistribution.Release, "example", firebaseappdistribution.ReleaseConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Result properties

<ResponseField name="accepted_invitation_count" type="number">
  Output only. Number of testers with accepted invitations. Returned by the lookup.
</ResponseField>

<ResponseField name="android_package_registration_state" type="string">
  Output only. Registration state of the Android package (BinaryType.APK). Returned by the lookup.
</ResponseField>

<ResponseField name="binary_download_uri" type="string">
  Output only. A signed link (which expires in one hour) to directly download the app binary (IPA/APK/AAB) file. Returned by the lookup.
</ResponseField>

<ResponseField name="binary_type" type="string">
  Output only. Type of binary. Returned by the lookup.
</ResponseField>

<ResponseField name="build_version" type="string">
  Output only. Build version of the release. For an Android release, the build version is the `versionCode`. For an iOS release, the build version is the `CFBundleVersion`. Returned by the lookup.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The time the release was created. Returned by the lookup.
</ResponseField>

<ResponseField name="display_version" type="string">
  Output only. Display version of the release. For an Android release, the display version is the `versionName`. For an iOS release, the display version is the `CFBundleShortVersionString`. Returned by the lookup.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The time the release will expire. Returned by the lookup.
</ResponseField>

<ResponseField name="feedback_count" type="number">
  Output only. Number of feedback reports left by testers. Returned by the lookup.
</ResponseField>

<ResponseField name="firebase_console_uri" type="string">
  Output only. A link to the Firebase console displaying a single release. Returned by the lookup.
</ResponseField>

<ResponseField name="installation_count" type="number">
  Output only. Number of testers who have downloaded this release. Returned by the lookup.
</ResponseField>

<ResponseField name="open_invitation_count" type="number">
  Output only. Number of testers who were invited (incl. expired invitations), but did not (yet) accept the invitation. Returned by the lookup.
</ResponseField>

<ResponseField name="release_notes" type="object">
  Notes that belong to a release. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="text" type="string">
      The text of the release notes. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="test_state" type="string">
  Output only. The overall state of tests run on this release Returned by the lookup.
</ResponseField>

<ResponseField name="testing_uri" type="string">
  Output only. A link to the release in the tester web clip or Android app that lets testers (which were granted access to the app) view release notes and install the app onto their devices. Returned by the lookup.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time the release was last updated. Returned by the lookup.
</ResponseField>

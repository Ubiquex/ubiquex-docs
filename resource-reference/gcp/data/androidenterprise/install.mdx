`google_androidenterprise_install` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

## Result properties

<ResponseField name="install_state" type="string">
  Install state. The state "installPending" means that an install request has recently been made and download to the device is in progress. The state "installed" means that the app has been installed. This field is read-only. Returned by the lookup.
</ResponseField>

<ResponseField name="product_id" type="string">
  The ID of the product that the install is for. For example, "app:com.google.android.gm". Returned by the lookup.
</ResponseField>

<ResponseField name="version_code" type="number">
  The version of the installed product. Guaranteed to be set only if the install state is "installed". Returned by the lookup.
</ResponseField>

## Lookup arguments

<ResponseField name="device_id" type="string" required>
  The real, unique identifier of the device this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="enterprise_id" type="string" required>
  The real, unique identifier of the Android Enterprise this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="install_id" type="string" required>
  The real, unique identifier of the install this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="user_id" type="string" required>
  The real, unique identifier of the user this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="install_state" type="string">
  Install state. The state "installPending" means that an install request has recently been made and download to the device is in progress. The state "installed" means that the app has been installed. This field is read-only. Returned by the lookup.
</ResponseField>

<ResponseField name="product_id" type="string">
  The ID of the product that the install is for. For example, "app:com.google.android.gm". Returned by the lookup.
</ResponseField>

<ResponseField name="version_code" type="number">
  The version of the installed product. Guaranteed to be set only if the install state is "installed". Returned by the lookup.
</ResponseField>

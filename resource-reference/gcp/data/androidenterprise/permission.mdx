`data_androidenterprise_permission` looks up a real Android app permission, along with its own human-readable name and description, from the Android Enterprise API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidenterprise_permission"})

    		ubx.Data(androidenterprise.Permission, "example", androidenterprise.PermissionConfig{
    			PermissionId: "example",
    			Language:     "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { data, intent, stack } from "@ubx/sdk";
    // ubx sdk gen --only google --lang ts --out ./local-sdk
    import { Permission } from "./local-sdk/google/sdk/typescript/google/data/androidenterprise/permission.ts";

    export default stack("example", () => {
      intent({ summary: "look up google_androidenterprise_permission" });

      data(Permission, "example", {

      });

    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.androidenterprise import Permission, PermissionConfig

    def describe():
        ubx.intent("look up google_androidenterprise_permission")

        ubx.data(Permission, "example", PermissionConfig(
            permission_id="example",
            language="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```
  </Tab>
</Tabs>

## Lookup arguments

<ResponseField name="language" type="string">
  The real, BCP-47 language code this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="permission_id" type="string" required>
  The real, unique identifier of the permission this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="description" type="string">
  A longer description of the Permissions resource, giving more details of what it affects. Returned by the lookup.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the permission. Returned by the lookup.
</ResponseField>

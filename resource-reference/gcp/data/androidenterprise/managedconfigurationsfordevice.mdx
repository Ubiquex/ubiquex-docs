## Lookup arguments

<ResponseField name="device_id" type="string" required>
  The real, unique identifier of the device this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="enterprise_id" type="string" required>
  The real, unique identifier of the Android Enterprise this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="managed_configuration_for_device_id" type="string" required>
  The real, unique identifier of the device-scoped managed configuration this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="user_id" type="string" required>
  The real, unique identifier of the user this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="configuration_variables" type="object">
  A configuration variables resource contains the managed configuration settings ID to be applied to a single user, as well as the variable set that is attributed to the user. The variable set will be used to replace placeholders in the managed configuration settings. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="mcm_id" type="string">
      The ID of the managed configurations settings. Optional lookup argument.
    </ResponseField>
    <ResponseField name="variable_set" type="list(object)">
      The variable set that is attributed to the user. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

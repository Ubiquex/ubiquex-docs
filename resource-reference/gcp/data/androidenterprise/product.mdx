## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidenterprise_product"})

    		ubx.Data(androidenterprise.Product, "example", androidenterprise.ProductConfig{
    			EnterpriseId: "example",
    			ProductId:    "example",
    			Language:     "example",
    		})
    	}))
    }
    ```

## Lookup arguments

<ResponseField name="enterprise_id" type="string" required>
  The real, unique identifier of the Android Enterprise this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="language" type="string">
  The real, BCP-47 language code this lookup is scoped to. **(AI-inferred)** Optional lookup argument.
</ResponseField>

<ResponseField name="product_id" type="string" required>
  The real, unique identifier of the product this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="app_restrictions_schema" type="object">
  Represents the list of app restrictions available to be pre-configured for the product. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="kind" type="string">
      Deprecated. Optional lookup argument.
    </ResponseField>
    <ResponseField name="restrictions" type="list(object)">
      The set of restrictions that make up this schema. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="app_tracks" type="list(object)">
  The tracks visible to the enterprise. Returned by the lookup.
</ResponseField>

<ResponseField name="app_version" type="list(object)">
  App versions currently available for this product. Returned by the lookup.
</ResponseField>

<ResponseField name="author_name" type="string">
  The name of the author of the product (for example, the app developer). Returned by the lookup.
</ResponseField>

<ResponseField name="available_countries" type="list(string)">
  The countries which this app is available in. Returned by the lookup.
</ResponseField>

<ResponseField name="available_tracks" type="list(string)">
  Deprecated, use appTracks instead. Returned by the lookup.
</ResponseField>

<ResponseField name="category" type="string">
  The app category (e.g. RACING, SOCIAL, etc.) Returned by the lookup.
</ResponseField>

<ResponseField name="content_rating" type="string">
  The content rating for this app. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  The localized promotional description, if available. Returned by the lookup.
</ResponseField>

<ResponseField name="details_url" type="string">
  A link to the (consumer) Google Play details page for the product. Returned by the lookup.
</ResponseField>

<ResponseField name="distribution_channel" type="string">
  How and to whom the package is made available. The value publicGoogleHosted means that the package is available through the Play store and not restricted to a specific enterprise. The value privateGoogleHosted means that the package is a private app (restricted to an enterprise) but hosted by Google. The value privateSelfHosted means that the package is a private app (restricted to an enterprise) and is privately hosted. Returned by the lookup.
</ResponseField>

<ResponseField name="features" type="list(string)">
  Noteworthy features (if any) of this product. Returned by the lookup.
</ResponseField>

<ResponseField name="full_description" type="string">
  The localized full app store description, if available. Returned by the lookup.
</ResponseField>

<ResponseField name="icon_url" type="string">
  A link to an image that can be used as an icon for the product. This image is suitable for use at up to 512px x 512px. Returned by the lookup.
</ResponseField>

<ResponseField name="last_updated_timestamp_millis" type="string">
  The approximate time (within 7 days) the app was last published, expressed in milliseconds since epoch. Returned by the lookup.
</ResponseField>

<ResponseField name="min_android_sdk_version" type="number">
  The minimum Android SDK necessary to run the app. Returned by the lookup.
</ResponseField>

<ResponseField name="permissions" type="list(object)">
  A list of permissions required by the app. Returned by the lookup.
</ResponseField>

<ResponseField name="product_pricing" type="string">
  Whether this product is free, free with in-app purchases, or paid. If the pricing is unknown, this means the product is not generally available anymore (even though it might still be available to people who own it). Returned by the lookup.
</ResponseField>

<ResponseField name="recent_changes" type="string">
  A description of the recent changes made to the app. Returned by the lookup.
</ResponseField>

<ResponseField name="requires_container_app" type="bool">
  Deprecated. Returned by the lookup.
</ResponseField>

<ResponseField name="screenshot_urls" type="list(string)">
  A list of screenshot links representing the app. Returned by the lookup.
</ResponseField>

<ResponseField name="signing_certificate" type="object">
  The real, PEM-encoded signing certificate for this app. **(AI-inferred)** Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="certificate_hash_sha1" type="string">
      The base64 urlsafe encoded SHA1 hash of the certificate. (This field is deprecated in favor of SHA2-256. It should not be used and may be removed at any time.) Optional lookup argument.
    </ResponseField>
    <ResponseField name="certificate_hash_sha256" type="string">
      The base64 urlsafe encoded SHA2-256 hash of the certificate. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="small_icon_url" type="string">
  A link to a smaller image that can be used as an icon for the product. This image is suitable for use at up to 128px x 128px. Returned by the lookup.
</ResponseField>

<ResponseField name="title" type="string">
  The name of the product. Returned by the lookup.
</ResponseField>

<ResponseField name="work_details_url" type="string">
  A link to the managed Google Play details page for the product, for use by an Enterprise admin. Returned by the lookup.
</ResponseField>

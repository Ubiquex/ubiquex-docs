`data_androidenterprise_entitlement` looks up a real user's own right to install and use a specific app, granted via the Android Enterprise (Google Play EMM) API.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidenterprise_entitlement"})

    		ubx.Data(androidenterprise.Entitlement, "example", androidenterprise.EntitlementConfig{
    			EnterpriseId:  "example",
    			EntitlementId: "example",
    			UserId:        "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="enterprise_id" type="string" required>
  The real, unique identifier of the Android Enterprise this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="entitlement_id" type="string" required>
  The real, unique identifier of the entitlement this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

<ResponseField name="user_id" type="string" required>
  The real, unique identifier of the user this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="product_id" type="string">
  The ID of the product that the entitlement is for. For example, "app:com.google.android.gm". Returned by the lookup.
</ResponseField>

<ResponseField name="reason" type="string">
  The reason for the entitlement. For example, "free" for free apps. This property is temporary: it will be replaced by the acquisition kind field of group licenses. Returned by the lookup.
</ResponseField>

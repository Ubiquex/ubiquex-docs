`google_androidenterprise_device` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	androidenterprise "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/androidenterprise"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_androidenterprise_device"})

    		ubx.Data(androidenterprise.Device, "example", androidenterprise.DeviceConfig{
    			DeviceId:     "example",
    			EnterpriseId: "example",
    			UserId:       "example",
    		})
    	}))
    }
    ```

## Result properties

<ResponseField name="android_id" type="string">
  The Google Play Services Android ID for the device encoded as a lowercase hex string. For example, "123456789abcdef0". Returned by the lookup.
</ResponseField>

<ResponseField name="device" type="string">
  The internal hardware codename of the device. This comes from android.os.Build.DEVICE. (field named "device" per logs/wireless/android/android_checkin.proto) Returned by the lookup.
</ResponseField>

<ResponseField name="latest_build_fingerprint" type="string">
  The build fingerprint of the device if known. Returned by the lookup.
</ResponseField>

<ResponseField name="maker" type="string">
  The manufacturer of the device. This comes from android.os.Build.MANUFACTURER. Returned by the lookup.
</ResponseField>

<ResponseField name="management_type" type="string">
  Identifies the extent to which the device is controlled by a managed Google Play EMM in various deployment configurations. Possible values include: - "managedDevice", a device that has the EMM's device policy controller (DPC) as the device owner. - "managedProfile", a device that has a profile managed by the DPC (DPC is profile owner) in addition to a separate, personal profile that is unavailable to the DPC. - "containerApp", no longer used (deprecated). - "unmanagedProfile", a device that has been allowed (by the domain's admin, using the Admin Console to enable the privilege) to use managed Google Play, but the profile is itself not owned by a DPC. Returned by the lookup.
</ResponseField>

<ResponseField name="model" type="string">
  The model name of the device. This comes from android.os.Build.MODEL. Returned by the lookup.
</ResponseField>

<ResponseField name="policy" type="object">
  The device policy for a given managed device. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="auto_update_policy" type="string">
      Controls when automatic app updates on the device can be applied. Recommended alternative: autoUpdateMode which is set per app, provides greater flexibility around update frequency. When autoUpdateMode is set to AUTO_UPDATE_POSTPONED or AUTO_UPDATE_HIGH_PRIORITY, autoUpdatePolicy has no effect. - choiceToTheUser allows the device's user to configure the app update policy. - always enables auto updates. - never disables auto updates. - wifiOnly enables auto updates only when the device is connected to wifi. *Important:* Changes to app update policies don't affect updates that are in progress. Any policy changes will apply to subsequent app updates. Optional lookup argument.
    </ResponseField>
    <ResponseField name="device_report_policy" type="string">
      Whether the device reports app states to the EMM. The default value is "deviceReportDisabled". Optional lookup argument.
    </ResponseField>
    <ResponseField name="maintenance_window" type="object">
      Maintenance window for managed Google Play Accounts. This allows Play store to update the apps on the foreground in the designated window. Optional lookup argument.
      <Expandable title="properties">
        <ResponseField name="duration_ms" type="string">
          Duration of the maintenance window, in milliseconds. The duration must be between 30 minutes and 24 hours (inclusive). Optional lookup argument.
        </ResponseField>
        <ResponseField name="start_time_after_midnight_ms" type="string">
          Start time of the maintenance window, in milliseconds after midnight on the device. Windows can span midnight. Optional lookup argument.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="policy_id" type="string">
      An identifier for the policy that will be passed with the app install feedback sent from the Play Store. Optional lookup argument.
    </ResponseField>
    <ResponseField name="product_availability_policy" type="string">
      The availability granted to the device for the specified products. "all" gives the device access to all products, regardless of approval status. "all" does not enable automatic visibility of "alpha" or "beta" tracks. "whitelist" grants the device access the products specified in productPolicy[]. Only products that are approved or products that were previously approved (products with revoked approval) by the enterprise can be whitelisted. If no value is provided, the availability set at the user level is applied by default. Optional lookup argument.
    </ResponseField>
    <ResponseField name="product_policy" type="list(object)">
      The list of product policies. The productAvailabilityPolicy needs to be set to WHITELIST or ALL for the product policies to be applied. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="product" type="string">
  The product name of the device. This comes from android.os.Build.PRODUCT. Returned by the lookup.
</ResponseField>

<ResponseField name="report" type="object">
  Device report updated with the latest app states for managed apps on the device. Returned by the lookup.
  <Expandable title="properties">
    <ResponseField name="app_state" type="list(object)">
      List of app states set by managed apps on the device. App states are defined by the app's developers. This field will always be present. Optional lookup argument.
    </ResponseField>
    <ResponseField name="last_updated_timestamp_millis" type="string">
      The timestamp of the last report update in milliseconds since epoch. This field will always be present. Optional lookup argument.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="retail_brand" type="string">
  Retail brand for the device, if set. See android.os.Build.BRAND Returned by the lookup.
</ResponseField>

<ResponseField name="sdk_version" type="number">
  API compatibility version. Returned by the lookup.
</ResponseField>

---
title: "google_apigee_app"
description: "`data_apigee_app` looks up a real, already-existing `google_apigee_app`."
---

It (a Developer App) is the credential-holding registration a developer creates to consume one or more Apigee API products, carrying the API key(s) used to authenticate its own requests.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apigee_app"})

    		ubx.Data(apigee.App, "example", apigee.AppConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

    ```python
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.apigee import App, AppConfig

    def describe():
        ubx.intent("look up google_apigee_app")

        ubx.data(App, "example", AppConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Result properties

<ResponseField name="api_products" type="list(object)">
  List of API products associated with the app. Returned by the lookup.
</ResponseField>

<ResponseField name="app_group" type="string">
  Name of the AppGroup Returned by the lookup.
</ResponseField>

<ResponseField name="app_id" type="string">
  ID of the app. Returned by the lookup.
</ResponseField>

<ResponseField name="attributes" type="list(object)">
  List of attributes. Returned by the lookup.
</ResponseField>

<ResponseField name="callback_url" type="string">
  Callback URL used by OAuth 2.0 authorization servers to communicate authorization codes back to apps. Returned by the lookup.
</ResponseField>

<ResponseField name="company_name" type="string">
  Name of the company that owns the app. Returned by the lookup.
</ResponseField>

<ResponseField name="created_at" type="string">
  Output only. Unix time when the app was created. Returned by the lookup.
</ResponseField>

<ResponseField name="credentials" type="list(object)">
  Output only. Set of credentials for the app. Credentials are API key/secret pairs associated with API products. Returned by the lookup.
</ResponseField>

<ResponseField name="developer_email" type="string">
  Email of the developer. Returned by the lookup.
</ResponseField>

<ResponseField name="developer_id" type="string">
  ID of the developer. Returned by the lookup.
</ResponseField>

<ResponseField name="key_expires_in" type="string">
  Duration, in milliseconds, of the consumer key that will be generated for the app. The default value, -1, indicates an infinite validity period. Once set, the expiration can't be updated. json key: keyExpiresIn Returned by the lookup.
</ResponseField>

<ResponseField name="last_modified_at" type="string">
  Output only. Last modified time as milliseconds since epoch. Returned by the lookup.
</ResponseField>

<ResponseField name="scopes" type="list(string)">
  Scopes to apply to the app. The specified scope names must already exist on the API product that you associate with the app. Returned by the lookup.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the credential. Returned by the lookup.
</ResponseField>

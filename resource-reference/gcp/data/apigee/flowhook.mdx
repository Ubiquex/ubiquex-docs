`google_apigee_flowhook` is a real, live data source: `ubx.Data`/`data`/`ubx.data` (per language) executes this lookup at resolve time, against Google Cloud's own real API, and returns whatever it finds. It is never created, modified, or destroyed by ubx -- see [docs/schema.md's own "Amendment: data sources"] for the real wire shape this compiles to (`data_sources[]`, never `resources[]`).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apigee_flowhook"})

    		ubx.Data(apigee.Flowhook, "example", apigee.FlowhookConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">

    ```python
    import ubx_sdk as ubx

        ubx.run("example", describe)
    ```

## Result properties

<ResponseField name="continue_on_error" type="bool">
  Optional. Flag that specifies whether execution should continue if the flow hook throws an exception. Set to `true` to continue execution. Set to `false` to stop execution if the flow hook throws an exception. Defaults to `true`. Returned by the lookup.
</ResponseField>

<ResponseField name="description" type="string">
  Description of the flow hook. Returned by the lookup.
</ResponseField>

<ResponseField name="flow_hook_point" type="string">
  Output only. Where in the API call flow the flow hook is invoked. Must be one of `PreProxyFlowHook`, `PostProxyFlowHook`, `PreTargetFlowHook`, or `PostTargetFlowHook`. Returned by the lookup.
</ResponseField>

<ResponseField name="shared_flow" type="string">
  Shared flow attached to this flow hook, or empty if there is none attached. Returned by the lookup.
</ResponseField>

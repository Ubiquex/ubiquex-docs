## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apigee_deployment"})

    		ubx.Data(apigee.Deployment, "example", apigee.DeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="api_proxy" type="string">
  API proxy. Returned by the lookup.
</ResponseField>

<ResponseField name="deploy_start_time" type="string">
  Time the API proxy was marked `deployed` in the control plane in millisconds since epoch. Returned by the lookup.
</ResponseField>

<ResponseField name="environment" type="string">
  Environment. Returned by the lookup.
</ResponseField>

<ResponseField name="errors" type="list(object)">
  Errors reported for this deployment. Populated only when state == ERROR. **Note**: This field is displayed only when viewing deployment status. Returned by the lookup.
</ResponseField>

<ResponseField name="instances" type="list(object)">
  Status reported by each runtime instance. **Note**: This field is displayed only when viewing deployment status. Returned by the lookup.
</ResponseField>

<ResponseField name="pods" type="list(object)">
  Status reported by runtime pods. **Note**: **This field is deprecated**. Runtime versions 1.3 and above report instance level status rather than pod status. Returned by the lookup.
</ResponseField>

<ResponseField name="proxy_deployment_type" type="string">
  Output only. The type of the deployment (standard or extensible) Deployed proxy revision will be marked as extensible in following 2 cases. 1. The deployed proxy revision uses extensible policies. 2. If a environment supports flowhooks and flow hook is configured. Returned by the lookup.
</ResponseField>

<ResponseField name="revision" type="string">
  API proxy revision. Returned by the lookup.
</ResponseField>

<ResponseField name="route_conflicts" type="list(object)">
  Conflicts in the desired state routing configuration. The presence of conflicts does not cause the state to be `ERROR`, but it will mean that some of the deployment's base paths are not routed to its environment. If the conflicts change, the state will transition to `PROGRESSING` until the latest configuration is rolled out to all instances. **Note**: This field is displayed only when viewing deployment status. Returned by the lookup.
</ResponseField>

<ResponseField name="service_account" type="string">
  The full resource name of Cloud IAM Service Account that this deployment is using, eg, `projects/-/serviceAccounts/&#123;email&#125;`. Returned by the lookup.
</ResponseField>

<ResponseField name="state" type="string">
  Current state of the deployment. **Note**: This field is displayed only when viewing deployment status. Returned by the lookup.
</ResponseField>

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apigee "github.com/ubiquex/ubx-sdk-google/sdk/go/google/data/apigee"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "look up google_apigee_security_incident"})

    		ubx.Data(apigee.SecurityIncident, "example", apigee.SecurityIncidentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  <Tab title="Python">
    ```python
    # ubx sdk gen --only google --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google.data.apigee import SecurityIncident, SecurityIncidentConfig

    def describe():
        ubx.intent("look up google_apigee_security_incident")

        ubx.data(SecurityIncident, "example", SecurityIncidentConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Lookup arguments

<ResponseField name="name" type="string" required>
  The real, fully-qualified resource name this lookup is scoped to. **(AI-inferred)** Required lookup argument.
</ResponseField>

## Result properties

<ResponseField name="detection_types" type="list(string)">
  Output only. Detection types which are part of the incident. Examples: Flooder, OAuth Abuser, Static Content Scraper, Anomaly Detection. Returned by the lookup.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. Display name of the security incident. Returned by the lookup.
</ResponseField>

<ResponseField name="first_detected_time" type="string">
  Output only. The time when events associated with the incident were first detected. Returned by the lookup.
</ResponseField>

<ResponseField name="last_detected_time" type="string">
  Output only. The time when events associated with the incident were last detected. Returned by the lookup.
</ResponseField>

<ResponseField name="last_observability_change_time" type="string">
  Output only. The time when the incident observability was last changed. Returned by the lookup.
</ResponseField>

<ResponseField name="observability" type="string">
  Optional. Indicates if the user archived this incident. Returned by the lookup.
</ResponseField>

<ResponseField name="risk_level" type="string">
  Output only. Risk level of the incident. Returned by the lookup.
</ResponseField>

<ResponseField name="traffic_count" type="string">
  Total traffic detected as part of the incident. Returned by the lookup.
</ResponseField>

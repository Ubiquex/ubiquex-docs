`google_eventarc_channel_connection` links an Eventarc channel to a specific third-party event provider's own registered connection, authorizing that provider to publish events into the channel.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_eventarc --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_eventarc/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	eventarc "github.com/ubiquex/ubx-sdk-google/sdk/go/google_eventarc/eventarc"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own channel connection"})

    		ubx.Resource(eventarc.EventarcChannelConnection, "ci-runner", eventarc.EventarcChannelConnectionConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_eventarc --lang ts --out ./local-sdk
    ```

  <Tab title="Python">

    ```python
    # ubx sdk gen --only google_eventarc --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_eventarc/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_eventarc.eventarc import EventarcChannelConnection, EventarcChannelConnectionConfig

    def describe():
        ubx.intent("payments own channel connection")

        ubx.resource(EventarcChannelConnection, "ci-runner", EventarcChannelConnectionConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="activation_token" type="string">
  Input only. Activation token for the channel. The token will be used during the creation of ChannelConnection to bind the channel with the provider project. This field will not be stored in the provider resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="channel" type="string">
  Required. The name of the connected subscriber Channel. This is a weak reference to avoid cross project and cross accounts references. This must be in `projects/&#123;project&#125;/location/&#123;location&#125;/channels/&#123;channel_id&#125;` format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The creation time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Resource labels. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Required. The name of the connection. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Server assigned ID of the resource. The server guarantees uniqueness and immutability until deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The last-modified time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

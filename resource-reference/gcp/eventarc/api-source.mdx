`google_eventarc_google_api_source` configures Eventarc to receive Google Cloud audit log-derived events for a defined set of Google API method(s), publishing them onto a message bus.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	eventarc "github.com/ubiquex/ubx-sdk-google/sdk/go/google/eventarc"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own api source"})

    		ubx.Resource(eventarc.GoogleApiSource, "example", eventarc.GoogleApiSourceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

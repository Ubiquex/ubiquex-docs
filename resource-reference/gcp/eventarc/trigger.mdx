`google_eventarc_trigger` routes matching event(s) (from a Google Cloud service, a custom channel, or a third-party source) directly to a single destination such as Cloud Run, the original point-to-point Eventarc routing model.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	eventarc "github.com/ubiquex/ubx-sdk-google/sdk/go/google/eventarc"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own trigger"})

    		ubx.Resource(eventarc.Trigger, "example", eventarc.TriggerConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<ResponseField name="destination" type="object">
  Represents a target of an invocation over HTTP. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="cloud_function" type="string">
      The Cloud Function resource name. Cloud Functions V1 and V2 are supported. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/functions/&#123;function&#125;` This is a read-only field. Creating Cloud Functions V1/V2 triggers is only supported via the Cloud Functions product. An error will be returned if the user sets this value. Optional.
    </ResponseField>
    <ResponseField name="cloud_run" type="object">
      Represents a Cloud Run destination. Optional.
      <Expandable title="properties">
        <ResponseField name="path" type="string">
          Optional. The relative path on the Cloud Run service the events should be sent to. The value must conform to the definition of a URI path segment (section 3.3 of RFC2396). Examples: "/route", "route", "route/subroute". Optional.
        </ResponseField>
        <ResponseField name="region" type="string">
          Required. The region the Cloud Run service is deployed in. Optional.
        </ResponseField>
        <ResponseField name="service" type="string">
          Required. The name of the Cloud Run service being addressed. See https://cloud.google.com/run/docs/reference/rest/v1/namespaces.services. Only services located in the same project as the trigger object can be addressed. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="gke" type="object">
      Represents a GKE destination. Optional.
      <Expandable title="properties">
        <ResponseField name="cluster" type="string">
          Required. The name of the cluster the GKE service is running in. The cluster must be running in the same project as the trigger being created. Optional.
        </ResponseField>
        <ResponseField name="location" type="string">
          Required. The name of the Google Compute Engine in which the cluster resides, which can either be compute zone (for example, us-central1-a) for the zonal clusters or region (for example, us-central1) for regional clusters. Optional.
        </ResponseField>
        <ResponseField name="namespace" type="string">
          Required. The namespace the GKE service is running in. Optional.
        </ResponseField>
        <ResponseField name="path" type="string">
          Optional. The relative path on the GKE service the events should be sent to. The value must conform to the definition of a URI path segment (section 3.3 of RFC2396). Examples: "/route", "route", "route/subroute". Optional.
        </ResponseField>
        <ResponseField name="service" type="string">
          Required. Name of the GKE service. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="http_endpoint" type="object">
      Represents a HTTP endpoint destination. Optional.
      <Expandable title="properties">
        <ResponseField name="uri" type="string">
          Required. The URI of the HTTP endpoint. The value must be a RFC2396 URI string. Examples: `http://10.10.10.8:80/route`, `http://svc.us-central1.p.local:8080/`. Only HTTP and HTTPS protocols are supported. The host can be either a static IP addressable from the VPC specified by the network config, or an internal DNS hostname of the service resolvable via Cloud DNS. Optional.

      </Expandable>
    </ResponseField>
    <ResponseField name="network_config" type="object">
      Network Configuration that can be inherited by other protos. Optional.
      <Expandable title="properties">
        <ResponseField name="network_attachment" type="string">

        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="workflow" type="string">
      The resource name of the Workflow whose Executions are triggered by the events. The Workflow resource should be deployed in the same project as the trigger. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/workflows/&#123;workflow&#125;` Optional.
    </ResponseField>
  </Expandable>

  Optional. The IAM service account email associated with the trigger. The service account represents the identity of the trigger. The `iam.serviceAccounts.actAs` permission must be granted on the service account to allow a principal to impersonate the service account. For more information, see the [Roles and permissions](/eventarc/docs/all-roles-permissions) page specific to the trigger destination. Optional; if omitted, computed by Google Cloud.

        <ResponseField name="subscription" type="string">
          Output only. The name of the Pub/Sub subscription created and managed by Eventarc as a transport for the event delivery. Format: `projects/&#123;PROJECT_ID&#125;/subscriptions/&#123;SUBSCRIPTION_NAME&#125;`. Computed by Google Cloud after `ship`.

          Optional. The name of the Pub/Sub topic created and managed by Eventarc as a transport for the event delivery. Format: `projects/&#123;PROJECT_ID&#125;/topics/&#123;TOPIC_NAME&#125;`. You can set an existing topic for triggers of the type `google.cloud.pubsub.topic.v1.messagePublished`. The topic you provide here is not deleted by Eventarc at trigger deletion. Optional.

  </Expandable>

`google_eventarc_message_buse` (a Message Bus) is Eventarc's central event routing hub that publishers send event(s) into and enrollment(s) subscribe destination(s) to receive matching event(s) from, the newer alternative to point-to-point triggers.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	eventarc "github.com/ubiquex/ubx-sdk-google/sdk/go/google/eventarc"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own message buse"})

    		ubx.Resource(eventarc.MessageBuse, "example", eventarc.MessageBuseConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

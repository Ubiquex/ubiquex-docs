## Properties

<ResponseField name="asset_type" type="string">
  The asset type of this authorized orgs desc. Valid values are `ASSET_TYPE_DEVICE`, and `ASSET_TYPE_CREDENTIAL_STRENGTH`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="authorization_direction" type="string">
  The direction of the authorization relationship between this organization and the organizations listed in the `orgs` field. The valid values for this field include the following: `AUTHORIZATION_DIRECTION_FROM`: Allows this organization to evaluate traffic in the organizations listed in the `orgs` field. `AUTHORIZATION_DIRECTION_TO`: Allows the organizations listed in the `orgs` field to evaluate the traffic in this organization. For the authorization relationship to take effect, all of the organizations must authorize and specify the appropriate relationship direction. For example, if organization A authorized organization B and C to evaluate its traffic, by specifying `AUTHORIZATION_DIRECTION_TO` as the authorization direction, organizations B and C must specify `AUTHORIZATION_DIRECTION_FROM` as the authorization direction in their `AuthorizedOrgsDesc` resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="authorization_type" type="string">
  A granular control type for authorization levels. Valid value is `AUTHORIZATION_TYPE_TRUST`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Resource name for the `AuthorizedOrgsDesc`. Format: `accessPolicies/&#123;access_policy&#125;/authorizedOrgsDescs/&#123;authorized_orgs_desc&#125;`. The `authorized_orgs_desc` component must begin with a letter, followed by alphanumeric characters or `_`. After you create an `AuthorizedOrgsDesc`, you cannot change its `name`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="orgs" type="list(string)">
  The list of organization ids in this AuthorizedOrgsDesc. Format: `organizations/` Example: `organizations/123456` Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_binaryauthorization_attestor` defines a trusted signer whose own attestation(s) Binary Authorization checks for before allowing a container image to deploy.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_binaryauthorization --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_binaryauthorization/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	binaryauthorization "github.com/ubiquex/ubx-sdk-google/sdk/go/google_binaryauthorization/binaryauthorization"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own attestor"})

    		ubx.Resource(binaryauthorization.BinaryauthorizationAttestor, "example", binaryauthorization.BinaryauthorizationAttestorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

  <Expandable title="properties">
    <ResponseField name="delegation_service_account_email" type="string">
      Output only. This field will contain the service account email address that this attestor will use as the principal when querying Container Analysis. Attestor administrators must grant this service account the IAM role needed to read attestations from the note_reference in Container Analysis (`containeranalysis.notes.occurrences.viewer`). This email address is fixed for the lifetime of the attestor, but callers should not make any other assumptions about the service account email; future versions may use an email based on a different naming pattern. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="note_reference" type="string">
      Required. The Grafeas resource name of a Attestation.Authority Note, created by the user, in the format: `projects/[PROJECT_ID]/notes/*`. This field may not be updated. A project ID must be used, not a project number. An attestation by this attestor is stored as a Grafeas Attestation.Authority Occurrence that names a container image and that links to this Note. Grafeas is an external dependency. Optional.
    </ResponseField>
    <ResponseField name="public_keys" type="list(object)">
      Optional. Public keys that verify attestations signed by this attestor. This field may be updated. If this field is non-empty, one of the specified public keys must verify that an attestation was signed by this attestor for the image specified in the admission request. If this field is empty, this attestor always returns that no valid attestations exist. Optional.

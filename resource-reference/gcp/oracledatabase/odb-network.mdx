`google_oracledatabase_odb_network` provisions the dedicated network Oracle Database@Google Cloud infrastructure (Exadata, Exascale VM clusters) is deployed into, peered with a Google Cloud VPC network for connectivity.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The date and time that the OdbNetwork was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="entitlement_id" type="string">
  Output only. The ID of the subscription entitlement associated with the OdbNetwork. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="gcp_oracle_zone" type="string">
  Optional. The GCP Oracle zone where OdbNetwork is hosted. Example: us-east4-b-r2. If not specified, the system will pick a zone based on availability. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels or tags associated with the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the OdbNetwork resource in the following format: projects/&#123;project&#125;/locations/&#123;region&#125;/odbNetworks/&#123;odb_network&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="network" type="string">
  Required. The name of the VPC network in the following format: projects/&#123;project&#125;/global/networks/&#123;network&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the ODB Network. Optional; if omitted, computed by Google Cloud.
</ResponseField>

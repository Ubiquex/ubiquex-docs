`google_oracledatabase_cloud_exadata_infrastructure` provisions the dedicated Exadata hardware infrastructure that Oracle Database@Google Cloud VM cluster(s) are created on.

## Example

    package main

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cloud exadata infrastructure"})

    		ubx.Resource(oracledatabase.CloudExadataInfrastructure, "example", oracledatabase.CloudExadataInfrastructureConfig{

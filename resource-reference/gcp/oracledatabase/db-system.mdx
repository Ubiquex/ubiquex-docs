`google_oracledatabase_db_system` provisions an Oracle Base Database Service system through Oracle Database@Google Cloud, a lighter-weight (non-Exadata) managed Oracle database deployment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	oracledatabase "github.com/ubiquex/ubx-sdk-google/sdk/go/google/oracledatabase"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own db system"})

    		ubx.Resource(oracledatabase.DbSystem, "example", oracledatabase.DbSystemConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

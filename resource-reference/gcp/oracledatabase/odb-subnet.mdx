`google_oracledatabase_odb_subnet` defines a subnet within an Oracle Database@Google Cloud ODB network, the IP address range Exadata or Exascale VM cluster resources are allocated from.

    package main

    }

## Properties

<ResponseField name="cidr_range" type="string">
  Required. The CIDR range of the subnet. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. The date and time that the OdbNetwork was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels or tags associated with the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the OdbSubnet resource in the following format: projects/&#123;project&#125;/locations/&#123;location&#125;/odbNetworks/&#123;odb_network&#125;/odbSubnets/&#123;odb_subnet&#125; Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="purpose" type="string">
  Required. Purpose of the subnet. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the ODB Subnet. Optional; if omitted, computed by Google Cloud.
</ResponseField>

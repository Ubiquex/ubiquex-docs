`google_oracledatabase_goldengate_connection` defines a connection GoldenGate uses to reach a source or target database for real-time data replication, as part of Oracle Database@Google Cloud.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own goldengate connection"})

    }

`google_datastore_index` is a composite index for Cloud Datastore, created to support queries Datastore's own automatic single-property indexing can't serve; a newly created index starts in a real `CREATING` state and becomes `READY` once built.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	datastore "github.com/ubiquex/ubx-sdk-google/sdk/go/google/datastore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own index"})

    		ubx.Resource(datastore.Index, "example", datastore.IndexConfig{
    			Ancestor: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

  </Tab>

    ```python
        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="ancestor" type="string">
  Required. The index's ancestor mode. Must not be ANCESTOR_MODE_UNSPECIFIED. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="index_id" type="string">
  Output only. The resource ID of the index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  Required. The entity kind to which this index applies. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="project_id" type="string">
  Output only. Project ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="properties" type="list(object)">
  Required. An ordered sequence of property names and their index attributes. Requires: * A maximum of 100 properties. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="direction" type="string">
      Whether this composite index property is real, sorted `ASCENDING` or `DESCENDING`. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="name" type="string">
      The real, indexed entity property name this composite index property covers. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the index. Optional; if omitted, computed by Google Cloud.
</ResponseField>

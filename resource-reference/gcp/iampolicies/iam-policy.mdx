`google_iampolicies_iam_policy` is a real, generic IAM v2 Policy resource, used to define Deny Policies and Principal Access Boundary Policies at organization, folder, or project scope -- Google Cloud's own newer, `kind`-discriminated policy model, distinct from the classic IAM allow-policy bindings on individual resources.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

<ResponseField name="display_name" type="string">
  A user-specified description of the `Policy`. This value can be up to 63 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  An opaque tag that identifies the current version of the `Policy`. IAM uses this value to help manage concurrent updates, so they do not cause one update to be overwritten by another. If this field is present in a CreatePolicyRequest, the value is ignored. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  Output only. The kind of the `Policy`. Always contains the value `DenyPolicy`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The resource name of the `Policy`, which must be unique. Format: `policies/&#123;attachment_point&#125;/denypolicies/&#123;policy_id&#125;` The attachment point is identified by its URL-encoded full resource name, which means that the forward-slash character, `/`, must be written as `%2F`. For example, `policies/cloudresourcemanager.googleapis.com%2Fprojects%2Fmy-project/denypolicies/my-deny-policy`. For organizations and folders, use the numeric ID in the full resource name. For projects, requests can use the alphanumeric or the numeric ID. Responses always contain the numeric ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

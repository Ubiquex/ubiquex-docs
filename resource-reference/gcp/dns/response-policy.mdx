`google_dns_response_policy` overrides standard DNS resolution for VPC network(s) it's attached to, letting queries for specific names return caller-defined responses instead of the real internet answer.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	dns "github.com/ubiquex/ubx-sdk-google/sdk/go/google/dns"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own response policy"})

    		ubx.Resource(dns.ResponsePolicy, "example", dns.ResponsePolicyConfig{
    			Description: "Managed by ubx.",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

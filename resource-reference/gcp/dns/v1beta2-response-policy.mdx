<Warning>
  This is Google Cloud's own **v1beta2** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_dns_response_policy`.
</Warning>

`google_dns_v1beta2_response_policy` overrides standard DNS resolution for VPC network(s) it's attached to, letting queries for specific names return caller-defined responses instead of the real internet answer.

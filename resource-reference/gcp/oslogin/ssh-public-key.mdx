`google_oslogin_ssh_public_key` registers an SSH public key against a user's own OS Login profile, authorizing that key for SSH access across every VM instance with OS Login enabled the user has IAM access to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_oslogin --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_oslogin/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	oslogin "github.com/ubiquex/ubx-sdk-google/sdk/go/google_oslogin/oslogin"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own ssh public key"})

    		ubx.Resource(oslogin.OsloginSshPublicKey, "example", oslogin.OsloginSshPublicKeyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="expiration_time_usec" type="string">
  An expiration time in microseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fingerprint" type="string">
  Output only. The SHA-256 fingerprint of the SSH public key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="key" type="string">
  Required. Public key text in SSH format, defined by [RFC4253](https://www.ietf.org/rfc/rfc4253.txt) section 6.6. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The canonical resource name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_oslogin_ssh_public_key`.
</Warning>

`google_oslogin_v1alpha_ssh_public_key` registers an SSH public key against a user's own OS Login profile, authorizing that key for SSH access across every VM instance with OS Login enabled the user has IAM access to.

## Properties

<ResponseField name="expiration_time_usec" type="string">
  An expiration time in microseconds since epoch. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="fingerprint" type="string">
  Output only. The SHA-256 fingerprint of the SSH public key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="key" type="string">
  Required. Public key text in SSH format, defined by [RFC4253](https://www.ietf.org/rfc/rfc4253.txt) section 6.6. Optional; if omitted, computed by Google Cloud.
</ResponseField>

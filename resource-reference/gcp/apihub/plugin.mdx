`google_apihub_plugin` configures an integration that automatically discovers, curates, or enriches API metadata within API hub from an external or internal source.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own plugin"})

    		ubx.Resource(apihub.Plugin, "example", apihub.PluginConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

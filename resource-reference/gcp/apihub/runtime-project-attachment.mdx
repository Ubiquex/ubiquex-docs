`google_apihub_runtime_project_attachment` attaches a Google Cloud project as a source of runtime API traffic or deployment data that API hub ingests and links to its own catalog.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apihub --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apihub/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apihub/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own runtime project attachment"})

    		ubx.Resource(apihub.ApihubRuntimeProjectAttachment, "example", apihub.ApihubRuntimeProjectAttachmentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Create time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of a runtime project attachment. Format: "projects/&#123;project&#125;/locations/&#123;location&#125;/runtimeProjectAttachments/&#123;runtime_project_attachment&#125;". Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="runtime_project" type="string">
  Required. Immutable. Google cloud project name in the format: "projects/abc" or "projects/123". As input, project name with either project id or number are accepted. As output, this field will contain project number. Optional; if omitted, computed by Google Cloud.
</ResponseField>

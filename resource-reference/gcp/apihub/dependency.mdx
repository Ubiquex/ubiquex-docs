title: "google_apihub_dependency"
description: "`google_apihub_dependency` records a relationship between two entities cataloged in API hub, e.g. one API depending on another it calls internally."
---

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own dependency"})

    		ubx.Resource(apihub.Dependency, "example", apihub.DependencyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

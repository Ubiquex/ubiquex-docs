`google_apihub_operation` is a single documented operation (e.g. one REST endpoint or RPC method) belonging to an API version cataloged in API hub, parsed from its own spec.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own operation"})

    		ubx.Resource(apihub.Operation, "example", apihub.OperationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

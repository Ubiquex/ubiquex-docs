`google_apihub_curation` configures a plugin-driven job that automatically enriches or classifies discovered API metadata within API hub, e.g. auto-detecting an API's own maturity level.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own curation"})

    		ubx.Resource(apihub.Curation, "example", apihub.CurationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the curation was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the curation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. The display name of the curation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="endpoint" type="object">
  The endpoint to be triggered for curation. The endpoint will be invoked with a request payload containing ApiMetadata. Response should contain curated data in the form of ApiMetadata. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="application_integration_endpoint_details" type="object">
      The details of the Application Integration endpoint to be triggered for curation. Optional.
      <Expandable title="properties">
        <ResponseField name="trigger_id" type="string">
          Required. The API trigger ID of the Application Integration workflow. Optional.
        </ResponseField>
        <ResponseField name="uri" type="string">
          Required. The endpoint URI should be a valid REST URI for triggering an Application Integration. Format: `https://integrations.googleapis.com/v1/&#123;name=projects/*/locations/*/integrations/*&#125;:execute` or `https://&#123;location&#125;-integrations.googleapis.com/v1/&#123;name=projects/*/locations/*/integrations/*&#125;:execute` Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="last_execution_error_code" type="string">
  Output only. The error code of the last execution of the curation. The error code is populated only when the last execution state is failed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_execution_error_message" type="string">
  Output only. Error message describing the failure, if any, during the last execution of the curation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="last_execution_state" type="string">
  Output only. The last execution state of the curation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the curation. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/curations/&#123;curation&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="plugin_instance_actions" type="list(object)">
  Output only. The plugin instances and associated actions that are using the curation. Note: A particular curation could be used by multiple plugin instances or multiple actions in a plugin instance. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="action_id" type="string">
      An identifier for this action, unique within its own containing plugin. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="plugin_instance" type="string">
      A reference to the plugin instance this applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time at which the curation was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

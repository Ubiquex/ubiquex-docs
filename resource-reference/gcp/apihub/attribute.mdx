`google_apihub_attribute` defines a custom metadata field (e.g. a maturity level or a team owner) that can be attached to APIs, versions, or other API hub entities for organization-specific classification.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own attribute"})

    		ubx.Resource(apihub.Attribute, "example", apihub.AttributeConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

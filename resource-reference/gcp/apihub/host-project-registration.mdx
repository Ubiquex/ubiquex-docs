`google_apihub_host_project_registration` registers a Google Cloud project as a source API hub automatically discovers API deployments (e.g. Apigee proxies, API Gateway configs) from.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_apihub --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_apihub/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google_apihub/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own host project registration"})

    		ubx.Resource(apihub.ApihubHostProjectRegistration, "example", apihub.ApihubHostProjectRegistrationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time at which the host project registration was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="gcp_project" type="string">
  Required. Immutable. Google cloud project name in the format: "projects/abc" or "projects/123". As input, project name with either project id or number are accepted. As output, this field will contain project number. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The name of the host project registration. Format: "projects/&#123;project&#125;/locations/&#123;location&#125;/hostProjectRegistrations/&#123;host_project_registration&#125;". Optional; if omitted, computed by Google Cloud.
</ResponseField>

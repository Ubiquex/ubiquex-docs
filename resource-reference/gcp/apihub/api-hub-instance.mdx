`google_apihub_api_hub_instance` is the provisioned API hub instance itself, the regional deployment new API, deployment, and plugin registration happens within.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	apihub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/apihub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own api hub instance"})

    		ubx.Resource(apihub.ApiHubInstance, "example", apihub.ApiHubInstanceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="config" type="object">
  Available configurations to provision an ApiHub Instance. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="agent_registry_sync_config" type="object">
      The configuration for Agent Registry sync. Optional.
      <Expandable title="properties">
        <ResponseField name="disabled" type="bool">
          Optional. If true, the MCP data sync to the Agent Registry will be disabled. The default value is false. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="cmek_key_name" type="string">
      Optional. The Customer Managed Encryption Key (CMEK) used for data encryption. The CMEK name should follow the format of `projects/([^/]+)/locations/([^/]+)/keyRings/([^/]+)/cryptoKeys/([^/]+)`, where the location must match the instance location. If the CMEK is not provided, a GMEK will be created for the instance. Optional.
    </ResponseField>
    <ResponseField name="disable_search" type="bool">
      Optional. If true, the search will be disabled for the instance. The default value is false. Optional.
    </ResponseField>
    <ResponseField name="encryption_type" type="string">
      Optional. Encryption type for the region. If the encryption type is CMEK, the cmek_key_name must be provided. If no encryption type is provided, GMEK will be used. Optional.
    </ResponseField>
    <ResponseField name="vertex_location" type="string">
      Optional. The name of the Vertex AI location where the data store is stored. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Description of the ApiHub instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Instance labels to represent user-provided metadata. Refer to cloud documentation on labels for more details. https://cloud.google.com/compute/docs/labeling-resources Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/apiHubInstances/&#123;apiHubInstance&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the ApiHub instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_message" type="string">
  Output only. Extra information about ApiHub instance state. Currently the message would be populated when state is `FAILED`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last update timestamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_vmwareengine_private_connection` establishes private connectivity between a Google Cloud VMware Engine network and an external network (e.g. an on-premises network reached via Cloud Interconnect or VPN).

## Example

<Tabs>

    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_vmwareengine/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmwareengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google_vmwareengine/vmwareengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own private connection"})

    		ubx.Resource(vmwareengine.VmwareenginePrivateConnection, "example", vmwareengine.VmwareenginePrivateConnectionConfig{
    			Name: "example",
    		})
    	}))

## Properties

<ResponseField name="create_time" type="string">
  Output only. Creation time of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. User-provided description for this private connection. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of the private connection. Resource names are schemeless URIs that follow the conventions in https://cloud.google.com/apis/design/resource_names. For example: `projects/my-project/locations/us-central1/privateConnections/my-connection` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peering_id" type="string">
  Output only. VPC network peering id between given network VPC and VMwareEngineNetwork. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peering_state" type="string">
  Output only. Peering state between service network and VMware Engine network. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="routing_mode" type="string">
  Optional. Routing Mode. Default value is set to GLOBAL. For type = PRIVATE_SERVICE_ACCESS, this field can be set to GLOBAL or REGIONAL, for other types only GLOBAL is supported. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="service_network" type="string">
  Required. Service network to create private connection. Specify the name in the following form: `projects/&#123;project&#125;/global/networks/&#123;network_id&#125;` For type = PRIVATE_SERVICE_ACCESS, this field represents servicenetworking VPC, e.g. projects/project-tp/global/networks/servicenetworking. For type = NETAPP_CLOUD_VOLUME, this field represents NetApp service VPC, e.g. projects/project-tp/global/networks/netapp-tenant-vpc. For type = DELL_POWERSCALE, this field represent Dell service VPC, e.g. projects/project-tp/global/networks/dell-tenant-vpc. For type= THIRD_PARTY_SERVICE, this field could represent a consumer VPC or any other producer VPC to which the VMware Engine Network needs to be connected, e.g. projects/project/global/networks/vpc. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the private connection. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Required. Private connection type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System-generated unique identifier for the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last update time of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="vmware_engine_network" type="string">
  Required. The relative resource name of Legacy VMware Engine network. Specify the name in the following form: `projects/&#123;project&#125;/locations/&#123;location&#125;/vmwareEngineNetworks/&#123;vmware_engine_network_id&#125;` where `&#123;project&#125;`, `&#123;location&#125;` will be same as specified in private connection resource name and `&#123;vmware_engine_network_id&#125;` will be in the form of `&#123;location&#125;`-default e.g. projects/project/locations/us-central1/vmwareEngineNetworks/us-central1-default. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="vmware_engine_network_canonical" type="string">
  Output only. The canonical name of the VMware Engine network in the form: `projects/&#123;project_number&#125;/locations/&#123;location&#125;/vmwareEngineNetworks/&#123;vmware_engine_network_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

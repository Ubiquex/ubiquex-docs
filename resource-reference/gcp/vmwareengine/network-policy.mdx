<ResponseField name="edge_services_cidr" type="string">
  Required. IP address range in CIDR notation used to create internet access and external IP access. An RFC 1918 CIDR block, with a "/26" prefix, is required. The range cannot overlap with any prefixes either in the consumer VPC network or in use by the private clouds attached to that VPC network. Optional; if omitted, computed by Google Cloud.
</ResponseField>

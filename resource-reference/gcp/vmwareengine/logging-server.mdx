`google_vmwareengine_logging_server` configures an external syslog server that a Google Cloud VMware Engine private cloud's own ESXi hosts forward log data to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmwareengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vmwareengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own logging server"})

    		ubx.Resource(vmwareengine.LoggingServer, "example", vmwareengine.LoggingServerConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. Creation time of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="hostname" type="string">
  Required. Fully-qualified domain name (FQDN) or IP Address of the logging server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of this logging server. Resource names are schemeless URIs that follow the conventions in https://cloud.google.com/apis/design/resource_names. For example: `projects/my-project/locations/us-central1-a/privateClouds/my-cloud/loggingServers/my-logging-server` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="port" type="number">
  Required. Port number at which the logging server receives logs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="protocol" type="string">
  Required. Protocol used by vCenter to send logs to a logging server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source_type" type="string">
  Required. The type of component that produces logs that will be forwarded to this logging server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System-generated unique identifier for the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last update time of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

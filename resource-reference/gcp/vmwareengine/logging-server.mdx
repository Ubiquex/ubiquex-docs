`google_vmwareengine_logging_server` configures an external syslog server that a Google Cloud VMware Engine private cloud's own ESXi hosts forward log data to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_vmwareengine --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_vmwareengine/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmwareengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google_vmwareengine/vmwareengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own logging server"})

    		ubx.Resource(vmwareengine.VmwareengineLoggingServer, "ci-runner", vmwareengine.VmwareengineLoggingServerConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<ResponseField name="name" type="string">
  Output only. The resource name of this logging server. Resource names are schemeless URIs that follow the conventions in https://cloud.google.com/apis/design/resource_names. </ResponseField>

<ResponseField name="port" type="number">
  Required. Port number at which the logging server receives logs. Optional; if omitted, computed by Google Cloud.

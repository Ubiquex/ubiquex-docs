`google_vmwareengine_network_peering` peers a Google Cloud VMware Engine network with another VPC network, extending connectivity between the private cloud and Google Cloud-native resources or another VMware Engine network.

## Example

## Properties

<ResponseField name="create_time" type="string">
  Output only. Creation time of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. User-provided description for this network peering. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="exchange_subnet_routes" type="bool">
  Optional. True if full mesh connectivity is created and managed automatically between peered networks; false otherwise. Currently this field is always true because Google Compute Engine automatically creates and manages subnetwork routes between two VPC networks when peering state is 'ACTIVE'. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="export_custom_routes" type="bool">
  Optional. True if custom routes are exported to the peered network; false otherwise. The default value is true. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="export_custom_routes_with_public_ip" type="bool">
  Optional. True if all subnet routes with a public IP address range are exported; false otherwise. The default value is true. IPv4 special-use ranges (https://en.wikipedia.org/wiki/IPv4#Special_addresses) are always exported to peers and are not controlled by this field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="import_custom_routes" type="bool">
  Optional. True if custom routes are imported from the peered network; false otherwise. The default value is true. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="import_custom_routes_with_public_ip" type="bool">
  Optional. True if all subnet routes with public IP address range are imported; false otherwise. The default value is true. IPv4 special-use ranges (https://en.wikipedia.org/wiki/IPv4#Special_addresses) are always imported to peers and are not controlled by this field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. The resource name of the network peering. NetworkPeering is a global resource and location can only be global. Resource names are scheme-less URIs that follow the conventions in https://cloud.google.com/apis/design/resource_names. For example: `projects/my-project/locations/global/networkPeerings/my-peering` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peer_mtu" type="number">
  Optional. Maximum transmission unit (MTU) in bytes. The default value is `1500`. If a value of `0` is provided for this field, VMware Engine uses the default value instead. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peer_network" type="string">
  Required. The relative resource name of the network to peer with a standard VMware Engine network. The provided network can be a consumer VPC network or another standard VMware Engine network. If the `peer_network_type` is VMWARE_ENGINE_NETWORK, specify the name in the form: `projects/&#123;project&#125;/locations/global/vmwareEngineNetworks/&#123;vmware_engine_network_id&#125;`. Otherwise specify the name in the form: `projects/&#123;project&#125;/global/networks/&#123;network_id&#125;`, where `&#123;project&#125;` can either be a project number or a project ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="peer_network_type" type="string">
  Required. The type of the network to peer with the VMware Engine network. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of the network peering. This field has a value of 'ACTIVE' when there's a matching configuration in the peer network. New values may be added to this enum when appropriate. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_details" type="string">
  Output only. Output Only. Details about the current state of the network peering. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. System-generated unique identifier for the resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Last update time of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="vmware_engine_network" type="string">
  Required. The relative resource name of the VMware Engine network. Specify the name in the following form: `projects/&#123;project&#125;/locations/&#123;location&#125;/vmwareEngineNetworks/&#123;vmware_engine_network_id&#125;` where `&#123;project&#125;` can either be a project number or a project ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_vmwareengine_hcx_activation_key` generates a key used to activate a VMware HCX site connecting an on-premises VMware environment to a Google Cloud VMware Engine private cloud, for live workload migration.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmwareengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vmwareengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own hcx activation key"})

    		ubx.Resource(vmwareengine.HcxActivationKey, "example", vmwareengine.HcxActivationKeyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="activation_key" type="string">
  Output only. HCX activation key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Creation time of HCX activation key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The resource name of this HcxActivationKey. Resource names are schemeless URIs that follow the conventions in https://cloud.google.com/apis/design/resource_names. For example: `projects/my-project/locations/us-central1/privateClouds/my-cloud/hcxActivationKeys/my-key` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. State of HCX activation key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">

</ResponseField>

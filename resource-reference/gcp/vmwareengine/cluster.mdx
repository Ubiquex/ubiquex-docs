`google_vmwareengine_cluster` is a cluster of node(s) within a Google Cloud VMware Engine private cloud, the unit VMware ESXi/vSAN compute and storage capacity is added to a private cloud in.

## Example

<Tabs>

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

`google_vmwareengine_external_address` assigns a public IP address to a specific VM running inside a Google Cloud VMware Engine private cloud, via NAT from the private cloud's own external address range.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	vmwareengine "github.com/ubiquex/ubx-sdk-google/sdk/go/google/vmwareengine"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own external address"})

    		ubx.Resource(vmwareengine.ExternalAddress, "example", vmwareengine.ExternalAddressConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

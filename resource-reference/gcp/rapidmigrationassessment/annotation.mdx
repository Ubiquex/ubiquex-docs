`google_rapidmigrationassessment_annotation` records real, user-supplied context (such as intent or priority) against assets discovered by a Rapid Migration Assessment `google_rapidmigrationassessment_collector`, informing Google's own first-party migration assessment and planning output.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	rapidmigrationassessment "github.com/ubiquex/ubx-sdk-google/sdk/go/google/rapidmigrationassessment"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own annotation"})

    		ubx.Resource(rapidmigrationassessment.Annotation, "example", rapidmigrationassessment.AnnotationConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

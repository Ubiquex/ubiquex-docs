`google_rapidmigrationassessment_collector` is a real Rapid Migration Assessment collector, the agent deployed into an existing environment to discover and inventory the real servers, workloads, and dependencies a migration-planning assessment needs.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	rapidmigrationassessment "github.com/ubiquex/ubx-sdk-google/sdk/go/google/rapidmigrationassessment"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own collector"})

    		ubx.Resource(rapidmigrationassessment.Collector, "example", rapidmigrationassessment.CollectorConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

  Output only. Store cloud storage bucket name (which is a guid) created with this Collector. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="client_version" type="string">
  Output only. Client version. Optional; if omitted, computed by Google Cloud.
</ResponseField>

</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Create time stamp. Optional; if omitted, computed by Google Cloud.
</ResponseField>

</ResponseField>

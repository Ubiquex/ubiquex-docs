`google_hypercomputecluster_cluster` provisions a Hypercompute Cluster, a pre-configured, tightly networked set of accelerator-optimized compute along with its own storage and networking, for large-scale AI training.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	hypercomputecluster "github.com/ubiquex/ubx-sdk-google/sdk/go/google/hypercomputecluster"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own cluster"})

    		ubx.Resource(hypercomputecluster.Cluster, "example", hypercomputecluster.ClusterConfig{
    ```

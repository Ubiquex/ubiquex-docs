## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	looker "github.com/ubiquex/ubx-sdk-google/sdk/go/google/looker"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own backup"})

    		ubx.Resource(looker.Backup, "example", looker.BackupConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the backup was started. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="encryption_config" type="object">
  Encryption configuration (i.e. CMEK). Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kms_key_name" type="string">
      Name of the CMEK key in KMS (input parameter). Optional.
    </ResponseField>
    <ResponseField name="kms_key_name_version" type="string">
      Output only. Full name and version of the CMEK key currently in use to encrypt Looker data. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/keyRings/&#123;ring&#125;/cryptoKeys/&#123;key&#125;/cryptoKeyVersions/&#123;version&#125;`. Empty if CMEK is not configured in this instance. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="kms_key_state" type="string">
      Output only. Status of the CMEK key. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. The time when the backup will be deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The relative resource name of the backup, in the following form: `projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/instances/&#123;instance_id&#125;/backups/&#123;backup&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the backup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

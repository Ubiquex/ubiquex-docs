<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_ces_agent`.
</Warning>

`google_ces_v1beta_agent` is a conversational agent built with Customer Engagement Suite's own CX Agent Studio, the underlying generative agent an app is configured to run.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_ces_v1beta --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_ces_v1beta/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	ces "github.com/ubiquex/ubx-sdk-google/sdk/go/google_ces_v1beta/ces"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta agent"})

    		ubx.Resource(ces.V1betaCesV1betaAgent, "example", ces.V1betaCesV1betaAgentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

`google_ces_v1beta_evaluation_expectation` defines a real expected outcome an evaluation checks a response against -- its own llm_criteria (an LLM-judged rubric) and tags -- so evaluation success can be defined by a real, inspectable rule rather than a hardcoded exact-match string.

## Example

    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta evaluation expectation"})

    		ubx.Resource(ces.V1betaEvaluationExpectation, "example", ces.V1betaEvaluationExpectationConfig{
    			Name: "example",
    		})
    	}))
    }

## Properties

<ResponseField name="create_time" type="string">
  Output only. Timestamp when the evaluation expectation was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Required. User-defined display name. Must be unique within the app. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  Output only. Etag used to ensure the object hasn't changed during a read-modify-write operation. If the etag is empty, the update will overwrite any concurrent changes. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="llm_criteria" type="object">
  Configuration for LLM-based evaluation criteria. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="prompt" type="string">
      Required. The prompt/instructions provided to the LLM judge. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The unique identifier of this evaluation expectation. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/apps/&#123;app&#125;/evaluationExpectations/&#123;evaluation_expectation&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tags" type="list(string)">
  Optional. User-defined tags for expectations. Can be used to filter expectations. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Timestamp when the evaluation expectation was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

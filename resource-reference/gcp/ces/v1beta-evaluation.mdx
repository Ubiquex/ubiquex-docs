`google_ces_v1beta_evaluation` is a real evaluation definition for a Customer Experience agent -- referencing its own evaluation_datasets, tracking evaluation_runs, and carrying aggregated_metrics plus an invalid/golden flag -- so agent quality can be measured against a defined, repeatable evaluation rather than judged only from live traffic.

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_ces_deployment`.
</Warning>

`google_ces_v1beta_deployment` publishes a specific, immutable version of a Customer Engagement Suite app to a live channel, making it available to handle real customer interactions.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	ces "github.com/ubiquex/ubx-sdk-google/sdk/go/google/ces"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta deployment"})

    		ubx.Resource(ces.V1betaDeployment, "example", ces.V1betaDeploymentConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="app_version" type="string">
  Optional. The resource name of the app version to deploy. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/apps/&#123;app&#125;/versions/&#123;version&#125;` Use `projects/&#123;project&#125;/locations/&#123;location&#125;/apps/&#123;app&#125;/versions/-` to use the draft app. Optional; if omitted, computed by Google Cloud.
</ResponseField>

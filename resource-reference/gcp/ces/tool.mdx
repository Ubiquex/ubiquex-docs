`google_ces_tool` registers an external function, API, or data source a Customer Engagement Suite agent can call during a conversation to fetch information or take an action.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_ces --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_ces/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	ces "github.com/ubiquex/ubx-sdk-google/sdk/go/google_ces/ces"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own tool"})

    		ubx.Resource(ces.CesTool, "ci-runner", ces.CesToolConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

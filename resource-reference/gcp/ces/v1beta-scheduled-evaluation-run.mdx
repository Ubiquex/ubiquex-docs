<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_ces_v1beta_scheduled_evaluation_run` is a real, recurring schedule (its own scheduling_config and next_scheduled_execution_time) that triggers an evaluation run automatically, tracking its own active state and last_completed_run, so evaluation happens on a real cadence instead of only when someone remembers to trigger it manually.

<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_ces_guardrail`.

`google_ces_v1beta_guardrail` defines a Responsible AI safety check (a content restriction on model input or output, at a configurable strictness level) enforced on a Customer Engagement Suite app.

<ResponseField name="llm_policy" type="object">
  Guardrail that blocks the conversation if the LLM response is considered violating the policy based on the LLM classification. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="allow_short_utterance" type="bool">
      Optional. By default, the LLM policy check is bypassed for short utterances. Enabling this setting applies the policy check to all utterances, including those that would normally be skipped. Optional.
    </ResponseField>
    <ResponseField name="fail_open" type="bool">
      Optional. If an error occurs during the policy check, fail open and do not trigger the guardrail. Optional.
    </ResponseField>
    <ResponseField name="max_conversation_messages" type="number">
      Optional. When checking this policy, consider the last 'n' messages in the conversation. When not set a default value of 10 will be used. Optional.
    </ResponseField>
    <ResponseField name="model_settings" type="object">
      Model settings contains various configurations for the LLM model. Optional.
      <Expandable title="properties">
        <ResponseField name="model" type="string">
          Optional. The LLM model that the agent should use. If not set, the agent will inherit the model from its parent agent. Optional.
        </ResponseField>
        <ResponseField name="temperature" type="number">
          Optional. If set, this temperature will be used for the LLM model. Temperature controls the randomness of the model's responses. Lower temperatures produce responses that are more predictable. Higher temperatures produce responses that are more creative. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="policy_scope" type="string">
      Required. Defines when to apply the policy check during the conversation. If set to `POLICY_SCOPE_UNSPECIFIED`, the policy will be applied to the user input. When applying the policy to the agent response, additional latency will be introduced before the agent can respond. Optional.
    </ResponseField>
    <ResponseField name="prompt" type="string">
      Required. Policy prompt. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

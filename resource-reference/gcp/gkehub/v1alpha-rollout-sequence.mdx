<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_gkehub_v1alpha_rollout_sequence` defines a real, fleet-wide rollout policy for cluster upgrades -- its own auto_upgrade_config, computed_release_channel, and ignored_clusters_selector -- so a control plane or node version rollout can be sequenced across a fleet's own clusters rather than triggered independently on each one.

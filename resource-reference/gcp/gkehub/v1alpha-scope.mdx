`google_gkehub_v1alpha_scope` is a real Fleet Scope -- a named grouping of namespaces and memberships within a fleet, tracked by its own state and uid -- used to apply configuration (bindings, RBAC, policy) to a real subset of a fleet's clusters rather than the whole fleet at once.

  The resource name for the scope `projects/&#123;project&#125;/locations/&#123;location&#125;/scopes/&#123;scope&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="namespace_labels" type="map(string)">
  Optional. Scope-level cluster namespace labels. For the member clusters bound to the Scope, these labels are applied to each namespace under the Scope. Scope-level labels take precedence over Namespace-level labels (`namespace_labels` in the Fleet Namespace resource) if they share a key. Keys and values must be Kubernetes-conformant. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="object">

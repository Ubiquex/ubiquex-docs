<Warning>
  This is Google Cloud's own **v2beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_gkehub_feature`.
</Warning>

`google_gkehub_v2beta_feature` enables a specific fleet-wide capability (e.g. Config Sync, Multi-cluster Ingress, or the Identity Service) across GKE clusters registered with a fleet via GKE Hub.

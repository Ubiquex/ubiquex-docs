`google_gkehub_v1beta_rbacrolebinding` grants a real RBAC role to a user or group (its own user, group, and role fields) within a fleet scope, so Kubernetes RBAC access can be defined once at the fleet level and applied consistently to every cluster in that scope.

## Example

    }

## Properties

<ResponseField name="create_time" type="string">
  Output only. When the rbacrolebinding was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. When the rbacrolebinding was deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="group" type="string">
  group is the group, as seen by the kubernetes cluster. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels for this RBACRolebinding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name for the rbacrolebinding `projects/&#123;project&#125;/locations/&#123;location&#125;/scopes/&#123;scope&#125;/rbacrolebindings/&#123;rbacrolebinding&#125;` or `projects/&#123;project&#125;/locations/&#123;location&#125;/memberships/&#123;membership&#125;/rbacrolebindings/&#123;rbacrolebinding&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="role" type="object">

  <Expandable title="properties">

    </ResponseField>

  </Expandable>

<ResponseField name="state" type="object">
  RBACRoleBindingLifecycleState describes the state of a RbacRoleBinding resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

      Output only. The current state of the rbacrolebinding resource. Computed by Google Cloud after `ship`.

<ResponseField name="uid" type="string">
  Output only. Google-generated UUID for this resource. This is unique across all rbacrolebinding resources. If a rbacrolebinding resource is deleted and another resource with the same name is created, it gets a different uid. Optional; if omitted, computed by Google Cloud.

<ResponseField name="update_time" type="string">

</ResponseField>

<ResponseField name="user" type="string">
  user is the name of the user as seen by the kubernetes cluster, example "alice" or "alice@domain.tld" Optional; if omitted, computed by Google Cloud.

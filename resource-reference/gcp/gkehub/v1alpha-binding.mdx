<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_gkehub_v1alpha_binding` binds a real fleet namespace or membership to a fleet scope, tracked by its own state and uid, so access and configuration that apply at the scope level actually reach the specific namespace or membership this binding names.

## Properties

<ResponseField name="create_time" type="string">
  Output only. When the membership binding was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. When the membership binding was deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels for this MembershipBinding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name for the membershipbinding itself `projects/&#123;project&#125;/locations/&#123;location&#125;/memberships/&#123;membership&#125;/bindings/&#123;membershipbinding&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scope" type="string">
  A Scope resource name in the format `projects/*/locations/*/scopes/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="object">
  MembershipBindingLifecycleState describes the state of a Binding resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="code" type="string">
      Output only. The current state of the MembershipBinding resource. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Google-generated UUID for this resource. This is unique across all membershipbinding resources. If a membershipbinding resource is deleted and another resource with the same name is created, it gets a different uid. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. When the membership binding was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

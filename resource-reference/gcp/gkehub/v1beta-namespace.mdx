`google_gkehub_v1beta_namespace` is a real fleet-scoped namespace -- its own namespace_labels and the scope it belongs to -- letting a namespace name and its labels be managed consistently across every cluster in a fleet scope rather than configured cluster by cluster.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	gkehub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/gkehub"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta namespace"})

    		ubx.Resource(gkehub.V1betaNamespace, "example", gkehub.V1betaNamespaceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

<ResponseField name="create_time" type="string">
  Output only. When the namespace was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="delete_time" type="string">
  Output only. When the namespace was deleted. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels for this Namespace. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  The resource name for the namespace `projects/&#123;project&#125;/locations/&#123;location&#125;/namespaces/&#123;namespace&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="namespace_labels" type="map(string)">
  Optional. Namespace-level cluster namespace labels. These labels are applied to the related namespace of the member clusters bound to the parent Scope. Scope-level labels (`namespace_labels` in the Fleet Scope resource) take precedence over Namespace-level labels if they share a key. Keys and values must be Kubernetes-conformant. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="scope" type="string">
  Required. Scope associated with the namespace Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="object">
  NamespaceLifecycleState describes the state of a Namespace resource. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="code" type="string">
      Output only. The current state of the Namespace resource. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. Google-generated UUID for this resource. This is unique across all namespace resources. If a namespace resource is deleted and another resource with the same name is created, it gets a different uid. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. When the namespace was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

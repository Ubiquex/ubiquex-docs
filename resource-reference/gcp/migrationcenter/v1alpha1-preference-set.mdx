<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_migrationcenter_preference_set`.
</Warning>

`google_migrationcenter_v1alpha1_preference_set` defines the sizing preferences (target region, machine series, commitment terms) Migration Center applies when generating a migration recommendation and cost estimate for a set of assets.

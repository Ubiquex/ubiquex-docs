<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_migrationcenter_source`.
</Warning>

`google_migrationcenter_v1alpha1_source` registers the origin (a discovery client, an import job, or a manually entered environment) that Migration Center asset data was collected from.

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the source was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Free-text description. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  User-friendly display name. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="error_frame_count" type="number">
  Output only. The number of frames that were reported by the source and contained errors. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="is_managed" type="bool">
  If `true`, the source is managed by other service(s). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The full name of the source. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="pending_frame_count" type="number">
  Output only. Number of frames that are still being processed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="priority" type="number">
  The information confidence of the source. The higher the value, the higher the confidence. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the source. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  Data source type. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The timestamp when the source was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

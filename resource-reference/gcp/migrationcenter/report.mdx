`google_migrationcenter_report` is a generated Migration Center sizing and cost report for a specific group of assets under a chosen preference set, recommending target Google Cloud resources.

## Example

  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own report"})

    		ubx.Resource(migrationcenter.Report, "example", migrationcenter.ReportConfig_{
    ```

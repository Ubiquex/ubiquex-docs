<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_migrationcenter_discovery_client`.
</Warning>

`google_migrationcenter_v1alpha1_discovery_client` registers a Migration Center discovery agent instance deployed in a source environment, that scans and reports on-premises or other-cloud asset(s) back to Migration Center.

## Properties

<ResponseField name="create_time" type="string">
  Output only. Time when the discovery client was first created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. Free text description. Maximum length is 1000 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. Free text display name. Maximum length is 63 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="errors" type="list(object)">
  Output only. Errors affecting client functionality. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="code" type="number">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="details" type="list(map(any))">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="message" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="expire_time" type="string">
  Optional. Client expiration time in UTC. If specified, the backend will not accept new frames after this time. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="heartbeat_time" type="string">
  Output only. Last heartbeat time. Healthy clients are expected to send heartbeats regularly (normally every few minutes). Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. Identifier. Full name of this discovery client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="recommended_versions" type="list(object)">
  Output only. The recommended versions of the discovery client. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="uri" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
    <ResponseField name="version" type="string">
      Optional; if omitted, computed by Google Cloud.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="service_account" type="string">
  Required. Service account used by the discovery client for various operation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="signals_endpoint" type="string">
  Output only. This field is intended for internal use. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="source" type="string">
  Required. Full name of the source object associated with this discovery client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Current state of the discovery client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="ttl" type="string">
  Optional. Input only. Client time-to-live. If specified, the backend will not accept new frames after this time. This field is input only. The derived expiration time is provided as output through the `expire_time` field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Time when the discovery client was last updated. This value is not updated by heartbeats, to view the last heartbeat time please refer to the `heartbeat_time` field. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version" type="string">
  Output only. Client version, as reported in recent heartbeat. Optional; if omitted, computed by Google Cloud.
</ResponseField>

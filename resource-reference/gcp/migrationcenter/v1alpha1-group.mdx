`google_migrationcenter_v1alpha1_group` is a named collection of discovered asset(s) within Migration Center, used to scope a sizing report or migration wave to a specific subset of infrastructure.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {

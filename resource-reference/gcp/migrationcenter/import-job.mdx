`google_migrationcenter_import_job` runs a bulk import of asset inventory data into Migration Center from uploaded file(s), rather than live discovery agent scanning.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	migrationcenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google/migrationcenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own import job"})

    		ubx.Resource(migrationcenter.ImportJob, "example", migrationcenter.ImportJobConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

<Warning>
  This is Google Cloud's own **v1alpha1** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_migrationcenter_import_job`.
</Warning>

`google_migrationcenter_v1alpha1_import_job` runs a bulk import of asset inventory data into Migration Center from uploaded file(s), rather than live discovery agent scanning.

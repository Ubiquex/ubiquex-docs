`google_migrationcenter_import_data_file` is a single uploaded file (e.g. an exported CSV inventory) processed as part of a Migration Center bulk asset import job.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_migrationcenter --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_migrationcenter/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	migrationcenter "github.com/ubiquex/ubx-sdk-google/sdk/go/google_migrationcenter/migrationcenter"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own import data file"})

    		ubx.Resource(migrationcenter.MigrationcenterImportDataFile, "example", migrationcenter.MigrationcenterImportDataFileConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="create_time" type="string">
  Output only. The timestamp when the file was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. User-friendly display name. Maximum length is 63 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="format" type="string">
  Required. The payload format. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Output only. The name of the file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the import data file. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="upload_file_info" type="object">
  A resource that contains a URI to which a data file can be uploaded. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="headers" type="map(string)">
      Output only. The headers that were used to sign the URI. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="signed_uri" type="string">
      Output only. Upload URI for the file. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="uri_expiration_time" type="string">
      Output only. Expiration time of the upload URI. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

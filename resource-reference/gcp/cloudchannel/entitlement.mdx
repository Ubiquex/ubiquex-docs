`google_cloudchannel_entitlement` gives a `google_cloudchannel_customer` the real means to use a specific Google Cloud or Workspace service, created through the Cloud Channel API as part of a successful order fulfillment.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudchannel "github.com/ubiquex/ubx-sdk-google/sdk/go/google/cloudchannel"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own entitlement"})

    		ubx.Resource(cloudchannel.Entitlement, "example", cloudchannel.EntitlementConfig{
    			Entitlement: map[string]any{"association_info": map[string]any{"base_entitlement": "example"}},
    			RequestId:   "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Entitlement } from "@ubx/sdk-google/google/cloudchannel/entitlement";

    export default stack("example", () => {
      intent({ summary: "example own entitlement" });

      resource(Entitlement, "example", {

    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.cloudchannel import Entitlement, EntitlementConfig
    from ubx.google.cloudchannel.entitlement import Entitlement_Entitlement, Entitlement_AssociationInfo

    def describe():
        ubx.intent("example own entitlement")

        ubx.resource(Entitlement, "example", EntitlementConfig(
            entitlement=Entitlement_Entitlement(association_info=Entitlement_AssociationInfo(base_entitlement="example")),
            request_id="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="entitlement" type="object">
  An entitlement is a representation of a customer's ability to use a service. Optional.
  <Expandable title="properties">
    <ResponseField name="association_info" type="object">
      Association links that an entitlement has to other entitlements. Optional.
      <Expandable title="properties">
        <ResponseField name="base_entitlement" type="string">
          The name of the base entitlement, for which this entitlement is an add-on. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="billing_account" type="string">
      Optional. The billing account resource name that is used to pay for this entitlement. Optional.
    </ResponseField>
    <ResponseField name="commitment_settings" type="object">
      Commitment settings for commitment-based offers. Optional.
      <Expandable title="properties">
        <ResponseField name="end_time" type="string">
          Output only. Commitment end timestamp. Computed by Google Cloud after `ship`.
        </ResponseField>
        <ResponseField name="renewal_settings" type="object">
          Renewal settings for renewable Offers. Optional.
          <Expandable title="properties">
            <ResponseField name="enable_renewal" type="bool">
              If false, the plan will be completed at the end date. Optional.
            </ResponseField>
            <ResponseField name="payment_cycle" type="object">
              Represents period in days/months/years. Optional.
              <Expandable title="properties">
                <ResponseField name="duration" type="number">
                  Total duration of Period Type defined. Optional.
                </ResponseField>
                <ResponseField name="period_type" type="string">
                  Period Type. Optional.
                </ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="payment_plan" type="string">
              Describes how a reseller will be billed. Optional.
            </ResponseField>
            <ResponseField name="resize_unit_count" type="bool">
              If true and enable_renewal = true, the unit (for example seats or licenses) will be set to the number of active units at renewal time. Optional.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="start_time" type="string">
          Output only. Commitment start timestamp. Computed by Google Cloud after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="create_time" type="string">
      Output only. The time at which the entitlement is created. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Output only. Resource name of an entitlement in the form: accounts/&#123;account_id&#125;/customers/&#123;customer_id&#125;/entitlements/&#123;entitlement_id&#125;. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="offer" type="string">
      Required. The offer resource name for which the entitlement is to be created. Takes the form: accounts/&#123;account_id&#125;/offers/&#123;offer_id&#125;. Optional.
    </ResponseField>
    <ResponseField name="parameters" type="list(object)">
      Extended entitlement parameters. When creating an entitlement, valid parameter names and values are defined in the Offer.parameter_definitions. For Google Workspace, the following Parameters may be accepted as input: - max_units: The maximum assignable units for a flexible offer OR - num_units: The total commitment for commitment-based offers The response may additionally include the following output-only Parameters: - assigned_units: The number of licenses assigned to users. For Google Cloud billing subaccounts, the following Parameter may be accepted as input: - display_name: The display name of the billing subaccount. Optional.
      <Expandable title="properties">
        <ResponseField name="editable" type="bool">
          Whether this entitlement parameter is real, editable by the reseller after the entitlement is created. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="name" type="string">
          The real, declared name of this entitlement parameter. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
        <ResponseField name="value" type="object">
          The real, decimal percentage value applied by this margin adjustment, or the real value of a typed entitlement parameter. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
          <Expandable title="properties">
            <ResponseField name="bool_value" type="bool">
              This entitlement parameter's own value, when its declared type is boolean. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="double_value" type="number">
              This entitlement parameter's own value, when its declared type is a floating-point number. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="int64_value" type="string">
              This entitlement parameter's own value, when its declared type is a 64-bit integer. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="proto_value" type="map(any)">
              This entitlement parameter's own value, when its declared type is a structured protobuf message. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
            <ResponseField name="string_value" type="string">
              This entitlement parameter's own value, when its declared type is a string. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="price_reference_id" type="string">
      Optional. Price reference ID for the offer. Only for offers that require additional price information. Used to guarantee that the pricing is consistent between quoting the offer and placing the order. Optional.
    </ResponseField>
    <ResponseField name="provisioned_service" type="object">
      Service provisioned for an entitlement. Optional.
      <Expandable title="properties">
        <ResponseField name="product_id" type="string">
          Output only. The product pertaining to the provisioning resource as specified in the Offer. Computed by Google Cloud after `ship`.
        </ResponseField>
        <ResponseField name="provisioning_id" type="string">
          Output only. Provisioning ID of the entitlement. For Google Workspace, this is the underlying Subscription ID. For Google Cloud, this is the Billing Account ID of the billing subaccount. Computed by Google Cloud after `ship`.
        </ResponseField>
        <ResponseField name="sku_id" type="string">
          Output only. The SKU pertaining to the provisioning resource as specified in the Offer. Computed by Google Cloud after `ship`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="provisioning_state" type="string">
      Output only. Current provisioning state of the entitlement. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="purchase_order_id" type="string">
      Optional. This purchase order (PO) information is for resellers to use for their company tracking usage. If a purchaseOrderId value is given, it appears in the API responses and shows up in the invoice. The property accepts up to 80 plain text characters. This is only supported for Google Workspace entitlements. Optional.
    </ResponseField>
    <ResponseField name="suspension_reasons" type="list(string)">
      Output only. Enumerable of all current suspension reasons for an entitlement. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="trial_settings" type="object">
      Settings for trial offers. Optional.
      <Expandable title="properties">
        <ResponseField name="end_time" type="string">
          Date when the trial ends. The value is in milliseconds using the UNIX Epoch format. See an example [Epoch converter](https://www.epochconverter.com). Optional.
        </ResponseField>
        <ResponseField name="trial" type="bool">
          Determines if the entitlement is in a trial or not: * `true` - The entitlement is in trial. * `false` - The entitlement is not in trial. Optional.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="update_time" type="string">
      Output only. The time at which the entitlement is updated. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="request_id" type="string">
  Optional. You can specify an optional unique request ID, and if you need to retry your request, the server will know to ignore the request if it's complete. For example, you make an initial request and the request times out. If you make the request again with the same request ID, the server can check if it received the original operation with the same request ID. If it did, it will ignore the second request. The request ID must be a valid [UUID](https://tools.ietf.org/html/rfc4122) with the exception that zero UUID is not supported (`00000000-0000-0000-0000-000000000000`). Optional.
</ResponseField>

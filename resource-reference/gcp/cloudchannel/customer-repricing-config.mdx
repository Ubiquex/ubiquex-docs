`google_cloudchannel_customer_repricing_config` is a reseller's repricing rule applied to a specific `google_cloudchannel_customer`, controlling the margin that customer is charged on top of Google's own price.

## Example

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own customer repricing config"})

    		ubx.Resource(cloudchannel.CustomerRepricingConfig, "example", cloudchannel.CustomerRepricingConfigConfig{

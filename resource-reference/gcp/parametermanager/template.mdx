## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	parametermanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/parametermanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own template"})

    		ubx.Resource(parametermanager.Template, "example", parametermanager.TemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";
    import { Template } from "@ubx/sdk-google/google/parametermanager/template";

    export default stack("example", () => {
      intent({ summary: "example own template" });

      resource(Template, "example", {
        name: "example",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import ubx_sdk as ubx
    from ubx.google.parametermanager import Template, TemplateConfig

    def describe():
        ubx.intent("example own template")

        ubx.resource(Template, "example", TemplateConfig(
            name="example",
        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

  Optional. Specifies the format of a Template. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  Optional. Labels as key value pairs Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the Template in the format `projects/*/locations/*/templates/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

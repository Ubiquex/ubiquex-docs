`google_parametermanager_parameter` is a named configuration parameter managed by Parameter Manager, with version(s) holding its own structured or plain-text value.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	parametermanager "github.com/ubiquex/ubx-sdk-google/sdk/go/google/parametermanager"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own parameter"})

    		ubx.Resource(parametermanager.Parameter, "example", parametermanager.ParameterConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

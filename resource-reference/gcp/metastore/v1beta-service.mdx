`google_metastore_v1beta_service` is a real, fully-managed Dataproc Metastore service, a Hive-compatible metadata catalog Dataproc, BigQuery, and other Spark/Hive-based tools can share against a single source of truth for table and schema metadata.

## Example

<Tabs>

    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	metastore "github.com/ubiquex/ubx-sdk-google/sdk/go/google/metastore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta service"})

    		ubx.Resource(metastore.V1betaService, "example", metastore.V1betaServiceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

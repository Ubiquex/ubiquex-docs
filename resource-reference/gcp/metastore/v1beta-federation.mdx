<Warning>
  This is Google Cloud's own **v1beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_metastore_federation`.
</Warning>

`google_metastore_v1beta_federation` exposes a single, real gRPC-queryable metadata surface federating multiple real backend metastores, such as BigQuery datasets, Dataplex Lakes, and other Dataproc Metastore services, without physically merging their data.

## Properties

<ResponseField name="backend_metastores" type="map(object)">
  A map from BackendMetastore rank to BackendMetastores from which the federation service serves metadata at query time. The map key represents the order in which BackendMetastores should be evaluated to resolve database names at query time and should be greater than or equal to zero. A BackendMetastore with a lower number will be evaluated before a BackendMetastore with a higher number. Optional; if omitted, computed by Google Cloud.

<ResponseField name="create_time" type="string">
  Output only. The time when the metastore federation was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="endpoint_uri" type="string">
  Output only. The federation endpoint. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="labels" type="map(string)">
  User-defined labels for the metastore federation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. The relative resource name of the federation, of the form: projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/federations/&#123;federation_id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the federation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state_message" type="string">
  Output only. Additional information about the current state of the metastore federation, if available. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="tags" type="map(string)">
  Optional. Input only. Immutable. Tag keys/values directly bound to this resource. For example: "123/environment": "production", "123/costCenter": "marketing" Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="uid" type="string">
  Output only. The globally unique resource identifier of the metastore federation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the metastore federation was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="version" type="string">
  Immutable. The Apache Hive metastore version of the federation. All backend metastore versions must be compatible with the federation version. Optional; if omitted, computed by Google Cloud.
</ResponseField>

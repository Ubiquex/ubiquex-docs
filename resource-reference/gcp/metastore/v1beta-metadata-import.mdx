`google_metastore_v1beta_metadata_import` bulk-loads existing Hive metastore metadata into a `google_metastore_service`, the real, one-time migration path for bringing an external Hive metadata catalog under Dataproc Metastore management.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	metastore "github.com/ubiquex/ubx-sdk-google/sdk/go/google/metastore"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own v1beta metadata import"})

    		ubx.Resource(metastore.V1betaMetadataImport, "example", metastore.V1betaMetadataImportConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="create_time" type="string">
  Output only. The time when the metadata import was started. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="database_dump" type="object">
  A specification of the location of and metadata about a database dump from a relational database management system. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="database_type" type="string">
      The type of the database. Optional.
    </ResponseField>
    <ResponseField name="gcs_uri" type="string">
      Optional. A Cloud Storage object or folder URI that specifies the source from which to import metadata. It must begin with gs://. Optional.
    </ResponseField>
    <ResponseField name="source_database" type="string">
      Optional. The name of the source database. Optional.
    </ResponseField>
    <ResponseField name="type" type="string">
      Optional. The type of the database dump. If unspecified, defaults to MYSQL. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Optional. The description of the metadata import. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="end_time" type="string">
  Output only. The time when the metadata import finished. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Identifier. The relative resource name of the metadata import, of the form:projects/&#123;project_number&#125;/locations/&#123;location_id&#125;/services/&#123;service_id&#125;/metadataImports/&#123;metadata_import_id&#125;. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The current state of the metadata import. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. The time when the metadata import was last updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

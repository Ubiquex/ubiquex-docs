<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_metastore_federation`.
</Warning>

`google_metastore_v1alpha_federation` exposes a single, real gRPC-queryable metadata surface federating multiple real backend metastores, such as BigQuery datasets, Dataplex Lakes, and other Dataproc Metastore services, without physically merging their data.

## Properties

<ResponseField name="backend_metastores" type="map(object)">
  A map from BackendMetastore rank to BackendMetastores from which the federation service serves metadata at query time. The map key represents the order in which BackendMetastores should be evaluated to resolve database names at query time and should be greater than or equal to zero. A BackendMetastore with a lower number will be evaluated before a BackendMetastore with a higher number. Optional; if omitted, computed by Google Cloud.

<ResponseField name="uid" type="string">

</ResponseField>

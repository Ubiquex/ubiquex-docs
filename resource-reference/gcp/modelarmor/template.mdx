`google_modelarmor_template` defines the safety and security filter configuration (prompt injection, jailbreak, sensitive data detection) Model Armor applies to LLM prompt(s) and response(s) passing through it.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	modelarmor "github.com/ubiquex/ubx-sdk-google/sdk/go/google/modelarmor"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own template"})

    		ubx.Resource(modelarmor.Template, "example", modelarmor.TemplateConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="backup_kind" type="string">
  Specifies the kind of backup, PHYSICAL or DEFAULT_SNAPSHOT. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="database_version" type="string">
  Output only. The instance database version at the time this backup was made. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  The description of this run, only applicable to on-demand backups. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disk_encryption_configuration" type="object">
  Disk encryption configuration for an instance. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kind" type="string">
      This is always `sql#diskEncryptionConfiguration`. Optional.
    </ResponseField>
    <ResponseField name="kms_key_name" type="string">
      Resource name of KMS key for disk encryption Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="disk_encryption_status" type="object">
  Disk encryption status for an instance. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="kind" type="string">
      This is always `sql#diskEncryptionStatus`. Optional.
    </ResponseField>
    <ResponseField name="kms_key_version_name" type="string">
      KMS key version used to encrypt the Cloud SQL instance resource Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="end_time" type="string">
  The time the backup operation completed in UTC timezone in [RFC 3339](https://tools.ietf.org/html/rfc3339) format, for example `2012-11-15T16:19:00.094Z`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="enqueued_time" type="string">
  The time the run was enqueued in UTC timezone in [RFC 3339](https://tools.ietf.org/html/rfc3339) format, for example `2012-11-15T16:19:00.094Z`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="error" type="object">
  Database instance operation error. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="code" type="string">
      Identifies the specific error that occurred. Optional.
    </ResponseField>
    <ResponseField name="kind" type="string">
      This is always `sql#operationError`. Optional.
    </ResponseField>
    <ResponseField name="message" type="string">
      Additional information about the error encountered. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="id" type="string">
  The identifier for this backup run. Unique only for a specific Cloud SQL instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="instance" type="string">
  Name of the database instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="kind" type="string">
  This is always `sql#backupRun`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="location" type="string">
  Location of the backups. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="max_chargeable_bytes" type="string">
  Output only. The maximum chargeable bytes for the backup. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="self_link" type="string">
  The URI of this resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="start_time" type="string">
  The time the backup operation actually started in UTC timezone in [RFC 3339](https://tools.ietf.org/html/rfc3339) format, for example `2012-11-15T16:19:00.094Z`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="status" type="string">
  The status of this run. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="time_zone" type="string">
  Backup time zone to prevent restores to an instance with a different time zone. Now relevant only for SQL Server. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="type" type="string">
  The type of this run; can be either "AUTOMATED" or "ON_DEMAND" or "FINAL". This field defaults to "ON_DEMAND" and is ignored, when specified for insert requests. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="window_start_time" type="string">
  The start time of the backup window during which this the backup was attempted in [RFC 3339](https://tools.ietf.org/html/rfc3339) format, for example `2012-11-15T16:19:00.094Z`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

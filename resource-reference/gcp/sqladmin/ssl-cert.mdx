## Input properties

<ResponseField name="common_name" type="string">
  User supplied name. Must be a distinct name from the other certificates for this instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

## Output properties

<ResponseField name="cert" type="string">
  PEM representation. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="cert_serial_number" type="string">
  Serial number, as extracted from the certificate. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="common_name" type="string">
  User supplied name. Must be a distinct name from the other certificates for this instance. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  The time when the certificate was created in [RFC 3339](https://tools.ietf.org/html/rfc3339) format, for example `2012-11-15T16:19:00.094Z` Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="expiration_time" type="string">
  The time when the certificate expires in [RFC 3339](https://tools.ietf.org/html/rfc3339) format, for example `2012-11-15T16:19:00.094Z`. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="instance" type="string">
  Name of the database instance. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="kind" type="string">
  This is always `sql#sslCert`. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="self_link" type="string">
  The URI of this resource. Computed by Google Cloud after `ship`.
</ResponseField>

<ResponseField name="sha1_fingerprint" type="string">
  Sha1 Fingerprint. Computed by Google Cloud after `ship`.
</ResponseField>

`google_iam_role` is a custom IAM role, a named, project- or organization-scoped bundle of permissions defined when none of Google Cloud's own predefined roles fit exactly.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own role"})

    		ubx.Resource(iam.Role, "example", iam.RoleConfig{
    			Role:   map[string]any{"name": "example-name"},
    			RoleId: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

    ```python
    import ubx_sdk as ubx
    from ubx.google.iam.role import Role, RoleConfig

    def describe():

            role={"name": "example-name"},

        ))

    if __name__ == "__main__":
        ubx.run("example", describe)
    ```

## Input properties

<ResponseField name="role" type="object">
  A role in the Identity and Access Management API. Optional.
  <Expandable title="properties">
    <ResponseField name="deleted" type="bool">
      The current deleted state of the role. This field is read only. It will be ignored in calls to CreateRole and UpdateRole. Optional.
    </ResponseField>
    <ResponseField name="description" type="string">
      Optional. A human-readable description for the role. Optional.
    </ResponseField>
    <ResponseField name="etag" type="string">
      Used to perform a consistent read-modify-write. Optional.
    </ResponseField>
    <ResponseField name="included_permissions" type="list(string)">
      The names of the permissions this role grants when bound in an IAM policy. Optional.
    </ResponseField>
    <ResponseField name="name" type="string">
      The name of the role. When `Role` is used in `CreateRole`, the role name must not be set. When `Role` is used in output and other input such as `UpdateRole`, the role name is the complete path. For example, `roles/logging.viewer` for predefined roles, `organizations/&#123;ORGANIZATION_ID&#125;/roles/myRole` for organization-level custom roles, and `projects/&#123;PROJECT_ID&#125;/roles/myRole` for project-level custom roles. Optional.
    </ResponseField>
    <ResponseField name="stage" type="string">
      The current launch stage of the role. If the `ALPHA` launch stage has been selected for a role, the `stage` field will not be included in the returned definition for the role. Optional.
    </ResponseField>
    <ResponseField name="title" type="string">
      Optional. A human-readable title for the role. Typically this is limited to 100 UTF-8 bytes. Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="role_id" type="string">
  The role ID to use for this role. A role ID may contain alphanumeric characters, underscores (`_`), and periods (`.`). It must contain a minimum of 3 characters and a maximum of 64 characters. Optional.
</ResponseField>

`google_iam_credential` represents a short-lived credential (an OAuth access token or ID token) generated for a service account via impersonation, without needing a long-lived service account key.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_iam --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_iam/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google_iam/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own credential"})

    		ubx.Resource(iam.IamCredential, "ci-runner", iam.IamCredentialConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_iam --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";
    import { IamCredential } from "./local-sdk/google_iam/sdk/typescript/google_iam/iam/iam_credential.ts";

    export default stack("payments", () => {
      intent({ summary: "payments own credential" });

      resource(IamCredential, "ci-runner", {
        name: "ci-runner",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_iam --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_iam/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_iam.iam import IamCredential, IamCredentialConfig

    def describe():
        ubx.intent("payments own credential")

        ubx.resource(IamCredential, "ci-runner", IamCredentialConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

## Properties

<ResponseField name="client_secret" type="string">
  Output only. The system-generated OAuth client secret. The client secret must be stored securely. If the client secret is leaked, you must delete and re-create the client credential. To learn more, see [OAuth client and credential security risks and mitigations](https://cloud.google.com/iam/docs/workforce-oauth-app#security) Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Whether the OauthClientCredential is disabled. You cannot use a disabled OauthClientCredential. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. A user-specified display name of the OauthClientCredential. Cannot exceed 32 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Identifier. The resource name of the OauthClientCredential. Format: `projects/&#123;project&#125;/locations/&#123;location&#125;/oauthClients/&#123;oauth_client&#125;/credentials/&#123;credential&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

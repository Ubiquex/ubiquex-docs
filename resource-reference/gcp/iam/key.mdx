`google_iam_key` is a cryptographic key belonging to a service account, a Workforce Identity Federation provider, or a Workload Identity Federation provider, depending on which resource it's attached to.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own key"})

    		ubx.Resource(iam.Key, "example", iam.KeyConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="expire_time" type="string">
  Output only. The time after which the key will be permanently deleted and cannot be recovered. Note that the key may get purged before this time if the total limit of keys per provider is exceeded. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="key_data" type="object">
  Represents a public key data along with its format. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="format" type="string">
      Output only. The format of the key. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="key" type="string">
      Output only. The key data. The format of the key is represented by the format field. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="key_spec" type="string">
      Required. The specifications for the key. Optional.
    </ResponseField>
    <ResponseField name="not_after_time" type="string">
      Output only. Latest timestamp when this key is valid. Attempts to use this key after this time will fail. Only present if the key data represents a X.509 certificate. Computed by Google Cloud after `ship`.
    </ResponseField>
    <ResponseField name="not_before_time" type="string">
      Output only. Earliest timestamp when this key is valid. Attempts to use this key before this time will fail. Only present if the key data represents a X.509 certificate. Computed by Google Cloud after `ship`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the key. Format: `locations/&#123;location&#125;/workforcePools/&#123;workforce_pool_id&#125;/providers/&#123;provider_id&#125;/keys/&#123;key_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="use" type="string">
  Required. The purpose of the key. Optional; if omitted, computed by Google Cloud.
</ResponseField>

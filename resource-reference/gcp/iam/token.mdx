`google_iam_token` represents a short-lived OAuth access token generated on demand for a service account via impersonation, the real, callable output of the IAM Service Account Credentials API's own `generateAccessToken` method.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own token"})

    		ubx.Resource(iam.Token, "example", iam.TokenConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">

## Properties

<ResponseField name="display_name" type="string">
  Optional. Gemini Enterprise only. The display name of the SCIM token. Cannot exceed 32 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. Gemini Enterprise only. The resource name of the SCIM Token. Format: `locations/&#123;location&#125;/workforcePools/&#123;workforce_pool&#125;/providers/ &#123;workforce_pool_provider&#125;/scimTenants/&#123;scim_tenant&#125;/tokens/&#123;token&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="security_token" type="string">
  Output only. Gemini Enterprise only. The token string. Provide this to the IdP for authentication. Will be set only during creation. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. Gemini Enterprise only. The state of the token. Optional; if omitted, computed by Google Cloud.
</ResponseField>

`google_iam_oauth_client` is an OAuth 2.0 client Google Cloud IAM issues, used by a workforce identity federation flow or a custom application to authenticate end users.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_iam --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_iam/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google_iam/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own oauth client"})

    		ubx.Resource(iam.IamOauthClient, "example", iam.IamOauthClientConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>

## Properties

<ResponseField name="allowed_grant_types" type="list(string)">
  Required. The list of OAuth grant types is allowed for the OauthClient. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="allowed_redirect_uris" type="list(string)">
  Required. The list of redirect uris that is allowed to redirect back when authorization process is completed. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="allowed_scopes" type="list(string)">
  Required. The list of scopes that the OauthClient is allowed to request during OAuth flows. The following scopes are supported: * `https://www.googleapis.com/auth/cloud-platform`: See, edit, configure, and delete your Google Cloud data and see the email address for your Google Account. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="client_id" type="string">
  Output only. The system-generated OauthClient id. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="client_type" type="string">
  Immutable. The type of OauthClient. Either public or private. For private clients, the client secret can be managed using the dedicated OauthClientCredential resource. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A user-specified description of the OauthClient. Cannot exceed 256 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Whether the OauthClient is disabled. You cannot use a disabled OAuth client. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. A user-specified display name of the OauthClient. Cannot exceed 32 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. Time after which the OauthClient will be permanently purged and cannot be recovered. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Identifier. The resource name of the OauthClient. Format:`projects/&#123;project&#125;/locations/&#123;location&#125;/oauthClients/&#123;oauth_client&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the OauthClient. Optional; if omitted, computed by Google Cloud.
</ResponseField>

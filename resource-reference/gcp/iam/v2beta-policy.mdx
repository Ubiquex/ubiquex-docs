<Warning>
  This is Google Cloud's own **v2beta** release channel (beta). Google may change or remove beta endpoints as a feature moves toward general availability -- confirm this endpoint is still live before depending on it in anything long-lived. No stable, generally-available equivalent is published yet.
</Warning>

`google_iam_v2beta_policy` is a real IAM v2 policy resource -- its own kind and rules -- a newer, more general policy shape than the classic Cloud IAM binding list, so access rules can be expressed and attached the same way regardless of which real IAM v2 policy kind they belong to.

<ResponseField name="name" type="string">
  Immutable. The resource name of the `Policy`, which must be unique. Format: `policies/&#123;attachment_point&#125;/denypolicies/&#123;policy_id&#125;` The attachment point is identified by its URL-encoded full resource name, which means that the forward-slash character, `/`, must be written as `%2F`. For example, `policies/cloudresourcemanager.googleapis.com%2Fprojects%2Fmy-project/denypolicies/my-deny-policy`. For organizations and folders, use the numeric ID in the full resource name. For projects, requests can use the alphanumeric or the numeric ID. Responses always contain the numeric ID. Optional; if omitted, computed by Google Cloud.
</ResponseField>

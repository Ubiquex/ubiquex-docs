## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own namespace"})

    		ubx.Resource(iam.Namespace, "example", iam.NamespaceConfig{
    			Name: "example",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { intent, resource, stack } from "@ubx/sdk";

    export default stack("example", () => {

      resource(Namespace, "example", {
        name: "example",
      });
    });
    ```
  </Tab>

    ```python
    import ubx_sdk as ubx

    def describe():

            name="example",

        ubx.run("example", describe)
    ```

## Properties

<ResponseField name="description" type="string">
  Optional. A description of the namespace. Cannot exceed 256 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Whether the namespace is disabled. If disabled, credentials may no longer be issued for identities within this namespace, however existing credentials will still be accepted until they expire. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. Time after which the namespace will be permanently purged and cannot be recovered. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the namespace. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="owner_service" type="object">
  The Google Cloud service that owns this namespace. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="principal_subject" type="string">
      Required. The service agent principal subject, e.g. "serviceAccount:service-1234@gcp-sa-gkehub.iam.gserviceaccount.com". Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the namespace. Optional; if omitted, computed by Google Cloud.
</ResponseField>

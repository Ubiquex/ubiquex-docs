`google_iam_workforce_pool` is a Workforce Identity Federation pool, letting an organization's own external workforce (e.g. employees federated through a corporate identity provider) access Google Cloud without a Google Workspace or Cloud Identity account.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own workforce pool"})

    		ubx.Resource(iam.WorkforcePool, "example", iam.WorkforcePoolConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="access_restrictions" type="object">
  Access related restrictions on the workforce pool. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">
    <ResponseField name="allowed_services" type="list(object)">
      Optional. Immutable. Services allowed for web sign-in with the workforce pool. If not set by default there are no restrictions. Optional.
      <Expandable title="properties">
        <ResponseField name="domain" type="string">
          The domain this allowed service applies to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="disable_programmatic_signin" type="bool">
      Optional. Disable programmatic sign-in by disabling token issue via the Security Token API endpoint. See [Security Token Service API] (https://cloud.google.com/iam/docs/reference/sts/rest). Optional.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="description" type="string">
  Optional. A description of the pool. Cannot exceed 256 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Disables the workforce pool. You cannot use a disabled pool to exchange tokens, or use existing tokens to access resources. If the pool is re-enabled, existing tokens grant access again. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="display_name" type="string">
  Optional. A display name for the pool. Cannot exceed 32 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. Time after which the workforce pool will be permanently purged and cannot be recovered. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the pool. Format: `locations/&#123;location&#125;/workforcePools/&#123;workforce_pool_id&#125;` Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="parent" type="string">
  Immutable. The resource name of the parent. Format: `organizations/&#123;org-id&#125;`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="session_duration" type="string">
  Optional. Duration that the Google Cloud access tokens, console sign-in sessions, and `gcloud` sign-in sessions from this pool are valid. Must be greater than 15 minutes (900s) and less than 12 hours (43200s). If `session_duration` is not configured, minted credentials have a default duration of one hour (3600s). For SAML providers, the lifetime of the token is the minimum of the `session_duration` and the `SessionNotOnOrAfter` claim in the SAML assertion. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the pool. Optional; if omitted, computed by Google Cloud.
</ResponseField>

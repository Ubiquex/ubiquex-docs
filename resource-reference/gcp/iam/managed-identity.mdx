`google_iam_managed_identity` is a managed identity within a Workload Identity Federation namespace, representing one workload that can authenticate to Google Cloud using its own external credentials.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	iam "github.com/ubiquex/ubx-sdk-google/sdk/go/google/iam"
    )

    func main() {
    	ubx.Main(ubx.Stack("example", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "example own managed identity"})

    		ubx.Resource(iam.ManagedIdentity, "example", iam.ManagedIdentityConfig{
    			Name: "example",
    		})
    	}))
    }
    ```

## Properties

<ResponseField name="description" type="string">
  Optional. A description of the managed identity. Cannot exceed 256 characters. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="disabled" type="bool">
  Optional. Whether the managed identity is disabled. If disabled, credentials may no longer be issued for the identity, however existing credentials will still be accepted until they expire. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="expire_time" type="string">
  Output only. Time after which the managed identity will be permanently purged and cannot be recovered. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Identifier. The resource name of the managed identity. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="state" type="string">
  Output only. The state of the managed identity. Optional; if omitted, computed by Google Cloud.
</ResponseField>

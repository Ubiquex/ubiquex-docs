`google_ftp_user` is a real user account provisioned on a `google_ftp_server`, the credential and access-control unit that authorizes SFTP clients to connect and transfer files into or out of the backing Cloud Storage bucket.

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_ftp --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_ftp/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	ftp "github.com/ubiquex/ubx-sdk-google/sdk/go/google_ftp/ftp"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own user"})

    		ubx.Resource(ftp.FtpUser, "ci-runner", ftp.FtpUserConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>

</ResponseField>

<ResponseField name="storage_directory_mappings" type="list(object)">
  Required. Mapping of Cloud Storage buckets to directories where the user will land in the SFTP server. Optional; if omitted, computed by Google Cloud.
  <Expandable title="properties">

      The real Cloud Storage bucket this FTP user's own storage directory mapping points at. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="bucket_prefix" type="string">
      The real object key prefix within `bucket` this storage directory mapping scopes the FTP user's access to. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="directory" type="string">
      The real, virtual FTP directory path this storage directory mapping exposes to the user. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
    <ResponseField name="permission" type="string">
      The real access level (`READ_ONLY` or `READ_WRITE`) this storage directory mapping grants the FTP user. Optional; if omitted, computed by Google Cloud. **(AI-inferred)**
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. [Output only] Update time stamp Optional; if omitted, computed by Google Cloud.
</ResponseField>

  <Expandable title="properties">

    <ResponseField name="credential_type" type="string">

  </Expandable>
</ResponseField>

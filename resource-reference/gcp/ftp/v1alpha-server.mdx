<Warning>
  This is Google Cloud's own **v1alpha** release channel (alpha). Google may change or remove alpha/preview endpoints at any time, often with no deprecation notice -- confirm this endpoint is still live before depending on it in anything long-lived. The stable, generally-available equivalent is `google_ftp_server`.
</Warning>

`google_ftp_v1alpha_server` is a Cloud FTP server, Google Cloud's managed, cloud-native way to move data in and out of Google Cloud Storage over SFTP, without operators having to run and patch their own SSH-based file transfer VM.

    <ResponseField name="allowed_cidr_blocks" type="list(string)">
      Optional. List of CIDR blocks that are allowed to access the Server. A CIDR range consists of an IP Address and a prefix length to construct the subnet mask. By default, the prefix length is 32 (i.e. matches a single IP address). For now, only IPV4 addresses are supported. Examples: "203.0.113.0/24" - matches with the IP addresses in the range 203.0.113.0 - 203.0.113.255. "0.0.0.0/0" - matches against any IP address. This field must contain at least one entry if the access type is EXTERNAL. The number of allowed CIDR blocks cannot exceed 500. Example: 192.168.0.0/16 Optional.
    </ResponseField>
    <ResponseField name="ip_address" type="string">

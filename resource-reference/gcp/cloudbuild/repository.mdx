`google_cloudbuild_repository` links a specific external Git repository into Cloud Build through a 2nd-gen connection, enabling it as a trigger source for build(s).

## Example

<Tabs>
  <Tab title="Go">
    ```go
    // ubx sdk gen --only google_cloudbuild --lang go --out ./local-sdk
    // go.mod: replace github.com/ubiquex/ubx-sdk-google/sdk/go => ./local-sdk/google_cloudbuild/sdk/go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	cloudbuild "github.com/ubiquex/ubx-sdk-google/sdk/go/google_cloudbuild/cloudbuild"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments own repository"})

    		ubx.Resource(cloudbuild.CloudbuildRepository, "ci-runner", cloudbuild.CloudbuildRepositoryConfig{
    			Name: "ci-runner",
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    // ubx sdk gen --only google_cloudbuild --lang ts --out ./local-sdk
    import { intent, resource, stack } from "@ubx/sdk";
    import { CloudbuildRepository } from "./local-sdk/google_cloudbuild/sdk/typescript/google_cloudbuild/cloudbuild/cloudbuild_repository.ts";

    export default stack("payments", () => {
      intent({ summary: "payments own repository" });

      resource(CloudbuildRepository, "ci-runner", {
        name: "ci-runner",
      });
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    # ubx sdk gen --only google_cloudbuild --lang py --out ./local-sdk
    # export PYTHONPATH=./local-sdk/google_cloudbuild/sdk/python:$PYTHONPATH
    import ubx_sdk as ubx
    from ubx.google_cloudbuild.cloudbuild import CloudbuildRepository, CloudbuildRepositoryConfig

    def describe():
        ubx.intent("payments own repository")

        ubx.resource(CloudbuildRepository, "ci-runner", CloudbuildRepositoryConfig(
            name="ci-runner",
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```
  </Tab>

## Properties

<ResponseField name="annotations" type="map(string)">
  Optional. Allows clients to store small amounts of arbitrary data. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="create_time" type="string">
  Output only. Server assigned timestamp for when the connection was created. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="etag" type="string">
  This checksum is computed by the server based on the value of other fields, and may be sent on update and delete requests to ensure the client has an up-to-date value before proceeding. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="name" type="string">
  Immutable. Resource name of the repository, in the format `projects/*/locations/*/connections/*/repositories/*`. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="remote_uri" type="string">
  Required. Git Clone HTTPS URI. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="update_time" type="string">
  Output only. Server assigned timestamp for when the connection was updated. Optional; if omitted, computed by Google Cloud.
</ResponseField>

<ResponseField name="webhook_id" type="string">
  Output only. External ID of the webhook created for the repository. Optional; if omitted, computed by Google Cloud.
</ResponseField>

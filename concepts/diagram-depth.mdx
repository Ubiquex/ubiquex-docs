---
title: "Diagram Medium: Depth"
description: "The ubx_required escape hatch and cross-node references."
---

A diagram naturally shows structure, which resources exist, how they
connect. It doesn't naturally express every last configuration detail a
resource might need, and forcing every attribute into a box-and-arrow
format would make diagrams unreadable. The diagram medium accepts that
limit deliberately, with one real, scoped exception.

## How it works

The diagram parser is purely structural, it reads real D2 topology and
translates it directly into resources, with no AI involved anywhere in
this medium. For an attribute a real provider schema marks required, but
that a diagram can't naturally express, a node can set it directly:

```d2
role: "ci-runner" {
  class: aws_iam_role
  ubx_required.assume_role_policy: "..."
}
```

This escape hatch is scoped narrowly: only genuinely required attributes
are accepted this way, anything else is refused immediately.

## Why letting any attribute be set this way doesn't work

If `ubx_required` accepted any attribute at all, the diagram medium
would quietly turn into "prose config with boxes drawn around it,"
losing the thing that makes it valuable, real, honest topology that a
human can actually read at a glance. Scoping the escape hatch strictly
to required attributes keeps that promise intact.

## What this actually looks like

A `ubx_required` value can also point at another node in the same
diagram, resolved into a real reference once every node's own type and
name are known:

```d2
attach: "attach" {
  class: aws_iam_role_policy_attachment
  ubx_required.role: "ref:role.name"
  ubx_required.policy_arn: "ref:policy.arn"
}
```

Neither `ref:` value is a literal string. Both resolve to the real, live
attribute of the node they name, which matters specifically for an IAM
role whose real name is only known after it's actually created.

## Why it matters

The diagram medium stays what it's actually good at, real topology,
readable at a glance, with one narrow, honest exception for the
attributes that genuinely can't be expressed any other way.

---
title: "Secrets & Redaction"
description: "Secret material never enters the ledger, not even by accident."
---

The ledger is permanent and, in a team setting, often widely readable.
If a real password or API key ever landed inside it, there'd be no
taking that back, every copy of the ledger, everywhere, would carry it
forever. Secrets need a guarantee stronger than "we'll try to be
careful."

## How it works

Two separate mechanisms make this true. First, a config value can
reference a secret's real location instead of holding its value:

```json
{ "master_password": { "$secret": { "backend": "aws_secrets_manager", "path": "payments/db-password" } } }
```

The AI, the ledger, and every proposal only ever see this reference. The
real value is fetched at ship time, never stored anywhere.

Second, any attribute a real provider schema marks sensitive gets
redacted automatically, the instant it's read from live infrastructure,
before it ever reaches the ledger:

```json
{ "admin_password": { "$redacted": { "sha256": "9f2a..." } } }
```

## Why "just be careful about what you paste" doesn't work

Relying on every person, every time, to remember never to paste a real
secret into a document means it only takes one mistake, one tired
Friday afternoon, for something permanent and irreversible to happen.
Automatic, schema-driven redaction removes the need to rely on anyone
remembering.

## What this actually looks like

Redaction uses a per-ledger salt so two redacted values can still be
compared for equality, has this secret actually changed, without either
one ever being recoverable from the hash alone. If that salt is ever
lost, the honest consequence is real but bounded: every future
comparison reports a false drift once, since the new salt produces
different hashes for the same real secret. It never causes a real secret
to leak, and it never causes a real change to go undetected.

## Why it matters

A secret can never end up in the ledger, structurally, not by policy.
There's no step in the pipeline where a real value could accidentally
slip through, because the redaction happens automatically, before the
ledger ever sees it.

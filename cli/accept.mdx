---
title: "ubx accept"
description: "Accept a proposal -- locally, or derived from a merged GitHub pull request -- and append it to the ledger"
---

```text
ubx accept [proposal.json] [flags]
ubx accept --from-merge <sha> --proposal-file <path> --github-repo <owner/name> [flags]
```

Signs a [proposal](/concepts/proposal) and appends it to the [ledger](/concepts/ledger),
using one of two acceptance tiers:

- **Local** — `ubx accept proposal.json` signs a file on disk, recording your OS
  username and the current time.
- **PR-merge** — `ubx accept --from-merge` derives acceptance from a merged
  GitHub pull request: it verifies the merge commit exists, that the proposal
  file at that commit hashes to the trailer claimed in the PR body, and records
  every reviewer whose most recent review was an approval.

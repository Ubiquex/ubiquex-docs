---
title: "ubx propose"
description: "Compute a draft proposal's canonical hash for a PR body's ubx-proposal trailer"
---

```text
ubx propose <proposal.json> [flags]
```

Computes a draft proposal's canonical hash and prints it as a
`ubx-proposal: <hash>` line, without touching the ledger. This is the first
step of PR-merge acceptance: put that line in the body of the pull request
carrying the proposal file, so `ubx accept --from-merge` has a claimed hash to
verify against once the PR is merged.

<Note>

  session. In the meantime, `ubx propose --help` is authoritative.
</Note>

---
title: "ubx version"
description: "Print the ubx version"
---

```text
ubx version [flags]
```

Prints the `ubx` binary's version string to stdout, and nothing else.

## Flags

| Flag | Description |
| --- | --- |
| `-h`, `--help` | help for version |

## Example

```text
$ ubx version
dev
```

<Note>
  A binary built without `-ldflags "-X github.com/ubiquex/ubiquex-cli/cli.Version=..."`
  always prints `dev` — that's what every build from source produces today,
  since there's no release process yet (see [Installation](/getting-started/installation)).
</Note>

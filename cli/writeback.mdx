---
title: "ubx writeback"
description: "Write an accepted drift_adopt proposal's recorded reality back into existing .tf source"
---

```text
ubx writeback <proposal-id> [flags]
```

Takes an already-*accepted* `drift_adopt` [proposal](/concepts/proposal) and
corrects your existing `.tf` source to match what it recorded — narrowly. It
only ever overwrites a literal attribute value (or inserts a new key into an
existing literal map, like a new tag), and only when it can locate the
resource block unambiguously. Anything it can't safely change — an attribute
whose current value is an expression, not a literal — is declined and reported,
never guessed at. By default it prints a diff; `--write` actually modifies the
file. Neither ever commits or pushes.

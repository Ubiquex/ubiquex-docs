---
title: "ubx scan"
description: "Compare one resource's live state against the ledger and generate a proposal if it differs"
---

```text
ubx scan [flags]
```

Reads one resource's live state (via a Terraform provider binary, speaking the
provider protocol directly) and compares it against the [ledger](/concepts/ledger).
If the resource is new, or its state has [drifted](/concepts/drift) from what's
recorded, `ubx scan` generates and prints a proposal. On a best-effort basis, it
also attempts [CloudTrail attribution](/concepts/attribution) for drift, and can
optionally surface drift as a GitHub issue or pull request.

  session. In the meantime, `ubx scan --help` is authoritative.

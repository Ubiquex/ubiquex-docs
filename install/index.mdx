---
title: "Install"
description: "Install ubx from a GitHub release or build it from source."
---

Two ways to install `ubx` today: download a prebuilt binary from GitHub
Releases, or build it from source with Go.

## GitHub Releases

Prebuilt binaries for macOS and Linux (Intel and Apple Silicon / ARM).

```bash
curl -L https://github.com/Ubiquex/ubiquex/releases/latest/download/ubx_<version>_<os>_<arch>.tar.gz | tar xz
sudo mv ubx /usr/local/bin/
```

Replace `<version>`, `<os>` (`darwin` or `linux`), and `<arch>` (`amd64`
or `arm64`) with the values matching your machine and the release you
want. Every release lists the exact filenames on its
[GitHub Releases page](https://github.com/Ubiquex/ubiquex/releases).

Verify the install:

```bash
ubx version
```

## Build from source

Requires Go 1.26 or later.

```bash
git clone https://github.com/Ubiquex/ubiquex.git
cd ubiquex
go build -o ubx ./cmd/ubx
sudo mv ubx /usr/local/bin/
```

Verify the install:

```bash
ubx version
```

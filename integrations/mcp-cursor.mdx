---
title: "Connect Cursor"
description: "Configure Cursor to call ubx mcp's own read-only tools."
---

Cursor reads MCP servers from an `mcp.json` file, the same
`mcpServers` shape Claude Desktop and Claude Code use.

## Configure

Create `.cursor/mcp.json` in your project for this repo only, or
`~/.cursor/mcp.json` in your home directory to make `ubx` available
everywhere:

```json
{
  "mcpServers": {
    "ubx": { "command": "ubx", "args": ["mcp"] }
  }
}
```

## Verify

Open Cursor Settings, then **MCP**. `ubx` should show as connected,
with its three tools listed underneath.

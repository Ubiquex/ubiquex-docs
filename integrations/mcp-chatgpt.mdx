---

This is narrower than it sounds, on purpose. Confirmed directly
against OpenAI's own current documentation: **ChatGPT web can't reach
`ubx mcp` at all** -- it only uses remote, plugin-supplied MCP tools
over HTTP, and doesn't read local configuration or expose a local
command menu. `ubx mcp` serves over stdio, a local process, which
ChatGPT web has no path to.

The **ChatGPT desktop app** is a separate surface that shares its MCP
configuration with Codex (OpenAI's own coding agent, CLI/desktop/IDE),
and that shared configuration genuinely does support local stdio
servers. This page covers that path specifically -- not a bridge or
workaround, the desktop app's own real, documented mechanism.

## Configure

In the ChatGPT desktop app, open **Settings**, then **MCP servers**,
then **Add server**. Enter a name (`ubx`), choose **STDIO**, and enter
`ubx mcp` as the command. Save, then **Restart**.

For direct file editing instead -- the same configuration Codex CLI and
the Codex IDE extension also read -- add an entry to
`~/.codex/config.toml`:

```toml
[mcp_servers.ubx]
command = "ubx"
args = ["mcp"]
```

## Verify

In the composer, type `/mcp` to view connected servers. `ubx` should
list its three tools.

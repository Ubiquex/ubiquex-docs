---
title: "Connect Claude Code"
description: "Configure Claude Code to call ubx mcp's own read-only tools."
---

Claude Code adds MCP servers through its own CLI command, not a config
file you hand-edit directly.

## Configure

Run this once, from anywhere:

```bash
claude mcp add ubx -- ubx mcp
```

The `--` separates Claude Code's own flags from the server's command --
everything after it runs exactly as typed, `ubx mcp` with no arguments
of its own. This adds `ubx` at user scope, available in every project.

For a team-shared setup instead, add `--scope project`: Claude Code
writes the entry to a `.mcp.json` file at the project root, which you
check into version control so everyone gets the same server:

```json
{
  "mcpServers": {
    "ubx": { "command": "ubx", "args": ["mcp"] }
  }
}
```

A teammate who pulls a repo with `.mcp.json` already in it still has
to approve the server once, the first time they run `claude`
interactively in that project.

## Verify

```bash
claude mcp list
```

`ubx` should show `✔ Connected`. Inside a session, `/mcp` lists the
same thing along with `ubx`'s three tools.

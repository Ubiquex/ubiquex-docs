---
title: "Connect Claude Desktop"
description: "Configure Claude Desktop to call ubx mcp's own read-only tools."
---

Claude Desktop starts MCP servers from a JSON config file, one entry
per server, the same shape every server in this file shares.

## Configure

Open the Claude menu (not the in-window settings) and select
**Settings...**, then the **Developer** tab, then **Edit Config**. This
opens (or creates) the real config file directly:

* **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
* **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Add a `ubx` entry:

```json
{
  "mcpServers": {
    "ubx": { "command": "ubx", "args": ["mcp"] }
  }
}
```

Claude Desktop launches `ubx mcp` with this config file's own working
directory context -- point Claude Desktop at a real ledger checkout the
same way you'd `cd` there yourself before running `ubx` from a
terminal.

## Verify

Quit Claude Desktop completely and relaunch it -- the config only loads
at startup. Click the "Add files, connectors, and more" indicator in
the composer, then **Connectors**, then **Manage connectors**. `ubx`
should list its three tools.

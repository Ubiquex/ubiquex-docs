---
title: "Connect VS Code"
description: "Configure VS Code to call ubx mcp's own read-only tools."
---

VS Code's own MCP config file uses a genuinely different top-level key
from Claude Desktop's, Claude Code's, and Cursor's -- `servers`, not
`mcpServers` -- confirmed directly against VS Code's own current
documentation, not assumed consistent with the others.

## Configure

Run **MCP: Add Server** from the Command Palette for a guided flow, or
create `.vscode/mcp.json` in your project directly:

```json
{
  "servers": {
    "ubx": { "command": "ubx", "args": ["mcp"] }
  }
}
```

For a config that follows you across projects instead, run **MCP:
Open User Configuration** from the Command Palette and add the same
entry there.

## Verify

Open the Chat view. `ubx` appears in the tools list with its three
tools; select it to confirm they're the ones `ubx mcp --help` lists
(`why`, `status`, `scan`).

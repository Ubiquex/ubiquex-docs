---
title: "Converting a real module"
description: "Turn an existing Terraform module into a real blueprint."
---

If your team has real, existing Terraform modules, they don't have to
be rewritten by hand to get ubx's trust guarantees.

## Get a real module

```bash
git clone https://github.com/terraform-aws-modules/terraform-aws-vpc.git
```

Any real module works, this tutorial uses a real, public one directly.

## Convert it

```bash
ubx blueprint convert --from-terraform ./terraform-aws-vpc --out ./vpc-blueprint
```

```bash
converted: 12 resources, 8 outputs, 2 for_each loops
1 question -- variable.tf line 42: unsupported function merge(), review manually
```

No AI involved. Every `variable` became a parameter, every `resource`
became a call, every `output` became a declared output.

## Build it

```bash
cd vpc-blueprint
ubx blueprint build .
```

```bash
built 12 resource(s) -> . (go, ts, py)
```

## Verify it resolves correctly

```bash
ubx blueprint verify .
```

```bash
verified "vpc-blueprint": content hash sha256:a1b2c3... matches (14 file(s))
```

## What you just did

You converted a real, existing, publicly-used Terraform module into a
real blueprint, mechanically, with the module's own precision
preserved rather than redrafted by an AI.

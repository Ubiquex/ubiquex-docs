Same commands, `hashicorp/google` instead of `hashicorp/aws`. Two real
resources, one referencing the other, shown in all three languages.

## Set up a stack

```bash
mkdir payments-gcp && cd payments-gcp
ubx init --source hashicorp/google --provider-version 5.40.0
```

## Author both resources

<Tabs>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	pubsub "github.com/ubiquex/ubx-sdk-google/sdk/go/google/pubsub"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments topic and worker subscription"})

    		topic := ubx.Resource(pubsub.Topic, "pipeline-events", pubsub.TopicConfig{
    			Name: "pipeline-events",
    		})

    		ubx.Resource(pubsub.Subscription, "pipeline-events-worker", pubsub.SubscriptionConfig{
    			Name:                "pipeline-events-worker",
    			Topic:               topic.Field("id"),
    			AckDeadlineSeconds:  30,
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    git clone https://github.com/Ubiquex/ubx-sdk-google.git
    ```
    ```typescript
    import { stack, intent, resource } from "@ubx/sdk";
    import { Topic } from "./ubx-sdk-google/sdk/typescript/google/pubsub/topic.ts";
    import { Subscription } from
      "./ubx-sdk-google/sdk/typescript/google/pubsub/subscription.ts";

    export default stack("payments", () => {
      intent({ summary: "payments topic and worker subscription" });

      const topic = resource(Topic, "pipeline-events", {
        name: "pipeline-events",
      });

      resource(Subscription, "pipeline-events-worker", {
        name: "pipeline-events-worker",
        topic: topic.id,
        ackDeadlineSeconds: 30,
      });
    });
    ```
    A real, local, cloned import, never a remote URL, the hermetic
    evaluator's own `--no-remote` flag refuses anything else.
  </Tab>
  <Tab title="Python">
    ```bash
    git clone https://github.com/Ubiquex/ubx-sdk-google.git
    ```
    Save this file **inside** the cloned repo's own `sdk/python/`
    directory (alongside the `ubx/` namespace package it imports from),
    as `ubx-sdk-google/sdk/python/create_platform.py`:
    ```python
    import ubx_sdk as ubx
    from google.pubsub import Topic, TopicConfig, Subscription, SubscriptionConfig

    def describe():
        ubx.intent("payments topic and worker subscription")

        topic = ubx.resource(Topic, "pipeline-events", TopicConfig(
            name="pipeline-events",
        ))

        ubx.resource(Subscription, "pipeline-events-worker", SubscriptionConfig(
            name="pipeline-events-worker",
            topic=topic.id,
            ack_deadline_seconds=30,
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```
  </Tab>
</Tabs>

Every tab resolves to the exact same delta:

```bash
Plan  payments

  + google_pubsub_topic.pipeline-events create
      name: "pipeline-events"

  + google_pubsub_subscription.pipeline-events-worker create
      name: "pipeline-events-worker"
      topic: $ref:payments.google_pubsub_topic.pipeline-events.id
      ack_deadline_seconds: 30

delta: +2 create(s), ~0 change(s), -0 terminate(s)
```

The subscription's `topic` isn't a guessed name, it's a real reference,
resolved to the topic's actual ID once it exists.

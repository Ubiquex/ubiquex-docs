---

Chat is the same drafting as markdown, held as a real, ongoing
conversation. This tutorial walks through one from start to finish.

## Start a session

```bash
ubx chat --stack payments
```

```bash
ubx chat: type a turn and press enter. /save to finalize, /quit (or EOF) to abandon without saving anything.
```

## Describe what you want, one message at a time

```bash
> We need a Postgres database for payments, like staging but smaller.
```

```bash
AI defaults, you are signing these:
  instance_class: defaulted to db.t3.small, one size below staging's db.t3.medium

+ aws_db_instance.payments-db create
    engine: "postgres"
    instance_class: "db.t3.small"
```

Add another turn:

```bash
> Make it multi-az.
```

```bash
+ aws_db_instance.payments-db create
    engine: "postgres"
    instance_class: "db.t3.small"
    multi_az: true
```

The whole draft redrew itself with both turns folded in, not just the
latest one appended.

## Finalize

```bash
> /save
```

```bash
captured dialogue: dialogues/9f2a1b3c....dlg.json
{ "schema_version": 1, "kind": "ubx:intent/v1", "stack": "payments", "resources": [ "..." ] }
```

## See the real conversation later

```bash
ubx why <hash> --dialogue
```

```bash
conversation (claude / claude-sonnet-5, started 2026-08-06T...):
  [Turn 1, ...]: We need a Postgres database for payments, like staging but smaller.
  [Turn 2, ...]: Make it multi-az.
```

## What you just did

You built up a real resource across two natural messages, and the
entire conversation, not just the final draft, became a permanent part
of the record.

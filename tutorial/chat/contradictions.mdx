---
title: "Changing your mind"
description: "See how a later message correcting an earlier one gets handled."
---

Real conversations aren't always linear. This tutorial deliberately
reverses an earlier decision partway through, and shows exactly how
that gets recorded, not silently overwritten.

## Start with one instance size

```bash
ubx chat --stack payments
```

```bash
> instance class db.t3.large
```

```bash
+ aws_db_instance.payments-db create
    instance_class: "db.t3.large"
```

## Change your mind

```bash
> actually, use db.t3.micro instead, not large
```

```bash
+ aws_db_instance.payments-db create
    instance_class: "db.t3.micro"

AI defaults, you are signing these:
  instance_class: Turn 1 requested db.t3.large; Turn 2 overrode it with
    db.t3.micro. Following the later turn.
```

The final draft reflects your correction, and the assumptions block
names both turns explicitly, so anyone reviewing this later sees the
real back-and-forth, not just the outcome.

## Finalize and check

```bash
> /save
```

```bash
ubx why <hash> --dialogue
```

```bash
conversation (claude / claude-sonnet-5, started ...):
  [Turn 1, ...]: instance class db.t3.large
  [Turn 2, ...]: actually, use db.t3.micro instead, not large
```

Both turns are still there, permanently. Nothing was ever erased, the
correction is just as visible as the original.

## What you just did

You reversed yourself mid-conversation and saw that ubx never quietly
drops the earlier turn or pretends it didn't happen. Both are part of
the honest record.

Six tutorials: building your first blueprint, doing the same thing
through an AI assistant instead, calling it from real SDK code, proving
a hand-written intent file calls it identically, mixing a call with
resources you wrote by hand in the same stack, and composing calls in
plain HCL with no SDK at all.

title: "Write your first program"
description: "Import real, published bindings and ship a real resource."
---

Four real, published repos already exist, one per provider, each with
all three languages as sibling subdirectories (`sdk/go/`,
`sdk/typescript/`, `sdk/python/`). This tutorial imports one directly,
no generation step at all.

## Add the real published repo

```bash
go mod init payments
go get github.com/ubiquex/ubx-sdk-aws/sdk/go
```

## Write a program

```go
package main

import (
	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
	sqs "github.com/ubiquex/ubx-sdk-aws/sdk/go/aws/sqs"
)

func main() {
	ubx.Main(ubx.Stack("payments", func() {
		ubx.Intent(ubx.IntentInfo{Summary: "payments own SQS queue"})
		ubx.Resource(sqs.Queue, "pipeline-events", sqs.QueueConfig{
			Name:                    "pipeline-events",
			MessageRetentionSeconds: 1209600,
		})
	}))
}
```

Save this as `create_platform.go`. `sqs.Queue` and `sqs.QueueConfig`
come straight from the real, published `ubx-sdk-aws/sdk/go` repo, real, typed
bindings, maintained and version-watched automatically.

## Resolve it

```bash
ubx plan --from-code create_platform.go
```

```bash

  + aws_sqs_queue.pipeline-events create
      message_retention_seconds: 1209600

ubx-proposal: 45f63ce10849...

```

## Ship it

```bash
ubx ship 45f63ce10849...
```

```bash

```

## What you just did

You imported real, typed bindings from a real, published repo, the
compiler checked your program against the exact wire attribute names
AWS expects, and you never had to generate anything locally.

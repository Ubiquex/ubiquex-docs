Same commands, `hashicorp/kubernetes` as the provider. Two real
resources, one referencing the other, shown in all five mediums.

## Set up a stack

```bash
mkdir payments-k8s && cd payments-k8s
ubx init --source hashicorp/kubernetes --provider-version 2.31.0
```

## Author both resources

<Tabs>
  <Tab title="Markdown">
    ```bash
    cat > platform.md << 'EOF'
    Create a Kubernetes secret called "db-credentials" in the "payments"
    namespace, with a key "password" referencing our secret store.

    Deploy a single-replica deployment called "payments-worker" in that
    same namespace, image "acme/payments-worker:latest", with an
    environment variable DB_PASSWORD sourced from that secret's password key.
    EOF
    ubx plan --from-doc platform.md --stack payments
    ```
  </Tab>
  <Tab title="Go">
    ```go
    package main

    import (
    	ubx "github.com/ubiquex/ubx-sdk-go/runtime"
    	core "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/core"
    	apps "github.com/ubiquex/ubx-sdk-kubernetes/sdk/go/kubernetes/apps"
    )

    func main() {
    	ubx.Main(ubx.Stack("payments", func() {
    		ubx.Intent(ubx.IntentInfo{Summary: "payments secret and worker deployment"})

    		secret := ubx.Resource(core.SecretV1, "db-credentials", core.SecretV1Config{
    			Metadata: core.ObjectMeta{Name: "db-credentials", Namespace: "payments"},
    			Data: map[string]any{
    				"password": ubx.Secret("aws_secrets_manager", "payments/db-password"),
    			},
    		})

    		ubx.Resource(apps.DeploymentV1, "payments-worker", apps.DeploymentV1Config{
    			Metadata: core.ObjectMeta{Name: "payments-worker", Namespace: "payments"},
    			Spec: apps.DeploymentSpec{
    				Replicas: 1,
    				Template: core.PodTemplate{
    					Containers: []core.Container{{
    						Name:  "payments-worker",
    						Image: "acme/payments-worker:latest",
    						Env: []core.EnvVar{{
    							Name: "DB_PASSWORD",
    							ValueFrom: core.EnvVarSource{
    								SecretKeyRef: core.SecretKeyRef{
    									Name: secret.Field("metadata").Field("name"),
    									Key:  "password",
    								},
    							},
    						}},
    					}},
    				},
    			},
    		})
    	}))
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    git clone https://github.com/Ubiquex/ubx-sdk-kubernetes.git
    ```
    ```typescript
    import { stack, intent, resource, secret } from "@ubx/sdk";
    import { SecretV1 } from "./ubx-sdk-kubernetes/sdk/typescript/kubernetes/secret/secret_v1.ts";
    import { DeploymentV1 } from
      "./ubx-sdk-kubernetes/sdk/typescript/kubernetes/deployment/deployment_v1.ts";

    export default stack("payments", () => {
      intent({ summary: "payments secret and worker deployment" });

      const dbSecret = resource(SecretV1, "db-credentials", {
        metadata: { name: "db-credentials", namespace: "payments" },
        data: { password: secret("aws_secrets_manager", "payments/db-password") },
      });

      resource(DeploymentV1, "payments-worker", {
        metadata: { name: "payments-worker", namespace: "payments" },
        spec: {
          replicas: 1,
          template: {
            containers: [{
              name: "payments-worker",
              image: "acme/payments-worker:latest",
              env: [{
                name: "DB_PASSWORD",
                valueFrom: { secretKeyRef: { name: dbSecret.metadata.name, key: "password" } },
              }],
            }],
          },
        },
      });
    });
    ```
    A real, local, cloned import, never a remote URL, the hermetic
    evaluator's own `--no-remote` flag refuses anything else.
  </Tab>
  <Tab title="Python">
    ```bash
    git clone https://github.com/Ubiquex/ubx-sdk-kubernetes.git
    ```
    Save this file **inside** the cloned repo's own `sdk/python/`
    directory (alongside the `ubx/` namespace package it imports from),
    as `ubx-sdk-kubernetes/sdk/python/create_platform.py`:
    ```python
    import ubx_sdk as ubx
    from kubernetes.core import SecretV1, SecretV1Config, ObjectMeta
    from kubernetes.apps import DeploymentV1, DeploymentV1Config

    def describe():
        ubx.intent("payments secret and worker deployment")

        db_secret = ubx.resource(SecretV1, "db-credentials", SecretV1Config(
            metadata=ObjectMeta(name="db-credentials", namespace="payments"),
            data={"password": ubx.secret("aws_secrets_manager", "payments/db-password")},
        ))

        ubx.resource(DeploymentV1, "payments-worker", DeploymentV1Config(
            metadata=ObjectMeta(name="payments-worker", namespace="payments"),
            spec={
                "replicas": 1,
                "template": {
                    "containers": [{
                        "name": "payments-worker",
                        "image": "acme/payments-worker:latest",
                        "env": [{
                            "name": "DB_PASSWORD",
                            "valueFrom": {"secretKeyRef": {"name": db_secret.metadata.name, "key": "password"}},
                        }],
                    }],
                },
            },
        ))

    if __name__ == "__main__":
        ubx.run("payments", describe)
    ```

The deployment's `secretKeyRef.name` is a real reference to the secret,
never a hardcoded name the two resources could quietly fall out of sync
on. The real secret value stays a reference the whole way through,
never appearing in either resource's own config.

## Ship it

```bash
ubx ship <hash>
```

```bash

  ✓ kubernetes_deployment_v1.payments-worker : shipped

```

The deployment correctly waited for the secret to ship first.

and secret-handling discipline work identically across prose, two

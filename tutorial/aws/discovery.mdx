---

Infrastructure created by hand, in the console, with no tool ever
involved, has no state file to read from. This tutorial finds it a
different way.

## Discover by tag

```bash
ubx scan --discover --tag team=payments --stack payments
```

```bash
found 4 resource(s) matching team=payments, not yet in the ledger
next: ubx accept <hash>  (record them as-is, zero blast radius)
```

Real ARNs, enumerated directly from AWS's own tagging API.

## Preview the grouping first

Before committing to a stack name:

```bash
ubx scan --discover --suggest-stacks --tag team=payments
```

```bash
suggested grouping (by tag "team"):
  payments: 4 resource(s)
```

Read-only, nothing written yet.

## Accept what you found

```bash
ubx accept <hash>
```

```bash
accepted <hash> (stack payments)
4 resource(s) adopted, 0 changed
```

## What you just did

You brought infrastructure that predates any tooling under the ledger,
using nothing but real tags and a real, live cloud read, no state file
ever involved.

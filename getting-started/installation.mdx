## Build from source

You need [Go](https://go.dev) 1.26 or later and a working `git` installation.

```bash
git clone https://github.com/Ubiquex/ubiquex-cli.git
cd ubiquex-cli
go build -o ubx ./cmd/ubx
```

This produces a single `ubx` binary in the current directory. Move it onto your
`PATH`, or invoke it as `./ubx`.

Confirm it built correctly:

```bash
./ubx version
```

## What you'll also need

- **A Terraform provider binary** for whatever cloud resources you're reading —
  ubx speaks the Terraform provider wire protocol directly. `ubx scan`/`ubx accept`
  can acquire and verify one for you (`--source hashicorp/aws
  --provider-version <version>`), or you can point at a binary you already have
  (`--provider /path/to/terraform-provider-aws`).
- **AWS credentials** in your environment, if you're reading AWS resources —
  ubx uses whatever the provider binary itself picks up (the same credential
  chain Terraform's AWS provider uses).
- **A GitHub personal access token** (`GITHUB_TOKEN`), only if you're using
  PR-merge acceptance or the drift-surfacing features — see
  [Attribution](/concepts/attribution) and the CLI reference for `ubx accept`
  and `ubx scan`.

The ubx SDK — a describe-only TypeScript library for authoring infrastructure
as typed code — is **not yet released**.

## What exists today

Resources are created and modified through **typed intent files** (`intent/v1`
JSON), resolved deterministically and shipped through the signed proposal
pipeline:

```bash
ubx resolve intent.json --source hashicorp/aws --provider-version 6.54.0 \
  --out change.prop.json
ubx accept change.prop.json
ubx ship <proposal-id>
```

See [ubx resolve](/cli/resolve) for the intent file format and the full
authoring flow, and the [create flow guide](/guides/create-flow) for a
complete worked example against real infrastructure.

## What the SDK will be

When released, the SDK will generate the same intent objects with type
safety and IDE support — it is an authoring frontend to the pipeline that
exists today, not a separate system. Code authored with the SDK will
evaluate in a hermetic sandbox and freeze to the same signed, hashed
proposal artifact that every other medium produces.

This page will become the SDK reference when the SDK ships.

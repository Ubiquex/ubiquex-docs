---
title: "ubx config"
description: "Show the resolved config cascade, every effective value and exactly which file supplied it."
---

Given how many files can contribute to one final config (Config Cascade
covers the real mechanism), you need a real way to see what actually
won. `ubx config` walks the same cascade every other command reads,
merges it, and prints each key's effective value next to the exact file
that supplied it, never a guess.

## Usage

```bash
ubx config [--stack <stack>]
```

## Examples

```bash
ubx config
```

```bash
stack             payments        (payments/.ubx/config.hcl)
provider.version  6.54.0          (prod/.ubx/config.hcl)
github_repo       acme/infra      (.ubx/config.hcl)

cascade stopped: repo boundary (/Users/roozbeh/infra)
```

With a remote ledger store configured, the resolved address derives too:

```bash
ubx config --stack payments
```

```bash
ledger address (stack "payments"): s3://acme-infra-ledger/payments
```

## Flags

<ResponseField name="--stack" type="string">
  Which stack to derive the `[ledger]` store's full address against, if it names a remote store.
</ResponseField>

## Notes

If nothing is found at all, from the current directory all the way to
the filesystem root, that's reported plainly rather than silently
printing an empty result. This command never modifies anything, it's
read-only, the same trust as any other reporting command.

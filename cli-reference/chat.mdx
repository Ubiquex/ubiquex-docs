---
title: "ubx chat"
description: "Interactively draft intent, one turn at a time, redrafted fresh after every message."
---

The chat medium's real entry point. Each line you type is one turn. The
whole conversation gets redrafted from scratch after every turn, never
an incremental patch, so a later message that contradicts an earlier one
is handled honestly rather than half-applied.

Nothing is written to disk until you explicitly finalize the session.
Quit or disconnect before that, and nothing was ever saved at all.

## Usage

```bash
ubx chat --stack <stack> [flags]
```

## Examples

```bash
ubx chat --stack payments
```

```bash
ubx chat: type a turn and press enter. /save to finalize, /quit (or EOF) to abandon without saving anything.
> We need a Postgres database for payments, like staging but smaller.
> Make it multi-az.
> /save
captured dialogue: dialogues/9f2a1b3c....dlg.json
{ "schema_version": 1, "kind": "ubx:intent/v1", "stack": "payments", "resources": [ "..." ] }
```

## Flags

<ResponseField name="--stack" type="string">
  Target stack name. Required.
</ResponseField>

<ResponseField name="--ledger-dir" type="string" default=".">
  Root directory containing `ledger/`, `dialogues/`, and `.ubx/` (default `.`).
</ResponseField>

<ResponseField name="--out" type="string">
  Write the finalized draft here instead of stdout. Only takes effect on `/save`.
</ResponseField>

<ResponseField name="--timeout" type="string" default="3m">
  Timeout for each turn's own drafting round trip (default `3m`).
</ResponseField>

## Notes

`/save` writes the real captured conversation, redacted as it was typed,
to `dialogues/<hash>.dlg.json` and emits the final draft. `/quit`, or
plain EOF, abandons the session, nothing on disk, nothing partially
written. A single turn that fails to draft doesn't lose the
conversation, the turn itself stays recorded and the next one tries
again with full context.
